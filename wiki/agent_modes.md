# Agent Modes Guide

Agent modes provide focused workflows for working with this repository. Use the mode that matches the current stage of your task and hand off when you need a different capability.

| Goal | Recommended mode |
|------|------------------|
| Understand an unfamiliar area | [Explore](../agent_modes/Explore.md) |
| Break down a complex change | [Plan](../agent_modes/Plan.md) |
| Implement a change | [Agent](../agent_modes/Agent.md) |
| Diagnose a failure | [Debug](../agent_modes/Debug.md) |
| Add or run tests | [Test](../agent_modes/Test.md) |
| Check quality or architecture | [Review](../agent_modes/Review.md) |
| Assess security | [Secure](../agent_modes/Secure.md) |
| Ask a focused question | [Ask](../agent_modes/Ask.md) |
| Discuss ideas informally | [Chat](../agent_modes/Chat.md) |

## Recommended workflow

For a substantial change, use **Explore → Plan → Agent → Test → Review**. For a defect, use **Debug → Agent → Test**. Revisit this guide whenever the task moves from research to implementation or verification.

See the complete [agent mode reference](../agent_modes/README.md) for descriptions and handoff examples.
