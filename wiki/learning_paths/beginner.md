# Learning Paths

## Overview

Structured learning paths to help you progress from beginner to advanced AI engineering.

---

## 🌱 Beginner Path

**Target Audience:** New to AI/ML, basic Python knowledge

### Prerequisites
- Python fundamentals (variables, loops, functions)
- Basic mathematics (algebra, functions)
- Command line basics

### Curriculum

#### Phase 1: Foundations (4-6 weeks)
1. **Python for Data Science**
   - NumPy arrays and operations
   - Pandas data manipulation
   - Matplotlib/Seaborn visualization

2. **Mathematics Essentials**
   - Linear algebra basics (vectors, matrices)
   - Calculus fundamentals (derivatives, gradients)
   - Probability basics

3. **ML Concepts Introduction**
   - What is machine learning?
   - Supervised vs unsupervised learning
   - Training/testing split

#### Phase 2: First Models (4-6 weeks)
1. **Classical ML Algorithms**
   - Linear regression
   - Logistic regression
   - Decision trees
   - K-means clustering

2. **Model Evaluation**
   - Accuracy, precision, recall
   - Cross-validation
   - Overfitting and underfitting

3. **Scikit-learn Basics**
   - Building pipelines
   - Hyperparameter tuning
   - Model persistence

#### Phase 3: Deep Learning Intro (4-6 weeks)
1. **Neural Networks Fundamentals**
   - Perceptrons and activation functions
   - Forward and backward propagation
   - Loss functions and optimizers

2. **First Neural Network**
   - Building with PyTorch/TensorFlow
   - Training loops
   - Debugging models

### Projects
- House price prediction
- Image classifier (MNIST/CIFAR-10)
- Customer segmentation

## 🚀 Intermediate Path

**Target Audience:** Some ML experience, built a few models

### Prerequisites
- Completed beginner path or equivalent
- Comfortable with Python and Jupyter notebooks
- Built at least 2-3 ML projects

### Curriculum

#### Phase 1: Advanced Deep Learning (6-8 weeks)
1. **Convolutional Neural Networks**
   - CNN architectures (ResNet, EfficientNet)
   - Transfer learning
   - Data augmentation

2. **Sequence Models**
   - RNNs and LSTMs
   - GRUs
   - Attention mechanisms

3. **Transformers**
   - Self-attention mechanism
   - BERT and variants
   - Fine-tuning pretrained models

#### Phase 2: MLOps Fundamentals (6-8 weeks)
1. **Version Control**
   - DVC for data versioning
   - Model versioning
   - Experiment tracking (MLflow, Weights & Biases)

2. **Pipeline Automation**
   - CI/CD for ML
   - Automated testing
   - Reproducible experiments

3. **Model Deployment**
   - REST APIs with FastAPI
   - Containerization with Docker
   - Cloud deployment basics

#### Phase 3: Specialization (Choose One)
- **Computer Vision**: Object detection, segmentation
- **NLP**: Text classification, named entity recognition
- **Recommendation Systems**: Collaborative filtering, ranking
- **Time Series**: Forecasting, anomaly detection

### Projects
- End-to-end ML pipeline
- Deployed model with API
- Fine-tuned transformer model

## 🔥 Advanced Path

**Target Audience:** Production AI engineers, building complex systems

### Prerequisites
- Completed intermediate path or equivalent
- Deployed models to production
- Strong understanding of ML/DL concepts

### Curriculum

#### Phase 1: Advanced Topics (8-10 weeks)
1. **Large Language Models**
   - LLM architectures
   - Prompt engineering
   - RAG systems
   - Fine-tuning strategies (LoRA, QLoRA)

2. **Generative AI**
   - GANs and variants
   - Diffusion models
   - VAEs

3. **Graph Neural Networks**
   - Graph convolutions
   - Message passing
   - Applications

#### Phase 2: Production Excellence (8-10 weeks)
1. **Scalable Inference**
   - Model optimization (quantization, pruning)
   - Distributed inference
   - Caching strategies

2. **Monitoring & Observability**
   - Model drift detection
   - Performance monitoring
   - Logging and alerting

3. **Security & Compliance**
   - Adversarial attacks
   - Privacy-preserving ML
   - Model governance

#### Phase 3: System Design (8-10 weeks)
1. **Architecture Patterns**
   - Microservices for ML
   - Event-driven architectures
   - Real-time vs batch processing

2. **Cost Optimization**
   - Resource management
   - Spot instances
   - Model compression

3. **Team Leadership**
   - Code reviews for ML
   - Documentation best practices
   - Mentoring junior engineers

### Projects
- Multi-model production system
- Real-time inference platform
- Custom LLM application with RAG

## Assessment Checkpoints

### Beginner → Intermediate
- [ ] Can explain bias-variance tradeoff
- [ ] Built and deployed a simple model
- [ ] Understand backpropagation
- [ ] Comfortable with PyTorch/TensorFlow basics

### Intermediate → Advanced
- [ ] Deployed multiple models to production
- [ ] Implemented CI/CD for ML
- [ ] Fine-tuned a transformer model
- [ ] Can debug model performance issues

### Advanced Mastery
- [ ] Designed scalable ML architecture
- [ ] Implemented monitoring and alerting
- [ ] Led ML project from conception to production
- [ ] Contributed to open-source ML projects
