# Research Skills

Information gathering, analysis, and critical thinking capabilities.

## Skills in This Category

- **Critical Thinking** - Logical reasoning and fallacy detection
- **Information Retrieval** - Effective search and evaluation techniques

## Why Research Skills Matter

Strong research skills enable:
- Faster problem resolution
- Better decision making
- Informed technical choices
- Continuous learning
- Evidence-based conclusions

## Getting Started

Start with [`critical_thinking.md`](critical_thinking.md) for foundational reasoning skills.
