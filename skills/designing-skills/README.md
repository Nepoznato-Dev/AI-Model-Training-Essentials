# Designing Skills

Design-related competencies for building better products and systems.

## Skills in This Category

- **API Design** - REST, GraphQL, gRPC interface design
- **GUI Design** - Graphical user interface principles
- **System Architecture** - Large-scale system design patterns
- **UI/UX Design** - User interface and experience design
- **Visual Design** - Visual aesthetics and branding

## Why Design Skills Matter

Good design enables:
- Better user experiences
- Maintainable systems
- Scalable architectures
- Consistent interfaces
- Reduced technical debt
