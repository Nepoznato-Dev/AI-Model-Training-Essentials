Text Formatting Skill

This skill allows you to format and display text in different styles using Markdown syntax.

You can use the following formatting options:

Text Styles
Bold

Use two asterisks to make text bold.

Example:
**bold example**

Result:
bold example

Italic

Use one asterisk to make text italic.

Example:
*italic example*

Result:
italic example

Bold + Italic

Use three asterisks to make text both bold and italic.

Example:
***bold and italic example***

Result:
bold and italic example

Underline

Use underscores to underline text.

Example:
_underlined example_

Result:
underlined example

Strikethrough

Use tildes to cross out text.

Example:
~~strikethrough example~~

Result:
strikethrough example

Links

To add a clickable link:

Example:
[link text](URL)

Result:
link text

Replace URL with the website address.

Headings

Use # symbols to create headings.

Example:

# Large Heading
## Medium Heading
### Small Heading

Result:

Large Heading
Medium Heading
Small Heading
Lists
Bullet Lists

Use - or * before items.

Example:

- Item one
- Item two
- Item three

Result:

Item one
Item two
Item three
Numbered Lists

Use numbers followed by a period.

Example:

1. First item
2. Second item
3. Third item

Result:

First item
Second item
Third item
Code Formatting
Inline Code

Use backticks for small code snippets.

Example:
print("Hello")

Result:
print("Hello")

Code Blocks

Use three backticks for multiple lines of code.

Example:

```python
print("Hello")

Result:
```python
print("Hello")
Quotes

Use > to create a quote.

Example:

> This is a quote

Result:

This is a quote

Horizontal Lines

Use three dashes to create a separator.

Example:

---

Result:
Use these formatting tools to improve readability, organize information, and make text easier to understand.
