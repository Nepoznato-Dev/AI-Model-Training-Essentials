## Learning Paths

### New Engineer Path (start here)
Build foundational cognitive skills for effective individual work.

```
1. Learning → How to acquire knowledge efficiently
2. Debugging → How to solve problems systematically
3. Writing → How to communicate your work clearly
4. Planning → How to structure and estimate your work
5. Explanation → How to share understanding with others
```

### AI/ML Engineer Path
Skills specifically important for working with AI systems.

```
1. Prompt Engineering → Designing effective LLM interactions
2. Debugging → Investigating ML-specific failures
3. Planning → Scoping experiments and managing timelines
4. Brainstorming → Generating approaches to model design
5. Summarization → Condensing research findings and experiment results
```

### Tech Lead Path
Skills for multiplying your impact through others.

```
1. Explanation → Communicating technical decisions clearly
2. Teaching → Developing team members' capabilities
3. Planning → Breaking down complex initiatives
4. Style Adaptation → Maintaining consistency across team output
5. Brainstorming → Facilitating productive team ideation
```

## Why Behavior Skills Matter

Strong behavioral skills enable:
- Faster problem solving
- Better collaboration
- Continuous improvement
- Knowledge sharing
- Career growth
