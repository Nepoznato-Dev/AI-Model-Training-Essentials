# Behavior Skills

Cognitive and personal effectiveness skills for individual contributors.

## Skills in This Category

- **Brainstorming** - Idea generation and creative thinking
- **Debugging** - Systematic problem investigation and resolution
- **Explanation** - Clear technical communication
- **Learning** - Efficient knowledge acquisition
- **Planning** - Task decomposition and estimation
- **Style Adaptation** - Adapting to team and project conventions
- **Summarization** - Information condensation
- **Teaching** - Effective instruction and mentoring

## Why Behavior Skills Matter

Strong behavioral skills enable:
- Faster problem solving
- Better collaboration
- Continuous improvement
- Knowledge sharing
- Career growth

New contributors should start with [`learning.md`](learning.md) and [`debugging.md`](debugging.md).
