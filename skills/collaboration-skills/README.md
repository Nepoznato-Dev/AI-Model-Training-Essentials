# Collaboration Skills

Skills for working effectively with others in team environments.

## Skills in This Category

- **Code Review** - Providing and receiving constructive code feedback
- **Pair Programming** - Collaborative development techniques
- **Team Collaboration** - Working effectively in teams

## Why Collaboration Skills Matter

Effective collaboration enables:
- Higher code quality
- Knowledge sharing
- Faster problem solving
- Team cohesion
- Reduced bus factor

## Getting Started

Start with [`code_review.md`](code_review.md) for essential review practices.
