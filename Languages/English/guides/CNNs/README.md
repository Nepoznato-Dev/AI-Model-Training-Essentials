# CNN Training Guide

## Overview

Comprehensive guide to training Convolutional Neural Networks for computer vision tasks.

## Chapters

1. **Fundamentals and Architecture** - Convolution operations, classic architectures (LeNet, VGG, ResNet)
2. **Advanced Architectures** - ResNet, DenseNet, EfficientNet, Vision Transformers
3. **Training Techniques** - Transfer learning, data augmentation, regularization
4. **Specialized Applications** - Object detection, segmentation, image generation
