# Prerequisites

This directory contains foundational knowledge required before diving into advanced AI/ML topics.

## 📚 Contents

### Python Basics
- **File**: `python_basics.md`
- **Topics**: Syntax, data structures, functions, OOP, common libraries
- **Prerequisite for**: All guides and projects

### Mathematics for ML
- **File**: `mathematics_for_ml.md`
- **Topics**: Linear algebra, calculus, probability, statistics
- **Prerequisite for**: CNNs, GANs, GNNs, Transformers, MoE

### Machine Learning Fundamentals
- **File**: `ml_fundamentals.md`
- **Topics**: Supervised/unsupervised learning, neural networks, training basics
- **Prerequisite for**: Advanced architecture guides

### Git & Version Control
- **File**: `git_basics.md` (available in `/guides/User Questions/prerequisites/`)
- **Topics**: Git commands, branching, collaboration workflows
- **Prerequisite for**: Contributing to projects

### Terminal/Command Line
- **File**: `terminal_basics.md` (available in `/guides/User Questions/prerequisites/`)
- **Topics**: Basic commands, navigation, scripting
- **Prerequisite for**: Running projects and tools

## 🎯 Learning Path

1. **Start Here**: Assess your current knowledge
2. **Python Basics**: Ensure strong Python foundation
3. **Mathematics**: Review math concepts as needed
4. **ML Fundamentals**: Understand core ML concepts
5. **Tools**: Learn Git and terminal basics
6. **Proceed to Guides**: Choose your specialization track

## ✅ Self-Assessment Checklist

Before starting advanced guides, you should be comfortable with:

- [ ] Writing Python functions and classes
- [ ] Using NumPy for array operations
- [ ] Understanding matrix multiplication and derivatives
- [ ] Explaining what a neural network is
- [ ] Running Python scripts from the command line
- [ ] Using Git for version control
