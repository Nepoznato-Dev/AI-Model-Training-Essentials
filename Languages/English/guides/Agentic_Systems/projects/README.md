# Agentic Systems Projects

Runnable projects for Agentic AI Systems.

## Projects

### 1. Simple Agent with Memory

A basic agent implementation with short-term and long-term memory.

**Files:**
- `simple_agent_memory/` - Agent with memory capabilities

### 2. Multi-Agent Collaboration

Multiple agents working together to solve complex tasks.

**Files:**
- `multi_agent_collaboration/` - Collaborative multi-agent system

### 3. Tool-Using Agent

An agent that can use external tools and APIs to accomplish tasks.

**Files:**
- `tool_using_agent/` - Agent with tool integration

### 4. Autonomous Task Planner

An agent that can plan and execute multi-step tasks autonomously.

**Files:**
- `autonomous_planner/` - Autonomous planning agent

## Getting Started

```bash
# Install dependencies
pip install -r requirements.txt

# Run a project
python <project_name>/main.py
```

## Requirements

See the main `requirements.txt` file in each project folder.
