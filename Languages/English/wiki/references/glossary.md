# Glossary

## Overview

Common terms and definitions used in AI engineering.

---

## A

**Activation Function**  
A function applied to the output of a neural network layer to introduce non-linearity. Common examples: ReLU, Sigmoid, Tanh, GELU.

**Attention Mechanism**  
A technique that allows models to focus on relevant parts of the input when producing each part of the output. Foundation of Transformer architectures.

**Autoencoder**  
A neural network trained to compress input data into a lower-dimensional representation and then reconstruct it.

**Automated Machine Learning (AutoML)**  
Tools and techniques that automate the process of selecting, designing, and optimizing machine learning models.

---

## B

**Backpropagation**  
The algorithm used to train neural networks by computing gradients of the loss function with respect to model parameters.

**Batch Size**  
The number of training samples processed before updating model parameters.

**Bias-Variance Tradeoff**  
The balance between a model's ability to fit training data (low bias) and generalize to new data (low variance).

**Batch Normalization**  
A technique to normalize layer inputs during training, improving stability and convergence speed.

---

## C

**Checkpoint**  
A saved snapshot of model weights and training state that can be restored later.

**Computer Vision (CV)**  
Field of AI focused on enabling machines to interpret and understand visual information.

**Convolutional Neural Network (CNN)**  
A neural network architecture designed for processing grid-like data such as images, using convolution operations.

**Cross-Validation**  
A technique for evaluating model performance by training and testing on different subsets of data.

---

## D

**Data Augmentation**  
Techniques to artificially increase training data size by creating modified versions of existing data.

**Deep Learning**  
Subset of machine learning using multi-layer neural networks to learn hierarchical representations.

**Diffusion Model**  
A generative model that learns to reverse a gradual noising process to generate new data samples.

**Dropout**  
A regularization technique that randomly sets a fraction of input units to zero during training.

---

## E

**Embedding**  
A dense vector representation of discrete items (words, users, products) in a continuous space.

**Epoch**  
One complete pass through the entire training dataset.

**Experiment Tracking**  
The practice of recording and comparing different model training runs, hyperparameters, and results.

**Ensemble Learning**  
Combining multiple models to improve overall performance and robustness.

---

## F

**Fine-tuning**  
The process of further training a pretrained model on a specific task or dataset.

**Feature Engineering**  
The process of selecting, modifying, or creating features from raw data to improve model performance.

**Federated Learning**  
A distributed learning approach where models are trained across multiple devices while keeping data localized.

**Few-Shot Learning**  
Learning to perform a task with only a small number of training examples.

---

## G

**Generative Adversarial Network (GAN)**  
A generative model consisting of a generator and discriminator trained in opposition.

**Gradient Descent**  
An optimization algorithm that minimizes loss by iteratively moving in the direction of steepest descent.

**Graph Neural Network (GNN)**  
Neural networks designed to operate on graph-structured data.

**Ground Truth**  
The actual, correct labels or values used for training and evaluation.

---

## H

**Hyperparameter**  
Configuration settings for a model that are set before training (e.g., learning rate, number of layers).

**Hidden State**  
The internal representation maintained by recurrent neural networks across time steps.

**Hugging Face**  
A company and platform providing tools and pretrained models for NLP and other ML tasks.

---

## I

**Inference**  
The process of using a trained model to make predictions on new data.

**Imbalanced Dataset**  
A dataset where classes are not represented equally, potentially causing model bias.

**Instance Segmentation**  
Computer vision task that detects and delineates each distinct object in an image.

---

## L

**Large Language Model (LLM)**  
A language model with billions of parameters trained on vast amounts of text data.

**Learning Rate**  
Hyperparameter controlling the step size during optimization; critical for training stability.

**Loss Function**  
A function that measures how well model predictions match the actual targets.

**Long Short-Term Memory (LSTM)**  
A type of recurrent neural network designed to capture long-range dependencies.

---

## M

**Machine Learning Operations (MLOps)**  
Practices for deploying, monitoring, and maintaining ML models in production.

**Model Drift**  
Degradation in model performance over time due to changes in data distribution.

**Multi-task Learning**  
Training a single model to perform multiple related tasks simultaneously.

**Mean Squared Error (MSE)**  
Common loss function for regression tasks measuring average squared difference.

---

## N

**Natural Language Processing (NLP)**  
Field of AI focused on interaction between computers and human language.

**Neural Network**  
Computing system inspired by biological neural networks, composed of interconnected nodes.

**Normalization**  
Scaling data to a standard range, often [0,1] or with zero mean and unit variance.

**Negative Sampling**  
Technique for training embeddings by sampling negative examples.

---

## O

**Overfitting**  
When a model learns training data too well, including noise, reducing generalization.

**Optimization**  
The process of adjusting model parameters to minimize the loss function.

**Object Detection**  
Computer vision task that identifies and locates objects in images.

**One-Shot Learning**  
Learning from a single training example per class.

---

## P

**Pretraining**  
Initial training on a large general dataset before fine-tuning on specific tasks.

**Precision and Recall**  
Metrics for classification: precision measures accuracy of positive predictions, recall measures coverage of actual positives.

**Prompt Engineering**  
Crafting effective inputs to guide language model outputs.

**PyTorch**  
Open-source deep learning framework developed by Meta's AI Research lab.

---

## Q

**Quantization**  
Reducing numerical precision of model weights to decrease size and improve inference speed.

**Query**  
Input provided to retrieve relevant information from a model or database.

---

## R

**Recurrent Neural Network (RNN)**  
Neural network designed for sequential data with connections forming directed cycles.

**Reinforcement Learning (RL)**  
Learning paradigm where agents learn through interaction with an environment via rewards.

**Retrieval-Augmented Generation (RAG)**  
Architecture combining retrieval from external knowledge with generative models.

**Regularization**  
Techniques to prevent overfitting by adding constraints to the learning process.

---

## S

**Supervised Learning**  
Learning from labeled training data with input-output pairs.

**Stochastic Gradient Descent (SGD)**  
Variant of gradient descent using random mini-batches for parameter updates.

**Self-Attention**  
Attention mechanism where queries, keys, and values all come from the same source.

**Semantic Segmentation**  
Computer vision task assigning class labels to every pixel in an image.

---

## T

**Transfer Learning**  
Applying knowledge from one task to improve performance on a different but related task.

**Token**  
Basic unit of text in NLP (word, subword, or character).

**Transformer**  
Neural network architecture based on self-attention, dominant in modern NLP.

**Temperature**  
Hyperparameter controlling randomness in language model generation.

---

## U

**Unsupervised Learning**  
Learning from unlabeled data to find hidden patterns or structures.

**Underfitting**  
When a model is too simple to capture underlying patterns in data.

**Upsampling**  
Increasing the resolution or size of data, commonly used in generative models.

---

## V

**Validation Set**  
Data subset used to tune hyperparameters and evaluate model during development.

**Variational Autoencoder (VAE)**  
Generative model that learns a probabilistic mapping between latent space and data.

**Vector Database**  
Database optimized for storing and querying high-dimensional vectors/embeddings.

---

## W

**Weights**  
Learnable parameters in a neural network that determine transformation of inputs.

**Word Embedding**  
Vector representation of words capturing semantic meaning.

**Weight Decay**  
Regularization technique adding penalty for large weights (L2 regularization).

---

## Z

**Zero-Shot Learning**  
Performing a task without any task-specific training examples.

**Zone Out**  
Variant of dropout where entire regions of feature maps are dropped.
