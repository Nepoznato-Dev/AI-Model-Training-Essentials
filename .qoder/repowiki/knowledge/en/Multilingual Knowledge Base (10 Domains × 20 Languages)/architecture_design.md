The knowledge base is a flat filesystem repository with no executable code. It follows a strict mirrored directory schema: the root contains one top-level folder per language (Arabic, English, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Mandarin_Simplified, Mandarin_Traditional, Persian, Polish, Portuguese, Russian, Spanish, Thai, Turkish, Vietnamese), each replicating an identical set of ten numbered thematic directories (`01_coding_and_technology` through `10_quick_reference`). The English directory is the canonical source (138+ files) while other languages are progressively translated. Each thematic directory holds topic-specific Markdown files; `01_coding_and_technology/programming_languages/` further nests 34 individual programming-language subdirectories, each containing its own reference file. A root `README.md` indexes all languages and topics, and each language's `README.md` provides a full file index, learning paths, usage guidelines for both AI systems and human readers, and contribution instructions. Content is consumed as static documentation by upstream components (guides, skills, agent modes, wiki) rather than executed.
