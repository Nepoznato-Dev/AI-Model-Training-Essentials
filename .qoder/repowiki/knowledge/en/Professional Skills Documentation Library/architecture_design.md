The module is a flat documentation repository with no executable code. It is organized by domain categories (behavior-skills, collaboration-skills, data-skills, designing-skills, devops-skills, focused-skills, management-skills, research-skills, security-skills, speaking-skills, technical-skills, testing-skills), each containing a category README plus one or more skill files. The top-level `README.md` catalogs all categories and links to them, while `skill-creator.md` defines the canonical skill template, YAML frontmatter schema, naming conventions, contribution workflow, and quality checklist that every skill file must follow. Each skill file begins with a structured YAML frontmatter block (title, description, category, version, status, authors, changelog, review dates, tags, difficulty_level, prerequisites, estimated_reading_time, contribution metadata) followed by standardized sections: Overview, Core Competencies, When to Use, Framework/Methodology, Practical Templates, Common Pitfalls, Best Practices, Tools & Resources, Examples, Success Indicators, Related Skills, and Version Information. The `focused-skills/` directory serves as a curated entry point linking skills to concrete guides and projects in the parent repo, including hands-on exercises with deliberately broken code.
