The module is organized as a flat documentation-and-examples tree with no executable package code. It contains three layers: (1) top-level navigation and onboarding files (`README.md`, `progression_map.md`, `how_to_build_ai.md`, `hardware_reality_check.md`); (2) topic-specific guide directories (`RAG/`, `Transformers/`, `CNNs/`, `GANs/`, `GNNs/`, `MoE/`, `Agentic_Systems/`, `Orchestration_Patterns/`, `Infrastructure_Layers/`) each following a uniform chapter-based structure (`chapter_*.md` plus a per-guide `README.md` and an optional `projects/` subfolder); and (3) cross-cutting support folders — `prerequisites/` (mathematics and ML fundamentals), `errors/` (common error fixes like CUDA OOM and ImportError_Transformers), and `User Questions/` (a parallel set of prerequisites, case studies, hardware guides, and progression maps). The `projects/` directory holds standalone runnable scripts (`main.py` or `rag_chatbot.py`) paired with `requirements.txt` and a `README.md`, independent of the guide chapters. Dependency direction is one-way: guides reference projects and prerequisite/error docs via relative Markdown links; projects do not import anything outside their own folder.
