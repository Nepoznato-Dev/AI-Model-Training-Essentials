Each file in this directory is a self-contained mode definition consisting of a YAML frontmatter block followed by a system prompt. The frontmatter declares the mode's `name`, `description`, `argument-hint`, allowed `tools` (e.g., `search`, `read`, `edit`, `execute/*`, `github/*`), subordinate `agents` to delegate to, and optional `handoffs` that specify how to transition to another mode with a ready-to-send prompt. `Orchestrator.md` is the central coordinator that lists all other modes as its `agents` and delegates work across them; leaf modes like `Agent`, `Debug`, `Plan` declare their own handoffs back into the ecosystem. `README.md` provides a categorized quick-reference table and suggested end-to-end workflows (e.g., Explore → Plan → Agent → Test → Review) that compose these modes. There is no executable code — the module is purely declarative configuration consumed by an agent runtime that parses the frontmatter and loads the prompt body as the mode's behavior.
