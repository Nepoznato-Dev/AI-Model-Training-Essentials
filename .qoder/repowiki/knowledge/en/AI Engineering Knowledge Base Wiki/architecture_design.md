Pure documentation module organized as a flat wiki with two subdirectories: `learning_paths/` holds progressive curricula (beginner, intermediate, advanced) that link to the same set of core topic pages, and `references/` holds lookup-style docs (API reference, glossary, troubleshooting, checklist). The root `README.md` acts as the navigation entry point, linking all core topic files (`getting_started.md`, `architecture_patterns.md`, `model_development.md`, `deployment.md`, `monitoring.md`, `security.md`, `repository_guide.md`) and cross-referencing sibling directories in the parent repo (`guides/`, `skills/`, `knowledge_base/`, `agent_modes/`). There is no build step or runtime code — content is authored as Markdown and consumed directly by readers.
