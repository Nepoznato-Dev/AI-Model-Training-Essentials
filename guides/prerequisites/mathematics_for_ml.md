# Mathematics for Machine Learning

Essential mathematical concepts needed for understanding deep learning architectures.

## 1. Linear Algebra

### Vectors and Matrices
- Vector operations (addition, scalar multiplication, dot product)
- Matrix operations (addition, multiplication, transpose)
- Special matrices (identity, diagonal, symmetric, orthogonal)

### Matrix Decompositions
- Eigenvalues and eigenvectors
- Singular Value Decomposition (SVD)
- Principal Component Analysis (PCA)

### Applications in Deep Learning
- Weight matrices in neural networks
- Embedding spaces and transformations
- Attention mechanisms (query, key, value matrices)

## 2. Calculus

### Differential Calculus
- Derivatives and partial derivatives
- Chain rule (critical for backpropagation)
- Gradients and gradient vectors

### Integral Calculus
- Basic integration concepts
- Area under curves (for probability distributions)

### Optimization
- Gradient descent algorithms
- Second-order methods (Newton's method, Hessian)
- Constrained optimization (Lagrange multipliers)

### Applications in Deep Learning
- Backpropagation algorithm
- Loss function optimization
- Learning rate scheduling

## 3. Probability Theory

### Basic Probability
- Probability axioms and rules
- Conditional probability
- Bayes' theorem

### Random Variables
- Discrete and continuous distributions
- Expected value and variance
- Common distributions (Gaussian, Bernoulli, categorical)

### Applications in Deep Learning
- Probabilistic models (VAEs, GANs)
- Uncertainty estimation
- Bayesian neural networks

## 4. Statistics

### Descriptive Statistics
- Mean, median, mode
- Variance and standard deviation
- Correlation and covariance

### Inferential Statistics
- Hypothesis testing
- Confidence intervals
- Maximum likelihood estimation

### Applications in Deep Learning
- Batch normalization statistics
- Evaluation metrics
- Model comparison and selection

## 5. Information Theory

### Core Concepts
- Entropy and cross-entropy
- KL divergence
- Mutual information

### Applications in Deep Learning
- Loss functions (cross-entropy loss)
- Regularization techniques
- VAE objective functions

## ✅ Self-Assessment

You're ready for deep learning when you can:

- [ ] Multiply matrices and understand the geometric interpretation
- [ ] Compute gradients of multivariable functions
- [ ] Apply the chain rule for composite functions
- [ ] Explain what a probability distribution is
- [ ] Calculate entropy and cross-entropy
- [ ] Understand eigenvectors conceptually

## 💡 Tips for Learning

1. **Focus on intuition** before rigorous proofs
2. **Visualize concepts** using plots and diagrams
3. **Connect to ML**: Always ask "how is this used in neural networks?"
4. **Practice regularly**: Solve problems daily
5. **Use code**: Implement math operations in NumPy/PyTorch
