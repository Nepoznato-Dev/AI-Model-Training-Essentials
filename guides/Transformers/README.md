# Transformers Training Guide

## Overview

Comprehensive guide to understanding and training Transformer models from scratch.

## Chapters

1. **Architecture Fundamentals** - Attention mechanisms, encoder/decoder structure
2. **Pre-training Strategies** - MLM, NSP, causal language modeling
3. **Fine-tuning Techniques** - Task-specific adaptation, parameter-efficient methods
4. **Advanced Architectures** - BERT, GPT, T5, and modern variants

## Quick Start

```bash
pip install transformers torch datasets accelerate
```
