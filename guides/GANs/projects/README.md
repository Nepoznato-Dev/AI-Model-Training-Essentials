# GAN Projects

Runnable projects for Generative Adversarial Networks (GANs).

## Projects

### 1. DCGAN - Image Generation

Deep Convolutional GAN for generating realistic images.

**Files:**
- `dcgan_image_generation/` - DCGAN implementation

### 2. Style Transfer with CycleGAN

Unpaired image-to-image translation.

**Files:**
- `style_transfer_cyclegan/` - CycleGAN for style transfer

### 3. Super Resolution with SRGAN

Single image super-resolution using GANs.

**Files:**
- `super_resolution_srgan/` - SRGAN implementation

## Getting Started

```bash
# Install dependencies
pip install -r requirements.txt

# Run a project
python <project_name>/main.py
```

## Requirements

See the main `requirements.txt` file in each project folder.
