# CNN Projects

Runnable projects for Convolutional Neural Networks (CNNs).

## Projects

### 1. Image Classification with ResNet

A complete image classification project using ResNet architecture with residual blocks, skip connections, and data augmentation.

**Files:**
- `image_classification_resnet/` - Image classifier using ResNet
  - `main.py` - Full ResNet implementation with training loop
  - `requirements.txt` - Dependencies (torch, torchvision)

### 2. Object Detection with YOLO

Real-time object detection implementation.

**Files:**
- `object_detection_yolo/` - YOLO-based object detector

### 3. Semantic Segmentation

Pixel-level image segmentation using U-Net.

**Files:**
- `semantic_segmentation_unet/` - U-Net for semantic segmentation

## Getting Started

```bash
# Install dependencies
pip install -r requirements.txt

# Run a project
python <project_name>/main.py
```

## Requirements

See the main `requirements.txt` file in each project folder.
