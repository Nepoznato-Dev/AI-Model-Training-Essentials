# GNN Training Guide

## Overview

Comprehensive guide to training Graph Neural Networks for graph-structured data.

## Chapters

1. **Fundamentals** - Graph theory basics, message passing, aggregation
2. **Architectures** - GCN, GAT, GraphSAGE, MPNN
3. **Training Techniques** - Sampling, batching, handling large graphs
4. **Applications** - Node classification, link prediction, graph classification

## Quick Start

```bash
pip install torch torch-geometric
```
