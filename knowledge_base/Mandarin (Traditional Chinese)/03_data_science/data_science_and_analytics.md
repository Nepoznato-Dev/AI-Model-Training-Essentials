# 資料科學與分析

## 核心概念

### 什麼是資料科學？
資料科學是一個跨領域的學科，運用科學方法、流程、演算法和系統從結構化與非結構化資料中提取知識和洞察。它結合了：
- **統計學**：分析的數學基礎
- **電腦科學**：程式設計、演算法、資料結構
- **領域專業知識**：特定主題知識
- **資料視覺化**：有效傳達研究結果

### 資料類型
- **結構化資料**：以列/欄組織（資料庫、試算表）
- **非結構化資料**：無預定義格式（文字、圖像、音訊、視訊）
- **半結構化資料**：部分組織但不嚴格（JSON、XML、HTML）
- **時間序列資料**：按時間順序索引的序列資料點
- **空間資料**：地理/位置基礎資訊
- **圖資料**：節點和邊表示關係

### 資料科學流程（CRISP-DM）
1. **業務理解**：定義目標和需求
2. **資料理解**：收集和探索初始資料
3. **資料準備**：清理、轉換和格式化資料（佔 80% 的工作）
4. **建模**：選擇和應用建模技術
5. **評估**：根據目標評估模型效能
6. **部署**：在生產環境中實施模型

## 統計基礎

### 描述性統計
- **集中趨勢量數**：平均數、中位數、眾數
- **離散程度量數**：全距、變異數、標準差、四分位距
- **分佈形狀**：偏度（不對稱性）、峰度（尾部厚度）
- **百分位數和四分位數**：在分佈中的位置

### 推論統計
- **假設檢定**：虛無假設、對立假設、p 值
- **信賴區間**：可能包含母體參數的值範圍
- **統計顯著性**：結果偶然發生的可能性
- **型 I 誤差**：偽陽性（拒絕真實的虛無假設）
- **型 II 誤差**：偽陰性（未能拒絕錯誤的虛無假設）
- **檢定力**：正確拒絕錯誤虛無假設的機率

### 機率分佈
- **常態分佈**：鐘形曲線，平均數 = 中位數 = 眾數
- **二項分佈**：成功/失敗結果
- **卜瓦松分佈**：固定區間內的事件計數
- **均勻分佈**：所有結果機率相等
- **指數分佈**：事件之間的時間
- **t 分佈**：小樣本量，未知母體變異數
- **卡方分佈**：類別資料分析

### 統計檢定
- **t 檢定**：比較兩組之間的平均數
- **ANOVA**：比較多組之間的平均數
- **卡方檢定**：測試類別變數的獨立性
- **Mann-Whitney U**：t 檢定的無母數替代方法
- **Pearson 相關**：連續變數之間的線性關係
- **Spearman 相關**：單調關係（基於排名）
- **Kolmogorov-Smirnov**：比較分佈

## 資料收集與儲存

### 資料來源
- **資料庫**：SQL、NoSQL、關聯式、文件儲存
- **APIs**：REST、GraphQL、網路爬蟲
- **檔案**：CSV、JSON、XML、Parquet、Avro
- **串流資料**：Kafka、Kinesis、即時資料流
- **調查和實驗**：主要資料收集
- **公開資料集**：政府資料、Kaggle、學術資源庫

### 資料倉儲
- **ETL**：擷取、轉換、載入流程
- **資料湖**：以原生格式儲存原始資料
- **資料倉儲**：用於分析的結構化、處理過的資料
- **資料超市**：倉儲的子集，用於特定部門
- **OLAP**：線上分析處理，多維查詢
- **星型架構**：由維度表包圍的事實表
- **雪花架構**：正規化的維度表

### 資料庫類型
- **關聯式（SQL）**：MySQL、PostgreSQL、Oracle、SQL Server
- **文件**：MongoDB、CouchDB（類 JSON 文件）
- **鍵值對**：Redis、DynamoDB（簡單的鍵值對）
- **欄族**：Cassandra、HBase（針對欄最佳化）
- **圖形**：Neo4j、Amazon Neptune（節點和關係）
- **時間序列**：InfluxDB、TimescaleDB（帶時間戳的資料）
- **向量**：Pinecone、Milvus（ML 的嵌入儲存）

## 資料預處理

### 資料清理
- **遺失值**：填補（平均數、中位數、眾數、預測）、刪除
- **離群值**：偵測（IQR、Z 分數）、處理（截斷、轉換）
- **重複**：識別和移除
- **不一致**：標準化格式、修正錯字
- **資料驗證**：檢查約束、範圍、類型

### 資料轉換
- **正規化**：縮放至 0-1 範圍
- **標準化**：Z 分數正規化（平均數 = 0，標準差 = 1）
- **編碼**：One-hot、標籤、順序、目標編碼
- **分箱**：將連續值分組為類別
- **對數轉換**：減少偏度
- **特徵縮放**：使特徵具有可比性

### 特徵工程
- **特徵創建**：從現有特徵衍生新特徵
- **特徵選擇**：選擇最相關的特徵
  - 過濾方法（相關性、卡方）
  - 包裝方法（遞迴特徵消除）
  - 嵌入方法（LASSO、基於樹的重要性）
- **降維**：PCA、t-SNE、UMAP
- **互動項**：特徵的乘積組合
- **多項式特徵**：創建高階項

## 探索性資料分析（EDA）

### EDA 技術
- **摘要統計**：描述集中趨勢、離散程度、形狀
- **單變量分析**：單一變數的分佈
- **雙變量分析**：兩個變數之間的關係
- **多變量分析**：多個變數的互動
- **相關分析**：識別關係和多重共線性
- **分群**：將相似觀測分組

### 視覺化工具
- **直方圖**：單一變數的分佈
- **盒鬚圖**：五數摘要、離群值偵測
- **散佈圖**：兩個連續變數之間的關係
- **熱力圖**：相關矩陣、密度
- **長條圖**：類別比較
- **折線圖**：隨時間的趨勢
- **小提琴圖**：帶盒鬚圖元素的分佈密度
- **配對圖**：變數對的多個散佈圖

### Python EDA 函式庫
- **pandas**：資料操作和分析
- **numpy**：數值運算
- **matplotlib**：基本繪圖
- **seaborn**：統計視覺化
- **plotly**：互動式視覺化
- **scipy**：科學運算和統計

## 資料科學中的機器學習

### 監督式學習
- **迴歸**：預測連續值
  - Linear Regression
  - Polynomial Regression
  - Ridge/LASSO/Elastic Net
  - Decision Tree Regressor
  - Random Forest Regressor
  - Gradient Boosting（XGBoost、LightGBM、CatBoost）
  
- **分類**：預測類別標籤
  - Logistic Regression
  - k-Nearest Neighbors
  - Naive Bayes
  - Support Vector Machines
  - Decision Trees
  - Random Forest
  - Gradient Boosting
  - Neural Networks

### 非監督式學習
- **聚類**：將相似觀測分組
  - k-Means
  - Hierarchical Clustering
  - DBSCAN（基於密度）
  - Gaussian Mixture Models
  - Spectral Clustering
  
- **降維**：減少特徵數量
  - Principal Component Analysis (PCA)
  - t-Distributed Stochastic Neighbor Embedding (t-SNE)
  - Uniform Manifold Approximation (UMAP)
  - Autoencoders
  
- **關聯規則**：找出共現項目
  - Apriori Algorithm
  - FP-Growth

### 模型評估
- **分類指標**：準確度、精確度、召回率、F1 分數、ROC-AUC、混淆矩陣
- **迴歸指標**：MAE、MSE、RMSE、R²、調整後 R²
- **交叉驗證**：k-fold、分層、留一法、時間序列分割
- **超參數調整**：網格搜尋、隨機搜尋、貝氏最佳化
- **學習曲線**：診斷偏差-變異權衡

## 進階分析

### 預測分析
- **預測**：時間序列預測（ARIMA、Prophet、LSTM）
- **風險建模**：信用評分、詐騙偵測、保險
- **客戶分析**：流失預測、傾向建模
- **需求預測**：庫存最佳化、供應鏈
- **維護預測**：設備故障預測

### 規範分析
- **最佳化**：線性規劃、整數規劃
- **模擬**：蒙地卡羅方法、離散事件模擬
- **決策分析**：決策樹、影響圖
- **A/B 測試**：實驗設計、統計顯著性
- **多臂老虎機**：自適應實驗

### 文字分析（NLP）
- **文字預處理**：分詞、詞幹提取、詞形還原
- **情感分析**：正面/負面/中立分類
- **主題建模**：LDA、NMF 用於主題發現
- **命名實體識別**：識別人物、地點、組織
- **文字分類**：垃圾郵件偵測、分類
- **詞嵌入**：Word2Vec、GloVe、BERT

## 資料倫理與治理

### 資料隱私
- **GDPR**：歐盟一般資料保護規範
- **CCPA**：加州消費者隱私法
- **HIPAA**：健康保險流通與責任法案（美國醫療）
- **匿名化**：移除個人識別資訊
- **差分隱私**：添加雜訊以保護個人
- **同意管理**：選擇加入/退出機制

### 資料品質
- **準確性**：資料的正確性
- **完整性**：所有必要資料都存在
- **一致性**：跨來源無矛盾
- **及時性**：資料在需要時可用
- **有效性**：符合定義的規則
- **唯一性**：無重複

### 偏差與公平性
- **抽樣偏差**：非代表性的資料收集
- **測量偏差**：有缺陷的資料收集工具
- **演算法偏差**：歧視性的模型預測
- **公平性指標**：人口統計平等、機會平等
- **偏差緩解**：預處理、處理中、後處理

### 資料治理框架
- **資料管理**：資料資產的責任
- **元資料管理**：關於資料的資料文件
- **資料血統**：追蹤資料流動和轉換
- **存取控制**：基於角色的權限
- **稽核追蹤**：記錄資料存取和變更
- **合規性**：遵守法規
