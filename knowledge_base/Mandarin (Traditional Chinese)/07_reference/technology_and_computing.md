# 技術與運算

## 什麼是電腦？

電腦是根據一組稱為程式的指令處理資料的電子裝置。現代電腦基於馮紐曼架構，由中央處理器（CPU）、記憶體、儲存裝置和輸入/輸出裝置組成。CPU 執行指令。RAM（隨機存取記憶體）在電腦運行時暫時儲存資料。SSD 和硬碟等儲存裝置永久儲存資料。

## 程式語言

程式語言是用於為電腦撰寫指令的形式語言。Python 是一種高階、直譯式、通用程式語言，以其簡單的語法和可讀性而聞名。它廣泛用於資料科學、機器學習、網頁開發和自動化。JavaScript 是網頁開發的主要語言，在瀏覽器中運行。Java 是一種編譯式、物件導向語言，廣泛用於企業軟體和 Android 開發。C 和 C++ 是較低階的語言，對硬體提供細緻的控制，用於系統程式設計、遊戲開發和效能關鍵應用。Rust 是一種專注於安全性和效能的現代系統程式語言。

## 網際網路如何運作

網際網路是使用標準化協定通訊的相互連接電腦的全球網路。全球資訊網是透過瀏覽器經由網際網路存取的網站和網頁系統。HTTP（超文本傳輸協定）和 HTTPS（安全 HTTP）是用於傳輸網頁的協定。IP 位址是分配給網路上每個裝置的唯一數字位址。DNS（域名系統）將人類可讀的域名（如 google.com）轉換為 IP 位址。路由器在裝置和網路之間導向網路流量。

## 網路與協定

TCP/IP 是網際網路的基礎協定套件。IP（網際網路協定）處理網路之間的定址和封包路由，而 TCP（傳輸控制協定）提供可靠、有序的傳遞，具有重傳和流量控制。UDP 是無連接的替代方案，用於低延遲比保證傳遞更重要的情況（例如串流、遊戲或 DNS 查詢）。HTTP 是用於客戶端和伺服器之間請求/回應通訊的無狀態應用層協定。HTTPS 是基於 TLS 的 HTTP，增加了加密和完整性保護。REST（表現層狀態轉換）是一種 API 架構風格，使用資源、標準 HTTP 動詞（GET、POST、PUT、PATCH、DELETE）和無狀態互動。WebSockets 提供持久的全雙工連接，因此客戶端和伺服器可以即時推送訊息，這對聊天、即時儀表板和協作應用程式很有用。

## 人工智慧

人工智慧（AI）是機器（特別是電腦系統）對人類智慧的模擬。機器學習是 AI 的子集，其中系統從資料中學習以做出預測或決策，而無需明確編程。深度學習是使用具有多層神經網路的機器學習子集。神經網路是受生物大腦結構啟發的計算模型。大型語言模型（LLM）是在大量文本上訓練的 AI 模型，用於生成和理解自然語言。

## 演算法與資料結構

演算法是解決問題的逐步程序。資料結構是在電腦中組織資料的方式，以便可以有效地存取和修改。常見的資料結構包括陣列、鏈結串列、堆疊、佇列、樹、圖和雜湊表。排序演算法以指定順序排列項目；常見範例有氣泡排序、合併排序和快速排序。二元搜尋是透過反覆將搜尋範圍減半來在已排序列表中尋找項目的高效演算法。

## 資料庫

資料庫是以電子方式儲存的結構化資料的有組織集合。關聯式資料庫將資料儲存在具有行和列的表格中。SQL（結構化查詢語言）是管理和查詢關聯式資料庫的標準語言。NoSQL 資料庫以表格關係以外的格式儲存資料，例如文件、鍵值對或圖形。常見的資料庫系統包括 PostgreSQL、MySQL、SQLite、MongoDB 和 Redis。資料庫中的索引以額外儲存為代價加速資料檢索。

## 系統設計基礎

系統設計專注於構建可靠、可擴展和可維護的軟體系統。負載平衡在多個伺服器之間分配流量，以提高可用性並減少延遲。水平擴展增加更多機器；垂直擴展為一台機器增加更多資源。快取將經常存取的資料儲存在快速儲存中（例如 Redis、Memcached 或 CDN 邊緣快取），以減少資料庫負載和回應時間。大規模資料庫需要複製、分區（分片）、備份策略和謹慎的一致性權衡。微服務將大型應用程式拆分為較小的獨立可部署服務，而單體應用程式將大部分邏輯保留在一個可部署單元中；兩種方法都涉及複雜性、部署速度、除錯和團隊自主性的權衡。

## 作業系統

作業系統（OS）是管理電腦硬體並為程式提供服務的軟體。常見的作業系統包括 Windows、macOS 和 Linux。Linux 是用於伺服器、嵌入式系統和 Android 的開源作業系統核心。作業系統管理程序（運行中的程式）、記憶體、檔案系統和輸入/輸出裝置。程序是程式的運行實例。執行緒是程序內執行的最小單元。

## 版本控制

版本控制系統追蹤程式碼隨時間的變化，允許開發人員協作並還原到先前狀態。Git 是最廣泛使用的版本控制系統。儲存庫（repo）是檔案及其歷史記錄的集合。提交是變更的已儲存快照。分支是獨立的開發線。拉取請求是將變更從一個分支合併到另一個分支的提議。

## 軟體開發實踐

物件導向程式設計（OOP）將程式碼組織成結合資料和行為的物件。OOP 的關鍵原則包括封裝、繼承、多型和抽象。測試驅動開發（TDD）是在撰寫程式碼之前撰寫測試的實踐。敏捷是一套強調迭代開發、協作和適應性的軟體開發方法論。DevOps 結合軟體開發和 IT 營運以縮短開發生命週期。API（應用程式介面）允許不同的軟體系統相互通訊。

## 雲端與 DevOps 基礎

雲端運算透過網際網路提供按需基礎設施和託管服務。三大公共雲端提供商是 AWS（Amazon Web Services）、Microsoft Azure 和 Google Cloud Platform（GCP）。常見的服務模型是 IaaS（基礎設施）、PaaS（平台）和 SaaS（軟體）。核心雲端構建塊包括運算實例/容器、物件儲存、託管資料庫、網路和 IAM（身分與存取管理）。CI/CD（持續整合和持續交付/部署）自動化構建、測試和發布管線，使程式碼可以安全地從提交轉移到生產環境。Docker 將應用程式和相依性打包到可移植容器中；在生產環境中，這些容器通常透過編排器（如 Kubernetes）、無伺服器平台或託管容器服務部署。

## 資料格式與工具

JSON（JavaScript 物件表示法）是由物件（鍵/值對）、陣列、字串、數字、布林值和 null 構建的輕量級文字格式；它廣泛用於 API。YAML 是支援巢狀結構和註解的人性化組態格式，常用於 CI/CD 和基礎設施定義。CSV（逗號分隔值）將表格資料儲存為分隔文字的行，常用於資料匯入/匯出管線。XML（可延伸標記語言）是用於舊式系統、組態和文件工作流程的基於標籤的結構化格式。開發人員通常使用 linter、結構描述驗證器（如 JSON Schema）、查詢工具（`jq`、XPath）和程式語言中的解析程式庫來驗證和轉換這些格式。

## 正規表示式（Regex）

正規表示式是用於搜尋、配對、擷取和轉換文字的模式語言。核心 regex 概念包括字面值（`cat`）、字元類別（`[a-z]`、`\d`）、量詞（`*`、`+`、`?`、`{n,m}`）、錨點（`^`、`$`）、群組（`(...)`）、替換（`a|b`）和跳脫特殊字元。Regex 大量用於輸入驗證、日誌解析、文字擷取和尋找/取代自動化。不同引擎（PCRE、JavaScript、Python `re`、RE2）有不同的功能集，因此工具之間的行為可能有所不同。Regex 功能強大但可能變得難以閱讀；複雜的模式應該經過測試和記錄以避免錯誤。

## 網路安全

網路安全是保護電腦系統、網路和資料免受數位攻擊的實踐。常見威脅包括惡意軟體（惡意軟體）、網路釣魚（旨在竊取資訊的詐騙通訊）、勒索軟體（加密資料並要求付款的惡意軟體）和拒絕服務攻擊。加密將資料轉換為只能用金鑰解碼的不可讀形式。HTTPS 使用 TLS（傳輸層安全性）來加密網頁流量。強大、獨特的密碼和雙因素驗證是基本的安全實踐。

## 開發人員的安全概念

OAuth 2.0 是一種授權框架，允許使用者授予應用程式有限存取權，而無需直接共享憑證。OpenID Connect（OIDC）是建立在 OAuth 2.0 之上的身分層，用於驗證。JWT（JSON Web Token）是包含宣告的緊湊令牌格式，通常用於無狀態驗證，但必須正確簽署並嚴格驗證（簽章、過期、發行者、受眾）。TLS 透過證書提供加密、完整性和伺服器驗證來保護傳輸中的資料。OWASP Top 10 是廣泛使用的常見網頁應用程式安全風險清單，包括存取控制中斷、加密失敗、注入、不安全設計、安全性組態錯誤、易受攻擊的元件以及日誌記錄/監控不足。安全開發需要深度防禦：輸入驗證、輸出編碼、最小權限、機密管理、相依性修補和定期安全測試。
