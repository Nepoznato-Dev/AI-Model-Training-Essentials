## 🔧 使用指南

### 適用於 AI 系統
- 所有檔案均採用清晰的層次結構標題
- 技術術語在內文中定義或在 `dictionary.md` 中查找
- 交叉引用使用 markdown 連結
- 程式碼範例包含語法突顯

### 適用於人類讀者
- 每個檔案開頭包含學習目標
- 標註適用的難度等級
- 技術檔案中包含練習和實作問題
- 在有幫助的地方使用視覺輔助（圖表、表格）

## 📝 貢獻

新增或修改內容時：

1. **遵循樣式指南：**
   - 僅對檔案標題使用 `#`
   - 對主要章節使用 `##`
   - 對小節使用 `###`
   - 對無序列表使用 `-`
   - 在程式碼區塊中包含語法突顯

2. **新增中繼資料**（YAML frontmatter）：
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **對事實性陳述包含引用來源**
4. **新增相關檔案的交叉引用**
5. **如果新增新檔案，請更新此 README**
