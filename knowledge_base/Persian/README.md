## 📝 مشارکت

هنگام اضافه کردن یا تغییر محتوا:

1. **دستورالعمل سبک را دنبال کنید:**
   - از `#` فقط برای عنوان فایل استفاده کنید
   - از `##` برای بخش‌های اصلی استفاده کنید
   - از `###` برای زیربخش‌ها استفاده کنید
   - از `-` برای لیست‌های نامرتب استفاده کنید
   - برجسته‌سازی نحو را در بلوک‌های کد بگنجانید

2. **فراداده اضافه کنید** (frontmatter YAML):
```yaml
---
title: "عنوان فایل"
description: "توضیح مختصر"
topics: [موضوع1, موضوع2, موضوع3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **ارجاعات را بگنجانید** برای ادعاهای واقعی
4. **ارجاعات متقابل اضافه کنید** به فایل‌های مرتبط
5. **این README را به‌روز کنید** اگر فایل جدید اضافه می‌کنید
