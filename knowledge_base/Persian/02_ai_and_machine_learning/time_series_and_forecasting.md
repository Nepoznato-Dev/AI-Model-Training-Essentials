# سری زمانی و پیش بینی
داده های سری زمانی هر داده ای است که در طول زمان جمع آوری می شود: قیمت سهام، خوانش دما، ترافیک وب سایت، ارقام فروش، نمایشگر ضربان قلب، مصرف انرژی. پیش بینی به معنای پیش بینی ارزش های آینده بر اساس الگوهای گذشته است. این یکی از کاربردی‌ترین کاربردهای علم داده و یکی از سخت‌ترین کاربردها است، زیرا آینده واقعاً نامشخص است و سری‌های زمانی دنیای واقعی پر از نویز، فصلی و شکست‌های ساختاری است.
---

## ویژگی های سری زمانی
| جزء | توضیحات | مثال |
|-----------|-------------|---------|
| **روند** | افزایش یا کاهش بلند مدت | افزایش دمای جهانی طی دهه ها |
| **فصلی** | الگوهای منظم و قابل پیش بینی در فواصل زمانی ثابت | فروش خرده فروشی در دسامبر هر سال افزایش می یابد |
| **دوچرخه** | نوسانات در فواصل غیر ثابت (اغلب اقتصادی) | رکود هر 5-10 سال |
| **نویز (باقیمانده)** | تغییرات تصادفی که قابل توضیح نیست | حرکت روزانه قیمت سهام |
| **خودهمبستگی** | مقادیر فعلی به مقادیر گذشته بستگی دارد | دمای امروز مشابه دمای دیروز |
### ایستایی
یک سری زمانی **ایستا** است اگر ویژگی های آماری آن (میانگین، واریانس) در طول زمان تغییر نکند. اکثر روش های پیش بینی ثابت بودن را فرض می کنند.
| تست | هدف |
|------|---------|
| **افزوده دیکی-فولر (ADF)** | آزمایش می کند که آیا یک ریشه واحد وجود دارد (غیر ساکن) |
| **تست KPSS** | آزمایش می کند که آیا این سری روند ثابت است |
| تحول | زمان استفاده |
|---------------|-------------|
| **متفاوت ** | حذف روند: y'(t) = y(t) - y(t-1) |
| **تبدیل لاگ** | تثبیت واریانس (برای رشد نمایی) |
| **تفاوت فصلی** | حذف فصلی بودن: y'(t) = y(t) - y(t-s) که در آن s طول فصل است |

## روش های پیش بینی کلاسیک
### میانگین های متحرک
| روش | توضیحات | بهترین برای |
|--------|------------|----------|
| **میانگین متحرک ساده (SMA)** | میانگین آخرین N مشاهدات | صاف کردن داده های نویز |
| **میانگین متحرک وزنی** | مشاهدات اخیر وزن بیشتری دارند | وقتی داده های اخیر اهمیت بیشتری دارد |
| **میانگین متحرک نمایی (EMA)** | وزن های در حال کاهش نمایی | پیگیری روندها با تاخیر کمتر |
### هموارسازی نمایی
| روش | اجزاء | مورد استفاده |
|--------|-----------|----------|
| **ساده (SES)** | فقط سطح | بدون روند، بدون فصلی |
| **هولت (دوبل)** | سطح + روند | داده هایی با روند اما بدون فصلی |
| **Holt-Winters (سه گانه)** | سطح + روند + فصلی | داده ها با روند و فصلی |
### آریما و انواع
ARIMA (AutoRegressive Integrated Moving Average) پیش‌بینی سری‌های زمانی کلاسیک است.
| جزء | معنی | پارامتر |
|-----------|---------|-----------|
| **AR (p)** | رگرسیون بر روی مقادیر p قبلی | چند مقدار گذشته برای استفاده |
| **من (د)** | تعداد مراحل متمایز برای ثابت کردن | چند بار تفاوت |
| **MA (q)** | مدل خطا به عنوان ترکیبی از خطاهای گذشته | تعداد خطاهای گذشته برای استفاده |
| نوع | پسوند | مورد استفاده |
|---------|-----------|----------|
| **ساریما** | اجزای فصلی (P، D، Q، s) را اضافه می کند | داده با فصلی قوی |
| **ARIMAX** | متغیرهای خارجی | وقتی از رویدادهای آینده مطلع شدید |
| **VAR** | ARIMA چند متغیره؛ چند سری وابسته به هم | وقتی متغیرها بر یکدیگر تأثیر می گذارند |

## رویکردهای مدرن ML
### LSTM و مدل های مبتنی بر RNN
| مدل | معماری | مزیت |
|-------|------------|-----------|
| **LSTM** | شبکه حافظه کوتاه مدت بلند مدت | وابستگی های زمانی دوربرد را می گیرد |
| **GRU** | واحد بازگشتی دردار (LSTM ساده تر) | آموزش سریعتر؛ عملکرد مشابه |
| **Seq2Seq** | رمزگذار - رمزگشا برای سری های زمانی | طول ورودی/خروجی انعطاف پذیر |
| **شبکه کانولوشن موقت (TCN)** | پیچیدگی های علّی متسع | آموزش موازی؛ میدان پذیرای طولانی |
### پیامبر (متا)
یک ابزار پیش‌بینی عملی که برای سری‌های زمانی تجاری طراحی شده است.
| ویژگی | توضیحات |
|---------|-------------|
| **تجزیه** | روند + فصلی + تعطیلات |
| **منعطف** | داده های از دست رفته، نقاط پرت، و شکست های ساختاری را مدیریت می کند |
| **قابل تفسیر** | کامپوننت ها برای انسان قابل خواندن هستند |
| **اتوماتیک** | پیش فرض های معقول؛ حداقل تنظیم مورد نیاز |
| قدرت | محدودیت |
|----------|------------|
| عالی برای معیارهای تجاری (فروش، کاربران) | برای داده های با فرکانس بسیار بالا ایده آل نیست |
| رسیدگی به تعطیلات و رویدادهای ویژه | فصلی بودن افزایشی یا ضربی را فرض می کند |
| مقاوم در برابر پرت | دقیق تر از یادگیری عمیق برای الگوهای پیچیده |
### مدل های مبتنی بر ترانسفورماتور
| مدل | ویژگی کلیدی |
|-------|------------|
| **اطلاع دهنده** | توجه پراکنده برای دنباله های طولانی |
| **Autoformer** | مکانیزم همبستگی خودکار برای تجزیه سری |
| **PatchTST** | وصله سری زمانی. مستقل از کانال |
| **TimesFM** (گوگل) | مدل پایه برای سری های زمانی; از پیش آموزش داده شده بر روی داده های متنوع |
| **کرونوس** (آمازون) | سری های زمانی توکنیز از معماری به سبک LLM استفاده می کند |

## تشخیص ناهنجاری در سری های زمانی
تشخیص الگوهای غیرعادی که از رفتار مورد انتظار منحرف می شوند.
| روش | رویکرد | مورد استفاده |
|--------|----------|----------|
| **آماری** | Z-score، IQR، نمودارهای کنترل | ساده، قابل درک |
| **جنگل ایزوله** | مبتنی بر درخت؛ جداسازی ناهنجاری ها با پارتیشن بندی تصادفی | تشخیص ناهنجاری چند متغیره |
| **LOF** (Local Outlier Factor) | بر اساس تراکم؛ تراکم محلی را با همسایگان مقایسه می کند | وقتی ناهنجاری ها در مناطق کم تراکم هستند |
| **رمزگذارهای خودکار** | خطای بازسازی؛ خطای بالا = ناهنجاری | الگوهای پیچیده و غیر خطی |
| **مبتنی بر LSTM** | پیش بینی مرحله بعدی؛ خطای بزرگ پیش بینی = ناهنجاری | ناهنجاری های متوالی |
### برنامه های کاربردی
| دامنه | ناهنجاری به چه معناست |
|--------|-------------------|
| **مالی** | تقلب، سقوط بازار، سقوط فلش ​​|
| **بهداشت** | ضربان قلب غیر طبیعی، شروع تشنج |
| **ساخت ** | خرابی تجهیزات، عیوب کیفی |
| **امنیت سایبری** | تلاش برای نفوذ، حملات DDoS |
| **زیرساخت** | اضافه بار سرور، خرابی شبکه |

## معیارهای ارزیابی
| متریک | فرمول (مفهومی) | زمان استفاده |
|--------|--------------------|-------------|
| **MAE** (میانگین خطای مطلق) | میانگین خطاهای مطلق | قابل تفسیر؛ واحدهای مشابه داده |
| **RMSE** (ریشه میانگین مربعات خطا) | جذر میانگین مجذور خطاهای | خطاهای بزرگ را بیشتر جریمه می کند |
| **MAPE** (میانگین درصد مطلق خطا) | میانگین درصد مطلق خطا | وقتی خطای نسبی مهم است |
| **SMAPE** (Symmetric MAPE) | نسخه متقارن MAPE | مقادیر نزدیک به صفر را بهتر کنترل می کند |
| **MASE** (میانگین مطلق مقیاس خطا) | MAE نسبت به یک پیش بینی ساده لوحانه | مقایسه بین سری های مختلف |

## خلاصه
پیش‌بینی سری‌های زمانی آمار کلاسیک را با یادگیری ماشین مدرن ترکیب می‌کند. روش های کلاسیک (ARIMA، هموارسازی نمایی، پیامبر) قابل تفسیر، سریع و اغلب به طرز شگفت آوری دقیق هستند. روش‌های یادگیری عمیق (LSTM، ترانسفورماتورها) الگوهای پیچیده را ثبت می‌کنند اما به داده‌ها و تنظیم بیشتری نیاز دارند. اصول کلیدی بدون در نظر گرفتن روش یکسان باقی می مانند: ساختار داده های خود (روند، فصلی بودن، نویز) را درک کنید، همیشه با یک خط پایه ساده مقایسه کنید، با معیارهای مناسب ارزیابی کنید و به یاد داشته باشید که آینده هرگز تکرار کامل گذشته نیست.
