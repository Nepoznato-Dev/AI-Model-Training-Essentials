# بهینه سازی
بهینه سازی ریاضیات یافتن بهترین راه حل از مجموعه ای از راه حل های امکان پذیر است. می پرسد: با توجه به یک تابع و محدودیت ها، چه ورودی خروجی را به حداقل می رساند (یا حداکثر می کند)؟ بهینه سازی موتور یادگیری ماشینی است – آموزش یک مدل به معنای به حداقل رساندن یک تابع ضرر است. این در تحقیقات عملیات، اقتصاد، طراحی مهندسی و تقریباً در هر زمینه کمی ظاهر می شود.
---

## فرمول مشکل
یک مشکل کلی **بهینه سازی** به شکل زیر است:
به حداقل رساندن f(x)
موضوع: gᵢ(x) ≤ 0 (قیود نابرابری)، hⱼ(x) = 0 (قیود برابری)
| ترم | معنی |
|------|---------|
| **تابع هدف** f(x) | کمیت برای به حداقل رساندن (یا حداکثر کردن) |
| **متغیرهای تصمیم** x | مقادیری که می توانیم کنترل کنیم |
| **منطقه امکان پذیر** | مجموعه ای از تمام x که همه محدودیت ها را برآورده می کند |
| **حداقل جهانی** | x* امکان پذیر با f(x*) ≤ f(x) برای همه x | امکان پذیر است
| **حداقل محلی** | x* امکان پذیر با f(x*) ≤ f(x) برای همه x امکان پذیر در برخی محله ها |
| **مسئله محدب** | f محدب است، منطقه امکان پذیر مجموعه محدب است (min محلی = دقیقه جهانی) |
---

## برنامه نویسی خطی (LP)
وقتی هم هدف و هم همه محدودیت ها **خطی** هستند، مشکل یک برنامه خطی است.
### فرم استاندارد
cᵀx را به حداقل برسانید
موضوع: Ax ≤ b، x ≥ 0
که در آن c، x ∈ ℝⁿ، A ∈ ℝᵐˣⁿ، b ∈ ℝᵐ.
### خواص
| اموال | بیانیه |
|----------|-----------|
| تحدب | LP همیشه یک مشکل محدب است |
| راه حل بهینه | همیشه در یک راس (نقطه گوشه) پلی توپ امکان پذیر |
| وجود | اگر منطقه امکان پذیر محدود و غیر خالی باشد، راه حل بهینه وجود دارد |
| بهینه چندگانه | اگر دو راس بهینه باشند، هر نقطه در لبه بین آنها نیز بهینه است |
### روش سیمپلکس
روش **سیمپلکس** (Dantzig، 1947) در امتداد لبه های پلی توپ امکان پذیر از راس به رأس حرکت می کند و همیشه هدف را تا رسیدن به حد مطلوب بهبود می بخشد.
| اموال | ارزش |
|----------|-------|
| بدترین زمان | O(2ⁿ) (نمایی - در عمل نادر) |
| میانگین زمان موردی | چند جمله ای برای اکثر مسائل کاربردی |
| ایده کلیدی | حرکت به راس مجاور با مقدار هدف بهتر |
**الگوریتم (نمای کلی):**
1. از یک راه حل اساسی اولیه (راس پلی توپ) شروع کنید
2. یک متغیر ورودی (متغیری که هدف را بهبود می بخشد) انتخاب کنید.
3. یک متغیر ترک را انتخاب کنید (حفظ امکان سنجی)
4. Pivot: حرکت به راس جدید
5. تا زمانی که هیچ جهت بهبودی وجود نداشته باشد، تکرار کنید
### روش های نقطه داخلی
جایگزین برای سیمپلکس: از داخل منطقه امکان پذیر به بهینه نزدیک شوید.
| اموال | ارزش |
|----------|-------|
| بدترین زمان | چند جمله ای (O(n³·5) برای برخی از انواع) |
| عملکرد عملی | رقابت با سیمپلکس در مسائل بزرگ |
| ایده کلیدی | یک "مسیر مرکزی" را در داخل کشور دنبال کنید |
### مثال LP کار شده
**مشکل:** یک کارخانه صندلی (x1) و میز (x2) تولید می کند.
- سود: 30 دلار برای هر صندلی، 50 دلار برای هر میز
- چوب: 2x1 + 4x2 ≤ 100 (فوت تخته موجود است)
- کار: x1 + 3x2 ≤ 60 (ساعت موجود)
- حداکثر: 30x1 + 50x2
**راه حل (روش گرافیکی برای 2 متغیر):**
- رئوس ناحیه امکان پذیر: (0.0)، (30.0)، (40.10)، (0.20)
- هدف را در هر رأس ارزیابی کنید:
  - (0,0): سود = 0
  - (30،0): سود = 900
  - (40،10): سود = 1700 ← بهینه
  - (0،20): سود = 1000
- **بهینه:** x1 = 40 صندلی، x2 = 10 میز، سود = 1700 دلار

## بهینه سازی محدب
اگر تابع هدف محدب باشد و ناحیه امکان پذیر یک مجموعه محدب باشد، یک مشکل **محدب** است.
### مجموعه ها و توابع محدب
| مفهوم | تعریف |
|---------|------------|
| **مجموعه محدب** | برای هر x، y در مجموعه و t ∈ [0,1]: tx + (1−t)y نیز در مجموعه است |
| **تابع محدب** | f(tx + (1-t)y) ≤ tf(x) + (1-t)f(y) برای همه t∈ [0,1] |
| **به شدت محدب** | نابرابری برای t ∈ (0,1) و x ≠ y | سخت است
**ویژگی کلیدی:** برای بهینه سازی محدب، هر حداقل محلی یک حداقل جهانی است.
### توابع محدب رایج
| تابع | محدب؟ | کجا |
|----------|---------|-------|
| تبر + b (خطی) | بله (و مقعر) | همه جا |
| x² | بله | ℝ |
| eˣ | بله | ℝ |
| -log(x) | بله | x > 0 |
| \|x\|ᵖ (p ≥ 1) | بله | ℝⁿ |
| max(f1، f2) اگر f1، f2 محدب | بله | تقاطع دامنه ها |
### نزول گرادیان
اساسی ترین الگوریتم بهینه سازی در یادگیری ماشینی
**قانون به‌روزرسانی:** x_{k+1} = x_k − α∇f(x_k)
که در آن α > 0 ** نرخ یادگیری ** (اندازه مرحله) است.
| نوع | به روز رسانی قانون | مزیت |
|---------|-------------|-----------|
| **دسته GD** | x ← x − α∇f(x) | همگرایی پایدار |
| **Stochastic GD (SGD)** | x ← x − α∇fᵢ(x) (یک نمونه) | سریع در هر تکرار، فرار از حداقل های محلی |
| **مینی بچ SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | تعادل بین دسته ای و تصادفی |
| **تحرک** | v ← βv − α∇f(x); x ← x + v | از طریق مناطق مسطح شتاب می گیرد |
| **آدم** | نرخ یادگیری تطبیقی ​​در هر پارامتر | برای یادگیری عمیق به خوبی کار می کند |
| **RMSprop** | مقیاس میزان یادگیری با میانگین اجرای قدر گرادیان | خوب برای RNN |
### نرخ های همگرایی
| روش | محدب f | به شدت محدب f |
|--------|---------|-------------------|
| نزول گرادیان | O(1/k) | O((1−μ/L)ᵏ) (خطی) |
| SGD | O(1/√k) | O(1/k) |
| شتاب GD (نستروف) | O(1/k²) | O((1−√(μ/L))ᵏ) |
که در آن k = تعداد تکرار، μ = پارامتر تحدب قوی، L = ثابت Lipschitz.
### انتخاب میزان یادگیری
| استراتژی | توضیحات |
|----------|-------------|
| ثابت α | ساده اما ممکن است واگرا شوند (خیلی بزرگ) یا به آرامی همگرا شوند (خیلی کوچک) |
| جستجوی خط | α را پیدا کنید که f(x - α∇f(x)) را در جهت گرادیان | به حداقل برساند
| برنامه های پوسیدگی | α_t = α₀ / (1 + βt) یا α_t = α₀ · βᵗ |
| گرم کردن | شروع کوچک، افزایش، سپس پوسیدگی (در آموزش ترانسفورماتور رایج) |
| تطبیقی ​​(آدام) | نرخ یادگیری هر پارامتر بر اساس آمار گرادیان |

## بهینه سازی محدود
### ضریب لاگرانژ
برای مسئله: f(x) را با h(x) = 0 کمینه کنید.
**لاگرانژی:** L(x, λ) = f(x) + λh(x)
در بهینه: ∇ₓL = 0 و ∇_λL = 0 (که h(x) = 0 را می دهد).
**مثال کار شده:** f(x,y) = x² + y² را با x + y = 1 به حداقل برسانید.
- L = x² + y² + λ(x + y - 1)
- ∂L/∂x = 2x + λ = 0 → x = -λ/2
- ∂L/∂y = 2y + λ = 0 → y = -λ/2
- محدودیت: x + y = 1 → −λ = 1 → λ = −1
- راه حل: x = 1/2، y = 1/2، f = 1/2
### شرایط KKT
شرایط **کاروش-کوهن-تاکر (KKT)** ضرب کننده های لاگرانژ را به محدودیت های نابرابری تعمیم می دهد.
برای: به حداقل رساندن f(x) با gᵢ(x) ≤ 0، hⱼ(x) = 0.
**لاگرانژی:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**شرایط KKT** (برای بهینه بودن لازم است):
| وضعیت | معادله |
|-----------|----------|
| ثابت بودن | ∇ₓL = 0 |
| امکان سنجی اولیه | gᵢ(x) ≤ 0، hⱼ(x) = 0 |
| امکان سنجی دوگانه | λᵢ ≥ 0 |
| سستی مکمل | λᵢgᵢ(x) = 0 برای همه i |
** سستی مکمل ** به این معنی است: اگر محدودیت gᵢ فعال نباشد (gᵢ(x) < 0)، آنگاه λᵢ = 0 (محدودیت بر راه حل تأثیر نمی گذارد).
برای مسائل محدب که شرایط اسلاتر را برآورده می کند، شرایط KKT هم لازم و هم کافی است.

## دوگانگی
هر مسئله بهینه سازی (*اولیه**) دارای یک مشکل **دوگانه** است.
### دوگانگی ضعیف و قوی
| مفهوم | بیانیه |
|---------|-----------|
| **دوکاره** | g(λ، ν) = infₓ L(x، λ، ν) |
| **مشکل دوگانه** | g(λ، ν) را با λ ≥ 0 | به حداکثر برسانید
| **دوگانگی ضعیف** | بهینه دوگانه ≤ بهینه اولیه (همیشه برقرار است) |
| **دوگانگی قوی** | بهینه دوگانه = بهینه اولیه (برای مسائل محدب با شرایط اسلاتر قابل استفاده است) |
| **شکاف دوگانگی** | بهینه اولیه - بهینه دوگانه (صفر تحت دوگانگی قوی) |
### چرا دوگانگی مهم است
| برنامه | چگونه دوگانگی کمک می کند |
|-------------|-------------------|
| کران پایین | Dual گواهی می دهد که راه حل اولیه چقدر خوب است |
| SVMs | مشکل دوگانه SVM منجر به ترفند هسته می شود |
| تجزیه و تحلیل حساسیت | متغیرهای دوگانه میزان تغییرات بهینه را در صورت کاهش محدودیت ها اندازه می گیرند |
| تجزیه | مشکلات بزرگ را می توان از طریق دوگانه | به زیرمشکلات کوچکتر تقسیم کرد

## برنامه نویسی عدد صحیح
وقتی برخی یا همه متغیرها باید **صحیح** باشند، مشکل بسیار سخت تر می شود (به طور کلی NP-hard).
### انواع
| نوع | توضیحات |
|------|-------------|
| IP خالص | همه متغیرها باید اعداد صحیح باشند |
| IP مختلط (MIP) | برخی از متغیرها عدد صحیح، برخی پیوسته |
| آی پی باینری | متغیرهای محدود به {0، 1} |
### روش های حل
| روش | ایده |
|--------|------|
| **شاخه و صحافی** | تقسیم به مسائل فرعی، حل آرامش LP، هرس |
| **هواپیماهای برش** | محدودیت های خطی را برای سفت تر کردن آرامش LP اضافه کنید
| **شاخه و برش** | ترکیب شاخه و کران با صفحات برش |
| **اکتشافی** | حریص، جستجوی محلی، بازپخت شبیه سازی شده برای راه حل های تقریبی |

## روش های ابتکاری و فراابتکاری
هنگامی که بهینه سازی دقیق غیرقابل حل است، اکتشافی راه حل های خوب (نه لزوما بهینه) پیدا می کند.
| روش | ایده کلیدی | بهترین برای |
|--------|----------|----------|
| **نزول شیب دار** | تندترین سراشیبی را دنبال کنید | توابع صاف و قابل تمایز |
| **روش نیوتن** | استفاده از اطلاعات مرتبه دوم (انحنا) | مشکلات صاف و دارای شرایط خوب |
| **بازپخت شبیه سازی شده** | راه حل های بدتر را با احتمال کاهشی بپذیرید | بهینه سازی جهانی، ترکیبی |
| **الگوریتم های ژنتیک** | تکامل یک جمعیت با استفاده از انتخاب، متقاطع، جهش | چند هدفه، غیر قابل تمایز |
| **ازدحام ذرات** | عوامل، تحت تأثیر بهترین موقعیت های شناخته شده | پیوسته، غیر محدب |
| **بهینه سازی بیزی** | ساخت مدل جایگزین، استفاده از تابع اکتساب | توابع جعبه سیاه گران قیمت (تنظیم فراپارامتر) |
### روش نیوتن برای بهینه سازی
**قانون به‌روزرسانی:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
که در آن H ماتریس هسی (ماتریس مشتقات دوم) است.
| اموال | ارزش |
|----------|-------|
| نرخ همگرایی | درجه دوم (نزدیک به بهینه) |
| هزینه هر تکرار | O(n³) برای وارونگی هسی |
| نیاز دارد | دو برابر متمایز، مثبت قطعی هسین |
| شبه نیوتن (BFGS) | هسی تقریبی از شیب | O(n²) در هر تکرار |

مسلماً بهینه سازی مهمترین ابزار ریاضی در یادگیری ماشینی است. هر مدلی که آموزش می دهید - از رگرسیون خطی گرفته تا مدل های زبان بزرگ - شامل حل یک مسئله بهینه سازی است. درک اینکه چه زمانی یک مسئله محدب است (بهینه جهانی تضمین شده)، چه زمانی نزول گرادیان همگرا می شود، و نحوه رسیدگی به محدودیت ها، پایه و اساس نظری را برای طراحی، اشکال زدایی و بهبود الگوریتم های یادگیری به شما می دهد.
