# تئوری بازی
تئوری بازی ریاضیات تعامل استراتژیک است - موقعیت‌هایی که نتیجه شما نه تنها به انتخاب‌های خودتان، بلکه به انتخاب‌های دیگران بستگی دارد. از جنگ قیمت‌گذاری بین شرکت‌ها گرفته تا مسابقات تسلیحات هسته‌ای، از حراج‌های آنلاین تا زیست‌شناسی تکاملی، نظریه بازی ابزارهایی را برای تجزیه و تحلیل درگیری و همکاری فراهم می‌کند. از طریق یادگیری تقویتی چند عاملی، شبکه های متخاصم مولد (GAN) و طراحی مکانیزم برای پلتفرم های آنلاین، به طور فزاینده ای به یادگیری ماشین مربوط می شود.

## بازی های استراتژیک
### تعریف
یک **بازی استراتژیک (به شکل عادی)** شامل موارد زیر است:
- مجموعه ای از بازیکنان N = {1، 2، ...، n}
- مجموعه های استراتژی S₁، S2، ...، Sₙ برای هر بازیکن
- توابع پرداخت u1، u2، ...، uₙ نگاشت پروفایل های استراتژی به اعداد واقعی
### مثال: معضل زندانی
| | همکاری (C) | نقص (D) |
|---|--------------|------------|
| **همکاری (C)** | (-1، -1) | (-3، 0) |
| **عیب (D)** | (0، -3) | (-2، -2) |
| تجزیه و تحلیل | نتیجه |
|----------|--------|
| استراتژی غالب | نقص (D بر C برای هر دو بازیکن غالب است) |
| تعادل نش | (D، D) با بازده (-2، -2) |
| بهینه اجتماعی | (C، C) با بازده (-1، -1) |
| معضل | عقلانیت فردی منجر به غیرعقلانی جمعی می شود |
### بازی های کلاسیک بیشتر
**نبرد دو جنس:**
| | اپرا | فوتبال |
|---|-------|----------|
| اپرا | (2، 1) | (0، 0) |
| فوتبال | (0، 0) | (1، 2) |
دو تعادل نش: (اپرا، اپرا) و (فوتبال، فوتبال).
**مرغ (Hawk-Dove):**
| | شاهین | کبوتر |
|---|------|------|
| شاهین | (-10، 10-) | (5، 0) |
| کبوتر | (0، 5) | (1، 1) |
دو تعادل نش: (شاهین، کبوتر) و (کبوتر، شاهین).

## استراتژی های غالب
| مفهوم | تعریف |
|---------|------------|
| **به شدت مسلط** | استراتژی sᵢ بازدهی بالاتری نسبت به هر استراتژی دیگری دارد، صرف نظر از انتخاب های مخالفان |
| **ضعيف غالب** | استراتژی sᵢ حداقل به همان اندازه بازدهی بالایی دارد و برای برخی از پروفایل های حریف بسیار بیشتر است |
| **استراتژی تحت سلطه** | استراتژی که هرگز بهترین پاسخ نیست |
**حذف مکرر استراتژی های تحت سلطه:**
1. هرگونه استراتژی تحت سلطه را حذف کنید
2. این کار را تا زمانی تکرار کنید که دیگر حذف نشود
3. اگر یک نمایه استراتژی باقی بماند، آن تعادل منحصر به فرد نش است

## تعادل نش
**تعادل نش** یک نمایه استراتژی است که در آن هیچ بازیکنی نمی تواند با تغییر یک طرفه استراتژی خود سود خود را بهبود بخشد.
### تعریف
(s1*، s2*، ...، sₙ*) یک تعادل نش است اگر برای هر بازیکن i:
uᵢ(sᵢ, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*) برای همه sᵢ ∈ Sᵢ
### یافتن تعادل نش (بازی 2×2)
**بهترین روش پاسخگویی:**
1. برای هر ستون، زیر بهترین پاسخ بازیکن 1 خط بکشید
2. برای هر ردیف، زیر بهترین پاسخ بازیکن 2 خط بکشید
3. سلول هایی که زیر هر دو خط کشیده شده اند، تعادل نش هستند
### وجود (قضیه نش)
هر بازی محدود حداقل یک تعادل نش دارد (احتمالاً در استراتژی های ترکیبی).
### استراتژی های ترکیبی
**استراتژی مختلط** توزیع احتمال بر روی استراتژی های خالص است.
| مفهوم | تعریف |
|---------|------------|
| استراتژی ترکیبی σᵢ | توزیع احتمال بر روی Sᵢ |
| استراتژی مختلط NE | هیچ بازیکنی نمی تواند با تغییر ترکیب خود سود مورد انتظار را بهبود بخشد |
| پشتیبانی | مجموعه ای از استراتژی های ناب با احتمال مثبت بازی شده |
**مثال کار شده: تطبیق پنی**
| | سرها | دم |
|---|-------|-------|
| سرها | (1، -1) | (-1، 1) |
| دم | (-1، 1) | (1، -1) |
بدون استراتژی خالص NE. NE مختلط: هر دو H و T را با احتمال ½ هر کدام بازی می کنند.

## قضیه Minimax
### بازی های حاصل جمع صفر
در یک **بازی حاصل جمع صفر**، سود یک بازیکن دقیقاً ضرر دیگری است: u1 + u2 = 0.
### قضیه مینیمکس فون نیومن
برای هر بازی محدود دو نفره با جمع صفر:
max_{σ1} min_{σ2} u1(σ1، σ2) = min_{σ2} max_{σ1} u1(σ1، σ2)
**maximin** (بهترین بدترین حالت برای بازیکن 1) برابر **مینیمکس** (بهترین بدترین حالت برای بازیکن 2) است. این مقدار مشترک، **ارزش بازی** است.
### حل بازی های حاصل جمع صفر
برای یک بازی 2×2 حاصل جمع صفر با ماتریس:
| | L | R |
|---|---|---|
| T | یک | b |
| ب | ج | d |
استراتژی ترکیبی بهینه بازیکن 1: بازی T با احتمال p = (d-c)/((a-b)+(d-c))
مقدار بازی: v = (ad−bc)/((a−b)+(d−c))

## بازی های گسترده
بازی هایی با حرکات متوالی به صورت **درخت بازی** نمایش داده می شوند.
### مفاهیم کلیدی
| مفهوم | تعریف |
|---------|------------|
| **درخت بازی** | درختی که تمام توالی های ممکن حرکت را نشان می دهد |
| **مجموعه اطلاعات** | مجموعه ای از گره ها که بازیکن نمی تواند |
| **اطلاعات کامل** | هر مجموعه اطلاعاتی یک تنه است (همه حرکات قابل مشاهده است) |
| **Subgame perfect NE** | تعادل نش در هر بازی فرعی |
| **القاء معکوس** | حل از انتهای درخت به عقب |
### قضیه زرملو
در بازی‌های دو نفره بدون هیچ شانسی با اطلاعات محدود و کامل: یا یک بازیکن استراتژی برنده دارد یا هر دو می‌توانند به تساوی کشانده شوند (مثلاً شطرنج).

## بازی های تعاونی
در **بازی های تعاونی**، بازیکنان می توانند توافق نامه ها و ائتلاف های الزام آور تشکیل دهند.
### عملکرد مشخصه
یک بازی مشارکتی با یک **تابع مشخصه** v: 2^N → ℝ تعریف می شود، جایی که v(S) مقداری است که ائتلاف S می تواند به دست آورد.
| اموال | تعریف |
|----------|------------|
| **سوپرافزونه** | v(S ∪ T) ≥ v(S) + v(T) برای S، T جدا |
| **محدب** | v(S ∪ {i}) − v(S) ≤ v(T ∪ {i}) − v(T) برای S ⊂ T |
### هسته
**هسته** مجموعه ای از تخصیص هایی است که هیچ ائتلافی نمی تواند با جدا شدن از آنها بهبود یابد:
هسته = {x ∈ ℝⁿ : Σᵢ∈N xᵢ = v(N)، Σᵢ∈S xᵢ ≥ v(S) برای همه S ⊂ N}
ممکن است هسته خالی باشد - در این صورت هیچ تخصیص پایدار وجود ندارد.
### ارزش Shapley
**ارزش Shapley** تخصیص منصفانه منحصر به فردی را بر اساس مشارکت های حاشیه ای ارائه می دهد:
φᵢ = Σ_{S ⊂ N\{i}} (|S|!(n−|S|−1)!/n!) · [v(S ∪ {i}) − v(S)]
| اموال | بیانیه |
|----------|-----------|
| کارایی | Σ φᵢ = v(N) (همه مقدار توزیع شده است) |
| تقارن | مشارکت کنندگان برابر بازدهی برابر دریافت می کنند |
| پخش کننده ساختگی | غیر مشارکت کنندگان صفر دریافت می کنند |
| افزودنی | φ(v + w) = φ(v) + φ(w) |
**تفسیر:** ارزش شپلی هر بازیکن، میانگین سهم حاشیه ای آنها در تمام ترتیبات احتمالی تشکیل ائتلاف است.
### مثال کارآمد
سه بازیکن: v(∅) = 0، v({1}) = 0، v({2}) = 0، v({3}) = 0، v({1،2}) = 50، v({1،3}) = 70، v({2،3}) = 60، v({1،2،3}) = 10.
| پخش کننده | مشارکت های حاشیه ای (میانگین بیش از سفارشات) | ارزش شیپلی |
|-------|----------------------------------------------|
| 1 | (100+50+70+70+50+0)/6 = 56.7 | 37.5 |
| 2 | (100+50+60+60+50+0)/6 | 27.5 |
| 3 | (100+70+60+70+60+0)/6 | 35.0 |
(دقیقا با استفاده از فرمول Shapley برای هر جایگشت محاسبه می شود.)

## طراحی مکانیزم
**طراحی مکانیزم** "نظریه بازی معکوس" است - به جای تجزیه و تحلیل بازی های داده شده، بازی هایی را طراحی کنید که نتایج دلخواه را ایجاد کنند.
### اصل وحی
هر مکانیسمی که به یک نتیجه دلخواه می رسد را می توان با یک **مکانیسم مکاشفه مستقیم** جایگزین کرد که در آن حقیقت گفتن یک تعادل نش است.
### تئوری حراج
| نوع حراج | قوانین | معادل درآمد |
|-------------|-------|---------------------|
| **قیمت اول مهر و موم شده** | بالاترین پیشنهاد برنده می شود، پیشنهاد خود را پرداخت می کند | همه حراج های استاندارد درآمد مورد انتظار یکسانی را به همراه دارند |
| **قیمت دوم مناقصه مهر و موم شده (ویکری)** | بالاترین پیشنهاد برنده می شود، دومین پیشنهاد بالاتر را می پردازد | (تحت ارزش های خصوصی مستقل) |
| **انگلیسی (صعودی)** | افزایش قیمت؛ اولین بار که برد را پذیرفت | — |
| **هلندی (نزولی)** | کاهش قیمت؛ اولین بار که برد را پذیرفت | — |
### حراج ویکری (قیمت دوم)
** استراتژی غالب: ** ارزش واقعی خود را پیشنهاد دهید.
| اموال | بیانیه |
|----------|-----------|
| مناقصه صادقانه | استراتژی غالب ضعیف |
| کارایی | کالا به بالاترین ارزش پیشنهاد دهنده می رود |
| درآمد | درآمد مورد انتظار مشابه با قیمت اول (قضیه هم ارزی درآمد) |
### طراحی حراج بهینه (Myerson)
حراج به حداکثر رساندن درآمد:
- به مناقصه گر با بالاترین **ارزش گذاری مجازی** تخصیص می دهد.
- قیمت رزرو را تعیین می کند
- ارزش گذاری مجازی: ψ(v) = v − (1−F(v))/f(v)

## ارتباط با یادگیری ماشین
### شبکه های متخاصم مولد (GAN)
GAN ها یک بازی دو نفره بین ژنراتور G و تشخیص دهنده D هستند:
min_G max_D V(D, G) = E[log D(x)] + E[log(1 − D(G(z)))]
| مفهوم نظریه بازی | معادل GAN |
|-------------------|-----------------|
| بازی دو نفره حاصل جمع صفر | مولد در مقابل ممیز |
| تعادل نش | G داده واقعی تولید می کند، D خروجی ½ در همه جا |
| Minimax | تابع هدف GAN |
| سقوط حالت | عدم رسیدن به تعادل |
### آموزش تقویتی چند عاملی (MARL)
| مفهوم | برنامه MARL |
|---------|-----------------|
| تعادل نش | سیاست های پایدار در تنظیمات چند عاملی |
| Minimax | سیاست های قوی در برابر مخالفان متخاصم |
| بازی های تعاونی | تشکیل ائتلاف، تخصیص وظایف |
| ارزش شیپلی | واگذاری اعتبار (کدام عامل چه کمکی کرده است؟) |
| طراحی مکانیزم | طراحی مشوق ها در سیستم های چند عاملی |
| نمایشنامه ساختگی | الگوریتم یادگیری همگرا به تعادل نش |
### سایر اتصالات ML
| برنامه | ابزار تئوری بازی |
|-------------|-----------------|
| طراحی حراج آگهی (گوگل، فیسبوک) | طراحی مکانیزم، تئوری حراج |
| طراحی بازار (Uber، Airbnb) | تئوری تطبیق، طراحی مکانیزم |
| استحکام خصمانه | بازی های مجموع صفر بین مهاجم و مدافع |
| تقسیم عادلانه | ارزش Shapley، تخصیص بدون حسادت |
| یادگیری فدرال | نظریه بازی مشارکتی برای اندازه گیری مشارکت |
| سیستم های توصیه | طراحی مکانیزم برای استخراج ترجیح واقعی |

## خلاصه
| مفهوم | ایده اصلی | نتیجه کلیدی |
|---------|-----------|------------|
| بازی های استراتژیک | بازیکنان، استراتژی ها، بازده | نمایش ماتریس بازی |
| استراتژی های غالب | بهترین بدون توجه به دیگران | حذف تکراری |
| تعادل نش | بدون انحراف یک طرفه سودآور | در هر بازی متناهی وجود دارد |
| استراتژی های ترکیبی | تصادفی بیش از اقدامات | قضیه وجود نش |
| Minimax | بهترین بدترین حالت (مجموع صفر) | قضیه مینیمکس فون نیومن |
| فرم گسترده | حرکات متوالی | استقرا به عقب، کمال زیر بازی |
| بازی های تعاونی | ائتلاف های الزام آور | هسته، ارزش شپلی |
| طراحی مکانیزم | طراحی بازی برای نتایج | اصل وحی، حراج بهینه |
| تئوری حراج | فروش از طریق رقابت | معادل درآمد، حراج ویکری |
نظریه بازی ریاضیات تفکر استراتژیک است. در دنیایی که به طور فزاینده‌ای با تعامل عوامل هوش مصنوعی، بازارهای خودکار و سیستم‌های متخاصم پرجمعیت می‌شود، نظریه بازی ابزار ضروری را برای پیش‌بینی رفتار، طراحی مکانیسم‌ها و ساختن سیستم‌های چند عاملی قوی فراهم می‌کند. برای دانشمندان داده، توضیح می‌دهد که GAN چگونه کار می‌کند، چگونه مزایده‌های آنلاین میلیاردها درآمد ایجاد می‌کنند و چگونه سیستم‌های هوش مصنوعی بسازند که در محیط‌های رقابتی عملکرد خوبی داشته باشند.
