#سیستم های دینامیک
یک **سیستم دینامیکی** توضیح می دهد که چگونه یک حالت در طول زمان طبق یک قانون ثابت تکامل می یابد. از مدارهای سیاره‌ای تا پویایی جمعیت، از الگوهای آب و هوا تا آموزش شبکه‌های عصبی، نظریه سیستم‌های دینامیکی زبان و ابزارهایی را برای درک چگونگی تغییر چیزها فراهم می‌کند. این فایل معادلات دیفرانسیل معمولی (ODE)، معادلات دیفرانسیل جزئی (PDEs)، تجزیه و تحلیل پایداری، آشفتگی و دوشاخه ها را پوشش می دهد.
---

## معادلات دیفرانسیل معمولی (ODE)
یک ODE یک تابع را با توجه به یک متغیر مستقل (معمولا زمان) به مشتقاتش مرتبط می کند.
### طبقه بندی
| اموال | انواع |
|----------|-------|
| **سفارش** | بالاترین مشتق موجود ( مرتبه اول، مرتبه دوم و غیره) |
| **خطی در مقابل غیرخطی** | خطی: y'' + p(t)y' + q(t)y = g(t); غیر خطی: هر چیز دیگری |
| **همگن** | g(t) = 0 (بدون عبارت اجباری) |
| **خودکار** | بدون وابستگی زمانی صریح: dy/dt = f(y) |
| **ضرایب ثابت** | p، q ثابت هستند |
### ODE های مرتبه اول
**شکل کلی:** dy/dt = f(t, y)
| نوع | فرم | روش حل |
|------|------|-----------------|
| قابل تفکیک | dy/dt = g(t)h(y) | جداسازی و ادغام: ∫dy/h(y) = ∫g(t)dt |
| خطی مرتبه اول | dy/dt + p(t)y = q(t) | ضریب یکپارچه: μ(t) = e^(∫p dt) |
| دقیق | M(t,y)dt + N(t,y)dy = 0 با ∂M/∂y = ∂N/∂t | تابع پتانسیل F(t,y) |
| برنولی | dy/dt + p(t)y = q(t)yⁿ | v = y^(1−n) را برای خطی کردن |
**مثال کار شده (عامل یکپارچه):** حل dy/dt + 2y = e^(−t)، y(0) = 1.
- عامل ادغام: μ(t) = e^(∫2 dt) = e^(2t)
- ضرب: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- ادغام: e^(2t)y = e^t + C
- y(t) = e^(-t) + Ce^(-2t)
- شرایط اولیه: y(0) = 1 → 1 = 1 + C → C = 0
- راه حل: y(t) = e^(−t)
### ODE های خطی مرتبه دوم
**شکل کلی:** ay'' + by' + cy = g(t)
** حالت همگن ** (g ​​= 0): معادله مشخصه ar² + br + c = 0 را حل کنید.
| ممیز | ریشه ها | راه حل عمومی |
|-------------|-------|------------------|
| b² > 4ac (بیش از حد میرا) | دو r1، r2 | واقعی متمایز y = C1e^(r1t) + C2e^(r2t) |
| b² = 4ac (به طور بحرانی میرا شده) | تکرار ریشه واقعی r | y = (C1 + C2t)e^(rt) |
| b² < 4ac (کم میرا) | ریشه های پیچیده α ± βi | y = e^(αt)(C1 cos βt + C2 sin βt) |
**تفسیر فیزیکی:** یک سیستم جرم- فنر-دمپر mx'' + bx' + kx = 0.
- میرایی بیش از حد: میرایی شدید، بدون نوسان (بستن درب)
- میرایی بحرانی: سریعترین بازگشت بدون نوسان (هدف طراحی سیستم تعلیق خودرو)
- کم میرا: با دامنه پوسیده نوسان می کند (سیم گیتار)
### سیستم های ODE
بسیاری از سیستم های واقعی شامل چندین متغیر متقابل هستند:
dx/dt = f(x, y)
dy/dt = g(x, y)
این را می توان به صورت برداری نوشت: d**x**/dt = **F**(**x**)
**سیستم های خطی:** d**x**/dt = A**x**، که در آن A یک ماتریس است.
راه حل به مقادیر ویژه A بستگی دارد:
| مقادیر ویژه | رفتار |
|-------------|-----------|
| هم واقعی، هم منفی | گره پایدار (همه مسیرها به مبدأ همگرا می شوند) |
| هر دو واقعی، مثبت | گره ناپایدار |
| واقعی، نشانه های متضاد | نقطه زین (ناپایدار) |
| پیچیده، قسمت واقعی منفی | مارپیچ پایدار (نوسان میرا) |
| پیچیده، بخش واقعی مثبت | مارپیچ ناپایدار |
| خیالی ناب | مرکز (مدارهای بسته) |

## پرتره فاز
**پرتره فاز** مسیرهای یک سیستم دینامیکی را در فضای حالت (بدون حل صریح) به تصویر می کشد.
### ویژگی های کلیدی
| ویژگی | توضیحات |
|---------|-------------|
| **نقطه ثابت (تعادل)** | جایی که dx/dt = 0 (بدون حرکت) |
| **مسیر** | مسیر ردیابی شده توسط سیستم در فضای حالت |
| **نالکلاین** | منحنی که در آن مشتق یک جزء صفر است |
| **چرخه حد ** | مدار بسته ایزوله (نوسان خودپایدار) |
| **حوضه جاذبه** | مجموعه شرایط اولیه منجر به جذب کننده معین |
| **Separatrix** | مرز بین حوضه های مختلف جاذبه |
### مدل شکارچی (Lotka-Volterra)
dx/dt = αx − βxy (شکار)
dy/dt = δxy - γy (درنده)
**نکات ثابت:**
1. (0، 0) - انقراض (نقطه زین)
2. (γ/δ، α/β) - همزیستی (مرکز - مدارهای بسته)
این سیستم نوسانات دوره ای را نشان می دهد: طعمه افزایش می یابد → شکارچیان افزایش می یابد → طعمه کاهش می یابد → شکارچیان کاهش می یابد → چرخه تکرار می شود.

## تجزیه و تحلیل پایداری
### پایداری خطی
برای یک نقطه ثابت x*، اطراف آن را خطی کنید: اجازه دهید u = x − x*، سپس du/dt ≈ J(x*)u که در آن J ماتریس ژاکوبین است.
**معیار پایداری:** نقطه ثابت:
- **پایدار** اگر همه مقادیر ویژه J دارای قطعات واقعی منفی باشند
- **ناپایدار** اگر مقدار ویژه دارای بخش واقعی مثبت باشد
- اگر مقادیر ویژه دارای قطعات واقعی صفر باشند، **تا حدی پایدار** هستند (نیاز به تحلیل غیرخطی دارند)
### ثبات لیاپانوف
**روش مستقیم لیاپانوف** ثبات را بدون خطی سازی تعیین می کند.
تابع **لیاپانوف** V(x) برآورده می‌کند:
1. V(x*) = 0 و V(x) > 0 برای x ≠ x* (مثبت قطعی)
2. dV/dt ≤ 0 در طول مسیرها (غیر افزایشی)
| وضعیت | نتیجه گیری |
|-----------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | ناپایدار |
**مثال کار شده:** سیستم dx/dt = −x + y²، dy/dt = −y.
- V(x,y) = x² + y² (تابع انرژی مانند) را امتحان کنید
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- مبدا نزدیک: dV/dt ≈ -2x² - 2y² < 0 (برای y کوچک، -2y² غالب است)
- نتیجه گیری: منشا به صورت محلی از نظر مجانبی پایدار است

## نظریه آشوب
**آشوب** قطعی و در عین حال غیرقابل پیش بینی است: سیستم از قوانین دقیق پیروی می کند، اما تفاوت های کوچک در شرایط اولیه منجر به نتایج بسیار متفاوتی می شود.
### الزامات برای آشوب
| اموال | توضیحات |
|----------|-------------|
| قطعی | بدون تصادفی - توسط معادلات دقیق اداره می شود |
| حساس به شرایط اولیه | مسیرهای نزدیک به طور نمایی از هم جدا می شوند |
| محدود | مسیرها به بی نهایت نمی گریزند |
| غیر دوره ای | هرگز دقیقا تکرار نمی شود |
### سیستم لورنز
مثال کلاسیک هرج و مرج جبرگرا:
dx/dt = σ(y − x)
dy/dt = x(ρ - z) - y
dz/dt = xy - βz
با پارامترهای استاندارد σ = 10، ρ = 28، β = 8/3:
- سیستم دارای سه نقطه ثابت است که همگی ناپایدار هستند
- مسیرها به دور یک نقطه ثابت می چرخند، سپس به طور ناگهانی به نقطه دیگر تغییر می کنند
- نتیجه **جاذب لورنز** است - یک جاذبه عجیب با ساختار فراکتال
** شار لیاپانوف:** میزان واگرایی مسیرهای مجاور را اندازه می گیرد.
- توان مثبت لیاپانوف → آشوب
- برای سیستم لورنز با پارامترهای استاندارد: بزرگترین توان ≈ 0.9 > 0
### نقشه لجستیک
یک سیستم گسسته ساده که هرج و مرج را نشان می دهد:
x_{n+1} = rx_n(1 - x_n)
| پارامتر r | رفتار |
|-------------|-----------|
| 0 < r < 1 | جمعیت از بین می رود (x → 0) |
| 1 < r < 3 | نقطه ثابت پایدار در x = 1 − 1/r |
| 3 < r < 3.449 | نوسان دوره-2 |
| 3.449 < r < 3.544 | نوسان دوره-4 |
| 3.544 < r < 3.570 | دوره-8، 16، 32، ... (آبشار دوره-دوبرابر) |
| r ≈ 3.570 | شروع هرج و مرج |
| 3.570 < r < 4 | بیشتر آشفته، با پنجره های دوره ای |
| r = 4 | کاملاً آشفته در [0، 1] |
### اثر پروانه
نام رایج برای وابستگی حساس به شرایط اولیه. در سیستم‌های آب‌وهوا (مدل‌سازی‌شده با معادلات لورنز)، پروانه‌ای که بال‌های خود را در برزیل تکان می‌دهد، می‌تواند گردباد را در تگزاس ایجاد کند - نه به این دلیل که پروانه باعث ایجاد آن می‌شود، بلکه به این دلیل که آشفتگی‌های کوچک به طور تصاعدی رشد می‌کنند.

## نظریه انشعاب
**دوشاخه** یک تغییر کیفی در رفتار سیستم به دلیل متغیر بودن یک پارامتر است.
### انواع انشعاب
| انشعاب | فرم عادی | چه اتفاقی می افتد |
|-------------|-------------|--------------|
| **زین-گره** | dx/dt = r − x² | دو نقطه ثابت ظاهر/ناپدید می شوند |
| **روان انتقادی** | dx/dt = rx − x² | دو نقطه ثابت مبادله ثبات |
| **چنگال (فوق بحرانی)** | dx/dt = rx − x³ | یک نقطه پایدار به دو نقطه پایدار + یک ناپایدار | تقسیم می شود
| **چنگال (زیر بحرانی)** | dx/dt = rx + x³ | شاخه های ناپایدار فرو می ریزند (اغلب فاجعه بار) |
| **Hopf** | سیستم دو بعدی | نقطه ثابت ناپایدار می شود، چرخه حد ظاهر می شود |
### نمودار انشعاب
نموداری از نقاط ثابت در مقابل مقدار پارامتر، که پایداری را نشان می‌دهد (جامد = پایدار، نقطه چین = ناپایدار). نمودار انشعاب نقشه لجستیک مسیر دوبرابر شدن دوره به سمت آشوب و ثابت معروف **Feigenbaum** δ ≈ 4.669 (نسبت جهانی بین فواصل انشعاب متوالی) را نشان می دهد.

## معادلات دیفرانسیل جزئی (PDEs)
PDE ها شامل توابع چندین متغیر و مشتقات جزئی آنها هستند.
### طبقه بندی PDE های خطی مرتبه دوم
برای Au_xx + 2Bu_xy + Cu_yy + ... = 0:
| نوع | وضعیت | رفتار | مثال |
|------|-----------|-----------|---------|
| **بیضوی** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | انتشار موج، حفظ ویژگی های تیز | معادله موج: u_tt = c²u_xx |
### معادله گرما
∂u/∂t = α ∂²u/∂x²
مدل‌های انتشار گرما، توزیع جمعیت، قیمت‌گذاری گزینه (Black-Scholes).
| اموال | بیانیه |
|----------|-----------|
| صاف کردن | راه حل ها بلافاصله صاف می شوند، حتی از داده های اولیه ناپیوسته |
| اصل حداکثر | حداکثر دما در زمان مرزی یا اولیه |
| برگشت پذیری زمان | برگشت ناپذیر — نمی تواند به عقب اجرا شود |
### معادله موج
∂²u/∂t² = c² ∂²u/∂x²
رشته های ارتعاشی، صدا، امواج الکترومغناطیسی را مدل می کند.
| اموال | بیانیه |
|----------|-----------|
| تکثیر | اختلالات با سرعت c |
| برگشت پذیری | زمان برگشت پذیر |
| راه حل d'Alembert | u(x,t) = f(x−ct) + g(x+ct) (ابرجای امواج چپ/راست) |
### معادله لاپلاس
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
محلول ها (توابع هارمونیک) دمای حالت پایدار، پتانسیل الکترواستاتیک، جریان سیال تراکم ناپذیر را نشان می دهند.
| اموال | بیانیه |
|----------|-----------|
| ویژگی مقدار میانگین | u(x0) = میانگین u در هر دایره ای که در مرکز x₀ |
| اصل حداکثر | بدون ماکزیمم یا مینیمم داخلی |
| منحصر به فرد بودن | کاملاً با شرایط مرزی تعیین می شود |

## ارتباط با یادگیری ماشین و علم داده
| DS Concept | برنامه |
|-----------|-------------|
| ODEs | ODE های عصبی (شبکه های عمق پیوسته)، پویایی شبکه های تکراری |
| تجزیه و تحلیل پایداری | دینامیک تمرین نزول گرادیان (آیا تلفات به طور پایدار در حال کاهش است؟) |
| توابع لیاپانوف | اثبات همگرایی الگوریتم های یادگیری، پایداری یادگیری تقویتی |
| هرج و مرج | درک حساسیت در RNN ها (شیب های در حال ناپدید شدن/انفجار)، پیش بینی آب و هوا |
| انشعاب | انتقال فاز در یادگیری (گروکینگ)، تغییرات رژیم در پویایی آموزش |
| PDE ها | مدل‌های انتشار (مدل‌های مولد مبتنی بر امتیاز)، شبکه‌های عصبی مبتنی بر فیزیک |
| معادله حرارت | فرآیندهای انتشار در مدل سازی مولد، گراف هموارسازی لاپلاسی |
| معادله موج | پردازش داده های لرزه ای، مدل سازی سیگنال های صوتی |
| Lotka-Volterra | پویایی جمعیت، اپیدمیولوژی، عوامل رقیب ML |
| پرتره فاز | تجسم دینامیک منظره از دست دادن، درک آموزش GAN |

## خلاصه
| موضوع | ایده اصلی | ابزار کلید |
|-------|-----------|----------|
| ODEs | توابع و مشتقات زمانی آنها | معادلات مشخصه، عوامل یکپارچه |
| سیستم های ODE | متغیرهای متقابل چندگانه | تحلیل ارزش ویژه ژاکوبین |
| پرتره فاز | تجسم دینامیک در فضای حالت | نقاط ثابت، تهی، چرخه های حدی |
| ثبات | آیا سیستم به تعادل باز می گردد؟ | خطی سازی، توابع لیاپانوف |
| هرج و مرج | غیرقابل پیش بینی قطعی | شارحان لیاپانوف، جاذبه های عجیب و غریب |
| انشعاب ها | تغییرات کیفی با پارامترها | اشکال عادی، نمودارهای انشعاب |
| PDE ها | توابع متغیرهای متعدد | معادلات گرما، موج و لاپلاس |
نظریه سیستم های پویا ریاضیات تغییر است. این توضیح می دهد که چرا برخی از سیستم ها مستقر می شوند، چرا برخی نوسان می کنند، و چرا برخی رفتار هرج و مرج دارند. برای دانشمندان داده، ابزارهایی برای درک دینامیک آموزش، طراحی الگوریتم‌های پایدار، مدل‌سازی سری‌های زمانی و ساختن نسل بعدی مدل‌های یادگیری ماشینی مبتنی بر فیزیک فراهم می‌کند.
