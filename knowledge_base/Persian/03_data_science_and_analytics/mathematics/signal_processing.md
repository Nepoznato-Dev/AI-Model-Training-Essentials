# پردازش سیگنال
پردازش سیگنال علم تجزیه و تحلیل، اصلاح و سنتز سیگنال ها است - نمایش مقادیر فیزیکی که در طول زمان، مکان یا فرکانس متفاوت است. صدا، تصاویر، ویدئو، داده های حسگر، امواج مغزی، قیمت سهام - همه سیگنال هستند. ابزارهای ریاضی پردازش سیگنال (تبدیل فوریه، فیلترها، تئوری نمونه‌برداری) برای یادگیری ماشین، ارتباطات، تصویربرداری پزشکی و تقریباً هر زمینه‌ای که با داده‌ها کار می‌کند، اساسی هستند.

## سیگنال ها و سیستم ها
### طبقه بندی سیگنال
| نوع | توضیحات | مثال |
|------|-------------|---------|
| **زمان پیوسته** | برای همه t ∈ ℝ تعریف شده است ولتاژ صدا، دما |
| **زمان گسسته** | تعریف شده در شاخص های عدد صحیح n | صدای نمونه، مقادیر پیکسل |
| **آنالوگ** | پیوسته در زمان و دامنه | شیار ضبط وینیل |
| **دیجیتال** | گسسته در زمان و دامنه کمی | فایل MP3، تصویر JPEG |
| **دوره ای** | x(t + T) = x(t) برای همه t | موج سینوسی، موج مربعی |
| **پریودیک** | بدون الگوی تکراری | سخنرانی، موسیقی |
| **قطعی** | کاملا قابل پیش بینی | موج سینوسی |
| **استوکاستیک** | شامل تصادفی | سر و صدا، قیمت سهام |
### ویژگی های سیستم
| اموال | تعریف | مثال |
|----------|-----------|---------|
| **خطی** | T[ax1 + bx2] = aT[x1] + bT[x2] | فیلتر پایین گذر |
| **تغییر زمان** | تغییر در ورودی → همان تغییر در خروجی | هر فیلتر ثابت |
| **علت** | خروجی فقط به ورودی های حال و گذشته بستگی دارد | سیستم بلادرنگ |
| **پایدار (BIBO)** | ورودی محدود → خروجی محدود | فیلتر خوش طراحی |
| **بی خاطره** | خروجی فقط به ورودی فعلی بستگی دارد | آمپلی فایر |

## تبدیل فوریه
**تبدیل فوریه** یک سیگنال را به فرکانس های تشکیل دهنده آن تجزیه می کند.
### تبدیل فوریه پیوسته
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
معکوس: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### جفت تبدیل فوریه
| دامنه زمانی x(t) | دامنه فرکانس X(f) |
|------------------------------------------|
| پالس مستطیلی | تابع سینک |
| تابع سینک | پالس مستطیلی |
| گاوسی e^{−at²} | گاوسی (√(π/a))e^{−π²f²/a} |
| دلتای دیراک δ(t) | 1 (همه فرکانس ها) |
| نمایی مختلط e^{j2πf₀t} | δ(f − f0) |
| کسینوس cos(2πf₀t) | ½[δ(f−f0) + δ(f+f0)] |
### ویژگی های کلیدی
| اموال | دامنه زمان | دامنه فرکانس |
|----------|------------|----------------|
| خطی بودن | ax1(t) + bx2(t) | aX1(f) + bX2(f) |
| تغییر زمان | x(t - t₀) | X(f)e^{−j2πft₀} |
| تغییر فرکانس | x(t)e^{j2πf₀t} | X(f − f0) |
| پیچیدگی | x1 (t) ∗ x2 (t) | X1(f) · X2(f) |
| ضرب | x1(t) · x2(t) | X1(f) ∗ X2(f) |
| تمایز | dx/dt | j2πf X(f) |
| قضیه پارسوال | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**قضیه پیچیدگی:** پیچیدگی در زمان = ضرب در فرکانس. این مهمترین ویژگی است - عملیات پیچشی گران قیمت را به ضرب ارزان تبدیل می کند.
### تبدیل فوریه گسسته (DFT)
برای یک دنباله x[0]، x[1]، ...، x[N−1]:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}، k = 0، 1، ...، N−1
| اموال | ارزش |
|----------|-------|
| ورودی | N نمونه واقعی یا مختلط |
| خروجی | N سطل فرکانس پیچیده |
| وضوح فرکانس | f_s/N (که در آن f_s نرخ نمونه برداری است) |
| فرکانس Nyquist | f_s/2 (حداکثر فرکانس قابل نمایش) |
| پیچیدگی | O(N²) محاسبات مستقیم |
### تبدیل فوریه سریع (FFT)
**FFT** DFT را در O(N log N) به جای O(N²) محاسبه می کند.
| N | O(N²) عملیات | O(N log N) عملیات | افزایش سرعت |
|---|-----------------|--------------------|---------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10¹² | 20,971,520 | 52,428× |
FFT یکی از مهم ترین الگوریتم هایی است که تاکنون اختراع شده است. پردازش صدای بلادرنگ، فشرده سازی تصویر (JPEG)، ارتباطات بی سیم (OFDM) و تجزیه و تحلیل طیفی را امکان پذیر می کند.

## تبدیل لاپلاس
**تبدیل لاپلاس** تبدیل فوریه را برای مدیریت سیستم های ناپایدار و تحلیل گذرا گسترش می دهد.
F(s) = ∫₀^∞ f(t) e^{−st} dt، که در آن s = σ + jω
### تبدیل لاپلاس رایج
| f(t) | F(s) | منطقه همگرایی |
|------|------|----------------------|
| δ(t) (تکانه) | 1 | همه s |
| u(t) (مرحله) | 1/s | Re(s) > 0 |
| e^{−at}u(t) | 1/(s+a) | Re(s) > -a |
| tⁿu(t) | n!/s^{n+1} | Re(s) > 0 |
| sin(ωt)u(t) | ω/(s²+ω²) | Re(s) > 0 |
| cos(ωt)u(t) | s/(s²+ω²) | Re(s) > 0 |
### اتصال به تبدیل فوریه
هنگامی که σ = 0 (s = jω)، تبدیل لاپلاس به تبدیل فوریه کاهش می یابد. تبدیل لاپلاس با گنجاندن اطلاعات در مورد رشد / پوسیدگی (σ) تصویر کامل تری را ارائه می دهد.

## Z-Transform
**تبدیل Z** معادل زمان گسسته تبدیل لاپلاس است.
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### متداول Z-Transforms
| x[n] | X(z) | ROC |
|------|------|-----|
| δ[n] | 1 | همه z |
| u[n] (مرحله) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|a\| |
| naⁿu[n] | az/(z−a)² | \|z\| > \|a\| |
| sin(ω₀n)u[n] | z sin(ω₀)/(z²−2z cos(ω₀)+1) | \|z\| > 1 |
### رابطه با سایر تحولات
| تبدیل | دامنه | متغیر |
|-----------|--------|----------|
| فوریه | فرکانس پیوسته | f یا ω |
| لاپلاس | فرکانس پیچیده | s = σ + jω |
| تبدیل Z | فرکانس پیچیده (گسسته) | z = e^{sT} |
دایره واحد در صفحه z (|z| = 1) با تبدیل فوریه مطابقت دارد.

## فیلترها
فیلترها به طور انتخابی اجزای فرکانس خاصی را عبور داده یا مسدود می کنند.
### انواع فیلتر
| نوع | پاس ها | بلوک | برنامه |
|------|--------|--------|-------------|
| **کم گذر** | فرکانس های پایین | فرکانس های بالا | یکنواخت کننده، ضد ریزش |
| **بالاگذر** | فرکانس های بالا | فرکانس های پایین | تشخیص لبه، حذف نویز |
| **باند گذر** | طیف وسیعی از فرکانس ها | خارج از محدوده | انتخاب کانال (رادیو) |
| **بند-استاپ (ناچ)** | همه چیز به جز یک محدوده | محدوده خاص | حذف هوم خط برق |
### فیلترهای FIR در مقابل IIR
| اموال | FIR (پاسخ تکانه محدود) | IIR (پاسخ بی نهایت تکانه) |
|---------------------------------------------------------------------------------------------------------------------|
| پاسخ ضربه ای | مدت زمان محدود | مدت بی نهایت |
| ثبات | همیشه پایدار | می تواند ناپایدار باشد |
| فاز | می تواند دقیقا خطی باشد | فاز عموما غیر خطی |
| بازخورد | نه | بله |
| محاسبات | ضرایب بیشتر مورد نیاز | ضرایب کمتر برای همان رول آف |
| طراحی | پنجره، Parks-McClellan | باترورث، چبیشف، بیضوی |
| تابع انتقال | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### مشخصات طراحی فیلتر
| پارامتر | توضیحات |
|-----------|-------------|
| **رمز عبور** | محدوده فرکانسی که باید با حداقل تلفات عبور کند |
| **باند توقف** | محدوده فرکانسی که باید کاهش یابد |
| **فرکانس قطع ** | مرز بین باند عبور و توقف |
| **ریپل** | تغییر در افزایش باند عبور (یا توقف) |
| **رول آف** | نرخ تضعیف (dB در هر اکتاو یا دهه) |
| **باند انتقال** | منطقه بین باند عبور و توقف |
### طرح های رایج فیلتر
| طراحی | مشخصات | مورد استفاده |
|--------|---------------|----------|
| **Butterworth** | باند عبور حداکثر صاف، رول آف متوسط ​​| هدف عمومی |
| **چبیشف نوع اول** | ریپل در باند عبور، رول آف تندتر | وقتی رول آف مهم است |
| **چبیشف نوع دوم** | ریپل در توقف بند، باند صاف | وقتی مسطح بودن باند عبور مهم است |
| **بیضوی (Cauer)** | ریپل در هر دو، شیب دارترین رول آف | حداقل سفارش مورد نیاز |
| **بسل** | فاز خطی (تاخیر گروه حداکثر مسطح) | حفظ شکل موج |

## نظریه نمونه گیری
### قضیه نمونه گیری نایکویست-شانون
اگر نرخ نمونه برداری از دو برابر حداکثر فرکانس بیشتر شود، می توان سیگنال پیوسته را کاملاً از نمونه های آن بازسازی کرد:
f_s > 2f_max
| ترم | تعریف |
|------|------------|
| **نرخ نمونه برداری** (f_s) | تعداد نمونه در ثانیه |
| **نرخ Nyquist** | 2f_max (حداقل نرخ نمونه برداری) |
| **فرکانس Nyquist** | f_s/2 (حداکثر فرکانس قابل نمایش) |
| **Aliasing** | فرکانس‌های بالا وقتی f_s < 2f_max به فرکانس‌های پایین تبدیل می‌شوند |
### نرخ های نمونه گیری رایج
| برنامه | نرخ | فرکانس Nyquist |
|-------------|------|-------------------|
| سخنرانی تلفنی | 8 کیلوهرتز | 4 کیلوهرتز |
| سی دی صوتی | 44.1 کیلوهرتز | 22.05 کیلوهرتز |
| صوتی حرفه ای | 48 کیلوهرتز | 24 کیلوهرتز |
| صدای با وضوح بالا | 96 کیلوهرتز | 48 کیلوهرتز |
| ویدیو (30 فریم در ثانیه) | 30 هرتز (زمانی) | 15 هرتز |
### Anti Aliasing
قبل از نمونه‌برداری، یک **فیلتر ضد aliasing** (کم گذر) فرکانس‌های بالاتر از f_s/2 را حذف می‌کند تا از همخوانی جلوگیری کند.

## پنجره
هنگام تجزیه و تحلیل یک بخش محدود از یک سیگنال، به طور ضمنی در یک پنجره مستطیلی ضرب می‌کنیم که باعث نشت طیفی می‌شود. **عملکردهای پنجره** این نشتی را کاهش می دهد.
### ویندوز معمولی
| پنجره | عرض لوب اصلی | سطح لوب کناری | مورد استفاده |
|--------|---------------|----------------|----------|
| مستطیل شکل | باریک ترین | -13 دسی بل | زمانی که وضوح بیشتر اهمیت دارد |
| هان | 2× مستطیل | -31 دسی بل | هدف عمومی |
| همینگ | 2× مستطیل | -41 دسی بل | کاهش نزدیکترین لوب کناری |
| بلکمن | 3× مستطیل | -58 دسی بل | محدوده دینامیکی بالا |
| قیصر | قابل تنظیم | قابل تنظیم (از طریق β) | وقتی مبادله قابل تنظیم است |
### نشت طیفی
ضرب یک سیگنال در یک پنجره، طیف آن را با طیف پنجره در هم می‌گیرد. لوب های اصلی گسترده تر وضوح فرکانس را کاهش می دهند. لوب های سمت پایین نشتی را کاهش می دهند.

## موجک
**موجک**ها توابع موج مانند کوچک و موضعی هستند که برای تجزیه و تحلیل سیگنال با وضوح چندگانه استفاده می شوند.
### تبدیل موجک
بر خلاف تبدیل فوریه (که اطلاعات فرکانس جهانی را می‌دهد)، تبدیل موجک مکان‌سازی **زمان-فرکانس** را می‌دهد.
| تبدیل | وضوح زمان | وضوح فرکانس |
|-----------|----------------|---------------------|
| فوریه | هیچ (جهانی) | عالی |
| کوتاه مدت FT | ثابت (اندازه پنجره) | ثابت |
| موجک | متغیر (در فرکانس بالا خوب) | متغیر (در فرکانس پایین خوب) |
### خانواده های موجک رایج
| خانواده | خواص | برنامه |
|--------|----------|-------------|
| **هار** | ساده ترین، ناپیوسته | تشخیص لبه، آنالیز سریع |
| **Daubechies** (dbN) | پشتیبانی فشرده، N لحظه ناپدید شدن | فشرده سازی، حذف نویز |
| **Symlets** | Daubechies تقریبا متقارن | کاهش اعوجاج فاز |
| **کت و شلوار** | طراحی شده برای شرایط لحظه | پردازش سیگنال |
| **مورلت** | سینوسی با پنجره گاوسی | تحلیل زمان-فرکانس |
| **کلاه مکزیکی** | مشتق دوم گوسی | تشخیص ویژگی |
### کاربردهای موجک
| برنامه | چگونه موجک ها کمک می کنند |
|-------------|-------------------|
| فشرده سازی تصویر (JPEG 2000) | نمایش با وضوح چندگانه، بهتر از DCT برای لبه ها |
| نویز زدایی | آستانه ضرایب موجک کوچک (سیگنال در ضرایب بزرگ است) |
| تشخیص ویژگی | تشخیص لبه، تشخیص گذرا در سری های زمانی |
| آنالیز ECG | تشخیص کمپلکس های QRS، طبقه بندی آریتمی |
| تحلیل لرزه ای | شناسایی لایه های زمین شناسی، پردازش سیگنال زلزله |

| تحلیل طیفی | تجزیه و تحلیل EEG/fMRI، نظارت بر ارتعاش، نگهداری پیش بینی |
| نرخ Nyquist | انتخاب نرخ های مناسب جمع آوری داده برای خطوط لوله ML |

## خلاصه
| ابزار | دامنه | بینش کلیدی |
|------|--------|-------------|
| تبدیل فوریه | زمان → فرکانس | سیگنال ها مجموع سینوسی ها هستند |
| تبدیل لاپلاس | زمان → فرکانس پیچیده | کنترل گذرا و پایداری |
| Z-Transform | زمان گسسته → مجتمع | تحلیل و طراحی فیلتر دیجیتال |

پردازش سیگنال پایه ریاضی را برای درک، تجزیه و تحلیل و دستکاری داده ها فراهم می کند. هر خط لوله یادگیری ماشینی که با سری های زمانی، صدا، تصاویر یا داده های حسگر کار می کند به طور ضمنی از مفاهیم پردازش سیگنال استفاده می کند. تبدیل فوریه، به ویژه، مسلماً مهمترین ابزار ریاضی بعد از حساب دیفرانسیل و انتگرال برای هر دانشمند داده است.
