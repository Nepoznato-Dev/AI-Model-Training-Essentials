# تئوری اطلاعات
نظریه اطلاعات که توسط کلود شانون در سال 1948 تأسیس شد، خود اطلاعات را کمیت می کند. یک پیام چقدر به شما می گوید؟ چقدر می توانید داده ها را فشرده کنید؟ چقدر سریع می توانید از طریق یک کانال پر سر و صدا ارتباط برقرار کنید؟ این سوالات پاسخ های ریاضی دقیقی دارند. فراتر از ارتباطات، نظریه اطلاعات برای یادگیری ماشین پایه‌ای شده است - آنتروپی متقابل تابع ضرر پیش‌فرض برای طبقه‌بندی است، واگرایی KL شباهت توزیع را اندازه‌گیری می‌کند و انتخاب ویژگی درایوهای اطلاعات متقابل.

## آنتروپی
**آنتروپی** میانگین عدم قطعیت یا "غافلگیری" یک متغیر تصادفی را اندازه گیری می کند.
### آنتروپی شانون (گسسته)
برای یک متغیر تصادفی گسسته X با تابع جرم احتمال p(x):
H(X) = -Σₓ p(x) log2 p(x)
واحدها: **bit** (هنگام استفاده از log2) یا **nats** (هنگام استفاده از ln).
| توزیع | آنتروپی | شهود |
|-------------|---------|-----------|
| سکه منصفانه (p = 0.5، 0.5) | 1 بیت | حداکثر عدم قطعیت برای نتیجه باینری |
| سکه مغرضانه (p = 0.9، 0.1) | 0.469 بیت | کمتر تعجب آور - بیشتر سرها |
| قطعی (p = 1، 0) | 0 بیت | اصلاً بدون قطعیت |
| قالب عادلانه (6 طرف) | 2.585 بیت | نتایج بیشتر = عدم اطمینان بیشتر |
| یکنواخت بیش از n نتیجه | log₂(n) بیت | حداکثر آنتروپی برای n نتیجه |
### خواص آنتروپی
| اموال | بیانیه |
|----------|-----------|
| غیر منفی | H(X) ≥ 0 |
| حداکثر | H(X) ≤ log2(\|X\|) با برابری برای توزیع یکنواخت |
| قانون زنجیره ای | H(X, Y) = H(X) + H(Y \| X) |
| تهویه باعث کاهش | H(X \| Y) ≤ H(X) |
| تقعر | H یک تابع مقعر از توزیع احتمال |
### آنتروپی دیفرانسیل (پیوسته)
برای یک متغیر تصادفی پیوسته X با چگالی p(x):
h(X) = −∫ p(x) log p(x) dx
برخلاف آنتروپی گسسته، آنتروپی دیفرانسیل می تواند **منفی** باشد.
| توزیع | آنتروپی دیفرانسیل |
|-------------|---------------------|
| یکنواخت روی [a,b] | log(b − a) |
| نرمال N(μ، σ²) | (1/2) log(2πeσ²) |
| نمایی(λ) | 1 - ln(λ) |

## اطلاعات مشترک، مشروط و متقابل
### آنتروپی مشترک
H(X, Y) = -Σₓ Σᵧ p(x, y) log p(x, y)
عدم قطعیت کل جفت (X,Y) را اندازه گیری می کند.
### آنتروپی شرطی
H(Y | X) = -Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) - H(X)
عدم قطعیت باقی مانده در مورد Y را پس از مشاهده X اندازه گیری می کند.
### اطلاعات متقابل
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
اندازه گیری می کند که دانستن X چقدر در مورد Y به شما می گوید (و بالعکس).
| اموال | بیانیه |
|----------|-----------|
| غیر منفی | I(X; Y) ≥ 0 |
| تقارن | I(X; Y) = I(Y; X) |
| رابطه با آنتروپی | I(X; Y) = H(X) - H(X \| Y) = H(Y) - H(Y \| X) |
| ارتباط با مفصل | I(X; Y) = H(X) + H(Y) - H(X, Y) |
| استقلال | I(X; Y) = 0 اگر X و Y مستقل باشند |
| خود اطلاعاتی | I(X; X) = H(X) |
### تصویری: نمودار آنتروپی
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## واگرایی KL
واگرایی **Kullback-Leibler (KL)** تفاوت یک توزیع با توزیع دیگر را اندازه گیری می کند.
D_KL(P || Q) = Σₓ P(x) log [P(x) / Q(x)]
| اموال | بیانیه |
|----------|-----------|
| غیر منفی | D_KL(P \|\| Q) ≥ 0 (نابرابری گیبز) |
| هویت | D_KL(P \|\| Q) = 0 اگر P = Q |
| عدم تقارن | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) به طور کلی |
| متریک نیست | عدم تقارن و نابرابری مثلث |
**تفسیر:** D_KL(P || Q) تعداد بیت های اضافی مورد نیاز برای رمزگذاری داده ها از P با استفاده از یک کد بهینه شده برای Q است.
### رابطه با مقادیر دیگر
| رابطه | فرمول |
|-------------|---------|
| متقابل آنتروپی | H(P، Q) = H(P) + D_KL(P \|\| Q) |
| اطلاعات متقابل | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| KL مشروط | D_KL(P(Y\|X) \|\| Q(Y\|X)) میانگین بالای X |

## آنتروپی متقابل
**آنتروپی متقاطع** بین توزیع های P و Q:
H(P، Q) = -Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### آنتروپی متقاطع به عنوان یک تابع ضرر
در طبقه بندی، P توزیع واقعی (برچسب کدگذاری شده یک گرم) و Q توزیع پیش بینی شده مدل است.
**آنتروپی متقاطع باینری (پیش از میلاد):**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**آنتروپی متقاطع طبقه ای:**
L = −Σᵢ yᵢ log(ŷᵢ)
| سناریو | y (درست) | ŷ (پیش بینی شده) | ضرر |
|----------|----------|--------------|------|
| درست، مطمئن | 1 | 0.95 | 0.051 |
| صحیح، نامشخص | 1 | 0.55 | 0.598 |
| اشتباه، مطمئن | 1 | 0.05 | 2.996 |
| اشتباه، نامطمئن | 1 | 0.45 | 0.799 |
به حداقل رساندن آنتروپی متقاطع معادل به حداقل رساندن واگرایی KL از توزیع واقعی است - به همین دلیل است که به عنوان یک تابع ضرر بسیار خوب عمل می کند.

## ظرفیت کانال
### مدل کانال ارتباطی
```
X → [Channel] → Y
```

- X: متغیر تصادفی ورودی
- Y: متغیر تصادفی خروجی
- کانال: تعریف شده توسط احتمالات شرطی p(y|x)
### قضیه کدگذاری کانال پر سر و صدا شانون
برای یک کانال با ظرفیت C، اگر نرخ انتقال R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C باشد، ارتباط قابل اعتماد غیرممکن است.
**ظرفیت کانال:**
C = max_{p(x)} I(X; Y)
### نمونه های مهم کانال
| کانال | توضیحات | ظرفیت |
|---------|-------------|----------|
| **تقارن دودویی (BSC)** | هر بیت را با احتمال p | برمیگرداند 1 - بیت H(p) |
| **پاک کردن باینری (BEC)** | هر بیت را با احتمال ε | پاک می کند 1 - ε بیت |
| **گاوسی (AWGN)** | Y = X + Z، Z ~ N(0، σ²) | بیت (1/2)log (1 + SNR) |
| **دودویی بدون صدا** | انتقال کامل | 1 بیت |

## کدگذاری و فشرده سازی منبع
### قضیه کدگذاری منبع
میانگین تعداد بیت های مورد نیاز برای رمزگذاری یک منبع با آنتروپی آن در زیر محدود می شود:
L ≥ H(X)
یک کد بهینه به L≈ H(X) می رسد.
### کدنویسی هافمن
یک کد **بدون پیشوند** که کدهای کوتاه تری را به نمادهای محتمل تر اختصاص می دهد.
| نماد | احتمال | کد هافمن | طول |
|--------|------------|------------|--------|
| A | 0.5 | 0 | 1 |
| ب | 0.25 | 10 | 2 |
| ج | 0.125 | 110 | 3 |
| D | 0.125 | 111 | 3 |
طول متوسط: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 بیت/نماد
آنتروپی: H = 1.75 بیت/نماد (در این مورد بهینه است!)
### Lossless در مقابل Lossy Compression
| نوع | اصل | مثال ها | محدود |
|------|-----------|----------|-------|
| **بی ضرر** | حذف افزونگی آماری | ZIP، PNG، FLAC | نرخ آنتروپی H(X) |
| **زیان** | حذف اطلاعات ادراکی نامربوط | JPEG, MP3, H.264 | تابع نرخ-اعوجاج R(D) |
**نظریه نرخ-اعوجاج:** برای فشرده سازی با تلفات با حداکثر اعوجاج D، حداقل نرخ R(D) = min I(X; X̂) مشروط به E[d(X, X̂)] ≤ D است.

## خلاصه
| مقدار | فرمول (گسسته) | معنی |
|----------|------------------|---------|
| آنتروپی H(X) | −Σ p(x) log p(x) | میانگین عدم قطعیت |
| آنتروپی مشترک H(X,Y) | -Σ p(x,y) log p(x,y) | مجموع عدم قطعیت جفت |
| آنتروپی شرطی H(Y\|X) | H(X,Y) - H(X) | عدم قطعیت باقی مانده در مورد Y با توجه به X |
| اطلاعات متقابل I(X;Y) | H(X) - H(X\|Y) | اطلاعات به اشتراک گذاشته شده بین X و Y |
| واگرایی KL D_KL(P\|\|Q) | Σ P(x) log(P(x)/Q(x)) | "فاصله" بین توزیع ها |
| متقاطع آنتروپی H(P,Q) | −Σ P(x) log Q(x) | هزینه رمزگذاری با استفاده از توزیع اشتباه |
| ظرفیت کانال C | حداکثر I(X;Y) | حداکثر نرخ ارتباط قابل اعتماد |
تئوری اطلاعات محدودیت‌های اساسی آنچه را که می‌توان آموخت، فشرده کرد و ارتباط داد، ارائه می‌کند. برای تمرین‌کنندگان یادگیری ماشین، توضیح می‌دهد که چرا آنتروپی متقاطع به عنوان یک تابع ضرر عمل می‌کند، چگونه کیفیت نمایش‌های آموخته‌شده را اندازه‌گیری کنیم، و چگونه در مورد مبادله بین پیچیدگی مدل و تناسب داده‌ها فکر کنیم. بینش شانون از سال 1948 به همان اندازه که در ارتباط از راه دور با هوش مصنوعی مدرن مرتبط است.
