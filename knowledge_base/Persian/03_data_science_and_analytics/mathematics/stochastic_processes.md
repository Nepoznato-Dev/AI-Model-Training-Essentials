# فرآیندهای تصادفی
**فرآیند تصادفی** مجموعه ای از متغیرهای تصادفی است که بر اساس زمان (یا مکان) نمایه می شوند. در حالی که نظریه احتمال رویدادهای تصادفی فردی را مطالعه می کند، فرآیندهای تصادفی چگونگی تکامل تصادفی را در طول زمان مطالعه می کنند. آنها قیمت سهام، طول صف، گسترش بیماری، تولید زبان و پویایی آموزش مدل های یادگیری ماشین را مدل می کنند.
---

## پایه ها
### تعریف
یک فرآیند تصادفی {X_t : t ∈ T} خانواده ای از متغیرهای تصادفی است که بر روی یک فضای احتمال مشترک تعریف شده اند. T مجموعه **مجموعه شاخص** (زمان):
- **زمان گسسته:** T = {0، 1، 2، ...}
- **زمان پیوسته:** T = [0، ∞)
**فضای حالت** S مجموعه مقادیر ممکنی است که X_t می تواند بگیرد.
### ویژگی های کلیدی
| اموال | تعریف |
|----------|------------|
| **ایستایی** | توزیع مشترک (X_{t1}، ...، X_{t2}) مشابه (X_{t1+τ}، ...، X_{tₖ+τ}) |
| **استقلال** | X_t مستقل از X_s برای t ≠ s |
| **ارگودیسم** | میانگین های زمانی به میانگین های گروهی همگرا می شوند |
| **ملک مارکوف** | آینده فقط به حال بستگی دارد نه گذشته |
| **مارتینگل** | ارزش آتی مورد انتظار برابر با ارزش فعلی |

## زنجیر مارکوف
یک **زنجیره مارکوف** یک فرآیند تصادفی است که در آن حالت آینده فقط به حالت فعلی (ویژگی بدون حافظه) بستگی دارد.
### زنجیره مارکوف زمان گسسته (DTMC)
P(X_{n+1} = j | X_n = i، X_{n-1} = i_{n-1}، ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**ماتریس انتقال** P دارای ورودی‌های p_{ij} = P (به j بروید | در حال حاضر در i).
| اموال | بیانیه |
|----------|-----------|
| مجموع ردیف | مجموع هر ردیف به 1 می رسد: Σⱼ p_{ij} = 1 |
| انتقال n مرحله ای | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| توزیع ثابت | πP = π (بردار ویژه سمت چپ با مقدار ویژه 1) |
### طبقه بندی ایالات
| ترم | تعریف |
|------|------------|
| **تکراری** | زنجیره با احتمال 1 به حالت i برمی گردد
| **گذرا** | احتمال عدم بازگشت هرگز |
| **جذب** | p_{ii} = 1 (یک بار وارد شده، هرگز خارج نشد) |
| **دوره** | GCD زمان بازگشت؛ دوره 1 = دوره ای |
| **ارتباط ** | حالات i و j می توانند به یکدیگر برسند |
### توزیع ثابت
برای یک زنجیره مارکوف بازگشتی غیرقابل کاهش و مثبت، توزیع ثابت π وجود دارد، منحصر به فرد است و برآورده می‌کند:
πP = π، Σᵢ πᵢ = 1
**تفسیر:** πᵢ = نسبت طولانی مدت زمان صرف شده در حالت i.
**مثال کار شده:** مدل آب و هوا با حالت {آفتابی، بارانی}.
P = [[0.9، 0.1]، [0.5، 0.5]] (ردیف: از آفتابی، از بارانی)
توزیع ثابت: πP = π
- π1 = 0.9π1 + 0.5π2
- π2 = 0.1π1 + 0.5π2
- π1 + π2 = 1
- حل: π1 = 5/6 ≈ 0.833، π2 = 1/6 ≈ 0.167
### همگرایی به ایستایی
برای یک زنجیره برگشت ناپذیر، غیر دوره ای و مثبت:
- Pⁿ → Π (ماتریس با همه ردیف ها برابر با π) به صورت n → ∞
- **زمان اختلاط:** تعداد مراحل تا زمانی که توزیع نزدیک به π باشد
- **شکاف طیفی:** 1 − |λ2| (که در آن λ2 دومین مقدار ویژه بزرگ است) سرعت اختلاط را تعیین می کند
### زنجیره مارکوف زمان پیوسته (CTMC)
انتقال ها در زمان های تصادفی که توسط توزیع های نمایی اداره می شود، رخ می دهد.
| مفهوم | توضیحات |
|---------|-------------|
| **ماتریس نرخ Q** | q_{ij} ≥ 0 برای i ≠ j; q_{ii} = −Σ_{j≠i} q_{ij} |
| **احتمالات گذار** | P(t) = e^{Qt} (ماتریس نمایی) |
| **توزیع ثابت** | πQ = 0 |
| **زمان برگزاری** | زمان در حالت i Exp(−q_{ii}) |

## پیاده روی تصادفی
**راهپیمایی تصادفی** مسیری است که با گام های تصادفی متوالی شکل می گیرد.
### پیاده روی تصادفی ساده
X_n = X_{n-1} + Z_n، که در آن Z_n ∈ {+1، −1} با احتمالات p، q = 1−p.
| اموال | p = 1/2 (متقارن) | p ≠ 1/2 (طرفدار) |
|----------|--------------------|------------------|
| E[X_n] | 0 | n(2p−1) |
| Var[X_n] | n | 4npq |
| به مبدأ برمی گردد؟ | بله (با احتمال 1) | نه (دریفت دور) |
| تکراری؟ | بله (در یک بعدی و دو بعدی) | نه |
### پیاده روی تصادفی در ابعاد بالاتر
| ابعاد | تکراری؟ | شهود |
|-----------|------------|-----------|
| 1D | بله | "مرد مست همیشه راه خانه را پیدا می کند" |
| دو بعدی | بله | "پرنده مست همیشه راه خود را به خانه پیدا می کند" |
| 3D+ | نه | "گنجشک مست هرگز راه خود را به خانه پیدا نمی کند" |
### اتصال به حرکت براونی
مقیاس گذاری یک پیاده روی تصادفی: اجازه دهید S_n = ΣZ_i. سپس به عنوان اندازه مرحله → 0 و مراحل → ∞:
S_{⌊nt⌋} / √n → B(t) (حرکت براونی، بر اساس قضیه دانسکر)
---

## حرکت براونی
**حرکت براونی** (فرایند وینر) B(t) محدودیت زمانی پیوسته یک راه رفتن تصادفی است.
### تعریف
B(t) برآورده می کند:
1. B(0) = 0
2. B(t) دارای مسیرهای پیوسته است
3. افزایش مستقل: B(t) - B(s) مستقل از B(s) - B(r) برای r <s <t
4. B(t) - B(s) ~ N(0، t - s) (افزایش گاوسی)
### ویژگی های کلیدی
| اموال | بیانیه |
|----------|-----------|
| E[B(t)] | = 0 |
| Var[B(t)] | = t |
| Cov[B(s)، B(t)] | = min(s، t) |
| هیچ جا قابل تمایز نیست | مسیرها پیوسته هستند اما هیچ مشتق |
| بعد فراکتال | گراف دارای ابعاد Hausdorff 3/2 |
| دارایی مارکوف | آینده فقط به موقعیت فعلی بستگی دارد |
| مارتینگل | E[B(t) | F_s] = B(s) برای s < t |
### حرکت براونی هندسی
S(t) = S(0) exp((μ - σ²/2)t + σB(t))
این مدل استاندارد برای قیمت سهام در چارچوب Black-Scholes است.
- μ: رانش (بازده مورد انتظار)
- σ: نوسانات
---

## فرآیندهای پواسون
یک **فرآیند پواسون** N(t) تعداد رویدادهایی را که در [0, t] رخ می دهند، شمارش می کند.
### تعریف
N(t) ~ پواسون(λt)، که در آن λ نرخ است (رویدادها در واحد زمان).
| اموال | بیانیه |
|----------|-----------|
| N(0) = 0 | — |
| افزایش مستقل | رویدادها در فواصل متمایز مستقل هستند |
| افزایش ثابت | N(t+s) - N(s) ~ پواسون(λt) |
| E[N(t)] | = λt |
| Var[N(t)] | = λt |
| زمان بین ورود | توزیع نمایی: T_i ~ Exp(λ) |
### کلیات
| نوع | توضیحات |
|---------|-------------|
| **غیر همگن** | نرخ λ(t) با زمان تغییر می کند |
| **پواسون مرکب** | هر رویداد یک اندازه تصادفی دارد: S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **اندازه گیری تصادفی پواسون** | نقاط در فضا-زمان، نه فقط زمان |
| **چند متغیره** | انواع رویدادهای متعدد با تعاملات احتمالی |

## Martingales
**مارتینگل** یک بازی منصفانه است: ارزش آینده مورد انتظار، با توجه به تمام اطلاعات فعلی، برابر با ارزش فعلی است.
### تعریف
{X_n} یک مارتینگل با توجه به فیلتراسیون {F_n} است اگر:
1. X_n قابل اندازه گیری F_n است (اقتباس شده)
2. E[|X_n|] < ∞ (قابل ادغام)
3. E[X_{n+1} | F_n] = X_n (بازی منصفانه)
| نوع | وضعیت | تفسیر |
|---------|-----------|----------------|
| **مارتینگل** | E[X_{n+1} | F_n] = X_n | بازی منصفانه |
| **Submartingale** | E[X_{n+1} | F_n] ≥ X_n | بازی مطلوب (ترندینگ) |
| **Supermartingale** | E[X_{n+1} | F_n] ≤ X_n | بازی نامطلوب (روند نزولی) |
### قضایای کلیدی
| قضیه | بیانیه |
|---------|-----------|
| **توقف اختیاری** | تحت شرایط، E[X_T] = E[X_0] برای زمان توقف T |
| **همگرایی** | یک مارتینگل محدود تقریباً مطمئناً همگرا می شود |
| **بیشترین نابرابری** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Doob's) |

## روش های مونت کارلو
**روش های مونت کارلو** از نمونه گیری تصادفی برای تخمین کمیت های قطعی استفاده می کنند.
### ایده اولیه
برای تخمین E[f(X)] که در آن X ~ P:
1. N نمونه بکشید: x1, x2, ..., x_N از P
2. محاسبه: Î = (1/N) Σᵢ f(xᵢ)
3. طبق قانون اعداد بزرگ: Î → E[f(X)] به صورت N → ∞
**خطا:** خطای استاندارد = σ_f / √N، که در آن σ_f² = Var[f(X)]
### تکنیک های کاهش واریانس
| تکنیک | ایده | افزایش سرعت |
|-----------|------|---------|
| **نمونه گیری اهمیت** | نمونه از Q به جای P، وزن توسط P/Q | می تواند دراماتیک باشد |
| **تغییرهای متضاد ** | از جفت (x، −x) برای لغو واریانس | استفاده کنید ~2x |
| **تغییرهای کنترل** | تابع انتظار شناخته شده مرتبط با f | را کم کنید متغیر |
| **نمونه گیری طبقه ای** | تقسیم دامنه، نمونه برداری از هر طبقه | کاهش واریانس |
| **رائو بلکول** | شرط آمار کافی | همیشه کمک می کند |

## زنجیره مارکوف مونت کارلو (MCMC)
MCMC یک زنجیره مارکوف می سازد که توزیع ثابت آن توزیع هدف است. پس از یک دوره "سوختن"، نمونه ها به طور تقریبی از هدف برداشت می کنند.
### الگوریتم متروپلیس-هیستینگ
| مرحله | اقدام |
|------|--------|
| 1 | وضعیت فعلی: x_t |
| 2 | پیشنهاد: x* ~ q(x* \| x_t) (توزیع پیشنهاد) |
| 3 | نسبت پذیرش: α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | قبول با احتمال α: x_{t+1} = x* (قبول) یا x_t (رد) |
**مورد خاص — الگوریتم متروپلیس:** پیشنهاد متقارن q(x*|x) = q(x|x*)، بنابراین α = min(1, π(x*)/π(x_t)).
### نمونه برداری گیبس
یک مورد خاص از Metropolis-Hastings که در آن هر متغیر از توزیع شرطی کامل خود به روز می شود.
برای π(x1، x2، ...، x2):
1. نمونه x1^{(t+1)} ~ π(x1 | x2^{(t)}، ...، xₖ^{(t)})
2. نمونه x2^{(t+1)} ~ π(x2 | x1^{(t+1)}، x₃^{(t)}، ...، x2^{(t)})
3. برای همه متغیرها ادامه دهید
4. تکرار کنید
| اموال | بیانیه |
|----------|-----------|
| همیشه می پذیرد | α = 1 (بدون مرحله رد) |
| نیاز دارد | امکان نمونه برداری از هر شرطی کامل |
| همگرایی | تضمین شده برای زنجیره های غیرقابل کاهش، دوره ای |
### MCMC Diagnostics
| تشخیصی | هدف |
|-----------|---------|
| **طراحی ردیابی** | بررسی بصری برای اختلاط و ثابت بودن |
| **همبستگی خودکار** | وابستگی نمونه را اندازه گیری می کند (خودهمبستگی کم می خواهد) |
| **گلمان-روبین (R̂)** | مقایسه زنجیره های متعدد؛ R̂ < 1.05 نشان دهنده همگرایی |
| **اندازه نمونه موثر** | N_eff = N / (1 + 2Σρₖ); حساب برای خودهمبستگی |
| **سوختن** | قبل از اینکه زنجیره به حالت ثابت برسد، نمونه های اولیه را دور بیندازید |

## ارتباط با یادگیری ماشین و علم داده
| فرآیند تصادفی | برنامه |
|-------------------|-------------|
| زنجیر مارکوف | PageRank (راه رفتن تصادفی روی نمودار وب)، تولید متن (مدل های n-gram)، MCMC |
| پیاده روی تصادفی | Node2Vec و DeepWalk (جاسازی نمودار)، کاوش در RL |
| حرکت براونی | مدل سازی قیمت سهام، مدل های انتشار در هوش مصنوعی مولد |
| فرآیندهای پواسون | مدل سازی ورود رویداد (کلیک ها، شکست ها)، تئوری صف |
| مارتینگالس | ریاضیات مالی، اثبات همگرایی SGD (تقریب تصادفی) |
| مونت کارلو | برآورد مقادیر مورد انتظار، استنتاج بیزی، یادگیری تقویتی (ارزیابی سیاست) |
| MCMC (Metropolis-Hastings) | نمونه برداری پسین بیزی، برنامه ریزی احتمالی (Stan, PyMC) |
| نمونه گیری گیبس | مدل‌های موضوعی (LDA)، شبکه‌های بیزی، حذف نویز تصویر |
| تشخیص MCMC | اطمینان از استنتاج قابل اعتماد از مدل های احتمالی |

## خلاصه
| فرآیند | فضای ایالتی | زمان | ویژگی کلید |
|---------|------------|------|--------------|
| زنجیره مارکوف | گسسته/پیوسته | گسسته/پیوسته | بدون حافظه (مخصوص مارکوف) |
| پیاده روی تصادفی | ℤᵈ | گسسته | مجموع i.i.d. مراحل |
| حرکت براونی | ℝ | پیوسته | افزایش گاوسی، مسیرهای پیوسته |
| فرآیند پواسون | ℕ | پیوسته | فرآیند شمارش با شکاف های نمایی |
| مارتینگل | ℝ | گسسته/پیوسته | بازی منصفانه (E[X_{t+1}|F_t] = X_t) |
فرآیندهای تصادفی ریاضیات تصادفی در طول زمان هستند. آنها زیربنای استنتاج بیزی مدرن (MCMC)، یادگیری تقویتی (فرایندهای تصمیم مارکوف)، مدل‌سازی مولد (مدل‌های انتشار)، ریاضیات مالی و تئوری صف هستند. درک این فرآیندها ابزارهایی را در اختیار شما قرار می دهد تا عدم قطعیت را به صورت پویا مدل سازی کنید - نه فقط به عنوان یک عکس فوری، بلکه همانطور که در حال تکامل است.
