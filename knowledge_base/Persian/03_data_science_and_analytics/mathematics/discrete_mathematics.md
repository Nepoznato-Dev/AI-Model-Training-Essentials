# ریاضیات گسسته
ریاضیات گسسته مطالعه ساختارهای ریاضی است که اساساً قابل شمارش یا جدا هستند - برخلاف ریاضیات پیوسته (حساب حساب، تجزیه و تحلیل واقعی) که با کمیت های صاف و ناگسستنی سروکار دارد. ریاضیات گسسته زیربنای علوم کامپیوتر، رمزنگاری، طراحی الگوریتم و ساختارهای داده است. اگر ریاضیات پیوسته دنیای فیزیکی را توصیف می کند، ریاضیات گسسته دنیای محاسباتی را توصیف می کند.

## نظریه مجموعه ها در عمق
مجموعه ها پایه ای هستند که تقریباً تمام ریاضیات مدرن بر روی آن بنا شده است. ** مجموعه** مجموعه ای نامرتب از اشیاء متمایز است که **عناصر** یا **عضو** نامیده می شوند.
### پایه های بدیهی (ZFC)
نظریه مجموعه های مدرن بر اساس بدیهیات **زرملو-فرانکل با اصل انتخاب (ZFC)** استوار است. این بدیهیات پارادوکس هایی مانند پارادوکس راسل ("مجموعه همه مجموعه هایی که خود را شامل نمی شوند") با محدود کردن نحوه تشکیل مجموعه ها حل می کنند.
| اصل مطلب | بیانیه غیر رسمی |
|-------|-------------------|
| توسعه پذیری | دو مجموعه اگر عناصر یکسانی داشته باشند |
| مجموعه خالی | مجموعه ای بدون عنصر وجود دارد: ∅ |
| جفت شدن | برای هر a، b، {a، b} وجود دارد |
| اتحادیه | برای هر خانواده ای از مجموعه ها، اتحاد آنها وجود دارد |
| پاور ست | برای هر مجموعه S، مجموعه همه زیر مجموعه های S وجود دارد: P(S) |
| بی نهایت | یک مجموعه بی نهایت وجود دارد |
| مشخصات | برای هر مجموعه A و ویژگی P، {x ∈ A : P(x)} وجود دارد |
| جایگزینی | تصویر یک مجموعه تحت یک تابع قابل تعریف یک مجموعه | است
| منظم بودن | هر مجموعه غیر خالی حاوی یک عنصر جدا از آن است (از خود عضویت جلوگیری می کند) |
| انتخاب | برای هر خانواده ای از مجموعه های مجزای جفتی غیر خالی، یک تابع انتخاب وجود دارد |
### کاردینالیته و اندازه مجموعه ها
**کاردینالیته** یک مجموعه، با علامت |S|، "اندازه" آن را اندازه گیری می کند.
| مفهوم | تعریف | مثال |
|---------|------------|---------|
| مجموعه محدود | دارای یک عدد طبیعی به عنوان اصلی | |{a، b، c}| = 3 |
| قابل شمارش بی نهایت | کاردینالیتی مشابه ℕ | ℤ، ℚ قابل شمارش بی نهایت هستند |
| غیر قابل شمارش | بزرگتر از ℕ | ℝ، P(ℕ)، مجموعه همه توابع ℕ → {0،1} |
| قضیه کانتور | برای هر مجموعه S، |P(S)| > |S| | |P(ℕ)| > |ℕ| |
** آرگومان مورب کانتور** ثابت می‌کند که ℝ غیرقابل شمارش است: فرض کنید می‌توانید همه واقعی‌ها را در [0,1] فهرست کنید، سپس یک واقعی جدید بسازید که با nامین واقعی فهرست شده در nامین رقم اعشار متفاوت باشد - تضاد.
### عملیات در مجموعه ها
| عملیات | علامت گذاری | تعریف | اموال |
|-----------|----------|-----------|----------|
| اتحادیه | A ∪ B | {x : x ∈ A یا x ∈ B} | جابجایی، تداعی |
| تقاطع | A ∩ B | {x : x ∈ A و x ∈ B} | جابجایی، تداعی |
| تفاوت | A \ B | {x : x ∈ A و x ∉ B} | تعویضی نیست |
| تفاوت متقارن | A △ B | (A \ B) ∪ (B \ A) | جابجایی، تداعی |
| مکمل | Aᶜ | U \ A (که در آن U مجموعه جهانی است) | (Aᶜ)ᶜ = A |
| محصول دکارتی | A × B | {(a,b) : a ∈ A, b ∈ B} | |A × B| = |A| · |ب| |
**قوانین دی مورگان:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A∩ B)ᶜ = Aᶜ ∪ Bᶜ
**اصل گنجاندن-استخراج** (برای مجموعه های محدود):
|A1 ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A1 ∩ ... ∩ Aₙ|

## روابط
یک **رابطه** R در مجموعه های A و B زیر مجموعه ای از A × B است. وقتی (a, b) ∈ R، aRb می نویسیم.
### انواع روابط
یک رابطه R در مجموعه A می تواند این ویژگی ها را داشته باشد:
| اموال | تعریف | مثال |
|----------|------------|---------|
| انعکاسی | ∀a ∈ A: aRa | ≤ در ℤ |
| غیر انعکاسی | ∀a ∈ A: ¬(aRa) | < در ℤ |
| متقارن | ∀a,b: aRb → bRa | = روی هر مجموعه |
| ضد متقارن | ∀a,b: aRb ∧ bRa → a = b | ≤ در ℤ |
| متعدی | ∀a,b,c: aRb ∧ bRc → aRc | <، ≤، = در ℤ |
### روابط هم ارزی
یک رابطه **هم ارزی** بازتابی، متقارن و متعدی است. این یک مجموعه را به ** کلاس های هم ارزی مجزا تقسیم می کند.
**مثال:** محاسبات مدولار. a ~ b اگر a ≡ b (mod n) را تعریف کنید. کلاس های هم ارزی [0]، [1]، ...، [n−1] هستند که ℤ را به n کلاس تقسیم می کنند.
**مثال کار شده:** در ℤ × ℤ، (a,b) ~ (c,d) را اگر a + d = b + c تعریف کنید. این یک رابطه هم ارزی است. کلاس [(0,0)] = {(n,n) : n ∈ ℤ}. کلاس [(1,0)] = {(n+1,n) : n ∈ ℤ}. این ساختار در واقع اعداد صحیح را از اعداد طبیعی تعریف می کند.
### سفارشات جزئی
* نظم جزئی** بازتابی، ضد متقارن و متعدی است. مجموعه ای با نظم جزئی را **مجموعه مرتب شده جزئی (poset)** می نامند.
| مفهوم | تعریف | مثال |
|---------|------------|---------|
| پوست | (S، ≤) با ≤ یک سفارش جزئی | (P(A)، ⊆) - زیرمجموعه‌های مرتب شده بر اساس گنجاندن |
| زنجیر | یک زیر مجموعه کاملا سفارشی | {∅, {a}, {a,b}} در P({a,b,c}) |
| ضد زنجیر | زیر مجموعه ای که در آن هیچ دو عنصر قابل مقایسه | {{a}، {b}} در P({a,b}) |
| نمودار هاسه | نمایش تصویری یک پوست | لبه ها را فقط برای پوشش روابط بکشید |
| کران بالا | یک عنصر ≥ هر عنصر در یک زیر مجموعه | sup({2,3}) = 6 اینچ (ℤ، \|) (بخش پذیری) |
| حداقل کران بالا (sup) | کوچکترین کران بالا | sup({2,3}) در (ℕ، ≤) 3 است |
| بزرگترین کران پایین (inf) | بزرگترین کران پایین | inf({4,6}) در (ℕ، \|) برابر 2 | است

## توابع
یک **تابع** f: A → B به هر عنصر A دقیقاً یک عنصر از B را اختصاص می دهد.
### طبقه بندی توابع
| نوع | تعریف | مثال |
|------|------------|---------|
| تزریقی (یک به یک) | f(a) = f(b) → a = b | f(x) = 2x از ℤ → ℤ |
| Surjective (روی) | ∀b ∈ B، ∃a ∈ A: f(a) = b | f(x) = x mod 2 از ℤ → {0,1} |
| دوطرفه | هم تزریقی و هم سطحی | f(x) = x + 1 از ℤ → ℤ |
### مفاهیم عملکرد مهم
| مفهوم | تعریف | مورد استفاده |
|---------|------------|----------|
| تابع معکوس | f-1 وجود دارد اگر f دوگانه | رمزگشایی داده های رمزگذاری شده |
| ترکیب | (g ∘ f)(x) = g(f(x)) | دگرگونی های زنجیره ای |
| تابع هویت | id(x) = x | عنصر خنثی برای ترکیب |
| نقطه ثابت | f(x) = x | تعاریف بازگشتی، معناشناسی |
| جایگشت | جدایی از یک مجموعه به خودش | تنظیم مجدد داده ها، درهم ریختن |
### توابع شمارش
با توجه به مجموعه های محدود |A| = m و |B| = n:
| نوع | شمارش |
|------|-------|
| همه توابع A → B | nᵐ |
| توابع تزریقی | n! / (n−m)! (اگر n ≥ m، دیگری 0) |
| توابع سطحی | Σₖ₌₀ⁿ (-1)ᵏ · C(n،k) · (n−k)ᵐ (با گنجاندن-استخراج) |
| توابع دوطرفه | n! (وقتی m = n) |

## ترکیبیات
ترکیب شناسی ریاضیات شمارش، ترتیب و انتخاب است.
### اصول اساسی شمارش
| اصل | بیانیه | مثال |
|-----------|-----------|---------|
| قانون جمع | اگر A و B متفرق باشند، |A ∪ B| = |A| + |B| | انتخاب میوه: 3 سیب + 4 پرتقال = 7 گزینه |
| قانون محصول | |A × B| = |A| · |ب| | لباس: 3 پیراهن × 4 شلوار = 12 لباس |
| قانون بیجکشن | اگر f: A → B یک انحراف است، |A| = |B| | شمارش زیر مجموعه ها با شمارش رشته های باینری |
| مکمل | |الف| = |U| − |عَل| | شمارش "حداقل یک" به عنوان کل منهای "هیچ" |
### جایگشت و ترکیب
| علامت گذاری | نام | فرمول | معنی |
|----------|------|---------|---------|
| C(n، k) یا (n k) | ضریب دو جمله ای | n! / (k!(n−k)!) | راه های انتخاب k مورد از n (ترتیب مهم نیست) |
| P(n، k) | k جایگشت های n | n! / (n−k)! | راه های چیدمان k آیتم از n ( نظم مهم است ) |
| n! | فاکتوریل | n × (n−1) × ... × 1 | راه های چیدمان همه n آیتم |
| (n k) با تکرار | چند انتخابی | C(n+k−1، k) | k را از n با تکرار مجاز انتخاب کنید |
**قضیه دو جمله ای:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**هویت پاسکال:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### اصل کبوتر
**شکل اصلی:** اگر n+1 شی در n کادر قرار داده شود، حداقل یک جعبه حاوی ≥ 2 شی است.
**شکل کلی:** اگر N شی در کادرهای k قرار داده شود، حداقل یک جعبه حاوی ≥ ⌈N/k⌉ شی است.
**نمونه های کار شده:**
1. از هر 13 نفر، حداقل 2 نفر در ماه تولد مشترک هستند. (13 نفر، 12 ماه → کبوتر.)
2. نشان دهید که در بین هر 5 عدد صحیح، 3 وجود دارد که مجموع آنها بر 3 بخش پذیر است.
   - مود 3 باقی مانده را در نظر بگیرید: {0، 1، 2}. با 5 عدد صحیح و 3 کلاس باقیمانده، توسط کبوترچاله تعمیم یافته، حداقل ⌈5/3⌉ = 2 یک باقیمانده را به اشتراک می گذارند.
   - اگر 3 یک باقیمانده r را به اشتراک بگذارند: مجموع آنها ≡ 3r ≡ 0 (mod 3).
   - اگر 2 باقیمانده 0 و 2 باقیمانده 1 را به اشتراک می گذارند: یکی از هر جفت را به اضافه یک عنصر باقی مانده-0 انتخاب کنید → مجموع ≡ 0 (mod 3).
3. **کاربرد در CS:** هر الگوریتم فشرده سازی بدون تلفات باید برخی از ورودی ها را گسترش دهد. (اگر هر رشته n بیتی به < n بیت فشرده شود، 2ⁿ رشته را به کمتر از 2ⁿ رشته فشرده نگاشت می کنید - که تزریق را نقض می کند.)
### اعداد کاتالان
nامین **عدد کاتالانی** Cₙ = C(2n, n) / (n+1) شمارش می کند:
| ساختار | مثال |
|-----------|---------|
| توالی پرانتز معتبر | ()()، (()) برای n = 2 |
| درختان باینری با n گره داخلی | 2 درخت برای n = 2 |
| مسیرهایی که از مورب عبور نمی کنند | مسیرهای شبکه از (0,0) تا (n,n) زیر y = x |
| مثلث های یک چند ضلعی | روش های تقسیم ضلع (n+2) به مثلث |
چند اول: C₀ = 1، C1 = 1، C2 = 2، C3 = 5، C4 = 14، C5 = 42.
عود: Cₙ₊1 = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## روابط عود
یک **رابطه عود** هر جمله از یک دنباله را به عنوان تابعی از عبارت های قبلی تعریف می کند.
### انواع و راه حل ها
| نوع | فرم | روش حل |
|------|------|-----------------|
| همگن خطی (ضریب ثابت.) | aₙ = c₁aₙ₋1 + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ | معادله مشخصه |
| خطی ناهمگن | aₙ = c1aₙ₋1 + ... + f(n) | محلول خاص + محلول همگن |
| تفرقه بیانداز و غلبه کن | T(n) = aT(n/b) + f(n) | قضیه استاد |
### روش معادله مشخصه
برای aₙ = c1aₙ₋1 + c2aₙ₋2، معادله مشخصه را تشکیل دهید:
r² - c1r - c2 = 0
| مورد | ریشه ها | راه حل عمومی |
|------|-------|------------------|
| دو ریشه واقعی مجزا r1، r2 | r1 ≠ r2 | aₙ = A·r1ⁿ + B·r2ⁿ |
| ریشه تکراری r | r1 = r2 = r | aₙ = (A + Bn)·rⁿ |
| ریشه های پیچیده α ± βi | تبدیل به قطبی: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**مثال کار شده:** دنباله فیبوناچی Fₙ = Fₙ₋1 + Fₙ₋2، F₀ = 0، F1 = 1.
- معادله مشخصه: r² − r − 1 = 0
- ریشه ها: r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618، ψ = (1−√5)/2 ≈ −0.618
- راه حل کلی: Fₙ = A·φⁿ + B·ψⁿ
- از شرایط اولیه: A = 1/√5، B = −1/√5
- **شکل بسته:** Fₙ = (φⁿ − ψⁿ) / √5 (فرمول بینه)
### قضیه استاد
برای تکرارهای شکل T(n) = aT(n/b) + f(n) که a ≥ 1، b > 1:
فرض کنید c = log_b(a).
| مورد | وضعیت | راه حل |
|------|-----------|----------|
| 1 | f(n) = O(nᵈ) که در آن d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c، و af(n/b) ≤ kf(n) برای برخی k <1 | T(n) = Θ(nᵈ) |
**مثال:**
- مرتب سازی ادغام: T(n) = 2T(n/2) + O(n). در اینجا a=2، b=2، c=1، f(n)=n=Θ(n¹). مورد 2: T(n) = Θ(n log n).
- جستجوی باینری: T(n) = T(n/2) + O(1). در اینجا a=1، b=2، c=0، f(n)=1=Θ(n⁰). مورد 2: T(n) = Θ(log n).

## توابع تولید
یک **تابع تولید** یک دنباله (aₙ) را به عنوان ضرایب یک سری توان رسمی کد می کند.
### انواع
| نوع | فرم | مورد استفاده |
|------|------|----------|
| معمولی (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ | ساختارها، ترکیبات بدون برچسب |
| نمایی (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n! | ساختارهای برچسب دار، جایگشت |
### توابع تولید کننده رایج
| دنباله aₙ | OGF G(x) |
|-------------|-----------|
| 1، 1، 1، 1، ... | 1/(1−x) |
| 1، 2، 3، 4، ... | 1/(1−x)² |
| 1, r, r², r³, ... | 1/(1−rx) |
| C(n,k) برای k ثابت | xᵏ/(1−x)ᵏ⁺¹ |
| فیبوناچی Fₙ | x/(1−x−x²) |
| کاتالان Cₙ | (1 − √(1−4x)) / (2x) |
### استفاده از توابع تولید برای حل تکرارها
**مثال کار شده:** حل aₙ = 3aₙ₋1 − 2aₙ₋2، a₀ = 1، a1 = 3.
1. اجازه دهید G(x) = Σ aₙxⁿ.
2. از عود: G(x) - a0 - a1x = 3x(G(x) - a₀) - 2x2G(x)
3. جایگزین: G(x) - 1 - 3x = 3x(G(x) - 1) - 2x²G(x)
4. G(x)(1 - 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x) (1−2x))
6. کسر جزئی: G(x) = 2/(1-2x) - 1/(1-x)
7. ضرایب استخراج: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺1 − 1
**تأیید:** a₀ = 2-1 = 1، a1 = 4-1 = 3، a2 = 8-1 = 7. بررسی: 3(3) - 2(1) = 7.

## جبر بولی و منطق گزاره ای
جبر بولی جبر دو مقدار صدق است: **درست (1)** و **نادرست (0)**. این پایه ریاضی مدارهای دیجیتال، پرس و جوهای پایگاه داده و شرط های برنامه نویسی است.
### عملیات و قوانین
| عملیات | نماد | معنی | جدول حقیقت |
|-----------|--------|---------|-------------|
| و | p ∧ q | درست زمانی که هر دو درست باشند | T∧T=T، T∧F=F، F∧T=F، F∧F=F |
| یا | p ∨ q | درست زمانی که حداقل یکی درست باشد | T∨T=T، T∨F=T، F∨T=T، F∨F=F |
| نه | ¬p | نفی | ¬T=F، ¬F=T |
| XOR | p ⊕ q | درست زمانی که دقیقا یکی درست است | T⊕T=F، T⊕F=T، F⊕T=T، F⊕F=F |
| دلالت دارد | p → q | نادرست فقط زمانی که p=T و q=F | T→T=T، T→F=F، F→T=T، F→F=T |
| دو شرطی | p ↔ q | درست زمانی که هر دو دارای یک مقدار | T↔T=T، T↔F=F، F↔T=F، F↔F=T |
### هویت های بولی کلیدی
| قانون | فرمول |
|-----|--------|
| جابجایی | p ∧ q = q ∧ p; p ∨ q = q ∨ p |
| انجمنی | (p ∧ q) ∧ r = p ∧ (q ∧ r) |
| توزیع | p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
| قوانین دی مورگان | ¬(p ∧ q) = ¬p ∨ ¬q; ¬(p ∨ q) = ¬p ∧ ¬q |
| نفی مضاعف | ¬(¬p) = p |
| ناتوانی | p ∧ p = p; p ∨ p = p |
| جذب | p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
| مخالف | (p → q) ≡ (¬q → ¬p) |
### فرم های عادی
| فرم | ساختار | مورد استفاده |
|------|-----------|----------|
| فرم طبیعی ربطی (CNF) | و از ORها: (A∨B) ∧ (C∨D) | حل کننده های SAT، اثبات قضیه وضوح |
| فرم عادی جدایی (DNF) | یا از ANDها: (A∧B) ∨ (C∧D) | طراحی مدار، سیستم های مبتنی بر قانون |
**تبدیل به CNF:** قوانین دی مورگان را اعمال کنید، OR را روی AND توزیع کنید، نفی مضاعف را حذف کنید.

## محاسبات مدولار و همخوانی ها
حساب مدولار اعداد صحیح را تحت عمل "باقی مانده پس از تقسیم" مطالعه می کند. برای رمزنگاری، هش کردن و تئوری اعداد ضروری است.
### تعاریف اصلی
| مفهوم | علامت گذاری | تعریف |
|---------|----------|------------|
| همخوانی | a ≡ b (mod n) | n (a − b) |
| کلاس باقیمانده | [a]ₙ | مجموعه {a + kn : k ∈ ℤ} |
| معکوس مدولار | a⁻¹ mod n | مقدار x به طوری که ax ≡ 1 (mod n) |
| اویلر totient | φ(n) | تعداد اعداد صحیح در {1,...,n} به n |
### ویژگی های کلیدی
| اموال | بیانیه |
|----------|----------|
| اضافه | اگر a ≡ b و c ≡ d (mod n)، آنگاه a+c ≡ b+d (mod n) |
| ضرب | اگر a ≡ b و c ≡ d (mod n)، سپس ac ≡ bd (mod n) |
| قضیه کوچک فرما | اگر p اول باشد و gcd(a,p) = 1، آنگاه aᵖ-1 ≡ 1 (mod p) |
| قضیه اویلر | اگر gcd(a,n) = 1، آنگاه a^φ(n) ≡ 1 (mod n) |
| قضیه باقیمانده چینی | اگر gcd(m,n) = 1، سیستم x ≡ a (mod m)، x ≡ b (mod n) راه حل منحصر به فردی دارد mod mn |
### محاسبه Totient اویلر
برای n = p1^a1 · p2^a2 · ... · pₖ^a2 (فاکتورسازی اول):
φ(n) = n · (1 - 1/p1) · (1 - 1/p2) · ... · (1 - 1/p2)
**مثال:** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4. در واقع، {1، 5، 7، 11} اولی به 12 هستند.
### کاربرد: رمزنگاری RSA (نمای کلی)
1. اعداد اول بزرگ p، q را انتخاب کنید. n = pq، φ(n) = (p-1) (q-1) را محاسبه کنید.
2. e را طوری انتخاب کنید که gcd(e, φ(n)) = 1 (نمای عمومی).
3. d ≡ e-1 (mod φ(n)) (نمای خصوصی) را محاسبه کنید.
4. رمزگذاری: c = mᵉ mod n. رمزگشایی: m = cᵈ mod n.
5. امنیت بر دشواری فاکتورگیری n برای یافتن p و q متکی است.

## استقراء ریاضی
**استقراء ریاضی** تکنیک اثبات اولیه برای عبارات مربوط به همه اعداد طبیعی است.
### ساختار یک اثبات با استقرا
1. **مورد پایه:** عبارت n = 0 (یا n = 1) را ثابت کنید.
2. **مرحله استقرایی:** فرض کنید عبارت برای n = k (فرضیه استقرایی) برقرار است، سپس آن را برای n = k + 1 ثابت کنید.
### انواع
| نوع | زمان استفاده |
|---------|-------------|
| القایی ساده | P(k) → P(k+1) |
| القایی قوی | P(0)، P(1)، ...، P(k) را برای اثبات P(k+1) |
| القای سازه | اثبات خواص ساختارهای تعریف شده بازگشتی (درخت، فرمول) |
| القایی گذرا | القایی را به مجموعه‌های منظم فراتر از ℕ | گسترش دهید
**مثال کار شده (استقرا قوی):** ثابت کنید هر عدد صحیح n ≥ 2 را می توان به عنوان حاصل ضرب اعداد اول نوشت.
- مبنا: n = 2 اول است، پس حاصل ضرب اعداد اول (خود) است.
- گام استقرایی: برای همه اعداد صحیح از 2 تا k درست فرض کنید. k+1 را در نظر بگیرید.
  - اگر k+1 اول باشد، انجام شد.
  - اگر k+1 مرکب باشد، k+1 = ab که 2 ≤ a، b ≤ k. بر اساس فرضیه استقرایی، a و b هر دو حاصل ضرب اعداد اول هستند، بنابراین k+1 حاصلضرب اعداد اول است.
