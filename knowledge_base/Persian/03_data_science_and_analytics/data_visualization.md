# تجسم داده ها
یک نمودار خوب طراحی شده می تواند الگوهایی را که جداول اعداد پنهان می کنند را نشان دهد. یک طراحی ضعیف می تواند گمراه کند، گیج کند یا خسته کند. تجسم داده ها هنر تبدیل داده ها به داستان های بصری است که تصمیمات را تعیین می کند. این فایل شامل انتخاب نمودار، اصول طراحی، اشتباهات رایج و ابزارهایی است که همه آن را ممکن می سازد.
---

## انتخاب نمودار مناسب
مهمترین تصمیم در هر تصویرسازی، انتخاب نوع نمودار مناسب برای داده ها و پیام شماست.
### راهنمای انتخاب نمودار
| هدف شما | بهترین انواع نمودار |
|-----------|-----------------|
| **مقایسه دسته ها** | نمودار میله ای، نمودار میله ای گروه بندی شده |
| **نمایش تغییر در طول زمان** | نمودار خطی، نمودار مساحتی |
| **نمایش توزیع** | هیستوگرام، طرح جعبه، طرح ویولن |
| **نمایش رابطه** | نمودار پراکندگی، نمودار حباب |
| **نمایش ترکیب** | میله پشته‌ای، نمودار دایره‌ای (برش‌های محدود)، نقشه درختی |
| **نمایش همبستگی** | نمودار پراکندگی، نقشه حرارتی، طرح زوجی |
| **نمایش رتبه** | نمودار میله ای افقی |
| **نمایش الگوهای جغرافیایی** | نقشه کوروپلت، نقشه نقطه |
| **نمایش قسمت به کل در طول زمان** | نمودار مساحت انباشته |
### چه زمانی از هر نمودار استفاده کنیم
| نمودار | نقاط قوت | اجتناب از وقتی |
|-------|-----------|-----------|
| **بار** | پاک کردن مقایسه بین دسته ها | دسته بندی های بسیار زیاد (> 15) |
| **خط** | روند در طول زمان؛ داده های پیوسته | داده ها متوالی نیستند |
| **پراکنده** | روابط بین دو متغیر | نقاط همپوشانی بیش از حد |
| **هیستوگرام** | شکل توزیع یک متغیر | اندازه های نمونه کوچک (<20) |
| **Box plot** | Summary statistics + outliers; compare distributions | Audience unfamiliar with them |
| **Heatmap** | Correlation matrices; patterns in 2D data | Too many variables |
| **Pie chart** | Simple composition (2–5 slices) | More than 5 slices; precise comparisons needed |
| **Violin plot** | Distribution density + quartiles | Small audiences unfamiliar with them |
| **Pair plot** | Quick overview of all variable relationships | Many variables (>8) |

## اصول طراحی
### ایده های اصلی توفت
اصول ادوارد توفت استاندارد طلایی برای تجسم داده ها باقی مانده است:
| اصل | توضیحات |
|-----------|-------------|
| **به حداکثر رساندن نسبت داده به جوهر ** | هر قطره جوهر باید داده را منتقل کند. همه چیزهای دیگر را حذف کنید. |
| **حذف چارتجونک** | بدون جلوه های سه بعدی، شیب های بی رویه، یا عناصر تزئینی. |
| **نمایش داده ها** | تحریف، پنهان یا گیلاس چینی نکنید. بگذارید داده ها صحبت کنند. |
| **ضرب های کوچک** | از نمودارهای کوچک مکرر برای مقایسه در بین دسته ها استفاده کنید. |
| **خطوط جرقه** | نمودارهای کوچک و به اندازه کلمه برای داده های روند درون خطی. |
### قوانین طراحی عملی
| قانون | چرا |
|------|-----|
| **محور y را از صفر شروع کنید** (برای نمودارهای میله ای) | در غیر این صورت تفاوت ها را اغراق می کنید |
| **لیبل مستقیم** | به جای استفاده از افسانه در صورت امکان، برچسب‌ها را روی خطوط/نوارها قرار دهید
| **استفاده هدفمند از رنگ** | برجسته کردن آنچه مهم است؛ استفاده از خاکستری برای متن |
| **ساده باشید** | یک پیام در هر نمودار؛ اضافه بار نکنید |
| **از ترازوهای ثابت استفاده کنید** | هنگام مقایسه نمودارها، محورها را ثابت نگه دارید |
| **معنی دار سفارش دهید** | مرتب سازی میله ها بر اساس مقدار (نه بر اساس حروف الفبا) مگر اینکه یک ترتیب طبیعی وجود داشته باشد |
| **ارائه زمینه** | معیارها، اهداف یا میانگین های تاریخی را اضافه کنید |
### دستورالعمل های رنگ
| مورد استفاده | رویکرد |
|----------|----------|
| **مقوله** | رنگ های متمایز (آبی، نارنجی، سبز، قرمز) - حداکثر 7-8 دسته |
| **توالی** | روشن تا تیره یک رنگ (آبی روشن → آبی تیره) |
| **واگرا ** | گرادیان دو رنگ برای داده ها با نقطه میانی معنی دار (قرمز ← سفید → آبی) |
| **دسترسی** | تست با شبیه سازهای کوررنگ. تنها به رنگ تکیه نکنید (برچسب ها یا الگوها را اضافه کنید) |

## داستان سرایی با داده
نمودار بدون روایت فقط یک تصویر است. داستان سرایی داده ها را به بینش تبدیل می کند.
### چارچوب داستان سرایی
1. **زمینه**: وضعیت چگونه است؟ مخاطب از قبل چه می داند؟
2. **تعارض**: مشکل، غافلگیری یا تنش در داده ها چیست؟
3. **قطعنامه**: مخاطب با این بینش چه باید بکند؟
### نکات کاربردی
| نکته | توضیحات |
|-----|-------------|
| **با بصیرت رهبری کنید** | عنوان نمودار را با غذای آماده انتخاب کنید، نه داده ها ("درآمد 30٪ رشد کرد" نه "درآمد بر اساس سه ماهه") |
| **نکته های کلیدی را حاشیه نویسی کنید** | برای رویدادهای مهم یا نقاط عطف پیام های متنی اضافه کنید |
| **استفاده از افشای تدریجی** | نمایش یک نمودار در یک زمان؛ ساختن داستان گام به گام |
| **آنچه مهم است را برجسته کنید** | از رنگ یا اندازه برای جلب توجه به نقطه داده کلیدی | استفاده کنید
| **یک «پس چی؟» ارائه دهید** | هر نمودار باید به یک سوال پاسخ دهد یا یک عمل را تحریک کند |

## اشتباهات رایج
| اشتباه | چرا بد است | رفع |
|---------|-------------|-----|
| **محور y کوتاه** | تفاوت های کوچک را اغراق می کند | برای نمودارهای میله ای از صفر شروع کنید |
| **محدوده زمانی چیدن گیلاس** | گمراه کننده در مورد روندها | نمایش محدوده کامل موجود |
| **رنگ های خیلی زیاد** | بیننده را غرق می کند | محدود به 5-7؛ استفاده از خاکستری برای متن |
| **محورهای دوگانه y** | دلالت بر همبستگی دارد که ممکن است وجود نداشته باشد | استفاده از دو نمودار مجزا |
| **نمودارهای سه بعدی** | نسبت ها را مخدوش می کند | همیشه از 2D | استفاده کنید
| **نمودار دایره ای با 10+ برش** | مقایسه غیر ممکن | به جای آن از نمودار میله ای استفاده کنید
| **برچسب های گم شده** | بیننده نمی تواند نمودار را درک کند | همیشه محورها، عنوان و واحدها را برچسب بزنید |
| **نمودار مناطق گمراه کننده** | مناطق انباشته ادراک سریال های فردی را تحریف می کند | از نمودارهای خطی یا مضرب کوچک | استفاده کنید

## طراحی داشبورد
داشبورد مجموعه‌ای از تجسم‌ها است که با هم داستان کاملی را در مورد یک فرآیند، سیستم یا کسب‌وکار بیان می‌کنند.
### انواع داشبورد
| نوع | مخاطب | هدف |
|------|----------|---------|
| **راهبردی** | مدیران اجرایی | KPIهای سطح بالا؛ روندهای بلند مدت |
| **عملیاتی** | مدیران | نظارت در زمان واقعی؛ عملیات روزانه |
| **تحلیلی** | تحلیلگران | کاوش عمیق؛ فیلتر کردن، دریل کردن |
### چک لیست طراحی
- **مخاطبان خود را بشناسید**: آنها از این داشبورد چه تصمیمی خواهند گرفت؟
- **قانون 5 ثانیه**: آیا می توان غذای اصلی را در 5 ثانیه فهمید؟
- **طراحی**: مهمترین معیارها در بالا سمت چپ (جایی که چشم ها اول می روند).
- ** محدود کردن انواع نمودار **: حداکثر 3 تا 4 نوع در هر داشبورد برای سازگاری.
- ** تعاملی به طور پیش فرض **: فیلترها، انتخابگرهای محدوده تاریخ، تمرینات.
- **عملکرد**: داشبوردهایی که بیش از 5 ثانیه طول می کشد تا بارگذاری شوند، استفاده نمی شوند.
- **موبایل**: اگر کاربران در حال حرکت به آن نیاز دارند، طراحی واکنشگرا را در نظر بگیرید.

## خلاصه
تجسم خوب داده در مورد وضوح، صداقت و تأثیر است. نمودار مناسب برای داده های خود را انتخاب کنید. هر چیزی را که پیام را ارائه نمی دهد حذف کنید. از رنگ و حاشیه نویسی برای راهنمایی بیننده استفاده کنید. و همیشه، همیشه اجازه دهید داده ها داستان را بیان کنند - نه برعکس.
