## نقاط عطف اصلی
### ریشه ها (2003–2006)
- **2003**: گروه مهدکودک مادام العمر MIT Media Lab توسعه Scratch را آغاز کرد
- به رهبری میچل رسنیک
- **هدف**: آموزش برنامه نویسی به کودکان از طریق بلوک های بصری
- با الهام از: لوگو (سیمور پاپرت)، لوگوی لگو، اسکویک ایتویز
- نام: "Scratch" - از DJ scratching (ترکیب رسانه ها با هم)
### Scratch 1.0 (2007)
- **2007**: اولین انتشار عمومی
- برنامه نویسی بلوک کشیدن و رها کردن
- پروژه های مبتنی بر Sprite (شخصیت ها، انیمیشن ها)
- صدا، گرافیک، انیمیشن
- ساخته شده در Squeak (Smalltalk)
- **هدف**: سنین 8 تا 16 سال، اما بسیار گسترده تر به کار گرفته شده است
### Scratch 1.4 (2009)
- بهبود رندر گرافیکی
- کتابخانه های جن بیشتر
- پشتیبانی بهتر از صدا
- آخرین نسخه ساخته شده بر روی Squeak
### Scratch 2.0 (2013)
- ** ویرایشگر کامل مبتنی بر وب ** - در مرورگر اجرا می شود
- متغیرهای ابری - به اشتراک گذاری داده ها بین پروژه ها
- کوله پشتی - به اشتراک گذاری sprites / اسکریپت ها بین پروژه ها
- بلوک های سفارشی (مانند توابع)
- ساخته شده در اکشن اسکریپت 3 (فلش)
- ویژگی های انجمن: ریمیکس، اشتراک گذاری، نظر
### Scratch 3.0 (2019)
- **بازنویسی کامل** - HTML5/JavaScript (بدون فلش)
- روی تبلت، تلفن، کروم بوک کار می کند
- **افزونه ها**:
  - خودکار (نقاشی)
  - حسگر ویدیو (دوربین)
  - متن به گفتار
  - ترجمه (ترجمه گوگل)
  - میکرو: بیت (سخت افزار)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- بهبود ویرایشگر صدا
- ویرایشگر رنگ جدید (وکتور + بیت مپ)
- کوله پشتی، متغیرهای ابری حفظ شده است
### Scratch Desktop & Beyond (2020–اکنون)
- **2020**: Scratch Desktop - ویرایشگر آفلاین (بر اساس الکترون)
- ادامه توسعه توسعه
- پسوندهای AI/ML (ایجاد شده توسط انجمن)
- ادغام با محاسبات فیزیکی (میکرو: بیت، آردوینو)

```
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## مفاهیم برنامه نویسی آموزش داده شد
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```
