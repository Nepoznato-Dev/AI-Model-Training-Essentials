# توسعه وب
## توسعه Frontend
### فن آوری های اصلی
#### HTML (زبان نشانه گذاری فرامتن)
- **HTML معنایی**: استفاده از برچسب های معنی دار (`<header>`,`<nav>`,`<main>`,`<article>`,`<section>`, `<aside>`TE , __PROTECTED_5_RO ED,
- **فرم**: انواع ورودی، اعتبارسنجی، برچسب های دسترسی
- **رسانه**: تعبیه تصاویر، ویدئو، صدا
- ** متا تگ ها **: SEO، viewport، رمزگذاری کاراکتر
- **ویژگی های HTML5**: بوم، SVG، ذخیره سازی محلی، موقعیت جغرافیایی، سوکت های وب
#### CSS (برگ‌های سبک آبشاری)
- **مدل جعبه**: محتوا، بالشتک، حاشیه، حاشیه
- **سیستم های چیدمان**:
  - **Flexbox**: طرح‌بندی‌های یک‌بعدی، توجیه محتوا، تراز کردن آیتم‌ها
  - **شبکه**: چیدمان های دو بعدی، قالب شبکه، ناحیه شبکه
  - **موقعیت **: ایستا، نسبی، مطلق، ثابت، چسبنده
- **طراحی پاسخگو**: پرسش های رسانه ای، رویکرد اول موبایل
- **متغیرهای CSS**: ویژگی های سفارشی برای قالب بندی
- ** انیمیشن ها **: انتقال، فریم های کلیدی، تبدیل
- **پیش پردازنده**: Sass، Less (متغیرها، میکسین ها، تودرتو)
#### جاوا اسکریپت
- **دستکاری DOM**: انتخاب، ایجاد، اصلاح عناصر
- **رویدادها**: کلیک کنید، ارسال کنید، صفحه کلید، رویدادهای سفارشی، نمایندگی رویداد
- ویژگی های **ES6+**: عملکردهای پیکان، تخریب ساختار، گسترش/استراحت، ماژول ها، همگام سازی/انتظار
- **API ها**: Fetch، XMLHttpRequest، localStorage، sessionStorage
- **TypeScript**: تایپ استاتیک، رابط ها، ژنریک ها، دکوراتورها
### فریم ورک های فرانت اند مدرن
#### واکنش نشان دهید
- **کامپوننت**: اجزای عملکردی، اجزای کلاس
- **قلاب**: useState، useEffect، useContext، useReducer، قلاب های سفارشی
- ** مدیریت دولتی **: Context API، Redux، Zustand، Recoil
- **مسیریابی**: روتر React (BrowserRouter، Routes، Route، Link)
- **اکوسیستم**: Next.js (SSR، SSG)، ریمیکس، گتسبی
- ** Virtual DOM **: رندر کارآمد از طریق الگوریتم diffing
#### Vue.js
- **گزینه API**: داده ها، روش ها، محاسبه شده، تماشا
- **Composition API**: setup()، ref، reactive، computed
- **دستورالعمل**: v-if، v-for، v-bind، v-on، v-model
- **Vuex/Pinia**: مدیریت دولتی
- **روتر Vue**: مسیریابی سمت مشتری
- **Nuxt.js**: چارچوب رندر سمت سرور
#### زاویه ای
- ** اجزاء **: تزئینات، قالب ها، قلاب چرخه زندگی
- **خدمات**: تزریق وابستگی، الگوی تک تن
- **RxJS**: برنامه نویسی واکنشی، قابل مشاهده
- **مسیریابی**: ماژول روتر، نگهبانان، حل کننده ها
- **فرم**: فرم های الگو محور و واکنشی
- **NgRx**: مدیریت حالت به سبک Redux
### ابزارها و باندلرها را بسازید
- **پک وب**: بسته بندی ماژول ها، تقسیم کد، لودرها، پلاگین ها
- **Vite**: ابزار ساخت سریع با استفاده از ماژول های بومی ES
- ** بسته**: باندلر با پیکربندی صفر
- ** جمع آوری **: بهینه شده برای کتابخانه ها
- **esbuild**: باندلر جاوا اسکریپت بسیار سریع
- **Babel**: ترانسپایلر جاوا اسکریپت برای سازگاری با عقب
- **PostCSS**: پردازش CSS با افزونه ها
### چارچوب ها و کتابخانه های CSS
- **بوت استرپ**: کتابخانه کامپوننت، سیستم شبکه، ابزارهای کمکی

- **Emotion**: CSS-in-JS با نقشه های منبع
## توسعه Backend

#### Node.js
- **زمان اجرا**: جاوا اسکریپت روی سرور (موتور V8)
- **Express.js**: حداقل چارچوب وب، معماری میان افزار
- **NestJS**: معماری الهام گرفته از Angular، TypeScript
- **Fastify **: چارچوب با عملکرد بالا
- **Koa**: Modern Express توسط همان سازندگان
- **مدیریت بسته**: npm، نخ، pnpm
#### پایتون
- **Django**: فریمورک با امکانات کامل، ORM، پنل مدیریت، شامل باتری
- **فلاسک**: میکروفریمورک، اکوسیستم الحاقی
- **FastAPI**: اسناد API مدرن، ناهمگام، خودکار
- ** هرم **: چارچوب انعطاف پذیر و مقیاس پذیر
#### سایر زبان های Backend
- **Ruby on Rails**: کنوانسیون روی پیکربندی، ActiveRecord ORM
- **Java Spring**: چارچوب سازمانی، تزریق وابستگی
- **PHP Laravel**: نحو زیبا، ORM گویا، قالب Blade
- **Go Gin**: عملکرد بالا، حداقل چارچوب
- **Rust Actix**: ایمنی حافظه، عملکرد
- **C# ASP.NET Core**: کراس پلتفرم، ویژگی های سازمانی
### یکپارچه سازی پایگاه داده

- **Prisma**: دسترسی به پایگاه داده ایمن نوع، کلاینت تولید شده خودکار
- **SQLAlchemy**: کیت ابزار Python SQL و ORM
- **ActiveRecord**: Ruby on Rails ORM
- **Hibernate**: Java ORM
- **Entity Framework**: .NET ORM
#### درایورهای پایگاه داده
- **pg**: سرویس گیرنده PostgreSQL برای Node.js
- **mysql2**: مشتری MySQL با وعده
- **pymongo**: درایور MongoDB برای پایتون
- **redis**: مشتری Redis برای چندین زبان
### توسعه API
#### REST API
- **روش های HTTP**: GET، POST، PUT، PATCH، DELETE
- **کدهای وضعیت**: 200، 201، 400، 401، 403، 404، 500
- **نامگذاری منابع**: اسم، جمع، سلسله مراتبی
- **نسخه سازی**: مسیر URL، سرصفحه ها، پارامترهای پرس و جو
- ** احراز هویت **: کلیدهای JWT، OAuth، API
- **مستندات**: OpenAPI/Swagger، Postman
#### GraphQL
- **تعریف طرحواره**: انواع، پرس و جوها، جهش ها، اشتراک ها
- **Resolvers**: واکشی داده در سطح میدان
- ** سرور آپولو **: اجرای سرور GraphQL
- **رله**: مشتری GraphQL فیس بوک
- **مزایا**: بدون واکشی بیش از حد، نقطه پایانی واحد، تایپ قوی
#### gRPC
- ** بافرهای پروتکل **: زبان تعریف رابط
- **HTTP/2**: جریان دوطرفه
- ** موارد استفاده **: ارتباطات میکروسرویس، برنامه های کاربردی بلادرنگ
### احراز هویت و مجوز
- **بر اساس جلسه**: کوکی ها، جلسات سمت سرور
- **مبتنی بر توکن**: JWT (JSON Web Tokens)، بدون تابعیت
- **OAuth 2.0**: چارچوب مجوز، ورود شخص ثالث
- **OpenID Connect **: لایه هویت در OAuth 2.0
- **SAML**: ورود به سیستم واحد سازمانی
- **هش کردن رمز عبور**: bcrypt، argon2، scrypt
- ** احراز هویت چند عاملی **: TOTP، SMS، کدهای ایمیل

## امنیت وب
### آسیب پذیری های رایج (10 OWASP برتر)
- **تزریق **: تزریق SQL، تزریق دستور
- ** احراز هویت شکسته **: ربودن جلسه، پر کردن اعتبار
- ** قرار گرفتن در معرض داده های حساس **: داده های رمزگذاری نشده، رمزنگاری ضعیف
- ** موجودیت های خارجی XML (XXE) **: آسیب پذیری های تجزیه کننده XML
- **دسترسی شکسته**: افزایش امتیاز، دسترسی غیرمجاز
- **پیکربندی اشتباه امنیتی**: اعتبار پیش فرض، خطاهای پرمخاطب
- **اسکریپت بین سایتی (XSS)**: منعکس شده، ذخیره شده، مبتنی بر DOM
- **Deserialization ناامن**: حملات تزریق اشیا
- **استفاده از کامپوننت هایی با آسیب پذیری های شناخته شده **: وابستگی های قدیمی
- ** ثبت و نظارت ناکافی **: رخنه های کشف نشده
### بهترین شیوه های امنیتی
- **HTTPS**: رمزگذاری TLS/SSL، HSTS
- **سیاست امنیتی محتوا (CSP)**: از حملات XSS جلوگیری کنید
- ** اعتبار سنجی ورودی **: ورودی کاربر را پاکسازی کنید
- **Output Encoding**: از حملات تزریق جلوگیری کنید
- **محافظت CSRF**: توکن های ضد CSRF، کوکی های SameSite
- **Rate Limiting**: از حملات brute force جلوگیری کنید
- **سربرگ های امنیتی**: گزینه های X-Frame، X-Content-Type-Options
- **اسکن وابستگی**: ممیزی npm، Snyk، Dependabot
