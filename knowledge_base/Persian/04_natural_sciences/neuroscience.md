#علوم اعصاب
علوم اعصاب مطالعه سیستم عصبی - مغز، نخاع و تمام اعصابی است که آنها را به بدن متصل می کند. این سطوح چندگانه را در بر می گیرد: از مولکول ها و ژن ها، تا نورون ها و سیناپس ها، مدارها و نواحی مغز، تا رفتار، شناخت و آگاهی. مغز پیچیده ترین ساختار در جهان شناخته شده است که شامل تقریباً 86 میلیارد نورون است که توسط تریلیون ها سیناپس به هم متصل شده اند و درک نحوه عملکرد آن یکی از چالش های بزرگ علم است.
---

## نورون
### بخش های یک نورون
| جزء | تابع |
|-----------|----------|
| **دندریت** | دریافت سیگنال از نورون های دیگر. پسوندهای شاخه مانند |
| **بدن سلولی (سوما)** | سیگنال های دریافتی را یکپارچه می کند. حاوی هسته |
| **آکسون** | فیبر بلند که سیگنال های الکتریکی (پتانسیل های عمل) را به دور از سوما ارسال می کند |
| **غلاف میلین** | لایه عایق اطراف آکسون ها افزایش سرعت انتقال سیگنال |
| **گره های رانویر** | شکاف در میلین؛ اجازه هدایت نمکی (پرش سیگنال بین گره ها) |
| **پایانه های آکسون (بوتون های سیناپسی)** | انتشار انتقال دهنده های عصبی به سیناپس |
### انواع نورون ها
| نوع | جهت | تابع |
|------|-----------|----------|
| **حسی (آوران)** | بدن → مغز | انتقال اطلاعات از حواس (لمس، دما، درد، بینایی و غیره) |
| **موتور (وابران)** | مغز → بدن | کنترل عضلات و غدد |
| **اینترنورون** | در CNS | اتصال نورون ها به نورون های دیگر؛ بیشتر نورون ها بین نورون هستند |

## نورون ها چگونه ارتباط برقرار می کنند
### پتانسیل اقدام
| فاز | توضیحات |
|-------|------------|
| **پتانسیل استراحت** | نورون در ~-70 میلی ولت است. پمپ سدیم پتاسیم تعادل یونی را حفظ می کند |
| **دپولاریزاسیون** | محرک کانال های سدیم را باز می کند. Na+ با عجله وارد می شود. افزایش پتانسیل غشا |
| **آستانه** | اگر پتانسیل به ~-55 میلی ولت برسد، یک پتانسیل عمل شلیک می شود (همه یا هیچ) |
| **فاز صعود** | کانال های سدیم دارای ولتاژ باز می شوند. سنبله های بالقوه تا ~40 میلی ولت |
| **فاز سقوط** | کانال های سدیم بسته می شوند. باز شدن کانال های پتاسیم؛ K+ خارج می شود. افت احتمالی |
| **کم شدن (هیپرپولاریزاسیون)** | پتانسیل برای مدت کوتاهی به زیر سطح استراحت کاهش می یابد |
| **دوره نسوز** | نورون نمی تواند بلافاصله دوباره شلیک کند. انتشار یک طرفه را تضمین می کند |
### سیناپس
| جزء | نقش |
|-----------|------|
| **نرون پیش سیناپسی** | سیگنال را ارسال می کند؛ حاوی وزیکول های سیناپسی با انتقال دهنده های عصبی |
| **شکاف سیناپسی** | شکاف کوچک (~20 نانومتر) بین نورون ها |
| **نرون پس سیناپسی** | سیگنال را دریافت می کند؛ دارای پروتئین های گیرنده |
| **انتقال دهنده های عصبی** | پیام رسان های شیمیایی که از سیناپس عبور می کنند |
| **گیرنده** | اتصال دهنده های عصبی باز کردن کانال های یونی یا راه اندازی آبشارهای پیام رسان دوم |

## انتقال دهنده های عصبی کلیدی
| انتقال دهنده عصبی | تابع | شرایط مرتبط |
|----------------------------|---------------------|
| **گلوتامات** | انتقال دهنده عصبی تحریکی اصلی؛ یادگیری؛ حافظه | بیش از حد → سمیت تحریکی (سکته مغزی، تخریب عصبی) |
| **گابا** | انتقال دهنده عصبی مهاری اصلی؛ فعالیت عصبی را کاهش می دهد | کمبود → اضطراب، صرع |
| **دوپامین** | پاداش؛ انگیزه؛ کنترل موتور؛ توجه | کمبود ← پارکینسون؛ بیش از حد → اسکیزوفرنی |
| **سروتونین** | خلق و خوی؛ خواب؛ اشتها؛ هضم | کسری ← افسردگی، اضطراب |
| **استیل کولین** | فعال سازی عضلات؛ یادگیری؛ حافظه | کسری → بیماری آلزایمر |
| **نوراپی نفرین** | برانگیختگی؛ هوشیاری؛ پاسخ استرس | اختلال در تنظیم ← ADHD. افسردگی |
| **اندورفین** | تسکین درد؛ لذت | رهاسازی ناشی از ورزش ("بالا بودن دونده") |

## ساختار مغز
### مناطق اصلی مغز
| منطقه | تابع |
|--------|----------|
| **قشر مغز** | شناخت بالاتر؛ به لوب های فرونتال، جداری، گیجگاهی، پس سری |
| **لوب پیشانی** | برنامه ریزی؛ تصمیم گیری؛ شخصیت؛ حرکت ارادی (قشر حرکتی) |
| **لوب جداری** | پردازش حسی؛ آگاهی فضایی؛ ناوبری |
| **لوب تمپورال** | شنوایی؛ درک زبان؛ حافظه (هیپوکامپ) |
| **لوب اکسیپیتال** | پردازش بصری |
| **مخچه** | هماهنگی حرکتی؛ تعادل؛ یادگیری حرکتی؛ برخی از عملکردهای شناختی |
| **ساقه مغز** | عملکردهای حیاتی: تنفس؛ ضربان قلب؛ چرخه خواب و بیداری |
| **تالاموس** | ایستگاه رله حسی؛ سیگنال ها را به نواحی قشری مناسب هدایت می کند |
| **هیپوتالاموس** | هموستاز؛ تنظیم هورمون؛ گرسنگی؛ تشنگی؛ ریتم های شبانه روزی |
### سیستم لیمبیک
| ساختار | تابع |
|-----------|----------|
| **آمیگدال** | پردازش عاطفی؛ ترس؛ تشخیص تهدید؛ حافظه عاطفی |
| **هیپوکامپ** | تشکیل حافظه؛ ناوبری فضایی؛ تبدیل حافظه کوتاه مدت به بلند مدت |
| ** عقده های قاعده ای** | شکل گیری عادت؛ یادگیری پاداش؛ کنترل موتور |
| **قشر سینگولیت** | تشخیص خطا؛ همدلی؛ کنترل تکانه؛ تنظیم احساسات |
| **هسته اکومبنس** | مدار پاداش؛ لذت؛ اعتیاد |

## عصب شناسی شناختی
### عملکردهای شناختی کلیدی و مناطق مغز آنها
| تابع | نواحی اولیه مغز |
|----------|-------------------|
| **توجه** | قشر جلوی مغز؛ قشر جداری؛ تالاموس |
| **حافظه کاری** | قشر جلوی مغز؛ قشر جداری |
| **حافظه بلند مدت** | هیپوکامپ (تشکیل)؛ کورتکس (ذخیره) |
| **زبان** | منطقه بروکا (تولید)؛ منطقه Wernicke (درک) |
| **تنظیم هیجان** | قشر جلوی مغز؛ آمیگدال; PFC شکمی |
| **تصمیم گیری** | قشر جلوی مغز؛ قشر اوربیتوفرونتال؛ مخطط |
| **پردازش بصری** | لوب اکسیپیتال → جریان شکمی ("چه") و جریان پشتی ("کجا") |
| **کنترل موتور** | قشر حرکتی؛ مخچه; عقده های قاعده ای |
### امواج مغزی
| موج | فرکانس | ایالت وابسته |
|------|-----------|-----------------|
| **دلتا** | 0.5-4 هرتز | خواب عمیق |
| **تتا** | 4-8 هرتز | خواب سبک؛ مدیتیشن؛ خواب آلودگی |
| **آلفا** | 8-13 هرتز | بیداری آرام؛ چشم بسته |
| **بتا** | 13 تا 30 هرتز | تفکر فعال؛ تمرکز؛ هوشیاری |
| **گاما** | 30-100 هرتز | شناخت بالاتر؛ الزام آور آگاهی |

## نوروپلاستیسیته
| نوع | توضیحات | مثال |
|------|-------------|---------|
| ** پلاستیسیته سیناپسی ** | قدرت سیناپس ها با فعالیت تغییر می کند | تقویت طولانی مدت (LTP)؛ افسردگی طولانی مدت (LTD) |
| ** پلاستیسیته سازه** | نورون ها دندریت ها یا آکسون های جدید رشد می کنند | یادگیری مهارت های جدید؛ بهبودی از آسیب |
| **نقشه برداری مجدد قشری** | نواحی مغز عملکردها را تغییر می دهند | قشر بینایی افراد نابینا لمس و صدا را پردازش می کند |
| **عصب زایی** | نورون های جدید متولد می شوند | در هیپوکامپ رخ می دهد. تحریک شده توسط ورزش و یادگیری |

## روش تحقیق
| روش | آنچه را اندازه گیری می کند | وضوح |
|--------|----------------|------------|
| **fMRI** | سطح اکسیژن خون (سیگنال BOLD) → فعالیت مغز | فضایی خوب (~ 1 میلی متر)؛ زمانی ضعیف (~1 ثانیه) |
| **EEG** | فعالیت الکتریکی از پوست سر | زمانی عالی (~1 میلی ثانیه)؛ فضایی ضعیف |
| **MEG** | میدان های مغناطیسی ناشی از فعالیت عصبی | زمانی و مکانی خوب |
| **پت** | ردیاب رادیواکتیو → فعالیت متابولیک | متوسط ​​مکانی و زمانی |
| **TMS** | پالس های مغناطیسی → به طور موقت ناحیه مغز را مختل می کند | شواهد علّی؛ عمق محدود |
| **ضبط تک واحدی** | فعالیت الکتریکی نورون های فردی | تک سلولی؛ تهاجمی؛ تحقیقات بیشتر حیوانی |
| **اپتوژنتیک** | نورون های فعال شده با نور | کنترل دقیق؛ تحقیقات حیوانی |
| **DTI** (تصویربرداری تانسور انتشار) | دستگاه های ماده سفید | نقشه اتصال |

## اختلالات عصبی و روانی
| اختلال | سیستم تحت تاثیر | ویژگی های کلیدی |
|----------|---------------|--------------|
| **آلزایمر** | قشر; هیپوکامپ | از دست دادن حافظه؛ پلاک های آمیلوئید؛ tau tangles |
| **پارکینسون** | ماده سیاه؛ عقده های قاعده ای | لرزش؛ سختی؛ از دست دادن نورون دوپامین |
| **صرع** | قشر مغز | تشنج های مکرر؛ فعالیت الکتریکی غیر طبیعی |
| **مولتیپل اسکلروزیس** | غلاف میلین (CNS) | دمیلیناسیون؛ اختلال در انتقال سیگنال |
| **افسردگی** | قشر جلوی مغز؛ سیستم لیمبیک | خلق و خوی ضعیف مداوم؛ عدم تعادل انتقال دهنده های عصبی |
| **اسکیزوفرنی** | چندین منطقه | توهمات؛ توهمات؛ اختلال در تنظیم دوپامین |
| **ALS** | نورون های حرکتی | ضعف عضلانی پیشرونده؛ مرگ نورون حرکتی |

## خلاصه
علوم اعصاب سیستم عصبی را در هر سطحی مطالعه می کند - از مکانیسم های مولکولی کانال های یونی گرفته تا تجربه ذهنی آگاهی. نورون ها از طریق پتانسیل های عمل الکتریکی و سیناپس های شیمیایی با استفاده از انتقال دهنده های عصبی مانند گلوتامات، گابا، دوپامین و سروتونین ارتباط برقرار می کنند. مغز در مناطق تخصصی سازماندهی شده است: قشر برای شناخت بالاتر، سیستم لیمبیک برای احساسات و حافظه، مخچه برای هماهنگی. نوروپلاستیسیته به این معنی است که مغز می تواند در طول زندگی خود را دوباره سیم کشی کند. روش‌های تحقیق از fMRI (رزولوشن فضایی خوب) تا EEG (تفکیک زمانی خوب) تا اپتوژنتیک (کنترل علّی دقیق) را شامل می‌شود. درک مغز بدون شک سخت ترین مشکل در علم است – این تنها اندامی است که خودش را مطالعه می کند.
