# Scratch — Version History & Evolution

## Timeline

| Version | Year | Key Theme |
|---------|------|-----------|
| Pre-Scratch | 2003 | Scratch Team forms at MIT Media Lab |
| Scratch 1.0 | 2007 | **Initial release** — visual programming for kids |
| Scratch 1.4 | 2009 | Improved graphics, more blocks |
| Scratch 2.0 | 2013 | **Major**: Web-based editor, cloud variables, backpack |
| Scratch 3.0 | 2019 | **Major**: Complete rewrite (HTML5/JS), extensions, pen |
| Scratch 3.x | 2019–25 | Video sensing, text-to-speech, translate, micro:bit |
| Scratch Jr. | 2014 | Simplified version for younger children (5-7) |
| Scratch Desktop | 2020 | Offline editor (Electron-based) |

## Major Milestones

### Origins (2003–2006)
- **2003**: MIT Media Lab's Lifelong Kindergarten group begins Scratch development
- Led by Mitchel Resnick
- **Goal**: Teach programming to children through visual blocks
- Inspired by: Logo (Seymour Papert), Lego Logo, Squeak Etoys
- Name: "Scratch" — from DJ scratching (mixing media together)

### Scratch 1.0 (2007)
- **2007**: First public release
- Drag-and-drop block programming
- Sprite-based projects (characters, animations)
- Sound, graphics, animation
- Built in Squeak (Smalltalk)
- **Target**: Ages 8-16, but adopted much wider

### Scratch 1.4 (2009)
- Improved graphics rendering
- More sprite libraries
- Better sound support
- Last version built on Squeak

### Scratch 2.0 (2013)
- **Complete web-based editor** — runs in browser
- Cloud variables — share data between projects
- Backpack — share sprites/scripts between projects
- Custom blocks (like functions)
- Built in ActionScript 3 (Flash)
- Community features: remix, share, comment

### Scratch 3.0 (2019)
- **Complete rewrite** — HTML5/JavaScript (no Flash)
- Works on tablets, phones, Chromebooks
- **Extensions**:
  - Pen (drawing)
  - Video Sensing (camera)
  - Text to Speech
  - Translate (Google Translate)
  - micro:bit (hardware)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Sound editor improvements
- New paint editor (vector + bitmap)
- Backpack, cloud variables retained

### Scratch Desktop & Beyond (2020–present)
- **2020**: Scratch Desktop — offline editor (Electron-based)
- Continued extension development
- AI/ML extensions (community-created)
- Integration with physical computing (micro:bit, Arduino)

## Block Categories Evolution

```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Programming Concepts Taught

```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Key Design Principles

```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
