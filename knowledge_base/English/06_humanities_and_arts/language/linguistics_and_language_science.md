# Linguistics and Language Science

Linguistics is the scientific study of language — its structure, meaning, use, acquisition, and evolution. Language is a defining feature of human communication: it is infinitely productive (speakers can create and understand sentences they have never encountered before), it is culturally transmitted (it is learned rather than purely innate), and it is continuously evolving. Understanding how language works is relevant to anyone building language technologies, teaching, translating, or working to communicate more effectively.

---

## The Levels of Language

### Overview

| Level | Studies | Unit of Analysis | Example Question |
|-------|---------|-----------------|-----------------|
| **Phonetics** | Physical sounds of speech | Phones (speech sounds) | How is the "p" in "pin" different from "spin"? |
| **Phonology** | Sound systems and patterns | Phonemes (contrastive sounds) | Why can English words start with "str" but not "ztr"? |
| **Morphology** | Structure of words | Morphemes (smallest meaning units) | How does "unhappiness" break down? |
| **Syntax** | Structure of sentences | Phrases; clauses | Why is "colourless green ideas sleep furiously" grammatical but nonsensical? |
| **Semantics** | Meaning | Words; sentences; propositions | What's the difference between "big" and "large"? |
| **Pragmatics** | Meaning in context | Speech acts; implicature | What does "can you pass the salt?" actually mean? |

## Phonetics and Phonology

### The International Phonetic Alphabet (IPA)

| Category | Symbols | Examples |
|----------|---------|---------|
| **Plosives** | p, b, t, d, k, g | "pat", "bat", "cat", "got" |
| **Fricatives** | f, v, θ, ð, s, z, ʃ, ʼ, h | "fat", "vat", "thin", "then", "sip", "zip" |
| **Nasals** | m, n, Å‹ | "mat", "nat", "sing" |
| **Approximants** | l, r, w, j | "let", "red", "wet", "yet" |
| **Affricates** | tʃ, dʼ | "church", "judge" |

### Key Phonological Concepts

| Concept | Description | Example |
|---------|-------------|---------|
| **Minimal pairs** | Two words differing in one phoneme that changes meaning | "pat" vs "bat" (p/b contrast) |
| **Phonotactics** | Rules about which sound combinations are allowed | English doesn't allow word-initial /Å‹/ |
| **Stress** | Emphasis on certain syllables | "REcord" (noun) vs "reCORD" (verb) |
| **Intonation** | Pitch patterns across utterances | Rising intonation = question in English |
| **Assimilation** | Sounds become more like neighbouring sounds | "handbag" often pronounced "hambag" |

## Morphology

### Types of Morphemes

| Type | Description | Example |
|------|-------------|---------|
| **Free morpheme** | Can stand alone as a word | "cat"; "run"; "happy" |
| **Bound morpheme** | Must attach to another morpheme | "-s" (plural); "-ed" (past tense); "un-" (negation) |
| **Derivational** | Creates a new word; may change part of speech | "happy" → "happiness" (adjective → noun) |
| **Inflectional** | Modifies a word's grammatical form; doesn't change part of speech | "walk" → "walked" (present → past) |

### Word Formation Processes

| Process | Description | Example |
|---------|-------------|---------|
| **Compounding** | Combining two free morphemes | "sunflower"; "toothbrush" |
| **Derivation** | Adding affixes | "teach" → "teacher" |
| **Clipping** | Shortening a word | "laboratory" → "lab" |
| **Blending** | Combining parts of two words | "smoke" + "fog" = "smog" |
| **Acronym** | Using initial letters | NASA; laser; scuba |
| **Borrowing** | Taking words from other languages | "sushi" (Japanese); "café" (French) |
| **Coinage** | Inventing a new word | "Google" (verb); "quark" |

## Syntax

### Phrase Structure

| Phrase | Head | Example |
|--------|------|---------|
| **Noun Phrase (NP)** | Noun | "the big red ball" |
| **Verb Phrase (VP)** | Verb | "ate the cake quickly" |
| **Prepositional Phrase (PP)** | Preposition | "in the garden" |
| **Adjective Phrase (AP)** | Adjective | "very happy about the result" |
| **Determiner Phrase (DP)** | Determiner | "the"; "my three favourite" |

### Syntactic Concepts

| Concept | Description | Example |
|---------|-------------|---------|
| **Constituency** | Words group into hierarchical units (constituents) | "the old man" is a constituent; "old man the" is not |
| **Recursion** | Phrases can contain phrases of the same type | "The cat that the dog that the rat bit chased ran away" |
| **Ambiguity** | A sentence with multiple structural interpretations | "I saw the man with the telescope" (who has the telescope?) |
| **Movement** | Elements can move from their base position | "What did you eat ___?" (what moved from object position) |
| **Agreement** | Words must match in features (number, person, gender) | "She runs" (not "She run") |

## Semantics

### Semantic Relations

| Relation | Description | Example |
|----------|-------------|---------|
| **Synonymy** | Same or similar meaning | "big" ≈ "large" |
| **Antonymy** | Opposite meaning | "hot" ↔ "cold" |
| **Hyponymy** | Specific → general | "rose" is a hyponym of "flower" |
| **Hypernymy** | General → specific | "fruit" is a hypernym of "apple" |
| **Meronymy** | Part → whole | "wheel" is a meronym of "car" |
| **Polysemy** | One word with multiple related meanings | "head" (body part; leader; top of something) |
| **Homonymy** | Same form; unrelated meanings | "bank" (river); "bank" (financial institution) |

### Compositional Semantics

| Concept | Description |
|---------|-------------|
| **Principle of compositionality** | The meaning of a complex expression is determined by its parts and how they're combined |
| **Thematic roles** | Agent (doer); Patient (affected); Instrument (tool); Goal; Source; Location |
| **Entailment** | If A is true, B must be true: "She murdered him" entails "He is dead" |
| **Presupposition** | Background assumption: "The king of France is bald" presupposes there is a king of France |

## Pragmatics

### Key Concepts

| Concept | Description | Example |
|---------|-------------|---------|
| **Speech acts** | Utterances perform actions: asserting; requesting; promising; apologising | "I apologise" = the act of apologising |
| **Implicature** | Meaning implied but not stated | "Some students passed" implicates "not all passed" |
| **Grice's Maxims** | Quality (be truthful); Quantity (be informative enough, not too much); Relation (be relevant); Manner (be clear) | Violating maxims creates implicatures |
| **Deixis** | Words whose reference depends on context | "here"; "now"; "this"; "she" |
| **Politeness** | Face-threatening acts mitigated by indirectness | "Could you possibly..." vs "Do this" |
| **Common ground** | Shared knowledge between speakers | "The usual" works only with shared context |

## Language Acquisition

### First Language Acquisition

| Stage | Age | Characteristics |
|-------|-----|-----------------|
| **Babbling** | 6–12 months | Repetitive syllables: "bababa"; "dadada" |
| **One-word (holophrastic)** | 12–18 months | Single words convey whole messages: "milk!" = "I want milk" |
| **Two-word** | 18–24 months | Simple combinations: "more milk"; "daddy go" |
| **Telegraphic** | 24–30 months | Multi-word but missing function words: "me want cookie" |
| **Later stages** | 3–5 years | Grammar develops; overregularisation ("goed"); vocabulary explosion |

### Key Debates

| Debate | Positions |
|--------|-----------|
| **Nature vs nurture** | Chomsky: innate Universal Grammar. Usage-based: language emerges from general cognitive abilities and input |
| **Critical period** | Lenneberg: language must be acquired before puberty. Evidence: feral children; late L2 learners |
| **Modularity** | Is language a separate module or does it use general cognition? |

## Summary

Linguistics studies language at multiple levels: phonetics (sounds), phonology (sound systems), morphology (word structure), syntax (sentence structure), semantics (meaning), and pragmatics (meaning in context). Language is infinitely productive — we can create and understand sentences we've never heard. Words are built from morphemes; sentences from hierarchical phrase structures. Meaning is compositional but also depends on context, implicature, and shared knowledge. Language acquisition begins with babbling and progresses through one-word and two-word stages, with the nature-nurture debate still unresolved. The world's ~7,000 languages belong to families (Indo-European, Sino-Tibetan, Niger-Congo) that reflect human migration and cultural history. For anyone working with language technology, understanding these fundamentals — how sounds map to meaning, how syntax works, how context shapes interpretation — is essential background that pure statistical models can't replace.
