# Neuroscience

Neuroscience is the study of the nervous system — the brain, spinal cord, and all the nerves that connect them to the body. It spans multiple levels: from molecules and genes, to individual neurons and synapses, to circuits and brain regions, to behaviour, cognition, and consciousness. The brain is the most complex structure in the known universe, containing roughly 86 billion neurons connected by trillions of synapses, and understanding how it works is one of the great challenges of science.

---

## The Neuron

### Parts of a Neuron

| Component | Function |
|-----------|----------|
| **Dendrites** | Receive signals from other neurons; branch-like extensions |
| **Cell body (soma)** | Integrates incoming signals; contains the nucleus |
| **Axon** | Long fibre that transmits electrical signals (action potentials) away from the soma |
| **Myelin sheath** | Insulating layer around axons; speeds up signal transmission |
| **Nodes of Ranvier** | Gaps in myelin; allow saltatory conduction (signal jumps between nodes) |
| **Axon terminals (synaptic boutons)** | Release neurotransmitters into the synapse |

### Types of Neurons

| Type | Direction | Function |
|------|-----------|----------|
| **Sensory (afferent)** | Body → brain | Carry information from senses (touch, temperature, pain, vision, etc.) |
| **Motor (efferent)** | Brain → body | Control muscles and glands |
| **Interneurons** | Within CNS | Connect neurons to other neurons; most neurons are interneurons |

---

## How Neurons Communicate

### The Action Potential

| Phase | Description |
|-------|-------------|
| **Resting potential** | Neuron is at ~-70 mV; sodium-potassium pump maintains ion balance |
| **Depolarisation** | Stimulus opens sodium channels; Na+ rushes in; membrane potential rises |
| **Threshold** | If potential reaches ~-55 mV, an action potential fires (all-or-nothing) |
| **Rising phase** | Voltage-gated sodium channels open; potential spikes to ~+40 mV |
| **Falling phase** | Sodium channels close; potassium channels open; K+ flows out; potential drops |
| **Undershoot (hyperpolarisation)** | Potential briefly drops below resting level |
| **Refractory period** | Neuron can't fire again immediately; ensures one-directional propagation |

### The Synapse

| Component | Role |
|-----------|------|
| **Presynaptic neuron** | Sends the signal; contains synaptic vesicles with neurotransmitters |
| **Synaptic cleft** | Tiny gap (~20 nm) between neurons |
| **Postsynaptic neuron** | Receives the signal; has receptor proteins |
| **Neurotransmitters** | Chemical messengers that cross the synapse |
| **Receptors** | Bind neurotransmitters; open ion channels or trigger second messenger cascades |

## Key Neurotransmitters

| Neurotransmitter | Function | Associated Conditions |
|-----------------|----------|----------------------|
| **Glutamate** | Main excitatory neurotransmitter; learning; memory | Excess → excitotoxicity (stroke, neurodegeneration) |
| **GABA** | Main inhibitory neurotransmitter; reduces neural activity | Deficit → anxiety, epilepsy |
| **Dopamine** | Reward; motivation; motor control; attention | Deficit → Parkinson's; excess → schizophrenia |
| **Serotonin** | Mood; sleep; appetite; digestion | Deficit → depression, anxiety |
| **Acetylcholine** | Muscle activation; learning; memory | Deficit → Alzheimer's disease |
| **Norepinephrine** | Arousal; alertness; stress response | Dysregulation → ADHD; depression |
| **Endorphins** | Pain relief; pleasure | Exercise-induced release ("runner's high") |

## Brain Structure

### Major Brain Regions

| Region | Function |
|--------|----------|
| **Cerebral cortex** | Higher cognition; divided into frontal, parietal, temporal, occipital lobes |
| **Frontal lobe** | Planning; decision-making; personality; voluntary movement (motor cortex) |
| **Parietal lobe** | Sensory processing; spatial awareness; navigation |
| **Temporal lobe** | Hearing; language comprehension; memory (hippocampus) |
| **Occipital lobe** | Visual processing |
| **Cerebellum** | Motor coordination; balance; motor learning; some cognitive functions |
| **Brainstem** | Vital functions: breathing; heart rate; sleep-wake cycle |
| **Thalamus** | Sensory relay station; routes signals to appropriate cortical areas |
| **Hypothalamus** | Homeostasis; hormone regulation; hunger; thirst; circadian rhythms |

### The Limbic System

| Structure | Function |
|-----------|----------|
| **Amygdala** | Emotional processing; fear; threat detection; emotional memory |
| **Hippocampus** | Memory formation; spatial navigation; converts short-term to long-term memory |
| **Basal ganglia** | Habit formation; reward learning; motor control |
| **Cingulate cortex** | Error detection; empathy; impulse control; emotion regulation |
| **Nucleus accumbens** | Reward circuit; pleasure; addiction |

## Cognitive Neuroscience

### Key Cognitive Functions and Their Brain Regions

| Function | Primary Brain Areas |
|----------|-------------------|
| **Attention** | Prefrontal cortex; parietal cortex; thalamus |
| **Working memory** | Prefrontal cortex; parietal cortex |
| **Long-term memory** | Hippocampus (formation); cortex (storage) |
| **Language** | Broca's area (production); Wernicke's area (comprehension) |
| **Emotion regulation** | Prefrontal cortex; amygdala; ventromedial PFC |
| **Decision-making** | Prefrontal cortex; orbitofrontal cortex; striatum |
| **Visual processing** | Occipital lobe → ventral stream ("what") and dorsal stream ("where") |
| **Motor control** | Motor cortex; cerebellum; basal ganglia |

### Brain Waves

| Wave | Frequency | Associated State |
|------|-----------|-----------------|
| **Delta** | 0.5–4 Hz | Deep sleep |
| **Theta** | 4–8 Hz | Light sleep; meditation; drowsiness |
| **Alpha** | 8–13 Hz | Relaxed wakefulness; eyes closed |
| **Beta** | 13–30 Hz | Active thinking; focus; alertness |
| **Gamma** | 30–100 Hz | Higher cognition; binding; consciousness |

## Neuroplasticity

| Type | Description | Example |
|------|-------------|---------|
| **Synaptic plasticity** | Strength of synapses changes with activity | Long-term potentiation (LTP); long-term depression (LTD) |
| **Structural plasticity** | Neurons grow new dendrites or axons | Learning new skills; recovery from injury |
| **Cortical remapping** | Brain regions reassign functions | Blind people's visual cortex processes touch and sound |
| **Neurogenesis** | New neurons are born | Occurs in hippocampus; stimulated by exercise and learning |

## Research Methods

| Method | What It Measures | Resolution |
|--------|-----------------|------------|
| **fMRI** | Blood oxygen level (BOLD signal) → brain activity | Good spatial (~1 mm); poor temporal (~1 s) |
| **EEG** | Electrical activity from scalp | Excellent temporal (~1 ms); poor spatial |
| **MEG** | Magnetic fields from neural activity | Good temporal and spatial |
| **PET** | Radioactive tracer → metabolic activity | Moderate spatial and temporal |
| **TMS** | Magnetic pulses → temporarily disrupt brain area | Causal evidence; limited depth |
| **Single-unit recording** | Electrical activity of individual neurons | Single cell; invasive; mostly animal research |
| **Optogenetics** | Light-activated neurons | Precise control; animal research |
| **DTI** (Diffusion Tensor Imaging) | White matter tracts | Connectivity mapping |

## Neurological and Psychiatric Disorders

| Disorder | Affected System | Key Features |
|----------|----------------|--------------|
| **Alzheimer's** | Cortex; hippocampus | Memory loss; amyloid plaques; tau tangles |
| **Parkinson's** | Substantia nigra; basal ganglia | Tremor; rigidity; dopamine neuron loss |
| **Epilepsy** | Cerebral cortex | Recurrent seizures; abnormal electrical activity |
| **Multiple sclerosis** | Myelin sheath (CNS) | Demyelination; disrupted signal transmission |
| **Depression** | Prefrontal cortex; limbic system | Persistent low mood; neurotransmitter imbalance |
| **Schizophrenia** | Multiple regions | Hallucinations; delusions; dopamine dysregulation |
| **ALS** | Motor neurons | Progressive muscle weakness; motor neuron death |

## Summary

Neuroscience studies the nervous system at every level — from the molecular mechanisms of ion channels to the subjective experience of consciousness. Neurons communicate through electrical action potentials and chemical synapses, using neurotransmitters like glutamate, GABA, dopamine, and serotonin. The brain is organised into specialised regions: the cortex for higher cognition, the limbic system for emotion and memory, the cerebellum for coordination. Neuroplasticity means the brain can rewire itself throughout life. Research methods range from fMRI (good spatial resolution) to EEG (good temporal resolution) to optogenetics (precise causal control). Understanding the brain is arguably the hardest problem in science — it's the only organ that studies itself.
