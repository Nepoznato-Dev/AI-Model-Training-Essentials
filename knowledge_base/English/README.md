## 📝 Contributing

When adding or modifying content:

1. **Follow the style guide:**
   - Use `#` for file title only
   - Use `##` for major sections
   - Use `###` for subsections
   - Use `-` for unordered lists
   - Include syntax highlighting in code blocks

2. **Add metadata** (YAML frontmatter):
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Include citations** for factual claims
4. **Add cross-references** to related files
5. **Update this README** if adding new files
