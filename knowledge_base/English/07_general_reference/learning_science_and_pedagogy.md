# Learning Science and Pedagogy

Learning science is the interdisciplinary study of how people learn — drawing from psychology, neuroscience, education, and cognitive science. Pedagogy is the practice and methodology of teaching. Together, they address questions relevant to anyone who teaches, trains, mentors, or designs educational content: What methods help people learn effectively? What common study techniques are inefficient? How should instruction be structured for optimal retention and transfer?

---

## How Learning Works

### The Learning Process

| Stage | Description | Key Factor |
|-------|-------------|------------|
| **Attention** | Information must be noticed to be processed | Novelty; relevance; emotional significance |
| **Encoding** | Information is transformed into a mental representation | Connecting to prior knowledge; elaboration |
| **Consolidation** | Memory traces are stabilised over time | Sleep; spaced repetition; reflection |
| **Storage** | Information is maintained in long-term memory | Meaningful organisation; connections to existing knowledge |
| **Retrieval** | Information is accessed when needed | Practice retrieving; varied contexts |
| **Transfer** | Knowledge is applied to new situations | Varied practice; understanding principles, not just procedures |

### Cognitive Load Theory

| Type | Description | Instructional Implication |
|------|-------------|--------------------------|
| **Intrinsic load** | Difficulty inherent to the material | Manage complexity; sequence from simple to complex |
| **Extraneous load** | Difficulty caused by poor instruction design | Remove unnecessary complexity; clear examples; good formatting |
| **Germane load** | Mental effort devoted to actual learning (schema construction) | Encourage elaboration; self-explanation; meaningful practice |

**Key insight**: working memory is limited (roughly 4±1 items at once). Instruction should minimise extraneous load so cognitive resources are available for learning.

## Evidence-Based Learning Strategies

### Highly Effective Strategies

| Strategy | Description | Why It Works | Evidence Level |
|----------|-------------|-------------|----------------|
| **Retrieval practice** | Actively recalling information from memory | Strengthens memory traces; identifies gaps | Very strong |
| **Spaced practice** | Distributing study sessions over time | Forces reconsolidation; combats forgetting curve | Very strong |
| **Interleaving** | Mixing different types of problems or topics | Improves discrimination; better transfer | Strong |
| **Elaboration** | Explaining how new information relates to what you know | Creates richer memory traces; deeper encoding | Strong |
| **Concrete examples** | Using specific examples to illustrate abstract concepts | Makes abstract ideas tangible; aids understanding | Strong |
| **Dual coding** | Combining words and visuals | Uses both verbal and visual processing channels | Strong |

### Ineffective Strategies (Despite Popularity)

| Strategy | Why It Feels Effective | Why It Actually Isn't |
|----------|----------------------|----------------------|
| **Rereading** | Fluency illusion — text feels familiar | Passive; doesn't strengthen retrieval |
| **Highlighting** | Feels productive; marks important info | Doesn't require deep processing |
| **Summarisation** | Seems like active engagement | Often copied verbatim; doesn't require retrieval |
| **Massed practice (cramming)** | Works for short-term recall | Rapid forgetting; poor transfer |
| **Learning styles** (visual/auditory/kinesthetic) | Intuitively appealing | No evidence that matching instruction to preferred style improves learning |

## The Forgetting Curve and Spaced Repetition

### Ebbinghaus Forgetting Curve

| Time After Learning | Retention (no review) |
|---------------------|----------------------|
| **20 minutes** | ~58% |
| **1 hour** | ~44% |
| **1 day** | ~33% |
| **2 days** | ~28% |
| **6 days** | ~25% |
| **31 days** | ~21% |

### Spaced Repetition Schedule

| Review | Timing | Effect |
|--------|--------|--------|
| **1st review** | 1 day after learning | Boosts retention significantly |
| **2nd review** | 3 days after | Further strengthens memory |
| **3rd review** | 7 days after | Memory becomes more durable |
| **4th review** | 14 days after | Long-term consolidation |
| **5th review** | 30 days after | Stable long-term memory |

Each review pushes the forgetting curve further out. The optimal interval increases with each successful retrieval.

## Bloom's Taxonomy

| Level | Cognitive Process | Action Verbs | Example Task |
|-------|-------------------|-------------|--------------|
| **Remember** | Recall facts and basic concepts | Define; list; name; identify | "List the phases of mitosis" |
| **Understand** | Explain ideas or concepts | Describe; explain; summarise; classify | "Explain why mitosis is important" |
| **Apply** | Use information in new situations | Solve; use; demonstrate; implement | "Predict what happens if mitosis is disrupted" |
| **Analyse** | Draw connections among ideas | Compare; contrast; categorise; examine | "Compare mitosis and meiosis" |
| **Evaluate** | Justify a stand or decision | Judge; critique; defend; argue | "Evaluate the consequences of uncontrolled cell division" |
| **Create** | Produce new or original work | Design; construct; develop; formulate | "Design an experiment to test the effect of a toxin on cell division" |

## Instructional Design Models

### ADDIE Model

| Phase | Description |
|-------|-------------|
| **Analyse** | Identify learners' needs; goals; existing knowledge; constraints |
| **Design** | Define learning objectives; assessment strategy; content structure |
| **Develop** | Create materials; activities; assessments |
| **Implement** | Deliver the instruction; facilitate learning |
| **Evaluate** | Assess effectiveness; gather feedback; iterate |

### Backward Design (Understanding by Design)

| Step | Description |
|------|-------------|
| **1. Identify desired results** | What should learners know, understand, and be able to do? |
| **2. Determine acceptable evidence** | How will you know they've achieved the results? (Assessment first) |
| **3. Plan learning experiences** | What activities, instruction, and practice will equip learners to succeed? |

### Scaffolding

| Technique | Description |
|-----------|-------------|
| **Modelling** | Demonstrate the skill or thought process |
| **Think-aloud** | Verbalise your reasoning while solving a problem |
| **Worked examples** | Show complete solutions before asking learners to solve problems |
| **Gradual release** | "I do → We do → You do" — progressively remove support |
| **Prompting** | Ask questions that guide learners toward the answer |
| **Chunking** | Break complex tasks into manageable pieces |

## Motivation and Engagement

### Self-Determination Theory

| Need | Description | How to Support |
|------|-------------|----------------|
| **Autonomy** | Feeling in control of one's own actions | Offer choices; explain rationale; avoid controlling language |
| **Competence** | Feeling effective and capable | Appropriate challenge; timely feedback; celebrate progress |
| **Relatedness** | Feeling connected to others | Collaborative learning; supportive environment; relevance to community |

### Growth vs Fixed Mindset (Carol Dweck)

| Mindset | Belief | Behaviour | Response to Failure |
|---------|--------|-----------|-------------------|
| **Fixed** | Intelligence is static | Avoids challenges; gives up easily | "I'm not good at this" |
| **Growth** | Intelligence can be developed | Embraces challenges; persists | "I haven't learned this yet" |

## Assessment

### Types of Assessment

| Type | Purpose | Timing | Example |
|------|---------|--------|---------|
| **Diagnostic** | Identify prior knowledge and misconceptions | Before instruction | Pre-test; concept inventory |
| **Formative** | Monitor learning; provide feedback | During instruction | Quizzes; exit tickets; peer review |
| **Summative** | Evaluate learning at the end | After instruction | Final exam; project; portfolio |
| **Authentic** | Assess real-world application | During or after | Case study; simulation; internship |

### Effective Feedback

| Principle | Description |
|-----------|-------------|
| **Timely** | Soon enough to act on it |
| **Specific** | Points to particular strengths and weaknesses |
| **Actionable** | Tells the learner what to do next |
| **Focused on the task** | Not about the person ("This argument needs more evidence" not "You're not a good writer") |
| **Balanced** | Identifies what's working and what needs improvement |

## Summary

Learning science shows that the most effective strategies are often counterintuitive. Retrieval practice (testing yourself) is far more effective than rereading. Spaced repetition beats cramming. Interleaving different types of problems improves discrimination and transfer. Cognitive load theory reminds us that working memory is limited — instruction should be designed to minimise extraneous load. Bloom's taxonomy provides a framework for progressing from recall to creation. Instructional design models (ADDIE, backward design) offer structured approaches to developing effective learning experiences. Motivation depends on autonomy, competence, and relatedness. Assessment should be aligned with learning objectives and include formative feedback, not just summative grades. The biggest myth in learning is that people have fixed "learning styles" — the evidence consistently shows that matching instruction to a preferred style doesn't improve outcomes. What works for everyone is effortful retrieval, spaced practice, varied examples, and meaningful feedback.
