# Abstract Algebra

Abstract algebra studies algebraic structures — sets equipped with operations that follow specific rules. Instead of working with numbers, abstract algebra works with any objects that satisfy the axioms. This generality is powerful: a theorem proved for "groups" applies to integers, symmetries, matrices, permutations, and quantum states simultaneously. Abstract algebra underpins cryptography, error-correcting codes, quantum computing, and the symmetry analysis used throughout physics.

---

## Groups

A **group** is the most fundamental algebraic structure. It captures the essence of symmetry.

### Definition

A **group** (G, ∗) is a set G with a binary operation ∗ satisfying:

| Axiom | Statement | Example (ℤ, +) |
|-------|-----------|-----------------|
| **Closure** | ∀a,b ∈ G: a ∗ b ∈ G | a + b is an integer |
| **Associativity** | (a ∗ b) ∗ c = a ∗ (b ∗ c) | (a + b) + c = a + (b + c) |
| **Identity** | ∃e ∈ G: e ∗ a = a ∗ e = a | 0 + a = a + 0 = a |
| **Inverse** | ∀a ∈ G, ∃a⁻¹: a ∗ a⁻¹ = a⁻¹ ∗ a = e | a + (−a) = 0 |

If the operation is also **commutative** (a ∗ b = b ∗ a), the group is called **abelian**.

### Examples of Groups

| Group | Set | Operation | Identity | Inverse | Abelian? |
|-------|-----|-----------|----------|---------|----------|
| (ℤ, +) | Integers | Addition | 0 | −a | Yes |
| (ℚ*, ×) | Non-zero rationals | Multiplication | 1 | 1/a | Yes |
| (ℤ/nℤ, +) | Residues mod n | Addition mod n | [0] | [n−a] | Yes |
| Sₙ | Permutations of {1,...,n} | Composition | id | Inverse permutation | No (n ≥ 3) |
| GL(n, ℝ) | Invertible n×n matrices | Matrix multiplication | Iₙ | A⁻¹ | No (n ≥ 2) |
| (ℝⁿ, +) | n-dimensional vectors | Vector addition | 0 | −v | Yes |

### Order of a Group and Elements

| Term | Definition | Example |
|------|------------|---------|
| **Order of G** (\|G\|) | Number of elements in G | \|ℤ/5ℤ\| = 5 |
| **Order of element a** (ord(a)) | Smallest positive k with aᵏ = e | ord(2) in (ℤ/7ℤ)* = 3 (since 2³ = 8 ≡ 1) |
| **Finite group** | \|G\| is finite | S₃ has order 6 |
| **Infinite group** | \|G\| is infinite | (ℤ, +) |

### Subgroups

A **subgroup** H of G is a subset H ⊆ G that is itself a group under the same operation.

**Subgroup test:** H is a subgroup of G iff:
1. H is non-empty
2. For all a, b ∈ H: a ∗ b⁻¹ ∈ H

**Examples:**
- (ℤ, +) has subgroups nℤ = {..., −2n, −n, 0, n, 2n, ...} for each n ≥ 0
- The **trivial subgroup** {e} and the group G itself are always subgroups
- In S₃, the set {id, (12)} is a subgroup of order 2

### Cosets and Lagrange's Theorem

For a subgroup H of G and element a ∈ G:
- **Left coset:** aH = {ah : h ∈ H}
- **Right coset:** Ha = {ha : h ∈ H}

**Lagrange's Theorem:** For a finite group G and subgroup H:
|H| divides |G|

**Corollaries:**
- The order of every element divides |G|
- If |G| = p (prime), then G is cyclic (has no non-trivial subgroups)
- a^|G| = e for all a ∈ G (generalises Fermat's Little Theorem)

### Cyclic Groups

A group G is **cyclic** if there exists g ∈ G such that every element of G is a power of g. We write G = ⟨g⟩.

| Property | Statement |
|----------|-----------|
| Every cyclic group is abelian | — |
| ℤ/nℤ under addition is cyclic | Generated by [1] |
| (ℤ/pℤ)* is cyclic for prime p | Generator is called a primitive root |
| Classification | Every finite cyclic group is isomorphic to ℤ/nℤ for some n |

## Homomorphisms and Isomorphisms

A **homomorphism** is a structure-preserving map between groups.

### Definitions

| Term | Definition | Example |
|------|------------|---------|
| **Homomorphism** | φ: G → H where φ(ab) = φ(a)φ(b) | det: GL(n,ℝ) → ℝ* |
| **Isomorphism** | A bijective homomorphism (groups are "the same") | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **Kernel** | ker(φ) = {g ∈ G : φ(g) = e_H} | ker(det) = SL(n, ℝ) |
| **Image** | im(φ) = {φ(g) : g ∈ G} | im(det) = ℝ* |

### First Isomorphism Theorem

If φ: G → H is a homomorphism, then:
G / ker(φ) ≅ im(φ)

This is one of the most important theorems in algebra — it says every homomorphism decomposes into a quotient followed by an isomorphism.

## Rings

A **ring** adds a second operation to a group, modelling arithmetic with both addition and multiplication.

### Definition

A **ring** (R, +, ×) is a set R with two operations satisfying:

| Axiom | Statement |
|-------|-----------|
| (R, +) is an abelian group | Addition is commutative, associative, has identity 0, every element has additive inverse |
| Multiplication is associative | (a × b) × c = a × (b × c) |
| Distributive laws | a(b + c) = ab + ac and (a + b)c = ac + bc |

If multiplication is also commutative and has an identity (1), R is a **commutative ring with unity**.

### Examples of Rings

| Ring | Description | Commutative? | Has 1? |
|------|-------------|-------------|--------|
| (ℤ, +, ×) | Integers | Yes | Yes |
| (ℚ, +, ×) | Rationals | Yes | Yes |
| (ℝ, +, ×) | Real numbers | Yes | Yes |
| (ℤ/nℤ, +, ×) | Integers mod n | Yes | Yes |
| Mₙ(ℝ) | n×n real matrices | No (n ≥ 2) | Yes |
| ℝ[x] | Polynomials with real coefficients | Yes | Yes |

### Ideals and Quotient Rings

An **ideal** I of a ring R is a subset that:
1. Is a subgroup under addition
2. Absorbs multiplication: for all r ∈ R and a ∈ I, both ra ∈ I and ar ∈ I

**Quotient ring** R/I: elements are cosets of I, with operations inherited from R.

**Example:** ℤ/nℤ = ℤ/nℤ is the quotient of ℤ by the ideal nℤ.

### Integral Domains and Fields

| Structure | Definition | Examples |
|-----------|------------|----------|
| **Integral domain** | Commutative ring with 1, no zero divisors (ab = 0 → a = 0 or b = 0) | ℤ, ℚ[x], ℝ[x] |
| **Field** | Commutative ring where every non-zero element has a multiplicative inverse | ℚ, ℝ, ℂ, ℤ/pℤ (p prime) |

## Fields

Fields are the most structured algebraic objects in common use. Every non-zero element can be added, subtracted, multiplied, and divided.

### Key Properties

| Property | Statement |
|----------|-----------|
| Every field is an integral domain | — |
| Every finite integral domain is a field | — |
| Characteristic | Smallest n with n·1 = 0, or 0 if no such n exists |
| char(ℚ) = char(ℝ) = char(ℂ) | = 0 |
| char(ℤ/pℤ) | = p (for prime p) |

### Finite Fields (Galois Fields)

For every prime power pᵏ, there exists a unique (up to isomorphism) finite field of order pᵏ, denoted GF(pᵏ) or 𝔽_{pᵏ}.

| Field | Size | Construction | Application |
|-------|------|-------------|-------------|
| GF(2) | 2 | {0, 1} mod 2 | Binary arithmetic, XOR |
| GF(2ᵏ) | 2ᵏ | Polynomials mod irreducible poly over GF(2) | AES encryption, CRC codes |
| GF(p) | p | ℤ/pℤ for prime p | Modular arithmetic, coding theory |
| GF(pᵏ) | pᵏ | Extension fields | Reed-Solomon codes, elliptic curves |

**Construction of GF(2⁸)** (used in AES):
- Start with GF(2) = {0, 1}
- Choose irreducible polynomial p(x) = x⁸ + x⁴ + x³ + x + 1 over GF(2)
- Elements are polynomials of degree < 8 with coefficients in GF(2)
- Arithmetic: polynomial addition (XOR) and multiplication mod p(x)

## Vector Spaces

A **vector space** is a set of vectors that can be added and scaled, forming the foundation of linear algebra.

### Definition

A **vector space** V over a field F is a set with:
- Vector addition: V × V → V (making V an abelian group)
- Scalar multiplication: F × V → V

Satisfying: associativity, commutativity of addition, distributivity of scalar multiplication, and 1·v = v.

### Key Concepts

| Concept | Definition | Example |
|---------|------------|---------|
| **Basis** | Linearly independent spanning set | {e₁, e₂, ..., eₙ} for Fⁿ |
| **Dimension** | Number of vectors in any basis | dim(ℝ³) = 3 |
| **Subspace** | Subset closed under addition and scalar multiplication | A plane through the origin in ℝ³ |
| **Linear combination** | Σ cᵢvᵢ where cᵢ ∈ F | 3v₁ + 2v₂ − v₃ |
| **Span** | Set of all linear combinations | Span({v₁, v₂}) = plane if v₁, v₂ independent |
| **Linear independence** | No vector is a linear combination of others | e₁, e₂, e₃ in ℝ³ |

### Important Vector Spaces

| Space | Description | Dimension |
|-------|-------------|-----------|
| Fⁿ | n-tuples over field F | n |
| Pₙ(F) | Polynomials of degree ≤ n | n + 1 |
| Mₘₓₙ(F) | m × n matrices over F | mn |
| C[a,b] | Continuous functions on [a,b] | Infinite |
| L²(ℝ) | Square-integrable functions | Infinite (Hilbert space) |

## Linear Maps and Eigen Theory

### Linear Maps

A **linear map** (linear transformation) T: V → W satisfies:
- T(u + v) = T(u) + T(v)
- T(cv) = cT(v) for all scalars c

| Concept | Definition | Example |
|---------|------------|---------|
| **Kernel** | {v ∈ V : T(v) = 0} | Null space of a matrix |
| **Image** | {T(v) : v ∈ V} | Column space of a matrix |
| **Rank-Nullity Theorem** | dim(ker T) + dim(im T) = dim(V) | Fundamental constraint |
| **Matrix representation** | T(v) = Av for some matrix A | Every linear map between finite-dimensional spaces |

### Eigenvalues and Eigenvectors

For a linear map T: V → V (or matrix A):

**Eigenvalue equation:** Av = λv, where v ≠ 0

| Term | Definition |
|------|------------|
| **Eigenvalue** λ | Scalar such that Av = λv for some v ≠ 0 |
| **Eigenvector** v | Non-zero vector satisfying Av = λv |
| **Characteristic polynomial** | det(A − λI) = 0 |
| **Eigenspace** | {v : Av = λv} — the set of all eigenvectors for λ (plus 0) |
| **Spectrum** | Set of all eigenvalues |

### Computing Eigenvalues

For a 2×2 matrix A = [[a, b], [c, d]]:
- Characteristic polynomial: λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2

**Key properties:**
- Sum of eigenvalues = trace(A) = sum of diagonal elements
- Product of eigenvalues = det(A)

### Diagonalisation

A matrix A is **diagonalisable** iff it has n linearly independent eigenvectors (where A is n×n).

If A = PDP⁻¹ where D is diagonal:
- Aᵏ = PDᵏP⁻¹ (fast matrix exponentiation)
- D contains eigenvalues on diagonal
- P contains eigenvectors as columns

**Spectral Theorem:** Every real symmetric matrix is diagonalisable by an orthogonal matrix. Its eigenvalues are real.

## Applications

### Coding Theory (Error-Correcting Codes)

Finite fields are the foundation of modern error-correcting codes.

| Code | Field | Corrects | Application |
|------|-------|----------|-------------|
| Hamming code | GF(2) | 1 error per block | RAM ECC, early networking |
| Reed-Solomon | GF(2ᵏ) | Multiple errors | CDs, DVDs, QR codes, satellite communication |
| BCH codes | GF(2ᵏ) | Multiple errors | Flash memory, satellite |
| LDPC codes | GF(2) | Multiple errors | Wi-Fi (802.11n), DVB-S2, 5G |

**Reed-Solomon encoding:** Treat data as a polynomial over GF(2ᵏ), evaluate at several points. Even if some evaluations are corrupted, the original polynomial can be recovered.

### Quantum Computing

Quantum states live in complex vector spaces (Hilbert spaces). Quantum gates are unitary matrices.

| Quantum Concept | Algebraic Structure |
|----------------|-------------------|
| Qubit | Unit vector in ℂ² (complex 2D vector space) |
| Quantum gate | Unitary matrix U ∈ U(2ⁿ) |
| Measurement | Projection operator |
| Entanglement | Non-separable tensor product state |
| No-cloning theorem | No linear map can copy an unknown quantum state |

**Single-qubit gates:**
| Gate | Matrix | Effect |
|------|--------|--------|
| Pauli-X (NOT) | [[0,1],[1,0]] | Bit flip |
| Pauli-Z | [[1,0],[0,−1]] | Phase flip |
| Hadamard | (1/√2)[[1,1],[1,−1]] | Creates superposition |
| CNOT | 4×4 controlled gate | Entangles two qubits |

### Cryptography

| Application | Algebra Used |
|-------------|-------------|
| RSA | Multiplicative group (ℤ/nℤ)* |
| Elliptic curve cryptography | Group of points on elliptic curve over finite field |
| AES | Arithmetic in GF(2⁸) |
| Diffie-Hellman | Cyclic subgroup of (ℤ/pℤ)* or elliptic curve group |

## Summary

| Structure | Operations | Key Property | Example |
|-----------|-----------|--------------|---------|
| Group | One (∗) | Closure, associativity, identity, inverse | (ℤ, +), Sₙ |
| Ring | Two (+, ×) | Abelian group under +, monoid under ×, distributive | ℤ, ℤ/nℤ, Mₙ(ℝ) |
| Field | Two (+, ×) | Ring where non-zero elements form a group under × | ℚ, ℝ, ℂ, GF(p) |
| Vector space | Scalar mult + addition | Module over a field | ℝⁿ, Pₙ(F), function spaces |

Abstract algebra provides the language for structure itself. Groups capture symmetry, rings capture arithmetic, fields capture division, and vector spaces capture linearity. These structures are not abstract for its own sake — they appear in every error-correcting code that protects your data, every cryptographic protocol that secures your communications, every quantum algorithm that may one day transform computing, and every linear transformation that runs through a neural network.
