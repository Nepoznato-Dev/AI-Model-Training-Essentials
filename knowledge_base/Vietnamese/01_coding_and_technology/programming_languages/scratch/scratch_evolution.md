# Scratch — Lịch sử và sự phát triển của phiên bản

| Phiên bản | Năm | Chủ đề chính |

| Trước đầu | 2003 | Các biểu mẫu của Scratch Team tại MIT Media Lab |

## Các cột mốc quan trọng
### Nguồn gốc (2003–2006)
- **2003**: Nhóm Mẫu giáo Suốt đời của MIT Media Lab bắt đầu phát triển Scratch
- Được dẫn dắt bởi Mitchel Resnick
- **Mục tiêu**: Dạy lập trình cho trẻ thông qua các khối trực quan
- Lấy cảm hứng từ: Logo (Seymour Papert), Logo Lego, Squeak Etoys
- Tên: "Scratch" — từ DJ gãi (trộn các phương tiện với nhau)
### Cào 1.0 (2007)
- **2007**: Phát hành lần đầu ra công chúng
- Lập trình khối kéo và thả
- Các dự án dựa trên Sprite (nhân vật, hình ảnh động)
- Âm thanh, đồ họa, hoạt hình
- Tích hợp Squeak (Smalltalk)
- **Mục tiêu**: Độ tuổi 8-16, nhưng được áp dụng rộng rãi hơn nhiều
### Cào 1.4 (2009)
- Cải thiện kết xuất đồ họa
- Thêm thư viện sprite
- Hỗ trợ âm thanh tốt hơn
- Phiên bản cuối cùng được xây dựng trên Squeak
### Cào 2.0 (2013)
- **Trình chỉnh sửa hoàn chỉnh dựa trên web** — chạy trong trình duyệt
- Biến đám mây - chia sẻ dữ liệu giữa các dự án
- Ba lô — chia sẻ họa tiết/tập lệnh giữa các dự án
- Khối tùy chỉnh (như chức năng)
- Tích hợp ActionScript 3 (Flash)
- Tính năng cộng đồng: remix, chia sẻ, bình luận
### Cào 3.0 (2019)
- **Viết lại hoàn chỉnh** — HTML5/JavaScript (không có Flash)
- Hoạt động trên máy tính bảng, điện thoại, Chromebook
- **Tiện ích mở rộng**:
  - Bút (vẽ)
  - Cảm biến video (máy ảnh)
  - Chuyển văn bản thành giọng nói
  - Dịch (Google Dịch)
  - micro:bit (phần cứng)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Cải tiến trình chỉnh sửa âm thanh
- Trình chỉnh sửa sơn mới (vector + bitmap)
- Ba lô, mây biến được giữ lại
### Scratch Desktop & Beyond (2020–nay)
- **2020**: Scratch Desktop — trình chỉnh sửa ngoại tuyến (Dựa trên điện tử)
- Tiếp tục phát triển mở rộng
- Tiện ích mở rộng AI/ML (do cộng đồng tạo)
- Tích hợp với máy tính vật lý (micro:bit, Arduino)
## Chặn danh mục Tiến hóa
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Khái niệm lập trình được dạy
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Nguyên tắc thiết kế chính
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
