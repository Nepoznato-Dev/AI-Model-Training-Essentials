# Lisp & Clojure — Những lỗi thường gặp và lỗi mẫu
Tài liệu này liệt kê các lỗi, bẫy và mô hình chống phổ biến nhất trong Lisp và Clojure cùng với các chỉnh sửa.
---

## 1. Trích dẫn nhầm lẫn
```lisp
;; ❌ WRONG — quoting prevents evaluation
'(1 2 (+ 1 2))  ;; (1 2 (+ 1 2)) — not (1 2 3)

;; ✅ CORRECT — use quasiquote for selective evaluation
`(1 2 ,(+ 1 2))  ;; (1 2 3)
```

---

## 2. Chưa hiểu`nil`vs`false`(Clojure)
```clojure
;; ❌ WRONG — assuming nil and false are interchangeable
(nil? false)   ;; false
(false? nil)   ;; false
(if nil "yes" "no")  ;; "no" (nil is falsy)
(if false "yes" "no")  ;; "no" (false is falsy)

;; ✅ CORRECT — both are falsy, but distinct
(identical? nil nil)   ;; true
(identical? false false) ;; true
(nil? nil)   ;; true
(false? false) ;; true
```

---

## 3. Sửa đổi Bộ sưu tập (Clojure)
```clojure
;; ❌ WRONG — expecting mutation
(def v [1 2 3])
(conj v 4)  ;; returns [1 2 3 4]
v  ;; still [1 2 3]!

;; ✅ CORRECT — rebind
(def v (conj v 4))
;; or use atoms/refs for shared mutable state
(def v (atom [1 2 3]))
(swap! v conj 4)
```

---

## 4. Không sử dụng`recur`cho đệ quy đuôi (Clojure)
```clojure
;; ❌ WRONG — stack overflow on large inputs
(defn sum [n]
  (if (zero? n) 0 (+ n (sum (dec n)))))

;; ✅ CORRECT — use recur
(defn sum [n]
  (loop [i n acc 0]
    (if (zero? i)
      acc
      (recur (dec i) (+ acc i)))))
```

---

##5. Vệ sinh Macro (Lisp thông thường)
```lisp
;; ❌ WRONG — variable capture in macro
(defmacro bad-double (x)
  `(* ,x 2))  ;; fine, but:
(defmacro bad-inc (x)
  `(let ((tmp 1))
     (+ ,x tmp)))  ;; tmp might be captured!

;; ✅ CORRECT — use gensym
(defmacro good-inc (x)
  (let ((tmp (gensym "tmp")))
    `(let ((,tmp 1))
       (+ ,x ,tmp))))
```

---

## Bản tóm tắt
Bẫy Lisp/Clojure: trích dẫn ngăn đánh giá (sử dụng quasiquote với`,`),`nil`và`false`đều sai nhưng khác biệt, các bộ sưu tập không thể thay đổi (liên kết lại hoặc sử dụng nguyên tử), sử dụng`recur`để đệ quy đuôi và sử dụng`gensym`trong macro để tránh chụp biến. Cách của Lisp là: tận dụng tính bất biến, hiểu hệ thống macro của trình đọc và viết các macro hợp lý.
