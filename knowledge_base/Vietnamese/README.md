Khi bạn thay đổi tệp cơ sở kiến ​​thức, hãy đồng bộ hóa phần đầu của nó:
1. **Bump`version`** theo sau[SemVer](https://semver.org/):
   - Bản vá (`1.0.x`): lỗi chính tả, định dạng, sửa lỗi nhỏ
   - Tiểu phần (`1.x.0`): phần mới, nội dung mở rộng, ví dụ mới
   - Major (`x.0.0`): viết lại hoặc tái cấu trúc hoàn chỉnh
2. **Thêm mục nhật ký thay đổi** (mới nhất trước tiên) mô tả những gì bạn đã thay đổi:   ```yaml
   changelog:
     - version: "1.1.0"

     - version: "1.0.0"
       date: "2026-08-05"

       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **Cập nhật`last_modified`** đến ngày bạn thay đổi
4. **Thêm chính bạn vào`contributors`** nếu đây là lần chỉnh sửa đầu tiên của bạn đối với tệp:   ```yaml
   contributors:
     - name: "Your Name"

       role: "contributor"
   ```
