## 🔧 使用指南

### 適用於 AI 系統
- 所有檔案都使用清晰的階層標題結構化
- 技術術語在文中定義或在 `dictionary.md` 中定義
- 交叉引用使用 Markdown 連結
- 程式碼範例包含語法突顯

### 適用於人類讀者
- 每個檔案開頭包含學習目標
- 適用的地方會標註難度等級
- 技術檔案中包含練習和實作問題
- 在有幫助的地方使用視覺輔助（圖表、表格）

## 📝 貢獻

在新增或修改內容時：

1. **遵循風格指南：**
   - 僅對檔案標題使用 `#`
   - 對主要章節使用 `##`
   - 對小節使用 `###`
   - 對無序列表使用 `-`
   - 在程式碼區塊中包含語法突顯

2. **新增中繼資料**（YAML frontmatter）：
```yaml
---
title: "檔案標題"
description: "簡短描述"
topics: [主題1, 主題2, 主題3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **包含引用**以支持事實陳述
4. **新增交叉引用**到相關檔案
5. **更新此 README**（如果新增檔案）
