# Englische Wissensdatenbank
Eine umfassende Sammlung von Referenzdokumenten zu den Themen Codierung, Technologie, KI, Wissenschaft, Wirtschaft, Geisteswissenschaften und mehr – verfasst in einem natürlichen, gesprächigen Stil, der sowohl für KI-Training als auch für menschliches Lernen konzipiert ist.
**Letzte Aktualisierung:** August 2026  
**Gesamtdateien:** 138+ Markdown-Dokumente  
**Organisation:** 10 thematische Verzeichnisse + 34 Referenzen zu Programmiersprachen
---

created: "2026-08-05"
last_modified: "2026-08-05"

```

| Feld | Quelle / Zweck |
|---|---|
| `title`| Aus der ersten `#`-Überschrift | der Datei gezogen
| `description`| Einzeilige Zusammenfassung; Themendateien verwenden den Eintrag aus dem Index dieser README-Datei wieder, Programmiersprachendateien verwenden eine generierte Beschreibung |
| `category`/`reviewed_by`| Abgeleitet vom übergeordneten Verzeichnis (`01_coding_and_technology`→ „Coding and Technology“ / „Coding & Technology Knowledge Base Team“) |
| `version`| Semantische Version; Bump bei jeder Bearbeitung (siehe unten) |
| `authors`/`contributors`| Ursprünglicher Autor und alle Personen, die die Datei seitdem bearbeitet haben |
| `changelog`| Nur anfügbare Änderungsliste, neueste zuerst |
| `review_date`/`next_review`| ~6-Monats- und ~1-Jahres-Trittfrequenz, entsprechend dem Zeitplan für die Kompetenzüberprüfung |
| `tags`| Dateinamen-Tokens plus ein sauberes Kategorieschlüsselwort (z. B. `coding-and-technology`) |
| `difficulty_level`| Nach Kategorie festgelegt, mit Überschreibungen pro Sprache (z. B. Haskell/Assembly →`advanced`, Scratch →`beginner`) |
| `estimated_reading_time`| Berechnet aus der Zeilenanzahl |
### Bearbeiten einer Datei
Wenn Sie eine Wissensdatenbankdatei ändern, halten Sie deren Titel synchron:
1. **Bump`version`** nach[SemVer](https://semver.org/):
   - Patch (`1.0.x`): Tippfehler, Formatierung, kleinere Korrekturen
   - Minor (`1.x.0`): neue Abschnitte, erweiterter Inhalt, neue Beispiele
   - Major (`x.0.0`): komplette Neufassung oder Umstrukturierung
2. **Fügen Sie einen Änderungsprotokolleintrag hinzu** (neuester zuerst), der beschreibt, was Sie geändert haben:   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **Aktualisieren Sie`last_modified`** auf das Datum Ihrer Änderung
4. **Fügen Sie sich selbst zu`contributors`hinzu **, wenn es Ihre erste Bearbeitung der Datei ist:   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
