## 📝 Beiträge

Beim Hinzufügen oder Ändern von Inhalten:

1. **Befolgen Sie den Styleguide:**
   - Verwenden Sie `#` nur für den Dateititel
   - Verwenden Sie `##` für Hauptabschnitte
   - Verwenden Sie `###` für Unterabschnitte
   - Verwenden Sie `-` für ungeordnete Listen
   - Verwenden Sie Syntaxhervorhebung in Codeblöcken

2. **Metadaten hinzufügen** (YAML-Frontmatter):
```yaml
---
title: "Dateitel"
description: "Kurze Beschreibung"
topics: [Thema1, Thema2, Thema3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Quellen angeben** für faktische Behauptungen
4. **Querverweise hinzufügen** zu verwandten Dateien
5. **Dieses README aktualisieren**, wenn neue Dateien hinzugefügt werden
