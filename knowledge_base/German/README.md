## 🔧 Nutzungsrichtlinien

### Für AI-Systeme
- Alle Dateien sind mit klaren hierarchischen Überschriften strukturiert
- Fachbegriffe werden inline oder in `dictionary.md` definiert
- Querverweise verwenden Markdown-Links
- Codebeispiele enthalten Syntaxhervorhebung

### Für menschliche Leser
- Jede Datei enthält am Anfang Lernziele
- Schwierigkeitsgrade werden, wo zutreffend, angegeben
- Übungen und Praxisaufgaben sind in technischen Dateien enthalten
- Visuelle Hilfen (Diagramme, Tabellen) werden eingesetzt, wo sie hilfreich sind

## 📝 Mitwirken

Beim Hinzufügen oder Ändern von Inhalten:

1. **Befolge den Stil-Leitfaden:**
   - Verwende `#` nur für den Dateititel
   - Verwende `##` für Hauptabschnitte
   - Verwende `###` für Unterabschnitte
   - Verwende `-` für ungeordnete Listen
   - Füge in Codeblöcken Syntaxhervorhebung hinzu

2. **Füge Metadaten hinzu** (YAML frontmatter):
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Füge Quellenangaben hinzu** für Tatsachenbehauptungen
4. **Füge Querverweise hinzu** auf verwandte Dateien
5. **Aktualisiere diese README**, wenn neue Dateien hinzugefügt werden
