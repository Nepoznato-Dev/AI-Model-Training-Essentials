# Scratch – Versionsverlauf und Entwicklung
## Zeitleiste
| Version | Jahr | Schlüsselthema |
|---------|------|-----------|
| Vorkratzen | 2003 | Scratch-Team bildet sich im MIT Media Lab |
| Scratch 1.0 | 2007 | **Erstveröffentlichung** – visuelle Programmierung für Kinder |
| Kratzer 1.4 | 2009 | Verbesserte Grafik, mehr Blöcke |
| Scratch 2.0 | 2013 | **Hauptsächlich**: Webbasierter Editor, Cloud-Variablen, Rucksack |
| Scratch 3.0 | 2019 | **Major**: Vollständige Neufassung (HTML5/JS), Erweiterungen, Stift |
| Scratch 3.x | 2019–25 | Videoerkennung, Text-to-Speech, Übersetzen, micro:bit |
| Scratch Jr. | 2014 | Vereinfachte Version für jüngere Kinder (5-7) |
| Scratch-Desktop | 2020 | Offline-Editor (elektronenbasiert) |
## Wichtige Meilensteine
### Ursprünge (2003–2006)
- **2003**: Die Lifelong Kindergarten-Gruppe des MIT Media Lab beginnt mit der Scratch-Entwicklung
- Unter der Leitung von Mitchel Resnick
- **Ziel**: Kindern das Programmieren durch visuelle Blockaden beibringen
- Inspiriert von: Logo (Seymour Papert), Lego Logo, Squeak Etoys
- Name: „Scratch“ – vom DJ-Scratching (Zusammenmischen von Medien)
### Scratch 1.0 (2007)
- **2007**: Erste öffentliche Veröffentlichung
- Drag-and-Drop-Blockprogrammierung
- Sprite-basierte Projekte (Charaktere, Animationen)
- Ton, Grafik, Animation
- Integriertes Quietschen (Smalltalk)
- **Zielgruppe**: Alter 8–16, aber viel weiter verbreitet
### Scratch 1.4 (2009)
- Verbesserte Grafikwiedergabe
- Weitere Sprite-Bibliotheken
- Bessere Soundunterstützung
- Letzte auf Squeak basierende Version
### Scratch 2.0 (2013)
- **Vollständiger webbasierter Editor** – läuft im Browser
- Cloud-Variablen – Daten zwischen Projekten teilen
- Rucksack – Teilen Sie Sprites/Skripte zwischen Projekten
- Benutzerdefinierte Blöcke (wie Funktionen)
- Integriertes ActionScript 3 (Flash)
- Community-Funktionen: Remixen, Teilen, Kommentieren
### Scratch 3.0 (2019)
- **Komplette Neufassung** – HTML5/JavaScript (kein Flash)
- Funktioniert auf Tablets, Telefonen und Chromebooks
- **Erweiterungen**:
  - Stift (Zeichnung)
  - Videoerkennung (Kamera)
  - Text-to-Speech
  - Übersetzen (Google Translate)
  - micro:bit (Hardware)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Verbesserungen des Sound-Editors
- Neuer Maleditor (Vektor + Bitmap)
- Rucksack, Cloud-Variablen bleiben erhalten
### Scratch Desktop & Beyond (2020–heute)
- **2020**: Scratch Desktop – Offline-Editor (elektronenbasiert)
- Weiterentwicklung der Erweiterung
- AI/ML-Erweiterungen (von der Community erstellt)
- Integration mit Physical Computing (micro:bit, Arduino)
## Evolution der Blockkategorien
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Programmierkonzepte gelehrt
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Wichtige Designprinzipien
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Wirkung und Akzeptanz
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
