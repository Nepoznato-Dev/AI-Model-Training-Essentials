# C#
C# (ausgesprochen „C-sharp“) ist eine moderne, objektorientierte, typsichere Programmiersprache, die von Microsoft unter der Leitung von Anders Hejlsberg entwickelt und erstmals 2002 veröffentlicht wurde. Sie läuft auf der .NET-Plattform und wurde entwickelt, um die Leistungsfähigkeit von C++ mit der Produktivität von Visual Basic zu kombinieren. Heute ist C# eine vielseitige, plattformübergreifende Sprache, die für Webanwendungen (ASP.NET), Desktop-Software (Windows), Spieleentwicklung (Unity), mobile Apps (MAUI), Cloud-Dienste (Azure) und mehr verwendet wird.
C# hat nach und nach die besten Ideen aus anderen Sprachen übernommen – LINQ, Async/Await, Datensätze, Mustervergleich – und ist damit eine der funktionsreichsten und entwicklerfreundlichsten verfügbaren Sprachen.
---

## Warum C# wichtig ist
- **Unity-Game-Engine**: Die primäre Sprache für Unity, die nach Entwicklerzahl weltweit beliebteste Game-Engine.
- **Enterprise-Entwicklung**: ASP.NET Core ist eines der schnellsten verfügbaren Web-Frameworks (an der Spitze der TechEmpower-Benchmarks).
- **Plattformübergreifend**: .NET 5+ läuft unter Windows, macOS und Linux. Nicht mehr nur für Windows.
- **Produktivität**: Hervorragende IDE-Unterstützung (Visual Studio, Rider), starkes Typsystem und moderne Syntaxfunktionen.
- **Async/Await-Pionier**: C# führte Async/Await im Jahr 2012 ein – Jahre bevor andere Sprachen das Muster übernahmen.
- **LINQ**: Mit der sprachintegrierten Abfrage können Sie SQL-ähnliche Abfragen direkt in C# für jede Datenquelle schreiben.
## Die Kompromisse
| Einschränkung | Einzelheiten | Typische Problemumgehung |
|-----------|---------|-----|
| **Windows-Zuordnung** | Historisch an Windows gebunden; Wahrnehmung hinkt der Realität hinterher | .NET 6+ ist vollständig plattformübergreifend |
| **Kleineres Ökosystem als Java** | Weniger Bibliotheken von Drittanbietern als Maven/PyPI | NuGet wächst; viele Java-Bibliotheken haben C#-Äquivalente |
| **In Startups seltener** | In Unternehmen beliebter als im Silicon Valley | Go, Rust, Node.js für Cloud-native Microservices |
| **Mobil (MAUI)** | Xamarin/MAUI ist weniger ausgereift als natives oder Flutter | Verwenden Sie natives Swift/Kotlin oder Flutter für komplexe mobile Apps |
| **Linux-GUI** | Begrenzte native GUI-Optionen unter Linux | Verwenden Sie webbasierte Benutzeroberflächen (Blazor) oder Avalonia |

## Parallelität und Parallelität
### async/await Interna
```csharp
// The state machine behind async/await
// When you write async/await, the compiler generates a state machine
// that suspends and resumes the method at each await point.

// Parallel async with structured concurrency
public async Task ProcessBatchAsync(IEnumerable<string> urls)
{
    using var semaphore = new SemaphoreSlim(10);  // Limit concurrency to 10
    var tasks = urls.Select(async url =>
    {
        await semaphore.WaitAsync();
        try
        {
            using var client = new HttpClient();
            var data = await client.GetStringAsync(url);
            Console.WriteLine($"Fetched {data.Length} chars from {url}");
        }
        finally
        {
            semaphore.Release();
        }
    });
    await Task.WhenAll(tasks);
}

// Channels — producer/consumer pattern
public async Task ProcessWithChannel()
{
    var channel = Channel.CreateBounded<string>(new BoundedChannelOptions(100)
    {
        FullMode = BoundedChannelFullMode.Wait
    });

    // Producer
    _ = Task.Run(async () =>
    {
        for (int i = 0; i < 1000; i++)
        {
            await channel.Writer.WriteAsync($"item-{i}");
            await Task.Delay(10);
        }
        channel.Writer.Complete();
    });

    // Consumer
    await foreach (var item in channel.Reader.ReadAllAsync())
    {
        Console.WriteLine($"Processing: {item}");
    }
}
```

## Designmuster
### Builder-Muster (Fluent API)
```csharp
public class HttpRequest
{
    public string Method { get; init; } = "GET";
    public string Url { get; init; } = "";
    public Dictionary<string, string> Headers { get; init; } = new();
    public string? Body { get; init; }
}

public class HttpRequestBuilder
{
    private string _method = "GET";
    private string _url = "";
    private readonly Dictionary<string, string> _headers = new();
    private string? _body;

    public HttpRequestBuilder Method(string m) { _method = m; return this; }
    public HttpRequestBuilder Url(string u) { _url = u; return this; }
    public HttpRequestBuilder Header(string k, string v) { _headers[k] = v; return this; }
    public HttpRequestBuilder Body(string b) { _body = b; return this; }
    public HttpRequest Build() => new() { Method = _method, Url = _url, Headers = _headers, Body = _body };
}

var request = new HttpRequestBuilder()
    .Method("POST").Url("/api/users")
    .Header("Content-Type", "application/json")
    .Body("{\"name\":\"Alice\"}")
    .Build();
```

## Zusammenfassung
C# ist eine ausgefeilte, moderne Allzwecksprache mit hervorragenden Tools und einem starken Ökosystem. Es zeichnet sich durch Unternehmensentwicklung, Spieleentwicklung (Unity) und plattformübergreifende Anwendungen aus. Die Sprache hat sich rasant weiterentwickelt – modernes C# ist prägnant, ausdrucksstark und typsicher. Obwohl es nicht über die Ökosystemgröße von Java oder Python verfügt, machen die Qualität und Konsistenz von .NET C# zu einer produktiven und unterhaltsamen Sprache für eine Vielzahl von Anwendungen.
