# Zukunft und Trends
Eine strukturierte Sammlung von Referenzdokumenten zu neuen Technologien, gesellschaftlichen Veränderungen, domänenspezifischen Zukunftsaussichten und strategischen Zukunftsrahmen – sie untersuchen, was kommt und wie man sich darauf vorbereiten kann.
