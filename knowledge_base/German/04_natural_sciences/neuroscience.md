# Neurowissenschaften
Die Neurowissenschaften beschäftigen sich mit dem Nervensystem – dem Gehirn, dem Rückenmark und allen Nerven, die diese mit dem Körper verbinden. Es erstreckt sich über mehrere Ebenen: von Molekülen und Genen über einzelne Neuronen und Synapsen, Schaltkreise und Gehirnregionen bis hin zu Verhalten, Kognition und Bewusstsein. Das Gehirn ist die komplexeste Struktur im bekannten Universum und enthält etwa 86 Milliarden Neuronen, die durch Billionen von Synapsen verbunden sind, und zu verstehen, wie es funktioniert, ist eine der großen Herausforderungen der Wissenschaft.
---

## Das Neuron
### Teile eines Neurons
| Komponente | Funktion |
|-----------|----------|
| **Dendriten** | Signale von anderen Neuronen empfangen; verzweigte Erweiterungen |
| **Zellkörper (Soma)** | Integriert eingehende Signale; enthält den Kern |
| **Axon** | Lange Faser, die elektrische Signale (Aktionspotentiale) vom Soma weg überträgt |
| **Myelinscheide** | Isolierschicht um Axone; beschleunigt die Signalübertragung |
| **Knoten von Ranvier** | Lücken im Myelin; erlauben saltatorische Leitung (Signalsprünge zwischen Knoten) |
| **Axon-Terminals (synaptische Boutons)** | Neurotransmitter in die Synapse freisetzen |
### Arten von Neuronen
| Geben Sie | ein Richtung | Funktion |
|------|-----------|----------|
| **Sensorisch (afferent)** | Körper → Gehirn | Übertragen Sie Informationen von Sinnen (Berührung, Temperatur, Schmerz, Sehen usw.) |
| **Motor (efferent)** | Gehirn → Körper | Muskeln und Drüsen kontrollieren |
| **Interneurone** | Innerhalb des ZNS | Neuronen mit anderen Neuronen verbinden; Die meisten Neuronen sind Interneurone |

## Wie Neuronen kommunizieren
### Das Aktionspotential
| Phase | Beschreibung |
|-------|-------------|
| **Ruhepotential** | Neuron liegt bei ~-70 mV; Natrium-Kalium-Pumpe hält das Ionengleichgewicht aufrecht |
| **Depolarisation** | Der Reiz öffnet Natriumkanäle; Na+ strömt herein; Membranpotential steigt |
| **Schwellenwert** | Wenn das Potential ~-55 mV erreicht, wird ein Aktionspotential ausgelöst (Alles oder Nichts) |
| **Aufstiegsphase** | Spannungsgesteuerte Natriumkanäle öffnen sich; Potenzialspitzen auf ~+40 mV |
| **Fallende Phase** | Natriumkanäle schließen sich; Kaliumkanäle öffnen sich; K+ fließt aus; potenzielle Tropfen |
| **Unterschreitung (Hyperpolarisation)** | Potenzial sinkt kurzzeitig unter Ruheniveau |
| **Refraktärzeit** | Neuron kann nicht sofort wieder feuern; sorgt für eine Ausbreitung in eine Richtung |
### Die Synapse
| Komponente | Rolle |
|-----------|------|
| **Präsynaptisches Neuron** | Sendet das Signal; enthält synaptische Vesikel mit Neurotransmittern |
| **Synaptischer Spalt** | Winzige Lücke (~20 nm) zwischen Neuronen |
| **Postsynaptisches Neuron** | Empfängt das Signal; verfügt über Rezeptorproteine ​​|
| **Neurotransmitter** | Chemische Botenstoffe, die die Synapse passieren |
| **Rezeptoren** | Neurotransmitter binden; öffnen Ionenkanäle oder lösen Second-Messenger-Kaskaden aus |

## Wichtige Neurotransmitter
| Neurotransmitter | Funktion | Zugehörige Bedingungen |
|-----------------|----------|--------|
| **Glutamat** | Haupterregender Neurotransmitter; Lernen; Erinnerung | Überschuss → Exzitotoxizität (Schlaganfall, Neurodegeneration) |
| **GABA** | Haupthemmender Neurotransmitter; reduziert die neuronale Aktivität | Defizit → Angst, Epilepsie |
| **Dopamin** | Belohnen; Motivation; Motorsteuerung; Aufmerksamkeit | Defizit → Parkinson; Übermaß → Schizophrenie |
| **Serotonin** | Stimmung; schlafen; Appetit; Verdauung | Defizit → Depression, Angst |
| **Acetylcholin** | Muskelaktivierung; Lernen; Erinnerung | Defizit → Alzheimer-Krankheit |
| **Noradrenalin** | Erregung; Wachsamkeit; Stressreaktion | Dysregulation → ADHS; Depression |
| **Endorphine** | Schmerzlinderung; Vergnügen | Belastungsbedingte Freisetzung („Runner’s High“) |

## Gehirnstruktur
### Wichtige Gehirnregionen
| Region | Funktion |
|--------|----------|
| **Großhirnrinde** | Höhere Erkenntnis; unterteilt in Frontal-, Parietal-, Temporal- und Okzipitallappen |
| **Frontallappen** | Planung; Entscheidungsfindung; Persönlichkeit; willkürliche Bewegung (motorischer Kortex) |
| **Parietallappen** | Sensorische Verarbeitung; räumliches Bewusstsein; Navigation |
| **Temporallappen** | Anhörung; Sprachverständnis; Gedächtnis (Hippocampus) |
| **Hinterhauptslappen** | Visuelle Verarbeitung |
| **Kleinhirn** | Motorische Koordination; Gleichgewicht; motorisches Lernen; einige kognitive Funktionen |
| **Hirnstamm** | Lebenswichtige Funktionen: Atmung; Herzfrequenz; Schlaf-Wach-Zyklus |
| **Thalamus** | Sensorische Relaisstation; leitet Signale an die entsprechenden kortikalen Bereiche weiter |
| **Hypothalamus** | Homöostase; Hormonregulierung; Hunger; Durst; zirkadiane Rhythmen |
### Das Limbische System
| Struktur | Funktion |
|-----------|----------|
| **Amygdala** | Emotionale Verarbeitung; Furcht; Bedrohungserkennung; emotionales Gedächtnis |
| **Hippocampus** | Gedächtnisbildung; räumliche Navigation; wandelt das Kurzzeitgedächtnis in das Langzeitgedächtnis um |
| **Basalganglien** | Gewohnheitsbildung; Belohnungslernen; Motorsteuerung |
| **Cingulärer Kortex** | Fehlererkennung; Empathie; Impulskontrolle; Emotionsregulierung |
| **Nucleus accumbens** | Belohnungsrunde; Vergnügen; Sucht |

## Kognitive Neurowissenschaften
### Wichtige kognitive Funktionen und ihre Gehirnregionen
| Funktion | Primäre Gehirnbereiche |
|----------|-----|
| **Achtung** | Präfrontaler Kortex; parietaler Kortex; Thalamus |
| **Arbeitsspeicher** | Präfrontaler Kortex; parietaler Kortex |
| **Langzeitgedächtnis** | Hippocampus (Formation); Kortex (Speicher) |
| **Sprache** | Broca-Gebiet (Produktion); Wernickes Bereich (Verstehen) |
| **Emotionsregulation** | Präfrontaler Kortex; Amygdala; ventromedialer PFC |
| **Entscheidungsfindung** | Präfrontaler Kortex; orbitofrontaler Kortex; Striatum |
| **Visuelle Verarbeitung** | Hinterhauptslappen → ventraler Strom („was“) und dorsaler Strom („wo“) |
| **Motorsteuerung** | Motorischer Kortex; Kleinhirn; Basalganglien |
### Gehirnwellen
| Welle | Häufigkeit | Assoziierter Staat |
|------|-----------|-----------------|
| **Delta** | 0,5–4 Hz | Tiefschlaf |
| **Theta** | 4–8 Hz | Leichter Schlaf; Meditation; Schläfrigkeit |
| **Alpha** | 8–13 Hz | Entspannter Wachzustand; Augen geschlossen |
| **Beta** | 13–30 Hz | Aktives Denken; Fokus; Wachsamkeit |
| **Gamma** | 30–100 Hz | Höhere Erkenntnis; Bindung; Bewusstsein |

## Neuroplastizität
| Geben Sie | ein Beschreibung | Beispiel |
|------|-------------|---------|
| **Synaptische Plastizität** | Stärke der Synapsen ändert sich mit der Aktivität | Langzeitpotenzierung (LTP); Langzeitdepression (LTD) |
| **Strukturelle Plastizität** | Neuronen bilden neue Dendriten oder Axone | Neue Fähigkeiten erlernen; Erholung von einer Verletzung |
| **Kortikale Neuzuordnung** | Gehirnregionen weisen Funktionen neu zu | Der visuelle Kortex blinder Menschen verarbeitet Berührungen und Geräusche |
| **Neurogenese** | Neue Neuronen werden geboren | Kommt im Hippocampus vor; angeregt durch Bewegung und Lernen |

## Forschungsmethoden
| Methode | Was es misst | Auflösung |
|--------|---|------------|
| **fMRT** | Blutsauerstoffgehalt (BOLD-Signal) → Gehirnaktivität | Gute Räumlichkeit (~1 mm); schlechte Zeit (~1 s) |
| **EEG** | Elektrische Aktivität von der Kopfhaut | Hervorragend zeitlich (~1 ms); schlechte räumliche |
| **MEG** | Magnetfelder aus neuronaler Aktivität | Gute zeitliche und räumliche |
| **HAUSTIER** | Radioaktiver Tracer → Stoffwechselaktivität | Mäßig räumlich und zeitlich |
| **TMS** | Magnetische Impulse → Gehirnbereich vorübergehend stören | Kausaler Beweis; begrenzte Tiefe |
| **Einzelaufnahme** | Elektrische Aktivität einzelner Neuronen | Einzelzelle; invasiv; überwiegend Tierversuche |
| **Optogenetik** | Lichtaktivierte Neuronen | Präzise Kontrolle; Tierforschung |
| **DTI** (Diffusion Tensor Imaging) | Bahnen der weißen Substanz | Konnektivitätszuordnung |

## Neurologische und psychiatrische Störungen
| Störung | Betroffenes System | Hauptmerkmale |
|----------|----------------|--------------|
| **Alzheimer** | Kortex; Hippocampus | Gedächtnisverlust; Amyloid-Plaques; Tau-Verwicklungen |
| **Parkinson** | Substantia nigra; Basalganglien | Tremor; Steifigkeit; Verlust von Dopamin-Neuronen |
| **Epilepsie** | Großhirnrinde | Wiederkehrende Anfälle; abnormale elektrische Aktivität |
| **Multiple Sklerose** | Myelinscheide (ZNS) | Demyelinisierung; gestörte Signalübertragung |
| **Depression** | Präfrontaler Kortex; Limbisches System | Anhaltende schlechte Laune; Neurotransmitter-Ungleichgewicht |
| **Schizophrenie** | Mehrere Regionen | Halluzinationen; Wahnvorstellungen; Dopamin-Dysregulation |
| **ALS** | Motoneuronen | Fortschreitende Muskelschwäche; Tod von Motoneuronen |

## Zusammenfassung
Die Neurowissenschaften untersuchen das Nervensystem auf allen Ebenen – von den molekularen Mechanismen der Ionenkanäle bis hin zur subjektiven Erfahrung des Bewusstseins. Neuronen kommunizieren über elektrische Aktionspotentiale und chemische Synapsen und nutzen dabei Neurotransmitter wie Glutamat, GABA, Dopamin und Serotonin. Das Gehirn ist in spezialisierte Regionen unterteilt: den Kortex für höhere kognitive Fähigkeiten, das limbische System für Emotionen und Erinnerungen, das Kleinhirn für Koordination. Neuroplastizität bedeutet, dass sich das Gehirn im Laufe des Lebens neu vernetzen kann. Die Forschungsmethoden reichen von fMRT (gute räumliche Auflösung) über EEG (gute zeitliche Auflösung) bis hin zur Optogenetik (präzise kausale Kontrolle). Das Gehirn zu verstehen ist wohl das schwierigste Problem in der Wissenschaft – es ist das einzige Organ, das sich selbst erforscht.
