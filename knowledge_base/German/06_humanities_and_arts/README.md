# Geisteswissenschaften und Kunst
Eine strukturierte Sammlung von Referenzdokumenten zu Geschichte, Kunst, Sprache, Philosophie, Psychologie und Religion – den Kerndisziplinen der Geisteswissenschaften, die einen Kontext für das Verständnis der menschlichen Zivilisation, des kreativen Ausdrucks und des kritischen Denkens bieten.
## Struktur
