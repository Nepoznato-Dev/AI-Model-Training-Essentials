# Goresan — Riwayat Versi & Evolusi
## Garis Waktu
| Versi | Tahun | Tema Utama |
|---------|------|-----------|
| Pra-Gores | 2003 | Formulir Tim Gores di MIT Media Lab |
| Gores 1.0 | 2007 | **Rilis awal** — pemrograman visual untuk anak-anak |
| Gores 1.4 | 2009 | Peningkatan grafis, lebih banyak blok |
| Gores 2.0 | 2013 | **Utama**: Editor berbasis web, variabel cloud, ransel |
| Gores 3.0 | 2019 | **Mayor**: Penulisan ulang lengkap (HTML5/JS), ekstensi, pena |
| Gores 3.x | 2019–25 | Penginderaan video, text-to-speech, terjemahan, mikro:bit |
| Gores Jr | 2014 | Versi sederhana untuk anak kecil (5-7) |
| Gores Desktop | 2020 | Editor offline (berbasis elektron) |
## Tonggak Penting
### Asal (2003–2006)
- **2003**: Kelompok TK Seumur Hidup MIT Media Lab memulai pengembangan Scratch
- Dipimpin oleh Mitchel Resnick
- **Tujuan**: Mengajarkan pemrograman kepada anak-anak melalui blok visual
- Terinspirasi oleh: Logo (Seymour Papert), Logo Lego, Squeak Etoys
- Nama: "Scratch" — dari DJ scratching (mencampur media bersama-sama)
### Gores 1.0 (2007)
- **2007**: Rilis publik pertama
- Pemrograman blok drag-and-drop
- Proyek berbasis sprite (karakter, animasi)
- Suara, grafik, animasi
- Dibangun di Squeak (Obrolan Kecil)
- **Target**: Usia 8-16 tahun, namun penerapannya jauh lebih luas
### Gores 1.4 (2009)
- Peningkatan rendering grafis
- Lebih banyak perpustakaan sprite
- Dukungan suara yang lebih baik
- Versi terakhir dibangun di atas Squeak
### Gores 2.0 (2013)
- **Editor berbasis web lengkap** — berjalan di browser
- Variabel cloud — berbagi data antar proyek
- Backpack — berbagi sprite/skrip antar proyek
- Blok khusus (seperti fungsi)
- Dibangun pada ActionScript 3 (Flash)
- Fitur komunitas: remix, bagikan, komentar
### Gores 3.0 (2019)
- **Selesaikan penulisan ulang** — HTML5/JavaScript (tanpa Flash)
- Berfungsi di tablet, ponsel, Chromebook
- **Ekstensi**:
  - Pena (menggambar)
  - Penginderaan Video (kamera)
  - Teks ke Ucapan
  - Terjemahan (Google Terjemahan)
  - mikro:bit (perangkat keras)
  - LEGO Mindstorms EV3
  - Kami Melakukan 2.0
- Peningkatan editor suara
- Editor cat baru (vektor + bitmap)
- Ransel, variabel cloud dipertahankan
### Scratch Desktop & Beyond (2020–sekarang)
- **2020**: Scratch Desktop — editor offline (berbasis elektron)
- Pengembangan ekstensi yang berkelanjutan
- Ekstensi AI/ML (buatan komunitas)
- Integrasi dengan komputasi fisik (mikro:bit, Arduino)

  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0

## Konsep Pemrograman Diajarkan
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Prinsip Desain Utama
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
