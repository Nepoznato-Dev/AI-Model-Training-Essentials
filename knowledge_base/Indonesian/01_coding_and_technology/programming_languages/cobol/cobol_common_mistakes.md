# COBOL — Kesalahan Umum & Anti-Pola
Dokumen ini mengkatalogkan kesalahan, jebakan, dan anti-pola paling umum di COBOL dengan koreksinya.
---

## 1. Tidak Menggunakan Nama Kondisi Tingkat 88
```cobol
* ❌ WRONG — magic numbers
01  STATUS-CODE     PIC 9.
    88  STATUS-ACTIVE   VALUE 1.
    88  STATUS-INACTIVE VALUE 2.

IF STATUS-CODE = 1  * what does 1 mean?
```

```cobol
* ✅ CORRECT — use 88-level for readability
01  STATUS-CODE     PIC 9.
    88  STATUS-ACTIVE   VALUE 1.
    88  STATUS-INACTIVE VALUE 2.

IF STATUS-ACTIVE
    PERFORM PROCESS-RECORD
END-IF
```

---

## 2. Luapan Numerik
```cobol
* ❌ WRONG — field too small
01  TOTAL    PIC 9(4).  * max 9999
COMPUTE TOTAL = A + B.   * silent truncation if > 9999

* ✅ CORRECT — adequate size or check ON SIZE ERROR
01  TOTAL    PIC 9(10).
COMPUTE TOTAL = A + B
    ON SIZE ERROR
        DISPLAY "Overflow!"
END-COMPUTE
```

---

## 3. Tidak Menginisialisasi Variabel
```cobol
* ❌ WRONG — uninitialized data
01  COUNTER  PIC 9(5).
* contains garbage from previous run

* ✅ CORRECT — VALUE clause
01  COUNTER  PIC 9(5) VALUE ZERO.
```

---

## 4. BERFORMASI Tanpa Batasan Eksplisit
```cobol
* ❌ WRONG — unbounded PERFORM
PERFORM PROCESS-RECORD UNTIL EOF-FLAG = 'Y'.
* if EOF-FLAG never set, infinite loop

* ✅ CORRECT — bounded PERFORM
PERFORM PROCESS-RECORD
    VARYING I FROM 1 BY 1
    UNTIL I > MAX-RECORDS
END-PERFORM
```

---

## 5. Tidak Menggunakan Fitur COBOL Modern
```cobol
* ❌ WRONG — old-style COBOL
MOVE SPACES TO WS-NAME.
IF WS-NAME = SPACES
    DISPLAY "EMPTY"
END-IF.

* ✅ CORRECT — modern COBOL (2002+)
IF FUNCTION TRIM(WS-NAME) = ""
    DISPLAY "EMPTY"
END-IF
```

---

## Ringkasan
Sintaks verbose COBOL menyembunyikan jebakan: angka ajaib tanpa nama kondisi tingkat 88, luapan numerik dari klausa PIC berukuran kecil, variabel yang tidak diinisialisasi, dan loop PERFORM tanpa batas. COBOL modern (2002+) menambahkan FUNCTION TRIM, inline PERFORM, dan peningkatan lainnya. Cara COBOLnya adalah: gunakan nama kondisi 88 level, centang ON SIZE ERROR, inisialisasi dengan VALUE, dan ikat semua loop.
