- Tingkat kesulitan dicatat jika berlaku
- Latihan dan soal latihan disertakan dalam file teknis
- Bantuan visual (diagram, tabel) digunakan jika membantu

## 📝 Berkontribusi

Saat menambahkan atau memodifikasi konten:

1. **Ikuti panduan gaya:**
   - Gunakan `#` hanya untuk judul file
   - Gunakan `##` untuk bagian utama
   - Gunakan `###` untuk subbagian
   - Gunakan `-` untuk daftar tidak berurut
   - Sertakan penyorotan sintaks dalam blok kode

2. **Tambahkan metadata** (frontmatter YAML):
```yaml
---
title: "Judul File"
description: "Deskripsi singkat"
topics: [topik1, topik2, topik3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Sertakan kutipan** untuk klaim faktual
4. **Tambahkan referensi silang** ke file terkait
5. **Perbarui README ini** jika menambahkan file baru
