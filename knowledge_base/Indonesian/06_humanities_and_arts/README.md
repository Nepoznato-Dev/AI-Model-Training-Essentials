# Humaniora dan Seni
Kumpulan dokumen referensi terstruktur yang mencakup sejarah, seni, bahasa, filsafat, psikologi, dan agama — disiplin inti humaniora yang memberikan konteks untuk memahami peradaban manusia, ekspresi kreatif, dan pemikiran kritis.
