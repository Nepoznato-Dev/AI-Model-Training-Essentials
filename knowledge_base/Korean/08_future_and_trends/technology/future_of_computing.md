# 컴퓨팅의 미래
컴퓨팅의 미래는 지난 60년 동안의 기본 가정에 도전하는 힘에 의해 형성되고 있습니다. 컴퓨팅 성능이 약 2년마다 두 배로 증가한다는 무어의 법칙이 둔화되고 있습니다. CPU와 메모리가 분리된 폰 노이만 아키텍처가 '메모리 벽'에 부딪히고 있습니다. 양자 컴퓨팅은 기존 컴퓨터가 해결할 수 없는 문제를 해결할 것을 약속합니다. 뉴로모픽 칩은 뇌의 구조를 모방합니다. 엣지 컴퓨팅은 처리를 중앙 집중식 데이터 센터에서 멀리 이동시킵니다. 그리고 AI는 명령을 실행하는 도구에서 학습하고 생성하고 추론하는 시스템으로 컴퓨터의 용도를 변화시키고 있습니다. 이러한 변화를 이해하는 것은 기술을 구축, 구매 또는 의존하는 모든 사람에게 중요합니다.
---

## 무어의 법칙의 종말
### 무슨 일이에요
| 시대 | 트랜지스터 크기 | 동향 |
|------|---|-------|
| **1970년대~2000년대** | 10,000nm → 130nm | 기하급수적 성장; 성능은 2년마다 두 배로 증가 |
| **2000년대~2010년대** | 130nm → 22nm | 성장은 지속됐으나 전력밀도 문제 발생 |
| **2010년대~2020년대** | 22nm → 3nm | 감속; 각 노드의 비용은 더 높습니다. 혜택이 감소 |
| **2020년대+** | 3nm → 1nm 미만 | 원자 한계에 접근하고 있습니다. 양자 효과 간섭 |
### 중요한 이유
| 결과 | 설명 |
|-------------|-------------|
| **성능 향상 속도 느림** | 무료 성능 향상을 위해 더 작은 트랜지스터에 의존할 수 없음 |
| **전문성** | 범용 CPU가 도메인별 가속기(GPU, TPU, NPU)에 자리를 내주다 |
| **소프트웨어 효율성이 중요합니다** | 하드웨어로는 무차별 공격을 할 수 없습니다. 알고리즘과 코드 품질이 더욱 중요해졌습니다 |
| **새로운 아키텍처 필요** | 폰 노이만 병목 현상; 메모리 벽; 전원 벽 |

## 양자 컴퓨팅
### 기초
| 개념 | 설명 |
|---------|-------------|
| **큐빗** | 퀀텀비트; 0, 1 또는 둘 다의 중첩일 수 있습니다 |
| **중첩** | 큐비트는 측정될 때까지 동시에 여러 상태로 존재 |
| **얽힘** | 두 개의 큐비트가 상관됩니다. 하나를 측정하면 즉시 다른 하나가 결정됩니다 |
| **간섭** | 양자 알고리즘은 정답을 증폭하고 잘못된 답을 취소 |
| **결맞음** | 큐빗은 환경과의 상호작용을 통해 양자 특성을 잃습니다. 주요 엔지니어링 과제 |
### 양자 대 고전
| 측면 | 클래식 | 양자 |
|---------|------------|---------|
| **기본단위** | 비트(0 또는 1) | Qubit(0과 1의 중첩) |
| **운영** | 논리 게이트(AND, OR, NOT) | 양자 게이트(Hadamard, CNOT 등) |
| **병렬성** | 한 번에 하나의 계산(또는 여러 개의 독립적인 계산) | 중첩을 통해 여러 가능성을 동시에 탐색할 수 있음 |
| **확장** | n 비트 = n 값 | n 큐비트 = 중첩된 2^n 값 |
| **오류율** | 매우 낮음 | 현재 높음; 오류 수정이 필요합니다 |
### Quantum이 탁월한 응용 분야
| 신청 | Quantum이 도움이 되는 이유 | 타임라인 |
|-------------|------|----------|
| **암호화** | Shor의 알고리즘은 RSA 암호화를 깨뜨릴 수 있습니다 | 현재 암호화를 위협합니다. 포스트 양자 암호화 개발 중 |
| **약물 발견** | 양자 수준에서 분자 상호 작용 시뮬레이션 | 실질적인 영향을 미치는 데 5~15년 |
| **최적화** | 방대한 검색 공간에서 최적의 솔루션 찾기 | 기호 논리학; 재원; 재료과학 |
| **머신러닝** | 특정 ML 알고리즘의 양자 속도 향상 | 초기 연구; 아직 불분명한 실질적인 이점 |
| **재료과학** | 원자 수준에서 신소재 시뮬레이션 | 배터리 재료; 촉매; 초전도체 |
### 현재 상태
| 회사/프로젝트 | 접근 | 큐비트 | 상태 |
|------|----------|---------|--------|
| **IBM** | 초전도 | 1,000+ | 콘도르 프로세서; 실제 문제에 대해서는 아직 입증되지 않은 양자 이점 |
| **구글** | 초전도 | 70세 이상 | 플라타너스; 특정 작업에 대한 양자 우위 주장(2019) |
| **이온Q** | 갇힌 이온 | 30+ (고충실도) | 높은 정확도; 느린 게이트 속도 |
| **양자** | 갇힌 이온 | 50세 이상 | 하니웰(Honeywell) + 캠브리지 퀀텀(Cambridge Quantum) 합병 |
| **사이퀀텀** | 포토닉 | 비공개 | 100만 큐비트 목표 |
| **마이크로소프트** | 토폴로지 | 연구단계 | 이론적으로 가장 오류에 강합니다. 구축하기가 가장 어렵다 |

## 뉴로모픽 컴퓨팅
| 측면 | 설명 |
|---------|-------------|
| **영감** | 뇌의 신경 구조 - 뉴런과 시냅스 |
| **주요 차이점** | 처리와 메모리는 같은 위치에 있습니다(시냅스처럼). 폰 노이만 병목 현상 없음 |
| **스파이킹 신경망** | 뉴런은 개별 스파이크를 통해 통신합니다. 에너지 효율 |
| **이벤트 중심** | 활성 뉴런만 전력을 소비합니다. 유휴 뉴런은 무료입니다 |
| **하드웨어 예** | 인텔 로이히; IBM 북극; 스피네이커 |
| **애플리케이션** | 엣지 AI; 로봇공학; 감각 처리; 항상 켜져 있는 장치 |

## 엣지 컴퓨팅
### 왜 엣지인가?
| 드라이버 | 설명 |
|---------|-------------|
| **지연 시간** | 로컬에서 데이터를 처리하면 클라우드로의 왕복이 방지됩니다 |
| **대역폭** | 모든 데이터를 클라우드로 전송할 필요는 없습니다(예: 보안 카메라의 비디오) |
| **개인정보보호** | 민감한 데이터가 기기에 유지됨 |
| **신뢰성** | 연결이 간헐적으로 중단될 때 작동 |
| **비용** | 클라우드 컴퓨팅 및 데이터 전송 비용 절감 |
### 엣지 컴퓨팅 스펙트럼
| 위치 | 대기 시간 | 사용 사례 |
|------------|---------|----------|
| **온디바이스**(전화, IoT) | <1ms | 음성인식; 카메라 처리 |
| **가장자리 근처**(게이트웨이, 기지국) | 1~10ms | 산업 제어; 자율주행차 |
| **원거리**(지역 데이터 센터) | 10~50ms | 콘텐츠 전달; 게임 |
| **클라우드**(중앙 데이터 센터) | 50~200ms | 훈련; 일괄 처리; 분석 |

## AI 하드웨어
### AI 가속기의 종류
| 하드웨어 | 힘 | 약점 | 예 |
|------------|------------|------------|---------|
| **GPU** | 대규모 병렬; 훈련 및 추론에 적합 | 전력에 굶주린; 범용 | 엔비디아 H100; AMD MI300 |
| **TPU**(텐서 처리 장치) | 텐서 작업을 위해 설계되었습니다. 효율적인 | GPU보다 유연성이 떨어짐 | 구글 TPU v5 |
| **NPU**(신경 처리 장치) | 온디바이스 AI 추론; 전력 효율적 | 추론으로 제한됩니다. 더 작은 모델 | 애플 신경 엔진; 퀄컴 헥사곤 |
| **FPGA** | 재구성 가능; 낮은 대기 시간 | 프로그래밍하기가 더 어렵습니다. 더 작은 생태계 | 인텔 애질렉스; 자일링스 Versal |
| **ASIC** | 특정 AI 워크로드에 맞게 맞춤 설계됨 | 디자인 비용이 많이 듭니다. 융통성이 없는 | Google TPU(ASIC이기도 함) 대뇌 |
| **웨이퍼 규모** | 전체 웨이퍼는 하나의 칩입니다. 대규모 병렬성 | 소설; 비싼 | 대뇌 WSE-3 |
### 기억의 벽
| 문제 | 설명 | 솔루션 |
|---------|-------------|------------|
| **폰 노이만 병목현상** | 데이터는 CPU와 메모리 사이를 이동해야 합니다. 이 전송은 계산보다 느립니다 | 근거리 메모리 컴퓨팅; 메모리 내 처리 |
| **메모리 대역폭** | AI 모델은 수십억 개의 매개변수를 읽어야 합니다. 메모리가 데이터를 충분히 빠르게 공급할 수 없음 | 고대역폭 메모리(HBM); 압축 |
| **메모리 용량** | 대형 모델은 빠른 메모리에 맞지 않습니다 | 모델 병렬성 느린 스토리지로 오프로드 |

## 요약
컴퓨팅의 미래는 단순히 과거의 연속이 아닙니다. 무어의 법칙이 둔화되면서 범용 프로세서에서 특수 가속기로 전환이 불가피해지고 있습니다. 양자 컴퓨팅은 암호화, 신약 개발, 재료 과학 등 특정 문제에 대해 기하급수적인 속도 향상을 약속하지만 실용적이고 오류가 수정된 양자 컴퓨터는 아직 수년이 걸립니다. 뉴로모픽 칩은 에너지 효율적인 엣지 AI를 위해 뇌의 아키텍처를 모방합니다. 엣지 컴퓨팅은 대기 시간을 줄이고 개인 정보 보호를 강화하기 위해 처리를 데이터 소스에 더 가깝게 이동합니다. AI 하드웨어는 다양화되고 있습니다. GPU, TPU, NPU, FPGA 및 맞춤형 ASIC은 각각 서로 다른 요구 사항을 충족합니다. 프로세서 속도와 메모리 대역폭 사이의 격차인 메모리 벽은 니어 메모리 컴퓨팅의 혁신을 주도하는 근본적인 병목 현상입니다. 포스트 실리콘 기술(포토닉스, 스핀트로닉스, 탄소 나노튜브)은 연구 중이지만 지금부터 수십 년 후에 컴퓨팅을 재편할 수 있습니다. 가장 중요한 주제는 전문화입니다. 일률적인 컴퓨팅 시대는 끝나고 특정 작업 부하에 최적화된 이기종 시스템으로 대체됩니다.
