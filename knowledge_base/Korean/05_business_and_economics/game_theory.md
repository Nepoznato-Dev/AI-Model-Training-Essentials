# 게임이론과 전략적 사고
게임 이론은 전략적 상호 작용, 즉 결과가 자신이 하는 일뿐만 아니라 다른 사람이 하는 일에 따라 달라지는 상황에 대한 수학적 연구입니다. 이는 비즈니스 경쟁, 국제 관계, 경매, 협상, 진화 생물학 및 교통 경로 선택과 같은 일상적인 결정 등 모든 곳에 적용됩니다. 핵심 통찰은 전략적 상황에서 합리적인 행위자가 자신의 전략을 최적화하는 데 그치지 않고 다른 사람이 무엇을 할지 예상하고 다른 사람도 똑같이 한다는 것입니다.
---

## 기본 개념
### 주요 용어
| 기간 | 정의 |
|------|------------|
| **게임** | 두 명 이상의 의사결정자(플레이어)의 선택이 서로의 결과에 영향을 미치는 상황 |
| **플레이어** | 게임의 의사결정자 |
| **전략** | 발생할 수 있는 모든 상황에 대한 완전한 행동 계획 |
| **보상** | 플레이어가 특정 전략 조합을 통해 받는 결과 |
| **내쉬 균형** | 어떤 플레이어도 일방적으로 전략을 변경하여 보상을 향상시킬 수 없는 일련의 전략 |
| **지배적 전략** | 다른 플레이어가 무엇을 하든 최선의 전략 |
| **제로섬 게임** | 한 플레이어의 이득은 정확히 다른 플레이어의 손실입니다 |
| **넌제로섬 게임** | 플레이어는 잠재적으로 모두 이득을 얻거나 모두 잃을 수 있습니다 |
| **협력 게임** | 플레이어는 구속력 있는 계약을 체결할 수 있습니다 |
| **비협조적 게임** | 구속력 있는 계약이 없습니다. 각 플레이어는 자기 이익을 위해 행동합니다 |

## 클래식 게임
### 죄수의 딜레마
용의자 2명이 체포됐다. 각자는 협력(침묵)할 수도 있고, 배신(고백)할 수도 있습니다.
| | B 협력 | B 결함 |
|---|-------------|----------|
| **A협력사** | A: 1년, B: 1년 | A: 10년, B: 무료 |
| **결함** | A: 무료, B: 10년 | A: 5년, B: 5년 |
| 통찰력 | 설명 |
|---------|-------------|
| **지배적 전략** | 두 선수 모두 결함이 지배적입니다 |
| **내쉬 균형** | 둘 다 불량(각 5년) |
| **파레토 최적** | 협력(각 1년) |
| **강의** | 개인의 합리적인 결정은 집단적으로 더 나쁜 결과를 초래할 수 있습니다 |
### 기타 고전 게임
| 게임 | 설명 | 내쉬 균형 | 레슨 |
|------|-------------|----|---------|
| **닭(매비둘기)** | 두 명의 운전자가 서로를 향해 향하고 있습니다. 방향을 바꾸거나 직진 | 하나는 방향을 바꾸고 하나는 직진 | 극단 정책; 헌신의 신뢰성 |
| **사슴 사냥** | 수사슴을 함께 사냥하거나(높은 보상) 혼자 토끼를 사냥(낮은 보상) | 수사슴 또는 둘 다 토끼 | 조정; 신뢰 |
| **성별 전투** | 두 플레이어는 서로 다른 결과를 선호하지만 조정을 원합니다 | 둘 다 같은 이벤트에 참여 | 다중 평형; 먼저 움직이는 사람이 유리하다 |
| **최후통첩 게임** | 제안자는 돈을 나눕니다. 응답자가 수락하거나 거부합니다(둘 다 아무것도 얻지 못함) | 제안자는 최소 제안을 제공합니다. 응답자가 수락합니다 | 부당한 제안을 거부하는 사람들(비합리적이지만 흔한 일) |
| **공공용품 게임** | 공유 수영장에 참여하거나 무임승차 | 모두 무임승차 | 공유지의 비극; 시행이 필요함 |

## 게임 종류
### 타이밍별
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **동시** | 플레이어는 동시에 이동합니다(또는 다른 사람의 이동을 모르고) | 가위바위보; 봉인입찰 경매 |
| **순차** | 플레이어는 차례로 이동합니다. 나중에 플레이어가 이전 움직임을 관찰합니다 | 체스; 시장 진입 결정 |
| **반복** | 같은 게임을 여러 번 플레이 | 반복되는 죄수의 딜레마; 지속적인 비즈니스 경쟁 |
### 정보별
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **완벽한 정보** | 모든 플레이어는 이전 동작을 모두 알고 있습니다 | 체스; 체커 |
| **불완전한 정보** | 일부 동작이 숨겨져 있습니다 | 포커; 비즈니스 경쟁 |
| **전체 정보** | 모든 플레이어는 모든 보상과 전략을 알고 있습니다 | 대부분의 교과서 게임 |
| **불완전한 정보** | 일부 보수 또는 유형을 알 수 없음 | 경매; 협상 |

## 솔루션 개념
### 내쉬 균형
| 측면 | 설명 |
|---------|-------------|
| **정의** | 어떤 플레이어도 전략만 변경하여 보상을 향상시킬 수 없습니다 |
| **찾는 방법** | 각 플레이어에 대해 다른 사람의 전략에 대한 최선의 대응을 찾으십시오. 그것들이 모두 교차하는 곳은 내쉬 균형입니다 |
| **존재** | 모든 유한 게임에는 적어도 하나의 내쉬 균형이 있습니다(혼합 전략에서 가능) |
| **독창성** | 게임은 여러 내쉬 균형을 가질 수 있습니다. 조정 문제가 발생합니다 |
| **제한사항** | 내쉬 균형은 어떤 균형이 선택될 것인지 알려주지 않습니다. 공정성을 설명하지 않습니다 |
### 지배적 전략 균형
| 단계 | 설명 |
|------|-------------|
| **1. 전략 파악** | 각 플레이어에게 사용 가능한 모든 전략 나열 |
| **2. 지배적인 전략 찾기** | 남들이 어떻게 하든 최선을 다하는 전략 |
| **3. 모든 플레이어가 하나를 가지고 있는 경우** | 조합은 지배적 전략 균형이다 |
| **4. 그렇지 않은 경우** | 지배 전략 또는 내쉬 균형의 반복 제거 사용 |
### 역방향 유도(순차적 게임)
| 단계 | 설명 |
|------|-------------|
| **1. 게임 트리 그리기** | 노드 = 결정 지점; 가지 = 행동 |
| **2. 끝에서 시작** | 각 터미널 노드에서 마지막 플레이어의 최적 선택 식별 |
| **3. 거꾸로 작업** | 각 이전 노드에서 최상의 결과를 가져오는 작업을 선택합니다 |
| **4. 결과** | 하위 게임 완벽한 균형 — 모든 결정 지점에서 최적의 전략 |

## 고급 개념
### 혼합 전략
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **혼합 전략** | 확률에 따라 행동 간 무작위화 | 가위바위보: 각각 1/3의 확률로 플레이 |
| **왜 무작위로 선택해야 하나요?** | 상대방이 당신의 움직임을 예측하는 것을 방지합니다 | 축구의 페널티킥; 세무조사 |
| **혼합 전략 내쉬 균형** | 각 플레이어는 자신의 순수한 전략에 무관심합니다 | 어느 플레이어도 상대방을 악용할 수 없습니다 |
### 반복게임과 민속정리
| 개념 | 설명 |
|---------|-------------|
| **무한히 반복됨** | 역진 귀납은 협력을 풀어줍니다. 원샷 게임과 동일 | 막판 탈북, 거꾸로 전파 |
| **무한반복** | 향후 처벌 위협을 통해 협력을 유지할 수 있다 | 맞대응; 암울한 방아쇠 전략 |
| **민속정리** | 무한히 반복되는 게임에서는 개별적으로 합리적인 보상이 내쉬 균형이 될 수 있습니다 | 미래가 중요하다면 협력은 가능하다 |
| **할인 요소** | 플레이어가 미래 보상을 얼마나 중요하게 생각하는지; 더 높다 = 더 많은 협력 | 환자 플레이어가 더 협력 |
### 메커니즘 설계(역게임 이론)
| 개념 | 설명 |
|---------|-------------|
| **목표** | 원하는 결과를 달성하기 위한 게임 규칙 설계 |
| **애플리케이션** | 경매; 투표 시스템; 계약 설계; 시장 디자인 |
| **계시원리** | 어떤 메커니즘으로든 달성할 수 있는 모든 결과는 진실되고 직접적인 메커니즘을 통해 달성될 수 있습니다 |
| **예** | Vickrey 경매(2차 가격 봉인 입찰) - 귀하의 진정한 가치를 입찰하는 것이 지배적인 전략입니다 |

## 요약
게임 이론은 결과가 다른 사람의 행동에 따라 달라지는 전략적 상호 작용을 연구합니다. 전략만 변경하면 어떤 플레이어도 이익을 얻지 못하는 내쉬 균형이 핵심 솔루션 개념입니다. 죄수의 딜레마와 같은 고전 게임은 개인의 합리적인 결정이 전체적으로 나쁜 결과를 낳을 수 있음을 보여줍니다. 순차 게임은 역진 귀납법으로 해결됩니다. 반복되는 게임은 미래의 처벌에 대한 위협을 통해 협력을 유지할 수 있습니다. 혼합 전략에는 예측할 수 없도록 무작위화가 포함됩니다. 메커니즘 설계는 질문을 뒤집습니다. 즉, 결과를 예측하는 대신 (경매에서와 같이) 원하는 결과를 달성하기 위한 규칙을 설계합니다. 응용 프로그램은 비즈니스(가격 책정, 진입, 경매), 정치(투표, 조약), 생물학(진화 안정 전략) 및 일상 생활에 걸쳐 있습니다. 근본적인 교훈은 전략은 단지 당신이 무엇을 하는지에 관한 것이 아니라 다른 사람들이 무엇을 할 것인지를 예상하고 그들도 같은 일을 하고 있다는 것을 아는 것에 관한 것이라는 것입니다.
