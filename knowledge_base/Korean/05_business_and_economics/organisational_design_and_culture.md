# 조직 디자인과 문화
조직설계는 전략을 효과적으로 실행하기 위해 구조, 프로세스, 역할, 의사결정 권한을 의도적으로 배열하는 것입니다. 문화는 사람들이 실제로 함께 일하는 방식을 형성하는 공유된 가치, 신념, 규범 및 행동입니다. 구조는 프레임워크를 제공합니다. 문화는 행동을 형성한다. 구조는 서류상으로 재설계될 수 있지만 문화가 변경을 지원하지 않으면 구현이 실패합니다. 마찬가지로, 비효율적인 구조와 결합된 강력한 문화는 점차적으로 조직 성과를 약화시킬 것입니다. 가장 효과적인 조직은 두 가지 모두를 해결하고 두 가지가 서로 깊게 연결되어 있음을 인식합니다.

## 조직 구조
### 공통 구조
| 구조 | 설명 | 강점 | 약점 |
|------------|-------------|------------|------------|
| **기능적** | 전문 분야(엔지니어링, 마케팅, 영업)별로 그룹화 | 깊은 전문성; 능률; 명확한 진로 | 사일로; 느린 부서 간 조정 |
| **부문별** | 제품, 시장 또는 지역별로 그룹화 | 고객/시장에 초점을 맞춥니다. 손익 책임 | 기능의 중복; 자원 경쟁 |
| **매트릭스** | 이중 보고: 기능 + 제품/프로젝트 | 유연성; 부서간 협업 | 착란; 권력 투쟁; 느린 결정 |
| **평면/수평** | 관리 계층이 거의 없습니다. 광범위한 통제 | 빠른 결정; 권한이 부여된 직원; 낮은 오버헤드 | 확장이 어렵습니다. 불분명한 보고 |
| **팀 기반** | 다기능 팀을 중심으로 구성됨 | 자치; 속도; 고객 중심 | 팀 간 조정 일관성 |
| **네트워크/플랫폼** | 핵심 팀 + 외부 파트너; 플랫폼은 다른 사람들을 가능하게 합니다 | 확장성; 유연성; 자산 경량화 | 품질 관리; 파트너 의존도 |
| **홀라크라시** | 자체 관리 팀 책임으로 정의된 역할 | 높은 자율성; 적응 | 혼란스럽다; 모든 사람에게 작동하지 않습니다 |
### 통제 범위
| 요인 | 좁은 스팬(4-6) | 넓은 범위(10-15+) |
|---------|------|-------|
| **관리 레이어** | 많은 | 거의 |
| **감독** | 닫다; 실습 | 위임됨; 손을 떼다 |
| **최고의 대상** | 복잡한 작업; 경험이 부족한 팀 | 일상적인 작업 경험이 풍부하고 자율적인 팀 |
| **위험** | 미세관리; 느린 결정 | 지원 부족; 조정 격차 |
### 중앙화 vs 탈중앙화
| 차원 | 중앙 집중식 | 탈중앙화 |
|------------|------------|---------------|
| **의사결정** | 하향식 | 가장자리로 밀린 |
| **속도** | 느림(상단에 병목 현상) | 신속함(현지에서 결정) |
| **일관성** | 높음 | 변수 |
| **혁신** | 상단의 대역폭에 의해 제한됨 | 여러 소스에서 나타남 |
| **최고의 대상** | 위기; 초기 단계; 규정 준수 산업 | 지식작업; 빠르게 움직이는 시장; 규모 확대 |

## 디자인 원칙
### 조직 설계의 주요 결정
| 결정 | 질문 | 옵션 |
|------------|------------|---------|
| **부서화** | 사람들을 어떻게 그룹화합니까? | 기능별; 제품; 고객; 지리학; 프로세스 |
| **지휘계통** | 누가 누구에게 보고하나요? | 명확한 계층 구조; 행렬; 네트워크 |
| **결정권** | 누가 무엇을 결정하나요? | 중앙 집중식; 분산화; RACI 매트릭스 |
| **조정 메커니즘** | 팀은 어떻게 협력하나요? | 연락 역할 다기능 팀; 통합자; 공유된 목표 |
| **표준화** | 표준화된 비용과 로컬 비용은 얼마입니까? | 프로세스; 출력; 기술; 규범 |
### 갤브레이스의 스타 모델
| 요소 | 설명 |
|---------|-------------|
| **전략** | 방향; 목표; 경쟁우위; 조직이 존재하는 이유 |
| **구조** | 보고관계 계층; 단위 그룹화 |
| **프로세스** | 정보 흐름; 의사결정; 계획; 예산 책정 |
| **보상** | 인센티브; 성능 측정; 전략과의 연계 |
| **사람** | 채용; 개발; 문화; 인간의 능력 |
핵심 통찰력: 전략이 구조를 주도합니다. 다른 모든 요소는 정렬되어야 합니다. 프로세스, 보상, 인력 개발을 변경하지 않고 구조를 변경하면 실패합니다.

## 조직문화
### 문화란 과연 무엇인가
| 레이어 | 설명 | 가시성 |
|-------|-------------|----------|
| **아티팩트** | 눈에 보이는 구조, 프로세스, 행동, 복장 규정, 사무실 배치 | 보기 쉽습니다. 해석하기 어렵다 |
| **신앙받는 가치** | 명시된 전략, 목표, 철학, 사명 선언문 | 공개적으로 선언되었습니다. 실제 동작과 일치하지 않을 수 있음 |
| **기본 가정** | 무의식, 당연한 믿음, 인식, 생각, 감정 | 보이지 않는; 행동의 진정한 동인 |
### 문화 유형(경쟁 가치 프레임워크)
| 문화 | 집중 | 특징 | 예 |
|---------|---------|---|---------|
| **클랜**(협력) | 내부 + 유연성 | 가족같은; 멘토링; 팀워크; 합의 | 자포스; 소규모 스타트업 |
| **애드호크라시**(만들기) | 외부 + 유연성 | 혁신적인; 위험 감수; 기업가적; 동적 | 구글(초기); 스페이스X |
| **시장**(경쟁) | 외부 + 제어 | 결과 지향; 경쟁력 있는; 목표 중심; 시장점유율 | 아마존; 월스트리트 기업 |
| **계층 구조**(제어) | 내부 + 제어 | 구조화; 프로세스 중심; 능률; 일관성 | 정부 기관 군대; 전통적인 은행 |
### 문화적 차원
| 차원 | 설명 |
|------------|-------------|
| **심리적 안전** | 사람들이 처벌에 대한 두려움 없이 위험을 감수하고 취약해질 수 있습니까? |
| **책임** | 사람들은 자신의 약속에 대해 책임을 지는가? |
| **투명성** | 정보는 공개적으로 공유됩니까, 아니면 권력으로 축적됩니까? |
| **혁신 관용** | 실패는 처벌을 받는가 아니면 배움으로 취급되는가? |
| **고객 지향** | 결정은 고객의 요구에 따라 시작됩니까, 아니면 내부 편의에 따라 시작됩니까? |
| **속도 대 품질** | 빠른 반복을 향한 편견인가, 아니면 신중한 숙고를 향한 편견인가? |
| **위계 존중** | 후배들이 선배들의 아이디어에 도전할 수 있나요? |

## 변경 관리
### 변화 계획이 실패하는 이유
| 이유 | 설명 |
|---------|-------------|
| **긴급하지 않음** | 사람들은 왜 변화가 필요한지 알지 못합니다 |
| **연합 없음** | 변화를 주도하는 강력한 그룹이 없습니다 |
| **비전 없음** | 미래 상태가 어떤 모습인지 불분명함 |
| **소통 불량** | 사람들은 변화나 변화 속에서 자신의 역할을 이해하지 못합니다 |
| **빠른 승리는 없습니다** | 추진력을 구축할 가시적인 진전이 없습니다 |
| **성급한 축하** | 변화가 내장되기 전에 승리를 선언 |
| **문화 저항** | 변화는 뿌리깊은 가정과 충돌 |
| **강화 없음** | 오래된 행동은 보상을 받습니다. 새로운 행동이 지속되지 않음 |
### Kotter의 8단계 모델
| 단계 | 액션 |
|------|---------|
| **1. 긴급 상황 조성** | 사람들이 변화하지 않을 때의 위협을 인식하도록 돕기 |
| **2. 지도연합** 구축 | 충분한 힘과 신뢰성을 갖춘 그룹을 결성하라 |
| **3. 전략적 비전 형성** | 미래에 대한 명확한 그림 만들기 |
| **4. 지원군 입대** | 임계 질량으로부터 동의 얻기 |
| **5. 작업 활성화** | 장벽을 제거하십시오. 사람들에게 권한을 부여 |
| **6. 단기적인 성공 창출** | 눈에 보이는 성공 창출 |
| **7. 가속 유지** | 계속 밀어붙이세요. 너무 일찍 승리를 선언하지 마십시오 |
| **8. 연구소 변경** | 문화에 새로운 행동을 정착 |

## 요약
조직 설계와 문화는 회사가 전략을 실행할 수 있는지 여부를 결정합니다. 구조는 보고 관계, 결정 권한 및 조정 메커니즘을 정의합니다. 문화는 사람들이 실제로 행동하는 방식, 즉 일상 업무를 안내하는 가정, 규범, 가치를 정의합니다. Galbraith의 스타 모델은 전략, 구조, 프로세스, 보상, 사람이 모두 일치해야 함을 상기시켜 줍니다. 문화 유형은 클랜(협력), 임시정부(혁신), 시장(경쟁), 계층 구조(통제)에 이르기까지 다양합니다. Kotter의 8단계 모델과 같은 변경 관리 프레임워크는 변화를 위한 구조를 제공하지만 실제 전쟁터는 문화입니다. 변화가 깊은 가정과 충돌하면 얼마나 잘 계획되었는지에 관계없이 실패할 것입니다. 원격 및 하이브리드 작업은 의사소통, 신뢰, 근접성 편향에 대한 새로운 과제를 추가합니다. 최고의 조직은 의도적으로 설계하고, 전략을 지원하는 문화를 구축하며, 환경이 변화할 때에도 계속해서 발전하려는 의지를 갖고 있습니다.
