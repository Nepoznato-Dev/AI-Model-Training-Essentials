# 지적재산권과 혁신
지적 재산(IP)은 법에 의해 무단 사용으로부터 보호되는 발명품, 예술 작품, 브랜드 이름, 디자인, 영업 비밀 등 정신의 창작물을 의미합니다. 혁신은 아이디어를 가치로 바꾸는 과정이다. IP법은 창작자에게 보상(임시 독점 제공)과 사회에 혜택(지식을 궁극적으로 무료로 제공)이라는 두 가지 상충되는 이익의 균형을 맞추기 위해 존재합니다. IP를 이해하는 것은 제품 구축, 콘텐츠 제작, 비즈니스 운영 또는 연구에 종사하는 모든 사람에게 필수적입니다.
---

## 지적재산권의 유형
### 개요
| 유형 | 보호 대상 | 기간 | 획득 방법 | 예 |
|------|----|----------|-------------|---------|
| **특허** | 발명품(공정, 기계, 구성물) | 출원일로부터 20년 | 애플리케이션; 시험; 부여 | 신약화합물 제조공정 |
| **저작권** | 저자의 원본 작품 | 수명 + 70년(대부분의 국가) | 생성 시 자동 | 서적; 음악; 소프트웨어 코드; 영화 |
| **상표** | 브랜드 식별자(이름, 로고, 슬로건) | 무기한(사용 및 갱신된 경우) | 상업에 사용; 등록 강화 | "Nike" 이름과 스우시 로고 |
| **영업비밀** | 기밀 사업 정보 | 무기한(비밀인 경우) | 등록이 없습니다. 비밀을 유지하기 위해 합리적인 조치를 취해야 합니다 | 코카콜라 공식; 구글 검색 알고리즘 |
| **산업 디자인** | 제품의 시각적 외관 | 15~25세(다양함) | 등록 | 스마트폰의 모양; 가구 디자인 |
| **지리적 표시** | 특정 지리적 출처를 지닌 제품 | 무기한 | 등록; 지역에 연결됨 | 샴페인; 파르미지아노-레지아노; 다르질링 차 |

## 특허
### 특허 요건
| 요구사항 | 설명 |
|-------------|-------------|
| **참신함** | 발명품은 새로운 것이어야 합니다. 이전에 세계 어느 곳에서도 공개되지 않은 |
| **비자명성(창의성)** | 발명은 해당 분야의 숙련자에게 자명하지 않아야 합니다 |
| **유용성(산업상 이용가능성)** | 발명은 구체적이고 실용적인 용도를 가져야 합니다 |
| **주제 자격** | 프로세스, 기계, 제조 또는 물질의 구성이어야 합니다. 추상적인 사상, 자연법칙, 자연현상은 특허를 받을 수 없습니다 |
### 특허의 종류
| 유형 | 설명 | 기간 |
|------|-------------|------|
| **실용특허** | 발명의 기능을 보호합니다 | 출원일로부터 20년 |
| **디자인특허** | 기능성 아이템의 장식적인 디자인을 보호 | 보조금 지급 후 15년(미국) |
| **식물특허** | 식물의 신품종 보호(무성생식) | 출원일로부터 20년 |
### 특허 프로세스
| 단계 | 설명 | 타임라인 |
|------|-------------|----------|
| **1. 선행기술 검색** | 기존 특허 및 출판물을 검색하여 신규성 확인 | 몇 주에서 몇 달까지 |
| **2. 신청서 초안** | 청구서 작성(보호 범위 정의) 및 설명 | 몇 주에서 몇 달까지 |
| **3. 파일신청** | 특허청 제출(USPTO, EPO 등) | 출원일 = 우선일 |
| **4. 시험** | 신규성, 비자명성, 유용성에 대한 특허 심사관의 평가 | 1~5년 |
| **5. 사무실 작업** | 심사관은 거부할 수 있습니다. 신청인이 주장을 주장하거나 수정함 | 앞뒤로 협상 |
| **6. 그랜트** | 허용되면 특허가 부여됩니다. 유지보수 비용 필요 | 생존을 위한 정기 수수료 |

## 저작권
### 저작권으로 보호되는 것
| 보호됨 | 보호되지 않음 |
|------------|---------------|
| 문학 작품(도서, 기사, 코드) | 아이디어; 사리; 시스템 |
| 음악작품(멜로디, 가사) | 제목; 이름; 짧은 문구 |
| 예술 작품(회화, 사진, 디자인) | 운영 방법 |
| 소프트웨어 코드(작성됨) | 알고리즘의 기능(특허를 받을 수 있음) |
| 영화; TV 쇼; 비디오 | 스타일; 기술 |
| 건축 디자인 | 건물의 기능적 측면 |
### 주요 저작권 개념
| 개념 | 설명 |
|---------|-------------|
| **고정** | 저작물이 유형의 매체(기록, 녹음)에 고정된 경우 저작권이 존재합니다 |
| **자동 보호** | 등록이 필요하지 않습니다(그러나 등록하면 미국에서 법적 손해배상을 받을 수 있습니다) |
| **공정한 사용/공정한 거래** | 비평, 논평, 교육, 패러디 등의 목적으로 무단사용 제한 |
| **크리에이티브 커먼즈** | 다양한 수준의 재사용을 허용하는 표준화된 라이센스 |
| **공개 도메인** | 저작권으로 보호되지 않는 저작물(만료, 면제, 부적격) |
| **고용 작업** | 직원이 자신의 업무 범위 내에서 만든 저작물은 고용주의 소유입니다 |

## 상표
### 상표 기초
| 측면 | 설명 |
|---------|-------------|
| **목적** | 상품/서비스의 출처를 식별합니다. 소비자 혼란 방지 |
| **특이성 스펙트럼** | 공상적(가장 강함) → 임의적 → 암시적 → 서술적(약함) → 일반적(보호 불가능) |
| **등록** | 필수는 아니지만(관습법상 사용 권리) 상당한 법적 이점을 제공합니다 |
| **수업** | 45개 등급(Nice Classification)으로 분류된 상품/서비스 |
| **유지관리** | 상업에 사용되어야 합니다. 정기적으로 등록 갱신 |
| **침해** | 무단도용시 혼란을 야기할 수 있음 |
### 상표의 차별성
| 카테고리 | 설명 | 보호성 | 예 |
|------------|---------------|---------------|---------|
| **멋진** | 브랜드 밖에서는 아무 의미도 없이 만들어진 단어 | 최강 | "코닥"; "제록스" |
| **임의** | 제품과 관련없이 사용된 실제 단어 | 매우 강함 | 컴퓨터용 "Apple" |
| **제안** | 제품의 특성에 대한 힌트 | 강한 | "넷플릭스"(인터넷 영화) |
| **설명** | 제품 설명 | 약한; 이차적인 의미가 필요합니다 | "홀리데이 인" |
| **일반** | 제품의 일반 이름 | 보호할 수 없음 | "아스피린"(한때 상표였습니다) |

## 영업비밀
| 측면 | 설명 |
|---------|-------------|
| **정의** | 비밀로 되어 경제적 가치가 있는 정보 일반적으로 알려져 있지 않습니다. 비밀을 유지하기 위해 합당한 노력을 기울이고 있습니다 |
| **예** | 방식; 알고리즘; 고객 목록; 제조 공정; 사업 전략 |
| **보호** | 등록이 없습니다. NDA가 필요합니다. 접근 통제; 꼭 알아야 할 내용 |
| **기간** | 무기한 — 비밀이 유지되는 한 |
| **남용** | 부적절한 수단에 의한 취득(도난, 간첩, NDA 위반) |
| **특허 대비** | 공개가 필요하지 않습니다. 시간 제한 없음; 하지만 독립적인 검색이나 리버스 엔지니어링에 대한 보호는 제공되지 않습니다 |

## 오픈 소스 및 개방형 혁신
### 오픈 소스 라이선스
| 라이센스 | 유형 | 주요 요구사항 | 예시 사용자 |
|---------|------|---|---------------|
| **MIT** | 허용 | 저작권 표시를 포함합니다. 보증 없음 | jQuery; 반응 |
| **아파치 2.0** | 허용 | 통지를 포함하십시오. 특허 부여 | 기계적 인조 인간; 쿠버네티스 |
| **BSD(2절)** | 허용 | 저작권 고지 포함 | 프리BSD |
| **GPL v3** | 카피레프트 | 파생 저작물도 GPL이어야 합니다 | 리눅스 커널; 워드프레스 |
| **LGPL** | 약한 카피레프트 | 링크는 카피레프트를 트리거하지 않습니다. 수정하면 | GTK |
| **MPL 2.0** | 파일 수준 카피레프트 | 수정된 파일은 열려 있어야 합니다. 새 파일은 독점적일 수 있습니다 | 파이어폭스 |
| **AGPL** | 강력한 카피레프트 | 네트워크 사용으로 인해 소스 공개 | MongoDB(이전) |
### 개방형 혁신 모델
| 모델 | 설명 | 예 |
|-------|-------------|---------|
| **오픈 소스** | 코드는 자유롭게 사용할 수 있습니다. 지역사회 기여 | 리눅스; 쿠버네티스; 반응 |
| **공개 데이터** | 누구나 사용할 수 있도록 공개적으로 공유된 데이터 | 정부 데이터세트 연구 데이터 |
| **오픈 하드웨어** | 공개적으로 공유되는 하드웨어 디자인 | 아두이노; 라즈베리 파이 |
| **특허 풀** | 여러 회사가 하나의 도메인에서 특허를 공유합니다 | MPEG-LA(비디오 코덱) |
| **경쟁 전 협업** | 경쟁업체는 공유된 과제에 대해 협력합니다 | 반도체연구소 |

## IP 전략
### 각 유형의 IP를 사용하는 경우
| 상황 | 추천 IP | 이유 |
|------------|---------------|---------|
| **새로운 발명품** | 특허 | 20년 독점; 강력한 보호 |
| **소프트웨어 알고리즘** | 특허 + 영업비밀 | 특허 가능한 경우 특허; 구현을 비밀로 유지 |
| **브랜드명/로고** | 상표 | 브랜드 아이덴티티를 무기한으로 보호 |
| **작성된 내용/코드** | 저작권 | 오토매틱; 표현을 보호합니다 |
| **레시피/공식** | 영업비밀 | 공개하지 않음 무기한 보호 |
| **제품 디자인** | 디자인 특허 + 트레이드 드레스 | 외관을 보호합니다 |
| **빠르게 변화하는 시장** | 영업비밀 + 선점자 이점 | 특허에는 시간이 너무 오래 걸립니다. 경쟁업체가 따라할 수 있는 것보다 더 빠르게 이동 |
---

## 요약
지적재산권법은 창작자에게 보상하는 것과 사회에 혜택을 주는 것 사이의 균형을 유지합니다. 특허는 대중에게 공개되는 대가로 20년 동안 발명품을 보호합니다. 저작권은 창작자의 생애 이후 70년 동안 저작물의 원본 작품을 보호합니다. 상표는 사용되는 한 브랜드 식별자를 무기한으로 보호합니다. 영업 비밀은 기밀 정보를 무기한으로 보호하지만 독립적인 발견에 대해서는 보호를 제공하지 않습니다. 오픈 소스 라이선스는 기존 IP에 대한 대안을 제공하여 공동 개발을 가능하게 합니다. 올바른 IP 전략은 창작 유형, 시장, 산업 속도, 회사의 목표에 따라 달라집니다. IP를 이해하는 것은 변호사만을 위한 것이 아닙니다. 지식 경제에서 창출, 구축 또는 혁신하는 모든 사람에게 필수적입니다.
