   - 메이저 (`x.0.0`): 완전한 재작성 또는 구조 조정

   ```yaml
     - version: "1.0.0"

       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```

4. **해당 파일의 첫 편집이라면 `contributors`에 자신을 추가**:

   ```yaml
   contributors:
     - name: "Your Name"
   ```
