   - 파일 제목에는 `#` 만 사용
   - 주요 섹션에는 `##` 사용
   - 하위 섹션에는 `###` 사용

```yaml
---
title: "파일 제목"
description: "간략한 설명"

difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

4. **관련 파일에 상호 참조 추가**
