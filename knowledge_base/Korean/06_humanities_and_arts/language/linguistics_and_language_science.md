# 언어학과 언어과학
언어학은 언어의 구조, 의미, 사용, 습득 및 진화에 대한 과학적 연구입니다. 언어는 인간 의사소통을 정의하는 특징입니다. 언어는 무한히 생산적이며(화자는 이전에 접한 적이 없는 문장을 만들고 이해할 수 있음), 문화적으로 전달되며(순전히 타고난 것이 아니라 학습됨) 지속적으로 진화합니다. 언어가 어떻게 작동하는지 이해하는 것은 언어 기술을 구축하고, 가르치고, 번역하고, 보다 효과적으로 의사소통하기 위해 노력하는 모든 사람과 관련이 있습니다.
---

## 언어의 수준
### 개요
| 레벨 | 연구 | 분석단위 | 예시 질문 |
|-------|---------|----|----|
| **음성학** | 말의 물리적 소리 | 전화(음성) | "pin"의 "p"는 "spin"과 어떻게 다른가요? |
| **음운론** | 사운드 시스템 및 패턴 | 음소(대조음) | 왜 영어 단어는 "str"로 시작하고 "ztr"로 시작할 수 없나요? |
| **형태** | 단어의 구조 | 형태소(최소 의미 단위) | '불행'은 어떻게 해소되는가? |
| **구문** | 문장의 구조 | 실없는 말; 조항 | "무색의 녹색 사상이 격렬하게 잠든다"는 말은 문법적으로는 맞지만 무의미한 이유는 무엇입니까? |
| **의미론** | 의미 | 단어; 문장; 제안 | "큰"과 "큰"의 차이점은 무엇인가요? |
| **화용론** | 문맥상 의미 | 언어 행위; 함축 | "소금 좀 넘겨줄래?"은(는) 무슨 뜻인가요? 실제로 뜻은? |

## 음성학과 음운론
### 국제 음성 알파벳(IPA)
| 카테고리 | 기호 | 예 |
|------------|---------|---------|
| **폭발물** | p, b, t, d, k, g | "팻", "박쥐", "고양이", "갓" |
| **마찰음** | f, v, θ, ð, s, z, ʃ, ʼ, h | "지방", "vat", "얇은", "다음", "sip", "zip" |
| **비강** | m, n, Å < | "매트", "nat", "노래하다" |
| **근사치** | l, r, w, j | "하자", "빨간색", "젖은", "아직" |
| **아프리카인** | tʃ, dʼ | "교회", "판사" |
### 주요 음운론적 개념
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **최소 쌍** | 의미가 바뀌는 하나의 음소가 다른 두 단어 | "pat" 대 "bat"(p/b 대비) |
| **음성학** | 허용되는 사운드 조합에 대한 규칙 | 영어에서는 단어 첫 글자 /Å</를 허용하지 않습니다 |
| **스트레스** | 특정 음절 강조 | "REcord"(명사) 대 "reCORD"(동사) |
| **억양** | 발화 전반에 걸친 피치 패턴 | 높아지는 억양 = 영어로 된 질문 |
| **동화** | 소리가 주변 소리와 더 유사해짐 | "핸드백"은 종종 "함백"으로 발음됨 |

## 형태
### 형태소의 종류
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **자유 형태소** | 단어로 홀로 설 수 있다 | "고양이"; "달리다"; "행복하다" |
| **바운드 형태소** | 다른 형태소에 부착되어야 함 | "-s"(복수); "-ed"(과거형); "un-"(부정) |
| **파생** | 새 단어를 만듭니다. 품사를 변경할 수 있습니다 | "행복하다" → "행복"(형용사 → 명사) |
| **변형** | 단어의 문법 형식을 수정합니다. 품사를 바꾸지 않는다 | "walk" → "walked"(현재 → 과거) |
### 단어 형성 과정
| 프로세스 | 설명 | 예 |
|---------|-------------|---------|
| **복리** | 두 개의 자유 형태소 결합 | "해바라기"; "칫솔" |
| **파생** | 접사 추가 | "가르치다" → "선생님" |
| **클리핑** | 단어 단축 | "실험실" → "실험실" |
| **블렌딩** | 두 단어의 부분 결합 | "연기" + "안개" = "스모그" |
| **약어** | 첫 글자 사용 | NASA; 원자 램프; 스쿠버 |
| **대출** | 다른 언어에서 단어 가져오기 | "초밥"(일본어); "카페"(프랑스어) |
| **주화** | 새로운 단어 발명 | "구글"(동사); "쿼크" |

## 구문
### 구문 구조
| 문구 | 머리 | 예 |
|---------|------|---------|
| **명사구(NP)** | 명사 | "큰 빨간 공" |
| **동사구(VP)** | 동사 | "케이크 빨리 먹어" |
| **전치사구(PP)** | 전치사 | "정원에서" |
| **형용사 문구(AP)** | 형용사 | "결과에 매우 만족합니다" |
| **결정어 구문(DP)** | 결정자 | "그만큼"; "내가 가장 좋아하는 세 가지" |
### 구문 개념
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **선거구** | 단어는 계층적 단위(구성요소)로 그룹화됩니다. "노인"은 구성 요소입니다. "늙은이"는 아니다 |
| **재귀** | 문구에는 동일한 유형의 문구가 포함될 수 있습니다 | "쥐가 쫓던 개가 도망간 고양이" |
| **모호함** | 다양한 구조적 해석이 가능한 문장 | "망원경을 가진 남자를 봤어요"(망원경을 가진 사람은 누구입니까?) |
| **이동** | 요소는 기본 위치에서 이동할 수 있습니다 | "___ 뭐 먹었어?" (오브젝트 위치에서 이동한 것) |
| **계약** | 단어는 특징(숫자, 사람, 성별)이 일치해야 합니다 | "그녀는 달린다"("그녀는 달린다" 아님) |

## 의미론
### 의미론적 관계
| 관계 | 설명 | 예 |
|----------|-------------|---------|
| **동의어** | 동일하거나 유사한 의미 | "큰" ≒ "큰" |
| **반의어** | 반대 의미 | "뜨거운" ← "차가운" |
| **하위어** | 특정 → 일반 | "장미"는 "꽃"의 하위어입니다 |
| **하이퍼니미** | 일반 → 특정 | "과일"은 "사과"의 상위어입니다 |
| **메로니미** | 부분 → 전체 | "바퀴"는 "자동차"의 약어입니다 |
| **다의성** | 여러 관련 의미를 지닌 한 단어 | "머리"(신체 부분, 리더, 사물의 상단) |
| **동일성** | 같은 형태; 관련 없는 의미 | "은행"(강); "은행"(금융 기관) |
### 구성 의미론
| 개념 | 설명 |
|---------|-------------|
| **구성성의 원리** | 복잡한 표현의 의미는 부분과 부분의 결합 방식에 따라 결정됩니다 |
| **주제별 역할** | 대리인(행위자) 환자(영향을 받음); 기구(도구); 목표; 원천; 위치 |
| **수반** | A가 참이면 B는 참이어야 합니다. "그녀가 그를 살해했습니다"는 "그는 죽었습니다"를 수반합니다 |
| **전제** | 배경 가정: "프랑스 왕은 대머리입니다"는 프랑스 왕이 있다고 가정합니다 |

## 화용론
### 주요 개념
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **화행** | 발언은 다음 작업을 수행합니다. 요청; 유망한; 사과하다 | "사과합니다" = 사과하는 행위 |
| **함축적** | 암시적이지만 명시되지 않은 의미 | "일부 합격"은 "모두 합격하지 않음"을 의미 |
| **그라이스의 맥심** | 품질(진실함) 수량(너무 많지 않고 충분히 유익함) 관계(관련성이 있어야 함) 매너(명확하게) | 격언을 위반하면 암시가 생성됩니다 |
| **데이시스** | 문맥에 따라 참조가 달라지는 단어 | "여기"; "지금"; "이것"; "그녀" |
| **공손함** | 간접적으로 완화된 얼굴 위협 행위 | "아마도..." vs "이것을 해주세요" |
| **공통점** | 연사 간 지식 공유 | "평상시"는 공유 컨텍스트에서만 작동합니다 |

## 언어습득
### 모국어 습득
| 무대 | 나이 | 특징 |
|-------|------|----|
| **옹알이** | 6~12개월 | 반복되는 음절: "bababa"; "다다다" |
| **한 단어(홀로프라스틱)** | 12~18개월 | 한 단어는 전체 메시지를 전달합니다: "우유!" = "우유를 원해요" |
| **두 단어** | 18~24개월 | 간단한 조합: "더 많은 우유"; "아빠 가세요" |
| **전신** | 24~30개월 | 여러 단어로 구성되어 있지만 기능 단어가 누락되었습니다. "me want cookie" |
| **나중 단계** | 3~5년 | 문법이 발달합니다. 과도한 규제("goed"); 어휘 폭발 |
### 주요 토론
| 토론 | 직위 |
|---------|----------|
| **본성 대 양육** | 촘스키: 타고난 보편적 문법. 사용법 기반: 언어는 일반적인 인지 능력과 입력에서 나타납니다 |
| **중요한 시기** | Lenneberg: 언어는 사춘기 이전에 습득되어야 합니다. 증거: 야생 어린이; 후기 L2 학습자 |
| **모듈화** | 언어는 별도의 모듈입니까, 아니면 일반 인지를 사용합니까? |

## 요약
언어학은 음성학(소리), 음운론(음운 체계), 형태론(단어 구조), 구문론(문장 구조), 의미론(의미), 화용론(문맥상 의미) 등 다양한 수준에서 언어를 연구합니다. 언어는 무한히 생산적입니다. 우리는 들어본 적도 없는 문장을 만들고 이해할 수 있습니다. 단어는 형태소로 구성됩니다. 계층적 구문 구조의 문장. 의미는 구성적이지만 맥락, 암시, 공유된 지식에 따라 달라집니다. 언어 습득은 옹알이로 시작하여 한 단어와 두 단어 단계를 거쳐 진행되며, 본성-양육 논쟁은 아직 해결되지 않았습니다. 세계의 약 7,000개 언어는 인류 이주와 문화 역사를 반영하는 어족(인도-유럽어, 중국-티베트어, 니제르-콩고)에 속합니다. 언어 기술을 다루는 모든 사람에게 이러한 기본 사항(소리가 의미에 매핑되는 방식, 구문이 작동하는 방식, 맥락이 해석을 형성하는 방식)을 이해하는 것은 순수 통계 모델이 대체할 수 없는 필수 배경입니다.
