# 문학
문학은 인류의 사고, 감정, 경험에 대한 가장 지속적인 기록입니다. 고대 문명의 구전 서사시부터 오늘날의 디지털 시대 소설까지, ​​모든 작품은 이전의 내용과 대화를 나누고 있습니다. 문학 장르, 사조, 기술을 이해하면 독서와 이러한 작품을 생산한 문화를 이해하는 데 있어 더 풍부한 렌즈를 얻을 수 있습니다.
---

## 문학 장르 및 형식
### 소설 장르
| 장르 | 주요 특성 | 주목할만한 사례 |
|-------|------------|----|
| **문학 소설** | 캐릭터 중심, 주제별 깊이, 문체 공예 | *앵무새 죽이기*(하퍼 리) |
| **공상과학** | 추측적 기술, 공간, 시간, 평행세계 | *듄*(허버트), *1984*(오웰) |
| **판타지** | 마법의 세계, 신화 속 생물 | *반지의 제왕*(톨킨), *해리포터*(롤링) |
| **미스터리/탐정** | 범죄 해결 퍼즐, 조사 | 셜록 홈즈(도일), 포와로(크리스티) |
| **공포** | 공포, 서스펜스, 초자연적 현상 | *샤이닝*(킹), *드라큘라*(스토커) |
| **로맨스** | 낭만적인 관계, 감정적인 여행 | *오만과 편견*(오스틴) |
| **역사 소설** | 특정 역사적 기간, 정확한 세부정보 | *책도둑*(Zusak), *Wolf Hall*(Mantel) |
| **마술적 사실주의** | 현실적인 환경에서 평범하게 취급되는 마법의 요소들 | *백년의 고독*(가르시아 마르케스) |
| **디스토피아** | 억압적인 사회, 미래 동향에 대해 경고하다 | *멋진 신세계*(Huxley), *The Handmaid's Tale*(Atwood) |
| **풍자** | 사회를 비판하는 데 사용되는 유머와 아이러니 | *걸리버 여행기*(스위프트), *Catch-22*(헬러) |
### 논픽션 양식
| 양식 | 설명 | 주목할만한 사례 |
|------|-------------|----|
| **전기/자서전** | 실제 사람들의 인생 이야기 | *어린 소녀의 일기*(안네 프랑크), *비커밍*(미셸 오바마) |
| **회고록** | 특정 경험이나 주제에 초점을 맞춘 개인 계정 | *교육*(Tara Westover) |
| **에세이** | 특정 주제에 대한 짧은 산문 | 제임스 볼드윈, 조안 디디온, 조지 오웰 |
| **저널리즘** | 뉴스 보도, 조사 기사, 특집 기사 | *모든 대통령의 부하들*(우드워드 및 번스타인) |
| **자조** | 개인 개발 및 실질적인 개선 | *생각하기, 빠르고 느리게*(Kahneman) |
| **철학 논문** | 철학적 질문의 체계적 탐구 | *명상*(마르쿠스 아우렐리우스) |
| **여행 글쓰기** | 장소, 문화 및 여행에 대한 설명 | *파타고니아에서*(채트윈) |
### 시 형식
| 양식 | 구조 | 예 |
|------|-------------|---------|
| **소네트** | 14행, 구체적인 운율 구성표 | 셰익스피어(ABAB CDCD EFEF GG), 페트라르칸(ABBAABBA CDECDE) |
| **하이쿠** | 5-7-5 음절 패턴 | 일본 전통, 자연 중심 |
| **리머릭** | 다섯 줄, AABBA 운율, 유머 | 가벼운 구절 |
| **자유 구절** | 일반 박자나 운율 없음 | 월트 휘트먼, T.S. 엘리엇 |
| **빌라넬** | 반복되는 후렴구가 있는 19줄 | "부드럽게 가지 마세요"(딜런 토마스) |
| **에픽** | 영웅적 행위에 대한 긴 이야기 | *오디세이*(호머), *베오울프* |
| **송시** | 주제를 다룬 서정시 | 키츠의 "그리스 항아리에 바치는 송가" |
| **엘레지** | 죽은 자를 애도하는 시 | "오 캡틴! 마이 캡틴!" (휘트먼) |
| **빈 구절** | 운율이 없는 약강 오보격 | 셰익스피어의 희곡, 밀턴의 *Paradise Lost* |

## 주요 문학 운동
문학은 뚜렷한 기간을 거쳐 발전해 왔으며 각 기간은 이전 기간에 대해 반응했습니다.
| 기간 | 시대 | 핵심 아이디어 | 주요 인물 |
|---------|-------|------------|---------------|
| **클래식** | 8세기. 기원전 – 5세기 CE | 이성, 질서, 휴머니즘 | 호머, 소포클레스, 버질 |
| **중세** | 5~15세기 | 종교적 주제, 기사도, 우화 | 단테, 초서 |
| **르네상스** | 14~17세기 | 인문주의, 고전학문의 부활 | 셰익스피어, 세르반테스 |
| **계몽** | 17~18세기 | 이성, 과학, 개인의 권리 | 볼테르, 스위프트 |
| **낭만주의** | 18세기 후반~19세기 중반 | 감성, 자연, 개인주의 | 워즈워스, 괴테, 메리 셸리 |
| **현실주의** | 19세기 중반 | 일상생활의 정확한 묘사 | 톨스토이, 조지 엘리엇, 마크 트웨인 |
| **자연주의** | 19세기 후반 | 결정론, 과학적 관찰 | 에밀 졸라, 스티븐 크레인 |
| **모더니즘** | 19세기 후반~20세기 중반. | 실험적 형태, 의식의 흐름 | 조이스, 버지니아 울프, T.S. 엘리엇 |
| **할렘 르네상스** | 1920년대~1930년대 | 아프리카계 미국인 문화 개화 | 랭스턴 휴즈, 조라 닐 허스턴 |
| **포스트모더니즘** | 20세기 중반 – 현재 | 단편화, 메타픽션, 아이러니 | 핀촌, 돈 드릴로 |
| **포스트식민지** | 20세기 중반 – 현재 | 정체성, 이동, 문화적 혼성성 | 치누아 아체베, 살만 루시디 |
각 운동은 부분적으로는 반란이었습니다. 낭만주의는 계몽주의 합리주의를 거부했다. 모더니즘은 빅토리아 시대의 관습에서 깨졌습니다. 포스트모더니즘은 거대 서사의 개념 자체에 의문을 제기했습니다.

## 문학적 장치
훌륭한 글쓰기는 다음과 같은 기술 툴킷을 사용합니다.
| 장치 | 그것이 하는 일 | 예 |
|---------|-------------|---------|
| **은유** | 직접 비교 | "세상은 모두 무대이다" (셰익스피어) |
| **비유** | "like" 또는 "as"를 사용한 비교 | "내 사랑은 붉고 붉은 장미같아" (번즈) |
| **의인화** | 인간이 아닌 것들에 부여된 인간적 특성 | "바람이 나무들 사이로 속삭였다" |
| **아이러니** | 기대와 현실의 대조 | 상황적, 극적, 언어적 아이러니 |
| **상징** | 추상적인 아이디어를 나타내는 객체 | *위대한 개츠비*의 초록불 |
| **예측** | 향후 이벤트에 대한 힌트 | *맥베스*에 나오는 마녀들의 예언 |
| **신뢰할 수 없는 내레이터** | 신뢰성이 훼손된 서술자 | *Lolita*(Nabokov), *Fight Club*(Palahniuk) |
| **의식의 흐름** | 생각의 지속적인 흐름 | *Ulysses*(조이스), *Mrs Dalloway*(울프) |
| **암시** | 다른 작품이나 행사에 대한 언급 | 성서적, 신화적 참고자료 |
| **우화** | 도덕적, 정치적 의미가 숨겨진 이야기 | *동물농장* (오웰) |
| **병치** | 대조되는 요소를 나란히 배치 | 빛과 어둠, 젊음과 나이 |
| **모티프** | 주제별 중요성을 지닌 반복 요소 | T.J. 박사의 눈 *개츠비*의 에클버그 |

## 이것이 중요한 이유
문학은 단순한 오락이 아닙니다. 사회가 경험을 처리하고, 가정에 도전하고, 대안을 상상하는 방식입니다. 소설은 여론을 바꿀 수 있습니다. 시는 시대를 정의할 수 있습니다. 문학적 표현을 형성한 전통, 장르, 기법을 이해하면 읽기, 쓰기, 세상 이해를 위한 더 풍부한 렌즈를 얻을 수 있습니다.
