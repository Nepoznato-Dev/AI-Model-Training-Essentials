# 음악이론과 음향학
음악 이론은 음악이 어떻게 작동하는지, 즉 일부 소리의 조합을 즐겁게 하거나 의미 있게 만들고 다른 소리를 조화롭지 않게 하거나 혼란스럽게 만드는 패턴, 구조 및 원리에 대한 연구입니다. 음향학은 소리의 물리학입니다. 진동이 공기를 통해 이동하는 방식, 진동이 생성되고 인식되는 방식입니다. C메이저 코드가 왜 기분 좋게 들리는지, 단조가 왜 슬프게 들리는지, 콘서트홀이 어떻게 디자인되었는지, 좋아하는 노래가 왜 오싹해지는지 설명합니다.
---

## 소리의 물리학
### 사운드 기초
| 부동산 | 설명 | 인식 |
|----------|-------------|----------|
| **빈도** | 초당 진동수(Hz) | 피치(높은 주파수 = 높은 피치) |
| **진폭** | 진동의 크기 | 음량(진폭이 클수록 커짐) |
| **파형** | 진동의 모양 | 음색(같은 음을 연주해도 피아노와 기타의 소리가 다른 이유) |
| **기간** | 진동이 지속되는 시간 | 메모 길이; 리듬 |
### 하모닉 시리즈
| 부분 | 빈도(기본 대비) | 간격 | 인지된 품질 |
|---------|------------|------------|------|
| **1차(기초)** | 에프 | 한마음 | 당신이 듣는 피치 |
| **2위** | 2층 | 옥타브 | 매우 자음 |
| **3위** | 3층 | 옥타브 + 5도 | 자음 |
| **4위** | 4층 | 두 옥타브 | 매우 자음 |
| **5위** | 5층 | 2옥타브 + 메이저 1/3 | 적당히 자음 |
| **6위** | 6층 | 2옥타브 + 5도 | 자음 |
| **7위** | 7층 | 2옥타브 + 마이너 7도 | 불협화음 |
고조파 계열은 특정 간격이 자음으로 들리는 이유, 즉 고조파가 겹치고 정렬되는 이유를 설명합니다.

## 피치 및 스케일
### 음악 간격
| 간격 | 반음 | 비율 | 캐릭터 | 예 |
|----------|------------|-------|------------|---------|
| **한마음** | 0 | 1:1 | 같은 피치 | C에서 C로 |
| **마이너 2위** | 1 | 16:15 | 시제; 불협화음 | C 에서 DB |
| **메이저2** | 2 | 9:8 | 단계; 가벼운 긴장감 | C에서 D까지 |
| **단3도** | 3 | 6:5 | 슬픈; 어두운 | C 에서 Eb |
| **메이저 3위** | 4 | 5:4 | 행복하다; 밝은 | C에서 E까지 |
| **완벽 4위** | 5 | 4:3 | 열려 있는; 모호한 | C부터 F까지 |
| **트리톤** | 6 | √2:1 | 매우 불협화음; 불안정 | C 에서 F# |
| **완벽 5위** | 7 | 3:2 | 강한; 자음 | C에서 G로 |
| **단6도** | 8 | 8:5 | 어두운; 부자 | C 에서 Ab |
| **메이저6** | 9 | 5:3 | 달콤한; 자음 | C에서 A로 |
| **단7도** | 10 | 9:5 | 블루지; 편안한 | C 에서 Bb |
| **메이저7** | 11 | 15:8 | 꿈꾸는 듯한; 시제 | C에서 B로 |
| **옥타브** | 12 | 2:1 | 같은 노트 클래스 | C에서 C로 |
### 일반적인 저울
| 규모 | 패턴(W = 전체 단계, H = 반 단계) | 캐릭터 | 예(C에서) |
|-------|---------------|------------|------|
| **메이저(아이오니아)** | W-W-H-W-W-W-H | 행복하다; 밝은 | C D E F G A B C |
| **내츄럴 마이너(에올리안)** | W-H-W-W-H-W-W | 슬픈; 어두운 | C D Eb F G Ab Bb C |
| **하모닉 마이너** | W-H-W-W-H-W+H-H | 이국적인; 극적인 | C D Eb F G Ab B C |
| **멜로딕 마이너** (오름차순) | W-H-W-W-W-W-H | 재즈; 정교한 | C D Eb F G A B C |
| **도리안** | W-H-W-W-W-H-W | 사소하지만 밝음 | C D Eb F G A Bb C |
| **믹솔리디안** | W-W-H-W-W-H-W | 블루지; 바위 | C D E F G A Bb C |
| **펜타토닉(메이저)** | W-W-min3-W-min3 | 열려 있는; 사람들; 블루스 | C D E G A C |
| **블루스** | min3-W-H-H-min3-W | 블루지; 영혼이 가득한 | C Eb F F# G Bb C |
| **반음계** | 모든 반걸음 | 시제; 무조 | C C# D D# E F F# G G# A A# B C |

## 하모니와 코드
### 트라이어드
| 코드 | 간격 | 캐릭터 | 예(C에서) |
|-------|------------|------------|------|
| **전공** | 루트 + M3 + P5 | 행복하다; 안정된 | C-E-G |
| **사소한** | 루트 + m3 + P5 | 슬픈; 안정된 | C-Eb-G |
| **감소** | 루트 + m3 + d5 | 시제; 불안정 | C-Eb-Gb |
| **증강** | 루트 + M3 + A5 | 신비한; 불안정 | C-E-G# |
### 7번째 코드
| 코드 | 간격 | 캐릭터 | 일반적인 용도 |
|---------|------------|------------|-------------|
| **메이저7** | 장3화음 + M7 | 꿈꾸는 듯한; 무성한 | 재즈; 로파이 |
| **도미넌트 7위** | 장3화음 + m7 | 블루지; 해결하고 싶어 | 주요 키의 V 코드 |
| **단7도** | 마이너 트라이어드 + m7 | 매끄러운; 편안한 | 재즈; R&B; 펑크 |
| **반감소 7위** | 감소된 트라이어드 + m7 | 시제; 모호한 | ii 단조의 코드; 재즈 |
| **하위 7위** | 감소된 트라이어드 + d7 | 매우 긴장되어 있습니다. 극적인 | 패스 코드; 변조 |
### 코드 진행
| 진행 | 이름 | 캐릭터 | 예시곡 |
|---------------|------|------------|---------------|
| **I-IV-V-I** | 표준 케이던스 | 해결됨; 클래식 | "트위스트 앤 샤우트"; "라 밤바" |
| **I-V-vi-IV** | 팝 진행 | 고양; 친숙한 | 수천 개의 팝송 |
| **ii-V-I** | 재즈 케이던스 | 매끄러운; 정교한 | 재즈 표준 |
| **I-vi-IV-V** | 50년대 진행 | 향수를 불러일으키는; 두왑 | "나 옆에 있어라"; "지구의 천사" |
| **vi-IV-I-V** | 마이너 팝 | 감정적인; anthemic | 많은 현대 팝송 |
| **I-IV-vi-V** | 변형 | 조금씩 다른 감정호 | "당신이 있든 없든" |
| **12마디 블루스** | I-I-I-I-IV-IV-I-I-V-IV-I-V | 블루스 표준 | 수많은 블루스와 록 노래 |

## 리듬과 미터
### 박자표
| 서명 | 바당 비트 | 참고 값 | 느낌 | 예 |
|------------|---------------|------------|------|---------|
| **4/4** (공통시) | 4 | 4분음표 | 기준; 바위; 팝 | 가장 인기 있는 음악 |
| **3/4** (왈츠 시간) | 3 | 4분음표 | 앞뒤로 흔들리는; 댄스 | "블루 다뉴브" |
| **6/8** | 6 | 여덟 번째 음표 | 화합물; 경쾌한 | "떠오르는 태양의 집" |
| **2/4** | 2 | 4분음표 | 3월다운 | "성조기는 영원히" |
| **5/4** | 5 | 4분음표 | 이상한; 불안한 | "Take Five" (데이브 브루벡) |
| **7/8** | 7 | 여덟 번째 음표 | 이상한; 복잡한 | "머니"(핑크 플로이드) |
### 리듬 개념
| 개념 | 설명 |
|---------|-------------|
| **템포** | 비트 속도(BPM으로 측정 - 분당 비트 수) |
| **싱코페이션** | 색다른 느낌을 강조; 리드미컬한 긴장감을 조성 |
| **스윙** | 비트의 부등분할(롱-숏 패턴) |
| **폴리리듬** | 동시에 두 개 이상의 상충되는 리듬(예: 3 대 4) |
| **그루브** | 리듬감 있는 추진력을 느꼈습니다. "주머니" |
| **루바토** | 표현적인 속도 증가 및 속도 감소 |

## 음악 형식
| 양식 | 설명 | 예 |
|------|-------------|---------|
| **바이너리(AB)** | 두 개의 대조 섹션 | 바로크 댄스 모음곡 |
| **3항(ABA)** | 성명; 차이; 반환 | 미뉴에트와 트리오; "반짝반짝" 변형 |
| **소나타 형식** | 박람회(테마); 개발(탐사); 요약(반환) | 클래식 교향곡; 베토벤 |
| **론도(ABACA)** | 메인 테마는 에피소드와 번갈아 가며 | 클래식 결승전 |
| **절-합창** | 교대 절(새 가사) 및 합창(반복) | 팝; 바위; 국가 |
| **12마디 블루스** | 4마디 프레이즈 3개(AAB 가사 구조) | 블루스; 초기 록 |
| **작곡을 통해** | 반복되는 섹션이 없습니다. 지속적인 신소재 | 예술곡; 프로그레시브 록 |

## 음향
### 실내 음향
| 부동산 | 설명 | 중요 사항 |
|------------|-------------|---------------|
| **잔향 시간(RT60)** | 소리가 60dB 감소하는 데 걸리는 시간 | 콘서트 홀(1.5-2.5s); 녹음실(0.3-0.5초) |
| **초기 반성** | 직접음으로부터 50ms 이내에 도착하는 소리 | 명쾌함; 친밀감 |
| **정재파** | 방의 공진 주파수 | 저음 형성; 특정 위치에서 null이 발생함 |
| **확산** | 여러 방향으로 소리가 산란되는 현상 | 균일한 사운드 분배 |
| **흡수** | 소리 에너지를 줄이는 재료 | 에코 감소; 반향 제어 |
| **플러터 에코** | 평행 표면 사이의 빠른 반복 반사 | 탐탁지 않은; 확산 또는 흡수로 고정 |
### 악기 계열
| 가족 | 사운드 제작 | 예 |
|---------|------|---------|
| **문자열** | 진동하는 현(구부리고, 뽑고, 치고) | 바이올린; 기타; 피아노; 하프 |
| **목관악기** | 진동 공기 기둥; 갈대 또는 가장자리 | 플루트; 클라리넷; 색소폰; 오보에 |
| **황동** | 컵 마우스피스의 진동 입술 | 트럼펫; 트롬본; 프렌치 호른; 튜바 |
| **타악기(피치)** | 충격; 명확한 음조를 생성 | 팀파니; 마림바; 실로폰 |
| **타악기(비음정)** | 충격; 무한한 피치를 생성 | 스네어 드럼; 심벌즈; 베이스 드럼 |
| **전자** | 발진기; 디지털 합성 | 합성기; 드럼 머신; 테레민 |

## 요약
음악 이론은 음악을 작동시키는 패턴을 설명합니다. 소리는 진동입니다. 주파수(피치), 진폭(크기) 및 파형(음색)으로 특징지어집니다. 고조파 계열은 특정 간격이 자음으로 들리는 이유를 설명합니다. 스케일은 음악 시스템을 정의하는 일련의 음표입니다. 메이저 스케일은 밝게 들립니다. 마이너 스케일은 어둡게 들립니다. 모드는 다른 색상을 제공합니다. 코드는 쌓인 간격으로 구성됩니다. 주요 3화음은 안정적입니다. 감소된 트라이어드는 긴장되어 있습니다. 일곱 번째 코드는 색상과 복잡성을 추가합니다. 코드 진행은 기대와 해결을 만들어냅니다. 리듬은 미터, 템포, 당김음, 그루브를 통해 시간을 구성합니다. 음악 형식은 이진법과 삼항법에서 소나타 형식, 절 합창에 이르기까지 구조를 제공합니다. 음향학은 소리가 공간에서 어떻게 작용하는지 설명합니다. 즉, 반향, 반사, 흡수 및 확산이 공간의 소리가 좋은지 여부를 결정합니다. 이러한 기본 사항을 이해하면 음악 창작과 감상이 풍부해집니다.
