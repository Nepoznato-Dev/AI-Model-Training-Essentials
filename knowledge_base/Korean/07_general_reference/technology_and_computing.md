# 기술과 컴퓨팅
컴퓨팅은 휴대폰, 자동차, 냉장고, 의료 기기, 현대 사회를 운영하는 인프라 등 어디에나 있습니다. 모든 작동 방식을 이해함으로써 이익을 얻기 위해 프로그래머가 될 필요는 없습니다. 이 파일은 컴퓨터가 무엇인지, 인터넷이 작동하는 방식, 소프트웨어가 구축되는 방식, 디지털 세계를 형성하는 개념 등 기본 사항을 다룹니다.
> **더 자세히 알고 싶으십니까?** 이 파일은 광범위한 개요입니다. 모든 주제에 대한 자세한 내용은[web development](../01_coding_and_technology/web_development.md),[database systems](../01_coding_and_technology/database_systems.md),[cloud architecture](../01_coding_and_technology/cloud_architecture.md),[networking](../01_coding_and_technology/networking_basics.md)및[security](../01_coding_and_technology/security_best_practices.md)를 포함하여 [`01_coding_and_technology/`](../01_coding_and_technology/)의 전용 파일을 참조하세요.

## 컴퓨터란 무엇입니까?
기본적으로 스마트폰부터 슈퍼컴퓨터까지 모든 컴퓨터는 동일한 작업을 수행합니다. 즉, 입력을 받아 지침(프로그램)에 따라 처리하고 출력을 생성합니다. 마법은 속도와 규모에 있습니다.
### 폰 노이만 아키텍처
거의 모든 최신 컴퓨터는 다음과 같은 기본 디자인을 따릅니다.
| 구성요소 | 그것이 하는 일 | 비유 |
|------------|-------------|---------|
| **CPU**(중앙 처리 장치) | 명령을 실행합니다. "뇌" | 레시피를 따르는 요리사 |
| **RAM**(메모리) | CPU가 활발히 사용하고 있는 데이터를 저장합니다. 전원이 꺼지면 손실됨 | 조리대 — 빠른 접근, 제한된 공간 |
| **스토리지**(SSD/HDD) | 데이터를 영구적으로 저장 | 식료품 저장실 — 접근 속도는 느리고 공간은 훨씬 더 많습니다 |
| **입력/출력** | 키보드, 마우스, 스크린, 네트워크 | 셰프가 주문을 받고 음식을 배달하는 방법 |
| **GPU**(그래픽 처리 장치) | 병렬 작업을 위한 특수 프로세서(그래픽, AI) | 동일한 작업을 동시에 수행하는 보조자 팀 |
**주요 통찰력**: RAM은 빠르지만 일시적입니다. 저장은 느리지만 영구적입니다. 컴퓨터가 "느리게 느껴진다"는 것은 RAM이 부족하여 저장소를 임시 메모리(스와핑)로 사용해야 하기 때문에 발생하는 경우가 많습니다. 이는 훨씬 더 느립니다.

## 프로그래밍 언어 - 컴퓨터와 대화
프로그래밍 언어는 컴퓨터가 실행할 수 있는 명령 집합입니다. 다양한 언어는 다양한 목적을 위해 설계되었습니다. 34개 개별 언어에 대한 자세한 내용은[`programming_languages/`](../01_coding_and_technology/programming_languages/)폴더를 참조하세요.
| 언어 | 최고의 대상 | 그것을 선택하는 이유 |
|------------|---------|---------------|
| **파이썬** | 데이터 과학, AI, 자동화, 웹 백엔드 | 간단한 구문; 거대한 생태계; 초보자에게 적합 |
| **자바스크립트** | 웹 프런트엔드, 전체 스택(Node.js) | 모든 브라우저에서 실행됩니다. 웹 개발에 꼭 필요한 |
| **자바** | 엔터프라이즈 소프트웨어, Android 앱 | 플랫폼 독립적(JVM); 대규모 생태계 |
| **C/C++** | 시스템 프로그래밍, 게임, 임베디드 | 최대 성능; 직접적인 하드웨어 제어 |
| **러스트** | 안전을 보장하는 시스템 프로그래밍 | 가비지 수집 없는 메모리 안전성 |
| **가기** | 클라우드 서비스, 마이크로서비스, CLI 도구 | 단순한; 뛰어난 동시성; 빠른 컴파일 |
| **SQL** | 데이터베이스 쿼리 | 데이터 작업을 위한 보편적인 언어 |
| **타입스크립트** | 대규모 웹 애플리케이션 | 유형 검사 기능이 있는 JavaScript; 버그를 일찍 잡는다 |

## 인터넷 작동 방식
인터넷은 웹과 다릅니다. 인터넷은 수십억 개의 장치를 연결하는 케이블, 라우터, 서버 및 프로토콜과 같은 물리적 네트워크입니다. 월드와이드웹(World Wide Web)은 (이메일, 파일 전송, 스트리밍, 게임 등과 함께) 인터넷에서 실행되는 하나의 서비스입니다.
### 웹 요청의 여정
브라우저에 `https://www.example.com`를 입력하면:
1. **DNS 조회**: 브라우저는 DNS 서버에 "www.example.com"을 IP 주소(예: 93.184.216.34)로 변환하도록 요청합니다.
2. **TCP 연결**: 장치는 TCP(신뢰할 수 있는 전달을 보장하는 프로토콜)를 사용하여 해당 IP 주소에 대한 연결을 설정합니다.
3. **TLS 핸드셰이크**: HTTPS를 사용하는 경우 브라우저와 서버는 암호화된 연결을 협상합니다.
4. **HTTP 요청**: 브라우저가 "/index.html 페이지를 제공하세요."라는 요청을 보냅니다.
5. **서버 처리**: 웹 서버는 페이지를 찾고, 데이터베이스에 쿼리하고, 응답을 준비합니다.
6. **HTTP 응답**: 서버는 HTML, CSS 및 JavaScript를 다시 보냅니다.
7. **렌더링**: 브라우저가 HTML을 구문 분석하고, CSS 스타일을 적용하고, JavaScript를 실행하여 페이지를 표시합니다.
이 전체 프로세스는 일반적으로 1초도 채 걸리지 않습니다.
### 주요 프로토콜
| 프로토콜 | 그것이 하는 일 | 레이어 |
|----------|-------------|-------|
| **IP**(인터넷 프로토콜) | 네트워크 간 패킷 라우팅 | 네트워크 |
| **TCP** | 안정적이고 순서화된 전달(손실된 패킷 재전송) | 교통 |
| **UDP** | 빠르고 신뢰할 수 없는 전달(재전송 없음) | 교통 |
| **HTTP/HTTPS** | 웹페이지 전송(HTTPS가 암호화 추가) | 신청 |
| **DNS** | 도메인 이름을 IP 주소로 변환 | 신청 |
| **SSH** | 컴퓨터에 대한 원격 액세스 보안 | 신청 |
| **SMTP/IMAP** | 이메일 보내기 및 받기 | 신청 |

## 소프트웨어 개발 — 프로그램 구축 방법
### 개발 과정
1. **코드 작성**: 개발자는 프로그래밍 언어로 지침을 작성합니다.
2. **테스트 코드**: 코드를 실행하여 올바르게 작동하는지 확인합니다.
3. **버전 관리**: 범용 표준인 Git을 사용하여 변경 사항을 추적합니다.
4. **검토**: 다른 개발자가 코드의 오류와 품질을 확인합니다.
5. **빌드**: 소스 코드를 실행 가능한 프로그램(컴파일)으로 변환합니다.
6. **배포**: 프로그램을 사용자(서버, 앱 스토어 등)에게 출시합니다.
7. **모니터**: 프로덕션에서 오류 및 성능 문제를 감시합니다.
### 주요 개념
| 개념 | 그것이 의미하는 것 | 중요한 이유 |
|---------|---------------|---|
| **버전 관리(Git)** | 시간 경과에 따른 코드의 모든 변경 사항 추적 | 협동; 실수를 취소하는 능력 |
| **API**(애플리케이션 프로그래밍 인터페이스) | 소프트웨어 구성 요소가 통신하는 정의된 방법 | 서로 다른 시스템이 함께 작동하도록 허용 |
| **데이터베이스** | 데이터를 위한 체계적인 스토리지 | 모든 애플리케이션은 데이터를 저장하고 검색해야 합니다 |
| **테스트** | 코드가 올바르게 작동하는지 자동으로 확인 | 버그가 사용자에게 도달하는 것을 방지합니다 |
| **CI/CD**(지속적 통합/전달) | 코드 커밋부터 프로덕션까지 자동화된 파이프라인 | 더 빠르고 안전한 릴리스 |
| **컨테이너화(Docker)** | 모든 종속성을 포함하여 애플리케이션을 패키지화 | "내 컴퓨터에서 작동"이 "어디서나 작동"이 됩니다 |

## 데이터베이스 — 데이터가 존재하는 곳
모든 애플리케이션은 데이터를 저장해야 합니다. 데이터베이스는 이를 효율적이고 안정적으로 수행하는 시스템입니다.
| 유형 | 데이터 저장 방법 | 최고의 대상 | 예 |
|------|------|----------|---------|
| **관계형(SQL)** | 행과 열이 있는 테이블 엄격한 스키마 | 구조화된 데이터 복잡한 쿼리; 거래 | PostgreSQL, MySQL, SQLite |
| **문서(NoSQL)** | JSON과 유사한 문서 유연한 스키마 | 반구조화된 데이터 신속한 반복 | 몽고DB, 카우치DB |
| **키-값** | 단순 키 → 값 쌍 | 캐싱; 세션 저장; 빠른 조회 | Redis, DynamoDB |
| **그래프** | 노드와 에지(관계) | 소셜 네트워크 추천 엔진 | Neo4j, 야누스그래프 |
| **시계열** | 타임 스탬프 데이터에 최적화 | 모니터링; 해석학; IoT | InfluxDB, 타임스케일DB |
**SQL**(Structured Query Language)은 관계형 데이터베이스의 표준 언어입니다. 이는 배울 수 있는 가장 귀중한 기술 중 하나입니다. 거의 모든 조직이 데이터베이스를 사용하고 SQL은 데이터베이스와 대화하는 방법입니다.

## 운영 체제
운영 체제(OS)는 사용자(및 프로그램)와 하드웨어 사이의 소프트웨어 계층입니다. 메모리, 프로세스, 파일 및 장치를 관리합니다.
| 운영체제 | 그것이 지배하는 곳 | 주요 기능 |
|----|------|-------------|
| **창** | 데스크톱/노트북 PC(시장 점유율 ~72%) | 가장 광범위한 소프트웨어/하드웨어 호환성 |
| **맥OS** | 창의적인 전문가, 개발자 | 유닉스 기반; 세련된 UI; 애플 생태계 |
| **리눅스** | 서버(~96%), 슈퍼컴퓨터(100%), 임베디드, 개발자 | 오픈 소스; 무료; 매우 사용자 정의 가능 |
| **안드로이드** | 모바일(글로벌 시장 점유율 약 72%) | Linux 커널 기반; 오픈 소스 |
| **iOS** | 모바일(전 세계 약 27%, 수익은 더 높음) | 폐쇄형 생태계; 우아한; 개인 정보 보호 중심 |
Linux는 특별히 언급할 가치가 있습니다. Linux는 대부분의 인터넷, 모든 상위 500대 슈퍼컴퓨터, 대부분의 클라우드 인프라 및 모든 Android 휴대폰을 지원합니다. 무료이며 오픈 소스이며 글로벌 커뮤니티에서 유지관리합니다.

## 클라우드 컴퓨팅
클라우드 컴퓨팅은 자체 하드웨어를 구입하고 유지 관리하는 대신 인터넷을 통해 컴퓨팅 리소스(서버, 스토리지, 데이터베이스 등)를 임대하는 것을 의미합니다. 클라우드 아키텍처, 서비스 모델 및 공급자 비교에 대한 포괄적인 가이드는 [cloud architecture](../01_coding_and_technology/cloud_architecture.md)를 참조하세요.
| 서비스 모델 | 당신이 얻는 것 | 비유 | 예 |
|---------------|-------------|---------|---------|
| **IaaS**(인프라) | 가상 서버, 스토리지, 네트워킹 | 토지를 임대하고 원하는 것을 건설 | AWS EC2, 구글 컴퓨트 엔진 |
| **PaaS**(플랫폼) | 런타임 환경; 코드를 가져오세요 | 가구가 딸린 아파트 임대 | 헤로쿠, 구글 앱 엔진 |
| **SaaS**(소프트웨어) | 신청서를 작성하세요. 그냥 사용하세요 | 호텔 숙박 | 지메일, 슬랙, 세일즈포스 |
3개의 주요 클라우드 제공업체는 **AWS**(Amazon, ~32% 시장 점유율), **Azure**(Microsoft, ~23%), **GCP**(Google, ~10%)입니다. 컴퓨팅, 스토리지, 데이터베이스, AI, 네트워킹 등을 다루는 수백 가지 서비스를 제공합니다.

## 사이버 보안 — 디지털 시스템 보호
사이버 보안은 공격으로부터 컴퓨터, 네트워크 및 데이터를 보호하는 관행입니다. 모든 것이 연결되어 있고 위반으로 인한 비용이 엄청나기 때문에 중요합니다. OWASP Top 10, 보안 개발 수명주기 및 비밀 관리를 다루는 전체 가이드는 [security best practices](../01_coding_and_technology/security_best_practices.md)를 참조하세요.
### 일반적인 위협
| 위협 | 그것은 무엇입니까 | 예방 |
|---------|------------|------------|
| **멀웨어** | 악성 소프트웨어(바이러스, 웜, 트로이 목마) | 바이러스 백신; 소프트웨어를 최신 상태로 유지 |
| **피싱** | 정보를 공개하도록 속이는 가짜 이메일/메시지 | 훈련; 이메일 필터링; 회의론 |
| **랜섬웨어** | 귀하의 데이터를 암호화합니다. 열쇠에 대한 지불을 요구 | 백업; 패치 시스템; 지불하지 않는다 |
| **디도스** | 트래픽으로 서비스를 압도함 | 트래픽 필터링 CDN 보호 |
| **SQL 주입** | 입력 필드에 악성 SQL 삽입 | 매개변수화된 쿼리 입력 유효성 검사 |
| **중간자** | 두 당사자 간의 통신을 가로채기 | HTTPS/TLS 암호화 |
### 보안 기본 사항
- **암호화**: 승인된 당사자만 읽을 수 있도록 데이터를 스크램블합니다. HTTPS는 TLS를 사용하여 웹 트래픽을 암호화합니다.
- **인증**: 본인임을 확인합니다. 다중 요소 인증(MFA)을 사용합니다. 즉, 비밀번호 + 기타 항목(코드, 생체 인식)입니다.
- **권한**: 권한을 확인합니다. 로그인했다고 해서 모든 것에 액세스해야 하는 것은 아닙니다.
- **최소 권한의 원칙**: 사용자와 시스템에 필요한 액세스 권한만 부여합니다.
- **패치 관리**: 소프트웨어를 최신 상태로 유지합니다. 대부분의 위반은 이미 패치가 있는 알려진 취약점을 악용합니다.

## 데이터 형식
프로그램은 특정 형식으로 데이터를 교환합니다. 가장 일반적인 것:
| 형식 | 구조 | 사용 대상 |
|---------|------------|----------|
| **제이슨** | 키-값 쌍 사람이 읽을 수 있는 | 아피스; 구성; 데이터 교환 |
| **XML** | 태그 기반; 장황하지만 유연함 | 레거시 시스템 서류; SOAP API |
| **YAML** | 들여쓰기 기반; 매우 읽기 쉽다 | 구성(Docker, Kubernetes, CI/CD) |
| **CSV** | 일반 텍스트 행과 열 | 데이터 가져오기/내보내기; 스프레드시트 |

## 요약
컴퓨팅은 마술이 아니라 엔지니어링입니다. 컴퓨터는 놀라운 속도로 명령을 따릅니다. 인터넷은 표준화된 프로토콜을 사용하여 수십억 개의 네트워크를 연결합니다. 소프트웨어는 반복적인 주기로 코드를 작성, 테스트 및 배포하는 사람들로 구성된 팀에 의해 구축됩니다. 데이터베이스는 데이터를 저장하고 검색합니다. 클라우드 컴퓨팅을 사용하면 누구나 필요에 따라 대규모 컴퓨팅 리소스에 액세스할 수 있습니다. 그리고 사이버 보안은 이를 악용하려는 사람들로부터 이 모든 것을 안전하게 보호하기 위한 지속적인 전투입니다. 이러한 기본 사항을 이해하면 사용자, 개발자 또는 현대 생활을 형성하는 기술을 이해하려는 사람이든 디지털 세계를 탐색하는 데 도움이 됩니다.
