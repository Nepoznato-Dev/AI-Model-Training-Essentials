# 과학과 교육학을 배우다
학습과학은 사람들이 어떻게 학습하는지에 대한 학제간 연구로, 심리학, 신경과학, 교육, 인지과학을 활용합니다. 교육학은 교육의 실천이자 방법론입니다. 그들은 함께 교육 콘텐츠를 가르치고, 훈련하고, 멘토하고, 디자인하는 모든 사람과 관련된 질문을 다룹니다. 어떤 방법이 사람들이 효과적으로 학습하는 데 도움이 됩니까? 어떤 일반적인 학습 기법이 비효율적인가요? 최적의 유지 및 전달을 위해 교육은 어떻게 구성되어야 합니까?
---

## 학습 작동 방식
### 학습 과정
| 무대 | 설명 | 핵심요소 |
|-------|-------------|------------|
| **주의** | 정보가 처리되려면 반드시 고지되어야 합니다 | 진기함; 관련성; 정서적 의미 |
| **인코딩** | 정보는 정신적 표현으로 변환됩니다 | 사전 지식과의 연결; 정교 |
| **통합** | 시간이 지남에 따라 메모리 추적이 안정화됨 | 잠; 간격을 둔 반복; 반사 |
| **스토리지** | 정보는 장기 기억에 유지됩니다 | 의미 있는 조직; 기존 지식과의 연결 |
| **검색** | 필요할 때 정보에 액세스 | 검색을 연습하세요. 다양한 맥락 |
| **이동** | 지식이 새로운 상황에 적용됩니다 | 다양한 연습; 단순한 절차가 아닌 원리 이해 |
### 인지 부하 이론
| 유형 | 설명 | 교육적 의미 |
|------|-------------|-------------|
| **고유부하** | 재료 고유의 어려움 | 복잡성을 관리합니다. 단순한 것부터 복잡한 것까지의 순서 |
| **외부하중** | 잘못된 명령어 설계로 인한 어려움 | 불필요한 복잡성을 제거하십시오. 명확한 예; 좋은 형식 |
| **게르만 하중** | 실제 학습에 전념하는 정신적인 노력(스키마 구축) | 정교화를 장려합니다. 자기 설명; 의미 있는 실천 |
**주요 통찰력**: 작업 메모리는 제한되어 있습니다(한 번에 대략 4±1개 항목). 수업은 학습에 인지 자원을 사용할 수 있도록 외부 부하를 최소화해야 합니다.

## 증거 기반 학습 전략
### 매우 효과적인 전략
| 전략 | 설명 | 작동 이유 | 증거 수준 |
|----------|-------------|-------------|---|
| **검색 연습** | 기억에서 정보를 적극적으로 회상 | 기억 흔적을 강화합니다. 격차 식별 | 매우 강함 |
| **간격연습** | 시간에 따른 학습 세션 배포 | 강제 재결합; 망각 곡선과 싸우다 | 매우 강하다 |
| **인터리빙** | 다양한 유형의 문제나 주제 혼합 | 차별을 개선합니다. 더 나은 환승 | 강한 |
| **정교** | 새로운 정보가 귀하가 알고 있는 것과 어떻게 관련되는지 설명하기 | 더 풍부한 메모리 추적을 생성합니다. 더 깊은 인코딩 | 강한 |
| **구체적인 예** | 구체적인 예를 사용하여 추상적 개념 설명 | 추상적인 아이디어를 실체화합니다. 이해를 돕습니다 | 강한 |
| **이중 코딩** | 단어와 영상의 결합 | 언어적 및 시각적 처리 채널을 모두 사용합니다 | 강한 |
### 비효율적인 전략(인기에도 불구하고)
| 전략 | 효과적이라고 느껴지는 이유 | 실제로는 그렇지 않은 이유 |
|----------|---------|---------|
| **다시 읽기** | 유창함의 환상 - 텍스트가 친숙하게 느껴짐 | 수동적인; 검색을 강화하지 않습니다 |
| **하이라이트** | 생산적인 느낌; 중요한 정보를 표시 | 깊은 처리가 필요하지 않습니다 |
| **요약** | 적극적으로 참여하는 것 같습니다 | 종종 그대로 복사됩니다. 검색이 필요하지 않습니다 |
| **집단연습(벼락치기)** | 단기 리콜에 사용 | 급속한 망각; 불쌍한 전송 |
| **학습 스타일**(시각/청각/운동 감각) | 직관적으로 매력적 | 선호하는 스타일에 맞는 교육이 학습을 향상시킨다는 증거는 없습니다 |

## 망각곡선과 간격 있는 반복
### 에빙하우스 망각곡선
| 학습 후 시간 | 보존(검토 없음) |
|---------|---------|
| **20분** | ~58% |
| **1시간** | ~44% |
| **1일** | ~33% |
| **2일** | ~28% |
| **6일** | ~25% |
| **31일** | ~21% |
### 간격 반복 일정
| 검토 | 타이밍 | 효과 |
|---------|---------|---------|
| **1차 리뷰** | 학습 후 1일 | 유지율 대폭 향상 |
| **2차 리뷰** | 3일 후 | 기억력을 더욱 강화 |
| **3번째 리뷰** | 7일 후 | 메모리의 내구성이 향상됨 |
| **4번째 리뷰** | 14일 후 | 장기 통합 |
| **5번째 리뷰** | 30일 후 | 안정적인 장기 기억 |
각 리뷰는 망각 곡선을 더욱 멀리 밀어냅니다. 검색이 성공할 때마다 최적의 간격이 늘어납니다.

## 블룸의 분류
| 레벨 | 인지 과정 | 동작 동사 | 예제 작업 |
|-------|------|-------------|--------------|
| **기억하세요** | 사실과 기본 개념을 상기하세요 | 정의하다; 목록; 이름; 식별 | "유사분열 단계 나열" |
| **이해** | 아이디어나 개념 설명 | 설명하다; 설명하다; 요약하다; 분류하다 | "유사분열이 왜 중요한지 설명하세요" |
| **신청** | 새로운 상황에서 정보를 활용하세요 | 해결하다; 사용; 입증하다; 구현 | "유사분열이 중단되면 어떤 일이 일어날지 예측하세요" |
| **분석** | 아이디어 간의 연결 그리기 | 비교하다; 차이; 분류하다; 조사하다 | "유사분열과 감수분열 비교" |
| **평가** | 입장이나 결정을 정당화 | 판사; 비평; 지키다; 논쟁하다 | "통제되지 않은 세포 분열의 결과를 평가합니다" |
| **만들기** | 새로운 작품이나 독창적인 작품 제작 | 설계; 건설하다; 개발하다; 공식화 | "세포 분열에 대한 독소의 영향을 테스트하기 위한 실험 설계" |

## 교육 설계 모델
### ADDIE 모델
| 단계 | 설명 |
|-------|-------------|
| **분석** | 학습자의 요구 사항을 파악합니다. 목표; 기존 지식; 제약 |
| **디자인** | 학습 목표를 정의합니다. 평가 전략; 콘텐츠 구조 |
| **개발** | 자료를 작성하십시오. 활동; 평가 |
| **구현** | 지시사항을 전달합니다. 학습 촉진 |
| **평가** | 효율성을 평가합니다. 피드백을 수집하고; 반복 |
### Backward Design (디자인에 의한 이해)
| 단계 | 설명 |
|------|-------------|
| **1. 원하는 결과 확인** | 학습자는 무엇을 알고, 이해하고, 할 수 있어야 하는가? |
| **2. 수용 가능한 증거 결정** | 그들이 결과를 달성했는지 어떻게 알 수 있나요? (평가 우선) |
| **3. 학습 경험 계획** | 학습자가 성공할 수 있도록 어떤 활동, 교육 및 연습을 하게 됩니까? |
### 비계
| 기술 | 설명 |
|------------|-------------|
| **모델링** | 기술이나 사고 과정을 보여줍니다 |
| **생각해 보세요** | 문제를 해결하면서 추론을 말로 표현하기 |
| **실제 사례** | 학습자에게 문제 해결을 요청하기 전에 완전한 솔루션 표시 |
| **점진적 출시** | "나는 한다 → 우리는 한다 → 너는 한다" — 점진적으로 지원 제거 |
| **프롬프트** | 학습자를 답으로 안내하는 질문하기 |
| **청킹** | 복잡한 작업을 관리 가능한 조각으로 나누기 |

## 동기 부여 및 참여
### 자기 결정 이론
| 필요 | 설명 | 지원 방법 |
|------|-------------|---|
| **자율성** | 자신의 행동을 통제할 수 있다는 느낌 | 선택사항 제공 근거를 설명하다; 언어 통제를 피하다 |
| **역량** | 효과적이고 유능하다는 느낌 | 적절한 도전; 시기적절한 피드백; 진행 상황을 축하 |
| **관련성** | 다른 사람과 연결된 느낌 | 협동 학습; 지원적인 환경; 커뮤니티와의 관련성 |
### 성장 대 고정적 사고방식(Carol Dweck)
| 사고방식 | 신념 | 행동 | 실패에 대한 대응 |
|---------|---------|----------|------|
| **고정** | 지능은 정적이다 | 도전을 피합니다. 쉽게 포기하다 | "나는 이것을 잘하지 못한다" |
| **성장** | 지능을 개발할 수 있습니다 | 도전을 수용합니다. 지속 | "나는 이것을 아직 배우지 못했습니다" |

## 평가
### 평가 유형
| 유형 | 목적 | 타이밍 | 예 |
|------|---------|---------|---------|
| **진단** | 사전 지식과 오해 식별 | 지시 전 | 사전 테스트; 컨셉 인벤토리 |
| **형성** | 학습 모니터링 피드백 제공 | 교육 중 | 퀴즈; 출구 티켓; 동료 검토 |
| **요약** | 마지막에 학습 평가 | 지시 후 | 최종 시험; 프로젝트; 포트폴리오 |
| **정품** | 실제 적용 평가 | 도중이나 이후 | 사례 연구 시뮬레이션; 인턴십 |
### 효과적인 피드백
| 원리 | 설명 |
|------------|-------------|
| **적절한** | 곧 조치를 취할 수 있을 만큼 |
| **구체적** | 특정 강점과 약점을 지적 |
| **실행 가능** | 학습자에게 다음에 무엇을 해야 할지 알려줍니다 |
| **과제에 집중** | 그 사람에 관한 것이 아닙니다("당신은 좋은 작가가 아닙니다"가 아니라 "이 주장에는 더 많은 증거가 필요합니다") |
| **균형** | 무엇이 효과가 있고 무엇이 개선이 필요한지 식별 |
---

## 요약
과학을 학습하면 가장 효과적인 전략이 직관에 반하는 경우가 많다는 것을 알 수 있습니다. 검색 연습(자신을 테스트하는 것)은 다시 읽는 것보다 훨씬 더 효과적입니다. 간격을 두고 반복하는 것이 벼락치기를 이기는 것입니다. 다양한 유형의 문제를 끼워 넣으면 차별과 전이가 향상됩니다. 인지 부하 이론은 작업 메모리가 제한되어 있다는 사실을 상기시켜 줍니다. 즉, 지침은 외부 부하를 최소화하도록 설계되어야 합니다. Bloom의 분류 체계는 회수에서 생성까지 진행하기 위한 프레임워크를 제공합니다. 교수 설계 모델(ADDIE, 역방향 설계)은 효과적인 학습 경험을 개발하기 위한 구조화된 접근 방식을 제공합니다. 동기 부여는 자율성, 역량 및 관련성에 따라 달라집니다. 평가는 학습 목표와 일치해야 하며 단순히 총괄 성적이 아닌 형성 피드백을 포함해야 합니다. 학습에 대한 가장 큰 신화는 사람들이 고정된 "학습 스타일"을 가지고 있다는 것입니다. 선호하는 스타일에 교육을 맞추는 것이 결과를 향상시키지 않는다는 증거가 일관되게 나타났습니다. 노력이 필요한 검색, 간격을 둔 연습, 다양한 예 및 의미 있는 피드백은 누구에게나 효과적입니다.
