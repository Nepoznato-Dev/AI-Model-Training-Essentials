# 연구 방법론
연구 방법론은 질문을 조사하고, 가설을 테스트하고, 신뢰할 수 있는 지식을 생성하기 위한 체계적인 접근 방식입니다. 과학 실험, 사회 과학 설문조사, 비즈니스 분석, 학술 연구 등 무엇을 수행하든 선택한 방법론에 따라 결과가 신뢰할 수 있고 재현 가능하며 유용한지 여부가 결정됩니다. 잘 설계된 연구는 신뢰할 수 있는 결과를 낳습니다. 제대로 설계되지 않은 디자인은 소음을 발생시키거나 더 나쁜 경우 자신감 넘치는 오답을 생성합니다.
---

## 연구 유형
| 차원 | 옵션 | 설명 |
|------------|---------|-------------|
| **목적** | 기본 vs 응용 | 기본: 지식 자체를 확장합니다. 적용: 실질적인 문제 해결 |
| **접근법** | 연역적 대 귀납적 | 연역적: 이론 → 가설 → 관찰. 귀납적: 관찰 → 패턴 → 이론 |
| **데이터 유형** | 정량적 vs 정성적 vs 혼합 | 정량적: 숫자. 질적: 단어, 의미. 혼합: 둘 다 |
| **시간 범위** | 단면 대 세로 | 단면적: 한 시점. 세로 방향: 시간이 지남에 따라 |
| **설정** | 실험적 vs 관찰적 | 실험적: 연구자가 변수를 조작합니다. 관찰: 연구자가 개입 없이 관찰 |
---

## 과학적 방법
| 단계 | 설명 |
|------|-------------|
| **1. 관찰** | 현상이나 패턴을 주목하세요 |
| **2. 질문** | 구체적이고 테스트 가능한 질문 작성 |
| **3. 가설** | 잠정적인 설명이나 예측 제안 |
| **4. 예측** | 가설로부터 테스트 가능한 예측 도출 |
| **5. 실험/관찰** | 예측을 테스트하기 위한 데이터 수집 |
| **6. 분석** | 데이터를 분석합니다. 결과가 가설을 뒷받침하는지 반박하는지 판단 |
| **7. 결론** | 결론을 도출하십시오. 한계를 고려하십시오. 추가 연구 제안 |
| **8. 동료 검토 및 복제** | 다른 사람들은 결과를 평가하고 재현하려고 시도합니다 |

## 정량적 연구
### 실험적 디자인
| 디자인 | 설명 | 힘 | 약점 |
|---------|-------------|----------|----------|
| **실제 실험(RCT)** | 치료 및 통제에 대한 무작위 배정 | 가장 강력한 인과관계 증거 | 값비싼; 일반화할 수 없습니다 |
| **준실험** | 무작위 할당이 없습니다. 비교 그룹 | 더 실용적입니다. 실제 설정 | 혼란스러운 변수 |
| **사전 테스트/사후 테스트** | 개입 전후 측정 | 시간에 따른 변화를 보여줍니다 | 외부 요인에 대한 통제 없음 |
| **요인 설계** | 여러 독립변수를 동시에 조작 | 변수 간의 상호 작용을 테스트합니다 | 복잡한; 큰 샘플이 필요함 |
| **피험자 내** | 모든 조건에서 동일한 참가자 | 개인차를 통제합니다. 참가자 감소 | 주문효과; 이월 |
| **과목간** | 각 조건에 따른 다양한 참가자 | 이월 효과 없음 | 개인차; 더 많은 참가자가 필요합니다 |
### 샘플링 방법
| 방법 | 유형 | 설명 | 사용 시기 |
|---------|------|-------------|-------------|
| **단순 무작위** | 확률 | 모든 회원은 동등한 선택 기회를 갖습니다 | 골드 스탠다드; 완전한 샘플링 프레임이 필요합니다 |
| **층화된 무작위** | 확률 | 지층으로 나누십시오. 각각의 무작위 샘플 | 하위 그룹의 표현 보장 |
| **클러스터** | 확률 | 무작위로 그룹을 선택합니다. 내의 모든 설문조사 | 대규모 인구; 비용 효율적인 |
| **편의성** | 비확률 | 누구든지 가능한 샘플 | 빠른; 값이 싼; 하지만 편견 |
| **목적** | 비확률 | 특정 사례를 의도적으로 선택 | 전문가 의견 특정 특성 |
| **눈덩이** | 비확률 | 기존 참가자 모집 | 접근하기 어려운 인구 |
### 통계분석
| 분석 유형 | 목적 | 예 |
|---------------|---------|---------|
| **기술통계** | 데이터 요약 | 평균; 중앙값; 표준편차; 빈도 분포 |
| **추론통계** | 표본을 통해 모집단에 대한 결론 도출 | t-테스트; 분산분석; 카이제곱; 회귀 |
| **상관관계** | 변수 간의 연관성 측정 | 피어슨의 r; 스피어먼의 로 |
| **회귀** | 종속변수와 독립변수 간의 모델 관계 | 선형 회귀; 로지스틱 회귀 |
| **요인분석** | 데이터의 기본 차원 식별 | PCA; 탐색적 요인 분석 |
| **메타분석** | 여러 연구의 결과 결합 | 치료 효과의 체계적인 검토 |

## 질적 연구
### 방법
| 방법 | 설명 | 최고의 대상 |
|---------|-------------|----------|
| **인터뷰** (반구조화) | 개방형 질문; 프로빙 | 경험에 대한 깊은 이해; 의미 |
| **포커스 그룹** | 진행자가 진행하는 그룹 토론 | 그룹 규범 탐색 아이디어 생성 |
| **민족지학** | 자연환경 몰입관찰 | 문화 이해; 사회적 관행 |
| **사례 연구** | 단일 사례 또는 소수 사례에 대한 심층 조사 | 맥락에 따른 복잡한 현상 |
| **근거이론** | 반복 코딩을 통해 데이터로부터 이론 구축 | 기존 이론이 부적절할 때 |
| **콘텐츠 분석** | 텍스트/미디어의 체계적인 코딩 | 대량의 텍스트; 미디어 분석 |
| **담론분석** | 사용중인 언어에 대한 연구; 권력관계 | 언어가 현실을 구성하는 방법 |
| **현상학** | 살아온 경험의 이해 | 사람들이 현상을 경험하는 방법 |
### 질적 연구의 품질 보장
| 기준 | 설명 | 달성 방법 |
|------------|-------------|---|
| **신뢰성**(내부 타당성) | 조사 결과는 참가자의 견해를 정확하게 나타냅니다 | 삼각 측량; 회원 확인; 장기간의 참여 |
| **이전 가능성**(외부 유효성) | 다른 상황에 적용 가능한 조사 결과 | 두꺼운 설명; 목적이 있는 샘플링 |
| **종속성**(신뢰성) | 연구가 반복되면 일관된 결과 | 감사 추적; 동료 보고 |
| **확인성**(객관성) | 연구자의 편견이 아닌 데이터에 근거한 결과 | 반사성; 삼각 측량; 감사 추적 |

## 혼합 방법
| 디자인 | 설명 | 사용 시기 |
|---------|-------------|-------------|
| **수렴 병렬** | 정량적 및 정성적 데이터를 동시에 수집합니다. 비교 | 폭과 깊이를 모두 원할 때 |
| **설명적 순차** | 양적 우선; 결과를 설명하기 위한 질적 분석 | 설문조사 결과에 대한 더 깊은 이해가 필요한 경우 |
| **탐색적 순차** | 질적 우선; 결과를 테스트하기 위한 정량적 | 도구나 이론을 먼저 개발해야 할 때 |

## 타당성 및 신뢰성
### 타당성에 대한 위협
| 위협 | 설명 | 완화 |
|---------|-------------|------------|
| **선택 편향** | 그룹은 개입 전에 체계적으로 다릅니다 | 무작위 할당; 매칭 |
| **감소 편향** | 참가자가 무작위로 탈락함 | 이유를 추적하세요. 치료 의도 분석 |
| **호손 효과** | 사람들은 관찰되기 때문에 행동을 바꾼다 | 통제 그룹; 눈부신 |
| **수요 특성** | 참가자들은 가설을 추측하고 그에 따라 행동합니다 | 기만; 커버스토리 |
| **실험자 편향** | 연구자의 기대가 결과에 영향을 미침 | 눈이 멀다; 표준화된 절차 |
| **혼란스러운** | 세 번째 변수는 관계를 설명합니다 | 통제변수; 무작위화; 통계적 조정 |
| **P-해킹** | 하나가 중요해질 때까지 많은 가설 테스트 | 사전등록; 다중 비교를 위한 수정 |
### 신뢰성 측정
| 측정 | 설명 |
|---------|-------------|
| **테스트-재테스트** | 동일한 테스트가 두 번 실시되었습니다. 점수 간의 상관관계 |
| **평가자간** | 다양한 평가자/코더 간의 합의 |
| **내부 일관성** | 크론바흐 알파; 동일한 구조를 측정하는 항목 |
| **병렬 형태** | 동일한 테스트의 서로 다른 버전 간 상관관계 |

## 연구윤리
| 원리 | 설명 |
|------------|-------------|
| **사전 동의** | 참가자는 자신이 동의하는 내용을 이해합니다. 자발적 참여 |
| **선의** | 혜택을 극대화하세요. 피해 최소화 |
| **악의 없음** | 해를 끼치지 마십시오 — 신체적, 심리적, 사회적 |
| **정의** | 혜택과 부담의 공정한 분배 취약한 인구를 착취하지 마세요 |
| **개인정보 보호 및 기밀 유지** | 참가자의 데이터를 보호합니다. 가능한 경우 익명화 |
| **철회권** | 참가자는 언제든지 불이익 없이 연구를 떠날 수 있습니다 |
| **보고** | 참여 후 연구 목적을 설명합니다. 특히 속임수가 사용된 경우 |

## 요약
연구 방법론은 연구 결과가 신뢰할 수 있는지 여부를 결정하는 프레임워크입니다. 가설을 검증하고 효과를 측정하는 데에는 정량적 방법(실험, 설문 조사, 통계 분석)이 가장 적합합니다. 질적 방법(인터뷰, 민족지학, 사례 연구)은 의미, 맥락 및 경험을 이해하는 데 가장 적합합니다. 혼합 방법은 폭과 깊이를 모두 결합합니다. 과학적 방법은 관찰부터 가설, 데이터 수집, 분석, 동료 검토를 거쳐 구조화된 프로세스를 제공합니다. 타당성(측정하고 있다고 생각하는 것을 측정하고 있습니까?)과 신뢰성(다시 동일한 결과를 얻을 수 있습니까?)이 핵심 품질 기준입니다. 연구 윤리는 지식 추구가 참가자의 권리와 복지를 희생하지 않도록 보장합니다. 가장 중요한 원칙은 방법론이 연구 질문에 도움이 된다는 것입니다. 가장 익숙하거나 쉬운 접근 방식이 아닌 질문에 가장 잘 답하는 접근 방식을 선택하십시오.
