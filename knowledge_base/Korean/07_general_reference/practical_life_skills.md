# 실생활의 기술
학교에서는 미적분학을 가르치지만 세금 신고, 균형 잡힌 식사 요리, 집을 관리하는 방법은 거의 가르치지 않습니다. 이는 일상적인 삶의 질에 영향을 미치는 실용적인 역량, 즉 자급자족하고 재정적으로 회복력을 갖추게 만드는 종류의 지식입니다. 이 파일은 필수 사항에 대한 밀집된 참조 자료입니다.

## 개인 금융
### 예산 책정: 50/30/20 규칙
Elizabeth Warren 상원의원이 대중화한 가장 간단한 예산 체계:
| 카테고리 | 백분율 | 포함 |
|----------|------------|----------|
| **필요** | 50% | 임대료/모기지, 공과금, 식료품, 보험, 최소 부채 지불, 운송 |
| **원함** | 30% | 외식, 엔터테인먼트, 구독, 취미, 여행 |
| **저축 및 부채 상환** | 20% | 비상자금, 투자, 추가채무상환, 퇴직연금 |
> **필요에 따라 조정**: 비용이 많이 드는 도시에서는 수요가 60~70%를 소비할 수 있습니다. 비율은 법칙이 아니라 지침입니다. 요점은 돈이 어디로 가는지 의도적으로 생각하는 것입니다.
### 주요 재무 개념
| 개념 | 그것이 의미하는 것 | 중요한 이유 |
|---------|---------------|---|
| **복리** | 원금과 누적이자에 대한 이자수익 | 연 수익률 7%로 $10,000 = 30년 후 ~$76,000(센트 추가 없음) |
| **긴급자금** | 유동적 저축 계좌에 3~6개월간 지출 | 실직, 의료비 또는 자동차 수리로 인한 부채 급증을 방지합니다 |
| **신용 점수** | 귀하의 신용도에 대한 수치 등급(대부분의 시스템에서 300-850) | 모기지 금리, 임대 신청, 보험료에 영향을 미칩니다 |
| **인플레이션** | 시간이 지남에 따라 가격이 전반적으로 상승합니다. 구매력 감소 | 매트리스 아래에 절약된 돈은 연간 가치의 ~2-3% 손실 |
| **다각화** | 다양한 자산 유형에 걸쳐 투자 분산 | 위험을 줄입니다. 절대로 한 주식이나 업종에 모든 돈을 투자하지 마세요 |
| **순자산** | 자산에서 부채를 뺀 | 재정건전성의 실제 척도, 소득보다 |
### 부채 관리
| 전략 | 작동 원리 | 최고의 대상 |
|----------|-------------|----------|
| **눈사태 방법** | 모든 부채에 대해 최소 금액을 지불합니다. 이자율이 가장 높은 부채에 먼저 추가 금액을 투입 | 지불된 총 이자를 최소화합니다. 수학적으로 최적 |
| **눈덩이 방식** | 모든 부채에 대해 최소 금액을 지불합니다. 가장 작은 잔액을 먼저 추가로 투입 | 빠른 승리는 동기를 부여합니다. 심리적으로 효과적 |
| **통합** | 여러 부채를 더 낮은 이자율로 하나의 대출로 결합 | 결제를 단순화합니다. 더 나은 요금을 확보할 수 있으면 작동합니다 |
### 세금 기본(일반 원칙)
- **소득세**: 대부분의 국가에서는 소득에 대해 점진적으로 세금을 부과합니다(소득이 높을수록 세율이 높음).
- **세금우대계좌**: 퇴직계좌(401(k), IRA, 연금, ISA)로 세금부담 경감
- **공제 vs 세액공제**: 공제는 과세 소득을 줄입니다. 세액공제는 납부해야 할 세금을 직접적으로 줄여줍니다(세액공제는 더 가치가 있습니다).
- **흔히 저지르는 실수**: 제때에 서류를 제출하지 않습니다. 프리랜서/부업 무시; 적격 공제를 청구하지 못한 경우

## 영양과 요리
### 다량 영양소
| 영양소 | 그램당 칼로리 | 기능 | 좋은 소스 |
|----------|------|----------|-------------|
| **탄수화물** | 4kcal | 1차 에너지원 뇌와 근육의 연료 | 전체 곡물, 과일, 야채, 콩과 식물 |
| **단백질** | 4kcal | 근육, 효소, 호르몬의 빌딩 블록 | 고기, 생선, 계란, 유제품, 콩류, 두부 |
| **지방** | 9kcal | 밀도 높은 에너지; 호르몬 생산; 영양 흡수 | 올리브 오일, 견과류, 아보카도, 지방이 많은 생선, 버터 |
### 가장 중요한 미량 영양소
| 비타민/미네랄 | 기능 | 결핍 증상 | 출처 |
|---|----------|-------|---------|
| **비타민 D** | 칼슘 흡수; 면역 기능 | 피로, 뼈통증, 잦은 질병 | 햇빛, 지방이 많은 생선, 강화 우유 |
| **철** | 혈액의 산소 수송 | 빈혈, 피로, 허약 | 붉은 고기, 시금치, 렌즈콩, 강화 시리얼 |
| **비타민 B12** | 신경 기능; 적혈구 형성 | 마비, 피로, 기억력 문제 | 고기, 계란, 유제품; 채식주의자를 위한 보충제 |
| **칼슘** | 뼈와 치아 구조; 근육 기능 | 약한 뼈, 근육 경련 | 유제품, 잎채소, 강화 식물성 우유 |
| **마그네슘** | 300개 이상의 효소 반응; 잠; 근육 이완 | 근육 경련, 불면증, 불안 | 견과류, 씨앗, 다크 초콜릿, 통곡물 |
| **오메가-3 지방산** | 뇌 건강; 항염증제 | 피부건조, 집중력저하, 관절통 | 지방이 많은 생선, 아마씨, 호두 |
### 균형 잡힌 접시
모든 식사에 대한 간단한 시각적 가이드:
- **반 접시**: 야채와 과일(다양한 색상)
- **분기**: 단백질(손바닥 크기 분량)
- **분기**: 복합 탄수화물(통곡물, 전분질 야채)
- **추가**: 건강한 지방(올리브 오일, 견과류, 아보카도 — 엄지손가락 크기)
### 요리 기초
| 기술 | 그것은 무엇입니까 | 최고의 대상 |
|------------|------------|----------|
| **소테잉** | 소량의 기름으로 중불에서 빠르게 조리 | 야채, 얇은 고기 조각, 새우 |
| **로스팅** | 고열(200-230°C / 400-450°F)에서 오븐 요리하기 | 야채, 통닭, 뿌리채소 |
| **찜** | 먼저 끓인 다음 낮은 불에서 액체에 천천히 조리하세요 | 질긴 고기, 스튜, 풍미 가득한 결과 |
| **찜** | 증기로 요리하기; 영양분과 색상을 보존합니다 | 야채, 생선, 만두 |
| **희미하게** | 짧게 끓인 후 얼음 목욕 | 색상 보존; 냉동 야채 준비 |
### 필수 식품 저장실 필수품
| 카테고리 | 아이템 |
|------------|---------|
| **곡물** | 쌀, 파스타, 귀리, 빵(또는 만드는데 필요한 밀가루) |
| **단백질** | 콩 통조림, 참치 통조림, 계란, 냉동 닭고기 |
| **야채** | 양파, 마늘, 감자, 냉동 혼합 야채 |
| **지방** | 올리브 오일, 버터 |
| **조미료** | 소금, 후추, 간장, 식초, 말린 허브 |
| **유제품/대체식품** | 우유, 치즈, 요구르트 |
> **경험 법칙**: 양파, 마늘, 기름, 소금, 단백질이 있으면 먹을 수 있는 음식을 만들 수 있습니다. 대부분의 요리법은 "계절 및 요리"의 변형입니다.

## 집 관리
### 계절 체크리스트
| 시즌 | 작업 |
|---------|-------|
| **봄** | 배수구를 청소하십시오. 지붕에 손상이 없는지 확인하십시오. 서비스 에어컨; 연기 탐지기 테스트; 딥클린 |
| **여름** | 잔디를 깍다; 해충 진입 지점을 확인하십시오. 깨끗한 창문; 야외 공간 유지 |
| **가을** | 나뭇잎을 긁어 모으십시오. 서비스 난방 시스템; 단열재를 점검하십시오. 깨끗한 굴뚝; 겨울철 파이프 |
| **겨울** | 배관 동파 방지(단열, 보온) 맑은 눈; 초안을 확인하세요. 용광로 필터 변경 |
### 스스로 할 수 있는 일반적인 수리
| 문제 | 수정 | 필요한 도구 |
|---------|-------|-------------|
| **달리는 화장실** | 플래퍼 밸브 교체(보통 원인) | 새로운 플래퍼($5); 도구나 조정 가능한 렌치가 필요하지 않습니다 |
| **막힌 배수구** | 플런저 먼저; 그런 다음 베이킹 소다 + 식초; 그런 다음 뱀을 배출 | 플런저, 베이킹 소다, 식초 |
| **바람이 잘 통하는 창문** | 프레임 주변의 웨더스트립 또는 코킹 | 코크건, 웨더스트립 테이프 |
| **삐걱거리는 문** | 실리콘 스프레이 또는 흑연으로 경첩 윤활 | 스프레이 윤활제 |
| **패치된 건식벽체** | 스패클 작은 구멍; 모래가 매끄러움; 페인트를 터치 | Spackle, 퍼티 나이프, 사포, 페인트 |
| **물이 새는 수도꼭지** | 일반적으로 마모된 와셔 또는 O-링; 먼저 물을 꺼라 | 조정 가능한 렌치, 교체용 와셔 |
### 전문가에게 전화해야 하는 경우
| 상황 | 왜 |
|------------|------|
| **전기공사**(전구교체 그 이상) | 화재 위험; 허가가 필요할 수 있음 |
| **가스기기** | 폭발/CO 위험; 항상 자격증을 갖춘 기술자를 이용하세요 |
| **구조적 변화**(벽체 제거, 기초 균열) | 무결성 구축; 허가가 필요함 |
| **벽 뒤의 배관** | 잘못하면 물 피해 위험 |
| **지붕 수리** | 추락 위험; 부적절한 수리로 인해 누출이 발생함 |
| **HVAC 시스템** | 복잡한; 잘못된 수리로 인해 보증이 무효화되거나 CO 문제가 발생할 수 있음 |

## 시간 관리
### 아이젠하워 매트릭스
| | 긴급 | 긴급하지 않음 |
|---|---|---|
| **중요** | **먼저 수행** — 위기, 기한, 긴급 상황 | **일정** — 운동, 학습, 계획, 관계 |
| **중요하지 않음** | **위임** — 방해, 일부 이메일, 다른 사람의 우선순위 | **제거** — 소셜 미디어 스크롤, 바쁜 업무, 시간 낭비 |
### 실용적인 기술
| 기술 | 작동 원리 | 최고의 대상 |
|------------|-------------|----------|
| **포모도로** | 25분 집중작업 → 5분 휴식 → 반복 | 미루는 습관; 지루한 작업을 통해 집중력 유지하기 |
| **시간 차단** | 달력의 특정 작업에 특정 시간 할당 | 우선순위가 혼합된 날; 중요한 작업에 시간 확보 |
| **2분 규칙** | 작업에 소요되는 시간이 2분 미만이면 즉시 수행 | 정신적으로 쌓인 작은 일들 정리하기 |
| **개구리를 먹어라** | 아침에 가장 어려운/가장 중요한 일을 가장 먼저 수행하세요 | 큰 프로젝트를 미루는 사람들 |
| **일괄 처리** | 유사한 작업(이메일, 전화, 심부름)을 하나의 시간 블록으로 그룹화 | 컨텍스트 전환 오버헤드 감소 |
### 수면 기초
| 요인 | 추천 | 왜 |
|---------|---------------|-----|
| **기간** | 성인의 경우 7~9시간(대부분 ~8시간 필요) | 인지기능, 면역체계, 감정조절 |
| **일관성** | 매일 같은 취침 시간과 기상 시간(주말 포함) | 일주기 리듬을 조절합니다. 잠들기가 더 쉬워진다 |
| **환경** | 서늘함(18-20°C), 어두움, 조용함 | 깊은 잠을 자려면 심부 체온이 떨어져야 합니다 |
| **화면** | 잠자리에 들기 30~60분 전에는 화면을 시청하지 마세요 | 블루라이트는 멜라토닌 생성을 억제합니다 |
| **카페인** | 오후 2시 이후에는 없음(반감기는 ~5-6시간) | 오후의 커피는 여전히 취침 시간에는 반쯤 활동적입니다 |

## 요약
실용적인 삶의 기술은 화려하지는 않지만 복합적입니다. 요리를 배우면 돈이 절약되고 건강도 좋아집니다. 예산은 부채의 급증을 방지합니다. 기본적인 주택 유지 관리로 수천 달러의 수리 비용을 절약할 수 있습니다. 좋은 수면과 시간 관리는 다른 모든 면에서 효율성을 배가시킵니다. 이는 일회성 학습이 아닙니다. 반복하면 더 쉬워지는 일상적인 연습입니다. 한 영역에서 시작하여 습관을 들이고 다음 영역으로 이동하세요.
