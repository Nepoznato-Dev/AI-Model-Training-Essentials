# NLP 기초
자연어 처리(NLP)는 인간의 언어를 이해하고, 생성하고, 사용하도록 기계를 가르치는 분야입니다. 이는 2020년 이후 AI를 변화시킨 검색 엔진, 챗봇, 번역 시스템, 감정 분석 및 대규모 언어 모델(LLM)을 지원합니다. 이 파일은 고전 기술에서 현대 Transformer 기반 아키텍처로의 진화를 다룹니다.
---

## 텍스트 전처리
원시 텍스트가 지저분합니다. 모델이 이를 사용하려면 먼저 정리하고 구조화해야 합니다.
| 단계 | 그것이 하는 일 | 예 |
|------|-------------|---------|
| **토큰화** | 텍스트를 토큰(단어, 하위 단어 또는 문자)으로 분할 | "나는 NLP를 좋아합니다" →`["I", "love", "NLP"]`|
| **소문자** | 소문자로 변환 | "안녕하세요" → "안녕하세요" |
| **단어 제거 중지** | 일반적인 단어 제거(the, is, at) | "고양이 토" → "고양이 토" |
| **어간 추출** | 단어 어미 자르기 (조잡한) | "실행 중" → "실행" |
| **정형화** | 사전 형식으로 축소(컨텍스트 인식) | "더 나은" → "좋은" |
| **정규화** | 인코딩 수정, 특수 문자 제거, 수축 확장 | "하지 마세요" → "하지 마세요" |
최신 Transformer 모델은 종종 불용어 제거 및 형태소 분석을 건너뛰며 데이터에서 이러한 패턴을 학습합니다.
---

## 텍스트 표현
기계에는 단어가 아닌 숫자가 필요합니다. 텍스트를 벡터로 표현하는 방법은 기본입니다.
### 고전적 접근 방식
| 방법 | 설명 | 제한사항 |
|---------|-------------|----------|
| **원-핫 인코딩** | 각 단어는 거대한 벡터에서 고유한 위치입니다 | 부족한; 의미론적 의미 없음 |
| **백 오브 워드(BoW)** | 단어 빈도를 계산합니다. 주문을 무시 | 단어 순서를 완전히 잃음 |
| **TF-IDF** | 문서의 빈도 × 말뭉치 전체의 희귀성에 따라 단어에 가중치를 부여 | 여전히 순서와 컨텍스트를 무시합니다 |
### 단어 임베딩
임베딩은 비슷한 단어가 서로 가까이 있는 밀집된 벡터에 단어를 매핑합니다.
| 모델 | 핵심 아이디어 |
|-------|----------|
| **워드2벡**(2013) | 문맥에서 단어 예측(CBOW) 또는 단어에서 문맥 예측(Skip-gram) |
| **글로브**(2014) | 전역 동시발생 통계 → 밀집 벡터 |
| **패스트텍스트**(2016) | Word2Vec + 하위 단어 정보(희귀 단어를 더 잘 처리) |
유명한 예:`king - man + woman ≈ queen`. 임베딩은 의미론적 관계를 포착합니다.
**제한사항**: 클래식 임베딩은 단어당 하나의 벡터를 할당하므로 다의어(여러 의미를 가진 단어)를 처리할 수 없습니다. "강둑"과 "은행 계좌"의 "은행"은 동일한 벡터를 얻습니다.

## 시퀀스 모델
Transformers 이전에는 NLP의 표준 접근 방식은 텍스트를 순차적으로 처리하는 것이었습니다.
| 건축 | 작동 원리 | 힘 | 약점 |
|-------------|-------------|----------|----------|
| **RNN** | 한 번에 하나씩 토큰을 처리합니다. 숨겨진 상태 유지 | 가변 길이 입력 처리 | 사라지는 그라데이션; 긴 종속성을 캡처할 수 없습니다 |
| **LSTM** | 정보 흐름을 제어하기 위한 게이트(망각, 입력, 출력)가 있는 RNN | 장거리 종속성이 더 좋음 | 여전히 순차적입니다. 훈련이 느림 |
| **그루** | 단순화된 LSTM(게이트 수가 적음) | LSTM보다 빠릅니다. 비슷한 성능 | 동일한 기본 제한 사항 |
이러한 모델은 텍스트를 왼쪽에서 오른쪽으로 처리하므로 학습 속도가 느리고(병렬화할 수 없음) 장거리 종속성으로 인해 어려움을 겪습니다.

## 주의 메커니즘
Attention을 사용하면 모델이 시퀀스의 모든 위치를 동시에 보고 현재 예측과 가장 관련성이 높은 위치를 결정할 수 있습니다.
### 주요 통찰력
RNN처럼 전체 문장을 단일 숨겨진 상태로 압축하는 대신 Attention은 가중치가 학습되는 모든 숨겨진 상태의 가중치 합을 계산합니다.
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

| 구성요소 | 역할 |
|------------|------|
| **쿼리(Q)** | 나는 무엇을 찾고 있나요? |
| **키(K)** | 내 안에는 무엇이 들어있나요? |
| **값(V)** | 나는 어떤 정보를 제공하나요? |
| **√d_k** | 큰 내적을 방지하기 위한 스케일링 팩터 |

## 트랜스포머 아키텍처
Transformer(Vaswani et al., 2017 — "Attention Is All You Need")는 재발을 주의로 완전히 대체했습니다. 이는 사실상 모든 현대 NLP의 기초입니다.
### 건축학
| 구성요소 | 설명 |
|------------|-------------|
| **인코더** | 입력 텍스트를 읽습니다. 상황에 맞는 표현을 생성합니다 |
| **디코더** | 출력 텍스트를 생성합니다. 인코더 출력에 참여 |
| **자기 주의** | 각 토큰은 동일한 순서로 다른 모든 토큰에 참여합니다 |
| **멀티 헤드 어텐션** | 여러 주의 헤드를 병렬로 실행합니다. 다양한 관계 포착 |
| **위치 인코딩** | 위치정보 주입(반복이 없기 때문에) |
| **피드포워드 네트워크** | 각 직위에 독립적으로 적용 |
| **레이어 정규화** | 훈련 안정화 |
| **잔여 연결** | 그라데이션 흐름에 대한 연결 건너뛰기 |
### 인코더 전용, 디코더 전용, 인코더-디코더
| 변형 | 건축 | 최고의 대상 | 예 |
|---------|-------------|----------|---------|
| **인코더 전용** | 텍스트를 이해합니다 | 분류, NER, 감정 분석 | BERT, 로버타, 데버타 |
| **디코더 전용** | 텍스트를 생성합니다 | 언어 모델, 챗봇, 코드 생성 | GPT-3/4, LLaMA, 클로드 |
| **인코더-디코더** | 텍스트 변환 | 번역, 요약 | T5, 바트, mBART |

## 주요 모델 계열
### BERT 제품군(인코더 전용)
| 모델 | 주요 기능 |
|-------|-------------|
| **버트**(2018) | 마스크된 언어 모델 + 다음 문장 예측 |
| **로버타** | NSP가 제거되었습니다. 더 많은 데이터로 더 오랫동안 훈련 |
| **앨버트** | 매개변수 공유; 더 작은 설치 공간 |
| **데버타** | 얽힌 관심; 향상된 NLU |
| **디스틸버트** | 40% 더 작고, 60% 더 빠르며, BERT 성능의 97%를 유지 |
### GPT 제품군(디코더 전용)
| 모델 | 매개변수 | 메모 |
|-------|------------|-------|
| **GPT-2** | 15억 | 표시된 디코더 전용 모델은 일관된 텍스트를 생성할 수 있습니다 |
| **GPT-3** | 175B | 퓨샷 학습; 미세 조정보다는 프롬프트 |
| **GPT-3.5 / GPT-4** | 비공개 | 명령 조정 + RLHF; 대화 |
| **LLaMA**(메타) | 7B–70B | 개방형; 오픈 소스 LLM 생태계 탄생 |
| **미스트랄 / 믹스트랄** | 7B / 8×7B(MoE) | 강력한 성능을 갖춘 효율적인 개방형 모델 |

| **요약** | 긴 텍스트 압축 | T5, 바트, GPT |
| **텍스트 생성** | 일관된 텍스트 생성 | GPT-4, LLaMA, 클로드 |

## 미세 조정 vs 프롬프트
| 접근 | 작동 원리 | 사용 시기 |
|----------|-------------|-------------|
| **미세 조정** | 작업별 데이터에 대한 모델 가중치 업데이트 | 데이터에 레이블이 지정되었습니다. 최대 성능이 필요합니다 |
| **프롬프트** | 자연어로 모델 지침 제공 | 빠른 프로토타이핑; 제한된 데이터; LLM 사용 |
| **퓨샷** | 프롬프트에 예제 포함 | 몇 가지 예제가 있지만 미세 조정하기에 충분하지 않은 경우 |
| **로라 / QLoRA** | 효율적인 미세 조정; 작은 하위 행렬 업데이트 | 제한된 GPU 메모리로 대형 모델을 미세 조정 |

## LLM 환경
현대 NLP 환경은 대규모 언어 모델이 지배합니다.
| 카테고리 | 예 | 메모 |
|----------|---------|-------|
| **독점** | GPT-4, 클로드, 쌍둥이자리 | 최고의 성능; API 액세스 전용 |
| **오픈 웨이트** | LLaMA 3, 미스트랄, 퀀 | 사용 가능한 무게; 로컬로 실행 |
| **오픈 소스** | 피티아, OPT | 완전 개방형(데이터, 가중치, 코드) |
| **다중 모드** | GPT-4V, 제미니, LLaVA | 텍스트 + 이미지 처리 |
| **코드 전문** | CodeLlama, StarCoder, DeepSeek 코더 | 코드 교육 |
| **소형/효율성** | 피-3, 젬마, TinyLlama | 소규모로 강력한 성능 |
현장이 빠르게 움직이고 있습니다. 오늘날의 최첨단 기술은 몇 달 안에 대체될 수 있습니다. 주의, 토큰화, 미세 조정, 평가 등 기본 요소는 안정적으로 유지됩니다.
