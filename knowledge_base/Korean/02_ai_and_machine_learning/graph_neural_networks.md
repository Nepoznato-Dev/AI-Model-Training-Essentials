# 그래프 신경망
그래프 신경망(GNN)은 그래프 구조 데이터(에지로 연결된 노드 네트워크)에서 작동하도록 설계된 신경망입니다. 기존 신경망은 그리드(이미지) 또는 시퀀스(텍스트)에서 작동하지만 GNN은 소셜 네트워크, 분자 그래프, 지식 그래프, 도로 네트워크, 추천 그래프 등 임의의 관계 구조를 처리합니다. 이는 약물 발견, 사기 탐지, 추천 시스템 및 엔터티 간의 관계가 중요한 모든 영역에 필수적입니다.
---

## 그래프란 무엇입니까?
| 구성요소 | 설명 | 예 |
|------------|-------------|---------|
| **노드(정점)** | 엔터티 | 사람, 분자의 원자, 도시 |
| **엣지** | 두 노드 간의 관계 | 우정, 화학결합, 도로 |
| **가장자리 가중치** | 관계의 강도 또는 유형 | 거리, 유사성, 용량 |
| **노드 기능** | 각 노드의 속성 | 나이, 원자 번호, 인구 |
| **가장자리 기능** | 각 에지의 속성 | 관계 유형, 거리 |
| **인접 행렬** | 노드 i와 j가 연결된 경우 A[i][j] = 1인 행렬 A | 그래프 구조를 인코딩 |
### 그래프 유형
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **무방향** | 가장자리에는 방향이 없습니다 | 우정 네트워크 |
| **감독** | 모서리에는 방향이 있습니다(A→B ≠ B→A) | 트위터 팔로워 |
| **가중치** | 모서리에는 숫자 값이 있습니다 | 거리가 있는 도로 네트워크 |
| **이기종** | 다중 노드 및 에지 유형 | 학술 그래프(논문, 저자, 장소) |
| **동적** | 시간에 따른 그래프 구조 변화 | 시간이 지남에 따라 진화하는 소셜 네트워크 |
| **양자** | 두 가지 유형의 노드; 유형 사이에서만 가장자리 | 사용자 아이템 추천 그래프 |
---

## 왜 일반 신경망이 아닌가?
| 접근 | 실패하는 이유 |
|----------|-------------|
| **피드포워드 네트워크** | 고정 크기 입력이 필요합니다. 그래프의 크기와 구조는 다양합니다 |
| **CNN** | 그리드 구조를 가정합니다. 그래프에는 일반 격자가 없습니다 |
| **RNN/변압기** | 순차적 순서를 가정합니다. 그래프에는 자연스러운 순서가 없습니다 |
GNN은 그래프 구조에서 직접 작동하여 이웃 노드의 맥락에서 각 노드를 처리함으로써 이 문제를 해결합니다.
---

## 핵심 GNN 아키텍처
### 메시지 전달 프레임워크
대부분의 GNN은 동일한 패턴을 따릅니다. 각 노드는 이웃으로부터 정보를 수집하고 결합하며 자체 표현을 업데이트합니다.
| 단계 | 설명 |
|------|-------------|
| **1. 메시지** | 각 노드는 현재 기능을 기반으로 이웃에게 메시지를 보냅니다.
| **2. 집계** | 각 노드는 모든 이웃으로부터 메시지를 수집하고 결합합니다 |
| **3. 업데이트** | 각 노드는 집계된 메시지를 사용하여 자체 표현을 업데이트합니다 |
| **4. 반복** | K 레이어에 대해 이 작업을 수행 → 각 노드는 K 홉 거리에서 정보를 캡처합니다 |
### 주요 GNN 모델
| 모델 | 집계 방법 | 핵심혁신 |
|-------|------|---|
| **GCN**(그래프 컨벌루션 네트워크) | 이웃 특징의 평균 | 단순한; 효과적인; 스펙트럼 동기 부여 |
| **그래프세이지** | 샘플 및 집계 평균, LSTM 또는 풀링을 사용할 수 있습니다 | 유도성(보이지 않는 노드 처리) 확장 가능 |
| **GAT**(그래프 어텐션 네트워크) | 주의 가중 이웃 집계 | 어떤 이웃이 가장 중요한지 알아보기 |
| **GIN**(그래프 동형 네트워크) | 이웃 특징의 합 | 표현력이 극대화됩니다. WL 테스트로 구별할 수 있는 모든 그래프를 구별할 수 있습니다 |
| **MPNN**(메시지 전달 신경망) | 일반 메시지 전달 프레임워크 | 다양한 GNN 변형 통합 |
### GCN 작동 방식(단계별)
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

K 레이어 이후 각 노드의 표현은 그래프에서 K 홉의 정보를 인코딩합니다.

## 그래프 수준 작업
| 작업 | 설명 | 예 |
|------|-------------|---------|
| **노드 분류** | 각 노드의 레이블 예측 | 사용자를 봇 또는 인간으로 분류 |
| **링크 예측** | 에지가 존재하는지(또는 존재할지) 예측 | 누락된 관계를 예측합니다. 연결 추천 |
| **그래프 분류** | 전체 그래프에 대한 레이블 예측 | 분자를 독성 또는 무독성으로 분류 |
| **커뮤니티 감지** | 조밀하게 연결된 노드의 클러스터 찾기 | 사회 집단 식별 |
| **그래프 생성** | 원하는 속성으로 새 그래프 생성 | 새로운 분자 설계 |

## 애플리케이션
### 약물 발견 및 분자 특성 예측
| 작업 | GNN이 도움이 되는 방법 |
|------|--------------|
| **분자특성 예측** | 분자를 그래프로 표현합니다(원자=노드, 결합=가장자리). 독성, 용해도, 결합 친화도 예측 |
| **약물간 상호작용** | 약물과 표적을 그래프로 모델링합니다. 불리한 상호작용 예측 |
| **새로운 약물 디자인** | 원하는 특성을 지닌 새로운 분자 그래프 생성 |
### 추천 시스템
| 접근 | 설명 |
|----------|-------------|
| **사용자 항목 그래프** | 사용자와 항목은 노드입니다. 구매/조회수는 우위에 있습니다 |
| **그래프 기반 협업 필터링** | GNN은 그래프를 통해 선호도를 전파합니다 |
| **지식 그래프 권장사항** | 사용자 선호도와 아이템 지식(장르, 배우, 감독)을 결합 |
### 사기 탐지
| 신청 | 그래프 구조 |
|-------------|---|
| **금융사기** | 거래는 그래프를 형성합니다. 사기 패턴이 하위 그래프 구조로 나타남 |
| **보험사기** | 청구인, 제공자 및 정책이 그래프를 형성합니다. 사기꾼의 고리가 감지되었습니다 |
| **계정 탈취** | 로그인 패턴이 그래프를 형성합니다. 비정상적인 연결 신호 손상 |
### 지식 그래프
| 작업 | 설명 |
|------|-------------|
| **링크 예측** | 누락된 사실 예측(예: "파리는 ?의 수도입니다.") |
| **엔티티 해결** | 두 개의 언급이 동일한 항목을 참조하는지 확인 |
| **질문답변** | 그래프를 탐색하여 답변 찾기 |

## 고급 GNN 개념
### 과도하게 스무딩
| 문제 | 설명 | 솔루션 |
|---------|-------------|----------|
| **과도한 스무딩** | 많은 레이어 이후에는 모든 노드 표현이 유사해집니다. | 제한 깊이(2~4개 레이어); 잔여 연결을 사용하십시오. 점핑 지식 활용 |
### 오버 스쿼싱
| 문제 | 설명 | 솔루션 |
|---------|-------------|----------|
| **과도한 스쿼싱** | 멀리 있는 노드의 정보는 고정 크기 벡터로 압축됩니다. | 그래프 변환기를 사용하십시오. 계층적 풀링 |
### 그래프 변환기
| 모델 | 주요 기능 |
|-------|-------------|
| **그래프 변환기** | 모든 노드 쌍에 표준 Transformer attention 적용 |
| **GPS**(그래프 프롬프트 시스템) | 로컬 GNN 레이어를 글로벌 Transformer 레이어와 결합 |
| **그래퍼** | 그래프 구조를 기반으로 위치 인코딩 추가 |
### 이종 그래프 네트워크
| 모델 | 설명 |
|-------|-------------|
| **R-GCN** | 관계형 GCN; 다양한 모서리 유형에 대한 다양한 가중치 매트릭스 |
| **한** | 이종주의 네트워크; 다양한 노드 및 에지 유형에 대한 관심 |
| **HetGNN** | 이종 그래프 신경망; 여러 노드 유형을 처리 |

## 요약
그래프 신경망은 딥 러닝을 관계형 데이터(네트워크, 분자, 지식 그래프 및 엔터티가 연결된 모든 시스템)로 확장합니다. 이는 이웃 간에 메시지를 전달하여 작동하며 각 노드가 로컬 컨텍스트에서 학습할 수 있도록 합니다. GNN은 약물 발견, 추천 시스템, 사기 탐지 및 지식 그래프에서 가장 강력한 응용 프로그램을 찾았습니다. 이 분야는 그래프 변환기, 이기종 그래프, 대규모 실제 네트워크를 위한 확장 가능한 교육 방향으로 발전하고 있습니다. 데이터에 관계가 있는 경우 GNN을 고려해 볼 가치가 있습니다.
