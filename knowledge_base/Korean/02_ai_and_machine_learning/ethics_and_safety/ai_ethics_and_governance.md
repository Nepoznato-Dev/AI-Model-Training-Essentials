# AI 윤리와 거버넌스
AI 시스템은 중립적이지 않습니다. 여기에는 교육을 받은 데이터, 작성자의 가치, 이를 배포하는 조직의 인센티브가 반영됩니다. 윤리는 단순히 "우리가 이걸 만들 수 있을까?"를 묻는 것이 아닙니다. 하지만 "그럴까요?" 거버넌스는 AI가 책임감 있게 개발되고 사용되도록 보장하는 구조(법률, 표준, 감독 기관)를 만드는 것입니다. 이 파일은 AI의 주요 윤리적 측면과 이를 해결하기 위해 등장하는 거버넌스 프레임워크를 다루고 있습니다.
---

## AI의 핵심 윤리 원칙
대부분의 AI 윤리 프레임워크는 일련의 공유 원칙에 수렴됩니다.
| 원리 | 그것이 의미하는 것 | 도전 |
|------------|---------------|----------|
| **공정성** | AI는 보호 대상 그룹을 차별해서는 안 된다 | 공정성을 수학적으로 정의하는 것은 어렵습니다. 서로 다른 공정성 정의가 충돌할 수 있음 |
| **투명성** | 사용자는 AI와 상호작용하는 시기와 작동 방식을 알아야 합니다 | 완전한 투명성으로 게임이 가능해집니다. 독점 시스템은 공개를 거부합니다 |
| **책임** | AI가 해를 끼칠 때 누군가는 책임을 져야 한다 | 개발자, 배포자 및 사용자에게 책임 분산 |
| **개인정보보호** | AI는 개인 데이터와 자율성을 존중해야 합니다 | 훈련 데이터에는 개인 정보가 포함되는 경우가 많습니다. 개인 정보 보호와 유틸리티 충돌 |
| **안전** | AI는 신체적, 정신적 피해를 주어서는 안 된다 | 피해를 정의하는 것은 상황에 따라 다릅니다. 극단적인 경우는 예측할 수 없습니다 |
| **사람의 감독** | 인간은 의미 있는 통제력을 유지해야 합니다 | 자동화 편향은 인간이 AI를 따르는 것을 의미합니다. 감독이 고무적인 일이 됨 |

## AI 시스템의 편견
### 편견은 어디에서 오는가
| 소스 | 설명 | 예 |
|---------|-------------|---------|
| **훈련 데이터** | 데이터에 인코딩된 역사적 편견 | 채용 데이터는 과거 차별을 반영 → 모델은 차별 |
| **라벨 편향** | 인간 주석자는 편견을 부과합니다 | 주석 작성자에 의해 낮은 평가를 받은 "여성" 이름으로 이력서 |
| **선택 편향** | 데이터가 대상 인구를 나타내지 않습니다 | 주로 밝은 피부의 얼굴을 대상으로 훈련된 얼굴 인식 |
| **측정 편향** | 보호된 속성에 대한 프록시 기능 | 우편번호는 인종과 상관관계가 있습니다 |
| **알고리즘 편향** | 최적화는 작은 편향을 증폭시킵니다 | 학습 데이터의 작은 차이가 예측의 큰 차이가 됩니다 |
### 공정성 측정항목
| 미터법 | 정의 | 사용 시기 |
|---------|------------|-------------|
| **인구학적 동등성** | 긍정적인 비율은 그룹 전체에서 동일합니다 | 동등한 결과를 원할 때 |
| **균등 확률** | 참양성률과 위양성률은 그룹 전체에서 동일함 | 동일한 오류율을 원할 때 |
| **예측 패리티** | 정밀도는 그룹 전체에서 동일합니다 | 예측이 모든 그룹에 대해 동일한 의미를 갖기를 원하는 경우 |
| **개인의 공정성** | 유사한 개인은 유사하게 대우받습니다 | 일관성을 원할 때 |
**불가능 정리**: 일반적으로 여러 공정성 정의를 동시에 충족할 수 없습니다. 사용할 공정성 측정항목을 선택하는 것 자체가 가치 판단입니다.
### 편견 완화
| 무대 | 기술 |
|-------|------------|
| **전처리** | 훈련 데이터의 균형을 재조정합니다. 편향된 기능을 제거합니다. 합성 오버샘플링 |
| **처리 중** | 손실 함수에 공정성 제약 조건을 추가합니다. 적대적 편향성 제거 |
| **후처리** | 그룹당 임계값을 조정합니다. 예측 보정 |
| **평가** | 정기적인 공정성 감사 세분화된 성능 지표 |

## 설명 가능성
### 설명 가능성이 중요한 이유
| 이유 | 설명 |
|---------|-------------|
| **신뢰** | 사용자는 결정이 내려진 이유를 이해해야 합니다 |
| **디버깅** | 개발자는 모델 오류를 찾아 수정해야 합니다 |
| **규제** | GDPR의 "설명할 권리"; EU AI법 요구사항 |
| **공정성** | 모델 동작을 이해하지 않으면 편향을 감지할 수 없습니다 |
| **책임** | 조직은 자동화된 의사결정을 정당화해야 합니다 |
### 설명 방법
| 방법 | 유형 | 작동 원리 | 제한사항 |
|---------|------|---------------|------------|
| **SHAP** | 기능 중요성 | 게임 이론을 사용하여 각 기능의 기여도 추정 | 계산 비용이 많이 듭니다. 근사치 |
| **라임** | 지역 대리인 | 예측을 중심으로 간단한 모델에 적합 | 불안정한; 실제 모델 논리를 반영하지 않습니다 |
| **주의 시각화** | 내부 메커니즘 | 모델이 어떤 입력에 참여하는지 표시 | 주의 ≠ 중요성; 오해의 소지가 있을 수 있습니다 |
| **반사실** | 가정 분석 | "이 기능이 다르다면 예측이 바뀔까요?" | 현실적인 반사실적에 의존함 |
| **기능 기여** | 중요도 점수 | 돌출 맵, 통합 그라디언트 | *이유*를 설명하지 않습니다. 그냥 *어디* |

## 환경에 미치는 영향
AI 모델을 훈련하고 실행하는 것은 에너지를 소비하고 탄소 배출을 발생시킵니다.
| 활동 | 예상 배출량 | 비교 |
|------------|------|------------|
| **GPT-4 교육** | 예상 CO2 50톤 이상 | 여러 자동차의 연간 배출량에 해당 |
| **대형 Transformer 교육** | 280~620톤 CO₂ | 자동차 수명의 5배 배출 |
| **일일 추론(100만 사용자)** | 전진; 모델 크기 및 하드웨어에 따라 다름 | 시간이 지남에 따라 훈련 배출량을 초과할 수 있음 |
| **7B 모델 미세 조정** | 1~5톤 CO₂ | 중요하지만 사전 훈련보다 훨씬 적음 |
### 완화
| 전략 | 영향 |
|----------|---------|
| **효율적인 하드웨어** | 새로운 GPU는 계산당 에너지 효율성이 더 높습니다 |
| **모델 최적화** | 더 작고 양자화된 모델은 더 적은 에너지를 사용합니다 |
| **그린에너지** | 재생 가능 에너지를 갖춘 전력 데이터 센터 |
| **효율적인 아키텍처** | 전문가의 혼합; 희소 모델; 증류 |
| **탄소 인식 스케줄링** | 그리드가 가장 깨끗할 때 훈련 실행 |

## 실천윤리 프레임워크
### AI 개발자를 위한
| 질문 | 중요한 이유 |
|------------|---------------|
| **이 시스템으로 인해 누가 피해를 입을 수 있습니까?** | 영향을 받는 이해관계자 식별 |
| **모델이 잘못되면 어떻게 되나요?** | 오류 비용 평가 |
| **모델의 결정을 설명할 수 있습니까?** | 설명 가능성 요구 사항 결정 |
| **훈련 데이터가 대표적인가요?** | 선택 및 측정 편향 확인 |
| **실패 모드는 무엇입니까?** | 극단적인 경우와 오용을 예측 |
| **시스템은 어떻게 모니터링됩니까?** | 지속적인 감독 계획 |
### AI를 배포하는 조직의 경우
| 연습 | 설명 |
|----------|-------------|
| **AI 거버넌스 위원회** | AI 배포를 검토하는 다기능 팀 |
| **영향 평가** | 배포 전 잠재적 피해 평가 |
| **인적 감독 프로세스** | AI 오류 발생 시 에스컬레이션 경로 지우기 |
| **정기감사** | 편향, 드리프트 및 의도하지 않은 결과 확인 |
| **사용자 피드백 채널** | 영향을 받은 사람들이 문제를 보고하도록 허용 |
| **문서** | 모델 결정 및 근거 기록 유지 |

## 요약
AI 윤리와 거버넌스는 엔지니어링 요구사항입니다. 편견, 불투명성, 환경 비용 및 개인정보 침해는 윤리적 문제일 뿐만 아니라; 그것은 실제로 해를 끼치는 결함입니다. EU AI법이 글로벌 표준을 설정하면서 거버넌스 환경이 빠르게 발전하고 있습니다. 규제만으로는 충분하지 않습니다. 공정성, 설명 가능성, 책임은 모든 AI 개발자의 일상 업무에 통합되어야 합니다. 핵심 질문은 신뢰할 만한 시스템을 구축하는 방법입니다.
