# 생성 AI 심층 분석
제너레이티브 AI는 기존 데이터를 단순히 분류하거나 예측하는 것이 아니라 이미지, 텍스트, 오디오, 비디오, 코드 등 새로운 콘텐츠를 생성하는 모델을 말합니다. 대규모 언어 모델이 가장 많은 관심을 받는 반면 생성 AI 환경은 훨씬 더 광범위합니다. 이 파일은 확산 모델부터 변형 자동 인코더, 흐름 모델까지 현대 생성 시스템의 아키텍처, 기술 및 장단점을 다룹니다.
---

## 모델을 "생성적"으로 만드는 것은 무엇입니까?
| 유형 | 그것이 하는 일 | 예 |
|------|-------------|---------|
| **차별적** | 클래스 간의 경계 알아보기 | "이 이미지는 고양이인가요, 개인가요?" |
| **생성** | 데이터 자체의 분포 알아보기 | "고양이의 새로운 이미지 생성" |
생성 모델은 데이터를 분류하는 방법뿐만 아니라 *데이터가 생성되는 방법*을 포착합니다. 이로 인해 근본적으로 더 강력해지고 훈련하기가 더 어려워집니다.
---

## 주요 생성 아키텍처
### 변형 자동 인코더(VAE)
VAE는 데이터의 압축되고 구조화된 표현(잠재 공간)을 학습한 다음 해당 공간에서 샘플링하여 새로운 샘플을 생성합니다.
| 구성요소 | 역할 |
|------------|------|
| **인코더** | 입력 데이터를 잠재 공간의 분포(평균 및 분산)에 매핑 |
| **잠재 공간** | 유사한 데이터 포인트가 서로 가까이 있는 연속적인 저차원 공간 |
| **디코더** | 잠재 공간의 포인트를 데이터 공간으로 다시 매핑 |
| **KL 발산** | 잠재 분포를 표준 정규에 가깝게 유지하는 정규화 용어 |
**생성 작동 방식**: 잠재 공간에서 무작위 벡터를 샘플링하고 → 디코더를 통해 전달하고 → 새 데이터 포인트를 얻습니다.
| 힘 | 약점 |
|------------|----------|
| 부드럽고 연속적인 잠재 공간 | 출력이 흐릿해지는 경향이 있음 |
| 원칙에 입각한 수학적 프레임워크 | 아키텍처의 용량에 따라 제한됨 |
| 예제 사이를 보간할 수 있습니다 | 확산 또는 GAN 출력보다 덜 선명함 |
VAE는 종종 다른 모델의 구성 요소로 사용됩니다(예: Stable Diffusion은 VAE를 파이프라인의 일부로 사용합니다).
### 생성적 적대 신경망(GAN)
GAN은 두 개의 네트워크, 즉 가짜 데이터를 생성하는 **생성기**와 진짜와 가짜를 구별하려고 하는 **판별기**를 서로 대결시킵니다.
| 구성요소 | 목표 |
|------------|------|
| **발전기** | 판별자를 속이는 데이터 생성 |
| **판별자** | 실제 데이터와 생성된 데이터를 올바르게 분류 |
그들은 동시에 훈련하며, 서로가 발전하도록 격려합니다. 이론적으로 생성기는 결국 실제 데이터와 구별할 수 없는 데이터를 생성합니다.
| GAN 변종 | 핵심혁신 |
|---------------|---------------|
| **DCGAN** | 컨벌루션 아키텍처; 안정적인 훈련 |
| **StyleGAN / StyleGAN2 / StyleGAN3** | 스타일 기반 생성; 사실적인 얼굴; 제어 가능한 속성 |
| **CycleGAN** | 짝이 없는 이미지-이미지 변환(말 → 얼룩말) |
| **Pix2Pix** | 쌍을 이루는 이미지 대 이미지 번역(스케치 → 사진) |
| **프로GAN** | 고해상도 이미지를 위한 점진적 성장 |
| **빅GAN** | 대규모 클래스 조건부 생성 |
**GAN이 감소한 이유**: 훈련은 불안정하기로 악명이 높습니다(모드 붕괴, 기울기 소멸). 이제 확산 모델은 대부분의 이미지 생성 작업에 대해 더 나은 품질을 제공합니다. GAN은 여전히 ​​실시간 애플리케이션(추론 속도가 빠름) 및 초해상도와 같은 특정 작업에 사용됩니다.
### 확산 모델
확산 모델은 이미지 및 비디오 생성을 위한 최신 기술입니다. 그들은 순수한 무작위 잡음이 될 때까지 데이터에 점차적으로 잡음을 추가한 다음 프로세스를 역전시키는 방법을 학습하는 방식으로 작업합니다.
| 단계 | 무슨 일이 일어나는지 |
|-------|-------------|
| **전진 프로세스(교육)** | 데이터가 파괴될 때까지 수백/수천 단계에 걸쳐 천천히 가우스 노이즈를 추가하세요 |
| **역과정(생성)** | 순수한 노이즈부터 시작하여 깨끗한 이미지가 나올 때까지 단계별로 노이즈 제거 방법 배우기 |
| 모델 | 개발자 | 주목할만한 기능 |
|-------|------------|----|
| **DDPM**(노이즈 제거 확산 확률 모델) | 호 외, 2020 | 확산 모델이 고품질 이미지를 생성할 수 있음을 보여줌 |
| **안정적인 확산** | 안정성 AI | 잠재 확산(압축된 공간에서 실행) 오픈 소스 |
| **DALL-E 3** | 오픈AI | 텍스트 이해를 위해 ChatGPT와 통합 |
| **중간 여행** | 중간 여정 | 예술적 품질; 비공개 소스 |
| **이미지n** | 구글 딥마인드 | 충실도 높은 텍스트-이미지 |
| **소라** | 오픈AI | 확산 변압기를 통한 비디오 생성 |
| **플럭스** | 블랙 포레스트 연구소 | Stable Diffusion의 개방형 후속 제품 |
### 확산 모델이 승리한 이유
| 장점 | 설명 |
|------------|-------------|
| **훈련 안정성** | GAN보다 훨씬 안정적입니다. 적대적 훈련 없음 |
| **출력 품질** | 최첨단 화질과 다양성 |
| **제어성** | 텍스트(CLIP을 통해), 인페인팅 마스크 또는 기타 조건으로 안내 가능 |
| **다양성** | GAN보다 모드 붕괴가 적습니다. 다양한 출력을 생성 |
| 단점 | 설명 |
|-------------|-------------|
| **느린 추론** | 많은 노이즈 제거 단계 필요(일반적으로 20~50) |
| **컴퓨팅 집약적** | 각 단계는 대규모 모델을 통한 전체 전진 과정입니다 |
### 잠재확산
픽셀 공간에서 확산을 실행하는 데 비용이 많이 듭니다. **잠재 확산**(Stable Diffusion에서 사용)은 대신 ​​압축된 잠재 공간에서 확산 프로세스를 실행합니다.
| 단계 | 무슨 일이 일어나는지 |
|------|-------------|
| 1. 압축 | 사전 훈련된 VAE는 이미지를 더 작은 잠재 표현으로 인코딩합니다 |
| 2. 확산 | 확산 모델은 잠재 공간에 노이즈를 추가/제거합니다 |
| 3. 디코딩 | VAE 디코더는 잠재 이미지를 다시 전체 이미지로 변환합니다.
이를 통해 품질을 유지하면서 훨씬 더 빠르고 저렴하게 생산할 수 있습니다.

## 텍스트 조건 생성
대부분의 최신 생성 시스템은 텍스트 프롬프트에 맞춰져 있습니다. 즉, 원하는 것을 설명하면 모델이 이를 생성합니다.
### CLIP(대조적 언어-이미지 사전 훈련)
CLIP은 텍스트와 이미지의 공유 임베딩 공간을 학습합니다. 인터넷에서 수십억 개의 이미지-텍스트 쌍을 학습했습니다.
| 능력 | 설명 |
|------------|-------------|
| **제로샷 분류** | 학습 없이 텍스트 설명을 사용하여 이미지 분류 |
| **이미지-텍스트 검색** | 텍스트 쿼리와 가장 관련성이 높은 이미지 찾기 |
| **유도 확산** | 이미지 생성을 텍스트 프롬프트 쪽으로 조정 |
### 분류자 없는 지침(CFG)
CFG는 생성된 이미지가 텍스트 프롬프트를 얼마나 가깝게 따르는지 제어합니다.
| CFG 규모 | 효과 |
|------------|---------|
| **1.0** | 안내가 없습니다. 다양하지만 프롬프트와 일치하지 않을 수 있음 |
| **5.0–7.5** | 균형 잡힌; 좋은 품질과 신속한 준수 |
| **10.0+** | 강한 접착력; 과포화되거나 인공물이 많은 이미지를 생성할 수 있음 |

## 기타 생성적 접근 방식
### 흐름 정규화
| 기능 | 설명 |
|---------|-------------|
| **작동 방식** | 데이터와 단순 분포 간의 가역적 매핑 알아보기 |
| **강도** | 정확한 가능성 계산 빠른 샘플링 |
| **약점** | 신중하게 설계된 아키텍처가 필요합니다. 유연성이 떨어짐 |
| **사용 사례** | 이상 징후 탐지, 밀도 추정 |
### 자기회귀 모델
| 기능 | 설명 |
|---------|-------------|
| **작동 방식** | 이전의 모든 요소를 ​​조건으로 한 번에 한 요소씩 데이터를 생성 |
| **강도** | 순차 데이터(텍스트, 코드, 음악)에 적합 |
| **약점** | 느린 생성(순차적이어야 함) 훈련 데이터 분포에 따라 제한됨 |
| **예** | GPT(텍스트), WaveNet(오디오), ImageGPT(이미지) |
### 에너지 기반 모델
| 기능 | 설명 |
|---------|-------------|
| **작동 방식** | 에너지 함수를 배우세요. 낮은 에너지 = 현실적인 데이터 |
| **강도** | 유연한; 정규화가 필요하지 않습니다 |
| **약점** | 훈련은 어렵다. 샘플링에는 MCMC가 필요합니다 |
| **사용 사례** | 이론 연구; 일부 로봇공학 응용 |

## 평가 지표
생성된 데이터의 품질을 어떻게 측정합니까? 생각보다 어렵습니다.
| 미터법 | | 측정 대상 | 제한사항 |
|---------|------|----|------------|
| **FID**(프레셰 시작 거리) | 이미지 | 실제 이미지 분포와 생성된 이미지 분포 사이의 거리 | 낮을수록 좋습니다. 다양성을 잘 포착하지 못함 |
| **IS**(개시 점수) | 이미지 | 생성된 이미지의 품질과 다양성 | 논란이 많은; 게임을 할 수 있습니다 |
| **클립 점수** | 텍스트를 이미지로 | 이미지가 텍스트 프롬프트와 얼마나 잘 일치합니까 | CLIP의 편견에 따라 다름 |
| **당황** | 텍스트 | 모델이 다음 토큰을 얼마나 잘 예측하는지 | 낮을수록 좋습니다. 일관성을 측정하지 않습니다 |
| **블루/루즈** | 텍스트 생성 | 참조 텍스트와 겹침 | 인간의 판단을 제대로 대변하지 못함 |
| **FAD**(프레셰 오디오 거리) | 오디오 | 실제 오디오 배포와 생성된 오디오 배포 사이의 거리 | 오디오용 FID와 유사 |

## 제어 가능한 생성
최신 시스템을 사용하면 단순한 텍스트 프롬프트 이상으로 생성되는 내용을 제어할 수 있습니다.
| 방법 | 제어 유형 | 예 |
|---------|-------------|---------|
| **인페인팅** | 마스크된 영역 채우기 | 사진에서 개체 제거 |
| **아웃페인팅** | 이미지 경계를 넘어 확장 | 풍경을 더 넓게 만드세요 |
| **컨트롤넷** | 구조적 안내(가장자리, 깊이, 포즈) | 특정 포즈에 맞는 이미지 생성 |
| **IP 어댑터** | 참조 이미지의 스타일 또는 콘텐츠 | "이 그림처럼 보이게 만드세요" |
| **로라** | 세밀하게 조정된 스타일이나 컨셉 | 특정 캐릭터 또는 아트 스타일 추가 |
| **이미지2이미지** | 기존 이미지 변환 | 스케치를 사실적인 이미지로 변환 |

## 비디오 생성
비디오 세대는 이미지 다음으로 발전하는 분야입니다. 그것은 시간과 움직임의 차원을 추가합니다.
| 모델 | 접근 | 주목할만한 기능 |
|-------|----------|----|
| **소라**(OpenAI) | 확산 변압기 | 최대 1080p; 물리학을 합리적으로 잘 이해하고 있습니다 |
| **활주로 Gen-3** | 확산 기반 | 상업용 비디오 생성 도구 |
| **피카** | 확산 기반 | 텍스트의 짧은 비디오 클립 |
| **클링** | 자기회귀 + 확산 | 긴 형식의 비디오 생성 |
| **Veo 2**(구글) | 확산 변압기 | 고품질의 물리적으로 일관된 비디오 |
### 비디오 생성의 과제
| 도전 | 왜 어려운가 |
|------------|---------------|
| **시간적 일관성** | 개체는 프레임 전체에서 동일하게 표시되어야 합니다. |
| **물리학** | 중력, 충돌, 유체 역학은 대략적으로 정확해야 합니다 |
| **길이** | 몇 분 분량의 일관된 비디오를 생성하는 것은 단일 이미지보다 훨씬 어렵습니다 |
| **컴퓨팅** | 비디오는 본질적으로 많은 이미지입니다. 프레임 수에 따른 비용 규모 |
| **평가** | 어떤 표준 지표도 비디오 품질을 잘 포착하지 못합니다 |

## 요약
Generative AI는 GAN에서 VAE를 거쳐 확산 모델 이상으로 발전했습니다. 이러한 모든 아키텍처의 핵심 통찰력은 동일합니다. 즉, 데이터 분포를 학습한 다음 이를 샘플링하여 새로운 콘텐츠를 만드는 것입니다. 확산 모델은 훈련 안정성과 출력 품질로 인해 현재 이미지와 비디오 생성을 지배하고 있습니다. VAE는 중요한 빌딩 블록 역할을 합니다. 자기회귀 모델은 텍스트와 코드를 지배합니다. 이 분야는 입력의 모든 조합에서 텍스트, 이미지, 오디오 및 비디오를 생성할 수 있는 시스템인 다중 모드 생성을 향해 나아가고 있으며 생성을 더 빠르고 저렴하며 제어하기 쉽게 만드는 방향으로 나아가고 있습니다.
