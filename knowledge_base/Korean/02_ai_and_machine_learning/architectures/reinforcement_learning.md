# 강화학습
강화 학습(RL)은 기계가 시행착오를 통해 일련의 결정을 내리는 방법을 학습하는 방법입니다. 모든 예시에 정답이 제공되는 지도 학습과 달리 RL은 에이전트에게 보상 신호만 제공하며 에이전트는 시간이 지남에 따라 어떤 작업이 최상의 결과로 이어지는지 파악해야 합니다. 이는 AlphaGo, 로봇 제어, 게임 플레이 AI 및 현대의 대규모 언어 모델을 인간 선호도에 맞추는 데 사용되는 기술인 RLHF의 이면에 있는 접근 방식입니다.
---

## 핵심 개념
RL은 의사결정을 **에이전트**와 **환경** 사이의 루프로 구성합니다.
| 구성요소 | 역할 | 예 |
|------------|------|---------|
| **에이전트** | 의사결정자 | 체스 프로그램, 로봇, 언어 모델 |
| **환경** | 에이전트가 상호작용하는 세계 | 체스판, 창고, 대화 |
| **상태** | 현황 | 보드 위치, 로봇 센서 판독값, 채팅 기록 |
| **액션** | 상담원이 할 수 있는 일 | 조각을 이동하고, 좌회전하고, 토큰을 생성하세요 |
| **보상** | 피드백 신호(스칼라 수) | 승리 시 +1, 충돌 시 -1, 인간 선호도 점수 |
| **정책** | 상태를 행동으로 매핑하는 전략 | "왕이 위협을 받으면 움직여라" |
| **가치 함수** | 상태로부터 기대되는 누적 보상 | "이 보드 위치는 약 +3점의 가치가 있습니다." |
### RL 루프
```
Agent observes State → chooses Action → Environment returns new State + Reward
        ↑                                                                         |
        └─────────────────────────────────────────────────────────────────────────┘
```

에이전트의 목표는 즉각적인 보상뿐만 아니라 시간이 지남에 따라 **누적 보상**을 최대화하는 것입니다. 이것이 RL이 지도 학습과 근본적으로 다른 점입니다.

## 다른 학습 패러다임과의 주요 차이점
| 측면 | 지도 학습 | 비지도 학습 | 강화 학습 |
|---------|------|---------|---------|
| **신호** | 모든 예시에 대한 올바른 라벨 | 라벨이 없습니다. 구조 찾기 | 스칼라 보상, 종종 지연됨 |
| **피드백** | 즉시 | 없음 | 지연되고 희박함 |
| **순서** | 각 예는 독립적입니다 | 각 예는 독립적입니다 | 행동은 미래 상태에 영향을 미칩니다 |
| **목표** | 예측 오류 최소화 | 패턴 발견 | 누적 보상 극대화 |

## 마르코프 결정 프로세스(MDP)
MDP는 RL의 수학적 프레임워크입니다. 그들은 미래가 어떻게 그곳에 도달했는지에 대한 기록(**마르코프 속성**)이 아니라 현재 상태에만 달려 있다고 가정합니다.
| 구성요소 | 표기법 | 의미 |
|------------|----------|---------|
| **주** | S | 에이전트가 처할 수 있는 모든 가능한 상황 |
| **작업** | A | 상담원이 할 수 있는 모든 일 |
| **전환 기능** | P(s' \|s, a) | 상태 s에서 조치 a를 수행한 후 상태 s'에 도달할 확률 |
| **보상 기능** | R(s, a, s') | 전환에 대해 받은 보상 |
| **할인 요소** | γ(감마) | 미래 보상과 즉각적인 보상의 가치를 얼마나 평가할 것인가(0 대 1) |
**반품**(총 할인된 보상)은 다음과 같습니다.
```
G = R₁ + γR₂ + γ²R₃ + ...
```

높은 할인 인자(γ가 1에 가까움)는 에이전트가 원시적이라는 것을 의미합니다. 낮다는 것은 근시안적이라는 뜻이다.

## 고전적인 RL 알고리즘
### 가치 기반 방법
이는 각 상태(또는 상태-작업 쌍)가 얼마나 좋은지 학습합니다.
| 알고리즘 | 핵심 아이디어 | 제한사항 |
|------------|----------|------------|
| **Q-러닝** | Q-값 테이블 알아보기: Q(상태, 행동) = 예상 보상 | 대규모 상태 공간으로 확장되지 않음 |
| **심층 Q-네트워크(DQN)** | 신경망을 사용하여 Q-값 근사화 | 개별 작업만 처리합니다. 불안정할 수 있습니다 |
| **이중 DQN** | Q-learning의 과대평가 편향 수정 | 여전히 개별 작업으로 제한됨 |
Q-러닝 업데이트 규칙:
```
Q(s, a) ← Q(s, a) + α [r + γ max Q(s', a') - Q(s, a)]
```

### 정책 기반 방법
이는 가치를 추정하지 않고 정책(전략)을 직접 학습합니다.
| 알고리즘 | 핵심 아이디어 | 장점 |
|------------|----------|-----------|
| **강화** | 몬테카를로 정책 구배; 좋은 결과를 향한 정책 업데이트 | 단순한; 지속적인 작업으로 작동 |
| **PPO**(근위 정책 최적화) | 크고 불안정한 변경을 방지하기 위해 정책 업데이트 클립 | 안정적인; 널리 사용됨; 좋은 기본값 |
| **TRPO** | 정책 업데이트를 위한 신뢰 지역 방법 | PPO보다 더 원칙적입니다. 구현하기가 더 어렵다 |
### 배우 평론가 방법
**행위자**(정책)와 **비평가**(가치 함수)의 장점을 결합합니다.
| 알고리즘 | 핵심 아이디어 |
|------------|----------|
| **A2C / A3C** | 장점 배우 평론가; 분산을 줄이기 위해 이점 추정을 사용합니다 |
| **SAC** (소프트 배우 평론가) | 탐색을 유지하면서 보상 극대화(엔트로피 정규화) |
| **TD3**(트윈 지연 DDPG) | 연속 행동 공간의 과대평가 해결 |

## RLHF: 인간 피드백을 통한 강화 학습
RLHF는 ChatGPT를 가능하게 한 기술입니다. 이는 텍스트를 예측할 수 있는 모델과 인간이 실제로 유용하다고 생각하는 출력을 생성하는 모델 사이의 격차를 해소합니다.
### 세 단계
| 단계 | 무슨 일이 일어나는지 | 출력 |
|------|-------------|-------|
| **1. 감독형 미세 조정(SFT)** | 사람이 작성한 고품질 예제에 대해 사전 훈련된 모델 미세 조정 | 지시사항을 합리적으로 잘 따르는 모델 |
| **2. 보상 모델 교육** | 인간은 모델 출력 쌍을 비교합니다. 인간의 선호도를 예측하는 모델 훈련 | 출력 품질을 평가하는 보상 모델 |
| **3. RL 최적화** | 보상 모델 점수를 최대화하기 위해 PPO를 사용하여 SFT 모델을 미세 조정 | 인간의 선호도에 맞춰 조정된 모델 |
### RLHF가 중요한 이유
RLHF가 없으면 언어 모델은 모든 책을 읽었지만 대화에서 어떻게 행동해야 할지 모르는 학생과 같습니다. 텍스트를 생성할 수 있지만 텍스트가 도움이 되지 않거나 독성이 있거나 요점을 완전히 놓칠 수 있습니다. RLHF는 텍스트가 어떻게 보이는지뿐만 아니라 *인간이 원하는 것*을 모델에 가르칩니다.
### 변형 및 대안
| 방법 | 설명 | 장점 |
|---------|-------------|------------|
| **DPO**(직접 선호도 최적화) | 보상 모델을 건너뛰세요. 인간의 선호도에 따라 정책을 직접 최적화 | 더 간단합니다. 훈련할 별도의 보상 모델이 없습니다 |
| **RLAIF** | 인간이 아닌 AI를 사용하여 선호도 라벨 생성 | 사람이 라벨링하는 것보다 저렴함 |
| **헌법 AI** | 인간의 라벨 없이 모델 동작을 안내하기 위해 일련의 원칙을 사용 | 더 확장 가능합니다. Anthropic의 접근 방식 |
| **GRPO**(그룹 상대 정책 최적화) | 별도의 모델이 아닌 그룹 내에서 출력 비교 | DeepSeek-R1에 사용됩니다. 가치 네트워크의 필요성 감소 |
---

## 탐색과 활용
이것이 RL의 중심 긴장입니다. **악용**은 효과가 있다고 알고 있는 작업을 선택하는 것을 의미합니다. **탐색**은 잠재적으로 더 나은 전략을 발견하기 위해 새로운 것을 시도하는 것을 의미합니다.
| 전략 | 작동 원리 | 트레이드오프 |
|----------|-------------|----------|
| **ε-탐욕** | 대부분의 경우 최선의 조치를 선택하십시오. 확률이 ε인 무작위 행동 | 단순하지만 비효율적 |
| **볼츠만 탐사** | 예상 값을 기반으로 확률적으로 작업 선택 | ε-탐욕보다 더 매끄러움 |
| **UCB**(신뢰 상한) | 불확실성이 높은 행동을 선호함(불확실성에 직면한 낙관주의) | 좋은 이론적 보장 |
| **엔트로피 정규화** | 다양한 주 방문에 대한 보너스 추가(SAC, PPO에서 사용) | 자연 탐사 장려 |

## 다중 에이전트 강화 학습
여러 에이전트가 동시에 학습하면 역학이 훨씬 더 복잡해집니다.
| 시나리오 | 도전 | 예 |
|----------|------------|---------|
| **협동조합** | 상담원은 조정해야 합니다. 학점 할당이 어렵다 | 로봇 축구팀; 분산형 센서 네트워크 |
| **경쟁력** | 반대자들은 적응합니다. 환경이 고정되어 있지 않습니다 | 게임 AI(포커, 스타크래프트); 사이버보안 |
| **혼합** | 일부 에이전트는 협력하고 다른 에이전트는 경쟁 | 경매 시장 교통 시스템 |
| 알고리즘 | 설명 |
|------------|-------------|
| **MADDPG** | DDPG의 다중 에이전트 버전; 중앙집중형 평론가, 분산형 행위자 |
| **마포** | 다중 에이전트 PPO; 실제로 널리 사용됨 |
| **셀프 플레이** | 에이전트는 자신의 사본에 대해 훈련합니다(AlphaGo, AlphaStar) |

## Sim-to-Real 전송
현실 세계에서 로봇을 훈련시키는 것은 느리고 위험합니다. 대신 에이전트는 시뮬레이션 교육을 받고 현실로 전환합니다.
| 도전 | 솔루션 |
|------------|----------|
| **현실 격차**(시뮬레이션 ≠ 실제 세계) | 도메인 무작위화: 훈련 중 물리 매개변수 변경 |
| **샘플 비효율성** | 모델 기반 RL을 사용하거나 대규모 병렬 시뮬레이션에서 학습 |
| **안전** | 제한된 RL: 훈련 중 안전하지 않은 행동에 페널티 부여 |
| **부분적인 관찰 가능성** | 시끄러운 센서와 지연된 관찰로 훈련 |
Boston Dynamics 및 Tesla와 같은 회사는 시뮬레이션을 광범위하게 사용하지만 시뮬레이션 성능과 실제 성능 간의 격차는 여전히 이 분야의 가장 큰 과제 중 하나입니다.

## 실용적인 팁
- **PPO로 시작하세요.** 가장 신뢰할 수 있는 범용 알고리즘입니다. 무엇을 사용해야 할지 잘 모르겠으면 PPO가 기본값입니다.
- **보상을 정규화하세요.** 보상 스케일링은 훈련 안정성에 큰 영향을 미칩니다.
- **벡터화된 환경을 사용합니다.** 많은 환경을 병렬로 실행하면(예: 8-64) 기울기 추정이 안정화되고 훈련 속도가 엄청나게 빨라집니다.
- **보상과 엔트로피를 모두 모니터링합니다.** 엔트로피가 0으로 떨어지면 에이전트가 탐색을 중단하고 로컬 최적 상태에 갇힐 수 있습니다.
- **보상 형성은 예술입니다.** 올바른 보상 기능을 설계하는 것은 종종 가장 어려운 부분입니다. 희박한 보상(마지막에만)은 학습 속도를 극도로 느리게 만듭니다. 조밀하고 잘 구성된 보상은 에이전트를 안내하지만 의도하지 않은 행동을 유발할 수 있습니다.
- **RLHF는 취약합니다.** 보상 모델이나 PPO 하이퍼 매개변수를 조금만 변경하면 품질이 크게 저하될 수 있습니다. 전체 RLHF 파이프라인이 필요하지 않은 경우 DPO는 보다 안정적인 대안입니다.

## 요약
강화 학습은 에이전트가 상호 작용을 통해 결정을 내리는 방법을 학습하는 방법에 대한 연구입니다. 이는 Q-학습과 같은 고전적인 알고리즘부터 PPO 및 SAC와 같은 최신 심층 RL 방법에 이르기까지 다양하며 게임 플레이에서 언어 모델 정렬에 이르기까지 AI의 가장 중요한 최근 발전을 뒷받침합니다. 핵심 과제는 동일하게 유지됩니다. 피드백이 지연되고 희소하며 시끄러울 때 최적의 동작을 어떻게 학습합니까? 영리한 수학을 바탕으로 한 시행착오라는 대답은 인공 지능 전체에서 가장 강력한 아이디어 중 하나로 밝혀졌습니다.
