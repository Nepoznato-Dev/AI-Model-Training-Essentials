# 연합 학습 및 개인 정보 보호
연합 학습은 원시 데이터를 공유하지 않고 여러 장치 또는 조직에서 기계 학습 모델을 교육하는 기술입니다. 데이터를 중앙 서버로 보내는 대신 각 장치는 로컬 모델을 훈련하고 모델 업데이트(기울기 또는 가중치)만 공유합니다. 중앙 서버는 이러한 업데이트를 집계하여 글로벌 모델을 생성합니다. 이는 Android 휴대폰에서 키보드 언어 모델을 훈련하기 위해 Google에서 설계했으며 이후 개인 정보 보호 AI의 핵심 기술이 되었습니다.
---

## 왜 연합학습인가?
| 동기부여 | 설명 | 예 |
|------------|-------------|---------|
| **데이터 개인정보 보호** | 원시 데이터는 장치를 떠나지 않습니다 | 의료 기록은 병원에 보관됩니다. 사진은 전화 속에 남아 |
| **규정 준수** | GDPR, HIPAA 및 기타 규정으로 인해 데이터 공유가 제한됩니다 | 은행은 고객 데이터를 공유하지 않고도 협업할 수 있습니다 |
| **데이터 볼륨** | 데이터 이동은 비용이 많이 들고 느림 | 데이터를 업로드해야 하는 경우 수십억 대의 전화기에 대한 교육은 비현실적입니다 |
| **데이터 민감도** | 일부 데이터는 동의가 있어도 공유하기에는 너무 민감합니다 | 정부 정보; 개인 건강 데이터 |
---

## 연합 학습의 작동 방식
### 기본 프로토콜(FedAvg)
| 단계 | 무슨 일이 일어나는지 |
|------|-------------|
| **1. 초기화** | 중앙 서버는 임의의 가중치를 사용하여 전역 모델을 생성합니다 |
| **2. 배포** | 서버는 현재 글로벌 모델을 선택된 장치로 보냅니다 |
| **3. 현지 교육** | 각 장치는 여러 시대에 걸쳐 로컬 데이터를 기반으로 모델을 훈련합니다 |
| **4. 업로드** | 장치는 업데이트된 모델 가중치(데이터 아님)를 다시 서버로 보냅니다. |
| **5. 집계** | 서버는 가중치를 평균화(Federated Averaging)하여 새로운 글로벌 모델을 생성합니다 |
| **6. 반복** | 모델이 수렴될 때까지 2단계로 돌아가기 |
```
Server: global_model = average(local_model_1, local_model_2, ..., local_model_n)
```

### 주요 속성
| 부동산 | 설명 |
|----------|-------------|
| **비IID 데이터** | 각 장치에는 서로 다른 데이터 분포가 있습니다(독립적이지 않고 동일하게 분포됨) |
| **불균형 데이터** | 일부 장치에는 많은 데이터가 있고 다른 장치에는 데이터가 거의 없습니다 |
| **일부 참여** | 모든 라운드에서 모든 장치를 사용할 수 있는 것은 아닙니다 |
| **커뮤니케이션 효율성** | 병목 현상은 계산이 아니라 의사소통이다 |

## 연합 학습 변형
| 변형 | 설명 | 장점 |
|---------|-------------|------------|
| **FedAvg** | 장치 전체의 평균 모델 가중치 | 단순한; IID 데이터에 잘 작동 |
| **페드프록스** | 로컬 트레이닝에 근접 용어를 추가합니다 | IID가 아닌 데이터에 더 적합 |
| **비계** | 제어 변량을 사용하여 데이터 이질성 수정 | 비IID 데이터에 대한 더 빠른 수렴 |
| **FedSGD** | FedAvg와 비슷하지만 라운드당 하나의 그라데이션 단계가 있습니다 | 라운드당 통신 비용 절감 |
| **맞춤형 FL** | 각 장치는 글로벌 모델과 함께 개인화된 모델을 유지합니다 | 더 나은 장치별 성능 |
| **수직 FL** | 당사자 간에 서로 다른 기능(다양한 샘플이 아님) | 당사자가 동일한 데이터의 서로 다른 측면을 보유하는 경우 |

## 차등 개인 정보 보호
차등 개인 정보 보호(DP)는 알고리즘의 출력에 개인 데이터가 포함되었는지 여부가 드러나지 않는다는 수학적 보장을 제공합니다.
### 핵심 정의
메커니즘 M은 하나의 레코드가 다른 두 데이터 세트 D와 D'에 대해 (ε, δ) 차등 프라이버시를 충족합니다.
```
P(M(D) ∈ S) ≤ e^ε × P(M(D') ∈ S) + Î´
```

| 매개변수 | 의미 |
|------------|---------|
| **ε(엡실론)** | 개인 정보 보호 예산. 더 작을수록 더 사적입니다. 일반적인 값: 0.1–10. |
| **δ(델타)** | 개인정보 보호 실패 확률. 일반적으로 1/N(데이터세트 크기의 반대)으로 설정됩니다. |
### 개인 정보 보호 추가 메커니즘
| 메커니즘 | 작동 원리 | 사용 사례 |
|------------|-------------|----------|
| **가우스 메커니즘** | 쿼리의 민감도에 맞게 보정된 가우스 노이즈 추가 | 연속 값(모델 가중치) |
| **라플라스 메커니즘** | 라플라스 잡음 추가 | 쿼리 계산 |
| **지수 메커니즘** | 유틸리티에 비례하는 확률로 출력 선택 | 개별 선택 |
### DP-SGD(차등 비공개 확률적 경사하강법)
| 단계 | 설명 |
|------|-------------|
| 1. 샘플별 기울기 계산 | 일괄 그라디언트 대신 |
| 2. 그라디언트 클립 | 각 그라디언트의 최대 노름 경계(단일 샘플의 영향 제한) |
| 3. 노이즈 추가 | 집계된 그라데이션에 보정된 가우스 노이즈 추가 |
| 4. 매개변수 업데이트 | 표준 경사하강법 단계 |
| 트레이드오프 | 설명 |
|------------|-------------|
| **개인정보 보호와 정확성** | 개인 정보 보호가 강화되면(낮은 ε) 더 많은 노이즈가 필요하므로 모델 정확도가 감소합니다 |
| **개인정보 보호 및 교육 시간** | 노이즈가 많을수록 수렴 속도가 느려집니다 |
| **개인정보 보호 예산 추적** | 각 훈련 단계는 개인 정보 보호 예산의 일부를 소비합니다. 한 번 사용하면 복구할 수 없습니다 |

## 차등 개인 정보 보호와 연합 학습 결합
| 레이어 | 보호 |
|-------|------------|
| **연합 학습** | 원시 데이터는 장치에 유지됩니다 |
| **차등 개인정보 보호** | 모델 업데이트에도 시끄러워서 개별 기여를 보호합니다 |
| **보안 집계** | 서버는 개별 업데이트가 아닌 모든 업데이트의 집계만 볼 수 있습니다 |
이 조합은 강력한 개인 정보 보호를 보장합니다. 서버가 손상되더라도 특정 개인의 데이터가 훈련에 사용되었는지 여부를 확인할 수 없습니다.

## 기타 개인정보 보호 기술
### 안전한 다자간 컴퓨팅(SMPC)
여러 당사자가 개별 입력을 공개하지 않고 결합된 데이터에 대해 함수를 계산합니다.
| 기능 | 설명 |
|---------|-------------|
| **작동 방식** | 데이터는 여러 당사자에게 분산된 공유로 분할됩니다. 주식에서 계산이 발생합니다 |
| **보증** | 어떤 당사자도 다른 사람의 의견에 대해 아무것도 배울 수 없습니다 |
| **오버헤드** | 상당한 통신 및 계산 비용 |
| **사용 사례** | 고객 데이터를 공유하지 않고 공동 위험 모델을 계산하는 은행 |
### 동형암호화(HE)
암호화된 데이터에 대해 직접 계산을 수행합니다.
| 유형 | 지원되는 내용 | 오버헤드 |
|------|----|----------|
| **일부 그** | 단일 연산(덧셈 또는 곱셈) | 낮음 |
| **약간 그래요** | 두 작업 모두 제한된 수 | 중간 |
| **완전히 그** | 임의 계산 | 매우 높음(100-1000x 감속) |
| 신청 | 설명 |
|-------------|-------------|
| **사적인 추론** | 암호화된 데이터에 대해 ML 모델을 실행합니다. 암호화된 예측 반환 |
| **암호화된 교육** | 암호화된 데이터에 대한 훈련(여전히 딥러닝에 대한 이론은 대부분임) |
| **비공개 쿼리** | 쿼리 또는 데이터를 공개하지 않고 데이터베이스 쿼리 |
### 신뢰할 수 있는 실행 환경(TEE)
OS에서도 데이터를 보호하는 하드웨어 기반 격리(Intel SGX, ARM Trustzone)
| 장점 | 제한사항 |
|------------|------------|
| 거의 네이티브 성능 | 특정 하드웨어 필요 |
| 강력한 보안 보장 | 제한된 메모리(엔클레이브 크기) |
| 암호화 오버헤드 없음 | 부채널 공격 가능 |

## 개인정보 보호 규정 및 ML
| 규제 | 지역 | ML에 미치는 영향 |
|------------|---------|-------------|
| **GDPR** | EU | 설명할 권리 데이터 최소화; 처리에 대한 동의 삭제할 권리 |
| **CCPA** | 캘리포니아 | 데이터 판매에 대한 알 권리, 삭제 및 거부권 |
| **HIPAA** | 미국(헬스케어) | 건강 데이터에 대한 엄격한 통제; 비식별화 요구사항 |
| **PIPL** | 중국 | 데이터 현지화 동의 요건; 국경 간 이동 규칙 |
| **AI법** | EU | 투명성 요구사항 위험 분류; 금지된 관행 |
### ML 워크플로에 미치는 영향
| GDPR 원칙 | ML의 의미 |
|---|---------------|
| **데이터 최소화** | 꼭 필요한 것만 수집하세요. 연합 학습이 도움이 됩니다 |
| **목적 제한** | 새로운 동의 없이는 데이터를 재사용할 수 없습니다 |
| **삭제권** | 훈련된 모델에서 개인의 데이터를 제거할 수 있어야 합니다(머신 언러닝) |
| **설명할 권리** | 모델은 개별 예측을 설명할 수 있을 만큼 충분히 해석 가능해야 합니다 |
| **개인정보 보호 설계** | 개인 정보 보호는 처음부터 시스템에 내장되어야 합니다 |

## 요약
연합 학습 및 개인정보 보호 기술은 데이터가 분산되거나 민감하거나 규제될 때 어떻게 강력한 AI 모델을 구축할 것인가라는 근본적인 문제를 해결합니다. 연합 학습은 기기에 데이터를 보관하고 모델 업데이트만 공유합니다. Differential privacy adds mathematical guarantees that individual contributions can't be detected. 안전한 계산과 동형 암호화는 더 나아가 암호화된 데이터에 대한 계산을 가능하게 합니다. 각 기술에는 통신 오버헤드, 정확도 감소, 계산 비용 등 비용이 들지만, 이를 함께 사용하면 전 세계 데이터에서 학습하면서 개인 정보 보호를 존중하는 AI를 구축하기 위한 툴킷이 형성됩니다.
