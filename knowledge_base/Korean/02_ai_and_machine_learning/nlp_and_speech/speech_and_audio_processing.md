# 음성 및 오디오 처리
음성 및 오디오 처리에는 기계가 소리를 듣고, 이해하고, 생성하고, 조작할 수 있도록 하는 기술이 포함됩니다. 여기에는 음성 인식(말을 텍스트로 변환), 음성 합성(텍스트를 음성으로 변환), 화자 식별, 음악 생성 및 환경 소리 이해가 포함됩니다. 이 분야는 딥 러닝을 통해 변화되었습니다. 현대 시스템은 음성 인식에 있어 인간 수준의 정확도에 접근하고 이상할 정도로 자연스러운 합성 음성을 생성합니다.
---

## 디지털 오디오 기초
소리는 압력파입니다. 디지털 방식으로 처리하기 위해 일정한 간격으로 파동을 샘플링합니다.
| 개념 | 설명 | 일반적인 값 |
|---------|-------------|---------------|
| **샘플링 속도** | 소리가 초당 몇 번 측정되는지 | 8kHz(전화), 16kHz(음성), 44.1kHz(CD), 48kHz(전문가) |
| **비트 심도** | 각 샘플의 정밀도 | 16비트(CD), 24비트(프로페셔널), 32비트 부동(처리) |
| **채널** | 모노(1), 스테레오(2), 서라운드(5.1, 7.1) | 음악용 스테레오; 음성용 모노 |
| **기간** | 오디오 길이 | 다양함 |
16kHz, 16비트 = 1.92MB의 1분 모노 녹음입니다. 44.1kHz, 16비트 = 30.3MB의 3분짜리 스테레오 곡입니다.
---

## 오디오 특징 추출
원시 오디오 파형은 모델이 직접 작업하기 어렵습니다. 소리의 중요한 특성을 포착하는 특징을 추출합니다.
| 기능 | 캡처 내용 | 사용 사례 |
|---------|------|----------|
| **멜 스펙트로그램** | 인간의 청각 인식에 매핑된 시간 경과에 따른 주파수 콘텐츠 | 음성인식, 음악분류 |
| **MFCC**(멜주파수 켑스트럴 계수) | 스펙트럼 포락선의 컴팩트한 표현 | 기존 음성 인식 |
| **크로마그램** | 피치 클래스 분포(어떤 음표가 연주되고 있는지) | 음악 분석, 코드 감지 |
| **제로크로싱율** | 신호가 0을 교차하는 빈도 | 유성음 및 무성음 감지 |
| **RMS 에너지** | 시간에 따른 신호 크기 | 음성 활동 감지 |
| **피치(F0)** | 기본주파수 | 화자 식별, 음악 전사 |
### 멜 스펙트로그램
딥 러닝을 위한 가장 일반적인 오디오 표현입니다. 오디오를 2D 이미지와 같은 형식으로 변환합니다.
| 축 | 나타냅니다 |
|------|------------|
| **X축** | 시간 |
| **Y축** | 주파수(Mel 척도 - 지각적 간격) |
| **색상/강도** | 해당 주파수 및 시간의 에너지 |
Mel 음계는 인간의 청력과 유사합니다. 즉, 높은 주파수보다 낮은 주파수를 더 잘 구별합니다.

## 자동 음성 인식(ASR)
ASR은 음성 언어를 텍스트로 변환합니다. 이는 오디오 AI의 가장 상업적으로 중요한 응용 프로그램 중 하나입니다.
### ASR의 진화
| 시대 | 접근 | 제한사항 |
|------|------------|------------|
| **2010년 이전** | 은닉 마르코프 모델 + 가우스 혼합 모델 | 광범위한 수작업 엔지니어링이 필요합니다. 시끄러운 환경에 취약한 |
| **2010-2015** | DNN-HMM 하이브리드 | 신경망이 GMM을 대체했습니다. 상당한 개선 |
| **2015-2020** | 엔드투엔드 모델(Deep Speech, LAS) | 오디오에서 텍스트까지 단일 신경망 |
| **2020+** | Transformer 기반(Whisper, Conformer) | 최첨단 정확도; 다국어; 견고한 |
### 주요 ASR 모델
| 모델 | 건축 | 훈련 데이터 | 주목할만한 기능 |
|-------|-------------|---------------|----|
| **속삭임**(OpenAI) | 인코더-디코더 변압기 | 680,000시간, 99개 언어 | 다국어; 악센트와 소음에 강함; 오픈 소스 |
| **순응자** | 컨볼루션 + 셀프 어텐션 | 다양한 | 로컬(conv) 및 글로벌(attention) 기능 결합 |
| **wav2vec 2.0** | 자체 감독 변압기 | 라벨이 없는 연설 | 전사 없이 원시 오디오에서 학습 |
| **USM**(구글) | 보편적 음성 모델 | 200만 시간, 300개 이상의 언어 | 대부분의 언어를 다룹니다 |
| **MMS**(메타) | 대규모 다국어 연설 | 1,400개 이상의 언어 | 자원이 적은 언어로 적용 범위 확장 |
### ASR 측정항목
| 미터법 | 설명 |
|---------|-------------|
| **WER**(단어 오류율) | 잘못 표기된 단어의 비율입니다. 낮을수록 좋습니다. 깨끗한 영어의 경우 인간의 성능은 ~4-5%입니다. |
| **CER**(문자 오류율) | WER과 동일하지만 문자 수준입니다. 단어 경계가 없는 언어(중국어, 일본어)에 사용됩니다. |
### 일반적인 ASR 과제
| 도전 | 설명 |
|------------|-------------|
| **악센트와 방언** | 비표준 액센트에 대한 성능이 크게 저하됨 |
| **배경 소음** | 음악, 교통, 기타 스피커의 정확도 저하 |
| **코드 전환** | 문장 중간에 언어를 전환하는 화자 |
| **동음어** | "거기" vs "그들의" vs "그들은" — 맥락 필요 |
| **구두점 및 서식** | ASR 출력은 일반적으로 구두점이 없습니다. 후처리가 필요함 |
| **저자원 언어** | 훈련 데이터가 거의 없는 언어에서는 대부분의 모델 성능이 좋지 않습니다 |

## 텍스트 음성 변환(TTS)
TTS는 서면 텍스트를 음성 오디오로 변환합니다. 현대 시스템은 종종 사람이 녹음한 것과 구별할 수 없는 음성을 생성합니다.
### TTS의 진화
| 시대 | 접근 | 품질 |
|------|----------|---------|
| **2010년 이전** | 연결(기록된 조각 연결) | 로봇; 제한된 표현 |
| **2010-2017** | 통계적 매개변수(HMM, 초기 신경) | 더 좋지만 여전히 합성으로 인식 가능 |
| **2017-2020** | 신경망(Tacotron, WaveNet) | 인간에 가까운 품질; 표현 |
| **2020+** | 신경 코덱(VALL-E, Bark) | 음성 복제; 소수; 매우 자연스러운 |
### 주요 TTS 모델
| 모델 | 건축 | 주목할만한 기능 |
|-------|-------------|----|
| **WaveNet** (딥마인드) | 자기회귀 생성 모델 | 최초의 진정한 자연스러운 TTS |
| **타코트론 2**(구글) | Seq2seq + 보코더 | 엔드투엔드; 고품질 |
| **비츠** | 변이 추론 + 적대적 훈련 | 빠른; 양질; 널리 사용되는 |
| **VALL-E** (마이크로소프트) | 신경 코덱 언어 모델 | 3초 샘플에서 음성 복제 |
| **나무껍질**(수노) | 변압기 기반 | 다국어; 말소리가 아닌 소리(웃음, 음악) |
| **일레븐랩스** | 상업용 | 업계 최고의 음성 복제 |
| **채팅TTS** | 오픈 소스 | 대화체 연설에 최적화됨 |
| **물고기 연설** | 오픈 소스 | 빠른; 다국어 |
### 음성 복제
음성 복제는 짧은 오디오 샘플에서 특정 사람처럼 들리는 합성 음성을 생성합니다.
| 방법 | 필요한 데이터 | 품질 |
|---------|------------|---------|
| **미세 조정** | 연설 10~60분 | 고품질; 스피커별 |
| **퓨샷** | 3~30초 연설 | 양질; 빠른 설정 |
| **제로샷** | 대상 화자 데이터 없음 | 추론 시 참조 오디오 사용 |
**윤리적 우려**: 음성 복제는 사칭, 사기, 딥페이크에 사용될 수 있습니다. 대부분의 상용 서비스 제공업체에는 음성 동의가 필요합니다.

## 실용적인 팁
- **항상 데이터를 들어보세요.** 훈련하기 전에 샘플 오디오를 들어보세요. 샘플링 속도, 소음 수준 및 스피커 특성을 확인하십시오.
- **샘플링 속도를 일치시킵니다.** Whisper에서는 16kHz를 예상합니다. 오디오가 44.1kHz인 경우 리샘플링하세요. 하지만 다운샘플링하면 정보가 손실된다는 점에 유의하세요.
- **오디오 데이터를 보강합니다.** 배경 소음을 추가하고, 속도와 피치를 변경하고, 다양한 마이크를 시뮬레이션합니다. 이는 견고성을 극적으로 향상시킵니다.
- **사전 훈련된 모델을 사용합니다.** ASR용 Whisper 및 TTS용 VITS/Bark는 훌륭한 출발점입니다. 미세 조정은 처음부터 훈련하는 것보다 거의 항상 더 좋습니다.
- **무음을 처리합니다.** 음성 활동 감지(VAD)는 처리 전에 묵음을 제거하여 컴퓨팅을 절약하고 정확성을 향상시킵니다. Silero VAD와 WebRTC VAD가 인기 있는 선택입니다.
- **볼륨을 표준화합니다.** 녹음마다 음량 수준이 매우 다릅니다. 처리하기 전에 일관된 수준으로 정규화합니다.
---

## 요약
음성 및 오디오 처리는 딥 러닝을 통해 혁신을 이루었습니다. Whisper와 같은 최신 ASR 시스템은 수십 개의 언어에 걸쳐 인간 수준의 정확성에 접근합니다. TTS 시스템은 사람이 녹음한 것과 점점 더 구별하기 어려운 음성을 생성합니다. 음성 복제는 몇 초 분량의 오디오부터 작동합니다. 음악 생성, 소스 분리 및 환경 소리 감지는 모두 빠르게 발전하고 있습니다. 이 분야는 자원이 부족한 언어, 시끄러운 환경, 음성 복제에 대한 윤리적 우려 등 지속적인 문제에 직면해 있습니다. 그러나 그 궤도는 분명합니다. 기계가 듣고 이해하고 소리를 생성하는 데 있어 인간만큼 능숙해지고 있습니다.
