# 멀티모달 AI
멀티모달 AI 시스템은 텍스트, 이미지, 오디오, 비디오 등 여러 유형의 데이터에서 얻은 정보를 동시에 처리하고 결합합니다. 초기 AI 시스템은 일반적으로 단일 모드(텍스트 전용, 이미지 전용)였지만 가장 유능한 최신 시스템은 다중 모드입니다. GPT-4V는 이미지와 텍스트를 함께 읽습니다. Gemini는 텍스트, 이미지, 오디오 및 비디오를 기본적으로 처리합니다. Sora와 같은 시스템은 텍스트 설명에서 비디오를 생성합니다. 이 파일은 다중 모드 AI의 작동 방식, 그 뒤에 있는 아키텍처, 양식 결합이 왜 그렇게 강력한지를 다룹니다.
---

## 왜 멀티모달인가?
| 혜택 | 설명 | 예 |
|---------|-------------|---------|
| **더 풍부한 이해** | 다양한 양식이 보완적인 정보를 제공합니다 | 동영상은 텍스트만으로는 전달할 수 없는 동작, 소리, 맥락을 전달합니다 |
| **더 나은 일반화** | 여러 양식에 걸친 학습으로 더욱 강력한 표현 생성 | "고양이"의 이미지와 텍스트 설명을 모두 본 모델은 개념을 더 잘 이해합니다 |
| **더 자연스러운 상호작용** | 인간은 여러 채널을 통해 의사소통합니다 | 당신이 가리키는 것을 볼 수 있는 음성 비서 |
| **교차 모드 전송** | 한 양식의 지식이 다른 양식에 도움이 됩니다 | 이미지 이해는 텍스트 생성을 향상시키고 그 반대도 마찬가지입니다 |

## 핵심 아키텍처
### 비전-언어 모델(VLM)
이미지와 텍스트를 함께 처리하는 모델입니다.
| 건축 | 작동 원리 | 예 |
|-------------|-------------|---------|
| **듀얼 인코더** | 이미지와 텍스트에 대한 별도의 인코더. 나중 단계에서 결합 | 클립, 정렬 |
| **퓨전 인코더** | 이미지와 텍스트 토큰이 인터리브되어 함께 처리됩니다 | 플라밍고, 쌍둥이자리 |
| **교차주의** | 텍스트 토큰은 이미지 기능에 참여합니다(또는 그 반대) | 플라밍고, 코카 |
| **통합 토크나이저** | 이미지는 토큰으로 변환되어 텍스트 토큰과 함께 처리됩니다. | 쌍둥이자리, 카멜레온 |
### 비전 언어 모델의 작동 방식
| 단계 | 설명 |
|------|-------------|
| **1. 이미지 인코딩** | 비전 인코더(ViT, SigLIP)는 이미지를 일련의 특징 벡터로 변환합니다 |
| **2. 텍스트 인코딩** | 언어 인코더가 텍스트 토큰을 처리합니다 |
| **3. 퓨즈 방식** | 이미지 특징은 언어 모델의 임베딩 공간에 투영됩니다.
| **4. 생성** | 언어 모델은 이미지와 텍스트 입력 모두에 따라 조건화된 텍스트를 생성합니다. |
### 주요 비전-언어 모델
| 모델 | 개발자 | 건축 | 주목할만한 기능 |
|-------|------------|-------------|----|
| **클립** | 오픈AI | 듀얼 인코더(ViT + 텍스트 인코더) | 텍스트를 통한 제로샷 이미지 분류 |
| **라바** | 오픈 소스 | LLaMA + CLIP 비주얼 인코더 | 오픈 소스 VLM; 강력한 커뮤니티 |
| **GPT-4V / 4o** | 오픈AI | 통합된 다중 모드 | 텍스트, 이미지, 오디오를 함께 처리 |
| **쌍둥이자리** | 구글 딥마인드 | 훈련을 통해 기본적으로 다중 모드 | 처음부터 다중 모드용으로 구축됨 |
| **클로드** | 인류학 | 비전 + 텍스트 | 문서 및 차트 이해력이 강함 |
| **Qwen-VL** | 알리바바 | 개방형 VLM | 폐쇄형 모델과의 경쟁 |
| **인턴VL** | 오픈 소스 | 멀티 스케일 비전 인코더 | 강력한 오픈 소스 옵션 |

## 비디오 모델
비디오는 이미지, 오디오, 텍스트 및 시간을 결합하여 가장 복잡한 양식을 만듭니다.
| 모델 | 유형 | 능력 |
|-------|------|-------------|
| **소라**(OpenAI) | 텍스트-비디오 | 최대 1080p; 물리학을 이해합니다 |
| **쌍둥이자리** | 영상이해 | 오디오가 포함된 긴 동영상 분석 가능 |
| **동영상-LLaVA** | 비디오 + 텍스트 | 오픈소스 영상 이해 |
| **활주로 Gen-3** | 텍스트/이미지-비디오 | 상업용 비디오 생성 |
| **클링** | 텍스트-비디오 | 긴 형식의 비디오 생성 |
### 비디오 이해 문제
| 도전 | 설명 |
|------------|-------------|

| **긴 컨텍스트** | 비디오 길이는 몇 시간이 될 수 있습니다. 모든 프레임을 처리하는 데 비용이 많이 듭니다 |
| **시청각 동기화** | 말한 내용과 표시된 내용을 연결하기 |
| **인과관계** | 비디오 시퀀스의 원인과 결과 이해 |

## 교차 모달 검색
다양한 양식에서 관련 콘텐츠를 찾습니다.
| 작업 | 설명 | 예 |
|------|-------------|---------|
| **텍스트 → 이미지** | 텍스트 쿼리와 일치하는 이미지 찾기 | 사진 라이브러리에서 "산 너머의 일몰"을 검색하세요 |
| **이미지 → 텍스트** | 이미지와 관련된 텍스트 찾기 | 이미지 캡션 생성 |
| **텍스트 → 오디오** | 설명과 일치하는 소리 찾기 | 사운드 디자인: "자갈 위의 발자국" |
| **이미지 → 이미지** | 시각적으로 유사한 이미지 찾기 | 이미지로 제품 검색 |
### 교차 모달 검색을 위한 CLIP
CLIP의 공유 임베딩 공간은 제로샷 크로스 모달 검색을 가능하게 합니다.
| 단계 | 설명 |
|------|-------------|
| 1 | 비전 인코더로 모든 이미지를 인코딩 |
| 2 | 텍스트 인코더를 사용하여 텍스트 쿼리를 인코딩 |
| 3 | 텍스트 임베딩과 모든 이미지 임베딩 간의 코사인 유사성 계산 |
| 4 | 유사성이 가장 높은 이미지 반환 |
이는 **제로샷** 기능이라는 속성과 같은 작업별 교육 없이도 작동합니다.

## 구현된 AI
구체화된 AI는 다중 모드 인식과 물리적 동작을 결합합니다.
| 시스템 | 양식 | 신청 |
|---------|------------|-------------|
| **RT-2** (구글) | 비전 + 언어 → 로봇 액션 | 텍스트 지침을 통한 범용 로봇 제어 |
| **옥토** | 오픈소스 로봇 정책 | 다양한 로봇 데이터 교육 |
| **테슬라 옵티머스** | 시각 + 언어 → 육체노동 | 일반업무용 휴머노이드 로봇 |
| **그림 01** | 비전 + 언어 + 스피치 | 대화 능력을 갖춘 휴머노이드 로봇 |
### 구현된 AI의 과제
| 도전 | 왜 어려운가 |
|------------|---------------|
| **시뮬과 실제 간극** | 시뮬레이션은 실제 물리학을 완벽하게 포착하지 못합니다 |
| **손재주** | 미세한 운동 제어(손, 손가락)가 매우 어렵습니다 |
| **안전** | 물리적 로봇은 실제 해를 끼칠 수 있다 |
| **실시간 처리** | 밀리초 안에 인식하고, 결정하고, 행동해야 합니다 |
| **일반화** | 빨간색 컵을 집도록 훈련된 로봇이 파란색 컵을 집는 데 실패할 수 있음 |

## 요약
다중 모드 AI는 단일 목적 모델에서 모든 형태의 데이터를 인식하고 추론하는 시스템으로의 전환을 나타냅니다. GPT-4V 및 Gemini와 같은 비전 언어 모델은 이미지와 텍스트를 함께 이해할 수 있습니다. Whisper 및 VALL-E와 같은 음성 모델은 오디오를 처리합니다. 비디오 모델은 움직이는 이미지의 전체 복잡성을 소리와 함께 처리하기 시작했습니다. 추세는 분명합니다. 미래의 가장 유능한 AI 시스템은 기본적으로 다중 모드가 되어 모든 유형의 정보를 동시에 처리할 것입니다. 데이터 정렬, 계산 비용, 평가, 구현된 배포 등의 과제는 중요하지만 2024~2026년의 진행 속도는 매우 빨랐습니다.
