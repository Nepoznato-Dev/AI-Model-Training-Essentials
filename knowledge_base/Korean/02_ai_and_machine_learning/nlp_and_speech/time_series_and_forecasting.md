# 시계열 및 예측
시계열 데이터는 주가, 온도 측정값, 웹사이트 트래픽, 판매 수치, 심박수 모니터, 에너지 소비량 등 시간이 지남에 따라 수집되는 모든 데이터입니다. 예측이란 과거 패턴을 기반으로 미래 가치를 예측하는 것을 의미합니다. 이는 데이터 과학의 가장 실용적으로 가치 있는 응용 프로그램 중 하나이자 가장 어려운 응용 프로그램 중 하나입니다. 미래는 정말 불확실하고 실제 시계열은 노이즈, 계절성 및 구조적 중단으로 가득 차 있기 때문입니다.
---

## 시계열의 특성
| 구성요소 | 설명 | 예 |
|------------|-------------|---------|
| **트렌드** | 장기적인 증가 또는 감소 | 수십 년에 걸쳐 상승하는 지구 온도 |
| **계절성** | 고정된 간격으로 규칙적이고 예측 가능한 패턴 | 매년 12월 소매판매 급증 |
| **주기성** | 고정되지 않은 간격의 변동(종종 경제적) | 5~10년마다 경기 침체 |
| **소음(잔여)** | 설명할 수 없는 무작위 변형 | 일일 주가 변동 |
| **자기상관** | 현재 가치는 과거 가치에 따라 달라집니다 | 오늘의 기온은 어제와 비슷합니다 |
### 정지성
시계열의 통계적 속성(평균, 분산)이 시간이 지나도 변하지 않으면 시계열은 **정적**입니다. 대부분의 예측 방법은 정상성을 가정합니다.
| 테스트 | 목적 |
|------|---------|
| **증강된 디키 풀러(ADF)** | 단위 루트가 있는지 테스트합니다(비고정) |
| **KPSS 테스트** | 계열이 추세에 고정되어 있는지 테스트합니다. |
| 변환 | 사용 시기 |
|---------------|-------------|
| **차이** | 추세 제거: y'(t) = y(t) - y(t-1) |
| **로그 변환** | 분산 안정화(지수 증가용) |
| **계절별 차이** | 계절성 제거: y'(t) = y(t) - y(t-s) 여기서 s는 계절 길이 |

## 고전적인 예측 방법
### 이동 평균
| 방법 | 설명 | 최고의 대상 |
|---------|-------------|----------|
| **단순이동평균(SMA)** | 마지막 N개 관찰의 평균 | 잡음이 있는 데이터 평활화 |
| **가중 이동 평균** | 최근 관찰에 더 높은 가중치가 부여됨 | 최신 데이터가 더 중요한 경우 |
| **지수이동평균(EMA)** | 기하급수적으로 감소하는 가중치 | 더 적은 지연으로 추세 추적 |
### 지수평활
| 방법 | 구성요소 | 사용 사례 |
|---------|------------|----------|
| **단순(SES)** | 레벨만 | 추세 없음, 계절성 없음 |
| **홀트스(더블)** | 수준 + 추세 | 추세는 있지만 계절성은 없는 데이터 |
| **홀트-윈터스(트리플)** | 수준 + 추세 + 계절성 | 추세와 계절성을 모두 갖춘 데이터 |
### ARIMA 및 변형
ARIMA(AutoRegressive Integrated Moving Average)는 고전적인 시계열 예측의 주요 도구입니다.
| 구성요소 | 의미 | 매개변수 |
|------------|---------|------------|
| **AR (p)** | 이전 p 값에 대한 회귀 | 사용할 과거 값의 개수 |
| **나는 (d)** | 정지 상태로 만들기 위한 차분 단계 수 | 몇 번이나 차이를 내는가 |
| **MA(q)** | 과거 오류의 조합으로 오류를 모델링 | 사용할 과거 오류 수 |
| 변형 | 확장 | 사용 사례 |
|---------|------------|----------|
| **사리마** | 계절 성분 추가(P, D, Q, s) | 계절성이 강한 데이터 |
| **애리맥스** | 외부 변수를 추가합니다 | 다가오는 이벤트에 대해 알고 있는 경우 |
| **VAR** | 다변량 ARIMA; 다중 상호의존 계열 | 변수가 서로 영향을 미치는 경우 |

## 최신 ML 접근 방식
### LSTM 및 RNN 기반 모델
| 모델 | 건축 | 장점 |
|-------|-------------|----------|
| **LSTM** | 장단기 기억 네트워크 | 장거리 시간 종속성 캡처 |
| **그루** | 게이트 순환 단위(간단한 LSTM) | 더 빠른 훈련; 비슷한 성능 |
| **Seq2Seq** | 시계열용 인코더-디코더 | 유연한 입력/출력 길이 |
| **시간적 컨벌루션 네트워크(TCN)** | 확장된 인과 컨볼루션 | 병렬 훈련; 긴 수용 필드 |
### 예언자(메타)
비즈니스 시계열을 위해 설계된 실용적인 예측 도구입니다.
| 기능 | 설명 |
|---------|-------------|
| **분해** | 추세 + 계절성 + 휴일 |
| **유연함** | 누락된 데이터, 이상값 및 구조적 중단 처리 |
| **해석 가능** | 구성 요소는 사람이 읽을 수 있습니다 |
| **자동** | 합리적인 기본값 최소한의 조정이 필요함 |
| 힘 | 제한사항 |
|------------|------------|
| 비즈니스 지표(판매, 사용자)에 적합 | 매우 높은 빈도의 데이터에는 적합하지 않음 |
| 공휴일 및 특별 이벤트 처리 | 덧셈 또는 곱셈 계절성을 가정 |
| 이상치에 강함 | 복잡한 패턴의 경우 딥러닝보다 정확성이 떨어짐 |
### Transformer 기반 모델
| 모델 | 주요 기능 |
|-------|-------------|
| **제보자** | 긴 시퀀스에 대한 ProbSparse 주의 |
| **자동형성** | 계열 분해를 위한 자기상관 메커니즘 |
| **패치TST** | 시계열을 패치합니다. 채널 독립적 |
| **TimesFM**(구글) | 시계열의 기초 모델 다양한 데이터에 대한 사전 학습 |
| **크로노스**(아마존) | 시계열을 토큰화합니다. LLM 스타일 아키텍처를 사용합니다 |

## 시계열의 이상 탐지
예상 동작에서 벗어나는 비정상적인 패턴을 감지합니다.
| 방법 | 접근 | 사용 사례 |
|---------|----------|----------|
| **통계** | Z-점수, IQR, 관리도 | 간단하고 잘 이해됨 |
| **고립 숲** | 트리 기반; 무작위 분할을 통해 이상 현상을 격리합니다 | 다변량 이상 탐지 |
| **LOF**(로컬 이상치 요인) | 밀도 기반; 지역 밀도를 이웃과 비교 | 저밀도 지역에 이상이 있는 경우 |
| **자동인코더** | 재구성 오류; 높은 오류 = 이상 | 복잡한 비선형 패턴 |
| **LSTM 기반** | 다음 단계를 예측합니다. 큰 예측 오류 = 이상 | 순차적 이상 |
### 애플리케이션
| 도메인 | 이상 징후의 의미 |
|---------|------|
| **금융** | 사기, 시장 붕괴, 플래시 충돌 |
| **헬스케어** | 비정상적인 심박수, 발작 발병 |
| **제조** | 설비고장, 품질불량 |
| **사이버 보안** | 침입 시도, DDoS 공격 |
| **인프라** | 서버 과부하, 네트워크 장애 |

## 평가 지표
| 미터법 | 수식(개념) | 사용 시기 |
|---------|---------|-------------|
| **MAE**(평균 절대 오류) | 절대오차의 평균 | 해석 가능; 데이터와 동일한 단위 |
| **RMSE**(제곱평균제곱근 오류) | 평균 제곱 오류의 제곱근 | 큰 오류에 대해 더 많은 처벌을 가함 |
| **MAPE**(평균 절대 백분율 오류) | 절대 백분율 오류의 평균 | 상대 오류가 중요한 경우 |
| **SMAPE**(대칭 MAPE) | MAPE의 대칭 버전 | 0에 가까운 값을 더 잘 처리합니다 |
| **MASE**(평균 절대 스케일링 오류) | 순진한 예측에 따른 MAE | 다른 시리즈 비교 |

## 실용적인 작업 흐름
| 단계 | 설명 |
|------|-------------|
| **1. 탐색** | 시리즈를 플롯합니다. 추세, 계절성, 이상값 식별 |
| **2. 분해** | 추세, 계절, 잔차 성분으로 분리 |
| **3. 스테이셔너라이즈** | 필요한 경우 차이점 비교 또는 변환 적용 |
| **4. 분할** | 시간 기반 분할(시계열에 대해 무작위 분할이 아님) |
| **5. 기준선** | 단순 예측으로 시작(마지막 값, 계절별 단순) |
| **6. 모델** | 기존 방법(ARIMA, Prophet)을 사용한 다음 ML 방법을 사용해 보세요 |
| **7. 평가** | 적절한 측정항목을 사용하세요. 기준선과 비교 |
| **8. 반복** | 기능 추가, 다양한 모델 시도, 하이퍼파라미터 조정 |

## 요약
시계열 예측은 고전적인 통계와 최신 기계 학습을 결합합니다. 고전적인 방법(ARIMA, 지수평활, Prophet)은 해석이 가능하고 빠르며 종종 정확합니다. 딥 러닝 방법(LSTM, Transformers)은 복잡한 패턴을 포착하지만 더 많은 데이터와 튜닝이 필요합니다. 주요 원칙은 방법에 관계없이 동일하게 유지됩니다. 즉, 데이터 구조(추세, 계절성, 노이즈)를 이해하고, 간단한 기준과 비교하고, 적절한 지표로 평가하고, 미래가 과거를 정확하게 복제하지 않을 것이라는 사실을 설명합니다.
