# 컴퓨터 비전 기초
컴퓨터 비전은 기계에게 이미지, 비디오, 3D 데이터 등 세상의 시각적 정보를 해석하고 이해할 수 있는 능력을 제공합니다. 휴대폰의 얼굴 인식부터 자율주행차, 의료 영상 분석, 산업 품질 관리에 이르기까지 모든 기능을 지원합니다. 이 파일은 핵심 개념, 아키텍처 및 기술을 다루고 있습니다.
---

## 컴퓨터가 이미지를 보는 방법
### 픽셀 및 채널
디지털 이미지는 픽셀 격자입니다. 각 픽셀에는 색상 강도를 나타내는 숫자 값이 있습니다.
| 이미지 유형 | 채널 | 픽셀당 값 | 예 |
|------------|----------|----|---------|
| **회색조** | 1 | 0(검은색) ~ 255(흰색) | 의료용 엑스레이 |
| **RGB** | 3 | 빨간색, 녹색, 파란색(각 0–255) | 표준 컬러 사진 |
| **RGBA** | 4 | RGB + 알파(투명도) | 투명한 배경의 이미지 |
| **HSV** | 3 | 색조, 채도, 값 | 색상 기반 세분화 |
1920×1080 RGB 이미지는`(1080, 1920, 3)`모양의 텐서입니다. 즉, 각각 3개의 값을 갖는 620만 픽셀입니다.
### 주요 작동
| 운영 | 설명 |
|------------|-------------|
| **크기 조정** | 대상 크기에 맞게 이미지 크기 조정(쌍선형, 최근접 보간) |
| **자르기** | 관심영역 추출 |
| **정규화** | 신경망의 경우 픽셀 값을 [0,1] 또는 [-1,1]로 조정 |
| **증강** | 훈련 데이터를 인위적으로 확장(회전, 뒤집기, 색상 지터, 자르기) |
---

## 컨볼루션: 핵심 작업
컨볼루션은 이미지 전체에 작은 필터(커널)를 밀어 넣어 각 위치의 내적을 계산합니다. 이것이 CNN이 가장자리, 텍스처 및 패턴을 감지하는 방법입니다.
### 컨볼루션 매개변수
| 매개변수 | 효과 |
|------------|---------|
| **커널 크기** | 3×3, 5×5, 7×7 — 더 큰 커널은 더 큰 패턴을 포착합니다 |
| **스트라이드** | 단계 크기; stride=2는 출력 크기를 절반으로 줄입니다 |
| **패딩** | 공간적 크기를 유지하려면 테두리 주위에 0을 추가하세요. |
| **필터 수** | 각 필터는 서로 다른 특징(가장자리, 질감, 색상 패턴)을 학습합니다 |
### 컨볼루션이 배우는 것
| 레이어 깊이 | 감지된 기능 |
|-------------|------|
| **초기 레이어** | 가장자리, 모서리, 간단한 텍스처 |
| **중간 레이어** | 도형, 오브제 파츠(바퀴, 눈, 나뭇잎) |
| **깊은 레이어** | 높은 수준의 개념(얼굴, 자동차, 동물) |
---

## CNN 아키텍처
CNN 아키텍처의 진화는 컴퓨터 비전 분야의 딥 러닝 발전 과정을 말해줍니다.
| 건축 | 연도 | 핵심혁신 |
|---------------|------|---------------|
| **르넷-5** | 1998 | 최초의 실용적인 CNN; 숫자 인식 |
| **알렉스넷** | 2012 | Deep CNN이 ImageNet을 이겼습니다. ReLU, 드롭아웃, GPU 훈련 |
| **VGGNet** | 2014 | 누적된 3×3 컨볼루션(깊을수록 좋음) |
| **GoogLeNet(인셉션)** | 2014 | Inception 모듈(병렬 필터 크기) 22개 레이어 |
| **레스넷** | 2015 | 연결 건너뛰기(잔여 학습) 152개 이상의 레이어 |
| **EfficientNet** | 2019 | 복합 스케일링(깊이 + 너비 + 해상도) |
| **ConvNeXt** | 2022 | 현대화된 ResNet; 트랜스포머와 경쟁 |
### ResNet이 모든 것을 변화시킨 이유
ResNet 이전에는 Vanishing Gradient 문제로 인해 매우 깊은 네트워크를 훈련하는 것이 거의 불가능했습니다. ResNet에서는 **연결 건너뛰기**(잔차 연결이라고도 함)를 도입했습니다. 즉, 레이어에 대한 입력이 출력에 추가됩니다.
```
output = F(x) + x    # Skip connection
```

이 간단한 아이디어를 통해 152개 이상의 레이어가 있는 네트워크를 효과적으로 훈련할 수 있었으며 이제 거의 모든 딥 아키텍처의 표준이 되었습니다.

## 핵심비전과제
### 이미지 분류
전체 이미지에 라벨을 할당합니다.
| 모델 | 접근 |
|-------|----------|
| CNN(ResNet, EfficientNet) | 전통적인 접근방식; 뛰어난 정확성 |
| 비전 트랜스포머(ViT) | 이미지를 일련의 패치로 처리합니다. 변압기 인코더 |
| 전이학습 | 데이터 세트에서 사전 훈련된 모델 미세 조정 |
### 객체 감지
경계 상자를 사용하여 이미지 내에서 여러 개체를 찾고 분류합니다.
| 모델 | 유형 | 속도 |
|-------|------|-------|
| **R-CNN** | 2단계(제안+분류) | 천천히 |
| **빠른 R-CNN** | 향상된 2단계 | 중간 |
| **더 빠른 R-CNN** | 지역 제안 네트워크 + 탐지기 | 중간 |
| **욜로**(v1–v10) | 단일 스테이지; 한 번에 상자 + 클래스 예측 | 매우 빠르다 |
| **디트** | 변압기 기반; 앵커 박스 없음 | 중간 |
**YOLO**(You Only Look Once)는 실시간 탐지에 적합합니다. **빠른 R-CNN**은 속도보다 정확성이 더 중요한 경우에 선호됩니다.
### 이미지 분할
이미지의 모든 픽셀을 분류합니다.
| 유형 | 설명 | 사용 사례 |
|------|-------------|----------|
| **의미론적 분할** | 각 픽셀은 클래스 라벨을 얻습니다 | 자율주행(도로, 자동차, 보행자) |
| **인스턴스 분할** | 각 픽셀 + 객체 인스턴스 ID | 개체 계산, 의료 영상 |
| **팬옵틱 분할** | 시맨틱 + 인스턴스 결합 | 종합적인 장면 이해 |
주요 모델: U-Net(의료 영상), Mask R-CNN(인스턴스), DeepLab(의미론), Segment Anything Model(SAM — 범용 분할).
### 이미지 생성
| 접근 | 설명 | 예 |
|----------|-------------|----------|
| **GAN** | 생성자 vs 판별자 적대적 훈련 | StyleGAN, CycleGAN |
| **VAE** | 잠재 분포를 알아보세요. 생성할 샘플 | 변형 자동 인코더 |
| **확산 모델** | 반복적으로 무작위 노이즈 제거 | 안정 확산, DALL-E, Midjourney |
확산 모델은 이미지 생성 품질 측면에서 GAN을 크게 능가했습니다.

## 비전을 위한 전이 학습
CNN을 처음부터 훈련하려면 막대한 데이터와 컴퓨팅이 필요합니다. 전이 학습을 사용하면 이미 수백만 개의 이미지(ImageNet)에 대해 훈련된 모델로 시작하여 특정 작업에 맞게 미세 조정할 수 있습니다.
### 단계
1. **사전 훈련된 모델을 선택합니다**(ResNet50, EfficientNet-B0, ViT).
2. **분류 헤드**를 자신의 것으로 교체합니다(클래스 수에 맞게).
3. **초기 레이어를 고정합니다**(가장자리와 같은 일반적인 특징을 캡처합니다).
4. 낮은 학습률로 데이터세트를 **미세 조정**합니다.
5. 더 많은 적응이 필요한 경우 **점진적으로 동결을 해제하세요**.
이 접근 방식은 일반적으로 1,000~10,000개의 레이블이 지정된 이미지로 높은 정확도를 달성합니다.

## 데이터 확대
증강은 변환을 적용하여 훈련 데이터 세트를 인위적으로 확장합니다.
| 증강 | 효과 | 사용 시기 |
|-------------|---------|-------------|
| **임의 자르기** | 임의의 지역으로 자르기 | 거의 항상 |
| **가로 뒤집기** | 거울 이미지 | 방향이 중요하지 않을 때 |
| **회전** | 임의의 각도로 회전 | 어떤 각도에서든 물체가 나타날 때 |
| **색상 지터** | 밝기, 대비, 채도를 무작위로 조정 | 조명이 다양할 때 |
| **임의 삭제** | 무작위 영역 마스크 | 견고성 향상 |
| **믹스업 / 컷믹스** | 두 개의 이미지와 라벨을 혼합하세요 | 정규화 |
라이브러리:`torchvision.transforms`,`albumentations`,`imgaug`,`tf.keras.preprocessing`.

## 실용적인 팁
- **전이 학습으로 시작하세요.** 사전 학습된 모델을 미세 조정하는 것이 거의 모든 경우에 처음부터 학습하는 것보다 낫습니다.
- **입력을 정규화합니다.** 사전 훈련된 모델이 기대하는 정규화(일반적으로 ImageNet 평균/표준)와 일치합니다.
- **적절한 측정항목을 사용합니다.** 균형 잡힌 데이터세트의 정확성; 불균형 또는 감지 작업을 위한 F1, mAP 또는 IoU.
- **데이터를 시각화합니다.** 샘플 이미지를 보고, 클래스 분포를 확인하고, 모델 예측을 검사합니다.
- **현명하게 확대하세요.** 해당 도메인에 적합한 변환만 적용하세요(의료 이미지를 수직으로 뒤집지 마세요).
- **과적합을 모니터링합니다.** 훈련 정확도는 높지만 검증이 낮은 경우 증강을 늘리거나 드롭아웃을 추가합니다.
