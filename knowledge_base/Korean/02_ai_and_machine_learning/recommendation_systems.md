# 추천 시스템
추천 시스템은 사용자가 다음에 무엇을 보고, 구매하고, 상호 작용할지 예측합니다. 소셜 미디어의 콘텐츠 피드, 전자 상거래 사이트의 제품 제안, 스트리밍 플랫폼의 영화 추천 및 검색 결과를 강화합니다. 대부분의 사용자에게 보이지 않음에도 불구하고 이는 전 세계에서 상업적으로 가장 영향력 있는 AI 시스템 중 하나입니다. Netflix는 추천 엔진이 가입자 이탈을 줄여 연간 10억 달러 이상을 절약한다고 추정합니다.
---

## 추천이 어려운 이유
| 도전 | 설명 |
|------------|-------------|
| **규모** | 수백만 명의 사용자 × 수백만 개의 항목 = 수십억 개의 가능한 쌍 |
| **희소성** | 각 사용자는 사용 가능한 항목 중 극히 일부와 상호작용했습니다 |
| **콜드 스타트** | 신규 사용자와 신규 아이템에는 상호작용 기록이 없습니다 |
| **동적 환경설정** | 시간이 지남에 따라 사용자 취향이 변합니다 |
| **정확성을 넘어서** | 추천은 다양하고, 참신하고, 우연적이어야 합니다 |
| **사업 목표** | 참여 극대화 ≠ 사용자 웰빙 극대화 |
---

## 핵심 접근 방식
### 협업 필터링
아이디어: 사용자 A와 B가 과거에 동의했다면 앞으로도 동의할 가능성이 높습니다.
| 유형 | 작동 원리 | 예 |
|------|-------------|---------|
| **사용자 기반** | 유사한 사용자를 찾으세요. 그들이 좋아하는 것을 추천 | "이것을 좋아한 사용자는 다음도 좋아했습니다..." |
| **아이템 기반** | 사용자가 이미 좋아하는 것과 유사한 항목 찾기 | "당신이 지켜봤기 때문에..." |
| **행렬 분해** | 사용자-항목 상호작용 매트릭스를 잠재 요인으로 분해 | SVD, ALS(교대 최소 제곱) |
| 힘 | 약점 |
|------------|----------|
| 항목 자체를 이해할 필요가 없습니다 | 콜드 스타트 ​​문제: 새 항목을 추천할 수 없습니다 |
| 복잡하고 암시적인 선호도 캡처 | 많은 상호작용 데이터가 필요함 |
| 모든 콘텐츠 유형에서 작동 | 인기 편향: 이미 인기 있는 상품을 추천 |
### 콘텐츠 기반 필터링
아이템 특성에 따라 사용자가 이미 좋아하는 것과 유사한 아이템을 추천합니다.
| 기능 유형 | 예 |
|---------------|---------|
| **텍스트** | 장르, 설명, 키워드, 출연진 |
| **오디오** | 템포, 장르, 무드(음악용) |
| **시각적** | 컬러 팔레트, 스타일(이미지/패션용) |
| **메타데이터** | 가격, 브랜드, 카테고리 |
| 힘 | 약점 |
|------------|----------|
| 항목에 대한 콜드 스타트 ​​없음(기능이 알려져 있음) | 사용자의 기존 취향을 벗어난 상품은 추천할 수 없습니다 |
| 더 적은 상호작용 데이터로 작동 | 좋은 기능 엔지니어링이 필요합니다 |
| 설명 가능("X와 유사하므로 권장됨") | 우연이 적다 |
### 하이브리드 접근 방식
대부분의 제작 시스템은 협업 및 콘텐츠 기반 방법을 결합합니다.
| 하이브리드 전략 | 설명 |
|---|-------------|
| **가중치** | 여러 모델의 점수 결합 |
| **전환** | 신규 사용자에게는 콘텐츠 기반을 사용하고, 기존 사용자에게는 협업을 사용 |
| **캐스케이드** | 먼저 간단한 모델을 사용한 다음 복잡한 모델로 개선 |
| **기능 조합** | 협업 및 콘텐츠 기능을 단일 모델로 병합 |
| **메타학습** | 다양한 추천자를 결합하는 방법 알아보기 |

## 최신 딥 러닝 접근 방식
### 2타워 모델
대규모 추천을 위한 주요 아키텍처(YouTube, Pinterest, Spotify에서 사용)
| 구성요소 | 역할 |
|------------|------|
| **사용자 타워** | 사용자 특징과 기록을 임베딩으로 인코딩하는 신경망 |
| **아이템 타워** | 항목 특징을 임베딩으로 인코딩하는 신경망 |
| **유사성** | 사용자와 항목 임베딩 간의 내적 또는 코사인 유사성 |
| 단계 | 설명 |
|------|-------------|
| 1 | 상호 작용하는 사용자 항목 쌍에 대해 유사한 임베딩을 생성하도록 두 타워를 훈련합니다 |
| 2 | 제공 시간에 항목 임베딩을 미리 계산합니다 |
| 3 | 사용자 요청의 경우 사용자 삽입 계산 |
| 4 | ANN(Approximous Nearest Neighbor) 검색을 사용하여 가장 유사한 항목 찾기 |
### 추천을 위한 시퀀스 모델
사용자 행동은 순차적입니다. 어제 시청한 내용이 오늘 시청할 내용에 영향을 미칩니다.
| 모델 | 접근 |
|-------|----------|
| **GRU4Rec** | 세션 기반 추천을 위한 GRU 기반 모델 |
| **SASRec** | Self-attention 기반 순차 추천기 |
| **BERT4Rec** | 순차적 추천을 위한 양방향 변환기 |
| **유튜브 DNN** | 시청 기록을 시퀀스로 처리하는 심층 신경망 |
### 검색과 순위 지정
최신 시스템은 권장 사항을 두 단계로 나눕니다.
| 무대 | 목적 | 방법 |
|-------|---------|---------|
| **검색(후보 생성)** | 수백만 개의 항목을 최대 1,000개의 후보로 좁힙니다 | 2타워 모델; ANN 검색; 빠르지만 대략적인 |
| **순위(득점)** | 후보자를 정확하게 점수 매기고 순서를 지정 | 많은 기능을 갖춘 심층 모델; 느리지만 정확함 |
| **재순위** | 다양성, 비즈니스 규칙, 신선도 조정 | 상황에 맞는 도적; 제약조건 최적화 |

## 평가 지표
| 미터법 | 측정 대상 | 사용 시기 |
|---------|------|-------------|
| **정밀@K** | 관련된 상위 K 권장사항의 비율 | 탑픽의 정확성이 중요할 때 |
| **리콜@K** | Top-K에서 발견된 관련 항목의 비율 | 좋은 아이템이 빠지지 않을까 걱정될 때 |
| **NDCG**(정규화 할인 누적 이득) | 순위 품질; 관련 항목을 더 높게 보상 | 순위가 중요한 경우 |
| **MAP**(평균 평균 정밀도) | 모든 사용자의 평균 정밀도 | 종합 순위 품질 |
| **적중률@K** | Top-K에 관련 항목이 하나 이상 표시되는지 여부 | 바이너리 관련성 시나리오 |
| **보도** | 추천받는 항목의 비율 | 다양성과 공정성 |
| **세렌디피티** | 예상치 못했지만 관련성이 높은 권장사항 | 사용자 만족도 |

## 콜드 스타트 ​​문제
| 시나리오 | 도전 | 솔루션 |
|----------|------------|------------|
| **신규 사용자** | 상호작용 기록 없음 | 인구통계를 사용하세요. 인기상품 보여주기 상황별 신호(위치, 장치, 시간) 사용 |
| **새 항목** | 아직 아무도 상호작용하지 않았습니다 | 콘텐츠 기능을 사용하세요. 탐색-이용 전략; 산적 알고리즘 |
| **새로운 시스템** | 데이터가 전혀 없습니다 | 유사한 도메인에서 학습을 전이합니다. 초기 콘텐츠 선별 |

## 탐색과 활용
| 전략 | 설명 | 트레이드오프 |
|----------|-------------|----------|
| **ε-탐욕** | 확률이 ε인 무작위 항목 표시 | 단순하지만 비효율적 |
| **톰슨 샘플링** | 품목 품질의 사후 분포 표본 | 원칙적인; 좋은 이론적 특성 |
| **신뢰상한(UCB)** | 불확실성이 높은 품목을 선호 | 탐험과 활용의 적절한 균형 |
| **컨텍스트 도적** | 사용자 컨텍스트에 따른 탐색 | 블라인드 탐색보다 더 효율적 |
| **다양성 주입** | 다양하거나 참신한 항목을 의도적으로 포함 | 단순한; 단기 참여가 감소할 수 있음 |

## 편견과 공정성
| 바이어스 유형 | 설명 | 영향 |
|------------|-------------|---------|
| **인기편향** | 인기상품 추천도 많아지고 인기도 많아져 | 롱테일 품목은 서비스가 부족합니다 |
| **선택 편향** | 모델은 가능한 모든 상호 작용이 아닌 관찰된 상호 작용을 통해 학습합니다 | 활성 사용자 쪽으로 치우쳐 있음 |
| **직위편향** | 높은 순위에 표시된 항목은 품질에 관계없이 더 많은 클릭을 얻습니다 | 최고 지위 강화 |
| **노출 편향** | 표시된 항목은 더 많은 훈련 신호를 얻습니다 | 피드백 루프 |
| **인구통계적 편견** | 권장사항은 인구통계에 따라 불공정한 방식으로 다릅니다 | 차별; 일부 그룹의 열악한 경험 |

## 요약
추천 시스템은 업계에서 가장 영향력 있는 AI 애플리케이션 중 하나입니다. 이 분야는 단순한 협업 필터링에서 사용자 기록, 항목 콘텐츠, 상황별 신호 및 비즈니스 목표를 결합하는 딥 러닝 아키텍처로 발전했습니다. 최신 시스템은 빠른 후보 생성을 위한 2타워 모델과 정확한 점수 매기기를 위한 심층 모델이 포함된 검색-순위-재순위 파이프라인을 사용합니다. 콜드 스타트, 편견, 탐색, 사용자 만족도와 비즈니스 목표의 균형을 맞추는 과제는 연구 및 엔지니어링의 활발한 영역으로 남아 있습니다.
