# 통계적 테스트 및 실험
통계는 과학의 문법이다. 이는 실제 패턴을 무작위 노이즈와 구별하고, 변경 사항이 실제로 개선되었는지 여부를 측정하고, 불확실성 속에서 결정을 내릴 수 있는 도구를 제공합니다. 이 파일은 가설 테스트, 실험 설계 및 사람들을 당황하게 만드는 일반적인 함정의 핵심 개념을 다루고 있습니다.
---

## 가설 테스트 프레임워크
모든 통계 테스트는 동일한 논리를 따릅니다.
1. **귀무가설(H₀) 명시**: 효과 없음/차이 없음.
2. **대립가설(H₁)을 서술하세요**: 효과/차이가 있습니다.
3. **유의 수준(α) 선택**: 일반적으로 0.05(위양성 가능성 5%).
4. **데이터를 수집하고 테스트 통계를 계산합니다**.
5. **p-값 계산**: H₀이 참인 경우 이 결과(또는 더 극단적인)를 관찰할 확률입니다.
6. **결정을 내립니다**: p < α인 경우 H₀를 기각합니다(통계적으로 유의함). 그렇지 않으면 H₀을 기각하지 못합니다.
### 주요 개념
| 개념 | 의미 | 일반적인 오해 |
|---------|---------|-------|
| **p-값** | P(데이터 \| H₀이 참임) | NOT "H₀이 참일 확률" |
| **α(유의수준)** | H₀ 기각 임계값 | 효과 중요성의 척도가 아님 |
| **통계적 유의성** | 우연만으로는 결과가 나올 가능성이 낮습니다 | 실질적으로 중요한 의미는 아닙니다 |
| **효과 크기** | 관찰된 효과의 크기 | p-값과 분리됩니다. 큰 N |에서는 작은 효과가 중요할 수 있습니다.
| **전력** | 거짓 H₀을 올바르게 거부할 확률 | 일반적으로 80% 이상을 목표로 합니다 |
| **신뢰 구간** | 매개변수에 대한 가능한 값의 범위 | 95% CI는 "참값이 이 범위에 있을 확률이 95%"라는 의미는 아닙니다. |
---

## 오류 유형
| | H₀은 참입니다 | H₀는 거짓입니다 |
|---|------------|------------|
| **H₀ 거부** | 제1종 오류(거짓양성) | ✅ 정답(참 긍정) |
| **H₀ 거부 실패** | ✅ 정확함(참 부정) | 제2종 오류(거짓음성) |
| 오류 | 기호 | 의미 |
|-------|---------|---------|
| **유형 I** | α | 효과가 없을 때 효과가 있다고 결론짓기 |
| **유형 II** | β | 실제 효과가 누락됨 |
---

## 올바른 테스트 선택
| 시나리오 | 테스트 | 가정 |
|------------|------|-------------|
| 두 그룹의 평균 비교 | **t-테스트**(독립) | 정규분포, 등분산 |
| 쌍을 이루는 관측치의 평균 비교 | **쌍체 t-검정** | 차이는 정규 분포를 따릅니다. |
| 3개 이상의 그룹의 평균 비교 | **ANOVA** | 정규분포, 등분산 |
| 범주형 분포 비교 | **카이제곱 검정** | 셀당 충분한 샘플 크기 |
| 분포 비교(비모수) | **만-휘트니 U** | 정규성 가정 없음 |
| 3개 이상의 그룹 비교(비모수적) | **크루스칼-월리스** | 정규성 가정 없음 |
| 상관관계 테스트 | **Pearson**(선형) 또는 **Spearman**(단조) | 피어슨: 정상성; Spearman: 순위 기반 |
| 데이터가 분포를 따르는지 테스트 | **콜모고로프-스미르노프** | 지속적인 데이터 |
### 모수적 대 비모수적
| | 파라메트릭 | 비모수적 |
|---|------------|---------------|
| **가정** | 데이터는 특정 분포(일반적으로 정규)를 따릅니다. | 분포 가정 없음 |
| **전력** | 가정이 충족되면 더 높아집니다 | 더 낮지만 더 강력함 |
| **사용 시기** | 대규모 샘플, 대략 정규 데이터 | 작은 표본, 치우친 데이터, 순서 데이터 |

## 특정 테스트 자세히 보기
### t-테스트
두 그룹의 평균을 비교합니다.
| 변형 | 사용 사례 |
|---------|----------|
| **독립 t-테스트** | 두 개의 별도 그룹(치료 대 대조군) |
| **쌍체 t-검정** | 동일한 그룹이 두 번 측정됨(전 vs 후) |
| **일표본 t-검정** | 표본 평균을 알려진 값과 비교 |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA(분산 분석)
비교는 3개 이상의 그룹에 대한 평균을 의미합니다. 하나 이상의 그룹 평균이 나머지 그룹 평균과 다른지 여부를 테스트합니다.
| 유형 | 디자인 |
|------|---------|
| **단방향 분산 분석** | 3개 이상의 수준을 갖는 하나의 독립변수 |
| **양방향 분산 분석** | 두 개의 독립 변수; 상호작용 효과 테스트 |
| **반복 측정 ANOVA** | 동일한 주제를 다른 조건에서 측정 |
ANOVA가 유의미한 경우 **사후 테스트**(Tukey의 HSD)를 수행하여 어떤 특정 그룹이 다른지 확인합니다.
### 카이제곱 테스트
두 범주형 변수가 독립적인지 여부를 테스트합니다.
| 사용 사례 | 예 |
|------------|---------|
| **독립성 테스트** | 성별이 제품 선호도와 관련이 있나요? |
| **핏의 좋음** | 주사위 굴림은 균일한 분포를 따르나요? |
**경험 법칙**: 각 셀의 예상 개수는 5 이상이어야 합니다.

## A/B 테스트
A/B 테스트는 비즈니스 결정에 가설 테스트를 적용하는 것입니다. 일반적으로 컨트롤(A)과 변형(B)을 비교합니다.
### 디자인 프로세스
| 단계 | 설명 |
|------|-------------|
| **1. 가설 정의** | "버튼 색상을 파란색에서 녹색으로 변경하면 클릭률이 높아집니다." |
| **2. 측정항목 선택** | 기본: 클릭률. 2차: 전환율, 수익. |
| **3. 표본 크기 계산** | 검출 가능한 최소 효과, 검정력(80%) 및 유의성(5%) 기준 |
| **4. 무작위** | 제어 및 치료에 사용자를 무작위로 할당 |
| **5. 실험 실행** | 목표 샘플 크기에 도달할 때까지 데이터 수집 |
| **6. 분석** | 적절한 통계 테스트를 사용하여 측정항목 비교 |
| **7. 결정** | 통계적으로나 실질적으로 유의미한 경우 구현 |
### 샘플 크기 계산
필요한 샘플 크기는 다음에 따라 다릅니다.
| 요인 | 표본 크기에 미치는 영향 |
|---------|---------|
| **감지할 수 있는 작은 효과** | 더 많은 샘플이 필요합니다 |
| **더 높은 전력** | 더 많은 샘플이 필요합니다 |
| **낮은 유의 수준** | 더 많은 샘플이 필요합니다 |
| **더 높은 분산** | 더 많은 샘플이 필요합니다 |
### 일반적인 A/B 테스트 실수
| 실수 | 왜 틀렸는가 |
|---------|---------------|
| **초기 엿보기** | 매일 결과 확인하면 위양성률 높아진다 |
| **수정 없는 여러 측정항목** | α=0.05에서 20개 측정항목 테스트 → 우연히 1개의 거짓양성 예상 |
| **목표 N 앞에서 정지함** | 저전력 테스트로 실제 효과를 감지할 수 없음 |
| **계절성 무시** | 휴일 기간과 일반 주 동안 테스트 실행 |
| **비무작위 할당** | 선택 편향(예: 새로운 사용자를 치료에 할당) |
| **의미와 중요성의 혼동** | 0.1% 상승은 통계적으로 유의미할 수 있지만 실행할 가치는 없습니다 |

## 다중 비교
여러 테스트를 동시에 실행하면 하나 이상의 잘못된 긍정 가능성이 크게 높아집니다.
| 테스트 횟수 | ≥1 거짓 긍정 확률(α=0.05에서) |
|---|--------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 40% |
| 20 | 64% |
### 수정
| 방법 | 작동 원리 | 사용 시기 |
|---------|-------------|-------------|
| **본페로니** | α를 테스트 횟수(α/n)로 나누기 | 보수적인; 몇 가지 비교 |
| **홀름-본페로니** | 단계적 절차; 덜 보수적 | 일반용도 |
| **벤자미니-호흐베르그(FDR)** | 허위발견율 제어 | 많은 테스트; 탐색적 분석 |

## 효과 크기
P-값은 효과가 존재하는지 *여부*를 알려줍니다. 효과 크기는 *얼마나 큰*지 알려줍니다.
| 측정 | | 통역 |
|---------|------|---------------|
| **코헨의 d** | 두 가지 수단의 차이점 | 0.2 = 소형, 0.5 = 중형, 0.8 = 대형 |
| **피어슨의 r** | 상관관계 | 0.1 = 소형, 0.3 = 중형, 0.5 = 대형 |
| **²²(에타제곱)** | 분산 분석 | 0.01 = 소형, 0.06 = 중형, 0.14 = 대형 |
| **승률** | 범주형 결과 | 1.0 = 효과 없음; >1 또는 <1 = 효과 |
**항상 p-값과 함께 효과 크기를 보고합니다.** 결과는 통계적으로 유의미하지만 실제로는 의미가 없을 수 있습니다.

## 베이지안 대 빈도주의자
| 측면 | 빈도주의자 | 베이지안 |
|---------|------------|---------|
| **확률** | 장기간의 사건 빈도 | 신념의 정도 |
| **매개변수** | 수정되었지만 알 수 없음 | 분포가 있는 무작위 변수 |
| **용도** | p-값, 신뢰 구간, 가설 검정 | 사후 분포, 신뢰할 수 있는 간격 |
| **이전** | 이전 신념이 통합되지 않았습니다 | 명시적 사전 배포 |
| **해석** | "이 실험을 여러 번 반복하면..." | "주어진 데이터에서 확률은..." |
| **강점** | 객관적이고, 확고한, 단순한 | 직관적인 해석, 사전 지식 통합 |
| **약점** | p-값이 널리 오해됨 | 사전 선택은 주관적일 수 있습니다 |

## 인과 추론 기본 사항
상관관계는 인과관계가 아닙니다. 그러나 때로는 연관 여부뿐만 아니라 *X가 Y의 원인인지*를 알아야 할 때도 있습니다.
| 방법 | 설명 | 사용 시기 |
|---------|-------------|-------------|
| **무작위 실험** | 골드 스탠다드; 무작위 할당으로 혼란을 제거합니다 | 무작위로 추출할 수 있는 경우 |
| **DiD(차이의 차이)** | 치료군과 대조군 사이의 시간 경과에 따른 변화 비교 | 정책변화, 자연실험 |
| **회귀 불연속성(RDD)** | 컷오프 임계값 활용 | 장학금, 자격 기준 |
| **도구변수(IV)** | 치료에 영향을 미치지만 결과에 직접적으로 영향을 미치지 않는 도구를 사용 | 무작위화가 불가능한 경우 |
| **성향점수 매칭** | 관찰된 특성에 따라 처리된 단위와 제어 단위를 일치시키세요 | 관찰 연구 |

## 일반적인 통계 오류
| 실수 | 설명 |
|---------|-------------|
| **해킹** | p < 0.05를 찾을 때까지 많은 분석 시도 |
| **고려** | 결과가 알려진 후 가설 |
| **생존편향** | 성공 사례만 보기(예: 성공적인 기업) |
| **심슨의 역설** | 데이터가 집계될 때와 그룹별로 분할될 때 추세가 반전됩니다 |
| **기본요금 무시** | 결과 해석 시 사전 확률 무시 |
| **생태학적 오류** | 그룹 수준 데이터에서 개인 행동 추론 |
| **혼란스러운** | 세 번째 변수는 관찰된 관계를 설명합니다 |
| **과적합** | 모델은 신호가 아닌 잡음을 포착합니다 |

## 요약
통계 테스트는 불확실한 상황에서 지적 정직성을 바탕으로 결정을 내리는 것입니다. 데이터를 수집하기 전에 항상 가설을 명시하십시오. 데이터 유형에 적합한 테스트를 선택하세요. p-값뿐만 아니라 효과 크기도 보고합니다. 다중 비교에 적합합니다. 그리고 기억하세요: 통계적 유의성은 실제적 유의성과 동일하지 않습니다.
