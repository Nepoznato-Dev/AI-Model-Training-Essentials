# 앙상블 방법
앙상블 방법은 여러 기계 학습 모델을 결합하여 단일 모델만으로 달성할 수 있는 것보다 더 나은 예측을 생성합니다. 직관은 간단합니다. 각각 어느 정도 정확하지만 서로 다른 오류를 내는 여러 모델이 있는 경우 해당 예측을 결합하면 개별 실수가 취소되고 보다 강력한 결과가 생성됩니다. 앙상블은 가장 경쟁력 있는 기계 학습 솔루션의 기반이 되며 생산 시스템에서 가장 신뢰할 수 있는 기술 중 하나로 남아 있습니다.
---

## 앙상블이 작동하는 이유
| 원리 | 설명 |
|------------|-------------|
| **군중의 지혜** | 평균을 낸 여러 개의 불완전한 추정이 단일 추정보다 낫습니다 |
| **편향-분산 절충** | 앙상블은 다른 요소를 희생하지 않고도 분산(배깅) 또는 편향(부스팅)을 줄일 수 있습니다.
| **오류 다양성** | 모델이 서로 다른 오류를 범하는 경우 이를 결합하면 개별 실수가 상쇄됩니다 |
| **결정 경계 평활화** | 여러 모델이 하나의 모델보다 더 강력한 의사결정 표면을 생성 |
---

## 배깅(부트스트랩 집계)
### 작동 방식
| 단계 | 설명 |
|------|-------------|
| **1. 부트스트랩 샘플링** | 학습 데이터에서 여러 개의 무작위 샘플(교체 포함) 추출 |
| **2. 기차 베이스 모델** | 각 부트스트랩 샘플(일반적으로 의사결정 트리)에 대해 하나의 모델 학습 |
| **3. 집계** | 회귀의 경우: 평균 예측. 분류: 다수결 |
### 주요 특징
| 특징 | 설명 |
|---------------|-------------|
| **편차 감소** | 평균화는 개별 모델 변동을 완화합니다 |
| **병렬 훈련** | 각 기본 모델은 독립적입니다. 동시에 훈련 가능 |
| **기본 평가** | 각 샘플은 일부 부트스트랩 샘플에서 제외됩니다. 검증을 위해 이를 사용 |
| **상관관계** | 각 분할에서 무작위 기능 선택으로 트리 간의 상관 관계 감소 |
### 랜덤 포레스트
| 측면 | 설명 |
|---------|-------------|
| **기본 학습자** | 의사결정나무 |
| **주요 추가** | 각 분할에서 임의의 기능 하위 집합(일반적으로 sqrt(n_features))만 고려 |
| **작동하는 이유** | 무작위 특징 선택은 트리의 상관 관계를 해제하여 앙상블을 더욱 강력하게 만듭니다. |
| **초매개변수** | 나무의 수; 최대 깊이; 리프당 최소 샘플; 최대 기능 |
| **강점** | 고차원 데이터를 처리합니다. 특이치에 강함; 기능 중요성 제공 |
| **약점** | 단일 트리보다 해석하기가 어렵습니다. 시끄러운 회귀 작업에 과적합될 수 있음 |
---

## 부스팅
### 작동 방식
| 단계 | 설명 |
|------|-------------|
| **1. 첫 번째 모델 훈련** | 데이터에 대한 기본 모델(종종 얕은 트리/"그루터기") 학습 |
| **2. 오류 식별** | 모델이 잘못된 인스턴스 찾기 |
| **3. 다음 모델 훈련** | 실수(재가중치 또는 잔차 적합치)에 초점을 맞춘 새 모델 학습 |
| **4. 순차적으로 결합** | 각각의 새로운 모델은 모든 이전 모델의 누적된 오류를 수정합니다 |
| **5. 반복** | 지정된 라운드 수 동안 계속 |
### 부스팅 알고리즘
| 알고리즘 | 손실 함수 | 주요 기능 |
|------------|---------------|-------------|
| **에이다부스트** | 지수 | 잘못 분류된 인스턴스에 다시 가중치를 부여합니다. 단순한; 소음에 민감 |
| **그라디언트 부스팅** | 미분 가능한 손실 | 잔차에 적합(손실 기울기). 더 유연하게 |
| **XGBoost** | 정규화된 그래디언트 부스팅 | L1/L2 정규화; 2차 기울기; 하드웨어 최적화 |
| **LightGBM** | 그라데이션 기반 단면 샘플링 | 잎 모양의 성장; 히스토그램 기반; 대규모 데이터 세트에서 빠른 속도 |
| **캣부스트** | 주문형 부스팅 | 기본적으로 범주형 기능을 처리합니다. 과적합 감소 |
### 부스팅 대 배깅
| 차원 | 포장 | 부스팅 |
|------------|---------|----------|
| **교육** | 병렬 | 순차 |
| **포커스** | 변동 감소 | 편견 감소 |
| **기본 모델** | 고분산, 저편향(깊은 나무) | 낮은 분산, 높은 편향(얕은 나무/그루터기) |
| **조합** | 동일한 무게 | 성과에 따른 가중치 |
| **과적합** | 덜 경향이 | 라운드가 너무 많으면 과적합될 수 있음 |
| **소음 민감도** | 견고함 | 시끄러운 데이터에 민감함 |

## 스태킹
### 작동 방식
| 단계 | 설명 |
|------|-------------|
| **1. 기차 베이스 모델** | 다양한 모델 학습(예: 랜덤 포레스트, SVM, 신경망, 그래디언트 부스팅) |
| **2. 예측 생성** | 아웃오브폴드 예측(교차 검증)을 입력 기능으로 사용 |
| **3. 메타 모델 훈련** | 기본 모델의 예측을 바탕으로 두 번째 수준 모델 학습 |
| **4. 최종 예측** | 기본 모델은 예측합니다. 메타 모델은 그들의 예측을 결합합니다 |
### 스태킹 모범 사례
| 연습 | 이유 |
|----------|---------|
| **다양한 기본 모델 사용** | 다른 알고리즘은 다른 오류를 만듭니다. 다양성이 핵심입니다 |
| **기본 예측에 교차 검증 사용** | 메타 모델이 과적합 기본 모델을 활용하는 방법을 학습하는 것을 방지합니다.
| **메타 모델을 단순하게 유지** | 로지스틱 회귀 또는 얕은 트리. 기본 모델이 무거운 작업을 수행합니다 |
| **메타 모델에 원시 기능 포함** | 때로는 메타 모델에 원래 기능에 대한 액세스 권한을 부여하는 것도 도움이 됩니다 |

## 투표 및 평균화
### 하드 투표(분류)
| 모델 | 예측 |
|-------|------------|
| 모델 A | 1급 |
| 모델 B | 클래스 0 |
| 모델 C | 1급 |
| **과반수 투표** | **클래스 1** |
### 소프트 투표(분류)
| 모델 | P(클래스0) | P(1급) |
|-------|------------|------------|
| 모델 A | 0.3 | 0.7 |
| 모델 B | 0.6 | 0.4 |
| 모델 C | 0.4 | 0.6 |
| **평균** | **0.43** | **0.57** |
| **예측** | | **클래스 1** |
### 가중 평균
| 모델 | 무게 | 예측 |
|-------|---------|----------|
| 모델 A | 0.5 | 0.8 |
| 모델 B | 0.3 | 0.6 |
| 모델 C | 0.2 | 0.9 |
| **가중평균** | | 0.5×0.8 + 0.3×0.6 + 0.2×0.9 = 0.76 |

## 실무 지침
### 언제 어떤 앙상블을 사용해야 할까요?
| 시나리오 | 권장 방법 |
|------------|------|
| **빠른 기준선; 표 형식 데이터** | 랜덤 포레스트 |
| **최대 정확도; 표 형식 데이터** | XGBoost/LightGBM/CatBoost |
| **시끄러운 데이터** | 배깅(부스팅하면 노이즈가 과적합됩니다) |
| **해석이 필요함** | 단일 모델 또는 기능 중요성이 있는 소규모 앙상블 |
| **다양한 모델 유형** | 스태킹 또는 투표 |
| **온라인 학습** | 스트리밍 앙상블 방법; 적응형 부스팅 |
| **불균형 데이터** | 균형 잡힌 랜덤 포레스트; 비용에 민감한 부스팅 |
### 앙상블 다양성 전략
| 전략 | 설명 |
|----------|-------------|
| **다양한 알고리즘** | 트리 기반, 선형 및 신경 모델 결합 |
| **다양한 기능** | 다양한 기능 하위 집합에 대한 모델 학습 |
| **다양한 데이터 하위 집합** | 자루에 넣기; 서브샘플링 |
| **다양한 하이퍼파라미터** | 다양한 구성의 동일한 알고리즘 |
| **다른 기간** | 다양한 시간대에 따라 훈련 |
---

## 요약
앙상블 방법은 여러 개의 불완전한 모델을 하나의 강력한 예측 변수로 결합하기 때문에 작동합니다. 배깅(랜덤 포레스트)은 부트스트랩 샘플과 평균화에 대해 병렬로 모델을 훈련하여 분산을 줄입니다. 부스팅(XGBoost, LightGBM, CatBoost)은 모델을 순차적으로 훈련하여 각각 이전 오류를 수정함으로써 편향을 줄입니다. 스태킹은 메타 모델을 사용하여 다양한 기본 모델을 결합합니다. 투표와 평균화는 가장 간단한 앙상블입니다. 공통 스레드는 다양성입니다. 앙상블은 구성 요소 모델이 개별적으로 합리적이지만 다른 오류를 범할 때 가장 잘 작동합니다. 실제로 표 형식 데이터에 대한 그래디언트 부스팅은 가장 성능이 좋은 단일 접근 방식인 반면, 다양한 모델을 스택하면 경쟁 및 고부담 애플리케이션에서 정확도가 더욱 향상됩니다.
