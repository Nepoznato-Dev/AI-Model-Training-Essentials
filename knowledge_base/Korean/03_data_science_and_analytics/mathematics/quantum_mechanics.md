# 양자역학
양자 역학은 원자, 전자, 광자 및 자연의 기본 입자와 같은 가장 작은 규모의 물리학 이론입니다. 이는 고전역학의 결정론적 세계를 확률, 중첩, 얽힘으로 대체합니다. 반직관적인 성격에도 불구하고 양자역학은 모든 과학 분야에서 가장 정확하게 검증된 이론입니다. 오늘날 그 원리는 양자 컴퓨터를 통한 컴퓨팅과 직접적인 관련이 있으며, 이는 기존 기계보다 기하급수적으로 빠르게 특정 문제를 해결할 것을 약속합니다.

## 역사적 동기
### 고전 물리학의 실패
| 문제 | 고전적 예측 | 관찰 | 해결 |
|---------|---------|-------------|------------|
| 흑체 방사선 | 자외선 재앙(짧은 λ에서 무한한 에너지) | 유한 피크 파장 | 플랑크: 에너지가 양자화됩니다(E = nhν) |
| 광전 효과 | KE는 빈도가 아닌 강도에 따라 달라집니다 | KE는 주파수에 따라 다름 | 아인슈타인: 빛은 양자화됩니다(광자, E = hν) |

## 파동-입자 이중성
### 드 브로이 파장
운동량 p를 갖는 모든 입자에는 연관된 파장이 있습니다.
λ = h/p = h/(mv)
| 입자 | 일반적인 λ | 관찰 가능한 파동 거동? |
|----------|------------|---------------|
| 전자(100eV) | 0.12nm | 예(결정 회절) |
| 양성자 | 0.003nm | 있음(중성자 산란) |
| 야구(40m/s) | 10⁻³⁴m | 아니요(감지하기에는 너무 작음) |
### 이중 슬릿 실험
전형적인 양자 실험:
1. 두 개의 슬릿에서 입자(전자, 광자)가 하나씩 발사됩니다.
2. 각 입자는 검출기의 단일 지점에 도달합니다.
3. 시간이 지남에 따라 간섭 패턴이 나타납니다. 마치 각 입자가 두 슬릿을 동시에 통과하는 것처럼 보입니다.
4. 입자가 어느 슬릿을 통과하는지 측정하면 간섭무늬가 사라진다
**결론:** 양자 물체는 순수한 입자도 아니고 순수한 파동도 아닙니다. 관찰되지 않을 때는 파동 같은 행동을 보이고, 측정할 때는 입자 같은 행동을 보입니다.

## 파동함수
### 정의
**파동함수** ψ(x, t)는 양자 시스템을 완벽하게 설명합니다. 이는 제곱 계수가 확률 밀도를 제공하는 복소수 함수입니다.
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### 정규화
총 확률은 1과 같아야 합니다.
∫ |ψ(x)|² dx = 1 (전체 공간에 걸쳐)
### 태어난 규칙
x와 x + dx 사이의 입자를 찾을 확률:
P(x ~ x+dx) = |ψ(x)|² dx
고유 상태 Φₙ를 사용하여 일반적으로 관찰할 수 있는 경우:
P(고유값 aₙ 측정) = |⟨ψₙ|ψ⟩|²
---

## 슈뢰딩거 방정식
### 시간 의존적 슈뢰딩거 방정식
나는ℏ ∂ψ/∂t = Ĥψ
여기서 Ĥ는 **해밀턴 연산자**(총 에너지 연산자)입니다.
### 시간에 무관한 슈뢰딩거 방정식
정지 상태(에너지 고유 상태)의 경우:
Ĥψ = Eψ
이것은 고유값 방정식입니다. 허용된 에너지 E는 Ĥ의 고유값입니다.
### 상자 속 입자(무한 정사각형 우물)
가장 간단한 양자 시스템: 0 < x < L에 제한된 입자.
| 수량 | 결과 |
|----------|---------|
| 파동함수 | ψₙ(x) = √(2/L) sin(nπx/L) |
| 에너지 수준 | Eₙ = n²π²ℏ²/(2mL²) = n²h²/(8mL²) |
| 접지 상태 | n = 1, E₁ = h²/(8mL²) |
| 영점 에너지 | E₁ > 0(입자는 완벽하게 정지할 수 없음) |
| 양자수 | n = 1, 2, 3, ... (양의 정수만 해당) |
### 양자 조화 발진기
V(x) = ½mΩ²x²
| 수량 | 결과 |
|----------|---------|
| 에너지 수준 | Eₙ = (n + ½)ℏΩ |
| 영점 에너지 | E₀ = ½ℏΩ |
| 간격 | ΔE = ℏΩ(균일) |
| 파동함수 | 에르미트 다항식 × 가우스 |

## 연산자와 관찰 가능 항목
양자역학에서 모든 물리적으로 관찰 가능한 것은 **에르미트 연산자**에 해당합니다.
### 주요 운영자
| 관찰 가능 | 연산자(위치 공간) | 고유값 |
|------------|-------------|-------------|
| 위치 | x̂ = x | 모든 실제 x |
| 모멘텀 | p̂ = −iℏ ∂/∂x | 모든 실제 p |
| 에너지(해밀턴) | Ĥ = −(ℏ²/2m)∂²/∂x² + V(x) | Eₙ(바운드 상태에 대해 이산) |
| 각운동량 | L̂ = r × p̂ | ℏ√(l(l+1)) |
| 스핀 | Ŝ = (ℏ/2)σ (파울리 행렬) | ±ℏ/2(스핀-½의 경우) |
### 기대값
상태 ψ에서 관찰 가능한 A를 측정한 평균 결과:
⟨A⟩ = ⟨ψ|Â|ψ⟩ = ∫ ψ*(x) Â ψ(x) dx
### 정류 관계
[Â, B̂] = ÂB̂ − B̂Â
| 정류자 | 결과 | 의의 |
|------------|---------|-------------|
| [x̂, p̂] | 나ℏ | 위치와 모멘텀이 호환되지 않습니다 |
| [L̂ₓ, L̂ᵧ] | iℏL̂_z | 각운동량 구성요소가 호환되지 않습니다 |
| [σ̂ₓ, σ̂ᵧ] | 2iσ̂_z | Pauli 행렬(스핀 구성요소) |
[Â, B̂] = 0이면 관측 가능 항목을 동시에 측정할 수 있습니다(고유 상태 공유).

## 불확정성 원리
### 하이젠베르크의 불확정성 원리
Δx · Δp ≥ ℏ/2
보다 일반적으로 두 관측 가능 개체 A와 B에 대해 다음과 같이 설명합니다.
ΔA · ΔB ≥ (1/2)|⟨[Â, B̂]⟩|
### 불확실성 관계
| 쌍 | 관계 | 통역 |
|------|----------|---|
| 포지션 모멘텀 | ΔxΔp ≥ ℏ/2 | 둘 다 정확히 알 수 없음 |
| 에너지 시간 | ΔEΔt ≥ ℏ/2 | 수명이 짧은 주에는 에너지가 불확실합니다 |
| 각운동량 | ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| | 모든 구성요소를 동시에 알 수 없음 |
**중요:** 불확실성은 측정 교란에 관한 것이 아니라 양자 상태의 기본 속성입니다. 입자는 명확한 위치와 운동량을 동시에 갖지 않습니다.

## 양자 상태와 중첩
### 디랙 표기법(Bra-Ket)
| 기호 | 이름 | 의미 |
|---------|------|---------|
| \|ψ⟩ | 케트 | 상태 벡터(열 벡터) |
| ⟨ψ\| | 브래지어 | 켤레 전치(행 벡터) |
| ⟨ψ\|ψ⟩ | 내부제품 | 상태 ψ에서 찾을 ψ의 진폭 |
| \|ψ\|² | 표준 제곱 | 확률 |
### 중첩 원리
\|ψ₁⟩ 및 \|ψ₂⟩가 유효한 양자 상태이면 모든 선형 조합도 유효합니다.
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

여기서 |α|² + |β|² = 1(정규화)입니다.
**측정:** 측정 시 시스템은 확률 |α|²의 경우 \|ψ₁⟩ 또는 확률 |β|²의 경우 \|ψ²⟩로 "붕괴"됩니다.
### 큐비트
**큐비트**는 양자 비트로, 2단계 양자 시스템입니다.
\|ψ⟩ = α\|0⟩ + β\|1⟩, 여기서 |α|² + |β|² = 1
| 대표 | \|0⟩ | \|1⟩ |
|---------------|------|------|
| 스핀 | 스핀업 ↑ | 스핀다운 ↓ |
| 광자 편광 | 수평 | 수직 |
| 에너지 수준 | 접지 상태 | 흥분된 상태 |
| 서킷 | \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**Bloch 구:** 모든 큐비트 상태는 다음과 같이 작성할 수 있습니다.
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iψ} sin(θ/2)\|1⟩
여기서 θ ∈ [0, π] 및 ψ ∈ [0, 2π)입니다. 상태 공간은 구입니다.

## 얽힘
두 개의 큐비트는 결합 상태를 개별 상태의 산물로 쓸 수 없을 때 **얽혀** 있습니다.
### 벨 상태(최대로 얽힘)
| 상태 | 표현 | 이름 |
|-------|------------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) | 벨 상태 |
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) | 벨 상태 |
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) | 벨 상태 |
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) | 단일 상태 |
### 얽힘의 속성
| 부동산 | 설명 |
|----------|-------------|
| 상관관계 | 하나의 큐비트를 측정하면 거리에 관계없이 다른 큐비트가 즉시 결정됩니다 |
| 통신 없음 | 얽힘만으로는 빛보다 빠르게 정보를 보낼 수 없다 |
| 일부일처제 | A가 B와 최대로 얽혀 있으면 C |
| 취약성 | 환경과의 상호작용으로 얽힘(결맞음)이 파괴됩니다 |
### EPR 역설과 벨의 정리
아인슈타인, 포돌스키, 로젠은 양자 역학이 불완전해야 한다고 주장했습니다(숨겨진 변수). Bell은 모든 국소 숨은 변수 이론이 특정 부등식을 만족한다는 것을 보여주었습니다. 실험은 벨 부등식을 위반하여 양자 역학을 확인하고 국지적 숨겨진 변수를 배제합니다.

## 양자 게이트
양자 게이트는 큐비트에 대한 단일 작업입니다.
### 단일 큐비트 게이트
| 게이트 | 매트릭스 | 효과 |
|------|----------|---------|
| **Pauli-X** (아님) | [[0,1],[1,0]] | 비트 뒤집기: \|0⟩ ← \|1⟩ |
| **파울리-Y** | [[0,−i],[i,0]] | 비트 + 위상 반전 |
| **파울리-Z** | [[1,0],[0,−1]] | 위상 반전: \|1⟩ → −\|1⟩ |
| **아다마르** (H) | (1/√2)[[1,1],[1,−1]] | 중첩 생성: \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **단계**(S) | [[1,0],[0,i]] | Z를 중심으로 π/2 회전 |
| **T 게이트** | [[1,0],[0,e^{irπ/4}]] | Z를 중심으로 π/4 회전 |
| **회전** Rₓ(θ) | cos(θ/2)I − i sin(θ/2)σₓ | X축을 기준으로 θ만큼 회전 |
### 2큐비트 게이트
| 게이트 | 설명 | 효과 |
|------|-------------|-------|
| **하지 않음** | 제어되지 않음 | 컨트롤이 \|1⟩ |인 경우 대상을 뒤집습니다.
| **CZ** | 제어-Z | 제어가 \|1⟩ |인 경우 대상에 Z를 적용합니다.
| **스왑** | 큐비트 교환 | \|ab⟩ → \|ba⟩ |
### 얽힘 만들기
큐비트 1에 H를 적용한 다음 큐비트 1을 제어로 사용하여 CNOT를 적용합니다.
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩
