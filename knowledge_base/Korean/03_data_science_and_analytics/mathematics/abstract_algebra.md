# 추상 대수학
추상 대수학은 대수적 구조, 즉 특정 규칙을 따르는 연산을 갖춘 집합을 연구합니다. 숫자로 작업하는 대신 추상 대수학은 공리를 충족하는 모든 객체로 작동합니다. 이 일반성은 강력합니다. "그룹"에 대해 증명된 정리는 정수, 대칭, 행렬, 순열 및 양자 상태에 동시에 적용됩니다. 추상 대수학은 물리학 전반에 걸쳐 사용되는 암호화, 오류 수정 코드, 양자 컴퓨팅 및 대칭 분석을 뒷받침합니다.
---

## 그룹
**그룹**은 가장 기본적인 대수 구조입니다. 대칭의 본질을 포착합니다.
### 정의
**그룹**(G, *)은 다음을 만족하는 이항 연산 *을 갖는 집합 G입니다.
| 공리 | 성명서 | 예(ℤ, +) |
|-------|------------|----|
| **폐쇄** | ∀a,b ∈ G: a * b ∈ G | a + b는 정수입니다 |
| **연관성** | (a * b) * c = a * (b * c) | (a + b) + c = a + (b + c) |
| **신원** | ∃e ∈ G: e * a = a * e = a | 0 + a = a + 0 = a |
| **역** | ∀a ∈ G, ∃a⁻¹: a * a⁻¹ = a⁻¹ * a = e | a + (−a) = 0 |
연산이 **가환적**(a * b = b * a)인 경우 그룹을 **아벨리안**이라고 합니다.
### 그룹의 예
| 그룹 | 설정 | 운영 | 정체성 | 역 | 아벨리안? |
|-------|------|------------|----------|---------|----------|
| (ℤ, +) | 정수 | 추가 | 0 | -a | 예 |
| (ℚ*, ×) | 0이 아닌 합리성 | 곱셈 | 1 | 1/a | 예 |
| (ℤ/nℤ, +) | 잔류물 모드 n | 추가 모드 n | [0] | [해당 없음] | 예 |
| Sₙ | {1,...,n}의 순열 | 구성 | 아이디 | 역순열 | 아니요(n ≥ 3) |
| GL(n, ℝ) | 가역 n×n 행렬 | 행렬 곱셈 | 나는ₙ | A⁻¹ | 아니요(n ≥ 2) |
| (ℝⁿ, +) | n차원 벡터 | 벡터 추가 | 0 | -v | 예 |
### 그룹 및 요소의 순서
| 기간 | 정의 | 예 |
|------|------------|---------|
| **G의 순서** (\|G\|) | G의 요소 수 | \|ℤ/5ℤ\| = 5 |
| **요소 a의 순서** (ord(a)) | aᵏ = e인 최소 양수 k | ord(2) in (ℤ/7ℤ)* = 3 (2³ = 8 ‚ 1이므로) |
| **유한군** | \|지\| 유한하다 | S₃의 주문은 6입니다 |
| **무한그룹** | \|지\| 무한하다 | (ℤ, +) |
### 하위 그룹
G의 **하위군** H는 그 자체가 동일한 연산 하에 있는 그룹인 H ⊆ G의 하위 집합입니다.
**하위군 테스트:** H는 Giff의 하위군입니다.
1. H는 비어 있지 않습니다.
2. 모든 a, b ∈ H에 대해: a * b⁻¹ ∈ H
**예:**
- (ℤ, +)에는 각 n ≥ 0에 대해 하위 그룹 nℤ = {..., −2n, −n, 0, n, 2n, ...}이 있습니다.
- **사소한 하위 그룹** {e} 및 그룹 G 자체는 항상 하위 그룹입니다.
- S₃에서 집합 {id, (12)}는 차수 2의 부분군입니다.
### 코세트와 라그랑주의 정리
G의 부분군 H와 요소 a ∈ G의 경우:
- **왼쪽 코셋:** aH = {ah : h ∈ H}
- **올바른 coset:** Ha = {ha : h ∈ H}
**라그랑주의 정리:** 유한 그룹 G와 부분 그룹 H의 경우:
|H| |G|를 나눈다
**추론:**
- 모든 요소의 순서는 |G|로 나뉩니다.
- 만약 |G| = p(소수)이면 G는 순환입니다(중요한 하위 그룹이 없음).
- a^|G| = 모든 a ∈ G에 대한 e(페르마의 작은 정리를 일반화함)
### 순환 그룹
G의 모든 요소가 g의 거듭제곱인 g ∈ G가 존재하는 경우 그룹 G는 **순환**입니다. G = ⟨g⟩라고 씁니다.
| 부동산 | 성명서 |
|----------|-----------|
| 모든 순환 그룹은 아벨적입니다 | — |
| 덧셈 아래의 ℤ/nℤ은 순환적입니다 | 생성자: [1] |
| (ℤ/pℤ)*는 소수 p에 대해 순환합니다 | 생성기를 기본 루트라고 합니다 |
| 분류 | 모든 유한 순환 그룹은 일부 n |에 대해 ℤ/nℤ과 동형입니다.

## 동형과 동형
**동형사상**은 그룹 간의 구조를 보존하는 지도입니다.
### 정의
| 기간 | 정의 | 예 |
|------|------------|---------|
| **동형** | Ø: G → H 여기서 Ø(ab) = Ø(a)Ø(b) | det: GL(n,ℝ) → ℝ* |
| **동형** | 전단사 동형(그룹은 "동일") | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **커널** | 커(Φ) = {g ∈ G : Φ(g) = e_H} | 커(det) = SL(n, ℝ) |
| **이미지** | im(Φ) = {Φ(g) : g ∈ G} | 메신저(det) = ℝ* |
### 첫 번째 동형성 정리
Φ: G → H가 동형이면:
G / 커(Φ) ≅ im(Φ)
이것은 대수학에서 가장 중요한 정리 중 하나입니다. 모든 동형은 동형이 뒤따르는 몫으로 분해된다는 뜻입니다.

## 반지
**링**은 그룹에 두 번째 연산을 추가하여 덧셈과 곱셈을 모두 사용하여 산술을 모델링합니다.
### 정의
**링**(R, +, ×)은 다음을 충족하는 두 가지 연산을 갖는 집합 R입니다.
| 공리 | 성명서 |
|-------|------------|
| (R, +)는 아벨 그룹입니다 | 덧셈은 교환적이고 결합적이며 항등성이 0이고 모든 요소에는 덧셈의 역원이 있습니다 |
| 곱셈은 ​​연관적이다 | (a × b) × c = a × (b × c) |
| 분배법칙 | a(b + c) = ab + ac 및 (a + b)c = ac + bc |
곱셈도 교환 가능하고 항등식(1)을 갖는 경우 R은 **단위가 있는 교환 가능한 고리**입니다.
### 반지의 예
| 반지 | 설명 | 교환 가능한가? | 1개 있나요? |
|------|-------------|-------------|--------|
| (ℤ, +, ×) | 정수 | 예 | 예 |
| (ℚ, +, ×) | 합리성 | 예 | 예 |
| (ℝ, +, ×) | 실수 | 예 | 예 |
| (ℤ/nℤ, +, ×) | 정수 mod n | 예 | 예 |
| Mₙ(ℝ) | n×n 실수 행렬 | 아니요(n ≥ 2) | 예 |
| ℝ[x] | 실수 계수를 갖는 다항식 | 예 | 예 |
### 이상과 몫 고리
링 R의 **이상적인** I는 다음과 같은 부분 집합입니다.
1. 추가 중인 하위 그룹입니다.
2. 곱셈을 흡수합니다. 모든 r ∈ R 및 a ∈ I에 대해 ra ∈ I 및 ar ∈ I 모두
**몫 고리** R/I: 요소는 R에서 상속된 작업을 포함하는 I의 coset입니다.
**예:** ℤ/nℤ = ℤ/nℤ은 이상적인 nℤ에 의한 ℤ의 몫입니다.
### 필수 도메인 및 필드
| 구조 | 정의 | 예 |
|------------|------------|----------|
| **통합 도메인** | 1이 있고 영 제수가 없는 교환 링(ab = 0 → a = 0 또는 b = 0) | ℤ, ℚ[x], ℝ[x] |
| **필드** | 0이 아닌 모든 요소가 곱셈의 역원을 갖는 교환 링 | ℚ, ℝ, ℂ, ℤ/pℤ (p 프라임) |

## 필드
필드는 일반적으로 사용되는 가장 구조화된 대수 객체입니다. 0이 아닌 모든 요소는 더하기, 빼기, 곱하기, 나누기가 가능합니다.
### 주요 속성
| 부동산 | 성명서 |
|----------|-----------|
| 모든 필드는 필수 도메인입니다 | — |
| 모든 유한 적분 영역은 필드입니다 | — |
| 특징 | n·1 = 0인 가장 작은 n, 또는 그러한 n이 존재하지 않는 경우 0 |
| char(ℚ) = char(ℝ) = char(ℂ) | = 0 |
| 문자(ℤ/pℤ) | = p(소수 p의 경우) |
### 유한 필드(갈루아 필드)
모든 소수 거듭제곱 pᵏ에 대해 GF(pᵏ) 또는 𝔽_{pᵏ}로 표시되는 고유한(동형까지) 유한 차수 pᵏ 필드가 존재합니다.
| 필드 | 사이즈 | 건설 | 신청 |
|---------|------|-------------|-------------|
| GF(2) | 2 | {0, 1} 모드 2 | 이진 산술, XOR |
| GF(2ᵏ) | 2ᵏ | GF(2)에 대한 다항식 mod irreducible 폴리 | AES 암호화, CRC 코드 |
| GF(p) | 피 | 소수 p의 경우 ℤ/pℤ | 모듈러 연산, 코딩 이론 |
| GF(pᵏ) | 피 | 확장 필드 | 리드 솔로몬 코드, 타원 곡선 |
**GF(2⁸)의 구성**(AES에 사용됨):
- GF(2) = {0, 1}로 시작
- GF(2) 대신 기약 다항식 p(x) = x⁸ + x⁴ + x³ + x + 1을 선택합니다.
- 요소는 GF(2)의 계수를 갖는 8차 미만의 다항식입니다.
- 산술: 다항식 덧셈(XOR) 및 곱셈 mod p(x)

## 벡터 공간
**벡터 공간**은 추가 및 크기 조정이 가능한 벡터 집합으로, 선형 대수학의 기초를 형성합니다.
### 정의
필드 F 위의 **벡터 공간** V는 다음을 포함하는 집합입니다.
- 벡터 추가: V × V → V(V를 아벨 그룹으로 만들기)
- 스칼라 곱셈: F × V → V
만족: 결합성, 덧셈의 교환성, 스칼라 곱셈의 분포성 및 1·v = v.
### 주요 개념
| 개념 | 정의 | 예 |
|---------|------------|---------|
| **기준** | 선형 독립 스패닝 세트 | Fⁿ에 대한 {e₁, e₂, ..., eₙ} |
| **차원** | 모든 기준의 벡터 수 | 어두움(ℝ³) = 3 |
| **부분공간** | 덧셈과 스칼라 곱셈에 따라 닫힌 부분 집합 | ℝ³의 원점을 통과하는 비행기 |
| **선형조합** | Σ cᵢvᵢ 여기서 cᵢ ∈ F | 3v₁ + 2v2 − v₃ |
| **스팬** | 모든 선형 조합의 집합 | Span({v₁, v2}) = 평면인 경우 v₁, v2는 독립 |
| **선형독립** | 어떤 벡터도 다른 벡터의 선형 조합이 아닙니다 | e₁, e₂, e₃ in ℝ³ |
### 중요한 벡터 공간
| 공간 | 설명 | 차원 |
|-------|-------------|----------|
| Fⁿ | 필드 F에 대한 n-튜플 | 엔 |
| Pₙ(F) | 차수 ≤ n의 다항식 | n + 1 |
| 남ₘₓₙ(여) | F에 대한 m × n 행렬 | 백만 |
| C[a,b] | [a,b]의 연속 함수 | 무한 |
| L²(ℝ) | 제곱 적분 가능 기능 | 무한(힐베르트 공간) |

## 선형 지도와 고유 이론
### 선형 지도
A **선형 맵**(선형 변환) T: V → W는 다음을 충족합니다.
- T(u + v) = T(u) + T(v)
- 모든 스칼라 c에 대해 T(cv) = cT(v)
| 개념 | 정의 | 예 |
|---------|------------|---------|
| **커널** | {v ∈ V : T(v) = 0} | 행렬의 영공간 |
| **이미지** | {T(v) : v ∈ V} | 행렬의 열 공간 |
| **순위-무효 정리** | 희미한(커 T) + 희미한(im T) = 희미한(V) | 기본적 제약 |
| **행렬 표현** | T(v) = 일부 행렬 A에 대한 Av | 유한차원 공간 사이의 모든 선형 지도 |
### 고유값과 고유벡터
선형 맵 T의 경우: V → V(또는 행렬 A):
**고유값 방정식:** Av = λv, 여기서 v ≠ 0
| 기간 | 정의 |
|------|------------|
| **고유값** λ | 일부 v ≠ 0 |
| **고유벡터** v | Av = λv를 만족하는 0이 아닌 벡터 |
| **특성 다항식** | det(A − λI) = 0 |
| **고유공간** | {v : Av = λv} — λ(더하기 0) |
| **스펙트럼** | 모든 고유값 세트 |
### 고유값 계산하기
2×2 행렬 A = [[a, b], [c, d]]의 경우:
- 특성 다항식: λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2
**주요 속성:**
- 고유값의 합 = Trace(A) = 대각선 요소의 합
- 고유값의 곱 = det(A)
### 대각선화
행렬 A는 n개의 선형 독립 고유 벡터(여기서 A는 n×n)를 갖는 경우 **대각선화가 가능**합니다.
A = PDP⁻1인 경우(여기서 D는 대각선임):
- Aᵏ = PDᵏP⁻¹(빠른 행렬 지수화)
- D는 대각선에 고유값을 포함합니다.
- P는 고유벡터를 열로 포함합니다.
**스펙트럼 정리:** 모든 실제 대칭 행렬은 직교 행렬에 의해 대각화가 가능합니다. 고유값은 실수입니다.

## 애플리케이션
### 코딩 이론(오류 수정 코드)
유한 필드는 현대 오류 수정 코드의 기초입니다.
| 코드 | 필드 | 수정 | 신청 |
|------|---------|----------|-------------|
| 해밍 코드 | GF(2) | 블록당 오류 1개 | RAM ECC, 초기 네트워킹 |
| 리드 솔로몬 | GF(2ᵏ) | 여러 오류 | CD, DVD, QR 코드, 위성통신 |
| BCH 코드 | GF(2ᵏ) | 여러 오류 | 플래시 메모리, 위성 |
| LDPC 코드 | GF(2) | 여러 오류 | Wi-Fi(802.11n), DVB-S2, 5G |
**리드 솔로몬 인코딩:** 데이터를 GF(2ᵏ)에 대한 다항식으로 처리하고 여러 지점에서 평가합니다. 일부 평가가 손상되더라도 원래 다항식을 복구할 수 있습니다.
### 양자 컴퓨팅
양자 상태는 복잡한 벡터 공간(힐베르트 공간)에 존재합니다. 양자 게이트는 단일 행렬입니다.
| 양자 개념 | 대수적 구조 |
|---|------|
| 큐비트 | ℂ² 단위 벡터(복소수 2D 벡터 공간) |
| 양자 게이트 | 유니터리 행렬 U ∈ U(2ⁿ) |
| 측정 | 투영 연산자 |
| 얽힘 | 분리 불가능한 텐서 제품 상태 |
| 복제 금지 정리 | 어떤 선형 지도도 알 수 없는 양자 상태를 복사할 수 없습니다 |
**단일 큐비트 게이트:**
| 게이트 | 매트릭스 | 효과 |
|------|----------|---------|

## 요약
| 구조 | 운영 | 주요 속성 | 예 |
|------------|------------|---------------|---------|
| 그룹 | 1개(*) | 폐쇄, 연관성, 동일성, 역 | (ℤ, +), Sₙ |
| 반지 | 2개(+, ×) | + 아래의 아벨 그룹, × 아래의 모노이드, 분배 | ℤ, ℤ/nℤ, Mₙ(ℝ) |
| 필드 | 2개(+, ×) | 0이 아닌 요소가 × 아래 그룹을 형성하는 링 | ℚ, ℝ, ℂ, GF(p) |
| 벡터 공간 | 스칼라 곱셈 + 덧셈 | 필드 위의 모듈 | ℝⁿ, Pₙ(F), 기능 공간 |
추상 대수학은 구조 자체에 대한 언어를 제공합니다. 그룹은 대칭을 캡처하고, 링은 산술을 캡처하고, 필드는 분할을 캡처하고, 벡터 공간은 선형성을 캡처합니다. 이러한 구조는 그 자체로는 추상적이지 않습니다. 데이터를 보호하는 모든 오류 수정 코드, 통신을 보호하는 모든 암호화 프로토콜, 언젠가 컴퓨팅을 변화시킬 수 있는 모든 양자 알고리즘, 신경망을 통해 실행되는 모든 선형 변환에 나타납니다.
