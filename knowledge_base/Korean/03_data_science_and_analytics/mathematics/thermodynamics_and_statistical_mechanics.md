# 열역학과 통계역학
열역학은 원자가 어떻게 생겼는지 알지 못한 채 온도, 압력, 엔트로피 측면에서 시스템의 거시적 동작을 설명합니다. 통계역학은 열역학을 아래에서 위로 설명합니다. 즉, 수많은 입자의 미세한 거동에서 거시적인 특성을 도출합니다. 이를 통해 정보 이론, 기계 학습 및 그 이상으로 이동한 개념인 에너지, 엔트로피 및 평형에 대한 가장 깊은 이해를 제공합니다.
---

## 열역학적 변수 및 상태
### 상태 변수
| 변수 | 유형 | 단위 | 설명 |
|------------|------|------|-------------|
| 온도(T) | 집중 | 켈빈(K) | 입자당 평균 운동 에너지 |
| 압력(P) | 집중 | 파스칼(Pa) | 단위 면적당 힘 |
| 볼륨(V) | 광범위한 | m² | 점유 공간 |
| 내부에너지(U) | 광범위한 | 줄(J) | 총 미세 에너지 |
| 엔트로피(S) | 광범위한 | J/K | 장애/미세상태 측정 |
| 입자수(N) | 광범위한 | 두더지 또는 개수 | 물질의 양 |
**집중** 변수는 시스템 크기에 의존하지 않습니다. **광범위한** 변수가 그렇습니다.
### 상태 방정식
이상기체의 경우: PV = nRT = Nk_BT
| 상수 | 가치 |
|----------|-------|
| R(가스 상수) | 8.314J/(mol·K) |
| k_B(볼츠만 상수) | 1.381 × 10⁻²³ J/K |
| N_A (아보가드로 수) | 6.022 × 10²³ /mol |

## 열역학 법칙
### 제0법칙
A가 B와 열평형을 이루고 B가 C와 열평형을 이루고 있다면 A는 C와 열평형을 이루고 있습니다.
**의미:** 온도는 잘 정의되어 있고 측정 가능합니다.
### 제1법칙(에너지 보존)
ΔU = Q - W
| 기호 | 의미 |
|---------|---------|
| ΔU | 내부에너지 변화 |
| 질문 | 시스템에 열이 추가됨 |
| 여 | 시스템에 의해 수행된 작업 |
**미분 형식:** dU = δQ − δW = δQ − PdV
| 프로세스 | 제약 | 결과 |
|---------|------------|------------|
| 등가성 | dV = 0 | W = 0, ΔU = Q |
| 등압 | dP = 0 | W = PΔV |
| 등온 | dT = 0 | ΔU = 0(이상기체), Q = W |
| 단열 | δQ = 0 | ΔU = -W |
### 제2법칙(엔트로피)
**클라우스 진술:** 열은 자발적으로 차가운 곳에서 뜨거운 곳으로 흐를 수 없습니다.
**켈빈-플랑크 진술:** 모든 열을 일로 변환할 수 있는 엔진은 없습니다.
**엔트로피 설명:** 모든 프로세스에 대해: ΔS_universe ≥ 0
| 프로세스 유형 | ΔS_유니버스 |
|-------------|-------------|
| 리버시블 | = 0 |
| 되돌릴 수 없음(실제) | > 0 |
**엔트로피 변화:** dS = δQ_rev / T
### 제3법칙
T → 0 K에 따라 완벽한 결정의 엔트로피는 0에 가까워집니다. lim_{T→0} S = 0
**의미:** 유한한 단계에서는 절대 영점에 도달할 수 없습니다.

## 심층 엔트로피
### 열역학적 엔트로피
S는 상태 함수입니다. 상태 A와 B 사이의 가역적 프로세스의 경우:
ΔS = ∫_A^B δQ_rev / T
**실시예:** 일정한 압력에서 물을 T₁에서 T2로 가열할 때 엔트로피 변화.
ΔS = ∫_{T₁}^{T²} (mc_p/T) dT = mc_p ln(T²/T₁)
### 통계적 엔트로피(볼츠만)
S = k_B lnΩ
여기서 Ω은 거시상태와 일치하는 미시상태의 수이다.
| 매크로스테이트 | 미시상태(Ω) | 엔트로피 |
|------------|----|---------|
| 상자 절반에 모든 가스 | 작은 | 낮음 |
| 가스가 고르게 분포됨 | 매우 큰 | 높음 |
| 0K에서 완벽한 결정 | 1 | 0 |
**연결:** 두 번째 법칙은 통계가 됩니다. 즉, 시스템은 압도적으로 가능성이 높기 때문에 더 많은 미시 상태가 있는 거시 상태로 진화합니다.

## 엔탈피와 자유 에너지
### 엔탈피
H = U + PV
일정한 압력을 받는 공정에 유용합니다(대부분의 화학 및 생물학).
ΔH = Q_p(일정한 압력에서의 열)
### 헬름홀츠 자유에너지
F = U - TS
| 부동산 | 성명서 |
|----------|-----------|
| 의미 | 일정한 T, V에서 추출 가능한 최대 일 |
| 평형 | 시스템은 일정한 T, V에서 F를 최소화합니다 |
| 파티션 기능과의 관계 | F = -k_BT ln Z |
### 깁스 프리 에너지
G = H − TS = U + PV − TS
| 부동산 | 성명서 |
|----------|-----------|
| 의미 | 일정한 T, P에서 최대 비팽창 작업 |
| 평형 | 시스템은 일정한 T, P에서 G를 최소화합니다 |
| 자발성 | ΔG < 0 → 자발적; ΔG = 0 → 평형 |
| 화학 반응 | ΔG = ΔH − TΔS는 방향을 결정합니다 |
### 열역학적 잠재력 요약
| 잠재력 | 자연변수 | 차동 | 최소화되는 경우 |
|------------|------|------------|---|
| U(내부에너지) | 에스, 브이 | dU = TdS − PdV | 고립된 시스템 |
| H(엔탈피) | S, P | dH = TdS + VdP | 상수 P, 단열 |
| F (헬름홀츠) | 티,브이 | dF = -SdT - PdV | 상수 T, V |
| G (깁스) | 티, 피 | dG = -SdT + VdP | 상수 T, P |

## 카르노 사이클
**카르노 사이클**은 T_H(더운) 온도와 T_C(차가운) 온도 사이에서 작동하는 가장 효율적인 열 엔진입니다.
### 4단계
| 무대 | 프로세스 | 무슨 일이 일어나는지 |
|---------|---------|-------------|
| 1 → 2 | 등온 팽창 | T_H의 뜨거운 저장소에서 열 Q_H를 흡수 |
| 2 → 3 | 단열팽창 | 가스가 T_H에서 T_C로 냉각됨 |
| 3 → 4 | 등온 압축 | 열 Q_C를 T_C의 저온 저장소로 거부 |
| 4 → 1 | 단열 압축 | T_C에서 T_H까지 가스 가열 |
### 카르노 효율
eta_Carnot = 1 − T_C/T_H
| T_H | T_C | eta_카르노 |
|------|-------|----------|
| 500K | 300K | 40% |
| 1000K | 300K | 70% |
| 300K | 299K | 0.33% |
**실제 엔진은 카르노 효율을 초과할 수 없습니다.** 실제 엔진은 항상 되돌릴 수 없습니다(마찰, 난기류, 유한한 온도 차이).

## 통계 역학
### 볼츠만 분포
온도 T에서 열 평형 상태에 있는 시스템의 경우 에너지 E_i를 갖는 미시 상태에 있을 확률은 다음과 같습니다.
P(E_i) = (1/Z) e^{−E_i / k_BT}
여기서 Z는 **파티션 함수**입니다.
Z = Σᵢ e^{−E_i / k_BT}
### 파티션 기능
Z는 시스템에 대한 모든 열역학적 정보를 인코딩합니다.
| 수량 | 공식 |
|------------|---------|
| 헬름홀츠 자유 에너지 | F = -k_BT ln Z |
| 평균 에너지 | ⟨E⟩ = −∂(ln Z)/∂β 여기서 β = 1/(k_BT) |
| 엔트로피 | S = k_B(ln Z + β⟨E⟩) |
| 열용량 | C_V = ∂⟨E⟩/∂T = k_Bβ²(⟨E²⟩ − ⟨E⟩²) |
| 압력 | P = (1/β) ∂(ln Z)/∂V |
### 실제 예: 2상태 시스템
입자는 상태 0(에너지 0) 또는 상태 1(에너지 ε)에 있을 수 있습니다.
Z = 1 + e^{−βε}
| 수량 | 결과 |
|----------|---------|
| P(상태 0) | 1/(1 + e^{−βε}) |
| P(상태 1) | e^{−βε}/(1 + e^{−βε}) |
| ⟨E⟩ | ε/(1 + e^{βε}) |
| 높은 T 한계(β→0) | ⟨E⟩ → ε/2 (동일 확률) |
| 낮은 T 한계(β→무한) | ⟨E⟩ → 0(바닥 상태) |
### 등분할 정리
각 2차 자유도는 평균 에너지에 ½k_BT를 기여합니다.
| 시스템 | 자유도 | ⟨E⟩ |
|---------|------|------|
| 단원자 가스(He) | 3 번역 | (3/2)k_BT |
| T실의 이원자 가스(N2) | 트랜스 3개 + 부패 2개 | (5/2)k_BT |
| 높은 T에서의 이원자 가스 | 트랜스 3개 + 부패 2개 + 진동 1개 | (7/2)k_BT |
| 솔리드(아인슈타인 모델) | 3개의 진동(원자당) | 3k_BT |

## 정보 이론과의 연결
### 섀넌 엔트로피와 열역학적 엔트로피
| 측면 | 섀넌 엔트로피 H(X) | 열역학적 엔트로피 S |
|---------|---------|----------|
| 정의 | −Σ pᵢ 로그 pᵢ | k_B ln Ω(또는 −k_B Σ pᵢ ln pᵢ) |
| 최대 | 균일한 분포 | 열평형 |
| 대책 | 불확실성/정보 내용 | 접근 가능한 미세상태의 수 |
| 단위 | 비트 또는 NAT | J/K |
**깁스 엔트로피 공식:** S = −k_B Σᵢ pᵢ ln pᵢ (섀넌 엔트로피와 형태가 동일)
### 최대 엔트로피 원리
두 필드 모두 동일한 원칙을 사용합니다. 즉, 지식 상태를 가장 잘 나타내는 분포는 알려진 제약 조건에 따라 엔트로피를 최대화하는 분포입니다.
| 제약 | 결과 분포 |
|------------|---------|
| 알려진 평균 | 지수분포 |
| 알려진 평균과 분산 | 가우스 분포 |
| 알려진 에너지 ⟨E⟩ | 볼츠만 분포 |
| 제약 없음 | 균일한 분포 |
### 란다우어의 원리
정보 1비트를 삭제하면 최소한 k_BT ln 2의 에너지가 열로 소산됩니다. 이는 정보 처리를 열역학에 직접 연결합니다. 계산에는 근본적인 에너지 비용이 있습니다.

## 요약
| 법칙/개념 | 핵심 아이디어 | 공식 |
|------------|------------|---------|
| 제0법칙 | 온도가 잘 정의되어 있습니다 | 열평형의 전이성 |
| 첫 번째 법칙 | 에너지가 보존됩니다 | ΔU = Q − W |
| 두 번째 법칙 | 우주의 엔트로피 증가 | ΔS ≥ 0 |
| 제3법칙 | 절대 영점은 달성할 수 없습니다 | S → 0 T → 0 |
| 볼츠만 엔트로피 | 엔트로피는 미세 상태를 계산합니다 | S = k_B ln Ω |
| 볼츠만 분포 | 에너지 상태의 확률 | P ∝ e^{−E/k_BT} |
| 파티션 기능 | 모든 열역학적 정보를 인코딩 | Z = Σ e^{−E_i/k_BT} |
| 자유 에너지 | 유용한 작업 가능 | F = U − TS, G = H − TS |
| 카르노 효율성 | 최대 열 엔진 효율 | θ = 1 - T_C/T_H |
열역학과 통계 역학은 물리학이 정보 이론을 만나는 곳입니다. 열 엔진을 제어하는 ​​것과 동일한 엔트로피가 데이터 압축을 제어합니다. 가스 분자를 설명하는 동일한 볼츠만 분포는 모든 분류기의 소프트맥스 레이어를 강화합니다. 이러한 연결을 이해하면 물리학, 확률 및 기계 학습에 대한 통합된 관점을 얻을 수 있습니다.
