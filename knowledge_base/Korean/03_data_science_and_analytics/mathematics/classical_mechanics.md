# 고전역학
고전 역학은 힘의 영향을 받는 물체의 운동을 설명합니다. 떨어지는 사과부터 궤도를 도는 행성까지, 진동하는 끈부터 충돌하는 입자까지, 그 원리는 거시적 세계를 지배합니다. 물리적 응용 외에도 고전 역학은 변분학, 대칭 기하학, 양자 역학과 현대 최적화를 뒷받침하는 해밀턴 프레임워크를 탄생시켰습니다.
---

## 뉴턴역학
### 뉴턴의 세 가지 법칙
| 법률 | 성명서 | 수학적 형태 |
|------|------------|------|
| **첫 번째(관성)** | 힘이 가해지지 않는 한 물체는 정지 상태 또는 등속 운동 상태를 유지합니다 | F_net = 0이면 v = 상수 |
| **두 번째(F = ma)** | 힘은 질량 곱하기 가속도와 같습니다 | **F** = m**a** = m(d²**x**/dt²) |
| **세 번째(작용-반응)** | 모든 행동에는 동등하고 반대되는 반응이 있습니다 | **F**₁₂ = −**F**₂₁ |
### 자유물체 도표
**자유물체도**는 물체를 분리하고 물체에 작용하는 모든 힘을 보여줍니다.
**공통군:**
| 힘 | 공식 | 방향 |
|-------|---------|----------|
| 중력(지구 근처) | F = mg | 하향 |
| 수직력 | 엔 | 표면에 수직 |
| 마찰(정적) | f_s ≤ μ_s N | 임박한 동의에 반대 |
| 마찰(운동) | f_k = μ_k N | 모션 반대 |
| 스프링(훅의 법칙) | F = -kx | 회복(균형을 향해) |
| 긴장 | 티 | 끈/로프를 따라 |
| 드래그 | F_d = ½C_d ρAv² | 속도 반대 |
### 작업 예: 경사면 블록
각도 θ로 마찰이 없는 경사면에 질량이 m인 블록이 있습니다.
- 힘: 중력(mg 아래로), 수직력(표면에 수직인 N)
- 중력 분해: mg sin θ(경사면을 따라), mg cos θ(표면으로)
- N = mg cos θ(표면에 수직인 움직임 없음)
- 경사에 따른 가속도: a = g sin θ

## 에너지 방법
### 일과 운동에너지
**일**은 힘에 의해 수행됨: W = ∫ **F** · d**r**
**일-에너지 정리:** W_net = ΔKE = ½mv²² − ½mv₁²
### 잠재적 에너지
| 힘 | 잠재적 에너지 | 메모 |
|-------|------|-------|
| 중력(표면 근처) | U = mgh | h = 기준 위 높이 |
| 중력(일반) | U = -GMm/r | 무한대에서 0 |
| 봄 | U = ½kx² | x = 평형으로부터의 변위 |
| 정전기 | U = kq₁q²/r | 좋아요 요금: 긍정적인 U |
### 에너지 절약
보존력만 작용하는 경우: E = KE + PE = 일정함
½mv₁² + U₁ = ½mv²² + U²
**실행된 예:** 높이 h에서 공이 떨어졌습니다.
- 초기 : KE = 0, PE = mgh
- 착지 직전: KE = ½mv², PE = 0
- 보존: mgh = ½mv² → v = √(2gh)
### 힘
P = dW/dt = **F** · **v** (일을 하는 속도)

## 모멘텀과 충돌
### 선형 모멘텀
**p** = m**v**
뉴턴의 제2법칙(대체 형식): **F** = d**p**/dt
### 운동량 보존
외부 힘이 없으면 전체 운동량은 보존됩니다.
| 충돌 유형 | KE 보존? | 모멘텀 보존? |
|---------------|---------------|-------|
| **탄력적** | 예 | 예 |
| **비탄력적** | 아니요 | 예 |
| **완전히 비탄력적** | 아니요(최대 손실) | 예(객체가 서로 붙어 있음) |
**1D 탄성 충돌:** 두 개의 질량 m₁, m²와 초기 속도 u₁, u₂:
- v₁ = ((m₁−m²)u₁ + 2m²u²) / (m₁+m²)
- v² = ((m²−m₁)u² + 2m₁u₁) / (m₁+m²)
### 각운동량
**L** = **r** × **p** = m(**r** × **v**)
토크: **τ** = d**L**/dt = **r** × **F**
**보존:** 외부 토크가 없으면 각운동량은 보존됩니다.

## 라그랑주 역학
**라그랑지안** 공식은 힘을 에너지로 대체하여 보다 우아하고 일반적인 프레임워크를 제공합니다.
### 라그랑지안
L = T − V (운동 에너지 - 위치 에너지)
### 최소작용의 원리(해밀턴의 원리)
시간 t₁와 t₂ 사이에 시스템이 취한 실제 경로는 **작업**을 최소화합니다(보다 정확하게는 고정 상태로 만듭니다).
S = ∫_{t₁}^{t²} L(q, q̇, t) dt
### 오일러-라그랑주 방정식
조건 δS = 0은 다음을 산출합니다:
d/dt(∂L/∂q̇) − ∂L/∂q = 0
각 일반화된 좌표 q에 대해.
**작업 예:** 단순 진자(길이 l, 질량 m, 수직으로부터 각도 θ).
- T = ½ml²θ̇²
- V = -mgl cos θ
- L = ½ml²θ̇² + mgl cos θ
- ∂L/∂θ = −mgl 죄 θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̈
- 오일러-라그랑주: ml²θ̈ + mgl sin θ = 0 → θ̈ + (g/l) sin θ = 0
### 라그랑주 역학의 장점
| 장점 | 설명 |
|------------|-------------|
| 좌표 독립 | 모든 좌표계에서 작동 |
| 제약 조건을 자연스럽게 처리 | 구속력을 계산할 필요가 없습니다 |
| 대칭 → 보존 | Noether의 정리는 대칭을 보존량과 연결합니다 |
| 쉽게 일반화 | 장, 상대성 이론, 양자역학 |

## 해밀턴 역학
**해밀턴** 공식은 (위치와 속도 대신) 위치와 운동량을 사용하는 라그랑주 역학의 재구성입니다.
### 해밀턴
H = Σᵢ pᵢq̇ᵢ − L = T + V(대부분의 기계 시스템의 경우)
여기서 pᵢ = ∂L/∂q̇ᵢ는 **일반화된 모멘타**입니다.
### 해밀턴 방정식
q̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
이는 2n개의 1차 ODE입니다(n개의 2차 오일러-라그랑주 방정식 대비).
**작업 예:** 고조파 발진기(질량 m, 스프링 상수 k).
- H = p²/(2m) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ (예상대로)
- ṗ = −∂H/∂x = −kx → mẍ = −kx (훅의 법칙)
### 포아송 괄호
함수 f(q, p) 및 g(q, p)의 경우:
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
| 부동산 | 성명서 |
|----------|-----------|
| 시간의 진화 | df/dt = {f, H} + ∂f/∂t |
| 보존 | f는 {f, H} = 0(및 ∂f/∂t = 0)인 경우 보존됩니다.
| 기본 괄호 | {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**양자 역학에 대한 연결:** 포아송 괄호는 정류자가 됩니다: {f, g} → (1/iℏ)[f̂, ĝ]

## 보존법칙과 뇌터의 정리
### 뇌터의 정리
라그랑지안의 모든 연속 대칭은 보존된 양에 해당합니다.
| 대칭 | 보존량 |
|------------|------|
| 시간 변환 불변 | 에너지 |
| 공간 이동 불변성 | 선형 운동량 |
| 회전 불변 | 각운동량 |
| 게이지 불변성 | 전기요금 |
이것은 모든 물리학에서 가장 심오한 결과 중 하나입니다. 이는 시공간의 기하학을 기본 보존 법칙과 연결합니다.
---

## 강체 역학
**강체**는 모든 내부 거리가 고정되어 있는 객체입니다.
### 주요 개념
| 개념 | 공식 | 설명 |
|---------|---------|-------------|
| **관성 모멘트** | I = Σmᵢrᵢ² 또는 I = ∫r² dm | 회전 가속도에 대한 저항 |
| **회전식 KE** | KE = ½IΩ² | 회전 에너지 |
| **각운동량** | L = IΩ | p = mv의 회전 아날로그 |
| **토크** | τ = Iα | F = ma의 회전 아날로그 |
### 관성 모멘트(일반적인 모양)
| 모양 | 축 | 나는 |
|-------|------|---|
| 솔리드 구 | 센터를 통해 | (2/5)MR² |
| 중공 구 | 센터를 통해 | (2/3)MR² |
| 솔리드 실린더 | 축을 따라 | (1/2)MR² |
| 얇은 막대 | 중심을 통과하여 수직 | (1/12)ML² |
| 얇은 막대 | 끝을 통해, 수직 | (1/3)ML² |
| 디스크 | 중심을 통과하여 수직 | (1/2)MR² |

## 궤도 역학
### 케플러의 법칙
| 법률 | 성명서 |
|------|------------|
| **첫 번째(줄임표)** | 행성은 태양을 한 초점으로 하는 타원 형태로 움직입니다.
| **두 번째(동일 영역)** | 태양에서 행성까지의 선은 같은 시간에 같은 면적을 쓸어버립니다 |
| **3차(고조파)** | T² ∝ a³(장반경 세제곱에 비례하는 주기 제곱) |
### 궤도 에너지
E = ½mv² - GMm/r
| 전자 | 궤도 유형 |
|---|------------|
| E< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 | 쌍곡선(언바운드) |
### 탈출 속도
v_escape = √(2GM/R)
지구의 경우: v_escape ≒ 11.2km/s

## 요약
| 프레임워크 | 핵심 방정식 | 힘 |
|------------|---------------|----------|
| 뉴턴식 | **F** = ㅋㅋㅋ** | 직관적이고 직접적인 힘 분석 |
| 라그랑지안 | d/dt(∂L/∂q̇) − ∂L/∂q = 0 | 좌표가 없고 제약 조건을 처리합니다. |
| 해밀턴 | q̇ = ∂H/∂p, ṗ = −∂H/∂q | Symlectic 구조, QM에 연결 |
| 보존법 | 뇌터의 정리 | 깊은 대칭 보존 연결 |
고전 역학은 떨어지는 공과 흔들리는 진자에만 국한되지 않습니다. 수학적 프레임워크인 라그랑주 역학과 해밀턴 역학은 모든 과학 분야에서 가장 영향력 있는 아이디어 중 하나입니다. 그들은 에너지 기반 모델과 물리학 기반 신경망이 이러한 수백 년 된 공식을 직접 활용하는 양자 역학, 장 ​​이론, 심지어 현대 기계 학습까지 일반화합니다.
