# 게임이론
게임 이론은 전략적 상호 작용의 수학입니다. 즉, 결과가 자신의 선택뿐만 아니라 다른 사람의 선택에도 좌우되는 상황입니다. 기업 간의 가격 전쟁부터 핵무기 경쟁까지, 온라인 경매부터 진화생물학까지, 게임 이론은 갈등과 협력을 분석하는 도구를 제공합니다. 다중 에이전트 강화 학습, 생성적 적대 네트워크(GAN) 및 온라인 플랫폼을 위한 메커니즘 설계를 통해 기계 학습과의 관련성이 점점 높아지고 있습니다.
---

## 전략형 게임
### 정의
**전략적 형식(일반 형식) 게임**은 다음으로 구성됩니다.
- 플레이어 세트 N = {1, 2, ..., n}
- 각 플레이어에 대한 전략 세트 S₁, S2, ..., Sₙ
- 보상 기능 u₁, u₂, ..., uₙ는 전략 프로필을 실수로 매핑합니다.
### 예: 죄수의 딜레마
| | 협력(C) | 결함(D) |
|---|---------------|------------|
| **협력(C)** | (−1, −1) | (−3, 0) |
| **결함(D)** | (0, -3) | (−2, −2) |
| 분석 | 결과 |
|----------|---------|
| 지배적 전략 | 결함(두 선수 모두 D가 C를 압도함) |
| 내쉬 균형 | 보수가 있는 (D, D) (−2, −2) |
| 사회적 최적 | 보수가 있는 (C, C) (−1, −1) |
| 딜레마 | 개인의 합리성은 집단적 비합리성을 낳는다 |
### 더 많은 클래식 게임
**성별 전투:**
| | 오페라 | 축구 |
|---|-------|----------|
| 오페라 | (2, 1) | (0, 0) |
| 축구 | (0, 0) | (1, 2) |
두 가지 내쉬 균형: (오페라, 오페라) 및 (축구, 축구).
**닭(매비둘기):**
| | 호크 | 비둘기 |
|---|------|------|
| 호크 | (−10, −10) | (5, 0) |
| 비둘기 | (0, 5) | (1, 1) |
두 가지 내쉬 균형: (Hawk, Dove) 및 (Dove, Hawk).

## 지배적 전략
| 개념 | 정의 |
|---------|------------|
| **엄격히 지배적임** | 전략은 상대방의 선택에 관계없이 다른 어떤 전략보다 더 높은 보상을 제공합니다 |
| **약한 지배력** | 전략은 적어도 다른 전략만큼 높은 보상을 제공하며 일부 상대 프로필의 경우 엄격히 더 높습니다 |
| **지배 전략** | 결코 최선의 대응이 아닌 전략 |
**지배 전략의 반복 제거:**
1. 엄격하게 지배되는 전략을 제거합니다.
2. 더 이상 제거할 수 없을 때까지 반복합니다.
3. 하나의 전략 프로파일이 남으면 고유한 내쉬 균형이다
---

## 내쉬 균형
**내쉬 균형**은 어떤 플레이어도 일방적으로 전략을 변경하여 보상을 향상시킬 수 없는 전략 프로필입니다.
### 정의
(s₁*, s₂*, ..., sₙ*)는 모든 플레이어 i에 대해 다음과 같은 경우 내쉬 균형입니다.
모든 sᵢ ∈ Sᵢ에 대해 uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*)
### 내쉬 균형 찾기(2×2 게임)
**최선의 응답 방법:**
1. 각 열에 대해 플레이어 1의 가장 좋은 답변에 밑줄을 긋습니다.
2. 각 행에 대해 참가자 2의 가장 좋은 반응에 밑줄을 긋습니다.
3. 둘 다 밑줄 친 셀은 내쉬 평형입니다.
### 존재(내쉬의 정리)
모든 유한 게임에는 적어도 하나의 내쉬 균형이 있습니다(아마도 혼합 전략에서).
### 혼합 전략
**혼합 전략**은 순수 전략에 대한 확률 분포입니다.
| 개념 | 정의 |
|---------|------------|
| 혼합 전략 σᵢ | Sᵢ에 대한 확률 분포 |
| 혼합 전략 NE | 어떤 플레이어도 혼합을 변경하여 예상 보수를 향상시킬 수 없습니다 |
| 지원 | 긍정적인 확률로 진행되는 순수 전략 세트 |
**실제 예시: 동전 매칭**
| | 머리 | 꼬리 |
|---|---------|-------|
| 머리 | (1, −1) | (−1, 1) |
| 꼬리 | (−1, 1) | (1, −1) |
순수한 전략 NE가 없습니다. 혼합 NE: 각각 ½ 확률로 H와 T를 모두 플레이합니다.

## 미니맥스 정리
### 제로섬 게임
**제로섬 게임**에서 한 플레이어의 이득은 정확히 다른 플레이어의 손실입니다(u₁ + u₂ = 0).
### 폰 노이만의 미니맥스 정리
모든 유한한 2인 제로섬 게임에 대해:
max_{σ₁} min_{σ2} u₁(σ₁, σ2) = min_{σ2} max_{σ₁} u₁(σ₁, σ2)
**최대값**(플레이어 1의 최악의 경우)은 **최소최대**(플레이어 2의 최악의 경우)와 같습니다. 이 공통된 가치는 **게임의 가치**입니다.
### 제로섬 게임 해결
행렬을 사용한 2×2 제로섬 게임의 경우:
| | 엘 | R |
|---|---|---|
| 티 | | 비 |
| 비 | c | 디 |
플레이어 1의 최적 혼합 전략: 확률 p = (d−c)/((a−b)+(d−c))로 T를 플레이합니다.
게임 가치: v = (ad−bc)/((a−b)+(d−c))

## 확장형 게임
순차적 이동이 있는 게임은 **게임 트리**로 표시됩니다.
### 주요 개념
| 개념 | 정의 |
|---------|------------|
| **게임 트리** | 가능한 모든 이동 순서를 보여주는 트리 |
| **정보세트** | 플레이어가 구별할 수 없는 노드 세트 |
| **완벽한 정보** | 모든 정보 세트는 싱글톤입니다(모든 움직임을 관찰할 수 있음) |
| **하위 게임 완벽 NE** | 모든 하위 게임의 내쉬 균형 |
| **역진유도** | 트리 끝에서부터 거꾸로 풀기 |
### 체르멜로의 정리
유한하고 완벽한 정보가 있는 2인 게임에서는 기회가 없습니다. 한 플레이어가 승리 전략을 갖고 있거나 둘 다 무승부를 강요할 수 있습니다(예: 체스).
---

## 협동 게임
**협력 게임**에서는 플레이어가 구속력 있는 계약과 연합을 형성할 수 있습니다.
### 특징적인 기능
협동 게임은 **특성 함수** v: 2^N → ℝ로 정의됩니다. 여기서 v(S)는 연합 S가 달성할 수 있는 가치입니다.
| 부동산 | 정의 |
|------------|------------|
| **초첨가제** | 서로소 S, T의 경우 v(S ∪ T) ≥ v(S) + v(T) |
| **볼록형** | v(S ∪ {i}) − v(S) ≤ v(T ∪ {i}) − v(T) for S ⊂ T |
### 핵심
**핵심**은 어떤 연합도 이탈하여 개선할 수 없는 할당 집합입니다.
코어 = {x ∈ ℝⁿ : Σᵢ∈N xᵢ = v(N), Σᵢ∈S xᵢ ≥ v(S) 모든 S ⊂ N에 대해}
코어가 비어 있을 수 있습니다. 이 경우 안정적인 할당이 존재하지 않습니다.
### 샤플리 가치
**Shapley 가치**는 한계 기여도를 기준으로 고유하고 공정한 할당을 제공합니다.
Φᵢ = Σ_{S ⊂ N\{i}} (|S|!(n−|S|−1)!/n!) · [v(S ∪ {i}) − v(S)]
| 부동산 | 성명서 |
|----------|-----------|
| 효율성 | Σ ψᵢ = v(N) (모든 값이 분산됨) |
| 대칭 | 동일한 기여자는 동일한 보상을 받습니다 |
| 더미 플레이어 | 비기여자는 0을 얻습니다 |
| 가산성 | Ø(v + w) = Ø(v) + Ø(w) |
**해석:** 각 플레이어의 Shapley 가치는 연합 형성의 가능한 모든 순서에 대한 평균 한계 기여입니다.
### 실제 사례
3명의 플레이어: v(∅) = 0, v({1}) = 0, v({2}) = 0, v({3}) = 0, v({1,2}) = 50, v({1,3}) = 70, v({2,3}) = 60, v({1,2,3}) = 100.
| 플레이어 | 한계 기여(주문 대비 평균) | 샤플리 가치 |
|---------|------------|---------------|
| 1 | (100+50+70+70+50+0)/6 = 56.7 | 37.5 |
| 2 | (100+50+60+60+50+0)/6 | 27.5 |
| 3 | (100+70+60+70+60+0)/6 | 35.0 |
(각 순열에 대해 Shapley 공식을 사용하여 정확하게 계산됩니다.)

## 메커니즘 디자인
**메커니즘 디자인**은 "역게임 이론"입니다. 주어진 게임을 분석하는 대신 원하는 결과를 생성하는 게임을 디자인합니다.
### 계시원리
원하는 결과를 달성하는 모든 메커니즘은 진실을 말하는 것이 내쉬 균형인 **직접 폭로 메커니즘**으로 대체될 수 있습니다.
### 경매 이론
| 경매 유형 | 규칙 | 수익 동등성 |
|-------------|-------|-------|
| **1차가격 봉인입찰** | 최고 입찰자가 승리하고 입찰가를 지불 | 모든 표준 경매는 동일한 예상 수익을 창출합니다 |
| **2차 봉인입찰(비크리)** | 최고 입찰자가 승리하고 두 번째로 높은 입찰가를 지불 | (독립적인 개인 가치 하에서) |
| **영어(오름차순)** | 가격이 상승합니다. 먼저 승리를 수락 | — |
| **네덜란드어(내림차순)** | 가격이 하락합니다. 먼저 승리를 수락 | — |
### 비크리 경매(2차 가격)
**주요 전략:** 진정한 가치를 입찰하세요.
| 부동산 | 성명서 |
|----------|-----------|
| 진실한 입찰 | 약하게 지배적인 전략 |
| 효율성 | 품목은 최고 가치 입찰자에게 전달됩니다 |
| 수익 | 1차 가격과 동일한 예상 수익(수익 등가 정리) |
### 최적 경매 설계(Myerson)
수익을 극대화하는 경매:
- **가상가치**가 가장 높은 입찰자에게 할당
- 예약 가격을 설정합니다
- 가상 가치 평가: ψ(v) = v − (1−F(v))/f(v)

## 머신러닝과의 연결
### 생성적 적대 신경망(GAN)
GAN은 생성자 G와 판별자 D 간의 2인 게임입니다.
min_G max_D V(D, G) = E[log D(x)] + E[log(1 − D(G(z)))]
| 게임 이론 개념 | GAN 등가 |
|-------|----|
| 2인용 제로섬 게임 | 생성기 대 판별기 |
| 내쉬 균형 | G는 실제 데이터를 생성하고 D는 모든 곳에서 ½을 출력합니다.
| 미니맥스 | GAN 목적 함수 |
| 모드 축소 | 평형에 도달하지 못함 |
### 다중 에이전트 강화 학습(MARL)
| 개념 | MARL 지원서 |
|---------|----|
| 내쉬 균형 | 다중 에이전트 설정의 안정적인 정책 |
| 미니맥스 | 적대적인 상대방에 대한 강력한 정책 |
| 협동 게임 | 연합 형성, 업무 할당 |
| 샤플리 가치 | 학점 할당(어떤 에이전트가 무엇을 기여했습니까?) |
| 메커니즘 설계 | 다중 에이전트 시스템의 인센티브 설계 |
| 가상의 놀이 | 내쉬 균형으로 수렴되는 학습 알고리즘 |
### 기타 ML 연결
| 신청 | 게임 이론 도구 |
|---------------|----|
| 광고 경매 디자인(구글, 페이스북) | 메커니즘 설계, 경매 이론 |
| 마켓플레이스 디자인(Uber, Airbnb) | 매칭 이론, 메커니즘 설계 |
| 적대적 견고성 | 공격자와 방어자 간의 제로섬 게임 |
| 공정한 구분 | Shapley 가치, 부러워하지 않는 할당 |
| 연합학습 | 기여도 측정을 위한 협동 게임 이론 |
| 추천 시스템 | 진실한 선호도 도출을 위한 메커니즘 설계 |

게임 이론은 전략적 사고의 수학입니다. AI 에이전트, 자동화된 시장 및 적대적 시스템의 상호 작용으로 점점 더 인구가 많아지는 세상에서 게임 이론은 행동 예측, 메커니즘 설계 및 강력한 다중 에이전트 시스템 구축을 위한 필수 툴킷을 제공합니다. 데이터 과학자를 위해 GAN의 작동 방식, 온라인 경매가 수십억 달러의 수익을 창출하는 방법, 경쟁 환경에서 잘 작동하는 AI 시스템을 구축하는 방법을 설명합니다.
