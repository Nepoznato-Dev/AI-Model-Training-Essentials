# 통계와 확률
확률과 통계는 데이터 과학, 기계 학습, 과학 연구의 수학적 기초입니다. 확률은 사건이 일어날 가능성을 알려줍니다. 통계는 데이터로부터 결론을 도출하는 방법을 알려줍니다. 이들은 함께 불확실성을 정량화 가능하고 관리 가능한 지식으로 전환합니다.
---

## 확률 이론
### 핵심 개념
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **샘플 공간** | 가능한 모든 결과의 집합 | 주사위 굴리기: {1, 2, 3, 4, 5, 6} |
| **이벤트** | 표본 공간의 하위 집합 | 짝수 굴리기: {2, 4, 6} |
| **확률** | 가능성을 측정하는 0과 1 사이의 숫자 | P(롤링 6) = 1/6 |
| **조건부 확률** | P(A|B): B가 주어졌을 때 A의 확률이 발생했습니다 | P(비|흐림) |
| **독립** | 하나가 다른 하나에 영향을 주지 않는 이벤트 | 동전 뒤집기는 독립적입니다 |
### 확률 규칙
| 규칙 | 공식 | 사용 사례 |
|------|---------|----------|
| **추가 규칙** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | A 또는 B의 확률 |
| **곱셈 규칙** | P(A ∩ B) = P(A) × P(B|A) | A와 B의 확률 |
| **보완 규칙** | P(A 아님) = 1 − P(A) | 사건이 발생하지 않을 확률 |
| **총확률의 법칙** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) | 상호 배타적인 이벤트로 파티셔닝 |
| **베이즈의 정리** | P(A|B) = P(B|A) × P(A) / P(B) | 증거로 신념 업데이트 |
### 확률 분포
| 유통 | 유형 | 주요 매개변수 | 사용 사례 |
|-------------|------|---|----------|
| **일반(가우스)** | 연속 | 평균(μ), 표준편차(σ) | 자연 현상, 측정 오류 |
| **이항** | 이산 | n(시행), p(확률) | 성공/실패 횟수 |
| **푸아송** | 이산 | λ(비율) | 시간/공간에 따른 희귀 사건 |
| **지수** | 연속 | λ(비율) | 이벤트 사이의 시간 |
| **유니폼** | 둘 다 | a, b(경계) | 똑같이 가능성이 높은 결과 |
| **카이제곱** | 연속 | k(자유도) | 적합도 테스트 |
| **t-분포** | 연속 | ν(자유도) | 소표본 추론 |
### 분포의 주요 속성
| 부동산 | 설명 |
|----------|-------------|
| **평균(기대값)** | 분포의 질량 중심: E[X] = Σ xᵢ × P(xᵢ) |
| **차이** | 평균을 중심으로 확산: Var(X) = E[(X − μ)²] |
| **표준편차** | 분산의 제곱근; 데이터와 동일한 단위 |
| **왜도** | 분포의 비대칭 |
| **첨도** | "꼬리" — 꼬리의 무게 |

## 통계적 추론
### 기술 통계와 추론 통계
| | 설명 | 추론 |
|---|-------------|-------------|
| **목적** | 데이터 요약 및 설명 | 표본을 통해 모집단에 대한 결론 도출 |
| **도구** | 평균, 중앙값, 최빈값, 표준편차, 차트 | 가설 검정, 신뢰 구간, 회귀 |
| **범위** | 당신이 가지고 있는 데이터만 | 샘플 이상의 일반화 |
### 가설 테스트 프레임워크
| 단계 | 설명 |
|------|-------------|
| 1. **주 가설** | 귀무가설(H₀): 효과 없음; 대안(H₁): 효과가 존재함 |
| 2. **유의성 수준 선택** | α = 0.05(기존) |
| 3. **테스트 선택** | 데이터 유형, 표본 크기 및 가정을 기준으로 |
| 4. **검정 통계량 계산** | 선택한 테스트에 따라 다름 |
| 5. **p-값 찾기** | H₀이 참인 경우 데이터를 관찰할 확률 |
| 6. **결정하기** | p < α이면 H₀을 기각합니다. 그렇지 않으면 H₀을 거부하지 못함 |
### 일반적인 통계 테스트
| 테스트 | 사용 시기 | 비교 대상 |
|------|-------------|----|
| **t-테스트** | 1~2개 그룹의 평균 비교 | 값 또는 서로의 평균을 그룹화 |
| **카이제곱 검정** | 범주형 데이터 | 관찰된 빈도와 예상 빈도 |
| **ANOVA** | 3개 이상의 그룹의 평균 비교 | 그룹 간 차이와 그룹 내 차이 |
| **만-휘트니 U** | t-검정에 대한 비모수적 대안 | 두 그룹의 순위 분포 |
| **피어슨 상관관계** | 두 연속변수 사이의 선형 관계 | r 값은 -1에서 +1까지 |
| **Spearman 상관관계** | 단조로운 관계(순위 기반) | 순서 또는 비정규 데이터의 ρ 값 |
### 신뢰구간
신뢰 구간은 모집단 모수에 대해 그럴듯한 값의 범위를 제공합니다.
- **평균에 대한 95% CI**(알려진 σ): x̄ ± 1.96 × (σ / √n)
- **해석**: "우리는 실제 모집단 평균이 이 구간 내에 있다고 95% 확신합니다."
- **더 넓은 CI** = 더 많은 불확실성(더 작은 표본, 더 높은 변동성 또는 더 높은 신뢰 수준)

## 회귀 분석
### 회귀 유형
| 유형 | 종속변수 | 사용 사례 |
|------|------|----------|
| **선형 회귀** | 연속 | 주택 가격, 매매 예측 |
| **로지스틱 회귀** | 바이너리(0/1) | 분류 : 스팸감지, 질병진단 |
| **다항 회귀** | 연속(곡선) | 성장 곡선, 비선형 추세 |
| **다중 회귀** | 연속형(2개 이상의 예측변수) | 혼란스러운 요인에 대한 제어 |
| **능선/올가미** | 연속(정규) | 과적합 방지, 특징 선택 |
### 선형 회귀 기본 사항
모델: **y = β₀ + β₁x + ε**
| 구성요소 | 의미 |
|------------|---------|
| β₀(절편) | x = 0일 때 y의 값 |
| β₁(기울기) | x의 한 단위 변화에 대한 y의 변화 |
| ε(오차항) | 설명할 수 없는 변형 |
**주요 측정항목:**
- **R²(결정계수)**: 모델이 설명하는 분산의 비율(0~1)
- **조정된 R²**: 예측 변수 수에 따라 R²에 페널티가 적용됨
- **RMSE**: 평균 제곱근 오차 — y와 동일한 단위의 평균 예측 오차
### 선형 회귀의 가정
| 가정 | 그것이 의미하는 것 | 확인 방법 |
|------------|---------------|-------------|
| **선형성** | X와 Y의 관계는 선형입니다 | 산점도 |
| **독립** | 관측치는 독립적입니다 | 연구 설계 |
| **동분산성** | 잔차의 일정한 분산 | 잔차 도표 |
| **정규성** | 잔차는 정규 분포를 따릅니다. | Q-Q 플롯, Shapiro-Wilk 테스트 |
| **다중공선성 없음** | 예측변수의 상관관계가 높지 않습니다 | VIF(변동팽창계수) |

## 베이지안 통계
### 빈도주의자 대 베이지안
| | 빈도주의자 | 베이지안 |
|---|-------------|----------|
| **확률의 의미** | 장기빈도 | 신념의 정도 |
| **매개변수는** | 수정되었지만 알 수 없음 | 분포가 있는 무작위 변수 |
| **용도** | p-값, 신뢰구간 | 사후 분포, 신뢰할 수 있는 간격 |
| **강점** | 객관적이고 확고한 | 사전 지식 통합, 직관적 해석 |
### 베이즈 정리의 실제 사례
**사후 = (우도 × 사전) / 증거 **
예 — 의료 테스트:
- 질병 유병률 : 1% (이전)
- 테스트 민감도 : 95% (진양성률)
- 검사 특이성 : 90% (진음성률)
- 양성 판정을 받은 경우: P(질병 | 양성) = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99) ≒ 8.8%
이러한 직관에 반하는 결과(질병이 희귀할 때 대부분의 긍정적인 결과는 위양성임)는 **기본율 오류**이며 베이지안 사고가 중요한 이유를 보여줍니다.

## 실용적인 팁
- 통계 테스트를 실행하기 전에 **항상 데이터를 시각화**하세요.
- **가정 확인** - 위반 시 결과가 무효화될 수 있음
- **효과 크기가 중요** — 통계적으로 유의미한 결과는 실질적으로 의미가 없을 수도 있습니다.
- **상관관계는 인과관계가 아닙니다** — 강한 상관관계라도 혼란을 야기할 수 있습니다.
- **다중 비교**로 인해 위양성률이 부풀려짐 - 수정 사항 적용(Bonferroni, FDR)
- **p-값뿐만 아니라 신뢰 구간 보고**
---

## 이것이 중요한 이유
통계는 과학 연구, 비즈니스 분석, 기계 학습의 중추입니다. 그것이 없으면 신호와 잡음을 구분할 수 없고, 무작위 변동에서 실제 효과를 식별할 수 없으며, 정량화된 불확실성으로 예측할 수 없습니다. A/B 테스트를 분석하든, ML 모델을 교육하든, 연구 논문을 읽든 관계없이 통계적 이해력은 필수적입니다.
