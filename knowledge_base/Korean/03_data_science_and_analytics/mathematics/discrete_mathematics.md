# 이산수학
이산 수학은 매끄럽고 깨지지 않는 수량을 다루는 연속 수학(미적분학, 실제 분석)과 달리 근본적으로 셀 수 있거나 분리된 수학적 구조에 대한 연구입니다. 이산 수학은 컴퓨터 과학, 암호화, 알고리즘 설계 및 데이터 구조를 뒷받침합니다. 연속 수학이 물리적 세계를 설명한다면 이산 수학은 계산 세계를 설명합니다.
---

## 심도 있는 이론 설정
집합은 거의 모든 현대 수학이 구축되는 기초입니다. **세트**는 **요소** 또는 **멤버**라고 불리는 고유한 개체의 순서가 지정되지 않은 컬렉션입니다.
### 공리 기초(ZFC)
현대 집합론은 **ZFC(선택의 공리)**를 갖춘 Zermelo-Fraenkel 공리**에 기초합니다. 이러한 공리는 집합이 형성될 수 있는 방법을 제한함으로써 러셀의 역설("자신을 포함하지 않는 모든 집합의 집합")과 같은 역설을 해결합니다.
| 공리 | 비공식 성명 |
|-------|---------|
| 확장성 | 두 집합이 동일한 요소를 갖는 경우에는 동일합니다 |
| 빈 세트 | 요소가 없는 집합이 있습니다. ∅ |
| 페어링 | 임의의 a, b에 대해 {a, b}가 존재합니다 |
| 연합 | 모든 세트 계열에 대해 해당 결합이 존재합니다 |
| 전원 세트 | 임의의 집합 S에 대해 S의 모든 부분 집합으로 구성된 집합이 존재합니다. P(S) |
| 인피니티 | 무한한 집합이 존재합니다 |
| 사양 | 임의의 집합 A와 속성 P에 대해 {x ∈ A : P(x)}가 존재합니다 |
| 교체 | 정의 가능한 함수 아래의 집합 이미지는 집합 |
| 규칙성 | 비어 있지 않은 모든 세트에는 해당 세트와 분리된 요소가 포함되어 있습니다(자체 멤버십 방지) |
| 선택 | 비어 있지 않은 쌍별 서로소 집합 계열에 대해 선택 함수가 존재합니다 |
### 세트의 카디널리티 및 크기
|S|로 표시된 집합의 **카디널리티**는 해당 집합의 "크기"를 측정합니다.
| 개념 | 정의 | 예 |
|---------|------------|---------|
| 유한 집합 | 카디널리티로 자연수를 가짐 | |{a, b, c}| = 3 |
| 셀 수 없을 만큼 무한 | ℕ와 동일한 카디널리티 | ℤ, ℚ는 셀 수 없이 무한하다 |
| 셀 수 없이 | ℕ보다 큼 | ℝ, P(ℕ), 모든 함수의 집합 ℕ → {0,1} |
| 칸토어의 정리 | 임의의 집합 S에 대해 |P(S)| > |에| | |피(ℕ)| > |ℕ| |
**Cantor의 대각선 논증**은 ℝ이 셀 수 없음을 증명합니다. 모든 실수를 [0,1]에 나열할 수 있다고 가정한 다음 소수점 n번째 자리에서 n번째 나열된 실수와 다른 새로운 실수를 구성합니다. 즉 모순입니다.
### 세트 작업
| 운영 | 표기법 | 정의 | 부동산 |
|------------|----------|------------|----------|
| 연합 | A ∪ B | {x : x ∈ A 또는 x ∈ B} | 교환, 연관 |
| 교차로 | A ∩ B | {x : x ∈ A 및 x ∈ B} | 교환, 연관 |
| 차이 | A \ B | {x : x ∈ A 및 x ∉ B} | 교환 가능하지 않음 |
| 대칭차이 | A △ B | (A \ B) ∪ (B \ A) | 교환, 연관 |
| 보완 | 아윰 | U \ A(여기서 U는 보편적 집합) | (Aᶜ)ᶜ = A |
| 데카르트 곱 | A × B | {(a,b) : a ∈ A, b ∈ B} | |A × B| = |아| · |비| |
**드 모건의 법칙:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**포함-배제 원칙**(유한 집합의 경우):
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|아ᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|

## 관계
집합 A와 B의 **관계** R은 A × B의 부분 집합입니다. (a, b) ∈ R일 때 aRb를 씁니다.
### 관계 유형
집합 A의 관계 R은 다음과 같은 속성을 가질 수 있습니다.
| 부동산 | 정의 | 예 |
|------------|------------|---------|
| 반사 | ∀a ∈ A: 아라 | ≤ ℤ |
| 무반사적 | ∀a ∈ A: ¬(aRa) | < ℤ |
| 대칭 | ∀a,b: aRb → bRa | = 임의의 세트 |
| 비대칭 | ∀a,b: aRb ∧ bRa → a = b | ≤ ℤ |
| 전이적 | ∀a,b,c: aRb ∧ bRc → aRc | <, ≤, = ℤ에 |
### 등가 관계
**동등 관계**는 반사적, 대칭적, 추이적입니다. 집합을 분리된 **동등 클래스**로 분할합니다.
**예:** 모듈식 연산. a ñ b (mod n)에 따라 a ~ b를 정의합니다. 등가 클래스는 [0], [1], ..., [n−1]이며, 이는 ℤ을 n개의 클래스로 분할합니다.
**실제 예:** ℤ × ℤ에서 a + d = b + c인 경우 (a,b) ~ (c,d)를 정의합니다. 이것이 동치관계입니다. 클래스 [(0,0)] = {(n,n) : n ∈ ℤ}. 클래스 [(1,0)] = {(n+1,n) : n ∈ ℤ}. 이 구성은 실제로 자연수의 정수를 정의합니다.
### 부분 주문
**부분 순서**는 반사적이고 반대칭적이며 추이적입니다. 부분 순서가 있는 집합을 **부분 순서 집합(포셋)**이라고 합니다.
| 개념 | 정의 | 예 |
|---------|------------|---------|
| 포셋 | (S, ≤) ≤ 부분 순서 | (P(A), ⊆) — 포함순으로 정렬된 하위 집합 |
| 체인 | 완전히 정렬된 하위 집합 | P({a,b,c})의 {∅, {a}, {a,b}} |
| 안티체인 | 비교할 수 있는 두 요소가 없는 하위 집합 | P({a,b})의 {{a}, {b}} |
| 하세 다이어그램 | 포셋의 시각적 표현 | 덮는 관계에 대해서만 모서리 그리기 |
| 상한 | 요소 ≥ 하위 집합의 모든 요소 | sup({2,3}) = 6 in (ℤ, \|) (가분성) |
| 최소 상한(sup) | 최소 상한 | (ℕ, ≤)의 sup({2,3})은 3 |
| 최대 하한(inf) | 최대 하한 | (ℕ, \|)의 inf({4,6})는 2 |

## 기능
A **함수** f: A → B는 A의 각 요소에 정확히 B의 한 요소를 할당합니다.
### 기능 분류
| 유형 | 정의 | 예 |
|------|------------|---------|
| 주사형(일대일) | f(a) = f(b) → a = b | f(x) = ℤ → ℤ에서 2x |
| 동사 (onto) | ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x mod 2 ℤ → {0,1} |
| 전단사 | 단사와 전사 모두 | f(x) = ℤ → ℤ에서 x + 1 |
### 중요한 기능 개념
| 개념 | 정의 | 사용 사례 |
|---------|------------|----------|
| 역함수 | f⁻¹는 f가 전단사인 경우에만 존재합니다 | 암호화된 데이터 해독 |
| 구성 | (g Ø f)(x) = g(f(x)) | 체인 변환 |
| 신원 기능 | 아이디(x) = x | 구성에 대한 중립 요소 |
| 고정점 | f(x) = x | 재귀적 정의, 의미론 |
| 순열 | 집합에서 그 자체로의 전단사 | 데이터 재배열, 셔플링 |
### 계산 기능
유한 집합이 주어지면 |A| = m 및 |B| =n:
| 유형 | 카운트 |
|------|---------|
| 모든 기능 A → B | 아니 |
| 분사 기능 | N! / (n-m)! (n ≥ m인 경우, 그렇지 않은 경우 0) |
| 전사적 기능 | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ (포함-제외 기준) |
| 전단사 기능 | N! (m = n일 때) |

## 조합론
조합론은 계산하고, 배열하고, 선택하는 수학입니다.
### 기본 계산 원리
| 원리 | 성명서 | 예 |
|------------|------------|---------|
| 합의 법칙 | A와 B가 서로소인 경우 |A ∪ B| = |아| + |비| | 과일 선택: 사과 3개 + 오렌지 4개 = 7가지 옵션 |
| 제품의 법칙 | |A × B| = |아| · |비| | 의상: 셔츠 3벌 × 바지 4벌 = 의상 12벌 |
| 전단사 규칙 | f: A → B가 전단사인 경우 |A| = |비| | 이진 문자열을 계산하여 하위 집합 계산 |
| 보완 | |아| = |유| − |아윰| | "적어도 하나"를 총계에서 "없음"을 뺀 값으로 계산 |
### 순열 및 조합
| 표기법 | 이름 | 공식 | 의미 |
|------------|------|---------|---------|
| C(n, k) 또는 (n k) | 이항계수 | N! / (k!(n−k)!) | n개 중에서 k개 항목을 선택하는 방법(순서는 중요하지 않음) |
| P(n, k) | n의 k-순열 | N! / (n-k)! | n개에서 k개 항목을 배열하는 방법(순서 중요) |
| N! | 팩토리얼 | n × (n−1) × ... × 1 | n개 항목을 모두 정렬하는 방법 |
| (n k) 반복 | 다중 선택 | C(n+k−1, k) | 반복이 허용되는 n 중에서 k를 선택하세요 |
**이항 정리:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**파스칼의 항등식:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### 비둘기집 원리
**기본 형식:** n+1개의 개체를 n개의 상자에 배치하는 경우 적어도 하나의 상자에는 ≥ 2개의 개체가 포함됩니다.
**일반 형식:** N개의 개체가 k개의 상자에 배치된 경우 적어도 하나의 상자에는 ≥ ⌈N/k⌉ 개체가 포함됩니다.
**실제 사례:**
1. 13명 중 최소 2명은 출생월을 공유합니다. (13명, 12개월 → 비둘기집.)
2. 5개의 정수 중에 그 합이 3으로 나누어지는 3개가 있음을 보여라.
   - 잔여물 모드 3: {0, 1, 2}를 고려하세요. 5개의 정수와 3개의 잔여물 클래스를 사용하면 일반화된 비둘기집에 의해 적어도 ⌈5/3⌉ = 2가 잔여물을 공유합니다.
   - 3이 나머지 r을 공유하는 경우: 그 합은 ‚ 3r ‚ 0(mod 3)입니다.
   - 2가 잔여물 0을 공유하고 2가 잔여물 1을 공유하는 경우: 각 쌍과 잔여물-0 요소에서 하나를 선택 → 합 Д 0(mod 3).
3. **CS에 적용:** 무손실 압축 알고리즘은 일부 입력을 확장해야 합니다. (모든 n 비트 문자열이 < n 비트로 압축된 경우 2ⁿ 문자열을 2ⁿ 미만의 압축 문자열로 매핑하여 주입성을 위반하게 됩니다.)
### 카탈로니아어 숫자
n번째 **카탈로니아 수** Cₙ = C(2n, n) / (n+1)은 다음과 같습니다.
| 구조 | 예 |
|------------|---------|
| 유효한 괄호 시퀀스 | ()(), (())(n = 2인 경우) |
| n개의 내부 노드가 있는 이진 트리 | n = 2인 경우 나무 2개 |
| 대각선을 넘지 않는 경로 | (0,0)에서 (n,n)까지의 그리드 경로가 y = x |
| 다각형의 삼각측량 | (n+2)-gon을 삼각형으로 나누는 방법 |
처음 몇 개: C₀ = 1, C₁ = 1, C₂ = 2, C₃ = 5, C₄ = 14, C₅ = 42.
반복: Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## 반복 관계
**반복 관계**는 수열의 각 항을 이전 항의 함수로 정의합니다.
### 유형 및 솔루션
| 유형 | 양식 | 해결 방법 |
|------|------|----|
| 선형 균질(상수 계수) | aₙ = c₁aₙ₋₁ + c2aₙ₋₂ + ... + cₖaₙ₋ₖ | 특성 방정식 |
| 선형 비균질 | aₙ = c₁aₙ₋₁ + ... + f(n) | 특정 용액 + 균질 용액 |
| 분열과 정복 | T(n) = aT(n/b) + f(n) | 마스터 정리 |
### 특성 방정식 방법
aₙ = c₁aₙ₋₁ + c2aₙ₋₂에 대해 특성 방정식을 구성합니다.
r² − c₁r − c² = 0
| 사례 | 뿌리 | 일반 솔루션 |
|------|-------|------|
| 두 개의 서로 다른 실근 r₁, r₂ | r₁ ≠ r² | aₙ = A·r₁ⁿ + B·r²ⁿ |
| 반복 루트 r | r₁ = r² = r | aₙ = (A + Bn)·rⁿ |
| 복소수 근 α ± βi | 극좌표로 변환: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**실제 예:** 피보나치 수열 Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1.
- 특성 방정식: r² − r − 1 = 0
- 근: r = (1 ± √5) / 2 → ψ = (1+√5)/2 ≒ 1.618, ψ = (1−√5)/2 ≒ −0.618
- 일반해 : Fₙ = A·Φⁿ + B·ψⁿ
- 초기조건에서 : A = 1/√5, B = −1/√5
- **폐쇄형:** Fₙ = (ψⁿ − ψⁿ) / √5 (Binet의 공식)
### 마스터 정리
a ≥ 1, b > 1인 T(n) = aT(n/b) + f(n) 형식의 재발의 경우:
c = log_b(a)라고 하자.
| 사례 | 조건 | 솔루션 |
|------|-------------|----------|
| 1 | f(n) = O(nᵈ) 여기서 d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c이고 k < 1 | T(n) = Θ(nᵈ) |
**예:**
- 병합 정렬: T(n) = 2T(n/2) + O(n). 여기서 a=2, b=2, c=1, f(n)=n=Θ(n1)입니다. 사례 2: T(n) = Θ(n log n).
- 이진 검색: T(n) = T(n/2) + O(1). 여기서 a=1, b=2, c=0, f(n)=1=Θ(n⁰)입니다. 사례 2: T(n) = Θ(log n).

## 함수 생성
**생성 함수**는 수열(aₙ)을 형식 거듭제곱 시리즈의 계수로 인코딩합니다.
### 유형
| 유형 | 양식 | 사용 사례 |
|------|------|----------|
| 보통 (OGF) | G(x) = Σₙ₌₀^킵 aₙxⁿ | 라벨이 지정되지 않은 구조, 구성 |
| 지수(EGF) | E(x) = Σₙ₌₀^킵 aₙxⁿ/n! | 레이블이 있는 구조, 순열 |
### 공통 생성 함수
| 시퀀스 aₙ | OGF G(x) |
|-------------|------------|
| 1, 1, 1, 1, ... | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² |
| 1, r, r², r³, ... | 1/(1−rx) |
| 고정 k에 대한 C(n,k) | xᵏ/(1−x)ᵏ⁺¹ |
| 피보나치 Fₙ | x/(1−x−x²) |
| 카탈로니아어 Cₙ | (1 − √(1−4x)) / (2x) |
### 생성 함수를 사용하여 반복 문제 해결
**실제 예:** aₙ = 3aₙ₋₁ − 2aₙ₋₂, a₀ = 1, a₁ = 3을 풉니다.
1. G(x) = Σ aₙxⁿ라고 하자.
2. 반복에서: G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. 대체: G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. 부분 분수: G(x) = 2/(1−2x) − 1/(1−x)
7. 계수 추출: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺¹ − 1
**검증:** a₀ = 2−1 = 1, a₁ = 4−1 = 3, a² = 8−1 = 7. 확인: 3(3) − 2(1) = 7.

## 부울 대수학과 명제 논리
부울 대수는 **참(1)**과 **거짓(0)**이라는 두 가지 진리값의 대수입니다. 이는 디지털 회로, 데이터베이스 쿼리 및 프로그래밍 조건의 수학적 기초입니다.
### 운영 및 법률
| 운영 | 기호 | 의미 | 진리표 |
|------------|---------|---------|-------------|
| 그리고 | 피 ∧ q | 둘 다 참인 경우에만 참 | T∧T=T, T∧F=F, F∧T=F, F∧F=F |
| 또는 | 피 ∨ q | 하나 이상이 참인 경우 참 | T∨T=T, T∨F=T, F∨T=T, F∨F=F |
| 아님 | ¬p | 부정 | ¬T=F, ¬F=T |
| XOR | p ⊕ q | 정확히 하나가 참인 경우 참 | T⊕T=F, T⊕F=T, F⊕T=T, F⊕F=F |
| 암시 | p → q | p=T 및 q=F인 경우에만 거짓 | T→T=T, T→F=F, F→T=T, F→F=T |
| 조건부 | p ⇔ q | 둘 다 동일한 값을 갖는 경우 참 | T⇔T=T, T⇔F=F, F⇔T=F, F⇔F=T |
### 주요 부울 ID
| 법률 | 공식 |
|------|---------|
| 교환성 | p ∧ q = q ∧ p; p ∨ q = q ∨ p |
| 연관성 | (p ∧ q) ∧ r = p ∧ (q ∧ r) |
| 분배성 | p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
| 드 모건의 법칙 | ¬(p ∧ q) = ¬p ∨ ¬q; ¬(p ∨ q) = ¬p ∧ ¬q |
| 이중 부정 | ¬(¬p) = p |
| 멱등성 | p ∧ p = p; p ∨ p = p |
| 흡수 | p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
| 대조 | (p → q) EMA (¬q → ¬p) |
### 일반 형식
| 양식 | 구조 | 사용 사례 |
|------|-------------|----------|
| 결합 정규형(CNF) | OR의 AND: (A∨B) ∧ (C∨D) | SAT 해결사, 분해 정리 증명 |
| 분리정규형(DNF) | AND의 OR: (A∧B) ∨ (C∧D) | 회로 설계, 규칙 기반 시스템 |
**CNF로 변환:** De Morgan의 법칙을 적용하고 OR를 AND에 배포하여 이중 부정을 제거합니다.

## 모듈식 산술 및 합동
모듈러 연산은 "나누기 후 나머지" 연산을 통해 정수를 연구합니다. 암호화, 해싱 및 숫자 이론에 필수적입니다.
### 핵심 정의
| 개념 | 표기법 | 정의 |
|---------|----------|------------|
| 일치 | a ñ b (mod n) | n 나누기 (a − b) |
| 잔류물 종류 | [a]ₙ | 집합 {a + kn : k ∈ ℤ} |
| 모듈러 역 | a⁻¹ 모드 n | ax 1(mod n) |
| 오일러의 토션트 | Φ(n) | {1,...,n}의 정수 개수를 n으로 변환 |
### 주요 속성
| 부동산 | 성명서 |
|------------|----------|
| 추가 | a DF b 및 c DF d (mod n)이면 a+c ‚ b+d (mod n) |
| 곱셈 | a DF b 및 c DF d (mod n)이면 ac DF bd (mod n) |
| 페르마의 작은 정리 | p가 소수이고 gcd(a,p) = 1이면 aᵖ⁻¹ ‚ 1 (mod p) |
| 오일러의 정리 | gcd(a,n) = 1이면 a^ψ(n)  1 (mod n) |
| 중국의 나머지 정리 | gcd(m,n) = 1이면 시스템 x = a (mod m), x = b (mod n)은 고유한 해 mod mn |
### 오일러의 토션트 계산하기
n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ(소인수분해)의 경우:
Φ(n) = n · (1 − 1/p₁) · (1 − 1/p²) · ... · (1 − 1/pₖ)
**예:** Φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4. 실제로 {1, 5, 7, 11}은 12의 서로소입니다.
### 애플리케이션: RSA 암호화(개요)
1. 큰 소수 p, q를 선택하세요. n = pq, Φ(n) = (p−1)(q−1)을 계산합니다.
2. gcd(e, Φ(n)) = 1(공개 지수)이 되도록 e를 선택합니다.
3. d χ e⁻¹ (mod ψ(n))(비공개 지수)을 계산합니다.
4. 암호화: c = mᵉ mod n. 해독: m = cᵈ mod n.
5. 보안은 p와 q를 찾기 위해 n을 인수분해하는 어려움에 의존합니다.

## 수학적 귀납법
**수학적 귀납법**은 모든 자연수에 대한 진술에 대한 주요 증명 기법입니다.
### 귀납법에 의한 증명의 구조
1. **기본 사례:** n = 0(또는 n = 1)에 대한 명제를 증명하십시오.
2. **귀납적 단계:** 명제가 n = k(귀납적 가설)에 대해 성립한다고 가정하고 n = k + 1에 대해 증명합니다.
### 변형
| 변형 | 사용 시기 |
|---------|-------------|
| 단순 인덕션 | P(k) → P(k+1) |
| 강력한 유도 | P(k+1) |
| 구조적 유도 | 재귀적으로 정의된 구조(트리, 공식)의 속성 증명 |
| 초한 유도 | ℕ |
**실제 예(강한 귀납법):** 모든 정수 n ≥ 2가 소수의 곱으로 쓰여질 수 있음을 증명하세요.
- 밑: n = 2는 소수이므로 소수(그 자체)의 곱입니다.
- 귀납적 단계: 2부터 k까지의 모든 정수에 대해 참이라고 가정합니다. k+1을 고려해보세요.
  - k+1이 소수이면 완료됩니다.
  - k+1이 합성수이면 k+1 = ab(2 ≤ a, b ≤ k)입니다. 귀납 가설에 따르면 a와 b는 모두 소수의 곱이므로 k+1은 소수의 곱입니다.
