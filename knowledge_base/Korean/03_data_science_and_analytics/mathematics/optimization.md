# 최적화
최적화는 실행 가능한 솔루션 세트에서 최상의 솔루션을 찾는 수학입니다. 함수와 제약 조건이 주어지면 어떤 입력이 출력을 최소화(또는 최대화)합니까? 최적화는 기계 학습의 엔진입니다. 모델을 훈련한다는 것은 손실 함수를 최소화하는 것을 의미합니다. 이는 운영 연구, 경제학, 엔지니어링 설계 및 거의 모든 정량적 분야에 나타납니다.
---

## 문제 공식화
일반적인 **최적화 문제**의 형식은 다음과 같습니다.
f(x) 최소화
적용 대상: gᵢ(x) ≤ 0(부등식 제약 조건), hⱼ(x) = 0(동등성 제약 조건)
| 기간 | 의미 |
|------|---------|
| **목적 함수** f(x) | 최소화(또는 최대화)할 수량 |
| **결정 변수** x | 우리가 통제할 수 있는 가치 |
| **가능지역** | 모든 제약 조건을 만족하는 모든 x의 집합 |
| **전역 최소값** | 모든 실현 가능 x에 대해 f(x*) ≤ f(x)인 실현 가능 x* |
| **로컬 최소값** | 일부 이웃의 모든 실현 가능 x에 대해 f(x*) ≤ f(x)인 실현 가능 x* |
| **볼록한 문제** | f는 볼록하고, 실현 가능 영역은 볼록 집합입니다(로컬 최소값 = 전역 최소값) |
---

## 선형 프로그래밍(LP)
목표와 모든 제약 조건이 모두 **선형**인 경우 문제는 선형 계획입니다.
### 표준 양식
cᵀx 최소화
적용 대상: Ax ≤ b, x ≥ 0
여기서 c, x ∈ ℝⁿ, A ∈ ℝᵐˣⁿ, b ∈ ℝᵐ.
### 속성
| 부동산 | 성명서 |
|----------|-----------|
| 볼록성 | LP는 항상 볼록 문제입니다 |
| 최적의 솔루션 | 항상 실현 가능한 폴리토프의 꼭지점(모서리점)에 |
| 존재 | 실행 가능한 영역이 제한되어 있고 비어 있지 않은 경우 최적의 솔루션이 존재합니다 |
| 다중 최적 | 두 정점이 최적인 경우 두 정점 사이의 가장자리에 있는 모든 점도 최적입니다 |
### 단순 방법
**단순 방법**(Dantzig, 1947)은 실행 가능한 폴리토프의 가장자리를 따라 꼭지점에서 꼭지점으로 이동하여 최적에 도달할 때까지 항상 목적을 개선합니다.
| 부동산 | 가치 |
|----------|-------|
| 최악의 시간 | O(2ⁿ) (지수 — 실제로는 드물다) |
| 평균 케이스 시간 | 대부분의 실제 문제에 대한 다항식 |
| 핵심 아이디어 | 더 나은 목표값을 갖는 인접 꼭지점으로 이동 |
**알고리즘(개요):**
1. 실행 가능한 기본 해(폴리토프의 꼭지점)에서 시작합니다.
2. 입력변수 선택(목표를 향상시키는 변수)
3. 이탈변수 선택(타당성 유지)
4. 피벗: 새 정점으로 이동
5. 개선 방향이 없을 때까지 반복합니다.
### 내부 포인트 방법
단순에 대한 대안: 실현 가능한 영역 내부에서 최적에 접근합니다.
| 부동산 | 가치 |
|----------|-------|
| 최악의 시간 | 다항식(일부 변형의 경우 O(n³·⁵)) |
| 실질적인 성과 | 대규모 문제에서 단순 경쟁 |
| 핵심 아이디어 | 내부를 통과하는 "중앙 경로"를 따라가세요 |
### 작업된 LP 예시
**문제:** 의자(x₁)와 테이블(x2)을 생산하는 공장이 있습니다.
- 수익: 의자당 $30, 테이블당 $50
- 목재 : 2x₁ + 4x₂ ≤ 100 (보드피트 가능)
- 노동력: x₁ + 3x² ≤ 60 (시간 이용 가능)
- 최대화: 30x₁ + 50x₂
**해결책(2개 변수에 대한 그래픽 방법):**
- 실현 가능 영역의 정점: (0,0), (30,0), (40,10), (0,20)
- 각 정점에서 목표를 평가합니다.
  - (0,0): 이익 = 0
  - (30,0): 이익 = 900
  - (40,10): 이익 = 1700 ← 최적
  - (0,20): 이익 = 1000
- **최적:** x₁ = 의자 40개, x² = 테이블 10개, 이익 = $1700

## 볼록 최적화
목적 함수가 볼록하고 실현 가능 영역이 볼록 세트인 경우 문제는 **볼록**입니다.
### 볼록 집합 및 함수
| 개념 | 정의 |
|---------|------------|
| **볼록한 집합** | 집합의 임의의 x, y에 대해 t ∈ [0,1]: tx + (1−t)y도 집합 |
| **볼록함수** | 모든 t ∈ [0,1] |
| **엄격히 볼록한** | t ∈ (0,1) 및 x ≠ y |
**주요 속성:** 볼록 최적화의 경우 모든 로컬 최소값은 전역 최소값입니다.
### 일반적인 볼록 함수
| 기능 | 볼록한? | 어디 |
|----------|---------|-------|
| ax + b(선형) | 예(오목형) | 모든 곳 |
| x² | 예 | ℝ |
| 에ˣ | 예 | ℝ |
| -로그(x) | 예 | x > 0 |
| \|x\|ᵖ (p ≥ 1) | 예 | ℝⁿ |
| max(f₁, f₂) if f₁, f₂ 볼록 | 예 | 도메인의 교차점 |
### 경사하강법
머신러닝의 가장 기본적인 최적화 알고리즘입니다.
**업데이트 규칙:** x_{k+1} = x_k − α∇f(x_k)
여기서 α > 0은 **학습률**(단계 크기)입니다.
| 변형 | 업데이트 규칙 | 장점 |
|---------|-------------|------------|
| **일괄 GD** | x ← x − α∇f(x) | 안정적인 융합 |
| **확률적 GD(SGD)** | x ← x − α∇fᵢ(x) (샘플 1개) | 반복당 빠르게, 로컬 최소값을 탈출합니다 |
| **미니배치 ₩₩** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | 배치와 확률론 간의 균형 |
| **모멘텀** | v ← βv − α∇f(x); x ← x + v | 평탄한 지역을 통해 가속 |
| **아담** | 매개변수별 적응형 학습률 | 딥 러닝을 위해 즉시 사용 가능 |
| **RMSprop** | 기울기 크기의 평균을 실행하여 학습 속도 확장 | RNN에 적합 |
### 수렴률
| 방법 | 볼록형 f | 강하게 볼록한 f |
|---------|----------|------|
| 경사하강법 | O(1/k) | O((1−μ/L)ᵏ) (선형) |
| 싱가포르 달러 | O(1/√k) | O(1/k) |
| 가속 GD (네스테로프) | O(1/k²) | O((1−√(μ/L))ᵏ) |
여기서 k = 반복 횟수, μ = 강력한 볼록성 매개변수, L = Lipschitz 상수.
### 학습률 선택
| 전략 | 설명 |
|----------|-------------|
| 고정 α | 단순하지만 갈라지거나(너무 크거나) 천천히 수렴할 수 있음(너무 작음) |
| 라인 검색 | 기울기 방향을 따라 f(x − α∇f(x))를 최소화하는 α 찾기 |
| 부패 일정 | α_t = α₀ / (1 + βt) 또는 α_t = α₀ · βᵗ |
| 워밍업 | 작게 시작하고 증가한 다음 감소합니다(변압기 훈련에서 일반적임) |
| 적응형(아담) | 기울기 통계를 기반으로 한 매개변수별 학습률 |

## 제한된 최적화
### 라그랑주 승수
문제의 경우: h(x) = 0인 조건에서 f(x)를 최소화합니다.
**라그랑지안:** L(x, λ) = f(x) + λh(x)
최적의 경우: ∇ₓL = 0 및 ∇_λL = 0(h(x) = 0 제공).
**작업된 예:** x + y = 1에 따라 f(x,y) = x² + y²를 최소화합니다.
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- 제약조건: x + y = 1 → −λ = 1 → λ = −1
- 해법: x = 1/2, y = 1/2, f = 1/2
### KKT 조건
**Karush-Kuhn-Tucker(KKT) 조건**은 라그랑주 승수를 부등식 제약 조건으로 일반화합니다.
For: gᵢ(x) ≤ 0, hⱼ(x) = 0에 따라 f(x)를 최소화합니다.
**라그랑지안:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT 조건**(최적화에 필요함):
| 조건 | 방정식 |
|------------|----------|
| 정상성 | ∇ₓL = 0 |
| 원초적 타당성 | gᵢ(x) ≤ 0, hⱼ(x) = 0 |
| 이중 타당성 | λᵢ ≥ 0 |
| 보완적인 느슨함 | 모든 i에 대해 λᵢgᵢ(x) = 0 |
**보완적 느슨함**은 제약조건 gᵢ가 활성화되지 않은 경우(gᵢ(x) < 0) λᵢ = 0(제약조건이 솔루션에 영향을 미치지 않음)을 의미합니다.
Slater의 조건을 충족하는 볼록 문제의 경우 KKT 조건이 필요하고 충분합니다.

## 이중성
모든 최적화 문제(**원초**)에는 관련된 **이중** 문제가 있습니다.
### 약함과 강함의 이중성
| 개념 | 성명서 |
|---------|------------|
| **이중 기능** | g(λ, ν) = infₓ L(x, λ, ν) |
| **이중 문제** | λ ≥ 0인 경우 g(λ, ν) 최대화 |
| **약한 이중성** | 이중 최적 ≤ 원시 최적(항상 유지) |
| **강한 이중성** | 이중 최적 = 원시 최적(슬레이터 조건의 볼록 문제에 적용됨) |
| **이중성 격차** | 원시 최적 - 이중 최적(강한 이중성에서는 0) |
### 이중성이 중요한 이유
| 신청 | 이중성이 어떻게 도움이 되는지 |
|-------------|------|
| 하한 | Dual은 원시 솔루션이 얼마나 좋은지에 대한 인증서를 제공합니다 |
| SVM | SVM 문제의 이중성으로 인해 커널 트릭 |
| 민감도 분석 | 이중 변수는 제약 조건이 완화된 경우 최적의 변화 정도를 측정합니다 |
| 분해 | 큰 문제는 이중 |

## 정수 프로그래밍
일부 또는 모든 변수가 **정수**여야 하는 경우 문제는 훨씬 더 어려워집니다(일반적으로 NP 하드).
### 유형
| 유형 | 설명 |
|------|-------------|
| 순수 IP | 모든 변수는 정수여야 합니다 |
| 혼합 IP(MIP) | 일부 변수는 정수, 일부는 연속 |
| 바이너리 IP | {0, 1}로 제한된 변수 |
### 해결 방법
| 방법 | 아이디어 |
|---------|------|
| **분기 및 바운드** | 하위 문제로 분할, LP 완화 해결, 정리 |
| **절단면** | LP 완화를 강화하기 위해 선형 제약 조건 추가 |
| **가지와 자르기** | 절단면과 분기 결합 결합 |
| **휴리스틱** | 근사해를 위한 탐욕, 지역 검색, 시뮬레이션 어닐링 |

## 휴리스틱 및 메타휴리스틱 방법
정확한 최적화가 어려운 경우 휴리스틱은 좋은(반드시 최적은 아님) 솔루션을 찾습니다.
| 방법 | 핵심 아이디어 | 최고의 대상 |
|---------|----------|----------|
| **경사하강법** | 가장 가파른 내리막을 따라가세요 | 부드럽고 미분 가능한 함수 |
| **뉴턴의 방법** | 2차(곡률) 정보 사용 | 원활하고 조건이 잘 맞는 문제 |
| **모의 어닐링** | 확률이 감소하는 더 나쁜 솔루션을 수용 | 전역 최적화, 조합 |
| **유전 알고리즘** | 선택, 교차, 돌연변이를 사용하여 인구를 진화시킵니다 | 다중 목적, 비미분 |
| **입자 떼** | 에이전트는 가장 잘 알려진 위치의 영향을 받아 공간을 탐색합니다 | 연속, 비볼록 |
| **베이지안 최적화** | 대리 모델 구축, 획득 기능 사용 | 고가의 블랙박스 기능(초매개변수 튜닝) |
### 뉴턴의 최적화 방법
**업데이트 규칙:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
여기서 H는 헤세 행렬(2차 도함수의 행렬)입니다.
| 부동산 | 가치 |
|----------|-------|
| 수렴률 | 2차(거의 최적) |
| 반복당 비용 | 헤세 반전의 경우 O(n³) |
| 필요 | 두 번 미분 가능하고 양의 정부호 헤세 행렬 |
| 준뉴턴(BFGS) | 그라디언트에서 대략적인 헤세 행렬 | 반복당 O(n²) |

## 기계 학습 및 데이터 과학과의 관련성
| 최적화 개념 | 신청 |
|---------|-------------|
| 경사하강법 | 신경망 훈련, 로지스틱 회귀, 모든 미분 가능한 모델 |
| SGD 및 변형 | 대규모 ML(미니배치 학습), 온라인 학습 |
| 아담, RMSprop | 딥러닝을 위한 기본 옵티마이저 |
| 볼록 최적화 | SVM, 로지스틱 회귀, LASSO, Ridge(글로벌 최적 보장) |
| 라그랑주 승수 | 제한된 학습, 공정한 ML, 리소스 할당 |
| KKT 조건 | SVM 이중 도출, 제약 활동 이해 |
| 이중성 | SVM 커널 트릭, 민감도 분석, 분해 방법 |
| 선형 프로그래밍 | 자원배분, 포트폴리오 최적화, 네트워크 흐름 |
| 정수 프로그래밍 | 특징 선택(이진), 스케줄링, 조합 문제 |
| 베이지안 최적화 | 하이퍼파라미터 튜닝(Optuna, Hyperopt) |
| 뉴턴/준뉴턴 | 중소 규모 문제에 대한 2차 방법(L-BFGS) |

## 요약
| 방법 | 문제 유형 | 보증 | 규모 |
|---------|-------------|------------|-------|
| 단순 | 선형 프로그래밍 | 정확한 최적 | 수백만 개의 변수 |
| 인테리어 포인트 | 볼록형(LP, QP, SOCP) | 정확한 최적 | 대규모 |
| 경사하강법 | 제한되지 않은 부드러운 | 로컬 최소값으로 수렴 | 매우 큼(딥 러닝) |
| 싱가포르 달러 | 대규모 경험적 위험 | 수렴(붕괴 포함) | 대규모 데이터 세트 |
| 뉴턴 / BFGS | 매끄럽고 두 번 미분 가능 | 이차 수렴 | 중소규모 |
| KKT / 라그랑주 | 구속(볼록) | 조건 하에서 정확함 | 중간 |
| 분기 및 경계 | 정수 프로그래밍 | 정확한 최적 | 중소규모 |
| 휴리스틱 | 임의(비볼록, 조합) | 보증 없음 | 다양함 |
최적화는 틀림없이 기계 학습에서 가장 중요한 수학적 도구입니다. 선형 회귀에서 대규모 언어 모델에 이르기까지 학습하는 모든 모델에는 최적화 문제 해결이 포함됩니다. 문제가 볼록할 때(전역 최적 보장), 경사 하강법이 수렴할 때, 제약 조건을 처리하는 방법을 이해하면 학습 알고리즘을 설계, 디버깅 및 개선하기 위한 이론적 기반을 얻을 수 있습니다.
