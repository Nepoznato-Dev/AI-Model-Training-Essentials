# 확률론적 과정
**확률적 과정**은 시간(또는 공간)에 따라 색인이 지정된 무작위 변수의 모음입니다. 확률 이론이 개별 무작위 사건을 연구하는 반면, 확률론적 프로세스는 시간이 지남에 따라 무작위성이 어떻게 진화하는지 연구합니다. 주가, 대기열 길이, 질병 확산, 언어 생성 및 기계 학습 모델의 훈련 역학을 모델링합니다.
---

## 기초
### 정의
확률론적 과정 {X_t : t ∈ T}는 공통 확률 공간에서 정의된 확률 변수의 계열입니다. T는 **인덱스 세트**(시간)입니다.
- **이산시간:** T = {0, 1, 2, ...}
- **연속시간:** T = [0, )
**상태 공간** S는 X_t가 취할 수 있는 가능한 값의 집합입니다.
### 주요 속성
| 부동산 | 정의 |
|------------|------------|
| **정상성** | (X_{t₁}, ..., X_{tₖ})의 결합 분포는 (X_{t₁+τ}, ..., X_{tₖ+τ})와 동일 |
| **독립** | X_t는 t ≠ s에 대해 X_s와 독립 |
| **에르고딕성** | 시간 평균은 앙상블 평균으로 수렴 |
| **마르코프 속성** | 미래는 과거가 아닌 현재에만 달려 있다 |
| **마팅게일** | 기대되는 미래 가치는 현재 가치와 같습니다 |
---

## 마르코프 체인
**마르코프 체인**은 미래 상태가 현재 상태(메모리 없는 속성)에만 의존하는 확률론적 프로세스입니다.
### 이산시간 마르코프 체인(DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**전이 행렬** P에는 항목 p_{ij} = P(j로 이동 | 현재 i에 있음)가 있습니다.
| 부동산 | 성명서 |
|----------|-----------|
| 행 합계 | 각 행의 합은 1입니다. Σⱼ p_{ij} = 1 |
| n단계 전환 | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| 고정식 유통 | πP = π(고유값이 1인 왼쪽 고유벡터) |
### 상태 분류
| 기간 | 정의 |
|------|------------|
| **반복** | 체인은 확률 1로 상태 i로 복귀합니다 |
| **일시적** | 결코 돌아오지 않을 확률이 0이 아님 |
| **흡수** | p_{ii} = 1(한 번 입력하면 절대 떠나지 않음) |
| **기간** | 반환 시간의 GCD; 기간 1 = 비주기적 |
| **소통 중** | 상태 i와 j가 서로 도달할 수 있음 |
### 고정 분포
환원 불가능한 양의 순환 마르코프 체인의 경우 고정 분포 π가 존재하고 고유하며 다음을 충족합니다.
πP = π, Σᵢ πᵢ = 1
**해석:** πᵢ = 상태 i에서 보낸 시간의 장기적 비율.
**작업된 예:** 상태가 {맑음, 비)인 날씨 모델입니다.
P = [[0.9, 0.1], [0.5, 0.5]] (행: Sunny에서, Rainy에서)
고정 분포: πP = π
- π₁ = 0.9π₁ + 0.5π₂
- π₂ = 0.1π₁ + 0.5π₂
- π₁ + π₂ = 1
- 풀이: π₁ = 5/6 ≒ 0.833, π₂ = 1/6 ≒ 0.167
### 정상성으로의 수렴
환원 불가능한 비주기적 양성 순환 사슬의 경우:
- Pⁿ → Π(모든 행이 π와 동일한 행렬): n → IGHT
- **혼합 시간:** 분포가 π에 가까워질 때까지의 단계 수
- **스펙트럼 갭:** 1 − |λ²| (여기서 λ2는 두 번째로 큰 고유값임) 혼합 속도를 결정합니다.
### 연속시간 마르코프 체인(CTMC)
전환은 지수 분포에 따라 임의의 시간에 발생합니다.
| 개념 | 설명 |
|---------|-------------|
| **비율 매트릭스 Q** | i ≠ j의 경우 q_{ij} ≥ 0; q_{ii} = −Σ_{j≠i} q_{ij} |
| **전환 확률** | P(t) = e^{Qt} (행렬 지수) |
| **고정 분포** | πQ = 0 |
| **홀딩시간** | 상태 i의 시간은 Exp(−q_{ii}) |

## 무작위 걷기
**랜덤 워크**는 연속적인 무작위 단계로 형성된 경로입니다.
### 단순 랜덤 워크
X_n = X_{n-1} + Z_n, 여기서 Z_n ∈ {+1, −1}, 확률 p, q = 1−p.
| 부동산 | p = 1/2(대칭) | p ≠ 1/2(편향) |
|----------|---------|------|
| E[X_n] | 0 | n(2p−1) |
| 변형[X_n] | 엔 | 4npq |
| 원산지로 돌아가나요? | 예(확률 1) | 아니오(표류) |
| 재발? | 예(1D 및 2D) | 아니요 |
### 더 높은 차원에서의 랜덤 워크
| 차원 | 재발? | 직관 |
|------------|------------|------------|
| 1D | 예 | "술취한 남자는 항상 집으로 가는 길을 찾아낸다" |
| 2D | 예 | "술에 취한 새는 항상 집으로 돌아오는 길을 찾는다" |
| 3D+ | 아니요 | "술 취한 참새는 집으로 돌아가지 못한다" |
### 브라운 운동과의 연결
랜덤 워크 스케일링: S_n = ΣZ_i로 둡니다. 그런 다음 단계 크기 → 0 및 단계 → :
S_{⌊nt⌋} / √n → B(t) (돈스커의 정리에 의한 브라운 운동)

## 브라운 운동
**브라운 운동** (위너 과정) B(t)는 무작위 걷기의 연속 시간 제한입니다.
### 정의
B(t)는 다음을 충족합니다.
1. B(0) = 0
2. B(t)에는 연속적인 경로가 있습니다.
3. 독립 증분: B(t) − B(s)는 r < s < t인 경우 B(s) − B(r)과 독립입니다.
4. B(t) − B(s) ~ N(0, t − s) (가우스 증분)
### 주요 속성
| 부동산 | 성명서 |
|----------|-----------|
| E[B(t)] | = 0 |
| 변[B(t)] | = 티 |
| Cov[B(들), B(t)] | = 최소(초, t) |
| 어디에서도 미분할 수 없음 | 경로는 연속적이지만 파생물은 없습니다 |
| 프랙탈 차원 | 그래프에는 Hausdorff 차원이 3/2 |
| 마르코프 속성 | 미래는 현재 위치에만 의존합니다 |
| 마틴게일 | E[B(티) | F_s] = s < t인 경우 B(s) |
### 기하학적 브라운 운동
S(t) = S(0) exp((μ − σ²/2)t + σB(t))
이것은 Black-Scholes 프레임워크의 주가에 대한 표준 모델입니다.
- μ: 드리프트(기대수익률)
- σ : 변동성
---

## 포아송 과정
**포아송 과정** N(t)는 [0, t]에서 발생하는 사건의 수를 계산합니다.
### 정의
N(t) ~ Poisson(λt), 여기서 λ는 비율(단위 시간당 이벤트 수)입니다.
| 부동산 | 성명서 |
|----------|-----------|
| N(0) = 0 | — |
| 독립적인 증분 | 서로소 간격의 사건은 독립적입니다 |
| 고정 증분 | N(t+s) − N(s) ~ 포아송(λt) |
| E[N(티)] | = λt |
| 변[N(t)] | = λt |
| 도착 간 시간 | 지수분포: T_i ~ Exp(λ) |
### 일반화
| 변형 | 설명 |
|---------|-------------|
| **비균질** | 속도 λ(t)는 시간에 따라 달라집니다 |
| **복합 포아송** | 각 이벤트는 임의의 크기를 갖습니다. S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **포아송 무작위 측정** | 시간만이 아닌 시공간 속의 포인트 |
| **다변수** | 상호작용이 가능한 다양한 이벤트 유형 |
---

## 마틴게일스
**마팅게일**은 공정한 게임입니다. 현재의 모든 정보를 바탕으로 예상되는 미래 가치는 현재 가치와 같습니다.
### 정의
{X_n}은 다음과 같은 경우 필터링 {F_n}에 관한 마틴게일입니다.
1. X_n은 F_n 측정 가능(적응됨)
2. E[|X_n|] < (적분 가능)
3. E[X_{n+1} | F_n] = X_n (공정한 게임)
| 변형 | 조건 | 통역 |
|---------|------------|---|
| **마팅게일** | E[X_{n+1} | F_n] = X_n | 공정한 게임 |
| **서브마틴게일** | E[X_{n+1} | F_n] ≥ X_n | 호조게임(상승세) |
| **슈퍼마틴게일** | E[X_{n+1} | F_n] ≤ X_n | 불리한 게임(하향 추세) |
### 핵심 정리
| 정리 | 성명서 |
|---------|------------|
| **선택적 중지** | 정지 시간 T |
| **융합** | 제한된 마틴게일은 거의 확실하게 수렴합니다 |
| **최대 불평등** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (두브스) |

## 몬테카를로 방법
**몬테카를로 방법**은 무작위 샘플링을 사용하여 결정론적 수량을 추정합니다.
### 기본 아이디어
X ~ P인 경우 E[f(X)]를 추정하려면 다음을 수행합니다.
1. P에서 N개의 샘플을 추출합니다: x₁, x2, ..., x_N
2. 계산: Î = (1/N) Σᵢ f(xᵢ)
3. 대수의 법칙: Î → E[f(X)] as N →
**오류:** 표준 오류 = σ_f / √N, 여기서 σ_f² = Var[f(X)]
### 분산 감소 기술
| 기술 | 아이디어 | 속도 향상 |
|------------|------|---------|
| **중요도 샘플링** | P 대신 Q에서 샘플, P/Q별 가중치 | 극적일 수 있다 |
| **대립 변이** | 쌍 (x, −x)을 사용하여 분산 취소 | ~2배 |
| **제어 변수** | f와 상관관계가 있는 알려진 기대 함수 빼기 | 다양함 |
| **계층화된 샘플링** | 도메인 분할, 각 지층 샘플링 | 변동 감소 |
| **라오-블랙웰** | 충분한 통계의 조건 | 항상 도움이 됩니다 |
---

## 마르코프 체인 몬테카를로(MCMC)
MCMC는 고정 분포가 목표 분포인 마르코프 체인을 구성합니다. "번인(burn-in)" 기간이 지나면 샘플이 대상에서 대략적으로 추출됩니다.
### 메트로폴리스-헤이스팅스 알고리즘
| 단계 | 액션 |
|------|---------|
| 1 | 현재 상태: x_t |
| 2 | 제안: x* ~ q(x* \| x_t) (제안 분포) |
| 3 | 합격률: α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | 확률 α로 수락: x_{t+1} = x*(수락) 또는 x_t(거부) |
**특수 사례 — 메트로폴리스 알고리즘:** 대칭 제안 q(x*|x) = q(x|x*), 따라서 α = min(1, π(x*)/π(x_t)).
### 깁스 샘플링
각 변수가 전체 조건부 분포에서 업데이트되는 Metropolis-Hastings의 특수 사례입니다.
목표 π(x₁, x2, ..., xₖ)의 경우:
1. 샘플 x₁^{(t+1)} ~ π(x₁ | x²^{(t)}, ..., xₖ^{(t)})
2. 샘플 x2^{(t+1)} ~ π(x2 | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. 모든 변수에 대해 계속
4. 반복
| 부동산 | 성명서 |
|----------|-----------|
| 항상 받아들인다 | α = 1(거부 단계 없음) |
| 필요 | 각각의 전체 조건부에서 샘플링하는 기능 |
| 융합 | 환원 불가능한 비주기적 체인에 대해 보장됨 |
### MCMC 진단
| 진단 | 목적 |
|------------|---------|
| **추적 플롯** | 혼합 및 정상성에 대한 육안 검사 |
| **자기상관** | 샘플 의존성 측정(낮은 자기상관 필요) |
| **겔만-루빈(R̂)** | 여러 체인을 비교하세요. R̂ < 1.05는 수렴을 제안합니다 |
| **유효 표본 크기** | N_eff = N / (1 + 2Σρₖ); 자기 상관에 대한 계정 |
| **번인** | 체인이 정상 상태에 도달하기 전에 초기 샘플 폐기 |
