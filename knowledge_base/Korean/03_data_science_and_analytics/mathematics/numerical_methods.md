# 수치해석법
수치적 방법은 수학적 이론과 실제 계산 사이의 가교 역할을 합니다. 순수 수학은 해가 존재한다는 것을 증명하는 반면, 수치적 방법은 실제로 유한 정밀도에 대한 대략적인 답을 계산합니다. 모든 기계 학습 모델, 물리 시뮬레이션 및 데이터 분석 파이프라인은 궁극적으로 수치 계산에 의존합니다. 이러한 방법(정확성, 안정성 및 한계)을 이해하는 것은 안정적인 소프트웨어를 구축하는 데 필수적입니다.

## 부동 소수점 산술
컴퓨터는 유한한 정밀도로 실수를 나타냅니다. **IEEE 754 표준**은 부동 소수점 숫자가 저장되고 조작되는 방법을 정의합니다.
### IEEE 754 형식
| 형식 | 비트 | 지수 | 가수 | 대략적인 십진수 | 범위 |
|---------|------|----------|----------|--------------|---------|
| 하프(fp16) | 16 | 5 | 10 | 3.3 | ±6.5 × 10⁴ |
| 싱글(fp32) | 32 | 8 | 23 | 7.2 | ±3.4 × 10³⁸ |
| 더블(fp64) | 64 | 11 | 52 | 15.9 | ±1.8 × 10³⁰⁸ |
### 머신 엡실론
**머신 엡실론**(ε_mach)은 부동 소수점에서 1 + ε_mach > 1이 되는 가장 작은 숫자입니다.
| 형식 | ε_마하 |
|---------|---------|
| fp16 | 2⁻¹⁰ ⁻ 9.8 × 10⁻⁴ |
| fp32 | 2⁻²³ ≒ 1.2 × 10⁻⁻ |
| fp64 | 2⁻⁵² ≒ 2.2 × 10⁻¹⁶ |
### 일반적인 함정
| 함정 | 예 | 결과 |
|---------|---------|-------------|
| **재난적인 취소** | 작은 x에 대해 (1 + x) − 1 계산 | 유효 자릿수 손실 |
| **흡수** | fp32에서는 10⁸ + 1 = 10⁸ | 큰 금액으로 인해 작은 가치가 손실됨 |
| **비연관성** | (a + b) + c ≠ a + (b + c) | 합계 순서가 중요합니다 |
| **영점에 가까운 나눗셈** | 1 / 10⁻³⁰⁰ → 오버플로 | 무한대 또는 NaN |
### 완화 전략
| 전략 | 설명 |
|----------|-------------|
| **카한 요약** | 흡수 오류를 줄이기 위한 보상된 합산 |
| **카한-바부스카-노마이어** | Kahan 합계의 향상된 버전 |
| **정렬된 요약** | 흡수를 피하기 위해 먼저 작은 숫자의 합 |
| **더블-더블 산술** | 확장된 정밀도를 위해 복식 쌍 사용 |
| **컨디셔닝 분석** | 문제 자체가 오류를 증폭시키는지 이해하기 |

## 루트 찾기
f(x) = 0이 되는 x를 구합니다.
### 이분법
| 부동산 | 가치 |
|----------|-------|
| 필요 | f 연속, f(a) 및 f(b)는 반대 부호를 갖습니다 |
| 융합 | 선형(오류는 각 단계를 절반으로 줄임) |
| 보장되나요? | 예 — 항상 수렴 |
| d 자리 반복 | ₁₀(2) ₁ d / log₁₀(2) ₁ 3.32d |
**알고리즘:**
1. f(a) · f(b) < 0인 구간 [a, b]로 시작합니다.
2. 중간점 c 계산 = (a + b) / 2
3. f(c) = 0 또는 |b − a| < 관용, 그만
4. f(a) · f(c) < 0이면 b = c로 설정합니다. 그렇지 않으면 a = c로 설정
5. 반복
### 뉴턴-랩슨 방법
| 부동산 | 가치 |
|----------|-------|
| 필요 | f 미분 가능, f'(x) ≠ 루트에서 0 |
| 융합 | 2차(루트 근처) |
| 보장되나요? | 아니요 — 분기되거나 순환될 수 있습니다 |
| 업데이트 규칙 | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**실제 예:** f(x) = x² − 2 = 0을 풀어 √2를 구합니다.
- f'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x² = 1.4167 − (2.0069 − 2) / 2.8333 = 1.4142
- x₃ = 1.41421356... (소수점 8자리까지 정확함)
### 시컨트 방법
뉴턴의 방법과 비슷하지만 도함수에 가깝습니다.
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
| 부동산 | 가치 |
|----------|-------|
| 융합 | 초선형(차수 1.618, 황금비) |
| 필요 | 두 가지 초기 추측(미분 필요 없음) |
### 근 찾기 방법 비교
| 방법 | 융합 | 파생 상품이 필요합니까? | 보장되나요? | 단계당 비용 |
|---------|-------------|------|-------------|---------------|
| 이등분 | 선형(1) | 아니요 | 예 | 1개의 함수 평가 |
| 뉴턴-랩슨 | 이차(2) | 예 | 아니요 | 2개의 함수 평가 |
| 시컨트 | 초선형(1.618) | 아니요 | 아니요 | 1개의 함수 평가 |
| 브렌트의 방법 | 초선형 | 아니요 | 예 | 다양함 |
**브렌트 방법**은 이등분(수렴 보장)과 할선/역 2차 보간(빠른 수렴)을 결합합니다. 이는 대부분의 숫자 라이브러리에서 기본 루트 찾기입니다.

## 수치 적분(구적법)
대략적으로 ∫ₐᵇ f(x) dx를 계산합니다.
### 방법
| 방법 | 공식 | 오류 | 주문 |
|---------|---------|-------|-------|
| **직사각형(중간점)** | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **사다리꼴** | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **심슨의 1/3** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | 오(h⁴) | 3 |
| **심슨의 3/8** | 4개의 동일한 간격의 점을 사용합니다 | 오(h⁴) | 4 |
| **가우스 구적법** | 최적의 노드 배치 | O(h²ⁿ) | n 포인트 |
### 복합 규칙
너비 h = (b−a)/n의 n개 하위 구간에 대해:
| 규칙 | 복합 공식 | 오류 |
|------|------|-------|
| 복합 사다리꼴 | h[f(a)/2 + Σf(xᵢ) + f(b)/2] | O(h²) |
| 복합 심슨의 | h/3[f(a) + 4Σf(홀수) + 2Σf(짝수) + f(b)] | 오(h⁴) |
**실제 예:** n = 4인 복합 사다리꼴을 사용하여 대략 ∫₀¹ e^(−x²) dx를 구합니다.
- h = 0.25, 포인트: 0, 0.25, 0.5, 0.75, 1
- f(0) = 1, f(0.25) = 0.9394, f(0.5) = 0.7788, f(0.75) = 0.5698, f(1) = 0.3679
- T = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- 참값: ≒ 0.7468 (오차 ≒ 0.5%)
### 적응형 구적법
함수가 급격하게 변하는 간격을 자동으로 세분화하고, 매끄러운 부분에서는 더 적은 수의 점을 사용합니다. `scipy.integrate.quad`가 사용하는 것입니다(QUADPACK 기준).

## 보간
알려진 데이터 포인트 사이의 값을 추정합니다.
### 방법
| 방법 | 설명 | 부드러움 | 진동 |
|---------|---------------|------------|-------------|
| **가장 가까운 이웃** | 가장 가까운 데이터 포인트 사용 | 불연속 | 없음 |
| **선형** | 점을 직선으로 연결 | C⁰(연속) | 없음 |
| **다항식(라그랑주)** | 모든 점을 통과하는 단일 다항식 | C^엔드 | 여러 점에서 심함(룽게 현상) |
| **큐빅 스플라인** | 조각별 입방체, 관절 부분이 매끄러움 | C² | 최소 |
| **방사형 기준 기능** | 방사형 커널의 가중 합계 | 커널에 따라 다름 | 낮음 |
### 라그랑주 보간
n+1개의 점 (x₀, y₀), ..., (xₙ, yₙ)이 주어지면 모든 점을 통과하는 ≤ n 차의 고유 다항식은 다음과 같습니다.
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**룬지 현상:** 동일한 간격의 점에서 높은 수준의 다항식 보간은 가장자리 근처에서 격렬하게 진동할 수 있습니다. Chebyshev 노드 또는 스플라인을 사용하여 완화됩니다.
### 큐빅 스플라인
C² 연속(연속 2차 도함수)인 조각별 3차 다항식입니다.
| 유형 | 경계조건 |
|------|------|
| 자연 스플라인 | S''(x₀) = S''(xₙ) = 0 |
| 고정된 스플라인 | S'(x₀) 및 S'(xₙ) 지정 |
| 매듭이 아닌 | x₁ 및 xₙ₋₁에서 연속 3차 도함수 |

## ODE 해결사
상미분방정식 dy/dt = f(t, y)를 수치적으로 풀기.
### 오일러의 방법
가장 간단한 ODE 솔버.
**업데이트:** y_{n+1} = y_n + h · f(t_n, y_n)
| 부동산 | 가치 |
|----------|-------|
| 주문 | 1(단계당 오류: O(h²), 전역: O(h)) |
| 안정성 | 조건부 안정(작은 h 필요) |
| 비용 | 단계당 1개의 기능 평가 |
### Runge-Kutta 방법
| 방법 | 주문 | 스테이지 | 메모 |
|---------|---------|---------|-------|
| **오일러** | 1 | 1 | 가장 단순한 |
| **중간점** | 2 | 2 | 더 나은 정확성 |
| **헌스(RK2)** | 2 | 2 | 예측-수정자 |
| **클래식 RK4** | 4 | 4 | 표준 주력 |
| **휴면-프린스(RK45)** | 4(5) | 6 | 적응형 단계 크기(ode45에서 사용됨) |
### 클래식 RK4(4차 Runge-Kutta)
k₁ = f(t_n, y_n)
k² = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk²/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k² + 2k₃ + k₄) / 6
| 부동산 | 가치 |
|----------|-------|
| 주문 | 4(전역 오류: O(h⁴)) |
| 비용 | 단계당 4가지 기능 평가 |
| 안정성 | 오일러보다 훨씬 낫습니다 |
| 사용법 | 비경직성 ODE에 대한 기본값 |
### 엄격한 ODE
**딱딱한** ODE에는 매우 다양한 시간 척도에 따라 달라지는 구성요소가 있습니다. 명시적 방법(Euler, RK4)에는 비현실적으로 작은 단계 크기가 필요합니다.
| 방법 | 유형 | 안정성 |
|---------|------|------------|
| 암시적 오일러 | 암시적 | A-안정(무조건 안정) |
| 역미분 공식(BDF) | 암시적 | A-안정(최대 5개) |
| 암시적 Runge-Kutta | 암시적 | L-안정 변형이 존재합니다 |
| 엘소다 | 자동 | 뻣뻣함/비뻣뻣함 간 전환 |

## 수치 안정성 및 컨디셔닝
### 조건 번호
**조건수**는 입력의 작은 변화에 비해 문제의 출력이 얼마나 변하는지를 측정합니다.
선형 시스템의 경우 Ax = b: κ(A) = ||A|| · ||A⁻¹||
| κ(A) | 통역 |
|-------|---------------|
| ≒ 1 | 좋은 조건 |
| 10³ | 약간 민감함 |
| 10⁸ | 조건이 좋지 않음(정확도가 최대 8자리 손실됨) |
| → | Singular(고유한 솔루션 없음) |
### 알고리즘의 안정성
입력의 작은 섭동이 출력의 작은 섭동으로 이어지는 경우(문제의 조건 수에 비해) 알고리즘은 **수치적으로 안정적**입니다.
| 알고리즘 | 안정적인? | 메모 |
|------------|---------|-------|
| 부분 피벗팅을 사용한 가우스 소거 | 예 | 표준 접근 방식 |
| QR을 통한 고유값 계산 | 예 | 뒤로 안정 |
| 순진한 합산(큰 + 작은 것부터) | 아니요 | Kahan 합계 사용 |
| 분산을 E[X²] − (E[X])² | 잠재적으로 아니오 | Welford의 온라인 알고리즘 사용 |
### Welford의 온라인 알고리즘
연속 평균 및 분산의 수치적으로 안정적인 계산:
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

이는 순진한 2단계 공식에서 발생하는 치명적인 취소를 방지합니다.
