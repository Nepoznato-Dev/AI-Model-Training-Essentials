# 전자기학
전자기학은 전기장과 자기장 및 이들의 상호 작용을 연구하는 학문입니다. 전자기학은 1860년대 맥스웰에 의해 통합되어 빛, 전기, 자기, 전파 및 원자 구조를 설명합니다. 이는 수학적으로 완전히 이해된 최초의 기본 힘이었으며, 그 방정식은 아인슈타인의 특수 상대성 이론과 현대 장 이론에 영감을 주었습니다.
---

## 전기장
### 쿨롱의 법칙
거리 r로 분리된 두 점전하 q₁ 및 q² 사이의 힘:
**F** = (1/4πε₀) · (q₁q²/r²) · r̂
| 상수 | 가치 |
|----------|-------|
| ε₀(자유 공간의 유전율) | 8.854 × 10⁻¹² F/m |
| 1/4πε₀(쿨롱 상수 k) | 8.988 × 10⁹ N·m²/C² |
### 전기장 정의
**E** = **F**/q(단위 전하당 힘)
포인트 요금 Q의 경우: **E** = (1/4πε₀) · (Q/r²) · r̂
### 전기력선
| 부동산 | 규칙 |
|------------|------|
| 방향 | 양전하에서 벗어나 음전하를 향하여 |
| 밀도 | 더 가까운 선 = 더 강한 필드 |
| 횡단 | 필드 라인은 절대 교차하지 않습니다 |
| 지휘자 | 선이 표면을 수직으로 만납니다 |
### 전위(전압)
V = −∫ **E** · d**l** (전위차는 E의 음의 선적분입니다)
**E** = −∇V(장은 음의 전위 변화도임)
포인트 요금의 경우: V = (1/4πε₀) · Q/r
| 개념 | 공식 | 단위 |
|---------|---------|------|
| 잠재적 에너지 | 유 = qV | 줄 |
| 전자 볼트 | 1eV = 1.602 × 10⁻¹⁹ J | 에너지 단위 |
| 등전위면 | V가 일정한 표면 | E는 그것에 수직이다 |

## 가우스의 법칙
### 성명
닫힌 표면을 통과하는 총 전기속은 둘러싸인 전하를 ε₀로 나눈 값과 같습니다.
∮ **E** · d**A** = Q_enc / ε₀
미분 형식: ∇ · **E** = ρ/ε₀
### 가우스 법칙 사용
가우스의 법칙은 대칭이 E를 적분에서 빼낼 수 있을 때 가장 유용합니다.
| 대칭 | 가우스 표면 | 결과 |
|----------|------|--------|
| 구형 | 구체 | E = Q/(4πε₀r²) 외부 |
| 원통형(라인 충전) | 실린더 | E = λ/(2πε₀r) |
| 평면(무한 시트) | 필박스 | E = σ/(2ε₀) |
| 평행판 사이 | 필박스 | E = σ/ε₀ |
---

## 도체 및 커패시터
### 정전기 평형 상태의 도체
| 부동산 | 설명 |
|----------|-------------|
| E = 0 내부 | 내부 필드를 취소하기 위해 요금을 재정렬 |
| 표면의 모든 전하 | 내부 순요금 없음 |
| E 표면에 수직 | 접선 성분 없음(그렇지 않으면 전하 이동) |
| 전체적으로 등전위 | 내부와 표면 어디에서나 동일한 V |
### 커패시터
**커패시터**는 두 도체 사이의 전기장에 에너지를 저장합니다.
| 구성 | 정전용량 |
|---------------|-------------|
| 평행판 | C = ε₀A/d |
| 원통형 | C = 2πε₀L / ln(b/a) |
| 구형 | C = 4πε₀ab / (b−a) |
| 공식 | Expression |
|---------|------------|
| Charge-voltage | Q = CV |
| Energy stored | U = ½CV² = ½Q²/C |
| Energy density | u = ½ε₀E² |
| Series combination | 1/C_total = 1/C₁ + 1/C² + ... |
| Parallel combination | C_total = C₁ + C₂ + ... |
### 유전체
κ가 일정한 유전체(절연재)를 삽입하면 정전 용량이 증가합니다. C = κC₀.

## 자기장
### 자기력
**F** = q(**v** × **B**) (로렌츠 힘, 자기 성분)
| 부동산 | 성명서 |
|----------|-----------|
| 방향 | v와 B 모두에 수직(오른손 법칙) |
| 작업 완료 | 0(힘은 속도에 수직임) |
| 원형 운동 | 균일한 B 필드의 반경 r = mv/(qB) |
### 비오-사바르 법칙
작은 전류 요소로 인한 자기장:
d**B** = (μ₀/4π) · I(d**l** × r̂) / r²
| 상수 | 가치 |
|----------|-------|
| μ₀(자유공간 투자율) | 4π × 10⁻⁷ T·m/A |
### 앙페르의 법칙
∮ **B** · d**l** = μ₀I_enc
미분 형식: ∇ × **B** = μ₀**J**
**애플리케이션:**
| 구성 | B 필드 |
|---------------|---------|
| 긴 직선 와이어 | B = μ₀I/(2πr) |
| 솔레노이드(내부) | B = μ₀nI |
| 토로이드(내부) | B = μ₀NI/(2πr) |
---

## 전자기 유도
### 패러데이의 법칙
변화하는 자속은 기전력(EMF)을 유도합니다.
EMF = -dΦ_B/dt
여기서 Φ_B = ∫ **B** · d**A**는 자속입니다.
미분 형식: ∇ × **E** = −∂**B**/∂t
**렌츠의 법칙:** 유도된 EMF는 자속 변화(마이너스 기호)에 반대됩니다.
### 유도의 응용
| 신청 | 원리 |
|-------------|------------|
| 발전기 | B 필드의 코일 회전 → EMF 교번 |
| 변압기 | 1차측 전류 변경 → 2차측 EMF |
| 인덕터 | 전류 변화에 반대: EMF = −L(dI/dt) |
| 와전류 | 벌크 도체의 유도 전류(제동, 가열) |
### 인덕터
| 공식 | 표현 |
|---------|------------|
| 플럭스 결합 | Φ = 리 |
| 저장된 에너지 | U = ½LI² |
| 시리즈 조합 | L_total = L₁ + L² + ... |
| 병렬결합 | 1/L_total = 1/L₁ + 1/L² + ... |
---

## 맥스웰 방정식
맥스웰의 방정식은 전기와 자기를 하나의 이론으로 통합합니다.
### 일체형으로
| 방정식 | 이름 | 성명서 |
|------------|------|------------|
| ∮ **E** · d**A** = Q/ε₀ | 가우스의 법칙(전기) | 전기속 = 밀폐전하 |
| ∮ **B** · d**A** = 0 | 가우스의 법칙(자기) | 자기 단극 없음 |
| ∮ **E** · d**l** = −dΦ_B/dt | 패러데이의 법칙 | B를 변경하면 E |
| ∮ **B** · d**l** = μ₀I + μ₀ε₀ dΦ_E/dt | 암페어-맥스웰 법칙 | 현재 및 변화하는 E는 B를 생산합니다 |
### 차등 형식
| 방정식 | 이름 | 표현 |
|------------|------|------------|
| 가우스(전기) | ∇ · **E** = ρ/ε₀ |
| 가우스(자기) | ∇ · **B** = 0 |
| 패러데이 | ∇ × **E** = −∂**B**/∂t |
| 암페어-맥스웰 | ∇ × **B** = μ₀**J** + μ₀ε₀ ∂**E**/∂t |
### 변위 전류
Maxwell의 주요 추가 사항: 용어 μ₀ε₀ ∂**E**/∂t(변위 전류). 이는 전하 보존을 보장하고 전자파를 예측합니다.
---

## 전자기파
진공(전하 없음, 전류 없음)에서 Maxwell 방정식은 파동 방정식을 생성합니다.
∇²**E** = μ₀ε₀ ∂²**E**/∂t²
∇²**B** = μ₀ε₀ ∂²**B**/∂t²
**빛의 속도:** c = 1/√(μ₀ε₀) ≒ 3 × 10⁸ m/s
### EM파의 속성
| 부동산 | 설명 |
|----------|-------------|
| 가로 | E와 B는 서로 수직이며 전파 방향에 |
| 단계 | E와 B가 동시에 최대값에 도달 |
| 크기 비율 | E = CB |
| 에너지 플럭스 | S = (1/μ₀)**E** × **B** (포인팅 벡터) |
| 강도 | I = ⟨S⟩ = E₀²/(2μ₀c) |
### 전자기 스펙트럼
| 유형 | 파장 | 빈도 | 소스 |
|------|-------------|----------|---------|
| 라디오 | > 1m | < 300 MHz | Antennas |
| Microwave | 1 mm − 1 m | 300 MHz − 300 GHz | Magnetrons, klystrons |
| Infrared | 700 nm − 1 mm | 300 GHz − 430 THz | Thermal radiation |
| Visible | 400 − 700 nm | 430 − 750 THz | Atomic transitions |
| Ultraviolet | 10 − 400 nm | 750 THz − 30 PHz | Hot objects, stars |
| X-ray | 0.01 − 10 nm | 30 PHz − 30 EHz | Electron deceleration |
| Gamma ray | < 0.01 nm | >30EHz | 핵 공정 |

## AC 회로
### RLC 회로 구성 요소
| 구성요소 | 전압-전류 관계 | 임피던스 |
|------------|------------|----------|
| 저항기(R) | V = IR | Z_R = R |
| 인덕터(L) | V = L(dI/dt) | Z_L = jΩL |
| 커패시터(C) | 나는 = C(dV/dt) | Z_C = 1/(jΩC) |
### 임피던스와 공명
총 임피던스(RLC 계열): Z = R + j(ΩL − 1/ΩC)
|오| = √(R² + (ΩL − 1/ΩC)²)
**공명:** ΩL = 1/ΩC → Ω₀ = 1/√(LC)인 경우
- 공진 시: 임피던스는 최소(= R), 전류는 최대
- **품질 인자:** Q = Ω₀L/R(공진의 선명도)
### AC 회로의 전원
| 수량 | 공식 |
|------------|---------|
| 평균 전력 | P_avg = V_rms · I_rms · cos ψ |
| 역률 | cos Φ = R/\|Z\| |
| RMS 전압 | V_rms = V₀/√2 |

| 커패시터/인덕터 | 신경망을 위한 아날로그 컴퓨팅, 뉴로모픽 하드웨어 |

| 벡터 미적분학(∇·, ∇×) | ML 이론 전반에 걸쳐 사용되는 필수 수학 도구 |

## 요약
| 법률 | 그것이 말하는 것 | 차등 형태 |
|------|-------------|------|
| 가우스(전기) | 전하는 전기장 발산을 생성합니다 | ∇ · E = ρ/ε₀ |
| 가우스(자기) | 자기 단극 없음 | ∇ · B = 0 |
| 패러데이 | B를 변경하면 컬링 E가 생성됨 | ∇ × E = −∂B/∂t |
| 암페어-맥스웰 | 현재와 ​​변화하는 E는 컬링 B를 만든다 | ∇ × B = μ₀J + μ₀ε₀∂E/∂t |
전자기학은 지금까지 구축된 물리이론 중 가장 완벽하고 검증된 이론입니다. 단 4개의 방정식으로 정전기부터 빛, 지금까지 제작된 모든 전자 장치의 동작에 이르기까지 모든 것을 설명합니다. 데이터 과학자에게 전자기학을 이해하면 파동 현상, 벡터 미적분학, 모든 최신 컴퓨팅 하드웨어의 기초가 되는 물리학에 대한 깊은 직관을 얻을 수 있습니다.
