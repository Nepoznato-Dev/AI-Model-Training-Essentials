# 동적 시스템
**동적 시스템**은 고정된 규칙에 따라 시간이 지남에 따라 상태가 어떻게 발전하는지 설명합니다. 행성 궤도에서 인구 역학, 날씨 패턴에서 신경망 훈련에 이르기까지 역학 시스템 이론은 사물이 어떻게 변화하는지 이해하기 위한 언어와 도구를 제공합니다. 이 파일은 상미분 방정식(ODE), 편미분 방정식(PDE), 안정성 분석, 혼돈 및 분기를 다룹니다.
---

## 상미분 방정식(ODE)
ODE는 함수를 단일 독립 변수(보통 시간)에 대한 도함수와 연관시킵니다.
### 분류
| 부동산 | 유형 |
|----------|-------|
| **주문** | 현재 가장 높은 도함수(1차, 2차 등) |
| **선형 대 비선형** | 선형: y'' + p(t)y' + q(t)y = g(t); 비선형: 기타 |
| **동질성** | g(t) = 0(강제항 없음) |
| **자율** | 명시적인 시간 의존성 없음: dy/dt = f(y) |
| **상수 계수** | p, q는 상수입니다 |
### 1차 ODE
**일반 형식:** dy/dt = f(t, y)
| 유형 | 양식 | 해결 방법 |
|------|------|----|
| 분리 가능 | dy/dt = g(t)h(y) | 분리 및 적분: ∫dy/h(y) = ∫g(t)dt |
| 선형 1차 | dy/dt + p(t)y = q(t) | 적분 인자: μ(t) = e^(∫p dt) |
| 정확 | M(t,y)dt + N(t,y)dy = 0, ∂M/∂y = ∂N/∂t | 잠재적인 함수 F(t,y) 찾기 |
| 베르누이 | dy/dt + p(t)y = q(t)yⁿ | v = y^(1−n)을 대체하여 선형화 |
**실제 예(적분 인자):** dy/dt + 2y = e^(−t), y(0) = 1을 풉니다.
- 적분 인자: μ(t) = e^(∫2 dt) = e^(2t)
- 곱셈: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- 적분: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- 초기 조건: y(0) = 1 → 1 = 1 + C → C = 0
- 해: y(t) = e^(−t)
### 2차 선형 ODE
**일반 형식:** ay'' + by' + cy = g(t)
**균질 사례** (g ​​= 0): 특성 방정식 ar² + br + c = 0을 풉니다.
| 판별자 | 뿌리 | 일반 솔루션 |
|-------------|-------|------|
| b² > 4ac(과감쇠) | 두 개의 서로 다른 실수 r₁, r₂ | y = C₁e^(r₁t) + C²e^(r²t) |
| b² = 4ac(임계 감쇠) | 반복되는 실수 루트 r | y = (C₁ + C²t)e^(rt) |
| b² < 4ac(감쇠 부족) | 복소수 근 α ± βi | y = e^(αt)(C₁ cos βt + C² sin βt) |
**물리적 해석:** 질량-스프링-댐퍼 시스템 mx'' + bx' + kx = 0.
- 오버댐핑: 강한 댐핑, 진동 없음(도어 클로저)
- 극도로 감쇠: 진동 없이 가장 빠른 복귀(자동차 서스펜션 설계 목표)
- Underdamped: 진폭이 감소하면서 진동합니다(기타 스트링).
### ODE 시스템
많은 실제 시스템에는 여러 상호 작용 변수가 포함됩니다.
dx/dt = f(x, y)
dy/dt = g(x, y)
이는 벡터 형식으로 작성할 수 있습니다: d**x**/dt = **F**(**x**)
**선형 시스템:** d**x**/dt = A**x**, 여기서 A는 행렬입니다.
해는 A의 고유값에 따라 달라집니다.
| 고유값 | 행동 |
|-------------|------------|
| 모두 실제, 부정 | 안정 노드(모든 궤적이 원점으로 수렴) |
| 실제적이고 긍정적인 | 불안정한 노드 |
| 실제 반대 표지판 | 안장점(불안정) |
| 복잡한 음의 실수부 | 안정된 나선형(감쇠진동) |
| 복잡한 양의 실수부 | 불안정한 나선 |
| 순수한 상상 | 중심(폐쇄궤도) |

## 위상 초상화
**단계 초상화**는 상태 공간에서 동적 시스템의 궤적을 시각화합니다(명시적으로 해결하지 않음).
### 주요 기능
| 기능 | 설명 |
|---------|-------------|
| **고정점(평형)** | 여기서 dx/dt = 0(동작 없음) |
| **궤적** | 상태 공간에서 시스템이 추적하는 경로 |
| **널라인** | 한 성분의 도함수가 0인 곡선 |
| **한계주기** | 고립된 폐쇄 궤도(자립 진동) |
| **매력의 유역** | 주어진 어트랙터로 이어지는 초기 조건 세트 |
| **세퍼트릭스** | 서로 다른 유역 사이의 경계 |
### 포식자-피식자 모델(Lotka-Volterra)
dx/dt = αx − βxy(먹이)
dy/dt = δxy − γy (포식자)
**고정 포인트:**
1. (0, 0) - 소멸(안장점)
2. (γ/δ, α/β) — 공존(중앙 — 닫힌 궤도)
시스템은 주기적인 진동을 나타냅니다. 먹이 증가 → 포식자 증가 → 먹이 감소 → 포식자 감소 → 주기가 반복됩니다.

## 안정성 분석
### 선형 안정성
고정점 x*에 대해 그 주위를 선형화합니다. u = x − x*라고 하고 du/dt ≒ J(x*)u입니다. 여기서 J는 야코비 행렬입니다.
**안정성 기준:** 고정점은 다음과 같습니다.
- J의 모든 고유값이 음의 실수부를 갖는 경우 **안정**
- **불안정** 고유값에 양의 실수부가 있는 경우
- 고유값에 실수부가 0인 경우 **약간 안정적**입니다(비선형 분석 필요).
### 리아푸노프 안정성
**Lyapunov의 직접 방법**은 선형화 없이 안정성을 결정합니다.
**Lyapunov 함수** V(x)는 다음을 충족합니다.
1. x ≠ x*에 대해 V(x*) = 0 및 V(x) > 0(양의 정부호)
2. 궤적을 따라 dV/dt ≤ 0(증가하지 않음)
| 조건 | 결론 |
|------------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | 불안정 |
**실제 예:** 시스템 dx/dt = −x + y², dy/dt = −y.
- V(x,y) = x² + y²(에너지 유사 함수)를 시도해 보세요.
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- 원점 근처: dV/dt ≒ −2x² − 2y² < 0(작은 y의 경우 −2y²가 지배적임)
- 결론: 원점은 국소적으로 점근적으로 안정하다

## 카오스 이론
**혼돈**은 결정적이지만 예측할 수 없습니다. 시스템은 정확한 규칙을 따르지만 초기 조건의 작은 차이로 인해 결과가 크게 달라집니다.
### 카오스 요구 사항
| 부동산 | 설명 |
|----------|-------------|
| 결정적 | 임의성 없음 - 정확한 방정식에 의해 제어됨 |
| 초기 조건에 민감 | 주변 궤적이 기하급수적으로 갈라집니다 |
| 경계 | 궤적은 무한대로 탈출하지 않습니다 |
| 비주기적 | 정확하게 반복하지 않음 |
### 로렌츠 시스템
결정론적 혼돈의 전형적인 예:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
표준 매개변수 σ = 10, ρ = 28, β = 8/3:
- 시스템에는 3개의 고정점이 있으며 모두 불안정합니다.
- 궤적은 한 고정 지점을 공전하다가 갑자기 다른 고정 지점으로 전환됩니다.
- 결과는 **로렌츠 어트랙터**입니다. 프랙탈 구조를 가진 이상한 어트랙터입니다.
**리아푸노프 지수:** 근처 궤적의 발산율을 측정합니다.
- 양의 리아푸노프 지수 → 혼돈
- 표준 매개변수를 사용하는 로렌츠 시스템의 경우: 최대 지수 ≒ 0.9 > 0
### 물류 지도
혼돈을 나타내는 단순한 이산 시스템:
x_{n+1} = rx_n(1 − x_n)
| 매개변수 r | 행동 |
|-------------|------------|
| 0 < r < 1 | 인구가 죽는다(x → 0) |
| 1 < r < 3 | x = 1 − 1/r에서 안정적인 고정점 |
| 3 < r < 3.449 | 주기-2 진동 |
| 3.449 < r < 3.544 | 4주기 진동 |
| 3.544 < r < 3.570 | 주기-8, 16, 32, ...(주기를 두 배로 늘리는 캐스케이드) |
| r ≒ 3.570 | 혼돈의 시작 |
| 3.570 < r < 4 | 주기적인 창이 있어 대부분 혼란스럽습니다. |
| r = 4 | [0, 1]에서 완전히 혼란스러운 상태 |
### 나비효과
초기 조건에 대한 민감한 의존성을 나타내는 유명한 이름입니다. 로렌츠 방정식으로 모델링된 기상 시스템에서는 브라질에서 날개를 펄럭이는 나비가 텍사스에서 토네이도를 일으킬 수 있습니다. 이는 나비가 토네이도를 일으키기 때문이 아니라 작은 섭동이 기하급수적으로 커지기 때문입니다.

## 분기 이론
**분기**는 매개변수가 변경됨에 따라 시스템 동작이 질적으로 변화하는 것입니다.
### 분기 유형
| 분기 | 정규형 | 무슨 일이 일어나는지 |
|-------------|-------------|--------------|
| **새들 노드** | dx/dt = r − x² | 두 개의 고정점이 나타나거나 사라짐 |
| **초임계** | dx/dt = rx − x² | 두 개의 고정점 교환 안정성 |
| **갈퀴(초임계)** | dx/dt = rx − x³ | 하나의 안정적인 포인트는 두 개의 안정적인 포인트 + 하나의 불안정한 포인트로 분할됩니다 |
| **갈퀴(아임계)** | dx/dt = rx + x³ | 불안정한 가지 붕괴(종종 재앙적) |
| **홉프** | 2D 시스템 | 고정점이 불안정해지고 한계 주기가 나타남 |
### 분기 다이어그램
고정점 대 매개변수 값의 플롯으로 안정성을 보여줍니다(실선 = 안정, 점선 = 불안정). 로지스틱 맵의 분기 다이어그램은 혼돈으로 가는 주기 배가 경로와 유명한 **파이겐바움 상수** δ ≒ 4.669(연속 분기 간격 사이의 보편적인 비율)를 보여줍니다.

## 편미분 방정식(PDE)
PDE에는 여러 변수의 함수와 해당 부분 파생물이 포함됩니다.
### 2차 선형 PDE의 분류
Au_xx + 2Bu_xy + Cu_yy + ... = 0의 경우:
| 유형 | 조건 | 행동 | 예 |
|------|-------------|----------|---------|
| **타원형** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | 파동 전파, 날카로운 특징 보존 | 파동 방정식: u_tt = c²u_xx |
### 열 방정식
∂u/∂t = α ∂²u/∂x²
열 확산, 인구 확산, 옵션 가격 책정(Black-Scholes)을 모델링합니다.
| 부동산 | 성명서 |
|----------|-----------|
| 스무딩 | 불연속적인 초기 데이터에서도 솔루션이 즉시 원활해집니다 |
| 최대 원리 | 경계 또는 초기 시간에 최대 온도 발생 |
| 시간 가역성 | 되돌릴 수 없음 - 뒤로 실행할 수 없음 |
### 파동 방정식
∂²u/∂t² = c² ∂²u/∂x²
진동하는 현, 소리, 전자기파를 모델링합니다.
| 부동산 | 성명서 |
|----------|-----------|
| 전파 | 교란은 속도 c로 이동 |
| 가역성 | 시간 가역성 |
| 달랑베르 솔루션 | u(x,t) = f(x−ct) + g(x+ct) (왼쪽/오른쪽 파동의 중첩) |
### 라플라스 방정식
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
해(고조파 함수)는 정상 상태 온도, 정전기 전위, 비압축성 유체 흐름을 나타냅니다.
| 부동산 | 성명서 |
|----------|-----------|
| 평균값 속성 | u(x₀) = x₀를 중심으로 하는 모든 원에 대한 u의 평균 |
| 최대 원리 | 내부 최대값 또는 최소값 없음 |
| 독창성 | 경계 조건에 의해 전적으로 결정됨 |
