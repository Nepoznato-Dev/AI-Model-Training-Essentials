# 정보이론
1948년 클로드 섀넌(Claude Shannon)이 창시한 정보 이론은 정보 자체를 수량화합니다. 메시지는 얼마나 많은 것을 말해주는가? 데이터를 얼마나 압축할 수 있나요? 시끄러운 채널을 통해 얼마나 빨리 통신할 수 있습니까? 이러한 질문에는 정확한 수학적 답이 있습니다. 통신 외에도 정보 이론은 기계 학습의 기초가 되었습니다. 교차 엔트로피는 분류를 위한 기본 손실 함수이고, KL 발산은 분포 유사성을 측정하며, 상호 정보는 기능 선택을 유도합니다.

## 엔트로피
**엔트로피**는 무작위 변수의 평균 불확실성 또는 '놀라움'을 측정합니다.
### 섀넌 엔트로피(이산)
확률 질량 함수 p(x)를 갖는 이산 확률 변수 X의 경우:
H(X) = −Σₓ p(x) log² p(x)
단위: **bits**(log₂ 사용 시) 또는 **nats**(ln 사용 시).
| 유통 | 엔트로피 | 직관 |
|-------------|---------|------------|
| 공정한 코인(p = 0.5, 0.5) | 1비트 | 이진 결과에 대한 최대 불확실성 |
| 편향된 코인(p = 0.9, 0.1) | 0.469비트 | 덜 놀랍습니다 - 대부분 머리 |
| 결정적(p = 1, 0) | 0비트 | 불확실성이 전혀 없음 |
| 공정한 주사위(6면) | 2.585비트 | 더 많은 결과 = 더 많은 불확실성 |
| n개 결과에 걸쳐 균일함 | log2(n) 비트 | n개의 결과에 대한 최대 엔트로피 |
### 엔트로피의 속성
| 부동산 | 성명서 |
|----------|-----------|
| 비부정성 | H(X) ≥ 0 |
| 최대 | H(X) ≤ log²(\|X\|)(균일 분포에 대한 동일성) |
| 체인 규칙 | H(X, Y) = H(X) + H(Y \| X) |
| 컨디셔닝 감소 | H(X \| Y) ≤ H(X) |
| 오목함 | H는 확률 분포의 오목 함수입니다. |
### 미분 엔트로피(연속)
밀도 p(x)를 갖는 연속 확률 변수 X의 경우:
h(X) = −∫ p(x) log p(x) dx
이산 엔트로피와 달리 미분 엔트로피는 **음수**일 수 있습니다.
| 유통 | 미분 엔트로피 |
|-------------|---------|
| [a,b]의 유니폼 | 로그(b − a) |
| 정규 N(μ, σ²) | (1/2) 로그(2πeσ²) |
| 지수(λ) | 1 - ln(λ) |

## 공동, 조건부 및 상호 정보
### 공동 엔트로피
H(X, Y) = −Σₓ Σᵧ p(x, y) 로그 p(x, y)
쌍(X, Y)의 총 불확실성을 측정합니다.
### 조건부 엔트로피
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
X를 관찰한 후 Y에 대해 남아 있는 불확실성을 측정합니다.
### 상호 정보
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
X가 Y에 대해 얼마나 많이 알고 있는지(또는 그 반대)를 측정합니다.
| 부동산 | 성명서 |
|----------|-----------|
| 비부정성 | I(X; Y) ≥ 0 |
| 대칭 | I(X; Y) = I(Y; X) |
| 엔트로피와의 관계 | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| 관절과의 관계 | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| 독립 | I(X; Y) = 0 X와 Y가 독립인 경우 |
| 자기정보 | I(X; X) = H(X) |
### 시각적: 엔트로피 다이어그램
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## KL 다이버전스
**Kullback-Leibler(KL) 발산**은 한 분포가 다른 분포와 얼마나 다른지 측정합니다.
D_KL(P || Q) = Σₓ P(x) 로그 [P(x) / Q(x)]
| 부동산 | 성명서 |
|----------|-----------|
| 비부정성 | D_KL(P \|\| Q) ≥ 0(깁스 부등식) |
| 정체성 | D_KL(P \|\| Q) = 0 iff P = Q |
| 비대칭 | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) 일반적으로 |
| 측정항목이 아님 | 대칭 및 삼각형 부등식 실패 |
**해석:** D_KL(P || Q)는 Q에 최적화된 코드를 사용하여 P의 데이터를 인코딩하는 데 필요한 추가 비트 수입니다.
### 다른 수량과의 관계
| 관계 | 공식 |
|---------------|---------|
| 교차 엔트로피 | H(P, Q) = H(P) + D_KL(P \|\| Q) |
| 상호 정보 | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| 조건부 KL | D_KL(P(Y\|X) \|\| Q(Y\|X))는 X |

## 교차 엔트로피
분포 P와 Q 사이의 **교차 엔트로피**:
H(P, Q) = −Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### 손실 함수로서의 교차 엔트로피
분류에서 P는 실제 분포(원-핫 인코딩된 레이블)이고 Q는 모델의 예측 분포입니다.
**이진 교차 엔트로피(BCE):**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**범주형 교차엔트로피:**
L = −Σᵢ yᵢ 로그(ŷᵢ)
| 시나리오 | y(참) | ŷ (예상) | 손실 |
|------------|------------|---------------|------|
| 정확하고 자신감 | 1 | 0.95 | 0.051 |
| 정확함, 불확실함 | 1 | 0.55 | 0.598 |
| 틀렸어, 자신감 | 1 | 0.05 | 2.996 |
| 틀렸음, 불확실함 | 1 | 0.45 | 0.799 |
교차 엔트로피를 최소화하는 것은 실제 분포에서 KL 발산을 최소화하는 것과 같습니다. 이것이 손실 함수와 마찬가지로 잘 작동하는 이유입니다.

## 채널 용량
### 통신 채널 모델
```
X → [Channel] → Y
```

- X : 입력확률변수
- Y: 랜덤변수 출력
- 채널: 조건부 확률 p(y|x)로 정의됨
### 섀넌의 시끄러운 채널 코딩 정리
용량 C인 채널의 경우 전송률 R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C이면 안정적인 통신이 불가능합니다.
**채널 용량:**
C = max_{p(x)} I(X; Y)
### 중요한 채널 예
| 채널 | 설명 | 용량 |
|---------|-------------|----------|
| **이진 대칭(BSC)** | 확률 p로 각 비트를 뒤집습니다 | 1 - H(p) 비트 |
| **바이너리 삭제(BEC)** | 확률 ε |으로 각 비트를 지웁니다. 1 − ε 비트 |
| **가우스(AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)log(1 + SNR) 비트 |
| **무소음 바이너리** | 완벽한 전송 | 1비트 |

## 소스 코딩 및 압축
### 소스 코딩 정리
소스를 인코딩하는 데 필요한 평균 비트 수는 엔트로피에 따라 제한됩니다.
L ≥ H(X)
최적의 코드는 L ≒ H(X)를 달성합니다.
### 허프만 코딩
더 가능성 있는 기호에 더 짧은 코드를 할당하는 **접두사 없는** 코드입니다.
| 기호 | 확률 | 허프만 코드 | 길이 |
|---------|-------------|-------------|---------|
| A | 0.5 | 0 | 1 |
| 비 | 0.25 | 10 | 2 |
| 다 | 0.125 | 110 | 3 |
| 디 | 0.125 | 111 | 3 |
평균 길이: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75비트/기호
엔트로피: H = 1.75비트/기호(이 경우 최적!)
### 무손실 압축과 손실 압축
| 유형 | 원리 | 예 | 한도 |
|------|-------------|----------|-------|
| **무손실** | 통계적 중복 제거 | 우편번호, PNG, FLAC | 엔트로피율 H(X) |
| **손실** | 지각적으로 관련성이 없는 정보 제거 | JPEG, MP3, H.264 | 비율-왜곡 함수 R(D) |
**속도 왜곡 이론:** 최대 왜곡 D를 갖는 손실 압축의 경우 최소 속도는 E[d(X, X̂)] ≤ D에 따라 R(D) = min I(X; X̂)입니다.

| 개념 | 정보 이론 | 열역학 |
|---------|------|---|
| 엔트로피 | 섀넌 엔트로피 H(X) | 볼츠만 엔트로피 S = k_B ln W |
| 최대 엔트로피 | 균일한 분포 | 열평형 |

수학적 형식은 동일합니다. Shannon은 의도적으로 통계 역학에서 "엔트로피"라는 용어를 빌렸습니다.
### 정보이론과 통계
| 개념 | 신청 |
|---------|-------------|
| 최대 가능성 | 경험적 분포에서 모델 분포로의 KL 발산을 최소화하는 것과 동일 |

| AIC / 빅 | 대략적인 KL 기반 모델 선정 기준 |

## 요약
| 수량 | 공식(이산형) | 의미 |
|------------|------|---------|
| 엔트로피 H(X) | −Σ p(x) 로그 p(x) | 평균 불확실성 |
| 결합 엔트로피 H(X,Y) | −Σ p(x,y) 로그 p(x,y) | 쌍의 총 불확실성 |
| 조건부 엔트로피 H(Y\|X) | H(X,Y) − H(X) | X가 주어지면 Y에 대한 남은 불확실성 |
| 상호정보 I(X;Y) | H(X) − H(X\|Y) | X와 Y가 공유하는 정보 |
| KL 발산 D_KL(P\|\|Q) | Σ P(x) 로그(P(x)/Q(x)) | 분포 간의 "거리" |
| 교차 엔트로피 H(P,Q) | −Σ P(x) 로그 Q(x) | 잘못된 분포를 사용한 인코딩 비용 |
| 채널 용량 C | 최대 I(X;Y) | 안정적인 최대 통신 속도 |
정보 이론은 학습하고, 압축하고, 전달할 수 있는 것의 근본적인 한계를 제공합니다. 기계 학습 실무자를 위해 교차 엔트로피가 손실 함수로 작동하는 이유, 학습된 표현의 품질을 측정하는 방법, 모델 복잡성과 데이터 적합성 간의 균형을 생각하는 방법을 설명합니다. 1948년 Shannon의 통찰력은 통신과 마찬가지로 현대 AI에도 여전히 관련성이 있습니다.
