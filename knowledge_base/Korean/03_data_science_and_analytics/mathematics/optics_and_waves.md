# 광학과 파동
파도는 소리, 빛, 물, 무선 신호, 양자 확률 진폭, 주식 시장 변동, 신경망 활성화의 진동 등 어디에나 있습니다. 빛을 연구하는 광학은 가장 잘 발달된 파동 과학이며, 그 수학적 도구(푸리에 분석, 간섭, 회절)는 모든 파동 현상에 적용됩니다. 파동을 이해하는 것은 신호 처리, 이미지 분석, 통신 및 모든 현대 기술의 물리적 계층에 필수적입니다.
---

## 파동 방정식
### 일반 파동 방정식
1차원 파동 방정식:
∂²u/∂t² = c² ∂²u/∂x²
여기서 u(x,t)는 파동 변위이고 c는 파동 속도입니다.
### 일반 솔루션(d'Alembert)
u(x,t) = f(x − ct) + g(x + ct)
여기서 f는 오른쪽으로 진행하는 파동이고 g는 왼쪽으로 진행하는 파동입니다.
### 주요 웨이브 매개변수
| 매개변수 | 기호 | 단위 | 설명 |
|------------|---------|------|-------------|
| 진폭 | A | 다양하다 | 최대 변위 |
| 파장 | λ | 미터 | 연속된 문장 사이의 거리 |
| 빈도 | f 또는 ν | 헤르츠(Hz) | 초당 사이클 |
| 기간 | T = 1/f | 초 | 하나의 완전한 주기에 소요되는 시간 |
| 파수 | k = 2π/λ | 라드/m | 공간 주파수 |
| 각주파수 | Ω = 2πf | 라드/초 | 시간적 주파수 |
| 파동 속도 | c = fλ = Ω/k | 밀리미터/초 | 전파 속도 |
### 정현파
u(x,t) = A sin(kx − Ωt + ψ)
여기서 ψ는 위상 상수입니다.
### 다양한 매체의 파동 속도
| 웨이브 유형 | 중간 | 속도 공식 |
|------------|---------|---------------|
| 문자열 | 장력 T, 선형 밀도 μ | c = √(T/μ) |
| 소리 | 벌크 계수 B, 밀도 ρ | c = √(B/ρ) |
| 소리(이상기체) | γ, R, T, M | c = √(γRT/M) |
| 전자파 | 유전율 ε, 투자율 μ | c = 1/√(με) |
| 전자기파(진공) ​​| ε₀, μ₀ | c = 3 × 10⁸m/s |

## 중첩과 간섭
### 중첩의 원리
두 개 이상의 파동이 겹칠 때 결과 변위는 개별 변위의 합입니다.
u_total = u₁ + u₂ + ... + uₙ
이는 선형 파동 방정식에 적용됩니다.
### 두 파동의 간섭
주파수와 진폭이 동일한 두 파동, 위상차 Δψ:
u_total = 2A cos(Δψ/2) sin(kx − Ωt + Δψ/2)
| 위상차 | 결과 | 강도 |
|----|---------|-----------|
| Δψ = 0, 2π, 4π, ... | **구조적**(진폭 = 2A) | 4I₀(최대) |
| ΔΦ = π, 3π, 5π, ... | **파괴적**(진폭 = 0) | 0(최소) |
| Δψ = π/2 | 부분 | 2I₀ |
### 간섭 조건
| 조건 | 유형 | 경로 차이 |
|------------|------|----|
| 건설적인 | 밝은 프린지 | ΔL = mλ (m = 0, 1, 2, ...) |
| 파괴적인 | 다크 프린지 | ΔL = (m + ½)λ |
---

## 영의 이중 슬릿 실험
빛은 거리 d만큼 떨어진 두 개의 좁은 슬릿을 통과하여 거리 L에 있는 스크린에 간섭 무늬를 만듭니다.
### 프린지 포지션
| 프린지 | 화면에서의 위치 |
|---------|------|
| 브라이트(최대) | y_m = mLL/d |
| 어두움(최소) | y_m = (m + ½)λL/d |
| 프린지 간격 | Δy = λL/d |
이 실험은 빛의 파동 특성을 입증했으며(Thomas Young, 1801) 나중에 양자 역학(파동-입자 이중성)의 핵심이 되었습니다.
---

## 회절
**회절**은 장애물 주위와 개구부를 통해 파동이 휘어지고 퍼지는 현상입니다.
### 단일 슬릿 회절
폭 a의 슬릿을 통과하는 빛은 밝고 어두운 무늬의 패턴을 생성합니다.
| 기능 | 조건 |
|---------|------------|
| 중앙 최대 | 가장 넓고 밝습니다. 폭 = 2λL/a |
| 미니마(어두운 줄무늬) | a sin θ = mλ (m = ±1, ±2, ...) |
| 2차 최대값 | 대략 최소값 사이; 훨씬 더 어두워 |
### 회절 격자
N개의 동일한 간격의 슬릿(간격 d)은 매우 선명한 최대값을 생성합니다.
d sin θ = mλ (m = 0, 1, 2, ...)
| 부동산 | 효과 |
|----------|---------|
| 더 많은 슬릿(더 큰 N) | 더 선명하고 더 밝은 맥시마 |
| 해상력 | R = mN(가까운 파장을 구별할 수 있음) |
| 응용프로그램 | 분광학, 파장 측정 |
### 레일리 기준(해상도 한계)
두 개의 포인트 소스는 하나의 중앙 최대값이 다른 하나의 첫 번째 최소값에 해당하는 경우에만 확인할 수 있습니다.
θ_min = 1.22 λ/D
여기서 D는 조리개 직경입니다.
| 시스템 | λ | 디 | θ_분 |
|---------|---|---|-------|
| 인간의 눈 | 550nm | 5mm | 1.3 × 10⁻⁴ 라드(~0.01°) |
| 허블 우주 망원경 | 550nm | 2.4m | 2.8 × 10⁻⁷ 라드 |
| 전파망원경(Arecibo) | 21cm | 305m | 8.4 × 10⁻⁴ 라드 |

## 양극화
**편파**는 횡파에서 전기장 진동의 방향을 나타냅니다.
### 편광 유형
| 유형 | 설명 |
|------|-------------|
| **선형** | E는 고정된 평면에서 진동 |
| **원형** | E는 원을 그리며 회전합니다(오른손잡이 또는 왼손잡이) |
| **타원형** | E는 타원을 추적합니다(가장 일반적임) |
| **비편광** | 모든 편광의 무작위 혼합(대부분의 자연광) |
### 말루스의 법칙
편광된 빛이 편광 방향에 대해 각도 θ로 편광판을 통과할 때:
나는 = I₀ cos²θ
| 각도 θ | 투과 강도 |
|---------|---------|
| 0° | 100% (I₀) |
| 30° | 75% |
| 45° | 50% |
| 60° | 25% |
| 90° | 0%(완전 차단) |
### 반사에 의한 편광(브루스터 각도)
브루스터 각도에서 반사된 빛은 완전히 편광됩니다.
tan θ_B = n²/n₁
| 인터페이스 | n₁ | n² | θ_B |
|------------|----|----|-----|
| 공기 → 유리 | 1.0 | 1.5 | 56.3° |
| 공기 → 물 | 1.0 | 1.33 | 53.1° |
| 유리 → 다이아몬드 | 1.5 | 2.42 | 58.1° |

## 기하광학
기하(광선) 광학은 빛을 인터페이스에서 구부러지면서 직선으로 이동하는 광선으로 취급합니다.
### 스넬의 법칙(굴절)
n₁ 죄 θ₁ = n² 죄 θ2
| 소재 | 굴절률 n |
|------------|------|
| 진공 | 1.000 |
| 공기 | 1.0003 |
| 물 | 1.33 |
| 유리(크라운) | 1.52 |
| 유리(부싯돌) | 1.62 |
| 다이아몬드 | 2.42 |
### 전체 내부 반사
빛이 밀도가 높은 매질에서 밀도가 낮은 매질로 **임계각**을 넘어 이동할 때:
θ_c = 아크사인(n²/n₁)
모든 빛은 반사됩니다. 이것이 광섬유가 작동하는 방식입니다.
### 얇은 렌즈 방정식
1/f = 1/d_o + 1/d_i
| 수량 | 의미 |
|------------|---------|
| 에프 | 초점 거리 |
| d_o | 물체 거리 |
| d_i | 이미지 거리 |
| M = -d_i/d_o | 배율 |
| 렌즈 유형 | 에프 | 이미지 |
|------------|---|-------|
| 수렴(볼록) | 긍정적 | 실제(d_o > f인 경우) 또는 가상 |
| 발산(오목) | 네거티브 | 항상 가상, 수직, 축소 |
### 거울 방정식
렌즈 방정식과 동일한 형식: 1/f = 1/d_o + 1/d_i, 여기서 f = R/2는 구형 거울의 경우입니다.

## 푸리에 광학
푸리에 광학은 이미징과 회절을 푸리에 변환 작업으로 처리합니다.
### 핵심 원칙
조리개의 원거리 회절 패턴은 조리개 함수의 **푸리에 변환**입니다.
| 조리개 | 회절 패턴(푸리에 변환) |
|------------|--------------|
| 단일 슬릿 | 싱크 기능 |
| 원형 조리개 | 에어리 디스크(J₁(r)/r) |
| 직사각형 조리개 | 2D 싱크 |
| 격자 | 이산 델타 함수 |
### 광학 푸리에 변환
렌즈는 2D 푸리에 변환을 수행합니다. 물체를 전면 초점면에 배치하면 후면 초점면에서 푸리에 변환이 생성됩니다.
### 애플리케이션
| 신청 | 푸리에 광학이 어떻게 도움이 됩니까 |
|-------------|------------|
| 이미지 필터링 | 푸리에 평면에 마스크를 배치하여 공간 주파수를 차단/통과 |
| 가장자리 감지 | 푸리에 평면의 고역 통과 필터링 |
| 패턴 인식 | 푸리에 변환을 통한 상관관계 |
| 홀로그래피 | 파면 기록 및 재구성 |
| 광컴퓨팅 | 빛의 속도로 푸리에 변환 수행 |

## 사운드 및 음향
### 음파 속성
| 부동산 | 일반적인 범위 | 단위 |
|----------|--------------|------|
| 빈도 | 20 − 20,000(사람의 청각) | 헤르츠 |
| 속도(공기, 20°C) | 343 | 밀리미터/초 |
| 속도(물) | 1,480 | 밀리미터/초 |
| 속도(강철) | 5,960 | 밀리미터/초 |
| 강도 임계값 | 10⁻² | W/m² |
### 데시벨 규모
β = 10 log₁₀(I/I₀)dB, 여기서 I₀ = 10⁻¹² W/m²
| 소리 | 강도(W/m²) | 레벨(dB) |
|-------|------|------------|
| 청력의 임계값 | 10⁻² | 0 |
| 바스락거리는 나뭇잎 | 10⁻¹¹ | 10 |
| 일반적인 대화 | 10⁻⁶ | 60 |
| 록 콘서트 | 1 | 120 |
| 고통의 역치 | 10 | 130 |
| 제트 엔진 | 100 | 140 |
### 도플러 효과
소스와 관찰자가 서로 상대적으로 움직일 때 관찰된 주파수:
f' = f(v ± v_o)/(v ∓ v_s)
| 시나리오 | 효과 |
|----------|---------|
| 소스 접근 | 더 높은 주파수(빛의 파란색 편이) |
| 소스 후퇴 | 낮은 주파수(빛의 적색 편이) |
| 응용프로그램 | 레이더, 의료용 초음파, 천문학(은하의 적색편이) |

## 기계 학습 및 데이터 과학과의 관련성
| 파동/광학 개념 | 신청 |
|---------|-------------|
| 파동방정식 | 물리학 기반 신경망, 지진 데이터 분석, 오디오 처리 |
| 푸리에 분석 | 신호처리, 스펙트럼 분석, 특징 추출의 기초 |
| 푸리에 변환 | CNN은 암시적으로 로컬 푸리에 분석을 수행합니다. 데이터 전처리에 사용되는 FFT |
| 간섭 | 아날로그 컴퓨팅, 광학 신경망 |
| 회절 | 이미지 형성 모델, 디블러링 알고리즘, 컴퓨터 사진 |
| 양극화 | 원격탐사, 물질분류, 위성영상 분석 |
| 기하광학 | 컴퓨터 비전의 카메라 모델, 합성 데이터 생성을 위한 광선 추적 |
| 렌즈 방정식 | 카메라 교정, 깊이 추정, 3D 재구성 |
| 푸리에 광학 | 광 컴퓨팅, 회절 심층 신경망(D²NN) |
| 도플러 효과 | 레이더 신호 처리, 의료 영상(도플러 초음파), 속도 추정 |
| 데시벨 규모 | 오디오 특성 엔지니어링, 음성 인식 전처리 |
| 샘플링 이론 | Nyquist-Shannon 정리는 파동 이론을 디지털 신호 처리에 연결합니다 |

## 요약
| 주제 | 핵심 아이디어 | 주요 방정식 |
|---------|------------|-------------|
| 파동방정식 | 파도는 속도 c로 전파 | ∂²u/∂t² = c²∂²u/∂x² |
| 중첩 | 파도가 선형적으로 추가됨 | u = u₁ + u₂ |
| 간섭 | 단계가 강화를 결정합니다 | Δψ = 2πΔL/λ |
| 회절 | 파도가 장애물 주위로 휘어집니다 | a sin θ = mλ (단일 슬릿) |
| 양극화 | 진동의 방향 | Malus의 법칙: I = I₀cos²θ |
| 기하광학 | 광선처럼 빛 | 스넬의 법칙: n₁sinθ₁ = n²sinθ₂ |
| 푸리에 광학 | 푸리에 변환으로 이미징 | 원거리 필드 = 조리개의 FT |
| 도플러 효과 | 모션으로 인한 주파수 이동 | f' = f(v ± v_o)/(v ∓ v_s) |
파동은 진동 시스템의 보편적인 언어입니다. 오디오 신호를 처리하든, 시계열을 분석하든, 이미지 인식 시스템을 설계하든, 물리 시뮬레이션을 구축하든 상관없이 파동 수학(중첩, 푸리에 분석, 간섭, 회절)은 필수 툴킷을 제공합니다. 광학은 가장 성숙한 파동과학으로서 현대 데이터 과학에 스며드는 이론적 기초와 실제 기술을 모두 제공합니다.
