# 그래프 이론
**그래프**는 모서리(링크)로 연결된 정점(노드)으로 구성된 수학적 구조입니다. 그래프 모델 관계: 소셜 네트워크, 로드맵, 신경 네트워크, 종속성, 통신 채널. 그래프 이론(이러한 구조에 대한 연구)은 컴퓨터 과학, 운영 연구 및 데이터 과학의 핵심인 알고리즘과 정리를 제공합니다.

## 기본 개념
### 정의
| 기간 | 정의 | 표기법 |
|------|------------|----------|
| **그래프** | 꼭지점과 모서리의 쌍 G = (V, E) | G |
| **정점(노드)** | V의 요소 | v, 유, w |
| **엣지** | 두 정점 사이의 연결 | e = (u, v) 또는 {u, v} |
| **주문** | 정점 수 | \|V\| =n |
| **사이즈** | 모서리 수 | \|E\| =m |
| **학위** | 꼭지점에 입사하는 모서리 수 | 각도(v) |
| **경로** | 가장자리로 연결된 개별 정점의 시퀀스 | v₁, v₂, ..., vₖ |
| **사이클** | 동일한 꼭지점에서 시작하고 끝나는 경로 | v₁ → v₂ → ... → vₖ → v₁ |
| **연결됨** | 모든 정점 쌍 사이에는 경로가 존재합니다 | — |
| **구성요소** | 최대 연결 하위 그래프 | — |
| **하위 그래프** | V와 E의 하위 집합으로 구성된 그래프 | H ⊆ G |
### 그래프 유형
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **무방향** | 가장자리에는 방향이 없습니다 | 우정 네트워크 |
| **감독(디그래프)** | 모서리에는 방향이 있습니다(호) | 웹페이지 링크 |
| **가중치** | 모서리는 숫자 값을 전달합니다 | 도로 거리 |
| **가중치 없음** | 모든 모서리는 동일합니다 | 사회적 관계 |
| **간단함** | 루프 없음, 다중 모서리 없음 | 대부분의 교과서 그래프 |
| **다중 그래프** | 동일한 꼭지점 사이에 여러 개의 가장자리가 허용됨 | 항공 노선(도시간 복수 항공편) |
| **완료** | 모든 정점 쌍이 연결되어 있습니다 | Kₙ에는 n(n−1)/2개의 간선이 있습니다 |
| **양자** | 정점은 두 그룹으로 나뉩니다. 가장자리만 교차 그룹 | 사용자 아이템 추천 매트릭스 |
| **평면형** | 가장자리 교차 없이 그릴 수 있음 | 회로 기판 레이아웃 |
| **나무** | 연결된 비순환 그래프 | 의사결정 트리, 파일 시스템 |
| **대그** | 지시됨, 지시되지 않은 사이클 | 작업 스케줄링, 종속성 그래프 |
### 핸드쉐이킹 정리
모든 정점 각도의 합은 모서리 수의 두 배와 같습니다.
Σᵥ도(v) = 2|E|
**추론:** 모든 그래프에는 짝수의 홀수 정점이 있습니다.
**예:** 10명의 파티에서 모두가 정확히 3명의 다른 사람과 악수하는 경우: Σ deg = 30이므로 |E| = 총 15번의 악수.

## 그래프 표현
그래프를 메모리에 저장하는 방법에 따라 실행하는 모든 알고리즘의 효율성이 결정됩니다.
| 대표 | 공간 | 가장자리 조회 | 이웃 반복 | 최고의 대상 |
|---|-------|-------------|-------|----------|
| **인접 매트릭스** | 오(n²) | 오(1) | 오(n) | 조밀한 그래프, 빠른 에지 테스트 |
| **인접 목록** | O(n + m) | O(도(v)) | O(도(v)) | 희소 그래프, 대부분의 실제 네트워크 |
| **가장자리 목록** | 오(m) | 오(m) | 오(m) | 간단한 알고리즘, Kruskal의 MST |
| **발생 매트릭스** | O(n·m) | 오(m) | 오(m) | 전문 알고리즘 |
### 인접 행렬
n × n 행렬 A. 여기서 A[i][j] = 에지 (i,j)가 존재하면 1이고, 그렇지 않으면 0입니다. 가중치 그래프의 경우 A[i][j] = 가중치입니다.
**속성:**
- 무방향 그래프에 대한 대칭
- Aᵏ[i][j] = i에서 j까지 길이 k인 걷기 횟수
- A의 고유값은 구조적 특성을 나타냅니다(분광 그래프 이론 참조).
### 인접 목록
각 정점 v가 이웃 목록을 저장하는 배열(또는 해시 맵)입니다.
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

이는 일반적으로 희소(m `` n²)인 실제 그래프에 대한 가장 일반적인 표현입니다.

## 나무
**트리**는 연결된 비순환 무방향 그래프입니다. **숲**은 나무들의 분리된 결합입니다.
### 나무의 속성
n개의 정점이 있는 트리의 경우:
- 정확히 n − 1개의 모서리를 가집니다.
- 두 정점 사이에는 정확히 하나의 경로가 있습니다.
- 가장자리를 제거하면 연결이 끊어집니다.
- 모서리를 추가하면 정확히 하나의 사이클이 생성됩니다.
### 나무의 종류
| 유형 | 설명 | 신청 |
|------|-------------|-------------|
| **뿌리나무** | 루트로 지정된 하나의 정점 | 파일 시스템, 조직도 |
| **이진 트리** | 각 노드에는 최대 2명의 하위 항목이 있습니다 | BST, 표현 분석, 의사결정 트리 |
| **균형 트리** | 높이는 O(log n) | AVL 트리, 레드-블랙 트리(데이터베이스) |
| **스패닝 트리** | 모든 정점을 포함하고 트리인 하위 그래프 | 네트워크 설계, 근사 알고리즘 |
| **최소 스패닝 트리** | 최소 총 가장자리 가중치를 갖는 스패닝 트리 | 네트워크 설계, 클러스터링 |
| **별 그래프** | 하나의 중앙 노드가 다른 모든 노드와 연결됨 | 허브 앤 스포크 네트워크 |
### 이진 트리 속성
| 부동산 | 공식 |
|------------|---------|
| 깊이 d의 최대 노드 | 2ᵈ |
| 높이가 h인 트리의 최대 노드 | 2ʰ⁺¹ − 1 |
| n 노드의 최소 높이 | ⌊log²(n)⌋ |
| 완전 이진 트리의 리프 노드 | 내부 노드 + 1 |
### 트리 순회
| 순회 | 주문 | 사용 사례 |
|------------|-------|----------|
| **선주문** | 루트 → 왼쪽 → 오른쪽 | 트리 복사, 접두사 표현식 |
| **순서대로** | 왼쪽 → 루트 → 오른쪽 | BST의 정렬된 출력 |
| **주문 후** | 왼쪽 → 오른쪽 → 루트 | 트리 삭제, 후위 표현 |
| **레벨 순서(BFS)** | 레벨별, 왼쪽에서 오른쪽으로 | 비가중 트리의 최단 경로 |

## 그래프 순회
순회 알고리즘은 도달 가능한 모든 정점을 체계적으로 방문합니다.
### 너비 우선 검색(BFS)
**큐**를 사용하여 레이어별로 정점을 탐색합니다.
| 부동산 | 가치 |
|----------|-------|
| 데이터 구조 | 대기열(FIFO) |
| 시간 복잡도 | O(V + E) |
| 공간 복잡도 | 오(V) |
| 최단 경로를 찾으십니까? | 예(비가중 그래프) |
| 완벽한? | 예(도달 가능한 모든 정점 탐색) |
**알고리즘:**
1. 소스 정점 s에서 시작합니다. 마크가 방문했어요. 대기열에 넣기 s.
2. 큐가 비어 있지 않은 동안: 정점 u를 큐에서 제거합니다. 방문하지 않은 각 이웃 v에 대해: v 방문 표시, 대기열 v.
**애플리케이션:** 비가중 그래프, 연결된 구성요소, 이분성 테스트, 웹 크롤링의 최단 경로입니다.
### 깊이 우선 검색(DFS)
**스택**(또는 재귀)을 사용하여 역추적하기 전에 최대한 깊이 탐색합니다.
| 부동산 | 가치 |
|----------|-------|
| 데이터 구조 | 스택(LIFO)/재귀 |
| 시간 복잡도 | O(V + E) |
| 공간 복잡도 | 오(V) |
| 최단 경로를 찾으십니까? | 아니요 |
| 완벽한? | 예(유한 그래프의 경우) |
**알고리즘:**
1. 정점 s에서 시작합니다. 마크가 방문했어요.
2. 방문하지 않은 각 이웃 v of s에 대해: v에서 재귀적으로 DFS합니다.
**DFS는 가장자리를 다음으로 분류합니다.**
- **트리 가장자리:** DFS 트리의 일부
- **뒤 가장자리:** 정점을 조상에 연결합니다(주기 표시).
- **앞쪽 가장자리:** 정점을 하위 요소에 연결합니다.
- **교차 모서리:** 서로 다른 가지의 정점을 연결합니다.
**응용 분야:** 토폴로지 정렬, 주기 감지, 강하게 연결된 구성 요소, 미로 해결.
### BFS와 DFS 비교
| 기준 | BFS | DFS |
|------------|------|-----|
| 전략 | 넓고 깊은 | 깊고 넓은 |
| 메모리 | 더 높음(상점 경계) | 하단(저장 경로) |
| 최단 경로(가중치 없음) | 보장됨 | 보장되지 않음 |
| 솔루션이 시작되기 직전일 때 사용 | 더 나은 | 더 나쁨 |
| 그래프가 매우 깊은 경우 사용 | 더 나쁨 | 더 나은 |
| 토폴로지 정렬 | Kahn의 알고리즘 변형 | 표준 접근 방식 |

## 최단 경로 알고리즘
정점 사이의 최단 경로를 찾는 것은 실제로 가장 중요한 그래프 문제 중 하나입니다.
### Dijkstra의 알고리즘
**음수가 아닌** 간선 가중치를 사용하여 단일 소스에서 그래프의 다른 모든 정점까지의 최단 경로를 찾습니다.
| 부동산 | 가치 |
|----------|-------|
| 가장자리 가중치 | ≥ 0이어야 합니다 |
| 시간(바이너리 힙) | O((V + E) 로그 V) |
| 시간(피보나치 힙) | O(E + V 로그 V) |
| 탐욕스러운? | 예 |
| 음수 가중치를 처리합니까? | 아니요 |
**알고리즘:**
1. 모든 v ≠ s에 대해 dist[s] = 0, dist[v] = 를 초기화합니다. 모든 꼭지점을 포함하는 우선순위 큐 Q.
2. Q가 비어 있지 않은 동안: 최소 거리로 정점 u를 추출합니다. 간선 가중치 w를 갖는 u의 각 이웃 v에 대해: dist[u] + w < dist[v]이면 dist[v] = dist[u] + w를 업데이트합니다.
**작업된 예:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### 벨만-포드 알고리즘
**음수** 가장자리 가중치를 처리하고 음수 주기를 감지합니다.
| 부동산 | 가치 |
|----------|-------|
| 가장자리 가중치 | 모두(음수 주기 감지) |
| 시간 복잡도 | O(V·E) |
| 공간 복잡도 | 오(V) |
| 부정적인 사이클을 처리합니까? | 예(탐지 및 보고) |
**알고리즘:**
1. 모든 v ≠ s에 대해 dist[s] = 0, dist[v] = 를 초기화합니다.
2. V − 1회 반복: 가중치 w가 있는 각 간선(u, v)에 대해: dist[u] + w < dist[v]인 경우 dist[v]를 업데이트합니다.
3. 음의 사이클을 확인하십시오. 가장자리가 여전히 완화될 수 있으면 음의 사이클이 존재하는 것입니다.
### 플로이드-워샬 알고리즘
**모든 정점 쌍** 사이의 최단 경로를 찾습니다.
| 부동산 | 가치 |
|----------|-------|
| 시간 복잡도 | O(V³) |
| 공간 복잡도 | O(V²) |
| 음수 가중치를 처리합니까? | 예(음수 순환은 아님) |
| 접근 | 동적 프로그래밍 |
**반복:** 각 중간 정점 k에 대해 dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]).
### 알고리즘 선택 가이드
| 시나리오 | 알고리즘 |
|----------|-----------|
| 단일 소스, 음수가 아닌 가중치 | 데이크스트라 |
| 단일 소스, 음수 가중치 가능 | 벨먼-포드 |
| 모든 쌍, 조밀한 그래프 | 플로이드-워샬 |
| 모든 쌍, 희소 그래프 | 각 정점에서 Dijkstra 실행 |
| 비가중 그래프 | BFS |
| DAG(주기 없음) | 위상 정렬 + 이완 |
| A*(경험적 안내) | A* 검색(좋은 휴리스틱을 사용한 길찾기용) |

## 최소 스패닝 트리
**최소 스패닝 트리(MST)**는 최소 총 가장자리 가중치로 모든 정점을 연결합니다.
### 속성
- MST에는 정확히 n − 1개의 모서리가 있습니다(n개의 정점에 대해).
- 그래프가 연결되어 있으면 MST가 존재합니다.
- 뚜렷한 간선 가중치를 갖는 그래프에는 고유한 MST가 있습니다.
- MST는 **절단 속성**을 충족합니다. 모든 절단을 교차하는 최소 무게 가장자리는 MST에 속합니다.
- MST는 **사이클 속성**을 만족합니다. 모든 사이클의 최대 중량 에지는 MST에 속하지 않습니다.
### 크루스칼 알고리즘
| 부동산 | 가치 |
|----------|-------|
| 전략 | Greedy — 가중치 순서대로 간선 추가 |
| 데이터 구조 | 분리된 집합(결합 찾기) |
| 시간 복잡도 | O(E로그E) |
| | 희소 그래프 |
**알고리즘:**
1. 모든 모서리를 가중치별로 정렬합니다.
2. 각 모서리에 대해(순서대로) 추가해도 주기가 생성되지 않으면(Union-Find로 확인) MST에 추가합니다.
3. n – 1개의 간선이 선택되면 중지합니다.
### 프림의 알고리즘
| 부동산 | 가치 |
|----------|-------|
| 전략 | Greedy — 시작 정점에서 트리 성장 |
| 데이터 구조 | 우선순위 큐(최소힙) |
| 시간 복잡도 | 이진 힙이 있는 O(E log V) |
| | 조밀한 그래프 |
**알고리즘:**
1. 임의의 꼭지점에서 시작합니다. MST의 일부로 표시하십시오.
2. MST의 정점을 외부 정점에 연결하는 최소 가중치 가장자리를 반복적으로 추가합니다.
3. 모든 정점이 포함되면 중지합니다.
### MST 애플리케이션
| 신청 | MST가 도움이 되는 방법 |
|---------------|---------------|
| 네트워크 설계 | 모든 위치를 연결하기 위한 최소한의 케이블/파이프 설치 |
| 클러스터링 | k − 1 개의 가장 긴 MST 간선을 제거하여 k 클러스터를 얻습니다. |
| 근사 알고리즘 | 미터법 TSP에 대한 2-근사 |
| 이미지 분할 | 색상 유사도의 MST를 기준으로 픽셀 그룹화 |
| 기능 제거 | 상관 그래프의 MST를 사용하여 중복 기능 제거 |

## 네트워크 흐름
네트워크 흐름 문제는 시스템을 통한 리소스 이동을 모델링합니다.
### 흐름 네트워크 정의
**흐름 네트워크**는 다음을 포함하는 방향성 그래프입니다.
- **소스** 정점 s(흐름 생성)
- A **싱크** 정점 t(흐름 소비)
- **용량** c(u,v) 각 모서리에서 ≥ 0
- **흐름** f(u,v)가 다음을 만족함:
  - **용량 제약:** 0 ≤ f(u,v) ≤ c(u,v)
  - **유동 보존:** 유입 = s와 t를 제외한 모든 정점에서 유출
### 최대 유량 문제
s에서 t까지의 최대 총 흐름을 구합니다.
**Ford-Fulkerson 방법:**
1. 잔차 그래프에 s에서 t까지 증가 경로가 존재하는 동안:
2. 경로를 따라 병목 용량 찾기
3. 병목 현상 정도만큼 경로를 따라 흐름을 증가시킵니다.
4. 잔여 용량 업데이트
| 알고리즘 | 시간 복잡도 | 메모 |
|------------|---|-------|
| 포드-풀커슨(DFS) | O(m · f*) 여기서 f*는 최대 유량 | 비합리적인 용량으로 종료될 수 없음 |
| 에드먼즈-카프(BFS) | O(V·E²) | 항상 종료되고 최단 증가 경로 선택 |
| Dinic의 알고리즘 | O(V² · E) | 차단 흐름을 사용합니다. 단위 용량에 대한 O(V^(1/2) · E) |
### 최대-유량 최소-컷 정리
s에서 t까지 **최대 유량**은 s에서 t를 분리하는 **최소 절단** 용량과 같습니다.
A **cut** (S, T)는 정점을 S(s 포함)와 T(t 포함)로 분할합니다. 절단 용량은 S에서 T까지의 모서리 용량의 합입니다.
**최대 유량 적용:**
- 이분 매칭(작업자에게 작업 할당)
- 이미지 분할(전경과 배경 분리)
- 야구 탈락(X팀이 여전히 승리할 수 있나요?)
- 네트워크 신뢰성(최대 데이터 처리량)
### Max Flow를 통한 이분 매칭
이분 그래프 G = (L ∪ R, E)가 주어지면:
1. L(용량 1)의 모든 정점에 가장자리가 있는 소스를 추가합니다.
2. R의 모든 꼭짓점의 가장자리를 포함하는 싱크 t를 추가합니다(용량 1).
3. 모든 원래 가장자리 용량을 1로 설정합니다.
4. 최대 유량 = 최대 매칭

## 스펙트럼 그래프 이론
스펙트럼 그래프 이론은 그래프와 관련된 행렬의 고유값과 고유벡터를 통해 그래프를 연구합니다.
### 주요 매트릭스
| 매트릭스 | 정의 | 캡처 내용 |
|---------|------------|------|
| **인접 행렬** A | A[i][j] = 간선 (i,j)가 존재하는 경우 1 | 연결 패턴 |
| **학위 매트릭스** D | 대각선; D[i][i] = 각도(i) | 정도별 정점 중요도 |
| **라플라시안** L = D − A | L[i][j] = −1(에지), deg(i)(대각선) | 그래프에서 함수의 부드러움 |
| **정규화된 라플라시안** L_norm = D^(−1/2) L D^(−1/2) | 규모 불변 버전 | 커뮤니티 구조 |
### 라플라시안의 고유값
라플라시안 L은 양의 준정부호이므로 모든 고유값은 ≥ 0입니다.
| 고유값 | 의미 |
|------------|---------|
| λ₁ = 0 | 항상 0입니다. 고유벡터는 상수 벡터입니다 |
| λ²(대수적 연결성) | > 0 그래프가 연결된 경우; 더 크다 = 더 잘 연결됨 |
| 0 고유값의 수 | 연결된 구성 요소 수와 동일 |
| λₙ | 최대 차수 및 그래프 확장 관련 |
### 스펙트럼 방법의 응용
| 신청 | 방법 |
|-------------|---------|
| **그래프 분할** | L의 고유벡터를 사용하여 그래프를 균형 잡힌 부분으로 분할 |
| **커뮤니티 감지** | 스펙트럼 클러스터링: 하단 고유 벡터를 사용하여 정점을 삽입한 다음 클러스터링 |
| **페이지랭크** | 웹 그래프의 인접 행렬(또는 전이 행렬)의 고유벡터 |
| **그래프 그리기** | 라플라시안의 고유벡터를 사용하여 꼭지점 위치 지정 |
| **반지도 학습** | 그래프 Laplacian(레이블 전파)을 사용하여 레이블 전파 |
| **그래프 신경망** | 스펙트럼 컨벌루션: L의 고유 벡터를 사용하여 그래프의 신호 필터링 |
### 치거의 불평등
두 번째 고유값 λ²를 그래프의 **확장**(얼마나 잘 연결되어 있는지)과 연관시킵니다.
λ² / 2 ≤ h(G) ≤ √(2λ²)
여기서 h(G)는 Cheeger 상수(등주선 수)입니다. 이는 λ²가 그래프를 두 조각으로 자르는 것이 얼마나 어려운지 대략적으로 측정한다는 것을 의미합니다. 이는 클러스터링에 대한 핵심 통찰력입니다.
