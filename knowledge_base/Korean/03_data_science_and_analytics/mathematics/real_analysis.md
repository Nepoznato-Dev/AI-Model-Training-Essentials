# 실제 분석
실제 분석은 미적분학의 엄격한 기초입니다. 기초 미적분학에서는 도함수와 적분을 계산하는 방법을 가르쳐 주지만 실제 분석에서는 이러한 기법이 *왜* 작동하는지, 그리고 언제 실패하는지 묻습니다. 확률 이론, 기능 분석, 최적화 및 기계 학습 알고리즘의 이론적 보장을 뒷받침하는 한계, 연속성, 수렴 및 통합에 대한 정확한 정의를 제공합니다.

## 시퀀스 및 시리즈
### 시퀀스
**수열**은 실수(aₙ)ₙ₌₁^ Infini의 순서가 지정된 목록입니다. 핵심 질문은 수열이 한계에 **수렴**하는가입니다.
**수렴의 정의:** 모든 ε > 0에 대해 모든 n > N에 대해 다음과 같은 N이 존재하는 경우 수열(aₙ)은 L로 수렴합니다. |aₙ − L| < ε.
| 개념 | 정의 | 예 |
|---------|------------|---------|
| **수렴** | lim aₙ = L이 존재하며 유한합니다 | aₙ = 1/n → 0 |
| **발산** | 수렴하지 않음 | aₙ = (−1)ⁿ 진동 |
| **무한대에 발산** | aₙ는 무한히 커진다 | aₙ = n² → 무한 |
| **제한됨** | \|aₙ\| ≤ 일부 M에 대한 M | 모든 수렴 시퀀스는 제한되어 있습니다 |
| **모노톤** | 항상 비감소 또는 비증가 | aₙ = 1 − 1/n이 증가하고 있습니다 |
| **코시 시퀀스** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | ℝ에서는 Cauchy ⟺ 수렴 |
**주요 이론:**
- **단조 수렴 정리:** 모든 유계 단조 수열은 수렴합니다.
- **Bolzano-Weierstrass 정리:** 모든 유계 수열은 수렴하는 부분 수열을 가집니다.
- **ℝ의 완전성:** ℝ의 모든 Cauchy 수열은 수렴합니다(이로 인해 ℝ와 ℚ가 구별됩니다).
### 시리즈
**계열**은 수열의 합입니다: Σₙ₌₁^∞ aₙ. 부분합 Sₙ = Σₖ₌₁ⁿ aₖ의 수열이 수렴하면 급수는 수렴합니다.
### 융합 테스트
| 테스트 | 조건 | 결론 |
|------|------------|------------|
| **발산 테스트** | 임 aₙ ≠ 0 | 시리즈가 다양함 |
| **비교 테스트** | 0 ≤ aₙ ≤ bₙ 및 Σbₙ는 수렴 | Σaₙ가 수렴 |
| **비율 테스트** | 임 \|aₙ₊₁/aₙ\| = 엘 | L< 1, diverges if L >1 |
| **루트 테스트** | 임섭 \|aₙ\|^(1/n) = L | L< 1, diverges if L >1 |
| **통합 테스트** | aₙ = f(n), f 감소, 양수 | Σaₙ는 ∫f(x)dx가 수렴하는 경우에 수렴합니다 |
| **교대 시리즈** | aₙ 감소, lim aₙ = 0, 교대 부호 | 시리즈 수렴 |
| **절대적인 융합** | Σ\|aₙ\| 수렴 | Σaₙ는 수렴합니다(재배열은 동일한 합계를 제공합니다) |
| **조건부 수렴** | Σaₙ는 수렴하지만 Σ\|aₙ\| 갈라진다 | 재배열은 임의의 합계를 제공할 수 있습니다(Riemann) |
### 중요 시리즈
| 시리즈 | 합계 | 조건 |
|---------|-------|------------|
| 기하학: Σ rⁿ | 1/(1−r) | \|r\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| 고조파: Σ 1/n | 발산(= ) | — |
| 지수: Σ xⁿ/n! | 에ˣ | 모든 x |
| ln(1+x)에 대한 테일러: Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < x ≤ 1 |

## 한계와 연속성
### 기능의 한계
**정의:** lim_{x→c} f(x) = L은 다음을 의미합니다. 모든 ε > 0에 대해 0 < |x − c|가 되는 δ > 0이 존재합니다. < δ는 |f(x) − L|을 의미합니다. < ε.
이것이 **ε-δ 정의**입니다. "x가 c에 접근할 때 f(x)가 L에 접근합니다."의 엄격한 버전입니다.
### 연속성
lim_{x→c} f(x) = f(c)인 경우 함수 f는 **c에서 연속**입니다. 동등하게: 모든 ε > 0에 대해 |x − c|가 되는 δ > 0이 존재합니다. < δ는 |f(x) − f(c)|를 의미합니다. < ε.
**불연속성 유형:**
| 유형 | 설명 | 예 |
|------|-------------|---------|
| 이동식 | 극한이 존재하지만 ≠ f(c) | f(x) = x = 0에서 sin(x)/x |
| 점프 | 왼쪽 및 오른쪽 제한이 존재하지만 다릅니다 | 단계 함수 |
| 무한 | 한도는 ± Infini | x = 0에서 f(x) = 1/x² |
| 진동 | 한도가 존재하지 않습니다 | f(x) = x = 0에서 sin(1/x) |
### 연속 함수의 주요 정리
| 정리 | 성명서 |
|---------|------------|
| **중간가치정리** | f가 [a,b]에서 연속이고 f(a) < k < f(b)인 경우 ∃c ∈ (a,b): f(c) = k |
| **극값 정리** | f가 [a,b]에서 연속이면 f는 [a,b] |에서 최대값과 최소값을 얻습니다.
| **경계정리** | f가 [a,b]에서 연속이면 f는 [a,b] |
| **균일한 연속성** | f가 [a,b]에서 연속이면 f는 [a,b]에서 균일 연속입니다(Heine-Cantor) |
**실제 예(IVT):** x³ + x − 1 = 0이 (0, 1)에 해를 갖는다는 것을 보여주세요.
- f(x) = x³ + x − 1이라고 가정합니다. f는 연속(다항식)입니다.
- f(0) = −1< 0 and f(1) = 1 >0.
- IVT에 따르면, ∃c ∈ (0,1): f(c) = 0입니다.

## 차별화
### 정의
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
이 극한이 존재하면 f는 c에서 **미분 가능**합니다.
### 미분성 대 연속성
| 관계 | 성명서 |
|---------------|------------|
| 미분가능 → 연속 | f가 c에서 미분 가능하면 f는 c |
| 연속 ↛ 미분 가능 | f(x) = \|x\| 는 0에서 연속이지만 0에서는 미분할 수 없습니다 |
| 어디에서도 미분할 수 없음 | Weierstrass 함수: 어디에서나 연속이고, 어디에서나 미분 가능 |
### 주요 결과
| 정리 | 성명서 |
|---------|------------|
| **평균값 정리** | f가 [a,b]에서 연속이고 (a,b)에서 미분 가능하면 ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **롤의 정리** | f(a) = f(b)일 때 MVT의 특수 사례: ∃c: f'(c) = 0 |
| **로피탈의 법칙** | lim f/g = 0/0 또는 무한/무한이면 lim f/g = lim f'/g'(후자가 존재할 경우) |
| **테일러의 정리** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x)(명시적 나머지 포함) |

## 통합
### 리만 통합
**리만 적분**은 ∫ₐᵇ f(x)dx를 리만 합의 극한으로 정의합니다.
**건축:**
1. [a,b]를 하위 구간으로 분할합니다. P = {x₀, x₁, ..., xₙ}
2. 샘플 포인트 tᵢ ∈ [xᵢ₋₁, xᵢ] 선택
3. 리만 합: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. S(P,f)의 극한이 메쉬 → 0으로 존재하면 f는 리만 적분 가능입니다.
**리만 통합성 기준:**
| 조건 | 통합 가능? |
|------------|-------------|
| [a,b]에서 연속 | 예 |
| 무한히 많은 불연속으로 제한됨 | 예 |
| [a,b]의 모노톤 | 예 |
| Dirichlet 함수(ℚ에 1, 무리수에 0) | 아니요 |
### 미적분학의 기본 정리
| 부품 | 성명서 |
|------|------------|
| **1부** | f가 [a,b]에서 연속인 경우 F(x) = ∫ₐˣ f(t)dt는 미분 가능하고 F'(x) = f(x) |
| **파트 2** | F' = f이고 f가 리만 적분 가능이면 ∫ₐᵇ f(x)dx = F(b) − F(a) |
### 르베그 통합
리만 적분에는 한계가 있습니다. 즉, 분석과 확률에서 발생하는 많은 함수를 통합할 수 없습니다. **르베그 적분**은 통합을 훨씬 더 광범위한 함수 클래스로 확장합니다.
**핵심 아이디어:** 도메인(x축)을 분할하는 대신 범위(y축)를 분할합니다.
| 측면 | 리만 적분 | 르베그 적분 |
|---------|------|------|
| 접근 | 파티션 도메인(x축) | 파티션 범위(y축) |
| 통합 | 연속, 조각별 연속 | 측정 가능한 기능 |
| 극한정리 | 약한 | 강력함(지배적 융합, 모노톤 융합) |
| 핸들 | "좋은" 기능 | 조밀한 불연속성을 갖는 함수 |
| 재단 | 고전 미적분학 | 현대 확률 이론 |
**르베그의 기준:** f가 거의 모든 곳에서 유계이고 연속인 경우 f는 [a,b]에서 리만 적분 가능합니다(불연속 집합의 측정값 0을 가짐).

## 미터법 공간
**미터법 공간**은 "거리" 개념을 추상 세트로 일반화합니다.
### 정의
**미터법 공간** (X, d)는 다음을 충족하는 거리 함수 d: X × X → ℝ를 갖는 집합 X입니다.
| 공리 | 성명서 |
|-------|------------|
| 비부정성 | d(x,y) ≥ 0 |
| 정체성 | d(x,y) = 0 x = y |
| 대칭 | d(x,y) = d(y,x) |
| 삼각형 부등식 | d(x,z) ≤ d(x,y) + d(y,z) |
### 공통 메트릭 공간
| 공간 | 설정 | 미터법 | 신청 |
|-------|------|---------|-------------|
| ℝⁿ 유클리드와 함께 | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² | 표준 기하학 |
| ℝⁿ 맨해튼과 함께 | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| | 그리드 기반 경로, LASSO |
| ℝⁿ 체비쇼프와 함께 | ℝⁿ | d(x,y) = 최대\|xᵢ−yᵢ\| | 체스 킹 거리 |
| 이산형 측정항목 | 모든 세트 | d(x,y) = x≠y이면 1, x=y이면 0 | 토폴로지 예 |
| 함수 공간 C[a,b] | 연속 기능 | d(f,g) = 최대\|f(x)−g(x)\| | 근사 이론 |
| 공간 | p-적분 가능 함수 | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) | 기능 분석, ML 규범 |
### 미터법 공간의 토폴로지 개념
| 개념 | 정의 | 예 |
|---------|------------|---------|
| **오픈 볼** | B(x,r) = {y : d(x,y) < r} | ℝ의 열린 구간(x−r, x+r) |
| **오픈 세트** | 모든 포인트에는 세트에 공이 포함되어 있습니다 | (0,1)은 ℝ에 열려 있습니다 |
| **비공개 세트** | 오픈 세트의 보완 | [0,1]은 ℝ |
| **폐쇄** | S를 포함하는 가장 작은 닫힌 집합 | (0,1) = [0,1]의 종결 |
| **컴팩트** | 열려 있는 모든 표지에는 유한한 하위 표지가 있습니다 | ℝⁿ: 폐쇄형 및 경계형(Heine-Borel) |
| **완료** | 모든 Cauchy 수열은 수렴합니다 | ℝ 완료되었습니다. ℚ는 |

## 균일한 수렴
일련의 함수(fₙ)는 두 가지 방법으로 수렴할 수 있습니다.
| 유형 | 정의 | 연속성을 유지합니까? |
|------|------------|---------|
| **포인트별** | ∀x: fₙ(x) → f(x) | 아니요 |
| **유니폼** | 저녁\|fₙ(x) − f(x)\| → 0 | 예 |
**균일 수렴**이 더 강력합니다. 수렴 속도는 모든 곳에서 동일합니다.
**주요 이론:**
- 연속함수의 균일극한은 연속이다.
- 리만 적분 함수의 등한선은 리만 적분 가능하며, 극한의 적분은 적분의 극한과 같습니다.
- **Weierstrass M-테스트:** If |fₙ(x)| 모든 x에 대해 ≤ Mₙ 및 ΣMₙ가 수렴한 다음 Σfₙ가 균일하게 수렴합니다.

## 측정 이론
**측정 이론**은 길이, 면적, 부피의 개념을 일반화합니다.
### 정의
집합 X의 **측정값**은 다음을 충족하는 함수 μ: Σ → [0, ∞] (여기서 Σ는 하위 집합의 σ 대수임)입니다.
- μ(∅) = 0
- **가산 가능한 가산성:** μ(∪ᵢ Aᵢ) = 서로소인 Aᵢ의 경우 Σᵢ μ(Aᵢ)
### 르베그 측정
ℝ에 대한 **르베그 측정** λ는 길이 개념을 확장합니다.
| 설정 | 르베그 측정 |
|------|----|
| 간격 [a,b] | b - a |
| 단일 포인트 {x} | 0 |
| 유한 집합 | 0 |
| 셀 수 있는 집합(예: ℚ) | 0 |
| 칸토어 세트 | 0(셀 수 없지만 0으로 측정) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### 주요 개념
| 개념 | 정의 |
|---------|------------|
| **거의 모든 곳(예:)** | 측정값 0 |
| **측정 가능한 기능** | 모든 오픈 세트의 사전 이미지를 측정할 수 있습니다 |
| **르베그 적분** | 측정 이론을 사용하여 정의된 적분 |
| **공간 부족** | 유한 p차 적분을 갖는 함수의 공간 |
### 중요한 수렴 정리
이러한 정리는 고급 수학에서 르베그 통합이 선호되는 이유입니다.
| 정리 | 성명서 |
|---------|------------|
| **모노톤 컨버전스** | fₙ ↑ f 점별이고 fₙ ≥ 0이면 ∫fₙ → ∫f |
| **지배되는 융합** | fₙ → f 점 방향 및 \|fₙ\| ≤ g(적분 가능), 그러면 ∫fₙ → ∫f |
| **Fatou의 보조정리** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
이러한 정리는 극한과 적분의 교환을 허용합니다. 이는 일반적으로 리만 적분에 실패합니다.

| 미터법 공간 | 클러스터링(k-평균, DBSCAN)의 거리 함수, 가장 가까운 이웃 |
| 컴팩트함 | 최적의 솔루션을 위한 존재 증명, 유한차원 최적화의 Heine-Borel |
| 균일한 수렴 | 근사(신경망 보편적 근사)가 어디에서나 작동하도록 보장 |
| 측정 이론 | 현대 확률의 기초(확률은 척도임), 르베그 적분으로 기대되는 값 |
| 르베그 통합 | 기대값 E[X] = ∫X dP는 르베그 적분 |
| 공간 | 정규화의 L1(LASSO), L²(Ridge), Lᵖ 규범 |
| 지배적인 융합 | 추정기의 일관성 입증, 베이지안 추론의 한계 상호 교환 |
