# 신호 처리
신호 처리는 신호(시간, 공간 또는 주파수에 따라 변하는 물리적 양의 표현)를 분석, 수정 및 합성하는 과학입니다. 오디오, 이미지, 비디오, 센서 데이터, 뇌파, 주가 등 모두 신호입니다. 신호 처리의 수학적 도구(푸리에 변환, 필터, 샘플링 이론)는 기계 학습, 통신, 의료 영상 및 데이터를 사용하는 거의 모든 분야의 기초입니다.
---

## 신호 및 시스템
### 신호 분류
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **연속시간** | 모든 t ∈ ℝ에 대해 정의됨 | 오디오 전압, 온도 |
| **이산 시간** | 정수 인덱스 n에서 정의됨 | 샘플링된 오디오, 픽셀 값 |
| **아날로그** | 시간과 진폭이 연속적 | 비닐 레코드 그루브 |
| **디지털** | 이산적인 시간 및 양자화된 진폭 | MP3 파일, JPEG 이미지 |
| **정기적** | x(t + T) = 모든 t에 대한 x(t) | 사인파, 구형파 |
| **비주기적** | 반복되는 패턴 없음 | 연설, 음악 |
| **결정적** | 완전히 예측 가능 | 사인파 |
| **확률론적** | 임의성을 포함 | 소음, 주가 |
### 시스템 속성
| 부동산 | 정의 | 예 |
|----------|------------|---------|
| **선형** | T[ax₁ + bx2] = aT[x₁] + bT[x2] | 저역 통과 필터 |
| **시간 불변** | 입력의 변화 → 출력의 동일한 변화 | 고정 필터 |
| **인과관계** | 출력은 현재 및 과거 입력에만 의존함 | 실시간 시스템 |
| **스테이블(BIBO)** | 제한된 입력 → 제한된 출력 | 잘 설계된 필터 |
| **메모리리스** | 출력은 현재 입력에만 의존합니다 | 증폭기 |

## 푸리에 변환
**푸리에 변환**은 신호를 구성 주파수로 분해합니다.
### 연속 푸리에 변환
X(f) = ∫_{−무한}^{무한} x(t) e^{−j2πft} dt
역수: x(t) = ∫_{−무한}^{무} X(f) e^{j2πft} df
### 푸리에 변환 쌍
| 시간 영역 x(t) | 주파수 영역 X(f) |
|------|---------|
| 직사각형 펄스 | 싱크 기능 |
| 싱크 기능 | 직사각형 펄스 |
| 가우스 e^{−at²} | 가우스 (√(π/a))e^{−π²f²/a} |
| 디랙 델타 δ(t) | 1(모든 주파수) |
| 복소수 지수 e^{j2πf₀t} | δ(f − f₀) |
| 코사인 cos(2πf₀t) | ½[δ(f−f₀) + δ(f+f₀)] |
### 주요 속성
| 부동산 | 시간 영역 | 주파수 영역 |
|----------|-------------|----|
| 선형성 | ax₁(t) + bx2(t) | aX₁(f) + bX2(f) |
| 시간 이동 | x(t − t₀) | X(f)e^{−j2πft₀} |
| 주파수 편이 | x(t)e^{j2πf₀t} | X(f − f₀) |
| 컨볼루션 | x₁(t) * x2(t) | X₁(f) · X²(f) |
| 곱셈 | x₁(t) · x²(t) | X₁(f) * X²(f) |
| 차별화 | dx/dt | j2πf X(f) |
| 파세발의 정리 | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**컨볼루션 정리:** 시간의 컨볼루션 = 주파수의 곱셈. 이것이 가장 중요한 속성입니다. 값비싼 컨볼루션 연산을 값싼 곱셈으로 바꿔줍니다.
### 이산 푸리에 변환(DFT)
시퀀스 x[0], x[1], ..., x[N−1]의 경우:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}, k = 0, 1, ..., N−1
| 부동산 | 가치 |
|----------|-------|
| 입력 | N개의 실수 또는 복소수 샘플 |
| 출력 | N개의 복합 주파수 빈 |
| 주파수 분해능 | f_s/N(여기서 f_s는 샘플링 속도임) |
| 나이퀴스트 주파수 | f_s/2 (표현 가능한 최대 주파수) |
| 복잡성 | O(N²) 직접 계산 |
### 고속 푸리에 변환(FFT)
**FFT**는 O(N²) 대신 O(N log N)로 DFT를 계산합니다.
| 엔 | O(N²) 운영 | O(N log N) 작업 | 속도 향상 |
|---|------|---------|---------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10² | 20,971,520 | 52,428× |
FFT는 지금까지 발명된 가장 중요한 알고리즘 중 하나입니다. 실시간 오디오 처리, 이미지 압축(JPEG), 무선 통신(OFDM) 및 스펙트럼 분석이 가능합니다.

## 라플라스 변환
**라플라스 변환**은 푸리에 변환을 확장하여 불안정한 시스템과 과도 해석을 처리합니다.
F(s) = ∫₀^킵 f(t) e^{−st} dt, 여기서 s = σ + jΩ
### 일반적인 라플라스 변환
| 에프(티) | F(들) | 융합지역 |
|------|------|---------|
| δ(t)(임펄스) | 1 | 모든 것 |
| u(t)(단계) | 1/초 | 응답 > 0 |
| e^{−at}u(t) | 1/(s+a) | 재(들) > −a |
| tⁿu(t) | n!/s^{n+1} | 응답 > 0 |
| 죄(Ωt)u(t) | Ω/(s²+Ω²) | 응답 > 0 |
| cos(Ωt)u(t) | s/(s²+Ω²) | 응답 > 0 |
### 푸리에 변환에 대한 연결
σ = 0(s = jΩ)인 경우 라플라스 변환은 푸리에 변환으로 축소됩니다. 라플라스 변환은 성장/쇠퇴(σ)에 대한 정보를 포함하여 보다 완전한 그림을 제공합니다.
---

## Z 변환
**Z 변환**은 라플라스 변환과 동등한 이산시간 변환입니다.
X(z) = Σ_{n=−무한대}^{무한} x[n] z^{−n}
### 일반적인 Z 변환
| x[n] | X(z) | ROC |
|------|------|------|
| δ[n] | 1 | 모든 z |
| u[n] (단계) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|a\| |
| 나ⁿu[n] | az/(z−a)² | \|z\| > \|a\| |
| 죄(Ω₀n)u[n] | z 사인(Ω₀)/(z²−2z cos(Ω₀)+1) | \|z\| > 1 |
### 다른 변환과의 관계
| 변환 | 도메인 | 변수 |
|------------|---------|----------|
| 푸리에 | 연속 주파수 | f 또는 Ω |
| 라플라스 | 복소주파수 | s = σ + jΩ |
| Z 변환 | 복소 주파수(이산) | z = e^{sT} |
z 평면의 단위원(|z| = 1)은 푸리에 변환에 해당합니다.

## 필터
필터는 특정 주파수 구성요소를 선택적으로 통과시키거나 차단합니다.
### 필터 유형
| 유형 | 패스 | 블록 | 신청 |
|------|----------|---------|-------------|
| **로우패스** | 저주파 | 고주파수 | 스무딩, 앤티앨리어싱 |
| **하이패스** | 고주파수 | 저주파 | 엣지 검출, 노이즈 제거 |
| **밴드패스** | 다양한 주파수 | 범위 밖 | 채널 선택(라디오) |
| **밴드스톱(노치)** | 범위를 제외한 모든 것 | 특정 범위 | 전력선 잡음 제거 |
### FIR 필터와 IIR 필터
| 부동산 | FIR(유한 충격 응답) | IIR(무한 임펄스 응답) |
|------------|------------------|------|
| 임펄스 응답 | 유한 기간 | 무한 기간 |
| 안정성 | 항상 안정적 | 불안정할 수 있음 |
| 단계 | 정확히 선형일 수 있음 | 일반적으로 비선형 위상 |
| 피드백 | 아니요 | 예 |
| 계산 | 더 많은 계수가 필요함 | 동일한 롤오프에 대한 계수가 적음 |
| 디자인 | 윈도잉, 파크스-맥클렐런 | 버터워스, 체비쇼프, 타원 |
| 전달 함수 | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### 필터 설계 사양
| 매개변수 | 설명 |
|------------|-------------|
| **패스밴드** | 최소한의 손실로 통과해야 하는 주파수 범위 |
| **스톱밴드** | 감쇠되어야 하는 주파수 범위 |
| **컷오프 주파수** | 통과대역과 정지대역 사이의 경계 |
| **리플** | 통과대역(또는 정지대역) 이득의 변화 |
| **롤오프** | 감쇠율(옥타브 또는 10년당 dB) |
| **전환 대역** | 통과대역과 정지대역 사이의 영역 |
### 일반적인 필터 설계
| 디자인 | 특징 | 사용 사례 |
|---------|---|----------|
| **버터워스** | 최대로 평탄한 통과대역, 적당한 롤오프 | 범용 |
| **체비쇼프 유형 I** | 통과대역의 리플, 가파른 롤오프 | 롤오프가 중요한 경우 |
| **체비쇼프 유형 II** | 저지대역의 리플, 평면 통과대역 | 통과대역 평탄도가 중요한 경우 |
| **타원형(카우어)** | 둘 다의 리플, 가장 가파른 롤오프 | 필요한 최소 주문 |
| **베셀** | 선형 위상(최대로 평탄한 그룹 지연) | 파형 형태 보존 |

## 샘플링 이론
### 나이퀴스트-섀넌 샘플링 정리
샘플링 속도가 최대 주파수의 두 배를 초과하면 연속 신호가 샘플에서 완벽하게 재구성될 수 있습니다.
f_s > 2f_max
| 기간 | 정의 |
|------|------------|
| **샘플링 속도**(f_s) | 초당 샘플 수 |
| **나이퀴스트 비율** | 2f_max(최소 샘플링 속도) |
| **나이퀴스트 주파수** | f_s/2 (표현 가능한 최대 주파수) |
| **앨리어싱** | f_s < 2f_max일 때 저주파로 가장하는 고주파수 |
### 공통 샘플링 속도
| 신청 | 평가 | 나이퀴스트 주파수 |
|-------------|------|------|
| 전화 연설 | 8kHz | 4kHz |
| 오디오 CD | 44.1kHz | 22.05kHz |
| 전문 오디오 | 48kHz | 24kHz |
| 고해상도 오디오 | 96kHz | 48kHz |
| 비디오(30fps) | 30Hz(일시적) | 15Hz |
### 앤티앨리어싱
샘플링 전에 **앨리어싱 방지 필터**(저역 통과)는 f_s/2 이상의 주파수를 제거하여 앨리어싱을 방지합니다.

## 윈도잉
신호의 유한 세그먼트를 분석할 때 암시적으로 직사각형 창을 곱하면 스펙트럼 누출이 발생합니다. **창 기능**은 이러한 누출을 줄여줍니다.
### 일반 창
| 창 | 메인 로브 폭 | 사이드 로브 레벨 | 사용 사례 |
|---------|---|----|----------|
| 직사각형 | 가장 좁은 | −13dB | 해상도가 가장 중요한 경우 |
| 한 | 2× 직사각형 | −31dB | 범용 |
| 해밍 | 2× 직사각형 | −41dB | 가장 가까운 측엽 감소 |
| 블랙맨 | 3× 직사각형 | −58dB | 높은 동적 범위 |
| 카이저 | 조정 가능 | 조정 가능(β를 통해) | 절충이 조정 가능한 경우 |
### 스펙트럼 누출
신호에 창을 곱하면 해당 스펙트럼이 창의 스펙트럼과 컨볼루션됩니다. 메인 로브가 넓을수록 주파수 분해능이 감소합니다. 하부 사이드 로브는 누출을 줄입니다.

## 웨이블릿
**웨이블릿**은 다중 해상도 신호 분석에 사용되는 작고 국부적인 파동형 함수입니다.
### 웨이블릿 변환
전역 주파수 정보를 제공하는 푸리에 변환과 달리 웨이블릿 변환은 **시간-주파수** 위치를 제공합니다.
| 변환 | 시간 해상도 | 주파수 분해능 |
|------------|---|-------|
| 푸리에 | 없음(글로벌) | 우수 |
| 단시간 FT | 고정(창 크기) | 고정 |
| 웨이블릿 | 가변적(고주파에 좋음) | 가변적(낮은 주파수에 좋음) |
### 일반적인 웨이블릿 계열
| 가족 | 속성 | 신청 |
|---------|------------|-------------|
| **하르** | 가장 단순하고 불연속적인 | 엣지 검출, 빠른 분석 |
| **Daubechies** (dbN) | 컴팩트한 지원, N 사라지는 순간 | 압축, 노이즈 제거 |
| **심렛** | 거의 대칭인 Daubechies | 위상 왜곡 감소 |
| **코이플릿** | 순간 조건에 맞게 설계됨 | 신호 처리 |
| **모레** | 가우스 창 정현파 | 시간-주파수 분석 |
| **멕시코 햇** | 가우스의 2차 미분 | 기능 감지 |
### 웨이블릿의 응용
| 신청 | 웨이블릿이 도움이 되는 방법 |
|-------------|------|
| 이미지 압축(JPEG 2000) | 가장자리에 대한 DCT보다 나은 다중 해상도 표현 |
| 노이즈 제거 | 임계값 작은 웨이블릿 계수(신호가 큰 계수에 있음) |
| 기능 감지 | 시계열의 에지 감지, 과도 감지 |
| 심전도 분석 | QRS 복합체 감지, 부정맥 분류 |
| 지진해석 | 지층 식별, 지진 신호 처리 |

## 기계 학습 및 데이터 과학과의 관련성
| 신호처리 개념 | 신청 |
|---------------|-------------|
| 푸리에 변환 | 오디오 ML을 위한 스펙트럼 기능, 시계열의 주파수 영역 분석 |
| FFT | CNN의 빠른 컨볼루션(스펙트럼 컨볼루션), 효율적인 상관관계 |
| 컨볼루션 정리 | CNN 작동 방식 이해(학습된 필터임) |
| 필터 | 전처리(평활화, 노이즈 제거), 특징 추출 |
| 샘플링 정리 | 이산화 이해, 센서 속도 선택, 앨리어싱 방지 |
| 윈도잉 | 오디오 ML(스펙트로그램)용 STFT, 시간-주파수 분석 |
| 웨이블릿 | 시계열, 압축, 노이즈 제거를 위한 특징 추출 |
| 라플라스/Z 변환 | 로봇공학의 제어이론, 시스템 안정성의 이해 |
| 스펙트럼 분석 | EEG/fMRI 분석, 진동 모니터링, 예측 유지 관리 |
| 나이퀴스트율 | ML 파이프라인에 적합한 데이터 수집 속도 선택 |

## 요약
| 도구 | 도메인 | 주요 통찰력 |
|------|---------|------------|
| 푸리에 변환 | 시간 → 빈도 | 신호는 정현파의 합입니다 |
| 라플라스 변환 | 시간 → 복소주파수 | 과도 현상 및 안정성 처리 |
| Z 변환 | 이산시간 → 복소수 | 디지털 필터 분석 및 설계 |
| FFT | 효율적인 DFT 계산 | O(N²) 대신 O(N log N) |
| 필터 | 주파수 선택 | 필요한 것은 전달하고, 필요하지 않은 것은 차단 |
| 샘플링 정리 | 연속 ⇔ 이산 | 충분히 빠르게 샘플을 채취하면 아무것도 잃지 않습니다 |
| 윈도잉 | 시간-주파수 절충 | 균형 해결 및 누출 |
| 웨이블릿 | 다중 해상도 분석 | 시간과 빈도 모두에서 지역적 |
신호 처리는 데이터를 이해하고, 분석하고, 조작하기 위한 수학적 기초를 제공합니다. 시계열, 오디오, 이미지 또는 센서 데이터로 작동하는 모든 기계 학습 파이프라인은 암시적으로 신호 처리 개념을 사용합니다. 특히 푸리에 변환은 모든 데이터 과학자에게 미적분학 다음으로 가장 중요한 수학적 도구일 것입니다.
