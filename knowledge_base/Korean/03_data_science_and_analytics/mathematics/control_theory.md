# 제어 이론
제어 이론은 시스템이 원하는 방식으로 작동하도록 만드는 수학입니다. 온도 조절기에서 자동 조종 장치, 로봇 팔에서 화학 반응기에 이르기까지 제어 시스템은 원하는 동작을 유지하기 위해 감지하고 결정하고 행동합니다. 이 현장에서는 강화 학습, 초매개변수 조정 및 적응형 시스템으로 마이그레이션된 개념인 안정성, 성능 및 견고성을 분석하기 위한 엄격한 도구를 제공합니다.

## 기본 개념
### 개방 루프와 폐쇄 루프 비교
| 유형 | 설명 | 예 | 장점 |
|------|-------------|---------|------------|
| **개방 루프** | 출력과 무관한 제어 동작 | 세탁기 타이머 | 간단하고 센서가 필요하지 않습니다 |
| **폐쇄 루프(피드백)** | 제어 동작은 출력에 따라 다름 | 온도 조절기, 크루즈 컨트롤 | 방해를 거부하고 견고함 |
### 블록 다이어그램 요소
| 요소 | 기호 | 기능 |
|---------|---------|---------|
| **식물** | G(들) | 제어되는 시스템 |
| **컨트롤러** | C(들) | 제어 동작 계산 |
| **센서** | H(들) | 출력 측정 |
| **합산 접합** | ⊕ | 오류 계산: r − y |
| **참고** | r(티) | 원하는 출력 |
| **오류** | e(t) = r(t) − y(t) | 원하는 것과 실제의 차이 |
| **소란** | d(티) | 플랜트에 영향을 미치는 원치 않는 입력 |
### 폐루프 전달 함수
표준 부정적인 피드백 시스템의 경우:
T(들) = C(들)G(들) / (1 + C(들)G(들)H(들))
| 수량 | 공식 |
|------------|---------|
| 개루프 전달 함수 | L(들) = C(들)G(들)H(들) |
| 폐루프 전달 함수 | T(들) = L(들)/H(들) / (1 + L(들)) |
| 오류 전달 함수 | E(들)/R(들) = 1 / (1 + L(들)) |
| 감도 | S(들) = 1 / (1 + L(들)) |

## 전달 함수
**전달 함수** H(s) = Y(s)/X(s)는 라플라스 영역에서 선형 시불변(LTI) 시스템의 입출력 관계를 설명합니다.
### 표준 양식
| 시스템 | 전달 함수 | 매개변수 |
|---------|------|------------|
| **1차** | K/(τs + 1) | K = 이득, τ = 시간 상수 |
| **2차** | KΩₙ²/(s² + 2ζΩₙs + Ωₙ²) | Ωₙ = 고유 주파수, ζ = 감쇠비 |
| **통합자** | K/초 | — |
| **차별화 요소** | Ks | — |
| **지연** | e^{−sT_d} | T_d = 시간 지연 |
### 2차 시스템 동작
| 감쇠비 ζ | 행동 | 극 위치 |
|----|------------|---------------|
| ζ = 0 | 감쇠되지 않은 진동 | 순수한 상상 |
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 | 과도한 감쇠(느리게, 진동 없음) | 실제적이고 뚜렷한 |
### 성능 지표(단계 응답)
| 미터법 | 공식(2차, 과소감쇠) | 설명 |
|---------|---------|-------------|
| 상승 시간(t_r) | ≒ 1.8/Ωₙ | 10%에서 90%로 갈 시간 |
| 피크타임(t_p) | π/(Ωₙ√(1−ζ²)) | 첫 번째 최대값까지의 시간 |
| 오버슈트(M_p) | e^{−πζ/√(1−ζ²)} × 100% | 최종 값보다 높은 최대 피크 |
| 정착 시간(t_s) | ≒ 4/(ζΩₙ) | 최종 시간의 2% 이내로 유지되는 시간 |
| 정상상태 오류 | 시스템 유형에 따라 다름 | 원하는 것과 실제의 차이(t → ) |

## PID 컨트롤러
**PID 컨트롤러**는 업계에서 가장 널리 사용되는 컨트롤러입니다(산업 컨트롤러의 90% 이상).
### PID 공식
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
라플라스 도메인에서: C(s) = K_p + K_i/s + K_d s
| 기간 | 효과 | 너무 많다 | 너무 적다 |
|------|---------|----------|------------|
| **비례(K_p)** | 현재 오류에 반응 | 진동, 불안정성 | 느린 응답, 큰 오류 |
| **적분(K_i)** | 정상 상태 오류 제거 | 오버슈트, 진동 | 영구 오프셋 |
| **미분(K_d)** | 향후 오류 예측(댐핑) | 소음 증폭 | 불량한 교란 거부 |
### PID 조정 방법
| 방법 | 접근 |
|---------|----------|
| **지글러-니콜스** | 진동할 때까지 K_u를 증가시킵니다. K_u와 기간 P_u를 사용하여 이득 설정 |
| **코헨-쿤** | 단계 응답 매개변수(이득, 시상수, 데드 타임) 기반 |
| **IMC(내부 모델 제어)** | 프로세스 모델을 기반으로 합니다. 우수한 견고성을 제공합니다 |
| **자동 튜닝** | 온라인 식별 + 튜닝(많은 최신 컨트롤러) |
| **수동** | K_p로만 시작하고 K_i를 추가하여 오프셋을 제거하고 K_d를 추가하여 감쇠 |
### 지글러-니콜스 규칙
1. K_i = K_d = 0으로 설정
2. 지속적인 진동까지 K_p 증가: 최종 이득 K_u, 주기 P_u
3. 이득 설정:
| 컨트롤러 | K_p | 케이 | K_d |
|------------|------|------|-----|
| 피 | 0.5K_u | — | — |
| PI | 0.45K_u | 1.2K_u/P_u | — |
| PID | 0.6K_u | 2K_u/P_u | K_u P_u/8 |

## 안정성 분석
출력이 제한된 입력에 대해 제한된 상태로 유지되면 시스템은 **안정적**입니다(BIBO 안정성).
### 극 기반 안정성
| 조건 | 안정성 |
|------------|------------|
| 왼쪽 절반 평면의 모든 극(Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) | 불안정 |
| 가상축의 극점(Re(s) = 0) | 약간 안정적(또는 반복적으로 불안정함) |
### Routh-Hurwitz 기준
명시적으로 극점을 계산하지 않고 안정성을 결정합니다. 특성 다항식 계수로부터 Routh 배열을 구성합니다.
**규칙:** 첫 번째 열의 부호 변경 횟수는 오른쪽 반평면 극의 수와 같습니다.
### 나이퀴스트 안정성 기준
복소 평면에 개루프 주파수 응답 L(jΩ)을 플로팅합니다.
**규칙:** 나이퀴스트 플롯이 개방 루프 불안정 극점 수와 동일한 횟수만큼 반시계 방향으로 점 (−1, 0)을 둘러싸는 경우 폐쇄 루프 시스템은 안정적입니다.
**이득 마진:** 불안정하기 전에 증가할 수 있는 이득의 양입니다(플롯에서 실제 축의 -1까지의 거리).
**위상 여유:** 불안정하기 전에 위상 지연이 얼마나 증가할 수 있는지(이득 교차 시 플롯에서 단위원까지의 각도)
### 보드 플롯 분석
게인(dB) 및 위상(도) 대 주파수(로그 스케일)를 플롯합니다.
| 미터법 | 정의 | 원하는 가치 |
|---------|------------|---------------|
| **이익마진(GM)** | 위상 = −180°에서 0dB에 도달하도록 이득 증가 | > 6dB |
| **위상 여유(PM)** | 이득 교차 시 위상(0dB) + 180° | > 45° |
| **이득 크로스오버** | 이득 = 0dB인 주파수 | — |
| **위상 교차** | 위상 = −180°인 주파수 | — |

## 상태공간 표현
MIMO(다중 입력 다중 출력) 시스템의 경우 상태공간 형식이 전달 함수보다 더 자연스럽습니다.
### 표준 양식
ẋ(t) = Ax(t) + Bu(t) (상태방정식)
y(t) = Cx(t) + Du(t) (출력 방정식)
| 매트릭스 | 이름 | 치수 |
|---------|------|------------|
| A | 시스템/상태 매트릭스 | n × n |
| 비 | 입력 행렬 | n × m |
| 다 | 출력 행렬 | p × n |
| 디 | 피드스루 매트릭스 | p × m |
### 상태공간으로부터의 전달 함수
G(s) = C(sI − A)⁻¹B + D
### 제어 가능성 및 관찰 가능성
| 부동산 | 테스트 | 의미 |
|------------|------|---------|
| **제어 가능** | 순위[C_B] = n(여기서 C_B = [B, AB, A²B, ...]) | 어떤 상태로도 조종 가능 |
| **관찰 가능** | 순위[O_B] = n(여기서 O_B = [C; CA; CA²; ...]) | 출력에서 상태를 확인할 수 있습니다 |
시스템은 피드백을 통해 안정화되도록 제어할 수 있어야 하고 상태 추정을 위해 관찰할 수 있어야 합니다.
### 상태 피드백
u = −Kx + r(전체 상태 피드백)
폐루프: ẋ = (A − BK)x + Br
**극점 배치:** A − BK가 원하는 고유값(극점)을 갖도록 K를 선택합니다.

## 최적의 제어
### 선형 2차 조정기(LQR)
최소화: J = ∫₀^킵 (xᵀQx + uᵀRu) dt
여기서 Q ≥ 0(상태 비용)이고 R > 0(통제 비용)입니다.
**해결책:** u = −Kx 여기서 K = R⁻¹BᵀP이고 P는 **대수적 리카티 방정식을 푼다:**
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
| 튜닝 | 효과 |
|---------|---------|
| Q 증가 | 더 빠른 응답, 더 많은 제어 노력 |
| R 증가 | 느린 응답, 적은 제어 노력 |
| 질문 ≫ R | 공격적인 제어(예: 높은 K_p) |
### 칼만 필터
가우스 잡음이 있는 선형 시스템에 대한 최적의 상태 추정기입니다.
**시스템 모델:**
ẋ = Ax + Bu + w (프로세스 노이즈 w ~ N(0, Q))
y = Cx + v (측정 노이즈 v ~ N(0, R))
**칼만 필터 방정식:**
- 예측: x̂⁻ = Ax̂ + Bu, P⁻ = APAᵀ + Q
- 업데이트: K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻1, x̂ = x̂⁻ + K(y − Cx̂⁻), P = (I − KC)P⁻
칼만 필터는 LQR 이중 필터로 추정 오류 분산을 최소화합니다.

제어 이론은 시스템이 원하는 대로 안정적이고 견고하며 효율적으로 작동하도록 만드는 수학입니다. 피드백, 안정성 및 최적성의 원칙은 로봇공학에서 강화 학습, 경제학에서 생물학에 이르기까지 다양한 분야에서 보편적인 것으로 입증되었습니다. 데이터 과학자에게 제어 이론은 적응 시스템을 이해하고, 안정적인 훈련 절차를 설계하고, 동적 환경과 상호 작용하는 지능형 에이전트를 구축하기 위한 언어를 제공합니다.
