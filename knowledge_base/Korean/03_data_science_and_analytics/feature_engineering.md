# 기능 엔지니어링
기능 엔지니어링은 원시 데이터를 기계 학습 모델을 더욱 효과적으로 만드는 표현으로 변환하는 프로세스입니다. 이는 종종 ML 파이프라인에서 가장 중요한 단계로 설명됩니다. 모델에 제공하는 기능은 선택한 알고리즘보다 더 중요합니다. 잘 만들어진 기능을 갖춘 간단한 모델은 일반적으로 처리되지 않은 원시 입력이 있는 복잡한 모델보다 성능이 뛰어납니다. 기술은 모델이 학습할 수 있는 신호를 생성할 수 있을 만큼 도메인과 데이터를 모두 이해하는 데 있습니다.
---

## 특성 엔지니어링이 중요한 이유
| 요인 | 영향 |
|---------|---------|
| **신호 품질** | 더 나은 기능 = 모델이 학습할 더 명확한 패턴 |
| **모델 단순성** | 좋은 기능을 사용하면 단순한 모델이 더 잘 작동할 수 있습니다. 복잡한 아키텍처의 필요성 감소 |
| **훈련 속도** | 관련성이 높고 확장성이 뛰어난 기능이 더 빠르게 수렴 |
| **일반화** | 도메인 정보 기능은 모델이 보이지 않는 데이터에 대해 작업하는 데 도움이 됩니다 |
| **해석성** | 이해관계자에게 의미 있는 기능을 더 쉽게 설명할 수 있음 |
---

## 특성 변환 유형
### 수치 변환
| 변환 | 공식/설명 | 사용 시기 |
|---------------|---------|-------------|
| **로그 변환** | 로그(x) 또는 로그(x + 1) | 오른쪽으로 치우친 분포; 금전적 가치 |
| **제곱근** | 제곱(x) | 적당한 왜곡; 카운트 데이터 |
| **박스-콕스** | 최적의 거듭제곱 변환을 찾는 매개변수 변환 | 데이터를 보다 정규 분포로 만들기 |
| **여-존슨** | Box-Cox와 비슷하지만 음수 값을 처리합니다 | 음수 값으로 왜곡된 데이터 |
| **표준화** | (x - 평균) / 표준 | 다양한 규모의 기능; 정규성을 가정하는 알고리즘 |
| **최소-최대 확장** | (x - 최소) / (최대 - 최소) | [0, 1]에 대한 경계 기능; 이미지 픽셀 값 |
| **강력한 확장** | (x - 중앙값) / IQR | 이상값이 있는 데이터 |
| **비닝** | 연속형을 범주형으로 변환 | 비선형 관계; 결정 트리 |
| **다항식 특징** | x², x³, x₁×x² | 선형 모델에서 비선형 관계 캡처 |
### 범주형 인코딩
| 인코딩 | 설명 | 사용 시기 |
|----------|-------------|-------------|
| **원-핫 인코딩** | 각 범주에 대한 이진 열 만들기 | 낮은 카디널리티 카테고리 트리 기반 모델은 기본적으로 처리 |
| **라벨 인코딩** | 각 카테고리에 정수 할당 | 순서형 범주; 트리 기반 모델 |
| **대상 인코딩** | 범주를 목표 변수의 평균으로 바꾸기 | 높은 카디널리티 카테고리 스무딩으로 과적합 방지 |
| **주파수 인코딩** | 카테고리를 개수 또는 빈도로 바꾸기 | 빈도 자체가 유익한 경우 |
| **바이너리 인코딩** | 정수로 인코딩된 범주를 이진수로 변환 | 높은 카디널리티; 차원성 대 원핫 감소 |
| **삽입** | 조밀한 벡터 표현 알아보기 | 매우 높은 카디널리티; 자연어 처리; 추천 시스템 |
| **해시 인코딩** | 고정된 개수의 기능으로 카테고리 해시 | 매우 높은 카디널리티; 온라인 학습 |
### 날짜 및 시간 기능
| 기능 | 설명 |
|---------|-------------|
| **시간** | 일일 패턴 캡처(출퇴근 시간, 야간) |
| **요일** | 주중 vs 주말 효과 |
| **월/분기** | 계절 패턴 |
| **주말임** | 주말 바이너리 플래그 |
| **휴일임** | 공휴일에 대한 이진 플래그 |
| **이벤트 이후 시간** | 마지막 구매 이후 일수; 마지막 로그인 이후 시간 |
| **순환 인코딩** | sin(2π × 시간 / 24), cos(2π × 시간 / 24) — 시간의 순환 특성 보존 |

## 누락된 값 처리
| 전략 | 설명 | 사용 시기 |
|----------|-------------|-------------|
| **행 삭제** | 누락된 값이 있는 행 제거 | 누락된 데이터는 작은 부분입니다. MCAR(무작위로 완전히 누락됨) |
| **열 삭제** | 결측값이 너무 많은 기능 제거 | 기능이 대부분 누락되었습니다. 중요하지 않음 |
| **평균/중앙값 대치** | 특성의 평균 또는 중앙값으로 채우기 | 단순한; 평균은 유지하지만 분산은 감소 |
| **모드 대치** | 가장 빈번한 값으로 범주형 채우기 | 범주형 기능 |
| **KNN 대치** | k-최근접 이웃을 사용하여 결측값 추정 | 유사한 인스턴스가 누락된 값을 예측하는 데 도움이 되는 경우 |
| **모델 기반 대체** | 누락된 값을 예측하도록 모델 학습 | 더 정확합니다. 계산 비용이 많이 든다 |
| **표시 누락** | 누락을 표시하는 이진 열 추가 | 누락 자체가 유익한 경우 |
| **보간** | 보간된 값으로 채우기(선형, 스플라인) | 시계열; 주문된 데이터 |
---

## 기능 선택
### 필터 방법
| 방법 | 설명 |
|---------|-------------|
| **상관관계** | 서로 상관관계가 높은 기능 제거 |
| **분산 임계값** | 분산이 거의 0인 특징 제거 |
| **상호 정보** | 각 기능이 대상에 대해 제공하는 정보 측정 |
| **카이제곱** | 범주형 특성과 대상 간의 독립성 테스트 |
| **ANOVA F-검정** | 숫자 특성 평균이 대상 클래스에 따라 다른지 테스트 |
### 래퍼 메서드
| 방법 | 설명 |
|---------|-------------|
| **앞으로 선택** | 비어 있는 상태로 시작하십시오. 한 번에 하나씩 최고의 기능을 추가하세요 |
| **역진 제거** | 모두부터 시작하십시오. 최악의 기능을 한 번에 하나씩 제거 |
| **재귀적 기능 제거(RFE)** | 모델을 반복적으로 훈련합니다. 가장 덜 중요한 기능을 제거 |
### 임베디드 메소드
| 방법 | 설명 |
|---------|-------------|
| **L1 정규화(올가미)** | 관련 없는 기능 가중치를 0으로 축소 |
| **트리 기반 중요도** | 트리 모델의 기능 중요도 사용 |
| **SHAP 값** | 예측에 대한 각 기능의 기여도 측정 |

## 도메인별 기능 엔지니어링
### 텍스트 기능
| 기능 | 설명 |
|---------|-------------|
| **TF-IDF** | 역 문서 빈도로 가중치가 부여된 용어 빈도 |
| **단어 임베딩** | 의미적 의미를 포착하는 밀집된 벡터(Word2Vec, GloVe) |
| **문자 N-그램** | 하위 단어 패턴을 캡처합니다. 오타 및 형태학에 유용함 |
| **텍스트 통계** | 길이; 단어 수; 문장 수; 평균 단어 길이 |
| **가독성 점수** | 플레쉬-킨케이드(Flesch-Kincaid); 총격 안개 지수 |
### 시계열 기능
| 기능 | 설명 |
|---------|-------------|
| **지연 기능** | 이전 값: y(t-1), y(t-7), y(t-30) |
| **롤링 통계** | 창에 대한 평균, 표준, 최소, 최대 |
| **차이점** | y(t) - y(t-1); 트렌드를 포착하다 |
| **계절별 차이** | 연간 계절성이 있는 월별 데이터의 경우 y(t) - y(t-12) |
| **푸리에 항** | 계절 패턴에 대한 사인 및 코사인 용어 |
### 이미지 기능(딥러닝 이전)
| 기능 | 설명 |
|---------|-------------|
| **HOG**(지향적 기울기 히스토그램) | 가장자리 방향 분포 |
| **LBP**(로컬 바이너리 패턴) | 텍스처 설명 |
| **SIFT**(규모 불변 특성 변환) | 키포인트 설명자 |
| **색상 히스토그램** | 이미지의 색상 분포 |

## 요약
기능 엔지니어링은 도메인 지식이 머신러닝과 만나는 곳입니다. 이는 지저분하고 불완전하며 고차원적인 원시 데이터를 모델이 학습할 수 있는 깨끗하고 유익한 표현으로 변환하는 프로세스입니다. 수치 변환은 기울이기와 크기 조정을 처리합니다. 범주형 인코딩은 레이블을 모델이 사용할 수 있는 숫자로 변환합니다. 날짜 기능은 시간적 패턴을 포착합니다. 결측값 전략은 불완전한 데이터를 처리합니다. 기능을 선택하면 노이즈와 중복성이 제거됩니다. 최고의 기능 엔지니어는 탐정처럼 생각합니다. 데이터에 어떤 신호가 있어야 하는지, 해당 신호가 어디에 숨겨져 있는지, 정직하고(데이터 누출 없음) 재현 가능하며 시간이 지남에 따라 변경되는 강력한 방식으로 신호를 추출하는 방법을 묻습니다.
