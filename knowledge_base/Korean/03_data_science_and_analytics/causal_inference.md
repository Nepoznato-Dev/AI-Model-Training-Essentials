# 인과 추론
인과 추론은 단순히 상관관계가 있는지 여부가 아니라 실제로 다른 원인이 발생하는지 여부를 판단하는 과학입니다. 상관관계는 두 변수가 함께 움직인다는 것을 나타냅니다. 인과관계는 하나를 바꾸면 다른 하나도 바뀔 것이라고 말한다. 이러한 구별은 의학(이 약이 효과가 있는가?), 정책(이 개입이 빈곤을 감소시키는가?), 비즈니스(이 광고 캠페인이 매출을 증가시키는가?) 및 과학(이 메커니즘이 현상을 설명하는가?)에서 엄청나게 중요합니다.
---

## 상관관계 대 인과관계
| 개념 | 설명 | 예 |
|---------|-------------|---------|
| **상관관계** | 두 변수가 함께 움직입니다 | 여름에는 아이스크림 판매와 익사 사망자 모두 증가 |
| **원인** | 하나의 변수가 다른 변수에 직접 영향을 미칩니다 | 흡연은 폐암을 유발합니다 |
| **혼란스러운** | 세 번째 변수는 | 더운 날씨로 인해 아이스크림 판매와 수영(그리고 익사)이 발생합니다 |
| **역인과관계** | 그 효과는 실제로 예상되는 원인을 유발합니다 | 사람들은 아프기 때문에 건강보조식품을 구입하는 것이지, 그 반대가 아닙니다 |
| **가짜 상관관계** | 우연한 관계 | 1인당 치즈 소비량은 침대 시트 얽힘으로 인한 사망과 관련이 있습니다 |
---

## 잠재적 결과 프레임워크
### 루빈 인과모델
| 개념 | 설명 |
|---------|-------------|
| **잠재적 결과** | 각 단위에 대해 Y(1)을 처리하면 결과가 있고, 처리하지 않으면 Y(0) |
| **치료효과** | 차이: 주어진 단위에 대한 Y(1) - Y(0) |
| **기본적인 문제** | 동일한 단위에 대해 Y(1)과 Y(0)을 모두 관찰할 수는 없습니다. 하나만 볼 수 있습니다. |
| **평균 치료 효과(ATE)** | 인구 전체의 개별 치료 효과 평균 |
| **반사실** | 관찰되지 않은 결과 - 다른 조건에서 어떤 일이 발생했을까요 |
### 주요 가정
| 가정 | 의미 | 만족시키는 방법 |
|------------|---------|---|
| **무시성(혼란 없음)** | 관찰된 공변량이 주어지면 치료 할당은 잠재적인 결과와 무관합니다 | 무작위화; 모든 혼란 요인 측정 |
| **긍정성(중복)** | 모든 단위는 치료 | 그룹 간 공변량 중복 확인 |
| **SUTVA** (안정적인 단위 처리 가치 가정) | 한 단위의 치료는 다른 단위의 결과에 영향을 미치지 않습니다. 치료가 일관됨 | 간섭 없음; 숨겨진 버전의 치료가 없습니다 |
| **일관성** | 관찰된 결과는 받은 치료 하의 잠재적 결과와 동일합니다 | 잘 정의된 치료 |

## 인과 추론 방법
### 실험 방법
| 방법 | 설명 | 힘 | 제한사항 |
|---------|-------------|----------|------------|
| **무작위 대조 시험(RCT)** | 치료 또는 대조에 단위를 무작위로 할당 | 골드 스탠다드; 혼란을 제거합니다 | 값비싼; 때로는 비윤리적입니다. 일반화할 수 없습니다 |
| **A/B 테스트** | 비즈니스/기술 맥락에서의 RCT | 단순한; 엄격한 | 단기 지표 참신한 효과; 간섭 |
| **스위치백 실험** | 기간에 따른 대체 치료 | 시장 간섭 처리 | 안정적인 환경 필요 |
### 준실험 방법
| 방법 | 설명 | 주요 가정 |
|---------|-------------|---|
| **DiD(차이의 차이)** | 시간 경과에 따른 치료군과 대조군 간의 결과 변화 비교 | 평행 추세: 그룹은 치료 없이 동일한 궤적을 따랐을 것입니다 |
| **회귀 불연속성(RD)** | 치료 컷오프 바로 위와 바로 아래의 단위 비교 | 컷오프 근처의 단위는 비교할 수 있습니다(마치 무작위인 것처럼) |
| **도구변수(IV)** | 치료에 영향을 주지만 치료를 통하지 않는 한 결과에는 영향을 미치지 않는 변수 사용 | 도구는 치료와 상관관계가 있습니다. 치료를 통해서만 결과에 영향을 미침 |
| **합성 제어** | 처리된 단위와 일치하도록 제어 단위의 가중치 조합 구성 | 합성 제어는 처리된 단위의 반사실적 |
| **성향점수 매칭** | 처리 확률이 비슷한 처리 단위와 대조 단위를 일치시키세요 | 모든 혼란 요인은 측정되어 성향 모델에 포함됩니다.
### 차이의 차이(시각화)
| 기간 | 치료군 | 통제 그룹 | 차이 |
|---------|---------------|---------------|------------|
| **전처리** | Y_t_pre | Y_c_pre | Y_t_pre - Y_c_pre |
| **치료후** | Y_t_포스트 | Y_c_포스트 | Y_t_post - Y_c_post |
| **DiD 추정** | | | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) |

## 방향성 비순환 그래프(DAG)
DAG는 인과관계 가정을 인코딩하고 혼란 요인을 식별하기 위한 시각적 도구입니다.
### 기본 구조
| 구조 | 패턴 | 시사점 |
|------------|---------|-------------|
| **체인** | A → B → C | A와 C는 B를 통해 연관됩니다. B를 제어하면 경로가 차단됩니다. |
| **포크** | A ← B → C | A와 C는 B에 의해 혼동됩니다. B를 제어하면 경로가 차단됩니다. |
| **콜라이더** | A → B ← C | A와 C는 독립적이다. B를 제어하면 경로가 열립니다(가짜 연결 생성) |
### DAG 규칙
| 규칙 | 설명 |
|------|-------------|
| **백도어 기준** | X가 Y에 미치는 인과 효과를 추정하려면 적절한 변수 |를 조건으로 모든 백도어 경로(X로 향하는 화살표가 있는 경로)를 차단하세요.
| **현관기준** | 백도어 경로를 차단할 수 없는 경우 중재자를 사용합니다. X → M → Y를 두 단계로 추정 |
| **콜라이더에 조건을 적용하지 마세요** | 일반적인 효과를 제어하면 가짜 경로가 열립니다 |
| **충돌체의 자손을 조건으로 삼지 마세요** | 충돌체 자체의 조절과 동일한 문제 |

## 일반적인 함정
| 함정 | 설명 | 예 |
|---------|-------------|---------|
| **변수편향 생략** | 혼란스러운 요인을 제어하지 못함 | 학력 추정 → 능력 통제 없이 소득 추정 |
| **과도한 통제** | 중재자 또는 충돌체에 대한 조건화 | 학력 → 소득 추정 시 직위 통제 |
| **선택 편향** | 치료에 의해 영향을 받는 변수에 대한 조건화 | 훈련학습 시 취업자만 분석 → 임금 |
| **불멸의 시간 편향** | 코호트 연구에서 개인 시간을 잘못 분류함 | 환자는 치료를 받을 수 있을 만큼 오래 생존해야 합니다 |
| **평균으로의 회귀** | 극단값은 평균 쪽으로 이동하는 경향이 있습니다 | 아픈 환자는 치료 후 호전됨 |
| **치료 후 편향** | 치료 후 발생하는 변수에 대한 조건화 | 약물 효능 평가 시 부작용 관리 |

## 요약
인과 추론은 '무슨 일이 일어났는지'를 넘어 '만약 상황이 달랐다면 무슨 일이 일어났을지'로 나아가는 것입니다. 근본적인 문제는 동일한 단위에 대해 처리된 결과와 처리되지 않은 결과를 모두 관찰할 수 없다는 것입니다. 즉, 반사실적은 항상 누락됩니다. 무작위 실험은 치료군과 대조군을 비교함으로써 이 문제를 해결합니다. 무작위화가 불가능할 경우 준실험 방법(DiD, 회귀 불연속, 도구 변수, 합성 제어)을 사용하여 관측 데이터로부터 반사실적을 재구성하려고 합니다. DAG는 가정을 명확하게 하고 제어할 올바른 변수를 식별하는 데 도움이 됩니다. 핵심 기술은 데이터 생성 프로세스에 대해 신중하게 생각하는 것입니다. 즉, 무엇이 원인인지, 혼란스러운 요소는 무엇인지, 충돌체는 무엇인지, 대안에서는 어떤 일이 발생했을지 등을 생각하는 것입니다.
