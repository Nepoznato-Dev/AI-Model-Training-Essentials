# 데이터 과학 및 분석
데이터 과학은 원시 데이터를 실행 가능한 통찰력으로 전환하는 분야입니다. 이는 통계, 컴퓨터 과학 및 도메인 전문 지식의 교차점에 있으며 금융에서 의료에 이르기까지 모든 부문에서 필수적이 되었습니다. 이 파일은 모든 실무자가 알아야 할 핵심 개념, 도구 및 워크플로를 안내합니다.
---

## 데이터 과학 프로세스
대부분의 프로젝트는 업계 표준 수명주기인 **CRISP-DM**의 일부 변형을 따릅니다.
| 단계 | 무슨 일이 일어나는지 | 일반적인 시간 |
|---------|-------------|-------------|
| **비즈니스 이해** | 목표, 성공 지표 및 제약 조건 정의 | 10~15% |
| **데이터 이해** | 데이터 수집, 탐색 및 프로파일링 | 10~15% |
| **데이터 준비** | 정리, 변형, 엔지니어 기능 | ~50~60% |
| **모델링** | 모델 선택 및 학습 | 10~15% |
| **평가** | 비즈니스 목표 대비 성과 평가 | 5~10% |
| **배포** | 모델을 프로덕션으로 배송 | 5~10% |
데이터 준비, 특히 데이터 정리는 데이터 과학자 시간의 약 80%를 소비하는 것으로 널리 추정됩니다.

## 데이터 유형 개요
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **구조적** | 행과 열로 구성 | SQL 테이블, 스프레드시트 |
| **구조화되지 않음** | 미리 정의된 형식 없음 | 텍스트, 이미지, 오디오, 비디오 |
| **반구조적** | 일부 조직이지만 유연함 | JSON, XML, HTML |
| **시계열** | 시간별로 색인된 순차적 데이터 | 주가, 센서 판독값 |
| **공간** | 지리적 또는 위치 기반 | GPS 좌표, 지도 데이터 |
| **그래프** | 관계를 나타내는 노드와 에지 | 소셜 네트워크, 지식 그래프 |

## 통계 기초
### 기술 통계와 추론 통계
기술 통계는 *가지고 있는* 것을 요약합니다. 추론 통계를 사용하면 *없는* 것(더 넓은 인구 집단)에 대한 결론을 도출할 수 있습니다.
| 개념 | 핵심 아이디어 |
|---------|------------|
| **중심 경향** | 평균(이상값에 민감), 중앙값(견고함), 모드(가장 빈번함) |
| **분산** | 범위, 분산, 표준편차, 사분위간 범위 |
| **분포 형태** | 왜도(비대칭), 첨도(꼬리 무거움) |
| **가설 검정** | 귀무 가설과 대립 가설, p-값, 유의 수준(α) |
| **신뢰구간** | 실제 모집단 매개변수를 포함할 가능성이 있는 범위 |
| **유형 I/유형 II 오류** | 거짓 긍정(true null 거부) / 거짓 부정(실제 효과 누락) |
### 일반적인 통계 테스트
| 테스트 | 사용 시기 |
|------|-------------|
| **t-테스트** | 두 그룹 간의 평균 비교 |
| **ANOVA** | 세 개 이상의 그룹에 대한 평균 비교 |
| **카이제곱** | 범주형 변수의 독립성 테스트 |
| **만-휘트니 U** | t-검정에 대한 비모수적 대안(정규성 가정 없음) |
| **피어슨 상관관계** | 두 연속변수 사이의 선형 관계 |
| **Spearman 상관관계** | 단조로운 관계(순위 기반, 더욱 강력함) |
### 알아야 할 확률 분포
| 유통 | 사용 사례 |
|-------------|----------|
| **보통** | 자연 현상, 측정 오류 - 고전적인 종형 곡선 |
| **이항** | 성공/실패 횟수(동전던지기, 전환율) |
| **푸아송** | 고정된 간격의 이벤트 수(시간당 호출 수, 배치당 결함) |
| **지수** | 이벤트 간 시간(대기 시간, 실패 간격) |
| **t-분포** | 작은 표본 또는 알 수 없는 모집단 분산 |
| **카이제곱** | 범주형 데이터 분석, 적합도 테스트 |

## 데이터 수집 및 저장
### 데이터의 출처
실제 데이터는 관계형 데이터베이스, API(REST, GraphQL), 플랫 파일(CSV, JSON, Parquet), 스트리밍 플랫폼(Kafka, Kinesis), 설문조사, 공개 저장소(Kaggle, 정부 포털) 등 다양한 소스에서 가져옵니다. 수신하는 형식에 따라 전처리 전략이 결정됩니다.
### 데이터 웨어하우징 개념
| 개념 | 설명 |
|---------|-------------|
| **ETL** | 추출 → 변환 → 로드 - 기존 파이프라인 접근 방식 |
| **엘트** | 추출 → 로드 → 변환 - 최신 클라우드 접근 방식(원본 로드, 창고 내 변환) |
| **데이터 레이크** | 원시 형식으로 저장된 원시 데이터(읽기 스키마) |
| **데이터 웨어하우스** | 분석에 최적화된 구조화되고 처리된 데이터(Schema-on-write) |
| **데이터 마트** | 하나의 부서 또는 도메인으로 범위가 지정된 웨어하우스의 하위 집합 |
| **스타 스키마** | 차원 테이블로 둘러싸인 중앙 팩트 테이블 |
| **눈송이 스키마** | 정규화된 차원 테이블(중복성 감소, 조인 증가) |
### 데이터베이스 유형
| 유형 | 예 | 최고의 대상 |
|------|----------|----------|
| **관계형(SQL)** | PostgreSQL, MySQL, 오라클 | 구조화된 데이터, ACID 트랜잭션 |
| **문서** | 몽고DB, 카우치DB | 유연한 스키마, JSON과 유사한 데이터 |
| **키-값** | Redis, DynamoDB | 캐싱, 세션, 단순 조회 |
| **컬럼 패밀리** | 카산드라, HBase | 쓰기가 많은 워크로드, 시계열 |
| **그래프** | Neo4j, 아마존 넵튠 | 관계, 소셜 네트워크 |
| **시계열** | InfluxDB, 타임스케일DB | IoT 측정항목, 모니터링 |
| **벡터** | 솔방울, 밀버스 | ML/AI 검색을 위한 스토리지 내장 |

## 데이터 전처리 및 특성 엔지니어링
### 청소 체크리스트
모든 실제 데이터 세트에는 문제가 있습니다. 표준 정리는 다음과 같습니다.
| 이슈 | 접근 |
|-------|----------|
| **누락된 값** | 대치(평균, 중앙값, 예측) 또는 희소한 경우 삭제 |
| **이상치** | IQR 또는 Z-점수를 통해 감지합니다. 캡핑 또는 변형 처리 |
| **중복** | 식별 및 제거 |
| **불일치** | 형식 표준화, 오타 수정, 단위 표준화 |
### 변환 기술
| 기술 | 그것이 하는 일 |
|------------|-------------|
| **정규화** | 값을 0~1 범위로 조정 |
| **표준화** | Z-점수: 평균 = 0, 표준 = 1 |
| **원-핫 인코딩** | 범주를 이진 열로 변환 |
| **라벨 인코딩** | 범주에 정수 레이블을 할당합니다 |
| **로그 변환** | 데이터의 오른쪽 편향 감소 |
| **비닝** | 연속 값을 개별 버킷으로 그룹화 |
### 기능 엔지니어링
기능 엔지니어링은 보통의 모델과 훌륭한 모델의 차이를 결정하는 경우가 많습니다. 주요 기술은 다음과 같습니다.
- **기능 생성**: 기존 열에서 새 열 파생(예: `age`에서 `age_group`).
- **기능 선택**: 필터 방법(상관), 래퍼 방법(재귀 제거), 내장 방법(LASSO, 트리 중요도).
- **차원성 감소**: 선형용 PCA, 시각화용 t-SNE 또는 UMAP.
- **상호작용 용어**: 특징을 곱셈적으로 결합하여 결합 효과를 포착합니다.

## 탐색적 데이터 분석(EDA)
EDA는 모델링하기 전에 데이터에 대한 직관을 개발하는 곳입니다. 목표는 패턴, 이상 현상, 관계를 찾아내는 것입니다.
### 올바른 차트 선택
| 차트 유형 | 최고의 대상 |
|------------|----------|
| **히스토그램** | 단일 변수의 분포 |
| **박스 플롯** | 5개 숫자 요약, 이상치 감지 |
| **산점도** | 두 연속변수 사이의 관계 |
| **히트맵** | 상관 행렬, 밀도 시각화 |
| **막대형 차트** | 카테고리 비교 |
| **선 차트** | 시간 경과에 따른 추세 |
| **바이올린 플롯** | 분포 밀도 + 상자 그림 요약 |
| **쌍 도표** | 모든 변수 쌍의 빠른 개요 |
### Python EDA 스택
| 도서관 | 역할 |
|---------|------|
| **판다** | 데이터 조작 및 분석 |
| **엉망** | 수치 컴퓨팅 |
| **매트플롯립** | 기초 계획 |
| **시본** | 통계 시각화(matplotlib 기반) |
| **음모** | 대화형 웹 기반 시각화 |
| **사이피** | 과학 컴퓨팅 및 통계 |

## 데이터 과학의 머신러닝
### 지도 학습 개요
| 작업 | 알고리즘 |
|------|------------|
| **회귀**(숫자 예측) | 선형, 능형/LASSO, 의사결정 트리, 랜덤 포레스트, 그래디언트 부스팅(XGBoost, LightGBM) |
| **분류**(범주 예측) | 로지스틱 회귀, k-NN, Naive Bayes, SVM, 의사결정 트리, 랜덤 포레스트, 신경망 |
### 비지도 학습 개요
| 작업 | 알고리즘 |
|------|------------|
| **클러스터링** | k-평균, 계층적, DBSCAN, 가우스 혼합 모델 |

| **협회 규정** | Apriori, FP-성장 |
### 모델 평가
| 측정항목 유형 | 주요 지표 |
|-------------|-------------|
| **분류** | 정확도, 정밀도, 재현율, F1 점수, ROC-AUC, 혼동 행렬 |
| **회귀** | MAE, MSE, RMSE, R², 조정된 R² |
| **검증** | k-겹 교차 검증, 계층화, 시계열 분할 |
| **튜닝** | 그리드 검색, 무작위 검색, 베이지안 최적화 |

### 대시보드 디자인 원칙

| 카테고리 | 예 |

| **고객** | 획득 비용(CAC), 이탈률, NPS, 만족도 점수 |
| **작동** | 효율성 비율, 주기 시간, 불량률 |
| **마케팅** | 전환율, 클릭률, ROAS, 기여도 |
| **제품** | 일일 활성 사용자, 참여, 유지, 기능 채택 |

## 고급 분석
| 접근 | 기술 | 사용 시기 |
|------------|------------|------------|

| **규정** | 선형 프로그래밍, 몬테카를로 시뮬레이션, A/B 테스트, 다중 무장 도적 | 의사결정 최적화 |
| **텍스트 분석** | 토큰화, 감정 분석, 주제 모델링(LDA), NER, 단어 임베딩(Word2Vec, BERT) | 텍스트에서 통찰력 추출 |

## 새로운 트렌드
- **AutoML**: 자동화된 파이프라인 생성 및 모델 선택.
- **MLOps**: ML 수명주기 관리에 적용되는 DevOps 방식입니다.
- **Feature Stores**: 팀 전체에서 재사용할 수 있는 중앙 집중식 기능 관리입니다.
- **데이터 메시**: 분산화된 도메인 소유 데이터 아키텍처.
- **LLM 및 생성 AI**: 텍스트, 코드 및 이미지 워크플로를 변환하는 대규모 언어 모델입니다.
- **에지 분석**: 클라우드가 아닌 기기에서 데이터를 처리합니다.
- **인과 추론**: 상관 관계를 넘어 실제 원인과 결과를 이해합니다.
- **연합 학습**: 분산된 데이터를 이동하지 않고 모델을 학습합니다.
- **책임 있는 AI**: 윤리, 설명 가능성 및 투명성이 표준 요구 사항으로 자리잡고 있습니다.
