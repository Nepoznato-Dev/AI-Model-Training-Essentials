# 지리공간 분석
지리공간 분석은 지리적 구성 요소(좌표, 주소, 경계 또는 지구상의 위치와 연결된 모든 데이터)가 있는 데이터를 조사하는 프로세스입니다. "고객은 어디에 있습니까?", "최적의 경로는 무엇입니까?", "시간이 지남에 따라 토지 이용이 어떻게 변화합니까?"와 같은 질문에 답합니다. 모든 데이터 세트에는 공간 차원이 있으며 이를 이해하면 순수 통계 분석이 놓치는 통찰력을 얻을 수 있습니다.
---

## 핵심 개념
### 좌표계
| 시스템 | 설명 | 사용 사례 |
|---------|-------------|----------|
| **WGS 84 (EPSG:4326)** | 글로벌 표준; 위도/경도(도) | GPS; 대부분의 웹 매핑; GeoJSON |
| **웹 메르카토르(EPSG:3857)** | 지구본을 원통에 투영합니다. 극의 영역을 왜곡 | 구글 지도; 맵박스; 대부분의 웹 타일 서비스 |
| **UTM**(범용 가로 메르카토르) | 지구를 60개 구역으로 나눕니다. 미터 기반 | 군대; 측량; 고정밀 로컬 작업 |
| **영국 내셔널 그리드(EPSG:27700)** | OSGB36 데이터; 미터 기반 | 영국 매핑 |
| **지역 예측** | 특정 지역에 대한 맞춤형 예측 | 특정 부위의 왜곡 최소화 |
### 기하학 유형
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **포인트** | 단일 좌표 | 레스토랑; 센서; 고객 |
| **라인스트링** | 포인트의 순서 | 도로; 강; 경로 |
| **다각형** | 내부가 닫힌 모양 | 국가; 호수; 배달 구역 |
| **멀티포인트** | 포인트 수집 | 도시의 모든 버스 정류장 |
| **다중선문자열** | 라인 모음 | 네트워크의 모든 도로 |
| **다중 다각형** | 다각형 컬렉션 | 군도; 섬이 있는 나라 |
| **기하학컬렉션** | 혼합형 | 도시, 도로, 강이 있는 나라 |

## 데이터 형식
| 형식 | 유형 | 주요 기능 |
|---------|------|-------------|
| **GeoJSON** | 텍스트(JSON) | 사람이 읽을 수 있음 웹 친화적인; 모든 기하학 유형을 지원합니다 |
| **셰이프파일** | 바이너리(여러 파일) ​​| ESRI의 레거시 형식; .shp + .shx + .dbf + .prj |
| **KML** | XML | 구글 어스; 3D 및 시간 지원 |
| **지오패키지** | SQLite 기반 | 단일 파일; 래스터와 벡터를 지원합니다. 현대 표준 |
| **GeoParquet** | 원주형(마루바닥) | 대규모 데이터 세트에 효율적입니다. 데이터 엔지니어링 도구와 통합 |
| **WKT / WKB** | 텍스트/바이너리 | 잘 알려진 텍스트; 잘 알려진 바이너리; 데이터베이스 저장에 사용 |
| **MVT** | 바이너리 | Mapbox 벡터 타일; 웹 클라이언트에 지도 데이터를 제공하기 위한 |

## 공간 연산
### 기본 작업
| 운영 | 설명 | 예 |
|------------|-------------|---------|
| **거리** | 기하학 사이의 거리 계산 | "10km 이내에 있는 모든 병원 찾기" |
| **버퍼** | 주어진 거리에서 형상 주위에 다각형 만들기 | "학교 주변 500m 구역을 보여주세요" |
| **교차로** | 기하학 사이의 겹치는 영역 찾기 | "홍수 지역에는 어떤 구획이 있나요?" |
| **연합** | 기하학을 하나로 병합 | "모든 토지 구획을 단일 지역으로 결합" |
| **차이점** | 하나의 기하학을 다른 기하학에서 빼기 | "보호구역을 제외한 건설가능지역" |
| **포함 / 이내** | 하나의 도형이 다른 도형 내부에 있는지 테스트 | "이 배달 지역에는 어떤 고객이 있나요?" |
| **가장 가까운 이웃** | 가장 가까운 기하학 찾기 | "가장 가까운 소방서가 어디죠?" |
| **공간 조인** | 공간 관계를 기반으로 속성 결합 | "각 포인트를 포함하는 인구 조사 지역에 할당" |
### 공간 인덱싱
| 지수 유형 | 설명 | 사용 사례 |
|------------|-------------|----------|
| **R-트리** | 경계 상자 계층 구조; 가장 일반적인 | 포스트GIS; SQLite; 범용 |
| **쿼드트리** | 사분면으로의 재귀적 세분화 | 포인트 데이터; 게임 엔진 |
| **지오해시** | 계층적 그리드; 문자열로 인코딩 | 근접 검색; 데이터베이스 샤딩 |
| **H3** (우버) | 육각형 계층 그리드 | 해석학; 승차 공유; 유니폼 쓰레기통 |
| **S2** (구글) | 구체의 셀 기반 계층 구조 | 대규모 공간 인덱싱 |

## 지리공간 분석 패턴
### 일반적인 분석 유형
| 패턴 | 설명 | 사용 사례 |
|---------|-------------|----------|
| **포인트 패턴 분석** | 포인트 분포 조사 | 범죄 매핑; 질병발생 감지 |
| **핫스팟 분석** | 통계적으로 유의미한 클러스터 찾기 | 소매점 위치 범죄; 역학 |
| **네트워크 분석** | 경로 최적화; 서비스 지역 | 기호 논리학; 비상 대응; 유틸리티 |
| **공간 보간** | 샘플링되지 않은 위치의 추정값 | 공기질; 토양 특성; 날씨 |
| **토지이용변화 감지** | 시간 경과에 따른 위성 이미지 비교 | 도시 확장; 삼림벌채; 농업 |
| **적합성 분석** | 다양한 기준을 충족하는 위치 찾기 | 사이트 선택; 보존 계획 |
| **공간 자기상관** | 주변 값이 어떻게 관련되어 있는지 측정 | 부동산 가격 질병 확산 |
### 수정 가능한 면적 단위 문제(MAUP)
| 측면 | 문제 |
|---------|---------|
| **규모 효과** | 분석 단위의 크기(인구 조사 지역, 카운티, 주)에 따라 결과가 변경됩니다 |
| **구역화 효과** | 같은 축척이라도 경계선을 어떻게 그리느냐에 따라 결과가 달라진다 |
| **의미** | 한 집계 수준의 결과가 다른 집계 수준에 적용된다고 가정하지 마십시오. 항상 경계에 대한 민감도를 테스트하세요 |

## 실제 고려 사항
| 우려사항 | 안내 |
|---------|----------|
| **좌표계** | 항상 CRS를 확인하세요. 계산에 예측을 혼합하지 마십시오. 거리를 계산하기 전에 변환 |
| **정밀도** | 부동 소수점 정밀도는 작은 규모에서 중요합니다. 적절한 데이터 유형 사용 |
| **성능** | 공간 작업은 비용이 많이 듭니다. 공간 인덱스를 사용합니다. 표시를 위해 형상을 단순화 |
| **토폴로지** | 분석 전 기하학이 유효한지(자체 교차, 닫힌 다각형 없음) 확인 |
| **규모** | Web Mercator는 영역을 왜곡합니다. 면적 계산에 사용하지 마세요 |
| **데이터 품질** | 널 형상, 중복 꼭지점, 은색 다각형 확인 |
---

## 요약
지리공간 분석은 위치 데이터를 실행 가능한 통찰력으로 바꿔줍니다. 점, 선, 다각형은 실제 개체를 나타냅니다. 공간 작업(거리, 버퍼, 교차점, 조인)은 근접성, 중첩 및 포함에 대한 질문에 답합니다. 도구는 데이터베이스 규모 분석을 위한 PostGIS부터 Python 워크플로를 위한 GeoPandas, 웹 시각화를 위한 Deck.gl까지 다양합니다. 주요 과제는 올바른 좌표계 선택, 대규모 데이터세트로 성능 관리, MAUP(집계 경계 선택이 결과에 영향을 미친다는 사실)를 인식하는 것입니다. 배송 경로를 최적화하든, 질병 확산을 분석하든, 도시 성장을 매핑하든 지리공간 분석은 순수 숫자로는 포착할 수 없는 공간적 맥락을 제공합니다.
