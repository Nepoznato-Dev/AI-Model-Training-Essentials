# 신경과학
신경과학은 신경계, 즉 뇌, 척수 및 이를 신체에 연결하는 모든 신경에 대한 연구입니다. 이는 분자와 유전자, 개별 뉴런과 시냅스, 회로와 뇌 영역, 행동, 인지, 의식에 이르기까지 다양한 수준에 걸쳐 있습니다. 뇌는 알려진 우주에서 가장 복잡한 구조로, 수조 개의 시냅스로 연결된 대략 860억 개의 뉴런을 포함하고 있으며, 그것이 어떻게 작동하는지 이해하는 것은 과학의 가장 큰 과제 중 하나입니다.
---

## 뉴런
### 뉴런의 부분
| 구성요소 | 기능 |
|------------|----------|
| **수상돌기** | 다른 뉴런으로부터 신호를 수신합니다. 가지형 확장 |
| **세포체(소마)** | 수신 신호를 통합합니다. 핵을 포함 |
| **축삭** | 체세포로부터 전기 신호(활동 전위)를 전달하는 장섬유 |
| **미엘린 수초** | 축삭 주변의 절연층; 신호 전송 속도 향상 |
| **랑비에 노드** | 미엘린의 공백; 도약 전도 허용(노드 간 신호 점프) |
| **축삭 말단(시냅스 부톤)** | 신경전달물질을 시냅스로 방출 |
### 뉴런의 종류
| 유형 | 방향 | 기능 |
|------|-------------|----------|
| **감각(구심성)** | 몸 → 뇌 | 감각정보 전달(촉각, 온도, 통증, 시각 등) |
| **모터(원심성)** | 뇌 → 몸 | 근육과 땀샘을 제어 |
| **인터뉴런** | 중추신경계 내 | 뉴런을 다른 뉴런에 연결합니다. 대부분의 뉴런은 중간뉴런이다 |
---

## 뉴런이 통신하는 방법
### 활동 가능성
| 단계 | 설명 |
|-------|-------------|
| **휴식 잠재력** | 뉴런은 ~-70mV에 있습니다. 나트륨-칼륨 펌프로 이온 균형 유지 |
| **탈분극** | 자극은 나트륨 채널을 엽니다. Na+가 돌진합니다. 막 전위 상승 |
| **임계값** | 전위가 ~-55mV에 도달하면 활동 전위가 발생합니다(전부 아니면 전무) |
| **상승 단계** | 전압 개폐 나트륨 채널이 열립니다. 최대 +40mV까지의 스파이크 가능성 |
| **하강 단계** | 나트륨 채널이 닫힙니다. 칼륨 채널이 열려 있습니다. K+가 흘러나온다; 잠재적 하락 |
| **언더슈트(과분극)** | 잠재력이 잠시 휴식 수준 아래로 떨어짐 |
| **불응기** | 뉴런은 즉시 다시 발사될 수 없습니다. 단방향 전파 보장 |
### 시냅스
| 구성요소 | 역할 |
|------------|------|
| **시냅스전 뉴런** | 신호를 보냅니다. 신경 전달 물질과 함께 시냅스 소포가 포함되어 있습니다 |
| **시냅스 틈** | 뉴런 사이의 작은 간격(~20 nm) |
| **시냅스후 뉴런** | 신호를 수신합니다. 수용체 단백질을 가지고 |
| **신경전달물질** | 시냅스를 통과하는 화학 전달자 |
| **수용체** | 신경전달물질 결합; 이온 채널을 열거나 두 번째 메신저 폭포를 촉발합니다 |

## 주요 신경전달물질
| 신경전달물질 | 기능 | 관련 조건 |
|----|------------|---------|
| **글루타메이트** | 주요 흥분성 신경전달물질; 학습; 메모리 | 과잉 → 흥분독성(뇌졸중, 신경변성) |
| **가바** | 주요 억제성 신경전달물질; 신경 활동 감소 | 적자→불안, 간질 |
| **도파민** | 보상; 동기 부여; 모터 제어; 주의 | 적자 → 파킨슨병; 과잉 → 정신분열증 |
| **세로토닌** | 분위기; 잠; 식욕; 소화 | 적자 → 우울증, 불안 |
| **아세틸콜린** | 근육 활성화; 학습; 메모리 | 적자 → 알츠하이머병 |
| **노르에피네프린** | 각성; 경보; 스트레스 반응 | 조절장애 → ADHD; 우울증 |
| **엔돌핀** | 통증 완화; 즐거움 | 운동 유발 방출("러너스 하이") |

## 신경가소성
| 유형 | 설명 | 예 |
|------|-------------|---------|
| **시냅스 가소성** | 활동에 따른 시냅스의 강도 변화 | 장기 강화(LTP); 장기 우울증(LTD) |
| **구조적 가소성** | 뉴런은 새로운 수상돌기 또는 축삭을 성장시킵니다 | 새로운 기술을 학습합니다. 부상 회복 |
| **피질 재매핑** | 뇌 영역의 기능 재할당 | 시각 장애인의 시각 피질은 촉각과 소리를 처리합니다 |
| **신경발생** | 새로운 뉴런이 탄생합니다 | 해마에서 발생합니다. 운동과 학습으로 자극 |

## 연구 방법
| 방법 | 측정 대상 | 해결 |
|---------|----|------------|
| **fMRI** | 혈중 산소 농도(굵은 신호) → 뇌 활동 | 좋은 공간(~1mm); 불량한 시간(~1초) |
| **뇌파** | 두피의 전기적 활동 | 우수한 시간적(~1ms); 열악한 공간 |
| **메그** | 신경 활동으로 인한 자기장 | 좋은 시간적, 공간적 |
| **애완동물** | 방사성 추적자 → 대사 활동 | 적당한 공간적, 시간적 |
| **TMS** | 자기 펄스 → 일시적으로 뇌 영역을 방해 | 인과관계 증거; 제한된 깊이 |
| **단일 녹음** | 개별 뉴런의 전기적 활동 | 단일 세포; 침습적; 주로 동물 연구 |
| **광유전학** | 빛 활성화 뉴런 | 정밀한 제어; 동물 연구 |
| **DTI**(확산 텐서 이미징) | 백질 책자 | 연결 매핑 |

## 요약
신경과학은 이온 채널의 분자 메커니즘부터 주관적인 의식 경험에 이르기까지 모든 수준에서 신경계를 연구합니다. 뉴런은 글루타메이트, GABA, 도파민, 세로토닌과 같은 신경 전달 물질을 사용하여 전기 활동 전위와 화학적 시냅스를 통해 통신합니다. 뇌는 고급 인지를 담당하는 피질, 감정과 기억을 담당하는 변연계, 조정을 담당하는 소뇌 등 특수한 영역으로 구성되어 있습니다. 신경가소성은 뇌가 일생 동안 스스로를 재구성할 수 있다는 것을 의미합니다. 연구 방법은 fMRI(좋은 공간 해상도)부터 EEG(좋은 시간 해상도), 광유전학(정확한 인과관계 제어)까지 다양합니다. 뇌를 이해하는 것은 틀림없이 과학에서 가장 어려운 문제입니다. 뇌는 스스로 연구하는 유일한 기관입니다.
