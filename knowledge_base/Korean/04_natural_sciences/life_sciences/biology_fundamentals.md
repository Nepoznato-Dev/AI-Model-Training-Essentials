# 생물학 기초
생물학은 생명의 과학이다. 모든 생명체는 특정한 특징을 공유합니다. 세포로 구성되어 있고, 에너지를 사용하고, 성장하고, 환경에 반응하고, 번식하고, 진화합니다. 생물학은 단일 세포 내부의 분자 기계부터 전체 생태계의 상호 작용까지 포괄하며 의학, 농업, 생명 공학 및 보존의 기초입니다.
---

## 세포 - 기본 단위
모든 생명체는 세포로 이루어져 있습니다. 두 가지 기본 유형이 있습니다.
### 원핵생물과 진핵생물
| 기능 | 원핵생물 | 진핵생물 |
|---------|-------------|------------|
| **핵** | 아니요 — DNA는 자유롭게 떠다닙니다 | 예 — 막에 둘러싸인 DNA |
| **사이즈** | 소형(1~5μm) | 더 큼(10-100μm) |
| **예** | 박테리아, 고세균 | 동물, 식물, 곰팡이, 원생 생물 |
| **복잡성** | 단순 | 복잡한 내부 구조(소기관) |
| **재생산** | 이진 핵분열 | 유사분열 또는 감수분열 |
| **DNA 형태** | 단일 원형 염색체 | 다중 선형 염색체 |
| **소기관** | 없음(리보솜만 해당) | 미토콘드리아, ER, 골지체, 리소좀 등 |
### 주요 세포 소기관
| 소기관 | 기능 | 발견 장소 |
|------------|----------|----------|
| **핵** | DNA를 저장합니다. 세포 활동을 제어 | 진핵생물만 |
| **미토콘드리아** | 세포호흡; ATP(에너지 화폐) 생산 | 진핵생물만 |
| **엽록체** | 광합성; 빛 에너지를 화학 에너지로 변환 | 식물 세포만 |
| **소포체** | 단백질과 지질 합성 | 진핵생물만 |
| **골지체** | 단백질을 수정, 포장 및 배송 | 진핵생물만 |
| **리보솜** | 단백질 합성(mRNA 번역) | 모든 셀 |
| **세포막** | 셀에 들어가고 나가는 것을 제어합니다 | 모든 셀 |
| **세포벽** | 구조적 지원 및 보호 | 식물, 곰팡이, 박테리아 |
| **액포** | 저장; 식물의 팽압을 유지 | 전체(대형 식물) |
| **리소좀** | 소화 및 폐기물 제거 | 동물세포는 주로 |

## DNA와 유전학
DNA는 살아있는 유기체를 만들고 운영하기 위한 사용 설명서입니다. 아데닌(A), 티민(T), 시토신(C), 구아닌(G)의 네 가지 염기로 이루어진 이중나선 구조입니다. A는 항상 T와 쌍을 이룹니다. C는 항상 G와 쌍을 이룹니다. 이 쌍은 DNA가 스스로를 복제하는 방식입니다.
### DNA에서 단백질까지
| 단계 | 프로세스 | 어디 | 무슨 일이 일어나는지 |
|------|---------|-------|-------------|
| **복제** | DNA → DNA | 핵 | DNA가 풀립니다. 각 가닥은 새로운 사본의 템플릿 역할을 합니다 |
| **녹취** | DNA → mRNA | 핵 | 유전자가 메신저 RNA로 복사됩니다 |
| **번역** | mRNA → 단백질 | 리보솜 | mRNA는 삼중항(코돈)으로 읽혀집니다. 각 코돈은 아미노산을 지정합니다 |
이러한 흐름(DNA → RNA → 단백질)을 분자생물학의 **중심 교리**라고 합니다.
### 유전자와 염색체
유전자는 단백질을 암호화하는 DNA 부분입니다. 인간 게놈에는 23쌍의 염색체에 대략 20,000개의 유전자가 들어 있습니다. 돌연변이(DNA 서열의 변화)는 진화의 원재료입니다.
| 돌연변이 유형 | 설명 | 예시 효과 |
|---------------|-------------|---|
| **점 돌연변이** | 단일 염기 변경(A → G) | 겸상 적혈구 빈혈(헤모글로빈 유전자의 1개 염기 변화) |
| **삽입** | 추가 베이스 추가 | 프레임시프트; 종종 파괴적 |
| **삭제** | 제거된 베이스 | 프레임시프트; 질병을 일으킬 수 |
| **중복** | 세그먼트가 복사되었습니다 | 추가 유전자 사본; 시간이 지남에 따라 새로운 기능으로 이어질 수 있음 |
| **염색체** | 대규모 재배치 | 전위; 암이나 불임을 유발할 수 있음 |
대부분의 돌연변이는 무해하고 일부는 유익하며 일부는 질병을 유발합니다.

## 자연 선택에 의한 진화
진화는 구어적인 의미에서 "단순한 이론"이 아닙니다. 진화는 모든 생물학을 통합하는 틀입니다. 메커니즘은 간단합니다.
1. 유기체는 환경이 지원할 수 있는 것보다 더 많은 자손을 생산합니다.
2. 개인마다 특성이 다릅니다(일부 특성은 유전될 수 있음).
3. 환경에 더 적합한 특성을 가진 개체는 생존하고 번식할 가능성이 더 높습니다.
4. 세대가 지나면서 유리한 특성이 인구 집단에서 더욱 흔해집니다.
아무런 안내 지능 없이도 이 과정은 박테리아부터 흰긴수염고래까지 지구상의 모든 생명체의 다양성을 설명합니다.
### 진화에 대한 증거
| 증거 유형 | 설명 |
|---------------|-------------|
| **화석 기록** | 수십억 년에 걸쳐 점진적인 변화를 보여줍니다. 과도기적 형태(Archaeopteryx, Tiktaalik) |
| **비교 해부학** | 상동 구조(인간 팔, 고래 지느러미발, 박쥐 날개는 동일한 뼈 레이아웃을 공유함) |
| **분자생물학** | DNA와 단백질 서열은 밀접하게 관련된 종에서 더 유사합니다 |
| **생물지리학** | 종 분포는 대륙 이동 및 격리 패턴과 일치합니다 |
| **관찰된 진화** | 박테리아의 항생제 내성; 곤충의 살충제 저항성; 실험실 실험 |
### 진화의 메커니즘
| 메커니즘 | 설명 |
|------------|-------------|
| **자연선택** | 세대를 거듭할수록 유리한 특성이 더욱 일반화됨 |
| **유전적 부동** | 대립유전자 빈도의 무작위 변화; 인구가 적을수록 더 강해집니다 |
| **유전자 흐름** | 집단 간 개인(및 유전자)의 이동 |
| **돌연변이** | DNA 변화로 인한 새로운 유전적 변이 |
| **성선택** | 짝짓기 성공을 향상시키는 특성이 더욱 보편화되었습니다(공작꼬리) |
| **종분화** | 개체군은 더 이상 교배할 수 없을 때까지 갈라집니다 |

## 생태학
생태학은 유기체가 서로 및 환경과 어떻게 상호 작용하는지 연구합니다.
### 조직 수준
| 레벨 | 설명 | 예 |
|-------|-------------|---------|
| **유기체** | 개인생물 | 사슴 한 마리 |
| **인구** | 한 지역에 있는 같은 종의 그룹 | 사슴 떼 |
| **커뮤니티** | 한 지역의 모든 인구 | 사슴 + 토끼 + 새 + 곤충 + 식물 |
| **생태계** | 커뮤니티 + 물리적 환경 | 숲 + 모든 유기체 + 토양 + 물 + 기후 |
| **생물권** | 지구상의 모든 생태계 | 심해부터 대기권까지 |
### 에너지 흐름
| 개념 | 설명 |
|---------|-------------|
| **제작자** | 햇빛을 에너지로 변환(식물, 조류, 남조류) |
| **주요 소비자** | 생산자(초식동물: 사슴, 토끼)를 먹는다 |
| **2차 소비자** | 1차 소비자(육식동물:늑대)를 먹는다 |
| **3차 소비자** | 상위 포식자(독수리, 범고래) |
| **분해자** | 죽은 물질(곰팡이, 박테리아) 분해 |
영양 단계 간 에너지 전달의 약 10%만이 열로 손실됩니다. 이것이 먹이사슬이 4~5단계를 거의 넘지 않는 이유이며, 먹이보다 포식자가 적은 이유입니다.
### 생지화학적 순환
| 사이클 | 핵심프로세스 |
|-------|-------------|
| **탄소 순환** | 광합성은 CO2를 제거합니다. 호흡과 연소가 방출 |
| **질소 순환** | 질소 고정 박테리아는 N2를 사용 가능한 형태로 전환합니다. 탈질균이 돌려준다 |
| **물 순환** | 증발 → 응축 → 침전 → 유출 → 반복 |
| **인 순환** | 암석이 풍화되면 인이 방출됩니다. 대기 단계 없음 |

## 분류학과 생명나무
모든 생물은 영역 → 왕국 → 문 → 강 → 목 → 과 → 속 → 종의 계층 구조로 분류됩니다.
### 세 가지 영역
| 도메인 | 세포 유형 | 주요 기능 | 예 |
|---------|------------|-------------|---------|
| **박테리아** | 원핵생물 | 펩티도글리칸 세포벽; 가장 친숙한 박테리아 | 대장균, 연쇄상 구균 |
| **고세아** | 원핵생물 | 펩티도글리칸 없음; 종종 극한성 물질 | 메탄생성물질, 호염성물질, 호열성물질 |
| **유카리아** | 진핵생물 | 막 결합 핵과 세포소기관 | 그 밖의 모든 것 |
### 유카르야 내 왕국
| 왕국 | 주요 기능 | 예 |
|---------|-------------|---------|
| **애니멀리아** | 다세포; 종속 영양; 세포벽 없음 | 인간, 곤충, 물고기, 새 |
| **식물** | 다세포; 독립 영양(광합성); 셀룰로오스 세포벽 | 나무, 풀, 양치류, 이끼 |
| **곰팡이** | 대부분 다세포입니다. 종속 영양(흡수); 키틴 세포벽 | 버섯, 효모, 곰팡이 |
| **프로티스타** | 대부분 단세포입니다. 다양한 | 아메바, 조류, 짚신벌레 |

## 요약
생물학은 분자부터 생태계까지 생명의 과학입니다. 모든 생명체는 단순한 원핵생물(박테리아, 고세균)이든 복잡한 진핵생물(동물, 식물, 균류)이든 세포로 구성됩니다. DNA는 중앙도그마(DNA → RNA → 단백질)를 통해 유전정보를 전달합니다. 자연선택에 의한 진화는 화석, 해부학, 분자생물학, 생물지리학, 직접적인 관찰을 통해 뒷받침되는 통합적 틀입니다. 생태학은 생산자로부터 소비자와 분해자를 거쳐 에너지가 흐르는 방식으로 유기체가 서로 및 환경과 상호 작용하는 방식을 연구합니다. 생명나무는 모든 유기체를 박테리아, 고세균, 진핵의 세 가지 영역으로 분류하며, 더 나아가 왕국, 문, 종으로 세분화합니다. 생물학은 의학, 농업, 생명공학, 보존의 기초입니다.
