# 유전학과 유전체학
유전학은 유전, 즉 형질이 DNA를 통해 부모에게서 자손에게 어떻게 전달되는지에 대한 연구입니다. 유전체학은 전체 게놈, 즉 모든 유전자, 비암호화 영역, 이들이 상호 작용하는 방식, 개인과 집단에 따라 어떻게 다른지에 대한 연구입니다. 유전학에서 게놈학으로의 전환은 시퀀싱 기술에 의해 주도되었습니다. 우리는 한 번에 하나의 유전자를 연구하는 것에서 몇 시간 만에 전체 게놈을 읽는 것으로 발전하여 의학, 농업, 법의학 및 진화에 대한 이해를 변화시키는 데이터를 생성했습니다.
---

## DNA 기초
### DNA 구조
| 구성요소 | 설명 |
|------------|-------------|
| **뉴클레오티드** | DNA의 빌딩 블록; 설탕(디옥시리보스), 인산염 그룹 및 질소 염기로 구성됨 |
| **기지** | 아데닌(A), 티민(T), 구아닌(G), 시토신(C) |
| **기본 페어링** | A는 T와 쌍을 이룹니다(2개의 수소 결합). G는 C와 쌍을 이룹니다(3개의 수소 결합) |
| **이중나선** | 역평행으로 이어지는 두 가닥(5'에서 3' 및 3'에서 5'); 나선형으로 꼬인 |
| **염색체** | 히스톤 단백질을 감싸고 있는 하나의 긴 DNA 분자. 인간은 46(23쌍) |
| **게놈** | 유기체의 완전한 DNA 세트입니다. 인간 게놈은 약 32억 염기쌍 |
### 분자생물학의 중심교리
| 단계 | 프로세스 | 위치 | 제품 |
|------|---------|----------|---------|
| **복제** | DNA → DNA | 핵 | 두 개의 동일한 DNA 분자 |
| **녹취** | DNA → mRNA | 핵 | 메신저 RNA |
| **번역** | mRNA → 단백질 | 리보솜(세포질) | 폴리펩티드 사슬(단백질) |

## 유전자 발현
### 유전자는 어떻게 규제되는가
| 레벨 | 메커니즘 | 예 |
|-------|------------|---------|
| **후생유전학** | DNA 메틸화; 히스톤 변형; 염색질 리모델링 | 여성의 X 염색체 하나의 침묵 |
| **전사** | 전사 인자는 프로모터/인핸서를 결합합니다. 활성화 또는 억제 | 박테리아의 Lac 오페론; 호르몬 반응 유전자 |
| **사후 전사** | 대체 접합; mRNA 안정성; 마이크로RNA | 하나의 유전자 → 여러 단백질 변종 |
| **번역** | 리보솜 가용성; 개시 인자 조절 | 페리틴 mRNA를 통한 철분 조절 |
| **번역 후** | 단백질 변형(인산화, 유비퀴틴화); 저하 | 세포주기 제어 |
---

## 상속 패턴
### 멘델의 유전학
| 패턴 | 설명 | 예 |
|---------|-------------|---------|
| **상염색체 우성** | 대립유전자 사본 1개로 충분합니다 | 헌팅턴병; 연골 무형성증 |
| **상염색체 열성** | 사본 2개 필요 | 낭포성 섬유증; 겸상적혈구빈혈 |
| **X-연결 우성** | X 염색체의 유전자; 한 장이면 충분합니다 | 레트 증후군 |
| **X-연관 열성** | X 염색체의 유전자; 남성이 더 많은 영향을 받음 | 혈우병; 색맹 |
| **통제** | 두 대립유전자 모두 동일하게 표현됨 | ABO 혈액형(A 및 B) |
| **불완전한 지배력** | 이형접합체는 중간이다 | 빨간색과 흰색 부모의 핑크 꽃 |
| **다유전자성** | 여러 유전자가 하나의 특성에 기여 | 키; 피부색; 지능 |
| **다발성** | 하나의 유전자가 여러 특성에 영향을 미칩니다 | 마르팡증후군(결합조직, 눈, 심장) |

## 유전체학
### 유전체학의 종류
| 유형 | 집중 | 신청 |
|------|---------|-------------|
| **구조유전체학** | 게놈에 있는 모든 단백질의 3D 구조 | 약물 디자인; 단백질 공학 |
| **기능유전체학** | 유전자는 무엇을 하는가? 유전자 상호작용; 표현 패턴 | 질병 메커니즘 이해 |
| **비교유전체학** | 종 전체의 게놈 비교 | 진화적 관계; 보존 지역 식별 |
| **메타유전체학** | 환경 시료의 DNA(배양되지 않음) | 미생물군집 연구; 새로운 유기체 발견 |
| **약물유전체학** | 유전자가 약물 반응에 미치는 영향 | 맞춤형 의약품; 약물 투여 |
| **후생유전학** | 게놈 전체의 후생유전학적 변형 | 암 진단; 발달 생물학 |
### DNA 시퀀싱 기술
| 세대 | 기술 | 읽기 길이 | 처리량 | 주요 기능 |
|------------|------------|-------------|------------|------------|
| **1세대** | 생어 시퀀싱 | ~1,000bp | 낮음 | 최고의 정확도; 검증에 사용됨 |
| **2세대** | 일루미나(Solexa) | 50~300bp | 매우 높음 | 짧은 읽기; 지배적인 플랫폼; 베이스당 저렴한 비용 |
| **2세대** | 이온 토렌트 | 200~400bp | 높음 | 반도체 기반; 광학 없음 |
| **3세대** | 팩바이오(SMRT) | 10,000~100,000bp | 보통 | 긴 읽기; 반복되는 영역을 해결합니다 |
| **3세대** | 옥스퍼드 나노포어 | 최대 수백만 bp | 보통에서 높음 | 매우 긴 읽기; 휴대용(MinION); 실시간 |

## 유전적 변이
### 변형 유형
| 유형 | 설명 | 빈도 |
|------|-------------|------------|
| **SNP**(단일 뉴클레오티드 다형성) | 단일 염기 변경 | 가장 일반적입니다. 1,000개 염기 중 ~1개 |
| **삽입/삭제(indel)** | 염기의 추가 또는 제거 | 프레임시프트 돌연변이를 일으킬 수 있음 |
| **CNV**(복사본 번호 변형) | 중복되거나 삭제된 세그먼트(1kb – 수 Mb) | 질병과 진화에 기여 |
| **구조적 변형** | 반전; 전위; 대규모 재배치 | 덜 일반적입니다. 병원성이 있을 수 있다 |
| **초소위성(STR)** | 짧은 탠덤 반복(2~6bp 반복) | 법의학; 친자확인 테스트 |
### GWAS(게놈 전체 연관 연구)
| 단계 | 설명 |
|------|-------------|
| **1. 샘플 수집** | 사례(질병 있음) 및 대조군(없음) |
| **2. 유전자형** | SNP 배열을 사용하여 수십만 개의 변종 유전자형 분석 |
| **3. 통계적 테스트** | 특성과의 연관성을 알아보기 위해 각 SNP를 테스트하세요 |
| **4. 맨해튼 플롯** | 모든 염색체에 대한 결과 시각화 |
| **5. 복제** | 독립 표본의 결과 확인 |

## 유전자 편집
### CRISPR-Cas9
| 구성요소 | 기능 |
|------------|----------|
| **가이드 RNA(gRNA)** | ~20개 뉴클레오티드; 표적 DNA 서열과 일치 |
| **Cas9 단백질** | 분자가위; 표적 부위에서 DNA를 절단 |
| **PAM 시퀀스** | 표적 옆의 짧은 모티프(NGG); Cas9 바인딩에 필요 |
| **HDR**(상동성 지향 복구) | 기증자 템플릿을 사용한 정확한 편집 |
| **NHEJ** (비동종 단부 접합) | 오류가 발생하기 쉬운 수리; 삽입/삭제(녹아웃) 생성 |
### 유전자 편집 애플리케이션
| 신청 | 설명 |
|-------------|-------------|
| **치료** | 질병을 유발하는 돌연변이 수정(낫적혈구; 베타지중해빈혈) |
| **농업** | 질병 저항성 작물; 개량된 가축 |
| **연구** | 녹아웃 모델을 생성합니다. 유전자 기능 연구 |
| **유전자 드라이브** | 집단을 통해 유전자 변형 확산(예: 말라리아 저항성 모기) |

## 윤리적 고려 사항
| 이슈 | 우려사항 |
|-------|---------|
| **유전적 프라이버시** | 귀하의 게놈 데이터는 누가 소유합니까? 고용주나 보험회사가 사용할 수 있나요? |
| **배아의 유전자 편집** | 유전되는 변화; 디자이너 아기; 의도하지 않은 목표 이탈 효과 |
| **유전적 차별** | GINA(미국)는 일부 차별로부터 보호하지만 격차가 있음 |
| **사전 동의** | 게놈 데이터를 통해 동의하지 않은 친척에 대한 정보가 공개됨 |
| **데이터 저장** | 게놈은 큽니다(~200GB 원시). 장기 저장 및 보안 문제 |
| **자본** | 유전체 의학은 부유한 인구에게만 제공된다면 건강 격차를 확대할 위험이 있습니다 |

## 요약
유전학은 개별 유전자가 어떻게 작동하고 유전되는지 연구합니다. 유전체학은 전체 게놈, 즉 모든 유전자, 상호 작용 및 변이를 연구합니다. DNA는 RNA로 전사되고, 이는 단백질로 번역됩니다. 유전자 발현은 후성 유전적, 전사적, 전사 후, 번역 및 번역 후 등 여러 수준에서 조절됩니다. 유전은 세대 간에 특성이 전달되는 방식을 결정하는 패턴(우성, 열성, 다유전성)을 따릅니다. 최신 시퀀싱 기술(Illumina, PacBio, Nanopore)은 전체 게놈을 빠르고 저렴하게 읽을 수 있습니다. CRISPR-Cas9는 의학과 농업 분야에서 혁신적인 잠재력을 지닌 정확한 유전자 편집을 가능하게 합니다. 가장 큰 과제는 윤리적입니다. 누가 게놈 데이터를 통제하는지, 배아에서 유전자 편집을 규제하는 방법, 게놈 의학이 특권층뿐만 아니라 모든 사람에게 이익이 되도록 보장하는 방법입니다.
