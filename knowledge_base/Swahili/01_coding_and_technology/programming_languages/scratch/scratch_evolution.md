# Scratch - Historia ya Toleo na Mageuzi
## Rekodi ya matukio
| Toleo | Mwaka | Mandhari Muhimu |
|---------|------|-----------|
| Kabla ya Mkwaruzo | 2003 | Fomu za Timu ya Kukwaruza kwenye MIT Media Lab |
| Mkwaruzo 1.0 | 2007 | **Toleo la kwanza** — utayarishaji wa programu kwa watoto |
| Mkwaruzo 1.4 | 2009 | Michoro iliyoboreshwa, vizuizi zaidi |
| Mkwaruzo 2.0 | 2013 | **Kubwa**: Kihariri kinachotegemea wavuti, anuwai za wingu, mkoba |
| Mkwaruzo 3.0 | 2019 | **Kubwa**: Kamilisha kuandika upya (HTML5/JS), viendelezi, kalamu |

| Mwangaza Eneo-kazi | 2020 | Kihariri cha nje ya mtandao (Kinachotokana na elektroni) |
## Mafanikio Makuu
### Asili (2003–2006)
- **2003**: Kikundi cha MIT Media Lab's Lifelong Chekechea kinaanza Ukuzaji wa Mwanzo
- Ikiongozwa na Mitchel Resnick
- **Lengo**: Fundisha programu kwa watoto kupitia vizuizi vya kuona
- Imehamasishwa na: Nembo (Karatasi ya Seymour), Nembo ya Lego, Squeak Etoys
- Jina: "Kucha" - kutoka kwa DJ kukwaruza (kuchanganya media pamoja)
### Mwanzo 1.0 (2007)
- **2007**: Toleo la kwanza la umma
- Buruta-an-dondosha programu ya kuzuia
- Miradi inayotegemea Sprite (wahusika, uhuishaji)
- Sauti, michoro, uhuishaji
- Imejengwa kwa Squeak (Smalltalk)
- **Lengo**: Miaka 8-16, lakini imepitishwa kwa upana zaidi
### Mwanzo 1.4 (2009)
- Utoaji wa picha ulioboreshwa
- Maktaba zaidi ya sprite
- Msaada bora wa sauti
- Toleo la mwisho lililojengwa kwenye Squeak
### Scratch 2.0 (2013)
- **Kihariri kamili kinachotegemea wavuti** - kinaendeshwa katika kivinjari
- Vigeu vya wingu - shiriki data kati ya miradi
- Mkoba - shiriki sprites / hati kati ya miradi
- Vitalu maalum (kama kazi)
- Imejengwa katika ActionScript 3 (Flash)
- Vipengele vya Jumuiya: remix, shiriki, maoni
### Mwanzo 3.0 (2019)
- **Kamilisha kuandika upya** — HTML5/JavaScript (hakuna Flash)
- Hufanya kazi kwenye kompyuta kibao, simu, Chromebook
- **Viendelezi**:
  - kalamu (mchoro)
  - Kuhisi Video (kamera)
  - Maandishi kwa Hotuba
  - Tafsiri (Tafsiri ya Google)
  - ndogo: kidogo (vifaa)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Maboresho ya kihariri cha sauti
- Mhariri mpya wa rangi (vekta + bitmap)
- Mkoba, anuwai za wingu zimehifadhiwa
### Scratch Desktop & Beyond (2020–sasa)
- **2020**: Eneo-kazi la Kukuna - kihariri cha nje ya mtandao (kinachotokana na elektroni)
- Maendeleo ya ugani kuendelea
- Viendelezi vya AI/ML (zilizoundwa na jumuiya)
- Ujumuishaji na kompyuta ya mwili (micro: kidogo, Arduino)

## Dhana za Utayarishaji Zinazofundishwa
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Kanuni Muhimu za Usanifu
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Athari na Kuasili
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
