# Riferimento rapido
Una raccolta strutturata di suggerimenti e guide di riferimento rapido per linguaggi di programmazione, strumenti da riga di comando, infrastruttura e DevOps, progettati per una rapida ricerca durante il lavoro quotidiano.

```
    ├── ansible_quick_ref.md               Ansible playbooks and automation
    ├── terraform_quick_ref.md             Terraform commands and IaC
    ├── cicd_pipeline_config.md            GitHub Actions, GitLab CI, Jenkins
    └── prometheus_and_grafana.md          PromQL, dashboards, alerting
```
