## 📝 Contribuire

Quando si aggiunge o modifica contenuto:

1. **Segui la guida di stile:**
   - Usa `#` solo per il titolo del file
   - Usa `##` per le sezioni principali
   - Usa `###` per le sottosezioni
   - Usa `-` per gli elenchi non ordinati
   - Includi l'evidenziazione della sintassi nei blocchi di codice

2. **Aggiungi metadati** (frontmatter YAML):
```yaml
---
title: "Titolo del File"
description: "Breve descrizione"
topics: [argomento1, argomento2, argomento3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Includi citazioni** per affermazioni fattuali
4. **Aggiungi riferimenti incrociati** ai file correlati
5. **Aggiorna questo README** se aggiungi nuovi file
