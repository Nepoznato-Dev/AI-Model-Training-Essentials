# Base di conoscenza inglese
Una raccolta completa di documenti di riferimento che trattano programmazione, tecnologia, intelligenza artificiale, scienza, economia, discipline umanistiche e altro ancora, scritti in uno stile naturale e colloquiale, progettato sia per la formazione sull'intelligenza artificiale che per l'apprendimento umano.
**Ultimo aggiornamento:** agosto 2026  
**File totali:** oltre 138 documenti con sconto  
**Organizzazione:** 10 directory tematiche + 34 riferimenti a linguaggi di programmazione
---

Per il flusso di lavoro generale del contributo: biforcazione, ramificazione, richieste pull, posizionamento dei file e convenzioni di denominazione, vedere la radice[CONTRIBUTING.md](../../CONTRIBUTING.md).
### Schema di Frontmatter
Ogni file inizia con questo blocco (tra i delimitatori `---`), suddiviso in cinque sezioni commentate:
```yaml
---
# Metadata
title: "Python"            # the file's H1 heading
description: "..."          # one-line summary (see field table below)
category: "Coding and Technology"
version: "1.0.0"
status: "active"            # active | draft | deprecated | archived

# Contribution
authors:
  - name: "AI Model Training Team"
    email: ""
    role: "original_author"  # original_author | contributor | maintainer | reviewer
contributors: []
changelog:
  - version: "1.0.0"
    date: "2026-08-05"
    author: "AI Model Training Team"
    changes: "Added YAML frontmatter metadata for contributor tracking"

# Review
created: "2026-08-05"
last_modified: "2026-08-05"
review_date: "2027-02-05"
reviewed_by: "Coding & Technology Knowledge Base Team"
next_review: "2027-08-05"

# Classification
tags: [python, programming-language, syntax, ecosystem, coding-and-technology]
difficulty_level: "intermediate"   # beginner | intermediate | advanced
prerequisites: []
estimated_reading_time: "58 min"

# Contribution Guide
contribution:
  license: "MIT"
  feedback_channel: "GitHub Issues"
  how_to_contribute: "Submit a PR with changes and update the changelog"
  review_process: "Changes are reviewed by category maintainers before merge"
---
```

| Campo | Fonte/Scopo |
|---|---|
| `title`| Estratto dalla prima intestazione`#`del file |
| `description`| Riepilogo di una riga; i file di argomento riutilizzano la voce dall'indice di questo README, i file del linguaggio di programmazione utilizzano una descrizione generata |
| `category`/`reviewed_by`| Derivato dalla directory principale (`01_coding_and_technology`→ "Coding and Technology" / "Coding & Technology Knowledge Base Team") |
| `version`| Versione semantica; bump su ogni modifica (vedi sotto) |
| `authors`/`contributors`| Autore originale più chiunque abbia da allora modificato il file |
| `changelog`| Elenco delle modifiche di sola aggiunta, prima la più recente |
| `review_date`/`next_review`| Cadenza di ~6 mesi e ~1 anno, che rispecchia il programma di revisione delle competenze |
| `tags`| Token del nome file più una parola chiave di categoria pulita (ad esempio`coding-and-technology`) |
| `difficulty_level`| Impostato per categoria, con sostituzioni per lingua (ad esempio Haskell/Assembly → `advanced`, Scratch → `beginner`) |
| `estimated_reading_time`| Calcolato dal conteggio delle righe |
### Modificare un file
Quando modifichi un file della knowledge base, mantieni sincronizzato il suo frontmatter:
1. **Bump`version`** seguendo[SemVer](https://semver.org/):
   - Patch (`1.0.x`): errori di battitura, formattazione, correzioni minori
   - Minore (`1.x.0`): nuove sezioni, contenuti ampliati, nuovi esempi
   - Maggiore (`x.0.0`): riscrittura o ristrutturazione completa
2. **Aggiungi una voce al registro delle modifiche** (prima la più recente) che descriva cosa hai modificato:   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **Aggiorna`last_modified`** alla data della modifica
4. **Aggiungiti a`contributors`** se è la prima modifica al file:   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
