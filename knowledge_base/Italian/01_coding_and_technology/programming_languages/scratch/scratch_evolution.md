# Scratch: cronologia ed evoluzione delle versioni
## Cronologia
| Versione | Anno | Tema chiave |
|---------|------|-----------|
| Pre-graffio | 2003| Si forma lo Scratch Team al MIT Media Lab |
| Gratta 1.0 | 2007| **Versione iniziale** — programmazione visiva per bambini |
| Gratta 1.4 | 2009| Grafica migliorata, più blocchi |
| Gratta e vinci 2.0 | 2013| **Maggiore**: editor basato sul Web, variabili cloud, zaino |
| Gratta 3.0 | 2019 | **Maggiore**: riscrittura completa (HTML5/JS), estensioni, penna |
| Gratta 3.x | 2019–25 | Rilevamento video, sintesi vocale, traduzione, micro:bit |
| Gratta Jr. | 2014| Versione semplificata per i bambini più piccoli (5-7) |
| Scratch Desktop | 2020 | Editor offline (basato su Electron) |
## Traguardi importanti
### Origini (2003-2006)
- **2003**: il gruppo Lifelong Kindergarten del MIT Media Lab inizia lo sviluppo di Scratch
- Guidato da Mitchell Resnick
- **Obiettivo**: insegnare la programmazione ai bambini attraverso blocchi visivi
- Ispirato da: Logo (Seymour Papert), Logo Lego, Squeak Etoys
- Nome: "Scratch" - dallo scratching del DJ (mixing di media insieme)
### Scratch 1.0 (2007)
- **2007**: Prima uscita pubblica
- Programmazione dei blocchi drag-and-drop
- Progetti basati su Sprite (personaggi, animazioni)
- Suono, grafica, animazione
- Squeak integrato (chiacchiere)
- **Target**: età 8-16, ma adozione molto più ampia
### Scratch 1.4 (2009)
- Resa grafica migliorata
- Altre librerie di sprite
- Migliore supporto audio
- Ultima versione basata su Squeak
### Scratch 2.0 (2013)
- **Editor completo basato sul Web**: viene eseguito nel browser
- Variabili cloud: condividi i dati tra progetti
- Zaino: condividi sprite/script tra progetti
- Blocchi personalizzati (come funzioni)
- ActionScript 3 integrato (Flash)
- Funzionalità della community: remix, condivisione, commento
### Scratch 3.0 (2019)
- **Riscrittura completa**: HTML5/JavaScript (no Flash)
- Funziona su tablet, telefoni, Chromebook
- **Estensioni**:
  - Penna (disegno)
  -Rilevamento video (fotocamera)
  - Sintesi vocale da testo
  - Traduci (Google Traduttore)
  -micro:bit (hardware)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Miglioramenti all'editor del suono
- Nuovo editor di colori (vettoriale + bitmap)
- Zaino, variabili cloud mantenute
### Scratch Desktop e oltre (2020-oggi)
- **2020**: Scratch Desktop: editor offline (basato su Electron)
- Sviluppo continuo dell'estensione
- Estensioni AI/ML (create dalla community)
- Integrazione con il calcolo fisico (micro:bit, Arduino)
## Evoluzione delle categorie di blocchi
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Concetti di programmazione insegnati
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Principi chiave di progettazione
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide

       Translated into 70+ languages
