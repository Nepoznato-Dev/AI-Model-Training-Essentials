# MATLAB — Errori comuni e anti-pattern
Questo documento cataloga gli errori, le trappole e gli anti-pattern più comuni in MATLAB con le relative correzioni.
---

## 1. Crescita di array in loop
```matlab
% ❌ WRONG — O(n²) reallocation
result = [];
for i = 1:10000
    result(end+1) = i^2;
end

% ✅ CORRECT — pre-allocate
result = zeros(1, 10000);
for i = 1:10000
    result(i) = i^2;
end

% ✅ BEST — vectorize
result = (1:10000).^2;
```

---

## 2.`*`vs`.*`(Matrice vs Elemento)
```matlab
% ❌ WRONG — matrix multiplication when element-wise intended
A = [1 2; 3 4];
B = [5 6; 7 8];
C = A * B;   % matrix product, not [5 12; 21 32]

% ✅ CORRECT — element-wise operations
C = A .* B;  % [5 12; 21 32]
C = A .^ 2;  % element-wise power
C = A ./ B;  % element-wise division
```

---

## 3. Utilizzo di`i`e`j`come variabili
```matlab
% ❌ WRONG — overwrites imaginary unit
i = 5;
z = 3 + 4*i;  % z = 3 + 20i, not 3 + 4i!

% ✅ CORRECT — use different variable names
idx = 5;
z = 3 + 4i;  % or 3 + 4*1i
```

---

## 4. Non comprendere`find`rispetto all'indicizzazione logica
```matlab
% ❌ WRONG — using find unnecessarily
indices = find(A > 5);
values = A(indices);

% ✅ CORRECT — logical indexing (faster, cleaner)
values = A(A > 5);
```

---

## 5. Funzioni integrate di shadowing
```matlab
% ❌ WRONG — naming variable after built-in
max = 100;   % now max() function is broken!
min = 0;     % now min() function is broken!

% ✅ CORRECT — use different names
maxVal = 100;
minVal = 0;
```

---

## 6. Non utilizzare`fprintf`per l'output
```matlab
% ❌ WRONG — disp with string concatenation
disp(['Result: ' num2str(x)]);

% ✅ CORRECT — fprintf
fprintf('Result: %.4f\n', x);
```

---

## Riepilogo
Il design incentrato sulla matrice di MATLAB crea trappole:`*`è la moltiplicazione di matrici (usa`.*`per gli elementi), la crescita degli array in loop è lenta (pre-allocare o vettorizzare),`i`/`j`sono unità immaginarie (non sovrascrivere) e l'indicizzazione logica è più veloce di`find`. Il metodo MATLAB è: vettorizzare tutto, preallocare, utilizzare l'indicizzazione logica e non oscurare mai le funzioni integrate.
