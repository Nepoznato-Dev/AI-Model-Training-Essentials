# การออกแบบและวัฒนธรรมองค์กร
การออกแบบองค์กรคือการจัดโครงสร้าง กระบวนการ บทบาท และสิทธิ์ในการตัดสินใจอย่างรอบคอบเพื่อดำเนินกลยุทธ์อย่างมีประสิทธิผล วัฒนธรรมคือค่านิยม ความเชื่อ บรรทัดฐาน และพฤติกรรมที่มีร่วมกัน ซึ่งกำหนดรูปแบบการทำงานร่วมกันของผู้คน โครงสร้างคือโครงกระดูก วัฒนธรรมคือบุคลิกภาพ คุณสามารถออกแบบโครงสร้างใหม่บนกระดาษได้ แต่หากวัฒนธรรมไม่สนับสนุนการเปลี่ยนแปลง มันจะไม่ทำงาน และวัฒนธรรมที่เข้มแข็งและมีโครงสร้างที่เลวร้ายจะค่อยๆ หายใจไม่ออก องค์กรที่ดีที่สุดได้รับทั้งสองอย่างอย่างถูกต้อง — และเข้าใจว่าพวกเขาเชื่อมโยงกันอย่างลึกซึ้ง
---

## โครงสร้างองค์กร
### โครงสร้างทั่วไป
| โครงสร้าง | คำอธิบาย | จุดแข็ง | จุดอ่อน |
|----------|-------------|-----------|------------|
| **การทำงาน** | จัดกลุ่มตามความเชี่ยวชาญ (วิศวกรรม การตลาด การขาย) | ความเชี่ยวชาญเชิงลึก ประสิทธิภาพ; เส้นทางอาชีพที่ชัดเจน | ไซโล; การประสานงานข้ามสายงานช้า |
| **ดิวิชั่น** | จัดกลุ่มตามผลิตภัณฑ์ ตลาด หรือภูมิศาสตร์ | มุ่งเน้นไปที่ลูกค้า/ตลาด ความรับผิดชอบด้าน P&L | ความซ้ำซ้อนของฟังก์ชัน การแข่งขันด้านทรัพยากร |
| **เมทริกซ์** | การรายงานแบบคู่: การทำงาน + ผลิตภัณฑ์/โครงการ | ความยืดหยุ่น; การทำงานร่วมกันข้ามสายงาน | ความสับสน; การแย่งชิงอำนาจ ตัดสินใจช้า |
| **แบน / แนวนอน** | มีชั้นการจัดการไม่กี่ชั้น ช่วงการควบคุมที่กว้าง | การตัดสินใจที่รวดเร็ว พนักงานที่ได้รับมอบอำนาจ ค่าใช้จ่ายต่ำ | ยากที่จะปรับขนาด การรายงานที่ไม่ชัดเจน |
| **ตามทีม** | จัดโดยทีมงานข้ามสายงาน | เอกราช; ความเร็ว; การมุ่งเน้นลูกค้า | การประสานงานระหว่างทีม ความสม่ำเสมอ |
| **เครือข่าย / แพลตฟอร์ม** | ทีมงานหลัก + พันธมิตรภายนอก แพลตฟอร์มช่วยให้ผู้อื่น | ความสามารถในการขยายขนาด; ความยืดหยุ่น; สินทรัพย์แสง | การควบคุมคุณภาพ การพึ่งพาพันธมิตร |
| **ความศักดิ์สิทธิ์** | ทีมที่จัดการด้วยตนเอง บทบาทที่กำหนดโดยความรับผิดชอบ | เอกราชสูง ปรับตัว | สับสน; ใช้ไม่ได้สำหรับทุกคน |
### ช่วงของการควบคุม
| ปัจจัย | ช่วงแคบ (4-6) | ช่วงกว้าง (10-15+) |
|--------|-------------------|---------------------|
| **ชั้นการจัดการ** | มากมาย | ไม่กี่ |
| **การกำกับดูแล** | ปิด; ลงมือทำ | ได้รับมอบหมาย; ปล่อยมือ |
| **ดีที่สุดสำหรับ** | งานที่ซับซ้อน ทีมที่ไม่มีประสบการณ์ | งานประจำ; ทีมงานที่มีประสบการณ์และเป็นอิสระ |
| **ความเสี่ยง** | การจัดการรายย่อย; ตัดสินใจช้า | ขาดการสนับสนุน ช่องว่างการประสานงาน |
### การรวมศูนย์เทียบกับการกระจายอำนาจ
| มิติข้อมูล | รวมศูนย์ | กระจายอำนาจ |
|----------|-----------|---------------|
| **การตัดสินใจ** | จากบนลงล่าง | ดันไปจนสุดขอบ |
| **ความเร็ว** | ช้า (คอขวดที่ด้านบน) | รวดเร็ว (ตัดสินใจได้ในพื้นที่) |
| **ความสม่ำเสมอ** | สูง | ตัวแปร |
| **นวัตกรรม** | ถูกจำกัดโดยแบนด์วิธของด้านบน | โผล่ออกมาจากหลายแหล่ง |
| **ดีที่สุดสำหรับ** | วิกฤติ; ระยะเริ่มต้น; อุตสาหกรรมหนักที่ต้องปฏิบัติตามกฎระเบียบ | งานความรู้ ตลาดที่เคลื่อนไหวเร็ว การขยายขนาด |

## หลักการออกแบบ
### การตัดสินใจที่สำคัญในการออกแบบองค์กร
| การตัดสินใจ | คำถาม | ตัวเลือก |
|----------|----------|---------|
| **การแบ่งแผนก** | เราจะจัดกลุ่มคนอย่างไร? | ตามหน้าที่; ผลิตภัณฑ์; ลูกค้า; ภูมิศาสตร์; กระบวนการ |
| **สายการบังคับบัญชา** | ใครรายงานต่อใคร? | ลำดับชั้นที่ชัดเจน เมทริกซ์; เครือข่าย |
| **สิทธิในการตัดสินใจ** | ใครเป็นคนตัดสินใจอะไร? | รวมศูนย์; กระจายอำนาจ; RACI เมทริกซ์ |
| **กลไกการประสานงาน** | ทีมทำงานร่วมกันอย่างไร? | บทบาทประสานงาน; ทีมงานข้ามสายงาน ผู้รวมระบบ; เป้าหมายร่วมกัน |
| **มาตรฐาน** | มาตรฐานเทียบกับท้องถิ่นเท่าไหร่? | กระบวนการ; เอาท์พุต; ทักษะ; บรรทัดฐาน |
### โมเดลดาราของกัลเบรธ
| องค์ประกอบ | คำอธิบาย |
|---------|-------------|
| **กลยุทธ์** | ทิศทาง; เป้าหมาย; ความได้เปรียบในการแข่งขัน เหตุผลที่องค์กรดำรงอยู่ |
| **โครงสร้าง** | การรายงานความสัมพันธ์ ลำดับชั้น; การจัดกลุ่มหน่วย |
| **กระบวนการ** | การไหลของข้อมูล การตัดสินใจ; การวางแผน; การจัดทำงบประมาณ |
| **รางวัล** | สิ่งจูงใจ; การวัดประสิทธิภาพ สอดคล้องกับกลยุทธ์ |
| **คน** | การจ้างงาน; การพัฒนา; วัฒนธรรม; ความสามารถของมนุษย์ |
ข้อมูลเชิงลึกที่สำคัญ: โครงสร้างขับเคลื่อนกลยุทธ์ องค์ประกอบอื่นๆ ทั้งหมดจะต้องสอดคล้องกัน การเปลี่ยนแปลงโครงสร้างโดยไม่เปลี่ยนกระบวนการ รางวัล และการพัฒนาบุคลากรจะล้มเหลว

## วัฒนธรรมองค์กร
### จริงๆ แล้ววัฒนธรรมคืออะไร
| เลเยอร์ | คำอธิบาย | การมองเห็น |
|-------|-------------|-----------|
| **สิ่งประดิษฐ์** | โครงสร้าง กระบวนการ พฤติกรรม การแต่งกาย แผนผังสำนักงานที่มองเห็นได้ | มองเห็นได้ง่าย ยากที่จะตีความ |
| **ค่านิยม** | ระบุกลยุทธ์ เป้าหมาย ปรัชญา พันธกิจ | ประกาศต่อสาธารณะ; อาจไม่ตรงกับพฤติกรรมจริง |
| **สมมติฐานพื้นฐาน** | หมดสติ ความเชื่อ การรับรู้ ความคิด ความรู้สึก | ล่องหน; ตัวขับเคลื่อนพฤติกรรมที่แท้จริง |
### ประเภทวัฒนธรรม (กรอบค่านิยมที่แข่งขันกัน)
| วัฒนธรรม | โฟกัส | ลักษณะ | ตัวอย่าง |
|---------|-------|----------------|---------|
| **แคลน** (ร่วมมือกัน) | ภายใน + ยืดหยุ่น | เหมือนครอบครัว; การให้คำปรึกษา; การทำงานเป็นทีม; ฉันทามติ | ซัปโปส; สตาร์ทอัพขนาดเล็ก |
| ** Adhocracy ** (สร้าง) | ภายนอก + ยืดหยุ่น | นวัตกรรม; การกล้าเสี่ยง; ผู้ประกอบการ; ไดนามิก | Google (ต้น); สเปซเอ็กซ์ |
| **ตลาด** (แข่งขัน) | ภายนอก + ควบคุม | มุ่งเน้นผลลัพธ์; การแข่งขัน; มุ่งเน้นเป้าหมาย; ส่วนแบ่งการตลาด | อเมซอน; บริษัทวอลล์สตรีท |
| **ลำดับชั้น** (ตัวควบคุม) | ภายใน + ควบคุม | มีโครงสร้าง; ขับเคลื่อนด้วยกระบวนการ; ประสิทธิภาพ; ความสม่ำเสมอ | หน่วยงานภาครัฐ ทหาร; ธนาคารแบบดั้งเดิม |
### มิติทางวัฒนธรรม
| มิติข้อมูล | คำอธิบาย |
|-----------|-------------|
| **ความปลอดภัยทางจิตใจ** | ผู้คนสามารถรับความเสี่ยงและเสี่ยงโดยไม่ต้องกลัวการลงโทษได้หรือไม่? |
| **ความรับผิดชอบ** | ผู้คนมีความรับผิดชอบต่อความมุ่งมั่นของตนหรือไม่? |
| **ความโปร่งใส** | ข้อมูลถูกแบ่งปันอย่างเปิดเผยหรือถูกกักตุนไว้เป็นอำนาจหรือไม่? |
| **การยอมรับนวัตกรรม** | ความล้มเหลวถูกลงโทษหรือถือเป็นการเรียนรู้หรือไม่? |
| **การปฐมนิเทศลูกค้า** | การตัดสินใจเริ่มต้นจากความต้องการของลูกค้าหรือความสะดวกภายใน? |
| **ความเร็วเทียบกับคุณภาพ** | มีอคติต่อการทำซ้ำอย่างรวดเร็วหรือการไตร่ตรองอย่างรอบคอบหรือไม่? |
| **การเคารพตามลำดับชั้น** | รุ่นน้องสามารถท้าทายความคิดรุ่นพี่ได้หรือไม่? |

## การจัดการการเปลี่ยนแปลง
### เหตุใดการริเริ่มการเปลี่ยนแปลงจึงล้มเหลว
| เหตุผล | คำอธิบาย |
|--------|-------------|
| **ไม่มีความเร่งด่วน** | ผู้คนไม่เห็นว่าเหตุใดจึงจำเป็นต้องเปลี่ยนแปลง |
| **ไม่มีแนวร่วม** | ไม่มีกลุ่มผู้มีอำนาจขับเคลื่อนการเปลี่ยนแปลง |
| **ไม่มีวิสัยทัศน์** | ไม่ชัดเจนว่าสถานะในอนาคตจะเป็นอย่างไร |
| **การสื่อสารไม่ดี** | ผู้คนไม่เข้าใจการเปลี่ยนแปลงหรือบทบาทของพวกเขา |
| **ไม่มีชัยชนะอย่างรวดเร็ว** | ไม่เห็นความคืบหน้าในการสร้างโมเมนตัม |
| **ฉลองก่อนกำหนด** | ประกาศชัยชนะก่อนการเปลี่ยนแปลงจะถูกฝัง |
| **การต่อต้านวัฒนธรรม** | เปลี่ยนข้อขัดแย้งด้วยสมมติฐานที่ฝังลึก |
| **ไม่มีการเสริมแรง** | พฤติกรรมเก่าได้รับรางวัล พฤติกรรมใหม่ไม่ยั่งยืน |
### โมเดล 8 ขั้นตอนของ Kotter
| ขั้นตอน | การกระทำ |
|------|--------|
| **1. สร้างความเร่งด่วน** | ช่วยให้ผู้คนมองเห็นภัยคุกคามของการไม่เปลี่ยนแปลง |
| **2. สร้างแนวร่วมแกนนำ** | รวมกลุ่มที่มีพลังและความน่าเชื่อถือเพียงพอ |
| **3. สร้างวิสัยทัศน์เชิงกลยุทธ์** | สร้างภาพอนาคตที่ชัดเจน |
| **4. รับสมัครกองทัพอาสา** | รับการซื้อเข้าจากมวลวิกฤต |
| **5. เปิดใช้งานการดำเนินการ** | ขจัดอุปสรรค; มอบอำนาจให้ผู้คน |
| **6. สร้างชัยชนะระยะสั้น** | สร้างความสำเร็จที่มองเห็นได้ |
| **7. เร่งความเร็วอย่างยั่งยืน** | ดันต่อไป; อย่าประกาศชัยชนะเร็วเกินไป |
| **8. การเปลี่ยนแปลงสถาบัน** | ยึดเหนี่ยวพฤติกรรมใหม่ในวัฒนธรรม |

## การทำงานระยะไกลและแบบผสมผสาน
| ท้าทาย | กลยุทธ์ |
|----------|----------|
| **การสื่อสาร** | ค่าเริ่มต้นเป็นลายลักษณ์อักษร ไม่ตรงกันก่อน; การตัดสินใจด้านเอกสาร |
| **ความไว้วางใจ** | วัดผลลัพธ์ ไม่ใช่ชั่วโมง หลีกเลี่ยงการเฝ้าระวัง |
| **การเริ่มต้นใช้งาน** | โปรแกรมที่มีโครงสร้าง ระบบบัดดี้; เอกสารที่ชัดเจน |
| **วัฒนธรรม** | พิธีกรรมโดยเจตนา ปกติทุกมือ กิจกรรมโซเชียลเสมือนจริง |
| **ตราสารทุน** | อคติเรื่องความใกล้ชิด: ตรวจสอบให้แน่ใจว่าพนักงานที่อยู่ห่างไกลได้รับการมองเห็นและโอกาสที่เท่าเทียมกัน |
| **ความร่วมมือ** | เป็นเจ้าของที่ชัดเจน; อินเทอร์เฟซที่กำหนด ซิงค์ปกติ |
| **ความเป็นอยู่ที่ดี** | เคารพขอบเขต สิทธิ์ในการยกเลิกการเชื่อมต่อ หลีกเลี่ยงการประชุมที่โอเวอร์โหลด |

## สรุป
การออกแบบและวัฒนธรรมองค์กรเป็นตัวกำหนดว่าบริษัทจะสามารถดำเนินกลยุทธ์ของตนได้หรือไม่ โครงสร้างกำหนดความสัมพันธ์ในการรายงาน สิทธิในการตัดสินใจ และกลไกการประสานงาน วัฒนธรรมเป็นตัวกำหนดพฤติกรรมที่แท้จริงของผู้คน เช่น สมมติฐาน บรรทัดฐาน และค่านิยมที่เป็นแนวทางในการทำงานในแต่ละวัน Star Model ของ Galbraith เตือนเราว่ากลยุทธ์ โครงสร้าง กระบวนการ รางวัล และบุคลากรทั้งหมดต้องสอดคล้องกัน ประเภทวัฒนธรรมมีตั้งแต่กลุ่ม (ความร่วมมือ) ไปจนถึงการสนับสนุน (นวัตกรรม) ไปจนถึงการตลาด (การแข่งขัน) ไปจนถึงลำดับชั้น (ควบคุม) กรอบการจัดการการเปลี่ยนแปลง เช่น โมเดล 8 ขั้นตอนของ Kotter จัดเตรียมโครงสร้างสำหรับการเปลี่ยนแปลง แต่วัฒนธรรมคือสมรภูมิที่แท้จริง หากการเปลี่ยนแปลงขัดแย้งกับสมมติฐานที่ลึกซึ้ง การเปลี่ยนแปลงนั้นจะล้มเหลวไม่ว่าจะวางแผนไว้ดีแค่ไหนก็ตาม การทำงานระยะไกลและแบบผสมผสานเพิ่มความท้าทายใหม่ๆ เกี่ยวกับการสื่อสาร ความไว้วางใจ และความลำเอียงในบริเวณใกล้เคียง องค์กรที่ดีที่สุดออกแบบอย่างจงใจ สร้างวัฒนธรรมที่สนับสนุนกลยุทธ์ของพวกเขา และยังคงเต็มใจที่จะพัฒนาทั้งเมื่อสภาพแวดล้อมเปลี่ยนแปลง
