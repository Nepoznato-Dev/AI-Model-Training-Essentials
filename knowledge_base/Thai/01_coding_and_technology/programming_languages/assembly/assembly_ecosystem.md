# การประกอบ - คู่มือระบบนิเวศและเครื่องมือ
คู่มือนี้ครอบคลุมถึงเครื่องมือที่จำเป็น แอสเซมเบลอร์ และโครงสร้างพื้นฐานในระบบนิเวศของแอสเซมบลี
---

## ผู้ประกอบตามสถาปัตยกรรม
### x86/x86-64
| ช่างประกอบ | แพลตฟอร์ม | หมายเหตุ |
|----------|----------|-------|
| **นาสม์** | ข้ามแพลตฟอร์ม | ไวยากรณ์ที่สะอาดและได้รับความนิยมสูงสุด |
| **แมสม์** | หน้าต่าง | Microsoft Macro แอสเซมเบลอร์ |
| **ฟาสม์** | ข้ามแพลตฟอร์ม | โฮสติ้งด้วยตนเอง รวดเร็ว |
| **แก๊ส (ตาม)** | ลินุกซ์/ยูนิกซ์ | GNU Assembler (ไวยากรณ์ AT&T) |
| **ยัสม์** | ข้ามแพลตฟอร์ม | รองรับ NASM |
| **UASM** | ข้ามแพลตฟอร์ม | รองรับ MASM |
### แขน
| ช่างประกอบ | แพลตฟอร์ม | หมายเหตุ |
|----------|----------|-------|
| **GNU เป็น (ARM)** | ข้ามแพลตฟอร์ม | การประกอบ ARM |
| **คีล ASM** | ฝังตัว | การพัฒนา ARM |
| **ผู้ประกอบ ARM** | แขน | ชุดคอมไพเลอร์ ARM |
### อื่น
| ช่างประกอบ | สถาปัตยกรรม | หมายเหตุ |
|----------|-------------|-------|
| **avr-as** | เอวีอาร์ | ไมโครคอนโทรลเลอร์ |
| **ราสม์** | Z80 | คอมพิวเตอร์ย้อนยุค |
| **ca65** | 6502 | NES พลเรือจัตวา |
| **สปิม / ดาวอังคาร** | เอ็มไอพีเอส | ทางการศึกษา |
```bash
# NASM (Linux x86-64)
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# NASM (Windows)
nasm -f win64 hello.asm -o hello.obj
golink /console /entry _start hello.obj

# FASM
fasm hello.asm hello

# GAS (AT&T syntax)
as -o hello.o hello.s
ld hello.o -o hello
```

## สร้างเครื่องมือ
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **ทำ** | ระบบอัตโนมัติบิลด์แบบคลาสสิก |
| **ซีเมค** | การสร้างข้ามแพลตฟอร์ม |
| **ฉัน** | ตัวเชื่อมโยง GNU |
| **lld** | ตัวเชื่อมโยง LLVM |
| **objcopy** | การจัดการไบนารี |
| **objdump** | การถอดชิ้นส่วน |
| **readelf / นาโนเมตร** | การตรวจสอบสัญลักษณ์ |
| **การถ่ายโอนข้อมูลฐานสิบหก** | การตรวจสอบไบนารี |
```makefile
# Makefile for NASM project
ASM = nasm
ASM_FLAGS = -f elf64
LD = ld
TARGET = hello

all: $(TARGET)

$(TARGET): hello.o
	$(LD) hello.o -o $(TARGET)

hello.o: hello.asm
	$(ASM) $(ASM_FLAGS) hello.asm -o hello.o

clean:
	rm -f *.o $(TARGET)
```

## การทดสอบ
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **สายรัดทดสอบแบบกำหนดเอง** | กรอบการทดสอบการประกอบ |
| **ความสามัคคี** | การทดสอบหน่วยที่ใช้ C (สำหรับโปรเจ็กต์แบบผสม) |
| **การทดสอบของ Google** | การทดสอบ C++ (สำหรับโปรเจ็กต์แบบผสม) |
| **มาโครที่กำหนดเอง** | มาโครการยืนยัน |
```nasm
; NASM test example
section .data
    test_pass db "PASS", 10, 0
    test_fail db "FAIL", 10, 0

section .text
    global _start

test_add:
    mov rax, 2
    mov rbx, 3
    add rax, rbx
    cmp rax, 5
    jne .fail
    ; print pass
    mov rax, 1
    mov rdi, 1
    mov rsi, test_pass
    mov rdx, 5
    syscall
    ret
.fail:
    mov rax, 1
    mov rdi, 1
    mov rsi, test_fail
    mov rdx, 5
    syscall
    ret

_start:
    call test_add
    mov rax, 60
    xor rdi, rdi
    syscall
```

## สรุป
ระบบนิเวศของแอสเซมบลีเป็นสถาปัตยกรรมเฉพาะและออกแบบให้น้อยที่สุด Toolchain มาตรฐานคือ: **NASM** (x86/x86-64) หรือ **GNU as** (ARM) สำหรับการประกอบ, **ld** สำหรับการเชื่อมโยง, **GDB** สำหรับการแก้ไขจุดบกพร่อง, **Ghidra** หรือ **IDA Pro** สำหรับวิศวกรรมย้อนกลับ และ **QEMU** สำหรับการจำลอง แอสเซมบลีเป็นเลิศในด้านการพัฒนาระบบปฏิบัติการ ระบบฝังตัว วิศวกรรมย้อนกลับ โค้ดที่มีความสำคัญต่อประสิทธิภาพ และการพัฒนาบูตโหลดเดอร์ ระบบนิเวศเป็นสิ่งจำเป็นสำหรับการทำความเข้าใจว่าคอมพิวเตอร์ทำงานอย่างไรในระดับต่ำสุด สำหรับการเรียนรู้ **MARS** (MIPS) และ **SASM** (x86) มีสภาพแวดล้อมที่เหมาะสำหรับผู้เริ่มต้น
