# JavaScript - คู่มือระบบนิเวศและเครื่องมือ
คู่มือนี้ครอบคลุมถึงเครื่องมือ เฟรมเวิร์ก และโครงสร้างพื้นฐานที่สำคัญในระบบนิเวศของ JavaScript
---

## รันไทม์
| รันไทม์ | สิ่งแวดล้อม | ดีที่สุดสำหรับ |
|---------|-------------|----------|
| **Node.js** | เซิร์ฟเวอร์/CLI | แบ็กเอนด์, API, เครื่องมือ |
| **ดีโน่** | เซิร์ฟเวอร์/CLI | ปลอดภัยตามค่าเริ่มต้น TypeScript เนทิฟ |
| **บุญ** | เซิร์ฟเวอร์/CLI | Bundler/ตัวทดสอบในตัวที่รวดเร็วและภายใน |
| **เบราว์เซอร์** | ฝั่งไคลเอ็นต์ | เว็บแอปพลิเคชั่น |

## การจัดการแพ็คเกจ
| เครื่องมือ | ทะเบียน | คุณสมบัติ |
|------|----------|----------|
| **เวลาบ่าย** | npmjs.com | เริ่มต้นด้วย Node.js |
| **เส้นด้าย** | npmjs.com | พื้นที่ทำงาน โหมด PnP |
| **pnpm** | npmjs.com | รวดเร็ว ดิสก์มีประสิทธิภาพ เข้มงวด |
| **ขนมปัง** | npmjs.com | รวดเร็วเป็นพิเศษ | ในตัว
```bash
npm init -y                   # initialize project
npm install express           # add dependency
npm install -D typescript     # add dev dependency
npm run build                 # run script from package.json
```

## สรุป
ระบบนิเวศของ JavaScript เป็นระบบนิเวศที่ใหญ่ที่สุดในการเขียนโปรแกรม สแต็กสมัยใหม่ได้แก่ **Vite** สำหรับการสร้าง, **pnpm** สำหรับแพ็คเกจ, **Vitest** สำหรับการทดสอบ, **ESLint + Prettier** สำหรับคุณภาพโค้ด, **React/Next.js** หรือ **Vue/Nuxt** สำหรับฟรอนต์เอนด์ และ **Vercel** หรือ **Cloudflare** สำหรับการปรับใช้ ตอนนี้ TypeScript เป็นสิ่งจำเป็นสำหรับโครงการที่จริงจัง ระบบนิเวศเคลื่อนไหวอย่างรวดเร็ว — อยู่กับปัจจุบันแต่หลีกเลี่ยงการปั่นป่วนของกรอบงาน
