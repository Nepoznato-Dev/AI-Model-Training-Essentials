# Rust - คู่มือระบบนิเวศและเครื่องมือ
คู่มือนี้ครอบคลุมถึงเครื่องมือ เฟรมเวิร์ก และโครงสร้างพื้นฐานที่สำคัญในระบบนิเวศของ Rust
---

## การจัดการและการสร้างแพ็คเกจ
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **สินค้า** | ตัวจัดการแพ็คเกจ, ระบบสร้าง, ตัวทดสอบ |
| **crates.io** | การลงทะเบียนแพ็คเกจอย่างเป็นทางการ |
| **เกิดสนิม** | ตัวติดตั้งและผู้จัดการ Toolchain |
| **แก้ไขสินค้า** | เพิ่ม/ลบ/อัปเกรดการอ้างอิง |
| **สินค้า-ดู** | สร้างใหม่จากการเปลี่ยนแปลงไฟล์ |
| **ตรวจสอบสินค้า** | เครื่องมือตรวจสอบช่องโหว่ด้านความปลอดภัย |
| **สินค้าติดขัด** | Linter (ในตัว) |
| **สินค้า-fmt** | ตัวจัดรูปแบบโค้ด (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

## การทดสอบ
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **การทดสอบสินค้า** | หน่วยในตัว + การทดสอบการรวม |
| **เกณฑ์** | กรอบการเปรียบเทียบ |
| **ผู้ประท้วง** | การทดสอบตามคุณสมบัติ |
| **จำลอง** | กรอบการเยาะเย้ย |
| **โตเกียว::test** | รองรับการทดสอบ Async |
| **อินสตาแกรม** | การทดสอบภาพรวม |
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## สรุป
ระบบนิเวศของ Rust มีความเหนียวแน่นและมีคุณภาพสูง โดยมีศูนย์กลางอยู่ที่ Cargo สแต็กมาตรฐานคือ **Cargo** สำหรับทุกสิ่ง (สร้าง ทดสอบ เผยแพร่), **Tokio** สำหรับ async, **Axum** หรือ **Actix-web** สำหรับเว็บ, **serde** สำหรับการทำให้เป็นอนุกรม, **SQLx** สำหรับฐานข้อมูล และ **clap** สำหรับ CLI ฟีเจอร์นักฆ่าของ Rust กำลังปรับใช้เป็นไบนารี่แบบคงที่เดียวโดยไม่มีการพึ่งพารันไทม์ ระบบนิเวศให้ความสำคัญกับความถูกต้องและประสิทธิภาพมากกว่าความสะดวกสบาย
