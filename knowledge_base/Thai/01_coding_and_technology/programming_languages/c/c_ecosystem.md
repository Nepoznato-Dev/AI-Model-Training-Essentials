# C - คู่มือระบบนิเวศและเครื่องมือ
คู่มือนี้ครอบคลุมถึงเครื่องมือ ไลบรารี และโครงสร้างพื้นฐานที่จำเป็นในระบบนิเวศ C
---

## คอมไพเลอร์
| คอมไพเลอร์ | แพลตฟอร์ม | หมายเหตุ |
|----------|----------|-------|
| **จีซีซี** | ลินุกซ์/ยูนิกซ์ | GNU Compiler Collection ที่ใช้กันอย่างแพร่หลาย |
| **เสียงดังกราว** | ข้ามแพลตฟอร์ม | ข้อความแสดงข้อผิดพลาดที่ดีกว่าที่ใช้ LLVM
| **MSVC** | หน้าต่าง | คอมไพเลอร์ Microsoft Visual C++ |
| **ทีซีซี** | ข้ามแพลตฟอร์ม | Tiny C Compiler การรวบรวมที่รวดเร็ว |
| **ซิกซีซี** | ข้ามแพลตฟอร์ม | คอมไพเลอร์ C ของ Zig การรวบรวมข้ามที่ยอดเยี่ยม |

## สร้างระบบ
| เครื่องมือ | พิมพ์ | ดีที่สุดสำหรับ |
|------|-|---------|
| **ทำ** | คลาสสิค | โปรเจ็กต์เรียบง่าย มาตรฐาน Unix |
| **ซีเมค** | ข้ามแพลตฟอร์ม | โครงการมาตรฐานอุตสาหกรรมที่ซับซ้อน |
| **มีซอน** | ทันสมัย ​​| ไวยากรณ์ที่รวดเร็วและสะอาดตา |
| **นินจา** | รวดเร็ว | ระบบสร้างระดับต่ำ (ใช้โดย CMake) |
| **บาเซล** | สเกล | โมโนเรโพส, Google |
| **xmake** | ทันสมัย ​​| ข้ามแพลตฟอร์มแบบ Lua
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## สรุป
ระบบนิเวศของ C เป็นรากฐานของการประมวลผลสมัยใหม่ Toolchain มาตรฐานคือ: **GCC** หรือ **Clang** สำหรับการคอมไพล์ **CMake** สำหรับบิลด์ **GDB** สำหรับการดีบัก **Valgrind** สำหรับการวิเคราะห์หน่วยความจำ และ **clang-tidy** สำหรับ Linting ไลบรารีหลัก ได้แก่ **OpenSSL** สำหรับ crypto, **libcurl** สำหรับ HTTP, **SQLite** สำหรับฐานข้อมูล ระบบนิเวศของ C นั้นเรียบง่ายด้วยการออกแบบ คุณสร้างสิ่งที่คุณต้องการได้ สำหรับการพัฒนาสมัยใหม่ ให้ใช้น้ำยาฆ่าเชื้อ (ASan, UBSan) ในระหว่างการทดสอบเสมอ
