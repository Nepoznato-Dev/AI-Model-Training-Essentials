# Scratch - ประวัติเวอร์ชันและวิวัฒนาการ
## ไทม์ไลน์
| เวอร์ชั่น | ปี | ธีมหลัก |
|---------|-|-----------|
| ก่อนเกา | 2546 | แบบฟอร์มทีม Scratch ที่ MIT Media Lab |
| เกา 1.0 | 2550 | **การเปิดตัวครั้งแรก** — โปรแกรมภาพสำหรับเด็ก |
| เกา 1.4 | 2552 | กราฟิกที่ได้รับการปรับปรุง บล็อกเพิ่มเติม |
| เกา 2.0 | 2013 | **สำคัญ**: โปรแกรมแก้ไขบนเว็บ ตัวแปรคลาวด์ แบ็คแพ็ค |
| เกา 3.0 | 2019 | **หลัก**: เขียนใหม่ทั้งหมด (HTML5/JS), ส่วนขยาย, ปากกา |
| เกา 3.x | 2562–25 | การตรวจจับวิดีโอ, การอ่านออกเสียงข้อความ, การแปล, micro:bit |

## เหตุการณ์สำคัญที่สำคัญ
### ออริจินส์ (2546–2549)
- **2003**: กลุ่ม Lifelong Kindergarten ของ MIT Media Lab เริ่มการพัฒนา Scratch
- นำโดยมิทเชล เรสนิค
- **เป้าหมาย**: สอนการเขียนโปรแกรมให้กับเด็กๆ ผ่านบล็อกภาพ
- แรงบันดาลใจจาก: โลโก้ (Seymour Papert), โลโก้ Lego, Squeak Etoys
- ชื่อ : Scratch — มาจาก DJ scratching (ผสมผสานสื่อเข้าด้วยกัน)
### รอยขีดข่วน 1.0 (2007)
- **2007**: เปิดตัวสู่สาธารณะครั้งแรก
- การเขียนโปรแกรมบล็อกแบบลากและวาง
- โปรเจ็กต์ที่ใช้สไปรท์ (ตัวละคร แอนิเมชั่น)
- เสียง กราฟิก แอนิเมชั่น
- มีเสียงรับสารภาพในตัว (Smalltalk)
- **เป้าหมาย**: อายุ 8-16 ปี แต่รับเลี้ยงในวงกว้างกว่ามาก
### รอยขีดข่วน 1.4 (2009)
- ปรับปรุงการเรนเดอร์กราฟิก
- ไลบรารีสไปรท์เพิ่มเติม
- รองรับเสียงที่ดีกว่า
- เวอร์ชันล่าสุดสร้างขึ้นบน Squeak
### สแครช 2.0 (2013)
- **โปรแกรมแก้ไขบนเว็บที่สมบูรณ์** — ทำงานในเบราว์เซอร์
- ตัวแปรคลาวด์ — แบ่งปันข้อมูลระหว่างโครงการ
- กระเป๋าเป้สะพายหลัง — แชร์สไปรท์/สคริปต์ระหว่างโปรเจ็กต์
- บล็อกที่กำหนดเอง (เช่นฟังก์ชั่น)
- สร้างขึ้นใน ActionScript 3 (แฟลช)
- คุณสมบัติชุมชน: รีมิกซ์ แบ่งปัน แสดงความคิดเห็น
### สแครช 3.0 (2019)
- **เขียนใหม่ทั้งหมด** — HTML5/JavaScript (ไม่มี Flash)
- ใช้งานได้บนแท็บเล็ต โทรศัพท์ Chromebook
- **ส่วนขยาย**:
  - ปากกา (วาดรูป)
  - การตรวจจับวิดีโอ (กล้อง)
  - ข้อความเป็นคำพูด
  - แปล (Google แปลภาษา)
  - ไมโคร:บิต (ฮาร์ดแวร์)
  - เลโก้มายด์สตอร์ม EV3
  - วีโด 2.0
- การปรับปรุงตัวแก้ไขเสียง
- เครื่องมือแก้ไขสีใหม่ (เวกเตอร์ + บิตแมป)
- แบ็คแพ็คตัวแปรคลาวด์ยังคงอยู่
### Scratch Desktop & Beyond (2020–ปัจจุบัน)
- **2020**: Scratch Desktop — โปรแกรมแก้ไขออฟไลน์ (ใช้อิเล็กตรอน)
- พัฒนาต่อยอดอย่างต่อเนื่อง
- ส่วนขยาย AI/ML (สร้างโดยชุมชน)
- บูรณาการกับการคำนวณทางกายภาพ (micro:bit, Arduino)
## วิวัฒนาการหมวดหมู่บล็อก
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## สอนแนวคิดการเขียนโปรแกรม
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## หลักการออกแบบที่สำคัญ
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
