# ศาสนาโลกและตำนานเปรียบเทียบ
ศาสนาของโลกเป็นระบบหลักของความเชื่อ การปฏิบัติ และชุมชนที่หล่อหลอมอารยธรรมของมนุษย์มาเป็นเวลาหลายพันปี ตำนานเชิงเปรียบเทียบศึกษาเรื่องราวที่วัฒนธรรมต่างๆ บอกเล่าเกี่ยวกับการสร้างสรรค์ วีรบุรุษ เทพเจ้า และความหมายของการดำรงอยู่ และรูปแบบที่โดดเด่นซึ่งเกิดขึ้นตามประเพณีที่แยกจากกันหลายพันไมล์และนับพันปี การทำความเข้าใจทั้งสองอย่างถือเป็นสิ่งสำคัญในการทำความเข้าใจว่าเหตุใดผู้คนจึงเชื่อในสิ่งที่พวกเขาเชื่อ วัฒนธรรมต่างกันอย่างไร และอะไรที่ทำให้ประสบการณ์ของมนุษย์เป็นหนึ่งเดียวกัน

### ภาพรวม
| ศาสนา | ต้นกำเนิด | ผู้ติดตาม | ข้อความหลัก | แนวคิดหลัก |
|----------|--------|-----------|-----------|-------------|
| **ศาสนาฮินดู** | อินเดีย (~ 2000 ปีก่อนคริสตศักราช) | ~1.2 พันล้าน | พระเวท; อุปนิษัท; ภควัทคีตา | ธรรมะ; กรรม; โมกชา; วงจรแห่งการเกิดใหม่ |
| **ศาสนายิว** | ตะวันออกกลาง (~ 1800 ปีก่อนคริสตศักราช) | ~15 ล้าน | โตราห์; ทัลมุก; ทานาค | นับถือพระเจ้าองค์เดียว; พันธสัญญา; กฎหมาย (ฮาลาคา) |
| **พุทธศาสนา** | อินเดีย (~ 500 ปีก่อนคริสตศักราช) | ~500 ล้าน | พระไตรปิฎก; พระสูตร | ความจริงอันสูงส่งสี่ประการ; เส้นทางแปดเท่า; นิพพาน |
| **ศาสนาเชน** | อินเดีย (~ 600 ปีก่อนคริสตศักราช) | ~4 ล้าน | อากามาส | อหิงสา (อหิงสา) หลายมุมมอง |
| **ศาสนาคริสต์** | ตะวันออกกลาง (~30 CE) | ~2.4 พันล้าน | พระคัมภีร์ (พันธสัญญาเดิม + ใหม่) | พระเยซูทรงเป็นผู้ช่วยให้รอด การฟื้นคืนชีพ; พระคุณ |
| **อิสลาม** | อาระเบีย (~610 CE) | ~1.9 พันล้าน | อัลกุรอาน; หะดีษ | เตาฮีด (เอกภาพของพระเจ้า); ห้าเสาหลัก |
| **ศาสนาซิกข์** | อินเดีย (~ ค.ศ. 1500) | ~30 ล้าน | คุรุแกรนธ์ซาฮิบ | พระเจ้าองค์เดียว ความเท่าเทียมกัน; บริการ |
| **ลัทธิขงจื้อ** | จีน (~ 500 ปีก่อนคริสตศักราช) | ~6 ล้าน (ตามศาสนา) | กวีนิพนธ์; ห้าคลาสสิก | เร็น (ความเมตตากรุณา); หลี่ (พิธีกรรม); ความสามัคคีทางสังคม |
| **ลัทธิเต๋า (Taoism)** | จีน (~ 400 ปีก่อนคริสตศักราช) | ~12 ล้าน | เต้าเต๋อจิง; จ้วงซี | Dao (ทาง); wu wei (ไม่กระทำ); ความเป็นธรรมชาติ |
| **ชินโต** | ญี่ปุ่น (โบราณ) | ~100 ล้าน | โคจิกิ; นิฮอน โชกิ | คามิ (วิญญาณในธรรมชาติ); ความบริสุทธิ์; พิธีกรรม |

## ตำนานเปรียบเทียบ
### การเดินทางของฮีโร่ (Monomyth)
โจเซฟ แคมป์เบลล์ระบุรูปแบบที่เกิดขึ้นซ้ำๆ ในตำนานทั่วทุกวัฒนธรรม:
| เวที | คำอธิบาย | ตัวอย่าง |
|-------|-------------|---------|
| **โลกธรรมดา** | ชีวิตปกติของฮีโร่ | โฟรโดในไชร์ |
| **โทรไปผจญภัย** | ความท้าทายหรือภารกิจปรากฏขึ้น | แกนดัล์ฟมาถึงพร้อมกับแหวน |
| **ปฏิเสธการโทร** | ฮีโร่ลังเล | โฟรโด: "ทำไมต้องเป็นฉัน" |
| **ความช่วยเหลือเหนือธรรมชาติ** | พี่เลี้ยงจัดหาเครื่องมือหรือคำแนะนำ | แกนดัล์ฟให้คำปรึกษา เอลรอนด์มอบมิตรภาพ |
| **ข้ามเกณฑ์** | ฮีโร่เข้าสู่สิ่งที่ไม่รู้จัก | ออกจากไชร์ |
| **ท้องวาฬ** | แยกตัวจากโลกที่รู้จักโดยสิ้นเชิง | เหมืองโมเรีย |
| **บททดสอบ พันธมิตร ศัตรู** | ความท้าทาย; มิตรภาพ; ฝ่ายค้าน | การทดลองต่างๆ สร้างความผูกพัน |
| **ทางเข้าถ้ำด้านในสุด** | เตรียมพบกับความท้าทายครั้งใหญ่ | ใกล้ภูเขาดูม |
| **ความเจ็บปวด** | วิกฤตการณ์ภาคกลาง ความตายและการเกิดใหม่ | การเผชิญหน้ากับศัตรู |
| **รางวัล** | การได้มาซึ่งสมบัติหรือความรู้ | แหวนถูกทำลาย |
| **ทางกลับ** | เดินทางกลับ; ความท้าทายสุดท้าย | กลับบ้าน |
| **การฟื้นคืนชีพ** | การเปลี่ยนแปลงครั้งสุดท้าย ฮีโร่ถูกเปลี่ยน | โฟรโดกลับมา แต่เปลี่ยนไปตลอดกาล |
| **กลับมาพร้อมน้ำอมฤต** | ฮีโร่นำปัญญาหรือของขวัญกลับคืนสู่โลกธรรมดา | ไชร์ถูกบันทึกไว้ |
### ตำนานการสร้าง
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **อดีตนิฮิโล** (จากความว่างเปล่า) | พระเจ้าสร้างจากความว่างเปล่า | ปฐมกาล (อับราฮัมมิก) |
| **ความโกลาหล** | คำสั่งโผล่ออกมาจากความสับสนวุ่นวายดึกดำบรรพ์ | กรีก (ความโกลาหล → ไกอา); นอร์ส (กินนุงคาป) |
| **ไข่คอสมิก** | จักรวาลฟักออกมาจากไข่ดึกดำบรรพ์ | ฮินดู (พราหมณ์); จีน (ปังกู่) |
| **ผู้ปกครองโลก** | พ่อฟ้าและแม่ดินแยกทาง | ชาวเมารี (รังกีและพ่อ); กรีก (ดาวยูเรนัสและไกอา) |
| **ดำน้ำดิน** | สัตว์ดำดิ่งลงสู่ผืนน้ำดึกดำบรรพ์เพื่อสร้างแผ่นดิน | ชนพื้นเมืองอเมริกัน; ญี่ปุ่น (อิซานางิ และ อิซานามิ) |
| **การเกิดขึ้น** | สิ่งมีชีวิตขึ้นสู่โลกต่างๆ สู่ปัจจุบัน | นาวาโฮ; โฮปิ |
### ตำนานน้ำท่วม
| ประเพณี | เรื่องราว |
|----------||-------|
| **อับราฮัมมิก** (ปฐมกาล) | พระเจ้าทรงส่งน้ำท่วม โนอาห์สร้างเรือ ช่วยไว้กับครอบครัวและสัตว์ของเขา |
| **เมโสโปเตเมีย** (มหากาพย์แห่งกิลกาเมช) | เทพเจ้าส่งน้ำท่วม อุตนาปิชติมต่อเรือ รอด |
| **ฮินดู** | พระวิษณุ (เหมือนมัทสยา ปลา) เตือนมนูถึงน้ำท่วม นำเรือของเขาไปสู่ความปลอดภัย |
| **กรีก** | ซุสส่งน้ำท่วม Deucalion และ Pyrrha เอาชีวิตรอดด้วยการสร้างเรือ |
| **เมโสอเมริกัน** | เทพเจ้าทำลายมนุษยชาติด้วยน้ำท่วม ไม่กี่คนรอด |

## การปฏิบัติทางศาสนา
### แนวทางปฏิบัติทั่วไปในศาสนาต่างๆ
| การปฏิบัติ | คำอธิบาย | ศาสนา |
|----------|-------------|-----------|
| **สวดมนต์** | การสื่อสารกับพระเจ้า | ศาสนาหลักทั้งหมด |
| **การทำสมาธิ** | การฝึกใคร่ครวญ; ความนิ่งภายใน | พุทธศาสนา; ศาสนาฮินดู; ศาสนาคริสต์ (ครุ่นคิด); ฆราวาส |
| **การถือศีลอด** | การละเว้นจากอาหารเพื่อจิตวิญญาณ | ศาสนาอิสลาม (รอมฎอน); ศาสนาคริสต์ (เข้าพรรษา); ศาสนายิว (ยมคิปปูร์) |
| **แสวงบุญ** | การเดินทางสู่สถานที่ศักดิ์สิทธิ์ | ศาสนาอิสลาม (เมกกะ); ศาสนาคริสต์ (เยรูซาเล็ม); ศาสนาฮินดู (พาราณสี); พุทธศาสนา (พุทธคยา) |
| **พิธีบวงสรวง** | ถวายแด่พระเจ้า | ประวัติศาสตร์ในประเพณีส่วนใหญ่ สัญลักษณ์ในทางปฏิบัติสมัยใหม่ |
| **การอ่านพระคัมภีร์** | ศึกษาคัมภีร์ศักดิ์สิทธิ์ | ศาสนาหลักทั้งหมด |
| **การกุศล** | มอบให้ผู้ที่ต้องการความช่วยเหลือ | ศาสนาหลักทุกศาสนา (ซะกาต; ส่วนสิบ; ดานา) |
| **พิธีกรรมทาง** | เครื่องหมายการเปลี่ยนแปลงชีวิต | การเกิด; การบรรลุนิติภาวะ; การแต่งงาน; ความตาย |

## โลกทัศน์ทางโลกและปรัชญา
| โลกทัศน์ | ความเชื่อหลัก | นักคิดคนสำคัญ |
|----------|-----------|--------------|
| **มนุษยนิยม** | เหตุผลและจริยธรรมของมนุษย์ปราศจากความเชื่อเหนือธรรมชาติ | เบอร์ทรันด์รัสเซลล์; คาร์ล เซแกน |
| **อัตถิภาวนิยม** | ชีวิตไม่มีความหมายโดยธรรมชาติ เราต้องสร้าง | ของเราเอง ซาร์ตร์; กามู; เคียร์เคการ์ด |
| **ลัทธิสโตอิก** | คุณธรรมเป็นสิ่งเดียวที่ดี ควบคุมสิ่งที่คุณทำได้ ยอมรับสิ่งที่คุณทำไม่ได้ | มาร์คัส ออเรลิอุส; เอพิกเตตัส; เซเนกา |
| **พุทธศาสนา(ฆราวาส)** | การมีสติและจริยธรรมโดยไม่มีการกล่าวอ้างเลื่อนลอย | สตีเฟน แบทเชเลอร์; แซม แฮร์ริส |
| **เห็นแก่ผู้อื่นอย่างมีประสิทธิผล** | ใช้หลักฐานและเหตุผลให้เกิดประโยชน์สูงสุด | ปีเตอร์ ซิงเกอร์; วิลเลียม แมคแอสคิล |

## สรุป
ศาสนาของโลกเป็นความพยายามที่เก่าแก่ที่สุดและแพร่หลายที่สุดของมนุษยชาติในการตอบคำถามพื้นฐาน: ทำไมเราถึงอยู่ที่นี่? เราควรใช้ชีวิตอย่างไร? จะเกิดอะไรขึ้นหลังความตาย? ความเชื่อของอับราฮัม (ศาสนายิว คริสต์ และอิสลาม) มีบรรพบุรุษร่วมกันในอับราฮัม และเน้นที่การนับถือพระเจ้าองค์เดียว พระคัมภีร์ และกฎหมายจริยธรรม ประเพณีตะวันออก (ฮินดู พุทธ เชน เต๋า) เน้นเรื่องธรรมะ กรรม การหลุดพ้นจากวัฏจักรแห่งการเกิดใหม่ และความสอดคล้องกับธรรมชาติ ตำนานเปรียบเทียบเผยให้เห็นรูปแบบที่โดดเด่นในวัฒนธรรมต่างๆ — การเดินทางของฮีโร่ ตำนานการสร้าง เรื่องราวน้ำท่วม — แนะนำโครงสร้างที่ลึกซึ้งในการเล่าเรื่องของมนุษย์ การปฏิบัติทางศาสนา (การสวดมนต์ นั่งสมาธิ การอดอาหาร การแสวงบุญ การกุศล) ปรากฏอยู่ในทุกประเพณี โลกทัศน์ทางโลก (มนุษยนิยม อัตถิภาวนิยม ลัทธิสโตอิกนิยม) เสนอกรอบความหมายที่ไม่ใช่ศาสนา การทำความเข้าใจประเพณีเหล่านี้ไม่ได้เกี่ยวกับการเชื่อประเพณีใดๆ แต่เป็นการทำความเข้าใจผู้คนหลายพันล้านคนซึ่งชีวิต ค่านิยม และการตัดสินใจของพวกเขาถูกกำหนดโดยพวกเขา
