# ปรัชญาและการคิดเชิงวิพากษ์
ปรัชญาไม่ใช่หัวข้อที่เต็มไปด้วยฝุ่นซึ่งสงวนไว้สำหรับชาวกรีกที่มีหนวดมีเคราในชุดคลุม มันเป็นระบบปฏิบัติการที่อยู่เบื้องหลังทุกการตัดสินใจของคุณ สิ่งที่ถือเป็นความรู้ สิ่งที่คุ้มค่าที่จะทำ วิธีบอกเล่าข้อโต้แย้งที่ดีจากข้อโต้แย้งที่ไม่ดี การคิดเชิงวิพากษ์เป็นด้านปฏิบัติ: ทักษะในการวิเคราะห์คำกล่าวอ้าง การระบุเหตุผลที่ไม่ถูกต้อง และการตัดสินใจที่ดีขึ้น ไฟล์นี้ครอบคลุมแนวคิดสำคัญ เครื่องมือในการประเมิน และกับดักทางปัญญาที่ดักจับทุกคน

## โรงเรียนแห่งความคิดที่สำคัญ
ปรัชญามีประเพณีมายาวนานนับพันปี ตำแหน่งที่สำคัญส่วนใหญ่สามารถจัดกลุ่มได้เป็นเพียงไม่กี่โรงเรียน
### โบราณและคลาสสิก
| โรงเรียน | แนวคิดหลัก | รูปสำคัญ |
|----------------------|-----------|------------|
| **ลัทธิสโตอิก** | มุ่งเน้นไปที่สิ่งที่คุณสามารถควบคุมได้ ยอมรับสิ่งที่คุณทำไม่ได้ คุณธรรมคือความดีเท่านั้น | มาร์คัส ออเรลิอุส, เอพิคเททัส, เซเนกา |
| **ผู้มีรสนิยมสูง** | ชีวิตที่ดีคือความสุขที่เรียบง่าย มิตรภาพ และการปราศจากความวิตกกังวล | เอพิคิวรัส |
| **ความเห็นถากถางดูถูก** | ปฏิเสธความปรารถนาทั่วไปและบรรทัดฐานทางสังคม ดำเนินชีวิตให้สอดคล้องกับธรรมชาติ | ไดโอจีเนส |
| **ความสงสัย** | ระงับการตัดสิน — ความแน่นอนเป็นไปไม่ได้หรืออย่างน้อยก็ยากมาก | ไพโร, Sextus Empiricus |
| **ลัทธิขงจื้อ** | ความสามัคคีทางสังคมผ่านการปลูกฝังคุณธรรม พิธีกรรม และความสัมพันธ์ที่เหมาะสม | ขงจื๊อ |
| **ลัทธิเต๋า** | อยู่ร่วมกับเต๋า (วิถี) การกระทำที่ไม่ต้องใช้ความพยายาม (wu wei) | ลาวซี่ |
| **พุทธศาสนา** | ความทุกข์เกิดจากการยึดติด ความหลุดพ้นตามมรรคมีองค์แปด | สิทธารถะโคตมะ |
### ปรัชญาสมัยใหม่
| โรงเรียน | แนวคิดหลัก | รูปสำคัญ |
|----------------------|-----------|------------|
| **เหตุผลนิยม** | ความรู้มาจากเหตุผลและความคิดที่มีมาแต่กำเนิดเป็นหลัก | เดส์การตส์, สปิโนซา, ไลบ์นิซ |
| **ประสบการณ์นิยม** | ความรู้มาจากประสบการณ์ทางประสาทสัมผัส จิตใจเป็นกระดานชนวนที่ว่างเปล่า | ล็อค, ฮูม, เบิร์กลีย์ |
| **ความเพ้อฝัน** | ความเป็นจริงคือพื้นฐานทางจิต โลกวัตถุเป็นเรื่องรอง | คานท์ (เหนือธรรมชาติ), เฮเกล (สัมบูรณ์) |
| **ลัทธิปฏิบัตินิยม** | ความหมายและความจริงของแนวคิดนั้นขึ้นอยู่กับผลที่ตามมาในทางปฏิบัติ | เพียร์ซ, เจมส์, ดิวอีย์ |
| **อัตถิภาวนิยม** | การดำรงอยู่มาก่อนแก่นแท้ เราสร้างความหมายของเราเองผ่านทางเลือก | ซาร์ตร์, เดอ โบวัวร์, กามู, เคียร์เคการ์ด |
| **ปรากฏการณ์วิทยา** | ศึกษาประสบการณ์อย่างมีสติจากมุมมองของบุคคลที่หนึ่ง | ฮุสเซิร์ล, ไฮเดกเกอร์, แมร์โล-ปองตี |
| **ปรัชญาการวิเคราะห์** | ชี้แจงภาษาและตรรกะ โดดเด่นในโลกที่พูดภาษาอังกฤษ | รัสเซลล์, วิตเกนสไตน์, เฟรจ |
### ร่วมสมัย
| โรงเรียน | แนวคิดหลัก | รูปสำคัญ |
|----------------------|-----------|------------|
| **ประโยชน์นิยม** | การกระทำที่ถูกต้องจะช่วยเพิ่มความเป็นอยู่โดยรวมให้สูงสุด | เบนท์แธม, มิลล์, นักร้อง |
| **ทันตกรรมวิทยา** | การกระทำบางอย่างย่อมถูกหรือผิดโดยธรรมชาติ ไม่ว่าผลที่ตามมาจะเป็นอย่างไร | คานท์ |
| **คุณธรรมจริยธรรม** | มุ่งเน้นไปที่ลักษณะนิสัยมากกว่ากฎเกณฑ์หรือผลลัพธ์ | อริสโตเติล, แมคอินไทร์ |
| **ลัทธิหลังสมัยใหม่** | ผู้ต้องสงสัยเล่าเรื่องใหญ่ ความจริงถูกหล่อหลอมด้วยพลังและบริบท | ฟูโกต์, เดอร์ริดา, ลีโอตาร์ด |
| **ลัทธิทำลายล้าง** | ชีวิตไม่มีความหมาย คุณค่า หรือวัตถุประสงค์โดยธรรมชาติ | Nietzsche (ได้รับการวินิจฉัย ไม่รับรอง) |
| **เรื่องไร้สาระ** | จักรวาลนั้นไร้ความหมาย แต่เราก็ควรดำเนินชีวิตอย่างท้าทายอยู่ดี | กามู |

## กรอบจริยธรรม
เมื่อคุณต้องการตัดสินใจว่าอะไรถูกต้อง คุณกำลังทำจริยธรรม ไม่ว่าคุณจะตระหนักหรือไม่ก็ตาม มีสามแนวทางหลัก
### กรอบทั้งสาม
| กรอบ | คำถามที่ถาม | ความแข็งแกร่ง | จุดอ่อน |
|----------|-----------------|----------|----------|
| **ลัทธิสืบเนื่อง** (ลัทธิอรรถประโยชน์) | “อะไรให้ผลลัพธ์ที่ดีที่สุด” | ใช้งานได้จริง วัดผลได้ ปรับขนาดตามนโยบาย | ยากที่จะคาดเดาผลที่ตามมา สามารถพิสูจน์การทำร้ายชนกลุ่มน้อยได้ |
| **ธรรมศาสตร์** (จริยธรรมกันเทียน) | “ทุกคนควรปฏิบัติตามกฎอะไร?” | ปกป้องสิทธิส่วนบุคคล สม่ำเสมอ | แข็ง; หน้าที่ขัดแย้งกัน |
| **คุณธรรมจริยธรรม** | “คนดีจะทำยังไงล่ะ” | ยืดหยุ่นได้; มุ่งเน้นไปที่ตัวละคร | คลุมเครือ; ไม่ได้ให้คำแนะนำการดำเนินการที่ชัดเจน |
### ความจำเป็นเด็ดขาดของคานท์
แบบทดสอบของคานท์ว่าการกระทำนั้นเป็นไปตามศีลธรรมหรือไม่:
1. **ความสามารถรอบด้าน**: คุณอยากให้ทุกคนทำเช่นนี้ได้ไหม? (หากการโกหกเป็นเรื่องสากล ความไว้ใจก็พังทลาย)
2. **มนุษยชาติเป็นจุดจบ**: อย่าปฏิบัติต่อผู้คนเป็นเพียงหนทางสู่จุดจบ
### จริยธรรมประยุกต์
| โดเมน | คำถามสำคัญ |
|--------|--------------|
| **จริยธรรม** | การทำแท้ง การการุณยฆาต พันธุวิศวกรรม สิทธิสัตว์ |
| **จริยธรรมทางธุรกิจ** | ความรับผิดชอบขององค์กร การแจ้งเบาะแส ค่าจ้างที่เป็นธรรม |
| **จริยธรรมด้านเทคโนโลยี/AI** | ความเป็นส่วนตัว อคติอัลกอริธึม อาวุธอัตโนมัติ การโยกย้ายงาน |
| **จริยธรรมสิ่งแวดล้อม** | ความรับผิดชอบต่อสภาพภูมิอากาศ สวัสดิภาพสัตว์ ความยุติธรรมระหว่างรุ่น |

## ตรรกะและการโต้แย้ง
ตรรกะคือการศึกษาการใช้เหตุผลที่ถูกต้อง มันให้เครื่องมือแก่คุณในการบอกได้ว่าเมื่อใดข้อโต้แย้งของใครบางคนสนับสนุนข้อสรุปของพวกเขาจริงๆ และเมื่อใดไม่สนับสนุน
### ประเภทของการใช้เหตุผล
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **นิรนัย** | ถ้าเหตุผลเป็นจริง ข้อสรุป *ต้อง* เป็นจริง | มนุษย์ทุกคนต้องตาย โสกราตีสเป็นมนุษย์ → โสกราตีสเป็นมนุษย์ |
| **อุปนัย** | สถานที่ให้ข้อสรุป *น่าจะ* ไม่แน่นอน | หงส์ทุกตัวที่ฉันเห็นเป็นสีขาว → หงส์ทั้งหมดอาจเป็นสีขาว |
| **ลักพาตัว** | การอนุมานเพื่อคำอธิบายที่ดีที่สุด | หญ้าก็เปียก คำอธิบายที่ดีที่สุด: ฝนตก |
### การเข้าใจผิดเชิงตรรกะทั่วไป
| การเข้าใจผิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **โฆษณาบ้าน** | โจมตีคน ไม่ใช่ทะเลาะ | “คุณไม่สามารถไว้ใจเธอในเรื่องเศรษฐศาสตร์ได้ เธอไม่ใช่นักเศรษฐศาสตร์” |
| **มนุษย์ฟาง** | การแสดงข้อโต้แย้งอย่างไม่ถูกต้องเพื่อให้โจมตีได้ง่ายขึ้น | “คุณต้องการลดงบประมาณทางทหารเหรอ? แล้วคุณอยากจะออกจากประเทศโดยไม่มีการป้องกัน?” |
| **อุทธรณ์ต่อผู้มีอำนาจ** | "X เป็นจริงเพราะผู้เชี่ยวชาญพูดเช่นนั้น" (โดยไม่ตรวจสอบข้อโต้แย้ง) | “ผู้ได้รับรางวัลโนเบลคนนี้พูดเรื่องนี้เกี่ยวกับการเมือง ดังนั้นมันจึงต้องถูกต้อง” |
| **การแบ่งขั้วแบบเท็จ** | นำเสนอเพียงสองตัวเลือกเมื่อมีมากกว่า | “ไม่ว่าคุณจะสนับสนุนนโยบายนี้หรือคุณไม่ใส่ใจเด็กๆ” |
| **ทางลาดลื่น** | A นำไปสู่ ​​Z ผ่านเหตุการณ์ที่ไม่น่าเป็นไปได้ต่อเนื่องกัน | “ถ้าเราทำให้กัญชาถูกกฎหมาย ในไม่ช้า เราก็จะทำให้ทุกอย่างถูกกฎหมาย” |
| **ถามคำถาม** | ข้อสรุปจะถือว่าอยู่ในสถานที่ | “กฎหมายนี้ไม่ยุติธรรมเพราะไม่ยุติธรรม” (ไม่ยุติธรรม = ไม่ยุติธรรม — สิ่งเดียวกัน) |
| **โพสต์เฉพาะกิจ Ergo propter เฉพาะกิจ** | A เกิดขึ้นก่อน B ดังนั้น A ทำให้เกิด B | "ฉันทานอาหารเสริมแล้วรู้สึกดีขึ้น อาหารเสริมได้ผล" |
| **ตู่ quoque** | “คุณก็ทำเหมือนกัน” — ปฏิเสธคำวิจารณ์เพราะว่านักวิจารณ์เป็นคนหน้าซื่อใจคด | “คุณบอกให้ฉันกินเพื่อสุขภาพ แต่คุณกินอาหารจานด่วน” |
| **ดึงดูดใจธรรมชาติ** | “ธรรมชาติ=ดี” | “มนุษย์วิวัฒนาการมาเพื่อกินเนื้อสัตว์ ดังนั้นการกินเจจึงผิดธรรมชาติและผิด” |
| **การเข้าใจผิดของต้นทุนจม** | ต่อเนื่องเพราะการลงทุนในอดีต ไม่ใช่มูลค่าในอนาคต | “เราใช้เงินไปแล้ว 10 ล้านเหรียญสหรัฐสำหรับโปรเจ็กต์นี้ เราหยุดไม่ได้แล้ว” |
### การประเมินข้อโต้แย้ง
อาร์กิวเมนต์ที่ดีมี:
1. **สถานที่จริง (หรือได้รับการสนับสนุนอย่างดี)**
2. **ตรรกะที่ถูกต้อง** (ข้อสรุปตามมาจากสถานที่)
3. **ไม่มีสมมติฐานแอบแฝง**
4. **ความเกี่ยวข้อง** (สถานที่กล่าวถึงข้อสรุปจริงๆ)

## ญาณวิทยา: เรารู้อะไรได้บ้าง?
ญาณวิทยาคือการศึกษาความรู้เองว่ามันคืออะไร เราได้มันมาอย่างไร และขีดจำกัดของมันคืออะไร
### แหล่งความรู้
| ที่มา | คำอธิบาย | ข้อจำกัด |
|--------|-------------|------------|
| **การรับรู้** | ประสบการณ์ทางประสาทสัมผัสโดยตรง | ภาพลวงตา ภาพหลอน ขอบเขตจำกัด |
| **เหตุผล** | การอนุมานเชิงตรรกะและการพิสูจน์ทางคณิตศาสตร์ | บอกคุณเฉพาะสิ่งต่อไปนี้จากสถานที่ของคุณ |
| **วิปัสสนา** | สำรวจความคิดและความรู้สึกของตัวเอง | การหลอกลวงตนเอง; จำกัด การเข้าถึงกระบวนการของคุณเอง |
| **คำให้การ** | สิ่งที่คนอื่นบอกคุณ | ผู้คนโกหก ถูกเข้าใจผิด หรือพูดง่ายเกินไป |
| **ความทรงจำ** | ย้อนนึกถึงประสบการณ์ที่ผ่านมา | ไม่น่าเชื่อถือ; สร้างสรรค์; ลดลงเมื่อเวลาผ่านไป |
| **วิธีการทางวิทยาศาสตร์** | การสังเกตอย่างเป็นระบบ การทดสอบสมมติฐาน การจำลองแบบ | ช้า; จำกัดเพียงคำถามที่สามารถทดสอบได้ ขึ้นอยู่กับกระบวนทัศน์ |
### ปัญหาญาณวิทยาที่สำคัญ
| ปัญหา | คำอธิบาย |
|---------|-------------|
| **ปัญหาการเหนี่ยวนำ** | เพียงเพราะดวงอาทิตย์ขึ้นทุกวันในอดีตไม่ได้ *ตามหลักเหตุผล* รับประกันว่าวันพรุ่งนี้จะเกิดขึ้น (ฮูม) |

| **ปัญหาการแบ่งเขต** | วิทยาศาสตร์แตกต่างจากวิทยาศาสตร์เทียมอะไร? (ตกใจ: การปลอมแปลง) |

| **ภาพลวงตา** | สติที่เราสัมผัสมันเป็นภาพลวงตา | ดูเหมือนว่าจะปฏิเสธสิ่งหนึ่งที่เรามั่นใจมากที่สุด |

| **ปัญหารถเข็น** | เป็นที่ยอมรับทางศีลธรรมหรือไม่ที่จะเสียสละคนหนึ่งคนเพื่อช่วยห้าคน? ทดสอบสัญชาตญาณเกี่ยวกับผลสืบเนื่องเทียบกับ deontology |

## อคติทางปัญญา
สมองของคุณใช้ทางลัด ส่วนใหญ่แล้วพวกเขาจะทำงานได้ดี เมื่อไม่ทำ ผลลัพธ์จะเรียกว่าอคติทางการรับรู้ การรู้จักพวกเขาเป็นขั้นตอนแรกในการหลีกเลี่ยงพวกเขา
### อคติในการตัดสินใจ
| อคติ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **อคติในการยืนยัน** | การค้นหาข้อมูลที่ยืนยันความเชื่อที่มีอยู่ | อ่านเฉพาะแหล่งข่าวที่เห็นด้วยกับคุณเท่านั้น |
| **การยึดเกาะ** | พึ่งพาข้อมูลชิ้นแรกที่พบมากเกินไป | การเจรจาจากราคาเริ่มต้นที่สูงเกินไป |
| **ฮิวริสติกความพร้อมใช้งาน** | ตัดสินความน่าจะเป็นโดยตัวอย่างที่นึกถึง | ประเมินความเสี่ยงเครื่องบินตกมากเกินไปเนื่องจากมีการรายงานอย่างกว้างขวาง |
| **เอฟเฟกต์ Dunning-Kruger** | คนที่มีความสามารถต่ำประเมินความสามารถของตนสูงเกินไป ผู้เชี่ยวชาญดูถูกดูแคลนพวกเขา | ผู้เริ่มต้นมั่นใจว่าพวกเขาสามารถแก้ปัญหาที่ผู้เชี่ยวชาญพบว่ายาก |
| **เอฟเฟ็กต์การจัดเฟรม** | การตัดสินใจเปลี่ยนแปลงไปตามวิธีการนำเสนอตัวเลือก | "อัตราการรอดชีวิต 90%" ฟังดูเหมือนดีกว่า "อัตราการเสียชีวิต 10%" |
| **ความเกลียดชังการสูญเสีย** | การสูญเสียให้ความรู้สึกแย่เป็นสองเท่าของการได้รับที่เทียบเท่ารู้สึกดี | ถือหุ้นขาดทุนเพราะการขายจะ "ล็อค" การขาดทุน |
| **สถานะที่เป็นอคติ** | ชอบให้ของเหมือนเดิม | ไม่เปลี่ยนแผนดีกว่าเพราะการเปลี่ยนแปลงคือความพยายาม |
### อคติทางสังคม
| อคติ | คำอธิบาย |
|-|-------------|
| **เอฟเฟกต์รัศมี** | ลักษณะเชิงบวกประการหนึ่งจะเติมสีสันให้กับความประทับใจโดยรวมของคุณต่อบุคคลหนึ่ง |
| **ข้อผิดพลาดในการระบุแหล่งที่มาโดยพื้นฐาน** | ถือว่าพฤติกรรมของผู้อื่นเป็นไปตามลักษณะนิสัย ของคุณเองตามสถานการณ์ |
| **อคติในกลุ่ม** | ให้ความสำคัญกับคนที่คุณมองว่าเป็นส่วนหนึ่งของกลุ่มของคุณ |
| **เอฟเฟคแบนด์วากอน** | การยอมรับความเชื่อเพราะมีอีกหลายคนยึดถือ |
| **การเข้าใจผิดเพียงโลก** | คนที่เชื่อว่าได้รับสิ่งที่พวกเขาสมควรได้รับ |
### วิธีบรรเทาอคติ
1. **ฝ่ายค้านคนเหล็ก**: สร้างข้อโต้แย้งที่แข็งแกร่งที่สุดที่คุณไม่เห็นด้วย
2. **ขอหลักฐานที่ไม่ยืนยัน**: มองหาเหตุผลที่คุณอาจผิดอย่างแข็งขัน
3. **พิจารณาอัตราฐาน**: โดยทั่วไปแล้วผลลัพธ์ประเภทนี้พบได้บ่อยเพียงใด
4. **ใช้รายการตรวจสอบและกรอบการทำงาน**: เปลี่ยนความคิดของคุณให้เป็นภายนอกเพื่อจับจุดบอด
5. **นอนหลับกับการตัดสินใจที่สำคัญ**: สัญชาตญาณแรกมักมีอคติ
6. **เชิญชวนให้เกิดความขัดแย้ง**: รายล้อมตัวคุณเองด้วยผู้คนที่จะบอกคุณเมื่อคุณทำผิด

## ทำไมเรื่องนี้ถึงสำคัญ
ปรัชญาและการคิดเชิงวิพากษ์ไม่ใช่แบบฝึกหัดที่เป็นนามธรรม มันเป็นเครื่องมือที่ใช้งานได้จริง:
- **กรอบจริยธรรม** ช่วยคุณจัดการกับปัญหาที่กลืนไม่เข้าคายไม่ออกอย่างแท้จริง ทั้งในด้านธุรกิจ เทคโนโลยี และชีวิตส่วนตัว
- **ตรรกะ** ช่วยให้คุณมองเห็นข้อโต้แย้งที่ไม่ดีในการเมือง การโฆษณา และโซเชียลมีเดีย
- **อคติด้านการรับรู้** อธิบายว่าทำไมคนฉลาดถึงตัดสินใจโง่ๆ และวิธีตัดสินใจให้น้อยลง
- **ญาณวิทยา** มีความเกี่ยวข้องมากขึ้นในยุคของการให้ข้อมูลผิด ๆ คุณจะรู้ได้อย่างไรว่าอะไรเป็นความจริง
คุณไม่จำเป็นต้องเห็นด้วยกับนักปรัชญาคนใดโดยเฉพาะ คุณเพียงแค่ต้องสามารถคิดได้อย่างชัดเจนว่าคุณเชื่ออะไรและเพราะเหตุใด
