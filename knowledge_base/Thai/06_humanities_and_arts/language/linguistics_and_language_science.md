# ภาษาศาสตร์และวิทยาศาสตร์ภาษา
ภาษาศาสตร์คือการศึกษาทางวิทยาศาสตร์เกี่ยวกับภาษา ทั้งโครงสร้าง ความหมาย การใช้ การได้มา และวิวัฒนาการ ภาษาเป็นคุณลักษณะที่กำหนดในการสื่อสารของมนุษย์: มีประสิทธิภาพอย่างไม่มีที่สิ้นสุด (ผู้พูดสามารถสร้างและเข้าใจประโยคที่พวกเขาไม่เคยพบมาก่อน) มีการถ่ายทอดทางวัฒนธรรม (เป็นการเรียนรู้มากกว่าโดยกำเนิดล้วนๆ) และมีการพัฒนาอย่างต่อเนื่อง การทำความเข้าใจวิธีการทำงานของภาษามีความเกี่ยวข้องกับใครก็ตามที่สร้างเทคโนโลยีภาษา การสอน การแปล หรือการทำงานเพื่อสื่อสารอย่างมีประสิทธิภาพมากขึ้น
---

## ระดับของภาษา
### ภาพรวม
| ระดับ | การศึกษา | หน่วยวิเคราะห์ | ตัวอย่างคำถาม |
|-------|---------|-----------------|-----------------|
| **สัทศาสตร์** | เสียงทางกายภาพของคำพูด | โทรศัพท์ (เสียงพูด) | ตัว "p" ใน "pin" แตกต่างจาก "spin" อย่างไร? |
| **สัทวิทยา** | ระบบเสียงและรูปแบบ | หน่วยเสียง (เสียงที่ตัดกัน) | ทำไมคำภาษาอังกฤษถึงขึ้นต้นด้วย "str" ​​แต่ไม่ใช่ "ztr"? |
| **สัณฐานวิทยา** | โครงสร้างของคำ | หน่วยคำ (หน่วยความหมายที่เล็กที่สุด) | “ความทุกข์” สลายได้อย่างไร? |
| **ไวยากรณ์** | โครงสร้างของประโยค | วลี; ข้อ | เหตุใด "แนวคิดสีเขียวไร้สีจึงหลับใหลอย่างดุเดือด" ถึงใช้หลักไวยากรณ์แต่ก็ไร้สาระ |
| **ความหมาย** | ความหมาย | คำ; ประโยค; ข้อเสนอ | "ใหญ่" และ "ใหญ่" แตกต่างกันอย่างไร? |
| **เชิงปฏิบัติ** | ความหมายในบริบท | คำพูด; โดยปริยาย | อะไร "คุณส่งเกลือได้ไหม" หมายถึงจริงๆเหรอ? |

## สัทศาสตร์และสัทวิทยา
### สัทอักษรสากล (IPA)
| หมวดหมู่ | สัญลักษณ์ | ตัวอย่าง |
|----------|---------|---------|
| **ตั้งใจ** | p, b, t, d, k, g | "ตบ", "ค้างคาว", "แมว", "ได้" |
| **คำเสียดแทรก** | f, v, θ, ð, s, z, ʃ, ', h | "อ้วน", "ถัง", "ผอม", "แล้ว", "จิบ", "zip" |
| **จมูก** | ม. n Å‹ | "เสื่อ", "แนท", "ร้องเพลง" |
| **โดยประมาณ** | l, r, w, j | "ให้", "แดง", "เปียก", "ยัง" |
| **แอฟริกาใต้** | tʃ, d' | "คริสตจักร", "ผู้พิพากษา" |
### แนวคิดหลักสัทวิทยา
| แนวคิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **คู่ขั้นต่ำ** | สองคำที่แตกต่างกันในหน่วยเสียงเดียวที่เปลี่ยนความหมาย | "pat" กับ "bat" (ความเปรียบต่าง p/b) |
| **การออกเสียง** | กฎเกี่ยวกับการอนุญาตให้ผสมเสียง | ภาษาอังกฤษไม่อนุญาตให้ใช้คำเริ่มต้น /Å‹/ |
| **ความเครียด** | เน้นบางพยางค์ | "REcord" (คำนาม) กับ "reCORD" (กริยา) |
| **น้ำเสียง** | รูปแบบระดับเสียงข้ามคำพูด | น้ำเสียงที่เพิ่มขึ้น = คำถามในภาษาอังกฤษ |
| **การดูดซึม** | เสียงจะเหมือนเสียงข้างเคียงมากขึ้น | "กระเป๋าถือ" มักออกเสียงว่า "hambag" |

## สัณฐานวิทยา
### ประเภทของหน่วยคำ
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **หน่วยคำฟรี** | สามารถยืนอยู่คนเดียวเป็นคำ | "แมว"; "วิ่ง"; "มีความสุข" |
| **หน่วยคำที่ถูกผูกไว้** | ต้องแนบไปกับหน่วยคำอื่น | "-s" (พหูพจน์); “-ed” (อดีตกาล); "un-" (ปฏิเสธ) |
| **อนุพันธ์** | สร้างคำใหม่ อาจเปลี่ยนส่วนของคำพูด | "มีความสุข" → "ความสุข" (คำคุณศัพท์ → คำนาม) |
| **ผันคำ** | ปรับเปลี่ยนรูปแบบไวยากรณ์ของคำ ไม่เปลี่ยนส่วนของคำพูด | "เดิน" → "เดิน" (ปัจจุบัน → อดีต) |
### กระบวนการสร้างคำ
| กระบวนการ | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **การประนอม** | การรวมสองหน่วยคำอิสระ | "ทานตะวัน"; "แปรงสีฟัน" |
| **ที่มา** | การเพิ่มส่วนต่อท้าย | "สอน" → "ครู" |
| **การตัดภาพ** | การย่อคำ | "ห้องปฏิบัติการ" → "ห้องปฏิบัติการ" |
| **การผสม** | การรวมส่วนของสองคำ | "ควัน" + "หมอก" = "หมอกควัน" |
| **อักษรย่อ** | ใช้ตัวอักษรเริ่มต้น | นาซ่า; เลเซอร์; ดำน้ำลึก |
| **การกู้ยืม** | การเอาคำจากภาษาอื่น | "ซูชิ" (ญี่ปุ่น); "cafe" (ฝรั่งเศส) |
| **เหรียญกษาปณ์** | การประดิษฐ์คำใหม่ | "Google" (กริยา); "ควาร์ก" |

## ไวยากรณ์
### โครงสร้างวลี
| วลี | หัว | ตัวอย่าง |
|--------|-|---------|
| **คำนามวลี (NP)** | คำนาม | “ลูกบอลสีแดงลูกใหญ่” |
| **กริยาวลี (VP)** | กริยา | “กินเค้กเร็ว” |
| **บุพบทวลี (PP)** | คำบุพบท | "ในสวน" |
| **คำคุณศัพท์วลี (AP)** | คำคุณศัพท์ | "พอใจกับผลลัพธ์มาก" |
| **วลีกำหนด (DP)** | ตัวกำหนด | "ที่"; "สามของโปรดของฉัน" |
### แนวคิดทางวากยสัมพันธ์
| แนวคิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **เขตเลือกตั้ง** | กลุ่มคำเป็นหน่วยลำดับชั้น (องค์ประกอบ) | “ผู้เฒ่า” เป็นส่วนประกอบ "เจ้าเฒ่า" ไม่ใช่ |
| **การเรียกซ้ำ** | วลีสามารถประกอบด้วยวลีประเภทเดียวกัน | “แมวที่หมาที่หนูกัดวิ่งหนี” |
| **ความคลุมเครือ** | ประโยคที่มีการตีความเชิงโครงสร้างหลายแบบ | “ฉันเห็นผู้ชายถือกล้องโทรทรรศน์” (ใครมีกล้องโทรทรรศน์?) |
| **การเคลื่อนไหว** | องค์ประกอบสามารถย้ายจากตำแหน่งฐาน | “คุณกินอะไรมาบ้าง____?” (สิ่งที่ย้ายจากตำแหน่งวัตถุ) |
| **ข้อตกลง** | คำต้องตรงกันในลักษณะ (ตัวเลข บุคคล เพศ) | "เธอวิ่ง" (ไม่ใช่ "เธอวิ่ง") |

## ความหมาย
### ความสัมพันธ์เชิงความหมาย
| ความสัมพันธ์ | คำอธิบาย | ตัวอย่าง |
|----------|-------------|---------|
| **คำพ้องความหมาย** | ความหมายเหมือนหรือคล้ายกัน | "ใหญ่" อยู่ที่ "ใหญ่" |
| **คำตรงข้าม** | ความหมายตรงข้าม | "ร้อน" ↔ "เย็น" |
| **สะกดจิต** | เฉพาะ → ทั่วไป | "กุหลาบ" เป็นคำสะกดของ "ดอกไม้" |
| **ไฮเปอร์นิมมี่** | ทั่วไป → เฉพาะ | "fruit" เป็นคำพ้องเสียงของ "apple" |
| **คำนาม** | ส่วน → ทั้งหมด | "wheel" เป็นคำย่อของ "car" |
| **โพลีเซมี** | คำเดียวที่มีหลายความหมายที่เกี่ยวข้อง | "หัว" (ส่วนของร่างกาย; ผู้นำ; ด้านบนของบางสิ่งบางอย่าง) |
| **คำพ้องเสียง** | รูปแบบเดียวกัน ความหมายที่ไม่เกี่ยวข้อง | "ธนาคาร" (แม่น้ำ); "ธนาคาร" (สถาบันการเงิน) |
### ความหมายเชิงองค์ประกอบ
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **หลักการจัดองค์ประกอบ** | ความหมายของนิพจน์ที่ซับซ้อนนั้นพิจารณาจากส่วนต่างๆ ของนิพจน์และวิธีการรวม |
| **บทบาทเฉพาะเรื่อง** | ตัวแทน (ผู้กระทำ); ผู้ป่วย (ได้รับผลกระทบ); เครื่องดนตรี (เครื่องมือ); เป้าหมาย; แหล่งที่มา; ที่ตั้ง |
| **รายละเอียดเพิ่มเติม** | ถ้า A เป็นจริง B ก็ต้องเป็นจริง: "เธอฆ่าเขา" แปลว่า "เขาตายแล้ว" |
| **ข้อสันนิษฐาน** | สมมติฐานเบื้องหลัง: "กษัตริย์ฝรั่งเศสทรงโล้น" สันนิษฐานว่ามีกษัตริย์แห่งฝรั่งเศส |

## เชิงปฏิบัติ
### แนวคิดหลัก
| แนวคิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **การกระทำคำพูด** | คำพูดดำเนินการ: การยืนยัน; การร้องขอ; มีแนวโน้ม; ขอโทษ | "ฉันขอโทษ" = การขอโทษ |
| **โดยนัย** | ความหมายโดยนัยแต่ไม่ได้ระบุ | “นักเรียนบางคนผ่าน” หมายความว่า “ไม่ผ่านทั้งหมด” |
| **แม็กซิมส์ของเกรซ** | คุณภาพ (เป็นจริง); ปริมาณ (ให้ข้อมูลเพียงพอ ไม่มากเกินไป) ความสัมพันธ์ (มีความเกี่ยวข้อง); ลักษณะ (ชัดเจน) | การละเมิดหลักคำสอนทำให้เกิดนัย |
| **เดซิซิส** | คำที่การอ้างอิงขึ้นอยู่กับบริบท | "ที่นี่"; "ตอนนี้"; "นี้"; "เธอ" |
| **ความสุภาพ** | การกระทำที่คุกคามใบหน้าบรรเทาลงโดยทางอ้อม | "คุณทำได้ไหม..." vs "ทำสิ่งนี้" |
| **จุดร่วม** | แบ่งปันความรู้ระหว่างวิทยากร | "ปกติ" ใช้ได้กับบริบทที่แชร์เท่านั้น |

## สรุป
ภาษาศาสตร์ศึกษาภาษาในหลายระดับ: สัทศาสตร์ (เสียง) สัทวิทยา (ระบบเสียง) สัณฐานวิทยา (โครงสร้างคำ) วากยสัมพันธ์ (โครงสร้างประโยค) ความหมาย (ความหมาย) และสัจนิยม (ความหมายในบริบท) ภาษามีประสิทธิผลอย่างไม่มีที่สิ้นสุด เราสามารถสร้างและเข้าใจประโยคที่เราไม่เคยได้ยินได้ คำถูกสร้างขึ้นจากหน่วยคำ ประโยคจากโครงสร้างวลีแบบลำดับชั้น ความหมายนั้นเป็นการเรียบเรียงแต่ยังขึ้นอยู่กับบริบท โดยนัย และความรู้ที่แบ่งปันด้วย การได้มาซึ่งภาษาเริ่มต้นด้วยการพูดพล่ามและดำเนินไปในระดับหนึ่งคำและสองคำ โดยที่ข้อถกเถียงเรื่องการเลี้ยงดูธรรมชาติยังคงไม่ได้รับการแก้ไข ภาษาทั่วโลกประมาณ 7,000 ภาษาเป็นของครอบครัว (อินโด-ยูโรเปียน ชิโน-ทิเบต ไนเจอร์-คองโก) ซึ่งสะท้อนถึงการอพยพของมนุษย์และประวัติศาสตร์ทางวัฒนธรรม สำหรับทุกคนที่ทำงานเกี่ยวกับเทคโนโลยีภาษา การทำความเข้าใจพื้นฐานเหล่านี้ เช่น เสียงที่แมปกับความหมาย วิธีการทำงานของไวยากรณ์ วิธีการตีความรูปร่างบริบท ถือเป็นพื้นฐานสำคัญที่แบบจำลองทางสถิติล้วนๆ ไม่สามารถแทนที่ได้
