# วรรณกรรม
วรรณกรรมคือบันทึกความคิด อารมณ์ และประสบการณ์ที่ยาวนานที่สุดของมนุษยชาติ ตั้งแต่มหากาพย์ปากเปล่าของอารยธรรมโบราณไปจนถึงนวนิยายยุคดิจิทัลในปัจจุบัน ทุกงานล้วนอยู่ในการสนทนากับสิ่งที่เกิดขึ้นก่อนหน้านี้ การทำความเข้าใจประเภทวรรณกรรม การเคลื่อนไหว และเทคนิคช่วยให้คุณมีมุมมองที่สมบูรณ์ยิ่งขึ้นในการอ่าน — และเพื่อทำความเข้าใจวัฒนธรรมที่สร้างผลงานเหล่านี้
---

## ประเภทและรูปแบบวรรณกรรม
### ประเภทนิยาย
| ประเภท | ลักษณะสำคัญ | ตัวอย่างที่โดดเด่น |
|-------|-----------|-----------------|
| **นิยายวรรณกรรม** | ขับเคลื่อนด้วยตัวละคร, ความลึกของธีม, งานฝีมือโวหาร | *เพื่อฆ่ากระเต็น* (ฮาร์เปอร์ ลี) |
| **นิยายวิทยาศาสตร์** | เทคโนโลยีเก็งกำไร อวกาศ เวลา โลกคู่ขนาน | *ดูน* (เฮอร์เบิร์ต), *1984* (ออร์เวลล์) |
| **แฟนตาซี** | โลกมหัศจรรย์ สัตว์ในตำนาน | *เดอะลอร์ดออฟเดอะริงส์* (โทลคีน), *แฮร์รี่ พอตเตอร์* (โรว์ลิ่ง) |
| **เรื่องลึกลับ/นักสืบ** | ไขปริศนาอาชญากรรมการสืบสวน | เชอร์ล็อค โฮล์มส์ (ดอยล์), ปัวโรต์ (คริสตี้) |
| **สยองขวัญ** | ความกลัว ความสงสัย สิ่งเหนือธรรมชาติ | *The Shining* (ราชา), *Dracula* (สโตเกอร์) |
| **โรแมนติก** | ความสัมพันธ์โรแมนติก การเดินทางทางอารมณ์ | *ความภาคภูมิใจและอคติ* (ออสเตน) |
| **นิยายอิงประวัติศาสตร์** | เจาะจงประวัติศาสตร์ รายละเอียดแม่น | *The Book Thief* (ซูซัค), *Wolf Hall* (หิ้ง) |
| **ความสมจริงที่มีมนต์ขลัง** | องค์ประกอบที่มีมนต์ขลังถือเป็นเรื่องธรรมดาในสภาพแวดล้อมที่สมจริง | *หนึ่งร้อยปีแห่งความโดดเดี่ยว* (การ์เซีย มาร์เกซ) |
| **ดิสโทเปีย** | สังคมกดขี่ เตือนแนวโน้มอนาคต | *โลกใหม่ที่กล้าหาญ* (ฮักซ์ลีย์), *เรื่องราวของสาวใช้* (แอทวูด) |
| **เสียดสี** | อารมณ์ขันและการประชดที่ใช้วิจารณ์สังคม | *การเดินทางของกัลลิเวอร์* (สวิฟท์), *Catch-22* (เฮลเลอร์) |
### แบบฟอร์มสารคดี
| แบบฟอร์ม | คำอธิบาย | ตัวอย่างที่โดดเด่น |
|------|-----------------|-----------------|
| **ชีวประวัติ / อัตชีวประวัติ** | เรื่องราวชีวิตของคนจริงๆ | *ไดอารี่ของเด็กสาว* (แอนน์ แฟรงก์), *การเป็น* (มิเชล โอบามา) |
| **ความทรงจำ** | บัญชีส่วนตัวที่เน้นประสบการณ์หรือธีมเฉพาะ | *มีการศึกษา* (Tara Westover) |
| **เรียงความ** | ร้อยแก้วสั้นในเรื่องใดเรื่องหนึ่ง | เจมส์ บอลด์วิน, โจน ดิเดียน, จอร์จ ออร์เวลล์ |
| **วารสารศาสตร์** | การรายงานข่าว บทความเชิงสืบสวน บทความสารคดี | *คนของประธานาธิบดีทุกคน* (วู้ดเวิร์ดและเบิร์นสไตน์) |
| **การช่วยตัวเอง** | การพัฒนาตนเองและการปรับปรุงเชิงปฏิบัติ | *การคิด เร็วและช้า* (คาห์เนมาน) |
| **บทความเชิงปรัชญา** | การสำรวจคำถามเชิงปรัชญาอย่างเป็นระบบ | *การทำสมาธิ* (มาร์คัส ออเรลิอุส) |
| **การเขียนเชิงท่องเที่ยว** | เรื่องราวสถานที่ วัฒนธรรม และการเดินทาง | *ในปาตาโกเนีย* (ฉัตวิน) |
### แบบฟอร์มบทกวี
| แบบฟอร์ม | โครงสร้าง | ตัวอย่าง |
|------|-----------|---------|
| **โคลง** | 14 บรรทัด รูปแบบสัมผัสเฉพาะ | เช็คสเปียร์ (ABAB CDCD EFEF GG), เพตราชาน (ABBAABBA CDECDE) |
| **ไฮกุ** | รูปแบบพยางค์ 5-7-5 | ประเพณีญี่ปุ่นเน้นธรรมชาติ |
| **ลิเมอริก** | ห้าบรรทัด สัมผัส AABBA ตลกขบขัน | กลอนเบา |
| **กลอนฟรี** | ไม่มีมิเตอร์หรือสัมผัสปกติ | วอลท์ วิทแมน, ที.เอส. เอเลียต |
| **วิลลาเนล** | 19 บรรทัดพร้อมละเว้นการทำซ้ำ | "อย่าไปอ่อนโยน" (ดีแลนโธมัส) |
| **มหากาพย์** | เรื่องเล่ายาวๆ เกี่ยวกับวีรกรรม | *โอดิสซี* (โฮเมอร์), *เบวูล์ฟ* |
| **บทกวี** | บทกวีโคลงสั้น ๆ กล่าวถึงหัวเรื่อง | "บทกวีบนโกศกรีก" ของ KEATS
| **สง่างาม** | บทกวีไว้อาลัยให้กับผู้ตาย | “โอ้กัปตัน! กัปตันของฉัน!” (วิทแมน) |
| **กลอนเปล่า** | Pentameter iambic ที่ไม่มีเสียง | บทละครของเช็คสเปียร์ *Paradise Lost* ของมิลตัน

## ขบวนการวรรณกรรมที่สำคัญ
วรรณกรรมมีวิวัฒนาการผ่านยุคสมัยที่แตกต่างกัน โดยแต่ละยุคสมัยมีปฏิกิริยาต่อต้านยุคสมัยก่อน:
| ระยะเวลา | ยุค | แนวคิดหลัก | บุคคลสำคัญ |
|----------------------|-----|-----------|---------------|
| **คลาสสิก** | ค. 8 ก่อนคริสตศักราช – ศตวรรษที่ 5 ซีอี | เหตุผล ระเบียบ มนุษยนิยม | โฮเมอร์, โซโฟคลีส, เวอร์จิล |
| **ยุคกลาง** | ศตวรรษที่ 5-15 | ธีมทางศาสนา อัศวิน ชาดก | ดันเต้, ชอเซอร์ |
| **ยุคฟื้นฟูศิลปวิทยา** | คริสต์ศตวรรษที่ 14-17 | มนุษยนิยม การฟื้นฟูการเรียนรู้แบบคลาสสิก | เช็คสเปียร์, เซอร์บันเตส |
| **การตรัสรู้** | คริสต์ศตวรรษที่ 17-18 | เหตุผล วิทยาศาสตร์ สิทธิส่วนบุคคล | วอลแตร์, สวิฟท์ |
| **ความโรแมนติก** | ปลายวันที่ 18 – กลางเดือน 19 ค. | อารมณ์ ธรรมชาติ ปัจเจกนิยม | เวิร์ดสเวิร์ธ, เกอเธ่, แมรี เชลลีย์ |
| **ความสมจริง** | กลางคริสต์ศตวรรษที่ 19 | บรรยายภาพชีวิตประจำวันได้อย่างแม่นยำ | ตอลสตอย, จอร์จ เอเลียต, มาร์ก ทเวน |
| **ธรรมชาตินิยม** | ช่วงปลายศตวรรษที่ 19 ค. | ความมุ่งมั่น การสังเกตทางวิทยาศาสตร์ | เอมิล โซล่า, สตีเฟน เครน |
| **สมัยใหม่** | ปลายวันที่ 19 – กลางศตวรรษที่ 20 ค. | รูปแบบการทดลอง กระแสแห่งจิตสำนึก | จอยซ์, เวอร์จิเนีย วูล์ฟ, ที.เอส. เอเลียต |
| **ฮาร์เล็มเรอเนซองส์** | คริสต์ทศวรรษ 1920 – 1930 | วัฒนธรรมแอฟริกันอเมริกันออกดอก | แลงสตัน ฮิวจ์ส, โซรา นีล เฮิร์สตัน |
| **ลัทธิหลังสมัยใหม่** | กลางคริสต์ศตวรรษที่ 20 – ปัจจุบัน | การกระจายตัว, อภิปรัชญา, ประชด | พินชอน, ดอน เดอลิลโล |
| **หลังอาณานิคม** | กลางคริสต์ศตวรรษที่ 20 – ปัจจุบัน | อัตลักษณ์ การแทนที่ การผสมผสานทางวัฒนธรรม | ชินัว อเชเบ, ซัลมาน รัชดี |
การเคลื่อนไหวแต่ละครั้งส่วนหนึ่งเป็นการกบฏ ยวนใจปฏิเสธเหตุผลนิยมตรัสรู้; ลัทธิสมัยใหม่แตกสลายจากอนุสัญญาวิคตอเรียน ลัทธิหลังสมัยใหม่ตั้งคำถามถึงแนวคิดเรื่องเรื่องเล่าที่ยิ่งใหญ่

## อุปกรณ์วรรณกรรม
การเขียนที่ยอดเยี่ยมใช้ชุดเครื่องมือของเทคนิค:
| อุปกรณ์ | มันทำอะไร | ตัวอย่าง |
|--------|-------------|---------|
| **อุปมา** | การเปรียบเทียบโดยตรง | “เวทีทั้งโลก” (เช็คสเปียร์) |
| **คำอุปมา** | การเปรียบเทียบโดยใช้ "like" หรือ "as" | "ความรักของฉันเหมือนกุหลาบแดง" (เบิร์นส์) |
| **ตัวตน** | คุณสมบัติของมนุษย์ที่มอบให้กับสิ่งที่ไม่ใช่มนุษย์ | “ลมกระซิบผ่านต้นไม้” |
| **ประชด** | ความแตกต่างระหว่างความคาดหวังและความเป็นจริง | สถานการณ์ ดราม่า และวาจาประชด |
| **สัญลักษณ์** | วัตถุที่แสดงถึงแนวคิดเชิงนามธรรม | ไฟเขียวใน *The Great Gatsby* |
| **ลางสังหรณ์** | คำแนะนำเกี่ยวกับเหตุการณ์ในอนาคต | คำทำนายของแม่มดใน *แมคเบธ* |
| **ผู้บรรยายไม่น่าเชื่อถือ** | ผู้บรรยายที่ถูกลดความน่าเชื่อถือ | *Lolita* (Nabokov), *Fight Club* (Palahniuk) |
| **สายธารแห่งสติ** | ความคิดไหลอย่างต่อเนื่อง | *ยูลิสซิส* (จอยซ์), *นางดัลโลเวย์* (วูล์ฟ) |
| **พาดพิง** | อ้างอิงถึงงานหรือเหตุการณ์อื่น | การอ้างอิงในพระคัมภีร์และตำนาน |
| **เปรียบเทียบ** | เรื่องราวที่มีความหมายทางศีลธรรมหรือการเมืองที่ซ่อนอยู่ | *แอนิมอลฟาร์ม* (ออร์เวลล์) |
| **การตีข่าว** | การวางองค์ประกอบที่ตัดกันเคียงข้างกัน | แสงสว่างเทียบกับความมืด ความเยาว์วัยเทียบกับอายุ |
| **แม่ลาย** | องค์ประกอบที่เกิดซ้ำซึ่งมีนัยสำคัญเฉพาะเรื่อง | ดวงตาของดร.ที.เจ. เอคเคิลเบิร์กใน *Gatsby* |

## ทำไมเรื่องนี้ถึงสำคัญ
วรรณกรรมไม่ใช่แค่ความบันเทิงเท่านั้น แต่ยังเป็นวิธีการประมวลผลของสังคม ท้าทายสมมติฐาน และจินตนาการถึงทางเลือกอื่น นวนิยายสามารถเปลี่ยนความคิดเห็นของประชาชนได้ บทกวีสามารถกำหนดยุคสมัยได้ การทำความเข้าใจประเพณี ประเภท และเทคนิคที่หล่อหลอมการแสดงออกทางวรรณกรรมช่วยให้คุณมีมุมมองที่สมบูรณ์ยิ่งขึ้นสำหรับการอ่าน การเขียน และความเข้าใจโลก
