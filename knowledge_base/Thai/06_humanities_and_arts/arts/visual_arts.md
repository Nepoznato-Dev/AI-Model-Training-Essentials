#ทัศนศิลป์
ทัศนศิลป์เป็นรูปแบบการสื่อสารที่เก่าแก่ที่สุดของมนุษยชาติ ตั้งแต่ภาพวาดในถ้ำ Lascaux ไปจนถึงการติดตั้งระบบดิจิทัลในปัจจุบัน การทำความเข้าใจความเคลื่อนไหวทางศิลปะ สื่อ และสถาบันที่อนุรักษ์ผลงานสร้างสรรค์จะทำให้คุณรู้สึกซาบซึ้งมากขึ้นว่าสังคมได้แสดงออกถึงความงดงาม อำนาจ จิตวิญญาณ และความขัดแย้งตลอดพันปีอย่างไร
---

## ขบวนการทางศิลปะตลอดหลายศตวรรษ
| การเคลื่อนไหว | ระยะเวลา | ลักษณะ | ศิลปินคนสำคัญ |
|---------||--------|-----------------|-------------|
| **ยุคฟื้นฟูศิลปวิทยา** | คริสต์ศตวรรษที่ 14-17 | ความสมจริง มุมมอง กายวิภาคศาสตร์ ธีมคลาสสิก | เลโอนาร์โด, มิเกลันเจโล, ราฟาเอล |
| **มารยาท** | ช่วงปลายศตวรรษที่ 16 ประมาณคริสตศักราช | หุ่นยาว สง่างามดั่งเทียม | เอล เกรโค, ปอนตอร์โม |
| **บาโรก** | ศตวรรษที่ 17 | แสงแห่งละคร ความเข้มข้นทางอารมณ์ ความยิ่งใหญ่ | คาราวัจโจ, แรมแบรนดท์, แบร์นินี |
| **โรโคโค** | ต้นคริสต์ศตวรรษที่ 18 | พาเลทท์ไม้ประดับ ขี้เล่น สีพาสเทล | ฟราโกนาร์ด, วัตโต |
| **นีโอคลาสสิก** | ปลายวันที่ 18 – ต้นศตวรรษที่ 19 ค. | กลับคืนสู่ความคลาสสิกความจริงจังทางศีลธรรม | เดวิด, อิงเกรส |
| **ความโรแมนติก** | ปลายวันที่ 18 – กลางเดือน 19 ค. | อารมณ์ ธรรมชาติ ความประเสริฐ | เทิร์นเนอร์, เดลาครัวซ์, เจริโกลต์ |
| **ความสมจริง** | กลางคริสต์ศตวรรษที่ 19 | การพรรณนาถึงชีวิตประจำวันอย่างไม่สมบูรณ์แบบ | Courbet, ข้าวฟ่าง |
| **อิมเพรสชันนิสม์** | ช่วงปลายศตวรรษที่ 19 ค. | แสง สี ฝีแปรงที่มองเห็นได้ ชีวิตสมัยใหม่ | โมเนต์, เรอนัวร์, เดอกาส์ |
| **โพสต์อิมเพรสชันนิสม์** | ช่วงปลายศตวรรษที่ 19 ค. | สีจัดจ้าน รูปทรงเรขาคณิต ความลึกของอารมณ์ | แวนโก๊ะ, เซซาน, โกแกง |
| **อาร์ตนูโว** | ทศวรรษที่ 1890 – 1910 | เส้นออร์แกนิก ลวดลายตกแต่ง | คลิมท์, มูชา, เกาดี |
| **การแสดงออก** | ต้นศตวรรษที่ 20 ค. | ฟอร์มบิดเบี้ยว อารมณ์รุนแรง | มุงค์, เคิร์ชเนอร์, คันดินสกี้ |
| **ลัทธิเขียนภาพแบบเหลี่ยม** | ต้นศตวรรษที่ 20 ค. | รูปทรงเรขาคณิต หลายมุมมอง | ปิกัสโซ, บราเก |
| **ลัทธิแห่งอนาคต** | คริสต์ทศวรรษ 1910 – 1920 | ความเร็ว เทคโนโลยี ไดนามิก | บอชโชนี่, บัลลา |
| **ดาด้า** | คริสต์ทศวรรษ 1910 – 1920 | ต่อต้านศิลปะ ไร้สาระ เร้าใจ | ดูชองป์, เฮาส์มันน์ |
| **สถิตยศาสตร์** | คริสต์ทศวรรษ 1920 – 1940 | ภาพความฝัน จิตใต้สำนึก อัตโนมัติ | ดาลี, มากริตต์, ฟรีดา คาห์โล |
| **การแสดงออกเชิงนามธรรม** | ทศวรรษที่ 1940 – 1950 | เป็นธรรมชาติ การวาดภาพด้วยท่าทาง ผืนผ้าใบขนาดใหญ่ | พอลล็อค, รอธโก, เดอ คูนนิ่ง |
| **ป๊อปอาร์ต** | ทศวรรษ 1950 – 1960 | ภาพวัฒนธรรมยอดนิยม สุนทรียภาพในการผลิตจำนวนมาก | วอร์ฮอล, ลิกเตนสไตน์ |
| **มินิมอล** | ทศวรรษที่ 1960 – 1970 | ความเรียบง่าย รูปทรงเรขาคณิต วัสดุอุตสาหกรรม | โดนัลด์ จัดด์, แอกเนส มาร์ติน |
| **คอนเซปต์อาร์ต** | ทศวรรษ 1960 – ปัจจุบัน | ไอเดียเหนือสุนทรียภาพ ข้อความ การแสดง | โซล เลวิตต์, โยโกะ โอโนะ |
| **ร่วมสมัย** | ทศวรรษ 1970 – ปัจจุบัน | สื่อหลากหลาย แนวความคิด วิจารณ์สังคม | แบงค์ซี, คูซามะ, อ้าย เว่ยเว่ย |

## สื่อศิลปะ
วัสดุและวิธีการที่ศิลปินใช้กำหนดรูปทรงของงาน:
| ปานกลาง | คำอธิบาย | ตัวอย่างที่โดดเด่น |
|--------|-------------|-----------------|
| **ภาพเขียนสีน้ำมัน** | เม็ดสีในน้ำมัน (ลินสีด, วอลนัท); แห้งช้า ปั่นได้ | แรมแบรนดท์, เวอร์เมียร์ |
| **อะคริลิก** | โพลีเมอร์สังเคราะห์ที่แห้งเร็ว อเนกประสงค์ | เดวิด ฮ็อคนีย์ |
| **สีน้ำ** | เม็ดสีที่แขวนลอยอยู่ในน้ำ โปร่งใส ส่องสว่าง | เจ.เอ็ม.ดับบลิว. เทิร์นเนอร์ |
| **ปูนเปียก** | เม็ดสีบนปูนปลาสเตอร์เปียก ทนทาน อนุสาวรีย์ | Michelangelo (โบสถ์ซิสทีน) |
| **ชาร์โคล/ดินสอ** | สื่อแห้งสำหรับการวาดภาพ ช่วงการแสดงออก | ภาพร่างของเลโอนาร์โด |
| **หมึก** | ของเหลวปานกลาง การประดิษฐ์ตัวอักษรที่แม่นยำ | จิตรกรรมพู่กันเอเชียตะวันออก |
| **ประติมากรรม** | แกะสลัก (หิน ไม้) ปั้นโมเดล (ดินเหนียว) หล่อ (บรอนซ์) | โรแดง, บรันกูซี |
| **การพิมพ์** | การแกะสลัก การพิมพ์หิน การพิมพ์สกรีน การแกะสลักไม้ | ดูเรอร์, โฮคุไซ |
| **การถ่ายภาพ** | พื้นผิวที่ไวต่อแสง ดิจิตอลหรือภาพยนตร์ | แอนเซล อดัมส์, ซินดี้ เชอร์แมน |
| **ศิลปะดิจิทัล** | คอมพิวเตอร์สร้างขึ้นหรือดัดแปลง; รวมถึง 3D, กำเนิด | บีเปิล, เรฟิก อนาดอล |
| **การติดตั้ง** | สภาพแวดล้อมที่สมจริงและเฉพาะเจาะจงไซต์ | คริสโต และจีนน์-โคลด |
| **ศิลปะการแสดง** | ร่างกาย เวลา พื้นที่ เป็นสื่อกลาง | มาริน่า อับราโมวิช |

## หลักการออกแบบ
ศิลปินใช้หลักการเหล่านี้เพื่อจัดองค์ประกอบภาพ:
| หลักการ | คำอธิบาย |
|-----------|-------------|
| **ยอดคงเหลือ** | การกระจายน้ำหนักการมองเห็น (สมมาตร, ไม่สมมาตร, รัศมี) |
| **ความแตกต่าง** | การวางองค์ประกอบต่างๆ เข้าด้วยกันเพื่อสร้างความน่าสนใจทางภาพ |
| **เน้น** | การสร้างจุดโฟกัสที่ดึงดูดสายตาของผู้ชม |
| **การเคลื่อนไหว** | ดึงดูดสายตาของผู้ชมผ่านองค์ประกอบ |
| **รูปแบบ/การซ้ำซ้อน** | การทำซ้ำองค์ประกอบเพื่อสร้างจังหวะและความสามัคคี |
| **สัดส่วน / ขนาด** | ความสัมพันธ์ขนาดระหว่างองค์ประกอบ |
| **ความสามัคคี/ความสามัคคี** | องค์ประกอบทั้งหมดทำงานร่วมกันเป็นอันหนึ่งอันเดียวกัน |

| **ปราโด** | มาดริด | ศิลปะยุโรป เวลาซเกซ, โกยา, เอล เกรโก |
| **อาศรม** | เซนต์ปีเตอร์สเบิร์ก | ผลงานมากกว่า 3 ล้านชิ้นครอบคลุมวัฒนธรรมโลก |
| **หอศิลป์แห่งชาติ** | ลอนดอน | จิตรกรรมยุโรปตะวันตก แวนโก๊ะ,ดาวินชี |

## ทำไมเรื่องนี้ถึงสำคัญ
ทัศนศิลป์ไม่ใช่แค่การตกแต่งเท่านั้น แต่ยังเป็นบันทึกความคิด ความเชื่อ และความทะเยอทะยานของมนุษย์ ภาพวาด ประติมากรรม และการจัดวางทุกชิ้นสะท้อนถึงวัฒนธรรมที่ผลิตผลงานชิ้นนี้ การทำความเข้าใจเกี่ยวกับความเคลื่อนไหวทางศิลปะช่วยให้คุณอ่านภาษาภาพที่ล้อมรอบตัวคุณในการโฆษณา สถาปัตยกรรม ภาพยนตร์ และการออกแบบ พิพิธภัณฑ์และหอศิลป์ไม่ได้เป็นเพียงแหล่งสะสมวัตถุเก่าๆ เท่านั้น แต่ยังเป็นบทสนทนาเกี่ยวกับความหมายของการเป็นมนุษย์อีกด้วย
