#ศิลปะการแสดง
ศิลปะการแสดง เช่น การแสดงละคร ภาพยนตร์ การเต้นรำ และดนตรี เป็นที่ที่ศิลปะมาบรรจบกับการแสดงสดของผู้ชม การแสดงจะเผยออกมาแบบเรียลไทม์ ไม่เหมือนภาพวาดบนผนังหรือหนังสือบนชั้นวาง โดยสร้างประสบการณ์ร่วมกันระหว่างศิลปินและผู้ชมซึ่งเป็นศูนย์กลางของวัฒนธรรมมนุษย์มาเป็นเวลาหลายพันปี
---

## โรงภาพยนตร์
โรงละครเป็นเวทีแห่งการเล่าเรื่องของมนุษยชาติมานานกว่า 2,500 ปี ตั้งแต่อัฒจันทร์ของกรีกโบราณไปจนถึงบรอดเวย์และเวสต์เอนด์ การแสดงสดยังคงเป็นหนึ่งในรูปแบบการแสดงออกทางศิลปะที่ทรงพลังที่สุด
### ฟอร์มดราม่า
| พิมพ์ | คำอธิบาย | ตัวอย่างที่โดดเด่น |
|------|-----------------|-----------------|
| **โศกนาฏกรรม** | ธีมจริงจังความหายนะของตัวเอก | โศกนาฏกรรมของชาวกรีก *แฮมเล็ต* ของเช็คสเปียร์
| **ตลก** | สถานการณ์ฮาๆ ตอนจบแบบ Happy Ending | คอเมดี้ของเช็คสเปียร์, ออสการ์ ไวลด์ |
| **โศกนาฏกรรม** | ผสมผสานองค์ประกอบที่น่าเศร้าและการ์ตูน | *รอโกโดต์* (เบ็คเก็ตต์) |
| **ละครเพลง** | รวมเพลงเต้นรำบทสนทนา | *แฮมิลตัน*, *เลส์ มิเซราเบลอส์* |
| **โอเปร่า** | ผลงานละครร้องเต็มๆ | *La Bohème* (ปุชชินี), *Carmen* (บิเซต์) |
| **เปรี้ยวจี๊ด** | รูปแบบที่ไม่ใช่แบบดั้งเดิม การมีส่วนร่วมของผู้ชม | โรงละครทดลอง |
| **เมโลดราม่า** | ตัวละครเกินจริง โครงเรื่องเร้าใจ | ละครประโลมโลกสมัยศตวรรษที่ 19 |
| **ตลก** | ตลกขำขัน สถานการณ์ไร้สาระ | Feydeau *ปิดเสียง* (Frayn) |
### นักเขียนบทละครคนสำคัญ
| ยุค | นักเขียนบทละคร |
|-----|------------|
| **คลาสสิก** | โซโฟคลีส, ยูริพิดีส, อริสโตเฟน |
| **เอลิซาเบธ / จาโคบีน** | เช็คสเปียร์, มาร์โลว์, จอนสัน |
| **ทันสมัย** | อิบเซ่น, เชคอฟ, สตรนด์เบิร์ก |
| **ศตวรรษที่ 20** | อาเธอร์ มิลเลอร์, เทนเนสซี วิลเลียมส์, ซามูเอล เบ็คเก็ตต์, ออกัสต์ วิลสัน |
| **ร่วมสมัย** | ลิน-มานูเอล มิแรนดา, ซูซาน-ลอรี พาร์คส์, ทอม สต็อปพาร์ด |
### ประเพณีการละครทั่วโลก
| ประเพณี | ต้นกำเนิด | ลักษณะ |
|----------|--------|----------------|
| **โน๊ะ** | ญี่ปุ่น | นักแสดงสวมหน้ากาก การเคลื่อนไหวอย่างมีสไตล์ช้า ธีมทางจิตวิญญาณ |
| **คาบูกิ** | ญี่ปุ่น | เครื่องแต่งกายสุดอลังการ การแต่งหน้าสุดอลังการ เรื่องราวทางประวัติศาสตร์ |
| **บุญระคุ** | ญี่ปุ่น | โรงละครหุ่นกระบอกที่มีคนเชิดหุ่นมองเห็นได้ |
| **ปักกิ่งโอเปร่า** | ประเทศจีน | ร้องเพลง บรรยาย กายกรรม ศิลปะการต่อสู้ |
| **กถากาลี** | อินเดีย | ละครเต้นรำกับการแต่งหน้าและเครื่องแต่งกายที่ประณีต |
| **ละครตลก dell'Arte** | อิตาลี | การแสดงด้นสด ตัวละครในหุ้น นักแสดงสวมหน้ากาก |
| **งิ้วปักกิ่ง** | จีน | การเคลื่อนไหวอย่างมีสไตล์ ท่าทางเชิงสัญลักษณ์ |

## ฟิล์ม
ภาพยนตร์เป็นรูปแบบศิลปะที่อายุน้อยที่สุดในบรรดารูปแบบศิลปะหลักๆ ซึ่งมีอายุไม่ถึงศตวรรษ แต่กลับกลายเป็นรูปแบบที่บริโภคกันอย่างแพร่หลายและมีอิทธิพลทางวัฒนธรรม
### ความเคลื่อนไหวของภาพยนตร์
| การเคลื่อนไหว | ระยะเวลา | ลักษณะ | ภาพยนตร์สำคัญ / ผู้กำกับ |
|----------|--------|----------------|--------------------------------|
| **การแสดงออกทางภาษาเยอรมัน** | ทศวรรษที่ 1920 | ภาพบิดเบี้ยว ธีมทางจิตวิทยา | *นอสเฟอราตู* (มูร์เนา), *มหานคร* (หลาง) |
| **ภาพตัดต่อโซเวียต** | คริสต์ทศวรรษ 1920 – 1930 | ตัดต่อตามความหมายการชนกันของช็อต | *เรือรบ Potemkin* ของไอเซนสไตน์ |
| **ลัทธินีโอเรียลลิสม์ของอิตาลี** | ทศวรรษที่ 1940 – 1950 | เรื่องราวของชนชั้นแรงงาน การถ่ายทำสถานที่ | *โจรจักรยาน* (เดอ สิก้า) |
| **คลื่นลูกใหม่ของฝรั่งเศส** | ทศวรรษ 1950 – 1960 | นวัตกรรมการตัดต่อ ทฤษฎีผู้แต่ง | โกดาร์ด, ทรัฟโฟต์ |
| **ฮอลลีวูดใหม่** | ทศวรรษที่ 1960 – 1980 | ธีมสำหรับผู้ใหญ่ที่ขับเคลื่อนโดยผู้กำกับ | คอปโปลา, สกอร์เซซี, คูบริก |
| **ภาพยนตร์เยอรมันใหม่** | ทศวรรษที่ 1960 – 1970 | การเมือง ขับเคลื่อนโดยผู้เขียน | ฟาสบินเดอร์, เวนเดอร์ส, แฮร์ซ็อก |
| **ด๊อกมี 95** | ทศวรรษ 1990 | กฎเกณฑ์แบบมินิมอล แสงธรรมชาติ | วอน เทรียร์, วินเทอร์เบิร์ก |
| **การเคลื่อนไหวของคลื่นลูกใหม่** | ยุค 2000 – ปัจจุบัน | ความหลากหลายของภาพยนตร์ทั่วโลก | นอลลีวูด คลื่นลูกใหม่เกาหลี |
### แนวคิดภาพยนตร์ที่สำคัญ
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **ฉากในฉาก** | ทุกสิ่งที่อยู่ในเฟรม — ฉาก เครื่องแต่งกาย แสง นักแสดง |
| **การตัดต่อ** | เทคนิคการตัดต่อที่สร้างความหมายผ่านการซ้อนภาพ |
| **การถ่ายภาพยนตร์** | ศิลปะแห่งการทำงานของกล้อง — การจัดเฟรม การเคลื่อนไหว การจัดแสง การเลือกใช้เลนส์ |
| **ทฤษฎีผู้เขียน** | ผู้กำกับที่เป็น “ผู้แต่ง” ภาพยนตร์ที่มีสไตล์ส่วนตัวเป็นที่จดจำ |
| **ประเภท** | หมวดหมู่ภาพยนตร์: ดราม่า, ตลก, สยองขวัญ, ไซไฟ, ตะวันตก, สารคดี ฯลฯ |
| **การออกแบบเสียง** | องค์ประกอบเสียงทั้งหมด: บทสนทนา เพลง เอฟเฟกต์เสียง ความเงียบ |
### อุตสาหกรรมภาพยนตร์รายใหญ่
| อุตสาหกรรม | ประเทศ | โดดเด่นสำหรับ |
|----------|---------|-------------|
| **ฮอลลีวูด** | สหรัฐอเมริกา | หนังดัง ระบบสตูดิโอ เข้าถึงทั่วโลก |
| **บอลลีวูด** | อินเดีย | เรื่องเล่าทางดนตรี ผลผลิตมหาศาล |
| **นอลลีวูด** | ไนจีเรีย | การผลิตที่รวดเร็ว ตรงสู่วิดีโอ |
| **เมืองคานส์ / ยุโรป** | ฝรั่งเศส / ยุโรป | ผู้กำกับภาพยนตร์ เทศกาลภาพยนตร์ |
| **ภาพยนตร์เกาหลี** | เกาหลีใต้ | การผสมผสานแนวความคิดเห็นทางสังคม |
| **อนิเมะ** | ญี่ปุ่น | ภาพยนตร์แอนิเมชันและซีรีส์ |

## เต้นรำ
การเต้นรำเป็นศิลปะแห่งการเคลื่อนไหวของมนุษย์ ซึ่งบ่อยครั้ง (แต่ไม่เสมอไป) จะถูกนำมาประกอบกับดนตรี ครอบคลุมพิธีกรรม ความบันเทิง และศิลปะชั้นสูง:
| แบบฟอร์ม | ต้นกำเนิด | ลักษณะ |
|------|-----------------------|----------------|
| **บัลเล่ต์** | เรเนซองส์ อิตาลี / ฝรั่งเศส | เทคนิคเชิงประมวล งานปวงต์ การเล่าเรื่อง |
| **นาฏศิลป์ร่วมสมัย** | ศตวรรษที่ 20 สหรัฐอเมริกา / ยุโรป | ปฏิเสธความเข้มงวดของบัลเล่ต์ งานพื้น การแสดงด้นสด |
| **แตะ** | สหรัฐอเมริกา (แอฟริกันอเมริกัน + รากไอริช) | จังหวะเท้าเป็นเครื่องเพอร์คัชชัน |
| **ฟลาเมงโก** | สเปน (อันดาลูเซีย) | กีตาร์ ร้องเพลง เพอร์คัชชัน ฝีเท้า ความเข้มข้นของอารมณ์ |
| **ฮิปฮอป / เบรคแดนซ์** | สหรัฐอเมริกา (บรองซ์, 1970) | บีบอย, ป๊อป, ล็อค, แบทเทิล |
| **นาฏศิลป์อินเดียคลาสสิก** | อินเดีย | Bharatanatyam, Kathak, Odissi — การเล่าเรื่องผ่านท่าทาง |
| **ห้องบอลรูม** | ยุโรป | การเต้นรำที่เป็นพันธมิตร: วอลทซ์, แทงโก้, ฟ็อกซ์ทรอต |
| **พื้นบ้าน / ดั้งเดิม** | ทั่วโลก | การเฉลิมฉลองทางวัฒนธรรม พิธีกรรม ชุมชน |
---

## ทำไมเรื่องนี้ถึงสำคัญ
ศิลปะการแสดงเป็นที่ที่วัฒนธรรมมีชีวิตชีวาแบบเรียลไทม์ ละครสอนการเอาใจใส่โดยวางเราไว้เป็นของคนอื่นเป็นเวลาสองชั่วโมง ภาพยนตร์สามารถทำให้เราได้เห็นประวัติศาสตร์หรือพาเราไปสู่โลกแห่งจินตนาการ การเต้นรำเป็นการแสดงออกถึงสิ่งที่คำพูดทำไม่ได้ รูปแบบศิลปะเหล่านี้รวมกันเป็นตัวแทนของเครื่องมือที่ทรงพลังที่สุดของมนุษยชาติในการเชื่อมโยง การไตร่ตรอง และการเปลี่ยนแปลง
