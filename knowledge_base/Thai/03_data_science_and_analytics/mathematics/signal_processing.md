# การประมวลผลสัญญาณ
การประมวลผลสัญญาณเป็นศาสตร์แห่งการวิเคราะห์ ดัดแปลง และสังเคราะห์สัญญาณ ซึ่งเป็นตัวแทนของปริมาณทางกายภาพที่แปรผันตามเวลา พื้นที่ หรือความถี่ เสียง รูปภาพ วิดีโอ ข้อมูลเซ็นเซอร์ คลื่นสมอง ราคาหุ้น ล้วนเป็นสัญญาณ เครื่องมือทางคณิตศาสตร์ในการประมวลผลสัญญาณ (การแปลงฟูเรียร์ ตัวกรอง ทฤษฎีการสุ่มตัวอย่าง) ถือเป็นรากฐานของการเรียนรู้ของเครื่อง การสื่อสาร การสร้างภาพทางการแพทย์ และแทบทุกสาขาที่ทำงานกับข้อมูล
---

| **ดิจิตอล** | ไม่ต่อเนื่องในเวลาและแอมพลิจูดเชิงปริมาณ | ไฟล์ MP3, ภาพ JPEG |

## การแปลงฟูริเยร์
**การแปลงฟูเรียร์** จะสลายสัญญาณให้เป็นความถี่ที่เป็นส่วนประกอบ
### การแปลงฟูเรียร์ต่อเนื่อง
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
ผกผัน: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### คู่การแปลงฟูริเยร์
| โดเมนเวลา x(t) | โดเมนความถี่ X(f) |
|----------------------------------|--------------------------------|
| พัลส์สี่เหลี่ยม | ฟังก์ชั่นบาป |
| ฟังก์ชั่นบาป | พัลส์สี่เหลี่ยม |
| เกาส์เซียน อี^{−at²} | เกาส์เซียน (√(π/a))e^{−π²f²/a} |
| ดิแรกเดลต้า δ(t) | 1 (ทุกความถี่) |
| เลขชี้กำลังเชิงซ้อน e^{j2πf₀t} | δ(ฉ − ฉ₀) |
| โคไซน์ cos(2πf₀t) | ½[δ(f−f₀) + δ(f+f₀)] |
### คุณสมบัติที่สำคัญ
| คุณสมบัติ | โดเมนเวลา | โดเมนความถี่ |
|----------|-----------------|-----------------|
| ความเป็นเชิงเส้น | ขวาน₁(t) + bx₂(t) | aX₁(ฉ) + bX₂(ฉ) |
| กะเวลา | x(t − t₀) | X(f)e^{−j2πft₀} |
| การเปลี่ยนความถี่ | x(t)e^{j2πf₀t} | X(ฉ − f₀) |
| การบิดตัว | x₁(t) ∗ x₂(t) | X₁(ฉ) · X₂(ฉ) |
| การคูณ | x₁(t) · x₂(t) | X₁(ฉ) ∗ X₂(ฉ) |
| ความแตกต่าง | dx/dt | j2πf X(ฉ) |
| ทฤษฎีบทของพาร์เซวาล | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**ทฤษฎีบทการโนโวลูชัน:** การโนโวลูชั่นในเวลา = การคูณความถี่ นี่คือคุณสมบัติที่สำคัญที่สุด — เปลี่ยนการดำเนินการของการบิดที่มีราคาแพงเป็นการคูณที่ถูก
### การแปลงฟูริเยร์แบบไม่ต่อเนื่อง (DFT)
สำหรับลำดับ x[0], x[1], ..., x[N−1]:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}, k = 0, 1, ..., N−1
| คุณสมบัติ | ค่า |
|----------|-------|
| ป้อนข้อมูล | N ตัวอย่างจริงหรือซับซ้อน |
| เอาท์พุท | N ถังความถี่ที่ซับซ้อน |
| ความละเอียดความถี่ | f_s/N (โดยที่ f_s คืออัตราการสุ่มตัวอย่าง) |
| ความถี่ของ Nyquist | f_s/2 (ความถี่สูงสุดที่สามารถแทนค่าได้) |
| ความซับซ้อน | O(N²) การคำนวณโดยตรง |
### การแปลงฟูเรียร์แบบเร็ว (FFT)
**FFT** คำนวณ DFT ใน O(N log N) แทน O(N²)
| ยังไม่มี | การดำเนินงาน O(N²) | O(N log N) การดำเนินการ | เร่งความเร็ว |
|---|------------------|----------------------|---------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10¹² | 20,971,520 | 52,428× |
FFT เป็นหนึ่งในอัลกอริธึมที่สำคัญที่สุดที่เคยคิดค้นขึ้นมา ช่วยให้สามารถประมวลผลเสียงแบบเรียลไทม์ การบีบอัดภาพ (JPEG) การสื่อสารไร้สาย (OFDM) และการวิเคราะห์สเปกตรัม

## การแปลงลาปลาซ
**การแปลงลาปลาซ** ขยายการแปลงฟูริเยร์เพื่อรองรับระบบที่ไม่เสถียรและการวิเคราะห์ชั่วคราว
F(s) = ∫₀^∞ f(t) e^{−st} dt โดยที่ s = σ + jω
### การแปลงลาปลาซทั่วไป
| ฉ(t) | ฉ | ภูมิภาคแห่งการบรรจบกัน |
|-|-------|----------------------|
| δ(t) (แรงกระตุ้น) | 1 | ทั้งหมด |
| คุณ(t) (ขั้นตอน) | 1/วินาที | เรื่อง > 0 |
| อี^{−at}คุณ(t) | 1/(s+ก) | เรื่อง > −a |
| เสื้อⁿu(t) | n!/s^{n+1} | เรื่อง > 0 |
| บาป(ωt)คุณ(t) | ω/(s²+ω²) | เรื่อง > 0 |
| cos(ωt)คุณ(t) | s/(s²+ω²) | เรื่อง > 0 |
### การเชื่อมต่อกับการแปลงฟูเรียร์
เมื่อ σ = 0 (s = jω) การแปลงลาปลาซจะลดลงเป็นการแปลงฟูริเยร์ การแปลงลาปลาซให้ภาพที่สมบูรณ์ยิ่งขึ้นโดยรวมข้อมูลเกี่ยวกับการเติบโต/การเสื่อม (σ)
---

## Z-Transform
**การแปลง Z** เทียบเท่ากับการแปลงเวลาแบบไม่ต่อเนื่องของการแปลงลาปลาซ
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### การแปลง Z ทั่วไป
| x[n] | X(z) | ร็อค |
|------|-|-----|
| δ[n] | 1 | ทั้งหมด z |
| คุณ[n] (ขั้นตอน) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|ก\| |
| naⁿu[n] | az/(z−a)² | \|z\| > \|ก\| |
| บาป(ω₀n)u[n] | z บาป(ω₀)/(z²−2z cos(ω₀)+1) | \|z\| > 1 |
### ความสัมพันธ์กับการเปลี่ยนแปลงอื่น ๆ
| แปลงร่าง | โดเมน | ตัวแปร |
|----------|--------|----------|
| ฟูริเยร์ | ความถี่ต่อเนื่อง | ฉ หรือ ω |
| ลาปลาซ | ความถี่เชิงซ้อน | s = σ + jω |
| Z-แปลง | ความถี่เชิงซ้อน (แยก) | z = อี^{sT} |
วงกลมหน่วยในระนาบ z (|z| = 1) สอดคล้องกับการแปลงฟูริเยร์

## ตัวกรอง
กรองผ่านหรือปิดกั้นส่วนประกอบความถี่บางอย่างแบบเลือกสรร
### ประเภทตัวกรอง
| พิมพ์ | ผ่าน | บล็อก | ใบสมัคร |
|------|--------|--------|-------------|
| **ผ่านต่ำ** | ความถี่ต่ำ | ความถี่สูง | ปรับให้เรียบ ป้องกันนามแฝง |
| **ผ่านสูง** | ความถี่สูง | ความถี่ต่ำ | การตรวจจับขอบ, การกำจัดสัญญาณรบกวน |
| **แบนด์พาส** | ช่วงความถี่ | นอกช่วง | การเลือกช่อง (วิทยุ) |
| **แบนด์สต็อป (รอยบาก)** | ทุกอย่างยกเว้นช่วง | ช่วงเฉพาะ | การกำจัดฮัมสายไฟ |
### FIR กับตัวกรอง IIR
| คุณสมบัติ | FIR (การตอบสนองแรงกระตุ้นจำกัด) | IIR (การตอบสนองแรงกระตุ้นไม่มีที่สิ้นสุด) |
|----------|-----------------------------------|--------------------------------|
| การตอบสนองแบบแรงกระตุ้น | ระยะเวลาจำกัด | ระยะเวลาไม่สิ้นสุด |
| ความมั่นคง | มั่นคงเสมอ | อาจไม่เสถียร |
| เฟส | สามารถเป็นเส้นตรง | โดยทั่วไปเฟสไม่เชิงเส้น |
| คำติชม | ไม่ | ใช่ |
| การคำนวณ | ต้องการสัมประสิทธิ์เพิ่มเติม | ค่าสัมประสิทธิ์น้อยลงสำหรับการโรลออฟเดียวกัน |
| การออกแบบ | Windowing, Parks-McClellan | Butterworth, Chebyshev, รูปไข่ |
| ฟังก์ชั่นถ่ายโอน | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### ข้อมูลจำเพาะการออกแบบตัวกรอง
| พารามิเตอร์ | คำอธิบาย |
|-----------|-------------|
| **หนังสือเดินทาง** | ช่วงความถี่ที่ควรผ่านโดยสูญเสียน้อยที่สุด |
| **แถบหยุด** | ช่วงความถี่ที่ควรลดทอน |
| **ความถี่ตัด** | ขอบเขตระหว่าง passband และ stopband |
| **ระลอกคลื่น** | ความแปรผันของพาสแบนด์ (หรือสต็อปแบนด์) ได้รับ |
| **เปิดตัว** | อัตราการลดทอน (dB ต่ออ็อกเทฟหรือทศวรรษ) |
| **วงทรานซิชั่น** | ขอบเขตระหว่าง passband และ stopband |
### การออกแบบตัวกรองทั่วไป
| การออกแบบ | ลักษณะ | ใช้กรณี |
|--------|----------------|----------|
| **บัตเตอร์เวิร์ธ** | แบนด์พาสแบนด์สูงสุด, โรลออฟปานกลาง | วัตถุประสงค์ทั่วไป |
| **เชบีเชฟ ประเภท 1** | ระลอกคลื่นใน passband การม้วนออกที่ชันมากขึ้น | เมื่อการโรลออฟมีความสำคัญ |
| **เชบีเชฟ ประเภท II** | ระลอกคลื่นในแถบหยุด, แบนด์พาสแบนด์ | เมื่อความเรียบของรหัสผ่านมีความสำคัญ |
| **รูปไข่ (คอเออร์)** | ระลอกคลื่นทั้งคู่ ม้วนออกที่ชันที่สุด | ต้องการสั่งซื้อขั้นต่ำ |
| **เบสเซล** | เฟสเชิงเส้น (การหน่วงเวลากลุ่มแบนสูงสุด) | การรักษารูปร่างรูปคลื่น |

## ทฤษฎีการสุ่มตัวอย่าง
### ทฤษฎีบทสุ่มตัวอย่าง Nyquist-Shannon
สัญญาณต่อเนื่องสามารถสร้างขึ้นใหม่ได้อย่างสมบูรณ์แบบจากตัวอย่าง หากอัตราการสุ่มตัวอย่างเกินสองเท่าของความถี่สูงสุด:
f_s > 2f_max
| ระยะเวลา | คำจำกัดความ |
|-|------------|
| **อัตราการสุ่มตัวอย่าง** (f_s) | จำนวนตัวอย่างต่อวินาที |
| **อัตรา Nquist** | 2f_max (อัตราการสุ่มตัวอย่างขั้นต่ำ) |
| **ความถี่ของ Nyquist** | f_s/2 (ความถี่สูงสุดที่สามารถแทนค่าได้) |
| **นามแฝง** | ความถี่สูงปลอมแปลงเป็นความถี่ต่ำเมื่อ f_s < 2f_max |
### อัตราการสุ่มตัวอย่างทั่วไป
| ใบสมัคร | อัตรา | ความถี่ Nyquist |
|-----------------|-|-------------------|
| คำพูดทางโทรศัพท์ | 8 กิโลเฮิร์ตซ์ | 4 กิโลเฮิร์ตซ์ |
| ซีดีเพลง | 44.1 กิโลเฮิร์ตซ์ | 22.05 กิโลเฮิร์ตซ์ |
| เสียงระดับมืออาชีพ | 48 กิโลเฮิร์ตซ์ | 24 กิโลเฮิร์ตซ์ |
| เสียงความละเอียดสูง | 96 กิโลเฮิร์ตซ์ | 48 กิโลเฮิร์ตซ์ |
| วิดีโอ (30 เฟรมต่อวินาที) | 30 Hz (ชั่วคราว) | 15 เฮิรตซ์ |
### ต่อต้านนามแฝง
ก่อนการสุ่มตัวอย่าง **ตัวกรองการป้องกันนามแฝง** (ความถี่ต่ำ) จะลบความถี่ที่สูงกว่า f_s/2 เพื่อป้องกันนามแฝง

## หน้าต่าง
เมื่อวิเคราะห์ส่วนที่จำกัดของสัญญาณ เราจะคูณด้วยหน้าต่างสี่เหลี่ยมโดยปริยาย ทำให้เกิดการรั่วไหลของสเปกตรัม **ฟังก์ชั่นหน้าต่าง** ลดการรั่วซึมนี้
### Windows ทั่วไป
| หน้าต่าง | ความกว้างของกลีบหลัก | ระดับกลีบข้าง | ใช้กรณี |
|----------------------|----------------|-----------------|----------|
| สี่เหลี่ยม | แคบที่สุด | −13 เดซิเบล | เมื่อความละเอียดมีความสำคัญที่สุด |
| ฮันน์ | 2× สี่เหลี่ยม | −31 เดซิเบล | วัตถุประสงค์ทั่วไป |
| แฮมมิง | 2× สี่เหลี่ยม | −41 เดซิเบล | ลดกลีบข้างที่ใกล้ที่สุด |
| แบล็คแมน | 3× สี่เหลี่ยม | −58 เดซิเบล | ช่วงไดนามิกสูง |
| ไกเซอร์ | ปรับได้ | ปรับได้ (ผ่าน β) | เมื่อปรับลดได้ |
### สเปกตรัมรั่วไหล
การคูณสัญญาณด้วยหน้าต่างจะรวมสเปกตรัมเข้ากับสเปกตรัมของหน้าต่าง กลีบหลักที่กว้างขึ้นจะช่วยลดความละเอียดของความถี่ กลีบด้านล่างช่วยลดการรั่วซึม

## เวฟเล็ต
**เวฟเล็ต** คือฟังก์ชันคล้ายคลื่นขนาดเล็กที่มีการแปลเป็นภาษาท้องถิ่น ซึ่งใช้สำหรับการวิเคราะห์สัญญาณแบบหลายความละเอียด
### การแปลงเวฟเล็ต
ต่างจากการแปลงฟูริเยร์ (ซึ่งให้ข้อมูลความถี่ทั่วโลก) การแปลงเวฟเล็ตให้การแปล **ความถี่เวลา**
| แปลงร่าง | ความละเอียดของเวลา | ความละเอียดความถี่ |
|----------|----------------|---------------------|
| ฟูริเยร์ | ไม่มี (ทั่วโลก) | ดีเยี่ยม |
| ระยะสั้น FT | แก้ไขแล้ว (ขนาดหน้าต่าง) | แก้ไข |
| เวฟเล็ต | ตัวแปร (ดีที่ความถี่สูง) | ตัวแปร (ดีที่ความถี่ต่ำ) |
### ครอบครัวเวฟเล็ตทั่วไป
| ครอบครัว | คุณสมบัติ | ใบสมัคร |
|----------------------|-----------|-------------|
| **ฮา** | ง่ายที่สุด ไม่ต่อเนื่อง | การตรวจจับขอบ การวิเคราะห์อย่างรวดเร็ว |
| **ดอเบชีส์** (dbN) | การสนับสนุนที่กะทัดรัด N ช่วงเวลาที่หายไป | การบีบอัด, การปฏิเสธ |
| **สัญลักษณ์** | Daubechies ที่เกือบจะสมมาตร | ลดการบิดเบือนเฟส |
| **คอยล์เล็ต** | ออกแบบมาเพื่อสภาวะปัจจุบัน | การประมวลผลสัญญาณ |
| **มอร์เล็ต** | ไซนัสอยด์แบบหน้าต่างเกาส์เซียน | การวิเคราะห์ความถี่เวลา |
| **หมวกเม็กซิกัน** | อนุพันธ์อันดับสองของ Gaussian | การตรวจจับคุณสมบัติ |
### การประยุกต์ใช้เวฟเล็ต
| ใบสมัคร | Wavelets ช่วยได้อย่างไร |
|-----------------|-------------------|
| การบีบอัดภาพ (JPEG 2000) | การแสดงหลายความละเอียด ดีกว่า DCT สำหรับขอบ |
| การปฏิเสธ | ค่าสัมประสิทธิ์เวฟเล็ตเล็กตามเกณฑ์ (สัญญาณอยู่ในค่าสัมประสิทธิ์ขนาดใหญ่) |
| การตรวจจับคุณสมบัติ | การตรวจจับขอบ การตรวจจับชั่วคราวในอนุกรมเวลา |
| การวิเคราะห์คลื่นไฟฟ้าหัวใจ | การตรวจจับคอมเพล็กซ์ QRS การจำแนกภาวะหัวใจเต้นผิดจังหวะ |
| การวิเคราะห์แผ่นดินไหว | การระบุชั้นทางธรณีวิทยา การประมวลผลสัญญาณแผ่นดินไหว |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดการประมวลผลสัญญาณ | ใบสมัคร |
|--------------------------|-------------|
| การแปลงฟูเรียร์ | คุณสมบัติสเปกตรัมสำหรับ ML เสียง การวิเคราะห์โดเมนความถี่ของอนุกรมเวลา |
| FFT | การบิดอย่างรวดเร็วใน CNN (การบิดสเปกตรัม) ความสัมพันธ์ที่มีประสิทธิภาพ
| ทฤษฎีบทการบิด | ทำความเข้าใจวิธีการทำงานของ CNN (เป็นตัวกรองที่เรียนรู้) |
| ตัวกรอง | การประมวลผลล่วงหน้า (การปรับให้เรียบ ลดสัญญาณรบกวน) การแยกคุณลักษณะ |
| ทฤษฎีบทการสุ่มตัวอย่าง | ทำความเข้าใจการแยกส่วน การเลือกอัตราเซ็นเซอร์ การหลีกเลี่ยงการใช้นามแฝง |
| หน้าต่าง | STFT สำหรับเสียง ML (สเปกโตรแกรม) การวิเคราะห์ความถี่เวลา |
| เวฟเล็ต | การแยกคุณลักษณะสำหรับอนุกรมเวลา การบีบอัด การดีนอยซ์ |
| Laplace/Z-transform | ทฤษฎีการควบคุมสำหรับหุ่นยนต์ ทำความเข้าใจเสถียรภาพของระบบ |
| การวิเคราะห์สเปกตรัม | การวิเคราะห์ EEG/fMRI, การตรวจสอบการสั่นสะเทือน, การบำรุงรักษาเชิงคาดการณ์ |
| อัตรา Nyquist | การเลือกอัตราการรวบรวมข้อมูลที่เหมาะสมสำหรับไปป์ไลน์ ML |

## สรุป
| เครื่องมือ | โดเมน | ข้อมูลเชิงลึกที่สำคัญ |
|------|--------|-------------|
| การแปลงฟูริเยร์ | เวลา → ความถี่ | สัญญาณเป็นผลรวมของไซนัสอยด์ |
| การแปลงลาปลาซ | เวลา → ความถี่เชิงซ้อน | จัดการชั่วคราวและเสถียรภาพ |
| Z-แปลง | เวลาไม่ต่อเนื่อง → ซับซ้อน | การวิเคราะห์และออกแบบตัวกรองดิจิทัล |
| FFT | การคำนวณ DFT ที่มีประสิทธิภาพ | O(N log N) แทน O(N²) |
| ตัวกรอง | การเลือกความถี่ | ผ่านสิ่งที่คุณต้องการ บล็อกสิ่งที่คุณไม่ต้องการ |
| ทฤษฎีบทการสุ่มตัวอย่าง | ต่อเนื่อง ↔ ไม่ต่อเนื่อง | ตัวอย่างเร็วพอ ไม่เสียอะไรเลย |
| หน้าต่าง | การแลกเปลี่ยนความถี่เวลา | ความละเอียดสมดุลและการรั่วไหล |
| เวฟเล็ต | การวิเคราะห์แบบหลายความละเอียด | ท้องถิ่นทั้งเวลาและความถี่ |
การประมวลผลสัญญาณเป็นรากฐานทางคณิตศาสตร์สำหรับการทำความเข้าใจ การวิเคราะห์ และการจัดการข้อมูล ไปป์ไลน์แมชชีนเลิร์นนิงทุกอันที่ทำงานกับอนุกรมเวลา เสียง รูปภาพ หรือข้อมูลเซ็นเซอร์จะใช้แนวคิดการประมวลผลสัญญาณโดยปริยาย โดยเฉพาะอย่างยิ่งการแปลงฟูริเยร์ถือเป็นเครื่องมือทางคณิตศาสตร์ที่สำคัญที่สุดรองจากแคลคูลัสสำหรับนักวิทยาศาสตร์ด้านข้อมูล
