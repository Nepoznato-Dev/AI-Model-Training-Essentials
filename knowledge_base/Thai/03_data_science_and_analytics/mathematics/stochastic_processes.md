# กระบวนการสุ่ม
**กระบวนการสุ่ม** คือชุดของตัวแปรสุ่มที่จัดทำดัชนีตามเวลา (หรือปริภูมิ) ในขณะที่ทฤษฎีความน่าจะเป็นจะศึกษาเหตุการณ์สุ่มแต่ละเหตุการณ์ กระบวนการสุ่มจะศึกษาว่าการสุ่มพัฒนาไปตามเวลาอย่างไร พวกเขาจำลองราคาหุ้น ความยาวคิว การแพร่กระจายของโรค การสร้างภาษา และไดนามิกการฝึกอบรมของโมเดลการเรียนรู้ของเครื่อง
---

## รากฐาน
### คำนิยาม
กระบวนการสุ่ม {X_t : t ∈ T} คือกลุ่มของตัวแปรสุ่มที่กำหนดบนปริภูมิความน่าจะเป็นทั่วไป T คือ **ชุดดัชนี** (เวลา):
- **เวลาไม่ต่อเนื่อง:** T = {0, 1, 2, ...}
- **เวลาต่อเนื่อง:** T = [0, ∞)
**พื้นที่สถานะ** S คือเซตของค่าที่เป็นไปได้ที่ X_t สามารถรับได้
### คุณสมบัติที่สำคัญ
| คุณสมบัติ | คำจำกัดความ |
|----------|------------|
| **ความคงที่** | การแจกแจงร่วมของ (X_{t₁}, ..., X_{tₖ}) เช่นเดียวกับ (X_{t₁+τ}, ..., X_{tₖ+τ}) |
| **ความเป็นอิสระ** | X_t เป็นอิสระจาก X_s สำหรับ t ≠ s |
| **การยศาสตร์** | เวลาเฉลี่ยมาบรรจบกันเป็นค่าเฉลี่ยทั้งมวล |
| **ทรัพย์สินมาร์คอฟ** | อนาคตขึ้นอยู่กับปัจจุบันเท่านั้น ไม่ใช่อดีต |
| **มาร์ติงเกล** | มูลค่าในอนาคตที่คาดหวังเท่ากับมูลค่าปัจจุบัน |
---

## มาร์คอฟเชนส์
**ลูกโซ่มาร์คอฟ** เป็นกระบวนการสุ่มที่สถานะในอนาคตขึ้นอยู่กับสถานะปัจจุบันเท่านั้น (คุณสมบัติที่ไม่มีหน่วยความจำ)
### โซ่มาร์คอฟแบบไม่ต่อเนื่องเวลา (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**เมทริกซ์การเปลี่ยนแปลง** P มีรายการ p_{ij} = P(go to j | ขณะนี้อยู่ที่ i)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ผลรวมแถว | แต่ละแถวจะรวมกันเป็น 1: Σⱼ p_{ij} = 1 |
| การเปลี่ยนแปลง n ขั้นตอน | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| จำหน่ายเครื่องเขียน | πP = π (เวกเตอร์ลักษณะเฉพาะด้านซ้ายที่มีค่าลักษณะเฉพาะ 1) |
### การจำแนกประเภทของรัฐ
| ระยะเวลา | คำจำกัดความ |
|-|------------|
| **เกิดซ้ำ** | เชนกลับสู่สถานะ i ด้วยความน่าจะเป็น 1 |
| **ชั่วคราว** | ความน่าจะเป็นที่ไม่เป็นศูนย์ที่จะไม่มีวันส่งกลับ |
| **ดูดซับ** | p_{ii} = 1 (เข้ามาแล้วไม่เคยออก) |
| **ระยะเวลา** | GCD ของเวลาส่งคืน; งวด 1 = เป็นระยะ |
| **การสื่อสาร** | สถานะ i และ j สามารถติดต่อกันได้ |
### จำหน่ายเครื่องเขียน
สำหรับลูกโซ่มาร์กอฟที่เกิดซ้ำเชิงบวกแบบลดไม่ได้ การแจกแจงแบบคงที่ π มีอยู่ มีลักษณะเฉพาะ และเป็นไปตาม:
πP = π, Σᵢ πᵢ = 1
**การตีความ:** πᵢ = สัดส่วนระยะยาวของเวลาที่ใช้ในสถานะ i
**ตัวอย่างการทำงาน:** แบบจำลองสภาพอากาศที่มีสถานะ {แดดจัด ฝนตก}
P = [[0.9, 0.1], [0.5, 0.5]] (แถว: จาก Sunny จาก Rainy)
การกระจายตัวแบบคงที่: πP = π
- π₁ = 0.9π₁ + 0.5π₂
- π₂ = 0.1π₁ + 0.5π₂
- π₁ + π₂ = 1
- การแก้โจทย์: π₁ = 5/6 data 0.833, π₂ = 1/6 data 0.167
### การบรรจบกันสู่ความนิ่ง
สำหรับลูกโซ่ที่เกิดซ้ำเชิงบวกแบบลดไม่ได้:
- Pⁿ → Π (เมทริกซ์ที่มีแถวทั้งหมดเท่ากับ π) เป็น n → ∞
- **เวลาในการผสม:** จำนวนขั้นตอนจนกระทั่งการกระจายเข้าใกล้ π
- **ช่องว่างสเปกตรัม:** 1 − |แล₂| (โดยที่ แล₂ คือค่าลักษณะเฉพาะที่ใหญ่เป็นอันดับสอง) เป็นตัวกำหนดความเร็วในการผสม
### โซ่มาร์คอฟแบบต่อเนื่องเวลา (CTMC)
การเปลี่ยนผ่านเกิดขึ้นในเวลาสุ่มซึ่งควบคุมโดยการแจกแจงแบบเอ็กซ์โปเนนเชียล
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **เมทริกซ์อัตรา Q** | q_{ij} ≥ 0 สำหรับฉัน ≠ j; q_{ii} = −Σ_{j≠i} q_{ij} |
| **ความน่าจะเป็นในการเปลี่ยนแปลง** | P(t) = e^{Qt} (เมทริกซ์เอ็กซ์โปเนนเชียล) |
| **จำหน่ายเครื่องเขียน** | πคิว = 0 |
| **ระยะเวลาในการถือครอง** | เวลาในสถานะ i คือ Exp(−q_{ii}) |

## เดินสุ่ม
**การเดินสุ่ม** คือเส้นทางที่เกิดจากก้าวสุ่มที่ต่อเนื่องกัน
### เดินสุ่มง่ายๆ
X_n = X_{n-1} + Z_n โดยที่ Z_n ∈ {+1, −1} ด้วยความน่าจะเป็น p, q = 1−p
| คุณสมบัติ | p = 1/2 (สมมาตร) | p ≠ 1/2 (เอนเอียง) |
|----------|---------------------|-------------------|
| อี[X_n] | 0 | n(2p−1) |
| วาร์[X_n] | n | 4npq |
| กลับคืนสู่จุดกำเนิด? | ใช่ (มีความน่าจะเป็น 1) | ไม่ (ลอยออกไป) |
| กำเริบ? | ใช่ (ใน 1D และ 2D) | ไม่ |
### สุ่มเดินในมิติที่สูงขึ้น
| มิติข้อมูล | กำเริบ? | สัญชาตญาณ |
|----------|------------|-----------|
| 1D | ใช่ | "คนเมามักจะหาทางกลับบ้านเสมอ" |
| 2D | ใช่ | "นกขี้เมามักจะหาทางกลับบ้านเสมอ" |
| 3D+ | ไม่ | "นกกระจอกเมาไม่เคยหาทางกลับบ้าน" |
### การเชื่อมต่อกับ Brownian Motion
ปรับขนาดการเดินแบบสุ่ม: ให้ S_n = ΣZ_i จากนั้นเป็นขนาดขั้นตอน → 0 และขั้นตอน → ∞:
S_{⌊nt⌋} / √n → B(t) (การเคลื่อนที่แบบบราวเนียน โดยทฤษฎีบทของดอนสเกอร์)
---

## บราวเนียนโมชั่น
**การเคลื่อนที่แบบ Brownian** (กระบวนการ Wiener) B(t) คือขีดจำกัดเวลาต่อเนื่องของการเดินแบบสุ่ม
### คำนิยาม
B(t) พอใจ:
1. ข(0) = 0
2. B(t) มีวิถีที่ต่อเนื่องกัน
3. การเพิ่มขึ้นอย่างอิสระ: B(t) − B(s) ไม่ขึ้นกับ B(s) − B(r) สำหรับ r < s < t
4. B(t) − B(s) ~ N(0, t − s) (เพิ่มทีละเกาส์เซียน)
### คุณสมบัติที่สำคัญ
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| อี[ข(ท)] | = 0 |
| วาร์[B(t)] | = เสื้อ |
| Cov[B(s), B(t)] | = นาที(s, t) |
| ไม่มีที่ไหนที่จะแตกต่าง | เส้นทางมีความต่อเนื่อง แต่ไม่มีอนุพันธ์ |
| มิติเศษส่วน | กราฟมีมิติ Hausdorff 3/2 |
| คุณสมบัติมาร์คอฟ | อนาคตขึ้นอยู่กับตำแหน่งปัจจุบันเท่านั้น |
| มาร์ติงเกล | อี[บี(ที) | F_s] = B สำหรับ s < t |
### การเคลื่อนไหวแบบบราวเนียนเรขาคณิต
S(t) = S(0) ประสบการณ์((μ − σ²/2)t + σB(t))
นี่คือโมเดลมาตรฐานสำหรับราคาหุ้นในกรอบการทำงานของ Black-Scholes
- μ: ดริฟท์ (คาดหวังผลตอบแทน)
- σ: ความผันผวน
---

## กระบวนการปัวซอง
**กระบวนการปัวซอง** N(t) นับจำนวนเหตุการณ์ที่เกิดขึ้นใน [0, t]
### คำนิยาม
N(t) ~ ปัวซง(γt) โดยที่ lad คืออัตรา (เหตุการณ์ต่อหน่วยเวลา)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ไม่มี(0) = 0 | — |
| เพิ่มขึ้นอย่างอิสระ | เหตุการณ์ที่อยู่ในช่วงเวลาที่ไม่ต่อเนื่องกันจะเป็นอิสระต่อกัน |
| เพิ่มขึ้นคงที่ | N(t+s) − N(s) ~ ปัวซง(แลต) |
| อี[N(t)] | = แลต |
| วาร์[N(t)] | = แลต |
| เวลาเดินทางถึง | การกระจายแบบเอ็กซ์โปเนนเชียล: T_i ~ Exp(γ) |
### ลักษณะทั่วไป
| ตัวแปร | คำอธิบาย |
|---------|-------------|
| **ไม่เป็นเนื้อเดียวกัน** | อัตรา แล(t) แปรผันตามเวลา |
| **สารประกอบปัวซอง** | แต่ละเหตุการณ์มีขนาดสุ่ม: S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **การวัดแบบสุ่มปัวซอง** | คะแนนในอวกาศ-เวลา ไม่ใช่แค่เวลา |
| **หลายตัวแปร** | เหตุการณ์หลายประเภทพร้อมการโต้ตอบที่เป็นไปได้ |
---

## มาร์ติงเกล
**มาร์ติงเกล** เป็นเกมที่ยุติธรรม: มูลค่าในอนาคตที่คาดหวัง เมื่อพิจารณาจากข้อมูลปัจจุบันทั้งหมด จะเท่ากับมูลค่าปัจจุบัน
### คำนิยาม
{X_n} คือ Martingale ที่เกี่ยวข้องกับการกรอง {F_n} หาก:
1. X_n สามารถวัดได้ F_n (ดัดแปลง)
2. E[|X_n|] < ∞ (บูรณาการได้)
3. อ[X_{n+1} | F_n] = X_n (เกมที่ยุติธรรม)
| ตัวแปร | สภาพ | การตีความ |
|---------|-----------|----------------|
| **มาร์ติงเกล** | อี[X_{n+1} | F_n] = X_n | เกมยุติธรรม |
| **ซับมาร์ติงเกล** | อี[X_{n+1} | F_n] ≥ X_n | เกมน่าเล่น (กำลังมาแรง) |
| **ซุปเปอร์มาร์ติงเกล** | อี[X_{n+1} | F_n] ≤ X_n | เกมเสียเปรียบ (มีแนวโน้มลดลง) |
### ทฤษฎีบทสำคัญ
| ทฤษฎีบท | คำชี้แจง |
|---------|-----------|
| **ทางเลือกในการหยุด** | ภายใต้เงื่อนไข E[X_T] = E[X_0] สำหรับระยะเวลาหยุด T |
| **การบรรจบกัน** | Martingale ที่มีขอบเขตมาบรรจบกันเกือบแน่นอน |
| **ความไม่เท่าเทียมกันสูงสุด** | P(max_{k≤n} X_k ≥ แลมบ์ดา) ≤ E[X_n] / แลม (ของดูบ) |
---

## วิธีการมอนติคาร์โล
**วิธีมอนติคาร์โล** ใช้การสุ่มตัวอย่างเพื่อประมาณปริมาณที่กำหนด
### แนวคิดพื้นฐาน
ในการประมาณค่า E[f(X)] โดยที่ X ~ P:
1. วาดตัวอย่าง N: x₁, x₂, ..., x_N จาก P
2. คำนวณ: Î = (1/N) Σᵢ f(xᵢ)
3. ตามกฎของจำนวนมาก: Î → E[f(X)] เป็น N → ∞
**ข้อผิดพลาด:** ข้อผิดพลาดมาตรฐาน = σ_f / √N โดยที่ σ_f² = Var[f(X)]
### เทคนิคการลดความแปรปรวน
| เทคนิค | ไอเดีย | เร่งความเร็ว |
|----------|-|---------|
| **ตัวอย่างความสำคัญ** | ตัวอย่างจาก Q แทนที่จะเป็น P น้ำหนักโดย P/Q | ดราม่าได้ |
| **การแปรผันของการต่อต้าน** | ใช้คู่ (x, −x) เพื่อยกเลิกความแปรปรวน | ~2x |
| **การควบคุมแปรผัน** | ลบฟังก์ชันที่ทราบความคาดหวังที่สัมพันธ์กับ f | ต่างกันไป |
| **การสุ่มตัวอย่างแบบแบ่งชั้น** | แบ่งโดเมน ตัวอย่างแต่ละชั้น | ลดความแปรปรวน |
| **เรา-แบล็คเวลล์** | เงื่อนไขบนสถิติที่เพียงพอ | ช่วยเสมอ |
---

## มาร์คอฟ เชน มอนติคาร์โล (MCMC)
MCMC สร้างห่วงโซ่มาร์คอฟซึ่งมีการกระจายแบบคงที่เป็นการกระจายเป้าหมาย หลังจากช่วง "เบิร์นอิน" ตัวอย่างจะดึงมาจากเป้าหมายโดยประมาณ
### อัลกอริทึม Metropolis-Hastings
| ขั้นตอน | การกระทำ |
|------|--------|
| 1 | สถานะปัจจุบัน: x_t |
| 2 | เสนอ: x* ~ q(x* \| x_t) (การกระจายข้อเสนอ) |
| 3 | อัตราการยอมรับ: α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | ยอมรับด้วยความน่าจะเป็น α: x_{t+1} = x* (ยอมรับ) หรือ x_t (ปฏิเสธ) |
**กรณีพิเศษ — อัลกอริธึมของ Metropolis:** ข้อเสนอแบบสมมาตร q(x*|x) = q(x|x*) ดังนั้น α = min(1, π(x*)/π(x_t))
### สุ่มตัวอย่างกิ๊บส์
กรณีพิเศษของ Metropolis-Hastings ซึ่งแต่ละตัวแปรได้รับการอัปเดตจากการแจกแจงแบบมีเงื่อนไขแบบเต็ม
สำหรับเป้าหมาย π(x₁, x₂, ..., xₖ):
1. ตัวอย่าง x₁^{(t+1)} ~ π(x₁ | x₂^{(t)}, ..., xₖ^{(t)})
2. ตัวอย่าง x₂^{(t+1)} ~ π(x₂ | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. ดำเนินการต่อสำหรับตัวแปรทั้งหมด
4. ทำซ้ำ
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ยอมรับ | เสมอ α = 1 (ไม่มีขั้นตอนการปฏิเสธ) |
| ต้องใช้ | ความสามารถในการสุ่มตัวอย่างจากแต่ละเงื่อนไข |
| การบรรจบกัน | รับประกันสำหรับโซ่ที่ลดลงเป็นระยะๆ
### การวินิจฉัย MCMC
| การวินิจฉัย | วัตถุประสงค์ |
|----------|---------|
| **ติดตามโครงเรื่อง** | ตรวจสอบด้วยสายตาเพื่อดูการผสมและความคงที่ |
| **ความสัมพันธ์อัตโนมัติ** | วัดการพึ่งพาตัวอย่าง (ต้องการความสัมพันธ์อัตโนมัติต่ำ) |
| **เกลแมน-รูบิน (ร̂)** | เปรียบเทียบหลายโซ่ R̂ < 1.05 แนะนำการบรรจบกัน |
| **ขนาดตัวอย่างที่มีประสิทธิภาพ** | N_eff = N / (1 + 2Σρₖ); บัญชีสำหรับความสัมพันธ์อัตโนมัติ |
| **เบิร์นอิน** | ทิ้งตัวอย่างเริ่มต้นก่อนที่โซ่จะถึงจุดคงที่ |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| กระบวนการสุ่ม | ใบสมัคร |
|-------------------|-------------|
| โซ่มาร์คอฟ | PageRank (การเดินแบบสุ่มบนกราฟเว็บ), การสร้างข้อความ (โมเดล n-gram), MCMC |
| เดินสุ่ม | Node2Vec และ DeepWalk (การฝังกราฟ) การสำรวจใน RL |
| การเคลื่อนไหวแบบบราวเนียน | การสร้างแบบจำลองราคาหุ้น แบบจำลองการแพร่กระจายใน AI กำเนิด |
| กระบวนการปัวซอง | การสร้างแบบจำลองเหตุการณ์การมาถึง (การคลิก ความล้มเหลว) ทฤษฎีการเข้าคิว |
| มาร์ติงเกล | คณิตศาสตร์การเงิน การพิสูจน์การบรรจบกันของ SGD (การประมาณสุ่ม) |
| มอนติคาร์โล | การประมาณค่าที่คาดหวัง การอนุมานแบบเบย์ การเรียนรู้แบบเสริมกำลัง (การประเมินนโยบาย) |
| MCMC (เมโทรโพลิส-เฮสติ้งส์) | การสุ่มตัวอย่างภายหลังแบบเบย์, การเขียนโปรแกรมความน่าจะเป็น (Stan, PyMC) |
| กิ๊บส์สุ่มตัวอย่าง | แบบจำลองหัวข้อ (LDA), เครือข่ายแบบเบย์, การลดสัญญาณรบกวนรูปภาพ |
| การวินิจฉัย MCMC | รับประกันการอนุมานที่เชื่อถือได้จากแบบจำลองความน่าจะเป็น

## สรุป
| กระบวนการ | พื้นที่ของรัฐ | เวลา | คุณสมบัติที่สำคัญ |
|---------|-------------|-|--------------|
| ห่วงโซ่มาร์คอฟ | ไม่ต่อเนื่อง/ต่อเนื่อง | ไม่ต่อเนื่อง/ต่อเนื่อง | ไร้ความทรงจำ (คุณสมบัติ Markov) |
| เดินสุ่ม | ℤᵈ | ไม่ต่อเนื่อง | ผลรวมของ i.i.d. ขั้นตอน |
| การเคลื่อนไหวแบบบราวเนียน | ℝ | ต่อเนื่อง | การเพิ่มขึ้นแบบเกาส์เซียน เส้นทางต่อเนื่อง |
| กระบวนการปัวซอง | ℕ | ต่อเนื่อง | กระบวนการนับโดยมีช่องว่างเอ็กซ์โปเนนเชียล |
| มาร์ติงเกล | ℝ | ไม่ต่อเนื่อง/ต่อเนื่อง | เกมที่ยุติธรรม (E[X_{t+1}|F_t] = X_t) |
กระบวนการสุ่มเป็นคณิตศาสตร์ของการสุ่มเมื่อเวลาผ่านไป พวกเขาสนับสนุนการอนุมานแบบเบย์สมัยใหม่ (MCMC) การเรียนรู้แบบเสริมกำลัง (กระบวนการตัดสินใจของมาร์คอฟ) การสร้างแบบจำลองกำเนิด (แบบจำลองการแพร่กระจาย) คณิตศาสตร์ทางการเงิน และทฤษฎีคิว การทำความเข้าใจกระบวนการเหล่านี้ช่วยให้คุณมีเครื่องมือในการสร้างแบบจำลองความไม่แน่นอนแบบไดนามิก ไม่ใช่แค่ภาพรวมเท่านั้น แต่ในขณะที่มีการเปลี่ยนแปลงอีกด้วย
