# คณิตศาสตร์ไม่ต่อเนื่อง
คณิตศาสตร์แยกเป็นการศึกษาโครงสร้างทางคณิตศาสตร์ที่สามารถนับหรือแยกจากกันโดยพื้นฐาน ตรงข้ามกับคณิตศาสตร์ต่อเนื่อง (แคลคูลัส การวิเคราะห์จริง) ซึ่งเกี่ยวข้องกับปริมาณที่ราบรื่นและไม่ขาดตอน คณิตศาสตร์แยกเป็นรากฐานของวิทยาการคอมพิวเตอร์ การเข้ารหัส การออกแบบอัลกอริทึม และโครงสร้างข้อมูล หากคณิตศาสตร์ต่อเนื่องอธิบายโลกทางกายภาพ คณิตศาสตร์แยกจะอธิบายโลกการคำนวณ
---

## กำหนดทฤษฎีเชิงลึก
เซตเป็นรากฐานที่สร้างคณิตศาสตร์สมัยใหม่เกือบทั้งหมด **ชุด** คือคอลเลกชันที่ไม่เรียงลำดับของวัตถุที่แตกต่างกัน เรียกว่า **องค์ประกอบ** หรือ **สมาชิก**
### รากฐานสัจพจน์ (ZFC)
ทฤษฎีเซตสมัยใหม่ขึ้นอยู่กับ **สัจพจน์เซอร์เมโล-ฟราเอนเคิลกับสัจพจน์แห่งการเลือก (ZFC)** สัจพจน์เหล่านี้แก้ไขความขัดแย้งเช่น Paradox ของรัสเซลล์ ("เซตของเซตทั้งหมดที่ไม่มีตัวมันเอง") โดยการจำกัดวิธีการสร้างเซต
| สัจพจน์ | คำแถลงที่ไม่เป็นทางการ |
|-------|--------------------|
| ส่วนขยาย | สองเซตมีค่าเท่ากันหากมีสมาชิก | เหมือนกัน
| ชุดเปล่า | มีเซตที่ไม่มีองค์ประกอบอยู่: ∅ |
| การจับคู่ | สำหรับ a, b ใดๆ จะมี {a, b} |
| ยูเนี่ยน | สำหรับตระกูลเซ็ตใดๆ ก็ตาม สหภาพของพวกมันจะมีอยู่ |
| ชุดเพาเวอร์ | สำหรับเซต S ใดๆ เซตของเซตย่อยทั้งหมดของ S จะมีอยู่: P(S) |
| อินฟินิตี้ | มีเซตอนันต์ |
| ข้อมูลจำเพาะ | สำหรับเซต A และคุณสมบัติ P ใดๆ จะมี {x ∈ A : P(x)} อยู่ |
| การทดแทน | รูปภาพของชุดภายใต้ฟังก์ชันที่กำหนดได้คือชุด |
| ความสม่ำเสมอ | ชุดที่ไม่ว่างเปล่าทุกชุดมีองค์ประกอบแยกจากกัน (ป้องกันการเป็นสมาชิกด้วยตนเอง) |
| ทางเลือก | สำหรับตระกูลเซตที่ไม่เป็นสมาชิกร่วมแบบคู่ที่ไม่ว่าง จะมีฟังก์ชันตัวเลือก |
### จำนวนสมาชิกและขนาดของเซต
**จำนวนสมาชิกในเซ็ต** ของเซต ซึ่งแสดงโดย |S| วัด "ขนาด" ของเซตนั้น
| แนวคิด | คำจำกัดความ | ตัวอย่าง |
|---------|------------|---------|
| เซตจำกัด | มีจำนวนธรรมชาติเป็นจำนวนนับ | |{ก, ข, ค}| = 3 |
| นับอนันต์ | ภาวะเชิงการนับเดียวกันกับ ℕ | ℤ, ℚ นับเป็นอนันต์ |
| นับไม่ได้ | ใหญ่กว่า ℕ | ℝ, P(ℕ) เซตของฟังก์ชันทั้งหมด ℕ → {0,1} |
| ทฤษฎีบทของคันทอร์ | สำหรับเซต S ใดๆ |P(S)| > |ส| | |P(ℕ)| > |ℕ| |
**ข้อโต้แย้งในแนวทแยงของคันทอร์** พิสูจน์ว่า ℝ ไม่สามารถนับได้: สมมติว่าคุณสามารถแสดงรายการจำนวนจริงทั้งหมดใน [0,1] ได้ จากนั้นจึงสร้างจำนวนจริงใหม่ที่แตกต่างจากจำนวนจริงที่อยู่ในรายการลำดับที่ n ในทศนิยมตำแหน่งที่ n ซึ่งขัดแย้งกัน
### การดำเนินงานในชุด
| การดำเนินงาน | สัญกรณ์ | คำจำกัดความ | คุณสมบัติ |
|----------|----------|------------|----------|
| ยูเนี่ยน | ก ∪ ข | {x : x ∈ A หรือ x ∈ B} | สับเปลี่ยน, เชื่อมโยง |
| ทางแยก | ก ∩ B | {x : x ∈ A และ x ∈ B} | สับเปลี่ยน, เชื่อมโยง |
| ความแตกต่าง | ก \ บี | {x : x ∈ A และ x ∉ B} | ไม่ใช่การสับเปลี่ยน |
| ความแตกต่างสมมาตร | ก △ ข | (A \ B) ∪ (B \ A) | สับเปลี่ยน, เชื่อมโยง |
| ส่วนประกอบ | อ่า | U \ A (โดยที่ U คือเซตสากล) | (ᶜ)ᶜ = อ |
| สินค้าคาร์ทีเซียน | ก × ข | {(a,b) : a ∈ A, b ∈ B} | |ก × ข| = |ก| · |ข| |
**กฎของเดอมอร์แกน:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**หลักการรวม-แยก** (สำหรับเซตจำกัด):
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|

## ความสัมพันธ์
**ความสัมพันธ์** R บนเซต A และ B เป็นสับเซตของ A × B เมื่อ (a, b) ∈ R เราจะเขียน aRb
### ประเภทของความสัมพันธ์
ความสัมพันธ์ R บนเซต A สามารถมีคุณสมบัติดังต่อไปนี้:
| คุณสมบัติ | คำจำกัดความ | ตัวอย่าง |
|----------|------------|---------|
| สะท้อน | ∀a ∈ A: อารา | ≤ บน ℤ |
| ไม่สะท้อนกลับ | ∀a ∈ A: ฌ(อารา) | < บน ℤ |
| สมมาตร | ∀a,b: aRb → bRa | = บนชุดใดก็ได้ |
| ต่อต้านสมมาตร | ∀a,b: aRb ∧ bRa → a = b | ≤ บน ℤ |
| สกรรมกริยา | ∀a,b,c: aRb ∧ bRc → aRc | <, ≤, = บน ℤ |
### ความสัมพันธ์ที่เท่าเทียมกัน
**ความสัมพันธ์ที่เท่าเทียมกัน** เป็นแบบสะท้อนกลับ สมมาตร และสกรรมกริยา โดยจะแบ่งชุดออกเป็น **คลาสที่เทียบเท่า** ที่ไม่เป็นสมาชิกร่วม
**ตัวอย่าง:** เลขคณิตแบบโมดูลาร์ กำหนด a ~ b iff a ≡ b (mod n) คลาสที่เทียบเท่าคือ [0], [1], ..., [n−1] ซึ่งแบ่ง ℤ ออกเป็น n คลาส
**ตัวอย่างการทำงาน:** บน ℤ × ℤ ให้นิยาม (a,b) ~ (c,d) iff a + d = b + c นี่คือความสัมพันธ์ที่เท่าเทียมกัน คลาส [(0,0)] = {(n,n) : n ∈ ℤ} คลาส [(1,0)] = {(n+1,n) : n ∈ ℤ} โครงสร้างนี้กำหนดจำนวนเต็มจากจำนวนธรรมชาติจริงๆ
### คำสั่งซื้อบางส่วน
**ลำดับบางส่วน** เป็นแบบสะท้อนกลับ ต้านสมมาตร และสกรรมกริยา ชุดที่มีการเรียงลำดับบางส่วนเรียกว่า **ชุดเรียงลำดับบางส่วน (poset)**
| แนวคิด | คำจำกัดความ | ตัวอย่าง |
|---------|------------|---------|
| โพเซต | (S, ≤) โดยมี ≤ ลำดับบางส่วน | (P(A), ⊆) — เซตย่อยเรียงลำดับโดยการรวม |
| โซ่ | เซตย่อยที่เรียงลำดับโดยสิ้นเชิง | {∅, {a}, {a,b}} ใน P({a,b,c}) |
| แอนตี้เชน | เซตย่อยที่ไม่มีสององค์ประกอบใดเทียบเคียงได้ | {{a}, {b}} ใน P({a,b}) |
| แผนภาพ Hasse | การแสดงภาพโพสท่า | วาดขอบเพื่อปกปิดความสัมพันธ์เท่านั้น |
| ขอบเขตบน | องค์ประกอบ ≥ ทุกองค์ประกอบในกลุ่มย่อย | sup({2,3}) = 6 นิ้ว (ℤ, \|) (หารลงตัว) |
| ขอบเขตบนน้อยที่สุด (sup) | ขอบเขตบนที่เล็กที่สุด | sup({2,3}) ใน (ℕ, ≤) คือ 3 |
| ขอบเขตล่างที่ยิ่งใหญ่ที่สุด (inf) | ขอบเขตล่างที่ใหญ่ที่สุด | inf({4,6}) ใน (ℕ, \|) คือ 2 |

## ฟังก์ชั่น
A **ฟังก์ชัน** f: A → B กำหนดให้กับแต่ละองค์ประกอบของ A เพียงหนึ่งองค์ประกอบของ B
### การจำแนกประเภทของฟังก์ชัน
| พิมพ์ | คำจำกัดความ | ตัวอย่าง |
|------|------------|---------|
| ฉีด (ตัวต่อตัว) | ฉ(ก) = ฉ(ข) → ก = ข | ฉ(x) = 2x จาก ℤ → ℤ |
| ศัลยกรรม (บน) | ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x ม็อด 2 จาก ℤ → {0,1} |
| วัตถุประสงค์ | ทั้งแบบฉีดและแบบศัลยกรรม | ฉ(x) = x + 1 จาก ℤ → ℤ |
### แนวคิดฟังก์ชั่นที่สำคัญ
| แนวคิด | คำจำกัดความ | ใช้กรณี |
|---------|------------|----------|
| ฟังก์ชันผกผัน | f⁻¹ มีอยู่ iff f คือ bijective | การถอดรหัสข้อมูลที่เข้ารหัส |
| องค์ประกอบ | (ก ∘ ฉ)(x) = ก(ฉ(x)) | การแปลงแบบผูกมัด |
| ฟังก์ชันระบุตัวตน | รหัส(x) = x | องค์ประกอบที่เป็นกลางสำหรับองค์ประกอบ |
| จุดคงที่ | ฉ(x) = x | คำจำกัดความแบบเรียกซ้ำ ความหมาย |
| การเรียงสับเปลี่ยน | การบิดเบี้ยวจากเซตถึงตัวมันเอง | การจัดเรียงข้อมูลใหม่ การสับเปลี่ยน |
### ฟังก์ชั่นการนับ
กำหนดเซตจำกัด |A| = ม. และ |B| = ไม่มี:
| พิมพ์ | นับ |
|-|-------|
| ฟังก์ชั่นทั้งหมด A → B | ไม่ใช่ |
| ฟังก์ชันฉีด | มะ! / (n−m)! (ถ้า n ≥ m มิฉะนั้น 0) |
| ฟังก์ชันเชิงปฏิเสธ | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ (โดยการรวม-แยก) |
| ฟังก์ชัน Bijective | มะ! (เมื่อ m = n) |

## การผสมผสาน
Combinatorics คือคณิตศาสตร์ของการนับ การจัดเรียง และการเลือก
### หลักการนับขั้นพื้นฐาน
| หลักการ | คำชี้แจง | ตัวอย่าง |
|----------|-----------|---------|
| กฎการรวม | ถ้า A และ B ไม่ต่อเนื่องกัน |A ∪ B| = |ก| + |ข| | การเลือกผลไม้: แอปเปิ้ล 3 ผล + ส้ม 4 ผล = 7 ตัวเลือก |
| กฎของผลิตภัณฑ์ | |ก × ข| = |ก| · |ข| | เครื่องแต่งกาย : เสื้อ 3 ตัว × กางเกง 4 ตัว = 12 ชุด |
| กฎการบอกทิศทาง | ถ้า f: A → B เป็นการบิดเบี้ยว |A| = |ข| | นับเซ็ตย่อยโดยการนับสตริงไบนารี |
| ส่วนประกอบ | |ก| = |ยู| − |อาᶜ| | นับ "อย่างน้อยหนึ่ง" เป็นผลรวมลบ "ไม่มี" |
### การเรียงสับเปลี่ยนและการรวมกัน
| สัญกรณ์ | ชื่อ | สูตร | ความหมาย |
|----------|-|---------|---------|
| C(n, k) หรือ (n k) | สัมประสิทธิ์ทวินาม | มะ! / (k!(n−k)!) | วิธีเลือก k รายการจาก n (ลำดับไม่สำคัญ) |
| P(น,เค) | k-พีชคณิตของ n | มะ! / (น−k)! | วิธีจัดเรียง k รายการจาก n (เรื่องการสั่งซื้อ) |
| มะ! | แฟกทอเรียล | n × (n−1) × ... × 1 | วิธีจัดเรียงทั้งหมด n รายการ |
| (n k) ด้วยการทำซ้ำ | เลือกหลายรายการ | C(n+k−1, k) | เลือก k จาก n โดยอนุญาตให้ทำซ้ำได้ |
**ทฤษฎีบททวินาม:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**ตัวตนของปาสคาล:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### หลักการรังนกพิราบ
**รูปแบบพื้นฐาน:** หากวางวัตถุ n+1 ลงใน n กล่อง อย่างน้อย 1 กล่องจะมีวัตถุ ≥ 2 ชิ้น
**รูปแบบทั่วไป:** หากวางวัตถุ N รายการลงในกล่อง k กล่อง อย่างน้อยหนึ่งกล่องจะมีวัตถุ ≥ ⌈N/k⌉
** ตัวอย่างการทำงาน: **
1. ในจำนวน 13 คน อย่างน้อย 2 คนเกิดร่วมกันในเดือนเกิด (13 คน 12 เดือน → หลุมนกพิราบ)
2. จงแสดงว่าในจำนวนเต็ม 5 จำนวนใด ๆ มี 3 ซึ่งผลรวมหารด้วย 3 ลงตัว
   - พิจารณาสิ่งตกค้าง mod 3: {0, 1, 2} ด้วยจำนวนเต็ม 5 ตัวและคลาสเรซิดิว 3 คลาส โดยรูนกพิราบทั่วไป อย่างน้อย ⌈5/3⌉ = 2 มีเรซิดิวร่วมกัน
   - ถ้า 3 แบ่งปันสิ่งตกค้าง r: ผลรวมของพวกเขา ≡ 3r ≡ 0 (mod 3)
   - ถ้า 2 แบ่งปันสารตกค้าง 0 และ 2 แบ่งปันสารตกค้าง 1: เลือกหนึ่งรายการจากแต่ละคู่บวกองค์ประกอบสารตกค้าง-0 → ผลรวม ≡ 0 (mod 3)
3. **การใช้งานใน CS:** อัลกอริธึมการบีบอัดแบบไม่สูญเสียข้อมูลใดๆ จะต้องขยายอินพุตบางส่วน (หากทุกสตริง n-บิตถูกบีบอัดเป็น < n บิต คุณจะต้องแมปสตริง 2ⁿ ลงในสตริงที่บีบอัดน้อยกว่า 2ⁿ — ละเมิด injectivity)
### หมายเลขคาตาลัน

## ความสัมพันธ์ที่เกิดซ้ำ
**ความสัมพันธ์การเกิดซ้ำ** กำหนดแต่ละเทอมของลำดับเป็นฟังก์ชันของคำศัพท์ก่อนหน้า
### ประเภทและแนวทางแก้ไข
| พิมพ์ | แบบฟอร์ม | วิธีการแก้ปัญหา |
|-|-------|-----------------|

### วิธีสมการลักษณะเฉพาะ
สำหรับ aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ ให้สร้างสมการคุณลักษณะ:
r² − c₁r − c₂ = 0
| กรณี | ราก | วิธีแก้ปัญหาทั่วไป |
|------|-------|------------------|
| รากจริงสองอันที่แตกต่างกัน r₁, r₂ | r₁ ≠ r₂ | aₙ = A·r₁ⁿ + B·r₂ⁿ |
| รูตซ้ำ r | r₁ = r₂ = r | aₙ = (A + Bn)·rⁿ |
| รากเชิงซ้อน α ± βi | แปลงเป็นขั้ว: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**ตัวอย่างการทำงาน:** ลำดับฟีโบนัชชี Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1
- สมการคุณลักษณะ: r² − r − 1 = 0
- ราก: r = (1 ± √5) / 2 → φ = (1+√5)/2 data 1.618, ψ = (1−√5)/2 γ −0.618
- วิธีแก้ทั่วไป: Fₙ = A·φⁿ + B·ψⁿ
- จากเงื่อนไขตั้งต้น: A = 1/√5, B = −1/√5
- **แบบฟอร์มปิด:** Fₙ = (φⁿ − ψⁿ) / √5 (สูตรของไบเน็ต)
### ทฤษฎีบทปริญญาโท
สำหรับการเกิดซ้ำในรูปแบบ T(n) = aT(n/b) + f(n) โดยที่ a ≥ 1, b > 1:
ให้ c = log_b(a)
| กรณี | สภาพ | โซลูชั่น |
|------|-----------|----------|
| 1 | f(n) = O(nᵈ) โดยที่ d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c และ af(n/b) ≤ kf(n) สำหรับ k < 1 | T(n) = Θ(nᵈ) |
**ตัวอย่าง:**
- การเรียงลำดับแบบผสาน: T(n) = 2T(n/2) + O(n) ที่นี่ a=2, b=2, c=1, f(n)=n=Θ(n¹) กรณีที่ 2: T(n) = Θ(n log n)
- การค้นหาแบบไบนารี: T(n) = T(n/2) + O(1) ที่นี่ a=1, b=2, c=0, f(n)=1=Θ(n⁰) กรณีที่ 2: T(n) = Θ(log n)

## การสร้างฟังก์ชั่น
**ฟังก์ชันการสร้าง** เข้ารหัสลำดับ (aₙ) เป็นค่าสัมประสิทธิ์ของอนุกรมกำลังแบบเป็นทางการ
### ประเภท
| พิมพ์ | แบบฟอร์ม | ใช้กรณี |
|------|-|---------|
| สามัญ (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ | โครงสร้างที่ไม่มีป้ายกำกับ องค์ประกอบ |
| เอ็กซ์โปเนนเชียล (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n! | โครงสร้างที่มีป้ายกำกับ การเรียงสับเปลี่ยน |
### ฟังก์ชั่นการสร้างทั่วไป
| ลำดับₙ | โอจีเอฟ G(x) |
|-------------|-----------|
| 1, 1, 1, 1, ... | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² |
| 1, r, r², r³, ... | 1/(1−rx) |
| C(n,k) สำหรับค่าคงที่ k | xᵏ/(1−x)ᵏ⁺¹ |
| ฟีโบนัชชี Fₙ | x/(1−x−x²) |
| คาตาลัน Cₙ | (1 − √(1−4x)) / (2x) |
### การใช้ฟังก์ชันการสร้างเพื่อแก้ปัญหาการเกิดซ้ำ
**ตัวอย่างที่ได้ผล:** แก้ aₙ = 3aₙ₋₁ − 2aₙ₋₂, a₀ = 1, a₁ = 3
1. ให้ G(x) = Σ aₙxⁿ
2. จากการเกิดซ้ำ: G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. แทน: G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. เศษส่วนบางส่วน: G(x) = 2/(1−2x) − 1/(1−x)
7. แยกค่าสัมประสิทธิ์: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺¹ − 1
**การตรวจสอบ:** a₀ = 2−1 = 1, a₁ = 4−1 = 3, a₂ = 8−1 = 7 ตรวจสอบ: 3(3) − 2(1) = 7

## พีชคณิตบูลีนและลอจิกเชิงประพจน์
พีชคณิตแบบบูลคือพีชคณิตของค่าความจริงสองค่า: **จริง (1)** และ **เท็จ (0)** เป็นรากฐานทางคณิตศาสตร์ของวงจรดิจิทัล การสืบค้นฐานข้อมูล และเงื่อนไขการเขียนโปรแกรม
### การดำเนินงานและกฎหมาย
| การดำเนินงาน | สัญลักษณ์ | ความหมาย | ตารางความจริง |
|----------|--------|---------|-------------|
| และ | พี ∧ คิว | จริงเฉพาะเมื่อทั้งสองเป็นจริง | T∧T=T, T∧F=F, F∧T=F, F∧F=F |
| หรือ | พี ∨ คิว | จริงเมื่ออย่างน้อยหนึ่งรายการเป็นจริง | T∨T=T, T∨F=T, F∨T=T, F∨F=F |
| ไม่ | §p | การปฏิเสธ | ฌT=F, ฌF=T |
| แฮคเกอร์ | พี ⊕ คิว | จริงเมื่อสิ่งหนึ่งเป็นจริง | T⊕T=F, T⊕F=T, F⊕T=T, F⊕F=F |
| หมายถึง | พี → คิว | เท็จเฉพาะเมื่อ p=T และ q=F | T→T=T, T→F=F, F→T=T, F→F=T |
| สองเงื่อนไข | พี ↔ คิว | เป็นจริงเมื่อทั้งคู่มีค่าเท่ากัน | T↔T=T, T↔F=F, F↔T=F, F↔F=T |
### รหัสประจำตัวบูลีนที่สำคัญ
| กฎหมาย | สูตร |
|-----|--------|

| สมาคม | (p ∧ q) ∧ r = p ∧ (q ∧ r) |

## เลขคณิตแบบโมดูลาร์และความสอดคล้อง
การศึกษาเลขคณิตแบบแยกส่วนจำนวนเต็มภายใต้การดำเนินการ "เศษหลังการหาร" มันจำเป็นสำหรับการเข้ารหัส การแฮช และทฤษฎีจำนวน
### คำจำกัดความหลัก
| แนวคิด | สัญกรณ์ | คำจำกัดความ |
|---------|----------|------------|
| ความสอดคล้อง | a ≡ b (mod n) | n หาร (a − b) |
| ชั้นสารตกค้าง | [ก]ₙ | เซต {a + kn : k ∈ ℤ} |
| โมดูลาร์ผกผัน | a⁻¹ mod n | ค่า x เช่นขวาน ≡ 1 (mod n) |
| totient ของออยเลอร์ | φ(n) | จำนวนเต็มใน {1,...,n} เป็นจำนวนเฉพาะถึง n |
### คุณสมบัติที่สำคัญ
| คุณสมบัติ | คำชี้แจง |
|----------|----------|
| นอกจากนี้ | ถ้า a ≡ b และ c ≡ d (mod n) แล้ว a+c ≡ b+d (mod n) |
| การคูณ | ถ้า a ≡ b และ c ≡ d (mod n) แล้ว ac ≡ bd (mod n) |
| ทฤษฎีบทเล็กของแฟร์มาต์ | ถ้า p เป็นจำนวนเฉพาะและ gcd(a,p) = 1 ดังนั้น aᵖ⁻¹ ≡ 1 (mod p) |
| ทฤษฎีบทของออยเลอร์ | ถ้า gcd(a,n) = 1 แล้ว a^φ(n) ≡ 1 (mod n) |
| ทฤษฎีบทเศษเหลือของจีน | ถ้า gcd(m,n) = 1 ระบบ x ≡ a (mod m), x ≡ b (mod n) มีวิธีแก้ปัญหาเฉพาะ mod mn |
### การคำนวณ Totient ของออยเลอร์
สำหรับ n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ (การแยกตัวประกอบเฉพาะ):
φ(n) = n · (1 − 1/p₁) · (1 − 1/p₂) · ... · (1 − 1/pₖ)
**ตัวอย่าง:** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4 โดยแท้แล้ว {1, 5, 7, 11} เป็นจำนวนเฉพาะร่วมของ 12
### แอปพลิเคชัน: การเข้ารหัส RSA (ภาพรวม)
1. เลือกจำนวนเฉพาะขนาดใหญ่ p, q คำนวณ n = pq, φ(n) = (p−1)(q−1)
2. เลือก e โดยให้ gcd(e, φ(n)) = 1 (เลขชี้กำลังสาธารณะ)
3. คำนวณ d ≡ e⁻¹ (mod φ(n)) (เลขชี้กำลังส่วนตัว)
4. เข้ารหัส: c = m n mod n ถอดรหัส: m = cᵈ mod n
5. ความปลอดภัยขึ้นอยู่กับความยากของการแยกตัวประกอบ n เพื่อค้นหา p และ q

## การเหนี่ยวนำทางคณิตศาสตร์
**การเหนี่ยวนำทางคณิตศาสตร์** เป็นเทคนิคการพิสูจน์เบื้องต้นสำหรับข้อความเกี่ยวกับจำนวนธรรมชาติทั้งหมด
### โครงสร้างของการพิสูจน์โดยการเหนี่ยวนำ
1. **กรณีฐาน:** พิสูจน์ข้อความที่ n = 0 (หรือ n = 1)
2. **ขั้นตอนการอุปนัย:** สมมติว่าประโยคนี้มีไว้เพื่อ n = k (สมมติฐานอุปนัย) แล้วพิสูจน์เพื่อหา n = k + 1
### รุ่นต่างๆ
| ตัวแปร | เมื่อใดควรใช้ |
|---------|-------------|
| การเหนี่ยวนำอย่างง่าย | พิสูจน์ P(k) → P(k+1) |
| การเหนี่ยวนำที่แข็งแกร่ง | สมมติ P(0), P(1), ..., P(k) เพื่อพิสูจน์ P(k+1) |
| การเหนี่ยวนำโครงสร้าง | พิสูจน์คุณสมบัติของโครงสร้างที่กำหนดแบบเรียกซ้ำ (ต้นไม้, สูตร) ​​|
| การเหนี่ยวนำแบบไม่มีที่สิ้นสุด | ขยายการเหนี่ยวนำไปยังชุดที่ได้รับการสั่งซื้ออย่างดีเกินกว่า ℕ |
**ตัวอย่างการทำงาน (การเหนี่ยวนำแบบ Strong):** พิสูจน์ว่าจำนวนเต็มทุกจำนวน n ≥ 2 สามารถเขียนเป็นผลคูณของจำนวนเฉพาะได้
- ฐาน: n = 2 เป็นจำนวนเฉพาะ จึงเป็นผลคูณของจำนวนเฉพาะ (ตัวมันเอง)
- ขั้นตอนการอุปนัย: ถือว่าเป็นจริงสำหรับจำนวนเต็มทั้งหมดตั้งแต่ 2 ถึง k พิจารณา k+1
  - ถ้า k+1 เป็นจำนวนเฉพาะ ก็เสร็จแล้ว
  - ถ้า k+1 เป็นผลประกอบ k+1 = ab โดยที่ 2 ≤ a, b ≤ k ตามสมมติฐานอุปนัย ทั้ง a และ b เป็นผลคูณของจำนวนเฉพาะ ดังนั้น k+1 จึงเป็นผลคูณของจำนวนเฉพาะ

| ความสัมพันธ์ที่เกิดซ้ำ | การโปรแกรมแบบไดนามิก การวิเคราะห์ความซับซ้อนของอัลกอริทึม โมเดลอนุกรมเวลา |
| การสร้างฟังก์ชัน | ฟังก์ชันการสร้างความน่าจะเป็น การแก้ปัญหาเชิงผสมผสานในงานวิศวกรรมเชิงคุณลักษณะ |
| หมายเลขคาตาลัน | การนับโครงสร้างต้นไม้ (แผนผังการตัดสินใจ) การแยกวิเคราะห์นิพจน์ การดำเนินการสแต็ก |
| ทฤษฎีกราฟ (ดูไฟล์ถัดไป) | การวิเคราะห์เครือข่ายโซเชียล ระบบแนะนำ การเป็นตัวแทนความรู้ |

## สรุป
| หัวข้อ | แนวคิดหลัก | เครื่องมือสำคัญ |
|-------|-----------|----------|
| ทฤษฎีเซต | คอลเลกชันของวัตถุที่แตกต่าง | สัจพจน์ ZFC, ภาวะเชิงการนับ, การดำเนินการ |
| ความสัมพันธ์ | การเชื่อมต่อระหว่างองค์ประกอบ | ความสัมพันธ์ที่เท่าเทียมกัน ลำดับบางส่วน |
| ฟังก์ชั่น | การแมประหว่างเซต | การฉีด, surjectivity, bijection |
| เชิงผสม | การจัดเตรียมการนับ | สัมประสิทธิ์ทวินาม หลักการรูนกพิราบ |
| ความสัมพันธ์ที่เกิดซ้ำ | ลำดับที่กำหนดแบบเรียกซ้ำ | สมการคุณลักษณะ ทฤษฎีบทมหาบัณฑิต |
| การสร้างฟังก์ชัน | ลำดับเป็นอนุกรมกำลัง | OGF/EGF การแก้การเกิดซ้ำเชิงพีชคณิต |
คณิตศาสตร์แยกเป็นภาษาและเครื่องมือในการให้เหตุผลเกี่ยวกับโครงสร้างจำกัดหรือโครงสร้างนับได้ ซึ่งเป็นสิ่งที่คอมพิวเตอร์จัดการอย่างชัดเจน ทุกอัลกอริทึม โครงสร้างข้อมูล การสืบค้นฐานข้อมูล และโปรโตคอลการเข้ารหัสทั้งหมดวางอยู่บนรากฐานที่แยกจากกัน ความเชี่ยวชาญในหัวข้อเหล่านี้ช่วยเพิ่มความสามารถในการแก้ปัญหา และให้คำศัพท์สำหรับการศึกษาขั้นสูงในด้านอัลกอริทึม ทฤษฎีความซับซ้อน และการเรียนรู้ของเครื่อง
