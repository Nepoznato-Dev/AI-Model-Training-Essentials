#กลศาสตร์คลาสสิก
กลศาสตร์คลาสสิกอธิบายการเคลื่อนที่ของวัตถุภายใต้อิทธิพลของแรง ตั้งแต่ลูกแอปเปิลที่ตกลงมาไปจนถึงดาวเคราะห์ที่โคจรรอบดาวเคราะห์ จากการสั่นของสายไปจนถึงการชนกันของอนุภาค หลักการของมันควบคุมโลกขนาดมหึมา นอกเหนือจากการใช้งานทางกายภาพแล้ว กลศาสตร์คลาสสิกยังให้กำเนิดแคลคูลัสของการแปรผัน เรขาคณิตเชิงสมมาตร และกรอบการทำงานของแฮมิลตันที่สนับสนุนกลศาสตร์ควอนตัมและการเพิ่มประสิทธิภาพสมัยใหม่

## กลศาสตร์นิวตัน
### กฎสามข้อของนิวตัน
| กฎหมาย | คำชี้แจง | แบบฟอร์มทางคณิตศาสตร์ |
|-----|-----------|-------------------|
| **ครั้งแรก (ความเฉื่อย)** | วัตถุยังคงอยู่นิ่งหรือเคลื่อนที่สม่ำเสมอ เว้นแต่จะถูกกระทำด้วยแรง | ถ้า F_net = 0 ดังนั้น v = ค่าคงที่ |
| **ที่สอง (F = แม่)** | แรงเท่ากับมวลคูณความเร่ง | **F** = ม**a** = ม(d²**x**/dt²) |
| **ที่สาม (การกระทำ-ปฏิกิริยา)** | ทุกการกระทำมีปฏิกิริยาที่เท่ากันและตรงกันข้าม | **F**₁₂ = −**F**₂₁ |
### ไดอะแกรมร่างกายฟรี
**แผนภาพวัตถุอิสระ** แยกวัตถุและแสดงแรงทั้งหมดที่กระทำต่อวัตถุนั้น
**กองกำลังร่วม:**
| บังคับ | สูตร | ทิศทาง |
|-------|---------|-----------|
| แรงโน้มถ่วง (ใกล้โลก) | F = มก. | ลง |
| แรงปกติ | ยังไม่มี | ตั้งฉากกับพื้นผิว |
| แรงเสียดทาน (คงที่) | f_s ≤ μ_s N | ต่อต้านการเคลื่อนไหวที่กำลังจะเกิดขึ้น |
| แรงเสียดทาน (จลนศาสตร์) | f_k = μ_k N | ต่อต้านการเคลื่อนไหว |
| ฤดูใบไม้ผลิ (กฎของฮุค) | F = −kx | การฟื้นฟู (สู่สมดุล) |
| ความตึงเครียด | ที | ตามเชือก/เชือก |
| ลาก | F_d = ½C_d ρAv² | ตรงข้ามกับความเร็ว |
### ตัวอย่างการทำงาน: บล็อกบนเอียง
บล็อกมวล m บนความลาดเอียงแบบไม่มีแรงเสียดทานที่มุม θ
- แรง: แรงโน้มถ่วง (มก. ลง), แรงตั้งฉาก (N ตั้งฉากกับพื้นผิว)
- สลายแรงโน้มถ่วง: mg sin θ (ตามความลาดเอียง), mg cos θ (สู่พื้นผิว)
- N = mg cos θ (ไม่มีการเคลื่อนไหวตั้งฉากกับพื้นผิว)
- ความเร่งตามแนวลาดเอียง: a = g sin θ

## วิธีพลังงาน
### งานและพลังงานจลน์
**งาน** ทำด้วยแรง: W = ∫ **F** · d**r**
**ทฤษฎีบทงาน-พลังงาน:** W_net = ΔKE = ½mv₂² − ½mv₁²
### พลังงานศักย์
| บังคับ | พลังงานศักย์ | หมายเหตุ |
|----------------------|-----------------|-------|
| แรงโน้มถ่วง (ใกล้พื้นผิว) | U = มก. | h = ความสูงเหนือการอ้างอิง |
| แรงโน้มถ่วง (ทั่วไป) | U = −GMm/r | ศูนย์ที่อนันต์ |
| ฤดูใบไม้ผลิ | U = ½kx² | x = การกระจัดจากสมดุล |
| ไฟฟ้าสถิต | U = kq₁q₂/r | ชอบค่าใช้จ่าย: บวก U |
### การอนุรักษ์พลังงาน
ถ้าแรงอนุรักษ์เท่านั้นที่กระทำ: E = KE + PE = ค่าคงที่
½mv₁² + U₁ = ½mv₂² + U₂
**ตัวอย่างการทำงาน:** ลูกบอลตกลงมาจากที่สูง h.
- เริ่มต้น: KE = 0, PE = มก
- ก่อนถึงพื้น: KE = ½mv², PE = 0
- การอนุรักษ์: mgh = ½mv² → v = √(2gh)
### พลัง
P = dW/dt = **F** · **v** (อัตราการทำงาน)

## โมเมนตัมและการชน
### โมเมนตัมเชิงเส้น
**พี** = ม**วี**
กฎข้อที่สองของนิวตัน (รูปแบบทางเลือก): **F** = d**p**/dt
### การอนุรักษ์โมเมนตัม
หากไม่มีแรงภายนอก โมเมนตัมรวมจะคงอยู่
| ประเภทการชน | KE อนุรักษ์? | โมเมนตัมอนุรักษ์ไว้? |
|---------------|---------------|---------------------|
| **ยางยืด** | ใช่ | ใช่ |
| **ไม่ยืดหยุ่น** | ไม่ | ใช่ |
| **ไม่ยืดหยุ่นอย่างสมบูรณ์แบบ** | ไม่ (ขาดทุนสูงสุด) | ใช่ (วัตถุติดกัน) |
**การชนแบบยืดหยุ่น 1 มิติ:** มวลสองก้อน m₁, m₂ ด้วยความเร็วเริ่มต้น u₁, u₂:
- v₁ = ((m₁−m₂)u₁ + 2m₂u₂) / (m₁+m₂)
- v₂ = ((m₂−m₁)u₂ + 2m₁u₁) / (m₁+m₂)
### โมเมนตัมเชิงมุม
**L** = **r** × **p** = ม(**r** × **v**)
แรงบิด: **τ** = d**L**/dt = **r** × **F**
**การอนุรักษ์:** หากไม่มีแรงบิดภายนอก โมเมนตัมเชิงมุมก็จะยังคงอยู่

## กลศาสตร์ลากรองจ์
สูตร **Lagrangian** แทนที่แรงด้วยพลังงาน ทำให้เกิดกรอบการทำงานที่หรูหราและทั่วถึงยิ่งขึ้น
### ลากรองจ์
L = T - V (พลังงานจลน์ลบพลังงานศักย์)
### หลักการของการกระทำน้อยที่สุด (หลักการของแฮมิลตัน)
เส้นทางจริงที่ระบบใช้ระหว่างเวลา t₁ และ t₂ ย่อให้เล็กสุด (แม่นยำยิ่งขึ้น ทำให้หยุดนิ่ง) **การกระทำ**:
S = ∫_{t₁}^{t₂} L(q, q̇, t) dt
### สมการออยเลอร์-ลากรองจ์
เงื่อนไข δS = 0 ให้ผลดังนี้:
d/dt(∂L/∂q̇) − ∂L/∂q = 0
สำหรับแต่ละพิกัดทั่วไป q
**ตัวอย่างการทำงาน:** ลูกตุ้มธรรมดา (ความยาว l มวล m มุม θ จากแนวตั้ง)
- T = ½มล²θ̇²
- V = −mgl cos θ
- L = ½ml²θ̇² + mgl cos θ
- ∂L/∂θ = −mgl บาป θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̇
- ออยเลอร์-ลากรองจ์: ml²θ¶ + mgl sin θ = 0 → θ + (g/l) sin θ = 0
### ข้อดีของกลศาสตร์ลากรองจ์
| ข้อได้เปรียบ | คำอธิบาย |
|-----------|-------------|
| พิกัดอิสระ | ทำงานในระบบพิกัดใด ๆ |
| จัดการกับข้อจำกัดอย่างเป็นธรรมชาติ | ไม่จำเป็นต้องคำนวณแรงจำกัด |
| สมมาตร → การอนุรักษ์ | ทฤษฎีบทของ Noether เชื่อมโยงสมมาตรกับปริมาณอนุรักษ์ |
| ทั่วไปได้อย่างง่ายดาย | สู่สนามแม่เหล็ก ทฤษฎีสัมพัทธภาพ กลศาสตร์ควอนตัม |

## กลศาสตร์แฮมิลตัน
สูตร **ฮามิลโทเนียน** เป็นการปรับสูตรกลศาสตร์ลากรองจ์ใหม่ที่ใช้ตำแหน่งและโมเมนตา (แทนตำแหน่งและความเร็ว)
### แฮมิลตันเนียน
H = Σᵢ pᵢq̇ᵢ − L = T + V (สำหรับระบบกลไกส่วนใหญ่)
โดยที่ pᵢ = ∂L/∂q̇ᵢ คือ **โมเมนตาทั่วไป**
### สมการของแฮมิลตัน
ค̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
เหล่านี้เป็น ODE ลำดับที่หนึ่ง 2n (เทียบกับสมการออยเลอร์-ลากรองจ์ลำดับที่สอง)
**ตัวอย่างการทำงาน:** ออสซิลเลเตอร์ฮาร์มอนิก (มวล m ค่าคงที่สปริง k)
- H = p²/(2ม.) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ (ตามที่คาดไว้)
- ṗ = −∂H/∂x = −kx → mẍ = −kx (กฎของฮุค)
### วงเล็บปัวซอง
สำหรับฟังก์ชัน f(q, p) และ g(q, p):
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| วิวัฒนาการของเวลา | df/dt = {f, H} + ∂f/∂t |
| การอนุรักษ์ | f ถูกสงวนไว้ iff {f, H} = 0 (และ ∂f/∂t = 0) |
| วงเล็บเหลี่ยมพื้นฐาน | {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**การเชื่อมต่อกับกลศาสตร์ควอนตัม:** วงเล็บปัวซองกลายเป็นสับเปลี่ยน: {f, g} → (1/iℏ)[f̂, ĝ]

## กฎหมายการอนุรักษ์และทฤษฎีบทของ Noether
### ทฤษฎีบทของโนเธอร์
ความสมมาตรต่อเนื่องทุกประการของลากรองจ์สอดคล้องกับปริมาณอนุรักษ์
| สมมาตร | ปริมาณอนุรักษ์ |
|----------|-------------------|
| ค่าคงที่การแปลเวลา | พลังงาน |
| ค่าคงที่การแปลเชิงพื้นที่ | โมเมนตัมเชิงเส้น |
| ค่าคงที่การหมุน | โมเมนตัมเชิงมุม |
| ค่าคงที่ของเกจ | ค่าไฟฟ้า |
นี่เป็นหนึ่งในผลลัพธ์ที่ลึกที่สุดในวิชาฟิสิกส์ทั้งหมด โดยเชื่อมโยงเรขาคณิตของกาลอวกาศกับกฎการอนุรักษ์ขั้นพื้นฐาน

## กลศาสตร์วงโคจร
### กฎของเคปเลอร์
| กฎหมาย | คำชี้แจง |
|-----|-----------|
| **ตัวแรก (วงรี)** | ดาวเคราะห์เคลื่อนที่เป็นวงรีโดยมีดวงอาทิตย์อยู่ที่จุดโฟกัสเดียว |
| **ที่สอง (พื้นที่เท่ากัน)** | เส้นจากดวงอาทิตย์ไปยังดาวเคราะห์กวาดพื้นที่เท่ากันในเวลาเท่ากัน |
| **ที่สาม (ฮาร์มอนิก)** | T² ∝ a³ (คาบกำลังสองเป็นสัดส่วนกับกึ่งแกนเอกยกกำลังสาม) |
### พลังงานวงโคจร
E = ½mv² - GMm/r
| อี | ประเภทวงโคจร |
|---|-----------|
| E< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 | ไฮเปอร์โบลิก (ไม่ผูกมัด) |
### หลบหนีความเร็ว
v_escape = √(2GM/R)
สำหรับโลก: v_escape ➤ 11.2 กม./วินาที

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดกลศาสตร์ | ใบสมัคร |
|------------------|-------------|
| กฎของนิวตัน | เครื่องยนต์ฟิสิกส์ในการจำลอง เกม AI หุ่นยนต์ |
| วิธีพลังงาน | โมเดลประหยัดพลังงาน, เครือข่าย Hopfield, เครื่องจักร Boltzmann |
| กลศาสตร์ลากรองจ์ | โครงข่ายประสาทเทียมตามหลักฟิสิกส์ การควบคุมที่เหมาะสม การเพิ่มประสิทธิภาพวิถี
| กลศาสตร์แฮมิลตัน | โครงข่ายประสาทเทียมแฮมิลตัน (HNN) ผู้บูรณาการเชิงสัญลักษณ์สำหรับการจำลอง
| กฎหมายการอนุรักษ์ | อคติแบบอุปนัยในโมเดล ML โครงข่ายประสาทเทียมที่เท่าเทียมกัน |
| ทฤษฎีบทของโนเธอร์ | การเรียนรู้ของเครื่องที่รับรู้ถึงสมมาตร การเรียนรู้เชิงลึกเชิงเรขาคณิต |
| ไดนามิกของร่างกายที่เข้มงวด | การจำลองหุ่นยนต์ พลศาสตร์โมเลกุล แอนิเมชั่น 3 มิติ |

## สรุป
| กรอบ | สมการแกนกลาง | ความแข็งแกร่ง |
|----------|--------------|----------|
| นิวตัน | **F** = ม**ก** | การวิเคราะห์แรงโดยตรงที่ใช้งานง่าย |
| ลากรองจ์ | d/dt(∂L/∂q̇) − ∂L/∂q = 0 | ไร้พิกัด จัดการข้อจำกัด |
| แฮมิลตัน | q̇ = ∂H/∂p, ṗ = −∂H/∂q | โครงสร้าง Symplectic เชื่อมต่อกับ QM |

กลศาสตร์แบบคลาสสิกไม่ได้เป็นเพียงเกี่ยวกับลูกบอลที่ตกลงมาและการแกว่งลูกตุ้มเท่านั้น กรอบทางคณิตศาสตร์ของมัน — กลศาสตร์ลากรองจ์และแฮมิลตัน — เป็นหนึ่งในแนวคิดที่มีอิทธิพลมากที่สุดในทางวิทยาศาสตร์ทั้งหมด โดยกล่าวถึงกลศาสตร์ควอนตัม ทฤษฎีภาคสนาม และแม้แต่การเรียนรู้ของเครื่องสมัยใหม่ โดยที่แบบจำลองที่ใช้พลังงานและโครงข่ายประสาทเทียมที่อิงตามฟิสิกส์ดึงมาจากสูตรที่มีอายุหลายศตวรรษเหล่านี้โดยตรง
