# การเพิ่มประสิทธิภาพ
การเพิ่มประสิทธิภาพเป็นคณิตศาสตร์ในการค้นหาวิธีแก้ปัญหาที่ดีที่สุดจากชุดวิธีแก้ปัญหาที่เป็นไปได้ มันถามว่า: เมื่อพิจารณาจากฟังก์ชันและข้อจำกัดแล้ว อินพุตใดที่จะย่อ (หรือขยาย) เอาต์พุตให้เหลือน้อยที่สุด การเพิ่มประสิทธิภาพเป็นกลไกของการเรียนรู้ของเครื่อง การฝึกโมเดลหมายถึงการลดฟังก์ชันที่สูญเสียให้เหลือน้อยที่สุด ปรากฏอยู่ในการวิจัยการดำเนินงาน เศรษฐศาสตร์ การออกแบบทางวิศวกรรม และแทบทุกสาขาเชิงปริมาณ
---

## การกำหนดปัญหา
**ปัญหาการเพิ่มประสิทธิภาพ** ทั่วไปมีรูปแบบดังนี้:
ย่อขนาด f(x) ให้เล็กสุด
ขึ้นอยู่กับ: gᵢ(x) ≤ 0 (ข้อจำกัดของความไม่เท่าเทียมกัน), hⱼ(x) = 0 (ข้อจำกัดของความเท่าเทียมกัน)
| ระยะเวลา | ความหมาย |
|------|---------|
| **ฟังก์ชันวัตถุประสงค์** f(x) | ปริมาณที่จะย่อให้เล็กสุด (หรือสูงสุด) |
| **ตัวแปรการตัดสินใจ** x | ค่าที่เราสามารถควบคุมได้ |
| **ภูมิภาคที่เป็นไปได้** | เซตของ x ทั้งหมดเป็นไปตามข้อจำกัดทั้งหมด |
| **ขั้นต่ำทั่วโลก** | เป็นไปได้ x* โดยมี f(x*) ≤ f(x) สำหรับ x | ที่เป็นไปได้ทั้งหมด
| **ขั้นต่ำในประเทศ** | เป็นไปได้ x* โดยมี f(x*) ≤ f(x) สำหรับ x ที่เป็นไปได้ทั้งหมดในบางพื้นที่ |
| **ปัญหานูน** | f คือนูน พื้นที่ที่เป็นไปได้คือเซตนูน (นาทีท้องถิ่น = นาทีทั่วโลก) |
---

## การเขียนโปรแกรมเชิงเส้น (LP)
เมื่อทั้งวัตถุประสงค์และข้อจำกัดทั้งหมดเป็นแบบ **เชิงเส้น** ปัญหาก็คือโปรแกรมเชิงเส้น
### แบบฟอร์มมาตรฐาน
ย่อเล็กสุด
ขึ้นอยู่กับ: ขวาน ≤ b, x ≥ 0
โดยที่ c, x ∈ ℝⁿ, A ∈ ℝᵐˣⁿ, b ∈ ℝᵐ
### คุณสมบัติ
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ความนูน | LP เป็นปัญหานูนเสมอ |
| ทางออกที่ดีที่สุด | อยู่ที่จุดยอด (จุดมุม) ของโพลีโทปที่เป็นไปได้เสมอ |
| การดำรงอยู่ | หากขอบเขตที่เป็นไปได้มีขอบเขตและไม่ว่างเปล่า แสดงว่ามีวิธีแก้ไขที่เหมาะสมที่สุด |
| ออพติมาหลายรายการ | หากจุดยอดสองจุดเหมาะสมที่สุด ทุกจุดบนขอบระหว่างจุดยอดทั้งสองจุดก็จะเหมาะสม | เช่นกัน
### วิธี Simplex
**วิธีซิมเพล็กซ์** (Dantzig, 1947) เคลื่อนที่ไปตามขอบของโพลีโทปที่เป็นไปได้จากจุดยอดหนึ่งไปอีกจุดหนึ่ง โดยจะปรับปรุงวัตถุประสงค์อยู่เสมอ จนกว่าจะถึงจุดที่เหมาะสมที่สุด
| คุณสมบัติ | ค่า |
|----------|-------|
| เวลาที่เลวร้ายที่สุด | O(2ⁿ) (เลขชี้กำลัง — หายากในทางปฏิบัติ) |
| เวลากรณีเฉลี่ย | พหุนามสำหรับปัญหาเชิงปฏิบัติส่วนใหญ่ |
| แนวคิดหลัก | ย้ายไปยังจุดยอดที่อยู่ติดกันโดยมีค่าวัตถุประสงค์ที่ดีกว่า |
**อัลกอริทึม (ภาพรวม):**
1. เริ่มต้นจากวิธีแก้ปัญหาพื้นฐานที่เป็นไปได้ (จุดยอดของโพลีโทป)
2. เลือกตัวแปรเข้า (ตัวแปรที่ปรับปรุงวัตถุประสงค์)
3. เลือกตัวแปรการทิ้ง (รักษาความเป็นไปได้)
4. Pivot: ย้ายไปยังจุดยอดใหม่
5. ทำซ้ำจนกว่าจะไม่มีทิศทางที่ดีขึ้น
### วิธีจุดภายใน
ทางเลือกแทนซิมเพล็กซ์: เข้าใกล้จุดที่เหมาะสมที่สุดจากภายในภูมิภาคที่เป็นไปได้
| คุณสมบัติ | ค่า |
|----------|-------|
| เวลาที่เลวร้ายที่สุด | พหุนาม (O(n³·⁵) สำหรับตัวแปรบางตัว) |
| ประสิทธิภาพการปฏิบัติ | แข่งขันกับซิมเพล็กซ์กับปัญหาใหญ่ |
| แนวคิดหลัก | เดินตาม "เส้นทางสายกลาง" ผ่านภายใน |
### ตัวอย่าง LP ที่ทำงานแล้ว
**ปัญหา:** โรงงานแห่งหนึ่งผลิตเก้าอี้ (x₁) และโต๊ะ (x₂)
- กำไร: $30 ต่อเก้าอี้, $50 ต่อโต๊ะ
- ไม้: 2x₁ + 4x₂ ≤ 100 (มีขากระดาน)
- แรงงาน: x₁ + 3x₂ ≤ 60 (ชั่วโมงที่มี)
- ขยายใหญ่สุด: 30x₁ + 50x₂
**วิธีแก้ปัญหา (วิธีกราฟิกสำหรับ 2 ตัวแปร):**
- จุดยอดของภูมิภาคที่เป็นไปได้: (0,0), (30,0), (40,10), (0,20)
- ประเมินวัตถุประสงค์ที่แต่ละจุดยอด:
  - (0,0): กำไร = 0
  - (30,0): กำไร = 900
  - (40,10): กำไร = 1,700 ← เหมาะสมที่สุด
  - (0,20): กำไร = 1,000
- **เหมาะสมที่สุด:** x₁ = เก้าอี้ 40 ตัว, x₂ = 10 โต๊ะ, กำไร = $1,700

## การเพิ่มประสิทธิภาพนูน
ปัญหาจะ **นูน** ถ้าฟังก์ชันวัตถุประสงค์นูนและพื้นที่ที่เป็นไปได้คือเซตนูน
### ชุดและฟังก์ชั่นนูน
| แนวคิด | คำจำกัดความ |
|---------|------------|
| **ชุดนูน** | สำหรับ x, y ใดๆ ที่อยู่ในเซตและ t ∈ [0,1]: tx + (1−t)y ก็อยู่ในเซตด้วย |
| **ฟังก์ชันนูน** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) สำหรับทุก t ∈ [0,1] |
| **นูนอย่างเคร่งครัด** | อสมการเข้มงวดสำหรับ t ∈ (0,1) และ x ≠ y |
**คุณสมบัติหลัก:** สำหรับการเพิ่มประสิทธิภาพแบบนูน ทุกค่าต่ำสุดในพื้นที่คือค่าต่ำสุดโดยรวม
### ฟังก์ชั่นนูนทั่วไป
| ฟังก์ชัน | นูน? | ที่ไหน |
|----------|---------|--------|
| ขวาน + b (เชิงเส้น) | ใช่ (และเว้า) | ทุกที่ |
| x² | ใช่ | ℝ |
| อีˣ | ใช่ | ℝ |
| −ล็อก(x) | ใช่ | x > 0 |
| \|x\|ᵖ (p ≥ 1) | ใช่ | ℝⁿ |
| สูงสุด(f₁, f₂) ถ้า f₁, f₂ นูน | ใช่ | จุดตัดของโดเมน |
### ไล่ระดับโคตร
อัลกอริธึมการปรับให้เหมาะสมขั้นพื้นฐานที่สุดในการเรียนรู้ของเครื่อง
**กฎการอัปเดต:** x_{k+1} = x_k − α∇f(x_k)
โดยที่ α > 0 คือ **อัตราการเรียนรู้** (ขนาดขั้นตอน)
| ตัวแปร | อัปเดตกฎ | ข้อได้เปรียบ |
|---------|-------------|-----------|
| **ชุด GD** | x ← x − α∇f(x) | การบรรจบกันอย่างมั่นคง |
| **สโตแคสติก GD (SGD)** | x ← x − α∇fᵢ(x) (หนึ่งตัวอย่าง) | รวดเร็วต่อการวนซ้ำ หลีกเลี่ยงค่าต่ำสุดของท้องถิ่น |
| **มินิแบทช์ SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | ยอดคงเหลือระหว่างแบทช์และสุ่ม |
| **โมเมนตัม** | v ← βv − α∇f(x); x ← x + วี | เร่งความเร็วผ่านพื้นที่ราบ |
| **อดัม** | อัตราการเรียนรู้แบบปรับเปลี่ยนได้ต่อพารามิเตอร์ | ทำงานได้ดีนอกกรอบสำหรับการเรียนรู้เชิงลึก |
| **RMSprop** | ปรับขนาดอัตราการเรียนรู้โดยใช้ค่าเฉลี่ยของขนาดการไล่ระดับสี | เหมาะสำหรับ RNN |
### อัตราการบรรจบกัน
| วิธีการ | นูนฉ | นูนอย่างยิ่ง f |
|----------------------|----------|-------------------|
| โคตรลาด | O(1/k) | O((1−μ/L)ᵏ) (เชิงเส้น) |
| ดอลลาร์สิงคโปร์ | O(1/√k) | O(1/k) |
| เร่ง GD (Nesterov) | O(1/k²) | O((1−√(ไมโคร/ลิตร))ᵏ) |
โดยที่ k = จำนวนการวนซ้ำ, μ = พารามิเตอร์นูนสูง, L = ค่าคงที่ลิปชิตซ์
### การเลือกอัตราการเรียนรู้
| กลยุทธ์ | คำอธิบาย |
|----------|-------------|
| แก้ไข α | เรียบง่าย แต่อาจแยกออก (ใหญ่เกินไป) หรือมาบรรจบกันช้า (เล็กเกินไป) |
| ค้นหาบรรทัด | ค้นหา α ที่ย่อ f(x − α∇f(x)) ให้เล็กสุดตามทิศทางการไล่ระดับสี |
| ตารางการสลายตัว | α_t = α₀ / (1 + βt) หรือ α_t = α₀ · βᵗ |
| วอร์มอัพ | เริ่มจากเล็กๆ เพิ่มขึ้น แล้วสลายตัว (พบได้ทั่วไปในการฝึกหม้อแปลงไฟฟ้า) |
| ปรับตัว (อดัม) | อัตราการเรียนรู้ต่อพารามิเตอร์ตามสถิติการไล่ระดับสี |

## การเพิ่มประสิทธิภาพที่มีข้อจำกัด
### ตัวคูณลากรองจ์
สำหรับปัญหา: ลดค่า f(x) ให้เหลือ h(x) = 0
**ลากรองจ์:** L(x, แลมบ์ดา) = f(x) + แลมฮ์(x)
ที่ค่าที่เหมาะสมที่สุด: ∇ₓL = 0 และ ∇_λL = 0 (ซึ่งให้ h(x) = 0)
**ตัวอย่างการทำงาน:** ย่อ f(x,y) = x² + y² ให้เหลือ x + y = 1
- L = x² + y² + แล(x + y − 1)
- ∂L/∂x = 2x + แล = 0 → x = −แล/2
- ∂L/∂y = 2y + แล = 0 → y = −แล/2
- ข้อจำกัด: x + y = 1 → −แล = 1 → แล = −1
- วิธีแก้: x = 1/2, y = 1/2, f = 1/2
### เงื่อนไข KKT
เงื่อนไข **Karush-Kuhn-Tucker (KKT)** จะทำให้ตัวคูณ Lagrange มีลักษณะทั่วไปตามข้อจำกัดของความไม่เท่าเทียมกัน
สำหรับ: ย่อ f(x) ให้เหลือ gᵢ(x) ≤ 0, hⱼ(x) = 0
**ลากรองจ์:** L(x, แลมบ์ดา, ν) = f(x) + Σᵢ ladᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**เงื่อนไข KKT** (จำเป็นสำหรับการเพิ่มประสิทธิภาพ):
| สภาพ | สมการ |
|----------|----------|
| ความคงที่ | ∇ₓL = 0 |
| ความเป็นไปได้เบื้องต้น | กᵢ(x) ≤ 0, hⱼ(x) = 0 |
| ความเป็นไปได้แบบคู่ | แลมบ์ ≥ 0 |
| ความหย่อนคล้อยเสริม | γᵢgᵢ(x) = 0 สำหรับ i | ทั้งหมด
**ความหย่อนเสริม** หมายถึง: หากข้อจำกัด gᵢ ไม่ได้ใช้งานอยู่ (gᵢ(x) < 0) ดังนั้น แลม = 0 (ข้อจำกัดไม่ส่งผลต่อวิธีแก้ปัญหา)
สำหรับปัญหานูนที่เป็นไปตามเงื่อนไขของสเลเตอร์ เงื่อนไข KKT นั้นมีความจำเป็นและเพียงพอ

## ความเป็นคู่
ปัญหาการปรับให้เหมาะสมทุกปัญหา (**เบื้องต้น**) มีปัญหา **คู่** ที่เกี่ยวข้อง
### ความเป็นคู่ที่อ่อนแอและแข็งแกร่ง
| แนวคิด | คำชี้แจง |
|---------|-----------|
| **ฟังก์ชั่นคู่** | ก.(แล, ν) = อินฟₓ L(x, แล, ν) |
| **ปัญหาคู่** | เพิ่ม g(แลมบ์ดา, ν) ให้ใหญ่สุด โดยขึ้นอยู่กับ แลมบ์ดา ≥ 0 |
| **ความเป็นคู่ที่อ่อนแอ** | สองค่าที่เหมาะสมที่สุด ≤ ค่าที่เหมาะสมที่สุด (คงไว้เสมอ) |
| **ความเป็นคู่ที่แข็งแกร่ง** | Dual optimum = Primal optimum (ถือเป็นปัญหานูนกับเงื่อนไขของ Slater) |
| **ช่องว่างความเป็นคู่** | Primal Optimal − Dual Optimize (ศูนย์ภายใต้ความเป็นคู่ที่แข็งแกร่ง) |
### ทำไมความเป็นคู่จึงมีความสำคัญ
| ใบสมัคร | Duality ช่วยได้อย่างไร |
|-----------------|-------------------|
| ขอบเขตล่าง | Dual ให้ใบรับรองว่าโซลูชันเบื้องต้นนั้นดีเพียงใด |
| SVM | ปัญหาคู่ของ SVM นำไปสู่เคล็ดลับเคอร์เนล |
| การวิเคราะห์ความไว | ตัวแปรคู่จะวัดว่าการเปลี่ยนแปลงที่เหมาะสมที่สุดมากเพียงใดหากข้อจำกัดผ่อนคลาย |
| การสลายตัว | ปัญหาใหญ่สามารถแบ่งออกเป็นปัญหาย่อยได้โดยใช้ dual |

## การเขียนโปรแกรมจำนวนเต็ม
เมื่อตัวแปรบางส่วนหรือทั้งหมดต้องเป็น **จำนวนเต็ม** ปัญหาจะยากขึ้นมาก (โดยทั่วไป NP-hard)
### ประเภท
| พิมพ์ | คำอธิบาย |
|-|-------------|
| เพียวไอพี | ตัวแปรทั้งหมดต้องเป็นจำนวนเต็ม |
| IP แบบผสม (MIP) | ตัวแปรบางตัวเป็นจำนวนเต็ม บางตัวต่อเนื่อง |
| IP ไบนารี | ตัวแปรจำกัดอยู่ที่ {0, 1} |
### วิธีการแก้ไข
| วิธีการ | ไอเดีย |
|--------|-|
| **สาขาและผูกพัน** | แตกประเด็นย่อย แก้ LP ผ่อนคลาย ตัด |
| **การตัดเครื่องบิน** | เพิ่มข้อจำกัดเชิงเส้นเพื่อกระชับการผ่อนคลาย LP |
| **กิ่งและตัด** | รวมกิ่งและขอบเขตเข้ากับระนาบการตัด |
| **ฮิวริสติกส์** | โลภค้นหาในท้องถิ่นจำลองการหลอมเพื่อหาวิธีแก้ปัญหาโดยประมาณ |

## วิธีการศึกษาแบบฮิวริสติกและเมทาฮิวริสติก
เมื่อการเพิ่มประสิทธิภาพที่แน่นอนนั้นทำได้ยาก การวิเคราะห์พฤติกรรมจะค้นหาวิธีแก้ปัญหาที่ดี (ไม่จำเป็นต้องเหมาะสมที่สุด)
| วิธีการ | แนวคิดหลัก | ดีที่สุดสำหรับ |
|--------|----------|----------|
| **ไล่ระดับโคตร** | เดินตามทางลงที่ชันที่สุด | ฟังก์ชั่นที่ราบรื่นและหาความแตกต่างได้ |
| **วิธีของนิวตัน** | ใช้ข้อมูลลำดับที่สอง (ความโค้ง) | เรียบเนียนทุกปัญหา |
| **จำลองการหลอม** | ยอมรับวิธีแก้ปัญหาที่แย่กว่าโดยมีความน่าจะเป็นลดลง | การเพิ่มประสิทธิภาพระดับโลก, การรวมกัน |
| **อัลกอริธึมทางพันธุกรรม** | พัฒนาประชากรโดยใช้การเลือก ครอสโอเวอร์ การกลายพันธุ์ | หลายวัตถุประสงค์, ไม่สามารถแยกแยะได้ |
| **ฝูงอนุภาค** | เจ้าหน้าที่สำรวจอวกาศโดยได้รับอิทธิพลจากตำแหน่งที่โด่งดังที่สุด | ต่อเนื่องไม่นูน |
| **การเพิ่มประสิทธิภาพแบบเบย์** | สร้างแบบจำลองตัวแทน ใช้ฟังก์ชันการรับข้อมูล | ฟังก์ชั่นกล่องดำราคาแพง (การปรับไฮเปอร์พารามิเตอร์) |
### วิธีการเพิ่มประสิทธิภาพของนิวตัน
**กฎการอัปเดต:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
โดยที่ H คือเมทริกซ์ Hessian (เมทริกซ์ของอนุพันธ์อันดับสอง)
| คุณสมบัติ | ค่า |
|----------|-------|
| อัตราการบรรจบกัน | กำลังสอง (ใกล้ค่าเหมาะสมที่สุด) |
| ต้นทุนต่อการวนซ้ำ | O(n³) สำหรับการผกผันของ Hessian |
| ต้องใช้ | สามารถหาอนุพันธ์ได้สองเท่า Hessian | ที่แน่นอนเชิงบวก
| เสมือนนิวตัน (BFGS) | Hessian โดยประมาณจากการไล่ระดับสี | O(n²) ต่อการวนซ้ำ |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดการเพิ่มประสิทธิภาพ | ใบสมัคร |
|---------------------|-------------|
| โคตรลาด | การฝึกอบรมโครงข่ายประสาทเทียม การถดถอยโลจิสติก โมเดลเชิงอนุพันธ์ใดๆ
| SGD และตัวแปร | ML ขนาดใหญ่ (การฝึกอบรมชุดย่อย) การเรียนรู้ออนไลน์ |
| อดัม, RMSprop | เครื่องมือเพิ่มประสิทธิภาพเริ่มต้นสำหรับการเรียนรู้เชิงลึก |
| การเพิ่มประสิทธิภาพนูน | SVM, การถดถอยโลจิสติก, LASSO, Ridge (รับประกันประสิทธิภาพสูงสุดระดับโลก)
| ตัวคูณลากรองจ์ | การเรียนรู้ที่มีข้อจำกัด, ML ที่ยุติธรรม, การจัดสรรทรัพยากร |
| เงื่อนไข KKT | การได้มาของ SVM แบบคู่ การทำความเข้าใจกิจกรรมข้อจำกัด
| ความเป็นคู่ | เคล็ดลับเคอร์เนล SVM การวิเคราะห์ความไว วิธีการสลายตัว |
| การเขียนโปรแกรมเชิงเส้น | การจัดสรรทรัพยากร การเพิ่มประสิทธิภาพพอร์ตโฟลิโอ การไหลของเครือข่าย |
| การเขียนโปรแกรมจำนวนเต็ม | การเลือกคุณสมบัติ (ไบนารี่) การกำหนดเวลา ปัญหาเชิงผสม |
| การเพิ่มประสิทธิภาพแบบเบย์ | การปรับไฮเปอร์พารามิเตอร์ (Optuna, Hyperopt) |
| นิวตัน/กึ่งนิวตัน | วิธีการลำดับที่สองสำหรับปัญหาขนาดเล็กถึงปานกลาง (L-BFGS) |

## สรุป
| วิธีการ | ประเภทปัญหา | การค้ำประกัน | สเกล |
|--------|-------------|------------|-------|
| เริมซ์ | การเขียนโปรแกรมเชิงเส้น | เหมาะสมที่สุด | ตัวแปรนับล้าน |
| จุดภายใน | นูน (LP, QP, SOCP) | เหมาะสมที่สุด | ขนาดใหญ่ |
| โคตรลาด | เรียบเนียนไม่มีข้อจำกัด | มาบรรจบกันที่ min | ใหญ่มาก (การเรียนรู้เชิงลึก) |
| ดอลลาร์สิงคโปร์ | ความเสี่ยงเชิงประจักษ์ขนาดใหญ่ | มาบรรจบกัน (ด้วยความเสื่อมโทรม) | ชุดข้อมูลขนาดใหญ่ |
| นิวตัน / บีเอฟจีเอส | ราบรื่น แตกต่างได้สองเท่า | การบรรจบกันกำลังสอง | ขนาดเล็กถึงขนาดกลาง |
| เคเคที / ลากรองจ์ | ข้อจำกัด (นูน) | ตรงตามเงื่อนไข | ปานกลาง |
| สาขาและผูกพัน | การเขียนโปรแกรมจำนวนเต็ม | เหมาะสมที่สุด | ขนาดเล็กถึงขนาดกลาง |
| ฮิวริสติกส์ | ใดๆ (ไม่นูน, เชิงรวมกัน) | ไม่มีการรับประกัน | ต่างกันไป |
การเพิ่มประสิทธิภาพถือเป็นเครื่องมือทางคณิตศาสตร์ที่สำคัญที่สุดในการเรียนรู้ของเครื่อง ทุกโมเดลที่คุณฝึกฝน ตั้งแต่การถดถอยเชิงเส้นไปจนถึงโมเดลภาษาขนาดใหญ่ เกี่ยวข้องกับการแก้ปัญหาการปรับให้เหมาะสม การทำความเข้าใจเมื่อปัญหาปรากฏออกมา (รับประกันว่าเหมาะสมที่สุดทั่วโลก) เมื่อการไล่ระดับสีจะมาบรรจบกัน และวิธีการจัดการกับข้อจำกัด จะทำให้คุณมีพื้นฐานทางทฤษฎีในการออกแบบ แก้ไขจุดบกพร่อง และปรับปรุงอัลกอริทึมการเรียนรู้
