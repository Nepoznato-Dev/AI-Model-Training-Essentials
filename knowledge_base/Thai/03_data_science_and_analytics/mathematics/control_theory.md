# ทฤษฎีการควบคุม
ทฤษฎีการควบคุมคือคณิตศาสตร์ในการทำให้ระบบทำงานตามที่คุณต้องการ ตั้งแต่เทอร์โมสตัทไปจนถึงระบบอัตโนมัติ จากแขนหุ่นยนต์ไปจนถึงเครื่องปฏิกรณ์เคมี ระบบควบคุมจะตรวจจับ ตัดสินใจ และดำเนินการเพื่อรักษาพฤติกรรมที่ต้องการ สาขานี้มอบเครื่องมือที่เข้มงวดสำหรับการวิเคราะห์ความเสถียร ประสิทธิภาพ และความทนทาน ซึ่งเป็นแนวคิดที่ได้ย้ายไปสู่การเรียนรู้แบบเสริมกำลัง การปรับแต่งไฮเปอร์พารามิเตอร์ และระบบที่ปรับเปลี่ยนได้

## แนวคิดพื้นฐาน
### Open-Loop กับ Closed-Loop
| พิมพ์ | คำอธิบาย | ตัวอย่าง | ข้อได้เปรียบ |
|------|-------------|---------|-----------|
| **เปิดวง** | ควบคุมการดำเนินการโดยไม่ขึ้นกับเอาต์พุต | ตัวจับเวลาเครื่องซักผ้า | ง่ายๆ ไม่ต้องใช้เซนเซอร์ |
| **วงปิด (ผลตอบรับ)** | การดำเนินการควบคุมขึ้นอยู่กับเอาต์พุต | เทอร์โมสตัท, ระบบควบคุมความเร็วอัตโนมัติ | ปฏิเสธสิ่งรบกวน แข็งแกร่ง |
### องค์ประกอบไดอะแกรมบล็อก
| องค์ประกอบ | สัญลักษณ์ | ฟังก์ชัน |
|---------|--------|----------|
| **พืช** | กรัม | ระบบควบคุม |
| **ตัวควบคุม** | ค(s) | การดำเนินการควบคุมการคำนวณ |
| **เซ็นเซอร์** | H(s) | วัดเอาต์พุต |
| **ทางแยกสรุป** | ⊕ | ข้อผิดพลาดในการคำนวณ: r − y |
| **อ้างอิง** | r(t) | เอาต์พุตที่ต้องการ |
| **ข้อผิดพลาด** | e(t) = r(t) − y(t) | ความแตกต่างระหว่างที่ต้องการและที่เกิดขึ้นจริง |
| **การรบกวน** | ง(t) | อินพุตที่ไม่พึงประสงค์ส่งผลกระทบต่อโรงงาน |
### ฟังก์ชั่นการถ่ายโอนแบบวงปิด
สำหรับระบบตอบรับเชิงลบมาตรฐาน:
T(s) = C(s)G(s) / (1 + C(s)G(s)H(s))
| ปริมาณ | สูตร |
|----------|---------|
| ฟังก์ชันการถ่ายโอนแบบวงเปิด | L(s) = C(s)G(s)H(s) |
| ฟังก์ชันการถ่ายโอนแบบวงปิด | T(s) = L(s)/H(s) / (1 + L(s)) |
| ฟังก์ชั่นถ่ายโอนข้อผิดพลาด | E(s)/R(s) = 1 / (1 + L(s)) |
| ความไว | S(s) = 1 / (1 + L(s)) |

## ฟังก์ชั่นการถ่ายโอน
**ฟังก์ชันการถ่ายโอน** H(s) = Y(s)/X(s) อธิบายความสัมพันธ์อินพุต-เอาต์พุตของระบบเชิงเส้นไม่แปรผันตามเวลา (LTI) ในโดเมน Laplace
### แบบฟอร์มมาตรฐาน
| ระบบ | ฟังก์ชั่นการถ่ายโอน | พารามิเตอร์ |
|--------|-------------------|------------|
| **สั่งซื้อครั้งแรก** | K/(τs + 1) | K = ได้รับ, τ = ค่าคงที่เวลา |
| **ลำดับที่สอง** | Kωₙ²/(s² + 2ζωₙs + ωₙ²) | ωₙ = ความถี่ธรรมชาติ ζ = อัตราส่วนการทำให้หมาด ๆ |
| **ผู้บูรณาการ** | เค/เอส | — |
| **ความแตกต่าง** | คริส | — |
| **ล่าช้า** | อี^{−sT_d} | T_d = การหน่วงเวลา |
### พฤติกรรมของระบบลำดับที่สอง
| อัตราส่วนการทำให้หมาด ๆ ζ | พฤติกรรม | ตำแหน่งขั้วโลก |
|-----------------|-----------|---------------|
| ζ = 0 | การสั่นแบบไม่หน่วง | จินตนาการล้วนๆ |
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 | Overdamped (ช้า ไม่สั่น) | จริงแตกต่าง |
### ตัวชี้วัดประสิทธิภาพ (การตอบสนองขั้นตอน)
| เมตริก | สูตร (ลำดับที่ 2, underdamped) | คำอธิบาย |
|--------|----------------------------------|-----------------|
| เวลาเพิ่มขึ้น (t_r) | อยู่ที่ 1.8/ωₙ | ถึงเวลาเปลี่ยนจาก 10% เป็น 90% |
| เวลาสูงสุด (t_p) | π/(ωₙ√(1−ζ²)) | ถึงเวลาสูงสุดครั้งแรก |
| เกิน (M_p) | e^{−πζ/√(1−ζ²)} × 100% | จุดสูงสุดสูงสุดเหนือค่าสุดท้าย |
| เวลาในการปักหลัก (t_s) | ➤ 4/(ζωₙ) | เวลาที่จะอยู่ภายใน 2% ของสุดท้าย |
| ข้อผิดพลาดในสถานะคงตัว | ขึ้นอยู่กับประเภทของระบบ | ความแตกต่างระหว่างที่ต้องการและความเป็นจริงเป็น t → ∞ |

## ตัวควบคุม PID
**ตัวควบคุม PID** เป็นตัวควบคุมที่ใช้กันอย่างแพร่หลายที่สุดในอุตสาหกรรม (มากกว่า 90% ของตัวควบคุมทางอุตสาหกรรม)
### สูตรพีไอดี
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
ในโดเมนลาปลาซ: C(s) = K_p + K_i/s + K_d s
| ระยะเวลา | เอฟเฟกต์ | มากเกินไป | น้อยเกินไป |
|------|--------|----------|------------|
| **สัดส่วน (K_p)** | ตอบสนองต่อข้อผิดพลาดปัจจุบัน | การสั่น ความไม่แน่นอน | ตอบสนองช้า ข้อผิดพลาดใหญ่ |
| **อินทิกรัล (K_i)** | ขจัดข้อผิดพลาดในสภาวะคงตัว | โอเวอร์ชูต, การสั่น | ออฟเซ็ตถาวร |
| **อนุพันธ์ (K_d)** | ทำนายข้อผิดพลาดในอนาคต (ทำให้หมาด ๆ) | การขยายสัญญาณรบกวน | การปฏิเสธการรบกวนที่ไม่ดี |
### วิธีการปรับแต่ง PID
| วิธีการ | วิธีการ |
|--------|----------|
| **ซีกเลอร์-นิโคลส์** | เพิ่ม K_u จนกระทั่งเกิดการสั่น ใช้ K_u และจุด P_u เพื่อตั้งค่ากำไร |
| **โคเฮน-คูน** | ขึ้นอยู่กับพารามิเตอร์การตอบสนองขั้นตอน (เกน, เวลาคงที่, เวลาตาย) |
| **IMC (การควบคุมโมเดลภายใน)** | ขึ้นอยู่กับแบบจำลองกระบวนการ ให้ความทนทานที่ดี |
| **ปรับอัตโนมัติ** | การระบุตัวตนออนไลน์ + การปรับแต่ง (ตัวควบคุมที่ทันสมัยมากมาย) |
| **คู่มือ** | เริ่มต้นด้วย K_p เท่านั้น เพิ่ม K_i เพื่อลบออฟเซ็ต เพิ่ม K_d สำหรับการหน่วง |
### กฎของซีกเลอร์-นิโคลส์
1. ตั้งค่า K_i = K_d = 0
2. เพิ่ม K_p จนกระทั่งเกิดการสั่นอย่างต่อเนื่อง: อัตราขยายสูงสุด K_u, ช่วง P_u
3. กำหนดกำไร:
| ตัวควบคุม | K_p | เค_ไอ | K_d |
|-----------|-----|-----|-----|
| ป | 0.5K_u | — | — |
| พี่ | 0.45K_u | 1.2K_u/P_u | — |
| พีไอดี | 0.6K_u | 2K_u/P_u | K_u P_u/8 |

## การวิเคราะห์ความเสถียร
ระบบจะ **เสถียร** หากเอาต์พุตยังคงมีขอบเขตสำหรับอินพุตที่มีขอบเขต (ความเสถียรของ BIBO)
### เสถียรภาพตามเสา
| สภาพ | ความมั่นคง |
|----------|-----------|
| เสาทั้งหมดในครึ่งระนาบด้านซ้าย (Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) | ไม่เสถียร |
| เสาบนแกนจินตภาพ (Re(s) = 0) | เสถียรเล็กน้อย (หรือไม่เสถียรหากเกิดซ้ำ) |
### เกณฑ์ Routh-Hurwitz
กำหนดความเสถียรโดยไม่ต้องใช้เสาประมวลผลอย่างชัดเจน สร้างอาร์เรย์ Routh จากค่าสัมประสิทธิ์พหุนามลักษณะเฉพาะ
**กฎ:** จำนวนการเปลี่ยนแปลงเครื่องหมายในคอลัมน์แรกเท่ากับจำนวนเสาระนาบครึ่งขวา
### เกณฑ์ความเสถียรของ Nyquist
พล็อตการตอบสนองความถี่วงเปิด L(jω) ในระนาบเชิงซ้อน
**กฎ:** ระบบวงปิดจะเสถียรถ้าพล็อต Nyquist ล้อมรอบจุด (−1, 0) ทวนเข็มนาฬิกาจำนวนครั้งเท่ากับจำนวนเสาที่ไม่เสถียรของวงเปิด
**อัตรากำไรขั้นต้น:** อัตราขยายจะเพิ่มขึ้นได้เท่าใดก่อนที่จะเกิดความไม่เสถียร (ระยะห่างจากจุดลงจุดถึง −1 บนแกนจริง)
**ระยะขอบ:** ระยะหน่วงของเฟสจะเพิ่มขึ้นได้มากเพียงใดก่อนที่จะเกิดความไม่เสถียร (มุมจากจุดหนึ่งไปยังอีกวงกลมหนึ่งหน่วยที่ครอสโอเวอร์แบบเกน)
### การวิเคราะห์พล็อตลางบอกเหตุ
อัตราขยาย (dB) และเฟส (องศา) เทียบกับความถี่ (สเกลบันทึก)
| เมตริก | คำจำกัดความ | ค่าที่ต้องการ |
|--------|-----------|---------------|
| **กำไรขั้นต้น (GM)** | รับเพิ่มขึ้นถึง 0 dB ที่เฟส = −180° | > 6 เดซิเบล |
| **ระยะขอบ (PM)** | เฟสที่ครอสโอเวอร์เกน (0 dB) + 180° | > 45° |
| **รับครอสโอเวอร์** | ความถี่โดยที่กำไร = 0 dB | — |
| **เฟสครอสโอเวอร์** | ความถี่โดยที่เฟส = −180° | — |

## การเป็นตัวแทนรัฐ-อวกาศ
สำหรับระบบหลายอินพุตหลายเอาต์พุต (MIMO) รูปแบบพื้นที่ของรัฐจะเป็นธรรมชาติมากกว่าฟังก์ชันการถ่ายโอน
### แบบฟอร์มมาตรฐาน
ẋ(t) = Ax(t) + Bu(t) (สมการสถานะ)
y(t) = Cx(t) + Du(t) (สมการเอาท์พุต)
| เมทริกซ์ | ชื่อ | ขนาด |
|----------------------|-|-----------|
| ก | เมทริกซ์ระบบ/สถานะ | ไม่มี × n |
| บี | เมทริกซ์อินพุต | ไม่มี × ม. |
| ซี | เมทริกซ์เอาท์พุต | พี × เอ็น |
| ดี | เมทริกซ์ฟีดทรู | พี × ม. |
### ถ่ายโอนฟังก์ชันจากรัฐ-อวกาศ
G(s) = C(sI − A)⁻¹B + D
### การควบคุมและการสังเกต
| คุณสมบัติ | ทดสอบ | ความหมาย |
|----------|-|---------|
| **ควบคุมได้** | อันดับ[C_B] = n (โดยที่ C_B = [B, AB, A²B, ...]) | สามารถบังคับเลี้ยวได้ทุกรัฐ |
| **สังเกตได้** | อันดับ[O_B] = n (โดยที่ O_B = [C; CA; CA²; ...]) | สามารถกำหนดสถานะจากเอาต์พุต |
ระบบจะต้องสามารถควบคุมได้เพื่อให้มีเสถียรภาพโดยการป้อนกลับ และสามารถสังเกตได้สำหรับการประมาณค่าสถานะ
### คำติชมของรัฐ
u = −Kx + r (ผลป้อนกลับสถานะเต็ม)
วงปิด: ẋ = (A − BK)x + Br
**การวางตำแหน่งขั้ว:** เลือก K เพื่อให้ A − BK มีค่าลักษณะเฉพาะ (ขั้ว) ที่ต้องการ

## การควบคุมที่เหมาะสมที่สุด
### ตัวควบคุมกำลังสองเชิงเส้น (LQR)
ย่อเล็กสุด: J = ∫₀^∞ (xᵀQx + uᵀRu) dt
โดยที่ Q ≥ 0 (ต้นทุนของรัฐ) และ R > 0 (ต้นทุนการควบคุม)
**วิธีแก้ปัญหา:** u = −Kx โดยที่ K = R⁻¹BᵀP และ P แก้ **สมการริคคาติพีชคณิต:**
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
| การปรับ | เอฟเฟกต์ |
|--------|--------|
| เพิ่ม Q | ตอบสนองเร็วขึ้น ควบคุมได้มากขึ้น |
| เพิ่ม R | การตอบสนองช้าลง ความพยายามในการควบคุมน้อยลง |
| ถาม ≫ R | การควบคุมที่ดุดัน (เช่น K_p สูง) |
### ตัวกรองคาลมาน
ตัวประมาณสถานะที่เหมาะสมที่สุดสำหรับระบบเชิงเส้นที่มีสัญญาณรบกวนแบบเกาส์เซียน
**รุ่นของระบบ:**
ẋ = Ax + Bu + w (สัญญาณรบกวนกระบวนการ w ~ N(0, Q))
y = Cx + v (สัญญาณรบกวนในการวัด v ~ N(0, R))
**สมการตัวกรองคาลมาน:**
- ทำนาย: x̂⁻ = Ax̂ + Bu, P⁻ = APAᵀ + Q
- อัปเดต: K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻¹, x̂ = x̂⁻ + K(y − Cx̂⁻), P = (I − KC)P⁻
ตัวกรองคาลมานเป็นแบบคู่ LQR ซึ่งช่วยลดความแปรปรวนของข้อผิดพลาดในการประมาณค่าให้เหลือน้อยที่สุด

| ความสามารถในการสังเกต | เราจะอนุมานรัฐได้ไหม? | การทดสอบอันดับบนเมทริกซ์ความสามารถในการสังเกต |
| แอลคิวอาร์ | ข้อเสนอแนะสถานะที่เหมาะสมที่สุด | สมการริคคาติ |
| ตัวกรองคาลมาน | การประมาณค่าสถานะที่เหมาะสมที่สุด | รอบทำนาย-อัพเดท |
ทฤษฎีการควบคุมเป็นคณิตศาสตร์ในการทำให้ระบบทำสิ่งที่คุณต้องการ เชื่อถือได้ แข็งแกร่ง และมีประสิทธิภาพ หลักการของการป้อนกลับ ความเสถียร และการเพิ่มประสิทธิภาพได้รับการพิสูจน์แล้วว่าเป็นสากล โดยปรากฏในสาขาต่างๆ ตั้งแต่วิทยาการหุ่นยนต์ไปจนถึงการเรียนรู้แบบเสริมกำลัง จากเศรษฐศาสตร์ไปจนถึงชีววิทยา สำหรับนักวิทยาศาสตร์ข้อมูล ทฤษฎีการควบคุมจัดเตรียมภาษาสำหรับการทำความเข้าใจระบบที่ปรับเปลี่ยนได้ การออกแบบขั้นตอนการฝึกอบรมที่มั่นคง และสร้างตัวแทนอัจฉริยะที่โต้ตอบกับสภาพแวดล้อมแบบไดนามิก
