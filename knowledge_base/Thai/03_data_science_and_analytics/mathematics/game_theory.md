# ทฤษฎีเกม
ทฤษฎีเกมเป็นคณิตศาสตร์ของการโต้ตอบเชิงกลยุทธ์ ซึ่งเป็นสถานการณ์ที่ผลลัพธ์ของคุณไม่ได้ขึ้นอยู่กับการเลือกของคุณเองเท่านั้น แต่ยังขึ้นอยู่กับการเลือกของผู้อื่นด้วย ตั้งแต่สงครามราคาระหว่างบริษัทไปจนถึงการแข่งขันอาวุธนิวเคลียร์ จากการประมูลออนไลน์ไปจนถึงชีววิทยาเชิงวิวัฒนาการ ทฤษฎีเกมมอบเครื่องมือสำหรับการวิเคราะห์ความขัดแย้งและความร่วมมือ มีความเกี่ยวข้องมากขึ้นกับการเรียนรู้ของเครื่องผ่านการเรียนรู้การเสริมกำลังแบบหลายตัวแทน เครือข่ายปฏิปักษ์ทั่วไป (GAN) และการออกแบบกลไกสำหรับแพลตฟอร์มออนไลน์
---

## เกมรูปแบบเชิงกลยุทธ์
### คำนิยาม
**เกมรูปแบบเชิงกลยุทธ์ (รูปแบบปกติ)** ประกอบด้วย:
- ชุดของผู้เล่น N = {1, 2, ..., n}
- กลยุทธ์กำหนด S₁, S₂, ..., Sₙ สำหรับผู้เล่นแต่ละคน
- ฟังก์ชั่นผลตอบแทน u₁, u₂, ..., uₙ จับคู่โปรไฟล์กลยุทธ์กับตัวเลขจริง
### ตัวอย่าง: ภาวะที่กลืนไม่เข้าคายไม่ออกของนักโทษ
| | ให้ความร่วมมือ (C) | ข้อบกพร่อง (D) |
|---|---------------|------------|
| **ร่วมมือ (C)** | (−1, −1) | (−3, 0) |
| **ข้อบกพร่อง (D)** | (0, −3) | (−2, −2) |
| บทวิเคราะห์ | ผลลัพธ์ |
|---------||--------|
| กลยุทธ์ที่โดดเด่น | ข้อบกพร่อง (D ครอบงำ C สำหรับผู้เล่นทั้งสอง) |
| สมดุลของแนช | (D, D) พร้อมผลตอบแทน (−2, −2) |
| สังคมที่เหมาะสมที่สุด | (C, C) พร้อมผลตอบแทน (−1, −1) |
| ภาวะที่กลืนไม่เข้าคายไม่ออก | ความมีเหตุผลส่วนบุคคลนำไปสู่ความไร้เหตุผลโดยรวม |
### เกมคลาสสิคเพิ่มเติม
**การต่อสู้ของเพศ:**
| | โอเปร่า | ฟุตบอล |
|---|-------|----------|
| โอเปร่า | (2, 1) | (0, 0) |
| ฟุตบอล | (0, 0) | (1, 2) |
สมดุลของแนชสองรายการ: (โอเปร่า, โอเปร่า) และ (ฟุตบอล, ฟุตบอล)
**ไก่ (เหยี่ยว-นกพิราบ):**
| | เหยี่ยว | นกพิราบ |
|---|-------|-|
| เหยี่ยว | (−10, −10) | (5, 0) |
| นกพิราบ | (0, 5) | (1, 1) |
สมดุลของแนชสองตัว: (ฮอว์ก, โดฟ) และ (โดฟ, ฮอว์ก)

## กลยุทธ์ที่โดดเด่น
| แนวคิด | คำจำกัดความ |
|---------|------------|
| **โดดเด่นอย่างเคร่งครัด** | กลยุทธ์ sᵢ ให้ผลตอบแทนที่สูงกว่ากลยุทธ์อื่น ๆ โดยไม่คำนึงถึงตัวเลือกของฝ่ายตรงข้าม |
| **เด่นอย่างอ่อนแอ** | กลยุทธ์ sᵢ ให้ผลตอบแทนสูงเป็นอย่างน้อยและสูงกว่านั้นสำหรับโปรไฟล์คู่ต่อสู้บางราย |
| **กลยุทธ์ที่โดดเด่น** | กลยุทธ์ที่ไม่เคยมีการตอบรับที่ดีที่สุด |
**การกำจัดกลยุทธ์ที่โดดเด่นซ้ำแล้วซ้ำเล่า:**
1. ลบกลยุทธ์ที่มีอำนาจเหนือกว่าออก
2. ทำซ้ำจนไม่สามารถเอาออกได้อีก
3. หากโปรไฟล์กลยุทธ์หนึ่งยังคงอยู่ นั่นคือความสมดุลของ Nash ที่เป็นเอกลักษณ์

## สมดุลของแนช
**ความสมดุลของแนช** คือโปรไฟล์กลยุทธ์ที่ไม่มีผู้เล่นคนใดสามารถปรับปรุงผลตอบแทนของตนเองได้โดยการเปลี่ยนกลยุทธ์เพียงฝ่ายเดียว
### คำนิยาม
(s₁*, s₂*, ..., sₙ*) คือความสมดุลของแนช หากสำหรับผู้เล่นทุกคน i:
uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*) สำหรับทุก sᵢ ∈ Sᵢ
### ค้นหา Nash Equilibria (เกม 2 × 2)
**วิธีการตอบกลับที่ดีที่สุด:**
1. สำหรับแต่ละคอลัมน์ ให้ขีดเส้นใต้คำตอบที่ดีที่สุดของผู้เล่นคนที่ 1
2. ในแต่ละแถว ให้ขีดเส้นใต้คำตอบที่ดีที่สุดของผู้เล่นคนที่ 2
3. เซลล์ที่ขีดเส้นใต้ทั้งสองไว้คือสมดุลของแนช
### การดำรงอยู่ (ทฤษฎีบทของแนช)
ทุกเกมที่มีขอบเขตจำกัดจะมีความสมดุลของ Nash อย่างน้อยหนึ่งรายการ (อาจเป็นในกลยุทธ์แบบผสม)
### กลยุทธ์แบบผสม
**กลยุทธ์แบบผสม** คือการกระจายความน่าจะเป็นเหนือกลยุทธ์ล้วนๆ
| แนวคิด | คำจำกัดความ |
|---------|------------|
| กลยุทธ์แบบผสม σᵢ | การแจกแจงความน่าจะเป็นเหนือ Sᵢ |
| กลยุทธ์แบบผสม NE | ไม่มีผู้เล่นคนใดสามารถปรับปรุงผลตอบแทนที่คาดหวังได้โดยการเปลี่ยนส่วนผสม |
| สนับสนุน | ชุดกลยุทธ์ล้วนๆ ที่เล่นด้วยความน่าจะเป็นเชิงบวก |
**ตัวอย่างการทำงาน: การจับคู่เพนนี**
| | หัว | ก้อย |
|---|-------|-------|
| หัว | (1, −1) | (−1, 1) |
| ก้อย | (−1, 1) | (1, −1) |
ไม่มีกลยุทธ์ที่บริสุทธิ์ NE Mixed NE: เล่นทั้ง H และ T โดยมีความน่าจะเป็นคนละ 1/2

## ทฤษฎีบทขั้นต่ำสุด
### เกม Zero-Sum
ใน **เกมผลรวมเป็นศูนย์** กำไรของผู้เล่นคนหนึ่งเท่ากับการสูญเสียของอีกฝ่ายอย่างแน่นอน: u₁ + u₂ = 0
### ทฤษฎีบทมินิแมกซ์ของฟอน นอยมันน์
สำหรับทุก ๆ เกมที่มีผู้เล่นสองคนที่มีจำนวนจำกัด:
max_{σ₁} min_{σ₂} u₁(σ₁, σ₂) = min_{σ₂} max_{σ₁} u₁(σ₁, σ₂)
**ค่าสูงสุด** (กรณีที่แย่ที่สุดสำหรับผู้เล่น 1) เท่ากับ **ค่าต่ำสุด** (กรณีที่แย่ที่สุดสำหรับผู้เล่น 2) ค่าทั่วไปนี้คือ **มูลค่าของเกม**
### การแก้ปัญหาเกม Zero-Sum
สำหรับเกมผลรวมศูนย์ 2×2 ที่มีเมทริกซ์:
| | ล | อาร์ |
|---|---|---|
| ที | ก | ข |
| บี | ค | ง |
กลยุทธ์แบบผสมที่ดีที่สุดของผู้เล่น 1: เล่น T ด้วยความน่าจะเป็น p = (d−c)/((a−b)+(d−c))
มูลค่าเกม: v = (ad−bc)/((a−b)+(d−c))

## เกมรูปแบบที่กว้างขวาง
เกมที่มีการเคลื่อนไหวตามลำดับจะแสดงเป็น **ผังเกม**
### แนวคิดหลัก
| แนวคิด | คำจำกัดความ |
|---------|------------|
| **ผังเกม** | ต้นไม้แสดงลำดับการเคลื่อนไหวที่เป็นไปได้ทั้งหมด |
| **ชุดข้อมูล** | ชุดของโหนดที่ผู้เล่นไม่สามารถแยกแยะได้ |
| **ข้อมูลครบถ้วน** | ทุกชุดข้อมูลเป็นซิงเกิลตัน (ทุกการเคลื่อนไหวที่สังเกตได้) |
| **เกมย่อยที่สมบูรณ์แบบ NE** | ความสมดุลของแนชในทุกเกมย่อย |
| **การเหนี่ยวนำย้อนกลับ** | แก้จากปลายต้นไม้ไปข้างหลัง |
### ทฤษฎีบทของเซอร์เมโล
ในเกมที่มีข้อมูลครบถ้วนและมีขอบเขตจำกัด ผู้เล่นสองคนโดยไม่มีโอกาส: ผู้เล่นคนใดคนหนึ่งมีกลยุทธ์ที่จะชนะ หรือทั้งสองคนสามารถบังคับให้เสมอกันได้ (เช่น หมากรุก)

## เกมสหกรณ์
ใน **เกมร่วมมือ** ผู้เล่นสามารถสร้างข้อตกลงและแนวร่วมที่มีผลผูกพันได้
### ฟังก์ชั่นลักษณะเฉพาะ
เกมร่วมมือถูกกำหนดโดย **ฟังก์ชันลักษณะเฉพาะ** v: 2^N → ℝ โดยที่ v(S) คือคุณค่าที่กลุ่มพันธมิตร S สามารถทำได้
| คุณสมบัติ | คำจำกัดความ |
|----------|------------|
| **สารเติมแต่งพิเศษ** | v(S ∪ T) ≥ v(S) + v(T) สำหรับการแยก S, T |
| **นูน** | v(S ∪ {i}) − v(S) ≤ v(T ∪ {i}) − v(T) สำหรับ S ⊂ T |
### แกนกลาง
**แกนหลัก** คือชุดของการจัดสรรที่ไม่มีแนวร่วมใดสามารถปรับปรุงได้โดยการทำลาย:
แกนกลาง = {x ∈ ℝⁿ : Σᵢ∈N xᵢ = v(N), Σᵢ∈S xᵢ ≥ v(S) สำหรับ S ⊂ N ทั้งหมด
แกนกลางอาจว่างเปล่า ในกรณีนี้ไม่มีการจัดสรรที่มั่นคง
### มูลค่าแชปลีย์
**มูลค่า Shapley** มอบการจัดสรรที่ยุติธรรมโดยเฉพาะโดยพิจารณาจากส่วนเพิ่ม:
φᵢ = Σ_{S ⊂ N\{i}} (|S|!(n−|S|−1)!/n!) · [v(S ∪ {i}) − v(S)]
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ประสิทธิภาพ | Σ φᵢ = v(N) (แจกแจงค่าทั้งหมด) |
| สมมาตร | ผู้มีส่วนร่วมเท่ากันจะได้รับผลตอบแทนเท่ากัน |
| ผู้เล่นดัมมี่ | ผู้ที่ไม่มีส่วนร่วมจะได้รับศูนย์ |
| สารเติมแต่ง | φ(วี + w) = φ(v) + φ(w) |
**การตีความ:** ค่า Shapley ของผู้เล่นแต่ละคนคือส่วนเพิ่มโดยเฉลี่ยจากการจัดลำดับที่เป็นไปได้ทั้งหมดในการสร้างแนวร่วม
### ตัวอย่างการทำงาน
ผู้เล่นสามคน: v(∅) = 0, v({1}) = 0, v({2}) = 0, v({3}) = 0, v({1,2}) = 50, v({1,3}) = 70, v({2,3}) = 60, v({1,2,3}) = 100
| ผู้เล่น | เงินสมทบส่วนเพิ่ม (เฉลี่ยมากกว่าการสั่งซื้อ) | ค่าแชปลีย์ |
|--------|--------------------------------------------------|---------------|
| 1 | (100+50+70+70+50+0)/6 = 56.7 | 37.5 |
| 2 | (100+50+60+60+50+0)/6 | 27.5 |
| 3 | (100+70+60+70+60+0)/6 | 35.0 |
(คำนวณอย่างแม่นยำโดยใช้สูตรแชปลีย์สำหรับการเรียงสับเปลี่ยนแต่ละครั้ง)

## การออกแบบกลไก
**การออกแบบกลไก** คือ "ทฤษฎีเกมผกผัน" — แทนที่จะวิเคราะห์เกมที่ให้มา ออกแบบเกมที่ให้ผลลัพธ์ที่ต้องการ
### หลักการเปิดเผย
กลไกใดๆ ที่ให้ผลลัพธ์ตามที่ต้องการสามารถถูกแทนที่ด้วย **กลไกการเปิดเผยโดยตรง** โดยที่การบอกความจริงคือความสมดุลของแนช
### ทฤษฎีการประมูล
| ประเภทการประมูล | กฎ | ความเท่าเทียมกันของรายได้ |
|-----------------|-------|---------------------|
| **ปิดประมูลราคาแรก** | ผู้ให้ราคาสูงสุดเป็นผู้ชนะ จ่ายราคาเสนอ | การประมูลมาตรฐานทั้งหมดให้รายได้ที่คาดหวังเท่ากัน |
| **ปิดประมูลราคาที่สอง (วิคเกรย์)** | ผู้ให้ราคาสูงสุดเป็นผู้ชนะ จ่ายราคาเสนอสูงสุดเป็นอันดับสอง | (ภายใต้คุณค่าส่วนตัวที่เป็นอิสระ) |
| **ภาษาอังกฤษ (จากน้อยไปหามาก)** | ราคาเพิ่มขึ้น; เป็นคนแรกที่ยอมรับชัยชนะ | — |
| **ภาษาดัตช์ (จากมากไปน้อย)** | ราคาตก; เป็นคนแรกที่ยอมรับชัยชนะ | — |
### ประมูลวิกกี้ (ราคาที่สอง)
**กลยุทธ์ที่โดดเด่น:** เสนอราคามูลค่าที่แท้จริงของคุณ
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ประมูลจริง | กลยุทธ์ที่โดดเด่นอย่างอ่อนแอ |
| ประสิทธิภาพ | รายการไปที่ผู้เสนอราคาสูงสุด |
| รายได้ | รายได้ที่คาดหวังเหมือนกับราคาแรก (ทฤษฎีบทความเท่าเทียมของรายได้) |
### การออกแบบการประมูลที่เหมาะสมที่สุด (Myerson)
การประมูลเพื่อสร้างรายได้สูงสุด:
- จัดสรรให้กับผู้ประมูลที่มี **การประเมินมูลค่าเสมือน** สูงสุด
- กำหนดราคาจอง
- การประเมินค่าเสมือน: ψ(v) = v − (1−F(v))/f(v)

## การเชื่อมต่อกับการเรียนรู้ของเครื่อง
### เครือข่ายฝ่ายตรงข้ามทั่วไป (GAN)
GAN เป็นเกมที่มีผู้เล่นสองคนระหว่างเครื่องกำเนิด G และตัวแบ่งแยก D:
min_G max_D V(D, G) = E[บันทึก D(x)] + E[บันทึก(1 − D(G(z)))]
| แนวคิดทฤษฎีเกม | เทียบเท่า GAN |
|--------------------|-----------------|
| เกมผลรวมศูนย์สำหรับผู้เล่นสองคน | เครื่องกำเนิดเทียบกับผู้แยกแยะ |
| สมดุลของแนช | G สร้างข้อมูลจริง D ส่งออก ½ ทุกที่ |
| มินิแม็กซ์ | ฟังก์ชันวัตถุประสงค์ GAN |
| โหมดยุบ | ความล้มเหลวในการเข้าถึงสมดุล |
### การเรียนรู้การเสริมกำลังแบบหลายตัวแทน (MARL)
| แนวคิด | แอปพลิเคชั่น MARL |
|---------|-----------------|
| สมดุลของแนช | นโยบายที่เสถียรในการตั้งค่าหลายตัวแทน |
| มินิแม็กซ์ | นโยบายที่แข็งแกร่งต่อฝ่ายตรงข้ามที่เป็นปฏิปักษ์ |
| เกมสหกรณ์ | การจัดตั้งแนวร่วม การจัดสรรงาน |
| ค่าแชปลีย์ | การโอนเครดิต(ตัวแทนไหนบริจาคอะไร?) |
| การออกแบบกลไก | การออกแบบสิ่งจูงใจในระบบหลายตัวแทน |
| การเล่นสมมติ | อัลกอริทึมการเรียนรู้มาบรรจบกับสมดุลของแนช
### การเชื่อมต่อ ML อื่น ๆ
| ใบสมัคร | เครื่องมือทฤษฎีเกม |
|-----------------|-----------------|
| การออกแบบการประมูลโฆษณา (Google, Facebook) | การออกแบบกลไก ทฤษฎีการประมูล |
| การออกแบบตลาด (Uber, Airbnb) | ทฤษฎีการจับคู่ การออกแบบกลไก |
| ความแข็งแกร่งของฝ่ายตรงข้าม | เกม Zero-sum ระหว่างผู้โจมตีและผู้พิทักษ์ |
| การแบ่งส่วนยุติธรรม | มูลค่า Shapley การจัดสรรแบบไร้อิจฉา |
| การเรียนรู้แบบสหพันธ์ | ทฤษฎีเกมร่วมมือเพื่อการวัดผลการมีส่วนร่วม |
| ระบบแนะนำ | การออกแบบกลไกเพื่อกระตุ้นความพึงพอใจตามความเป็นจริง |

## สรุป
| แนวคิด | แนวคิดหลัก | ผลลัพธ์ที่สำคัญ |
|---------|-----------|------------|
| เกมรูปแบบเชิงกลยุทธ์ | ผู้เล่น กลยุทธ์ ผลตอบแทน | การแสดงเมทริกซ์เกม |
| กลยุทธ์ที่โดดเด่น | ดีที่สุดโดยไม่คำนึงถึงผู้อื่น | การกำจัดซ้ำ |
| สมดุลของแนช | ไม่มีการเบี่ยงเบนฝ่ายเดียวที่ทำกำไรได้ มีอยู่ในทุกเกมที่มีขอบเขต |
| กลยุทธ์แบบผสม | สุ่มการกระทำ | ทฤษฎีบทการดำรงอยู่ของแนช |
| มินิแม็กซ์ | กรณีเลวร้ายที่สุด (ผลรวมศูนย์) | ทฤษฎีบทมินิแมกซ์ของวอนนอยมันน์ |
| รูปแบบที่กว้างขวาง | การเคลื่อนไหวตามลำดับ | การเหนี่ยวนำย้อนกลับความสมบูรณ์แบบของเกมย่อย |
| เกมสหกรณ์ | แนวร่วมที่มีผลผูกพัน | แกนหลัก, ค่า Shapley |
| การออกแบบกลไก | ออกแบบเกมเพื่อผลลัพธ์ | หลักการเปิดเผย การประมูลที่เหมาะสมที่สุด |
| ทฤษฎีการประมูล | ขายผ่านการแข่งขัน | รายได้เท่าเทียม ประมูลวิกกี้ |
ทฤษฎีเกมเป็นคณิตศาสตร์ของการคิดเชิงกลยุทธ์ ในโลกที่มีประชากรเพิ่มมากขึ้นจากการโต้ตอบกับตัวแทน AI ตลาดอัตโนมัติ และระบบฝ่ายตรงข้าม ทฤษฎีเกมเป็นชุดเครื่องมือที่จำเป็นสำหรับการทำนายพฤติกรรม การออกแบบกลไก และสร้างระบบหลายตัวแทนที่แข็งแกร่ง สำหรับนักวิทยาศาสตร์ข้อมูล จะอธิบายวิธีการทำงานของ GAN วิธีที่การประมูลออนไลน์สร้างรายได้นับพันล้าน และวิธีการสร้างระบบ AI ที่ทำงานได้ดีในสภาพแวดล้อมที่มีการแข่งขัน
