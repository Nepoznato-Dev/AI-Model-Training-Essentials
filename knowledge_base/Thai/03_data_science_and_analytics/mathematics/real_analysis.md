# วิเคราะห์จริง
การวิเคราะห์ที่แท้จริงคือรากฐานอันเข้มงวดของแคลคูลัส แม้ว่าแคลคูลัสเบื้องต้นจะสอนวิธีคำนวณอนุพันธ์และอินทิกรัล แต่การวิเคราะห์จริงจะถามว่า *ทำไม* เทคนิคเหล่านี้จึงได้ผล และเมื่อใดที่ล้มเหลว โดยให้คำจำกัดความที่แม่นยำของขีดจำกัด ความต่อเนื่อง การบรรจบกัน และการบูรณาการที่สนับสนุนทฤษฎีความน่าจะเป็น การวิเคราะห์เชิงฟังก์ชัน การเพิ่มประสิทธิภาพ และหลักประกันทางทฤษฎีที่อยู่เบื้องหลังอัลกอริธึมการเรียนรู้ของเครื่อง
---

## ลำดับและซีรีส์
### ลำดับ
**ลำดับ** คือรายการเรียงลำดับของจำนวนจริง (aₙ)ₙ₌₁^∞ คำถามหลักคือ: ลำดับ **มาบรรจบกัน** ถึงขีดจำกัดหรือไม่
**คำจำกัดความของการลู่เข้า:** ลำดับ (aₙ) มาบรรจบกันที่ L ถ้าทุกๆ ε > 0 มี N อยู่ ดังนั้นสำหรับ n ทั้งหมด > N: |aₙ − L| < ε.
| แนวคิด | คำจำกัดความ | ตัวอย่าง |
|---------|------------|---------|
| **มาบรรจบกัน** | lim aₙ = L มีอยู่และมีจำกัด | aₙ = 1/n → 0 |
| **แตกต่าง** | ไม่มาบรรจบกัน | aₙ = (−1)ⁿ แกว่ง |
| **แตกต่างไป ∞** | aₙ เติบโตอย่างไร้ขอบเขต | aₙ = n² → ∞ |
| **มีขอบเขต** | \|aₙ\| ≤ M สำหรับ M | บางตัว ทุกลำดับมาบรรจบกันมีขอบเขต |
| **โมโนโทน** | ไม่ว่าจะไม่ลดลงหรือไม่เพิ่มขึ้นเสมอ | aₙ = 1 − 1/n กำลังเพิ่มขึ้น |
| **ลำดับ Cauchy** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | ใน ℝ Cauchy ⟺ มาบรรจบกัน |
**ทฤษฎีบทสำคัญ:**
- **ทฤษฎีบทการบรรจบกันของโมโนโทน:** ลำดับโมโนโทนที่มีขอบเขตทั้งหมดมาบรรจบกัน
- **ทฤษฎีบทโบลซาโน-ไวเออร์สแตรส:** ทุกลำดับที่มีขอบเขตจะมีลำดับย่อยมาบรรจบกัน
- **ความสมบูรณ์ของ ℝ:** ทุกลำดับ Cauchy ใน ℝ มาบรรจบกัน (ซึ่งแยกความแตกต่าง ℝ จาก ℚ)
### ชุด
**ซีรีส์** คือผลรวมของลำดับ: Σₙ₌₁^∞ aₙ อนุกรมจะบรรจบกันถ้าลำดับของผลรวมบางส่วน Sₙ = Σₖ₌₁ⁿ aₖ มาบรรจบกัน
### การทดสอบการลู่เข้า
| ทดสอบ | สภาพ | สรุป |
|------|-----------|------------|
| **การทดสอบความแตกต่าง** | ลิมₙ ≠ 0 | ซีรีส์แตกต่าง |
| **การทดสอบเปรียบเทียบ** | 0 ≤ aₙ ≤ bₙ และ Σbₙ มาบรรจบกัน | Σaₙ มาบรรจบกัน |
| **การทดสอบอัตราส่วน** | ลิม \|aₙ₊₁/aₙ\| = ล | บรรจบกันถ้า L< 1, diverges if L >1 |
| **การทดสอบรูท** | ลิมซุป \|aₙ\|^(1/n) = L | มาบรรจบกันถ้า L< 1, diverges if L >1 |
| **การทดสอบอินทิกรัล** | aₙ = f(n), f ลดลง, บวก | Σaₙ มาบรรจบกัน iff ∫f(x)dx มาบรรจบกัน |
| **ซีรีส์สลับกัน** | aₙ ลดลง, lim aₙ = 0, เครื่องหมายสลับ | ซีรีส์มาบรรจบกัน |
| **การบรรจบกันอย่างแท้จริง** | Σ\|aₙ\| มาบรรจบกัน | Σaₙ มาบรรจบกัน (และการจัดเรียงใหม่ให้ผลรวมเท่ากัน) |
| **การบรรจบกันแบบมีเงื่อนไข** | Σaₙ มาบรรจบกัน แต่ Σ\|aₙ\| แตกต่าง | การจัดเรียงใหม่สามารถให้ผลรวมเท่าใดก็ได้ (Riemann) |
### ซีรีส์สำคัญ
| ซีรีส์ | ผลรวม | สภาพ |
|--------|-----|-----------|
| เรขาคณิต: Σ rⁿ | 1/(1−r) | \|ร\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| ฮาร์มอนิก: Σ 1/n | แตกต่าง (= ∞) | — |
| เอ็กซ์โปเนนเชียล: Σ xⁿ/n! | อีˣ | ทั้งหมด x |
| เทย์เลอร์สำหรับ ln(1+x): Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < x ≤ 1 |

## ข้อจำกัดและความต่อเนื่อง
### ข้อจำกัดของฟังก์ชัน
**คำจำกัดความ:** lim_{x→c} f(x) = L หมายถึง: สำหรับทุก ๆ ε > 0 จะมี δ > 0 โดยที่ 0 < |x − c| < δ หมายถึง |f(x) − L| < ε.
นี่คือคำจำกัดความ **ε-δ** — เวอร์ชันที่เข้มงวดของ "f(x) เข้าใกล้ L เมื่อ x เข้าใกล้ c"
### ความต่อเนื่อง
ฟังก์ชัน f จะ **ต่อเนื่องที่ c** ถ้า lim_{x→c} f(x) = f(c) ในทำนองเดียวกัน: สำหรับทุก ๆ ε > 0 จะมี δ > 0 โดยที่ |x − c| < δ หมายถึง |f(x) − f(c)| < ε.
**ประเภทของความไม่ต่อเนื่อง:**
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| ถอดได้ | มีขีดจำกัดแต่ ≠ f(c) | f(x) = บาป(x)/x ที่ x = 0 |
| กระโดด | มีขีดจำกัดด้านซ้ายและขวาแต่แตกต่างกัน | ฟังก์ชั่นขั้นตอน |
| อนันต์ | ขีดจำกัดคือ ±∞ | f(x) = 1/x² ที่ x = 0 |
| สั่น | ไม่มีขีดจำกัด | f(x) = บาป(1/x) ที่ x = 0 |
### ทฤษฎีบทสำคัญสำหรับฟังก์ชันต่อเนื่อง
| ทฤษฎีบท | คำชี้แจง |
|---------|-----------|
| **ทฤษฎีบทค่ากลาง** | ถ้า f ต่อเนื่องกันบน [a,b] และ f(a) < k < f(b) แล้ว ∃c ∈ (a,b): f(c) = k |
| **ทฤษฎีบทมูลค่าสูงสุด** | ถ้า f ต่อเนื่องกันบน [a,b] f จะไปถึงค่าสูงสุดและต่ำสุดบน [a,b] |
| **ทฤษฎีบทขอบเขต** | ถ้า f ต่อเนื่องกันบน [a,b] f จะขอบเขตบน [a,b] |
| **ความต่อเนื่องสม่ำเสมอ** | f มีความต่อเนื่องสม่ำเสมอบน [a,b] ถ้า f มีความต่อเนื่องบน [a,b] (Heine-Cantor) |
**ตัวอย่างการทำงาน (IVT):** แสดง x³ + x − 1 = 0 มีคำตอบใน (0, 1)
- ให้ f(x) = x³ + x − 1. f เป็นค่าต่อเนื่อง (พหุนาม)
- f(0) = −1< 0 and f(1) = 1 >0
- โดย IVT, ∃c ∈ (0,1): f(c) = 0

## ความแตกต่าง
### คำนิยาม
f'(c) = lim_{h→0} (f(c+h) − f(c)) / ชั่วโมง
หากมีขีดจำกัดนี้ f จะ **หาผลต่าง** ที่ c
### ความแตกต่างเทียบกับความต่อเนื่อง
| ความสัมพันธ์ | คำชี้แจง |
|--------------|-----------|
| หาอนุพันธ์ได้ → ต่อเนื่อง | ถ้า f สามารถหาอนุพันธ์ได้ที่ c แล้ว f จะต่อเนื่องที่ c |
| ต่อเนื่อง ↛ หาอนุพันธ์ได้ | ฉ(x) = \|x\| มีความต่อเนื่องที่ 0 แต่หาอนุพันธ์ไม่ได้ตรงนั้น |
| ไม่มีที่ไหนที่จะแตกต่าง | ฟังก์ชันไวเออร์สตราส: ต่อเนื่องทุกแห่ง หาอนุพันธ์ไม่ได้ |
### ผลลัพธ์ที่สำคัญ
| ทฤษฎีบท | คำชี้แจง |
|---------|-----------|
| **ทฤษฎีบทค่าเฉลี่ย** | ถ้า f ต่อเนื่องกันบน [a,b] และสามารถหาอนุพันธ์ได้บน (a,b) ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **ทฤษฎีบทของโรลส์** | กรณีพิเศษของ MVT เมื่อ f(a) = f(b): ∃c: f'(c) = 0 |
| **กฎของโลปิตาล** | ถ้า lim f/g = 0/0 หรือ ∞/∞ ดังนั้น lim f/g = lim f'/g' (เมื่อมีอย่างหลัง) |
| **ทฤษฎีบทของเทย์เลอร์** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x) โดยมีเศษเหลือชัดเจน |

## บูรณาการ
### บูรณาการรีมันน์
**อินทิกรัลรีมันน์** กำหนด ∫ₐᵇ f(x)dx เป็นขีดจำกัดของผลบวกของรีมันน์
**การก่อสร้าง:**
1. การแบ่ง [a,b] เป็นช่วงย่อย: P = {x₀, x₁, ..., xₙ}
2. เลือกจุดตัวอย่าง tᵢ ∈ [xᵢ₋₁, xᵢ]
3. ผลรวมรีมันน์: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. ถ้าขีดจำกัดของ S(P,f) อยู่ที่ mesh → 0, f คือ Riemann integrable
**เกณฑ์การรวมระบบของ Riemann:**
| สภาพ | บูรณาการ? |
|-----------|-------------|
| ต่อเนื่องบน [a,b] | ใช่ |
| ผูกมัดด้วยความไม่ต่อเนื่องมากมาย | ใช่ |
| เสียงเดียวใน [a,b] | ใช่ |
| ฟังก์ชันไดริชเลต์ (1 บน ℚ, 0 บนความไม่ลงตัว) | ไม่ |
### ทฤษฎีบทพื้นฐานของแคลคูลัส
| ส่วน | คำชี้แจง |
|------|-----------|
| **ตอนที่ 1** | ถ้า f ต่อเนื่องกันบน [a,b] แล้ว F(x) = ∫ₐˣ f(t)dt สามารถหาอนุพันธ์ได้ และ F'(x) = f(x) |
| **ตอนที่ 2** | ถ้า F' = f และ f เป็นปริพันธ์ของรีมันน์ได้ ดังนั้น ∫ₐᵇ f(x)dx = F(b) − F(a) |
### บูรณาการ Lebesgue
อินทิกรัลของรีมันน์มีข้อจำกัด — ไม่สามารถบูรณาการฟังก์ชันต่างๆ มากมายที่เกิดขึ้นในการวิเคราะห์และความน่าจะเป็นได้ **อินทิกรัล Lebesgue** ขยายการบูรณาการไปสู่คลาสฟังก์ชันที่กว้างขึ้นมาก
**แนวคิดหลัก:** แทนที่จะแบ่งพาร์ติชันโดเมน (แกน x) ให้แบ่งพาร์ติชันช่วง (แกน y)
| ด้าน | อินทิกรัลรีมันน์ | อินทิกรัล Lebesgue |
|----------------------|-----------------|-------------------|
| วิธีการ | โดเมนพาร์ติชัน (แกน x) | ช่วงพาร์ติชั่น (แกน y) |
| รวม | ต่อเนื่อง, ต่อเนื่องเป็นชิ้น ๆ | ฟังก์ชั่นที่วัดได้ |
| ทฤษฎีบทลิมิต | อ่อนแอ | ทรงพลัง (การบรรจบกันที่โดดเด่น, การบรรจบกันแบบโมโนโทน) |
| จับ | ฟังก์ชั่น "ดี" | ฟังก์ชั่นที่มีความไม่ต่อเนื่องหนาแน่น |
| รากฐานของ | แคลคูลัสคลาสสิก | ทฤษฎีความน่าจะเป็นสมัยใหม่ |
**เกณฑ์ของ Lebesgue:** f คือ Riemann ที่บูรณาการได้ใน [a,b] iff f มีขอบเขตและต่อเนื่องกันเกือบทุกที่ (เซตของความไม่ต่อเนื่องมีค่าเป็นศูนย์)

## ช่องว่างเมตริก
**ปริภูมิเมตริก** เป็นการสรุปแนวคิดเรื่อง "ระยะทาง" ไปจนถึงเซตนามธรรม
### คำนิยาม
**ปริภูมิเมตริก** (X, d) คือเซต X ที่มีฟังก์ชันระยะทาง d: X × X → ℝ น่าพอใจ:
| สัจพจน์ | คำชี้แจง |
|-------|-----------|
| การไม่ปฏิเสธ | ง(x,y) ≥ 0 |
| ตัวตน | d(x,y) = 0 ถ้า x = y |
| สมมาตร | ง(x,y) = ง(y,x) |
| อสมการสามเหลี่ยม | d(x,z) ≤ d(x,y) + d(y,z) |
### ช่องว่างเมตริกทั่วไป
| อวกาศ | ตั้ง | เมตริก | ใบสมัคร |
|-------|-----|--------|-------------|
| ℝⁿ กับแบบยุคลิด | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² | เรขาคณิตมาตรฐาน |
| ℝⁿ กับแมนฮัตตัน | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| | เส้นทางแบบกริด LASSO |
| ℝⁿ กับ Chebyshev | ℝⁿ | d(x,y) = สูงสุด\|xᵢ−yᵢ\| | ระยะทางราชาหมากรุก |
| เมตริกแยก | ชุดใดก็ได้ | d(x,y) = 1 ถ้า x≠y, 0 ถ้า x=y | ตัวอย่างโทโพโลยี |
| พื้นที่ฟังก์ชัน C[a,b] | ฟังก์ชั่นต่อเนื่อง | d(f,g) = สูงสุด\|f(x)−g(x)\| | ทฤษฎีการประมาณ |
| Lᵖอวกาศ | ฟังก์ชันอินทิเกรต p | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) | การวิเคราะห์เชิงฟังก์ชัน บรรทัดฐานของ ML |
### แนวคิดเชิงทอพอโลยีในปริภูมิเมตริก
| แนวคิด | คำจำกัดความ | ตัวอย่าง |
|---------|------------|---------|
| **เปิดบอล** | B(x,r) = {y : d(x,y) < r} | ช่วงเวลาเปิด (x−r, x+r) ใน ℝ |
| **ชุดเปิด** | ทุกจุดมีลูกบอลอยู่ในเซต | (0,1) เปิดอยู่ใน ℝ |
| **ชุดปิด** | เสริมชุดเปิด | [0,1] ถูกปิดใน ℝ |
| **ปิด** | ชุดปิดที่เล็กที่สุดที่มี S | ปิด (0,1) = [0,1] |
| **กะทัดรัด** | ทุกปกที่เปิดอยู่จะมีซับคัฟเวอร์จำกัด | ใน ℝⁿ: ปิดและมีขอบเขต (Heine-Borel) |
| **สมบูรณ์** | ทุกลำดับ Cauchy มาบรรจบกัน | ℝ เสร็จสมบูรณ์; ℚ ไม่ใช่ |

## การบรรจบกันที่สม่ำเสมอ
ลำดับของฟังก์ชัน (fₙ) สามารถมาบรรจบกันได้สองวิธี:
| พิมพ์ | คำจำกัดความ | รักษาความต่อเนื่อง? |
|------|----------------|--------------------------------|
| **ตามจุด** | ∀x: fₙ(x) → f(x) | ไม่ |
| **เครื่องแบบ** | ซุป\|fₙ(x) − ฉ(x)\| → 0 | ใช่ |
**การบรรจบกันแบบสม่ำเสมอ** แข็งแกร่งขึ้น: อัตราการลู่เข้าจะเท่ากันทุกที่
**ทฤษฎีบทสำคัญ:**
- ขีดจำกัดสม่ำเสมอของฟังก์ชันต่อเนื่องคือต่อเนื่อง
- ขีดจำกัดสม่ำเสมอของฟังก์ชันอินทิกรัลรีมันน์คืออินทิกรัลแบบรีมันน์ และอินทิกรัลของลิมิตเท่ากับลิมิตของอินทิกรัล
- **Weierstrass M-test:** ถ้า |fₙ(x)| ≤ Mₙ สำหรับ x และ ΣMₙ ทั้งหมดมาบรรจบกัน จากนั้น Σfₙ มาบรรจบกันอย่างสม่ำเสมอ

## ทฤษฎีการวัด
**ทฤษฎีการวัด** ให้แนวคิดทั่วไปเกี่ยวกับความยาว พื้นที่ และปริมาตร
### คำนิยาม
**การวัด** บนเซต X คือฟังก์ชัน μ: Σ → [0, ∞] (โดยที่ Σ คือพีชคณิตของเซตย่อย) ที่น่าพอใจ:
- μ(∅) = 0
- **การบวกแบบนับได้:** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) สำหรับการแยก Aᵢ
### วัดเลเบส
**การวัดแบบ Lebesgue** λ บน ℝ ขยายแนวคิดเรื่องความยาว:
| ตั้ง | วัด Lebesgue |
|-----|-----------------|
| ช่วง [a,b] | ข − ก |
| จุดเดียว {x} | 0 |
| เซตจำกัด | 0 |
| ชุดนับได้ (เช่น ℚ) | 0 |
| ชุดคันทอร์ | 0 (นับไม่ได้แต่วัดเป็นศูนย์) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### แนวคิดหลัก
| แนวคิด | คำจำกัดความ |
|---------|------------|
| **เกือบทุกที่ (เช่น)** | คุณสมบัติคงอยู่ยกเว้นในชุดของการวัดศูนย์ |
| **ฟังก์ชันที่วัดได้** | ภาพพรีอิมเมจของทุกชุดที่เปิดสามารถวัดได้ |
| **Lebesgue อินทิกรัล** | อินทิกรัลกำหนดโดยใช้ทฤษฎีการวัด |
| **ช่องว่าง** | ปริภูมิของฟังก์ชันที่มีอินทิกรัลกำลัง p-th อันจำกัด |
### ทฤษฎีบทการลู่เข้าที่สำคัญ
ทฤษฎีบทเหล่านี้เป็นสาเหตุว่าทำไมการบูรณาการของ Lebesgue จึงเป็นที่ต้องการในคณิตศาสตร์ขั้นสูง:
| ทฤษฎีบท | คำชี้แจง |
|---------|-----------|
| **การบรรจบกันแบบโมโนโทน** | ถ้า fₙ ↑ f ตามจุดและ fₙ ≥ 0 ดังนั้น ∫fₙ → ∫f |
| **การบรรจบกันครอบงำ** | ถ้า fₙ → f ตามจุด และ \|fₙ\| ≤ g (อินทิเกรตได้) จากนั้น ∫fₙ → ∫f |
| **บทแทรกของ Fatou** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
ทฤษฎีบทเหล่านี้อนุญาตให้มีการแลกเปลี่ยนลิมิตและอินทิกรัล ซึ่งเป็นสิ่งที่ล้มเหลวในการบูรณาการรีมันน์โดยทั่วไป

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดการวิเคราะห์ | ใบสมัคร |
|-----------------|-------------|
| ขีดจำกัดและการบรรจบกัน | การทำความเข้าใจเมื่ออัลกอริธึมวนซ้ำ (การไล่ระดับสี, EM) มาบรรจบกัน
| ความต่อเนื่อง | ฟังก์ชันการเปิดใช้งานจะต้องต่อเนื่องกันสำหรับ backpropagation |
| ความแตกต่าง | การเพิ่มประสิทธิภาพตามการไล่ระดับสีต้องใช้ฟังก์ชันการสูญเสียที่หาอนุพันธ์ได้ |
| ทฤษฎีบทค่าเฉลี่ย | ขอบเขตข้อผิดพลาดในการประมาณเชิงตัวเลข การพิสูจน์การลู่เข้า |
| ช่องว่างเมตริก | ฟังก์ชันระยะทางในการจัดกลุ่ม (k-mean, DBSCAN) เพื่อนบ้านที่ใกล้ที่สุด |
| ความกะทัดรัด | การพิสูจน์การดำรงอยู่สำหรับโซลูชันที่เหมาะสมที่สุด Heine-Borel ในการเพิ่มประสิทธิภาพมิติอันจำกัด |
| ชุดบรรจบกัน | รับรองว่าการประมาณค่า (การประมาณค่าโครงข่ายประสาทเทียมสากล) ใช้งานได้ทุกที่ |
| ทฤษฎีการวัด | รากฐานของความน่าจะเป็นสมัยใหม่ (ความน่าจะเป็นคือการวัด) ค่าที่คาดหวังในรูปของปริพันธ์เลอเบส |
| บูรณาการ Lebesgue | ค่าที่คาดหวัง E[X] = ∫X dP คืออินทิกรัล Lebesgue |
| ช่องว่าง | L¹ (LASSO), L² (ริดจ์), Lᵖ บรรทัดฐานในการทำให้เป็นมาตรฐาน |
| บรรจบกันครอบงำ | การพิสูจน์ความสอดคล้องกันของตัวประมาณค่า ขีดจำกัดการแลกเปลี่ยนในการอนุมานแบบเบย์ |
