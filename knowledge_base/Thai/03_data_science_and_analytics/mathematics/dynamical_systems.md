# ระบบไดนามิก
**ระบบไดนามิก** อธิบายว่าสถานะมีการพัฒนาอย่างไรเมื่อเวลาผ่านไปตามกฎที่ตายตัว ตั้งแต่วงโคจรของดาวเคราะห์ไปจนถึงพลวัตของประชากร จากรูปแบบสภาพอากาศไปจนถึงการฝึกอบรมโครงข่ายประสาทเทียม ทฤษฎีระบบไดนามิกให้ภาษาและเครื่องมือในการทำความเข้าใจว่าสิ่งต่าง ๆ เปลี่ยนแปลงไปอย่างไร ไฟล์นี้ครอบคลุมถึงสมการเชิงอนุพันธ์สามัญ (ODE) สมการเชิงอนุพันธ์ย่อย (PDE) การวิเคราะห์เสถียรภาพ ความโกลาหล และการแยกไปสองทาง
---

## สมการเชิงอนุพันธ์สามัญ (ODE)
ODE เชื่อมโยงฟังก์ชันกับอนุพันธ์ของมันโดยคำนึงถึงตัวแปรอิสระตัวเดียว (โดยปกติคือเวลา)
### การจำแนกประเภท
| คุณสมบัติ | ประเภท |
|----------|-------|
| **สั่งซื้อ** | ปัจจุบันอนุพันธ์สูงสุด (ลำดับที่ 1, ลำดับที่ 2 เป็นต้น) |
| **เชิงเส้นและไม่เชิงเส้น** | เชิงเส้น: y'' + p(t)y' + q(t)y = g(t); ไม่เชิงเส้น: อย่างอื่น |
| **เป็นเนื้อเดียวกัน** | g(t) = 0 (ไม่มีเงื่อนไขบังคับ) |
| **อัตโนมัติ** | ไม่มีการพึ่งพาเวลาที่ชัดเจน: dy/dt = f(y) |
| **ค่าสัมประสิทธิ์คงที่** | p, q เป็นค่าคงที่ |
### ODE ลำดับแรก
**รูปแบบทั่วไป:** dy/dt = f(t, y)
| พิมพ์ | แบบฟอร์ม | วิธีการแก้ปัญหา |
|-|-------|-----------------|
| แยกออกได้ | dy/dt = g(t)h(y) | แยกและอินทิเกรต: ∫dy/h(y) = ∫g(t)dt |
| ลำดับแรกเชิงเส้น | dy/dt + p(t)y = q(t) | ปัจจัยอินทิเกรต: μ(t) = e^(∫p dt) |
| แน่นอน | M(t,y)dt + N(t,y)dy = 0 โดยที่ ∂M/∂y = ∂N/∂t | ค้นหาฟังก์ชันที่เป็นไปได้ F(t,y) |
| เบอร์นูลลี | dy/dt + p(t)y = q(t)yⁿ | แทน v = y^(1−n) ให้เป็นเส้นตรง |
**ตัวอย่างการทำงาน (ปัจจัยการอินทิเกรต):** แก้ dy/dt + 2y = e^(−t), y(0) = 1
- ปัจจัยอินทิเกรต: μ(t) = e^(∫2 dt) = e^(2t)
- คูณ: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- อินทิเกรต: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- เงื่อนไขเริ่มต้น: y(0) = 1 → 1 = 1 + C → C = 0
- วิธีแก้: y(t) = e^(−t)
### ODE เชิงเส้นลำดับที่สอง
**รูปแบบทั่วไป:** ay'' + by' + cy = g(t)
**กรณีที่เป็นเนื้อเดียวกัน** (g ​​= 0): แก้สมการคุณลักษณะ ar² + br + c = 0
| จำแนก | ราก | วิธีแก้ปัญหาทั่วไป |
|-----------------|-------|------------------|
| b² > 4ac (โอเวอร์โหลด) | สองค่าจริงที่แตกต่างกัน r₁, r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (หน่วงขั้นวิกฤติ) | ทำซ้ำรูทจริง r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (ลดแรงกระแทก) | รากเชิงซ้อน α ± βi | y = e^(αt)(C₁ cos βt + C₂ sin βt) |
**การตีความทางกายภาพ:** ระบบแมส-สปริง-แดมเปอร์ mx'' + bx' + kx = 0
- Overdamped: หน่วงหนัก, ไม่มีการสั่น (โช๊คประตู)
- หน่วงขั้นวิกฤต: กลับเร็วที่สุดโดยไม่มีการสั่น (เป้าหมายการออกแบบระบบกันสะเทือนของรถยนต์)
- Underdamped: แกว่งไปตามแอมพลิจูดที่เสื่อมลง (สายกีตาร์)
### ระบบของ ODE
ระบบจริงหลายระบบเกี่ยวข้องกับตัวแปรโต้ตอบหลายตัว:
dx/dt = ฉ(x, y)
dy/dt = g(x, y)
สามารถเขียนได้ในรูปแบบเวกเตอร์: d**x**/dt = **F**(**x**)
**ระบบเชิงเส้นตรง:** d**x**/dt = A**x** โดยที่ A คือเมทริกซ์
สารละลายขึ้นอยู่กับค่าลักษณะเฉพาะของ A:
| ค่าลักษณะเฉพาะ | พฤติกรรม |
|-------------|-----------|
| ทั้งจริงและลบ | โหนดที่เสถียร (วิถีทั้งหมดมาบรรจบกันที่จุดเริ่มต้น) |
| ทั้งจริงทั้งบวก | โหนดไม่เสถียร |
| จริง เครื่องหมายตรงกันข้าม | จุดอาน (ไม่เสถียร) |
| ส่วนจำนวนจริงเชิงซ้อนที่เป็นลบ | เกลียวเสถียร (การแกว่งแบบหน่วง) |
| ส่วนจริงที่เป็นบวกและซับซ้อน | เกลียวไม่เสถียร |
| จินตนาการล้วนๆ | ศูนย์กลาง (วงโคจรปิด) |

## ภาพบุคคลเฟส
**เฟสแนวตั้ง** แสดงให้เห็นภาพวิถีของระบบไดนามิกในพื้นที่สถานะ (โดยไม่ต้องแก้ไขอย่างชัดเจน)
### คุณสมบัติที่สำคัญ
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **จุดคงที่ (สมดุล)** | โดยที่ dx/dt = 0 (ไม่มีการเคลื่อนไหว) |
| **วิถี** | เส้นทางที่ติดตามโดยระบบในพื้นที่สถานะ |
| **เป็นโมฆะ** | เส้นโค้งโดยที่อนุพันธ์ขององค์ประกอบหนึ่งเป็นศูนย์ |
| **วงจรจำกัด** | วงโคจรปิดที่แยกเดี่ยว (การแกว่งอย่างยั่งยืนในตัวเอง) |
| **แอ่งน้ำแห่งแหล่งท่องเที่ยว** | ชุดของเงื่อนไขเริ่มต้นที่นำไปสู่ตัวดึงดูดที่กำหนด |
| **เซพาราทริกซ์** | เขตแดนระหว่างแอ่งต่าง ๆ ของแหล่งท่องเที่ยว |
### โมเดลนักล่า-เหยื่อ (Lotka-Volterra)
dx/dt = αx − βxy (เหยื่อ)
dy/dt = δxy − γy (นักล่า)
**จุดคงที่:**
1. (0, 0) — การสูญพันธุ์ (จุดอาน)
2. (γ/δ, α/β) — การอยู่ร่วมกัน (ศูนย์กลาง — วงโคจรปิด)
ระบบจะแสดงการแกว่งเป็นระยะ: เหยื่อเพิ่มขึ้น → ผู้ล่าเพิ่มขึ้น → เหยื่อลดลง → ผู้ล่าลดลง → วงจรซ้ำ

## การวิเคราะห์ความเสถียร
### เสถียรภาพเชิงเส้น
สำหรับจุดคงที่ x* ให้ทำให้เป็นเชิงเส้นรอบจุดนั้น: ให้ u = x − x* จากนั้น du/dt µ J(x*)u โดยที่ J คือเมทริกซ์จาโคเบียน
**เกณฑ์ความเสถียร:** จุดคงที่คือ:
- **เสถียร** หากค่าลักษณะเฉพาะทั้งหมดของ J มีส่วนจริงเป็นลบ
- **ไม่เสถียร** หากค่าลักษณะเฉพาะใดๆ มีส่วนจริงที่เป็นบวก
- **เสถียรเล็กน้อย** หากค่าลักษณะเฉพาะมีส่วนที่แท้จริงเป็นศูนย์ (ต้องการการวิเคราะห์แบบไม่เชิงเส้น)
### เสถียรภาพของเลียปูนอฟ
**วิธีการโดยตรงของ Lyapunov** กำหนดความเสถียรโดยไม่มีการทำให้เชิงเส้น
A **ฟังก์ชัน Lyapunov** V(x) เป็นไปตาม:
1. V(x*) = 0 และ V(x) > 0 สำหรับ x ≠ x* (บวกแน่นอน)
2. dV/dt ≤ 0 ตามวิถี (ไม่เพิ่มขึ้น)
| สภาพ | สรุป |
|----------||------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | ไม่เสถียร |
**ตัวอย่างการทำงาน:** ระบบ dx/dt = −x + y², dy/dt = −y
- ลอง V(x,y) = x² + y² (ฟังก์ชันคล้ายพลังงาน)
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- จุดกำเนิดใกล้: dV/dt µ −2x² − 2y² < 0 (สำหรับ y เล็ก ค่า −2y² จะครอบงำ)
- สรุป: ต้นกำเนิดมีความคงตัวเชิงซีมโทติคัลเฉพาะที่

## ทฤษฎีความโกลาหล
**ความโกลาหล** เป็นสิ่งที่กำหนดได้แต่คาดเดาไม่ได้: ระบบเป็นไปตามกฎที่แน่นอน แต่ความแตกต่างเล็กน้อยในเงื่อนไขเริ่มต้นนำไปสู่ผลลัพธ์ที่แตกต่างกันอย่างมากมาย
### ข้อกำหนดสำหรับ Chaos
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| กำหนด | ไม่มีการสุ่ม — ควบคุมโดยสมการที่แน่นอน |
| ไวต่อสภาวะเริ่มต้น | วิถีใกล้เคียงแตกต่างแบบทวีคูณ |
| ผูกมัด | วิถีไม่หนีไปสู่อนันต์ |
| ไม่เป็นระยะ | ห้ามพูดซ้ำทุกประการ |
### ระบบลอเรนซ์
ตัวอย่างคลาสสิกของความสับสนวุ่นวายที่กำหนด:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy - βz
ด้วยพารามิเตอร์มาตรฐาน σ = 10, ρ = 28, β = 8/3:
- ระบบมีจุดคงที่ 3 จุด ไม่เสถียรทั้งหมด
- วิถีโคจรรอบจุดคงที่จุดหนึ่ง จากนั้นจึงสลับไปยังอีกจุดหนึ่งอย่างกะทันหัน
- ผลลัพธ์คือ **ตัวดึงดูดลอเรนซ์** ซึ่งเป็นตัวดึงดูดแปลก ๆ ที่มีโครงสร้างแฟร็กทัล
**เลขชี้กำลังเลียปูนอฟ:** วัดอัตราการเบี่ยงเบนของวิถีใกล้เคียง
- เลขชี้กำลัง Lyapunov เชิงบวก → ความโกลาหล
- สำหรับระบบลอเรนซ์ที่มีพารามิเตอร์มาตรฐาน: เลขชี้กำลังที่ใหญ่ที่สุด data 0.9 > 0
### แผนที่ลอจิสติกส์
ระบบแยกที่เรียบง่ายที่แสดงถึงความสับสนวุ่นวาย:
x_{n+1} = rx_n(1 − x_n)
| พารามิเตอร์ r | พฤติกรรม |
|-------------|-----------|
| 0 < r < 1 | ประชากรเสียชีวิต (x → 0) |
| 1 < r < 3 | จุดคงที่คงที่ที่ x = 1 − 1/r |
| 3 < r < 3.449 | การแกว่งของคาบ-2 |
| 3.449 < ร < 3.544 | การแกว่งของคาบ-4 |
| 3.544 < ร < 3.570 | ช่วง-8, 16, 32, ... (น้ำตกเพิ่มเป็นสองเท่า) |
| ร µ 3.570 | ความวุ่นวาย |
| 3.570 < r < 4 | มีความวุ่นวายเป็นส่วนใหญ่ โดยมีหน้าต่างเป็นระยะ |
| r = 4 | วุ่นวายเต็มที่ใน [0, 1] |
### เอฟเฟกต์ผีเสื้อ
ชื่อยอดนิยมสำหรับการพึ่งพาเงื่อนไขเริ่มต้นที่ละเอียดอ่อน ในระบบสภาพอากาศ (จำลองโดยสมการลอเรนซ์) ผีเสื้อที่กระพือปีกในบราซิลอาจทำให้เกิดพายุทอร์นาโดในเท็กซัส ไม่ใช่เพราะผีเสื้อทำให้เกิดพายุทอร์นาโด แต่เป็นเพราะการก่อกวนเล็กๆ น้อยๆ เพิ่มมากขึ้นแบบทวีคูณ

## ทฤษฎีการแยกไปสองทาง
**การแยกไปสองทาง** คือการเปลี่ยนแปลงเชิงคุณภาพในลักษณะการทำงานของระบบเนื่องจากพารามิเตอร์มีการเปลี่ยนแปลง
### ประเภทของการแยกไปสองทาง
| การแยกไปสองทาง | แบบฟอร์มปกติ | เกิดอะไรขึ้น |
|-------------|-------------|--------------|
| **โหนดอาน** | dx/dt = r − x² | จุดคงที่สองจุดปรากฏ/หายไป |
| **การถอดเสียง** | dx/dt = rx − x² | เสถียรภาพการแลกเปลี่ยนจุดคงที่สองจุด |
| **โกย (วิกฤตยิ่งยวด)** | dx/dt = rx − x³ | จุดเสถียรหนึ่งจุดแบ่งออกเป็นสองจุดเสถียร + จุดที่ไม่เสถียร |
| **โกย (ซับวิกฤต)** | dx/dt = rx + x³ | กิ่งก้านไม่มั่นคงพังทลาย (มักเกิดความหายนะ) |
| **ฮอปฟ์** | ระบบ 2D | จุดคงที่ไม่เสถียร วงรอบขีดจำกัดปรากฏ |
### แผนภาพการแยกไปสองทาง
พล็อตของจุดคงที่เทียบกับค่าพารามิเตอร์ ซึ่งแสดงความเสถียร (ทึบ = เสถียร, เส้นประ = ไม่เสถียร) แผนภาพการแยกไปสองทางของแผนที่ลอจิสติกส์เผยให้เห็นเส้นทางที่เพิ่มขึ้นเป็นสองเท่าของช่วงเวลาสู่ความโกลาหลและ **ค่าคงที่ Feigenbaum** ที่มีชื่อเสียง δ data 4.669 (อัตราส่วนสากลระหว่างช่วงการแยกไปสองทางต่อเนื่องกัน)

## สมการเชิงอนุพันธ์บางส่วน (PDE)
PDE เกี่ยวข้องกับฟังก์ชันของตัวแปรหลายตัวและอนุพันธ์ย่อยของตัวแปรเหล่านั้น
### การจำแนกประเภทของ PDE เชิงเส้นลำดับที่สอง
สำหรับ Au_xx + 2Bu_xy + Cu_yy + ... = 0:
| พิมพ์ | สภาพ | พฤติกรรม | ตัวอย่าง |
|------|-----------|-----------|---------|
| **รูปไข่** | B² - เอซี< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | การแพร่กระจายของคลื่นคงคุณสมบัติคมชัด | สมการคลื่น: u_tt = c²u_xx |
### สมการความร้อน
∂u/∂t = α ∂²u/∂x²
แบบจำลองการแพร่กระจายความร้อน การแพร่กระจายของประชากร ราคาตัวเลือก (Black-Scholes)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| การปรับให้เรียบ | การแก้ปัญหาจะราบรื่นทันที แม้จากข้อมูลเริ่มต้นที่ไม่ต่อเนื่อง |
| หลักการสูงสุด | อุณหภูมิสูงสุดเกิดขึ้นที่ขอบเขตหรือเวลาเริ่มต้น |
| การย้อนกลับของเวลา | กลับไม่ได้ — ไม่สามารถวิ่งย้อนกลับ |
### สมการคลื่น
∂²u/∂t² = ค² ∂²u/∂x²
แบบจำลองการสั่นสะเทือน สตริง เสียง คลื่นแม่เหล็กไฟฟ้า
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| การขยายพันธุ์ | สิ่งรบกวนเคลื่อนที่ด้วยความเร็ว c |
| การพลิกกลับได้ | ย้อนเวลาได้ |
| โซลูชันดาล็องแบร์ ​​| u(x,t) = f(x−ct) + g(x+ct) (การซ้อนทับของคลื่นซ้าย/ขวา) |
### สมการของลาปลาซ
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
สารละลาย (ฟังก์ชันฮาร์มอนิก) แสดงถึงอุณหภูมิในสภาวะคงตัว ศักย์ไฟฟ้าสถิตย์ การไหลของของเหลวที่ไม่สามารถบีบอัดได้
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| คุณสมบัติค่าเฉลี่ย | u(x₀) = ค่าเฉลี่ยของคุณเหนือวงกลมใดๆ ที่มีศูนย์กลางอยู่ที่ x₀ |
| หลักการสูงสุด | ไม่มีค่าสูงสุดหรือค่าต่ำสุดภายใน |
| ความเป็นเอกลักษณ์ | กำหนดโดยเงื่อนไขขอบเขตทั้งหมด |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| ดีเอส คอนเซ็ปต์ | ใบสมัคร |
|-----------|-------------|
| ODE | ODE ประสาท (เครือข่ายเชิงลึกต่อเนื่อง) การเปลี่ยนแปลงของเครือข่ายที่เกิดซ้ำ
| การวิเคราะห์ความเสถียร | การฝึกพลวัตของการไล่ระดับลง (การสูญเสียลดลงอย่างเสถียรหรือไม่?) |
| ฟังก์ชัน Lyapunov | พิสูจน์การบรรจบกันของอัลกอริทึมการเรียนรู้ เสริมความมั่นคงในการเรียนรู้ |
| ความโกลาหล | ทำความเข้าใจความไวใน RNN (การไล่ระดับสีที่หายไป/การระเบิด) การพยากรณ์อากาศ |
| การแยกไปสองทาง | การเปลี่ยนช่วงในการเรียนรู้ (grokking) การเปลี่ยนแปลงระบอบการปกครองในพลวัตการฝึกอบรม |
| PDE | โมเดลการแพร่กระจาย (โมเดลกำเนิดตามคะแนน) โครงข่ายประสาทเทียมตามฟิสิกส์
| สมการความร้อน | กระบวนการแพร่ในการสร้างแบบจำลองเชิงกำเนิด กราฟ การปรับให้เรียบของลาปลาเชียน |
| สมการคลื่น | การประมวลผลข้อมูลแผ่นดินไหว การสร้างแบบจำลองสัญญาณเสียง |
| ล็อตก้า-โวลแตร์รา | พลวัตของประชากร ระบาดวิทยา ตัวแทน ML ที่แข่งขันกัน |
| เฟสพอร์ตเทรต | การแสดงภาพพลวัตของภูมิทัศน์ที่สูญเสีย ทำความเข้าใจการฝึกอบรม GAN

## สรุป
| หัวข้อ | แนวคิดหลัก | เครื่องมือสำคัญ |
|-------|-----------|----------|
| ODE | ฟังก์ชันและอนุพันธ์ของเวลา | สมการคุณลักษณะเฉพาะตัวประกอบการปริพันธ์ |
| ระบบของ ODE | ตัวแปรโต้ตอบหลายตัว | การวิเคราะห์ค่าลักษณะเฉพาะของจาโคเบียน |
| เฟสพอร์ตเทรต | การแสดงภาพไดนามิกในพื้นที่รัฐ | จุดคงที่, nullclines, รอบขีดจำกัด |
| ความมั่นคง | ระบบจะกลับสู่สมดุลหรือไม่? | การทำให้เชิงเส้นตรง, ฟังก์ชันเลียปูนอฟ |
| ความโกลาหล | ความคาดเดาไม่ได้เชิงกำหนด | เลขชี้กำลัง Lyapunov ตัวดึงดูดที่แปลกประหลาด |
| การแยกไปสองทาง | การเปลี่ยนแปลงเชิงคุณภาพพร้อมพารามิเตอร์ | รูปแบบปกติ แผนภาพแฉก |
| PDE | ฟังก์ชันของตัวแปรหลายตัว | สมการความร้อน คลื่น และลาปลาซ |
ทฤษฎีระบบไดนามิกคือคณิตศาสตร์ของการเปลี่ยนแปลง มันอธิบายว่าทำไมบางระบบถึงสงบลง ทำไมบางระบบถึงแกว่ง และทำไมบางระบบมีพฤติกรรมวุ่นวาย สำหรับนักวิทยาศาสตร์ข้อมูล มีเครื่องมือสำหรับการทำความเข้าใจไดนามิกของการฝึกอบรม การออกแบบอัลกอริธึมที่เสถียร การสร้างแบบจำลองอนุกรมเวลา และการสร้างโมเดลการเรียนรู้ของเครื่องที่อิงตามฟิสิกส์รุ่นต่อไป
