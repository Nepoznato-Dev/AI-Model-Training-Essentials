#แม่เหล็กไฟฟ้า
แม่เหล็กไฟฟ้าคือการศึกษาสนามไฟฟ้าและสนามแม่เหล็กและปฏิกิริยาระหว่างกัน แม่เหล็กไฟฟ้าเป็นอันหนึ่งอันเดียวกันโดยแมกซ์เวลล์ในคริสต์ทศวรรษ 1860 อธิบายแสง ไฟฟ้า แม่เหล็ก คลื่นวิทยุ และโครงสร้างของอะตอม มันเป็นพลังพื้นฐานประการแรกที่ต้องเข้าใจอย่างถ่องแท้ทางคณิตศาสตร์ และสมการของมันเป็นแรงบันดาลใจให้เกิดทฤษฎีสัมพัทธภาพพิเศษและทฤษฎีสนามสมัยใหม่ของไอน์สไตน์
---

## สนามไฟฟ้า
### กฎของคูลอมบ์
แรงระหว่างประจุสองจุด q₁ และ q₂ คั่นด้วยระยะทาง r:
**F** = (1/4πε₀) · (q₁q₂/r²) · r̂
| ค่าคงที่ | ค่า |
|----------|-------|
| ε₀ (การอนุญาตของพื้นที่ว่าง) | 8.854 × 10⁻¹² F/m |
| 1/4πε₀ (ค่าคงที่คูลอมบ์ k) | 8.988 × 10⁹ N·m²/C² |
### คำจำกัดความของสนามไฟฟ้า
**E** = **F**/q (แรงต่อหน่วยประจุ)
สำหรับการชาร์จแบบจุด Q: **E** = (1/4πε₀) · (Q/r²) · r̂
### เส้นสนามไฟฟ้า
| คุณสมบัติ | กฎ |
|----------|-|
| ทิศทาง | ชี้ออกไปจากประจุบวก ไปทางลบ |
| ความหนาแน่น | เส้นที่ใกล้กว่า = สนามที่แข็งแกร่งกว่า |
| ข้าม | เส้นสนามไม่เคยข้าม |
| ตัวนำ | เส้นตรงบรรจบกับพื้นผิวตั้งฉาก |
### ศักย์ไฟฟ้า (แรงดันไฟฟ้า)
V = −∫ **E** · d**l** (ความต่างศักย์คืออินทิกรัลเส้นลบของ E)
**E** = −∇V (ฟิลด์คือความชันเชิงลบของศักยภาพ)
สำหรับการชาร์จแบบจุด: V = (1/4πε₀) · Q/r
| แนวคิด | สูตร | หน่วย |
|---------|---------|-|
| พลังงานศักย์ | U = คิววี | จูลส์ |
| อิเล็กตรอน-โวลต์ | 1 eV = 1.602 × 10⁻¹⁹ J | หน่วยพลังงาน |
| พื้นผิวสมศักย์ | พื้นผิว โดยที่ V คงที่ | E ตั้งฉากกับมัน |
---

## กฎของเกาส์
### คำแถลง
ฟลักซ์ไฟฟ้ารวมที่ผ่านพื้นผิวปิดใดๆ เท่ากับประจุปิดหารด้วย ε₀:
∮ **E** · d**A** = Q_enc / ε₀
ในรูปแบบดิฟเฟอเรนเชียล: ∇ · **E** = ρ/ε₀
### การใช้กฎของเกาส์
กฎของเกาส์มีประโยชน์มากที่สุดเมื่อความสมมาตรทำให้สามารถดึง E ออกจากอินทิกรัลได้
| สมมาตร | พื้นผิวเกาส์เซียน | ผลลัพธ์ |
|----------|-----------------|--------|
| ทรงกลม | สเฟียร์ | E = Q/(4πε₀r²) ด้านนอก |
| ทรงกระบอก (ประจุเส้น) | กระบอกสูบ | E = แล/(2πε₀r) |
| ระนาบ (แผ่นอนันต์) | ป้อมปืน | E = σ/(2ε₀) |
| ระหว่างแผ่นขนาน | ป้อมปืน | E = σ/ε₀ |
---

## ตัวนำและตัวเก็บประจุ
### ตัวนำในสมดุลไฟฟ้าสถิต
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| E = 0 ภายใน | ค่าธรรมเนียมจัดเรียงใหม่เพื่อยกเลิกฟิลด์ภายใน |
| ประจุทั้งหมดบนพื้นผิว | ภายในไม่มีค่าบริการสุทธิ |
| E ตั้งฉากที่พื้นผิว | ไม่มีส่วนประกอบในวงสัมผัส (มิฉะนั้น ประจุจะเคลื่อนที่) |
| ศักย์ไฟฟ้าเท่ากันตลอด | V เดียวกันทุกที่ทั้งภายในและภายนอก |
### ตัวเก็บประจุ
**ตัวเก็บประจุ** เก็บพลังงานไว้ในสนามไฟฟ้าระหว่างตัวนำ 2 ตัว
| การกำหนดค่า | ความจุ |
|--------------|-------------|
| จานขนาน | C = ε₀A/d |
| ทรงกระบอก | C = 2πε₀L / ln(b/a) |
| ทรงกลม | C = 4πε₀ab / (b−a) |
| สูตร | นิพจน์ |
|---------|------------|
| ประจุแรงดันไฟฟ้า | ถาม = CV |
| พลังงานที่สะสมไว้ | U = ½CV² = ½Q²/C |
| ความหนาแน่นของพลังงาน | คุณ = ½ε₀E² |
| ชุดรวม | 1/C_total = 1/C₁ + 1/C₂ + ... |
| การรวมกันแบบขนาน | C_total = C₁ + C₂ + ... |
### ไดอิเล็กทริก
การใส่ไดอิเล็กตริก (วัสดุฉนวน) ด้วยค่าคงที่ κ จะเพิ่มความจุ: C = κC₀

## สนามแม่เหล็ก
### แรงแม่เหล็ก
**F** = q(**v** × **B**) (แรงลอเรนซ์ ส่วนประกอบแม่เหล็ก)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ทิศทาง | ตั้งฉากกับทั้ง v และ B (กฎมือขวา) |
| ทำงานเสร็จแล้ว | ศูนย์ (แรงตั้งฉากกับความเร็ว) |
| การเคลื่อนที่แบบวงกลม | รัศมี r = mv/(qB) ในฟิลด์ B สม่ำเสมอ |
### กฎหมาย Biot-Savart
สนามแม่เหล็กเนื่องจากองค์ประกอบกระแสเล็ก:
d**B** = (μ₀/4π) · ฉัน(d**l** × r̂) / r²
| ค่าคงที่ | ค่า |
|----------|-------|
| μ₀ (การซึมผ่านของพื้นที่ว่าง) | 4π × 10⁻⁷ T·m/A |
### กฎของแอมแปร์
∮ **B** · d**l** = μ₀I_enc
ในรูปแบบดิฟเฟอเรนเชียล: ∇ × **B** = μ₀**J**
**การใช้งาน:**
| การกำหนดค่า | ฟิลด์ B |
|--------------|---------|
| ลวดตรงยาว | B = μ₀I/(2πr) |
| โซลินอยด์ (ด้านใน) | B = μ₀nI |
| Toroid (ด้านใน) | B = μ₀NI/(2πr) |
---

## การเหนี่ยวนำแม่เหล็กไฟฟ้า
### กฎของฟาราเดย์
การเปลี่ยนแปลงของฟลักซ์แม่เหล็กจะทำให้เกิดแรงเคลื่อนไฟฟ้า (EMF):
EMF = −dΦ_B/dt
โดยที่ Φ_B = ∫ **B** · d**A** คือฟลักซ์แม่เหล็ก
ในรูปแบบดิฟเฟอเรนเชียล: ∇ × **E** = −∂**B**/∂t
**กฎของเลนซ์:** EMF ที่ถูกเหนี่ยวนำจะต่อต้านการเปลี่ยนแปลงของฟลักซ์ (เครื่องหมายลบ)
### การประยุกต์ใช้การเหนี่ยวนำ
| ใบสมัคร | หลักการ |
|-------------|-----------|
| เครื่องกำเนิดไฟฟ้า | คอยล์หมุนในสนาม B → EMF สลับ |
| หม้อแปลงไฟฟ้า | การเปลี่ยนกระแสในปฐมภูมิ → EMF ในทุติยภูมิ |
| ตัวเหนี่ยวนำ | ตรงข้ามกับการเปลี่ยนแปลงในปัจจุบัน: EMF = −L(dI/dt) |
| กระแสน้ำวน | กระแสเหนี่ยวนำในตัวนำจำนวนมาก (การเบรก การทำความร้อน) |
### ตัวเหนี่ยวนำ
| สูตร | นิพจน์ |
|---------|------------|
| การเชื่อมโยงฟลักซ์ | Φ = LI |
| พลังงานที่สะสมไว้ | U = ½LI² |
| ชุดรวม | L_total = L₁ + L₂ + ... |
| การรวมกันแบบขนาน | 1/L_total = 1/L₁ + 1/L₂ + ... |
---

## สมการของแมกซ์เวลล์
สมการของแมกซ์เวลล์รวมไฟฟ้าและแม่เหล็กเข้าไว้ในทฤษฎีเดียว
### ในรูปแบบอินทิกรัล
| สมการ | ชื่อ | คำชี้แจง |
|----------|-|-----------|
| ∮ **E** · d**A** = Q/ε₀ | กฎของเกาส์ (ไฟฟ้า) | ฟลักซ์ไฟฟ้า = ประจุปิด |
| ∮ **B** · ง**A** = 0 | กฎของเกาส์ (แม่เหล็ก) | ไม่มีขั้วแม่เหล็กเดี่ยว |
| ∮ **E** · d**l** = −dΦ_B/dt | กฎของฟาราเดย์ | การเปลี่ยน B จะทำให้เกิด E |
| ∮ **B** · d**l** = μ₀I + μ₀ε₀ dΦ_E/dt | กฎหมายแอมแปร์-แมกซ์เวลล์ | E ปัจจุบันและการเปลี่ยนแปลงผลิต B |
### ในรูปแบบที่แตกต่างกัน
| สมการ | ชื่อ | นิพจน์ |
|----------|-|------------|
| เกาส์ (ไฟฟ้า) | ∇ · **E** = ρ/ε₀ |
| เกาส์ (แม่เหล็ก) | ∇ · **B** = 0 |
| ฟาราเดย์ | ∇ × **E** = −∂**B**/∂t |
| แอมแปร์-แม็กซ์เวลล์ | ∇ × **B** = μ₀**J** + μ₀ε₀ ∂**E**/∂t |
### กระแสแทนที่
การเพิ่มที่สำคัญของ Maxwell: คำว่า μ₀ε₀ ∂**E**/∂t (กระแสการกระจัด) สิ่งนี้ทำให้มั่นใจได้ถึงการอนุรักษ์ประจุและคาดการณ์คลื่นแม่เหล็กไฟฟ้า
---

## คลื่นแม่เหล็กไฟฟ้า
ในสุญญากาศ (ไม่มีประจุ ไม่มีกระแส) สมการของแมกซ์เวลล์จะให้สมการคลื่น:
∇²**E** = μ₀ε₀ ∂²**E**/∂t²
∇²**B** = μ₀ε₀ ∂²**B**/∂t²
**ความเร็วแสง:** c = 1/√(μ₀ε₀) µ 3 × 10⁸ m/s
### คุณสมบัติของคลื่น EM
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| ขวาง | E และ B ตั้งฉากกันและกับทิศทางการแพร่กระจาย |
| ในเฟส | E และ B ไปถึงจุดสูงสุดพร้อมกัน |
| อัตราส่วนขนาด | E = CB |
| ฟลักซ์พลังงาน | S = (1/μ₀)**E** × **B** (เวกเตอร์การชี้) |
| ความเข้ม | ฉัน = ⟨S⟩ = E₀²/(2μ₀c) |
### สเปกตรัมแม่เหล็กไฟฟ้า
| พิมพ์ | ความยาวคลื่น | ความถี่ | ที่มา |
|------|-----------|-----------|--------|
| วิทยุ | > 1 ม. | < 300 MHz | Antennas |
| Microwave | 1 mm − 1 m | 300 MHz − 300 GHz | Magnetrons, klystrons |
| Infrared | 700 nm − 1 mm | 300 GHz − 430 THz | Thermal radiation |
| Visible | 400 − 700 nm | 430 − 750 THz | Atomic transitions |
| Ultraviolet | 10 − 400 nm | 750 THz − 30 PHz | Hot objects, stars |
| X-ray | 0.01 − 10 nm | 30 PHz − 30 EHz | Electron deceleration |
| Gamma ray | < 0.01 nm | >30 EHz | กระบวนการนิวเคลียร์ |

## วงจรไฟฟ้ากระแสสลับ
### ส่วนประกอบวงจร RLC
| ส่วนประกอบ | ความสัมพันธ์ระหว่างแรงดันไฟฟ้าและกระแส | ความต้านทาน |
|----------|------------------------|-----------|
| ตัวต้านทาน (R) | วี = IR | Z_R = ร |
| ตัวเหนี่ยวนำ (L) | วี = L(dI/dt) | Z_L = jωL |
| ตัวเก็บประจุ (C) | ผม = C(dV/dt) | Z_C = 1/(jωC) |
### ความต้านทานและเสียงสะท้อน
อิมพีแดนซ์รวม (ซีรีย์ RLC): Z = R + j(ωL − 1/ωC)
|ω| = √(R² + (ωL − 1/ωC)²)
**เสียงสะท้อน:** เมื่อ ωL = 1/ωC → ω₀ = 1/√(LC)
- ที่เสียงสะท้อน: อิมพีแดนซ์คือค่าต่ำสุด (= R) กระแสคือค่าสูงสุด
- **ปัจจัยด้านคุณภาพ:** Q = ω₀L/R (ความคมชัดของเสียงสะท้อน)
### กำลังในวงจรไฟฟ้ากระแสสลับ
| ปริมาณ | สูตร |
|----------|---------|
| กำลังเฉลี่ย | P_avg = V_rms · I_rms · cos φ |
| ตัวประกอบกำลัง | เพราะ φ = R/\|Z\| |
| แรงดัน RMS | V_rms = V₀/√2 |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิด EM | ใบสมัคร |
|-----------|-------------|
| สมการของแมกซ์เวลล์ | โครงข่ายประสาทเทียมตามหลักฟิสิกส์ แม่เหล็กไฟฟ้าเชิงคำนวณ |
| สมการคลื่น | รากฐานการประมวลผลสัญญาณ แรงจูงใจในการวิเคราะห์ฟูริเยร์
| สเปกตรัมแม่เหล็กไฟฟ้า | ข้อมูลเซ็นเซอร์ (กล้องอินฟราเรด เรดาร์ ภาพถ่ายดาวเทียม) |
| วงจรไฟฟ้ากระแสสลับ / อิมพีแดนซ์ | ทำความเข้าใจกับฮาร์ดแวร์ที่ใช้ ML (แหล่งจ่ายไฟ ความสมบูรณ์ของสัญญาณ) |
| การชี้เวกเตอร์ | การไหลของพลังงานในการสื่อสารไร้สาย (เกี่ยวข้องกับ IoT/edge ML) |
| กฎของเกาส์ | คล้ายคลึงกับความแตกต่างในแคลคูลัสเวกเตอร์ ใช้ในการจำลองพลศาสตร์ของไหล |
| ตัวเก็บประจุ/ตัวเหนี่ยวนำ | การคำนวณแบบอะนาล็อกสำหรับโครงข่ายประสาทเทียม ฮาร์ดแวร์นิวมอร์ฟิก
| เสียงสะท้อน | การออกแบบตัวกรอง การวิเคราะห์โดเมนความถี่ วิธีสเปกตรัม |
| ปัญหาค่าขอบเขต | วิธีไฟไนต์เอลิเมนต์ การจำลองแบบตาข่าย |
| แคลคูลัสเวกเตอร์ (∇·, ∇×) | เครื่องมือทางคณิตศาสตร์สำคัญที่ใช้ตลอดทฤษฎี ML |

## สรุป
| กฎหมาย | มันบอกว่าอะไร | แบบฟอร์มส่วนต่าง |
