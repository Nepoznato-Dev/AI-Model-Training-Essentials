# สถิติและความน่าจะเป็น
ความน่าจะเป็นและสถิติเป็นรากฐานทางคณิตศาสตร์ของวิทยาศาสตร์ข้อมูล การเรียนรู้ของเครื่อง และการวิจัยทางวิทยาศาสตร์ ความน่าจะเป็นจะบอกคุณว่าเหตุการณ์ต่างๆ มีแนวโน้มเป็นอย่างไร สถิติจะบอกวิธีการสรุปผลจากข้อมูล พวกเขาร่วมกันเปลี่ยนความไม่แน่นอนให้เป็นความรู้เชิงปริมาณและจัดการได้
---

## ทฤษฎีความน่าจะเป็น
### แนวคิดหลัก
| แนวคิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **พื้นที่ตัวอย่าง** | ชุดของผลลัพธ์ที่เป็นไปได้ทั้งหมด | ทอยลูกเต๋า: {1, 2, 3, 4, 5, 6} |
| **กิจกรรม** | เซตย่อยของพื้นที่ตัวอย่าง | การทอยเลขคู่: {2, 4, 6} |
| **ความน่าจะเป็น** | ตัวเลขระหว่าง 0 ถึง 1 การวัดความน่าจะเป็น | P(กลิ้ง 6) = 1/6 |
| **ความน่าจะเป็นแบบมีเงื่อนไข** | P(A|B): ความน่าจะเป็นของ A ที่กำหนด B เกิดขึ้น | P(ฝน | มีเมฆมาก) |
| **ความเป็นอิสระ** | เหตุการณ์ที่เหตุการณ์หนึ่งไม่ส่งผลกระทบต่ออีกเหตุการณ์หนึ่ง | การพลิกเหรียญมีความเป็นอิสระ |
### กฎความน่าจะเป็น
| กฎ | สูตร | ใช้กรณี |
|------|---------|----------|
| **กฎเพิ่มเติม** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | ความน่าจะเป็นของ A หรือ B |
| **กฎการคูณ** | P(A ∩ B) = P(A) × P(B|A) | ความน่าจะเป็นของ A และ B |
| **กฎการเสริม** | P(ไม่ใช่ A) = 1 − P(A) | ความน่าจะเป็นของเหตุการณ์ที่ไม่เกิดขึ้น |
| **กฎแห่งความน่าจะเป็นทั้งหมด** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) | การแบ่งพาร์ติชันตามเหตุการณ์ที่ไม่เกิดร่วมกัน |
| **ทฤษฎีบทของเบย์ส** | P(A|B) = P(B|A) × P(A) / P(B) | อัพเดตความเชื่อด้วยหลักฐาน |
### การแจกแจงความน่าจะเป็น
| การจัดจำหน่าย | พิมพ์ | พารามิเตอร์ที่สำคัญ | ใช้กรณี |
|-----------------|-|-----------------|----------|
| **ปกติ (เกาส์เซียน)** | ต่อเนื่อง | ค่าเฉลี่ย (μ) ส่วนเบี่ยงเบนมาตรฐาน (σ) | ปรากฏการณ์ทางธรรมชาติ ข้อผิดพลาดในการวัด |
| **ทวินาม** | ไม่ต่อเนื่อง | n (การทดลอง), p (ความน่าจะเป็น) | ความสำเร็จ/ความล้มเหลวนับ |
| **ปัวซอง** | ไม่ต่อเนื่อง | แล (อัตรา) | เหตุการณ์ที่หายากในช่วงเวลา/พื้นที่ |
| **เอ็กซ์โปเนนเชียล** | ต่อเนื่อง | แล (อัตรา) | เวลาระหว่างเหตุการณ์ |
| **เครื่องแบบ** | ทั้งสอง | a, b (ขอบเขต) | ผลลัพธ์ที่เป็นไปได้เท่าเทียมกัน |
| **ไคสแควร์** | ต่อเนื่อง | k (องศาอิสระ) | การทดสอบความพอดี |
| **t-การกระจาย** | ต่อเนื่อง | ν (ระดับความอิสระ) | การอนุมานตัวอย่างขนาดเล็ก |
### คุณสมบัติที่สำคัญของการแจกแจง
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| **ค่าเฉลี่ย (ค่าที่คาดหวัง)** | จุดศูนย์กลางมวลของการแจกแจง: E[X] = Σ xᵢ × P(xᵢ) |
| **ผลต่าง** | กระจายไปทั่วค่าเฉลี่ย: Var(X) = E[(X − μ)²] |
| **ส่วนเบี่ยงเบนมาตรฐาน** | รากที่สองของความแปรปรวน หน่วยเดียวกับข้อมูล |
| **ความเบ้** | ความไม่สมมาตรของการกระจาย |
| **เคอร์โทซิส** | "ความเป็นหาง" — หางหนักแค่ไหน |

## การอนุมานทางสถิติ
### เชิงพรรณนาและสถิติเชิงอนุมาน
| | บรรยาย | อนุมาน |
|---|-------------|-------------|
| **วัตถุประสงค์** | สรุปและอธิบายข้อมูล | สรุปเกี่ยวกับประชากรจากกลุ่มตัวอย่าง |
| **เครื่องมือ** | ค่าเฉลี่ย ค่ามัธยฐาน โหมด ค่าเบี่ยงเบนมาตรฐาน แผนภูมิ | การทดสอบสมมุติฐาน ช่วงความเชื่อมั่น การถดถอย |
| **ขอบเขต** | เฉพาะข้อมูลที่คุณมี | การวางนัยทั่วไปนอกเหนือจากตัวอย่างของคุณ |
### กรอบการทดสอบสมมติฐาน
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| 1. **สมมุติฐาน** | สมมติฐานว่าง (H₀): ไม่มีผล; ทางเลือก (H₁): มีผล |
| 2. **เลือกระดับความสำคัญ** | α = 0.05 (ธรรมดา) |
| 3. **เลือกแบบทดสอบ** | ขึ้นอยู่กับประเภทข้อมูล ขนาดตัวอย่าง และสมมติฐาน |
| 4. **คำนวณสถิติการทดสอบ** | ขึ้นอยู่กับการทดสอบที่เลือก |
| 5. **หาค่า p** | ความน่าจะเป็นในการสังเกตข้อมูลหาก H₀ เป็นจริง |
| 6. **ตัดสินใจ** | ถ้า p < α ให้ปฏิเสธ H₀; มิฉะนั้นจะไม่สามารถปฏิเสธ H₀ | ได้
### การทดสอบทางสถิติทั่วไป
| ทดสอบ | เมื่อใดควรใช้ | เปรียบเทียบอะไร |
|------|-----------------|-----------------|
| **ที-เทสต์** | เปรียบเทียบค่าเฉลี่ย 1–2 กลุ่ม | จัดกลุ่มค่าเฉลี่ยของค่าหรือต่อกัน |
| **การทดสอบไคสแควร์** | ข้อมูลหมวดหมู่ | ความถี่ที่สังเกตได้เทียบกับความถี่ที่คาดหวัง |
| **ความแปรปรวน** | เปรียบเทียบค่าเฉลี่ยของ 3+ กลุ่ม | ความแปรปรวนระหว่างกลุ่มกับภายในกลุ่ม |
| **แมนน์-วิทนีย์ ยู** | ทางเลือกที่ไม่ใช่พารามิเตอร์สำหรับ t-test | การกระจายอันดับของสองกลุ่ม |
| **ความสัมพันธ์แบบเพียร์สัน** | ความสัมพันธ์เชิงเส้นระหว่างตัวแปรต่อเนื่องสองตัว | ค่า r จาก −1 ถึง +1 |
| **ความสัมพันธ์ของสเปียร์แมน** | ความสัมพันธ์แบบโมโนโทนิก (ตามอันดับ) | ค่า ρ สำหรับข้อมูลลำดับหรือข้อมูลที่ไม่ปกติ |
### ช่วงความเชื่อมั่น
ช่วงความเชื่อมั่นให้ช่วงค่าที่เป็นไปได้สำหรับพารามิเตอร์ประชากร:
- **95% CI สำหรับค่าเฉลี่ย** (รู้จักกันในชื่อ σ): x̄ ± 1.96 × (σ / √n)
- **การตีความ**: "เรามั่นใจ 95% ว่าค่าเฉลี่ยประชากรที่แท้จริงอยู่ภายในช่วงเวลานี้"
- **CI ที่กว้างขึ้น** = มีความไม่แน่นอนมากขึ้น (ตัวอย่างน้อยลง ความแปรปรวนสูงขึ้น หรือระดับความเชื่อมั่นสูงขึ้น)

## การวิเคราะห์การถดถอย
### ประเภทของการถดถอย
| พิมพ์ | ตัวแปรตาม | ใช้กรณี |
|------|------------------|----------|
| **การถดถอยเชิงเส้น** | ต่อเนื่อง | ทำนายราคาบ้าน ขาย |
| **การถดถอยโลจิสติก** | ไบนารี่ (0/1) | การจัดหมวดหมู่: การตรวจจับสแปม, การวินิจฉัยโรค |
| **การถดถอยพหุนาม** | ต่อเนื่อง (โค้ง) | กราฟการเติบโต แนวโน้มไม่เชิงเส้น |
| **การถดถอยพหุคูณ** | ต่อเนื่อง (ตัวทำนาย 2+ ตัว) | การควบคุมตัวรบกวน |
| **ริดจ์/บ่วงบาศ** | ต่อเนื่อง (สม่ำเสมอ) | การป้องกันการโอเวอร์ฟิต การเลือกคุณสมบัติ |
### พื้นฐานการถดถอยเชิงเส้น
แบบจำลอง: **y = β₀ + β₁x + ε**
| ส่วนประกอบ | ความหมาย |
|----------|---------|
| β₀ (สกัดกั้น) | ค่า y เมื่อ x = 0 |
| β₁ (ความชัน) | เปลี่ยนเป็น y สำหรับการเปลี่ยนแปลงหนึ่งหน่วยใน x |
| ε (คำผิดพลาด) | รูปแบบที่ไม่สามารถอธิบายได้ |
**ตัวชี้วัดหลัก:**
- **R² (สัมประสิทธิ์การกำหนด)**: สัดส่วนของความแปรปรวนที่อธิบายโดยแบบจำลอง (0 ถึง 1)
- **ปรับ R²**: R² ถูกลงโทษสำหรับจำนวนตัวทำนาย
- **RMSE**: ค่าคลาดเคลื่อนรูทค่าเฉลี่ยกำลังสอง — ค่าคลาดเคลื่อนในการทำนายค่าเฉลี่ยในหน่วยเดียวกันกับ y
### สมมติฐานของการถดถอยเชิงเส้น
| อัสสัมชัญ | มันหมายถึงอะไร | วิธีตรวจสอบ |
|----------|--------------|--------------|
| **ความเป็นเชิงเส้น** | ความสัมพันธ์ระหว่าง X และ Y เป็นแบบเชิงเส้น | แปลงกระจาย |
| **ความเป็นอิสระ** | การสังเกตมีความเป็นอิสระ | การออกแบบการศึกษา |
| **การรักร่วมเพศ** | ความแปรปรวนคงที่ของสารตกค้าง | แปลงที่เหลือ |
| **ความปกติ** | ที่เหลือมีการกระจายตามปกติ | พล็อต QQ, การทดสอบชาปิโร-วิลค์ |
| **ไม่มี multicollinearity** | ตัวทำนายไม่มีความสัมพันธ์กันมากนัก | VIF (ปัจจัยเงินเฟ้อแปรปรวน) |

## สถิติแบบเบย์
### คนประจำกับ Bayesian
| | คนประจำ | แบบเบย์ |
|---|-------------|----------|
| **ความน่าจะเป็นหมายถึง** | ความถี่ระยะยาว | ระดับความเชื่อ |
| **พารามิเตอร์คือ** | แก้ไขแล้ว แต่ไม่ทราบ | ตัวแปรสุ่มที่มีการแจกแจง |
| **การใช้งาน** | ค่า p, ช่วงความเชื่อมั่น | การแจกแจงหลัง, ช่วงเวลาที่น่าเชื่อถือ |
| **จุดแข็ง** | วัตถุประสงค์มั่นคง | รวมความรู้เดิม การตีความตามสัญชาตญาณ |
### ทฤษฎีบทของเบย์สในทางปฏิบัติ
**หลัง = (ความน่าจะเป็น × ก่อนหน้า) / หลักฐาน**
ตัวอย่าง — การทดสอบทางการแพทย์:
- ความชุกของโรค: 1% (ก่อนหน้า)
- ความไวในการทดสอบ: 95% (อัตราบวกจริง)
- ความจำเพาะของการทดสอบ: 90% (อัตราติดลบจริง)
- หากผลตรวจเป็นบวก: P(โรค | บวก) = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99) กลับไปยัง 8.8%
ผลลัพธ์ที่สวนทางกับสัญชาตญาณนี้ — ผลลัพธ์เชิงบวกส่วนใหญ่จะเป็นผลบวกลวงเมื่อโรคนี้เกิดขึ้นไม่บ่อย — คือ **การเข้าใจผิดของอัตราพื้นฐาน** และมันแสดงให้เห็นว่าเหตุใดการคิดแบบเบย์จึงมีความสำคัญ

## เคล็ดลับการปฏิบัติ
- **แสดงภาพข้อมูลของคุณเสมอ** ก่อนทำการทดสอบทางสถิติ
- **ตรวจสอบสมมติฐาน** — การละเมิดอาจทำให้ผลลัพธ์เป็นโมฆะ
- **ขนาดเอฟเฟกต์มีความสำคัญ** — ผลลัพธ์ที่มีนัยสำคัญทางสถิติอาจไม่มีความหมายในทางปฏิบัติ
- **ความสัมพันธ์ไม่ใช่สาเหตุ** — แม้แต่ความสัมพันธ์ที่รุนแรงก็อาจทำให้เกิดความสับสนได้
- **การเปรียบเทียบหลายรายการ** เพิ่มอัตราผลบวกลวง — ใช้การแก้ไข (Bonferroni, FDR)
- **รายงานช่วงความเชื่อมั่น** ไม่ใช่แค่ค่า p

## ทำไมเรื่องนี้ถึงสำคัญ
สถิติเป็นหัวใจสำคัญของการวิจัยทางวิทยาศาสตร์ การวิเคราะห์ธุรกิจ และการเรียนรู้ของเครื่อง หากไม่มีสิ่งนี้ คุณจะไม่สามารถบอกสัญญาณจากสัญญาณรบกวน ระบุผลกระทบที่แท้จริงจากความผันผวนแบบสุ่ม หรือคาดการณ์ด้วยความไม่แน่นอนเชิงปริมาณได้ ไม่ว่าคุณจะวิเคราะห์การทดสอบ A/B ฝึกอบรมโมเดล ML หรืออ่านเอกสารวิจัย ความรู้ทางสถิติถือเป็นสิ่งสำคัญ
