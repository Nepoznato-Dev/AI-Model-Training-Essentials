#กลศาสตร์ควอนตัม
กลศาสตร์ควอนตัมเป็นทฤษฎีฟิสิกส์ในระดับที่เล็กที่สุด ได้แก่ อะตอม อิเล็กตรอน โฟตอน และอนุภาคพื้นฐานของธรรมชาติ มันมาแทนที่โลกที่กำหนดขึ้นของกลศาสตร์คลาสสิกด้วยความน่าจะเป็น การซ้อนทับ และการพัวพัน แม้จะมีธรรมชาติที่ขัดกับสัญชาตญาณ แต่กลศาสตร์ควอนตัมก็เป็นทฤษฎีที่ได้รับการทดสอบอย่างแม่นยำที่สุดในวิทยาศาสตร์ทั้งหมด ในปัจจุบัน หลักการของโปรแกรมนี้มีความเกี่ยวข้องโดยตรงกับการคำนวณผ่านคอมพิวเตอร์ควอนตัม ซึ่งสัญญาว่าจะแก้ไขปัญหาบางอย่างได้เร็วกว่าเครื่องจักรแบบดั้งเดิมแบบทวีคูณ

## ความเป็นคู่ของคลื่นและอนุภาค
### ความยาวคลื่นของ Broglie
ทุกอนุภาคที่มีโมเมนตัม p มีความยาวคลื่นสัมพันธ์กัน:
แล = ชม./พี = ชม./(มิลลิโวลต์)
| อนุภาค | โดยทั่วไป แล | พฤติกรรมคลื่นที่สังเกตได้? |
|----------|-----------|---------------------------|
| อิเล็กตรอน (100 eV) | 0.12 นาโนเมตร | ใช่ (การเลี้ยวเบนของคริสตัล) |
| โปรตอน | 0.003 นาโนเมตร | ใช่ (การกระเจิงนิวตรอน) |
| เบสบอล (40 ม./วินาที) | 10⁻³⁴ ม. | ไม่ (เล็กเกินไปที่จะตรวจพบ) |
### การทดลองแบบ Double-Slit
การทดลองควอนตัมที่สำคัญ:
1. ปล่อยอนุภาคไฟ (อิเล็กตรอน โฟตอน) ทีละจุด โดยแบ่งเป็น 2 ช่อง
2. อนุภาคแต่ละอนุภาคตกลงที่จุดเดียวบนเครื่องตรวจจับ
3. เมื่อเวลาผ่านไป รูปแบบการรบกวนจะปรากฏขึ้น ราวกับว่าแต่ละอนุภาคผ่านช่องทั้งสองพร้อมกัน
4. หากคุณวัดว่าอนุภาคทะลุผ่านช่องใด รูปแบบการรบกวนจะหายไป
**บทสรุป:** วัตถุควอนตัมไม่ใช่ทั้งอนุภาคและคลื่นล้วนๆ โดยแสดงพฤติกรรมคล้ายคลื่นเมื่อตรวจไม่พบ และแสดงพฤติกรรมคล้ายอนุภาคเมื่อตรวจวัด

## ฟังก์ชั่นคลื่น
### คำนิยาม
**ฟังก์ชันคลื่น** ψ(x, t) อธิบายระบบควอนตัมได้อย่างสมบูรณ์ เป็นฟังก์ชันที่มีค่าเชิงซ้อนซึ่งมีโมดูลัสกำลังสองให้ความหนาแน่นของความน่าจะเป็น:
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### การทำให้เป็นมาตรฐาน
ความน่าจะเป็นรวมจะต้องเท่ากับ 1:
∫ |ψ(x)|² dx = 1 (ทั่วทุกพื้นที่)
### กฎแห่งการเกิด
ความน่าจะเป็นในการค้นหาอนุภาคระหว่าง x ถึง x + dx:
P(x ถึง x+dx) = |ψ(x)|² dx
สำหรับการสังเกตทั่วไปด้วย eigenstates φₙ:
P(การวัดค่าลักษณะเฉพาะ aₙ) = |⟨φₙ|ψ⟩|²

## สมการชโรดิงเงอร์
### สมการชโรดิงเงอร์ตามเวลา
iℏ ∂ψ/∂t = Ĥψ
โดยที่ Ĥ คือ **ตัวดำเนินการแบบแฮมิลตัน** (ตัวดำเนินการพลังงานทั้งหมด)
### สมการ Schrodinger ที่ไม่ขึ้นกับเวลา
สำหรับรัฐที่อยู่นิ่ง (ลักษณะเฉพาะของพลังงาน):
Ĥψ = อี ψ
นี่คือสมการค่าลักษณะเฉพาะ: พลังงานที่อนุญาต E คือค่าลักษณะเฉพาะของ Ĥ
### อนุภาคในกล่อง (Infinite Square Well)
ระบบควอนตัมที่ง่ายที่สุด: อนุภาคถูกจำกัดไว้ที่ 0 < x < L
| ปริมาณ | ผลลัพธ์ |
|---------||--------|
| ฟังก์ชันคลื่น | ψₙ(x) = √(2/L) บาป(nπx/L) |
| ระดับพลังงาน | Eₙ = n²π²ℏ²/(2mL²) = n²h²/(8mL²) |
| สถานะภาคพื้นดิน | n = 1, E₁ = h²/(8mL²) |
| พลังงานจุดศูนย์ | E₁ > 0 (อนุภาคไม่สามารถอยู่นิ่งได้อย่างสมบูรณ์) |
| หมายเลขควอนตัม | n = 1, 2, 3, ... (จำนวนเต็มบวกเท่านั้น) |
### ควอนตัมฮาร์มอนิกออสซิลเลเตอร์
V(x) = ½mω²x²
| ปริมาณ | ผลลัพธ์ |
|---------||--------|
| ระดับพลังงาน | Eₙ = (n + ½)ℏω |
| พลังงานจุดศูนย์ | E₀ = ½ℏω |
| การเว้นวรรค | ΔE = ℏω (สม่ำเสมอ) |
| ฟังก์ชันคลื่น | พหุนามเฮอร์ไมต์ × เกาส์เซียน |

## หลักความไม่แน่นอน
### หลักความไม่แน่นอนของไฮเซนเบิร์ก
∆x · ∆p ≥ ℏ/2
โดยทั่วไปแล้ว สำหรับ A และ B ที่สามารถสังเกตได้สองตัวใดๆ:
ΔA · ΔB ≥ (1/2)|⟨[Â, B̂]⟩|
### ความสัมพันธ์ที่ไม่แน่นอน
| จับคู่ | ความสัมพันธ์ | การตีความ |
|------|----------|----------------|
| ตำแหน่งโมเมนตัม | ΔxΔp ≥ ℏ/2 | ไม่สามารถรู้ได้อย่างแม่นยำทั้งคู่ |
| พลังงาน-เวลา | ΔEΔt ≥ ℏ/2 | รัฐอายุสั้นมีพลังงานไม่แน่นอน |
| โมเมนตัมเชิงมุม | ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| | ไม่สามารถรู้ส่วนประกอบทั้งหมดพร้อมกันได้ |
**สำคัญ:** ความไม่แน่นอนไม่ได้เกี่ยวกับการรบกวนในการวัด แต่เป็นคุณสมบัติพื้นฐานของสถานะควอนตัม อนุภาคไม่มีตำแหน่งและโมเมนตัมที่แน่นอนพร้อมกัน

## รัฐควอนตัมและการซ้อนทับ
### สัญลักษณ์ Dirac (Bra-Ket)
| สัญลักษณ์ | ชื่อ | ความหมาย |
|--------|-|---------|
| \|ψ⟩ | เกตุ | เวกเตอร์สถานะ (เวกเตอร์คอลัมน์) |
| ⟨ψ\| | บรา | คอนจูเกตทรานสโพส (เวกเตอร์แถว) |
| ⟨φ\|ψ⟩ | สินค้าภายใน | แอมพลิจูดสำหรับ ψ จะพบได้ในสถานะ φ |
| \|ψ\|² | บรรทัดฐานกำลังสอง | ความน่าจะเป็น |
### หลักการซ้อนทับ
ถ้า \|ψ₁⟩ และ \|ψ₂⟩ เป็นสถานะควอนตัมที่ถูกต้อง ดังนั้นผลรวมเชิงเส้นใดๆ ก็ใช้ได้เช่นกัน:
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

โดยที่ |α|² + |β|² = 1 (การทำให้เป็นมาตรฐาน)
**การวัด:** เมื่อวัดแล้ว ระบบจะ "ยุบ" เป็น \|ψ₁⟩ ด้วยความน่าจะเป็น |α|² หรือ \|ψ₂⟩ ด้วยความน่าจะเป็น |β|²
### ควิบิต
**คิวบิต** คือบิตควอนตัม: ระบบควอนตัมสองระดับ
\|ψ⟩ = α\|0⟩ + β\|1⟩ โดยที่ |α|² + |β|² = 1
| การเป็นตัวแทน | \|0⟩ | \|1⟩ |
|------------------|-------|-|
| หมุน | หมุนขึ้น ↑ | หมุนลง ↓ |
| โฟตอนโพลาไรเซชัน | แนวนอน | แนวตั้ง |
| ระดับพลังงาน | สถานะภาคพื้นดิน | รัฐตื่นเต้น |
| วงจร | \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**Bloch Sphere:** สถานะ qubit ใดๆ สามารถเขียนได้เป็น:
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iφ} sin(θ/2)\|1⟩
โดยที่ θ ∈ [0, π] และ φ ∈ [0, 2π) พื้นที่ของรัฐเป็นทรงกลม

## ความพัวพัน
คิวบิตสองอัน **พันกัน** เมื่อสถานะร่วมไม่สามารถเขียนเป็นผลคูณของแต่ละรัฐได้
### Bell States (พันกันมากที่สุด)
| รัฐ | นิพจน์ | ชื่อ |
|-------|-----------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) | รัฐเบลล์ |
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) | รัฐเบลล์ |
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) | รัฐเบลล์ |
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) | สถานะเสื้อกล้าม |
### คุณสมบัติของพัวพัน
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| สหสัมพันธ์ | การวัดหนึ่งควิบิตจะกำหนดอีกอันหนึ่งทันที โดยไม่คำนึงถึงระยะทาง |
| ไม่มีการสื่อสาร | ไม่สามารถใช้สิ่งกีดขวางเพียงอย่างเดียวในการส่งข้อมูลเร็วกว่าแสง |
| คู่สมรสคนเดียว | ถ้า A พัวพันกับ B มากที่สุด ก็จะไม่สามารถพัวพันกับ C | ได้
| ความเปราะบาง | การโต้ตอบกับสิ่งแวดล้อมทำลายสิ่งกีดขวาง (decoherence) |
### EPR Paradox และทฤษฎีบทของเบลล์
ไอน์สไตน์ โพโดลสกี และโรเซนแย้งว่ากลศาสตร์ควอนตัมจะต้องไม่สมบูรณ์ (ตัวแปรที่ซ่อนอยู่) เบลล์แสดงให้เห็นว่าทฤษฎีตัวแปรซ่อนเร้นเฉพาะที่เป็นไปตามความไม่เท่าเทียมกันบางประการ การทดลองละเมิดความไม่เท่าเทียมกันของเบลล์ - ยืนยันกลศาสตร์ควอนตัมและตัดตัวแปรที่ซ่อนอยู่ในเครื่องออก

### เกตส์ควิบิตเดี่ยว
| ประตู | เมทริกซ์ | เอฟเฟกต์ |
|------|--------|--------|
| **พอลลี-เอ็กซ์** (NOT) | [[0,1],[1,0]] | พลิกบิต: \|0⟩ ↔ \|1⟩ |
| **พอลลี-ย** | [[0,−i],[i,0]] | บิต + พลิกเฟส |
| **พอลลี-ซี** | [[1,0],[0,−1]] | พลิกเฟส: \|1⟩ → −\|1⟩ |
| **ฮาดามาร์ด** (H) | (1/√2)[[1,1],[1,−1]] | สร้างการซ้อนทับ: \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **เฟส** (S) | [[1,0],[0,i]] | π/2 หมุนรอบ Z |
| **ประตูที** | [[1,0],[0,e^{iπ/4}]] | π/4 หมุนรอบ Z |
| **การหมุน** Rₓ(θ) | cos(θ/2)I − i sin(θ/2)σₓ | หมุนด้วย θ รอบแกน X |
### ประตูสองควิบิต
| ประตู | คำอธิบาย | เอฟเฟกต์ |
|------|-------------|--------|
| **CNO** | ควบคุม-ไม่ | พลิกเป้าหมายหากการควบคุมคือ \|1⟩ |
| **ซีซี** | ควบคุม-Z | ใช้ Z กับเป้าหมายหากการควบคุมคือ \|1⟩ |
| **สลับ** | แลกเปลี่ยน qubits | \|ab⟩ → \|ba⟩ |
### สร้างความพัวพัน
ใช้ H กับ qubit 1 จากนั้น CNOT ด้วย qubit 1 เป็นตัวควบคุม:
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩

## อัลกอริทึมควอนตัม
| อัลกอริทึม | เร่งความเร็ว | ใบสมัคร |
|----------|---------|-------------|
| **ชอร์** | เลขชี้กำลัง (แฟคตอริ่ง) | ทำลายการเข้ารหัส RSA |
| **โกรเวอร์ส** | กำลังสอง (ค้นหา) | การค้นหาแบบไม่มีโครงสร้างใน O(√N) |
| **วีคิวอี** | ฮิวริสติก | การค้นหาพลังงานสถานะภาคพื้นดิน (เคมี วัสดุ) |
| **QAOA** | ฮิวริสติก | การเพิ่มประสิทธิภาพแบบผสมผสาน |
| **HHL** | เอ็กซ์โปเนนเชียล (ภายใต้เงื่อนไข) | การแก้ระบบเชิงเส้น |
| **การจำลองควอนตัม** | เอ็กซ์โปเนนเชียล | การจำลองระบบควอนตัม (แรงจูงใจดั้งเดิมของไฟน์แมน) |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดควอนตัม | ใบสมัคร |
|----------------|-------------|
| Qubits และการซ้อนทับ | การเรียนรู้ของเครื่องควอนตัม การสุ่มตัวอย่างที่ปรับปรุงด้วยควอนตัม |
| พัวพัน | การสื่อสารควอนตัม การกระจายคีย์ควอนตัม (QKD) |
| ประตูควอนตัม | การออกแบบวงจรควอนตัมสำหรับรูทีนย่อย ML
| อัลกอริทึมของโกรเวอร์ | การเร่งความเร็วแบบ Quadratic สำหรับการเพิ่มประสิทธิภาพตามการค้นหา |
| อัลกอริธึมของ Shor | ภัยคุกคามต่อการเข้ารหัสในปัจจุบัน กระตุ้นให้เกิดการเข้ารหัสลับหลังควอนตัม |
| การจำลองควอนตัม | การค้นพบยา วัสดุศาสตร์ การจำลองทางเคมี |
| อัลกอริธึมการเปลี่ยนแปลง (VQE, QAOA) | ML ควอนตัมระยะสั้นบนอุปกรณ์ NISQ |
| กฎโดยกำเนิด | ผลลัพธ์ความน่าจะเป็นคล้ายคลึงกับการสุ่มตัวอย่างจากการแจกแจง |
| ผลิตภัณฑ์เทนเซอร์ | ระบบหลายควิบิต (พื้นที่สถานะเอ็กซ์โพเนนเชียล — คณิตศาสตร์เดียวกับพีชคณิตหลายเชิงเส้นใน ML) |
| เมทริกซ์หน่วยเดียว | อะนาล็อกควอนตัมของการแปลงมุมฉาก |

## สรุป
| แนวคิด | แนวคิดหลัก | สมการสำคัญ |
|---------|-----------|-------------|
| ความเป็นคู่ของอนุภาคคลื่น | สสารมีคุณสมบัติเป็นคลื่น | แล = ชั่วโมง/พี |
| ฟังก์ชันคลื่น | คำอธิบายที่สมบูรณ์ของสถานะควอนตัม | P(x) = \|ψ(x)\|² |
| สมการโชรดิงเงอร์ | สถานะควอนตัมมีวิวัฒนาการอย่างไร | iℏ ∂ψ/∂t = Ĥψ |
| ตัวดำเนินการ | สิ่งที่สังเกตได้คือตัวดำเนินการ Hermitian | ⟨A⟩ = ⟨ψ\|Â\|ψ⟩ |
| ความไม่แน่นอน | ข้อจำกัดพื้นฐานเกี่ยวกับความรู้พร้อมกัน | ΔxΔp ≥ ℏ/2 |
| การซ้อนทับ | สามารถเพิ่มรัฐได้ | \|ψ⟩ = α\|0⟩ + β\|1⟩ |
| พัวพัน | สถานะร่วมที่แยกกันไม่ออก | \|Φ⁺⟩ = (\|00⟩ + \|11⟩)/√2 |
| ประตูควอนตัม | การดำเนินการรวมบน qubits | H, CNOT และชุดเกตสากล |
กลศาสตร์ควอนตัมท้าทายสัญชาตญาณที่ลึกซึ้งที่สุดของเราเกี่ยวกับความเป็นจริง ไม่ว่าจะเป็นอนุภาคที่เป็นคลื่น วัตถุในสองแห่งพร้อมกัน ความสัมพันธ์ที่ท้าทายคำอธิบายแบบคลาสสิก แต่คณิตศาสตร์ก็มีความแม่นยำและการทำนายก็แม่นยำอย่างไม่มีใครเทียบได้ สำหรับนักวิทยาศาสตร์ข้อมูล กลศาสตร์ควอนตัมกำลังมีความเกี่ยวข้องโดยตรงผ่านการประมวลผลควอนตัม ซึ่งสัญญาว่าจะเปลี่ยนแปลงการเพิ่มประสิทธิภาพ การเข้ารหัส การจำลอง และการเรียนรู้ของเครื่อง
