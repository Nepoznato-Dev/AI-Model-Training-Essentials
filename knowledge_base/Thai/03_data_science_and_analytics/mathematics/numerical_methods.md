# วิธีการเชิงตัวเลข
วิธีการเชิงตัวเลขเป็นสะพานเชื่อมระหว่างทฤษฎีทางคณิตศาสตร์และการคำนวณเชิงปฏิบัติ แม้ว่าคณิตศาสตร์บริสุทธิ์จะพิสูจน์ว่ามีวิธีแก้ปัญหาอยู่ แต่จริงๆ แล้ววิธีการเชิงตัวเลขจะคำนวณคำตอบโดยประมาณเพื่อให้ได้ความแม่นยำอันจำกัด โมเดลแมชชีนเลิร์นนิง การจำลองทางฟิสิกส์ และไปป์ไลน์การวิเคราะห์ข้อมูลทุกรูปแบบต้องอาศัยการคำนวณเชิงตัวเลขในท้ายที่สุด การทำความเข้าใจวิธีการเหล่านี้ — ความแม่นยำ ความเสถียร และข้อจำกัด — เป็นสิ่งจำเป็นสำหรับการสร้างซอฟต์แวร์ที่เชื่อถือได้

## เลขคณิตทศนิยม
คอมพิวเตอร์แสดงจำนวนจริงด้วยความแม่นยำจำกัด **มาตรฐาน IEEE 754** กำหนดวิธีจัดเก็บและจัดการตัวเลขทศนิยม

|----------------------|-|----------|----------|---------------------------|-------|
| ครึ่ง (fp16) | 16 | 5 | 10 | 3.3 | ±6.5 × 10⁴ |
| โสด (fp32) | 32 | 8 | 23 | 7.2 | ±3.4 × 10³⁸ |
| สองเท่า (fp64) | 64 | 11 | 52 | 15.9 | ±1.8 × 10³⁰⁸ |
### เครื่องเอปไซลอน
**เอปไซลอนของเครื่อง** (ε_mach) เป็นตัวเลขที่น้อยที่สุดโดยที่ 1 + ε_mach > 1 ในจุดลอยตัว
| รูปแบบ | ε_mach |
|--------|--------|
| fp16 | 2⁻¹⁰ data 9.8 × 10⁻⁴ |
| fp32 | 2⁻²³ หยาบคาย 1.2 × 10⁻⁷ |
| fp64 | 2⁻⁵² พรีเมี่ยม 2.2 × 10⁻¹⁶ |

## การค้นหาราก
การหา x โดยที่ f(x) = 0
### วิธีการแบ่งส่วน
| คุณสมบัติ | ค่า |
|----------|-------|
| ต้องใช้ | f ต่อเนื่อง f(a) และ f(b) มีเครื่องหมายตรงกันข้าม |
| การบรรจบกัน | เชิงเส้น (ข้อผิดพลาดลดลงครึ่งหนึ่งในแต่ละขั้นตอน) |
| รับประกัน? | ใช่ — มาบรรจบกัน | เสมอ
| การวนซ้ำสำหรับตัวเลข d | µ d / log₁₀(2) µ 3.32d |
**อัลกอริทึม:**
1. เริ่มต้นด้วยช่วง [a, b] โดยที่ f(a) · f(b) < 0
2. คำนวณจุดกึ่งกลาง c = (a + b) / 2
3. ถ้า f(c) = 0 หรือ |b − a| < ความอดทน หยุด
4. ถ้า f(a) · f(c) < 0, ให้เซต b = c; หรือตั้งค่า a = c
5. ทำซ้ำ
### วิธีนิวตัน-ราฟสัน
| คุณสมบัติ | ค่า |
|----------|-------|
| ต้องใช้ | f หาอนุพันธ์ได้ f'(x) ≠ 0 ที่รูต |
| การบรรจบกัน | กำลังสอง (ใกล้รูท) |
| รับประกัน? | ไม่ — อาจแตกต่างหรือหมุนเวียน |
| กฎการอัพเดท | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**ตัวอย่างที่ได้ผล:** ค้นหา √2 โดยการแก้ f(x) = x² − 2 = 0
- ฉ'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x₂ = 1.4167 − (2.0069 − 2) / 2.8333 = 1.4142
- x₃ = 1.41421356... (แก้ไขเป็นทศนิยม 8 ตำแหน่ง)
### วิธีการตัดออก
เช่นเดียวกับวิธีของนิวตัน แต่ประมาณค่าอนุพันธ์:
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
| คุณสมบัติ | ค่า |
|----------|-------|
| การบรรจบกัน | เส้นตรงยิ่งยวด (อันดับ อยู่ที่ 1.618, อัตราส่วนทองคำ) |
| ต้องใช้ | การเดาเบื้องต้นสองครั้ง (ไม่ต้องมีอนุพันธ์) |
### การเปรียบเทียบวิธีการหารูท
| วิธีการ | การบรรจบกัน | จำเป็นต้องมีอนุพันธ์หรือไม่? | รับประกัน? | ราคาต่อขั้นตอน |
|----------------------|-------------|-------------------|-------------|---------------|
| การแบ่งส่วน | เชิงเส้น (1) | ไม่ | ใช่ | 1 ฟังก์ชั่นประเมิน |
| นิวตัน-ราฟสัน | กำลังสอง (2) | ใช่ | ไม่ | 2 ฟังก์ชั่นประเมินผล |
| ซีแคนท์ | เส้นตรงยิ่งยวด (1.618) | ไม่ | ไม่ | 1 ฟังก์ชั่นประเมิน |
| วิธีการของเบรนต์ | เส้นตรง | ไม่ | ใช่ | ต่างกันไป |
**วิธีของเบรนต์** เป็นการรวมการแบ่งสองส่วน (การลู่เข้าที่รับประกัน) กับการประมาณค่ากำลังสองแบบซีแคนต์/ผกผัน (การลู่เข้าแบบเร็ว) มันเป็นเครื่องมือค้นหารูทเริ่มต้นในไลบรารีตัวเลขส่วนใหญ่

## บูรณาการเชิงตัวเลข (การสร้างพื้นที่สี่เหลี่ยมจัตุรัส)
กำลังคำนวณ ∫ₐᵇ f(x) dx โดยประมาณ
### วิธีการ
| วิธีการ | สูตร | ผิดพลาด | สั่งซื้อ |
|--------|---------|-------|-------|
| **สี่เหลี่ยมผืนผ้า (จุดกึ่งกลาง)** | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **สี่เหลี่ยมคางหมู** | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **ซิมป์สัน 1/3** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | O(ซ⁴) | 3 |
| **ซิมป์สัน 3/8** | ใช้ 4 จุดเว้นระยะเท่ากัน | O(ซ⁴) | 4 |
| **การสร้างพื้นที่สี่เหลี่ยมจัตุรัสแบบเกาส์เซียน** | ตำแหน่งโหนดที่เหมาะสมที่สุด | O(h²ⁿ) | n คะแนน |
### กฎรวม
สำหรับช่วงย่อย n ของความกว้าง h = (b−a)/n:
| กฎ | สูตรผสม | ผิดพลาด |
|------|------------------|-------|
| คอมโพสิตสี่เหลี่ยมคางหมู | h[f(a)/2 + Σf(xᵢ) + f(b)/2] | O(h²) |
| คอมโพสิตซิมป์สัน | h/3[f(a) + 4Σf(คี่) + 2Σf(คู่) + f(b)] | h/3[f(a) + 4Σf(คี่) + 2Σf(คู่) + f(b)] | O(ซ⁴) |
**ตัวอย่างการทำงาน:** โดยประมาณ ∫₀¹ e^(−x²) dx โดยใช้รูปสี่เหลี่ยมคางหมูผสมที่มี n = 4
- ชม. = 0.25, คะแนน: 0, 0.25, 0.5, 0.75, 1
- ฉ(0) = 1, ฉ(0.25) = 0.9394, ฉ(0.5) = 0.7788, ฉ(0.75) = 0.5698, ฉ(1) = 0.3679
- ต = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- ค่าจริง: หยาบคาย 0.7468 (ข้อผิดพลาด 0.5%)
### การสร้างพื้นที่สี่เหลี่ยมจัตุรัสแบบปรับได้
แบ่งย่อยช่วงเวลาที่ฟังก์ชันเปลี่ยนแปลงอย่างรวดเร็วโดยอัตโนมัติ โดยใช้จุดที่ราบรื่นน้อยลง นี่คือสิ่งที่`scipy.integrate.quad`ใช้ (ขึ้นอยู่กับ QUADPACK)

## การแก้ไข
การประมาณค่าระหว่างจุดข้อมูลที่ทราบ
### วิธีการ
| วิธีการ | คำอธิบาย | ความเรียบเนียน | การสั่น |
|--------|-------------|------------|-------------|
| **เพื่อนบ้านที่ใกล้ที่สุด** | ใช้จุดข้อมูลที่ใกล้เคียงที่สุด | ไม่ต่อเนื่อง | ไม่มี |
| **เชิงเส้น** | เชื่อมต่อจุดด้วยเส้นตรง | C⁰ (ต่อเนื่อง) | ไม่มี |
| **พหุนาม (ลากรองจ์)** | พหุนามเดี่ยวผ่านทุกจุด | ค^∞ | รุนแรงหลายจุด(ปรากฏการณ์รุงเง) |
| **เส้นโค้งลูกบาศก์** | ลูกบาศก์เรียงเป็นชิ้น เรียบตรงรอยต่อ | ซี² | น้อยที่สุด |
| **ฟังก์ชันพื้นฐานแนวรัศมี** | ผลรวมถ่วงน้ำหนักของเมล็ดในแนวรัศมี | ขึ้นอยู่กับเคอร์เนล | ต่ำ |
### การแก้ไขลากรองจ์
เมื่อกำหนดให้ n+1 คะแนน (x₀, y₀), ..., (xₙ, yₙ) ซึ่งเป็นพหุนามเฉพาะของดีกรี ≤ n ที่ผ่านทุกจุด:
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**ปรากฏการณ์ของรุงเง:** การประมาณค่าพหุนามระดับสูงที่จุดที่เว้นระยะเท่ากันสามารถแกว่งไปมาใกล้ขอบได้อย่างดุเดือด บรรเทาลงโดยใช้โหนดหรือเส้นโค้งของ Chebyshev
### ลูกบาศก์ Splines
พหุนามลูกบาศก์แบบแยกชิ้นที่ต่อเนื่องกันของ C² (อนุพันธ์อันดับสองต่อเนื่องกัน)
| พิมพ์ | สภาพขอบเขต |
|------|------------------|
| เส้นโค้งตามธรรมชาติ | S''(x₀) = S''(xₙ) = 0 |
| เส้นโค้งที่ถูกยึด | ระบุ S'(x₀) และ S'(xₙ) |
| ไม่ใช่ปม | อนุพันธ์อันดับสามต่อเนื่องที่ x₁ และ xₙ₋₁ |

## นักแก้ปัญหา ODE
การแก้สมการเชิงอนุพันธ์สามัญ dy/dt = f(t, y) ด้วยตัวเลข
### วิธีการของออยเลอร์
ตัวแก้ปัญหา ODE ที่ง่ายที่สุด
**อัปเดต:** y_{n+1} = y_n + h · f(t_n, y_n)
| คุณสมบัติ | ค่า |
|----------|-------|
| สั่งซื้อ | 1 (ข้อผิดพลาดต่อขั้นตอน: O(h²), global: O(h)) |
| ความมั่นคง | เสถียรตามเงื่อนไข (ต้องการ h เล็กน้อย) |
| ราคา | การประเมินฟังก์ชัน 1 รายการต่อขั้นตอน |
### วิธีรุ่งเง-คุตตะ
| วิธีการ | สั่งซื้อ | ขั้นตอน | หมายเหตุ |
|--------|-------|--------|--------|
| **ออยเลอร์** | 1 | 1 | ง่ายที่สุด |
| **จุดกึ่งกลาง** | 2 | 2 | แม่นยำยิ่งขึ้น |
| **ของฮอน (RK2)** | 2 | 2 | ตัวทำนาย-ตัวแก้ไข |
| **คลาสสิค RK4** | 4 | 4 | ม้านั่งทำงานมาตรฐาน |
| **ดอร์มานด์-ปรินซ์ (RK45)** | 4(5) | 6 | ขนาดขั้นตอนที่ปรับเปลี่ยนได้ (ใช้ใน ode45) |
### Classic RK4 (ลำดับที่ 4 Runge-Kutta)
k₁ = ฉ(t_n, y_n)
k₂ = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk₂/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k₂ + 2k₃ + k₄) / 6
| คุณสมบัติ | ค่า |
|----------|-------|
| สั่งซื้อ | 4 (ข้อผิดพลาดส่วนกลาง: O(h⁴)) |
| ราคา | การประเมินฟังก์ชัน 4 รายการต่อขั้นตอน |
| ความมั่นคง | ดีกว่าออยเลอร์ | มาก
| การใช้งาน | ค่าเริ่มต้นสำหรับ ODE ที่ไม่แข็งขัน |
### ODE ที่แข็งแกร่ง
ODE ที่เข้มงวด** มีส่วนประกอบที่แตกต่างกันไปตามมาตราส่วนเวลาที่แตกต่างกันอย่างมากมาย วิธีการที่ชัดเจน (ออยเลอร์, RK4) ต้องใช้ขนาดขั้นตอนที่เล็กจนไม่สามารถปฏิบัติได้
| วิธีการ | พิมพ์ | ความมั่นคง |
|----------------------|-|-----------|
| ออยเลอร์โดยนัย | โดยปริยาย | A-stable (เสถียรโดยไม่มีเงื่อนไข) |
| สูตรความแตกต่างแบบย้อนกลับ (BDF) | โดยปริยาย | A-stable (มากถึง 5 อันดับ) |
| โดยปริยาย Runge-Kutta | โดยปริยาย | มีแวเรียนต์ที่เสถียรของ L อยู่ |
| แอลโซดา | อัตโนมัติ | สลับระหว่างแบบแข็ง/ไม่แข็ง |

## เสถียรภาพเชิงตัวเลขและการปรับสภาพ
### เลขที่เงื่อนไข
**หมายเลขเงื่อนไข** จะวัดว่าผลลัพธ์ของปัญหาเปลี่ยนแปลงไปมากน้อยเพียงใด โดยสัมพันธ์กับการเปลี่ยนแปลงเล็กน้อยในอินพุต
สำหรับระบบเชิงเส้น Ax = b: κ(A) = ||A|| · ||A⁻¹||
| κ(ก) | การตีความ |
|-------|---------------|
| อยู่ที่ 1 | มีเครื่องปรับอากาศ |
| 10ลูกบาศก์ | อ่อนไหวเล็กน้อย |
| 10⁸ | ไม่มีเงื่อนไข (สูญเสียความแม่นยำ ~ 8 หลัก) |
| → ∞ | เอกพจน์ (ไม่มีวิธีแก้ปัญหาเฉพาะ) |
### ความเสถียรของอัลกอริทึม
อัลกอริธึมจะ **มีเสถียรภาพเชิงตัวเลข** หากการรบกวนเล็กน้อยในอินพุตนำไปสู่การรบกวนเล็กน้อยในเอาต์พุต (สัมพันธ์กับหมายเลขเงื่อนไขของปัญหา)
| อัลกอริทึม | มั่นคง? | หมายเหตุ |
|----------|---------|-------|
| การกำจัดแบบเกาส์เซียนด้วยการหมุนรอบบางส่วน | ใช่ | วิธีการมาตรฐาน |
| คำนวณค่าลักษณะเฉพาะผ่าน QR | ใช่ | ย้อนหลังมีเสถียรภาพ |
| ผลรวมไร้เดียงสา (ใหญ่ + เล็กก่อน) | ไม่ | ใช้ผลรวมคาฮัน |
| ความแปรปรวนทางคอมพิวเตอร์เป็น E[X²] − (E[X])² | อาจไม่มี | ใช้อัลกอริทึมออนไลน์ของ Welford |
### อัลกอริทึมออนไลน์ของ Welford
การคำนวณค่าเฉลี่ยและความแปรปรวนที่เสถียรทางตัวเลข:
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

วิธีนี้จะหลีกเลี่ยงการยกเลิกหายนะที่เกิดขึ้นในสูตรสองรอบที่ไร้เดียงสา

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| วิธีการเชิงตัวเลข | ใบสมัคร |
|-----------------|-------------|
| จุดลอยตัว (fp16/fp32/bf16) | การฝึกอบรมแบบผสมความแม่นยำ การหาปริมาณแบบจำลอง ประสิทธิภาพของหน่วยความจำ |
| การค้นหารูต | การประมาณค่าความน่าจะเป็นสูงสุด (การค้นหาโดยที่การไล่ระดับสี = 0) |
| การบูรณาการเชิงตัวเลข | การอนุมานแบบเบย์ (การคำนวณความน่าจะเป็นส่วนเพิ่ม) ค่าที่คาดหวัง |
| การแก้ไข | การปรับให้เรียบ การใส่ร้าย โมเดลตัวแทน ฟังก์ชั่นการเปิดใช้งาน |
| ตัวแก้ปัญหา ODE | ODE ประสาท, RNN ในเวลาต่อเนื่อง, พลวัตของประชากร, ML ตามหลักฟิสิกส์
| หมายเลขเงื่อนไข | ทำความเข้าใจประเด็นตัวเลขในการถดถอยเชิงเส้น สมการปกติ |
| ผลรวมที่เสถียร | ฟังก์ชันการสูญเสียทางคอมพิวเตอร์ สถิติการทำให้เป็นมาตรฐานแบบแบทช์ |
| RK4 / ตัวแก้ปัญหาแบบปรับตัว | จำลองระบบไดนามิก ฝึกอบรมเครือข่ายเชิงลึกต่อเนื่อง |

## สรุป
| หัวข้อ | แนวคิดหลัก | วิธีสำคัญ |
|-------|-----------|------------|
| จุดลอยตัว | การแสดงความแม่นยำจำกัด | IEEE 754, ผลรวม Kahan |
| การค้นหารูต | แก้ f(x) = 0 | การแบ่งส่วน, Newton-Raphson, Brent's |
| การบูรณาการเชิงตัวเลข | ประมาณ ∫f(x)dx | สี่เหลี่ยมคางหมู, ซิมป์สัน, การสร้างพื้นที่สี่เหลี่ยมจัตุรัสเกาส์เซียน |
| การแก้ไข | การประมาณค่าระหว่างจุดข้อมูล | ลูกบาศก์เส้นโค้ง, ลากรองจ์, RBF |
| ตัวแก้ปัญหา ODE | แก้ dy/dt = f(t,y) | ออยเลอร์, RK4, วิธีการปรับตัว |
| ความมั่นคง | ความไวต่อข้อผิดพลาดในการปัดเศษ | หมายเลขเงื่อนไข อัลกอริธึมที่เสถียร |
วิธีการเชิงตัวเลขคือจุดที่คณิตศาสตร์มาบรรจบกับความเป็นจริง ไม่มีคอมพิวเตอร์เครื่องใดสามารถแทนจำนวนจริงได้เป๊ะๆ ในทางปฏิบัติ ไม่มีการคำนวณอนุพันธ์เชิงสัญลักษณ์ในทางปฏิบัติ และไม่มีการคำนวณอินทิกรัลในรูปแบบปิดสำหรับปัญหาในโลกแห่งความเป็นจริง การทำความเข้าใจวิธีการเชิงตัวเลขทำให้คุณสามารถเลือกอัลกอริทึมที่เหมาะสม ทำนายความแม่นยำของอัลกอริทึม และหลีกเลี่ยงข้อบกพร่องเล็กๆ น้อยๆ ที่เกิดขึ้นจากการคำนวณที่มีความแม่นยำจำกัด
