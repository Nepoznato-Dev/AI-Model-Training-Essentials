# ตรรกะและการคิดอย่างมีวิจารณญาณ
ตรรกะคือการศึกษาการใช้เหตุผลที่ถูกต้อง วิธีสร้างข้อโต้แย้งที่ถูกต้องและระบุข้อโต้แย้งที่มีข้อบกพร่อง การคิดอย่างมีวิจารณญาณเป็นนิสัยที่มีวินัยในการตั้งคำถามต่อสมมติฐาน ประเมินหลักฐาน และให้เหตุผลอย่างรอบคอบ ทักษะเหล่านี้มีความสำคัญไม่เพียงแต่ในวิชาคณิตศาสตร์และวิทยาการคอมพิวเตอร์เท่านั้น แต่ยังมีความสำคัญในการตัดสินใจในชีวิตประจำวัน การวิจัยทางวิทยาศาสตร์ และการนำทางในโลกที่เต็มไปด้วยข้อมูล
---

## อาร์กิวเมนต์คืออะไร?
ตามตรรกะ **อาร์กิวเมนต์** คือชุดของข้อความ (สถานที่) ที่มีวัตถุประสงค์เพื่อสนับสนุนข้อสรุป
| ส่วนประกอบ | บทบาท | ตัวอย่าง |
|----------|-|---------|
| **สถานที่** | ข้อความที่เสนอไว้เป็นหลักฐาน | "มนุษย์ทุกคนต้องตาย" |
| **บทสรุป** | การเรียกร้องสิทธิสนับสนุนสถานที่ | "โสกราตีสเป็นมนุษย์" |
| **การอนุมาน** | ขั้นตอนเชิงตรรกะจากสถานที่สู่ข้อสรุป | "โสกราตีสเป็นมนุษย์ ดังนั้น..." |
### ใช้ได้เทียบกับเสียง
| ระยะเวลา | ความหมาย | ตัวอย่าง |
|------|---------|---------|
| **ถูกต้อง** | ถ้าสถานที่เป็นจริง ข้อสรุปจะต้องเป็นจริง | โครงสร้างถูกต้อง แม้ว่าสถานที่จะเป็นเท็จ |
| **ไม่ถูกต้อง** | ข้อสรุปไม่ได้ตามมาจากสถานที่ | โครงสร้างลอจิคัลใช้งานไม่ได้ |
| **เสียง** | ถูกต้อง และสถานที่ทั้งหมดเป็นจริง | มาตรฐานทองคำของการโต้แย้ง |
| **ไม่ปลอดภัย** | ไม่ถูกต้องหรือมีสถานที่เท็จ | อาร์กิวเมนต์ที่มีข้อบกพร่องมากที่สุด |

## ประเภทของการใช้เหตุผล
| พิมพ์ | ทิศทาง | ความแข็งแกร่ง | ตัวอย่าง |
|------|-----------|----------|---------|
| **นิรนัย** | ทั่วไป → เฉพาะ | แน่นอน (ถ้าถูกต้อง) | “สัตว์เลี้ยงลูกด้วยนมทุกชนิดมีปอด วาฬก็คือสัตว์เลี้ยงลูกด้วยนม ดังนั้น วาฬจึงมีปอด” |
| **อุปนัย** | เฉพาะ → ทั่วไป | น่าจะเป็น | “หงส์ทุกตัวที่ฉันเห็นเป็นสีขาว ดังนั้น หงส์ทุกตัวก็น่าจะเป็นสีขาว” |
| **ลักพาตัว** | การสังเกต → คำอธิบายที่ดีที่สุด | เป็นไปได้ | “หญ้าเปียก คำอธิบายที่ดีที่สุดคือฝนตก” |

## ตรรกะเชิงประพจน์
ตรรกะเชิงประพจน์เกี่ยวข้องกับประพจน์ง่ายๆ และวิธีการรวมเข้าด้วยกัน:
### การเชื่อมต่อเชิงตรรกะ
| เกี่ยวพัน | สัญลักษณ์ | ความหมาย | เงื่อนไขความจริง |
|----------|--------|---------|----------------|
| **และ** | ∧ (p ∧ q) | การเชื่อมต่อ | จริงเฉพาะเมื่อทั้งสองเป็นจริง |
| **หรือ** | ∨ (p ∨ q) | การแยกทาง | จริงเมื่ออย่างน้อยหนึ่งรายการเป็นจริง |
| **ไม่** | ฌ (âp) | การปฏิเสธ | ค่าความจริงตรงข้าม |
| **ถ้า...แล้ว** | → (p → q) | นัย | เท็จเฉพาะเมื่อ p เป็นจริง และ q เป็นเท็จ |
| **ไอเอฟเอฟ** | ↔ (p ↔ q) | เงื่อนไขสองเงื่อนไข | เป็นจริงเมื่อทั้งสองมีค่าความจริงเท่ากัน |
### ตารางความจริงสำหรับนัย (p → q)
| พี | คิว | พี → คิว |
|---|---|-------|
| ที | ที | ที |
| ที | ฉ | ฉ |
| ฉ | ที | ที |
| ฉ | ฉ | ที |
หมายเหตุ: หลักฐานเท็จทำให้ความหมายนั้นเป็นจริงอย่างว่างเปล่า "ถ้าดวงจันทร์เป็นเนยแข็ง ฉันก็คือพระสันตะปาปา" เป็นเรื่องจริงตามหลักเหตุผล

## พีชคณิตแบบบูล
พีชคณิตแบบบูลเป็นคณิตศาสตร์ของค่าจริง/เท็จ และเป็นรากฐานของการออกแบบและการเขียนโปรแกรมวงจรดิจิทัล:
| กฎหมาย | นิพจน์ | ความหมาย |
|-----|-----------|---------|
| **สับเปลี่ยน** | ก ∧ B = B ∧ ก | การสั่งซื้อไม่สำคัญ |
| **สมาคม** | (A ∧ B) ∧ C = A ∧ (B ∧ C) | การจัดกลุ่มไม่สำคัญ |
| **จำหน่าย** | A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) | AND กระจายมากกว่า OR |
| **เดอ มอร์แกนส์** | ฌ(A ∧ B) = ฌA ∨ ฌB | การปฏิเสธจะพลิก AND เป็น OR |
| **เดอ มอร์แกนส์** | ฌ(A ∨ B) = ฌA ∧ ฌB | การปฏิเสธจะพลิก OR เป็น AND |
| **การปฏิเสธสองครั้ง** | ฌ(ฌA) = ก | การปฏิเสธสองครั้งยกเลิก |
| **ตัวตน** | ก ∧ ต = ก; ก ∨ F = ก | องค์ประกอบเอกลักษณ์ |
| **ส่วนเสริม** | ก ∧ ฌA = F; ก ∨ ฌA = T | ความขัดแย้งและซ้ำซาก |

## การเข้าใจผิดเชิงตรรกะทั่วไป
การตระหนักถึงความผิดพลาดเป็นสิ่งสำคัญสำหรับการคิดอย่างมีวิจารณญาณ:
### การเข้าใจผิดอย่างเป็นทางการ (ข้อผิดพลาดทางโครงสร้าง)
| การเข้าใจผิด | โครงสร้าง | ตัวอย่าง |
|---------|-----------|---------|
| **ยืนยันผลที่ตามมา** | ถ้า P แล้ว Q. Q. ดังนั้น P. | “ถ้าฝนตก พื้นก็เปียก พื้นก็เปียก ฝนก็ตก” (เป็นสปริงเกอร์ก็ได้) |
| **การปฏิเสธสิ่งที่มาก่อน** | ถ้า P แล้ว Q ไม่ใช่ P ดังนั้น ไม่ใช่ Q. | “ถ้าฝนตก พื้นก็เปียก ฝนไม่ตก พื้นจึงไม่เปียก” |
### การเข้าใจผิดอย่างไม่เป็นทางการ (ข้อผิดพลาดของเนื้อหา)
| การเข้าใจผิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **โฆษณา Hominem** | โจมตีคน ไม่ใช่ทะเลาะ | “คุณไม่สามารถเชื่อถือแผนเศรษฐกิจของเธอได้ เธอไม่ใช่นักเศรษฐศาสตร์ด้วยซ้ำ” |
| **มนุษย์ฟาง** | การแสดงข้อโต้แย้งอย่างไม่ถูกต้องเพื่อให้โจมตีได้ง่ายขึ้น | “คุณต้องการลดการใช้จ่ายทางทหารเหรอ? ดังนั้นคุณจึงต้องการออกจากประเทศโดยไม่มีการป้องกัน!” |
| **อุทธรณ์ต่อผู้มีอำนาจ** | อ้างถึงหน่วยงานที่ไม่ใช่ผู้เชี่ยวชาญในสาขาที่เกี่ยวข้อง | “คนดังคนนี้บอกว่าการลดน้ำหนักแบบนี้ได้ผล ดังนั้นมันจึงต้องได้ผล” |
| **ภาวะที่กลืนไม่เข้าคายไม่ออก** | นำเสนอเพียงสองตัวเลือกเมื่อมีมากกว่า | “คุณจะอยู่กับเราหรือต่อต้านเรา” |
| **ทางลาดลื่น** | การโต้แย้งว่าเหตุการณ์หนึ่งย่อมนำไปสู่ผลลัพธ์สุดขั้วอย่างหลีกเลี่ยงไม่ได้ | “ถ้าเรายอมให้สิ่งนี้ สิ่งต่อไปที่คุณรู้คือความวุ่นวายทั้งหมด” |
| **การใช้เหตุผลแบบวงกลม** | ข้อสรุปจะถือว่าอยู่ในสถานที่ | “หนังสือเล่มนี้เป็นความจริงเพราะมันบอกว่ามันเป็นเรื่องจริง” |
| **สรุปด่วน** | สรุปแบบกว้างๆ จากหลักฐานไม่เพียงพอ | “ฉันเจอคนหยาบคายสองคนจากเมืองนั้น ทุกคนที่นั่นต้องหยาบคาย” |
| **โพสต์เฉพาะกิจ Ergo Propter Hoc** | สมมติสาเหตุจากลำดับเวลา | "ฉันทานอาหารเสริมตัวนี้แล้วรู้สึกดีขึ้น ดังนั้นมันจะต้องได้ผล" |
| **ปลาเฮอริ่งแดง** | แนะนำหัวข้อที่ไม่เกี่ยวข้องเพื่อเบี่ยงเบนความสนใจ | “คุณถามเกี่ยวกับนโยบายการศึกษาของฉัน แต่สิ่งสำคัญจริงๆ ก็คือเศรษฐกิจ” |
| **แบนด์วากอน** | บางสิ่งเป็นจริงเพราะหลายคนเชื่อ | "ใครๆ ก็ซื้อผลิตภัณฑ์นี้ ดังนั้นมันจะต้องดีที่สุด" |

## การประเมินข้อโต้แย้ง: รายการตรวจสอบ
| ขั้นตอน | คำถาม |
|------|----------|
| 1. **ระบุข้อสรุป** | ข้อโต้แย้งที่พยายามพิสูจน์คืออะไร? |
| 2. **ระบุสถานที่** | มีการเสนอหลักฐานอะไรบ้าง? |
| 3. **ตรวจสอบความถูกต้อง** | ข้อสรุปตามมาจากสถานที่หรือไม่? |
| 4. **ตรวจสอบความสมบูรณ์** | สถานที่เกิดเหตุจริงหรือไม่? |
| 5. **มองหาการเข้าใจผิด** | มีข้อผิดพลาดด้านโครงสร้างหรือเนื้อหาหรือไม่ |
| 6. **พิจารณาข้อโต้แย้ง** | อาจมีข้อโต้แย้งอะไรบ้าง? |
| 7. **ประเมินคุณภาพหลักฐาน** | หลักฐานมีความน่าเชื่อถือ เพียงพอ และเกี่ยวข้องหรือไม่ |

## ทำไมเรื่องนี้ถึงสำคัญ
ตรรกะและการคิดเชิงวิพากษ์เป็นรากฐานของคณิตศาสตร์ วิทยาการคอมพิวเตอร์ กฎหมาย และการซักถามทางวิทยาศาสตร์ ในโลกที่เต็มไปด้วยข้อมูลที่ไม่ถูกต้อง การโฆษณา และวาทศาสตร์โน้มน้าวใจ ความสามารถในการประเมินข้อโต้แย้งอย่างเข้มงวดไม่ได้เป็นเพียงทักษะทางวิชาการเท่านั้น แต่ยังเป็นทักษะในการเอาตัวรอดอีกด้วย ไม่ว่าคุณจะแก้ไขโค้ด ออกแบบอัลกอริทึม หรือตัดสินใจในชีวิต การใช้เหตุผลที่ชัดเจนจะแยกการตัดสินที่ดีออกจากการตัดสินใจที่ไม่ดี
