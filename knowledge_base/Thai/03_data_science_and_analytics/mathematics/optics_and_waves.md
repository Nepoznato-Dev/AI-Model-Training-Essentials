#ทัศนศาสตร์และคลื่น
คลื่นมีอยู่ทุกหนทุกแห่ง: เสียง แสง น้ำ สัญญาณวิทยุ แอมพลิจูดของความน่าจะเป็นควอนตัม ความผันผวนของตลาดหุ้น และการสั่นสะเทือนของการเปิดใช้งานโครงข่ายประสาทเทียม ทัศนศาสตร์ — การศึกษาเรื่องแสง — เป็นศาสตร์เกี่ยวกับคลื่นที่ได้รับการพัฒนาอย่างดีที่สุด และเครื่องมือทางคณิตศาสตร์ของวิทยาศาสตร์ (การวิเคราะห์ฟูเรียร์ การรบกวน การเลี้ยวเบน) นำไปใช้กับปรากฏการณ์คลื่นทุกรูปแบบ การทำความเข้าใจคลื่นเป็นสิ่งจำเป็นสำหรับการประมวลผลสัญญาณ การวิเคราะห์ภาพ การสื่อสาร และเลเยอร์ทางกายภาพของเทคโนโลยีสมัยใหม่ทั้งหมด

## สมการคลื่น
### สมการคลื่นทั่วไป
สมการคลื่นหนึ่งมิติ:
∂²u/∂t² = ค² ∂²u/∂x²
โดยที่ u(x,t) คือการกระจัดของคลื่น และ c คือความเร็วคลื่น
### โซลูชันทั่วไป (d'Alembert)
คุณ(x,t) = f(x − ct) + g(x + ct)
โดยที่ f คือคลื่นเคลื่อนที่ไปทางขวา และ g คือคลื่นเคลื่อนที่ไปทางซ้าย
### พารามิเตอร์คีย์เวฟ
| พารามิเตอร์ | สัญลักษณ์ | หน่วย | คำอธิบาย |
|----------|--------|--|-------------|
| แอมพลิจูด | ก | แตกต่างกันไป | การกระจัดสูงสุด |
| ความยาวคลื่น | แล | เมตร | ระยะห่างระหว่างยอดติดต่อกัน |
| ความถี่ | f หรือ ν | เฮิรตซ์ (Hz) | รอบต่อวินาที |
| ระยะเวลา | T = 1/ฉ | วินาที | เวลาสำหรับหนึ่งรอบที่สมบูรณ์ |
| หมายเลขคลื่น | k = 2π/แล | ราด/ม | ความถี่เชิงพื้นที่ |
| ความถี่เชิงมุม | ω = 2πf | rad/s | ความถี่ชั่วคราว |
| ความเร็วคลื่น | ค = fแล = ω/k | เมตร/วินาที | ความเร็วของการแพร่กระจาย |
### คลื่นไซน์
คุณ(x,t) = บาป(kx − ωt + φ)
โดยที่ φ คือค่าคงที่เฟส
### ความเร็วคลื่นในสื่อต่างๆ
| ประเภทคลื่น | ปานกลาง | สูตรความเร็ว |
|----------|--------|---------------|
| สตริง | ความตึงเครียด T ความหนาแน่นเชิงเส้น μ | ค = √(T/μ) |
| เสียง | โมดูลัสเป็นกลุ่ม B ความหนาแน่น ρ | ค = √(B/ρ) |
| เสียง(แก๊สเหมาะ) | γ, R, T, M | ค = √(γRT/M) |
| คลื่นอีเอ็ม | การอนุญาต ε การซึมผ่าน μ | c = 1/√(με) |
| คลื่น EM (สุญญากาศ) | ε₀, μ₀ | c = 3 × 10⁸ m/s |

## การซ้อนทับและการรบกวน
### หลักการซ้อนทับ
เมื่อคลื่นสองลูกขึ้นไปทับซ้อนกัน ผลลัพธ์ของการกระจัดคือผลรวมของการกระจัดแต่ละครั้ง:
u_total = u₁ + u₂ + ... + uₙ
สิ่งนี้ถือเป็นสมการคลื่นเชิงเส้น
### การรบกวนของคลื่นสองลูก
คลื่นสองลูกที่มีความถี่และแอมพลิจูดเท่ากัน เฟสต่างกัน Δφ:
u_total = 2A cos(Δφ/2) sin(kx − ωt + Δφ/2)
| ความแตกต่างของเฟส | ผลลัพธ์ | ความเข้ม |
|-----------------|--------|-----------|
| Δφ = 0, 2π, 4π, ... | **เชิงสร้างสรรค์** (แอมพลิจูด = 2A) | 4I₀ (สูงสุด) |
| Δφ = π, 3π, 5π, ... | **การทำลายล้าง** (แอมพลิจูด = 0) | 0 (ขั้นต่ำ) |
| Δφ = π/2 | บางส่วน | 2I₀ |
### เงื่อนไขการแทรกแซง
| สภาพ | พิมพ์ | ความแตกต่างของเส้นทาง |
|----------|-------|-----------------|
| สร้างสรรค์ | ฟรุ้งฟริ้ง | ΔL = mแล (m = 0, 1, 2, ...) |
| ทำลายล้าง | ขอบสีเข้ม | ΔL = (ม. + ½)แล |

## การทดลอง Double-Slit ของ Young
แสงส่องผ่านช่องแคบๆ สองช่องซึ่งคั่นด้วยระยะห่าง d ทำให้เกิดรูปแบบการรบกวนบนหน้าจอที่ระยะ L
### ตำแหน่งขอบ
| ขอบ | ตำแหน่งบนหน้าจอ |
|--------|-------------------|
| สดใส (สูงสุด) | y_m = mγL/d |
| มืด (ขั้นต่ำ) | y_m = (m + ½)แลล/d |
| ระยะห่างขอบ | ∆y = แลล/d |
การทดลองนี้พิสูจน์ธรรมชาติของคลื่นของแสง (Thomas Young, 1801) และต่อมาได้กลายเป็นศูนย์กลางของกลศาสตร์ควอนตัม (ความเป็นคู่ของคลื่น-อนุภาค)

## การเลี้ยวเบน
**การเลี้ยวเบน** คือการโค้งงอและการแพร่กระจายของคลื่นรอบสิ่งกีดขวางและผ่านช่องเปิด
### การเลี้ยวเบนแบบช่องเดียว
แสงผ่านช่องกว้าง a ทำให้เกิดลวดลายของขอบสว่างและมืด
| คุณสมบัติ | สภาพ |
|---------|-----------|
| ศูนย์กลางสูงสุด | กว้างที่สุดและสว่างที่สุด ความกว้าง = 2γL/a |
| Minima (ขอบดำ) | บาป θ = mแล (m = ±1, ±2, ...) |
| จุดสูงสุดรอง | ประมาณระหว่างขั้นต่ำ; หรี่ลงมาก |
### ตะแกรงเลี้ยวเบน
N รอยกรีดที่มีระยะห่างเท่ากัน (ระยะห่าง d) ให้ค่าสูงสุดที่คมชัดมาก:
d บาป θ = mแล (m = 0, 1, 2, ...)
| คุณสมบัติ | เอฟเฟกต์ |
|---------||--------|
| กรีดเพิ่มเติม (ใหญ่ N) | คมชัดสูงสุดสดใสยิ่งขึ้น |
| กำลังแก้ไข | R = mN (สามารถแยกแยะความยาวคลื่นใกล้เคียงได้) |
| แอปพลิเคชั่น | สเปกโทรสโกปี การวัดความยาวคลื่น |
### เกณฑ์ Rayleigh (ขีดจำกัดความละเอียด)
แหล่งที่มาของจุดสองจุดสามารถแก้ไขได้เมื่อค่าสูงสุดตรงกลางของจุดหนึ่งตกลงบนจุดต่ำสุดแรกของอีกจุดหนึ่ง:
θ_นาที = 1.22 แลมบ์ดา
โดยที่ D คือเส้นผ่านศูนย์กลางรูรับแสง
| ระบบ | แล | ดี | θ_นาที |
|--------|---|---|-------|
| ดวงตาของมนุษย์ | 550 นาโนเมตร | 5 มม. | 1.3 × 10⁻⁴ ราด (~0.01°) |
| กล้องโทรทรรศน์อวกาศฮับเบิล | 550 นาโนเมตร | 2.4 ม. | 2.8 × 10⁻⁷ rad |
| กล้องโทรทรรศน์วิทยุ (อาเรซีโบ) | 21 ซม. | 305 ม. | 8.4 × 10⁻⁴ ราด |

## โพลาไรซ์
**โพลาไรเซชัน** อธิบายการวางแนวของการสั่นของสนามไฟฟ้าในคลื่นตามขวาง
### ประเภทของโพลาไรซ์
| พิมพ์ | คำอธิบาย |
|-|-------------|
| **เชิงเส้น** | E แกว่งในระนาบคงที่ |
| **แบบวงกลม** | E หมุนเป็นวงกลม (มือขวาหรือมือซ้าย) |
| **เครื่องเดินวงรี** | E ติดตามวงรี (ทั่วไปที่สุด) |
| **ไม่มีขั้ว** | การผสมแบบสุ่มของโพลาไรซ์ทั้งหมด (แสงธรรมชาติส่วนใหญ่) |
### กฎของมาลัส
เมื่อแสงโพลาไรซ์ผ่านโพลาไรเซอร์ที่มุม θ ไปยังทิศทางโพลาไรเซชัน:
ฉัน = ฉัน₀ cos²θ
| มุม θ | ความเข้มของการส่งผ่าน |
|---------|----------------------|
| 0° | 100% (I₀) |
| 30° | 75% |
| 45° | 50% |
| 60° | 25% |
| 90° | 0% (ถูกบล็อกโดยสมบูรณ์) |
### โพลาไรเซชันโดยการสะท้อน (มุมของบรูว์สเตอร์)
แสงที่สะท้อนจากมุมของบริวสเตอร์จะมีโพลาไรซ์โดยสิ้นเชิง:
ตาล θ_B = n₂/n₁
| อินเตอร์เฟซ | ไม่มี | ไม่มี | θ_B |
|-----------|----|----|-----|
| อากาศ → แก้ว | 1.0 | 1.5 | 56.3° |
| อากาศ → น้ำ | 1.0 | 1.33 | 53.1° |
| แก้ว → เพชร | 1.5 | 2.42 | 58.1° |

## เลนส์เรขาคณิต
เลนส์เรขาคณิต (รังสี) ถือว่าแสงเป็นรังสีที่เดินทางเป็นเส้นตรงและโค้งงอที่ส่วนต่อประสาน
### กฎของสเนลล์ (การหักเห)
n₁ บาป θ₁ = n₂ บาป θ₂
| วัสดุ | ดัชนีการหักเหของแสง n |
|----------|-------------------|
| เครื่องดูดฝุ่น | 1.000 |
| แอร์ | 1.0003 |
| น้ำ | 1.33 |
| แก้ว(มงกุฎ) | 1.52 |
| แก้ว (หินเหล็กไฟ) | 1.62 |
| เพชร | 2.42 |
### การสะท้อนกลับภายในทั้งหมด
เมื่อแสงเดินทางจากตัวกลางที่มีความหนาแน่นมากขึ้นไปยังตัวกลางที่มีความหนาแน่นน้อยกว่า ซึ่งเกิน **มุมวิกฤติ**:
θ_c = อาร์คซิน(n₂/n₁)
แสงทั้งหมดจะสะท้อนออกมา — นี่คือวิธีการทำงานของเส้นใยแก้วนำแสง
### สมการเลนส์บาง
1/f = 1/d_o + 1/d_i
| ปริมาณ | ความหมาย |
|----------|---------|
| ฉ | ทางยาวโฟกัส |
| ดี_โอ | ระยะห่างของวัตถุ |
| ดี_ไอ | ระยะภาพ |
| M = −d_i/d_o | กำลังขยาย |
| ประเภทเลนส์ | ฉ | รูปภาพ |
|----------|---|-------|
| การบรรจบกัน (นูน) | บวก | จริง (ถ้า d_o > f) หรือเสมือน |
| การเบี่ยงเบน (เว้า) | เชิงลบ | เสมือนเสมอ ตั้งตรง ลดขนาด |
### สมการกระจก
รูปแบบเดียวกับสมการของเลนส์: 1/f = 1/d_o + 1/d_i โดยที่ f = R/2 สำหรับกระจกทรงกลม

## เลนส์ฟูริเยร์
เลนส์ฟูริเยร์ถือว่าการถ่ายภาพและการเลี้ยวเบนเป็นการดำเนินการแปลงฟูริเยร์
### หลักการสำคัญ
รูปแบบการเลี้ยวเบนของสนามระยะไกลของรูรับแสงคือ **การแปลงฟูเรียร์** ของฟังก์ชันรูรับแสง
| รูรับแสง | รูปแบบการเลี้ยวเบน (การแปลงฟูเรียร์) |
|----------|--------------------------------------------|
| กรีดเดี่ยว | ฟังก์ชั่นบาป |
| รูรับแสงแบบวงกลม | ดิสก์โปร่งสบาย (J₁(r)/r) |
| รูรับแสงสี่เหลี่ยม | บาป 2D |
| ตะแกรง | ฟังก์ชันเดลต้าแยก |
### การแปลงฟูริเยร์ออปติคอล
เลนส์ทำการแปลงฟูริเยร์ 2 มิติ: การวางวัตถุไว้ที่ระนาบโฟกัสด้านหน้าจะสร้างการแปลงฟูริเยร์ที่ระนาบโฟกัสด้านหลัง
### แอปพลิเคชัน
| ใบสมัคร | Fourier Optics ช่วยได้อย่างไร |
|-------------|-------------------------|
| การกรองรูปภาพ | วางมาสก์ไว้ที่ระนาบฟูริเยร์เพื่อป้องกัน/ส่งความถี่เชิงพื้นที่ |
| การตรวจจับขอบ | การกรองผ่านความถี่สูงในระนาบฟูริเยร์
| การจดจำรูปแบบ | ความสัมพันธ์ผ่านการแปลงฟูริเยร์ |
| โฮโลแกรม | การบันทึกและการสร้างแนวคลื่นใหม่ |
| การคำนวณด้วยแสง | ทำการแปลงฟูริเยร์ด้วยความเร็วแสง |

### เอฟเฟกต์ดอปเปลอร์
ความถี่ที่สังเกตได้เมื่อแหล่งกำเนิดและผู้สังเกตการณ์เคลื่อนที่สัมพันธ์กัน:
f' = f(v ± v_o)/(v ∓ v_s)
| สถานการณ์ | เอฟเฟกต์ |
|---------||--------|
| ที่มาใกล้ | ความถี่สูง (กะสีน้ำเงินสำหรับแสง) |
| แหล่งที่มาถอย | ความถี่ต่ำ (กะสีแดงสำหรับแสง) |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดคลื่น/ทัศนศาสตร์ | ใบสมัคร |
|---------------------|-------------|
| สมการคลื่น | โครงข่ายประสาทเทียมตามหลักฟิสิกส์ การวิเคราะห์ข้อมูลแผ่นดินไหว การประมวลผลเสียง
| การวิเคราะห์ฟูริเยร์ | รากฐานของการประมวลผลสัญญาณ การวิเคราะห์สเปกตรัม การดึงคุณลักษณะ |
| การแปลงฟูเรียร์ | CNN ทำการวิเคราะห์ฟูริเยร์ในพื้นที่โดยปริยาย FFT ใช้ในการประมวลผลข้อมูลล่วงหน้า |
| การรบกวน | การคำนวณแบบอะนาล็อก โครงข่ายประสาทเชิงแสง |
| การเลี้ยวเบน | แบบจำลองการก่อตัวของภาพ อัลกอริธึมการลดความเบลอ การถ่ายภาพด้วยคอมพิวเตอร์
| โพลาไรซ์ | การสำรวจระยะไกล การจำแนกประเภทวัสดุ การวิเคราะห์ภาพถ่ายดาวเทียม |
| เลนส์เรขาคณิต | โมเดลกล้องในคอมพิวเตอร์วิทัศน์ การติดตามรังสีสำหรับการสร้างข้อมูลสังเคราะห์ |
| สมการเลนส์ | การปรับเทียบกล้อง การประมาณความลึก การสร้างภาพ 3 มิติใหม่
| เลนส์ฟูริเยร์ | การประมวลผลด้วยแสง, โครงข่ายประสาทเชิงลึกแบบเลี้ยวเบน (D²NN) |
| เอฟเฟกต์ดอปเปลอร์ | การประมวลผลสัญญาณเรดาร์ การถ่ายภาพทางการแพทย์ (อัลตราซาวนด์ดอปเปลอร์) การประมาณความเร็ว
| สเกลเดซิเบล | วิศวกรรมคุณลักษณะเสียง การประมวลผลการรู้จำเสียงล่วงหน้า |
| ทฤษฎีการสุ่มตัวอย่าง | ทฤษฎีบท Nyquist-Shannon เชื่อมต่อทฤษฎีคลื่นกับการประมวลผลสัญญาณดิจิทัล |

## สรุป
| หัวข้อ | แนวคิดหลัก | สมการสำคัญ |
|-------|-----------|-------------|
| สมการคลื่น | คลื่นแพร่กระจายด้วยความเร็ว c | ∂²u/∂t² = c²∂²u/∂x² |
| การซ้อนทับ | คลื่นบวกเชิงเส้น | คุณ = คุณ₁ + คุณ₂ |
| การรบกวน | เฟสกำหนดกำลังเสริม | Δφ = 2πΔL/แล |
| การเลี้ยวเบน | คลื่นโค้งรอบสิ่งกีดขวาง | a sin θ = mแล (ช่องเดียว) |
| โพลาไรซ์ | การวางแนวของการสั่น | กฎของมาลัส: I = I₀cos²θ |
| เลนส์เรขาคณิต | แสงราวกับรังสี | กฎของสเนลล์: n₁sinθ₁ = n₂sinθ₂ |
| เลนส์ฟูริเยร์ | การถ่ายภาพเป็นการแปลงฟูริเยร์ | สนามไกล = FT ของรูรับแสง |
| เอฟเฟกต์ดอปเปลอร์ | การเปลี่ยนความถี่จากการเคลื่อนไหว | f' = f(v ± v_o)/(v ∓ v_s) |
