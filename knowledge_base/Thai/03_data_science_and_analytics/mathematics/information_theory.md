# ทฤษฎีสารสนเทศ
ทฤษฎีสารสนเทศก่อตั้งโดย Claude Shannon ในปี 1948 เพื่อวัดปริมาณของข้อมูล ข้อความบอกคุณได้มากแค่ไหน? คุณสามารถบีบอัดข้อมูลได้มากแค่ไหน? คุณสามารถสื่อสารผ่านช่องทางที่มีเสียงดังได้เร็วแค่ไหน? คำถามเหล่านี้มีคำตอบทางคณิตศาสตร์ที่แม่นยำ นอกเหนือจากการสื่อสารแล้ว ทฤษฎีสารสนเทศยังกลายเป็นรากฐานของการเรียนรู้ของเครื่องอีกด้วย เอนโทรปีข้ามเป็นฟังก์ชันการสูญเสียเริ่มต้นสำหรับการจำแนกประเภท ความแตกต่างของ KL จะวัดความคล้ายคลึงกันในการกระจาย และการเลือกคุณสมบัติขับเคลื่อนข้อมูลร่วมกัน

## เอนโทรปี
**เอนโทรปี** วัดความไม่แน่นอนโดยเฉลี่ยหรือ "ความประหลาดใจ" ของตัวแปรสุ่ม
### แชนนอนเอนโทรปี (ไม่ต่อเนื่อง)
สำหรับตัวแปรสุ่มแบบไม่ต่อเนื่อง X ที่มีฟังก์ชันมวลความน่าจะเป็น p(x):
H(X) = −Σₓ p(x) log₂ p(x)
หน่วย: **บิต** (เมื่อใช้ log₂) หรือ **nats** (เมื่อใช้ ln)
| การจัดจำหน่าย | เอนโทรปี | สัญชาตญาณ |
|-------------|---------|-----------|
| เหรียญยุติธรรม (p = 0.5, 0.5) | 1 บิต | ความไม่แน่นอนสูงสุดสำหรับผลลัพธ์ไบนารี |
| เหรียญเอนเอียง (p = 0.9, 0.1) | 0.469 บิต | น่าแปลกใจน้อยกว่า — ส่วนใหญ่เป็นหัว |
| กำหนด (p = 1, 0) | 0 บิต | ไม่มีความไม่แน่นอนเลย |
| แฟร์ตาย (6 ด้าน) | 2.585 บิต | ผลลัพธ์มากขึ้น = ความไม่แน่นอนมากขึ้น |
| สม่ำเสมอมากกว่า n ผลลัพธ์ | log₂(n) บิต | เอนโทรปีสูงสุดสำหรับผลลัพธ์ n |
### คุณสมบัติของเอนโทรปี
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| การไม่ปฏิเสธ | สูง(X) ≥ 0 |
| สูงสุด | H(X) ≤ log₂(\|X\|) ด้วยความเท่าเทียมกันสำหรับการแจกแจงแบบสม่ำเสมอ |
| กฎลูกโซ่ | H(X, Y) = H(X) + H(Y \| X) |
| การปรับสภาพช่วยลด | H(X \| Y) ≤ H(X) |
| ความเว้า | H คือฟังก์ชันเว้าของการแจกแจงความน่าจะเป็น |
### เอนโทรปีเชิงอนุพันธ์ (ต่อเนื่อง)
สำหรับตัวแปรสุ่มต่อเนื่อง X ที่มีความหนาแน่น p(x):
h(X) = −∫ p(x) บันทึก p(x) dx
ต่างจากเอนโทรปีแบบไม่ต่อเนื่อง เอนโทรปีเชิงอนุพันธ์อาจเป็น **เชิงลบ**
| การจัดจำหน่าย | เอนโทรปีเชิงอนุพันธ์ |
|-----------------|---------------------|
| เครื่องแบบบน [a,b] | บันทึก(ข − ก) |
| ปกติ N(μ, σ²) | (1/2) บันทึก(2πeσ²) |
| เอ็กซ์โปเนนเชียล(แล) | 1 − ln(แลมบ์ดา) |

## ข้อมูลร่วม เงื่อนไข และร่วมกัน
### เอนโทรปีร่วม
H(X, Y) = −Σₓ Σᵧ p(x, y) บันทึก p(x, y)
วัดความไม่แน่นอนรวมของคู่สกุลเงิน (X, Y)
### เอนโทรปีแบบมีเงื่อนไข
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
วัดความไม่แน่นอนที่เหลืออยู่เกี่ยวกับ Y หลังจากสังเกต X
### ข้อมูลร่วมกัน
I(X; Y) = Σₓ Σᵧ p(x, y) บันทึก [p(x, y) / (p(x)p(y))]
วัดว่าความรู้ X บอกคุณเกี่ยวกับ Y ได้มากเพียงใด (และในทางกลับกัน)
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| การไม่ปฏิเสธ | ฉัน(X; Y) ≥ 0 |
| สมมาตร | ฉัน(X; Y) = ฉัน(Y; X) |
| ความสัมพันธ์กับเอนโทรปี | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| ความสัมพันธ์กับข้อต่อ | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| อิสรภาพ | I(X; Y) = 0 ถ้า X และ Y มีความเป็นอิสระ |
| ข้อมูลตนเอง | ฉัน(X; X) = ส(X) |
### ภาพ: แผนภาพเอนโทรปี
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## KL ไดเวอร์เจนซ์
**ความแตกต่างระหว่าง Kullback-Leibler (KL)** จะวัดว่าการกระจายแบบหนึ่งแตกต่างจากอีกแบบหนึ่งอย่างไร
D_KL(P || Q) = Σₓ P(x) บันทึก [P(x) / Q(x)]
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| การไม่ปฏิเสธ | D_KL(P \|\| Q) ≥ 0 (อสมการของกิ๊บส์) |
| ตัวตน | D_KL(P \|\| Q) = 0 ถ้า P = Q |
| ไม่สมมาตร | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) โดยทั่วไป |
| ไม่ใช่เมตริก | ไม่สมมาตรและอสมการสามเหลี่ยม |
**การตีความ:** D_KL(P || Q) คือจำนวนบิตพิเศษที่จำเป็นในการเข้ารหัสข้อมูลจาก P โดยใช้โค้ดที่ปรับให้เหมาะสมสำหรับ Q
### ความสัมพันธ์กับปริมาณอื่น ๆ
| ความสัมพันธ์ | สูตร |
|-------------|---------|
| ข้ามเอนโทรปี | H(P, Q) = H(P) + D_KL(P \|\| Q) |
| ข้อมูลร่วมกัน | ฉัน(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| KL แบบมีเงื่อนไข | D_KL(P(Y\|X) \|\| Q(Y\|X)) เฉลี่ยส่วน X |
---

## ข้ามเอนโทรปี
**ข้ามเอนโทรปี** ระหว่างการแจกแจง P และ Q:
H(P, Q) = −Σₓ P(x) บันทึก Q(x) = H(P) + D_KL(P || Q)
### Cross-Entropy เป็นฟังก์ชันการสูญเสีย
ในการจำแนกประเภท P คือการกระจายที่แท้จริง (ป้ายกำกับที่เข้ารหัสแบบร้อนเดียว) และ Q คือการกระจายตัวที่คาดการณ์ของแบบจำลอง
**ไบนารีข้ามเอนโทรปี (คริสตศักราช):**
L = −[บันทึก y(ŷ) + (1−y) บันทึก(1−ŷ)]
**เอนโทรปีข้ามหมวดหมู่:**
L = −Σᵢ yᵢ บันทึก(ŷᵢ)
| สถานการณ์ | y (จริง) | ŷ (ทำนาย) | การสูญเสีย |
|----------|----------|---------------|------|
| ถูกต้องมั่นใจ | 1 | 0.95 | 0.051 |
| ถูกต้องไม่แน่ใจ | 1 | 0.55 | 0.598 |
| ผิดมั่นใจ | 1 | 0.05 | 2.996 |
| ผิดไม่แน่ใจ | 1 | 0.45 | 0.799 |
การลดเอนโทรปีข้ามให้เหลือน้อยที่สุดนั้นเทียบเท่ากับการลดความแตกต่างของ KL จากการแจกแจงที่แท้จริงให้เหลือน้อยที่สุด ซึ่งเป็นเหตุผลว่าทำไมมันจึงทำงานได้ดีพอๆ กับฟังก์ชันการสูญเสีย

## ความจุช่อง
### รูปแบบช่องทางการสื่อสาร
```
X → [Channel] → Y
```

- X: อินพุตตัวแปรสุ่ม
- Y: ตัวแปรสุ่มเอาท์พุต
- Channel: กำหนดโดยความน่าจะเป็นแบบมีเงื่อนไข p(y|x)
### ทฤษฎีบทการเข้ารหัสช่องสัญญาณรบกวนของแชนนอน
สำหรับช่องที่มีความจุ C หากอัตราการส่งข้อมูล R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C การสื่อสารที่เชื่อถือได้จะเป็นไปไม่ได้
**ความจุช่อง:**
C = สูงสุด_{p(x)} ฉัน(X; Y)
### ตัวอย่างช่องที่สำคัญ
| ช่อง | คำอธิบาย | ความจุ |
|---------|-------------|----------|
| **ไบนารีสมมาตร (BSC)** | พลิกแต่ละบิตด้วยความน่าจะเป็น p | 1 − บิต H(p) |
| **การลบแบบไบนารี่ (BEC)** | ลบแต่ละบิตด้วยความน่าจะเป็น ε | 1 − ε บิต |
| **เกาส์เซียน (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2) บันทึก (1 + SNR) บิต |
| **ไบนารีไร้เสียง** | การส่งผ่านที่สมบูรณ์แบบ | 1 บิต |

## การเข้ารหัสแหล่งที่มาและการบีบอัด
### ทฤษฎีบทการเข้ารหัสแหล่งที่มา
จำนวนบิตเฉลี่ยที่จำเป็นในการเข้ารหัสแหล่งที่มาถูกจำกัดไว้ด้านล่างด้วยเอนโทรปี:
ยาว ≥ สูง(X)
รหัสที่เหมาะสมที่สุดจะได้ L γ H(X)
### การเข้ารหัสของฮัฟฟ์แมน
รหัส **ไม่มีคำนำหน้า** ที่กำหนดรหัสที่สั้นกว่าให้กับสัญลักษณ์ที่น่าจะเป็นไปได้มากขึ้น
| สัญลักษณ์ | ความน่าจะเป็น | รหัสฮัฟฟ์แมน | ความยาว |
|--------|-------------|-------------|--------|
| ก | 0.5 | 0 | 1 |
| บี | 0.25 | 10 | 2 |
| ซี | 0.125 | 110 | 3 |
| ดี | 0.125 | 111 | 3 |
ความยาวเฉลี่ย: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 บิต/สัญลักษณ์
เอนโทรปี: H = 1.75 บิต/สัญลักษณ์ (เหมาะสมที่สุดในกรณีนี้!)
### การบีบอัดแบบ Lossless และ Lossy
| พิมพ์ | หลักการ | ตัวอย่าง | ขีดจำกัด |
|------|-----------|----------|-------|
| **ไม่สูญเสีย** | ลบความซ้ำซ้อนทางสถิติ | ZIP, PNG, FLAC | อัตราเอนโทรปี H(X) |
| **ขาดทุน** | ลบข้อมูลที่ไม่เกี่ยวข้องโดยการรับรู้ | JPEG, MP3, H.264 | ฟังก์ชันอัตราการบิดเบือน R(D) |
**ทฤษฎีอัตรา-ความผิดเพี้ยน:** สำหรับการบีบอัดแบบสูญเสียโดยมีความบิดเบือนสูงสุด D อัตราขั้นต่ำคือ R(D) = นาที I(X; X̂) ขึ้นอยู่กับ E[d(X, X̂)] ≤ D

## การเชื่อมต่อกับฟิลด์อื่น
### ทฤษฎีสารสนเทศและอุณหพลศาสตร์
| แนวคิด | ทฤษฎีสารสนเทศ | อุณหพลศาสตร์ |
|---------|-------------------|----------------|
| เอนโทรปี | แชนนอนเอนโทรปี H(X) | Boltzmann เอนโทรปี S = k_B ln W |
| เอนโทรปีสูงสุด | การกระจายเครื่องแบบ | สมดุลความร้อน |
| ความแตกต่างของ KL | ความแตกต่างในการกระจาย | ฟรีพลังงานแตกต่าง |
| ข้อมูลร่วมกัน | ข้อมูลที่ใช้ร่วมกัน | ความสัมพันธ์ในระบบฟิสิคัล |
รูปแบบทางคณิตศาสตร์เหมือนกัน - แชนนอนจงใจยืมคำว่า "เอนโทรปี" จากกลศาสตร์ทางสถิติ
### ทฤษฎีสารสนเทศและสถิติ
| แนวคิด | ใบสมัคร |
|---------|-------------|
| ความน่าจะเป็นสูงสุด | เทียบเท่ากับการลดความแตกต่างของ KL จากเชิงประจักษ์ไปสู่การกระจายแบบจำลอง |
| ข้อมูลฟิชเชอร์ | ความโค้งของความแตกต่างของ KL; ขอบเขตล่างของความแปรปรวนของตัวประมาณค่า (Cramér-Rao) |
| ความยาวคำอธิบายขั้นต่ำ (MDL) | การเลือกแบบจำลองโดยการลดความยาวการเข้ารหัสทั้งหมดให้เหลือน้อยที่สุด
| เอไอซี / บิค | เกณฑ์การเลือกโมเดลตาม KL โดยประมาณ |

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล
| แนวคิดด้านไอที | แอปพลิเคชัน ML |
|----------|----------------|
| การสูญเสียข้ามเอนโทรปี | การสูญเสียการจำแนกประเภทเริ่มต้น (ไบนารีและหลายคลาส) |
| ความแตกต่างของ KL | การสูญเสีย VAE (เงื่อนไขการทำให้เป็นมาตรฐาน), การจับคู่การกระจาย, การกลั่น |
| ข้อมูลร่วมกัน | การเลือกคุณสมบัติ (MIFS), การเรียนรู้การเป็นตัวแทน (InfoMax), การคลี่คลาย |
| เอนโทรปี | เกณฑ์การแยกแผนผังการตัดสินใจ (การได้รับข้อมูล) การสำรวจใน RL (เอนโทรปีสูงสุด RL) |
| ความจุช่อง | ความซับซ้อนในการสื่อสาร การทำความเข้าใจขอบเขตทั่วไป |
| การเข้ารหัสแหล่งที่มา | การบีบอัดข้อมูลเพื่อการจัดเก็บและการส่งข้อมูล การเข้ารหัสที่มีประสิทธิภาพ |
| เอนโทรปีสูงสุด | ตัวแยกประเภท MaxEnt การเลือกก่อนหน้าในการอนุมานแบบเบย์ |
| อัตราบิดเบือน | ทำความเข้าใจกับการแลกเปลี่ยนในการบีบอัดแบบสูญเสีย การหาปริมาณในโครงข่ายประสาทเทียม
| ข้อมูลฟิชเชอร์ | การไล่ระดับตามธรรมชาติ การทำความเข้าใจความไวของพารามิเตอร์ |
| MDL / AIC / BIC | การเลือกรุ่น การป้องกันการติดตั้งมากเกินไป

## สรุป
| ปริมาณ | สูตร (ไม่ต่อเนื่อง) | ความหมาย |
|----------|-------------------|---------|
| เอนโทรปี H(X) | −Σ p(x) บันทึก p(x) | ความไม่แน่นอนเฉลี่ย |
| เอนโทรปีร่วม H(X,Y) | −Σ p(x,y) บันทึก p(x,y) | ความไม่แน่นอนรวมของคู่ |
| เอนโทรปีแบบมีเงื่อนไข H(Y\|X) | H(X,Y) − H(X) | ความไม่แน่นอนที่เหลืออยู่เกี่ยวกับ Y ให้ X |
| ข้อมูลร่วมกัน I(X;Y) | H(X) − H(X\|Y) | ข้อมูลที่แบ่งปันระหว่าง X และ Y |
| ความแตกต่างของ KL D_KL(P\|\|Q) | Σ P(x) บันทึก(P(x)/Q(x)) | "ระยะทาง" ระหว่างการแจกแจง |
| ข้ามเอนโทรปี H(P,Q) | −Σ P(x) บันทึก Q(x) | ต้นทุนการเข้ารหัสโดยใช้การกระจายที่ไม่ถูกต้อง |
| ความจุช่อง C | สูงสุด ฉัน(X;Y) | อัตราการสื่อสารที่เชื่อถือได้สูงสุด |
ทฤษฎีสารสนเทศให้ข้อจำกัดพื้นฐานของสิ่งที่สามารถเรียนรู้ บีบอัด และสื่อสารได้ สำหรับผู้ปฏิบัติงานด้านแมชชีนเลิร์นนิง จะอธิบายว่าทำไมเอนโทรปีข้ามจึงทำงานเป็นฟังก์ชันการสูญเสีย วิธีวัดคุณภาพของการนำเสนอที่เรียนรู้ และวิธีการคิดเกี่ยวกับการแลกเปลี่ยนระหว่างความซับซ้อนของโมเดลและความเหมาะสมของข้อมูล ข้อมูลเชิงลึกของ Shannon จากปี 1948 ยังคงเกี่ยวข้องกับ AI สมัยใหม่พอๆ กับที่เกี่ยวข้องกับโทรคมนาคม
