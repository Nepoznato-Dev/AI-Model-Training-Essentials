# อุณหพลศาสตร์และกลศาสตร์ทางสถิติ
อุณหพลศาสตร์อธิบายพฤติกรรมมหภาคของระบบในแง่ของอุณหภูมิ ความดัน และเอนโทรปี โดยไม่รู้ว่าอะตอมมีลักษณะอย่างไร กลศาสตร์ทางสถิติอธิบายอุณหพลศาสตร์จากล่างขึ้นบน โดยได้คุณสมบัติระดับมหภาคจากพฤติกรรมระดับจุลภาคของอนุภาคจำนวนมหาศาล เมื่อรวมกันแล้วจะทำให้เกิดความเข้าใจที่ลึกซึ้งที่สุดเกี่ยวกับพลังงาน เอนโทรปี และสมดุล ซึ่งเป็นแนวคิดที่ได้ย้ายไปสู่ทฤษฎีข้อมูล การเรียนรู้ของเครื่อง และอื่นๆ
---

## ตัวแปรทางอุณหพลศาสตร์และสถานะ
### ตัวแปรสถานะ
| ตัวแปร | พิมพ์ | หน่วย | คำอธิบาย |
|----------|-|-|-------------|
| อุณหภูมิ (T) | แบบเร่งรัด | เคลวิน (K) | พลังงานจลน์เฉลี่ยต่ออนุภาค |
| ความดัน (P) | แบบเร่งรัด | ปาสคาล (Pa) | แรงต่อหน่วยพื้นที่ |
| ปริมาณ (V) | กว้างขวาง | ลบ.ม. | พื้นที่ถูกครอบครอง |
| พลังงานภายใน (U) | กว้างขวาง | จูล (เจ) | พลังงานจุลภาคทั้งหมด |
| เอนโทรปี (S) | กว้างขวาง | เจ/เค | การวัดความผิดปกติ/ไมโครสเตต |
| จำนวนอนุภาค (N) | กว้างขวาง | โมลหรือนับ | ปริมาณสาร |
ตัวแปร **แบบเร่งรัด** ไม่ได้ขึ้นอยู่กับขนาดของระบบ ตัวแปร ** กว้างขวาง ** ทำ
### สมการของรัฐ
สำหรับก๊าซในอุดมคติ: PV = nRT = Nk_BT
| ค่าคงที่ | ค่า |
|----------|-------|
| R (ค่าคงที่ของแก๊ส) | 8.314 J/(โมล·K) |
| k_B (ค่าคงที่โบลต์ซมันน์) | 1.381 × 10⁻²³ J/K |
| N_A (เลขอาโวกาโดร) | 6.022 × 10²³ /mol |

## กฎของอุณหพลศาสตร์
### กฎศูนย์
ถ้า A อยู่ในสมดุลทางความร้อนกับ B และ B กับ C แล้ว A จะอยู่ในสมดุลทางความร้อนกับ C
**ความหมาย:** อุณหภูมิมีการกำหนดไว้อย่างดีและสามารถวัดได้
### กฎข้อที่หนึ่ง (การอนุรักษ์พลังงาน)
∆U = Q - W
| สัญลักษณ์ | ความหมาย |
|--------|---------|
| ∆U | การเปลี่ยนแปลงพลังงานภายใน |
| ถาม | เพิ่มความร้อนให้กับระบบ |
| ว | งานที่ทำโดยระบบ |
**รูปแบบส่วนต่าง:** dU = δQ − δW = δQ − PdV
| กระบวนการ | ข้อจำกัด | ผลที่ตามมา |
|---------|-----------|-------------|
| ไอโซคอริก | ดีวี = 0 | W = 0, ΔU = Q |
| ไอโซบาริก | ดีพี = 0 | W = PΔV |
| อุณหภูมิคงที่ | ดีที = 0 | ΔU = 0 (ก๊าซในอุดมคติ), Q = W |
| อะเดียแบติก | δQ = 0 | ∆U = −W |
### กฎข้อที่สอง (เอนโทรปี)
**คำกล่าวของคลอเซียส:** ความร้อนไม่สามารถไหลจากความเย็นไปร้อนได้เอง
**คำกล่าวของ Kelvin-Planck:** ไม่มีเครื่องยนต์ใดที่สามารถแปลงความร้อนทั้งหมดให้เป็นงานได้
**คำสั่งเอนโทรปี:** สำหรับกระบวนการใดๆ: ΔS_universe ≥ 0
| ประเภทกระบวนการ | ∆S_จักรวาล |
|-------------|-------------|
| กลับด้านได้ | = 0 |
| กลับไม่ได้ (จริง) | > 0 |
**การเปลี่ยนแปลงเอนโทรปี:** dS = δQ_rev / T
### กฎข้อที่สาม
เมื่อ T → 0 K เอนโทรปีของผลึกสมบูรณ์จะเข้าใกล้ศูนย์: lim_{T→0} S = 0
**ความหมาย:** ศูนย์สัมบูรณ์ไม่สามารถบรรลุได้ในขั้นตอนอันจำกัด
---

## เอนโทรปีเชิงลึก
### เอนโทรปีทางอุณหพลศาสตร์
S เป็นฟังก์ชันสถานะ สำหรับกระบวนการที่สามารถย้อนกลับได้ระหว่างสถานะ A และ B:
ΔS = ∫_A^B δQ_rev / T
**ตัวอย่างการทำงาน:** เอนโทรปีเปลี่ยนแปลงเมื่อให้ความร้อนน้ำจาก T₁ เป็น T₂ ที่ความดันคงที่
ΔS = ∫_{T₁}^{T₂} (mc_p/T) dT = mc_p ln(T₂/T₁)
### เอนโทรปีทางสถิติ (Boltzmann)
S = k_B ln Ω
โดยที่ Ω คือจำนวนไมโครสเตตที่สอดคล้องกับมาโครสเตต
| แมโครสเตต | ไมโครสเตต (Ω) | เอนโทรปี |
|----------|-----------------|---------|
| แก๊สหมดในกล่องครึ่งเดียว | เล็ก | ต่ำ |
| ก๊าซกระจายอย่างสม่ำเสมอ | ใหญ่มาก | สูง |
| คริสตัลสมบูรณ์แบบที่ 0 K | 1 | 0 |
**การเชื่อมต่อ:** กฎข้อที่สองกลายเป็นกฎทางสถิติ — ระบบพัฒนาไปสู่มาโครสเตตที่มีไมโครสเตตมากขึ้น เพียงเพราะว่าพวกมันมีความเป็นไปได้มากกว่าอย่างท่วมท้น
---

## เอนทาลปีและพลังงานอิสระ
### เอนทาลปี
H = U + พีวี
มีประโยชน์สำหรับกระบวนการที่ความดันคงที่ (เคมีและชีววิทยาส่วนใหญ่)
ΔH = Q_p (ความร้อนที่ความดันคงที่)
### พลังงานฟรีของเฮล์มโฮลทซ์
F = U - TS
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ความหมาย | สกัดงานได้สูงสุดที่ค่าคงที่ T, V |
| สมดุล | ระบบจะย่อ F ให้เหลือน้อยที่สุดที่ค่าคงที่ T, V |
| ความสัมพันธ์กับฟังก์ชันพาร์ติชัน | F = −k_BT ln Z |
### พลังงานกิ๊บส์ฟรี
G = H - TS = U + PV - TS
| คุณสมบัติ | คำชี้แจง |
|----------|-----------|
| ความหมาย | งานไม่ขยายสูงสุดที่ค่าคงที่ T, P |
| สมดุล | ระบบจะย่อ G ให้เหลือน้อยที่สุดที่ค่าคงที่ T, P |
| ความเป็นธรรมชาติ | ΔG < 0 → เกิดขึ้นเอง; ΔG = 0 → สมดุล |
| ปฏิกิริยาเคมี | ΔG = ΔH − TΔS กำหนดทิศทาง |
### สรุปศักยภาพทางอุณหพลศาสตร์
| ศักยภาพ | ตัวแปรธรรมชาติ | ส่วนต่าง | ย่อเล็กสุดเมื่อ |
|----------|-------------------|-----------------|----------------|
| U (พลังงานภายใน) | ส, วี | dU = TdS - PdV | ระบบแยก |
| H (เอนทาลปี) | ส, พี | dH = TdS + VdP | ค่าคงที่ P, อะเดียแบติก |
| F (เฮล์มโฮลทซ์) | ที, วี | dF = −SdT − PdV | ค่าคงที่ T, V |
| จี (กิ๊บส์) | ที, พี | dG = −SdT + VdP | ค่าคงที่ T, P |

## วัฏจักรการ์โนต์
**วงจรคาร์โนต์** เป็นกลไกความร้อนที่มีประสิทธิภาพมากที่สุดเท่าที่จะเป็นไปได้ โดยทำงานระหว่างอุณหภูมิ T_H (ร้อน) และ T_C (เย็น)
### สี่ขั้นตอน
| เวที | กระบวนการ | เกิดอะไรขึ้น |
|-------|---------|-------|
| 1 → 2 | การขยายตัวของไอโซเทอร์มอล | ดูดซับความร้อน Q_H จากอ่างเก็บน้ำร้อนที่ T_H |
| 2 → 3 | การขยายตัวแบบอะเดียแบติก | แก๊สเย็นลงจาก T_H ถึง T_C |
| 3 → 4 | การบีบอัดไอโซเทอร์มอล | ปฏิเสธความร้อน Q_C ไปยังอ่างเก็บน้ำเย็นที่ T_C |
| 4 → 1 | การบีบอัดแบบอะเดียแบติก | ความร้อนของแก๊สตั้งแต่ T_C ถึง T_H |
### ประสิทธิภาพของการ์โนต์
η_คาร์โนต์ = 1 − T_C/T_H
| ที_เอช | ที_ซี | η_คาร์โนต์ |
|-----|-----|----------|
| 500 พัน | 300 พัน | 40% |
| 1,000 พัน | 300 พัน | 70% |
| 300 พัน | 299 เค | 0.33% |
**ไม่มีเครื่องยนต์จริงใดที่สามารถเกินประสิทธิภาพของการ์โนต์ได้** เครื่องยนต์จริงไม่สามารถย้อนกลับได้เสมอ (แรงเสียดทาน ความปั่นป่วน ความแตกต่างของอุณหภูมิที่จำกัด)

## กลศาสตร์สถิติ
### การกระจายของ Boltzmann
สำหรับระบบที่อยู่ในสมดุลความร้อนที่อุณหภูมิ T ความน่าจะเป็นที่จะอยู่ในไมโครสเตตที่มีพลังงาน E_i:
P(E_i) = (1/Z) อี^{−E_i / k_BT}
โดยที่ Z คือ **ฟังก์ชันพาร์ติชัน**:
Z = Σᵢ อี^{−E_i / k_BT}
### ฟังก์ชั่นพาร์ติชั่น
Z เข้ารหัสข้อมูลทางอุณหพลศาสตร์ทั้งหมดเกี่ยวกับระบบ
| ปริมาณ | สูตร |
|----------|---------|
| พลังงานฟรี Helmholtz | F = −k_BT ln Z |
| พลังงานเฉลี่ย | ⟨E⟩ = −∂(ln Z)/∂β โดยที่ β = 1/(k_BT) |
| เอนโทรปี | S = k_B(ln Z + β⟨E⟩) |
| ความจุความร้อน | C_V = ∂⟨E⟩/∂T = k_Bβ²(⟨E²⟩ − ⟨E⟩²) |
| ความดัน | P = (1/β) ∂(ln Z)/∂V |
### ตัวอย่างการทำงาน: ระบบสองสถานะ
อนุภาคสามารถอยู่ในสถานะ 0 (พลังงาน 0) หรือสถานะ 1 (พลังงาน ε)
Z = 1 + อี^{−βε}
| ปริมาณ | ผลลัพธ์ |
|---------||--------|
| P(สถานะ 0) | 1/(1 + อี^{−βε}) |
| P(สถานะ 1) | e^{−βε}/(1 + e^{−βε}) |
| ⟨E⟩ | ε/(1 + อี^{βε}) |
| ขีดจำกัด T สูง (β→0) | ⟨E⟩ → ε/2 (ความน่าจะเป็นเท่ากัน) |
| ขีดจำกัด T ต่ำ (β→∞) | ⟨E⟩ → 0 (สถานะกราวด์) |
### ทฤษฎีบทการแบ่งส่วน
ระดับความเป็นอิสระกำลังสองแต่ละระดับมีส่วนช่วย ½k_BT ให้กับพลังงานเฉลี่ย
| ระบบ | องศาอิสระ | ⟨E⟩ |
|--------|-------------------|------|
| ก๊าซโมเลกุลเดี่ยว (He) | 3 คำแปล | (3/2)k_BT |
| ก๊าซไดอะตอมมิก (N₂) ที่ห้อง T | 3 ทรานส์ + 2 เน่า | (5/2)k_BT |
| ก๊าซไดอะตอมมิกที่ T สูง | 3 ทรานส์ + 2 เน่า + 1 ไวบ์ | (7/2)k_BT |
| ของแข็ง (แบบจำลองไอน์สไตน์) | 3 การสั่น (ต่ออะตอม) | 3k_BT |

## การเชื่อมต่อกับทฤษฎีสารสนเทศ
### แชนนอนเอนโทรปีกับเอนโทรปีทางอุณหพลศาสตร์
| ด้าน | แชนนอนเอนโทรปี H(X) | อุณหพลศาสตร์เอนโทรปี S |
|----------------------|---------------------|------------------------|
| คำจำกัดความ | −Σ pᵢ บันทึก pᵢ | k_B ln Ω (หรือ −k_B Σ pᵢ ln pᵢ) |
| สูงสุดเมื่อ | การกระจายเครื่องแบบ | สมดุลความร้อน |
| มาตรการ | ความไม่แน่นอน/เนื้อหาข้อมูล | จำนวนไมโครสเตตที่เข้าถึงได้ |
| หน่วย | บิตหรือแนท | เจ/เค |
**สูตรเอนโทรปีของ Gibbs:** S = −k_B Σᵢ pᵢ ln pᵢ (เหมือนกับเอนโทรปีของแชนนอน)
### หลักการเอนโทรปีสูงสุด
ทั้งสองสาขาใช้หลักการเดียวกัน: การกระจายที่แสดงถึงสถานะความรู้ของเราได้ดีที่สุดคือการกระจายเอนโทรปีสูงสุดภายใต้ข้อจำกัดที่ทราบ
| ข้อจำกัด | การกระจายผลลัพธ์ |
|-----------|----------------------|
| รู้จักหมายถึง | การแจกแจงแบบเอ็กซ์โปเนนเชียล |
| ค่าเฉลี่ยและความแปรปรวนที่ทราบ | การแจกแจงแบบเกาส์เซียน |
| พลังงานที่รู้จัก ⟨E⟩ | การกระจาย Boltzmann |
| ไม่มีข้อจำกัด | การกระจายเครื่องแบบ |
### หลักการของแลนเดาเออร์
การลบข้อมูลหนึ่งบิตจะกระจายพลังงานอย่างน้อย k_BT ln 2 เป็นความร้อน สิ่งนี้เชื่อมโยงการประมวลผลข้อมูลโดยตรงกับอุณหพลศาสตร์ - การคำนวณมีค่าใช้จ่ายพลังงานขั้นพื้นฐาน

| แนวคิดเทอร์โม/StatMech | ใบสมัคร |
|------------------------|-------------|
| การกระจาย Boltzmann | ฟังก์ชั่น Softmax แบบจำลองพลังงาน การจำลองการอบอ่อน |
| ฟังก์ชันพาร์ติชัน | การทำให้ค่าคงที่เป็นมาตรฐานในแบบจำลองความน่าจะเป็น ยากโดยทั่วไป |
| พลังงานฟรี | การอนุมานแบบแปรผัน (การลดพลังงานอิสระแบบแปรผันให้เหลือน้อยที่สุด = การลดความแตกต่างของ KL ให้เหลือน้อยที่สุด) |
| เอนโทรปี | การทำให้เป็นมาตรฐาน การสำรวจใน RL (เอนโทรปีสูงสุด RL) ต้นไม้การตัดสินใจ |
| หลักการเอนโทรปีสูงสุด | ตัวแยกประเภท MaxEnt, การเลือกก่อนหน้า, การประมาณค่าการกระจาย |
| การจำลองการหลอม | การเพิ่มประสิทธิภาพระดับโลกโดยค่อยๆ ลด "อุณหภูมิ" |
| กลศาสตร์สถิติ | ทำความเข้าใจการเปลี่ยนช่วงในการเรียนรู้ (grokking, double descent) |
| การแบ่งส่วน | ทำความเข้าใจการกระจายพลังงานในการจำลองทางกายภาพ |
| หลักการของ Landauer | ขีดจำกัดพื้นฐานของการคำนวณ การคำนวณแบบพลิกกลับได้ |
| กิ๊บส์สุ่มตัวอย่าง | วิธี MCMC ได้รับแรงบันดาลใจโดยตรงจากกลศาสตร์ทางสถิติ |
| อุณหภูมิ (เป็น softmax) | ควบคุมการสุ่มของการทำนาย: P(i) ∝ exp(z_i/T) |

## สรุป
| กฎหมาย/แนวคิด | แนวคิดหลัก | สูตร |
|------------|-----------|---------|
| กฎหมายศูนย์ | อุณหภูมิถูกกำหนดไว้อย่างดี | การผ่านของสมดุลความร้อน |
| กฎข้อแรก | พลังงานถูกอนุรักษ์ | ∆U = Q − W |
| กฎข้อที่สอง | เอนโทรปีของจักรวาลเพิ่มขึ้น | ∆S ≥ 0 |
| กฎข้อที่สาม | ศูนย์สัมบูรณ์ไม่สามารถบรรลุได้ | S → 0 เป็น T → 0 |
| เอนโทรปีของ Boltzmann | เอนโทรปีนับไมโครสเตต | S = k_B ln Ω |
| การกระจาย Boltzmann | ความน่าจะเป็นของสถานะพลังงาน | P ∝ e^{−E/k_BT} |
| ฟังก์ชันพาร์ติชัน | เข้ารหัสข้อมูลทางอุณหพลศาสตร์ทั้งหมด | Z = Σ อี^{−E_i/k_BT} |
| พลังงานฟรี | มีงานมีประโยชน์ | F = U - TS, G = H - TS |
| ประสิทธิภาพของการ์โนต์ | ประสิทธิภาพเครื่องยนต์ความร้อนสูงสุด | η = 1 − T_C/T_H |
