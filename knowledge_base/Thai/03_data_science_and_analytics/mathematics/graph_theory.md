# ทฤษฎีกราฟ
**กราฟ** คือโครงสร้างทางคณิตศาสตร์ที่ประกอบด้วยจุดยอด (โหนด) ที่เชื่อมต่อกันด้วยขอบ (ลิงก์) ความสัมพันธ์ของแบบจำลองกราฟ: เครือข่ายสังคม แผนที่ถนน โครงข่ายประสาทเทียม การพึ่งพา ช่องทางการสื่อสาร ทฤษฎีกราฟ — การศึกษาโครงสร้างเหล่านี้ — ให้อัลกอริธึมและทฤษฎีบทที่เป็นศูนย์กลางของวิทยาการคอมพิวเตอร์ การวิจัยปฏิบัติการ และวิทยาศาสตร์ข้อมูล
---

## แนวคิดพื้นฐาน
### คำจำกัดความ
| ระยะเวลา | คำจำกัดความ | สัญกรณ์ |
|------|------------|----------|
| **กราฟ** | คู่ G = (V, E) ของจุดยอดและขอบ | กรัม |
| **จุดยอด (โหนด)** | องค์ประกอบของ V | v, คุณ, w |
| **ขอบ** | การเชื่อมต่อระหว่างสองจุดยอด | e = (u, v) หรือ {u, v} |
| **สั่งซื้อ** | จำนวนจุดยอด | \|วี\| = น |
| **ขนาด** | จำนวนขอบ | \|อี\| = ม |
| **ปริญญา** | จำนวนขอบที่ตกกระทบกับจุดยอด | องศา(วี) |
| **เส้นทาง** | ลำดับของจุดยอดที่แตกต่างกันซึ่งเชื่อมต่อกันด้วยขอบ | วี₁, วี₂, ..., วีₖ |
| **รอบ** | เส้นทางที่เริ่มต้นและสิ้นสุดที่จุดยอดเดียวกัน | วี₁ → วี₂ → ... → วีₖ → วี₁ |
| **เชื่อมต่อแล้ว** | มีเส้นทางอยู่ระหว่างจุดยอดทุกคู่ | — |
| **ส่วนประกอบ** | กราฟย่อยที่เชื่อมต่อสูงสุด | — |
| **คำบรรยาย** | กราฟที่เกิดจากเซตย่อยของ V และ E | ซ ⊆ ก |
### ประเภทของกราฟ
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **ไม่ได้กำหนดทิศทาง** | ขอบไม่มีทิศทาง | เครือข่ายมิตรภาพ |
| **กำกับ (ไดกราฟ)** | ขอบมีทิศทาง (ส่วนโค้ง) | ลิงค์หน้าเว็บ |
| **ถ่วงน้ำหนัก** | ขอบมีค่าตัวเลข | ระยะทางถนน |
| **ไม่ถ่วงน้ำหนัก** | ขอบทั้งหมดเท่ากัน | การเชื่อมต่อทางสังคม |
| **เรียบง่าย** | ไม่มีการวนซ้ำ ไม่มีหลายขอบ | กราฟตำราเรียนส่วนใหญ่ |
| **มัลติกราฟ** | อนุญาตให้ใช้หลายขอบระหว่างจุดยอดเดียวกัน | เส้นทางบิน (หลายเที่ยวบินระหว่างเมือง) |

| **ระนาบ** | สามารถวาดได้โดยไม่ต้องข้ามขอบ | เค้าโครงแผงวงจร |
| **ต้นไม้** | กราฟอะไซเคิลที่เชื่อมต่อกัน | แผนผังการตัดสินใจ ระบบไฟล์ |
| **ดีเอจี** | กำกับ ไม่มีรอบกำกับ | การกำหนดเวลางาน กราฟการพึ่งพา |
### เลมมาการจับมือกัน
ผลรวมขององศาจุดยอดทั้งหมดเท่ากับ 2 เท่าของจำนวนขอบ:
Σᵥ องศา(v) = 2|E|
**ข้อพิสูจน์:** ทุกกราฟมีจำนวนจุดยอดที่เป็นองศาคี่เป็นจำนวนคู่
**ตัวอย่าง:** ในงานปาร์ตี้ที่มีคน 10 คน ทุกคนจับมือกันกับอีก 3 คนพอดี: Σ deg = 30 ดังนั้น |E| = จับมือทั้งหมด 15 ครั้ง

## การแสดงกราฟ
วิธีที่คุณจัดเก็บกราฟไว้ในหน่วยความจำจะกำหนดประสิทธิภาพของทุกอัลกอริทึมที่คุณใช้งาน
| การเป็นตัวแทน | อวกาศ | การค้นหาขอบ | ย้ำเพื่อนบ้าน | ดีที่สุดสำหรับ |
|----------------|-------|-------------|--------------------|----------|
| **เมทริกซ์ความเชื่อมโยง** | O(n²) | โอ(1) | โอ(n) | กราฟหนาแน่น การทดสอบขอบอย่างรวดเร็ว |
| **รายการที่อยู่ติดกัน** | O(n + ม.) | O(องศา(วี)) | O(องศา(วี)) | กราฟกระจัดกระจาย เครือข่ายในโลกแห่งความเป็นจริงส่วนใหญ่ |
| **รายการขอบ** | โอ(ม) | โอ(ม) | โอ(ม) | อัลกอริธึมอย่างง่าย MST | ของ Kruskal
| **เมทริกซ์อุบัติการณ์** | O(n · ม.) | โอ(ม) | โอ(ม) | อัลกอริธึมเฉพาะทาง |
### เมทริกซ์ที่อยู่ติดกัน
เมทริกซ์ n × n A โดยที่ A[i][j] = 1 ถ้ามีขอบ (i,j) มิฉะนั้นจะเป็น 0 สำหรับกราฟถ่วงน้ำหนัก A[i][j] = น้ำหนัก
**คุณสมบัติ:**
- สมมาตรสำหรับกราฟที่ไม่มีทิศทาง
- Aᵏ[i][j] = จำนวนการเดินที่มีความยาว k จาก i ถึง j
- ค่าลักษณะเฉพาะของ A เปิดเผยคุณสมบัติเชิงโครงสร้าง (ดูทฤษฎีกราฟสเปกตรัม)
### รายการที่อยู่ติดกัน
อาร์เรย์ (หรือแฮชแมป) ที่จุดยอด v แต่ละจุดเก็บรายชื่อเพื่อนบ้าน
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

นี่คือการแสดงกราฟที่ใช้กันทั่วไปในโลกแห่งความเป็นจริง ซึ่งโดยทั่วไปจะกระจัดกระจาย (m ≪ n²)

## ต้นไม้
**ต้นไม้** คือกราฟที่เชื่อมโยงกันและไม่มีทิศทางแบบวนรอบ **ป่า** คือการรวมตัวกันของต้นไม้ที่ไม่ปะติดปะต่อกัน
### คุณสมบัติของต้นไม้
สำหรับต้นไม้ที่มี n จุดยอด:
- มันมีขอบ n − 1 พอดี
- มีเส้นทางเดียวระหว่างสองจุดยอดใดๆ
- การถอดขอบใด ๆ จะเป็นการยกเลิกการเชื่อมต่อ
- การเพิ่มขอบใดๆ จะสร้างรอบเดียวเท่านั้น
### ประเภทของต้นไม้
| พิมพ์ | คำอธิบาย | ใบสมัคร |
|------|-------------|-------------|
| **รากต้นไม้** | จุดยอดหนึ่งที่กำหนดให้เป็น root | ระบบไฟล์ แผนผังองค์กร |
| **ต้นไม้ไบนารี** | แต่ละโหนดมีลูกได้สูงสุด 2 ลูก | BST, การแยกวิเคราะห์นิพจน์, แผนผังการตัดสินใจ |
| **ต้นไม้สมดุล** | ความสูงคือ O(log n) | ต้นไม้ AVL ต้นไม้แดง-ดำ (ฐานข้อมูล) |
| **ทอดต้นไม้** | กราฟย่อยที่รวมจุดยอดทั้งหมดและเป็นแผนภูมิต้นไม้ | การออกแบบเครือข่าย อัลกอริธึมการประมาณ |
| **ต้นไม้ขยายขั้นต่ำ** | ต้นไม้ทอดที่มีน้ำหนักขอบรวมขั้นต่ำ | การออกแบบเครือข่าย การจัดกลุ่ม |
| **กราฟดาว** | โหนดกลางหนึ่งโหนดเชื่อมต่อกับโหนดอื่นทั้งหมด | เครือข่ายแบบฮับและพูด |
### คุณสมบัติต้นไม้ไบนารี
| คุณสมบัติ | สูตร |
|----------|---------|
| โหนดสูงสุดที่ความลึก d | 2ᵈ |
| โหนดสูงสุดในแผนผังความสูง h | 2ʰ⁺¹ − 1 |
| ความสูงขั้นต่ำสำหรับ n โหนด | ⌊log₂(n)⌋ |
| โหนดใบในต้นไม้ไบนารีเต็ม | โหนดภายใน + 1 |
### การสำรวจต้นไม้
| การข้ามผ่าน | สั่งซื้อ | ใช้กรณี |
|----------|-------|----------|
| **สั่งจองล่วงหน้า** | รูท → ซ้าย → ขวา | การคัดลอกต้นไม้ นิพจน์คำนำหน้า |
| **ตามลำดับ** | ซ้าย → รูท → ขวา | เรียงลำดับเอาต์พุตจาก BST |
| **หลังสั่งซื้อ** | ซ้าย → ขวา → รูท | การลบต้นไม้ นิพจน์ postfix |
| **ลำดับระดับ (BFS)** | ทีละระดับ ซ้ายไปขวา | เส้นทางที่สั้นที่สุดในต้นไม้ที่ไม่ถ่วงน้ำหนัก |

## การข้ามกราฟ
อัลกอริธึมการแวะเยี่ยมชมทุกจุดยอดที่สามารถเข้าถึงได้อย่างเป็นระบบ
### การค้นหาแบบกว้างก่อน (BFS)
สำรวจจุดยอดทีละชั้นโดยใช้ **คิว**
| คุณสมบัติ | ค่า |
|----------|-------|
| โครงสร้างข้อมูล | คิว (FIFO) |
| ความซับซ้อนของเวลา | O(วี + อี) |
| ความซับซ้อนของพื้นที่ | โอ(วี) |
| ค้นหาเส้นทางที่สั้นที่สุด? | ใช่ (กราฟไม่ถ่วงน้ำหนัก) |
| สมบูรณ์? | ใช่ (สำรวจจุดยอดที่เข้าถึงได้ทั้งหมด) |
**อัลกอริทึม:**
1. เริ่มต้นที่จุดยอดต้นทาง s มาร์คมาเยือนแล้ว เข้าคิว
2. ในขณะที่คิวไม่ว่างเปล่า: ยกเลิกคิวจุดยอด u สำหรับเพื่อนบ้านที่ยังไม่ได้เยี่ยมชม v ของคุณ: ทำเครื่องหมาย v เยี่ยมชม, เข้าคิว v.
**แอปพลิเคชัน:** เส้นทางที่สั้นที่สุดในกราฟแบบไม่ถ่วงน้ำหนัก ส่วนประกอบที่เชื่อมต่อ การทดสอบแบบสองฝ่าย การรวบรวมข้อมูลเว็บ
### การค้นหาเชิงลึกก่อน (DFS)
สำรวจให้ลึกที่สุดเท่าที่จะเป็นไปได้ก่อนที่จะย้อนรอยโดยใช้ **สแต็ก** (หรือการเรียกซ้ำ)
| คุณสมบัติ | ค่า |
|----------|-------|
| โครงสร้างข้อมูล | สแต็ก (LIFO) / การเรียกซ้ำ |
| ความซับซ้อนของเวลา | O(วี + อี) |
| ความซับซ้อนของพื้นที่ | โอ(วี) |
| ค้นหาเส้นทางที่สั้นที่สุด? | ไม่ |
| สมบูรณ์? | ใช่ (สำหรับกราฟจำกัด) |
**อัลกอริทึม:**
1. เริ่มต้นที่จุดยอด s มาร์คมาเยือนแล้ว
2. สำหรับ v เพื่อนบ้านที่ไม่มีใครเยี่ยมชม v ของ s: DFS ซ้ำจาก v
**DFS แบ่งประเภทขอบเป็น:**
- **ขอบต้นไม้:** ส่วนหนึ่งของแผนผัง DFS
- **ขอบด้านหลัง:** เชื่อมต่อจุดยอดกับจุดบนสุด (ระบุรอบ)
- **ขอบไปข้างหน้า:** เชื่อมต่อจุดยอดกับจุดที่อยู่ระดับล่าง
- **ขอบตัดขวาง:** เชื่อมต่อจุดยอดในสาขาต่างๆ
**แอปพลิเคชัน:** การเรียงลำดับทอพอโลยี การตรวจจับวงจร ส่วนประกอบที่เชื่อมต่ออย่างแน่นหนา การแก้เขาวงกต
### การเปรียบเทียบ BFS กับ DFS
| เกณฑ์ | บีเอฟเอส | ดีเอฟเอส |
|-----------|-----|-----|
| กลยุทธ์ | กว้างแล้วลึก | ลึกแล้วกว้าง |
| หน่วยความจำ | สูงกว่า (ชายแดนร้านค้า) | ล่าง (เส้นทางร้านค้า) |
| เส้นทางที่สั้นที่สุด (ไม่ถ่วงน้ำหนัก) | รับประกัน | ไม่รับประกัน |
| ใช้เมื่อสารละลายใกล้จะเริ่มต้น | ดีกว่า | แย่กว่า |
| ใช้เมื่อกราฟลึกมาก | แย่กว่า | ดีกว่า |
| การเรียงลำดับโทโพโลยี | ตัวแปรอัลกอริทึมของคาห์น | วิธีการมาตรฐาน |

## อัลกอริธึมเส้นทางที่สั้นที่สุด
การค้นหาเส้นทางที่สั้นที่สุดระหว่างจุดยอดถือเป็นปัญหากราฟที่สำคัญที่สุดประการหนึ่ง
### อัลกอริทึมของ Dijkstra
ค้นหาเส้นทางที่สั้นที่สุดจากแหล่งเดียวไปยังจุดยอดอื่นๆ ทั้งหมดในกราฟที่มีน้ำหนักขอบ **ไม่เป็นลบ**
| คุณสมบัติ | ค่า |
|----------|-------|
| ตุ้มน้ำหนักขอบ | จะต้องเป็น ≥ 0 |
| เวลา (ไบนารีฮีป) | O((V + E) บันทึก V) |
| เวลา (ฮีปฟีโบนัชชี) | O(E + V บันทึก V) |
| โลภ? | ใช่ |
| จัดการกับน้ำหนักติดลบหรือไม่? | ไม่ |
**อัลกอริทึม:**
1. เริ่มต้น dist[s] = 0, dist[v] = ∞ สำหรับ v ≠ s ทั้งหมด คิวลำดับความสำคัญ Q พร้อมจุดยอดทั้งหมด
2. ในขณะที่ Q ไม่ว่างเปล่า ให้แยกจุดยอด u ด้วย dist ขั้นต่ำ สำหรับเพื่อนบ้านแต่ละตัว v ของ u ที่มีน้ำหนักขอบ w: ถ้า dist[u] + w < dist[v] ให้อัปเดต dist[v] = dist[u] + w
**ตัวอย่างการทำงาน:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### อัลกอริทึมของเบลล์แมน-ฟอร์ด
จัดการน้ำหนักขอบ **ที่เป็นลบ** และตรวจจับวงจรที่เป็นลบ
| คุณสมบัติ | ค่า |
|----------|-------|
| ตุ้มน้ำหนักขอบ | Any (ตรวจพบวงจรลบ) |
| ความซับซ้อนของเวลา | O(V · E) |
| ความซับซ้อนของพื้นที่ | โอ(วี) |
| จัดการกับวงจรเชิงลบหรือไม่? | ใช่ (ตรวจพบและรายงาน) |
**อัลกอริทึม:**
1. เริ่มต้น dist[s] = 0, dist[v] = ∞ สำหรับ v ≠ s ทั้งหมด
2. ทำซ้ำ V − 1 ครั้ง: สำหรับแต่ละขอบ (u, v) โดยมีน้ำหนัก w: ถ้า dist[u] + w < dist[v], อัปเดต dist[v]
3. ตรวจสอบวงจรลบ: หากขอบใดๆ ยังคงสามารถผ่อนคลายได้ แสดงว่ามีวงจรลบเกิดขึ้น
### อัลกอริทึมของฟลอยด์-วอร์แชล
ค้นหาเส้นทางที่สั้นที่สุดระหว่างจุดยอด **ทุกคู่**
| คุณสมบัติ | ค่า |
|----------|-------|
| ความซับซ้อนของเวลา | O(V³) |
| ความซับซ้อนของพื้นที่ | O(V²) |
| จัดการกับน้ำหนักติดลบหรือไม่? | ใช่ (แต่ไม่ใช่วงจรติดลบ) |
| วิธีการ | การเขียนโปรแกรมแบบไดนามิก |
**การเกิดซ้ำ:** dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) สำหรับแต่ละจุดยอดตรงกลาง k
### คู่มือการเลือกอัลกอริทึม
| สถานการณ์ | อัลกอริทึม |
|----------|-----------|
| แหล่งเดียว น้ำหนักไม่เป็นลบ | ดิจค์สตรา |
| แหล่งเดียว สามารถให้น้ำหนักติดลบได้ | เบลล์แมน-ฟอร์ด |
| ทุกคู่กราฟหนาแน่น | ฟลอยด์-วอร์แชล |
| ทุกคู่กราฟกระจัดกระจาย | เรียกใช้ Dijkstra จากแต่ละจุดยอด |
| กราฟไม่ถ่วงน้ำหนัก | บีเอฟเอส |
| DAG (ไม่มีรอบ) | การเรียงลำดับทอพอโลยี + การผ่อนคลาย |
| A* (ฮิวริสติกชี้นำ) | A* search (เพื่อการค้นหาเส้นทางด้วยฮิวริสติกที่ดี) |

## ต้นไม้ขยายขั้นต่ำ
**แผนผังการขยายขั้นต่ำ (MST)** เชื่อมต่อจุดยอดทั้งหมดที่มีน้ำหนักขอบรวมขั้นต่ำ
### คุณสมบัติ
- MST มีขอบ n − 1 พอดี (สำหรับจุดยอด n จุด)
- มี MST หากกราฟเชื่อมต่ออยู่
- กราฟที่มีน้ำหนักขอบที่แตกต่างกันจะมี MST ที่ไม่ซ้ำกัน
- MST เป็นไปตาม **คุณสมบัติการตัด**: ขอบที่มีน้ำหนักขั้นต่ำที่ตัดกับการตัดใดๆ จะเป็นของ MST
- MST เป็นไปตาม **คุณสมบัติของรอบ**: ขอบของน้ำหนักสูงสุดในรอบใด ๆ ไม่ได้เป็นของ MST
### อัลกอริทึมของ Kruskal
| คุณสมบัติ | ค่า |
|----------|-------|
| กลยุทธ์ | Greedy — เพิ่มขอบตามลำดับน้ำหนัก |
| โครงสร้างข้อมูล | Disjoint-set (ยูเนี่ยน-ค้นหา) |
| ความซับซ้อนของเวลา | O(E บันทึก E) |
| ดีที่สุดสำหรับ | กราฟกระจัดกระจาย |
**อัลกอริทึม:**
1. จัดเรียงขอบทั้งหมดตามน้ำหนัก
2. สำหรับแต่ละขอบ (ตามลำดับ): หากการเพิ่มไม่ได้สร้างวงจร (ตรวจสอบกับ union-find) ให้เพิ่มลงใน MST
3. หยุดเมื่อเลือกขอบ n − 1
### อัลกอริทึมของพริม
| คุณสมบัติ | ค่า |
|----------|-------|
| กลยุทธ์ | Greedy — ปลูกต้นไม้จากจุดเริ่มต้น |
| โครงสร้างข้อมูล | คิวลำดับความสำคัญ (min-heap) |
| ความซับซ้อนของเวลา | O(E log V) พร้อมไบนารีฮีป |
| ดีที่สุดสำหรับ | กราฟหนาแน่น |
**อัลกอริทึม:**
1. เริ่มจากจุดยอดใดก็ได้ ทำเครื่องหมายว่าเป็นส่วนหนึ่งของ MST
2. เพิ่มขอบน้ำหนักต่ำสุดซ้ำๆ ที่เชื่อมต่อจุดยอดใน MST กับจุดยอดด้านนอก
3. หยุดเมื่อรวมจุดยอดทั้งหมดแล้ว
### แอปพลิเคชัน MST
| ใบสมัคร | MST ช่วยได้อย่างไร |
|-------------|---------------|
| การออกแบบเครือข่าย | วางสายเคเบิล/ท่อขั้นต่ำเพื่อเชื่อมต่อทุกสถานที่ |
| การจัดกลุ่ม | ลบขอบ MST ที่ยาวที่สุด k - 1 เพื่อรับ k กลุ่ม |
| อัลกอริธึมการประมาณ | การประมาณ 2 สำหรับเมตริก TSP |
| การแบ่งส่วนรูปภาพ | จัดกลุ่มพิกเซลตาม MST ของความคล้ายคลึงของสี |
| การกำจัดคุณสมบัติ | ลบคุณลักษณะที่ซ้ำซ้อนโดยใช้ MST ของกราฟสหสัมพันธ์ |

## การไหลของเครือข่าย
ปัญหาการไหลของเครือข่ายจำลองการเคลื่อนย้ายทรัพยากรผ่านระบบ
### คำจำกัดความของเครือข่ายโฟลว์
**เครือข่ายโฟลว์** เป็นกราฟกำกับที่มี:
- จุดยอด **แหล่งที่มา** (สร้างกระแส)
- A **sink** จุดยอด t (สิ้นเปลืองการไหล)
- **ความจุ** c(u,v) ≥ 0 บนแต่ละขอบ
- **ไหล** f(u,v) น่าพอใจ:
  - **ข้อจำกัดด้านความจุ:** 0 ≤ f(u,v) ≤ c(u,v)
  - **การอนุรักษ์การไหล:** ไหลเข้า = ไหลออกที่ทุกจุดยอด ยกเว้น s และ t
### ปัญหาการไหลสูงสุด
ค้นหาการไหลรวมสูงสุดจาก s ถึง t
**วิธีการของฟอร์ด-ฟุลเกอร์สัน:**
1. ในขณะที่มีเส้นทางการเสริมจาก s ถึง t ในกราฟที่เหลือ:
2. ค้นหาความจุคอขวดตามเส้นทาง
3. เพิ่มการไหลตามเส้นทางตามปริมาณคอขวด
4. อัพเดตกำลังการผลิตคงเหลือ
| อัลกอริทึม | ความซับซ้อนของเวลา | หมายเหตุ |
|----------|----------------|-------|
| ฟอร์ด-ฟุลเคอร์สัน (ดีเอฟเอส) | O(m · f*) โดยที่ f* คือการไหลสูงสุด | ไม่อาจยุติด้วยความสามารถที่ไม่ลงตัว |
| เอ็ดมอนด์ส-คาร์ป (บีเอฟเอส) | O(V · E²) | ยุติเสมอ เลือกเส้นทางเสริมที่สั้นที่สุด |
| อัลกอริทึมของ Dinic | O(V² · E) | ใช้การปิดกั้นกระแส O(V^(1/2) · E) สำหรับความจุหน่วย |
### ทฤษฎีบท Max-Flow Min-Cut
**การไหลสูงสุด** จาก s ถึง t เท่ากับ **การตัดขั้นต่ำ** ความจุที่แยก s ออกจาก t
**ตัด** (S, T) แบ่งพาร์ติชันจุดยอดเป็น S (ประกอบด้วย s) และ T (ประกอบด้วย t) ความสามารถในการตัดคือผลรวมของความสามารถในการตัดขอบตั้งแต่ S ถึง T
**การใช้งานของกระแสสูงสุด:**
- การจับคู่ทวิภาคี (มอบหมายคนงานให้กับงาน)
- การแบ่งส่วนภาพ (แยกพื้นหน้าจากพื้นหลัง)
- ตกรอบเบสบอล (ทีม X จะยังชนะได้หรือไม่)
- ความน่าเชื่อถือของเครือข่าย (ปริมาณข้อมูลสูงสุด)
### การจับคู่ทวิภาคีผ่าน Max Flow
รับกราฟสองฝ่าย G = (L ∪ R, E):
1. เพิ่มแหล่งที่มาที่มีขอบให้กับจุดยอดทั้งหมดในหน่วย L (ความจุ 1)
2. เพิ่ม sink t โดยมีขอบจากจุดยอดทั้งหมดใน R (ความจุ 1)
3. ตั้งค่าความจุขอบดั้งเดิมทั้งหมดเป็น 1
4. การไหลสูงสุด = การจับคู่สูงสุด

## ทฤษฎีกราฟสเปกตรัม
ทฤษฎีกราฟสเปกตรัมศึกษากราฟผ่านค่าลักษณะเฉพาะและเวกเตอร์ลักษณะเฉพาะของเมทริกซ์ที่เกี่ยวข้องกับกราฟ
### เมทริกซ์ที่สำคัญ
| เมทริกซ์ | คำจำกัดความ | สิ่งที่จับ |
|--------|------------|------------------|
| **เมทริกซ์คำติดกัน** A | A[i][j] = 1 ถ้าขอบ (i,j) มี | รูปแบบการเชื่อมต่อ |
| **เมทริกซ์ระดับ** D | เส้นทแยงมุม; D[i][i] = องศา(i) | ความสำคัญของจุดยอดตามระดับ |
| **ลาปลาเซียน** L = D − A | L[i][j] = −1 ถ้าขอบ, องศา(i) บนเส้นทแยงมุม | ความราบรื่นของฟังก์ชันบนกราฟ |
| **ลาปลาเชียนที่ทำให้เป็นมาตรฐาน** L_norm = D^(−1/2) L D^(−1/2) | เวอร์ชันไม่แปรผันตามมาตราส่วน | โครงสร้างชุมชน |
### ค่าลักษณะเฉพาะของ Laplacian
Laplacian L เป็นค่ากึ่งแน่นอนเชิงบวก ดังนั้นค่าลักษณะเฉพาะทั้งหมดจึงเท่ากับ ≥ 0
| ค่าลักษณะเฉพาะ | ความหมาย |
|------------|---------|
| แล₁ = 0 | เป็นศูนย์เสมอ eigenvector คือเวกเตอร์คงที่ |
| แล₂ (การเชื่อมต่อพีชคณิต) | > 0 มีการเชื่อมต่อกราฟ iff; ใหญ่ขึ้น = เชื่อมต่อได้ดีขึ้น |
| จำนวนค่าลักษณะเฉพาะที่เป็นศูนย์ | เท่ากับจำนวนส่วนประกอบที่เชื่อมต่อ |
| แลₙ | เกี่ยวข้องกับระดับสูงสุดและการขยายกราฟ |
### การประยุกต์วิธีสเปกตรัม
| ใบสมัคร | วิธีการ |
|-------------|--------|
| **การแบ่งพาร์ติชันกราฟ** | ใช้ eigenvectors ของ L เพื่อแยกกราฟออกเป็นส่วนสมดุล |
| **การตรวจจับชุมชน** | การจัดกลุ่มสเปกตรัม: จุดยอดฝังโดยใช้ eigenvectors ด้านล่าง จากนั้นจัดกลุ่ม |
| **อันดับหน้า** | Eigenvector ของเมทริกซ์ adjacency (หรือเมทริกซ์การเปลี่ยนแปลง) ของกราฟเว็บ |
| **วาดกราฟ** | วางตำแหน่งจุดยอดโดยใช้เวกเตอร์ลักษณะเฉพาะของ Laplacian |
| **การเรียนรู้แบบกึ่งกำกับดูแล** | เผยแพร่ฉลากโดยใช้กราฟ Laplacian (การขยายพันธุ์ฉลาก) |
| **โครงข่ายประสาทเทียมแบบกราฟ** | การโน้มน้าวสเปกตรัม: กรองสัญญาณบนกราฟโดยใช้เวกเตอร์ลักษณะเฉพาะของ L |
### ความไม่เท่าเทียมกันของเชียร์เกอร์
เชื่อมโยงค่าลักษณะเฉพาะที่สอง แล₂ กับ **การขยายตัว** ของกราฟ (มีความเชื่อมโยงกันดีเพียงใด):
แลมบ์ดา / 2 ≤ ชม.(G) ≤ √(2แลม₂)
โดยที่ h(G) คือค่าคงที่ของชีเกอร์ (หมายเลขไอโซเพอริเมตริก) ซึ่งหมายความว่า แล₂ วัดโดยประมาณว่าการตัดกราฟออกเป็นสองส่วนนั้นยากเพียงใด ซึ่งเป็นข้อมูลเชิงลึกที่สำคัญสำหรับการจัดกลุ่ม

## ความเกี่ยวข้องกับการเรียนรู้ของเครื่องและวิทยาศาสตร์ข้อมูล

| ดิจกสตรา / A* | การวางแผนเส้นทาง เกมค้นหาเส้นทางด้วย AI การนำทางด้วยหุ่นยนต์ |

|-------|-----------|----------------------|
| พื้นฐาน | จุดยอด ขอบ องศา เส้นทาง | การจับมือกันบทแทรก |
| ตัวแทน | วิธีจัดเก็บกราฟ | เมทริกซ์ที่อยู่ติดกันเทียบกับรายการที่อยู่ติดกัน |

| การเดินทาง | การสำรวจจุดยอดอย่างเป็นระบบ | BFS (เส้นทางที่สั้นที่สุด), DFS (การสำรวจเชิงลึก) |
| เส้นทางที่สั้นที่สุด | เส้นทางน้ำหนักขั้นต่ำ | ไดจ์คสตรา, เบลล์แมน-ฟอร์ด, ฟลอยด์-วอร์แชล |

| กระแสเครือข่าย | ปริมาณงานสูงสุด | ฟอร์ด-ฟุลเกอร์สัน ทฤษฎีบทตัดขั้นต่ำของการไหลสูงสุด |
| ทฤษฎีสเปกตรัม | ค่าลักษณะเฉพาะเปิดเผยโครงสร้าง | ค่าลักษณะเฉพาะของ Laplacian, การจัดกลุ่มสเปกตรัม |
ทฤษฎีกราฟถือเป็นสาขาวิชาคณิตศาสตร์ที่นำไปใช้ได้โดยตรงที่สุดกับวิทยาศาสตร์ข้อมูลสมัยใหม่ เครือข่ายโซเชียล กราฟความรู้ โครงสร้างโมเลกุล กราฟการคำนวณในกรอบการเรียนรู้เชิงลึก ความละเอียดของการพึ่งพา ระบบการแนะนำ ล้วนเป็นปัญหาพื้นฐานของกราฟ อัลกอริธึมที่กล่าวถึงในที่นี้ไม่ใช่แค่ทางทฤษฎีเท่านั้น พวกเขาทำงานเป็นจำนวนมากในระบบการผลิตทุกวัน
