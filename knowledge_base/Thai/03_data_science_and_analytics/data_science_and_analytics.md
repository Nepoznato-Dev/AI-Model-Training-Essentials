# วิทยาศาสตร์ข้อมูลและการวิเคราะห์
วิทยาศาสตร์ข้อมูลเป็นวินัยในการเปลี่ยนข้อมูลดิบให้เป็นข้อมูลเชิงลึกที่นำไปปฏิบัติได้ โดยเป็นจุดบรรจบกันของสถิติ วิทยาการคอมพิวเตอร์ และความเชี่ยวชาญในสาขาต่างๆ และกลายเป็นสิ่งจำเป็นในทุกภาคส่วนตั้งแต่การเงินไปจนถึงการดูแลสุขภาพ ไฟล์นี้จะอธิบายแนวคิดหลัก เครื่องมือ และขั้นตอนการทำงานที่ผู้ปฏิบัติงานทุกคนควรรู้
---

## กระบวนการวิทยาศาสตร์ข้อมูล
โปรเจ็กต์ส่วนใหญ่เป็นไปตามการเปลี่ยนแปลงของ **CRISP-DM** ซึ่งเป็นวงจรชีวิตมาตรฐานอุตสาหกรรม:
| เฟส | เกิดอะไรขึ้น | เวลาปกติ |
|-------|-------------|--------------|
| **ความเข้าใจทางธุรกิจ** | กำหนดวัตถุประสงค์ ตัวชี้วัดความสำเร็จ และข้อจำกัด | 10–15% |
| **ความเข้าใจข้อมูล** | รวบรวม สำรวจ และจัดทำโปรไฟล์ข้อมูล | 10–15% |
| **การเตรียมข้อมูล** | ทำความสะอาด แปลง คุณสมบัติวิศวกร | ~50–60% |
| **การสร้างแบบจำลอง** | เลือกและฝึกโมเดล | 10–15% |
| **การประเมินผล** | ประเมินผลการปฏิบัติงานเทียบกับเป้าหมายทางธุรกิจ | 5–10% |
| **การปรับใช้** | จัดส่งโมเดลเพื่อการผลิต | 5–10% |
เรื่องตลกเก่าๆ ก็คือ 80% ของวิทยาศาสตร์ข้อมูลกำลังล้างข้อมูล มันอยู่ไม่ไกลจากความจริง

## ประเภทข้อมูลโดยสรุป
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **มีโครงสร้าง** | จัดเรียงเป็นแถวและคอลัมน์ | ตาราง SQL สเปรดชีต |
| **ไม่มีโครงสร้าง** | ไม่มีรูปแบบที่กำหนดไว้ล่วงหน้า | ข้อความ รูปภาพ เสียง วีดีโอ |
| **กึ่งโครงสร้าง** | บางองค์กรแต่มีความยืดหยุ่น | JSON, XML, HTML |
| **อนุกรมเวลา** | ข้อมูลตามลำดับที่จัดทำดัชนีตามเวลา | ราคาหุ้นการอ่านเซ็นเซอร์ |
| **เชิงพื้นที่** | ตามภูมิศาสตร์หรือตามสถานที่ | พิกัด GPS ข้อมูลแผนที่ |
| **กราฟ** | โหนดและขอบที่แสดงถึงความสัมพันธ์ | โซเชียลเน็ตเวิร์ก กราฟความรู้ |

## สถิติพื้นฐาน
### สถิติเชิงพรรณนาและเชิงอนุมาน
สถิติเชิงพรรณนาสรุปสิ่งที่คุณ *มี*; สถิติเชิงอนุมานช่วยให้คุณได้ข้อสรุปเกี่ยวกับสิ่งที่คุณ *ไม่มี* มี (ประชากรในวงกว้าง)
| แนวคิด | แนวคิดหลัก |
|---------|-----------|
| **แนวโน้มภาคกลาง** | ค่าเฉลี่ย (อ่อนไหวต่อค่าผิดปกติ) ค่ามัธยฐาน (คงที่) โหมด (บ่อยที่สุด) |
| **การกระจายตัว** | พิสัย ความแปรปรวน ส่วนเบี่ยงเบนมาตรฐาน พิสัยระหว่างควอไทล์ |
| **รูปแบบการกระจายตัว** | ความเบ้ (ไม่สมมาตร), ความโด่ง (ความหนักของหาง) |
| **การทดสอบสมมติฐาน** | สมมติฐานว่างกับทางเลือก ค่า p ระดับนัยสำคัญ (α) |
| **ช่วงความเชื่อมั่น** | ช่วงน่าจะมีพารามิเตอร์ประชากรที่แท้จริง |
| **ข้อผิดพลาดประเภท I / ประเภท II** | ผลบวกลวง (ปฏิเสธค่าว่างจริง) / ผลลบลวง (ไม่มีผลจริง) |
### การทดสอบทางสถิติทั่วไป
| ทดสอบ | เมื่อใดควรใช้ |
|-|-------------|
| **ที-เทสต์** | เปรียบเทียบค่าเฉลี่ยระหว่างสองกลุ่ม |
| **ความแปรปรวน** | เปรียบเทียบค่าเฉลี่ยระหว่างสามกลุ่มขึ้นไป |
| **ไคสแควร์** | ทดสอบความเป็นอิสระของตัวแปรเด็ดขาด |
| **แมนน์-วิทนีย์ ยู** | ทางเลือกที่ไม่ใช่พารามิเตอร์สำหรับการทดสอบที (ไม่มีการสันนิษฐานเรื่องภาวะปกติ) |
| **ความสัมพันธ์แบบเพียร์สัน** | ความสัมพันธ์เชิงเส้นระหว่างตัวแปรต่อเนื่องสองตัว |
| **ความสัมพันธ์ของสเปียร์แมน** | ความสัมพันธ์แบบโมโนโทนิก (ตามอันดับ แข็งแกร่งยิ่งขึ้น) |
### การแจกแจงความน่าจะเป็นที่น่ารู้
| การจัดจำหน่าย | ใช้กรณี |
|-------------|----------|
| **ปกติ** | ปรากฏการณ์ทางธรรมชาติ ข้อผิดพลาดในการวัด — เส้นโค้งระฆังแบบคลาสสิก |
| **ทวินาม** | จำนวนความสำเร็จ/ล้มเหลว (การพลิกเหรียญ อัตราการแปลง) |
| **ปัวซอง** | จำนวนเหตุการณ์ในช่วงเวลาคงที่ (การโทรต่อชั่วโมง ข้อบกพร่องต่อชุด) |
| **เอ็กซ์โปเนนเชียล** | เวลาระหว่างเหตุการณ์ (เวลารอ ช่วงเวลาความล้มเหลว) |
| **t-การกระจาย** | กลุ่มตัวอย่างขนาดเล็กหรือความแปรปรวนของประชากรที่ไม่ทราบ |
| **ไคสแควร์** | การวิเคราะห์ข้อมูลเชิงหมวดหมู่ การทดสอบความดีเหมาะสม |

## การรวบรวมและจัดเก็บข้อมูล
### ข้อมูลมาจากไหน
ข้อมูลในโลกแห่งความเป็นจริงมาจากหลายแหล่ง: ฐานข้อมูลเชิงสัมพันธ์, API (REST, GraphQL), ไฟล์แฟลต (CSV, JSON, Parquet), แพลตฟอร์มการสตรีม (Kafka, Kinesis), แบบสำรวจ และที่เก็บข้อมูลสาธารณะ (Kaggle, พอร์ทัลรัฐบาล) รูปแบบที่คุณได้รับจะกำหนดกลยุทธ์ในการประมวลผลล่วงหน้าส่วนใหญ่
### แนวคิดคลังข้อมูล
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **ETL** | แยก → แปลง → โหลด — วิธีการไปป์ไลน์แบบดั้งเดิม |
| **ELT** | แยก → โหลด → แปลง — วิธีการคลาวด์สมัยใหม่ (โหลดดิบ แปลงในคลังสินค้า) |
| **ดาต้าเลค** | ข้อมูลดิบที่จัดเก็บในรูปแบบดั้งเดิม (สคีมาเมื่ออ่าน) |
| **คลังข้อมูล** | ข้อมูลที่มีโครงสร้างและประมวลผลได้รับการปรับให้เหมาะสมสำหรับการวิเคราะห์ (สคีมาเมื่อเขียน) |
| **ดาต้ามาร์ท** | ชุดย่อยของคลังสินค้า กำหนดขอบเขตไว้ที่แผนกหรือโดเมนเดียว |
| **สคีมาดาว** | ตารางข้อเท็จจริงกลางล้อมรอบด้วยตารางมิติ |
| **สคีมาเกล็ดหิมะ** | ตารางมิติที่ทำให้เป็นมาตรฐาน (ซ้ำซ้อนน้อยลง รวมมากขึ้น) |
### ประเภทฐานข้อมูล
| พิมพ์ | ตัวอย่าง | ดีที่สุดสำหรับ |
|------|----------|----------|
| **เชิงสัมพันธ์ (SQL)** | PostgreSQL, MySQL, ออราเคิล | ข้อมูลที่มีโครงสร้าง ธุรกรรม ACID |
| **เอกสาร** | MongoDB, CouchDB | สคีมาที่ยืดหยุ่น ข้อมูลเหมือน JSON |
| **คีย์-ค่า** | เรดดิส, DynamoDB | การแคช เซสชัน การค้นหาแบบง่าย |
| **คอลัมน์-ครอบครัว** | แคสแซนดรา, HBase | ปริมาณงานเขียนหนัก อนุกรมเวลา |
| **กราฟ** | Neo4j, อเมซอน เนปจูน | ความสัมพันธ์, โซเชียลเน็ตเวิร์ก |
| **อนุกรมเวลา** | InfluxDB, TimescaleDB | ตัวชี้วัด IoT, การตรวจสอบ |
| **เวกเตอร์** | ไพน์โคน, มิลวัส | การฝังที่เก็บข้อมูลสำหรับการค้นหา ML/AI |

## การประมวลผลข้อมูลล่วงหน้าและวิศวกรรมคุณสมบัติ
### รายการตรวจสอบการทำความสะอาด
ชุดข้อมูลจริงทุกชุดมีปัญหา นี่คือการล้างข้อมูลมาตรฐาน:
| ปัญหา | วิธีการ |
|-------|----------|
| **ค่าหายไป** | การใส่ร้าย (ค่าเฉลี่ย ค่ามัธยฐาน การทำนาย) หรือการลบหากกระจัดกระจาย |
| **ค่าผิดปกติ** | ตรวจจับผ่าน IQR หรือ Z-score รักษาด้วยการกำหนดสูงสุดหรือการแปลง |
| **ซ้ำ** | ระบุและลบ |
| **ความไม่สอดคล้องกัน** | ปรับรูปแบบให้เป็นมาตรฐาน แก้ไขคำผิด ปรับหน่วยให้เป็นมาตรฐาน |
### เทคนิคการแปลงร่าง
| เทคนิค | มันทำอะไร |
|-----------|-------------|
| **การทำให้เป็นมาตรฐาน** | ปรับสเกลค่าเป็นช่วง 0–1 |
| **มาตรฐาน** | คะแนน Z: ค่าเฉลี่ย = 0, มาตรฐาน = 1 |
| **การเข้ารหัสแบบร้อนแรง** | แปลงหมวดหมู่เป็นคอลัมน์ไบนารี |
| **การเข้ารหัสฉลาก** | กำหนดป้ายกำกับจำนวนเต็มให้กับหมวดหมู่ |
| **การเปลี่ยนแปลงบันทึก** | ลดการเบ้ขวาในข้อมูล |
| **บินนิ่ง** | จัดกลุ่มค่าต่อเนื่องลงในที่เก็บข้อมูลแบบไม่ต่อเนื่อง |
### คุณสมบัติทางวิศวกรรม
วิศวกรรมคุณลักษณะมักเป็นความแตกต่างระหว่างโมเดลธรรมดากับโมเดลที่ยอดเยี่ยม เทคนิคสำคัญได้แก่:
- **การสร้างฟีเจอร์**: รับคอลัมน์ใหม่จากคอลัมน์ที่มีอยู่ (เช่น`age_group`จาก`age`)
- **การเลือกคุณสมบัติ**: วิธีการกรอง (ความสัมพันธ์), วิธีการตัดคำ (การกำจัดแบบเรียกซ้ำ), วิธีการฝัง (LASSO, ความสำคัญของต้นไม้)
- **การลดขนาด**: PCA สำหรับเชิงเส้น, t-SNE หรือ UMAP สำหรับการแสดงภาพ
- **เงื่อนไขการโต้ตอบ**: การรวมคุณสมบัติแบบทวีคูณเพื่อบันทึกเอฟเฟกต์ข้อต่อ

## การวิเคราะห์ข้อมูลเชิงสำรวจ (EDA)
EDA เป็นที่ที่คุณพัฒนาสัญชาตญาณเกี่ยวกับข้อมูลของคุณก่อนการสร้างแบบจำลอง เป้าหมายคือการสังเกตรูปแบบ ความผิดปกติ และความสัมพันธ์
### การเลือกแผนภูมิที่เหมาะสม
| ประเภทแผนภูมิ | ดีที่สุดสำหรับ |
|----------|----------|
| **ฮิสโตแกรม** | การแจกแจงของตัวแปรตัวเดียว |
| **พล็อตกล่อง** | สรุปตัวเลขห้าตัว การตรวจจับค่าผิดปกติ |
| **พล็อตกระจาย** | ความสัมพันธ์ระหว่างตัวแปรต่อเนื่องสองตัว |
| **แผนที่ความร้อน** | เมทริกซ์สหสัมพันธ์ การแสดงภาพความหนาแน่น |
| **แผนภูมิแท่ง** | การเปรียบเทียบหมวดหมู่ |
| **แผนภูมิเส้น** | แนวโน้มในช่วงเวลาหนึ่ง |
| **เนื้อเรื่องไวโอลิน** | ความหนาแน่นของการกระจาย + สรุปพล็อตกล่อง |
| **พล็อตคู่** | ภาพรวมโดยย่อของคู่ตัวแปรทั้งหมด |

## การเรียนรู้ของเครื่องในวิทยาศาสตร์ข้อมูล
### การเรียนรู้แบบมีผู้สอนโดยสรุป
| งาน | อัลกอริทึม |
|------|-----------|
| **การถดถอย** (ทายตัวเลข) | เชิงเส้น, แนวสัน/LASSO, แผนผังการตัดสินใจ, ฟอเรสต์สุ่ม, การเร่งการไล่ระดับสี (XGBoost, LightGBM) |
| **การจัดประเภท** (ทำนายประเภท) | การถดถอยโลจิสติก, k-NN, Naive Bayes, SVM, ต้นไม้การตัดสินใจ, ฟอเรสต์สุ่ม, โครงข่ายประสาทเทียม
### การเรียนรู้แบบไม่มีผู้ดูแลโดยสรุป
| งาน | อัลกอริทึม |
|------|-----------|

### หลักการออกแบบแดชบอร์ด
แดชบอร์ดที่ดีต้องปฏิบัติตามกฎบางประการ: รู้จักผู้ชมของคุณ เลือกการแสดงภาพที่เหมาะสมสำหรับแต่ละเมตริก ใช้สีอย่างมีกลยุทธ์ (ไม่ใช่เชิงตกแต่ง) รักษามาตราส่วนที่สอดคล้องกัน และเปิดใช้งานการโต้ตอบ (ตัวกรอง การเจาะลึก) ประสิทธิภาพก็มีความสำคัญเช่นกัน — ไม่มีใครรอแดชบอร์ดที่ช้า

| **การตลาด** | อัตราการแปลง อัตราการคลิกผ่าน ROAS การระบุแหล่งที่มา |
| **สินค้า** | ผู้ใช้ที่ใช้งานรายวัน, การมีส่วนร่วม, การรักษาผู้ใช้, การใช้คุณลักษณะ |

## จริยธรรมข้อมูลและการกำกับดูแล
### กฎระเบียบความเป็นส่วนตัว
| กฎระเบียบ | ขอบเขต |
|----------||-------|
| **จีดีพีอาร์** | เจ้าของข้อมูลของสหภาพยุโรป สิทธิ์ในการลบ การยินยอม การเคลื่อนย้ายข้อมูล |
| **CCPA** | ผู้บริโภคชาวแคลิฟอร์เนีย ยกเลิกการขายข้อมูล |
| **HIPAA** | ข้อมูลด้านการดูแลสุขภาพของสหรัฐอเมริกา กฎการรักษาความลับที่เข้มงวด |
### ขนาดคุณภาพข้อมูล
| มิติข้อมูล | คำถาม |
|----------|----------|
| **ความแม่นยำ** | ข้อมูลถูกต้องหรือไม่? |
| **ความสมบูรณ์** | มีอะไรหายไปหรือเปล่า? |
| **ความสม่ำเสมอ** | แหล่งข่าวเห็นด้วยหรือไม่? |
| **ความทันเวลา** | เป็นปัจจุบันหรือไม่? |
| **ความถูกต้อง** | เป็นไปตามรูปแบบที่คาดหวังหรือไม่ |
| **ความเป็นเอกลักษณ์** | มีรายการที่ซ้ำกันหรือไม่? |
### อคติและความยุติธรรม
อคติสามารถเข้าสู่ขั้นตอนใดก็ได้: อคติในการสุ่มตัวอย่าง (ข้อมูลที่ไม่ใช่ตัวแทน) อคติในการวัด (เครื่องมือที่มีข้อบกพร่อง) หรืออคติของอัลกอริทึม (การคาดการณ์แบบเลือกปฏิบัติ) กลยุทธ์การลดผลกระทบ ได้แก่ การประมวลผลล่วงหน้า (การแก้ไขข้อมูล) การประมวลผล (การจำกัดโมเดล) และการประมวลผลภายหลัง (การปรับเอาต์พุต) ตัวชี้วัดความเป็นธรรม เช่น ความเท่าเทียมกันทางประชากรศาสตร์และโอกาสที่เท่าเทียมกัน จะช่วยระบุปริมาณของปัญหา

## เทรนด์ที่กำลังมาแรง
- **AutoML**: การสร้างไปป์ไลน์อัตโนมัติและการเลือกโมเดล
- **MLOps**: แนวทางปฏิบัติ DevOps ที่นำไปใช้กับการจัดการวงจรการใช้งาน ML
- **ร้านค้าฟีเจอร์**: การจัดการฟีเจอร์แบบรวมศูนย์เพื่อนำมาใช้ซ้ำทั่วทั้งทีม
- **Data Mesh**: สถาปัตยกรรมข้อมูลแบบกระจายอำนาจที่เป็นเจ้าของโดเมน
- **LLM และ Generative AI**: โมเดลภาษาขนาดใหญ่ที่เปลี่ยนแปลงเวิร์กโฟลว์ข้อความ โค้ด และรูปภาพ
- **Edge Analytics**: การประมวลผลข้อมูลบนอุปกรณ์มากกว่าในระบบคลาวด์
- **การอนุมานเชิงสาเหตุ**: ก้าวข้ามความสัมพันธ์เพื่อทำความเข้าใจสาเหตุและผลกระทบที่แท้จริง
- **การเรียนรู้แบบสหพันธรัฐ**: การฝึกอบรมโมเดลข้อมูลแบบกระจายอำนาจโดยไม่ต้องย้ายข้อมูล
- **AI ที่รับผิดชอบ**: จริยธรรม การอธิบาย และความโปร่งใสกลายเป็นข้อกำหนดมาตรฐาน
