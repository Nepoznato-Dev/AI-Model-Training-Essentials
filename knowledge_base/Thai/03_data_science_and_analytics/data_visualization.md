# การแสดงข้อมูล
แผนภูมิที่ออกแบบมาอย่างดีสามารถเปิดเผยรูปแบบที่ตารางตัวเลขซ่อนอยู่ การออกแบบที่ไม่ดีอาจทำให้เข้าใจผิด สับสน หรือน่าเบื่อได้ การสร้างภาพข้อมูลเป็นงานฝีมือในการเปลี่ยนข้อมูลให้เป็นเรื่องราวแบบภาพเพื่อประกอบการตัดสินใจ ไฟล์นี้ครอบคลุมถึงการเลือกแผนภูมิ หลักการออกแบบ ข้อผิดพลาดทั่วไป และเครื่องมือที่ทำให้ทุกอย่างเป็นไปได้
---

## การเลือกแผนภูมิที่เหมาะสม
การตัดสินใจที่สำคัญที่สุดในการแสดงภาพคือการเลือกประเภทแผนภูมิที่เหมาะสมสำหรับข้อมูลและข้อความของคุณ
### คู่มือการเลือกแผนภูมิ
| เป้าหมายของคุณ | ประเภทแผนภูมิที่ดีที่สุด |
|----------|-----------------|
| **เปรียบเทียบหมวดหมู่** | แผนภูมิแท่ง แผนภูมิแท่งที่จัดกลุ่ม |
| **แสดงการเปลี่ยนแปลงเมื่อเวลาผ่านไป** | แผนภูมิเส้น แผนภูมิพื้นที่ |
| **แสดงการจำหน่าย** | ฮิสโตแกรม พล็อตกล่อง พล็อตไวโอลิน |
| **แสดงความสัมพันธ์** | พล็อตกระจาย แผนภูมิฟอง |
| **แสดงองค์ประกอบ** | แท่งแบบเรียงซ้อน แผนภูมิวงกลม (ส่วนจำกัด) แผนผังต้นไม้ |
| **แสดงความสัมพันธ์** | พล็อตกระจาย, แผนที่ความร้อน, พล็อตคู่ |
| **แสดงอันดับ** | แผนภูมิแท่งแนวนอน |
| **แสดงรูปแบบทางภูมิศาสตร์** | แผนที่ Choropleth, dot map |
| **แสดงบางส่วนต่อทั้งหมดในช่วงเวลาหนึ่ง** | แผนภูมิพื้นที่แบบเรียงซ้อน |
### เมื่อใดควรใช้แต่ละแผนภูมิ
| แผนภูมิ | จุดแข็ง | หลีกเลี่ยงเมื่อ |
|-------|-----------|-----------|
| **บาร์** | การเปรียบเทียบที่ชัดเจนในหมวดหมู่ต่างๆ | มีหมวดหมู่มากเกินไป (>15) |
| **ไลน์** | แนวโน้มในช่วงเวลาหนึ่ง ข้อมูลต่อเนื่อง | ข้อมูลไม่เรียงลำดับ |
| **กระจาย** | ความสัมพันธ์ระหว่างตัวแปรสองตัว | มีจุดที่ทับซ้อนกันมากเกินไป |
| **ฮิสโตแกรม** | รูปแบบการกระจายของตัวแปรตัวเดียว | ขนาดตัวอย่างเล็ก (<20) |
| **Box plot** | Summary statistics + outliers; compare distributions | Audience unfamiliar with them |
| **Heatmap** | Correlation matrices; patterns in 2D data | Too many variables |
| **Pie chart** | Simple composition (2–5 slices) | More than 5 slices; precise comparisons needed |
| **Violin plot** | Distribution density + quartiles | Small audiences unfamiliar with them |
| **Pair plot** | Quick overview of all variable relationships | Many variables (>8) |

## หลักการออกแบบ
### แนวคิดหลักของทัฟเต้
หลักการของ Edward Tufte ยังคงเป็นมาตรฐานทองคำสำหรับการแสดงภาพข้อมูล:
| หลักการ | คำอธิบาย |
|-----------|-------------|
| **เพิ่มอัตราส่วนหมึกข้อมูลสูงสุด** | หมึกทุกหยดควรถ่ายทอดข้อมูล ลบทุกอย่างอื่นออก |
| **กำจัด Chartjunk** | ไม่มีเอฟเฟกต์ 3 มิติ การไล่ระดับสีโดยไม่จำเป็น หรือองค์ประกอบตกแต่ง |
| **แสดงข้อมูล** | อย่าบิดเบือน ซ่อน หรือเด็ดเชอร์รี่ ปล่อยให้ข้อมูลพูด |
| **ทวีคูณเล็ก** | ใช้แผนภูมิขนาดเล็กซ้ำๆ เพื่อเปรียบเทียบระหว่างหมวดหมู่ต่างๆ |
| **เส้นแบบประกายไฟ** | แผนภูมิขนาดคำขนาดเล็กสำหรับข้อมูลแนวโน้มแบบอินไลน์ |
### กฎการออกแบบเชิงปฏิบัติ
| กฎ | ทำไม |
|------|-----|
| **เริ่มแกน y ที่ศูนย์** (สำหรับแผนภูมิแท่ง) | มิฉะนั้น คุณจะพูดเกินจริงถึงความแตกต่าง |
| **ติดป้ายกำกับโดยตรง** | ใส่ป้ายกำกับบนเส้น/แท่งแทนการใช้คำอธิบายเมื่อเป็นไปได้ |
| **ใช้สีอย่างตั้งใจ** | เน้นสิ่งที่สำคัญ ใช้สีเทาสำหรับบริบท |
| **ทำให้มันง่าย** | หนึ่งข้อความต่อแผนภูมิ อย่าโอเวอร์โหลด |
| **ใช้เครื่องชั่งสม่ำเสมอ** | เมื่อเปรียบเทียบแผนภูมิ ให้แกนคงเดิม |
| **สั่งอย่างมีความหมาย** | จัดเรียงแท่งตามค่า (ไม่เรียงตามตัวอักษร) เว้นแต่จะมีการเรียงลำดับตามธรรมชาติ |
| **ให้บริบท** | เพิ่มเกณฑ์มาตรฐาน เป้าหมาย หรือค่าเฉลี่ยในอดีต |
### แนวทางสี
| ใช้กรณี | วิธีการ |
|----------|----------|
| **หมวดหมู่** | เฉดสีที่แตกต่าง (น้ำเงิน ส้ม เขียว แดง) — สูงสุด 7–8 หมวดหมู่ |
| **ตามลำดับ** | จากสว่างไปมืดในเฉดสีเดียว (ฟ้าอ่อน → น้ำเงินเข้ม) |
| **แตกต่าง** | การไล่ระดับสีสองสีสำหรับข้อมูลที่มีจุดกึ่งกลางที่มีความหมาย (แดง ← ขาว → น้ำเงิน) |
| **การเข้าถึง** | ทดสอบด้วยเครื่องจำลองการตาบอดสี ไม่ต้องพึ่งสีเพียงอย่างเดียว (เพิ่มป้ายกำกับหรือลวดลาย) |

## การเล่าเรื่องด้วยข้อมูล
แผนภูมิที่ไม่มีการบรรยายเป็นเพียงภาพ การเล่าเรื่องเปลี่ยนข้อมูลให้เป็นข้อมูลเชิงลึก
### กรอบการเล่าเรื่อง
1. **บริบท**: สถานการณ์เป็นอย่างไร ผู้ชมรู้อะไรบ้างแล้ว?
2. **ข้อขัดแย้ง**: อะไรคือปัญหา ความประหลาดใจ หรือความตึงเครียดในข้อมูล
3. **การแก้ไข**: ผู้ชมควรทำอย่างไรกับข้อมูลเชิงลึกนี้
### เคล็ดลับการปฏิบัติ
| เคล็ดลับ | คำอธิบาย |
|-----|-------------|
| **เป็นผู้นำด้วยความเข้าใจ** | ตั้งชื่อแผนภูมิด้วยประเด็นสำคัญ ไม่ใช่ข้อมูล ("รายได้เพิ่มขึ้น 30%" ไม่ใช่ "รายได้ตามไตรมาส") |
| **ใส่คำอธิบายประกอบประเด็นสำคัญ** | เพิ่มข้อความบรรยายเหตุการณ์สำคัญหรือจุดเปลี่ยน |
| **ใช้การเปิดเผยแบบก้าวหน้า** | แสดงทีละแผนภูมิ สร้างเรื่องราวทีละขั้นตอน |
| **เน้นสิ่งที่สำคัญ** | ใช้สีหรือขนาดเพื่อดึงดูดความสนใจไปยังจุดข้อมูลสำคัญ |
| **ระบุ "แล้วไงล่ะ?"** | ทุกแผนภูมิควรตอบคำถามหรือแสดงการดำเนินการ |

## ข้อผิดพลาดทั่วไป
| ความผิดพลาด | ทำไมมันแย่ | แก้ไข |
|---------|-------------|-----|
| **แกน y ที่ถูกตัดทอน** | พูดเกินจริงถึงความแตกต่างเล็ก ๆ น้อย ๆ | เริ่มต้นที่ศูนย์สำหรับแผนภูมิแท่ง |
| **ช่วงเวลาเก็บเชอร์รี่** | ความเข้าใจผิดเกี่ยวกับเทรนด์ | แสดงช่วงที่มีอยู่ทั้งหมด |
| **มีสีมากเกินไป** | ครอบงำผู้ชม | จำกัดที่ 5–7; ใช้สีเทาสำหรับบริบท |
| **แกน y คู่** | หมายถึงความสัมพันธ์ที่อาจไม่มี | ใช้แผนภูมิสองแผนภูมิแยกกัน |
| **แผนภูมิ 3 มิติ** | บิดเบือนสัดส่วน | ใช้ 2D | เสมอ
| **แผนภูมิวงกลมที่มีมากกว่า 10 ชิ้น** | เปรียบเทียบไม่ได้ | ใช้แผนภูมิแท่งแทน |
| **ไม่มีป้ายกำกับ** | ผู้ดูไม่เข้าใจแผนภูมิ | ติดป้ายกำกับแกน ชื่อ และหน่วย | เสมอ
| **แผนภูมิพื้นที่ที่ทำให้เข้าใจผิด** | พื้นที่ซ้อนกันบิดเบือนการรับรู้ของแต่ละซีรีส์ | ใช้แผนภูมิเส้นหรือทวีคูณเล็กๆ |

## การออกแบบแดชบอร์ด
แดชบอร์ดคือชุดของการแสดงภาพที่ร่วมกันบอกเล่าเรื่องราวที่สมบูรณ์เกี่ยวกับกระบวนการ ระบบ หรือธุรกิจ
### ประเภทแดชบอร์ด
| พิมพ์ | ผู้ชม | วัตถุประสงค์ |
|------|----------|---------|
| **เชิงกลยุทธ์** | ผู้บริหาร | KPI ระดับสูง แนวโน้มระยะยาว |
| **ปฏิบัติการ** | ผู้จัดการ | การตรวจสอบแบบเรียลไทม์ การดำเนินงานรายวัน |
| **วิเคราะห์** | นักวิเคราะห์ | การสำรวจเชิงลึก การกรองการเจาะลึก |
### รายการตรวจสอบการออกแบบ
- **รู้จักผู้ชมของคุณ**: พวกเขาจะตัดสินใจอะไรจากแดชบอร์ดนี้
- **กฎ 5 วินาที**: สามารถเข้าใจประเด็นหลักภายใน 5 วินาทีได้หรือไม่
- **เค้าโครง**: เมตริกที่สำคัญที่สุดด้านซ้ายบน (โดยคำนึงถึงความสำคัญก่อน)
- **จำกัดประเภทแผนภูมิ**: สูงสุด 3-4 ประเภทต่อแดชบอร์ดเพื่อความสอดคล้อง
- **โต้ตอบโดยค่าเริ่มต้น**: ตัวกรอง ตัวเลือกช่วงวันที่ การเจาะลึก
- **ประสิทธิภาพ**: แดชบอร์ดที่ใช้เวลาโหลดมากกว่า 5 วินาทีจะไม่ถูกใช้งาน
- **อุปกรณ์เคลื่อนที่**: พิจารณาการออกแบบที่ตอบสนองต่อผู้ใช้หากผู้ใช้ต้องการในระหว่างเดินทาง

## สรุป
