#วิธีการประกอบ
วิธีการแบบ Ensemble ผสมผสานโมเดลการเรียนรู้ของเครื่องหลายแบบเข้าด้วยกันเพื่อสร้างการคาดการณ์ที่ดีกว่าโมเดลเดียวสามารถทำได้เพียงอย่างเดียว สัญชาตญาณตรงไปตรงมา: หากคุณมีแบบจำลองหลายแบบที่แต่ละแบบจำลองค่อนข้างแม่นยำแต่ทำข้อผิดพลาดต่างกัน การรวมการคาดการณ์เข้าด้วยกันจะยกเลิกข้อผิดพลาดแต่ละรายการและให้ผลลัพธ์ที่ชัดเจนยิ่งขึ้น วงดนตรีอยู่เบื้องหลังโซลูชันแมชชีนเลิร์นนิงที่มีการแข่งขันสูงที่สุด และยังคงเป็นเทคนิคที่เชื่อถือได้มากที่สุดในระบบการผลิต
---

## ทำไมวงดนตรีถึงทำงาน
| หลักการ | คำอธิบาย |
|-----------|-------------|
| **ภูมิปัญญาฝูงชน** | การประมาณค่าที่ไม่สมบูรณ์หลายค่าโดยค่าเฉลี่ยจะดีกว่าค่าประมาณค่าเดียว |
| **การแลกเปลี่ยนความแปรปรวนอคติ** | วงดนตรีสามารถลดความแปรปรวน (การบรรจุถุง) หรืออคติ (การเพิ่ม) โดยไม่ต้องเสียสละสิ่งอื่น
| **ข้อผิดพลาดด้านความหลากหลาย** | หากโมเดลสร้างข้อผิดพลาดที่แตกต่างกัน การรวมโมเดลเหล่านั้นเข้าด้วยกันจะยกเลิกข้อผิดพลาดแต่ละรายการ |
| **ขอบเขตการตัดสินใจราบรื่นขึ้น** | โมเดลหลายตัวสร้างพื้นที่การตัดสินใจที่แข็งแกร่งมากกว่าโมเดลเดียว |

## การบรรจุถุง (การรวม Bootstrap)
### มันทำงานอย่างไร
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. การสุ่มตัวอย่าง Bootstrap** | สุ่มตัวอย่างหลายตัวอย่าง (พร้อมการทดแทน) จากข้อมูลการฝึกอบรม |
| **2. โมเดลฐานรถไฟ** | ฝึกโมเดลหนึ่งตัวในแต่ละตัวอย่างบูตสแตรป (โดยทั่วไปคือแผนผังการตัดสินใจ) |
| **3. รวม** | สำหรับการถดถอย: การทำนายโดยเฉลี่ย สำหรับการจัดหมวดหมู่: คะแนนเสียงข้างมาก |
### ลักษณะสำคัญ
| ลักษณะเฉพาะ | คำอธิบาย |
|---------------|-------------|
| **ลดความแปรปรวน** | การหาค่าเฉลี่ยจะช่วยลดความผันผวนของโมเดลแต่ละรายการ |
| **การฝึกคู่ขนาน** | แต่ละโมเดลพื้นฐานมีความเป็นอิสระ สามารถฝึกได้พร้อมกัน |
| **การประเมินนอกถุง** | แต่ละตัวอย่างจะเหลืออยู่ในตัวอย่างบูตสแตรปบางตัวอย่าง ใช้สำหรับการตรวจสอบ |
| **การตกแต่ง** | การเลือกคุณสมบัติแบบสุ่มในแต่ละการแยกจะลดความสัมพันธ์ระหว่างต้นไม้ |
### ป่าสุ่ม
| ด้าน | คำอธิบาย |
|--------|-------------|
| **ผู้เรียนพื้นฐาน** | ต้นไม้การตัดสินใจ |
| **ส่วนเพิ่มเติมที่สำคัญ** | ในแต่ละการแยก ให้พิจารณาเฉพาะชุดย่อยของคุณลักษณะแบบสุ่ม (โดยทั่วไปคือ sqrt(n_features)) |
| **ทำไมมันถึงได้ผล** | การเลือกคุณสมบัติแบบสุ่มจะตกแต่งต้นไม้ ทำให้ชุดมีความแข็งแกร่งมากขึ้น |
| **ไฮเปอร์พารามิเตอร์** | จำนวนต้นไม้ ความลึกสูงสุด ตัวอย่างขั้นต่ำต่อใบ; คุณสมบัติสูงสุด |
| **จุดแข็ง** | จัดการข้อมูลมิติสูง ทนทานต่อค่าผิดปกติ ให้ความสำคัญกับคุณลักษณะ |
| **จุดอ่อน** | ตีความได้น้อยกว่าต้นไม้เดี่ยว สามารถใช้งานการถดถอยที่มีเสียงดังมากเกินไปได้

## กำลังใจ
### มันทำงานอย่างไร
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. รถไฟรุ่นแรก** | ฝึกโมเดลพื้นฐาน (มักเป็นต้นไม้ตื้น / "ตอไม้") บนข้อมูล |
| **2. ระบุข้อผิดพลาด** | ค้นหากรณีใดที่แบบจำลองผิดพลาด |
| **3. เทรนรุ่นต่อไป** | ฝึกโมเดลใหม่โดยเน้นที่ข้อผิดพลาด (ถ่วงน้ำหนักใหม่หรือติดตั้งส่วนที่เหลือ) |
| **4. รวมตามลำดับ** | รุ่นใหม่แต่ละรุ่นจะแก้ไขข้อผิดพลาดที่สะสมของรุ่นก่อนหน้าทั้งหมด |
| **5. ซ้ำ** | ต่อไปตามจำนวนรอบที่กำหนด |
### การส่งเสริมอัลกอริทึม
| อัลกอริทึม | ฟังก์ชันการสูญเสีย | คุณสมบัติที่สำคัญ |
|----------|--------------|-------------|
| **AdaBoost** | เอ็กซ์โปเนนเชียล | ปรับน้ำหนักอินสแตนซ์ที่จัดประเภทผิดอีกครั้ง เรียบง่าย; ไวต่อเสียงรบกวน |
| **การเร่งการไล่ระดับสี** | การสูญเสียเชิงอนุพันธ์ใด ๆ | เหมาะกับสิ่งตกค้าง (การไล่ระดับของการสูญเสีย); ยืดหยุ่นมากขึ้น |
| **XGBoost** | การเร่งการไล่ระดับสีแบบสม่ำเสมอ | การทำให้เป็นมาตรฐานของ L1/L2; การไล่ระดับสีลำดับที่สอง การเพิ่มประสิทธิภาพฮาร์ดแวร์ |
| **LightGBM** | การสุ่มตัวอย่างด้านเดียวแบบไล่ระดับสี | การเจริญเติบโตตามใบ อิงฮิสโตแกรม; รวดเร็วบนชุดข้อมูลขนาดใหญ่ |
| **CatBoost** | สั่งบูสต์ | จัดการคุณสมบัติหมวดหมู่โดยกำเนิด; ลดการฟิตติ้งมากเกินไป |
### การเร่งเทียบกับการห่อ
| มิติข้อมูล | การบรรจุถุง | ส่งเสริม |
|----------|---------|----------|
| **การฝึกอบรม** | ขนาน | ลำดับ |
| **โฟกัส** | ลดความแปรปรวน | ลดอคติ |
| **รุ่นพื้นฐาน** | ความแปรปรวนสูง อคติต่ำ (ต้นไม้ลึก) | ความแปรปรวนต่ำ มีอคติสูง (ต้นไม้ตื้น / ตอไม้) |
| **การรวมกัน** | น้ำหนักเท่ากัน | ถ่วงน้ำหนักด้วยประสิทธิภาพ |
| **การโอเวอร์ฟิต** | มีแนวโน้มน้อยลง | สามารถฟิตเกินได้ถ้าหลายรอบเกินไป |
| **ความไวต่อเสียงรบกวน** | แข็งแกร่ง | ไวต่อข้อมูลที่มีเสียงดัง |

## ซ้อน
### มันทำงานอย่างไร
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. โมเดลฐานรถไฟ** | ฝึกฝนโมเดลที่หลากหลาย (เช่น ฟอเรสต์แบบสุ่ม, SVM, โครงข่ายประสาทเทียม, การเร่งการไล่ระดับสี) |
| **2. สร้างคำทำนาย** | ใช้การคาดการณ์ที่ไม่ครึ่งหน้า (การตรวจสอบความถูกต้องข้าม) เป็นคุณลักษณะอินพุต |
| **3. ฝึกเมตาโมเดล** | ฝึกฝนโมเดลระดับที่สองตามการคาดการณ์ของโมเดลพื้นฐาน |
| **4. ทำนายสุดท้าย** | แบบจำลองพื้นฐานทำนาย; meta-model รวมการคาดการณ์ |
### แนวทางปฏิบัติที่ดีที่สุดในการซ้อน
| การปฏิบัติ | เหตุผล |
|---------||--------|
| **ใช้โมเดลพื้นฐานที่หลากหลาย** | อัลกอริธึมที่ต่างกันทำให้เกิดข้อผิดพลาดต่างกัน ความหลากหลายคือประเด็นทั้งหมด |
| **ใช้การตรวจสอบข้ามสำหรับการทำนายฐาน** | ป้องกันไม่ให้เมตาโมเดลเรียนรู้ที่จะใช้ประโยชน์จากโมเดลฐานที่มากเกินไป |
| **ทำให้ meta-model เรียบง่าย** | การถดถอยโลจิสติกหรือต้นไม้ตื้น รุ่นพื้นฐานทำหน้าที่ยกของหนัก |
| **รวมฟีเจอร์ดิบใน meta-model** | บางครั้งก็มีประโยชน์ในการให้ meta-model เข้าถึงคุณสมบัติดั้งเดิมด้วย |

## การลงคะแนนเสียงและการหาค่าเฉลี่ย
### การลงคะแนนอย่างหนัก (จำแนก)
| รุ่น | การทำนาย |
|-------|-----------|
| รุ่น ก | ชั้น 1 |
| รุ่นบี | คลาส 0 |
| รุ่นซี | ชั้น 1 |
| **เสียงข้างมาก** | **ชั้น 1** |
### Soft Voting (จำแนกประเภท)
| รุ่น | P(คลาส 0) | ป(คลาส 1) |
|-------|-----------|-----------|
| รุ่น ก | 0.3 | 0.7 |
| รุ่นบี | 0.6 | 0.4 |
| รุ่นซี | 0.4 | 0.6 |
| **เฉลี่ย** | **0.43** | **0.57** |
| **การทำนาย** | | **ชั้น 1** |
### ถัวเฉลี่ยถ่วงน้ำหนัก
| รุ่น | น้ำหนัก | การทำนาย |
|-------|--------|-----------|
| รุ่น ก | 0.5 | 0.8 |
| รุ่นบี | 0.3 | 0.6 |
| รุ่นซี | 0.2 | 0.9 |
| **ค่าเฉลี่ยถ่วงน้ำหนัก** | | 0.5×0.8 + 0.3×0.6 + 0.2×0.9 = 0.76 |

## คำแนะนำการปฏิบัติ
### เมื่อใดควรใช้ชุดใด
| สถานการณ์ | วิธีที่แนะนำ |
|----------|-------------------|
| **พื้นฐานด่วน; ข้อมูลแบบตาราง** | ป่าสุ่ม |
| **ความแม่นยำสูงสุด ข้อมูลแบบตาราง** | XGBoost / LightGBM / CatBoost |
| **ข้อมูลมีสัญญาณรบกวน** | การห่อ (การเพิ่มจะทำให้เสียงรบกวนมากเกินไป) |
| **จำเป็นต้องมีการตีความ** | รุ่นเดี่ยวหรือชุดเล็กที่มีความสำคัญด้านคุณสมบัติ |
| **หลากหลายรุ่น** | การซ้อนหรือการลงคะแนนเสียง |
| **เรียนออนไลน์** | วิธีการสตรีมมิ่งทั้งมวล การเพิ่มประสิทธิภาพแบบปรับตัว |
| **ข้อมูลไม่สมดุล** | ป่าสุ่มที่สมดุล; การส่งเสริมที่คำนึงถึงต้นทุน |
### รวบรวมกลยุทธ์ความหลากหลาย
| กลยุทธ์ | คำอธิบาย |
|----------|-------------|
| **อัลกอริธึมที่แตกต่างกัน** | รวมโมเดลแบบต้นไม้ แบบเชิงเส้น และแบบนิวรัล |
| **คุณสมบัติที่แตกต่าง** | ฝึกฝนโมเดลบนชุดย่อยของคุณสมบัติที่แตกต่างกัน |
| **ชุดย่อยของข้อมูลที่แตกต่างกัน** | การบรรจุถุง; การสุ่มตัวอย่าง |
| **ไฮเปอร์พารามิเตอร์ที่แตกต่างกัน** | อัลกอริธึมเดียวกันกับการกำหนดค่าที่หลากหลาย |
| **ช่วงเวลาต่างกัน** | ฝึกบนหน้าต่างเวลาที่แตกต่างกัน |

## สรุป
วิธีการทั้งมวลทำงานได้เนื่องจากรวมแบบจำลองที่ไม่สมบูรณ์หลายตัวเข้าไว้ในตัวทำนายที่แข็งแกร่งตัวเดียว การบรรจุถุง (ป่าสุ่ม) ช่วยลดความแปรปรวนโดยโมเดลการฝึกอบรมควบคู่ไปกับตัวอย่างบูตสแตรปและการหาค่าเฉลี่ย การบูสต์ (XGBoost, LightGBM, CatBoost) ช่วยลดอคติโดยการฝึกโมเดลตามลำดับ โดยแต่ละโมเดลจะแก้ไขข้อผิดพลาดก่อนหน้านี้ การซ้อนใช้เมตาโมเดลเพื่อรวมโมเดลพื้นฐานที่หลากหลาย การลงคะแนนเสียงและการหาค่าเฉลี่ยเป็นชุดที่ง่ายที่สุด หัวข้อทั่วไปคือความหลากหลาย: ชุดวงดนตรีจะทำงานได้ดีที่สุดเมื่อโมเดลส่วนประกอบมีความสมเหตุสมผลแต่มีข้อผิดพลาดต่างกัน ในทางปฏิบัติ การเพิ่มการไล่ระดับสีบนข้อมูลแบบตารางมักเป็นวิธีเดียวที่มีประสิทธิภาพสูงสุด ในขณะที่การซ้อนโมเดลที่หลากหลายจะช่วยเพิ่มความแม่นยำในการแข่งขันและแอปพลิเคชันที่มีเดิมพันสูง
