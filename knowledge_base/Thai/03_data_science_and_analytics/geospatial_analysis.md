# การวิเคราะห์เชิงพื้นที่
การวิเคราะห์เชิงพื้นที่เป็นกระบวนการตรวจสอบข้อมูลที่มีองค์ประกอบทางภูมิศาสตร์ เช่น พิกัด ที่อยู่ ขอบเขต หรือข้อมูลใดๆ ที่เชื่อมโยงกับตำแหน่งบนโลก โดยตอบคำถามต่างๆ เช่น "ลูกค้าของเราอยู่ที่ไหน" "เส้นทางใดที่เหมาะสมที่สุด" และ "การใช้ที่ดินเปลี่ยนแปลงไปตามกาลเวลาอย่างไร" ชุดข้อมูลทุกชุดมีมิติเชิงพื้นที่ และการทำความเข้าใจจะปลดล็อกข้อมูลเชิงลึกที่การวิเคราะห์ทางสถิติเพียงอย่างเดียวพลาดไป
---

## แนวคิดหลัก
### ระบบพิกัด
| ระบบ | คำอธิบาย | ใช้กรณี |
|--------|-------------|----------|
| **WGS 84 (กำไรต่อหุ้น:4326)** | มาตรฐานระดับโลก ละติจูด/ลองจิจูด เป็นองศา | จีพีเอส; การทำแผนที่เว็บส่วนใหญ่ จีโอเจสัน |
| **เว็บ Mercator (EPSG:3857)** | ฉายภาพโลกลงบนทรงกระบอก บิดเบือนพื้นที่บริเวณเสา | Google แผนที่; กล่องแผนที่; บริการไทล์เว็บส่วนใหญ่ |
| **UTM** (เครื่องเมอร์เคเตอร์ตามขวางสากล) | แบ่งโลกออกเป็น 60 โซน ตามเมตร | ทหาร; การสำรวจ; งานท้องถิ่นที่มีความแม่นยำสูง |
| **ตารางแห่งชาติอังกฤษ (EPSG:27700)** | ข้อมูล OSGB36; ตามเมตร | การทำแผนที่สหราชอาณาจักร |
| **ประมาณการท้องถิ่น** | การฉายภาพแบบกำหนดเองสำหรับภูมิภาคเฉพาะ | ลดการบิดเบือนของพื้นที่เฉพาะ |
### ประเภทเรขาคณิต
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **จุด** | พิกัดเดียว | ร้านอาหาร; เซ็นเซอร์; ลูกค้า |
| **LineString** | ลำดับของคะแนน | ถนน; แม่น้ำ; เส้นทาง |
| **รูปหลายเหลี่ยม** | รูปทรงปิดพร้อมภายใน | ประเทศ; ทะเลสาบ; โซนจัดส่ง |
| **มัลติพอยต์** | การสะสมคะแนน | ป้ายรถเมล์ทั้งหมดในเมือง |
| **MultiLineString** | ชุดของเส้น | ถนนทุกสายในเครือข่าย |
| **หลายเหลี่ยม** | การรวบรวมรูปหลายเหลี่ยม | หมู่เกาะ; ประเทศที่มีเกาะ |
| **GeometryCollection** | ประเภทผสม | ประเทศที่มีเมือง ถนน และแม่น้ำ |

## รูปแบบข้อมูล
| รูปแบบ | พิมพ์ | คุณสมบัติที่สำคัญ |
|--------|-------|-------------|
| **GeoJSON** | ข้อความ (JSON) | มนุษย์สามารถอ่านได้; เป็นมิตรกับเว็บ; รองรับรูปทรงเรขาคณิตทุกประเภท |
| **ไฟล์รูปร่าง** | ไบนารี่ (หลายไฟล์) | รูปแบบเดิมจาก ESRI; .shp + .shx + .dbf + .prj |
| **KML** | XML | กูเกิลเอิร์ธ; รองรับ 3D และเวลา |
| **จีโอแพ็คเกจ** | ที่ใช้ SQLite | ไฟล์เดียว; รองรับแรสเตอร์และเวกเตอร์ มาตรฐานทันสมัย ​​|
| **จีโอปาร์เก้** | เสา (ไม้ปาร์เก้) | มีประสิทธิภาพสำหรับชุดข้อมูลขนาดใหญ่ ผสานรวมกับเครื่องมือวิศวกรรมข้อมูล |
| **WKT / WKB** | ข้อความ / ไบนารี | ข้อความที่รู้จักกันดี; ไบนารี่ที่รู้จักกันดี; ใช้สำหรับจัดเก็บฐานข้อมูล |
| **เอ็มวีที** | ไบนารี่ | ไทล์เวกเตอร์ Mapbox; สำหรับการให้บริการข้อมูลแผนที่ไปยังเว็บไคลเอ็นต์ |

## ปฏิบัติการเชิงพื้นที่
### การดำเนินงานขั้นพื้นฐาน
| การดำเนินงาน | คำอธิบาย | ตัวอย่าง |
|----------|-------------|---------|
| **ระยะทาง** | คำนวณระยะห่างระหว่างรูปทรงเรขาคณิต | "ค้นหาโรงพยาบาลทั้งหมดภายใน 10 กม." |
| **บัฟเฟอร์** | สร้างรูปหลายเหลี่ยมรอบเรขาคณิตตามระยะที่กำหนด | "โชว์โซน 500 เมตร รอบโรงเรียน" |
| **สี่แยก** | ค้นหาพื้นที่ทับซ้อนกันระหว่างเรขาคณิต | “พัสดุไหนอยู่ในเขตน้ำท่วมบ้าง?” |
| **สหภาพ** | รวมรูปทรงเรขาคณิตให้เป็นหนึ่ง | "รวมแปลงที่ดินทั้งหมดให้เป็นภาคเดียว" |
| **ความแตกต่าง** | ลบเรขาคณิตหนึ่งจากอีก | "พื้นที่ที่สามารถสร้างได้ ยกเว้นโซนที่ได้รับการคุ้มครอง" |
| **มี / ภายใน** | ทดสอบว่าเรขาคณิตหนึ่งอยู่ภายใน | อื่นหรือไม่ “ลูกค้าคนไหนที่อยู่ในพื้นที่จัดส่งนี้” |
| **เพื่อนบ้านที่ใกล้ที่สุด** | ค้นหาเรขาคณิตที่ใกล้เคียงที่สุด | "สถานีดับเพลิงที่ใกล้ที่สุดอยู่ที่ไหน" |
| **ร่วมเชิงพื้นที่** | เข้าร่วมแอตทริบิวต์ตามความสัมพันธ์เชิงพื้นที่ | "มอบหมายแต่ละจุดให้กับการสำรวจสำมะโนประชากรที่มีอยู่" |
### การจัดทำดัชนีเชิงพื้นที่
| ประเภทดัชนี | คำอธิบาย | ใช้กรณี |
|----------|-------------|----------|
| **อาร์-ทรี** | ลำดับชั้นของกรอบขอบเขต; ที่พบบ่อยที่สุด | โพสต์ GIS; เอสคิวไลต์; วัตถุประสงค์ทั่วไป |
| **ควอดทรี** | การแบ่งย่อยแบบเรียกซ้ำเป็นจตุภาค | ข้อมูลจุด เครื่องยนต์เกม |
| **จีโอแฮช** | ตารางลำดับชั้น เข้ารหัสเป็นสตริง | การค้นหาบริเวณใกล้เคียง การแบ่งส่วนฐานข้อมูล |
| **H3** (อูเบอร์) | ตารางลำดับชั้นหกเหลี่ยม | การวิเคราะห์; การแชร์รถ; ถังขยะเครื่องแบบ |
| **S2** (Google) | ลำดับชั้นที่อิงเซลล์บนทรงกลม | การจัดทำดัชนีเชิงพื้นที่ขนาดใหญ่ |

| **Kepler.gl** | จาวาสคริปต์ | การแสดงภาพเชิงพื้นที่ที่ขับเคลื่อนด้วย WebGL |

## รูปแบบการวิเคราะห์เชิงพื้นที่
### ประเภทการวิเคราะห์ทั่วไป
| รูปแบบ | คำอธิบาย | ใช้กรณี |
|---------|-------------|----------|
| **การวิเคราะห์รูปแบบจุด** | ตรวจสอบการกระจายคะแนน | การทำแผนที่อาชญากรรม การตรวจหาการระบาดของโรค |
| **การวิเคราะห์ฮอตสปอต** | ค้นหากลุ่มที่มีนัยสำคัญทางสถิติ | ที่ตั้งร้านค้าปลีก อาชญากรรม; ระบาดวิทยา |
| **การวิเคราะห์เครือข่าย** | การเพิ่มประสิทธิภาพเส้นทาง พื้นที่ให้บริการ | โลจิสติกส์; การตอบสนองฉุกเฉิน สาธารณูปโภค |
| **การแก้ไขเชิงพื้นที่** | ค่าประมาณ ณ ตำแหน่งที่ไม่ได้สุ่มตัวอย่าง | คุณภาพอากาศ; คุณสมบัติของดิน สภาพอากาศ |
| **การตรวจจับการเปลี่ยนแปลงการใช้ที่ดิน** | เปรียบเทียบภาพถ่ายดาวเทียมในช่วงเวลาหนึ่ง | แผ่กิ่งก้านสาขา; ตัดไม้ทำลายป่า; เกษตรกรรม |
| **การวิเคราะห์ความเหมาะสม** | ค้นหาสถานที่ที่ตรงตามเกณฑ์หลายข้อ | การเลือกไซต์ การวางแผนอนุรักษ์ |
| **ความสัมพันธ์อัตโนมัติเชิงพื้นที่** | วัดว่าค่าใกล้เคียงเกี่ยวข้องกันอย่างไร | ราคาทรัพย์สิน การแพร่กระจายของโรค |
### ปัญหาหน่วย Areal ที่แก้ไขได้ (MAUP)
| ด้าน | ปัญหา |
|--------|---------|
| **เอฟเฟกต์สเกล** | ผลลัพธ์จะเปลี่ยนแปลงขึ้นอยู่กับขนาดของหน่วยการวิเคราะห์ (การสำรวจสำมะโนประชากรเทียบกับเทศมณฑลและรัฐ) |
| **เอฟเฟกต์การแบ่งเขต** | ผลลัพธ์จะเปลี่ยนไปขึ้นอยู่กับวิธีการวาดขอบเขต แม้จะอยู่ในระดับเดียวกัน |
| **ความหมาย** | อย่าถือว่าผลลัพธ์ในระดับการรวมหนึ่งนำไปใช้กับอีกระดับหนึ่ง ทดสอบความไวต่อขอบเขต | เสมอ

## ข้อควรพิจารณาในทางปฏิบัติ
| ความกังวล | คำแนะนำ |
|---------|----------|
| **ระบบอ้างอิงพิกัด** | ตรวจสอบ CRS เสมอ อย่าผสมการคาดการณ์ในการคำนวณ แปลงสภาพก่อนคำนวณระยะทาง |
| **ความแม่นยำ** | ความแม่นยำของจุดลอยตัวมีความสำคัญในขนาดเล็ก ใช้ประเภทข้อมูลที่เหมาะสม |
| **ประสิทธิภาพ** | การดำเนินงานเชิงพื้นที่มีราคาแพง ใช้ดัชนีเชิงพื้นที่ ลดความซับซ้อนของรูปทรงเรขาคณิตสำหรับการแสดงผล |
| **โทโพโลยี** | ตรวจสอบให้แน่ใจว่ารูปทรงเรขาคณิตนั้นถูกต้อง (ไม่มีจุดตัดของตัวเอง รูปหลายเหลี่ยมแบบปิด) ก่อนการวิเคราะห์ |
| **สเกล** | Web Mercator บิดเบือนพื้นที่ อย่าใช้สำหรับการคำนวณพื้นที่ |
| **คุณภาพของข้อมูล** | ตรวจสอบรูปทรงว่าง จุดยอดซ้ำ รูปหลายเหลี่ยมเศษไม้ |

## สรุป
การวิเคราะห์เชิงพื้นที่จะเปลี่ยนข้อมูลตำแหน่งให้เป็นข้อมูลเชิงลึกที่นำไปใช้ได้จริง จุด เส้น และรูปหลายเหลี่ยมแสดงถึงตัวตนในโลกแห่งความเป็นจริง การดำเนินการเชิงพื้นที่ — ระยะทาง บัฟเฟอร์ จุดตัด การรวม — ตอบคำถามเกี่ยวกับความใกล้ชิด การทับซ้อนกัน และการกักกัน เครื่องมือมีตั้งแต่ PostGIS สำหรับการวิเคราะห์ระดับฐานข้อมูลไปจนถึง GeoPandas สำหรับเวิร์กโฟลว์ Python ไปจนถึง Deck.gl สำหรับการแสดงภาพเว็บ ความท้าทายที่สำคัญคือการเลือกระบบพิกัดที่เหมาะสม การจัดการประสิทธิภาพด้วยชุดข้อมูลขนาดใหญ่ และการตระหนักถึง MAUP — ความจริงที่ว่าการเลือกขอบเขตการรวมตัวของคุณจะส่งผลต่อผลลัพธ์ของคุณ ไม่ว่าคุณจะปรับเส้นทางการจัดส่งให้เหมาะสม วิเคราะห์การแพร่กระจายของโรค หรือจัดทำแผนที่การเติบโตของเมือง การวิเคราะห์เชิงพื้นที่จะให้บริบทเชิงพื้นที่ที่ตัวเลขล้วนไม่สามารถจับภาพได้
