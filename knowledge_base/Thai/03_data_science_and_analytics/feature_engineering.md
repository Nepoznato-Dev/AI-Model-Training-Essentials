# คุณสมบัติทางวิศวกรรม
วิศวกรรมฟีเจอร์เป็นกระบวนการในการแปลงข้อมูลดิบให้เป็นตัวแทนที่ทำให้โมเดลการเรียนรู้ของเครื่องมีประสิทธิภาพมากขึ้น มักได้รับการอธิบายว่าเป็นขั้นตอนที่สำคัญที่สุดในไปป์ไลน์ ML คุณสมบัติที่คุณให้กับโมเดลมีความสำคัญมากกว่าอัลกอริทึมที่คุณเลือก โดยทั่วไปแล้ว โมเดลที่เรียบง่ายพร้อมคุณสมบัติที่ออกแบบมาอย่างดีจะมีประสิทธิภาพเหนือกว่าโมเดลที่ซับซ้อนด้วยอินพุตดิบที่ยังไม่ได้ประมวลผล ศิลปะอยู่ที่การทำความเข้าใจทั้งโดเมนและข้อมูลที่ดีพอที่จะสร้างสัญญาณที่โมเดลสามารถเรียนรู้ได้
---

## ทำไมคุณลักษณะทางวิศวกรรมจึงมีความสำคัญ
| ปัจจัย | ผลกระทบ |
|--------|--------|
| **คุณภาพสัญญาณ** | คุณสมบัติที่ดีกว่า = รูปแบบที่ชัดเจนยิ่งขึ้นสำหรับโมเดลในการเรียนรู้ |
| **โมเดลเรียบง่าย** | คุณสมบัติที่ดีช่วยให้โมเดลที่เรียบง่ายทำงานได้ดี ความต้องการสถาปัตยกรรมที่ซับซ้อนน้อยลง |
| **ความเร็วการฝึก** | ฟีเจอร์ที่เกี่ยวข้องและปรับขนาดได้เหมาะสมมาบรรจบกันเร็วขึ้น |
| **ลักษณะทั่วไป** | คุณลักษณะที่แจ้งโดยโดเมนช่วยให้โมเดลทำงานกับข้อมูลที่มองไม่เห็น |
| **การตีความ** | คุณสมบัติที่มีความหมายง่ายต่อการอธิบายให้ผู้มีส่วนได้ส่วนเสีย |

## ประเภทของการเปลี่ยนแปลงคุณสมบัติ
### การแปลงตัวเลข
| การเปลี่ยนแปลง | สูตร / คำอธิบาย | เมื่อใดควรใช้ |
|------------------|---------------------------------|-------------|
| **บันทึกการแปลง** | บันทึก(x) หรือ บันทึก(x + 1) | การแจกแจงแบบเบ้ขวา ค่าเงิน |
| **รากที่สอง** | sqrt(x) | เอียงปานกลาง นับข้อมูล |
| **กล่อง-ค็อกซ์** | การแปลงพาราเมตริกที่ค้นหาการแปลงกำลังที่ดีที่สุด | ทำให้ข้อมูลมีการกระจายแบบปกติมากขึ้น |
| **ยอ-จอห์นสัน** | เช่นเดียวกับ Box-Cox แต่จัดการค่าลบ | ข้อมูลเบ้ที่มีค่าลบ |
| **มาตรฐาน** | (x - ค่าเฉลี่ย) / มาตรฐาน | คุณสมบัติที่มีขนาดต่างกัน อัลกอริธึมที่ถือว่าปกติ |
| **สเกลต่ำสุด-สูงสุด** | (x - นาที) / (สูงสุด - นาที) | กำหนดขอบเขตคุณสมบัติเป็น [0, 1]; ค่าพิกเซลของภาพ |
| **การปรับขนาดที่แข็งแกร่ง** | (x - ค่ามัธยฐาน) / IQR | ข้อมูลที่มีค่าผิดปกติ |
| **บินนิ่ง** | แปลงค่าต่อเนื่องเป็นหมวดหมู่ | ความสัมพันธ์แบบไม่เชิงเส้น ต้นไม้ตัดสินใจ |
| **คุณสมบัติพหุนาม** | x², x³, x₁×x₂ | การจับความสัมพันธ์แบบไม่เชิงเส้นในโมเดลเชิงเส้น |
### การเข้ารหัสหมวดหมู่
| การเข้ารหัส | คำอธิบาย | เมื่อใดควรใช้ |
|----------|-------------|-------------|
| **การเข้ารหัสแบบร้อนแรง** | สร้างคอลัมน์ไบนารีสำหรับแต่ละหมวดหมู่ | หมวดหมู่ที่มีคาร์ดินัลต่ำ โมเดลแบบต้นไม้จัดการโดยกำเนิด |
| **การเข้ารหัสฉลาก** | กำหนดจำนวนเต็มให้กับแต่ละหมวดหมู่ | หมวดหมู่ลำดับ; โมเดลแบบต้นไม้ |
| **การเข้ารหัสเป้าหมาย** | แทนที่หมวดหมู่ด้วยค่าเฉลี่ยของตัวแปรเป้าหมาย | หมวดหมู่ที่มีคาร์ดินัลลิตี้สูง หลีกเลี่ยงการปรับให้เรียบเกินไป |
| **การเข้ารหัสความถี่** | แทนที่หมวดหมู่ด้วยจำนวนหรือความถี่ | เมื่อความถี่นั้นให้ข้อมูล |
| **การเข้ารหัสแบบไบนารี** | แปลงหมวดหมู่ที่เข้ารหัสจำนวนเต็มเป็นเลขฐานสอง | จำนวนสมาชิกในเซ็ตสูง ลดมิติเทียบกับหนึ่งร้อน |
| **การฝัง** | เรียนรู้การแสดงเวกเตอร์หนาแน่น | จำนวนสมาชิกที่สูงมาก เอ็นแอลพี; ระบบผู้แนะนำ |
| **การเข้ารหัสแฮช** | หมวดหมู่แฮชเป็นจำนวนคุณสมบัติคงที่ | จำนวนสมาชิกที่สูงมาก การเรียนรู้ออนไลน์ |
### คุณสมบัติวันที่และเวลา
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **ชั่วโมงของวัน** | บันทึกรูปแบบรายวัน (ชั่วโมงเร่งด่วน กลางคืน) |
| **วันในสัปดาห์** | เอฟเฟกต์วันธรรมดากับสุดสัปดาห์ |
| **เดือน/ไตรมาส** | รูปแบบตามฤดูกาล |
| **เป็นวันหยุดสุดสัปดาห์** | ธงไบนารีสำหรับสุดสัปดาห์ |
| **เป็นวันหยุด** | ธงไบนารีสำหรับวันหยุดนักขัตฤกษ์ |
| **เวลาตั้งแต่เหตุการณ์** | วันนับจากการซื้อครั้งล่าสุด ชั่วโมงนับตั้งแต่เข้าสู่ระบบครั้งล่าสุด |
| **การเข้ารหัสแบบวนรอบ** | sin(2π × hour / 24), cos(2π × hour / 24) — คงลักษณะวงกลมของเวลา |

## การจัดการกับค่าที่หายไป
| กลยุทธ์ | คำอธิบาย | เมื่อใดควรใช้ |
|----------|-------------|-------------|
| **วางแถว** | ลบแถวที่มีค่าหายไป | ข้อมูลที่หายไปเป็นเพียงเศษเสี้ยวเล็กๆ MCAR (หายไปโดยสิ้นเชิงโดยการสุ่ม) |
| **วางคอลัมน์** | ลบคุณลักษณะที่มีค่าหายไปมากเกินไป | คุณลักษณะส่วนใหญ่หายไป ไม่สำคัญ |
| **การใส่ร้ายเฉลี่ย / ค่ามัธยฐาน** | เติมค่าเฉลี่ยหรือค่ามัธยฐานของจุดสนใจ | เรียบง่าย; คงค่าเฉลี่ยแต่ลดความแปรปรวน |
| **การใส่ร้ายโหมด** | เติมหมวดหมู่ด้วยค่าที่พบบ่อยที่สุด | คุณสมบัติหมวดหมู่ |
| **การใส่ร้าย KNN** | ใช้เพื่อนบ้านที่ใกล้ที่สุด k เพื่อประมาณค่าที่หายไป | เมื่ออินสแตนซ์ที่คล้ายกันช่วยทำนายค่าที่หายไป |
| **การใส่ร้ายตามโมเดล** | ฝึกแบบจำลองเพื่อทำนายค่าที่หายไป | แม่นยำยิ่งขึ้น มีราคาแพงในการคำนวณ |
| **ขาดตัวบ่งชี้** | เพิ่มคอลัมน์ไบนารีที่ตั้งค่าสถานะหายไป | เมื่อความหายนั้นเป็นข้อมูล |
| **การแก้ไข** | เติมค่าที่สอดแทรก (เชิงเส้น, เส้นโค้ง) | อนุกรมเวลา ข้อมูลการสั่งซื้อ |

## การเลือกคุณสมบัติ
### วิธีการกรอง
| วิธีการ | คำอธิบาย |
|--------|-------------|
| **ความสัมพันธ์** | ลบคุณลักษณะที่มีความสัมพันธ์กันอย่างมาก |
| **เกณฑ์ผลต่าง** | ลบคุณลักษณะที่มีความแปรปรวนใกล้ศูนย์ |
| **ข้อมูลร่วมกัน** | ข้อมูลการวัดที่แต่ละคุณสมบัติให้เกี่ยวกับเป้าหมาย |
| **ไคสแควร์** | ทดสอบความเป็นอิสระระหว่างคุณลักษณะตามหมวดหมู่และเป้าหมาย |
| **การทดสอบ ANOVA F** | ทดสอบว่าคุณสมบัติเชิงตัวเลขหมายถึงความแตกต่างระหว่างคลาสเป้าหมาย | หรือไม่
### วิธีการห่อ
| วิธีการ | คำอธิบาย |
|--------|-------------|
| **การเลือกส่งต่อ** | เริ่มว่างเปล่า เพิ่มคุณสมบัติที่ดีที่สุดทีละครั้ง |
| **ตกรอบย้อนหลัง** | เริ่มต้นด้วยทั้งหมด ลบคุณลักษณะที่แย่ที่สุดทีละรายการ |
| **การกำจัดฟีเจอร์แบบเรียกซ้ำ (RFE)** | ฝึกโมเดลซ้ำแล้วซ้ำอีก ลบคุณสมบัติที่สำคัญน้อยที่สุด |
### วิธีการฝังตัว
| วิธีการ | คำอธิบาย |
|--------|-------------|
| **การทำให้เป็นมาตรฐาน L1 (Lasso)** | ย่อน้ำหนักฟีเจอร์ที่ไม่เกี่ยวข้องให้เหลือศูนย์ |
| **ความสำคัญตามต้นไม้** | ใช้ความสำคัญของคุณลักษณะจากแบบจำลองต้นไม้ |
| **ค่า SHAP** | วัดการมีส่วนร่วมของแต่ละฟีเจอร์ต่อการคาดการณ์ |

## วิศวกรรมคุณสมบัติเฉพาะโดเมน
### คุณสมบัติข้อความ
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **TF-IDF** | ความถี่ของภาคเรียนถ่วงน้ำหนักด้วยความถี่ของเอกสารผกผัน |
| **การฝังคำ** | เวกเตอร์หนาแน่นจับความหมายเชิงความหมาย (Word2Vec, GloVe) |
| **อักขระ n-กรัม** | จับรูปแบบคำย่อย มีประโยชน์สำหรับการพิมพ์ผิดและสัณฐานวิทยา |
| **สถิติข้อความ** | ความยาว; จำนวนคำ; การนับประโยค ความยาวคำเฉลี่ย |
| **คะแนนการอ่านค่า** | เฟลช-คินเคด; ดัชนีหมอกปืน |
### คุณสมบัติอนุกรมเวลา
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **คุณสมบัติล่าช้า** | ค่าก่อนหน้า: y(t-1), y(t-7), y(t-30) |
| **สถิติการกลิ้ง** | Mean, std, min, max บนหน้าต่าง |
| **ความแตกต่าง** | y(t) - y(t-1); จับเทรนด์ |
| **ความแตกต่างตามฤดูกาล** | y(t) - y(t-12) สำหรับข้อมูลรายเดือนที่มีฤดูกาลรายปี |
| **เงื่อนไขฟูเรียร์** | คำศัพท์ไซน์และโคไซน์สำหรับรูปแบบตามฤดูกาล |
### คุณสมบัติรูปภาพ (การเรียนรู้ก่อนลึก)
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **HOG** (ฮิสโตแกรมของการไล่ระดับสีเชิง) | การกระจายของทิศทางขอบ |
| **LBP** (รูปแบบไบนารีท้องถิ่น) | คำอธิบายพื้นผิว |
| **SIFT** (การแปลงฟีเจอร์แบบไม่แปรผันตามมาตราส่วน) | คำอธิบายประเด็นสำคัญ |
| **ฮิสโตแกรมสี** | การกระจายสีในภาพ |

## แนวทางปฏิบัติที่ดีที่สุดด้านวิศวกรรมคุณลักษณะ
| การปฏิบัติ | คำอธิบาย |
|----------|-------------|
| **หลีกเลี่ยงข้อมูลรั่วไหล** | อย่าใช้ข้อมูลจากอนาคตหรือชุดทดสอบเพื่อสร้างคุณลักษณะ |
| **เอกสารทุกอย่าง** | บันทึกว่ามีการใช้การแปลงใดบ้าง และเพราะเหตุใด |
| **เวอร์ชันคุณสมบัติของคุณ** | ติดตามการเปลี่ยนแปลงคุณลักษณะควบคู่ไปกับการเปลี่ยนแปลงโมเดล |
| **ตรวจสอบความถูกต้องโดยมีและไม่มี** | ทดสอบว่าฟีเจอร์ใหม่ปรับปรุงประสิทธิภาพของโมเดลจริงหรือไม่ |
| **เก็บไว้ทำซ้ำได้** | ไปป์ไลน์ทางวิศวกรรมที่มีคุณลักษณะควรกำหนดได้และสามารถทำซ้ำได้
| **คุณสมบัติการตรวจสอบดริฟท์** | การกระจายคุณสมบัติอาจมีการเปลี่ยนแปลงเมื่อเวลาผ่านไป ตรวจสอบและฝึกอบรมใหม่ |

## สรุป
วิศวกรรมฟีเจอร์คือจุดที่ความรู้โดเมนมาบรรจบกับแมชชีนเลิร์นนิง เป็นกระบวนการในการแปลงข้อมูลดิบที่ยุ่งเหยิง ไม่สมบูรณ์ มีมิติสูง ให้กลายเป็นการนำเสนอข้อมูลที่สะอาดตาซึ่งโมเดลสามารถเรียนรู้ได้ การแปลงตัวเลขทำให้เกิดความเบ้และมาตราส่วน การเข้ารหัสตามหมวดหมู่จะแปลงป้ายกำกับเป็นโมเดลตัวเลขที่สามารถใช้ได้ คุณสมบัติวันที่จับรูปแบบเวลา กลยุทธ์มูลค่าที่ขาดหายไปจัดการกับข้อมูลที่ไม่สมบูรณ์ การเลือกคุณสมบัติจะขจัดสัญญาณรบกวนและความซ้ำซ้อน วิศวกรฟีเจอร์ที่เก่งที่สุดคิดเหมือนนักสืบ โดยถามว่าสัญญาณใดที่ควรมีอยู่ในข้อมูล สัญญาณเหล่านั้นอาจซ่อนอยู่ที่ไหน และจะแยกสัญญาณออกมาด้วยวิธีที่เที่ยงตรง (ไม่มีข้อมูลรั่วไหล) ทำซ้ำได้ และทนทานต่อการเปลี่ยนแปลงเมื่อเวลาผ่านไป
