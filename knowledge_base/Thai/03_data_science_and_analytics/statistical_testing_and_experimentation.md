# การทดสอบและการทดลองทางสถิติ
สถิติคือไวยากรณ์ของวิทยาศาสตร์ โดยจะให้เครื่องมือแก่คุณในการแยกแยะรูปแบบที่แท้จริงจากสัญญาณรบกวนแบบสุ่ม เพื่อวัดว่าการเปลี่ยนแปลงช่วยปรับปรุงสิ่งต่างๆ จริงหรือไม่ และเพื่อการตัดสินใจภายใต้ความไม่แน่นอน ไฟล์นี้ครอบคลุมแนวคิดหลักของการทดสอบสมมติฐาน การออกแบบการทดลอง และข้อผิดพลาดทั่วไปที่ทำให้ผู้คนสับสน
---

## กรอบการทดสอบสมมติฐาน
การทดสอบทางสถิติทุกครั้งใช้ตรรกะเดียวกัน:
1. **ระบุสมมติฐานว่าง (H₀)**: ไม่มีผลกระทบ / ไม่มีความแตกต่าง
2. **ระบุสมมติฐานทางเลือก (H₁)**: มีผลกระทบ/ความแตกต่าง
3. **เลือกระดับนัยสำคัญ (α)**: ปกติ 0.05 (โอกาส 5% ของผลบวกลวง)
4. **รวบรวมข้อมูลและคำนวณสถิติการทดสอบ**
5. **คำนวณค่า p**: ความน่าจะเป็นที่จะสังเกตผลลัพธ์นี้ (หรือสุดขั้วมากกว่านั้น) หาก H₀ เป็นจริง
6. **ตัดสินใจ**: ถ้า p < α ให้ปฏิเสธ H₀ (มีนัยสำคัญทางสถิติ) มิฉะนั้น ไม่สามารถปฏิเสธ H₀ ได้
### แนวคิดหลัก
| แนวคิด | ความหมาย | ความเข้าใจผิดที่พบบ่อย |
|---------|---------|---------------------|
| **ค่า p** | P(data \| H₀ เป็นจริง) | ไม่ใช่ "ความน่าจะเป็นที่ H₀ เป็นจริง" |
| **α (ระดับนัยสำคัญ)** | เกณฑ์ในการปฏิเสธ H₀ | ไม่ใช่การวัดความสำคัญของเอฟเฟกต์ |
| **นัยสำคัญทางสถิติ** | ผลลัพธ์ไม่น่าเป็นไปได้เนื่องจากโอกาสเพียงอย่างเดียว | ไม่ได้หมายความว่ามีนัยสำคัญในทางปฏิบัติ |
| **ขนาดเอฟเฟกต์** | ขนาดของผลกระทบที่สังเกตได้ | แยกจากค่า p เอฟเฟกต์เล็กๆ อาจมีความสำคัญด้วย N ขนาดใหญ่ |
| **พลัง** | ความน่าจะเป็นที่จะปฏิเสธเท็จ H₀ | ได้อย่างถูกต้อง โดยทั่วไปตั้งเป้าไว้ที่ 80%+ |
| **ช่วงความเชื่อมั่น** | ช่วงของค่าที่เป็นไปได้สำหรับพารามิเตอร์ | CI 95% ไม่ได้หมายความว่า "ความน่าจะเป็น 95% ที่ค่าจริงจะอยู่ในช่วงนี้" |

## ประเภทของข้อผิดพลาด
| | H₀ เป็นจริง | H₀ เป็นเท็จ |
|---|-----------|------------|
| **ปฏิเสธH₀** | ข้อผิดพลาดประเภท I (ผลบวกลวง) | ✅ถูกต้อง (บวกจริง) |
| **ล้มเหลวในการปฏิเสธ H₀** | ✅ ถูกต้อง (ลบจริง) | ข้อผิดพลาด Type II (ลบลวง) |
| ผิดพลาด | สัญลักษณ์ | ความหมาย |
|-------|--------|---------|
| **ประเภทที่ 1** | α | สรุปว่ามีผลเมื่อไม่มี |
| **ประเภท II** | เบต้า | ขาดเอฟเฟคจริง |

## การเลือกแบบทดสอบที่เหมาะสม
| สถานการณ์ | ทดสอบ | สมมติฐาน |
|----------|-|-------------|
| เปรียบเทียบค่าเฉลี่ยของ 2 กลุ่ม | **t-test** (อิสระ) | การแจกแจงแบบปกติ ความแปรปรวนเท่ากัน |
| เปรียบเทียบวิธีการสังเกตแบบคู่ | **จับคู่ที-เทสต์** | โดยทั่วไปจะแจกแจงความแตกต่าง |
| เปรียบเทียบค่าเฉลี่ยของ 3+ กลุ่ม | **ความแปรปรวน** | การแจกแจงแบบปกติ ความแปรปรวนเท่ากัน |
| เปรียบเทียบการแจกแจงตามหมวดหมู่ | **การทดสอบไคสแควร์** | ขนาดตัวอย่างที่เพียงพอต่อเซลล์ |
| เปรียบเทียบการแจกแจง (ไม่ใช่พารามิเตอร์) | **แมนน์-วิทนีย์ ยู** | ไม่มีการสันนิษฐานเรื่องปกติ |
| เปรียบเทียบ 3+ กลุ่ม (ไม่ใช่พารามิเตอร์) | **ครัสคาล-วาลลิส** | ไม่มีการสันนิษฐานเรื่องปกติ |
| ทดสอบความสัมพันธ์ | **Pearson** (เชิงเส้น) หรือ **Spearman** (โมโนโทนิก) | เพียร์สัน: ความปกติ; Spearman: ตามอันดับ |
| ทดสอบว่าข้อมูลเป็นไปตามการแจกแจง | **โคลโมโกรอฟ-สมีร์นอฟ** | ข้อมูลต่อเนื่อง |
### พาราเมตริกกับที่ไม่ใช่พาราเมตริก
| | พาราเมตริก | ไม่ใช่พารามิเตอร์ |
|---|-----------|---------------|
| **สมมติฐาน** | ข้อมูลเป็นไปตามการแจกแจงเฉพาะ (โดยปกติจะเป็นปกติ) | ไม่มีสมมติฐานการกระจาย |
| **พลัง** | สูงขึ้นเมื่อเป็นไปตามสมมติฐาน | ต่ำกว่า แต่แข็งแกร่งกว่า |
| **เมื่อใดควรใช้** | ตัวอย่างขนาดใหญ่ ข้อมูลปกติโดยประมาณ | ตัวอย่างเล็กๆ ข้อมูลเบ้ ข้อมูลลำดับ |

## การทดสอบเฉพาะโดยละเอียด
### t-ทดสอบ
เปรียบเทียบค่าเฉลี่ยของสองกลุ่ม
| ตัวแปร | ใช้กรณี |
|---------|----------|
| **การทดสอบทีอิสระ** | สองกลุ่มที่แยกจากกัน (การรักษา กับ กลุ่มควบคุม) |
| **จับคู่ที-เทสต์** | กลุ่มเดียวกันวัดสองครั้ง (ก่อน vs หลัง) |
| **การทดสอบทีหนึ่งตัวอย่าง** | เปรียบเทียบค่าเฉลี่ยตัวอย่างกับค่าที่ทราบ |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA (การวิเคราะห์ความแปรปรวน)
การเปรียบเทียบหมายถึงกลุ่มตั้งแต่ 3 กลุ่มขึ้นไป ทดสอบว่าค่าเฉลี่ยของกลุ่มอย่างน้อยหนึ่งกลุ่มแตกต่างจากที่เหลือหรือไม่
| พิมพ์ | การออกแบบ |
|------|--------|
| **การวิเคราะห์ความแปรปรวนทางเดียว** | ตัวแปรอิสระหนึ่งตัวที่มี 3+ ระดับ |
| **การวิเคราะห์ความแปรปรวนสองทาง** | ตัวแปรอิสระสองตัว ทดสอบเอฟเฟกต์การโต้ตอบ |
| **มาตรการ ANOVA ซ้ำ** | วิชาเดียวกันวัดภายใต้เงื่อนไขที่ต่างกัน |
หาก ANOVA มีนัยสำคัญ ให้ติดตามผลด้วย **การทดสอบหลังการทดสอบ** (HSD ของ Tukey) เพื่อดูว่ากลุ่มใดแตกต่างกัน
### การทดสอบไคสแควร์
ทดสอบว่าตัวแปรประเภทสองตัวเป็นอิสระต่อกันหรือไม่
| ใช้กรณี | ตัวอย่าง |
|----------|---------|
| **ทดสอบความเป็นอิสระ** | เพศสัมพันธ์กับความชอบในผลิตภัณฑ์หรือไม่? |
| **ความพอดี** | ลูกกลิ้งแม่พิมพ์มีการกระจายตัวสม่ำเสมอหรือไม่ |
**กฎทั่วไป**: แต่ละเซลล์ควรมีจำนวนที่คาดหวังอย่างน้อย 5

## การทดสอบ A/B
การทดสอบ A/B คือการประยุกต์ใช้การทดสอบสมมติฐานกับการตัดสินใจทางธุรกิจ โดยทั่วไปจะเปรียบเทียบการควบคุม (A) กับตัวแปร (B)
### กระบวนการออกแบบ
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. กำหนดสมมติฐาน** | "การเปลี่ยนสีปุ่มจากสีน้ำเงินเป็นสีเขียวจะทำให้อัตราการคลิกผ่านเพิ่มขึ้น" |
| **2. เลือกเมตริก** | หลัก: อัตราการคลิกผ่าน รอง: อัตราการแปลง รายได้ |
| **3. คำนวณขนาดตัวอย่าง** | ขึ้นอยู่กับผลการตรวจจับขั้นต่ำ กำลัง (80%) และนัยสำคัญ (5%) |
| **4. สุ่ม** | สุ่มมอบหมายให้ผู้ใช้ควบคุมและรักษา |
| **5. ดำเนินการทดสอบ** | รวบรวมข้อมูลจนกว่าจะถึงขนาดตัวอย่างเป้าหมาย |
| **6. วิเคราะห์** | เปรียบเทียบตัวชี้วัดโดยใช้การทดสอบทางสถิติที่เหมาะสม |
| **7. ตัดสินใจ** | นำไปใช้หากมีนัยสำคัญทางสถิติและในทางปฏิบัติ |
### การคำนวณขนาดตัวอย่าง
ขนาดตัวอย่างที่คุณต้องการขึ้นอยู่กับ:
| ปัจจัย | ผลกระทบต่อขนาดตัวอย่าง |
|--------|----------------------|
| **เอฟเฟกต์การตรวจจับน้อยลง** | ต้องการตัวอย่างเพิ่มเติม |
| **พลังสูงกว่า** | ต้องการตัวอย่างเพิ่มเติม |
| **ระดับนัยสำคัญต่ำกว่า** | ต้องการตัวอย่างเพิ่มเติม |
| **ความแปรปรวนที่สูงขึ้น** | ต้องการตัวอย่างเพิ่มเติม |
### ข้อผิดพลาดทั่วไปในการทดสอบ A/B
| ความผิดพลาด | ทำไมมันผิด |
|---------|---------------|
| **แอบดูแต่เนิ่นๆ** | การตรวจสอบผลลัพธ์รายวันจะทำให้อัตราผลบวกลวงสูงขึ้น |
| **หลายเมตริกที่ไม่มีการแก้ไข** | การทดสอบ 20 ตัวชี้วัดที่ α=0.05 → คาดว่าจะเกิดผลบวกลวง 1 รายการโดยบังเอิญ |
| **หยุดก่อนถึงเป้า N** | การทดสอบที่มีกำลังต่ำกว่าไม่สามารถตรวจจับเอฟเฟกต์ที่แท้จริงได้ |
| **ไม่สนใจฤดูกาล** | ทำการทดสอบในช่วงวันหยุดเทียบกับสัปดาห์ปกติ |
| **การมอบหมายงานแบบไม่สุ่ม** | อคติในการเลือก (เช่น การกำหนดผู้ใช้ใหม่ให้ทำการรักษา) |
| **สับสนระหว่างความสำคัญกับความสำคัญ** | การเพิ่ม 0.1% อาจมีนัยสำคัญทางสถิติแต่ไม่คุ้มกับการจัดส่ง |

## การเปรียบเทียบหลายรายการ
เมื่อคุณทำการทดสอบหลายครั้งพร้อมกัน โอกาสที่ผลบวกลวงอย่างน้อยหนึ่งครั้งจะเพิ่มขึ้นอย่างมาก
| จำนวนการทดสอบ | ความน่าจะเป็นของ ≥1 ผลบวกลวง (ที่ α=0.05) |
|----------------|--------------------------------------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 40% |
| 20 | 64% |
### การแก้ไข
| วิธีการ | มันทำงานอย่างไร | เมื่อใดควรใช้ |
|--------|-------------|-------------|
| **บอนเฟอโรนี** | หาร α ด้วยจำนวนการทดสอบ (α/n) | ซึ่งอนุรักษ์นิยม; การเปรียบเทียบเล็กน้อย |
| **โฮล์ม-บอนเฟอร์โรนี** | ขั้นตอนการลดขั้นตอน; อนุรักษ์นิยมน้อยกว่า | การใช้งานทั่วไป |
| **เบนจามินิ-ฮอชเบิร์ก (FDR)** | ควบคุมอัตราการค้นพบที่ผิดพลาด | การทดสอบมากมาย การวิเคราะห์เชิงสำรวจ |

## ขนาดเอฟเฟกต์
ค่า P จะบอกคุณ *ว่ามี* เอฟเฟกต์อยู่หรือไม่ ขนาดเอฟเฟกต์จะบอกคุณ*ว่ามันใหญ่แค่ไหน*
| วัด | สำหรับ | การตีความ |
|---------|-----|---------------|
| **โคเฮนส์** | ความแตกต่างระหว่างสองวิธี | 0.2 = เล็ก 0.5 = กลาง 0.8 = ใหญ่ |
| **เพียร์สัน r** | สหสัมพันธ์ | 0.1 = เล็ก 0.3 = กลาง 0.5 = ใหญ่ |
| **η² (เอตา-กำลังสอง)** | การวิเคราะห์ความแปรปรวน | 0.01 = เล็ก 0.06 = ปานกลาง 0.14 = ใหญ่ |
| **อัตราต่อรอง** | ผลลัพธ์เชิงหมวดหมู่ | 1.0 = ไม่มีผลกระทบ; >1 หรือ <1 = เอฟเฟกต์ |
**รายงานขนาดเอฟเฟกต์ควบคู่ไปกับค่า p เสมอ** ผลลัพธ์อาจมีนัยสำคัญทางสถิติแต่ไม่มีความหมายในทางปฏิบัติ

## Bayesian กับ Frequentist
| ด้าน | คนประจำ | แบบเบย์ |
|--------|------------|----------|
| **ความน่าจะเป็น** | ความถี่ของเหตุการณ์ระยะยาว | ระดับความเชื่อ |
| **พารามิเตอร์** | แก้ไขแล้ว แต่ไม่ทราบ | ตัวแปรสุ่มที่มีการแจกแจง |
| **การใช้งาน** | ค่า p ช่วงความเชื่อมั่น การทดสอบสมมติฐาน | การแจกแจงหลัง, ช่วงเวลาที่น่าเชื่อถือ |
| **ก่อนหน้า** | ไม่มีความเชื่อก่อนหน้ารวมอยู่ด้วย | การแจกแจงก่อนหน้าอย่างชัดเจน |
| **การตีความ** | "ถ้าเราทำการทดลองนี้ซ้ำหลายครั้ง..." | "จากข้อมูล ความน่าจะเป็นที่..." |
| **จุดแข็ง** | วัตถุประสงค์ มั่นคง เรียบง่าย | การตีความที่ใช้งานง่ายรวมเอาความรู้เดิม |
| **จุดอ่อน** | ค่า p เข้าใจผิดอย่างกว้างขวาง | การเลือกก่อนหน้าอาจเป็นอัตนัย |

## พื้นฐานการอนุมานเชิงสาเหตุ
ความสัมพันธ์ไม่ใช่สาเหตุ แต่บางครั้งคุณจำเป็นต้องรู้ว่า *ว่า X ทำให้เกิด Y* หรือไม่ ไม่ใช่แค่ว่าสิ่งเหล่านั้นเกี่ยวข้องกันหรือไม่
| วิธีการ | คำอธิบาย | เมื่อใดควรใช้ |
|--------|-------------|-------------|
| **การทดลองแบบสุ่ม** | มาตรฐานทองคำ การสุ่มช่วยขจัดสิ่งรบกวน | เมื่อคุณสามารถสุ่ม |
| **ความแตกต่างในความแตกต่าง (DiD)** | เปรียบเทียบการเปลี่ยนแปลงในช่วงเวลาระหว่างการรักษาและการควบคุม | การเปลี่ยนแปลงนโยบาย การทดลองทางธรรมชาติ |
| **ความไม่ต่อเนื่องของการถดถอย (RDD)** | ใช้ประโยชน์จากเกณฑ์การตัดออก | ทุนการศึกษาเกณฑ์คุณสมบัติ |
| **ตัวแปรเครื่องมือ (IV)** | ใช้เครื่องมือที่ส่งผลต่อการรักษาแต่ไม่ส่งผลโดยตรง | เมื่อไม่สามารถสุ่มได้ |
| **การจับคู่คะแนนความโน้มเอียง** | จับคู่หน่วยที่ได้รับการบำบัดและควบคุมตามคุณลักษณะที่สังเกตได้ | การศึกษาเชิงสังเกต |

## ข้อผิดพลาดทางสถิติทั่วไป
| ความผิดพลาด | คำอธิบาย |
|---------|-------------|
| **พี-แฮ็ค** | ลองวิเคราะห์มาหลายตัวจนเจอ p < 0.05 |
| **ฮาร์คิง** | การตั้งสมมติฐานหลังจากทราบผลลัพธ์แล้ว |
| **อคติในการเอาชีวิตรอด** | มองแต่ความสำเร็จ (เช่น บริษัทที่ประสบความสำเร็จ) |
| **ความขัดแย้งของซิมป์สัน** | แนวโน้มจะกลับตัวเมื่อมีการรวมข้อมูลและแยกตามกลุ่ม |
| **ละเลยอัตราฐาน** | ละเว้นความน่าจะเป็นก่อนหน้าเมื่อตีความผลลัพธ์ |
| **การเข้าใจผิดทางนิเวศวิทยา** | การอนุมานพฤติกรรมส่วนบุคคลจากข้อมูลระดับกลุ่ม |
| **น่าสับสน** | ตัวแปรตัวที่สามอธิบายความสัมพันธ์ที่สังเกตได้ |
| **การโอเวอร์ฟิต** | โมเดลจับสัญญาณรบกวน ไม่ใช่สัญญาณ |

## สรุป
การทดสอบทางสถิติเป็นเรื่องเกี่ยวกับการตัดสินใจภายใต้ความไม่แน่นอนด้วยความซื่อสัตย์ทางปัญญา ระบุสมมติฐานของคุณก่อนรวบรวมข้อมูลเสมอ เลือกการทดสอบที่เหมาะสมสำหรับประเภทข้อมูลของคุณ รายงานขนาดเอฟเฟกต์ ไม่ใช่แค่ค่า p ถูกต้องสำหรับการเปรียบเทียบหลายรายการ และจำไว้ว่า: นัยสำคัญทางสถิติไม่เหมือนกับนัยสำคัญในทางปฏิบัติ
