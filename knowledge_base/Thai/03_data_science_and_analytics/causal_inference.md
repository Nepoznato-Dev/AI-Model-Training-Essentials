# การอนุมานเชิงสาเหตุ
การอนุมานเชิงสาเหตุเป็นศาสตร์ในการพิจารณาว่าสิ่งหนึ่งทำให้เกิดสิ่งอื่นจริงหรือไม่ ไม่ใช่แค่ว่าสิ่งเหล่านั้นมีความสัมพันธ์กันหรือไม่ สหสัมพันธ์จะบอกคุณว่าตัวแปรสองตัวเคลื่อนที่ไปด้วยกัน สาเหตุบอกคุณว่าการเปลี่ยนแปลงอันหนึ่งจะเปลี่ยนอันอื่น ความแตกต่างนี้มีความสำคัญอย่างมากในด้านการแพทย์ (ยานี้ใช้ได้ผลหรือไม่) นโยบาย (การแทรกแซงนี้ช่วยลดความยากจนหรือไม่) ธุรกิจ (แคมเปญโฆษณานี้เพิ่มยอดขายหรือไม่) และวิทยาศาสตร์ (กลไกนี้อธิบายปรากฏการณ์นี้หรือไม่)
---

## ความสัมพันธ์และสาเหตุ
| แนวคิด | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **ความสัมพันธ์** | ตัวแปรสองตัวเคลื่อนที่ไปด้วยกัน | ยอดขายไอศกรีมและผู้เสียชีวิตจากการจมน้ำเพิ่มขึ้นในช่วงฤดูร้อน |
| **สาเหตุ** | ตัวแปรหนึ่งส่งผลโดยตรงต่อ | อีกหนึ่งตัวแปร บุหรี่ทำให้เกิดมะเร็งปอด |
| **น่าสับสน** | ตัวแปรที่สามทำให้ทั้งสอง | อากาศร้อนทั้งขายไอติมและว่ายน้ำ(และจมน้ำ) |
| **สาเหตุย้อนกลับ** | ผลกระทบจริง ๆ แล้วทำให้เกิดสาเหตุที่ควร | คนส่วนใหญ่ซื้ออาหารเสริมเพื่อสุขภาพเพราะป่วย ไม่ใช่อย่างอื่น |
| **ความสัมพันธ์ปลอม** | ความสัมพันธ์บังเอิญ | การบริโภคชีสต่อหัวมีความสัมพันธ์กับการเสียชีวิตจากการพันกันของผ้าปูที่นอน
---

## กรอบผลลัพธ์ที่เป็นไปได้
### โมเดลสาเหตุรูบิน
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **ผลลัพธ์ที่อาจเกิดขึ้น** | สำหรับแต่ละหน่วย จะมีผลหากได้รับการรักษา Y(1) และผลลัพธ์หากไม่ได้รับการรักษา Y(0) |
| **ผลการรักษา** | ความแตกต่าง: Y(1) - Y(0) สำหรับหน่วยที่กำหนด |
| **ปัญหาพื้นฐาน** | เราไม่สามารถสังเกตทั้ง Y(1) และ Y(0) สำหรับหน่วยเดียวกันได้ — เราจะเห็นเพียงหน่วยเดียว |
| **ผลการรักษาโดยเฉลี่ย (ATE)** | ค่าเฉลี่ยของผลการรักษารายบุคคลทั่วทั้งประชากร |
| **ข้อโต้แย้ง** | ผลลัพธ์ที่ไม่มีใครสังเกตเห็น — สิ่งที่จะเกิดขึ้นภายใต้เงื่อนไขอื่น |
### สมมติฐานที่สำคัญ
| อัสสัมชัญ | ความหมาย | วิธีทำให้พอใจ |
|----------|--------|----------------|
| **การเพิกเฉย (ความไม่สับสน)** | การกำหนดการรักษาไม่ขึ้นกับผลลัพธ์ที่อาจเกิดขึ้น เมื่อพิจารณาจากตัวแปรร่วมที่สังเกตได้ การสุ่ม; วัดสิ่งรบกวนทั้งหมด |
| **แง่บวก (ทับซ้อนกัน)** | ทุกหน่วยมีความน่าจะเป็นที่ไม่เป็นศูนย์ที่จะได้รับการรักษาอย่างใดอย่างหนึ่ง | ตรวจสอบการทับซ้อนของตัวแปรร่วมระหว่างกลุ่ม |
| **SUTVA** (สมมติฐานมูลค่าการรักษาหน่วยที่มีเสถียรภาพ) | การรักษาของหน่วยหนึ่งไม่ส่งผลกระทบต่อผลลัพธ์ของอีกหน่วย การรักษามีความสม่ำเสมอ | ไม่มีการรบกวน; ไม่มีการรักษาแบบซ่อนเร้น |
| **ความสม่ำเสมอ** | ผลลัพธ์ที่สังเกตได้เท่ากับผลลัพธ์ที่เป็นไปได้ภายใต้การรักษาที่ได้รับ | การรักษาที่ชัดเจน |

## วิธีการอนุมานเชิงสาเหตุ
### วิธีการทดลอง
| วิธีการ | คำอธิบาย | ความแข็งแกร่ง | ข้อจำกัด |
|----------------------|-------------|----------|------------|
| **การทดลองแบบสุ่มที่มีกลุ่มควบคุม (RCT)** | สุ่มกำหนดหน่วยให้รักษาหรือควบคุม | มาตรฐานทองคำ ขจัดความสับสน | แพง; บางครั้งก็ผิดจรรยาบรรณ ไม่อาจสรุป |
| **การทดสอบ A/B** | RCT ในบริบทของธุรกิจ/เทคโนโลยี | เรียบง่าย; เข้มงวด | ตัวชี้วัดระยะสั้น เอฟเฟกต์แปลกใหม่ การรบกวน |
| **การทดลองสลับกลับ** | ทางเลือกการรักษาตามระยะเวลา | จัดการกับการแทรกแซงในตลาด | ต้องมีสภาพแวดล้อมที่มั่นคง |
### วิธีกึ่งทดลอง
| วิธีการ | คำอธิบาย | สมมติฐานที่สำคัญ |
|--------|-----------------|----------------|
| **ความแตกต่างในความแตกต่าง (DiD)** | เปรียบเทียบการเปลี่ยนแปลงผลลัพธ์ระหว่างกลุ่มที่ได้รับการรักษาและกลุ่มควบคุมในช่วงเวลาหนึ่ง | แนวโน้มคู่ขนาน: กลุ่มต่างๆ คงจะเดินตามวิถีเดียวกันโดยไม่มีการรักษา |
| **ความไม่ต่อเนื่องของการถดถอย (RD)** | เปรียบเทียบหน่วยด้านบนและด้านล่างจุดตัดการรักษา | หน่วยที่อยู่ใกล้จุดตัดจะเทียบเคียงได้ (ราวกับสุ่ม) |
| **ตัวแปรเครื่องมือ (IV)** | ใช้ตัวแปรที่ส่งผลต่อการรักษาแต่ไม่ส่งผลต่อผลลัพธ์ ยกเว้นผ่านการรักษา | เครื่องมือมีความสัมพันธ์กับการรักษา ส่งผลต่อผลลัพธ์ผ่านการรักษาเท่านั้น |
| **การควบคุมแบบสังเคราะห์** | สร้างชุดควบคุมแบบถ่วงน้ำหนักเพื่อให้ตรงกับหน่วยที่ได้รับการบำบัด | การควบคุมแบบสังเคราะห์แสดงถึงข้อโต้แย้งของหน่วยที่ได้รับการบำบัดอย่างแม่นยำ
| **การจับคู่คะแนนความโน้มเอียง** | จับคู่หน่วยบำบัดและควบคุมที่มีความน่าจะเป็นในการรักษาใกล้เคียงกัน | ตัวกวนทั้งหมดจะถูกวัดและรวมไว้ในโมเดลแนวโน้ม |
### ความแตกต่างในความแตกต่าง (มองเห็นได้)
| ระยะเวลา | กลุ่มที่ได้รับการรักษา | กลุ่มควบคุม | ความแตกต่าง |
|--------|--------------|---------------|------------|
| **ก่อนการรักษา** | Y_t_pre | Y_c_pre | Y_t_pre - Y_c_pre |
| **หลังการรักษา** | Y_t_โพสต์ | Y_c_post | Y_t_post - Y_c_post |
| **DiD ประมาณการ** | | | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) |

## กราฟอะไซคลิกกำกับ (DAGs)
DAG เป็นเครื่องมือภาพสำหรับการเข้ารหัสสมมติฐานเชิงสาเหตุและระบุตัวรบกวน
### โครงสร้างพื้นฐาน
| โครงสร้าง | รูปแบบ | นัย |
|----------|---------|-------------|
| **เชน** | ก → ข → ค | A และ C เชื่อมโยงกันผ่าน B; การควบคุม B จะบล็อกเส้นทาง |
| **ส้อม** | ก ← B → C | A และ C ถูก B สับสน; การควบคุม B จะบล็อกเส้นทาง |
| **คอลไลเดอร์** | ก → ข ← ค | A และ C เป็นอิสระจากกัน การควบคุมสำหรับ B จะเปิดเส้นทาง (สร้างการเชื่อมโยงปลอม) |
### กฎสำหรับ DAG
| กฎ | คำอธิบาย |
|-|-------------|
| **เกณฑ์แบ็คดอร์** | เพื่อประเมินผลกระทบเชิงสาเหตุของ X บน Y ให้ปิดกั้นเส้นทางลับๆ ทั้งหมด (เส้นทางที่มีลูกศรชี้ไปที่ X) โดยการปรับเงื่อนไขตามตัวแปรที่เหมาะสม |
| **เกณฑ์ประตูหน้า** | หากไม่สามารถปิดกั้นเส้นทางลับๆ ได้ ให้ใช้ตัวกลาง: ประมาณค่า X → M → Y ในสองขั้นตอน |
| **ไม่มีเงื่อนไขชน** | การควบคุมเอฟเฟกต์ทั่วไปจะเปิดเส้นทางปลอม |
| **ไม่มีเงื่อนไขลูกหลานของผู้ชน** | ปัญหาเดียวกับการปรับสภาพบนตัวชนกันเอง |

## ข้อผิดพลาดทั่วไป
| หลุมพราง | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **ละเว้นอคติของตัวแปร** | ไม่สามารถควบคุมตัวรบกวนได้ | การประมาณการศึกษา → รายได้โดยไม่ต้องควบคุมความสามารถ |
| **ควบคุมมากเกินไป** | การปรับสภาพบนตัวกลางหรือตัวชนกัน | การควบคุมตำแหน่งงานเมื่อประมาณการศึกษา → รายได้ |
| **อคติในการเลือก** | การปรับสภาพตัวแปรที่ได้รับผลกระทบจากการรักษา | วิเคราะห์เฉพาะคนมีงานทำตอนเรียนอบรม → ค่าจ้าง |
| **อคติเวลาอมตะ** | การจัดประเภทเวลาบุคคลผิดในการศึกษาตามรุ่น | คนไข้ต้องอยู่รอดได้นานพอที่จะรับการรักษา |
| **การถดถอยสู่ค่าเฉลี่ย** | ค่าสุดขั้วมีแนวโน้มที่จะเคลื่อนไปทางค่าเฉลี่ย | คนไข้อาการดีขึ้นหลังการรักษาโดยไม่คำนึงถึง |
| **อคติหลังการรักษา** | การปรับสภาพตัวแปรที่เกิดขึ้นหลังการรักษา | การควบคุมเหตุการณ์ไม่พึงประสงค์เมื่อประเมินประสิทธิภาพของยา |

## สรุป
การอนุมานเชิงสาเหตุเป็นเรื่องเกี่ยวกับการย้ายจาก "สิ่งที่เกิดขึ้น" ไปเป็น "สิ่งที่จะเกิดขึ้นหากสิ่งต่าง ๆ แตกต่างออกไป" ความท้าทายพื้นฐานคือเราไม่สามารถสังเกตทั้งผลลัพธ์ที่ได้รับและไม่ได้รับการรักษาในหน่วยเดียวกันได้ เนื่องจากข้อเท็จจริงที่ขัดแย้งจะขาดหายไปอยู่เสมอ การทดลองแบบสุ่มช่วยแก้ปัญหานี้โดยการเปรียบเทียบกลุ่มการรักษาและกลุ่มควบคุม เมื่อไม่สามารถสุ่มได้ วิธีการทดลองกึ่งทดลอง เช่น DiD ความไม่ต่อเนื่องของการถดถอย ตัวแปรเครื่องมือ การควบคุมแบบสังเคราะห์ พยายามสร้างข้อเท็จจริงที่โต้แย้งขึ้นมาใหม่จากข้อมูลเชิงสังเกต DAG ช่วยให้สมมติฐานชัดเจนและระบุตัวแปรที่เหมาะสมในการควบคุม ทักษะหลักคือการคิดอย่างรอบคอบเกี่ยวกับกระบวนการสร้างข้อมูล อะไรเป็นสาเหตุ อะไรเป็นตัวรบกวน อะไรเป็นตัวชน และสิ่งที่จะเกิดขึ้นภายใต้ทางเลือกอื่น
