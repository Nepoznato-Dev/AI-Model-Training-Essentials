# วิทยาศาสตร์ข้อมูลและการวิเคราะห์

## แนวคิดหลัก

### วิทยาศาสตร์ข้อมูลคืออะไร?
วิทยาศาสตร์ข้อมูลเป็นสาขาวิชาสหวิทยาการที่ใช้วิธีการทางวิทยาศาสตร์ กระบวนการ อัลกอริทึม และระบบเพื่อดึงความรู้และข้อมูลเชิงลึกจากข้อมูลที่มีโครงสร้างและไม่มีโครงสร้าง ประกอบด้วย:
- **สถิติ**: พื้นฐานทางคณิตศาสตร์สำหรับการวิเคราะห์
- **วิทยาการคอมพิวเตอร์**: การเขียนโปรแกรม อัลกอริทึม โครงสร้างข้อมูล
- **ความเชี่ยวชาญเฉพาะด้าน**: ความรู้ในหัวข้อนั้นๆ
- **การแสดงภาพข้อมูล**: การสื่อสารผลการค้นพบอย่างมีประสิทธิภาพ

### ประเภทของข้อมูล
- **ข้อมูลที่มีโครงสร้าง**: จัดระเบียบเป็นแถว/คอลัมน์ (ฐานข้อมูล สเปรดชีต)
- **ข้อมูลที่ไม่มีโครงสร้าง**: ไม่มีรูปแบบที่กำหนดไว้ล่วงหน้า (ข้อความ รูปภาพ เสียง วิดีโอ)
- **ข้อมูลกึ่งโครงสร้าง**: มีการจัดระเบียบบ้างแต่ไม่เข้มงวด (JSON, XML, HTML)
- **ข้อมูลอนุกรมเวลา**: จุดข้อมูลเรียงตามลำดับที่จัดทำดัชนีตามลำดับเวลา
- **ข้อมูลเชิงพื้นที่**: ข้อมูลทางภูมิศาสตร์/ตำแหน่ง
- **ข้อมูลกราฟ**: โหนดและเส้นที่แสดงความสัมพันธ์

### กระบวนการวิทยาศาสตร์ข้อมูล (CRISP-DM)
1. **ความเข้าใจธุรกิจ**: กำหนดวัตถุประสงค์และความต้องการ
2. **ความเข้าใจข้อมูล**: รวบรวมและสำรวจข้อมูลเริ่มต้น
3. **การเตรียมข้อมูล**: ทำความสะอาด แปลงรูปแบบ และจัดรูปแบบข้อมูล (80% ของงาน)
4. **การสร้างแบบจำลอง**: เลือกและใช้เทคนิคการสร้างแบบจำลอง
5. **การประเมิน**: ประเมินประสิทธิภาพของโมเดลเทียบกับวัตถุประสงค์
6. **การนำไปใช้**: นำโมเดลไปใช้ในสภาพแวดล้อมการผลิต

## พื้นฐานสถิติ

### สถิติเชิงพรรณนา
- **มาตรวัดแนวโน้มเข้าสู่ส่วนกลาง**: ค่าเฉลี่ย มัธยฐาน ฐานนิยม
- **มาตรวัดการกระจาย**: พิสัย ความแปรปรวน ส่วนเบี่ยงเบนมาตรฐาน พิสัยระหว่างควอไทล์
- **รูปร่างของการแจกแจง**: ความเบ้ (ความไม่สมมาตร) ความโด่ง (หาง)
- **เปอร์เซ็นไทล์และควอไทล์**: ตำแหน่งภายใน การแจกแจง

### สถิติเชิงอนุมาน
- **การทดสอบสมมติฐาน**: สมมติฐานว่าง สมมติฐานทางเลือก ค่า p
- **ช่วงความเชื่อมั่น**: ช่วงของค่าที่มีแนวโน้มว่าจะมีพารามิเตอร์ของประชากร
- **นัยสำคัญทางสถิติ**: ความน่าจะเป็นที่ผลลัพธ์เกิดขึ้นโดยบังเอิญ
- **ข้อผิดพลาดประเภท I**: บวกปลอม (ปฏิเสธสมมติฐานว่างที่เป็นจริง)
- **ข้อผิดพลาดประเภท II**: ลบปลอม (ไม่สามารถปฏิเสธสมมติฐานว่างที่เป็นเท็จ)
- **พลังทางสถิติ**: ความน่าจะเป็นที่จะปฏิเสธสมมติฐานว่างที่เป็นเท็จได้อย่างถูกต้อง

### การแจกแจงความน่าจะเป็น
- **การแจกแจงปกติ**: เส้นโค้งระฆัง ค่าเฉลี่ย = มัธยฐาน = ฐานนิยม
- **การแจกแจงทวินาม**: ผลลัพธ์สำเร็จ/ล้มเหลว
- **การแจกแจงปัวซอง**: จำนวนเหตุการณ์ในช่วงเวลาที่กำหนด
- **การแจกแจงสม่ำเสมอ**: ทุกผลลัพธ์มีโอกาสเท่าเทียมกัน
- **การแจกแจงเอกซ์โพเนนเชียล**: เวลาระหว่างเหตุการณ์
- **การแจกแจง t**: ตัวอย่างขนาดเล็ก ความแปรปรวนของประชากรไม่ทราบ
- **การแจกแจงไคสแควร์**: การวิเคราะห์ข้อมูลเชิงหมวดหมู่

### การทดสอบทางสถิติ
- **การทดสอบ t**: เปรียบเทียบค่าเฉลี่ยระหว่างสองกลุ่ม
- **ANOVA**: เปรียบเทียบค่าเฉลี่ย across หลายกลุ่ม
- **การทดสอบไคสแควร์**: ทดสอบความเป็นอิสระของตัวแปรเชิงหมวดหมู่
- **Mann-Whitney U**: ทางเลือกที่ไม่ใช้พารามิเตอร์สำหรับการทดสอบ t
- **สหสัมพันธ์เพียร์สัน**: ความสัมพันธ์เชิงเส้นระหว่างตัวแปรต่อเนื่อง
- **สหสัมพันธ์สเปียร์แมน**: ความสัมพันธ์แบบโมโนโทนิก (อิงอันดับ)
- **Kolmogorov-Smirnov**: เปรียบเทียบการแจกแจง

## การรวบรวมและการจัดเก็บข้อมูล

### แหล่งข้อมูล
- **ฐานข้อมูล**: SQL, NoSQL, เชิงสัมพันธ์, ที่เก็บเอกสาร
- **API**: REST, GraphQL, การขูดเว็บ
- **ไฟล์**: CSV, JSON, XML, Parquet, Avro
- **ข้อมูลสตรีมมิ่ง**: Kafka, Kinesis, ฟีดแบบเรียลไทม์
- **การสำรวจและการทดลอง**: การรวบรวมข้อมูลปฐมภูมิ
- **ชุดข้อมูลสาธารณะ**: ข้อมูลรัฐบาล, Kaggle, ที่เก็บข้อมูลทางวิชาการ

### คลังข้อมูล
- **ETL**: กระบวนการ Extract, Transform, Load
- **Data Lake**: ที่เก็บข้อมูลดิบในรูปแบบดั้งเดิม
- **Data Warehouse**: ข้อมูลที่มีโครงสร้างและผ่านการประมวลผลสำหรับการวิเคราะห์
- **Data Mart**: ส่วนย่อยของคลังข้อมูลสำหรับแผนกเฉพาะ
- **OLAP**: Online Analytical Processing, คำค้นหาหลายมิติ
- **Star Schema**: ตารางความจริงล้อมรอบด้วยตารางมิติ
- **Snowflake Schema**: ตารางมิติที่ทำให้เป็นมาตรฐาน

### ประเภทของฐานข้อมูล
- **เชิงสัมพันธ์ (SQL)**: MySQL, PostgreSQL, Oracle, SQL Server
- **เอกสาร**: MongoDB, CouchDB (เอกสารคล้าย JSON)
- **คีย์-ค่า**: Redis, DynamoDB (คู่คีย์-ค่าอย่างง่าย)
- **คอลัมน์**: Cassandra, HBase (เหมาะสำหรับคอลัมน์)
- **กราฟ**: Neo4j, Amazon Neptune (โหนดและความสัมพันธ์)
- **อนุกรมเวลา**: InfluxDB, TimescaleDB (ข้อมูลที่มี timestamp)
- **เวกเตอร์**: Pinecone, Milvus (ที่เก็บ embedding สำหรับ ML)

## การประมวลผลข้อมูลเบื้องต้น

### การทำความสะอาดข้อมูล
- **ค่าที่หายไป**: การเติมค่า (ค่าเฉลี่ย มัธยฐาน ฐานนิยม การทำนาย) การลบ
- **ค่าผิดปกติ**: การตรวจจับ (IQR, คะแนน Z) การรักษา (การจำกัด การแปลง)
- **ข้อมูลซ้ำ**: การระบุและการลบ
- **ความไม่สอดคล้อง**: การมาตรฐานรูปแบบ การแก้ไขข้อผิดพลาดในการพิมพ์
- **การตรวจสอบความถูกต้องของข้อมูล**: การตรวจสอบข้อจำกัด ช่วง ประเภท

### การแปลงข้อมูล
- **การปรับให้เป็นมาตรฐาน**: การปรับขนาดให้อยู่ในช่วง 0-1
- **การมาตรฐาน**: การปรับมาตรฐาน Z-score (ค่าเฉลี่ย=0, ส่วนเบี่ยงเบนมาตรฐาน=1)
- **การเข้ารหัส**: One-hot, label, ordinal, target encoding
- **การแบ่งถัง**: การจัดกลุ่มค่าต่อเนื่องเป็นหมวดหมู่
- **การแปลงลอการิทึม**: ลดความเบ้
- **การปรับขนาดฟีเจอร์**: ทำให้ฟีเจอร์สามารถเปรียบเทียบได้

### วิศวกรรมฟีเจอร์
- **การสร้างฟีเจอร์**: การได้มาซึ่งฟีเจอร์ใหม่จากฟีเจอร์ที่มีอยู่
- **การเลือกฟีเจอร์**: เลือกฟีเจอร์ที่เกี่ยวข้องมากที่สุด
  - วิธีการกรอง (สหสัมพันธ์ ไคสแควร์)
  - วิธีการห่อหุ้ม (การกำจัดฟีเจอร์แบบเรียกซ้ำ)
  - วิธีการฝังตัว (LASSO, ความสำคัญตามต้นไม้)
- **การลดมิติ**: PCA, t-SNE, UMAP
- **เทอมปฏิสัมพันธ์**: การรวมฟีเจอร์แบบคูณ
- **ฟีเจอร์พหุนาม**: การสร้างเทอมลำดับสูงกว่า

## การวิเคราะห์ข้อมูลเชิงสำรวจ (EDA)

### เทคนิค EDA
- **สถิติสรุป**: อธิบายแนวโน้มเข้าสู่ส่วนกลาง การกระจาย รูปร่าง
- **การวิเคราะห์ตัวแปรเดียว**: การแจกแจงของตัวแปรเดียว
- **การวิเคราะห์สองตัวแปร**: ความสัมพันธ์ระหว่างสองตัวแปร
- **การวิเคราะห์หลายตัวแปร**: ปฏิสัมพันธ์ของหลายตัวแปร
- **การวิเคราะห์สหสัมพันธ์**: ระบุความสัมพันธ์และ multicollinearity
- **การแบ่งส่วน**: การจัดกลุ่มการสังเกตที่คล้ายกัน

### เครื่องมือการแสดงภาพ
- **ฮิสโตแกรม**: การแจกแจงของตัวแปรเดียว
- **Box Plot**: สรุปห้าตัวเลข การตรวจจับค่าผิดปกติ
- **Scatter Plot**: ความสัมพันธ์ระหว่างสองตัวแปรต่อเนื่อง
- **Heatmap**: เมทริกซ์สหสัมพันธ์ ความหนาแน่น
- **แผนภูมิแท่ง**: การเปรียบเทียบเชิงหมวดหมู่
- **แผนภูมิเส้น**: แนวโน้มตลอดเวลา
- **Violin Plot**: ความหนาแน่นของการแจกแจงพร้อมองค์ประกอบ box plot
- **Pair Plot**: Scatter plot หลายรายการสำหรับคู่ตัวแปร

### ไลบรารี Python สำหรับ EDA
- **pandas**: การจัดการและการวิเคราะห์ข้อมูล
- **numpy**: การคำนวณเชิงตัวเลข
- **matplotlib**: การพล็อตพื้นฐาน
- **seaborn**: การแสดงภาพทางสถิติ
- **plotly**: การแสดงภาพแบบโต้ตอบ
- **scipy**: การคำนวณทางวิทยาศาสตร์และสถิติ

## Machine Learning ในวิทยาศาสตร์ข้อมูล

### การเรียนรู้ภายใต้การดูแล
- **การถดถอย**: ทำนายค่าต่อเนื่อง
  - การถดถอยเชิงเส้น
  - การถดถอยพหุนาม
  - Ridge/LASSO/Elastic Net
  - Decision Tree Regressor
  - Random Forest Regressor
  - Gradient Boosting (XGBoost, LightGBM, CatBoost)

- **การจำแนกประเภท**: ทำนายป้ายกำกับเชิงหมวดหมู่
  - การถดถอยโลจิสติก
  - k-Nearest Neighbors
  - Naive Bayes
  - Support Vector Machines
  - Decision Trees
  - Random Forest
  - Gradient Boosting
  - Neural Networks

### การเรียนรู้ بدونการดูแล
- **การจัดกลุ่ม**: จัดกลุ่มการสังเกตที่คล้ายกัน
  - k-Means
  - Hierarchical Clustering
  - DBSCAN (อิงความหนาแน่น)
  - Gaussian Mixture Models
  - Spectral Clustering

- **การลดมิติ**: ลดจำนวนฟีเจอร์
  - Principal Component Analysis (PCA)
  - t-Distributed Stochastic Neighbor Embedding (t-SNE)
  - Uniform Manifold Approximation (UMAP)
  - Autoencoder

- **กฎความสัมพันธ์**: ค้นหารายการที่เกิดขึ้นร่วมกัน
  - อัลกอริทึม Apriori
  - FP-Growth

### การประเมินโมเดล
- **เมตริกการจำแนกประเภท**: ความแม่นยำ ความแม่นยำ Recall, F1-score, ROC-AUC, confusion matrix
- **เมตริกการถดถอย**: MAE, MSE, RMSE, R², Adjusted R²
- **Cross-Validation**: k-fold, stratified, leave-one-out, time series split
- **การปรับ Hyperparameter**: Grid search, random search, การเพิ่มประสิทธิภาพแบบเบย์
- **Learning Curves**: วินิจฉัย tradeoff bias-variance

- **Apache Hadoop**: MapReduce, HDFS (Hadoop Distributed File System)

### แพลตฟอร์มคลาวด์
- **AWS**: S3, EMR, Redshift, SageMaker, Glue
- **Google Cloud**: BigQuery, Dataproc, AI Platform, Cloud Storage
- **Azure**: Synapse Analytics, Databricks, Machine Learning, Data Lake
- **Snowflake**: คลังข้อมูลบนคลาวด์

### เครื่องมือ Pipeline ข้อมูล

- **รักษาความสอดคล้อง**: มาตรฐานรูปแบบและมาตราส่วน
- **เปิดใช้งานการโต้ตอบ**: ตัวกรอง drill-downs tooltip
- **เพิ่มประสิทธิภาพ**: การโหลดเร็ว คำค้นหาที่มีประสิทธิภาพ
- ** consideration มือถือ**: การออกแบบที่ตอบสนอง

### Key Performance Indicators (KPI)
- **การเงิน**: รายได้ อัตรากำไร ROI, customer lifetime value
- **ลูกค้า**: ต้นทุนการได้มา อัตราการยกเลิก คะแนนความพึงพอใจ NPS
- **การดำเนินงาน**: อัตราประสิทธิภาพ เวลาในรอบวงจร อัตราข้อบกพร่อง
- **การตลาด**: อัตราการ конверต์ click-through rates การ атрибуติ
- **ผลิตภัณฑ์**: ผู้ใช้ที่ใช้งานอยู่ การมีส่วนร่วม การรักษาลูกค้า การนำฟีเจอร์ไปใช้

## การวิเคราะห์ขั้นสูง

### การวิเคราะห์เชิงคาดการณ์
- **การพยากรณ์**: การทำนายอนุกรมเวลา (ARIMA, Prophet, LSTM)
- **การสร้างแบบจำลองความเสี่ยง**: การให้คะแนนเครดิต การตรวจจับการฉ้อโกง การประกันภัย
- **การวิเคราะห์ลูกค้า**: การทำนายการยกเลิก โมเดลความโน้มเอียง
- **การพยากรณ์ความต้องการ**: การเพิ่มประสิทธิภาพสินค้าคงคลัง ห่วงโซ่อุปทาน
- **การพยากรณ์การบำรุงรักษา**: การคาดการณ์ความล้มเหลวของอุปกรณ์

### การวิเคราะห์เชิงกำหนด
- **การเพิ่มประสิทธิภาพ**: การเขียนโปรแกรมเชิงเส้น การเขียนโปรแกรมจำนวนเต็ม
- **การจำลอง**: วิธีการ Monte Carlo การจำลองเหตุการณ์ไม่ต่อเนื่อง
- **การวิเคราะห์การตัดสินใจ**: ต้นไม้การตัดสินใจ แผนภาพอิทธิพล
- **การทดสอบ A/B**: การออกแบบการทดลอง นัยสำคัญทางสถิติ
- **Multi-Armed Bandits**: การทดลองแบบปรับตัว

### Text Analytics (NLP)
- **การประมวลผลข้อความเบื้องต้น**: Tokenization, stemming, lemmatization
- **การวิเคราะห์ความรู้สึก**: การจำแนกประเภท บวก/ลบ/กลาง
- **การสร้างแบบจำลองหัวข้อ**: LDA, NMF สำหรับการค้นพบหัวข้อ
- **Named Entity Recognition**: การระบุบุคคล สถานที่ องค์กร
- **การจำแนกประเภทข้อความ**: การตรวจจับสแปม การ categorize
- **Word Embeddings**: Word2Vec, GloVe, BERT

## จริยธรรมและการกำกับดูแลข้อมูล

### ความเป็นส่วนตัวของข้อมูล
- **GDPR**: ข้อบังคับทั่วไปว่าด้วยการคุ้มครองข้อมูลของสหภาพยุโรป
- **CCPA**: กฎหมายความเป็นส่วนตัวของผู้บริโภคแคลิฟอร์เนีย
- **HIPAA**: กฎหมายความสามารถในการพกพาและความรับผิดชอบด้านประกันสุขภาพ (การดูแลสุขภาพสหรัฐฯ)
- **การทำให้ไม่ระบุชื่อ**: การลบข้อมูลที่ระบุตัวตนได้
- **ความเป็นส่วนตัวแบบดิฟเฟอเรนเชียล**: การเพิ่มเสียงรบกวนเพื่อปกป้องบุคคล
- **การจัดการความยินยอม**: กลไก opt-in/opt-out

### คุณภาพข้อมูล
- **ความถูกต้อง**: ความถูกต้องของข้อมูล
- **ความสมบูรณ์**: ข้อมูลที่ต้องการทั้งหมดมีอยู่
- **ความสอดคล้อง**: ไม่มีความขัดแย้ง across แหล่งที่มา
- **ความทันเวลา**: ข้อมูลมี sẵnเมื่อต้องการ
- **ความถูกต้อง**: เป็นไปตามกฎที่กำหนด
- **ความเป็นเอกลักษณ์**: ไม่มีข้อมูลซ้ำ

### อคติและความยุติธรรม
- **อคติการสุ่มตัวอย่าง**: การรวบรวมข้อมูลที่ไม่เป็นตัวแทน
- **อคติการวัด**: เครื่องมือรวบรวมข้อมูลที่มีข้อบกพร่อง
- **อคติของอัลกอริทึม**: การทำนายที่เลือกปฏิบัติของโมเดล
- **เมตริกความยุติธรรม**: ความเท่าเทียมทางประชากร โอกาสที่เท่าเทียม
- **การลดอคติ**: Pre-processing, in-processing, post-processing

### กรอบการกำกับดูแลข้อมูล
- **Data Stewardship**: ความรับผิดชอบสำหรับสินทรัพย์ข้อมูล
- **การจัดการ Metadata**: เอกสารข้อมูลเกี่ยวกับข้อมูล
- **Data Lineage**: การติดตามการไหลและการแปลงข้อมูล
- **การควบคุมการเข้าถึง**: การอนุญาตตามบทบาท
- **Audit Trails**: การบันทึกการเข้าถึงและการเปลี่ยนแปลงข้อมูล
- **การปฏิบัติตาม**: การปฏิบัติตามกฎระเบียบ

## เส้นทางอาชีพในวิทยาศาสตร์ข้อมูล

### บทบาท
- **นักวิเคราะห์ข้อมูล**: มุ่งเน้นการวิเคราะห์เชิงพรรณนา dashboard การรายงาน
- **นักวิทยาศาสตร์ข้อมูล**: การสร้างแบบจำลองทางสถิติ machine learning การวิเคราะห์ขั้นสูง
- **ML Engineer**: ระบบ ML ในการผลิต การ deploy โมเดล MLOps
- **Data Engineer**: Pipeline ข้อมูล โครงสร้างพื้นฐาน กระบวนการ ETL
- **Analytics Manager**: ความเป็นผู้นำของทีม กลยุทธ์ การจัดการผู้มีส่วนได้ส่วนเสีย
- **BI Developer**: การสร้าง dashboard การพัฒนารายงาน
- **Research Scientist**: อัลกอริทึมใหม่ สิ่งตีพิมพ์ การวิจัยขั้นสูง

### เมทริกซ์ทักษะ
- **ด้านเทคนิค**: Python/R, SQL, สถิติ, framework ML, แพลตฟอร์มคลาวด์
- **การวิเคราะห์**: การแก้ปัญหา การคิดเชิงวิพากษ์ การออกแบบการทดลอง
- **การสื่อสาร**: การเล่าเรื่อง การแสดงภาพ ทักษะการนำเสนอ
- **ธุรกิจ**: ความรู้ด้านโดเมน การจัดการผู้มีส่วนได้ส่วนเสีย การวิเคราะห์ ROI
- **เครื่องมือ**: Git, Jupyter, Docker, CI/CD, version control สำหรับโมเดล

## แนวโน้มที่เกิดขึ้นใหม่

### การพัฒนาล่าสุด
- **AutoML**: การสร้าง pipeline machine learning อัตโนมัติ
- **MLOps**: แนวปฏิบัติ DevOps สำหรับ machine learning
- **Feature Stores**: การจัดการฟีเจอร์แบบรวมศูนย์
- **Data Mesh**: สถาปัตยกรรมข้อมูลแบบกระจายอำนาจ
- **LLM และ AI สร้างสรรค์**: โมเดลภาษาขนาดใหญ่ การสร้างเนื้อหา
- **Edge Analytics**: การประมวลผลข้อมูลที่อุปกรณ์ต้นทาง
- **การวิเคราะห์แบบเรียลไทม์**: การวิเคราะห์ข้อมูลสตรีมมิ่ง
- **Augmented Analytics**: การเตรียมข้อมูลและข้อมูลเชิงลึกที่ช่วยโดย AI

### ทิศทางในอนาคต
- **Quantum Machine Learning**: การคำนวณควอนตัมสำหรับ ML
- **Federated Learning**: การฝึกโมเดลบนข้อมูลแบบกระจาย
- **Causal Inference**: ก้าวข้ามความสัมพันธ์ไปสู่ความเป็นเหตุผล
- **AI ที่มีความรับผิดชอบ**: จริยธรรม ความสามารถในการอธิบาย ความโปร่งใส
- **Data Fabric**: การจัดการข้อมูลแบบบูรณาการ across สภาพแวดล้อม
