## ระบบสุริยะ
ระบบสุริยะคือดวงอาทิตย์และทุกสิ่งที่โคจรรอบดวงอาทิตย์ ได้แก่ ดาวเคราะห์ 8 ดวง ดาวเคราะห์แคระ ดวงจันทร์ ดาวเคราะห์น้อย ดาวหาง และฝุ่น
| ดาวเคราะห์ | ระยะทางจากดวงอาทิตย์ | คุณสมบัติที่สำคัญ | ข้อเท็จจริงที่น่าสังเกต |
|--------|------------------|-------------|-------------|
| **สารปรอท** | 58 ล้านกม. | ดาวเคราะห์ที่เล็กที่สุด ไม่มีบรรยากาศ | อุณหภูมิแกว่งตั้งแต่ −180°C ถึง 430°C |
| **วีนัส** | 108 ล้านกม. | บรรยากาศเป็นพิษหนา | ดาวเคราะห์ที่ร้อนที่สุด (~465°C) เนื่องจากปรากฏการณ์เรือนกระจกที่ควบคุมไม่ได้ |
| **โลก** | 150 ล้านกม. | น้ำของเหลว ชีวิต | ดาวเคราะห์ดวงเดียวที่รู้จักสิ่งมีชีวิต |
| **ดาวอังคาร** | 228 ล้านกม. | สีแดง (พื้นผิวเหล็กออกไซด์) | ภูเขาไฟที่ใหญ่ที่สุดในระบบสุริยะ (Olympus Mons) |
| **ดาวพฤหัสบดี** | 778 ล้านกม. | ดาวเคราะห์ที่ใหญ่ที่สุด | มวลมีมากกว่าดาวเคราะห์ดวงอื่นทั้งหมดรวมกัน พายุจุดแดงใหญ่ |
| **ดาวเสาร์** | 1.4 พันล้านกม. | ระบบวงแหวนสุดอลังการ | วงแหวนที่ทำจากน้ำแข็งและอนุภาคหิน |
| **ดาวยูเรนัส** | 2.9 พันล้านกม. | หมุนไปด้านข้าง | ฤดูกาลสุดขั้ว แต่ละเสาได้รับแสงแดดต่อเนื่องนาน 42 ปี |
| **ดาวเนปจูน** | 4.5 พันล้านกม. | ดาวเคราะห์ที่อยู่ไกลที่สุด | ลมแรงที่สุดในระบบสุริยะ (~2,100 กม./ชม.) |
ดวงอาทิตย์เป็นดาวฤกษ์ขนาดกลางที่แปลงไฮโดรเจน 600 ล้านตันให้เป็นฮีเลียมทุก ๆ วินาทีผ่านนิวเคลียร์ฟิวชัน มีอายุประมาณ 4.6 พันล้านปี และมีอายุประมาณครึ่งหนึ่งของชีวิต

### ห้ามหาสมุทร
แปซิฟิกเป็นมหาสมุทรที่ใหญ่ที่สุด (ครอบคลุมพื้นที่มากกว่าที่ดินทั้งหมดรวมกัน) มหาสมุทรแอตแลนติกแยกอเมริกาออกจากยุโรปและแอฟริกา มหาสมุทรอินเดียมีอากาศอบอุ่นที่สุด มหาสมุทรทางใต้ล้อมรอบทวีปแอนตาร์กติกา มหาสมุทรอาร์กติกมีขนาดเล็กที่สุดและตื้นที่สุด
ความลึกของมหาสมุทรเฉลี่ย: ~3,688 เมตร จุดที่ลึกที่สุดคือร่องลึกบาดาลมาเรียนา ที่ระดับประมาณ 11,000 เมตร หากคุณทิ้งภูเขาเอเวอเรสต์ลงไป ก็จะมีน้ำอยู่เหนือนั้นยาวกว่าหนึ่งไมล์

## ร่างกายมนุษย์
ร่างกายมนุษย์เป็นเครื่องจักรที่มีความซับซ้อนอย่างมาก และส่วนใหญ่ทำงานโดยไม่ได้รับข้อมูลจากคุณโดยไม่รู้ตัว
| ระบบ | หมายเลขสำคัญ | มันทำอะไร |
|--------|------------|-------------|
| **เซลล์** | ~37 ล้านล้าน | โครงสร้างพื้นฐาน ประเภทต่างๆ สำหรับงานที่แตกต่างกัน |
| **กระดูก** | 206 (ผู้ใหญ่) | โครงสร้าง การป้องกัน การสร้างเม็ดเลือด |
| **เซลล์ประสาท** | ~86 พันล้าน (สมอง) | ประมวลผลและส่งข้อมูล |
| **หลอดเลือด** | รวม ~100,000 กม. | หากวางแบบต่อจนจบ พวกมันจะโคจรรอบโลก 2.5 เท่า |
| **ปริมาณน้ำ** | ~60% ของน้ำหนักตัว | ปฏิกิริยาเคมีทุกอย่างในร่างกายของคุณเกิดขึ้นในน้ำ |
| **หัวใจ** | ~100,000 ครั้ง/วัน | สูบฉีดเลือดได้ ~7,500 ลิตรต่อวัน |
| **ปอด** | ~480 ล้านถุงลม | พื้นที่ผิวประมาณขนาดสนามเทนนิส |
**กระดูก**: ยาวที่สุดคือกระดูกโคนขา (กระดูกต้นขา) ที่เล็กที่สุดคือลวดเย็บในหู (3 มม.) ทารกมีกระดูกประมาณ 300 ชิ้น หลอมรวมเข้าด้วยกันเมื่อคุณเติบโต
**สมอง**: ใช้พลังงานประมาณ 20% ของร่างกายของคุณแม้จะเป็นเพียง 2% ของน้ำหนักของคุณก็ตาม สามารถประมวลผลข้อมูลภาพได้ภายในเวลาเพียง 13 มิลลิวินาที

## น้ำ — โมเลกุลที่ทำให้ชีวิตเป็นไปได้
น้ำ (H₂O) เป็นเรื่องแปลก มันจะขยายตัวเมื่อมันแข็งตัว (ซึ่งเป็นเหตุให้น้ำแข็งลอยได้ ซึ่งถือเป็นเรื่องผิดปกติสำหรับของแข็ง) มีความจุความร้อนสูง (ซึ่งเป็นเหตุให้เมืองชายฝั่งทะเลมีสภาพอากาศอบอุ่นน้อยกว่า) เป็นตัวทำละลายที่ดีเยี่ยม (ซึ่งเป็นสาเหตุที่ทำให้สารอาหารผ่านร่างกายของคุณ)
| คุณสมบัติ | ค่า |
|----------|-------|
| จุดเยือกแข็ง | 0°C (32°F) |
| จุดเดือด | 100°C (212°F) ที่ระดับน้ำทะเล |
| % ของน้ำในโลกที่เป็นน้ำเค็ม | ~97.5% |
| %ที่เป็นน้ำจืด | ~2.5% (ส่วนใหญ่ติดอยู่ในน้ำแข็ง) |
| เข้าถึงน้ำจืดได้ | น้อยกว่า 1% ของน้ำทั้งหมด |

## แสง ความเร็ว และมาตราส่วน
ความเร็วแสงอยู่ที่ ~300,000 กม./วินาที (186,000 ไมล์/วินาที) นี่ไม่ใช่แค่ความเร็วเท่านั้น แต่ยังเป็นขีดจำกัดความเร็วของจักรวาลด้วย ไม่มีสิ่งใดที่มีมวลสามารถเข้าถึงได้
| ระยะทาง | แสงใช้เวลานานเท่าใด |
|----------|---------------------|
| โลกสู่ดวงจันทร์ | ~1.3 วินาที |
| ดวงอาทิตย์สู่โลก | ~8 นาที |
| ดวงอาทิตย์ถึงดาวเนปจูน | ~4 ชั่วโมง |
| ไปยังดาวที่ใกล้ที่สุด (Proxima Centauri) | ~4.24 ปี |
| ข้ามทางช้างเผือก | ~100,000 ปี |
| ไปยังกาแล็กซีที่ใกล้ที่สุด (แอนโดรเมดา) | ~2.5 ล้านปี |
ปีแสงเป็นระยะทาง ไม่ใช่เวลา — ประมาณ 9.46 ล้านล้านกิโลเมตร

## สัตว์ — อ้างอิงด่วน
| กลุ่ม | คุณสมบัติที่สำคัญ | ตัวอย่าง | นับ |
|----------------------|------------|----------|--------|
| **สัตว์เลี้ยงลูกด้วยนม** | เลือดอุ่น; ให้กำเนิด; พยาบาลสาว | คน วาฬ ค้างคาว ช้าง | ~6,400 ชนิด |
| **นก** | เลือดอุ่น; ขน; วางไข่ | นกอินทรี นกเพนกวิน นกฮัมมิ่งเบิร์ด | ~10,000 สายพันธุ์ |
| **สัตว์เลื้อยคลาน** | เลือดเย็น; ตาชั่ง | งู เต่า จระเข้ | ~11,000 สายพันธุ์ |
| **สัตว์ครึ่งบกครึ่งน้ำ** | เลือดเย็น; อาศัยอยู่บนบกและในน้ำ | กบ ซาลาแมนเดอร์ | ~8,000 สปีชีส์ |
| **ปลา** | เหงือก; อาศัยอยู่ในน้ำ | ปลาแซลมอน ปลาฉลาม ปลาการ์ตูน | ~35,000 สายพันธุ์ |
| **แมลง** | หกขา; โครงกระดูกภายนอก | ด้วง มด ผีเสื้อ | ~1 ล้าน+ สปีชีส์ |
วาฬสีน้ำเงินเป็นสัตว์ที่ใหญ่ที่สุดที่เคยรู้จัก มีความยาวถึง 30 เมตร และหนัก 200 ตัน แมลงที่เล็กที่สุดคือตัวต่อแมลงวันนางฟ้า ขนาด 0.14 มม. แมลงมีจำนวนมากกว่าสัตว์กลุ่มอื่นๆ ทั้งหมดรวมกัน

## พื้นฐานด้านพลังงาน
พลังงานมาในหลายรูปแบบ แต่ปฏิบัติตามกฎข้อเดียวเสมอ: ไม่สามารถสร้างหรือทำลายได้ มีเพียงการเปลี่ยนแปลงเท่านั้น
| ที่มา | พิมพ์ | มันทำงานอย่างไร |
|--------|-------|-------------|
| **เชื้อเพลิงฟอสซิล** (น้ำมัน ถ่านหิน ก๊าซ) | ไม่หมุนเวียน | เผาอินทรียวัตถุโบราณ ปล่อยCO₂ |
| **นิวเคลียร์** | ไม่หมุนเวียน (จำกัดเชื้อเพลิง) | แยกอะตอมเพื่อปลดปล่อยพลังงาน ไม่มีCO₂แต่เป็นกากกัมมันตภาพรังสี |
| **พลังงานแสงอาทิตย์** | ต่ออายุ | โฟตอนทำให้อิเล็กตรอนหลวมในซิลิคอน |
| **ลม** | ต่ออายุ | การเคลื่อนตัวของอากาศหมุนกังหัน |
| **ไฟฟ้าพลังน้ำ** | ต่ออายุ | น้ำที่ตกลงมาหมุนกังหัน |
| **ความร้อนใต้พิภพ** | ต่ออายุ | ความร้อนจากภายในโลก |
พลังงานไฟฟ้าวัดเป็นกิโลวัตต์-ชั่วโมง (kWh) ครัวเรือนทั่วไปในสหรัฐฯ ใช้พลังงานประมาณ 900 kWh ต่อเดือน

## สรุป
ความรู้ทั่วไปไม่ได้เกี่ยวกับการท่องจำความรู้รอบตัว แต่คือการมีบริบทเพียงพอที่จะเข้าใจโลกรอบตัวคุณ เมื่อคุณรู้ว่าความเร็วแสงคือขีดจำกัดความเร็วของจักรวาล คุณจะเข้าใจว่าทำไมการเดินทางระหว่างดวงดาวจึงเป็นเรื่องยาก เมื่อคุณรู้ว่ามีเพียง 1% ของน้ำในโลกเท่านั้นที่เป็นน้ำจืด คุณจะเข้าใจว่าทำไมความขัดแย้งเรื่องน้ำจึงทวีความรุนแรงมากขึ้น เมื่อคุณรู้ว่าร่างกายมนุษย์ทำงานอย่างไรในระดับพื้นฐาน คุณจะสามารถตัดสินใจเกี่ยวกับสุขภาพของคุณได้ดีขึ้น ข้อเท็จจริงเหล่านี้ไม่ได้แยกออกจากกัน - พวกมันเชื่อมโยงถึงกันและกับทุกสิ่งทุกอย่าง
