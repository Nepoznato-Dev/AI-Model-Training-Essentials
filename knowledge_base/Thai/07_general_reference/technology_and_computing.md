# เทคโนโลยีและคอมพิวเตอร์
คอมพิวเตอร์มีอยู่ทุกที่ ในโทรศัพท์ ในรถยนต์ ตู้เย็น อุปกรณ์ทางการแพทย์ และโครงสร้างพื้นฐานที่ขับเคลื่อนสังคมยุคใหม่ คุณไม่จำเป็นต้องเป็นโปรแกรมเมอร์เพื่อที่จะได้ประโยชน์จากการทำความเข้าใจวิธีการทำงานทั้งหมด ไฟล์นี้ครอบคลุมเนื้อหาพื้นฐาน: คอมพิวเตอร์คืออะไร อินเทอร์เน็ตทำงานอย่างไร ซอฟต์แวร์ถูกสร้างขึ้นอย่างไร และแนวคิดที่หล่อหลอมโลกดิจิทัล
> **ต้องการเจาะลึกกว่านี้ไหม** ไฟล์นี้เป็นภาพรวมแบบกว้างๆ หากต้องการครอบคลุมหัวข้อโดยละเอียด โปรดดูไฟล์เฉพาะใน[`01_coding_and_technology/`](../01_coding_and_technology/)— รวมถึง[database systems](../01_coding_and_technology/database_systems.md),[cloud architecture](../01_coding_and_technology/cloud_architecture.md),[networking](../01_coding_and_technology/networking_basics.md)และ
---

## คอมพิวเตอร์คืออะไร?
ที่แกนหลัก คอมพิวเตอร์ทุกเครื่องตั้งแต่สมาร์ทโฟนไปจนถึงซูเปอร์คอมพิวเตอร์ ทำสิ่งเดียวกัน คือ รับอินพุต ประมวลผลตามคำสั่ง (โปรแกรม) และสร้างเอาต์พุต ความมหัศจรรย์อยู่ที่ความเร็วและขนาด
### สถาปัตยกรรมของวอนนอยมันน์
คอมพิวเตอร์สมัยใหม่เกือบทั้งหมดมีการออกแบบพื้นฐานดังนี้:
| ส่วนประกอบ | มันทำอะไร | การเปรียบเทียบ |
|----------|-------------|---------|
| **CPU** (หน่วยประมวลผลกลาง) | ดำเนินการตามคำแนะนำ; "สมอง" | เชฟทำตามสูตร |
| **RAM** (หน่วยความจำ) | เก็บข้อมูลที่ CPU กำลังใช้งานอยู่ หายไปเมื่อปิดเครื่อง | เคาน์เตอร์ — เข้าถึงได้รวดเร็ว พื้นที่จำกัด |
| **อุปกรณ์จัดเก็บข้อมูล** (SSD/HDD) | เก็บข้อมูลอย่างถาวร | ตู้กับข้าว — เข้าถึงได้ช้าลง มีพื้นที่มากขึ้น |
| **อินพุต/เอาต์พุต** | คีย์บอร์ด เมาส์ หน้าจอ เน็ตเวิร์ค | เชฟรับออเดอร์และส่งอาหารอย่างไร |
| **GPU** (หน่วยประมวลผลกราฟิก) | โปรเซสเซอร์เฉพาะสำหรับงานคู่ขนาน (กราฟิก, AI) | ทีมผู้ช่วยที่ทำงานเดียวกันพร้อมๆ กัน |
**ข้อมูลเชิงลึกที่สำคัญ**: RAM ทำงานเร็วแต่ชั่วคราว การจัดเก็บช้าแต่ถาวร เมื่อคอมพิวเตอร์ของคุณ "รู้สึกช้า" มักเป็นเพราะ RAM เหลือน้อยและต้องใช้พื้นที่จัดเก็บข้อมูลเป็นหน่วยความจำชั่วคราว (การสลับ) ซึ่งช้ากว่ามาก

## ภาษาการเขียนโปรแกรม — การพูดคุยกับคอมพิวเตอร์
ภาษาโปรแกรมคือชุดคำสั่งที่คอมพิวเตอร์สามารถดำเนินการได้ ภาษาต่างๆ ได้รับการออกแบบมาเพื่อวัตถุประสงค์ที่แตกต่างกัน สำหรับรายละเอียดครอบคลุม 34 ภาษา โปรดดูที่โฟลเดอร์ [`programming_languages/`](../01_coding_and_technology/programming_languages/)
| ภาษา | ดีที่สุดสำหรับ | ทำไมถึงเลือกมัน |
|----------|---------|---------------|
| **หลาม** | วิทยาศาสตร์ข้อมูล, AI, ระบบอัตโนมัติ, แบ็กเอนด์ของเว็บ | ไวยากรณ์ง่ายๆ ระบบนิเวศขนาดใหญ่ เหมาะสำหรับผู้เริ่มต้น |
| **จาวาสคริปต์** | ส่วนหน้าของเว็บแบบเต็มสแต็ก (Node.js) | ทำงานในทุกเบราว์เซอร์ จำเป็นสำหรับการพัฒนาเว็บ |
| **ชวา** | ซอฟต์แวร์ระดับองค์กร แอพ Android | ไม่ขึ้นกับแพลตฟอร์ม (JVM); ระบบนิเวศน์ขนาดใหญ่ |
| **ค/ค++** | การเขียนโปรแกรมระบบ เกมส์ ฝังตัว | ประสิทธิภาพสูงสุด การควบคุมฮาร์ดแวร์โดยตรง |
| **สนิม** | การเขียนโปรแกรมระบบพร้อมรับประกันความปลอดภัย | ความปลอดภัยของหน่วยความจำโดยไม่ต้องเก็บขยะ |
| **ไป** | บริการคลาวด์ ไมโครเซอร์วิส เครื่องมือ CLI | เรียบง่าย; การทำงานพร้อมกันที่ดีเยี่ยม การรวบรวมอย่างรวดเร็ว |
| **SQL** | แบบสอบถามฐานข้อมูล | ภาษาสากลสำหรับการทำงานกับข้อมูล |
| **TypeScript** | เว็บแอปพลิเคชั่นขนาดใหญ่ | JavaScript พร้อมการตรวจสอบประเภท จับแมลงได้เร็ว |

## อินเทอร์เน็ตทำงานอย่างไร
อินเทอร์เน็ตไม่เหมือนกับเว็บ อินเทอร์เน็ตคือเครือข่ายทางกายภาพ ไม่ว่าจะเป็นสายเคเบิล เราเตอร์ เซิร์ฟเวอร์ และโปรโตคอลที่เชื่อมต่อกับอุปกรณ์นับพันล้านเครื่อง เวิลด์ไวด์เว็บเป็นบริการหนึ่งที่ทำงานบนอินเทอร์เน็ต (พร้อมกับอีเมล การถ่ายโอนไฟล์ การสตรีม การเล่นเกม ฯลฯ)
### การเดินทางของคำขอทางเว็บ
เมื่อคุณพิมพ์`https://www.example.com`ลงในเบราว์เซอร์ของคุณ:
1. **การค้นหา DNS**: เบราว์เซอร์ของคุณขอให้เซิร์ฟเวอร์ DNS แปล "www.example.com" เป็นที่อยู่ IP (เช่น 93.184.216.34)
2. **การเชื่อมต่อ TCP**: อุปกรณ์ของคุณสร้างการเชื่อมต่อกับที่อยู่ IP นั้นโดยใช้ TCP (โปรโตคอลที่รับประกันการจัดส่งที่เชื่อถือได้)
3. **การจับมือ TLS**: หากใช้ HTTPS เบราว์เซอร์และเซิร์ฟเวอร์ของคุณจะเจรจาต่อรองการเชื่อมต่อที่เข้ารหัส
4. **คำขอ HTTP**: เบราว์เซอร์ของคุณส่งคำขอ: "ขอเพจให้ฉันที่ /index.html"
5. **การประมวลผลเซิร์ฟเวอร์**: เว็บเซิร์ฟเวอร์ค้นหาเพจ อาจสอบถามฐานข้อมูล และเตรียมการตอบกลับ
6. **การตอบสนอง HTTP**: เซิร์ฟเวอร์ส่งคืน HTML, CSS และ JavaScript
7. **การเรนเดอร์**: เบราว์เซอร์ของคุณแยกวิเคราะห์ HTML ใช้สไตล์ CSS และรัน JavaScript เพื่อแสดงเพจ
โดยทั่วไปกระบวนการทั้งหมดนี้จะใช้เวลาไม่ถึงหนึ่งวินาที
### โปรโตคอลที่สำคัญ
| โปรโตคอล | มันทำอะไร | เลเยอร์ |
|----------|-------------|-------|
| **IP** (อินเทอร์เน็ตโปรโตคอล) | กำหนดเส้นทางแพ็กเก็ตระหว่างเครือข่าย | เครือข่าย |
| **ทีซีพี** | เชื่อถือได้ จัดส่งตามคำสั่ง (ส่งแพ็กเก็ตที่สูญหายอีกครั้ง) | ขนส่ง |
| **UDP** | การจัดส่งที่รวดเร็วและไม่น่าเชื่อถือ (ไม่มีการส่งสัญญาณซ้ำ) | ขนส่ง |
| **HTTP/HTTPS** | การถ่ายโอนหน้าเว็บ (HTTPS เพิ่มการเข้ารหัส) | ใบสมัคร |
| **DNS** | แปลชื่อโดเมนเป็นที่อยู่ IP | ใบสมัคร |
| **SSH** | เข้าถึงคอมพิวเตอร์ระยะไกลอย่างปลอดภัย | ใบสมัคร |
| **SMTP/IMAP** | การส่งและรับอีเมล์ | ใบสมัคร |

## การพัฒนาซอฟต์แวร์ — วิธีสร้างโปรแกรม
### กระบวนการพัฒนา
1. **เขียนโค้ด**: นักพัฒนาเขียนคำสั่งในภาษาการเขียนโปรแกรม
2. **รหัสทดสอบ**: เรียกใช้รหัสเพื่อตรวจสอบว่าทำงานได้อย่างถูกต้อง
3. **การควบคุมเวอร์ชัน**: ติดตามการเปลี่ยนแปลงโดยใช้ Git — มาตรฐานสากล
4. **การตรวจสอบ**: นักพัฒนารายอื่นตรวจสอบโค้ดเพื่อดูข้อผิดพลาดและคุณภาพ
5. **Build**: แปลงซอร์สโค้ดให้เป็นโปรแกรมที่รันได้ (คอมไพล์)
6. **ปรับใช้**: เผยแพร่โปรแกรมให้กับผู้ใช้ (เซิร์ฟเวอร์ ร้านค้าแอป ฯลฯ)
7. **การตรวจสอบ**: คอยดูข้อผิดพลาดและปัญหาด้านประสิทธิภาพในการผลิต
### แนวคิดหลัก
| แนวคิด | มันหมายถึงอะไร | ทำไมมันถึงสำคัญ |
|---------|-------------------|----------------|
| **การควบคุมเวอร์ชัน (Git)** | ติดตามทุกการเปลี่ยนแปลงโค้ดเมื่อเวลาผ่านไป | การทำงานร่วมกัน; ความสามารถในการยกเลิกข้อผิดพลาด |
| **API** (อินเทอร์เฟซการเขียนโปรแกรมแอปพลิเคชัน) | วิธีที่กำหนดไว้สำหรับส่วนประกอบซอฟต์แวร์ในการสื่อสาร | ช่วยให้ระบบต่างๆทำงานร่วมกันได้ |
| **ฐานข้อมูล** | จัดระเบียบการจัดเก็บข้อมูล | ทุกแอปพลิเคชันจำเป็นต้องจัดเก็บและดึงข้อมูล |
| **การทดสอบ** | การตรวจสอบอัตโนมัติว่าโค้ดทำงานถูกต้อง | ป้องกันข้อบกพร่องไม่ให้เข้าถึงผู้ใช้ |
| **CI/CD** (บูรณาการ/จัดส่งอย่างต่อเนื่อง) | ไปป์ไลน์อัตโนมัติตั้งแต่การคอมมิตโค้ดไปจนถึงการใช้งานจริง | เผยแพร่เร็วขึ้นและปลอดภัยยิ่งขึ้น |
| **คอนเทนเนอร์ (นักเทียบท่า)** | จัดทำแพ็คเกจแอปพลิเคชันด้วยการขึ้นต่อกันทั้งหมด | "ทำงานบนเครื่องของฉัน" กลายเป็น "ทำงานได้ทุกที่" |

## ฐานข้อมูล — ที่ซึ่งมีข้อมูลอยู่
ทุกแอปพลิเคชันจำเป็นต้องจัดเก็บข้อมูล ฐานข้อมูลคือระบบที่ทำสิ่งนี้ได้อย่างมีประสิทธิภาพและเชื่อถือได้
| พิมพ์ | วิธีการจัดเก็บข้อมูล | ดีที่สุดสำหรับ | ตัวอย่าง |
|------|---------|----------|---------|
| **เชิงสัมพันธ์ (SQL)** | ตารางที่มีแถวและคอลัมน์ สคีมาที่เข้มงวด | ข้อมูลที่มีโครงสร้าง แบบสอบถามที่ซับซ้อน การทำธุรกรรม | PostgreSQL, MySQL, SQLite |
| **เอกสาร (NoSQL)** | เอกสารที่เหมือน JSON สคีมาแบบยืดหยุ่น | ข้อมูลกึ่งโครงสร้าง การวนซ้ำอย่างรวดเร็ว | MongoDB, CouchDB |
| **คีย์-ค่า** | คีย์ธรรมดา → คู่ค่า | แคช; ที่เก็บข้อมูลเซสชัน ค้นหาอย่างรวดเร็ว | เรดดิส, DynamoDB |
| **กราฟ** | โหนดและขอบ (ความสัมพันธ์) | เครือข่ายสังคมออนไลน์ เครื่องยนต์แนะนำ | Neo4j, JanusGraph |
| **อนุกรมเวลา** | ปรับให้เหมาะสมสำหรับข้อมูลที่ประทับเวลา | การตรวจสอบ; การวิเคราะห์; ไอโอที | InfluxDB, TimescaleDB |
**SQL** (Structured Query Language) เป็นภาษามาตรฐานสำหรับฐานข้อมูลเชิงสัมพันธ์ นี่เป็นหนึ่งในทักษะทางเทคนิคที่มีค่าที่สุดที่คุณสามารถเรียนรู้ได้ เกือบทุกองค์กรใช้ฐานข้อมูล และ SQL คือวิธีที่คุณพูดคุยกับพวกเขา

## ระบบปฏิบัติการ
ระบบปฏิบัติการ (OS) คือเลเยอร์ซอฟต์แวร์ระหว่างคุณ (และโปรแกรมของคุณ) และฮาร์ดแวร์ จัดการหน่วยความจำ กระบวนการ ไฟล์ และอุปกรณ์
| ระบบปฏิบัติการ | มันครอบงำที่ไหน | คุณสมบัติที่สำคัญ |
|----|------------------|-------------|
| **หน้าต่าง** | พีซีตั้งโต๊ะ/แล็ปท็อป (ส่วนแบ่งตลาด ~72%) ความเข้ากันได้ของซอฟต์แวร์/ฮาร์ดแวร์ที่หลากหลายที่สุด |
| **macOS** | ผู้เชี่ยวชาญด้านการสร้างสรรค์, นักพัฒนา | ใช้ระบบปฏิบัติการยูนิกซ์; UI ที่สวยงาม; ระบบนิเวศของ Apple |
| **ลินุกซ์** | เซิร์ฟเวอร์ (~96%), ซูเปอร์คอมพิวเตอร์ (100%), แบบฝัง, นักพัฒนา | โอเพ่นซอร์ส; ฟรี; ปรับแต่งได้อย่างมาก |
| **แอนดรอยด์** | มือถือ (~72% ส่วนแบ่งตลาดทั่วโลก) | ขึ้นอยู่กับเคอร์เนล Linux; โอเพ่นซอร์ส |
| **iOS** | มือถือ (~27% ทั่วโลก แต่รายได้สูงกว่า) | ระบบนิเวศแบบปิด ขัด; เน้นความเป็นส่วนตัว |
Linux สมควรได้รับการกล่าวถึงเป็นพิเศษ: มันขับเคลื่อนอินเทอร์เน็ตส่วนใหญ่, ซูเปอร์คอมพิวเตอร์ชั้นนำ 500 ทุกเครื่อง, โครงสร้างพื้นฐานคลาวด์ส่วนใหญ่ และโทรศัพท์ Android ทั้งหมด เป็นฟรี โอเพ่นซอร์ส และดูแลโดยชุมชนทั่วโลก

## คลาวด์คอมพิวติ้ง
การประมวลผลแบบคลาวด์หมายถึงการเช่าทรัพยากรการประมวลผล (เซิร์ฟเวอร์ พื้นที่เก็บข้อมูล ฐานข้อมูล ฯลฯ) ผ่านทางอินเทอร์เน็ต แทนที่จะซื้อและบำรุงรักษาฮาร์ดแวร์ของคุณเอง สำหรับคำแนะนำที่ครอบคลุมเกี่ยวกับสถาปัตยกรรมคลาวด์ โมเดลบริการ และการเปรียบเทียบผู้ให้บริการ โปรดดูที่ [cloud architecture](../01_coding_and_technology/cloud_architecture.md)
| รูปแบบการให้บริการ | สิ่งที่คุณได้รับ | การเปรียบเทียบ | ตัวอย่าง |
|---------|-------------|---------|---------|
| **IaaS** (โครงสร้างพื้นฐาน) | เซิร์ฟเวอร์เสมือน พื้นที่เก็บข้อมูล ระบบเครือข่าย | เช่าที่ดินพร้อมสิ่งปลูกสร้างตามที่คุณต้องการ | AWS EC2, Google Compute Engine |
| **PaaS** (แพลตฟอร์ม) | สภาพแวดล้อมรันไทม์ คุณนำรหัส | ให้เช่าอพาร์ทเมนต์พร้อมเฟอร์นิเจอร์ | Heroku, Google App Engine |
| **SaaS** (ซอฟต์แวร์) | กรอกใบสมัคร; คุณเพียงแค่ใช้มัน | พักที่โรงแรม | Gmail, Slack, Salesforce |
ผู้ให้บริการคลาวด์รายใหญ่สามราย ได้แก่ **AWS** (Amazon, ~32% ส่วนแบ่งตลาด), **Azure** (Microsoft, ~23%) และ **GCP** (Google, ~10%) พวกเขาเสนอบริการหลายร้อยรายการครอบคลุมการประมวลผล พื้นที่จัดเก็บ ฐานข้อมูล AI ระบบเครือข่าย และอื่นๆ อีกมากมาย

## ความปลอดภัยทางไซเบอร์ - การปกป้องระบบดิจิทัล
การรักษาความปลอดภัยทางไซเบอร์คือแนวทางปฏิบัติในการปกป้องคอมพิวเตอร์ เครือข่าย และข้อมูลจากการโจมตี เป็นเรื่องสำคัญเพราะทุกอย่างเชื่อมโยงกัน และค่าใช้จ่ายของการละเมิดก็มหาศาล สำหรับคำแนะนำฉบับเต็มที่ครอบคลุม OWASP Top 10, วงจรการพัฒนาที่ปลอดภัย และการจัดการข้อมูลลับ โปรดดูที่
### ภัยคุกคามทั่วไป
| ภัยคุกคาม | มันคืออะไร | การป้องกัน |
|----------------------|-----------|------------|
| **มัลแวร์** | ซอฟต์แวร์ที่เป็นอันตราย (ไวรัส เวิร์ม โทรจัน) | แอนตี้ไวรัส; อัปเดตซอฟต์แวร์อยู่เสมอ |
| **ฟิชชิ่ง** | อีเมล/ข้อความปลอมหลอกให้คุณเปิดเผยข้อมูล | การฝึกอบรม; การกรองอีเมล ความสงสัย |
| **แรนซัมแวร์** | เข้ารหัสข้อมูลของคุณ เรียกร้องการชำระเงินสำหรับกุญแจ | การสำรองข้อมูล; ระบบแพทช์ ไม่ต้องจ่าย |
| **ดีดอส** | ล้นหลามบริการด้วยการจราจร | การกรองการรับส่งข้อมูล การป้องกัน CDN |
| **การแทรก SQL** | การแทรก SQL ที่เป็นอันตรายลงในช่องป้อนข้อมูล | แบบสอบถามที่กำหนดพารามิเตอร์ การตรวจสอบอินพุต |
| **คนกลาง** | การสกัดกั้นการสื่อสารระหว่างสองฝ่าย | การเข้ารหัส HTTPS/TLS |
### พื้นฐานด้านความปลอดภัย
- **การเข้ารหัส**: แย่งข้อมูลเพื่อให้เฉพาะผู้ที่ได้รับอนุญาตเท่านั้นที่สามารถอ่านได้ HTTPS ใช้ TLS เพื่อเข้ารหัสการรับส่งข้อมูลเว็บ
- **การตรวจสอบสิทธิ์**: ยืนยันตัวตน ใช้การรับรองความถูกต้องด้วยหลายปัจจัย (MFA) — รหัสผ่าน + อย่างอื่น (รหัส ไบโอเมตริก)
- **การอนุญาต**: ตรวจสอบการอนุญาต เพียงเพราะคุณเข้าสู่ระบบไม่ได้หมายความว่าคุณควรเข้าถึงทุกสิ่ง
- **หลักการของสิทธิ์ขั้นต่ำ**: ให้ผู้ใช้และระบบเฉพาะการเข้าถึงที่พวกเขาต้องการเท่านั้น ไม่มีอะไรเพิ่มเติม
- **การจัดการแพตช์**: อัปเดตซอฟต์แวร์อยู่เสมอ การละเมิดส่วนใหญ่ใช้ประโยชน์จากช่องโหว่ที่ทราบซึ่งมีแพตช์อยู่แล้ว

## รูปแบบข้อมูล
โปรแกรมแลกเปลี่ยนข้อมูลในรูปแบบเฉพาะ ที่พบบ่อยที่สุด:
| รูปแบบ | โครงสร้าง | ใช้สำหรับ |
|--------|-----------|----------|
| **เจสัน** | คู่คีย์-ค่า มนุษย์สามารถอ่านได้ | API; การกำหนดค่า; การแลกเปลี่ยนข้อมูล |
| **XML** | ตามแท็ก; ละเอียดแต่ยืดหยุ่น | ระบบเดิม; เอกสาร; SOAP API |
| **YAML** | ตามการเยื้อง; น่าอ่านมาก | การกำหนดค่า (นักเทียบท่า, Kubernetes, CI/CD) |
| **ซีเอสวี** | แถวและคอลัมน์ข้อความธรรมดา | การนำเข้า/ส่งออกข้อมูล สเปรดชีต |

## สรุป
คอมพิวเตอร์ไม่ใช่สิ่งมหัศจรรย์ แต่เป็นวิศวกรรม คอมพิวเตอร์ปฏิบัติตามคำแนะนำด้วยความเร็วที่เหลือเชื่อ อินเทอร์เน็ตเชื่อมต่อผู้คนหลายพันล้านคนโดยใช้โปรโตคอลมาตรฐาน ซอฟต์แวร์ถูกสร้างขึ้นโดยทีมงานที่เขียน ทดสอบ และปรับใช้โค้ดในรอบการทำซ้ำ ฐานข้อมูลจัดเก็บและดึงข้อมูล การประมวลผลแบบคลาวด์ช่วยให้ทุกคนเข้าถึงทรัพยากรการประมวลผลขนาดใหญ่ได้ตามความต้องการ และความปลอดภัยทางไซเบอร์คือการต่อสู้ที่ดำเนินไปอย่างต่อเนื่องเพื่อปกป้องทั้งหมดนี้ให้ปลอดภัยจากผู้ที่ต้องการใช้ประโยชน์จากมัน การทำความเข้าใจพื้นฐานเหล่านี้ช่วยให้คุณนำทางโลกดิจิทัลได้ ไม่ว่าคุณจะเป็นผู้ใช้ นักพัฒนา หรือเพียงแค่ใครบางคนที่พยายามทำความเข้าใจกับเทคโนโลยีที่หล่อหลอมชีวิตยุคใหม่
