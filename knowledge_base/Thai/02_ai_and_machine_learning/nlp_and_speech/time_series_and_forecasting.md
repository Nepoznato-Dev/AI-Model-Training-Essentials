# อนุกรมเวลาและการพยากรณ์
ข้อมูลอนุกรมเวลาคือข้อมูลใดๆ ที่รวบรวมในช่วงเวลาหนึ่ง เช่น ราคาหุ้น การอ่านอุณหภูมิ การเข้าชมเว็บไซต์ ตัวเลขยอดขาย เครื่องวัดอัตราการเต้นของหัวใจ การใช้พลังงาน การพยากรณ์หมายถึงการทำนายมูลค่าในอนาคตตามรูปแบบในอดีต เป็นหนึ่งในการประยุกต์ใช้วิทยาศาสตร์ข้อมูลที่มีคุณค่าในทางปฏิบัติมากที่สุด และเป็นหนึ่งในการใช้งานที่ยากที่สุด เนื่องจากอนาคตมีความไม่แน่นอนอย่างแท้จริง และอนุกรมเวลาในโลกแห่งความเป็นจริงเต็มไปด้วยสัญญาณรบกวน ฤดูกาล และการพังทลายของโครงสร้าง
---

## ลักษณะของอนุกรมเวลา
| ส่วนประกอบ | คำอธิบาย | ตัวอย่าง |
|----------|-------------|---------|
| **เทรนด์** | เพิ่มขึ้นหรือลดลงในระยะยาว | อุณหภูมิโลกสูงขึ้นในรอบหลายทศวรรษ |
| **ฤดูกาล** | รูปแบบปกติที่คาดเดาได้ในช่วงเวลาคงที่ | ยอดค้าปลีกพุ่งทุกเดือนธันวาคม |
| **วัฏจักร** | ความผันผวนในช่วงเวลาที่ไม่คงที่ (มักเป็นเรื่องทางเศรษฐกิจ) | ถดถอยทุกๆ 5-10 ปี |
| **เสียงรบกวน (ตกค้าง)** | รูปแบบสุ่มที่ไม่สามารถอธิบายได้ | การเคลื่อนไหวของราคาหุ้นรายวัน |
| **ความสัมพันธ์อัตโนมัติ** | ค่าปัจจุบันขึ้นอยู่กับค่าที่ผ่านมา | อุณหภูมิวันนี้ใกล้เคียงกับเมื่อวาน |
### ความคงที่
อนุกรมเวลาจะ **คงที่** หากคุณสมบัติทางสถิติ (ค่าเฉลี่ย ความแปรปรวน) ไม่เปลี่ยนแปลงเมื่อเวลาผ่านไป วิธีการพยากรณ์ส่วนใหญ่จะถือว่าความคงที่
| ทดสอบ | วัตถุประสงค์ |
|------|---------|
| **Augmented Dickey-Fuller (ADF)** | ทดสอบว่ามีหน่วยรูทอยู่หรือไม่ (ไม่คงที่) |
| **การทดสอบ KPSS** | ทดสอบว่าซีรีส์เป็นแบบคงที่ตามเทรนด์หรือไม่ |
| การเปลี่ยนแปลง | เมื่อใดควรใช้ |
|---------------|-------------|
| **ความแตกต่าง** | ลบแนวโน้ม: y'(t) = y(t) - y(t-1) |
| **บันทึกการแปลง** | รักษาความแปรปรวนให้คงที่ (สำหรับการเติบโตแบบเอ็กซ์โปเนนเชียล) |
| **ความแตกต่างตามฤดูกาล** | ลบฤดูกาล: y'(t) = y(t) - y(t-s) โดยที่ s คือความยาวของฤดูกาล |

## วิธีการพยากรณ์แบบคลาสสิก
### ค่าเฉลี่ยเคลื่อนที่
| วิธีการ | คำอธิบาย | ดีที่สุดสำหรับ |
|--------|-------------|----------|
| **ค่าเฉลี่ยเคลื่อนที่อย่างง่าย (SMA)** | ค่าเฉลี่ยของการสังเกต N ครั้งล่าสุด | ปรับข้อมูลที่มีเสียงดังให้เรียบ |
| **ค่าเฉลี่ยเคลื่อนที่ถ่วงน้ำหนัก** | การสังเกตล่าสุดมีน้ำหนักมากขึ้น | เมื่อข้อมูลล่าสุดมีความสำคัญมากขึ้น |
| **ค่าเฉลี่ยเคลื่อนที่แบบเอ็กซ์โปเนนเชียล (EMA)** | น้ำหนักลดลงแบบทวีคูณ | ติดตามแนวโน้มด้วยความล่าช้าน้อยลง |
### การปรับให้เรียบแบบเอ็กซ์โปเนนเชียล
| วิธีการ | ส่วนประกอบ | ใช้กรณี |
|--------|-----------|----------|
| **แบบง่าย (SES)** | ระดับเท่านั้น | ไม่มีเทรนด์ ไม่มีฤดูกาล |
| **โฮลท์ส (ดับเบิ้ล)** | ระดับ + แนวโน้ม | ข้อมูลมีแนวโน้มแต่ไม่มีฤดูกาล |
| **โฮลท์-วินเทอร์ส (ทริปเปิล)** | ระดับ + แนวโน้ม + ฤดูกาล | ข้อมูลที่มีทั้งแนวโน้มและฤดูกาล |
### ARIMA และตัวแปร
ARIMA (AutoRegressive Integrated Moving Average) เป็นกลไกหลักในการพยากรณ์อนุกรมเวลาแบบคลาสสิก
| ส่วนประกอบ | ความหมาย | พารามิเตอร์ |
|----------|---------|-----------|
| **AR (p)** | ถดถอยกับค่า p ก่อนหน้า | ต้องใช้ค่าในอดีตกี่ค่า |
| **ฉัน (ง)** | จำนวนขั้นตอนต่าง ๆ ในการทำเครื่องเขียน | ต่างกันกี่ครั้ง |
| **MA (q)** | สร้างแบบจำลองข้อผิดพลาดโดยการรวมกันของข้อผิดพลาดในอดีต | มีข้อผิดพลาดในอดีตกี่ข้อในการใช้ |
| ตัวแปร | ส่วนขยาย | ใช้กรณี |
|---------|-----------|----------|
| **ซาริมา** | เพิ่มส่วนประกอบตามฤดูกาล (P, D, Q, s) | ข้อมูลที่มีฤดูกาลที่แข็งแกร่ง |
| **อาริแม็กซ์** | เพิ่มตัวแปรภายนอก | เมื่อคุณทราบเกี่ยวกับกิจกรรมที่จะเกิดขึ้น |
| **วาร์** | ARIMA หลายตัวแปร; หลายชุดที่เป็นอิสระต่อกัน | เมื่อตัวแปรกระทบกัน |

## แนวทาง ML สมัยใหม่
### โมเดลที่ใช้ LSTM และ RNN
| รุ่น | สถาปัตยกรรม | ข้อได้เปรียบ |
|-------|-------------|-----------|
| **LSTM** | เครือข่ายหน่วยความจำระยะสั้นระยะยาว | จับภาพการพึ่งพาชั่วคราวในระยะยาว |
| **กรู** | Gated Recurrent Unit (LSTM ง่ายกว่า) | การฝึกอบรมที่เร็วขึ้น ประสิทธิภาพใกล้เคียงกัน |
| **Seq2Seq** | ตัวเข้ารหัส-ตัวถอดรหัสสำหรับอนุกรมเวลา | ความยาวอินพุต/เอาท์พุตที่ยืดหยุ่น
| **เครือข่าย Convolutional ชั่วคราว (TCN)** | การโน้มน้าวใจเชิงสาเหตุแบบขยาย | การฝึกอบรมแบบขนาน สนามรับสัญญาณยาว |
### พระศาสดา (เมตา)
เครื่องมือพยากรณ์เชิงปฏิบัติที่ออกแบบมาสำหรับอนุกรมเวลาทางธุรกิจ
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **การสลายตัว** | เทรนด์ + ฤดูกาล + วันหยุด |
| **ยืดหยุ่น** | จัดการกับข้อมูลที่ขาดหายไป ค่าผิดปกติ และตัวแบ่งโครงสร้าง |
| **ตีความได้** | ส่วนประกอบต่างๆ นั้นมนุษย์สามารถอ่านได้ |
| **อัตโนมัติ** | ค่าเริ่มต้นที่สมเหตุสมผล ต้องการการปรับแต่งขั้นต่ำ |
| ความแข็งแกร่ง | ข้อจำกัด |
|----------|------------|
| เหมาะสำหรับการวัดผลทางธุรกิจ (ยอดขาย ผู้ใช้) | ไม่เหมาะสำหรับข้อมูลความถี่สูงมาก |
| จัดการวันหยุดและกิจกรรมพิเศษ | ถือว่าฤดูกาลบวกหรือทวีคูณ |
| ทนทานต่อค่าผิดปกติ | แม่นยำน้อยกว่าการเรียนรู้เชิงลึกสำหรับรูปแบบที่ซับซ้อน |
### โมเดลที่ใช้หม้อแปลงไฟฟ้า
| รุ่น | คุณสมบัติที่สำคัญ |
|-------|-------------|
| **ผู้แจ้ง** | ความสนใจ ProbSparse สำหรับลำดับยาว |
| **ออโต้ฟอร์เมอร์** | กลไกความสัมพันธ์อัตโนมัติสำหรับการสลายตัวแบบอนุกรม |
| **แพทช์TST** | แพทช์อนุกรมเวลา ไม่ขึ้นกับช่องสัญญาณ |
| **TimesFM** (Google) | แบบจำลองพื้นฐานสำหรับอนุกรมเวลา ฝึกอบรมล่วงหน้าเกี่ยวกับข้อมูลที่หลากหลาย |
| **โครโนส** (อเมซอน) | โทเค็นอนุกรมเวลา ใช้สถาปัตยกรรมสไตล์ LLM |

## การตรวจจับความผิดปกติในอนุกรมเวลา
การตรวจจับรูปแบบที่ผิดปกติซึ่งเบี่ยงเบนไปจากพฤติกรรมที่คาดหวัง
| วิธีการ | วิธีการ | ใช้กรณี |
|--------|----------|----------|
| **สถิติ** | คะแนน Z, IQR, แผนภูมิควบคุม | เรียบง่ายเข้าใจดี |
| **ป่าโดดเดี่ยว** | แบบต้นไม้; แยกความผิดปกติโดยการแบ่งพาร์ติชันแบบสุ่ม | การตรวจจับความผิดปกติหลายตัวแปร |
| **LOF** (ปัจจัยค่าผิดปกติในพื้นที่) | ตามความหนาแน่น; เปรียบเทียบความหนาแน่นในท้องถิ่นกับเพื่อนบ้าน | เมื่อความผิดปกติเกิดขึ้นในบริเวณที่มีความหนาแน่นต่ำ |
| **ตัวเข้ารหัสอัตโนมัติ** | ข้อผิดพลาดในการฟื้นฟู; ข้อผิดพลาดสูง = ความผิดปกติ | รูปแบบที่ซับซ้อนและไม่เชิงเส้น |
| **อิง LSTM** | ทำนายขั้นตอนต่อไป ข้อผิดพลาดในการทำนายขนาดใหญ่ = ความผิดปกติ | ความผิดปกติตามลำดับ |
### แอปพลิเคชัน
| โดเมน | ความผิดปกติหมายถึงอะไร |
|--------|-------------------|
| **การเงิน** | การฉ้อโกง ตลาดล่ม แฟลชล่ม |
| **การดูแลสุขภาพ** | อัตราการเต้นของหัวใจผิดปกติ เริ่มมีอาการชัก |
| **การผลิต** | อุปกรณ์ขัดข้อง บกพร่องด้านคุณภาพ |
| **ความปลอดภัยทางไซเบอร์** | ความพยายามในการบุกรุก, การโจมตี DDoS |
| **โครงสร้างพื้นฐาน** | เซิร์ฟเวอร์โอเวอร์โหลด เครือข่ายขัดข้อง |

## ตัวชี้วัดการประเมินผล
| เมตริก | สูตร (แนวความคิด) | เมื่อใดควรใช้ |
|----------------------|---------------------|-------------|
| **แม่** (หมายถึงข้อผิดพลาดสัมบูรณ์) | ค่าเฉลี่ยของข้อผิดพลาดสัมบูรณ์ | ตีความได้; หน่วยเดียวกับข้อมูล |
| **RMSE** (ข้อผิดพลาด Root Mean Squared) | รากที่สองของข้อผิดพลาดกำลังสองเฉลี่ย | ลงโทษข้อผิดพลาดขนาดใหญ่ เพิ่มเติม |
| **MAPE** (ข้อผิดพลาดเปอร์เซ็นต์สัมบูรณ์เฉลี่ย) | ค่าเฉลี่ยของเปอร์เซ็นต์ข้อผิดพลาดสัมบูรณ์ | เมื่อข้อผิดพลาดสัมพัทธ์มีความสำคัญ |
| **SMAPE** (MAPE แบบสมมาตร) | MAPE | เวอร์ชันสมมาตร จัดการค่าใกล้ศูนย์ได้ดีขึ้น |
| **MASE** (ข้อผิดพลาดมาตราส่วนเฉลี่ยสัมบูรณ์) | แม่สัมพันธ์กับการพยากรณ์ที่ไร้เดียงสา | เปรียบเทียบระหว่างซีรีย์ต่างๆ |

## ขั้นตอนการปฏิบัติงานจริง
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. สำรวจ** | พล็อตซีรีส์; ระบุแนวโน้ม ฤดูกาล ค่าผิดปกติ |
| **2. สลายตัว** | แยกเป็นองค์ประกอบเทรนด์ ฤดูกาล และสารตกค้าง |
| **3. เครื่องเขียน** | ใช้ความแตกต่างหรือการแปลงหากจำเป็น |
| **4. แยก** | การแยกตามเวลา (ไม่เคยแยกแบบสุ่มสำหรับอนุกรมเวลา) |
| **5. พื้นฐาน** | เริ่มต้นด้วยการคาดการณ์แบบไร้เดียงสา (ค่าสุดท้าย ไร้เดียงสาตามฤดูกาล) |
| **6. รุ่น** | ลองใช้วิธีคลาสสิก (ARIMA, ศาสดา) จากนั้นจึงใช้วิธี ML |
| **7. ประเมิน** | ใช้ตัวชี้วัดที่เหมาะสม เปรียบเทียบกับพื้นฐาน |
| **8. ย้ำ** | เพิ่มฟีเจอร์ ลองใช้โมเดลต่างๆ ปรับแต่งไฮเปอร์พารามิเตอร์ |

## เครื่องมือและไลบรารี
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **แบบจำลองสถิติ** | อนุกรมเวลาคลาสสิก (ARIMA, ETS, การสลายตัว) |
| **ศาสดา** (เมตา) | การพยากรณ์อนุกรมเวลาทางธุรกิจ |
| **sktime** | อินเทอร์เฟซ ML แบบรวมสำหรับอนุกรมเวลา |
| **ปาเป้า** | ไลบรารีการคาดการณ์ที่ครอบคลุม (คลาสสิก + การเรียนรู้เชิงลึก) |
| **GluonTS** (อเมซอน) | การสร้างแบบจำลองอนุกรมเวลาความน่าจะเป็น |
| **นักประสาทวิทยา** | ศาสดาที่มีส่วนประกอบของโครงข่ายประสาทเทียม |

## สรุป
การคาดการณ์อนุกรมเวลาผสมผสานสถิติแบบคลาสสิกเข้ากับการเรียนรู้ของเครื่องสมัยใหม่ วิธีการแบบดั้งเดิม (ARIMA, การทำให้เรียบแบบเอกซ์โปเนนเชียล, ศาสดาพยากรณ์) สามารถตีความได้ รวดเร็ว และมักจะแม่นยำ วิธีการเรียนรู้เชิงลึก (LSTM, Transformers) จับรูปแบบที่ซับซ้อน แต่ต้องใช้ข้อมูลและการปรับแต่งมากขึ้น หลักการสำคัญยังคงเหมือนเดิมไม่ว่าจะใช้วิธีใดก็ตาม: ทำความเข้าใจโครงสร้างข้อมูลของคุณ (แนวโน้ม ฤดูกาล สัญญาณรบกวน) เปรียบเทียบกับเส้นฐานง่ายๆ ประเมินด้วยตัวชี้วัดที่เหมาะสม และคำนึงถึงข้อเท็จจริงที่ว่าอนาคตจะไม่จำลองอดีตอย่างแน่นอน
