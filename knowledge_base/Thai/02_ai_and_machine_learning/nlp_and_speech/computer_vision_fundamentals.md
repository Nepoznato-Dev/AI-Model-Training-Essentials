#ความรู้พื้นฐานด้านการมองเห็นคอมพิวเตอร์
คอมพิวเตอร์วิทัศน์ช่วยให้เครื่องจักรสามารถตีความและทำความเข้าใจข้อมูลภาพจากโลก เช่น รูปภาพ วิดีโอ และข้อมูล 3 มิติ มันขับเคลื่อนทุกสิ่งตั้งแต่การจดจำใบหน้าบนโทรศัพท์ของคุณไปจนถึงรถยนต์ที่ขับเคลื่อนด้วยตนเอง การวิเคราะห์ภาพทางการแพทย์ และการควบคุมคุณภาพทางอุตสาหกรรม ไฟล์นี้ครอบคลุมแนวคิดหลัก สถาปัตยกรรม และเทคนิค
---

## คอมพิวเตอร์เห็นภาพอย่างไร
### พิกเซลและช่อง
รูปภาพดิจิทัลคือตารางพิกเซล แต่ละพิกเซลมีค่าตัวเลขที่แสดงถึงความเข้มของสี
| ประเภทรูปภาพ | ช่อง | ค่าต่อพิกเซล | ตัวอย่าง |
|----------|----------|-----------------|---------|
| **ระดับสีเทา** | 1 | 0 (ดำ) ถึง 255 (ขาว) | รังสีเอกซ์ทางการแพทย์ |
| **RGB** | 3 | แดง เขียว น้ำเงิน (ตัวละ 0–255) | ภาพถ่ายสีมาตรฐาน |
| **RGBA** | 4 | RGB + อัลฟ่า (โปร่งใส) | รูปภาพที่มีพื้นหลังโปร่งใส |
| **HSV** | 3 | ฮิว, ความอิ่มตัว, ค่า | การแบ่งส่วนตามสี |
ภาพ RGB ขนาด 1920×1080 เป็นเทนเซอร์ของรูปร่าง`(1080, 1920, 3)`ซึ่งมีขนาด 6.2 ล้านพิกเซล โดยแต่ละภาพมี 3 ค่า
### การดำเนินงานที่สำคัญ
| การดำเนินงาน | คำอธิบาย |
|-----------|-------------|
| **การปรับขนาด** | ปรับขนาดภาพตามขนาดเป้าหมาย (แบบไบเนียร์ การแก้ไขเพื่อนบ้านที่ใกล้ที่สุด) |
| **การครอบตัด** | แยกภูมิภาคที่สนใจ |
| **การทำให้เป็นมาตรฐาน** | ปรับขนาดค่าพิกเซลเป็น [0,1] หรือ [-1,1] สำหรับโครงข่ายประสาทเทียม |
| **การเสริมความงาม** | ขยายข้อมูลการฝึกโดยไม่ตั้งใจ (การหมุน การพลิก การกระวนกระวายใจของสี การครอบตัด) |

## Convolution: ปฏิบัติการหลัก
การบิดเกลียวจะเลื่อนตัวกรองขนาดเล็ก (เคอร์เนล) ไปทั่วรูปภาพ โดยคำนวณผลคูณจุดในแต่ละตำแหน่ง นี่คือวิธีที่ CNN ตรวจจับขอบ พื้นผิว และลวดลาย
### พารามิเตอร์การบิด
| พารามิเตอร์ | เอฟเฟกต์ |
|----------|--------|
| **ขนาดเคอร์เนล** | 3×3, 5×5, 7×7 — เมล็ดที่ใหญ่กว่าจะจับรูปแบบที่ใหญ่กว่า |
| **ก้าวย่าง** | ขนาดขั้นตอน; stride=2 ลดขนาดเอาต์พุตลงครึ่งหนึ่ง |
| **การเสริม** | เพิ่มศูนย์รอบๆ เส้นขอบเพื่อรักษามิติเชิงพื้นที่ |
| **จำนวนตัวกรอง** | ฟิลเตอร์แต่ละตัวจะเรียนรู้คุณสมบัติที่แตกต่างกัน (ขอบ พื้นผิว รูปแบบสี) |
### เรียนรู้อะไรเกี่ยวกับ Convolutions
| ความลึกของชั้น | ตรวจพบคุณสมบัติ |
|-----------------|------------------|
| **ชั้นต้น** | ขอบ มุม พื้นผิวเรียบๆ |
| **ชั้นกลาง** | รูปทรง ส่วนต่างๆ ของวัตถุ (ล้อ ตา ใบไม้) |
| **ชั้นลึก** | แนวคิดระดับสูง (ใบหน้า รถ สัตว์) |

## สถาปัตยกรรมของ CNN
วิวัฒนาการของสถาปัตยกรรมของ CNN บอกเล่าเรื่องราวของความก้าวหน้าของการเรียนรู้เชิงลึกในด้านคอมพิวเตอร์วิทัศน์
| สถาปัตยกรรม | ปี | นวัตกรรมที่สำคัญ |
|-----------------|-|---------------|
| **เลอเน็ต-5** | 1998 | ซีเอ็นเอ็นเชิงปฏิบัติครั้งแรก; การรู้จำตัวเลข |
| **อเล็กซ์เน็ต** | 2555 | Deep CNN ชนะ ImageNet; ReLU, การออกกลางคัน, การฝึกอบรม GPU |
| **VGGNet** | 2014 | ซ้อน 3 × 3 convolutions (ลึก = ดีกว่า) |
| **GoogLeNet (เริ่มต้น)** | 2014 | โมดูลการเริ่มต้น (ขนาดตัวกรองแบบขนาน); 22 ชั้น |
| **เรสเน็ต** | 2558 | ข้ามการเชื่อมต่อ (การเรียนรู้ที่เหลือ); 152+ เลเยอร์ |
| **EfficientNet** | 2019 | การปรับขนาดแบบผสม (ความลึก + ความกว้าง + ความละเอียด) |
| **ConvNeXt** | 2022 | ResNet ที่ทันสมัย; แข่งขันกับ Transformers |
### ทำไม ResNet ถึงเปลี่ยนแปลงทุกอย่าง
ก่อน ResNet การฝึกอบรมเครือข่ายที่ลึกมากแทบจะเป็นไปไม่ได้เลยเนื่องจากปัญหาการไล่ระดับสีที่หายไป ResNet เปิดตัว **ข้ามการเชื่อมต่อ** (หรือที่เรียกว่าการเชื่อมต่อที่เหลือ): อินพุตไปยังเลเยอร์จะถูกเพิ่มไปยังเอาต์พุต
```
output = F(x) + x    # Skip connection
```

แนวคิดง่ายๆ นี้ช่วยให้เครือข่ายที่มีเลเยอร์มากกว่า 152 เลเยอร์ได้รับการฝึกอบรมอย่างมีประสิทธิภาพ และตอนนี้ก็เป็นมาตรฐานในสถาปัตยกรรมเชิงลึกเกือบทั้งหมดแล้ว

## งานวิสัยทัศน์หลัก
### การจำแนกประเภทภาพ
กำหนดป้ายกำกับให้กับรูปภาพทั้งหมด
| รุ่น | วิธีการ |
|-------|----------|
| ซีเอ็นเอ็น (ResNet, EfficientNet) | แนวทางดั้งเดิม ความแม่นยำดีเยี่ยม |
| วิชั่นทรานส์ฟอร์มเมอร์ส (ViT) | ถือว่าภาพเป็นลำดับของแพตช์ ตัวเข้ารหัสหม้อแปลงไฟฟ้า |
| ถ่ายทอดการเรียนรู้ | ปรับแต่งโมเดลที่ได้รับการฝึกล่วงหน้าบนชุดข้อมูลของคุณ |
### การตรวจจับวัตถุ
ค้นหาและจัดประเภทวัตถุหลายรายการภายในภาพด้วยกล่องขอบ
| รุ่น | พิมพ์ | ความเร็ว |
|-------|-------|-------|
| **R-CNN** | สองขั้นตอน (ข้อเสนอ + การจำแนกประเภท) | ช้า |
| **ด่วน R-CNN** | ปรับปรุงสองขั้นตอน | ปานกลาง |
| **R-CNN เร็วขึ้น** | เครือข่ายข้อเสนอภูมิภาค + ตัวตรวจจับ | ปานกลาง |
| **โยโล** (v1–v10) | ขั้นตอนเดียว; ทำนายกล่อง+คลาสในหนึ่งรอบ | เร็วมาก |
| **DETR** | ที่ใช้หม้อแปลงไฟฟ้า; ไม่มีกล่องสมอ | ปานกลาง |
**YOLO** (คุณดูเพียงครั้งเดียว) เป็นสิ่งที่ต้องทำสำหรับการตรวจจับแบบเรียลไทม์ **แนะนำให้ใช้ R-CNN ที่เร็วกว่า** เมื่อความแม่นยำมีความสำคัญมากกว่าความเร็ว
### การแบ่งส่วนรูปภาพ
จำแนกทุกพิกเซลในภาพ
| พิมพ์ | คำอธิบาย | ใช้กรณี |
|------|-------------|----------|
| **การแบ่งส่วนความหมาย** | แต่ละพิกเซลจะมีป้ายกำกับคลาส | การขับขี่อัตโนมัติ (ถนน รถยนต์ คนเดินเท้า) |
| **การแบ่งส่วนอินสแตนซ์** | ID อินสแตนซ์ของพิกเซล + วัตถุแต่ละรายการ | การนับวัตถุ การถ่ายภาพทางการแพทย์ |
| **การแบ่งส่วนแบบ Panoptic** | ความหมาย + อินสแตนซ์รวม | ความเข้าใจฉากที่ครอบคลุม |
โมเดลหลัก: U-Net (การถ่ายภาพทางการแพทย์), Mask R-CNN (อินสแตนซ์), DeepLab (ความหมาย), Segment Anything Model (SAM - การแบ่งส่วนสากล)
### การสร้างภาพ
| วิธีการ | คำอธิบาย | ตัวอย่าง |
|----------|-------------|----------|
| **GAN** | การฝึกอบรมปฏิปักษ์ระหว่างเครื่องปั่นไฟกับผู้แบ่งแยก | StyleGAN, CycleGAN |
| **VAE** | เรียนรู้การกระจายแฝง ตัวอย่างเพื่อสร้าง | ตัวเข้ารหัสอัตโนมัติแบบต่างๆ |
| **แบบจำลองการแพร่กระจาย** | ลดเสียงรบกวนแบบสุ่มซ้ำๆ | การแพร่กระจายที่เสถียร, DALL-E, Midjourney |
โมเดลการแพร่กระจายมีมากกว่า GANs อย่างมากในด้านคุณภาพการสร้างภาพ

## ถ่ายทอดการเรียนรู้เพื่อวิสัยทัศน์
การฝึกอบรม CNN ตั้งแต่เริ่มต้นต้องใช้ข้อมูลและการประมวลผลจำนวนมหาศาล การเรียนรู้แบบถ่ายโอนช่วยให้คุณเริ่มต้นด้วยโมเดลที่ได้รับการฝึกอบรมเกี่ยวกับรูปภาพนับล้านภาพ (ImageNet) แล้ว และปรับแต่งให้เหมาะกับงานเฉพาะของคุณ
### ขั้นตอน
1. **เลือกรุ่นที่ผ่านการฝึกอบรมมาแล้ว** (ResNet50, EfficientNet-B0, ViT)
2. **แทนที่ส่วนหัวการจัดหมวดหมู่** ด้วยของคุณเอง (ตรงกับจำนวนคลาสของคุณ)
3. **ตรึงเลเยอร์แรกๆ** (โดยจะบันทึกคุณลักษณะทั่วไป เช่น ขอบ)
4. **ปรับแต่ง** บนชุดข้อมูลของคุณด้วยอัตราการเรียนรู้ต่ำ
5. **ค่อยๆ คลายน้ำแข็ง** หากคุณต้องการปรับตัวเพิ่มเติม
วิธีการนี้ทำให้ได้ความแม่นยำสูงเป็นประจำโดยมีรูปภาพที่มีป้ายกำกับเพียง 1,000–10,000 ภาพ
---

## การเพิ่มข้อมูล
Augmentation จะขยายชุดข้อมูลการฝึกของคุณโดยไม่ตั้งใจโดยใช้การแปลง
| การเสริม | เอฟเฟกต์ | เมื่อใดควรใช้ |
|-------------|--------|-------------|
| **ครอบตัดแบบสุ่ม** | ครอบตัดเป็นภูมิภาคสุ่ม | เกือบทุกครั้ง |
| **พลิกแนวนอน** | ภาพสะท้อนในกระจก | เมื่อการวางแนวไม่สำคัญ |
| **การหมุน** | หมุนตามมุมสุ่ม | เมื่อวัตถุปรากฏที่มุมใดมุมหนึ่ง |
| **สีกระวนกระวายใจ** | สุ่มปรับความสว่าง คอนทราสต์ ความอิ่มตัว | เมื่อแสงสว่างเปลี่ยนไป |
| **สุ่มลบ** | มาสก์ภูมิภาคสุ่ม | ปรับปรุงความทนทาน |
| **มิกซ์อัพ / CutMix** | ผสมผสานสองภาพและป้ายกำกับ | การทำให้เป็นมาตรฐาน |
ไลบรารี:`torchvision.transforms`,`albumentations`,`imgaug`,`tf.keras.preprocessing`.

## เคล็ดลับการปฏิบัติ
- **เริ่มต้นด้วยการถ่ายโอนการเรียนรู้** การปรับแต่งโมเดลที่ได้รับการฝึกล่วงหน้าอย่างละเอียดจะเหนือกว่าการฝึกตั้งแต่เริ่มต้นในเกือบทุกกรณี
- **ทำให้อินพุตของคุณเป็นมาตรฐาน** จับคู่การทำให้เป็นมาตรฐานตามที่โมเดลที่ได้รับการฝึกล่วงหน้าคาดหวัง (โดยปกติคือ ImageNet ค่าเฉลี่ย/มาตรฐาน)
- **ใช้ตัวชี้วัดที่เหมาะสม** ความแม่นยำของชุดข้อมูลที่สมดุล F1, mAP หรือ IoU สำหรับงานที่ไม่สมดุลหรือการตรวจจับ
- **แสดงข้อมูลของคุณเป็นภาพ** ดูภาพตัวอย่าง ตรวจสอบการแจกแจงของคลาส ตรวจสอบการทำนายแบบจำลอง
- **เพิ่มพูนอย่างชาญฉลาด** ใช้เฉพาะการแปลงที่เหมาะกับโดเมนของคุณเท่านั้น (อย่าพลิกรูปภาพทางการแพทย์ในแนวตั้ง)
- **ตรวจสอบการออกกำลังกายมากเกินไป** หากความแม่นยำในการฝึกสูงแต่การตรวจสอบความถูกต้องต่ำ ให้เพิ่มส่วนเสริมหรือเพิ่มการออกกลางคัน
