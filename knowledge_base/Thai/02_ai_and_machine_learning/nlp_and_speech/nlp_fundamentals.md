#ความรู้พื้นฐาน NLP
การประมวลผลภาษาธรรมชาติ (NLP) เป็นสาขาหนึ่งของเครื่องจักรการสอนเพื่อทำความเข้าใจ สร้างสรรค์ และทำงานกับภาษามนุษย์ โดยขับเคลื่อนเครื่องมือค้นหา แชทบอท ระบบการแปล การวิเคราะห์ความรู้สึก และโมเดลภาษาขนาดใหญ่ (LLM) ที่เปลี่ยนแปลง AI มาตั้งแต่ปี 2020 ไฟล์นี้ครอบคลุมวิวัฒนาการจากเทคนิคคลาสสิกไปจนถึงสถาปัตยกรรมที่ใช้ Transformer สมัยใหม่
---

## การประมวลผลข้อความล่วงหน้า
ข้อความดิบไม่เป็นระเบียบ ก่อนที่แบบจำลองจะสามารถใช้งานได้ จะต้องทำความสะอาดและสร้างโครงสร้างก่อน
| ขั้นตอน | มันทำอะไร | ตัวอย่าง |
|------|-------------|---------|
| **การแปลงโทเค็น** | แบ่งข้อความออกเป็นโทเค็น (คำ คำย่อย หรืออักขระ) | "ฉันรัก NLP" →`["I", "love", "NLP"]`|
| **ตัวพิมพ์เล็ก** | แปลงเป็นตัวพิมพ์เล็ก | "สวัสดี" → "สวัสดี" |
| **หยุดการลบคำ** | ลบคำทั่วไป (the, is, at) | "แมวนั่ง" → "แมวนั่ง" |
| **การกั้นขวาง** | สับคำลงท้าย (ดิบ) | "วิ่ง" → "วิ่ง" |
| **การย่อคำ** | ลดเป็นรูปแบบพจนานุกรม (รับรู้บริบท) | "ดีกว่า" → "ดี" |
| **การทำให้เป็นมาตรฐาน** | แก้ไขการเข้ารหัส ลบตัวอักษรพิเศษ ขยายการย่อ | "อย่า" → "อย่า" |
โมเดล Transformer สมัยใหม่มักจะข้ามการหยุดการลบคำและการกั้นคำ — โดยจะเรียนรู้รูปแบบเหล่านี้จากข้อมูล
---

## การแสดงข้อความ
เครื่องจักรต้องการตัวเลข ไม่ใช่คำพูด วิธีที่เราแสดงข้อความในรูปแบบเวกเตอร์ถือเป็นพื้นฐาน
### แนวทางคลาสสิก
| วิธีการ | คำอธิบาย | ข้อจำกัด |
|----------------------|-------------|-----------|
| **การเข้ารหัสแบบร้อนแรง** | แต่ละคำมีตำแหน่งที่ไม่ซ้ำกันในเวกเตอร์ขนาดใหญ่ | เบาบาง; ไม่มีความหมายเชิงความหมาย |
| **ถุงคำ (BoW)** | นับความถี่คำ เพิกเฉยต่อคำสั่ง | สูญเสียลำดับคำทั้งหมด |
| **TF-IDF** | น้ำหนักคำตามความถี่ในเอกสาร × ความหายากในคลังข้อมูล | ยังคงละเว้นลำดับและบริบท |
### การฝังคำ
การฝังจะจับคู่คำกับเวกเตอร์หนาแน่นซึ่งมีคำที่คล้ายกันอยู่ใกล้กัน
| รุ่น | แนวคิดหลัก |
|-------|----------|
| **Word2Vec** (2013) | ทำนายคำจากบริบท (CBOW) หรือบริบทจากคำ (ข้ามกรัม) |
| **ถุงมือ** (2014) | สถิติการเกิดร่วมทั่วโลก → เวกเตอร์หนาแน่น |
| **ข้อความด่วน** (2016) | Word2Vec + ข้อมูลคำย่อย (จัดการคำหายากได้ดีกว่า) |
ตัวอย่างที่มีชื่อเสียง:`king - man + woman ≈ queen`การฝังจะจับความสัมพันธ์เชิงความหมาย
**ข้อจำกัด**: การฝังแบบคลาสสิกจะกำหนดเวกเตอร์หนึ่งตัวต่อคำ ดังนั้นจึงไม่สามารถจัดการกับคำหลายคำได้ (คำที่มีความหมายหลากหลาย) "ธนาคาร" ใน "ริมฝั่งแม่น้ำ" และ "บัญชีธนาคาร" มีเวกเตอร์เดียวกัน
---

## แบบจำลองลำดับ
ก่อน Transformers แนวทางมาตรฐานสำหรับ NLP คือการประมวลผลข้อความตามลำดับ
| สถาปัตยกรรม | มันทำงานอย่างไร | ความแข็งแกร่ง | จุดอ่อน |
|-------------|-------------|----------|----------|
| **อาร์เอ็นเอ็น** | ประมวลผลโทเค็นทีละครั้ง รักษาสถานะที่ซ่อนอยู่ | จัดการอินพุตที่มีความยาวผันแปรได้ | การไล่ระดับสีที่หายไป; ไม่สามารถบันทึกการพึ่งพาที่ยาวนาน |
| **LSTM** | RNN พร้อมเกต (ลืม อินพุต เอาต์พุต) เพื่อควบคุมการไหลของข้อมูล | ดีกว่าในการพึ่งพาระยะยาว | ยังคงต่อเนื่องกัน; ฝึกช้า |
| **กรู** | LSTM แบบง่าย (ประตูน้อยลง) | เร็วกว่า LSTM; ประสิทธิภาพใกล้เคียงกัน | ข้อจำกัดพื้นฐานเดียวกัน |
โมเดลเหล่านี้ประมวลผลข้อความจากซ้ายไปขวา ซึ่งหมายความว่าจะฝึกได้ช้า (ไม่สามารถเทียบเคียงได้) และประสบปัญหากับการขึ้นต่อกันในระยะยาว
---

## กลไกความสนใจ
ความสนใจช่วยให้แบบจำลองดูตำแหน่งทั้งหมดในลำดับพร้อมกัน และตัดสินใจว่าตำแหน่งใดที่เกี่ยวข้องกับการคาดการณ์ในปัจจุบันมากที่สุด
### ข้อมูลเชิงลึกที่สำคัญ
แทนที่จะบีบอัดประโยคทั้งหมดให้เป็นสถานะที่ซ่อนอยู่สถานะเดียว (เช่นเดียวกับที่ RNN ทำ) ความสนใจจะคำนวณผลรวมแบบถ่วงน้ำหนักของสถานะที่ซ่อนอยู่ทั้งหมด ซึ่งเป็นที่ที่การเรียนรู้น้ำหนัก
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

| ส่วนประกอบ | บทบาท |
|-----------|-|
| **แบบสอบถาม (ถาม)** | ฉันกำลังมองหาอะไร? |
| **คีย์ (K)** | ฉันประกอบด้วยอะไรบ้าง? |
| **ค่า (V)** | ฉันให้ข้อมูลอะไรบ้าง? |
| **√d_k** | ปัจจัยการปรับขนาดเพื่อป้องกันผลิตภัณฑ์จุดขนาดใหญ่ |
---

## สถาปัตยกรรมหม้อแปลงไฟฟ้า
The Transformer (Vaswani et al., 2017 — "Attention Is All You Need") แทนที่การเกิดซ้ำทั้งหมดด้วยความสนใจ เป็นรากฐานของ NLP สมัยใหม่เกือบทั้งหมด
### สถาปัตยกรรม
| ส่วนประกอบ | คำอธิบาย |
|-----------|-------------|
| **ตัวเข้ารหัส** | อ่านข้อความที่ป้อน สร้างการนำเสนอตามบริบท |
| **ตัวถอดรหัส** | สร้างข้อความเอาต์พุต เข้าร่วมกับเอาต์พุตตัวเข้ารหัส |
| **การเอาใจใส่ตนเอง** | โทเค็นแต่ละตัวจะเข้าร่วมกับโทเค็นอื่น ๆ ทั้งหมดในลำดับเดียวกัน |
| **ความสนใจแบบหลายหัว** | เรียกใช้หัวความสนใจหลายรายการพร้อมกัน จับความสัมพันธ์ที่แตกต่าง |
| **การเข้ารหัสตำแหน่ง** | แทรกข้อมูลตำแหน่ง (เนื่องจากไม่มีการเกิดซ้ำ) |
| **เครือข่ายฟีดส่งต่อ** | นำไปใช้กับแต่ละตำแหน่งโดยแยกจากกัน |
| **การทำให้เลเยอร์เป็นมาตรฐาน** | ทำให้การฝึกอบรมมีเสถียรภาพ |
| **การเชื่อมต่อที่เหลือ** | ข้ามการเชื่อมต่อสำหรับโฟลว์การไล่ระดับสี |
### ตัวเข้ารหัสเท่านั้น, ตัวถอดรหัสเท่านั้น, ตัวเข้ารหัส-ตัวถอดรหัส
| ตัวแปร | สถาปัตยกรรม | ดีที่สุดสำหรับ | ตัวอย่าง |
|---------|-------------|----------|---------|
| **ตัวเข้ารหัสเท่านั้น** | เข้าใจข้อความ | การจำแนกประเภท, NER, การวิเคราะห์ความรู้สึก | เบิร์ต, โรเบอร์ต้า, เดเบอร์ต้า |
| **ตัวถอดรหัสเท่านั้น** | สร้างข้อความ | โมเดลภาษา แชทบอท การสร้างโค้ด | GPT-3/4, ลามา, คลอดด์ |
| **ตัวเข้ารหัส-ตัวถอดรหัส** | แปลงข้อความ | การแปล การสรุป | T5, BART, เอ็มบาร์ต |

## ครอบครัวต้นแบบที่สำคัญ
### ตระกูล BERT (ตัวเข้ารหัสเท่านั้น)
| รุ่น | คุณสมบัติที่สำคัญ |
|-------|-------------|
| **เบิร์ต** (2018) | โมเดลภาษามาสก์ + การทำนายประโยคถัดไป |
| **โรเบอร์ต้า** | ลบ NSP; ฝึกฝนได้นานขึ้นด้วยข้อมูลที่มากขึ้น |
| **อัลเบิร์ต** | การแชร์พารามิเตอร์ รอยเท้าที่เล็กลง |
| **เดอเบอร์ต้า** | ความสนใจที่ไม่เป็นระเบียบ; ปรับปรุง NLU |
| **ดิสทิลเบิร์ต** | เล็กลง 40% เร็วขึ้น 60% คงประสิทธิภาพของ BERT ไว้ 97%
### ตระกูล GPT (ตัวถอดรหัสเท่านั้น)
| รุ่น | พารามิเตอร์ | หมายเหตุ |
|-------|-----------|-------|
| **GPT-2** | 1.5B | โมเดลเฉพาะตัวถอดรหัสที่แสดงสามารถสร้างข้อความที่สอดคล้องกัน |
| **GPT-3** | 175B | การเรียนรู้แบบไม่กี่ช็อต ได้รับแจ้งแทนที่จะปรับแต่ง |
| **GPT-3.5 / GPT-4** | ไม่เปิดเผย | ปรับคำสั่ง + RLHF; บทสนทนา |
| **LLaMA** (เมตา) | 7B–70B | เปิดน้ำหนัก; สร้างระบบนิเวศ LLM โอเพ่นซอร์ส |
| **มิสทรัล / มิกซ์ทรัล** | 7B / 8×7B (โมอี) | รุ่นเปิดที่มีประสิทธิภาพพร้อมประสิทธิภาพที่แข็งแกร่ง |

## งาน NLP หลัก
| งาน | คำอธิบาย | รุ่นทั่วไป |
|------|-------------|--------------|
| **การจัดหมวดหมู่ข้อความ** | กำหนดป้ายกำกับให้กับข้อความ (สแปม/ไม่ใช่สแปม บวก/ลบ) | BERT ตัวแยกประเภทที่ปรับแต่งอย่างดี |
| **การจดจำเอนทิตีที่มีชื่อ (NER)** | ระบุบุคคล องค์กร สถานที่ ในข้อความ | เลเยอร์ BERT + CRF |
| **การวิเคราะห์ความรู้สึก** | กำหนดอารมณ์ | BERT ที่ปรับแต่งแล้วหรือ Zero-shot LLM |
| **การแปลด้วยเครื่อง** | แปลระหว่างภาษา | T5, mBART, MarianMT |
| **ตอบคำถาม** | ตอบคำถามตามบริบท | BERT (สกัด), GPT (กำเนิด) |
| **สรุป** | ย่อข้อความยาว | T5, BART, GPT |
| **การสร้างข้อความ** | สร้างข้อความที่สอดคล้องกัน | GPT-4, LLaMA, คลอดด์ |

## การปรับแต่งแบบละเอียดเทียบกับการแจ้ง
| วิธีการ | มันทำงานอย่างไร | เมื่อใดควรใช้ |
|----------|-------------|-------------|
| **การปรับแบบละเอียด** | อัปเดตน้ำหนักโมเดลในข้อมูลเฉพาะงานของคุณ | คุณได้ติดป้ายกำกับข้อมูลแล้ว ต้องการประสิทธิภาพสูงสุด |
| **แจ้ง** | ให้คำแนะนำโมเดลในภาษาธรรมชาติ | การสร้างต้นแบบอย่างรวดเร็ว ข้อมูลที่จำกัด; การใช้ LLM |
| **ไม่กี่ช็อต** | รวมตัวอย่างในพรอมต์ | เมื่อคุณมีตัวอย่างบางส่วนแต่ไม่เพียงพอสำหรับการปรับแต่ง |
| **LoRA / QLoRA** | การปรับแต่งที่มีประสิทธิภาพ อัปเดตเมทริกซ์อันดับต่ำขนาดเล็ก | ปรับแต่งโมเดลขนาดใหญ่ที่มีหน่วยความจำ GPU ที่จำกัด |

## เครื่องมือและกรอบการทำงาน
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **กอดหน้าหม้อแปลง** | โมเดลที่ได้รับการฝึกอบรมล่วงหน้า โทเค็นเซอร์ ไปป์ไลน์การปรับแต่ง |
| **สปาซี** | ไปป์ไลน์ NLP ระดับการผลิต (โทเค็น, NER, POS, การพึ่งพา) |
| **NLTK** | ทางการศึกษา; อัลกอริธึม NLP แบบคลาสสิก |
| **เกนซิม** | การสร้างแบบจำลองหัวข้อ (LDA), การฝังคำ (Word2Vec, Doc2Vec) |
| **LangChain / LlamaIndex** | กรอบงานสำหรับการสร้างแอปพลิเคชันที่ขับเคลื่อนด้วย LLM |
| **vLLM** | การให้บริการ LLM ความเร็วสูง |
| **โทเค็นไนเซอร์ (HF)** | การสร้างโทเค็นอย่างรวดเร็ว (BPE, Word Piece, Sentence Piece) |

## ภูมิทัศน์ LLM
ภูมิทัศน์ NLP สมัยใหม่ถูกครอบงำโดยโมเดลภาษาขนาดใหญ่:
| หมวดหมู่ | ตัวอย่าง | หมายเหตุ |
|----------|---------|--------|
