# การเรียนรู้แบบเสริมกำลัง
การเรียนรู้แบบเสริมกำลัง (RL) เป็นวิธีที่เครื่องจักรเรียนรู้เพื่อสร้างลำดับการตัดสินใจโดยการลองผิดลองถูก ต่างจากการเรียนรู้แบบมีผู้สอนซึ่งมีคำตอบที่ถูกต้องให้กับทุกตัวอย่าง RL ให้สัญญาณรางวัลแก่ตัวแทนเท่านั้น และตัวแทนจะต้องพิจารณาว่าการกระทำใดนำไปสู่ผลลัพธ์ที่ดีที่สุดเมื่อเวลาผ่านไป เป็นแนวทางที่อยู่เบื้องหลัง AlphaGo การควบคุมด้วยหุ่นยนต์ AI ในการเล่นเกม และที่สำคัญคือ RLHF ซึ่งเป็นเทคนิคที่ใช้ในการจัดวางโมเดลภาษาขนาดใหญ่สมัยใหม่ให้สอดคล้องกับความชอบของมนุษย์
---

## แนวคิดหลัก
RL วางกรอบการตัดสินใจเป็นวงจรระหว่าง **ตัวแทน** และ **สภาพแวดล้อม**
| ส่วนประกอบ | บทบาท | ตัวอย่าง |
|----------|-|---------|
| **ตัวแทน** | ผู้มีอำนาจตัดสินใจ | โปรแกรมหมากรุก หุ่นยนต์ ภาษาจำลอง |
| **สิ่งแวดล้อม** | โลกที่ตัวแทนโต้ตอบด้วย | กระดานหมากรุก โกดัง บทสนทนา |
| **รัฐ** | สถานการณ์ปัจจุบัน | ตำแหน่งบอร์ด การอ่านเซ็นเซอร์หุ่นยนต์ ประวัติการสนทนา |
| **การกระทำ** | สิ่งที่ตัวแทนสามารถทำได้ | ย้ายชิ้นส่วน เลี้ยวซ้าย สร้างโทเค็น |
| **รางวัล** | สัญญาณตอบรับ (เลขสเกลาร์) | +1 สำหรับการชนะ -1 สำหรับการชน คะแนนความชอบของมนุษย์ |
| **นโยบาย** | การแม็ปกลยุทธ์ระบุถึงการดำเนินการ | “ถ้ากษัตริย์ถูกคุกคามก็ย้ายมันไป” |
| **ฟังก์ชันค่า** | คาดหวังผลตอบแทนสะสมจากรัฐ | “ตำแหน่งบอร์ดนี้มีค่าประมาณ +3 แต้ม” |
### วง RL
```
Agent observes State → chooses Action → Environment returns new State + Reward
        ↑                                                                         |
        └─────────────────────────────────────────────────────────────────────────┘
```

เป้าหมายของตัวแทนคือการเพิ่ม **รางวัลสะสม** สูงสุดเมื่อเวลาผ่านไป ไม่ใช่แค่รางวัลทันที นี่คือสิ่งที่ทำให้ RL แตกต่างโดยพื้นฐานจากการเรียนรู้แบบมีผู้สอน

| ด้าน | การเรียนรู้แบบมีผู้สอน | การเรียนรู้แบบไม่มีผู้ดูแล | การเรียนรู้แบบเสริมกำลัง |
|----------------------|-------------------|-----------|--------------------------------|
| **สัญญาณ** | ป้ายกำกับที่ถูกต้องสำหรับทุกตัวอย่าง | ไม่มีป้ายกำกับ ค้นหาโครงสร้าง | สเกลาร์รางวัลมักล่าช้า |

| **เป้าหมาย** | ลดข้อผิดพลาดในการทำนายให้เหลือน้อยที่สุด | ค้นพบรูปแบบ | เพิ่มผลตอบแทนสะสมสูงสุด |

## กระบวนการตัดสินใจของมาร์คอฟ (MDP)
MDP เป็นกรอบทางคณิตศาสตร์สำหรับ RL พวกเขาถือว่าอนาคตขึ้นอยู่กับสถานะปัจจุบันเท่านั้น ไม่ใช่ประวัติว่าคุณไปถึงที่นั่นได้อย่างไร (**ทรัพย์สินของ Markov**)
| ส่วนประกอบ | สัญกรณ์ | ความหมาย |
|----------|----------|---------|
| **รัฐ** | ส | สถานการณ์ที่เป็นไปได้ทั้งหมดที่ตัวแทนสามารถอยู่ใน |
| **การดำเนินการ** | ก | ทุกสิ่งที่ตัวแทนทำได้ |
| **ฟังก์ชันการเปลี่ยนผ่าน** | P(s' \| s, a) | ความน่าจะเป็นที่จะถึงสถานะ s' หลังจากดำเนินการ a ในสถานะ s |
| **ฟังก์ชั่นรางวัล** | R(s, a, s') | รางวัลที่ได้รับสำหรับการเปลี่ยนแปลง |
| **ปัจจัยส่วนลด** | γ (แกมมา) | มูลค่ารางวัลในอนาคตเทียบกับรางวัลทันที (0 ต่อ 1) เท่าไหร่ |
**ผลตอบแทน** (รางวัลที่ลดราคาทั้งหมด) คือ:
```
G = R₁ + γR₂ + γ²R₃ + ...
```

ปัจจัยคิดลดที่สูง (γ ใกล้ 1) หมายความว่าตัวแทนมีสายตายาว ต่ำหมายถึงสายตาสั้น

## อัลกอริธึม RL แบบคลาสสิก
### วิธีการตามมูลค่า
สิ่งเหล่านี้เรียนรู้ว่าแต่ละรัฐ (หรือคู่การกระทำของรัฐ) ดีเพียงใด
| อัลกอริทึม | แนวคิดหลัก | ข้อจำกัด |
|----------|----------|------------|
| **Q-การเรียนรู้** | เรียนรู้ตารางค่า Q: Q(สถานะ, การกระทำ) = รางวัลที่คาดหวัง | ไม่ปรับขนาดเป็นพื้นที่รัฐขนาดใหญ่ |
| **Deep Q-Network (DQN)** | ใช้โครงข่ายประสาทเทียมเพื่อประมาณค่า Q | จัดการเฉพาะการดำเนินการที่ไม่ต่อเนื่องเท่านั้น อาจไม่เสถียร |
| **ดับเบิล DQN** | แก้ไขอคติในการประเมินค่าสูงเกินไปของ Q-learning | ยังคงจำกัดอยู่ที่การดำเนินการที่ไม่ต่อเนื่อง |
กฎการอัปเดต Q-learning:
```
Q(s, a) ← Q(s, a) + α [r + γ max Q(s', a') - Q(s, a)]
```

### วิธีการตามนโยบาย
สิ่งเหล่านี้เรียนรู้นโยบาย (กลยุทธ์) โดยตรงโดยไม่ต้องประมาณค่า
| อัลกอริทึม | แนวคิดหลัก | ข้อได้เปรียบ |
|----------|----------|-----------|
| **เสริมกำลัง** | การไล่ระดับนโยบายมอนติคาร์โล ปรับปรุงนโยบายมุ่งสู่ผลลัพธ์ที่ดี | เรียบง่าย; ทำงานร่วมกับการกระทำต่อเนื่อง |
| **PPO** (การเพิ่มประสิทธิภาพนโยบายใกล้เคียง) | อัปเดตนโยบายคลิปเพื่อป้องกันการเปลี่ยนแปลงขนาดใหญ่ที่ไม่เสถียร | มั่นคง; ใช้กันอย่างแพร่หลาย; ค่าเริ่มต้นที่ดี |
| **ธปท.** | วิธีภูมิภาคที่เชื่อถือได้สำหรับการอัปเดตนโยบาย | มีหลักการมากกว่า PPO ยากที่จะนำไปใช้ |
### วิธีการนักแสดง-นักวิจารณ์
รวมสิ่งที่ดีที่สุดของทั้งสอง: **นักแสดง** (นโยบาย) และ **นักวิจารณ์** (ฟังก์ชันคุณค่า)
| อัลกอริทึม | แนวคิดหลัก |
|----------|----------|
| **A2C / A3C** | ข้อได้เปรียบ นักแสดง-นักวิจารณ์; ใช้การประมาณค่าความได้เปรียบเพื่อลดความแปรปรวน |
| **SAC** (ซอฟท์นักแสดง-นักวิจารณ์) | เพิ่มรางวัลสูงสุดในขณะที่ยังคงการสำรวจ (การทำให้เป็นมาตรฐานของเอนโทรปี) |
| **TD3** (DDPG ล่าช้าคู่) | จัดการกับการประมาณค่าสูงเกินไปในพื้นที่การดำเนินการต่อเนื่อง |

## RLHF: การเรียนรู้แบบเสริมแรงจากผลตอบรับของมนุษย์
RLHF เป็นเทคนิคที่ทำให้ ChatGPT เป็นไปได้ โดยเชื่อมช่องว่างระหว่างแบบจำลองที่สามารถคาดเดาข้อความกับแบบจำลองที่สร้างผลลัพธ์ที่มนุษย์พบว่ามีประโยชน์จริง ๆ
### สามขั้นตอน
| ขั้นตอน | เกิดอะไรขึ้น | เอาท์พุท |
|------|-------------|--------|
| **1. การปรับแต่งแบบละเอียดภายใต้การดูแล (SFT)** | ปรับแต่งโมเดลที่ได้รับการฝึกอบรมล่วงหน้าเกี่ยวกับตัวอย่างคุณภาพสูงที่เขียนโดยมนุษย์ | โมเดลที่ทำตามคำแนะนำได้ดีพอสมควร |
| **2. การฝึกอบรมโมเดลรางวัล** | มนุษย์เปรียบเทียบคู่ของเอาท์พุตโมเดล ฝึกแบบจำลองเพื่อทำนายความชอบของมนุษย์ | โมเดลการให้รางวัลที่ให้คะแนนคุณภาพผลผลิต |
| **3. การเพิ่มประสิทธิภาพ RL** | ใช้ PPO เพื่อปรับแต่งโมเดล SFT เพื่อเพิ่มคะแนนของโมเดลรางวัลให้สูงสุด | แบบจำลองที่สอดคล้องกับความชอบของมนุษย์ |
### ทำไม RLHF จึงมีความสำคัญ
หากไม่มี RLHF โมเดลภาษาก็เหมือนกับนักเรียนที่อ่านหนังสือทุกเล่มแต่ไม่รู้ว่าจะประพฤติตัวอย่างไรในการสนทนา อาจสร้างข้อความได้ แต่ข้อความอาจไม่มีประโยชน์ เป็นพิษ หรือพลาดประเด็นไปโดยสิ้นเชิง RLHF สอนโมเดล *สิ่งที่มนุษย์ต้องการ* ไม่ใช่แค่หน้าตาของข้อความเท่านั้น
### ตัวแปรและทางเลือก
| วิธีการ | คำอธิบาย | ข้อได้เปรียบ |
|----------------------|-------------|-----------|
| **DPO** (การเพิ่มประสิทธิภาพการตั้งค่าโดยตรง) | ข้ามรูปแบบการให้รางวัล เพิ่มประสิทธิภาพนโยบายโดยตรงจากการตั้งค่าของมนุษย์ | ง่ายกว่า; ไม่มีรูปแบบการให้รางวัลแยกต่างหากในการฝึก |
| **RLAIF** | ใช้ AI (แทนที่จะเป็นมนุษย์) เพื่อสร้างป้ายกำกับการตั้งค่า | ราคาถูกกว่าการติดฉลากคน |
| **AI รัฐธรรมนูญ** | ใช้ชุดหลักการเพื่อเป็นแนวทางในการทำงานของโมเดลโดยไม่มีป้ายกำกับของมนุษย์ | ปรับขนาดได้มากขึ้น แนวทางมานุษยวิทยา |
| **GRPO** (การเพิ่มประสิทธิภาพนโยบายแบบกลุ่มสัมพันธ์) | เปรียบเทียบเอาต์พุตภายในกลุ่มแทนที่จะเปรียบเทียบกับโมเดลที่แยกจากกัน | ใช้ใน DeepSeek-R1; ลดความต้องการเครือข่ายมูลค่า |

## การสำรวจและการแสวงหาผลประโยชน์
นี่คือความตึงเครียดส่วนกลางใน RL **การแสวงหาผลประโยชน์** หมายถึงการเลือกการกระทำที่คุณรู้ว่าใช้ได้ผลดี **การสำรวจ** หมายถึงการลองสิ่งใหม่ๆ เพื่อค้นพบกลยุทธ์ที่อาจดีกว่า
| กลยุทธ์ | มันทำงานอย่างไร | การแลกเปลี่ยน |
|----------|-------------|-----------|
| **ε-โลภ** | เลือกการกระทำที่ดีที่สุดเกือบตลอดเวลา การกระทำแบบสุ่มที่มีความน่าจะเป็น ε | เรียบง่ายแต่ไม่มีประสิทธิภาพ |
| **การสำรวจของ Boltzmann** | เลือกการดำเนินการตามความน่าจะเป็นโดยพิจารณาจากค่าประมาณ | เนียนกว่าε-โลภ |
| **UCB** (ขอบเขตความเชื่อมั่นขั้นสูง) | ชอบการกระทำที่มีความไม่แน่นอนสูง (การมองโลกในแง่ดีเมื่อเผชิญกับความไม่แน่นอน) | รับประกันตามทฤษฎีดี |
| **การทำให้เอนโทรปีเป็นมาตรฐาน** | เพิ่มโบนัสสำหรับการเยี่ยมชมรัฐต่างๆ (ใช้ใน SAC, PPO) | ส่งเสริมการสำรวจธรรมชาติ |

## การเรียนรู้การเสริมกำลังแบบหลายตัวแทน
เมื่อตัวแทนหลายคนเรียนรู้พร้อมกัน ไดนามิกจะซับซ้อนมากขึ้น
| สถานการณ์ | ท้าทาย | ตัวอย่าง |
|----------|-----------|---------|
| **สหกรณ์** | ตัวแทนจะต้องประสานงาน การให้เครดิตเป็นเรื่องยาก | ทีมฟุตบอลหุ่นยนต์ เครือข่ายเซ็นเซอร์แบบกระจาย |
| **การแข่งขัน** | ฝ่ายตรงข้ามปรับตัว สภาพแวดล้อมไม่นิ่ง | เกม AI (โป๊กเกอร์, สตาร์คราฟต์); ความปลอดภัยทางไซเบอร์ |
| **ผสม** | ตัวแทนบางคนร่วมมือกัน คนอื่นแข่งขันกัน | ตลาดประมูล ระบบจราจร |
| อัลกอริทึม | คำอธิบาย |
|-----------|-------------|
| **MADDPG** | DDPG เวอร์ชันหลายเอเจนต์ นักวิจารณ์แบบรวมศูนย์, นักแสดงแบบกระจายอำนาจ |
| **แมปโป** | PPO หลายตัวแทน; ใช้กันอย่างแพร่หลายในทางปฏิบัติ |
| **เล่นเอง** | ตัวแทนฝึกต่อต้านสำเนาของตัวเอง (AlphaGo, AlphaStar) |

## โอนซิมไปจริง
การฝึกหุ่นยนต์ในโลกแห่งความเป็นจริงนั้นช้าและอันตราย เจ้าหน้าที่จะฝึกฝนการจำลองและถ่ายทอดสู่ความเป็นจริงแทน
| ท้าทาย | โซลูชั่น |
|----------|----------|
| **ช่องว่างความเป็นจริง** (การจำลอง ≠ โลกแห่งความเป็นจริง) | การสุ่มโดเมน: เปลี่ยนแปลงพารามิเตอร์ทางฟิสิกส์ระหว่างการฝึก |
| **ตัวอย่างความไร้ประสิทธิภาพ** | ใช้ RL ตามโมเดลหรือฝึกในการจำลองแบบคู่ขนานขนาดใหญ่ |
| **ความปลอดภัย** | RL ที่จำกัด: ลงโทษการกระทำที่ไม่ปลอดภัยระหว่างการฝึกอบรม |
| **การสังเกตได้บางส่วน** | ฝึกด้วยเซ็นเซอร์ที่มีเสียงดังและการสังเกตล่าช้า |
บริษัทต่างๆ เช่น Boston Dynamics และ Tesla ใช้การจำลองอย่างกว้างขวาง แต่ช่องว่างระหว่างประสิทธิภาพการจำลองและทางกายภาพยังคงเป็นหนึ่งในความท้าทายที่ใหญ่ที่สุดในภาคสนาม

## เครื่องมือและกรอบการทำงาน
| เครื่องมือ | วัตถุประสงค์ | ดีที่สุดสำหรับ |
|------|---------|----------|
| **เส้นฐานที่เสถียร3** | ทำความสะอาดการใช้งาน Python ของ PPO, SAC, TD3, DQN | การเรียนรู้และสร้างต้นแบบ |
| **RLlib** | ไลบรารี RL ที่ปรับขนาดได้ที่สร้างขึ้นบน Ray | การฝึกอบรมแบบกระจายขนาดใหญ่ |
| **CleanRL** | การใช้งานไฟล์เดียวสำหรับการวิจัย | ทำความเข้าใจอัลกอริธึมอย่างลึกซึ้ง |
| **ยิมเนเซียม (OpenAI)** | อินเทอร์เฟซสภาพแวดล้อมมาตรฐาน | การกำหนดปัญหา RL |
| **ไอแซคยิม / ไอแซคแล็บ** | การจำลองทางฟิสิกส์ที่เร่งด้วย GPU | หุ่นยนต์ จำลองสู่จริง |
| **TRL** (ไลบรารี Transformer RL) | RLHF, DPO, PPO สำหรับโมเดลภาษา | การจัดตำแหน่ง LLM |
| **OpenRLHF** | กรอบงาน RLHF แบบกระจาย | ฝึกอบรมโมเดลขนาดใหญ่ด้วย RLHF |

## เคล็ดลับการปฏิบัติ
- **เริ่มต้นด้วย PPO** เป็นอัลกอริธึมสำหรับวัตถุประสงค์ทั่วไปที่น่าเชื่อถือที่สุด หากคุณไม่แน่ใจว่าจะใช้อะไร PPO จะเป็นค่าเริ่มต้น
- **ทำให้รางวัลของคุณเป็นปกติ** การปรับขนาดรางวัลส่งผลต่อความเสถียรของการฝึกเป็นอย่างมาก
- **ใช้สภาพแวดล้อมแบบเวกเตอร์** การเรียกใช้สภาพแวดล้อมหลายรายการพร้อมกัน (เช่น 8–64) จะทำให้การประมาณความลาดชันคงที่และเพิ่มความเร็วในการฝึกฝนได้อย่างมาก
- **ตรวจสอบทั้งรางวัลและเอนโทรปี** หากเอนโทรปีลดลงเหลือศูนย์ แสดงว่าตัวแทนของคุณหยุดการสำรวจและอาจติดอยู่ในค่าที่เหมาะสมที่สุดในท้องถิ่น
- **การกำหนดรูปแบบรางวัลเป็นศิลปะ** การออกแบบฟังก์ชันการให้รางวัลที่ถูกต้องมักเป็นส่วนที่ยากที่สุด รางวัลน้อยชิ้น (เฉพาะตอนท้าย) ทำให้การเรียนรู้ช้ามาก รางวัลที่หนาแน่นและมีรูปร่างดีจะนำทางเจ้าหน้าที่ แต่อาจนำไปสู่พฤติกรรมที่ไม่ได้ตั้งใจได้
- **RLHF มีความเปราะบาง** การเปลี่ยนแปลงเล็กน้อยต่อโมเดลการให้รางวัลหรือไฮเปอร์พารามิเตอร์ PPO อาจทำให้คุณภาพลดลงอย่างมาก DPO เป็นทางเลือกที่มีความเสถียรมากกว่า หากคุณไม่ต้องการไปป์ไลน์ RLHF แบบเต็ม

## สรุป
การเรียนรู้แบบเสริมกำลังคือการศึกษาว่าตัวแทนเรียนรู้ที่จะตัดสินใจผ่านการมีปฏิสัมพันธ์ได้อย่างไร มีตั้งแต่อัลกอริธึมคลาสสิก เช่น Q-learning ไปจนถึงวิธี RL เชิงลึกสมัยใหม่ เช่น PPO และ SAC และเป็นรากฐานของความก้าวหน้าที่สำคัญที่สุดใน AI ตั้งแต่การเล่นเกมไปจนถึงการจัดตำแหน่งโมเดลภาษา ความท้าทายหลักยังคงเหมือนเดิม: คุณจะเรียนรู้พฤติกรรมที่เหมาะสมได้อย่างไรเมื่อผลตอบรับล่าช้า กระจัดกระจาย และเสียงดัง คำตอบคือการลองผิดลองถูกซึ่งนำโดยคณิตศาสตร์อันชาญฉลาด กลายเป็นแนวคิดที่ทรงพลังที่สุดอย่างหนึ่งในด้านปัญญาประดิษฐ์ทั้งหมด
