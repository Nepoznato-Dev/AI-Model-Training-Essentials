# กราฟโครงข่ายประสาทเทียม
Graph Neural Networks (GNN) คือโครงข่ายประสาทเทียมที่ออกแบบมาเพื่อทำงานบนข้อมูลที่มีโครงสร้างกราฟ — เครือข่ายของโหนดที่เชื่อมต่อกันด้วย Edge ในขณะที่โครงข่ายประสาทเทียมแบบดั้งเดิมทำงานบนกริด (รูปภาพ) หรือลำดับ (ข้อความ) GNN จะจัดการโครงสร้างเชิงสัมพันธ์ตามอำเภอใจ เช่น เครือข่ายสังคม กราฟโมเลกุล กราฟความรู้ เครือข่ายถนน กราฟแนะนำ และอื่นๆ สิ่งเหล่านี้กลายเป็นสิ่งจำเป็นสำหรับการค้นคว้ายา การตรวจจับการฉ้อโกง ระบบการแนะนำ และขอบเขตใดๆ ที่ความสัมพันธ์ระหว่างหน่วยงานมีความสำคัญ
---

## กราฟคืออะไร?
| ส่วนประกอบ | คำอธิบาย | ตัวอย่าง |
|----------|-------------|---------|
| **โหนด (จุดยอด)** | เอนทิตี | คน อะตอม โมเลกุล เมือง |
| **ขอบ** | ความสัมพันธ์ระหว่างสองโหนด | มิตรภาพ พันธะเคมี ถนน |
| **น้ำหนักขอบ** | จุดแข็งหรือประเภทของความสัมพันธ์ | ระยะทาง ความเหมือน ความจุ |
| **คุณสมบัติของโหนด** | คุณสมบัติของแต่ละโหนด | อายุ เลขอะตอม ประชากร |
| **คุณสมบัติขอบ** | คุณลักษณะของแต่ละขอบ | ประเภทของความสัมพันธ์ ระยะทาง |
| **เมทริกซ์คำติดกัน** | เมทริกซ์ A โดยที่ A[i][j] = 1 ถ้าโหนด i และ j เชื่อมต่อกัน | เข้ารหัสโครงสร้างกราฟ |
### ประเภทของกราฟ
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **ไม่ได้กำหนดทิศทาง** | ขอบไม่มีทิศทาง | เครือข่ายมิตรภาพ |
| **กำกับ** | ขอบมีทิศทาง (A→B ≠ B→A) | ผู้ติดตามทวิตเตอร์ |
| **ถ่วงน้ำหนัก** | ขอบมีค่าตัวเลข | โครงข่ายถนนที่มีระยะทาง |
| **ต่างกัน** | หลายประเภทโหนดและขอบ | กราฟวิชาการ (เอกสาร ผู้เขียน สถานที่) |
| **ไดนามิก** | โครงสร้างกราฟเปลี่ยนแปลงไปตามกาลเวลา | เครือข่ายสังคมออนไลน์ที่พัฒนาไปตามกาลเวลา |
| **ทั้งสองฝ่าย** | โหนดสองประเภท ขอบระหว่างประเภทเท่านั้น | กราฟคำแนะนำรายการผู้ใช้ |

## ทำไมไม่โครงข่ายประสาทเทียมปกติ?
| วิธีการ | ทำไมมันล้มเหลว |
|----------|-------------|
| **เครือข่ายฟีดฟอร์เวิร์ด** | ต้องมีอินพุตขนาดคงที่ กราฟมีขนาดและโครงสร้างแตกต่างกันไป |
| **ซีเอ็นเอ็น** | ถือว่าโครงสร้างกริด กราฟไม่มีตารางปกติ |
| **RNN/หม้อแปลงไฟฟ้า** | ถือว่าเรียงลำดับตามลำดับ กราฟไม่มีการเรียงลำดับตามธรรมชาติ |
GNN แก้ปัญหานี้โดยดำเนินการโดยตรงบนโครงสร้างกราฟ โดยประมวลผลแต่ละโหนดในบริบทของเพื่อนบ้าน

## สถาปัตยกรรม GNN หลัก
### กรอบการส่งข้อความ
GNN ส่วนใหญ่มีรูปแบบเดียวกัน: แต่ละโหนดรวบรวมข้อมูลจากเพื่อนบ้าน รวมเข้าด้วยกัน และอัปเดตการนำเสนอของตนเอง
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. ข้อความ** | แต่ละโหนดส่งข้อความไปยังเพื่อนบ้าน (ตามคุณสมบัติปัจจุบัน) |
| **2. รวม** | แต่ละโหนดรวบรวมและรวมข้อความจากเพื่อนบ้านทั้งหมด |
| **3. อัพเดท** | แต่ละโหนดอัพเดตการแสดงของตนเองโดยใช้ข้อความรวม |
| **4. ซ้ำ** | ทำสิ่งนี้กับเลเยอร์ K → แต่ละโหนดจะรวบรวมข้อมูลจาก K hops ออกไป |
### โมเดล GNN ที่สำคัญ
| รุ่น | วิธีการรวม | นวัตกรรมที่สำคัญ |
|-------|-------------------|----------------|
| **GCN** (เครือข่ายกราฟ Convolutional) | ค่าเฉลี่ยของคุณสมบัติเพื่อนบ้าน | เรียบง่าย; มีประสิทธิภาพ; แรงจูงใจทางสเปกตรัม |
| **กราฟSAGE** | ตัวอย่างและผลรวม สามารถใช้ค่าเฉลี่ย, LSTM หรือการรวมกลุ่ม | อุปนัย (จัดการโหนดที่มองไม่เห็น); ปรับขนาดได้ |
| **GAT** (เครือข่ายความสนใจกราฟ) | การรวมเพื่อนบ้านที่เน้นความสนใจ | เรียนรู้ว่าเพื่อนบ้านคนไหนสำคัญที่สุด |
| **GIN** (เครือข่ายกราฟไอโซมอร์ฟิซึม) | ผลรวมของคุณสมบัติเพื่อนบ้าน | แสดงออกได้อย่างสูงสุด; สามารถแยกแยะกราฟใดๆ ที่สามารถแยกความแตกต่างได้ด้วยการทดสอบ WL |
| **MPNN** (ข้อความผ่านโครงข่ายประสาทเทียม) | กรอบการส่งข้อความทั่วไป | รวมตัวแปร GNN จำนวนมาก |
### GCN ทำงานอย่างไร (ทีละขั้นตอน)
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

หลังจากเลเยอร์ K การแสดงของแต่ละโหนดจะเข้ารหัสข้อมูลจาก K กระโดดออกไปในกราฟ

## งานระดับกราฟ
| งาน | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **การจำแนกโหนด** | ทำนายป้ายกำกับของแต่ละโหนด | จำแนกผู้ใช้เป็นบอทหรือมนุษย์ |
| **ลิงค์ทำนาย** | ทายว่าขอบนั้นมีอยู่ (หรือจะมีอยู่) | ทำนายความสัมพันธ์ที่ขาดหายไป แนะนำการเชื่อมต่อ |
| **การจัดหมวดหมู่กราฟ** | ทำนายป้ายกำกับสำหรับกราฟทั้งหมด | จำแนกโมเลกุลว่าเป็นพิษหรือไม่เป็นพิษ |
| **การตรวจจับชุมชน** | ค้นหากลุ่มของโหนดที่เชื่อมต่ออย่างหนาแน่น | ระบุกลุ่มโซเชียล |
| **การสร้างกราฟ** | สร้างกราฟใหม่ด้วยคุณสมบัติที่ต้องการ | ออกแบบโมเลกุลใหม่ |

## แอปพลิเคชัน
### การค้นพบยาและการทำนายคุณสมบัติระดับโมเลกุล
| งาน | GNN ช่วยเหลืออย่างไร |
|-|---------------|
| **การทำนายคุณสมบัติทางโมเลกุล** | แสดงโมเลกุลเป็นกราฟ (อะตอม=โหนด พันธะ=ขอบ) ทำนายความเป็นพิษ ความสามารถในการละลาย ความผูกพันผูกพัน |
| **ปฏิกิริยาระหว่างยากับยา** | จำลองยาและเป้าหมายเป็นกราฟ ทำนายปฏิกิริยาที่ไม่พึงประสงค์ |
| **ดีโนโวยาดีไซน์** | สร้างกราฟโมเลกุลใหม่พร้อมคุณสมบัติที่ต้องการ |
### ระบบการแนะนำ
| วิธีการ | คำอธิบาย |
|----------|-------------|
| **กราฟรายการผู้ใช้** | ผู้ใช้และรายการเป็นโหนด การซื้อ/มุมมองมีขอบ |
| **การกรองการทำงานร่วมกันโดยใช้กราฟ** | GNN เผยแพร่การตั้งค่าผ่านกราฟ |
| **คำแนะนำกราฟความรู้** | รวมการตั้งค่าของผู้ใช้เข้ากับความรู้รายการ (ประเภท นักแสดง ผู้กำกับ) |
### การตรวจจับการฉ้อโกง
| ใบสมัคร | โครงสร้างกราฟ |
|-----------------|----------------|
| **การฉ้อโกงทางการเงิน** | ธุรกรรมในรูปแบบกราฟ รูปแบบการฉ้อโกงปรากฏเป็นโครงสร้างกราฟย่อย |
| **การฉ้อโกงประกันภัย** | ผู้เรียกร้อง ผู้ให้บริการ และนโยบายจะสร้างกราฟ ตรวจพบวงแหวนของผู้ฉ้อโกง |
| **การครอบครองบัญชี** | รูปแบบการเข้าสู่ระบบจะสร้างกราฟ การเชื่อมต่อที่ผิดปกติส่งสัญญาณประนีประนอม |
### กราฟความรู้
| งาน | คำอธิบาย |
|-|-------------|
| **ลิงค์ทำนาย** | ทำนายข้อเท็จจริงที่ขาดหายไป (เช่น "ปารีสเป็นเมืองหลวงของ ?") |
| **การแก้ไขเอนทิตี** | ตรวจสอบว่าการกล่าวถึงสองครั้งอ้างถึงเอนทิตีเดียวกัน |
| **ตอบคำถาม** | นำทางกราฟเพื่อค้นหาคำตอบ |

## แนวคิด GNN ขั้นสูง
### ปรับให้เรียบมากเกินไป
| ปัญหา | คำอธิบาย | โซลูชั่น |
|---------|-------------|----------|
| **เรียบเนียน** | หลังจากหลายเลเยอร์ การแสดงโหนดทั้งหมดจะคล้ายกัน | จำกัดความลึก (2-4 ชั้น) ใช้การเชื่อมต่อที่เหลือ ใช้ความรู้กระโดด |
### บีบมากเกินไป
| ปัญหา | คำอธิบาย | โซลูชั่น |
|---------|-------------|----------|
| **บีบจนเกินไป** | ข้อมูลจากโหนดระยะไกลถูกบีบอัดเป็นเวกเตอร์ขนาดคงที่ | ใช้หม้อแปลงกราฟ การรวมลำดับชั้น |
### กราฟหม้อแปลง
| รุ่น | คุณสมบัติที่สำคัญ |
|-------|-------------|
| **หม้อแปลงกราฟ** | ใช้ความสนใจของ Transformer มาตรฐานกับคู่โหนดทั้งหมด |
| **GPS** (ระบบแสดงกราฟ) | รวมเลเยอร์ GNN ท้องถิ่นกับเลเยอร์ Transformer ทั่วโลก |
| **ช่างภาพ** | เพิ่มการเข้ารหัสตำแหน่งตามโครงสร้างกราฟ |
### เครือข่ายกราฟที่แตกต่างกัน
| รุ่น | คำอธิบาย |
|-------|-------------|
| **R-GCN** | GCN เชิงสัมพันธ์; เมทริกซ์น้ำหนักที่แตกต่างกันสำหรับประเภทขอบที่แตกต่างกัน |
| **ฮัน** | เครือข่ายความสนใจที่แตกต่างกัน ความสนใจเหนือโหนดและประเภท Edge ที่แตกต่างกัน |
| **HetGNN** | โครงข่ายประสาทเทียมกราฟต่างกัน จัดการโหนดหลายประเภท |

## สรุป
Graph Neural Networks ขยายการเรียนรู้เชิงลึกไปยังข้อมูลเชิงสัมพันธ์ เช่น เครือข่าย โมเลกุล กราฟความรู้ และระบบใดๆ ที่เอนทิตีเชื่อมต่อกัน ทำงานโดยส่งข้อความระหว่างเพื่อนบ้าน ทำให้แต่ละโหนดเรียนรู้จากบริบทท้องถิ่นของตน GNN พบการใช้งานที่แข็งแกร่งที่สุดในการค้นพบยา ระบบการแนะนำ การตรวจจับการฉ้อโกง และกราฟความรู้ สาขานี้กำลังพัฒนาไปสู่การแปลงกราฟ กราฟต่างกัน และการฝึกอบรมที่ปรับขนาดได้สำหรับเครือข่ายขนาดใหญ่ในโลกแห่งความเป็นจริง หากข้อมูลของคุณมีความสัมพันธ์ GNN ก็น่าพิจารณา
