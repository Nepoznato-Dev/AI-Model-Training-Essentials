# การเรียนรู้แบบสหพันธ์และความเป็นส่วนตัว
การเรียนรู้แบบสมาพันธ์เป็นเทคนิคในการฝึกโมเดลการเรียนรู้ของเครื่องบนอุปกรณ์หรือองค์กรต่างๆ โดยไม่ต้องแชร์ข้อมูลดิบ แทนที่จะส่งข้อมูลไปยังเซิร์ฟเวอร์กลาง แต่ละอุปกรณ์จะฝึกโมเดลในเครื่องและแชร์เฉพาะการอัปเดตโมเดลเท่านั้น (การไล่ระดับสีหรือน้ำหนัก) เซิร์ฟเวอร์กลางรวมการอัปเดตเหล่านี้เพื่อสร้างแบบจำลองสากล ได้รับการออกแบบโดย Google เพื่อฝึกโมเดลภาษาแป้นพิมพ์บนโทรศัพท์ Android และตั้งแต่นั้นมาก็กลายเป็นเทคนิคสำคัญสำหรับ AI ในการรักษาความเป็นส่วนตัว
---

## ทำไมต้องเรียนแบบสมาพันธ์?
| แรงจูงใจ | คำอธิบาย | ตัวอย่าง |
|------------|-------------|---------|
| **ความเป็นส่วนตัวของข้อมูล** | ข้อมูลดิบไม่เคยออกจากอุปกรณ์ | เวชระเบียนจะอยู่ในโรงพยาบาล รูปภาพยังคงอยู่ในโทรศัพท์ |
| **การปฏิบัติตามกฎระเบียบ** | GDPR, HIPAA และข้อบังคับอื่นๆ จำกัดการแบ่งปันข้อมูล | ธนาคารสามารถทำงานร่วมกันได้โดยไม่ต้องเปิดเผยข้อมูลลูกค้า |
| **ปริมาณข้อมูล** | การย้ายข้อมูลมีราคาแพงและช้า | การฝึกอบรมบนโทรศัพท์หลายพันเครื่องนั้นไม่สามารถทำได้หากต้องอัปโหลดข้อมูล |
| **ความละเอียดอ่อนของข้อมูล** | ข้อมูลบางอย่างมีความอ่อนไหวเกินกว่าจะแบ่งปันแม้จะได้รับความยินยอม | หน่วยสืบราชการลับของรัฐบาล ข้อมูลสุขภาพส่วนบุคคล |
---

## วิธีการทำงานของการเรียนรู้แบบสมาพันธ์
### โปรโตคอลพื้นฐาน (FedAvg)
| ขั้นตอน | เกิดอะไรขึ้น |
|-|-------------|
| **1. เริ่มต้น** | เซิร์ฟเวอร์กลางสร้างโมเดลสากลที่มีน้ำหนักสุ่ม |
| **2. แจกจ่าย** | เซิร์ฟเวอร์ส่งโมเดลสากลปัจจุบันไปยังอุปกรณ์ที่เลือก |
| **3. การฝึกอบรมในพื้นที่** | อุปกรณ์แต่ละเครื่องจะฝึกโมเดลกับข้อมูลในตัวเครื่องเป็นเวลาหลายยุค |
| **4. อัพโหลด** | อุปกรณ์ส่งน้ำหนักโมเดลที่อัปเดต (ไม่ใช่ข้อมูล) กลับไปยังเซิร์ฟเวอร์ |
| **5. รวม** | เซิร์ฟเวอร์หาค่าเฉลี่ยน้ำหนัก (Federated Averaging) เพื่อสร้างโมเดลสากลใหม่ |
| **6. ซ้ำ** | กลับไปที่ขั้นตอนที่ 2 จนกระทั่งโมเดลมาบรรจบกัน |
```
Server: global_model = average(local_model_1, local_model_2, ..., local_model_n)
```

### คุณสมบัติที่สำคัญ
| คุณสมบัติ | คำอธิบาย |
|----------|-------------|
| **ข้อมูลที่ไม่ใช่ IID** | อุปกรณ์แต่ละเครื่องมีการกระจายข้อมูลที่แตกต่างกัน (ไม่เป็นอิสระและกระจายเหมือนกัน) |
| **ข้อมูลไม่สมดุล** | อุปกรณ์บางชนิดมีข้อมูลจำนวนมาก อุปกรณ์อื่นๆ มี | น้อยมาก
| **การมีส่วนร่วมบางส่วน** | อุปกรณ์บางรุ่นอาจไม่มีจำหน่ายในทุกรอบ |
| **ประสิทธิภาพการสื่อสาร** | คอขวดคือการสื่อสาร ไม่ใช่การคำนวณ |

## ตัวแปรการเรียนรู้แบบสหพันธรัฐ
| ตัวแปร | คำอธิบาย | ข้อได้เปรียบ |
|---------|-------------|-----------|
| **FedAvg** | น้ำหนักโมเดลโดยเฉลี่ยในอุปกรณ์ต่างๆ | เรียบง่าย; ทำงานได้ดีกับข้อมูล IID |
| **FedProx** | เพิ่มคำศัพท์ที่ใกล้เคียงกับการฝึกอบรมในท้องถิ่น | ดีกว่าสำหรับข้อมูลที่ไม่ใช่ IID |
| **นั่งร้าน** | ใช้ตัวแปรควบคุมเพื่อแก้ไขความหลากหลายของข้อมูล | การบรรจบกันที่เร็วขึ้นกับข้อมูลที่ไม่ใช่ IID
| **FedSGD** | เช่นเดียวกับ FedAvg แต่มีการไล่ระดับสีหนึ่งขั้นต่อรอบ | ลดต้นทุนการสื่อสารต่อรอบ |
| **FL ส่วนบุคคล** | อุปกรณ์แต่ละชิ้นยังคงรักษาโมเดลส่วนบุคคลไว้ควบคู่ไปกับโมเดลระดับโลก | ประสิทธิภาพต่ออุปกรณ์ที่ดีขึ้น |
| **แนวตั้ง FL** | คุณสมบัติที่แตกต่างกัน (ตัวอย่างไม่แตกต่างกัน) ในแต่ละฝ่าย | เมื่อฝ่ายต่างๆ ถือแง่มุมที่แตกต่างกันของข้อมูลเดียวกัน |

## ความเป็นส่วนตัวที่แตกต่าง
Differential Privacy (DP) ให้การรับประกันทางคณิตศาสตร์ว่าผลลัพธ์ของอัลกอริทึมจะไม่เปิดเผยว่าข้อมูลของบุคคลใดถูกรวมอยู่หรือไม่
### คำจำกัดความหลัก
กลไก M ตอบสนอง (ε, δ) - ความเป็นส่วนตัวแบบดิฟเฟอเรนเชียล หากสำหรับชุดข้อมูลสองชุด D และ D ' ที่แตกต่างกันในหนึ่งระเบียน:
```
P(M(D) ∈ S) ≤ e^ε × P(M(D') ∈ S) + Î´
```

| พารามิเตอร์ | ความหมาย |
|----------|---------|
| **ε (เอปไซลอน)** | งบประมาณความเป็นส่วนตัว เล็กลง = เป็นส่วนตัวมากขึ้น ค่าทั่วไป: 0.1–10 |
| **δ (เดลต้า)** | ความน่าจะเป็นของการรับประกันความเป็นส่วนตัวล้มเหลว โดยทั่วไปจะตั้งค่าเป็น 1/N (ผกผันกับขนาดชุดข้อมูล) |
### กลไกในการเพิ่มความเป็นส่วนตัว
| กลไก | มันทำงานอย่างไร | ใช้กรณี |
|----------|-------------|----------|
| **กลไกเกาส์เซียน** | เพิ่มสัญญาณรบกวนแบบเกาส์เซียนที่ปรับเทียบตามความไวของแบบสอบถาม | ค่าต่อเนื่อง (น้ำหนักแบบจำลอง) |
| **กลไกลาปลาซ** | เพิ่มเสียงลาปลาซ | การนับแบบสอบถาม |
| **กลไกเอ็กซ์โปเนนเชียล** | เลือกเอาต์พุตที่มีความน่าจะเป็นตามสัดส่วนกับยูทิลิตี้ | ตัวเลือกแบบแยกส่วน |
### DP-SGD (โคตรสุ่มสุ่มแบบดิฟเฟอเรนเชียล)
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| 1. คำนวณการไล่ระดับสีต่อตัวอย่าง | แทนการไล่ระดับสีแบบแบทช์ |
| 2. การไล่ระดับสีคลิป | ผูกบรรทัดฐานสูงสุดของแต่ละการไล่ระดับสี (จำกัดอิทธิพลของตัวอย่างเดียว) |
| 3. เพิ่มเสียงรบกวน | เพิ่มสัญญาณรบกวนแบบเกาส์เซียนที่ปรับเทียบแล้วลงในการไล่ระดับสีแบบรวม |
| 4. อัปเดตพารามิเตอร์ | ขั้นตอนการไล่ระดับแบบมาตรฐาน |
| การแลกเปลี่ยน | คำอธิบาย |
|-----------|-------------|
| **ความเป็นส่วนตัวเทียบกับความถูกต้อง** | ความเป็นส่วนตัวที่แข็งแกร่งยิ่งขึ้น (ε ต่ำกว่า) ต้องใช้สัญญาณรบกวนมากขึ้น ซึ่งจะลดความแม่นยำของโมเดล |
| **ความเป็นส่วนตัวเทียบกับเวลาฝึกอบรม** | เสียงรบกวนมากขึ้นหมายถึงการบรรจบกันช้าลง |
| **การติดตามงบประมาณความเป็นส่วนตัว** | แต่ละขั้นตอนการฝึกอบรมใช้งบประมาณความเป็นส่วนตัวบางส่วน ใช้แล้วไม่สามารถกู้คืนได้ |

## ผสมผสานการเรียนรู้แบบสหพันธรัฐเข้ากับความเป็นส่วนตัวที่แตกต่างกัน
| เลเยอร์ | การป้องกัน |
|-------|-----------|
| **การเรียนรู้แบบสหพันธ์** | ข้อมูลดิบยังคงอยู่ในอุปกรณ์ |
| **ความเป็นส่วนตัวที่แตกต่าง** | แม้แต่การอัปเดตโมเดลก็ยังส่งเสียงดัง ปกป้องการมีส่วนร่วมส่วนบุคคล |
| **การรวมตัวที่ปลอดภัย** | เซิร์ฟเวอร์จะเห็นเฉพาะผลรวมของการอัปเดตทั้งหมด ไม่ใช่รายการอัปเดตแต่ละรายการ |
การรวมกันนี้ให้การรับประกันความเป็นส่วนตัวที่แข็งแกร่ง: แม้ว่าเซิร์ฟเวอร์จะถูกบุกรุก แต่ก็ไม่สามารถระบุได้ว่าข้อมูลของบุคคลใดถูกใช้ในการฝึกอบรมหรือไม่

## เทคนิคการรักษาความเป็นส่วนตัวอื่น ๆ
### การประมวลผลหลายฝ่ายที่ปลอดภัย (SMPC)
หลายฝ่ายคำนวณฟังก์ชันบนข้อมูลที่รวมกันโดยไม่เปิดเผยอินพุตของแต่ละคน
| คุณสมบัติ | คำอธิบาย |
|---------|-------------|
| **มันทำงานอย่างไร** | ข้อมูลถูกแบ่งออกเป็นการแบ่งปันที่กระจายระหว่างฝ่ายต่างๆ การคำนวณเกิดขึ้นกับหุ้น |
| **รับประกัน** | ไม่มีฝ่ายใดเรียนรู้อะไรเกี่ยวกับอินพุตของผู้อื่น |
| **ค่าโสหุ้ย** | ต้นทุนการสื่อสารและการคำนวณที่สำคัญ |
| **กรณีการใช้งาน** | ธนาคารต่างๆ คำนวณแบบจำลองความเสี่ยงร่วมโดยไม่เปิดเผยข้อมูลลูกค้า
### การเข้ารหัสแบบโฮโมมอร์ฟิก (HE)
ทำการคำนวณโดยตรงกับข้อมูลที่เข้ารหัส
| พิมพ์ | รองรับอะไร | ค่าโสหุ้ย |
|------|-----------------|----------|
| **HE บางส่วน** | การดำเนินการครั้งเดียว (บวกหรือคูณ) | ต่ำ |
| **ค่อนข้างเขา** | จำนวนจำกัดของการดำเนินการทั้งสอง | ปานกลาง |
| **ครบแล้ว** | การคำนวณตามอำเภอใจ | สูงมาก (ชะลอตัว 100-1000x) |
| ใบสมัคร | คำอธิบาย |
|-------------|-------------|
| **อนุมานส่วนตัว** | เรียกใช้โมเดล ML กับข้อมูลที่เข้ารหัส ส่งคืนการทำนายที่เข้ารหัส |
| **การฝึกอบรมแบบเข้ารหัส** | ฝึกฝนข้อมูลที่เข้ารหัส (ยังคงเป็นทฤษฎีส่วนใหญ่สำหรับการเรียนรู้เชิงลึก) |
| **คำถามส่วนตัว** | สืบค้นฐานข้อมูลโดยไม่เปิดเผยแบบสอบถามหรือข้อมูล |
### สภาพแวดล้อมการดำเนินการที่เชื่อถือได้ (TEE)
การแยกตามฮาร์ดแวร์ (Intel SGX, ARM Trustzone) ที่ปกป้องข้อมูลแม้กระทั่งจากระบบปฏิบัติการ
| ข้อได้เปรียบ | ข้อจำกัด |
|----------||------------|
| ประสิทธิภาพใกล้เคียงพื้นเมือง | ต้องใช้ฮาร์ดแวร์เฉพาะ |
| รับประกันความปลอดภัยที่แข็งแกร่ง | หน่วยความจำจำกัด (ขนาดวงล้อม) |
| ไม่มีค่าใช้จ่ายในการเข้ารหัส | การโจมตีช่องด้านข้างเป็นไปได้ |

## ข้อบังคับความเป็นส่วนตัวและ ML
| กฎระเบียบ | ภูมิภาค | ผลกระทบต่อ ML |
|------------|--------|-------------|
| **จีดีพีอาร์** | สหภาพยุโรป | สิทธิ์ในการอธิบาย การลดขนาดข้อมูล ความยินยอมในการประมวลผล สิทธิ์ในการลบ |
| **CCPA** | แคลิฟอร์เนีย | สิทธิ์ในการทราบ ลบ และเลือกไม่ขายข้อมูล |
| **HIPAA** | สหรัฐอเมริกา (การดูแลสุขภาพ) | การควบคุมข้อมูลด้านสุขภาพอย่างเข้มงวด ข้อกำหนดในการไม่ระบุตัวตน |
| **PIPL** | จีน | การแปลข้อมูล ข้อกำหนดในการยินยอม กฎการโอนข้ามพรมแดน |
| **พระราชบัญญัติ AI** | สหภาพยุโรป | ข้อกำหนดด้านความโปร่งใส การจำแนกความเสี่ยง การปฏิบัติที่ต้องห้าม |
### ผลกระทบต่อเวิร์กโฟลว์ ML
| หลักการ GDPR | ความหมาย ML |
|----------------|---------------|
| **การลดขนาดข้อมูล** | รวบรวมเฉพาะสิ่งที่จำเป็น การเรียนรู้แบบสหพันธรัฐช่วยได้ |

| **สิทธิ์ในการลบ** | จะต้องสามารถลบข้อมูลของบุคคลออกจากโมเดลที่ผ่านการฝึกอบรมได้ (การไม่เรียนรู้ของเครื่อง) |
| **สิทธิ์ในการอธิบาย** | โมเดลต้องสามารถตีความได้มากพอที่จะอธิบายการคาดเดาส่วนบุคคล |
| **ความเป็นส่วนตัวตามการออกแบบ** | ความเป็นส่วนตัวจะต้องสร้างไว้ในระบบตั้งแต่เริ่มต้น |

| **ข้อมูลที่ไม่ใช่ IID** | อุปกรณ์มีการกระจายข้อมูลที่แตกต่างกันมาก ซึ่งส่งผลกระทบต่อการบรรจบกัน |

| **ความหลากหลายของฮาร์ดแวร์** | อุปกรณ์ที่แตกต่างกันมีความสามารถในการคำนวณที่แตกต่างกัน |

## สรุป
เทคนิคการเรียนรู้แบบสมาพันธ์และการรักษาความเป็นส่วนตัวช่วยแก้ไขความตึงเครียดพื้นฐาน: คุณจะสร้างโมเดล AI ที่ทรงพลังได้อย่างไรเมื่อมีการกระจายข้อมูล ละเอียดอ่อน หรือควบคุม การเรียนรู้แบบสมาพันธ์จะเก็บข้อมูลไว้ในอุปกรณ์และแชร์เฉพาะการอัปเดตโมเดลเท่านั้น ความเป็นส่วนตัวที่แตกต่างเพิ่มการรับประกันทางคณิตศาสตร์ว่าไม่สามารถตรวจพบการมีส่วนร่วมแต่ละรายการได้ การคำนวณที่ปลอดภัยและการเข้ารหัสแบบโฮโมมอร์ฟิกก้าวไปอีกขั้น ทำให้สามารถคำนวณข้อมูลที่เข้ารหัสได้ แต่ละเทคนิคมีค่าใช้จ่าย — ค่าใช้จ่ายในการสื่อสาร, ความแม่นยำลดลง, ค่าใช้จ่ายในการคำนวณ — แต่เมื่อรวมกันแล้ว เทคนิคเหล่านี้จะสร้างชุดเครื่องมือสำหรับการสร้าง AI ที่เคารพความเป็นส่วนตัวในขณะที่ยังคงเรียนรู้จากข้อมูลของโลก
