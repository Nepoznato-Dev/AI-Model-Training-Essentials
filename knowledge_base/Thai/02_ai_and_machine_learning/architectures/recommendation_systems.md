# ระบบการแนะนำ
ระบบการแนะนำจะคาดเดาสิ่งที่ผู้ใช้ต้องการดู ซื้อ หรือโต้ตอบด้วยต่อไป พวกเขาขับเคลื่อนฟีดเนื้อหาบนโซเชียลมีเดีย คำแนะนำผลิตภัณฑ์บนเว็บไซต์อีคอมเมิร์ซ ภาพยนตร์ที่เลือกสรรบนแพลตฟอร์มสตรีมมิ่ง และผลการค้นหา แม้ว่าผู้ใช้ส่วนใหญ่จะมองไม่เห็น แต่ก็เป็นหนึ่งในระบบ AI ที่มีผลกระทบเชิงพาณิชย์มากที่สุดในโลก - Netflix ประมาณการว่ากลไกการแนะนำจะช่วยประหยัดเงินได้มากกว่า 1 พันล้านดอลลาร์ต่อปีโดยลดการเลิกใช้งานของสมาชิก
---

## ทำไมคำแนะนำถึงยาก
| ท้าทาย | คำอธิบาย |
|-----------|-------------|
| **สเกล** | ผู้ใช้นับล้าน × ล้านรายการ = คู่ที่เป็นไปได้นับพันล้าน |
| **กระจัดกระจาย** | ผู้ใช้แต่ละคนได้โต้ตอบกับรายการที่มีอยู่เพียงเล็กน้อย |
| **สตาร์ทเย็น** | ผู้ใช้ใหม่และรายการใหม่ไม่มีประวัติการโต้ตอบ |
| **การตั้งค่าไดนามิก** | รสนิยมผู้ใช้เปลี่ยนไปตามกาลเวลา |
| **เกินความแม่นยำ** | คำแนะนำจะต้องมีความหลากหลาย แปลกใหม่ และบังเอิญ |
| **เป้าหมายทางธุรกิจ** | เพิ่มการมีส่วนร่วมสูงสุด ≠ เพิ่มความเป็นอยู่ที่ดีของผู้ใช้ให้สูงสุด |

## แนวทางหลัก
### การกรองการทำงานร่วมกัน
แนวคิด: หากผู้ใช้ A และ B ตกลงกันในอดีต พวกเขาอาจจะตกลงกันในอนาคต
| พิมพ์ | มันทำงานอย่างไร | ตัวอย่าง |
|------|-------------|---------|
| **ตามผู้ใช้** | ค้นหาผู้ใช้ที่คล้ายกัน แนะนำสิ่งที่พวกเขาชอบ | "ผู้ใช้ที่ชื่นชอบสิ่งนี้ก็ชอบ..." |
| **ตามรายการ** | ค้นหารายการที่คล้ายกับสิ่งที่ผู้ใช้ชอบแล้ว | "เพราะคุณดู..." |
| **การแยกตัวประกอบเมทริกซ์** | แยกเมทริกซ์การโต้ตอบระหว่างผู้ใช้กับรายการออกเป็นปัจจัยแฝง | SVD, ALS (กำลังสองน้อยที่สุดสลับกัน) |
| ความแข็งแกร่ง | จุดอ่อน |
|----------|----------|
| ไม่ต้องเข้าใจรายการเอง | ปัญหาสตาร์ทเย็น: ไม่สามารถแนะนำรายการใหม่ได้ |
| รวบรวมการตั้งค่าที่ซับซ้อนและโดยนัย | ต้องใช้ข้อมูลการโต้ตอบจำนวนมาก |
| ใช้ได้กับเนื้อหาทุกประเภท | อคติความนิยม: แนะนำสินค้ายอดนิยมอยู่แล้ว |
### การกรองตามเนื้อหา
แนะนำรายการที่คล้ายกับรายการที่ผู้ใช้ชอบอยู่แล้ว โดยพิจารณาจากคุณสมบัติของรายการ
| ประเภทคุณสมบัติ | ตัวอย่าง |
|-------------|---------|
| **ข้อความ** | ประเภท คำอธิบาย คำสำคัญ นักแสดง |
| **เสียง** | จังหวะ, ประเภท, อารมณ์ (สำหรับดนตรี) |
| **ภาพ** | จานสี สไตล์ (สำหรับรูปภาพ/แฟชั่น) |
| **ข้อมูลเมตา** | ราคา ยี่ห้อ หมวดหมู่ |
| ความแข็งแกร่ง | จุดอ่อน |
|----------|----------|
| ไม่มีการสตาร์ทเย็นสำหรับรายการ (ทราบคุณสมบัติแล้ว) | ไม่สามารถแนะนำรายการที่อยู่นอกรสนิยมของผู้ใช้ได้ |
| ใช้งานได้กับข้อมูลการโต้ตอบน้อย | ต้องใช้วิศวกรรมคุณลักษณะที่ดี |
| อธิบายได้ ("แนะนำเพราะคล้ายกับ X") | ความบังเอิญน้อยลง |
### แนวทางแบบผสมผสาน
ระบบการผลิตส่วนใหญ่จะรวมวิธีการทำงานร่วมกันและแบบอิงเนื้อหาเข้าด้วยกัน
| กลยุทธ์ไฮบริด | คำอธิบาย |
|----------------|-------------|
| **ถ่วงน้ำหนัก** | รวมคะแนนจากหลายรุ่น |
| **การสลับ** | ใช้เนื้อหาตามผู้ใช้ใหม่ การทำงานร่วมกันสำหรับผู้ใช้ที่จัดตั้งขึ้น |
| **น้ำตก** | ใช้โมเดลแบบง่ายก่อน จากนั้นจึงปรับแต่งด้วยโมเดลที่ซับซ้อน |
| **การผสมผสานคุณสมบัติ** | รวมคุณสมบัติการทำงานร่วมกันและเนื้อหาไว้ในรูปแบบเดียว |
| **เมตาเลิร์นนิง** | เรียนรู้วิธีรวมผู้แนะนำต่างๆ |

## แนวทางการเรียนรู้เชิงลึกสมัยใหม่
### โมเดลสองทาวเวอร์
สถาปัตยกรรมที่โดดเด่นสำหรับการแนะนำในวงกว้าง (ใช้โดย YouTube, Pinterest, Spotify)
| ส่วนประกอบ | บทบาท |
|-----------|-|
| **หอผู้ใช้** | โครงข่ายประสาทเทียมที่เข้ารหัสคุณสมบัติและประวัติของผู้ใช้ในการฝัง |
| **ไอเทมทาวเวอร์** | โครงข่ายประสาทเทียมที่เข้ารหัสคุณลักษณะของรายการเป็นการฝัง |
| **ความเหมือน** | ความคล้ายคลึงกันของดอทโปรดัคหรือโคไซน์ระหว่างการฝังผู้ใช้และรายการ
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| 1 | ฝึกหอคอยทั้งสองเพื่อสร้างการฝังที่คล้ายกันสำหรับคู่ไอเท็มผู้ใช้ที่มีการโต้ตอบ |
| 2 | ณ เวลาแสดงผล ให้ฝังรายการคำนวณล่วงหน้า |
| 3 | สำหรับคำขอของผู้ใช้ ให้คำนวณการฝังผู้ใช้ |
| 4 | ใช้การค้นหาเพื่อนบ้านที่ใกล้ที่สุดโดยประมาณ (ANN) เพื่อค้นหารายการที่คล้ายกันมากที่สุด |
### แบบจำลองลำดับสำหรับคำแนะนำ
พฤติกรรมของผู้ใช้จะเป็นไปตามลำดับ — สิ่งที่คุณดูเมื่อวานนี้มีอิทธิพลต่อสิ่งที่คุณจะดูในวันนี้
| รุ่น | วิธีการ |
|-------|----------|
| **GRU4Rec** | โมเดลตาม GRU สำหรับคำแนะนำตามเซสชัน |
| **SASRec** | ผู้แนะนำตามลำดับการเอาใจใส่ตนเอง |
| **BERT4Rec** | หม้อแปลงไฟฟ้าแบบสองทิศทางสำหรับคำแนะนำตามลำดับ |
| **YouTube DNN** | โครงข่ายประสาทเทียมระดับลึกที่จัดการประวัติการดูเป็นลำดับ |
### การดึงข้อมูลเทียบกับการจัดอันดับ
ระบบสมัยใหม่แบ่งคำแนะนำออกเป็นสองขั้นตอน:
| เวที | วัตถุประสงค์ | วิธีการ |
|-------|---------|--------|
| **การดึงข้อมูล (การสร้างผู้สมัคร)** | จำกัดรายการหลายล้านรายการให้เหลือเพียง ~1,000 ผู้สมัคร | โมเดลสองทาวเวอร์ ค้นหาแอน; เร็วแต่ประมาณ |
| **อันดับ (คะแนน)** | ให้คะแนนและเรียงลำดับผู้สมัครอย่างแม่นยำ | รุ่นลึกพร้อมคุณสมบัติมากมาย ช้ากว่าแต่แม่นยำ |
| **การจัดอันดับใหม่** | ปรับเพื่อความหลากหลาย กฎเกณฑ์ทางธุรกิจ ความสดใหม่ | โจรตามบริบท การเพิ่มประสิทธิภาพข้อ จำกัด |

## ตัวชี้วัดการประเมินผล
| เมตริก | มันวัดอะไร | เมื่อใดควรใช้ |
|--------|-----------------|-------------|
| **ความแม่นยำ@K** | เศษส่วนของคำแนะนำยอดนิยม K ที่เกี่ยวข้อง | เมื่อคุณใส่ใจกับความแม่นยำของตัวเลือกอันดับต้นๆ |
| **Recall@K** | เศษส่วนของรายการที่เกี่ยวข้องที่พบใน top-K | เมื่อคุณใส่ใจไม่พลาดของดี |
| **NDCG** (กำไรสะสมที่มีส่วนลดตามปกติ) | การจัดอันดับคุณภาพ รางวัลที่ทำให้รายการที่เกี่ยวข้องสูงขึ้น | เมื่อลำดับการจัดอันดับมีความสำคัญ |
| **MAP** (ความแม่นยำเฉลี่ยเฉลี่ย) | ความแม่นยำเฉลี่ยของผู้ใช้ทั้งหมด | อันดับคุณภาพโดยรวม |
| **อัตราการเข้าชม@K** | มีรายการที่เกี่ยวข้องอย่างน้อยหนึ่งรายการปรากฏใน top-K | หรือไม่ สถานการณ์ที่เกี่ยวข้องกับไบนารี |
| **ความคุ้มครอง** | เศษส่วนของรายการที่ได้รับการแนะนำ | ความหลากหลายและความเป็นธรรม |
| **ความบังเอิญ** | คำแนะนำที่ไม่คาดคิดแต่มีความเกี่ยวข้อง | ความพึงพอใจของผู้ใช้ |

## ปัญหาสตาร์ทเย็น
| สถานการณ์ | ท้าทาย | โซลูชั่น |
|----------|-----------|-----------|
| **ผู้ใช้ใหม่** | ไม่มีประวัติการโต้ตอบ | ใช้ข้อมูลประชากร แสดงรายการยอดนิยม ใช้สัญญาณตามบริบท (สถานที่ อุปกรณ์ เวลา) |
| **สินค้าใหม่** | ยังไม่มีใครโต้ตอบด้วย | ใช้คุณสมบัติเนื้อหา กลยุทธ์การสำรวจและแสวงหาผลประโยชน์ อัลกอริธึมโจร |
| **ระบบใหม่** | ไม่มีข้อมูลเลย | ถ่ายทอดการเรียนรู้จากโดเมนที่คล้ายคลึงกัน ดูแลจัดการเนื้อหาเริ่มต้น |

## การสำรวจและการแสวงหาผลประโยชน์
| กลยุทธ์ | คำอธิบาย | การแลกเปลี่ยน |
|----------|-------------|-----------|
| **ε-โลภ** | แสดงรายการสุ่มที่มีความน่าจะเป็น ε | เรียบง่ายแต่ไม่มีประสิทธิภาพ |
| **ทอมป์สัน แซมปลิง** | ตัวอย่างจากการแจกแจงคุณภาพสินค้าภายหลัง | มีหลักการ; คุณสมบัติทางทฤษฎีที่ดี |
| **ขอบเขตความเชื่อมั่นขั้นสูง (UCB)** | ชอบรายการที่มีความไม่แน่นอนสูง | ความสมดุลที่ดีของการสำรวจและการแสวงหาผลประโยชน์ |
| **โจรตามบริบท** | การสำรวจมีเงื่อนไขตามบริบทของผู้ใช้ | มีประสิทธิภาพมากกว่าการสำรวจแบบคนตาบอด |
| **ฉีดความหลากหลาย** | จงใจรวมรายการที่หลากหลายหรือแปลกใหม่ | เรียบง่าย; อาจลดการมีส่วนร่วมในระยะสั้น |

## อคติและความยุติธรรม
| ประเภทอคติ | คำอธิบาย | ผลกระทบ |
|----------|-------------|--------|
| **อคติความนิยม** | สินค้ายอดนิยมได้รับการแนะนำมากขึ้นเรื่อยๆ | รายการหางยาวไม่ได้รับการดูแล |
| **อคติในการเลือก** | โมเดลเรียนรู้จากการโต้ตอบที่สังเกตได้ ไม่ใช่ทั้งหมดที่เป็นไปได้ | เอียงไปทางผู้ใช้ที่ใช้งานอยู่ |
| **อคติตำแหน่ง** | รายการที่แสดงในตำแหน่งที่สูงกว่าจะได้รับการคลิกมากขึ้นโดยไม่คำนึงถึงคุณภาพ | ตอกย้ำตำแหน่งสูงสุด |
| **อคติจากการสัมผัส** | รายการที่แสดงจะได้รับสัญญาณการฝึกอบรมเพิ่มเติม | ห่วงคำติชม |
| **อคติทางประชากรศาสตร์** | ข้อเสนอแนะแตกต่างกันไปตามกลุ่มประชากรในลักษณะที่ไม่ยุติธรรม | การเลือกปฏิบัติ; ประสบการณ์ที่ไม่ดีสำหรับบางกลุ่ม |
### กลยุทธ์การบรรเทาผลกระทบ
| กลยุทธ์ | คำอธิบาย |
|----------|-------------|
| **การถ่วงน้ำหนักแนวโน้มผกผัน** | ลดน้ำหนักไอเท็มยอดนิยมในเทรนนิ่ง |
| **ชั้นลดอคติ** | เพิ่มองค์ประกอบการลดอคติให้กับโมเดล |
| **ข้อจำกัดด้านความเป็นธรรม** | เพิ่มข้อจำกัดเพื่อให้มั่นใจว่าได้รับการปฏิบัติอย่างเท่าเทียมกัน |
| **คำแนะนำที่หลากหลาย** | ปรับให้เหมาะสมอย่างชัดเจนเพื่อความหลากหลายควบคู่ไปกับความเกี่ยวข้อง |
| **การตรวจสอบและติดตาม** | ตรวจสอบคำแนะนำเกี่ยวกับอคติระหว่างกลุ่มเป็นประจำ |

| **ยูทูป** | วิดีโอแนะนำ | โครงข่ายประสาทเทียมระดับลึกสำหรับการสร้างผู้สมัคร รูปแบบการจัดอันดับแยก |
| **สปอติฟาย** | แนะนำเพลง | การกรองร่วมกัน + NLP ในเพลย์ลิสต์ + การวิเคราะห์เสียง |
| **อเมซอน** | คำแนะนำผลิตภัณฑ์ | การกรองการทำงานร่วมกันแบบรายการต่อรายการ ส่วนบุคคลตามขนาด |
| **ติ๊กต๊อก** | ฟีดวิดีโอสั้น | การเรียนรู้แบบเสริมกำลัง เน้นการสำรวจ |
| **พินเตอร์** | คำแนะนำด้วยภาพ | โมเดลสองทาวเวอร์ ความคล้ายคลึงกันทางสายตา |

## เครื่องมือและกรอบการทำงาน
| เครื่องมือ | วัตถุประสงค์ |
|------|---------|
| **ผู้แนะนำ TensorFlow (TFRS)** | โมเดลสองทาวเวอร์ การดึงข้อมูล การจัดอันดับ |
| **PyTorch RecSys** | โมเดลคำแนะนำเชิงการวิจัย |
| **เซอร์ไพรส์** | การกรองการทำงานร่วมกันแบบคลาสสิก (SVD, NMF, KNN) |
| **โดยนัย** | การกรองการทำงานร่วมกันอย่างรวดเร็วสำหรับการตอบรับโดยนัย (ALS, BPR) |
| **Faiss** (เมตา) | การค้นหาเพื่อนบ้านที่ใกล้ที่สุดโดยประมาณในระดับ |
| **มิลวัส / ไพน์โคน / วีวิเอต** | ฐานข้อมูลเวกเตอร์สำหรับการค้นหาความคล้ายคลึงกัน
| **Recbol** | ห้องสมุดวิจัยข้อเสนอแนะที่ครอบคลุม |
| **เมอร์ลิน** (NVIDIA) | ไปป์ไลน์คำแนะนำที่เร่งด้วย GPU |

## สรุป
ระบบการแนะนำเป็นหนึ่งในแอปพลิเคชัน AI ที่มีอิทธิพลมากที่สุดในอุตสาหกรรม สาขานี้ได้พัฒนาจากการกรองการทำงานร่วมกันแบบง่ายๆ ไปจนถึงสถาปัตยกรรมการเรียนรู้เชิงลึกที่รวมประวัติผู้ใช้ เนื้อหารายการ สัญญาณตามบริบท และวัตถุประสงค์ทางธุรกิจ ระบบสมัยใหม่ใช้ไปป์ไลน์การเรียกข้อมูล-การจัดอันดับ-การจัดอันดับใหม่ โดยมีโมเดลสองทาวเวอร์สำหรับการสร้างผู้สมัครที่รวดเร็ว และโมเดลเชิงลึกเพื่อการให้คะแนนที่แม่นยำ ความท้าทายต่างๆ เช่น การเริ่มต้นใหม่ อคติ การสำรวจ และการสร้างสมดุลระหว่างความพึงพอใจของผู้ใช้กับเป้าหมายทางธุรกิจ ยังคงเป็นประเด็นสำคัญของการวิจัยและวิศวกรรม
