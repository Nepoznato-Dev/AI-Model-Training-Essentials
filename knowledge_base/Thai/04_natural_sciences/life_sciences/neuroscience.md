#ประสาทวิทยา
ประสาทวิทยาศาสตร์คือการศึกษาระบบประสาท ได้แก่ สมอง ไขสันหลัง และเส้นประสาททั้งหมดที่เชื่อมต่อระบบประสาทเหล่านี้เข้ากับร่างกาย ครอบคลุมหลายระดับ ตั้งแต่โมเลกุลและยีน ไปจนถึงเซลล์ประสาทและไซแนปส์ส่วนบุคคล ไปจนถึงวงจรและบริเวณสมอง พฤติกรรม การรับรู้ และจิตสำนึก สมองเป็นโครงสร้างที่ซับซ้อนที่สุดในจักรวาลนี้ โดยมีเซลล์ประสาทประมาณ 86 พันล้านเซลล์เชื่อมต่อกันด้วยไซแนปส์หลายล้านล้านเซลล์ และการทำความเข้าใจว่ามันทำงานอย่างไรถือเป็นหนึ่งในความท้าทายที่ยิ่งใหญ่ของวิทยาศาสตร์
---

## เซลล์ประสาท
### ส่วนของเซลล์ประสาท
| ส่วนประกอบ | ฟังก์ชัน |
|----------|----------|
| **เดนไดรต์** | รับสัญญาณจากเซลล์ประสาทอื่น ส่วนขยายที่เหมือนสาขา |
| **ตัวเซลล์(โสม)** | รวมสัญญาณขาเข้า ประกอบด้วยนิวเคลียส |
| **แอกซอน** | เส้นใยยาวที่ส่งสัญญาณไฟฟ้า (ศักยะงาน) ออกห่างจากโสม |
| **เปลือกไมอีลิน** | ชั้นฉนวนรอบแอกซอน เร่งความเร็วในการส่งสัญญาณ |
| **โหนดของแรนเวียร์** | ช่องว่างในไมอีลิน อนุญาตให้นำเกลือ (สัญญาณข้ามระหว่างโหนด) |
| **เทอร์มินัล Axon (บูตงซินแนปติก)** | ปล่อยสารสื่อประสาทเข้าสู่ไซแนปส์ |
### ประเภทของเซลล์ประสาท
| พิมพ์ | ทิศทาง | ฟังก์ชัน |
|------|-----------|----------|
| **ประสาทสัมผัส (อวัยวะ)** | ร่างกาย → สมอง | นำข้อมูลจากประสาทสัมผัส (สัมผัส อุณหภูมิ ความเจ็บปวด การมองเห็น ฯลฯ) |
| **มอเตอร์ (ออกฤทธิ์)** | สมอง → ร่างกาย | ควบคุมกล้ามเนื้อและต่อมต่างๆ |
| **นักศึกษาฝึกงาน** | ภายใน CNS | เชื่อมต่อเซลล์ประสาทกับเซลล์ประสาทอื่น เซลล์ประสาทส่วนใหญ่เป็นอินเตอร์นิวรอน |

## เซลล์ประสาทสื่อสารอย่างไร
### ศักยภาพการดำเนินการ
| เฟส | คำอธิบาย |
|-------|-------------|
| **ศักยภาพในการพักผ่อน** | เซลล์ประสาทอยู่ที่ ~-70 mV; ปั๊มโซเดียม-โพแทสเซียมรักษาสมดุลของไอออน |
| **ดีโพลาไรซ์** | สิ่งกระตุ้นจะเปิดช่องโซเดียม Na+ รีบเข้ามา; ศักยภาพของเมมเบรนเพิ่มขึ้น |
| **เกณฑ์** | หากศักย์ไฟฟ้าถึง ~-55 mV ศักย์ไฟฟ้าจะเกิดเพลิงไหม้ (ทั้งหมดหรือไม่มีเลย) |
| **ระยะที่เพิ่มขึ้น** | ช่องโซเดียมที่มีรั้วรอบขอบชิดเปิดอยู่ อาจเพิ่มขึ้นถึง ~+40 mV |
| **ระยะตก** | ช่องโซเดียมปิด; ช่องโพแทสเซียมเปิด K+ ไหลออกมา; อาจลดลง |
| **อันเดอร์ชูต (ไฮเปอร์โพลาไรเซชัน)** | ศักยภาพจะลดลงต่ำกว่าระดับพักชั่วคราว |
| **ช่วงทนไฟ** | เซลล์ประสาทไม่สามารถยิงได้อีกในทันที ช่วยให้มั่นใจได้ถึงการแพร่กระจายในทิศทางเดียว |
### ไซแนปส์
| ส่วนประกอบ | บทบาท |
|-----------|-|
| **เซลล์ประสาทพรีไซแนปติก** | ส่งสัญญาณ; มีถุงซินแนปติกพร้อมสารสื่อประสาท
| **รอยแยกซินแนปติก** | ช่องว่างเล็กๆ (~20 นาโนเมตร) ระหว่างเซลล์ประสาท
| **เซลล์ประสาทหลังซินแนปติก** | รับสัญญาณ; มีโปรตีนตัวรับ |
| **สารสื่อประสาท** | สารเคมีที่ส่งผ่านไซแนปส์ |
| **ตัวรับ** | ผูกสารสื่อประสาท; ช่องไอออนเปิดหรือทริกเกอร์ผู้ส่งสารคนที่สองลดหลั่น |

## สารสื่อประสาทที่สำคัญ
| สารสื่อประสาท | ฟังก์ชัน | เงื่อนไขที่เกี่ยวข้อง |
|-----------------|----------|----------------------|
| **กลูตาเมต** | สารสื่อประสาทกระตุ้นหลัก การเรียนรู้; หน่วยความจำ | ส่วนเกิน → ความเป็นพิษต่อร่างกาย (โรคหลอดเลือดสมอง, การเสื่อมของระบบประสาท) |
| **กาบา** | สารสื่อประสาทยับยั้งหลัก ลดการทำงานของระบบประสาท | การขาดดุล → ความวิตกกังวล โรคลมบ้าหมู |
| **โดปามีน** | รางวัล; แรงจูงใจ; การควบคุมมอเตอร์ ความสนใจ | การขาดดุล → พาร์กินสัน; ส่วนเกิน → โรคจิตเภท |
| **เซโรโทนิน** | อารมณ์; นอน; ความอยากอาหาร; การย่อยอาหาร | การขาดดุล → ซึมเศร้า วิตกกังวล |
| **อะเซทิลโคลีน** | การกระตุ้นกล้ามเนื้อ การเรียนรู้; หน่วยความจำ | การขาดดุล → โรคอัลไซเมอร์ |
| **นอร์อิพิเนฟริน** | เร้าอารมณ์; ความตื่นตัว; การตอบสนองต่อความเครียด | ความผิดปกติ → ADHD; ภาวะซึมเศร้า |
| **เอ็นโดรฟิน** | บรรเทาอาการปวด; ความสุข | การปล่อยตัวที่เกิดจากการออกกำลังกาย ("นักวิ่งสูง") |

## โครงสร้างสมอง
### บริเวณสมองหลัก
| ภูมิภาค | ฟังก์ชัน |
|--------|----------|
| **เปลือกสมอง** | ความรู้ความเข้าใจที่สูงขึ้น แบ่งออกเป็นหน้าผาก, ข้างขม่อม, ขมับ, กลีบท้ายทอย |
| **กลีบหน้าผาก** | การวางแผน; การตัดสินใจ; บุคลิกภาพ; การเคลื่อนไหวโดยสมัครใจ (เยื่อหุ้มสมองยนต์) |
| **กลีบข้างขม่อม** | การประมวลผลทางประสาทสัมผัส การรับรู้เชิงพื้นที่ การนำทาง |
| **กลีบขมับ** | การได้ยิน; ความเข้าใจภาษา หน่วยความจำ (ฮิปโปแคมปัส) |
| **กลีบท้ายทอย** | การประมวลผลภาพ |
| **สมองน้อย** | การประสานงานของมอเตอร์ สมดุล; การเรียนรู้เกี่ยวกับมอเตอร์ ฟังก์ชั่นการรับรู้บางอย่าง |
| **ก้านสมอง** | ฟังก์ชั่นที่สำคัญ: การหายใจ; อัตราการเต้นของหัวใจ วงจรการนอนหลับ-ตื่น |
| **ฐานดอก** | สถานีถ่ายทอดประสาทสัมผัส ส่งสัญญาณไปยังบริเวณเปลือกนอกที่เหมาะสม |
| **ไฮโปทาลามัส** | สภาวะสมดุล; การควบคุมฮอร์โมน ความหิว; กระหาย; จังหวะการเต้นของหัวใจ |
### ระบบลิมบิก
| โครงสร้าง | ฟังก์ชัน |
|----------|----------|
| **อมิกดาลา** | การประมวลผลทางอารมณ์ กลัว; การตรวจจับภัยคุกคาม ความทรงจำทางอารมณ์ |
| **ฮิปโปแคมปัส** | การสร้างความทรงจำ การนำทางเชิงพื้นที่ แปลงหน่วยความจำระยะสั้นเป็นหน่วยความจำระยะยาว |
| **ปมประสาทฐาน** | การสร้างนิสัย รางวัลการเรียนรู้ การควบคุมมอเตอร์ |
| **เยื่อหุ้มสมองซิงกูเลต** | การตรวจจับข้อผิดพลาด ความเข้าอกเข้าใจ; การควบคุมแรงกระตุ้น การควบคุมอารมณ์ |
| **นิวเคลียส แอคคัมเบนส์** | วงจรรางวัล; ความพึงพอใจ; ติดยาเสพติด |

## ประสาทวิทยาศาสตร์เกี่ยวกับความรู้ความเข้าใจ
### ฟังก์ชั่นการรับรู้ที่สำคัญและบริเวณสมอง
| ฟังก์ชัน | พื้นที่สมองปฐมภูมิ |
|----------|-------------------|
| **คำเตือน** | เยื่อหุ้มสมองส่วนหน้า; เยื่อหุ้มสมองข้างขม่อม; ฐานดอก |
| **หน่วยความจำการทำงาน** | เยื่อหุ้มสมองส่วนหน้า; เยื่อหุ้มสมองข้างขม่อม |
| **ความจำระยะยาว** | ฮิปโปแคมปัส (รูปแบบ); เยื่อหุ้มสมอง (ที่เก็บข้อมูล) |
| **ภาษา** | พื้นที่ของ Broca (การผลิต); พื้นที่ของเวอร์นิเก (ความเข้าใจ) |
| **การควบคุมอารมณ์** | เยื่อหุ้มสมองส่วนหน้า; ต่อมทอนซิล; เวนโตรมีเดียล PFC |
| **การตัดสินใจ** | เยื่อหุ้มสมองส่วนหน้า; เยื่อหุ้มสมองส่วนหน้า; ริ้ว |
| **การประมวลผลภาพ** | กลีบท้ายทอย → กระแสหน้าท้อง ("อะไร") และกระแสหลัง ("ที่ไหน") |
| **การควบคุมมอเตอร์** | เยื่อหุ้มสมองมอเตอร์; สมองน้อย; ปมประสาทฐาน |
### คลื่นสมอง
| คลื่น | ความถี่ | รัฐที่เกี่ยวข้อง |
|------|-----------|-----------------|
| **เดลต้า** | 0.5–4 เฮิร์ตซ์ | นอนหลับลึก |
| **ทีต้า** | 4–8 เฮิร์ตซ์ | นอนหลับสบาย; การทำสมาธิ; อาการง่วงนอน |
| **อัลฟ่า** | 8–13 เฮิร์ตซ์ | ผ่อนคลายความตื่นตัว; ปิดตา |
| **เบต้า** | 13–30 เฮิรตซ์ | คิดอย่างกระตือรือร้น จุดสนใจ; ความตื่นตัว |
| **แกมมา** | 30–100 เฮิรตซ์ | ความรู้ความเข้าใจที่สูงขึ้น ผูกพัน; สติ |

## ความยืดหยุ่นของระบบประสาท
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **ความเป็นพลาสติกแบบซินแนปติก** | ความแรงของไซแนปส์เปลี่ยนไปตามกิจกรรม | ศักยภาพระยะยาว (LTP); ภาวะซึมเศร้าระยะยาว (LTD) |
| **ความเป็นพลาสติกของโครงสร้าง** | เซลล์ประสาทสร้างเดนไดรต์หรือแอกซอนใหม่ การเรียนรู้ทักษะใหม่ ฟื้นตัวจากอาการบาดเจ็บ |
| **การแมปเยื่อหุ้มสมองใหม่** | บริเวณสมองกำหนดฟังก์ชันใหม่ | เยื่อหุ้มสมองการมองเห็นของคนตาบอด ประมวลผลการสัมผัสและเสียง |
| **การสร้างระบบประสาท** | เซลล์ประสาทใหม่ถือกำเนิดขึ้น | เกิดขึ้นในฮิบโป; กระตุ้นด้วยการออกกำลังกายและการเรียนรู้ |

## วิธีการวิจัย
| วิธีการ | มันวัดอะไร | ความละเอียด |
|--------|-----------------|------------|
| **fMRI** | ระดับออกซิเจนในเลือด (สัญญาณ BOLD) → การทำงานของสมอง | เชิงพื้นที่ที่ดี (~ 1 มม.) ชั่วขณะไม่ดี (~ 1 วินาที) |
| **EEG** | กิจกรรมทางไฟฟ้าจากหนังศีรษะ | ชั่วขณะที่ดีเยี่ยม (~ 1 ms); เชิงพื้นที่ไม่ดี |
| **เม็ก** | สนามแม่เหล็กจากกิจกรรมประสาท | ชั่วคราวและเชิงพื้นที่ที่ดี |
| **สัตว์เลี้ยง** | ตัวติดตามกัมมันตภาพรังสี → กิจกรรมการเผาผลาญ | เชิงพื้นที่และเชิงเวลาปานกลาง |
| **ทีเอ็มเอส** | คลื่นแม่เหล็ก → รบกวนพื้นที่สมองชั่วคราว | หลักฐานเชิงสาเหตุ ความลึกจำกัด |
| **การบันทึกหน่วยเดียว** | กิจกรรมทางไฟฟ้าของเซลล์ประสาทแต่ละตัว | เซลล์เดียว รุกราน; การวิจัยสัตว์ส่วนใหญ่ |
| **ออพโตเจเนติกส์** | เซลล์ประสาทที่กระตุ้นด้วยแสง | การควบคุมที่แม่นยำ การวิจัยสัตว์ |
| **DTI** (การถ่ายภาพเทนเซอร์แบบกระจาย) | ทางเดินสสารสีขาว | การทำแผนที่การเชื่อมต่อ |

## สรุป
ประสาทวิทยาศาสตร์ศึกษาระบบประสาทในทุกระดับ ตั้งแต่กลไกระดับโมเลกุลของช่องไอออนไปจนถึงประสบการณ์ส่วนตัวของการมีสติ เซลล์ประสาทสื่อสารผ่านศักยะงานทางไฟฟ้าและไซแนปส์ทางเคมี โดยใช้สารสื่อประสาท เช่น กลูตาเมต GABA โดปามีน และเซโรโทนิน สมองถูกจัดเป็นบริเวณเฉพาะ: เปลือกสมองสำหรับการรับรู้ที่สูงขึ้น, ระบบลิมบิกสำหรับอารมณ์และความทรงจำ, สมองน้อยสำหรับการประสานงาน ความยืดหยุ่นของระบบประสาทหมายถึงสมองสามารถเชื่อมต่อตัวเองใหม่ได้ตลอดชีวิต วิธีการวิจัยมีตั้งแต่ fMRI (ความละเอียดเชิงพื้นที่ที่ดี) ไปจนถึง EEG (ความละเอียดชั่วคราวที่ดี) ไปจนถึงออพโตเจเนติกส์ (การควบคุมสาเหตุที่แม่นยำ) การทำความเข้าใจสมองถือเป็นปัญหาที่ยากที่สุดในทางวิทยาศาสตร์ เป็นอวัยวะเดียวที่ศึกษาตัวเอง
