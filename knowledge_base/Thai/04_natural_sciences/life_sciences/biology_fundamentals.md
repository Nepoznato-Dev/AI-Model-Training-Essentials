# พื้นฐานชีววิทยา
ชีววิทยาเป็นศาสตร์แห่งชีวิต สิ่งมีชีวิตทุกชนิดมีคุณสมบัติบางอย่างร่วมกัน ได้แก่ พวกมันสร้างจากเซลล์ ใช้พลังงาน เติบโต ตอบสนองต่อสภาพแวดล้อม สืบพันธุ์ และพัฒนา ชีววิทยาครอบคลุมตั้งแต่กลไกระดับโมเลกุลภายในเซลล์เดียวไปจนถึงปฏิสัมพันธ์ของระบบนิเวศทั้งหมด และเป็นรากฐานของการแพทย์ เกษตรกรรม เทคโนโลยีชีวภาพ และการอนุรักษ์
---

## เซลล์ — หน่วยพื้นฐาน
สิ่งมีชีวิตทุกชนิดประกอบด้วยเซลล์ มีสองประเภทพื้นฐาน:
### โปรคาริโอตกับยูคาริโอต
| คุณสมบัติ | โปรคาริโอต | ยูคาริโอต |
|---------|-------------|------------|
| **นิวเคลียส** | ไม่ — DNA ลอยได้อย่างอิสระ | ใช่ — DNA อยู่ในเยื่อหุ้มเซลล์ |
| **ขนาด** | เล็ก (1-5 μm) | ใหญ่กว่า (10-100 μm) |
| **ตัวอย่าง** | แบคทีเรีย อาร์เคีย | สัตว์ พืช เห็ดรา กลุ่มผู้ประท้วง |
| **ความซับซ้อน** | ง่าย | โครงสร้างภายในที่ซับซ้อน (ออร์แกเนล) |
| **การสืบพันธุ์** | ฟิชชันแบบไบนารี | ไมโทซิสหรือไมโอซิส |
| **แบบฟอร์มดีเอ็นเอ** | โครโมโซมวงกลมเดี่ยว | โครโมโซมเชิงเส้นหลายตัว |
| **ออร์แกเนลส์** | ไม่มี (ไรโบโซมเท่านั้น) | Mitochondria, ER, Golgi, ไลโซโซม ฯลฯ |
### ออร์แกเนลล์ที่สำคัญ
| ออร์แกเนลล์ | ฟังก์ชัน | พบใน |
|----------|----------|----------|
| **นิวเคลียส** | เก็บดีเอ็นเอ; ควบคุมกิจกรรมของเซลล์ | ยูคาริโอตเท่านั้น |
| **ไมโตคอนเดรีย** | การหายใจระดับเซลล์ ผลิต ATP (สกุลเงินพลังงาน) | ยูคาริโอตเท่านั้น |
| **คลอโรพลาสต์** | การสังเคราะห์ด้วยแสง; แปลงพลังงานแสงเป็นพลังงานเคมี | เซลล์พืชเท่านั้น |
| **ตาข่ายเอนโดพลาสมิก** | การสังเคราะห์โปรตีนและไขมัน | ยูคาริโอตเท่านั้น |
| **อุปกรณ์กอลจิ** | ดัดแปลง บรรจุ และจัดส่งโปรตีน | ยูคาริโอตเท่านั้น |
| **ไรโบโซม** | การสังเคราะห์โปรตีน (แปล mRNA) | เซลล์ทั้งหมด |
| **เยื่อหุ้มเซลล์** | ควบคุมสิ่งที่เข้า/ออกจากเซลล์ | เซลล์ทั้งหมด |
| **ผนังเซลล์** | การสนับสนุนโครงสร้างและการป้องกัน | พืช เชื้อรา แบคทีเรีย |
| **แวคิวโอล** | พื้นที่จัดเก็บ; รักษาแรงดัน turgor ในพืช ทั้งหมด (ใหญ่ในพืช) |
| **ไลโซโซม** | การย่อยอาหารและการกำจัดของเสีย | เซลล์สัตว์เป็นหลัก |

## ดีเอ็นเอและพันธุศาสตร์
DNA คือคู่มือการใช้งานสำหรับการสร้างและดำเนินสิ่งมีชีวิต มันเป็นเกลียวคู่ที่ประกอบด้วยฐานสี่ฐาน: อะดีนีน (A), ไทมีน (T), ไซโตซีน (C) และกัวนีน (G) A จับคู่กับ T เสมอ C จับคู่กับ G เสมอ การจับคู่นี้เป็นวิธีที่ DNA คัดลอกตัวเอง
### จาก DNA สู่โปรตีน
| ขั้นตอน | กระบวนการ | ที่ไหน | เกิดอะไรขึ้น |
|------|---------|-------|-------------|
| **การจำลอง** | ดีเอ็นเอ → ดีเอ็นเอ | นิวเคลียส | ดีเอ็นเอคลี่คลาย แต่ละเส้นทำหน้าที่เป็นเทมเพลตสำหรับสำเนาใหม่ |
| **การถอดความ** | ดีเอ็นเอ → mRNA | นิวเคลียส | ยีนถูกคัดลอกไปยัง Messenger RNA |
| **คำแปล** | mRNA → โปรตีน | ไรโบโซม | mRNA ถูกอ่านเป็นแฝด (codons); โคดอนแต่ละตัวระบุกรดอะมิโน |
การไหลนี้ — DNA → RNA → โปรตีน — เรียกว่า **ความเชื่อหลัก** ของอณูชีววิทยา
### ยีนและโครโมโซม
ยีนเป็นส่วนต่างๆ ของ DNA ที่สร้างรหัสสำหรับโปรตีน จีโนมมนุษย์ประกอบด้วยยีนประมาณ 20,000 ยีนในโครโมโซม 23 คู่ การกลายพันธุ์ — การเปลี่ยนแปลงในลำดับดีเอ็นเอ — เป็นวัตถุดิบของการวิวัฒนาการ
| ประเภทการกลายพันธุ์ | คำอธิบาย | ตัวอย่างเอฟเฟกต์ |
|------------------|-------------|----------------|
| **การเปลี่ยนแปลงจุด** | การเปลี่ยนแปลงฐานเดียว (A → G) | โรคโลหิตจางชนิดเคียว (การเปลี่ยนแปลงฐานหนึ่งของยีนฮีโมโกลบิน) |
| **การแทรก** | เพิ่มฐานพิเศษแล้ว | เฟรมชิฟต์; มักจะก่อกวน |
| **การลบ** | ลบฐานแล้ว | เฟรมชิฟต์; ทำให้เกิดโรคได้ |
| **การทำสำเนา** | คัดลอกส่วนแล้ว | สำเนายีนพิเศษ สามารถนำไปสู่ฟังก์ชั่นใหม่เมื่อเวลาผ่านไป |
| **โครโมโซม** | การจัดเรียงใหม่ขนาดใหญ่ | การโยกย้าย; อาจทำให้เกิดมะเร็งหรือมีบุตรยากได้ |
การกลายพันธุ์ส่วนใหญ่ไม่เป็นอันตราย บางชนิดมีประโยชน์ และบางชนิดทำให้เกิดโรค

## วิวัฒนาการโดยการคัดเลือกโดยธรรมชาติ
วิวัฒนาการไม่ใช่ "เพียงทฤษฎี" ในแง่ภาษาพูด แต่เป็นกรอบการทำงานที่รวมเป็นหนึ่งเดียวของชีววิทยาทั้งหมด กลไกตรงไปตรงมา:
1. สิ่งมีชีวิตผลิตลูกหลานได้มากกว่าที่สิ่งแวดล้อมสามารถรองรับได้
2. บุคคลมีลักษณะแตกต่างกันไป (ลักษณะบางอย่างสามารถถ่ายทอดทางพันธุกรรมได้)
3. บุคคลที่มีลักษณะเหมาะสมกับสภาพแวดล้อมมากกว่ามีแนวโน้มที่จะอยู่รอดและสืบพันธุ์ได้
4. เมื่อผ่านไปหลายชั่วอายุคน ลักษณะที่ได้เปรียบจะพบเห็นได้ทั่วไปในประชากร
กระบวนการนี้อธิบายความหลากหลายของสิ่งมีชีวิตทั้งหมดบนโลก โดยไม่ต้องใช้สติปัญญานำทางใดๆ ตั้งแต่แบคทีเรียไปจนถึงวาฬสีน้ำเงิน
### หลักฐานวิวัฒนาการ
| ประเภทหลักฐาน | คำอธิบาย |
|---------------|-------------|
| **บันทึกฟอสซิล** | แสดงให้เห็นการเปลี่ยนแปลงอย่างค่อยเป็นค่อยไปในช่วงหลายพันล้านปี รูปแบบการนำส่ง (Archaeopteryx, Tiktaalik) |
| **กายวิภาคเปรียบเทียบ** | โครงสร้างที่คล้ายคลึงกัน (แขนมนุษย์ ตีนกบวาฬ ปีกค้างคาว มีโครงร่างกระดูกเหมือนกัน) |
| **อณูชีววิทยา** | ลำดับ DNA และโปรตีนมีความคล้ายคลึงกันมากกว่าในสปีชีส์ที่เกี่ยวข้องอย่างใกล้ชิด |
| **ชีวภูมิศาสตร์** | การกระจายพันธุ์ตรงกับรูปแบบการเคลื่อนตัวของทวีปและการแยกตัว |
| **วิวัฒนาการที่สังเกตได้** | ความต้านทานยาปฏิชีวนะในแบคทีเรีย ความต้านทานต่อสารกำจัดศัตรูพืชในแมลง การทดลองในห้องปฏิบัติการ |
### กลไกของวิวัฒนาการ
| กลไก | คำอธิบาย |
|-----------|-------------|
| **คัดเลือกโดยธรรมชาติ** | ลักษณะที่ได้เปรียบกลายเป็นเรื่องปกติไปหลายชั่วอายุคน |
| **การดริฟท์ทางพันธุกรรม** | การเปลี่ยนแปลงความถี่อัลลีลแบบสุ่ม แข็งแกร่งขึ้นในประชากรขนาดเล็ก |
| **การไหลของยีน** | การย้ายถิ่นของบุคคล (และยีน) ระหว่างประชากร |
| **การกลายพันธุ์** | การแปรผันทางพันธุกรรมใหม่ที่เกิดจากการเปลี่ยนแปลง DNA |
| **การเลือกเพศ** | ลักษณะที่ช่วยเพิ่มความสำเร็จในการผสมพันธุ์กลายเป็นเรื่องปกติมากขึ้น (หางนกยูง) |
| **ข้อมูลจำเพาะ** | ประชากรจะแตกต่างกันออกไปจนกระทั่งไม่สามารถผสมข้ามพันธุ์ได้อีกต่อไป |

## นิเวศวิทยา
นิเวศวิทยาศึกษาว่าสิ่งมีชีวิตมีปฏิสัมพันธ์กันและกับสิ่งแวดล้อมอย่างไร
### ระดับขององค์กร
| ระดับ | คำอธิบาย | ตัวอย่าง |
|-------|-------------|---------|
| **สิ่งมีชีวิต** | สิ่งมีชีวิตส่วนบุคคล | กวางตัวหนึ่ง |
| **ประชากร** | กลุ่มพันธุ์เดียวกันในพื้นที่ | ฝูงกวาง |
| **ชุมชน** | ประชากรทั้งหมดในพื้นที่ | กวาง + กระต่าย + นก + แมลง + พืช |
| **ระบบนิเวศ** | ชุมชน + สภาพแวดล้อมทางกายภาพ | ป่า + สิ่งมีชีวิตทั้งหมด + ดิน + น้ำ + ภูมิอากาศ |
| **ชีวมณฑล** | ระบบนิเวศทั้งหมดบนโลก | ทุกสิ่งตั้งแต่ท้องทะเลลึกไปจนถึงบรรยากาศชั้นบน |
### การไหลของพลังงาน
| แนวคิด | คำอธิบาย |
|---------|-------------|
| **ผู้ผลิต** | แปลงแสงแดดเป็นพลังงาน (พืช สาหร่าย ไซยาโนแบคทีเรีย) |
| **ผู้บริโภคหลัก** | กินผู้ผลิต (สัตว์กินพืช: กวาง, กระต่าย) |
| **ผู้บริโภครอง** | กินผู้บริโภคหลัก (สัตว์กินเนื้อ : หมาป่า) |
| **ผู้บริโภคระดับอุดมศึกษา** | สัตว์นักล่าอันดับต้นๆ (อินทรี ออร์กา) |
| **ตัวย่อยสลาย** | สลายสารที่ตายแล้ว (เชื้อรา แบคทีเรีย) |
มีการถ่ายโอนพลังงานระหว่างระดับสารอาหารเพียงประมาณ 10% เท่านั้น ส่วนที่เหลือจะสูญเสียไปในรูปของความร้อน นี่คือเหตุผลว่าทำไมห่วงโซ่อาหารจึงไม่ค่อยมีระดับเกิน 4-5 และเหตุใดจึงมีผู้ล่าน้อยกว่าเหยื่อ
### วัฏจักรชีวธรณีเคมี
| วงจร | กระบวนการสำคัญ |
|-------|-------------|
| **วัฏจักรคาร์บอน** | การสังเคราะห์ด้วยแสงจะกำจัดCO₂; การหายใจและการเผาไหม้จะปล่อยออกมา |
| **วัฏจักรไนโตรเจน** | แบคทีเรียตรึงไนโตรเจนจะเปลี่ยน N₂ เป็นรูปแบบที่ใช้งานได้ ดีไนตริไฟริ่งแบคทีเรียคืนความมัน |
| **วัฏจักรของน้ำ** | การระเหย → การควบแน่น → การตกตะกอน → การไหลบ่า → ทำซ้ำ |
| **วัฏจักรฟอสฟอรัส** | การผุกร่อนของหินจะปล่อยฟอสฟอรัสออกมา ไม่มีเฟสบรรยากาศ |

## อนุกรมวิธานและต้นไม้แห่งชีวิต
สิ่งมีชีวิตทั้งหมดแบ่งออกเป็นลำดับชั้น: โดเมน → อาณาจักร → ไฟลัม → คลาส → ลำดับ → ครอบครัว → สกุล → สปีชีส์
### สามโดเมน
| โดเมน | ประเภทเซลล์ | คุณสมบัติที่สำคัญ | ตัวอย่าง |
|----------------------|-----------|-------------|---------|
| **แบคทีเรีย** | โปรคาริโอต | ผนังเซลล์เปปติโดไกลแคน แบคทีเรียที่คุ้นเคยที่สุด | อี. โคไล สเตรปโตคอคคัส |
| **อาร์เคีย** | โปรคาริโอต | ไม่มีเพปทิโดไกลแคน; มักเป็นพวกหัวรุนแรง | เมทาโนเจน, ฮาโลฟิล, เทอร์โมฟิล |
| **ยูคาร์ยา** | ยูคาริโอต | นิวเคลียสและออร์แกเนลล์ที่จับกับเมมเบรน | อย่างอื่น |
### อาณาจักรภายใน Eukarya
| ราชอาณาจักร | คุณสมบัติที่สำคัญ | ตัวอย่าง |
|---------|-------------|---------|
| **สัตว์เดรัจฉาน** | หลายเซลล์; เฮเทอโรโทรฟิก; ไม่มีผนังเซลล์ | คน แมลง ปลา นก |
| **แพลนเต้** | หลายเซลล์; ออโตโทรฟิก (การสังเคราะห์ด้วยแสง); ผนังเซลล์เซลลูโลส | ต้นไม้ หญ้า เฟิร์น มอส |
| **เชื้อรา** | ส่วนใหญ่เป็นเซลล์หลายเซลล์ เฮเทอโรโทรฟิก (การดูดซึม); ผนังเซลล์ไคติน | เห็ด ยีสต์ เชื้อรา |
| **โปรติสต้า** | ส่วนใหญ่เป็นเซลล์เดียว หลากหลาย | อะมีบา สาหร่าย พารามีเซียม |

## สรุป
ชีววิทยาเป็นศาสตร์แห่งชีวิตตั้งแต่โมเลกุลไปจนถึงระบบนิเวศ สิ่งมีชีวิตทั้งหมดประกอบด้วยเซลล์ ไม่ว่าจะเป็นโปรคาริโอตเชิงเดี่ยว (แบคทีเรีย อาร์เคีย) หรือยูคาริโอตเชิงซ้อน (สัตว์ พืช เชื้อรา) DNA นำข้อมูลทางพันธุกรรมผ่านความเชื่อหลัก: DNA → RNA → โปรตีน วิวัฒนาการโดยการคัดเลือกโดยธรรมชาติเป็นกรอบการทำงานที่รวมเป็นหนึ่งเดียว โดยมีฟอสซิล กายวิภาคศาสตร์ อณูชีววิทยา ชีวภูมิศาสตร์ และการสังเกตโดยตรง นิเวศวิทยาศึกษาว่าสิ่งมีชีวิตมีปฏิสัมพันธ์ระหว่างกันและสิ่งแวดล้อมอย่างไร โดยพลังงานที่ไหลจากผู้ผลิตผ่านผู้บริโภคและผู้ย่อยสลาย ต้นไม้แห่งชีวิตแบ่งสิ่งมีชีวิตทั้งหมดออกเป็นสามโดเมน ได้แก่ แบคทีเรีย อาร์เคีย และยูคาร์ยา โดยแบ่งย่อยออกเป็นอาณาจักร ไฟลา และสปีชีส์ ชีววิทยาเป็นพื้นฐานของการแพทย์ เกษตรกรรม เทคโนโลยีชีวภาพ และการอนุรักษ์
