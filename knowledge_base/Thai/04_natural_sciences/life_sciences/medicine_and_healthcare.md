# ยาและการดูแลสุขภาพ
การแพทย์เป็นศาสตร์และการฝึกฝนในการวินิจฉัย การรักษา และการป้องกันโรค นี่เป็นหนึ่งในความพยายามของมนุษย์ที่เก่าแก่ที่สุด - คำสาบานของฮิปโปเครติสมีมาตั้งแต่สมัยกรีกโบราณ - และเป็นหนึ่งในความพยายามที่เปลี่ยนแปลงอย่างรวดเร็วที่สุด ในศตวรรษที่ผ่านมาเพียงศตวรรษเดียว เราเปลี่ยนจากการไม่มียาปฏิชีวนะ มาเป็นการบำบัดด้วยยีนที่สามารถสร้าง DNA ของผู้ป่วยขึ้นมาใหม่ได้
ไฟล์นี้ครอบคลุมถึงวิธีการทำงานของยา: ความเชี่ยวชาญเฉพาะทาง, วิธีการวินิจฉัยและการรักษาโรค, วิธีการจัดการระบบการดูแลสุขภาพ และคำถามทางจริยธรรมที่เกิดขึ้นเมื่อชีวิตมนุษย์ตกอยู่ในอันตราย

## วิธีการทำงานของร่างกาย — บทแนะนำสั้นๆ
ก่อนจะทำความเข้าใจเรื่องโรคจะช่วยให้เข้าใจว่าสุขภาพดีเป็นอย่างไร ร่างกายมนุษย์มีระบบอวัยวะหลัก 11 ระบบ ซึ่งแต่ละระบบมีหน้าที่เฉพาะแต่ล้วนเชื่อมโยงกันอย่างลึกซึ้ง
| ระบบ | อวัยวะสำคัญ | ฟังก์ชันหลัก | ปัญหาทั่วไป |
|----------------------|-----------|-----------------|-----------------|
| **โรคหัวใจและหลอดเลือด** | หัวใจ หลอดเลือด | สูบฉีดเลือด; ส่งออกซิเจนและสารอาหาร | โรคหัวใจ โรคหลอดเลือดสมอง ความดันโลหิตสูง |
| **ระบบทางเดินหายใจ** | ปอด, ทางเดินหายใจ | แลกเปลี่ยนออกซิเจนและคาร์บอนไดออกไซด์ | โรคหอบหืด ปอดอุดกั้นเรื้อรัง ปอดบวม มะเร็งปอด |
| **การย่อยอาหาร** | กระเพาะอาหาร ลำไส้ ตับ ตับอ่อน | สลายอาหาร ดูดซับสารอาหาร กำจัดของเสีย | โรคกรดไหลย้อน แผลในกระเพาะอาหาร IBD โรคตับ |
| **ประสาท** | สมอง ไขสันหลัง เส้นประสาท | ข้อมูลกระบวนการ ควบคุมการทำงานของร่างกาย | อัลไซเมอร์ พาร์กินสัน โรคลมบ้าหมู โรคหลอดเลือดสมอง |
| **ต่อมไร้ท่อ** | ต่อมใต้สมอง, ต่อมไทรอยด์, ต่อมหมวกไต, ตับอ่อน | ผลิตฮอร์โมนที่ควบคุมการเผาผลาญ การเจริญเติบโต การสืบพันธุ์ | เบาหวาน โรคไทรอยด์ โรคอ้วน |
| **ภูมิคุ้มกัน/น้ำเหลือง** | เม็ดเลือดขาว ต่อมน้ำเหลือง ม้าม | ป้องกันเชื้อโรค | โรคภูมิต้านตนเอง ภูมิคุ้มกันบกพร่อง โรคภูมิแพ้ |
| **กล้ามเนื้อและกระดูก** | กระดูก กล้ามเนื้อ ข้อต่อ | ร่างกายรองรับ; เปิดใช้งานการเคลื่อนไหว | โรคข้ออักเสบ โรคกระดูกพรุน กระดูกหัก ปวดหลัง |
| **ปัสสาวะ/ไต** | ไต, กระเพาะปัสสาวะ | กรองเลือด กำจัดของเสีย; ควบคุมของเหลว | โรคไต โรคติดเชื้อ นิ่วในไต |
| **การสืบพันธุ์** | รังไข่/อัณฑะ มดลูก ฯลฯ | เปิดใช้งานการทำซ้ำ | ภาวะมีบุตรยาก มะเร็ง ความผิดปกติของฮอร์โมน |
| **จำนวนเต็ม** | ผิว ผม เล็บ | ปกป้องร่างกาย ควบคุมอุณหภูมิ | กลาก สะเก็ดเงิน มะเร็งผิวหนัง การติดเชื้อ |
| **โลหิตวิทยา** | เลือดไขกระดูก | ขนส่งออกซิเจน ต่อสู้กับการติดเชื้อ ลิ่มเลือด | โรคโลหิตจาง มะเร็งเม็ดเลือดขาว ความผิดปกติของการแข็งตัวของเลือด |
### สภาวะสมดุลของร่างกาย - พระราชบัญญัติการปรับสมดุลของร่างกาย
ทุกระบบในร่างกายทำงานเพื่อรักษา **สภาวะสมดุล** — รักษาสภาวะภายในให้คงที่แม้จะมีการเปลี่ยนแปลงจากภายนอก อุณหภูมิร่างกายของคุณอยู่ที่ประมาณ 37°C ไม่ว่าจะข้างนอกหนาวจัดหรือร้อนอบอ้าว pH ในเลือดอยู่ระหว่าง 7.35 ถึง 7.45 ระดับน้ำตาลในเลือดเพิ่มขึ้นและลดลงในช่วงแคบๆ ซึ่งควบคุมโดยอินซูลินและกลูคากอน
โรคมักเกิดขึ้นเมื่อสภาวะสมดุลลดลง ไข้คือระบบภูมิคุ้มกันของคุณที่จงใจเพิ่มอุณหภูมิร่างกายเพื่อต่อสู้กับการติดเชื้อ โรคเบาหวานคือความล้มเหลวของการควบคุมระดับน้ำตาลในเลือด ภาวะหัวใจล้มเหลวคือระบบหัวใจและหลอดเลือดไม่สามารถรักษาการไหลเวียนของเลือดได้อย่างเพียงพอ

## ความเชี่ยวชาญทางการแพทย์
การแพทย์มีความเชี่ยวชาญสูง คำแนะนำที่เป็นประโยชน์สำหรับผู้ที่ทำสิ่งใดมีดังนี้
| พิเศษ | โฟกัส | เงื่อนไขทั่วไป |
|----------|-------|-------------------|
| **หทัยวิทยา** | หัวใจและหลอดเลือด | หัวใจวาย หัวใจเต้นผิดจังหวะ หัวใจล้มเหลว |
| **ประสาทวิทยา** | ระบบประสาทและสมอง | โรคหลอดเลือดสมอง, โรคลมบ้าหมู, MS, พาร์กินสัน |
| **มะเร็งวิทยา** | มะเร็ง | เนื้องอกทุกประเภท (อ่อนโยนและร้าย) |
| **ระบบทางเดินอาหาร** | ระบบย่อยอาหาร | IBD โรคตับ มะเร็งลำไส้ |
| **วิทยาระบบทางเดินหายใจ** | ปอดและการหายใจ | โรคหอบหืด ปอดอุดกั้นเรื้อรัง ปอดบวม |
| **วิทยาต่อมไร้ท่อ** | ฮอร์โมนและการเผาผลาญ | เบาหวาน โรคไทรอยด์ โรคอ้วน |
| **โรคไต** | ไต | โรคไตเรื้อรัง การฟอกไต |
| **จิตเวชศาสตร์** | สุขภาพจิต | อาการซึมเศร้า วิตกกังวล โรคจิตเภท ไบโพลาร์ |
| **ศัลยศาสตร์กระดูกและข้อ** | กระดูก ข้อต่อ กล้ามเนื้อ | กระดูกหัก เปลี่ยนข้อ บาดเจ็บจากการเล่นกีฬา |
| **โรคผิวหนัง** | ผิว | กลาก สะเก็ดเงิน มะเร็งผิวหนัง สิว |
| **เวชศาสตร์ฉุกเฉิน** | ภาวะเฉียบพลันและเป็นอันตรายถึงชีวิต | อาการบาดเจ็บ หัวใจวาย โรคหลอดเลือดสมอง |
| **เวชศาสตร์ครอบครัว** | การดูแลเบื้องต้นแบบครบวงจร | ทุกอย่าง — จุดติดต่อแรก |
| **กุมารเวชศาสตร์** | สุขภาพเด็ก | พัฒนาการโรคในเด็ก |
| **ผู้สูงอายุ** | การดูแลผู้สูงอายุ | ภาวะเรื้อรังหลายอย่าง, polypharmacy |

## การวินิจฉัย — การค้นหาว่ามีอะไรผิดปกติ
การวินิจฉัยเป็นกระบวนการกำจัดและยืนยัน แพทย์จะรวบรวมเบาะแส (อาการ ประวัติ ผลการตรวจ) และจำกัดความเป็นไปได้ให้แคบลง
### กระบวนการวินิจฉัย
1. **ประวัติ**: มีอาการอย่างไร? พวกเขาเริ่มเมื่อไหร่? อะไรทำให้พวกเขาดีขึ้นหรือแย่ลง? ประวัติครอบครัว? ยา? สิ่งนี้เพียงอย่างเดียวทำให้ความเป็นไปได้แคบลงอย่างมาก
2. **การตรวจร่างกาย**: สัญญาณชีพ (อุณหภูมิ ความดันโลหิต อัตราการเต้นของหัวใจ) การฟังหัวใจและปอด การคลำช่องท้อง ตรวจสอบปฏิกิริยาตอบสนอง
3. **การวินิจฉัยแยกโรค**: รายการอาการที่เป็นไปได้ตามลำดับ จากมีแนวโน้มมากที่สุดไปน้อยที่สุด (และจากอันตรายที่สุดไปหาอันตรายน้อยที่สุด)
4. **การทดสอบ**: ได้รับคำสั่งให้ยืนยันหรือตัดเงื่อนไขของส่วนต่างออก
### การทดสอบวินิจฉัยทั่วไป
| ทดสอบ | มันแสดงอะไร | ดีที่สุดสำหรับ |
|------|--------------|----------|
| **การตรวจเลือด (CBC)** | เม็ดเลือดแดง/ขาว เกล็ดเลือด | ติดเชื้อ โลหิตจาง ความผิดปกติของเลือด |
| **แผงเมตาบอลิซึม** | การทำงานของไต, การทำงานของตับ, อิเล็กโทรไลต์, กลูโคส | การทำงานของอวัยวะ คัดกรองเบาหวาน |
| **เอ็กซ์เรย์** | โครงสร้างหนาแน่น (กระดูก ปอด) | กระดูกหัก ปอดบวม ขนาดหัวใจ |
| **ซีทีสแกน** | ภาพตัดขวางโดยละเอียดโดยใช้รังสีเอกซ์ | อาการบาดเจ็บ เนื้องอก เลือดออกภายใน |
| **เอ็มอาร์ไอ** | รายละเอียดเนื้อเยื่ออ่อนที่ดีเยี่ยม (ไม่มีรังสี) | เนื้องอกในสมอง เอ็นฉีกขาด ปัญหากระดูกสันหลัง |
| **อัลตราซาวนด์** | ภาพเรียลไทม์โดยใช้คลื่นเสียง | การตั้งครรภ์ โรคนิ่ว การทำงานของหัวใจ |
| **การตรวจชิ้นเนื้อ** | ตัวอย่างเนื้อเยื่อตรวจด้วยกล้องจุลทรรศน์ | การวินิจฉัยโรคมะเร็ง ภาวะการอักเสบ |
| **คลื่นไฟฟ้าหัวใจ/EKG** | กิจกรรมทางไฟฟ้าของหัวใจ | หัวใจเต้นผิดจังหวะ |
| **ส่องกล้อง** | กล้องผ่านทางเดินอาหาร | แผลเป็น ติ่งเนื้อ มะเร็ง |
### คัดกรอง — ค้นหาโรคก่อนแสดงอาการ
การตรวจคัดกรองจะมองหาโรคในผู้ที่สบายดี เป้าหมายคือการตรวจพบปัญหาตั้งแต่เนิ่นๆ เมื่อสามารถรักษาได้มากกว่า
| การคัดกรอง | ใคร | บ่อยแค่ไหน |
|----------|-----|-----------|
| **ความดันโลหิต** | ผู้ใหญ่ทุกคน | ทุก 1-2 ปี |
| **คอเลสเตอรอล** | ผู้ใหญ่ 20+ | ทุก 4-6 ปี |
| **การตรวจแมมโมแกรม** | ผู้หญิง 40-74 | ทุก 1-2 ปี |
| **การส่องกล้องลำไส้ใหญ่** | ผู้ใหญ่ 45-75 | ทุก ๆ 10 ปี |
| **แปปสเมียร์** | ผู้หญิง 21-65 | ทุก 3-5 ปี |
| **ตรวจคัดกรองโรคเบาหวาน** | ผู้ใหญ่ 35-70 ที่มีน้ำหนักเกิน | ทุก 3 ปี |

## การรักษา — แก้ไขปัญหา
ตัวเลือกการรักษามีตั้งแต่การไม่ทำอะไรเลย (หลายอาการสามารถแก้ไขได้ด้วยตัวเอง) ไปจนถึงการแทรกแซงเชิงรุก แนวทางที่ถูกต้องขึ้นอยู่กับอาการ ความรุนแรง สุขภาพโดยรวมของผู้ป่วย และหลักฐานว่าสิ่งใดที่ใช้ได้ผล
| วิธีการ | ตัวอย่าง | เมื่อใช้ |
|----------|---------|-----------|
| **เฝ้ารอ** | ติดตามโดยไม่ต้องรักษา | เงื่อนไขเล็กน้อยที่น่าจะแก้ไขได้ ผลการวิจัยที่มีความเสี่ยงต่ำ |
| **ไลฟ์สไตล์ที่เปลี่ยนไป** | อาหาร การออกกำลังกาย การนอนหลับ การจัดการความเครียด | บรรทัดแรกสำหรับภาวะเรื้อรังต่างๆ (ความดันโลหิตสูง เบาหวานชนิดที่ 2) |
| **ยา** | ยาปฏิชีวนะ ยาลดความดันโลหิต อินซูลิน ยาแก้ซึมเศร้า | เมื่อวิถีชีวิตเปลี่ยนแปลงไม่เพียงพอ |
| **ศัลยกรรม** | ผ่าตัดไส้ติ่ง เปลี่ยนข้อ กำจัดเนื้องอก | เมื่อปัญหาเชิงโครงสร้างจำเป็นต้องซ่อมแซมทางกายภาพ |
| **การฉายรังสีบำบัด** | รังสีมุ่งเป้าฆ่าเซลล์มะเร็ง | การรักษามะเร็งมักใช้ร่วมกับการผ่าตัด |
| **ภูมิคุ้มกันบำบัด** | ควบคุมระบบภูมิคุ้มกันต้านมะเร็ง | มะเร็งบางชนิด (มะเร็งผิวหนัง, มะเร็งปอด) |
| **กายภาพบำบัด** | แบบฝึกหัดเพื่อฟื้นฟูการเคลื่อนไหวและการทำงาน | หลังได้รับบาดเจ็บ การผ่าตัด หรือมีอาการปวดเรื้อรัง |
| **จิตบำบัด** | การบำบัดด้วยการพูดคุย (CBT, จิตพลศาสตร์ ฯลฯ) | ภาวะสุขภาพจิต ยังมีประสิทธิภาพในการบรรเทาอาการปวดเรื้อรัง |
| **การดูแลแบบประคับประคอง** | บรรเทาอาการและคุณภาพชีวิต | เจ็บป่วยร้ายแรง ไม่ จำกัด เพียงการสิ้นสุดของชีวิต |

| คลาสยา | มันทำอะไร | ตัวอย่าง | หมายเหตุสำคัญ |

## ระบบการดูแลสุขภาพ — สังคมจัดระเบียบการดูแลอย่างไร
ระบบการรักษาพยาบาลในแต่ละประเทศมีความแตกต่างกันอย่างมาก แต่ทุกประเทศต้องเผชิญกับความท้าทายพื้นฐานที่เหมือนกัน นั่นคือ จะให้การดูแลรักษาคุณภาพสูงแก่ทุกคนได้อย่างไร โดยไม่ทำให้บุคคลหรือระบบต้องล้มละลาย
| รุ่น | มันทำงานอย่างไร | ตัวอย่าง | จุดแข็ง | จุดอ่อน |
|-------|-------------|----------|-----------|------------|
| **ผู้ชำระเงินรายเดียว** | กองทุนรัฐบาลและมักจะให้การดูแล | สหราชอาณาจักร (NHS), แคนาดา, สแกนดิเนเวีย | ความคุ้มครองสากล; การควบคุมต้นทุน | เวลารอ; ทางเลือกที่จำกัด |
| **ประกันสังคม** | เงินสมทบจากนายจ้างและลูกจ้างเข้า "กองทุนเจ็บป่วย" ที่ไม่แสวงหาผลกำไร | เยอรมนี ฝรั่งเศส ญี่ปุ่น | สากล; บริษัทประกันหลายรายแข่งขันกัน | ซับซ้อน; แพง |
| **ผู้จ่ายเงินหลายราย (ตามนายจ้าง)** | ประกันเอกชนผ่านนายจ้าง รัฐบาลคุ้มครองผู้สูงอายุ/ยากจน | สหรัฐอเมริกา | นวัตกรรม; เวลารอสั้นสำหรับผู้ประกันตน | ไม่มีประกัน 27 ล้านคน ต้นทุนสูงสุด |
| **ออกนอกกระเป๋า** | คนไข้จ่ายตรง | ประเทศที่มีรายได้ต่ำที่สุด | ง่าย | คนรวยเท่านั้นที่จะได้รับการดูแล |
สหรัฐฯ ใช้จ่ายด้านการดูแลสุขภาพต่อคนประมาณ 2 เท่าเมื่อเทียบกับประเทศร่ำรวยอื่นๆ โดยให้ผลลัพธ์ที่แย่ลงในหลายมาตรการ (อายุขัย อัตราการตายของทารก การเสียชีวิตที่สามารถป้องกันได้) เหตุผลมีความซับซ้อน: ความสิ้นเปลืองในการบริหารจัดการ ราคายาที่สูง สิ่งจูงใจในการคิดค่าบริการที่ให้ผลตอบแทนในปริมาณมากกว่ามูลค่า และการเข้าถึงที่ไม่เท่าเทียมกัน

## สาธารณสุข — การปกป้องประชากร
แม้ว่าการแพทย์ทางคลินิกจะมุ่งเน้นไปที่ผู้ป่วยแต่ละราย แต่ด้านสาธารณสุขจะพิจารณาที่ประชากร เครื่องมือของมันคือระบาดวิทยา การฉีดวัคซีน สุขาภิบาล การศึกษา และนโยบาย
### ความสำเร็จด้านสาธารณสุขที่ยิ่งใหญ่ที่สุด
1. **การฉีดวัคซีน** — กำจัดไข้ทรพิษ โปลิโอเกือบหาย ป้องกันการเสียชีวิตหลายล้านคนต่อปี
2. **น้ำสะอาดและสุขาภิบาล** — กำจัดอหิวาตกโรคในประเทศที่พัฒนาแล้ว ยังคงเป็นนักฆ่ารายใหญ่ในประเทศกำลังพัฒนา
3. **ยาปฏิชีวนะ** — เปลี่ยนโรคติดเชื้อจากโทษประหารชีวิตไปสู่ภาวะที่รักษาได้
4. **การควบคุมยาสูบ** — อัตราการสูบบุหรี่ลดลงอย่างมากในหลายประเทศ ป้องกันมะเร็งและหัวใจวายได้หลายล้านราย
5. **ความปลอดภัยทางถนน** — เข็มขัดนิรภัย ถุงลมนิรภัย และกฎหมายว่าด้วยการเมาแล้วขับ ลดอัตราการเสียชีวิตจากการจราจรลงครึ่งหนึ่งในหลายประเทศ
### ระบาดวิทยา — ศาสตร์แห่งรูปแบบ
นักระบาดวิทยาศึกษาว่าโรคแพร่กระจายผ่านประชากรได้อย่างไร แนวคิดหลัก:
| ระยะเวลา | ความหมาย | ตัวอย่าง |
|------|---------|---------|
| **อุบัติการณ์** | กรณีใหม่ในช่วงเวลา | พบผู้ป่วยเบาหวานรายใหม่ 500 ราย ต่อ 100,000 คนต่อปี |
| **ความชุก** | กรณีและปัญหาทั้งหมดที่มีอยู่ ณ เวลาหนึ่ง | ปัจจุบันผู้ใหญ่ 10% เป็นโรคเบาหวาน |
| **อัตราการเสียชีวิต** | เสียชีวิตด้วยโรค | เสียชีวิต 150 รายต่อ 100,000 รายจากโรคหัวใจ |
| **R₀ (R-ไม่มีอะไร)** | จำนวนเฉลี่ยของผู้ติดเชื้อ 1 รายที่จะติดเชื้อ | โรคหัด: 12-18; ไข้หวัดใหญ่: 1-2 |
| **ภูมิคุ้มกันหมู่** | เมื่อคนมีภูมิคุ้มกันเพียงพอจนโรคไม่สามารถแพร่กระจายได้ง่าย | จำเป็นต้องฉีดวัคซีน ~95% สำหรับโรคหัด |

## จริยธรรมทางการแพทย์ — คำถามยากๆ
การแพทย์ทำให้เกิดคำถามทางจริยธรรมที่ไม่มีคำตอบง่ายๆ หลักการสี่ประการที่เป็นแนวทางด้านจริยธรรมทางการแพทย์ส่วนใหญ่:
1. **ความเป็นอิสระ**: ผู้ป่วยมีสิทธิ์ในการตัดสินใจโดยอาศัยข้อมูลรอบด้านเกี่ยวกับการดูแลของตนเอง แม้ว่าแพทย์จะไม่เห็นด้วยก็ตาม
2. **ผลประโยชน์**: กระทำการโดยคำนึงถึงประโยชน์สูงสุดของผู้ป่วย
3. **การไม่มุ่งร้าย**: "ก่อนอื่น อย่าทำอันตราย" หลีกเลี่ยงการรักษาที่ผลเสียมีมากกว่าผลประโยชน์
4. **ความยุติธรรม**: แจกจ่ายทรัพยากรด้านการดูแลสุขภาพอย่างยุติธรรม
หลักการเหล่านี้บางครั้งขัดแย้งกัน ผู้ป่วยอาจปฏิเสธการรักษาเพื่อช่วยชีวิต (ความเป็นอิสระเทียบกับผลประโยชน์) ยาราคาแพงอาจเป็นประโยชน์ต่อผู้ป่วยรายหนึ่งแต่ทำให้ทรัพยากรหมดไปจากผู้ป่วยอีกหลายคน (ผลประโยชน์เทียบกับความยุติธรรม)
ประเด็นสำคัญทางจริยธรรมในการแพทย์แผนปัจจุบัน:
- **การดูแลระยะสุดท้าย**: เมื่อใดจึงควรถอนการช่วยชีวิต? อะไรคือความแตกต่างระหว่างการดูแลแบบประคับประคอง (บรรเทาทุกข์) และนาเซียเซีย (จงใจจบชีวิต)?
- **การแจ้งความยินยอม**: ผู้ป่วยจะต้องเข้าใจถึงความเสี่ยง ประโยชน์ และทางเลือกอื่น ๆ ก่อนที่จะตกลงรับการรักษา สิ่งนี้ซับซ้อนกว่าที่คิด ผู้ป่วยส่วนใหญ่ไม่เข้าใจความเสี่ยงทางสถิติอย่างถ่องแท้
- **การจัดสรรทรัพยากร**: ใครบ้างที่ได้รับการปลูกถ่ายอวัยวะเมื่อมีอวัยวะไม่เพียงพอ? ใครบ้างที่ได้รับเครื่องช่วยหายใจในช่วงที่มีการระบาดใหญ่?
- **การทดสอบและแก้ไขทางพันธุกรรม**: ขณะนี้เราสามารถคัดกรองเอ็มบริโอเพื่อหาโรคทางพันธุกรรมและแก้ไขยีนด้วย CRISPR ได้ เราควร? เส้นแบ่งระหว่างการรักษาโรคกับการ "ออกแบบ" ทารกอยู่ที่ไหน?
- **AI ในการแพทย์**: ใครเป็นผู้รับผิดชอบเมื่อเครื่องมือวินิจฉัย AI ทำผิดพลาด เราจะแน่ใจได้อย่างไรว่า AI จะไม่เข้ารหัสอคติ

## สรุป
การแพทย์เป็นทั้งวิทยาศาสตร์และศิลปะ วิทยาศาสตร์นี้มีความพิเศษมาก เราสามารถจัดลำดับจีโนมได้ภายในไม่กี่ชั่วโมง ปลูกอวัยวะจากสเต็มเซลล์ และตั้งโปรแกรมระบบภูมิคุ้มกันใหม่เพื่อต่อสู้กับมะเร็ง ศิลปะอยู่ที่การนำวิทยาศาสตร์นั้นไปประยุกต์ใช้กับผู้ป่วยแต่ละราย โดยแต่ละคนมีค่านิยม สถานการณ์ และความชอบของตนเอง ระบบการรักษาพยาบาลทั่วโลกต่อสู้กับความท้าทายเดียวกัน นั่นก็คือการมอบการดูแลคุณภาพสูงให้กับทุกคนโดยไม่หยุดชะงัก ความตึงเครียดระหว่างสิ่งที่เป็นไปได้ทางการแพทย์กับสิ่งที่ยั่งยืนทางเศรษฐกิจจะเพิ่มมากขึ้นเมื่อการรักษามีความก้าวหน้ามากขึ้นและอายุของประชากรมากขึ้น การทำความเข้าใจวิธีการทำงานของยา — วิธีการวินิจฉัย รักษา และป้องกันโรค — เป็นสิ่งสำคัญสำหรับการตัดสินใจอย่างรอบรู้เกี่ยวกับสุขภาพของคุณและสุขภาพของสังคม
