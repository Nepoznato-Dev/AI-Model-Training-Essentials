#พันธุศาสตร์และจีโนมิกส์
พันธุศาสตร์เป็นการศึกษาเกี่ยวกับพันธุกรรม - ลักษณะต่างๆ ได้รับการถ่ายทอดจากพ่อแม่สู่ลูกหลานผ่านทาง DNA อย่างไร จีโนมิกส์คือการศึกษาจีโนมทั้งหมด ได้แก่ ยีนทั้งหมด บริเวณที่ไม่มีการเข้ารหัส วิธีโต้ตอบของพวกมัน และความแตกต่างระหว่างแต่ละบุคคลและประชากร การเปลี่ยนจากพันธุกรรมไปสู่จีโนมิกส์ขับเคลื่อนโดยเทคโนโลยีการหาลำดับ เราเปลี่ยนจากการศึกษายีนทีละยีนไปเป็นการอ่านจีโนมทั้งหมดภายในเวลาไม่กี่ชั่วโมง สร้างข้อมูลที่เปลี่ยนแปลงการแพทย์ เกษตรกรรม นิติเวช และความเข้าใจของเราเกี่ยวกับวิวัฒนาการ
---

## ความรู้พื้นฐานด้านดีเอ็นเอ
### โครงสร้างดีเอ็นเอ
| ส่วนประกอบ | คำอธิบาย |
|-----------|-------------|
| **นิวคลีโอไทด์** | การสร้างบล็อคของ DNA; ประกอบด้วยน้ำตาล (ดีออกซีไรโบส) หมู่ฟอสเฟต และเบสไนโตรเจน |
| **ฐาน** | อะดีนีน (A), ไทมีน (T), กวานีน (G), ไซโตซีน (C) |
| **การจับคู่ฐาน** | จับคู่กับ T (พันธะไฮโดรเจน 2 อัน); G จับคู่กับ C (พันธะไฮโดรเจน 3 พันธะ) |
| **เกลียวคู่** | เส้นสองเส้นวิ่งต้านขนาน (5' ถึง 3' และ 3' ถึง 5'); บิดเป็นเกลียว |
| **โครโมโซม** | โมเลกุล DNA ยาวเดี่ยวพันรอบโปรตีนฮิสโตน มนุษย์มี 46 (23 คู่) |
| **จีโนม** | ชุดดีเอ็นเอที่สมบูรณ์ในสิ่งมีชีวิต จีโนมมนุษย์อยู่ที่ ~3.2 พันล้านคู่เบส |
### ความเชื่อกลางของอณูชีววิทยา
| ขั้นตอน | กระบวนการ | ที่ตั้ง | สินค้า |
|------|---------|----------|---------|
| **การจำลอง** | ดีเอ็นเอ → ดีเอ็นเอ | นิวเคลียส | DNA โมเลกุลที่เหมือนกันสองโมเลกุล |
| **การถอดความ** | ดีเอ็นเอ → mRNA | นิวเคลียส | เมสเซนเจอร์ อาร์เอ็นเอ |
| **คำแปล** | mRNA → โปรตีน | ไรโบโซม (ไซโตพลาสซึม) | สายโพลีเปปไทด์ (โปรตีน) |

## การแสดงออกของยีน
### วิธีควบคุมยีน
| ระดับ | กลไก | ตัวอย่าง |
|-------|-----------|---------|
| **อีพีเจเนติกส์** | เมทิลเลชันของดีเอ็นเอ การปรับเปลี่ยนฮิสโตน การปรับปรุงโครมาติน | การปิดเสียงโครโมโซม X หนึ่งโครโมโซมในเพศหญิง |
| **การถอดเสียง** | ปัจจัยการถอดความผูกมัดโปรโมเตอร์/สารเพิ่มประสิทธิภาพ; เปิดใช้งานหรือระงับ | Lac operon ในแบคทีเรีย ยีนที่ตอบสนองต่อฮอร์โมน |
| **หลังการถอดความ** | การประกบทางเลือก; ความเสถียรของเอ็มอาร์เอ็นเอ; ไมโครอาร์เอ็นเอ | หนึ่งยีน → โปรตีนหลายแบบ |
| **คำแปล** | ความพร้อมของไรโบโซม; การควบคุมปัจจัยการเริ่มต้น | การควบคุมธาตุเหล็กผ่านเฟอร์ริติน mRNA |
| **หลังการแปล** | การดัดแปลงโปรตีน (ฟอสโฟรีเลชั่น, การแพร่หลาย); การย่อยสลาย | การควบคุมวัฏจักรของเซลล์ |

## รูปแบบการสืบทอด
### พันธุศาสตร์เมนเดเลียน
| รูปแบบ | คำอธิบาย | ตัวอย่าง |
|---------|-------------|---------|
| **ออโตโซมเด่น** | อัลลีลหนึ่งชุดก็เพียงพอแล้ว | โรคฮันติงตัน; achondroplasia |
| **ออโตโซมด้อย** | ต้องใช้สำเนาสองชุด | โรคปอดเรื้อรัง; โรคโลหิตจางชนิดเคียว |
| **X-linked เด่น** | ยีนบนโครโมโซม X; หนึ่งสำเนาเพียงพอ | กลุ่มอาการ Rett |
| **X-linked recessive** | ยีนบนโครโมโซม X; ผู้ชายได้รับผลกระทบมากขึ้น | โรคฮีโมฟีเลีย; ตาบอดสี |
| **ความโดดเด่น** | อัลลีลทั้งสองแสดงออกอย่างเท่าเทียมกัน | กรุ๊ปเลือด ABO (A และ B) |
| **การครอบงำที่ไม่สมบูรณ์** | เฮเทอโรไซโกตอยู่ระดับกลาง | ดอกไม้สีชมพูจากพ่อแม่สีแดงและสีขาว |
| **โพลีเจนิก** | ยีนหลายตัวมีส่วนทำให้เกิดลักษณะเดียว | ความสูง; สีผิว; สติปัญญา |
| **ภาวะมีบุตรยาก** | ยีนหนึ่งตัวส่งผลต่อหลายลักษณะ | กลุ่มอาการมาร์ฟาน (เนื้อเยื่อเกี่ยวพัน ดวงตา หัวใจ) |

## จีโนมิกส์
### ประเภทของจีโนมิกส์
| พิมพ์ | โฟกัส | ใบสมัคร |
|-|-------|-------------|
| **จีโนมิกส์โครงสร้าง** | โครงสร้าง 3 มิติของโปรตีนทั้งหมดในจีโนม | การออกแบบยา วิศวกรรมโปรตีน |
| **จีโนมิกเชิงฟังก์ชัน** | ยีนทำอะไร ปฏิสัมพันธ์ของยีน รูปแบบการแสดงออก | ทำความเข้าใจกลไกการเกิดโรค |
| **จีโนมเปรียบเทียบ** | การเปรียบเทียบจีโนมข้ามสายพันธุ์ | ความสัมพันธ์เชิงวิวัฒนาการ การระบุภูมิภาคอนุรักษ์ |
| **เมเทโนมิกส์** | DNA จากตัวอย่างสิ่งแวดล้อม (ไม่ได้เพาะเลี้ยง) | การศึกษาไมโครไบโอม การค้นพบสิ่งมีชีวิตใหม่ |
| **เภสัชพันธุศาสตร์** | ยีนส่งผลต่อการตอบสนองต่อยาอย่างไร | ยาเฉพาะบุคคล; การให้ยา |
| **อีพีจีโนมิกส์** | การดัดแปลง epigenetic ทั่วทั้งจีโนม การวินิจฉัยโรคมะเร็ง ชีววิทยาพัฒนาการ |
### เทคโนโลยีการหาลำดับดีเอ็นเอ
| รุ่น | เทคโนโลยี | อ่านความยาว | ปริมาณงาน | คุณสมบัติที่สำคัญ |
|----------|-----------|-------------|------------|-------------|
| **รุ่นแรก** | ลำดับแซงเจอร์ | ~1,000 บีพี | ต่ำ | ความแม่นยำมาตรฐานทองคำ ใช้สำหรับการตรวจสอบ |
| **รุ่นที่สอง** | อิลลูมินา (โซเล็กซ่า) | 50–300 bp | สูงมาก | อ่านเรื่องสั้น; แพลตฟอร์มที่โดดเด่น ต้นทุนต่อฐานต่ำ |
| **รุ่นที่สอง** | ไอออน ทอร์เรนต์ | 200–400 บีพี | สูง | ใช้เซมิคอนดักเตอร์; ไม่มีเลนส์ |
| **รุ่นที่สาม** | PacBio (SMRT) | 10,000–100,000 ครั้ง | ปานกลาง | อ่านยาว; แก้ไขขอบเขตที่ซ้ำกัน |
| **รุ่นที่สาม** | อ็อกซ์ฟอร์ด นาโนพอร์ | สูงถึงล้าน bp | ปานกลางถึงสูง | อ่านยาวมาก; แบบพกพา (มินเนี่ยน); เรียลไทม์ |

## การเปลี่ยนแปลงทางพันธุกรรม
### ประเภทของการเปลี่ยนแปลง
| พิมพ์ | คำอธิบาย | ความถี่ |
|------|-------------|-----------|
| **SNP** (พหุสัณฐานของนิวคลีโอไทด์เดี่ยว) | การเปลี่ยนแปลงฐานเดียว | พบมากที่สุด; ~1 ใน 1,000 ฐาน |
| **การแทรก / การลบ (อินเดล)** | การบวกหรือการลบฐาน | สามารถทำให้เกิดการกลายพันธุ์ของ frameshift ได้ |
| **CNV** (รูปแบบหมายเลขสำเนา) | ส่วนที่ทำซ้ำหรือถูกลบ (1 kb – หลาย Mb) | มีส่วนทำให้เกิดโรคและวิวัฒนาการ |
| **การเปลี่ยนแปลงโครงสร้าง** | การผกผัน; การโยกย้าย; การจัดเรียงใหม่ครั้งใหญ่ | พบได้น้อย; สามารถทำให้เกิดโรคได้ |
| **ไมโครแซทเทลไลท์ (STR)** | ทำซ้ำตามกันสั้น ๆ (ทำซ้ำ 2–6 bp) | นิติเวช; การทดสอบความเป็นพ่อ |
### GWAS (การศึกษาสมาคมทั้งจีโนม)
| ขั้นตอน | คำอธิบาย |
|-|-------------|
| **1. เก็บตัวอย่าง** | กรณี (มีโรค) และการควบคุม (ไม่มี) |
| **2. จีโนไทป์** | ใช้อาร์เรย์ SNP เพื่อจีโนไทป์ตัวแปรนับแสน |
| **3. การทดสอบทางสถิติ** | ทดสอบ SNP แต่ละรายการเพื่อเชื่อมโยงกับคุณลักษณะ |
| **4. พล็อตแมนฮัตตัน** | แสดงภาพผลลัพธ์ของโครโมโซมทั้งหมด |
| **5. การจำลองแบบ** | ยืนยันการค้นพบในกลุ่มตัวอย่างอิสระ |

## การแก้ไขยีน
### CRISPR-Cas9
| ส่วนประกอบ | ฟังก์ชัน |
|----------|----------|
| **ไกด์ RNA (gRNA)** | ~20 นิวคลีโอไทด์; ตรงกับลำดับ DNA เป้าหมาย |
| **โปรตีน Cas9** | กรรไกรโมเลกุล ตัด DNA ที่ไซต์เป้าหมาย |
| **ลำดับ PAM** | แม่ลายสั้น (NGG) ติดกับเป้าหมาย จำเป็นสำหรับการผูก Cas9 |
| **HDR** (การซ่อมแซมที่เน้นความคล้ายคลึงกัน) | แก้ไขได้อย่างแม่นยำโดยใช้เทมเพลตผู้บริจาค |
| **NHEJ** (การเข้าร่วมการสิ้นสุดที่ไม่คล้ายคลึงกัน) | การซ่อมแซมที่เกิดข้อผิดพลาด; สร้างการแทรก/การลบ (สิ่งที่น่าพิศวง) |
### แอปพลิเคชั่นแก้ไขยีน
| ใบสมัคร | คำอธิบาย |
|-------------|-------------|
| **การรักษา** | แก้ไขการกลายพันธุ์ที่ก่อให้เกิดโรค (เคียวเซลล์; เบต้าธาลัสซีเมีย) |
| **เกษตรศาสตร์** | พืชต้านทานโรค ปรับปรุงปศุสัตว์ |
| **การวิจัย** | สร้างโมเดลที่น่าพิศวง ศึกษาการทำงานของยีน |
| **ยีนไดรฟ์** | แพร่กระจายการดัดแปลงพันธุกรรมผ่านประชากร (เช่น ยุงที่ต้านทานโรคมาลาเรีย) |

## ข้อพิจารณาด้านจริยธรรม
| ปัญหา | ความกังวล |
|-------|---------|
| **ความเป็นส่วนตัวทางพันธุกรรม** | ใครเป็นเจ้าของข้อมูลจีโนมของคุณ? นายจ้างหรือบริษัทประกันสามารถใช้ได้หรือไม่? |
| **การตัดต่อยีนในเอ็มบริโอ** | การเปลี่ยนแปลงที่สืบทอดได้ นักออกแบบทารก; ผลกระทบนอกเป้าหมายโดยไม่ได้ตั้งใจ |
| **การเลือกปฏิบัติทางพันธุกรรม** | GINA (US) ป้องกันการเลือกปฏิบัติบางประการ แต่มีช่องว่าง |
| **แจ้งความยินยอม** | ข้อมูลจีโนมเปิดเผยข้อมูลเกี่ยวกับญาติที่ไม่ยินยอม |
| **การจัดเก็บข้อมูล** | จีโนมมีขนาดใหญ่ (ดิบ ~ 200 GB); ความท้าทายในการจัดเก็บข้อมูลและความปลอดภัยในระยะยาว |
| **ตราสารทุน** | ยาจีโนมเสี่ยงที่จะขยายความเหลื่อมล้ำทางด้านสุขภาพหากมีให้เฉพาะกับประชากรที่ร่ำรวยเท่านั้น |

## สรุป
พันธุศาสตร์ศึกษาว่ายีนแต่ละตัวทำงานอย่างไรและสืบทอดมาอย่างไร จีโนมส์ศึกษาจีโนมทั้งหมด ยีนทั้งหมด ปฏิสัมพันธ์ และความแปรผันของพวกมัน DNA ถูกคัดลอกไปเป็น RNA ซึ่งถูกแปลเป็นโปรตีน การแสดงออกของยีนถูกควบคุมในหลายระดับ: เอพิเจเนติก, การถอดเสียง, หลังการถอดเสียง, การแปล และหลังการแปล การสืบทอดเป็นไปตามรูปแบบ (เด่น, ถอย, โพลีจีนิก) ที่กำหนดลักษณะที่ถ่ายทอดระหว่างรุ่น เทคโนโลยีการหาลำดับสมัยใหม่ (Illumina, PacBio, Nanopore) สามารถอ่านจีโนมทั้งหมดได้อย่างรวดเร็วและประหยัด CRISPR-Cas9 ช่วยให้สามารถตัดต่อยีนได้อย่างแม่นยำพร้อมศักยภาพในการเปลี่ยนแปลงในด้านการแพทย์และการเกษตร ความท้าทายที่ใหญ่ที่สุดคือเรื่องจริยธรรม: ใครเป็นผู้ควบคุมข้อมูลจีโนม วิธีควบคุมการแก้ไขยีนในเอ็มบริโอ และวิธีให้แน่ใจว่าการแพทย์ด้านจีโนมจะเป็นประโยชน์ต่อทุกคน ไม่ใช่แค่เฉพาะผู้มีสิทธิพิเศษเท่านั้น
