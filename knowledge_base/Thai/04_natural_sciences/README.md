## วิทยาศาสตร์ชีวภาพ
การศึกษาสิ่งมีชีวิตและกระบวนการของสิ่งมีชีวิต
| ไฟล์ | หัวข้อ | ความยาก |
|------|--------|-----------|
| [biology_fundamentals.md](life_sciences/biology_fundamentals.md)| เซลล์ ดีเอ็นเอ วิวัฒนาการ นิเวศวิทยา อนุกรมวิธาน | ระดับเริ่มต้น |
| [genetics_and_genomics.md](life_sciences/genetics_and_genomics.md)| โครงสร้างดีเอ็นเอ, การแสดงออกของยีน, CRISPR, GWAS, การหาลำดับ | ระดับเริ่มต้น |
| [medicine_and_healthcare.md](life_sciences/medicine_and_healthcare.md)| ระบบอวัยวะ การวินิจฉัย การรักษา ระบบสุขภาพ จริยธรรม | ระดับเริ่มต้น |
| [neuroscience.md](life_sciences/neuroscience.md)| เซลล์ประสาท โครงสร้างสมอง สารสื่อประสาท ความเป็นพลาสติก ความผิดปกติ | ระดับเริ่มต้น |
| [food_agriculture_and_nutrition.md](life_sciences/food_agriculture_and_nutrition.md)| เกษตรกรรม โภชนาการ ความปลอดภัยของอาหาร ระบบอาหาร ความยั่งยืน | ระดับเริ่มต้น |
## วิทยาศาสตร์กายภาพ
การศึกษาเรื่องสิ่งไม่มีชีวิตและพลังงาน - กฎพื้นฐานของจักรวาล
| ไฟล์ | หัวข้อ | ความยาก |
|------|--------|-----------|
| [physics.md](physical_sciences/physics.md)| แรง กลศาสตร์ อุณหพลศาสตร์ แม่เหล็กไฟฟ้า สัมพัทธภาพ กลศาสตร์ควอนตัม | ระดับเริ่มต้น |
| [chemistry.md](physical_sciences/chemistry.md)| โครงสร้างอะตอม ตารางธาตุ พันธะ ปฏิกิริยา เคมีอินทรีย์ | ระดับเริ่มต้น |
| [materials_science.md](physical_sciences/materials_science.md)| โครงสร้างผลึก โพลีเมอร์ โลหะผสม สารกึ่งตัวนำ วัสดุนาโน | ระดับเริ่มต้น |
## โลกและสิ่งแวดล้อม
การศึกษาดาวเคราะห์ของเรา ระบบของมัน และตำแหน่งของมันในจักรวาล
| ไฟล์ | หัวข้อ | ความยาก |
|------|--------|-----------|
| [earth_science.md](earth_and_environment/earth_science.md)| โครงสร้างโลก แผ่นเปลือกโลก บรรยากาศ สภาพอากาศ เวลาทางธรณีวิทยา | ระดับเริ่มต้น |
| [astronomy_and_cosmology.md](earth_and_environment/astronomy_and_cosmology.md)| ดวงดาว กาแล็กซี บิ๊กแบง สสารมืด ดาวเคราะห์นอกระบบ | ระดับเริ่มต้น |
| [environmental_science_and_sustainability.md](earth_and_environment/environmental_science_and_sustainability.md)| ระบบนิเวศ การเปลี่ยนแปลงสภาพภูมิอากาศ พลังงานหมุนเวียน มลพิษ นโยบาย | ระดับเริ่มต้น |
