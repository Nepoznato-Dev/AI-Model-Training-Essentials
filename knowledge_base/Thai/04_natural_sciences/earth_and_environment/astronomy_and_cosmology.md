# ดาราศาสตร์และจักรวาลวิทยา
ดาราศาสตร์คือการศึกษาวัตถุท้องฟ้า เช่น ดวงดาว ดาวเคราะห์ กาแล็กซี และทุกสิ่งที่อยู่นอกชั้นบรรยากาศของโลก จักรวาลวิทยาคือการศึกษาจักรวาลโดยรวม: ต้นกำเนิด โครงสร้าง วิวัฒนาการ และชะตากรรมขั้นสุดท้าย พวกเขาร่วมกันตอบคำถามพื้นฐานที่สุดบางข้อที่มนุษย์เคยถาม: จักรวาลเริ่มต้นอย่างไร มันใหญ่แค่ไหน? เราอยู่คนเดียวเหรอ? จะเกิดอะไรขึ้นกับมันในที่สุด?
---

## ขนาดของจักรวาล
### บันไดระยะทางจักรวาล
| วิธีการ | พิสัย | มันวัดอะไร |
|--------|-------|-----------------|
| **เรดาร์** | ระบบสุริยะ | ตีกลับสัญญาณวิทยุจากดาวเคราะห์ วัดเวลากลับ |
| **พารัลแลกซ์** | มากถึง ~10,000 ปีแสง | การเคลื่อนตัวของดาวฤกษ์ใกล้เคียงอย่างเห็นได้ชัดกับพื้นหลังอันห่างไกลในขณะที่โลกโคจรรอบดวงอาทิตย์ |
| **เทียนมาตรฐาน (ตัวแปรเซเฟอิด)** | มากถึง ~100 ล้านปีแสง | ระยะเวลาการเต้นเป็นจังหวะมีความสัมพันธ์กับความสว่างภายใน |
| **ซูเปอร์โนวาประเภท Ia** | พันล้านปีแสง | การระเบิดของดาวแคระขาวโดยมีความส่องสว่างสูงสุดสม่ำเสมอ |
| **เรดชิฟต์ (กฎของฮับเบิล)** | ระยะทางจักรวาล | ความเร็วถดถอยแปรผันตามระยะทาง จักรวาลที่กำลังขยายตัว |

## ดวงดาว
### วงจรชีวิตของดวงดาว
| เวที | คำอธิบาย | ระยะเวลา |
|-------|-------------|----------|
| **เมฆโมเลกุล** | ก๊าซและฝุ่นที่เย็นและหนาแน่น แรงโน้มถ่วงเริ่มถล่มบริเวณ | ล้านปี |
| **โปรโตสตาร์** | แกนกลางที่ยุบตัวจะร้อนขึ้น ยังไม่หลอมไฮโดรเจน | ~100,000 ปี |
| **ลำดับหลัก** | ไฮโดรเจนฟิวชันในแกนกลาง มั่นคง; ตอนนี้ดวงอาทิตย์ของเราอยู่ที่ไหน | ~10 พันล้านปี (คล้ายดวงอาทิตย์) |
| **ยักษ์แดง** | แกนไฮโดรเจนหมดแล้ว ชั้นนอกขยายและเย็น | ~1 พันล้านปี |

| **ที่เหลือ** | ดาวแคระขาว ดาวนิวตรอน หรือหลุมดำ | หลายพันล้านปีหรือนานกว่านั้น |

## กาแล็กซี
### ประเภทของกาแลคซี (การจำแนกประเภทฮับเบิล)
| พิมพ์ | คำอธิบาย | ตัวอย่าง |
|------|-------------|---------|
| **เครื่องเดินวงรี (E)** | เรียบ; ไม่มีรูป; รูปร่างรูปไข่ ดาวเก่า; แก๊สน้อย | M87 |
| **เกลียว(S)** | แผ่นแบน; แขนเกลียว นูนตรงกลาง; การก่อตัวดาวฤกษ์ที่ใช้งานอยู่ | ทางช้างเผือก; แอนโดรเมดา (M31) |

| **ไม่สม่ำเสมอ (Irr)** | ไม่มีรูปร่างกำหนด มักเป็นผลมาจากปฏิสัมพันธ์ของกาแลคซี | เมฆแมเจลแลนขนาดใหญ่ |

## จักรวาลวิทยา
### ทฤษฎีบิ๊กแบง
| หลักฐาน | คำอธิบาย |
|----------|-------------|
| **พื้นหลังไมโครเวฟคอสมิก (CMB)** | สายัณห์ของบิ๊กแบง; 2.725 เคล; สม่ำเสมอในทุกทิศทาง ความผันผวนเล็ก ๆ ของกาแลคซีเมล็ดพืช |
| **การขยายตัวของฮับเบิล** | กาแล็กซีกำลังถอยห่างจากเรา ยิ่งไกลออกไปก็ยิ่งเร็วขึ้น — พื้นที่เองก็กำลังขยายตัว |
| **ความอุดมสมบูรณ์ของธาตุแสง** | การสังเคราะห์นิวเคลียสแบบบิ๊กแบงทำนายอัตราส่วนที่สังเกตได้ของไฮโดรเจน ฮีเลียม และลิเธียม |
| **โครงสร้างขนาดใหญ่** | การกระจายตัวของกาแลคซีตรงกับการคาดการณ์จากความผันผวนของความหนาแน่นเริ่มต้น |
### เส้นเวลาของจักรวาล
| เวลาหลังบิ๊กแบง | เหตุการณ์ |
|---------------------|-------|
| **10^-43 วินาที** | ยุคพลังค์; กองกำลังทั้งหมดรวมกันเป็นหนึ่งเดียว ฟิสิกส์อย่างที่เรารู้มันพัง |
| **10^-36 วินาที** | อัตราเงินเฟ้อเริ่มต้นขึ้น จักรวาลขยายตัวแบบทวีคูณ |
| **10^-12 วินาที** | ความสมมาตรของ Electroweak แตก สนามฮิกส์ให้มวลอนุภาค |
| **10^-6 วินาที** | ควาร์กรวมกันเป็นโปรตอนและนิวตรอน |
| **3 นาที** | การสังเคราะห์นิวเคลียสของบิ๊กแบง; นิวเคลียสของอะตอมตัวแรก (H, He, Li) |
| **380,000 ปี** | การรวมตัวกันอีกครั้ง; รูปแบบอะตอม CMB เปิดตัว; จักรวาลกลายเป็นโปร่งใส |
| **100–200 ล้านปี** | ดาวดวงแรกลุกไหม้ (ดาวประชากร III) |
| **1 พันล้านปี** | กาแลคซีแรกก่อตัว |
| **9.2 พันล้านปี** | รูปแบบระบบสุริยะ |
| **13.8 พันล้านปี** | ตอนนี้ |
### สสารมืดและพลังงานมืด
| ส่วนประกอบ | สัดส่วน | หลักฐาน | ธรรมชาติ |
|----------|-----------|----------|--------|
| **เรื่องธรรมดา** | ~5% | มองเห็นได้; ปล่อย/ดูดซับแสง | เข้าใจดี (อะตอม อนุภาค) |
| **สสารมืด** | ~27% | เส้นโค้งการหมุนของกาแล็กซี เลนส์โน้มถ่วง รูปแบบ CMB | ไม่ทำปฏิกิริยากับแสง ตรวจพบผ่านแรงโน้มถ่วงเท่านั้น |
| **พลังงานมืด** | ~68% | การเร่งการขยายตัวของจักรวาล (ซูเปอร์โนวาประเภท Ia) | ไม่ทราบ; อาจเป็นค่าคงที่ทางจักรวาลวิทยา (พลังงานสุญญากาศ) |

## ดาวเคราะห์นอกระบบและการค้นหาสิ่งมีชีวิต
### วิธีการตรวจจับ
| วิธีการ | มันทำงานอย่างไร | จุดแข็ง |
|----------------------|-------------|-----------|
| **การเดินทาง** | ดาวเคราะห์เคลื่อนผ่านหน้าดาวฤกษ์ ดาวหรี่ลงเล็กน้อย | วิธีที่มีประสิทธิผลมากที่สุด (Kepler, TESS); ให้ขนาดและคาบการโคจร |
| **ความเร็วในแนวรัศมี** | แรงโน้มถ่วงของดาวเคราะห์ทำให้ดาวฤกษ์โยกเยก ดอปเปลอร์เคลื่อนตัวในแสงดาว | ให้มวล; ใช้ได้กับดาวเคราะห์ขนาดใหญ่ใกล้ดาวฤกษ์ |
| **การถ่ายภาพโดยตรง** | ปิดกั้นแสงดาว; ถ่ายภาพดาวเคราะห์โดยตรง | ใช้งานได้กับดาวเคราะห์ขนาดใหญ่ที่อยู่ห่างไกลจากดาวฤกษ์ |
| **ไมโครเลนส์โน้มถ่วง** | แรงโน้มถ่วงของดาวเคราะห์ทำให้แสงจากดาวฤกษ์ที่อยู่ด้านหลัง | ตรวจจับดาวเคราะห์ในระยะไกล เหตุการณ์ที่หายาก |
| **โหราศาสตร์** | วัดตำแหน่งที่แม่นยำของดาว ตรวจจับการโยกเยก | ประกอบกับความเร็วแนวรัศมี |
### โซนที่อยู่อาศัย
| ปัจจัย | ข้อกำหนด |
|--------|-------------|
| **ระยะทางจากดาว** | ไม่ร้อนเกินไป ไม่หนาวเกินไป ของเหลวบนพื้นผิวได้ |
| **ประเภทดาว** | มั่นคง; อายุยืนยาว (คนแคระ G, K, M ชอบ) |
| **มวลดาวเคราะห์** | แรงโน้มถ่วงเพียงพอที่จะยึดบรรยากาศ ไม่ใหญ่โตจนกลายเป็นก๊าซยักษ์ |
| **บรรยากาศ** | ภาวะเรือนกระจกเพื่อรักษาอุณหภูมิพื้นผิว การป้องกันจากรังสี |
| **สนามแม่เหล็ก** | สะท้อนลมดาวฤกษ์ ปกป้องบรรยากาศ |

## สรุป
ดาราศาสตร์และจักรวาลวิทยาศึกษาทุกสิ่งตั้งแต่ดาวเคราะห์ไปจนถึงจักรวาลทั้งหมด ดาวฤกษ์เกิดในเมฆโมเลกุล ใช้เวลาหลายพันล้านปีในการหลอมรวมไฮโดรเจน และสิ้นสุดเป็นดาวแคระขาว ดาวนิวตรอน หรือหลุมดำ กาแล็กซี - กังหัน, ทรงรี, ไม่สม่ำเสมอ - เป็นส่วนสำคัญของโครงสร้างขนาดใหญ่ของจักรวาล ทฤษฎีบิ๊กแบงซึ่งสนับสนุนโดย CMB การขยายตัวของฮับเบิล และความอุดมสมบูรณ์ของธาตุแสง บรรยายถึงเอกภพที่เริ่มต้นเมื่อ 13.8 พันล้านปีก่อน และประกอบด้วยสสารธรรมดา ~5% สสารมืด ~27% และพลังงานมืด ~68% การค้นพบดาวเคราะห์นอกระบบได้แสดงให้เห็นว่าดาวเคราะห์มีอยู่ทั่วไป และการค้นหาโลกที่สามารถอยู่อาศัยได้ยังคงดำเนินต่อไป บทเรียนที่ครอบคลุมคือเราไม่รู้มากนัก สสารมืดและพลังงานมืดรวมกันเป็น 95% ของจักรวาล และเรายังไม่รู้ว่าสิ่งใดสิ่งหนึ่งคืออะไร
