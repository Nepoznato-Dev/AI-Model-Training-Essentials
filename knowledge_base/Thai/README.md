## 📝 การมีส่วนร่วม

เมื่อเพิ่มหรือแก้ไขเนื้อหา:

1. **ปฏิบัติตามคู่มือสไตล์:**
   - ใช้ `#` สำหรับชื่อไฟล์เท่านั้น
   - ใช้ `##` สำหรับส่วนหลัก
   - ใช้ `###` สำหรับส่วนย่อย
   - ใช้ `-` สำหรับรายการไม่มีลำดับ
   - รวมการเน้นไวยากรณ์ในบล็อกโค้ด

2. **เพิ่มเมตาดาตา** (frontmatter YAML):
```yaml
---
title: "ชื่อไฟล์"
description: "คำอธิบายสั้นๆ"
topics: [หัวข้อ1, หัวข้อ2, หัวข้อ3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **รวมการอ้างอิง** สำหรับการอ้างข้อเท็จจริง
4. **เพิ่มการอ้างอิงข้าม** ไปยังไฟล์ที่เกี่ยวข้อง
5. **อัปเดต README นี้** หากคุณเพิ่มไฟล์ใหม่
