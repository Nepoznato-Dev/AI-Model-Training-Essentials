# Lisp & Clojure: patrones idiomáticos y mejores prácticas
Esta guía cubre patrones idiomáticos para Lisp y Clojure.
---

## Modismos de clojure
```clojure
;; ✅ Prefer immutable data
(def users [{:name "Alice" :age 30}])

;; ✅ Threading macros
(-> users
    (filter #(>= (:age %) 18))
    (map :name)
    (sort))

;; ✅ Destructuring
(let [{:keys [name email age]} user]
  (println name email))

(let [[first & rest] items]
  (println first rest))

;; ✅ Keywords as functions
(:name user)          ;; get :name from user
(filter :active users) ;; filter where :active is truthy

;; ✅ comp and partial
(def process (comp sort filter-active map-names))

;; ✅ Spec for validation
(s/def ::name string?)
(s/def ::age (s/and int? pos?))
(s/def ::user (s/keys :req [::name ::age]))
```

---

## Modismos comunes de Lisp
```lisp
;; ✅ Use push/new for building lists
(let ((result '()))
  (dolist (item items)
    (push (process item) result))
  (nreverse result))

;; ✅ with-open for resources
(with-open-file (stream "data.txt" :direction :input)
  (loop for line = (read-line stream nil nil)
        while line
        do (process line)))

;; ✅ Multiple values
(multiple-value-bind (quotient remainder)
    (truncate 17 5)
  (format t "~A remainder ~A~%" quotient remainder))
```

---

## Resumen
Los modismos de Clojure enfatizan: datos inmutables, macros de subprocesos (`->`,`->>`), desestructuración, palabras clave como funciones y especificaciones para validación. Los modismos comunes de Lisp enfatizan:`with-open`para recursos,`push`/`nreverse`para creación de listas y valores múltiples. Ambos valoran la homoiconicidad y el desarrollo impulsado por REPL.
