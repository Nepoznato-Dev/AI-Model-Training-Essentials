# Kotlin — Referencia de sintaxis
Este documento proporciona una referencia de sintaxis completa y estructurada para Kotlin (2.0+). Complementa la referencia principal de Kotlin centrándose en patrones de sintaxis exhaustivos, seguridad nula, corrutinas y modismos de Kotlin.

## Operadores y expresiones
### Operadores principales
| Operador | Nombre | Ejemplo | Notas |
|----------|------|---------|-------|
| `+``-``*``/``%`| Aritmética | `a + b`| |
| `..`| Gama | `1..10`| Gama inclusiva |
| `until`| Campo semiabierto | `1 until 10`| `1..9`|
| `downTo`| Rango descendente | `10 downTo 1`| |
| `==``!=` | Igualdad estructural | `a == b`| Llamadas`.equals()`|
| `===``!==` | Igualdad referencial | `a === b`| Misma instancia |
| `<``>``<=``>=` | Comparación | `a >= b`| Requiere`Comparable`|
| `&&``\|\|``!`| Lógico | `a && b`| Cortocircuito |
| `?:`| Operador de Elvis | `a ?: b`| Devuelve`b`si`a`es nulo |
| `?.`| Llamada segura | `a?.b`| Devuelve nulo si`a`es nulo |
| `!!`| Aserción no nula | `a!!`| Lanza NPE si es nulo |
| `as`| Elenco | `a as String`| Lanza ClassCastException |
| `as?`| Reparto seguro | `a as? String`| Devuelve nulo en caso de error |
| `in`| Membresía | `x in list`| |
| `!in`| No miembro | `x !in list`| |
| `is`| Verificación de tipo | `x is String`| Reparto inteligente después del control |
| `!is`| No tipo | `x !is String`| |
### Sobrecarga del operador
```kotlin
data class Vector2D(val x: Double, val y: Double) {
    operator fun plus(other: Vector2D) = Vector2D(x + other.x, y + other.y)
    operator fun minus(other: Vector2D) = Vector2D(x - other.x, y - other.y)
    operator fun times(scalar: Double) = Vector2D(x * scalar, y * scalar)
    operator fun unaryMinus() = Vector2D(-x, -y)
    operator fun component1() = x
    operator fun component2() = y
}

val v = Vector2D(1.0, 2.0) + Vector2D(3.0, 4.0)  // Vector2D(4.0, 6.0)
val (x, y) = v  // Destructuring via componentN
```

## Controlar el flujo
### Expresiones
```ksharp
// if is an expression
val max = if (a > b) a else b

// when is an expression
val description = when {
    x > 0 -> "positive"
    x < 0 -> "negative"
    else -> "zero"
}

// when with subject
val length = when (s) {
    is String -> s.length
    is Collection -> s.size
    is Array<*> -> s.size
    else -> -1
}
```

### Repartos inteligentes
```kotlin
// Smart cast — compiler narrows type after check
fun process(obj: Any): String = when (obj) {
    is Int -> "Integer: $obj"          // obj is Int here
    is String -> "String(${obj.length})" // obj is String here
    is List<*> -> "List with ${obj.size} items"
    null -> "null"
    else -> "Unknown: ${obj::class}"
}

// Smart cast with &&
fun validate(x: Any?) {
    if (x != null && x is String) {
        println(x.length)  // Smart cast to String
    }
}
```

## Clases y objetos
```kotlin
// Data class
data class User(val name: String, val email: String) {
    // Auto-generates: equals, hashCode, toString, copy, componentN
}

// Sealed class hierarchy
sealed class Result<out T> {
    data class Success<T>(val data: T) : Result<T>()
    data class Error(val exception: Throwable) : Result<Nothing>()
    object Loading : Result<Nothing>()
}

// Object — singleton
object AppConfig {
    val apiBaseUrl = "https://api.example.com"
    val timeout = 30_000
}

// Companion object — factory methods, static-like members
class Database private constructor(val url: String) {
    companion object {
        fun connect(url: String): Database = Database(url)
    }
}

// Enum with behavior
enum class Planet(val mass: Double, val radius: Double) {
    EARTH(5.97e24, 6.371e6),
    MARS(6.42e23, 3.390e6);

    fun surfaceGravity(): Double = 6.674e-11 * mass / (radius * radius)
}

// Value class — zero-overhead wrapper
@JvmInline
value class Email(val value: String) {
    init { require(value.contains("@")) { "Invalid email" } }
}

// Delegation
interface Printer { fun print() }
class ConsolePrinter : Printer { override fun print() = println("console") }
class Service(printer: Printer) : Printer by printer
```

## Corrutinas y flujo
```kotlin
// Suspend function
suspend fun fetchUser(id: String): User = withContext(Dispatchers.IO) {
    httpClient.get("/api/users/$id").body()
}

// Coroutine builders
launch { }       // Fire and forget
async { }        // Returns Deferred<T>
runBlocking { }  // Blocks thread (for main/test)

// Structured concurrency
coroutineScope {
    val deferred1 = async { task1() }
    val deferred2 = async { task2() }
    val result = deferred1.await() + deferred2.await()
}

// Channels
val channel = Channel<Int>()
launch { repeat(5) { channel.send(it) }; channel.close() }
launch { for (value in channel) { println(value) } }

// Flow — cold async stream
fun numbers(): Flow<Int> = flow {
    for (i in 1..10) {
        delay(100)
        emit(i)
    }
}

// Flow operators
numbers()
    .filter { it % 2 == 0 }
    .map { it * it }
    .flowOn(Dispatchers.Default)
    .collect { println(it) }

// StateFlow — hot state holder
class ViewModel {
    private val _uiState = MutableStateFlow<UiState>(UiState.Loading)
    val uiState: StateFlow<UiState> = _uiState.asStateFlow()
}
```

## Genéricos y sistema de tipos
```kotlin
// Generic function
fun <T> listOf(item: T, vararg rest: T): List<T> = listOf(item, *rest)

// Generic class
class Stack<T> {
    private val items = mutableListOf<T>()
    fun push(item: T) = items.add(item)
    fun pop(): T = items.removeAt(items.lastIndex)
    fun peek(): T = items.last()
}

// Variance
interface Producer<out T> { fun produce(): T }   // Covariant — produces T
interface Consumer<in T> { fun consume(item: T) } // Contravariant — consumes T

// Type constraints
fun <T : Comparable<T>> sorted(a: T, b: T): List<T> =
    if (a <= b) listOf(a, b) else listOf(b, a)

// Reified type parameters (inline functions)
inline fun <reified T> Gson.fromJson(json: String): T =
    this.fromJson(json, T::class.java)

// Star projection
fun printAll(items: List<*>) {
    items.forEach { println(it) }
}
```

## Funciones de alcance
```kotlin
// let — transform nullable, scope: 'it'
val length: Int? = name?.let { it.length }

// apply — configure object, scope: 'this', returns this
val user = User("Alice", "").apply {
    email = "alice@example.com"
}

// also — side effect, scope: 'it', returns this
val result = compute().also { log("Result: $it") }

// run — compute with context, scope: 'this', returns result
val description = user.run { "$name ($email)" }

// with — operate on object, scope: 'this', returns result
with(config) {
    println("Host: $host, Port: $port")
}
```

## Resumen
La sintaxis de Kotlin es concisa, segura e interoperable con Java. La seguridad nula elimina una clase completa de errores en el momento de la compilación. Las corrutinas proporcionan una forma natural de escribir código asincrónico. Las clases selladas, las clases de datos y las funciones de extensión permiten el modelado de dominio expresivo. El poder del lenguaje proviene de la interacción de sus características: funciones de alcance, DSL, clases en línea y genéricos reificados se combinan para producir código que es seguro y agradable de escribir.
