# Scratch: historial de versiones y evolución
## Línea de tiempo
| Versión | Año | Tema clave |
|---------|------|-----------|
| Pre-Scratch | 2003 | Se forma el Scratch Team en el MIT Media Lab |
| Rasca 1.0 | 2007 | **Lanzamiento inicial** — programación visual para niños |
| Rasca 1.4 | 2009 | Gráficos mejorados, más bloques |
| Rasca 2.0 | 2013 | **Principal**: editor basado en web, variables en la nube, mochila |
| Rasca 3.0 | 2019 | **Principal**: reescritura completa (HTML5/JS), extensiones, lápiz |
| Rasca 3.x | 2019-25 | Detección de vídeo, conversión de texto a voz, traducción, micro:bit |
| Rasca Jr. | 2014 | Versión simplificada para niños más pequeños (5-7) |
| Escritorio borrador | 2020 | Editor sin conexión (basado en electrones) |
## Hitos importantes
### Orígenes (2003-2006)
- **2003**: El grupo Lifelong Kindergarten del MIT Media Lab comienza el desarrollo de Scratch
- Dirigido por Mitchel Resnick
- **Objetivo**: Enseñar programación a los niños a través de bloques visuales.
- Inspirado por: Logotipo (Seymour Papert), Logotipo de Lego, Squeak Etoys
- Nombre: "Scratch" — de DJ scratching (mezcla de medios juntos)
### Scratch 1.0 (2007)
- **2007**: primer lanzamiento público
- Programación de bloques de arrastrar y soltar
- Proyectos basados en Sprites (personajes, animaciones)
- Sonido, gráficos, animación.
- Chirrido integrado (Smalltalk)
- **Objetivo**: edades entre 8 y 16 años, pero una adopción mucho más amplia
### Scratch 1.4 (2009)
- Representación de gráficos mejorada
- Más bibliotecas de sprites
- Mejor soporte de sonido
- Última versión construida en Squeak
### Scratch 2.0 (2013)
- **Editor completo basado en web**: se ejecuta en el navegador
- Variables de la nube: comparte datos entre proyectos
- Mochila: comparte sprites/scripts entre proyectos
- Bloques personalizados (como funciones)
- Construido en ActionScript 3 (Flash)
- Funciones de la comunidad: remezclar, compartir, comentar
### Scratch 3.0 (2019)
- **Reescritura completa** — HTML5/JavaScript (sin Flash)
- Funciona en tabletas, teléfonos y Chromebooks
- **Extensiones**:
  - Bolígrafo (dibujo)
  - Detección de vídeo (cámara)
  - Texto a voz
  - Traducir (Traductor de Google)
  -micro:bit (hardware)
  - LEGO Mindstorms EV3
  - Nosotros hacemos 2.0
- Mejoras en el editor de sonido.
- Nuevo editor de pintura (vector + mapa de bits)
- Mochila, variables de nube retenidas
### Scratch Desktop y más allá (2020-presente)
- **2020**: Scratch Desktop: editor sin conexión (basado en electrones)
- Desarrollo continuo de extensiones.
- Extensiones AI/ML (creadas por la comunidad)
- Integración con computación física (micro:bit, Arduino)
## Evolución de las categorías de bloques
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Conceptos de programación enseñados
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Principios clave de diseño
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Impacto y adopción
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
