# Diccionario Español — Definiciones Comunes de Palabras

Una lista de referencia de palabras en inglés de uso frecuente y sus significados,
que cubre vocabulario cotidiano, términos académicos y palabras comúnmente encontradas
en preguntas y discusiones.

---

## A

**abandon** — abandonar permanentemente; renunciar a una meta o lugar.
**ability** — el poder o habilidad para hacer algo.
**abstract** — existente como concepto más que como cosa concreta; un resumen de un documento.
**accurate** — correcto y preciso; libre de errores.
**achieve** — alcanzar exitosamente una meta mediante esfuerzo.
**acknowledge** — aceptar o admitir la verdad de algo; mostrar reconocimiento.
**acquire** — obtener o conseguir algo, usualmente mediante esfuerzo o compra.
**adapt** — ajustarse a nuevas condiciones o requisitos.
**adequate** — satisfactorio; justo lo suficiente para un propósito.
**adjacent** — junto a o contiguo a algo más.
**adjust** — hacer pequeños cambios para mejorar el ajuste o función.
**advance** — moverse hacia adelante; progreso; también, antes del tiempo actual.
**advantage** — una condición que da una posición favorable sobre otros.
**adverse** — desfavorable; dañino.
**affect** — tener un impacto sobre algo (verbo); emoción (sustantivo, formal).
**aggregate** — un todo formado combinando varios elementos.
**algorithm** — un conjunto de reglas o pasos para resolver un problema o tarea.
**allocate** — asignar recursos para un propósito particular.
**alter** — cambiar algo, usualmente parcialmente.
**ambiguous** — poco claro; puede interpretarse de más de una manera.
**analyse** — examinar en detalle para entender o explicar.
**annotate** — añadir notas explicativas a un texto o diagrama.
**anticipate** — esperar o prepararse para algo antes de que ocurra.
**apparent** — claramente visible o entendido; pareciendo ser verdadero.
**approach** — una forma de tratar algo; acercarse.
**approximate** — casi correcto; no exacto.
**assess** — evaluar o juzgar la calidad, valor o naturaleza de algo.
**assign** — dar una tarea o rol a alguien; asignar.
**assume** — aceptar algo como verdadero sin prueba.
**attribute** — una cualidad o característica; atribuir algo a una causa (verbo).
**automate** — hacer que un proceso opere automáticamente sin intervención humana.

## B

**benefit** — una ventaja o resultado positivo.
**bias** — una preferencia injusta a favor o en contra de algo; error sistemático.
**brief** — corto en tiempo o longitud; un resumen o instrucciones.

## C

**calculate** — determinar un valor usando matemáticas.
**capable** — teniendo la habilidad o cualidades necesarias para algo.
**capacity** — la cantidad máxima que algo puede contener o hacer.
**categorise** — colocar en grupos basándose en características compartidas.
**clarify** — hacer algo más fácil de entender.
**classify** — organizar en categorías o grupos.
**coherent** — lógico y consistente; fácil de entender.
**collaborate** — trabajar junto con otros hacia una meta común.
**compile** — reunir y organizar información; convertir código fuente en código ejecutable.
**complex** — consistiendo de muchas partes interconectadas; no simple.
**component** — una parte o elemento de un todo mayor.
**comprehend** — entender completamente.
**compute** — calcular o procesar datos.
**concept** — una idea abstracta o noción general.
**conclude** — llegar a una decisión o terminar algo.
**condition** — un requisito; un estado de ser; circunstancias.
**configure** — organizar o configurar un sistema de una forma particular.
**confirm** — establecer la verdad o precisión de algo.
**conflict** — un desacuerdo serio; un choque entre fuerzas opuestas.
**consistent** — siempre comportándose de la misma forma; no contradictorio.
**context** — las circunstancias que rodean algo; información de fondo.
**contrast** — comparar para mostrar diferencias.
**convert** — cambiar de una forma, unidad o uso a otro.
**coordinate** — organizar diferentes elementos para trabajar juntos.
**criteria** — estándares por los cuales algo es juzgado (plural de criterion).

## D

**data** — hechos y estadísticas recopilados para análisis.
**debug** — encontrar y corregir errores en código de computadora.
**define** — dar el significado de una palabra o describir los límites de algo.
**demonstrate** — mostrar cómo funciona o se hace algo.
**deploy** — poner en uso; instalar y ejecutar software en un entorno productivo.
**derive** — obtener algo de una fuente; llegar a una conclusión mediante razonamiento.
**determine** — descubrir o establecer algo conclusivamente.
**develop** — construir, crecer o hacer algo más elaborado con el tiempo.
**differ** — ser diferente; discrepar.
**distinct** — claramente diferente y separado.
**distribute** — extender o compartir a través de múltiples ubicaciones o personas.
**domain** — un campo de conocimiento o actividad; una dirección web.
**duplicate** — una copia exacta; copiar algo.

## E

**efficient** — lograr resultados con mínimo desperdicio de tiempo o recursos.
**element** — un componente básico; una de las sustancias químicas en la tabla periódica.
**embed** — fijar firmemente dentro; incorporar en una estructura mayor.
**enable** — hacer posible; activar una característica.
**enhance** — mejorar la calidad o valor de algo.
**entity** — una cosa con existencia distinta; un objeto en un sistema.
**enumerate** — listar elementos uno por uno; contar.
**environment** — alrededores; en computación, el sistema y configuración en el que se ejecuta el software.
**error** — un error; una desviación del comportamiento correcto.
**estimate** — un cálculo aproximado; juzgar roughly.
**evaluate** — formar una opinión después de consideración cuidadosa.
**execute** — llevar a cabo un plan o instrucción; ejecutar un programa de computadora.
**explicit** — claramente declarado sin dejar nada implícito.
**extend** — hacer más largo o grande; añadir funcionalidad.
**extract** — sacar u obtener de una fuente.

## F

**factor** — un elemento que contribuye a un resultado; descomponer en componentes (matemáticas).
**feature** — un aspecto distintivo o capacidad.
**filter** — remover elementos no deseados; un dispositivo o función que selecciona elementos.
**flexible** — capaz de adaptarse a diferentes condiciones.
**format** — la disposición o diseño de datos; preparar para uso.
**framework** — una estructura básica que proporciona soporte para construir algo.
**function** — el propósito de algo; un bloque reutilizable de código (programación).
**fundamental** — formando la base o fundamento; esencial.

## G

**generate** — producir o crear.
**global** — relativo al mundo entero; aplicando a un sistema completo.
**guideline** — una regla general o recomendación.

## H

**hierarchy** — un sistema clasificado por niveles de autoridad o importancia.
**hypothesis** — una explicación propuesta que puede ser probada.

## I

**identify** — reconocer y nombrar algo.
**implement** — poner un plan o sistema en efecto.
**implicit** — implicado sin ser declarado directamente.
**index** — un puntero a ubicación de datos; una lista alfabética (sustantivo); categorizar (verbo).
**infer** — llegar a una conclusión a partir de evidencia sin declaración explícita.
**initialise** — establecer una variable o sistema a un estado inicial.
**input** — datos proporcionados a un sistema; ingresar datos.
**integrate** — combinar partes en un todo; añadir una característica a un sistema existente.
**interface** — un punto donde dos sistemas se encuentran e interactúan; un contrato en programación.
**interpret** — explicar el significado de algo; ejecutar código línea por línea.
**iterate** — repetir un proceso, frecuentemente con cambios incrementales.

## J

**justify** — dar razones para una decisión; alinear texto a lo largo de un margen.

## K

**key** — esencial; un valor usado para buscar datos; un secreto criptográfico.

## L

**layer** — un nivel en una jerarquía; un componente apilado sobre otros.
**legacy** — heredado del pasado; software antiguo aún en uso.
**limit** — un límite; el valor máximo o mínimo permitido.
**linear** — dispuesto en línea recta; aumento proporcional.
**link** — una conexión entre dos cosas; un hipervínculo.
**local** — relativo a un área cercana; en computación, ejecutándose en la misma máquina.
**logic** — razonamiento de acuerdo a reglas; el flujo de control en un programa.

## M

**maintain** — mantener en buena condición; continuar en el tiempo.
**manipulate** — manejar o controlar, algunas veces con habilidad; influenciar injustamente.
**map** — asociar claves con valores (estructura de datos); mostrar relaciones espaciales.
**merge** — combinar en uno; unir ramas de código.
**method** — una forma de hacer algo; una función adjunta a un objeto (POO).
**migrate** — mover datos o sistemas de un entorno a otro.
**model** — una representación de algo; un sistema de IA entrenado.
**modify** — cambiar parcialmente.
**monitor** — observar y verificar en el tiempo; una pantalla de visualización.

## N

**navigate** — encontrar un camino a través de; moverse entre páginas o pantallas.
**node** — un punto en una red o estructura de árbol.
**normalise** — escalar valores a un rango estándar; reducir redundancia en una base de datos.

## O

**objective** — una meta u objetivo; no influenciado por sentimientos personales (adjetivo).
**obtain** — obtener o adquirir.
**optimise** — hacer tan efectivo o eficiente como sea posible.
**output** — datos producidos por un sistema; el resultado de una computación.
**override** — tomar control sobre una configuración o método existente.

## P

**parameter** — un valor pasado a una función; una característica medible.
**parse** — analizar texto en componentes; interpretar datos estructurados.
**pattern** — una disposición repetida; una plantilla para resolver un problema común.
**persist** — continuar existiendo; guardar datos para que sobrevivan reinicios.
**pipeline** — una serie de etapas conectadas donde la salida de una alimenta la siguiente.
**precise** — exacto; preciso en detalle fino.
**predict** — decir qué ocurrirá antes de que suceda.
**prioritise** — clasificar tareas por importancia y abordar las más importantes primero.
**process** — una serie de pasos; una instancia de programa en ejecución (verbo: manejar o transformar).
**prompt** — una señal o instrucción dada a un modelo de IA o usuario.
**property** — una característica o atributo; un valor perteneciente a un objeto.
**protocol** — un conjunto de reglas para comunicación entre sistemas.

## Q

**query** — una solicitud de información desde una base de datos; una pregunta.
**queue** — una línea de elementos esperando ser procesados (primero en entrar, primero en salir).

## R

**recursive** — una función o proceso que se llama o refiere a sí mismo.
**redundant** — innecesario porque duplica funcionalidad existente; extra para respaldo.
**refactor** — reestructurar código existente sin cambiar su comportamiento externo.
**reference** — un puntero a un valor; una fuente citada para información.
**relevant** — estrechamente conectado al tema en cuestión.
**render** — producir salida (gráficos, texto o HTML).
**represent** — representar o describir algo.
**requirement** — una condición o característica necesaria.
**resolve** — encontrar una solución; determinar un valor (ej. un nombre DNS).
**retrieve** — recuperar información almacenada.
**robust** — fuerte y confiable, especialmente bajo estrés.

## S

**scalable** — capaz de manejar carga de trabajo incrementada sin degradar rendimiento.
**schema** — la estructura o diseño de una base de datos o formato de datos.
**scope** — el rango de efecto; la sección de código donde una variable es visible.
**segment** — una sección o parte distinta.
**semantic** — relativo al significado, especialmente en lenguaje o código.
**sequence** — un conjunto de cosas en un orden particular.
**session** — un período de actividad; una conexión entre cliente y servidor.
**simulate** — imitar el comportamiento de un sistema.
**source** — el origen de algo; código original antes de compilación.
**specify** — declarar clara y en detalle.
**static** — no cambiante; en computación, fijo en tiempo de compilación o no asociado con instancias.
**store** — guardar datos para uso posterior.
**structure** — la disposición de partes; un tipo de dato compuesto.
**summarise** — dar una declaración breve de los puntos principales.
**synchronise** — causar que ocurra al mismo tiempo o ritmo.
**syntax** — las reglas que gobiernan la estructura de declaraciones en un lenguaje.

## T

**template** — un modelo o patrón usado como punto de partida.
**threshold** — un nivel o punto que desencadena una acción cuando se alcanza.
**token** — una unidad de texto en PLN; una credencial de autenticación.
**trace** — seguir un camino; un registro de ejecución de programa para depuración.
**transform** — cambiar en forma, naturaleza o apariencia.
**transmit** — enviar datos de un lugar a otro.

## U

**uniform** — consistente y sin cambios en todo.
**unique** — el único de su tipo; ocurriendo solo una vez.
**update** — traer a un estado más actual.
**utilise** — hacer uso de algo.

## V

**validate** — confirmar que algo cumple requisitos o es correcto.
**variable** — un contenedor nombrado para un valor que puede cambiar.
**verify** — verificar corrección o verdad.
**version** — una forma específica de un producto en un punto particular de su desarrollo.

## W

**workflow** — una serie de pasos seguidos para completar una tarea.
**warrant** — justificación para una acción; un documento legal autorizando algo.

## X

**xenophobia** — miedo u odio a extranjeros o extraños.

## Y

**yield** — producir o proporcionar; ceder; la cantidad producida.

## Z

**zero-sum** — una situación donde la ganancia de una persona equivale a la pérdida de otra.
**zone** — un área con características o límites distintos.
