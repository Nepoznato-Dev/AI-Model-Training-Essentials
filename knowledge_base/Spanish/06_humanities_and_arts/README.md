# Humanidades y Artes
Una colección estructurada de documentos de referencia que cubren historia, arte, lenguaje, filosofía, psicología y religión: las disciplinas centrales de las humanidades que brindan contexto para comprender la civilización humana, la expresión creativa y el pensamiento crítico.
