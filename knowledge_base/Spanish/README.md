   - Use `##` para secciones principales
   - Use `###` para subsecciones

   - Incluya resaltado de sintaxis en bloques de código

2. **Agregue metadatos** (frontmatter YAML):
```yaml

```

3. **Incluya citas** para afirmaciones factuales
