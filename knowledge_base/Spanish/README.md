## 📝 Contribuciones

Al agregar o modificar contenido:

1. **Sigue la guía de estilo:**
   - Usa `#` solo para el título del archivo
   - Usa `##` para secciones principales
   - Usa `###` para subsecciones
   - Usa `-` para listas desordenadas
   - Incluye resaltado de sintaxis en bloques de código

2. **Añade metadatos** (frontmatter YAML):
```yaml
---
title: "Título del Archivo"
description: "Breve descripción"
topics: [tema1, tema2, tema3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Incluye citas** para afirmaciones factuales
4. **Añade referencias cruzadas** a archivos relacionados
5. **Actualiza este README** si añades nuevos archivos
