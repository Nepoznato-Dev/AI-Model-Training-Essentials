# Base de conocimientos de inglés
Una colección completa de documentos de referencia que cubren codificación, tecnología, IA, ciencia, negocios, humanidades y más, escritos en un estilo conversacional natural diseñado tanto para el entrenamiento de IA como para el aprendizaje humano.
**Última actualización:** agosto de 2026  
**Archivos totales:** 138+ documentos de rebajas  
**Organización:** 10 directorios temáticos + 34 referencias de lenguajes de programación
---

## Estructura del directorio
```
knowledge_base/English/
├── 01_coding_and_technology/          # Programming, web, databases, cloud, networking, DevOps, security
│   └── programming_languages/         # 34 individual language references
│       ├── python/python.md
│       ├── javascript/javascript.md
│       ├── rust/rust.md
│       ├── go/go.md
│       └── ... (34 languages total)
├── 02_ai_and_machine_learning/        # AI, ML, LLMs, prompt engineering, CV, NLP, MLOps
├── 03_data_science_and_analytics/     # Analytics, statistics, mathematics, visualisation, experimentation
├── 04_natural_sciences/               # Physics, chemistry, biology, medicine, environment
├── 05_business_and_economics/         # Economics, finance, law, marketing, management
├── 06_humanities_and_arts/            # History, geography, arts, psychology, language, philosophy
├── 07_general_reference/              # Dictionary, general knowledge, communication
├── 08_future_and_trends/              # Future projections, emerging tech, scenario planning
├── 09_lessons_from_failures/          # AI failures, security issues, system reliability

```

### Editar un archivo
Cuando cambias un archivo de base de conocimientos, mantén su contenido frontal sincronizado:
1. **Bump`version`** siguiente [SemVer](https://semver.org/):
   - Parche (`1.0.x`): errores tipográficos, formato, correcciones menores
   - Menor (`1.x.0`): nuevas secciones, contenido ampliado, nuevos ejemplos
   - Major (`x.0.0`): reescritura o reestructuración completa
2. **Agregue una entrada al registro de cambios** (la más reciente primero) que describa lo que cambió:   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **Actualice `last_modified`** a la fecha de su cambio
4. **Agréguese a`contributors`** si es su primera edición del archivo:   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
