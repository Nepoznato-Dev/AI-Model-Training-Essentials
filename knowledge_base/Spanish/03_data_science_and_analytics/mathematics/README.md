# Matemáticas
Una colección completa de documentos de referencia detallados que cubren matemáticas puras, matemáticas aplicadas, física y matemáticas de ingeniería: los fundamentos cuantitativos esenciales para la ciencia de datos, el aprendizaje automático y la informática científica.

## Referencias cruzadas
Muchos archivos se basan unos en otros. Cadenas de dependencia clave:
- **Optimización** se basa en`mathematics.md`(cálculo, álgebra lineal) y`real_analysis.md`(convergencia)
- **Teoría de la información** se conecta a`statistics_and_probability.md`y`thermodynamics_and_statistical_mechanics.md`(entropía)
- **Mecánica Cuántica** requiere`abstract_algebra.md`(espacios vectoriales) y`classical_mechanics.md`(analogía hamiltoniana)
- **Procesamiento de señales** se basa en`optics_and_waves.md`(teoría de ondas) y`numerical_methods.md`(cálculo FFT)
- **Teoría de juegos** se conecta con`optimization.md`y`stochastic_processes.md`(estrategias mixtas, dinámica evolutiva)
