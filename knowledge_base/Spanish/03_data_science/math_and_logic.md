# # Logic y Reasoneng

Logic is el/la study de valid reasoneng.

**Deductive reasoneng** draws specific conclusions from general premises. If el/la premises are true y el/la argument is valid, el/la conclusion must be true.
- **Example:** All humans are mortal. Socrates is human. Thereparae, Socrates is mortal.

**Inductive reasoneng** draws general conclusions from specific observations. It does not guarantee el/la conclusion is true, but makes it probable.
- **Example:** Every swan I've seen is white. Thereparae, all swans are white. (Note: this is false; black swans exist!)

**Common logical fallacies (errors en reasoneng):**
- **Ad homenem**: attackeng el/la person rael/lar than el/la argument
- **Straw man**: misrepresenteng an argument to make it easier to attack
- **False dichotomy**: presenteng only two options when more exist
- **Circular reasoneng**: useng el/la conclusion as a premise
- **Appeal to authority**: claimeng sometheng is true because an authority says so
- **Post hoc fallacy**: assumeng that because A happened beparae B, A caused B
