# Neurociencia
La neurociencia es el estudio del sistema nervioso: el cerebro, la médula espinal y todos los nervios que los conectan con el cuerpo. Abarca múltiples niveles: desde moléculas y genes, hasta neuronas y sinapsis individuales, circuitos y regiones cerebrales, comportamiento, cognición y conciencia. El cerebro es la estructura más compleja del universo conocido y contiene aproximadamente 86 mil millones de neuronas conectadas por billones de sinapsis, y comprender cómo funciona es uno de los grandes desafíos de la ciencia.
---

## La Neurona
### Partes de una neurona
| Componente | Función |
|-----------|----------|
| **Dendritas** | Recibir señales de otras neuronas; extensiones en forma de rama |
| **Cuerpo celular (soma)** | Integra señales entrantes; contiene el núcleo |
| **Axón** | Fibra larga que transmite señales eléctricas (potenciales de acción) fuera del soma |
| **Vaina de mielina** | Capa aislante alrededor de los axones; acelera la transmisión de señales |
| **Nodos de Ranvier** | Lagunas en mielina; permitir la conducción saltatoria (saltos de señal entre nodos) |
| **Terminales de axones (botones sinápticos)** | Libera neurotransmisores en la sinapsis |
### Tipos de neuronas
| Tipo | Dirección | Función |
|------|-----------|----------|
| **Sensorial (aferente)** | Cuerpo → cerebro | Llevar información de los sentidos (tacto, temperatura, dolor, visión, etc.) |
| **Motriz (eferente)** | Cerebro → cuerpo | Controla músculos y glándulas |
| **Interneuronas** | Dentro del SNC | Conectar neuronas con otras neuronas; la mayoría de las neuronas son interneuronas |

## Cómo se comunican las neuronas
### El potencial de acción
| Fase | Descripción |
|-------|-------------|
| **Potencial de reposo** | La neurona está a ~-70 mV; bomba de sodio y potasio mantiene el equilibrio iónico |
| **Despolarización** | El estímulo abre los canales de sodio; Na+ entra precipitadamente; el potencial de membrana aumenta |
| **Umbral** | Si el potencial alcanza ~-55 mV, se activa un potencial de acción (todo o nada) |
| **Fase ascendente** | Se abren canales de sodio dependientes de voltaje; picos potenciales a ~+40 mV |
| **Fase de caída** | Los canales de sodio se cierran; canales de potasio abiertos; K+ sale; caídas potenciales |
| **Subestimación (hiperpolarización)** | El potencial cae brevemente por debajo del nivel de reposo |
| **Período refractario** | Neuron no puede volver a disparar inmediatamente; asegura la propagación unidireccional |
### La sinapsis
| Componente | Rol |
|-----------|--------------|
| **Neurona presináptica** | Envía la señal; contiene vesículas sinápticas con neurotransmisores |
| **Hendidura sináptica** | Pequeña brecha (~20 nm) entre neuronas |
| **Neurona postsináptica** | Recibe la señal; tiene proteínas receptoras |
| **Neurotransmisores** | Mensajeros químicos que cruzan la sinapsis |
| **Receptores** | Unir neurotransmisores; abrir canales iónicos o desencadenar cascadas de segundos mensajeros |

## Neurotransmisores clave
| Neurotransmisor | Función | Condiciones asociadas |
|-----------------|----------|----------------------|
| **Glutamato** | Neurotransmisor excitador principal; aprendiendo; memoria | Exceso → excitotoxicidad (ictus, neurodegeneración) |
| **GABA** | Neurotransmisor inhibidor principal; reduce la actividad neuronal | Déficit → ansiedad, epilepsia |
| **Dopamina** | Premio; motivación; control de motores; atención | Déficit → Parkinson; exceso → esquizofrenia |
| **Serotonina** | Ánimo; dormir; apetito; digestión | Déficit → depresión, ansiedad |
| **Acetilcolina** | Activación muscular; aprendiendo; memoria | Déficit → Enfermedad de Alzheimer |
| **Norepinefrina** | Excitación; vigilancia; respuesta al estrés | Desregulación → TDAH; depresión |
| **endorfinas** | Alivio del dolor; placer | Liberación inducida por el ejercicio ("euforia del corredor") |

## Estructura del cerebro
### Principales regiones del cerebro
| Región | Función |
|--------|----------|
| **Cortex cerebral** | Cognición superior; dividido en lóbulos frontal, parietal, temporal y occipital |
| **Lóbulo frontal** | Planificación; Toma de decisiones; personalidad; movimiento voluntario (corteza motora) |
| **Lóbulo parietal** | Procesamiento sensorial; conciencia espacial; navegación |
| **Lóbulo temporal** | Audiencia; comprensión del lenguaje; memoria (hipocampo) |
| **Lóbulo occipital** | Procesamiento visual |
| **Cerebelo** | Coordinación motora; balance; aprendizaje motor; algunas funciones cognitivas |
| **Tronco cerebral** | Funciones vitales: respiración; frecuencia cardíaca; ciclo sueño-vigilia |
| **Tálamo** | Estación de retransmisión sensorial; encamina señales a áreas corticales apropiadas |
| **Hipotálamo** | Homeostasis; regulación hormonal; hambre; sed; ritmos circadianos |
### El sistema límbico
| Estructura | Función |
|-----------|----------|
| **Amígdala** | Procesamiento emocional; miedo; detección de amenazas; memoria emocional |
| **Hipocampo** | Formación de la memoria; navegación espacial; convierte la memoria de corto plazo en memoria de largo plazo |
| **Ganglios basales** | Formación de hábitos; recompensar el aprendizaje; control de motores |
| **Corteza cingulada** | Detección de errores; empatía; control de impulsos; regulación de las emociones |
| **Núcleo accumbens** | Circuito de recompensa; placer; adicción |

## Neurociencia cognitiva
### Funciones cognitivas clave y sus regiones cerebrales
| Función | Áreas primarias del cerebro |
|----------|-------------------|
| **Atención** | corteza prefrontal; corteza parietal; tálamo |
| **Memoria de trabajo** | corteza prefrontal; corteza parietal |
| **Memoria a largo plazo** | Hipocampo (formación); corteza (almacenamiento) |
| **Idioma** | Área de Broca (producción); Área de Wernicke (comprensión) |
| **Regulación de las emociones** | corteza prefrontal; amígdala; PFC ventromedial |
| **Toma de decisiones** | corteza prefrontal; corteza orbitofrontal; estriado |
| **Procesamiento visual** | Lóbulo occipital → corriente ventral ("qué") y corriente dorsal ("dónde") |
| **Control de motores** | corteza motora; cerebelo; ganglios basales |
### Ondas cerebrales
| Ola | Frecuencia | Estado asociado |
|------|-----------|-----------------|
| **Delta** | 0,5–4 Hz | Sueño profundo |
| **Theta** | 4–8 Hz | Sueño ligero; meditación; somnolencia |
| **Alfa** | 8–13 Hz | Vigilia relajada; ojos cerrados |
| **Beta** | 13–30 Hz | Pensamiento activo; enfocar; estado de alerta |
| **Gama** | 30–100 Hz | Cognición superior; vinculante; conciencia |

## Neuroplasticidad
| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Plasticidad sináptica** | La fuerza de las sinapsis cambia con la actividad | Potenciación a largo plazo (LTP); depresión a largo plazo (LTD) |
| **Plasticidad estructural** | A las neuronas les crecen nuevas dendritas o axones | Aprender nuevas habilidades; recuperación de una lesión |
| **Remapeo cortical** | Las regiones del cerebro reasignan funciones | La corteza visual de las personas ciegas procesa el tacto y el sonido |
| **Neurogénesis** | Nacen nuevas neuronas | Ocurre en el hipocampo; estimulado por el ejercicio y el aprendizaje |

## Métodos de investigación
| Método | Qué mide | Resolución |
|--------|-----------------|------------|
| **fMRI** | Nivel de oxígeno en sangre (señal en NEGRITA) → actividad cerebral | Buen espacial (~1 mm); temporal pobre (~1 s) |
| **EEG** | Actividad eléctrica del cuero cabelludo | Excelente temporal (~1 ms); pobre espacial |
| **MEG** | Campos magnéticos de la actividad neuronal | Bueno temporal y espacial |
| **MASCOTA** | Trazador radiactivo → actividad metabólica | Moderado espacial y temporal |
| **TMS** | Pulsos magnéticos → alteran temporalmente el área del cerebro | evidencia causal; profundidad limitada |
| **Grabación de una sola unidad** | Actividad eléctrica de neuronas individuales | Celda única; invasor; principalmente investigación con animales |
| **Optogenética** | Neuronas activadas por luz | Control preciso; investigación con animales |
| **DTI** (Imágenes con tensor de difusión) | Tractos de materia blanca | Mapeo de conectividad |

## Trastornos neurológicos y psiquiátricos
| Trastorno | Sistema afectado | Características clave |
|----------|----------------|--------------|
| **Alzheimer** | Corteza; hipocampo | Pérdida de memoria; placas amiloides; enredos tau |
| **Parkinson** | sustancia negra; ganglios basales | Temblor; rigidez; pérdida de neuronas de dopamina |
| **Epilepsia** | Corteza cerebral | Convulsiones recurrentes; actividad eléctrica anormal |
| **Esclerosis múltiple** | Vaina de mielina (SNC) | Desmielinización; transmisión de señal interrumpida |
| **Depresión** | corteza prefrontal; sistema límbico | Estado de ánimo bajo persistente; desequilibrio de neurotransmisores |
| **Esquizofrenia** | Varias regiones | Alucinaciones; ilusiones; desregulación de la dopamina |
| **ELA** | Neuronas motoras | Debilidad muscular progresiva; muerte de la neurona motora |

## Resumen
La neurociencia estudia el sistema nervioso en todos sus niveles, desde los mecanismos moleculares de los canales iónicos hasta la experiencia subjetiva de la conciencia. Las neuronas se comunican a través de potenciales de acción eléctricos y sinapsis químicas, utilizando neurotransmisores como glutamato, GABA, dopamina y serotonina. El cerebro está organizado en regiones especializadas: la corteza para la cognición superior, el sistema límbico para las emociones y la memoria, y el cerebelo para la coordinación. La neuroplasticidad significa que el cerebro puede reconfigurarse a lo largo de la vida. Los métodos de investigación van desde la resonancia magnética funcional (buena resolución espacial), el EEG (buena resolución temporal) y la optogenética (control causal preciso). Comprender el cerebro es posiblemente el problema más difícil de la ciencia: es el único órgano que se estudia a sí mismo.
