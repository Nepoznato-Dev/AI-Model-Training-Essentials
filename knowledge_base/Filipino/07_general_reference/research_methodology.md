# Pamamaraan ng Pananaliksik
Ang pamamaraan ng pananaliksik ay ang sistematikong diskarte sa pagsisiyasat ng mga tanong, pagsubok ng mga hypotheses, at pagbuo ng maaasahang kaalaman. Nagsasagawa ka man ng mga siyentipikong eksperimento, mga survey sa agham panlipunan, pagsusuri sa negosyo, o pananaliksik sa akademiko, tinutukoy ng pamamaraang pipiliin mo kung kapani-paniwala, maaaring kopyahin, at kapaki-pakinabang ang iyong mga natuklasan. Ang isang mahusay na idinisenyong pag-aaral ay gumagawa ng mga mapagkakatiwalaang resulta; ang isang hindi maganda ang disenyo ay gumagawa ng ingay - o mas masahol pa, may kumpiyansa na mga maling sagot.
---

## Mga Uri ng Pananaliksik
| Dimensyon | Mga Pagpipilian | Paglalarawan |
|-----------|---------|-------------|
| **Layunin** | Basic vs Applied | Basic: pagpapalawak ng kaalaman para sa sarili nitong kapakanan. Inilapat: paglutas ng isang praktikal na problema |
| **Paglapit** | Deductive vs Inductive | Deduktibo: teorya → hypothesis → pagmamasid. Pasaklaw: pagmamasid → pattern → teorya |
| **Uri ng data** | Quantitative vs Qualitative vs Mixed | Dami: mga numero. Kwalitatibo: mga salita, kahulugan. Mixed: pareho |
| **Horizon ng oras** | Cross-sectional vs Longitudinal | Cross-sectional: isang punto sa oras. Longitudinal: sa paglipas ng panahon |
| **Setting** | Eksperimento kumpara sa Obserbasyonal | Eksperimental: ang mananaliksik ay nagmamanipula ng mga variable. Obserbasyonal: nagmamasid ang mananaliksik nang walang interbensyon |
---

## Ang Paraang Siyentipiko
| Hakbang | Paglalarawan |
|------|-------------|
| **1. Pagmamasid** | Pansinin ang isang phenomenon o pattern |
| **2. Tanong** | Bumuo ng isang tiyak, masusubok na tanong |
| **3. Hypothesis** | Magmungkahi ng pansamantalang paliwanag o hula |
| **4. Hula** | Kumuha ng mga masusubok na hula mula sa hypothesis |
| **5. Eksperimento / Pagmamasid** | Mangolekta ng data upang subukan ang mga hula |
| **6. Pagsusuri** | Pag-aralan ang datos; matukoy kung sinusuportahan o pinabulaanan ng mga resulta ang hypothesis |
| **7. Konklusyon** | Gumuhit ng mga konklusyon; isaalang-alang ang mga limitasyon; magmungkahi ng karagdagang pananaliksik |
| **8. Peer review at replikasyon** | Sinusuri at tinatangka ng iba na kopyahin ang mga natuklasan |

## Dami ng Pananaliksik
### Mga Pang-eksperimentong Disenyo
| Disenyo | Paglalarawan | Lakas | Kahinaan |
|--------|-------------|----------|----------|
| **True experiment (RCT)** | Random na pagtatalaga sa paggamot at kontrol | Pinakamatibay na katibayan ng sanhi | Mahal; maaaring hindi i-generalize |
| **Quasi-experiment** | Walang random na pagtatalaga; mga pangkat ng paghahambing | Mas praktikal; real-world na mga setting | Nakakalito na mga variable |
| **Pre-test / post-test** | Sukatin bago at pagkatapos ng interbensyon | Nagbabago ang mga palabas sa paglipas ng panahon | Walang kontrol para sa mga panlabas na salik |
| **Factorial design** | Maramihang mga independiyenteng variable na manipulahin nang sabay-sabay | Sinusuri ang mga pakikipag-ugnayan sa pagitan ng mga variable | Kumplikado; malaking sample ang kailangan |
| **Sa loob ng mga paksa** | Parehong kalahok sa lahat ng kundisyon | Kinokontrol ang mga indibidwal na pagkakaiba; mas kaunting mga kalahok | Mga epekto ng order; carryover |
| **Sa pagitan ng mga paksa** | Iba't ibang kalahok sa bawat kondisyon | Walang carryover effect | Mga indibidwal na pagkakaiba; kailangan ng higit pang mga kalahok |
### Mga Paraan ng Sampling
| Paraan | Uri | Paglalarawan | Kailan Gagamitin |
|--------|------|-------------|-------------|
| **Simpleng random** | Probability | Ang bawat miyembro ay may pantay na pagkakataon ng pagpili | Pamantayan ng ginto; nangangailangan ng kumpletong sampling frame |
| **Stratified random** | Probability | Hatiin sa strata; random na sample mula sa bawat | Tiyaking representasyon ng mga subgroup |
| **Cluster** | Probability | Random na pumili ng mga grupo; survey lahat sa loob ng | Malaking populasyon; cost-effective na |
| **Kaginhawahan** | Non-probability | Sample kung sino ang available | Mabilis; mura; ngunit may kinikilingan |
| **Layunin** | Non-probability | Sadyang pumili ng mga partikular na kaso | Mga opinyon ng eksperto; mga tiyak na katangian |
| **Snowball** | Non-probability | Ang mga kasalukuyang kalahok ay nagre-recruit ng iba | Mga populasyon na mahirap abutin |
### Pagsusuri sa Istatistika
| Uri ng Pagsusuri | Layunin | Halimbawa |
|--------------|---------|---------|
| **Mga deskriptibong istatistika** | Ibuod ang data | ibig sabihin; panggitna; karaniwang paglihis; mga pamamahagi ng dalas |
| **Inferential statistics** | Gumawa ng mga konklusyon tungkol sa isang populasyon mula sa isang sample | t-pagsusulit; ANOVA; chi-squared; pagbabalik |
| **Kaugnayan** | Sukatin ang kaugnayan sa pagitan ng mga variable | Pearson's r; Spearman's rho |
| **Regression** | Modelong ugnayan sa pagitan ng dependent at independent variable | Linear regression; logistic regression |
| **Factor analysis** | Tukuyin ang mga pinagbabatayan na dimensyon sa data | PCA; pagsusuri sa kadahilanan ng eksplorasyon |
| **Meta-analysis** | Pagsamahin ang mga resulta mula sa maraming pag-aaral | Systematic na pagsusuri ng mga epekto ng paggamot |

## Kwalitatibong Pananaliksik
### Mga Paraan
| Paraan | Paglalarawan | Pinakamahusay Para sa |
|--------|-------------|----------|
| **Mga Panayam** (semi-structured) | Mga bukas na tanong; pagsisiyasat | Malalim na pag-unawa sa mga karanasan; kahulugan |
| **Mga focus group** | Pangkatang talakayan na ginagabayan ng isang moderator | Paggalugad ng mga pamantayan ng grupo; pagbuo ng mga ideya |
| **Etnograpiya** | Immersive na pagmamasid sa natural na setting | Pag-unawa sa mga kultura; mga gawi sa lipunan |
| **Pag-aaral ng kaso** | Malalim na imbestigasyon ng isang kaso o maliit na bilang | Mga kumplikadong phenomena sa konteksto |
| **Grounded theory** | Bumuo ng teorya mula sa data sa pamamagitan ng iterative coding | Kapag hindi sapat ang umiiral na teorya |
| **Pagsusuri ng nilalaman** | Systematic coding ng text/media | Malaking volume ng teksto; pagsusuri ng media |
| **Pagsusuri sa diskurso** | Pag-aaral ng wikang ginagamit; relasyon sa kapangyarihan | Paano binubuo ng wika ang katotohanan |
| **Phenomenology** | Pag-unawa sa buhay na karanasan | Paano nararanasan ng mga tao ang isang kababalaghan |
### Pagtitiyak ng Kalidad sa Kwalitatibong Pananaliksik
| Pamantayan | Paglalarawan | Paano Makamit |
|-----------|-------------|----------------|
| **Credibility** (panloob na bisa) | Ang mga natuklasan ay tumpak na kumakatawan sa mga pananaw ng mga kalahok | Triangulation; pagsusuri ng miyembro; matagal na pakikipag-ugnayan |
| **Transferability** (external validity) | Naaangkop ang mga natuklasan sa ibang konteksto | Makapal na paglalarawan; may layuning sampling |
| **Pagiging maaasahan** (pagkakatiwalaan) | Ang mga natuklasan ay pare-pareho kung ang pag-aaral ay inuulit | Audit trail; pagtatalumpati ng kasamahan |
| **Pagkukumpirma** (objectivity) | Ang mga natuklasan ay nag-ugat sa data, hindi bias ng mananaliksik | Reflexivity; triangulation; audit trail |

## Mixed Methods
| Disenyo | Paglalarawan | Kailan Gagamitin |
|--------|-------------|-------------|
| **Convergent parallel** | Mangolekta ng quantitative at qualitative data nang sabay-sabay; ihambing | Kapag gusto mo ang parehong lapad at lalim |
| **Paliwanag na sunud-sunod** | quantitative muna; husay upang ipaliwanag ang mga resulta | Kapag ang mga resulta ng survey ay nangangailangan ng mas malalim na pag-unawa |
| **Pagkasunod-sunod ng paggalugad** | Qualitative muna; dami sa mga natuklasan sa pagsubok | Kapag kailangan mo munang bumuo ng mga instrumento o teorya |

## Bisa at Maaasahan
### Mga Banta sa Bisa
| Banta | Paglalarawan | Pagbabawas |
|--------|-------------|------------|
| **Pagkiling sa pagpili** | Ang mga pangkat ay sistematikong naiiba bago ang interbensyon | Random na pagtatalaga; tumutugma sa |
| **Attrition bias** | Ang mga kalahok ay nag-drop out nang hindi random | Subaybayan ang mga dahilan; intention-to-treat analysis |
| **Epekto ng Hawthorne** | Nagbabago ang mga tao ng pag-uugali dahil sila ay inoobserbahan | Mga pangkat ng kontrol; nagbubulag-bulagan |
| **Mga katangian ng demand** | Hulaan ng mga kalahok ang hypothesis at kumilos nang naaayon | Panlilinlang; pabalat ng mga kwento |
| **Pagkiling ng eksperimento** | Ang mga inaasahan ng mananaliksik ay nakakaimpluwensya sa mga resulta | Pagbubulag; pamantayang pamamaraan |
| **Nalilito** | Ipinapaliwanag ng ikatlong variable ang kaugnayan | Kontrolin ang mga variable; randomization; pagsasaayos ng istatistika |
| **P-hacking** | Pagsubok sa maraming hypotheses hanggang ang isa ay makabuluhan | Pre-registration; pagwawasto para sa maramihang paghahambing |
### Mga Panukalang Maaasahan
| Sukatin | Paglalarawan |
|---------|-------------|
| **Pagsubok-muling pagsubok** | Parehong pagsubok na pinangangasiwaan ng dalawang beses; ugnayan sa pagitan ng mga marka |
| **Inter-rater** | Kasunduan sa pagitan ng iba't ibang rater / coder |
| **Internal na pagkakapare-pareho** | alpha ni Cronbach; mga item na sumusukat sa parehong construct |
| **Mga parallel form** | Kaugnayan sa pagitan ng iba't ibang bersyon ng parehong pagsubok |

## Etika ng Pananaliksik
| Prinsipyo | Paglalarawan |
|-----------|-------------|
| **Informed consent** | Naiintindihan ng mga kalahok kung ano ang kanilang sinasang-ayunan; boluntaryong paglahok |
| **Beneficence** | I-maximize ang mga benepisyo; bawasan ang pinsala |
| **Di-maleficence** | Huwag saktan — pisikal, sikolohikal, panlipunan |
| **Hustisya** | Makatarungang pamamahagi ng mga benepisyo at pasanin; huwag pagsamantalahan ang mga mahihinang populasyon |
| **Privacy at confidentiality** | Protektahan ang data ng mga kalahok; anonymise kung saan posible |
| **Karapatang mag-withdraw** | Ang mga kalahok ay maaaring umalis sa pag-aaral anumang oras nang walang parusa |
| **Debriefing** | Ipaliwanag ang layunin ng pag-aaral pagkatapos ng pakikilahok; lalo na kung panlilinlang ang ginamit |
---

## Buod
Ang pamamaraan ng pananaliksik ay ang balangkas na tumutukoy kung ang iyong mga natuklasan ay mapagkakatiwalaan. Ang mga quantitative na pamamaraan (mga eksperimento, survey, statistical analysis) ay pinakamainam para sa pagsubok ng mga hypotheses at pagsukat ng mga epekto. Ang mga pamamaraan ng husay (panayam, etnograpiya, pag-aaral ng kaso) ay pinakamainam para sa pag-unawa sa kahulugan, konteksto, at karanasan. Pinagsasama-sama ang mga pinaghalong pamamaraan para sa lapad at lalim. Ang siyentipikong pamamaraan ay nagbibigay ng isang nakabalangkas na proseso mula sa pagmamasid sa pamamagitan ng hypothesis, pagkolekta ng data, pagsusuri, at pagsusuri ng mga kasamahan. Ang pagiging wasto (sinusukat mo ba kung ano sa tingin mo ang iyong sinusukat?) at pagiging maaasahan (makakakuha ka ba ng parehong mga resulta muli?) ay ang pangunahing pamantayan sa kalidad. Tinitiyak ng etika ng pananaliksik na ang paghahanap ng kaalaman ay hindi nagdudulot ng pinsala sa mga karapatan at kapakanan ng mga kalahok. Ang pinakamahalagang prinsipyo ay ang pamamaraan ay nagsisilbi sa tanong sa pananaliksik — piliin ang diskarte na pinakamahusay na sumasagot sa iyong tanong, hindi ang isa na pinakapamilyar o pinakamadaling.
