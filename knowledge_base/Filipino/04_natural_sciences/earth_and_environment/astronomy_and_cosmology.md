# Astronomy at Cosmology
Ang Astronomy ay ang pag-aaral ng mga celestial na bagay — mga bituin, planeta, kalawakan, at lahat ng bagay na lampas sa kapaligiran ng Earth. Ang kosmolohiya ay ang pag-aaral ng sansinukob sa kabuuan: ang pinagmulan, istraktura, ebolusyon, at huling kapalaran. Sama-sama, tinutugunan nila ang ilan sa mga pinakapangunahing tanong na itinanong ng mga tao: Paano nagsimula ang uniberso? Gaano ito kalaki? tayo lang ba? Ano ang mangyayari dito sa huli?

## Mga bituin
### Stellar Lifecycle
| Yugto | Paglalarawan | Tagal |
|-------|-------------|----------|
| **Molecular cloud** | Malamig, siksik na gas at alikabok; nagsimulang gumuho ang gravity ng mga rehiyon | Milyun-milyong taon |
| **Protostar** | Ang pagbagsak ng core ay umiinit; hindi pa nagsasama ng hydrogen | ~100,000 taon |
| **Pangunahing pagkakasunud-sunod** | Hydrogen fusion sa core; matatag; kung saan ang ating Araw ngayon | ~10 bilyong taon (tulad ng Araw) |
| **Pulang higante** | Naubos ang core hydrogen; lumalawak at lumalamig ang mga panlabas na layer | ~1 bilyong taon |
| **Planetary nebula / supernova** | Na-eject ang mga panlabas na layer (mababa ang masa) o nag-collapse ng core (mataas na masa) | Mga araw hanggang libu-libong taon |
| **Labi** | White dwarf, neutron star, o black hole | Bilyong taon o mas matagal |

## Kosmolohiya
### Ang Big Bang Theory
| Katibayan | Paglalarawan |
|----------|-------------|
| **Cosmic Microwave Background (CMB)** | Afterglow ng Big Bang; 2.725 K; uniporme sa lahat ng direksyon; maliliit na pagbabagu-bago seeded galaxies |
| **Pagpapalawak ng Hubble** | Ang mga kalawakan ay umuurong mula sa atin; mas malayo, mas mabilis — ang espasyo mismo ay lumalawak |
| **Kasaganaan ng mga light elements** | Hinulaan ng Big Bang nucleosynthesis ang mga naobserbahang ratio ng hydrogen, helium, at lithium |
| **Malaking istraktura** | Ang pamamahagi ng mga kalawakan ay tumutugma sa mga hula mula sa mga paunang pagbabagu-bago ng density |
### Timeline ng Uniberso
| Oras Pagkatapos ng Big Bang | Kaganapan |
|---------------------|-------|
| **10^-43 segundo** | Panahon ng Planck; lahat ng pwersa ay nagkakaisa; physics tulad ng alam namin ito break down |
| **10^-36 segundo** | Nagsisimula ang inflation; universe exponentially exponentially |
| **10^-12 segundo** | Electroweak symmetry break; Ang field ng Higgs ay nagbibigay ng mass ng mga particle |
| **10^-6 na segundo** | Ang mga quark ay pinagsama sa mga proton at neutron |
| **3 minuto** | Big Bang nucleosynthesis; unang atomic nuclei (H, He, Li) |
| **380,000 taon** | Recombination; nabuo ang mga atomo; Inilabas ang CMB; universe nagiging transparent |
| **100–200 milyong taon** | Nag-aapoy ang mga unang bituin (Population III star) |
| **1 bilyong taon** | Nabuo ang mga unang kalawakan |
| **9.2 bilyong taon** | Mga anyo ng solar system |
| **13.8 bilyong taon** | Ngayon |
### Madilim na Bagay at Madilim na Enerhiya
| Bahagi | Proporsyon | Katibayan | Kalikasan |
|-----------|-----------|----------|--------|
| **Ordinaryong bagay** | ~5% | Nakikita; naglalabas/sumisipsip ng liwanag | Naiintindihan ng mabuti (mga atomo, mga particle) |
| **Madilim na bagay** | ~27% | Mga kurba ng pag-ikot ng kalawakan; gravitational lensing; Mga pattern ng CMB | Hindi nakikipag-ugnayan sa liwanag; nakita lamang sa pamamagitan ng gravity |
| **Madilim na enerhiya** | ~68% | Pagpapabilis ng paglawak ng uniberso (Type Ia supernovae) | Hindi alam; posibleng cosmological constant (vacuum energy) |

## Exoplanets at ang Paghahanap ng Buhay
### Mga Paraan ng Pagtuklas
| Paraan | Paano Ito Gumagana | Mga Lakas |
|--------|-------------|-----------|
| **Pagsakay** | Ang planeta ay dumadaan sa harap ng bituin; bahagyang lumabo ang bituin | Pinaka produktibong pamamaraan (Kepler, TESS); nagbibigay ng laki at orbital period |
| **Radial na bilis** | Ang gravity ng planeta ay nagiging sanhi ng pag-urong ng bituin; Doppler shift sa liwanag ng bituin | Nagbibigay ng masa; gumagana para sa napakalaking planeta na malapit sa bituin |
| **Direktang imaging** | Harangan ang liwanag ng bituin; direktang kunan ng larawan ang planeta | Gumagana para sa malalaking planeta na malayo sa bituin |
| **Gravitational microlensing** | Ang gravity ng planeta ay nagbaluktot ng liwanag mula sa isang background star | Nakikita ang mga planeta sa malalayong distansya; mga bihirang kaganapan |
| **Astrometry** | Sukatin ang tumpak na posisyon ng bituin; tuklasin ang pag-uurong | Komplementaryo sa radial velocity |
### Ang Habitable Zone
| Salik | Kinakailangan |
|--------|--------------|
| **Distansya mula sa bituin** | Hindi masyadong mainit; hindi masyadong malamig; likidong tubig na posible sa ibabaw |
| **Uri ng bituin** | Matatag; matagal na buhay (G, K, M dwarf preferred) |
| **Planet mass** | Sapat na gravity upang hawakan ang isang kapaligiran; hindi masyadong malaki para maging isang higanteng gas |
| **Atmosphere** | Greenhouse effect upang mapanatili ang temperatura sa ibabaw; proteksyon mula sa radiation |
| **Magnetic field** | Pinapalihis ang stellar wind; pinoprotektahan ang kapaligiran |

## Buod
Pinag-aaralan ng astronomy at kosmolohiya ang lahat mula sa mga planeta hanggang sa buong uniberso. Ang mga bituin ay ipinanganak sa molekular na ulap, gumugugol ng bilyun-bilyong taon sa pagsasanib ng hydrogen, at nagtatapos bilang mga white dwarf, neutron star, o black hole. Ang mga kalawakan — spiral, elliptical, irregular — ay ang mga bloke ng gusali ng malakihang istruktura ng uniberso. Ang teorya ng Big Bang, na sinusuportahan ng CMB, pagpapalawak ng Hubble, at kasaganaan ng light element, ay naglalarawan sa isang uniberso na nagsimula 13.8 bilyong taon na ang nakalilipas at binubuo ng ~5% ordinaryong bagay, ~27% dark matter, at ~68% dark energy. Ipinakita ng mga pagtuklas sa Exoplanet na karaniwan ang mga planeta, at nagpapatuloy ang paghahanap ng mga mundong matitirhan. Ang pangkalahatang aral ay kung gaano karami ang hindi natin alam: ang dark matter at dark energy na magkasama ay bumubuo sa 95% ng uniberso, at hindi pa rin natin alam kung ano ang alinman sa mga ito.
