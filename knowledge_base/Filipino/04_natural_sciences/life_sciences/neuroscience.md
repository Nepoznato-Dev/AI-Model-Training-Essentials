# Neuroscience
Ang neuroscience ay ang pag-aaral ng nervous system — ang utak, spinal cord, at lahat ng nerves na nag-uugnay sa kanila sa katawan. Ito ay sumasaklaw sa maraming antas: mula sa mga molekula at gene, sa mga indibidwal na neuron at synapses, sa mga circuit at rehiyon ng utak, sa pag-uugali, katalusan, at kamalayan. Ang utak ay ang pinaka-kumplikadong istraktura sa kilalang uniberso, na naglalaman ng humigit-kumulang 86 bilyong neuron na konektado ng trilyong synapses, at ang pag-unawa kung paano ito gumagana ay isa sa mga malalaking hamon ng agham.
---

## Ang Neuron
### Mga Bahagi ng isang Neuron
| Bahagi | Function |
|-----------|----------|
| **Dendrites** | Tumanggap ng mga signal mula sa iba pang mga neuron; mga extension na parang sangay |
| **Katawan ng cell (soma)** | Pinagsasama ang mga papasok na signal; naglalaman ng nucleus |
| **Axon** | Mahabang hibla na nagpapadala ng mga de-koryenteng signal (mga potensyal na pagkilos) palayo sa soma |
| **Myelin sheath** | Insulating layer sa paligid ng axons; pinapabilis ang paghahatid ng signal |
| **Mga Node ng Ranvier** | Mga puwang sa myelin; payagan ang saltatory conduction (signal jumps between nodes) |
| **Axon terminals (synaptic boutons)** | Ilabas ang mga neurotransmitter sa synapse |
### Mga Uri ng Neurons
| Uri | Direksyon | Function |
|------|-----------|----------|
| **Sensory (afferent)** | Katawan → utak | Magdala ng impormasyon mula sa mga pandama (paghawak, temperatura, sakit, paningin, atbp.) |
| **Motor (efferent)** | Utak → katawan | Kontrolin ang mga kalamnan at glandula |
| **Mga Interneuron** | Sa loob ng CNS | Ikonekta ang mga neuron sa iba pang mga neuron; karamihan sa mga neuron ay mga interneuron |

## Paano Nakikipag-usap ang mga Neuron
### Ang Potensyal ng Pagkilos
| Yugto | Paglalarawan |
|-------|-------------|
| **Potensyal sa pagpapahinga** | Ang neuron ay nasa ~-70 mV; ang sodium-potassium pump ay nagpapanatili ng balanse ng ion |
| **Depolarisasyon** | Ang stimulus ay nagbubukas ng mga channel ng sodium; Nagmamadali ang Na+; tumataas ang potensyal ng lamad |
| **Threshold** | Kung ang potensyal ay umabot sa ~-55 mV, ang isang potensyal na pagkilos ay sunog (all-or-nothing) |
| **Rising phase** | Ang mga channel ng sodium na may boltahe ay bukas; mga potensyal na spike sa ~+40 mV |
| **Falling phase** | Isara ang mga channel ng sodium; bukas ang mga channel ng potasa; Ang K+ ay dumadaloy palabas; potensyal na pagbaba |
| **Undershoot (hyperpolarization)** | Ang potensyal ay panandaliang bumaba sa ibaba ng antas ng pahinga |
| **Panahon ng repraktoryo** | Neuron ay hindi maaaring magpaputok muli kaagad; tinitiyak ang one-directional propagation |
### Ang Synapse
| Bahagi | Tungkulin |
|-----------|------|
| **Presynaptic neuron** | Nagpapadala ng signal; naglalaman ng mga synaptic vesicle na may mga neurotransmitter |
| **Synaptic cleft** | Maliit na agwat (~20 nm) sa pagitan ng mga neuron |
| **Possynaptic neuron** | Tumatanggap ng signal; ay may mga receptor na protina |
| **Mga Neurotransmitter** | Mga kemikal na mensahero na tumatawid sa synapse |
| **Mga Receptor** | Magbigkis ng mga neurotransmitter; magbukas ng mga channel ng ion o mag-trigger ng mga second messenger cascades |

## Mga Pangunahing Neurotransmitter
| Neurotransmitter | Function | Mga Kaugnay na Kundisyon |
|-----------------|----------|---------------------|
| **Glutamate** | Pangunahing excitatory neurotransmitter; pag-aaral; memorya | Sobra → excitotoxicity (stroke, neurodegeneration) |
| **GABA** | Pangunahing nagbabawal na neurotransmitter; binabawasan ang aktibidad ng neural | Depisit → pagkabalisa, epilepsy |
| **Dopamine** | Gantimpala; pagganyak; kontrol ng motor; pansin | Depisit → Parkinson's; labis → schizophrenia |
| **Serotonin** | Mood; matulog; gana sa pagkain; pantunaw | Depisit → depresyon, pagkabalisa |
| **Acetylcholine** | Pag-activate ng kalamnan; pag-aaral; memorya | Depisit → Alzheimer's disease |
| **Norepinephrine** | Pagpukaw; pagkaalerto; tugon ng stress | Dysregulation → ADHD; depresyon |
| **Endorphin** | Pananakit; kasiyahan | Exercise-induced release ("runner's high") |

## Istraktura ng Utak
### Mga Pangunahing Rehiyon ng Utak
| Rehiyon | Function |
|--------|----------|
| **Cerebral cortex** | Mas mataas na katalusan; nahahati sa frontal, parietal, temporal, occipital lobes |
| **frontal lobe** | Pagpaplano; paggawa ng desisyon; personalidad; boluntaryong paggalaw (motor cortex) |
| **Parietal lobe** | Pagproseso ng pandama; spatial na kamalayan; nabigasyon |
| **Temporal na lobe** | Pagdinig; pag-unawa sa wika; memorya (hippocampus) |
| **Occipital lobe** | Visual na pagproseso |
| **Cerebellum** | Koordinasyon ng motor; balanse; pag-aaral ng motor; ilang mga nagbibigay-malay na function |
| **Brainstem** | Mga mahahalagang tungkulin: paghinga; rate ng puso; sleep-wake cycle |
| **Thalamus** | istasyon ng sensory relay; mga ruta ng signal sa naaangkop na cortical area |
| **Hypothalamus** | Homeostasis; regulasyon ng hormone; gutom; pagkauhaw; circadian rhythms |
### Ang Limbic System
| Istraktura | Function |
|-----------|----------|
| **Amygdala** | Pagproseso ng emosyonal; takot; pagtuklas ng pagbabanta; emosyonal na memorya |
| **Hippocampus** | Pagbuo ng memorya; spatial nabigasyon; nagko-convert ng panandalian sa pangmatagalang memorya |
| **Basal ganglia** | Pagbuo ng ugali; gantimpala sa pag-aaral; kontrol ng motor |
| **Cingulate cortex** | Pagtuklas ng error; empatiya; kontrol ng salpok; regulasyon ng emosyon |
| **Nucleus accumbens** | Gantimpala circuit; kasiyahan; pagkagumon |

## Neuroplasticity
| Uri | Paglalarawan | Halimbawa |
|------|-------------|---------|
| **Synaptic plasticity** | Ang lakas ng mga synapses ay nagbabago sa aktibidad | Pangmatagalang potentiation (LTP); pangmatagalang depresyon (LTD) |
| **Kaplastikan sa istruktura** | Ang mga neuron ay lumalaki ng mga bagong dendrite o axon | Pag-aaral ng mga bagong kasanayan; pagbawi mula sa pinsala |
| **Cortical remapping** | Ang mga rehiyon ng utak ay muling nagtalaga ng mga function | Pinoproseso ng visual cortex ng mga bulag ang touch at sound |
| **Neurogenesis** | Ang mga bagong neuron ay ipinanganak | Nangyayari sa hippocampus; pinasigla ng ehersisyo at pag-aaral |

## Paraan ng Pananaliksik
| Paraan | Ang Sinusukat Nito | Resolusyon |
|--------|-----------------|------------|
| **fMRI** | Antas ng oxygen sa dugo (BOLD signal) → aktibidad ng utak | Magandang spatial (~1 mm); mahinang temporal (~1 s) |
| **EEG** | Aktibidad na elektrikal mula sa anit | Napakahusay na temporal (~1 ms); mahinang spatial |
| **MEG** | Magnetic field mula sa aktibidad ng neural | Magandang temporal at spatial |
| **PET** | Radioactive tracer → metabolic activity | Katamtamang spatial at temporal |
| **TMS** | Magnetic pulses → pansamantalang nakakagambala sa lugar ng utak | Katibayan ng sanhi; limitadong lalim |
| **Pagre-record ng isang unit** | Aktibidad ng elektrikal ng mga indibidwal na neuron | Isang cell; nagsasalakay; karamihan ay pananaliksik sa hayop |
| **Optogenetics** | Light-activated neurons | Tumpak na kontrol; pananaliksik sa hayop |
| **DTI** (Diffusion Tensor Imaging) | White matter tracts | Pagmamapa ng pagkakakonekta |

## Mga Neurological at Psychiatric Disorder
| Disorder | Apektadong System | Mga Pangunahing Tampok |
|----------|----------------|--------------|
| **Alzheimer's** | Cortex; hippocampus | Pagkawala ng memorya; amyloid plaques; tau gusot |
| **Parkinson's** | Substantia nigra; basal ganglia | Panginginig; tigas; pagkawala ng dopamine neuron |
| **Epilepsy** | Cerebral cortex | Paulit-ulit na mga seizure; abnormal na aktibidad ng kuryente |
| **Multiple sclerosis** | Myelin sheath (CNS) | Demyelination; nagambalang paghahatid ng signal |
| **Depresyon** | Prefrontal cortex; limbic system | Patuloy na mababang mood; neurotransmitter imbalance |
| **Schizophrenia** | Maramihang mga rehiyon | Hallucinations; mga maling akala; dopamine dysregulation |
| **ALS** | Mga neuron ng motor | Progresibong kahinaan ng kalamnan; pagkamatay ng motor neuron |

## Buod
Pinag-aaralan ng neuroscience ang sistema ng nerbiyos sa bawat antas — mula sa mga mekanismo ng molekular ng mga channel ng ion hanggang sa pansariling karanasan ng kamalayan. Ang mga neuron ay nakikipag-usap sa pamamagitan ng mga potensyal na pagkilos ng kuryente at mga kemikal na synapses, gamit ang mga neurotransmitter tulad ng glutamate, GABA, dopamine, at serotonin. Ang utak ay isinaayos sa mga dalubhasang rehiyon: ang cortex para sa mas mataas na katalusan, ang limbic system para sa emosyon at memorya, ang cerebellum para sa koordinasyon. Ang neuroplasticity ay nangangahulugan na ang utak ay maaaring i-rewire ang sarili sa buong buhay. Ang mga pamamaraan ng pananaliksik ay mula sa fMRI (magandang spatial na resolusyon) hanggang sa EEG (magandang temporal na resolusyon) hanggang sa optogenetics (tumpak na kontrol sa sanhi). Ang pag-unawa sa utak ay maaaring ang pinakamahirap na problema sa agham — ito ang tanging organ na nag-aaral sa sarili nito.
