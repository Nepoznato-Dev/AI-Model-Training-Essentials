# Intellectual Property at Innovation
Ang intelektwal na ari-arian (IP) ay tumutukoy sa mga likha ng isip — mga imbensyon, masining na gawa, mga pangalan ng tatak, disenyo, mga lihim ng kalakalan — na pinoprotektahan ng batas mula sa hindi awtorisadong paggamit. Ang inobasyon ay ang proseso ng paggawa ng mga ideya sa halaga. Umiiral ang batas ng IP upang balansehin ang dalawang magkatunggaling interes: nagbibigay-kasiyahan sa mga tagalikha (sa pamamagitan ng pagbibigay sa kanila ng mga pansamantalang monopolyo) at pakikinabang sa lipunan (sa pamamagitan ng pagtiyak na ang kaalaman ay magiging malayang magagamit). Ang pag-unawa sa IP ay mahalaga para sa sinumang gumagawa ng mga produkto, paglikha ng nilalaman, pagpapatakbo ng isang negosyo, o pagtatrabaho sa pananaliksik.
---

## Mga Uri ng Intelektwal na Ari-arian
### Pangkalahatang-ideya
| Uri | Ano ang Pinoprotektahan Nito | Tagal | Paano Nakuha | Halimbawa |
|------|-----------------|----------|-------------|---------|
| **Patent** | Mga imbensyon (mga proseso, makina, komposisyon) | 20 taon mula sa pag-file | Application; pagsusuri; bigyan | Isang bagong tambalang gamot; isang proseso ng pagmamanupaktura |
| **Copyright** | Mga orihinal na gawa ng may-akda | Buhay + 70 taon (karamihan ng mga bansa) | Awtomatiko sa paggawa | Mga aklat; musika; software code; mga pelikula |
| **Trademark** | Mga identifier ng brand (mga pangalan, logo, slogan) | Hindi tiyak (kung ginamit at na-renew) | Gamitin sa komersiyo; pinapalakas ang pagpaparehistro | Pangalan ng "Nike" at logo ng swoosh |
| **Trade secret** | Kumpidensyal na impormasyon ng negosyo | Hindi tiyak (basta sikreto) | Walang pagpaparehistro; dapat gumawa ng mga makatwirang hakbang upang panatilihing lihim | Formula ng Coca-Cola; Algoritmo ng paghahanap sa Google |
| **Disenyong pang-industriya** | Visual na hitsura ng isang produkto | 15–25 taon (nag-iiba-iba) | Pagpaparehistro | Hugis ng isang smartphone; disenyo ng muwebles |
| **Heograpikal na indikasyon** | Mga produktong may partikular na heograpikal na pinagmulan | Walang Katiyakan | Pagpaparehistro; naka-link sa rehiyon | Champagne; Parmigiano-Reggiano; Darjeeling tea |

## Mga patent
### Mga Kinakailangan sa Patent
| Kinakailangan | Paglalarawan |
|-------------|-------------|
| **Kabago-bago** | Ang imbensyon ay dapat na bago; hindi isiniwalat dati kahit saan sa mundo |
| **Di-halata (imbentong hakbang)** | Ang imbensyon ay hindi dapat halata sa isang taong may kasanayan sa nauugnay na larangan |
| **Utility (industrial applicability)** | Ang imbensyon ay dapat may tiyak, praktikal na gamit |
| **Pagiging karapat-dapat sa paksa** | Dapat ay isang proseso, makina, paggawa, o komposisyon ng bagay; ang mga abstract na ideya, batas ng kalikasan, at natural na phenomena ay hindi patentable |
### Mga Uri ng Patent
| Uri | Paglalarawan | Termino |
|------|-------------|------|
| **Utility patent** | Pinoprotektahan ang paggana ng isang imbensyon | 20 taon mula sa pag-file |
| **Patent ng disenyo** | Pinoprotektahan ang ornamental na disenyo ng isang functional na item | 15 taon mula sa grant (US) |
| **Patent ng halaman** | Pinoprotektahan ang mga bagong uri ng halaman (asexually reproduced) | 20 taon mula sa pag-file |
### Proseso ng Patent
| Hakbang | Paglalarawan | Timeline |
|------|-------------|----------|
| **1. Naunang paghahanap ng sining** | Maghanap ng mga umiiral na patent at publikasyon upang suriin ang bago | Linggo hanggang buwan |
| **2. Draft application** | Sumulat ng mga claim (tukuyin ang saklaw ng proteksyon) at paglalarawan | Linggo hanggang buwan |
| **3. File application** | Isumite sa opisina ng patent (USPTO, EPO, atbp.) | Araw ng paghahain = priority date |
| **4. Pagsusuri** | Mga review ng patent examiner para sa bago, hindi halata, utility | 1–5 taon |
| **5. Mga aksyon sa opisina** | Maaaring tanggihan ng tagasuri; ang aplikante ay nakikipagtalo o nagsususog sa mga claim | Balik-balik na negosasyon |
| **6. Grant** | Kung pinapayagan, ang patent ay ipinagkaloob; kailangan ang mga bayarin sa pagpapanatili | Pana-panahong mga bayarin upang manatiling buhay |

## Copyright
### Ano ang Pinoprotektahan ng Copyright
| Pinoprotektahan | Hindi Pinoprotektahan |
|-----------|----------------|
| Mga akdang pampanitikan (aklat, artikulo, code) | Mga ideya; katotohanan; mga sistema |
| Mga gawang pangmusika (melody, lyrics) | Mga Pamagat; mga pangalan; maikling parirala |
| Mga masining na gawa (pinta, larawan, disenyo) | Paraan ng pagpapatakbo |
| Software code (tulad ng nakasulat) | Ang function ng algorithm (maaaring patentable) |
| Mga pelikula; Mga palabas sa TV; mga video | Mga Estilo; mga diskarte |
| Mga disenyong arkitektura | Mga functional na aspeto ng mga gusali |
### Mga Pangunahing Konsepto sa Copyright
| Konsepto | Paglalarawan |
|---------|-------------|
| **Pag-aayos** | Ang copyright ay umiiral kapag ang gawa ay naayos sa isang tangible medium (nakasulat, naitala) |
| **Awtomatikong proteksyon** | Walang kinakailangang pagpaparehistro (ngunit ang pagpaparehistro ay nagbibigay-daan sa mga pinsala ayon sa batas sa US) |
| **Patas na paggamit / patas na pakikitungo** | Limitadong paggamit nang walang pahintulot para sa pagpuna, komentaryo, edukasyon, parody |
| **Creative Commons** | Mga standardized na lisensya na nagpapahintulot sa iba't ibang antas ng muling paggamit |
| **Pampublikong domain** | Mga gawang hindi protektado ng copyright (nag-expire, isinusuko, o hindi karapat-dapat) |
| **Trabaho para inupahan** | Ang mga gawang ginawa ng mga empleyado sa loob ng kanilang saklaw ng trabaho ay pagmamay-ari ng employer |

## Mga trademark
### Mga Pangunahing Kaalaman sa Trademark
| Aspeto | Paglalarawan |
|--------|--------------|
| **Layunin** | Tukuyin ang pinagmulan ng mga kalakal/serbisyo; maiwasan ang pagkalito ng mamimili |
| **Katangian spectrum** | Fanciful (pinakamalakas) → Arbitrary → Suggestive → Descriptive (mahina) → Generic (hindi mapoprotektahan) |
| **Pagpaparehistro** | Hindi kinakailangan (mga karapatan ng karaniwang batas mula sa paggamit) ngunit nagbibigay ng makabuluhang legal na mga bentahe |
| **Mga Klase** | Mga kalakal/serbisyo na inuri sa 45 na klase (Nice Classification) |
| **Pagpapanatili** | Dapat gamitin sa komersiyo; pana-panahong na-renew ang pagpaparehistro |
| **Paglabag** | Ang hindi awtorisadong paggamit ay malamang na magdulot ng kalituhan |
### Katangian ng Trademark
| Kategorya | Paglalarawan | Protektahan | Halimbawa |
|----------|-------------|--------------|---------|
| **Kahanga-hanga** | Nag-imbento ng mga salita na walang kahulugan sa labas ng tatak | Pinakamalakas | "Kodak"; "Xerox" |
| **Arbitrary** | Mga totoong salita na ginamit na walang kaugnayan sa produkto | Napakalakas | "Apple" para sa mga computer |
| **Nagmumungkahi** | Mga pahiwatig sa likas na katangian ng produkto | Malakas | "Netflix" (internet flicks) |
| **Naglalarawan** | Inilalarawan ang produkto | mahina; nangangailangan ng pangalawang kahulugan | "Holiday Inn" |
| **Generic** | Ang karaniwang pangalan ng produkto | Hindi mapoprotektahan | "Aspirin" (dati ay isang trademark) |

## Trade Secrets
| Aspeto | Paglalarawan |
|--------|--------------|
| **Kahulugan** | Impormasyong may halaga sa ekonomiya mula sa pagiging lihim; ay hindi karaniwang kilala; at napapailalim sa mga makatwirang pagsisikap na mapanatili ang lihim |
| **Mga Halimbawa** | Mga pormula; mga algorithm; mga listahan ng customer; mga proseso ng pagmamanupaktura; mga diskarte sa negosyo |
| **Proteksyon** | Walang pagpaparehistro; nangangailangan ng mga NDA; mga kontrol sa pag-access; batayan na kailangang malaman |
| **Tagal** | Walang katiyakan — hangga't ang sikreto ay pinananatili |
| **Maling paggamit** | Pagkuha sa pamamagitan ng hindi tamang paraan (pagnanakaw, espiya, paglabag sa NDA) |
| **vs Patents** | Walang kinakailangang pagsisiwalat; walang limitasyon sa oras; ngunit walang proteksyon laban sa independiyenteng pagtuklas o reverse engineering |

## Open Source at Open Innovation
### Mga Lisensya sa Open Source
| Lisensya | Uri | Pangunahing Kinakailangan | Mga Halimbawang Gumagamit |
|---------|------|----------------|----------------|
| **MIT** | Pinahintulutan | Isama ang paunawa sa copyright; walang warranty | jQuery; React |
| **Apache 2.0** | Pinahintulutan | Isama ang paunawa; patent grant | Android; Kubernetes |
| **BSD (2-sugnay)** | Pinahintulutan | Isama ang paunawa sa copyright | FreeBSD |
| **GPL v3** | Copyleft | Ang mga derivative na gawa ay dapat ding GPL | Linux kernel; WordPress |
| **LGPL** | Mahina copyleft | Ang pag-link ay hindi nagti-trigger ng copyleft; ginagawa ng pagbabago | GTK |
| **MPL 2.0** | copyleft sa antas ng file | Dapat na bukas ang mga binagong file; ang mga bagong file ay maaaring pagmamay-ari | Firefox |
| **AGPL** | Malakas na copyleft | Ang paggamit ng network ay nag-trigger ng pagsisiwalat ng pinagmulan | MongoDB (dating) |
### Open Innovation Models
| Modelo | Paglalarawan | Halimbawa |
|-------|-------------|---------|
| **Open source** | Malayang magagamit ang code; mga kontribusyon sa komunidad | Linux; Kubernetes; React |
| **Buksan ang data** | Pampublikong ibinahagi ang data para sa sinumang gumamit ng | Mga dataset ng pamahalaan; datos ng pananaliksik |
| **Buksan ang hardware** | Ang mga disenyo ng hardware ay bukas na ibinahagi | Arduino; Raspberry Pi |
| **Mga patent pool** | Maraming kumpanya ang nagbabahagi ng mga patent sa isang domain | MPEG-LA (mga video codec) |
| **Pre-competitive na pakikipagtulungan** | Nagtutulungan ang mga kakumpitensya sa mga ibinahaging hamon | Semiconductor Research Corporation |

## Diskarte sa IP
### Kailan Gagamitin ang Bawat Uri ng IP
| Sitwasyon | Inirerekomendang IP | Dahilan |
|-----------|----------------|--------|
| **Nobelang imbensyon** | Patent | 20-taong monopolyo; malakas na proteksyon |
| **Algoritmo ng software** | Patent + trade secret | Patent kung patentable; panatilihing lihim ang pagpapatupad |
| **Pangalan / logo ng tatak** | Trademark | Pinoprotektahan ang pagkakakilanlan ng tatak nang walang katapusan |
| **Nakasulat na nilalaman / code** | Copyright | Awtomatiko; pinoprotektahan ang expression |
| **Recipe / formula** | Trade secret | Walang pagsisiwalat; walang tiyak na proteksyon |
| **Disenyo ng produkto** | Design patent + trade dress | Pinoprotektahan ang hitsura |
| **Mabilis na gumagalaw na merkado** | Trade secret + first-mover advantage | Masyadong mahaba ang mga patent; kumilos nang mas mabilis kaysa sa maaaring kopyahin ng mga kakumpitensya |

## Buod
Binabalanse ng batas ng intelektwal na ari-arian ang mga nagbibigay-kasiyahang tagalikha sa lipunang nakikinabang. Pinoprotektahan ng mga patent ang mga imbensyon sa loob ng 20 taon kapalit ng pagsisiwalat sa publiko. Pinoprotektahan ng copyright ang mga orihinal na gawa ng may-akda para sa buhay ng lumikha at 70 taon. Pinoprotektahan ng mga trademark ang mga identifier ng brand nang walang katapusan hangga't ginagamit ang mga ito. Pinoprotektahan ng mga trade secret ang kumpidensyal na impormasyon nang walang hanggan ngunit hindi nag-aalok ng proteksyon laban sa malayang pagtuklas. Ang mga open source na lisensya ay nagbibigay ng alternatibo sa tradisyonal na IP, na nagpapagana ng collaborative development. Ang tamang diskarte sa IP ay nakasalalay sa uri ng paglikha, merkado, bilis ng industriya, at mga layunin ng kumpanya. Ang pag-unawa sa IP ay hindi lamang para sa mga abogado — ito ay mahalaga para sa sinumang gumagawa, nagtatayo, o nagbabago sa isang ekonomiya ng kaalaman.
