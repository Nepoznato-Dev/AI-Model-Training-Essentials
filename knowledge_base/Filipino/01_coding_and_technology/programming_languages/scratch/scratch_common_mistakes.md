# Scratch — Mga Karaniwang Pagkakamali at Anti-Pattern
Kino-catalog ng dokumentong ito ang mga pinakakaraniwang pagkakamali at bitag sa Scratch na may mga pagwawasto.
---

## 1. Hindi Paggamit ng "Stop" para Tapusin ang Mga Script
```
❌ WRONG — script keeps running after game over
when green flag clicked
forever
    if <touching [edge v]?> then
        say [Game Over]
        // script continues!
    end
end

✅ CORRECT — use stop block
when green flag clicked
forever
    if <touching [edge v]?> then
        say [Game Over]
        stop [all v]
    end
end
```

---

## 2. I-clone ang pagkalito
```
❌ WRONG — modifying original sprite thinking it's a clone
when I start as a clone
change [score v] by (1)  // modifies global variable
// but "when green flag clicked" also runs on clones!

✅ CORRECT — separate clone logic from original
when green flag clicked
// setup code only

when I start as a clone
// clone-specific behavior only
```

---

## 3. Oras ng Pag-broadcast
```
❌ WRONG — expecting immediate response
broadcast [jump v]
// code continues immediately, doesn't wait!

✅ CORRECT — use broadcast and wait
broadcast [jump v] and wait
// now waits for all recipients to finish
```

---

## 4. Variable Saklaw
```
❌ WRONG — using global variable when local needed
// All sprites share the variable "my variable"
// Sprite A changes it, Sprite B sees the change

✅ CORRECT — use "For this sprite only"
// Create variable as "For this sprite only"
// Each sprite has its own copy
```

---

## 5. Infinite Loops Nang Walang Yield
```
❌ WRONG — freezes the program
when green flag clicked
forever
    // no wait or visual change
    // locks up the interface
end

✅ CORRECT — add a small wait
when green flag clicked
forever
    // do work
    wait (0.1) seconds
end
```

---

## Buod
Scratch traps: palaging gumamit ng "stop" upang tapusin ang mga laro, paghiwalayin ang clone logic mula sa orihinal na sprite logic, gamitin ang "broadcast at maghintay" para sa sabay-sabay na komunikasyon, gumamit ng mga variable na partikular sa sprite kapag kinakailangan, at magdagdag ng mga paghihintay nang walang hanggan upang maiwasan ang pagyeyelo. Nagtuturo ang scratch ng mga pangunahing konsepto — igalang ang modelong hinimok ng kaganapan.
