# Scratch — Kasaysayan ng Bersyon at Ebolusyon
## Timeline
| Bersyon | Taon | Pangunahing Tema |
|---------|------|-----------|
| Pre-Scratch | 2003 | Mga form ng Scratch Team sa MIT Media Lab |
| Scratch 1.0 | 2007 | **Initial release** — visual programming para sa mga bata |
| Scratch 1.4 | 2009 | Pinahusay na graphics, mas maraming mga bloke |
| Scratch 2.0 | 2013 | **Major**: Web-based na editor, cloud variable, backpack |
| Scratch 3.0 | 2019 | **Major**: Kumpletuhin ang muling pagsulat (HTML5/JS), mga extension, panulat |

## Mga Pangunahing Milestone
### Mga Pinagmulan (2003–2006)
- **2003**: Ang pangkat ng Lifelong Kindergarten ng MIT Media Lab ay nagsimulang mag-develop ng Scratch
- Pinangunahan ni Mitchel Resnick
- **Layunin**: Magturo ng programming sa mga bata sa pamamagitan ng visual blocks
- May inspirasyon ng: Logo (Seymour Papert), Lego Logo, Squeak Etoys
- Pangalan: "Scratch" — mula sa DJ scratching (paghahalo ng media)
### Scratch 1.0 (2007)
- **2007**: Unang pampublikong paglabas
- I-drag-and-drop block programming
- Mga proyektong batay sa Sprite (mga character, animation)
- Tunog, graphics, animation
- Built in Squeak (Smalltalk)
- **Target**: Edad 8-16, ngunit pinagtibay nang mas malawak
### Scratch 1.4 (2009)
- Pinahusay na pag-render ng graphics
- Higit pang mga sprite library
- Mas mahusay na suporta sa tunog
- Huling bersyon na binuo sa Squeak
### Scratch 2.0 (2013)
- **Kumpletong web-based na editor** — tumatakbo sa browser
- Cloud variable — magbahagi ng data sa pagitan ng mga proyekto
- Backpack — magbahagi ng mga sprite/script sa pagitan ng mga proyekto
- Mga custom na bloke (tulad ng mga function)
- Built in ActionScript 3 (Flash)
- Mga tampok ng komunidad: remix, ibahagi, komento
### Scratch 3.0 (2019)
- **Kumpletuhin ang muling pagsulat** — HTML5/JavaScript (walang Flash)
- Gumagana sa mga tablet, telepono, Chromebook
- **Mga Extension**:
  - Panulat (pagguhit)
  - Video Sensing (camera)
  - Text to Speech
  - Isalin (Google Translate)
  - micro:bit (hardware)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Mga pagpapabuti ng sound editor
- Bagong paint editor (vector + bitmap)
- Backpack, cloud variable na pinanatili
### Scratch Desktop & Beyond (2020–kasalukuyan)
- **2020**: Scratch Desktop — offline na editor (Batay sa elektron)
- Patuloy na pagpapaunlad ng extension
- Mga extension ng AI/ML (ginawa ng komunidad)
- Pagsasama sa pisikal na computing (micro:bit, Arduino)

## Itinuro ang Mga Konsepto sa Programming
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Pangunahing Prinsipyo ng Disenyo
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
