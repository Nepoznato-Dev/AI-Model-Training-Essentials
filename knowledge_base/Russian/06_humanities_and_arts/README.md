# Гуманитарные науки и искусство
Структурированная коллекция справочных документов, охватывающих историю, искусство, язык, философию, психологию и религию — основные дисциплины гуманитарных наук, которые обеспечивают контекст для понимания человеческой цивилизации, творческого самовыражения и критического мышления.
