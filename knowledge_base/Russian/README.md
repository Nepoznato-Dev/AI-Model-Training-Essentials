## 📝 Вклад в проект

При добавлении или изменении содержимого:

1. **Следуйте руководству по стилю:**
   - Используйте `#` только для заголовка файла
   - Используйте `##` для основных разделов
   - Используйте `###` для подразделов
   - Используйте `-` для маркированных списков
   - Включайте подсветку синтаксиса в блоках кода

2. **Добавьте метаданные** (блок YAML frontmatter):
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Указывайте источники** для фактических утверждений
4. **Добавляйте перекрёстные ссылки** на связанные файлы
5. **Обновляйте этот README** при добавлении новых файлов
