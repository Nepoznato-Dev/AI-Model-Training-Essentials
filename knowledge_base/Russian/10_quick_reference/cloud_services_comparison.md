# Сравнение облачных сервисов
Параллельное сравнение трех основных поставщиков облачных услуг — AWS, Azure и Google Cloud — по вычислительным ресурсам, хранилищам, базам данных, искусственному интеллекту и машинному обучению, сетям, мониторингу и инфраструктуре как код. Полезно для архитекторов, решающих, какую платформу использовать, или переноса сервисов из одного облака в другое.
---

## Обзор поставщика
| | АВС | Лазурный | Облако Google (GCP) |
|---|-----|-------|---------------------|
| **Доля рынка** | ~31% (самый большой) | ~25% (секунда) | ~11% (третий, самый быстрорастущий) |
| **Сильные стороны** | Широта услуг; зрелость; экосистема | Интеграция предприятия; гибридное облако; стек Microsoft | Данные/ИИ; Кубернетес; глобальная сеть |
| **Лучший вариант** | Стартапы для предприятий; самый широкий каталог услуг | Предприятия с Microsoft/Active Directory; гибрид | Рабочие нагрузки с интенсивным использованием данных; Kubernetes-родной; ИИ/МО |
| **Регионы** | 33 региона, 105 Аз | 60+ регионов | 40+ регионов, 100+ зон |
| **Уровень бесплатного пользования** | 12 месяцев бесплатного пользования + всегда бесплатно | 12 месяцев бесплатно + кредит в размере 200 долларов США | Кредит в размере 300 долларов США на 90 дней + всегда бесплатно |

## Когда какой использовать
| Сценарий | Рекомендуется | Почему |
|----------|-------------|-----|
| **Самый широкий выбор услуг; зрелая экосистема** | АВС | Самый большой каталог; большинство сторонних интеграций |
| **Корпорация Майкрософт; Активный каталог; гибрид** | Лазурный | Встроенная интеграция с AD; мощный гибридный инструмент |
| **Хранилище данных; БигQuery; аналитика** | GCP | BigQuery — лучший в своем классе; бесшовная интеграция данных |
| **Разработка на основе Kubernetes** | GCP | GKE — наиболее совершенный управляемый Kubernetes |
| **Приложения генеративного искусственного интеллекта и LLM** | Azure или GCP | Azure OpenAI для моделей GPT; Vertex AI для Близнецов |
| **Глобальные приложения с низкой задержкой** | GCP | Глобальная сеть Google является настоящим преимуществом |
| **Нагрузка на правительство/высокие требования к соблюдению требований** | AWS или Azure | Большинство сертификатов соответствия; GovCloud регионы |
| **Стартапы, чувствительные к затратам** | GCP или AWS | Уровень бесплатного пользования GCP щедр; У AWS есть стартовые кредиты |
| **Существующий стек Microsoft/.NET** | Лазурный | Тесная интеграция с Visual Studio, .NET, Office 365 |
| **Мультиоблачная стратегия** | Терраформ + все три | Используйте Terraform для управления ресурсами в облаках |

## Краткое содержание
Все три облака эффективны, надежны и постоянно расширяются. Выбор обычно сводится к тому, что уже знает ваша команда, как выглядят ваши существующие контракты и какие конкретные услуги важны для вашей рабочей нагрузки. Мультиоблачность становится все более распространенной — используйте Terraform или Pulumi, чтобы избежать привязки к поставщику на уровне инфраструктуры, и выбирайте каждое облако по тому, что оно делает лучше всего.
