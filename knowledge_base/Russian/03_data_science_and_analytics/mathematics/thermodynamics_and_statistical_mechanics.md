# Термодинамика и статистическая механика
Термодинамика описывает макроскопическое поведение систем с точки зрения температуры, давления и энтропии, не зная, как выглядят атомы. Статистическая механика объясняет термодинамику снизу вверх: она выводит макроскопические свойства из микроскопического поведения огромного числа частиц. Вместе они обеспечивают глубочайшее понимание энергии, энтропии и равновесия — концепций, которые перекочевали в теорию информации, машинное обучение и не только.
---

## Термодинамические переменные и состояние
### Переменные состояния
| Переменная | Тип | Единица | Описание |
|----------|------|------|-------------|
| Температура (Т) | Интенсив | Кельвин (К) | Средняя кинетическая энергия частицы |
| Давление (Р) | Интенсив | Паскаль (Па) | Сила на единицу площади |
| Объем (В) | Обширный | м³ | Пространство занято |
| Внутренняя энергия (U) | Обширный | Джоуль (Дж) | Полная микроскопическая энергия |
| Энтропия (S) | Обширный | Дж/К | Мера беспорядка/микросостояний |
| Количество частиц (N) | Обширный | родинки или количество | Количество вещества |
**Интенсивные** переменные не зависят от размера системы; **обширные** переменные.
### Уравнение состояния
Для идеального газа: PV = nRT = Nk_BT.
| Константа | Значение |
|----------|-------|
| R (газовая постоянная) | 8,314 Дж/(моль·К) |
| k_B (постоянная Больцмана) | 1,381 × 10⁻²³ Дж/К |
| N_A (число Авогадро) | 6,022 × 10²³ /моль |

## Законы термодинамики
### Нулевой закон
Если А находится в тепловом равновесии с В, а В с С, то А находится в тепловом равновесии с С.
**Значение:** Температура четко определена и измерима.
### Первый закон (энергосбережение)
ΔU = Q − W
| Символ | Значение |
|--------|---------|
| ΔU | Изменение внутренней энергии |
| вопрос | В систему добавлено тепло |
| Вт | Работа, выполняемая системой |
**Дифференциальная форма:** dU = δQ − δW = δQ − PdV
| Процесс | Ограничение | Следствие |
|---------|-----------|-------------|
| изохорный | дВ = 0 | W = 0, ΔU = Q |
| Изобарный | дП = 0 | W = PΔV |
| Изотермический | дТ = 0 | ΔU = 0 (идеальный газ), Q = W |
| Адиабатический | δQ знак равно 0 | ΔU = −W |
### Второй закон (Энтропия)
**Утверждение Клаузиуса:** Тепло не может самопроизвольно переходить от холодного к горячему.
**Утверждение Кельвина-Планка:** Ни один двигатель не может преобразовать всё тепло в работу.
**Утверждение об энтропии:** Для любого процесса: ΔS_universe ≥ 0.
| Тип процесса | ΔS_вселенная |
|-------------|-------------|
| Двусторонний | = 0 |
| Необратимый (реальный) | > 0 |
**Изменение энтропии:** dS = δQ_rev / T
### Третий закон
При T → 0 К энтропия идеального кристалла стремится к нулю: lim_{T→0} S = 0
**Значение:** Абсолютный ноль недостижим за конечные шаги.

## Энтропия в глубине
### Термодинамическая энтропия
S — функция состояния. Для обратимого процесса между состояниями A и B:
ΔS = ∫_A^B δQ_rev / T
**Работающий пример:** Изменение энтропии при нагреве воды от T₁ до T₂ при постоянном давлении.
ΔS = ∫_{T₁}^{T₂} (mc_p/T) dT = mc_p ln(T₂/T₁)
### Статистическая энтропия (Больцман)
S = k_B ln Ом
где Ω — количество микросостояний, соответствующих макросостоянию.
| Макростейт | Микросостояния (Ом) | Энтропия |
|-----------|-----------------|---------|
| Весь газ в одной половине коробки | Маленький | Низкий |
| Газ равномерно распределен | Очень большой | Высокий |
| Идеальный кристалл при 0 К | 1 | 0 |
**Связь:** Второй закон становится статистическим: системы развиваются в сторону макросостояний с большим количеством микросостояний просто потому, что они гораздо более вероятны.

## Энтальпия и свободная энергия
### Энтальпия
Н = У + ПВ
Полезно для процессов при постоянном давлении (большая часть химии и биологии).
ΔH = Q_p (тепло при постоянном давлении)
### Свободная энергия Гельмгольца
F = U - ТС
| Недвижимость | Заявление |
|----------|-----------|
| Значение | Максимальная работа, извлекаемая при постоянных T, V |
| Равновесие | Система минимизирует F при постоянных T, V |
| Связь с функцией распределения | F = −k_BT ln Z |
### Свободная энергия Гиббса
Г = Ч - ТС = U + PV - TS
| Недвижимость | Заявление |
|----------|-----------|
| Значение | Максимальная работа без расширения при постоянных T, P |
| Равновесие | Система минимизирует G при постоянных T, P |
| Спонтанность | ΔG < 0 → спонтанно; ΔG = 0 → равновесие |
| Химические реакции | ΔG = ΔH − TΔS определяет направление |
### Сводка термодинамических потенциалов
| Потенциал | Естественные переменные | Дифференциал | Свернуто, когда |
|-----------|-------------------|-------------|----------------|
| U (внутренняя энергия) | С, В | dU = TdS − PdV | Изолированная система |
| Н (энтальпия) | С, П | dH = TdS + VdP | Константа P, адиабатическая |
| Ф (Гельмгольц) | Т, В | dF = −SdT − PdV | Константа Т, В |
| Дж (Гиббс) | Т, П | dG = −SdT + VdP | Константа Т, П |

## Цикл Карно
**Цикл Карно** — это наиболее эффективный тепловой двигатель, работающий в диапазоне температур T_H (горячий) и T_C (холодный).
### Четыре этапа
| Этап | Процесс | Что происходит |
|-------|---------|-------------|
| 1 → 2 | Изотермическое расширение | Поглощать тепло Q_H из горячего резервуара при T_H |
| 2 → 3 | Адиабатическое расширение | Газ охлаждается от T_H до T_C |
| 3 → 4 | Изотермическое сжатие | Отвод тепла Q_C в холодный резервуар при T_C |
| 4 → 1 | Адиабатическое сжатие | Газовое отопление от T_C до T_H |
### Эффективность Карно
η_Карно = 1 − T_C/T_H
| Т_Х | Т_С | η_Карно |
|-----|-----|----------|
| 500 К | 300 К | 40% |
| 1000 К | 300 К | 70% |
| 300 К | 299 К | 0,33% |
**Ни один реальный двигатель не может превысить КПД Карно.** Реальные двигатели всегда необратимы (трение, турбулентность, конечная разница температур).

## Статистическая механика
### Распределение Больцмана
Для системы, находящейся в тепловом равновесии при температуре T, вероятность находиться в микросостоянии с энергией E_i:
P(E_i) = (1/Z) e^{−E_i / k_BT}
где Z — **функция распределения**:
Z = Σᵢ e^{−E_i / k_BT}
### Функция разделения
Z кодирует всю термодинамическую информацию о системе.
| Количество | Формула |
|----------|---------|
| Свободная энергия Гельмгольца | F = −k_BT ln Z |
| Средняя энергия | ⟨E⟩ = −∂(ln Z)/∂β, где β = 1/(k_BT) |
| Энтропия | S = k_B(ln Z + β⟨E⟩) |
| Теплоемкость | C_V = ∂⟨E⟩/∂T = k_Bβ²(⟨E²⟩ − ⟨E⟩²) |
| Давление | P = (1/β) ∂(ln Z)/∂V |
### Рабочий пример: система с двумя состояниями
Частица может находиться в состоянии 0 (энергия 0) или состоянии 1 (энергия ε).
Z = 1 + е^{−βε}
| Количество | Результат |
|----------|--------|
| P(состояние 0) | 1/(1 + e^{−βε}) |
| P(состояние 1) | e^{−βε}/(1 + e^{−βε}) |
| ⟨Е⟩ | ε/(1 + e^{βε}) |
| Верхний предел T (β→0) | ⟨E⟩ → ε/2 (равная вероятность) |
| Нижний предел T (β→∞) | ⟨E⟩ → 0 (основное состояние) |
### Теорема о равнораспределении
Каждая квадратичная степень свободы вносит вклад в среднюю энергию ½k_BT.
| Система | Степени свободы | ⟨Е⟩ |
|--------|-------------------|------|
| Одноатомный газ (He) | 3 переводные | (3/2)k_BT |
| Двухатомный газ (N₂) в помещении T | 3 транса + 2 рот | (5/2)k_BT |
| Двухатомный газ при высоких температурах | 3 транса + 2 рот + 1 виб | (7/2)k_BT |
| Твердое тело (модель Эйнштейна) | 3 колебательных (на атом) | 3к_БТ |

## Связь с теорией информации
### Энтропия Шеннона против термодинамической энтропии
| Аспект | Энтропия Шеннона H(X) | Термодинамическая энтропия S |
|--------|---------------------|------------------------|
| Определение | −Σ pᵢ log pᵢ | k_B ln Ω (или −k_B Σ pᵢ ln pᵢ) |
| Максимум, когда | Равномерное распределение | Тепловое равновесие |
| Меры | Неопределенность/содержание информации | Количество доступных микросостояний |
| Единицы | Биты или нац | Дж/К |
**Формула энтропии Гиббса:** S = −k_B Σᵢ pᵢ ln pᵢ (идентична по форме энтропии Шеннона)
### Принцип максимальной энтропии
В обеих областях используется один и тот же принцип: распределение, которое лучше всего отражает наше состояние знаний, — это то, которое максимизирует энтропию с учетом известных ограничений.
| Ограничение | Результирующее распределение |
|-----------|----------------------|
| Известное среднее | Экспоненциальное распределение |
| Известное среднее значение и дисперсия | Распределение Гаусса |
| Известная энергия ⟨E⟩ | Распределение Больцмана |
| Никаких ограничений | Равномерное распределение |
### Принцип Ландауэра
При стирании одного бита информации не менее k_BT ln 2 энергии рассеивается в виде тепла. Это напрямую связывает обработку информации с термодинамикой — вычисления требуют фундаментальных затрат энергии.

## Актуальность для машинного обучения и науки о данных
| Концепция Thermo/StatMech | Приложение |
|------------------------|-------------|
| Распределение Больцмана | Функция Softmax, энергетические модели, имитация отжига |
| Функция раздела | Нормирующая константа в вероятностных моделях, вообще трудноразрешимых |
| Бесплатная энергия | Вариационный вывод (минимизация вариационной свободной энергии = минимизация КЛ-дивергенции) |
| Энтропия | Регуляризация, исследование в RL (максимальная энтропия RL), деревья решений |
| Принцип максимальной энтропии | Классификаторы MaxEnt, предварительный отбор, оценка распределения |
| Имитация отжига | Глобальная оптимизация путем постепенного снижения «температуры» |
| Статистическая механика | Понимание фазовых переходов в обучении (грокинг, двойной спуск) |
| Равнораспределение | Понимание распределения энергии в физическом моделировании |
| Принцип Ландауэра | Фундаментальные ограничения вычислений, обратимые вычисления |
| Выборка Гиббса | Метод MCMC, вдохновленный статистической механикой |
| Температура (в softmax) | Управляет случайностью прогнозов: P(i) ∝ exp(z_i/T) |

## Краткое содержание
| Закон/Концепция | Основная идея | Формула |
|------------|-----------|---------|
| Нулевой закон | Температура четко определена | Транзитивность теплового равновесия |
| Первый закон | Энергия сохраняется | ΔU знак равно Q - W |
| Второй закон | Энтропия Вселенной возрастает | ΔS ≥ 0 |
| Третий закон | Абсолютный ноль недостижим | S → 0 при Т → 0 |
| Энтропия Больцмана | Энтропия считает микросостояния | S = k_B ln Ом |
| Распределение Больцмана | Вероятность энергетических состояний | P ∝ e^{−E/k_BT} |
| Функция раздела | Кодирует всю термодинамическую информацию | Z знак равно Σ e^{−E_i/k_BT} |
| Бесплатная энергия | Есть полезная работа | F знак равно U - TS, грамм знак равно ЧАС - TS |
| Эффективность Карно | Максимальная эффективность теплового двигателя | η знак равно 1 − Т_С/Т_Н |
Термодинамика и статистическая механика — это то, где физика встречается с теорией информации. Та же энтропия, которая управляет тепловыми двигателями, управляет сжатием данных. То же распределение Больцмана, которое описывает молекулы газа, управляет слоем softmax в каждом классификаторе. Понимание этих связей дает вам единое представление о физике, вероятности и машинном обучении.
