# Численные методы
Численные методы являются мостом между математической теорией и практическими вычислениями. Хотя чистая математика доказывает, что решения существуют, численные методы на самом деле вычисляют приблизительные ответы с конечной точностью. Каждая модель машинного обучения, физическое моделирование и конвейер анализа данных в конечном итоге опираются на численные вычисления. Понимание этих методов — их точности, стабильности и ограничений — необходимо для создания надежного программного обеспечения.
---

## Арифметика с плавающей запятой
Компьютеры представляют действительные числа с конечной точностью. **Стандарт IEEE 754** определяет, как хранятся и обрабатываются числа с плавающей запятой.
### Форматы IEEE 754
| Формат | Биты | Экспонента | Мантисса | Приблизительные десятичные цифры | Диапазон |
|--------|------|----------|----------|---------------------------|-------|
| Половина (fp16) | 16 | 5 | 10 | 3.3 | ±6,5 × 10⁴ |
| Одиночный (fp32) | 32 | 8 | 23 | 7.2 | ±3,4 × 10³⁸ |
| Двойной (fp64) | 64 | 11 | 52 | 15,9 | ±1,8 × 10³⁰⁸ |
### Машина Эпсилон
**Машинный эпсилон** (ε_mach) – это наименьшее число, для которого 1 + ε_mach > 1 в формате с плавающей запятой.
| Формат | ε_мах |
|--------|--------|
| фп16 | 2⁻¹⁰ ≈ 9,8 × 10⁻⁴ |
| фп32 | 2⁻²³ ≈ 1,2 × 10⁻⁷ |
| fp64 | 2⁻⁵² ≈ 2,2 × 10⁻¹⁶ |
### Распространенные ошибки
| ловушка | Пример | Следствие |
|---------|---------|-------------|
| **Катастрофическая отмена** | Вычисление (1 + x) − 1 для малого x | Потеря значащих цифр |
| **Поглощение** | 10⁸ + 1 = 10⁸ в fp32 | Небольшие ценности теряются в больших суммах |
| **Неассоциативность** | (а + б) + с ≠ а + (б + с) | Порядок суммы имеет значение |
| **Деление на почти ноль** | 1 / 10⁻³⁰⁰ → переполнение | Бесконечность или NaN |
### Стратегии смягчения последствий
| Стратегия | Описание |
|----------|-------------|
| **Суммирование Кахана** | Компенсированное суммирование для уменьшения ошибки поглощения |
| **Кахан-Бабушка-Ноймайер** | Улучшенная версия суммирования Кахана |
| **Сортированное суммирование** | Сначала суммируйте небольшие числа, чтобы избежать поглощения |
| **Двойная-двойная арифметика** | Используйте пары двойных чисел для повышения точности |
| **Анализ кондиционирования** | Поймите, усиливает ли сама проблема ошибки |

## Поиск корня
Нахождение x такого, что f(x) = 0.
### Метод бисекции
| Недвижимость | Значение |
|----------|-------|
| Требуется | f непрерывен, f(a) и f(b) имеют противоположные знаки |
| Конвергенция | Линейный (ошибка уменьшается вдвое на каждом шаге) |
| Гарантировано? | Да — всегда сходится |
| Итерации для d цифр | ≈ d / log₁₀(2) ≈ 3,32д |
**Алгоритм:**
1. Начните с интервала [a, b], где f(a) · f(b) < 0.
2. Вычислить среднюю точку c = (a + b)/2.
3. Если f(c) = 0 или |b − a| <терпимость, стоп
4. Если f(a) · f(c) < 0, положим b = c; иначе установите a = c
5. Повторите
### Метод Ньютона-Рафсона
| Недвижимость | Значение |
|----------|-------|
| Требуется | f дифференцируемый, f'(x) ≠ 0 в корне |
| Конвергенция | Квадратичный (около корня) |
| Гарантировано? | Нет — может расходиться или циклически повторяться |
| Обновить правило | x_{n+1} = x_n - f(x_n) / f'(x_n) |
**Рабочий пример:** Найдите √2, решив f(x) = x² − 2 = 0.
- f'(x) = 2x
- х₀ = 1,5
- х₁ = 1,5 - (2,25 - 2) / 3 = 1,5 - 0,0833 = 1,4167
- x₂ = 1,4167 - (2,0069 - 2) / 2,8333 = 1,4142
- x₃ = 1,41421356... (с точностью до 8 знаков после запятой)
### Метод секущего
Подобен методу Ньютона, но аппроксимирует производную:
x_{n+1} = x_n - f(x_n) · (x_n - x_{n-1}) / (f(x_n) - f(x_{n-1}))
| Недвижимость | Значение |
|----------|-------|
| Конвергенция | Суперлинейный (порядок ≈ 1,618, золотое сечение) |
| Требуется | Два первоначальных предположения (производная не требуется) |
### Сравнение методов поиска корня
| Метод | Конвергенция | Нужна производная? | Гарантировано? | Стоимость за шаг |
|--------|-------------|-------------------|-------------|---------------|
| Бисекция | Линейный (1) | Нет | Да | 1 функция оценки |
| Ньютон-Рафсон | Квадратичный (2) | Да | Нет | 2 вычисления функции |
| Секанс | Суперлинейный (1,618) | Нет | Нет | 1 функция оценки |
| Метод Брента | Суперлинейный | Нет | Да | Варьируется |
**Метод Брента** сочетает деление пополам (гарантированная сходимость) с секущей/обратно-квадратичной интерполяцией (быстрая сходимость). Это средство поиска корней по умолчанию в большинстве числовых библиотек.

## Численное интегрирование (квадратура)
Примерное вычисление ∫ₐᵇ f(x) dx.
### Методы
| Метод | Формула | Ошибка | Заказать |
|--------|---------|-------|-------|
| **Прямоугольник (середина)** | (b−a) · f((a+b)/2) | О(ч²) | 1 |
| **Трапециевидный** | (b−a)/2 · [f(a) + f(b)] | О(ч²) | 2 |
| **1/3 Симпсонов** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | О(ч⁴) | 3 |
| **3/8 Симпсонов** | Использует 4 равноотстоящие друг от друга точки | О(ч⁴) | 4 |
| **Гауссова квадратура** | Оптимальное размещение узлов | О(ч²ⁿ) | n точек |
### Составные правила
Для n подинтервалов ширины h = (b−a)/n:
| Правило | Составная формула | Ошибка |
|------|-------------------|-------|
| Композитный трапециевидный | h[f(a)/2 + Σf(xᵢ) + f(b)/2] | О(ч²) |
| Композитный Симпсон | h/3[f(a) + 4Σf(нечетный) + 2Σf(четный) + f(b)] | О(ч⁴) |
**Рабочий пример:** Приблизительное значение ∫₀¹ e^(−x²) dx с использованием составной трапеции с n = 4.
- h = 0,25, баллы: 0, 0,25, 0,5, 0,75, 1
- f(0) = 1, f(0,25) = 0,9394, f(0,5) = 0,7788, f(0,75) = 0,5698, f(1) = 0,3679
- Т = 0,25[1/2 + 0,9394 + 0,7788 + 0,5698 + 0,3679/2] = 0,25[1/2 + 2,2880 + 0,1840] = 0,7430
- Истинное значение: ≈ 0,7468 (погрешность ≈ 0,5%)
### Адаптивная квадратура
Автоматически подразделяет интервалы, в которых функция быстро меняется, используя меньшее количество точек, где она плавна. Это то, что использует`scipy.integrate.quad`(на основе QUADPACK).

## Интерполяция
Оценка значений между известными точками данных.
### Методы
| Метод | Описание | Гладкость | Колебания |
|--------|-------------|------------|-------------|
| **Ближайший сосед** | Использовать ближайшую точку данных | Прерывистый | Нет |
| **Линейный** | Соединить точки прямыми линиями | C⁰ (непрерывный) | Нет |
| **Полином (Лагранжа)** | Один полином через все точки | С^∞ | Тяжелый по многим пунктам (феномен Рунге) |
| **Кубический сплайн** | Кусочно-кубическая, гладкая на стыках | С² | Минимальный |
| **Радиальная базисная функция** | Взвешенная сумма радиальных ядер | Зависит от ядра | Низкий |
### Интерполяция Лагранжа
Учитывая n+1 точку (x₀, y₀), ..., (xₙ, yₙ), уникальный многочлен степени ≤ n, проходящий через все точки:
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**Феномен Рунге.** Полиномиальная интерполяция высокой степени в равноотстоящих друг от друга точках может сильно колебаться вблизи краев. Смягчается за счет использования узлов Чебышева или сплайнов.
### Кубические сплайны
Кусочные кубические полиномы, непрерывные по C² (непрерывные вторые производные).
| Тип | Граничное условие |
|------|-------------------|
| Натуральный сплайн | S''(x₀) = S''(xₙ) = 0 |
| Зажатый шлиц | S'(x₀) и S'(xₙ) указаны |
| Не узел | Третья производная непрерывна в точках x₁ и xₙ₋₁ |

## Решатели ОДУ
Численное решение обыкновенных дифференциальных уравнений dy/dt = f(t, y).
### Метод Эйлера
Самый простой решатель ОДУ.
**Обновление:** y_{n+1} = y_n + h · f(t_n, y_n)
| Недвижимость | Значение |
|----------|-------|
| Заказать | 1 (ошибка на шаг: O(h²), глобальная: O(h)) |
| Стабильность | Условно стабильный (требуется небольшой h) |
| Стоимость | 1 вычисление функции на шаг |
### Методы Рунге-Кутты
| Метод | Заказать | Этапы | Заметки |
|--------|-------|--------|-------|
| **Эйлер** | 1 | 1 | Самый простой |
| **Середина** | 2 | 2 | Повышенная точность |
| **Хын (RK2)** | 2 | 2 | Предиктор-корректор |
| **Классический RK4** | 4 | 4 | Стандартная рабочая лошадка |
| **Дорманд-Принц (RK45)** | 4(5) | 6 | Адаптивный размер шага (используется в ode45) |
### Классический RK4 (Рунге-Кутта 4-го порядка)
k₁ = f(t_n, y_n)
k₂ = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk₂/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k₂ + 2k₃ + k₄) / 6
| Недвижимость | Значение |
|----------|-------|
| Заказать | 4 (глобальная ошибка: O(h⁴)) |
| Стоимость | 4 оценки функций на шаг |
| Стабильность | Гораздо лучше, чем Эйлер |
| Использование | По умолчанию для нежестких ОДУ |
### Жесткие ОДУ
**жесткая** ОДУ имеет компоненты, которые изменяются в совершенно разных временных масштабах. Явные методы (Эйлер, RK4) требуют непрактично малого размера шага.
| Метод | Тип | Стабильность |
|--------|------|-----------|
| Неявный Эйлер | Неявное | А-стабильный (безусловно стабильный) |
| Формула обратного дифференцирования (BDF) | Неявное | А-стабильный (до порядка 5) |
| Неявный Рунге-Кутта | Неявное | Существуют L-стабильные варианты |
| ЛСОДА | Автоматический | Переключение между жестким/нежестким |

## Численная стабильность и кондиционирование
### Номер условия
**Число условия** показывает, насколько сильно изменяются выходные данные задачи по сравнению с небольшими изменениями входных данных.
Для линейной системы Ax = b: κ(A) = ||A|| · ||А⁻¹||
| κ(А) | Интерпретация |
|-------|---------------|
| ≈ 1 | С хорошим кондиционером |
| 10³ | Слегка чувствительная |
| 10⁸ | Плохое состояние (потеря ~8 цифр точности) |
| → ∞ | Единственное число (нет единственного решения) |
### Стабильность алгоритмов
Алгоритм является **численно стабильным**, если небольшие отклонения на входных данных приводят к небольшим отклонениям на выходе (относительно числа обусловленности задачи).
| Алгоритм | Стабильный? | Заметки |
|-----------|---------|-------|
| Метод исключения Гаусса с частичным поворотом | Да | Стандартный подход |
| Вычисление собственных значений с помощью QR | Да | Обратная стабильная |
| Наивное суммирование (сначала большое + маленькое) | Нет | Используйте суммирование Кахана |
| Вычисление дисперсии как E[X²] − (E[X])² | Потенциально нет | Используйте онлайн-алгоритм Уэлфорда |
### Онлайн-алгоритм Уэлфорда
Численно стабильное вычисление скользящего среднего и дисперсии:
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

Это позволяет избежать катастрофической отмены, которая происходит в простой двухпроходной формуле.

| Численный метод | Приложение |
|-----------------|-------------|

| RK4 / адаптивные решатели | Моделирование динамических систем, обучение сетей непрерывной глубины |

## Краткое содержание
| Тема | Основная идея | Ключевой метод |
|-------|-----------|------------|
| Плавающая точка | Представление конечной точности | IEEE 754, суммирование Кахана |
| Поиск корня | Решите f(x) = 0 | Биссекция, Ньютон-Рафсон, Брентс |
| Численное интегрирование | Приблизительное ∫f(x)dx | Трапециевидная, квадратура Симпсона, Гаусса |
| Интерполяция | Оценка между точками данных | Кубические сплайны, Лагранж, RBF |
| Решатели ОДУ | Решите dy/dt = f(t,y) | Эйлер, RK4, адаптивные методы |
| Стабильность | Чувствительность к ошибкам округления | Число условий, устойчивые алгоритмы |
Численные методы — это то, где математика встречается с реальностью. Ни один компьютер не может точно представить большинство действительных чисел, на практике никакая производная не вычисляется символически, и ни один интеграл не вычисляется в закрытой форме для реальных задач. Понимание численных методов позволит вам выбрать правильный алгоритм, спрогнозировать его точность и избежать тонких ошибок, возникающих в арифметике с конечной точностью.
