# Обработка сигналов
Обработка сигналов — это наука об анализе, изменении и синтезе сигналов — представлений физических величин, изменяющихся во времени, пространстве или частоте. Аудио, изображения, видео, данные датчиков, мозговые волны, цены на акции — все это сигналы. Математические инструменты обработки сигналов (преобразования Фурье, фильтры, теория выборки) лежат в основе машинного обучения, коммуникаций, медицинской визуализации и практически всех областей, связанных с данными.
---

## Сигналы и системы
### Классификация сигналов
| Тип | Описание | Пример |
|------|-------------|---------|
| **Непрерывно** | Определено для всех t ∈ ℝ | Аудио напряжение, температура |
| **Дискретное время** | Определено по целочисленным индексам n | Сэмплированный звук, значения пикселей |
| **Аналоговый** | Непрерывный по времени и амплитуде | Грунтовка для виниловой пластинки |
| **Цифровой** | Дискретный по времени и квантованный по амплитуде | Файл MP3, изображение JPEG |
| **Периодический** | x(t + T) = x(t) для всех t | Синусоидальная волна, прямоугольная волна |
| **Апериодический** | Нет повторяющегося рисунка | Речь, музыка |
| **Детерминированный** | Полностью предсказуемо | Синусоидальная волна |
| **Стохастик** | Содержит случайность | Шум, цены на акции |
### Свойства системы
| Недвижимость | Определение | Пример |
|----------|-----------|---------|
| **Линейный** | Т[ax₁ + bx₂] = aT[x₁] + bT[x₂] | Фильтр нижних частот |
| **Независимый от времени** | Сдвиг на входе → тот же сдвиг на выходе | Любой фиксированный фильтр |
| **Причинно-следственная связь** | Выход зависит только от текущих и прошлых входов | Система реального времени |
| **Стабильный (BIBO)** | Ограниченный вход → ограниченный выход | Хорошо продуманный фильтр |
| **Без памяти** | Выход зависит только от текущего входа | Усилитель |

## Преобразование Фурье
**Преобразование Фурье** разлагает сигнал на составляющие его частоты.
### Непрерывное преобразование Фурье
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
Обратное: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### Пары преобразований Фурье
| Временная область x(t) | Частотная область X(f) |
|-------------------|----------------------|
| Прямоугольный импульс | функция синк |
| функция синк | Прямоугольный импульс |
| Гауссово e^{−at²} | Гауссово (√(π/a))e^{−π²f²/a} |
| Дельта Дирака δ(t) | 1 (все частоты) |
| Комплексная экспонента e^{j2πf₀t} | δ(е - е₀) |
| Косинус cos(2πf₀t) | ½[δ(f−f₀) + δ(f+f₀)] |
### Ключевые свойства
| Недвижимость | Временная область | Частотная область |
|----------|-------------|-----------------|
| Линейность | топор₁(т) + bx₂(т) | аХ₁(е) + bX₂(е) |
| Сдвиг времени | х (т - т₀) | X(f)e^{−j2πft₀} |
| Сдвиг частоты | х(т)е^{j2πf₀t} | Икс (е - е₀) |
| Свертка | х₁(т) * х₂(т) | X₁(ж) · X₂(ж) |
| Умножение | х₁(т) · х₂(т) | X₁(ж) * X₂(ж) |
| Дифференциация | дх/дт | j2πf X(f) |
| Теорема Парсеваля | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**Теорема о свертке:** Свертка по времени = умножение по частоте. Это самое важное свойство — оно превращает дорогостоящие операции свертки в дешевые умножения.
### Дискретное преобразование Фурье (ДПФ)
Для последовательности x[0], x[1], ..., x[N−1]:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}, k = 0, 1, ..., N−1
| Недвижимость | Значение |
|----------|-------|
| Ввод | N реальных или сложных выборок |
| Выход | N комплексных частотных элементов |
| Разрешение по частоте | f_s/N (где f_s — частота дискретизации) |
| Частота Найквиста | f_s/2 (максимально представимая частота) |
| Сложность | O(N²) прямое вычисление |
### Быстрое преобразование Фурье (БПФ)
**БПФ** вычисляет ДПФ за O(N log N) вместо O(N²).
| Н | O(N²) Операции | O(N log N) Операции | Ускорение |
|---|------------------|----------------------|---------|
| 1,024 | 1 048 576 | 10 240 | 102× |
| 1 048 576 | 1,1 × 10¹² | 20 971 520 | 52 428 × |
БПФ — один из самых важных алгоритмов, когда-либо изобретенных. Он обеспечивает обработку звука в реальном времени, сжатие изображений (JPEG), беспроводную связь (OFDM) и спектральный анализ.

## Преобразование Лапласа
**Преобразование Лапласа** расширяет преобразование Фурье для работы с нестабильными системами и анализа переходных процессов.
F(s) = ∫₀^∞ f(t) e^{−st} dt, где s = σ + jω
### Общие преобразования Лапласа
| е(т) | Ф(ы) | Регион конвергенции |
|------|------|----------------------|
| δ(t) (импульс) | 1 | Все с |
| и(т) (шаг) | 1/с | Re(s) > 0 |
| е^{-at}u(t) | 1/(с+а) | Re(s) > −а |
| тⁿи(т) | n!/s^{n+1} | Re(s) > 0 |
| грех(ωt)u(t) | ω/(s²+ω²) | Re(s) > 0 |
| потому что(ωt)u(t) | с/(s²+ω²) | Re(s) > 0 |
### Подключение к преобразованию Фурье
Когда σ = 0 (s = jω), преобразование Лапласа сводится к преобразованию Фурье. Преобразование Лапласа дает более полную картину, включая информацию о росте/распаде (σ).
---

## Z-преобразование
**Z-преобразование** является эквивалентом преобразования Лапласа в дискретном времени.
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### Общие Z-преобразования
| х[п] | Х(г) | РПЦ |
|------|------|-----|
| δ[n] | 1 | Все г |
| u[n] (шаг) | г/(г−1) | \|з\| > 1 |
| аⁿу[п] | г/(г-а) | \|з\| > \|а\| |
| наⁿу[н] | аз/(z−a)² | \|з\| > \|а\| |
| грех(ω₀n)u[n] | z sin(ω₀)/(z²−2z cos(ω₀)+1) | \|з\| > 1 |
### Связь с другими преобразованиями
| Трансформировать | Домен | Переменная |
|-----------|--------|----------|
| Фурье | Непрерывная частота | е или ω |
| Лаплас | Комплексная частота | s знак равно σ + jω |
| Z-преобразование | Комплексная частота (дискретная) | z = е^{sT} |
Единичный круг в плоскости z (|z| = 1) соответствует преобразованию Фурье.

## Фильтры
Фильтры избирательно пропускают или блокируют определенные частотные компоненты.
### Типы фильтров
| Тип | Проходит | Блоки | Приложение |
|------|--------|--------|-------------|
| **Низкочастотный** | Низкие частоты | Высокие частоты | Сглаживание, сглаживание |
| **Высокочастотный** | Высокие частоты | Низкие частоты | Обнаружение краев, удаление шума |
| **Полосовой** | Диапазон частот | За пределами диапазона | Выбор канала (радио) |
| **Заграждающая полоса (вырез)** | Все, кроме диапазона | Определенный диапазон | Удаление шума в линии электропередачи |
### FIR против БИХ-фильтров
| Недвижимость | FIR (конечная импульсная характеристика) | БИХ (бесконечная импульсная характеристика) |
|----------|-----------------------------------------------|--------------------------------|
| Импульсный ответ | Конечная продолжительность | Бесконечная продолжительность |
| Стабильность | Всегда стабильно | Может быть нестабильным |
| Фаза | Может быть точно линейным | Обычно нелинейная фаза |
| Обратная связь | Нет | Да |
| Вычисление | Нужно больше коэффициентов | Меньше коэффициентов при том же спаде |
| Дизайн | Окна, Парки-Макклеллан | Баттерворт, Чебышев, эллиптический |
| Передаточная функция | Ч(г) знак равно Σ bₖz⁻ᵏ | H(z) знак равно Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### Технические характеристики фильтра
| Параметр | Описание |
|-----------|-------------|
| **Полоса пропускания** | Диапазон частот, который должен пройти с минимальными потерями |
| **Полоса задерживания** | Диапазон частот, который следует ослабить |
| **Частота среза** | Граница между полосой пропускания и полосой задерживания |
| **Пульсация** | Изменение коэффициента усиления в полосе пропускания (или полосе задерживания) |
| **Спад** | Скорость затухания (дБ на октаву или декаду) |
| **Переходная полоса** | Область между полосой пропускания и полосой задерживания |
### Общие конструкции фильтров
| Дизайн | Характеристики | Вариант использования |
|--------|----------------|----------|
| **Баттерворт** | Максимально плоская полоса пропускания, умеренный спад | Общего назначения |
| **Чебышев Тип I** | Пульсации в полосе пропускания, более крутой спад | Когда спад имеет значение |
| **Чебышев Тип II** | Пульсации в полосе задерживания, плоская полоса пропускания | Когда неравномерность полосы пропускания имеет значение |
| **Эллиптический (Кауэр)** | Пульсация в обоих случаях, самый крутой спад | Необходим минимальный заказ |
| **Бессель** | Линейная фаза (максимально плоская групповая задержка) | Сохранение формы сигнала |

## Теория выборки
### Теорема Найквиста-Шеннона о выборке
Непрерывный сигнал можно идеально восстановить по его выборкам, если частота дискретизации вдвое превышает максимальную частоту:
f_s > 2f_max
| Срок | Определение |
|------|------------|
| **Частота выборки** (f_s) | Количество выборок в секунду |
| **Коэффициент Найквиста** | 2f_max (минимальная частота дискретизации) |
| **Частота Найквиста** | f_s/2 (максимально представимая частота) |
| **Псевдонимы** | Высокие частоты маскируются под низкие, когда f_s < 2f_max |
### Общие частоты дискретизации
| Приложение | Оценить | Частота Найквиста |
|-------------|------|-------------------|
| Телефонная речь | 8 кГц | 4 кГц |
| Аудио компакт-диск | 44,1 кГц | 22,05 кГц |
| Профессиональное аудио | 48 кГц | 24 кГц |
| Аудио высокого разрешения | 96 кГц | 48 кГц |
| Видео (30 кадров в секунду) | 30 Гц (временное) | 15 Гц |
### Сглаживание
Перед выборкой **фильтр сглаживания** (низкочастотный) удаляет частоты выше f_s/2, чтобы предотвратить наложение спектров.

## Окно
При анализе конечного сегмента сигнала мы неявно умножаем его на прямоугольное окно, вызывая утечку спектра. **Оконные функции** уменьшают эту утечку.
### Общие окна
| Окно | Ширина главного лепестка | Уровень бокового лепестка | Вариант использования |
|--------|----------------|-----------------|----------|
| Прямоугольный | Самый узкий | −13 дБ | Когда разрешение важнее всего |
| Ханн | 2× прямоугольный | −31 дБ | Общего назначения |
| Хэмминг | 2× прямоугольный | −41 дБ | Уменьшен ближайший боковой лепесток |
| Блэкман | 3× прямоугольный | −58 дБ | Высокий динамический диапазон |
| Кайзер | Регулируемый | Регулируемый (через β) | Когда компромисс настраиваемый |
### Спектральная утечка
Умножение сигнала на окно сворачивает его спектр со спектром окна. Более широкие основные лепестки снижают разрешение по частоте; нижние боковые лепестки уменьшают утечку.

## Вейвлеты
**Вейвлеты** — это небольшие локализованные волновые функции, используемые для анализа сигналов с разными разрешениями.
### Вейвлет-преобразование
В отличие от преобразования Фурье (которое дает глобальную информацию о частоте), вейвлет-преобразование дает **частотно-временную** локализацию.
| Трансформировать | Разрешение времени | Разрешение по частоте |
|-----------|----------------|---------------------|
| Фурье | Нет (глобально) | Отлично |
| Краткосрочный FT | Фиксированный (размер окна) | Исправлено |
| Вейвлет | Переменная (хорошо на высоких частотах) | Переменная (хороша на низкой частоте) |
### Общие семейства вейвлетов
| Семья | Недвижимость | Приложение |
|--------|-----------|-------------|
| **Хаар** | Простейший, прерывистый | Обнаружение кромок, быстрый анализ |
| **Добеши** (дБН) | Компактная опора, N исчезающих моментов | Сжатие, шумоподавление |
| **Симлеты** | Почти симметричный Добеши | Уменьшение фазовых искажений |
| **Коифлеты** | Создан для сиюминутных условий | Обработка сигналов |
| **Морле** | Синусоида с гауссовским окном | Частотно-временной анализ |
| **Мексиканская шляпа** | Вторая производная Гаусса | Обнаружение функций |
### Применение вейвлетов
| Приложение | Как помогают вейвлеты |
|-------------|-------------------|
| Сжатие изображения (JPEG 2000) | Представление с несколькими разрешениями лучше, чем DCT для краев |
| Шумоподавление | Пороговые малые вейвлет-коэффициенты (сигнал в больших коэффициентах) |
| Обнаружение функций | Обнаружение границ, обнаружение переходных процессов во временных рядах |
| анализ ЭКГ | Обнаружение комплексов QRS, классификация аритмий |
| Сейсмический анализ | Идентификация геологических слоев, обработка сигналов землетрясений |

## Краткое содержание
| Инструмент | Домен | Ключевая информация |
|------|--------|-------------|
| Преобразование Фурье | Время → Частота | Сигналы представляют собой суммы синусоид |
| Преобразование Лапласа | Время → Комплексная частота | Обрабатывает переходные процессы и стабильность |
| Z-преобразование | Дискретное время → Комплекс | Анализ и проектирование цифровых фильтров |
| БПФ | Эффективное вычисление ДПФ | O(N log N) вместо O(N²) |
| Фильтры | Выбор частоты | Передайте то, что вам нужно, заблокируйте то, что вам не нужно |
| Теорема выборки | Непрерывный ↔ дискретный | Отбирайте образцы достаточно быстро, ничего не теряйте |
| Окно | Компромисс время-частота | Разрешение баланса и утечка |
| Вейвлеты | Многоуровневый анализ | Локальный как по времени, так и по частоте |
Обработка сигналов обеспечивает математическую основу для понимания, анализа и манипулирования данными. Каждый конвейер машинного обучения, который работает с временными рядами, аудио, изображениями или данными датчиков, неявно использует концепции обработки сигналов. В частности, преобразование Фурье, возможно, является самым важным математическим инструментом после вычислений для любого специалиста по данным.
