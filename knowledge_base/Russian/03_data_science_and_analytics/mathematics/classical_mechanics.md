# Классическая механика
Классическая механика описывает движение объектов под действием сил. От падающих яблок до вращающихся вокруг планет, от вибрирующих струн до сталкивающихся частиц — ее принципы управляют макроскопическим миром. Помимо физических приложений, классическая механика породила вариационное исчисление, симплектическую геометрию и гамильтонову структуру, лежащую в основе квантовой механики и современной оптимизации.
---

## Ньютоновская механика
### Три закона Ньютона
| Закон | Заявление | Математическая форма |
|-----|-----------|-------------------|
| **Первый (Инерция)** | Объект остается в покое или в равномерном движении, если на него не действует сила | Если F_net = 0, то v = константа |
| **Второй (F = ма)** | Сила равна массе, умноженной на ускорение | **F** = m**a** = m(d²**x**/dt²) |
| **Третий (Действие-Реакция)** | Каждое действие имеет равное и противоположное противодействие | **F**₁₂ = −**F**₂₁ |
### Диаграммы свободного тела
**Диаграмма свободного тела** изолирует объект и показывает все силы, действующие на него.
**Общие силы:**
| Сила | Формула | Направление |
|-------|---------|-----------|
| Гравитация (около Земли) | F = мг | Вниз |
| Нормальная сила | Н | Перпендикулярно поверхности |
| Трение (статическое) | f_s ≤ μ_s N | Противостоит надвигающемуся движению |
| Трение (кинетическое) | f_k = μ_k N | Противодействует движению |
| Пружина (закон Гука) | F = −kx | Восстановление (к равновесию) |
| Напряжение | Т | По веревке/веревке |
| Перетащить | F_d = ½C_d ρAv² | Противодействует скорости |
### Рабочий пример: блокировка на наклоне
Блок массы m на наклонной поверхности без трения под углом θ.
- Силы: сила тяжести (мг вниз), нормальная сила (Н перпендикулярно поверхности)
- Разложение силы тяжести: мг sin θ (вдоль наклона), мг cos θ (на поверхность)
- N = mg cos θ (нет движения перпендикулярно поверхности)
- Ускорение по уклону: a = g sin θ.

## Энергетические методы
### Работа и кинетическая энергия
**Работа**, совершаемая силой: W = ∫ **F** · d**r**
**Теорема о рабочей энергии:** W_net = ΔKE = ½mv₂² − ½mv₁²
### Потенциальная энергия
| Сила | Потенциальная энергия | Заметки |
|-------|-----------------|-------|
| Гравитация (около поверхности) | U = мгх | h = высота над эталоном |
| Гравитация (общая) | U = −GMm/r | Ноль в бесконечности |
| Весна | U = ½kx² | x = смещение от равновесия |
| Электростатический | U = kq₁q₂/r | Подобные обвинения: положительные U |
### Сохранение энергии
Если действуют только консервативные силы: E = KE + PE = константа.
½мв₁² + U₁ = ½мв₂² + U₂
**Работающий пример:** мяч упал с высоты h.
- Начальное: KE = 0, PE = mgh
- Непосредственно перед ударом по земле: KE = ½mv², PE = 0
- Сохранение: mgh = ½mv² → v = √(2gh)
### Власть
P = dW/dt = **F** · **v** (скорость выполнения работы)

## Импульс и столкновения
### Линейный импульс
**p** = м**в**
Второй закон Ньютона (альтернативная форма): **F** = d**p**/dt.
### Сохранение импульса
Если нет внешних сил: полный импульс сохраняется.
| Тип столкновения | К.Е. Сохранено? | Импульс сохраняется? |
|---------------|----------------|---------------------|
| **Эластичный** | Да | Да |
| **Неэластичный** | Нет | Да |
| **Совершенно неэластичный** | Нет (максимальная потеря) | Да (предметы слипаются) |
**1D упругое столкновение:** Две массы m₁, m₂ с начальными скоростями u₁, u₂:
- v₁ = ((m₁−m₂)u₁ + 2m₂u₂) / (m₁+m₂)
- v₂ = ((m₂−m₁)u₂ + 2m₁u₁) / (m₁+m₂)
### Угловой момент
**L** = **r** × **p** = m(**r** × **v**)
Крутящий момент: **τ** = d**L**/dt = **r** × **F**
**Сохранение:** При отсутствии внешнего крутящего момента угловой момент сохраняется.

## Лагранжева механика
Формулировка **Лагранжа** заменяет силы энергией, обеспечивая более элегантную и общую структуру.
### Лагранжиан
L = T - V (кинетическая энергия минус потенциальная энергия)
### Принцип наименьшего действия (принцип Гамильтона)
Фактический путь, пройденный системой между моментами t₁ и t₂, минимизирует (точнее, делает стационарным) **действие**:
S = ∫_{t₁}^{t₂} L(q, q̇, t) dt
### Уравнения Эйлера-Лагранжа
Условие δS = 0 дает:
d/dt(∂L/∂q̇) − ∂L/∂q = 0
для каждой обобщенной координаты q.
**Работающий пример:** Простой маятник (длина l, масса м, угол θ от вертикали).
- Т = ½ мл²θ̇²
- V = −mgl cos θ
- L = ½ мл²θ̇² + мгл cos θ
- ∂L/∂θ = −mgl sin θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̈
- Эйлера-Лагранжа: ml²θ̈ + mgl sin θ = 0 → θ̈ + (г/л) sin θ = 0
### Преимущества лагранжевой механики
| Преимущество | Объяснение |
|-----------|-------------|
| Координатно-независимый | Работает в любой системе координат |
| Естественно справляется с ограничениями | Нет необходимости рассчитывать силы ограничения |
| Симметрия → сохранение | Теорема Нётер связывает симметрии с сохраняющимися величинами |
| Легко обобщает | Полям, теории относительности, квантовой механике |

## Гамильтонова механика
Формулировка **Гамильтона** представляет собой переформулировку лагранжевой механики, в которой используются положения и импульсы (вместо положений и скоростей).
### Гамильтониан
H = Σᵢ pᵢq̇ᵢ - L = T + V (для большинства механических систем)
где pᵢ = ∂L/∂q̇ᵢ — **обобщенные импульсы**.
### Уравнения Гамильтона
q̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
Это 2n ОДУ первого порядка (по сравнению с n уравнениями Эйлера-Лагранжа второго порядка).
**Работающий пример:** Гармонический осциллятор (масса m, жесткость пружины k).
- H = p²/(2м) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ (как и ожидалось)
- ṗ = −∂H/∂x = −kx → mẍ = −kx (закон Гука)
### Скобки Пуассона
Для функций f(q, p) и g(q, p):
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
| Недвижимость | Заявление |
|----------|-----------|
| Эволюция времени | df/dt = {f, H} + ∂f/∂t |
| Сохранение | f сохраняется тогда и только тогда, когда {f, H} = 0 (и ∂f/∂t = 0) |
| Фундаментальные скобки | {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**Связь с квантовой механикой:** скобки Пуассона становятся коммутаторами: {f, g} → (1/iℏ)[f̂, ĝ]

## Законы сохранения и теорема Нётер
### Теорема Нётер
Каждая непрерывная симметрия лагранжиана соответствует сохраняющейся величине.
| Симметрия | Сохраняющееся количество |
|----------|-------------------|
| Инвариантность перевода времени | Энергия |
| Пространственная трансляционная инвариантность | Линейный импульс |
| Вращательная инвариантность | Угловой момент |
| Калибровочная инвариантность | Электрический заряд |
Это один из самых глубоких результатов во всей физике — он связывает геометрию пространства-времени с фундаментальными законами сохранения.

## Динамика твердого тела
**Твёрдое тело** — это объект, все внутренние расстояния которого остаются фиксированными.
### Ключевые понятия
| Концепция | Формула | Описание |
|---------|---------|-------------|
| **Момент инерции** | I = Σmᵢrᵢ² или I = ∫r² дм | Устойчивость к вращательному ускорению |
| **Вращательный КЭ** | КЭ = ½Iω² | Энергия вращения |
| **Угловой момент** | L = Iω | Вращательный аналог p = mv |
| **Крутящий момент** | τ = Iα | Вращательный аналог F = ma |
### Моменты инерции (обычные формы)
| Форма | Ось | я |
|-------|------|---|
| Твердая сфера | Через центр | (2/5)MR² |
| Полая сфера | Через центр | (2/3)MR² |
| Твердый цилиндр | Вдоль оси | (1/2)MR² |
| Тонкий стержень | Через центр, перпендикулярно | (1/12)ML² |
| Тонкий стержень | Сквозной конец, перпендикулярно | (1/3)ML² |
| Диск | Через центр, перпендикулярно | (1/2)MR² |

## Орбитальная механика
### Законы Кеплера
| Закон | Заявление |
|-----|-----------|
| **Первый (многоточие)** | Планеты движутся по эллипсам, в одном из фокусов которых находится Солнце |
| **Второй (Равные площади)** | Линия от Солнца до планеты проходит равные площади за равное время |
| **Третий (Гармонический)** | T² ∝ a³ (квадрат периода пропорционален кубу большой полуоси) |
### Орбитальная энергия
E = ½mv² − GMm/r
| Е | Тип орбиты |
|---|-----------|
| Е< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 | Гиперболический (несвязанный) |
### Скорость убегания
v_escape = √(2GM/R)
Для Земли: v_escape ≈ 11,2 км/с.

## Актуальность для машинного обучения и науки о данных
| Концепция механики | Приложение |
|------------------|-------------|
| Законы Ньютона | Физические двигатели в симуляциях, игровой искусственный интеллект, робототехника |
| Энергетические методы | Энергетические модели, сети Хопфилда, машины Больцмана |
| Лагранжева механика | Нейронные сети, основанные на физике, оптимальное управление, оптимизация траектории |
| Гамильтонова механика | Гамильтоновы нейронные сети (HNN), симплектические интеграторы для моделирования |
| Законы сохранения | Индуктивные смещения в моделях машинного обучения, эквивариантные нейронные сети |
| Теорема Нётер | Машинное обучение с учетом симметрии, глубокое геометрическое обучение |
| Динамика твердого тела | Робототехническое моделирование, молекулярная динамика, 3D-анимация |
| Орбитальная механика | Спутниковое позиционирование (GPS для ML на основе определения местоположения), проектирование космических миссий |
| Фазовое пространство (гамильтониан) | Понимание динамических систем, сетей аттракторов |
| Вариационное исчисление | Оптимальный транспорт, генеративное моделирование (согласование потоков) |

## Краткое содержание
| Рамочная | Основное уравнение | Сила |
|-----------|--------------|----------|
| Ньютоновский | **F** = м**а** | Интуитивный прямой анализ сил |
| Лагранжиан | d/dt(∂L/∂q̇) − ∂L/∂q знак равно 0 | Бескоординатный, учитывает ограничения |
| гамильтониан | q̇ = ∂H/∂p, ṗ = −∂H/∂q | Симплектическая структура соединяется с QM |
| Законы сохранения | Теорема Нётер | Глубокая связь с сохранением симметрии |
Классическая механика – это не только падающие шарики и раскачивающиеся маятники. Ее математические основы — лагранжева и гамильтонова механика — являются одними из самых влиятельных идей во всей науке. Они обобщают квантовую механику, теорию поля и даже современное машинное обучение, где энергетические модели и нейронные сети, основанные на физике, опираются непосредственно на эти многовековые формулировки.
