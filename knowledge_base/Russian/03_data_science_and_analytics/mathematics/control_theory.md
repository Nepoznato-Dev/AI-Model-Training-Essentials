# Теория управления
Теория управления — это математика, позволяющая заставить системы вести себя так, как вы хотите. От термостатов до автопилотов, от роботизированного оружия до химических реакторов — системы управления чувствуют, принимают решения и действуют для поддержания желаемого поведения. Эта область предоставляет точные инструменты для анализа стабильности, производительности и надежности — концепций, которые перекочевали в обучение с подкреплением, настройку гиперпараметров и адаптивные системы.

## Фундаментальные понятия
### Открытый цикл против закрытого цикла
| Тип | Описание | Пример | Преимущество |
|------|-------------|---------|-----------|
| **Разомкнутый контур** | Управляющее действие независимо от выхода | Таймер для стиральной машины | Просто, датчик не нужен |
| **Замкнутый контур (обратная связь)** | Управляющее действие зависит от выхода | Термостат, круиз-контроль | Устойчивость к помехам, надежность |
### Элементы блок-схемы
| Элемент | Символ | Функция |
|---------|--------|----------|
| **Растение** | Г(ы) | Управляемая система |
| **Контроллер** | С(ы) | Вычисляет управляющее действие |
| **Датчик** | Ч(ы) | Измеряет выход |
| **Сводящий узел** | ⊕ | Ошибка вычисления: r − y |
| **Ссылка** | р(т) | Желаемый результат |
| **Ошибка** | е(т) = г(т) - у(т) | Разница между желаемым и фактическим |
| **Нарушение** | д(т) | Нежелательное воздействие на растение |
### Передаточная функция с обратной связью
Для стандартной системы отрицательной обратной связи:
T(s) = C(s)G(s) / (1 + C(s)G(s)H(s))
| Количество | Формула |
|----------|---------|
| Передаточная функция разомкнутого контура | L(s) = C(s)G(s)H(s) |
| Передаточная функция с обратной связью | T(s) = L(s)/H(s) / (1 + L(s)) |
| Функция передачи ошибок | E(s)/R(s) = 1 / (1 + L(s)) |
| Чувствительность | S(s) = 1 / (1 + L(s)) |

## Передаточные функции
**Переносная функция** H(s) = Y(s)/X(s) описывает соотношение ввода-вывода линейной нестационарной (LTI) системы в области Лапласа.
### Стандартные формы
| Система | Передаточная функция | Параметры |
|--------|-------------------|------------|
| **Первый заказ** | К/(τs + 1) | K = коэффициент усиления, τ = постоянная времени |
| **Второго порядка** | Kωₙ²/(s² + 2ζωₙs + ωₙ²) | ωₙ = собственная частота, ζ = коэффициент затухания |
| **Интегратор** | К/с | — |
| **Дифференциатор** | кс | — |
| **Задержка** | е^{−sT_d} | T_d = задержка |
### Поведение системы второго порядка
| Коэффициент демпфирования ζ | Поведение | Расположение полюсов |
|-----------------|-----------|---------------|
| ζ знак равно 0 | Незатухающие колебания | Чисто воображаемый |
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 | Передемпфированный (медленный, без колебаний) | Настоящий, отчетливый |
### Показатели производительности (шаговый отклик)
| Метрическая | Формула (2-го порядка, с недостаточным демпфированием) | Описание |
|--------|----------------------------------|-------------|
| Время нарастания (t_r) | ≈ 1,8/ωₙ | Время перейти от 10% к 90% |
| Время пик (t_p) | π/(ωₙ√(1−ζ²)) | Время до первого максимума |
| Перерегулирование (M_p) | e^{−πζ/√(1−ζ²)} × 100% | Максимальный пик выше конечного значения |
| Время урегулирования (t_s) | ≈ 4/(ζωₙ) | Время оставаться в пределах 2% от финала |
| Устойчивая ошибка | Зависит от типа системы | Разница между желаемым и фактическим при t → ∞ |

## ПИД-регуляторы
**ПИД-регулятор** является наиболее широко используемым контроллером в промышленности (более 90% промышленных контроллеров).
### Формула ПИД-регулятора
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
В области Лапласа: C(s) = K_p + K_i/s + K_d s.
| Срок | Эффект | Слишком много | Слишком мало |
|------|--------|----------|------------|
| **Пропорциональный (K_p)** | Реагирует на текущую ошибку | Колебания, нестабильность | Медленный ответ, большая ошибка |
| **Интеграл (К_и)** | Устраняет установившуюся ошибку | Перерегулирование, колебания | Постоянное смещение |
| **Производная (K_d)** | Прогнозирует будущую ошибку (демпфирование) | Усиление шума | Плохое подавление помех |
### Методы настройки ПИД-регулятора
| Метод | Подход |
|--------|----------|
| **Циглер-Николс** | Увеличивайте К_у до появления колебаний; используйте K_u и период P_u для установки прибыли |
| **Коэн-Кун** | На основе параметров переходного процесса (усиление, постоянная времени, мертвое время) |
| **IMC (Внутренний контроль модели)** | На основе модели процесса; обеспечивает хорошую надежность |
| **Автонастройка** | Онлайн-идентификация + настройка (многие современные контроллеры) |
| **Руководство** | Начните только с K_p, добавьте K_i, чтобы убрать смещение, добавьте K_d для демпфирования |
### Правила Циглера-Николса
1. Установите K_i = K_d = 0.
2. Увеличивайте K_p до тех пор, пока не возникнут устойчивые колебания: максимальный коэффициент усиления K_u, период P_u.
3. Установите выигрыш:
| Контроллер | К_п | К_и | К_д |
|-----------|-----|-----|-----|
| П | 0,5К_у | — | — |
| ПИ | 0,45К_у | 1.2К_у/П_у | — |
| ПИД | 0,6К_у | 2К_у/П_у | К_у П_у/8 |

## Анализ стабильности
Система **стабильна**, если ее выход остается ограниченным при ограниченных входах (стабильность BIBO).
### Стабильность на основе шеста
| Состояние | Стабильность |
|-----------|-----------|
| Все полюса в левой полуплоскости (Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) | Нестабильный |
| Полюсы на мнимой оси (Re(s) = 0) | Маргинально стабильный (или нестабильный при повторении) |
### Критерий Рауса-Гурвица
Определяет устойчивость без явного вычисления полюсов. Создает массив Рауса из коэффициентов характеристического полинома.
**Правило:** Количество смен знака в первом столбце равно количеству полюсов правой полуплоскости.
### Критерий устойчивости Найквиста
Показывает частотную характеристику разомкнутого контура L(jω) в комплексной плоскости.
**Правило:** Замкнутая система устойчива, если график Найквиста окружает точку (−1, 0) против часовой стрелки количество раз, равное числу нестабильных полюсов разомкнутой системы.
**Запас усиления:** Насколько может увеличиться усиление до появления нестабильности (расстояние от графика до −1 на реальной оси).
**Запас по фазе:** насколько может увеличиться фазовая задержка до появления нестабильности (угол от графика к единичному кругу при пересечении усиления).
### Анализ графика Боде
На графике отображается усиление (дБ) и фаза (градусы) в зависимости от частоты (логарифмическая шкала).
| Метрическая | Определение | Желаемая стоимость |
|--------|-----------|---------------|
| **Маржа прибыли (GM)** | Увеличение усиления до 0 дБ при фазе = −180° | > 6 дБ |
| **Запас по фазе (PM)** | Фаза при усилении кроссовера (0 дБ) + 180° | > 45° |
| **Усиление пересечения** | Частота, где усиление = 0 дБ | — |
| **Пересечение фаз** | Частота, где фаза = −180° | — |

## Представление в пространстве состояний
Для систем с несколькими входами и несколькими выходами (MIMO) форма пространства состояний более естественна, чем передаточные функции.
### Стандартная форма
ẋ(t) = Ax(t) + Bu(t) (уравнение состояния)
y(t) = Cx(t) + Du(t) (выходное уравнение)
| Матрица | Имя | Размеры |
|--------|------|-----------|
| А | Матрица системы/состояния | п × п |
| Б | Входная матрица | п × м |
| С | Выходная матрица | р × п |
| Д | Проходная матрица | р × м |
### Передаточная функция из пространства состояний
G(s) = C(sI − A)⁻¹B + D
### Управляемость и наблюдаемость
| Недвижимость | Тест | Значение |
|----------|------|---------|
| **Управляемый** | Rank[C_B] = n (где C_B = [B, AB, A²B, ...]) | Может направиться в любое состояние |
| **Наблюдаемое** | Rank[O_B] = n (где O_B = [C; CA; CA²; ...]) | Может определить состояние по выходным данным |
Система должна быть управляемой, чтобы ее можно было стабилизировать с помощью обратной связи, и наблюдаемой для оценки состояния.
### Обратная связь о состоянии
u = −Kx + r (полная обратная связь по состоянию)
Замкнутый контур: ẋ = (A − BK)x + Br
**Размещение полюсов:** Выберите K так, чтобы A − BK имел желаемые собственные значения (полюсы).

## Оптимальное управление
### Линейный квадратичный регулятор (LQR)
Минимизировать: J = ∫₀^∞ (xᵀQx + uᵀRu) dt
где Q ≥ 0 (стоимость государства) и R > 0 (стоимость управления).
**Решение:** u = −Kx, где K = R⁻¹BᵀP, а P решает **алгебраическое уравнение Риккати:**
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
| Тюнинг | Эффект |
|--------|--------|
| Увеличение Q | Более быстрая реакция, больше усилий по контролю |
| Увеличение R | Более медленный ответ, меньше усилий по контролю |
| К ≫ Р | Агрессивный контроль (например, высокий K_p) |
### Фильтр Калмана
Оптимальная оценка состояния для линейных систем с гауссовским шумом.
**Модель системы:**
ẋ = Ax + Bu + w (шум процесса w ~ N(0, Q))
y = Cx + v (шум измерения v ~ N(0, R))
**Уравнения фильтра Калмана:**
- Прогноз: x̂⁻ = Ax̂ + Bu, P⁻ = APAᵀ + Q
- Обновление: K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻¹, x̂ = x̂⁻ + K(y − Cx̂⁻), P = (I − KC)P⁻
Фильтр Калмана является двойным LQR — он минимизирует дисперсию ошибки оценки.

Теория управления — это математика, позволяющая заставить системы делать то, что вы хотите — надежно, устойчиво и эффективно. Его принципы обратной связи, стабильности и оптимальности оказались универсальными, проявляясь в различных областях: от робототехники до обучения с подкреплением, от экономики до биологии. Для специалистов по данным теория управления предоставляет язык для понимания адаптивных систем, разработки стабильных процедур обучения и создания интеллектуальных агентов, взаимодействующих с динамической средой.
