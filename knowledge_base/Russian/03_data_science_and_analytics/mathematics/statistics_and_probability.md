# Статистика и вероятность
Вероятность и статистика — это математические основы науки о данных, машинного обучения и научных исследований. Вероятность говорит вам, насколько вероятны события; Статистика подскажет вам, как делать выводы на основе данных. Вместе они превращают неопределенность в измеримые и управляемые знания.
---

## Теория вероятностей
### Основные понятия
| Концепция | Описание | Пример |
|---------|-------------|---------|
| **Образец пространства** | Набор всех возможных исходов | Бросание кубика: {1, 2, 3, 4, 5, 6} |
| **Событие** | Подмножество выборочного пространства | Выпадение четного числа: {2, 4, 6} |
| **Вероятность** | Число от 0 до 1 для измерения вероятности | P(прокатывается 6) = 1/6 |
| **Условная вероятность** | P(A|B): вероятность события A при условии B произошла | P(дождь | облачно) |
| **Независимость** | События, когда одно не влияет на другое | Подбрасывание монеты независимо |
### Правила вероятности
| Правило | Формула | Вариант использования |
|------|---------|----------|
| **Правило добавления** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | Вероятность A или B |
| **Правило умножения** | P(A ∩ B) = P(A) × P(B|A) | Вероятность A и B |
| **Правило дополнения** | P(не А) знак равно 1 - P(А) | Вероятность того, что событие не произойдет |
| **Закон полной вероятности** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) | Разбиение по взаимоисключающим событиям |
| **Теорема Байеса** | P(A|B) = P(B|A) × P(A) / P(B) | Обновление убеждений доказательствами |
### Распределения вероятностей
| Распространение | Тип | Ключевые параметры | Вариант использования |
|-------------|------|----------------|----------|
| **Нормальный (Гауссовский)** | Непрерывный | Среднее значение (μ), стандартное отклонение (σ) | Природные явления, ошибки измерений |
| **Биномиальный** | Дискретный | n (испытания), p (вероятность) | Успех/неудача имеет значение |
| **Пуассон** | Дискретный | λ (ставка) | Редкие события во времени/пространстве |
| **Экспоненциальный** | Непрерывный | λ (ставка) | Время между событиями |
| **Униформа** | Оба | а, б (границы) | Равновероятные исходы |
| **Хи-квадрат** | Непрерывный | k (степени свободы) | Тесты на соответствие |
| **t-распределение** | Непрерывный | ν (степени свободы) | Вывод по небольшой выборке |
### Ключевые свойства дистрибутивов
| Недвижимость | Описание |
|----------|-------------|
| **Среднее (ожидаемое значение)** | Центр масс распределения: E[X] = Σ xᵢ × P(xᵢ) |
| **Отклонение** | Разброс вокруг среднего значения: Var(X) = E[(X − µ)²] |
| **Стандартное отклонение** | Квадратный корень дисперсии; те же единицы, что и данные |
| **Асимметрия** | Асимметрия распределения |
| **Куртосис** | «Хвостатость» — насколько тяжелы хвосты |

## Статистический вывод
### Описательная статистика против логической статистики
| | Описательный | Выводы |
|---|-------------|-------------|
| **Цель** | Обобщение и описание данных | Сделайте выводы о населении по выборке |
| **Инструменты** | Среднее значение, медиана, мода, стандартное отклонение, графики | Проверка гипотез, доверительные интервалы, регрессия |
| **Объем** | Только те данные, которые у вас есть | Обобщение за пределами выборки |
### Платформа проверки гипотез
| Шаг | Описание |
|------|-------------|
| 1. **Гипотезы состояния** | Нулевая гипотеза (H₀): нет эффекта; Альтернатива (H₁): эффект существует |
| 2. **Выберите уровень значимости** | α = 0,05 (условное) |
| 3. **Выбрать тест** | На основе типа данных, размера выборки и предположений |
| 4. **Рассчитать статистику тестирования** | Зависит от выбранного теста |
| 5. **Найти значение p** | Вероятность наблюдения данных, если H₀ истинно |
| 6. **Принимайте решение** | Если p < α, отклоните H₀; в противном случае не удастся отклонить H₀ |
### Общие статистические тесты
| Тест | Когда использовать | Что сравнивает |
|------|-------------|-----------------|
| **Т-тест** | Сравнить средние значения 1–2 групп | Сгруппировать средние значения по отношению к значению или друг к другу |
| **Тест хи-квадрат** | Категориальные данные | Наблюдаемые и ожидаемые частоты |
| **АНОВА** | Сравните средние значения 3+ групп | Межгрупповая и внутригрупповая дисперсия |
| **Манн-Уитни Ю** | Непараметрическая альтернатива t-критерию | Ранговые распределения двух групп |
| **Корреляция Пирсона** | Линейная связь между двумя непрерывными переменными | значение r от −1 до +1 |
| **Корреляция Спирмена** | Монотонные отношения (ранговые) | Значение ρ для порядковых или ненормальных данных |
### Доверительные интервалы
Доверительный интервал дает диапазон вероятных значений параметра совокупности:
- **95% ДИ для среднего значения** (известное σ): x̄ ± 1,96 × (σ / √n)
- **Интерпретация**: «Мы на 95 % уверены, что истинное среднее значение генеральной совокупности лежит в этом интервале».
- **Более широкий ДИ** = большая неопределенность (меньшая выборка, более высокая вариабельность или более высокий уровень достоверности)

## Регрессионный анализ
### Типы регрессии
| Тип | Зависимая переменная | Вариант использования |
|------|-------------------|----------|
| **Линейная регрессия** | Непрерывный | Прогнозирование цен на жилье, продаж |
| **Логистическая регрессия** | Двоичный (0/1) | Классификация: обнаружение спама, диагностика заболеваний |
| **Полиномиальная регрессия** | Непрерывный (изогнутый) | Кривые роста, нелинейные тенденции |
| **Множественная регрессия** | Непрерывный (2+ предикторов) | Контроль за мешающими факторами |
| **Ридж/Лассо** | Непрерывный (регуляризованный) | Предотвращение переобучения, выбор функций |
### Основы линейной регрессии
Модель: **y = β₀ + β₁x + ε**
| Компонент | Значение |
|-----------|---------|
| β₀ (перехват) | Значение y, когда x = 0 |
| β₁ (наклон) | Изменение y при изменении x на одну единицу |
| ε (член ошибки) | Необъяснимая вариация |
**Основные показатели:**
- **R² (коэффициент детерминации)**: доля дисперсии, объясняемая моделью (от 0 до 1).
- **Скорректированный R²**: R² штрафуется за количество предикторов.
- **RMSE**: Среднеквадратическая ошибка — средняя ошибка прогноза в тех же единицах, что и y.
### Предположения линейной регрессии
| Успение | Что это значит | Как проверить |
|-----------|--------------|--------------|
| **Линейность** | Связь между X и Y линейна | Диаграммы рассеяния |
| **Независимость** | Наблюдения независимые | Дизайн исследования |
| **Гомоскедастичность** | Постоянная дисперсия остатков | Остаточные участки |
| **Нормальность** | Остатки нормально распределены | График Q-Q, тест Шапиро-Уилка |
| **Нет мультиколлинеарности** | Предикторы не сильно коррелируют | VIF (коэффициент инфляции дисперсии) |

## Байесовская статистика
### Частотный против байесовского
| | Частый посетитель | Байесовский |
|---|-------------|----------|
| **Вероятность означает** | Долгосрочная частота | Степень веры |
| **Параметры** | Исправлено, но неизвестно | Случайные величины с распределениями |
| **Применение** | p-значения, доверительные интервалы | Апостериорные распределения, достоверные интервалы |
| **Сильные стороны** | Объективный, хорошо зарекомендовавший себя | Включает предварительные знания, интуитивную интерпретацию |
### Теорема Байеса на практике
**Апостериорный = (Вероятность × Априорный) / Доказательства**
Пример — медицинское обследование:
- Распространенность заболевания: 1% (ранее)
- Чувствительность теста: 95% (истинно положительный уровень)
- Специфичность теста: 90% (истинно отрицательный показатель)
- Если у вас положительный результат теста: P(болезнь | положительный) = (0,95 × 0,01) / (0,95 × 0,01 + 0,10 × 0,99) ≈ 8,8%
Этот противоречивый результат (большинство положительных результатов являются ложноположительными, когда заболевание встречается редко) — это **ошибка базовой оценки**, и он показывает, почему байесовское мышление имеет значение.

## Практические советы
- **Всегда визуализируйте свои данные** перед выполнением любого статистического теста.
– **Проверьте предположения**: нарушения могут сделать результаты недействительными.
- **Размер эффекта имеет значение** — статистически значимый результат может оказаться практически бессмысленным.
- **Корреляция не является причинно-следственной связью** — даже сильные корреляции могут иметь сбивающие с толку факторы.
– **Множественные сравнения** повышают уровень ложноположительных результатов — внесите поправки (Бонферрони, Рузвельт).
– **Сообщайте о доверительных интервалах**, а не только о p-значениях.

## Почему это важно
Статистика является основой научных исследований, бизнес-аналитики и машинного обучения. Без него вы не сможете отличить сигнал от шума, выявить реальные эффекты от случайных флуктуаций или сделать прогнозы с количественной неопределенностью. Независимо от того, анализируете ли вы A/B-тесты, тренируете модели машинного обучения или читаете научные статьи, статистическая грамотность имеет важное значение.
