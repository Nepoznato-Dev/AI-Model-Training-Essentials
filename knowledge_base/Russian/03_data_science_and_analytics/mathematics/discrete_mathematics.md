# Дискретная математика
Дискретная математика — это изучение математических структур, которые по своей сути являются счетными или разделенными — в отличие от непрерывной математики (исчисления, реального анализа), которая имеет дело с гладкими, непрерывными величинами. Дискретная математика лежит в основе информатики, криптографии, разработки алгоритмов и структур данных. Если непрерывная математика описывает физический мир, то дискретная математика описывает вычислительный мир.

## Теория множеств в глубине
Множества — это фундамент, на котором построена почти вся современная математика. **Набор** – это неупорядоченная коллекция отдельных объектов, называемых **элементами** или **членами**.
### Аксиоматические основы (ZFC)
Современная теория множеств опирается на **аксиомы Цермело-Френкеля с аксиомой выбора (ZFC)**. Эти аксиомы разрешают такие парадоксы, как парадокс Рассела («множество всех множеств, которые не содержат самих себя»), ограничивая способы формирования множеств.
| Аксиома | Неофициальное заявление |
|-------|--------------------|
| Экстенсиональность | Два множества равны тогда и только тогда, когда они состоят из одних и тех же элементов |
| Пустой набор | Существует множество без элементов: ∅ |
| Сопряжение | Для любых a, b существует {a, b} |
| Союз | Для любого семейства множеств существует их объединение |
| Набор мощности | Для любого множества S существует множество всех его подмножеств: P(S) |
| Бесконечность | Существует бесконечное множество |
| Спецификация | Для любого множества A и свойства P существует {x ∈ A : P(x)} |
| Замена | Образ множества при определимой функции есть множество |
| Регулярность | Каждое непустое множество содержит непересекающийся с ним элемент (предотвращает самочленство) |
| Выбор | Для любого семейства непустых попарно непересекающихся множеств существует функция выбора |
### Мощность и размер наборов
**Мощность** множества, обозначаемая |S|, измеряет его «размер».
| Концепция | Определение | Пример |
|---------|------------|---------|
| Конечный набор | Имеет натуральное число по мощности | |{а, б, в}| = 3 |
| Счетная бесконечность | Та же мощность, что и ℕ | ℤ, ℚ счетно бесконечны |
| Бесчисленное | Больше, чем ℕ | ℝ, P(ℕ), множество всех функций ℕ → {0,1} |
| Теорема Кантора | Для любого множества S |P(S)| > |С| | |П(ℕ)| > |ℕ| |
**Диагональный аргумент Кантора** доказывает, что ℝ несчетен: предположим, что вы можете перечислить все действительные числа в [0,1], затем построить новое числовое число, которое отличается от n-го перечисленного вещественного числа в n-м десятичном знаке — противоречие.
### Операции с множествами
| Операция | Обозначение | Определение | Недвижимость |
|-----------|----------|------------|----------|
| Союз | А ∪ Б | {x : x ∈ A или x ∈ B} | Коммутативный, ассоциативный |
| Пересечение | А ∩ Б | {x : x ∈ A и x ∈ B} | Коммутативный, ассоциативный |
| Разница | А \ Б | {x : x ∈ A и x ∉ B} | Не коммутативен |
| Симметричная разница | А △ Б | (А \ В) ∪ (В \ А) | Коммутативный, ассоциативный |
| Дополнить | Аᶜ | U \ A (где U — универсальное множество) | (Aᶜ)ᶜ = А |
| Декартово произведение | А × Б | {(a,b) : a ∈ A, b ∈ B} | |А × Б| = |А| · |Б| |
**Законы де Моргана:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (А ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**Принцип включения-исключения** (для конечных множеств):
|А₁ ∪ А₂ ∪ ... ∪ Аₙ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|

## Отношения
**Отношение** R на множествах A и B является подмножеством A × B. Когда (a, b) ∈ R, мы пишем aRb.
### Типы отношений
Отношение R на множестве A может иметь следующие свойства:
| Недвижимость | Определение | Пример |
|----------|------------|---------|
| Рефлексивный | ∀a ∈ A: aRa | ≤ на ℤ |
| Иррефлексивный | ∀a ∈ A: ¬(aRa) | < на ℤ |
| Симметричный | ∀a,b: aRb → bRa | = на любом множестве |
| Антисимметричный | ∀a,b: aRb ∧ bRa → a = b | ≤ на ℤ |
| Переходный | ∀a,b,c: aRb ∧ bRc → aRc | <, ≤, = на ℤ |
### Отношения эквивалентности
**Отношение эквивалентности** рефлексивно, симметрично и транзитивно. Он разбивает множество на непересекающиеся **классы эквивалентности**.
**Пример:** Модульная арифметика. Определим a ~ b тогда и только тогда, когда a ≡ b (mod n). Классами эквивалентности являются [0], [1], ..., [n−1], которые разбивают ℤ на n классов.
**Рабочий пример:** Для ℤ × ℤ определите (a,b) ~ (c,d), если и только если a + d = b + c. Это отношение эквивалентности. Класс [(0,0)] = {(n,n) : n ∈ ℤ}. Класс [(1,0)] = {(n+1,n) : n ∈ ℤ}. Эта конструкция фактически определяет целые числа из натуральных чисел.
### Частичные заказы
**Частичный порядок** является рефлексивным, антисимметричным и транзитивным. Набор с частичным порядком называется **частично упорядоченным набором (poset)**.
| Концепция | Определение | Пример |
|---------|------------|---------|
| Посет | (S, ≤) с ≤ частичным порядком | (P(A), ⊆) — подмножества, упорядоченные по включению |
| Цепь | Полностью упорядоченное подмножество | {∅, {a}, {a,b}} в P({a,b,c}) |
| Античейн | Подмножество, в котором нет двух сопоставимых элементов | {{a}, {b}} в P({a,b}) |
| Диаграмма Хассе | Визуальное представление частичного набора | Рисовать ребра только для закрывающих отношений |
| Верхняя граница | Элемент ≥ каждый элемент в подмножестве | суп({2,3}) = 6 в (ℤ, \|) (делимость) |
| Наименьшая верхняя граница (up) | Наименьшая верхняя граница | суп({2,3}) в (ℕ, ≤) равен 3 |
| Наибольшая нижняя граница (inf) | Наибольшая нижняя граница | inf({4,6}) в (ℕ, \|) равно 2 |

## Функции
A **функция** f: A → B присваивает каждому элементу A ровно один элемент B.
### Классификация функций
| Тип | Определение | Пример |
|------|------------|---------|
| Инъективный (один-к-одному) | е(а) = е(б) → а = б | f(x) = 2x из ℤ → ℤ |
| Сюръективный (на) | ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x mod 2 из ℤ → {0,1} |
| Биективный | И инъективное, и сюръективное | f(x) = x + 1 из ℤ → ℤ |
### Важные функциональные понятия
| Концепция | Определение | Вариант использования |
|---------|------------|----------|
| Обратная функция | f⁻¹ существует тогда и только тогда, когда f биективен | Расшифровка зашифрованных данных |
| Состав | (г ∘ е)(х) = г(е(х)) | Цепные преобразования |
| Функция идентичности | идентификатор (х) = х | Нейтральный элемент композиции |
| Фиксированная точка | е(х) = х | Рекурсивные определения, семантика |
| Перестановка | Биекция множества в себя | Перестановка данных, перетасовка |
### Счетные функции
Учитывая конечные множества |A| = m и |B| = н:
| Тип | Граф |
|------|-------|
| Все функции А → Б | нᵐ |
| Инъективные функции | н! / (н-м)! (если n ≥ m, иначе 0) |
| Сюръективные функции | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ (путем включения-исключения) |
| Биективные функции | н! (когда м = п) |

## Комбинаторика
Комбинаторика – это математика счета, расположения и выбора.
### Основные принципы подсчета
| Принцип | Заявление | Пример |
|-----------|-----------|---------|
| Правило суммы | Если A и B не пересекаются, |A ∪ B| = |А| + |Б| | Выбор фрукта: 3 яблока + 4 апельсина = 7 вариантов |
| Правило продукта | |А × Б| = |А| · |Б| | Экипировка: 3 рубашки × 4 брюк = 12 нарядов |
| Правило биекции | Если f: A → B — биекция, |A| = |В| | Подсчет подмножеств путем подсчета двоичных строк |
| Дополнить | |А| = |У| − |Аᶜ| | Посчитайте «хотя бы один» как общее количество минус «нет» |
### Перестановки и комбинации
| Обозначение | Имя | Формула | Значение |
|----------|------|---------|---------|
| C(n, k) или (n k) | Биномиальный коэффициент | н! / (к!(n−k)!) | Способы выбрать k предметов из n (порядок не имеет значения) |
| Р(п, к) | k-перестановки n | н! / (n−k)! | Способы расположить k предметов из n (порядок имеет значение) |
| н! | Факториал | п × (n−1) × ... × 1 | Способы расстановки всех n предметов |
| (n k) с повторением | Мультивыбор | C(n+k−1, k) | Выберите k из n с допустимым повторением |
**Биномиальная теорема:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**Тождество Паскаля:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### Принцип «ячейки»
**Основная форма:** Если n+1 объект помещен в n ящиков, то хотя бы один ящик содержит ≥ 2 объектов.
**Общая форма:** Если N объектов помещены в k ящиков, то хотя бы один ящик содержит ≥ ⌈N/k⌉ объектов.
**Работающие примеры:**
1. Среди любых 13 человек как минимум двое имеют одинаковый месяц рождения. (13 человек, 12 месяцев → ячейка.)
2. Докажите, что среди любых 5 целых чисел найдутся 3, сумма которых делится на 3.
   - Рассмотрим остатки по модулю 3: {0, 1, 2}. При 5 целых числах и 3 классах остатков по обобщенной классификации по крайней мере ⌈5/3⌉ = 2 имеют общий остаток.
   - Если 3 имеют общий остаток r: их сумма ≡ 3r ≡ 0 (по модулю 3).
   - Если 2 разделяют остаток 0 и 2 разделяют остаток 1: выберите по одному из каждой пары плюс элемент остатка-0 → сумма ≡ 0 (модуль 3).
3. **Применение в CS:** Любой алгоритм сжатия без потерь должен расширять некоторые входные данные. (Если каждая n-битная строка сжата до <n бит, вы отобразите 2ⁿ строки в менее чем 2ⁿ сжатые строки, что нарушает инъективность.)
### Каталонские цифры
Энное **каталонское число** Cₙ = C(2n, n) / (n+1) считается:
| Структура | Пример |
|-----------|---------|
| Допустимые последовательности в скобках | ()(), (()) для n = 2 |
| Бинарные деревья с n внутренними узлами | 2 дерева для n = 2 |
| Пути, не пересекающие диагональ | Пути сетки от (0,0) до (n,n), остающиеся ниже y = x |
| Триангуляции многоугольника | Способы разбить (n+2)-угольник на треугольники |
Первые несколько: C₀ = 1, C₁ = 1, C₂ = 2, C₃ = 5, C₄ = 14, C₅ = 42.
Повторение: Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## Рекуррентные отношения
**Рекуррентное отношение** определяет каждый член последовательности как функцию предыдущих членов.
### Типы и решения
| Тип | Форма | Метод решения |
|------|------|-----------------|
| Линейно-однородный (постоянный коэффициент) | aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ | Характеристическое уравнение |
| Линейная неоднородная | аₙ = c₁aₙ₋₁ + ... + f(n) | Частное решение + гомогенный раствор |
| Разделяй и властвуй | Т(п) = аТ(п/б) + е(п) | Основная теорема |
### Метод характеристического уравнения
Для aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ составим характеристическое уравнение:
r² - c₁r - c₂ = 0
| Дело | Корни | Общее решение |
|------|-------|------------------|
| Два различных действительных корня r₁, r₂ | р₁ ≠ р₂ | аₙ = А·r₁ⁿ + B·r₂ⁿ |
| Повторный корень г | р₁ знак равно р₂ знак равно р | аₙ = (А + Bn)·rⁿ |
| Комплексные корни α ± βi | Преобразовать в полярную форму: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**Работающий пример:** последовательность Фибоначчи Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1.
- Характеристическое уравнение: r² − r − 1 = 0
- Корни: r = (1 ± √5)/2 → φ = (1+√5)/2 ≈ 1,618, ψ = (1−√5)/2 ≈ −0,618.
- Общее решение: Fₙ = A·φⁿ + B·ψⁿ
- Из начальных условий: A = 1/√5, B = −1/√5.
- **Закрытая форма:** Fₙ = (φⁿ − ψⁿ) / √5 (формула Бине)
### Главная теорема
Для повторений вида T(n) = aT(n/b) + f(n), где a ≥ 1, b > 1:
Пусть c = log_b(a).
| Дело | Состояние | Решение |
|------|-----------|----------|
| 1 | f(n) = O(nᵈ), где d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c, и af(n/b) ≤ kf(n) для некоторого k < 1 | Т(п) = Θ(пᵈ) |
**Примеры:**
- Сортировка слиянием: T(n) = 2T(n/2) + O(n). Здесь a=2, b=2, c=1, f(n)=n=Θ(n¹). Случай 2: T(n) = Θ(n log n).
- Бинарный поиск: T(n) = T(n/2) + O(1). Здесь a=1, b=2, c=0, f(n)=1=Θ(n⁰). Случай 2: T(n) = Θ(log n).

## Генерирующие функции
**Производящая функция** кодирует последовательность (aₙ) как коэффициенты формального степенного ряда.
### Типы
| Тип | Форма | Вариант использования |
|------|------|----------|
| Обычный (OGF) | G(x) знак равно Σₙ₌₀^∞ аₙxⁿ | Немеченые структуры, композиции |
| Экспонента (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n! | Меченые структуры, перестановки |
### Общие генерирующие функции
| Последовательность aₙ | ОГФ G(x) |
|-------------|-----------|
| 1, 1, 1, 1, ... | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² |
| 1, р, р², р³, ... | 1/(1−rx) |
| C(n,k) при фиксированном k | xᵏ/(1−x)ᵏ⁺¹ |
| Фибоначчи Fₙ | х/(1-x-x²) |
| Каталанский Cₙ | (1 − √(1−4x)) / (2x) |
### Использование порождающих функций для решения повторений
**Рабочий пример:** Решите aₙ = 3aₙ₋₁ − 2aₙ₋₂, a₀ = 1, a₁ = 3.
1. Пусть G(x) = Σ aₙxⁿ.
2. Из рекуррентности: G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. Заменить: G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. Частные дроби: G(x) = 2/(1−2x) − 1/(1−x)
7. Извлечь коэффициенты: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺¹ − 1.
**Проверка:** a₀ = 2−1 = 1, a₁ = 4−1 = 3, a₂ = 8−1 = 7. Проверка: 3(3) − 2(1) = 7.

## Булева алгебра и логика высказываний
Булева алгебра — это алгебра двух истинностных значений: **Истина (1)** и **Ложь (0)**. Это математическая основа цифровых схем, запросов к базам данных и условий программирования.
### Операции и законы
| Операция | Символ | Значение | Таблица истинности |
|-----------|--------|---------|-------------|
| И | п ∧ q | Верно только тогда, когда оба верны | Т∧Т=Т, Т∧F=F, F∧T=F, F∧F=F |
| ИЛИ | п ∨ q | Истинно, если хотя бы одно истинно | Т∨Т=Т, Т∨F=Т, Ф∨Т=Т, F∨F=F |
| НЕ | ¬п | Отрицание | ¬T=F, ¬F=T |
| ИСКЛЮЧАЮЩЕЕ ИЛИ | п ⊕ q | Правда, когда верно только одно | Т⊕Т=Ф, Т⊕Ф=Т, Ф⊕Т=Т, Ф⊕Ф=Ф |
| ПОДРАЗУМЕВАЕТ | п → д | Ложь только тогда, когда p=T и q=F | Т→Т=Т, Т→Ж=Ж, Ф→Т=Т, Ф→Ж=Т |
| ДВУУСЛОВНЫЙ | п ↔ q | Истинно, когда оба имеют одинаковое значение | Т↔Т=Т, Т↔F=F, F↔T=F, F↔F=T |
### Ключевые логические идентификаторы
| Закон | Формула |
|-----|--------|
| Коммутативность | п ∧ q = q ∧ р; п ∨ q знак равно q ∨ п |
| Ассоциативность | (p ∧ q) ∧ r знак равно p ∧ (q ∧ r) |
| Дистрибутивность | п ∧ (q ∨ r) знак равно (p ∧ q) ∨ (p ∧ r) |
| Законы де Моргана | ¬(p ∧ q) = ¬p ∨ ¬q; ¬(p ∨ q) = ¬p ∧ ¬q |
| Двойное отрицание | ¬(¬p) = р |
| Идемпотентность | р ∧ р = р; п ∨ п знак равно п |
| Поглощение | р ∨ (р ∧ q) = р; п ∧ (п ∨ q) знак равно п |
| Контрапозитивный | (p → q) ≡ (¬q → ¬p) |
### Нормальные формы
| Форма | Структура | Вариант использования |
|------|-----------|----------|
| Конъюнктивная нормальная форма (КНФ) | И ОР: (A∨B) ∧ (C∨D) | Решатели SAT, доказательство теорем разрешения |
| Дизъюнктивная нормальная форма (ДНФ) | ИЛИ операторов AND: (A∧B) ∨ (C∧D) | Схемотехника, системы, основанные на правилах |
**Преобразование в CNF:** Примените законы Де Моргана, распределите OR над AND, устраните двойные отрицания.

## Модульная арифметика и сравнения
Модульная арифметика изучает целые числа под действием операции «остаток после деления». Это важно для криптографии, хеширования и теории чисел.
### Основные определения
| Концепция | Обозначение | Определение |
|---------|----------|------------|
| Конгруэнтность | а ≡ б (модуль п) | n делит (a − b) |
| Класс остатка | [а]ₙ | Множество {a + kn : k ∈ ℤ} |
| Модульный инверсный | a⁻¹ мод n | Значение x такое, что ax ≡ 1 (mod n) |
| Тотент Эйлера | φ(п) | Подсчет целых чисел в {1,...,n}, взаимно простых с n |
### Ключевые свойства
| Недвижимость | Заявление |
|----------|----------|
| Дополнение | Если a ≡ b и c ≡ d (mod n), то a+c ≡ b+d (mod n) |
| Умножение | Если a ≡ b и c ≡ d (mod n), то ac ≡ bd (mod n) |
| Маленькая теорема Ферма | Если p простое число и НОД(a,p) = 1, то aᵖ⁻¹ ≡ 1 (mod p) |
| Теорема Эйлера | Если НОД(a,n) = 1, то a^φ(n) ≡ 1 (mod n) |
| Китайская теорема об остатках | Если НОД(m,n) = 1, система x ≡ a (mod m), x ≡ b (mod n) имеет единственное решение mod mn |
### Вычисление тотента Эйлера
Для n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ (простая факторизация):
φ(n) = n · (1 - 1/p₁) · (1 - 1/p₂) · ... · (1 - 1/pₖ)
**Пример:** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4. Действительно, {1, 5, 7, 11} взаимно просты с 12.
### Приложение: криптография RSA (обзор)
1. Выберите большие простые числа p, q. Вычислите n = pq, φ(n) = (p−1)(q−1).
2. Выберите e такое, что НОД(e, φ(n)) = 1 (публичный показатель).
3. Вычислить d ≡ e⁻¹ (mod φ(n)) (частный показатель).
4. Зашифровать: c = mᵉ mod n. Расшифруйте: m = cᵈ mod n.
5. Безопасность зависит от сложности факторизации n для нахождения p и q.

## Математическая индукция
**Математическая индукция** – это основной метод доказательства утверждений обо всех натуральных числах.
### Структура доказательства по индукции
1. **Базовый случай:** Докажите утверждение для n = 0 (или n = 1).
2. **Шаг индукции.** Предположим, что утверждение верно для n = k (индуктивное предположение), затем докажем его для n = k + 1.
### Варианты
| Вариант | Когда использовать |
|---------|-------------|
| Простая индукция | Докажите P(k) → P(k+1) |
| Сильная индукция | Предположим, P(0), P(1), ..., P(k), чтобы доказать P(k+1) |
| Структурная индукция | Доказать свойства рекурсивно определенных структур (деревьев, формул) |
| Трансфинитная индукция | Распространите индукцию на хорошо упорядоченные множества за пределами ℕ |
**Рабочий пример (сильная индукция):** Докажите, что каждое целое число n ≥ 2 можно записать в виде произведения простых чисел.
- Основание: n = 2 — простое число, поэтому оно является произведением простых чисел (само по себе).
- Индуктивный шаг: предположим, что верно для всех целых чисел от 2 до k. Рассмотрим k+1.
  - Если k+1 простое, готово.
  - Если k+1 составное, k+1 = ab, где 2 ≤ a, b ≤ k. По индуктивному предположению и a, и b являются произведениями простых чисел, поэтому k+1 является произведением простых чисел.
