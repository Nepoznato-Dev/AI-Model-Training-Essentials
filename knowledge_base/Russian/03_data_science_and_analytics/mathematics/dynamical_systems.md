# Динамические системы
**Динамическая система** описывает, как государство развивается с течением времени в соответствии с фиксированным правилом. От орбит планет до динамики населения, от погодных условий до обучения нейронных сетей — теория динамических систем предоставляет язык и инструменты для понимания того, как все меняется. Этот файл охватывает обыкновенные дифференциальные уравнения (ОДУ), уравнения в частных производных (УЧП), анализ устойчивости, хаос и бифуркации.
---

## Обыкновенные дифференциальные уравнения (ОДУ)
ОДУ связывает функцию с ее производными относительно одной независимой переменной (обычно времени).
### Классификация
| Недвижимость | Типы |
|----------|-------|
| **Заказать** | Присутствует высшая производная (1-го порядка, 2-го порядка и т. д.) |
| **Линейный и нелинейный** | Линейная: y'' + p(t)y' + q(t)y = g(t); Нелинейное: что-нибудь еще |
| **Однородный** | g(t) = 0 (без принудительных условий) |
| **Автономный** | Нет явной зависимости от времени: dy/dt = f(y) |
| **Постоянные коэффициенты** | p, q — константы |
### ОДУ первого порядка
**Общая форма:** dy/dt = f(t, y)
| Тип | Форма | Метод решения |
|------|------|-----------------|
| Разъемный | dy/dt = г(т)ч(у) | Разделим и проинтегрируем: ∫dy/h(y) = ∫g(t)dt |
| Линейный первого порядка | dy/dt + p(t)y = q(t) | Интегрирующий коэффициент: µ(t) = e^(∫p dt) |
| Точный | M(t,y)dt + N(t,y)dy = 0 с ∂M/∂y = ∂N/∂t | Найти потенциальную функцию F(t,y) |
| Бернулли | dy/dt + p(t)y знак равно q(t)yⁿ | Замените v = y^(1−n), чтобы линеаризовать |
**Рабочий пример (интегрирующий коэффициент):** Решите dy/dt + 2y = e^(-t), y(0) = 1.
- Интегрирующий коэффициент: µ(t) = e^(∫2 dt) = e^(2t)
- Умножить: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- Интегрировать: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- Начальное условие: y(0) = 1 → 1 = 1 + C → C = 0.
- Решение: y(t) = e^(−t)
### Линейные ОДУ второго порядка
**Общая форма:** ay'' + by' + cy = g(t)
**Однородный случай** (g ​​= 0): Решите характеристическое уравнение ar² + br + c = 0.
| Дискриминант | Корни | Общее решение |
|-------------|-------|------------------|
| b² > 4ac (с чрезмерным демпфированием) | Два различных действительных r₁, r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (критическое затухание) | Повторный вещественный корень r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (недостаточное демпфирование) | Комплексные корни α ± βi | y знак равно е^(αt)(C₁ потому что βt + C₂ грех βt) |
**Физическая интерпретация:** Система масса-пружина-демпфер mx'' + bx' + kx = 0.
- Чрезмерное демпфирование: сильное демпфирование, отсутствие колебаний (доводчик)
- Критическое демпфирование: самый быстрый возврат без колебаний (цель конструкции подвески автомобиля)
- Недостаточное демпфирование: колеблется с затухающей амплитудой (гитарная струна)
### Системы ОДУ
Многие реальные системы включают в себя несколько взаимодействующих переменных:
dx/dt = f(x, y)
dy/dt = g(x, y)
Это можно записать в векторной форме: d**x**/dt = **F**(**x**)
**Линейные системы:** d**x**/dt = A**x**, где A — матрица.
Решение зависит от собственных значений A:
| Собственные значения | Поведение |
|-------------|-----------|
| Оба реальные, отрицательные | Стабильный узел (все траектории сходятся к началу координат) |
| Оба настоящие, позитивные | Нестабильный узел |
| Реальные, противоположные знаки | Седловая точка (неустойчивая) |
| Комплексная, отрицательная действительная часть | Стабильная спираль (затухающие колебания) |
| Сложная, положительная действительная часть | Нестабильная спираль |
| Чисто воображаемый | Центр (замкнутые орбиты) |

## Фазовые портреты
**Фазовый портрет** визуализирует траектории динамической системы в пространстве состояний (без явного решения).
### Ключевые особенности
| Особенность | Описание |
|---------|-------------|
| **Фиксированная точка (равновесие)** | Где dx/dt = 0 (нет движения) |
| **Траектория** | Путь, проходимый системой в пространстве состояний |
| **Нулевой клин** | Кривая, где производная одного компонента равна нулю |
| **Предельный цикл** | Изолированная замкнутая орбита (автоколебания) |
| **Бассейн притяжения** | Набор начальных условий, приводящих к заданному аттрактору |
| **Сепаратриса** | Граница между различными бассейнами притяжения |
### Модель Хищник-Жертва (Лотка-Вольтерра)
dx/dt = αx − βxy (добыча)
dy/dt = δxy − γy (хищник)
**Фиксированные точки:**
1. (0, 0) — угасание (седлая точка)
2. (γ/δ, α/β) — сосуществование (центр — замкнутые орбиты)
Система демонстрирует периодические колебания: количество добычи увеличивается → количество хищников увеличивается → количество добычи уменьшается → количество хищников уменьшается → цикл повторяется.

## Анализ стабильности
### Линейная стабильность
Для фиксированной точки x* выполните линеаризацию вокруг нее: пусть u = x − x*, тогда du/dt ≈ J(x*)u, где J — матрица Якоби.
**Критерий стабильности:** Фиксированная точка:
- **Стабильный**, если все собственные значения J имеют отрицательные действительные части.
- **Нестабилен**, если какое-либо собственное значение имеет положительную действительную часть.
- **Маргинально стабильный**, если собственные значения имеют нулевую действительную часть (требуется нелинейный анализ)
###Ляпунов Стабильность
**Прямой метод Ляпунова** определяет устойчивость без линеаризации.
**Функция Ляпунова** V(x) удовлетворяет:
1. V(x*) = 0 и V(x) > 0 при x ≠ x* (положительно определённый)
2. dV/dt ≤ 0 вдоль траекторий (невозрастающая)
| Состояние | Заключение |
|-----------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | Нестабильный |
**Работающий пример:** Система dx/dt = −x + y², dy/dt = −y.
- Попробуйте V(x,y) = x² + y² (энергетическая функция)
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- Около начала координат: dV/dt ≈ −2x² − 2y² < 0 (для малых y доминирует −2y²)
- Вывод: начало координат локально асимптотически устойчиво.

## Теория хаоса
**Хаос** детерминирован, но непредсказуем: система следует точным правилам, но малейшие различия в начальных условиях приводят к совершенно разным результатам.
### Требования для Хаоса
| Недвижимость | Описание |
|----------|-------------|
| Детерминированный | Никакой случайности — все подчиняется точным уравнениям |
| Чувствителен к начальным условиям | Близлежащие траектории расходятся экспоненциально |
| Ограниченный | Траектории не уходят в бесконечность |
| Непериодический | Никогда не повторяется в точности |
### Система Лоренца
Классический пример детерминированного хаоса:
dx/dt = σ(y − x)
dy/dt = x(ρ - z) - y
dz/dt = xy − βz
При стандартных параметрах σ = 10, ρ = 28, β = 8/3:
- Система имеет три фиксированные точки, все нестабильные.
- Траектории вращаются вокруг одной фиксированной точки, а затем внезапно переключаются на другую.
- В результате получился **аттрактор Лоренца** — странный аттрактор с фрактальной структурой.
**Показатель Ляпунова:** измеряет скорость расхождения ближайших траекторий.
- Положительный показатель Ляпунова → хаос
- Для системы Лоренца со стандартными параметрами: наибольший показатель степени ≈ 0,9 > 0.
### Логистическая карта
Простая дискретная система, демонстрирующая хаос:
x_{n+1} = rx_n(1 − x_n)
| Параметр г | Поведение |
|-------------|-----------|
| 0 < г < 1 | Население вымирает (x → 0) |
| 1 < г < 3 | Устойчивая неподвижная точка при x = 1 − 1/r |
| 3 < г < 3,449 | Колебания периода-2 |
| 3,449 < г < 3,544 | Колебания периода 4 |
| 3,544 < г < 3,570 | Период-8, 16, 32, ... (каскад удвоения периода) |
| р ≈ 3,570 | Наступление хаоса |
| 3,570 < г < 4 | Преимущественно хаотичный, с периодическими окнами |
| р = 4 | Полностью хаотичен на [0, 1] |
### Эффект бабочки
Популярное название чувствительной зависимости от начальных условий. В погодных системах (моделируемых уравнениями Лоренца) взмах крыльев бабочки в Бразилии может вызвать торнадо в Техасе — не потому, что его вызывает бабочка, а потому, что крошечные возмущения растут в геометрической прогрессии.

## Теория бифуркации
**Бифуркация** — это качественное изменение поведения системы при изменении параметра.
### Типы бифуркаций
| Бифуркация | Нормальная форма | Что происходит |
|-------------|-------------|--------------|
| **Седло-узел** | dx/dt = r − x² | Появляются/исчезают две фиксированные точки |
| **Транскритический** | dx/dt = rx − x² | Две фиксированные точки обменной стабильности |
| **Вилы (сверхкритический)** | dx/dt = rx - x³ | Одна стабильная точка распадается на две стабильные + одну нестабильную |
| **Вилы (докритический)** | dx/dt = rx + x³ | Нестабильные ветви обрушиваются (часто катастрофически) |
| **Хопф** | 2D-система | Фиксированная точка становится нестабильной, появляется предельный цикл |
### Бифуркационная диаграмма
График зависимости фиксированных точек от значения параметра, показывающий стабильность (сплошная линия = стабильная, пунктирная = нестабильная). Бифуркационная диаграмма логистической карты показывает путь удвоения периода к хаосу и знаменитую **константу Фейгенбаума** δ ≈ 4,669 (универсальное соотношение между последовательными бифуркационными интервалами).

## Уравнения в частных производных (ЧДУ)
УЧП включают функции нескольких переменных и их частные производные.
### Классификация линейных УЧП второго порядка
Для Au_xx + 2Bu_xy + Cu_yy + ... = 0:
| Тип | Состояние | Поведение | Пример |
|------|-----------|-----------|---------|
| **Эллиптический** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | Распространение волн сохраняет резкие черты | Волновое уравнение: u_tt = c²u_xx |
### Уравнение теплопроводности
∂u/∂t = α ∂²u/∂x²
Моделирование диффузии тепла, распределения населения, ценообразования опционов (Блэк-Шоулз).
| Недвижимость | Заявление |
|----------|-----------|
| Сглаживание | Решения мгновенно становятся гладкими, даже при наличии разрывных исходных данных |
| Принцип максимума | Максимальная температура возникает на границе или в начальный момент времени |
| Обратимость во времени | Необратимо — нельзя бежать назад |
### Волновое уравнение
∂²u/∂t² = c² ∂²u/∂x²
Моделирует вибрирующие струны, звук, электромагнитные волны.
| Недвижимость | Заявление |
|----------|-----------|
| Распространение | Возмущения распространяются со скоростью c |
| обратимость | обратимый во времени |
| раствор Даламбера | u(x,t) = f(x−ct) + g(x+ct) (суперпозиция левых/правых волн) |
### Уравнение Лапласа
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
Решения (гармонические функции) представляют собой установившуюся температуру, электростатический потенциал, течение несжимаемой жидкости.
| Недвижимость | Заявление |
|----------|-----------|
| Среднее значение свойства | u(x₀) = среднее значение u по любому кругу с центром в x₀ |
| Принцип максимума | Нет внутренних максимумов и минимумов |
| Уникальность | Полностью определяется граничными условиями |

Теория динамических систем — это математика изменений. Это объясняет, почему некоторые системы стабилизируются, почему некоторые колеблются и почему некоторые ведут себя хаотично. Для специалистов по данным он предоставляет инструменты для понимания динамики обучения, разработки стабильных алгоритмов, моделирования временных рядов и построения следующего поколения моделей машинного обучения с учетом физики.
