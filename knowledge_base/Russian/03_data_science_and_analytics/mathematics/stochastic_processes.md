# Случайные процессы
**Стохастический процесс** — это совокупность случайных величин, индексированных во времени (или пространстве). В то время как теория вероятностей изучает отдельные случайные события, стохастические процессы изучают, как случайность развивается с течением времени. Они моделируют цены на акции, длину очередей, распространение болезней, генерацию языка и динамику обучения моделей машинного обучения.
---

## Фонды
### Определение
Случайный процесс {X_t : t ∈ T} — это семейство случайных величин, определенных в общем вероятностном пространстве. T — **набор индексов** (время):
- **Дискретное время:** T = {0, 1, 2, ...}
- **Непрерывное время:** T = [0, ∞)
**Пространство состояний** S — это набор возможных значений, которые может принимать X_t.
### Ключевые свойства
| Недвижимость | Определение |
|----------|------------|
| **Стационарность** | Совместное распределение (X_{t₁}, ..., X_{tₖ}) такое же, как (X_{t₁+τ}, ..., X_{tₖ+τ}) |
| **Независимость** | X_t не зависит от X_s при t ≠ s |
| **Эргодичность** | Средние по времени сходятся к средним по ансамблю |
| **Марковская недвижимость** | Будущее зависит только от настоящего, а не от прошлого |
| **Мартингейл** | Ожидаемая будущая стоимость равна текущей стоимости |
---

## Цепи Маркова
**Цепь Маркова** — это случайный процесс, в котором будущее состояние зависит только от текущего состояния (свойство без памяти).
### Цепи Маркова с дискретным временем (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**Матрица перехода** P содержит записи p_{ij} = P(перейти к j | в настоящее время в i).
| Недвижимость | Заявление |
|----------|-----------|
| Суммы строк | Сумма каждой строки равна 1: Σⱼ p_{ij} = 1 |
| n-шаговый переход | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| Стационарное распределение | πP = π (левый собственный вектор с собственным значением 1) |
### Классификация состояний
| Срок | Определение |
|------|------------|
| **Периодический** | Цепь возвращается в состояние i с вероятностью 1 |
| **Переходный** | Ненулевая вероятность никогда не вернуться |
| **Увлекательный** | p_{ii} = 1 (однажды вошел, никогда не покидаю) |
| **Точка** | НОД времени возврата; период 1 = апериодический |
| **Общение** | Состояния i и j могут достигать друг друга |
### Стационарное распространение
Для неприводимой положительной рекуррентной цепи Маркова стационарное распределение π существует, уникально и удовлетворяет:
πP = π, Σᵢ πᵢ = 1
**Интерпретация:** πᵢ = долгосрочная доля времени, проведенного в состоянии i.
**Работающий пример:** Модель погоды с состояниями {Солнечно, Дождливо}.
P = [[0,9, 0,1], [0,5, 0,5]] (ряды: из Солнечно, из Дождливо)
Стационарное распределение: πP = π
- π₁ = 0,9π₁ + 0,5π₂
- π₂ = 0,1π₁ + 0,5π₂
- π₁ + π₂ = 1
- Решение: π₁ = 5/6 ≈ 0,833, π₂ = 1/6 ≈ 0,167.
### Сходимость к стационарности
Для неприводимой апериодической положительной рекуррентной цепи:
- Pⁿ → Π (матрица, все строки которой равны π) при n → ∞
- **Время смешивания:** Количество шагов, пока распределение не приблизится к π.
- **Спектральный разрыв:** 1 − |λ₂| (где λ₂ — второе по величине собственное значение) определяет скорость смешивания.
### Цепи Маркова непрерывного времени (CTMC)
Переходы происходят в случайные моменты времени, определяемые экспоненциальным распределением.
| Концепция | Описание |
|---------|-------------|
| **Матрица ставок Q** | q_{ij} ≥ 0 для i ≠ j; q_{ii} = −Σ_{j≠i} q_{ij} |
| **Вероятность перехода** | P(t) = e^{Qt} (матричная экспонента) |
| **Стационарное распределение** | πQ знак равно 0 |
| **Время выдержки** | Время в состоянии i равно Exp(−q_{ii}) |

## Случайные блуждания
**Случайное блуждание** — это путь, образованный последовательными случайными шагами.
### Простое случайное блуждание
X_n = X_{n-1} + Z_n, где Z_n ∈ {+1, −1} с вероятностями p, q = 1−p.
| Недвижимость | р = 1/2 (симметричный) | р ≠ 1/2 (смещенно) |
|----------|---------------------|-------------------|
| Е[X_n] | 0 | п(2p−1) |
| Вар[X_n] | п | 4нпк |
| Возвращение к истоку? | Да (с вероятностью 1) | Нет (уходит) |
| Повторяющийся? | Да (в 1D и 2D) | Нет |
### Случайное блуждание в высших измерениях
| Размерность | Повторяющийся? | Интуиция |
|-----------|------------|-----------|
| 1Д | Да | «Пьяный мужчина всегда находит дорогу домой» |
| 2D | Да | «Пьяная птица всегда находит дорогу домой» |
| 3D+ | Нет | «Пьяный воробей никогда не найдет дорогу домой» |
### Связь с броуновским движением
Масштабирование случайного блуждания: пусть S_n = ΣZ_i. Тогда при размере шага → 0 и шагах → ∞:
S_{⌊nt⌋} / √n → B(t) (броуновское движение по теореме Донскера)
---

## Броуновское движение
**Брауновское движение** (винеровский процесс) B(t) — это предел случайного блуждания в непрерывном времени.
### Определение
B(t) удовлетворяет:
1. В(0) = 0
2. B(t) имеет непрерывные пути
3. Независимые приращения: B(t) − B(s) не зависит от B(s) − B(r) при r < s < t.
4. B(t) − B(s) ~ N(0, t − s) (гауссовы приращения)
### Ключевые свойства
| Недвижимость | Заявление |
|----------|-----------|
| Е[Б(т)] | = 0 |
| Вар[B(t)] | = т |
| Cov[B(s), B(t)] | = мин(с, т) |
| Нигде не дифференцируемо | Пути непрерывны, но не имеют производной |
| Фрактальное измерение | Граф имеет размерность Хаусдорфа 3/2 |
| Марковская недвижимость | Будущее зависит только от текущего положения |
| Мартингейл | Е[Б(т) | F_s] = B(s) для s < t |
### Геометрическое броуновское движение
S(t) = S(0) exp((μ − σ²/2)t + σB(t))
Это стандартная модель цен на акции в рамках Блэка-Шоулза.
- μ: дрейф (ожидаемый доход)
- σ: волатильность

## Пуассоновские процессы
**Процесс Пуассона** N(t) подсчитывает количество событий, происходящих в [0, t].
### Определение
N(t) ~ Пуассона(λt), где λ — скорость (событий в единицу времени).
| Недвижимость | Заявление |
|----------|-----------|
| Н(0) = 0 | — |
| Независимые приращения | События в непересекающихся интервалах независимы |
| Стационарные приращения | N(t+s) − N(s) ~ Пуассон(λt) |
| Е[N(т)] | = λt |
| Вар[N(t)] | = λt |
| Время прибытия | Экспоненциально распределено: T_i ~ Exp(λ) |
### Обобщения
| Вариант | Описание |
|---------|-------------|
| **Неоднородный** | Скорость λ(t) меняется со временем |
| **Соединительный Пуассон** | Каждое событие имеет случайный размер: S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **Случайная мера Пуассона** | Точки в пространстве-времени, а не только во времени |
| **Многомерный** | Несколько типов событий с возможным взаимодействием |

## Мартингалы
**Мартингейл** — это честная игра: ожидаемая будущая стоимость с учетом всей текущей информации равна текущей стоимости.
### Определение
{X_n} является мартингалом относительно фильтрации {F_n}, если:
1. X_n F_n-измеримо (адаптировано)
2. E[|X_n|] < ∞ (интегрируемое).
3. Е[X_{n+1} | F_n] = X_n (честная игра)
| Вариант | Состояние | Интерпретация |
|---------|-----------|----------------|
| **Мартингейл** | Е[X_{n+1} | F_n] = X_n | Честная игра |
| **Субмартингейл** | Е[X_{n+1} | F_n] ≥ X_n | Благоприятная игра (тренд вверх) |
| **Супермартингейл** | Е[X_{n+1} | F_n] ≤ X_n | Неблагоприятная игра (тенденция к снижению) |
### Ключевые теоремы
| Теорема | Заявление |
|---------|-----------|
| **Необязательная остановка** | При условиях E[X_T] = E[X_0] для времени остановки T |
| **Конвергенция** | Ограниченный мартингал почти наверняка сходится |
| **Максимальное неравенство** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Дуба) |

## Методы Монте-Карло
**Метод Монте-Карло** использует случайную выборку для оценки детерминированных величин.
### Основная идея
Чтобы оценить E[f(X)], где X ~ P:
1. Нарисуйте N образцов: x₁, x₂, ..., x_N из P.
2. Вычислить: Î = (1/N) Σᵢ f(xᵢ)
3. По закону больших чисел: Î → E[f(X)] при N → ∞
**Ошибка:** Стандартная ошибка = σ_f / √N, где σ_f² = Var[f(X)]
### Методы уменьшения дисперсии
| Техника | Идея | Ускорение |
|-----------|------|---------|
| **Выборка по значимости** | Выборка из Q вместо P, вес по P/Q | Может быть драматичным |
| **Противоположные варианты** | Используйте пары (x, −x), чтобы устранить дисперсию | ~2x |
| **Управление переменными** | Вычтите функцию известного ожидания, коррелирующую с f | Варьируется |
| **Стратифицированная выборка** | Разделить домен, выбрать каждый слой | Уменьшает дисперсию |
| **Рао-Блэквелл** | Условие достаточной статистики | Всегда помогает |

## Марковская цепь Монте-Карло (MCMC)
MCMC строит цепь Маркова, стационарное распределение которой является целевым распределением. После периода «приработки» выборки приближаются к целевому значению.
### Алгоритм Метрополиса-Гастингса
| Шаг | Действие |
|------|--------|
| 1 | Текущее состояние: x_t |
| 2 | Предложить: x* ~ q(x* \| x_t) (распределение предложений) |
| 3 | Коэффициент приемки: α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | Принять с вероятностью α: x_{t+1} = x* (принять) или x_t (отклонить) |
**Особый случай — алгоритм Метрополиса:** Симметричное предложение q(x*|x) = q(x|x*), поэтому α = min(1, π(x*)/π(x_t)).
### Выборка Гиббса
Особый случай Метрополиса-Гастингса, когда каждая переменная обновляется из своего полного условного распределения.
Для цели π(x₁, x₂, ..., xₖ):
1. Выборка x₁^{(t+1)} ~ π(x₁ | x₂^{(t)}, ..., xₖ^{(t)})
2. Выборка x₂^{(t+1)} ~ π(x₂ | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. Продолжить для всех переменных.
4. Повторите
| Недвижимость | Заявление |
|----------|-----------|
| Всегда принимает | α = 1 (без шага отклонения) |
| Требуется | Возможность выборки из каждого полного условного |
| Конвергенция | Гарантия для неприводимых апериодических цепей |
### MCMC Диагностика
| Диагностика | Цель |
|-----------|---------|
| **Отслеживание графика** | Визуальная проверка смешивания и стационарности |
| **Автокорреляция** | Измеряет выборочную зависимость (нужна низкая автокорреляция) |
| **Гельман-Рубин (Р)** | Сравните несколько цепочек; R̂ < 1,05 предполагает конвергенцию |
| **Эффективный размер выборки** | N_eff = N/(1 + 2Σρₖ); учитывает автокорреляцию |
| **Выгорание** | Отбросить первоначальные образцы до того, как цепь достигнет стационарности |

## Актуальность для машинного обучения и науки о данных
| Случайный процесс | Приложение |
|-------------------|-------------|
| Цепи Маркова | PageRank (случайное блуждание по веб-графу), генерация текста (n-граммные модели), MCMC |
| Случайные прогулки | Node2Vec и DeepWalk (встраивание графов), исследование в RL |
| Броуновское движение | Моделирование цен на акции, модели диффузии в генеративном искусственном интеллекте |
| Пуассоновские процессы | Моделирование поступления событий (кликов, сбоев), теория массового обслуживания |
| Мартингалы | Финансовая математика, доказывающая сходимость SGD (стохастическая аппроксимация) |
| Монте-Карло | Оценка ожидаемых значений, байесовский вывод, обучение с подкреплением (оценка политики) |
| MCMC (Метрополис-Гастингс) | Байесовская апостериорная выборка, вероятностное программирование (Стэн, PyMC) |
| Выборка Гиббса | Тематические модели (LDA), байесовские сети, шумоподавление изображений |
| MCMC диагностика | Обеспечение надежных выводов из вероятностных моделей |

## Краткое содержание
| Процесс | Государственное пространство | Время | Ключевая недвижимость |
|---------|-------------|------|--------------|
| Цепь Маркова | Дискретный/непрерывный | Дискретный/непрерывный | Без памяти (свойство Маркова) |
| Случайное блуждание | ℤᵈ | Дискретный | Сумма i.id. шаги |
| Броуновское движение | ℝ | Непрерывный | Гауссовы приращения, непрерывные пути |
| Пуассоновский процесс | ℕ | Непрерывный | Процесс счета с экспоненциальными разрывами |
| Мартингейл | ℝ | Дискретный/непрерывный | Честная игра (E[X_{t+1}|F_t] = X_t) |
Стохастические процессы — это математика случайности во времени. Они лежат в основе современного байесовского вывода (MCMC), обучения с подкреплением (марковские процессы принятия решений), генеративного моделирования (модели диффузии), финансовой математики и теории массового обслуживания. Понимание этих процессов дает вам инструменты для динамического моделирования неопределенности — не просто как моментальный снимок, а по мере ее развития.
