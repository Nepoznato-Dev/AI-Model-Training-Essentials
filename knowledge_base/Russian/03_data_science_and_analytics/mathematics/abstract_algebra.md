# Абстрактная алгебра
Абстрактная алгебра изучает алгебраические структуры — множества, оснащенные операциями, подчиняющимися определенным правилам. Вместо работы с числами абстрактная алгебра работает с любыми объектами, удовлетворяющими аксиомам. Эта общность сильна: теорема, доказанная для «групп», применима к целым числам, симметриям, матрицам, перестановкам и квантовым состояниям одновременно. Абстрактная алгебра лежит в основе криптографии, кодов, исправляющих ошибки, квантовых вычислений и анализа симметрии, используемого в физике.

## Группы
**Группа** – это наиболее фундаментальная алгебраическая структура. Он отражает суть симметрии.
### Определение
**Группа** (G, ∗) — это множество G с бинарной операцией ∗, удовлетворяющей:
| Аксиома | Заявление | Пример (ℤ, +) |
|-------|-----------|-----------------|
| **Закрытие** | ∀a,b ∈ G: а∗ b ∈ G | a + b — целое число |
| **Ассоциативность** | (а * б) * с знак равно а * (б * с) | (а + б) + с = а + (б + с) |
| **Личность** | ∃e ∈ G: е∗ а знак равно а ∗ е знак равно а | 0 + а = а + 0 = а |
| **Инверсия** | ∀a ∈ G, ∃a⁻¹: а∗ a⁻¹ знак равно a⁻¹ ∗ а знак равно е | а + (−а) знак равно 0 |
Если операция также **коммутативна** (a ∗ b = b ∗ a), группа называется **абелевой**.
### Примеры групп
| Группа | Установить | Операция | идентичность | Обратный | Абелев? |
|-------|-----|-----------|----------|---------|----------|
| (ℤ, +) | Целые числа | Дополнение | 0 | −а | Да |
| (ℚ*, ×) | Ненулевые рациональные числа | Умножение | 1 | 1/а | Да |
| (ℤ/nℤ, +) | Остатки мод n | Дополнение мод | [0] | [н-д] | Да |
| Сₙ | Перестановки {1,...,n} | Состав | идентификатор | Обратная перестановка | Нет (n ≥ 3) |
| GL(п, ℝ) | Обратимые матрицы n×n | Умножение матриц | яₙ | А⁻¹ | Нет (n ≥ 2) |
| (ℝⁿ, +) | n-мерные векторы | Сложение векторов | 0 | -v | Да |
### Порядок группы и элементов
| Срок | Определение | Пример |
|------|------------|---------|
| **Порядок G** (\|G\|) | Количество элементов в G | \|ℤ/5ℤ\| = 5 |
| **Порядок элемента a** (ord(a)) | Наименьший положительный k с aᵏ = e | ord(2) в (ℤ/7ℤ)* = 3 (поскольку 2³ = 8 ≡ 1) |
| **Конечная группа** | \|Г\| конечно | S₃ имеет порядок 6 |
| **Бесконечная группа** | \|Г\| бесконечен | (ℤ, +) |
### Подгруппы
**Подгруппа** H группы G — это подмножество H ⊆ G, которое само является группой при выполнении той же операции.
**Тест подгруппы:** H является подгруппой G тогда и только тогда, когда:
1. H непусто
2. Для всех a, b ∈ H: a∗ b⁻¹ ∈ H
**Примеры:**
- (ℤ, +) имеет подгруппы nℤ = {..., −2n, −n, 0, n, 2n, ...} для каждого n ≥ 0
- **тривиальная подгруппа** {e} и сама группа G всегда являются подгруппами.
- В S₃ множество {id, (12)} является подгруппой порядка 2.
### Классы смежности и теорема Лагранжа
Для подгруппы H группы G и элемента a ∈ G:
- **Левый смежный класс:** aH = {ah : h ∈ H}
- **Правый смежный класс:** Ha = {ha : h ∈ H}
**Теорема Лагранжа:** Для конечной группы G и подгруппы H:
|Ч| делит |G|
**Следствия:**
- Порядок каждого элемента делит |G|
- Если |G| = p (простое), то G циклическая (не имеет нетривиальных подгрупп)
- а^|Г| = e для всех a ∈ G (обобщает Малую теорему Ферма)
### Циклические группы
Группа G называется **циклической**, если существует элемент g ∈ G такой, что каждый элемент группы G является степенью группы g. Пишем G = ⟨g⟩.
| Недвижимость | Заявление |
|----------|-----------|
| Каждая циклическая группа абелева | — |
| ℤ/nℤ при сложении является циклическим | Сгенерировано [1] |
| (ℤ/pℤ)* является циклическим для простого числа p | Генератор называется примитивным корнем |
| Классификация | Любая конечная циклическая группа изоморфна ℤ/nℤ для некоторого n |

## Гомоморфизмы и изоморфизмы
**Гомоморфизм** — это отображение между группами, сохраняющее структуру.
### Определения
| Срок | Определение | Пример |
|------|------------|---------|
| **Гомоморфизм** | φ: G → H, где φ(ab) = φ(a)φ(b) | det: GL(n,ℝ) → ℝ* |
| **Изоморфизм** | Биективный гомоморфизм (группы «одни и те же») | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **Ядро** | ker(φ) = {g ∈ G : φ(g) = e_H} | ker(det) = SL(n, ℝ) |
| **Изображение** | im(φ) = {φ(g) : g ∈ G} | им(дет) = ℝ* |
### Первая теорема об изоморфизме
Если φ: G → H — гомоморфизм, то:
Г / кер(φ) ≅ im(φ)
Это одна из самых важных теорем алгебры: она гласит, что каждый гомоморфизм разлагается на частное, за которым следует изоморфизм.

## Кольца
**Кольцо** добавляет в группу вторую операцию, моделирующую арифметику как сложения, так и умножения.
### Определение
**Кольцо** (R, +, ×) — это множество R с двумя операциями, удовлетворяющими:
| Аксиома | Заявление |
|-------|-----------|
| (R, +) — абелева группа | Сложение коммутативно, ассоциативно, имеет тождество 0, каждый элемент имеет аддитивный обратный |
| Умножение ассоциативно | (а × б) × с знак равно а × (б × с) |
| Распределительные законы | a(b + c) = ab + ac и (a + b)c = ac + bc |
Если умножение также коммутативно и имеет тождество (1), R — **коммутативное кольцо с единицей**.
### Примеры колец
| Кольцо | Описание | Коммутативный? | Имеет 1? |
|------|-------------|-------------|--------|
| (ℤ, +, ×) | Целые числа | Да | Да |
| (ℚ, +, ×) | Рациональное мышление | Да | Да |
| (ℝ, +, ×) | Действительные числа | Да | Да |
| (ℤ/nℤ, +, ×) | Целые числа мод n | Да | Да |
| Мₙ(ℝ) | действительные матрицы n×n | Нет (n ≥ 2) | Да |
| ℝ[х] | Полиномы с действительными коэффициентами | Да | Да |
### Идеалы и факторкольца
**Идеальный** I кольца R — это подмножество, которое:
1. Добавляется ли подгруппа
2. Поглощает умножение: для всех r € R и a € I как ra € I, так и ar € I.
**Кольцо факторов** R/I: элементы являются смежными классами I с операциями, унаследованными от R.
**Пример:** ℤ/nℤ = ℤ/nℤ — это частное ℤ по идеалу nℤ.
### Целочисленные домены и поля
| Структура | Определение | Примеры |
|-----------|------------|----------|
| **Интегрированный домен** | Коммутативное кольцо с 1, без делителей нуля (ab = 0 → a = 0 или b = 0) | ℤ, ℚ[х], ℝ[х] |
| **Поле** | Коммутативное кольцо, в котором каждый ненулевой элемент имеет мультипликативный обратный | ℚ, ℝ, ℂ, ℤ/pℤ (p простое) |

## Поля
Поля являются наиболее структурированными широко используемыми алгебраическими объектами. Каждый ненулевой элемент можно складывать, вычитать, умножать и делить.
### Ключевые свойства
| Недвижимость | Заявление |
|----------|-----------|
| Каждое поле является областью целостности | — |
| Каждая конечная область целостности является полем | — |
| Характеристика | Наименьшее n, где n · 1 = 0 или 0, если такого n не существует |
| символ(ℚ) = символ(ℝ) = символ(ℂ) | = 0 |
| символ(ℤ/pℤ) | = p (для простого p) |
### Конечные поля (поля Галуа)
Для каждой простой степени pᵏ существует уникальное (с точностью до изоморфизма) конечное поле порядка pᵏ, обозначаемое GF(pᵏ) или 𝔽_{pᵏ}.
| Поле | Размер | Строительство | Приложение |
|-------|------|-------------|-------------|
| ГФ(2) | 2 | {0, 1} мод 2 | Двоичная арифметика, XOR |
| ГФ(2ᵏ) | 2ᵏ | Полиномы по модулю неприводимого поли над GF(2) | Шифрование AES, коды CRC |
| ГФ(п) | р | ℤ/pℤ для простого числа p | Модульная арифметика, теория кодирования |
| GF(pᵏ) | пᵏ | Поля расширения | Коды Рида-Соломона, эллиптические кривые |
**Конструкция GF(2⁸)** (используется в AES):
- Начните с GF(2) = {0, 1}
- Выберите неприводимый многочлен p(x) = x⁸ + x⁴ + x³ + x + 1 над GF(2)
- Элементы представляют собой полиномы степени < 8 с коэффициентами из GF(2)
- Арифметика: полиномиальное сложение (XOR) и умножение по модулю p(x)

## Векторные пространства
**Векторное пространство** — это набор векторов, которые можно складывать и масштабировать, образуя основу линейной алгебры.
### Определение
**Векторное пространство** V над полем F — это множество, в котором:
- Сложение векторов: V × V → V (делает V абелевой группой)
- Скалярное умножение: F × V → V
Удовлетворительно: ассоциативность, коммутативность сложения, дистрибутивность скалярного умножения и 1·v = v.
### Ключевые понятия
| Концепция | Определение | Пример |
|---------|------------|---------|
| **Основа** | Линейно независимый связующий набор | {e₁, e₂, ..., eₙ} для Fⁿ |
| **Размер** | Количество векторов в любом базисе | тусклый(ℝ³) = 3 |
| **Подпространство** | Подмножество, замкнутое при сложении и скалярном умножении | Плоскость, проходящая через начало координат в ℝ³ |
| **Линейная комбинация** | Σ cᵢvᵢ где cᵢ ∈ F | 3в₁ + 2в₂ − v₃ |
| **Промежуток** | Набор всех линейных комбинаций | Span({v₁, v₂}) = плоскость, если v₁, v₂ независимы |
| **Линейная независимость** | Ни один вектор не является линейной комбинацией других | e₁, e₂, e₃ в ℝ³ |
### Важные векторные пространства
| Космос | Описание | Размерность |
|-------|-------------|-----------|
| Фⁿ | n-кортежи над полем F | п |
| Пₙ(Ф) | Полиномы степени ≤ n | п + 1 |
| Мₘₓₙ(Ф) | матрицы m × n над F | мин |
| С[а,б] | Непрерывные функции на [a,b] | бесконечный |
| L²(ℝ) | Квадратно-интегрируемые функции | Бесконечное (гильбертово пространство) |

## Линейные карты и теория собственных чисел
### Линейные карты
**Линейное отображение** (линейное преобразование) T: V → W удовлетворяет:
- Т(и + v) = Т(и) + Т(v)
- T(cv) = cT(v) для всех скаляров c
| Концепция | Определение | Пример |
|---------|------------|---------|
| **Ядро** | {v ∈ V : T(v) = 0} | Нулевое пространство матрицы |
| **Изображение** | {T(v) : v ∈ V} | Столбцовое пространство матрицы |
| **Теорема о недействительности ранга** | dim(ker T) + dim(im T) = dim(V) | Фундаментальное ограничение |
| **Матричное представление** | T(v) = Av для некоторой матрицы A | Всякое линейное отображение конечномерных пространств |
### Собственные значения и собственные векторы
Для линейного отображения T: V → V (или матрицы A):
**Уравнение собственных значений:** Av = λv, где v ≠ 0
| Срок | Определение |
|------|------------|
| **Собственное значение** λ | Скаляр такой, что Av = λv для некоторого v ≠ 0 |
| **Собственный вектор** v | Ненулевой вектор, удовлетворяющий Av = λv |
| **Характеристический полином** | дет(А - λI) знак равно 0 |
| **Айгенпространство** | {v : Av = λv} — множество всех собственных векторов для λ (плюс 0) |
| **Спектр** | Набор всех собственных значений |
### Вычисление собственных значений
Для матрицы 2×2 A = [[a, b], [c, d]]:
- Характеристический полином: λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2
**Основные свойства:**
- Сумма собственных значений = трассировка(A) = сумма диагональных элементов
- Произведение собственных значений = det(A)
### Диагонализация
Матрица A является **диагонализуемой** тогда и только тогда, когда она имеет n линейно независимых собственных векторов (где A равно n×n).
Если A = PDP⁻¹, где D — диагональ:
- Aᵏ = PDᵏP⁻¹ (быстрое матричное возведение в степень)
- D содержит собственные значения на диагонали
- P содержит собственные векторы в виде столбцов
**Спектральная теорема:** Любая вещественная симметричная матрица диагонализируется ортогональной матрицей. Его собственные значения действительны.

## Приложения
### Теория кодирования (коды, исправляющие ошибки)
Конечные поля являются основой современных кодов, исправляющих ошибки.
| Код | Поле | Исправляет | Приложение |
|------|-------|----------|-------------|
| Код Хэмминга | ГФ(2) | 1 ошибка на блок | RAM ECC, ранняя работа в сети |
| Рид-Соломон | ГФ(2ᵏ) | Множественные ошибки | CD, DVD, QR-коды, спутниковая связь |
| Коды BCH | ГФ(2ᵏ) | Множественные ошибки | Флэш-память спутниковая |
| Коды LDPC | ГФ(2) | Множественные ошибки | Wi-Fi (802.11n), DVB-S2, 5G |
**Кодировка Рида-Соломона.** Рассматривайте данные как полином по GF(2ᵏ), оценивайте в нескольких точках. Даже если некоторые оценки повреждены, исходный полином можно восстановить.
### Квантовые вычисления
Квантовые состояния живут в комплексных векторных пространствах (гильбертовых пространствах). Квантовые ворота представляют собой унитарные матрицы.
| Квантовая концепция | Алгебраическая структура |
|----------------|-------------------|
| Кубит | Единичный вектор в ℂ² (комплексное двумерное векторное пространство) |
| Квантовые ворота | Унитарная матрица U ∈ U(2ⁿ) |
| Измерение | Оператор проекции |
| Запутывание | Состояние неразделимого тензорного произведения |
| Теорема о запрете клонирования | Никакая линейная карта не может скопировать неизвестное квантовое состояние |
**Однокубитные вентили:**
| Ворота | Матрица | Эффект |
|------|--------|--------|
| Паули-Х (НЕ) | [[0,1],[1,0]] | Битовый флип |
| Паули-З | [[1,0],[0,−1]] | Переворот фазы |
| Адамар | (1/√2)[[1,1],[1,−1]] | Создает суперпозицию |
| CNOT | Управляемые ворота 4×4 | Запутывает два кубита |
### Криптография
| Приложение | Алгебра Б/у |
|-------------|-------------|
| ЮАР | Мультипликативная группа (ℤ/nℤ)* |
| Криптография на основе эллиптических кривых | Группа точек на эллиптической кривой над конечным полем |
| АЭС | Арифметика в GF(2⁸) |
| Диффи-Хеллман | Циклическая подгруппа (ℤ/pℤ)* или группа эллиптических кривых |

| Кольцо | Два (+, ×) | Абелева группа относительно +, моноид относительно ×, дистрибутив | ℤ, ℤ/nℤ, Mₙ(ℝ) |

Абстрактная алгебра предоставляет язык для самой структуры. Группы отражают симметрию, кольца отражают арифметику, поля отражают деление, а векторные пространства отражают линейность. Эти структуры не абстрактны сами по себе — они присутствуют в каждом коде исправления ошибок, который защищает ваши данные, в каждом криптографическом протоколе, который защищает ваши коммуникации, в каждом квантовом алгоритме, который однажды может изменить вычисления, и в каждом линейном преобразовании, которое проходит через нейронную сеть.
