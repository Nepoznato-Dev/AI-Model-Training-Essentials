# Теория графов
**График** — это математическая структура, состоящая из вершин (узлов), соединенных ребрами (связями). Графы моделируют взаимоотношения: социальные сети, дорожные карты, нейронные сети, зависимости, каналы связи. Теория графов — изучение этих структур — предоставляет алгоритмы и теоремы, которые играют центральную роль в информатике, исследовании операций и науке о данных.
---

## Фундаментальные понятия
### Определения
| Срок | Определение | Обозначение |
|------|------------|----------|
| **График** | Пара G = (V, E) вершин и ребер | г |
| **Вершина (узел)** | Элемент V | в, ты, ш |
| **Край** | Связь между двумя вершинами | е = (u, v) или {u, v} |
| **Заказать** | Количество вершин | \|В\| = п |
| **Размер** | Количество ребер | \|Е\| = м |
| **Степень** | Количество ребер, инцидентных вершине | град(в) |
| **Путь** | Последовательность различных вершин, соединенных ребрами | v₁, v₂, ..., vₖ |
| **Цикл** | Путь, который начинается и заканчивается в одной вершине | v₁ → v₂ → ... → vₖ → v₁ |
| **Подключено** | Между каждой парой вершин существует путь | — |
| **Компонент** | Максимальный связный подграф | — |
| **Подграф** | Граф, сформированный из подмножества V и E | ЧАС ⊆ Г |
### Типы графиков
| Тип | Описание | Пример |
|------|-------------|---------|
| **Ненаправленный** | Края не имеют направления | Сеть дружбы |
| **Режиссер (орграф)** | Ребра имеют направление (дуги) | Ссылки на веб-страницы |
| **Взвешенный** | Края имеют числовые значения | Дорожные расстояния |
| **Невзвешенный** | Все ребра эквивалентны | Социальные связи |
| **Просто** | Никаких петель и кратных ребер | Большинство графиков из учебника |
| **Мультиграф** | Допускается наличие нескольких ребер между одинаковыми вершинами | Маршруты полетов (множественные рейсы между городами) |
| **Завершено** | Каждая пара вершин связна | Kₙ имеет n(n−1)/2 ребер |
| **Двусторонний** | Вершины разделены на две группы; ребра пересекают только группы | Матрицы рекомендаций по пользовательским элементам |
| **Планарный** | Можно рисовать без пересечения ребер | Макеты печатных плат |
| **Дерево** | Связный ациклический граф | Деревья решений, файловые системы |
| **ДАГ** | Направленные, не направленные циклы | Планирование задач, графики зависимостей |
### Лемма о рукопожатии
Сумма всех степеней вершин равна удвоенному количеству ребер:
Σᵥ deg(v) = 2|E|
**Следствие:** В каждом графе есть четное число вершин нечетной степени.
**Пример:** В группе из 10 человек, где каждый пожимает руку ровно трем другим: Σ deg = 30, поэтому |E| = Всего 15 рукопожатий.

## Представления графов
То, как вы храните график в памяти, определяет эффективность каждого алгоритма, который вы на нем запускаете.
| Представительство | Космос | Поиск края | Итерация соседей | Лучшее для |
|----------------|-------|-------------|--------------------|----------|
| **Матрица смежности** | О(n²) | О(1) | О(п) | Плотные графы, быстрые тесты на краях |
| **Список смежности** | О(п + м) | О(град(v)) | О(град(v)) | Разреженные графы, большинство реальных сетей |
| **Список краев** | О(м) | О(м) | О(м) | Простые алгоритмы, MST Крускала |
| **Матрица заболеваемости** | О(п · м) | О(м) | О(м) | Специализированные алгоритмы |
### Матрица смежности
Матрица A размера n × n, где A[i][j] = 1, если ребро (i,j) существует, и 0 в противном случае. Для взвешенных графов A[i][j] = вес.
**Свойства:**
- Симметрично для неориентированных графов
- Aᵏ[i][j] = количество прогулок длины k от i до j
- Собственные значения A раскрывают структурные свойства (см. Теорию спектральных графов ).
### Список смежности
Массив (или хэш-карта), в котором каждая вершина v хранит список своих соседей.
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

Это наиболее распространенное представление реальных графов, которые обычно являются разреженными (m ≪ n²).

## Деревья
**Дерево** — это связный ациклический неориентированный граф. **лес** – это непересекающееся объединение деревьев.
### Свойства деревьев
Для дерева с n вершинами:
- Он имеет ровно n − 1 ребер.
- Между любыми двумя вершинами существует ровно один путь
- Удаление любого края отключает его
- Добавление любого ребра создает ровно один цикл
### Виды деревьев
| Тип | Описание | Приложение |
|------|-------------|-------------|
| **Дерево с корнями** | Одна вершина назначена корневой | Файловые системы, организационные структуры |
| **Двоичное дерево** | Каждый узел имеет не более 2 дочерних элементов | BST, анализ выражений, деревья решений |
| **Сбалансированное дерево** | Высота равна O(log n) | Деревья АВЛ, красно-черные деревья (базы данных) |
| **Охватывающее дерево** | Подграф, включающий все вершины и являющийся деревом | Проектирование сетей, алгоритмы аппроксимации |
| **Минимальное связующее дерево** | Остовное дерево с минимальным общим весом ребра | Проектирование сетей, кластеризация |
| **Звездный график** | Один центральный узел, подключенный ко всем остальным | Звездообразные сети |
### Свойства двоичного дерева
| Недвижимость | Формула |
|----------|---------|
| Максимальное количество узлов на глубине d | 2ᵈ |
| Максимальное количество узлов в дереве высоты h | 2ʰ⁺¹ − 1 |
| Минимальная высота для n узлов | ⌊log₂(n)⌋ |
| Листовые узлы в полном двоичном дереве | Внутренние узлы + 1 |
### Обход дерева
| Обход | Заказать | Вариант использования |
|-----------|-------|----------|
| **Предварительный заказ** | Корневой → Левый → Правый | Копирование дерева, префиксное выражение |
| **В порядке** | Слева → Корень → Справа | Сортированный вывод из BST |
| **Постзаказ** | Слева → Справа → Корень | Удаление дерева, постфиксное выражение |
| **Порядок уровней (BFS)** | Уровень за уровнем, слева направо | Кратчайший путь в невзвешенном дереве |

## Обходы графа
Алгоритмы обхода систематически посещают каждую достижимую вершину.
### Поиск в ширину (BFS)
Исследует вершины слой за слоем, используя **очередь**.
| Недвижимость | Значение |
|----------|-------|
| Структура данных | Очередь (ФИФО) |
| Временная сложность | О(В + Е) |
| Пространственная сложность | О(В) |
| Находит кратчайший путь? | Да (невзвешенные графики) |
| Полный? | Да (исследует все достижимые вершины) |
**Алгоритм:**
1. Начните с исходной вершины s. Марк посетил. Очередь с.
2. Пока очередь не пуста: удалить из очереди вершину u. Для каждого непосещенного соседа v из u: отметьте v как посещенное, поставьте v в очередь.
**Приложения**: кратчайший путь в невзвешенных графах, связанные компоненты, проверка двудольности, сканирование веб-страниц.
### Поиск в глубину (DFS)
Прежде чем вернуться назад, исследуйте как можно глубже, используя **стек** (или рекурсию).
| Недвижимость | Значение |
|----------|-------|
| Структура данных | Стек (ЛИФО)/рекурсия |
| Временная сложность | О(В + Е) |
| Пространственная сложность | О(В) |
| Находит кратчайший путь? | Нет |
| Полный? | Да (для конечных графов) |
**Алгоритм:**
1. Начните с вершины s. Марк посетил.
2. Для каждого непосещенного соседа v из s: рекурсивно DFS из v.
**DFS классифицирует ребра на:**
– **Ребра дерева:** часть дерева DFS.
- **Задние ребра:** соединяют вершину с ее предком (укажите циклы).
- **Впереди ребра:** соединяют вершину с ее потомком.
- **Перекрестные ребра:** соединяют вершины в разных ветвях.
**Приложения**: топологическая сортировка, обнаружение циклов, сильно связанные компоненты, решение лабиринтов.
### Сравнение BFS и DFS
| Критерий | БФС | ДФС |
|-----------|-----|-----|
| Стратегия | Широкий, затем глубокий | Глубоко, затем широко |
| Память | Высшее (граница магазинов) | Нижний (путь магазинов) |
| Кратчайший путь (невзвешенный) | Гарантировано | Не гарантировано |
| Используйте, когда решение близко к началу | Лучше | Хуже |
| Используйте, когда график очень глубокий | Хуже | Лучше |
| Топологическая сортировка | Вариант алгоритма Кана | Стандартный подход |

## Алгоритмы кратчайшего пути
Поиск кратчайшего пути между вершинами — одна из наиболее практически важных задач графов.
### Алгоритм Дейкстры
Находит кратчайшие пути от одного источника ко всем остальным вершинам графа с **неотрицательными** весами ребер.
| Недвижимость | Значение |
|----------|-------|
| Краевые грузики | Должно быть ≥ 0 |
| Время (двоичная куча) | O((V + E) log V) |
| Время (куча Фибоначчи) | O(E + V log V) |
| Жадный? | Да |
| Справляется с отрицательными весами? | Нет |
**Алгоритм:**
1. Инициализировать dist[s] = 0, dist[v] = ∞ для всех v ≠ s. Очередь приоритетов Q со всеми вершинами.
2. Пока Q не пуст: извлеките вершину u с минимальным расстоянием. Для каждого соседа v из u с весом ребра w: если dist[u] + w < dist[v], обновить dist[v] = dist[u] + w.
**Работающий пример:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### Алгоритм Беллмана-Форда
Обрабатывает **отрицательные** веса ребер и обнаруживает отрицательные циклы.
| Недвижимость | Значение |
|----------|-------|
| Краевые грузики | Любой (обнаруживает отрицательные циклы) |
| Временная сложность | О(В · Е) |
| Пространственная сложность | О(В) |
| Справляется с негативными циклами? | Да (обнаруживает и сообщает) |
**Алгоритм:**
1. Инициализировать dist[s] = 0, dist[v] = ∞ для всех v ≠ s.
2. Повторите V - 1 раз: для каждого ребра (u, v) с весом w: если dist[u] + w < dist[v], обновите dist[v].
3. Проверьте наличие отрицательных циклов: если какое-либо ребро все еще можно ослабить, отрицательный цикл существует.
### Алгоритм Флойда-Уоршалла
Находит кратчайшие пути между **всеми парами** вершин.
| Недвижимость | Значение |
|----------|-------|
| Временная сложность | О(V³) |
| Пространственная сложность | О(В²) |
| Справляется с отрицательными весами? | Да (но не отрицательные циклы) |
| Подход | Динамическое программирование |
**Повторение:** dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) для каждой промежуточной вершины k.
### Руководство по выбору алгоритма
| Сценарий | Алгоритм |
|----------|-----------|
| Один источник, неотрицательные веса | Дейкстра |
| Один источник, возможны отрицательные веса | Беллман-Форд |
| Все пары, плотный граф | Флойд-Уоршалл |
| Все пары, разреженный граф | Запускаем Дейкстру из каждой вершины |
| Невзвешенный график | БФС |
| DAG (без циклов) | Топологическая сортировка + релаксация |
| A* (на основе эвристики) | Поиск A* (для поиска пути с хорошей эвристикой) |

## Минимальное связующее дерево
**Минимальное связующее дерево (MST)** соединяет все вершины с минимальным общим весом ребер.
### Характеристики
- MST имеет ровно n - 1 ребер (для n вершин).
- MST существует тогда и только тогда, когда граф связен.
- Граф с разными весами ребер имеет уникальный MST.
- MST удовлетворяет свойству **cut**: ребро минимального веса, пересекающее любой разрез, принадлежит MST.
- MST удовлетворяет **свойству цикла**: ребро максимального веса в любом цикле не принадлежит MST.
### Алгоритм Краскала
| Недвижимость | Значение |
|----------|-------|
| Стратегия | Жадный — добавление ребер в порядке веса |
| Структура данных | Непересекающееся множество (поиск объединения) |
| Временная сложность | O(E log E) |
| Лучшее для | Разреженные графы |
**Алгоритм:**
1. Отсортируйте все ребра по весу.
2. Для каждого ребра (по порядку): если его добавление не создает цикл (проверьте с помощью Union-Find), добавьте его в MST.
3. Остановитесь, когда выбрано n − 1 ребер.
### Алгоритм Прима
| Недвижимость | Значение |
|----------|-------|
| Стратегия | Жадный — вырастить дерево из начальной вершины |
| Структура данных | Приоритетная очередь (мин-куча) |
| Временная сложность | O(E log V) с двоичной кучей |
| Лучшее для | Плотные графы |
**Алгоритм:**
1. Начните с любой вершины. Отметьте его как часть MST.
2. Несколько раз добавьте ребро минимального веса, соединяющее вершину в MST с вершиной вне его.
3. Остановитесь, когда все вершины будут включены.
### Приложения MST
| Приложение | Как помогает MST |
|-------------|---------------|
| Сетевой дизайн | Проложите минимум кабеля/трубы для соединения всех мест |
| Кластеризация | Удалите k - 1 самых длинных ребер MST, чтобы получить k кластеров |
| Алгоритмы аппроксимации | 2-приближение для метрики TSP |
| Сегментация изображений | Группировка пикселей по цветовому сходству MST |
| Удаление функции | Удалите избыточные функции с помощью MST корреляционного графа |

## Сетевой поток
Проблемы сетевых потоков моделируют движение ресурсов через систему.
### Определение сети потока
**Сеть потоков** – это ориентированный граф, в котором:
- **исходная** вершина s (создает поток)
- **стоковая** вершина t (потребляет поток)
- **Пропускные способности** c(u,v) ≥ 0 на каждом ребре
- **Поток** f(u,v), удовлетворяющий:
  - **Ограничение емкости:** 0 ≤ f(u,v) ≤ c(u,v)
  - **Сохранение потока:** приток = отток в каждой вершине, кроме s и t.
### Проблема с максимальным потоком
Найдите максимальный общий расход от s до t.
**Метод Форда-Фалкерсона:**
1. Пока в остаточном графе существует увеличивающий путь от s до t:
2. Найдите узкие места на пути
3. Увеличить поток на пути на величину узкого места.
4. Обновление остаточных мощностей
| Алгоритм | Временная сложность | Заметки |
|-----------|----------------|-------|
| Форд-Фалкерсон (DFS) | O(m · f*), где f* — максимальный поток | Не может заканчиваться иррациональными способностями |
| Эдмондс-Карп (БФС) | О(В · Е²) | Всегда завершает работу, выбирает кратчайший путь расширения |
| Алгоритм Динича | О(V² · E) | Использует блокировку потоков; O(V^(1/2) · E) для единичных мощностей |
### Теорема о максимальном потоке и минимальном сокращении
**Максимальный поток** от s до t равен **минимальной пропускной способности**, отделяющей s от t.
**cut** (S, T) делит вершины на S (содержащую s) и T (содержащую t). Пропускная способность сечения — это сумма емкостей ребер от S до T.
**Применение максимального расхода:**
- Двустороннее сопоставление (назначение работников на рабочие места)
- Сегментация изображения (отделение переднего плана от фона)
- Выбывание в бейсболе (сможет ли команда X победить?)
- Надежность сети (максимальная пропускная способность данных)
### Двустороннее сопоставление через максимальный поток
Учитывая двудольный граф G = (L ∪ R, E):
1. Добавить источник s с ребрами ко всем вершинам в L (емкость 1).
2. Добавить сток t с ребрами из всех вершин в R (емкость 1)
3. Установите для всех исходных мощностей ребер значение 1.
4. Максимальный расход = максимальное соответствие

## Теория спектральных графов
Спектральная теория графов изучает графы через собственные значения и собственные векторы матриц, связанных с графом.
### Ключевые матрицы
| Матрица | Определение | Что он фиксирует |
|--------|------------|------------------|
| **Матрица смежности** A | A[i][j] = 1, если ребро (i,j) существует | Схема подключения |
| **Матрица степеней** D | Диагональ; D[i][i] = град(я) | Важность вершин по степени |
| **Лапласиан** L = D − A | L[i][j] = −1, если ребро, deg(i) на диагонали | Гладкость функций на графике |
| **Нормализованный лапласиан** L_norm = D^(−1/2) L D^(−1/2) | Масштабно-инвариантная версия | Структура сообщества |
### Собственные значения лапласиана
Лапласиан L положительно полуопределенен, поэтому все собственные значения ≥ 0.
| собственное значение | Значение |
|------------|---------|
| λ₁ знак равно 0 | Всегда ноль; собственный вектор — постоянный вектор |
| λ₂ (алгебраическая связность) | > 0 тогда и только тогда, когда граф связен; больше = лучше связь |
| Число нулевых собственных значений | Равно количеству связных компонентов |
| λₙ | Относится к максимальной степени и расширению графа |
### Приложения спектральных методов
| Приложение | Метод |
|-------------|--------|
| **Разбиение графа** | Используйте собственные векторы L, чтобы разбить граф на сбалансированные части |
| **Обнаружение сообщества** | Спектральная кластеризация: встраивание вершин с использованием нижних собственных векторов, затем кластеризация |
| **Рейтинг страницы** | Собственный вектор матрицы смежности (или матрицы перехода) веб-графа |
| **График** | Расположите вершины, используя собственные векторы лапласиана |
| **Полу-контролируемое обучение** | Распространение меток с помощью графа Лапласа (распространение меток) |
| **Графовые нейронные сети** | Спектральные свертки: фильтрация сигналов на графах с использованием собственных векторов L |
### Неравенство Чигера
Связывает второе собственное значение λ₂ с **расширением** графа (насколько оно связно):
λ₂/2 ≤ h(G) ≤ √(2λ₂)
где h(G) — константа Чигера (изопериметрическое число). Это означает, что λ₂ приблизительно измеряет, насколько сложно разрезать граф на две части — ключевой момент для кластеризации.

## Краткое содержание
| Тема | Основная идея | Ключевой алгоритм/Результат |
|-------|-----------|----------------------|
| Основы | Вершины, ребра, степени, пути | Лемма о рукопожатии |
| Представительства | Как хранить графики | Матрица смежности против списка смежности |
| Деревья | Связные ациклические графы | n вершин → n−1 ребер |
| Обходы | Систематическое исследование вершин | BFS (кратчайший путь), DFS (глубокое исследование) |
| Кратчайшие пути | Маршруты минимального веса | Дейкстра, Беллман-Форд, Флойд-Уоршалл |
| Минимальное связующее дерево | Самый дешевый способ соединить все вершины | Краскала, Прима |
| Сетевой поток | Максимальная пропускная способность | Форд-Фалкерсон, теорема о максимальном потоке и минимальном сокращении |
| Спектральная теория | Собственные значения раскрывают структуру | Собственные значения Лапласа, спектральная кластеризация |
Теория графов, возможно, является наиболее применимой отраслью математики к современной науке о данных. Социальные сети, графы знаний, молекулярные структуры, графы вычислений в средах глубокого обучения, разрешение зависимостей, системы рекомендаций — все это по сути проблемы графов. Описанные здесь алгоритмы носят не просто теоретический характер; они ежедневно работают в производственных системах в больших масштабах.
