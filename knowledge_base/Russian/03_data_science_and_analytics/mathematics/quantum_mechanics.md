# Квантовая механика
Квантовая механика — это теория физики в мельчайших масштабах — атомах, электронах, фотонах и фундаментальных частицах природы. Он заменяет детерминированный мир классической механики вероятностями, суперпозициями и запутанностью. Несмотря на свою противоречивую природу, квантовая механика является наиболее точно проверенной теорией во всей науке. Сегодня его принципы становятся непосредственно актуальными для вычислений с помощью квантовых компьютеров, которые обещают решать определенные проблемы экспоненциально быстрее, чем классические машины.

## Историческая мотивация
### Неудачи классической физики
| Проблема | Классическое предсказание | Наблюдение | Разрешение |
|---------|---------------------|--------------|------------|
| Излучение черного тела | Ультрафиолетовая катастрофа (бесконечная энергия при коротких λ) | Конечная пиковая длина волны | Планк: энергия квантована (E = nhν) |
| Фотоэлектрический эффект | КЭ зависит от интенсивности, а не от частоты | КЭ зависит от частоты | Эйнштейн: свет квантован (фотоны, E = hν) |
| Атомные спектры | Непрерывный спектр излучения | Дискретные спектральные линии | Бор: электроны занимают квантованные орбиты |

## Корпускулярно-волновой дуализм
### Длина волны де Бройля
Каждая частица с импульсом p имеет соответствующую длину волны:
λ = h/p = h/(мв)
| Частица | Типичный λ | Наблюдаемое поведение волн? |
|----------|-----------|---------------------------|
| Электрон (100 эВ) | 0,12 нм | Да (дифракция кристалла) |
| Протон | 0,003 нм | Да (рассеяние нейтронов) |
| Бейсбол (40 м/с) | 10⁻³⁴ м | Нет (слишком мал, чтобы его можно было обнаружить) |
### Эксперимент с двумя щелями
Квинтэссенция квантового эксперимента:
1. Частицы огня (электроны, фотоны) по одной в две щели.
2. Каждая частица попадает в одну точку детектора.
3. Со временем возникает интерференционная картина — как будто каждая частица прошла через обе щели одновременно.
4. Если измерить, через какую щель проходит частица, интерференционная картина исчезнет.
**Вывод:** Квантовые объекты не являются ни чисто частицами, ни чисто волнами. Они демонстрируют волновое поведение, когда их не наблюдают, и поведение, подобное частицам, когда их измеряют.

## Волновая функция
### Определение
**Волновая функция** ψ(x, t) полностью описывает квантовую систему. Это комплексная функция, квадрат модуля которой дает плотность вероятности:
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### Нормализация
Общая вероятность должна равняться 1:
∫ |ψ(x)|² dx = 1 (по всему пространству)
### Правило рождения
Вероятность найти частицу между x и x + dx:
P(x до x+dx) = |ψ(x)|² dx
Для общей наблюдаемой с собственными состояниями φₙ:
P(собственное значение измерения aₙ) = |⟨φₙ|ψ⟩|²

## Уравнение Шрёдингера
### Зависящее от времени уравнение Шрёдингера
я ℏ ∂ψ/∂t = Ĥψ
где Ĥ — **оператор Гамильтона** (оператор полной энергии).
### Независимое от времени уравнение Шрёдингера
Для стационарных состояний (собственных энергетических состояний):
Ĥψ = Eψ
Это уравнение собственных значений: разрешенные энергии E являются собственными значениями Ĥ.
### Частица в коробке (Бесконечный квадратный колодец)
Простейшая квантовая система: частица, ограниченная 0 < x < L.
| Количество | Результат |
|----------|--------|
| Волновые функции | ψₙ(x) = √(2/L) sin(nπx/L) |
| Энергетические уровни | Eₙ = n²π²ℏ²/(2мл²) = n²h²/(8мл²) |
| Основное состояние | n = 1, E₁ = h²/(8 мл²) |
| Энергия нулевой точки | E₁ > 0 (частица не может быть совершенно неподвижной) |
| Квантовое число | n = 1, 2, 3, ... (только положительные целые числа) |
### Квантовый гармонический осциллятор
V(x) = ½mω²x²
| Количество | Результат |
|----------|--------|
| Энергетические уровни | Eₙ = (n + ½)ℏω |
| Энергия нулевой точки | E₀ = ½ℏω |
| Расстояние | ΔE = ℏω (равномерный) |
| Волновые функции | Полиномы Эрмита × Гауссовский |

## Операторы и наблюдаемые
В квантовой механике каждая физическая наблюдаемая соответствует **эрмитовому оператору**.
### Ключевые операторы
| Наблюдаемый | Оператор (позиционное пространство) | Собственные значения |
|-----------|--------------------------|-------------|
| Позиция | х̂ = х | Все настоящие х |
| Импульс | p̂ знак равно −iℏ ∂/∂x | Все реальные р |
| Энергия (гамильтониан) | Ĥ = −(ℏ²/2м)∂²/∂x² + V(x) | Eₙ (дискретный для связанных состояний) |
| Угловой момент | L̂ знак равно р × p̂ | ℏ√(л(л+1)) |
| Спин | Ŝ = (ℏ/2)σ (матрицы Паули) | ±ℏ/2 (для спина ½) |
### Ожидаемые значения
Средний результат измерения наблюдаемой A в состоянии ψ:
⟨A⟩ = ⟨ψ|Â|ψ⟩ = ∫ ψ*(x) Â ψ(x) dx
### Коммутационные отношения
[Â, B̂] = AB̂ − B̂Â
| Коммутатор | Результат | Значение |
|-----------|--------|-------------|
| [х̂, р̂] | яℏ | Позиция и импульс несовместимы |
| [L̂ₓ, L̂ᵧ] | яℏL̂_z | Компоненты углового момента несовместимы |
| [σ̂ₓ, σ̂ᵧ] | 2iσ̂_z | Матрицы Паули (спиновые компоненты) |
Если [Â, B̂] = 0, наблюдаемые могут измеряться одновременно (разделять собственные состояния).

## Принцип неопределенности
### Принцип неопределенности Гейзенберга
Δx · Δp ≥ ℏ/2
В более общем смысле, для любых двух наблюдаемых A и B:
ΔA · ΔB ≥ (1/2)|⟨[Â, B̂]⟩|
### Отношения неопределенности
| Пара | Связь | Интерпретация |
|------|----------|----------------|
| Позиция-импульс | ΔxΔp ≥ ℏ/2 | Не могу точно знать оба |
| Энергия-время | ΔEΔt ≥ ℏ/2 | Недолговечные государства имеют неопределенную энергетику |
| Угловой момент | ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| | Невозможно знать все компоненты одновременно |
**Важно:** Неопределенность связана не с помехами в измерениях — это фундаментальное свойство квантовых состояний. Частица не имеет одновременно определенного положения и импульса.

## Квантовые состояния и суперпозиция
### Обозначение Дирака (Бра-Кет)
| Символ | Имя | Значение |
|--------|------|---------|
| \|ψ⟩ | Кет | Вектор состояния (вектор-столбец) |
| ⟨ψ\| | Бюстгальтер | Сопряженное транспонирование (вектор-строка) |
| ⟨φ\|ψ⟩ | Внутренний продукт | Амплитуда ψ, которую нужно найти в состоянии φ |
| \|ψ\|² | Норма в квадрате | Вероятность |
### Принцип суперпозиции
Если \|ψ₁⟩ и \|ψ₂⟩ являются допустимыми квантовыми состояниями, то любая линейная комбинация также допустима:
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

где |α|² + |β|² = 1 (нормализация).
**Измерение:** При измерении система «коллапсирует» до \|ψ₁⟩ с вероятностью |α|² или \|ψ₂⟩ с вероятностью |β|².
### Кубиты
**Кубит** — это квантовый бит: двухуровневая квантовая система.
\|ψ⟩ = α\|0⟩ + β\|1⟩, где |α|² + |β|² = 1
| Представительство | \|0⟩ | \|1⟩ |
|---------------|------|------|
| Спин | Раскрутить ↑ | Вращение вниз ↓ |
| Поляризация фотонов | Горизонтальный | Вертикальный |
| Уровень энергии | Основное состояние | Возбужденное состояние |
| Схема | \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**Сфера Блоха:** Любое состояние кубита можно записать как:
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iφ} sin(θ/2)\|1⟩
где θ ∈ [0, π] и φ ∈ [0, 2π). Государственное пространство представляет собой сферу.

## Запутывание
Два кубита считаются **запутанными**, когда их совместное состояние не может быть записано как произведение отдельных состояний.
### Состояния колокола (максимально запутанные)
| Государство | Выражение | Имя |
|-------|-----------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) | Состояние Белла |
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) | Состояние Белла |
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) | Состояние Белла |
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) | Синглетное состояние |
### Свойства запутанности
| Недвижимость | Описание |
|----------|-------------|
| Корреляция | Измерение одного кубита мгновенно определяет другой, независимо от расстояния |
| Нет связи | Невозможно использовать только запутанность для передачи информации быстрее скорости света |
| Моногамия | Если A максимально запутано с B, оно не может быть запутано с C |
| Хрупкость | Взаимодействие с окружающей средой разрушает запутанность (декогеренцию) |
### Парадокс ЭПР и теорема Белла
Эйнштейн, Подольский и Розен утверждали, что квантовая механика должна быть неполной (скрытые переменные). Белл показал, что любая локальная теория скрытых переменных удовлетворяет определенным неравенствам. Эксперименты нарушают неравенства Белла, подтверждая квантовую механику и исключая локальные скрытые переменные.

## Квантовые ворота
Квантовые вентили — это унитарные операции над кубитами.
### Однокубитные вентили
| Ворота | Матрица | Эффект |
|------|--------|--------|
| **Паули-X** (НЕ) | [[0,1],[1,0]] | Переворот бита: \|0⟩ ↔ \|1⟩ |
| **Паули-Ю** | [[0,−i],[i,0]] | Бит + переворот фазы |
| **Паули-З** | [[1,0],[0,−1]] | Переворот фазы: \|1⟩ → −\|1⟩ |
| **Адамар** (H) | (1/√2)[[1,1],[1,−1]] | Создает суперпозицию: \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **Фаза** (S) | [[1,0],[0,i]] | вращение на π/2 вокруг Z |
| **Т-ворота** | [[1,0],[0,e^{iπ/4}]] | вращение π/4 вокруг Z |
| **Вращение** Rₓ(θ) | потому что (θ/2)I - я грех (θ/2)σₓ | Вращение на θ вокруг оси X |
### Двухкубитные вентили
| Ворота | Описание | Эффект |
|------|-------------|--------|
| **CNOT** | Контролируемое-НЕ | Переворачивает цель, если управление равно \|1⟩ |
| **Чехия** | Контролируемый-Z | Применяет Z к цели, если управление равно \|1⟩ |
| **ОБМЕН** | Обмен кубитами | \|ab⟩ → \|ba⟩ |
### Создание запутанности
Примените H к кубиту 1, затем CNOT с кубитом 1 в качестве управления:
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩

Квантовая механика бросает вызов нашим глубочайшим представлениям о реальности: частицы являются волнами, объекты находятся в двух местах одновременно, корреляции, которые не поддаются классическому объяснению. Тем не менее, его математика точна, а его предсказания не имеют себе равных по точности. Для ученых, занимающихся данными, квантовая механика становится непосредственно актуальной благодаря квантовым вычислениям, которые обещают преобразовать оптимизацию, криптографию, моделирование и, возможно, само машинное обучение.
