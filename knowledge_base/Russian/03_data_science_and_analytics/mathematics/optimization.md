# Оптимизация
Оптимизация — это математика поиска лучшего решения из набора возможных решений. Он спрашивает: при наличии функции и ограничений, какие входные данные минимизируют (или максимизируют) выходные данные? Оптимизация — это двигатель машинного обучения: обучение модели означает минимизацию функции потерь. Он появляется в исследованиях операций, экономике, инженерном проектировании и практически во всех количественных областях.
---

## Формулировка задачи
Общая **задача оптимизации** имеет вид:
Минимизировать f(x)
При условии: gᵢ(x) ≤ 0 (ограничения-неравенства), hⱼ(x) = 0 (ограничения-равенства)
| Срок | Значение |
|------|---------|
| **Целевая функция** f(x) | Количество, которое нужно минимизировать (или максимизировать) |
| **Переменные решения** x | Ценности, которые мы можем контролировать |
| **Возможный регион** | Набор всех x, удовлетворяющих всем ограничениям |
| **Глобальный минимум** | Выполнимое x* с f(x*) ≤ f(x) для всех допустимых x |
| **Местный минимум** | Допустимый x* с f(x*) ≤ f(x) для всех допустимых x в некоторой окрестности |
| **Выпуклая задача** | f выпукло, допустимая область представляет собой выпуклое множество (локальный минимум = глобальный минимум) |
---

## Линейное программирование (ЛП)
Когда и цель, и все ограничения **линейны**, проблема представляет собой линейную программу.
### Стандартная форма
Свернуть cᵀx
При условии: Ax ≤ b, x ≥ 0
где с, х € ℝⁿ, А € ℝᵐˣⁿ, б € ℝᵐ.
### Характеристики
| Недвижимость | Заявление |
|----------|-----------|
| Выпуклость | ЛП — всегда выпуклая задача |
| Оптимальное решение | Всегда в вершине (угловой точке) допустимого многогранника |
| Существование | Если допустимая область ограничена и непуста, оптимальное решение существует |
| Множественные оптимумы | Если две вершины оптимальны, каждая точка на ребре между ними также оптимальна |
### Симплексный метод
**Симплексный метод** (Данциг, 1947) перемещается вдоль ребер допустимого многогранника от вершины к вершине, всегда улучшая цель, пока не достигнет оптимума.
| Недвижимость | Значение |
|----------|-------|
| Наихудшее время | O(2ⁿ) (экспоненциальная — на практике редко) |
| Среднее время | Полином для большинства практических задач |
| Основная идея | Перейти к соседней вершине с лучшим целевым значением |
**Алгоритм (обзор):**
1. Начните с базового допустимого решения (вершины многогранника).
2. Выберите входную переменную (та, которая улучшает цель)
3. Выберите выходную переменную (сохраните осуществимость)
4. Поворот: переход к новой вершине.
5. Повторяйте до тех пор, пока не исчезнет направление улучшения.
### Методы внутренних точек
Альтернатива симплексу: приблизиться к оптимуму изнутри допустимой области.
| Недвижимость | Значение |
|----------|-------|
| Наихудшее время | Полином (O(n³·⁵) для некоторых вариантов) |
| Практическое исполнение | Конкуренция с симплексом в решении больших задач |
| Основная идея | Следуйте по «центральному пути» через интерьер |
### Пример работающего LP
**Задача:** Фабрика производит стулья (x₁) и столы (x₂).
- Прибыль: 30 долларов за стул, 50 долларов за стол.
- Дерево: 2x₁ + 4x₂ ≤ 100 (доступны ножки для доски)
- Труд: x₁ + 3x₂ ≤ 60 (доступные часы)
- Максимизация: 30x₁ + 50x₂
**Решение (графический метод для двух переменных):**
- Вершины допустимой области: (0,0), (30,0), (40,10), (0,20)
- Оцените цель в каждой вершине:
  - (0,0): прибыль = 0
  - (30,0): прибыль = 900
  - (40,10): прибыль = 1700 ← оптимально
  - (0,20): прибыль = 1000
- **Оптимально:** x₁ = 40 стульев, x₂ = 10 столов, прибыль = 1700 долларов США.

## Выпуклая оптимизация
Задача считается **выпуклой**, если целевая функция выпукла, а допустимая область представляет собой выпуклое множество.
### Выпуклые множества и функции
| Концепция | Определение |
|---------|------------|
| **Выпуклый набор** | Для любых x, y в множестве и t ∈ [0,1]: tx + (1−t)y также находится в множестве |
| **Выпуклая функция** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) для всех t ∈ [0,1] |
| **Строго выпуклый** | Неравенство является строгим при t ∈ (0,1) и x ≠ y |
**Ключевое свойство:** Для выпуклой оптимизации каждый локальный минимум является глобальным минимумом.
### Общие выпуклые функции
| Функция | Выпуклый? | Где |
|----------|---------|-------|
| топор + b (линейный) | Да (и вогнутый) | Везде |
| х² | Да | ℝ |
| еˣ | Да | ℝ |
| -log(х) | Да | х > 0 |
| \|x\|ᵖ (p ≥ 1) | Да | ℝⁿ |
| max(f₁, f₂), если f₁, f₂ выпуклая | Да | Пересечение доменов |
### Градиентный спуск
Самый фундаментальный алгоритм оптимизации в машинном обучении.
**Правило обновления:** x_{k+1} = x_k − α∇f(x_k)
где α > 0 — **скорость обучения** (размер шага).
| Вариант | Обновить правило | Преимущество |
|---------|-------------|-----------|
| **Пакетный ГД** | x ← x − α∇f(x) | Стабильная конвергенция |
| **Стохастический GD (SGD)** | x ← x − α∇fᵢ(x) (один образец) | Быстро на итерацию, позволяет избежать локальных минимумов |
| **Мини-партия SGD** | x ← x − α(1/|B|)ΣᵢاB ∇fᵢ(x) | Баланс между пакетным и стохастическим |
| **Импульс** | v ← βv − α∇f(x); х ← х + v | Ускоряется через плоские регионы |
| **Адам** | Адаптивная скорость обучения по каждому параметру | Хорошо работает «из коробки» для глубокого обучения |
| **RMSprop** | Масштабируйте скорость обучения, используя среднее значение градиента | Хорошо для RNN |
### Скорость сходимости
| Метод | Выпуклая ж | Сильно выпуклое f |
|--------|----------|-------------------|
| Градиентный спуск | О(1/к) | O((1−μ/L)ᵏ) (линейный) |
| сингапурский доллар | О(1/√к) | О(1/к) |
| Ускоренный ГД (Нестеров) | О(1/к²) | O((1−√(μ/L))ᵏ) |
где k = количество итераций, µ = параметр сильной выпуклости, L = константа Липшица.
### Выбор скорости обучения
| Стратегия | Описание |
|----------|-------------|
| Фиксированный α | Просто, но может расходиться (слишком большой) или медленно сходиться (слишком маленький) |
| Поиск линии | Найдите α, которое минимизирует f(x − α∇f(x)) вдоль направления градиента |
| Графики распада | α_t = α₀ / (1 + βt) или α_t = α₀ · βᵗ |
| Разминка | Начинайте с малого, увеличивайте, затем распадайтесь (обычное явление при обучении трансформаторам) |
| Адаптивный (Адам) | Скорость обучения по каждому параметру на основе статистики градиентов |

## Ограниченная оптимизация
### Множители Лагранжа
Для задачи: минимизировать f(x) при условии, что h(x) = 0.
**Лагранжиан:** L(x, λ) = f(x) + λh(x)
В оптимуме: ∇ₓL = 0 и ∇_λL = 0 (что дает h(x) = 0).
**Работающий пример:** Минимизируйте f(x,y) = x² + y² при условии, что x + y = 1.
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- Ограничение: x + y = 1 → −λ = 1 → λ = −1.
- Решение: x = 1/2, y = 1/2, f = 1/2.
### Условия ККТ
**Условия Каруша-Куна-Такера (KKT)** обобщают множители Лагранжа на ограничения-неравенства.
Для: минимизировать f(x) при условии, что gᵢ(x) ≤ 0, hⱼ(x) = 0.
**Лагранжиан:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**Условия ККТ** (необходимые для оптимальности):
| Состояние | Уравнение |
|-----------|----------|
| Стационарность | ∇ₓL знак равно 0 |
| Первичная осуществимость | gᵢ(x) ≤ 0, hⱼ(x) = 0 |
| Двойная осуществимость | λᵢ ≥ 0 |
| Дополнительная расслабленность | λᵢgᵢ(x) = 0 для всех i |
**Дополнительная нежесткость** означает: если ограничение gᵢ не активно (gᵢ(x) < 0), то λᵢ = 0 (ограничение не влияет на решение).
Для выпуклых задач, удовлетворяющих условию Слейтера, условия ККТ являются одновременно необходимыми и достаточными.

## Двойственность
Каждая задача оптимизации («основная**») имеет связанную с ней **двойственную** задачу.
### Слабая и сильная двойственность
| Концепция | Заявление |
|---------|-----------|
| **Двойная функция** | g(λ, ν) = infₓ L(x, λ, ν) |
| **Двойная задача** | Максимизировать g(λ, ν) при условии λ ≥ 0 |
| **Слабая двойственность** | Двойной оптимальный ≤ Первичный оптимальный (всегда выполняется) |
| **Сильная двойственность** | Двойной оптимум = Первичный оптимум (справедливо для выпуклых задач с условием Слейтера) |
| **Разрыв двойственности** | Первичный оптимальный — двойственный оптимальный (ноль при сильной двойственности) |
### Почему двойственность имеет значение
| Приложение | Как помогает двойственность |
|-------------|-------------------|
| Нижние границы | Dual выдает сертификат качества основного решения |
| СВМ | Двойственная проблема SVM приводит к трюку с ядром |
| Анализ чувствительности | Двойные переменные измеряют, насколько изменится оптимум, если ограничения будут ослаблены |
| Разложение | Большие проблемы можно разделить на более мелкие подзадачи с помощью двойного |

## Целочисленное программирование
Когда некоторые или все переменные должны быть **целыми**, проблема становится намного сложнее (в целом NP-сложной).
### Типы
| Тип | Описание |
|------|-------------|
| Чистый IP | Все переменные должны быть целыми числами |
| Смешанный IP (MIP) | Некоторые переменные целые, некоторые непрерывные |
| Бинарный IP | Переменные ограничены {0, 1} |
### Методы решения
| Метод | Идея |
|--------|------|
| **Ветвь и граница** | Разделить на подзадачи, решить ЛП-релаксацию, сократить |
| **Режущие плоскости** | Добавьте линейные ограничения, чтобы ужесточить релаксацию LP |
| **Ветвь и срез** | Комбинирование ветвей и границ с секущими плоскостями |
| **Эвристика** | Жадный, локальный поиск, имитация отжига для приближенных решений |

## Эвристические и метаэвристические методы
Когда точная оптимизация невозможна, эвристика находит хорошие (не обязательно оптимальные) решения.
| Метод | Ключевая идея | Лучшее для |
|--------|----------|----------|
| **Градиентный спуск** | Следуйте по самому крутому спуску | Гладкие дифференцируемые функции |
| **Метод Ньютона** | Использовать информацию второго порядка (кривизны) | Гладкие, хорошо обусловленные задачи |
| **Имитация отжига** | Принимать худшие решения с уменьшающейся вероятностью | Глобальная оптимизация, комбинаторная |
| **Генетические алгоритмы** | Развивайте популяцию, используя отбор, скрещивание и мутацию | Многокритериальный, недифференцируемый |
| **Рой частиц** | Агенты исследуют космос под влиянием самых известных позиций | Сплошной, невыпуклый |
| **Байесовская оптимизация** | Постройте суррогатную модель, используйте функцию сбора данных | Дорогие функции черного ящика (настройка гиперпараметров) |
### Метод Ньютона для оптимизации
**Правило обновления:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
где H — матрица Гессе (матрица вторых производных).
| Недвижимость | Значение |
|----------|-------|
| Скорость сходимости | Квадратичный (около оптимума) |
| Стоимость за итерацию | O(n³) для инверсии Гессе |
| Требуется | Дважды дифференцируемый положительно определенный гессиан |
| Квазиньютон (BFGS) | Приблизительный гессиан по градиентам | O(n²) на итерацию |

## Актуальность для машинного обучения и науки о данных
| Концепция оптимизации | Приложение |
|-----|-----------------------------|
| Градиентный спуск | Обучение нейронных сетей, логистическая регрессия, любая дифференцируемая модель |
| SGD и варианты | Крупномасштабное МО (мини-пакетное обучение), онлайн-обучение |
| Адам, RMSprop | Оптимизаторы по умолчанию для глубокого обучения |
| Выпуклая оптимизация | SVM, логистическая регрессия, LASSO, Ridge (гарантированный глобальный оптимум) |
| Множители Лагранжа | Ограниченное обучение, справедливое машинное обучение, распределение ресурсов |
| Условия ККТ | Получение двойного SVM, понимание активности ограничений |
| Двойственность | Трюк с ядром SVM, анализ чувствительности, методы декомпозиции |
| Линейное программирование | Распределение ресурсов, оптимизация портфеля, сетевой поток |
| Целочисленное программирование | Выбор функций (двоичный), планирование, комбинаторные задачи |
| Байесовская оптимизация | Настройка гиперпараметров (Оптуна, Гиперопт) |
| Ньютон/квазиньютон | Методы второго порядка для задач малого и среднего размера (L-BFGS) |

## Краткое содержание
| Метод | Тип проблемы | Гарантии | Масштаб |
|--------|-------------|------------|-------|
| Симплекс | Линейное программирование | Точный оптимум | Миллионы переменных |
| Внутренняя точка | Выпуклый (LP, QP, SOCP) | Точный оптимум | Крупномасштабные |
| Градиентный спуск | Гладкая неограниченная | Сходится к локальному минимуму | Очень большой (глубокое обучение) |
| сингапурский доллар | Крупномасштабный эмпирический риск | Сходится (с распадом) | Массивные наборы данных |
| Ньютон / БФГС | Гладкая, дважды дифференцируемая | Квадратичная сходимость | Малый и средний |
| ККТ/Лагранж | Ограниченный (выпуклый) | Точно в условиях | Средний |
| Ветвь и граница | Целочисленное программирование | Точный оптимум | Малый и средний |
| Эвристика | Любой (невыпуклый, комбинаторный) | Нет гарантии | Варьируется |
Оптимизация, пожалуй, самый важный математический инструмент в машинном обучении. Каждая обучаемая вами модель — от линейной регрессии до больших языковых моделей — включает в себя решение задачи оптимизации. Понимание того, когда проблема является выпуклой (гарантированный глобальный оптимум), когда градиентный спуск сходится и как справляться с ограничениями, дает вам теоретическую основу для проектирования, отладки и улучшения алгоритмов обучения.
