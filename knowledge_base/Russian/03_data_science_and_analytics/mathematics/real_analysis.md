# Реальный анализ
Реальный анализ является строгой основой исчисления. В то время как вводное исчисление учит вас, как вычислять производные и интегралы, реальный анализ задается вопросом, почему* эти методы работают — и когда они терпят неудачу. Он дает точные определения пределов, непрерывности, сходимости и интеграции, которые лежат в основе теории вероятностей, функционального анализа, оптимизации и теоретических гарантий, лежащих в основе алгоритмов машинного обучения.

## Последовательности и серии
### Последовательности
**Последовательность** — это упорядоченный список действительных чисел (aₙ)ₙ₌₁^∞. Главный вопрос: **сходится** ли последовательность к пределу?
**Определение сходимости:** Последовательность (aₙ) сходится к L, если для любого ε > 0 существует N такое, что для всех n > N: |aₙ − L| < е.
| Концепция | Определение | Пример |
|---------|------------|---------|
| **Конвергентный** | lim aₙ = L существует и конечен | аₙ = 1/n → 0 |
| **Дивергент** | Не сходится | aₙ = (−1)ⁿ колеблется |
| **Расхождение к ∞** | aₙ растет без ограничений | аₙ = n² → ∞ |
| **Ограничено** | \|аₙ\| ≤ M для некоторого M | Всякая сходящаяся последовательность ограничена |
| **Монотонный** | Либо всегда неубывающая, либо невозрастающая | aₙ = 1 − 1/n увеличивается |
| **Последовательность Коши** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | В ℝ Коши ⟺ сходящийся |
**Основные теоремы:**
- **Теорема о монотонной сходимости:** Любая ограниченная монотонная последовательность сходится.
- **Теорема Больцано-Вейерштрасса:** У каждой ограниченной последовательности есть сходящаяся подпоследовательность.
- **Полнота ℝ:** Каждая последовательность Коши в ℝ сходится (это отличает ℝ от ℚ)
### Ряд
**серия** — это сумма последовательности: Σₙ₌₁^∞ aₙ. Ряд сходится, если сходится последовательность частичных сумм Sₙ = Σₖ₌₁ⁿ aₖ.
### Тесты сходимости
| Тест | Состояние | Заключение |
|------|-----------|------------|
| **Тест на дивергенцию** | лим аₙ ≠ 0 | Серия расходится |
| **Сравнительный тест** | 0 ≤ aₙ ≤ bₙ и Σbₙ сходится | Σaₙ сходится |
| **Тест на соотношение** | lim \|aₙ₊₁/aₙ\| = Л | Сходится, если L< 1, diverges if L >1 |
| **Корневой тест** | lim суп \|aₙ\|^(1/n) = L | Сходится, если L< 1, diverges if L >1 |
| **Интегральный тест** | aₙ = f(n), f убывающая, положительная | Σaₙ сходится тогда и только тогда, когда ∫f(x)dx сходится |
| **Альтернативные серии** | aₙ убывающая, lim aₙ = 0, знаки чередуются | Ряд сходится |
| **Абсолютная конвергенция** | Σ\|аₙ\| сходится | Σaₙ сходится (и перестановки дают ту же сумму) |
| **Условная сходимость** | Σaₙ сходится, но Σ\|aₙ\| расходится | Перестановки могут дать любую сумму (Риман) |
### Важная серия
| Серия | Сумма | Состояние |
|--------|-----|-----------|
| Геометрический: Σ rⁿ | 1/(1−r) | \|р\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| Гармоника: Σ 1/n | Расходится (= ∞) | — |
| Экспонента: Σ xⁿ/n! | еˣ | Все х |
| Тейлор для ln(1+x): Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < х ≤ 1 |

## Ограничения и непрерывность
### Ограничения функций
**Определение:** lim_{x→c} f(x) = L означает: для любого ε > 0 существует δ > 0 такое, что 0 < |x − c| < δ влечет |f(x) − L| < е.
Это **определение ε-δ** — строгая версия выражения «f(x) приближается к L, когда x приближается к c».
### Непрерывность
Функция f является **непрерывной в точке c**, если lim_{x→c} f(x) = f(c). Эквивалентно: для любого ε > 0 существует δ > 0 такое, что |x − c| < δ влечет |f(x) − f(c)| < е.
**Типы разрывов:**
| Тип | Описание | Пример |
|------|-------------|---------|
| Съемный | Предел существует, но ≠ f(c) | f(x) = sin(x)/x при x = 0 |
| Прыжок | Левый и правый пределы существуют, но различаются | Ступенчатая функция |
| бесконечный | Предел составляет ±∞ | f(x) = 1/x² при x = 0 |
| Колеблющийся | Предел не существует | f(x) = sin(1/x) при x = 0 |
### Ключевые теоремы для непрерывных функций
| Теорема | Заявление |
|---------|-----------|
| **Теорема о промежуточном значении** | Если f непрерывна на [a,b] и f(a) < k < f(b), то ∃c ∈ (a,b): f(c) = k |
| **Теорема об экстремальном значении** | Если f непрерывна на [a,b], f достигает своего максимума и минимума на [a,b] |
| **Теорема об ограниченности** | Если f непрерывна на [a,b], f ограничена на [a,b] |
| **Равномерная непрерывность** | f равномерно непрерывна на [a,b], если f непрерывна на [a,b] (Хейне-Кантор) |
**Рабочий пример (IVT):** Покажите, что x³ + x − 1 = 0 имеет решение в (0, 1).
- Пусть f(x) = x³ + x − 1. f непрерывен (полиномиален).
- f(0) = −1< 0 and f(1) = 1 >0.
- По IVT, ∃c ∈ (0,1): f(c) = 0.

## Дифференциация
### Определение
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
Если этот предел существует, f **дифференцируема** в точке c.
### Дифференцируемость против непрерывности
| Отношения | Заявление |
|--------------|-----------|
| Дифференцируемый → Непрерывный | Если f дифференцируема в точке c, f непрерывна в точке c |
| Непрерывный ↛ Дифференцируемый | f(x) = \|x\| непрерывен в 0, но не дифференцируем там |
| Нигде не дифференцируемо | Функция Вейерштрасса: непрерывная всюду, нигде не дифференцируемая |
### Ключевые результаты
| Теорема | Заявление |
|---------|-----------|
| **Теорема о среднем значении** | Если f непрерывна на [a,b] и дифференцируема на (a,b), ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **Теорема Ролля** | Особый случай MVT, когда f(a) = f(b): ∃c: f'(c) = 0 |
| **Правило Лопиталя** | Если lim f/g = 0/0 или ∞/∞, то lim f/g = lim f'/g' (когда последний существует) |
| **Теорема Тейлора** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x) с явным остатком |

## Интеграция
### Интегрирование Римана
**Интеграл Римана** определяет ∫ₐᵇ f(x)dx как предел сумм Римана.
**Строительство:**
1. Разбить [a,b] на подинтервалы: P = {x₀, x₁, ..., xₙ}
2. Выберите точки выборки tᵢ ∈ [xᵢ₋₁, xᵢ]
3. Сумма Римана: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. Если предел S(P,f) существует при сетке → 0, f интегрируема по Риману.
**Критерии интегрируемости Римана:**
| Состояние | Интегрируемый? |
|-----------|-------------|
| Непрерывно на [a,b] | Да |
| Ограничено конечным числом разрывов | Да |
| Монотонный на [a,b] | Да |
| Функция Дирихле (1 на ℚ, 0 на иррациональных числах) | Нет |
### Основная теорема исчисления
| Часть | Заявление |
|------|-----------|
| **Часть 1** | Если f непрерывен на [a,b], то F(x) = ∫ₐˣ f(t)dt дифференцируемо и F'(x) = f(x) |
| **Часть 2** | Если F' = f и f интегрируема по Риману, то ∫ₐᵇ f(x)dx = F(b) − F(a) |
### Интеграция Лебега
Интеграл Римана имеет ограничения — он не может интегрировать многие функции, возникающие при анализе и вероятности. **Интеграл Лебега** расширяет интегрирование на гораздо более широкий класс функций.
**Ключевая идея:** Вместо разделения домена (ось X) разделите диапазон (ось Y).
| Аспект | Интеграл Римана | Лебег Интеграл |
|--------|-----------------|-------------------|
| Подход | Область разделения (ось X) | Диапазон раздела (ось Y) |
| Интегрирует | Непрерывный, кусочно-непрерывный | Измеримые функции |
| Предельные теоремы | Слабый | Мощный (доминируемая конвергенция, монотонная конвергенция) |
| Ручки | «Приятные» функции | Функции с плотными разрывами |
| Фонд | Классическое исчисление | Современная теория вероятностей |
**Критерий Лебега:** f интегрируема по Риману на [a,b] тогда и только тогда, когда f ограничена и непрерывна почти всюду (множество разрывов имеет нулевую меру).

## Метрические пространства
**Метрическое пространство** обобщает понятие «расстояния» на абстрактные множества.
### Определение
**Метрическое пространство** (X, d) — это множество X с функцией расстояния d: X × X → ℝ, удовлетворяющей:
| Аксиома | Заявление |
|-------|-----------|
| Негативность | d(x,y) ≥ 0 |
| идентичность | d(x,y) = 0 тогда и только тогда, когда x = y |
| Симметрия | d(x,y) = d(y,x) |
| Неравенство треугольника | d(x,z) ≤ d(x,y) + d(y,z) |
### Общие метрические пространства
| Космос | Установить | Метрическая | Приложение |
|-------|-----|--------|-------------|
| ℝⁿ с евклидовым | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² | Стандартная геометрия |
| ℝⁿ с Манхэттеном | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| | Пути на основе сетки, ЛАССО |
| ℝⁿ с Чебышевым | ℝⁿ | d(x,y) = max\|xᵢ−yᵢ\| | Шахматный король на расстоянии |
| Дискретная метрика | Любой набор | d(x,y) = 1, если x≠y, 0, если x=y | Примеры топологии |
| Функциональное пространство C[a,b] | Непрерывные функции | d(f,g) = max\|f(x)−g(x)\| | Теория приближения |
| Lᵖ пространство | p-интегрируемые функции | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) | Функциональный анализ, нормы ML |
### Топологические концепции в метрических пространствах
| Концепция | Определение | Пример |
|---------|------------|---------|
| **Открытый мяч** | B(x,r) = {y : d(x,y) <r} | Открытый интервал (x−r, x+r) в ℝ |
| **Открытый набор** | В каждой точке есть шар, содержащийся в множестве | (0,1) открыт в ℝ |
| **Закрытый набор** | Дополнение открытого набора | [0,1] замкнуто в ℝ |
| **Закрытие** | Наименьшее замкнутое множество, содержащее S | Замыкание (0,1) = [0,1] |
| **Компактный** | Каждое открытое покрытие имеет конечное подпокрытие | В ℝⁿ: замкнуто и ограничено (Гейне-Борель) |
| **Завершено** | Любая последовательность Коши сходится | ℝ завершено; ℚ нет |

## Равномерная сходимость
Последовательность функций (fₙ) может сходиться двумя способами:
| Тип | Определение | Сохраняет непрерывность? |
|------|------------|----------------------|
| **Поточечно** | ∀x: fₙ(x) → f(x) | Нет |
| **Униформа** | суп\|fₙ(x) − f(x)\| → 0 | Да |
**Равномерная сходимость** сильнее: скорость сходимости везде одинакова.
**Основные теоремы:**
- Равномерный предел непрерывных функций непрерывен
- Равномерный предел функций, интегрируемых по Риману, интегрируем по Риману, а интеграл от предела равен пределу интегралов.
- **М-критерий Вейерштрасса:** Если |fₙ(x)| ≤ Mₙ для всех x и ΣMₙ сходится, то Σfₙ сходится равномерно

## Теория меры
**Теория меры** обобщает понятия длины, площади и объема.
### Определение
**Мера** на множестве X — это функция µ: Σ → [0, ∞] (где Σ — σ-алгебра подмножеств), удовлетворяющая:
- мкм(∅) = 0
- **Счётная аддитивность:** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) для непересекающегося Aᵢ
### Мера Лебега
**Мера Лебега** λ на ℝ расширяет понятие длины:
| Установить | Мера Лебега |
|-----|-----------------|
| Интервал [a,b] | б - а |
| Одна точка {x} | 0 |
| Конечный набор | 0 |
| Счетное множество (например, ℚ) | 0 |
| Набор Кантора | 0 (несчетно, но мера равна нулю) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### Ключевые понятия
| Концепция | Определение |
|---------|------------|
| **Почти везде (п.в.)** | Свойство справедливо, за исключением множества нулевой меры |
| **Измеримая функция** | Прообраз любого открытого множества измерим |
| **Интеграл Лебега** | Интеграл, определенный с помощью теории меры |
| **Lᵖ пробелы** | Пространства функций с конечным интегралом p-й степени |
### Важные теоремы о сходимости
Эти теоремы объясняют, почему интегрирование Лебега предпочтительнее в высшей математике:
| Теорема | Заявление |
|---------|-----------|
| **Монотонная сходимость** | Если fₙ ↑ f поточечно и fₙ ≥ 0, то ∫fₙ → ∫f |
| **Доминирующая конвергенция** | Если fₙ → f поточечно и \|fₙ\| ≤ g (интегрируемо), то ∫fₙ → ∫f |
| **Лемма Фату** | ∫lim инф fₙ ≤ lim инф ∫fₙ |
Эти теоремы позволяют менять местами пределы и интегралы, чего нельзя добиться при интегрировании по Риману в целом.

Настоящий анализ — это то место, где растет математика. Он заменяет интуитивные понятия «приближение», «непрерывность» и «площадь» точными определениями, которые можно доказать и обобщить. Для специалистов по данным и инженеров машинного обучения анализ дает теоретические гарантии: когда сходится градиентный спуск? Когда функция потерь ведет себя хорошо? Когда мы сможем обменяться ограничениями и ожиданиями? Это не философские вопросы — они определяют, работает ли ваш алгоритм или молча терпит неудачу.
