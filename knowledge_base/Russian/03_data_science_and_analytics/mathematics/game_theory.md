# Теория игр
Теория игр — это математика стратегического взаимодействия — ситуаций, в которых ваш результат зависит не только от вашего собственного выбора, но и от выбора других. От ценовых войн между компаниями до гонки ядерных вооружений, от онлайн-аукционов до эволюционной биологии — теория игр предоставляет инструменты для анализа конфликтов и сотрудничества. Оно становится все более актуальным для машинного обучения благодаря многоагентному обучению с подкреплением, генеративно-состязательным сетям (GAN) и проектированию механизмов для онлайн-платформ.
---

## Игры стратегической формы
### Определение
**Игра в стратегической (нормальной) форме** состоит из:
- Набор игроков N = {1, 2, ..., n}
- Стратегия устанавливает S₁, S₂, ..., Sₙ для каждого игрока
- Функции выигрыша u₁, u₂, ..., uₙ, отображающие профили стратегий в действительные числа.
### Пример: дилемма заключенного
| | Сотрудничать (С) | Дефект (D) |
|---|---------------|------------|
| **Сотрудничать (С)** | (−1, −1) | (−3, 0) |
| **Дефект (D)** | (0, −3) | (−2, −2) |
| Анализ | Результат |
|----------|--------|
| Доминирующая стратегия | Дефект (D доминирует над C у обоих игроков) |
| Равновесие Нэша | (D, D) с выигрышем (−2, −2) |
| Социальный оптимум | (C, C) с выигрышем (−1, −1) |
| Дилемма | Индивидуальная рациональность приводит к коллективной иррациональности |
### Больше классических игр
**Битва полов:**
| | Опера | Футбол |
|---|-------|----------|
| Опера | (2, 1) | (0, 0) |
| Футбол | (0, 0) | (1, 2) |
Два равновесия Нэша: (Опера, Опера) и (Футбол, Футбол).
**Курица (Ястреб-Голубь):**
| | Ястреб | Голубь |
|---|------|------|
| Ястреб | (−10, −10) | (5, 0) |
| Голубь | (0, 5) | (1, 1) |
Два равновесия Нэша: (Ястреб, Голубь) и (Голубь, Ястреб).

## Доминирующие стратегии
| Концепция | Определение |
|---------|------------|
| **Строго доминантный** | Стратегия sᵢ дает более высокий выигрыш, чем любая другая стратегия, независимо от выбора оппонентов |
| **Слабо доминантный** | Стратегия sᵢ дает как минимум такой же высокий выигрыш, как и любая другая, а для некоторых профилей оппонентов строго выше |
| **Доминируемая стратегия** | Стратегия, которая никогда не будет лучшим ответом |
**Итеративное устранение доминирующих стратегий:**
1. Удалите все строго доминируемые стратегии.
2. Повторяйте до тех пор, пока больше нельзя будет удалить.
3. Если остается один профиль стратегии, то это единственное равновесие по Нэшу.
---

## Равновесие Нэша
**Равновесие Нэша** — это такой профиль стратегии, при котором ни один игрок не может увеличить свой выигрыш, изменив в одностороннем порядке свою стратегию.
### Определение
(s₁*, s₂*, ..., sₙ*) является равновесием Нэша, если для каждого игрока i:
uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*) для всех sᵢ ∈ Sᵢ
### Нахождение равновесия Нэша (игры 2×2)
**Лучший способ ответа:**
1. В каждом столбце подчеркните лучший ответ игрока 1.
2. В каждой строке подчеркните лучший ответ игрока 2.
3. Ячейки, где оба подчеркнуты, представляют собой равновесия Нэша.
### Существование (теорема Нэша)
Каждая конечная игра имеет хотя бы одно равновесие Нэша (возможно, в смешанных стратегиях).
### Смешанные стратегии
**Смешанная стратегия** — это распределение вероятностей по чистым стратегиям.
| Концепция | Определение |
|---------|------------|
| Смешанная стратегия σᵢ | Распределение вероятностей по Sᵢ |
| Смешанная стратегия NE | Ни один игрок не может улучшить ожидаемый выигрыш, изменив свою комбинацию |
| Поддержка | Набор чистых стратегий, в которые играют с положительной вероятностью |
**Рабочий пример: сопоставление монет**
| | Руководители | Тейлз |
|---|-------|-------|
| Руководители | (1, −1) | (−1, 1) |
| Тейлз | (−1, 1) | (1, −1) |
Никакой чистой стратегии NE. Смешанный НЭ: оба играют H и T с вероятностью ½ каждый.

## Теорема о минимаксе
### Игры с нулевой суммой
В **игре с нулевой суммой** выигрыш одного игрока равен проигрышу другого: u₁ + u₂ = 0.
### Теорема фон Неймана о минимаксе
Для каждой конечной игры с нулевой суммой для двух игроков:
max_{σ₁} min_{σ₂} u₁(σ₁, σ₂) = min_{σ₂} max_{σ₁} u₁(σ₁, σ₂)
**Максимин** (наилучший наихудший случай для игрока 1) равен **минимаксу** (наилучший наихудший случай для игрока 2). Эта общая ценность и есть **ценность игры**.
### Решение игр с нулевой суммой
Для игры с нулевой суммой 2 × 2 с матрицей:
| | Л | р |
|---|---|---|
| Т | а | б |
| Б | с | д |
Оптимальная смешанная стратегия игрока 1: игра T с вероятностью p = (d−c)/((a−b)+(d−c))
Ценность игры: v = (ad−bc)/((a−b)+(d−c))

## Игры расширенной формы
Игры с последовательными ходами представлены в виде **деревьев игр**.
### Ключевые понятия
| Концепция | Определение |
|---------|------------|
| **Дерево игр** | Дерево, показывающее все возможные последовательности ходов |
| **Информационный набор** | Набор узлов, которые игрок не может различить |
| **Идеальная информация** | Каждый информационный набор является одноэлементным (все ходы наблюдаемы) |
| **Идеальный NE для подигры** | Равновесие Нэша в каждой подигре |
| **Обратная индукция** | Решить от конца дерева назад |
### Теорема Цермело
В играх для двух игроков с конечной информацией и без шансов: либо у одного игрока есть выигрышная стратегия, либо оба могут добиться ничьей (например, в шахматах).

## Кооперативные игры
В **кооперативных играх** игроки могут формировать обязательные соглашения и коалиции.
### Характеристическая функция
Кооперативная игра определяется **характеристической функцией** v: 2^N → ℝ, где v(S) — значение, которого может достичь коалиция S.
| Недвижимость | Определение |
|----------|------------|
| **Супердобавка** | v(S ∪ T) ≥ v(S) + v(T) для непересекающихся S, T |
| **Выпуклый** | v(S ∪ {i}) − v(S) ⩽ v(T ∪ {i}) − v(T) для S ⊂ T |
### Ядро
**Ядро** – это набор распределений, при котором ни одна коалиция не может улучшиться путем отделения:
Core = {x ∈ ℝⁿ: ΣᵢاN xᵢ = v(N), ΣᵢاS xᵢ ≥ v(S) для всех S ⊂ N}
Ядро может быть пустым — в этом случае стабильного распределения не существует.
### Значение Шепли
**Ценность Шепли** обеспечивает уникальное справедливое распределение, основанное на предельном вкладе:
φᵢ = Σ_{S ⊂ N\{i}} (|S|!(n−|S|−1)!/n!) · [v(S ∪ {i}) − v(S)]
| Недвижимость | Заявление |
|----------|-----------|
| Эффективность | Σ φᵢ = v(N) (все значения распределены) |
| Симметрия | Равные участники получают равные выплаты |
| Пустынный игрок | Не-участники получают ноль |
| Аддитивность | φ(v + w) = φ(v) + φ(w) |
**Интерпретация:** Значение Шепли каждого игрока — это его средний предельный вклад при всех возможных порядках формирования коалиции.
### Рабочий пример
Три игрока: v(∅) = 0, v({1}) = 0, v({2}) = 0, v({3}) = 0, v({1,2}) = 50, v({1,3}) = 70, v({2,3}) = 60, v({1,2,3}) = 100.
| Игрок | Предельные вклады (усредненные по заказам) | Значение Шепли |
|--------|--------------------------------------------------|----------------|
| 1 | (100+50+70+70+50+0)/6 = 56,7 | 37,5 |
| 2 | (100+50+60+60+50+0)/6 | 27,5 |
| 3 | (100+70+60+70+60+0)/6 | 35,0 |
(Точно рассчитывается по формуле Шепли для каждой перестановки.)

## Конструкция механизма
**Проектирование механизмов** — это «теория обратных игр»: вместо анализа заданных игр разрабатывайте игры, которые приносят желаемые результаты.
### Принцип откровения
Любой механизм, обеспечивающий желаемый результат, может быть заменен **механизмом прямого раскрытия**, где высказывание правды является равновесием Нэша.
### Теория аукционов
| Тип аукциона | Правила | Эквивалент дохода |
|-------------|-------|---------------------|
| **Закрытое предложение по первой цене** | Победит участник, предложивший самую высокую цену, и заплатит свою ставку | Все стандартные аукционы приносят одинаковый ожидаемый доход |
| **Закрытая цена второй цены (Викри)** | Победит участник, предложивший самую высокую цену, и заплатит вторую по величине ставку | (по независимым частным ценностям) |
| **Английский (по возрастанию)** | Цена растет; первым, кто принял победы | — |
| **Голландский (по убыванию)** | Цена падает; первым, кто принял победы | — |
### Аукцион Викри (вторичная цена)
**Доминирующая стратегия.** Предлагайте свою истинную ценность.
| Недвижимость | Заявление |
|----------|-----------|
| Правдивые торги | Слабо доминирующая стратегия |
| Эффективность | Товар достается тому, кто предложит наибольшую цену |
| Доход | Тот же ожидаемый доход, что и от первичной цены (теорема эквивалентности дохода) |
### Оптимальный дизайн аукциона (Майерсон)
Аукцион, максимизирующий доход:
– Распределяется участнику торгов с самой высокой **виртуальной оценкой**.
- Устанавливает резервную цену
- Виртуальная оценка: ψ(v) = v − (1−F(v))/f(v)

## Связь с машинным обучением
### Генеративно-состязательные сети (GAN)
GAN — это игра для двух игроков между генератором G и дискриминатором D:
min_G max_D V(D, G) = E[log D(x)] + E[log(1 − D(G(z)))]
| Концепция теории игр | ГАН-эквивалент |
|----|---------------------------------|
| Игра для двух игроков с нулевой суммой | Генератор против дискриминатора |
| Равновесие Нэша | G генерирует реальные данные, D везде выводит ½ |
| Минимакс | Целевая функция GAN |
| Режим свертывания | Неспособность достичь равновесия |
### Многоагентное обучение с подкреплением (MARL)
| Концепция | Приложение MARL |
|---------|-----------------|
| Равновесие Нэша | Стабильные политики в мультиагентных настройках |
| Минимакс | Надежная политика против враждебных оппонентов |
| Кооперативные игры | Формирование коалиции, распределение задач |
| Значение Шепли | Переуступка кредита (какой агент что внес?) |
| Конструкция механизма | Проектирование стимулов в многоагентных системах |
| Вымышленная пьеса | Алгоритм обучения, сходящийся к равновесию Нэша |
### Другие подключения ML
| Приложение | Инструмент теории игр |
|-------------|-----------------|
| Дизайн рекламного аукциона (Google, Facebook) | Проектирование механизмов, теория аукционов |
| Дизайн маркетплейса (Uber, Airbnb) | Теория согласования, проектирование механизмов |
| Состязательная устойчивость | Игры с нулевой суммой между нападающим и защитником |
| Ярмарка | Ценность Шепли, распределение без зависти |
| Федеративное обучение | Теория кооперативных игр для измерения вклада |
| Рекомендательные системы | Разработка механизма для правдивого выявления предпочтений |

## Краткое содержание
| Концепция | Основная идея | Ключевой результат |
|---------|-----------|------------|
| Игры стратегической формы | Игроки, стратегии, выплаты | Представление игровой матрицы |
| Доминирующие стратегии | Лучшее независимо от других | Повторное исключение |
| Равновесие Нэша | Никаких выгодных односторонних отклонений | Существует в каждой конечной игре |
| Смешанные стратегии | Рандомизировать действия | Теорема существования Нэша |
| Минимакс | Лучший худший случай (нулевая сумма) | Теорема фон Неймана о минимаксе |
| Обширная форма | Последовательные ходы | Обратная индукция, совершенство подигр |
| Кооперативные игры | Обязательные коалиции | Ядро, значение Шепли |
| Конструкция механизма | Разрабатывайте игры, ориентированные на результат | Принцип раскрытия, оптимальные аукционы |
| Теория аукционов | Продажа через конкурс | Эквивалентность доходов, аукцион Викри |
Теория игр — это математика стратегического мышления. В мире, все более населенном взаимодействующими агентами искусственного интеллекта, автоматизированными торговыми площадками и состязательными системами, теория игр предоставляет необходимый набор инструментов для прогнозирования поведения, проектирования механизмов и построения надежных многоагентных систем. Для специалистов по данным он объясняет, как работают GAN, как онлайн-аукционы приносят миллиарды доходов и как создавать системы искусственного интеллекта, которые хорошо работают в конкурентной среде.
