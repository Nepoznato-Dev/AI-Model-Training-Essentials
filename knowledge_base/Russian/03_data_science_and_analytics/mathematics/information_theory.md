# Теория информации
Теория информации, основанная Клодом Шенноном в 1948 году, количественно определяет саму информацию. О чем вам говорит сообщение? Насколько можно сжимать данные? Как быстро вы можете общаться по зашумленному каналу? Эти вопросы имеют точные математические ответы. Помимо коммуникации, теория информации стала основой машинного обучения: кросс-энтропия является функцией потерь по умолчанию для классификации, расхождение KL измеряет сходство распределения, а взаимная информация определяет выбор функций.

## Энтропия
**Энтропия** измеряет среднюю неопределенность или «неожиданность» случайной величины.
### Энтропия Шеннона (дискретная)
Для дискретной случайной величины X с функцией массы вероятности p(x):
H(X) = −Σₓ p(x) log₂ p(x)
Единицы измерения: **биты** (при использовании log₂) или **nats** (при использовании ln).
| Распространение | Энтропия | Интуиция |
|-------------|---------|-----------|
| Честная монета (p = 0,5, 0,5) | 1 бит | Максимальная неопределенность для бинарного результата |
| Предвзятая монета (p = 0,9, 0,1) | 0,469 бит | Менее удивительно — в основном головы |
| Детерминированный (p = 1, 0) | 0 бит | Никакой неопределенности |
| Ярмарка кубика (6 сторон) | 2,585 бит | Больше результатов = больше неопределенности |
| Равномерные для n исходов | log₂(n) бит | Максимальная энтропия для n исходов |
### Свойства энтропии
| Недвижимость | Заявление |
|----------|-----------|
| Негативность | Н(Х) ≥ 0 |
| Максимум | H(X) ≤ log₂(\|X\|) с равенством для равномерного распределения |
| Правило цепочки | Н(Х, Y) = Н(Х) + Н(Y \| X) |
| Кондиционирование уменьшает | Н(Х \| Y) ≤ Н(Х) |
| Вогнутость | H — вогнутая функция распределения вероятностей |
### Дифференциальная энтропия (непрерывная)
Для непрерывной случайной величины X с плотностью p(x):
h(X) = −∫ p(x) log p(x) dx
В отличие от дискретной энтропии, дифференциальная энтропия может быть **отрицательной**.
| Распространение | Дифференциальная энтропия |
|-------------|---------------------|
| Униформа на [a,b] | журнал (б - а) |
| Нормальный N(μ, σ²) | (1/2) log(2πeσ²) |
| Экспонента(λ) | 1 − ln(λ) |

## Совместная, условная и взаимная информация
### Совместная энтропия
H(X, Y) = −Σₓ Σᵧ p(x, y) log p(x, y)
Измеряет общую неопределенность пары (X, Y).
### Условная энтропия
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
Измеряет оставшуюся неопределенность относительно Y после наблюдения X.
### Взаимная информация
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
Измеряет, насколько знание X говорит вам об Y (и наоборот).
| Недвижимость | Заявление |
|----------|-----------|
| Негативность | Я(Х; Y) ≥ 0 |
| Симметрия | Я(Х; Y) = Я(Y; Х) |
| Отношение к энтропии | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| Отношение к совместному | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| Независимость | I(X; Y) = 0 тогда и только тогда, когда X и Y независимы |
| Самоинформация | Я(Х; Х) = Н(Х) |
### Визуализация: энтропийная диаграмма
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## КЛ Дивергенция
**Расхождение Кульбака-Лейблера (KL)** показывает, насколько одно распределение отличается от другого.
D_KL(P || Q) = Σₓ P(x) log [P(x) / Q(x)]
| Недвижимость | Заявление |
|----------|-----------|
| Негативность | D_KL(P \|\| Q) ≥ 0 (неравенство Гиббса) |
| идентичность | D_KL(P \|\| Q) = 0 тогда и только тогда, когда P = Q |
| Асимметрия | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) в общем |
| Не показатель | Неверная симметрия и неравенство треугольника |
**Интерпретация:** D_KL(P || Q) — это дополнительное количество битов, необходимое для кодирования данных из P с использованием кода, оптимизированного для Q.
### Связь с другими величинами
| Отношения | Формула |
|-------------|---------|
| Перекрестная энтропия | H(P, Q) = H(P) + D_KL(P \|\| Q) |
| Взаимная информация | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| Условный КЛ | D_KL(P(Y\|X) \|\| Q(Y\|X)) усреднённый по X |

## Перекрестная энтропия
**Перекрестная энтропия** между распределениями P и Q:
H(P, Q) = −Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### Перекрестная энтропия как функция потерь
В классификации P — это истинное распределение (метка с горячим кодированием), а Q — предсказанное распределение модели.
**Двоичная кросс-энтропия (BCE):**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**Категорическая кросс-энтропия:**
L = −Σᵢ yᵢ log(ŷᵢ)
| Сценарий | y (правда) | ŷ (прогнозируется) | Потеря |
|----------|----------|---------------|------|
| Правильный, уверенный | 1 | 0,95 | 0,051 |
| Верно, неуверенно | 1 | 0,55 | 0,598 |
| Неправильно, уверенно | 1 | 0,05 | 2,996 |
| Неправильно, неуверенно | 1 | 0,45 | 0,799 |
Минимизация перекрестной энтропии эквивалентна минимизации отклонения KL от истинного распределения — вот почему она так хорошо работает как функция потерь.

## Емкость канала
### Модель канала связи
```
X → [Channel] → Y
```

- X: входная случайная величина
- Y: выходная случайная величина
- Канал: определяется условными вероятностями p(y|x)
### Теорема Шеннона о кодировании канала с шумом
Для канала с пропускной способностью C, если скорость передачи R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C, надежная связь невозможна.
**Пропускная способность канала:**
C = max_{p(x)} I(X; Y)
### Примеры важных каналов
| Канал | Описание | Емкость |
|---------|-------------|----------|
| **Двоично-симметричный (BSC)** | Переворачивает каждый бит с вероятностью p | 1 − H(p) бит |
| **Двоичное стирание (BEC)** | Стирает каждый бит с вероятностью ε | 1 − ε бит |
| **Гауссовский (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)log(1 + SNR) биты |
| **Бесшумный двоичный файл** | Идеальная передача | 1 бит |

## Кодирование и сжатие исходного кода
### Теорема о кодировании исходного кода
Среднее количество бит, необходимое для кодирования источника, ограничено снизу его энтропией:
L ≥ H(X)
Оптимальный код достигает L ≈ H(X).
### Кодирование Хаффмана
Код **без префиксов**, который присваивает более вероятным символам более короткие коды.
| Символ | Вероятность | Кодекс Хаффмана | Длина |
|--------|-------------|-------------|--------|
| А | 0,5 | 0 | 1 |
| Б | 0,25 | 10 | 2 |
| С | 0,125 | 110 | 3 |
| Д | 0,125 | 111 | 3 |
Средняя длина: 0,5(1) + 0,25(2) + 0,125(3) + 0,125(3) = 1,75 бит/символ.
Энтропия: H = 1,75 бит/символ (в данном случае оптимально!)
### Сжатие без потерь и сжатие с потерями
| Тип | Принцип | Примеры | Лимит |
|------|-----------|----------|-------|
| **Без потерь** | Удалить статистическую избыточность | ZIP, PNG, FLAC | Уровень энтропии H(X) |
| **С потерями** | Удалить ненужную для восприятия информацию | JPEG, MP3, H.264 | Функция искажения скорости R(D) |
**Теория искажения скорости:** Для сжатия с потерями и максимальным искажением D минимальная скорость равна R(D) = min I(X; X̂) при условии E[d(X, X̂)] ≤ D.

## Связи с другими полями
### Теория информации и термодинамика
| Концепция | Теория информации | Термодинамика |
|---------|-------------------|----------------|
| Энтропия | Энтропия Шеннона H(X) | Энтропия Больцмана S = k_B ln W |
| Максимальная энтропия | Равномерное распределение | Тепловое равновесие |
| КЛ дивергенция | Разница в распределении | Разница свободной энергии |
| Взаимная информация | Общая информация | Корреляции в физических системах |
Математические формы идентичны — Шеннон намеренно заимствовал термин «энтропия» из статистической механики.
### Теория информации и статистика
| Концепция | Приложение |
|---------|-------------|
| Максимальная вероятность | Эквивалент минимизации отклонения KL от эмпирического распределения к модельному |
| Информация о Фишере | Кривизна дивергенции KL; нижняя граница дисперсии оценки (Крамер-Рао) |
| Минимальная длина описания (MDL) | Выбор модели путем минимизации общей длины кодирования |
| АИК/БИК | Приблизительные критерии выбора модели на основе KL |

## Краткое содержание
| Количество | Формула (дискретная) | Значение |
|----------|-------------------|---------|
| Энтропия H(X) | −Σ p(x) log p(x) | Средняя неопределенность |
| Совместная энтропия H(X,Y) | −Σ p(x,y) log p(x,y) | Полная неопределенность пары |
| Условная энтропия H(Y\|X) | Ч(Х,Y) - Ч(Х) | Остающаяся неопределенность в отношении Y при условии X |
| Взаимная информация I(X;Y) | Ч(Х) - Ч(Х\|Y) | Информация, которой обмениваются X и Y |
| Дивергенция КЛ D_KL(P\|\|Q) | Σ P(x) log(P(x)/Q(x)) | «Расстояние» между раздачами |
| Перекрестная энтропия H(P,Q) | −Σ P(x) log Q(x) | Стоимость кодирования при неправильном распределении |
| Пропускная способность канала C | макс I(X;Y) | Максимальная надежная скорость связи |
Теория информации определяет фундаментальные пределы того, что можно изучить, сжать и передать. Для специалистов по машинному обучению это объясняет, почему кросс-энтропия работает как функция потерь, как измерить качество изученных представлений и как подумать о компромиссе между сложностью модели и соответствием данных. Идеи Шеннона, сделанные в 1948 году, остаются столь же актуальными для современного искусственного интеллекта, как и для телекоммуникаций.
