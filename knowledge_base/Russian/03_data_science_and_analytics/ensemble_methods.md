# Ансамблевые методы
Ансамблевые методы объединяют несколько моделей машинного обучения для получения более точных прогнозов, чем любая отдельная модель. Интуиция проста: если у вас есть несколько моделей, каждая из которых в некоторой степени точна, но допускает разные ошибки, объединение их прогнозов компенсирует отдельные ошибки и дает более надежный результат. Ансамбли лежат в основе большинства конкурентоспособных решений машинного обучения и остаются одними из самых надежных методов в производственных системах.
---

## Почему ансамбли работают
| Принцип | Описание |
|-----------|-------------|
| **Мудрость толпы** | Несколько несовершенных оценок, усредненных, лучше, чем любая отдельная оценка |
| **Компромисс смещения и дисперсии** | Ансамбли могут уменьшить дисперсию (объединение) или смещение (повышение), не жертвуя при этом другими |
| **Разнообразие ошибок** | Если модели допускают разные ошибки, их объединение компенсирует отдельные ошибки |
| **Сглаживание границ решений** | Несколько моделей создают более надежную поверхность принятия решений, чем одна модель |
---

## Бэггинг (агрегирование начальной загрузки)
### Как это работает
| Шаг | Описание |
|------|-------------|
| **1. Бутстрап-выборка** | Нарисуйте несколько случайных выборок (с заменой) из обучающих данных |
| **2. Базовые модели поездов** | Обучите одну модель на каждой начальной выборке (обычно деревья решений) |
| **3. Совокупный** | Для регрессии: средние прогнозы. Для классификации: большинство голосов |
### Ключевые характеристики
| Характеристика | Описание |
|---------------|-------------|
| **Уменьшает дисперсию** | Усреднение сглаживает колебания отдельных моделей |
| **Параллельное обучение** | Каждая базовая модель независима; можно обучать одновременно |
| **Оценка «из коробки»** | Каждый сэмпл исключен из некоторых бутстрап-сэмплов; используйте их для проверки |
| **Декорреляция** | Случайный выбор признаков при каждом разбиении снижает корреляцию между деревьями |
### Случайный лес
| Аспект | Описание |
|--------|-------------|
| **Базовый обучающийся** | Деревья решений |
| **Ключевое дополнение** | При каждом разбиении рассматривайте только случайное подмножество объектов (обычно sqrt(n_features)) |
| **Почему это работает** | Случайный выбор объектов декорирует деревья, делая ансамбль более надежным |
| **Гиперпараметры** | Количество деревьев; максимальная глубина; минимум образцов на лист; максимальные возможности |
| **Сильные стороны** | Обрабатывает многомерные данные; устойчив к выбросам; обеспечивает важность функции |
| **Слабые стороны** | Менее интерпретируемо, чем одиночные деревья; может адаптироваться к задачам регрессии с шумом |

## Повышение
### Как это работает
| Шаг | Описание |
|------|-------------|
| **1. Обучите первую модель** | Обучите базовую модель (часто неглубокое дерево/пень) на данных |
| **2. Выявить ошибки** | Найдите случаи, когда модель ошиблась |
| **3. Обучить следующую модель** | Обучите новую модель, ориентированную на ошибки (перевзвешенные или подогнанные по остатку) |
| **4. Объединить последовательно** | Каждая новая модель исправляет накопленные ошибки всех предыдущих моделей |
| **5. Повторить** | Продолжить указанное количество раундов |
### Алгоритмы повышения
| Алгоритм | Функция потерь | Ключевая особенность |
|-----------|--------------|-------------|
| **АдаБуст** | Экспоненциальный | Переоценивает неправильно классифицированные экземпляры; простой; чувствителен к шуму |
| **Усиление градиента** | Любая дифференцируемая потеря | Соответствует остаткам (градиент потерь); более гибкий |
| **XGBoost** | Регуляризованное повышение градиента | регуляризация L1/L2; градиенты второго порядка; оптимизация оборудования |
| **ЛайтГБМ** | Односторонняя выборка на основе градиента | Листовой рост; на основе гистограмм; быстро работать с большими наборами данных |
| **CatBoost** | Заказал повышение | Изначально обрабатывает категориальные функции; уменьшает переобучение |
### Бустинг против Бэггинга
| Размерность | Упаковка | Повышение |
|-----------|---------|----------|
| **Обучение** | Параллельно | Последовательный |
| **Фокус** | Уменьшает дисперсию | Уменьшает предвзятость |
| **Базовые модели** | Высокая дисперсия, низкий уровень смещения (глубокие деревья) | Низкая дисперсия, высокая погрешность (неглубокие деревья/пни) |
| **Комбинация** | Равный вес | Взвешивается по производительности |
| **Переоснащение** | Менее склонен | Можно переобучить, если слишком много раундов |
| **Чувствительность к шуму** | Прочный | Чувствителен к зашумленным данным |

## Укладка
### Как это работает
| Шаг | Описание |
|------|-------------|
| **1. Базовые модели поездов** | Обучайте разнообразные модели (например, случайный лес, SVM, нейронную сеть, повышение градиента) |
| **2. Генерировать прогнозы** | Использовать прогнозы вне сгиба (перекрестная проверка) в качестве входных признаков |
| **3. Метамодель поезда** | Обучение модели второго уровня на основе предсказаний базовой модели |
| **4. Окончательный прогноз** | Базовые модели прогнозируют; метамодель объединяет их предсказания |
### Лучшие практики стекирования
| Практика | Причина |
|----------|--------|
| **Используйте разнообразные базовые модели** | Разные алгоритмы допускают разные ошибки; главное в разнообразии |
| **Используйте перекрестную проверку для базовых прогнозов** | Не позволяет метамодели научиться использовать переобучение базовых моделей |
| **Сохраняйте метамодель простой** | Логистическая регрессия или мелкое дерево; базовые модели выполняют тяжелую работу |
| **Включить необработанные функции в метамодель** | Иногда полезно предоставить метамодели доступ к исходным функциям |

| Модель | Прогноз |
|-------|-----------|
| Модель А | Класс 1 |
| Модель Б | Класс 0 |
| Модель С | Класс 1 |
| **Голос большинства** | **Класс 1** |
### Мягкое голосование (классификация)
| Модель | P(Класс 0) | П(Класс 1) |
|-------|-----------|-----------|
| Модель А | 0,3 | 0,7 |
| Модель Б | 0,6 | 0,4 |
| Модель С | 0,4 | 0,6 |
| **Средний** | **0,43** | **0,57** |
| **Прогноз** | | **Класс 1** |
### Взвешенное усреднение
| Модель | Вес | Прогноз |
|-------|--------|-----------|
| Модель А | 0,5 | 0,8 |
| Модель Б | 0,3 | 0,6 |
| Модель С | 0,2 | 0,9 |
| **Средневзвешенное** | | 0,5×0,8 + 0,3×0,6 + 0,2×0,9 = 0,76 |

## Практическое руководство
### Когда какой ансамбль использовать
| Сценарий | Рекомендуемый метод |
|----------|-------------------|
| **Быстрый базовый уровень; табличные данные** | Случайный лес |
| **Максимальная точность; табличные данные** | XGBoost/LightGBM/CatBoost |
| **Зашумленные данные** | Бэггинг (усиление будет перекрывать шум) |
| **Требуется интерпретируемость** | Отдельная модель или небольшой ансамбль с важными функциями |
| **Различные типы моделей** | Складывание или голосование |
| **Онлайн-обучение** | Потоковые ансамблевые методы; адаптивное повышение |
| **Несбалансированные данные** | Сбалансированный случайный лес; экономически чувствительное повышение |
### Стратегии ансамблевого разнообразия
| Стратегия | Описание |
|----------|-------------|
| **Различные алгоритмы** | Объедините древовидные, линейные и нейронные модели |
| **Различные функции** | Обучение моделей различным подмножествам функций |
| **Различные подмножества данных** | Упаковка; подвыборка |
| **Различные гиперпараметры** | Тот же алгоритм с разными конфигурациями |
| **Разные периоды времени** | Тренируйтесь в разных временных окнах |

## Краткое содержание
Ансамблевые методы работают, потому что они объединяют несколько несовершенных моделей в один надежный предиктор. Пакетирование (случайные леса) уменьшает дисперсию за счет параллельного обучения моделей на бутстреп-выборках и усреднении. Повышение (XGBoost, LightGBM, CatBoost) уменьшает смещение за счет последовательного обучения моделей, каждая из которых исправляет предыдущие ошибки. При штабелировании используется метамодель для объединения различных базовых моделей. Голосование и усреднение — простейшие ансамбли. Общей нитью является разнообразие: ансамбли работают лучше всего, когда модели их компонентов разумны по отдельности, но допускают разные ошибки. На практике повышение градиента табличных данных часто является наиболее эффективным отдельным подходом, в то время как объединение различных моделей повышает точность в соревнованиях и приложениях с высокими ставками.
