# Геопространственный анализ
Геопространственный анализ — это процесс изучения данных, имеющих географический компонент — координаты, адреса, границы или любые данные, привязанные к местоположению на Земле. Он отвечает на такие вопросы, как «где находятся наши клиенты?», «какой оптимальный маршрут?» и «как меняется землепользование с течением времени?». Каждый набор данных имеет пространственное измерение, и его понимание открывает возможность понять, чего не хватает чистому статистическому анализу.
---

## Основные понятия
### Системы координат
| Система | Описание | Вариант использования |
|--------|-------------|----------|
| **WGS 84 (EPSG:4326)** | Глобальный стандарт; широта/долгота в градусах | GPS; большинство веб-картографий; ГеоJSON |
| **Веб-Меркатор (EPSG:3857)** | Проецирует глобус на цилиндр; искажает площадь на полюсах | Карты Google; картографический ящик; большинство сервисов веб-плиток |
| **UTM** (Универсальный поперечный Меркатор) | Делит Землю на 60 зон; на основе метров | Военный; геодезия; высокоточные локальные работы |
| **Британская национальная сеть (EPSG:27700)** | Данные OSGB36; на основе метров | Картографирование Великобритании |
| **Местные прогнозы** | Пользовательские прогнозы для конкретных регионов | Минимизировать искажения для определенной области |
### Типы геометрии
| Тип | Описание | Пример |
|------|-------------|---------|
| **Точка** | Единая координата | Ресторан; датчик; клиент |
| **СтрокаЛинии** | Упорядоченная последовательность точек | Дорога; река; маршрут |
| **Многоугольник** | Закрытая форма с интерьером | Страна; озеро; зона доставки |
| **Мультиточка** | Сбор очков | Все автобусные остановки в городе |
| **Мультистрочная строка** | Коллекция линий | Все дороги в сети |
| **Мультиполигон** | Коллекция полигонов | Архипелаг; страна с островами |
| **Коллекция Геометрии** | Смешанные типы | Страна со своими городами, дорогами и реками |

## Форматы данных
| Формат | Тип | Ключевая особенность |
|--------|------|-------------|
| **GeoJSON** | Текст (JSON) | Человекочитаемый; веб-дружественный; поддерживает все типы геометрии |
| **Шейп-файл** | Двоичный (несколько файлов) | Устаревший формат от ESRI; .shp + .shx + .dbf + .prj |
| **КМЛ** | XML | Google Планета Земля; поддерживает 3D и время |
| **Геопакет** | на основе SQLite | Один файл; поддерживает растр и вектор; современный стандарт |
| **ГеоПаркет** | Столбчатый (Паркет) | Эффективен для больших наборов данных; интегрируется с инструментами обработки данных |
| **ВКТ / ВКБ** | Текстовый/Двоичный | Известный текст; Известный двоичный файл; используется для хранения баз данных |
| **МВТ** | Двоичный | Векторные плитки Mapbox; для предоставления картографических данных веб-клиентам |

## Пространственные операции
### Основные операции
| Операция | Описание | Пример |
|-----------|-------------|---------|
| **Расстояние** | Рассчитать расстояние между геометриями | «Найти все больницы в радиусе 10 км» |
| **Буфер** | Создать многоугольник вокруг геометрии на заданном расстоянии | «Покажи 500-метровую зону вокруг школы» |
| **Перекресток** | Найдите область перекрытия между геометриями | «Какие участки находятся в зоне затопления?» |
| **Союз** | Объединить геометрии в одну | «Объединить все земельные участки в один регион» |
| **Разница** | Вычесть одну геометрию из другой | «Зона застройки без учета охранных зон» |
| **Содержит/внутри** | Проверить, находится ли одна геометрия внутри другой | «Какие клиенты находятся в этой зоне доставки?» |
| **Ближайший сосед** | Найдите ближайшую геометрию | «Какое ближайшее пожарное депо?» |
| **Пространственное соединение** | Объединение атрибутов на основе пространственных отношений | «Назначьте каждую точку входящему в нее переписному участку» |
### Пространственное индексирование
| Тип индекса | Описание | Вариант использования |
|-----------|-------------|----------|
| **R-дерево** | Иерархия ограничивающих рамок; наиболее распространенный | ПостГИС; SQLite; общего назначения |
| **Квадродерево** | Рекурсивное разбиение на квадранты | Данные о точках; игровые движки |
| **Геохэш** | Иерархическая сетка; кодирует в строку | Поиск близости; сегментирование базы данных |
| **H3** (Uber) | Шестиугольная иерархическая сетка | Аналитика; совместное использование поездок; контейнеры для униформы |
| **S2** (Google) | Ячеечная иерархия на сфере | Масштабная пространственная индексация |

## Шаблоны геопространственного анализа
### Распространенные типы анализа
| Узор | Описание | Вариант использования |
|---------|-------------|----------|
| **Анализ точечного рисунка** | Изучите распределение очков | картирование преступности; обнаружение вспышек заболеваний |
| **Анализ горячих точек** | Найдите статистически значимые кластеры | Розничное расположение; преступление; эпидемиология |
| **Сетевой анализ** | Оптимизация маршрута; зоны обслуживания | Логистика; реагирование на чрезвычайные ситуации; коммунальные услуги |
| **Пространственная интерполяция** | Оценить значения в невыбранных местоположениях | Качество воздуха; свойства почвы; погода |
| **Обнаружение изменений в землепользовании** | Сравните спутниковые снимки с течением времени | Разрастание городов; вырубка лесов; сельское хозяйство |
| **Анализ пригодности** | Найдите места, соответствующие нескольким критериям | Выбор места; планирование консервации |
| **Пространственная автокорреляция** | Измерьте, как связаны ближайшие значения | Цены на недвижимость; распространение болезней |
### Проблема с изменяемой единицей площади (MAUP)
| Аспект | Проблема |
|--------|---------|
| **Эффект масштаба** | Результаты меняются в зависимости от размера единиц анализа (переписные участки, округа или штаты) |
| **Эффект зонирования** | Результаты меняются в зависимости от того, как нарисованы границы, даже в одном и том же масштабе |
| **Смысл** | Никогда не предполагайте, что результаты на одном уровне агрегирования применимы на другом; всегда проверяйте чувствительность к границам |

## Практические соображения
| Концерн | Руководство |
|---------|----------|
| **Системы координат** | Всегда проверяйте CRS; никогда не смешивайте прогнозы в расчетах; преобразование перед вычислением расстояний |
| **Точность** | Точность чисел с плавающей запятой имеет значение в небольших масштабах; использовать соответствующие типы данных |
| **Производительность** | Пространственные операции обходятся дорого; использовать пространственные индексы; упростить геометрию для отображения |
| **Топология** | Перед анализом убедитесь, что геометрия верна (нет самопересечений, замкнутых многоугольников) |
| **Масштаб** | Паутина Меркатора искажает площадь; не используйте его для расчета площади |
| **Качество данных** | Проверка нулевой геометрии, повторяющихся вершин, ленточных многоугольников |

## Краткое содержание
Геопространственный анализ превращает данные о местоположении в полезную информацию. Точки, линии и многоугольники представляют собой объекты реального мира. Пространственные операции — расстояние, буфер, пересечение, соединение — отвечают на вопросы о близости, перекрытии и сдерживании. Инструменты варьируются от PostGIS для анализа в масштабе базы данных до GeoPandas для рабочих процессов Python и Deck.gl для веб-визуализации. Ключевыми проблемами являются выбор правильной системы координат, управление производительностью при работе с большими наборами данных и знание MAUP — того факта, что выбор границ агрегирования влияет на ваши результаты. Независимо от того, оптимизируете ли вы маршруты доставки, анализируете распространение болезней или составляете карту роста городов, геопространственный анализ обеспечивает пространственный контекст, который не могут быть уловлены чистыми числами.
