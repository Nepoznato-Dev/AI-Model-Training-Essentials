# Визуализация данных
Хорошо спроектированная диаграмма может выявить закономерности, скрытые таблицами чисел. Плохо спроектированный вариант может ввести в заблуждение, запутать или утомить. Визуализация данных — это искусство превращения данных в визуальные истории, которые помогают принимать решения. В этом файле рассказывается о выборе диаграмм, принципах проектирования, типичных ошибках и инструментах, которые делают все это возможным.
---

## Выбор правильного графика
Самым важным решением в любой визуализации является выбор правильного типа диаграммы для ваших данных и сообщения.
### Руководство по выбору диаграммы
| Ваша цель | Лучшие типы диаграмм |
|-----------|-----------------|
| **Сравнить категории** | Гистограмма, сгруппированная гистограмма |
| **Показать изменения с течением времени** | Линейный график, диаграмма с областями |
| **Показать распределение** | Гистограмма, коробчатый сюжет, скрипичный сюжет |
| **Показать родство** | Точечная диаграмма, пузырьковая диаграмма |
| **Показать композицию** | Столбчатая диаграмма с накоплением, круговая диаграмма (ограниченные фрагменты), древовидная карта |
| **Показать корреляцию** | Точечная диаграмма, тепловая карта, парный график |
| **Показать рейтинг** | Горизонтальная гистограмма |
| **Показать географические закономерности** | Карта-карта, точечная карта |
| **Отображение части к целому с течением времени** | Диаграмма с накоплением |
### Когда использовать каждый график
| Диаграмма | Сильные стороны | Избегайте, когда |
|-------|-----------|-----------|
| **Бар** | Четкое сравнение категорий | Слишком много категорий (>15) |
| **Линия** | Тенденции с течением времени; непрерывные данные | Данные не являются последовательными |
| **Разброс** | Отношения между двумя переменными | Слишком много перекрывающихся точек |
| **Гистограмма** | Форма распределения одной переменной | Небольшие размеры выборки (<20) |
| **Box plot** | Summary statistics + outliers; compare distributions | Audience unfamiliar with them |
| **Heatmap** | Correlation matrices; patterns in 2D data | Too many variables |
| **Pie chart** | Simple composition (2–5 slices) | More than 5 slices; precise comparisons needed |
| **Violin plot** | Distribution density + quartiles | Small audiences unfamiliar with them |
| **Pair plot** | Quick overview of all variable relationships | Many variables (>8) |

## Принципы проектирования
### Основные идеи Тафте
Принципы Эдварда Тафти остаются золотым стандартом визуализации данных:
| Принцип | Описание |
|-----------|-------------|
| **Максимальное соотношение чернил для данных** | Каждая капля чернил должна передавать данные. Удалите все остальное. |
| **Устранение чартерного мусора** | Никаких 3D-эффектов, произвольных градиентов и декоративных элементов. |
| **Показать данные** | Не искажайте, не прячьте и не выбирайте вишни. Пусть данные говорят. |
| **Маленькие магазины** | Используйте повторяющиеся небольшие диаграммы для сравнения категорий. |
| **Спарклайны** | Крошечные диаграммы размером в слово для встроенных данных о тенденциях. |
### Практические правила проектирования
| Правило | Почему |
|------|-----|
| **Начать ось Y с нуля** (для гистограмм) | В противном случае вы преувеличиваете различия |
| **Ярлык напрямую** | По возможности помещайте метки на линии/столбцы вместо использования легенды |
| **Используйте цвет целенаправленно** | Выделите то, что важно; используйте серый цвет для контекста |
| **Будьте проще** | Одно сообщение на график; не перегружайте |
| **Используйте согласованные шкалы** | При сравнении диаграмм сохраняйте одинаковые оси |
| **Заказывайте осмысленно** | Сортировка столбцов по значению (не в алфавитном порядке), если не существует естественного порядка |
| **Укажите контекст** | Добавьте контрольные показатели, целевые показатели или средние исторические значения |
### Рекомендации по цвету
| Вариант использования | Подход |
|----------|----------|
| **Категорийный** | Выраженные оттенки (синий, оранжевый, зеленый, красный) — максимум 7–8 категорий |
| **Последовательный** | От светлого до темного одного оттенка (голубой → темно-синий) |
| **Расходящиеся** | Двухцветный градиент для данных со значимой средней точкой (красный ← белый → синий) |
| **Доступность** | Тестирование на симуляторах дальтонизма; не полагайтесь только на цвет (добавьте надписи или узоры) |

## Рассказывание историй с помощью данных
Диаграмма без повествования — это просто картинка. Рассказывание историй превращает данные в понимание.
### Структура повествования
1. **Контекст**: Какова ситуация? Что уже знает аудитория?
2. **Конфликт**. В чем заключается проблема, неожиданность или противоречивость данных?
3. **Решение**. Что аудитории следует делать с этой мыслью?
### Практические советы
| Совет | Описание |
|-----|-------------|
| **Управляйте знаниями** | Назовите диаграмму выводом, а не данными («Выручка выросла на 30%», а не «Выручка по кварталам») |
| **Комментируйте ключевые моменты** | Добавьте текстовые выноски для важных событий или поворотных моментов |
| **Используйте постепенное раскрытие информации** | Показывать по одному графику за раз; создайте историю шаг за шагом |
| **Выделите самое важное** | Используйте цвет или размер, чтобы привлечь внимание к ключевой точке данных |
| **Укажите вопрос «Ну и что?»** | Каждая диаграмма должна отвечать на вопрос или побуждать к действию |

## Распространенные ошибки
| Ошибка | Почему это плохо | Исправить |
|---------|-------------|-----|
| **Усеченная ось Y** | Преувеличивает небольшие различия | Начинайте с нуля для гистограмм |
| **Временной диапазон сбора вишен** | Вводят в заблуждение относительно тенденций | Показать весь доступный ассортимент |
| **Слишком много цветов** | Потрясает зрителя | Ограничьте до 5–7; используйте серый цвет для контекста |
| **Двойные оси Y** | Подразумевает корреляцию, которой может не быть | Используйте две отдельные диаграммы |
| **3D-диаграммы** | Искажает пропорции | Всегда используйте 2D |
| **Круговые диаграммы с более чем 10 фрагментами** | Невозможно сравнить | Вместо этого используйте гистограмму |
| **Отсутствуют ярлыки** | Зритель не может понять диаграмму | Всегда обозначайте оси, названия и единицы измерения |
| **Вводящие в заблуждение диаграммы областей** | Сложенные области искажают восприятие отдельных серий | Используйте линейные графики или небольшие кратные |

## Дизайн приборной панели
Панель мониторинга — это набор визуализаций, которые вместе рассказывают полную историю о процессе, системе или бизнесе.
### Типы информационных панелей
| Тип | Аудитория | Цель |
|------|----------|---------|
| **Стратегический** | Руководители | KPI высокого уровня; долгосрочные тенденции |
| **Работает** | Менеджеры | Мониторинг в режиме реального времени; ежедневные операции |
| **Аналитический** | Аналитики | Глубокое исследование; фильтрация, детализация |
### Контрольный список проектирования
– **Знайте свою аудиторию**: какие решения они примут на этой панели?
- **Правило 5 секунд**: можно ли усвоить основную мысль за 5 секунд?
– **Макет**: самые важные показатели вверху слева (куда обращают внимание в первую очередь).
- **Ограничить типы диаграмм**: максимум 3–4 типа на панель мониторинга для обеспечения единообразия.
- **Интерактивно по умолчанию**: фильтры, переключатели диапазонов дат, детализация.
- **Производительность**: панели мониторинга, загрузка которых занимает >5 секунд, не используются.
– **Мобильные устройства**. Рассмотрите возможность использования адаптивного дизайна, если он нужен пользователям в дороге.

## Краткое содержание
Хорошая визуализация данных предполагает ясность, честность и эффективность. Выберите подходящую диаграмму для ваших данных. Удалите все, что не служит сообщению. Используйте цвет и аннотации, чтобы направлять зрителя. И всегда, всегда позволяйте данным рассказывать историю, а не наоборот.
