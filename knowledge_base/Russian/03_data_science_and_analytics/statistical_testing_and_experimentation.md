# Статистическое тестирование и экспериментирование
Статистика – это грамматика науки. Он дает вам инструменты, позволяющие отличать реальные закономерности от случайного шума, определять, действительно ли изменение улучшило ситуацию, и принимать решения в условиях неопределенности. В этом файле описаны основные концепции проверки гипотез, планирования эксперимента и распространенные ошибки, которые сбивают людей с толку.
---

## Структура проверки гипотез
Каждый статистический тест следует одной и той же логике:
1. **Укажите нулевую гипотезу (H₀)**: Нет эффекта/нет разницы.
2. **Изложите альтернативную гипотезу (H₁)**: Эффект/разница есть.
3. **Выберите уровень значимости (α)**: обычно 0,05 (вероятность ложноположительного результата 5%).
4. **Соберите данные и вычислите тестовую статистику**.
5. **Рассчитать значение p**: вероятность получения этого результата (или более экстремального), если H₀ верно.
6. **Примите решение**: если p < α, отклоните H₀ (статистически значимо). В противном случае не удастся отклонить H₀.
### Ключевые понятия
| Концепция | Значение | Распространенное заблуждение |
|---------|---------|---------------------|
| **p-значение** | P(данные \| H₀ верны) | НЕ «вероятность того, что H₀ верна» |
| **α (уровень значимости)** | Порог отклонения H₀ | Не показатель важности эффекта |
| **Статистическая значимость** | Результат маловероятен по чистой случайности | НЕ означает практически значимое |
| **Размер эффекта** | Величина наблюдаемого эффекта | Отдельно от значения p; крошечный эффект может быть значительным при большом N |
| **Сила** | Вероятность правильного отклонения ложного H₀ | Обычно стремятся к 80%+ |
| **Доверительный интервал** | Диапазон возможных значений параметра | 95% ДИ не означает «вероятность 95%, что истинное значение находится в этом диапазоне» |
---

## Типы ошибок
| | H₀ правда | H₀ неверно |
|---|-----------|------------|
| **Отклонить H₀** | Ошибка типа I (ложное срабатывание) | ✅ Правильно (истинно позитивно) |
| **Не удалось отклонить H₀** | ✅ Правильно (истинно отрицательно) | Ошибка II рода (ложноотрицательный результат) |
| Ошибка | Символ | Значение |
|-------|--------|---------|
| **Тип I** | α | Делаем вывод, что эффект есть, а его нет |
| **Тип II** | β | Отсутствие реального эффекта |

## Выбор правильного теста
| Сценарий | Тест | Предположения |
|----------|------|-------------|
| Сравнить средства 2 групп | **t-тест** (независимый) | Нормальное распределение, равная дисперсия |
| Сравнить средства парных наблюдений | **Парный t-критерий** | Различия распределены нормально |
| Сравните средние значения 3+ групп | **АНОВА** | Нормальное распределение, равная дисперсия |
| Сравните категориальные распределения | **Тест хи-квадрат** | Достаточный размер выборки на ячейку |
| Сравнить распределения (непараметрические) | **Манн-Уитни Ю** | Нет предположения о нормальности |
| Сравнить 3+ группы (непараметрические) | **Краскал-Уоллис** | Нет предположения о нормальности |
| Тест корреляции | **Пирсон** (линейный) или **Спирмен** (монотонный) | Пирсон: нормальность; Копейщик: на основе рангов |
| Проверьте, соответствуют ли данные распределению | **Колмогоров-Смирнов** | Непрерывные данные |
### Параметрический и непараметрический
| | Параметрический | Непараметрический |
|---|-----------|---------------|
| **Предположения** | Данные следуют определенному распределению (обычно нормальному) | Нет предположения о распределении |
| **Сила** | Выше, когда предположения оправдались | Ниже, но надежнее |
| **Когда использовать** | Большие выборки, примерно нормальные данные | Маленькие выборки, искаженные данные, порядковые данные |

## Подробные тесты
### t-тест
Сравнивает средства двух групп.
| Вариант | Вариант использования |
|---------|----------|
| **Независимый t-тест** | Две отдельные группы (лечение и контроль) |
| **Парный t-критерий** | Одна и та же группа измерялась дважды (до и после) |
| **Одновыборочный t-критерий** | Сравнить выборочное среднее с известным значением |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA (дисперсионный анализ)
Сравнивает средние значения по 3 или более группам. Проверяет, отличается ли хотя бы одно среднее значение группы от остальных.
| Тип | Дизайн |
|------|--------|
| **Односторонний дисперсионный анализ** | Одна независимая переменная с 3+ уровнями |
| **Двусторонний дисперсионный анализ** | Две независимые переменные; тесты эффектов взаимодействия |
| **Повторные измерения ANOVA** | Одни и те же предметы, измеренные в разных условиях |
Если ANOVA значителен, проведите **апостериорные тесты** (HSD Тьюки), чтобы определить, какие конкретные группы отличаются.
### Тест хи-квадрат
Проверяет, являются ли две категориальные переменные независимыми.
| Вариант использования | Пример |
|----------|---------|
| **Тест на независимость** | Связан ли пол с предпочтением продукта? |
| **Хорошее соответствие** | Равномерно ли распределение кубиков при броске? |
**Практическое правило**: ожидаемое количество ячеек должно быть не менее 5.

## A/B-тестирование
A/B-тестирование — это применение проверки гипотез к бизнес-решениям, обычно сравнивающее контрольный вариант (A) с вариантом (B).
### Процесс проектирования
| Шаг | Описание |
|------|-------------|
| **1. Определить гипотезу** | «Изменение цвета кнопки с синего на зеленый повысит рейтинг кликов» |
| **2. Выберите показатель** | Основной: рейтинг кликов. Второстепенные: коэффициент конверсии, доход. |
| **3. Рассчитать размер выборки** | На основе минимально обнаруживаемого эффекта, мощности (80%) и значимости (5%) |
| **4. Случайный** | Случайное назначение пользователей для контроля и лечения |
| **5. Запустить эксперимент** | Собирать данные до тех пор, пока не будет достигнут целевой размер выборки |
| **6. Анализ** | Сравните показатели, используя соответствующий статистический тест |
| **7. Решите** | Внедрить, если статистически и практически значимо |
### Расчет размера выборки
Необходимый размер выборки зависит от:
| Фактор | Влияние на размер выборки |
|--------|----------------------|
| **Меньший эффект для обнаружения** | Нужно больше образцов |
| **Высшая мощность** | Нужно больше образцов |
| **Нижний уровень значимости** | Нужно больше образцов |
| **Более высокая дисперсия** | Нужно больше образцов |
### Распространенные ошибки A/B-тестирования
| Ошибка | Почему это неправильно |
|---------|---------------|
| **Подсматриваем рано** | Ежедневная проверка результатов увеличивает количество ложноположительных результатов |
| **Несколько показателей без коррекции** | Тестирование 20 метрик при α=0,05 → ожидайте 1 случайного ложного срабатывания |
| **Остановка перед целью N** | Тест с недостаточной мощностью не может обнаружить реальные эффекты |
| **Игнорируя сезонность** | Проведение теста в праздничные дни по сравнению с обычной неделей |
| **Неслучайное назначение** | Предвзятость отбора (например, назначение на лечение новых пользователей) |
| **Спутанное значение с важностью** | Увеличение на 0,1% может быть статистически значимым, но его не стоит отправлять |

## Множественные сравнения
Когда вы запускаете множество тестов одновременно, вероятность хотя бы одного ложноположительного результата резко возрастает.
| Количество тестов | Вероятность ≥1 ложного срабатывания (при α=0,05) |
|----------------|----------------------------------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 40% |
| 20 | 64% |
### Исправления
| Метод | Как это работает | Когда использовать |
|--------|-------------|-------------|
| **Бонферрони** | Разделите α на количество тестов (α/n) | Консервативный; несколько сравнений |
| **Холм-Бонферрони** | Процедура понижения; менее консервативный | Общего использования |
| **Бенджамини-Хохберг (ФРГ)** | Контролирует уровень ложного обнаружения | Множество тестов; исследовательский анализ |

## Размер эффекта
P-значения сообщают вам, *существует ли* эффект. Размер эффекта говорит вам, насколько он велик.
| Мера | Для | Интерпретация |
|---------|-----|---------------|
| **Черт Коэна** | Разница между двумя средствами | 0,2 = маленький, 0,5 = средний, 0,8 = большой |
| **Пирсонс** | Корреляция | 0,1 = маленький, 0,3 = средний, 0,5 = большой |
| **η² (эта-квадрат)** | дисперсионный анализ | 0,01 = маленький, 0,06 = средний, 0,14 = большой |
| **Коэффициент шансов** | Категориальные результаты | 1,0 = нет эффекта; >1 или <1 = эффект |
**Всегда указывайте величину эффекта вместе со значениями p.** Результат может быть статистически значимым, но практически бессмысленным.

## Байесовский против частого
| Аспект | Частый посетитель | Байесовский |
|--------|------------|----------|
| **Вероятность** | Долгосрочная частота событий | Степень веры |
| **Параметры** | Исправлено, но неизвестно | Случайные величины с распределениями |
| **Применение** | p-значения, доверительные интервалы, проверка гипотез | Апостериорные распределения, достоверные интервалы |
| **Предыдущий** | Никаких предварительных убеждений | Явное предварительное распределение |
| **Интерпретация** | "Если бы мы повторили этот эксперимент много раз..." | "Учитывая данные, вероятность того, что..." |
| **Сильные стороны** | Объективный, устоявшийся, простой | Интуитивная интерпретация, включающая предварительные знания |
| **Слабые стороны** | p-значения широко понимаются неправильно | Выбор приора может быть субъективным |

## Основы причинного вывода
Корреляция – это не причинно-следственная связь. Но иногда вам нужно знать *вызвало ли X Y*, а не только то, связаны ли они.
| Метод | Описание | Когда использовать |
|--------|-------------|-------------|
| **Рандомизированные эксперименты** | Золотой стандарт; случайное назначение устраняет помехи | Когда вы можете рандомизировать |
| **Разница в различиях (DiD)** | Сравните изменения с течением времени между лечением и контролем | Изменения в политике, естественные эксперименты |
| **Разрыв регрессии (RDD)** | Используйте порог отсечки | Стипендии, пороги участия |
| **Инструментальные переменные (IV)** | Используйте инструмент, который влияет на лечение, но не на результат напрямую | Когда рандомизация невозможна |
| **Сопоставление показателей склонности** | Сопоставление обрабатываемых и управляющих блоков по наблюдаемым характеристикам | Наблюдательные исследования |

## Распространенные статистические ошибки
| Ошибка | Описание |
|---------|-------------|
| **п-хакинг** | Пробуйте множество анализов, пока не найдете p < 0,05 |
| **ВНИМАНИЕ** | Выдвижение гипотез после того, как стали известны результаты |
| **Предвзятость выжившего** | Смотрим только на успехи (например, на успешные компании) |
| **Парадокс Симпсона** | Тенденция меняется на противоположную, когда данные агрегируются, а не разбиваются по группам |
| **Игнорирование базовой ставки** | Игнорирование априорной вероятности при интерпретации результатов |
| **Экологическое заблуждение** | Выводы об индивидуальном поведении на основе данных на уровне группы |
| **Сбивает с толку** | Третья переменная объясняет наблюдаемую взаимосвязь |
| **Переоснащение** | Модель улавливает шум, а не сигнал |
---

## Краткое содержание
Статистическое тестирование предполагает принятие решений в условиях неопределенности с интеллектуальной честностью. Всегда высказывайте свои гипотезы перед сбором данных. Выберите правильный тест для вашего типа данных. Сообщайте о размерах эффекта, а не только о значениях p. Правильно для множественных сравнений. И помните: статистическая значимость — это не то же самое, что практическая значимость.
