# Разработка функций
Разработка функций — это процесс преобразования необработанных данных в представления, которые делают модели машинного обучения более эффективными. Его часто называют самым важным шагом в конвейере машинного обучения: функции, которые вы предоставляете модели, имеют большее значение, чем выбранный вами алгоритм. Простая модель с хорошо продуманными функциями обычно превосходит сложную модель с необработанными, необработанными входными данными. Искусство заключается в том, чтобы достаточно хорошо понимать как предметную область, так и данные, чтобы создавать сигналы, на которых модель может учиться.
---

## Почему важна разработка функций
| Фактор | Воздействие |
|--------|--------|
| **Качество сигнала** | Лучшие функции = более четкие шаблоны для изучения модели |
| **Простота модели** | Хорошие функции позволяют более простым моделям работать хорошо; меньше необходимости в сложной архитектуре |
| **Скорость обучения** | Соответствующие, хорошо масштабируемые функции сходятся быстрее |
| **Обобщение** | Функции, основанные на предметной информации, помогают моделям работать с невидимыми данными |
| **Интерпретируемость** | Значимые функции легче объяснить заинтересованным сторонам |

## Типы преобразований объектов
### Числовые преобразования
| Трансформация | Формула/Описание | Когда использовать |
|---------------|----------------------|-------------|
| **Преобразование журнала** | журнал(х) или журнал(х + 1) | Правое распределение; денежные ценности |
| **Квадратный корень** | кврт(х) | Умеренный перекос; подсчитать данные |
| **Бокс-Кокс** | Параметрическое преобразование, которое находит лучшее степенное преобразование | Обеспечение более нормального распределения данных |
| **Йео-Джонсон** | Как Box-Cox, но обрабатывает отрицательные значения | Искаженные данные с отрицательными значениями |
| **Стандартизация** | (x - среднее) / стандарт | Функции с разными масштабами; алгоритмы, предполагающие нормальность |
| **Мин-макс масштабирование** | (х - мин) / (макс - мин) | Ограничивающие объекты до [0, 1]; значения пикселей изображения |
| **Надежное масштабирование** | (x - медиана) / IQR | Данные с выбросами |
| **Биннинг** | Преобразование непрерывного в категориальное | Нелинейные отношения; деревья решений |
| **Полиномиальные характеристики** | x², x³, x₁×x₂ | Учет нелинейных связей в линейных моделях |
### Категориальные кодировки
| Кодирование | Описание | Когда использовать |
|----------|-------------|-------------|
| **Горячее кодирование** | Создайте двоичный столбец для каждой категории | Категории малой мощности; древовидные модели обрабатываются изначально |
| **Кодировка этикетки** | Присвойте целое число каждой категории | Порядковые категории; древовидные модели |
| **Целевая кодировка** | Заменить категорию средним значением целевой переменной | Категории высокой мощности; избегайте переобучения при сглаживании |
| **Частотное кодирование** | Заменить категорию ее количеством или частотой | Когда частота сама по себе информативна |
| **Двоичное кодирование** | Преобразование категорий с целочисленной кодировкой в ​​двоичные цифры | Высокая мощность; уменьшает размерность по сравнению с one-hot |
| **Встраивание** | Изучите плотное векторное представление | Очень высокая мощность; НЛП; рекомендательные системы |
| **Хеш-кодирование** | Хэш-категории для фиксированного количества функций | Очень высокая мощность; онлайн-обучение |
### Функции даты и времени
| Особенность | Описание |
|---------|-------------|
| **Час дня** | Фиксирует ежедневные закономерности (час пик, ночное время) |
| **День недели** | Эффекты будних и выходных дней |
| **Месяц/квартал** | Сезонные модели |
| **Выходные** | Бинарный флаг на выходные |
| **Праздник** | Двоичный флаг для государственных праздников |
| **Время после события** | Дней с момента последней покупки; часов с момента последнего входа в систему |
| **Циклическое кодирование** | sin(2π × час/24), cos(2π × час/24) — сохраняет круговую природу времени |

## Обработка пропущенных значений
| Стратегия | Описание | Когда использовать |
|----------|-------------|-------------|
| **Удалить строки** | Удалить строки с пропущенными значениями | Недостающие данные составляют небольшую часть; MCAR (отсутствует совершенно случайно) |
| **Удалить столбцы** | Удалить объекты со слишком большим количеством пропущенных значений | Функция практически отсутствует; не важно |
| **Среднее/медианное вменение** | Заполните средним или медианным значением объекта | Простой; сохраняет среднее значение, но уменьшает дисперсию |
| **Вменение режима** | Заполните категорию наиболее частым значением | Категориальные особенности |
| **Вменение KNN** | Используйте k-ближайших соседей, чтобы оценить недостающее значение | Когда подобные примеры помогают предсказать пропущенное значение |
| **Вменение на основе модели** | Обучите модель прогнозированию пропущенных значений | Более точный; вычислительно дорого |
| **Отсутствует индикатор** | Добавьте двоичный столбец, помечающий отсутствие | Когда отсутствие само по себе информативно |
| **Интерполяция** | Заполнить интерполированными значениями (линейными, сплайнами) | Временной ряд; заказанные данные |

## Выбор функции
### Методы фильтрации
| Метод | Описание |
|--------|-------------|
| **Корреляция** | Удалить функции, сильно коррелирующие друг с другом |
| **Порог отклонения** | Удалить функции с почти нулевой дисперсией |
| **Взаимная информация** | Измерьте информацию о цели, которую предоставляет каждая функция |
| **Хи-квадрат** | Проверка независимости между категориальными признаками и целью |
| **F-тест ANOVA** | Проверьте, различаются ли числовые средние значения признаков в разных целевых классах |
### Методы-обертки
| Метод | Описание |
|--------|-------------|
| **Прямой выбор** | Начните пусто; добавляйте лучшие функции по одной |
| **Обратное исключение** | Начните со всего; удалять худшие функции по одной |
| **Рекурсивное устранение признаков (RFE)** | Многократно обучать модель; удалить наименее важные функции |
### Встроенные методы
| Метод | Описание |
|--------|-------------|
| **Регуляризация L1 (Лассо)** | Сжимает нерелевантные веса функций до нуля |
| **Важность на основе дерева** | Использовать важность признаков из древовидных моделей |
| **Значения SHAP** | Измерьте вклад каждой функции в прогнозы |

## Разработка функций, специфичных для предметной области
### Текстовые функции
| Особенность | Описание |
|---------|-------------|
| **ТФ-ИДФ** | Частота терминов, взвешенная по обратной частоте документов |
| **Внедрение слов** | Плотные векторы, улавливающие семантическое значение (Word2Vec, GloVe) |
| **Н-граммы символов** | Захват шаблонов подслов; полезно при опечатках и морфологии |
| **Текстовая статистика** | Длина; количество слов; количество предложений; средняя длина слова |
| **Оценки читабельности** | Флеш-Кинкейд; Индекс артиллерийского тумана |
### Особенности временных рядов
| Особенность | Описание |
|---------|-------------|
| **Функции задержки** | Предыдущие значения: y(t-1), y(t-7), y(t-30) |
| **Постоянная статистика** | Среднее, стандартное, мин, макс над окном |
| **Разница** | у(т) - у(т-1); улавливает тренд |
| **Сезонная разница** | y(t) - y(t-12) для ежемесячных данных с годовой сезонностью |

| Особенность | Описание |
|---------|-------------|
| **HOG** (гистограмма ориентированных градиентов) | Распределение краевых направлений |
| **LBP** (локальные бинарные шаблоны) | Описание текстуры |
| **SIFT** (масштабно-инвариантное преобразование объектов) | Дескрипторы ключевых точек |
| **Цветные гистограммы** | Распределение цветов на изображении |

## Лучшие практики разработки функций
| Практика | Описание |
|----------|-------------|
| **Избегайте утечки данных** | Никогда не используйте информацию из будущего или тестовый набор для создания функций |
| **Документируйте все** | Запишите, какие преобразования были применены и почему |
| **Версия функций** | Отслеживайте изменения функций вместе с изменениями модели |
| **Проверить с наличием и без** | Проверьте, действительно ли новая функция улучшает производительность модели |
| **Сохраняйте воспроизводимость** | Конвейеры разработки функций должны быть детерминированными и повторяемыми |
| **Отслеживание изменений функций** | Распределение функций может меняться со временем; контролировать и переобучать |

## Краткое содержание
Разработка функций — это сочетание предметной области и машинного обучения. Это процесс преобразования необработанных данных — беспорядочных, неполных, многомерных — в чистые, информативные представления, на которых модели могут учиться. Числовые преобразования управляют перекосом и масштабом. Категориальные кодировки преобразуют метки в числа, которые могут использовать модели. Функции даты фиксируют временные закономерности. Стратегии отсутствия ценности обрабатывают неполные данные. Выбор функций устраняет шум и избыточность. Лучшие инженеры-функционеры мыслят как детективы: они спрашивают, какие сигналы должны присутствовать в данных, где эти сигналы могут быть спрятаны и как извлечь их честным (без утечки данных), воспроизводимым и устойчивым к изменениям с течением времени образом.
