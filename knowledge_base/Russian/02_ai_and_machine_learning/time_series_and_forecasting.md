# Временные ряды и прогнозирование
Данные временных рядов — это любые данные, собранные с течением времени: цены на акции, показания температуры, посещаемость веб-сайта, показатели продаж, данные пульсометров, потребление энергии. Прогнозирование означает предсказание будущих значений на основе прошлых моделей. Это одно из наиболее практически ценных применений науки о данных — и одно из самых сложных, поскольку будущее действительно неопределенно, а реальные временные ряды полны шума, сезонности и структурных разрывов.
---

## Характеристики временного ряда
| Компонент | Описание | Пример |
|-----------|-------------|---------|
| **Тренд** | Долгосрочное увеличение или уменьшение | Глобальная температура растет на протяжении десятилетий |
| **Сезонность** | Регулярные, предсказуемые закономерности через фиксированные промежутки времени | Розничные продажи растут каждый декабрь |
| **Цикличность** | Колебания через нефиксированные промежутки времени (часто экономические) | Рецессии каждые 5-10 лет |
| **Шум (остаточный)** | Случайное изменение, которое невозможно объяснить | Ежедневные движения цен на акции |
| **Автокорреляция** | Текущие значения зависят от прошлых значений | Сегодняшняя температура аналогична вчерашней |
### Стационарность
Временной ряд считается **стационарным**, если его статистические свойства (среднее значение, дисперсия) не меняются с течением времени. Большинство методов прогнозирования предполагают стационарность.
| Тест | Цель |
|------|---------|
| **Дополненный Дикки-Фуллер (ADF)** | Проверяет наличие единичного корня (нестационарный) |
| **Тест КПСС** | Проверяет, является ли ряд стационарным по тренду |
| Трансформация | Когда использовать |
|---------------|-------------|
| **Разница** | Удалить тренд: y'(t) = y(t) - y(t-1) |
| **Преобразование журнала** | Стабилизировать дисперсию (для экспоненциального роста) |
| **Сезонные различия** | Удалить сезонность: y'(t) = y(t) - y(t-s), где s — продолжительность сезона |

## Классические методы прогнозирования
### Скользящие средние
| Метод | Описание | Лучшее для |
|--------|-------------|----------|
| **Простое скользящее среднее (SMA)** | Среднее значение последних N наблюдений | Сглаживание зашумленных данных |
| **Взвешенное скользящее среднее** | Более поздние наблюдения получили больший вес | Когда последние данные имеют большее значение |
| **Экспоненциальная скользящая средняя (EMA)** | Экспоненциально убывающие веса | Отслеживание тенденций с меньшими задержками |
### Экспоненциальное сглаживание
| Метод | Компоненты | Вариант использования |
|--------|-----------|----------|
| **Простой (SES)** | Только уровень | Нет тренда, нет сезонности |
| **Холта (двойной)** | Уровень + тренд | Данные с тенденцией, но без сезонности |
| **Холт-Уинтерс (Тройной)** | Уровень + тренд + сезонность | Данные с тенденцией и сезонностью |
###АРИМА и варианты
ARIMA (авторегрессионное интегрированное скользящее среднее) — это рабочая лошадка классического прогнозирования временных рядов.
| Компонент | Значение | Параметр |
|-----------|---------|-----------|
| **АР (п)** | Регрессия по предыдущим значениям p | Сколько прошлых значений использовать |
| **Я (д)** | Количество шагов дифференцирования, чтобы сделать стационарным | Сколько раз разница |
| **МА (к)** | Смоделируйте ошибку как комбинацию прошлых ошибок | Сколько прошлых ошибок использовать |
| Вариант | Расширение | Вариант использования |
|---------|-----------|----------|
| **САРИМА** | Добавляет сезонные компоненты (P, D, Q, s) | Данные с сильной сезонностью |
| **АРИМАКС** | Добавляет внешние переменные | Когда вы узнаете о предстоящих событиях |
| **ВАР** | Многомерный ARIMA; несколько взаимозависимых серий | Когда переменные влияют друг на друга |

## Современные подходы к машинному обучению
### Модели на основе LSTM и RNN
| Модель | Архитектура | Преимущество |
|-------|-------------|-----------|
| **ЛСТМ** | Сеть долговременной краткосрочной памяти | Фиксирует долгосрочные временные зависимости |
| **ГРУ** | Закрытый рекуррентный блок (более простой LSTM) | Более быстрое обучение; аналогичная производительность |
| **Seq2Seq** | Кодер-декодер временных рядов | Гибкая длина ввода/вывода |
| **Временная сверточная сеть (TCN)** | Расширенные причинные извилины | Параллельное обучение; длинное рецептивное поле |
### Пророк (Мета)
Практический инструмент прогнозирования, предназначенный для бизнес-временных рядов.
| Особенность | Описание |
|---------|-------------|
| **Разложение** | Тренд + сезонность + праздники |
| **Гибкий** | Обрабатывает недостающие данные, выбросы и структурные разрывы |
| **Интерпретируемый** | Компоненты удобочитаемы |
| **Автоматически** | Разумные значения по умолчанию; требуется минимальная настройка |
| Сила | Ограничение |
|----------|------------|
| Отлично подходит для бизнес-показателей (продажи, пользователи) | Не идеально подходит для очень высокочастотных данных |
| Обрабатывает праздники и специальные мероприятия | Предполагает аддитивную или мультипликативную сезонность |
| Устойчив к выбросам | Менее точное, чем глубокое обучение, для сложных шаблонов |
### Модели на основе трансформатора
| Модель | Ключевая особенность |
|-------|-------------|
| **Информер** | ProbSparse внимание для длинных последовательностей |
| **Автоформер** | Механизм автокорреляции для разложения рядов |
| **ПатчТСТ** | Исправляет временной ряд; независимый от канала |
| **TimesFM** (Google) | Базовая модель временных рядов; предварительно обучен на разнообразных данных |
| **Хронос** (Амазонка) | Токенизирует временные ряды; использует архитектуру в стиле LLM |

## Обнаружение аномалий во временных рядах
Обнаружение необычных закономерностей, которые отклоняются от ожидаемого поведения.
| Метод | Подход | Вариант использования |
|--------|----------|----------|
| **Статистическая** | Z-показатель, IQR, контрольные диаграммы | Просто, понятно |
| **Изолированный лес** | Древовидный; изолирует аномалии путем случайного разделения | Многомерное обнаружение аномалий |
| **LOF** (коэффициент локального выброса) | На основе плотности; сравнивает плотность населения с плотностью соседей | Когда аномалии находятся в регионах с низкой плотностью населения |
| **Автоэнкодеры** | Ошибка реконструкции; высокая ошибка = аномалия | Сложные нелинейные узоры |
| **На основе LSTM** | Прогнозировать следующий шаг; большая ошибка прогноза = аномалия | Последовательные аномалии |
### Приложения
| Домен | Что означают аномалии |
|--------|-------------------|
| **Финансы** | Мошенничество, крах рынка, флэш-крахи |
| **Здравоохранение** | Нарушение сердечного ритма, начало судорог |
| **Производство** | Отказ оборудования, дефекты качества |
| **Кибербезопасность** | Попытки проникновения, DDoS-атаки |
| **Инфраструктура** | Перегрузка сервера, сбои сети |

## Метрики оценки
| Метрическая | Формула (концептуальная) | Когда использовать |
|--------|---------------------|-------------|
| **MAE** (средняя абсолютная ошибка) | Среднее значение абсолютных ошибок | интерпретируемый; те же единицы, что и данные |
| **RMSE** (среднеквадратическая ошибка) | Квадратный корень из среднеквадратических ошибок | Наказывает за крупные ошибки подробнее |
| **MAPE** (средняя абсолютная процентная ошибка) | Среднее значение абсолютных процентных ошибок | Когда относительная ошибка имеет значение |
| **SMAPE** (симметричный MAPE) | Симметричная версия MAPE | Лучше обрабатывает значения, близкие к нулю |
| **MASE** (средняя абсолютная масштабированная ошибка) | MAE относительно наивного прогноза | Сравнение разных серий |

## Практический рабочий процесс
| Шаг | Описание |
|------|-------------|
| **1. Исследуйте** | Сюжет сериала; выявить тренд, сезонность, выбросы |
| **2. Разложить** | Разделение на трендовые, сезонные и остаточные компоненты |
| **3. Стационарный** | При необходимости примените разность или преобразования |
| **4. Сплит** | Разделение по времени (никогда не случайное разделение временных рядов) |
| **5. Базовый уровень** | Начните с простого прогноза (последнее значение, сезонный прогноз) |
| **6. Модель** | Попробуйте классические методы (ARIMA, Prophet), затем методы ML |
| **7. Оценить** | Используйте соответствующие метрики; сравнить с базовым уровнем |
| **8. Итерировать** | Добавляйте функции, пробуйте разные модели, настраивайте гиперпараметры |

## Краткое содержание
Прогнозирование временных рядов сочетает классическую статистику с современным машинным обучением. Классические методы (ARIMA, экспоненциальное сглаживание, Prophet) интерпретируемы, быстры и часто удивительно точны. Методы глубокого обучения (LSTM, Transformers) фиксируют сложные закономерности, но требуют больше данных и настройки. Ключевые принципы остаются неизменными независимо от метода: понимать структуру ваших данных (тенденция, сезонность, шум), всегда сравнивать их с простой базовой линией, оценивать с помощью соответствующих показателей и помнить, что будущее никогда не является идеальным повторением прошлого.
