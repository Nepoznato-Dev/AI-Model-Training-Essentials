# Федеративное обучение и конфиденциальность
Федеративное обучение — это метод обучения моделей машинного обучения на нескольких устройствах или в организациях без совместного использования необработанных данных. Вместо отправки данных на центральный сервер каждое устройство обучает локальную модель и передает только обновления модели (градиенты или веса). Центральный сервер объединяет эти обновления для создания глобальной модели. Он был разработан Google для обучения моделей языка клавиатуры на телефонах Android — и с тех пор стал ключевым методом для сохранения конфиденциальности ИИ.
---

## Почему федеративное обучение?
| Мотивация | Описание | Пример |
|------------|-------------|---------|
| **Конфиденциальность данных** | Необработанные данные никогда не покидают устройство | Медицинские документы остаются в больнице; фотографии остаются в телефоне |
| **Соответствие нормативным требованиям** | GDPR, HIPAA и другие правила ограничивают обмен данными | Банки могут сотрудничать, не разглашая данные о клиентах |
| **Объем данных** | Перенос данных — это дорого и медленно | Обучение на миллиардах телефонов непрактично, если необходимо загружать данные |
| **Конфиденциальность данных** | Некоторые данные слишком конфиденциальны, чтобы их можно было передавать даже при наличии согласия | правительственная разведка; личные данные о здоровье |
---

## Как работает федеративное обучение
### Базовый протокол (FedAvg)
| Шаг | Что происходит |
|------|-------------|
| **1. Инициализировать** | Центральный сервер создает глобальную модель со случайными весами |
| **2. Распространить** | Сервер отправляет текущую глобальную модель выбранным устройствам |
| **3. Местное обучение** | Каждое устройство обучает модель на своих локальных данных в течение нескольких эпох |
| **4. Загрузить** | Устройства отправляют обновленные веса моделей (не данные) обратно на сервер |
| **5. Совокупный** | Сервер усредняет веса (федеративное усреднение) для создания новой глобальной модели |
| **6. Повторить** | Возвращайтесь к шагу 2, пока модель не сойдётся |
```
Server: global_model = average(local_model_1, local_model_2, ..., local_model_n)
```

### Ключевые свойства
| Недвижимость | Описание |
|----------|-------------|
| **Данные, не относящиеся к IID** | Каждое устройство имеет разное распределение данных (не независимое, а одинаковое) |
| **Несбалансированные данные** | На некоторых устройствах много данных, на других очень мало |
| **Частичное участие** | Не все устройства доступны в каждом раунде |
| **Эффективность связи** | Узким местом является общение, а не вычисления |
---

## Варианты федеративного обучения
| Вариант | Описание | Преимущество |
|---------|-------------|-----------|
| **ФедАвг** | Средний вес модели на разных устройствах | Простой; хорошо работает с данными IID |
| **ФедПрокс** | Добавляет дополнительный срок к местному обучению | Лучше для данных, отличных от IID |
| **ЛЕША** | Использует контрольные переменные для коррекции неоднородности данных | Более быстрая сходимость данных, отличных от IID |
| **ФедСГД** | Как FedAvg, но с одним шагом градиента за раунд | Снижение стоимости связи за раунд |
| **Персонализированный FL** | Каждое устройство поддерживает персональную модель наряду с глобальной | Улучшенная производительность каждого устройства |
| **Вертикальная FL** | Различные функции (а не разные образцы) у разных сторон | Когда стороны владеют разными аспектами одних и тех же данных |
---

## Дифференциальная конфиденциальность
Дифференциальная конфиденциальность (DP) обеспечивает математическую гарантию того, что выходные данные алгоритма не покажут, были ли включены данные какого-либо человека.
### Основное определение
Механизм M обеспечивает (ε, δ)-дифференциальную конфиденциальность, если для любых двух наборов данных D и D', которые различаются одной записью:
```
P(M(D) ∈ S) ≤ e^ε × P(M(D') ∈ S) + Î´
```

| Параметр | Значение |
|-----------|---------|
| **ε (эпсилон)** | Бюджет конфиденциальности. Меньше = более приватно. Типичные значения: 0,1–10. |
| **δ (дельта)** | Вероятность того, что гарантия конфиденциальности не удастся. Обычно устанавливается на 1/N (обратно размеру набора данных). |
### Механизмы повышения конфиденциальности
| Механизм | Как это работает | Вариант использования |
|-----------|-------------|----------|
| **Гауссов механизм** | Добавьте гауссов шум, откалиброванный по чувствительности запроса | Непрерывные значения (веса модели) |
| **Механизм Лапласа** | Добавить шум Лапласа | Подсчет запросов |
| **Экспоненциальный механизм** | Выбирайте результаты с вероятностью, пропорциональной их полезности | Дискретный выбор |
### DP-SGD (Дифференциально частный стохастический градиентный спуск)
| Шаг | Описание |
|------|-------------|
| 1. Вычисление градиентов для каждой выборки | Вместо пакетных градиентов |
| 2. Градиенты обрезки | Ограничивает максимальную норму каждого градиента (ограничивает влияние любого отдельного образца) |
| 3. Добавьте шум | Добавьте калиброванный гауссов шум к агрегированному градиенту |
| 4. Обновить параметры | Стандартный шаг градиентного спуска |
| Компромисс | Описание |
|-----------|-------------|
| **Конфиденциальность или точность** | Более строгая конфиденциальность (более низкое ε) требует большего шума, что снижает точность модели |
| **Конфиденциальность и время обучения** | Больше шума означает более медленную сходимость |
| **Отслеживание бюджета конфиденциальности** | Каждый этап обучения потребляет часть бюджета конфиденциальности; однажды потраченное, его невозможно вернуть |
---

## Сочетание федеративного обучения с дифференциальной конфиденциальностью
| Слой | Защита |
|-------|-----------|
| **Федеративное обучение** | Необработанные данные остаются на устройствах |
| **Дифференциальная конфиденциальность** | Даже обновления моделей содержат шум, защищая отдельные вклады |
| **Безопасное агрегирование** | Сервер видит только совокупность всех обновлений, а не отдельные |
Такое сочетание обеспечивает надежные гарантии конфиденциальности: даже если сервер будет взломан, он не сможет определить, использовались ли данные какого-либо конкретного человека при обучении.
---

## Другие методы сохранения конфиденциальности
### Безопасные многосторонние вычисления (SMPC)
Несколько сторон вычисляют функцию на основе своих объединенных данных, не раскрывая свои индивидуальные входные данные.
| Особенность | Описание |
|---------|-------------|
| **Как это работает** | Данные разбиваются на доли, распределяемые между сторонами; вычисления происходят на акциях |
| **Гарантия** | Ни одна сторона ничего не узнает о вкладе других |
| **Накладные расходы** | Значительные затраты на связь и вычисления |
| **Сценарий использования** | Банки рассчитывают совместные модели риска, не разглашая данные о клиентах |
### Гомоморфное шифрование (HE)
Выполняйте вычисления непосредственно на зашифрованных данных.
| Тип | Что он поддерживает | Накладные расходы |
|------|-----------------|----------|
| **Частично HE** | Одна операция (сложение ИЛИ умножение) | Низкий |
| **Несколько ОН** | Ограниченное количество обеих операций | Средний |
| **Полностью HE** | Произвольные вычисления | Очень высокий (замедление в 100-1000 раз) |
| Приложение | Описание |
|-------------|-------------|
| **Частный вывод** | Запуск моделей машинного обучения на зашифрованных данных; вернуть зашифрованные прогнозы |
| **Зашифрованное обучение** | Обучение зашифрованным данным (по-прежнему в основном теоретическое для глубокого обучения) |
| **Частные вопросы** | Запросить базу данных, не раскрывая запрос или данные |
### Доверенные среды выполнения (TEE)
Аппаратная изоляция (Intel SGX, ARM Trustzone), защищающая данные даже из ОС.
| Преимущество | Ограничение |
|-----------|------------|
| Почти родная производительность | Требуется специальное оборудование |
| Надежные гарантии безопасности | Ограниченная память (размер анклава) |
| Никаких криптографических накладных расходов | Возможны атаки по побочным каналам |

## Правила конфиденциальности и ОД
| Регулирование | Регион | Влияние на ОД |
|------------|--------|-------------|
| **ВВП** | ЕС | Право на объяснение; минимизация данных; согласие на обработку; право на удаление |
| **CCPA** | Калифорния | Право знать, удалять и отказываться от продажи данных |
| **HIPAA** | США (здравоохранение) | Строгий контроль данных о состоянии здоровья; требования деидентификации |
| **ПИПЛ** | Китай | Локализация данных; требования согласия; правила трансграничных переводов |
| **Закон об искусственном интеллекте** | ЕС | Требования прозрачности; классификация рисков; запрещенные практики |
### Влияние на рабочие процессы машинного обучения
| Принцип GDPR | Применение машинного обучения |
|----------------|---------------|
| **Минимизация данных** | Собирайте только то, что необходимо; федеративное обучение помогает |
| **Ограничение цели** | Невозможно повторно использовать данные без нового согласия |
| **Право на удаление** | Должен уметь удалять данные человека из обученной модели (машинное отучение) |
| **Право на объяснение** | Модели должны быть достаточно интерпретируемыми, чтобы объяснить отдельные прогнозы |
| **Конфиденциальность по замыслу** | Конфиденциальность должна быть встроена в системы с самого начала |

## Проблемы
| Вызов | Описание |
|-----------|-------------|
| **Стоимость связи** | Отправка обновлений модели на миллионы устройств обходится дорого |
| **Данные, не относящиеся к IID** | Устройства имеют очень разное распределение данных, что мешает конвергенции |
| **Отставшие** | Медленные устройства задерживают весь раунд |
| **Компромисс конфиденциальности и полезности** | Более высокий уровень конфиденциальности означает худшую производительность модели |
| **Отравляющие атаки** | Злонамеренные участники могут испортить глобальную модель |
| **Извлечение модели** | Даже общие обновления модели могут привести к утечке информации об обучающих данных |
| **Неоднородность оборудования** | Разные устройства имеют разные вычислительные возможности |

## Краткое содержание
Методы федеративного обучения и сохранения конфиденциальности решают фундаментальное противоречие: как создавать мощные модели ИИ, когда данные распределены, конфиденциальны или регулируются? Федеративное обучение сохраняет данные на устройствах и передает только обновления моделей. Дифференциальная конфиденциальность добавляет математические гарантии того, что индивидуальный вклад не может быть обнаружен. Безопасные вычисления и гомоморфное шифрование идут дальше, позволяя выполнять вычисления на зашифрованных данных. Каждый метод имеет свои издержки — накладные расходы на связь, снижение точности, вычислительные затраты — но вместе они образуют набор инструментов для создания ИИ, который уважает конфиденциальность и при этом учится на мировых данных.
