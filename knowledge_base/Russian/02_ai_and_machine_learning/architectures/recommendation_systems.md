# Рекомендательные системы
Системы рекомендаций предсказывают, что пользователь захочет увидеть, купить или с чем взаимодействовать в следующий раз. Они обеспечивают подачу контента в социальных сетях, предложения продуктов на сайтах электронной коммерции, выбор фильмов на потоковых платформах и результаты поиска. Несмотря на то, что они невидимы для большинства пользователей, они входят в число наиболее коммерчески эффективных систем искусственного интеллекта в мире — по оценкам Netflix, их система рекомендаций экономит более 1 миллиарда долларов в год за счет сокращения оттока подписчиков.
---

## Почему рекомендации сложны
| Вызов | Описание |
|-----------|-------------|
| **Масштаб** | Миллионы пользователей × миллионы элементов = миллиарды возможных пар |
| **Разреженность** | Каждый пользователь взаимодействовал с небольшой частью доступных элементов |
| **Холодный старт** | Новые пользователи и новые элементы не имеют истории взаимодействия |
| **Динамические настройки** | Вкусы пользователей со временем меняются |
| **За пределами точности** | Рекомендации также должны быть разнообразными, новыми и случайными |
| **Бизнес-цели** | Максимизация вовлеченности ≠ максимизация благополучия пользователей |
---

## Основные подходы
### Совместная фильтрация
Идея: если пользователи А и Б согласились в прошлом, они, вероятно, согласятся и в будущем.
| Тип | Как это работает | Пример |
|------|-------------|---------|
| **На основе пользователей** | Найдите похожих пользователей; порекомендовать то, что им понравилось | "Пользователям, которым это понравилось, также понравилось..." |
| **На основе предметов** | Найдите похожие предметы на то, что уже нравится пользователю | «Потому что ты смотрел...» |
| **Матричная факторизация** | Разложить матрицу взаимодействия пользователя и элемента на скрытые факторы | СВД, АЛС (попеременный метод наименьших квадратов) |
| Сила | Слабость |
|----------|----------|
| Не нужно разбираться в самих предметах | Проблема с холодным стартом: не могу рекомендовать новинки |
| Фиксирует сложные, неявные предпочтения | Требуется много данных о взаимодействии |
| Работает с любым типом контента | Предвзятость популярности: рекомендует уже популярные товары |
### Контентная фильтрация
Рекомендуйте товары, похожие на те, которые уже нравятся пользователю, основываясь на их характеристиках.
| Тип функции | Пример |
|-------------|---------|
| **Текст** | Жанр, описание, ключевые слова, актерский состав |
| **Аудио** | Темп, жанр, настроение (для музыки) |
| **Визуальный** | Цветовая палитра, стиль (для образов/моды) |
| **Метаданные** | Цена, марка, категория |
| Сила | Слабость |
|----------|----------|
| Нет холодного старта предметов (особенности известны) | Не могу рекомендовать товары, которые не соответствуют вкусам пользователя |
| Работает с меньшим количеством данных взаимодействия | Требуется хорошая разработка функций |
| Объяснимо («рекомендуется, потому что это похоже на X») | Меньше случайности |
### Гибридные подходы
Большинство производственных систем сочетают методы совместной работы и методы, основанные на контенте.
| Гибридная стратегия | Описание |
|----------------|-------------|
| **Взвешенный** | Объедините результаты нескольких моделей |
| **Переключение** | Используйте контент на основе контента для новых пользователей и совместную работу для уже существующих |
| **Каскад** | Сначала используйте простую модель, а затем уточняйте сложную |
| **Комбинация функций** | Объединение функций совместной работы и контента в единую модель |
| **Метаобучение** | Узнайте, как комбинировать разные рекомендации |

## Современные подходы к глубокому обучению
### Модели с двумя башнями
Доминирующая архитектура для крупномасштабных рекомендаций (используется YouTube, Pinterest, Spotify).
| Компонент | Роль |
|-----------|------|
| **Пользовательская башня** | Нейронная сеть, которая кодирует функции и историю пользователя во встраивание |
| **Башня предметов** | Нейронная сеть, которая кодирует характеристики предмета во встраивание |
| **Сходство** | Скалярное произведение или косинусное сходство между встраиваниями пользователя и элемента |
| Шаг | Описание |
|------|-------------|
| 1 | Обучите обе башни создавать одинаковые вложения для взаимодействующих пар пользователь-элемент |
| 2 | Во время обслуживания предварительно вычисляются вложения элементов |
| 3 | Для запроса пользователя вычислите внедрение пользователя |
| 4 | Используйте приблизительный поиск ближайшего соседа (ANN), чтобы найти наиболее похожие объекты |
### Модели последовательностей для рекомендаций
Поведение пользователей последовательно: то, что вы смотрели вчера, влияет на то, что вы будете смотреть сегодня.
| Модель | Подход |
|-------|----------|
| **GRU4Rec** | Модель на основе GRU для рекомендаций на основе сеансов |
| **САСРек** | Последовательная рекомендация, основанная на самообслуживании |
| **BERT4Rec** | Двунаправленный трансформатор для последовательных рекомендаций |
| **ДНН YouTube** | Глубокая нейронная сеть, рассматривающая историю просмотров как последовательность |
### Извлечение и ранжирование
Современные системы разделяют рекомендации на два этапа:
| Этап | Цель | Метод |
|-------|---------|--------|
| **Поиск (генерация кандидатов)** | Сократить миллионы позиций до примерно 1000 кандидатов | Двухбашенная модель; поиск ИНС; быстро, но приблизительно |
| **Рейтинг (оценка)** | Точно оценивайте и упорядочивайте кандидатов | Глубокая модель с множеством функций; медленнее, но точнее |
| **Изменение рейтинга** | С поправкой на разнообразие, бизнес-правила, свежесть | Контекстные бандиты; оптимизация ограничений |

## Метрики оценки
| Метрическая | Что он измеряет | Когда использовать |
|--------|-----------------|-------------|
| **Точность@К** | Доля релевантных рекомендаций Top-K | Когда вы заботитесь о точности лучших результатов |
| **Вспомнить@К** | Доля релевантных элементов, найденных в топ-К | Когда вы заботитесь о том, чтобы не пропустить хорошие товары |
| **NDCG** (нормализованная дисконтированная совокупная прибыль) | Качество ранжирования; награды за повышение соответствующих предметов | Когда порядок ранжирования имеет значение |
| **MAP** (средняя средняя точность) | Средняя точность среди всех пользователей | Общее качество рейтинга |
| **Частота попаданий@K** | Появится ли хотя бы один релевантный товар в топ-К | Сценарии двоичной релевантности |
| **Охват** | Доля товаров, которые рекомендуются | Разнообразие и справедливость |
| **Интуиция** | Неожиданные, но актуальные рекомендации | Удовлетворенность пользователей |

## Проблема холодного запуска
| Сценарий | Вызов | Решения |
|----------|-----------|-----------|
| **Новый пользователь** | Нет истории взаимодействия | Используйте демографические данные; показывать популярные товары; использовать контекстные сигналы (местоположение, устройство, время) |
| **Новый товар** | С ним еще никто не взаимодействовал | Используйте возможности контента; стратегии исследования-эксплуатации; бандитские алгоритмы |
| **Новая система** | Никаких данных | Перенос обучения из схожих областей; курировать первоначальный контент |

## Исследование против эксплуатации
| Стратегия | Описание | Компромисс |
|----------|-------------|-----------|
| **ε-жадный** | Показать случайные предметы с вероятностью ε | Просто, но неэффективно |
| **Выборка Томпсона** | Выборка из апостериорного распределения качества изделия | Принципиальный; хорошие теоретические свойства |
| **Верхняя доверительная граница (UCB)** | Предпочитаю предметы с высокой неопределенностью | Хороший баланс разведки и эксплуатации |
| **Контекстные бандиты** | Исследование в зависимости от контекста пользователя | Более эффективно, чем слепое исследование |
| **Внедрение разнообразия** | Намеренно включайте разнообразные или новые предметы | Простой; может сократить краткосрочное взаимодействие |
---

## Предвзятость и справедливость
| Тип смещения | Описание | Воздействие |
|-----------|-------------|--------|
| **Предвзятость популярности** | Популярные товары получают больше рекомендаций и становятся все более популярными | Длиннохвостые предметы недостаточно обслуживаются |
| **Смещение выбора** | Модели учатся на наблюдаемых взаимодействиях, а не на всех возможных | Склонен к активным пользователям |
| **Смещение позиции** | Товары, показанные на более высоких позициях, получают больше кликов независимо от качества | Укрепляет верхние позиции |
| **Смещение экспозиции** | Показанные элементы получают больше обучающего сигнала | Обратная связь |
| **Демографическая предвзятость** | Рекомендации несправедливо различаются в зависимости от демографической группы | Дискриминация; неудачный опыт для некоторых групп |
### Стратегии смягчения последствий
| Стратегия | Описание |
|----------|-------------|
| **Взвешивание обратной склонности** | Уменьшите вес популярных предметов на тренировках |
| **Устранение искажений** | Добавьте в модель компонент устранения смещения |
| **Ограничения справедливости** | Добавить ограничения для обеспечения справедливого обращения |
| **Разнообразные рекомендации** | Явно оптимизируйте разнообразие наряду с релевантностью |
| **Аудит и мониторинг** | Регулярно проверяйте рекомендации на предмет предвзятости между группами |

## Краткое содержание
Рекомендательные системы являются одними из наиболее эффективных приложений искусственного интеллекта в промышленности. Эта область превратилась из простой совместной фильтрации в архитектуры глубокого обучения, которые объединяют историю пользователей, содержимое элементов, контекстные сигналы и бизнес-цели. Современные системы используют конвейер поиска-ранжирования-переранжирования с двухбашенными моделями для быстрой генерации кандидатов и глубокими моделями для точной оценки. Проблемы — холодный запуск, предвзятость, исследование и баланс удовлетворенности пользователей с бизнес-целями — остаются активными областями исследований и разработок.
