# Глубокое погружение в генеративный искусственный интеллект
Генеративный ИИ относится к моделям, которые создают новый контент — изображения, текст, аудио, видео, код — а не просто классифицируют или прогнозируют существующие данные. Хотя большую часть внимания привлекают большие языковые модели, сфера генеративного ИИ гораздо шире. В этом файле описаны архитектуры, методы и компромиссы, лежащие в основе современных генеративных систем, от диффузионных моделей до вариационных автоэнкодеров и моделей потоков.
---

## Что делает модель «генеративной»?
| Тип | Что он делает | Пример |
|------|-------------|---------|
| **Дискриминационный** | Изучите границу между классами | «Это изображение — кошка или собака?» |
| **Генераторный** | Изучите распределение самих данных | «Создать новый образ кота» |
Генеративные модели фиксируют *как производятся данные*, а не только то, как их классифицировать. Это делает их существенно более сильными — и их труднее тренировать.
---

## Основные генеративные архитектуры
### Вариационные автоэнкодеры (VAE)
VAE изучают сжатое структурированное представление (скрытое пространство) данных, а затем генерируют новые выборки, производя выборку из этого пространства.
| Компонент | Роль |
|-----------|------|
| **Кодер** | Сопоставляет входные данные с распределением в скрытом пространстве (среднее значение и дисперсия) |
| **Скрытое пространство** | Непрерывное маломерное пространство, в котором схожие точки данных расположены близко друг к другу |
| **Декодер** | Отображает точки в скрытом пространстве обратно в пространство данных |
| **Дивергенция KL** | Член регуляризации, который сохраняет скрытое распределение близким к стандартному нормальному |
**Как работает генерация**: выберите случайный вектор из скрытого пространства → пропустите его через декодер → получите новую точку данных.
| Сила | Слабость |
|----------|----------|
| Гладкое, непрерывное скрытое пространство | Выходные данные имеют тенденцию быть размытыми |
| Принципиальная математическая основа | Ограничено возможностями архитектуры |
| Можно интерполировать примеры | Менее резкие, чем выходы диффузии или GAN |
VAE часто используются в качестве компонентов в других моделях (например, Stable Diffusion использует VAE как часть своего конвейера).
### Генеративно-состязательные сети (GAN)
GAN противопоставляют друг другу две сети: **генератор**, создающий фальшивые данные, и **дискриминатор**, который пытается отличить настоящие от фальшивых.
| Компонент | Цель |
|-----------|------|
| **Генератор** | Производить данные, которые обманывают дискриминатор |
| **Дискриминатор** | Правильно классифицируйте реальные и сгенерированные данные |
Они тренируются одновременно, подталкивая друг друга к совершенствованию. Теоретически генератор в конечном итоге выдает данные, неотличимые от реальных данных.
| ГАН Вариант | Ключевые инновации |
|-------------|---------------|
| **ДКГАН** | Сверточные архитектуры; стабильное обучение |
| **СтильГАН/СтильГАН2/СтильГАН3** | Генерация на основе стиля; фотореалистичные лица; управляемые атрибуты |
| **ЦиклГАН** | Непарный перевод изображения в изображение (лошадь → зебра) |
| **Пикс2Пикс** | Парный перевод изображения в изображение (эскиз → фото) |
| **ПроГАН** | Прогрессивный рост изображений с высоким разрешением |
| **БигГАН** | Класс-условная генерация в масштабе |
**Почему GAN пришли в упадок**: Обучение общеизвестно нестабильно (сбой режима, исчезновение градиентов). Модели диффузии теперь обеспечивают лучшее качество для большинства задач создания изображений. GAN по-прежнему используются для приложений реального времени (они быстро делают выводы) и конкретных задач, таких как суперразрешение.
### Модели диффузии
Диффузионные модели — это современный уровень создания изображений и видео. Они работают, постепенно добавляя шум к данным, пока они не станут чистым случайным шумом, а затем учатся обращать этот процесс вспять.
| Фаза | Что происходит |
|-------|-------------|
| **Прямой процесс (обучение)** | Медленно добавляйте гауссов шум на протяжении сотен/тысяч шагов, пока данные не будут уничтожены |
| **Обратный процесс (генерация)** | Научитесь шумоподавлять шаг за шагом, начиная с чистого шума, пока не появится чистое изображение |
| Модель | Разработчик | Примечательная особенность |
|-------|-----------|-----------------|
| **DDPM** (диффузионно-вероятностная модель с шумоподавлением) | Хо и др., 2020 | Показано, что диффузионные модели могут создавать высококачественные изображения |
| **Стабильная диффузия** | Стабильность ИИ | Латентная диффузия (протекает в сжатом пространстве); с открытым исходным кодом |
| **ДАЛЛ-И 3** | ОпенАИ | Интегрирован с ChatGPT для понимания текста |
| **В середине пути** | Мидпути | Художественное качество; с закрытым исходным кодом |
| **Изображение** | Google ДипМайнд | Высококачественное преобразование текста в изображение |
| **Сора** | ОпенАИ | Генерация видео с помощью диффузионных преобразователей |
| **ПОТОК** | Лаборатории Шварцвальда | Преемник Stable Diffusion в открытом весе |
### Почему диффузионные модели победили
| Преимущество | Объяснение |
|-----------|-------------|
| **Стабильность обучения** | Гораздо более стабильный, чем GAN; никакой состязательной подготовки |
| **Качество вывода** | Современное качество и разнообразие изображений |
| **Управляемость** | Можно управлять текстом (через CLIP), масками рисования или другими условиями |
| **Разнообразие** | Меньше коллапса режима, чем у GAN; генерирует разнообразные результаты |
| Недостаток | Объяснение |
|-------------|-------------|
| **Медленный вывод** | Требуется много шагов шумоподавления (обычно 20–50) |
| **Интенсивные вычисления** | Каждый шаг представляет собой полный проход вперед по большой модели |
### Скрытая диффузия
Запуск диффузии в пиксельном пространстве обходится дорого. **Скрытая диффузия** (используется стабильной диффузией) вместо этого запускает процесс диффузии в сжатом скрытом пространстве.
| Шаг | Что происходит |
|------|-------------|
| 1. Сжать | Предварительно обученный VAE кодирует изображение в скрытое представление меньшего размера |
| 2. Диффузный | Модель диффузии добавляет/удаляет шум в скрытом пространстве |
| 3. Декодирование | Декодер VAE преобразует скрытое изображение обратно в полное изображение |
Это делает генерацию значительно быстрее и дешевле, сохраняя при этом качество.

## Генерация с условием текста
Большинство современных генеративных систем работают с текстовыми подсказками — вы описываете то, что хотите, и модель это генерирует.
### CLIP (предварительная тренировка контрастного языка и изображения)
CLIP изучает общее пространство для встраивания текста и изображений. Он был обучен на миллиардах пар изображение-текст из Интернета.
| Возможность | Описание |
|------------|-------------|
| **Классификация нулевых выстрелов** | Классифицируйте изображения с помощью текстовых описаний без какого-либо обучения |
| **Извлечение изображения и текста** | Найдите наиболее подходящее изображение для текстового запроса |
| **Направляющая диффузия** | Направляйте создание изображений в сторону текстовой подсказки |
### Руководство без классификаторов (CFG)
CFG контролирует, насколько точно сгенерированное изображение соответствует текстовой подсказке.
| Шкала CFG | Эффект |
|-----------|--------|
| **1.0** | Никаких указаний; разнообразны, но могут не соответствовать подсказке |
| **5,0–7,5** | Сбалансированный; хорошее качество и быстрое выполнение |
| **10,0+** | Сильная приверженность; может создавать перенасыщенные изображения или изображения с большим количеством артефактов |

## Другие генеративные подходы
### Нормализация потоков
| Особенность | Описание |
|---------|-------------|
| **Как это работает** | Изучите обратимое сопоставление данных и простое распределение |
| **Сила** | Точный расчет вероятности; быстрый отбор проб |
| **Слабость** | Требует тщательно разработанной архитектуры; менее гибкий |
| **Примеры использования** | Обнаружение аномалий, оценка плотности |
### Модели авторегрессии
| Особенность | Описание |
|---------|-------------|
| **Как это работает** | Генерируйте данные по одному элементу за раз, учитывая все предыдущие элементы |
| **Сила** | Естественно для последовательных данных (текст, код, музыка) |
| **Слабость** | Медленная генерация (должна быть последовательной); ограничено распределением обучающих данных |
| **Примеры** | GPT (текст), WaveNet (аудио), ImageGPT (изображения) |
### Энергетические модели
| Особенность | Описание |
|---------|-------------|
| **Как это работает** | Изучите энергетическую функцию; низкая энергия = реалистичные данные |
| **Сила** | Гибкий; нормализация не требуется |
| **Слабость** | Обучение сложно; отбор проб требует MCMC |
| **Примеры использования** | Теоретические исследования; некоторые приложения робототехники |

## Метрики оценки
Как вы измеряете качество генерируемых данных? Это сложнее, чем вы думаете.
| Метрическая | Для | Что он измеряет | Ограничение |
|--------|-----|-----------------|------------|
| **FID** (начальное расстояние по Фреше) | Изображения | Расстояние между реальными и сгенерированными распределениями изображений | Чем ниже, тем лучше; плохо отражает разнообразие |
| **IS** (начальная оценка) | Изображения | Качество и разнообразие создаваемых изображений | Спорный; можно играть |
| **Оценка CLIP** | Преобразование текста в изображение | Насколько изображение соответствует текстовой подсказке | Зависит от предубеждений CLIP |
| **Недоумение** | Текст | Насколько хорошо модель предсказывает следующий токен | Чем ниже, тем лучше; не измеряет согласованность |
| **СИНИЙ/РУЖЕВЫЙ** | Генерация текста | Перекрытие с текстом ссылки | Плохой показатель человеческого суждения |
| **FAD** (расстояние звука по Фреше) | Аудио | Расстояние между реальными и сгенерированными аудиораспределениями | Аналог FID для аудио |

## Управляемая генерация
Современные системы позволяют вам контролировать то, что генерируется, помимо текстовых подсказок.
| Метод | Тип управления | Пример |
|--------|-------------|---------|
| **Рисование** | Заполните замаскированные области | Удалить объект с фотографии |
| **Перекраска** | Выйти за границы изображения | Сделайте пейзаж шире |
| **КонтрольНет** | Структурное руководство (края, глубина, поза) | Создать изображение, соответствующее определенной позе |
| **IP-адаптер** | Стиль или содержание эталонного изображения | «Сделай так, как на этой картине» |
| **ЛОРА** | Доработанный стиль или концепция | Добавьте конкретного персонажа или художественный стиль |
| **Изображение2Изображение** | Преобразование существующего изображения | Превратите эскиз в фотореалистичное изображение |

## Генерация видео
Генерация видео — это следующий рубеж после изображений. Это добавляет измерение времени и движения.
| Модель | Подход | Примечательная особенность |
|-------|----------|-----------------|
| **Сора** (OpenAI) | Диффузионный трансформатор | До 1080p; достаточно хорошо понимает физику |
| **Взлетно-посадочная полоса Gen-3** | На основе диффузии | Инструмент для создания коммерческого видео |
| **Пика** | На основе диффузии | Короткие видеоклипы из текста |
| **Клинг** | Авторегрессия + диффузия | Создание длинного видео |
| **Вео 2** (Google) | Диффузионный трансформатор | Высококачественное, физически согласованное видео |
### Проблемы при создании видео
| Вызов | Почему это сложно |
|-----------|--------------|
| **Временная согласованность** | Объекты должны выглядеть одинаково во всех кадрах |
| **Физика** | Гравитация, столкновения, гидродинамика должны быть примерно правильными |
| **Длина** | Создать несколько минут связного видео гораздо сложнее, чем одно изображение |
| **Вычислить** | Видео — это, по сути, множество изображений; шкала затрат с количеством кадров |
| **Оценка** | Ни один стандартный показатель не обеспечивает хорошего качества видео |

## Экономика генерации
| Фактор | Воздействие |
|--------|--------|
| **Стоимость обучения** | Диффузионные модели: $100 тыс.–$10 млн+ в зависимости от масштаба |
| **Стоимость вывода** | Генерация изображения: ~ 0,01–0,05 доллара за изображение в масштабе |
| **Аппаратное обеспечение** | Обучение: несколько графических процессоров A100/H100; Вывод: возможен один графический процессор |
| **Открытый и закрытый** | Открытые модели (Stable Diffusion, FLUX) могут работать локально; закрытые модели (DALL-E, Midjourney) доступны только по API |

## Краткое содержание
Генеративный ИИ эволюционировал от GAN через VAE к диффузионным моделям и далее. Ключевая идея во всех этих архитектурах одна и та же: изучить распределение данных, а затем использовать их для создания нового контента. Модели диффузии в настоящее время доминируют в создании изображений и видео из-за их стабильности обучения и качества вывода. VAE служат важнейшими строительными блоками. Авторегрессионные модели доминируют над текстом и кодом. Эта область движется к мультимодальной генерации — системам, которые могут создавать текст, изображения, аудио и видео из любой комбинации входных данных — и к тому, чтобы сделать генерацию быстрее, дешевле и более управляемой.
