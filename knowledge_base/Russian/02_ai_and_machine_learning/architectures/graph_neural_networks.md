# Графовые нейронные сети
Графовые нейронные сети (GNN) — это нейронные сети, предназначенные для работы с графоструктурированными данными — сетями узлов, соединенных ребрами. В то время как традиционные нейронные сети работают с сетками (изображениями) или последовательностями (текстом), GNN обрабатывают произвольные реляционные структуры: социальные сети, молекулярные графы, графы знаний, дорожные сети, графы рекомендаций и многое другое. Они стали необходимы для открытия лекарств, обнаружения мошенничества, систем рекомендаций и любой области, где отношения между объектами имеют значение.
---

## Что такое граф?
| Компонент | Описание | Пример |
|-----------|-------------|---------|
| **Узел (вершина)** | Сущность | Человек, атом молекулы, город |
| **Край** | Связь между двумя узлами | Дружба, химическая связь, дорога |
| **Толщина кромки** | Сила или тип отношений | Расстояние, сходство, емкость |
| **Функции узла** | Атрибуты каждого узла | Возраст, атомный номер, население |
| **Элементы края** | Атрибуты каждого ребра | Тип отношений, расстояние |
| **Матрица смежности** | Матрица A, где A[i][j] = 1, если узлы i и j соединены | Кодирует структуру графа |
### Типы графиков
| Тип | Описание | Пример |
|------|-------------|---------|
| **Ненаправленный** | Края не имеют направления | Сеть дружбы |
| **Режиссер** | Ребра имеют направление (A→B ≠ B→A) | Последователи Твиттера |
| **Взвешенный** | Ребра имеют числовые значения | Дорожная сеть с расстояниями |
| **Неоднородный** | Несколько типов узлов и ребер | Академический график (доклады, авторы, места проведения) |
| **Динамический** | Структура графа меняется со временем | Социальная сеть развивается с течением времени |
| **Двусторонний** | Два типа узлов; ребра только между типами | График рекомендаций по пользовательским элементам |
---

## Почему не обычные нейронные сети?
| Подход | Почему это не удается |
|----------|-------------|
| **Сеть прямой связи** | Требует ввода фиксированного размера; графики различаются по размеру и структуре |
| **Си-эн-эн** | Предполагает сеточную структуру; графики не имеют регулярной сетки |
| **РНН/Трансформатор** | Предполагает последовательный порядок; графы не имеют естественного порядка |
GNN решают эту проблему, работая непосредственно со структурой графа, обрабатывая каждый узел в контексте его соседей.
---

## Базовые архитектуры GNN
### Платформа передачи сообщений
Большинство GNN следуют одной и той же схеме: каждый узел собирает информацию от своих соседей, объединяет ее и обновляет свое собственное представление.
| Шаг | Описание |
|------|-------------|
| **1. Сообщение** | Каждый узел отправляет сообщение своим соседям (на основе своих текущих функций) |
| **2. Совокупный** | Каждый узел собирает и объединяет сообщения от всех соседей |
| **3. Обновление** | Каждый узел обновляет свое собственное представление, используя агрегированное сообщение |
| **4. Повторить** | Сделайте это для K слоев → каждый узел собирает информацию с K прыжков |
### Ключевые модели GNN
| Модель | Метод агрегирования | Ключевые инновации |
|-------|-------------------|----------------|
| **GCN** (Сверточная сеть графов) | Среднее значение свойств соседей | Простой; эффективный; спектральная мотивация |
| **ГрафSAGE** | Выборка и совокупность; можно использовать среднее значение, LSTM или объединение | Индуктивный (обрабатывает невидимые узлы); масштабируемый |
| **GAT** (Сеть внимания к графам) | Агрегация соседей по вниманию | Узнает, какие соседи важнее всего |
| **GIN** (Сеть изоморфизма графов) | Сумма свойств соседей | Максимально выразительный; может различить любые графы, различимые с помощью теста WL |
| **MPNN** (нейронная сеть передачи сообщений) | Общая структура передачи сообщений | Унифицирует многие варианты GNN |
### Как работает GCN (шаг за шагом)
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

После K слоев представление каждого узла кодирует информацию из K прыжков в графе.

## Задачи уровня графа
| Задача | Описание | Пример |
|------|-------------|---------|
| **Классификация узлов** | Предсказать метку каждого узла | Классифицируйте пользователей как ботов или людей |
| **Прогнозирование ссылок** | Предсказать, существует ли ребро (или будет существовать) | Прогнозировать отсутствие отношений; рекомендовать соединения |
| **Классификация графиков** | Предсказать метку для всего графа | Классифицируйте молекулы как токсичные и нетоксичные |
| **Обнаружение сообщества** | Найдите кластеры плотно связанных узлов | Определить социальные группы |
| **Создание графика** | Генерировать новые графики с желаемыми свойствами | Создавать новые молекулы |

## Приложения
### Открытие лекарств и прогнозирование молекулярных свойств
| Задача | Как помогают GNN |
|------|--------------|
| **Прогнозирование молекулярных свойств** | Представляйте молекулы в виде графов (атомы=узлы, связи=ребра); прогнозировать токсичность, растворимость, сродство связывания |
| **Взаимодействие лекарств** | Смоделируйте лекарства и цели в виде графика; прогнозировать неблагоприятные взаимодействия |
| **Разработка лекарств заново** | Создание новых молекулярных графов с желаемыми свойствами |
### Рекомендательные системы
| Подход | Описание |
|----------|-------------|
| **График пользовательских элементов** | Пользователи и элементы являются узлами; покупки/просмотры - это края |
| **Совместная фильтрация на основе графов** | GNN распространяют предпочтения через граф |
| **Рекомендации по графику знаний** | Объедините предпочтения пользователя со знанием предметов (жанры, актеры, режиссеры) |
### Обнаружение мошенничества
| Приложение | Структура графа |
|-------------|----------------|
| **Финансовое мошенничество** | Транзакции образуют график; мошеннические шаблоны возникают в виде структур подграфов |
| **Мошенничество в сфере страхования** | Заявители, поставщики и политики образуют график; раскрыты кольца мошенников |
| **Поглощение аккаунтов** | Шаблоны входа в систему образуют график; аномальные соединения скомпрометировали сигнал |
### Графики знаний
| Задача | Описание |
|------|-------------|
| **Прогнозирование ссылок** | Предсказать недостающие факты (например, «Париж — столица?») |
| **Разрешение объекта** | Определить, относятся ли два упоминания к одному и тому же объекту |
| **Ответы на вопросы** | Перемещайтесь по графику, чтобы найти ответы |

## Расширенные концепции GNN
### Чрезмерное сглаживание
| Проблема | Описание | Решение |
|---------|-------------|----------|
| **Чрезмерное сглаживание** | После многих слоев все представления узлов становятся одинаковыми | Предельная глубина (2-4 слоя); использовать остаточные связи; используйте знания о прыжках |
### Чрезмерное сжатие
| Проблема | Описание | Решение |
|---------|-------------|----------|
| **Чрезмерное сжатие** | Информация от удаленных узлов сжимается в векторы фиксированного размера | Используйте преобразователи графов; иерархическое объединение |
### Трансформаторы графов
| Модель | Ключевая особенность |
|-------|-------------|
| **Преобразователь графиков** | Применить стандартное внимание Transformer ко всем парам узлов |
| **GPS** (система графических подсказок) | Объедините локальные слои GNN с глобальными слоями Transformer |
| **Графографист** | Добавить позиционное кодирование на основе структуры графа |
### Гетерогенные графовые сети
| Модель | Описание |
|-------|-------------|
| **R-GCN** | Реляционный GCN; разные весовые матрицы для разных типов ребер |
| **ХАН** | Гетерогенная сеть внимания; внимание к различным типам узлов и ребер |
| **ХетГНН** | Нейронная сеть с гетерогенным графом; обрабатывает несколько типов узлов |

## Масштабируемость
| Вызов | Решение |
|-----------|----------|
| **Большие графы** (миллионы узлов) | Мини-пакетное обучение; выборка соседей |
| **Память** | Разделение графа по графическим процессорам |
| **Скорость** | Разреженные матричные операции; специализированные библиотеки |
### Стратегии выборки
| Стратегия | Описание |
|----------|-------------|
| **Выборка узлов** | Выборка подмножества узлов и их окрестностей K-hop |
| **Выборка краев** | Выборка ребер и узлов, которые они соединяют |
| **Кластерная выборка** | Разбить граф на кластеры; поезд на кластерах |
| **Выборка методом случайного блуждания** | Выборка узлов посредством случайного блуждания от целевых узлов |

## Краткое содержание
Графовые нейронные сети расширяют глубокое обучение реляционным данным — сетям, молекулам, графам знаний и любой системе, где сущности связаны между собой. Они работают, передавая сообщения между соседями, позволяя каждому узлу учиться на основе своего локального контекста. GNN нашли свое самое сильное применение в разработке лекарств, системах рекомендаций, обнаружении мошенничества и графах знаний. Эта область развивается в сторону преобразователей графов, гетерогенных графов и масштабируемого обучения для огромных реальных сетей. Если ваши данные имеют взаимосвязи, вероятно, стоит рассмотреть GNN.
