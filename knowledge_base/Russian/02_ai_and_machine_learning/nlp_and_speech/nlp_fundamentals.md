# Основы НЛП
Обработка естественного языка (НЛП) — это область обучения машин понимать, генерировать и работать с человеческим языком. Он поддерживает поисковые системы, чат-боты, системы перевода, анализ настроений и большие языковые модели (LLM), которые преобразовали ИИ с 2020 года. Этот файл описывает эволюцию от классических методов к современным архитектурам на основе Transformer.
---

## Предварительная обработка текста
Необработанный текст беспорядочен. Прежде чем модель сможет использовать ее, ее необходимо очистить и структурировать.
| Шаг | Что он делает | Пример |
|------|-------------|---------|
| **Токенизация** | Разделить текст на лексемы (слова, подслова или символы) | «Я люблю НЛП» →`["I", "love", "NLP"]`|
| **В нижнем регистре** | Преобразовать в нижний регистр | «Привет» → «привет» |
| **Удаление стоп-слов** | Удалить общие слова (the, is, at) | "кот сидел" → "кот сидел" |
| **Стэмминг** | Обрезать окончания слов (грубо) | «бег» → «бег» |
| **Лемматизация** | Привести к словарной форме (с учетом контекста) | «лучше» → «хорошо» |
| **Нормализация** | Исправить кодировку, удалить специальные символы, расширить сокращения | «не делай» → «не делай» |
Современные модели Transformer часто пропускают удаление стоп-слов и определение корней — они изучают эти шаблоны на основе данных.

## Текстовое представление
Машинам нужны цифры, а не слова. То, как мы представляем текст в виде векторов, имеет фундаментальное значение.
### Классические подходы
| Метод | Описание | Ограничение |
|--------|-------------|-----------|
| **Горячее кодирование** | Каждое слово занимает уникальную позицию в огромном векторе | Редкий; никакого смыслового значения |
| **Мешок слов (BoW)** | Подсчитайте частоты слов; игнорировать заказ | Полностью теряет порядок слов |
| **ТФ-ИДФ** | Вес слов по частоте в документе × редкость в корпусе | Все еще игнорирует порядок и контекст |
### Встраивание слов
Вложения отображают слова в плотные векторы, где похожие слова расположены близко друг к другу.
| Модель | Ключевая идея |
|-------|----------|
| **Word2Vec** (2013 г.) | Предсказать слово по контексту (CBOW) или контекст по слову (Skip-gram) |
| **Перчатка** (2014) | Глобальная статистика совпадений → плотные векторы |
| **БыстрыйТекст** (2016) | Word2Vec + информация о подсловах (лучше обрабатывает редкие слова) |
Знаменитый пример: `king - man + woman ≈ queen`. Вложения фиксируют семантические отношения.
**Ограничение**: классические вложения присваивают каждому слову один вектор, поэтому они не могут обрабатывать многозначность (слова с несколькими значениями). «Банк» в «береге реки» и «банковском счете» получает один и тот же вектор.

## Модели последовательностей
До «Трансформеров» стандартным подходом НЛП была последовательная обработка текста.
| Архитектура | Как это работает | Сила | Слабость |
|-------------|-------------|----------|----------|
| **РНН** | Обрабатывать токены по одному; поддерживать скрытое состояние | Обрабатывает ввод переменной длины | Исчезающие градиенты; не могу захватить длинные зависимости |
| **ЛСТМ** | RNN с вентилями (забывание, ввод, вывод) для управления информационными потоками | Лучше в долгосрочных зависимостях | Все еще последовательный; медленно обучаться |
| **ГРУ** | Упрощенный LSTM (меньше вентилей) | Быстрее, чем LSTM; аналогичная производительность | Те же фундаментальные ограничения |
Эти модели обрабатывают текст слева направо, а это означает, что они медленно обучаются (не могут распараллеливаться) и испытывают проблемы с долгосрочными зависимостями.

## Механизм внимания
Внимание позволяет модели одновременно просматривать все позиции в последовательности и решать, какие из них наиболее актуальны для текущего прогноза.
### Ключевая информация
Вместо того, чтобы сжимать все предложение в одно скрытое состояние (как это делают RNN), внимание вычисляет взвешенную сумму всех скрытых состояний, где изучаются веса.
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

| Компонент | Роль |
|-----------|------|
| **Запрос (Q)** | Что я ищу? |
| **Ключ (К)** | Что я содержу? |
| **Значение (В)** | Какую информацию я предоставляю? |
| **√d_k** | Коэффициент масштабирования для предотвращения больших скалярных произведений |

## Архитектура-трансформер
Трансформатор (Васвани и др., 2017 — «Внимание — это все, что вам нужно») полностью заменил повторение вниманием. Это основа практически всего современного НЛП.
### Архитектура
| Компонент | Описание |
|-----------|-------------|
| **Кодер** | Читает вводимый текст; создает контекстные представления |
| **Декодер** | Генерирует выходной текст; следит за выходом кодировщика |
| **Внимание к себе** | Каждый токен обслуживает все остальные токены в той же последовательности |
| **Многоголовое внимание** | Запускайте несколько голов внимания параллельно; запечатлеть различные отношения |
| **Позиционное кодирование** | Ввести информацию о позиции (поскольку повторения нет) |
| **Сеть прямой связи** | Применяется к каждой позиции отдельно |
| **Нормализация слоя** | Стабилизация обучения |
| **Остаточные соединения** | Пропуск соединений для градиентного потока |
### Только кодер, Только декодер, Кодер-декодер
| Вариант | Архитектура | Лучшее для | Примеры |
|---------|-------------|----------|---------|
| **Только для кодировщиков** | Понимает текст | Классификация, NER, анализ настроений | БЕРТ, РОБЕРТа, ДеБЕРТа |
| **Только для декодера** | Генерирует текст | Языковые модели, чат-боты, генерация кода | GPT-3/4, LLaMA, Клод |
| **Кодер-декодер** | Преобразует текст | Перевод, реферирование | Т5, БАРТ, мБАРТ |

## Семейства основных моделей
### Семейство BERT (только для кодировщиков)
| Модель | Ключевая особенность |
|-------|-------------|
| **БЕРТ** (2018) | Модель замаскированного языка + прогнозирование следующего предложения |
| **РОБЕРТа** | Убран НСП; обучались дольше с большим количеством данных |
| **АЛЬБЕРТ** | Совместное использование параметров; меньшая площадь |
| **ДеБЕРТа** | Распутанное внимание; улучшенный НЛУ |
| **ДистиллБЕРТ** | На 40 % меньше, на 60 % быстрее, сохраняет 97 % производительности BERT |
### Семейство GPT (только для декодера)
| Модель | Параметры | Заметки |
|-------|-----------|-------|
| **ГПТ-2** | 1,5Б | Показано, что модели, поддерживающие только декодер, могут генерировать связный текст |
| **ГПТ-3** | 175Б | Обучение за несколько кадров; подсказывал, а не настраивал |
| **ГПТ-3,5 / ГПТ-4** | Нераскрыто | По инструкции + РЛХФ; разговорный |
| **ЛАМА** (Мета) | 7Б–70Б | Открытый вес; породила экосистему LLM с открытым исходным кодом |
| **Мистраль/Мистраль** | 7Б/8×7Б (МО) | Эффективные открытые модели с высокой производительностью |

## Основные задачи НЛП
| Задача | Описание | Типичная модель |
|------|-------------|--------------|
| **Классификация текста** | Присвоить тексту метку (спам/не спам, положительный/негативный) | BERT, тонко настроенные классификаторы |
| **Распознавание именованных объектов (NER)** | Определить людей, организации, места в тексте | BERT + слой CRF |
| **Анализ настроений** | Определить эмоциональный тон | Точная настройка BERT или LLM с нулевым выстрелом |
| **Машинный перевод** | Переводить между языками | Т5, мБАРТ, МарианМТ |
| **Ответы на вопросы** | Отвечайте на вопросы с учетом контекста | BERT (экстрактивный), GPT (генеративный) |
| **Обобщение** | Сжать длинный текст | Т5, БАРТ, ГПТ |
| **Генерация текста** | Создание связного текста | GPT-4, LLaMA, Клод |

## Точная настройка и подсказки
| Подход | Как это работает | Когда использовать |
|----------|-------------|-------------|
| **Точная настройка** | Обновите вес модели на основе данных, специфичных для вашей задачи | Вы пометили данные; нужна максимальная производительность |
| **Подсказка** | Дайте модели инструкции на естественном языке | Быстрое прототипирование; ограниченные данные; использование LLM |
| **Немного выстрелов** | Включите примеры в приглашение | Если у вас есть несколько примеров, но недостаточно для доработки |
| **ЛоРА/КЛоРА** | Эффективная тонкая настройка; обновить небольшие матрицы низкого ранга | Точная настройка больших моделей с ограниченной памятью графического процессора |

## Ландшафт LLM
В современном НЛП доминируют модели большого языка:
| Категория | Примеры | Заметки |
|----------|---------|-------|
| **Собственность** | GPT-4, Клод, Близнецы | Лучшее выступление; Доступ только через API |
| **Открытый вес** | LLaMA 3, Мистраль, Квен | Доступные веса; запускать локально |
| **Открытый исходный код** | Пифия, ОПТ | Полностью открыт (данные, веса, код) |
| **Мультимодальный** | ГПТ-4В, Близнецы, LLaVA | Обработка текста + изображения |
| **Специализированный по коду** | CodeLlama, StarCoder, DeepSeek Coder | Обучился коду |
| **Маленький/эффективный** | Фи-3, Джемма, Крошечная Лама | Высокая производительность в небольших масштабах |
Поле движется быстро. То, что является передовым сегодня, может быть заменено через несколько месяцев. Основы — внимание, токенизация, тонкая настройка, оценка — остаются стабильными.
