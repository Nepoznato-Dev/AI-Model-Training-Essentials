# Основы компьютерного зрения
Компьютерное зрение дает машинам возможность интерпретировать и понимать визуальную информацию из окружающего мира — изображения, видео и трехмерные данные. Он поддерживает все: от распознавания лиц на вашем телефоне до беспилотных автомобилей, анализа медицинских изображений и промышленного контроля качества. В этом файле описаны основные концепции, архитектуры и методы.
---

## Как компьютеры видят изображения
### Пиксели и каналы
Цифровое изображение представляет собой сетку пикселей. Каждый пиксель имеет числовые значения, представляющие интенсивность цвета.
| Тип изображения | Каналы | Значения на пиксель | Пример |
|-----------|----------|-----------------|---------|
| **Оттенки серого** | 1 | от 0 (черный) до 255 (белый) | Медицинский рентген |
| **RGB** | 3 | Красный, Зеленый, Синий (каждый 0–255) | Стандартные цветные фотографии |
| **РГБА** | 4 | RGB + Альфа (прозрачность) | Изображения с прозрачным фоном |
| **ВПГ** | 3 | Оттенок, Насыщенность, Значение | Сегментация по цвету |
Изображение RGB размером 1920×1080 представляет собой тензор формы`(1080, 1920, 3)`— это 6,2 миллиона пикселей, каждый из которых имеет 3 значения.
### Ключевые операции
| Операция | Описание |
|-----------|-------------|
| **Изменение размера** | Масштабирование изображения до целевых размеров (билинейная интерполяция по ближайшему соседу) |
| **Обрезка** | Извлечь интересующую область |
| **Нормализация** | Масштабируйте значения пикселей до [0,1] или [-1,1] для нейронных сетей |
| **Аугментация** | Искусственно расширить данные обучения (поворот, переворот, дрожание цвета, обрезка) |
---

## Свертка: основная операция
Свертка перемещает небольшой фильтр (ядро) по изображению, вычисляя скалярное произведение в каждой позиции. Именно так CNN обнаруживают края, текстуры и узоры.
### Параметры свертки
| Параметр | Эффект |
|-----------|--------|
| **Размер ядра** | 3×3, 5×5, 7×7 — более крупные ядра улавливают более крупные закономерности |
| **Страйд** | Размер шага; шаг = 2 уменьшает выходные размеры вдвое |
| **Отступы** | Добавьте нули вокруг границы, чтобы сохранить пространственные размеры |
| **Количество фильтров** | Каждый фильтр изучает разные характеристики (край, текстуру, цветовой рисунок) |
### Чему учат свертки
| Глубина слоя | Обнаруженные особенности |
|-------------|------------------|
| **Ранние слои** | Края, углы, простые текстуры |
| **Средние слои** | Формы, части предметов (колеса, глаза, листья) |
| **Глубокие слои** | Концепты высокого уровня (лица, автомобили, животные) |

## Архитектуры CNN
Эволюция архитектур CNN рассказывает историю прогресса глубокого обучения в компьютерном зрении.
| Архитектура | Год | Ключевые инновации |
|-------------|------|---------------|
| **ЛеНет-5** | 1998 | Первый практический CNN; распознавание цифр |
| **АлексНет** | 2012 | Deep CNN выигрывает ImageNet; ReLU, отсев, обучение графическому процессору |
| **ВГГНет** | 2014 | Сложенные извилины 3х3 (глубже = лучше) |
| **GoogLeNet (начало)** | 2014 | Начальные модули (размеры параллельных фильтров); 22 слоя |
| **РесНет** | 2015 | Пропустить соединения (остаточное обучение); 152+ слоев |
| **Эффективная сеть** | 2019 | Комплексное масштабирование (глубина + ширина + разрешение) |
| **ConvNeXt** | 2022 | Модернизированный ResNet; конкурировать с Трансформерами |
### Почему ResNet все изменил
До ResNet обучение очень глубоких сетей было практически невозможно из-за проблемы исчезающего градиента. В ResNet появилась **пропуск соединений** (также называемая остаточными соединениями): входные данные слоя добавляются к его выходным данным.
```
output = F(x) + x    # Skip connection
```

Эта простая идея позволила эффективно обучать сети с более чем 152 уровнями, и теперь она является стандартной практически для всех глубоких архитектур.

## Основные задачи видения
### Классификация изображений
Присвойте метку всему изображению.
| Модель | Подход |
|-------|----------|
| CNN (ResNet, EfficientNet) | Традиционный подход; отличная точность |
| Трансформаторы зрения (ВиТ) | Рассматривайте изображение как последовательность патчей; Трансформаторный энкодер |
| Передача обучения | Точная настройка предварительно обученной модели в вашем наборе данных |
### Обнаружение объектов
Найдите и классифицируйте несколько объектов на изображении с помощью ограничивающих рамок.
| Модель | Тип | Скорость |
|-------|------|-------|
| **Р-CNN** | Двухэтапный (предложение + классификация) | Медленно |
| **Быстрый R-CNN** | Улучшенный двухступенчатый | Средний |
| **Быстрее R-CNN** | Сеть региональных предложений + детектор | Средний |
| **ЙОЛО** (v1–v10) | Одноступенчатый; прогнозировать ящики + классы за один проход | Очень быстро |
| **ДЕТР** | Трансформаторный; без якорных ящиков | Средний |
**YOLO** («Ты смотришь только один раз») — идеальный вариант для обнаружения в реальном времени. **Более быстрый R-CNN** предпочтителен, когда точность важнее скорости.
### Сегментация изображений
Классифицируйте каждый пиксель изображения.
| Тип | Описание | Вариант использования |
|------|-------------|----------|
| **Семантическая сегментация** | Каждый пиксель получает метку класса | Автономное вождение (дорога, автомобиль, пешеход) |
| **Сегментация экземпляров** | Каждый пиксель + идентификатор экземпляра объекта | Подсчет объектов, медицинская визуализация |
| **Паноптическая сегментация** | Семантика + экземпляр в сочетании | Комплексное понимание сцены |
Ключевые модели: U-Net (медицинская визуализация), Mask R-CNN (экземпляр), DeepLab (семантическая), Segment Anything Model (SAM — универсальная сегментация).
### Генерация изображений
| Подход | Описание | Примеры |
|----------|-------------|----------|
| **ГАНы** | Генератор против дискриминатора состязательное обучение | СтильГАН, ЦиклГАН |
| **ВАЭ** | Изучите скрытое распределение; образец для создания | Вариационные автоэнкодеры |
| **Модели диффузии** | Итерационное шумоподавление случайного шума | Стабильная диффузия, DALL-E, Midjourney |
Диффузионные модели во многом превзошли GAN по качеству генерации изображений.

## Перенос обучения для зрения
Обучение CNN с нуля требует огромных данных и вычислений. Трансферное обучение позволяет начать с модели, уже обученной на миллионах изображений (ImageNet), и настроить ее для конкретной задачи.
### Шаги
1. **Выберите предварительно обученную модель** (ResNet50, EfficientNet-B0, ViT).
2. **Замените заголовок классификации** на свой собственный (соответствующий количеству классов).
3. **Заморозьте ранние слои** (они фиксируют общие элементы, например края).
4. **Точная настройка** вашего набора данных с низкой скоростью обучения.
5. **Размораживайте постепенно**, если вам нужна дополнительная адаптация.
Этот подход обычно обеспечивает высокую точность при использовании всего лишь 1 000–10 000 помеченных изображений.

## Увеличение данных
Расширение искусственно расширяет набор обучающих данных за счет применения преобразований.
| Увеличение | Эффект | Когда использовать |
|-------------|--------|-------------|
| **Случайный урожай** | Обрезать до случайной области | Почти всегда |
| **Горизонтальный переворот** | Зеркальное изображение | Когда ориентация не имеет значения |
| **Вращение** | Поворот на случайный угол | Когда объекты появляются под любым углом |
| **Дрожание цвета** | Произвольная регулировка яркости, контрастности, насыщенности | Когда освещение меняется |
| **Случайное удаление** | Маскировать случайные регионы | Повышает надежность |
| **Миксап/КутМикс** | Смешать два изображения и метки | Регуляризация |
Библиотеки: `torchvision.transforms`, `albumentations`, `imgaug`, `tf.keras.preprocessing`.

## Практические советы
– **Начните с трансферного обучения.** Точная настройка предварительно обученной модели почти во всех случаях превосходит обучение с нуля.
- **Нормализуйте входные данные.** Соответствуйте нормализации, которую ожидает предварительно обученная модель (обычно среднее значение ImageNet/стандартное значение).
- **Используйте соответствующие показатели.** Точность для сбалансированных наборов данных; F1, mAP или IoU для несбалансированных задач или задач обнаружения.
- **Визуализируйте свои данные.** Просматривайте образцы изображений, проверяйте распределение классов, проверяйте прогнозы моделей.
– **Дополняйте с умом.** Применяйте только те преобразования, которые имеют смысл для вашего домена (не переворачивайте медицинские изображения по вертикали).
- **Отслеживать переоснащение.** Если точность обучения высокая, но проверка низкая, увеличьте увеличение или добавьте отсев.
