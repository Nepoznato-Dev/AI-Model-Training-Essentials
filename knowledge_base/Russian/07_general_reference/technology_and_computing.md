# Технологии и вычисления
Компьютеры повсюду — в вашем телефоне, автомобиле, холодильнике, медицинских устройствах и инфраструктуре, которая управляет современным обществом. Вам не нужно быть программистом, чтобы понять, как все это работает. В этом файле рассматриваются основы: что такое компьютер, как работает Интернет, как создается программное обеспечение, а также концепции, формирующие цифровой мир.
> **Хотите углубиться?** Этот файл представляет собой общий обзор. Подробное освещение любой темы см. в специальных файлах [`01_coding_and_technology/`](../01_coding_and_technology/), включая [database systems](../01_coding_and_technology/database_systems.md), [cloud architecture](../01_coding_and_technology/cloud_architecture.md),[networking](../01_coding_and_technology/networking_basics.md)и.

## Что такое компьютер?
По своей сути каждый компьютер — от смартфона до суперкомпьютера — делает одно и то же: принимает входные данные, обрабатывает их в соответствии с инструкциями (программой) и выдает выходные данные. Магия – в скорости и масштабе.
### Архитектура фон Неймана
Почти все современные компьютеры следуют этой базовой схеме:
| Компонент | Что он делает | Аналогия |
|-----------|-------------|---------|
| **ЦП** (Центральный процессор) | Выполняет инструкции; "мозг" | Шеф-повар следует рецепту |
| **ОЗУ** (Память) | Хранит данные, которые активно использует ЦП; теряется при отключении питания | Столешница — быстрый доступ, ограниченное пространство |
| **Хранилище** (SSD/HDD) | Постоянно хранит данные | Кладовая — более медленный доступ, гораздо больше места |
| **Ввод/вывод** | Клавиатура, мышь, экран, сеть | Как повар принимает заказы и доставляет еду |
| **GPU** (Графический процессор) | Специализированный процессор для параллельных задач (графика, AI) | Команда помощников одновременно выполняет одну и ту же задачу |
**Ключевая мысль**: оперативная память работает быстро, но временно. Хранение происходит медленно, но постоянно. Когда ваш компьютер «медленен», это часто происходит потому, что ему не хватает оперативной памяти и ему приходится использовать хранилище в качестве временной памяти (подкачка), что происходит намного медленнее.

## Языки программирования — общение с компьютерами
Язык программирования — это набор инструкций, которые может выполнить компьютер. Разные языки созданы для разных целей. Подробное описание 34 отдельных языков см. в папке [`programming_languages/`](../01_coding_and_technology/programming_languages/).
| Язык | Лучшее для | Почему стоит выбрать его |
|----------|---------|---------------|
| **Питон** | Наука о данных, искусственный интеллект, автоматизация, веб-серверы | Простой синтаксис; огромная экосистема; отлично подходит для начинающих |
| **JavaScript** | Полный пакет веб-интерфейсов (Node.js) | Запускается в каждом браузере; необходим для веб-разработки |
| **Ява** | Корпоративное программное обеспечение, приложения для Android | Независимость от платформы (JVM); большая экосистема |
| **С/С++** | Системное программирование, игры встраиваемые | Максимальная производительность; прямой аппаратный контроль |
| **Ржавчина** | Системное программирование с гарантиями безопасности | Безопасность памяти без сборки мусора |
| **Вперёд** | Облачные сервисы, микросервисы, инструменты CLI | Простой; отличный параллелизм; быстрая компиляция |
| **SQL** | Запросы к базе данных | Универсальный язык работы с данными |
| **Типскрипт** | Масштабные веб-приложения | JavaScript с проверкой типов; рано обнаруживает ошибки |

## Как работает Интернет
Интернет — это не то же самое, что сеть. Интернет — это физическая сеть, состоящая из кабелей, маршрутизаторов, серверов и протоколов, которые соединяют миллиарды устройств. Всемирная паутина — это служба, работающая в Интернете (наряду с электронной почтой, передачей файлов, потоковой передачей, играми и т. д.).
### Путь веб-запроса
Когда вы вводите`https://www.example.com`в свой браузер:
1. **Поиск DNS**. Ваш браузер запрашивает DNS-сервер преобразовать «www.example.com» в IP-адрес (например, 93.184.216.34).
2. **TCP-соединение**: ваше устройство устанавливает соединение с этим IP-адресом с помощью TCP (протокол, гарантирующий надежную доставку).
3. **Подтверждение TLS**. При использовании HTTPS ваш браузер и сервер согласовывают зашифрованное соединение.
4. **HTTP-запрос**. Ваш браузер отправляет запрос: «Дайте мне страницу /index.html».
5. **Обработка сервером**: веб-сервер находит страницу, возможно, запрашивает базу данных и готовит ответ.
6. **Ответ HTTP**: сервер отправляет обратно HTML, CSS и JavaScript.
7. **Рендеринг**. Ваш браузер анализирует HTML, применяет стили CSS и выполняет JavaScript для отображения страницы.
Весь этот процесс обычно занимает меньше секунды.
### Ключевые протоколы
| Протокол | Что он делает | Слой |
|----------|-------------|-------|
| **IP** (Интернет-протокол) | Маршрутизирует пакеты между сетями | Сеть |
| **TCP** | Надежная, упорядоченная доставка (повторная передача потерянных пакетов) | Транспорт |
| **UDP** | Быстрая, ненадежная доставка (без повторной передачи) | Транспорт |
| **HTTP/HTTPS** | Передача веб-страницы (HTTPS добавляет шифрование) | Приложение |
| **DNS** | Переводит доменные имена в IP-адреса | Приложение |
| **SSH** | Безопасный удаленный доступ к компьютерам | Приложение |
| **SMTP/IMAP** | Отправка и получение электронной почты | Приложение |

## Разработка программного обеспечения — как создаются программы
### Процесс разработки
1. **Написание кода**. Разработчики пишут инструкции на языке программирования.
2. **Тестовый код**. Запустите код, чтобы убедиться, что он работает правильно.
3. **Контроль версий**: отслеживайте изменения с помощью Git — универсального стандарта.
4. **Проверка**. Другие разработчики проверяют код на наличие ошибок и качество.
5. **Сборка**: Преобразование исходного кода в работоспособную программу (компиляция).
6. **Развертывание**. Выпуск программы для пользователей (серверов, магазинов приложений и т. д.).
7. **Отслеживание**: следите за ошибками и проблемами производительности в рабочей среде.
### Ключевые понятия
| Концепция | Что это значит | Почему это важно |
|---------|---------------|----------------|
| **Контроль версий (Git)** | Отслеживайте каждое изменение кода с течением времени | Сотрудничество; способность исправлять ошибки |
| **API** (Интерфейс прикладного программирования) | Определенный способ взаимодействия программных компонентов | Позволяет различным системам работать вместе |
| **База данных** | Организованное хранилище данных | Каждому приложению необходимо хранить и извлекать данные |
| **Тестирование** | Автоматизированная проверка правильности работы кода | Предотвращает попадание ошибок в пользователей |
| **CI/CD** (непрерывная интеграция/доставка) | Автоматизированный конвейер от принятия кода до производства | Более быстрые и безопасные выпуски |
| **Контейнеризация (Docker)** | Упакуйте приложение со всеми его зависимостями | «Работает на моей машине» становится «работает везде» |

## Базы данных — где живут данные
Каждое приложение должно хранить данные. Базы данных — это системы, которые делают это эффективно и надежно.
| Тип | Как хранятся данные | Лучшее для | Примеры |
|------|-------------------|----------|---------|
| **Реляционный (SQL)** | Таблицы со строками и столбцами; строгая схема | Структурированные данные; сложные запросы; сделки | PostgreSQL, MySQL, SQLite |
| **Документ (NoSQL)** | JSON-подобные документы; гибкая схема | Полуструктурированные данные; быстрая итерация | MongoDB, CouchDB |
| **Ключ-значение** | Простой ключ → пары значений | Кэширование; хранение сеансов; быстрый поиск | Редис, DynamoDB |
| **График** | Узлы и ребра (отношения) | Социальные сети; рекомендательные системы | Neo4j, ЯнусГраф |
| **Временной ряд** | Оптимизирован для данных с отметкой времени | Мониторинг; аналитика; Интернет вещей | InfluxDB, TimescaleDB |
**SQL** (язык структурированных запросов) — стандартный язык для реляционных баз данных. Это один из самых ценных технических навыков, которые вы можете освоить — почти каждая организация использует базы данных, и SQL — это то, как вы с ними общаетесь.

## Операционные системы
Операционная система (ОС) — это программный уровень между вами (и вашими программами) и оборудованием. Он управляет памятью, процессами, файлами и устройствами.
| ОС | Где оно доминирует | Ключевая особенность |
|----|-------------------|-------------|
| **Окна** | Настольные ПК/ноутбуки (доля рынка ~72%) | Широчайшая совместимость программного и аппаратного обеспечения |
| **macOS** | Креативные профессионалы, разработчики | на базе Unix; полированный пользовательский интерфейс; экосистема Apple |
| **Линукс** | Серверы (~96%), суперкомпьютеры (100%), встраиваемые системы, разработчики | Открытый исходный код; бесплатно; чрезвычайно настраиваемый |
| **Андроид** | Мобильная связь (~72% мировой доли рынка) | На основе ядра Linux; открытый исходный код |
| **iOS** | Мобильные устройства (~27% в мире, но более высокий доход) | Закрытая экосистема; полированный; ориентированный на конфиденциальность |
Linux заслуживает особого упоминания: он поддерживает большую часть Интернета, каждый суперкомпьютер из топ-500, большую часть облачной инфраструктуры и все телефоны Android. Он бесплатный, с открытым исходным кодом и поддерживается глобальным сообществом.

## Облачные вычисления
Облачные вычисления означают аренду вычислительных ресурсов (серверов, хранилищ, баз данных и т. д.) через Интернет вместо покупки и обслуживания собственного оборудования. Подробное руководство по облачной архитектуре, моделям обслуживания и сравнению поставщиков см. в [cloud architecture](../01_coding_and_technology/cloud_architecture.md).
| Модель обслуживания | Что вы получаете | Аналогия | Примеры |
|---------------|-------------|---------|---------|
| **IaaS** (Инфраструктура) | Виртуальные серверы, системы хранения данных, сети | Аренда земельного участка и строительство того, что вы хотите | AWS EC2, Google Compute Engine |
| **PaaS** (Платформа) | Среда выполнения; вы приносите код | Аренда меблированной квартиры | Heroku, Google App Engine |
| **SaaS** (Программное обеспечение) | Полное заявление; ты просто используешь это | Пребывание в отеле | Gmail, Slack, Salesforce |
Тремя основными поставщиками облачных услуг являются **AWS** (Amazon, доля рынка ~32%), **Azure** (Microsoft, ~23%) и **GCP** (Google, ~10%). Они предлагают сотни услуг, охватывающих вычисления, хранение данных, базы данных, искусственный интеллект, сети и многое другое.

## Кибербезопасность — защита цифровых систем
Кибербезопасность — это практика защиты компьютеров, сетей и данных от атак. Это важно, потому что все взаимосвязано, и цена нарушений огромна. Полное руководство по OWASP Top 10, безопасному жизненному циклу разработки и управлению секретами см. в.
### Распространенные угрозы
| Угроза | Что это такое | Профилактика |
|--------|-----------|------------|
| **Вредоносное ПО** | Вредоносное ПО (вирусы, черви, трояны) | Антивирус; обновляйте программное обеспечение |
| **Фишинг** | Поддельные электронные письма/сообщения, вынуждающие вас раскрыть информацию | Обучение; фильтрация электронной почты; скептицизм |
| **Программы-вымогатели** | Шифрует ваши данные; требует оплаты за ключ | Резервные копии; патч-системы; не платить |
| **DDoS** | Перегружает сервис трафиком | Фильтрация трафика; защита CDN |
| **SQL-инъекция** | Вставка вредоносного SQL в поля ввода | Параметризованные запросы; проверка ввода |
| **Человек посередине** | Перехват связи между двумя сторонами | HTTPS/TLS-шифрование |
### Основы безопасности
- **Шифрование**: данные шифруются, чтобы их могли прочитать только уполномоченные лица. HTTPS использует TLS для шифрования веб-трафика.
- **Аутентификация**: подтвердите личность. Используйте многофакторную аутентификацию (MFA) — пароль + что-то еще (код, биометрия).
- **Авторизация**: проверьте разрешения. Тот факт, что вы вошли в систему, не означает, что вы должны иметь доступ ко всему.
- **Принцип минимальных привилегий**: предоставляйте пользователям и системам только тот доступ, который им необходим, и не более того.
- **Управление исправлениями**: обновляйте программное обеспечение. Большинство взломов используют известные уязвимости, для которых уже есть исправления.

## Форматы данных
Программы обмениваются данными в определенных форматах. Наиболее распространенные:
| Формат | Структура | Используется для |
|--------|-----------|----------|
| **JSON** | Пары ключ-значение; человекочитаемый | API; конфигурация; обмен данными |
| **XML** | На основе тегов; многословный, но гибкий | Устаревшие системы; документы; API-интерфейсы SOAP |
| **ЯМЛ** | На основе отступов; очень читабельно | Конфигурация (Docker, Kubernetes, CI/CD) |
| **CSV** | Строки и столбцы обычного текста | Импорт/экспорт данных; электронные таблицы |

## Краткое содержание
Вычисление — это не магия, это инженерия. Компьютеры следуют инструкциям с невероятной скоростью. Интернет соединяет миллиарды из них, используя стандартизированные протоколы. Программное обеспечение создается группами людей, которые пишут, тестируют и развертывают код в итерационных циклах. Базы данных хранят и извлекают данные. Облачные вычисления позволяют любому получить доступ к огромным вычислительным ресурсам по требованию. А кибербезопасность — это постоянная битва за то, чтобы защитить все это от людей, которые хотят этим воспользоваться. Понимание этих основ поможет вам ориентироваться в цифровом мире — независимо от того, являетесь ли вы пользователем, разработчиком или просто человеком, пытающимся разобраться в технологиях, которые формируют современную жизнь.
