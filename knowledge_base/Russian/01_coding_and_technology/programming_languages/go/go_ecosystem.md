В этом руководстве рассматриваются основные инструменты, платформы и инфраструктура экосистемы Go.

## Инструментарий (встроенный)
| Инструмент | Цель |
|------|---------|
| **иди строй** | Компилировать пакеты и зависимости |
| **пройти тест** | Запустить тесты |
| **сходить к ветеринару** | Статический анализ |
| **иди нахуй** | Форматирование кода |
| **перейти на мод** | Управление модулями |
| **иди, док** | Просмотрщик документации |
| **иди сгенерируй** | Генерация кода |
| **перейти к установке** | Скомпилировать и установить |
| **иди беги** | Скомпилировать и запустить |
```bash
go mod init example.com/project  # initialize module
go get github.com/pkg/errors     # add dependency
go mod tidy                      # clean up dependencies
go build -o app ./cmd/app       # build binary
go test ./...                    # run all tests
go test -race ./...              # with race detector
go test -cover ./...             # with coverage
go vet ./...                     # static analysis
```

## Тестирование
| Инструмент | Цель |
|------|---------|
| **тестирование** | Встроенная среда тестирования |
| **свидетельствовать** | Утверждения и издевательства |
| **го-кмп** | Глубокое сравнение |
| **httptest** | Утилиты для тестирования HTTP |
| **гоу-фузз/фузз** | Фазз-тестирование |
| **бенчстат** | Сравнение эталонов |
```go
func TestAdd(t *testing.T) {
    got := Add(2, 3)
    if got != 5 {
        t.Errorf("Add(2, 3) = %d, want 5", got)
    }
}

// Table-driven tests
func TestAdd(t *testing.T) {
    tests := []struct{
        name string
        a, b, want int
    }{
        {"positive", 2, 3, 5},
        {"zero", 0, 0, 0},
        {"negative", -1, 1, 0},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got := Add(tt.a, tt.b)
            if got != tt.want {
                t.Errorf("got %d, want %d", got, tt.want)
            }
        })
    }
}
```

## Краткое содержание
Экосистема Go прагматична и минималистична. Стандартная библиотека охватывает HTTP, JSON, тестирование и многое другое — часто устраняя необходимость в платформах. Современный стек: **модули go** для зависимостей, **golangci-lint** для анализа, **Gin** или **Chi** для Интернета, **pgx** или **sqlc** для баз данных, **cobra** для интерфейсов командной строки и **статические двоичные файлы** для развертывания. Сильная сторона Go — в простоте: быстрая компиляция, небольшие двоичные файлы и единая двоичная модель развертывания.
