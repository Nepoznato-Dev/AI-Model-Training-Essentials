В этом руководстве рассматриваются основные инструменты, платформы и инфраструктура экосистемы Java.

## Инструменты сборки
| Инструмент | Тип | Лучшее для |
|------|------|----------|
| **Мавен** | на основе XML | Предприятие, соглашение важнее конфигурации |
| **Грейдл** | Groovy/Kotlin DSL | Гибкий, Android, крупные проекты |
| **Муравей** | на основе XML | Унаследованные проекты |
| **Базель** | Многоязычный | Монорепозитории, в масштабе Google |
```bash
# Maven
mvn clean install               # build
mvn test                        # run tests
mvn package                     # create JAR/WAR

# Gradle
./gradlew build                 # build
./gradlew test                  # run tests
./gradlew bootRun               # run Spring Boot app
```

## Тестирование
| Рамочная | Цель |
|-----------|---------|
| **Юнит 5** | Стандартная среда тестирования |
| **Мокито** | Издевательство |
| **УтверждатьJ** | Беглые утверждения |
| **Тестовые контейнеры** | Интеграционные тесты на основе Docker |
| **WireMock** | Издевательство над HTTP API |
| **АрхЮнит** | Архитектурные тесты |
| **Гарантированный отдых** | Тестирование REST API |
| **ДжМХ** | Микробенчмаркинг |
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;
    @InjectMocks UserService service;

    @Test
    void shouldFindUserById() {
        when(repo.findById(1L)).thenReturn(Optional.of(new User("Alice")));
        var user = service.findById(1L);
        assertThat(user.name()).isEqualTo("Alice");
    }
}
```

## Краткое содержание
Экосистема Java является наиболее развитой в сфере корпоративных вычислений. Стандартный стек: **Gradle** или **Maven** для сборок, **Spring Boot** для веб-сайтов и микросервисов, **JUnit 5 + Mockito** для тестирования, **Hibernate** для ORM, **IntelliJ IDEA** в качестве IDE и **Docker** для развертывания. Сильная сторона Java — это обширная экосистема, корпоративная поддержка и обратная совместимость. Современная Java (17+) с записями, запечатанными классами, сопоставлением с образцом и виртуальными потоками оживляет язык.
