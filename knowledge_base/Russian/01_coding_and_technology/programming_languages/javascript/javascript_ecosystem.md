## Управление пакетами
| Инструмент | Реестр | Особенности |
|------|----------|----------|
| **нпм** | npmjs.com | По умолчанию с Node.js |
| **пряжа** | npmjs.com | Рабочие области, режим PnP |
| **пнпм** | npmjs.com | Быстрый, экономичный, строгий |
| **булочка** | npmjs.com | Сверхбыстрый встроенный |
```bash
npm init -y                   # initialize project
npm install express           # add dependency
npm install -D typescript     # add dev dependency
npm run build                 # run script from package.json
```

## Краткое содержание
Экосистема JavaScript является крупнейшей в программировании. Современный стек: **Vite** для сборки, **pnpm** для пакетов, **Vitest** для тестирования, **ESLint + Prettier** для качества кода, **React/Next.js** или **Vue/Nuxt** для внешнего интерфейса и **Vercel** или **Cloudflare** для развертывания. TypeScript теперь необходим для любого серьезного проекта. Экосистема развивается быстро — оставайтесь в курсе событий, но избегайте смены инфраструктур.
