# Rust — Руководство по экосистеме и инструментам
В этом руководстве рассматриваются основные инструменты, платформы и инфраструктура экосистемы Rust.
---

## Управление пакетами и сборка
| Инструмент | Цель |
|------|---------|
| **Груз** | Менеджер пакетов, система сборки, запуск тестов |
| **crates.io** | Официальный реестр пакетов |
| **ржавчина** | Установщик и менеджер Toolchain |
| **груз-редактировать** | Добавить/удалить/обновить зависимости |
| **грузовые часы** | Перестроить при изменении файла |
| **грузовой аудит** | Проверка уязвимостей безопасности |
| **груз-резкий** | Линтер (встроенный) |
| **грузовая перевозка** | Средство форматирования кода (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

## Тестирование
| Инструмент | Цель |
|------|---------|
| **испытание груза** | Встроенный модуль + интеграционные тесты |
| **критерий** | Система сравнительного анализа |
| **протест** | Тестирование на основе свойств |
| **насмешка** | Издевательская структура |
| **токио::тест** | Поддержка асинхронного тестирования |
| **инста** | Моментальное тестирование |
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## Краткое содержание
Экосистема Rust является целостной и высококачественной, сосредоточенной вокруг Cargo. Стандартный стек: **Cargo** для всего (сборка, тестирование, публикация), **Tokio** для асинхронности, **Axum** или **Actix-web** для Интернета, **serde** для сериализации, **SQLx** для баз данных и **clap** для CLI. Отличительная особенность Rust — развертывание как один статический двоичный файл без каких-либо зависимостей во время выполнения. Экосистема отдает приоритет правильности и производительности, а не удобству.
