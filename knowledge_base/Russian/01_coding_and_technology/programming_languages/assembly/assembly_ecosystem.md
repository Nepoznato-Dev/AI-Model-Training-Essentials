## Сборщики по архитектуре
### х86/х86-64
| Ассемблер | Платформа | Заметки |
|-----------|----------|-------|
| **НАСМ** | Кроссплатформенный | Самый популярный и понятный синтаксис |
| **МАСМ** | Окна | Ассемблер макросов Microsoft |
| **ФАСМ** | Кроссплатформенный | Самостоятельный хостинг, быстро |
| **ГАЗ (а.с.)** | Линукс/Юникс | GNU Assembler (синтаксис AT&T) |
| **ЯСМ** | Кроссплатформенный | NASM-совместимый |
| **УАСМ** | Кроссплатформенный | MASM-совместимый |
### РУКА
| Ассемблер | Платформа | Заметки |
|-----------|----------|-------|
| **GNU как (ARM)** | Кроссплатформенный | Сборка ARM |
| **Кейл АСМ** | Встроенный | Разработка ARM |
| **Ассемблер ARM** | АРМ | Компилятор ARM |
### Другой
| Ассемблер | Архитектура | Заметки |
|-----------|-------------|-------|
| **авр-ас** | АВР | Микроконтроллеры |
| **расм** | Z80 | Ретро-вычисления |
| **ca65** | 6502 | РЭШ, Коммодор |
| **СПИМ/МАРС** | МИПС | Образовательный |
```bash
# NASM (Linux x86-64)
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# NASM (Windows)
nasm -f win64 hello.asm -o hello.obj
golink /console /entry _start hello.obj

# FASM
fasm hello.asm hello

# GAS (AT&T syntax)
as -o hello.o hello.s
ld hello.o -o hello
```

```makefile
# Makefile for NASM project
ASM = nasm
ASM_FLAGS = -f elf64
LD = ld
TARGET = hello

all: $(TARGET)

$(TARGET): hello.o
	$(LD) hello.o -o $(TARGET)

hello.o: hello.asm
	$(ASM) $(ASM_FLAGS) hello.asm -o hello.o

clean:
	rm -f *.o $(TARGET)
```

## Тестирование
| Инструмент | Цель |
|------|---------|
| **Пользовательский тестовый комплект** | Платформа для тестирования сборки |
| **Единство** | Модульное тестирование на основе C (для смешанных проектов) |
| **Тест Google** | Тестирование C++ (для смешанных проектов) |
| **Пользовательские макросы** | Макросы утверждений |
```nasm
; NASM test example
section .data
    test_pass db "PASS", 10, 0
    test_fail db "FAIL", 10, 0

section .text
    global _start

test_add:
    mov rax, 2
    mov rbx, 3
    add rax, rbx
    cmp rax, 5
    jne .fail
    ; print pass
    mov rax, 1
    mov rdi, 1
    mov rsi, test_pass
    mov rdx, 5
    syscall
    ret
.fail:
    mov rax, 1
    mov rdi, 1
    mov rsi, test_fail
    mov rdx, 5
    syscall
    ret

_start:
    call test_add
    mov rax, 60
    xor rdi, rdi
    syscall
```

## Краткое содержание
Экосистема Ассамблеи зависит от архитектуры и минималистична по дизайну. Стандартная цепочка инструментов: **NASM** (x86/x86-64) или **GNU as** (ARM) для сборки, **ld** для компоновки, **GDB** для отладки, **Ghidra** или **IDA Pro** для обратного проектирования и **QEMU** для эмуляции. Сборка превосходно справляется с разработкой операционных систем, встроенных систем, обратного проектирования, критически важного для производительности кода и разработки загрузчика. Экосистема необходима для понимания того, как компьютеры работают на самом низком уровне. Для обучения **MARS** (MIPS) и **SASM** (x86) предоставляют среду, удобную для начинающих.
