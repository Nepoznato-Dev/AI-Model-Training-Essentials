## Системы сборки
| Инструмент | Тип | Лучшее для |
|------|------|----------|
| **Сделать** | Классический | Простые проекты, стандарт Unix |
| **CMake** | Кроссплатформенный | Отраслевые стандарты, сложные проекты |
| **Мезон** | Современный | Быстрый и понятный синтаксис |
| **Ниндзя** | Быстро | Система сборки низкого уровня (используется CMake) |
| **Базель** | Масштаб | Монорепозитории, Google |
| **xmake** | Современный | Кроссплатформенный на основе Lua |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## Краткое содержание
Экосистема C является основой современных вычислений. Стандартная цепочка инструментов: **GCC** или **Clang** для компиляции, **CMake** для сборки, **GDB** для отладки, **Valgrind** для анализа памяти и **clang-tidy** для анализа. Ключевые библиотеки включают **OpenSSL** для шифрования, **libcurl** для HTTP, **SQLite** для баз данных. Экосистема C по своей конструкции минимальна — вы создаете то, что вам нужно. Для современных разработок всегда используйте дезинфицирующие средства (ASan, UBSan) во время тестирования.
