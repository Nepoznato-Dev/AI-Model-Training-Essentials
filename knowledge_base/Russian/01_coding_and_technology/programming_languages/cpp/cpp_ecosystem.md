# C++ — Руководство по экосистеме и инструментам
В этом руководстве рассматриваются основные инструменты, библиотеки и инфраструктура экосистемы C++.
---

## Компиляторы
| Компилятор | Платформа | Заметки |
|----------|----------|-------|
| **GCC (g++)** | Линукс/Юникс | Коллекция компиляторов GNU, широко используемая |
| **Кланг++** | Кроссплатформенный | Отличная диагностика на базе LLVM |
| **МСВК** | Окна | Компилятор Microsoft Visual C++ |
| **Intel oneAPI (icpx)** | Кроссплатформенный | Высокая производительность, высокопроизводительные вычисления |
| **зиг с++** | Кроссплатформенный | Отличная кросс-компиляция |
```bash
g++ -std=c++23 -O2 -Wall -Wextra -o app main.cpp
clang++ -std=c++23 -stdlib=libc++ -o app main.cpp
```

## Системы сборки
| Инструмент | Тип | Лучшее для |
|------|------|----------|
| **CMake** | Кроссплатформенный | Отраслевой стандарт, большинство проектов |
| **Мезон** | Современный | Быстрый, понятный синтаксис, серверная часть Ninja |
| **Базель** | Масштаб | Монорепозитории, в масштабе Google |
| **Конан + CMake** | Поддержка пакетов | Управление пакетами C++ |
| **xmake** | Современный | Встроенный менеджер пакетов на основе Lua |
| **Сделать** | Классический | Простые проекты Unix |
| **Ниндзя** | Быстро | Низкоуровневая система сборки |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.24)
project(myapp LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(myapp src/main.cpp)
target_compile_features(myapp PRIVATE cxx_std_23)

# Find packages
find_package(fmt REQUIRED)
target_link_libraries(myapp PRIVATE fmt::fmt)
```

## Тестирование
| Рамочная | Цель |
|-----------|---------|
| **Тест Google (gtest)** | Самый популярный Google |
| **Google Mock (gmock)** | Издевательская структура |
| **Уловка2** | Одиночный заголовок, в стиле BDD |
| **докторант** | Легкий одинарный |
| **Буст.Тест** | Тестирование на основе Boost |
| **Бенчмарк Google** | Микробенчмаркинг |
| **наностенд** | Облегченный бенчмаркинг |
```cpp
// Catch2 example
#define CATCH_CONFIG_MAIN
#include <catch2/catch.hpp>

TEST_CASE("vector operations") {
    std::vector<int> v = {1, 2, 3};
    REQUIRE(v.size() == 3);
    REQUIRE(v[0] == 1);
    SECTION("push_back") {
        v.push_back(4);
        REQUIRE(v.size() == 4);
    }
}
```

## Краткое содержание
C++ имеет самую богатую и сложную экосистему. Стандартная цепочка инструментов: **GCC** или **Clang** для компиляции, **CMake** для сборок, **Conan** или **vcpkg** для пакетов, **Google Test** или **Catch2** для тестирования, **clang-tidy** для проверки, **GDB** для отладки и **ASan/UBSan** для дезинфицирующих средств. Ключевые библиотеки включают **Boost** для утилит, **fmt** для форматирования, **nlohmann/json** для JSON, **spdlog** для ведения журналов, **Eigen** для математических вычислений и **Qt** для графического интерфейса. Современный C++ (20/23) с концепциями, диапазонами, сопрограммами и модулями трансформирует экосистему. Всегда компилируйте с`-Wall -Wextra -Werror`и используйте дезинфицирующие средства в CI.
