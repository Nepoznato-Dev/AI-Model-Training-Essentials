# Scratch — История версий и эволюция
## Временная шкала
| Версия | Год | Ключевая тема |
|---------|------|-----------|
| Предварительная царапина | 2003 | В медиалаборатории Массачусетского технологического института формируется Scratch-команда |
| Скретч 1.0 | 2007 | **Первая версия** — визуальное программирование для детей |
| Скретч 1.4 | 2009 | Улучшенная графика, больше блоков |
| Скретч 2.0 | 2013 | **Основное**: веб-редактор, облачные переменные, рюкзак |
| Скретч 3.0 | 2019 | **Основное**: Полная переработка (HTML5/JS), расширения, перо |
| Скретч 3.x | 2019–25 | Распознавание видео, преобразование текста в речь, перевод, micro:bit |

| Скретч-рабочий стол | 2020 | Офлайн-редактор (электронный) |
## Основные вехи
### Истоки (2003–2006)
- **2003**: группа Lifelong Kindergarten MIT Media Lab начинает разработку Scratch.
- Под руководством Митчела Резника
- **Цель**: научить детей программированию с помощью визуальных блоков.
- Вдохновлено: логотипом (Сеймур Пейперт), логотипом Lego, Squeak Etoys.
- Название: «Scratch» — от диджейского скретча (смешивания медиа).
### Скретч 1.0 (2007)
- **2007**: Первый публичный выпуск.
- Программирование блоков перетаскиванием
- Проекты на основе спрайтов (персонажи, анимация)
- Звук, графика, анимация
- Встроенный писк (Smalltalk)
– **Цель**: дети от 8 до 16 лет, но охват гораздо шире.
### Скретч 1.4 (2009)
- Улучшен рендеринг графики.
- Больше библиотек спрайтов
- Улучшенная звуковая поддержка
- Последняя версия, построенная на Squeak
### Скретч 2.0 (2013)
- **Полноценный веб-редактор** — работает в браузере.
- Облачные переменные — обменивайтесь данными между проектами.
- Рюкзак — делитесь спрайтами/скриптами между проектами.
- Пользовательские блоки (например, функции)
- Встроенный ActionScript 3 (Flash)
- Функции сообщества: ремикс, публикация, комментарии.
### Скретч 3.0 (2019)
- **Полная переработка** — HTML5/JavaScript (без Flash).
- Работает на планшетах, телефонах, Chromebook
- **Расширения**:
  - Ручка (рисунок)
  - Видеосенсор (камера)
  - Преобразование текста в речь
  - Перевести (Google Переводчик)
  - микро:бит (аппаратное обеспечение)
  - LEGO Mindstorms EV3
  - МыДо 2.0
- Улучшения звукового редактора.
- Новый редактор рисования (вектор + растровое изображение)
- Рюкзак, облачные переменные сохранены
### Scratch Desktop и не только (2020 – настоящее время)
- **2020**: Scratch Desktop — автономный редактор (на базе Electronic).
- Продолжение разработки расширений.
- Расширения AI/ML (созданные сообществом)
- Интеграция с физическими вычислениями (micro:bit, Arduino)
## Эволюция категорий блоков
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Изучаемые концепции программирования
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Ключевые принципы проектирования
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Влияние и принятие
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
