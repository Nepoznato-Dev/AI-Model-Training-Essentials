# Веб-разработка
## Фронтенд-разработка
### Основные технологии
#### HTML (язык разметки гипертекста)
– **Семантический HTML**: использование осмысленных тегов (`<header>`,`<nav>`,`<main>`,`<article>`,`<section>`,`<aside>`,`<footer>`).
- **Формы**: типы ввода, проверка, метки доступности.
- **Медиа**: изображения, видео, встраивание аудио.
- **Метатеги**: SEO, область просмотра, кодировка символов.
- **Функции HTML5**: Canvas, SVG, локальное хранилище, геолокация, веб-сокеты.
#### CSS (каскадные таблицы стилей)
- **Блок-модель**: содержимое, отступы, границы, поля.
- **Системы компоновки**:
  - **Flexbox**: одномерные макеты, выравнивание содержимого, выравнивание элементов.
  - **Сетка**: двумерные макеты, шаблон сетки, область сетки.
  - **Позиционирование**: статическое, относительное, абсолютное, фиксированное, закрепленное.
– **Адаптивный дизайн**: медиазапросы, подход, ориентированный на мобильные устройства.
- **Переменные CSS**: пользовательские свойства для тем.
- **Анимация**: переходы, ключевые кадры, преобразования.
- **Препроцессоры**: Sass, Less (переменные, примеси, вложенность)
#### JavaScript
- **Манипулирование DOM**: выбор, создание и изменение элементов.
- **События**: нажатие, отправка, клавиатура, пользовательские события, делегирование событий.
- **Функции ES6+**: стрелочные функции, деструктуризация, распространение/отдых, модули, асинхронность/ожидание.
- **API**: Fetch, XMLHttpRequest, localStorage, sessionStorage.
- **TypeScript**: статическая типизация, интерфейсы, дженерики, декораторы.
### Современные интерфейсные фреймворки
#### Реакция
- **Компоненты**: функциональные компоненты, компоненты классов.
- **Хуки**: useState, useEffect, useContext, useReducer, пользовательские хуки.
- **Управление состоянием**: Context API, Redux, Zustand, Recoil.
- **Маршрутизация**: React Router (BrowserRouter, Routes, Route, Link)
- **Экосистема**: Next.js (SSR, SSG), Remix, Gatsby.
- **Виртуальный DOM**: эффективный рендеринг с помощью алгоритма сравнения.
#### Vue.js
- **API параметров**: данные, методы, вычисления, наблюдение.
- **API композиции**: setup(), ref, реактивный, вычисляемый.
- **Директивы**: v-if, v-for, v-bind, v-on, v-model
- **Vuex/Pinia**: управление состоянием.
- **Vue Router**: маршрутизация на стороне клиента.
- **Nuxt.js**: платформа рендеринга на стороне сервера.
#### Угловой
- **Компоненты**: декораторы, шаблоны, крючки жизненного цикла.
- **Сервисы**: внедрение зависимостей, одноэлементный шаблон.
- **RxJS**: Реактивное программирование, наблюдаемые.
- **Маршрутизация**: RouterModule, охранники, преобразователи.
- **Формы**: реактивные формы на основе шаблонов.
- **NgRx**: управление состоянием в стиле Redux.
### Инструменты сборки и сборщики
- **Webpack**: объединение модулей, разделение кода, загрузчики, плагины.
- **Vite**: инструмент быстрой сборки с использованием собственных модулей ES.
- **Посылка**: сборщик с нулевой конфигурацией.
- **Объединенный пакет**: оптимизирован для библиотек.
- **esbuild**: Чрезвычайно быстрый сборщик JavaScript.
- **Babel**: транспилятор JavaScript для обратной совместимости.
- **PostCSS**: обработка CSS с помощью плагинов.
### CSS-фреймворки и библиотеки
- **Bootstrap**: библиотека компонентов, сетка, утилиты.
- **Tailwind CSS**: фреймворк CSS, ориентированный на утилиты.
- **Material UI**: реализация Material Design от Google.
- **Интерфейс Chakra**: Доступная библиотека компонентов.
- **Ant Design**: компоненты пользовательского интерфейса корпоративного уровня.
- **Стилизованные компоненты**: библиотека CSS-in-JS.
- **Emotion**: CSS-in-JS с исходными картами.
## Бэкэнд-разработка
### Серверные языки
#### Node.js
- **Среда выполнения**: JavaScript на сервере (движок V8).
- **Express.js**: минимальная веб-инфраструктура, архитектура промежуточного программного обеспечения.
- **NestJS**: архитектура на основе Angular, TypeScript.
- **Fastify**: высокопроизводительная платформа.
- **Коа**: Modern Express от тех же авторов.
- **Управление пакетами**: npm, пряжа, pnpm.
#### Питон
- **Django**: полнофункциональный фреймворк, ORM, панель администратора, батарейки в комплекте.
- **Flask**: микрофреймворк, экосистема расширений.
- **FastAPI**: современная асинхронная автоматическая документация по API.
- **Пирамида**: гибкая масштабируемая структура.
#### Другие серверные языки
- **Ruby on Rails**: Соглашение о конфигурации, ActiveRecord ORM.
- **Java Spring**: корпоративная среда, внедрение зависимостей.
- **PHP Laravel**: элегантный синтаксис, Eloquent ORM, шаблоны Blade.
- **Go Gin**: высокая производительность, минимальный фреймворк.
- **Rust Actix**: безопасность памяти, производительность.
- **C# ASP.NET Core**: кроссплатформенные корпоративные функции.
### Интеграция с базой данных
#### ORM (объектно-реляционное сопоставление)
- **Sequelize**: Node.js ORM для баз данных SQL.
- **Prisma**: типобезопасный доступ к базе данных, автоматически создаваемый клиент.
- **SQLAlchemy**: набор инструментов Python SQL и ORM.
- **ActiveRecord**: Ruby on Rails ORM
- **Спящий режим**: Java ORM
- **Entity Framework**: .NET ORM.
#### Драйверы баз данных
- **pg**: клиент PostgreSQL для Node.js.
- **mysql2**: клиент MySQL с обещаниями.
- **pymongo**: драйвер MongoDB для Python.
- **redis**: клиент Redis для нескольких языков.
### Разработка API
#### REST API
- **Методы HTTP**: GET, POST, PUT, PATCH, DELETE.
- **Коды состояния**: 200, 201, 400, 401, 403, 404, 500.
- **Именование ресурсов**: существительные, множественное число, иерархическое расположение.
– **Управление версиями**: URL-путь, заголовки, параметры запроса.
- **Аутентификация**: JWT, OAuth, ключи API.
- **Документация**: OpenAPI/Swagger, Postman.
#### ГрафQL
- **Определение схемы**: типы, запросы, мутации, подписки.
- **Резолверы**: получение данных на уровне поля.
- **Сервер Apollo**: реализация сервера GraphQL.
- **Relay**: клиент Facebook GraphQL.
- **Преимущества**: отсутствие чрезмерной выборки, одна конечная точка, строгая типизация.
#### gRPC
- **Буферы протокола**: язык определения интерфейса.
- **HTTP/2**: двунаправленная потоковая передача.
- **Примеры использования**: связь с микросервисами, приложения реального времени.
### Аутентификация и авторизация
- **На основе сеанса**: файлы cookie, сеансы на стороне сервера.
- **На основе токенов**: JWT (веб-токены JSON), без сохранения состояния.
- **OAuth 2.0**: система авторизации, сторонний вход в систему.
- **OpenID Connect**: уровень идентификации на OAuth 2.0.
- **SAML**: корпоративный единый вход.
- **Хеширование паролей**: bcrypt, argon2, scrypt.
- **Многофакторная аутентификация**: TOTP, SMS, коды электронной почты.
## DevOps и развертывание
### Контроль версий
- **Git**: распределенный контроль версий.
- **GitHub/GitLab/Bitbucket**: хостинг репозитория.
- **Стратегии ветвления**: Git Flow, GitHub Flow, разработка на основе ствола.
- **CI/CD**: автоматизированные конвейеры тестирования и развертывания.
### Контейнеризация
- **Docker**: среда выполнения контейнера, Dockerfile, изображения.
- **Docker Compose**: оркестровка нескольких контейнеров.
- **Реестры контейнеров**: Docker Hub, AWS ECR, Google GCR.
- **Рекомендации**: многоэтапные сборки, минимальное количество базовых образов.
### Оркестровка
- **Kubernetes**: оркестровка контейнеров, модули, сервисы, развертывания.
- **Helm**: менеджер пакетов Kubernetes.
- **Service Mesh**: Istio, Linkerd для сетей микросервисов.
### Облачные платформы
- **AWS**: EC2, S3, Lambda, RDS, CloudFront, ECS/EKS.
- **Google Cloud**: вычислительная система, облачное хранилище, облачные функции, GKE.
- **Azure**: виртуальные машины, хранилище BLOB-объектов, функции, AKS.
- **Vercel**: развертывание внешнего интерфейса, бессерверные функции.
- **Netlify**: статический хостинг сайтов, бессерверные функции.
- **Heroku**: Платформа как услуга (PaaS)
- **DigitalOcean**: упрощенная облачная инфраструктура.
### Конвейеры CI/CD
- **Действия GitHub**: автоматизация рабочих процессов.
- **GitLab CI**: встроенная непрерывная интеграция.
- **Jenkins**: расширяемый сервер автоматизации.
- **CircleCI**: облачная CI/CD.
- **Travis CI**: служба непрерывной интеграции.
- **ArgoCD**: непрерывная доставка GitOps для Kubernetes.
### Мониторинг и журналирование
- **Производительность приложений**: New Relic, Datadog, AppDynamics.
- **Отслеживание ошибок**: Sentry, Rollbar, Bugsnag.
- **Журналирование**: стек ELK (Elasticsearch, Logstash, Kibana), Splunk.
- **Мониторинг работоспособности**: Pingdom, UptimeRobot
– **Аналитика**: Google Analytics, Mixpanel, Amplitude.
## Веб-производительность
### Методы оптимизации
- **Разделение кода**: отложенная загрузка, динамический импорт.
- **Tree Shaking**: удаление неиспользуемого кода.
- **Минификация**: уменьшение размера файлов.
- **Сжатие**: Gzip, Brotli.
- **Кэширование**: кеш браузера, CDN, сервис-воркеры.
- **Оптимизация изображений**: WebP, AVIF, отложенная загрузка, адаптивные изображения.
- **Критический CSS**: встраивание стилей над сгибом.
- **Оптимизация базы данных**: индексирование, оптимизация запросов, объединение пулов соединений.
### Основные веб-показатели
- **LCP (наибольшая отрисовка контента)**: производительность загрузки (<2,5 с)
- **FID (первая задержка ввода)**: интерактивность (<100 мс)
- **CLS (кумулятивный сдвиг макета)**: визуальная стабильность (<0,1)
- **INP (Взаимодействие со следующей отрисовкой)**: показатель отклика.
### Сети доставки контента (CDN)
- **Cloudflare**: безопасность, производительность, DNS.
- **Akamai**: корпоративный CDN.
- **Amazon CloudFront**: AWS CDN
- **Быстро**: облачная платформа Edge.
- **StackPath**: пограничные службы.
## Веб-безопасность
### Распространенные уязвимости (ТОП-10 OWASP)
- **Внедрение**: внедрение SQL, внедрение команд.
- **Нарушение аутентификации**: перехват сеанса, подстановка учетных данных.
- **Раскрытие конфиденциальных данных**: незашифрованные данные, слабая криптография.
- **Внешние объекты XML (XXE)**: уязвимости синтаксического анализатора XML.
- **Нарушение контроля доступа**: повышение привилегий, несанкционированный доступ.
- **Неправильная конфигурация безопасности**: учетные данные по умолчанию, подробные ошибки.
- **Межсайтовый скриптинг (XSS)**: отраженный, сохраненный, на основе DOM.
- **Небезопасная десериализация**: атаки путем внедрения объектов.
- **Использование компонентов с известными уязвимостями**: устаревшие зависимости.
- **Недостаточное ведение журнала и мониторинг**: необнаруженные нарушения.
### Рекомендации по обеспечению безопасности
- **HTTPS**: шифрование TLS/SSL, HSTS.
- **Политика безопасности контента (CSP)**: предотвращение XSS-атак.
- **Проверка ввода**: очистка вводимых пользователем данных.
- **Кодирование вывода**: предотвращение атак путем внедрения.
- **Защита CSRF**: токены защиты от CSRF, файлы cookie SameSite.
- **Ограничение скорости**: предотвращение атак методом перебора.
- **Заголовки безопасности**: параметры X-Frame, параметры X-Content-Type.
- **Сканирование зависимостей**: аудит npm, Snyk, Dependabot.
## Тестирование
### Типы тестирования
- **Модульное тестирование**: отдельные компоненты/функции.
- **Интеграционное тестирование**: взаимодействие компонентов.
- **Комплексное (E2E)**: полный рабочий процесс пользователя.
- **Визуальная регрессия**: обнаружение изменений пользовательского интерфейса.
- **Тестирование производительности**: нагрузочное, стрессовое, пиковое тестирование.
- **Тестирование доступности**: соответствие WCAG.
### Платформы тестирования
- **Jest**: среда тестирования JavaScript.
- **Mocha**: гибкий инструмент для запуска тестов.
- **pytest**: среда тестирования Python.
- **RSpec**: среда тестирования Ruby.
- **JUnit**: среда тестирования Java.
### Инструменты E2E-тестирования
- **Selenium**: автоматизация браузера.
- **Кипарис**: современное тестирование E2E.
- **Драматург**: кроссбраузерная автоматизация.
- **Кукловод**: управление Chrome без головы.
## Доступность (a11y)
### Рекомендации WCAG
– **Ощутимо**: варианты текста, подписи, адаптируемый контент.
- **Работо**: навигация с помощью клавиатуры, достаточное время, никаких судорог.
- **Понятность**: читаемость, предсказуемость, помощь при вводе.
- **Надежность**: совместимость со вспомогательными технологиями.
### Реализация
– **Семантический HTML**: правильная иерархия заголовков, ориентиры.
- **Атрибуты ARIA**: роли, состояния, свойства.
- **Управление фокусом**: видимые индикаторы фокуса, логический порядок вкладок.
- **Цветовой контраст**: соотношение текста минимум 4,5:1.
- **Тестирование программ чтения с экрана**: NVDA, JAWS, VoiceOver.
- **Навигация с помощью клавиатуры**: доступны все интерактивные элементы.
## Прогрессивные веб-приложения (PWA)
### Возможности PWA
- **Сервисные работники**: офлайн-функциональность, фоновая синхронизация.
- **Манифест веб-приложения**: приглашение к установке, значки, цвета темы.
- **Оболочка приложения**: кэшированный скелет пользовательского интерфейса.
- **Push-уведомления**: взаимодействие с пользователем.
- **Адаптивный дизайн**: работает на всех устройствах.
- **Требуется HTTPS**: безопасный контекст.
### Инструменты
- **Workbox**: библиотеки сервисных работников.
- **Маяк**: аудит PWA.
- **PWA Builder**: создание манифестов и значков.
## Новые технологии
### Веб-сборка (Wasm)
- **Цель**: запускать скомпилированный код в браузере со скоростью, близкой к исходной.
- **Языки**: цели компиляции C++, Rust, Go.
- **Примеры использования**: игры, редактирование видео, криптография, выводы машинного обучения.
### Бессерверная архитектура
- **Функции как услуга**: AWS Lambda, функции Azure, функции Google Cloud.
- **Преимущества**: отсутствие управления сервером, автоматическое масштабирование, оплата по факту использования.
– **Соображения**: холодный запуск, привязка к поставщику, сложность отладки.
### Архитектура Jamstack
- **JavaScript**: интерактивность на стороне клиента.
- **API**: бессерверные функции, сторонние сервисы.
- **Разметка**: готовые статические файлы.
- **Инструменты**: Next.js, Gatsby, Hugo, Eleventy.
- **Преимущества**: производительность, безопасность, масштабируемость, опыт разработчиков.
### Общение в реальном времени
- **WebSockets**: двусторонняя связь.
- **События, отправленные сервером**: потоковая передача от сервера к клиенту.
- **WebRTC**: одноранговое видео, аудио, данные.
- **Примеры использования**: чат, совместная работа, прямые трансляции, игры.
### Микро-интерфейсы
- **Концепция**: распространение микросервисов на интерфейс.
– **Подходы**: интеграция на этапе сборки, во время выполнения, периферийная интеграция.
- **Преимущества**: независимое развертывание, автономия команды.
- **Проблемы**: согласованность, производительность, сложность.
