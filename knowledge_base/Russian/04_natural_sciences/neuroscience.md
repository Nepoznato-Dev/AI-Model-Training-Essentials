# Нейронаука
Нейронаука — это изучение нервной системы — головного мозга, спинного мозга и всех нервов, которые соединяют их с телом. Оно охватывает несколько уровней: от молекул и генов до отдельных нейронов и синапсов, цепей и областей мозга, поведения, познания и сознания. Мозг — самая сложная структура в известной вселенной, содержащая примерно 86 миллиардов нейронов, соединенных триллионами синапсов, и понимание того, как он работает, является одной из величайших задач науки.
---

## Нейрон
### Части нейрона
| Компонент | Функция |
|-----------|----------|
| **Дендриты** | Получать сигналы от других нейронов; ветвящиеся расширения |
| **Тело клетки (сома)** | Интегрирует входящие сигналы; содержит ядро ​​|
| **Аксон** | Длинное волокно, передающее электрические сигналы (потенциалы действия) от сомы |
| **Миелиновая оболочка** | Изолирующий слой вокруг аксонов; ускоряет передачу сигнала |
| **Узлы Ранвье** | Разрывы в миелине; разрешить скачкообразную проводимость (скачки сигнала между узлами) |
| **Аксонные терминали (синаптические бутоны)** | Выпуск нейромедиаторов в синапс |
### Типы нейронов
| Тип | Направление | Функция |
|------|-----------|----------|
| **Сенсорная (афферентная)** | Тело → мозг | Несут информацию от органов чувств (осязание, температура, боль, зрение и т. д.) |
| **Двигатель (эфферентный)** | Мозг → тело | Контролируйте мышцы и железы |
| **Интернейроны** | Внутри ЦНС | Соединяйте нейроны с другими нейронами; большинство нейронов являются интернейронами |

## Как нейроны общаются
### Потенциал действия
| Фаза | Описание |
|-------|-------------|
| **Потенциал покоя** | Нейрон находится при ~-70 мВ; натриево-калиевый насос поддерживает ионный баланс |
| **Деполяризация** | Стимул открывает натриевые каналы; Na+ врывается; мембранный потенциал повышается |
| **Порог** | Если потенциал достигает ~-55 мВ, срабатывает потенциал действия (все или ничего) |
| **Фаза роста** | Потенциал-управляемые натриевые каналы открываются; потенциальные скачки до ~+40 мВ |
| **Фаза падения** | Натриевые каналы закрываются; калиевые каналы открываются; К+ вытекает; потенциальные падения |
| **Недолет (гиперполяризация)** | Потенциал ненадолго падает ниже уровня покоя |
| **Рефрактерный период** | Нейрон не может немедленно выстрелить снова; обеспечивает однонаправленное распространение |
### Синапс
| Компонент | Роль |
|-----------|------|
| **Пресинаптический нейрон** | Отправляет сигнал; содержит синаптические везикулы с нейротрансмиттерами |
| **Синаптическая щель** | Крошечный зазор (~20 нм) между нейронами |
| **Постсинаптический нейрон** | Получает сигнал; имеет рецепторные белки |
| **Нейромедиаторы** | Химические посланники, пересекающие синапс |
| **Рецепторы** | Связать нейротрансмиттеры; открыть ионные каналы или запустить каскады вторичных мессенджеров |

## Ключевые нейромедиаторы
| Нейромедиатор | Функция | Сопутствующие условия |
|-----------------|----------|----------------------|
| **Глутамат** | Главный возбуждающий нейромедиатор; обучение; память | Избыток → эксайтотоксичность (инсульт, нейродегенерация) |
| **ГАБА** | Главный тормозной нейромедиатор; снижает нервную активность | Дефицит → тревога, эпилепсия |
| **Дофамин** | Награда; мотивация; управление двигателем; внимание | Дефицит → Паркинсон; избыток → шизофрения |
| **Серотонин** | Настроение; спать; аппетит; пищеварение | Дефицит → депрессия, тревога |
| **Ацетилхолин** | Активация мышц; обучение; память | Дефицит → Болезнь Альцгеймера |
| **Норадреналин** | Возбуждение; бдительность; реакция на стресс | Дисрегуляция → СДВГ; депрессия |
| **Эндорфины** | Облегчение боли; удовольствие | Релаксация, вызванная физическими упражнениями («кайф бегуна») |

## Структура мозга
### Основные области мозга
| Регион | Функция |
|--------|----------|
| **Кора головного мозга** | Высшее познание; делится на лобную, теменную, височную, затылочную доли |
| **Лобная доля** | Планирование; принятие решений; личность; произвольные движения (моторная кора) |
| **Теменная доля** | Сенсорная обработка; пространственное осознание; навигация |
| **Височная доля** | слух; понимание языка; память (гиппокамп) |
| **Затылочная доля** | Визуальная обработка |
| **Мозжечок** | Координация движений; баланс; двигательное обучение; некоторые когнитивные функции |
| **Ствол мозга** | Жизненно важные функции: дыхание; частота сердечных сокращений; цикл сна-бодрствования |
| **Таламус** | Сенсорная релейная станция; направляет сигналы в соответствующие области коры |
| **Гипоталамус** | Гомеостаз; гормональная регуляция; голод; жажда; циркадные ритмы |
### Лимбическая система
| Структура | Функция |
|-----------|----------|
| **Минодалина** | Эмоциональная обработка; страх; обнаружение угроз; эмоциональная память |
| **Гиппокамп** | Формирование памяти; пространственная навигация; преобразует кратковременную память в долговременную |
| **Базальные ганглии** | Формирование привычки; вознаграждать обучение; управление двигателем |
| **Поясная кора** | Обнаружение ошибок; сочувствие; импульсное управление; регулирование эмоций |
| **Прилежащее ядро** | Схема вознаграждения; удовольствие; зависимость |

## Нейропластичность
| Тип | Описание | Пример |
|------|-------------|---------|
| **Синаптическая пластичность** | Сила синапсов меняется в зависимости от активности | Долговременная потенциация (ДП); долговременная депрессия (LTD) |
| **Структурная пластичность** | Нейроны выращивают новые дендриты или аксоны | Обучение новым навыкам; восстановление после травмы |
| **Корковое переназначение** | Области мозга переназначают функции | Зрительная кора слепых людей обрабатывает осязание и звук |
| **Нейрогенез** | Рождаются новые нейроны | Происходит в гиппокампе; стимулируется упражнениями и обучением |

## Методы исследования
| Метод | Что он измеряет | Разрешение |
|--------|-----------------|------------|
| **фМРТ** | Уровень кислорода в крови (ЖИРНЫЙ сигнал) → активность мозга | Хорошая пространственная (~1 мм); плохое временное (~1 с) |
| **ЭЭГ** | Электрическая активность кожи головы | Отличное временное (~1 мс); плохой пространственный |
| **МЭГ** | Магнитные поля от нейронной активности | Хорошее временное и пространственное |
| **ПЭТ** | Радиоактивный индикатор → метаболическая активность | Умеренный пространственный и временной |
| **ТМС** | Магнитные импульсы → временно нарушают работу области мозга | Причинно-следственные доказательства; ограниченная глубина |
| **Отдельная запись** | Электрическая активность отдельных нейронов | Одна ячейка; инвазивный; в основном исследования на животных |
| **Оптогенетика** | Светоактивируемые нейроны | Точный контроль; исследования на животных |
| **DTI** (Диффузионно-тензорная визуализация) | Пучки белого вещества | Сопоставление возможностей подключения |

## Краткое содержание
Нейронаука изучает нервную систему на всех уровнях — от молекулярных механизмов ионных каналов до субъективного опыта сознания. Нейроны общаются посредством электрических потенциалов действия и химических синапсов, используя нейротрансмиттеры, такие как глутамат, ГАМК, дофамин и серотонин. Мозг разделен на специализированные области: кора для высших когнитивных функций, лимбическая система для эмоций и памяти, мозжечок для координации. Нейропластичность означает, что мозг может перестраиваться на протяжении всей жизни. Методы исследования варьируются от фМРТ (хорошее пространственное разрешение) до ЭЭГ (хорошее временное разрешение) и оптогенетики (точный причинный контроль). Понимание мозга, пожалуй, самая сложная проблема в науке: это единственный орган, который изучает сам себя.
