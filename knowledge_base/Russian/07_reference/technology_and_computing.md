# Технология и вычисления

## Что такое компьютер?

Компьютер — это электронное устройство, которое обрабатывает данные согласно набору инструкций, называемому программой. Современные компьютеры основаны на архитектуре фон Неймана, которая состоит из центрального процессора (CPU), памяти, накопителя и устройств ввода-вывода. CPU выполняет инструкции. RAM (оперативная память) временно хранит данные во время работы компьютера. Накопители, такие как SSD и жёсткие диски, хранят данные постоянно.

## Языки программирования

Язык программирования — это формальный язык, используемый для написания инструкций для компьютеров. Python — это высокоуровневый интерпретируемый язык программирования общего назначения, известный своим простым синтаксисом и читаемостью. Он широко используется в науке о данных, машинном обучении, веб-разработке и автоматизации. JavaScript — основной язык для веб-разработки, работающий в браузерах. Java — компилируемый объектно-ориентированный язык, широко используемый в корпоративном ПО и разработке под Android. C и C++ — низкоуровневые языки, дающие точный контроль над оборудованием, используемые в системном программировании, разработке игр и приложениях, критичных к производительности. Rust — современный системный язык программирования, ориентированный на безопасность и производительность.

## Как работает интернет

Интернет — это глобальная сеть взаимосвязанных компьютеров, взаимодействующих с помощью стандартизированных протоколов. Всемирная паутина (World Wide Web) — это система веб-сайтов и веб-страниц, доступных через интернет посредством браузеров. HTTP (HyperText Transfer Protocol) и HTTPS (защищённый HTTP) — протоколы, используемые для передачи веб-страниц. IP-адрес — это уникальный числовой адрес, присваиваемый каждому устройству в сети. DNS (Domain Name System) преобразует понятные человеку доменные имена (например, google.com) в IP-адреса. Маршрутизатор направляет сетевой трафик между устройствами и сетями.

## Сети и протоколы

TCP/IP — базовый набор протоколов интернета. IP (Internet Protocol) отвечает за адресацию и маршрутизацию пакетов между сетями, а TCP (Transmission Control Protocol) обеспечивает надёжную, упорядоченную доставку с повторной передачей и управлением потоком. UDP — это альтернатива без установления соединения, используемая, когда низкая задержка важнее гарантированной доставки (например, при потоковом вещании, играх или DNS-запросах). HTTP — это протокол прикладного уровня без сохранения состояния для обмена запросами и ответами между клиентами и серверами. HTTPS — это HTTP поверх TLS, добавляющий шифрование и защиту целостности. REST (Representational State Transfer) — это архитектурный стиль API, использующий ресурсы, стандартные HTTP-методы (GET, POST, PUT, PATCH, DELETE) и взаимодействия без сохранения состояния. WebSockets обеспечивают постоянные полнодуплексные соединения, позволяющие клиенту и серверу обмениваться сообщениями в реальном времени, что полезно для чатов, живых панелей мониторинга и совместных приложений.

## Искусственный интеллект

Искусственный интеллект (ИИ) — это имитация человеческого интеллекта машинами, в частности компьютерными системами. Машинное обучение — это подраздел ИИ, в котором системы учатся на данных, чтобы делать прогнозы или принимать решения без явного программирования. Глубокое обучение — это подраздел машинного обучения, использующий нейронные сети со множеством слоёв. Нейронные сети — это вычислительные модели, отдалённо вдохновлённые структурой биологического мозга. Большие языковые модели (LLM) — это модели ИИ, обученные на огромных объёмах текста для генерации и понимания естественного языка.

## Алгоритмы и структуры данных

Алгоритм — это пошаговая процедура решения задачи. Структуры данных — это способы организации данных в компьютере так, чтобы к ним можно было эффективно обращаться и изменять их. К распространённым структурам данных относятся массивы, связанные списки, стеки, очереди, деревья, графы и хеш-таблицы. Алгоритмы сортировки упорядочивают элементы в заданном порядке; распространённые примеры — сортировка пузырьком, сортировка слиянием и быстрая сортировка. Бинарный поиск — это эффективный алгоритм поиска элемента в отсортированном списке путём многократного деления диапазона поиска пополам.

## Базы данных

База данных — это организованная коллекция структурированных данных, хранящихся в электронном виде. Реляционная база данных хранит данные в таблицах со строками и столбцами. SQL (Structured Query Language) — стандартный язык управления реляционными базами данных и запросов к ним. NoSQL-базы данных хранят данные в форматах, отличных от табличных отношений, таких как документы, пары ключ-значение или графы. К распространённым системам баз данных относятся PostgreSQL, MySQL, SQLite, MongoDB и Redis. Индекс в базе данных ускоряет извлечение данных за счёт дополнительного места для хранения.

## Основы проектирования систем

Проектирование систем сосредоточено на создании надёжных, масштабируемых и удобных в сопровождении программных систем. Балансировка нагрузки распределяет трафик между несколькими серверами для повышения доступности и снижения задержки. Горизонтальное масштабирование добавляет больше машин; вертикальное масштабирование добавляет больше ресурсов одной машине. Кеширование хранит часто запрашиваемые данные в быстром хранилище (например, Redis, Memcached или кэши на границе сети CDN), чтобы снизить нагрузку на базу данных и время отклика. Базы данных в масштабе требуют репликации, партиционирования (шардинга), стратегий резервного копирования и тщательного баланса согласованности. Микросервисы разбивают крупные приложения на более мелкие независимо развёртываемые сервисы, тогда как монолиты сохраняют большую часть логики в одном развёртываемом модуле; оба подхода связаны с компромиссами в сложности, скорости развёртывания, отладке и автономности команд.

## Операционные системы

Операционная система (ОС) — это программное обеспечение, управляющее оборудованием компьютера и предоставляющее сервисы программам. К распространённым операционным системам относятся Windows, macOS и Linux. Linux — это ядро ОС с открытым исходным кодом, используемое на серверах, во встраиваемых системах и в Android. ОС управляет процессами (запущенными программами), памятью, файловыми системами и устройствами ввода-вывода. Процесс — это выполняющийся экземпляр программы. Поток (thread) — наименьшая единица выполнения внутри процесса.

## Управление версиями

Системы управления версиями отслеживают изменения кода с течением времени, позволяя разработчикам сотрудничать и возвращаться к предыдущим состояниям. Git — самая широко используемая система управления версиями. Репозиторий (repo) — это набор файлов и их история. Коммит — это сохранённый снимок изменений. Ветка (branch) — независимая линия разработки. Pull request — это предложение объединить изменения из одной ветки в другую.

## Практики разработки программного обеспечения

Объектно-ориентированное программирование (ООП) организует код в объекты, объединяющие данные и поведение. Ключевые принципы ООП включают инкапсуляцию, наследование, полиморфизм и абстракцию. Разработка через тестирование (TDD) — это практика написания тестов до написания кода. Agile — набор методологий разработки ПО, делающих упор на итеративную разработку, сотрудничество и адаптивность. DevOps объединяет разработку ПО и ИТ-операции для сокращения жизненного цикла разработки. API (Application Programming Interfaces) позволяют разным программным системам взаимодействовать друг с другом.

## Основы облачных технологий и DevOps

Облачные вычисления предоставляют инфраструктуру и управляемые сервисы по требованию через интернет. Три крупнейших публичных облачных провайдера — это AWS (Amazon Web Services), Microsoft Azure и Google Cloud Platform (GCP). Распространённые модели обслуживания — IaaS (инфраструктура), PaaS (платформа) и SaaS (программное обеспечение). К основным облачным строительным блокам относятся вычислительные инстансы/контейнеры, объектное хранилище, управляемые базы данных, сети и IAM (управление идентификацией и доступом). CI/CD (непрерывная интеграция и непрерывная доставка/развёртывание) автоматизирует конвейеры сборки, тестирования и выпуска, позволяя коду безопасно переходить от коммита к продакшену. Docker упаковывает приложения и зависимости в переносимые контейнеры; в продакшене такие контейнеры обычно развёртываются с помощью оркестраторов (например, Kubernetes), бессерверных платформ или управляемых контейнерных сервисов.

## Форматы данных и инструментарий

JSON (JavaScript Object Notation) — это лёгкий текстовый формат, построенный из объектов (пар ключ-значение), массивов, строк, чисел, булевых значений и null; он широко используется в API. YAML — это удобный для человека формат конфигурации, поддерживающий вложенные структуры и комментарии, часто используемый в CI/CD и определениях инфраструктуры. CSV (Comma-Separated Values) хранит табличные данные в виде строк текста, разделённого запятыми, и распространён в конвейерах импорта/экспорта данных. XML (eXtensible Markup Language) — это тегированный структурированный формат, используемый в устаревших системах, конфигурациях и документарных рабочих процессах. Разработчики обычно проверяют и преобразуют эти форматы с помощью линтеров, валидаторов схем (например, JSON Schema), инструментов запросов (`jq`, XPath) и библиотек разбора на своём языке программирования.

## Регулярные выражения (Regex)

Регулярное выражение — это язык шаблонов, используемый для поиска, сопоставления, извлечения и преобразования текста. Основные концепции регулярных выражений включают литералы (`cat`), классы символов (`[a-z]`, `\d`), квантификаторы (`*`, `+`, `?`, `{n,m}`), якоря (`^`, `$`), группы (`(...)`), альтернативы (`a|b`) и экранирование специальных символов. Регулярные выражения широко используются для валидации ввода, разбора логов, извлечения текста и автоматизации поиска/замены. Разные движки (PCRE, JavaScript, Python `re`, RE2) имеют разные наборы возможностей, поэтому поведение может отличаться между инструментами. Регулярные выражения мощны, но их бывает трудно читать; сложные шаблоны следует тестировать и документировать, чтобы избежать ошибок.

## Кибербезопасность

Кибербезопасность — это практика защиты компьютерных систем, сетей и данных от цифровых атак. К распространённым угрозам относятся вредоносное ПО (malware), фишинг (мошенническая коммуникация, предназначенная для кражи информации), программы-вымогатели (ransomware — вредоносное ПО, шифрующее данные и требующее выкуп) и атаки типа «отказ в обслуживании». Шифрование преобразует данные в нечитаемую форму, которую можно расшифровать только с помощью ключа. HTTPS использует TLS (Transport Layer Security) для шифрования веб-трафика. Надёжные уникальные пароли и двухфакторная аутентификация — фундаментальные практики безопасности.

## Концепции безопасности для разработчиков

OAuth 2.0 — это фреймворк авторизации, позволяющий пользователям предоставлять приложению ограниченный доступ без прямой передачи учётных данных. OpenID Connect (OIDC) — это уровень идентификации, построенный поверх OAuth 2.0, для аутентификации. JWT (JSON Web Token) — компактный формат токена, содержащий утверждения (claims), часто используемый для аутентификации без сохранения состояния, но он должен быть правильно подписан и строго проверен (подпись, срок действия, издатель, аудитория). TLS защищает данные при передаче, обеспечивая шифрование, целостность и аутентификацию сервера с помощью сертификатов. OWASP Top 10 — широко используемый список распространённых рисков безопасности веб-приложений, включая нарушенный контроль доступа, криптографические сбои, инъекции, небезопасный дизайн, неправильную конфигурацию безопасности, уязвимые компоненты и недостаточное логирование/мониторинг. Безопасная разработка требует эшелонированной защиты: валидации ввода, кодирования вывода, минимальных привилегий, управления секретами, обновления зависимостей и регулярного тестирования безопасности.
