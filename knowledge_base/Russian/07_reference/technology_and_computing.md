# Технологии и вычисления

## Что такое компьютер?

Компьютер — это электронное устройство, которое обрабатывает данные в соответствии с набором инструкций, называемым программой. Современные компьютеры основаны на архитектуре фон Неймана, которая включает центральный процессор (CPU), память, хранилище и устройства ввода-вывода. CPU выполняет инструкции. RAM (random access memory) временно хранит данные во время работы компьютера. Устройства хранения, такие как SSD и жёсткие диски, сохраняют данные постоянно.

## Языки программирования

Язык программирования — это формальный язык, используемый для записи инструкций для компьютеров. Python — высокоуровневый интерпретируемый язык общего назначения, известный простым синтаксисом и хорошей читаемостью. Он широко применяется в data science, machine learning, web development и автоматизации. JavaScript — основной язык web development и выполняется в браузерах. Java — компилируемый объектно-ориентированный язык, широко используемый в корпоративном ПО и разработке под Android. C и C++ — более низкоуровневые языки, обеспечивающие тонкий контроль над оборудованием; их применяют в системном программировании, разработке игр и задачах, критичных к производительности. Rust — современный системный язык программирования, ориентированный на безопасность и производительность.

## Как работает интернет

Интернет — это глобальная сеть взаимосвязанных компьютеров, которые обмениваются данными по стандартизированным протоколам. World Wide Web — это система сайтов и веб-страниц, доступ к которым осуществляется через интернет через браузеры. HTTP (HyperText Transfer Protocol) и HTTPS (secure HTTP) — протоколы, используемые для передачи веб-страниц. IP-адрес — это уникальный числовой адрес, присваиваемый каждому устройству в сети. DNS (Domain Name System) переводит понятные человеку доменные имена (например, google.com) в IP-адреса. Маршрутизатор направляет сетевой трафик между устройствами и сетями.

## Сети и протоколы

TCP/IP — базовый стек протоколов интернета. IP (Internet Protocol) отвечает за адресацию и маршрутизацию пакетов между сетями, а TCP (Transmission Control Protocol) обеспечивает надёжную и упорядоченную доставку с повторной передачей и управлением потоком. UDP — это альтернативный протокол без установления соединения, используемый там, где низкая задержка важнее гарантированной доставки (например, в streaming, gaming или DNS-запросах). HTTP — протокол прикладного уровня без сохранения состояния для обмена по модели request/response между клиентами и серверами. HTTPS — это HTTP поверх TLS, добавляющий шифрование и защиту целостности. REST (Representational State Transfer) — архитектурный стиль API, использующий ресурсы, стандартные HTTP-глаголы (GET, POST, PUT, PATCH, DELETE) и взаимодействия без сохранения состояния. WebSockets обеспечивают постоянные полнодуплексные соединения, благодаря которым клиент и сервер могут отправлять сообщения в реальном времени; это полезно для чатов, live dashboards и совместных приложений.

## Искусственный интеллект

Искусственный интеллект (AI) — это моделирование человеческого интеллекта машинами, прежде всего компьютерными системами. Machine learning — подраздел AI, в котором системы учатся на данных делать прогнозы или принимать решения без явного программирования. Deep learning — подраздел machine learning, использующий нейронные сети со многими слоями. Нейронные сети — вычислительные модели, в общих чертах вдохновлённые устройством биологического мозга. Large language models (LLMs) — это AI-модели, обученные на огромных объёмах текста для генерации и понимания естественного языка.

## Алгоритмы и структуры данных

Алгоритм — это пошаговая процедура решения задачи. Структуры данных — это способы организации данных в компьютере, позволяющие эффективно получать к ним доступ и изменять их. К распространённым структурам данных относятся массивы, связанные списки, стеки, очереди, деревья, графы и hash tables. Алгоритмы сортировки располагают элементы в заданном порядке; типичные примеры — bubble sort, merge sort и quicksort. Binary search — эффективный алгоритм поиска элемента в отсортированном списке путём последовательного деления диапазона поиска пополам.

## Базы данных

База данных — это организованная коллекция структурированных данных, хранящихся в электронном виде. Реляционная база данных хранит данные в таблицах со строками и столбцами. SQL (Structured Query Language) — стандартный язык для управления реляционными базами данных и выполнения запросов к ним. NoSQL-базы данных хранят данные в форматах, отличных от табличных отношений, например в виде документов, пар key-value или графов. К распространённым системам баз данных относятся PostgreSQL, MySQL, SQLite, MongoDB и Redis. Индекс в базе данных ускоряет извлечение данных ценой дополнительного места для хранения.

## Основы проектирования систем

Проектирование систем сосредоточено на создании надёжных, масштабируемых и поддерживаемых программных систем. Балансировка нагрузки распределяет трафик между несколькими серверами, чтобы повысить доступность и снизить задержку. Горизонтальное масштабирование добавляет новые машины; вертикальное — добавляет ресурсы одной машине. Кэширование сохраняет часто запрашиваемые данные в быстром хранилище (например, Redis, Memcached или edge-кэши CDN), чтобы уменьшить нагрузку на базу данных и сократить время ответа. Базы данных на больших масштабах требуют репликации, партиционирования (sharding), стратегий резервного копирования и аккуратного выбора компромиссов согласованности. Микросервисы делят крупные приложения на меньшие независимо развёртываемые сервисы, тогда как монолиты сохраняют большую часть логики в одном развёртываемом блоке; оба подхода связаны с компромиссами по сложности, скорости развёртывания, отладке и автономии команд.

## Операционные системы

Операционная система (OS) — это программное обеспечение, управляющее аппаратными ресурсами компьютера и предоставляющее сервисы программам. К распространённым операционным системам относятся Windows, macOS и Linux. Linux — это open-source ядро OS, используемое на серверах, во встраиваемых системах и в Android. OS управляет процессами (запущенными программами), памятью, файловыми системами и устройствами ввода-вывода. Процесс — это работающий экземпляр программы. Поток — наименьшая единица выполнения внутри процесса.

## Контроль версий

Системы контроля версий отслеживают изменения в коде со временем, позволяя разработчикам совместно работать и возвращаться к предыдущим состояниям. Git — наиболее широко используемая система контроля версий. Repository (repo) — это набор файлов и история их изменений. Commit — сохранённый снимок изменений. Branch — независимая линия разработки. Pull request — предложение объединить изменения из одной ветки в другую.

## Практики разработки ПО

Объектно-ориентированное программирование (OOP) организует код в объекты, объединяющие данные и поведение. Ключевые принципы OOP включают инкапсуляцию, наследование, полиморфизм и абстракцию. Test-driven development (TDD) — практика, при которой тесты пишутся до написания кода. Agile — набор методологий разработки ПО, делающих акцент на итеративной разработке, сотрудничестве и адаптивности. DevOps объединяет разработку ПО и IT-операции, чтобы сократить жизненный цикл разработки. API (Application Programming Interfaces) позволяют разным программным системам взаимодействовать друг с другом.

## Основы облака и DevOps

Облачные вычисления предоставляют инфраструктуру и управляемые сервисы по запросу через интернет. Три крупнейших публичных облачных провайдера — AWS (Amazon Web Services), Microsoft Azure и Google Cloud Platform (GCP). Распространённые модели сервисов — IaaS (infrastructure), PaaS (platform) и SaaS (software). Ключевые строительные блоки облака включают вычислительные инстансы/контейнеры, объектное хранилище, управляемые базы данных, сети и IAM (Identity and Access Management). CI/CD (Continuous Integration and Continuous Delivery/Deployment) автоматизирует конвейеры сборки, тестирования и релизов, чтобы код мог безопасно переходить от commit к production. Docker упаковывает приложения и зависимости в переносимые контейнеры; в production такие контейнеры обычно разворачивают через оркестраторы (например, Kubernetes), serverless-платформы или управляемые контейнерные сервисы.

## Форматы данных и инструменты

JSON (JavaScript Object Notation) — это лёгкий текстовый формат, построенный из объектов (пар key/value), массивов, строк, чисел, логических значений и null; он широко используется в API. YAML — удобный для человека формат конфигурации, поддерживающий вложенные структуры и комментарии; он часто применяется в CI/CD и описаниях инфраструктуры. CSV (Comma-Separated Values) хранит табличные данные в виде строк разделённого текста и часто используется в конвейерах импорта/экспорта данных. XML (eXtensible Markup Language) — структурированный формат на основе тегов, применяемый в унаследованных системах, конфигурации и документообороте. Разработчики обычно проверяют и преобразуют эти форматы с помощью линтеров, валидаторов схем (например, JSON Schema), инструментов запросов (`jq`, XPath) и библиотек парсинга на своём языке программирования.

## Регулярные выражения (Regex)

Регулярное выражение — это язык шаблонов, используемый для поиска, сопоставления, извлечения и преобразования текста. Базовые концепции regex включают литералы (`cat`), классы символов (`[a-z]`, `\d`), квантификаторы (`*`, `+`, `?`, `{n,m}`), якоря (`^`, `$`), группы (`(...)`), альтернативы (`a|b`) и экранирование специальных символов. Регулярные выражения активно используются для проверки ввода, разбора логов, извлечения текста и автоматизации find/replace. Разные движки (PCRE, JavaScript, Python `re`, RE2) поддерживают разные возможности, поэтому поведение может различаться в зависимости от инструмента. Регулярные выражения очень мощны, но могут становиться трудночитаемыми; сложные шаблоны следует тестировать и документировать, чтобы избегать ошибок.

## Кибербезопасность

Кибербезопасность — это практика защиты компьютерных систем, сетей и данных от цифровых атак. К распространённым угрозам относятся malware (вредоносное ПО), phishing (мошеннические сообщения, предназначенные для кражи информации), ransomware (вредоносное ПО, шифрующее данные и требующее выкуп) и атаки типа denial-of-service. Шифрование преобразует данные в нечитаемую форму, которую можно расшифровать только с помощью ключа. HTTPS использует TLS (Transport Layer Security) для шифрования веб-трафика. Надёжные уникальные пароли и двухфакторная аутентификация — базовые практики безопасности.

## Концепции безопасности для разработчиков

OAuth 2.0 — это фреймворк авторизации, позволяющий пользователям предоставлять приложению ограниченный доступ без прямой передачи учётных данных. OpenID Connect (OIDC) — слой идентификации поверх OAuth 2.0 для аутентификации. JWT (JSON Web Token) — компактный формат токена, содержащего claims; его часто используют для аутентификации без сохранения состояния, но он должен быть корректно подписан и строго проверен (signature, expiration, issuer, audience). TLS защищает данные при передаче, обеспечивая шифрование, целостность и аутентификацию сервера с помощью сертификатов. OWASP Top 10 — широко используемый список распространённых рисков безопасности веб-приложений, включая broken access control, cryptographic failures, injection, insecure design, security misconfiguration, vulnerable components и insufficient logging/monitoring. Безопасная разработка требует многоуровневой защиты (defense-in-depth): валидации ввода, кодирования вывода, принципа наименьших привилегий, управления секретами, своевременного обновления зависимостей и регулярного тестирования безопасности.
