#PHP
PHP (Hypertext Preprocessor) é uma linguagem de script do lado do servidor criada por Rasmus Lerdorf em 1994 e lançada pela primeira vez em 1995. Originalmente projetado para gerar páginas web dinâmicas, o PHP evoluiu para uma linguagem de uso geral com todos os recursos. Ele alimenta aproximadamente 75% de todos os sites com uma linguagem de servidor conhecida, incluindo WordPress, Facebook (originalmente), Wikipedia, Slack e milhões de outros sites.
O PHP moderno (8.x) é uma linguagem muito diferente do PHP do início dos anos 2000. Agora ele possui propriedades digitadas, expressões de correspondência, enumerações, fibras, classes somente leitura e um sistema de tipos robusto. Apesar de sua reputação entre os desenvolvedores (muitas vezes criticado por inconsistências), o PHP é prático, amplamente implantado e continua a melhorar.
---

## Por que o PHP é importante
- **Dominância na Web**: executa aproximadamente 75% dos sites. Somente o WordPress alimenta 43% da web.
- **Baixa barreira de entrada**: Implante enviando arquivos para qualquer hospedagem compartilhada. Sem compilação, sem etapa de construção.
- **Ecossistema maduro**: Composer (gerenciador de pacotes), Laravel, Symfony — ferramentas maduras e testadas em batalha.
- **Prático**: crie um site dinâmico em minutos com configuração mínima.
- **Melhoria contínua**: o PHP 8.x trouxe melhorias significativas na qualidade de vida.
- **Mercado freelancer**: Enorme demanda por desenvolvedores de WordPress, Laravel e e-commerce (WooCommerce, Magento).
## As compensações
| Limitação | Detalhes | Solução alternativa típica |
|-------|---------|-------------------|
| **Nomenclatura inconsistente** | `strpos`vs`str_replace`,`array_key_exists`vs`in_array`— nenhuma convenção consistente | Aprenda as inconsistências; usar o preenchimento automático do IDE |
| **Bagagem histórica** | Recursos e padrões legados do PHP 5 e anteriores | Use PHP moderno (8.2+); siga os padrões PSR |
| **Desempenho** | Mais lento que Go, Rust ou Java para tarefas não relacionadas à web | Usar OPcache; considere Swoole para assíncrono; usar PHP-FPM |
| **Não é ideal para ambientes não web** | CLI, desktop, dispositivos móveis, ciência de dados – não os pontos fortes do PHP | Use Python, Go ou outras linguagens para trabalhos fora da web |
| **Reputação de segurança** | O código PHP legado tem muitos problemas de segurança | Utilize frameworks modernos; siga as melhores práticas de segurança |

## Fundamentos de sintaxe
### Estrutura Básica
```php
<?php
declare(strict_types=1);

// Variables (always prefixed with $)
$name = "Alice";
$age = 30;
$score = 9.5;
$active = true;
$items = [1, 2, 3];

// String interpolation
echo "Hello, $name! You are $age years old.";
echo "Score: {$score}";

// Arrays (both indexed and associative)
$fruits = ["apple", "banana", "cherry"];
$user = [
    "name" => "Alice",
    "age" => 30,
    "email" => "alice@example.com",
];

echo $user["name"];  // "Alice"
```

### Funções e tipos
```php
// Typed functions (PHP 7+)
function add(int $a, int $b): int {
    return $a + $b;
}

function greet(string $name, string $greeting = "Hello"): string {
    return "$greeting, $name!";
}

// Nullable types
function findUser(int $id): ?array {
    return $id > 0 ? ["id" => $id, "name" => "Alice"] : null;
}

// Union types (PHP 8.0+)
function formatId(int|string $id): string {
    return "ID: $id";
}

// Named arguments (PHP 8.0+)
function createUser(string $name, int $age, string $role = "viewer"): array {
    return compact("name", "age", "role");
}

$user = createUser(name: "Alice", age: 30, role: "admin");

// Spread operator
$defaults = ["timeout" => 30, "retries" => 3];
$config = [...$defaults, "timeout" => 60];  // ["timeout" => 60, "retries" => 3]
```

### Classes e OOP
```php
// Class with typed properties
class Animal {
    public function __construct(
        protected readonly string $name,
    ) {}

    public function speak(): string {
        return "{$this->name} makes a sound";
    }

    public function getName(): string {
        return $this->name;
    }
}

class Dog extends Animal {
    public function speak(): string {
        return "{$this->name} says woof";
    }
}

// Interface
interface Serializable {
    public function toJson(): string;
}

// Enum (PHP 8.1+)
enum Status: string {
    case Active = 'active';
    case Inactive = 'inactive';
    case Pending = 'pending';

    public function label(): string {
        return match($this) {
            Status::Active => 'Active',
            Status::Inactive => 'Inactive',
            Status::Pending => 'Pending Review',
        };
    }
}

$status = Status::Active;
echo $status->label();  // "Active"
```

### Corresponder expressão e fluxo de controle
```php
// Match expression (PHP 8.0+) — like switch but returns a value
$label = match($status) {
    'active' => 'Active User',
    'inactive' => 'Inactive User',
    'pending' => 'Pending Review',
    default => 'Unknown Status',

// Null coalescing
$name = $user['name'] ?? 'Guest';

// Nullsafe operator (PHP 8.0+)
$country = $user?->getAddress()?->getCountry()?->getName();

// Arrow functions (short closures)
$doubled = array_map(fn($n) => $n * 2, [1, 2, 3, 4, 5]);

// Named arguments + spread
```


### Fechamentos e funções de ordem superior
```php
// Closures with use (capture variables)
$multiplier = 3;
$multiply = fn($x) => $x * $multiplier;
echo $multiply(5);  // 15

// Returning closures
function makeGreeter(string $greeting): Closure {
    return fn(string $name) => "$greeting, $name!";
}

$hello = makeGreeter("Hello");
echo $hello("Alice");  // "Hello, Alice!"

// Array reduce with closures
$users = [
    ["name" => "Alice", "age" => 30],
    ["name" => "Bob", "age" => 25],
    ["name" => "Charlie", "age" => 35],
];

$totalAge = array_reduce($users, fn(int $sum, array $u) => $sum + $u["age"], 0);
$names = array_map(fn($u) => $u["name"], $users);
$adults = array_filter($users, fn($u) => $u["age"] >= 30);
```

### Fibras (PHP 8.1+) — Multitarefa Cooperativa
```php
// Fibers — low-level cooperative concurrency
$fiber = new Fiber(function (): void {

    echo "Step 3\n";

$fiber->start();              // Step 1
$resumed = $fiber->resume("hello");  // Step 2 with: hello
$fiber->resume("world");      // Step 3

```

### Características — Reutilização horizontal de código
```php
// Traits — reusable method collections (PHP's solution to single inheritance)
trait HasTimestamps {
    public function createdAt(): string {
        return $this->created_at->format("Y-m-d H:i:s");
    }

    public function updatedAt(): string {
        return $this->updated_at->format("Y-m-d H:i:s");
    }
}

trait HasUuid {
    public function generateUuid(): string {
        return sprintf(
            "%04x%04x-%04x-%04x-%04x-%04x%04x%04x",
            mt_rand(0, 0xffff), mt_rand(0, 0xffff),
            mt_rand(0, 0xffff),
            mt_rand(0, 0x0fff) | 0x4000,
            mt_rand(0, 0x3fff) | 0x8000,
            mt_rand(0, 0xffff), mt_rand(0, 0xffff), mt_rand(0, 0xffff)
        );
    }
}

class Post {
    use HasTimestamps, HasUuid;

    public DateTime $created_at;
    public DateTime $updated_at;
    public string $id;

    public function __construct() {
        $this->id = $this->generateUuid();
        $this->created_at = new DateTime();
        $this->updated_at = new DateTime();
    }
}

$post = new Post();
echo $post->id;            // UUID string
echo $post->createdAt();   // "2024-01-15 14:30:00"
```

### Swoole — Simultaneidade baseada em corrotinas
```php
// Swoole enables Go-like concurrency in PHP
use Swoole\Coroutine;
use Swoole\Coroutine\Http\Client;

Coroutine\run(function () {
    // Concurrent HTTP requests
    $results = [];

    Coroutine::create(function () use (&$results) {
        $client = new Client("api.example.com", 443, true);
        $client->get("/users");
        $results["users"] = $client->body;
    });

    Coroutine::create(function () use (&$results) {
        $client = new Client("api.example.com", 443, true);
        $client->get("/posts");
        $results["posts"] = $client->body;
    });
});
```

```php
declare(strict_types=1);

namespace Tests\Unit;

use PHPUnit\Framework\TestCase;
use App\Models\User;
use App\Services\UserService;

class UserServiceTest extends TestCase
{
    private UserService $service;

    protected function setUp(): void
    {
        $this->service = new UserService();
    }

    public function test_creates_user_with_valid_data(): void
    {
        $user = $this->service->create("Alice", "alice@example.com");

    }
}
```

```php
// myext.c (simplified)
PHP_FUNCTION(myext_fast_hash) {
    char *data;
    size_t data_len;
    if (zend_parse_parameters(ZEND_NUM_ARGS(), "s", &data, &data_len) == FAILURE) {
        return;
    }
    unsigned long hash = 5381;
    for (size_t i = 0; i < data_len; i++) {
        hash = ((hash << 5) + hash) + data[i];
    }
    RETURN_LONG(hash);
}
```

## Padrões de Projeto
### Padrão de repositório
```php
interface UserRepositoryInterface {
    public function findById(int $id): ?User;
    public function findAll(): array;
    public function save(User $user): User;
}

class EloquentUserRepository implements UserRepositoryInterface {
    public function findById(int $id): ?User { return User::find($id); }
    public function findAll(): array { return User::all()->toArray(); }
    public function save(User $user): User { $user->save(); return $user; }
}

class UserController {
    public function __construct(private UserRepositoryInterface $repo) {}
    public function show(int $id): JsonResponse {
        return response()->json($this->repo->findById($id));
    }
}
```

### Padrão de Middleware
```php
class AuthenticationMiddleware {
    public function handle(ServerRequestInterface $request, callable $next): ResponseInterface {
        $token = $request->getHeaderLine("Authorization");
        if (empty($token) || !$this->validateToken($token)) {
            return new Response(401, body: "Unauthorized");
        }
        return $next($request);
    }
}
```

### Contêiner de serviço/injeção de dependência

```php
class OrderService {
    public function __construct(
        private PaymentGateway $payment,

        private Mailer $mailer,
    ) {}

        $order = $this->orders->create($request->toArray());

        return $order;
    }
}
```

## Resumo
PHP é o carro-chefe pragmático da web. Ele alimenta a maioria dos sites, tem um ecossistema enorme e o PHP moderno (8.x) é uma linguagem bem projetada com tipos, enums e sintaxe limpa adequados. Não é a linguagem mais elegante e não é adequada para todos os domínios – mas para desenvolvimento web, especialmente gerenciamento de conteúdo, comércio eletrônico e freelancer, PHP continua sendo uma escolha prática e amplamente utilizada.
