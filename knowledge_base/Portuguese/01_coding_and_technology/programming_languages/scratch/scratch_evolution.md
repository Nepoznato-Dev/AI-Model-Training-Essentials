# Scratch – Histórico de versões e evolução
## Linha do tempo
| Versão | Ano | Tema principal |
|--------|------|-----------|
| Pré-arranhão | 2003 | Equipe Scratch se forma no MIT Media Lab |
| Raspe 1.0 | 2007 | **Lançamento inicial** — programação visual para crianças |
| Raspe 1.4 | 2009 | Gráficos melhorados, mais blocos |
| Raspe 2.0 | 2013 | **Principal**: Editor baseado na Web, variáveis ​​de nuvem, mochila |
| Raspe 3.0 | 2019 | **Principal**: Reescrita completa (HTML5/JS), extensões, caneta |
| Raspe 3.x | 2019–25 | Detecção de vídeo, conversão de texto em fala, tradução, micro:bit |
| Raspe Jr. | 2014 | Versão simplificada para crianças mais novas (5-7) |
| Área de Trabalho Scratch | 2020 | Editor offline (baseado em elétrons) |
## Marcos importantes
### Origens (2003–2006)
- **2003**: O grupo Lifelong Kindergarten do MIT Media Lab inicia o desenvolvimento do Scratch
- Liderado por Mitchel Resnick
- **Objetivo**: Ensinar programação para crianças por meio de blocos visuais
- Inspirado em: Logotipo (Seymour Papert), Logotipo Lego, Squeak Etoys
- Nome: "Scratch" — de DJ scratching (mistura de mídia)
### Raspadinha 1.0 (2007)
- **2007**: Primeiro lançamento público
- Programação de blocos de arrastar e soltar
- Projetos baseados em Sprite (personagens, animações)
- Som, gráficos, animação
- Squeak integrado (Smalltalk)
- **Alvo**: idades entre 8 e 16 anos, mas adotado de forma muito mais ampla
### Raspadinha 1.4 (2009)
- Melhor renderização gráfica
- Mais bibliotecas de sprites
- Melhor suporte de som
- Última versão construída no Squeak
### Raspadinha 2.0 (2013)
- **Editor completo baseado na web** — roda no navegador
- Variáveis de nuvem — compartilhe dados entre projetos
- Mochila — compartilhe sprites/scripts entre projetos
- Blocos personalizados (como funções)
- Integrado ActionScript 3 (Flash)
- Recursos da comunidade: remixar, compartilhar, comentar
### Raspadinha 3.0 (2019)
- **Reescrita completa** — HTML5/JavaScript (sem Flash)
- Funciona em tablets, telefones, Chromebooks
- **Extensões**:
  - Caneta (desenho)
  - Detecção de vídeo (câmera)
  - Texto para fala
  - Traduzir (Google Tradutor)
  -micro:bit (hardware)
  - LEGO Mindstorms EV3
  - Nós fazemos 2.0
- Melhorias no editor de som
- Novo editor de pintura (vetor + bitmap)
- Mochila, variáveis de nuvem retidas
### Scratch Desktop e além (2020-presente)
- **2020**: Scratch Desktop — editor offline (baseado em Electron)
- Desenvolvimento contínuo de extensões
- Extensões AI/ML (criadas pela comunidade)
- Integração com computação física (micro:bit, Arduino)
## Evolução das categorias de blocos
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Conceitos de programação ensinados
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Princípios-chave de design
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Impacto e adoção
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
