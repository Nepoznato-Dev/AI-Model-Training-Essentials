# Prolog – Padrões Idiomáticos e Melhores Práticas
Este guia cobre padrões idiomáticos para escrever código Prolog limpo e idiomático.
---

## Correspondência de padrões
```prolog
% ✅ Head matching for clarity
factorial(0, 1).
factorial(N, F) :-
    N > 0,
    N1 is N - 1,
    factorial(N1, F1),
    F is N * F1.

% ✅ List patterns
my_length([], 0).
my_length([_|T], N) :-
    my_length(T, N1),
    N is N1 + 1.

% ✅ Guard clauses
classify(N, positive) :- N > 0.
classify(0, zero).
classify(N, negative) :- N < 0.
```

---

## Cortes e Determinismo
```prolog
% ✅ Green cut (remove unnecessary choicepoints)
max(X, Y, X) :- X >= Y, !.
max(_, Y, Y).

% ✅ Avoid red cuts (changing semantics)
% ✅ Use -> (if-then-else) instead
classify(N) ->
    ( N > 0 -> positive
    ; N =:= 0 -> zero
    ; negative
    ).
```

## Resumo
As expressões idiomáticas do Prolog enfatizam: correspondência de padrões em cabeças, recursão de cauda com acumuladores, cortes verdes para eficiência e estilo declarativo. Siga as convenções de estilo Prolog. Prolog valoriza a pureza lógica – “a relação é o programa”.
