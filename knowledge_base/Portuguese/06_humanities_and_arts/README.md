# Humanidades e Artes
Uma coleção estruturada de documentos de referência que abrangem história, artes, linguagem, filosofia, psicologia e religião — as disciplinas centrais das humanidades que fornecem contexto para a compreensão da civilização humana, da expressão criativa e do pensamento crítico.
