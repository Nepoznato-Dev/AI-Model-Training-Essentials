# Dicionário de Inglês – Definições de Palavras Comuns
Uma lista de referência de palavras em inglês usadas com frequência e seus significados,
cobrindo vocabulário cotidiano, termos acadêmicos e palavras comumente encontradas
em perguntas e discussões.
---

## Um
**abandonar** — deixar para trás permanentemente; desistir de um objetivo ou lugar.
**habilidade** — o poder ou habilidade para fazer algo.
**abstrato** — existindo como um conceito e não como uma coisa concreta; um resumo de um documento.
**preciso** — correto e preciso; livre de erros.
**alcançar** — alcançar com sucesso uma meta através do esforço.
**reconhecer** — aceitar ou admitir a verdade de algo; para mostrar reconhecimento.
**adquirir** — obter ou ganhar algo, geralmente por meio de esforço ou compra.
**adaptar** — para se ajustar a novas condições ou requisitos.
**adequado** — satisfatório; apenas o suficiente para um propósito.
**adjacente** — próximo ou adjacente a outra coisa.
**ajustar** — para fazer pequenas alterações para melhorar o ajuste ou a função.
**avançar** — avançar; progresso; também, à frente do tempo atual.
**vantagem** — uma condição que dá uma posição favorável sobre outras.
**adverso** — desfavorável; prejudicial.
**afetar** — causar impacto em algo (verbo); emoção (substantivo, formal).
**agregado** — um todo formado pela combinação de vários elementos.
**algoritmo** — um conjunto de regras ou etapas para resolver um problema ou tarefa.
**alocar** — para atribuir recursos para uma finalidade específica.
**alter** — para mudar algo, geralmente parcialmente.
**ambíguo** — pouco claro; pode ser interpretado de mais de uma maneira.
**analisar** — examinar detalhadamente para compreender ou explicar.
**anotar** — para adicionar notas explicativas a um texto ou diagrama.
**antecipar** — esperar ou preparar-se para algo antes que aconteça.
**aparente** — claramente visível ou compreendido; parecendo ser verdade.
**abordagem** — uma forma de lidar com algo; chegar perto.
**aproximado** — quase correto; não exato.
**avaliar** — para avaliar ou julgar a qualidade, valor ou natureza de algo.
**atribuir** — para atribuir uma tarefa ou função a alguém; para alocar.
**supor** — aceitar algo como verdadeiro sem provas.
**atributo** — uma qualidade ou recurso; creditar algo a uma causa (verbo).
**automatizar** — para fazer um processo operar automaticamente sem intervenção humana.
##B
**benefício** — uma vantagem ou resultado positivo.
**preconceito** — uma preferência injusta a favor ou contra algo; erro sistemático.
**breve** — curto em tempo ou duração; um resumo ou instruções.
##C
**calcular** — para determinar um valor usando matemática.
**capaz** — ter a habilidade ou qualidades necessárias para alguma coisa.
**capacidade** — a quantidade máxima que algo pode reter ou fazer.
**categorizar** — para colocar em grupos com base em características compartilhadas.
**esclarecer** — para tornar algo mais fácil de entender.
**classificar** — para organizar em categorias ou grupos.
**coerente** — lógico e consistente; fácil de entender.
**colaborar** — trabalhar junto com outras pessoas em direção a um objetivo comum.
**compilar** — para coletar e organizar informações; para converter o código-fonte em código executável.
**complexo** — composto por muitas partes interligadas; não é simples.
**componente** — uma parte ou elemento de um todo maior.
**compreender** — para compreender completamente.
**compute** — para calcular ou processar dados.
**conceito** — uma ideia abstrata ou noção geral.
**concluir** — para tomar uma decisão ou terminar algo.
**condição** — um requisito; um estado de ser; circunstâncias.
**configurar** — para organizar ou configurar um sistema de uma maneira específica.
**confirmar** — para estabelecer a verdade ou exatidão de algo.
**conflito** — um desacordo sério; um confronto entre forças opostas.
**consistente** — comportando-se sempre da mesma maneira; não contraditório.
**contexto** — as circunstâncias que cercam algo; informações básicas.
**contraste** — para comparar para mostrar diferenças.
**converter** — para mudar de uma forma, unidade ou uso para outro.
**coordenar** — para organizar diferentes elementos para trabalharem juntos.
**critérios** — padrões pelos quais algo é julgado (plural de critério).
##D
**dados** — fatos e estatísticas coletados para análise.
**debug** — para encontrar e corrigir erros no código do computador.
**definir** — para dar o significado de uma palavra ou descrever os limites de algo.
**demonstrar** — para mostrar como algo funciona ou é feito.
**implantar** — para colocar em uso; para instalar e executar software em um ambiente ativo.
**derivar** — para obter algo de uma fonte; chegar a uma conclusão através do raciocínio.
**determinar** — para descobrir ou estabelecer algo de forma conclusiva.
**desenvolver** — para construir, crescer ou fazer algo mais elaborado ao longo do tempo.
**diferente** — ser diferente; discordar.
**distinto** — claramente diferente e separado.
**distribuir** — para espalhar ou compartilhar entre vários locais ou pessoas.
**domínio** — uma área de conhecimento ou atividade; um endereço da web.
**duplicado** — uma cópia exata; copiar algo.
## E
**eficiente** — alcançando resultados com o mínimo de desperdício de tempo ou recursos.
**elemento** — um componente básico; uma das substâncias químicas da tabela periódica.
**incorporar** — para fixar firmemente dentro; para incorporar em uma estrutura maior.
**habilitar** — tornar possível; para ativar um recurso.
**melhorar** — para melhorar a qualidade ou o valor de algo.
**entidade** — uma coisa com existência distinta; um objeto em um sistema.
**enumerar** — para listar itens um por um; contar.
**ambiente** — entorno; na computação, o sistema e a configuração em que o software é executado.
**erro** — um erro; um desvio do comportamento correto.
**estimativa** — um cálculo aproximado; para julgar aproximadamente.
**avaliar** — para formar uma opinião após consideração cuidadosa.
**executar** — para executar um plano ou instrução; para executar um programa de computador.
**explícito** — claramente declarado e não deixando nada implícito.
**estender** — para tornar mais longo ou maior; para adicionar funcionalidade.
**extrair** — para retirar ou obter de uma fonte.
##F
**fator** — elemento que contribui para um resultado; para dividir em componentes (matemática).
**recurso** — um aspecto ou capacidade distintiva.
**filtro** — para remover elementos indesejados; um dispositivo ou função que seleciona itens.
**flexível** — capaz de se adaptar a diferentes condições.
**formato** — a organização ou layout dos dados; para preparar para uso.
**framework** — uma estrutura básica que fornece suporte para a construção de algo.
**função** — o propósito de algo; um bloco de código reutilizável (programação).
**fundamental** — formando a base ou alicerce; essencial.
##G
**gerar** — para produzir ou criar.
**global** — relativo ao mundo inteiro; aplicando-se a um sistema inteiro.
**diretriz** — uma regra ou recomendação geral.
##H
**hierarquia** — um sistema classificado por níveis de autoridade ou importância.
**hipótese** — uma explicação proposta que pode ser testada.
## EU
**identificar** — para reconhecer e nomear algo.
**implementar** — para colocar um plano ou sistema em prática.
**implícito** — implícito sem ser declarado diretamente.
**index** — um ponteiro para a localização dos dados; uma lista alfabética (substantivo); categorizar (verbo).
**inferir** — para chegar a uma conclusão a partir de evidências sem declaração explícita.
**initialise** — para definir uma variável ou sistema para um estado inicial.
**entrada** — dados fornecidos a um sistema; para inserir dados.
**integrar** — para combinar partes em um todo; para adicionar um recurso a um sistema existente.
**interface** — um ponto onde dois sistemas se encontram e interagem; um contrato de programação.
**interpretar** — para explicar o significado de algo; para executar o código linha por linha.
**iterar** — para repetir um processo, geralmente com alterações incrementais.
##J
**justificar** — para fundamentar uma decisão; para alinhar o texto ao longo de uma margem.
##K
**chave** — essencial; um valor usado para procurar dados; um segredo criptográfico.
## eu
**camada** — um nível em uma hierarquia; um componente empilhado sobre outros.
**legado** — herdado do passado; software antigo ainda em uso.
**limite** — um limite; o valor máximo ou mínimo permitido.
**linear** — dispostos em linha reta; aumento proporcional.
**link** — uma conexão entre duas coisas; um hiperlink.
**local** — relativo a uma área próxima; em computação, rodando na mesma máquina.
**lógica** — raciocínio de acordo com regras; o fluxo de controle em um programa.
##M
**manter** — para manter em boas condições; para continuar ao longo do tempo.
**manipular** — para manusear ou controlar, às vezes com habilidade; influenciar injustamente.
**mapa** — para associar chaves a valores (estrutura de dados); para mostrar relações espaciais.
**mesclar** — para combinar em um; para juntar ramificações de código.
**método** — uma maneira de fazer algo; uma função anexada a um objeto (OOP).
**migrar** — para mover dados ou sistemas de um ambiente para outro.
**modelo** — uma representação de algo; um sistema de IA treinado.
**modificar** — para alterar parcialmente.
**monitorar** — para observar e verificar ao longo do tempo; uma tela de exibição.
##N
**navegar** — para encontrar um caminho; para mover entre páginas ou telas.
**nó** — um ponto em uma rede ou estrutura em árvore.
**normalizar** — para dimensionar valores para um intervalo padrão; para reduzir a redundância em um banco de dados.
## Ó
**objetivo** — uma meta ou objetivo; não influenciado por sentimentos pessoais (adjetivo).
**obter** — para obter ou adquirir.
**otimizar** — para torná-lo o mais eficaz ou eficiente possível.
**saída** — dados produzidos por um sistema; o resultado de um cálculo.
**substituir** — para assumir o controle de uma configuração ou método existente.
##P
**parâmetro** — um valor passado para uma função; uma característica mensurável.
**parse** — para analisar texto em componentes; para interpretar dados estruturados.
**padrão** — um arranjo repetido; um modelo para resolver um problema comum.
**persistir** — continuar a existir; para salvar dados para que sobrevivam às reinicializações.
**pipeline** — uma série de estágios conectados onde a saída de um alimenta o próximo.
**preciso** — exato; preciso até aos mínimos detalhes.
**prever** — para dizer o que acontecerá antes que aconteça.
**priorizar** — para classificar as tarefas por importância e abordar as mais importantes primeiro.
**processo** — uma série de etapas; uma instância de programa em execução (verbo: manipular ou transformar).
**prompt** — uma dica ou instrução dada a um modelo ou usuário de IA.
**propriedade** — uma característica ou atributo; um valor pertencente a um objeto.
**protocolo** — um conjunto de regras para comunicação entre sistemas.
##Q
**consulta** — uma solicitação de informações de um banco de dados; uma pergunta.
**fila** — uma linha de itens aguardando para serem processados ​​(primeiro a entrar, primeiro a sair).
##R
**recursivo** — uma função ou processo que chama ou se refere a si mesmo.
**redundante** — desnecessário porque duplica a funcionalidade existente; extra para backup.
**refatorar** — para reestruturar o código existente sem alterar seu comportamento externo.
**referência** — um ponteiro para um valor; uma fonte citada para obter informações.
**relevante** — intimamente ligado ao tópico em questão.
**render** — para produzir saída (gráficos, texto ou HTML).
**representar** — representar ou descrever algo.
**requisito** — uma condição ou recurso necessário.
**resolver** — para encontrar uma solução; para determinar um valor (por exemplo, um nome DNS).
**recuperar** — para recuperar informações armazenadas.
**robusto** — forte e confiável, especialmente sob estresse.
##S
**escalável** — capaz de lidar com o aumento da carga de trabalho sem prejudicar o desempenho.
**esquema** — a estrutura ou layout de um banco de dados ou formato de dados.
**escopo** — o alcance do efeito; a seção do código onde uma variável está visível.
**segmento** — uma seção ou parte distinta.
**semântico** — relacionado ao significado, especialmente na linguagem ou código.
**sequência** — um conjunto de coisas em uma ordem específica.
**sessão** — um período de atividade; uma conexão entre cliente e servidor.
**simular** — para imitar o comportamento de um sistema.
**fonte** — a origem de algo; código original antes da compilação.
**especificar** — para declarar de forma clara e detalhada.
**estático** — sem alteração; em computação, fixo em tempo de compilação ou não associado a instâncias.
**armazenar** — para salvar dados para uso posterior.
**estrutura** — a disposição das peças; um tipo de dados composto.
**resumir** — para fazer uma breve exposição dos pontos principais.
**sincronizar** — fazer com que aconteça ao mesmo tempo ou taxa.
**sintaxe** — as regras que regem a estrutura das declarações em uma linguagem.
##T
**modelo** — um modelo ou padrão usado como ponto de partida.
**limiar** — um nível ou ponto que desencadeia uma ação quando alcançado.
**token** — uma unidade de texto em PNL; uma credencial de autenticação.
**trace** — para seguir um caminho; um registro da execução do programa para depuração.
**transformar** — para mudar de forma, natureza ou aparência.
**transmitir** — para enviar dados de um lugar para outro.
## você
**uniforme** — consistente e inalterado por completo.
**único** — o único do gênero; ocorrendo apenas uma vez.
**atualizar** — para trazer para um estado mais atual.
**utilizar** — fazer uso de algo.
##V
**validar** — para confirmar que algo atende aos requisitos ou está correto.
**variável** — um contêiner nomeado para um valor que pode mudar.
**verificar** — para verificar a correção ou veracidade.
**versão** — uma forma específica de um produto em um determinado ponto de seu desenvolvimento.
## C
**fluxo de trabalho** — uma série de etapas seguidas para concluir uma tarefa.
**mandado** — justificativa para uma ação; um documento legal que autoriza algo.
## X
**xenofobia** — medo ou ódio de estrangeiros ou estranhos.
## S
**rendimento** — para produzir ou fornecer; ceder; a quantidade produzida.
##Z
**soma zero** — uma situação em que o ganho de uma pessoa é igual à perda de outra.
**zona** — uma área com características ou limites distintos.

## Termos Técnicos Adicionais
**abstração** — oculta detalhes complexos de implementação e mostra apenas recursos essenciais.
**acrônimo** — uma palavra formada pelas letras iniciais de uma frase (por exemplo, NASA, ASCII).
**adjetivo** — uma palavra que descreve um substantivo ou pronome.
**advérbio** — uma palavra que modifica um verbo, adjetivo ou outro advérbio, geralmente terminando em -ly.
**afixo** — um morfema adicionado à raiz de uma palavra (prefixo no início, sufixo no final).
**ágil** — uma metodologia de desenvolvimento de software que enfatiza o progresso iterativo e a flexibilidade.
**analogia** — uma comparação entre duas coisas para explicar ou esclarecer.
**antônimo** — uma palavra com significado oposto a outra palavra.
**aforismo** — uma declaração concisa que expressa uma verdade ou princípio geral.
**apócrifo** — de autenticidade duvidosa; amplamente divulgado, mas provavelmente falso.
**arquétipo** — um modelo original ou exemplo típico de algo.
**artefato** — um objeto feito por humanos; na computação, um subproduto não intencional do processamento.
**afirmação** — uma declaração confiante; na programação, uma verificação de que uma condição é verdadeira.
**assíncrono** — não ocorrendo ao mesmo tempo; permitindo que as operações prossigam sem espera.
**atenuar** — para reduzir força, valor ou intensidade.
**axioma** — uma afirmação aceita como verdadeira sem prova; um princípio fundamental.
**backpropagation** — um algoritmo para treinar redes neurais por meio da propagação de erros para trás.
**largura de banda** — a faixa de frequências disponíveis; capacidade de transferência de dados.
**binário** — composto por duas partes; sistema numérico de base 2 usando 0s e 1s.
**bit** — a menor unidade de dados (0 ou 1); abreviação de dígito binário.
**blockchain** — uma tecnologia de contabilidade distribuída que registra transações em vários computadores.
**boolean** — relacionado à lógica com valores verdadeiros ou falsos; nomeado em homenagem a George Boole.
**gargalo** — um ponto de congestionamento que torna um processo ou sistema mais lento.
**byte** — uma unidade de informação digital que normalmente consiste em 8 bits.
**cache** — um componente de hardware ou software que armazena dados para acesso futuro mais rápido.
**calibrar** — para ajustar com precisão para obter medições ou desempenho precisos.
**cascata** — uma série de estágios em que cada um aciona o próximo; efeito cascata.
**catalisador** — uma substância que acelera uma reação química; qualquer coisa que cause mudança.
**causalidade** — a relação entre causa e efeito.
**centróide** — o centro geométrico de uma forma; posição média dos pontos.
**checksum** — um valor calculado a partir de dados para detectar erros ou adulterações.
**cifra** — um algoritmo para criptografia ou descriptografia; um código secreto.
**coalescer** — unir-se para formar um todo.
**cognitivo** — relacionado aos processos mentais de percepção, memória, julgamento e raciocínio.
**coorte** — um grupo que compartilha uma característica ou experiência comum dentro de um período definido.
**garantia** — ativos dados em garantia de um empréstimo; secundário ou acompanhante.
**coloquial** — linguagem informal usada em conversas comuns.
**combinatória** — o ramo da matemática que lida com combinações e permutações.
**comutativo** — uma propriedade onde a ordem não importa (a+b = b+a).
**simultaneidade** — vários cálculos acontecendo durante períodos sobrepostos.
**conjectura** — uma conclusão formada com base em informações incompletas; uma hipótese matemática.
**conjunção** — uma palavra que conecta cláusulas ou sentenças (e, mas, ou); operador lógico AND.
**consenso** — acordo geral entre um grupo.
**restrição** — uma limitação ou restrição do que é possível.
**corolário** — uma proposição decorrente de outra já provada.
**correlação** — uma relação mútua entre duas variáveis; não implica causalidade.
**criptomoeda** — uma moeda digital protegida por criptografia, muitas vezes descentralizada.
**cristalizar** — para formar cristais; para deixar claro ou definitivo.
**em cadeia** — para conectar dispositivos ou tarefas em uma série sequencial.
**desconvolução** — reversão da convolução; separando sinais ou imagens mistas.
**dedução** — raciocínio desde princípios gerais até conclusões específicas.
**defenestração** — o ato de jogar alguém pela janela.
**deitico** — referindo-se a algo apontando (isso, aquilo, aqui, ali).
**demográfico** — dados estatísticos sobre populações ou grupos.
**denotação** — o significado literal ou primário de uma palavra.
**obsoleto** — marcado como obsoleto, mas ainda funcional; desencorajado de usar.
**derivada** — uma medida de taxa de mudança (cálculo); derivado de outra coisa.
**determinístico** — produzindo a mesma saída com a mesma entrada; previsível.
**diacrônico** — estudar fenômenos à medida que mudam ao longo do tempo.
**didático** — destinado a ensinar, principalmente com instrução moral.
**difração** — a curvatura das ondas em torno de obstáculos ou através de aberturas.
**dígrafo** — dois caracteres representando um som (sh, ch, th).
**desambiguar** — para remover ambiguidade; deixar algo mais claro.
**discreto** — separado e distinto; individual (oposto de contínuo).
**disjuntivo** — apresentando alternativas; operação lógica OR.
**divergência** — o processo de separação ou afastamento.
**docstring** — documentação incorporada no código-fonte explicando o propósito da função.
**excêntrico** — não convencional ou ligeiramente estranho; fora do centro.
**eclético** — seleção de diversas fontes ou estilos.
**caso extremo** — um cenário extremo ou raro que requer tratamento especial.
**elegia** — um poema triste ou lamento pelos mortos.
**elide** — omitir ou confundir sons ou sílabas.
**reticências** — omissão de palavras; três pontos (...) indicando continuação ou pausa.
**embargo** — uma proibição oficial de comércio ou publicação.
**empatia** — a capacidade de compreender e compartilhar os sentimentos dos outros.
**empírico** — baseado na observação ou experiência, e não na teoria.
**emular** — para imitar ou combinar, especialmente em computação (emulação de software).
**endêmico** — nativo ou restrito a uma determinada região; constantemente presente.
**efêmero** — durando muito pouco tempo; temporário.
**epistemologia** — o estudo do conhecimento, sua natureza e escopo.
**época** — um período significativo na história; no ML, uma passagem pelos dados de treinamento.
**equilíbrio** — um estado de equilíbrio entre forças opostas.
**equivocar** — usar linguagem ambígua para ocultar a verdade.
**ergódico** — tendo propriedades estatísticas totalmente uniformes; aleatório, mas representativo.
**esotérico** — destinado ou compreendido por um grupo pequeno e especializado.
**etnografia** — o estudo sistemático de pessoas e culturas por meio da observação.
**etimologia** — o estudo das origens das palavras e do desenvolvimento histórico.
**eufemismo** — uma expressão suave que substitui uma expressão áspera ou desagradável.
**evanescente** — passageiro; desaparecendo como vapor.
**exacerbar** — para piorar um problema.
**imposto de consumo** — para cortar; um imposto sobre certos bens.
**existencial** — relativo à existência; sobre a liberdade e a escolha humana.
**exógeno** — originado de fatores externos.
**agilizar** — para fazer acontecer mais cedo; acelerar.
**exponencial** — envolvendo exponenciação; crescimento acelerando ao longo do tempo.
**extrapolar** — para estimar além dos dados conhecidos, ampliando as tendências.
**fachada** — a frente de um edifício; uma aparência externa enganosa.
**falácia** — uma crença equivocada; raciocínio falho na argumentação.
**falsificável** — capaz de ser provado falso; um critério para afirmações científicas.
**ciclo de feedback** — um sistema onde as saídas influenciam as entradas, amplificando ou estabilizando.
