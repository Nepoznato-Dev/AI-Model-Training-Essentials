# Tecnologia e Computação

## O que é um Computador?

Um computador é um dispositivo eletrônico que processa dados de acordo com um conjunto de instruções chamado programa. Os computadores modernos são baseados na arquitetura de von Neumann, que consiste em uma unidade central de processamento (CPU), memória, armazenamento e dispositivos de entrada/saída. A CPU executa instruções. A RAM (memória de acesso aleatório) armazena dados temporariamente enquanto o computador está em funcionamento. Dispositivos de armazenamento, como SSDs e discos rígidos, guardam dados permanentemente.

## Linguagens de Programação

Uma linguagem de programação é uma linguagem formal usada para escrever instruções para computadores. Python é uma linguagem de programação de alto nível, interpretada e de propósito geral, conhecida por sua sintaxe simples e legibilidade. É amplamente usada em ciência de dados, machine learning, desenvolvimento web e automação. JavaScript é a principal linguagem para desenvolvimento web e roda em navegadores. Java é uma linguagem compilada e orientada a objetos amplamente usada em software corporativo e no desenvolvimento Android. C e C++ são linguagens de nível mais baixo que oferecem controle detalhado sobre o hardware e são usadas em programação de sistemas, desenvolvimento de jogos e aplicações críticas de desempenho. Rust é uma linguagem moderna de programação de sistemas focada em segurança e desempenho.

## Como a Internet Funciona

A internet é uma rede global de computadores interconectados que se comunicam usando protocolos padronizados. A World Wide Web é um sistema de sites e páginas web acessados pela internet por meio de navegadores. HTTP (HyperText Transfer Protocol) e HTTPS (HTTP seguro) são os protocolos usados para transferir páginas web. Um endereço IP é um endereço numérico único atribuído a cada dispositivo em uma rede. DNS (Domain Name System) traduz nomes de domínio legíveis por humanos (como google.com) em endereços IP. Um roteador direciona o tráfego de rede entre dispositivos e redes.

## Redes e Protocolos

TCP/IP é o conjunto de protocolos fundamental da internet. O IP (Internet Protocol) lida com endereçamento e roteamento de pacotes entre redes, enquanto o TCP (Transmission Control Protocol) fornece entrega confiável e ordenada, com retransmissão e controle de fluxo. UDP é uma alternativa sem conexão usada quando baixa latência importa mais do que entrega garantida (por exemplo, em streaming, jogos ou consultas DNS). HTTP é um protocolo sem estado da camada de aplicação para comunicação de requisição/resposta entre clientes e servidores. HTTPS é HTTP sobre TLS, acrescentando criptografia e proteção de integridade. REST (Representational State Transfer) é um estilo arquitetural de API que usa recursos, verbos HTTP padrão (GET, POST, PUT, PATCH, DELETE) e interações sem estado. WebSockets fornecem conexões persistentes e full-duplex para que cliente e servidor possam enviar mensagens em tempo real, o que é útil para chat, painéis ao vivo e aplicativos colaborativos.

## Inteligência Artificial

Inteligência artificial (AI) é a simulação da inteligência humana por máquinas, especialmente sistemas computacionais. Machine learning é um subconjunto de AI em que sistemas aprendem com dados para fazer previsões ou tomar decisões sem serem explicitamente programados. Deep learning é um subconjunto de machine learning que usa redes neurais com muitas camadas. Redes neurais são modelos computacionais vagamente inspirados na estrutura de cérebros biológicos. Large language models (LLMs) são modelos de AI treinados com grandes quantidades de texto para gerar e compreender linguagem natural.

## Algoritmos e Estruturas de Dados

Um algoritmo é um procedimento passo a passo para resolver um problema. Estruturas de dados são formas de organizar dados em um computador para que possam ser acessados e modificados com eficiência. Estruturas de dados comuns incluem arrays, listas encadeadas, pilhas, filas, árvores, grafos e tabelas hash. Algoritmos de ordenação organizam itens em uma ordem especificada; exemplos comuns são bubble sort, merge sort e quicksort. Busca binária é um algoritmo eficiente para encontrar um item em uma lista ordenada, reduzindo repetidamente pela metade o intervalo de busca.

## Bancos de Dados

Um banco de dados é uma coleção organizada de dados estruturados armazenados eletronicamente. Um banco de dados relacional armazena dados em tabelas com linhas e colunas. SQL (Structured Query Language) é a linguagem padrão para gerenciar e consultar bancos de dados relacionais. Bancos de dados NoSQL armazenam dados em formatos diferentes de relações tabulares, como documentos, pares chave-valor ou grafos. Sistemas de banco de dados comuns incluem PostgreSQL, MySQL, SQLite, MongoDB e Redis. Um índice em um banco de dados acelera a recuperação de dados ao custo de armazenamento extra.

## Fundamentos de Design de Sistemas

O design de sistemas se concentra em construir sistemas de software confiáveis, escaláveis e fáceis de manter. Balanceamento de carga distribui o tráfego entre vários servidores para melhorar a disponibilidade e reduzir a latência. Escalabilidade horizontal adiciona mais máquinas; escalabilidade vertical adiciona mais recursos a uma única máquina. Cache armazena dados acessados com frequência em armazenamento rápido (por exemplo, Redis, Memcached ou caches de borda de CDN) para reduzir a carga no banco de dados e o tempo de resposta. Bancos de dados em escala exigem replicação, particionamento (sharding), estratégias de backup e trade-offs cuidadosos de consistência. Microservices dividem aplicações grandes em serviços menores implantáveis de forma independente, enquanto monólitos mantêm a maior parte da lógica em uma única unidade implantável; ambas as abordagens envolvem trade-offs em complexidade, velocidade de implantação, depuração e autonomia das equipes.

## Sistemas Operacionais

Um sistema operacional (OS) é um software que gerencia o hardware do computador e fornece serviços para programas. Sistemas operacionais comuns incluem Windows, macOS e Linux. Linux é um kernel de OS open source usado em servidores, sistemas embarcados e Android. O OS gerencia processos (programas em execução), memória, sistemas de arquivos e dispositivos de entrada/saída. Um processo é uma instância em execução de um programa. Uma thread é a menor unidade de execução dentro de um processo.

## Controle de Versão

Sistemas de controle de versão acompanham mudanças no código ao longo do tempo, permitindo que desenvolvedores colaborem e revertam para estados anteriores. Git é o sistema de controle de versão mais usado. Um repositório (repo) é uma coleção de arquivos e seu histórico. Um commit é um snapshot salvo de alterações. Uma branch é uma linha independente de desenvolvimento. Um pull request é uma proposta para mesclar mudanças de uma branch em outra.

## Práticas de Desenvolvimento de Software

Programação orientada a objetos (OOP) organiza o código em objetos que combinam dados e comportamento. Princípios-chave de OOP incluem encapsulamento, herança, polimorfismo e abstração. Test-driven development (TDD) é a prática de escrever testes antes de escrever código. Agile é um conjunto de metodologias de desenvolvimento de software que enfatizam desenvolvimento iterativo, colaboração e adaptabilidade. DevOps combina desenvolvimento de software e operações de TI para encurtar o ciclo de vida de desenvolvimento. APIs (Application Programming Interfaces) permitem que diferentes sistemas de software se comuniquem entre si.

## Noções Básicas de Cloud e DevOps

Cloud computing fornece infraestrutura sob demanda e serviços gerenciados pela internet. Os três principais provedores de cloud pública são AWS (Amazon Web Services), Microsoft Azure e Google Cloud Platform (GCP). Modelos de serviço comuns são IaaS (infraestrutura), PaaS (plataforma) e SaaS (software). Blocos fundamentais de cloud incluem instâncias/containers de computação, armazenamento de objetos, bancos de dados gerenciados, redes e IAM (Identity and Access Management). CI/CD (Continuous Integration and Continuous Delivery/Deployment) automatiza pipelines de build, teste e release para que o código possa ir com segurança do commit à produção. Docker empacota aplicações e dependências em containers portáteis; em produção, esses containers normalmente são implantados por meio de orquestradores (como Kubernetes), plataformas serverless ou serviços gerenciados de containers.

## Formatos de Dados e Ferramentas

JSON (JavaScript Object Notation) é um formato de texto leve construído a partir de objetos (pares chave/valor), arrays, strings, números, booleanos e null; é amplamente usado em APIs. YAML é um formato de configuração amigável para humanos que suporta estruturas aninhadas e comentários, comumente usado em CI/CD e definições de infraestrutura. CSV (Comma-Separated Values) armazena dados tabulares como linhas de texto delimitado e é comum em pipelines de importação/exportação de dados. XML (eXtensible Markup Language) é um formato estruturado baseado em tags usado em sistemas legados, configuração e fluxos documentais. Desenvolvedores geralmente validam e transformam esses formatos com linters, validadores de schema (como JSON Schema), ferramentas de consulta (`jq`, XPath) e bibliotecas de parsing na linguagem de programação usada.

## Expressões Regulares (Regex)

Uma expressão regular é uma linguagem de padrões usada para pesquisar, corresponder, extrair e transformar texto. Conceitos centrais de regex incluem literais (`cat`), classes de caracteres (`[a-z]`, `\d`), quantificadores (`*`, `+`, `?`, `{n,m}`), âncoras (`^`, `$`), grupos (`(...)`), alternância (`a|b`) e escape de caracteres especiais. Regex é muito usado para validação de entrada, parsing de logs, extração de texto e automação de localizar/substituir. Motores diferentes (PCRE, JavaScript, Python `re`, RE2) têm conjuntos de recursos diferentes, então o comportamento pode variar entre ferramentas. Regex é poderosa, mas pode se tornar difícil de ler; padrões complexos devem ser testados e documentados para evitar bugs.

## Cibersegurança

Cibersegurança é a prática de proteger sistemas computacionais, redes e dados contra ataques digitais. Ameaças comuns incluem malware (software malicioso), phishing (comunicação fraudulenta projetada para roubar informações), ransomware (malware que criptografa dados e exige pagamento) e ataques de negação de serviço. Criptografia transforma dados em uma forma ilegível que só pode ser decodificada com uma chave. HTTPS usa TLS (Transport Layer Security) para criptografar o tráfego web. Senhas fortes e exclusivas, além de autenticação de dois fatores, são práticas fundamentais de segurança.

## Conceitos de Segurança para Desenvolvedores

OAuth 2.0 é um framework de autorização que permite aos usuários conceder acesso limitado a uma aplicação sem compartilhar credenciais diretamente. OpenID Connect (OIDC) é uma camada de identidade construída sobre OAuth 2.0 para autenticação. JWT (JSON Web Token) é um formato compacto de token contendo claims, frequentemente usado para autenticação stateless, mas ele deve ser assinado corretamente e validado com rigor (assinatura, expiração, emissor, audiência). TLS protege dados em trânsito fornecendo criptografia, integridade e autenticação do servidor por meio de certificados. O OWASP Top 10 é uma lista amplamente usada de riscos comuns de segurança em aplicações web, incluindo broken access control, falhas criptográficas, injection, design inseguro, configuração incorreta de segurança, componentes vulneráveis e logging/monitoramento insuficientes. O desenvolvimento seguro exige defense-in-depth: validação de entrada, codificação de saída, menor privilégio, gerenciamento de segredos, correção de dependências e testes regulares de segurança.
