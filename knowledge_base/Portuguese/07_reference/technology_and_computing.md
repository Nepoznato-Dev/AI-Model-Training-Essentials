# Tecnologia e Computação

## O que é um Computador?

Um computador é um dispositivo eletrônico que processa dados de acordo com um conjunto de instruções chamado programa. Os computadores modernos são baseados na arquitetura de von Neumann, que consiste em uma unidade central de processamento (CPU), memória, armazenamento e dispositivos de entrada/saída. A CPU executa instruções. A RAM (memória de acesso aleatório) armazena dados temporariamente enquanto o computador está em funcionamento. Dispositivos de armazenamento como SSDs e discos rígidos armazenam dados permanentemente.

## Linguagens de Programação

Uma linguagem de programação é uma linguagem formal usada para escrever instruções para computadores. Python é uma linguagem de programação de alto nível, interpretada e de propósito geral, conhecida por sua sintaxe simples e legibilidade. Ela é amplamente usada em ciência de dados, aprendizado de máquina, desenvolvimento web e automação. JavaScript é a principal linguagem para desenvolvimento web e é executada em navegadores. Java é uma linguagem compilada e orientada a objetos, amplamente usada em software corporativo e desenvolvimento Android. C e C++ são linguagens de nível mais baixo que oferecem controle detalhado sobre o hardware e são usadas em programação de sistemas, desenvolvimento de jogos e aplicações críticas em desempenho. Rust é uma linguagem moderna de programação de sistemas focada em segurança e desempenho.

## Como a Internet Funciona

A internet é uma rede global de computadores interconectados que se comunicam usando protocolos padronizados. A World Wide Web é um sistema de sites e páginas da web acessados pela internet por meio de navegadores. HTTP (HyperText Transfer Protocol) e HTTPS (HTTP seguro) são os protocolos usados para transferir páginas da web. Um endereço IP é um endereço numérico exclusivo atribuído a cada dispositivo em uma rede. O DNS (Domain Name System) traduz nomes de domínio legíveis por humanos (como google.com) em endereços IP. Um roteador direciona o tráfego de rede entre dispositivos e redes.

## Redes e Protocolos

TCP/IP é o conjunto de protocolos fundamental da internet. O IP (Internet Protocol) lida com o endereçamento e o roteamento de pacotes entre redes, enquanto o TCP (Transmission Control Protocol) fornece entrega confiável e ordenada, com retransmissão e controle de fluxo. O UDP é uma alternativa sem conexão usada quando a baixa latência é mais importante do que a entrega garantida (por exemplo, em streaming, jogos ou consultas DNS). O HTTP é um protocolo sem estado da camada de aplicação para comunicação de requisição/resposta entre clientes e servidores. O HTTPS é HTTP sobre TLS, adicionando criptografia e proteção de integridade. REST (Representational State Transfer) é um estilo de arquitetura de API que usa recursos, verbos HTTP padrão (GET, POST, PUT, PATCH, DELETE) e interações sem estado. WebSockets fornecem conexões persistentes e full-duplex para que cliente e servidor possam enviar mensagens em tempo real, o que é útil para chat, painéis em tempo real e aplicativos colaborativos.

## Inteligência Artificial

Inteligência artificial (IA) é a simulação da inteligência humana por máquinas, especialmente sistemas computacionais. Aprendizado de máquina é um subconjunto da IA no qual sistemas aprendem a partir de dados para fazer previsões ou tomar decisões sem serem explicitamente programados. Aprendizado profundo é um subconjunto do aprendizado de máquina que usa redes neurais com muitas camadas. Redes neurais são modelos computacionais vagamente inspirados na estrutura de cérebros biológicos. Modelos de linguagem de grande porte (LLMs) são modelos de IA treinados com quantidades massivas de texto para gerar e compreender linguagem natural.

## Algoritmos e Estruturas de Dados

Um algoritmo é um procedimento passo a passo para resolver um problema. Estruturas de dados são formas de organizar dados em um computador para que possam ser acessados e modificados com eficiência. Estruturas de dados comuns incluem arrays, listas ligadas, pilhas, filas, árvores, grafos e tabelas hash. Algoritmos de ordenação organizam itens em uma ordem especificada; exemplos comuns são bubble sort, merge sort e quicksort. A busca binária é um algoritmo eficiente para encontrar um item em uma lista ordenada, reduzindo repetidamente pela metade o intervalo de busca.

## Bancos de Dados

Um banco de dados é uma coleção organizada de dados estruturados armazenados eletronicamente. Um banco de dados relacional armazena dados em tabelas com linhas e colunas. SQL (Structured Query Language) é a linguagem padrão para gerenciar e consultar bancos de dados relacionais. Bancos de dados NoSQL armazenam dados em formatos diferentes de relações tabulares, como documentos, pares chave-valor ou grafos. Sistemas de banco de dados comuns incluem PostgreSQL, MySQL, SQLite, MongoDB e Redis. Um índice em um banco de dados acelera a recuperação de dados ao custo de armazenamento extra.

## Fundamentos de Design de Sistemas

O design de sistemas se concentra na construção de sistemas de software confiáveis, escaláveis e de fácil manutenção. O balanceamento de carga distribui o tráfego entre vários servidores para melhorar a disponibilidade e reduzir a latência. Escalabilidade horizontal adiciona mais máquinas; escalabilidade vertical adiciona mais recursos a uma única máquina. Cache armazena dados acessados com frequência em armazenamento rápido (por exemplo, Redis, Memcached ou caches de borda de CDN) para reduzir a carga no banco de dados e o tempo de resposta. Bancos de dados em escala exigem replicação, particionamento (sharding), estratégias de backup e escolhas cuidadosas de consistência. Microsserviços dividem aplicações grandes em serviços menores implantáveis de forma independente, enquanto monólitos mantêm a maior parte da lógica em uma única unidade implantável; ambas as abordagens envolvem trade-offs em complexidade, velocidade de implantação, depuração e autonomia das equipes.

## Sistemas Operacionais

Um sistema operacional (SO) é um software que gerencia o hardware do computador e fornece serviços para programas. Sistemas operacionais comuns incluem Windows, macOS e Linux. Linux é um kernel de sistema operacional de código aberto usado em servidores, sistemas embarcados e Android. O SO gerencia processos (programas em execução), memória, sistemas de arquivos e dispositivos de entrada/saída. Um processo é uma instância em execução de um programa. Uma thread é a menor unidade de execução dentro de um processo.

## Controle de Versão

Sistemas de controle de versão acompanham alterações no código ao longo do tempo, permitindo que desenvolvedores colaborem e revertam para estados anteriores. Git é o sistema de controle de versão mais amplamente usado. Um repositório (repo) é uma coleção de arquivos e seu histórico. Um commit é um snapshot salvo das alterações. Uma branch é uma linha independente de desenvolvimento. Um pull request é uma proposta para mesclar alterações de uma branch em outra.

## Práticas de Desenvolvimento de Software

A programação orientada a objetos (OOP) organiza o código em objetos que combinam dados e comportamento. Princípios fundamentais de OOP incluem encapsulamento, herança, polimorfismo e abstração. Desenvolvimento orientado por testes (TDD) é a prática de escrever testes antes de escrever código. Agile é um conjunto de metodologias de desenvolvimento de software que enfatizam desenvolvimento iterativo, colaboração e adaptabilidade. DevOps combina desenvolvimento de software e operações de TI para encurtar o ciclo de vida do desenvolvimento. APIs (Application Programming Interfaces) permitem que diferentes sistemas de software se comuniquem entre si.

## Fundamentos de Nuvem e DevOps

Computação em nuvem fornece infraestrutura sob demanda e serviços gerenciados pela internet. Os três principais provedores de nuvem pública são AWS (Amazon Web Services), Microsoft Azure e Google Cloud Platform (GCP). Modelos de serviço comuns são IaaS (infraestrutura), PaaS (plataforma) e SaaS (software). Blocos fundamentais da nuvem incluem instâncias de computação/contêineres, armazenamento de objetos, bancos de dados gerenciados, redes e IAM (Identity and Access Management). CI/CD (Continuous Integration and Continuous Delivery/Deployment) automatiza pipelines de build, teste e release para que o código possa ir com segurança do commit à produção. Docker empacota aplicações e dependências em contêineres portáteis; em produção, esses contêineres normalmente são implantados por meio de orquestradores (como Kubernetes), plataformas serverless ou serviços gerenciados de contêineres.

## Formatos de Dados e Ferramentas

JSON (JavaScript Object Notation) é um formato de texto leve composto por objetos (pares chave/valor), arrays, strings, números, booleanos e null; ele é amplamente usado em APIs. YAML é um formato de configuração amigável para humanos que oferece suporte a estruturas aninhadas e comentários, comumente usado em CI/CD e definições de infraestrutura. CSV (Comma-Separated Values) armazena dados tabulares como linhas de texto delimitado e é comum em pipelines de importação/exportação de dados. XML (eXtensible Markup Language) é um formato estruturado baseado em tags usado em sistemas legados, configuração e fluxos de trabalho de documentos. Desenvolvedores normalmente validam e transformam esses formatos com linters, validadores de esquema (como JSON Schema), ferramentas de consulta (`jq`, XPath) e bibliotecas de parsing em sua linguagem de programação.

## Expressões Regulares (Regex)

Uma expressão regular é uma linguagem de padrões usada para pesquisar, corresponder, extrair e transformar texto. Conceitos centrais de regex incluem literais (`cat`), classes de caracteres (`[a-z]`, `\d`), quantificadores (`*`, `+`, `?`, `{n,m}`), âncoras (`^`, `$`), grupos (`(...)`), alternância (`a|b`) e escape de caracteres especiais. Regex é amplamente usado para validação de entrada, parsing de logs, extração de texto e automação de localizar/substituir. Diferentes motores (PCRE, JavaScript, Python `re`, RE2) têm conjuntos de recursos diferentes, portanto o comportamento pode variar entre ferramentas. Regex é poderoso, mas pode se tornar difícil de ler; padrões complexos devem ser testados e documentados para evitar bugs.

## Cibersegurança

Cibersegurança é a prática de proteger sistemas computacionais, redes e dados contra ataques digitais. Ameaças comuns incluem malware (software malicioso), phishing (comunicação fraudulenta projetada para roubar informações), ransomware (malware que criptografa dados e exige pagamento) e ataques de negação de serviço. Criptografia transforma dados em uma forma ilegível que só pode ser decodificada com uma chave. O HTTPS usa TLS (Transport Layer Security) para criptografar o tráfego da web. Senhas fortes e exclusivas, além de autenticação de dois fatores, são práticas fundamentais de segurança.

## Conceitos de Segurança para Desenvolvedores

OAuth 2.0 é um framework de autorização que permite aos usuários conceder acesso limitado a uma aplicação sem compartilhar credenciais diretamente. OpenID Connect (OIDC) é uma camada de identidade construída sobre o OAuth 2.0 para autenticação. JWT (JSON Web Token) é um formato compacto de token contendo claims, frequentemente usado para autenticação sem estado, mas deve ser assinado corretamente e validado de forma rigorosa (assinatura, expiração, emissor, audiência). TLS protege os dados em trânsito ao fornecer criptografia, integridade e autenticação do servidor por meio de certificados. O OWASP Top 10 é uma lista amplamente usada de riscos comuns de segurança em aplicações web, incluindo controle de acesso quebrado, falhas criptográficas, injeção, design inseguro, configuração incorreta de segurança, componentes vulneráveis e registro/monitoramento insuficientes. O desenvolvimento seguro exige defesa em profundidade: validação de entrada, codificação de saída, privilégio mínimo, gestão de segredos, correção de dependências e testes regulares de segurança.
