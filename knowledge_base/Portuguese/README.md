# Base de conhecimento
Uma coleção abrangente de documentos de referência que abrangem codificação, tecnologia, IA, ciência, negócios, humanidades e muito mais — escritos em um estilo natural e coloquial, projetado tanto para treinamento em IA quanto para aprendizado humano.
**Última atualização:** agosto de 2026  
**Total de arquivos:** mais de 138 documentos de descontos  
**Organização:** 10 diretórios temáticos + 34 referências de linguagens de programação
---

| Campo | Fonte/Objetivo |
|---|---|
| `title`| Extraído do primeiro título`#`do arquivo |
| `description`| Resumo de uma linha; arquivos de tópico reutilizam a entrada do índice deste README, arquivos de linguagem de programação usam uma descrição gerada |
| `category`/`reviewed_by`| Derivado do diretório pai (`01_coding_and_technology`→ "Coding and Technology" / "Coding & Technology Knowledge Base Team") |
| `version`| Versão semântica; esbarre em cada edição (veja abaixo) |
| `authors`/`contributors`| Autor original mais qualquer pessoa que tenha editado o arquivo desde então |
| `changelog`| Lista de alterações apenas anexadas, as mais recentes primeiro |
| `review_date`/`next_review`| Cadência de aproximadamente 6 meses e aproximadamente 1 ano, refletindo o cronograma de revisão de habilidades |
| `tags`| Tokens de nome de arquivo mais uma palavra-chave de categoria limpa (por exemplo,`coding-and-technology`) |
| `difficulty_level`| Definido por categoria, com substituições por idioma (por exemplo, Haskell/Assembly →`advanced`, Scratch →`beginner`) |
| `estimated_reading_time`| Calculado a partir da contagem de linhas |
### Editando um arquivo
Ao alterar um arquivo da base de conhecimento, mantenha seu frontmatter sincronizado:
1. **Bump`version`** seguindo [SemVer](https://semver.org/):
   - Patch (`1.0.x`): erros de digitação, formatação, pequenas correções
   - Menor (`1.x.0`): novas seções, conteúdo expandido, novos exemplos
   - Major (`x.0.0`): reescrita ou reestruturação completa
2. **Adicione uma entrada no changelog** (o mais recente primeiro) descrevendo o que você alterou:   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **Atualize`last_modified`** para a data da sua alteração
4. **Adicione-se a`contributors`** se for sua primeira edição no arquivo:   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
