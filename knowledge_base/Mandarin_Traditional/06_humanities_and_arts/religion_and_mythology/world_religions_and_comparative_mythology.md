# 世界宗教與比較神話
世界宗教是數千年來塑造人類文明的主要信仰、實踐和社群體系。比較神話學研究不同文化講述的有關創造、英雄、諸神和存在意義的故事，以及相隔數千英里和數千年的傳統中反覆出現的引人注目的模式。理解兩者對於理解人們為何相信自己的信念、文化有何不同以及人類經驗的共同點至關重要。

## 比較神話
### 英雄之旅（Monomyth）
約瑟夫·坎貝爾發現了一種在不同文化的神話中反覆出現的模式：
|舞台|描述 |範例|
|--------|-------------|---------|
| **平凡的世界** |英雄的平凡生活|佛羅多在夏爾 |
| **冒險的召喚** |出現挑戰或任務 |甘道夫帶著魔戒到來 |
| **拒絕來電** |英雄猶豫|佛羅多：「為什麼是我？」 |
| **超自然的援助** | Mentor提供工具或指導|甘道夫給予建議；埃爾隆德提供獎學金 |
| **跨越門檻** |英雄進入未知|離開夏爾 |
| **鯨魚的腹部** |與已知世界完全分離 |莫瑞亞礦井 |
| **測驗、盟友、敵人** |挑戰；友誼；反對派 |各種嘗試；形成債券|
| **接近最裡面的洞穴** |為重大挑戰做好準備 |接近末日山|
| **磨難** |中央危機；死亡與重生|與敵人對抗|
| **獎勵** |獲得寶藏或知識|戒指被毀|
| **回歸之路** |回程旅程；最後的挑戰|返回首頁 |
| **復活** |最終改造；英雄換了 |佛羅多歸來，但一切都永遠改變了 |
| **帶著長生不老藥回來** |英雄將智慧或禮物帶回平凡世界 |夏爾得救了 |

＃＃ 概括
世界宗教是人類最古老、最廣泛的嘗試來回答基本問題：我們為什麼在這裡？我們應該怎樣生活？死後會發生什麼事？亞伯拉罕信仰（猶太教、基督教、伊斯蘭教）有一個共同的祖先－亞伯拉罕，並強調一神論、聖經和倫理法。東方傳統（印度教、佛教、耆那教、道教）著重佛法、業力、從輪迴中解脫、與自然的和諧。比較神話揭示了跨文化的顯著模式——英雄的旅程、創世神話、洪水故事——暗示了人類講故事的深層結構。宗教活動（祈禱、冥想、禁食、朝聖、慈善）出現在每一個傳統中。世俗世界觀（人道主義、存在主義、斯多葛主義）提供了非宗教的意義框架。了解這些傳統並不是要相信它們中的任何一個，而是要了解數十億人的生活、價值觀和決定都是由這些傳統決定的。
