# 表演藝術
表演藝術——戲劇、電影、舞蹈和音樂表演——是藝術與觀眾現場互動的地方。與牆上的畫或書架上的書不同，表演是即時展開的，在藝術家和觀眾之間創造了一種共享體驗，這在數千年來一直是人類文化的核心。
---

## 劇院
2500 多年來，劇院一直是人類說故事的舞台。從古希臘的圓形劇場到百老匯和倫敦西區，現場表演仍然是最強大的藝術表達形式之一。
### 戲劇形式
|類型 |描述 |著名的例子|
|------|-------------|-----------------|
| **悲劇** |嚴肅題材，主角垮台 |希臘悲劇，莎士比亞的*哈姆雷特* |
| **喜劇** |幽默的情景，美好的結局|莎士比亞的喜劇，奧斯卡王爾德 |
| **悲喜劇** |融合悲劇與喜劇元素| *等待戈多*（貝克特）|
| **音樂劇** |歌、舞、對白融為一體| *漢密爾頓*，*悲慘世界* |
| **歌劇** |全唱戲劇作品| *波希米亞人*（普契尼）、*卡門*（比才）|
| **前衛** |非傳統形式，觀眾參與 |實驗劇場|
| **情節劇** |誇張的人物，煽情的情節| 19 世紀舞臺情節劇 |
| **鬧劇** |肢體喜劇、荒誕情境| Feydeau，*噪音關閉*（弗雷恩）|
### 主要劇作家
|時代|劇作家 |
|-----|------------|
| **古典** |索福克勒斯、歐裡庇得斯、阿里斯托芬 |
| **伊莉莎白/詹姆士一世** |莎士比亞、馬洛、瓊森 |
| **現代** |易卜生、契訶夫、史特林堡 |
| **二十世紀** |阿瑟·米勒、田納西·威廉姆斯、塞繆爾·貝克特、奧古斯特·威爾遜 |
| **當代** |林-曼努爾米蘭達、蘇珊-洛瑞·帕克斯、湯姆·斯托帕德
### 全球戲劇傳統
|傳統|產地 |特色 |
|------------|--------------------|----------------|
| **能樂** |日本 |蒙面表演者，緩慢的程式化動作，精神主題|
| **歌舞伎** |日本 |精緻的服裝、戲劇性的妝容、歷史故事|
| **文樂** |日本 |木偶劇院與可見的木偶師 |
| **京劇** |中國 |歌唱、朗誦、雜技、武術|
| **卡塔卡利語** |印度 |精心化妝和服裝的舞劇 |
| **即興喜劇** |義大利 |即興表演、庫存人物、蒙面表演者 |
| **京劇** |中國 |程式化的動作，象徵性的手勢|

＃＃ 電影
電影是主要藝術形式中最年輕的——只有一個多世紀的歷史——但它已成為消費最廣泛、文化影響力最廣的藝術形式。
### 電影運動
|運動|期間 |特色 |重要電影/導演 |
|----------|--------|----------------|------------------------|
| **德國表現主義** | 20 年代 |扭曲的視覺效果、心理主題| *諾斯費拉圖*（穆爾瑙）、*大都會*（朗）|
| **蘇聯蒙太奇** | 1920 年代 – 1930 年代 |剪輯即意義，鏡頭碰撞|愛森斯坦的*戰艦波將金號* |
| **義大利新寫實主義** | 20 世紀 40 年代 – 1950 年代 |工人階級故事，外景拍攝| *自行車竊賊*（德西卡）|
| **法國新浪潮** | 20 世紀 50 年代 – 1960 年代 |創新剪輯，作者論|特呂弗·戈達爾 |
| **新好萊塢** | 20 世紀 60 年代 – 1980 年代 |導演驅動、成熟主題|科波拉、斯科塞斯、庫伯力克 |
| **新德國電影** | 20 世紀 60 年代 – 1970 年代 |政治，導演驅動 |法斯賓德、文德斯、赫爾佐格 |
| **多美95** | 20 世紀 90 年代 |極簡規則，自然採光|馮提爾 (Von Trier)，溫特貝格 |
| **新浪潮運動** | 2000 年代至今 |全球電影多元化 |諾萊塢，韓國新浪潮 |
### 關鍵電影概念
|概念 |描述 |
|---------|-------------|
| **場景調度** |一切都放置在框架內——佈景、服裝、燈光、演員|
| **蒙太奇** |透過並置鏡頭創造意義的剪輯技巧 |
| **攝影** |攝影藝術－取景、動作、燈光、鏡頭選擇|
| **作者理論** |導演作為電影“作者”，具有辨識度的個人風格 |
| **類型** |影片類別：劇情片、喜劇片、恐怖片、科幻片、西部片、紀錄片等|
| **聲音設計** |所有音訊元素：對話、音樂、音效、靜音 |
### 主要電影產業
|工業|國家 |著名的 |
|----------|---------|-------------|
| **好萊塢** |美國 |大片、製片廠體系、全球影響力|
| **寶萊塢** |印度 |音樂敘事，海量產出|
| **諾萊塢** |奈及利亞 |快速製作，直接製作影片 |
| **坎城/歐洲** |法國/歐洲|作者電影、電影節 |
| **韓國電影** |韓國 |類型融合、社會評論 |
| **動漫** |日本 |動畫電影和系列 |

＃＃ 舞蹈
舞蹈是人類運動的藝術，通常（但並非總是）伴隨著音樂。它涵蓋儀式、娛樂和高雅藝術：
|表格 |產地 |特色 |
|------|--------------------|----------------|
| **芭蕾** |文藝復興時期的義大利/法國|編碼技術、足尖訓練、敘事 |
| **當代舞蹈** | 20世紀美國/歐洲 |拒絕僵化的芭蕾舞、地板動作、即興創作|
| **點擊** |美國（非裔美國人+愛爾蘭血統）|節奏步法作為打擊樂 |
| **弗拉門戈** |西班牙（安達盧西亞）|吉他、歌唱、打擊樂步法、情感強度|
| **嘻哈/霹靂舞** |美國（布朗克斯，20 世紀 70 年代）| B-boying、pop、locking、戰鬥 |
| **古典印度舞** |印度 | Bharatanatyam、Kathak、Odissi — 透過手勢說故事 |
| **宴會廳** |歐洲 |伴舞：華爾滋、探戈、狐步|
| **民間/傳統** |全球 |文化慶典、儀式、社區 |
---

## 為什麼這很重要
表演藝術是文化即時活躍的地方。戲劇透過讓我們站在另一個人的立場上兩個小時來培養同理心。電影可以讓我們見證歷史，或是帶我們進入想像的世界。舞蹈表達了言語無法表達的東西。這些藝術形式共同代表了人類最強大的連結、反思和變革工具。
