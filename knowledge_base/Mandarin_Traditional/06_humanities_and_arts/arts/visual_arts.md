#視覺藝術
視覺藝術是人類最古老的溝通形式——從拉斯科的洞穴壁畫到今天的數位裝置。了解藝術運動、媒介和保存創意作品的機構，可以讓您更深入地了解社會數千年來如何表達美、力量、靈性和異議。
---

## 幾個世紀以來的藝術運動
|運動|期間 |特色 |主要藝術家 |
|----------|--------|----------------|------------------------|
| **文藝復興** | 14世紀至17世紀|寫實主義、透視、解剖、古典主題 |李奧納多、米開朗基羅、拉斐爾 |
| **矯揉造作** | 16世紀晚期。 |修長的身材，人造的優雅|埃爾·格列柯，蓬托爾莫 |
| **巴洛克** |十七世紀|戲劇性的燈光、情感的強度、宏偉|卡拉瓦喬、倫勃朗、貝尼尼 |
| **洛可可** | 18世紀初。 |裝飾性、俏皮、柔和的調色板 |華托弗拉戈納爾 |
| **新古典主義** | 18世紀末至19世紀初|回歸古典秩序，道德嚴肅 |大衛安格爾 |
| **浪漫主義** | 18世紀末至19世紀中期|情感、自然、崇高|特納、德拉克洛瓦、傑里科|
| **寫實主義** |十九世紀中期。 |對日常生活的不理想描述|米勒·庫爾貝 |
| **印象派** |十九世紀末。 |光、色彩、可見的筆觸、現代生活|莫內、雷諾瓦、德加 |
| **後印象派** |十九世紀末。 |大膽的色彩、幾何形狀、情感深度|梵谷、塞尚、高更 |
| **新藝術風格** | 1890 年代 – 1910 年代 |有機線條、裝飾圖案|克林姆、穆夏、高第 |
| **表現主義** | 20世紀初c. |扭曲的形式，強烈的情感|蒙克、基什內爾、康丁斯基 |
| **立體主義** | 20世紀初c. |幾何形狀，多視角|布拉克·畢卡索 |
| **未來主義** | 1910 年代 – 1920 年代 |速度、技術、活力|博喬尼·巴拉 |
| **達達** | 1910 年代 – 1920 年代 |反藝術、荒誕、挑釁|豪斯曼杜尚 |
| **超現實主義** | 1920 年代 – 1940 年代 |夢境意象、無意識、自動主義 |達利、馬格里特、弗里達·卡羅 |
| **抽象表現主義** | 20 世紀 40 年代 – 1950 年代 |自發的手勢繪畫、大型畫布|波洛克、羅斯科、德庫寧 |
| **普普藝術** | 20 世紀 50 年代 – 1960 年代 |大眾文化意象、量產美學|沃霍爾，列支敦士登 |
| **極簡主義** | 20 世紀 60 年代 – 1970 年代 |簡約、幾何形狀、工業材料 |唐納德·賈德、艾格尼絲·馬丁 |
| **概念藝術** | 20 世紀 60 年代至今 |關於美學、文本、表現的想法 |索爾·勒維特、小野洋子 |
| **當代** | 20 世紀 70 年代至今 |多元化媒體、概念、社會評論 |班克斯、草間彌生、艾未未 |

## 藝術媒介
藝術家使用的材料和方法塑造了作品本身：
|中|描述 |著名的例子|
|--------|-------------|-----------------|
| **油畫** |油中色素（亞麻籽、核桃）；慢乾，可混合|倫勃朗、維米爾 |
| **壓克力** |快乾合成聚合物；多才多藝 |大衛霍克尼 |
| **水彩** |顏料懸浮在水中；透明、發光| J.M.W.特納|
| **壁畫** |濕石膏上的顏料；耐用、不朽|米開朗基羅（西斯汀教堂）|
| **木炭/鉛筆** |用於繪圖的乾燥介質；表達範圍 |萊昂納多的草圖|
| **墨水** |流體介質；書法，精確|東亞毛筆畫|
| **雕塑** |雕刻（石、木）、造型（黏土）、鑄造（青銅）|布朗庫西·羅丹 |
| **版畫** |蝕刻、平版印刷、網版印刷、木刻|葛飾北齋·丟勒 |
| **攝影** |光敏表面；數位或電影|安塞爾亞當斯、辛蒂雪曼 |
| **數位藝術** |電腦生成或操縱的；包括 3D、生成 |雷菲克·阿納多爾·比普爾 |
| **安裝** |特定地點的沉浸式環境 |克里斯托和珍妮-克洛德|
| **行為藝術** |身體、時間、空間為媒介|瑪麗娜·阿布拉莫維奇 |

## 設計原則
藝術家使用這些原則來組織視覺元素：
|原理|說明 |
|------------|-------------|
| **餘額** |視覺權重分佈（對稱、不對稱、放射狀）|
| **對比** |並置不同元素以創造視覺趣味|
| **強調** |創造吸引觀眾眼球的焦點 |
| **運動** |引導觀眾的視線貫穿構圖|
| **模式/重複** |重複元素創造節奏與統一|
| **比例/比例** |元素之間的大小關係 |
| **團結/和諧** |所有元素作為一個有凝聚力的整體一起工作|

## 為什麼這很重要
視覺藝術不僅僅是裝飾——它是人類思想、信仰和願望的記錄。每幅畫、雕塑和裝置都反映了其產生的文化。了解藝術運動可以幫助您解讀廣告、建築、電影和設計中圍繞您的視覺語言。博物館和畫廊不僅僅是舊物品的儲藏室，它們還是關於人類意義的生動對話。
