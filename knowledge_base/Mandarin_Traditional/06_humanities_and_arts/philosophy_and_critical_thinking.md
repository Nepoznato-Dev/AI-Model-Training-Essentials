# 哲學與批判性思維
哲學並不是一門為穿著託加長袍、留著鬍子的希臘人保留的塵土飛揚的學科。它是你所做的每一個決定背後的作業系統——什麼算是知識，什麼值得做，如何區分好論點和壞論點。批判性思考是實用的一面：分析主張、發現錯誤推理並做出更好決策的技能。該文件涵蓋了主要想法、評估它們的工具以及每個人都會遇到的認知陷阱。
---

## 主要思想流派
哲學有幾千年的傳統。大多數重要職位都可以分為幾所學校。
### 古與古典
|學校 |核心理念|關鍵人物|
|--------|------------|------------|

| **享樂主義** |美好的生活就是簡單的快樂、友誼和免於焦慮的自由。 |伊壁鳩魯|

## 道德框架
當你需要決定什麼是正確的時候，你就在遵守道德——無論你是否意識到。主要有以下三種方法。
### 三個框架
|框架|它所提出的問題|實力|弱點|
|------------|----------------|----------|----------|
| **結果主義**（功利主義）| 「什麼會產生最好的結果？」| 實用、可衡量、符合政策|難以預測後果；可以證明傷害少數群體是正當的|
| **道義論**（康德倫理學）| “每個人都應該遵守什麼規則？” |保護個人權利；一致|死板的;相互衝突的職責|
| **美德倫理** | “一個好人會做什麼？” |靈活的;注重性格|模糊的;沒有給出明確的行動指導|
### 康德的絕對命令
康德對一個行為是否道德的檢驗：
1. **普遍性**：你希望每個人都這樣做嗎？ （如果說謊普遍存在，信任就會崩潰。）
2. **以人性為目的**：永遠不要僅僅將人視為達到目的的手段。
### 應用倫理學
|域名 |關鍵問題|
|--------|--------------|
| **生物倫理學** |墮胎、安樂死、基因工程、動物權 |
| **商業道德** |企業責任、舉報、公平工資 |
| **技術/人工智慧道德** |隱私、演算法偏見、自主武器、工作取代 |
| **環境道德** |氣候責任、動物福利、代際正義 |

## 邏輯與論證
邏輯是對有效推理的研究。它為您提供了工具來判斷某人的論點何時真正支持他們的結論，何時不支持。
### 推理類型
|類型 |描述 |範例|
|------|-------------|---------|
| **演繹** |若前提為真，則結論*必須*為真。 |所有人類都會有一死。蘇格拉底是人。 → 蘇格拉底終有一死。 |
| **感應式** |前提使結論“可能”，而不是確定。 |我見過的每隻天鵝都是白色的。 → 可能所有天鵝都是白色的。 |
| **溯因** |推論出最好的解釋。 |草是濕的。最好的解釋：下雨了。 |
### 常見的邏輯謬誤
|謬論|描述 |範例|
|---------|-------------|---------|
| **人身攻擊** |攻擊人，而不是爭論| “你不能相信她的經濟學——她不是經濟學家。” |
| **稻草人** |扭曲論點以使其更容易受到攻擊 | “你想削減軍事預算？所以你想讓這個國家失去防禦能力？” |
| **訴諸權威** | 「X 是正確的，因為專家是這麼說的」（沒有檢查論證）| 「這位諾貝爾獎得主這樣說是關於政治的，所以這一定是對的。」 |
| **錯誤的二分法** |當存在更多選項時僅提供兩個選項 | “要么你支持這項政策，要么你不關心孩子。” |
| **滑坡** |通過一系列看似不可能的事件，A 通往 Z | “如果我們使大麻合法化，很快我們就會使一切合法化。” |
| **提出問題** |結論是在前提下假設的 | “這項法律不公正，因為它不公平。” （不公正=不公平——同樣的事情）|
| **事後因故** | A 發生在 B 之前，因此 A 導致了 B | “我服用了補充劑，然後我感覺好多了——補充劑起作用了。” |
| **你現在** | “你也這麼做”——駁斥批評，因為批評者虛偽| “你告訴我要吃得更健康，但你卻吃快餐。” |
| **訴諸自然** | “自然=好” | “人類進化來吃肉，所以素食主義是不自然和錯誤的。” |
| **沉沒成本謬論** |繼續是因為過去的投資，而不是未來的價值| “我們已經在這個項目上花費了 1000 萬美元；我們現在不能停止。” |
### 評估參數
一個好的論證有：
1. **真實（或有充分支持的）前提**
2. **有效的邏輯**（從前提得出結論）
3. **沒有隱藏的假設**
4. **相關性**（前提實際上解決了結論）

## 認識論：我們能知道什麼？
認識論是對知識本身的研究——它是什麼、我們如何獲得它以及它的限制是什麼。
### 知識來源
|來源 |描述 |限制|
|--------|-------------|------------|
| **感知** |直接的感官經驗 |幻覺、幻覺，範圍有限|
| **原因** |邏輯演繹與數學證明|只告訴您從您的場所發生的情況 |
| **內省** |檢查你自己的想法和感受|自欺欺人；對您自己的進程的有限訪問
| **見證** |別人告訴你什麼 |人們說謊、犯錯或過度簡化 |
| **記憶體** |回顧過去的經歷|不可靠；重建；隨著時間的推移而退化|
| **科學方法** |系統觀察、假設檢定、複製 |慢的;僅限於可測試的問題；範式依賴|
### 關鍵認識論問題
|問題 |描述 |
|---------|-------------|
| **歸納問題** |僅僅因為過去太陽每天都會升起，並不能「邏輯上」保證明天也會升起（休謨）|
| **蓋蒂爾問題** |合理的真實信念可能不是知識－運氣好的話你可能是對的 |
| **分界問題** |科學與偽科學的差別是什麼？ （波普爾：可證偽性）|
| **不確定性** |僅憑證據可能無法唯一確定哪種理論是正確的 |

## 認知偏差
你的大腦會走捷徑。大多數時候，它們工作得很好。如果不這樣做，結果稱為認知偏誤。了解它們是避免它們的第一步。
### 決策偏差
|偏見|描述 |範例|
|------|-------------|---------|
| **確認偏誤** |尋求證實現有信念的資訊|只閱讀與您觀點一致的新聞來源 |
| **錨定** |過度依賴遇到的第一個訊息 |從過高的初始價格進行談判 |
| **可用性啟發式** |透過想到例子的難易度來判斷機率|高估了飛機失事的風險，因為此類事件被廣泛報道
| **鄧寧-克魯格效應** |能力低下的人高估了自己的能力；專家低估了他們的水平初學者自信自己能夠解決專家認為很難的問題 |
| **取景效果** |決策會根據選項的呈現方式而改變 | “90%的存活率”聽起來比“10%的死亡率”好 |
| **損失厭惡** |損失的感覺大約是同等收益感覺良好的兩倍持有虧損股票，因為賣出會“鎖定”損失|
| **現狀偏見** |喜歡事物保持不變 |不改用更好的計劃，因為改變需要付出努力 |
### 社會偏見
|偏見|說明 |
|------|-------------|
| **光環效應** |一個正面的特質會影響您對一個人的整體印象 |
| **基本歸因錯誤** |將別人的行為歸因於性格，將自己的行為歸因於環境|
| **群體內偏見** |偏愛那些你認為屬於你的團隊的人 |
| **跟風效應** |因為許多其他人也持有這些信念而接受這些信念 |
| **正義世界謬誤** |相信人們會得到他們應得的 |
### 如何減少偏見
1. **鋼鐵人反對派**：建構你不同意的論點的最強版本。
2. **尋求反駁證據**：積極尋找你可能錯誤的原因。
3. **考慮基本利率**：這種類型的結果一般有多常見？
4. **使用清單和框架**：將你的思維具體化以發現盲點。
5. **在重要決定上睡覺**：第一直覺往往是有偏見的。
6. **邀請不同意見**：讓自己周圍都是那些會在你錯誤時告訴你的人。

## 為什麼這很重要
哲學和批判性思考不是抽象的練習。它們是實用的工具：
- **道德框架**幫助您應對商業、技術和個人生活中的真正困境。
- **邏輯**可以幫助您發現政治、廣告和社交媒體中的不良論點。
- **認知偏誤**解釋了為什麼聰明人會做出愚蠢的決定，以及如何減少做出愚蠢的決定。
- **知識論**在錯誤訊息時代變得越來越重要：你如何知道什麼是真實的？
你不需要同意任何特定的哲學家。你只需要能夠清楚地思考你相信什麼以及為什麼。
