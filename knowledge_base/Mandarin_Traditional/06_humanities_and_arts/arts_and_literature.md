# 藝術與文學
人類的創意表達——無論是書籍、繪畫、音樂或電影——是最持久的文明記錄之一。了解主要流派、運動和人物為我們當今生活的世界提供了背景。每部小說、每一部交響樂、每一部電影都與之前的事物對話。
---

## 文學流派與形式
### 小說類型
|類型 |主要特徵|著名的例子|
|--------|---------|-----------------|
| **文學小說** |人物驅動、主題深度、風格工藝 | *殺死一隻知更鳥*（哈珀李）|
| **科幻小說** |投機技術、空間、時間、平行世界| *沙丘*（赫伯特），*1984*（奧威爾）|
| **幻想** |神奇的世界，神秘的生物| *魔戒*（托爾金），*哈利波特*（羅琳）|
| **懸疑/偵探** |解決犯罪難題、調查 |夏洛克福爾摩斯（道爾）、波洛（克里斯蒂） |
| **恐怖** |恐懼、懸疑、超自然 | *閃靈*（國王）、*德古拉*（史托克）|
| **浪漫** |浪漫關係，情感旅程| *傲慢與偏見*（奧斯汀）|
| **歷史小說** |具體的歷史時期，準確的細節| *偷書賊*（祖薩克）、*狼廳*（曼特爾）|
| **魔幻寫實** |現實環境中的魔法元素被視為普通元素 | *一百年的孤獨*（加西亞·馬奎斯）|
### 非小說形式
|表格 |描述 |
|------|-------------|
| **傳記/自傳** |真實人物的生活故事——*年輕女孩的日記*（安妮·弗蘭克）、*成為*（米歇爾·奧巴馬）|
| **回憶錄** |專注於特定體驗或主題的個人帳戶 |
| **論文** |關於特定主題的短文——詹姆斯鮑德溫、瓊迪迪安 |
| **新聞** |新聞報導、調查文章、專題文章 |
| **自助** |個人發展與實踐提升|
### 詩歌形式
|表格 |結構|範例|
|------|------------|---------|
| **十四行詩** | 14行，具體節奏|莎士比亞 (ABAB CDCD EFEF GG)、彼特拉克 (ABBAABBA CDECDE) |
| **俳句** | 5-7-5 音節模式 |日本傳統，注重自然|
| **利默里克** |五句台詞，AABBA韻，幽默|輕詩|
| **自由詩** |沒有規律的韻律或韻律|沃爾特·惠特曼，T.S.艾略特 |
| **維拉內爾** | 19 行重複的副歌 | “不要溫柔”（迪倫·托馬斯）|
| **史詩** |關於英雄事蹟的長篇敘述| *奧德賽*（荷馬），*貝奧武甫* |

## 主要文學運動
文學經歷了不同的時期，每個時期都與前一個時期發生反應：
|期間 |時代|關鍵想法|主要人物 |
|--------|-----|------------|----------------|
| **古典** | 8世紀公元前 – 5世紀歐盟CE |理性、秩序、人文主義 |荷馬、索福克勒斯、維吉爾 |
| **中世紀** | 5世紀至15世紀|宗教題材、騎士精神、寓言|喬叟但丁|
| **文藝復興** | 14世紀至17世紀|人文主義，古典學的復興|莎士比亞、塞萬提斯 |
| **啟蒙** |十七至十八世紀。 |理性、科學、個人權利 |伏爾泰、史威夫特 |
| **浪漫主義** | 18世紀末至19世紀中期|情感、自然、個人主義 |華茲華斯、歌德、瑪麗雪萊 |
| **寫實主義** |十九世紀中期。 |精準描繪日常生活|托爾斯泰、喬治·艾略特、馬克·吐溫 |
| **現代主義** |十九世紀末至二十世紀中期|實驗形式，意識流|喬伊斯、弗吉尼亞·伍爾夫、T.S.艾略特 |
| **後現代主義** | 20世紀中期– 現在 |碎片化、後設小說、諷刺 |唐德里羅品欽 |
每一次運動都在某種程度上是一場叛亂。浪漫主義拒絕啟蒙理性主義；現代主義打破了維多利亞時代的慣例；後現代主義質疑宏大敘事的概念。

## 視覺藝術
### 幾個世紀以來的藝術運動
|運動|期間 |特色 |主要藝術家 |
|----------|--------|----------------|------------------------|
| **文藝復興** | 14世紀至17世紀|寫實主義、透視、解剖 |李奧納多、米開朗基羅、拉斐爾 |
| **巴洛克** |十七世紀|戲劇性的燈光，情感的強度|卡拉瓦喬、倫勃朗、貝尼尼 |
| **印象派** |十九世紀末。 |光、色彩、可見的筆觸|莫內、雷諾瓦、德加 |
| **後印象派** |十九世紀末。 |大膽的色彩、幾何圖形|梵谷、塞尚、高更 |
| **立體主義** | 20世紀初c. |幾何形狀，多視角|布拉克·畢卡索 |
| **超現實主義** | 1920 年代 – 1940 年代 |夢境意象，無意識|達利、馬格里特、弗里達·卡羅 |
| **抽象表現主義** | 20 世紀 40 年代 – 1950 年代 |自發的手勢繪畫 |波洛克、羅斯科、德庫寧 |
| **普普藝術** | 20 世紀 50 年代 – 1960 年代 |流行文化意象|沃霍爾，列支敦士登 |
| **當代** | 20 世紀 70 年代至今 |多元化媒體、概念、社會評論 |班克斯、草間彌生、艾未未 |
### 藝術媒介
繪畫（油畫、壓克力、水彩、壁畫）、素描（鉛筆、木炭、墨水）、雕塑（雕刻、建模、鑄造）、版畫（蝕刻、平版印刷、絲網印刷）、攝影（數位、電影）、數位藝術（3D 建模、生成藝術）、裝置藝術和表演藝術。

＃＃ 音樂
### 古典音樂時期
|期間 |年 |特色 |主要作曲家 |
|--------|------|----------------|------------------------|
| **中世紀** | 500–1400 |格里高利聖歌，早期複音音樂|希爾德加德·馮·賓根 |
| **文藝復興** | 1400–1600 |聲樂複音音樂、牧歌|若斯坎·德·佩雷斯·帕萊斯特里納 |
| **巴洛克** | 1600–1750 |華麗的旋律，連續低音|巴赫、亨德爾、維瓦爾第 |
| **古典** | 1750–1820 |形式平衡、清晰 |莫札特、海頓、貝多芬 |
| **浪漫** | 1820–1900 |情感表達，擴大管弦樂|蕭邦、華格納、柴可夫斯基 |
| **20 世紀/當代** | 1900 年至今 |無調性、極簡主義、實驗 |史特拉汶斯基、荀貝格、菲利普‧格拉斯 |
### 現代音樂流派
|類型 |主要特徵|著名藝術家 |
|------|----------|----------------|
| **爵士樂** |即興創作，搖擺節奏|路易斯·阿姆斯特朗、邁爾斯·戴維斯、約翰·科爾特蘭 |
| **藍調** | 12小節結構，富有表現力的人聲| B.B. King，渾水
| **搖滾** |電吉他，節奏強勁|披頭四、齊柏林飛船、涅槃 |
| **嘻哈/饒舌** |有節奏的演講、節拍、DJ 文化 |圖帕克、肯德里克拉馬爾、Jay-Z |
| **電子** |合成器，數位製作| Kraftwerk、Daft Punk、Aphex Twin |
| **國家** |民間傳統，說故事|約翰尼卡許、多莉帕頓 |
| **R&B / 靈魂樂** |動人的歌聲，律動 |艾瑞莎·富蘭克林、史蒂夫·旺德、碧昂絲 |
### 音樂理論基礎
音樂的組成部分：**音符和音階**（大調、小調、五聲音階、調式）、**和弦與和聲**（三和弦、七和弦、進行）、**節奏和韻律**（拍號、速度、切分音）、**旋律和對位法**以及**形式和結構**（奏鳴曲形式、主歌合唱、奏響樂樂樂樂曲樂曲）。

## 戲劇和電影
### 劇場
2500 多年來，劇院一直是人類說故事的舞台。主要的戲劇形式有：
|類型 |描述 |著名的例子|
|------|-------------|-----------------|
| **悲劇** |嚴肅題材，主角垮台 |希臘悲劇，莎士比亞的*哈姆雷特* |
| **喜劇** |幽默的情景，美好的結局|莎士比亞的喜劇，奧斯卡王爾德 |
| **音樂劇** |歌、舞、對白融為一體| *漢密爾頓*，*悲慘世界* |
| **前衛** |非傳統形式，觀眾參與 |實驗劇場|
主要劇作家：莎士比亞、契訶夫、田納西·威廉斯、亞瑟·米勒、塞繆爾·貝克特、奧古斯特·威爾森。

## 文學裝置
偉大的寫作需要使用一系列技巧：
|設備|它有什麼作用 |
|--------|-------------|
| **隱喻** |直接比較（「世界就是一個舞台」）|
| **明喻** |使用“like”或“as”進行比較 |
| **擬人化** |賦予非人類事物人類的品質|
| **諷刺** |期望與現實的比較 |
| **象徵意義** |代表抽象思想的對象|
| **預示** |關於未來事件的提示 |
| **不可靠的敘述者** |可信度受損的敘述者|
| **意識流** |思緒不斷流動|

## 為什麼這很重要
藝術和文學不僅僅是娛樂——它們是社會處理經驗、挑戰假設和想像替代方案的方式。一部小說可以改變輿論；一幅畫可以定義一個時代；一首歌可以成為改變的讚歌。了解塑造創意表達的傳統和運動可以讓您以更豐富的視角來理解世界。
