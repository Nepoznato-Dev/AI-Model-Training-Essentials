# 聯邦學習和隱私
聯合學習是一種跨多個設備或組織訓練機器學習模型而無需共享原始資料的技術。每個設備不將資料發送到中央伺服器，而是訓練本地模型並僅共享模型更新（梯度或權重）。中央伺服器聚合這些更新以產生全域模型。它是由Google設計的，用於訓練 Android 手機上的鍵盤語言模型 - 此後它已成為保護隱私的人工智慧的關鍵技術。
---

## 為什麼要聯邦學習？
|動機|描述 |範例|
|------------|-------------|---------|
| **資料隱私** |原始資料永遠不會離開裝置|病歷保存在醫院；照片保留在手機上|
| **監管合規性** | GDPR、HIPAA 和其他法規限制資料共享 |銀行無需共享客戶資料即可進行協作 |
| **數據量** |移動數據既昂貴又緩慢|如果必須上傳數據，那麼在數十億部手機上進行訓練是不切實際的 |
| **資料敏感度** |有些資料過於敏感，即使經過同意也無法分享 |政府情報；個人健康資料|
---

## 聯邦學習的工作原理
### 基本協定 (FedAvg)
|步驟|發生了什麼事 |
|------|-------------|
| **1.初始化** |中央伺服器建立具有隨機權重的全域模型 |
| **2.分發** |伺服器將目前全域模型傳送到選定的設備 |
| **3.本地訓練** |每個設備都會根據其本地資料訓練模型幾個時期 |
| **4.上傳** |裝置將更新後的模型權重（而非資料）傳回伺服器 |
| **5.合計** |伺服器對權重進行平均（聯合平均）以建立新的全域模型 |
| **6。重複** |返回步驟 2，直到模型收斂 |
```
Server: global_model = average(local_model_1, local_model_2, ..., local_model_n)
```

### 關鍵屬性
|物業 |描述 |
|----------|-------------|
| **非獨立同分佈資料** |每個設備的資料分佈不同（非獨立同分佈）|
| **不平衡數據** |有些設備有大量數據，有些設備則很少 |
| **部分參與** |並非所有設備在每一輪都可用 |
| **溝通效率** |瓶頸是通信，而不是計算 |

## 聯邦學習變體
|變體 |說明 |優勢 |
|--------|-------------|------------|
| **聯準會平均** |跨裝置的平均模型權重 |簡單的;適用於 IID 資料 |
| **FedProx** |為本地培訓添加最近術語 |更適合非 IID 資料 |
| **鷹架** |使用控制變數來修正資料異質性 |非獨立同分佈資料的更快收斂 |
| **聯準會新元** |與 FedAvg 類似，但每輪有一個梯度步長 |每輪通訊成本更低 |
| **個人化FL** |每台設備都與全球設備保持個性化模型 |更好的每台設備性能 |
| **垂直FL** |各方的不同特徵（不是不同的樣本）|當各方持有相同資料的不同面向時 |

## 差異隱私
差分隱私 (DP) 提供了數學保證，即演算法的輸出不會洩露是否包含任何個人的資料。
### 核心定義
如果對於任兩個資料集 D 和 D' 在一筆記錄中不同，則機制 M 滿足 (ε, δ)-差分隱私：
```
P(M(D) ∈ S) ≤ e^ε × P(M(D') ∈ S) + Î´
```

|參數|意義|
|------------|---------|
| **ε（ε）** |隱私權預算。更小=更私密。典型值：0.1–10。 |
| **δ（δ）** |隱私權保障失敗的機率。通常設定為 1/N（資料集大小的倒數）。 |
### 新增隱私的機制
|機制|它是如何運作的 |使用案例|
|------------|-------------|----------|
| **高斯機制** |新增校準到查詢靈敏度的高斯雜訊 |連續值（模型權重）|
| **拉普拉斯機制** |新增拉普拉斯雜訊 |計數查詢 |
| **指數機制** |選擇與其效用成正比的機率的輸出 |離散選擇|
### DP-SGD（差分私有隨機梯度下降）
|步驟|描述 |
|------|-------------|
| 1. 計算每個樣本的梯度 |而不是批量梯度 |
| 2.剪輯漸變|限制每個梯度的最大範數（限制任何單一樣本的影響）|
| 3.新增雜訊|將校準的高斯雜訊加入聚合梯度 |
| 4.更新參數|標準梯度下降步驟|
|權衡|描述 |
|------------|-------------|
| **隱私與準確性** |更強的隱私（更低的ε）需要更多的噪聲，這會降低模型的準確性 |
| **隱私與訓練時間** |噪音越大意味著收斂速度越慢 |
| **隱私預算追蹤** |每個訓練步驟都會消耗一些隱私預算；一旦花費，就無法收回|
---

## 將聯邦學習與差異隱私結合
|層 |保護|
|------|----------|
| **聯邦學習** |原始資料保留在設備上 |
| **差異隱私** |甚至模型更新也很吵雜，保護個人貢獻 |
| **安全性聚合** |伺服器只能看到所有更新的聚合，而不是單一更新 |
這種組合提供了強大的隱私保證：即使伺服器受到損害，它也無法確定訓練中是否使用了任何特定個人的資料。
---

## 其他隱私保護技術
### 安全多方運算 (SMPC)
多方根據其組合資料計算函數，而無需透露各自的輸入。
|特色 |描述 |
|---------|-------------|
| **它是如何運作的** |資料被分成分佈在各方之間的共享；計算發生在股票上 |
| **保證** |任何一方都不會了解其他方的輸入資訊 |
| **開銷** |大量的通訊和計算成本|
| **用例** |銀行在不共享客戶資料的情況下計算聯合風險模型|
### 同態加密 (HE)
直接對加密資料執行計算。
|類型 |它支援什麼 |開銷|
|------|-----------------|----------|
| **部分是他** |一次運算（加法或乘法）|低|
| **有點他** |兩項操作數量有限|中|
| **完全他** |任意計算 |非常高（減速 100-1000 倍）|
|應用 |描述 |
|-------------|-------------|
| **私人推論** |在加密資料上運行機器學習模型；返回加密預測 |
| **加密訓練** |訓練加密資料（對於深度學習來說仍然主要是理論上的）|
| **私人查詢** |查詢資料庫而不洩漏查詢或資料 |
### 可信任執行環境 (TEE)
基於硬體的隔離（Intel SGX、ARM Trustzone）甚至可以保護作業系統中的資料。
|優勢 |限制|
|------------|------------|
|接近原生的效能 |需要特定硬體 |
|強而有力的安全保障|記憶體有限（飛地大小）|
|無加密開銷 |可能發生旁道攻擊 |

## 隱私法規與機器學習
|監管|地區 |對機器學習的影響 |
|------------|--------|-------------|
| **GDPR** |歐盟|解釋權；資料最小化；同意處理；刪除權|
| **CCPA** |加州 |知情權、刪除權和選擇退出資料銷售的權利 |
| **健康保險流通與責任法案** |美國（醫療保健）|嚴格控制健康數據；去識別化要求 |
| **PIPL** |中國 |資料本地化；同意要求；跨境轉帳規則|
| **人工智慧法案** |歐盟|透明度要求；風險分類；禁止的做法|
### 對機器學習工作流程的影響
| GDPR 原則 |機器學習的意義 |
|----------------|------------------------|
| **資料最小化** |只收集需要的東西；聯邦學習有幫助|
| **目的限制** |未經新同意，無法重複使用資料 |
| **刪除權** |必須能夠從經過訓練的模型中刪除一個人的資料（機器取消學習）|
| **解釋權** |模型必須具有足夠的可解釋性，才能解釋個人的預測 |
| **隱私設計** |隱私必須從一開始就內建到系統中 |

## 挑戰
|挑戰|描述 |
|------------|-------------|
| **通訊費用** |在數百萬台設備上發送模型更新的成本高昂 |
| **非獨立同分佈資料** |設備的資料分佈差異很大，損害了融合 |
| **落後者** |慢速設備會延遲整輪比賽 |
| **隱私與實用性的權衡** |更強的隱私意味著更差的模型性能
| **中毒攻擊** |惡意參與者可能會破壞全球模式 |
| **模型提取** |即使共享模型更新也可能洩露有關訓練資料的資訊 |
| **硬體異質性** |不同的設備有不同的運算能力 |

＃＃ 概括
聯邦學習和隱私保護技術解決了一個根本性的矛盾：當資料是分散式的、敏感的或受監管的時候，如何建立強大的人工智慧模型？聯邦學習將資料保留在設備上並僅共享模型更新。差異隱私增加了個人貢獻無法被偵測到的數學保證。安全計算和同態加密更進一步，允許對加密資料進行計算。每種技術都有成本——通訊開銷、準確性降低、計算費用——但它們共同構成了一個工具包，用於構建尊重隱私的人工智慧，同時仍然可以從世界數據中學習。
