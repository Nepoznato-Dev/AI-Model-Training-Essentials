# 強化學習
強化學習 (RL) 是機器學習透過反覆試驗做出一系列決策的方式。與為每個範例提供正確答案的監督學習不同，強化學習僅向代理提供獎勵訊號，且代理人必須隨著時間的推移找出哪些操作會帶來最佳結果。它是 AlphaGo、機器人控制、遊戲人工智慧以及最重要的 RLHF（用於將現代大型語言模型與人類偏好保持一致的技術）背後的方法。
---

## 核心概念
強化學習將決策架構建構為**代理**和**環境**之間的循環。
|組件|角色 |範例|
|------------|------|---------|
| **代理** |決策者|國際象棋程式、機器人、語言模型 |
| **環境** |代理與之互動的世界 |棋盤、倉庫、對話|
| **狀態** |現況|棋盤位置、機器人感應器讀數、聊天記錄 |
| **行動** |代理可以做什麼 |移動一個棋子，左轉，生成一個令牌 |
| **獎勵** |回饋訊號（標量）| +1 表示獲勝，-1 表示崩潰，人類偏好分數 |
| **政策** |戰略將狀態映射到行動| “如果國王受到威脅，就移動它”|
| **價值函數** |國家的預期累積獎勵| “這個棋盤位置大約值+3分”|
### 強化學習循環
```
Agent observes State → chooses Action → Environment returns new State + Reward
        ↑                                                                         |
        └─────────────────────────────────────────────────────────────────────────┘
```

代理的目標是隨著時間的推移最大化**累積獎勵**，而不僅僅是即時獎勵。這就是強化學習與監督學習的根本差異。
---

## 與其他學習範式的主要區別
|方面|監督式學習|無監督學習 |強化學習 |
|--------------------|--------------------|---------------------|------------------------|
| **訊號** |每個範例的正確標籤 |沒有標籤；尋找結構 |標量獎勵，經常延遲 |
| **回饋** |立即 |無 |延遲且稀疏|
| **順序** |每個例子都是獨立的 |每個例子都是獨立的 |行動影響未來狀態|
| **目標** |最小化預測誤差 |發現模式 |最大化累積獎勵 |

## 馬可夫決策過程 (MDP)
MDP 是強化學習的數學框架。他們認為未來僅取決於當前狀態，而不取決於您如何到達那裡的歷史（**馬可夫屬性**）。
|組件|符號|意義|
|------------|----------|---------|
| **國家** | S |代理人可能處於的所有可能情況 |
| **行動** |一個 |代理可以做的所有事情 |
| **轉換函數** | P(s' \| s, a) | P(s' \| s, a) |在狀態 s 中採取動作 a 後到達狀態 s' 的機率 |
| **獎勵功能** | R(s, a, s') | R(s, a, s') |獲得的過渡獎勵 |
| **折扣係數** | γ（伽瑪）|未來獎勵與眼前獎勵的價值有多大（0 到 1）|
**回報**（總折扣獎勵）是：
```
G = R₁ + γR₂ + γ²R₃ + ...
```

高折扣因子（γ接近1）意味著代理人有遠見。低意味著它是短視的。

## 經典強化學習演算法
### 基於值的方法
這些學習每個狀態（或狀態-動作對）的好壞。
|演算法|關鍵理念|限制|
|------------|----------|------------|
| **Q-學習** |了解 Q 值表：Q(狀態，動作) = 預期獎勵 |無法擴展到大型狀態空間 |
| **深度 Q 網路 (DQN)** |使用神經網路來近似 Q 值 |只處理離散動作；可能不穩定 |
| **雙 DQN** |修復 Q-learning 的高估偏差 |仍僅限於離散行動|
Q-learning更新規則：
```
Q(s, a) ← Q(s, a) + α [r + γ max Q(s', a') - Q(s, a)]
```

### 基於策略的方法
這些直接學習策略（策略）而不估計值。
|演算法|關鍵理念|優勢 |
|------------|----------|------------|
| **加強** |蒙特卡羅政策梯度；更新政策以取得良好成果|簡單的;持續行動|
| **PPO**（近端策略優化）|剪輯政策更新以防止重大的、不穩定的變化|穩定的;廣泛使用；良好的預設|
| **TRPO** |策略更新的信任域方法|比PPO更有原則性；實施起來更困難|
### Actor-Critic 方法
結合兩者的優點：**參與者**（政策）和**批評家**（價值函數）。
|演算法|關鍵理念|
|------------|----------|
| **A2C / A3C** |優勢演員評論家；使用優勢估計來減少方差 |
| **SAC**（軟演員評論家）|在保持探索的同時最大化獎勵（熵正則化）|
| **TD3**（雙延遲 DDPG）|解決連續動作空間中的高估問題 |

## RLHF：根據人類回饋進行強化學習
RLHF 是使 ChatGPT 成為可能的技術。它彌合了可以預測文本的模型和產生人類實際上認為有用的輸出的模型之間的差距。
### 三個步驟
|步驟|發生了什麼 |輸出|
|------|-------------|--------|
| **1.監督微調 (SFT)** |根據高品質的人工編寫範例微調預訓練模型 |能夠很好地遵循說明的模型 |
| **2.獎勵模型訓練** |人類比較成對的模型輸出；訓練模型來預測人類偏好 |對輸出品質進行評分的獎勵模型 |
| **3.強化學習最佳化** |使用PPO微調SFT模型，最大化獎勵模型的分數 |符合人類偏好的模型 |
### 為什麼 RLHF 很重要
如果沒有 RLHF，語言模型就像一個讀過每一本書但不知道如何在對話中表現的學生。它可以生成文本，但文本可能沒有幫助、有毒或完全沒有抓住要點。 RLHF 教導模型「人類想要什麼」——而不僅僅是文本的樣子。
### 變體和替代方案
|方法|描述 |優點 |
|--------|-------------|------------|
| **DPO**（直接偏好優化）|跳過獎勵模式；直接根據人類偏好優化政策 |更簡單；沒有單獨的獎勵模型可以訓練|
| **RLAIF** |使用人工智慧（而非人類）產生偏好標籤 |比人工標記更便宜 |
| **憲法人工智慧** |使用一組原則來指導模型行為，無需人工標籤 |更具可擴展性；人擇的方法|
| **GRPO**（集團相關政策最佳化）|比較一組內的輸出，而不是與單獨的模型進行比較 |用於DeepSeek-R1；減少對價值網絡的需求|

## 探索與利用
這是強化學習的核心張力。 **利用**意味著選擇你知道行之有效的行動。 **探索**意味著嘗試新事物以發現可能更好的策略。
|战略|它是如何运作的 |权衡|
|----------|-------------|------------|
| **ε-貪婪** |大多時候選擇最好的動作；機率為 ε 的隨機行動 |簡單但低效|
| **玻爾茲曼探索** |根據估計值概率性地選擇行動 |比 ε-貪婪更平滑 |
| **UCB**（信賴上限）|偏好具有高度不確定性的行動（面對不確定性保持樂觀）|良好的理論保證|
| **熵正則化** |為訪問不同的州添加獎勵（用於 SAC、PPO） |鼓勵自然探索 |

## 多智能體強化學習
當多個智能體同時學習時，動態就會變得更加複雜。
|場景|挑戰|範例|
|----------|------------|---------|
| **合作** |代理商必須協調；學分分配很難|機器人足球隊；分佈式感測器網路|
| **有競爭力** |對手適應；環境是非平穩的 |遊戲人工智慧（撲克、星海爭霸）；網路安全 |
| **混合** |一些代理商合作，另一些代理商競爭 |拍賣市場；交通系統|
|演算法|描述 |
|------------|-------------|
| **MADDPG** | DDPG多代理版本；集中的评论家，分散的行动者|
| **MAPPO** |多智能体PPO；广泛应用于实践 |
| **自玩** |智能体针对自身副本进行训练（AlphaGo、AlphaStar）|

## 模擬到真實的傳輸
在現實世界中訓練機器人既緩慢又危險。相反，代理在模擬中進行訓練並轉移到現實中。
|挑戰|解決方案 |
|------------|----------|
| **現實差距**（模擬≠現實世界）|領域隨機化：在訓練期間改變物理參數 |
| **樣品效率低** |使用基於模型的 RL 或在大型並行模擬中進行訓練 |
| **安全** |約束強化學習：懲罰訓練期間的不安全行為 |
| **部分可觀察性** |使用噪音感測器和延遲觀測進行訓練 |
波士頓動力和特斯拉等公司廣泛使用模擬，但模擬性能和物理性能之間的差距仍然是該領域最大的挑戰之一。

## 實用技巧
- **從 PPO 開始。 ** 它是最可靠的通用演算法。如果您不確定要使用什麼，PPO 是預設值。
- **使你的獎勵正常化。 ** 獎勵比例會大大影響訓練的穩定性。
- **使用向量化環境。 ** 並行運行多個環境（例如 8-64）可以穩定梯度估計並大幅加快訓練速度。
- **同時監控獎勵和熵。 ** 如果熵降至零，則您的代理程式已停止探索並且可能陷入局部最優。
- **獎勵塑造是一門藝術。 ** 設計正確的獎勵函數通常是最困難的部分。稀疏的獎勵（僅在最後）使學習變得極其緩慢。密集、形狀良好的獎勵可以指導智能體，但可能會帶來意想不到的行為。
- **RLHF 很脆弱。 ** 獎勵模型或 PPO 超參數的微小變化可能會導致品質大幅下降。如果您不需要完整的 RLHF 管道，DPO 是更穩定的替代方案。

＃＃ 概括
強化學習是對智能體如何透過互動學習做出決策的研究。它的範圍從 Q-learning 等經典演算法到 PPO 和 SAC 等現代深度強化學習方法，並且它支撐著人工智慧領域的一些最重要的最新進展——從遊戲到語言模型對齊。核心挑戰仍然是一樣的：當回饋延遲、稀疏和嘈雜時，如何學習最佳行為？答案是在巧妙的數學指導下進行反覆試驗，結果證明這是所有人工智慧中最強大的想法之一。
