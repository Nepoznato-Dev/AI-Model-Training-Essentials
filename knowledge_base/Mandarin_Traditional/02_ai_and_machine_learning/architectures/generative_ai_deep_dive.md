# 生成式人工智慧深入研究
生成式人工智慧是指創建新內容（圖像、文字、音訊、視訊、程式碼）的模型，而不僅僅是對現有資料進行分類或預測。雖然大型語言模型受到了大部分關注，但生成式人工智慧的前景要廣闊得多。該文件涵蓋了現代生成系統背後的架構、技術和權衡，從擴散模型到變分自動編碼器再到流模型。
---

## 是什麼讓模型具有「生成性」？
|類型 |它有什麼作用 |範例|
|------|-------------|---------|
| **歧視性** |了解班級之間的界限 | “這個圖像是貓還是狗？” |
| **生成** |了解資料本身的分佈 | “生成一個新的貓形象”|
產生模型擷取*資料是如何產生的*，而不僅僅是如何對其進行分類。這使得它們從根本上變得更強大——也更難訓練。
---

## 主要生成架構
### 變分自動編碼器 (VAE)
VAE 學習資料的壓縮、結構化表示（潛在空間），然後透過從該空間取樣來產生新樣本。
|組件|角色 |
|------------|------|
| **編碼器** |將輸入資料對應到潛在空間中的分佈（平均值和變異數） |
| **潛在空間** |連續的低維度空間，其中相似的數據點靠得很近 |
| **解碼器** |將潛在空間中的點映射回資料空間 |
| **KL 散度** |正則化項使潛在分佈接近標準常態 |
**產生如何運作**：從潛在空間取樣隨機向量→將其通過解碼器→獲得新的資料點。
|實力|弱點|
|----------|----------|
|平滑、連續的潛在空間 |輸出往往是模糊的 |
|有原則的數學架構 |受架構容量限制 |
|可以在範例之間插入 |不如擴散或 GAN 輸出銳利 |
VAE 通常用作其他模型中的組件（例如，穩定擴散使用 VAE 作為其管道的一部分）。
### 生成對抗網路（GAN）
GAN 讓兩個網路相互競爭：一個產生虛假資料的**產生器**，以及一個試圖辨別真實與虛假資料的**鑑別器**。
|組件|目標|
|------------|------|
| **發電機** |產生愚弄鑑別器的資料 |
| **鑑別器** |正確分類真實資料與產生資料 |
他們同時訓練，互相推動對方進步。理論上，生成器最終會產生與真實資料無法區分的資料。
| GAN 變體 |關鍵創新|
|------------|----------------|
| **DCGAN** |卷積架構；穩定訓練|
| **StyleGAN / StyleGAN2 / StyleGAN3** |基於風格的生成；逼真的面孔；可控屬性|
| **CycleGAN** |不成對的影像轉換為影像（馬 → 斑馬）|
| **像素2像素** |配對影像到影像翻譯（草圖 → 照片）|
| **ProGAN** |高解析度影像的漸進式成長 |
| **BigGAN** |大規模類別條件產生 |
**GAN 為何衰退**：眾所周知，訓練非常不穩定（模式崩潰、梯度消失）。擴散模型現在可以為大多數影像生成任務提供更好的品質。 GAN 仍然用於即時應用程式（它們的推理速度很快）和超解析度等特定任務。
### 擴散模型
擴散模型是影像和視訊生成的最新技術。他们的工作原理是逐渐向数据中添加噪声，直到变成纯随机噪声，然后学习逆转该过程。
|相|發生了什麼事 |
|--------|-------------|
| **正向過程（訓練）** |緩慢地添加數百/數千步的高斯噪聲，直到資料被破壞 |
| **逆向過程（生成）** |逐步學習去噪，從純噪聲開始，直到出現乾淨的圖像 |
|型號|開發人員|顯著特點|
|--------|---------|-----------------|
| **DDPM**（去噪擴散機率模型）|何等人，2020 |顯示擴散模型可以產生高品質影像 |
| **穩定擴散** |穩定性人工智慧 |潛在擴散（在壓縮空間中運作）；開源 |
| **DALL-E 3** |開放人工智慧 |與 ChatGPT 整合以進行文字理解 |
| **中途** |中途 |藝術性;閉源 |
| **圖像** |Google DeepMind |高保真文字到圖像 |
| **索拉** |開放人工智慧 |透過擴散變壓器產生影片 |
| **通量** |黑森林實驗室|穩定擴散的開放重量後繼者 |
### 為什麼擴散模型獲勝
|優勢 |說明|
|------------|-------------|
| **訓練穩定性** |比 GAN 穩定得多；沒有對抗性訓練|
| **輸出品質** |最先進的影像品質和多樣性 |
| **可控制性** |可以透過文字（透過 CLIP）、修復遮罩或其他條件進行引導 |
| **多元化** |比 GAN 更少的模式崩潰；產生不同的產出 |
|缺點|說明|
|-------------|-------------|
| **推理緩慢** |需要許多去雜訊步驟（典型值為 20-50） |
| **計算密集型** |每一步都是對大型模型的完整前向傳遞 |
### 潛在擴散
在像素空間中運行擴散是昂貴的。 **潛在擴散**（由穩定擴散使用）改為在壓縮的潛在空間中運行擴散過程。
|步驟|發生了什麼事 |
|------|-------------|
| 1. 壓縮 |預先訓練的 VAE 將影像編碼為較小的潛在表示 |
| 2. 擴散|擴散模型添加/消除潛在空間中的雜訊 |
| 3. 解碼 | VAE 解碼器將潛在影像轉換回完整影像 |
這使得發電速度顯著加快、成本降低，同時維持品質。

## 文字條件生成
大多數現代生成系統都以文字提示為條件——您描述您想要的內容，然後模型生成它。
### CLIP（對比語言-影像預訓練）
CLIP 學習文字和圖像的共享嵌入空間。它接受了來自互聯網的數十億圖像文字對的訓練。
|能力|描述 |
|------------|-------------|
| **零樣本分類** |無需任何訓練即可使用文字描述對圖像進行分類 |
| **圖文檢索** |尋找與文字查詢最相關的圖像 |
| **引導擴散** |引導圖像生成朝向文字提示 |
### 無分類器指導 (CFG)
CFG 控制產生的圖像遵循文字提示的程度。
| CFG 規模 |效果|
|------------|--------|
| **1.0** |沒有指導；多樣但可能與提示不符 |
| **5.0–7.5** |均衡;良好的品質和及時的遵守|
| **10.0+** |堅持力強；可產生過飽和或偽影較多的影像

## 其他生成方法
### 流量標準化
|特色 |描述 |
|---------|-------------|
| **它是如何運作的** |學習資料和簡單分佈之間的可逆映射 |
| **實力** |精確的似然計算；快速取樣|
| **弱點** |需要精心設計的架構；不太靈活|
| **用例** |異常檢測、密度估計 |
### 自迴歸模型
|特色 |描述 |
|---------|-------------|
| **它是如何運作的** |一次產生一個元素的數據，以所有先前的元素為條件 |
| **實力** |自然的順序資料（文字、程式碼、音樂）|
| **弱點** |產生速度慢（必須是順序的）；受訓練資料分佈限制 |
| **範例** | GPT（文字）、WaveNet（音訊）、ImageGPT（圖像）|
### 基於能量的模型
|特色 |描述 |
|---------|-------------|
| **它是如何運作的** |學習能量函數；低能量=真實數據|
| **實力** |靈活的;無需標準化 |
| **弱點** |訓練困難；採樣需要MCMC |
| **用例** |理論研究；一些機器人應用|

## 評估指標
如何衡量產生數據的品質？這比你想像的還要難。
|公制|對於 |它測量什麼 |限制|
|--------|-----|-----------------|------------|
| **FID**（Fréchet 起始距離）|圖片 |真實影像分佈與生成影像分佈之間的距離 |越低越好；沒有很好地捕捉多樣性|
| **IS**（初始分數）|圖片 |生成圖像的品質和多樣性 |有爭議的;可以玩遊戲|
| **剪輯分數** |文字轉影像 |影像與文字提示的匹配程度如何？取決於 CLIP 的偏見 |
| **困惑** |文字|模型預測下一個標記的效果如何？越低越好；不衡量連貫性|
| **藍色/胭脂** |文本生成 |與參考文本重疊|人類判斷的糟糕代表
| **FAD**（Fréchet 音訊距離）|音訊|真實與產生的音訊分佈之間的距離 |類似音訊的 FID |

## 可控發電
現代系統讓您可以控制生成的內容，而不僅僅是文字提示。
|方法|控制类型 |示例|
|--------|-------------|---------|
| **修復** |填滿遮罩區域 |從照片中刪除物件 |
| **外畫** |超越圖像邊界|讓風景更寬廣 |
| **控制網** |結構指導（邊緣、深度、姿勢）|產生與特定姿勢相符的圖像 |
| **IP 適配器** |參考圖像的樣式或內容 | “讓它看起來像這幅畫”|
| **洛拉** |微調風格或概念|加入特定的角色或藝術風格 |
| **Img2Img** |轉換現有影像 |將草圖變成逼真的影像 |

## 影片生成
視訊生成是繼影像之後的下一個前沿領域。它增加了時間和運動的維度。
|型號|方法|顯著特點|
|--------|----------|-----------------|
| **索拉** (OpenAI) |擴散變壓器|高達 1080p；相當了解物理學|
| **跑道第三代** |基於擴散|商業視頻生成工具|
| **皮卡** |基於擴散|文字短視頻剪輯|
| **克林** |自回歸+擴散 |長視頻生成 |
| **Veo 2**（Google）|擴散變壓器|高品質、物理一致的影片 |
### 影片產生的挑戰
|挑戰|為什麼很難 |
|------------|--------------|
| **時間一致性** |物件在不同幀中看起來應該是相同的 |
| **物理** |重力、碰撞、流體力學必須大致正確 |
| **長度** |產生幾分鐘的連貫影片比產生單一影像困難得多 |
| **計算** |影片本質上是許多影像；成本與幀數的關係|
| **評估** |沒有標準指標可以很好地捕捉視頻品質|

## 發電經濟學
|因素|影響 |
|--------|--------|
| **培訓費用** |擴散模型：10 萬美元至 1000 萬美元以上，視規模而定 |
| **推理成本** |圖像生成：每張圖像約 0.01–0.05 美元 |
| **硬體** |訓練：多個A100/H100 GPU；推理：單 GPU 成為可能 |
| **開放式與封閉式** |開放式模型（Stable Diffusion、FLUX）可以本地運作；封閉模型（DALL-E、Midjourney）僅支援 API |

＃＃ 概括
生成式人工智慧已經從 GAN 發展到 VAE，再到擴散模型等等。所有這些架構的關鍵見解都是相同的：了解資料的分佈，然後從中取樣以建立新內容。由於其訓練穩定性和輸出質量，擴散模型目前在影像和視訊生成中佔據主導地位。 VAE 是關鍵的建置模組。自迴歸模型主導文字和程式碼。該領域正在朝著多模式生成的方向發展——可以透過任意輸入組合生成文字、圖像、音訊和視訊的系統——並朝著使生成更快、更便宜、更可控的方向發展。
