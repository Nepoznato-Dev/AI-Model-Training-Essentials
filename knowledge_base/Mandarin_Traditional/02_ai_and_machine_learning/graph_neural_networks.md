# 圖神經網絡
圖神經網路 (GNN) 是設計用於對圖結構資料進行操作的神經網絡，即透過邊連接的節點網路。傳統神經網路在網格（圖像）或序列（文字）上工作，而 GNN 可以處理任意關係結構：社交網路、分子圖、知識圖、道路網路、推薦圖等。它們對於藥物發現、詐欺偵測、推薦系統以及實體之間的關係很重要的任何領域都至關重要。
---

## 什麼是圖？
|組件|描述 |範例|
|------------|-------------|---------|
| **節點（頂點）** |實體|一個人，一個分子的原子，一座城市|
| **邊緣** |兩個節點之間的關係 |友誼、化學鍵、道路|
| **邊緣重量** |關係的強度或類型 |距離、相似度、容量 |
| **節點功能** |每個節點的屬性|年齡、原子序數、人口|
| **邊緣特徵** |每條邊的屬性 |關係類型、距離 |
| **鄰接矩陣** |矩陣 A，其中 A[i][j] = 1，如果節點 i 和 j 連接 |
### 圖表的類型
|類型 |描述 |範例|
|------|-------------|---------|
| **無指引** |邊緣沒有方向 |友情網|
| **導演** |邊有方向 (A→B ≠ B→A) |推特追蹤者 |
| **加權** |邊有數值 |道路網絡與距離|
| **異質** |多種節點與邊緣類型 |學術圖表（論文、作者、地點）|
| **動態** |圖結構隨時間變化 |社交網絡隨著時間的推移而發展|
| **雙方** |兩種類型的節點；邊緣僅在類型之間 |使用者-專案推薦圖 |
---

## 為什麼不使用常規神經網路？
|方法|為什麼失敗 |
|----------|-------------|
| **前饋網路** |需要固定大小的輸入；圖表的大小和結構各不相同 |
| **美國有線電視新聞網** |假設網格結構；圖表沒有規則的網格 |
| **RNN/變壓器** |假設順序；圖沒有自然順序 |
GNN 透過直接在圖結構上操作、在其鄰居的上下文中處理每個節點來解決這個問題。
---

## 核心 GNN 架構
### 訊息傳遞框架
大多數 GNN 遵循相同的模式：每個節點從其鄰居收集信息，組合信息，並更新自己的表示。
|步驟|描述 |
|------|-------------|
| **1.留言** |每個節點向其鄰居發送訊息（基於其當前功能）|
| **2.合計** |每個節點收集並組合來自所有鄰居的訊息 |
| **3.更新** |每個節點使用聚合訊息更新自己的表示 |
| **4.重複** |對 K 層執行此操作→每個節點捕獲 K 跳之外的資訊 |
### 關鍵 GNN 模型
|型號|聚合方法|關鍵創新|
|--------|--------------------------------|----------------|
| **GCN**（圖卷積網絡）|鄰居特徵的平均值 |簡單的;有效的;光譜動機|
| **GraphSAGE** |樣本和聚合；可以使用平均值、LSTM 或池化 |歸納（處理看不見的節點）；可擴展 |
| **GAT**（圖注意力網）|注意力加權鄰居聚合 |了解哪些鄰居最重要 |
| **GIN**（圖同構網絡）|鄰居特徵總和 |最大限度地表達；可以區分任何可透過 WL 測試區分的圖 |
| **MPNN**（訊息傳遞神經網路）|通用訊息傳遞框架|統一許多 GNN 變體 |
### GCN 的工作原理（一步一步）
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

經過 K 層後，每個節點的表示對圖中距離 K 跳的資訊進行編碼。

## 圖表級任務
|任務|描述 |範例|
|------|-------------|---------|
| **節點分類** |預測每個節點的標籤 |將使用者分類為機器人或人類 |
| **連結預測** |預測邊緣是否存在（或將存在） |預測缺失的關係；建議連結 |
| **圖分類** |預測整個圖的標籤 |將分子分類為有毒或無毒 |
| **社區偵測** |尋找密集連結節點的群集 |辨識社會群體 |
| **圖形生成** |產生具有所需屬性的新圖表 |設計新分子|
---

## 應用
### 藥物發現與分子特性預測
|任務| GNN 如何提供幫助 |
|------|--------------|
| **分子性質預測** |將分子表示為圖（原子=節點，鍵=邊）；預測毒性、溶解度、結合親和力 |
| **藥物間交互作用** |將藥物和標靶建模為圖表；預測不良交互作用|
| **從頭藥物設計** |產生具有所需特性的新穎分子圖 |
### 推薦系統
|方法|描述 |
|----------|-------------|
| **使用者-專案圖** |使用者和物品都是節點；購買/觀看是優勢 |
| **基於圖的協同過濾** | GNN 透過圖傳播偏好 |
| **知識圖譜推薦** |將使用者偏好與專案知識（類型、演員、導演）結合 |
### 詐欺偵測
|應用 |圖結構|
|-------------|----------------|
| **財務詐欺** |交易形成圖表；詐欺模式以子圖結構的形式出現
| **保險詐欺** |索賠人、提供者和保單形成一個圖表；詐騙團夥被發現|
| **帳號接管** |登入模式形成圖表；異常連線訊號洩漏|
### 知識圖譜
|任務|說明 |
|------|-------------|
| **連結預測** |預測缺失的事實（例如，「巴黎是…的首都？」）|
| **實體解析** |判斷兩個提及是否指的是同一實體 |
| **問答** |瀏覽圖表尋找答案 |

## 進階 GNN 概念
### 過度平滑
|問題 |說明 |解決方案 |
|---------|-------------|----------|
| **過度平滑** |經過許多層後，所有節點表示都變得相似 |限制深度（2-4層）；使用剩餘連接；使用跳躍知識|
### 過度擠壓
|問題 |說明 |解決方案 |
|---------|-------------|----------|
| **過度擠壓** |來自遠端節點的資訊被壓縮為固定大小的向量 |使用圖形轉換器；分層池|
### 圖形轉換器
|型號|主要特點|
|--------|-------------|
| **圖形轉換器** |將標準 Transformer 注意力應用於所有節點對 |
| **GPS**（圖形提示系統）|將局部 GNN 層與全域 Transformer 層結合 |
| **繪圖師** |新增基於圖結構的位置編碼 |
### 異構圖網絡
|型號|描述 |
|--------|-------------|
| **R-GCN** |關係型GCN；不同邊緣類型的不同權重矩陣|
| **韓** |異質注意力網；注意不同的節點和邊類型 |
| **HetGNN** |異構圖神經網路；處理多種節點類型 |

|挑戰|解決方案 |

| **記憶體** |跨 GPU 的圖形分割區 |
| **速度** |稀疏矩陣運算；專業圖書館|
### 抽樣策略
|戰略|描述 |
|----------|-------------|
| **節點取樣** |對節點子集及其 K 跳鄰域進行取樣 |
| **邊緣取樣** |範例邊及其連接的節點 |
| **聚類抽樣** |將圖形分割為簇；群集訓練 |
| **隨機遊走採樣** |透過從目標節點隨機遊走的樣本節點 |

＃＃ 概括
圖神經網路將深度學習擴展到關係資料—網路、分子、知識圖以及任何實體連結的系統。它們透過在鄰居之間傳遞訊息來工作，允許每個節點從其本地上下文中學習。 GNN 在藥物發現、推薦系統、詐欺偵測和知識圖譜中找到了最強大的應用。該領域正在朝著圖轉換器、異構圖和大規模現實網路的可擴展訓練方向發展。如果您的資料有關係，GNN 可能值得考慮。
