# 人工智慧道德與治理
人工智慧系統不是中立的。它們反映了接受培訓的數據、創建者的價值觀以及部署它們的組織的激勵措施。道德不只是問「我們能建造這個嗎？」但「我們應該嗎？」治理就是建立法律、標準、監督機構等結構，以確保人工智慧的開發和使用是負責任的。該文件涵蓋了人工智慧的關鍵道德維度以及為解決這些問題而出現的治理框架。
---

## 人工智慧的核心道德原則
大多數人工智慧道德框架都遵循一組共同原則。
|原理|這意味著什麼？挑戰|
|------------|--------------|------------|
| **公平** |人工智慧不應歧視受保護群體 |從數學上定義公平是非常困難的。不同的公平定義存在衝突|
| **透明度** |用戶應該知道他們何時與人工智慧互動以及它是如何工作的 |完全透明可以進行遊戲；專有系統拒絕披露|
| **責任** |當人工智慧造成傷害時，必須有人負責 |將責任分散到開發人員、部署人員和使用者之間 |
| **隱私** |人工智慧應尊重個人資料和自主權 |訓練資料通常包括個人資訊；隱私與實用的衝突|
| **安全** |人工智慧不應造成身體或心理傷害|傷害的定義取決於具體情況；邊緣情況是不可預測的 |
| **人類監督** |人類應該保留有意義的控制|自動化偏見意味著人類服從人工智慧；監督變成橡皮圖章|

## 人工智慧系統中的偏見
### 偏見從何而來
|來源 |描述 |範例|
|--------|-------------|---------|
| **訓練資料** |資料中編碼的歷史偏差|招募資料反映了過去的歧視→模型歧視|
| **標籤偏差** |人類註釋者強加他們的偏見帶有“女性”名字的簡歷被註釋者評分較低
| **選擇偏差** |資料不代表目標族群|臉部辨識主要針對淺膚色臉孔進行訓練
| **測量偏差** |受保護屬性的功能代理 |郵遞區號與種族相關
| **演算法偏差** |優化放大了小偏差 |訓練資料中的小差距會成為預測中的大差距|
### 公平性指標
|公制|定義 |何時使用 |
|--------|------------|-------------|
| **人口平等** |各組陽性率相等 |當您想要平等的結果時 |
| **均等賠率** |各組的真陽性率和假陽性率相等 |當您想要相同的錯誤率時 |
| **預測平價** |各組的精度相同 |當您希望預測對所有群體都具有相同的意義時 |
| **個人公平** |相似的人受到相似的對待|當您想要一致性時 |
**不可能性定理**：通常無法同時滿足多個公平性定義。選擇使用哪一種公平指標本身就是價值判斷。
### 減少偏見
|舞台|技術|
|------|----------|
| **預處理** |重新平衡訓練資料；刪除有偏見的特徵；合成過採樣|
| **處理中** |為損失函數添加公平約束；對抗性去偏見|
| **後處理** |調整每組的閾值；校準預測|
| **評估** |定期公平性審核；分類績效指標|

## 可解釋性
### 為什麼可解釋性很重要
|原因 |描述 |
|--------|-------------|
| **信任** |使用者需要了解為什麼要做決定 |
| **調試** |開發人員需要尋找並修復模型錯誤 |
| **監管** | GDPR 的「解釋權」；歐盟人工智慧法案要求 |
| **公平** |如果不了解模型行為，就無法偵測偏差 |
| **責任** |組織需要證明自動化決策的合理性|
### 解釋方法
|方法|類型 |它是如何運作的 |限制|
|--------|------|-------------|------------|
| **形状** |特征重要性|使用博弈论估计每个特征的贡献 |计算成本昂贵；近似值|
| **石灰** |本地代孕 |围绕预测拟合一个简单模型 |不稳定；不反映实际的模型逻辑 |
| **注意力可视化** |内部机制|显示模型关注哪些输入 |关注≠重要性；可能会产生误导 |
| **反事实** |假设分析| “如果这个特征不同，预测会改变吗？” |取决于现实的反事实|
| **特征归因** |重要性分数 |显着图、积分梯度 |没有解释*为什么*；就在*哪里* |

## 人工智慧監管
### 歐盟人工智慧法案 (2026)
全球首部綜合性人工智慧法。
|風險等級|範例 |要求|
|------------|----------|----------|
| **不可接受的風險** |社會評分；潛意識操縱；即時生物辨識監控（有例外）|禁止 |
| **高風險** |醫療人工智慧；自動駕駛汽車；執法;關鍵基礎設施|合格評定；人為監督；透明度|
| **風險有限** |聊天機器人；深度造假；推薦系統|必須揭露人工智慧的參與 |
| **風險最小** |垃圾郵件過濾器；視頻遊戲；大多數人工智慧應用|無具體要求 |
### 其他監管方法
|地區 |方法|狀態 |
|--------|----------|--------|
| **美國** |特定行業；行政命令；自願承諾|支離破碎；沒有全面的聯邦法律|
| **英國** |以原則為基礎；產業監管機構|人工智慧安全研究所；支持創新的方法|
| **中國** |生成式人工智慧、深度造假、建議的具體規定 |積極執法；內容要求|
| **加拿大** | AIDA（人工智慧和數據法案）|建議的;類似於歐盟的做法|
| **巴西** |人工智慧監管框架|進行中 |

## 環境影響
訓練和運行人工智慧模型會消耗能源並產生碳排放。
|活動 |預計排放量|比較|
|----------|--------------------|------------|
| **訓練 GPT-4** |估計排放超過 50 噸二氧化碳 |相當於幾輛汽車的年排放量|
| **訓練大型 Transformer** | 280-620 噸二氧化碳 |汽車終身排放量的 5 倍 |
| **每日推理（100 萬用戶）** |正在進行；取決於型號尺寸和硬體|隨著時間的推移可能會超過訓練排放量 |
| **微調 7B 模型** | 1-5 噸二氧化碳 |顯著但比預訓練少很多 |
### 緩解措施
|戰略|影響 |
|----------|--------|
| **高效率的硬體** |新型 GPU 每次運算的能源效率更高 |
| **模型最佳化** |較小的量化模型使用較少的能量 |
| **綠色能源** |使用再生能源為資料中心供電|
| **高效架構** |專家組合；稀疏模型；蒸餾|
| **碳意識調度** |當網格最乾淨時進行訓練 |

## 智慧財產權和版權
|問題 |描述 |狀態 |
|--------|-------------|--------|
| **版權作品訓練** |未經許可使用書籍、文章、圖像訓練模式 |積極的訴訟；合理使用辯論|
| **人工智慧產生的輸出** |誰擁有人工智慧產生的內容？ |美國版權局：如果沒有足夠的人類作者，人工智慧產生的內容不受版權保護
| **風格模仿** |人工智慧可以模仿藝術家的風格 |法律上是灰色的；道德問題|
| **選擇退出機制** |一些提供者允許創作者選擇退出培訓 |機器人.txt；內容過濾 |

## 負責任的揭露
|原理|說明 |
|------------|-------------|
| **部署前測試** |發布前的紅隊、偏見審核、安全評估 |
| **逐步部署** |從有限的訪問開始；隨著安全性得到證實而擴大|
| **事件報告** |記錄並分享有關失敗和危害的資訊 |
| **錯誤賞金** |獎勵發現漏洞的外部研究人員 |
| **模型卡** |記錄模型的功能、限制與預期用途 |

## 實用道德框架
### 對於人工智慧開發者
|問題 |為什麼這很重要？
|----------|--------------|
| **誰可能會受到該系統的傷害？ ** |確定受影響的利害關係人 |
| **如果模型錯誤會發生什麼事？ ** |評估錯誤的成本 |
| **模型的決策可以解釋一下嗎？ ** |確定可解釋性要求 |
| **訓練資料是否具代表性？ ** |檢查選擇與測量偏差 |
| **故障模式有哪些？ ** |預測邊緣情況與濫用 |
| **如何監控系統？ ** |持續監督計劃|
### 對於部署人工智慧的組織
|實踐|描述 |
|----------|-------------|
| **人工智慧治理委員會** |跨職能團隊審查人工智慧部署 |
| **影響評估** |部署前評估潛在危害 |
| **人工監督流程** |當人工智慧出錯時清除升級路徑 |
| **定期審核** |檢查是否有偏見、漂移和意外後果 |
| **使用者回饋管道** |允許受影響的人回報問題|
| **文檔** |維護模型決策和理由的記錄 |

＃＃ 概括
人工智慧道德和治理不是事後的想法——它們是工程要求。偏見、不透明、環境成本和侵犯隱私不僅僅是道德問題；它們是對真實的人造成真正傷害的錯誤。治理格局正在迅速發展，歐盟人工智慧法案設定了全球標準。但僅靠監管還不夠。每個人工智慧開發人員都需要在日常工作中考慮公平性、可解釋性和問責制。問題不在於人工智慧是否該被治理，而是如何建構值得信任的系統。
