# 語音和音訊處理
語音和音訊處理涵蓋了讓機器聽到、理解、產生和操縱聲音的技術。這包括語音辨識（將口語單字轉換為文字）、語音合成（將文字轉換為口語單字）、說話者辨識、音樂生成和環境聲音理解。深度學習已經改變了這個領域——現代系統的語音辨識精度達到了人類水平，並產生出奇自然的合成聲音。
---

## 數位音訊基礎知識
聲音是一種壓力波。為了以數位方式處理它，我們定期對波進行採樣。
|概念 |描述 |典型值|
|--------|-------------|---------------|
| **取樣率** |每秒測量聲音多少次 | 8 kHz（電話）、16 kHz（語音）、44.1 kHz（CD）、48 kHz（專業）|
| **位元深度** |每個樣品的精確度 | 16 位元（CD）、24 位元（專業）、32 位元浮點（處理）|
| **頻道** |單聲道 (1)、立體聲 (2)、環繞聲 (5.1、7.1) |音樂立體聲；單聲道語音 |
| **持續時間** |音訊長度 |變更 |
1 分鐘單聲道錄音，頻率為 16 kHz，16 位元 = 1.92 MB。一首 3 分鐘的立體聲歌曲，44.1 kHz，16 位元 = 30.3 MB。

## 音訊特徵提取
原始音訊波形很難讓模型直接使用。我們提取捕捉聲音重要特徵的特徵。
|特色 |它捕捉了什麼 |使用案例|
|------|----------------|----------|
| **梅爾譜圖** |隨時間變化的頻率內容，映射到人類聽覺感知 |語音識別、音樂分類|
| **MFCC**（梅爾頻率倒譜係數）|頻譜包絡的緊湊表示 |傳統語音辨識 |
| **色譜圖** |音高分佈（正在播放哪些音符）|音樂分析、和弦偵測 |
| **過零度** |訊號過零的頻率 |濁音與清音偵測 |
| **均方根能量** |隨時間變化的訊號響度|語音活動偵測 |
| **俯仰 (F0)** |基頻|說話者辨識、音樂轉錄 |
### 梅爾頻譜圖
深度學習最常見的音訊表示。它將音訊轉換為類似 2D 影像的格式：
|軸|代表|
|------|------------|
| **X 軸** |時間 |
| **Y 軸** |頻率（梅爾等級 - 感知間隔）|
| **顏色/強度** |在該頻率和時間的能量|
梅爾音階近似於人類的聽力：我們比高頻更擅長區分低頻。

## 自動語音辨識 (ASR)
ASR 將口語轉換為文字。它是音訊人工智慧最重要的商業應用之一。
### ASR 的演變
|時代|方法|限制|
|-----|----------|------------|
| **2010 年以前** |隱馬可夫模型+高斯混合模型|需要大量的手工工程；噪音條件下較差|
| **2010-2015** | DNN-HMM 混合 |神經網路取代了 GMM；顯著改善|
| **2015-2020** |端對端模型（深度語音、LAS）|從音訊到文字的單一神經網路 |
| **2020+** |基於 Transformer（Whisper、Conformer）|最先進的精度；多種語言;堅固耐用 |
### 關鍵 ASR 模型
|型號|建築|培訓數據|顯著特點|
|--------|-------------|------------------------|-----------------|
| **耳語** (OpenAI) |編碼器-解碼器變壓器| 680,000 小時，99 種語言 |多種語言;對口音和噪音具有穩健性；開源 |
| **符合者** |卷積+自註意力|各種|結合局部（轉換）與全局（注意力）特徵 |
| **wav2vec 2.0** |自我監督變壓器 |未標記的言論 |從原始音頻中學習，無需轉錄 |
| **USM**（Google）|通用語音模型 | 200 萬小時，300 多種語言 |涵蓋的大多數語言 |
| **彩信**（元）|大規模多語語音 | 1,400 多種語言 |將覆蓋範圍擴展到資源匱乏的語言 |
### ASR 指標
|公制|描述 |
|--------|-------------|
| **WER**（字錯誤率）|錯誤轉錄的單字百分比。越低越好。對於乾淨的英語，人類的表現約為 4-5%。 |
| **CER**（字元錯誤率）|與 WER 相同，但在角色層級。用於沒有單字邊界的語言（中文、日文）。 |
### 常見的 ASR 挑戰
|挑戰|描述 |
|------------|-------------|
| **口音和方言** |對於非標準口音，表現顯著下降 |
| **背景噪音** |音樂、交通、其他說話者會降低準確度 |
| **代碼轉換** |說話者在句子中間切換語言 |
| **同音字** | 「那裡」與「他們的」與「他們是」－需要上下文 |
| **標點符號和格式** | ASR 輸出通常不加標點；需要後製 |
| **低資源語言** |大多數模型對於訓練資料很少的語言表現不佳

## 文字轉語音 (TTS)
TTS 將書面文字轉換為語音音訊。現代系統產生的語音通常與人類錄音無法區分。
### TTS 的演變
|時代|方法|品質 |
|-----|----------|---------|
| **2010 年以前** |連結（拼接記錄的片段）|機器人；表達能力有限|
| **2010-2017** |統計參數（HMM、早期神經網路）|更好，但仍可被識別為合成的 |
| **2017-2020** |神經網路（Tacotron、WaveNet）|接近人類的品質；富有表現力|
| **2020+** |神經編解碼器（VALL-E、Bark）|語音克隆；少射；高度自然 |
### 關鍵 TTS 模型
|型號|建築|顯著特點|
|--------|-------------|-----------------|
| **WaveNet** (DeepMind) |自回歸生成模型 |第一個真正聽起來自然的 TTS |
| **Tacotron 2**（Google）| Seq2seq + 聲碼器 |端到端；高品質|
| **維特** |變分推理+對抗訓練 |快速地;品質好；廣泛應用|
| **VALL-E**（微軟）|神經編解碼器語言模型 |從 3 秒樣本克隆聲音 |
| **樹皮** (Suno) |基於變壓器|多種語言;非言語聲音（笑聲、音樂） |
| **十一實驗室** |商業|業界領先的語音克隆|
| **聊天TTS** |開源|針對對話式語音進行了最佳化 |
| **魚語** |開源|快速地;多語言 |
### 語音克隆
語音克隆可以從短音訊樣本中創建聽起來像特定人的合成語音。
|方法|所需資料|品質 |
|--------|------------|---------|
| **微調** | 10-60 分鐘演講 |高品質;特定於演講者 |
| **少射** | 3-30 秒演講 |品質好；快速設定 |
| **零射擊** |沒有目標說話者資料 |在推理時使用參考音訊 |
**道德問題**：語音複製可用於冒充、詐欺和深度偽造。大多數商業提供者都需要語音同意。

## 實用技巧
- **始終聆聽您的數據。 ** 在进行任何训练之前，请聆听示例音频。注意采样率、噪声水平和扬声器特性。
- **匹配采样率。 ** Whisper 預計為 16 kHz。如果您的音频为 44.1 kHz，请对其重新采样 - 但请注意，下采样会丢失信息。
- **增強音訊資料。 ** 添加背景噪音，改变速度和音调，模拟不同的麦克风。這極大地提高了魯棒性。
- **使用預先訓練的模型。 ** 用于 ASR 的 Whisper 和用于 TTS 的 VITS/Bark 是很好的起点。微調幾乎總是比從頭開始訓練好。
- **处理静音。 ** 语音活动检测 (VAD) 在处理之前消除静音，从而节省计算量并提高准确性。 Silero VAD 和 WebRTC VAD 是受歡迎的選擇。
- **标准化音量。 **不同的录音具有非常不同的响度级别。處理前標準化至一致的水平。

＃＃ 概括
深度學習徹底改變了語音和音訊處理。 Whisper 等現代 ASR 系統在數十種語言中都達到了人類層面的準確性。 TTS 系統產生的語音與人類錄音越來越難以區分。語音克隆可以從幾秒鐘的音訊開始。音樂生成、來源分離和環境聲音檢測都在快速發展。该领域面临着持续的挑战——资源匮乏的语言、嘈杂的环境、语音克隆的伦理问题——但发展轨迹是明确的：机器在听觉、理解和产生声音方面正变得和人类一样好。
