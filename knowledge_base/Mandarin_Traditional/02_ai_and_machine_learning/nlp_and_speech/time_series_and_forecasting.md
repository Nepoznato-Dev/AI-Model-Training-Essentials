# 時間序列與預測
時間序列資料是隨時間推移收集的任何資料：股票價格、溫度讀數、網站流量、銷售資料、心率監測器、能源消耗。預測是指根據過去的模式預測未來的價值。它是資料科學最有實際價值的應用之一，也是最困難的應用之一，因為未來確實是不確定的，而現實世界的時間序列充滿了雜訊、季節性和結構性中斷。
---

## 時間序列的特徵
|組件|描述 |範例|
|------------|-------------|---------|
| **趨勢** |長期增減|數十年來全球氣溫不斷上升
| **季節性** |固定時間間隔內有規律、可預測的模式 |每年 12 月零售額激增 |
| **週期性** |以非固定間隔波動（通常是經濟波動） |每5-10年就會出現一次衰退|
| **噪音（殘餘）** |無法解釋的隨機變化 |每日股價走勢|
| **自相關** |目前值取決於過去值 |今天的氣溫與昨天相似 |
### 平穩性
如果時間序列的統計屬性（平均值、變異數）不隨時間變化，則該時間序列是**平穩的**。大多數預測方法都假設平穩性。
|測試|目的|
|------|---------|
| **增強迪基-富勒 (ADF)** |測試單位根是否存在（非平穩） |
| **KPSS 測試** |測試該系列是否趨勢平穩 |
|轉型|何時使用 |
|----------------|-------------|
| **差異** |刪除趨勢： y'(t) = y(t) - y(t-1) |
| **對數轉換** |穩定變異數（指數成長）|
| **季節性差異** |消除季節性： y'(t) = y(t) - y(t-s) 其中 s 是季節長度 |

## 經典預測方法
### 移動平均線
|方法|描述 |最適合 |
|--------|-------------|----------|
| **簡單移動平均線 (SMA)** |最後 N 個觀測值的平均值 |平滑雜訊資料 |
| **加權移動平均線** |最近的觀察結果獲得更高的權重 |當最新數據更重要時 |
| **指數移動平均線 (EMA)** |重量呈指數下降|以較少的滯後追蹤趨勢 |
### 指數平滑
|方法|元件|使用案例|
|--------|------------|----------|
| **簡單（SES）** |僅限等級 |無趨勢，無季節性 |
| **霍爾特（雙人房）** |水平+趨勢|數據有趨勢但無季節性 |
| **霍爾特-溫特斯（三重）** |水平+趨勢+季節性 |具有趨勢和季節性的數據 |
### ARIMA 及其變體
ARIMA（自迴歸綜合移動平均線）是經典時間序列預測的主力。
|組件|意義|參數|
|------------|---------|------------|
| **AR (p)** |對先前的 p 值進行迴歸 |使用多少個過去的值|
| **我（d）** |使平穩的差分步驟數 |相差多少倍|
| **MA (q)** |將錯誤建模為過去錯誤的組合 |使用多少過去的錯誤|
|變體 |擴充|使用案例|
|--------|------------|----------|
| **薩裡瑪** |加入季節性成分（P、D、Q、s）|資料季節性較強|
| **阿里麥克斯** |新增外部變數 |當您了解即將舉行的活動時 |
| **VAR** |多元 ARIMA；多個相互依存的系列|當變數相互影響時|

## 現代機器學習方法
### 基於 LSTM 和 RNN 的模型
|型號|建築|優勢 |
|--------|-------------|------------|
| **LSTM** |長短期記憶網絡|捕捉遠程時間依賴性 |
| **格魯** |門控循環單元（更簡單的 LSTM）|更快的訓練；類似的表現 |
| **Seq2Seq** |時間序列的編碼器-解碼器 |靈活的輸入/輸出長度|
| **時間卷積網（TCN）** |擴張因果卷積 |並行訓練；長感受野|
### 先知（元）
專為業務時間序列設計的實用預測工具。
|特色 |描述 |
|---------|-------------|
| **分解** |趨勢+季節性+假期|
| **靈活** |處理缺失資料、異常值與結構斷裂 |
| **可解釋** |組件是人類可讀的 |
| **自動** |合理的預設值；需要最少的調整|
|實力|限制|
|----------|------------|
|非常適合業務指標（銷售額、用戶）|對於高頻數據來說並不理想 |
|處理假期和特殊活動|假設加法或乘法季節性 |
|對異常值具有穩健性 |對於複雜模式的準確度不如深度學習 |
### 基於 Transformer 的模型
|型號|主要特點|
|--------|-------------|
| **線人** | ProbSparse 對長序列的關注 |
| **自動成型機** |級數分解的自相關機制|
| **補丁TST** |修補時間序列；頻道無關|
| **TimesFM**（Google）|時間序列的基礎模型；對不同資料進行預訓練 |
| **Chronos**（亞馬遜）|對時間序列進行標記；使用LLM風格的架構|

## 時間序列中的異常檢測
檢測偏離預期行為的異常模式。
|方法|方法|使用案例|
|--------|----------|----------|
| **統計** | Z 分數、IQR、控制圖 |簡單易懂|
| **隔離森林** |基於樹；透過隨機分區隔離異常 |多變量異常檢測 |
| **LOF**（局部異常值因子）|基於密度；與鄰居比較本地密度 |當異常出現在低密度區域時 |
| **自動編碼器** |重建錯誤；高錯誤 = 異常 |複雜的非線性模式 |
| **基於 LSTM** |預測下一步；大的預測誤差=異常|連續異常 |
### 應用程式
|網域 |異常意味著什麼？
|--------|--------------------|
| **金融** |詐欺、市場崩盤、閃電崩盤 |
| **醫療保健** |心率異常、癲癇發作 |
| **製造** |設備故障、品質缺陷|
| **網路安全** |入侵嘗試、DDoS 攻擊 |
| **基礎架構** |伺服器過載、網路故障|

## 評估指標
|公制|公式（概念）|何時使用 |
|--------|---------------------|-------------|
| **MAE**（平均絕對誤差）|絕對誤差的平均值|可解釋；與數據相同的單位 |
| **RMSE**（均方根誤差）|平均平方誤差的平方根 |大錯誤處罰更多 |
| **MAPE**（平均絕對百分比誤差）|絕對百分比誤差的平均值 |當相對誤差很重要時 |
| **SMAPE**（對稱 MAPE）| MAPE 的對稱版本 |更好地處理接近零的值 |
| **MASE**（平均絕對標度誤差）| MAE 相對於天真的預測 |不同系列的比較|

## 實際工作流程
|步驟|描述 |
|------|-------------|
| **1.探索** |繪製系列圖；識別趨勢、季節性、異常值 |
| **2.分解** |分為趨勢、季節性和殘餘成分 |
| **3.靜止** |如果需要，應用差分或變換 |
| **4.分裂** |基於時間的分割（時間序列絕不隨機分割）|
| **5.基線** |從天真的預測開始（最後一個值，季節性天真）|
| **6。型號** |嘗試經典方法（ARIMA、Prophet），然後嘗試 ML 方法 |
| **7.評估** |使用適當的指標；與基準比較|
| **8.迭代** |新增功能、嘗試不同的模型、調整超參數 |

＃＃ 概括
時間序列預測將經典統計與現代機器學習結合。經典方法（ARIMA、指數平滑、Prophet）可解釋、快速且通常準確。深度學習方法（LSTM、Transformers）捕捉複雜模式，但需要更多資料和調整。無論採用何種方法，關鍵原則都是相同的：了解資料的結構（趨勢、季節性、雜訊）、與簡單的基準進行比較、使用適當的指標進行評估，並考慮到未來不會完全複製過去的事實。
