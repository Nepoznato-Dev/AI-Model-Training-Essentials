# NLP 基礎知識
自然語言處理 (NLP) 是教導機器理解、產生和使用人類語言的領域。它為搜尋引擎、聊天機器人、翻譯系統、情感分析和大型語言模型 (LLM) 提供支持，這些模型自 2020 年以來已經改變了人工智慧。該文件涵蓋了從經典技術到基於 Transformer 的現代架構的演進。
---

## 文字預處理
原始文本很混亂。在模型可以使用它之前，需要對其進行清理和結構化。
|步驟|它有什麼作用 |範例|
|------|-------------|---------|
| **代幣化** |將文字拆分為標記（單字、子單字或字元）| “我愛 NLP” →`["I", "love", "NLP"]`|
| **小寫** |轉為小寫 | “你好”→“你好”|
| **停用字刪除** |刪除常用字（the、is、at）| 「貓坐著」→「貓坐著」|
| **詞幹** |砍掉詞尾（粗略）| 「運行」→「運行」 |
| **詞形還原** |簡化為字典形式（上下文感知）| “更好”→“好”|
| **標準化** |修復編碼、刪除特殊字元、展開縮寫 | “不要”→“不要” |
現代 Transformer 模型經常跳過停用詞刪除和詞幹提取——它們從資料中學習這些模式。

## 文字表示
機器需要數字，而不是文字。我們如何將文字表示為向量是基礎。
### 經典方法
|方法|描述 |限制|
|--------|-------------|------------|
| **One-Hot 編碼** |每個單字都是一個巨大向量中的唯一位置 |疏;無語義 |
| **詞袋 (BoW)** |統計詞頻；忽略順序 |完全失去詞序 |
| **TF-IDF** |按文檔中的頻率 × 語料庫中的稀有度對單字進行加權 |仍然忽略順序和上下文 |
### 字嵌入
嵌入將單字映射到密集向量，其中相似的單字靠近在一起。
|型號|關鍵理念|
|--------|----------|
| **Word2Vec** (2013) |根據上下文預測單字 (CBOW) 或根據單字上下文預測單字 (Skip-gram) |
| **手套** (2014) |全域共現統計→稠密向量|
| **快速文字** (2016) | Word2Vec + 子字資訊（更好地處理稀有字） |
著名的例子：`king - man + woman ≈ queen`。嵌入捕獲語義關係。
**限制**：經典嵌入為每個單字分配一個向量，因此它們無法處理一詞多義（具有多種含義的單字）。 「河岸」和「銀行帳戶」中的「銀行」獲得相同的向量。

## 序列模型
在 Transformer 出現之前，NLP 的標準方法是按順序處理文字。
|建築|它是如何運作的 |實力|弱點|
|----------|-------------|----------|----------|
| **RNN** |一次處理一個令牌；保持隱藏狀態 |處理可變長度輸入 |梯度消失；無法捕獲長依賴關係|
| **LSTM** | RNN 帶有門（遺忘、輸入、輸出）來控制資訊流 |更擅長遠端依賴 |仍然是連續的；訓練慢|
| **格魯** |簡化的 LSTM（更少的門）|比 LSTM 更快；類似的表現 |相同的基本限制|
這些模型從左到右處理文本，這意味著它們訓練速度很慢（無法並行）並且難以應對遠端依賴性。
---

## 注意力機制
注意力機制讓模型同時查看序列中的所有位置，並決定哪些位置與目前預測最相關。
### 關鍵見解
注意力機制不是將整個句子壓縮為單一隱藏狀態（如 RNN 那樣），而是計算所有隱藏狀態的加權和，並在其中學習權重。
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

|組件|角色 |
|------------|------|
| **查詢（Q）** |我在尋找什麼？ |
| **鍵 (K)** |我包含什麼？ |
| **值（V）** |我提供什麼資訊？ |
| **√d_k** |防止大點積的縮放因子 |
---

## Transformer 架構
Transformer（Vaswani 等人，2017 年——「Attention Is All You Need」）完全用注意力取代了復發。它幾乎是所有現代 NLP 的基礎。
＃＃＃ 建築學
|組件|描述 |
|------------|-------------|
| **編碼器** |讀取輸入文字；產生上下文表徵 |
| **解碼器** |產生輸出文字；專注於編碼器輸出 |
| **自我關注** |每個令牌以相同的順序關注所有其他令牌 |
| **多頭注意力** |並行運行多個注意力頭；捕捉不同的關係|
| **位置編碼** |注入位置資訊（因為沒有重複）|
| **前饋網路** |獨立應用於每個職位 |
| **層標準化** |穩定訓練|
| **剩餘連接** |梯度流的跳過連接 |
### 僅編碼器、僅解碼器、編碼器-解碼器
|變體 |建築|最適合 |範例 |
|---------|-------------|----------|---------|
| **僅編碼器** |理解文字 |分類、NER、情緒分析 |伯特、羅伯塔、德伯特 |
| **僅解碼器** |生成文字 |語言模型、聊天機器人、代碼生成 | GPT-3/4，LLaMA，克勞德 |
| **編碼器-解碼器** |轉換文字 |翻譯、摘要 | T5、BART、mBART |

## 主要模型系列
### BERT 系列（僅限編碼器）
|型號|主要特點|
|--------|-------------|
| **伯特** (2018) |掩碼語言模型+下一句預測|
| **羅伯塔** |刪除了 NSP；使用更多資料訓練更長 |
| **阿爾伯特** |參數共享；佔地面積較小|
| **德伯特** |注意力分散；改進的 NLU |
| **DistillBERT** |體積縮小 40%，速度提高 60%，保留 BERT 97% 的效能 |
### GPT 系列（僅限解碼器）
|型號|參數|筆記|
|--------|---------|--------|
| **GPT-2** | 1.5B | 1.5B顯示僅解碼器模型可以產生連貫的文字 |
| **GPT-3** | 175B | 175B少樣本學習；提示而非微調|
| **GPT-3.5 / GPT-4** |未公開 |指令調整+RLHF；會話 |
| **LLaMA**（元）| 7B–70B |自由重量；催生了開源LLM生態系統|
| **米斯特拉爾/混合** | 7B / 8×7B（教育部）|高效開放機型，性能強勁|

## 核心 NLP 任務
|任務|說明 |典型型號|
|------|-------------|--------------|
| **文字分類** |為文字分配標籤（垃圾郵件/非垃圾郵件，正面/負面）| BERT，微調分類器 |
| **命名實體識別 (NER)** |識別文本中的人物、組織、地點 | BERT + CRF 層 |
| **情緒分析** |確定情緒基調 |微調 BERT 或零樣本 LLM |
| **機器翻譯** |語言間翻譯 | T5、mBART、瑪麗安MT |
| **問答** |根據上下文回答問題 | BERT（提取）、GPT（生成）|
| **總結** |壓縮長文 | T5、BART、GPT |
| **文本生成** |生成連貫的文本 | GPT-4，駱駝，克勞德 |

## 微調與提示
|方法|它是如何運作的 |何時使用 |
|----------|-------------|-------------|
| **微調** |更新特定於任務的資料的模型權重 |您已標記資料；需要最大效能|
| **提示** |用自然語言給出模型指令 |快速原型製作；數據有限；使用法學碩士 |
| **少射** |在提示中包含範例 |當你有幾個例子但不足以進行微調時 |
| **LoRA / QLoRA** |高效微調；更新小型低秩矩陣 |使用有限的 GPU 記憶體微調大型模型 |

## 法學碩士景觀
現代 NLP 領域由大型語言模型主導：
|類別 |範例 |筆記|
|----------|---------|--------|
| **專有** | GPT-4，克勞德，雙子座 |最佳表現；僅限 API 存取 |
| **自由重量** | LLaMA 3，米斯特拉爾，Qwen |可用重量；本地運行 |
| **開源** |皮提亞，OPT |完全開放（資料、權重、程式碼）|
| **多式聯運** | GPT-4V、雙子座、LLaVA |處理文字+圖片 |
| **代碼專業** | CodeLlama、StarCoder、DeepSeek 編碼器 |接受過代碼訓練 |
| **小型/高效** | Phi-3、Gemma、TinyLlama |小規模下表現強勁|
该领域正在快速发展。今天的前沿技術可能會在幾個月內被取代。基本面——注意力、代幣化、微調、評估——保持穩定。
