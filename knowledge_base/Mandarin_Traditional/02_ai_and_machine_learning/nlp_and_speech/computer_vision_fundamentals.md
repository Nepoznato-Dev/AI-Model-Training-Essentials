# 電腦視覺基礎知識
電腦視覺使機器能夠解釋和理解來自世界的視覺訊息——圖像、視訊和 3D 數據。它為從手機上的人臉識別到自動駕駛汽車、醫學影像分析和工業品質控制的一切提供支援。該文件涵蓋了核心概念、架構和技術。
---

## 電腦如何檢視影像
### 像素和通道
數位影像是像素網格。每個像素都有代表顏色強度的數值。
|影像類型|頻道 |每像素值 |範例|
|------------|----------|-----------------|---------|
| **灰階** | 1 | 0（黑色）至 255（白色）|醫用X射線|
| **RGB** | 3 |紅色、綠色、藍色（每個 0–255）|標準彩色照片|
| **RGBA** | 4 | RGB + Alpha（透明度）|透明背景的圖像|
| **單純皰疹病毒** | 3 |色相、飽和度、明度 |基於顏色的分割 |
1920×1080 RGB 影像是形狀為`(1080, 1920, 3)`的張量，即 620 萬像素，每個像素有 3 個值。
### 關鍵操作
|運營|描述 |
|------------|-------------|
| **調整大小** |將影像縮放到目標尺寸（雙線性、最近鄰插值）|
| **裁切** |提取感興趣區域 |
| **標準化** |將神經網路的像素值縮放為 [0,1] 或 [-1,1] |
| **增強** |人為擴展訓練資料（旋轉、翻轉、顏色抖動、裁切）|

## 卷積：核心運算
卷積在影像上滑動一個小濾鏡（內核），計算每個位置的點積。這就是 CNN 檢測邊緣、紋理和圖案的方式。
### 卷積參數
|參數|效果|
|------------|--------|
| **内核大小** | 3×3、5×5、7×7 — 较大的内核捕获更大的模式 |
| **大步** |步长大小； stride=2 将输出尺寸减半 |
| **填充** |在边界周围添加零以保留空间维度 |
| **过滤器数量** |每个过滤器学习不同的特征（边缘、纹理、颜色图案）|
### 卷積學到什麼
|層深|偵測到的特性 |
|----------|--------------------|
| **早期層** |邊緣、角落、簡單紋理 |
| **中間層** |形狀、物體部分（輪子、眼睛、葉子）|
| **深層** |高階概念（臉孔、汽車、動物）|

## CNN 架構
CNN 架構的演進講述了深度學習在電腦視覺領域的進步。
|建築|年份|關鍵創新|
|------------|-----|------------|
| **LeNet-5** | 1998 |第一個實用的 CNN；數位辨識 |
| **亞歷克斯網路** | 2012 | Deep CNN 戰勝 ImageNet； ReLU、dropout、GPU 訓練 |
| **VGGNet** | 2014年|堆疊 3×3 卷積（更深=更好）|
| **GoogLeNet（盜夢空間）** | 2014年| Inception 模組（平行過濾器大小）；22層|
| **ResNet** | 2015 | 2015 跳過連線（殘差學習）；152+ 層 |
| **高效網** | 2019 | 2019複合縮放（深度+寬度+解析度）|
| **ConvNeXt** | 2022 | 2022現代化的 ResNet；與變形金剛競爭|
### 為什麼 ResNet 改變了一切
在 ResNet 之前，由於梯度消失問題，訓練非常深的網路幾乎是不可能的。 ResNet 引入了**跳過連接**（也稱為殘差連接）：層的輸入被添加到其輸出中。
```
output = F(x) + x    # Skip connection
```

這個簡單的想法使得 152+ 層的網路能夠得到有效的訓練，現在它幾乎成為所有深度架構的標準。

## 核心願景任務
### 影像分類
為整個影像分配標籤。
|型號|方法|
|--------|----------|
| CNN（ResNet、EfficientNet）|傳統方法；卓越的準確性 |
|視覺變形金剛 (ViT) |將影像視為補丁序列；變壓器編碼器|
|遷移學習|在資料集上微調預訓練模型 |
### 物體偵測
使用邊界框尋找影像中的多個物件並對其進行分類。
|型號|類型 |速度|
|--------|------|--------|
| **R-CNN** |兩階段（提案+分類）|慢|
| **快速 R-CNN** |改進的兩級|中|
| **更快的 R-CNN** |區域提案網路+偵測器 |中|
| **YOLO** (v1–v10) |單級；一次性預測框+類別 |非常快速|
| **DETR** |基於變壓器；沒有錨框|中|
**YOLO**（You Only Look Once）是即時偵測的首選。當準確性比速度更重要時，**更快的 R-CNN** 是首選。
### 影像分割
將影像中的每個像素分類。
|類型 |描述 |使用案例|
|------|-------------|----------|
| **語意分割** |每個像素都有一個類別標籤 |自動駕駛（道路、汽車、行人）|
| **實例分割** |每個像素+物件實例ID|計數物件、醫學成像 |
| **全景分割** |語意+實例結合|全面場景了解|
關鍵模型：U-Net（醫學影像）、Mask R-CNN（實例）、DeepLab（語意）、Segment Anything Model（SAM — 通用分割）。
### 圖片生成
|方法|描述 |範例 |
|----------|-------------|----------|
| **GAN** |生成器与判别器对抗训练 | StyleGAN、CycleGAN |
| **VAE** |学习潜在分布；生成样本 |变分自编码器 |
| **扩散模型** |迭代地消除随机噪声 |稳定扩散、DALL-E、中途 |
就影像生成品質而言，擴散模型已大大超越 GAN。

## 視覺遷移學習
從頭開始訓練 CNN 需要大量數據和計算。遷移學習可讓您從已在數百萬張影像 (ImageNet) 上訓練的模型開始，並針對您的特定任務進行微調。
### 步驟
1. **選擇預訓練模型**（ResNet50、EfficientNet-B0、ViT）。
2. **將分類頭**替換為您自己的分類頭（與您的類別數相符）。
3. **凍結早期層**（它們捕捉邊緣等通用特徵）。
4. 以低學習率對資料集進行**微調**。
5. **如果您需要更多適應，請逐漸解凍**。
這種方法通常只需 1,000-10,000 個標記影像即可實現高精度。

## 資料增強
增強透過應用轉換來人為地擴展您的訓練資料集。
|增強 |效果|何時使用 |
|-------------|--------|-------------|
| **隨機裁切** |裁切到隨機區域 |幾乎總是 |
| **水平翻轉** |鏡像|當方向不重要時 |
| **旋轉** |隨機角度旋轉 |當物體以任意角度出現時 |
| **顏色抖動** |隨機調整亮度、對比、飽和度 |當光線變化時 |
| **隨機擦除** |屏蔽隨機區域 |提高穩健性 |
| **混音/剪切混音** |混合兩個圖像和標籤 |正則化|
庫：`torchvision.transforms`、`albumentations`、`imgaug`、`tf.keras.preprocessing`。

## 實用技巧
- **從遷移學習開始。 ** 幾乎在所有情況下，微調預訓練模型都勝過從頭開始訓練。
- **將您的輸入標準化。 ** 匹配預訓練模型期望的標準化（通常是 ImageNet 平均值/標準差）。
- **使用適當的指標。 **平衡資料集的準確性；用於不平衡或偵測任務的 F1、mAP 或 IoU。
- **可視化您的數據。 ** 查看範例影像，檢查類別分佈，檢查模型預測。
- **明智地增強。 ** 僅應用對您的領域有意義的轉換（不要垂直翻轉醫學影像）。
- **監控過度擬合。 ** 如果訓練準確度較高但驗證較低，請增加增強或增加 dropout。
