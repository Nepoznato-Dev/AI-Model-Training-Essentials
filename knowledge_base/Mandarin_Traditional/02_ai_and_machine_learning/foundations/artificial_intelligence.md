# 人工智慧
人工智慧是試圖建構機器，使其能夠完成人類需要智慧才能完成的事情：識別面孔、理解語音、做出決定、編寫文字、玩遊戲、駕駛汽車、診斷疾病。這個領域和計算本身一樣古老 — 艾倫圖靈問「機器能思考嗎？」1950 年，但最近（2020 年代）能力的爆炸性增長使人工智慧成為人類歷史上最重要和最具爭議的技術之一。
---

## 簡史
幾十年來，人工智慧經歷了炒作和失望的循環。了解這段歷史可以幫助您理解為什麼人們既興奮又懷疑。
|時代|發生了什麼事 |結果|
|-----|----------------|---------|
| **1950 年代-1960 年代** |早期的樂觀。提出圖靈測試（1950）。達特茅斯會議硬幣「人工智慧」（1956）。早期的程式如 ELIZA（聊天機器人）和 SHRDLU（語言理解）。 | 興奮：「我們將在一代人的時間內擁有通用人工智慧！」|
| **20世紀70年代** |第一個人工智慧冬天。早期方法的限制變得顯而易見。資金枯竭。 |失望：承諾未兌現 |
| **20世紀80年代** |專家系統蓬勃發展－編碼人類專業知識的基於規則的程序。日本第五代計畫。 |再次興奮：企業人工智慧投資|
| **1987-1993** |第二個人工智慧冬天。事實證明，專家系統很脆弱且維護成本昂貴。 |再次失望|
| **2000s** |機器學習受到關注。更多可用數據（互聯網）。統計方法取代了手工編碼的規則。 |穩步前進|
| **2012+** |深度學習革命。 AlexNet 使用 GPU 贏得了 ImageNet 競賽。神經網路在視覺、語音和語言方面開始優於傳統方法。 |快速轉型|
| **2017** | 《Attention Is All You Need》論文介紹了 Transformer 架構。 |為接下來的一切打下基礎 |
| **2020-2026** |大型語言模型（GPT-3、GPT-4、Claude、Gemini、LLaMA）。人工智慧生成文字、程式碼、圖像、影片。企業採用加速。 |人工智慧成為日常生活的一部分 |

## 現代人工智慧如何運作
### 機器學習－從數據中學習
機器學習不是編寫明確的規則，而是將資料提供給自行發現模式的演算法。
|類型 |它是如何運作的 |範例|
|------|-------------|---------|
| **監督學習** |在標記範例上進行訓練（輸入→正確輸出）|垃圾郵件偵測：提供數千封標有「垃圾郵件」或「非垃圾郵件」的電子郵件 |
| **無監督學習** |在未標記的資料中尋找模式 |客戶細分：無需預先定義群組即可將相似客戶分組 |
| **強化學習** |代理人透過反覆試驗來學習，獲得獎勵或懲罰 |玩遊戲的人工智慧：嘗試動作、獲勝獲得積分、了解哪些策略有效 |
### 深度學習—神經網絡
深度學習使用人工神經網路——簡單的數學運算層，堆疊在一起，可以學習極其複雜的模式。 「深」是指層數。
關鍵架構：
|建築|最擅長 |實際使用 |
|----------|---------|----------------|
| **CNN**（卷積神經網路）|影像與空間資料|人臉辨識、醫學影像、自動駕駛汽車 |
| **RNN/LSTM** |序列資料（時間序列）|語音辨識、音樂產生（很大程度上被變形金剛取代）|
| **變壓器** |一切——文字、圖像、音訊、程式碼| GPT、Claude、Gemini、BERT、DALL-E——主導架構 |
| **GAN**（生成對抗網路）|生成真實資料 |影像合成、風格遷移（部分被擴散模型取代）|
| **擴散模型** |高品質影像/視訊生成 |穩定擴散，DALL-E 3，中途，索拉 |
### 大型語言模型 (LLM)
LLM 是基於 Transformer 的模型，經過大量文字訓練。他們學習預測序列中的下一個標記（單字片段），這需要理解語法、事實、推理，甚至類似於「知識」的東西。
|型號|開發人員|顯著特點|
|--------|---------|-----------------|
| **GPT-4 / GPT-4o** |開放人工智慧 |多模式（文字+圖像）；強而有力的推理 |
| **克勞德** |人擇 |注重安全與幫助；長上下文視窗|
| **雙子座** |Google DeepMind |原生多式聯運；與Google服務整合|
| **駱駝 / 駱駝 3** |元 |自由重量；可以在本地運行；大型社區|
| **米斯特拉爾** |米斯特拉爾人工智慧 |高效的開放模型可與更大的模型競爭|
**訓練過程**：
1. **預訓練**：從海量文字資料中學習（預測下一個標記）。這是模型獲取「知識」的地方。
2. **微調**：針對特定任務或根據人類偏好進行訓練。
3. **RLHF**（來自人類回饋的強化學習）：人類對模型輸出進行評分；此模型學習產生人類喜歡的輸出。
**上下文視窗**（模型一次可以處理多少文字）已從 4K 令牌（早期的 GPT-3）成長到 2026 年模型中的超過 100 萬個代幣。

## 人工智慧能做什麼、不能做什麼
### 當前能力
|任務|效能|限制 |
|------|-------------|-------------|
| **文字生成** |優秀－連貫、情境相關、風格多元 |可以產生幻覺（自信地產生假訊息）|
| **程式碼生成** |非常適合常見模式；可以編寫整個程式|與新穎的架構作鬥爭；可能會引入微妙的錯誤|
| **圖像生成** |逼真；藝術風格；編輯|手和文字仍然不完善；與精確的空間推理作鬥爭|
| **翻譯** |主要語言對接近人類 |資源匱乏的語言不太準確；文化的細微差別可能會丟失|
| **語音辨識** |純淨的音訊接近人類 |與濃重的口音和背景噪音作鬥爭|
| **推理** |進步很快；可以解決很多邏輯問題|未能解決需要真正理解的新問題 |
| **數學** |擅長標準問題|在新穎的校樣上犯錯；不能替代形式驗證|
| **規劃與工具使用** |新興（代理）|在沒有人工監督的情況下，對於複雜的多步驟任務仍然不可靠 |
### 人工智慧不能做什麼（截至 2026 年）
- **真正理解**人類所做的任何事情 - 它處理模式，而不是意義
- **保證事實準確性** - 幻覺仍然是一個未解決的問題
- **在沒有監督的情況下在高風險決策中取代人類判斷**
- **完美概括**到與訓練資料截然不同的領域
- **在不可預測的物理環境中自主操作**（機器人仍然很難）

## 人工智慧道德與安全
人工智慧不是中立的。它反映了它所訓練的資料、開發人員的選擇以及部署它的組織的激勵。
### 主要問題
|問題 |發生了什麼 |範例|
|--------|-------------|---------|
| **偏見** |人工智慧系統重現並放大訓練資料中的偏差招募演算法有利於男性候選人；臉部辨識對於深色皮膚的錯誤率更高
| **隱私權** |人工智慧接受個人資料訓練；監控能力|有關版權作品的培訓；公共場所臉部辨識|
| **濫用** |深度造假、假訊息、自動網路釣魚 |人工智慧生成政客的假影片；自動詐騙電話|
| **工作轉移** |以前由人類完成的任務的自動化|內容創建、客戶服務、資料輸入、一些程式設計 |
| **對齊** |確保人工智慧目標符合人類價值 |人工智慧被告知「最大化回形針產量」可能會將所有物質轉化為回形針 |
| **存在風險** |對未來AGI的理論關注|研究人員之間的爭論－有些人認為這是緊迫的，有些人則認為為時過早
### 誰在從事安全工作
- **Anthropic** — 由前 OpenAI 研究人員創立，專門關注人工智慧安全
- **DeepMind Safety** — Google DeepMind 內的研究團隊
- **MIRI**（機器智能研究所）－理論安全研究
- **ARC**（人工智慧研究中心）－實證安全研究
- **政府機構** — 歐盟人工智慧法案 (2026)、美國行政命令、國際框架

## 機器人技術與嵌入式人工智慧
機器人技術將人工智慧與實體機器結合。儘管取得了數十年的進步，但與世界的實體互動仍然比數位智慧困難得多。
- **波士頓動力公司的 Atlas** — 先進的雙足運動；跑酷；倉庫任務
- **工業機器人**（ABB、FANUC、KUKA）－自動化製造；焊接;組裝
- **手術機器人**（達文西系統）－微創手術，精準度超越人手
- **家用機器人** (Roomba) — 簡單但商業上成功
- **人形機器人**（Tesla Optimus、Figure AI）－新興；通用體力任務仍然非常困難
數位人工智慧（已經取得了巨大進步）和實體人工智慧（在靈活性、平衡性和不可預測的環境中掙扎）之間的差距是該領域面臨的巨大挑戰之一。

| **小語言模型** |在消費性硬體上運行的高效模型；品質接近大型型號|

＃＃ 概括
人工智慧是21世紀迄今最重大的技術發展。這不是魔法，而是透過大量資料、強大的硬體和巧妙的架構實現的大規模模式匹配。其變革性在於，模式匹配如果做得足夠好，可以複製許多以前需要人類智慧的任務。挑戰同樣重大：幻覺、偏見、工作取代、濫用，以及從狹義人工智慧到通用智慧的道路是短還是長的懸而未決的問題。顯而易見的是，人工智慧將重塑各行各業、各職業、日常生活的方方面面。了解它的工作原理以及它不能做什麼對於駕馭我們正在建立的世界至關重要。
