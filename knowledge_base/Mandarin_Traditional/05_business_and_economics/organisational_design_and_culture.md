# 組織設計與文化
組織設計是為了有效執行策略而對結構、流程、角色和決策權進行的有意安排。文化是塑造人們實際合作方式的共同價值、信念、規範和行為。結構提供架構；文化塑造行為。可以在紙上重新設計結構，但如果文化不支持變革，實施就會失敗。同樣，強大的文化與無效的結構結合也會逐漸損害組織績效。最有效的組織會同時解決這兩個問題，並認識到它們之間是緊密相連的。
---

## 組織架構
### 常見結構
|結構|描述 |優點 |弱點|
|------------|-------------|------------|------------|
| **功能性** |按專業分組（工程、行銷、銷售）|深厚的專業知識；效率;清晰的職業道路 |筒倉；跨職能協調緩慢|
| **部門** |依產品、市場或地理位置分組 |關注顧客/市場；損益責任 |職能重複；資源競爭|
| **矩陣** |雙重報告：職能+產品/專案|彈性;跨職能協作|困惑;權力鬥爭；緩慢的決定|
| **平面/水平** |管理層較少；廣泛的控制範圍|快速決策；賦予員工權力；低開銷|難以擴展；報告不明確|
| **基於團隊** |圍繞跨職能團隊組織 |自治;速度;以客戶為中心 |團隊間的協調；一致性|
| **網路/平台** |核心團隊+外部合作夥伴；平台賦能他人|可擴展性；靈活性;輕資產|品質控制；對合作夥伴的依賴|
| **合弄制** |自我管理的團隊；由職責定義的角色|高度自主性；自適應 |令人困惑；並不適合所有人|
### 控制範圍
|因素|窄跨 (4-6) |跨距大（10-15+）|
|--------------------|--------------------|---------------------|
| **管理層** |許多 |很少|
| **監督** |關閉;動手|委託；放手 |
| **最適合** |複雜的任務；缺乏經驗的團隊|日常任務；經驗豐富、自主的團隊 |
| **風險** |微觀管理；緩慢的決定|缺乏支持；協調差距|
### 集中化與分散化
|尺寸|集中式|去中心化|
|----------|----------|--------------|
| **決策** |由上而下|被推到邊緣|
| **速度** |慢（上瓶頸）|快速（本地決策）|
| **一致性** |高|變數|
| **創新** |受top頻寬限制|來自多個來源|
| **最適合** |危機;早期階段；合規重工業|知識工作；快速變化的市場；放大 |

## 設計原則
### 組織設計中的關鍵決策
|決定|問題 |選項|
|----------|----------|---------|
| **部門化** |我們如何將人分組？ |按功能；產品;顧客;地理;流程|
| **命令鏈** |誰向誰報告？ |層次清晰；矩陣;網路|
| **決定權** |誰決定什麼？ |集中;去中心化； RACI矩陣|
| **協調機制** |團隊如何協同工作？ |聯絡角色；跨職能團隊；整合商；共同目標|
| **標準化** |標準化與在地化的差異是多少？ |流程；產出；技能；規格 |
### 加爾布雷斯的明星模特
|元素|描述 |
|---------|-------------|
| **策略** |方向;目標；競爭優勢；該組織存在的原因|
| **結構** |報告關係；等級制度;單位分組 |
| **流程** |資訊流；決策;規劃;預算|
| **獎勵** |激勵措施；績效衡量；與策略保持一致|
| **人** |招募；發展;文化;人類的能力|
關鍵見解：策略驅動結構。所有其他元素必須對齊。改變結構而不改變流程、獎勵和人員發展將會失敗。

## 組織文化
### 文化到底是什麼
|層 |描述 |能見度|
|--------|-------------|------------|
| **文物** |可見的結構、流程、行為、著裝規範、辦公室佈局 |容易看到；難以解釋|
| **所擁護的價值觀** |明確的策略、目標、理念、使命宣言|公開宣布；可能與實際行為不符 |
| **基本假設** |無意識的、被視為理所當然的信念、看法、想法、感受|無形的;行為的真正驅動力|
### 文化類型（競爭價值架構）
|文化|焦點 |特色 |範例|
|--------|---------|----------------|---------|
| **氏族**（合作）|內部+彈性|像家人一樣；指導；團隊合作；共識 |捷步；小型新創公司|
| **臨時性**（創建）|外部+彈性|創新的;承擔風險；創業精神；動態 |Google（早期）；太空探索技術公司 |
| **市場**（競爭）|外部+控制|以結果為導向；競爭的;以目標為中心；市場份額|亞馬遜;華爾街公司|
| **層級結構**（控制）|內部+控制|結構化；流程驅動；效率;一致性|政府機構；軍隊;傳統銀行|
### 文化維度
|尺寸|描述 |
|------------|-------------|
| **心理安全** |人們能否承擔風險並表現出脆弱性而不必擔心受到懲罰？ |
| **責任** |人們要為自己的承諾負責嗎？ |
| **透明度** |資訊是公開分享還是作為權力被儲存？ |
| **創新寬容** |失敗是受到懲罰還是被視為學習？ |
| **以顧客為導向** |決策是從顧客需求出發還是從內部便利出發？ |
| **速度與質量** |是偏向快速迭代還是仔細考慮？ |
| **等級尊重** |初級人員可以挑戰高級人員的想法嗎？ |

## 變革管理
### 為什麼變革計畫失敗
|原因 |描述 |
|--------|-------------|
| **不緊急** |人們不明白為什麼需要改變|
| **沒有聯盟** |沒有強大的團體推動變革|
| **沒有視力** |不清楚未來的狀態是什麼樣子 |
| **溝通不良** |人們不理解這種變化或他們在其中的角色|
| **沒有速效** |沒有明顯的進展來建立勢頭|
| **過早的慶祝** |在嵌入變革之前宣布勝利 |
| **文化抵抗** |改變與根深蒂固的假設相衝突|
| **無加固** |舊行為得到獎勵；新行為未能持續|
### Kotter 的 8 步驟模型
|步驟|行動|
|------|--------|
| **1.制造紧迫感** |帮助人们看到不改变的威胁|
| **2.建立指导联盟** |组建一个有足够权力和信誉的团体 |
| **3.形成战略愿景** |创造清晰的未来图景 |
| **4.招募志愿军** |获得关键群体的支持 |
| **5.启用操作** |消除障碍；赋予人们权力|
| **6。產生短期勝利** |創造看得見的成功|
| **7.持续加速** |继续推动；不要太早宣布胜利|
| **8.机构变革** |在文化中锚定新行为|

## 遠端和混合工作
|挑戰|戰略|
|------------|----------|
| **通讯** |默认为书面；异步优先；记录决定|
| **信任** |衡量结果，而不是时间；避免监视|
| **入职** |结构化课程；好友系统；明确的文档|
| **文化** |有意识的仪式；定期全体人员；虚拟社交活动|
| **股权** |邻近偏见：确保远程工作人员获得平等的可见性和机会 |
| **合作** |所有权清晰；定义的接口；定期同步 |
| **幸福** |尊重界限；断开连接的权利；避免会议超载 |
---

＃＃ 概括
組織設計和文化決定了一個公司能否執行其策略。結構定義了報告關係、決策權和協調機制。文化定義了人們的實際行為方式──指導日常工作的假設、規範和價值觀。加爾布雷斯的明星模型提醒我們，策略、結構、流程、獎勵和人員必須保持一致。文化類型從氏族（協作）到臨時（創新）到市場（競爭）到等級（控制）。像科特的八步驟模型這樣的變革管理框架為變革提供了結構，但文化才是真正的戰場——如果變革與深刻的假設相衝突，那麼無論計劃得多麼好，它都將失敗。遠距和混合工作為溝通、信任和鄰近偏見帶來了新的挑戰。最好的組織會精心設計，建立支持其策略的文化，並在環境變化時仍願意不斷發展。
