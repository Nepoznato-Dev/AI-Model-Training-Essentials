# 供應鏈和營運管理
供應鏈管理是對涉及尋源、採購、轉換和物流的所有活動的協調——從原材料到客戶手中的成品。營運管理是生產系統的日常運作。它們共同決定了公司是否能夠在正確的時間、以正確的成本、以正確的品質交付正確的產品。疫情、晶片短缺和運河堵塞表明，全球供應鏈是多麼脆弱且相互關聯。
---

## 供應鏈基礎知識
### 供應鏈流程
|舞台|活動 |主要關注點|
|--------|----------|-------------|
| **計劃** |需求預測；供應計劃；標準與操作 |準確度;反應能力|
| **來源** |供應商選擇；採購;承包|成本;品質;可靠性;道德 |
| **製作** |生產;集會;品質控制|效率;彈性;容量|
| **交付** |倉儲；訂單履行；交通 |速度;成本;準確度 |
| **返回** |逆向物流；返回；回收|顧客滿意度；成本回收|
### 供應鏈類型
|類型 |特點 |最適合 |
|------|----------------|----------|
| **高效率** |利用率高；低成本;可預測|需求穩定的功能性產品（雜貨）|
| **反應靈敏** |緩衝能力；靈活的;快|需求不確定的創新產品（時尚）|
| **有彈性** |冗餘;能見度;適應性 |高風險環境；關鍵貨物|
| **敏捷** |延期；大規模客製化|產品品種多、生命週期短 |
| **精益** |消除浪費；基於拉動；及時 |大容量；品種少；需求穩定|

## 庫存管理
### 庫存類型
|類型 |描述 |目的|
|------|-------------|---------|
| **原料** |未處理的輸入 |緩衝供應波動|
| **進行中工作 (WIP)** |半成品|生產階段之間的緩衝|
| **成品** |準備出售 |緩衝需求變化|
| **MRO**（維護、修理、營運）|營運所需的物資 |維持生產運作 |
| **安全庫存** |超出預期需求的額外庫存 |防範不確定性|
| **管道庫存** |在地點之間過境 |運輸過程中不可避免的 |
### 庫存管理模型
|型號|說明 |何時使用 |
|--------|-------------|-------------|
| **EOQ**（經濟訂單數量）|最小化總持有+訂購成本的最佳訂單規模|需求穩定；恆定的交貨時間|
| **再訂購點 (ROP)** |庫存下降到閾值時訂購 |持續審查；可預測的需求|
| **ABC分析** |以價值對項目分類：A（高）、B（中）、C（低）|優先考慮管理階層的關注|
| **準時制 (JIT)** |僅根據生產需求接收貨品 |穩定的供應鏈；低變異性 |
| **供應商管理庫存 (VMI)** |供應商管理庫存水準 |強大的供應商關係 |
| **寄售** |供應商擁有庫存直到使用為止 |降低買家的搬運成本|

## 生產系統
### 製造方法
|方法|描述 |卷 |品种 |示例|
|----------|-------------|--------|---------|---------|
| **工作店** |客製化產品；通用設備|低|高|機械車間；訂製家具 |
| **批次** |批量生產；批次之間的轉換|中等|中|麵包店；藥品 |
| **量產** |大容量；專用設備；裝配線|高|低|汽車；電子產品 |
| **連續流動** |不間斷生產；全自動|非常高|非常低|煉油；化學品；鋼 |
| **大規模訂製** |高產量+高品種；靈活的自動化|高|高|戴爾電腦；Nike為你|
### 精實製造
|原理|說明 |
|------------|-------------|
| **價值** |定義顧客認為有價值的東西 |
| **價值流** |繪製所有步驟；辨識那些能增加價值的|
| **流量** |讓創造價值的步驟順利進行而不會中斷 |
| **拉** |仅在客户要求时生产 |
| **完美** |持续消除浪费（muda）|
### 七種浪費（Muda）
|廢物|描述 |範例|
|--------|-------------|---------|
| **生產過剩** |賺得比需要的多|當需求不確定時按預測生產 |
| **等待** |步驟之間的空閒時間|等待下一台機器的零件|
| **交通** |不必要的物料移動 |在遙遠的倉庫之間移動產品 |
| **過度加工** |做超出必要的工作 |額外檢查；不必要的功能|
| **庫存** |庫存過剩，超出需求 | 「以防萬一」的安全庫存 |
| **運動** |人員不必要的流動|步行取工具；伸手去拿零件|
| **缺陷** |不符合規格的產品 |返工；廢料;保固索賠|

## 物流運輸
### 交通方式
|模式|成本|速度|產能 |最適合 |
|------|------|--------|----------|----------|
| **公路**（卡車）|中等|中等|中等|最後一英里；區域性；靈活的路由|
| **鐵路** |低|中|高|大宗商品；陸地長途|
| **海事**（船舶）|非常低|很慢|非常高|國際的;大部分;貨櫃 |
| **空氣** |非常高|非常快|低|高價值；緊迫的;易腐爛|
| **管道** |低（施工後）|連續 |高|油;氣體;水 |
| **聯運** |變動 |變動 |高|組合模式；貨櫃貨運|
### 倉庫設計
|決定|選項|權衡|
|----------|---------|------------|
| **倉庫數量** |很少（集中）與很多（區域）|成本效率與交付速度 |
| **自動化等級** |手動 vs 半自動 vs 全自動 |資本成本與勞動成本和準確性 |
| **佈局** | U 型流與貫通流 |空間利用率與行駛距離|
| **儲存系統** |貨架；貨架；自動化/RS；旋轉木馬|密度與可及性與成本|

## 供應鏈風險管理
### 常見風險
|風險類別 |範例 |緩解措施 |
|--------------|----------|------------|
| **需求風險** |預測錯誤；牛鞭效應|更好的預測；需求感知；安全庫存|
| **供應風險** |供應商破產；品質故障|雙重來源；供應商審核；安全庫存|
| **物流風險** |港口擁擠；運營商故障 |多式聯運；替代路線|
| **地緣政治風險** |關稅；貿易戰；制裁|近岸外包；多元化採購國家|
| **自然災害** |地震;洪水;流行病|地理多樣化；業務連續性計劃|
| **網路風險** |勒索軟體；資料外洩|資訊科技安全；備份系統|
### 牛鞭效應
|原因 |描述 |解決方案 |
|--------|-------------|----------|
| **需求預測更新** |每個階段都會增加自己的安全庫存|跨鏈共享銷售點資料 |
| **訂單批量** |定期訂購造成需求激增|減少訂單週期時間；電子資料交換 |
| **價格波動** |促銷期間提前購買 |每日低價；價格穩定|
| **配給與短缺遊戲** |缺貨期間超額訂購 |根據過去的銷售情況進行分配；分享容量資訊 |

## 現代供應鏈趨勢
|趨勢 |描述 |影響 |
|--------|-------------|--------|
| **數位孿生** |用於模擬的供應鏈虛擬複製品|更好的規劃；情境分析|
| **供應鏈控制塔** |整個鏈條的集中可見性|更快地回應中斷 |
| **近岸外包/友岸外包** |將生產轉移到離本國或盟國更近的地方|降低風險；成本較高|
| **循環供應鏈** |再利用、再製造、回收設計 |永續性；資源效率|
| **人工智慧驅動的需求感知** |用於短期預測的即時數據機器學習 |更準確；更快的回應 |
| **自動駕駛汽車和無人機** |自動駕駛卡車；無人機送貨|成本更低；更快的最後一英里|

＃＃ 概括
供應鏈和營運管理旨在提高貨物的實際流動效率、反應速度和彈性。庫存管理平衡持有庫存的成本和缺貨風險。生產系統範圍從加工車間（客製化、小批量）到連續流程（商品、大批量）。精益製造消除浪費，提高效率。物流決策—運輸模式、倉庫位置、自動化水準—決定成本和服務品質。風險管理解決牛鞭效應、供應商失敗、地緣政治混亂和自然災害。數位孿生、人工智慧驅動的需求感知和近岸外包等現代趨勢反映了該行業對日益動盪的世界的反應。最好的供應鏈不僅是高效的，而且是可見的、靈活的，並且為中斷做好了準備。
