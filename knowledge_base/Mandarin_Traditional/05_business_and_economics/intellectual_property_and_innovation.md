# 智慧財產權與創新
智慧財產權 (IP) 指受法律保護免於未經授權使用的智力創造－發明、藝術作品、品牌名稱、設計、商業機密。創新是將想法轉化為價值的過程。智慧財產權法的存在是為了平衡兩種相互競爭的利益：獎勵創造者（透過給予他們暫時的壟斷權）和造福社會（透過確保知識最終免費獲得）。了解知識產權對於任何建立產品、創建內容、經營業務或從事研究工作的人都至關重要。
---

## 智慧財產權類型
＃＃＃ 概述
|類型 |它保護什麼 |持續時間 |如何獲得 |範例|
|------|-----------------|----------|-------------|----------|
| **專利** |發明（工藝、機器、組合物）|提交後 20 年 |應用;考試;授予|一種新的藥物化合物；製造過程 |
| **版權** |原創作品 |壽命 + 70 年（大多數國家/地區）|創建後自動 |圖書;音樂;軟體程式碼；電影 |
| **商標** |品牌識別碼（名稱、標誌、口號）|無限期（如果使用並續訂）|用於商業；登記加強| “Nike”名稱和旋風標誌|
| **商業機密** |商業機密資訊|無限期（只要保密）|無需註冊；必須採取合理措施保守秘密|可口可樂配方；Google搜尋演算法|
| **工業設計** |產品視覺外觀| 15–25 年（各不相同）|註冊|智慧型手機的形狀；家具設計|
| **地理標誌** |具有特定地理來源的產品|不定 |登記;連結至地區 |香檳酒;帕馬森-雷吉亞諾；大吉嶺茶|

## 專利
### 專利要求
|要求 |描述 |
|-------------|-------------|
| **新奇** |發明必須是新穎的；以前從未在世界任何地方披露過|
| **非顯而易見性（創造性）** |發明對於相關領域的技術人員來說必須不是顯而易見的 |
| **實用性（工業適用性）** |發明必須有特定的、實際的用途|
| **主題資格** |必須是過程、機器、製造或物質的組合；抽象思想、自然法則和自然現像不可申請專利|
### 專利類型
|類型 |描述 |術語 |
|------|-------------|------|
| **實用專利** |保護發明的功能 |提交後 20 年 |
| **設計專利** |保護功能性物品的裝飾設計 |授予後 15 年（美國）|
| **植物專利** |保護植物新品種（無性繁殖）|提交後 20 年 |
### 專利流程
|步驟|說明 |時間軸 |
|------|-------------|----------|
| **1.現有技術檢索** |搜尋現有專利和出版物以檢查新穎性 |幾週到幾個月|
| **2.申請草案** |撰寫權利要求（定義保護範圍）和描述 |幾週到幾個月|
| **3.文件申請** |提交給專利局（USPTO、EPO等）|申請日=優先權日|
| **4.考試** |專利審查員對新穎性、非顯而易見性、實用性的審查 | 1–5 年 |
| **5.辦公室行動** |審查員可以拒絕；申請人提出異議或修改權利要求 |來回洽談|
| **6。格蘭特** |如果允許，則授予專利；需要維護費|維持生存的定期費用|

## 版權
### 版權保護什麼
|受保護 |不受保護 |
|------------|--------------|
|文學作品（書籍、文章、代號）|想法；事實；系統|
|音樂作品（旋律、歌詞）|頭銜；姓名；簡短的短語|
|藝術作品（繪畫、照片、設計）|操作方法 |
|軟體程式碼（以書面形式）|演算法的功能（可能可申請專利）|
|電影；電視節目；錄影帶 |風格；科技 |
|建築設計|建築物的功能面|
### 關鍵版權概念
|概念 |描述 |
|---------|-------------|
| **固定** |當作品固定在有形媒介（寫下來、記錄下來）中時，版權就存在 |
| **自動保護** |無需註冊（但註冊可以在美國獲得法定損害賠償） |
| **合理使用/公平交易** |未經許可限制用於批評、評論、教育、模仿 |
| **知識共享** |標準化許可證允許不同程度的重複使用 |
| **公共領域** |不受版權保護的作品（過期、放棄或不合格）|
| **受僱工作** |員工在本職工作範圍內創作的作品，屬於雇主所有 |

## 商標
### 商標基礎知識
|方面|描述 |
|--------|-------------|
| **目的** |辨識商品/服務的來源；防止消費者混淆|
| **特色譜** |幻想性（最強）→任意性→暗示性→描述性（弱）→通用性（不可保護）|
| **註冊** |不是必需的（普通法的使用權利），但提供了顯著的法律優勢 |
| **課程** |商品/服務分為 45 個類別（尼斯分類）|
| **維護** |必須用於商業；定期更新註冊|
| **侵權** |未經授權使用可能會造成混亂|
### 商標顯著性
|類別 |描述 |防護性|範例|
|----------|-------------|----------------|---------|
| **幻想** |發明了在品牌之外沒有任何意義的字詞 |最強| 「柯達」； 「施樂」|
| **任意** |使用與產品無關的真實字詞|很強|電腦上的「蘋果」|
| **建議** |關於產品性質的提示 |強| “Netflix”（網絡電影）|
| **描述性** |描述產品 |虛弱的;需要次要意義 | “假日酒店”|
| **通用** |產品通用名稱|不受保護| “阿斯匹靈”（曾經是一個商標）|

## 商業機密
|方面|描述 |
|--------|-------------|
| **定义** |由于保密而具有经济价值的信息；不为普遍所知；并会采取合理的努力来保守秘密|
| **示例** |公式；算法；客户名单；制造工艺；经营策略|
| **保护** |无需注册；需要保密协议；访问控制；需要了解的基础 |
| **持续时间** |无限期——只要保守秘密|
| **挪用** |通过不正当手段获取（盗窃、间谍活动、违反保密协议）|
| **与专利** |无需披露；没有时间限制；但无法防止独立发现或逆向工程|

## 開源與開放創新
### 開源許可證
|許可證|類型 |關鍵要求 |範例使用者 |
|--------|------|----------------|----------------|
| **麻省理工學院** |寬容 |包括版權聲明；無保固| jQuery；反應 |
| **阿帕契2.0** |寬容 |包括通知；專利授權|安卓;庫伯內特 |
| **BSD（2 條款）** |寬容 |包括版權聲明 |自由BSD |
| **GPL v3** |版權左 |衍生作品也必須是 GPL | Linux核心； WordPress |
| **LGPL** |弱 Copyleft |連結不會觸發 Copyleft；修改確實| GTK |
| **MPL 2.0** |檔案級 Copyleft |修改後的檔案必須是開啟的；新檔案可以是專有的|火狐 |
| **AGPL** |強版權 |網路使用引發消息來源外洩| MongoDB（以前）|
### 開放式創新模式
|型號|描述 |範例|
|--------|-------------|---------|
| **開源** |程式碼免費提供；社群貢獻 | Linux；庫伯內特斯；反應 |
| **開放資料** |公開共享的資料供任何人使用|政府資料集；研究資料|
| **開放硬體** |公開共享硬體設計| Arduino；樹莓派 |
| **專利池** |多個公司在一個領域共享專利| MPEG-LA（視頻編解碼器）|
| **賽前合作** |競爭對手合作應對共同挑戰 |半導體研究公司|

## 智慧財產權策略
### 何時使用每種類型的 IP
|情況|推薦IP |原因 |
|------------|----------------|--------|
| **新發明** |專利 | 20年壟斷；強力保護|
| **軟體演算法** |專利+商業機密|專利（如果可申請專利）；保密實施 |
| **品牌名稱/標誌** |商標|無限期保護品牌形象|
| **書面內容/程式碼** |版權所有 |自動的;保護表達|
| **食譜/配方** |商業秘密|不披露；無限期保護|
| **產品設計** |設計專利+商業外觀|保護外觀 |
| **快速變化的市場** |商業機密+先發優勢|專利申請時間太長；行動速度快於競爭對手的複製速度|
---

＃＃ 概括
智慧財產權法平衡了獎勵創造者與造福社會的關係。專利保護發明 20 年，以換取公開揭露。版權對原創作品的保護期限為創作者終生加上 70 年。只要品牌識別碼被使用，商標就會無限期地保護它們。商業秘密無限期地保護機密訊息，但不能防止獨立發現。開源許可證提供了傳統 IP 的替代方案，支援協作開發。正確的智慧財產權策略取決於創作類型、市場、產業速度和公司目標。了解智慧財產權不僅僅是律師的專利，對於任何在知識經濟中創造、建立或創新的人來說都至關重要。
