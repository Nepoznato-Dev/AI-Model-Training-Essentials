# 行動開發
行動開發是為智慧型手機和平板電腦建立應用程式的實踐——主要針對 iOS (Apple) 和 Android (Google)。它涵蓋了從小螢幕的 UI 設計到管理電池壽命、處理網路不穩定以及透過商店分發應用程式的一切。該領域已經顯著成熟，跨平台框架現在在大多數用例中與本機開發競爭。

## 主要移動問題
### 離線優先設計
行動應用程式必須在沒有可靠網路的情況下運作。
|戰略|描述 |
|----------|-------------|
| **本機資料庫** |在裝置上儲存資料（SQLite、Room、CoreData、Realm）|
| **同步策略** |線上時與伺服器同步；解決衝突|
| **樂觀的使用者介面** |立即更新UI；當伺服器回應時進行協調 |
| **快取** |快取 API 回應；離線時從快取提供服務 |
＃＃＃ 表現
|專注|解決方案 |
|---------|----------|
| **應用程式啟動時間** |延遲載入；最大限度地減少初始化工作|
| **記憶體使用情況** |影像壓縮；避免記憶體洩漏；使用分析工具|
| **電池耗盡** |減少後台工作；批量網路請求；使用高效率的定位服務|
| **網路效率** |壓縮有效負載；使用分頁；積極快取|
| **列表滾動** |回收視圖；對圖像使用延遲加載 |
＃＃＃ 安全
|專注|解決方案 |
|---------|----------|
| **靜態資料** |加密敏感資料（iOS 上的 Keychain、Android 上的 EncryptedSharedPreferences）|
| **網路** |總是使用 HTTPS；敏感應用程式的憑證固定|
| **身份驗證** |生物辨識（臉部辨識、指紋）；OAuth；代幣儲存 |
| **程式碼混淆** |適用於 Android 的 ProGuard/R8； iOS 的位碼 |
| **越獄/root檢測** |檢測受感染的設備；限制功能|

## 應用程式生命週期
|狀態 |描述 |做什麼 |
|--------|-------------|------------|
| **前台（活動）** |使用者正在與應用程式互動 |正常運作 |
| **背景** |應用程式不可見但仍在記憶體中 |暫停動畫；保存狀態 |
| **暫停** |作業系統已凍結應用程式以節省資源 |沒有什麼;應用程式被凍結 |
| **終止** |作業系統殺死了應用程式以釋放記憶體 |下次啟動時恢復狀態 |

＃＃ 概括
行動開發提供了本機（最佳效能、特定於平台）和跨平台（共享程式碼庫、更快迭代）之間的選擇。 Flutter 和 React Native 已經成熟到跨平台是大多數應用程式的正確選擇。無論框架如何，核心挑戰仍然相同：離線優先設計、有限硬體上的性能、電池效率、不受信任設備上的安全性以及導航應用程式商店審查流程。該領域獎勵那些首先考慮用戶體驗的開發人員——快速啟動、平滑滾動以及優雅地處理不良連接。
