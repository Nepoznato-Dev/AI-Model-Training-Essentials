# 研究方法論
研究方法是調查問題、檢驗假設和產生可靠知識的系統方法。無論您是在進行科學實驗、社會科學調查、商業分析還是學術研究，您選擇的方法都決定了您的發現是否可信、可重複和有用。精心設計的研究會產生值得信賴的結果；設計不良的答案會產生噪音，或者更糟的是，會產生自信的錯誤答案。
---

## 研究類型
|尺寸|選項|說明 |
|------------|---------|-------------|
| **目的** |基礎與應用 |基本：為了知識本身而擴展知識。應用：解決實際問題 |
| **方法** |演繹與歸納|演繹：理論→假設→觀察。歸納：觀察→模式→理論|
| **資料類型** |定量、定性、混合 |數量：數字。定性：字詞、意義。混合：兩者|
| **時間範圍** |橫斷面與縱向 |橫斷面：某一時間點。縱向：隨著時間的推移|
| **設定** |實驗與觀察 |實驗：研究者操縱變因。觀察性：研究者在沒有介入的情況下觀察|
---

## 科學方法
|步驟|描述 |
|------|-------------|
| **1.觀察** |注意一種現像或模式 |
| **2.問題** |制定一個具體的、可測試的問題|
| **3.假設** |提出初步解釋或預測 |
| **4.預測** |從假設中得出可檢驗的預測 |
| **5.實驗/觀察** |收集資料來測試預測 |
| **6。分析** |分析數據；確定結果是否支持或反駁假設|
| **7.結論** |得出結論；考慮限制；建議進一步研究|
| **8.同儕審查和複製** |其他人評估並嘗試重現研究結果 |

## 量化研究
### 實驗設計
|設計|描述 |力量|弱點|
|--------|-------------|----------|---------|
| **真實實驗（RCT）** |隨機分配治療和對照|最有力的因果證據|昂貴的;不可一概而論|
| **準實驗** |沒有隨機分配；比較組|更實用；現實世界的設定|混雜變數 |
| **預測試/後測** |幹預前後的測量|顯示隨時間的變化|無法控制外部因素|
| **因子設計** |同時操縱多個自變數|測試變數之間的交互作用 |複雜的;需要大量樣品|
| **科目內** |所有條件下的相同參與者 |控制個體差異；參與者減少 |訂單效應；結轉 |
| **科目之間** |每種情況下的不同參與者 |無殘留效應 |個別差異；需要更多參與者|
### 取樣方法
|方法|類型 |描述 |何時使用 |
|--------|------|-------------|------------|
| **簡單隨機** |機率 |每個會員都有平等的選擇機會 |黃金標準；需要完整的採樣框|
| **分層隨機** |機率 |分層；從每個 | 隨機抽取樣本確保子群體的代表性 |
| **集群** |機率 |隨機選擇組；調查所有內部|人口眾多；性價比|
| **便利** |非機率|採樣任何有空的人 |快的;便宜的;但有偏見|
| **有目的** |非機率|刻意選擇具體案例|專家意見；具體特點|
| **雪球** |非機率|現有參與者招募其他參與者 |難以接觸的人群|
### 統計分析
|分析類型 |目的|範例|
|--------------|---------|---------|
| **描述性統計** |總結資料|意思是;中位數；標準差；頻率分佈 |
| **推論統計** |從樣本得出關於總體的結論 | t 檢定；變異數分析；卡方；迴歸 |
| **相關性** |測量變數之間的關聯 |皮爾森的 r;斯皮爾曼氏rho |
| **迴歸** |因變數與自變數之間的模型關係 |線性迴歸；邏輯迴歸 |
| **因素分析** |辨識資料中的基礎構面 |主成分分析；探索性因素分析|
| **薈萃分析** |結合多項研究的結果 |治療效果系統性回顧|

## 質性研究
＃＃＃ 方法
|方法|描述 |最適合 |
|--------|-------------|----------|
| **訪談**（半結構化）|開放式問題；探測|對經驗的深刻理解；意義 |
| **焦點小組** |由主持人引導的小組討論 |探索群體規範；產生想法|
| **民族誌** |自然環境中的沉浸式觀察 |了解文化；社會實踐|
| **案例研究** |深入查處單案或小案數|背景下的複雜現象|
| **紮根理論** |透過迭代編碼從資料建構理論 |當現有理論不充分時 |
| **內容分析** |文字/媒體的系統編碼 |大量文字；媒體分析 |
| **話語分析** |研究所使用的語言；權力關係|語言如何建構現實|
| **現象學** |了解生活經驗 |人們如何體驗一種現象|
### 確保定性研究的質量
|標準|描述 |如何實現 |
|------------|-------------|----------------|
| **可信度**（內部效度）|調查結果準確地代表了參與者的觀點|三角測量；會員檢查；長期參與 |
| **可轉讓性**（外部有效性）|適用於其他情況的調查結果 |詳細描述；有目的的抽樣|
| **可靠性**（可靠性）|如果重複研究，結果是一致的|審計追蹤；同行報告|
| **可證實性**（客觀性）|研究結果植根於數據，而非研究人員的偏見 |反身性；三角測量；審計追蹤|

## 混合方法
|設計|說明 |何時使用 |
|--------|-------------|-------------|
| **收斂並行** |同時收集定量和定性資料；比較|當您想要廣度和深度時 |
| **解釋性順序** |定量第一；定性解釋結果|當調查結果需要更深入的了解時 |
| **探索性順序** |質為先；定量測試結果|當您需要先開發儀器或理論時 |

## 效度和可靠性
### 有效性的威脅
|威脅|描述 |緩解措施 |
|--------|-------------|------------|
| **選擇偏差** |幹預前各組存在系統性差異|隨機分配；配對|
| **流失偏差** |參與者非隨機退出 |追蹤原因；意圖治療分析|
| **霍桑效應** |人們改變行為是因為他們被觀察了|對照組；致盲|
| **需求特徵** |參與者猜測假設並採取相應行動 |欺騙；封面故事|
| **實驗者偏差** |研究者的期望影響結果|致盲；標準化程序|
| **混淆** |第三個變數解釋了關係 |控制變數；隨機化；統計調整|
| **P-黑客** |測試許多假設，直到其中一個具有顯著性 |預先登記；多重比較校正|
### 可靠度措施
|測量|描述 |
|---------|-------------|
| **測驗再測驗** |相同的測驗進行兩次；分數之間的相關性|
| **評估者間** |不同評估者/編碼者之間的協議 |
| **內部一致性** |克朗巴赫阿爾法；測量相同結構的項目|
| **並行形式** |同一測試不同版本之間的相關性 |

## 研究倫理
|原理|說明 |
|------------|-------------|
| **知情同意** |參與者了解他們同意的內容；自願參與 |
| **慈善** |利益最大化；盡量減少傷害|
| **非惡意** |不傷害身體、心理、社會 |
| **正義** |公平分配利益與負擔；不要剝削弱勢群體|
| **隱私權與保密** |保護參與者的資料；盡可能匿名 |
| **退出權** |參與者可以隨時退出研究而不會受到處罰 |
| **報告** |參與後解釋研究的目的；特別是如果使用了欺騙手段 |

＃＃ 概括
研究方法是決定你的研究結果是否值得信賴的框架。定量方法（實驗、調查、統計分析）最適合檢驗假設和測量效果。質性方法（訪談、民族誌、個案研究）最適合理解意義、背景和經驗。混合方法結合了廣度和深度。科學方法提供了從觀察到假設、資料收集、分析和同儕審查的結構化過程。有效性（您測量的是您認為正在測量的內容嗎？）和可靠性（您會再次得到​​相同的結果嗎？）是關鍵的品質標準。研究倫理確保對知識的追求不會以犧牲參與者的權利和福祉為代價。最重要的原則是方法論服務於研究問題——選擇最能回答你的問題的方法，而不是最熟悉或最簡單的方法。
