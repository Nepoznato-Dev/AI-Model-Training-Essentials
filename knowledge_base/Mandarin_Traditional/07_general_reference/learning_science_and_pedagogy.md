# 學習科學和教育學
學習科學是對人們如何學習的跨領域研究—借鏡心理學、神經科學、教育和認知科學。教育學是教學的實踐和方法。他們共同解決了與任何教學、培訓、指導或設計教育內容的人相關的問題：什麼方法可以幫助人們有效學習？哪些常見的學習方法效率低？應如何建構教學以實現最佳保留和轉移？
---

## 學習如何進行
### 學習過程
|舞台|描述 |關鍵因素|
|--------|-------------|------------|
| **注意** |訊息處理須注意 |新奇;關聯;情感意義|
| **編碼** |資訊轉化為心理表徵 |連結到先驗知識；闡述 |
| **整合** |記憶痕跡隨著時間的推移而穩定|睡覺;間隔重複；反思|
| **儲存** |資訊保存在長期記憶中|有意義的組織；與現有知識的連結|
| **檢索** |需要時即可存取資訊 |練習檢索；不同的背景 |
| **轉讓** |知識應用於新情況|多樣化的練習；理解原理，而不僅僅是程序|
### 認知負荷理論
|類型 |描述 |教學意義|
|------|-------------|--------------------------|
| **內在負載** |材料固有的難度|管理複雜性；從簡單到複雜的順序 |
| **外部負載** |教學設計不當造成的困難 |消除不必要的複雜性；清晰的例子；良好的格式 |
| **德國負載** |投入到實際學習中的腦力勞動（圖式構建） |鼓勵詳細闡述；自我解釋；有意義的實踐|
**關鍵見解**：工作記憶是有限的（一次大約 4±1 項）。教學應盡量減少無關負荷，以便認知資源可用於學習。

## 實證學習策略
### 高效策略
|戰略|描述 |為什麼它有效？證據等級|
|----------|-------------|-------------|----------------|
| **檢索練習** |主動從記憶中回憶資訊 |強化記憶痕跡；找出差距|很強|
| **間隔練習** |隨著時間的推移分配學習課程|部隊重組；對抗遺忘曲線|很強|
| **交錯** |混合不同類型的問題或主題 |改善歧視；更好的轉移|強|
| **詳細說明** |解釋新資訊如何與您所知道的相關聯 |創造更豐富的記憶痕跡；更深層次的編碼 |強|
| **具體例子** |用具體的例子來說明抽象的概念 |使抽象的想法變得具體；幫助理解|強|
| **雙編碼** |文字與視覺的結合|使用語言和視覺處理管道 |強|
### 無效的策略（儘管很受歡迎）
|戰略|為什麼感覺有效 |為什麼它實際上不是|
|----------|------------------------|----------------------|
| **重讀** |流暢錯覺－文字感覺很熟悉 |被動的;不加強檢索 |
| **突出顯示** |感覺富有成效；標記重要資訊 |不需要深加工 |
| **總結** |看起來像是積極參與 |經常逐字複製；不需要檢索 |
| **集中練習（臨時抱佛腳）** |適用於短期回憶 |快速遺忘；轉移不良|
| **學習風格**（視覺/聽覺/動覺）|直覺吸引人 |沒有證據表明將教學與首選風格相匹配可以改善學習 |

## 遺忘曲線與間隔重複
### 艾賓浩斯遺忘曲線
|學習後的時間 |保留（無審查）|
|--------------------------------|------------------------|
| **20 分鐘** | 〜58% |
| **1 小時** | ~44% |
| **1 天** | ~33% |
| **2 天** | 〜28% |
| **6 天** | 〜25% |
| **31 天** | 〜21% |
### 間隔重複計劃
|評論 |時間 |效果|
|--------|--------|--------|
| **第一次評論** |學習後1天 |顯著提高保留率 |
| **第二次審查** | 3 天後 |進一步強化記憶 |
| **第三次評論** | 7 天後 |內存變得更耐用 |
| **第四次評論** | 14 天後 |長期鞏固|
| **第五次評論** | 30 天後 |穩定的長期記憶 |
每一次回顧都會將遺忘曲線推得更遠。最佳間隔隨著每次成功檢索而增加。

## 布魯姆分類法
|水平|認知過程|動作動詞|範例任務 |
|------|--------------------|-------------|--------------|
| **記住** |回憶事實和基本概念|定義;列表;姓名;識別| “列出有絲分裂的階段” |
| **了解** |解釋想法或概念 |描述;解釋;總結;分類 | “解釋為什麼有絲分裂很重要”|
| **申請** |在新情況下使用資訊 |解決;使用;證明;實施 | “預測如果有絲分裂被破壞會發生什麼” |
| **分析** |建立想法之間的聯繫|比較;對比;分類；檢查| “比較有絲分裂和減數分裂”|
| **評估** |證明立場或決定的合理性 |法官;批判;保衛;論點| “評估不受控制的細胞分裂的後果”|
| **創建** |創作新的或原創的作品 |設計;構造;發展;制定 | “設計一個實驗來測試毒素對細胞分裂的影響”|

## 教學設計模型
### ADDIE模型
|相|描述 |
|--------|-------------|
| **分析** |確定學習者的需求；目標；現有知識；限制|
| **設計** |定義學習目標；評量策略；內容架構 |
| **開發** |建立材料；活動;評估|
| **實施** |傳達指令；方便學習 |
| **評估** |評估有效性；收集回饋；迭代|
### 逆向設計（透過設計理解）
|步驟|描述 |
|------|-------------|
| **1.確定所需的結果** |學習者應該知道、理解並且能夠做到什麼？ |
| **2.確定可接受的證據** |您如何知道他們已經取得了成果？ （先評估）|
| **3.計畫學習經驗** |哪些活動、指導和實踐將使學習者成功？ |
### 鷹架
|技術|描述 |
|------------|-------------|
| **建模** |展示技能或思考過程 |
| **出聲思考** |在解決問題時用語言表達你的推理 |
| **工作範例** |在要求學習者解決問題之前展示完整的解決方案 |
| **逐步發布** | 「我願意→我們願意→你願意」—逐步消除支援 |
| **提示** |提問，引導學習者找到答案 |
| **分塊** |將複雜的任務分解為可管理的部分 |

## 動機和參與
### 自決理論
|需要|描述 |如何支援 |
|------|-------------|----------------|
| **自治** |感覺可以控制自己的行為|提供選擇；解釋理由；避免控制語言|
| **能力** |感覺有效和有能力|適當的挑戰；及時回饋；慶祝進步|
| **相關性** |感覺與他人有連結 |協作學習；支持性環境；與社區的相關性|
### 成長與固定心態（Carol Dweck）
|心態|信念|行為 |對失敗的回應|
|--------|--------|------------|--------------------|
| **已修復** |智力是靜態的|迴避挑戰；輕易放棄| “我不擅長這個” |
| **成長** |智力是可以發展的|擁抱挑戰；持續| 「我還沒學會這個」 |

＃＃ 評估
### 評估類型
|類型 |目的|時間 |範例|
|------|---------|--------|---------|
| **診斷** |辨識先驗知識與誤解 |教學前|預測試；概念盤點 |
| **形成性** |監控學習情況；提供回饋 |教學期間 |測驗；出境門票；同儕審查 |
| **總結性** |最後評估學習情況 |指導後 |期末考試；項目;投資組合 |
| **正品** |評估實際應用 |期間或之後 |案例研究；模擬;實習|
### 有效的回饋
|原理|說明 |
|------------|-------------|
| **及時** |很快就可以採取行動|
| **具體** |指出特定的優點和缺點|
| **可操作** |告訴學習者下一步該做什麼 |
| **專注於任務** |與人無關（“這個論點需要更多證據”而不是“你不是一個好作家”）|
| **平衡** |確定什麼是有效的以及什麼需要改進 |
---

＃＃ 概括
學習科學表明，最有效的策略往往是違反直覺的。檢索練習（測試自己）比重讀更有效。間隔重複勝過死記硬背。不同類型的問題交織在一起可以改善區分和轉移。認知負荷理論提醒我們，工作記憶是有限的──教學的設計應盡量減少無關負荷。布魯姆的分類法提供了一個從回憶到創造的框架。教學設計模型（ADDIE，逆向設計）提供了開發有效學習經驗的結構化方法。動機取決於自主性、能力和相關性。評估應與學習目標保持一致，並包括形成性回饋，而不僅僅是總結成績。學習中最大的神話是人們有固定的「學習風格」——證據一致表明，將教學與首選風格相匹配並不能改善結果。對每個人都有效的是努力檢索、間隔練習、多樣化的例子和有意義的回饋。
