# 寫作和溝通基礎知識
寫作和溝通是有效傳達想法的技能——無論是透過電子郵件、報告、文件、簡報或對話。大多數知識工作從根本上來說都是溝通工作：專業人員需要解釋他們的想法、說服他人、記錄決策、編寫規格、展示發現以及跨團隊合作。意思和理解之間的差距是大多數問題的根源，而更好的溝通可以縮小這一差距。
---

## 清晰寫作的原則
### 核心原則
|原理|描述 |範例|
|------------|-------------|---------|
| **清晰度** |準確地說出你的意思；避免歧義 | “系統將在 UTC 下午 3 點重新啟動”而不是“系統將很快重新啟動”|
| **簡潔** |使用最少的文字 | 「我們需要」→ 只是說明需要什麼 |
| **特異性** |使用具體的細節，而不是含糊的語言 | “第三季度收入增長 15%”而不是“收入大幅增長”|
| **主動語態** |物件執行該動作 | “團隊發布了該功能”而不是“該功能已發布”|
| **每句話一個想法** |不要讓句子過多 |將長而複雜的句子拆分為較短的句子 |
| **並行結構** |對清單中的項目使用相同的語法形式 | “跑步、游泳和騎自行車”而不是“跑步、游泳和騎自行車”|
| **觀眾意識** |為你的讀者而不是你自己寫作|工程師的技術文檔；高管摘要|
### 常見寫作問題
|問題 |描述 |修復|
|---------|-------------|-----|
| **名詞化** |將動詞變成名詞（使散文變得死氣沉沉）| “我們決定”而不是“我們做出了決定”|
| **對沖** |不必要地削弱你的訊息 | 「這表明」→「這表明」（當你有證據時）|
| **行話過多** |與非技術讀者一起使用技術術語 |解釋術語；使用類比|
| **黃鼠狼的話** |模糊的限定詞破壞了意義|刪除「非常」、「相當」、「有點」、「可以說」|
| **埋鉛** |隱藏重點|將最重要的訊息放在第一位 |
| **花園小路句子** |導致讀者錯誤解讀的句子 |重組以求清晰 |

## 專業寫作的類型
### 技術文檔
|類型 |目的|觀眾|主要特點|
|------|---------|----------|------------|
| **自述文件** |專案概況 |新使用者；貢獻者|快速啟動；它做什麼；如何安裝|
| **API 文件** |如何使用API |開發商 |端點；參數;範例；錯誤代碼 |
| **架構決策記錄（ADR）** |記錄做出決定的原因 |未來的開發商；利害關係人 |語境;決定;後果|
| **運作手冊/劇本** |逐步操作流程|營運團隊|準確的命令；預期產出；回滾步驟|
| **RFC（徵求意見）** |提出改變；徵求回饋|團隊;利害關係人 |問題;提議;替代方案；權衡|
| **屍檢** |解決事件後進行分析 |團隊;管理 |時間軸；根本原因；行動項目|
### 商務寫作
|類型 |目的|主要特點|
|------|---------|-------------|
| **電子郵件** |與同事、客戶溝通 |清晰的主題行；每封電子郵件一個請求；號召性用語|
| **報告** |目前的調查結果或分析 |執行摘要;結構化部分；資料視覺化|
| **提案** |說服某人批准或資助某事 |問題;解決方案;好處;成本;時間線|
| **會議記錄** |記錄決策和行動項目|所做的決定；誰做什麼；到什麼時候|
| **狀態更新** |溝通進度 |做了什麼；下一步是什麼？阻斷劑|

## 結構化訊息
### 金字塔原理（芭芭拉·明托）
|水平|描述 |
|--------|-------------|
| **結論/建議** |從答案開始 |
| **關鍵論點** |支持結論的3-4個理由|
| **支持證據** |每個論點的資料、範例、分析 |
**為什麼有效**：忙碌的讀者首先想要答案，然後是推理。如果他們只讀第一段，他們就會明白重點。
### 倒金字塔（新聞）
|水平|描述 |
|--------|-------------|
| **領先** |最重要的訊息（人物、事件、時間、地點、原因）|
| **身體** |重要細節；語境;報價|
| **尾巴** |背景;不太重要的訊息 |
### SCQA 框架
|元素|描述 |範例|
|---------|-------------|---------|
| **情況** |目前狀態 | “我們的應用程式每秒處理 10,000 個請求”|
| **併發症** |問題或改變| “流量每月增加 30%” |
| **問題** |我們該做什麼？ | “我們如何處理 10 倍的流量？” |
| **答案** |建議| “遷移到具有自動擴展功能的微服務架構”|

## 演講
### 演示結構
|部分|目的|時間分配|
|--------|---------|-----------------|
| **掛鉤** |吸引註意力；陳述問題 | 10% |
| **背景** |為什麼這很重要；背景| 15% |
| **主要內容** | 3大要點有據可依 | 60% |
| **結論** |總結;號召性用語| 10% |
| **問答** |解決問題 | 5% |
### 投影片設計原則
|原理|說明 |
|------------|-------------|
| **每張投影片一個想法** |每張投影片傳達一個點|
| **最小文字** |滑軌支撐揚聲器；它們不是示範 |
| **視覺勝於言語** |盡可能使用圖表、圖表、圖像來取代重點 |
| **一致的設計** |總是採用相同的字體、顏色、佈局 |
| **可讀** |文字夠大；足夠的對比|
| **數據視覺化** |展示洞察力，而不僅僅是數據 |
### 處理問題
|情況|戰略|
|------------|----------|
| **你知道答案** |回答簡潔；提供證據|
| **你不知道** | “這是一個很好的問題。我沒有確切的數據，但我會跟進”|
| **敵意的問題** |承認顧慮；解決實質問題；不要採取防禦措施|
| **不清楚的問題** | “讓我確認一下我明白了——你問的是 X 還是 Y？” |
| **題外話** | 「這很重要，但超出了本次討論的範圍。讓我們把它離線」|

## 說服力和影響力
### 亞里斯多德的修辭訴求
|上訴 |描述 |如何使用 |
|--------|-------------|------------|
| **標誌**（邏輯）|理由與證據|資料;邏輯論證；個案研究|
| **悲傷**（情感）|情感連結 |故事；生動的例子；共同的價值觀|
| **精神**（可信度）|信任與權威|專業知識;往績記錄；參考;誠信|
### 西奧迪尼的說服原則
|原理|說明 |應用 |
|------------|-------------|-------------|
| **互惠** |人報恩 |先分享有用的資訊 |
| **承諾與一致性** |人信守承諾|首先獲得小協議 |
| **社會證明** |人們跟隨別人|表明同行已經在這樣做 |
| **權限** |人們追隨專家|引用憑證；參考研究|
| **喜歡** |人們對自己喜歡的人說「是」 |尋找共同點；真誠 |
| **稀缺** |人們珍惜稀有|突顯獨特優勢；時間限制|

## 跨文化交流
|尺寸|描述 |對溝通的影響|
|------------|-------------|------------------------|
| **高語境與低語境** |高：意義是隱含的。低：含義明確 |高語境文化（日本、阿拉伯）期望讀者進行推論；低語境（美國、德國）期待所有陳述 |
| **直接與間接** |如何直接傳達分歧或壞消息|直接（荷蘭、以色列）與間接（日本、泰國）|
| **正式** |溝通的正式程度 |正式（德國、日本）與非正式（澳洲、美國）|
| **時間導向** |單一時間（準時）與多時間（彈性）|影響會議期望與截止日期|
| **權力距離** |階級制度如何影響溝通？高權力距離：後輩​​不會公開挑戰前輩 |

＃＃ 概括
清晰的写作和沟通是为了被理解。从要点开始（金字塔原理）。使用主动语态、具体语言和短句。結構化訊息，以便讀者可以找到所需的內容。技術文件應該是可瀏覽的並且由範例驅動。商务写作应该以推荐为主导。簡報應在每張投影片上展示一個想法。說服結合了邏輯（標識）、證據（情感）和可信度（精神）。跨文化意識可以防止全球團隊中的誤解。基本技能是受眾意識：知道讀者是誰，他們需要知道什麼，以及什麼格式可以支持他們的理解。對更清晰溝通的投資可以減少混亂、減少誤解並加快決策速度，從而帶來回報。
