# 世界文化與社會
文化是社會的框架──成員用來回應世界和彼此之間的共同信念、價值觀、習俗、行為和人工製品。理解文化多樣性不是死記硬背，而是要理解文化多樣性。它是關於認識到看待世界的方式有數以千計，而其他系統是內部連貫的、有歷史依據的，並且值得根據自己的方式來理解。
---

## 文化維度
人類學家和跨文化心理學家使用框架來系統地比較社會。最有影響力的是吉爾特霍夫斯泰德的文化維度模型。
|尺寸|它測量什麼 |對比範例 |
|------------------------|-----------------|-----------------|
| **權力距離** |多少不平等被視為正常？高（馬來西亞、菲律賓）與低（丹麥、紐西蘭）|
| **個人主義與集體主義** | 「我」身分認同與「我們」身分認同|高度個人主義（美國、澳洲）與高度集體主義（瓜地馬拉、印尼）|
| **男性氣質與女性氣質** |競爭與成就 vs 合作與生活品質 |男性（日本、匈牙利）與女性（瑞典、荷蘭）|
| **避免不確定性** |容忍歧義和無組織的情況|高（希臘、葡萄牙）與低（新加坡、牙買加）|
| **長期與短期定位** |未來的獎勵與當前的傳統|長期（中國、韓國）與短期（美國、尼日利亞）|
| **放縱與克制** |滿足衝動的自由與嚴格的社會規範|放縱（墨西哥、尼日利亞）與克制（俄羅斯、埃及）|
> **實用洞察**：這些是頻譜位置，而不是價值判斷。高權力距離文化並不「壓抑」——它可能重視對長輩的尊重和社會和諧。低權力距離文化並不「混亂」——它可能重視精英管理和公開辯論。

## 主要文化區
### 東亞
|方面|詳情 |
|--------|---------|
| **國家** |中國、日本、韓國、台灣、越南 |
| **哲學根源** |儒、道、佛、神道|
| **關鍵值** |孝道、教化、和諧、面子（社會聲譽）、集體責任|
| **溝通方式** |高語境：意義是隱含的、間接的、字裡行間的 |
| **時間導向** |長期;強調堅持與未來的回報|
| **商業文化** |關係至上；透過用餐和反覆會面建立的信任；尊重等級制度|
東亞文化與中國的書寫系統、筷子使用和農曆新年慶祝活動有著共同的影響，但又存在顯著差異——日本人的交流比中國人更加間接，韓國商業文化比台灣人更加等級化。
### 南亞
|方面|詳情 |
|--------|---------|
| **國家** |印度、巴基斯坦、孟加拉、斯里蘭卡、尼泊爾 |
| **哲學根源** |印度教、佛教、伊斯蘭教、錫克教、耆那教 |
| **關鍵值** |家庭責任、尊重長輩、精神多樣性、熱情好客（atithi devo bhava —“客人就是上帝”）|
| **溝通方式** |高語境；著名的搖頭；間接分歧|
| **社會結構** |大家庭系統；印度歷史種姓的影響；牢固的社區紐帶|
| **語言多樣性** |數百種語言；最常使用的語言包括印地語、孟加拉語、烏爾都語、泰米爾語、泰盧固語 |
### 中東和北非 (MENA)
|方面|詳情 |
|--------|---------|
| **國家** |沙烏地阿拉伯、阿拉伯聯合大公國、埃及、摩洛哥、伊朗、土耳其、以色列 |
| **哲學根源** |伊斯蘭教、猶太教、基督教（起源於這裡）、奧斯曼與波斯傳統 |
| **關鍵值** |熱情好客、榮譽、家庭忠誠、宗教儀式、慷慨|
| **溝通方式** |高語境；關係驅動；間接拒絕保全面子|
| **商業文化** |人際關係至關重要；談判可能會很漫長；星期五是穆斯林占多數的國家的聖日|
| **多元化說明** |範圍巨大－世俗的土耳其與保守的沙烏地阿拉伯有很大不同；黎巴嫩比也門更國際化
### 撒哈拉以南非洲
|方面|詳情 |
|--------|---------|
| **國家** | 46+ 個國家；奈及利亞、衣索比亞、肯亞、南非、迦納、塞內加爾位列人口最多國家之列
| **哲學根源** | Ubuntu（「我是因為我們是」）、祖先傳統、伊斯蘭教、基督教、原住民信仰體系 |
| **關鍵值** |社區、大家庭、口傳傳統、尊重長輩、好客|
| **語言多樣性** | 2,000 多種語言；斯瓦希里語、約魯巴語、阿姆哈拉語、祖魯語、豪薩語、伊博語是最常用的語言 |
| **社會結構** |年齡階級系統、部落歸屬、強烈的社區認同 |
| **多樣性說明** |地球上基因和文化最多樣化的大陸。對「非洲文化」的概括就像對「歐洲文化」的概括——在高層次上是可能的，但在細節上會產生誤導 |
＃＃＃ 拉美
|方面|詳情 |
|--------|---------|
| **國家** |墨西哥、巴西、阿根廷、哥倫比亞、秘魯、智利等 |
| **哲學根源** |原住民文明（阿茲特克、瑪雅、印加）、天主教、非洲僑民影響 |
| **關鍵值** |家庭（familismo）、個人關係（personalismo）、溫暖、時間的彈性 |
| **溝通方式** |高語境；身體接近和觸摸是正常的；間接分歧|
| **時間導向** |多時性－同時執行多項任務；關係優先於日程安排|
| **商業文化** |信任和個人聯繫先於業務；會議從擴展的社交對話開始 |
### 西方（歐洲、北美、澳洲）
|方面|詳情 |
|--------|---------|
| **國家** |美國、加拿大、英國、德國、法國、澳洲、紐西蘭、北歐國家 |
| **哲學根源** |希臘羅馬哲學、基督教、啟蒙運動、自由主義 |
| **關鍵值** |個人主義、任人唯賢、直接、準時、創新|
| **溝通方式** |低語境：意義明確； “說出你的意思”|
| **時間導向** |單一性－時間是一種需要管理的資源；守時是一種美德|
| **商業文化** |任務第一；重視效率；合約高於關係；扁平的等級制度（特別是在北歐國家）|
> **西方內部的多元性**：北歐社會民主主義與美國資本主義有很大不同。德國人的直接與英國人的禮貌不同。義大利人的表現力與瑞士人的矜持不同。 「西方文化」是一個有用的縮寫，但不是一個整體。

## 溝通風格：高語境與低語境
愛德華·T·霍爾的框架是跨文化理解最實用的工具之一。
|特色 |高語境 |低語境 |
|---------|-------------|----------|
| **含义** |在情境、关系和非语言暗示中 |用明确的话来说|
| **协议** |以信任为基础；可能是口头的 |书面合同优先 |
| **不同意** |间接; “也许”通常意味着“不” |直接的; “不”的意思是“不” |
| **反馈** |微妙的;私下交付保住面子|明确；直接发货|
| **沉默** |舒服的;有意义|不舒服；出问题了|
| **示例** |日本、中国、阿拉伯国家、拉丁​​美洲|美国、德国、斯堪的纳维亚、瑞士 |

## 社會結構和組織
|結構|描述 |常見之處 |
|------------|-------------|-------------|
| **核心家庭** |限家長 + 孩子 |全球西方國家、城市地區|
| **大家庭** |多代人共同生活或密切接觸|南亞、中東、非洲、拉丁美洲 |
| **氏族/部落** |擁有共同祖先的更大的親屬群體|非洲、中東、中亞部分地區 |
| **種姓/階級** |世襲的社會分層|歷史印度（現已合法廢除）；階級制度無所不在|
| **平等主義** |最小的層級結構；以績效為基礎 |北歐國家線上社群|

## 宗教與文化實踐
宗教不僅僅是信仰，它還影響著飲食、穿著、日曆、性別角色、工作時間和法律體系。
|宗教 |追隨者|主要文化影響|
|----------|----------|----------------------|
| **基督教** |約 24 億 |週日休息；聖誕節/復活節日曆；影響了西方的法律和道德|
| **伊斯蘭教** |約 19 億 |每日五次祈禱；齋戒月齋戒；清真飲食法；週五為集會日|
| **印度教** |約 12 億 |種姓影響；許多人實行素食主義；排燈節/灑紅節；牛尊|
| **佛教** |約 5 億 |冥想;非暴力；修道院傳統；世俗環境中的正念|
| **錫克教** |約 3000 萬 |頭巾；蘭加爾（社區廚房）；平等;服務（服務）|
| **猶太教** |約 1500 萬 |安息日（週六休息）；猶太飲食法；崇高的聖日；重視學習|
| **世俗/非宗教** |約 12 億 |沒有宗教日曆；多元價值觀；不同國家差異很大|

## 全球化與文化變革
文化不是靜態的。全球化、移民和網路正在重塑世界各地的文化習俗。
**均質化與雜交：**
- 有些人認為全球化正在創造單一的消費文化（麥當勞、Netflix、英語作為通用語言）
- 其他人則看到雜交：當地文化吸收並改變全球影響（寶萊塢、韓國流行音樂、非洲節奏）
- 現實是兩者兼具：表面層的融合（服飾、科技）與深層的多元性（價值觀、溝通、認同）
**主要趨勢：**
- 都市化：超過 56% 的世界人口居住在城市（1950 年為 30%）
- 移民：全球約有 2.8 億國際移民，創造了僑民社區
- 數位文化：社群媒體創造跨國文化社區
- 語言轉換：世界上約 7,000 種語言中約 40% 處於瀕危狀態；英語、普通話和西班牙語占主導地位
---

＃＃ 概括
了解其他文化並不是關於刻板印象，而是關於培養文化智慧：認識到你的規範不具有普遍性、適當地調整你的行為以及跨越差異相互尊重的能力。上述框架（文化維度、高/低背景、社會結構）是思考的工具，而不是給人們貼上標籤的盒子。每個人都同時受到多種文化的影響──國家的、地區的、專業的、世代的、家庭的。我們的目標不是根據護照來預測某人的行為方式，而是以好奇心而不是判斷力來對待差異。
