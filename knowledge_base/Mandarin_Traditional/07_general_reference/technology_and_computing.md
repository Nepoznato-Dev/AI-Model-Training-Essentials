# 技術與計算
計算無所不在——在你的手機、你的汽車、你的冰箱、你的醫療設備以及運行現代社會的基礎設施中。您無需成為程式設計師即可從了解其工作原理中受益。該文件涵蓋了基礎知識：什麼是電腦、互聯網如何運作、軟體如何建構以及塑造數位世界的概念。
> **想要深入了解嗎？ ** 該文件是一個廣泛的概述。任何主題的詳細介紹，請參閱[`01_coding_and_technology/`](../01_coding_and_technology/)中的專用檔案 — 包括、[database systems](../01_coding_and_technology/database_systems.md)、[cloud architecture](../01_coding_and_technology/cloud_architecture.md)、[networking](../01_coding_and_technology/networking_basics.md)和。

## 什麼是計算機？
從本質上講，每台電腦（從智慧型手機到超級電腦）都做同樣的事情：接受輸入，根據指令（程式）處理它，並產生輸出。神奇之處在於速度和規模。
### 馮諾依曼架構
幾乎所有現代電腦都遵循以下基本設計：
|組件|它有什麼作用 |類比|
|------------|-------------|---------|
| **CPU**（中央處理單元）|執行指令；“大腦” |主廚按照食譜做|
| **RAM**（記憶體）|儲存CPU正在使用的資料；斷電時遺失|檯面－快速訪問，空間有限|
| **儲存**（SSD/HDD）|永久儲存資料 |食品儲藏室－存取速度較慢，空間較大 |
| **輸入/輸出** |鍵盤、滑鼠、螢幕、網路|廚師如何接單並送餐 |
| **GPU**（圖形處理單元）|用於平行任務（圖形、AI）的專用處理器 |一組助手同時執行相同的任務 |
**關鍵見解**：RAM 速度很快，但只是暫時的。儲存速度緩慢但持久。當您的電腦「感覺很慢」時，通常是因為它的 RAM 不足，必須使用儲存空間作為臨時記憶體（交換），這要慢得多。

## 互聯網如何運作
互聯網與網路不同。網路是實體網路——連接數十億設備的電纜、路由器、伺服器和協定。萬維網是一項在網路上運行的服務（還有電子郵件、文件傳輸、串流媒體、遊戲等）。
### Web 請求的旅程
當您在瀏覽器中輸入`https://www.example.com`時：
1. **DNS 查找**：您的瀏覽器要求 DNS 伺服器將「www.example.com」轉換為 IP 位址（如 93.184.216.34）。
2. **TCP 連線**：您的裝置使用 TCP（保證可靠傳輸的協定）建立與該 IP 位址的連線。
3. **TLS 握手**：如果使用 HTTPS，您的瀏覽器和伺服器將協商加密連線。
4. **HTTP 請求**：您的瀏覽器發送請求：“給我 /index.html 的頁面。”
5. **伺服器處理**：Web 伺服器查找頁面，可能會查詢資料庫，並準備回應。
6. **HTTP 回應**：伺服器傳回 HTML、CSS 和 JavaScript。
7. **渲染**：您的瀏覽器解析 HTML、套用 CSS 樣式並執行 JavaScript 以顯示頁面。
整個過程通常需要不到一秒鐘的時間。
### 關鍵協議
|協定|它有什麼作用 |層|
|----------|-------------|--------|
| **IP**（網際網路協定）|在網路之間路由資料包 |網路|
| **TCP** |可靠、有序的傳送（重新傳輸遺失的資料包）|交通 |
| **UDP** |快速、不可靠的傳送（無重送）|交通 |
| **HTTP/HTTPS** |網頁傳輸（HTTPS新增加密）|應用程式 |
| **DNS** |將網域轉換為 IP 位址 |應用程式 |
| **SSH** |安全地遠端存取電腦|應用 |
| **SMTP/IMAP** |電子郵件傳送與接收 |應用 |

## 軟體開發－程式如何構建
### 開發流程
1. **編寫程式碼**：開發人員用程式語言寫指令。
2. **測試程式碼**：執行程式碼以驗證是否正常運作。
3. **版本控制**：使用通用標準 Git 追蹤變更。
4. **審查**：其他開發人員檢查程式碼的錯誤和品質。
5. **Build**：將原始碼轉換為可運行的程式（編譯）。
6. **部署**：將程式發佈給使用者（伺服器、應用程式商店等）。
7. **監控**：監視生產中的錯誤和效能問題。
### 關鍵概念
|概念 |這意味著什麼？為什麼這很重要？
|--------|-------------|----------------|
| **版本控制 (Git)** |追蹤一段時間內程式碼的每次變更 |合作;修正錯誤的能力|
| **API**（應用程式介面）|軟體元件通訊的定義方式 |允許不同系統協同工作 |
| **資料庫** |資料有組織的儲存|每個應用程式都需要儲存和檢索資料|
| **測試** |自動檢查程式碼是否正常運作 |防止錯誤影響使用者 |
| **CI/CD**（持續整合/交付）|從程式碼提交到生產的自動化管道 |更快、更安全的發布 |
| **容器化（Docker）** |打包應用程式及其所有依賴項 | “在我的機器上運行”變成“在任何地方都可以運行”|

## 資料庫－資料所在
每個應用程式都需要儲存資料。資料庫是高效、可靠地完成此任務的系統。
|類型 |資料如何儲存 |最適合 |範例 |
|------|--------------------|----------|---------|
| **關係式 (SQL)** |有行和列的表格；嚴格的模式|結構化資料；複雜的查詢；交易 | PostgreSQL、MySQL、SQLite |
| **文檔 (NoSQL)** |類似 JSON 的文檔；靈活的模式|半結構化資料；快速迭代 | MongoDB、CouchDB |
| **鍵值** |簡單鍵→值對|快取；會話儲存；快速尋找| Redis、DynamoDB |
| **圖表** |節點與邊（關係）|社群網路；推薦引擎| Neo4j、JanusGraph |
| **時間序列** |針對帶有時間戳記的資料進行了最佳化 |監控；分析；物聯網 | InfluxDB、TimescaleDB |
**SQL**（結構化查詢語言）是關聯式資料庫的標準語言。這是您可以學習的最有價值的技術技能之一 - 幾乎每個組織都使用資料庫，而 SQL 是您與他們交談的方式。

## 作業系統
作業系統 (OS) 是您（和您的程式）與硬體之間的軟體層。它管理記憶體、進程、檔案和設備。
|作業系統 |它在哪敵占主導地位|主要特點|
|----|--------------------|-------------|
| **Windows** |桌上型電腦/筆記型電腦（約 72% 的市佔率）|最廣泛的軟體/硬體相容性 |
| **macOS** |創意專業人士、開發人員 |基於Unix；精美的使用者介面；蘋果生態系統 |
| **Linux** |伺服器 (~96%)、超級電腦 (100%)、嵌入式、開發人員 |開源；自由的;高度可自訂|
| **安卓** |行動（全球市佔率約 72%）|基於Linux核心；開源|
| **iOS** |移動（全球約 27%，但收入更高）|封閉的生態系統；拋光；注重隱私 |
Linux 值得特別一提：它為大部分互聯網、每台 500 強超級電腦、大多數雲端基礎設施以及所有 Android 手機提供動力。它是免費的、開源的，並由全球社群維護。

## 雲端運算
雲端運算意味著透過互聯網租用運算資源（伺服器、儲存、資料庫等），而不是購買和維護自己的硬體。有關雲端架構、服務模型和提供者比較的綜合指南，請參閱[cloud architecture](../01_coding_and_technology/cloud_architecture.md)。
|服務模式|你得到什麼 |類比|範例 |
|----------------|-------------|---------|---------|
| **IaaS**（基礎設施）|虛擬伺服器、儲存、網路|租一塊地，建造你想要的東西 | AWS EC2、Google運算引擎 |
| **PaaS**（平台）|運行時環境；你帶上代碼|出租帶家具的公寓 | Heroku，Google應用程式引擎 |
| **SaaS**（軟體）|完成申請；你只要使用它|入住飯店 | Gmail、Slack、Salesforce |
三大雲端供應商分別是**AWS**（亞馬遜，約 32% 的市佔率）、**Azure**（微軟，約 23%）和 **GCP**（Google，約 10%）。他們提供數百種服務，涵蓋運算、儲存、資料庫、人工智慧、網路等。

## 網路安全－保護數位系統
網路安全是保護電腦、網路和資料免受攻擊的實踐。這很重要，因為一切都是相互關聯的，而違規的成本是巨大的。涵蓋 OWASP Top 10、安全開發生命週期和機密管理的完整指南，請參閱。
### 常見威脅
|威脅|它是什麼 |預防|
|--------|------------|------------|
| **惡意軟體** |惡意軟體（病毒、蠕蟲、木馬）|防毒；保持軟體更新 |
| **網路釣魚** |虛假電子郵件/訊息誘騙您洩露資訊 |訓練;電子郵件過濾；懷疑主義|
| **勒索軟體** |加密您的資料；要求支付鑰匙費用|備份；修補程式系統；不付錢|
| **DDoS** |流量壓垮服務 |流量過濾； CDN保護|
| **SQL注入** |將惡意 SQL 插入輸入欄位 |參數化查詢；輸入驗證|
| **中間人** |攔截兩方之間的通訊 | HTTPS/TLS 加密 |
### 安全基礎知識
- **加密**：對資料進行加密，以便只有授權方才能讀取它。 HTTPS 使用 TLS 加密 Web 流量。
- **身份驗證**：驗證身份。使用多重身份驗證 (MFA) — 密碼 + 其他內容（代碼、生物識別）。
- **授權**：驗證權限。僅僅因為您已登入並不意味著您應該訪問所有內容。
- **最小權限原則**：僅向使用者和系統提供他們需要的存取權限，僅此而已。
- **修補程式管理**：保持軟體更新。大多數違規行為都利用了已經有修補程式的已知漏洞。

## 資料格式
程式以特定格式交換資料。最常見的：
|格式|結構|用於 |
|--------|------------|----------|
| **JSON** |鍵值對；人類可讀 |蜜蜂;配置;資料交換|
| **XML** |基於標籤；冗長但靈活 |遺留系統；文件； SOAP API |
| **YAML** |基於縮排；非常易讀 |配置（Docker、Kubernetes、CI/CD）|
| **CSV** |純文字行與列|資料匯入/匯出；電子表格|

＃＃ 概括
計算不是魔法——它是工程。計算機以令人難以置信的速度執行指令。網路使用標準化協定將數十億個設備連接起來。軟體是由在迭代周期中編寫、測試和部署程式碼的團隊所建構的。資料庫儲存和檢索資料。雲端運算讓任何人都可以按需存取海量運算資源。網路安全是一場持續不斷的戰鬥，目的是確保所有這些都免受那些想要利用它的人的侵害。了解這些基礎知識可以幫助您駕馭數位世界——無論您是使用者、開發人員，還是只是試圖理解塑造現代生活的技術的人。
