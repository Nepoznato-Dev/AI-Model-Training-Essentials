# 醫藥與保健
醫學是診斷、治療和預防疾病的科學和實踐。這是人類最古老的事業之一——希波克拉底誓言可以追溯到古希臘——也是變化最快的事業之一。光是上個世紀，我們就從沒有抗生素發展到擁有可以重寫患者 DNA 的基因療法。
該文件涵蓋了醫學的運作方式：主要專業、疾病如何診斷和治療、醫療保健系統如何組織，以及當人類生命受到威脅時出現的道德問題。
---

## 身體如何運作－快速瀏覽
在了解疾病之前，了解健康是什麼樣子會有所幫助。人體有 11 個主要器官系統，每個器官系統都有特定的功能，但緊密相連。
|系統|重要器官|主要功能|常見問題 |
|--------|---------|-----------------|-----------------|
| **心血管** |心臟、血管|泵血；輸送氧氣和營養|心臟病、中風、高血壓|
| **呼吸系統** |肺部、呼吸道 |交換氧氣和二氧化碳 |氣喘、慢性阻塞性肺病、肺炎、肺癌|
| **消化** |胃、腸、肝、胰|分解食物；吸收營養；消除浪費| GERD、潰瘍、IBD、肝病 |
| **緊張** |大腦、脊髓、神經 |處理訊息；控制身體功能|阿茲海默症、帕金森氏症、癲癇、中風|
| **內分泌** |腦下垂體、甲狀腺、腎上腺、胰臟 |產生調節新陳代謝、生長、繁殖的荷爾蒙|糖尿病、甲狀腺疾病、肥胖|
| **免疫/淋巴** |白血球、淋巴結、脾 |防禦病原體 |自體免疫疾病、免疫缺陷、過敏 |
| **肌肉骨骼** |骨骼、肌肉、關節 |支撐體；啟用運動|關節炎、骨質疏鬆、骨折、背痛|
| **泌尿/腎臟** |腎臟、膀胱 |過濾血液；清除廢物；調節液體|腎臟疾病、泌尿道感染、腎結石 |
| **生殖** |卵巢/睪丸、子宮等|啟用複製 |不孕不孕、癌症、荷爾蒙失調 |
| **外皮** |皮膚、頭髮、指甲|保護身體；調節溫度|濕疹、牛皮癬、皮膚癌、感染 |
| **血液學** |血液、骨髓|輸送氧氣；對抗感染；血塊|貧血、白血病、凝血障礙|
### 體內平衡－身體的平衡行為
身體的每個系統都致力於維持**體內平衡**——儘管外部發生變化，仍保持內部條件穩定。無論室外嚴寒還是酷熱，您的體溫都會保持在 37°C 左右。血液 pH 值保持在 7.35 至 7.45 之間。血糖在一個狹窄的範圍內上升和下降，受胰島素和升糖素的調節。
當體內平衡被破壞時，通常會發生疾病。發燒是您的免疫系統故意提高體溫以抵抗感染。糖尿病是血糖調節失敗。心臟衰竭是心血管系統無法維持足夠的血流量。

## 診斷 — 找出問題所在
診斷是一個排除和確認的過程。醫生收集線索（症狀、病史、檢查結果）並縮小可能性。
### 診斷過程
1. **病史**：有什麼症狀？他們什麼時候開始的？是什麼讓它們變得更好或更糟？家史？藥物治療？僅此一點就大大縮小了可能性。
2. **身體檢查**：生命徵象（體溫、血壓、心跳）、聽心肺、觸診腹部、檢查反射。
3. **鑑別診斷**：可能情況的排名列表，從最有可能到最不可能（以及從最危險到最不危險）。
4. **測試**：指令確認或排除差速器上的情況。
### 常見診斷測試
|測試|它顯示了什麼 |最適合 |
|------|--------------|----------|
| **血液檢測（CBC）** |紅/白血球、血小板 |感染、貧血、血液疾病|
| **代謝面板** |腎功能、肝功能、電解質、血糖|器官功能、糖尿病篩檢|
| **X 光** |緻密結構（骨骼、肺）|骨折、肺炎、心臟大小|
| **CT 掃描** |使用 X 光觀察詳細的橫斷面 |外傷、腫瘤、內出血|
| **核磁共振** |優秀的軟組織細節（無放射線）|腦腫瘤、韌帶撕裂、脊椎問題 |
| **超音波** |使用聲波的即時影像 |懷孕、膽結石、心臟功能|
| **切片** |顯微鏡下檢查的組織樣本|癌症診斷、發炎狀況|
| **心電圖/心電圖** |心臟的電活動|心律不整、心臟病發作 |
| **內視鏡檢查** |相機穿過消化道|潰瘍、息肉、癌症|
### 篩檢 — 在出現症狀之前發現疾病
篩檢測試會在感覺良好的人身上尋找疾病。我們的目標是在問題更容易治療時及早發現問題。
|放映|誰 |多久一次 |
|------------|-----|------------|
| **血壓** |成人所有 |每 1-2 年 |
| **膽固醇** | 20 歲以上成人 |每 4-6 年 |
| **乳房X光檢查** | 40-74 歲女性 |每 1-2 年 |
| **大腸鏡檢查** | 45-75 歲成人 |每10年|
| **子宮頸抹片檢查** | 21-65 歲女性 |每 3-5 年 |
| **糖尿病篩檢** | 35-70 歲超重的成年人 |每 3 年 |

## 治療－解決問題
治療選擇範圍從無所作為（許多情況會自行解決）到積極幹預。正確的方法取決於病情、嚴重程度、患者的整體健康狀況以及有效的證據。
|方法|範例 |使用時 |
|----------|---------|------------|
| **警惕等待** |無需積極治療即可監測|可能解決的小問題；低風險發現|
| **生活方式的改變** |飲食、運動、睡眠、壓力管理|許多慢性疾病（高血壓、2 型糖尿病）的一線治療 |
| **藥物** |抗生素、降血壓藥、胰島素、抗憂鬱藥|當生活方式的改變還不夠時 |
| **手術** |闌尾切除術、關節置換術、腫瘤切除|當結構問題需要物理修復時 |
| **放射治療** |標靶放射殺死癌細胞|癌症治療，通常與手術結合|
| **免疫治療** |利用免疫系統對抗癌症|某些癌症（黑色素瘤、肺癌）|
| **物理治療** |恢復運動和功能的練習|受傷、手術或慢性疼痛後 |
| **心理治療** |談話療法（CBT、心理動力學等）|心理健康狀況；對慢性疼痛也有效|
| **安寧療護** |症狀緩解和生活品質|嚴重疾病；不限於報廢 |
### 藥理基礎知識
|藥品類|它有什麼作用 |範例 |重要提示|
|------------|-------------|----------|----------------|
| **抗生素** |殺死細菌 |青黴素、阿莫西林、環丙沙星|不針對病毒；過度使用會產生抵抗力|
| **止痛藥** |緩解疼痛|布洛芬、對乙醯氨基酚、嗎啡 |鴉片類藥物具有高度成癮性；謹慎使用|
| **抗高血壓藥** |降低血壓 | ACE 抑制劑、β 受體阻斷劑、利尿劑 |經常需要多種藥物；終身治療|
| **他汀類藥物** |降低膽固醇 |阿托伐他汀、瑞舒伐他汀 |全球處方最多的藥物之一 |
| **抗凝血劑** |預防血栓|華法林、肝素、阿哌沙班 |出血風險；需監測|
| **抗憂鬱藥物** |治療憂鬱症和焦慮症 | SSRIs、SNRIs、三環類 |需要幾週的時間才能工作；不要突然停下|
| **胰島素** |降低血糖 |速效、長效|對於第 1 型糖尿病至關重要；有時適用於類型 2 |
| **化療** |殺死快速分裂的細胞 |順鉑、紫杉醇|健康快速分裂細胞受損帶來的副作用

## 醫療保健系統－社會如何組織護理
各國的醫療保健系統差異巨大，但它們都面臨著相同的根本挑戰：如何在不導致個人或系統破產的情況下為每個人提供高品質的照護。
|型号|它是如何运作的 |示例 |优势 |弱点|
|--------|-------------|----------|------------|------------|
| **單一付款人** |政府資助並經常提供護理|英國 (NHS)、加拿大、斯堪的納維亞 |全民覆蓋；成本控制|等待時間；選擇有限|
| **社會保險** |雇主和僱員對非營利性「疾病基金」的強制性繳款|德國、法國、日本 |普遍的;多家保險公司競爭|複雜的;昂貴|
| **多付款人（基於雇主）** |透過雇主提供私人保險；政府涵蓋老年人/窮人|美國 |創新;被保險人等待時間短| 2700 萬人沒有保險；最高成本|
| **自付费用** |患者直接付款 |大多数低收入国家 |简单|只有富人才能得到照顾|
美國人均醫療保健支出大約是其他富裕國家的兩倍，許多指標（預期壽命、嬰兒死亡率、可預防的死亡）的結果更差。原因很複雜：行政浪費、藥品價格高、獎勵數量多於價值的按服務收費激勵措施以及不平等的取得機會。

## 公共衛生－保護人群
臨床醫學關注的是個別患者，而公共衛生關注的是人群。其工具包括流行病學、疫苗接種、衛生、教育和政策。
### 最偉大的公共衛生成就
1. **疫苗接種** — 消滅天花，幾乎消滅小兒麻痺，每年防止數百萬人死亡
2. **清潔水和衛生設施** — 已開發國家消除了霍亂；仍然是發展中國家的主要殺手
3. **抗生素**－將傳染病從死刑轉變為可治療的疾病
4. **菸草控制**－許多國家的吸菸率大幅下降，預防了數百萬人的癌症和心臟病
5. **道路安全**－安全帶、安全氣囊和酒駕法使許多國家的交通死亡率降低了一半
### 流行病學 — 模式科學
流行病學家研究疾病如何在人群中傳播。關鍵概念：
|術語 |意義|範例|
|------|---------|---------|
| **發生率** |一段時間內的新病例 |每年每 10 萬人新增 500 例糖尿病病例 |
| **盛行率** |某個時間點的現有病例總數 |目前有 10% 的成年人患有糖尿病 |
| **死亡率** |疾病死亡人數 |每 10 萬人中有 150 人死於心臟病 |
| **R₀（R-無）** |一名感染者平均會感染多少人|麻疹：12-18；流感：1-2 |
| **群體免疫** |當足夠多的人具有免疫力時，疾病就不會輕易傳播|需要約 95% 的人接種麻疹疫苗 |

## 醫學倫理—難題
醫學提出的倫理問題沒有簡單的答案。指導大多數醫學道德的四個原則：
1. **自主**：即使醫生不同意，病人也有權就自己的照護做出明智的決定。
2. **仁慈**：以病人的最大利益為出發點。
3. **非惡意**：「首先，不要傷害。」避免弊大於利的治療。
4. **正義**：公平分配醫療資源。
這些原則有時會發生衝突。患者可能會拒絕挽救生命的治療（自主與仁慈）。一種昂貴的藥物可能會使一名患者受益，但會消耗許多其他患者的資源（慈善與正義）。
現代醫學的關鍵倫理問題：
- **安寧療護**：何時撤回維生系統適合？安寧療護（減輕痛苦）和安樂死（故意結束生命）有什麼不同？
- **知情同意**：患者在同意治療之前必須了解風險、好處和替代方案。這比聽起來更複雜——大多數患者並不完全了解統計風險。
- **資源分配**：當器官不足時誰接受器官移植？大流行期間誰獲得呼吸器？
- **基因測試和編輯**：我們現在可以篩選胚胎的遺傳疾病並使用 CRISPR 編輯基因。我們應該嗎？治療疾病和「設計」嬰兒之間的界線在哪裡？
- **人工智慧在醫學中**：當人工智慧診斷工具出錯時，誰該負責？我們如何確保人工智慧不會編碼偏見？

＃＃ 概括
醫學既是一門科學，也是一門藝術。科學是非凡的——我們可以在數小時內對基因組進行測序，用幹細胞培育器官，並重新編程免疫系統來對抗癌症。藝術在於將科學應用於個別患者，每個患者都有自己的價值觀、環境和偏好。世界各地的醫療保健系統都在努力應對同樣的挑戰：在不破產的情況下為每個人提供高品質的照護。隨著治療方法變得更加先進和人口老化，醫學上可行與經濟上永續之間的緊張關係只會加劇。了解醫學的工作原理——如何診斷、治療和預防疾病——對於就自己的健康和社會的健康做出明智的決定至關重要。
