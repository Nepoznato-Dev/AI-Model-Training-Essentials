# 化學
如果物理是遊戲規則，那麼化學就是各個部分相互作用時發生的事情。化學研究原子如何結合、分裂和重新排列——也就是說，所有材料的行為。它彌合了基礎物理學與複雜的生物學、地質學和工程學之間的差距。
---

## 原子結構
### 30 秒了解原子
原子有一個原子核（質子+中子），周圍有殼層中的電子。質子數定義了元素（1 = 氫，6 = 碳，79 = 金）。中子數決定同位素（碳 12 與碳 14）。電子的排列決定了原子如何與其他原子結合。
|粒子|充電|品質 (amu) |地點 |
|----------|--------|------------|----------|
| **質子** | +1 | 〜1 |核心 |
| **中子** | 0 | 〜1 |核心 |
| **電子** | −1 | ~1/1836 |電子殼|
### 電子組態
電子佔據原子核周圍的殼層（能階）。每個殼層擁有最大數量的電子：
|壳牌|麦克斯电子|子壳 |距核的距离 |
|--------|--------------|------------|------------------------|
| **1 (K)** | 2 | 1秒|最近的|
| **2（大）** | 8 | 2 秒，2 秒 | |
| **3（男）** | 18 | 18 3s、3p、3d | |
| **4（N）** | 32 | 32 4s、4p、4d、4f |最远（化合价）|
最外層的殼（價殼）決定化學行為。具有全價殼層的原子（稀有氣體）是惰性的；具有不完整殼層的原子反應以實現穩定性。

## 元素週期表
元素週期表不是隨機列表，而是化學行為圖。同一列（組）中的元素表現相似，因為它們具有相同數量的價電子。
### 關鍵群體
|集團|元素|行為 |
|--------|----------|----------|
| **鹼金屬**（第 1 組）|李、娜、K… |反應性極強，失去 1 個電子，在水中爆炸 |
| **鹼土金屬**（第 2 族）|鈹、鎂、鈣... |反應性，失去 2 個電子，形成鹼性氧化物 |
| **鹵素**（第 17 組）| F、Cl、Br、I... |非常活潑，獲得 1 個電子，形成鹽 |
| **稀有氣體**（第 18 組）|他、Ne、Ar... |幾乎完全惰性－完整的電子殼層|
| **過渡金屬**（第 3-12 族）|鐵、銅、金...|可變氧化態，形成有色化合物 |
| **鑭系元素** (57-71) | Ce、Nd、Eu... |稀土元素；用於磁鐵、雷射、磷光體|
| **錒系元素** (89-103) | U、Pu、Am... |全部具有放射性；核能中使用的鈾和鈽|
### 週期性趨勢
|趨勢 |跨越一個時期 (→) |下一組 (↓) |
|--------|---------------------|--------------------|
| **原子半徑** |減少（更多質子將電子拉得更緊）|增加（更多電子殼層） |
| **電離能** |增加（更難去除電子）|減少（外層電子遠離原子核）|
| **電負性** |增加（共享電子的吸引力更強）|減少 |
| **金屬特性** |減少 |增加|

## 化學鍵合
原子鍵結以實現穩定的電子組態。三種主要類型：
### 債券類型
|債券類型|機制|實力|範例|
|------------|------------|----------|---------|
| **離子** |一個原子放棄一個電子，另一個原子接受它。相反的電荷相互吸引。 |強|氯化鈉（食鹽）|
| **共價** |原子共享電子。 |比離子強 | H2O（水）、CO2、DNA |
| **金屬** |電子在原子間自由流動，形成電荷「海洋」。 |變數|鐵、銅、金（所有金屬）|
### 分子間力
除了分子內的鍵之外，分子之間的力決定熔點、沸點和溶解度：
|力|實力|範例|
|--------|----------|---------|
| **氫鍵** |強（分子間力）|水 (H2O)、DNA 鹼基對 |
| **偶極子-偶極子** |中|鹽酸、丙酮|
| **倫敦分散** |弱（但普遍）|所有分子；在石油等非極性物質中占主導地位
氫鍵是水如此小分子的沸點異常高的原因，也是冰漂浮的原因（氫鍵形成開放的晶體結構）。

## 化學反應
化學反應會重新排列原子——打破舊的鍵並形成新的鍵——而不改變原子本身。
### 反應類型
|類型 |圖案|範例|
|------|---------|---------|
| **合成** | A + B → AB | 2H2 + O2 → 2H2O |
| **分解** | AB → A + B | 2H2O → 2H2 + O2 |
| **單一更換** | A + BC → AC + B | Zn + CuSO₄ → ZnSO₄ + Cu |
| **雙重更換** | AB + CD → AD + CB | AgNO₃ + NaCl → AgCl + NaNO₃ |
| **燃燒** |燃料 + O2 → CO2 + H2O | CH₄ + 2O2 → CO2 + 2H2O |
| **氧化還原** |物種之間的電子轉移 |生鏽：4Fe + 3O2 → 2Fe2O₃ |
### 平衡方程
每個化學方程式兩側的每種類型原子的數量必須相同（質量守恆）。調整係數（分子前面的數字）以達到平衡，而不是分子內的下標。
### 反應率
|因素 |對利率的影響|為什麼 |
|--------|----------------|-----|
| **溫度** |增加|分子運動得更快，碰撞更劇烈 |
| **專注** |增加|每體積更多的分子，更多的碰撞 |
| **表面積** |增加|更多暴露的顆粒可發生反應|
| **催化劑** |增加|降低活化能而不被消耗 |
| **壓力**（氣體）|增加|分子被迫靠得更近|

## 酸、鹼和 pH 值
pH 範圍為 0 至 14。低於 7 為酸性，高於 7 為鹼性（鹼性），7 為中性。
|物質 |酸鹼度|筆記|
|------------|-----|--------|
| **胃酸** | 〜1.5 |強度足以溶解金屬 |
| **檸檬汁** | 〜2.0 |檸檬酸|
| **醋** | 〜2.5 |醋酸|
| **純水** | 7.0 |中性|
| **血** | 〜7.4 |嚴格監管； ±0.5的偏差可能是致命的 |
| **小蘇打溶液** | 〜8.5 |溫和的鹼 |
| **漂白水** | 〜13 |強鹼（氫氧化鈉）|
每個整數階躍代表酸度的 10 倍變化，因此 pH 3 的酸性是 pH 4 的十倍，是 pH 5 的一百倍。

## 有機化學
有機化學是對碳基化合物的研究。碳是獨特的－它形成四個穩定的共價鍵，可以以長鏈和環的形式與自身結合，是所有已知生命的基礎。
### 關鍵功能組
|集團|結構|發現於 |
|--------|------------|----------|
| **羥基** (−OH) |氧氣+氫氣|醇類（乙醇、甲醇）|
| **羰基** (C=O) |碳與氧雙鍵 |醛、酮、糖|
| **羧基** (−COOH) |羰基+羥基|有機酸（醋酸、胺基酸）|
| **氨基** (−NH2) |氮+兩個氫|胺基酸、蛋白質 |
| **磷酸鹽** (−PO₄) |磷+四個氧| DNA、ATP（細胞能量）|
| **甲基** (−CH₃) |碳+三個氫 |基因表現（甲基化），脂肪 |
### 生命大分子
|高分子|積木 |功能|
|----------------|----------------|----------|
| **蛋白質** |胺基酸（20種）|酵素、結構、訊號傳導、運輸 |
| **碳水化合物** |單醣（葡萄糖）|結構儲能（纖維素）|
| **脂質** |脂肪酸+甘油 |細胞膜、長期能量儲存、荷爾蒙|
| **核酸** |核苷酸|資訊儲存（DNA、RNA）|

## 物質狀態
|狀態 |形狀|卷 |粒子行為|
|--------|--------|--------|--------------------|
| **固體** |固定|固定|粒子原地振動；牢固的聯繫|
| **液體** |呈容器形狀|固定|粒子互相滑過；中等債券|
| **天然氣** |填充容器|填充容器|顆粒自由移動；弱/無鍵 |
| **等離子** |填充容器|填充容器|電離氣體；從原子中剝離的電子（恆星、閃電）|
在特定溫度和壓力下發生相變：熔化、凍結、蒸發、冷凝、昇華（直接固體→氣體）和沈積（氣體→固體）。

＃＃ 概括
化學是研究原子如何結合和相互作用的科學。元素週期表根據元素的化學行為來組織元素，而化學行為是由電子組態決定的。原子以離子鍵（轉移電子）、共價鍵（共享電子）或金屬鍵（自由流動電子）鍵結。化學反應在質量守恆的同時重新排列原子，其速率取決於溫度、濃度、表面積和催化劑。酸和鹼以對數 pH 值表示。有機化學—碳化合物的研究—透過四種大分子類別來支撐所有生物學：蛋白質、碳水化合物、脂質和核酸。了解化學對於生物學、醫學、材料科學、環境科學和工程至關重要。
