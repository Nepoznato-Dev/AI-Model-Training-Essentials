# 遺傳學和基因組學
遺傳學是一門研究遺傳的學科，即性狀如何透過 DNA 從父母傳給後代。基因組學是對整個基因組的研究：所有基因、非編碼區域、它們如何相互作用以及它們如何在個體和人群中變化。從遺傳學到基因組學的轉變是由定序技術推動的——我們從一次研究一個基因發展到在數小時內讀取整個基因組，產生的數據正在改變醫學、農業、法醫學以及我們對演化的理解。

## DNA 基礎知識
### DNA 結構
|組件|描述 |
|------------|-------------|
| **核苷酸** | DNA 的組成部分；由糖（脫氧核糖）、磷酸基團和含氮鹼基組成 |
| **基地** |腺嘌呤 (A)、胸腺嘧啶 (T)、鳥嘌呤 (G)、胞嘧啶 (C) |
| **鹼基配對** | A與T配對（2個氫鍵）； G 與 C 配對（3 個氫鍵）|
| **雙螺旋** |兩條反平行運行的鏈（5' 至 3' 和 3' 至 5'）；扭曲成螺旋|
| **染色體** |包裹著組蛋白的單一長 DNA 分子；人類有 46 個（23 對）|
| **基因組** |有機體中完整的DNA組；人類基因組約有 32 億個鹼基對 |
### 分子生物學的中心法則
|步驟|流程|地點 |產品 |
|------|---------|----------|---------|
| **複製** |去氧核糖核酸→去氧核糖核酸|核心 |兩個相同的DNA分子|
| **轉錄** | DNA → mRNA |核心 |信使RNA |
| **翻譯** | mRNA → 蛋白質 |核醣體（細胞質） |多肽鏈（蛋白質）|

## 基因表達
### 基因是如何調控的
|水平|機制|範例|
|--------|------------|---------|
| **表觀遺傳** | DNA甲基化；組蛋白修飾；染色質重塑 |女性中一條X染色體的沉默|
| **轉錄** |轉錄因子結合啟動子/增強子；活化或抑制|細菌中的紫膠操縱子；荷爾蒙反應基因|
| **轉錄後** |選擇性拼接； mRNA穩定性；微小RNA |一種基因→多種蛋白質變體|
| **翻譯** |核醣體可用性；起始因子調控|透過鐵蛋白 mRNA 調節鐵
| **翻譯後** |蛋白質修飾（磷酸化、泛素化）；降解|細胞週期控制|

## 繼承模式
### 孟德爾遺傳學
|圖案|描述 |範例|
|---------|-------------|---------|
| **體染色體顯性遺傳** |等位基因的一份副本就足夠了 |亨廷頓舞蹈症；軟骨發育不全 |
| **體染色體隱性遺傳** |需要兩份 |囊性纖維化;鐮狀細胞性貧血 |
| **X連鎖顯性** | X染色體上的基因；一份就足夠了 |雷特症候群|
| **X連鎖隱性** | X染色體上的基因；男性受影響更大血友病;色盲 |
| **共顯性** |兩個等位基因的表達相同| ABO 血型（A 和 B）|
| **不完全的統治** |雜合子是中間的|紅色和白色父母的粉紅色花朵|
| **多基因** |多個基因促成一種性狀 |高度;膚色；情報|
| **多效性** |一個基因影響多個性狀|馬凡氏症候群（結締組織、眼睛、心臟）|

## 基因組學
### 基因組學的類型
|類型 |焦點|應用 |
|------|--------|-------------|
| **結構基因體學** |基因組中所有蛋白質的 3D 結構 |藥物設計；蛋白質工程|
| **功能基因體學** |基因有什麼作用；基因交互作用；表現模式|了解疾病機制 |
| **比較基因體學** |比較不同物種的基因組 |演化關係；辨識保護區|
| **宏基因體學** |來自環境樣本的 DNA（未培養）|微生物組研究；發現新生物|
| **藥物基因體學** |基因如何影響藥物反應？個人化醫療；藥物劑量|
| **表觀基因組學** |全基因組表觀遺傳修飾|癌症診斷；發育生物學|
### DNA 定序技術
|一代|技術 |閱讀長度 |吞吐量|主要特點|
|------------|------------|-------------|------------|------------|
| **第一代** |桑格定序| 〜1,000 bp |低|黃金標準精度；用於驗證|
| **第二代** | Illumina（Solexa）| 50–300 bp |非常高|短讀；主導平台；每個鹼基成本低|
| **第二代** |離子激流| 200–400 bp |高|基於半導體；無光學|
| **第三代** |太平洋生物 (SMRT) | 10,000–100,000 bp |中|長讀；解決重複區域 |
| **第三代** |牛津奈米孔 |高達數百萬bp |中到高|超長閱讀；便攜式（MinION）；實時|

## 遺傳變異
### 變異類型
|類型 |描述 |頻率|
|------|-------------|------------|
| **SNP**（單核苷酸多態性）|單鹼基變化|最常見； ~1,000 個鹼基中就有 1 個 |
| **插入/刪除（indel）** |鹼基的添加或去除 |可能導致移碼突變|
| **CNV**（拷貝數變異）|重複或刪除的段落（1 kb – 幾 Mb）|有助於疾病和進化|
| **結構變化** |倒轉；易位；大重組|較不常見；可能致病|
| **微衛星（STR）** |短串聯重複序列（2-6 bp 重複）|法醫；親子鑑定 |
### GWAS（全基因組關聯研究）
|步驟|描述 |
|------|-------------|
| **1.收集樣本** |病例（有疾病）和對照（無疾病）|
| **2.基因型** |使用 SNP 陣列對數十萬種變異進行基因分型 |
| **3.統計檢定** |測試每個 SNP 與性狀的關聯 |
| **4.曼哈頓情節** |可視化所有染色體的結果 |
| **5.複製** |確認獨立樣本中的發現 |

## 基因編輯
### CRISPR-Cas9
|組件|功能|
|------------|----------|
| **引導 RNA (gRNA)** | 〜20個核苷酸；配對目標 DNA 序列 |
| **Cas9 蛋白** |分子剪刀；在目標位點切割 DNA |
| **PAM 序列** |目標旁的短基序 (NGG)； Cas9 結合所需 |
| **HDR**（同源定向修復）|使用捐贈者範本進行精確編輯 |
| **NHEJ**（非同源末端連接）|容易出錯的修復；創建插入/刪除（剔除）|
### 基因編輯應用
|應用 |描述 |
|-------------|-------------|
| **治療** |修正致病突變（鐮狀細胞；β-地中海貧血）|
| **農業** |抗病作物；改良牲畜|
| **研究** |創建淘汰模型；研究基因功能|
| **基因驅動** |在人群中傳播基因改造（例如抗瘧疾蚊子）|

## 道德考慮
|問題 |關注|
|--------|---------|
| **遺傳隱私** |誰擁有您的基因組資料？雇主或保險公司可以使用它嗎？ |
| **胚胎基因編輯** |可遺傳的變化；設計師嬰兒；意外的脫靶效應|
| **基因歧視** | GINA（美國）防止某些歧視，但仍存在差距 |
| **知情同意** |基因組數據揭示了未經同意的親屬信息
| **資料儲存** |基因組很大（原始基因組約 200 GB）；長期儲存與安全挑戰|
| **股權** |如果基因組醫學僅適用於富裕人群，則可能會擴大健康差距
---

＃＃ 概括
遺傳學研究個體基因如何發揮作用並遺傳。基因組學研究整個基因組——所有基因、它們的相互作用以及它們的變異。 DNA被轉錄成RNA，RNA被翻譯成蛋白質。基因表現在多個層面上受到調節：表觀遺傳、轉錄、轉錄後、翻譯和翻譯後。遺傳遵循決定性狀如何在世代之間傳遞的模式（顯性、隱性、多基因）。現代定序技術（Illumina、PacBio、Nanopore）可以快速且便宜地讀取整個基因組。 CRISPR-Cas9 能夠實現精確的基因編輯，在醫學和農業領域具有變革潛力。最大的挑戰是道德方面的：誰控制基因組數據，如何監管胚胎中的基因編輯，以及如何確保基因組醫學惠及所有人，而不僅僅是特權階級。
