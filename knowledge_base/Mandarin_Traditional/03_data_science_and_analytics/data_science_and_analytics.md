# 數據科學與分析
數據科學是將原始數據轉化為可操作的見解的學科。它位於統計學、電腦科學和領域專業知識的交叉點，並且已經成為從金融到醫療保健的各個領域的重要組成部分。該文件介紹了每個從業者都應該了解的核心概念、工具和工作流程。
---

## 資料科學過程
大多數專案都遵循行業標準生命週期 **CRISP-DM** 的一些變體：
|相|發生了什麼 |典型時間 |
|--------|-------------|--------------|
| **業務理解** |定義目標、成功指標與限制條件 | 10–15% |
| **資料理解** |收集、探索和分析資料 | 10–15% |
| **資料準備** |清理、改造、設計功能 | 〜50–60% |
| **建模** |選擇與訓練模型 | 10–15% |
| **評估** |根據業務目標評估績效 | 5–10% |
| **部署** |將模型交付生產 | 5–10% |
根據廣泛估計，資料準備（尤其是資料清理）消耗了資料科學家約 80% 的時間。

## 統計基礎知識
### 描述性統計與推論性統計
描述性統計總結了您*擁有*的東西；推論統計可以讓你對你「沒有」的東西（更廣泛的人群）得出結論。
|概念 |關鍵想法|
|--------|------------|
| **集中趨勢** |平均數（對異常值敏感）、中位數（穩健）、眾數（最常見）|
| **分散** |極差、變異數、標準差、四分位數間距 |
| **分佈形狀** |偏度（不對稱）、峰度（尾重）|
| **假設檢定** |虛假設與備擇假設、p 值、顯著水準 (α) |
| **信賴區間** |可能包含真實總體參數的範圍 |
| **I 類/II 類錯誤** |假陽性（拒絕真正的無效值）/假陰性（缺少真實效果）|
### 常見統計測試
|測試|何時使用 |
|------|-------------|
| **t 檢定** |比較兩組之間的平均值 |
| **變異數分析** |比較三個或更多組別的平均值 |
| **卡方** |測試分類變數的獨立性 |
| **曼-惠特尼大學** | t 檢定的非參數替代方案（無正態性假設）|
| **皮爾遜相關性** |兩個連續變數之間的線性關係 |
| **斯皮爾曼相關性** |單調關係（基於排名，更穩健）|
### 值得了解的機率分佈
|分銷|使用案例|
|-------------|----------|
| **正常** |自然現象、測量誤差－經典鐘形曲線|
| **二項式** |成功/失敗計數（拋硬幣、轉換率）|
| **泊松** |固定間隔內的事件計數（每小時呼叫次數、每批缺陷）|
| **指數** |事件之間的時間（等待時間、故障間隔）|
| **t-分佈** |小樣本或未知總體變異數 |
| **卡方** |分類資料分析、適合度檢定 |

## 資料收集和存儲
### 數據從何而來
現實世界的資料有許多來源：關聯式資料庫、API（REST、GraphQL）、平面檔案（CSV、JSON、Parquet）、串流平台（Kafka、Kinesis）、調查和公共儲存庫（Kaggle、政府入口網站）。您收到的格式很大程度上決定了您的預處理策略。
### 資料倉儲概念
|概念 |描述 |
|---------|-------------|
| **ETL** |擷取 → 轉換 → 載入 — 傳統的管道方法 |
| **英語語言測試** |提取 → 載入 → 轉換 — 現代雲端方法（載入原始數據，在倉庫內轉換）|
| **資料湖** |以本機格式儲存的原始資料（讀取時模式）|
| **資料倉儲** |為分析而最佳化的結構化、經過處理的資料（寫入時模式）|
| **資料集市** |倉庫的子集，範圍為一個部門或域 |
| **星型架構** |中央事實表被維度表包圍 |
| **雪花模式** |標準化維度表（較少的冗餘，更多的連結）|
### 資料庫類型
|類型 |範例 |最適合 |
|------|----------|----------|
| **關係式 (SQL)** | PostgreSQL、MySQL、Oracle |結構化資料、ACID 事務 |
| **檔案** | MongoDB、CouchDB |靈活的架構、類似 JSON 的資料 |
| **鍵值** | Redis、DynamoDB |快取、會話、簡單查找 |
| **列族** |卡桑德拉、HBase |寫入繁重的工作負載、時間序列 |
| **圖表** | Neo4j、亞馬遜海王星 |人際關係、社群網路 |
| **時間序列** | InfluxDB、TimescaleDB |物聯網指標、監控 |
| **向量** |松果，Milvus |用於 ML/AI 搜尋的嵌入儲存 |

## 資料預處理與特徵工程
### 清潔清單
每個真實的資料集都有問題。這是標準清理：
|問題 |方法|
|--------|----------|
| **缺失值** |插補（平均數、中位數、預測），或稀疏情況下的刪除 |
| **異常值** |透過 IQR 或 Z 分數檢測；封蓋或轉換處理|
| **重複** |識別並刪除 |
| **不一致** |標準化格式、修復拼字錯誤、標準化單位 |
### 轉換技術
|技術|它有什麼作用 |
|------------|-------------|
| **標準化** |將數值縮放到 0–1 範圍 |
| **標準化** | Z 分數：平均值 = 0，標準差 = 1 |
| **One-hot 編碼** |將類別轉換為二進位列 |
| **標籤編碼** |將整數標籤指派給類別 |
| **日誌轉換** |減少資料右偏 |
| **分檔** |將連續值分組到離散桶中 |
### 特徵工程
特徵工程通常是平庸模型和優秀模型之間的區別。關鍵技術包括：
- **功能建立**：從現有列派生新列（例如，從`age`派生`age_group`）。
- **特徵選擇**：過濾方法（相關）、包裝方法（遞歸消除）、嵌入方法（LASSO、樹重要性）。
- **降維**：用於線性的 PCA、用於視覺化的 t-SNE 或 UMAP。
- **交互項**：乘法組合特徵以捕捉聯合效果。

## 探索性資料分析 (EDA)
EDA 是您在建模之前培養對數據的直覺的地方。目標是發現模式、異常和關係。
### 選擇正確的圖表
|圖表類型 |最適合 |
|------------|----------|
| **直方圖** |單一變數的分佈 |
| **箱線圖** |五數匯總、異常值檢測 |
| **散佈圖** |兩個連續變數之間的關係 |
| **熱圖** |相關矩陣、密度視覺化 |
| **長條圖** |比較類別 |
| **折線圖** |隨時間變化的趨勢|
| **小提琴情節** |分佈密度+箱線圖總結|
| **配對圖** |所有變數對的快速概覽 |
### Python EDA 堆疊
|圖書館 |角色 |
|---------|------|
| **熊貓** |資料處理與分析|
| **numpy** |數值計算|
| **matplotlib** |基礎繪圖|
| **海生** |統計視覺化（基於 matplotlib 建置）|
| **情節** |基於網路的互動式視覺化 |
| **scipy** |科學計算與統計|

## 資料科學中的機器學習
### 監督學習概覽
|任務|演算法 |
|------|------------|
| **迴歸**（預測一個數字）|線性、嶺/LASSO、決策樹、隨機森林、梯度提升（XGBoost、LightGBM）|
| **分類**（預測一個類別） |邏輯迴歸、k-NN、樸素貝葉斯、SVM、決策樹、隨機森林、神經網路 |
### 無監督學習概覽
|任務|演算法 |
|------|------------|
| **聚類** | k 均值、分層、DBSCAN、高斯混合模型 |
| **降維** | PCA、t-SNE、UMAP、自動編碼器 |
| **協會規則** | Apriori，FP-成長 |
### 模型評估
|公制類型 |關鍵指標|
|-------------|-------------|
| **分類** |準確率、精確率、召回率、F1 分數、ROC-AUC、混淆矩陣 |
| **回歸** | MAE、MSE、RMSE、R²、調整後的 R² |
| **驗證** | k 折交叉驗證、分層、時間序列分割 |
| **調整** |網格搜尋、隨機搜尋、貝葉斯最佳化 |

### 儀表板設計原則
有效的儀表板遵循既定原則：識別受眾、為每個指標選擇適當的視覺化、策略性地使用顏色（而不是裝飾性的）、保持一致的比例以及啟用互動性（過濾器、向下鑽取）。效能也很重要－載入時間慢的儀表板會降低使用者採用率。

## 資料倫理與治理
### 隱私權規定
|監理|範圍 |
|----------|------|
| **GDPR** |歐盟資料主體；刪除權、同意權、資料可攜性|
| **CCPA** |加州消費者；選擇退出資料銷售 |
| **健康保險流通與責任法案** |美國醫療保健資料；嚴格的保密規定|
### 資料品質維度
|尺寸|問題 |
|------------|----------|
| **準確度** |數據正確嗎？ |
| **完整性** |有遺漏嗎？ |
| **一致性** |消息來源同意嗎？ |
| **時效性** |是目前的嗎？ |
| **有效期限** |它符合預期的格式嗎？ |
| **獨特性** |有重複的嗎？ |
### 偏見與公平
偏差可以在任何階段出現：抽樣偏差（非代表性數據）、測量偏差（有缺陷的儀器）或演算法偏差（歧視性預測）。緩解策略包括預處理（修復資料）、處理中（約束模型）和後處理（調整輸出）。人口平等和機會均等等公平指標有助於量化問題。

## 新興趨勢
- **AutoML**：自動化管道建立和模型選擇。
- **MLOps**：應用於 ML 生命週期管理的 DevOps 實務。
- **功能儲存**：集中功能管理，以便跨團隊重複使用。
- **資料網格**：分散的、網域擁有的資料架構。
- **法學碩士和生成式人工智慧**：轉換文字、程式碼和圖像工作流程的大型語言模型。
- **邊緣分析**：在裝置上而不是在雲端處理資料。
- **因果推理**：超越相關性來理解實際的因果關係。
- **聯邦學習**：在不移動分散資料的情況下訓練模型。
- **負責任的人工智慧**：道德、可解釋性和透明度成為標準要求。
