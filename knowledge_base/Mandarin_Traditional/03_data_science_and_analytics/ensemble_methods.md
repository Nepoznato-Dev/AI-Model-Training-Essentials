# 整合方法
整合方法結合了多個機器學習模型，可以產生比任何單一模型單獨實現的更好的預測。直覺很簡單：如果您有多個模型，每個模型都有些準確，但會產生不同的錯誤，那麼將它們的預測結合起來將消除單一錯誤並產生更穩健的結果。整合是最具競爭力的機器學習解決方案的背後，並且仍然是生產系統中最可靠的技術之一。
---

## 為什麼整合有效
|原理|說明 |
|------------|-------------|
| **群众的智慧** |多个不完美的估计的平均值比任何单个估计都要好 |
| **偏差-方差权衡** |集成可以在不牺牲其他 | 的情况下减少方差（bagging）或偏差（boosting）
| **错误多样性** |如果模型犯了不同的错误，将它们组合起来可以消除个别错误 |
| **决策边界平滑** |多个模型可创建比单个模型更稳健的决策面 |
---

## 裝袋（引導聚合）
### 它是如何運作的
|步驟|描述 |
|------|-------------|
| **1.引導抽樣** |從訓練資料中抽取多個隨機樣本（帶替換）|
| **2.火車基礎模型** |在每個引導樣本（通常是決策樹）上訓練一個模型 |
| **3.合計** |對於迴歸：平均預測。分類：多數票|
### 主要特徵
|特點|描述 |
|----------------|-------------|
| **減少變異數** |平均值可以消除各模型的波動 |
| **並行訓練** |每個基礎模型都是獨立的；可以同時訓練|
| **袋外評估** |每個樣本都被排除在一些引導樣本之外；使用它們進行驗證 |
| **去相關** |每次分割時的隨機特徵選擇會降低樹之間的相關性 |
### 隨機森林
|方面|描述 |
|--------|-------------|
| **基礎學習者** |決策樹|
| **關鍵補充** |在每次分割時，僅考慮特徵的隨機子集（通常為 sqrt(n_features)） |
| **為什麼它有效** |隨機特徵選擇使樹去相關，使整體更加穩健 |
| **超參數** |樹木數；最大深度；每片葉子的最小樣本數；最大功能 |
| **優勢** |處理高維度資料；對異常值具有穩健性；提供特徵重要性|
| **弱點** |比單棵樹更難解釋；可能會過度擬合吵雜的迴歸任務
---

## 提升
### 它是如何運作的
|步驟|描述 |
|------|-------------|
| **1.训练第一个模型** |在数据上训练基本模型（通常是浅树/“树桩”）|
| **2.识别错误** |找出模型出错的实例 |
| **3.训练下一个模型** |训练一个专注于错误的新模型（重新加权或残差拟合）|
| **4.按顺序组合** |每个新模型都会纠正所有先前模型的累积误差 |
| **5.重复** |继续指定的回合数 |
### 增強演算法
|演算法|損失函數|主要特點|
|------------|--------------|-------------|
| **AdaBoost** |指數|重新加權錯誤分類的實例；簡單的;對雜訊敏感|
| **梯度提升** |任何可微分損失 |擬合殘差（損失梯度）；更有彈性 |
| **XGBoost** |正規化梯度提升 | L1/L2 正規化；二階梯度；硬體最佳化|
| **LightGBM** |基於梯度的一側採樣 |葉向生長；基於直方圖；快速處理大型資料集 |
| **貓咪助推** |訂購升壓|本地處理分類特徵；減少過度擬合 |
### Boosting 與 Bagging
|尺寸|裝袋|提升|
|------------|---------|----------|
| **培訓** |平行|順序 |
| **焦點** |減少變異數 |減少偏見 |
| **基本型號** |高方差、低偏差（深樹）|低方差、高偏差（淺樹/樹樁）|
| **組合** |同等重量|依績效加權 |
| **過度擬合** |不易發生 |如果輪數太多，可能會過擬合 |
| **噪音敏感度** |堅固耐用|對雜訊資料敏感 |

## 堆疊
### 它是如何運作的
|步驟|描述 |
|------|-------------|
| **1.火車基礎模型** |訓練不同的模型（例如隨機森林、SVM、神經網路、梯度提升）|
| **2.產生預測** |使用折疊預測（交叉驗證）作為輸入特徵 |
| **3.訓練元模型** |根據基本模型的預測訓練二級模型 |
| **4.最終預測** |基礎模型預測；元模型結合了他們的預測|
### 堆疊最佳實踐
|實踐|原因 |
|----------|--------|
| **使用不同的基礎模型** |不同的演算法會產生不同的錯誤；多樣性是重點|
| **使用交叉驗證進行基本預測** |防止元模型學習利用過度擬合的基本模型 |
| **保持元模型簡單** |邏輯迴歸或淺樹；基本模型承擔繁重的工作|
| **在元模型中包含原始特徵** |有時也有助於讓元模型存取原始功能 |

## 實用指導
### 何時使用哪個 Ensemble
|場景 |推薦方法 |
|----------|--------------------|
| **快速基線；表格資料** |隨機森林|
| **最大準確度；表格資料** | XGBoost / LightGBM / CatBoost | XGBoost / LightGBM / CatBoost |
| **噪音資料** |裝袋（提升會過度擬合雜訊）|
| **需要可解釋性** |具有特徵重要性的單一模型或小型整體 |
| **多樣的型號類型** |堆疊或投票 |
| **線上學習** |串流集成方法；自適應增強|
| **資料不平衡** |平衡隨機森林；成本敏感的提升|
### 整體多樣性策略
|戰略|描述 |
|----------|-------------|
| **不同的演算法** |結合基於樹、線性和神經模型 |
| **不同的功能** |在不同的特徵子集上訓練模型 |
| **不同的資料子集** |裝袋；二次抽樣|
| **不同的超參數** |相同的演算法不同的配置 |
| **不同時間段** |在不同的時間窗口進行訓練 |
---

＃＃ 概括
整合方法之所以有效，是因為它們將多個不完美的模型組合成一個強大的預測器。套袋（隨機森林）透過在引導樣本上並行訓練模型並求平均值來減少變異數。 Boosting（XGBoost、LightGBM、CatBoost）透過順序訓練模型來減少偏差，每個模型都會修正先前的錯誤。 Stacking 使用元模型來組合不同的基本模型。投票和平均是最簡單的組合。共同點是多樣性：當組件模型各自合理但會犯不同的錯誤時，整合效果最好。在實踐中，表格資料的梯度提升通常是表現最高的單一方法，而堆疊不同的模型可以進一步提高競賽和高風險應用中的準確性。
