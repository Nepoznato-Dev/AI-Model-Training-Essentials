# 資料視覺化
精心設計的圖表可以揭示數字表隱藏的模式。設計不良的產品可能會產生誤導、混亂或令人厭煩。數據視覺化是將數據轉化為為決策提供資訊的視覺故事的技術。該文件涵蓋圖表選擇、設計原則、常見錯誤以及使這一切成為可能的工具。
---

## 選擇正確的圖表
任何視覺化中最重要的決定是為您的資料和訊息選擇正確的圖表類型。
### 圖表選擇指南
|您的目標 |最佳圖表類型 |
|------------|------------------|
| **比較類別** |長條圖、分組長條圖|
| **顯示隨時間的變化** |折線圖、面積圖 |
| **顯示分佈** |直方圖、箱型圖、小提琴圖 |
| **顯示關係式** |散佈圖、氣泡圖|
| **顯示構圖** |堆疊長條圖、圓餅圖（有限切片）、樹狀圖 |
| **顯示相關性** |散佈圖、熱圖、配對圖 |
| **顯示排名** |水平條形圖|
| **顯示地理模式** |等值線圖、點圖 |
| **隨著時間的推移顯示部分到整體** |堆積面積圖|
### 何時使用每個圖表
|圖表|優勢 |避免何時 |
|--------|---------|------------|
| **酒吧** |太多跨類別的清晰比較 |類別 (>15) |
| **線路** |隨時間變化的趨勢；連續資料|資料不是連續的 |
| **分散** |兩個變數之間的關係 |重疊點太多 |
| **直方圖** |一個變數的分佈形狀 |小樣本量 (<20) |
| **Box plot** | Summary statistics + outliers; compare distributions | Audience unfamiliar with them |
| **Heatmap** | Correlation matrices; patterns in 2D data | Too many variables |
| **Pie chart** | Simple composition (2–5 slices) | More than 5 slices; precise comparisons needed |
| **Violin plot** | Distribution density + quartiles | Small audiences unfamiliar with them |
| **Pair plot** | Quick overview of all variable relationships | Many variables (>8) |

## 設計原則
### Tufte 的核心理念
Edward Tufte 的原則仍然是資料視覺化的黃金標準：
|原理|說明 |
|------------|-------------|
| **最大化數據墨水比率** |每一滴墨水都應該傳達數據。刪除所有其他內容。 |
| **消除圖表垃圾** |沒有 3D 效果、無用的漸層或裝飾元素。 |
| **顯示數據** |不要扭曲、隱藏或挑選。讓數據說話。 |
| **小倍數** |使用重複的小圖表進行跨類別比較。 |
| **迷你圖** |用於內聯趨勢資料的小型字大小圖表。 |
### 實用設計規則
|規則|為什麼 |
|------|-----|
| **y 軸從零開始**（對於條形圖）|否則你就會誇大差異|
| **直接標記** |盡可能將標籤放在線條/條上，而不是使用圖例 |
| **有目的地使用顏色** |突出顯示重要的內容；使用灰色作為上下文 |
| **保持簡單** |每個圖表一則訊息；請勿超載|
| **使用一致的尺度** |比較圖表時，保持軸相同 |
| **有意義的訂購** |按值（不是按字母順序）對條形圖進行排序，除非存在自然順序 |
| **提供背景** |新增基準、目標或歷史平均值 |
### 顏色指南
|使用案例|方法|
|----------|----------|
| **分類** |不同的色調（藍色、橘色、綠色、紅色）－最多 7-8 個類別 |
| **順序** |從淺到深的一種色調（淺藍色→深藍色）|
| **分歧** |具有有意義的中點的資料的二色調梯度（紅色←白色→藍色）|
| **輔助功能** |使用色盲模擬器進行測試；不要只依賴顏色（添加標籤或圖案） |

## 用數據說故事
沒有敘述的圖表只是一張圖片。講故事將數據轉化為洞察力。
### 說故事的框架
1. **背景**：情況如何？觀眾已經知道什麼？
2. **衝突**：數據中的問題、意外或緊張是什麼？
3. **解決方案**：觀眾應該根據這項見解做什麼？
### 實用技巧
|提示 |描述 |
|-----|-------------|
| **以洞察力引領** |以要點而不是數據來命名圖表（“收入增長了 30%”而不是“按季度收入”）|
| **標註要點** |為重要事件或轉折點添加文字標註 |
| **使用漸進式揭露** |一次顯示一張圖表；一步步建立故事|
| **突出重要的事情** |使用顏色或大小來引起對關鍵數據點的注意 |
| **提供「那又怎樣？」** |每個圖表都應該回答一個問題或提示一個行動 |

## 常見錯誤
|錯誤|為什麼它不好 |修復 |
|---------|-------------|-----|
| **截斷的 y 軸** |誇大微小差異|長條圖從零開始 |
| **採摘時間範圍** |關於趨勢的誤導|顯示完整的可用範圍 |
| **顏色太多** |震撼觀眾|限制為 5-7 個；使用灰色作為上下文 |
| **雙 y 軸** |暗示可能不存在的相關性 |使用兩個單獨的圖表 |
| **3D 圖表** |扭曲比例 |永遠使用 2D |
| **具有 10 多個切片的餅圖** |無法比較|使用條形圖代替 |
| **缺少標籤** |檢視者無法理解圖表 |總是標記軸、標題和單位 |
| **誤導性面積圖** |堆疊區域扭曲了單一系列的感知 |使用折線圖或小倍數 |

## 儀表板設計
儀表板是可視化的集合，它們共同講述了有關流程、系統或業務的完整故事。
### 儀表板類型
|類型 |觀眾|目的|
|------|----------|---------|
| **策略** |行政人員 |高階 KPI；長期趨勢|
| **營運** |經理 |即時監控；日常營運|
| **分析** |分析師 |深度探索；過濾、深入分析 |
### 設計清單
- **了解您的受眾**：他們會從此儀表板做出什麼決定？
- **5秒法則**：5秒內能否掌握主要內容？
- **佈局**：最重要的指標位於左上角（眼睛首先看到的位置）。
- **限制圖表類型**：每個儀表板最多 3-4 種類型以保持一致性。
- **預設情況下互動式**：過濾器、日期範圍選擇器、向下鑽取。
- **效能**：載入時間超過 5 秒的儀表板不會被使用。
- **移動**：如果使用者在旅途中需要它，請考慮響應式設計。

＃＃ 概括
良好的數據視覺化涉及清晰度、誠實性和影響力。為您的數據選擇正確的圖表。刪除所有與該訊息無關的內容。使用顏色和註釋來引導觀看者。始終、始終讓數據說故事，而不是相反。
