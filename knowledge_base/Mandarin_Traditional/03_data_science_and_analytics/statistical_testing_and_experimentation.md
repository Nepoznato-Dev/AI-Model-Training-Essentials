# 統計測試和實驗
統計學是科學的語法。它為您提供了區分真實模式和隨機雜訊的工具，衡量變更是否真正改善了情況，並在不確定的情況下做出決策。該文件涵蓋了假設檢定、實驗設計的核心概念，以及令人困惑的常見陷阱。
---

## 假設檢定框架
每個統計檢定都遵循相同的邏輯：
1. **陳述原假設 (H₀)**：沒有影響/沒有差異。
2. **陳述備擇假設 (H₁)**：存在效果/差異。
3. **選擇顯著水準 (α)**：通常為 0.05（5% 的假陽性幾率）。
4. **收集資料並計算檢定統計量**。
5. **計算 p 值**：如果 H₀ 為真，則觀察到此結果（或更極端）的機率。
6. **做出決定**：如果 p < α，則拒絕 H₀（具有統計顯著性）。否則，無法拒絕 H₀。
### 關鍵概念
|概念 |意義|常見的誤解 |
|--------|---------|---------------------|
| **p 值** | P(數據\| H₀為真) |不是「H₀ 為真的機率」|
| **α（顯著水準）** |拒絕 H₀ | 的閾值不是效果重要性的衡量標準|
| **統計意義** |僅憑偶然性，結果不太可能|並不意味著具有實際意義 |
| **效果大小** |觀察到的影響的大小|與 p 值分開；當 N 較大時，微小的影響可能會顯著 |
| **電源** |正確拒絕錯誤 H₀ 的機率 |通常目標是 80% 以上 |
| **信賴區間** |參數的合理值範圍 | 95% CI 並不表示「真實值有 95% 的機率在此範圍內」|
---

## 錯誤類型
| | H₀ 為真 | H₀ 為假 |
|---|-----------|------------|
| **拒絕 H₀** | I 類錯誤（誤報）| ✅ 正確（真陽性）|
| **無法拒絕H₀** | ✅ 正確（真陰性）| II 類錯誤（假陰性）|
|錯誤 |符號|意義|
|--------|--------|---------|
| **I 型** | α |當沒有效果時就得出有效果的結論|
| **II 型** | β |缺少真實效果|
---

## 選擇正確的測試
|場景 |測試|假設|
|----------|------|-------------|
|比較 2 組的平均值 | **t 檢定**（獨立）|常態分佈，等方差 |
|比較配對觀察的平均值 | **配對 t 檢定** |差異呈常態分佈|
|比較 3 個以上組別的平均值 | **變異數分析** |常態分佈，等變異數 |
|比較分類分佈 | **卡方檢定** |每個細胞有足夠的樣本量 |
|比較分佈（非參數）| **曼-惠特尼大學** |無正態性假設 |
|比較 3 個以上組（非參數）| **克魯斯卡爾-沃利斯** |無正態性假設 |
|測試相關性 | **Pearson**（線性）或 **Spearman**（單調）|皮爾森：正常；斯皮爾曼：基於等級 |
|測試資料是否服從分佈 | **柯爾莫哥洛夫-斯米爾諾夫** |連續資料|
### 參數化與非參數化
| |參數|非參數|
|---|-----------|---------------|
| **假設** |資料遵循特定分佈（通常是常態分佈） |無分佈假設 |
| **電源** |滿足假設時更高 |更低，但更堅固 |
| **何時使用** |大樣本，近似常態資料|小樣本、傾斜資料、有序資料 |

## 詳細具體測試
### t 檢定
比較兩組的平均值。
|變體 |使用案例|
|---------|----------|
| **獨立 t 檢定** |兩個獨立的組別（治療組與對照組）|
| **配對 t 檢定** |同一組測量兩次（之前與之後）|
| **單樣本 t 檢定** |將樣本平均數與已知值進行比較 |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA（變異數分析）
比較 3 個或更多組的平均值。測試至少一組平均值是否與其他組別不同。
|類型 |設計|
|------|--------|
| **單因子變異數分析** |具有 3 個以上等級的一個自變數 |
| **雙向變異數分析** |兩個自變數；測試交互效果|
| **重複測量變異數分析** |相同的受試者在不同條件下測量|
如果變異數分析顯著，請進行**事後檢定**（Tukey 的 HSD）以找出哪些特定組別有差異。
### 卡方檢驗
測試兩個分類變數是否獨立。
|使用案例|範例|
|----------|---------|
| **獨立性測試** |性別與產品偏好有關嗎？ |
| **貼合度** |骰子是否遵循均勻分佈？ |
**經驗法則**：每個單元格的預期計數應至少為 5。
---

## A/B 測試
A/B 測試是假設檢定在業務決策中的應用—通常將對照 (A) 與變異 (B) 進行比較。
### 設計流程
|步驟|描述 |
|------|-------------|
| **1.定義假設** | “將按鈕顏色從藍色改為綠色將提高點擊率”|
| **2.選擇指標** |主要：點擊率。第二：轉換率、收入。 |
| **3.計算樣本量** |基於最小可偵測效果、效能 (80%) 和顯著性 (5%) |
| **4.隨機化** |隨機分配使用者進行控制與治療 |
| **5.運行實驗** |收集數據直至達到目標樣本量 |
| **6。分析** |使用適當的統計檢定來比較指標 |
| **7.決定** |如果具有統計意義和實際意義，則實施 |
### 樣本量計算
您需要的樣本量取決於：
|因素|對樣本量的影響|
|--------|----------------------|
| **檢測到的影響較小** |需要更多樣品 |
| **更高功率** |需要更多樣品 |
| **較低的顯著水準** |需要更多樣品 |
| **更高的變異數** |需要更多樣品 |
### 常見的 A/B 測試錯誤
|錯誤|為什麼這是錯的 |
|--------|----------------|
| **早點看** |每日檢查結果會增加誤報率 |
| **多個指標無需修正** |在 α=0.05 處測試 20 個指標 → 預計會偶然出現 1 個誤報 |
| **在目標 N 之前停止** |動力不足的測試無法檢測出真實效果 |
| **忽略季節性** |在假期期間與正常週進行測試 |
| **非隨機分配** |選擇偏差（例如，為新使用者分配治療）|
| **混淆意義與重要性** | 0.1% 的提升可能具有統計意義，但不值得運送 |
---

## 多重比較
當您同時執行多項測驗時，至少出現一項誤報的可能性會急劇增加。
|測試次數|假陽性率≥1（α=0.05）|
|----------------|----------------------------------------------------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 10 40% |
| 20 | 20 64% |
### 更正
|方法|它是如何運作的 |何時使用 |
|--------|-------------|-------------|
| **邦費羅尼** |將 α 除以測試次數 (α/n) |保守的;一些比較|
| **霍爾姆-邦費羅尼** |降血壓程序；不那麼保守|一般用途 |
| **傑明尼-霍赫伯格 (FDR)** |控制錯誤發現率|許多測試；探索性分析 |
---

## 效果大小
P 值告訴您*是否*有效果。效應大小告訴您它有“多大”。
|測量|對於|解讀|
|--------|-----|----------------|
| **科恩的d** |兩種方法之間的差異| 0.2 = 小，0.5 = 中，0.8 = 大 |
| **皮爾遜的r** |相關性| 0.1 = 小，0.3 = 中，0.5 = 大 |
| **η²（eta 平方）** |變異數分析 | 0.01 = 小，0.06 = 中，0.14 = 大 |
| **優勢比** |分類結果 | 1.0 = 無影響； >1 或 <1 = 效果 |
**始終與 p 值一起報告效應大小。 ** 結果可能具有統計顯著性，但實際上毫無意義。

## 貝葉斯主義與頻率主義
|方面|常客 |貝葉斯 |
|--------|------------|----------|
| **機率** |事件的長期頻率|信念程度|
| **參數** |已修復但未知 |具有分佈的隨機變數 |
| **用途** | p 值、信賴區間、假設檢定 |後驗分佈，可信區間 |
| **之前** |沒有納入先前的信念|明確先驗分佈 |
| **解讀** | 「如果我們重複這個實驗多次...」| 「根據數據，機率...」|
| **優勢** |客觀、完善、簡單 |直覺的解釋，融合了先驗知識 |
| **弱點** | p 值被廣泛誤解 |先驗的選擇可能是主觀的 |

## 因果推理基礎知識
相關性不是因果關係。但有時您需要知道 *X 是否導致 Y*，而不僅僅是它們是否相關。
|方法|說明 |何時使用 |
|--------|-------------|-------------|
| **隨機實驗** |黃金標準；隨機分配消除了混雜因素當你可以隨機化|
| **雙重差分 (DiD)** |比較治療組和對照組之間隨時間的變化|政策變化，自然實驗|
| **斷點回歸 (RDD)** |利用截止閾值 |獎學金、資格門檻|
| **工具變數 (IV)** |使用影響治療但不直接影響結果的儀器 |當隨機化不可能時 |
| **傾向分數配對** |根據觀察到的特徵配對處理單元和對照單元 |觀察性研究|
---

## 常見統計錯誤
|錯誤|描述 |
|---------|-------------|
| **p-駭客** |嘗試多次分析，直到發現 p < 0.05 |
| **聆聽** |已知結果後進行假設 |
| **倖存者偏差** |只專注於成功（例如，成功的公司）|
| **辛普森悖論** |當資料聚合與按組拆分時，趨勢會逆轉 |
| **基本利率忽略** |解釋結果時忽略先驗機率 |
| **生態謬誤** |從群體層次的資料推論個體行為 |
| **混淆** |第三個變數解釋了觀察到的關係|
| **過度擬合** |模型捕捉噪聲，而不是信號 |
---

＃＃ 概括
統計測試是在不確定的情況下以理智的誠實做出決策。在收集數據之前始終陳述您的假設。為您的資料類型選擇正確的測試。報告效應大小，而不僅僅是 p 值。多重比較正確。請記住：統計顯著性與實際顯著性不同。
