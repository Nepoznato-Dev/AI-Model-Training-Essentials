# 特徵工程
特徵工程是將原始資料轉換為使機器學習模型更有效的表示的過程。它通常被描述為 ML 管道中最重要的步驟 - 您為模型提供的功能比您選擇的演算法更重要。具有精心設計的特徵的簡單模型通常會優於具有原始、未經處理的輸入的複雜模型。藝術在於充分理解領域和數據，以創建模型可以學習的訊號。
---

## 為什麼特徵工程很重要
|因素|影響 |
|--------|--------|
| **訊號品質** |更好的特徵 = 更清晰的模型學習模式 |
| **模型簡單** |好的特性可以讓更簡單的模型表現良好；減少對複雜架構的需求
| **訓練速度** |相關的、規模化的特徵收斂得更快 |
| **概括** |領域知情功能可協助模型處理看不見的資料 |
| **可解釋性** |有意義的功能更容易向利害關係人解釋|
---

## 特徵轉換的類型
### 數值變換
|轉型|公式/說明|何時使用 |
|----------------|--------------------------------|-------------|
| **對數轉換** | log(x) 或 log(x + 1) |右偏分佈；貨幣價值|
| **平方根** |開方(x) |適度傾斜；計數資料|
| **博克斯-考克斯** |尋找最佳功率變換的參數變換 |使資料更加常態分佈 |
| **楊約翰遜** |與 Box-Cox 類似，但處理負值 |帶有負值的傾斜數據 |
| **標準化** | (x - 平均值) / 標準差 |具有不同尺度的特徵；假設常態性的演算法 |
| **最小-最大縮放** | (x - 最小值) / (最大值 - 最小值) |將特徵限制為 [0, 1]；影像像素值|
| **穩健的縮放** | (x - 中位數) / IQR |含有異常值的資料 |
| **分檔** |將連續轉換為分類 |非線性關係；決策樹 |
| **多項式特徵** | x2, x3, x₁×x2 |捕捉線性模型中的非線性關係 |
### 分類編碼
|編碼 |說明 |何時使用 |
|----------|-------------|-------------|
| **One-hot 編碼** |為每個類別建立一個二進位列 |低基數類別；基於樹的模型本地處理
| **標籤編碼** |為每個類別分配整數 |序數類別；基於樹的模型|
| **目標編碼** |將類別替換為目標變數的平均值 |高基數類別；透過平滑避免過度擬合 |
| **頻率編碼** |將類別替換為其計數或頻率 |當頻率本身就具有資訊性時 |
| **二進位編碼** |將整數編碼類別轉換為二進位數字 |高基數；降低維度與 one-hot |
| **嵌入** |學習密集向量表示 |基數非常高；自然語言處理；推薦系統|
| **哈希編碼** |將類別哈希為固定數量的特徵 |基數非常高；在線學習 |
### 日期和時間功能
|特色 |描述 |
|---------|-------------|
| **一天中的某个时间** |捕捉日常模式（高峰时段、夜间）|
| **星期幾** |工作日 vs 週末效果 |
| **月/季** |季節性圖案 |
| **是週末** |週末的二進位標誌 |
| **是假期** |公共假期的二进制标志 |
| **事件发生后的时间** |自上次购买以来的天数；自上次登录以来的小时数 |
| **循环编码** | sin(2π × 小时 / 24), cos(2π × 小时 / 24) — 保留时间的循环性质 |

## 處理缺失值
|戰略|說明 |何時使用 |
|----------|-------------|-------------|
| **刪除行** |刪除缺失值的行 |缺失資料只是一小部分； MCAR（完全隨機缺失）|
| **刪除列** |刪除缺失值過多的特徵 |大部分功能缺失；不重要|
| **平均數/中位數插補** |填充特徵的平均數或中位數 |簡單的;保留平均數但減少變異數 |
| **模式插補** |以最常見的值填入類別 |分類特徵|
| **KNN 插補** |使用 k-近鄰估計缺失值 |當相似的實例有助於預測缺失值時 |
| **基於模型的插補** |訓練模型來預測缺失值 |更準確；計算成本高|
| **缺少指示器** |新增標記缺少的二進位列 |當缺失本身就具有豐富的資訊時 |
| **內插** |以內插法填滿（線性、樣條）|時間序列；訂購資料|

## 特徵選擇
### 過濾方法
|方法|描述 |
|--------|-------------|
| **相關性** |刪除彼此高度相關的特徵 |
| **變異數閾值** |刪除變異數接近零的特徵 |
| **相互資訊** |測量每個特徵提供的有關目標的資訊 |
| **卡方** |測試分類特徵與目標之間的獨立性 |
| **變異數分析 F 檢定** |測試不同目標類別的數字特徵平均值是否不同 |
### 包裝方法
|方法|描述 |
|--------|-------------|
| **向前選擇** |從空白開始；一次增加一個最好的功能 |
| **向後消除** |從一切開始；一次刪除一個最糟糕的功能 |
| **遞歸特徵消除（RFE）** |反覆訓練模型；刪除最不重要的功能 |
### 嵌入方法
|方法|描述 |
|--------|-------------|
| **L1 正規化（套索）** |將不相關的特徵權重縮小到零 |
| **基於樹的重要性** |使用樹模型中的特徵重要性 |
| **形狀值** |衡量每個特徵對預測的貢獻 |

## 特定領域的特徵工程
### 文字特徵
|特色 |描述 |
|---------|-------------|
| **TF-IDF** |以逆文檔頻率加權的詞頻 |
| **詞嵌入** |捕獲語意的密集向量（Word2Vec、GloVe）|
| **字元 n 元語法** |捕捉子詞模式；對於拼字錯誤和詞法有用 |
| **文字統計** |長度;字數統計；句子計數；平均字長 |
| **可讀性分數** |弗萊施-金凱德；噴槍霧指數|
### 時間序列特徵
|特色 |描述 |
|---------|-------------|
| **滯後功能** |先前值：y(t-1)、y(t-7)、y(t-30) |
| **滾動統計** |視窗上的平均值、標準差、最小值、最大值 |
| **差異** | y(t) - y(t-1)；捕捉趨勢|
| **季節差異** | y(t) - y(t-12) 用於具有年度季節性的月度資料 |
| **傅立葉項** |季節性模式的正弦和餘弦術語 |
### 影像特徵（深度學習前）
|特色 |描述 |
|---------|-------------|
| **HOG**（定向梯度直方圖）|邊緣方向分佈|
| **LBP**（本地二進位模式）|紋理描述|
| **SIFT**（尺度不變特徵變換）|關鍵點描述子 |
| **顏色直方圖** |影像中顏色的分佈|

## 特徵工程最佳實踐
|實踐|描述 |
|----------|-------------|
| **避免資料外洩** |永遠不要使用來自未來或測試集的資訊來創建特徵 |
| **記錄一切** |記錄應用了哪些轉換以及原因 |
| **版本化您的功能** |追蹤功能變更以及模型變更 |
| **使用和不使用**進行驗證 |測試新功能是否真正提高了模型性能 |
| **保持可重複性** |特徵工程管道應該是確定性的和可重複的 |
| **監控功能漂移** |特徵分佈可能會隨著時間的推移而改變；監控和再訓練|
---

＃＃ 概括
特徵工程是領域知識與機器學習的結合。這是將原始資料（雜亂、不完整、高維）轉換為模型可以學習的乾淨、資訊豐富的表示的過程。數值轉換處理傾斜和縮放。分類編碼將標籤轉換為模型可以使用的數字。日期特徵捕捉時間模式。缺失值策略處理不完整的資料。特徵選擇消除了噪音和冗餘。最好的功能工程師像偵探一樣思考：他們詢問資料中應該存在哪些訊號，這些訊號可能隱藏在哪裡，以及如何以誠實（無資料外洩）、可重複且能夠隨時間變化的方式提取它們。
