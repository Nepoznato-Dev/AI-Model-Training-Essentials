# 統計與機率
機率和統計學是數據科學、機器學習和科學研究的數學基礎。機率告訴你事件發生的可能性有多大；統計學告訴你如何從數據中得出結論。他們共同將不確定性轉化為可量化、可管理的知識。
---

## 機率論
### 核心概念
|概念 |描述 |範例|
|---------|-------------|---------|
| **樣本空間** |所有可能結果的集合|擲骰子：{1, 2, 3, 4, 5, 6} |
| **活動** |樣本空間的子集 |滾動偶數：{2, 4, 6} |
| **機率** |測量可能性的 0 到 1 之間的數字 | P(滾動 6) = 1/6 |
| **條件機率** | P(A|B)：在給定 B 的情況下 A 發生的機率 | P(雨 | 陰天) |
| **獨立** |一方不影響另一方的事件 |投擲硬幣是獨立的 |
### 機率規則
|規則|公式|使用案例|
|------|---------|----------|
| **加法规则** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | A 或 B 的概率 |
| **乘法规则** | P(A ∩ B) = P(A) × P(B|A) | P(A ∩ B) = P(A) × P(B|A) | A 和 B 的概率 |
| **补足规则** | P(非 A) = 1 − P(A) |事件不发生的概率 |
| **总概率定律** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) |按互斥事件划分 |
| **贝叶斯定理** | P(A|B) = P(B|A) × P(A) / P(B) |用证据更新信念|
### 機率分佈
|分銷|類型 |關鍵參數|使用案例|
|----------|------|----------------|----------|
| **常態（高斯）** |連續 |平均值 (μ)、標準差 (σ) |自然現象、測量誤差|
| **二項式** |離散| n（試驗），p（機率）|成功/失敗很重要|
| **泊松** |離散| λ（速率）|跨越時間/空間的罕見事件 |
| **指數** |連續 | λ（速率）|事件之間的時間 |
| **制服** |兩者 | a、b（邊界）|同等可能的結果 |
| **卡方** |連續 | k（自由度）|適合優度檢定 |
| **t-分佈** |連續 | ν（自由度）|小樣本推論 |
### 分佈的關鍵屬性
|物業 |描述 |
|----------|-------------|
| **平均值（預期值）** |分佈的質心：E[X] = Σ xᵢ × P(xᵢ) |
| **變異數** |圍繞著平均值： Var(X) = E[(X − μ)²] |
| **標準差** |變異數的平方根；與資料相同的單位 |
| **偏度** |分佈不對稱|
| **峰度** | 「尾巴」－尾巴有多重 |

## 統計推斷
### 描述性統計與推論性統計
| |描述性|推理 |
|---|-------------|-------------|
| **目的** |總結與描述資料 |從樣本中得出關於總體的結論 |
| **工具** |平均值、中位數、眾數、標準差、圖表 |假設檢定、信賴區間、迴歸 |
| **範圍** |僅您擁有的數據 |超越你的樣本進行概括 |
### 假設檢定框架
|步驟|描述 |
|------|-------------|
| 1. **陳述假設** |虛假設（H₀）：沒有影響；替代方案（H₁）：效果存在 |
| 2. **選擇顯著水準** | α = 0.05（常規）|
| 3. **選擇測試** |基於資料類型、樣本大小和假設 |
| 4. **計算檢定統計量** |取決於所選的測試 |
| 5. **找出 p 值** |如果 H₀ 為真，則觀察到資料的機率 |
| 6. **做出決定** |如果 p < α，則拒絕 H₀；否則，無法拒絕 H₀ |
### 常見統計測試
|測試|何時使用 |比較什麼 |
|------|-------------|-----------------|
| **t 檢定** |比較 1-2 組的平均值 |將平均值分組為一個值或彼此分組 |
| **卡方檢定** |分類資料|觀察到的頻率與預期的頻率 |
| **變異數分析** |比較 3 個以上組別的平均值 |組間變異數與組內變異數 |
| **曼-惠特尼大學** | t 檢定的非參數替代方案 |兩組的排名分佈|
| **皮爾遜相關性** |兩個連續變數之間的線性關係 | r 值從 −1 到 +1 |
| **斯皮爾曼相關性** |單調關係（基於等級）|序數或非常態資料的 ρ 值 |
### 信賴區間
信賴區間給出了總體參數的一系列合理值：
- **平均值的 95% CI**（已知 σ）：x̄ ± 1.96 × (σ / √n)
- **解釋**：“我們有 95% 的信心認為真實總體平均值位於該區間內”
- **較寬的 CI** = 較大的不確定性（較小的樣本、較高的變異性或較高的信賴水準）

## 迴歸分析
### 迴歸類型
|類型 |因變數|使用案例|
|------|--------------------|----------|
| **線性迴歸** |連續 |預測房價、銷售|
| **邏輯迴歸** |二進位 (0/1) |分類：垃圾郵件偵測、疾病診斷|
| **多項式迴歸** |連續（彎曲）|成長曲線，非線性趨勢|
| **多元迴歸** |連續（2+ 個預測變數）|控制混雜因素|
| **山脊/套索** |連續（正規化）|防止過擬合，特徵選擇|
### 線性迴歸基礎知識
模型：**y = β₀ + β₁x + ε**
|組件|意義|
|------------|---------|
| β₀（截距）| x = 0 時 y 的值 |
| β₁（斜率）| x 变化一单位时 y 的变化 |
| ε（誤差項）|無法解釋的變異 |
**關鍵指標：**
- **R²（決定係數）**：模型解釋的變異數比例（0 到 1）
- **調整 R²**：R² 因預測變數數量而受到懲罰
- **RMSE**：均方根誤差 — 與 y 單位相同的平均預測誤差
### 線性迴歸的假設
|假設|這意味著什麼？如何檢查 |
|------------|--------------|--------------|
| **線性** | X 與 Y 之間的關係是線性的 |散佈圖|
| **獨立** |觀察是獨立的 |研究設計|
| **同方差** |殘差常數變異數 |剩餘地塊|
| **正常** |殘差呈常態分佈 | Q-Q 圖，Shapiro-Wilk 檢定 |
| **無多重共線性** |預測因子並非高度相關 | VIF（變異數膨脹因子）|

## 貝葉斯統計
### 頻率論與貝葉斯論
| |常客 |貝葉斯 |
|---|-------------|----------|
| **機率意味著** |長期運行頻率|信念程度|
| **參數為** |已修復但未知 |具有分佈的隨機變數 |
| **用途** | p 值、信賴區間 |後驗分佈，可信賴區間 |
| **優勢** |客觀、有理|結合先驗知識、直覺解釋 |
### 貝葉斯定理的實踐
**後驗=（可能性×先驗）/證據**
範例 — 醫學檢測：
- 疾病盛行率：1%（之前）
- 測試靈敏度：95%（真陽性率）
- 測試特異性：90%（真陰性率）
- 若檢測呈陽性：P(疾病 | 陽性) = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99) ≈ 8.8%
這種違反直覺的結果——當疾病罕見時，大多數陽性結果都是假陽性——是**基本率謬誤**，它說明了為什麼貝葉斯思維很重要。

## 實用技巧
- **在運行任何統計測試之前始終可視化您的資料**
- **檢查假設** - 違規可能會使結果無效
- **效果大小很重要** - 統計上顯著的結果可能實際上毫無意義
- **相關性不是因果關係**——即使是很強的相關性也可能會產生混雜因素
- **多重比較** 誇大誤報率 - 應用修正（Bonferroni、FDR）
- **報告信賴區間**，而不僅僅是 p 值
---

## 為什麼這很重要
統計學是科學研究、商業分析和機器學習的支柱。沒有它，您就無法區分訊號和噪聲，無法識別隨機波動的真實影響，也無法做出具有量化不確定性的預測。無論您是分析 A/B 測試、訓練 ML 模型還是閱讀研究論文，統計素養都是必不可少的。
