# 動力系統
**動態系統**描述了狀態如何根據固定規則隨時間演變。從行星軌道到人口動態，從天氣模式到訓練神經網絡，動力系統理論提供了理解事物如何變化的語言和工具。此文件涵蓋常微分方程 (ODE)、偏微分方程 (PDE)、穩定性分析、混沌和分岔。
---

## 常微分方程 (ODE)
ODE 將函數與其相對於單一自變數（通常是時間）的導數連結起來。
＃＃＃ 分類
|物業 |類型 |
|----------|--------|
| **訂單** |存在的最高導數（一階、二階等）|
| **線性與非線性** |線性：y'' + p(t)y' + q(t)y = g(t)；非線性：其他任何東西|
| **同质** | g(t) = 0（无强迫项）|
| **自主** |無明確的時間依賴：dy/dt = f(y) |
| **常数系数** | p、q 是常数 |
### 一階常微分方程
**一般形式：** dy/dt = f(t, y)
|類型 |表格 |解決方法|
|------|------|-----------------|
|可分離 | dy/dt = g(t)h(y) |分離與積分： ∫dy/h(y) = ∫g(t)dt |
|線性一階 | dy/dt + p(t)y = q(t) |積分因子：μ(t) = e^(∫p dt) |
|準確| M(t,y)dt + N(t,y)dy = 0 且 ∂M/∂y = ∂N/∂t |求勢函數 F(t,y) |
|伯努利| dy/dt + p(t)y = q(t)yⁿ |代入 v = y^(1−n) 來線性化 |
**工作範例（積分因子）：** 解 dy/dt + 2y = e^(−t), y(0) = 1。
- 積分因子：μ(t) = e^(∫2 dt) = e^(2t)
- 乘法：d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- 積分：e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- 初始條件：y(0) = 1 → 1 = 1 + C → C = 0
- 解：y(t) = e^(−t)
### 二階線性常微分方程
**一般形式：** ay'' + by' + cy = g(t)
**齊次情況** (g​​ = 0)：解特徵方程式 ar² + br + c = 0。
|判別式|根|通用解決方案|
|-------------|------|------------------|
| b² > 4ac（過阻尼）|兩個不同的實數 r₁、r2 | y = C₁e^(r₁t) + C2e^(r2t) |
| b² = 4ac（臨界阻尼）|重實根 r | y = (C₁ + C2t)e^(rt) |
| b² < 4ac（欠阻尼）|複數根 α ± βi | y = e^(αt)(C₁ cos βt + C2 sin βt) |
**物理解釋：** 質量-彈簧-阻尼器系統 mx'' + bx' + kx = 0。
- 過阻尼：重阻尼，無振盪（閉門器）
- 臨界阻尼：最快返回且無振盪（汽車懸吊設計目標）
- 欠阻尼：以衰減幅度振盪（吉他弦）
### 常微分方程組
許多實際系統涉及多個交互作用的變數：
dx/dt = f(x, y)
dy/dt = g(x, y)
這可以寫成向量形式：d**x**/dt = **F**(**x**)
**線性系統：** d**x**/dt = A**x**，其中 A 是矩陣。
解取決於 A 的特徵值：
|特徵值 |行為 |
|------------|------------|
|既有實數，也有負數|穩定節點（所有軌跡收斂到原點）|
|既真實又積極|不穩定的節點 |
|實數相反的符號 |鞍點（不穩定）|
|複數負實部 |穩定螺旋（阻尼振盪）|
|複數正實部 |不穩定的螺旋 |
|純屬虛構|中心（閉合軌道）|

## 相圖
**相圖**可視化狀態空間中動力系統的軌跡（無需明確求解）。
### 主要特點
|特色 |描述 |
|---------|-------------|
| **定點（平衡）** |其中 dx/dt = 0（無運動）|
| **軌跡** |系統在狀態空間中追蹤的路徑|
| **零斜線** |一個分量的導數為零的曲線 |
| **極限循環** |孤立閉合軌道（自持振盪）|
| **吸引力盆地** |導致給定吸引子的一組初始條件 |
| **分離體** |不同吸引力盆地之間的邊界|
### 捕食者-獵物模型 (Lotka-Volterra)
dx/dt = αx − βxy（獵物）
dy/dt = δxy − γy（掠食者）
**固定点：**
1. (0, 0) — 滅絕（鞍點）
2. (γ/δ, α/β) — 共存（中心 — 閉合軌道）
該系統表現出週期性振盪：獵物增加→捕食者增加→獵物減少→捕食者減少→循環重複。

## 穩定性分析
### 線性穩定性
對於固定點 x*，對其進行線性化：令 u = x − x*，則 du/dt ≈ J(x*)u，其中 J 是雅可比矩陣。
**穩定準則：** 不動點為：
- **穩定** 如果 J 的所有特徵值都有負實部
- **不穩定**如果任何特徵值具有正實部
- **邊際穩定** 如果特徵值的實部為零（需要非線性分析）
### 李亞普諾夫穩定性
**李亞普諾夫直接法**無需線性化即可確定穩定性。
**Lyapunov 函數** V(x) 滿足：
1. V(x*) = 0 且 V(x) > 0，因为 x ≠ x*（正定）
2. 沿軌跡 dV/dt ≤ 0（非增加）
|狀況 |結論 |
|------------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 |不穩定|
**工作範例：**系統 dx/dt = −x + y²，dy/dt = −y。
- 試試 V(x,y) = x² + y²（類別能量函數）
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- 近原點：dV/dt ≈ −2x² − 2y² < 0（對於小 y，−2y² 占主導地位）
- 結論：原點局部漸近穩定

## 混沌理論
**混沌**是確定性但不可預測的：系統遵循精確的規則，但初始條件的微小差異會導致截然不同的結果。
### 混沌的要求
|物業 |描述 |
|----------|-------------|
|確定性|沒有隨機性－由精確方程式控制|
|對初始條件敏感 |附近的軌跡呈指數級分歧|
|有界|軌跡不會逃逸到無窮大|
|非週期|從不完全重複 |
### 洛倫茲系統
確定性混沌的經典例子：
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy – βz
標準參數 σ = 10、ρ = 28、β = 8/3：
- 系統有三個固定點，皆不穩定
- 軌跡繞著一個固定點運行，然後突然切換到另一個固定點
- 結果是 **洛倫茲吸引子** — 具有分形結構的奇怪吸引子
**李雅普諾夫指數：** 測量附近軌跡的發散率。
- 正李雅普諾夫指數 → 混沌
- 對於具有標準參數的洛倫茲系統：最大指數 ≈ 0.9 > 0
### 物流地圖
一個表現出混沌的簡單離散系統：
x_{n+1} = rx_n(1 − x_n)
|參數 r |行為 |
|------------|------------|
| 0 < r < 1 |人口滅絕 (x → 0) |
| 1 < r < 3 | 1 < r < 3 | x = 1 − 1/r | 處的穩定不動點
| 3 < r < 3.449 | 3 < r < 3.449週期 2 振盪 |
| 3.449 < r < 3.544 | 3.449 < r < 3.544週期 4 振盪 |
| 3.544 < r < 3.570 |週期 8、16、32、...（倍週期級聯）|
| r ≈ 3.570 |混亂的開始|
| 3.570 < r < 4 |大多是混亂的，有週期性視窗 |
| r = 4 | [0, 1] | 上完全混沌
### 蝴蝶效應
對初始條件的敏感依賴性的流行名稱。在天氣系統（由洛倫茲方程式建模）中，巴西的一隻蝴蝶扇動翅膀可能會在德克薩斯州引發龍捲風——不是因為蝴蝶引起的，而是因為微小的擾動呈指數級增長。

## 分岔理論
**分叉**是系統行為隨著參數變化而發生的質變。
### 分叉的類型
|分叉|範式|發生了什麼 |
|----------|-------------|--------------|
| **鞍節點** | dx/dt = r − x² |兩個固定點出現/消失 |
| **跨臨界** | dx/dt = rx − x² |兩定點互換穩定性|
| **乾草叉（超臨界）** | dx/dt = rx − x³ |一個穩定點分裂為兩個穩定點+一個不穩定點 |
| **乾草叉（亞臨界）** | dx/dt = rx + x³|不穩定的樹枝倒塌（通常是災難性的）|
| **霍普夫** | 2D系統|不動點變得不穩定，出現極限環 |
### 分叉圖
固定點與參數值的關係圖，顯示穩定性（實線 = 穩定，虛線 = 不穩定）。邏輯圖的分叉圖揭示了通往混沌的倍週期路線和著名的 **費根鮑姆常數** δ ≈ 4.669（連續分叉區間之間的通用比率）。

## 偏微分方程 (PDE)
偏微分方程涉及多個變數及其偏導數的函數。
### 二階線性偏微分方程的分類
對於 Au_xx + 2Bu_xy + Cu_yy + ... = 0：
|類型 |狀況 |行為 |範例|
|------|---------|------------|---------|
| **橢圓形** | B² - AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 |波傳播，保留銳利特徵 |波動方程式： u_tt = c²u_xx |
### 熱方程
∂u/∂t = α ∂²u/∂x²
模擬熱擴散、人口分佈、選擇權定價（Black-Scholes）。
|物業 |聲明|
|----------|------------|
|平滑|即使初始資料不連續，解決方案也會立即變得平滑 |
|最大化原則|最高溫度出現在邊界或初始時間 |
|時間可逆 |不可逆－無法倒退|
### 波動方程
∂²u/∂t² = c² ∂²u/∂x²
模擬振動弦、聲音、電磁波。
|物業 |聲明|
|----------|------------|
|傳播|幹擾以 c 的速率傳播 |
|可逆性|時間可逆|
|達朗貝爾溶液| u(x,t) = f(x−ct) + g(x+ct) (左/右波的疊加)|
### 拉普拉斯方程
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
解（調和函數）代表穩態溫度、靜電勢、不可壓縮流體流動。
|物業 |聲明|
|----------|------------|
|平均值屬性 | u(x₀) = u 在以 x₀ 為中心的任何圓上的平均值 |
|最大化原則|沒有內部最大值或最小值|
|獨特性|完全由邊界條件決定 |
