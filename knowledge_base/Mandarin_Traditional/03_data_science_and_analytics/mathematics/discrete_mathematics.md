# 離散數學
離散數學是對從根本上可數或分離的數學結構的研究，而不是連續數學（微積分、實分析），後者處理平滑、不間斷的數量。離散數學是電腦科學、密碼學、演算法設計和資料結構的基礎。如果連續數學描述了物理世界，那麼離散數學則描述了計算世界。

## 深入闡述理論
集合幾乎是所有現代數學的基礎。 **集合**是不同物件的無序集合，稱為**元素**或**成員**。
### 公理基礎 (ZFC)
現代集合論依賴 **Zermelo-Fraenkel 公理和選擇公理 (ZFC)**。這些公理透過限制集合的形成方式來解決諸如羅素悖論（「所有不包含自身的集合的集合」）之類的悖論。
|公理|非正式聲明|
|--------|--------------------|
|外延性|兩個集合相等當且僅當它們具有相同的元素 |
|空集合|存在一個沒有元素的集合： ∅ |
|配對 |對任意a，b，存在{a，b} |
|聯盟|對任何集合族，它們的並集都存在 |
|電源組|對於任何集合S，S的所有子集的集合都存在：P(S) |
|無限|存在無限集合 |
|規格|對任一集合 A 且屬性 P，存在 {x ∈ A : P(x)} |
|更換|可定義函數下的集合的形像是集合 |
|規律性|每個非空集合都包含一個與其不相交的元素（防止自成員資格）|
|選擇|對於任何非空成對不相交集族，都存在選擇函數 |
### 集合的基數和大小
集合的**基數**，表示為 |S|，衡量其「大小」。
|概念 |定義 |範例|
|--------|------------|---------|
|有限集 |有自然數為基數 | |{a,b,c}| = 3 |
|可數無窮 |與 ℕ | 相同的基數ℤ, ℚ 可數為無窮 |
|不可數|大於 ℕ | ℝ, P(ℕ)，所有函數的集合 ℕ → {0,1} |
|康托爾定理 |對任一集合 S，|P(S)| > |S| | |P(ℕ)| > |ℕ| |
**康托爾的對角論證**證明 ℝ 是不可數的：假設您可以列出 [0,1] 中的所有實數，然後構造一個與小數點後第 n 個列出的實數不同的新實數 — 矛盾。
### 集合的運算
|營運|符號|定義 |物業 |
|------------|----------|------------|----------|
|聯盟| A ∪ B | {x : x Î A 或 x Î B} |交換律、結合律 |
|交叉口| A ∩ B | {x : x ∈ A 且 x ∈ B} |交換律、結合律 |
|差|甲\乙| {x : x ∈ A 且 x ∉ B} |不可交換 |
|對稱差| △B| (A \ B) ∪ (B \ A) | (A \ B) ∪ (B \ A) |交換律、結合律 |
|補充 | Aᶜ | U\A（其中U是通用集）| (Aᶜ)ᶜ = A |
|笛卡爾積|甲 × 乙 | {(a,b) : a Î A, b Î B} | |A×B| =|A| ·|B| |
**德摩根定律：**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**包含-排除原則**（對於有限集）：
|A₁ ∪ A2 ∪ ... ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺ |

## 關係
集合 A 和 B 上的 **關係** R 是 A × B 的子集。當 (a, b) ∈ R 時，我們寫成 aRb。
### 關係類型
集合 A 上的關係 R 可以有下列屬性：
|物業 |定義 |範例|
|----------|------------|---------|
|反身性| ∀a ∈ A: aRa | ≤ ℤ |
|不自反 | ∀a ∈ A: Ø(aRa) | < 上 ℤ |
|對稱| ∀a,b: aRb → bRa | = 在任意集合上 |
|反對稱| ∀a,b: aRb ∧ bRa → a = b | ≤ ℤ |
|及物| ∀a,b,c: aRb ∧ bRc → aRc | <、≤、= ℤ |
### 等價關係
**等價關係**是自反的、對稱的、傳遞的。它將集合劃分為不相交的**等價類**。
**範例：** 模算術。定義 a ~ b 當且僅當 a == b (mod n)。等價類為 [0], [1], ..., [n−1]，將 ℤ 分為 n 個類。
**工作範例：** 在 ℤ × ℤ 上，定義 (a,b) ~ (c,d) 當且僅當 a + d = b + c。這是一個等價關係。類別 [(0,0)] = {(n,n) : n ∈ ℤ}。類別 [(1,0)] = {(n+1,n) : n ∈ ℤ}。這種結構實際上定義了自然數中的整數。
### 部分訂單
**偏序**是自反的、反對稱的、傳遞的。具有偏序的集合稱為**偏序集合（poset）**。
|概念 |定義 |範例|
|--------|------------|---------|
|姿勢| (S, ≤) 且 ≤ 偏序 | (P(A), ⊆) — 依包含排序的子集 |
|鏈|全序子集 | P({a,b,c}) 中的 {∅, {a}, {a,b}} |
|反鏈|沒有兩個元素可比較的子集 | P({a,b}) 中的 {{a}, {b}} |
|哈斯圖|偏序集的視覺表示 |僅繪製邊緣以覆蓋關係 |
|上限 |一個元素 ≥ 子集中的每個元素 | super({2,3}) = 6 in (ℤ, \|) （整除性） |
|最小上界（sup）|最小上限 | (ℕ, ≤) 中的sup({2,3}) 是3 |
|最大下界 (inf) |最大下界 | (ℕ, \|) 中的 inf({4,6}) 為 2 |

## 函數
A **函數** f: A → B 為 A 的每個元素恰好分配 B 的一個元素。
### 函數的分類
|類型 |定義 |範例|
|------|------------|---------|
|單射（一對一）| f(a) = f(b) → a = b | f(x) = 2x 由 ℤ → ℤ |
|滿射（到）| ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x mod 2 由 ℤ → {0,1} |
|雙射|單射與滿射| f(x) = x + 1 由 ℤ → ℤ |
### 重要的函數概念
|概念 |定義 |使用案例|
|---------|------------|----------|
|反函數 | f⁻¹ 存在當且僅當 f 是雙射 |解密加密資料 |
|成分| (g ∘ f)(x) = g(f(x)) | (g ∘ f)(x) = g(f(x)) |連結轉換 |
|恆等函數| id(x) = x |成分為中性元素|
|定點| f(x) = x | f(x) = x |遞歸定義、語意 |
|排列|從集合到自身的雙射 |重新排列資料、改組 |
### 計數函數
給定有限集合 |A| = m 和 |B| = n：
|類型 |計數|
|------|--------|
|所有功能 A → B |不 | |
|內射函數 |嗯！ / (n−m)! (若 n ≥ m，則為 0)|
|滿射函數 | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ（經由包含-排除）|
|雙射函數|嗯！ (當 m = n 時) |

## 組合學
組合學是計算、排列和選擇的數學。
### 基本計數原則
|原理|宣告|範例|
|------------|------------|---------|
|總和規則 |如果 A 和 B 不相交，|A ∪ B| =|A| + |B| |選擇果實：3個蘋果+4個橘子=7種選擇|
|產品規則| |A×B| =|A| ·|B| |服裝： 3 件襯衫 × 4 條褲子 = 12 套服裝 |
|雙射規則 |如果 f: A → B 是雙射，|A| =|B| |透過計算二進位字串來計算子集 |
|補充 | |一個| =|U| - |Aᶜ| |將「至少一個」計為總數減去「無」 |
### 排列與組合
|符號|名稱 |公式|意義|
|----------|------|---------|---------|
| C(n, k) 或 (n k) |二項式係數 |嗯！ / (k!(n−k)!) |從 n 項中選擇 k 項的方法（順序無關緊要） |
| P(n, k) | P(n, k) | n | k 的排列嗯！ / (n−k)! |從 n 個項目中排列 k 個項目的方法（順序很重要）|
|嗯！ |階乘 | n × (n−1) × ... × 1 |排列所有 n 項的方法 |
| (n k) 重複 |多選 | C(n+k−1, k) | C(n+k−1, k) | C(n+k−1, k) |從n選擇k並允許重複|
**二項式定理：**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**帕斯卡恆等式：** C(n,k) = C(n−1,k−1) + C(n−1,k)
### 鴿籠原理
**基本形式：** 如果將n+1個物體放入n個盒子中，則至少有一個盒子包含≥2個物體。
**一般形式：** 若將N個物體放入k個盒子中，則至少有一個盒子包含≥ ⌈N/k⌉ 個物體。
**工作範例：**
1. 任意 13 人中，至少有 2 人同一出生月份。 （13 人，12 個月 → 歸入檔案。）
2. 證明任 5 個整數中，存在 3 個其和能被 3 整除。
   - 考慮餘數 mod 3: {0, 1, 2}。對於 5 個整數和 3 個殘基類別，透過廣義鴿巢，至少 ⌈5/3⌉ = 2 共用一個殘基。
   - 如果 3 共享一個殘基 r：它們的和 == 3r == 0 (mod 3)。
   - 如果 2 個共享殘基 0 且 2 個共享殘基 1：從每對中選擇一個加上一個殘基 0 元素 → sum == 0 (mod 3)。
3. **在CS中的應用：**任何無損壓縮演算法都必須擴展一些輸入。 （如果每個 n 位元字串都壓縮為 < n 位，則將 2ⁿ 字串對應到少於 2ⁿ 壓縮字串 - 違反了單射性。）
### 加泰隆尼亞數字
第 n 個 **加泰隆尼亞數** Cₙ = C(2n, n) / (n+1) 計數：
|結構|範例|
|------------|---------|
|有效的括號序列 | ()(), (()) 對於 n = 2 |
|具有 n 個內部節點的二元樹 | n = 2 時有 2 棵樹 |
|不穿過對角線的路徑 |從 (0,0) 到 (n,n) 的網格路徑保持低於 y = x |
|多邊形的三角剖分|將 (n+2) 邊形分成三角形的方法 |
前幾個：C₀ = 1、C₁ = 1、C2 = 2、C₃ = 5、C₄ = 14、C₅ = 42。
遞歸式： Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## 遞迴關係
**遞歸關係**將序列的每一項定義為前一項的函數。
### 類型和解決方案
|類型 |表格 |解決方法|
|------|------|-----------------|
|線性齊次（常數係數）| aₙ = c₁aₙ₋₁ + c2aₙ₋2 + ... + cₖaₙ₋ₖ |特徵方程式|
|線性非齊次 | aₙ = c₁aₙ₋₁ + ... + f(n) |特定溶液+均質溶液 |
|分而治之 | T(n) = aT(n/b) + f(n) | T(n) = aT(n/b) + f(n) |主定理|
### 特徵方程法
對於aₙ=c₁aₙ₋₁+c2aₙ₋，形成特徵方程式：
r2−c₁r−c2=0
|案例 |根|通用解決方案|
|------|------|------------------|
|兩個不同的實根 r₁, r2 | r₁ ≠ r2 | aₙ = A·r₁ⁿ + B·r2ⁿ |
|重複根 r | r₁ = r2 = r | aₙ = (A + Bn)·rⁿ |
|複數根 α ± βi |轉換為極座標： r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**工作範例：** 斐波那契數列 Fₙ = Fₙ₋₁ + Fₙ₋2，F₀ = 0，F₁ = 1。
- 特徵方程式：r² − r − 1 = 0
- 根：r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618, ψ = (1−√5)/2 ≈ −0.618
- 通解：Fₙ = A·φⁿ + B·ψⁿ
- 依初始條件：A = 1/√5，B = −1/√5
- **閉合形式：** Fₙ = (φⁿ − ψⁿ) / √5 （比奈公式）
### 主定理
對於 T(n) = aT(n/b) + f(n) 形式的遞歸，其中 a ≥ 1，b > 1：
令 c = log_b(a)。
|案例 |狀況 |解決方案 |
|------|------------|----------|
| 1 | f(n) = O(nᵈ) 其中 d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c，且 af(n/b) ≤ kf(n) 對某些 k < 1 | T(n) = θ(nᵈ) | T(n) = θ(nᵈ) |
**範例：**
- 歸併排序：T(n) = 2T(n/2) + O(n)。這裡a=2，b=2，c=1，f(n)=n=θ(n1)。情況 2：T(n) = θ(n log n)。
- 二分查找：T(n) = T(n/2) + O(1)。這裡a=1，b=2，c=0，f(n)=1=θ(n⁰)。情況 2：T(n) = θ(log n)。

## 產生函數
**產生函數**將序列 (aₙ) 編碼為形式冪級數的係數。
### 類型
|類型 |表格 |使用案例|
|------|------|----------|
|普通 (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ |未標記的結構、組合物 |
|指數 (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n！ |标记结构、排列 |
### 常用生成函數
|序列 aₙ | OGF G（x）|
|------------|------------|
| 1, 1, 1, 1, ... | 1/(1−x) | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² | 1/(1−x)² |
| 1、r、r2、r3、... | 1/(1−rx) | 1/(1−rx) |
| C(n,k) 對於固定 k | xᵏ/(1−x)ᵏ⁺¹ |
|斐波那契 Fₙ | x/(1−x−x²) | x/(1−x−x²) |
|加泰隆尼亞語 Cₙ | (1 − √(1−4x)) / (2x) | (1 − √(1−4x)) / (2x) |
### 使用生成函數解決遞歸問題
**工作範例：** 解 aₙ = 3aₙ₋₁ − 2aₙ₋2，a₀ = 1，a₁ = 3。
1. 設 G(x) = Σ aₙxⁿ。
2. 根據遞推式： G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. 代入： G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. 部分分數：G(x) = 2/(1−2x) − 1/(1−x)
7. 提取係數：aₙ = 2·2ⁿ − 1 = 2ⁿ⁺1 − 1
**驗證：** a₀ = 2−1 = 1，a₁ = 4−1 = 3，a2 = 8−1 = 7。檢查：3(3) − 2(1) = 7。

## 布林代數與命題邏輯
布林代數是兩個真值的代數：**True (1)** 和 **False (0)**。它是數位電路、資料庫查詢和程式條件的數學基礎。
### 營運和法律
|運作|符號|意義|真值表|
|------------|--------|---------|-------------|
|且| p ∧ q |僅當兩者皆為真時才為真 | T∧T=T，T∧F=F，F∧T=F，F∧F=F |
|或 | p ∨ q |當至少有一個為真時為真 | T∨T=T，T∨F=T，F∨T=T，F∨F=F |
|不 | Øp |否定| ØT=F，ØF=T |
|異或| p ⊕ q |當剛好有一個為真時為真 | T⊕T=F，T⊕F=T，F⊕T=T，F⊕F=F |
|意味著 | p → q |僅當 p=T 且 q=F 時為 False | T→T=T，T→F=F，F→T=T，F→F=T |
|雙條件| p ↔ q |當兩者相同值時為真 | T↔T=T，T↔F=F，F↔T=F，F↔F=T |
### 關鍵布林恆等式
|法律|公式|
|-----|--------|
|交換律 | p ∧ q = q ∧ p； p ∨ q = q ∨ p |
|關聯性| (p ∧ q) ∧ r = p ∧ (q ∧ r) |
|分配率| p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
|德摩根定律 | Ø(p ∧ q) = Øp ∨ Øq; Ø(p ∨ q) = Øp ∧ Øq |
|雙重否定| Ø(Øp) = p |
|冪等性 | p ∧ p = p； p ∨ p = p |
|吸收| p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
|反證| (p → q) ≡ (Øq → Øp) |
### 範式
|表格 |結構|使用案例|
|------|------------|----------|
|連結範式 (CNF) | OR 的與： (A∨B) ∧ (C∨D) | SAT 求解器，解析定理證明 |
|析取範式 (DNF) | AND 的或： (A∧B) ∨ (C∧D) |電路設計，基於規則的系統|
**轉換為 CNF：** 應用德摩根定律，將 OR 分配給 AND，消除雙重否定。

## 模算術和同餘
模算術研究「除法餘數」運算下的整數。它對於密碼學、雜湊和數論至關重要。
### 核心定義
|概念 |符號|定義 |
|---------|----------|------------|
|一致性| a == b (mod n) | a == b (mod n) | n 除 (a − b) |
|殘留類別| [一]ₙ |集合 {a + kn : k ∈ ℤ} |
|模逆| a⁻¹ mod n |值 x 使得 ax == 1 (mod n) |
|歐拉方程式 | φ(n) |與 n 互質的 {1,...,n} 中的整數計數 |
### 關鍵屬性
|物業 |聲明|
|----------|----------|
|加法 |若 a == b 且 c == d (mod n)，則 a+c == b+d (mod n) |
|乘法|若 a == b 且 c == d (mod n)，則 ac == bd (mod n) |
|費馬小定理 |若 p 是質數且 gcd(a,p) = 1，則 aᵖ⁻¹ ≡ 1 (mod p) |
|歐拉定理|若 gcd(a,n) = 1，則 a^φ(n) == 1 (mod n) |
|中國剩餘定理|若 gcd(m,n) = 1，則係統 x == a (mod m), x == b (mod n) 有唯一解 mod mn |
### 計算歐拉 Totient
對於 n = p₁^a₁·p2^a2·...·pₖ^aₖ（質因數分解）：
φ(n) = n·(1−1/p₁)·(1−1/p2)·...·(1−1/pₖ)
**範例：** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4。事實上，{1, 5, 7, 11} 與 12 互質。
### 應用：RSA 加密（概述）
1. 選擇大質數p、q。計算 n = pq，φ(n) = (p−1)(q−1)。
2. 選擇 e 使得 gcd(e, φ(n)) = 1（公共指數）。
3. 計算 d eq e⁻1 (mod φ(n))（私有指數）。
4. 加密：c = mᵉ mod n。解密：m = cᵈ mod n。
5. 安全性依賴因式分解 n 來求 p 和 q 的難度。

## 數學歸納法
**數學歸納法**是所有自然數陳述的主要證明技術。
### 歸納證明的結構
1. **基本情況：** 證明 n = 0（或 n = 1）的陳述。
2. **歸納步驟：** 假設該命題對於 n = k（歸納假設）成立，然後證明 n = k + 1。
### 變體
|變體 |何時使用 |
|---------|-------------|
|簡單歸納|證明 P(k) → P(k+1) |
|強感應|假設 P(0), P(1), ..., P(k) 證明 P(k+1) |
|結構歸納|證明遞歸定義的結構（樹、公式）的性質 |
|超限歸納 |將歸納法擴展到 ℕ | 以外的良序集合
**工作範例（強歸納法）：** 證明每個整數 n ≥ 2 都可以寫成質數的乘積。
- 基數：n = 2 是質數，因此它是質數（本身）的乘積。
- 歸納步驟：假設從 2 到 k 的所有整數都是 true。考慮k+1。
  - 如果 k+1 是質數，完成。
  - 如果 k+1 是合數，則 k+1 = ab，其中 2 ≤ a，b ≤ k。根據歸納假設，a 和 b 都是質數的乘積，因此 k+1 是質數的乘積。
