#真實分析
實分析是微積分的嚴格基礎。雖然入門微積分教您如何計算導數和積分，但真正的分析會問「為什麼」這些技術有效 - 以及它們何時失敗。它提供了極限、連續性、收斂性和積分的精確定義，這些定義支撐著機率論、泛函分析、最佳化以及機器學習演算法背後的理論保證。

## 序列和系列
### 序列
**序列** 是實數 (aₙ)ₙ₌₁^∞ 的有序列表。核心問題是：序列是否**收斂**到極限？
**收斂的定義：** 如果對每個 ε > 0，存在 N，使得對所有 n > N： |aₙ − L|，則序列 (aₙ) 收斂到 L < ε。
|概念 |定義 |範例|
|--------|------------|---------|
| **收斂** | lim aₙ = L 存在且有限 | aₙ = 1/n → 0 |
| **發散** |不收斂| aₙ = (−1)ⁿ 振盪 |
| **發散至無窮大** | aₙ 無限成長 | aₙ = n² → ∞ |
| **有界** | \|aₙ\| ≤ M 對某些 M |每個收斂序列都是有界的 |
| **單調** |要麼永遠不減，要麼永遠不增加| aₙ = 1 − 1/n 增加 |
| **柯西序列** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε |在 ℝ 中，柯西 ⟺ 收斂 |
**關鍵定理：**
- **单调收敛定理：** 每个有界单调序列收敛
- **Bolzano-Weierstrass 定理：** 每个有界序列都有一个收敛子序列
- **ℝ 的完备性：** ℝ 中的每个柯西序列都收敛（这将 ℝ 与 ℚ 区分开来）
＃＃＃ 系列
**級數**是數列的和：Σₙ₌₁^∞ aₙ。若部份與數列 Sₙ = Σₖ₌₁ⁿ aₖ 收斂，則級數收斂。
### 收斂測試
|測試|狀況 |結論 |
|------|------------|------------|
| **分歧測試** | lim aₙ ≠ 0 |系列發散|
| **對比測試** | 0 ≤ aₙ ≤ bₙ 且 Σbₙ 收斂 | Σaₙ 收斂 |
| **比率測試** | lim \|aₙ₊₁/aₙ\| = L |如果 L< 1, diverges if L >1 | 則收斂
| **根測試** | limsup \|aₙ\|^(1/n) = L |若 L< 1, diverges if L >1 | 收斂
| **整體測試** | aₙ = f(n)，f 遞減，正 | Σaₙ 收斂當且僅當 ∫f(x)dx 收斂 |
| **交替系列** | aₙ 遞減，lim aₙ = 0，交替符號 |級數收斂 |
| **絕對收斂** | Σ\|aₙ\|收斂| Σaₙ 收斂（並且重新排列給出相同的總和）|
| **條件收斂** | Σaₙ 收斂，但 Σ\|aₙ\|發散|重排可以給出任意和 (黎曼) |
### 重要係列
|系列|總和|狀況 |
|--------|-----|------------|
|幾何：Σ rⁿ | 1/(1−r) | 1/(1−r) | \|r\|< 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
|諧波：Σ 1/n |發散 (= ∞) | — |
|指數：Σ xⁿ/n！ | eˣ |所有 x |
| ln(1+x) 的泰勒： Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | ln(1+x) | −1 < x ≤ 1 |

## 限制和連續性
### 函數的限制
**定義：** lim_{x→c} f(x) = L 表示：對每個 ε > 0，存在 δ > 0 使得 0 < |x − c| < δ 意味著 |f(x) − L| < ε。
這就是 **ε-δ 定義** — “f(x) 逼近 L 當 x 逼近 c”的嚴格版本。
### 連續性
如果 lim_{x→c} f(x) = f(c)，則函數 f **在 c** 連續。等價地：對每個 ε > 0，都存在 δ > 0 使得 |x − c| < δ 意味著 |f(x) − f(c)| < ε。
**不連續性的類型：**
|類型 |描述 |範例|
|------|-------------|---------|
|可拆|存在極限但 ≠ f(c) | f(x) = sin(x)/x 在 x = 0 |
|跳轉|左、右極限存在但不同 |階躍函數|
|無限|極限為±∞| f(x) = 1/x² 在 x = 0 |
|振盪|限制不存在 | f(x) = sin(1/x) 在 x = 0 |
### 連續函數的關鍵定理
|定理|宣告|
|--------|------------|
| **中間值定理** |若 f 在 [a,b] 上連續且 f(a) < k < f(b)，則 ∃c ∈ (a,b)： f(c) = k |
| **極值定理** |如果 f 在 [a,b] 上連續，則 f 在 [a,b] | 上達到最大值和最小值
| **有界定理** |若 f 在 [a,b] 上連續，則 f 在 [a,b] | 上有界
| **均勻連續性** |如果 f 在 [a,b] 上連續 (Heine-Cantor) | f 在 [a,b] 上一致連續
**工作範例 (IVT)：** 顯示 x3 + x − 1 = 0 在 (0, 1) 中有一個解。
- 設 f(x) = x3 + x − 1。 f 是連續的（多項式）。
- f(0) = −1< 0 and f(1) = 1 >0。
- 經 IVT，∃c ∈ (0,1)：f(c) = 0。

## 差異化
＃＃＃ 定義
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
如果存在此極限，則 f 在 c 處**可微**。
### 可微性與連續性
|關係 |聲明|
|--------------|------------|
|可微→連續|若 f 在 c 處可微，則 f 在 c | 處連續
|連續 ↛ 可微 | f(x) = \|x\|在 0 處連續但不可微 |
|無處可微 | Weierstrass 函數：處處連續，處處可微 |
### 主要結果
|定理|宣告|
|--------|------------|
| **中值定理** |若 f 在 [a,b] 上連續且在 (a,b) 上可微，則 ∃c： f'(c) = (f(b)−f(a))/(b−a) |
| **羅爾定理** |當 f(a) = f(b) 時 MVT 的特殊情況： ∃c: f'(c) = 0 |
| **洛必達法則** |若 lim f/g = 0/0 或 ∞/∞，則 lim f/g = lim f'/g'（當後者存在時）|
| **泰勒定理** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k！ · (x−a)ᵏ + Rₙ(x) 具有明確餘數 |

＃＃ 一體化
### 黎曼積分
**黎曼積分** 將 ∫ₐᵇ f(x)dx 定義為黎曼和的極限。
**施工：**
1. 將 [a,b] 分成子區間：P = {x₀, x₁, ..., xₙ}
2. 選擇樣本點 tᵢ ∈ [xᵢ₋₁, xᵢ]
3.黎曼和：S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. 若網格 → 0 時 S(P,f) 的極限存在，則 f 是黎曼可積的
**黎曼可積性標準：**
|狀況 |可積？ |
|------------|-------------|
|連續 [a,b] |是的 |
|以有限多個不連續點為界 |是的 |
| [a,b] 上單調 |是的 |
|狄利克雷函數（ℚ 為 1，無理數為 0）|沒有 |
### 微積分基本定理
|部分|聲明|
|------|------------|
| **第 1 部分** |若 f 在 [a,b] 上連續，則 F(x) = ∫ₐˣ f(t)dt 可微且 F'(x) = f(x) |
| **第 2 部分** |若 F' = f 且 f 是黎曼可積，則 ∫ₐᵇ f(x)dx = F(b) − F(a) |
### 勒貝格積分
黎曼積分有其限制——它無法整合分析和機率中出現的許多函數。 **勒貝格積分**將積分擴展到更廣泛的函數類別。
**關鍵思想：** 不是劃分域（x 軸），而是劃分範圍（y 軸）。
|方面|黎曼積分|勒貝格積分|
|--------------------|-----------------|--------------------|
|方法|分區域（x 軸）|分區範圍（y 軸）|
|整合|連續、分段連續 |可測量的功能|
|極限定理|弱|強（主導收斂、單調收斂）|
|手把| 「好」的功能 |具有密集不連續性的函數 |
|成立|經典微積分 |現代機率論|
**勒貝格準則：** f 在 [a,b] 上是黎曼可積的，當且僅當 f 幾乎處處有界且連續（不連續性集合的測度為零）。

## 度量空間
**度量空間**將「距離」的概念概括為抽象集合。
＃＃＃ 定義
**度量空間** (X, d) 是一個具有距離函數 d 的集合 X： X × X → ℝ 滿足：
|公理|聲明|
|------|----------|
|非負性| d(x,y) ≥ 0 |
|身份 | d(x,y) = 0 當且僅當 x = y |
|對稱性| d(x,y) = d(y,x) |
|三角不等式| d(x,z) ≤ d(x,y) + d(y,z) |
### 常見度量空間
|空間|設定|公制|應用程式 |
|--------|-----|--------|-------------|
| ℝⁿ 与欧几里得 | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² |标准几何形状 |
| ℝⁿ 与曼哈顿 | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| |基于网格的路径，LASSO |
| ℝⁿ 与切比雪夫 | ℝⁿ | d(x,y) = max\|xᵢ−yᵢ\| |棋王距离|
|离散度量 |任意套装 |如果 x≠y，则 d(x,y) = 1；如果 x=y，则 0 |拓扑示例 |
|函数空间 C[a,b] |连续函数 | d(f,g) = max\|f(x)−g(x)\| |近似论|
| Lᵖ 空间 | p-可积函数 | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) |函数分析、ML 规范 |
### 度量空間中的拓樸概念
|概念 |定義 |範例|
|--------|------------|---------|
| **開球** | B(x,r) = {y : d(x,y) < r} | ℝ | 中的開區間 (x−r, x+r)
| **開放組** |每個點都有一個球包含在集合中 | (0,1) 開於 ℝ |
| **閉集** |開集的補 | [0,1] 閉於 ℝ |
| **關閉** |包含 S 的最小閉集 | (0,1) = [0,1] | 的閉包
| **緊湊** |每個打開的蓋子都有一個有限的子蓋子|在 ℝⁿ 中：閉有界 (Heine-Borel) |
| **完成** |每個柯西序列都收斂 | ℝ 已完成； ℚ 不是 |

## 均勻收斂
函數序列 (fₙ) 可以透過兩種方式收斂：
|類型 |定義 |保持連續性？ |
|------|------------|----------------------|
| **逐點** | ∀x: fₙ(x) → f(x) |沒有 |
| **制服** | sup\|fₙ(x) − f(x)\| → 0 |是的 |
**均勻收斂**更強：收斂速度到處都是相同的。
**關鍵定理：**
- 連續函數的一致極限是連續的
- 黎曼可積函數的一致極限是黎曼可積的，且極限的積分等於積分的極限
- **Weierstrass M 檢定：** 如果 |fₙ(x)| ≤ Mₙ 對於所有 x 且 ΣMₙ 收斂，則 Σfₙ 一致收斂

## 測量理論
**測量論**概括了長度、面積和體積的概念。
＃＃＃ 定義
集合 X 上的 **測度** 是一個函數 μ: Σ → [0, ∞] （其中 Σ 是子集的 σ 代數），滿足：
- μ(∅) = 0
- **可數可加性：** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) 對於不相交的 Aᵢ
### 勒貝格測度
ℝ 上的 **勒貝格測度** λ 擴展了長度的概念：
|設定|勒貝格測度|
|-----|-----------------|
|區間 [a,b] | b − a |
|單點 {x} | 0 |
|限量集 | 0 |
|可數集（例如，ℚ）| 0 |
|康托集| 0（不可數但測量為零）|
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### 關鍵概念
|概念 |定義 |
|---------|------------|
| **几乎无处不在（a.e.）** |除非在一组测度为零 | 上，否则属性均成立。
| **可测量功能** |每个开集的原像都是可测的 |
| **勒贝格积分** |使用测度论定义积分 |
| **Lᵖ 空间** |具有有限 p 次方积分的函数空间 |
### 重要的收斂定理
這些定理是勒貝格積分在高等數學中受到青睞的原因：
|定理|宣告|
|--------|------------|
| **單調收斂** |若 fₙ ↑ f 逐點且 fₙ ≥ 0，則 ∫fₙ → ∫f |
| **主導趨同** |若 fₙ → f 逐點且 \|fₙ\| ≤ g（可積），則 ∫fₙ → ∫f |
| **法圖引理** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
這些定理允許交換極限和積分——這對黎曼積分來說通常是失敗的。

## 與機器學習和資料科學的相關性
|分析概念|應用 |
|----------------|-------------|
|極限與收斂|了解迭代演算法（梯度下降，EM）何時收斂 |
|連續性|反向傳播的激活函數必須是連續的 |
|可微性|基於梯度的最佳化需要可微的損失函數 |
|中值定理|數值近似中的誤差界限、收斂證明 |
|度量空間|聚類中的距離函數（k 均值、DBSCAN）、最近鄰 |
|緊湊性|最優解的存在性證明，有限維優化中的 Heine-Borel |
|均勻收斂|保證近似（神經網路通用近似）在任何地方都有效 |
|測量理論|現代機率的基礎（機率是一種測量），期望值為勒貝格積分 |
|勒貝格積分|期望值 E[X] = ∫X dP 是勒貝格積分 |
| Lᵖ 空間 |正規化中的 L1 (LASSO)、L2 (Ridge)、Lᵖ 範數 |
|主導收斂|證明估計量的一致性，貝葉斯推論中的互換限制 |

真正的分析是數學成長的地方。它用可以證明和概括的精確定義取代了「接近」、「連續」和「區域」的直覺概念。對於資料科學家和機器學習工程師來說，分析提供了理論保證：梯度下降何時收斂？損失函數什麼時候表現良好？我們什麼時候可以交換限制和期望？這些不是哲學問題——它們決定了你的演算法是否有效或默默失敗。
