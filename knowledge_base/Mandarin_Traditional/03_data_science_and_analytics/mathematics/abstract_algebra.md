# 抽象代數
抽象代數研究代數結構－具有遵循特定規則的運算的集合。抽象代數不是處理數字，而是處理任何滿足公理的物件。這種普遍性是強大的：為「群」證明的定理同時適用於整數、對稱性、矩陣、排列和量子態。抽象代數是密碼學、糾錯碼、量子計算和整個物理學中使用的對稱分析的基礎。
---

## 團體
**群**是最基本的代數結構。它抓住了對稱的本質。
＃＃＃ 定義
**群** (G, *) 是一個具有二元運算 * 的集合 G，滿足：
|公理|聲明|例 (ℤ, +) |
|--------|---------|-----------------|
| **關閉** | ∀a,b ∈ G: a ∗ b ∈ G | a + b 是整數 |
| **關聯性** | (a*b)*c=a*(b*c)| (a + b) + c = a + (b + c) | (a + b) + c = a + (b + c) |
| **身份** | ∃e ∈ G: e ＊ a = a ＊ e = a | 0 + a = a + 0 = a |
| **逆** | ∀a ∈ G, ∃a⁻1: a * a⁻1 = a⁻1 * a = e | a + (−a) = 0 |
如果該運算也是**交換性** (a * b = b * a)，則該群稱為**阿貝爾**。
### 群組的範例
|集團|設定|營運|身分 |逆|阿貝爾？ |
|--------|-----|------------|----------|---------|---------|
| (ℤ, +) |整數 |加法 | 0 | -a |是的 |
| (ℚ*, ×) |非零有理數|乘法| 1 | 1/一個 |是的 |
| (ℤ/nℤ, +) |餘數 mod n |加法 n | [0]| [n−a] | [n−a] |是的 |
| Sₙ | {1,...,n} | 的排列成分|編號 |逆排列|否 (n ≥ 3) |
| GL(n, ℝ) | GL(n, ℝ) |可逆 n×n 矩陣 |矩陣乘法 |我ₙ | A⁻1 |否 (n ≥ 2) |
| (ℝⁿ, +) | n 維向量 |向量加法 | 0 | -v|是的 |
### 群組和元素的順序
|術語 |定義 |範例|
|------|------------|---------|
| **G 階** (\|G\|) | G | 中的元素數\|ℤ/5ℤ\| = 5 |
| **元素 a 的順序** (ord(a)) |最小正 k 且 aᵏ = e | (ℤ/7ℤ)* = 3 中的 ord(2)（因為 2³ = 8 ≡ 1） |
| **有限群** | \|G\|是有限的| S₃ 的階數為 6 |
| **無限群** | \|G\|是無限大| (ℤ, +) |
### 子群組
G 的**子群** H 是子集 H ⊆ G ，它本身就是同一操作下的群。
**子群測試：** H 是 G 的子群當且僅當：
1. H非空
2. 對所有 a, b ∈ H: a ∗ b⁻1 ∈ H
**範例：**
- (ℤ, +) 具有子群 nℤ = {..., −2n, −n, 0, n, 2n, ...} 對每個 n ≥ 0
- **平凡子群** {e} 和群 G 本身總是子群
- 在 S₃ 中，集合 {id, (12)} 是 2 階子群
### 陪集與拉格朗日定理
對於 G 的子群 H 且元素 a ∈ G：
- **左陪集：** aH = {ah : h ∈ H}
- **右陪集：** Ha = {ha : h ∈ H}
**拉格朗日定理：** 對於有限群 G 和子群 H：
|H|除|G|
**推論：**
- 每個元素的順序除|G|
- 如果|G| = p（質數），則 G 是循環的（沒有非平凡子群）
-a^|G| = e 對所有 a ∈ G （推廣費馬小定理）
### 迴圈群
如果存在 g ∈ G 且 G 的每個元素都是 g 的冪，則群 G 是**循環**。我們寫 G = ⟨g⟩。
|物業 |聲明|
|----------|------------|
|每个循环群都是交换群 | — |
|加法下的 ℤ/nℤ 是循环 |由 [1] | 生成
| (ℤ/pℤ)* 对于素数 p 是循环的 |生成元称为原根 |
|分类|对于某些 n | 每个有限循环群都同构于 ℤ/nℤ

## 同態和同構
**同態**是群組之間的結構保留映射。
### 定義
|術語 |定義 |範例|
|------|------------|---------|
| **同態** | φ: G → H 其中 φ(ab) = φ(a)φ(b) |偵測： GL(n,ℝ) → ℝ* |
| **同構** |雙射同態（群是「相同的」） | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **核心** | ker(φ) = {g ∈ G : φ(g) = e_H} | ker(det) = SL(n, ℝ) |
| **圖片** | im(φ) = {φ(g) : g ∈ G} | im(det) = ℝ* |
### 第一同構定理
如果 φ: G → H 是同態，則：
G / ker(φ) ≅ im(φ)
這是代數中最重要的定理之一──它說每個同態都分解成一個商，後面跟著一個同構。

## 戒指
**環**將第二個運算加到組中，對加法和乘法的算術進行建模。
＃＃＃ 定義
**環** (R, +, ×) 是集合 R，其兩個運算滿足：
|公理|聲明|
|------|----------|
| (R, +) 是阿貝爾群 |加法是可交換的、結合的、恆等式 0、每個元素都有加法逆元 |
|乘法為結合律 | (a × b) × c = a × (b × c) | (a × b) × c = a × (b × c) |
|分配律| a(b + c) = ab + ac 且 (a + b)c = ac + bc |
如果乘法也是可交換的並且具有恆等式 (1)，則 R 是**具有單位的交換環**。
### 戒指的例子
|戒指|描述 |可交換的？ |有1個嗎？ |
|------|-------------|-------------|--------|
| (ℤ, +, ×) |整數 |是的 |
| (ℚ, +, ×) |理由|是的 |
| (ℝ, +, ×) |實數 |是的 |
| (ℤ/nℤ, +, ×) |整數 mod n |是的 |
| Mₙ(ℝ) | n×n 實數矩陣 |否 (n ≥ 2) |是的 |
| ℝ[x] |具有實數係數的多項式 |是的 |是的 |
### 理想與商環
環 R 的**理想** I 是滿足以下條件的子集：
1. 是加法下的子群
2. 吸收乘法：對所有 r ε R 和 a ε I，ra ε I 和 ar ε I
**商環** R/I：元素是 I 的陪集，操作繼承自 R。
**範例：** ℤ/nℤ = ℤ/nℤ 是 ℤ 除以理想 nℤ 的商數。
### 積分域和字段
|結構|定義 |範例 |
|------------|------------|----------|
| **積分域** | 1 的交換環，無零因數 (ab = 0 → a = 0 或 b = 0) | ℤ, ℚ[x], ℝ[x] |
| **領域** |每個非零元素都有一個乘法逆元的交換環 | ℚ、ℝ、ℂ、ℤ/pℤ（p 質數）|

## 字段
域是常用的最結構化的代數物件。每個非零元素都可以進行加、減、乘、除運算。
### 關鍵屬性
|物業 |聲明|
|----------|------------|
|每個領域都是一個完整的領域 | — |
|每個有限積分域都是一個域 | — |
|特點| n·1 = 0 時的最小 n，若不存在這樣的 n，則為 0 |
| char(ℚ) = char(ℝ) = char(ℂ) | = 0 |
|字元（ℤ/pℤ）| = p（對於質數 p）|
### 有限域（伽羅瓦域）
對於每個質數冪 pᵏ，都存在一個唯一的（直至同構）pᵏ 階有限域，表示為 GF(pᵏ) 或 𝔽_{pᵏ}。
|領域|尺寸|建築 |應用 |
|--------|------|-------------|----------|
| GF(2) | 2 | {0, 1} 模 2 |二進位算術，異或 |
| GF(2ᵏ) | 2ᵏ |多項式對 GF(2) 上的不可約多項式取模 | AES 加密、CRC 代碼 |
| GF（p）| p| ℤ/pℤ 對質數 p |模算術、編碼理論|
| GF(pᵏ) | GF(pᵏ) | pᵏ |擴充欄位 | Reed-Solomon 碼、橢圓曲線 |
**GF(2⁸)的構造**（用於 AES）：
- 從 GF(2) = {0, 1} 開始
- 在 GF(2) 上選擇不可約多項式 p(x) = x⁸ + x⁴ + x3 + x + 1
- 元素是次數 < 8 的多項式，係數為 GF(2)
- 算術：多項式加法 (XOR) 和乘法 mod p(x)

## 向量空間
**向量空間**是一組可以相加和縮放的向量，構成線性代數的基礎。
＃＃＃ 定義
域 F 上的 **向量空間** V 是一個集合：
- 向量加法：V × V → V（使 V 成為阿貝爾群）
- 標量乘法：F × V → V
滿足：結合律、加法交換律、標量乘法分配律、1·v = v。
### 關鍵概念
|概念 |定義 |範例|
|--------|------------|---------|
| **基礎** |線性無關的生成集 | Fⁿ | {e₁, e2, ..., eₙ} |
| **尺寸** |任意基底中的向量數量 |暗淡（ℝ³）= 3 |
| **子空間** |加法與標量乘法下的封閉子集 |經過 ℝ³ | 中原點的平面
| **線性組合** | Σ cᵢvᵢ 其中 cᵢ ∈ F | 3v₁ + 2v2 - v₃ |
| **跨距** |所有線性組合的集合 | Span({v₁, v2}) = 平面，若 v₁, v2 獨立 |
| **線性獨立** |沒有一個向量是其他向量的線性組合 | ℝ3 中的 e₁、e2、e₃ |
### 重要的向量空間
|空間|描述 |尺寸|
|--------|-------------|------------|
| Fⁿ |字段 F 上的 n 元組 | n |
| Pₙ(F) |次數 ≤ n | 的多項式n + 1 |
| Mₘₓₙ(F) | F 上的 m × n 矩陣 |百萬 |
| C[a,b] | [a,b] | 上的連續函數無限|
| L²(ℝ) |平方可積函數 |無限（希爾伯特空間）|

## 線性映射與特徵理論
### 線性映射
一個**線性映射**（線性變換）T：V→W滿足：
- T(u + v) = T(u) + T(v)
- 對於所有標量 c，T(cv) = cT(v)
|概念 |定義 |範例|
|--------|------------|---------|
| **核心** | {v ∈ V : T(v) = 0} |矩陣的零空間 |
| **圖片** | {T(v) : v ∈ V} |矩陣的列空間 |
| **秩無效定理** |暗淡（ker T）+暗淡（im T）=暗淡（V）|基本約束|
| **矩陣表示** | T(v) = Av 對於某個矩陣 A |有限維空間之間的每個線性映射|
### 特徵值和特徵向量
對於線性映射 T：V → V（或矩陣 A）：
**特徵值方程式：** Av = λv，其中v ≠ 0
|術語 |定義 |
|------|------------|
| **特徵值** λ |對於某些 v ≠ 0，Av = λv 的標量 |
| **特徵向量** v |滿足 Av = λv | 的非零向量
| **特徵多項式** | det(A − λI) = 0 |
| **特徵空間** | {v : Av = λv} — λ 的所有特徵向量的集合（加上 0） |
| **光譜** |所有特徵值的集合 |
### 計算特徵值
對於 2×2 矩陣 A = [[a, b], [c, d]]：
- 特徵多項式： λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2
**關鍵屬性：**
- 特徵值之和 = 跡 (A) = 對角線元素總和
- 特徵值的乘積 = det(A)
### 對角化
矩陣 A **可對角化**當且僅當它具有 n 個線性獨立特徵向量（其中 A 為 n×n）。
如果 A = PDP⁻1，其中 D 是對角線：
- Aᵏ = PDᵏP⁻¹（快速矩陣求冪）
- D 包含對角線上的特徵值
- P 包含特徵向量作為列
**譜定理：** 每個實對稱矩陣可以透過正交矩陣對角化。它的特徵值是實數。

## 應用
### 編碼理論（糾錯碼）
有限域是現代糾錯碼的基礎。
|代碼|領域|更正|應用 |
|------|--------|----------|----------|
|漢明碼 | GF(2) |每塊 1 個錯誤 | RAM ECC、早期網路|
|里德-所羅門 | GF(2ᵏ) |多個錯誤 | CD、DVD、QR 碼、衛星通訊 |
| BCH 碼 | GF(2ᵏ) |多個錯誤 |衛星快閃記憶體|
| LDPC碼| GF(2) |多個錯誤 | Wi-Fi (802.11n)、DVB-S2、5G |
**Reed-Solomon 編碼：** 將資料視為 GF(2ᵏ) 上的多項式，在多個點進行評估。即使某些評估被破壞，也可以恢復原始多項式。
### 量子計算
量子態存在於複向量空間（希爾伯特空間）。量子閘是酉矩陣。
|量子概念|代數結構|
|----------------|--------------------|
|量子位元 | ℂ² 中的單位向量（複數二維向量空間）|
|量子閘|酉矩陣 U ∈ U(2ⁿ) |
|測量|投影算符 |
|糾纏|不可分離張量積狀態 |
|不可複製定理|沒有線性映射可以複製未知的量子態 |
**單量子位元閘：**
|門 |矩陣|效果|
|------|--------|--------|
| Pauli-X（非）| [[0,1],[1,0]] |位元翻轉 |
|泡利-Z | [[1,0],[0,−1]] |相位翻轉|
|哈達瑪| (1/√2)[[1,1],[1,−1]] | (1/√2)[[1,1],[1,−1]] |建立疊加 |
|中國諾特| 4×4 控制閘 |糾纏兩個量子位元 |
### 密碼學
|應用 |代數使用 |
|-------------|-------------|
| RSA |乘法群 (ℤ/nℤ)* |
|橢圓曲線密碼學 |有限域上橢圓曲線上的點群 |
|高級加密標準 | GF(2⁸) 中的算術 |
|迪菲·赫爾曼 | (ℤ/pℤ)* 的循環子群或橢圓曲線群 |
