# 隨機過程
**隨機過程**是按時間（或空間）索引的隨機變數的集合。機率論研究單一隨機事件，而隨機過程研究隨機性如何隨時間演變。他們對股票價格、隊列長度、疾病傳播、語言生成以及機器學習模型的訓練動態進行建模。
---

## 基礎
＃＃＃ 定義
隨機過程 {X_t : t ∈ T} 是在公共機率空間上定義的一系列隨機變數。 T 是**索引集**（時間）：
- **離散時間：** T = {0, 1, 2, ...}
- **連續時間：** T = [0, ∞)
**狀態空間** S 是 X_t 可以取的可能值的集合。
### 關鍵屬性
|物業 |定義 |
|----------|------------|
| **平穩性** | (X_{t₁}, ..., X_{tₖ}) 的聯合分佈與 (X_{t₁+τ}, ..., X_{tₖ+τ}) 相同 |
| **獨立** |對於 t ≠ s，X_t 獨立於 X_s |
| **遍歷性** |時間平均值收斂於整體平均值 |
| **馬可夫性質** |未來只取決於現在，而不取決於過去 |
| **鞅** |預期未來值等於目前值 |
---

## 馬可夫鏈
**馬可夫鏈**是一個隨機過程，其中未來狀態僅取決於當前狀態（無記憶屬性）。
### 離散時間馬可夫鏈 (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**轉移矩陣** P 具有條目 p_{ij} = P(轉到 j | 目前位於 i)。
|物業 |聲明|
|----------|------------|
|行總和|每行總和為 1： Σⱼ p_{ij} = 1 |
| n 步過渡 | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
|固定式配送| πP = π（特徵值為 1 的左特徵向量）|
### 國家分類
|術語 |定義 |
|------|------------|
| **經常性** |鏈以機率 1 返回狀態 i |
| **瞬態** |永不返回的非零機率 |
| **吸收** | p_{ii} = 1（一旦進入，永不離開）|
| **期間** |返回時間的 GCD；週期 1 = 非週期 |
| **溝通** |狀態 i 和 j 可以互相到達 |
### 固定分佈
對於不可約的正循環馬可夫鏈，平穩分佈 π 存在且唯一，滿足：
πP = π, Σᵢ πᵢ = 1
**解釋：** πᵢ = 處於狀態 i 的長期時間比例。
**工作範例：**狀態為{晴天、雨天}的天氣模型。
P = [[0.9, 0.1], [0.5, 0.5]]（行：來自晴天，來自雨天）
平穩分佈： πP = π
- π₁=0.9π₁+0.5π2
- π2 = 0.1π₁ + 0.5π2
- π₁ + π2 = 1
- 求解： π₁ = 5/6 ≈ 0.833, πϒ = 1/6 ≈ 0.167
### 收斂到平穩性
對於不可約、非週期、正循環鏈：
- Pⁿ → Π（所有行都等於 π 的矩陣）為 n → Infini
- **混合時間：** 分佈接近 π 之前的步驟數
- **光譜間隙：** 1 − |λ2| （其中 λ2 是第二大特徵值）決定混合速度
### 連續時間馬可夫鏈 (CTMC)
轉變發生在受指數分佈支配的隨機時間。
|概念 |描述 |
|---------|-------------|
| **速率矩陣Q** | q_{ij} ≥ 0（i ≠ j）； q_{ii} = −Σ_{j≠i} q_{ij} |
| **轉移機率** | P(t) = e^{Qt}（矩陣指數）|
| **固定分佈** | πQ = 0 |
| **保持時間** |狀態 i 的時間為 Exp(−q_{ii}) |

## 隨機遊走
**隨機遊走**是由連續的隨機步驟形成的路徑。
### 簡單隨機遊走
X_n = X_{n-1} + Z_n，其中 Z_n ∈ {+1, −1}，機率為 p，q = 1−p。
|物業 | p = 1/2（對稱）| p ≠ 1/2（有偏差）|
|----------|---------------------|--------------------|
| E[X_n] | 0 | n(2p−1) | n(2p−1) | n(2p−1) | n(2p−1)
|變數[X_n] | n | 4npq |
|返回原點？ |是（機率為 1）|不（漸行漸遠）|
|反覆發作？ |是（一維和二維）|沒有 |
### 高維度隨機遊走
|尺寸|反覆發作？ |直覺|
|------------|------------|------------|
|一維 |是的 | 「醉酒的人總能找到回家的路」|
| 2D |是的 | “醉鳥總是能找到回家的路”|
| 3D+ |沒有 | 「喝醉的麻雀永遠找不到回家的路」 |
### 與布朗運動的聯繫
縮放隨機遊走：令 S_n = ΣZ_i。然後步長 → 0 且步長 → ∞：
S_{⌊nt⌋} / √n → B(t) （布朗運動，根據 Donsker 定理）
---

## 布朗運動
**布朗運動**（維納過程）B(t) 是隨機遊走的連續時間限制。
＃＃＃ 定義
B(t) 滿足：
1. B(0) = 0
2. B(t) 具有連續路徑
3. 獨立增量：B(t) − B(s) 獨立於 B(s) − B(r)，且 r < s < t
4. B(t) − B(s) ~ N(0, t − s) （高斯增量）
### 關鍵屬性
|物業 |聲明|
|----------|------------|
| E[B(t)] | = 0 |
|變數[B(t)] | = t |
| Cov[B(s), B(t)] | Cov[B(s), B(t)] | = 分鐘（s，t）|
|無處可微 |路徑是連續的但沒有導數 |
|分形維數 |圖的 Hausdorff 維數為 3/2 |
|馬可夫性質 |未來僅取決於目前位置 |
|鞅| E[B(t) | F_s] = B(s) 對於 s < t |
### 幾何布朗運動
S(t) = S(0) exp((μ − σ²/2)t + σB(t))
這是布萊克-斯科爾斯框架中股票價格的標準模型。
- μ：漂移（預期回報）
- σ：波動性
---

## 泊松過程
**泊松過程** N(t) 計算 [0, t] 中發生的事件數。
＃＃＃ 定義
N(t) ~ Poisson(λt)，其中 λ 是速率（每單位時間的事件）。
|物業 |聲明|
|----------|------------|
| N(0) = 0 | N(0) = 0 — |
|獨立增量|不相交區間內的事件是獨立的 |
|固定增量| N(t+s) − N(s) ~ 泊松(λt) |
| E[N(t)] | = λt |
|變數[N(t)] | = λt |
|到達間隔時間 |指數分佈：T_i ~ Exp(λ) |
### 概括
|變體 |說明 |
|---------|-------------|
| **非同質性** |速率 λ(t) 隨時間變化 |
| **複合泊松** |每個事件都有一個隨機大小：S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **泊松隨機測量** |時空點，而不僅僅是時間|
| **多元** |具有可能互動的多種事件類型 |
---

## 鞅
**鞅**是一個公平的遊戲：在給定所有當前資訊的情況下，預期未來價值等於當前價值。
＃＃＃ 定義
{X_n} 是關於過濾 {F_n} 的鞅，如果：
1. X_n 是 F_n 可測量的（已調整）
2. E[|X_n|] < ∞（可積）
3.E[X_{n+1}|E[X_{n+1}] F_n] = X_n（公平遊戲）
|變體 |狀況 |解讀|
|--------|---------|----------------|
| **鞅** | E[X_{n+1} | F_n] = X_n |公平遊戲|
| **下鞅** | E[X_{n+1} | F_n] ≥ X_n |好遊戲（熱度上升）|
| **超級鞅** | E[X_{n+1} | F_n] ≤ X_n |不利的遊戲（趨勢下降） |
### 關鍵定理
|定理|宣告|
|--------|------------|
| **可選停止** |在某些條件下，E[X_T] = E[X_0]，停止時間為 T |
| **收斂** |有界鞅幾乎肯定收斂 |
| **最大不平等** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Doob 的) |
---

## 蒙特卡羅方法
**蒙特卡羅方法**使用隨機抽樣來估計確定性數量。
### 基本思想
估計 E[f(X)]，其中 X ~ P：
1. 從P中抽取N個樣本：x₁, x2, ..., x_N
2. 計算： Î = (1/N) Σᵢ f(xᵢ)
3. 根據大數定律： Î → E[f(X)] as N → ∞
**誤差：** 標準誤 = σ_f / √N，其中 σ_f² = Var[f(X)]
### 方差減少技術
|技術|想法 |加速|
|------------|------|---------|
| **重要性抽樣** |從 Q 而不是 P 採樣，按 P/Q 加權 |可以是戲劇性的|
| **對立變數** |使用 (x, −x) 對消除變異數 | 〜2x |
| **控制變數** |減去與 f | 相關的已知期望函數變化 |
| **分層抽樣** |分割域，對各層進行取樣 |減少變異數 |
| **拉奧-布萊克威爾** |條件是有足夠的統計數據|總是有幫助 |

## 馬可夫鏈蒙地卡羅 (MCMC)
MCMC構造一個馬可夫鏈，其平穩分佈是目標分佈。經過「老化」期後，樣本近似於目標值。
### Metropolis-Hastings 演算法
|步驟|行動|
|------|--------|
| 1 |目前狀態：x_t |
| 2 |提議：x* ~ q(x* \| x_t) （提議分佈） |
| 3 |接受率： α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 |以機率 α 接受：x_{t+1} = x*（接受）或 x_t（拒絕）|
**特殊情況 - Metropolis 演算法：** 對稱提議 q(x*|x) = q(x|x*)，因此 α = min(1, π(x*)/π(x_t))。
### 吉布斯取樣
Metropolis-Hastings 的一個特例，其中每個變數都根據其完整條件分佈進行更新。
對於目標 π(x₁, x2, ..., xₖ)：
1. 樣本 x₁^{(t+1)} ~ π(x₁ | x2^{(t)}, ..., xₖ^{(t)})
2. 樣本 x2^{(t+1)} ~ π(x2 | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. 繼續處理所有變數
4. 重複
|物業 |聲明|
|----------|------------|
|總是接受 | α = 1（無拒絕步驟）|
|需要|能夠從每個完整的條件中進行採樣 |
|收斂|保證不可約的非週期鏈 |
### MCMC 診斷
|診斷|目的|
|------------|---------|
| **追蹤圖** |目視檢查混合和平穩性 |
| **自相關** |測量樣本依賴性（需要低自相關）|
| **格爾曼-魯賓 (R̂)** |比較多個鏈； R̂ < 1.05 顯示收斂 |
| **有效樣本量** | N_eff = N / (1 + 2Σρₖ);考慮自相關|
| **老化** |在鏈達到靜止之前丟棄初始樣本 |

|隨機過程|應用 |

|吉布斯取樣|主題模型（LDA）、貝葉斯網路、影像去噪 |
| MCMC 診斷 |確保機率模型的可靠推理 |

隨機過程是隨時間變化的隨機性的數學。它們支撐現代貝葉斯推理 (MCMC)、強化學習（馬可夫決策過程）、生成模型（擴散模型）、金融數學和排隊理論。了解這些過程為您提供了動態建模不確定性的工具 - 不僅僅是作為快照，而是隨著它的發展。
