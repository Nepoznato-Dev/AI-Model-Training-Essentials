# 資訊理論
資訊理論由克勞德·香農 (Claude Shannon) 於 1948 年創立，對資訊本身進行量化。一則訊息能告訴你多少訊息？您可以將資料壓縮到什麼程度？在吵雜的頻道上您的通訊速度有多快？這些問題都有精確的數學答案。除了通訊之外，資訊理論已成為機器學習的基礎——交叉熵是分類的預設損失函數，KL 散度衡量分佈相似性，互資訊驅動特徵選擇。
---

## 熵
**熵**衡量隨機變數的平均不確定性或「意外」。
### 香農熵（離散）
對於具有機率質量函數 p(x) 的離散隨機變數 X：
H(X) = −Σₓ p(x) log2 p(x)
單位：**位**（使用 log2 時）或 **nats**（使用 ln 時）。
|分銷|熵 |直覺|
|------------|---------|------------|
|公平币 (p = 0.5, 0.5) | 1 位 |二元结果的最大不确定性|
|有偏差的硬币 (p = 0.9, 0.1) | 0.469 位 |不那么令人惊讶——大部分都是正面|
|确定性 (p = 1, 0) | 0 位 |完全没有不确定性|
|公平模具（6 面）| 2.585 位 |更多结果 = 更多不确定性 |
|统一 n 个结果 | log2(n) 位 | n 个结果的最大熵 |
### 熵的性質
|物業 |聲明|
|----------|------------|
|非負性| H(X) ≥ 0 |
|最大| H(X) ≤ log2(\|X\|) 且均勻分佈相等 |
|鍊式法則| H(X, Y) = H(X) + H(Y \| X) | H(X, Y) = H(X) + H(Y \| X) |
|調節減少| H(X \| Y) ≤ H(X) | H(X \| Y) ≤ H(X) |
|凹度| H 是機率分佈的凹函數 |
### 微分熵（連續）
對於密度為 p(x) 的連續隨機變數 X：
h(X) = −∫ p(x) log p(x) dx
與離散熵不同，微分熵可以是**負**。
|分銷|微分熵|
|----------|------------------------|
| [a,b] 上的製服 |日誌（b - a）|
|常態 N(μ, σ²) | (1/2) log(2πeσ²) | (1/2) log(2πeσ²) |
|指數(λ) | 1 − ln(λ) | 1 − ln(λ) |

## 聯合資訊、條件資訊與互資訊
### 聯合熵
H(X, Y) = −Σₓ Σᵧ p(x, y) log p(x, y)
測量對 (X, Y) 的總不確定度。
### 條件熵
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
測量觀察 X 後 Y 的剩餘不確定度。
### 互資訊
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
衡量 X 對 Y 的了解有多少（反之亦然）。
|物業 |聲明|
|----------|------------|
|非負性| I(X;Y) ≥ 0 |
|對稱性| I(X; Y) = I(Y; X) | I(X; Y) = I(Y; X) |
|與熵的關係式 | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
|與關節的關係 | I(X;Y) = H(X) + H(Y) − H(X, Y) |
|獨立| I(X; Y) = 0 當且僅當 X 和 Y 獨立 |
|自我資訊 | I(X;X) = H(X) | I(X;X) = H(X) |
### 視覺：熵圖
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## KL 散度
**Kullback-Leibler (KL) 散度**衡量一種分佈與另一種分佈的差異程度。
D_KL(P || Q) = Σₓ P(x) log [P(x) / Q(x)]
|物業 |聲明|
|----------|------------|
|非負性| D_KL(P \|\| Q) ≥ 0（吉布斯不等式）|
|身份 | D_KL(P \|\| Q) = 0 當且僅當 P = Q |
|不對稱|一般而言，D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) |
|不是一個指標 |對稱性與三角不等式失敗 |
**解釋：** D_KL(P || Q) 是使用針對 Q 最佳化的程式碼對 P 中的資料進行編碼所需的額外位數。
### 與其他數量的關係
|關係 |公式|
|-------------|---------|
|交叉熵 | H(P, Q) = H(P) + D_KL(P \|\| Q) |
|互資訊| I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
|有條件 KL | D_KL(P(Y\|X) \|\| Q(Y\|X)) X | 上的平均值
---

## 交叉熵
分佈 P 和 Q 之間的 **交叉熵**：
H(P, Q) = −Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### 交叉熵作為損失函數
在分類中，P 是真實分佈（one-hot 編碼標籤），Q 是模型的預測分佈。
**二元交叉熵（BCE）：**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**分類交叉熵：**
L = −Σᵢ yᵢ log(ŷᵢ)
|場景| y（真）| ŷ（預測）|損失|
|----------|----------|----------------|------|
|正確、自信| 1 | 0.95 | 0.95 0.051 | 0.051
|正確，不確定 | 1 | 0.55 | 0.55 0.598 | 0.598
|錯了，自信| 1 | 0.05 | 0.05 2.996 | 2.996
|錯誤，不確定| 1 | 0.45 | 0.45 0.799 | 0.799
最小化交叉熵相當於最小化與真實分佈的 KL 散度——這就是它作為損失函數效果如此良好的原因。

## 頻道容量
### 溝通管道模型
```
X → [Channel] → Y
```

- X：輸入隨機變數
- Y：輸出隨機變數
- 通道：由條件機率 p(y|x) 定義
### 香農的噪音通道編碼定理
對於容量為C的頻道，如果傳輸速率為R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C，則可靠通訊是不可能的。
**頻道容量：**
C = max_{p(x)} I(X; Y)
### 重要頻道範例
|頻道|說明 |產能 |
|---------|-------------|----------|
| **二元對稱 (BSC)** |以機率 p | 翻轉每一位1 − H(p) 位元 |
| **二元擦除（BEC）** |以機率 ε 擦除每一位元 | 1 − ε 位元 |
| **高斯 (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)log(1 + SNR) 位元 |
| **無噪音二進位** |完美傳輸 | 1 位元 |

## 原始碼編碼和壓縮
### 原始碼定理
對源進行編碼所需的平均位數受其熵限制：
L≥H(X)
最優程式碼實作 L ≈ H(X)。
### 霍夫曼編碼
**無前綴**代碼，將較短的代碼分配給更可能的符號。
|符號|機率|霍夫曼代碼|長度 |
|--------|-------------|-------------|--------|
|一 | 0.5 | 0.5 0 | 1 |
|乙| 0.25 | 0.25 10 | 10 2 |
| C | 0.125 | 0.125 110 | 110 3 |
| d | 0.125 | 0.125 111 | 111 3 |
平均長度：0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 位元/符號
熵：H = 1.75 位元/符號（本例中最佳！）
### 無損壓縮與有損壓縮
|類型 |原理|範例 |限制|
|------|------------|----------|--------|
| **無損** |消除統計冗餘 |郵遞區號、PNG、FLAC |熵率 H(X) |
| **有損** |刪除感知上不相關的資訊 | JPEG、MP3、H.264 |率失真函數 R(D) |
**速率失真理論：** 對於具有最大失真 D 的有損壓縮，最小速率為 R(D) = min I(X; X̂)，且滿足 E[d(X, X̂)] ≤ D。

## 與其他欄位的連接
### 資訊理論與熱力學
|概念 |資訊理論|熱力學|
|--------------------|--------------------------------|----------------|
|熵 |香農熵 H(X) |玻爾茲曼熵 S = k_B ln W |
|最大熵 |均勻分佈|熱平衡|
| KL 散度 |分佈差異|自由能差|
|互資訊|共享資訊|物理系統中的相關性|
數學形式是相同的－香農故意借用了統計力學中的「熵」一詞。
### 資訊理論與統計學
|概念 |應用 |
|---------|-------------|
|最大似然|相當於最小化從經驗分佈到模型分佈的 KL 散度 |
|費雪資訊| KL散度的曲率；估計變異數的下界 (Cramér-Rao) |
|最小描述長度 (MDL) |透過最小化總編碼長度來選擇模型 |
| AIC/BIC |基於 KL 的近似模型選擇標準 |

＃＃ 概括
|數量 |公式（離散）|意義|
|----------|--------------------|---------|
|熵 H(X) | −Σ p(x) log p(x) |平均不確定性|
|聯合熵 H(X,Y) | −Σ p(x,y) log p(x,y) | −Σ p(x,y) log p(x,y) |配對的總不確定性 |
|條件熵 H(Y\|X) | H(X,Y) − H(X) | H(X,Y) − H(X) |給定 X | Y 的剩餘不確定性
|互資訊 I(X;Y) | H(X) − H(X\|Y) | H(X) − H(X\|Y) | X 與 Y 之間共享的資訊 |
| KL 散度 D_KL(P\|\|Q) | Σ P(x) log(P(x)/Q(x)) |分佈之間的「距離」|
|交叉熵 H(P,Q) | −Σ P(x) log Q(x) |使用錯誤分佈的編碼成本 |
|通道容量C|最大 I(X;Y) |最大可靠通訊速率 |
資訊理論提供了可學習、壓縮和溝通的基本限制。對於機器學習從業者來說，它解釋了為什麼交叉熵作為損失函數，如何衡量學習表示的質量，以及如何考慮模型複雜性和數據擬合之間的權衡。香農 1948 年的見解至今仍與現代人工智慧和電力資訊息相關。
