# 量子力學
量子力學是最小尺度的物理理論－原子、電子、光子和自然界的基本粒子。它用機率、疊加和糾纏取代了經典力學的確定性世界。儘管量子力學具有違反直覺的性質，但它是所有科學中經過最精確檢驗的理論。如今，它的原理正與量子電腦的計算直接相關，量子電腦有望比傳統電腦以指數速度更快解決某些問題。

## 波粒二象性
### 德布羅意波長
每個動量為 p 的粒子都有一個相關的波長：
λ = h/p = h/(mv)
|粒子|典型 λ |可觀察到的波浪行為？ |
|----------|----------|----------------------------|
|電子（100 eV）| 0.12奈米|是（晶體繞射）|
|質子 | 0.003奈米|是（中子散射）|
|棒球 (40 m/s) | 10⁻3⁴米|否（太小而無法偵測到）|
### 雙縫實驗
典型的量子實驗：
1. 在兩個狹縫中一次發射一個粒子（電子、光子）
2. 每個粒子落在探測器上的一個點上
3. 隨著時間的推移，會出現干涉圖案──就好像每個粒子同時通過兩個狹縫
4. 如果測量粒子穿過哪個狹縫，干涉圖案就會消失
**結論：** 量子物體既不是純粹的粒子，也不是純粹的波。它們在未觀察到時表現出波狀行為，在測量時表現出粒子狀行為。

## 波函數
＃＃＃ 定義
**波函數** ψ(x, t) 完整地描述了一個量子系統。它是一個複值函數，其平方模給出了機率密度：
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### 標準化
總機率必須等於 1：
∫ |ψ(x)|² dx = 1（在所有空間上）
### 天生法則
求 x 和 x + dx 之間粒子的機率：
P(x 至 x+dx) = |ψ(x)|² dx
對於具有本徵態 φₙ 的一般可觀測量：
P(測量特徵值aₙ) = |⟨φₙ|ψ⟩|²
---

## 薛丁格方程
### 瞬態薛丁格方程
iℏ ∂ψ/∂t = Ĥψ
其中 Ĥ 是 **哈密爾頓算符**（總能量算符）。
### 與時間無關的薛丁格方程
對於穩態（能量本徵態）：
ψ = Eψ
這是一個特徵值方程式：允許的能量 E 是 Ĥ 的特徵值。
### 盒中粒子（無限方井）
最簡單的量子系統：粒子限制在 0 < x < L。
|数量 |结果 |
|----------|--------|
|波函數| ψₙ(x) = √(2/L) sin(nπx/L) |
|能量等級| Eₙ = n²π²ℏ²/(2mL²) = n²h²/(8mL²) |
|基態| n = 1，E₁ = h²/(8mL²) |
|零點能量| E₁ > 0（粒子無法完全靜止）|
|量子數| n = 1, 2, 3, ...（僅限正整數）|
### 量子諧波振盪器
V(x) = ½mω²x²
|數量 |成果 |
|----------|--------|
|能量等級| Eₙ = (n + ½)ℏω |
|零點能量| E₀ = ½ℏω |
|間距| ΔE = ℏω（均勻）|
|波函數|厄米多項式 × 高斯 |

## 運算子和可觀察量
在量子力學中，每個物理可觀察量都對應於一個**厄米算符**。
### 關鍵操作員
|可觀察|運算子（位置空間）|特徵值 |
|------------|------------------------|-------------|
|職位| x̂ = x |全部真實x|
|勢頭| p̂ = −iℏ ∂/∂x |全部真實p |
|能量（哈密爾頓）| Ĥ = −(ℏ²/2m)∂²/∂x² + V(x) | Eₙ（束縛態的離散）|
|角動量| L̂ = r × p̂ | ℏ√(l(l+1)) |
|旋轉| Ŝ = (ℏ/2)σ（泡利矩陣）| ±ℏ/2（對於旋轉 1/2）|
### 期望值
狀態 ψ 上測量可觀測 A 的平均結果：
⟨A⟩ = ⟨ψ|Â|ψ⟩ = ∫ ψ*(x) ψ(x) dx
### 交換關係
[，B̂] = B̂ − B̂
|換向器|結果 |意義 |
|------------|--------|-------------|
| [x̂, p̂] |我ℏ |位置和動量是不相容的|
| [L̂ₓ，L̂ᵧ] | iℏL̂_z |角動量分量不相容 |
| [σ̂ₓ, σ̂ᵧ] | 2iσ̂_z |泡利矩陣（自旋分量）|
如果 [Â, B̂] = 0，則可以同時測量可觀測量（共享本徵態）。

## 不確定原理
### 海森堡測不準原理
Δx·Δp≥ℏ/2
更一般地，對於任兩個可觀察量 A 和 B：
ΔA · ΔB ≥ (1/2)|⟨[,B̂]⟩|
### 不確定性關係
|配對|關係 |解讀|
|------|----------|----------------|
|位置動量| ΔxΔp ≥ ℏ/2 |無法準確了解兩者 |
|能源時代| ΔEΔt ≥ ℏ/2 |短暫的狀態具有不確定的能量|
|角動量| ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| |無法同時知道所有組件 |
**重要提示：** 不確定性與測量幹擾無關－它是量子態的基本特性。粒子不會同時具有確定的位置和動量。

## 量子態和疊加
### 狄拉克表示法 (Bra-Ket)
|符號|名稱 |意義|
|--------|------|---------|
| \|ψ⟩ |凱特 |狀態向量（列向量）|
| ⟨ψ\| |胸罩 |共軛轉置（行向量）|
| ⟨φ\|ψ⟩ |內積 | ψ 狀態的振幅 |
| \|ψ\|² |範數平方 |機率|
### 疊加原理
如果 \|ψ₁⟩ 和 \|ψ2⟩ 是有效的量子態，則任何線性組合也是有效的：
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

其中 |α|² + |β|² = 1（歸一化）。
**測量：** 測量時，系統以 |α|2 的機率「崩潰」到 \|ψ₁⟩ 或以 |β|2 的機率「崩潰」到 \|ψ2⟩。
### 量子位元
**量子位元**是一個量子位元：一個兩層量子系統。
\|ψ⟩ = α\|0⟩ + β\|1⟩，其中 |α|² + |β|² = 1
|代表| \|0⟩ | \|1⟩ |
|----------------|------|------|
|旋轉|旋轉起來 ↑ |向下旋轉 ↓ |
|光子偏振|水平|垂直|
|能量水平|基態|興奮狀態|
|電路| \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**布洛赫球體：**任何量子位元狀態都可以寫成：
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iφ} sin(θ/2)\|1⟩
其中 θ ε [0, π] 且 φ ε [0, 2π)。狀態空間是一個球體。

## 糾纏
當兩個量子位元的聯合狀態無法寫成各個狀態的乘積時，它們就被**糾纏**。
### 貝爾狀態（最大糾纏）
|狀態 |表達 |名稱 |
|--------|------------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) |貝爾州|
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) |貝爾州|
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) |貝爾州|
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) |單線態|
### 糾纏的性質
|物業 |描述 |
|----------|-------------|
|相關性|無論距離如何，測量一個量子位元即可立即確定另一個量子位元 |
|沒有溝通|無法單獨使用糾纏以比光更快的速度發送訊息 |
|一夫一妻制 |如果A與B最大程度地糾纏，則它不能與C糾纏 |
|脆弱性|與環境的互動破壞了糾纏（退相干） |
### EPR 悖論與貝爾定理
愛因斯坦、波多爾斯基和羅森認為量子力學一定是不完整的（隱變數）。貝爾表明，任何局部隱變量理論都滿足某些不等式。實驗違反了貝爾不等式——證實了量子力學並排除了局部隱變量。

## 量子閘
量子閘是量子位元上的酉運算。
### 單量子位元閘
|門 |矩陣|效果|
|------|--------|--------|
| **泡利-X**（否）| [[0,1],[1,0]] |位元翻轉：\|0⟩↔\|1⟩|
| **泡利-Y** | [[0,−i],[i,0]] |位元+相位翻轉|
| **泡利-Z** | [[1,0],[0,−1]] |相位翻轉： \|1⟩ → −\|1⟩ |
| **阿達瑪** (H) | (1/√2)[[1,1],[1,−1]] | (1/√2)[[1,1],[1,−1]] |建立疊加： \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **階段** (S) | [[1,0],[0,i]] |繞 Z 旋轉 π/2 |
| **T型閘** | [[1,0],[0,e^{iπ/4}]] |繞 Z 旋轉 π/4 |
| **旋轉** Rₓ(θ) | cos(θ/2)I − i sin(θ/2)σₓ |繞 X 軸旋轉 θ |
### 二量子位元閘
|门 |描述 |效果|
|------|-------------|--------|
| **中國不** |受控-NOT |如果控制為 \|1⟩ | 則翻轉目標
| **捷克** |受控-Z |如果控制為 \|1⟩ |，則將 Z 應用於目標
| **交換** |交換量子位元 | \|ab⟩ → \|ba⟩ |
### 創造糾纏
將 H 應用於量子位元 1，然後以量子位元 1 作為控制進行 CNOT：
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩
