# 最佳化
最佳化是從一組可行解決方案中找到最佳解決方案的數學。它問：給定一個函數和約束，什麼輸入可以最小化（或最大化）輸出？最佳化是機器學習的引擎－訓練模型意味著最小化損失函數。它出現在運籌學、經濟學、工程設計以及幾乎所有定量領域。
---

## 問題表述
一般的**最佳化問題**具有以下形式：
最小化 f(x)
服從：gᵢ(x) ≤ 0（不等式限制），hⱼ(x) = 0（等式限制）
|術語 |意義|
|------|---------|
| **目標函數** f(x) |最小化（或最大化）的數量 |
| **決策變數** x |我們可以控制的價值|
| **可行區域** |滿足所有限制的所有 x 的集合 |
| **全域最小值** |對所有可行 x，可行 x* 且 f(x*) ≤ f(x) |
| **局部極小值** |對於某個鄰域中的所有可行 x，可行 x* 且 f(x*) ≤ f(x) |
| **凸問題** | f 是凸的，可行區域是凸集（局部最小值 = 全域最小值） |
---

## 線性規劃 (LP)
當目標和所有限制都是**線性**時，問題就是線性規劃。
### 標準表格
最小化 cᵀx
滿足：Ax ≤ b，x ≥ 0
其中c，x ε ℝⁿ，A ε ℝᵐˣⁿ，b ε ℝᵐ。
＃＃＃ 特性
|物業 |聲明|
|----------|------------|
|凸性| LP 永遠是凸問題 |
|最優解 |總是位於可行多胞形的頂點（角點）|
|存在|若可行區域有界且非空，則存在最適解 |
|多重最優|如果兩個頂點是最優的，則它們之間的邊上的每個點也是最優的 |
### 單純形法
**單純形法**（Datzig，1947）沿著可行多面體的邊緣從一個頂點移動到另一個頂點，始終改進目標，直到達到最佳值。
|物業 |價值|
|----------|--------|
|最壞情況時間| O(2ⁿ)（指數 - 實務上很少見）|
|平均案例時間 |大多數實際問題的多項式 |
|關鍵理念|移動到具有更好目標值的相鄰頂點 |
**演算法（概述）：**
1. 從基本可行解（多面體的頂點）開始
2. 選擇一個輸入變數（可以改善目標的變數）
3.選擇離開變數（保持可行性）
4. Pivot：移動到新的頂點
5. 重複直到不存在改進方向
### 內點法
單純形的替代方案：從可行區域內接近最優值。
|物業 |價值|
|----------|--------|
|最壞情況時間|多項式（對於某些變體為 O(n3·⁵)）|
|實用效能|在大型議題上與單純形競爭
|關鍵理念|沿著內部的「中心路徑」|
### 已工作 LP 範例
**問題：** 一家工廠生產椅子 (x₁) 和桌子 (x2)。
- 利润：每把椅子 30 美元，每张桌子 50 美元
- 木材：2x₁ + 4x2 ≤ 100（可用板腳）
- 勞動力：x₁ + 3x2 ≤ 60（可用小時數）
- 最大化：30x₁ + 50x2
**解決方案（2個變數的圖形方法）：**
- 可行區域的頂點：(0,0)、(30,0)、(40,10)、(0,20)
- 評估每個頂點的目標：
  - (0,0)：利潤 = 0
  - (30,0)：利潤 = 900
  - (40,10): 利潤 = 1700 ← 最優
  - (0,20)：利潤 = 1000
- **最佳：** x₁ = 40 張椅子，x2 = 10 張桌子，利潤 = 1700 美元

## 凸優化
如果目標函數是凸的且可行區域是凸集，則問題是**凸**。
### 凸集和函數
|概念 |定義 |
|---------|------------|
| **凸集** |對集合中的任何 x, y 且 t ∈ [0,1]： tx + (1−t)y 也在集合中 |
| **凸函數** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) 對所有 t ∈ [0,1] |
| **嚴格凸** |對 t ∈ (0,1) 且 x ≠ y | 來說，不等式是嚴格的。
**關鍵屬性：** 對於凸最佳化，每個局部最小值都是全域最小值。
### 常見的凸函數
|功能|凸？ |哪裡 |
|----------|---------|--------|
| ax + b（線性）|是（且凹）|無所不在 |
| x² |是的 | ℝ |
| eˣ |是的 | ℝ |
| −log(x) |是的 | x > 0 |
| \|x\|ᵖ (p ≥ 1) |是的 | ℝⁿ |
| max(f1, f2) 如果 f1, f2 凸 |是的 |域的交集 |
### 梯度下降
機器學習中最基本的最佳化演算法。
**更新規則：** x_{k+1} = x_k − α∇f(x_k)
其中 α > 0 是**學習率**（步長）。
|變體 |更新規則 |優勢 |
|--------|-------------|------------|
| **批量GD** | x ← x − α∇f(x) |穩定收斂 |
| **隨機 GD (SGD)** | x ← x − α∇fᵢ(x)（一個樣本）|每次迭代速度快，逃脫局部最小值 |
| **小批量 SGD** | x ← x − α(1/|B|)ΣᵢεB ∇fᵢ(x) |批次與隨機之間的平衡 |
| **勢頭** | v ← βv − α∇f(x); x ← x + v |經由平坦區域加速 |
| **亞當** |每個參數的自適應學習率 |開箱即用，適合深度學習 |
| **RMS 螺旋** |透過梯度大小的運行平均值來縮放學習率 |適合 RNN |
### 收斂率
|方法|凸 f |強凸 f |
|--------|----------|--------------------|
|梯度下降| O(1/k) | O(1/k) | O((1−μ/L)ᵏ)（線性）|
|新元 | O(1/√k) | O(1/√k) | O(1/k) | O(1/k) |
|加速 GD (Nesterov) | O(1/k²) | O(1/k²) | O((1−√(μ/L))ᵏ) | O((1−√(μ/L))ᵏ)
其中 k = 迭代次數，μ = 強凸性參數，L = Lipschitz 常數。
### 選擇學習率
|戰略|描述 |
|----------|-------------|
|固定α |簡單但可能發散（太大）或收斂緩慢（太小）|
|線搜尋|找出沿梯度方向最小化 f(x − α∇f(x)) 的 α |
|腐爛時間表| α_t = α₀ / (1 + βt) 或 α_t = α₀ · βᵗ |
|熱身|從小處開始，增加，然後衰減（在變壓器訓練中常見）|
|自適應（亞當）|基於梯度統計的每個參數學習率 |

## 約束優化
### 拉格朗日乘數
對於該問題：在 h(x) = 0 的情況下最小化 f(x)。
**拉格朗日：** L(x, λ) = f(x) + λh(x)
最優情況下：∇ₓL = 0 且∇_λL = 0（得 h(x) = 0）。
**工作範例：** 在 x + y = 1 的條件下最小化 f(x,y) = x² + y²。
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- 限制：x + y = 1 → −λ = 1 → λ = −1
- 解：x = 1/2，y = 1/2，f = 1/2
### KKT 條件
**Karush-Kuhn-Tucker (KKT) 條件**將拉格朗日乘數推廣到不等式限制條件。
對於：在 gᵢ(x) ≤ 0、hⱼ(x) = 0 的條件下最小化 f(x)。
**拉格朗日：** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT 條件**（最適性所必需）：
|狀況 |方程式 |
|------------|----------|
|平穩性| ∇ₓL = 0 |
|初步可行性| gᵢ(x) ≤ 0, hⱼ(x) = 0 |
|雙重可行性 | λᵢ ≥ 0 |
|互補鬆弛 |對所有 i，λᵢgᵢ(x) = 0 |
**互補鬆弛**表示：如果約束 gᵢ 未活化 (gᵢ(x) < 0)，則 λᵢ = 0 （限制不影響解）。
對於滿足斯萊特條件的凸問題，KKT 條件既是必要的又是充分的。

## 二元性
每個最佳化問題（**原始**）都有一個相關的**對偶**問題。
### 弱對偶和強對偶
|概念 |宣告|
|--------|------------|
| **雙重功能** | g(λ, ν) = infₓ L(x, λ, ν) |
| **雙重問題** |在 λ ≥ 0 的情況下最大化 g(λ, ν) |
| **弱對偶性** |對偶最優 ≤ 原始最優（始終成立）|
| **強二元性** |對偶最優 = 原始最優（適用於斯萊特條件的凸問題）|
| **對偶差距** |原始最優 - 對偶最優（強對偶性下為零）|
### 為什麼二元性很重要
|應用 |二元性如何提供幫助？
|------------------------|--------------------|
|下限 | Dual 證明了原始解決方案有多好 |
|支援向量機 | SVM 問題的對偶導致核技巧 |
|敏感度分析 |雙變量衡量如果放鬆約束，最優變化有多大？
|分解 |大問題可以透過對偶 | 分解為更小的子問題。

## 整數規劃
當某些或所有變數必須是**整數**時，問題就會變得更加困難（通常是 NP 困難）。
### 類型
|類型 |描述 |
|------|-------------|
|純IP |所有變數必須是整數 |
|混合 IP (MIP) |有些变量是整数，有些是连续 |
|二進位IP |變數限制為 {0, 1} |
###解決方法
|方法|想法 |
|--------|------|
| **分支定界** |分割為子問題，解出 LP 鬆弛，剪枝 |
| **切割平面** |新增線性限制以收緊 LP 鬆弛 |
| **分支與切割** |將分支定界與剖切面結合 |
| **啟發式** |貪婪、局部搜尋、模擬退火求近似解 |
---

## 啟發式與元啟發式方法
當精確最佳化難以解決時，啟發式方法會找到好的（不一定是最佳的）解決方案。
|方法|關鍵理念|最適合 |
|--------|----------|----------|
| **梯度下降** |沿著最陡的下坡路線 |平滑、可微的函數 |
| **牛頓法** |使用二階（曲率）資訊 |順利、條件良好的問題 |
| **模擬退火** |以降低的機率接受較差的解決方案 |全局最佳化，組合 |
| **遺傳演算法** |使用選擇、交叉、突變來演化族群 |多目標，不可微 |
| **粒子群** |受最著名職位影響，特工探索太空 |連續、非凸 |
| **貝葉斯最佳化** |建立代理模型，使用獲取函數|昂貴的黑盒函數（超參數調整）|
### 牛頓優化法
**更新規則：** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
其中 H 是 Hessian 矩陣（二階導數矩陣）。
|物業 |價值|
|----------|--------|
|收斂速度|二次（接近最佳）|
|每次迭代成本 | Hessian 反演的 O(n3) |
|需要|兩次可微、正定 Hessian |
|擬牛頓 (BFGS) |從梯度近似 Hessian |每次迭代 O(n²) |

|方法|問題類型 |保證|規模|
|--------|-------------|------------|--------|
|單工|線性規劃|精確最優|數以百萬計的變數|

最佳化可以說是機器學習中最重要的數學工具。您訓練的每個模型（從線性迴歸到大型語言模型）都涉及解決最佳化問題。了解問題何時是凸的（保證全局最優）、梯度下降何時收斂以及如何處理約束，為您提供設計、調試和改進學習演算法的理論基礎。
