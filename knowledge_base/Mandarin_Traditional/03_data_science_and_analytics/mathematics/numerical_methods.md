# 數值方法
數值方法是數學理論和實際計算之間的橋樑。雖然純數學證明了解的存在，但數值方法實際上計算的是有限精度的近似答案。每個機器學習模型、物理模擬和數據分析管道最終都依賴數值計算。了解這些方法——它們的準確性、穩定性和局限性——對於建立可靠的軟體至關重要。
---

## 浮點運算
計算機以有限精度表示實數。 **IEEE 754 標準**定義如何儲存和操作浮點數。
### IEEE 754 格式
|格式|位元|指數|尾數|近似十進位數字|範圍 |
|--------|------|----------|---------|----------------------------|--------|
|半 (fp16) | 16 | 16 5 | 10 | 10 3.3 | ±6.5×10⁴|
|單人 (fp32) | 32 | 32 8 | 23 | 23 7.2 | ±3.4 × 10³⁸ |
|雙 (fp64) | 64 | 64 11 | 11 52 | 52 15.9 | 15.9 ±1.8 × 10³⁰⁸ |
### 機器埃普西隆
**機器 epsilon** (ε_mach) 是浮點型中 1 + ε_mach > 1 的最小數。
|格式| ε_馬赫 |
|--------|--------|
| FP16 | 2⁻1⁰ ≈ 9.8 × 10⁻⁴ |
| FP32 | 2⁻²³ ≈ 1.2 × 10⁻⁷ |
| FP64 | 2⁻⁵² ≈ 2.2 × 10⁻1⁶ |
### 常見陷阱
|陷阱|範例|後果|
|---------|---------|-------------|
| **災難性取消** |計算 (1 + x) − 1 對於小 x |有效數字遺失 |
| **吸收** | 10⁸ + 1 = 10⁸ (fp32) |小價值損失大金額 |
| **非關聯性** | (a + b) + c ≠ a + (b + c) |總和順序很重要 |
| **除以接近零** | 1 / 10⁻3⁰⁰ → 溢位 |無限大或 NaN |
### 緩解策略
|戰略|描述 |
|----------|-------------|
| **卡漢求和** |補償求和以減少吸收誤差 |
| **卡漢-巴布斯卡-諾邁爾** | Kahan求和的改良版 |
| **排序求和** |先對小數求和以避免吸收 |
| **雙精度算術** |使用成對的雙精度數來擴展精度 |
| **體能分析** |了解問題本身是否會放大錯誤 |

## 求根
求 x 使得 f(x) = 0。
### 二分法
|物業 |價值|
|----------|--------|
|需要| f 連續，f(a) 和 f(b) 符號相反 |
|收斂|線性（每一步誤差減半）|
|有保證嗎？ |是的－總是收斂|
| d 位數字的迭代 | ≈ d / log₁₀(2) ≈ 3.32d |
**演算法：**
1. 從區間 [a, b] 開始，其中 f(a) · f(b) < 0
2. 计算中点 c = (a + b) / 2
3. 如果 f(c) = 0 或 |b − a| < 寬容，停止
4.若f(a)·f(c)<0，則設b=c；否則設 a = c
5. 重複
### 牛頓拉夫遜法
|物業 |價值|
|----------|--------|
|需| f 可微分，f'(x) ≠ 0 根 |
|收斂|二次（近根）|
|有保證嗎？ |否－可能會出現分歧或循環|
|更新規則 | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**工作範例：** 透過解 f(x) = x² − 2 = 0 求 √2。
- f'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x2 = 1.4167 - (2.0069 - 2) / 2.8333 = 1.4142
- x₃ = 1.41421356...（精確到小數點後 8 位）
### 割線法
類似牛頓法，但近似導數：
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
|物業 |價值|
|----------|--------|
|收斂|超線性（階數 ≈ 1.618，黃金比）|
|需要|兩個初步猜測（無需導數）|
### 求根法比較
|方法|收斂|需要衍生性商品嗎？ |有保證嗎？ |每步驟成本|
|--------|-------------|--------------------|-------------|----------------|
|二分|線性 (1) |沒有 |是的 | 1 函數評估 |
|牛頓-拉夫森|二次 (2) |是的 |沒有 | 2 函數評估 |
|割線|超線性 (1.618) |沒有 |沒有 | 1 函數評估 |
|布倫特法|超線性|沒有 |是的 |變化 |
**布倫特方法** 將二分法（確保收斂）與割線/逆二次插值（快速收斂）結合。它是大多數數值庫中預設的根查找器。

## 數值積分（求積）
近似計算 ∫ₐᵇ f(x) dx。
＃＃＃ 方法
|方法|公式|錯誤|訂單|
|--------|---------|--------|--------|
| **長方形（中點）** | (b−a) · f((a+b)/2) | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **梯形** | (b−a)/2 · [f(a) + f(b)] | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **辛普森的 1/3** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | (b−a)/6 · [f(a) + 4f(m) + f(b)] | O(h⁴) | 3 |
| **辛普森 3/8** |使用 4 個等距點 | O(h⁴) | 4 |
| **高斯求積** |最佳節點放置 | O(h²ⁿ) | n 點 |
### 複合規則
對於寬度為 h = (b−a)/n 的 n 個子區間：
|規則|複合配方|錯誤|
|------|--------------------|--------|
|複合梯形| h[f(a)/2 + Σf(xᵢ) + f(b)/2] | h[f(a)/2 + Σf(xᵢ) + f(b)/2] O(h²) |
|複合辛普森 | h/3[f(a) + 4Σf(奇數) + 2Σf(偶數) + f(b)] | O(h⁴) |
**工作範例：** 使用 n = 4 的複合梯形近似 ∫₀1 e^(−x²) dx。
- h = 0.25，點數：0、0.25、0.5、0.75、1
- f(0) = 1、f(0.25) = 0.9394、f(0.5) = 0.7788、f(0.75) = 0.5698、f(1) = 0.3679
- T = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- 真實值： ≈ 0.7468（誤差 ≈ 0.5%）
### 自適應正交
自動細分函數快速變化的區間，在平滑的情況下使用較少的點。這就是`scipy.integrate.quad`使用的（基於 QUADPACK）。

## 插值
估計已知資料點之間的值。
＃＃＃ 方法
|方法|描述 |光滑度|振盪|
|--------|-------------|------------|------------|
| **最近的鄰居** |使用最近的資料點 |不連續 |無 |
| **線性** |以直線連接點 | C⁰（連續）|無 |
| **多項式（拉格朗日）** |通過所有點的單多項式 | C^∞|許多點都嚴重（龍格現象）|
| **三次樣條** |分段立方，接縫處光滑 | C² |最小 |
| **徑向基底函數** |徑向核的加權和 |取決於內核 |低|
### 拉格朗日插值
給定 n+1 個點 (x₀, y₀), ..., (xₙ, yₙ)，通過所有點的唯一次數 ≤ n 多項式：
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**龍格現象：** 等距點的高次多項式插值可能會在邊緣附近劇烈振盪。透過使用切比雪夫節點或樣條線可以緩解。
### 三次樣條
C² 連續的分段三次多項式（連續二階導數）。
|類型 |邊界條件|
|------|--------------------|
|自然樣條| S''(x₀) = S''(xₙ) = 0 |
|夾緊花鍵| S'(x₀) 和 S'(xₙ) 指定 |
|不結|在 x₁ 且 xₙ₋₁ 處連續的三階導數 |

## ODE 求解器
以數值方式解常微分方程 dy/dt = f(t, y)。
### 歐拉方法
最簡單的 ODE 求解器。
**更新：** y_{n+1} = y_n + h · f(t_n, y_n)
|物業 |價值|
|----------|--------|
|訂單| 1（每步驟錯誤：O(h²)，全域：O(h)）|
|穩定性|有條件穩定（需要小 h）|
|成本|每步 1 次函數評估 |
### 龍格-庫塔方法
|方法|訂單|階段 |筆記|
|--------|--------|--------|--------|
| **歐拉** | 1 | 1 |最簡單|
| **中點** | 2 | 2 |更高的準確度 |
| **赫恩 (RK2)** | 2 | 2 |預測校正器 |
| **經典RK4** | 4 | 4 |標準主力 |
| **多蒙王子 (RK45)** | 4(5) | 4(5) | 6 |自適應步長（在ode45中使用）|
### 經典 RK4（4 階龍格-庫塔）
k₁ = f(t_n, y_n)
k2 = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk2/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k2 + 2k₃ + k₄) / 6
|物業 |價值|
|----------|--------|
|訂單| 4（全域誤差：O(h⁴)）|
|成本|每步驟 4 次功能評估 |
|穩定性|比歐拉好很多|
|用途 |非剛性 ODE 的預設值 |
### 剛性 ODE
**剛性** ODE 的組成部分在不同的時間尺度上變化很大。顯式方法（Euler、RK4）需要不切實際的小步長。
|方法|型別 |穩定性|
|--------|------|------------|
|隱式歐拉|隱式| A-穩定（無條件穩定）|
|後向微分公式（BDF）|隱式| A-穩定（最多 5 階）|
|隱式龍格-庫塔|隱式|存在 L-穩定變體 |
| LSODA |自動|在剛性/非剛性之間切換 |

## 數值穩定性和調節
### 條件號
**條件數**衡量問題的輸出相對於輸入的微小變化有多少變化。
對於線性系統 Ax = b： κ(A) = ||A|| · ||A⁻1||
| κ(A)|解讀|
|--------|----------------|
| ≈ 1 |條件優越 |
| 10立方|輕度敏感|
| 10⁸ |病態（損失約 8 位元精度）|
| → 無限大 |奇異（無唯一解） |
### 演算法的穩定性
如果輸入中的小擾動導致輸出中的小擾動（相對於問題的條件數），則演算法是**數值穩定的**。
|演算法|穩定的？ |筆記|
|------------|---------|--------|
|部分旋轉的高斯消去法 |是的 |標準方法 |
|透過 QR 計算特徵值 |是的 |向後穩定|
|樸素求和（先大+小）|沒有 |使用卡漢求和 |
|計算方差為 E[X²] − (E[X])² |可能沒有 |使用 Welford 的線上演算法 |
### 韋爾福德線上演算法
運行平均值和變異數的數值穩定計算：
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

這避免了在簡單的兩次傳遞公式中發生的災難性抵消。

|數值方法|應用 |
|----------------|-------------|
|浮點 (fp16/fp32/bf16) |混合精準度訓練、模型量化、記憶體效率 |
|尋根|最大似然估計（找出梯度 = 0 的位置）|
|數值積分 |貝葉斯推論（計算邊際可能性），期望值 |
|內插|平滑、插補、代理模型、激活函數 |
| ODE 解算器 |神經常微分方程、連續時間 RNN、群體動力學、基於物理的 ML |
|條件編號|了解線性迴歸、正規方程式中的數值問題 |
|穩定求和|計算損失函數、批量歸一化統計 |
| RK4 / 自適應解算器 |模擬動力系統，訓練連續深度網路 |

＃＃ 概括
|主題 |核心理念|關鍵方法|
|--------|---------|------------|
|浮點|有限精度表示 | IEEE 754，卡漢求和 |
|尋根|解 f(x) = 0 |二等分，牛頓拉夫森，布倫特|
|數值積分 |近似 ∫f(x)dx |梯形、辛普森求積、高斯求積|
|內插|資料點之間的估計 |三次樣條、拉格朗日、RBF |
| ODE 解算器 |解 dy/dt = f(t,y) |歐拉、RK4、自適應法 |
|穩定性|對舍入誤差的敏感度 |條件數，演算法穩定|
數值方法是數學與現實的結合。沒有計算機可以準確地表示大多數實數，在實踐中沒有符號計算導數，也沒有針對現實世界問題以封閉形式計算積分。了解數值方法可以讓您選擇正確的演算法，預測其準確性，並避免有限精度算術產生的細微錯誤。
