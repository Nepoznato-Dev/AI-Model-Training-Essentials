# 經典力學
經典力學描述了物體在力的影響下的運動。從下落的蘋果到繞著軌道運行的行星，從振動的弦到碰撞的粒子，它的原理支配著宏觀世界。除了物理應用之外，經典力學還催生了變分法、辛幾何以及支撐量子力學和現代最佳化的哈密頓框架。
---

## 牛頓力學
### 牛頓三定律
|法律|聲明|數學形式|
|-----|---------|--------------------|
| **第一（慣性）** |除非受到力的作用，否則物體保持靜止或勻速運動 |如果 F_net = 0，則 v = 常數 |
| **第二（F = ma）** |力等於質量乘以加速度 | **F** = m**a** = m(d²**x**/dt²) |
| **第三（動作-反應）** |每個動作都會產生大小相等、方向相反的反應 | **F**₁2 = -**F**2₁ |
### 自由體圖
**自由體圖**隔離一個物體並顯示作用在其上的所有力。
**共同力量：**
|力|公式|方向 |
|--------|---------|------------|
|重力（近地球）| F = 毫克 |向下|
|法向力|尼 |垂直於表面 |
|摩擦力（靜態）| f_s ≤ μ_s N |反對即將發生的議案 |
|摩擦力（動能）| f_k = μ_k N |反對議案 |
|彈簧（胡克定律）| F = −kx |恢復（趨向平衡）|
|緊張| T |沿著繩子/繩子|
|拖曳 | F_d = ½C_d ρAv² |反對速度 |
### 範例：斜坡上的方塊
質量為 m 的木塊位於角度為 θ 的無摩擦斜面上。
- 力：重力（毫克向下）、法向力（N 垂直於表面）
- 分解重力：mg sin θ（沿斜坡），mg cos θ（進入表面）
- N = mg cos θ（垂直於表面無運動）
- 沿著斜坡的加速度：a = g sin θ

## 能量方法
### 功和動能
**功** 由力完成：W = ∫ **F** · d**r**
**功能量定理：** W_net = ΔKE = ½mv²² − ½mv₁²
### 位能
|力|位能|筆記|
|--------|-----------------|--------|
|重力（近表面）| U = 毫克 | h = 參考高度以上 |
|重力（一般）| U = −GMm/r |無限遠為零|
|春天| U = ½kx² | x = 平衡位移 |
|靜電| U = kq₁q2/r |類似電荷：正U|
### 節約能源
如果只有保守力起作用：E = KE + PE = 常數
½mv₁² + U₁ = ½mv²² + U²
**工作範例：** 球從高度 h 落下。
- 初始：KE = 0，PE = mgh
- 在即將落地前：KE = ½mv²，PE = 0
- 守恆：mgh = ½mv² → v = √(2gh)
＃＃＃ 力量
P = dW/dt = **F** · **v**（做功率）

## 動量和碰撞
### 線性動量
**p** = m**v**
牛頓第二定律（替代形式）： **F** = d**p**/dt
### 動量守恆
如果沒有外力：總動量守恆。
|碰撞類型| KE 保守嗎？ |動量守恆？ |
|--------------|--------------|----------|
| **有彈性** |是的 |是的 |
| **無彈性** |沒有 |是的 |
| **完全無彈性** |否（最大損失）|是（物體黏在一起）|
**一維彈性碰撞：** 兩個質量 m₁、m2，初始速度為 u₁、u2：
- v₁ = ((m₁−m2)u₁ + 2m2u2) / (m₁+m2)
- v2 = ((m2−m₁)u2 + 2m₁u₁) / (m₁+m2)
### 角動量
**L** = **r** × **p** = m(**r** × **v**)
扭矩：**τ** = d**L**/dt = **r** × **F**
**守恆：** 如果沒有外部扭矩，角動量守恆。

## 拉格朗日力學
**拉格朗日**公式用能量代替力，提供了一個更優雅和通用的框架。
### 拉格朗日
L = T − V（動能減去位能）
### 最小作用原理（漢密爾頓原理）
系統在時間 t₁ 和 t2 之間所採取的實際路徑最小化（更準確地說，使靜止）**動作**：
S = ∫_{t₁}^{t2} L(q, q̇, t) dt
### 歐拉-拉格朗日方程
條件 δS = 0 得：
d/dt(∂L/∂q̇) − ∂L/∂q = 0
對於每個廣義座標 q。
**工作範例：** 簡單擺（長度 l，質量 m，與垂直方向的角度 θ）。
- T = ½ml²θ̇²
- V = −mgl cos θ
- L = ½ml²θ̇² + mgl cos θ
- ∂L/∂θ = −mgl sin θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̈
- 歐拉-拉格朗日：ml²θ̈ + mgl sin θ = 0 → θ̈ + (g/l) sin θ = 0
### 拉格朗日力學的優點
|優勢 |說明|
|------------|-------------|
|座標獨立 |適用於任何座標系 |
|自然地處理約束 |無需計算約束力 |
|對稱→守恆|諾特定理將對稱性與守恆量連結 |
|輕鬆概括 |到場、相對論、量子力學 |
---

## 哈密頓力學
**哈密爾頓**公式是拉格朗日力學的重新公式，它使用位置和動量（而不是位置和速度）。
### 哈密頓量
H = Σᵢ pᵢq̇ᵢ − L = T + V（對於大多數機械系統）
其中 pᵢ = ∂L/∂q̇ᵢ 是**廣義動量**。
### 漢密爾頓方程
q̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
這些是 2n 個一階 ODE（相對於 n 個二階歐拉-拉格朗日方程式）。
**工作範例：** 諧波振盪器（質量 m，彈簧常數 k）。
- H = p²/(2m) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ （如預期）
- ṗ = −∂H/∂x = −kx → mẍ = −kx （胡克定律）
### 泊松括號
對於函數 f(q, p) 和 g(q, p)：
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
|物業 |聲明|
|----------|------------|
|時間演變| df/dt = {f, H} + ∂f/∂t |
|保護| f 是守恆的當且僅當 {f, H} = 0（且 ∂f/∂t = 0）|
|基本括號| {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**與量子力學的連結：** 泊松括號成為交換子：{f, g} → (1/iℏ)[f̂, ĝ]

## 守恆定律與諾特定理
### 諾特定理
拉格朗日量的每個連續對稱性都對應於一個守恆量。
|對稱性|保守數量 |
|----------|--------------------|
|時間平移不變性 |能源|
|空間平移不變性 |線性動量|
|旋轉不變性|角動量|
|規格不變性 |電荷 |
這是所有物理學中最深刻的結果之一——它將時空幾何與基本守恆定律連結起來。

## 剛體動力學
**剛體**是所有內部距離保持固定的物體。
### 關鍵概念
|概念 |公式|描述 |
|---------|---------|-------------|
| **轉動慣量** | I = Σmᵢrᵢ² 或 I = ∫r² dm |抗旋轉加速度|
| **旋轉KE** | KE = ½Iω² |旋轉能量|
| **角動量** | L = Iω | p = mv | 的旋轉模擬
| **扭力** | τ = Iα | F = ma | 的旋轉模擬
### 轉動慣量（常見形狀）
|形狀|軸|我|
|--------|------|---|
|實心球|通過中心| (2/5)MR² |
|空心球|經中心| (2/3)MR² |
|實心圓柱|沿軸心| (1/2)MR² |
|細棒|經過中心，垂直| (1/12)ML² |
|細棒|經由端部，垂直| (1/3)ML² |
|光碟|經中心，垂直| (1/2)MR² |

## 軌道力學
### 開普勒定律
|法律|聲明|
|-----|------------|
| **第一个（省略号）** |行星绕椭圆运动，太阳位于一个焦点 |
| **第二（等面积）** |从太阳到行星的直线在相同的时间内扫过相同的面积|
| **三次（谐波）** | T² ∝ a³（周期的平方与长半轴的立方成正比）|
### 軌道能量
E = ½mv² – GMm/r
|電子|軌道類型|
|---|-----------|
| E< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 |双曲线（未绑定）|
### 逃逸速度
v_escape = √(2GM/R)
對於地球：v_escape ≈ 11.2 km/s

經典力學不僅僅是下落的球和擺動的鐘擺。它的數學框架——拉格朗日力學和哈密頓力學——是所有科學中最有影響力的思想之一。它們推廣到量子力學、場論，甚至現代機器學習，其中基於能量的模型和基於物理的神經網路直接借鑒了這些具有數百年歷史的公式。
