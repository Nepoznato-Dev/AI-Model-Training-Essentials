# 控制理論
控制理論是使系統按照您希望的方式運作的數學。從恆溫器到自動駕駛儀，從機械手臂到化學反應器，控制系統感知、決定並採取行動以維持所需的行為。該領域提供了用於分析穩定性、性能和穩健性的嚴格工具，這些概念已遷移到強化學習、超參數調整和自適應系統中。
---

## 基本概念
### 開環與閉環
|類型 |描述 |範例|優點 |
|------|-------------|---------|------------|
| **開環** |控制動作獨立於輸出|洗衣機定時器|簡單，無需感應器 |
| **閉迴路（回饋）** |控制動作取決於輸出|恆溫器、巡航控制|拒絕乾擾，穩健|
### 框圖元素
|元素|符號|功能|
|---------|--------|----------|
| **工廠** | G(s) |被控制的系統|
| **控制器** | C(s) |運算控制動作 |
| **感測器** | H(s) |測量輸出 |
| **求和點** | ⊕ |計算誤差：r − y |
| **參考** | r(t) | r(t) |期望的輸出|
| **錯誤** | e(t) = r(t) − y(t) |期望與實際之間的差異|
| **打擾** | d(t) |影響工廠的不需要的輸入 |
### 閉環傳遞函數
對於標準負回饋系統：
T(s) = C(s)G(s) / (1 + C(s)G(s)H(s))
|數量 |公式|
|----------|---------|
|開環傳遞函數| L(s) = C(s)G(s)H(s) | L(s) = C(s)G(s)H(s) |
|閉環傳遞函數| T(s) = L(s)/H(s) / (1 + L(s)) |
|誤差傳遞函數| E(s)/R(s) = 1 / (1 + L(s)) |
|靈敏度| S(s) = 1 / (1 + L(s)) | S(s) = 1 / (1 + L(s)) |

## 傳遞函數
**傳遞函數** H(s) = Y(s)/X(s) 描述拉普拉斯域中線性時不變 (LTI) 系統的輸入輸出關係。
### 標準表格
|系統|傳遞函數|參數|
|--------|--------------------|------------|
| **一階** | K/(τs + 1) | K = 增益，τ = 時間常數 |
| **二階** | Kωₙ²/(s² + 2ζωₙs + ωₙ²) | ωₙ = 固有頻率，ze = 阻尼比 |
| **積分器** | K/s | — |
| **差異化因素** |凱斯 | — |
| **延遲** | e^{−sT_d} | T_d = 時間延遲 |
### 二階系統行為
|阻尼比 ζ |行為 |桿位置 |
|-----------------|---------|----------------|
| δ = 0 |無阻尼振盪|純屬虛構|
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 |過阻尼（緩慢，無振盪）|真實、鮮明 |
### 效能指標（階躍響應）
|公制|公式（二階，欠阻尼）|描述 |
|--------|------------------------------------|-------------|
|上升時間 (t_r) | ≈ 1.8/ωₙ |從 10% 到 90% 的時間到了 |
|高峰時間 (t_p) | π/(ωₙ√(1−z²)) |達到第一最大值的時間 |
|過衝 (M_p) | e^{−πz/√(1−z²)} × 100% |高於最終值的最大峰值 |
|穩定時間 (t_s) | ≈ 4/(ζωₙ) |時間與最終成績維持在 2% 以內 |
|穩態誤差|取決於系統型別 |當 t → ∞ | 時，期望值與實際值的差異

## PID 控制器
**PID控制器**是工業中使用最廣泛的控制器（超過90%的工業控制器）。
### PID 公式
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
在拉普拉斯域中： C(s) = K_p + K_i/s + K_d s
|術語 |效果|太多了|太少了|
|------|--------|----------|------------|
| **比例 (K_p)** |對當前錯誤作出反應 |振盪、不穩定 |反應慢、誤差大|
| **積分 (K_i)** |消除穩態誤差 |過衝、振盪|持續偏移|
| **導數 (K_d)** |預測未來誤差（阻尼）|噪音放大|抗干擾能力差|
### PID整定方法
|方法|方法|
|--------|----------|
| **齊格勒-尼可斯** |增大K_u直至振盪；使用 K_u 和週期 P_u 設定增益 |
| **科恩-庫恩** |基於階躍響應參數（增益、時間常數、死區時間）|
| **IMC（內模型控制）** |基於流程模型；提供良好的穩健性|
| **自動調整** |線上識別+調整（許多現代控制器）|
| **手冊** |僅從 K_p 開始，添加 K_i 以消除偏移，添加 K_d 以實現阻尼 |
### 齊格勒-尼科爾斯規則
1.設定K_i = K_d = 0
2. 增加K_p直至持續振盪：最終增益K_u，週期P_u
3. 設定增益：
|控制器| K_p | K_i | K_d |
|------------|-----|-----|-----|
|普 | 0.5K_u | — | — |
| PI | 0.45K_u | 1.2K_u/P_u | — |
| PID| 0.6K_u | 2K_u/P_u | K_u P_u/8 |

## 穩定性分析
如果系統的輸出對於有界輸入保持有界（BIBO 穩定性），則系統是**穩定的**。
### 基於桿的穩定性
|狀況 |穩定性|
|------------|------------|
|所有極點均位於左半平面 (Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) |不穩定|
|虛軸上的極點 (Re(s) = 0) |邊緣穩定（或重複不穩定）|
### 勞斯-赫爾維茲準則
無需顯式計算極點即可確定穩定性。根據特徵多項式係數構造勞斯數組。
**規則：** 第一列符號變化的數量等於右半平面極點的數量。
### 奈奎斯特穩定準則
在複平面中繪製開環頻率響應 L(jω)。
**規則：** 如果奈奎斯特圖逆時針圍繞點 (−1, 0) 的次數等於開環不穩定極點的數量，則閉環系統穩定。
**增益裕度：** 在不穩定之前增益可以增加多少（從繪圖到實軸上 -1 的距離）。
**相位裕度：** 在不穩定之前可以增加多少相位滯後（增益交叉處從圖到單位圓的角度）。
### 波特圖分析
繪製增益 (dB) 和相位（度數）與頻率（對數刻度）的關係圖。
|公制|定義 |期望值|
|--------|------------|---------------|
| **利潤率（GM）** |在相位 = −180° 時增益增加至 0 dB | > 6 分貝 |
| **相位裕度 (PM)** |增益交叉時的相位 (0 dB) + 180° | > 45° |
| **獲得交叉** |增益 = 0 dB 時的頻率 | — |
| **相位交叉** |相位 = −180° 時的頻率 | — |

## 狀態空間表示
對於多輸入多輸出（MIMO）系統，狀態空間形式比傳遞函數更自然。
### 標準表格
ẋ(t) = Ax(t) + Bu(t)（狀態方程式）
y(t) = Cx(t) + Du(t)（輸出方程式）
|矩陣|名稱 |尺寸|
|--------|------|------------|
|一個 |系統/狀態矩陣| n × n |
|乙|輸入矩陣| n × 公尺 |
| C |輸出矩陣| p × n |
| d |饋通矩陣 | p × m |
### 狀態空間的傳遞函數
G(s) = C(sI − A)⁻1B + D
### 可控性和可觀察性
|物業 |測試|意義|
|----------|------|---------|
| **可控制** | Rank[C_B] = n（其中 C_B = [B, AB, A²B, ...]）|可以轉向任何狀態 |
| **可觀察** | Rank[O_B] = n（其中 O_B = [C; CA; CA²; ...]）|可以根據輸出確定狀態 |
系統必須是可控制的，可透過回饋來穩定，並且可觀察以進行狀態估計。
### 狀態回饋
u = −Kx + r（全狀態回授）
閉環：ẋ = (A − BK)x + Br
**極點位置：** 選擇 K，使 A − BK 具有所需的特徵值（極點）。

## 最優控制
### 線性二次調節器 (LQR)
最小化： J = ∫₀^∞ (xᵀQx + uᵀRu) dt
其中 Q ≥ 0（狀態成本）且 R > 0（控製成本）。
**解：** u = −Kx 其中 K = R⁻1BᵀP，並且 P 求解 **代數 Riccati 方程式：**
AᵀP + PA − PBR⁻1BᵀP + Q = 0
|調整|效果|
|--------|--------|
|增加 Q |反應更快，控制力更強 |
|增加 R |反應速度較慢，控制力度較小 |
| Q ≫ R |積極的控制（如高 K_p） |
### 卡爾曼濾波器
具有高斯雜訊的線性系統的最佳狀態估計器。
**系統型號：**
ẋ = Ax + Bu + w（過程雜訊 w ~ N(0, Q)）
y = Cx + v（測量雜訊 v ~ N(0, R)）
**卡爾曼濾波器方程式：**
- 預測：x̂⁻ = Ax̂ + Bu, P⁻ = APAᵀ + Q
- 更新：K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻1，x̂ = x̂⁻ + K(y − Cx̂⁻)，P = (I − KC)P⁻
卡爾曼濾波器是 LQR 對偶濾波器 — 它最大限度地減少了估計誤差方差。

控制理論是讓系統可靠、穩健、有效率地做你想做的事的數學。事實證明，它的回饋、穩定性和最優性原則具有普遍性，出現在從機器人到強化學習、從經濟到生物學的各個領域。對於資料科學家來說，控制理論提供了理解自適應系統、設計穩定的訓練程序以及構建與動態環境互動的智慧代理的語言。
