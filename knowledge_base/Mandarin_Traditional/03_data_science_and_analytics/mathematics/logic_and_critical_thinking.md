# 邏輯與批判性思維
邏輯是對有效推理的研究——如何建構合理的論證並識別有缺陷的論點。批判性思考是質疑假設、評估證據和仔細推理的紀律習慣。這些技能不僅在數學和電腦科學中至關重要，而且在日常決策、科學研究和駕馭資訊豐富的世界中也至關重要。
---

## 什麼是論證？
在邏輯中，**論證**是一組旨在支持結論的陳述（前提）。
|組件|角色 |範例|
|------------|------|---------|
| **前提** |作為證據的聲明 | “所有人都會死” |
| **結論** |場地支持的主張| “蘇格拉底終有一死”|
| **推論** |從前提到結論的邏輯步驟| 「蘇格拉底是人，因此…」 |
### 有效與合理
|術語 |意義|範例|
|------|---------|---------|
| **有效** |如果前提為真，則結論必定為真 |即使前提是錯誤的，結構也是正確的 |
| **無效** |結論不是從前提得來的 |邏輯結構被打破|
| **聲音** |有效並且所有前提實際上都是正確的 |論證的黃金標準|
| **不健全** |無效或有虛假前提 |最有缺陷的論點|
---

## 推理類型
|類型 |方向 |實力|範例|
|------|---------|----------|------|
| **演繹** |一般→具體|某些（如果有效）| “所有哺乳動物都有肺。鯨魚是哺乳動物。因此，鯨魚有肺。” |
| **感應式** |具體→一般|可能 | “我見過的每一隻天鵝都是白色的。因此，所有的天鵝可能都是白色的。” |
| **溯因** |觀察→最佳解釋|似是而非的| “草濕了，最好的解釋就是下雨了。” |

## 命題邏輯
命題邏輯處理簡單的命題以及它們如何組合：
### 邏輯連接詞
|連接詞|符號|意義|真實條件 |
|------------|--------|---------|----------------|
| **和** | ∧ (p ∧ q) |連詞|僅當兩者都為真時才為真 |
| **或** | ∨ (p ∨ q) |析取 |當至少有一個為真時為真 |
| **不** | ← (←p) |否定|相反的真值 |
| **若...那麼** | → (p → q) |寓意 |僅當 p 為真且 q 為假時才為假 |
| **國際金融論壇** | ↔ (p ↔ q) |雙條件|當兩者有相同的真值時為真 |
### 蘊涵真值表 (p → q)
| p|問 | p → q |
|---|---|-------|
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |
注意：錯誤的前提使得暗示空洞地真實。 「如果月亮是乳酪，那麼我就是教宗」在邏輯上是正確的。

## 布林代數
布林代數是真/假值的數學，是數位電路設計和程式設計的基礎：
|法 |表達 |意義|
|-----|------------|---------|
| **可交換** | A ∧ B = B ∧ A |順序並不重要 |
| **聯想** | (A∧B)∧C=A∧(B∧C)|分組並不重要 |
| **分配** | A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) | AND 分佈於 OR |
| **德摩根** | Ø(A ∧ B) = ØA ∨ ØB |否定將 AND 翻轉為 OR |
| **德摩根** | Ø(A ∨ B) = ØA ∧ ØB |否定將 OR 翻轉為 AND |
| **雙重否定** | Ø(ØA) = A |兩個否定取消 |
| **身份** | A∧T=A; A ∨ F = A |身份元素|
| **補充** | A ∧ ØA = F； A ∨ ØA = T |矛盾與同義反覆 |

## 常見的邏輯謬誤
認識謬誤對於批判性思考至關重要：
### 形式謬誤（結構性錯誤）
|謬論|結構|範例|
|--------|------------|---------|
| **確認後果** |如果 P 則 Q. Q. 因此 P. | 「如果下雨，地就濕了。地濕了，所以就下雨了。」 （可能是灑水器。）
| **否認前因** |如果 P 則 Q。不是 P。因此不是 Q。 「如果下雨，地就濕。沒有下雨，所以地不濕。」 |
### 非正式謬誤（內容錯誤）
|謬論|描述 |範例|
|---------|-------------|---------|
| **人身攻擊** |攻擊人，而不是爭論| “你不能相信她的經濟計劃——她甚至不是經濟學家。” |
| **稻草人** |扭曲論點以使其更容易受到攻擊 | “你想減少軍事開支？所以你想讓這個國家毫無防備！” |
| **向當局上訴** |引用非相關領域專家的權威人士 | “這位名人說這種飲食有效，所以它一定有效。” |
| **虛假困境** |當有更多選項時只提供兩個選項 | 「你要嘛支持我們，要嘛反對我們。」 |
| **滑坡** |認為一個事件將不可避免地導致極端結果| “如果我們允許這種情況發生，接下來你就會知道，一切都會一片混亂。” |
| **循環推理** |結論是在前提下假設的 | “這本書是真的，因為它說的是真的。” |
| **倉促概括** |從證據不足得出廣泛的結論| “我在那個城市遇到了兩個粗魯的人。那裡的每個人都一定很粗魯。” |
| **事後 Ergo Propter Hoc** |從時間序列假設因果關係 | 「我服用了這種補充劑，感覺好多了，所以它一定有效。」 |
| **紅鯡魚** |引入一個不相關的話題來分散注意力 | “你問我的教育政策，但真正重要的是經濟。” |
| **跟風** |有些事是真的，因為很多人相信它 | 「每個人都買這個產品，所以它一定是最好的。」 |

## 評估參數：清單
|步驟|問題 |
|------|----------|
| 1. **確定結論** |論證試圖證明什麼？ |
| 2. **確定場所** |提供什麼證據？ |
| 3. **檢查有效性** |結論是從前提推導出來的嗎？ |
| 4. **檢查健全性** |這些前提真的是真的嗎？ |
| 5. **尋找謬誤** |是否有結構或內容錯誤？ |
| 6. **考慮反駁** |可能會有什麼反對意見？ |
| 7. **評估證據品質** |證據是否可靠、充分且相關？ |
---

## 為什麼這很重要
邏輯和批判性思考是數學、電腦科學、法律和科學探究的基礎。在一個充滿錯誤訊息、廣告和說服性言論的世界裡，嚴格評估論點的能力不僅僅是一種學術技能——更是一種生存技能。無論您是在調試程式碼、設計演算法還是做出人生決策，清晰的推理都可以區分正確的判斷和錯誤的判斷。
