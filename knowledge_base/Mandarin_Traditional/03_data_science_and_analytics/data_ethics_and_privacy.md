# 資料倫理與隱私
資料倫理是對資料收集、分析和部署如何影響人們的權利、自主權和福祉的研究。隱私是對誰控制個人資訊以及如何分享個人資訊的具體關注。這些主題已經從學術辯論變成了頭版新聞——GDPR 的執行、影響數十億用戶的資料洩露，以及公眾越來越意識到科技公司的資料實踐對民主、平等和個人自由產生真正的影響。
---

## 為什麼數據道德很重要
|關注|描述 |現實世界的影響 |
|--------|-------------|--------------------|
| **監視資本主義** |公司大規模將個人資料貨幣化 |失去隱私；操縱行為|
| **演算法偏差** |用有偏見的資料訓練的模型會重現偏見招募、貸款、治安方面的歧視 |
| **知情同意** |使用者不明白他們同意什麼 |為一個目的收集的資料用於另一目的|
| **資料外洩** |敏感資料因安全性差而暴露 |身分盜竊；財務詐欺；名譽受損 |
| **過濾氣泡** |個人化提要強化既有信念|政治兩極化；錯誤訊息|
| **深色圖案** |旨在誘騙用戶共享數據的 UI不需要的訂閱；意外的數據共享|

## 隱私框架和法規
### 主要隱私權法
|监管 |地区 |关键要求|
|------------|--------------------|-----------------|
| **GDPR**（一般資料保護規範）|歐盟/歐洲經濟區 |處理的合法依據；存取權；被遺忘的權利；資料可攜性；72 小時違規通知；高達全球收入 4% 的罰款 |
| **CCPA / CPRA**（加州隱私權法案）|美國加州 |知情權；刪除權；選擇停止銷售的權利；兒童的有限選擇|
| **LGPD**（Lei Geral de Proteção de Dados）|巴西 |與 GDPR 類似；合法依據；資料主體權利；需要 DPO |
| **PIPL**（個人資訊保護法）|中國 |需同意；資料本地化；跨境轉帳限制|
| **POPIA**（個人資訊保護法）|南非 |合法處理的條件；資料主體權利；調節器|
| **DPDP 法**（數位個人資料保護法）|印度 |同意;目的限制；資料主體權利；資料信託義務|
### GDPR 核心原則
|原理|要求 |
|------------|-------------|
| **合法、公平、透明** |合法處理資料；不誤導使用者；公開您收集的內容 |
| **目的限制** |僅出於指定、明確的目的收集資料 |
| **資料最小化** |只收集您真正需要的 |
| **準確度** |保持資料準確；更正或刪除不準確的資料 |
| **儲存限制** |資料保留時間不要超過必要的時間 |
| **誠信與保密** |保護資料免於未經授權的存取和遺失 |
| **責任** |證明遵守上述所有規定 |

## 隱私保護技術
|技術|它是如何運作的 |權衡|
|------------|-------------|------------|
| **匿名化** |刪除個人識別資訊 (PII) |難以完全匿名；重新識別風險 |
| **化名** |以假名替換標識符 |可逆； GDPR 下的個人資料仍然存在 |
| **差異隱私** |將校準雜訊加入查詢結果 |降低準確度；提供數學隱私權保障|
| **聯邦學習** |在設備上訓練模型；只分享模型更新|訓練速度較慢；通訊開銷|
| **安全多方計算** |多方在不洩漏輸入的情況下計算函數 |計算成本昂貴；實施起來很複雜|
| **同態加密** |對加密資料執行計算 |非常慢；有限營運支援|
| **資料脫敏** |隱藏部分資料（例如`***-**-1234`）|簡單但有限的保護 |

## 道德資料收集
### 道德收集原則
|原理|說明 |
|------------|-------------|
| **知情同意** |使用者了解他們同意什麼；不被法律術語埋沒|
| **目的透明** |明確說明收集資料的原因以及如何使用資料 |
| **最小收藏** |只收集達到既定目的所需的東西 |
| **使用者控制** |讓使用者存取、修正、下載和刪除他們的資料 |
| **保留有限** |不再需要時刪除資料 |
| **影響評估** |在收集敏感資料之前評估潛在危害 |
### 常見的深色圖案
|圖案|描述 |範例|
|---------|-------------|---------|
| **隱私胡鬧** |誘騙用戶分享超出他們預期的內容 |註冊時預先勾選「與朋友分享」|
| **羅奇汽車旅館** |註冊方便；難以取消|帳號刪除需要電話或傳真|
| **強制連續性** |免費試用版轉換為付費版，恕不另行通知 |信用卡上顯示訂閱費用 |
| **確認羞辱** |讓使用者感到內疚並選擇加入 | “不，謝謝，我不想省錢”|
| **隱藏設定** |隱藏在選單深處的隱私控制|選擇退出隱藏在 5 級設定下 |

## 數據的偏差與公平性
|偏見的來源|描述 |範例|
|----------------|-------------|---------|
| **選擇偏差** |數據不代表目標人群|僅根據某一人群的數據訓練招募模型 |
| **歷史偏見** |過去的歧視被編碼在數據中|逮捕記錄反映了有偏見的警務做法|
| **測量偏差** |用作代理的變數是有缺陷的 |使用郵遞區號作為信用度的代理 |
| **聚合偏差** |將不同群體視為同質群體 |一種模式適用於所有種族；忽略特定於群體的模式 |
| **倖存者偏差** |只看成功案例|研究成功的新創企業，而忽略失敗的新創企業 |
### 緩解策略
|戰略|描述 |
|----------|-------------|
| **多樣化的資料收集** |確保培訓資料代表所有受影響群體 |
| **偏差審計** |定期測試模型對不同群體的不同影響 |
| **公平指標** |衡量人口平等、機會均等、賠率均等 |
| **人工審核** |讓人類檢視高風險決策 |
| **透明度報告** |發布有關跨人口統計模型性能的數據 |
| **社區參與** |讓受影響社區參與設計和評估 |

## 資料治理
### 資料治理中的角色
|角色 |責任|
|------|----------------|
| **資料擁有者** |負責資料領域的高階領導 |
| **資料管家** |日常管理；品質;分類 |
| **資料保護官 (DPO)** | GDPR 合規性；隱私影響評估；與監管機構聯絡|
| **資料工程師** |管道；貯存;轉型|
| **資料科學家** |分析;造型;報告|
| **資料隱私分析師** |監控合規性；處理資料主體請求 |
### 資料分類
|分類|描述 |處理|
|----------------|-------------|----------|
| **公開** |可以自由分享|無限 |
| **內部** |僅限員工 |存取控制；沒有外部共用|
| **機密** |敏感商業資料 |加密;嚴格的存取控制；稽核日誌|
| **受限** |高度敏感；監管（PII、健康、金融）|靜態和傳輸中加密；資料處理；最小存取權限 |

＃＃ 概括
資料道德和隱私不再是可選的考慮因素——它們是法律要求、商業要求和道德義務。 GDPR 和類似法規制定了明確的規則：最少收集、透明使用、嚴格保護並賦予使用者控制權。差分隱私、聯合學習和加密等隱私保護技術使得在不暴露個人身分的情況下從資料中獲取價值成為可能。但僅靠技術還不夠。組織需要資料治理結構、偏見審計實踐以及將個人資料視為需要管理而不僅僅是被利用的文化。做到這一點的公司將贏得信任；那些不這樣做的公司將面臨監管罰款、公眾強烈反對，以及用戶共享資料意願的緩慢侵蝕。
