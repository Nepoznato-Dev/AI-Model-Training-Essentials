# 地理空間分析
地理空間分析是檢查具有地理成分（座標、地址、邊界或與地球上某個位置相關的任何資料）的資料的過程。它回答了諸如「我們的客戶在哪裡？」、「最佳路線是什麼？」以及「土地利用如何隨時間變化？」等問題。每個資料集都有一個空間維度，理解它可以解鎖純統計分析所錯過的見解。
---

## 核心概念
### 座標系
|系统|描述 |使用案例|
|--------|-------------|----------|
| **WGS 84 (EPSG:4326)** |全球标准；纬度/经度（以度为单位）|全球定位系统;大多数网络地图； GeoJSON |
| **网络墨卡托 (EPSG:3857)** |将地球仪投影到圆柱体上；扭曲极点面积 |谷歌地图；地图盒；大多数网络磁贴服务|
| **UTM**（通用横轴墨卡托）|将地球分为60个区域；以米为基础 |军队;测量；高精度本地作业|
| **英国国家电网（EPSG：27700）** | OSGB36数据；以米为基础 |英国地图|
| **本地预测** |针对特定区域的自定义预测 |最大限度地减少特定区域的变形 |
### 幾何類型
|類型 |描述 |範例|
|------|-------------|---------|
| **點** |單座標 |一家餐廳；感測器；一位客戶 |
| **線串** |點的有序序列 |一條路；一條河；一條路線 |
| **多邊形** |有內部的封閉形狀|一個國家；一個湖；交貨區 |
| **多點** |積分收集|一個城市的所有公車站 |
| **多行字串** |線條集合|網路中的所有道路|
| **多重多邊形** |多邊形的集合|一個群島；一個有島嶼的國家|
| **幾何集合** |混合型|一個擁有城市、道路和河流的國家|
---

## 資料格式
|格式|类型 |主要特点|
|--------|------|-------------|
| **GeoJSON** |文本 (JSON) |人类可读；网络友好；支持所有几何类型 |
| **形状文件** |二进制（多个文件）| ESRI 的旧版格式； .shp + .shx + .dbf + .prj |
| **KML** | XML |谷歌地球；支持3D和时间|
| **地理包** |基于 SQLite |单个文件；支持光栅和矢量；现代标准|
| **GeoParquet** |柱状（实木复合地板）|对于大型数据集有效；与数据工程工具集成|
| **WKT / WKB** |文本/二进制|众所周知的文本；众所周知的二进制文件；用于数据库存储|
| **MVT** |二进制 | Mapbox 矢量图块；用于向网络客户端提供地图数据|

## 空間操作
### 基本操作
|運營|描述 |範例|
|------------|-------------|---------|
| **距離** |計算幾何圖形之間的距離 | “查找10公里內所有醫院” |
| **緩衝區** |以給定距離圍繞幾何體創建多邊形 | “顯示學校周圍 500m 的區域”|
| **十字路口** |找出幾何圖形之間的重疊區域 | “哪些地塊位於洪水區？” |
| **聯盟** |將幾何圖形合併為一個 | “將所有地塊合併為一個區域”|
| **差異** |從一種幾何圖形中減去另一種幾何圖形 | “可建設面積不包括保護區”|
| **包含/內** |測試一個幾何體是否在另一個幾何體內部 | “哪些客戶在這個送貨範圍內？” |
| **最近的鄰居** |找到最接近的幾何形狀 | “最近的消防局是哪一個？” |
| **空間連結** |基於空間關係連結屬性| “將每個點分配給其包含的人口普查區域” |
### 空間索引
|指數類型 |說明 |使用案例|
|------------|-------------|----------|
| **R 樹** |邊界框層次結構；最常見 |後地理資訊系統； SQLite；通用 |
| **四叉樹** |遞歸細分為象限 |點資料；遊戲引擎|
| **Geohash** |分層網格；編碼為字串 |鄰近搜尋；資料庫分片 |
| **H3**（優步）|六邊形分層格 |分析；共乘；統一垃圾箱|
| **S2**（Google）|球體上基於單元的層次結構 |大規模空間索引 |

## 地理空間分析模式
### 常見分析類型
|圖案|描述 |使用案例|
|---------|-------------|----------|
| **點模式分析** |檢查點分佈 |犯罪地圖；疾病爆發檢測|
| **熱點分析** |尋找具有統計顯著性的聚類 |零售地點；犯罪;流行病學 |
| **網路分析** |路線最佳化；服務領域 |後勤;緊急應變；公用事業|
| **空間內插** |未採樣位置的估計值 |空氣品質；土壤特性；天氣 |
| **土地利用變化檢測** |比較一段時間內的衛星圖像 |城市擴張；毀林；農業 |
| **適宜性分析** |尋找符合多個條件的地點 |選址；保護規劃|
| **空間自相關** |測量附近值的相關性 |房地產價格；疾病傳播|
### 可修改面積單位問題 (MAUP)
|方面|問題 |
|--------|---------|
| **規模經濟** |結果會根據分析單位的大小而變化（人口普查區、縣、州）|
| **分區效應** |結果會根據邊界的繪製方式而變化，即使比例相同 |
| **意義** |切勿假設一個聚合層級的結果適用於另一個聚合層級；總是測試對邊界的敏感度|

## 實際考慮
|關注|指導|
|---------|----------|
| **座標參考系統** |經常檢查 CRS；切勿在計算中混合預測；在計算距離之前進行變換 |
| **精確** |浮點精度在小規模下很重要；使用適當的資料類型 |
| **性能** |空間操作成本高；使用空間索引；簡化顯示幾何形狀|
| **拓樸** |分析前確保幾何形狀有效（無自相交、閉合多邊形）|
| **規模** | Web 墨卡托扭曲面積；不要用它來計算面積 |
| **資料品質** |檢查空白幾何圖形、重複頂點、長條多邊形 |
---

＃＃ 概括
地理空間分析將位置資料轉化為可操作的見解。點、線和多邊形代表現實世界的實體。空間操作——距離、緩衝區、交叉、連接——回答有關鄰近、重疊和包含的問題。工具範圍廣泛，從用於資料庫規模分析的 PostGIS、用於 Python 工作流程的 GeoPandas 到用於 Web 視覺化的 Deck.gl。關鍵挑戰是選擇正確的座標系、管理大型資料集的效能以及了解 MAUP——您選擇的聚合邊界會影響您的結果。無論您是優化配送路線、分析疾病傳播還是繪製城市成長圖，地理空間分析都可以提供純數字無法捕捉的空間背景。
