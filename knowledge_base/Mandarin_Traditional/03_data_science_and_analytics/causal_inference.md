# 因果推理
因果推理是一門確定一件事是否確實導致另一件事的科學，而不僅僅是它們是否相關。相關性告訴您兩個變數一起移動。因果關係告訴你，改變一個就會改變另一個。這種區別在醫學（這種藥物有效嗎？）、政策（這種幹預措施是否減少貧窮？）、商業（這種廣告活動是否增加銷售量？）和科學（這種機制是否解釋了這種現象？）非常重要。
---

## 相關性與因果性
|概念 |描述 |範例|
|---------|-------------|---------|
| **相關性** |兩個變數一起移動 |夏季冰淇淋銷售和溺水死亡人數雙雙增加
| **因果關係** |一個變數直接影響另一個變數 |吸菸導致肺癌|
| **混淆** |第三個變數導致兩者 |炎熱的天氣導致冰淇淋銷售和游泳（和溺水）|
| **反向因果關係** |結果實際上導致了假定的原因 |人們購買保健品是因為生病了，而不是相反 |
| **虛假相關性** |巧合的關係|人均乳酪消費量與床單纏繞死亡有關

## 潛在成果框架
### 魯賓因果模型
|概念 |描述 |
|---------|-------------|
| **潛在結果** |對於每個單元，如果處理 Y(1) 則有一個結果，如果未處理 Y(0) | 則有一個結果
| **治療效果** |區別：給定單位的 Y(1) - Y(0) |
| **根本問題** |對於同一個單元，我們永遠無法同時觀察到 Y(1) 和 Y(0) — 我們只能看到一個 |
| **平均治療效果 (ATE)** |群體中個別治療效果的平均值|
| **反事實** |未觀察到的結果－在其他條件下會發生什麼事|
### 關鍵假設
|假設|意義|如何滿足|
|------------|--------------------|----------------|
| **可忽略性（無混淆性）** |鑑於觀察到的協變量，治療分配與潛在結果無關|隨機化；衡量所有混雜因素|
| **積極性（重疊）** |每個單位接受任一治療的機率均非零 |檢查組之間的協變量重疊 |
| **SUTVA**（穩定單位處理值假設）|一個單位的治療不會影響另一個單位的結果；治療一致|無幹擾；沒有隱藏版本的治療|
| **一致性** |觀察到的結果等於接受治療的潛在結果|明確的治療 |

## 因果推理方法
### 實驗方法
|方法|描述 |實力|限制|
|--------|-------------|----------|------------|
| **隨機對照試驗（RCT）** |隨機分配單位進行治療或對照 |黃金標準；消除混淆 |昂貴的;有時不道德；不可一概而論|
| **A/B 測驗** |商業/技術背景下的 RCT |簡單的;嚴謹|短期指標；新奇效果；幹擾|
| **折返實驗** |不同時間段的交替治療 |處理市場幹擾|需要穩定的環境 |
### 準實驗方法
|方法|描述 |关键假设|
|--------|-------------|----------------|
| **雙差分 (DiD)** |比較治療組和對照組隨時間的結果變化 |平行趨勢：在沒有治療的情況下，群體會遵循相同的軌跡|
| **迴歸不連續性 (RD)** |比較治療截止值上方和下方的單位 |接近截止值的單位具有可比性（如同隨機）|
| **工具變數 (IV)** |使用影響治療但不影響結果（除非透過治療）的變數 |儀器與治療相關；僅透過治療影響結果|
| **綜合控制** |建構控制單元的加權組合以符合處理單元 |綜合控制準確地代表了被處理單位的反事實 |
| **傾向分數配對** |將具有相似治療機率的治療組和對照組進行配對 |所有混雜因素均經過測量並包含在傾向模型中 |
### 雙重差異（視覺化）
|期間 |治療組|對照組|差異|
|--------|--------------|----------------|------------|
| **預處理** | Y_t_pre | Y_c_pre | Y_t_pre - Y_c_pre |
| **後處理** | Y_t_post | Y_c_post | Y_t_post - Y_c_post |
| **DiD 估計** | | | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) |

## 有向無環圖 (DAG)
DAG 是用於編碼因果假設和識別混雜因素的視覺化工具。
### 基本結構
|結構|圖案|寓意 |
|------------|---------|-------------|
| **鏈** | A → B → C | A和C經由B關聯；控制 B 會阻塞路徑 |
| **叉子** | A ← B → C | A 和 C 被 B 混淆；控制 B 會阻塞路徑 |
| **對撞機** | A → B ← C | A和C是獨立的；控制 B 開啟路徑（建立虛假關聯） |
### DAG 規則
|規則|描述 |
|------|-------------|
| **後門標準** |要估計 X 對 Y 的因果影響，請透過調節適當的變數來阻止所有後門路徑（帶有指向 X 的箭頭的路徑）|
| **前门标准** |如果无法阻止后门路径，请使用中介：分两个阶段估计 X → M → Y |
| **不要以碰撞器为条件** |控制共同效果会打开一条虚假路径|
| **不要以碰撞器的后代为条件** |与对撞机本身的调节有同样的问题|

## 常見陷阱
|陷阱|描述 |範例|
|---------|-------------|---------|
| **省略變數偏差** |未能控制混雜因素|估算教育程度 → 不控制能力的收入 |
| **過度控制** |調節中介者或對撞機 |在估算教育程度 → 收入時控制職稱 |
| **選擇偏差** |調節受治療影響的變數|研究訓練→工資時只分析就業人員|
| **不朽的時間偏差** |隊列研究中的人員時間錯誤分類患者必須存活足夠長的時間才能接受治療|
| **迴歸平均值** |極值往往會趨向平均值 |患者治療後病情好轉無論如何|
| **治療後偏差** |以治療後發生的變數為條件|評估藥物療效時控制不良事件|

＃＃ 概括
因果推理是超越「發生了什麼事」到「如果事情不同的話會發生什麼事」。根本的挑戰是我們永遠無法觀察到同一單位經過治療和未經治療的結果——反事實總是缺失。隨機實驗透過使治療組和對照組具有可比性來解決這個問題。當隨機化不可能時，準實驗方法——DiD、不連續性迴歸、工具變數、合成控制——嘗試從觀察資料重建反事實。 DAG 有助於明確假設並確定要控制的正確變數。關鍵技能是仔細思考資料生成過程：什麼導致什麼，什麼是混雜因素，什麼是碰撞，以及在替代方案下會發生什麼。
