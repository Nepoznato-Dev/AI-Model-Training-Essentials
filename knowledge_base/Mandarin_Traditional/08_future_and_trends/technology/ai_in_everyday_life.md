# 日常生活中的人工智慧
人工智能不再是一个未来概念——它已融入日常生活。從您醒來並檢查手機的那一刻（推薦演算法決定您看到的通知）到您入睡的那一刻（您的智慧揚聲器處理您的最後一個命令），人工智慧系統正在代表您、為您做出決定，有時甚至是關於您的決定。了解人工智慧出現在哪裡、它在基本層面上如何運作以及它的影響不再是可選的，而是 21 世紀知情公民的要求。

## 常見人工智慧系統如何運作
### 推薦系統
|組件|描述 |
|------------|-------------|
| **協同過濾** | 「喜歡 X 的使用者也喜歡 Y」—基於使用者或專案之間的相似性 |
| **基於內容的過濾** | 「您喜歡動作片，這裡有更多動作片」—基於項目功能 |
| **混合** |結合兩種方法；大多數真實的系統都是混合的|
| **探索與利用** |展示您可能喜歡的內容（利用）與介紹新內容（探索）|
### 搜尋引擎
|步驟|描述 |
|------|-------------|
| **爬行** |自動機器人（蜘蛛）造訪網頁並追蹤連結 |
| **索引** |頁面被分析並儲存在龐大的資料庫中 |
| **查詢處理** |您的搜尋字詞已被解析；意圖被推斷 |
| **排名** |數百個訊號決定順序：相關性；權威;新鮮;地點;個人化|
| **結果** |顯示熱門結果；可能包含廣告；知識面板；精選片段|
### 垃圾郵件過濾器
|技術|描述 |
|------------|-------------|
| **基於規則** |關鍵字；寄件者信譽；已知的垃圾郵件模式|
| **統計** |樸素貝葉斯分類器；鑑於其特徵，電子郵件是垃圾郵件的機率 |
| **機器學習** |從數十億封電子郵件中學習的深度學習模型 |
| **合奏** |多種方法的結合；持續更新|
### 詐欺偵測
|方面|描述 |
|--------|-------------|
| **实时计分** |每笔交易均以毫秒计分 |
| **特点** |数量;地点;时间;设备;商人;消费模式|
| **异常检测** |标记偏离用户正常模式的交易 |
| **误报** |关键挑战：阻止合法交易成本高昂且令人沮丧 |

|關注|描述 |範例|

## 人工智慧素養
### 每個人都應該知道什麼
|概念 |描述 |
|---------|-------------|
| **人工智慧是統計性的** |它從數據中學習模式；它不「理解」人類的意義|
| **人工智慧可能是錯誤的** |模型會犯錯；信心不等於準確|
| **人工智慧有偏見** |訓練資料反映了歷史偏差；模型可以放大它們|
| **人工智慧不是中立的** |設計選擇（優化什麼、使用什麼資料）嵌入值 |
| **人工智慧可以被操縱** |對抗性例子；及時注射；數據中毒|
| **人工智慧正在迅速發展** |去年不可能實現的功能今天可能已成為家常便飯 |
### 關於人工智慧系統的問題
|問題 |為什麼這很重要？
|----------|--------------|
| **這是根據什麼資料進行訓練的？ ** |確定模型知道什麼以及它可能有什麼偏差 |
| **它優化的目的是什麼？ ** |目標函數決定行為；目標不一致會導致問題|
| **故障模式有哪些？ ** |知道何時不信任人工智慧與知道何時信任它同樣重要 |
| **失敗時誰負責？ ** |責任必須明確，尤其是在高風險領域 |
| **我可以選擇退出嗎？ ** |並非所有人工智慧系統都給你選擇 |
| **這對我的隱私有何影響？ ** |許多人工智慧系統需要個人資料才能運作 |

＃＃ 概括
人工智慧不再是科幻小說——它是基礎設施。推薦演算法塑造您觀看、閱讀和購買的內容。搜尋引擎決定您找到什麼資訊。垃圾郵件過濾器和詐欺偵測可保護您免受威脅。醫療AI輔助診斷。導航應用程式優化您的通勤。但這些系統也引發了有關隱私、監視、偏見和自主性的基本問題。注意力經濟利用人工智慧來最大限度地提高參與度，但往往以心理健康和民主話語為代價。人工智慧素養——了解這些系統如何運作、它們的局限性及其影響——正變得像十年前的數位素養一樣重要。關鍵不是要害怕人工智慧或崇拜它，而是要充分了解它，以便明智地使用它，適當地質疑它，並要求部署它的人承擔責任。
