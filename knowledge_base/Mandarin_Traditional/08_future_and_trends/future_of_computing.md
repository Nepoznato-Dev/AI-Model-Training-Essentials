# 計算的未來
挑戰過去 60 年基本假設的力量正在塑造計算的未來。摩爾定律——計算能力大約每兩年翻一番——正在放緩。馮·諾依曼架構——獨立的 CPU 和記憶體——正在撞上「記憶體牆」。量子計算有望解決經典計算機無法解決的問題。神經形態晶片模仿大腦的結構。邊緣運算使處理遠離集中式資料中心。人工智慧正在改變電腦的用途——從執行指令的工具到學習、生成和推理的系統。了解這些轉變對於任何建造、購買或依賴技術的人都很重要。
---

## 摩爾定律的終結
＃＃＃ 發生了什麼
|時代|晶體管尺寸|趨勢 |
|-----|----------------|--------|
| **1970 年代–2000 年代** | 10,000 奈米 → 130 奈米 |指數增長；性能每約 2 年翻倍 |
| **2000 年代–2010 年代** | 130 奈米 → 22 奈米 |增長持續，但功率密度成為問題|
| **2010 年代–2020 年代** | 22 奈米 → 3 奈米 |減速；每個節點的成本更高；福利減少|
| **2020 年代+** | 3 奈米 → 亞 1 奈米 |接近原子極限；量子效應干涉|
### 為什麼它很重要
|後果|描述 |
|-------------|-------------|
| **性能提升緩慢** |不能依靠更小的電晶體來免費提高性能 |
| **專業化** |通用 CPU 讓位給特定領域加速器（GPU、TPU、NPU）|
| **軟體效率很重要** |無法對硬體進行暴力破解；演算法和程式碼品質變得更重要 |
| **需要新架構** |馮諾依曼瓶頸；記憶牆；電源牆|

## 量子計算
### 基礎知識
|概念 |描述 |
|---------|-------------|
| **量子位元** |量子位元；可以是 0、1 或兩者的疊加 |
| **疊加** |一個量子位元同時存在於多種狀態，直到測量為止 |
| **糾纏** |兩個量子位元變得相關；測量其中一個即可立即確定另一個|
| **幹擾** |量子演算法放大正確答案並消除錯誤答案 |
| **退相干** |量子位元透過與環境的互動而失去量子特性；主要的工程挑戰|
### 量子與經典
|方面|古典|量子|
|--------|------------|---------|
| **基本單位** |位元（0 或 1）|量子位元（0 和 1 的疊加）|
| **運作** |邏輯閘（AND、OR、NOT）|量子閘（Hadamard、CNOT 等）|
| **並行性** |一次進行一項計算（或許多獨立的計算） |疊加可以同時探索多種可能性 |
| **縮放** | n 位元 = n 個值 | n 個量子位元 = 2^n 個疊加值 |
| **錯誤率** |非常低|目前處於高位；需要糾錯|
### 量子擅長的應用
|應用 |為什麼量子有幫助？時間軸 |
|------------|--------------------|----------|
| **密碼學** | Shor演算法可破解RSA加密 |威脅目前的加密；後量子密碼學正在開發|
| **藥物發現** |模擬量子層次的分子交互作用| 5-15 年產生實際影響 |
| **優化** |在廣闊的搜尋空間中尋找最佳解決方案 |後勤;金融;材料科學|
| **機器學習** |某些機器學習演算法的量子加速 |早期研究；實際優勢尚不清楚|
| **材料科學** |在原子層級模擬新材料|電池材料；催化劑；超導體|
### 目前狀態
|公司/專案 |方法|量子位元 |狀態 |
|--------------------|----------|--------|--------|
| **IBM** |超導| 1,000+ |禿鷹處理器；量子優勢尚未在實際問題中得到證明
| **Google** |超導| 70+ |梧桐；聲稱針對特定任務的量子霸權（2019）|
| **離子Q** |被捕獲的離子| 30+（高保真）|精度高；較慢的門速度|
| **量子** |被捕獲的離子| 50+ |合併霍尼韋爾 + 劍橋量子 |
| **PsiQuantum** |光子|未公開 |目標是 100 萬個量子位元 |
| **微軟** |拓樸|研究階段|理論上最不易出錯；最難建造|

## 邊緣運算
### 為什麼是邊緣？
|司機 |說明 |
|--------|-------------|
| **延遲** |本地處理資料避免往返雲端 |
| **頻寬** |並非所有資料都需要傳送到雲端（例如來自安全攝影機的視訊）|
| **隱私權** |敏感資料保留在裝置上 |
| **可靠性** |在連接間歇性時工作 |
| **成本** |降低雲端運算與資料傳輸成本 |
### 邊緣運算頻譜
|地點 |延遲 |使用案例|
|----------|---------|----------|
| **設備上**（電話、物聯網）| <1 毫秒 |語音辨識；相機處理|
| **近邊緣**（網關、基地台）| 1–10 毫秒 |工業控制；自動駕駛汽車|
| **遠端**（區域資料中心）| 10–50 毫秒 |內容傳遞；遊戲 |
| **雲端**（中央資料中心）| 50–200 毫秒 |訓練;批次；分析|

## 人工智慧硬體
### AI 加速器的類型
|硬體|實力|弱點|範例|
|----------|----------|----------|------|
| **GPU** |大規模並行；有利於訓練與推理 |耗電；通用 |英偉達 H100； AMD MI300 | AMD MI300
| **TPU**（張量處理單元）|專為張量運算設計；高效|不如 GPU 靈活 |Google TPU v5 |
| **NPU**（神經處理單元）|裝置端人工智慧推理；節能 |僅限於推理；較小的型號|蘋果神經引擎；高通六邊形 |
| **FPGA** |可重新配置；低延遲 |更難編程；較小的生態系統|英特爾Agilex；賽靈思 Versal |
| **專用積體電路** |專為特定人工智慧工作負載客製化設計 |設計成本昂貴；不靈活|Google TPU（也是 ASIC）；大腦 |
| **晶圓級** |整個晶圓就是一顆晶片；大規模並行|小說;昂貴|大腦 WSE-3 |
### 記憶牆
|問題 |說明 |解決方案 |
|--------|-------------|------------|
| **馮諾依曼瓶頸** |資料必須在CPU與記憶體之間移動；這種傳輸比計算慢 |近記憶體計算；記憶體處理|
| **記憶體頻寬** | AI模型需要讀取數十億個參數；記憶體無法足夠快地提供資料|高頻寬記憶體（HBM）；壓縮|
| **記憶體容量** |大型模型不適合快速記憶體 |模型並行性；卸載到較慢的儲存|

|技術 |描述 |潛力|
|------------|-------------|------------|
| **光子計算** |使用光代替電進行計算 |快點;功率較低；小型化的挑戰|

| **生物計算** |使用活細胞進行計算 |可程式生物學；醫療應用 |

＃＃ 概括
計算的未來並不是過去的簡單延續。摩爾定律正在放緩，迫使人們從通用處理器轉向專用加速器。量子運算有望為特定問題（密碼學、藥物發現、材料科學）帶來指數級的加速，但實用的、糾錯的量子電腦還需要數年時間。神經形態晶片模仿大腦的架構，實現節能邊緣人工智慧。邊緣運算使處理過程更接近資料來源，以降低延遲並提高隱私性。 AI 硬體正在多樣化——GPU、TPU、NPU、FPGA 和客製化 ASIC 各自滿足不同的需求。記憶體牆（處理器速度和記憶體頻寬之間的差距）是推動近記憶體運算創新的基本瓶頸。後矽技術（光子學、自旋電子學、奈米碳管）正在研究中，但可能在幾十年後重塑計算。整體主題是專業化：一刀切的運算時代正在結束，取而代之的是針對特定工作負載最佳化的異質系統。
