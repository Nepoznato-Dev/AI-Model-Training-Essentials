## 貢獻和元數據
此知識庫中的每個內容檔案（除此`README.md`之外的所有內容）都以 YAML frontmatter 區塊開啟。它遵循[skills](../../skills/skill-creator.md)使用的相同貢獻者追蹤模式，因此作者身份、編輯和評論在兩個集合中保持可追溯。對於一般貢獻工作流程（分叉、分支、拉取請求、檔案放置和命名約定），請參閱根[CONTRIBUTING.md](../../CONTRIBUTING.md)。
### Frontmatter 架構
每個檔案都以此區塊開始（在`---`分隔符號之間），分為五個註解部分：
```yaml
---
# Metadata
title: "Python"            # the file's H1 heading
description: "..."          # one-line summary (see field table below)
category: "Coding and Technology"
version: "1.0.0"
status: "active"            # active | draft | deprecated | archived

# Contribution
authors:
  - name: "AI Model Training Team"
    email: ""
    role: "original_author"  # original_author | contributor | maintainer | reviewer
contributors: []
changelog:
  - version: "1.0.0"
    date: "2026-08-05"
    author: "AI Model Training Team"
    changes: "Added YAML frontmatter metadata for contributor tracking"

# Review
created: "2026-08-05"
last_modified: "2026-08-05"
review_date: "2027-02-05"
reviewed_by: "Coding & Technology Knowledge Base Team"
next_review: "2027-08-05"

# Classification
tags: [python, programming-language, syntax, ecosystem, coding-and-technology]
difficulty_level: "intermediate"   # beginner | intermediate | advanced
prerequisites: []
estimated_reading_time: "58 min"

# Contribution Guide
contribution:
  license: "MIT"
  feedback_channel: "GitHub Issues"
  how_to_contribute: "Submit a PR with changes and update the changelog"
  review_process: "Changes are reviewed by category maintainers before merge"
---
```

|領域 |來源/目的|
|---|---|
|`title`|從文件的第一個`#`標題中提取 |
|`description`|一行摘要；主題文件重用本自述文件索引中的條目，程式語言檔案使用產生的描述 |
|`category`/`reviewed_by`|源自父目錄（`01_coding_and_technology`→“編碼與技術”/“編碼與技術知識庫團隊”）|
|`version`|語意版本；每次編輯都會出現碰撞（見下文）|
|`authors`/`contributors`|原作者以及此後編輯過該文件的任何人 |
|`changelog`|僅附加更改列表，最新的在前 |
|`review_date`/`next_review`| 〜6 個月和〜1 年的節奏，反映了技能審查時間表 |
|`tags`|檔名標記加上乾淨的類別關鍵字（例如`coding-and-technology`）|
|`difficulty_level`|按類別設置，並按語言覆蓋（例如 Haskell/Assembly →`advanced`、Scratch →`beginner`）|
|`estimated_reading_time`|依行數計算 |
### 編輯文件
當您變更知識庫檔案時，請保持其 frontmatter 同步：
1. **凹凸`version`** 以下[SemVer](https://semver.org/)：
   - 補丁（`1.0.x`）：拼字錯誤、格式、細微修正
   - 次要 (`1.x.0`)：新部分、擴充內容、新範例
   - 主要 (`x.0.0`): 完全重寫或重組
2. **新增變更日誌條目**（最新的在前）描述您所做的變更：   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **將`last_modified`** 更新為更改日期
4. **如果這是您第一次編輯該文件，請將自己加入`contributors`**：   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
