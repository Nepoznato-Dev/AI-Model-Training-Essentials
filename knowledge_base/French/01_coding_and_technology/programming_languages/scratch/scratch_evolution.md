# Scratch — Historique et évolution des versions
## Chronologie
| Version | Année | Thème clé |
|---------|------|-----------|
| Pré-Scratch | 2003 | Formulaires de l'équipe Scratch au MIT Media Lab |
| Rayure 1.0 | 2007 | **Version initiale** — programmation visuelle pour les enfants |
| Rayure 1.4 | 2009 | Graphiques améliorés, plus de blocs |
| Grattez 2.0 | 2013 | **Majeur** : éditeur Web, variables cloud, sac à dos |
| Grattez 3.0 | 2019 | **Majeur** : Réécriture complète (HTML5/JS), extensions, stylet |
| Grattez 3.x | 2019-25 | Détection vidéo, synthèse vocale, traduction, micro:bit |
| Scratch Jr. | 2014 | Version simplifiée pour les plus jeunes (5-7 ans) |
| Bureau à gratter | 2020 | Éditeur hors ligne (basé sur Electron) |
## Étapes majeures
### Origines (2003-2006)
- **2003** : Le groupe Lifelong Kindergarten du MIT Media Lab commence le développement de Scratch
- Dirigé par Mitchel Resnick
- **Objectif** : Enseigner la programmation aux enfants à travers des blocs visuels
- Inspiré par : Logo (Seymour Papert), Logo Lego, Squeak Etoys
- Nom : "Scratch" – du DJ scratching (mélange de médias ensemble)
### Rayure 1.0 (2007)
- **2007** : Première sortie publique
- Programmation de blocs par glisser-déposer
- Projets basés sur des sprites (personnages, animations)
- Son, graphisme, animation
- Squeak intégré (Smalltalk)
- **Cible** : 8 à 16 ans, mais adopté beaucoup plus largement
### Rayure 1.4 (2009)
- Rendu graphique amélioré
- Plus de bibliothèques de sprites
- Meilleur support sonore
- Dernière version construite sur Squeak
### Scratch 2.0 (2013)
- **Éditeur Web complet** — s'exécute dans le navigateur
- Variables cloud - partagez des données entre projets
- Sac à dos - partagez des sprites/scripts entre projets
- Blocs personnalisés (comme les fonctions)
- Construit en ActionScript 3 (Flash)
- Fonctionnalités communautaires : remixer, partager, commenter
### Scratch 3.0 (2019)
- **Réécriture complète** — HTML5/JavaScript (pas de Flash)
- Fonctionne sur tablettes, téléphones, Chromebooks
- **Extensions** :
  - Stylo (dessin)
  - Détection vidéo (caméra)
  - Synthèse vocale
  - Traduire (Google Traduction)
  - micro:bit (matériel)
  - LEGO Mindstorms EV3
  -WeDo 2.0
- Améliorations de l'éditeur de son
- Nouvel éditeur de peinture (vecteur + bitmap)
- Sac à dos, variables cloud conservées
### Scratch Desktop et au-delà (2020-présent)
- **2020** : Scratch Desktop — éditeur hors ligne (basé sur Electron)
- Poursuite du développement des extensions
- Extensions AI/ML (créées par la communauté)
- Intégration avec l'informatique physique (micro:bit, Arduino)
## Évolution des catégories de blocs
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Concepts de programmation enseignés
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Principes de conception clés
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Impact et adoption
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
