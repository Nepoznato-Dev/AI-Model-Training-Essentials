# MATLAB — Erreurs courantes et anti-modèles
Ce document répertorie les erreurs, pièges et anti-modèles les plus courants dans MATLAB avec des corrections.
---

## 1. Développer des tableaux en boucles
```matlab
% ❌ WRONG — O(n²) reallocation
result = [];
for i = 1:10000
    result(end+1) = i^2;
end

% ✅ CORRECT — pre-allocate
result = zeros(1, 10000);
for i = 1:10000
    result(i) = i^2;
end

% ✅ BEST — vectorize
result = (1:10000).^2;
```

---

## 2.`*`vs`.*`(Matrice vs Élément)
```matlab
% ❌ WRONG — matrix multiplication when element-wise intended
A = [1 2; 3 4];
B = [5 6; 7 8];
C = A * B;   % matrix product, not [5 12; 21 32]

% ✅ CORRECT — element-wise operations
C = A .* B;  % [5 12; 21 32]
C = A .^ 2;  % element-wise power
C = A ./ B;  % element-wise division
```

---

## 3. Utilisation de`i`et`j`comme variables
```matlab
% ❌ WRONG — overwrites imaginary unit
i = 5;
z = 3 + 4*i;  % z = 3 + 20i, not 3 + 4i!

% ✅ CORRECT — use different variable names
idx = 5;
z = 3 + 4i;  % or 3 + 4*1i
```

---

## 4. Ne pas comprendre`find`par rapport à l'indexation logique
```matlab
% ❌ WRONG — using find unnecessarily
indices = find(A > 5);
values = A(indices);

% ✅ CORRECT — logical indexing (faster, cleaner)
values = A(A > 5);
```

---

## 5. Fonctions d'observation intégrées
```matlab
% ❌ WRONG — naming variable after built-in
max = 100;   % now max() function is broken!
min = 0;     % now min() function is broken!

% ✅ CORRECT — use different names
maxVal = 100;
minVal = 0;
```

---

## 6. Ne pas utiliser`fprintf`pour la sortie
```matlab
% ❌ WRONG — disp with string concatenation
disp(['Result: ' num2str(x)]);

% ✅ CORRECT — fprintf
fprintf('Result: %.4f\n', x);
```

---

## Résumé
La conception centrée sur la matrice de MATLAB crée des pièges :`*`est une multiplication matricielle (utilisez`.*`pour les éléments), la croissance des tableaux en boucles est lente (pré-allocation ou vectorisation),`i`/`j`sont des unités imaginaires (ne pas écraser) et l'indexation logique est plus rapide que`find`. La méthode MATLAB est la suivante : tout vectoriser, pré-allouer, utiliser l'indexation logique et ne jamais masquer les fonctions intégrées.
