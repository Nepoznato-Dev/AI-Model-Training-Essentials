# Knowledge Base

Welcome to the AI Engineering Knowledge Base! This repository contains comprehensive guides, skills documentation, and project templates for building AI systems.

## 📚 Overview

This knowledge base is organized into several key sections:

### Guides (`/guides`)
In-depth technical guides on specific AI/ML topics:
- **CNNs** - Convolutional Neural Networks for computer vision
- **GANs** - Generative Adversarial Networks for synthetic data generation
- **GNNs** - Graph Neural Networks for graph-structured data
- **Agentic Systems** - Building autonomous AI agents
- **Transformers** - Attention-based architectures
- **MoE** - Mixture of Experts models
- **RAG** - Retrieval-Augmented Generation systems
- **Orchestration Patterns** - Design patterns for AI systems
- **Infrastructure Layers** - Infrastructure considerations for AI

### Skills (`/skills`)
Practical skill development resources organized by category:
- **Technical Skills** - Core programming and ML engineering
- **Data Skills** - Data analysis, database design, and management
- **Security Skills** - Secure coding practices for AI systems
- **Management Skills** - Project and team management
- **DevOps Skills** - Deployment, monitoring, and operations
- **Research Skills** - Research methodology and literature review
- **Collaboration Skills** - Teamwork and communication
- **Design Skills** - System and architecture design
- **Testing Skills** - Testing strategies for AI systems
- **Behavior Skills** - Professional behavior and ethics
- **Speaking Skills** - Presentation and communication
- **Writing Skills** - Technical writing and documentation

### Agent Modes (`/agent_modes`)
Documentation for different AI agent operational modes:
- **Ask.Agent** - Question-answering mode
- **Chat.Agent** - Conversational mode
- **Plan.Agent** - Planning and strategy mode
- **Explore.Agent** - Research and exploration mode
- **Debug.Agent** - Troubleshooting mode
- **Review.Agent** - Code review mode
- **Test.Agent** - Testing mode
- **Secure.Agent** - Security-focused mode
- **Agent.Agent** - Meta-agent coordination

### Projects (`/guides/projects`)
Runnable code examples and project templates:
- **RAG Chatbot** - Complete RAG-based chatbot implementation
- **RAG Simple** - Minimal RAG example for learning

## 🚀 Getting Started

1. **Choose your path**: Start with the [progression map](guides/progression_map.md) to understand the learning journey
2. **Pick a topic**: Browse the guides directory for in-depth technical content
3. **Build skills**: Work through relevant skill categories based on your goals
4. **Run projects**: Clone and run the example projects to see concepts in action

## 📖 How to Use This Repository

### For Learning
- Follow the progression maps to build foundational knowledge
- Read guides in sequence (Chapter 1 → Chapter 2 → etc.)
- Complete hands-on projects to reinforce learning

### For Reference
- Search for specific topics using GitHub's search
- Check the error guides for common troubleshooting
- Review skill documentation for best practices

### For Building
- Use project templates as starting points
- Adapt code examples to your use case
- Follow security and DevOps guidelines for production

## 🔧 Prerequisites

- Familiarity with machine learning concepts
