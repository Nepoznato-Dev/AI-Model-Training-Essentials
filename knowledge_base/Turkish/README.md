### Dosyayı Düzenleme
Bir bilgi tabanı dosyasını değiştirdiğinizde ön maddesini senkronize tutun:
1. **`version`'yi ** [SemVer](https://semver.org/)'ye göre artırın:
   - Yama (`1.0.x`): yazım hataları, biçimlendirme, küçük düzeltmeler
   - Küçük (`1.x.0`): yeni bölümler, genişletilmiş içerik, yeni örnekler
   - Büyük (`x.0.0`): yeniden yazma veya yeniden yapılandırmayı tamamlayın
2. **Neyi değiştirdiğinizi açıklayan bir değişiklik günlüğü girişi ekleyin** (önce en yenisi):   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **`last_modified`**'yi değişiklik tarihinize güncelleyin
4. **Eğer dosyada ilk düzenlemenizse kendinizi `contributors`'ye ekleyin **:   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
