## 📝 Katkıda Bulunma

İçerik eklerken veya değiştirirken:

1. **Stil rehberine uyun:**
   - Yalnızca dosya başlığı için `#` kullanın
   - Ana bölümler için `##` kullanın
   - Alt bölümler için `###` kullanın
   - Sırasız listeler için `-` kullanın
   - Kod bloklarında sözdizimi vurgulaması ekleyin

2. **Meta veri ekleyin** (YAML frontmatter):
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Olgusal iddialar için kaynak ekleyin**
4. **İlgili dosyalara çapraz başvuru ekleyin**
5. **Yeni dosyalar ekliyorsanız bu README'yi güncelleyin**
