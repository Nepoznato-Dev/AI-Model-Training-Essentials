# Scratch — Sürüm Geçmişi ve Gelişimi
## Zaman Çizelgesi
| Sürüm | Yıl | Anahtar Tema |
|-----------|----------|-----------|
| Çizilme Öncesi | 2003 | Scratch Takımı MIT Medya Laboratuarında Oluşturuldu |
| Çizik 1.0 | 2007 | **İlk sürüm** — çocuklar için görsel programlama |
| Çizik 1.4 | 2009 | Geliştirilmiş grafikler, daha fazla blok |
| Çizik 2.0 | 2013 | **Binbaşı**: Web tabanlı düzenleyici, bulut değişkenleri, sırt çantası |
| Çizik 3.0 | 2019 | **Ana**: Tam yeniden yazma (HTML5/JS), uzantılar, kalem |
| Çizik 3.x | 2019–25 | Video algılama, metinden konuşmaya, çeviri, mikro:bit |
| Scratch Jr. | 2014 | Küçük çocuklar için basitleştirilmiş versiyon (5-7) |
| Masaüstünü Çiz | 2020 | Çevrimdışı düzenleyici (Elektron tabanlı) |
## Önemli Kilometre Taşları
### Kökenler (2003–2006)
- **2003**: MIT Media Lab'in Hayat Boyu Anaokulu grubu Scratch'i geliştirmeye başladı
- Mitchel Resnick liderliğinde
- **Hedef**: Çocuklara görsel bloklarla programlamayı öğretmek
- İlham veren: Logo (Seymour Papert), Lego Logosu, Squeak Etoys
- İsim: "Scratch" — DJ'in çiziktirmesinden (medyanın birlikte karıştırılması)
### Çizik 1.0 (2007)
- **2007**: İlk halka açık yayın
- Sürükle ve bırak blok programlama
- Sprite tabanlı projeler (karakterler, animasyonlar)
- Ses, grafik, animasyon
- Dahili Squeak (Smalltalk)
- **Hedef**: 8-16 yaş arası, ancak çok daha geniş çapta benimsendi
### Çizik 1.4 (2009)
- Geliştirilmiş grafik oluşturma
- Daha fazla sprite kütüphanesi
- Daha iyi ses desteği
- Squeak üzerine kurulu son sürüm
### Çizik 2.0 (2013)
- **Tam web tabanlı düzenleyici** — tarayıcıda çalışır
- Bulut değişkenleri — projeler arasında veri paylaşımı
- Sırt Çantası — projeler arasında spriteları/senaryoları paylaşın
- Özel bloklar (işlevler gibi)
- Dahili ActionScript 3 (Flash)
- Topluluk özellikleri: remiksleme, paylaşma, yorum yapma
### Çizik 3.0 (2019)
- **Tamamen yeniden yazma** — HTML5/JavaScript (Flash yok)
- Tabletlerde, telefonlarda ve Chromebook'larda çalışır
- **Uzantılar**:
  - Kalem (çizim)
  - Video Algılama (kamera)
  - Metinden Konuşmaya
  - Çevir (Google Çeviri)
  - mikro:bit (donanım)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Ses düzenleyici iyileştirmeleri
- Yeni boya düzenleyici (vektör + bitmap)
- Sırt çantası, bulut değişkenleri korundu
### Scratch Masaüstü ve Ötesi (2020-günümüz)
- **2020**: Scratch Desktop — çevrimdışı düzenleyici (Electron tabanlı)
- Devam eden uzantı geliştirme
- AI/ML uzantıları (topluluk tarafından oluşturulan)
- Fiziksel hesaplamayla entegrasyon (mikro:bit, Arduino)
## Blok Kategorileri Gelişimi
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Öğretilen Programlama Kavramları
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Temel Tasarım İlkeleri
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Etki ve Benimseme
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
