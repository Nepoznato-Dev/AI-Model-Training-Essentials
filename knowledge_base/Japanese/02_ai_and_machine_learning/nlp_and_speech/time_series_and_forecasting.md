# 時系列と予測
時系列データとは、株価、気温測定値、Web サイトのトラフィック、売上高、心拍数モニター、エネルギー消費など、時間の経過とともに収集されるあらゆるデータです。予測とは、過去のパターンに基づいて将来の値を予測することを意味します。これは、データ サイエンスの実用的に最も価値のあるアプリケーションの 1 つであり、また最も困難なものの 1 つです。なぜなら、将来はまったく不確実であり、現実世界の時系列にはノイズ、季節性、構造上の欠陥がたくさんあるからです。
---

## 時系列の特徴
|コンポーネント |説明 |例 |
|----------|---------------|----------|
| **トレンド** |長期的な増減 |地球の気温は数十年にわたって上昇 |
| **季節性** |一定間隔での規則的で予測可能なパターン |毎年 12 月に小売売上高が急増 |
| **循環性** |不定間隔での変動（多くの場合経済的） | 5 ～ 10 年ごとに景気後退が起こる |
| **ノイズ (残留)** |説明できないランダムな変動 |日々の株価の動き |
| **自己相関** |現在の値は過去の値に依存します |今日の気温は昨日と同じです |
### 定常性
統計的特性 (平均、分散) が時間の経過とともに変化しない場合、時系列は **定常** です。ほとんどの予測方法は定常性を前提としています。
|テスト |目的 |
|-----|----------|
| **拡張ディッキーフラー (ADF)** |単位根が存在するかどうかをテストします (非定常) |
| **KPSS テスト** |シリーズの傾向が定常であるかどうかをテストします。
|変換 |いつ使用するか |
|--------------|---------------|
| **差異** |トレンドの削除: y'(t) = y(t) - y(t-1) |
| **ログ変換** |分散を安定化する (指数関数的な増加に対応) |
| **季節の違い** |季節性の削除: y'(t) = y(t) - y(t-s) ここで、s は季節の長さです。

## 古典的な予測方法
### 移動平均
|方法 |説明 |最適な用途 |
|----------|---------------|----------|
| **単純移動平均 (SMA)** |最後の N 個の観測値の平均 |ノイズの多いデータの平滑化 |
| **加重移動平均** |最近の観察ほど重要度が高くなります。最近のデータがより重要な場合 |
| **指数移動平均 (EMA)** |重みを指数関数的に減少させる |遅延を少なくして傾向を追跡 |
### 指数平滑法
|方法 |コンポーネント |使用例 |
|----------|-----------|----------|
| **シンプル (SES)** |レベルのみ |トレンドも季節性もありません |
| **ホルツ (ダブル)** |レベル+トレンド |傾向はあるが季節性がないデータ |
| **ホルト-ウィンターズ (トリプル)** |レベル + トレンド + 季節性 |トレンドと季節性の両方を備えたデータ |
### ARIMA とバリアント
ARIMA (AutoRegressive Integrated Moving Average) は、古典的な時系列予測の主力です。
|コンポーネント |意味 |パラメータ |
|----------|-----------|----------|
| **AR (p)** |以前の p 値の回帰 |過去の値をいくつ使用するか |
| **私 (d)** |定常状態にするための差分ステップの数 |何倍の差 |
| **MA (q)** |過去のエラーの組み合わせとしてエラーをモデル化します。過去のエラーをいくつ使用するか |
|バリアント |拡張子 |使用例 |
|----------|-----------|----------|
| **サリマ** |季節成分 (P、D、Q、s) を追加します。季節性の強いデータ |
| **アリマックス** |外部変数を追加します |今後のイベントについて知っているとき |
| **VAR** |多変量 ARIMA。複数の相互依存シリーズ |変数が相互に影響を与える場合 |

## 最新の ML アプローチ
### LSTM および RNN ベースのモデル
|モデル |建築 |利点 |
|----------|---------------|----------|
| **LSTM** |長短期記憶ネットワーク |長期にわたる一時的な依存関係をキャプチャ |
| **GRU** |ゲート付きリカレント ユニット (より単純な LSTM) |トレーニングの迅速化。同様のパフォーマンス |
| **Seq2Seq** |時系列のエンコーダ/デコーダ |柔軟な入出力長 |
| **時間畳み込みネットワーク (TCN)** |拡張因果畳み込み |並行トレーニング。長い受容野 |
### 預言者 (メタ)
ビジネス時系列向けに設計された実用的な予測ツールです。
|特集 |説明 |
|----------|---------------|
| **分解** |トレンド + 季節性 + 休日 |
| **柔軟** |欠損データ、外れ値、構造上の破損を処理 |
| **解釈可能** |コンポーネントは人間が判読できる |
| **自動** |合理的なデフォルト。最小限のチューニングが必要 |
|強さ |制限 |
|----------|-----------|
|ビジネス指標 (売上、ユーザー) に最適 |非常に高頻度のデータには理想的ではありません。
|休日や特別なイベントに対応 |加法的または乗法的な季節性を仮定します。
|外れ値に対して堅牢 |複雑なパターンでは深層学習よりも精度が劣る |
### トランスベースのモデル
|モデル |主な機能 |
|------|-----------|
| **情報者** |長いシーケンスに対する ProbSparse の注意 |
| **オートフォーマー** |級数分解のための自己相関メカニズム |
| **パッチTST** |時系列にパッチを適用します。チャンネルに依存しない |
| **TimesFM** (Google) |時系列の基礎モデル。多様なデータで事前トレーニング |
| **クロノス** (Amazon) |時系列をトークン化します。 LLM スタイルのアーキテクチャを使用 |

## 時系列での異常検出
予想される動作から逸脱する異常なパターンを検出します。
|方法 |アプローチ |使用例 |
|----------|----------|----------|
| **統計** | Zスコア、IQR、管理図 |シンプルでわかりやすい |
| **孤立の森** |ツリーベース。ランダムな分割により異常を隔離します。多変量異常検出 |
| **LOF** (局所外れ値係数) |密度ベース。ローカル密度を近隣密度と比較します。異常が低密度領域にある場合 |
| **オートエンコーダー** |再構築エラー。高いエラー = 異常 |複雑な非線形パターン |
| **LSTM ベース** |次のステップを予測します。大きな予測誤差 = 異常 |連続的な異常 |
### アプリケーション
|ドメイン |異常が意味するもの |
|--------|--------|
| **財務** |詐欺、市場暴落、フラッシュクラッシュ |
| **ヘルスケア** |異常な心拍数、発作の発症 |
| **製造** |設備故障、品質不良 |
| **サイバーセキュリティ** |侵入試行、DDoS 攻撃 |
| **インフラストラクチャ** |サーバーの過負荷、ネットワーク障害 |

## 評価指標
|メトリック |式（概念的） |いつ使用するか |
|----------|---------------------|---------------|
| **MAE** (平均絶対誤差) |絶対誤差の平均 |解釈可能;データと同じ単位 |
| **RMSE** (二乗平均平方根誤差) |平均二乗誤差の平方根 |大きなエラーにさらにペナルティを課す |
| **MAPE** (平均絶対パーセント誤差) |絶対パーセント誤差の平均 |相対誤差が重要な場合 |
| **SMAPE** (対称 MAPE) | MAPE の対称バージョン |ゼロに近い値をより適切に処理します。
| **MASE** (平均絶対スケール誤差) |単純な予測と比較した MAE |異なるシリーズ間の比較 |

## 実践的なワークフロー
|ステップ |説明 |
|------|---------------|
| **1.探索** |シリーズをプロットします。傾向、季節性、外れ値を特定する |
| **2.分解** |トレンド成分、季節成分、残差成分に分ける |
| **3.ステーショナライズ** |必要に応じて差分または変換を適用します。
| **4.分割** |時間ベースの分割 (時系列のランダムな分割はありません) |
| **5.ベースライン** |単純な予測 (最後の値、季節的な単純) から開始します。
| **6.モデル** |古典的な手法 (ARIMA、Prophet) を試してから、ML 手法を試してください。
| **7.評価** |適切な指標を使用します。ベースラインと比較 |
| **8.反復** |機能を追加し、さまざまなモデルを試し、ハイパーパラメーターを調整します。

＃＃ まとめ
時系列予測は、古典的な統計と最新の機械学習を組み合わせたものです。古典的な方法 (ARIMA、指数平滑法、Prophet) は解釈可能で高速で、多くの場合正確です。深層学習手法 (LSTM、Transformers) は複雑なパターンを捕捉しますが、より多くのデータと調整が必要です。どの方法であっても重要な原則は同じです。つまり、データの構造 (傾向、季節性、ノイズ) を理解し、単純なベースラインと比較し、適切な指標で評価し、将来が過去を正確に複製するわけではないという事実を考慮します。
