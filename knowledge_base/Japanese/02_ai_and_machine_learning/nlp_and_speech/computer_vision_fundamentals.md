# コンピュータービジョンの基礎
コンピューター ビジョンにより、機械は画像、ビデオ、3D データなど、世界からの視覚情報を解釈して理解できるようになります。携帯電話の顔認識から自動運転車、医療画像分析、産業品質管理に至るまで、あらゆるものに電力を供給します。このファイルには、中心となる概念、アーキテクチャ、およびテクニックが含まれています。
---

## コンピューターが画像を認識する仕組み
### ピクセルとチャネル
デジタル画像はピクセルのグリッドです。各ピクセルには色の強度を表す数値があります。
|画像の種類 |チャンネル |ピクセルごとの値 |例 |
|----------|----------|------|----------|
| **グレースケール** | 1 | 0（黒）～255（白） |医療用X線 |
| **RGB** | 3 |赤、緑、青 (各 0 ～ 255) |標準カラー写真 |
| **RGBA** | 4 | RGB + アルファ (透明度) |背景が透明な画像 |
| **HSV** | 3 |色相、彩度、明度 |色ベースのセグメンテーション |
1920×1080 RGB イメージは、形状`(1080, 1920, 3)`のテンソルです。つまり、620 万ピクセルで、それぞれに 3 つの値があります。
### キー操作
|操作 |説明 |
|----------|---------------|
| **サイズ変更** |画像をターゲット寸法にスケール変更 (双線形、最近傍補間) |
| **トリミング** |関心領域を抽出する |
| **正規化** |ニューラル ネットワークのピクセル値を [0,1] または [-1,1] にスケールします。
| **拡張** |トレーニング データを人為的に拡張 (回転、反転、カラー ジッター、クロップ) |
---

## 畳み込み: コア操作
畳み込みは、画像上で小さなフィルター (カーネル) をスライドさせ、各位置でドット積を計算します。これが、CNN がエッジ、テクスチャ、パターンを検出する方法です。
### 畳み込みパラメータ
|パラメータ |効果 |
|----------|----------|
| **カーネル サイズ** | 3×3、5×5、7×7 — より大きなカーネルはより大きなパターンをキャプチャします。
| **ストライド** |ステップサイズ。 stride=2 は出力次元を半分にします。
| **パディング** |境界線の周囲にゼロを追加して空間寸法を維持する |
| **フィルターの数** |各フィルターは異なる特徴 (エッジ、テクスチャ、カラー パターン) を学習します。
### 畳み込みが学ぶこと
|層の深さ |検出された特徴 |
|-----------|------|
| **初期のレイヤー** |エッジ、コーナー、シンプルなテクスチャ |
| **中間層** |形、オブジェクトパーツ（車輪、目、葉っぱ） |
| **深層** |高レベルのコンセプト (顔、車、動物) |

## CNN アーキテクチャ
CNN アーキテクチャの進化は、コンピューター ビジョンにおけるディープ ラーニングの進歩を物語っています。
|建築 |年 |主要なイノベーション |
|------------|------|---------------|
| **LeNet-5** | 1998年 |最初の実用的な CNN。数字認識 |
| **アレックスネット** | 2012年 | Deep CNN が ImageNet に勝利。 ReLU、ドロップアウト、GPU トレーニング |
| **VGGNet** | 2014年 |積み重ねられた 3×3 畳み込み (深い = 優れている) |
| **GoogLeNet (インセプション)** | 2014年 |インセプション モジュール (並列フィルター サイズ)。 22層 |
| **ResNet** | 2015年 |接続をスキップします (残留学習)。 152 以上のレイヤー |
| **EfficientNet** | 2019年 |複合スケーリング (深さ + 幅 + 解像度) |
| **ConvNext** | 2022年 |最新化された ResNet。トランスフォーマーと競合 |
### ResNet がすべてを変えた理由
ResNet が登場する前は、勾配消失の問題により、非常に深いネットワークをトレーニングすることはほぼ不可能でした。 ResNet は **スキップ接続** (残余接続とも呼ばれます) を導入しました。これは、レイヤーへの入力がその出力に追加されるものです。
```
output = F(x) + x    # Skip connection
```

このシンプルなアイデアにより、152 層以上のネットワークを効果的にトレーニングできるようになり、現在では事実上すべてのディープ アーキテクチャで標準となっています。

## コアビジョンタスク
### 画像の分類
画像全体にラベルを割り当てます。
|モデル |アプローチ |
|------|----------|
| CNN (ResNet、EfficientNet) |従来のアプローチ。優れた精度 |
|ビジョントランスフォーマー (ViT) |画像を一連のパッチとして扱います。トランスエンコーダ |
|転移学習 |データセット上で事前トレーニングされたモデルを微調整する |
### 物体検出
境界ボックスを使用して、画像内の複数のオブジェクトを検索して分類します。
|モデル |タイプ |スピード |
|------|------|------|
| **R-CNN** | 2段階（提案＋分類） |遅い |
| **高速 R-CNN** |改良された二段階 |中 |
| **高速な R-CNN** |地域提案ネットワーク＋検出器 |中 |
| **YOLO** (v1–v10) |シングルステージ。 1 回のパスでボックス + クラスを予測する |非常に速い |
| **DETR** |トランスベース。アンカーボックスなし |中 |
**YOLO** (You Only Look Once) はリアルタイム検出の頼りになります。 **速度よりも精度が重要な場合は、より高速な R-CNN** が推奨されます。
### 画像のセグメンテーション
画像内のすべてのピクセルを分類します。
|タイプ |説明 |使用例 |
|------|---------------|----------|
| **セマンティック セグメンテーション** |各ピクセルはクラス ラベルを取得します。自動運転（道路、自動車、歩行者） |
| **インスタンスのセグメンテーション** |各ピクセル + オブジェクト インスタンス ID |物体を数える、医用画像処理 |
| **パノプティックセグメンテーション** |セマンティック + インスタンスの組み合わせ |包括的なシーンの理解 |
主要なモデル: U-Net (医療画像)、Mask R-CNN (インスタンス)、DeepLab (セマンティック)、Segment Anything Model (SAM - ユニバーサル セグメンテーション)。
### 画像の生成
|アプローチ |説明 |例 |
|----------|---------------|----------|
| **GAN** |ジェネレーターとディスクリミネーターの敵対的トレーニング |スタイルGAN、CycleGAN |
| **VAE** |潜在的な分布を学びます。生成するサンプル |変分オートエンコーダ |
| **普及モデル** |ランダム ノイズを反復的にノイズ除去します。安定拡散、DALL-E、ミッドジャーニー |
拡散モデルは、画像生成の品質において GAN を大幅に上回っています。

## ビジョンのための転移学習
CNN をゼロからトレーニングするには、大量のデータとコンピューティングが必要です。転移学習を使用すると、数百万の画像 (ImageNet) ですでにトレーニングされたモデルから始めて、特定のタスクに合わせて微調整できます。
### ステップ
1. **事前トレーニングされたモデルを選択します** (ResNet50、EfficientNet-B0、ViT)。
2. **分類ヘッド**を独自の(クラス数に一致する)ものと交換します。
3. **初期レイヤーをフリーズ** (エッジなどの一般的な特徴をキャプチャします)。
4. 低い学習率でデータセットを **微調整**します。
5. さらに適応させる必要がある場合は、**徐々に解凍**してください。
このアプローチでは、わずか 1,000 ～ 10,000 枚のラベル付き画像で高い精度が日常的に達成されます。
---

## データ拡張
拡張では、変換を適用することでトレーニング データセットを人為的に拡張します。
|拡張 |効果 |いつ使用するか |
|---------------|--------|---------------|
| **ランダムクロップ** |ランダムな領域に切り取る |ほぼ常に |
| **水平反転** |鏡像 |向きが関係ない場合 |
| **回転** |ランダムな角度で回転 |オブジェクトが任意の角度で表示される場合 |
| **色のジッター** |明るさ、コントラスト、彩度をランダムに調整 |照明が変化するとき |
| **ランダム消去** |ランダムな領域をマスクする |堅牢性の向上 |
| **ミックスアップ / カットミックス** | 2 つの画像とラベルをブレンドする |正則化 |
ライブラリ:`torchvision.transforms`、`albumentations`、`imgaug`、`tf.keras.preprocessing`。

## 実践的なヒント
- **転移学習から始めます。** ほとんどの場合、事前トレーニングされたモデルを微調整する方が、最初からトレーニングするよりも優れています。
- **入力を正規化します。** 事前トレーニングされたモデルが期待する正規化 (通常は ImageNet 平均/標準) と一致します。
- **適切な指標を使用します。** バランスの取れたデータセットの精度。不均衡タスクまたは検出タスク用の F1、mAP、または IoU。
- **データを視覚化します。** サンプル イメージを確認し、クラス分布を確認し、モデルの予測を検査します。
- **賢明に拡張します。** ドメインにとって意味のある変換のみを適用してください (医療画像を垂直方向に反転しないでください)。
- **過学習を監視します。** トレーニングの精度は高いが検証が低い場合は、拡張を増やすか、ドロップアウトを追加します。
