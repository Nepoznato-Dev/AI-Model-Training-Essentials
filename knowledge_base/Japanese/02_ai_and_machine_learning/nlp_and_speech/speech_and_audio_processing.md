# 音声と音声の処理
音声とオーディオの処理には、機械が音を聞き、理解し、生成し、操作できるようにするテクノロジーが含まれます。これには、音声認識 (話し言葉をテキストに変換)、音声合成 (テキストを話し言葉に変換)、話者識別、音楽生成、および環境音の理解が含まれます。この分野はディープラーニングによって変革されました。最新のシステムは音声認識の精度が人間レベルに近づき、不気味なほど自然な合成音声を生成します。
---

## デジタルオーディオの基礎
音は圧力波です。デジタル処理するために、一定の間隔で波形をサンプリングします。
|コンセプト |説明 |代表値 |
|-------|-----------|---------------|
| **サンプルレート** |音は1秒間に何回測定されるか | 8 kHz (電話)、16 kHz (音声)、44.1 kHz (CD)、48 kHz (プロフェッショナル) |
| **ビット深度** |各サンプルの精度 | 16 ビット (CD)、24 ビット (プロフェッショナル)、32 ビット浮動小数点 (プロセッシング) |
| **チャンネル** |モノラル (1)、ステレオ (2)、サラウンド (5.1、7.1) |音楽用ステレオ。モノラル音声 |
| **期間** |音声の長さ |さまざま |
16 kHz、16 ビットでの 1 分間のモノラル録音 = 1.92 MB。 44.1 kHz、16 ビットの 3 分間のステレオ曲 = 30.3 MB。
---

## オーディオ特徴の抽出
生のオーディオ波形をモデルが直接扱うのは困難です。サウンドの重要な特徴を捉えた特徴を抽出します。
|特集 |何がキャプチャされるのか |使用例 |
|----------|------|----------|
| **メルスペクトログラム** |人間の聴覚知覚にマッピングされた、時間の経過に伴う周波数成分 |音声認識、音楽分類 |
| **MFCC** (メル周波数ケプストラム係数) |スペクトルエンベロープのコンパクトな表現 |従来の音声認識 |
| **クロマグラム** |ピッチクラスの分布 (どのノートが演奏されているか) |音楽分析、コード検出 |
| **ゼロクロス率** |信号がゼロと交差する頻度 |有声音と無声音の検出 |
| **RMS エネルギー** |時間の経過に伴う信号音量 |音声アクティビティの検出 |
| **ピッチ (F0)** |基本周波数 |話者の識別、音楽の転写 |
### メルスペクトログラム
ディープラーニングの最も一般的な音声表現。オーディオを 2D 画像のような形式に変換します。
|軸 | |を表します
|------|-----------|
| **X 軸** |時間 |
| **Y 軸** |周波数 (メルスケール上 - 知覚的間隔) |
| **色/強度** |その周波数と時間におけるエネルギー |
メル スケールは人間の聴覚に近似しています。つまり、私たちは高周波よりも低周波を区別するのが得意です。

## 自動音声認識 (ASR)
ASR は話し言葉をテキストに変換します。これは、オーディオ AI の商業的に最も重要なアプリケーションの 1 つです。
### ASR の進化
|時代 |アプローチ |制限 |
|-----|----------|---------------|
| **2010 年以前** |隠れマルコフ モデル + 混合ガウス モデル |広範囲にわたる手作業によるエンジニアリングが必要。騒音の多い環境では苦手です。
| **2010-2015** | DNN-HMM ハイブリッド |ニューラル ネットワークは GMM に取って代わりました。大幅な改善 |
| **2015-2020** |エンドツーエンド モデル (ディープ スピーチ、LAS) |音声からテキストまでの単一ニューラル ネットワーク |
| **2020+** |トランスベース (ウィスパー、コンフォーマー) |最先端の精度。多言語。堅牢 |
### 主要な ASR モデル
|モデル |建築 |トレーニングデータ |注目の機能 |
|------|-----------|---------------|------|
| **ささやき** (OpenAI) |エンコーダ/デコーダトランス | 680,000 時間、99 言語 |多言語対応。アクセントやノイズに強い。オープンソース |
| **適合者** |畳み込み + 自己注意 |いろいろ |ローカル (conv) 機能とグローバル (attention) 機能を組み合わせます。
| **wav2vec 2.0** |自己監視型変圧器 |ラベルのないスピーチ |文字起こしなしで生の音声から学習 |
| **USM** (Google) |普遍的な音声モデル | 200 万時間、300 以上の言語 |ほとんどの言語をカバー |
| **MMS** (メタ) |大規模な多言語によるスピーチ | 1,400 以上の言語 |対象範囲をリソースの少ない言語にまで拡大 |
### ASR メトリクス
|メトリック |説明 |
|----------|---------------|
| **WER** (単語誤り率) |誤って転写された単語の割合。低いほど良いです。人間のきれいな英語のパフォーマンスは最大 4 ～ 5% です。 |
| **CER** (文字エラー率) | WER と同じですが、キャラクターレベルです。単語境界のない言語 (中国語、日本語) に使用されます。 |
### ASR の一般的な課題
|チャレンジ |説明 |
|----------|---------------|
| **アクセントと方言** |非標準のアクセントではパフォーマンスが大幅に低下します。
| **バックグラウンドノイズ** |音楽、交通、その他のスピーカーによる精度の低下 |
| **コードスイッチング** |話者が文章の途中で言語を切り替える |
| **同音異義語** | 「そこ」対「彼ら」対「彼らは」 — コンテキストが必要 |
| **句読点と書式設定** |通常、ASR 出力には中断がありません。後処理が必要 |
| **低リソース言語** |ほとんどのモデルは、トレーニング データが少ない言語ではパフォーマンスが低下します。

## テキスト読み上げ (TTS)
TTS は、書かれたテキストを音声に変換します。最新のシステムは、多くの場合、人間の録音と区別できない音声を生成します。
### TTSの進化
|時代 |アプローチ |品質 |
|-----|----------|----------|
| **2010 年以前** |連結 (記録されたフラグメントをつなぎ合わせる) |ロボット;限られた表現力 |
| **2010-2017** |統計パラメトリック (HMM、初期のニューラル) |より優れていますが、それでも合成として認識できます |
| **2017-2020** |ニューラル (Tacotron、WaveNet) |人間に近い品質。表現力豊か |
| **2020+** |ニューラル コーデック (VALL-E、Bark) |音声のクローン作成。数発のショット。非常に自然 |
### 主要な TTS モデル
|モデル |建築 |注目の機能 |
|------|---------------|------|
| **WaveNet** (ディープマインド) |自己回帰生成モデル |初めての真に自然なサウンドの TTS |
| **タコトロン 2** (Google) | Seq2seq + ボコーダー |エンドツーエンド。高品質 |
| **ヴィッツ** |変分推論 + 敵対的トレーニング |速い;良質;広く使用されています |
| **VALL-E** (マイクロソフト) |ニューラル コーデック言語モデル | 3 秒のサンプルからの音声クローン |
| **バーク** (スノ) |トランスベース |多言語対応。音声以外の音（笑い声、音楽） |
| **イレブンラボ** |コマーシャル |業界をリードする音声クローン |
| **チャットTTS** |オープンソース |会話用に最適化 |
| **フィッシュスピーチ** |オープンソース |速い;多言語 |
### 音声クローン作成
音声クローン作成では、短い音声サンプルから特定の人物のように聞こえる合成音声を作成します。
|方法 |必要なデータ |品質 |
|----------|-----------|----------|
| **微調整** | 10～60分のスピーチ |高品質;スピーカー固有 |
| **数ショット** | 3 ～ 30 秒のスピーチ |良質;素早いセットアップ |
| **ゼロショット** |ターゲットスピーカーデータがありません |推論時に参照音声を使用する |
**倫理的懸念**: 音声クローンは、なりすまし、詐欺、ディープフェイクに使用される可能性があります。ほとんどの商用プロバイダーでは音声による同意が必要です。

## 実践的なヒント
- **常にデータを聞いてください。** 何かをトレーニングする前に、サンプル音声を聞いてください。サンプル レート、ノイズ レベル、スピーカーの特性に注目してください。
- **サンプル レートを一致させます。** Whisper は 16 kHz を想定しています。オーディオが 44.1 kHz の場合は、リサンプリングします。ただし、ダウンサンプリングでは情報が失われることに注意してください。
- **オーディオ データを拡張します。** バックグラウンド ノイズを追加し、速度とピッチを変更し、さまざまなマイクをシミュレートします。これにより堅牢性が飛躍的に向上します。
- **事前トレーニングされたモデルを使用します。** ASR の場合は Whisper、TTS の場合は VITS/Bark が優れた出発点となります。微調整は、ほとんどの場合、ゼロからトレーニングするよりも優れています。
- **無音を処理します。** 音声アクティビティ検出 (VAD) は、処理前に無音を除去し、計算量を節約し、精度を向上させます。 Silero VAD と WebRTC VAD が一般的な選択肢です。
- **音量を正規化します。** 録音が異なれば、音量レベルも大きく異なります。処理前に一貫したレベルに正規化します。

＃＃ まとめ
音声とオーディオの処理はディープラーニングによって革命を起こしました。 Whisper のような最新の ASR システムは、数十の言語にわたって人間レベルの精度に近づきます。 TTS システムが生成する音声は、人間の録音と区別できなくなりつつあります。音声クローンは数秒の音声から機能します。音楽の生成、音源の分離、環境音の検出はすべて急速に進歩しています。この分野は、リソースの少ない言語、騒がしい環境、音声クローン作成に関する倫理的懸念など、継続的な課題に直面していますが、その道筋は明らかです。機械は音を聞き、理解し、生成する点で人間と同じくらい優れた能力を持ちつつあります。
