# 生成 AI の詳細
生成 AI とは、既存のデータを単に分類または予測するのではなく、新しいコンテンツ (画像、テキスト、オーディオ、ビデオ、コード) を作成するモデルを指します。大規模な言語モデルが最も注目を集めていますが、生成 AI の状況ははるかに広範囲に及びます。このファイルは、拡散モデルから変分オートエンコーダ、フロー モデルに至るまで、最新の生成システムの背後にあるアーキテクチャ、技術、トレードオフをカバーしています。
---

## モデルを「生成的」にするものは何ですか?
|タイプ |何をするのか |例 |
|------|-------------|----------|
| **差別的** |クラス間の境界を学ぶ | 「この画像は猫ですか、それとも犬ですか？」 |
| **生成** |データ自体の分布を学ぶ | 「猫の新しい画像を生成する」 |
生成モデルは、データを分類する方法だけでなく、*データがどのように生成されるか*を捉えます。これにより、彼らは根本的により強力になり、訓練するのが難しくなります。
---

## 主要な生成アーキテクチャ
### 変分オートエンコーダ (VAE)
VAE は、データの圧縮された構造化表現 (潜在空間) を学習し、その空間からサンプリングすることで新しいサンプルを生成します。
|コンポーネント |役割 |
|-----------|------|
| **エンコーダ** |入力データを潜在空間の分布 (平均と分散) にマッピングします。
| **潜在空間** |類似したデータ点が互いに接近している連続的な低次元空間 |
| **デコーダ** |潜在空間内の点をデータ空間にマッピングします。
| **KL ダイバージェンス** |潜在分布を標準正規値に近づける正則化項 |
**生成の仕組み**: 潜在空間からランダム ベクトルをサンプリング → デコーダに渡す → 新しいデータ ポイントを取得します。
|強さ |弱点 |
|----------|----------|
|滑らかで連続的な潜在空間 |出力がぼやける傾向があります |
|原理的な数学的枠組み |アーキテクチャの容量による制限 |
|例間を補間できる |拡散または GAN 出力よりもシャープさが劣ります。
VAE は他のモデルのコンポーネントとして使用されることがよくあります (たとえば、Stable Diffusion はパイプラインの一部として VAE を使用します)。
### 敵対的生成ネットワーク (GAN)
GAN は、偽のデータを作成する **ジェネレーター** と、本物と偽物を区別しようとする **ディスクリミネーター** という 2 つのネットワークを互いに戦わせます。
|コンポーネント |目標 |
|-----------|------|
| **ジェネレーター** |識別子をだますデータを作成する |
| **識別子** |実際のデータと生成されたデータを正しく分類する |
彼らは同時にトレーニングを行い、お互いに向上を促します。理論的には、ジェネレーターは最終的に実際のデータと区別できないデータを生成します。
| GAN バリアント |主要なイノベーション |
|------------|------|
| **DCGAN** |畳み込みアーキテクチャ。安定したトレーニング |
| **スタイルGAN / スタイルGAN2 / スタイルGAN3** |スタイルベースの生成。写実的な顔。制御可能な属性 |
| **CycleGAN** |ペアになっていない画像間の変換 (馬 → シマウマ) |
| **Pix2Pix** |画像間のペア変換 (スケッチ → 写真) |
| **プロガン** |高解像度画像の漸進的成長 |
| **BigGAN** |大規模なクラス条件付き生成 |
**GAN が衰退した理由**: トレーニングは不安定であることで有名です (モード崩壊、勾配の消失)。拡散モデルは、ほとんどの画像生成タスクでより高い品質を生成するようになりました。 GAN は、リアルタイム アプリケーション (推論が速い) や超解像度などの特定のタスクに今でも使用されています。
### 普及モデル
拡散モデルは、画像とビデオの生成における現在の最先端技術です。彼らは、純粋なランダムノイズになるまでデータにノイズを徐々に追加し、その後、そのプロセスを逆にすることを学習することによって機能します。
|フェーズ |何が起こるのか |
|------|-----------|
| **今後のプロセス (トレーニング)** |データが破壊されるまで、数百または数千のステップにわたってゆっくりとガウス ノイズを追加します。
| **逆プロセス (生成)** |純粋なノイズから始めて、きれいな画像が現れるまで、段階的にノイズを除去する方法を学びましょう。
|モデル |開発者 |注目の機能 |
|------|-----------|------|
| **DDPM** (ノイズ除去拡散確率モデル) |ホー他、2020 |展示された拡散モデルは高品質の画像を生成できます |
| **安定した拡散** |安定性AI |潜在拡散 (圧縮空間内で実行)。オープンソース |
| **ダルイー 3** |オープンAI |テキスト理解のために ChatGPT と統合 |
| **旅の途中** |旅の途中 |芸術的な品質。クローズドソース |
| **イマージェン** | Google ディープマインド |高忠実度のテキストから画像への変換 |
| **ソラ** |オープンAI |拡散トランスによるビデオ生成 |
| **フラックス** |黒い森の研究所 | Stable Diffusion のオープンウェイト後継 |
### 普及モデルが勝った理由
|利点 |説明 |
|----------|---------------|
| **トレーニングの安定性** | GAN よりもはるかに安定しています。敵対的トレーニングなし |
| **出力品質** |最先端の画質と多様性 |
| **コントロール性** |テキスト (CLIP 経由)、マスクの修復、またはその他の条件でガイドできます。
| **多様性** | GAN よりもモード崩壊が少ない。多様な出力を生成します |
|デメリット |説明 |
|---------------|---------------|
| **推論が遅い** |多くのノイズ除去ステップが必要 (通常 20 ～ 50) |
| **コンピューティング集約型** |各ステップは、大規模なモデルを通過する完全な前方パスです。
### 潜在的拡散
ピクセル空間での拡散の実行にはコストがかかります。 **潜在拡散** (安定拡散で使用) は、代わりに圧縮された潜在空間で拡散プロセスを実行します。
|ステップ |何が起こるのか |
|------|---------------|
| 1. 圧縮 |事前トレーニングされた VAE は、画像をより小さな潜在表現にエンコードします。
| 2. 拡散 |拡散モデルは潜在空間のノイズを追加/削除します。
| 3. デコード | VAE デコーダは、潜在画像を完全な画像に変換します。
これにより、品質を維持しながら、生成が劇的に高速かつ安価になります。

## テキスト条件付き生成
最新の生成システムのほとんどはテキスト プロンプトを条件としています。つまり、必要なものを記述すると、モデルがそれを生成します。
### CLIP (対照言語イメージ事前トレーニング)
CLIP は、テキストと画像の共有埋め込みスペースを学習します。これは、インターネットから取得した何十億もの画像とテキストのペアを使用してトレーニングされました。
|能力 |説明 |
|-----------|---------------|
| **ゼロショット分類** |トレーニングなしでテキストの説明を使用して画像を分類 |
| **画像テキストの検索** |テキストクエリに最も関連性の高い画像を見つける |
| **拡散を導く** |画像生成をテキスト プロンプトに向ける |
### 分類子を使用しないガイダンス (CFG)
CFG は、生成された画像がテキスト プロンプトにどの程度従うかを制御します。
| CFGスケール |効果 |
|----------|----------|
| **1.0** |ガイダンスはありません。多様ですがプロンプトと一致しない可能性があります |
| **5.0–7.5** |バランスが取れています。良質と迅速な遵守 |
| **10.0+** |強い付着力。過飽和な画像やアーティファクトの多い画像が生成される可能性があります。

## 他の生成的アプローチ
### フローの正規化
|特集 |説明 |
|----------|---------------|
| **仕組み** |データと単純な分布の間の可逆マッピングを学習する |
| **強さ** |正確な尤度の計算。高速サンプリング |
| **弱点** |慎重に設計されたアーキテクチャが必要です。柔軟性が低い |
| **使用例** |異常検知、密度推定 |
### 自己回帰モデル
|特集 |説明 |
|----------|---------------|
| **仕組み** |前のすべての要素を条件として、一度に 1 要素ずつデータを生成します。
| **強さ** |シーケンシャル データ (テキスト、コード、音楽) の場合は自然 |
| **弱点** |生成が遅い (順次である必要がある)。トレーニング データの分布によって制限される |
| **例** | GPT (テキスト)、WaveNet (オーディオ)、ImageGPT (画像) |
### エネルギーベースのモデル
|特集 |説明 |
|----------|---------------|
| **仕組み** |エネルギー関数を学びます。低エネルギー = 現実的なデータ |
| **強さ** |フレキシブル;正規化は必要ありません |
| **弱点** |トレーニングは難しいです。サンプリングには MCMC が必要です |
| **使用例** |理論的研究;いくつかのロボット工学アプリケーション |

## 評価指標
生成されたデータの品質をどのように測定しますか?それはあなたが思っているよりも難しいです。
|メトリック | |の場合何を測定するのか |制限 |
|----------|-----|------|----------|
| **FID** (フレシェ開始距離) |画像 |実際の画像分布と生成された画像分布の間の距離 |低いほど良いです。多様性をうまく捉えていない |
| **IS** (インセプション スコア) |画像 |生成された画像の品質と多様性 |物議を醸す;ゲームすることができます |
| **クリップスコア** |テキストから画像へ |画像がテキスト プロンプトとどの程度一致しているか | CLIP の偏見による |
| **困惑** |テキスト |モデルが次のトークンをどの程度正確に予測するか |低いほど良いです。コヒーレンスを測定しません |
| **ブルー / ルージュ** |テキスト生成 |参照テキストとの重複 |人間の判断を代理するのは不十分 |
| **FAD** (フレシェ音声距離) |オーディオ |実際のオーディオ配布と生成されたオーディオ配布の間の距離 |オーディオの FID に類似 |
---

## 制御可能な生成
最新のシステムでは、テキスト プロンプト以外に生成される内容を制御できます。
|方法 |コントロールの種類 |例 |
|----------|---------------|----------|
| **修復** |マスクされた領域を塗りつぶす |写真からオブジェクトを削除する |
| **外壁塗装** |画像の境界を越えて拡張する |風景を広くする |
| **コントロールネット** |構造ガイダンス (エッジ、深度、ポーズ) |特定のポーズに一致する画像を生成 |
| **IP アダプター** |参照画像からのスタイルまたはコンテンツ | 「この絵のように見せてください」 |
| **LoRA** |微調整されたスタイルまたはコンセプト |特定のキャラクターまたはアート スタイルを追加する |
| **Img2Img** |既存の画像を変換する |スケッチを写実的な画像に変換 |

## ビデオ生成
ビデオ生成は画像の次のフロンティアです。時間と動きの次元が加わります。
|モデル |アプローチ |注目の機能 |
|------|----------|------|
| **ソラ** (OpenAI) |拡散トランス |最大1080p。物理学をかなりよく理解しています。
| **滑走路 Gen-3** |拡散ベース |コマーシャルビデオ生成ツール |
| **ピカ** |拡散ベース |テキストからの短いビデオクリップ |
| **クリング** |自己回帰 + 拡散 |長編ビデオの生成 |
| **Veo 2** (Google) |拡散トランス |高品質で物理的に一貫したビデオ |
### ビデオ生成における課題
|チャレンジ |なぜ難しいのか |
|----------|--------------|
| **時間的な一貫性** |オブジェクトはフレーム間で同じに見える必要があります。
| **物理学** |重力、衝突、流体力学はほぼ正確でなければなりません |
| **長さ** |数分間にわたる一貫したビデオを生成することは、単一の画像を作成するよりもはるかに困難です。
| **コンピューティング** |ビデオは本質的に多くの画像です。コストはフレーム数に応じて変化します |
| **評価** |ビデオ品質を適切に把握できる標準的な指標はありません。

## 世代の経済学
|係数 |影響 |
|----------|----------|
| **トレーニング費用** |普及モデル: 規模に応じて 10 万ドル～1,000 万ドル以上 |
| **推論コスト** |画像生成: 大規模な画像あたり ~$0.01 ～ 0.05 |
| **ハードウェア** |トレーニング: 複数の A100/H100 GPU。推論: 単一 GPU が可能 |
| **オープン vs クローズ** |オープン モデル (Stable Diffusion、FLUX) はローカルで実行できます。クローズド モデル (DALL-E、Midjourney) は API のみです |

＃＃ まとめ
生成 AI は、GAN から VAE を経て、拡散モデルへと進化してきました。これらすべてのアーキテクチャで重要な洞察は同じです。データの分布を学習し、そこからサンプリングして新しいコンテンツを作成することです。現在、拡散モデルは、トレーニングの安定性と出力品質により、画像とビデオの生成で主流となっています。 VAE は重要な構成要素として機能します。自己回帰モデルはテキストとコードを支配します。この分野は、マルチモーダル生成 (入力の任意の組み合わせからテキスト、画像、オーディオ、ビデオを生成できるシステム) に向けて、また、生成をより速く、より安く、より制御しやすくする方向に進んでいます。
