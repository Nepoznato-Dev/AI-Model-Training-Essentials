# グラフニューラルネットワーク
グラフ ニューラル ネットワーク (GNN) は、グラフ構造のデータ (エッジで接続されたノードのネットワーク) を操作するように設計されたニューラル ネットワークです。従来のニューラル ネットワークはグリッド (画像) またはシーケンス (テキスト) で動作しますが、GNN はソーシャル ネットワーク、分子グラフ、ナレッジ グラフ、道路ネットワーク、推奨グラフなどの任意のリレーショナル構造を処理します。これらは、創薬、不正行為検出、推奨システム、およびエンティティ間の関係が重要となるあらゆる分野に不可欠なものとなっています。
---

## グラフとは何ですか?
|コンポーネント |説明 |例 |
|----------|---------------|----------|
| **ノード (頂点)** |エンティティ |人、分子の原子、都市 |
| **エッジ** | 2 つのノード間の関係 |友情、化学結合、道路 |
| **エッジの重み** |関係の強さまたは種類 |距離、類似性、容量 |
| **ノードの機能** |各ノードの属性 |年齢、原子番号、人口 |
| **エッジ機能** |各エッジの属性 |関係の種類、距離 |
| **隣接行列** |行列 A (ノード i と j が接続されている場合、A[i][j] = 1) |グラフ構造をエンコードします |
### グラフの種類
|タイプ |説明 |例 |
|------|-------------|----------|
| **方向性なし** |エッジには方向がありません |友好ネットワーク |
| **監督** |エッジには方向があります (A→B ≠ B→A) |ツイッターのフォロワー |
| **加重** |エッジには数値があります |距離のある道路ネットワーク |
| **異種混合** |複数のノードとエッジのタイプ |学術グラフ (論文、著者、会場) |
| **ダイナミック** |時間の経過とともに変化するグラフ構造 |時間の経過とともに進化するソーシャル ネットワーク |
| **二部構成** | 2 種類のノード。タイプ間のみのエッジ |ユーザーアイテムレコメンデーショングラフ |
---

## なぜ通常のニューラル ネットワークではだめなのでしょうか?
|アプローチ |なぜ失敗するのか |
|----------|---------------|
| **フィードフォワード ネットワーク** |固定サイズの入力が必要です。グラフはサイズと構造が異なります。
| **CNN** |グリッド構造を想定しています。グラフには規則的なグリッドがありません。
| **RNN/トランスフォーマー** |連続した順序を想定します。グラフには自然な順序がありません。
GNN は、グラフ構造を直接操作し、隣接するノードのコンテキストで各ノードを処理することで、この問題を解決します。
---

## コア GNN アーキテクチャ
### メッセージパッシングフレームワーク
ほとんどの GNN は同じパターンに従います。各ノードは近隣ノードから情報を収集し、それを結合し、自身の表現を更新します。
|ステップ |説明 |
|------|---------------|
| **1.メッセージ** |各ノードは、(現在の機能に基づいて) 近隣ノードにメッセージを送信します。
| **2.集計** |各ノードはすべての近隣ノードからのメッセージを収集して結合します。
| **3.更新** |各ノードは、集約されたメッセージを使用して自身の表現を更新します。
| **4.繰り返し** |これを K 層に対して実行します → 各ノードは K ホップ離れたところから情報を取得します |
### 主要な GNN モデル
|モデル |集計方法 |主要なイノベーション |
|------|-------------------|----------------|
| **GCN** (グラフ畳み込みネットワーク) |隣接フィーチャの平均 |単純;効果的;スペクトルモチベーション |
| **グラフSAGE** |サンプリングと集計。平均値、LSTM、またはプーリングを使用できます。誘導的 (目に見えないノードを処理します)。スケーラブル |
| **GAT** (グラフ アテンション ネットワーク) |アテンション加重近隣アグリゲーション |どの隣人が最も重要かを知る |
| **GIN** (グラフ同型写像ネットワーク) |隣接フィーチャの合計 |最大限に表現力豊か。 WL テストで区別できるグラフはすべて区別できます。
| **MPNN** (メッセージ パッシング ニューラル ネットワーク) |一般的なメッセージ受け渡しフレームワーク |多くの GNN バリアントを統合 |
### GCN の仕組み (ステップバイステップ)
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

K 層の後、各ノードの表現はグラフ内で K ホップ離れたところからの情報をエンコードします。

## グラフレベルのタスク
|タスク |説明 |例 |
|------|-------------|----------|
| **ノードの分類** |各ノードのラベルを予測する |ユーザーをボットまたは人間に分類する |
| **リンク予測** |エッジが存在する (または今後存在する) かどうかを予測する |欠落している関係を予測します。推奨接続 |
| **グラフの分類** |グラフ全体のラベルを予測する |分子を有毒または無毒に分類する |
| **コミュニティ検出** |密に接続されたノードのクラスターを見つける |社会的グループを特定する |
| **グラフの生成** |必要なプロパティを持つ新しいグラフを生成 |新しい分子を設計する |

## アプリケーション
### 創薬と分子特性予測
|タスク | GNN はどのように役立つのか |
|------|--------------|
| **分子物性予測** |分子をグラフとして表現します (原子 = ノード、結合 = エッジ)。毒性、溶解性、結合親和性を予測 |
| **薬物間相互作用** |薬物とターゲットをグラフとしてモデル化します。有害な相互作用を予測する |
| **デノボ医薬品デザイン** |目的の特性を持つ新しい分子グラフを生成 |
### レコメンデーション システム
|アプローチ |説明 |
|----------|---------------|
| **ユーザーアイテムグラフ** |ユーザーとアイテムはノードです。購入/閲覧はエッジです |
| **グラフベースの協調フィルタリング** | GNN はグラフを通じて設定を伝播します。
| **ナレッジ グラフに関する推奨事項** |ユーザーの好みとアイテムの知識 (ジャンル、俳優、監督) を組み合わせる |
### 不正行為の検出
|アプリケーション |グラフの構造 |
|-----------|----------------|
| **金融詐欺** |トランザクションはグラフを形成します。不正なパターンがサブグラフ構造として現れる |
| **保険詐欺** |請求者、プロバイダー、ポリシーがグラフを形成します。詐欺師の集団が発見される |
| **アカウントの乗っ取り** |ログインパターンがグラフを形成します。異常な接続信号の侵害 |
### ナレッジグラフ
|タスク |説明 |
|------|---------------|
| **リンク予測** |欠落している事実を予測します (例: 「パリは?の首都です」) |
| **エンティティの解決** | 2 つの言及が同じエンティティを参照しているかどうかを判断する |
| **質問への回答** |グラフをナビゲートして答えを見つけます |

## 高度な GNN 概念
### 過剰な平滑化
|問題 |説明 |ソリューション |
|----------|---------------|----------|
| **過剰な平滑化** |多くの層を重ねると、すべてのノード表現が似たものになります。深さを制限します (2 ～ 4 層)。残りの接続を使用します。ジャンプの知識を使用する |
### 過剰な潰し
|問題 |説明 |ソリューション |
|----------|---------------|----------|
| **過剰な潰し** |離れたノードからの情報は固定サイズのベクトルに圧縮されます。グラフトランスフォーマーを使用します。階層プーリング |
### グラフトランスフォーマー
|モデル |主な機能 |
|------|-----------|
| **グラフ トランスフォーマー** |標準の Transformer アテンションをすべてのノード ペアに適用します。
| **GPS** (グラフ プロンプト システム) |ローカル GNN レイヤーとグローバル Transformer レイヤーを結合する |
| **グラフォーマー** |グラフ構造に基づいて位置エンコーディングを追加する |
### 異種グラフ ネットワーク
|モデル |説明 |
|------|-----------|
| **R-GCN** |リレーショナル GCN。異なるエッジ タイプに対する異なる重み行列 |
| **ハン** |異種注意ネットワーク。さまざまなノードとエッジのタイプに注意 |
| **HetGNN** |異種グラフ ニューラル ネットワーク。複数のノードタイプを処理します。

## スケーラビリティ
|チャレンジ |ソリューション |
|----------|----------|
| **大規模なグラフ** (数百万ノード) |ミニバッチトレーニング。近隣サンプリング |
| **メモリ** | GPU 間のグラフの分割 |
| **速度** |スパース行列演算。特殊なライブラリ |
### サンプリング戦略
|戦略 |説明 |
|----------|---------------|
| **ノードのサンプリング** |ノードのサブセットとその K ホップ近傍をサンプリングする |
| **エッジサンプリング** |サンプル エッジとそれらが接続するノード |
| **クラスターのサンプリング** |グラフをクラスターに分割します。クラスタ上でトレーニングする |
| **ランダム ウォーク サンプリング** |ターゲット ノードからのランダム ウォークによるサンプル ノード |

＃＃ まとめ
グラフ ニューラル ネットワークは、ディープ ラーニングをリレーショナル データ (ネットワーク、分子、ナレッジ グラフ、およびエンティティが接続されているあらゆるシステム) に拡張します。これらは近隣ノード間でメッセージを渡すことによって機能し、各ノードがローカル コンテキストから学習できるようにします。 GNN は、創薬、推奨システム、不正行為検出、ナレッジ グラフに最も強力な用途を見出しています。この分野は、グラフ トランスフォーマー、異種グラフ、大規模な実世界ネットワークのスケーラブルなトレーニングに向けて進化しています。データに関係がある場合は、おそらく GNN を検討する価値があります。
