# 因果推論
因果推論は、あることが実際に別のことを引き起こすかどうかを判断する科学であり、単に相関関係があるかどうかだけではありません。相関関係は、2 つの変数が一緒に動くことを示します。因果関係は、一方を変更すると他方も変更されることを示しています。この区別は、医学 (この薬は効果があるか?)、政策 (この介入は貧困を削減するか?)、ビジネス (この広告キャンペーンは売上を増加させるか?)、科学 (このメカニズムは現象を説明できるか?) において非常に重要です。
---

## 相関関係と因果関係
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **相関関係** | 2 つの変数が一緒に移動する |夏にはアイスクリームの売り上げと溺死が増加する |
| **因果関係** |ある変数が別の変数に直接影響を与える |喫煙は肺がんの原因となる |
| **混乱を招く** | 3 番目の変数は両方の原因を引き起こします。暑い気候はアイスクリームの販売と水泳（そして溺死）の両方を引き起こします。
| **逆因果関係** |結果は、想定されている原因を実際に引き起こします。人々は病気だから健康補助食品を買うのであって、その逆ではない |
| **偽相関** |偶然の関係 |一人当たりのチーズ消費量はシーツ絡みによる死亡と相関する |
---

## 潜在的な結果のフレームワーク
### ルービン因果モデル
|コンセプト |説明 |
|----------|---------------|
| **潜在的な結果** |各ユニットには、治療された場合の結果 Y(1) と治療されなかった場合の結果 Y(0) があります。
| **治療効果** |違い: 指定されたユニットの Y(1) - Y(0) |
| **根本的な問題** |同じユニットの Y(1) と Y(0) の両方を観測することはできません。観測できるのは 1 つだけです |
| **平均治療効果 (ATE)** |集団全体における個々の治療効果の平均 |
| **反事実** |観察されなかった結果 — 他の条件下では何が起こったのか |
### 重要な前提条件
|仮定 |意味 |満足する方法 |
|----------|----------|-----|
| **無視可能性 (混乱のなさ)** |観察された共変量を考慮すると、治療の割り当ては潜在的な結果とは独立しています。ランダム化;すべての交絡因子を測定する |
| **ポジティブ (重複)** |すべてのユニットは、いずれかの治療を受ける可能性がゼロではありません。グループ間の共変量の重複を確認する |
| **STVA** (安定した治療単位値の仮定) |あるユニットの治療が他のユニットの結果に影響を与えることはありません。治療は一貫しています |干渉はありません。治療の隠しバージョンはありません |
| **一貫性** |観察された結果は、受けた治療の下での潜在的な結果と等しい |明確に定義された治療 |

## 因果推論の方法
### 実験方法
|方法 |説明 |強さ |制限 |
|----------|---------------|----------|---------------|
| **ランダム化比較試験 (RCT)** |ユニットを治療または制御にランダムに割り当てます。ゴールドスタンダード;交絡を排除します |高い;時には非倫理的です。一般化できないかもしれません |
| **A/B テスト** |ビジネス/テクノロジーの文脈における RCT |単純;厳格な |短期的な指標。斬新な効果。干渉 |
| **スイッチバック実験** |一定期間にわたる交互治療 |市場での干渉に対処する |安定した環境が必要 |
### 準実験的方法
|方法 |説明 |主な前提条件 |
|----------|---------------|-----|
| **差分間差 (DiD)** |治療群と対照群間の転帰の変化を経時的に比較する |平行傾向: 治療がなければグループは同じ軌道をたどったでしょう |
| **回帰不連続性 (RD)** |治療カットオフのすぐ上とすぐ下のユニットを比較 |カットオフに近い単位は (ランダムであるかのように) 比較可能です。
| **操作変数 (IV)** |治療に影響を与えるが、治療以外の結果には影響しない変数を使用する |器具は治療と相関関係があります。治療を通じてのみ結果に影響を与える |
| **合成コントロール** |処理単位に一致するように制御単位の重み付けされた組み合わせを構築します。合成制御は、処理されたユニットの反事実を正確に表現します。
| **傾向スコアのマッチング** |治療単位と対照単位を同様の治療確率で一致させます。すべての交絡因子が測定され、傾向モデルに含まれます。
### 差異の中の差異 (視覚化)
|期間 |治療を受けたグループ |コントロールグループ |違い |
|------|--------------|---------------|----------|
| **前処理** | Y_t_pre | Y_c_pre | Y_t_pre - Y_c_pre |
| **後処理** | Y_t_post | Y_c_post | Y_t_post - Y_c_post |
| **DiD 推定値** | | | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) |

## 有向非巡回グラフ (DAG)
DAG は、因果関係の仮定をエンコードし、交絡因子を特定するための視覚的なツールです。
### 基本構造
|構造 |パターン |意味 |
|----------|-----------|---------------|
| **チェーン** | A → B → C | A と C は B を通じて関連付けられます。 B を制御するとパスがブロックされます。
| **フォーク** | A ← B → C | A と C は B によって混同されます。 B を制御するとパスがブロックされます。
| **コライダー** | A → B ← C | A と C は独立しています。 B を制御するとパスが開きます (偽の関連付けが作成されます)。
### DAG のルール
|ルール |説明 |
|------|---------------|
| **バックドア基準** | Y に対する X の因果関係を推定するには、適切な変数を条件付けしてすべてのバックドア パス (X への矢印のあるパス) をブロックします。
| **フロントドア基準** |バックドア パスをブロックできない場合は、メディエーターを使用します。X → M → Y を 2 段階で推定します。
| **コライダーに条件を付けないでください** |共通の効果を制御すると、偽の道が開かれる |
| **コライダーの子孫を条件にしないでください** |コライダー自体の条件付けと同じ問題 |

## よくある落とし穴
|落とし穴 |説明 |例 |
|----------|---------------|----------|
| **変数バイアスの省略** |交絡因子の制御に失敗する |能力をコントロールせずに学歴→収入を見積もる |
| **過剰制御** |メディエーターまたはコライダーの条件付け |学歴→収入を見積もる際の役職の管理 |
| **選択バイアス** |治療の影響を受ける変数の条件付け |訓練→賃金を研究する場合は雇用者のみを分析する |
| **不滅の時間バイアス** |コホート研究における滞在時間の誤分類 |患者は治療を受けるのに十分な期間生存しなければなりません |
| **平均値への回帰** |極端な値は平均に近づく傾向があります。病気の患者は治療後には関係なく改善する |
| **治療後のバイアス** |治療後に発生する変数の条件付け |薬効を推定する際の有害事象の管理 |

＃＃ まとめ
因果推論は、「何が起こったか」を超えて、「状況が異なっていたらどうなるか」に進むことです。根本的な課題は、同じユニットの治療結果と未治療結果の両方を観察することは決してできないことです。つまり、反事実が常に欠落しているのです。ランダム化実験では、治療群と対照群を比較することでこの問題を解決します。ランダム化が不可能な場合、疑似実験的手法 (DiD、回帰不連続性、操作変数、総合制御) が観察データから反事実を再構築しようとします。 DAG は、仮定を明確にし、制御する適切な変数を特定するのに役立ちます。重要なスキルは、データ生成プロセスについて注意深く考えることです。つまり、何が原因で、何が交絡因子、何が衝突し、代替案では何が起こったのかを考えることです。
