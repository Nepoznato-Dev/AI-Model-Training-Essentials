# 統計的なテストと実験
統計は科学の文法です。これは、実際のパターンをランダムなノイズから区別し、変更によって実際に状況が改善されたかどうかを測定し、不確実性の下で意思決定を行うためのツールを提供します。このファイルでは、仮説検証、実験計画、そして人々をつまずかせるよくある落とし穴の中核となる概念を取り上げています。
---

## 仮説検証フレームワーク
すべての統計テストは同じロジックに従います。
1. **帰無仮説 (H₀) を述べます**: 効果はなく、差異もありません。
2. **対立仮説 (H₁) を述べます**: 効果 / 差異があります。
3. **有意水準 (α) を選択します**: 通常は 0.05 (偽陽性の確率 5%)。
4. **データを収集し、検定統計量を計算します**。
5. **p 値を計算します**: H₀ が true の場合にこの結果が観察される確率 (またはより極端な値)。
6. **決定を行う**: p < α の場合、H₀ を拒否します (統計的に有意)。そうでない場合は、H₀ を拒否できません。
### 主要な概念
|コンセプト |意味 |よくある誤解 |
|----------|----------|----------|
| **p 値** | P(データ \| H₀ は true) | 「H₀が真である確率」ではありません |
| **α (有意水準)** | H₀ を拒否するためのしきい値 |効果の重要性の尺度ではありません |
| **統計的有意性** |偶然だけで結果が出る可能性は低い |実質的に重要という意味ではありません |
| **効果量** |観察された影響の大きさ | p 値とは別にします。 N | が大きい場合は、小さな効果でも重大な影響を与える可能性があります。
| **パワー** |偽の H₀ を正しく拒否する確率 |通常は 80% 以上を目指します |
| **信頼区間** |パラメーターの妥当な値の範囲 | 95% CI は、「95% の確率で真の値がこの範囲内にある」という意味ではありません。
---

## エラーの種類
| | H₀ は真です | H₀ は偽です |
|---|----------|---------------|
| **H を拒否します** |タイプ I エラー (偽陽性) | ✅ 正しい (真陽性) |
| **H₀ を拒否できませんでした** | ✅ 正しい (真陰性) |タイプ II エラー (偽陰性) |
|エラー |記号 |意味 |
|----------|----------|----------|
| **タイプ I** | α |効果がないのに効果があると結論付ける |
| **タイプ II** | β |本当の効果が欠けている |
---

## 適切なテストの選択
|シナリオ |テスト |仮定 |
|----------|------|---------------|
| 2 つのグループの平均を比較する | **t 検定** (独立) |正規分布、等分散 |
|ペアの観測値の平均値を比較する | **対応のある t 検定** |差は正規分布する |
| 3 つ以上のグループの平均を比較する | **分散分析** |正規分布、等分散 |
|カテゴリ分布を比較する | **カイ二乗検定** |セルあたりの十分なサンプル サイズ |
|分布の比較 (ノンパラメトリック) | **マン・ホイットニー U** |正規性の仮定がない |
| 3 つ以上のグループを比較 (ノンパラメトリック) | **クラスカル ウォリス** |正規性の仮定がない |
|相関関係をテストする | **ピアソン** (線形) または **スピアマン** (単調) |ピアソン: 正常性。スピアマン: ランクベース |
|データが分布に従っているかどうかをテストする | **コルモゴロフ-スミルノフ** |連続データ |
### パラメトリックとノンパラメトリック
| |パラメトリック |ノンパラメトリック |
|---|-----------|---------------|
| **前提** |データは特定の分布に従います (通常は正規分布)。分布の仮定なし |
| **パワー** |仮定が満たされると高くなります |低いがより堅牢 |
| **使用する場合** |大きなサンプル、ほぼ正常なデータ |小さなサンプル、偏ったデータ、順序データ |
---

## 特定のテストの詳細
### t検定
2 つのグループの平均を比較します。
|バリアント |使用例 |
|----------|----------|
| **独立した t 検定** | 2 つの別々のグループ (治療 vs 対照) |
| **対応のある t 検定** |同じグループが 2 回測定 (前と後) |
| **1 サンプル t 検定** |サンプル平均を既知の値と比較する |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA (分散分析)
3 つ以上のグループの平均を比較します。少なくとも 1 つのグループ平均が残りのグループ平均と異なるかどうかを検定します。
|タイプ |デザイン |
|------|----------|
| **一元配置分散分析** | 3 レベル以上の 1 つの独立変数 |
| **二元配置分散分析** | 2 つの独立変数。相互作用効果をテストする |
| **反復測定 ANOVA** |同じ被験者を異なる条件で測定 |
ANOVA が有意な場合は、**事後検定** (Tukey の HSD) を追跡して、どの特定のグループが異なるかを調べます。
### カイ二乗検定
2 つのカテゴリ変数が独立しているかどうかをテストします。
|使用例 |例 |
|----------|----------|
| **独立性のテスト** |性別は製品の好みに関係していますか? |
| **フィット感の良さ** |サイコロの目は一様分布に従いますか? |
**経験則**: 各セルの予想カウントは少なくとも 5 である必要があります。
---

## A/B テスト
A/B テストは仮説テストをビジネス上の意思決定に適用するもので、通常は対照 (A) とバリアント (B) を比較します。
### 設計プロセス
|ステップ |説明 |
|------|---------------|
| **1.仮説を定義** | 「ボタンの色を青から緑に変更すると、クリック率が向上します」 |
| **2.メトリックを選択** |プライマリ: クリックスルー率。二次: コンバージョン率、収益。 |
| **3.サンプルサイズを計算** |最小の検出可能な効果、検出力 (80%)、および有意性 (5%) に基づく |
| **4.ランダム化** |ユーザーを制御と治療にランダムに割り当てます。
| **5.実験を実行** |目標サンプルサイズに達するまでデータを収集する |
| **6.分析** |適切な統計テストを使用してメトリクスを比較する |
| **7.決定** |統計的かつ実質的に有意な場合は実装する |
### サンプルサイズの計算
必要なサンプル サイズは以下によって異なります。
|係数 |サンプルサイズへの影響 |
|------|----------------------|
| **検出する影響が小さくなります** |もっとサンプルが必要 |
| **高出力** |もっとサンプルが必要 |
| **低い有意水準** |もっとサンプルが必要 |
| **より高い分散** |もっとサンプルが必要 |
### A/B テストでよくある間違い
|間違い |なぜそれが間違っているのか |
|-------|---------------|
| **早めの覗き見** |結果を毎日確認すると誤検知率が上昇 |
| **補正なしの複数の指標** | α=0.05 で 20 のメトリクスをテスト → 偶然 1 つの誤検知が予想される |
| **目標 N の手前で停止します** |能力不足のテストでは実際の影響を検出できない |
| **季節性を無視** |休日期間と通常の週にテストを実行する |
| **非ランダムな割り当て** |選択バイアス (例: 新しいユーザーを治療に割り当てる) |
| **重要性と重要性を混同する** | 0.1% の上昇は統計的に有意である可能性がありますが、出荷する価値はありません。
---

## 複数の比較
多くのテストを同時に実行すると、少なくとも 1 つの偽陽性が発生する可能性が大幅に増加します。
|テスト数 | ≥1 の偽陽性の確率 (α=0.05 の場合) |
|----------------|----------------------------------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 40% |
| 20 | 64% |
### 訂正
|方法 |仕組み |いつ使用するか |
|----------|---------------|---------------|
| **ボンフェローニ** | α をテスト数で割る (α/n) |保守的;いくつかの比較 |
| **ホルム・ボンフェローニ** |ステップダウン手順。それほど保守的ではない |一般用途 |
| **ベンジャミニ ホッホベルグ (FDR)** |誤検出率を制御 |多くのテスト。探索的分析 |
---

## 効果の大きさ
P 値は、効果が「存在するかどうか」を示します。効果サイズは、それが*どのくらい大きい*かを示します。
|測定 | |の場合解釈 |
|-------|-----|------|
| **コーエンのd** | 2 つの平均の違い | 0.2 = 小、0.5 = 中、0.8 = 大 |
| **ピアソンのr** |相関関係 | 0.1 = 小、0.3 = 中、0.5 = 大 |
| **η² (イータ二乗)** |分散分析 | 0.01 = 小、0.06 = 中、0.14 = 大 |
| **オッズ比** |カテゴリ別の結果 | 1.0 = 効果なし。 >1 または <1 = 効果 |
**常に p 値とともに効果量を報告します。** 結果は統計的に有意であっても、実質的には無意味である場合があります。

## ベイジアン vs 頻度主義
|側面 |頻繁に使う人 |ベイジアン |
|----------|-----------|----------|
| **確率** |長期にわたるイベントの頻度 |信念の度合い |
| **パラメータ** |修正済みだが不明 |分布を伴う確率変数 |
| **用途** | p 値、信頼区間、仮説検定 |事後分布、信頼区間 |
| **前** |以前の信念は組み込まれていません |明示的な事前分布 |
| **解釈** | 「この実験を何度も繰り返したら…」 | 「データを考慮すると、確率は...」 |
| **強み** |客観的、確立された、シンプル |予備知識を取り入れた直感的な解釈 |
| **弱点** | p 値は広く誤解されています。事前の選択は主観的なものになる可能性があります。

## 因果推論の基本
相関関係は因果関係ではありません。しかし、場合によっては、X が関連しているかどうかだけでなく、*X が Y を引き起こしたかどうか* を知る必要があることもあります。
|方法 |説明 |いつ使用するか |
|----------|---------------|---------------|
| **ランダム化実験** |ゴールドスタンダード;ランダムな割り当てにより交絡因子が排除される |ランダム化できる場合 |
| **差分差分 (DiD)** |治療と対照間の経時的変化を比較 |政策変更、自然実験 |
| **回帰不連続性 (RDD)** |カットオフしきい値を利用する |奨学金、資格基準 |
| **操作変数 (IV)** |治療には影響するが、結果には直接影響しない機器を使用する |ランダム化が不可能な場合 |
| **傾向スコア マッチング** |観察された特性に基づいて処理単位と対照単位を一致させる |観察研究 |
---

## よくある統計上の間違い
|間違い |説明 |
|----------|---------------|
| **p-ハッキング** | p < 0.05 | が見つかるまで多くの分析を試みます。
| **ハーキング** |結果がわかった後の仮説 |
| **生存者バイアス** |成功だけを見る (例: 成功した企業) |
| **シンプソンのパラドックス** |データをグループごとに分割した場合と集計した場合では、傾向が逆転します。
| **基本レート無視** |結果を解釈する際の事前確率の無視 |
| **生態学的誤謬** |グループレベルのデータから個人の行動を推測する |
| **混乱を招く** | 3 番目の変数は、観察された関係を説明します。
| **過学習** |モデルは信号ではなくノイズをキャプチャします |
---

＃＃ まとめ
統計的テストは、不確実性の下で知的正直さをもって意思決定を下すことです。データを収集する前に、必ず仮説を述べてください。データの種類に適したテストを選択してください。 p 値だけでなく、効果の大きさをレポートします。多重比較の場合は修正します。そして、統計的な有意性は実際の有意性と同じではないことを覚えておいてください。
