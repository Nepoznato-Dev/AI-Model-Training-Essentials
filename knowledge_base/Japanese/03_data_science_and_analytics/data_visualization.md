# データの視覚化
適切に設計されたグラフは、数字の表では隠れているパターンを明らかにすることができます。デザインが不十分だと、誤解を招いたり、混乱させたり、退屈させたりする可能性があります。データビジュアライゼーションは、データを意思決定を伝える視覚的なストーリーに変える技術です。このファイルには、チャートの選択、設計原則、よくある間違い、およびそれをすべて可能にするツールが含まれています。
---

## 適切なチャートの選択
ビジュアライゼーションにおいて最も重要な決定は、データとメッセージに適したグラフの種類を選択することです。
### チャート選択ガイド
|あなたの目標 |最適なグラフの種類 |
|----------|------|
| **カテゴリーを比較** |棒グラフ、グループ化棒グラフ |
| **時間の経過に伴う変化を表示** |折れ線グラフ、面グラフ |
| **配信を表示** |ヒストグラム、ボックス プロット、バイオリン プロット |
| **関係を表示** |散布図、バブル チャート |
| **構成を表示** |積み上げ棒、円グラフ (限定されたスライス)、ツリーマップ |
| **相関関係を表示** |散布図、ヒートマップ、ペア プロット |
| **ランキングを表示** |横棒グラフ |
| **地理的パターンを表示** |コロプレスマップ、ドットマップ |
| **部分から全体を時間の経過とともに表示** |積み上げ面グラフ |
### 各グラフをいつ使用するか
|チャート |強み |次の場合は避けてください |
|------|-----------|-----------|
| **バー** |カテゴリ間の明確な比較 |カテゴリが多すぎます (>15) |
| **ライン** |時間の経過に伴う傾向。連続データ |データは連続していません |
| **散布** | 2 つの変数間の関係 |重なっている点が多すぎます |
| **ヒストグラム** | 1 つの変数の分布形状 |サンプル サイズが小さい (<20) |
| **Box plot** | Summary statistics + outliers; compare distributions | Audience unfamiliar with them |
| **Heatmap** | Correlation matrices; patterns in 2D data | Too many variables |
| **Pie chart** | Simple composition (2–5 slices) | More than 5 slices; precise comparisons needed |
| **Violin plot** | Distribution density + quartiles | Small audiences unfamiliar with them |
| **Pair plot** | Quick overview of all variable relationships | Many variables (> 8) |

## 設計原則
### タフテの核となるアイデア
Edward Tufte の原則は、依然としてデータ視覚化のゴールドスタンダードです。
|原則 |説明 |
|----------|---------------|
| **データインク比率を最大化** |インクの一滴一滴がデータを伝達する必要があります。他のすべてを削除します。 |
| **チャートジャンクを排除** | 3D 効果、不必要なグラデーション、装飾要素はありません。 |
| **データを表示** |歪めたり、隠したり、抜粋したりしないでください。データに語らせましょう。 |
| **小さな倍数** |カテゴリ間の比較には、小さなグラフを繰り返し使用します。 |
| **スパークライン** |インライントレンドデータ用の小さなワードサイズのグラフ。 |
### 実際の設計ルール
|ルール |なぜ |
|------|-----|
| **y 軸をゼロから開始** (棒グラフの場合) |そうしないと違いが誇張されてしまいます。
| **直接ラベルを付ける** |可能な場合は、凡例を使用する代わりに、線/棒にラベルを付けます。
| **意図的に色を使用する** |重要なことを強調表示します。コンテキストにグレーを使用する |
| **シンプルにしてください** |チャートごとに 1 つのメッセージ。過負荷にしないでください。
| **一貫したスケールを使用してください** |グラフを比較するときは、軸を同じにしてください。
| **有意義な注文** |自然な順序がない限り、バーを (アルファベット順ではなく) 値で並べ替えます。
| **コンテキストを提供してください** |ベンチマーク、目標、または過去の平均を追加します。
### 色のガイドライン
|使用例 |アプローチ |
|----------|----------|
| **カテゴリ** |独特の色合い (青、オレンジ、緑、赤) — 最大 7 ～ 8 カテゴリ |
| **順次** | 1 つの色相の明から暗 (水色→紺色) |
| **発散** |意味のある中間点を持つデータの 2 色階調 (赤 ← 白 → 青) |
| **アクセシビリティ** |色覚異常シミュレーターを使用してテストします。色だけに依存しないでください (ラベルやパターンを追加します)。

## データを使ったストーリーテリング
物語のないチャートは単なる絵に過ぎません。ストーリーテリングはデータを洞察に変えます。
### ストーリーテリングのフレームワーク
1. **状況**: 状況は何ですか?視聴者がすでに知っていることは何ですか?
2. **矛盾**: データの問題、驚き、または緊張は何ですか?
3. **解決策**: この洞察に対して視聴者は何をすべきですか?
### 実践的なヒント
|ヒント |説明 |
|-----|---------------|
| **洞察力を持ってリードする** |グラフにデータではなく要点をタイトルに付けます (「四半期ごとの収益」ではなく「収益が 30% 増加」)。
| **重要なポイントに注釈を付ける** |重要なイベントや転換点にテキストの吹き出しを追加する |
| **段階的な開示を使用する** |一度に 1 つのチャートを表示します。ストーリーを段階的に構築する |
| **重要なことを強調表示** |色やサイズを使用して重要なデータ ポイントに注目を集めます |
| **「だから何?」を入力してください** |すべてのグラフは質問に答えるか、アクションを促す必要があります。

## よくある間違い
|間違い |なぜダメなのか |修正 |
|----------|---------------|-----|
| **Y 軸の切り詰め** |小さな違いを誇張する |棒グラフの場合はゼロから開始 |
| **さくらんぼ狩りの時間帯** |トレンドに関する誤解 |利用可能な全範囲を表示 |
| **色が多すぎる** |見る者を圧倒します | 5 ～ 7 に制限します。コンテキストにグレーを使用する |
| **二重 Y 軸** |存在しない可能性のある相関関係を暗示します。 2 つの別々のグラフを使用する |
| **3D チャート** |プロポーションを歪める |常に 2D を使用する |
| **10 個以上のスライスを含む円グラフ** |比較することは不可能 |代わりに棒グラフを使用してください。
| **ラベルがありません** |視聴者がチャートを理解できない |軸、タイトル、単位には常にラベルを付けます。
| **誤解を招く面グラフ** |積み重ねられた領域は個々のシリーズの認識を歪めます |折れ線グラフまたは小さな倍数を使用する |

## ダッシュボードのデザイン
ダッシュボードは、プロセス、システム、またはビジネスに関する完全なストーリーを一緒に伝えるビジュアライゼーションのコレクションです。
### ダッシュボードの種類
|タイプ |観客 |目的 |
|------|----------|----------|
| **戦略的** |役員 |高レベルの KPI。長期的な傾向 |
| **動作中** |マネージャー |リアルタイム監視。日常業務 |
| **分析** |アナリスト |深い探求;フィルタリング、ドリルダウン |
### 設計チェックリスト
- **視聴者を知る**: 彼らはこのダッシュボードからどのような決定を下すでしょうか?
- **5 秒ルール**: 5 秒で重要なポイントを把握できますか?
- **レイアウト**: 最も重要な指標は左上 (最初に目が行く場所)。
- **グラフの種類を制限する**: 一貫性を保つため、ダッシュボードごとに最大 3 ～ 4 種類。
- **デフォルトで対話型**: フィルター、日付範囲セレクター、ドリルダウン。
- **パフォーマンス**: 読み込みに 5 秒以上かかるダッシュボードは使用されません。
- **モバイル**: ユーザーが外出先で必要とする場合は、レスポンシブ デザインを検討してください。

＃＃ まとめ
優れたデータ視覚化は、明快さ、誠実さ、影響力を重視します。データに適したグラフを選択してください。メッセージを提供しないものはすべて削除します。色と注釈を使用して閲覧者をガイドします。そして常に、常にデータにストーリーを語らせてください。その逆ではありません。
