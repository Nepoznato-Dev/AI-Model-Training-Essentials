# 動的システム
**動的システム**は、固定ルールに従って状態が時間の経過とともにどのように進化するかを記述します。惑星の軌道から人口動態、気象パターンからニューラルネットワークの訓練に至るまで、力学システム理論は、物事がどのように変化するかを理解するための言語とツールを提供します。このファイルは、常微分方程式 (ODE)、偏微分方程式 (PDE)、安定性解析、カオス、分岐をカバーしています。
---

## 常微分方程式 (ODE)
ODE は、関数を単一の独立変数 (通常は時間) に関する導関数に関連付けます。
### 分類
|プロパティ |種類 |
|----------|----------|
| **注文** |現在の最高導関数 (1 次、2 次など) |
| **線形と非線形** |線形: y'' + p(t)y' + q(t)y = g(t);非線形: その他 |
| **均質** | g(t) = 0 (強制項なし) |
| **自律型** |明示的な時間依存性なし: dy/dt = f(y) |
| **定数係数** | p、q は定数です |
### 一次常微分方程式
**一般形式:** dy/dt = f(t, y)
|タイプ |フォーム |解決方法 |
|------|------|------|
|分離可能 | dy/dt = g(t)h(y) |分離と積分: ∫dy/h(y) = ∫g(t)dt |
|線形一次 | dy/dt + p(t)y = q(t) |積分係数: μ(t) = e^(∫p dt) |
|正確 | M(t,y)dt + N(t,y)dy = 0 (∂M/∂y = ∂N/∂t |ポテンシャル関数 F(t,y) を求めます。
|ベルヌーイ | dy/dt + p(t)y = q(t)yⁿ | v = y^(1−n) を代入して線形化 |
**作業例 (積分係数):** dy/dt + 2y = e^(−t)、y(0) = 1 を解きます。
- 積分係数: μ(t) = e^(∫2 dt) = e^(2t)
- 乗算: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- 積分: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- 初期条件: y(0) = 1 → 1 = 1 + C → C = 0
- 解: y(t) = e^(−t)
### 2次線形常微分方程式
**一般形式:** ay'' + by' + cy = g(t)
**均一の場合** (g​​ = 0): 特性方程式 ar² + br + c = 0 を解きます。
|判別式 |ルーツ |一般的な解決策 |
|-----------|------|------|
| b² > 4ac (過減衰) | 2 つの異なる実数 r₁、r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (臨界減衰) |実数根の繰り返し r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (減衰不足) |複素根 α ± βi | y = e^(αt)(C1 cos βt + C2 sin βt) |
**物理的解釈:** マス-スプリング-ダンパー システム mx'' + bx' + kx = 0。
- 過減衰: 強い減衰、振動なし (ドアクローザー)
- 臨界減衰: 振動なしで最速の復帰 (車のサスペンションの設計目標)
- アンダーダンピング: 減衰する振幅で発振します (ギター弦)
### ODE のシステム
実際のシステムの多くには、相互作用する複数の変数が含まれます。
dx/dt = f(x, y)
dy/dt = g(x, y)
これはベクトル形式で記述できます: d**x**/dt = **F**(**x**)
**線形システム:** d**x**/dt = A**x**、A は行列です。
解は A の固有値に依存します。
|固有値 |行動 |
|---------------|----------|
|実数、負の両方 |安定ノード (すべての軌跡が原点に収束) |
|両方とも現実的、ポジティブ |不安定なノード |
|実数、反対の符号 |サドルポイント（不安定） |
|複素数、負の実部 |安定スパイラル（減衰振動） |
|複素数、正の実部 |不安定なスパイラル | 写真 不安定なスパイラル
|純粋な想像上の |中心 (閉じた軌道) |

## フェーズポートレート
**位相ポートレート**は、(明示的に解決せずに)状態空間内の動的システムの軌跡を視覚化します。
### 主な機能
|特集 |説明 |
|----------|---------------|
| **不動点 (平衡)** |ここで、dx/dt = 0 (動きなし) |
| **軌跡** |状態空間内でシステムによってトレースされるパス |
| **ヌルクライン** | 1 つの成分の導関数がゼロになる曲線 |
| **リミットサイクル** |孤立した閉鎖軌道（自立振動） |
| **魅力の盆地** |特定のアトラクターを導く初期条件のセット |
| **セパラトリックス** |異なる引力盆地の境界 |
### 捕食者-被食者モデル (ロトカ-ヴォルテラ)
dx/dt = αx − βxy (獲物)
dy/dt = δxy − γy (捕食者)
**修正点:**
1. (0, 0) — 消滅 (鞍点)
2. (γ/δ、α/β) — 共存 (中心 — 閉じた軌道)
このシステムは周期的な振動を示します。獲物が増加する→捕食者が増加する→獲物が減少する→捕食者が減少する→サイクルが繰り返されます。

## 安定性解析
### 線形安定性
固定点 x* の場合、その周囲を線形化します。u = x − x* とすると、du/dt ≈ J(x*)u ここで、J はヤコビ行列です。
**安定性の基準:** 固定点は次のとおりです。
- **J のすべての固有値が負の実部を持つ場合、**安定**
- **いずれかの固有値が正の実部を持つ場合は不安定**
- 固有値の実部がゼロの場合、**わずかに安定** (非線形解析が必要)
### リアプノフの安定性
**リアプノフの直接法**は、線形化を行わずに安定性を決定します。
**リアプノフ関数** V(x) は次の条件を満たします。
1. x ≠ x* (正定値) の場合、V(x*) = 0 および V(x) > 0
2. 軌跡に沿った dV/dt ≤ 0 (増加しない)
|状態 |結論 |
|----------|---------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 |不安定 |
**実際の例:** システム dx/dt = −x + y²、dy/dt = −y。
- V(x,y) = x² + y² (エネルギーに似た関数) を試してください。
- dV/dt = 2x(−x + y2) + 2y(−y) = −2x2 + 2xy2 − 2y2
- 原点付近: dV/dt ≈ −2x² − 2y² < 0 (y が小さい場合、－2y² が支配的)
- 結論: 原点は局所的に漸近的に安定している

## カオス理論
**カオス**は決定論的ですが予測不可能です。システムは正確なルールに従いますが、初期条件のわずかな違いが大きく異なる結果をもたらします。
### カオスの要件
|プロパティ |説明 |
|----------|---------------|
|決定論的 |ランダム性なし - 正確な方程式によって支配される |
|初期条件に敏感 |近くの軌道は指数関数的に発散します。
|有界 |軌跡は無限に逃げない |
|不定期 |正確に繰り返すことはありません |
### ローレンツシステム
決定論的カオスの典型的な例:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
標準パラメータ σ = 10、ρ = 28、β = 8/3 の場合:
- システムには 3 つの固定点があり、すべて不安定です
- 軌道は 1 つの固定点を周回し、その後突然別の固定点に切り替わります
- 結果は **ローレンツ アトラクター** — フラクタル構造を持つ奇妙なアトラクターです
**リアプノフ指数:** 近くの軌道の発散率を測定します。
- 正のリアプノフ指数 → カオス
- 標準パラメータを使用したローレンツ系の場合: 最大指数 ≈ 0.9 > 0
### ロジスティックマップ
カオスを示す単純な離散システム:
x_{n+1} = rx_n(1 − x_n)
|パラメータ r |行動 |
|---------------|----------|
| 0 < r < 1 |人口が絶滅する (x → 0) |
| 1 < r < 3 | x = 1 − 1/r | における安定な固定点
| 3 < r < 3.449 |周期 2 の発振 |
| 3.449 < r < 3.544 |周期 4 の発振 |
| 3.544 < r < 3.570 |期間-8、16、32、... (期間 2 倍カスケード) |
| r ≈ 3.570 |混乱の始まり |
| 3.570 < r < 4 |ほとんどがカオスで、周期的なウィンドウが存在します。
| r = 4 | [0, 1] で完全にカオス |
### バタフライエフェクト
初期条件への敏感な依存性の通称。 (ローレンツ方程式でモデル化された) 気象システムでは、ブラジルで蝶が羽ばたくと、テキサスで竜巻が引き起こされる可能性があります。それは蝶が原因ではなく、小さな摂動が指数関数的に増大するためです。

## 分岐理論
**分岐** は、パラメーターが変化するときのシステムの動作の質的な変化です。
### 分岐の種類
|分岐 |標準形 |何が起こるのか |
|---------------|---------------|--------------|
| **サドルノード** | dx/dt = r − x² | 2つの不動点が現れる/消える |
| **トランスクリティカル** | dx/dt = rx − x² | 2 つの固定点交換の安定性 |
| **ピッチフォーク (超臨界)** | dx/dt = rx − x³ | 1 つの安定点が 2 つの安定点 + 1 つの不安定点に分割されます。
| **ピッチフォーク (未臨界)** | dx/dt = rx + x3 |不安定な枝は崩壊します (多くの場合壊滅的)。
| **ホップ** | 2Dシステム |固定小数点が不安定になり、リミットサイクルが発生 |
### 分岐図
安定性を示す、固定点とパラメーター値のプロット (実線 = 安定、破線 = 不安定)。ロジスティック マップの分岐図は、カオスへの周期 2 倍ルートと有名な **ファイゲンバウム定数** δ ≈ 4.669 (連続する分岐間隔間の普遍比) を明らかにします。

## 偏微分方程式 (PDE)
PDE には、複数の変数の関数とその偏導関数が含まれます。
### 2 次線形偏微分方程式の分類
Au_xx + 2Bu_xy + Cu_yy + ... = 0の場合:
|タイプ |状態 |行動 |例 |
|------|-----------|-----------|----------|
| **楕円** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 |波の伝播、シャープな特徴を維持 |波動方程式: u_tt = c²u_xx |
### 熱方程式
∂u/∂t = α ∂²u/∂x²
熱拡散、人口拡散、オプション価格設定をモデル化します (Black-Scholes)。
|プロパティ |声明 |
|----------|----------|
|スムージング |不連続な初期データからでも、瞬時に解がスムーズになります |
|最大原理 |最高温度は境界または初期時に発生します。
|時間可逆性 |不可逆的 — 逆方向に実行することはできません |
### 波動方程式
∂²u/∂t² = c² ∂²u/∂x²
弦の振動、音、電磁波をモデル化します。
|プロパティ |声明 |
|----------|----------|
|伝播 |外乱は速度 c で移動します。
|可逆性 |時間可逆 |
|ダランベールのソリューション | u(x,t) = f(x−ct) + g(x+ct) (左右の波の重ね合わせ) |
### ラプラスの方程式
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
解 (調和関数) は、定常状態の温度、静電位、非圧縮性流体の流れを表します。
|プロパティ |声明 |
|----------|----------|
|平均値プロパティ | u(x₀) = x₀ を中心とする円上の u の平均 |
|最大原理 |内部最大値または最小値はありません |
|独自性 |境界条件によって完全に決定される |
