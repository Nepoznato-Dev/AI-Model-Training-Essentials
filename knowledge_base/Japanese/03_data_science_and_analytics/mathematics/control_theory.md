# 制御理論
制御理論は、システムを希望どおりに動作させるための数学です。サーモスタットからオートパイロット、ロボットアームから化学反応器に至るまで、制御システムは望ましい動作を維持するために感知、決定、および動作します。この分野は、安定性、パフォーマンス、堅牢性を分析するための厳密なツールを提供します。これらの概念は、強化学習、ハイパーパラメータ調整、適応システムに移行しています。
---

## 基本的な概念
### 開ループと閉ループ
|タイプ |説明 |例 |利点 |
|------|---------------|----------|-----------|
| **オープンループ** |出力に依存しない制御アクション |洗濯機のタイマー |シンプル、センサー不要 |
| **閉ループ (フィードバック)** |制御動作は出力に依存します |サーモスタット、クルーズコントロール |外乱を排除し、堅牢 |
### ブロック図の要素
|要素 |記号 |機能 |
|----------|----------|----------|
| **植物** | G(s) |制御されているシステム |
| **コントローラー** | C(s) |制御アクションを計算します |
| **センサー** | H(s) |出力を測定する |
| **サミングジャンクション** | ⊕ |誤差を計算します: r − y |
| **参考** | r(t) |望ましい出力 |
| **エラー** | e(t) = r(t) − y(t) |希望と実際の違い |
| **騒動** | d(t) |プラントに影響を与える不要な入力 |
### 閉ループ伝達関数
標準的な負帰還システムの場合:
T(s) = C(s)G(s) / (1 + C(s)G(s)H(s))
|数量 |式 |
|----------|----------|
|開ループ伝達関数 | L(s) = C(s)G(s)H(s) |
|閉ループ伝達関数 | T(s) = L(s)/H(s) / (1 + L(s)) |
|誤差伝達関数 | E(s)/R(s) = 1 / (1 + L(s)) |
|感度 | S(s) = 1 / (1 + L(s)) |

## 伝達関数
**伝達関数** H(s) = Y(s)/X(s) は、ラプラス領域の線形時不変 (LTI) システムの入出力関係を表します。
### 標準フォーム
|システム |伝達関数 |パラメータ |
|----------|--------|----------|
| **一次** | K/(τs + 1) | K = ゲイン、τ = 時定数 |
| **二次** | Kωₙ²/(s² + 2ζωₙs + ωₙ²) | ωₙ = 固有振動数、ξ = 減衰比 |
| **インテグレーター** | K/秒 | — |
| **差別化要素** | Ｋさん | — |
| **遅延** | e^{−sT_d} | T_d = 時間遅延 |
### 二次システムの動作
|減衰比 ξ |行動 |ポールの位置 |
|-----------------|-----------|---------------|
| ξ = 0 |非減衰発振 |純粋な想像上の |
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 |過減衰 (低速、発振なし) |本物、独特 |
### パフォーマンス指標 (ステップ応答)
|メトリック |式 (2 次、不足減衰) |説明 |
|----------|---------------------------------|---------------|
|立ち上がり時間 (t_r) | ≈ 1.8/ωₙ | 10% から 90% に到達するまでの時間 |
|ピーク時間 (t_p) | π/(ωₙ√(1−ζ²)) |最初の最大値までの時間 |
|オーバーシュート (M_p) | e^{−πξ/√(1−ξ²)} × 100% |最終値を超える最大ピーク |
|セトリング時間 (t_s) | ≈ 4/(ζωₙ) |最終目標の 2% 以内に留まるまでの時間 |
|定常状態エラー |システムの種類に応じて異なります | t → ∞ | 望ましい値と実際の差

## PID コントローラー
**PID コントローラー** は、業界で最も広く使用されているコントローラーです (産業用コントローラーの 90% 以上)。
### PID 式
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
ラプラス領域の場合: C(s) = K_p + K_i/s + K_d s
|用語 |効果 |多すぎる |少なすぎる |
|------|----------|----------|---------------|
| **比例 (K_p)** |現在のエラーに反応します |発振、不安定性 |応答が遅い、エラーが大きい |
| **積分 (K_i)** |定常状態誤差を排除 |オーバーシュート、発振 |永続的なオフセット |
| **微分値 (K_d)** |将来の誤差を予測 (減衰) |ノイズ増幅 |妨害の除去が不十分 |
### PID 調整方法
|方法 |アプローチ |
|----------|----------|
| **ジーグラー・ニコルズ** |発振するまで K_u を増加します。 K_u と周期 P_u を使用してゲインを設定します。
| **コーエン・クーン** |ステップ応答パラメーター (ゲイン、時定数、デッドタイム) に基づく |
| **IMC (内部モデル制御)** |プロセスモデルに基づく;優れた堅牢性を提供します。
| **オートチューニング** |オンライン識別 + チューニング (多くの最新コントローラー) |
| **マニュアル** | K_p のみで開始し、オフセットを除去するために K_i を追加し、減衰のために K_d を​​追加します。
### ジーグラー・ニコルズ則
1. K_i = K_d = 0 を設定します。
2. 発振が持続するまで K_p を増加します: 最終ゲイン K_u、周期 P_u
3. ゲインを設定します。
|コントローラー | K_p |きい | K_d |
|----------|-----|-----|-----|
| P | 0.5K_u | — | — |
| PI | 0.45K_u | 1.2K_u/P_u | — |
| PID | 0.6K_u | 2K_u/P_u | K_u P_u/8 |

## 安定性解析
システムの出力が制限された入力に対して制限されたままであれば、システムは **安定** です (BIBO 安定性)。
### ポールベースの安定性
|状態 |安定性 |
|----------|----------|
|左半平面内のすべての極 (Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) |不安定 |
|虚軸上の極 (Re(s) = 0) |ぎりぎり安定 (または繰り返しでは不安定) |
### ラウス・ハーヴィッツ基準
極を明示的に計算せずに安定性を決定します。特性多項式係数から Routh 配列を構築します。
**ルール:** 最初の列の符号変更の数は、右半平面の極の数と等しくなります。
### ナイキスト安定性基準
開ループ周波数応答 L(jω) を複素平面にプロットします。
**ルール:** ナイキスト プロットが点 (−1, 0) を反時計回りに開ループの不安定な極の数と同じ回数だけ囲む場合、閉ループ システムは安定しています。
**ゲイン余裕:** 不安定になる前にどれだけゲインを増加できるか (実軸上のプロットから -1 までの距離)。
**位相余裕:** 不安定になる前にどの程度の位相遅れが増加する可能性があるか (ゲイン交差時のプロットから単位円までの角度)。
### ボード線図解析
ゲイン (dB) と位相 (度) と周波数 (対数スケール) をプロットします。
|メトリック |定義 |望ましい値 |
|------|-----------|------|
| **ゲインマージン (GM)** |位相 = −180°で 0 dB に達するまでゲインを増加 | > 6dB |
| **位相余裕 (PM)** |ゲインクロスオーバー時の位相 (0 dB) + 180° | > 45° |
| **ゲインクロスオーバー** |ゲイン = 0 dB の周波数 | — |
| **位相クロスオーバー** |位相 = −180°の周波数 | — |

## 状態空間表現
多入力多出力 (MIMO) システムの場合、状態空間形式は伝達関数よりも自然です。
### 標準フォーム
ẋ(t) = Ax(t) + Bu(t) (状態方程式)
y(t) = Cx(t) + Du(t) (出力式)
|マトリックス |名前 |寸法 |
|----------|------|----------|
|あ |システム/状態マトリックス | n × n |
| B |入力行列 | n × m |
| C |出力行列 | p × n |
| D |フィードスルーマトリックス | p×m |
### 状態空間からの伝達関数
G(s) = C(sI − A)⁻¹B + D
### 制御性と可観測性
|プロパティ |テスト |意味 |
|----------|------|----------|
| **制御可能** | Rank[C_B] = n (C_B = [B, AB, A²B, ...]) |任意の状態に切り替えることができます |
| **観測可能** | Rank[O_B] = n (O_B = [C; CA; CA²; ...]) |出力から状態を判断できる |
システムは、フィードバックによって安定化できるように制御可能であり、状態推定のために観察可能でなければなりません。
### 状態のフィードバック
u = −Kx + r (完全状態フィードバック)
閉ループ: ẋ = (A − BK)x + Br
**極の配置:** A − BK が目的の固有値 (極) になるように K を選択します。

## 最適な制御
### 線形二次レギュレータ (LQR)
最小化: J = ∫₀^∞ (xᵀQx + uᵀRu) dt
ここで、Q ≥ 0 (状態コスト) および R > 0 (制御コスト) です。
**解法:** u = −Kx ここで、K = R⁻¹BᵀP、P は **代数リカッチ方程式を解きます:**
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
|チューニング |効果 |
|----------|----------|
| Qを増やす |より速い応答、より多くの制御努力 |
| Rを大きくする |応答が遅くなり、制御の労力が減ります |
| Q ≫ R |積極的な制御 (高い K_p など) |
### カルマンフィルター
ガウス ノイズを伴う線形システムに最適な状態推定器。
**システムモデル:**
ẋ = Ax + Bu + w (プロセスノイズ w ~ N(0, Q))
y = Cx + v (測定ノイズ v ~ N(0, R))
**カルマン フィルター方程式:**
- 予測: x̂⁻ = Ax̂ + Bu、P⁻ = APAᵀ + Q
- 更新: K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻¹、x̂ = x̂⁻ + K(y − Cx̂⁻)、P = (I − KC)P⁻
カルマン フィルターは LQR デュアルであり、推定誤差の分散を最小限に抑えます。

制御理論は、システムに希望どおりの動作を確実に、堅牢に、効率的に実行させるための数学です。フィードバック、安定性、最適性の原則は普遍的であることが証明されており、ロボット工学から強化学習、経済学から生物学に至るまでの分野に現れています。データ サイエンティストにとって、制御理論は、適応システムを理解し、安定したトレーニング手順を設計し、動的環境と対話するインテリジェント エージェントを構築するための言語を提供します。
