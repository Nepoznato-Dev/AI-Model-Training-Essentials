# 量子力学
量子力学は、原子、電子、光子、自然界の基本粒子といった最小スケールの物理学の理論です。これは、古典力学の決定論的な世界を確率、重ね合わせ、もつれに置き換えます。直観に反する性質にもかかわらず、量子力学は科学全体の中で最も正確にテストされた理論です。今日、その原理は量子コンピューターを介したコンピューティングに直接関連しており、古典的なマシンよりも指数関数的に速く特定の問題を解決できることが期待されています。

## 波動と粒子の二重性
### ド・ブロイ波長
運動量 p を持つすべての粒子には、関連する波長があります。
λ = h/p = h/(mv)
|粒子 |典型的な λ |観測可能な波の挙動? |
|----------|-----------|--------------------|
|電子 (100 eV) | 0.12nm |はい (結晶回折) |
|プロトン | 0.003nm |はい (中性子散乱) |
|野球（40m/s） | 10⁻³⁴メートル |いいえ (小さすぎて検出できません) |
### 二重スリット実験
典型的な量子実験:
1. 2つのスリットから粒子（電子、光子）を1つずつ発射
2. 各粒子は検出器上の 1 点に到達します。
3. 時間の経過とともに、あたかも各粒子が両方のスリットを同時に通過したかのような干渉パターンが現れます。
4. 粒子がどのスリットを通過するかを計測すると干渉縞が消える
**結論:** 量子物体は純粋な粒子でも純粋な波でもない。それらは、観察されていない場合には波のような挙動を示し、測定される場合には粒子のような挙動を示します。

## 波動関数
＃＃＃ 意味
**波動関数** ψ(x, t) は量子システムを完全に記述します。これは、二乗係数が確率密度を与える複素数値関数です。
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### 正規化
確率の合計は 1 に等しくなければなりません。
∫ |ψ(x)|² dx = 1 (全空間にわたって)
### 生まれつきのルール
x と x + dx の間で粒子が見つかる確率:
P(x から x+dx) = |ψ(x)|² dx
固有状態 φₙ を持つ一般的なオブザーバブルの場合:
P(固有値 aₙ の測定) = |⟨φₙ|ψ⟩|²

## シュレーディンガー方程式
### 時間依存のシュレディンガー方程式
iℏ ∂ψ/∂t = Ĥψ
ここで、Ĥ は **ハミルトニアン演算子** (総エネルギー演算子) です。
### 時間に依存しないシュレーディンガー方程式
定常状態 (エネルギー固有状態) の場合:
Ĥψ = Eψ
これは固有値方程式です。許容エネルギー E は Ĥ の固有値です。
### 箱の中の粒子 (無限正方形ウェル)
最も単純な量子システム: 0 < x < L に閉じ込められた粒子。
|数量 |結果 |
|----------|----------|
|波動関数 | ψₙ(x) = √(2/L) sin(nπx/L) |
|エネルギーレベル | Eₙ = n²π²ℏ²/(2mL²) = n²h²/(8mL²) |
|基底状態 | n = 1、E₁ = h²/(8mL²) |
|ゼロ点エネルギー | E₁ > 0 (粒子は完全に静止することはできません) |
|量子数 | n = 1、2、3、... (正の整数のみ) |
### 量子調和発振器
V(x) = 1/2mω²x²
|数量 |結果 |
|----------|----------|
|エネルギーレベル | Eₙ = (n + 1/2)ℏω |
|ゼロ点エネルギー | E₀ = 1/2ℏω |
|間隔 | ΔE = ℏω (一様) |
|波動関数 |エルミート多項式 × ガウス |

## 演算子とオブザーバブル
量子力学では、すべての物理的観測値は **エルミート演算子**に対応します。
### キーオペレーター
|観測可能 |演算子 (位置空間) |固有値 |
|----------|---------------|---------------|
|ポジション | x̂ = x |すべて実数 x |
|勢い | p̂ = −iℏ ∂/∂x |すべて実数 p |
|エネルギー (ハミルトニアン) | Ĥ = −(ℏ²/2m)∂²/∂x² + V(x) | Eₙ (境界状態の離散) |
|角運動量 | L̂ = r × p̂ | ℏ√(l(l+1)) |
|スピン | Ŝ = (ℏ/2)σ (パウリ行列) | ±ℏ/2 (スピン-1/2 の場合) |
### 期待値
状態 ψ 上の観測可能な A を測定した平均結果:
⟨A⟩ = ⟨ψ|Â|ψ⟩ = ∫ ψ*(x) Â ψ(x) dx
### 通電関係
[Â, B̂] = ÂB̂ − B̂Â
|整流子 |結果 |重要性 |
|----------|----------|---------------|

## 不確定性原理
### ハイゼンベルクの不確定性原理
Δx・Δp ≧ ℏ/2
より一般的には、任意の 2 つのオブザーバブル A と B に対して、次のようになります。
ΔA · ΔB ≥ (1/2)|⟨[Â, B̂]⟩|
### 不確実性関係
|ペア |関係 |解釈 |
|------|----------|-----|
|ポジションの勢い | ΔxΔp ≥ ℏ/2 |両方を正確に知ることはできません。
|エネルギー時間 | ΔEΔt ≥ ℏ/2 |短命な状態のエネルギーは不確実です |
|角運動量 | ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| |すべてのコンポーネントを同時に知ることはできません。
**重要:** 不確実性は測定の乱れに関するものではなく、量子状態の基本的な特性です。粒子は、明確な位置と運動量を同時に持っているわけではありません。

## 量子状態と重ね合わせ
### ディラック記法 (括弧)
|記号 |名前 |意味 |
|----------|------|----------|
| \|ψ⟩ |ケット |状態ベクトル (列ベクトル) |
| ⟨ψ\| |ブラ |共役転置 (行ベクトル) |
| ⟨φ\|ψ⟩ |内積 |状態 φ | で求められる ψ の振幅
| \|ψ\|² |ノルム二乗 |確率 |
### 重ね合わせの原理
\|ψ₁⟩ と \|ψ₂⟩ が有効な量子状態である場合、線形結合も有効です。
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

ここで、 |α|² + |β|² = 1 (正規化)。
**測定:** 測定すると、システムは |α|² の確率で \|ψ₁⟩ または |β|² の確率で \|ψ₂⟩ に「崩壊」します。
### 量子ビット
**量子ビット** は量子ビット、つまり 2 レベルの量子システムです。
\|ψ⟩ = α\|0⟩ + β\|1⟩、ここで |α|² + |β|² = 1
|代表 | \|0⟩ | \|1⟩ |
|---------------|------|------|
|スピン |スピンアップ ↑ |スピンダウン ↓ |
|光子偏光 |水平 |垂直 |
|エネルギーレベル |基底状態 |興奮状態 |
|回路 | \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**ブロック球:** 量子ビットの状態は次のように記述できます。
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iφ} sin(θ/2)\|1⟩
ここで、θ ∈ [0, π] および φ ∈ [0, 2π)。状態空間は球です。

## もつれ
2 つの量子ビットは、それらの結合状態を個々の状態の積として書き込むことができない場合、**もつれ**となります。
### ベル ステート (最大限のもつれ)
|状態 |式 |名前 |
|------|-----------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) |ベルの状態 |
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) |ベルの状態 |
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) |ベルの状態 |
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) |一重項状態 |
### もつれの性質
|プロパティ |説明 |
|----------|---------------|
|相関関係 |一方の量子ビットを測定すると、距離に関係なく、もう一方の量子ビットが即座に決定されます。
|連絡がありません |エンタングルメントのみを使用して光より速く情報を送信することはできません。
|一夫一婦制 | A が B と最大限に絡み合った場合、C と絡み合うことはできません。
|もろさ |環境との相互作用によりエンタングルメント (デコヒーレンス) が破壊される |
### EPR のパラドックスとベルの定理
アインシュタイン、ポドルスキー、ローゼンは、量子力学は不完全（隠れた変数）でなければならないと主張しました。ベルは、あらゆる局所隠れ変数理論が特定の不等式を満たすことを示しました。実験はベルの不等式に違反し、量子力学を確認し、局所的な隠れ変数を除外します。

## 量子ゲート
量子ゲートは量子ビットに対する単一演算です。
### シングル量子ビットゲート
|ゲート |マトリックス |効果 |
|------|--------|----------|
| **パウリ-X** (非) | [[0,1],[1,0]] |ビット反転: \|0⟩ ↔ \|1⟩ |
| **パウリ-Y** | [[0,−i],[i,0]] |ビット + 位相反転 |
| **パウリ-Z** | [[1,0],[0,−1]] |位相反転: \|1⟩ → −\|1⟩ |
| **アダマール** (H) | (1/√2)[[1,1],[1,−1]] |重ね合わせを作成します: \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **フェーズ** (S) | [[1,0],[0,i]] | Z 周りの π/2 回転 |
| **T ゲート** | [[1,0],[0,e^{iπ/4}]] | Z 周りの π/4 回転 |
| **回転** Rₓ(θ) | cos(θ/2)I − i sin(θ/2)σₓ | X軸回りにθ回転 |
### 2量子ビットゲート
|ゲート |説明 |効果 |
|------|---------------|----------|
| **ありません** |制御されていない |コントロールが \|1⟩ | の場合、ターゲットを反転します。
| **CZ** |コントロールZ |コントロールが \|1⟩ | の場合、ターゲットに Z を適用します。

### もつれの作成
H を量子ビット 1 に適用し、次に量子ビット 1 を制御として CNOT を適用します。
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩
