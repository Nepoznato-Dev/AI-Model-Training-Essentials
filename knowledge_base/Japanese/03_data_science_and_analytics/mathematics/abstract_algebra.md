# 抽象代数
抽象代数では、代数構造、つまり特定の規則に従う演算を備えた集合を研究します。抽象代数は数値を扱う代わりに、公理を満たすあらゆるオブジェクトを扱います。この一般性は強力です。「群」について証明された定理は、整数、対称性、行列、順列、および量子状態に同時に適用されます。抽象代数は、暗号学、誤り訂正符号、量子コンピューティング、物理学全般で使用される対称性解析を支えています。

## グループ
**群** は最も基本的な代数構造です。シンメトリーの本質を捉えています。
＃＃＃ 意味
**グループ** (G, ∗) は、次を満たす二項演算 ∗ を持つ集合 G です。
|公理 |声明 |例 (ℤ、+) |
|------|-----------|------|
| **締め切り** | ∀a,b ∈ G: a ∗ b ∈ G | a + b は整数です |
| **結合性** | (a ∗ b) ∗ c = a ∗ (b ∗ c) | (a + b) + c = a + (b + c) |
| **アイデンティティ** | ∃e ∈ G: e ∗ a = a ∗ e = a | 0 + a = a + 0 = a |
| **逆** | ∀a ∈ G, ∃a⁻¹: a ∗ a⁻¹ = a⁻¹ ∗ a = e | a + (−a) = 0 |
演算が **可換** (a ∗ b = b ∗ a) である場合、その群は **アーベル型** と呼ばれます。
### グループの例
|グループ |セット |操作 |アイデンティティ |インバース |アーベル人？ |
|----------|-----|---------------|----------|-----------|----------|
| (ℤ、+) |整数 |追加 | 0 | −a |はい |
| (ℚ*、×) |ゼロ以外の有理数 |乗算 | 1 | 1/a |はい |
| (ℤ/nℤ, +) |残差 mod n |加算mod n | [0] | [該当なし] |はい |
| Sₙ | {1,...,n} の順列 |構成 | ID |逆順列 |いいえ (n ≥ 3) |
| GL(n, ℝ) |可逆な n×n 行列 |行列の乗算 |私ₙ | A⁻¹ |いいえ (n ≥ 2) |
| (ℝⁿ、+) | n 次元ベクトル |ベクトル追加 | 0 | −v |はい |
### グループと要素の順序
|用語 |定義 |例 |
|------|-----------|----------|
| **G の順序** (\|G\|) | G の要素の数 | \|ℤ/5ℤ\| = 5 |
| **要素 a の順序** (ord(a)) | aᵏ = e | の最小の正の k ord(2) in (ℤ/7ℤ)* = 3 (2³ = 8 ≡ 1 であるため) |
| **有限群** | \|G\|有限である | S₃ の次数は 6 |
| **無限グループ** | \|G\|は無限です | (ℤ、+) |
### サブグループ
G の **部分群** H は、それ自体が同じ操作に基づく群である部分集合 H ⊆ G です。
**サブグループ検定:** H は G のサブグループです。
1. H は空ではありません
2. すべての a、b ∈ H について: a ∗ b⁻¹ ∈ H
**例:**
- (ℤ, +) には、各 n ≥ 0 に対してサブグループ nℤ = {..., −2n, −n, 0, n, 2n, ...} があります。
- **自明な部分群** {e} と群 G 自体は常に部分群です
- S₃ では、集合 {id, (12)} は次数 2 のサブグループです
### 剰余類とラグランジュの定理
G の部分群 H および要素 a ∈ G の場合:
- **左剰余類:** aH = {ah : h ∈ H}
- **右剰余類:** Ha = {ha : h ∈ H}
**ラグランジュの定理:** 有限群 G と部分群 H の場合:
|H| |G| を割る
**結果:**
- 各要素の順序は |G| を分割します。
- |G| の場合= p (素数)、G は巡回 (自明でない部分群を持たない)
- a^|G| = e for all a ∈ G (フェルマーの小定理を一般化)
### 循環グループ
G のすべての要素が g のべき乗である g ∈ G が存在する場合、群 G は **巡回** です。 G = ⟨g⟩ と書きます。
|プロパティ |声明 |
|----------|----------|
|すべての巡回群はアーベル行列です。 — |
|加算中のℤ/nℤは循環的です | [1] によって生成されました。
| (ℤ/pℤ)* は素数 p に対して巡回です |ジェネレータはプリミティブルートと呼ばれます。
|分類 |すべての有限巡回群は、ある n | について ℤ/nℤ と同型です。

## 準同​​型性と同型性
**準同型性**は、グループ間の構造を保存するマップです。
### 定義
|用語 |定義 |例 |
|------|-----------|----------|
| **準同型性** | φ: G → H ただし、φ(ab) = φ(a)φ(b) | det: GL(n,ℝ) → ℝ* |
| **同型写像** |全単射準同型性 (グループは「同じ」) | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **カーネル** | ker(φ) = {g ∈ G : φ(g) = e_H} | ker(det) = SL(n, ℝ) |
| **画像** | im(φ) = {φ(g) : g ∈ G} | im(det) = ℝ* |
### 第一同型定理
φ: G → H が準同型の場合、次のようになります。
G / ker(φ) ≅ im(φ)
これは代数における最も重要な定理の 1 つです。これは、すべての準同型性が商に分解され、その後に同型性が続くと述べています。

## リング
**リング**はグループに 2 番目の演算を追加し、加算と乗算の両方で算術演算をモデル化します。
＃＃＃ 意味
**リング** (R, +, ×) は、次を満たす 2 つの演算を含む集合 R です。
|公理 |声明 |
|------|-----------|
| (R, +) はアーベル群 |加算は可換性、結合性があり、恒等度 0 を持ち、すべての要素は加法逆元を持ちます。
|乗算は結合的です | (a × b) × c = a × (b × c) |
|分配法則 | a(b + c) = ab + ac および (a + b)c = ac + bc |
乗算も可換で恒等式 (1) を持つ場合、R は **単一性を持つ可換環** です。
### リングの例
|リング |説明 |可換性? | 1 がありますか? |
|------|---------------|---------------|----------|
| (ℤ、+、×) |整数 |はい |はい |
| (ℚ、+、×) |根拠 |はい |はい |
| (ℝ、+、×) |実数 |はい |はい |
| (ℤ/nℤ、+、×) |整数 mod n |はい |はい |
| Mₙ(ℝ) | n×n 実数行列 |いいえ (n ≥ 2) |はい |
| ℝ[x] |実係数を持つ多項式 |はい |はい |
### 理想と商のリング
環 R の **理想的な** I は、次の部分集合です。
1. 追加中のサブグループです
2. 乗算を吸収します。すべての r ∈ R と a ∈ I、ra ∈ I と ar ∈ I の両方について
**商環** R/I: 要素は I の剰余類であり、演算は R から継承されます。
**例:** ℤ/nℤ = ℤ/nℤ は、ℤ と理想的な nℤ の商です。
### 統合ドメインとフィールド
|構造 |定義 |例 |
|----------|---------------|----------|
| **統合ドメイン** | 1 の可換環、ゼロ除数なし (ab = 0 → a = 0 または b = 0) | ℤ、ℚ[x]、ℝ[x] |
| **フィールド** |すべての非ゼロ要素が乗法逆元を持つ可換リング | ℚ、ℝ、ℂ、ℤ/pℤ (p 素数) |

## フィールド
体は、一般的に使用される最も構造化された代数オブジェクトです。ゼロ以外の要素はすべて加算、減算、乗算、除算できます。
### 主要なプロパティ
|プロパティ |声明 |
|----------|----------|
|すべてのフィールドは整数領域です。 — |
|すべての有限積分領域は体です。 — |
|特徴 | n・1 = 0 の最小の n、またはそのような n が存在しない場合は 0 |
|文字(ℚ) = 文字(ℝ) = 文字(ℂ) | = 0 |
| char(ℤ/pℤ) | = p (素数 p の場合) |
### 有限体 (ガロア体)
すべての素数べき pᵏ に対して、GF(pᵏ) または 𝔽_{pᵏ} で示される次数 pᵏ の固有の (同型までの) 有限体が存在します。
|フィールド |サイズ |建設 |アプリケーション |
|----------|------|---------------|---------------|
| GF(2) | 2 | {0, 1} mod 2 |バイナリ算術、XOR |
| GF(2ᵏ) | 2ᵏ | GF(2) 上の多項式 mod 既約多項式 | AES暗号化、CRCコード |
| GF(p) | p | ℤ/pℤ 素数 p の場合 |モジュラー算術、コーディング理論 |
| GF(pᵏ) |ぺ |拡張フィールド |リードソロモン符号、楕円曲線 |
**GF(2⁸)の構築** (AESで使用):
- GF(2) = {0, 1} から開始
- GF(2) に対して既約多項式 p(x) = x⁸ + x⁴ + x³ + x + 1 を選択します。
- 要素は、GF(2) の係数を持つ次数 < 8 の多項式です。
- 算術演算: 多項式加算 (XOR) および乗算 mod p(x)

## ベクトルスペース
**ベクトル空間** は、線形代数の基礎を形成する、追加およびスケールできるベクトルのセットです。
＃＃＃ 意味
体 F 上の **ベクトル空間** V は、次の集合です。
- ベクトル加算: V × V → V (V をアーベル群にする)
- スカラー倍算: F × V → V
満足: 結合性、加算の可換性、スカラー倍算の分配性、および 1・v = v。
### 主要な概念
|コンセプト |定義 |例 |
|----------|---------------|----------|
| **基礎** |線形独立スパニングセット | {e₁, e₂, ..., eₙ} for Fⁿ |
| **寸法** |任意の基底内のベクトルの数 |ディム(ℝ³) = 3 |
| **亜空間** |加算とスカラー乗算で閉じたサブセット | ℝ³ の原点を通る平面 |
| **線形結合** | Σ cᵢvᵢ ここで、 cᵢ ∈ F | 3v₁ + 2v₂ − v₃ |
| **スパン** |すべての線形結合のセット | Span({v₁, v₂}) = v₁、v₂ が独立している場合の平面 |
| **線形独立性** |他のベクトルの線形結合となるベクトルはありません。 ℝ3 の e₁、e₂、e₃ |
### 重要なベクトル空間
|スペース |説明 |寸法 |
|----------|---------------|----------|
| Fⁿ |フィールド F 上の n タプル | n |
| Pₙ(F) |次数 ≤ n の多項式 | n + 1 |
| Mₘₓₙ(F) | F 上の m × n 行列 |ん |
| C[a,b] | [a,b] の連続関数 |無限 |
| L²(ℝ) |平方積分可能関数 |無限 (ヒルベルト空間) |

## 線形マップと固有理論
### 線形マップ
**線形マップ** (線形変換) T: V → W は次を満たします。
- T(u + v) = T(u) + T(v)
- すべてのスカラー c の T(cv) = cT(v)
|コンセプト |定義 |例 |
|----------|---------------|----------|
| **カーネル** | {v ∈ V : T(v) = 0} |行列の空スペース |
| **画像** | {T(v) : v ∈ V} |行列の列空間 |
| **ランクヌルリティ定理** | dim(ker T) + dim(im T) = dim(V) |基本的な制約 |
| **行列表現** | T(v) = ある行列 A の Av |有限次元空間間のあらゆる線形マップ |
### 固有値と固有ベクトル
線形マップ T: V → V (または行列 A) の場合:
**固有値方程式:** Av = λv、ここで v ≠ 0
|用語 |定義 |
|------|-----------|
| **固有値** λ |ある v ≠ 0 に対して Av = λv となるようなスカラー |
| **固有ベクトル** v | Av = λv | を満たす非ゼロベクトル
| **特性多項式** | det(A − λI) = 0 |
| **固有空間** | {v : Av = λv} — λ のすべての固有ベクトルのセット (プラス 0) |
| **スペクトル** |すべての固有値のセット |
### 固有値の計算
2×2 行列 A = [[a, b], [c, d]] の場合:
- 特性多項式: λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2
**主要なプロパティ:**
- 固有値の合計 = トレース(A) = 対角要素の合計
- 固有値の積 = det(A)
### 対角化
行列 A は、n 個の線形独立固有ベクトル (A は n×n) を持っている場合、**対角化可能**です。
A = PDP⁻¹ の場合、D は対角線です:
- Aᵏ = PDᵏP⁻¹ (高速行列累乗)
- D には対角線上の固有値が含まれます
- P には列として固有ベクトルが含まれます
**スペクトル定理:** すべての実対称行列は、直交行列によって対角化できます。その固有値は実数です。

## アプリケーション
### 符号化理論 (誤り訂正符号)
有限体は、最新の誤り訂正コードの基礎です。
|コード |フィールド |修正 |アプリケーション |
|------|----------|----------|---------------|
|ハミングコード | GF(2) |ブロックごとに 1 つのエラー | RAM ECC、初期のネットワーキング |
|リードソロモン | GF(2ᵏ) |複数のエラー | CD、DVD、QRコード、衛星通信 |
| BCHコード | GF(2ᵏ) |複数のエラー |フラッシュメモリ、衛星 |
| LDPC 符号 | GF(2) |複数のエラー | Wi-Fi (802.11n)、DVB-S2、5G |
**リードソロモン符号化:** データを GF(2ᵏ) 上の多項式として扱い、いくつかの点で評価します。たとえ一部の評価が壊れていたとしても、元の多項式を復元することができます。
### 量子コンピューティング
量子状態は複素ベクトル空間 (ヒルベルト空間) に存在します。量子ゲートはユニタリ行列です。
|量子の概念 |代数構造 |
|-|-----------------|
|量子ビット | ℂ² の単位ベクトル (複素 2D ベクトル空間) |
|量子ゲート |ユニタリ行列 U ∈ U(2ⁿ) |
|測定 |射影演算子 |
|もつれ |分離不可能なテンソル積の状態 |
|クローン作成のない定理 |線形マップは未知の量子状態をコピーできません。
**単一量子ビットゲート:**
|ゲート |マトリックス |効果 |
|------|--------|----------|
|パウリ-X (ない) | [[0,1],[1,0]] |ビットフリップ |
|パウリZ | [[1,0],[0,−1]] |位相反転 |
|アダマール | (1/√2)[[1,1],[1,−1]] |重ね合わせを作成します |
|ない | 4×4制御ゲート | 2つの量子ビットをもつれさせる |
