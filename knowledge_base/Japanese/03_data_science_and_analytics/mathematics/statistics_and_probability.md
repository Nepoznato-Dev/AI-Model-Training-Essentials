# 統計と確率
確率と統計は、データ サイエンス、機械学習、科学研究の数学的基礎です。確率は、出来事が起こる可能性を示します。統計は、データから結論を引き出す方法を示します。これらを組み合わせることで、不確実性が定量化可能で管理可能な知識に変わります。
---

## 確率理論
### 中心となる概念
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **サンプル空間** |考えられるすべての結果のセット |サイコロを振る: {1, 2, 3, 4, 5, 6} |
| **イベント** |サンプル空間のサブセット |偶数のローリング: {2, 4, 6} |
| **確率** |尤度を測定する 0 から 1 までの数値 | P(ローリング6) = 1/6 |
| **条件付き確率** | P(A|B): B が発生した場合に A が発生する確率 | P(雨 | 曇り) |
| **独立** |一方が他方に影響を与えないイベント |コイン投げは独立しています |
### 確率ルール
|ルール |式 |使用例 |
|------|--------|----------|
| **加算ルール** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | A または B の確率 |
| **乗算のルール** | P(A ∩ B) = P(A) × P(B|A) | A と B の確率 |
| **補完ルール** | P(A ではない) = 1 − P(A) |イベントが発生しない確率 |
| **総確率の法則** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) |相互に排他的なイベントによるパーティショニング |
| **ベイズの定理** | P(A|B) = P(B|A) × P(A) / P(B) |信念を証拠で更新する |
### 確率分布
|配布 |タイプ |主要なパラメータ |使用例 |
|---------------|------|-----|----------|
| **通常 (ガウス)** |連続 |平均 (μ)、標準偏差 (σ) |自然現象、測定誤差 |
| **二項** |離散 | n (試行回数)、p (確率) |成功/失敗のカウント |
| **ポアソン** |離散 | λ (レート) |時空を超えた稀な出来事 |
| **指数関数** |連続 | λ (レート) |イベント間の時間 |
| **制服** |両方 | a、b (境界) |同様に起こり得る結果 |
| **カイ二乗** |連続 | k (自由度) |適合度テスト |
| **t-分布** |連続 | ν (自由度) |小規模サンプル推論 |
### ディストリビューションの主要なプロパティ
|プロパティ |説明 |
|----------|---------------|
| **平均 (期待値)** |分布の重心: E[X] = Σ xᵢ × P(xᵢ) |
| **分散** |平均値の周囲の広がり: Var(X) = E[(X − μ)²] |
| **標準偏差** |分散の平方根。データと同じ単位 |
| **歪度** |分布の非対称性 |
| **尖度** | 「尾っぽさ」 — 尾の重さ |

## 統計的推論
### 記述統計と推論統計
| |説明 |推測 |
|---|-------------|---------------|
| **目的** |データの要約と説明 |サンプルから母集団についての結論を導き出す |
| **ツール** |平均、中央値、最頻値、標準偏差、グラフ |仮説検定、信頼区間、回帰 |
| **範囲** |あなたが持っているデータのみ |サンプルを超えて一般化する |
### 仮説検証フレームワーク
|ステップ |説明 |
|------|---------------|
| 1. **仮説を立てる** |帰無仮説 (H₀): 効果なし。代替 (H₁): 効果は存在します |
| 2. **有意水準を選択** | α＝0.05（従来） |
| 3. **テストを選択** |データタイプ、サンプルサイズ、仮定に基づく |
| 4. **検定統計量を計算** |選択したテストによって異なります |
| 5. **p 値を求める** | H₀ が true の場合にデータを観測する確率 |
| 6. **決断を下す** | p < α の場合、H₀ を拒否します。それ以外の場合、H₀ | を拒否できません。
### 一般的な統計検定
|テスト |いつ使用するか |比較するもの |
|------|---------------|------|
| **t 検定** | 1 ～ 2 グループの平均を比較する |値に対するグループ平均、または相互のグループ平均 |
| **カイ二乗検定** |カテゴリデータ |観測された周波数と期待される周波数 |
| **分散分析** | 3 つ以上のグループの平均を比較する |グループ間分散とグループ内分散 |
| **マン・ホイットニー U** | t 検定に代わるノンパラメトリック | 2 つのグループの順位分布 |
| **ピアソン相関** | 2 つの連続変数間の線形関係 | −1 から +1 までの r 値 |
| **スピアマン相関** |単調関係（ランクベース） |順序データまたは非正規データの ρ 値 |
### 信頼区間
信頼区間は、母集団パラメータの妥当な値の範囲を示します。
- **平均値の 95% CI** (既知の σ): x̄ ± 1.96 × (σ / √n)
- **解釈**: 「母集団の真の平均値がこの範囲内にあると 95% 確信しています。」
- **CI が広い** = 不確実性が高くなります (サンプルが小さい、変動性が高い、または信頼水準が高い)

## 回帰分析
### 回帰の種類
|タイプ |従属変数 |使用例 |
|-----|--------|----------|
| **線形回帰** |連続 |住宅価格、販売の予測 |
| **ロジスティック回帰** |バイナリ (0/1) |分類: スパム検出、病気の診断 |
| **多項式回帰** |連続（曲線） |成長曲線、非線形傾向 |
| **重回帰** |連続 (2 つ以上の予測子) |交絡因子の制御 |
| **リッジ/なげなわ** |連続 (正規化) |過学習の防止、特徴の選択 |
### 線形回帰の基本
モデル: **y = β₀ + β₁x + ε**
|コンポーネント |意味 |
|----------|----------|
| β₀ (切片) | x = 0 の場合の y の値 |
| β₁ (傾き) | x の 1 単位の変化に対する y の変化 |
| ε (誤差項) |説明できない変化 |
**主要な指標:**
- **R² (決定係数)**: モデルによって説明される分散の割合 (0 ～ 1)
- **調整済み R²**: 予測変数の数に対してペナルティが課される R²
- **RMSE**: 二乗平均平方根誤差 — y と同じ単位の平均予測誤差
### 線形回帰の仮定
|仮定 |意味 |確認方法 |
|----------|--------------|--------------|
| **直線性** | X と Y の関係は線形です |散布図 |
| **独立** |観測は独立しています |研究デザイン |
| **等分散性** |残差の定数分散 |残りのプロット |
| **正常** |残差は正規分布します。 Q-Q プロット、シャピロ-ウィルク検定 |
| **多重共線性なし** |予測変数の相関性は高くありません。 VIF (分散インフレ率) |

## ベイズ統計
### 頻度主義とベイズ主義
| |頻繁に使う人 |ベイジアン |
|---|-------------|----------|
| **確率とは** |長期的な頻度 |信念の度合い |
| **パラメータは** |修正済みだが不明 |分布を伴う確率変数 |
| **用途** | p 値、信頼区間 |事後分布、信頼区間 |
| **強み** |客観的、確立された |事前知識を組み込み、直感的に解釈 |
### ベイズの定理の実践
**事後 = (可能性 × 事前) / 証拠**
例 - 医療検査:
- 病気の有病率: 1% (以前)
・検査感度：95％（真陽性率）
- 検査特異度: 90% (真陰性率)
- 検査結果が陽性の場合: P(病気 | 陽性) = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99) ≈ 8.8%
この直観に反する結果 (病気がまれな場合、ほとんどの陽性結果は偽陽性である) は **基礎率の誤謬** であり、ベイズ主義の考え方が重要である理由を示しています。

## 実践的なヒント
- **統計テストを実行する前に、必ずデータを視覚化してください**
- **前提条件を確認** - 違反があると結果が無効になる可能性があります
- **効果の大きさは重要です** - 統計的に有意な結果は実質的に無意味である可能性があります
- **相関関係は因果関係ではありません** - 強い相関関係であっても交絡因子が存在する可能性があります
- **複数の比較**により偽陽性率が増大 - 補正を適用 (Bonferroni、FDR)
- **p 値だけでなく信頼区間をレポート**
---

## なぜこれが重要なのか
統計は、科学研究、ビジネス分析、機械学習の根幹です。これがなければ、信号とノイズを区別したり、ランダムな変動から実際の影響を特定したり、定量化された不確実性を使用して予測を行うことはできません。 A/B テストを分析する場合でも、ML モデルをトレーニングする場合でも、研究論文を読む場合でも、統計リテラシーは不可欠です。
