# 信号処理
信号処理は、時間、空間、または周波数とともに変化する物理量の表現である信号を分析、変更、合成する科学です。音声、画像、ビデオ、センサーデータ、脳波、株価、すべてが信号です。信号処理の数学的ツール (フーリエ変換、フィルター、サンプリング理論) は、機械学習、通信、医療画像処理、およびデータを扱うほぼすべての分野の基礎です。
---

## 信号とシステム
### 信号の分類
|タイプ |説明 |例 |
|------|-------------|----------|
| **連続時間** |すべての t ∈ ℝ | に対して定義されます。オーディオ電圧、温度 |
| **離散時間** |整数インデックス n | で定義されます。サンプリングされたオーディオ、ピクセル値 |
| **アナログ** |時間と振幅が連続 |ビニールレコードの溝 |
| **デジタル** |時間的に離散的で量子化された振幅 | MP3ファイル、JPEG画像 |
| **定期的** |すべての t に対して x(t + T) = x(t) |正弦波、方形波 |
| **非周期的** |繰り返しパターンなし |スピーチ、音楽 |
| **決定論的** |完全に予測可能 |正弦波 |
| **確率的** |ランダム性が含まれています |騒音・株価 |
### システムプロパティ
|プロパティ |定義 |例 |
|----------|-----------|----------|
| **線形** | T[ax₁ + bx₂] = aT[x₁] + bT[x₂] |ローパスフィルター |
| **時間不変** |入力のシフト → 出力の同じシフト |任意の固定フィルター |
| **因果関係** |出力は現在と過去の入力のみに依存します。リアルタイムシステム |
| **安定した (BIBO)** |境界付き入力 → 境界付き出力 |適切に設計されたフィルター |
| **記憶のない** |出力は現在の入力のみに依存します。アンプ |

## フーリエ変換
**フーリエ変換**は、信号をその構成周波数に分解します。
### 連続フーリエ変換
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
逆: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### フーリエ変換ペア
|時間領域 x(t) |周波数領域 X(f) |
|---------------------|---------------------|
|方形パルス |シンク関数 |
|シンク関数 |方形パルス |
|ガウス e^{−at²} |ガウス (√(π/a))e^{−π²f²/a} |
|ディラック デルタ δ(t) | 1 (すべての周波数) |
|複素指数 e^{j2πf₀t} | δ(f − f₀) |
|コサイン cos(2πf₀t) | 1/2[δ(f−f₀) + δ(f+f₀)] |
### 主要なプロパティ
|プロパティ |タイムドメイン |周波数ドメイン |
|----------|---------------|------|
|直線性 | ax₁(t) + bx₂(t) | aX₁(f) + bX₂(f) |
|タイムシフト | x(t − t₀) | X(f)e^{−j2πft₀} |
|周波数シフト | x(t)e^{j2πf₀t} | X(f − f₀) |
|コンボリューション | x₁(t) ∗ x₂(t) | X₁(f) · X₂(f) |
|乗算 | x₁(t) · x₂(t) | X₁(f) ∗ X₂(f) |
|差別化 | DX/DT | j2πf X(f) |
|パーシヴァルの定理 | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**畳み込み定理:** 時間の畳み込み = 周波数の乗算。これは最も重要な特性です。これにより、高価な畳み込み演算が安価な乗算に変わります。
### 離散フーリエ変換 (DFT)
シーケンス x[0]、x[1]、...、x[N−1] の場合:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}、k = 0, 1, ..., N−1
|プロパティ |値 |
|----------|----------|
|入力 | N 個の実数または複素数のサンプル |
|出力 | N 個の複素周波数ビン |
|周波数分解能 | f_s/N (f_s はサンプリング レート) |
|ナイキスト周波数 | f_s/2 (表現可能な最大周波数) |
|複雑さ | O(N²) 直接計算 |
### 高速フーリエ変換 (FFT)
**FFT** は、O(N²) ではなく O(N log N) で DFT を計算します。
| N | O(N²) の操作 | O(N log N) 操作 |スピードアップ |
|---|-----------------|-----------|----------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10¹² | 20,971,520 | 52,428× |
FFT は、これまでに発明された最も重要なアルゴリズムの 1 つです。リアルタイムの音声処理、画像圧縮 (JPEG)、無線通信 (OFDM)、スペクトル分析が可能になります。
---

## ラプラス変換
**ラプラス変換**は、フーリエ変換を拡張して、不安定なシステムと過渡解析を処理します。
F(s) = ∫₀^∞ f(t) e^{−st} dt、s = σ + jω
### 一般的なラプラス変換
| f(t) | F(s) |収束領域 |
|------|------|-----------|
| δ(t) (インパルス) | 1 |すべての |
| u(t) (ステップ) | 1/秒 | Re(s) > 0 |
| e^{−at}u(t) | 1/(s+a) | Re(s) > −a |
| tⁿu(t) | n!/s^{n+1} | Re(s) > 0 |
| sin(ωt)u(t) | ω/(s²+ω²) | Re(s) > 0 |
| cos(ωt)u(t) | s/(s²+ω²) | Re(s) > 0 |
### フーリエ変換への接続
σ = 0 (s = jω) の場合、ラプラス変換はフーリエ変換に帰着します。ラプラス変換は、成長/衰退 (σ) に関する情報を含めることにより、より完全な画像を提供します。
---

## Z 変換
**Z 変換** は、ラプラス変換と等価な離散時間変換です。
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### 一般的な Z 変換
| x[n] | X(z) |ロック |
|------|------|-----|
| δ[n] | 1 |すべてのz |
| u[n] (ステップ) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|a\| |
|なⁿu[n] | z/(z−a)² | \|z\| > \|a\| |
| sin(ω₀n)u[n] | z sin(ω₀)/(z²−2z cos(ω₀)+1) | \|z\| > 1 |
### 他の変換との関係
|変換 |ドメイン |変数 |
|----------|----------|----------|
|フーリエ |連続周波数 | f または ω |
|ラプラス |複素周波数 | s = σ + jω |
| Z 変換 |複素周波数 (離散) | z = e^{sT} |
Z 平面内の単位円 (|z| = 1) はフーリエ変換に対応します。
---

## フィルター
フィルターは、特定の周波数成分を選択的に通過またはブロックします。
### フィルターの種類
|タイプ |パス |ブロック |アプリケーション |
|------|----------|----------|---------------|
| **ローパス** |低周波 |高周波 |スムージング、アンチエイリアス |
| **ハイパス** |高周波 |低周波 |エッジ検出、ノイズ除去 |
| **バンドパス** |周波数範囲 |範囲外 |チャンネル選択（ラジオ） |
| **バンドストップ (ノッチ)** |範囲を除くすべて |特定の範囲 |電源ラインのハム除去 |
### FIR フィルターと IIR フィルター
|プロパティ | FIR (有限インパルス応答) | IIR (無限インパルス応答) |
|----------|----------------------------|----------------------------|
|インパルス応答 |有限期間 |持続時間は無限 |
|安定性 |常に安定 |不安定になる可能性があります |
|フェーズ |正確に線形にすることができます |一般に非線形位相 |
|フィードバック |いいえ |はい |
|計算 |さらに多くの係数が必要です |同じロールオフの係数が少なくなる |
|デザイン |ウィンドウイング、パークス・マクレラン |バターワース、チェビシェフ、楕円 |
|伝達関数 | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### フィルター設計仕様
|パラメータ |説明 |
|----------|---------------|
| **通過帯域** |最小限の損失で通過すべき周波数範囲 |
| **阻止帯域** |減衰すべき周波数範囲 |
| **カットオフ周波数** |通過帯域と阻止帯域の境界 |
| **リップル** |通過帯域 (または阻止帯域) ゲインの変動 |
| **ロールオフ** |減衰率 (オクターブまたはディケードごとの dB) |
| **遷移バンド** |通過帯域と阻止帯域の間の領域 |
### 一般的なフィルター設計
|デザイン |特徴 |使用例 |
|----------|----------------|----------|
| **バターワース** |最大限に平坦な通過帯域、中程度のロールオフ |汎用 |
| **チェビシェフ I 型** |通過帯域のリップル、急峻なロールオフ |ロールオフが重要な場合 |
| **チェビシェフ II 型** |阻止帯域のリップル、平坦な通過帯域 |通過帯域の平坦性が重要な場合 |
| **楕円 (カウアー)** |両方のリップル、最も急なロールオフ |必要な最小注文数 |
| **ベッセル** |線形位相 (最大限に平坦な群遅延) |波形形状の保持 |

## サンプリング理論
### ナイキスト・シャノンのサンプリング定理
サンプリング レートが最大周波数の 2 倍を超える場合、連続信号はサンプルから完全に再構築できます。
f_s > 2f_max
|用語 |定義 |
|------|-----------|
| **サンプリング レート** (f_s) | 1 秒あたりのサンプル数 |
| **ナイキストレート** | 2f_max (最小サンプリング レート) |
| **ナイキスト周波数** | f_s/2 (表現可能な最大周波数) |
| **エイリアス** | f_s < 2f_max | の場合、高周波が低周波に見せかけます。
### 一般的なサンプリングレート
|アプリケーション |レート |ナイキスト周波数 |
|-----------|------|--------|
|電話演説 | 8kHz | 4kHz |
|オーディオCD | 44.1kHz | 22.05kHz |
|プロオーディオ | 48kHz | 24kHz |
|ハイレゾオーディオ | 96kHz | 48kHz |
|ビデオ (30 fps) | 30 Hz (時間的) | 15Hz |
### アンチエイリアシング
サンプリング前に、**アンチエイリアシング フィルター** (ローパス) によって f_s/2 を超える周波数が除去され、エイリアシングが防止されます。

## ウィンドウ処理
信号の有限セグメントを分析する場合、暗黙的に長方形のウィンドウを乗算し、スペクトル漏れを引き起こします。 **ウィンドウ関数** により、この漏れが軽減されます。
### 一般的なウィンドウ
|ウィンドウ |メインローブ幅 |サイドローブレベル |使用例 |
|------|----------------|------|----------|
|長方形 |最も狭い | −13dB |解像度が最も重要な場合 |
|ハン | 2×長方形 | −31dB |汎用 |
|ハミング | 2×長方形 | −41dB |最近傍サイドローブの減少 |
|ブラックマン | 3×長方形 | −58dB |ハイダイナミックレンジ |
|カイザー |調整可能 |調整可能 (β経由) |トレードオフが調整可能な場合 |
### スペクトル漏れ
信号をウィンドウで乗算すると、そのスペクトルがウィンドウのスペクトルと畳み込まれます。メインローブが広いと周波数分解能が低下します。下部サイドローブにより漏れが軽減されます。
---

## ウェーブレット
**ウェーブレット**は、多重解像度信号解析に使用される小さな局所的な波のような関数です。
### ウェーブレット変換
フーリエ変換 (グローバルな周波数情報を与える) とは異なり、ウェーブレット変換は **時間-周波数** の位置特定を与えます。
|変換 |時間解像度 |周波数分解能 |
|----------|----------------|----------|
|フーリエ |なし (グローバル) |素晴らしい |
|ショートタイムFT |固定 (ウィンドウ サイズ) |修正済み |
|ウェーブレット |可変（高周波得意） |可変（低周波が得意） |
### 一般的なウェーブレット ファミリ
|家族 |プロパティ |アプリケーション |
|----------|----------|---------------|
| **ハール** |最も単純な、不連続な |エッジ検出、迅速な分析 |
| **ドーベシー** (dbN) |コンパクトなサポート、N の消滅瞬間 |圧縮、ノイズ除去 |
| **シムレット** |ほぼ対称的なドーベシー |位相歪みの低減 |
| **コイフレット** |モーメント条件に合わせて設計 |信号処理 |
| **モレ** |ガウス ウィンドウ正弦波 |時間周波数解析 |
| **メキシカンハット** |ガウスの二次導関数 |特徴検出 |
### ウェーブレットの応用
|アプリケーション |ウェーブレットがどのように役立つのか |
|-----------|-----------|
|画像圧縮 (JPEG 2000) |エッジでは DCT よりも優れた多重解像度表現 |
|ノイズ除去 |小さなウェーブレット係数のしきい値 (信号は大きな係数にあります) |
|特徴検出 |時系列のエッジ検出、トランジェント検出 |
|心電図分析 | QRS 群の検出、不整脈の分類 |
|耐震解析 |地層の特定、地震信号処理 |

＃＃ まとめ
|ツール |ドメイン |重要な洞察 |
|------|--------|---------------|
|フーリエ変換 |時間 → 周波数 |信号は正弦波の合計です。
|ラプラス変換 |時間 → 複素周波数 |過渡現象と安定性を処理 |
| Z 変換 |離散時間 → 複素数 |デジタルフィルターの解析と設計 |
| FFT |効率的な DFT 計算 | O(N²) の代わりに O(N log N) |
|フィルター |周波数の選択 |必要なものは渡し、必要のないものはブロック |
|サンプリング定理 |連続 ↔ 離散 |十分な速さでサンプルを採取し、何も失わない |
|ウィンドウ処理 |時間と周波数のトレードオフ |分解能とリークのバランスをとる |
|ウェーブレット |多重解像度解析 |時間と周波数の両方でローカル |
信号処理は、データの理解、分析、操作のための数学的基盤を提供します。時系列、音声、画像、またはセンサー データを処理するすべての機械学習パイプラインは、信号処理の概念を暗黙的に使用します。特にフーリエ変換は、データ サイエンティストにとって微積分の次に最も重要な数学ツールであることは間違いありません。
