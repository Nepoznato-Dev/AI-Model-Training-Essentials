# グラフ理論
**グラフ** は、エッジ (リンク) で接続された頂点 (ノード) で構成される数学的構造です。グラフは、ソーシャル ネットワーク、ロードマップ、ニューラル ネットワーク、依存関係、通信チャネルなどの関係をモデル化します。グラフ理論 (これらの構造の研究) は、コンピューター サイエンス、オペレーション リサーチ、データ サイエンスの中心となるアルゴリズムと定理を提供します。
---

## 基本的な概念
### 定義
|用語 |定義 |表記法 |
|------|-----------|----------|
| **グラフ** |頂点とエッジのペア G = (V, E) | G |
| **頂点 (ノード)** | V | の要素v、u、w |
| **エッジ** | 2 つの頂点間の接続 | e = (u, v) または {u, v} |
| **注文** |頂点の数 | \|V\| = n |
| **サイズ** |エッジの数 | \|E\| =m |
| **学位** |頂点に付随するエッジの数 |度(v) |
| **パス** |エッジによって接続された一連の個別の頂点 | v₁、v₂、...、vₖ |
| **サイクル** |同じ頂点で始まり同じ頂点で終わるパス | v₁ → v₂ → ... → vₖ → v₁ |
| **接続済み** |パスは頂点のすべてのペアの間に存在します。 — |
| **コンポーネント** |最大接続部分グラフ | — |
| **サブグラフ** | V と E のサブセットから形成されたグラフ | H ⊆ G |
### グラフの種類
|タイプ |説明 |例 |
|------|-------------|----------|
| **方向性なし** |エッジには方向がありません |友好ネットワーク |
| **指示 (ダイグラフ)** |エッジには方向があります (円弧) | Web ページのリンク |
| **加重** |エッジには数値が含まれます。道路距離 |
| **加重なし** |すべてのエッジは等価です |社会的なつながり |
| **シンプル** |ループや複数のエッジはありません |ほとんどの教科書のグラフ |
| **マルチグラフ** |同じ頂点間の複数のエッジは許可されます。飛行ルート（都市間の複数便） |
| **完了** |すべての頂点のペアは接続されています。 Kₙ には n(n−1)/2 のエッジがあります |
| **二部構成** |頂点は 2 つのグループに分割されます。エッジはグループのみを交差します |ユーザーアイテムの推奨マトリックス |
| **平面** |エッジを交差させずに描画可能 |回路基板のレイアウト |
| **木** |接続された非循環グラフ |デシジョン ツリー、ファイル システム |
| **DAG** |有向、有向サイクルなし |タスクのスケジューリング、依存関係グラフ |
### ハンドシェイクの補題
すべての頂点次数の合計は、エッジ数の 2 倍に等しくなります。
Σᵥ 度(v) = 2|E|
**結果:** すべてのグラフには偶数の奇数次の頂点があります。
**例:** 10 人のパーティーで、全員がちょうど 3 人と握手をする場合: Σ deg = 30 したがって、|E| = 合計 15 回の握手。

## グラフ表現
グラフをメモリに保存する方法によって、グラフ上で実行するすべてのアルゴリズムの効率が決まります。
|代表 |スペース |エッジ ルックアップ |近傍を反復する |最適な用途 |
|-----|----------|---------------|----------|----------|
| **隣接行列** | O(n²) |お(1) | O(n) |緻密なグラフ、素早いエッジテスト |
| **隣接リスト** | O(n + m) | O(度(v)) | O(度(v)) |疎なグラフ、ほとんどの実世界のネットワーク |
| **エッジ リスト** | O(m) | O(m) | O(m) |シンプルなアルゴリズム、Kruskal の MST |
| **発生率マトリックス** | O(n・m) | O(m) | O(m) |特殊なアルゴリズム |
### 隣接行列
n × n 行列 A。エッジ (i,j) が存在する場合は A[i][j] = 1、そうでない場合は 0。重み付きグラフの場合、A[i][j] = 重みです。
**プロパティ:**
- 無向グラフの対称
- Aᵏ[i][j] = i から j までの長さ k の歩行の数
- A の固有値は構造特性を明らかにします (スペクトル グラフ理論を参照)
### 隣接リスト
各頂点 v がその近傍のリストを格納する配列 (またはハッシュ マップ)。
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

これは、実際のグラフの最も一般的な表現であり、通常は疎 (m ≪ n²) です。

## 木
**ツリー**は、接続された非循環の無向グラフです。 **フォレスト** は、互いに素な木の結合です。
### 木の性質
n 個の頂点を持つツリーの場合:
- 正確に n − 1 個のエッジがあります
- 任意の 2 つの頂点間にはパスが 1 つだけ存在します
- エッジを削除すると切断されます
- エッジを追加すると、正確に 1 つのサイクルが作成されます
### 木の種類
|タイプ |説明 |アプリケーション |
|------|---------------|---------------|
| **根付いた木** |ルートとして指定された 1 つの頂点 |ファイル システム、組織図 |
| **二分木** |各ノードには最大 2 つの子があります。 BST、式解析、決定木 |
| **バランスの取れたツリー** |高さは O(log n) | AVL ツリー、赤黒ツリー (データベース) |
| **スパニング ツリー** |すべての頂点を含むツリーであるサブグラフ |ネットワーク設計、近似アルゴリズム |
| **最小スパニング ツリー** |エッジの総重みが最小のスパニング ツリー |ネットワーク設計、クラスタリング |
| **スターグラフ** | 1 つの中央ノードが他のすべての中央ノードに接続される |ハブアンドスポーク ネットワーク |
### バイナリ ツリーのプロパティ
|プロパティ |式 |
|----------|----------|
|深さ d の最大ノード数 | 2ᵈ |
|高さ h のツリー内の最大ノード数 | 2ʰ⁺¹ − 1 |
| n ノードの最小高さ | ⌊log₂(n)⌋ |
|完全なバイナリ ツリーのリーフ ノード |内部ノード + 1 |
### ツリートラバーサル
|トラバーサル |注文 |使用例 |
|----------|----------|----------|
| **予約注文** |ルート→左→右 |ツリー、プレフィックス式をコピーする |
| **注文中** |左→ルート→右 | BST | からのソートされた出力
| **注文後** |左→右→ルート |ツリー、後置式の削除 |
| **レベルオーダー (BFS)** |レベルごと、左から右へ |重み付けされていないツリーの最短パス |

## グラフの走査
トラバーサル アルゴリズムは、到達可能なすべての頂点を体系的に訪問します。
### 幅優先検索 (BFS)
**キュー**を使用して、頂点をレイヤーごとに探索します。
|プロパティ |値 |
|----------|----------|
|データ構造 |キュー (FIFO) |
|時間計算量 | O(V + E) |
|空間の複雑さ | O(V) |
|最短経路を見つけますか? |はい (重み付けされていないグラフ) |
|完了？ |はい (到達可能な頂点をすべて調査します) |
**アルゴリズム:**
1. ソース頂点 s から開始します。マークさんが訪問しました。エンキュー s.
2. キューが空でない間に、頂点 u をデキューします。 u の未訪問の近隣 v ごとに、v を訪問済みとしてマークし、v をキューに入れます。
**アプリケーション:** 重み付けされていないグラフ、接続されたコンポーネント、二部性テスト、Web クローリングにおける最短パス。
### 深さ優先検索 (DFS)
**スタック** (または再帰) を使用して、後戻りする前にできるだけ深く探索します。
|プロパティ |値 |
|----------|----------|
|データ構造 |スタック (LIFO) / 再帰 |
|時間計算量 | O(V + E) |
|空間の複雑さ | O(V) |
|最短経路を見つけますか? |いいえ |
|完了？ |はい (有限グラフの場合) |
**アルゴリズム:**
1. 頂点 s から開始します。マークさんが訪問しました。
2. s の未訪問の近隣 v ごとに、v から再帰的に DFS を実行します。
**DFS はエッジを次のように分類します:**
- **ツリー エッジ:** DFS ツリーの一部
- **バックエッジ:** 頂点をその祖先に接続します (サイクルを示します)
- **前方エッジ:** 頂点をその子孫に接続します
- **クロスエッジ:** 異なるブランチの頂点を接続します
**アプリケーション:** トポロジカルソート、サイクル検出、強く接続されたコンポーネント、迷路の解決。
### BFS と DFS の比較
|基準 | BFS | DFS |
|----------|-----|-----|
|戦略 |広くて深い |深くて広い |
|メモリ |ハイアー（店舗フロンティア） |下 (パスを格納) |
|最短パス (重み付けなし) |保証付き |保証されません |
|ソリューションの開始が近づいている場合に使用します。より良い |最悪 |
|グラフが非常に深い場合に使用します。最悪 |より良い |
|トポロジカルソート |カーンのアルゴリズムのバリアント |標準的なアプローチ |

## 最短パスのアルゴリズム
頂点間の最短経路を見つけることは、実際上最も重要なグラフ問題の 1 つです。
### ダイクストラのアルゴリズム
**非負**のエッジ ウェイトを使用して、単一のソースからグラフ内の他のすべての頂点への最短パスを検索します。
|プロパティ |値 |
|----------|----------|
|エッジの重み | ≧ 0 である必要があります |
|時間 (バイナリ ヒープ) | O((V + E) log V) |
|時間 (フィボナッチ ヒープ) | O(E + V log V) |
|よく深い？ |はい |
|負の重みを処理しますか? |いいえ |
**アルゴリズム:**
1. すべての v ≠ s に対して dist[s] = 0、dist[v] = ∞ を初期化します。すべての頂点を持つ優先キュー Q。
2. Q が空でない場合: 最小距離で頂点 u を抽出します。エッジ重み w を持つ u の各近傍 v について: dist[u] + w < dist[v] の場合、dist[v] = dist[u] + w を更新します。
**実際の例:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### ベルマン・フォードアルゴリズム
**負**のエッジの重みを処理し、負のサイクルを検出します。
|プロパティ |値 |
|----------|----------|
|エッジの重み |任意 (負のサイクルを検出) |
|時間計算量 | O(V・E) |
|空間の複雑さ | O(V) |
|負のサイクルに対処しますか? |はい (検出およびレポート) |
**アルゴリズム:**
1. すべての v ≠ s に対して dist[s] = 0、dist[v] = ∞ を初期化します。
2. V − 1 回繰り返します: 重み w を持つ各エッジ (u, v) に対して: dist[u] + w < dist[v] の場合、dist[v] を更新します。
3. 負のサイクルを確認します。エッジがまだ緩和できる場合は、負のサイクルが存在します。
### フロイド・ウォーシャルアルゴリズム
頂点の**すべてのペア**間の最短パスを検索します。
|プロパティ |値 |
|----------|----------|
|時間計算量 | O(V3) |
|空間の複雑さ | O(V²) |
|負の重みを処理しますか? |はい (ただし、負のサイクルではありません) |
|アプローチ |動的プログラミング |
**繰り返し:** 中間頂点 k ごとに dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。
### アルゴリズム選択ガイド
|シナリオ |アルゴリズム |
|----------|----------|
|単一ソース、非負の重み |ディクストラ |
|単一ソース、負の重み付けが可能 |ベルマン・フォード |
|すべてのペア、密なグラフ |フロイド・ウォーシャル |
|すべてのペア、疎グラフ |各頂点からダイクストラを実行します。
|重み付けされていないグラフ | BFS |
| DAG (サイクルなし) |トポロジカルソート + 緩和 |
| A* (ヒューリスティックガイド付き) | A* 検索 (適切なヒューリスティックによるパスファインディング用) |

## 最小スパニング ツリー数
**最小スパニング ツリー (MST)** は、最小の総エッジ ウェイトですべての頂点を接続します。
### プロパティ
- MST には正確に n − 1 個のエッジがあります (n 個の頂点に対して)
- グラフが接続されている場合、MST が存在します。
- 明確なエッジの重みを持つグラフには固有の MST があります
- MST は **カット プロパティ** を満たします。任意のカットと交差する最小重みエッジは MST に属します。
- MST は **サイクル プロパティ** を満たします。どのサイクルの最大重みエッジも MST に属しません。
### クラスカルのアルゴリズム
|プロパティ |値 |
|----------|----------|
|戦略 |貪欲 — 重み順にエッジを追加 |
|データ構造 |素集合 (共用体検索) |
|時間計算量 | O(E log E) |
|最適 |疎なグラフ |
**アルゴリズム:**
1. すべてのエッジを重みで並べ替えます。
2. 各エッジに対して (順番に): 追加してもサイクルが作成されない場合 (union-find で確認)、MST に追加します。
3. n − 1 個のエッジが選択された時点で停止します。
### プリムのアルゴリズム
|プロパティ |値 |
|----------|----------|
|戦略 |貪欲 — 開始頂点からツリーを成長させる |
|データ構造 |優先キュー (最小ヒープ) |
|時間計算量 | O(E log V) バイナリ ヒープ |
|最適 |密なグラフ |
**アルゴリズム:**
1. 任意の頂点から開始します。これを MST の一部としてマークします。
2. MST 内の頂点とその外側の頂点を接続する最小重みエッジを繰り返し追加します。
3. すべての頂点が含まれたら停止します。
### MST アプリケーション
|アプリケーション | MST はどのように役立つのか |
|------------|------|
|ネットワーク設計 |すべての場所を接続するための最小限のケーブル/パイプを敷設 |
|クラスタリング | k − 1 個の最長 MST エッジを削除して、k 個のクラスターを取得します。
|近似アルゴリズム |メートル法 TSP の 2 近似 |
|画像のセグメンテーション |色の類似性の MST によってピクセルをグループ化する |
|機能の削除 |相関グラフのMSTを利用して冗長な特徴を削除 |

## ネットワークフロー
ネットワーク フローの問題は、システム内のリソースの移動をモデル化します。
### フローネットワークの定義
**フロー ネットワーク**は、次のような有向グラフです。
- **ソース** 頂点 (フローを生成)
- **シンク** 頂点 t (フローを消費)
- **容量** 各エッジで c(u,v) ≥ 0
- **フロー** f(u,v) を満たす:
  - **容量制約:** 0 ≤ f(u,v) ≤ c(u,v)
  - **流れ保存:** s と t を除くすべての頂点での流入 = 流出
### 最大流量の問題
s から t までの最大合計流量を求めます。
**フォード・フルカーソン法:**
1. 残差グラフには s から t への拡張パスが存在します。
2. パスに沿ったボトルネック容量を見つける
3. パスに沿った流量をボトルネック分だけ増加させる
4. 残存容量を更新する
|アルゴリズム |時間計算量 |メモ |
|----------|----------------|------|
|フォード・フルカーソン (DFS) | O(m · f*) ここで、f* は最大流量 |不合理な能力では終了できない |
|エドモンズ カープ (BFS) | O(V・E²) |常に終了し、最短の拡張パスを選択します。
|ディニックのアルゴリズム | O(V²・E) |ブロッキングフローを使用します。ユニット容量の場合は O(V^(1/2) · E) |
### 最大流量最小カット定理
s から t までの**最大流量**は、s から t を隔てる**最小カット**容量と等しくなります。
**カット** (S, T) は、頂点を S (s を含む) と T (t を含む) に分割します。カット能力はS刃からT刃までの能力の合計となります。
**最大流量の用途:**
- 二者マッチング（従業員をジョブに割り当てる）
- 画像のセグメンテーション (前景と背景を分離)
- 野球の敗退 (チーム X はまだ勝つことができますか?)
- ネットワークの信頼性 (最大のデータ スループット)
### Max Flow による 2 部マッチング
二部グラフ G = (L ∪ R, E) の場合:
1. L のすべての頂点にエッジを持つソースを追加します (容量 1)
2. R のすべての頂点からのエッジを持つシンク t を追加します (容量 1)
3. 元のエッジ容量をすべて 1 に設定します。
4. 最大流量 = 最大マッチング

## スペクトルグラフ理論
スペクトル グラフ理論では、グラフに関連付けられた行列の固有値と固有ベクトルを通じてグラフを研究します。
### 主要なマトリックス
|マトリックス |定義 |何がキャプチャされるのか |
|----------|-----------|---------------------|
| **隣接行列** A |エッジ (i,j) が存在する場合、A[i][j] = 1 |接続パターン |
| **次数マトリックス** D |対角線; D[i][i] = 度(i) |頂点の重要度別 |
| **ラプラシアン** L = D − A | L[i][j] = −1 エッジ、対角線上の deg(i) |グラフ上の関数の滑らかさ |
| **正規化ラプラシアン** L_norm = D^(−1/2) L D^(−1/2) |スケール不変バージョン |コミュニティ構造 |
### ラプラシアンの固有値
ラプラシアン L は正の半定値であるため、すべての固有値は ≥ 0 になります。
|固有値 |意味 |
|-----------|-----------|
| λ₁ = 0 |常にゼロ。 eigenvector は定数ベクトルです |
| λ₂ (代数接続性) | > 0 (グラフが接続されている場合)。大きい = 接続が良くなる |
|ゼロ固有値の数 |接続コンポーネントの数に等しい |
| λₙ |最大次数とグラフ展開に関連する |
### スペクトル法の応用
|アプリケーション |方法 |
|---------------|----------|
| **グラフの分割** | L の固有ベクトルを使用してグラフをバランスのとれた部分に分割する |
| **コミュニティ検出** |スペクトル クラスタリング: 底部固有ベクトルを使用して頂点を埋め込み、クラスター化します。
| **ページランク** | Web グラフの隣接行列 (または遷移行列) の固有ベクトル |
| **グラフ描画** |ラプラシアン | の固有ベクトルを使用して頂点を配置します。
| **半教師あり学習** |グラフ ラプラシアンを使用してラベルを伝播する (ラベルの伝播) |
| **グラフ ニューラル ネットワーク** |スペクトル畳み込み: L | の固有ベクトルを使用してグラフ上の信号をフィルター処理します。
### チーガーの不等式
第 2 固有値 λ₂ をグラフの **展開** (どの程度よく接続されているか) に関連付けます。
λ₂ / 2 ≤ h(G) ≤ √(2λ₂)
ここで、h(G) はチーガー定数 (等周数) です。これは、λ₂ がグラフを 2 つの部分に分割することがどれだけ難しいかをおおよそ測定することを意味します。これは、クラスタリングの重要な洞察です。

グラフ理論はおそらく、現代のデータ サイエンスに最も直接適用できる数学の分野です。ソーシャル ネットワーク、ナレッジ グラフ、分子構造、深層学習フレームワークの計算グラフ、依存関係の解決、推奨システムはすべて、基本的にグラフの問題です。ここで説明するアルゴリズムは単なる理論的なものではありません。これらは実稼働システムで毎日大規模に実行されます。
