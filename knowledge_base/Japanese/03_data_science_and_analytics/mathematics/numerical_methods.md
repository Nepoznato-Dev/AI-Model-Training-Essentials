# 数値的手法
数値的手法は、数学理論と実際の計算の間の架け橋です。純粋な数学は解が存在することを証明しますが、数値的手法は実際には有限の精度で近似的な答えを計算します。すべての機械学習モデル、物理シミュレーション、データ分析パイプラインは最終的に数値計算に依存します。信頼性の高いソフトウェアを構築するには、これらの方法 (精度、安定性、制限) を理解することが不可欠です。
---

## 浮動小数点演算
コンピューターは有限の精度で実数を表します。 **IEEE 754 標準**は、浮動小数点数の格納方法と操作方法を定義しています。
### IEEE 754 フォーマット
|フォーマット |ビット |指数 |仮数 |おおよその 10 進数 |範囲 |
|----------|------|----------|----------|---------------------------|----------|
|ハーフ (fp16) | 16 | 5 | 10 | 3.3 | ±6.5×10⁴ |
|シングル (fp32) | 32 | 8 | 23 | 7.2 | ±3.4 × 103⁸ |
|ダブル (fp64) | 64 | 11 | 52 | 15.9 | ±1.8 × 103⁰⁸ |
### マシンイプシロン
**マシン イプシロン** (ε_mach) は、浮動小数点で 1 + ε_mach > 1 となる最小の数です。
|フォーマット | ε_マッハ |
|----------|----------|
| FP16 | 2⁻¹⁰ ≈ 9.8 × 10⁻⁴ |
| FP32 | 2⁻²³ ≈ 1.2 × 10⁻⁷ |
| FP64 | 2⁻⁵² ≈ 2.2 × 10⁻¹⁶ |
### よくある落とし穴
|落とし穴 |例 |結果 |
|----------|----------|---------------|
| **致命的なキャンセル** |小さい x について (1 + x) − 1 を計算する |有効数字の欠落 |
| **吸収** | fp32 では 10⁸ + 1 = 10⁸ |大きな金額では小さな価値が失われる |
| **非結合性** | (a + b) + c ≠ a + (b + c) |合計順序が重要 |
| **ゼロに近い除算** | 1 / 10⁻³⁰⁰ → オーバーフロー |無限大または NaN |
### 緩和戦略
|戦略 |説明 |
|----------|---------------|
| **カハンの合計** |吸収誤差を低減するための補正された合計 |
| **カハン・バブスカ・ノイマイヤー** | Kahan の合計の改良版 |
| **ソートされた合計** |吸収を避けるために、最初に小さな数値を合計します。
| **倍倍演算** |精度を拡張するには double のペアを使用します。
| **コンディショニング分析** |問題自体がエラーを増幅させるかどうかを理解する |

## ルート検索
f(x) = 0 となる x を求めます。
### 二等分法
|プロパティ |値 |
|----------|----------|
|必要なもの | f 連続、f(a) と f(b) は反対の符号を持ちます。
|収束 |線形 (誤差はステップごとに半分になります) |
|保証されていますか？ |はい — 常に収束します |
| d 桁の反復 | ≈ d / log₁₀(2) ≈ 3.32d |
**アルゴリズム:**
1. f(a) · f(b) < 0 の区間 [a, b] から開始します。
2. 中点 c = (a + b) / 2 を計算します。
3. f(c) = 0 または |b − a| の場合< 許容範囲、停止
4. f(a) · f(c) < 0 の場合、b = c を設定します。それ以外の場合は a = c を設定します
5. 繰り返します
### ニュートン・ラフソン法
|プロパティ |値 |
|----------|----------|
|必要なもの | f 微分可能、根で f'(x) ≠ 0 |
|収束 |二次関数 (ルートに近い) |
|保証されていますか？ |いいえ — 分岐または循環する可能性があります |
|更新ルール | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**作業例:** f(x) = x² − 2 = 0 を解いて √2 を求めます。
- f'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x₂ = 1.4167 − (2.0069 − 2) / 2.8333 = 1.4142
- x₃ = 1.41421356... (小数点以下 8 桁まで修正)
### セカント法
ニュートン法と似ていますが、導関数を近似します。
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
|プロパティ |値 |
|----------|----------|
|収束 |超線形 (次数 ≈ 1.618、黄金比) |
|必要なもの | 2 つの初期推測 (導関数は必要ありません) |
### 根を見つける方法の比較
|方法 |収束 |デリバティブは必要ですか? |保証されていますか？ |ステップごとのコスト |
|--------|-------------|--------|-------------|--------------|
|二等分 |リニア (1) |いいえ |はい | 1 関数評価 |
|ニュートン・ラフソン |二次方程式 (2) |はい |いいえ | 2 つの関数評価 |
|セカント |スーパーリニア (1.618) |いいえ |いいえ | 1 関数評価 |
|ブレント法 |スーパーリニア |いいえ |はい |さまざま |
**Brent の方法** は、二分法 (収束保証) と割線/逆二次補間 (高速収束) を組み合わせています。これは、ほとんどの数値ライブラリのデフォルトのルートファインダーです。

## 数値積分 (求積)
∫ₐᵇ f(x) dx を近似的に計算します。
### メソッド
|方法 |式 |エラー |注文 |
|----------|-----------|----------|----------|
| **長方形 (中点)** | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **台形** | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **シンプソンズ 1/3** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | O(h⁴) | 3 |
| **シンプソンズ 3/8** |等間隔の 4 つの点を使用します。 O(h⁴) | 4 |
| **ガウス求積法** |最適なノード配置 | O(h²ⁿ) | n点 |
### 複合ルール
幅 h = (b−a)/n の n 部分間隔の場合:
|ルール |複合フォーミュラ |エラー |
|------|------|------|
|複合台形 | h[f(a)/2 + Σf(xᵢ) + f(b)/2] | O(h²) |
|複合シンプソンズ | h/3[f(a) + 4Σf(奇数) + 2Σf(偶数) + f(b)] | O(h⁴) |
**作業例:** n = 4 の複合台形を使用して ∫₀¹ e^(−x²) dx を近似します。
- h = 0.25、ポイント: 0、0.25、0.5、0.75、1
- f(0) = 1、f(0.25) = 0.9394、f(0.5) = 0.7788、f(0.75) = 0.5698、f(1) = 0.3679
- T = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- 真の値: ≈ 0.7468 (誤差 ≈ 0.5%)
### 適応直交法
関数が急速に変化する区間を自動的に細分化し、関数が滑らかな場合には使用するポイントを減らします。これは、`scipy.integrate.quad` が使用するものです (QUADPACK に基づいています)。

## 補間
既知のデータポイント間の値を推定します。
### メソッド
|方法 |説明 |滑らかさ |振動 |
|----------|---------------|---------------|-------------|
| **最も近い隣人** |最も近いデータ ポイントを使用する |不連続 |なし |
| **線形** |点を直線で結ぶ | C⁰ (連続) |なし |
| **多項式 (ラグランジュ)** |すべての点を通る単一の多項式 | C^∞ |多くの点で厳しい (ルンゲ現象) |
| **3次スプライン** |区分的に立方体、接合部は滑らか | C² |最小限 |
| **動径基底関数** |放射状カーネルの加重合計 |カーネルに依存 |低い |
### ラグランジュ補間
n+1 点 (x₀, y₀), ..., (xₙ, yₙ) が与えられた場合、すべての点を通過する次数 ≤ n の一意の多項式は次のようになります。
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**ルンゲ現象:** 等間隔の点での高度な多項式補間は、エッジ付近で激しく振動する可能性があります。チェビシェフ ノードまたはスプラインを使用することで軽減されます。
### 3次スプライン
C² 連続である区分的 3 次多項式 (連続 2 次導関数)。
|タイプ |境界条件 |
|-----|---------------------|
|ナチュラルスプライン | S''(x₀) = S''(xₙ) = 0 |
|クランプされたスプライン | S'(x₀) と S'(xₙ) が指定されました |
|結び目ではない | x₁ および xₙ₋₁ で連続する 3 次導関数 |

## ODE ソルバー
常微分方程式 dy/dt = f(t, y) を数値的に解きます。
### オイラー法
最も単純な ODE ソルバー。
**更新:** y_{n+1} = y_n + h · f(t_n, y_n)
|プロパティ |値 |
|----------|----------|
|注文 | 1 (ステップごとのエラー: O(h²)、グローバル: O(h)) |
|安定性 |条件的に安定 (小さい h が必要) |
|コスト |ステップごとに 1 つの関数評価 |
### ルンゲ・クッタ法
|方法 |注文 |ステージ |メモ |
|----------|----------|----------|----------|
| **オイラー** | 1 | 1 |最も単純な |
| **中間点** | 2 | 2 |精度の向上 |
| **フンさん (RK2)** | 2 | 2 |予測補正器 |
| **クラシック RK4** | 4 | 4 |標準的な主力製品 |
| **ドーマンド プリンス (RK45)** | 4(5) | 6 |適応ステップ サイズ (ode45 で使用) |
### Classic RK4 (4次ルンゲクッタ)
k₁ = f(t_n, y_n)
k₂ = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk₂/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k₂ + 2k₃ + k₄) / 6
|プロパティ |値 |
|----------|----------|
|注文 | 4 (グローバル エラー: O(h⁴)) |
|コスト |ステップごとに 4 つの関数評価 |
|安定性 |オイラーよりもはるかに優れています |
|使い方 |非スティッフ ODE のデフォルト |
### 厳密な ODE
**硬い** ODE には、非常に異なる時間スケールで変化するコンポーネントが含まれています。陽的手法 (オイラー、RK4) では、非現実的に小さいステップ サイズが必要です。
|方法 |タイプ |安定性 |
|----------|------|----------|
|暗黙的なオイラー |暗黙的 | A-stable (無条件に安定) |
|後方微分公式 (BDF) |暗黙的 | A-安定 (次数 5 まで) |
|暗黙のルンゲ・クッタ |暗黙的 | L 安定変異体が存在します。
|リソーダ |自動 |硬い/硬いを切り替えます |

## 数値安定性と条件付け
### 条件番号
**条件番号**は、入力の小さな変化に対して問題の出力がどの程度変化するかを測定します。
線形システム Ax = b の場合: κ(A) = ||A|| · ||A⁻¹||
| κ(A) |解釈 |
|------|------|
| ≈ 1 |コンディション良好 |
| 103 |軽度の敏感性 |
| 10⁸ |条件が悪い (最大 8 桁の精度が失われる) |
| → ∞ |単数 (一意の解決策なし) |
### アルゴリズムの安定性
入力の小さな摂動が出力の小さな摂動につながる場合、アルゴリズムは **数値的に安定しています** (問題の条件数と比較して)。
|アルゴリズム |安定した？ |メモ |
|----------|-----------|----------|
|部分ピボットによるガウス消去 |はい |標準的なアプローチ |
| QR による固有値の計算 |はい |後方安定 |
|単純な合計 (最初に大きい + 小さい) |いいえ |カハン和を使用する |
|分散を E[X²] − (E[X])² として計算します。いいえの可能性があります | Welford のオンライン アルゴリズムを使用する |
### ウェルフォードのオンライン アルゴリズム
数値的に安定した移動平均と分散の計算:
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

これにより、単純な 2 パス式で発生する壊滅的なキャンセルが回避されます。

数値的手法は、数学と現実が出会う場所です。ほとんどの実数を正確に表現できるコンピューターはなく、実際には微分が記号的に計算されることはなく、現実世界の問題に対して閉形式で積分が評価されることもありません。数値的手法を理解すると、適切なアルゴリズムを選択し、その精度を予測し、有限精度の演算から生じる微妙なバグを回避できるようになります。
