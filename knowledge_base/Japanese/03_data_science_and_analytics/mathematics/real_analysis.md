# 実際の分析
実際の分析は微積分の厳密な基礎です。微積分の入門では微分と積分の計算方法を学びますが、実際の分析では、これらの手法が「なぜ」機能するのか、そしていつ失敗するのかが問われます。これは、確率理論、関数分析、最適化、および機械学習アルゴリズムの背後にある理論的保証を支える限界、連続性、収束、統合の正確な定義を提供します。
---

## シーケンスとシリーズ
### シーケンス
**シーケンス**は、実数 (aₙ)ₙ₌₁^∞ の順序付きリストです。中心的な質問は、数列が極限まで**収束**するかどうかということです。
**収束の定義:** すべての ε > 0 について、すべての n > N について次のような N が存在する場合、数列 (aₙ) は L に収束します: |aₙ − L| < ε。
|コンセプト |定義 |例 |
|----------|---------------|----------|
| **収束** | lim aₙ = L は存在し、有限です。 aₙ = 1/n → 0 |
| **発散** |収束しない | aₙ = (−1)ⁿ は振動します |
| **∞への発散** | aₙは際限なく成長します。 aₙ = n² → ∞ |
| **境界あり** | \|aₙ\|一部の M については ≤ M |すべての収束シーケンスは有界です |
| **モノトーン** |常に非減少または非増加のいずれか | aₙ = 1 − 1/n は増加しています |
| **コーシーシーケンス** | ∀ε > 0、∃N: ∀m,n > N、\|aₘ − aₙ\| < ε | ℝ では、コーシー ⟺ 収束 |
**重要な定理:**
- **単調収束定理:** すべての有界単調数列は収束します
- **ボルツァーノ・ワイエルシュトラスの定理:** すべての有界シーケンスには収束部分シーケンスがあります。
- **ℝ の完全性:** ℝ のすべてのコーシー数列が収束します (これにより、ℝ と ℚ が区別されます)
＃＃＃ シリーズ
**シリーズ** は、シーケンス Σₙ₌₁^∞ aₙ の合計です。部分和の列 Sₙ = Σₖ₌₁ⁿ aₖ が収束すると、級数は収束します。
### 収束テスト
|テスト |状態 |結論 |
|------|-----------|-----------|
| **発散テスト** | lim aₙ ≠ 0 |シリーズが分岐 |
| **比較テスト** | 0 ≤ aₙ ≤ bₙ と Σbₙ は収束する | Σaₙ が収束する |
| **比率テスト** |リム \|aₙ₊₁/aₙ\| =L | L< 1, diverges if L >1 | の場合は収束します。
| **ルートテスト** | lim sup \|aₙ\|^(1/n) = L | L< 1, diverges if L >1 | の場合は収束します。
| **統合テスト** | aₙ = f(n)、f は減少、正 | ∫f(x)dx が収束する場合、Σaₙ は収束します。
| **交互シリーズ** | aₙ 減少、lim aₙ = 0、交互の符号 |級数が収束する |
| **絶対収束** | Σ\|aₙ\|収束する | Σaₙ は収束します (並べ替えても同じ和が得られます) |
| **条件付き収束** | Σaₙ は収束しますが、Σ\|aₙ\|発散する |並べ替えは任意の和を与えることができます (リーマン) |
### 重要なシリーズ
|シリーズ |合計 |状態 |
|----------|-----|----------|
|幾何学的: Σ rⁿ | 1/(1−r) | \|r\|  1 |< 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
|高調波: Σ 1/n |発散 (= ∞) | — |
|指数関数: Σ xⁿ/n! | eˣ |すべて× |
| ln(1+x) のテイラー: Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < x ≤ 1 |

## 限界と継続性
### 機能の制限
**定義:** lim_{x→c} f(x) = L は、すべての ε > 0 に対して、0 < |x − c| となるような δ > 0 が存在することを意味します。 < δ は |f(x) − L| を意味します。 < ε。
これは **ε-δ の定義**、つまり「x が c に近づくと f(x) は L に近づく」の厳密版です。
### 継続性
lim_{x→c} f(x) = f(c) の場合、関数 f は **c で連続です**。同等: すべての ε > 0 に対して、 |x − c| となるような δ > 0 が存在します。 < δ は |f(x) − f(c)| を意味します。 < ε。
**不連続性の種類:**
|タイプ |説明 |例 |
|------|-------------|----------|
|取り外し可能 |極限は存在しますが、≠ f(c) | f(x) = sin(x)/x (x = 0) |
|ジャンプ |左右の制限は存在しますが、異なります。ステップ関数 |
|無限 |限界は±∞です | f(x) = 1/x² (x = 0) |
|振動 |制限は存在しません | x = 0 で f(x) = sin(1/x) |
### 連続関数の重要な定理
|定理 |声明 |
|----------|----------|
| **中間値定理** | f が [a,b] 上で連続で、f(a) < k < f(b) の場合、∃c ∈ (a,b) となります。 f(c) = k |
| **極値定理** | f が [a,b] 上で連続である場合、f は [a,b] 上で最大値と最小値になります。
| **有界定理** | f が [a,b] 上で連続である場合、f は [a,b] 上で有界になります。
| **均一な連続性** | f が [a,b] 上で連続である場合、f は [a,b] 上で一様連続です (ハイネ-カントール) |
**実際の例 (IVT):** x³ + x − 1 = 0 の解は (0, 1) にあることを示します。
- f(x) = x³ + x − 1 とします。f は連続 (多項式) です。
- f(0) = −1< 0 and f(1) = 1 >0.
- IVT により、∃c ∈ (0,1): f(c) = 0。

## 差別化
＃＃＃ 意味
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
この制限が存在する場合、f は c で**微分可能**です。
### 微分可能性と連続性
|関係 |声明 |
|--------------|----------|
|微分可能 → 連続 | f が c で微分可能である場合、f は c | で連続です。
|連続 ↛ 微分可能 | f(x) = \|x\|は 0 で連続ですが、そこでは微分できません |
|どこにも微分不可能 |ワイエルシュトラス関数: どこでも連続、どこでも微分可能 |
### 主な結果
|定理 |声明 |
|----------|----------|
| **平均値定理** | f が [a,b] 上で連続で、(a,b) 上で微分可能である場合、∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **ロールの定理** | f(a) = f(b): ∃c: f'(c) = 0 | の場合の MVT の特殊なケース
| **ロピタルのルール** | lim f/g = 0/0 または ∞/∞ の場合、 lim f/g = lim f'/g' (後者が存在する場合) |
| **テイラーの定理** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x) と明示的な剰余 |

＃＃ 統合
### リーマン積分
**リーマン積分** は、∫ₐᵇ f(x)dx をリーマン和の極限として定義します。
**建設:**
1. [a,b] を部分区間に分割します: P = {x₀, x₁, ..., xₙ}
2. サンプル点 tᵢ ∈ [xᵢ₋₁, xᵢ] を選択します。
3. リーマン和: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. S(P,f) の極限がメッシュ → 0 として存在する場合、f はリーマン可積分である
**リーマン積分性の基準:**
|状態 |統合可能? |
|----------|---------------|
| [a,b] で連続 |はい |
|有限個の不連続点で囲まれている |はい |
| [a,b] のモノトーン |はい |
|ディリクレ関数 (ℚ では 1、無理数では 0) |いいえ |
### 微積分の基本定理
|パート |声明 |
|------|-----------|
| **パート 1** | f が [a,b] 上で連続である場合、F(x) = ∫ₐˣ f(t)dt は微分可能であり、F'(x) = f(x) |
| **パート 2** | F' = f で、f がリーマン可積分の場合、 ∫ₐᵇ f(x)dx = F(b) − F(a) |
### ルベーグ統合
リーマン積分には限界があります。解析や確率で生じる多くの関数を統合することはできません。 **ルベーグ積分** は、積分をより幅広いクラスの関数に拡張します。
**重要なアイデア:** ドメイン (X 軸) を分割する代わりに、範囲 (Y 軸) を分割します。
|側面 |リーマン積分 |ルベーグ・インテグラル |
|--------|------|--------|
|アプローチ |パーティション ドメイン (x 軸) |パーティション範囲 (y 軸) |
|統合します |連続、区分的連続 |測定可能な関数 |
|極限定理 |弱い |強力（ドミナントコンバージェンス、モノトーンコンバージェンス） |
|ハンドル | 「うれしい」機能 |密な不連続性を持つ関数 |
| |の基礎古典的な微積分 |現代の確率理論 |
**ルベーグの基準:** f が有界でほぼどこでも連続である場合 (不連続点の集合の測度が 0 である場合)、 f は [a,b] 上でリーマン可積分です。

## メトリック スペース
**計量空間** は、抽象集合に対する「距離」の概念を一般化します。
＃＃＃ 意味
**計量空間** (X, d) は、以下を満たす距離関数 d: X × X → ℝ を持つ集合 X です。
|公理 |声明 |
|------|-----------|
|非否定性 | d(x,y) ≥ 0 |
|アイデンティティ | x = y | の場合、d(x,y) = 0
|対称性 | d(x,y) = d(y,x) |
|三角不等式 | d(x,z) ≤ d(x,y) + d(y,z) |
### 一般的な計量空間
|スペース |セット |メトリック |アプリケーション |
|----------|-----|----------|---------------|
| ℝⁿ ユークリッド | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² |標準ジオメトリ |
|マンハッタンとℝⁿ | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| |グリッドベースのパス、LASSO |
|チェビシェフとℝⁿ | ℝⁿ | d(x,y) = max\|xᵢ−yᵢ\| |チェスキングの距離 |
|離散メトリック |任意のセット | d(x,y) = x≠y の場合は 1、x=y の場合は 0 |トポロジの例 |
|関数空間 C[a,b] |連続関数 | d(f,g) = max\|f(x)−g(x)\| |近似理論 |
| Lᵖスペース | p 可積分関数 | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) |機能分析、ML 規範 |
### 計量空間における位相概念
|コンセプト |定義 |例 |
|----------|---------------|----------|
| **オープンボール** | B(x,r) = {y : d(x,y) < r} | ℝ の開区間 (x−r, x+r) |
| **オープンセット** |すべてのポイントにはセットに含まれるボールがあります。 (0,1) は ℝ にオープンしています |
| **クローズドセット** |開集合の補数 | [0,1] は ℝ で閉じられています |
| **締め切り** | S | を含む最小の閉集合(0,1) = [0,1] | の閉包
| **コンパクト** |すべての開いたカバーには有限のサブカバーがあります。 ℝⁿ: 閉鎖および有界 (ハイネ・ボレル) |
| **完了** |すべてのコーシー数列は収束します。 ℝは完了です。 ℚはそうではありません |

## 一様収束
一連の関数 (fₙ) は次の 2 つの方法で収束できます。
|タイプ |定義 |継続性を維持しますか? |
|------|-----------|-----------|
| **ポイントごとに** | ∀x: fₙ(x) → f(x) |いいえ |
| **制服** | sup\|fₙ(x) − f(x)\| → 0 |はい |
**均一収束** はより強力です。収束率はどこでも同じです。
**重要な定理:**
- 連続関数の一様極限は連続です
- リーマン可積分関数の一様極限はリーマン可積分であり、その極限の積分は積分の極限と等しい
- **ワイアーシュトラスの M 検定:** |fₙ(x)| の場合すべての x について ≤ Mₙ および ΣMₙ が収束すると、Σfₙ は一様に収束します

## 測定理論
**測定理論** は、長さ、面積、体積の概念を一般化します。
＃＃＃ 意味
集合 X の **測度** は、次を満たす関数 μ: Σ → [0, ∞] (Σ は部分集合の σ 代数) です。
- μ(∅) = 0
- **可算加法性:** 素な Aᵢ の場合、μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ)
### ルベーグ測定
ℝ の **ルベーグ測度** λ は、長さの概念を拡張します。
|セット |ルベーグ測定 |
|-----|------|
|間隔 [a,b] | b − a |
|単一点 {x} | 0 |
|有限集合 | 0 |
|可算集合 (例: ℚ) | 0 |
|カントールセット | 0 (数えられないがゼロを測定) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### 主要な概念
|コンセプト |定義 |
|-----------|-----------|
| **ほぼどこでも (つまり)** |プロパティは、メジャー ゼロのセットを除いて保持されます。
| **測定可能な機能** |すべてのオープンセットのプリイメージが測定可能 |
| **ルベーグ積分** |測度理論を使用して定義された積分 |
| **スペース** |有限の p 乗積分の関数の空間 |
### 重要な収束定理
これらの定理が、高度な数学でルベーグ積分が好まれる理由です。
|定理 |声明 |
|----------|----------|
| **モノトーン コンバージェンス** | fₙ ↑ f が点的にかつ fₙ ≥ 0 の場合、∫fₙ → ∫f |
| **ドミナントコンバージェンス** | fₙ → f 点単位で \|fₙ\| の場合≤ g (可積分) の場合、∫fₙ → ∫f |
| **ファトゥーの補題** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
これらの定理により、限界値と積分値の交換が可能になりますが、リーマン積分では一般にこれが失敗します。
