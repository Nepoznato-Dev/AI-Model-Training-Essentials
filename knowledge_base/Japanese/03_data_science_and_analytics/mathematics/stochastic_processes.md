# 確率過程
**確率過程** は、時間 (または空間) によってインデックス付けされた確率変数のコレクションです。確率論は個々のランダムな出来事を研究するのに対し、確率過程はランダム性が時間の経過とともにどのように進化するかを研究します。これらは、株価、行列の長さ、病気の蔓延、言語生成、機械学習モデルのトレーニングダイナミクスをモデル化します。
---

## 基礎
＃＃＃ 意味
確率過程 {X_t : t ∈ T} は、共通の確率空間上で定義された確率変数のファミリーです。 T は **インデックス セット** (時間) です。
- **離散時間:** T = {0, 1, 2, ...}
- **連続時間:** T = [0, ∞)
**状態空間** S は、X_t が取り得る値のセットです。
### 主要なプロパティ
|プロパティ |定義 |
|----------|-----------|
| **定常性** | (X_{t₁}, ..., X_{tₖ}) の同時分布は (X_{t₁+τ}, ..., X_{tₖ+τ}) と同じ |
| **独立** | t ≠ s の場合、X_t は X_s から独立しています。
| **エルゴディシティ** |時間平均はアンサンブル平均に収束します。
| **マルコフ プロパティ** |未来は過去ではなく現在のみに依存します |
| **マーチンゲール** |将来の期待値は現在値と等しい |
---

## マルコフ連鎖
**マルコフ連鎖**は、将来の状態が現在の状態 (記憶のない特性) にのみ依存する確率過程です。
### 離散時間マルコフ連鎖 (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**遷移行列** P にはエントリ p_{ij} = P(go to j | currently at i) があります。
|プロパティ |声明 |
|----------|----------|
|行の合計 |各行の合計は 1 になります。 Σⱼ p_{ij} = 1 |
| n 段階の遷移 | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
|定常分布 | πP = π (固有値 1 の左固有ベクトル) |
### 国家の分類
|用語 |定義 |
|------|-----------|
| **再発** |チェーンは確率 1 で状態 i に戻ります。
| **一時的** |二度と戻らない可能性がゼロではない |
| **吸収** | p_{ii} = 1 (一度入力すると決して離れることはできません) |
| **期間** |戻り時間の GCD。期間 1 = 非周期 |
| **コミュニケーション** |状態 i と j は相互に到達できます。
### 定常分布
既約の正の反復マルコフ連鎖の場合、定常分布 π が存在し、一意であり、次の条件を満たします。
πP = π、Σᵢ πᵢ = 1
**解釈:** πᵢ = 状態 i で費やされる時間の長期的な割合。
**作業例:** 状態 {晴れ、雨} の気象モデル。
P = [[0.9, 0.1], [0.5, 0.5]] (行: 晴れから、雨から)
定常分布: πP = π
- π₁ = 0.9π₁ + 0.5π₂
- π₂ = 0.1π₁ + 0.5π₂
- π₁ + π₂ = 1
- 解法: π₁ = 5/6 ≈ 0.833、π₂ = 1/6 ≈ 0.167
### 定常性への収束
既約、非周期、正の反復連鎖の場合:
- Pⁿ → Π (すべての行が π に等しい行列) as n → ∞
- **混合時間:** 分布が π に近づくまでのステップ数
- **スペクトルギャップ:** 1 − |λ₂| (ここで、λ₂ は 2 番目に大きい固有値です) が混合速度を決定します
### 連続時間マルコフ連鎖 (CTMC)
遷移は、指数分布に基づいてランダムなタイミングで発生します。
|コンセプト |説明 |
|----------|---------------|
| **レート マトリックス Q** | q_{ij} ≥ 0 (i ≠ j); q_{ii} = −Σ_{j≠i} q_{ij} |
| **遷移確率** | P(t) = e^{Qt} (行列指数) |
| **定常分布** | πQ = 0 |
| **開催時間** |状態 i の時間は Exp(−q_{ii}) |

## ランダムウォーク
**ランダム ウォーク**は、連続したランダムなステップによって形成されるパスです。
### 単純なランダムウォーク
X_n = X_{n-1} + Z_n、ここで Z_n ∈ {+1, −1}、確率 p, q = 1−p。
|プロパティ | p = 1/2 (対称) | p ≠ 1/2 (バイアスあり) |
|----------|---------------------|----------|
| E[X_n] | 0 | n(2p−1) |
|変数[X_n] | n | 4npq |
|原点回帰? |はい (確率 1) |いいえ (漂流) |
|再発？ |はい (1D および 2D) |いいえ |
### 高次元でのランダムウォーク
|寸法 |再発？ |直感 |
|----------|---------------|----------|
| 1D |はい | 「酔った男はいつも家に帰る道を見つける」 |
| 2D |はい | 「酔った鳥は必ず家に帰る」 |
| 3D+ |いいえ | 「酔ったスズメは決して家に帰ることができない」 |
### ブラウン運動との関係
ランダム ウォークのスケーリング: S_n = ΣZ_i とします。次に、ステップ サイズ → 0 およびステップ → ∞ として、次のようになります。
S_{⌊nt⌋} / √n → B(t) (ブラウン運動、ドンスカーの定理による)
---

## ブラウン運動
**ブラウン運動** (ウィーナー過程) B(t) は、ランダム ウォークの連続時間制限です。
＃＃＃ 意味
B(t) は次の条件を満たします。
1. B(0) = 0
2. B(t) には連続したパスがあります
3. 独立した増分: B(t) − B(s) は、r < s < t の場合、B(s) − B(r) から独立しています。
4. B(t) − B(s) ~ N(0, t − s) (ガウス増分)
### 主要なプロパティ
|プロパティ |声明 |
|----------|----------|
| E[B(t)] | = 0 |
|変数[B(t)] | =t |
| Cov[B(s), B(t)] | = 分(s, t) |
|どこにも微分不可能 |パスは連続していますが、導関数はありません。
|フラクタル次元 |グラフのハウスドルフ次元は 3/2 |
|マルコフ特性 |未来は現在の位置のみに依存します |
|マーチンゲール | E[B(t) | F_s] = B(s) s < t |
### 幾何ブラウン運動
S(t) = S(0) exp((μ − σ²/2)t + σB(t))
これは、ブラック・ショールズの枠組みにおける株価の標準モデルです。
・μ：ドリフト（期待リターン）
- σ: ボラティリティ
---

## ポアソン過程
**ポアソン プロセス** N(t) は、[0, t] で発生するイベントの数をカウントします。
＃＃＃ 意味
N(t) ~ ポアソン(λt)。ここで、λ はレート (単位時間あたりのイベント数) です。
|プロパティ |声明 |
|----------|----------|
| N(0) = 0 | — |
|独立した増分 |互いに素な間隔のイベントは独立しています。
|定常増分 | N(t+s) − N(s) 〜 ポアソン(λt) |
| E[N(t)] | = λt |
|変数[N(t)] | = λt |
|到着間の時間 |指数分布: T_i ~ Exp(λ) |
### 一般化
|バリアント |説明 |
|----------|---------------|
| **非均質** |レート λ(t) は時間とともに変化します |
| **複合ポアソン** |各イベントのサイズはランダムです。 S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **ポアソンランダム測定** |時間だけでなく時空の点 |
| **多変量** |インタラクションの可能性がある複数のイベント タイプ |
---

## マーチンゲール
**マーチンゲール** は公正なゲームです。現在の情報がすべて与えられた場合、将来の期待値は現在の値と等しくなります。
＃＃＃ 意味
次の場合、{X_n} は濾過 {F_n} に関するマーチンゲールです。
1. X_n は F_n 測定可能 (適応)
2. E[|X_n|] < ∞ (可積分)
3. E[X_{n+1} | F_n] = X_n (フェアゲーム)
|バリアント |状態 |解釈 |
|----------|----------|-----|
| **マーチンゲール** | E[X_{n+1} | F_n] = X_n |公正なゲーム |
| **サブマルチンゲール** | E[X_{n+1} | F_n] ≥ X_n |好調な試合（上昇傾向） |
| **スーパーマーチンゲール** | E[X_{n+1} | F_n] ≤ X_n |不利な試合（下降傾向） |
### 重要な定理
|定理 |声明 |
|----------|----------|
| **オプションの停止** |条件下では、停止時間 T | E[X_T] = E[X_0]
| **コンバージェンス** |有界マーチンゲールはほぼ確実に収束します。
| **最大不等式** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Doob's) |

## モンテカルロ法
**モンテカルロ法**は、ランダムサンプリングを使用して決定論的な量を推定します。
### 基本的な考え方
X ~ P の場合に E[f(X)] を推定するには:
1. N 個のサンプルを描画します: P から x₁、x₂、...、x_N
2. 計算: Î = (1/N) Σᵢ f(xᵢ)
3. 大数の法則: Î → E[f(X)] as N → ∞
**エラー:** 標準誤差 = σ_f / √N、ここで σ_f² = Var[f(X)]
### 差異削減テクニック
|テクニック |アイデア |スピードアップ |
|----------|------|----------|
| **重要なサンプリング** | P ではなく Q からサンプリング、P/Q で重み付け |ドラマチックになる可能性があります |
| **対義語は変化します** |ペア (x, −x) を使用して分散をキャンセルします。 ～2倍 |
| **制御変数** | f | と相関する既知の期待関数を減算します。さまざま |
| **層別サンプリング** |ドメインを分割し、各階層をサンプリング |分散を減らす |
| **ラオ-ブラックウェル** |十分な統計に関する条件 |いつも役に立ちます |
---

## マルコフ連鎖モンテカルロ (MCMC)
MCMC は、定常分布がターゲット分布であるマルコフ連鎖を構築します。 「バーンイン」期間の後、サンプルはターゲットからのドローに近似します。
### メトロポリス-ヘイスティングス アルゴリズム
|ステップ |アクション |
|------|----------|
| 1 |現在の状態: x_t |
| 2 |提案: x* ~ q(x* \| x_t) (提案分布) |
| 3 |合格率: α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)] |
| 4 |確率 α で受け入れる: x_{t+1} = x* (受け入れ) または x_t (拒否) |
**特殊なケース — メトロポリス アルゴリズム:** 対称提案 q(x*|x) = q(x|x*)、したがって α = min(1, π(x*)/π(x_t))。
### ギブスサンプリング
各変数が完全な条件付き分布から更新されるメトロポリス ヘイスティングスの特殊なケース。
ターゲット π(x₁, x₂, ..., xₖ) の場合:
1. サンプル x₁^{(t+1)} ~ π(x₁ | x₂^{(t)}, ..., xₖ^{(t)})
2. サンプル x₂^{(t+1)} ~ π(x₂ | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. すべての変数について続行します
4. 繰り返します
|プロパティ |声明 |
|----------|----------|
|常に受け入れます | α = 1 (拒否ステップなし) |
|必要なもの |それぞれの完全な条件からサンプリングする機能 |
|収束 |既約非周期連鎖を保証 |
### MCMC 診断
|診断 |目的 |
|----------|----------|
| **プロットをトレース** |混合と安定性を視覚的にチェック |
| **自己相関** |サンプル依存性を測定します (低い自己相関が必要) |
| **ゲルマン・ルービン (R̂)** |複数のチェーンを比較します。 R^ < 1.05 は収束を示唆します |
| **有効なサンプルサイズ** | N_eff = N / (1 + 2Σρₖ);自己相関を説明する |
| **焼き付き** |チェーンが定常状態に達する前に最初のサンプルを破棄します。

|確率過程 |アプリケーション |
|---------------------|---------------|
|マルコフ連鎖 | マルコフ連鎖PageRank (Web グラフ上のランダム ウォーク)、テキスト生成 (N グラム モデル)、MCMC |
|ランダムウォーク | Node2Vec と DeepWalk (グラフ埋め込み)、RL での探索 |
|ブラウン運動 |生成AIにおける株価モデリング、普及モデル |
|ポアソン過程 |イベント到着 (クリック、失敗)、キュー理論のモデリング |
|マーチンゲール諸島 |金融数学、SGD の収束の証明 (確率的近似) |
|モンテカルロ |期待値推定、ベイズ推論、強化学習（政策評価） |
| MCMC (メトロポリス - ヘイスティングス) |ベイズ事後サンプリング、確率的プログラミング (Stan、PyMC) |
|ギブスサンプリング |トピック モデル (LDA)、ベイジアン ネットワーク、画像ノイズ除去 |
| MCMC診断 |確率モデルからの信頼できる推論を保証する |

＃＃ まとめ
|プロセス |状態空間 |時間 |キープロパティ |
|----------|---------------|----------|--------------|
|マルコフ連鎖 |離散/連続 |離散/連続 |メモリレス (マルコフ特性) |
|ランダムウォーク | ℤᵈ |離散 | i.idの合計ステップ |
|ブラウン運動 | ℝ |連続 |ガウス増分、連続パス |
|ポアソン過程 | ℕ |連続 |指数関数的なギャップのある計数プロセス |
|マーチンゲール | ℝ |離散/連続 |フェアゲーム (E[X_{t+1}|F_t] = X_t) |
確率過程は、時間の経過に伴うランダム性の数学です。これらは、現代ベイズ推論 (MCMC)、強化学習 (マルコフ決定プロセス)、生成モデリング (拡散モデル)、金融数学、およびキュー理論を支えています。これらのプロセスを理解すると、不確実性をスナップショットとしてだけでなく、その進化に合わせて動的にモデル化するツールが得られます。
