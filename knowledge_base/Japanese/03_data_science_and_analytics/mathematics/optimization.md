＃ 最適化
最適化は、一連の実行可能なソリューションから最適なソリューションを見つける数学です。それは、関数と制約が与えられたときに、どの入力が出力を最小化 (または最大化) するのかを尋ねます。最適化は機械学習のエンジンです。モデルをトレーニングするということは、損失関数を最小化することを意味します。これは、オペレーションズ リサーチ、経済学、エンジニアリング設計、および事実上あらゆる定量的分野に現れます。
---

## 問題の定式化
一般的な **最適化問題** の形式は次のとおりです。
f(x) を最小化する
条件: gᵢ(x) ≤ 0 (不等式制約)、hⱼ(x) = 0 (平等制約)
|用語 |意味 |
|-----|----------|
| **目的関数** f(x) |最小化 (または最大化) する量 |
| **意思決定変数** x |私たちが制御できる値 |
| **実現可能な地域** |すべての制約を満たすすべての x のセット |
| **グローバル最小値** |すべての実現可能な x に対して f(x*) ≤ f(x) となる実現可能な x* |
| **局所最小値** |ある近傍のすべての実現可能な x に対して f(x*) ≤ f(x) となる実現可能な x* |
| **凸問題** | f は凸、実現可能な領域は凸セット (ローカル最小値 = グローバル最小値) |
---

## 線形計画法 (LP)
目的とすべての制約の両方が **線形** の場合、問題は線形計画になります。
### 標準フォーム
最小化
条件: Ax ≤ b、x ≥ 0
ここで、c、x ∈ ℝⁿ、A ∈ ℝᵐˣⁿ、b ∈ ℝᵐです。
### プロパティ
|プロパティ |声明 |
|----------|----------|
|凸面 | LP は常に凸問題です |
|最適なソリューション |常に実現可能な多面体の頂点 (コーナー点) にあります |
|存在 |実行可能な領域が制限されており、空でない場合、最適な解決策が存在します。
|複数の最適化 | 2 つの頂点が最適であれば、それらの間のエッジ上のすべての点も最適になります。
### シンプレックス法
**シンプレックス法** (Dantzig、1947) は、実現可能な多面体のエッジに沿って頂点から頂点へと移動し、最適に到達するまで常に目的を改善します。
|プロパティ |値 |
|----------|----------|
|最悪の場合の時間 | O(2ⁿ) (指数関数的 — 実際にはまれです) |
|平均ケース時間 |ほとんどの実際的な問題に対する多項式 |
|重要なアイデア |より良い目標値を持つ隣接する頂点に移動 |
**アルゴリズム (概要):**
1. 基本的な実現可能な解決策 (多面体の頂点) から開始します。
2. 参入変数 (目的を改善する変数) を選択します。
3. 離脱変数を選択する (実現可能性を維持する)
4. ピボット: 新しい頂点に移動します。
5. 改善の方向性がなくなるまで繰り返します
### 内点法
シンプレックスの代替: 実行可能領域内から最適値にアプローチします。
|プロパティ |値 |
|----------|----------|
|最悪の場合の時間 |多項式 (一部のバリアントでは O(n³·⁵)) |
|実用性能 |大規模な問題ではシンプレックスと競合 |
|重要なアイデア |内部を通る「中央の道」をたどる |
### 成功したLPの例
**問題:** 工場では椅子 (x₁) とテーブル (x₂) を生産しています。
- 利益: 椅子 1 脚あたり 30 ドル、テーブル 1 脚あたり 50 ドル
- 木材: 2x₁ + 4x₂ ≤ 100 (ボードフィートも利用可能)
- 労働時間: x₁ + 3x₂ ≤ 60 (利用可能な時間)
- 最大化: 30x₁ + 50x₂
**解法 (2 変数のグラフィカルな方法):**
- 実行可能領域の頂点: (0,0)、(30,0)、(40,10)、(0,20)
- 各頂点での目標を評価します。
  - (0,0): 利益 = 0
  - (30,0): 利益 = 900
  - (40,10): 利益 = 1700 ← 最適
  - (0,20): 利益 = 1000
- **最適:** x₁ = 椅子 40 脚、x₂ = テーブル 10 脚、利益 = 1700 ドル

## 凸型最適化
目的関数が凸で、実行可能領域が凸集合である場合、問題は **凸** です。
### 凸集合と関数
|コンセプト |定義 |
|-----------|-----------|
| **凸セット** |集合内の任意の x、y および t ∈ [0,1] について: tx + (1−t)y も集合内にあります。
| **凸関数** |すべての t ∈ [0,1] に対して f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) |
| **厳密に凸型** |不等式は t ∈ (0,1) および x ≠ y に対して厳密です。
**重要なプロパティ:** 凸最適化の場合、すべての局所最小値は大域最小値になります。
### 一般的な凸関数
|機能 |凸？ |どこ |
|----------|-----------|----------|
| ax + b (線形) |はい (凹型) |どこでも |
| x² |はい | ℝ |
| eˣ |はい | ℝ |
| −log(x) |はい | x > 0 |
| \|x\|ᵖ (p ≥ 1) |はい | ℝⁿ |
| max(f₁, f₂) f₁, f₂ 凸の場合 |はい |ドメインの交差 |
### 勾配降下法
機械学習における最も基本的な最適化アルゴリズム。
**更新ルール:** x_{k+1} = x_k − α∇f(x_k)
ここで、α > 0 は **学習率** (ステップ サイズ) です。
|バリアント |更新ルール |利点 |
|----------|---------------|----------|
| **バッチ GD** | x ← x − α∇f(x) |安定した収束 |
| **確率的 GD (SGD)** | x ← x − α∇fᵢ(x) (1 サンプル) |反復あたりの速度が速く、極小値を回避します。
| **ミニバッチ SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) |バッチと確率のバランス |
| **勢い** | v ← βv − α∇f(x); x ← x + v |平坦な領域でも加速 |
| **アダム** |パラメータごとの適応学習率 |深い学習にそのまま使用しても問題なく動作します。
| **RMSprop** |勾配の大きさの移動平均による学習率のスケール | RNN に適しています |
### 収束率
|方法 |凸 f |強凸f |
|----------|----------|--------|
|勾配降下 | O(1/k) | O((1−μ/L)ᵏ) (線形) |
|シンガポールドル | O(1/√k) | O(1/k) |
|加速GD (ネステロフ) | O(1/k²) | O((1−√(μ/L))ᵏ) |
ここで、k = 反復回数、μ = 強い凸パラメータ、L = リプシッツ定数です。
### 学習率の選択
|戦略 |説明 |
|----------|---------------|
|固定α |シンプルですが、発散する (大きすぎる) か、ゆっくりと収束する (小さすぎる) 可能性があります。
|ライン検索 |勾配方向に沿って f(x − α∇f(x)) を最小化する α を見つけます。
|崩壊スケジュール | α_t = α₀ / (1 + βt) または α_t = α₀ · βᵗ |
|ウォームアップ |小さく開始し、増加し、その後減衰します (トランスフォーマーのトレーニングで一般的) |
|アダプティブ (アダム) |勾配統計に基づくパラメータごとの学習率 |

## 制約付きの最適化
### ラグランジュ乗数
問題の場合: h(x) = 0 を条件として f(x) を最小化します。
**ラグランジアン:** L(x, λ) = f(x) + λh(x)
最適な場合: ∇ₓL = 0 および ∇_λL = 0 (これにより h(x) = 0 が得られます)。
**作業例:** x + y = 1 を条件として f(x,y) = x² + y² を最小化します。
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- 制約: x + y = 1 → −λ = 1 → λ = −1
- 解: x = 1/2、y = 1/2、f = 1/2
### KKTの条件
**Karush-Kuhn-Tucker (KKT) 条件** は、ラグランジュ乗数を不等式制約に一般化します。
例: gᵢ(x) ≤ 0、hⱼ(x) = 0 を条件として f(x) を最小化します。
**ラグランジアン:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT 条件** (最適化のために必要):
|状態 |方程式 |
|----------|----------|
|定常性 | ∇ₓL = 0 |
|基本的な実現可能性 | gᵢ(x) ≤ 0、hⱼ(x) = 0 |
|二重の実現可能性 | λᵢ ≥ 0 |
|補完的なたるみ |すべての i について λᵢgᵢ(x) = 0 |
**相補的緩み** は、制約 gᵢ がアクティブでない場合 (gᵢ(x) < 0)、λᵢ = 0 (制約は解に影響を与えない) を意味します。
スレーター条件を満たす凸問題の場合、KKT 条件は必要かつ十分です。

## 二重性
すべての最適化問題 (**基本**) には、関連する**双対** 問題があります。
### 弱さと強さの二元性
|コンセプト |声明 |
|----------|----------|
| **デュアル機能** | g(λ, ν) = infₓ L(x, λ, ν) |
| **二重の問題** | λ ≥ 0 | を条件として g(λ, ν) を最大化します。
| **弱い二重性** |二重最適 ≤ 主最適 (常に成り立つ) |
| **強い二面性** |二重最適 = 主最適 (スレーター条件の凸問題に当てはまります) |
| **二重性のギャップ** |主最適 − 二重最適 (強い双対性の下ではゼロ) |
### なぜ二元性が重要なのか
|アプリケーション |二元性がどのように役立つのか |
|-----------|-----------|
|下限 | Dual は、主要なソリューションがどれほど優れているかを証明します。
| SVM | SVM の問題の二重性はカーネルのトリックにつながります。
|感度分析 |二重変数は、制約が緩和された場合に最適値がどの程度変化するかを測定します。
|分解 |大きな問題は、二重 | | を介して小さなサブ問題に分割できます。

## 整数計画法
一部またはすべての変数が **整数** でなければならない場合、問題はさらに難しくなります (一般に NP 困難)。
＃＃＃ 種類
|タイプ |説明 |
|------|---------------|
|ピュアIP |すべての変数は整数でなければなりません |
|混合 IP (MIP) |一部の変数は整数、一部は連続 |
|バイナリ IP |変数は {0, 1} に制限されます |
### 解決方法
|方法 |アイデア |
|------|------|
| **分岐と拘束** |サブ問題に分割し、LP 緩和を解決し、枝刈り |
| **切断平面** |線形制約を追加して LP 緩和を強化します。
| **分岐と切断** |分岐結合と切断面を組み合わせる |
| **ヒューリスティック** |貪欲、局所探索、近似解のシミュレーテッドアニーリング |
---

## ヒューリスティック手法とメタヒューリスティック手法
正確な最適化が難しい場合は、ヒューリスティックによって適切な (必ずしも最適ではない) 解決策が見つかります。
|方法 |主要なアイデア |最適な用途 |
|----------|----------|----------|
| **勾配降下法** |最も急な下り坂をたどる |滑らかで微分可能な関数 |
| **ニュートン法** | 2 次 (曲率) 情報を使用する |スムーズでよく調整された問題 |
| **模擬アニーリング** |確率が減少する、より悪い解決策を受け入れる |大域的最適化、組み合わせ |
| **遺伝的アルゴリズム** |選択、交叉、突然変異を使用して集団を進化させる |多目的、微分不可能 |
| **粒子の群れ** |エージェントは最もよく知られている位置に影響を受けて宇宙を探索します |連続、非凸 |
| **ベイズ最適化** |サロゲートモデルの構築、取得関数の使用 |高価なブラックボックス関数 (ハイパーパラメータ調整) |
### ニュートンの最適化法
**更新ルール:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
ここで、H はヘッセ行列 (二次導関数の行列) です。
|プロパティ |値 |
|----------|----------|
|収束率 |二次関数 (最適に近い) |
|反復ごとのコスト | O(n³) ヘッセ行列反転 |
|必要なもの | 2 回微分可能、正定値ヘッセ行列 |
|準ニュートン (BFGS) |勾配からの近似ヘシアン |反復あたり O(n²) |

## 機械学習とデータ サイエンスとの関連性
|最適化のコンセプト |アプリケーション |
|---------------------|---------------|
|勾配降下 |ニューラル ネットワーク、ロジスティック回帰、微分可能なモデルのトレーニング |
| SGD とバリアント |大規模 ML (ミニバッチ トレーニング)、オンライン学習 |
|アダム、RMSprop |深層学習のデフォルトのオプティマイザー |
|凸最適化 | SVM、ロジスティック回帰、LASSO、Ridge (グローバルな最適性を保証) |
|ラグランジュ乗数 |制約付き学習、公平な ML、リソース割り当て |
| KKTの条件 | SVM デュアルの導出、制約アクティビティの理解 |
|二重性 | SVM カーネルのトリック、感度分析、分解方法 |
|線形計画法 |リソース割り当て、ポートフォリオ最適化、ネットワークフロー |
|整数計画法 |特徴選択 (バイナリ)、スケジューリング、組み合わせ問題 |
|ベイズ最適化 |ハイパーパラメータ調整 (Optuna、Hyperopt) |
|ニュートン/準ニュートン |中小規模の問題に対する二次手法 (L-BFGS) |

＃＃ まとめ
|方法 |問題の種類 |保証 |スケール |
|----------|---------------|---------------|----------|
|シンプレックス |線形計画法 |正確な最適 |数百万の変数 |
|インテリアポイント |凸型 (LP、QP、SOCP) |正確な最適 |大規模 |
|勾配降下 |スムーズな拘束なし |ローカル最小値に収束します |非常に大規模 (深層学習) |
|シンガポールドル |大規模な経験的リスク |収束（減衰あり） |大規模なデータセット |
|ニュートン / BFGS |滑らか、二回微分可能 |二次収束 |中小規模 |
| KKT / ラグランジュ |拘束（凸） |条件下で正確 |中 |
|枝と束縛 |整数計画法 |正確な最適 |中小規模 |
|ヒューリスティック |任意 (非凸、組み合わせ) |保証なし |さまざま |
最適化はおそらく、機械学習において最も重要な数学的ツールです。線形回帰から大規模な言語モデルまで、トレーニングするすべてのモデルには、最適化問題の解決が含まれます。問題が凸である場合 (大域的最適性が保証されている)、勾配降下法が収束する場合、および制約の処理方法を理解することで、学習アルゴリズムを設計、デバッグ、改善するための理論的基礎が得られます。
