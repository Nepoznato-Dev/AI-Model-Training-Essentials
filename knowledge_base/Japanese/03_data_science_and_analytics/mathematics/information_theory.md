# 情報理論
1948 年にクロード シャノンによって確立された情報理論は、情報そのものを定量化します。メッセージはどれくらい伝えてくれますか?データをどの程度圧縮できますか?ノイズの多いチャネル上でどれくらいの速度で通信できますか?これらの質問には正確な数学的答えがあります。通信を超えて、情報理論は機械学習の基礎となっています。クロスエントロピーは分類のデフォルトの損失関数であり、KL 発散は分布の類似性を測定し、相互情報量は特徴の選択を推進します。
---

## エントロピー
**エントロピー**は、確率変数の平均的な不確実性または「驚き」を測定します。
### シャノンのエントロピー (離散)
確率質量関数 p(x) を持つ離散確率変数 X の場合:
H(X) = −Σₓ p(x) log₂ p(x)
単位: **bits** (log₂ を使用する場合) または **nats** (ln を使用する場合)。
|配布 |エントロピー |直感 |
|---------------|-----------|----------|
|公正なコイン (p = 0.5, 0.5) | 1ビット |バイナリ結果の最大不確実性 |
|バイアスのあるコイン (p = 0.9, 0.1) | 0.469ビット |それほど驚くべきことではありません - ほとんどが頭 |
|決定論的 (p = 1, 0) | 0ビット |まったく不確実性はありません |
|フェアダイス（6面）｜ 2.585ビット |より多くの結果 = より多くの不確実性 |
| n 個にわたる均一な結果 | log₂(n) ビット | n 個の結果の最大エントロピー |
### エントロピーの性質
|プロパティ |声明 |
|----------|----------|
|非否定性 | H(X) ≧ 0 |
|最大 | H(X) ≤ log₂(\|X\|) 一様分布の場合 |
|チェーンルール | H(X, Y) = H(X) + H(Y \| X) |
|コンディショニングが減少する | H(X \| Y) ≤ H(X) |
|凹面 | H は確率分布の凹関数です |
### 微分エントロピー (連続)
密度 p(x) の連続確率変数 X の場合:
h(X) = −∫ p(x) log p(x) dx
離散エントロピーとは異なり、微分エントロピーは**負**になる可能性があります。
|配布 |微分エントロピー |
|---------------|----------|
| [a,b] のユニフォーム | log(b − a) |
|正規 N(μ, σ²) | (1/2) log(2πeσ²) |
|指数関数(λ) | 1 − ln(λ) |

## 共同情報、条件付き情報、および相互情報
### 結合エントロピー
H(X, Y) = −Σₓ Σᵧ p(x, y) log p(x, y)
ペア (X, Y) の合計の不確実性を測定します。
### 条件付きエントロピー
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
X を観察した後に Y について残っている不確実性を測定します。
### 相互情報
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
X を知っていると Y についてどれだけ分かるか (またはその逆) を測定します。
|プロパティ |声明 |
|----------|----------|
|非否定性 | I(X; Y) ≥ 0 |
|対称性 | I(X; Y) = I(Y; X) |
|エントロピーとの関係 | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
|ジョイントとの関係 | I(X; Y) = H(X) + H(Y) − H(X, Y) |
|独立 | X と Y が独立している場合、I(X; Y) = 0 |
|自己情報 | I(X; X) = H(X) |
### ビジュアル: エントロピー図
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## KL ダイバージェンス
**カルバック-ライブラー (KL) ダイバージェンス** は、ある分布が別の分布とどれだけ異なるかを測定します。
D_KL(P || Q) = Σₓ P(x) log [P(x) / Q(x)]
|プロパティ |声明 |
|----------|----------|
|非否定性 | D_KL(P \|\| Q) ≥ 0 (ギブスの不等式) |
|アイデンティティ | D_KL(P \|\| Q) = 0 (P = Q | の場合)
|非対称 |一般に D_KL(P \|\| Q) ≠ D_KL(Q \|\| P)
|指標ではありません |対称性と三角不等式の失敗 |
**解釈:** D_KL(P || Q) は、Q に最適化されたコードを使用して P からのデータをエンコードするために必要な追加のビット数です。
### 他の数量との関係
|関係 |式 |
|-----------|-----------|
|クロスエントロピー | H(P, Q) = H(P) + D_KL(P \|\| Q) |
|相互情報 | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
|条件付き KL | D_KL(P(Y\|X) \|\| Q(Y\|X)) X の平均値 |

## クロスエントロピー
分布 P と Q 間の **相互エントロピー**:
H(P, Q) = −Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### 損失関数としてのクロスエントロピー
分類では、P は真の分布 (ワンホット エンコードされたラベル) で、Q はモデルの予測分布です。
**バイナリクロスエントロピー (BCE):**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**カテゴリカルクロスエントロピー:**
L = −Σᵢ yᵢ log(ŷᵢ)
|シナリオ | y (真) | ŷ (予測) |損失 |
|----------|----------|----------|-----|
|正しい、自信がある | 1 | 0.95 | 0.051 |
|正しい、不確実 | 1 | 0.55 | 0.598 |
|間違っています、自信があります | 1 | 0.05 | 2.996 |
|間違っている、不確か | 1 | 0.45 | 0.799 |
クロスエントロピーを最小限に抑えることは、真の分布からの KL 発散を最小限に抑えることと同じです。これが、損失関数が非常にうまく機能する理由です。

## チャネル容量
### 通信チャネルモデル
```
X → [Channel] → Y
```

- X: 入力確率変数
- Y: 出力確率変数
- チャネル: 条件付き確率 p(y|x) によって定義されます。
### シャノンのノイジー チャネル符号化定理
容量 C のチャネルの場合、伝送速度 R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C の場合、安定した通信は不可能です。
**チャンネル容量:**
C = max_{p(x)} I(X; Y)
### 重要なチャネルの例
|チャンネル |説明 |容量 |
|----------|---------------|----------|
| **二値対称 (BSC)** |確率 p | で各ビットを反転します。 1 − H(p) ビット |
| **バイナリ消去 (BEC)** |各ビットを確率 ε | で消去します。 1 − ε ビット |
| **ガウス (AWGN)** | Y = X + Z、Z ~ N(0, σ²) | (1/2)log(1 + SNR) ビット |
| **ノイズレスバイナリ** |完璧なトランスミッション | 1ビット |

## ソースコーディングと圧縮
### ソースコーディング定理
ソースをエンコードするために必要な平均ビット数は、そのエントロピーによって以下の制限を受けます。
L≧H(X)
最適なコードは、L ≈ H(X) を達成します。
### ハフマンコーディング
**プレフィックスフリー** コード。より確率の高いシンボルに短いコードを割り当てます。
|記号 |確率 |ハフマンコード |長さ |
|----------|---------------|---------------|----------|
|あ | 0.5 | 0 | 1 |
| B | 0.25 | 10 | 2 |
| C | 0.125 | 110 | 3 |
| D | 0.125 | 111 | 3 |
平均長: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 ビット/シンボル
エントロピー: H = 1.75 ビット/シンボル (この場合最適!)
### 可逆圧縮と非可逆圧縮
|タイプ |原則 |例 |制限 |
|------|-----------|----------|----------|
| **ロスレス** |統計的な冗長性を削除 | ZIP、PNG、FLAC |エントロピー率 H(X) |
| **不可逆** |知覚的に無関係な情報を削除する | JPEG、MP3、H.264 |レート歪み関数 R(D) |
**レート歪み理論:** 最大歪み D の非可逆圧縮の場合、E[d(X, X̂)] ≤ D の条件下で、最小レートは R(D) = min I(X; X̂) となります。

### 情報理論と熱力学
|コンセプト |情報理論 |熱力学 |
|---------|-------------------|----------------|
|エントロピー |シャノンのエントロピー H(X) |ボルツマンエントロピー S = k_B ln W |
|最大エントロピー |一様分布 |熱平衡 |
| KLダイバージェンス |分布の違い |自由エネルギーの差 |
|相互情報 |共有情報 |物理システムの相関関係 |
数学的な形式は同一です。シャノンは統計力学から「エントロピー」という用語を意図的に借用しました。
### 情報理論と統計
|コンセプト |アプリケーション |
|----------|---------------|
|最大尤度 |経験的分布からモデル分布への KL 発散を最小限に抑えることと同等 |
|フィッシャー情報 | KL 発散の曲率;推定量分散の下限 (Cramér-Rao) |
|最小説明長 (MDL) |エンコード長の合計を最小限に抑えることによるモデルの選択 |
| AIC / BIC | KL ベースのモデル選択基準の概算 |

情報理論は、学習、圧縮、伝達できる内容の基本的な制限を提供します。機械学習の実践者向けに、クロスエントロピーが損失関数として機能する理由、学習された表現の品質を測定する方法、モデルの複雑さとデータの適合性の間のトレードオフについて考える方法について説明します。 1948 年のシャノンの洞察は、電気通信と同様に現代の AI にも依然として関連しています。
