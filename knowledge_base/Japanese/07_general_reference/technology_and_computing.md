# テクノロジーとコンピューティング
携帯電話、車、冷蔵庫、医療機器、現代社会を運営するインフラストラクチャなど、コンピューティングはあらゆる場所に存在します。プログラマーでなくても、すべての仕組みを理解することができます。このファイルには、コンピューターとは何か、インターネットがどのように機能するか、ソフトウェアがどのように構築されるか、デジタル世界を形作る概念などの基本事項が含まれています。

## コンピューターとは何ですか?
スマートフォンからスーパーコンピューターに至るまで、すべてのコンピューターはその中核では同じことを行います。入力を受け取り、それを命令 (プログラム) に従って処理し、出力を生成します。魔法はスピードとスケールにあります。
### フォン・ノイマン・アーキテクチャ
最近のほとんどすべてのコンピューターは、次の基本設計に従っています。
|コンポーネント |何をするのか |類推 |
|----------|---------------|----------|
| **CPU** (中央処理装置) |命令を実行します。 「脳」 |レシピに従うシェフ |
| **RAM** (メモリ) | CPU がアクティブに使用しているデータを保存します。電源がオフになると失われる |カウンタートップ — 迅速なアクセス、限られたスペース |
| **ストレージ** (SSD/HDD) |データを永続的に保存 |パントリー — アクセスが遅くなり、スペースが大幅に増加 |
| **入力/出力** |キーボード、マウス、画面、ネットワーク |シェフが注文を受けて料理を提供する方法 |
| **GPU** (グラフィックス プロセッシング ユニット) |並列タスク (グラフィックス、AI) に特化したプロセッサ |アシスタントのチームが全員同時に同じタスクを実行する |
**重要な洞察**: RAM は高速ですが、一時的です。ストレージは遅いですが永続的です。コンピュータが「遅い」と感じるときは、多くの場合、RAM が不足しており、ストレージを一時メモリ (スワッピング) として使用する必要があるため、速度が大幅に低下します。

プログラミング言語は、コンピューターが実行できる一連の命令です。異なる言語は異なる目的のために設計されています。 34 の個別言語の詳細については、[`programming_languages/`](../01_coding_and_technology/programming_languages/) フォルダーを参照してください。
|言語 |最適な用途 |それを選ぶ理由 |
|----------|-----------|---------------|
| **Python** |データ サイエンス、AI、自動化、Web バックエンド |シンプルな構文。巨大な生態系。初心者に最適 |

| **行く** |クラウド サービス、マイクロサービス、CLI ツール |単純;優れた同時実行性。高速コンパイル |
| **SQL** |データベースクエリ |データを操作するための汎用言語 |
| **TypeScript** |大規模な Web アプリケーション |型チェックを備えた JavaScript。バグを早期に発見します |

## インターネットの仕組み
インターネットはウェブと同じものではありません。インターネットは、数十億のデバイスを接続するケーブル、ルーター、サーバー、プロトコルなどの物理ネットワークです。 World Wide Web は、インターネット上で実行されるサービスの 1 つです (電子メール、ファイル転送、ストリーミング、ゲームなどとともに)。
### Web リクエストの流れ
ブラウザに`https://www.example.com`と入力すると、次のようになります。
1. **DNS ルックアップ**: ブラウザは DNS サーバーに「www.example.com」を IP アドレス (93.184.216.34 など) に変換するよう要求します。
2. **TCP 接続**: デバイスは、TCP (信頼性の高い配信を保証するプロトコル) を使用して、その IP アドレスへの接続を確立します。
3. **TLS ハンドシェイク**: HTTPS を使用している場合、ブラウザとサーバーは暗号化された接続をネゴシエートします。
4. **HTTP リクエスト**: ブラウザは「/index.html のページをください」というリクエストを送信します。
5. **サーバー処理**: Web サーバーはページを見つけ、場合によってはデータベースにクエリを実行し、応答を準備します。
6. **HTTP 応答**: サーバーは HTML、CSS、および JavaScript を送り返します。
7. **レンダリング**: ブラウザは HTML を解析し、CSS スタイルを適用し、JavaScript を実行してページを表示します。
通常、このプロセス全体には 1 秒もかかりません。
### 主要なプロトコル
|プロトコル |何をするのか |レイヤー |
|----------|---------------|----------|
| **IP** (インターネット プロトコル) |ネットワーク間でパケットをルーティングします。ネットワーク |
| **TCP** |信頼性の高い順序付けられた配信 (失われたパケットを再送信) |輸送 |
| **UDP** |高速で信頼性の低い配信 (再送信なし) |輸送 |
| **HTTP/HTTPS** | Web ページ転送 (HTTPS による暗号化の追加) |アプリケーション |
| **DNS** |ドメイン名を IP アドレスに変換します |アプリケーション |
| **SSH** |コンピュータへの安全なリモート アクセス |アプリケーション |
| **SMTP/IMAP** |メールの送受信 |アプリケーション |

## ソフトウェア開発 — プログラムの構築方法
### 開発プロセス
1. **コードを書く**: 開発者はプログラミング言語で命令を書きます。
2. **テストコード**: コードを実行して、正しく動作することを確認します。
3. **バージョン管理**: 世界標準の Git を使用して変更を追跡します。
4. **レビュー**: 他の開発者がコードのエラーと品質をチェックします。
5. **ビルド**: ソース コードを実行可能なプログラムに変換します (コンパイル)。
6. **展開**: プログラムをユーザー (サーバー、アプリ ストアなど) にリリースします。
7. **監視**: 本番環境でのエラーやパフォーマンスの問題を監視します。
### 主要な概念
|コンセプト |意味 |なぜそれが重要なのか |
|-------|---------------|--------------|
| **バージョン管理 (Git)** |コードへのすべての変更を時間の経過とともに追跡する |コラボレーション;間違いを元に戻す能力 |
| **API** (アプリケーション プログラミング インターフェイス) |ソフトウェアコンポーネントが通信するための定義された方法 |異なるシステムの連携を可能にする |
| **データベース** |データの整理されたストレージ |すべてのアプリケーションはデータを保存および取得する必要があります。
| **テスト** |コードが正しく動作するかどうかを自動チェックします。バグがユーザーに到達するのを防ぎます |
| **CI/CD** (継続的インテグレーション/デリバリー) |コードコミットから本番環境までの自動パイプライン |より速く、より安全なリリース |
| **コンテナ化 (Docker)** |アプリケーションをすべての依存関係とともにパッケージ化する | 「自分のマシンで動作」が「どこでも動作」になる |

## データベース — データが存在する場所
すべてのアプリケーションはデータを保存する必要があります。データベースは、これを効率的かつ確実に行うシステムです。
|タイプ |データの保存方法 |最適な用途 |例 |
|-----|--------|----------|----------|
| **リレーショナル (SQL)** |行と列を含むテーブル。厳密なスキーマ |構造化データ。複雑なクエリ。取引 | PostgreSQL、MySQL、SQLite |
| **ドキュメント (NoSQL)** | JSON のようなドキュメント。柔軟なスキーマ |半構造化データ。迅速な反復 | MongoDB、CouchDB |
| **キーと値** |単純なキー → 値のペア |キャッシング;セッションストレージ。高速検索 | Redis、DynamoDB |
| **グラフ** |ノードとエッジ (関係) |ソーシャルネットワーク;レコメンデーションエンジン | Neo4j、ヤヌスグラフ |
| **時系列** |タイムスタンプ付きデータ用に最適化 |監視;分析; IoT | InfluxDB、TimescaleDB |
**SQL** (構造化照会言語) は、リレーショナル データベースの標準言語です。これは、学習できる最も貴重な技術スキルの 1 つです。ほぼすべての組織がデータベースを使用しており、SQL はそれらと対話する手段です。

## オペレーティング システム
オペレーティング システム (OS) は、ユーザー (およびプログラム) とハードウェアの間のソフトウェア層です。メモリ、プロセス、ファイル、デバイスを管理します。
| OS |それが支配する場所 |主な機能 |
|----|--------|-------------|
| **Windows** |デスクトップ/ラップトップ PC (市場シェア約 72%) |最も広範なソフトウェア/ハードウェア互換性 |
| **macOS** |クリエイティブプロフェッショナル、開発者 | Unix ベース。洗練されたUI。アップルのエコシステム |
| **Linux** |サーバー (~96%)、スーパーコンピューター (100%)、組み込み、開発者 |オープンソース。無料;非常にカスタマイズ可能 |
| **アンドロイド** |モバイル (世界市場シェア約 72%) | Linux カーネルに基づいています。オープンソース |
| **iOS** |モバイル (全世界で約 27%、ただし収益は高い) |閉鎖的なエコシステム。磨かれた;プライバシー重視 |
Linux は特筆に値します。Linux は、ほとんどのインターネット、トップ 500 に入るすべてのスーパーコンピューター、ほとんどのクラウド インフラストラクチャ、およびすべての Android スマートフォンに電力を供給しています。これは無料、オープンソースであり、グローバル コミュニティによって維持されています。

## クラウド コンピューティング
クラウド コンピューティングとは、独自のハードウェアを購入して保守するのではなく、インターネット経由でコンピューティング リソース (サーバー、ストレージ、データベースなど) をレンタルすることを意味します。クラウド アーキテクチャ、サービス モデル、プロバイダーの比較に関する包括的なガイドについては、「[cloud architecture](../01_coding_and_technology/cloud_architecture.md)」を参照してください。
|サービスモデル |得られるもの |類推 |例 |
|--------------|-------------|----------|----------|
| **IaaS** (インフラストラクチャ) |仮想サーバー、ストレージ、ネットワーキング |土地を借りて好きなものを建てる | AWS EC2、Google Compute Engine |
| **PaaS** (プラットフォーム) |ランタイム環境。コードを持ってきます |家具付きアパートを借りる | Heroku、Google App Engine |
| **SaaS** (ソフトウェア) |申請を完了します。それを使うだけです |ホテルに泊まる | Gmail、Slack、Salesforce |
3 つの主要なクラウド プロバイダーは、**AWS** (Amazon、市場シェア約 32%)、**Azure** (Microsoft、約 23%)、*​​GCP** (Google、約 10%) です。彼らは、コンピューティング、ストレージ、データベース、AI、ネットワーキングなどをカバーする何百ものサービスを提供しています。

## サイバーセキュリティ — デジタル システムの保護
サイバーセキュリティは、コンピュータ、ネットワーク、データを攻撃から守る実践です。すべてがつながっており、侵害のコストは莫大であるため、これは重要です。 OWASP トップ 10、安全な開発ライフサイクル、およびシークレット管理をカバーする完全なガイドについては、「」を参照してください。
### 一般的な脅威
|脅威 |それは何ですか |予防 |
|----------|-----------|---------------|
| **マルウェア** |悪意のあるソフトウェア (ウイルス、ワーム、トロイの木馬) |ウイルス対策;ソフトウェアを最新の状態に保つ |
| **フィッシング** |偽のメール/メッセージで情報を漏らすよう騙す |トレーニング;電子メールのフィルタリング。懐疑論 |
| **ランサムウェア** |データを暗号化します。キーの支払いを要求します |バックアップ;パッチシステム。支払わない |
| **DDoS** |トラフィックでサービスを圧倒する |トラフィックフィルタリング。 CDN 保護 |
| **SQL インジェクション** |悪意のある SQL を入力フィールドに挿入する |パラメータ化されたクエリ。入力検証 |
| **中間者** |二者間の通信の傍受 | HTTPS/TLS 暗号化 |
### セキュリティの基礎
- **暗号化**: データをスクランブルして、許可された当事者だけがデータを読み取れるようにします。 HTTPS は TLS を使用して Web トラフィックを暗号化します。
- **認証**: 身元を確認します。多要素認証 (MFA)、つまりパスワード + 他のもの (コード、生体認証) を使用します。
- **権限**: 権限を確認します。ログインしているからといって、すべてにアクセスする必要があるというわけではありません。
- **最小特権の原則**: ユーザーとシステムに必要なアクセスのみを与え、それ以上は与えません。
- **パッチ管理**: ソフトウェアを常に最新の状態に保ちます。ほとんどの侵害は、すでにパッチが適用されている既知の脆弱性を悪用します。

## データ形式
プログラムは特定の形式でデータを交換します。最も一般的なもの:
|フォーマット |構造 |用途 |
|----------|-----------|----------|
| **JSON** |キーと値のペア。人間が読める | API;構成;データ交換 |
| **XML** |タグベース。冗長だが柔軟 |レガシーシステム。書類; SOAP API |
| **YAML** |インデントベース。とても読みやすい |構成 (Docker、Kubernetes、CI/CD) |
| **CSV** |プレーンテキストの行と列 |データのインポート/エクスポート。スプレッドシート |

＃＃ まとめ
コンピューティングは魔法ではなく、エンジニアリングです。コンピューターは信じられないほどの速度で命令に従います。インターネットは、標準化されたプロトコルを使用して何十億もの人々を接続します。ソフトウェアは、反復サイクルでコードを作成、テスト、デプロイする人々のチームによって構築されます。データベースはデータを保存および取得します。クラウド コンピューティングにより、誰でもオンデマンドで大規模なコンピューティング リソースにアクセスできるようになります。そして、サイバーセキュリティは、これらすべてを悪用しようとする人々から安全を守るための継続的な戦いです。これらの基本を理解することは、ユーザーであっても、開発者であっても、あるいは現代の生活を形作っているテクノロジーを理解しようとしているだけの人であっても、デジタル世界をナビゲートするのに役立ちます。
