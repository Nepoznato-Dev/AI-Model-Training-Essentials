# 研究方法
研究方法論は、疑問を調査し、仮説を検証し、信頼できる知識を生成するための体系的なアプローチです。科学実験、社会科学調査、ビジネス分析、学術研究のいずれを実施する場合でも、選択した方法論によって、結果が信頼でき、再現可能で、有用であるかどうかが決まります。適切に設計された研究は信頼できる結果をもたらします。設計が不十分だとノイズが発生したり、さらに悪いことに自信を持って間違った答えが生じたりします。
---

## 研究の種類
|寸法 |オプション |説明 |
|----------|-----------|---------------|
| **目的** |基本と応用 |基本: それ自体のために知識を拡張すること。応用: 実際の問題を解決する |
| **アプローチ** |演繹的 vs 帰納的 |演繹：理論→仮説→観察。帰納的: 観察 → パターン → 理論 |
| **データ型** |定量的 vs 定性的 vs 混合 |定量的: 数字。質的: 言葉、意味。混合: 両方 |
| **時間軸** |断面と縦方向 |断面: ある時点。縦方向: 時間の経過 |
| **設定** |実験的 vs 観察的 |実験的: 研究者が変数を操作します。観察的: 研究者は介入なしで観察します |
---

## 科学的方法
|ステップ |説明 |
|------|---------------|
| **1.観察** |現象やパターンに注目してください |
| **2.質問** |具体的でテスト可能な質問を立てる |
| **3.仮説** |暫定的な説明または予測を提案する |
| **4.予測** |仮説から検証可能な予測を導き出す |
| **5.実験・観察** |データを収集して予測をテストする |
| **6.分析** |データを分析します。結果が仮説を裏付けるか反駁するかを判断する |
| **7.結論** |結論を導き出す。制限を考慮する。さらなる研究を提案する |
| **8.ピアレビューと複製** |他の人は結果を評価し、再現しようと試みます。

## 定量的調査
### 実験計画
|デザイン |説明 |強さ |弱点 |
|----------|---------------|----------|----------|
| **真の実験 (RCT)** |治療と対照へのランダムな割り当て |最も強力な因果関係の証拠 |高い;一般化できないかもしれません |
| **疑似実験** |ランダムな割り当てはありません。比較グループ |より実用的。現実世界の設定 |交絡変数 |
| **事前テスト / 事後テスト** |介入前後の測定 |時間の経過に伴う変化を示す |外部要因を制御できない |
| **要因計画** |複数の独立変数を同時に操作 |変数間の相互作用をテストします。複雑な;大量のサンプルが必要 |
| **被験者内** |すべての条件で同じ参加者 |個人差をコントロールします。参加者が少なくなる |順序効果。キャリーオーバー |
| **被験者間** |各条件で異なる参加者 |キャリーオーバー効果なし |個人差。より多くの参加者が必要 |
### サンプリング方法
|方法 |タイプ |説明 |いつ使用するか |
|----------|------|---------------|---------------|
| **単純なランダム** |確率 |すべてのメンバーは平等に選ばれるチャンスを持っています |ゴールドスタンダード;完全なサンプリング フレームが必要です |
| **層別ランダム** |確率 |層に分けて、各 | からのランダムなサンプルサブグループの表現を保証する |
| **クラスター** |確率 |グループをランダムに選択します。 | 内ですべてを調査します。人口が多い。費用対効果の高い |
| **利便性** |非確率 |利用可能な人をサンプルします。素早い;安い;しかし偏見がある |
| **目的** |非確率 |特定のケースを意図的に選択する |専門家の意見;特有の特徴 |
| **スノーボール** |非確率 |既存の参加者が他の参加者を募集します |到達が困難な集団 |
### 統計分析
|分析タイプ |目的 |例 |
|--------------|----------|----------|
| **記述統計** |データを要約する |平均;中央値;標準偏差。度数分布 |
| **推論統計** |サンプルから母集団についての結論を導き出す | t検定;分散分析;カイ二乗。回帰 |
| **相関関係** |変数間の関連性を測定する |ピアソンのr;スピアマンのロー |
| **回帰** |従属変数と独立変数間のモデル関係 |線形回帰。ロジスティック回帰 |
| **因子分析** |データ内の基礎となるディメンションを特定する | PCA;探索的因子分析 |
| **メタ分析** |複数の研究の結果を組み合わせる |治療効果の系統的レビュー |

## 定性的調査
### メソッド
|方法 |説明 |最適な用途 |
|----------|---------------|----------|
| **インタビュー** (半構造化) |自由回答形式の質問。調査 |経験に対する深い理解。意味 |
| **フォーカス グループ** |モデレーターによるグループディスカッション |グループの規範を探求する。アイデアを生み出す |
| **エスノグラフィー** |自然環境の中での臨場感あふれる観察 |文化を理解する。社会慣行 |
| **ケーススタディ** |単一のケースまたは少数のケースの詳細な調査 |コンテキスト内の複雑な現象 |
| **根拠のある理論** |反復コーディングを通じてデータから理論を構築する |既存の理論が不十分な場合 |
| **コンテンツ分析** |テキスト/メディアの体系的なコーディング |大量のテキスト。メディア分析 |
| **談話分析** |使用されている言語の研究。力関係 |言語が現実をどのように構築するか |
| **現象学** |生きた経験を理解する |人は現象をどのように経験するのか |
### 定性調査の品質を確保する
|基準 |説明 |達成方法 |
|----------|---------------|-----|
| **信頼性** (内部妥当性) |調査結果は参加者の意見を正確に表しています。三角測量;メンバーのチェック。長期にわたる関与 |
| **譲渡可能性** (外部有効性) |他の状況にも適用できる調査結果 |分厚い説明。目的のあるサンプリング |
| **ディペンダビリティ** (信頼性) |研究が繰り返された場合、結果は一貫していました。監査証跡。同僚の報告会 |
| **確認可能性** (客観性) |研究者の偏見ではなく、データに基づいた調査結果 |反射性。三角測量。監査証跡 |

## 混合メソッド
|デザイン |説明 |いつ使用するか |
|----------|---------------|---------------|
| **収束平行** |定量的データと定性的データを同時に収集します。比較 |広さと深さの両方が欲しいとき |
| **連続的な説明** |まずは定量的。結果を説明するための定性的 |調査結果をより深く理解する必要がある場合 |
| **探索的なシーケンシャル** |定性的第一。定量的な結果をテストする |最初に機器または理論を開発する必要がある場合 |

## 有効性と信頼性
### 有効性に対する脅威
|脅威 |説明 |緩和 |
|----------|---------------|---------------|
| **選択バイアス** |介入前、グループは体系的に異なります。ランダムな割り当て;一致する |
| **離職バイアス** |参加者がランダムに脱落する |理由を追跡します。治療意図分析 |
| **ホーソン効果** |人は観察されているために行動を変える |対照群；目がくらむ |
| **需要特性** |参加者は仮説を推測し、それに応じて行動します。欺瞞;カバーストーリー |
| **実験者のバイアス** |研究者の期待が結果に影響を与える |目がくらむ;標準化された手順 |
| **混乱を招く** | 3 番目の変数は関係を説明します |制御変数。ランダム化;統計的調整 |
| **P-ハッキング** | 1 つが重要になるまで、多くの仮説をテストする |事前登録;多重比較の補正 |
### 信頼性対策
|測定 |説明 |
|----------|---------------|
| **テスト-再テスト** |同じテストを 2 回実施。スコア間の相関関係 |
| **評価者間** |異なる評価者/コーディング者間の合意 |
| **内部の一貫性** |クロンバックのアルファ。同じ構造を測定するアイテム |
| **並列形式** |同じテストの異なるバージョン間の相関関係 |

## 研究倫理
|原則 |説明 |
|----------|---------------|
| **インフォームドコンセント** |参加者は自分たちが何に同意するのかを理解しています。自主参加 |
| **慈善** |メリットを最大化します。被害を最小限に抑える |
| **非悪意** |身体的、心理的、社会的に危害を加えないでください。
| **正義** |受益と負担の公平な配分。弱い立場にある人々を搾取しないでください。
| **プライバシーと機密保持** |参加者のデータを保護します。可能な限り匿名化する |
| **撤回する権利** |参加者はいつでもペナルティなしで研究を中止できます。
| **報告会** |参加後に研究の目的を説明します。特に欺瞞が使用された場合。
---

＃＃ まとめ
研究方法論は、調査結果が信頼できるかどうかを判断する枠組みです。仮説を検証し、効果を測定するには、定量的な方法 (実験、調査、統計分析) が最適です。意味、文脈、経験を理解するには、定性的方法（インタビュー、民族誌調査、ケーススタディ）が最適です。混合手法を組み合わせて幅と深さを実現します。科学的手法は、観察から仮説、データ収集、分析、ピアレビューに至る構造化されたプロセスを提供します。妥当性 (測定していると考えているものを測定していますか?) と信頼性 (同じ結果が再び得られるか?) が重要な品質基準です。研究倫理により、知識の追求が参加者の権利や幸福を犠牲にしないことが保証されます。最も重要な原則は、方法論が研究課題に役立つということです。つまり、最もよく知られている、または簡単なアプローチではなく、質問に最もよく答えるアプローチを選択してください。
