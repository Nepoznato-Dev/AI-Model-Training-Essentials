# 学習科学と教育学
学習科学は、心理学、神経科学、教育、認知科学に基づいて、人がどのように学習するのかを学際的に研究するものです。教育学は教育の芸術および科学です。彼らは一緒に、教育、トレーニング、メンター、教育コンテンツのデザインを行う人にとって重要な質問、つまり人々の学習に実際に役立つものは何か? に答えます。効果のない一般的な勉強法は何ですか?最大限の記憶保持と伝達を実現するには、指導をどのように構成する必要がありますか?

## 学習の仕組み
### 学習プロセス
|ステージ |説明 |重要な要素 |
|----------|---------------|---------------|
| **注意** |情報が処理されるには注意が必要です |斬新さ;関連性;感情的な意味 |
| **エンコーディング** |情報は精神的な表現に変換されます |事前知識との接続。詳細 |
| **統合** |メモリ トレースは時間の経過とともに安定します。寝る;間隔をあけて繰り返します。反射 |
| **ストレージ** |情報は長期記憶に保持されます。意味のある組織。既存の知識とのつながり |
| **検索** |情報は必要なときにアクセスされます |取り出す練習をしてください。さまざまなコンテキスト |
| **転送** |知識は新しい状況に適用されます |さまざまな実践。手順だけでなく原則を理解する |
### 認知負荷理論
|タイプ |説明 |教育上の意味 |
|-----|----------|---------------|
| **固有負荷** |素材特有の難しさ |複雑さを管理します。単純なものから複雑なものへのシーケンス |
| **無関係な負荷** |不適切な命令設計による困難 |不必要な複雑さを排除します。明確な例。適切な書式設定 |
| **ドイツ荷重** |実際の学習（スキーマ構築）に費やす精神的労力 |詳細を奨励します。自己説明。有意義な練習 |
**重要な洞察**: 作業記憶は限られています (一度におよそ 4±1 項目)。指導では、認知リソースを学習に利用できるように、無関係な負荷を最小限に抑える必要があります。

## 証拠に基づいた学習戦略
### 非常に効果的な戦略
|戦略 |説明 |なぜ機能するのか |証拠レベル |
|----------|---------------|---------------|----------------|
| **検索の練習** |記憶から情報を積極的に呼び出す |記憶の痕跡を強化します。ギャップを特定する |非常に強い |
| **間隔をあけた練習** |勉強会を時間的に配信 |再統合を強制する。忘却曲線と戦う |非常に強い |
| **インターリーブ** |さまざまな種類の問題やトピックを混合する |差別を改善します。より良い転送 |強い |
| **詳細** |新しい情報があなたの知っていることとどのように関連するかを説明する |より豊富なメモリ トレースを作成します。より深いエンコーディング |強い |
| **具体的な例** |具体的な例を使用して抽象的な概念を説明する |抽象的なアイデアを具体的なものにします。理解を助ける |強い |
| **デュアルコーディング** |言葉とビジュアルの組み合わせ |言語処理チャネルと視覚処理チャネルの両方を使用します。強い |
### 非効果的な戦略 (人気にもかかわらず)
|戦略 |なぜ効果があると感じるのか |実際にはそうではない理由 |
|----------|----------------------|-----------|
| **再読** |流暢さの錯覚 — テキストに親しみを感じる |受け身;検索は強化されません |
| **ハイライト** |生産的だと感じます。重要な情報をマークします |深い処理は必要ありません |
| **要約** |積極的に取り組んでいるようです |多くの場合、そのままコピーされます。取得する必要はありません |
| **集団練習 (詰め込み)** |短期的なリコールに効果的 |急速な物忘れ。転送不良 |
| **学習スタイル** (視覚/聴覚/運動感覚) |直感的に魅力的 |指導を好みのスタイルに合わせると学習が改善されるという証拠はない |

## 忘却曲線と一定の反復
### エビングハウスの忘却曲線
|学習後の時間 |保持 (レビューなし) |
|---------------------|---------------------|
| **20 分** | ~58% |
| **1 時間** | ~44% |
| **1 日** | ~33% |
| **2 日間** | ~28% |
| **6 日間** | ~25% |
| **31 日** | ~21% |
### 間隔をあけた繰り返しスケジュール
|レビュー |タイミング |効果 |
|----------|----------|----------|
| **最初のレビュー** |学習から 1 日後 |保持力を大幅に向上 |
| **2 回目のレビュー** | 3日後 |記憶力をさらに強化 |
| **3 回目のレビュー** | 7日後 |メモリの耐久性が向上 |
| **4 回目のレビュー** | 14日後 |長期的な統合 |
| **5 回目のレビュー** | 30日後 |安定した長期記憶 |
レビューを行うたびに、忘却曲線がさらに押し出されます。最適な間隔は、取得が成功するたびに増加します。

## ブルームの分類法
|レベル |認知プロセス |アクション動詞 |タスク例 |
|----------|--------|---------------|--------------|
| **覚えておいてください** |事実と基本概念を思い出す |定義する;リスト;名前;特定する | "有糸分裂の段階をリストする" |
| **理解しました** |アイデアやコンセプトを説明する |説明する;説明する;要約する。分類する | 「有糸分裂がなぜ重要なのか説明してください」 |
| **適用** |新しい状況で情報を使用する |解決する;使用;実演する。実装する | 「有糸分裂が中断された場合に何が起こるかを予測する」 |
| **分析** |アイデア間のつながりを描く |比較する;対比;カテゴリー化する。調べる | 「有糸分裂と減数分裂を比較する」 |
| **評価** |立場や決定を正当化する |裁判官;批評;守る;議論する | 「制御されていない細胞分裂の影響を評価する」 |
| **作成** |新作またはオリジナル作品の制作 |デザイン;構築する。開発する;定式化 | 「細胞分裂に対する毒素の影響をテストする実験を計画する」 |

## インストラクショナルデザインモデル
### ADDIEモデル
|フェーズ |説明 |
|------|-----------|
| **分析** |学習者のニーズを特定します。目標。既存の知識。制約 |
| **デザイン** |学習目標を定義します。評価戦略。コンテンツ構造 |
| **開発** |マテリアルを作成します。活動。評価 |
| **実装** |指示を伝達します。学習を促進する |
| **評価** |有効性を評価する。フィードバックを収集する。反復 |
### バックワードデザイン (デザインによる理解)
|ステップ |説明 |
|------|---------------|
| **1.望ましい結果を特定する** |学習者は何を知り、理解し、何ができるようになるべきでしょうか? |
| **2.許容可能な証拠を決定する** |彼らが結果を達成したかどうかはどうやってわかりますか? (評価が先) |
| **3.学習体験を計画する** |どのような活動、指導、練習をすれば学習者は成功できるのでしょうか? |
### 足場
|テクニック |説明 |
|----------|---------------|
| **モデリング** |スキルや思考プロセスをデモンストレーションする |
| **思考音声** |問題を解決しながら推論を言語化する |
| **実際の例** |学習者に問題の解決を求める前に、完全な解決策を提示する |
| **段階的リリース** | 「私はやります→私たちはやります→あなたはやります」—段階的にサポートを削除 |
| **プロンプト** |学習者を答えに導く質問をする |
| **チャンク** |複雑なタスクを管理可能な部分に分割する |

## モチベーションとエンゲージメント
### 自己決定理論
|必要 |説明 |サポート方法 |
|-----|---------------|-----|
| **自律性** |自分の行動をコントロールできていると感じる |選択肢を提供します。根拠を説明する。言語制御を避ける |
| **能力** |効果的で有能であると感じる |適切な挑戦。タイムリーなフィードバック。進歩を祝う |
| **関連性** |他者とのつながりを感じる |共同学習。支援的な環境。コミュニティとの関連性 |
### 成長 vs 固定観念 (キャロル・ドゥエック)
|考え方 |信念 |行動 |障害への対応 |
|----------|----------|---------------|--------|
| **修正済み** |知性は静的です |課題を回避します。簡単にあきらめます | 「私はこれが苦手です」 |
| **成長** |知性は開発できる |挑戦を受け入れる。持続する | 「これはまだ習っていません」 |

＃＃ 評価
### 評価の種類
|タイプ |目的 |タイミング |例 |
|------|--------|----------|-----------|
| **診断** |事前の知識と誤解を特定する |指導前 |事前テスト;コンセプトインベントリ |
| **形成的** |学習を監視する。フィードバックを提供する |指導中 |クイズ;出口切符。ピアレビュー |
| **要約** |最後に学習を評価する |指導後 |最終試験;プロジェクト;ポートフォリオ |
| **本物** |現実世界のアプリケーションを評価する |最中またはその後 |ケーススタディ;シミュレーション;インターンシップ |
### 効果的なフィードバック
|原則 |説明 |
|----------|---------------|
| **タイムリー** |すぐにでも行動しましょう |
| **具体的な** |特定の長所と短所を指摘 |
| **実用的** |学習者に次に何をすべきかを指示します。
| **タスクに集中** |その人についてではありません (「この議論にはもっと証拠が必要です」、「あなたは優れたライターではありません」ではありません) |
| **バランスの取れた** |機能しているものと改善が必要なものを特定する |

＃＃ まとめ
科学を学ぶと、最も効果的な戦略は直感に反することが多いことがわかります。再読よりも、検索の練習 (自分自身を試す) の方がはるかに効果的です。間隔をあけて繰り返したほうが、詰め込み学習に勝ります。さまざまな種類の問題を交互に配置することで、識別と転移が改善されます。認知負荷理論は、作業記憶には限界があることを思い出させます。無関係な負荷を最小限に抑えるように指導を設計する必要があります。ブルームの分類法は、想起から作成に進むためのフレームワークを提供します。インストラクショナル デザイン モデル (ADDIE、バックワード デザイン) は、効果的な学習エクスペリエンスを開発するための構造化されたアプローチを提供します。モチベーションは自主性、能力、関連性によって決まります。評価は学習目標に合わせて行う必要があり、単なる総評点ではなく形成的なフィードバックを含める必要があります。学習における最大の誤解は、人々は固定的な「学習スタイル」を持っているということです。証拠は、指導を好みのスタイルに合わせても成果が向上しないことを一貫して示しています。誰にとっても有効なのは、努力による検索、間隔をあけた練習、さまざまな例、有意義なフィードバックです。
