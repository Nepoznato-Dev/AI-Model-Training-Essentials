# 世界の文化と社会
文化は社会の枠組みであり、メンバーが自分たちの世界やお互いに対処するために使用する共有の信念、価値観、習慣、行動、および工芸品です。文化的多様性を理解することは、トリビアを暗記することではありません。それは、世界の見方は数千あるうちの一つであり、他のシステムは内部的に一貫性があり、歴史に基づいており、独自の観点から理解する価値があることを認識することです。
---

## 文化的側面
人類学者と異文化心理学者は、フレームワークを使用して社会を体系的に比較します。最も影響力のあるのは、ヘルト・ホフステードの文化的次元モデルです。
|寸法 |何を測定するのか |コントラストの例 |
|-----------|------|------|
| **電力距離** |どの程度の不平等が普通として受け入れられるのか |高 (マレーシア、フィリピン) vs 低 (デンマーク、ニュージーランド) |
| **個人主義 vs 集団主義** | 「私」のアイデンティティ vs 「私たち」のアイデンティティ |高度な個人主義 (アメリカ、オーストラリア) vs 高度な集団主義 (グアテマラ、インドネシア) |
| **男性性 vs 女性性** |競争と成果 vs 協力と生活の質 |男性的 (日本、ハンガリー) vs 女性的 (スウェーデン、オランダ) |
| **不確実性の回避** |曖昧さと構造化されていない状況に対する許容度 |ハイ (ギリシャ、ポルトガル) vs ロー (シンガポール、ジャマイカ) |
| **長期志向と短期志向** |将来の報酬と現在の伝統 |長期 (中国、韓国) vs 短期 (米国、ナイジェリア) |
| **耽溺 vs 拘束** |衝動を満たす自由と厳格な社会規範 | Indulgent (メキシコ、ナイジェリア) vs Restrained (ロシア、エジプト) |
> **実践的な洞察**: これらはスペクトルの位置であり、価値判断ではありません。高い権力と距離を置く文化は「抑圧的」ではありません。年長者への敬意と社会的調和を重視するのかもしれません。権力の距離が低い文化は「混沌」ではありません。能力主義とオープンな議論を重視しているのかもしれません。

## 主要な文化地域
### 東アジア
|側面 |詳細 |
|--------|--------|
| **国** |中国、日本、韓国、台湾、ベトナム |
| **哲学的ルーツ** |儒教、道教、仏教、神道 |
| **キーの値** |親孝行、教育、調和、面子（社会的評価）、連帯責任 |
| **コミュニケーション スタイル** |ハイコンテキスト: 意味は暗黙的、間接的、行間から読み取られます。
| **時間志向** |長期;持続性と将来の報酬を重視 |
| **ビジネス文化** |関係第一。食事と繰り返しのミーティングを通じて築かれた信頼。階層を尊重 |
東アジアの文化は、中国語の文字体系の影響、箸の使用、旧正月のお祝いなどを共有していますが、大きく異なります。日本のコミュニケーションは中国語よりもはるかに間接的であり、韓国のビジネス文化は台湾よりも階層的です。
### 南アジア
|側面 |詳細 |
|--------|--------|
| **国** |インド、パキスタン、バングラデシュ、スリランカ、ネパール |
| **哲学的ルーツ** |ヒンドゥー教、仏教、イスラム教、シーク教、ジャイナ教 |
| **キーの値** |家族の義務、年長者への敬意、精神的な多様性、もてなし（athi devo bhava — 「ゲストは神です」） |
| **コミュニケーション スタイル** |ハイコンテキスト。有名な頭のぐらつき。間接的な意見の相違 |
| **社会構造** |大家族制度。インドの歴史的カーストの影響。コミュニティの強い絆 |
| **言語の多様性** |何百もの言語。最も話されている言語はヒンディー語、ベンガル語、ウルドゥー語、タミル語、テルグ語 |
### 中東および北アフリカ (MENA)
|側面 |詳細 |
|--------|--------|
| **国** |サウジアラビア、UAE、エジプト、モロッコ、イラン、トルコ、イスラエル |
| **哲学的ルーツ** |イスラム教、ユダヤ教、キリスト教（起源はここ）、オスマン帝国、ペルシアの伝統 |
| **キーの値** |おもてなし、名誉、家族への忠誠心、宗教遵守、寛大さ |
| **コミュニケーション スタイル** |ハイコンテキスト。関係主導型。面子を保つことを間接的に拒否 |
| **ビジネス文化** |個人的な関係は不可欠です。交渉は長引くかもしれない。イスラム教徒が多数派の国では金曜日が聖日です |
| **多様性に関するメモ** |広大な範囲 - 世俗的なトルコは保守的なサウジアラビアとは大きく異なります。レバノンはイエメンよりも国際的です |
### サハラ以南のアフリカ
|側面 |詳細 |
|--------|--------|
| **国** | 46か国以上。人口が最も多い国はナイジェリア、エチオピア、ケニア、南アフリカ、ガーナ、セネガル |
| **哲学的ルーツ** | Ubuntu (「私たちがいるから私はいる」)、祖先の伝統、イスラム教、キリスト教、先住民の信念体系 |
| **キーの値** |コミュニティ、大家族、口頭伝承、年長者への敬意、おもてなし |
| **言語の多様性** | 2,000 以上の言語。スワヒリ語、ヨルバ語、アムハラ語、ズールー語、ハウサ語、イボ語が最も話されています |
| **社会構造** |年齢による制度、部族への所属、強い共同体としてのアイデンティティ |
| **多様性に関するメモ** |地球上で遺伝的にも文化的にも最も多様な大陸。 「アフリカ文化」について一般化することは、「ヨーロッパ文化」について一般化することに似ています。大まかには可能ですが、細部では誤解を招く可能性があります。
＃＃＃ ラテンアメリカ
|側面 |詳細 |
|--------|--------|
| **国** |メキシコ、ブラジル、アルゼンチン、コロンビア、ペルー、チリ、他 |
| **哲学的ルーツ** |先住民文明 (アステカ、マヤ、インカ)、カトリック、アフリカ離散の影響 |
| **キーの値** |家族 (familismo)、個人的な関係 (personalismo)、温かさ、時間の柔軟性 |
| **コミュニケーション スタイル** |ハイコンテキスト。物理的な接近や接触は正常です。間接的な意見の相違 |
| **時間志向** |ポリクロニック — 複数のタスクを同時に実行します。スケジュールより人間関係が優先 |
| **ビジネス文化** |信頼と個人的なつながりはビジネスに優先します。ミーティングは社交的な会話から始まります |
### 西部 (ヨーロッパ、北アメリカ、オーストラリア)
|側面 |詳細 |
|--------|--------|
| **国** |米国、カナダ、英国、ドイツ、フランス、オーストラリア、ニュージーランド、北欧諸国 |
| **哲学的ルーツ** |ギリシャ・ローマ哲学、キリスト教、啓蒙主義、自由主義 |
| **キーの値** |個人主義、実力主義、率直さ、時間厳守、革新 |
| **コミュニケーション スタイル** |ローコンテキスト: 意味が明示的です。 「言いたいことを言ってください」 |
| **時間志向** |単時的 — 時間は管理すべきリソースです。時間厳守は美徳です |
| **ビジネス文化** |タスクファースト。効率性が重視される。人間関係よりも契約。フラットな階層 (特に北欧諸国) |
> **西側の多様性**: 北欧の社会民主主義はアメリカの資本主義とは大きく異なります。ドイツ人の率直さはイギリス人の礼儀正しさとは異なります。イタリアの表現力はスイスの保護区とは異なります。 「西洋文化」は便利な略語ですが、一枚岩ではありません。

## コミュニケーション スタイル: ハイコンテキストとローコンテキスト
エドワード T. ホールのフレームワークは、異文化を理解するための最も実用的なツールの 1 つです。
|特集 |ハイコンテキスト |ローコンテキスト |
|----------|---------------|---------------|
| **意味** |状況、関係性、そして非言語的な手がかりにおいて |はっきりとした言葉で |
| **合意** |信頼に基づいて;口頭でのこともある |書面による契約が望ましい |
| **意見の相違** |間接的; 「たぶん」は「いいえ」を意味することがよくあります。直接; 「いいえ」は「いいえ」を意味します |
| **フィードバック** |微妙;体面を保つために個人的に配信されました |明示的;直接配送 |
| **沈黙** |快適;意味のある |不快;何かが間違っています |
| **例** |日本、中国、アラブ諸国、ラテンアメリカ |アメリカ、ドイツ、スカンジナビア、スイス |

## 社会構造と組織
|構造 |説明 |一般的な場所 |
|----------|---------------|---------------|
| **核家族** |親と子供のみ |欧米諸国、世界の都市部 |
| **大家族** |複数の世代が同居または密接に接触している |南アジア、中東、アフリカ、ラテンアメリカ |

## 宗教と文化的実践
宗教は単なる信仰ではなく、食事、服装、カレンダー、性別役割、営業時間、法制度を形成します。
|宗教 |信奉者 |主な文化的影響 |
|----------|-----------|-----------|
| **キリスト教** | ～24億 |日曜休み。クリスマス/イースターカレンダー。西洋の法と倫理に影響を与えた |
| **イスラム教** | ～19億 |毎日5回の祈り。ラマダン断食。ハラール食事法。会衆の日としての金曜日 |
| **ヒンドゥー教** | ～12億 |カーストの影響。多くの人が菜食主義。ディワリ/ホーリー祭。牛への敬意 |
| **仏教** | ～5億 |瞑想;非暴力。修道院の伝統。世俗的な文脈におけるマインドフルネス |
| **シーク教** | ～3,000万 |ターバン;ランガル（共同キッチン）。平等;サービス (セヴァ) |
| **ユダヤ教** | ～1,500万 |シャバット（土曜日の休み）。コーシャ的な食事法。聖なる祝日。勉強に重点を置く |
| **世俗/非宗教** | ～12億 |宗教的なカレンダーはありません。多元的な価値観。国によって大きく異なります |

## グローバリゼーションと文化的変化
文化は静的なものではありません。グローバリゼーション、移民、インターネットにより、世界中で文化的慣習が再形成されています。
**均質化とハイブリダイゼーション:**
- グローバリゼーションが単一の消費文化を生み出していると主張する人もいます（マクドナルド、Netflix、共通語としての英語）
- ハイブリッド化を考える人もいます: 地元の文化が世界的な影響を吸収し、変化させます (ボリウッド、K-ポップ、アフロビート)
- 現実は両方です: 表面レベルの融合 (服装、テクノロジー) と深層レベルの多様性 (価値観、コミュニケーション、アイデンティティ)
**主なトレンド:**
- 都市化: 世界人口の 56% 以上が都市に住んでいます (1950 年の 30% から増加)
- 移住: 世界中で約 2 億 8,000 万人の国際移民が発生し、離散コミュニティを形成
- デジタル文化: ソーシャルメディアが国境を越えた文化コミュニティを生み出す
- 言語の変化: 世界の約 7,000 言語のうち約 40% が絶滅の危機に瀕しています。英語、中国語、スペイン語が主流
---

＃＃ まとめ
他文化を理解することは固定観念に関することではありません。文化的知性を発展させることです。つまり、自分の規範が普遍的ではないことを認識し、自分の行動を適切に適応させ、違いを越えて敬意を持って交流する能力です。上記のフレームワーク (文化的側面、高/低コンテキスト、社会構造) は思考のためのツールであり、人々にラベルを付けるための箱ではありません。すべての個人は、国、地域、職業、世代、家族など、多くの文化によって同時に形成されます。目的は、パスポートに基づいて誰かがどのように行動するかを予測することではなく、判断ではなく好奇心を持って違いに近づくことです。
