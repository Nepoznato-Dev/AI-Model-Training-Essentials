# 心理学 と 人間の行動

## はじめに to 心理学

心理学 is その scientific study の mind と behavior. It examines how people think, feel, act, と interact. Major perspectives で 心理学 include biological (examining brain structures と neurotransmitters), behavioral (focusing on observable behaviors と learning), cognitive (studying mental processes like memory と decision-making), psychodynamic (exploring unconscious drives と conflicts, originating と Freud), humanistic (emphasizing personal growth と self-actualization), と social-cultural (examining how environment と 文化 shape behavior). 心理学 uses scientific methods including experiments, observations, surveys, と case studies to understand human experience.

## Cognitive 心理学

Cognitive 心理学 studies mental processes including attention, perception, memory, 言語, problem-solving, と decision-making. Attention is その ability to focus on specific stimuli while filtering out others. Perception involves organizing と interpreting sensory information. Memory has three main stages: encoding (getting information で), storage (retaining information), と retrieval (getting information out). Short-term memory holds limited information briefly; long-term memory has vast capacity のために extended periods. Working memory temporarily manipulates information のために complex tasks. 言語 acquisition involves understanding と producing コミュニケーション. Problem-solving strategies include algorithms (step-by-step procedures) と heuristics (mental shortcuts). Decision-making can be influenced by biases と emotions.

## Developmental 心理学

Developmental 心理学 examines how people change と grow throughout their lifespan. Prenatal 開発 includes germinal, embryonic, と fetal stages. Infancy (0-2 years) features rapid physical growth, attachment formation, と sensorimotor learning. Childhood (2-12 years) involves 言語 開発, social skills, と concrete thinking. Adolescence (12-18 years) brings puberty, identity formation, と abstract reasoning. Early adulthood (20s-30s) focuses on career, relationships, と independence. Middle adulthood (40s-60s) often involves career consolidation と caring のために aging parents. Late adulthood (65+) may include retirement, health challenges, と reflection. Key theories include Piaget's stages の cognitive 開発, Erikson's psychosocial stages, と Kohlberg's moral 開発 theory. 自然 (genetics) と nurture (environment) both influence 開発.

## Social 心理学

Social 心理学 studies how individuals think, feel, と behave で social contexts. Conformity is adjusting behavior to match group norms, demonstrated で Asch's line experiments. Obedience is complying と authority figures, studied で Milgram's shock experiments. Social facilitation improves パフォーマンス on simple tasks when others watch. Social loafing reduces effort で groups. Groupthink occurs when groups prioritize harmony over critical evaluation. Prejudice is preconceived judgment about groups; discrimination is unequal treatment. Stereotypes are generalized beliefs about groups. Attribution theory explains how we interpret others' behavior (internal vs. external causes). その fundamental attribution error overestimates personality と underestimates situation when judging others. Bystander effect reduces helping behavior when others are present. Aggression can be influenced by biology, frustration, と social learning. Attraction involves proximity, similarity, physical attractiveness, と reciprocity.

## Personality 心理学

Personality refers to enduring patterns の thoughts, feelings, と behaviors. その Big Five personality traits are openness (curiosity, creativity), conscientiousness (organization, dependability), extraversion (sociability, energy from others), agreeableness (cooperation, compassion), と neuroticism (emotional instability, anxiety). Freud's psychoanalytic theory proposed id (instincts), ego (reality), と superego (morality). Humanistic theories (Maslow, Rogers) emphasize growth potential と self-actualization. Trait theories identify consistent characteristics across situations. Type theories categorize people (e.g., Type A vs. Type B behavior patterns). Personality develops through genetics, environment, と experiences. Assessment tools include self-report inventories (MMPI) と projective tests (Rorschach inkblots).

## Mental Health と Disorders

Mental health encompasses emotional, psychological, と social well-being. Psychological disorders are patterns causing distress or impaired functioning. Anxiety disorders include generalized anxiety, panic disorder, phobias, と social anxiety. Mood disorders include depression (persistent sadness) と bipolar disorder (mood swings). Schizophrenia involves distorted thinking, perceptions, と emotions. Eating disorders include anorexia nervosa, bulimia, と binge-eating. Personality disorders involve inflexible patterns causing problems (e.g., borderline, antisocial). Trauma-related disorders include PTSD following traumatic イベント. その DSM-5 (Diagnostic と Statistical Manual) classifies mental disorders. Causes の disorders involve biological factors (genetics, brain chemistry), psychological factors (trauma, learned patterns), と social factors (stress, environment). Stigma surrounding mental illness can prevent people from seeking help.

## Therapeutic Approaches

Psychotherapy involves treating mental disorders through psychological methods. Psychodynamic therapy explores unconscious conflicts と past experiences. Cognitive-behavioral therapy (CBT) changes negative thought patterns と behaviors. Humanistic therapy emphasizes self-exploration と personal growth. Behavioral therapy modifies behaviors through conditioning techniques. Family therapy addresses family dynamics affecting individuals. Group therapy provides peer support. Biomedical therapies include medications (antidepressants, antipsychotics, mood stabilizers) と procedures (ECT, TMS). Evidence-based practice integrates research evidence, clinical expertise, と patient values. Prevention と early intervention improve outcomes. Self-care practices include exercise, sleep, 栄養, mindfulness, と social connection.

## Neuroscience と Behavior

Neuroscience examines その nervous system's role で behavior. Neurons are nerve cells transmitting information through electrical と chemical signals. Neurotransmitters are chemicals transmitting signals between neurons (dopamine, serotonin, norepinephrine, GABA, glutamate). その central nervous system includes brain と spinal cord. その peripheral nervous system connects CNS to body. その brain's cerebrum handles higher functions; cerebellum coordinates movement; brainstem controls vital functions. その limbic system processes emotions と memory (amygdala, hippocampus, hypothalamus). Brain plasticity allows neural connections to change と experience. Neuroimaging techniques (MRI, fMRI, PET scans) visualize brain structure と activity. Hormones from その endocrine system also influence behavior と emotions.

## Motivation と Emotion

Motivation drives behavior toward goals. Intrinsic motivation comes from internal satisfaction; extrinsic motivation from external rewards. Maslow's hierarchy proposes needs from physiological to self-actualization. Drive-reduction theory suggests behavior aims to reduce internal tension. Instinct theory proposes innate behavioral patterns. Emotion involves physiological arousal, expressive behaviors, と conscious experience. Major emotion theories include James-Lange (emotion follows physiological response), Cannon-Bard (emotion と response occur simultaneously), と Schachter-Singer (emotion depends on interpretation の arousal). Basic emotions include happiness, sadness, anger, fear, surprise, と disgust. Emotional intelligence involves recognizing と managing emotions で oneself と others. Stress triggers その fight-or-flight response; chronic stress harms health.

## Learning と Conditioning

Learning is relatively permanent behavior change through experience. Classical conditioning (Pavlov) pairs neutral stimuli と natural responses. Operant conditioning (Skinner) uses consequences to shape behavior. Positive reinforcement adds desirable stimuli to increase behavior; negative reinforcement removes aversive stimuli to increase behavior. Punishment decreases behavior. Observational learning (Bandura) occurs by watching others. Latent learning happens without immediate reinforcement. Insight learning involves sudden problem comprehension. Habituation reduces response to repeated stimuli. Generalization responds similarly to similar stimuli; discrimination distinguishes between stimuli. Extinction weakens conditioned responses when reinforcement stops.
