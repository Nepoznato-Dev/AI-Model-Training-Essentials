# 気候変動テクノロジーとグリーンイノベーション
気候テクノロジーには、温室効果ガスの排出量を削減し、気候変動に適応し、世界経済を持続可能な基盤に移行させるために設計されたツール、システム、イノベーションが含まれます。これはおそらく 21 世紀で最も重要なテクノロジー領域です。管理可能な 1.5 ℃ の温暖化と、壊滅的な 3 ℃ 以上の気温の差は、これらのテクノロジーをどれだけ迅速に大規模に展開できるかに大きく依存します。この課題は科学的なものだけでなく、経済的、政治的、社会的なものでもあります。

## 炭素予算
### 部門別の温室効果ガス排出量
|セクター |世界の排出量に占める割合 |主要な情報源 |
|----------|--------------------------|---------------|
| **エネルギー (電気と熱)** | ~25% |石炭;天然ガス;石油発電所 |
| **農業、林業、土地利用** | ~18% |家畜 (メタン);森林伐採。肥料（亜酸化窒素） |
| **業界** | ~21% |セメント;鋼鉄;化学物質。製造 |
| **輸送** | ~16% |道路車両。航空;送料 |
| **建物** | ~6% |加熱;冷却;料理 |
| **その他のエネルギー** | ~10% |化石燃料採掘による一時的な排出。パイプライン |
### 排出量ギャップ
|コンセプト |説明 |
|----------|---------------|
| **パリ協定の目標** |温暖化を産業革命以前の水準より 1.5°C または 2°C より十分低い値に制限する |
| **炭素収支 (1.5°C)** |約 4,000 億トンの CO₂ が残留 (2023 年から)。現在のレートで、～2030 年までに枯渇する |
| **現在の軌道** |現在の政策に基づくと、2100 年までに約 2.5 ～ 2.9 ℃の温暖化が予想される |
| **ネットゼロ目標** |ほとんどの国は 2050 年までに純ゼロを約束しています (一部の国は 2060 年または 2070 年まで)。
| **排出ギャップ** |必要なことと各国が実際に行っていることの違い |

## エネルギー技術
### 再生可能エネルギー
|テクノロジー |仕組み |コストの傾向 |制限 |
|----------|---------------|---------------|---------------|
| **太陽光発電** |太陽電池は太陽光を電気に変換します。 2010 年以来最大 90% 減少。史上最も安い電気 |間欠;保管が必要です。土地利用 |
| **陸上風力発電** |風力で発電機に接続されたタービンを回す | 写真2010 年以来最大 70% 減少 |間欠;視覚的なインパクト。騒音 |
| **洋上風力発電** |海洋の風力タービン。より強く、より安定した風 |減少しているが陸上よりも高価 |海洋生態系。メンテナンス;グリッド接続 |
| **水力発電** |水はタービンを通って流れます。成熟したテクノロジー。低コスト |新しいサイトは限られています。生態系の破壊。干ばつのリスク |
| **地熱** |地球内部からの熱 |安定した;ベースロード |場所固有。探査リスク |
| **潮汐/波** |海の動きがタービンを駆動する |早期;高価です |予測可能だが厳しい環境。限られたサイト |
### エネルギー貯蔵
|テクノロジー |期間 |容量 |最適な用途 |
|----------|----------|----------|----------|
| **リチウムイオン電池** |営業時間 |中 |グリッドピーキング。 EV;自宅保管 |
| **揚水式** |数時間から数日 |非常に大きい |グリッドスケール。成熟したテクノロジー |
| **フロー電池** |営業時間 |スケーラブル |長期間;工業用 |
| **圧縮空気** |数時間から数日 |大 |グリッドスケール。地層が必要 |
| **グリーン水素** |日々から季節へ |非常に大きい |季節ごとの保管。工業用熱。送料 |
| **蓄熱** |営業時間 |中 |集中太陽光発電;産業プロセス |
### 原子力エネルギー
|タイプ |説明 |ステータス |
|------|---------------|----------|
| **核分裂 (現在)** |重原子 (ウラン) を分解してエネルギーを放出 |世界の電力の約 10%。低炭素;物議を醸す |
| **小型モジュラーリアクター (SMR)** |工場で組み立てられます。より小さい;潜在的に安全 |開発中。最初の導入は 2020 年代後半になる見込み |
| **フュージョン** |軽い原子 (水素) を融合してエネルギーを放出 |実験(ITER);コマーシャルから数十年 |
| **第 IV 世代の原子炉** |先進的なデザイン。燃料の使用が改善される。無駄を減らす |研究段階。いくつかのプロトタイプ |

## 輸送の脱炭素化
### 電気自動車
|側面 |説明 |
|----------|---------------|
| **バッテリーEV (BEV)** |完全電動。排気管からの排出ガスがゼロ。支配的なテクノロジー |
| **プラグイン ハイブリッド (PHEV)** |電気 + 燃焼。どちらでも実行できます。ブリッジテクノロジー |
| **範囲** |通常 300 ～ 500 km。世代ごとに改善 |
| **充電中** |ホーム (遅い);公共 DC 急速充電器 (80% まで 20 ～ 30 分) |
| **グリッドへの影響** |スマート充電;車両からグリッドまで。管理された充電によりグリッドのストレスが軽減される |
| **コスト** |購入価格はICE車両と同等に近づく。総所有コストはすでに低い |
### 電化が難しい輸送機関
|セクター |チャレンジ |ソリューション |
|----------|-----------|----------|
| **航空** |長時間のフライトにはバッテリーが重すぎる |持続可能な航空燃料 (SAF);水素;効率の向上 |
| **送料** |膨大なエネルギーが必要 |緑色のアンモニア。メタノール;ウィンドアシスト。ゆっくり蒸します |
| **大型トラック輸送** |長距離;高い積載量 |水素燃料電池;電気高速道路。より大きなバッテリー |
| **レール** |多くの国ではすでにほとんどが電化されています。電動化を継続する。非電化線用の水素 |

## 産業の脱炭素化
### 主要な課題
|業界 |排出源 |脱炭素化の道筋 |
|----------|------|--------------------------|
| **セメント** |化学プロセス（焼成）＋エネルギー |代替バインダー;炭素回収。グリーン水素窯 |
| **スチール** |還元剤として使用される石炭 |グリーン水素直接還元鉄 (DRI);電気炉 |
| **化学品** |原料 + エネルギー |緑色の水素。バイオベースの原料。電化 |
| **プラスチック** |化石原料 |バイオプラスチック;ケミカルリサイクル。循環経済 |
| **アルミニウム** |電気を大量に消費する製錬 |再生可能エネルギーを利用した製錬所。不活性アノード技術 |
### 二酸化炭素の回収、利用、貯留 (CCUS)
|テクノロジー |説明 |ステータス |
|----------|---------------|----------|
| **点光源キャプチャ** |産業用煙道から CO₂ が大気中に入る前に回収 |パイロット/デモ段階。高価です |
| **ダイレクト エア キャプチャ (DAC)** |周囲空気から CO₂ を直接除去 |初期の商用 (Climeworks、カーボン エンジニアリング)。非常に高価です |
| **炭素利用** |回収したCO₂を製品（燃料、コンクリート、化学品）に変換 |ほとんどの経路の研究段階 |
| **地中貯蔵** | CO₂ を深い岩層に注入 |実証済みのテクノロジー。展開が限定的。監視が必要 |
| **CCS によるバイオエネルギー (BECCS)** |バイオマスを燃やす。 CO₂を回収します。正味マイナス排出量をもたらす |理論的;限定的な展開 |

## 炭素除去
|アプローチ |説明 |スケールの可能性 |コスト |
|----------|---------------|-----|-----|
| **植林と植林** |木を植える。森林を回復する |高 |低 (10 ～ 50 ドル/トン) |
| **土壌炭素隔離** |再生型農業;被覆作物。不耕起 |高 |低からマイナス (お金の節約) |
| **バイオ炭** |バイオマスを熱分解する。土に加える |中 |中型 ($50-200/トン) |
| **強化されたウェザリング** | CO₂を吸収する砕石を散布 |高 |中型 ($50-200/トン) |
| **海洋ベースのアプローチ** |海洋肥料;アルカリ性強化 |不確か |不明 |
| **DAC + ストレージ** |地中貯留による直接空気回収 |高 |高 (現在 250 ～ 600 ドル/トン、下落すると予想) |

## 気候変動対策の経済学
|コンセプト |説明 |
|----------|---------------|
| **カーボンプライシング** |排出量に価格を付ける税またはキャップアンドトレード制度 |
| **グリーン保険料** |ゼロカーボン代替品と化石燃料同等品の追加コスト |
| **学習曲線** |クリーン テクノロジーのコストは導入に伴って低下します (ライトの法則) |
| **座礁資産** |ネットゼロの世界では無価値になる化石燃料埋蔵量とインフラ |
| **移行するだけ** |化石燃料に依存する労働者と地域社会が取り残されないようにする |
| **気候変動金融** |特に発展途上国における緩和と適応のための資金提供（年間1,000億ドルの約束） |

＃＃ まとめ
気候変動テクノロジーは、エネルギー、輸送、産業、農業、炭素除去など、経済全体に広がります。太陽光と風力は現在、世界のほとんどの地域で最も安価な新電力源ですが、断続的には貯蔵（バッテリー、揚水水力、グリーン水素）と送電網の近代化が必要です。電気自動車は乗用車の内燃エンジンに取って代わりつつありますが、航空、海運、重工業は水素、持続可能な燃料、炭素回収などの異なるソリューションを必要としています。産業の脱炭素化（セメント、鉄鋼、化学物質）は、化学プロセスに排出が組み込まれているため、最も困難な課題です。残留排出量に対処するには、再植林から直接的な大気回収に至るまでの炭素除去が必要です。適応技術は、社会が過去の排出によってすでに固定化されている変化に対処するのに役立ちます。経済状況は変化しています。クリーン テクノロジーは学習曲線に従い、導入に伴ってコストが低下し、何もしないことのコストが行動のコストを大幅に上回ります。問題はもはや移行が起こるかどうかではなく、それが十分な速さで起こるかどうかだ。
