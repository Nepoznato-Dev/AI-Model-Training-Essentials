# 行動経済学と意思決定科学
行動経済学は、人間が実際にどのように意思決定を行うのかを研究するものであり、合理的なエージェントがどのように意思決定を行うのかを研究するものではありません。伝統的な経済学では、人々は合理的で利己的であり、情報処理が得意であると想定されています。カーネマン、トベルスキー、セイラーらによる数十年にわたる研究では、これが非常に不正確であることが示されています。人々は頭の中でショートカットを使用し、無関係な文脈に影響され、最近の情報を過大評価し、体系的に予測可能な間違いを犯します。これらのパターンを理解することは、より良い製品、ポリシー、組織、個人の意思決定を設計するために不可欠です。
---

## 2 つの思考システム
|システム |特徴 |スピード |努力 |例 |
|----------|----------------|----------|----------|---------|
| **システム 1** |自動;直感的。感情的な |速い |低い |表情を読み取る。慣れた道を運転する |
| **システム 2** |意図的に;分析的。論理的 |遅い |高 |数学の問題を解く。製品仕様の比較 |
**重要な洞察**: ほとんどの意思決定はシステム 1 によって行われます。システム 2 は怠惰で、システム 1 が困ったときにのみ関与します。これは、私たちの意思決定のほとんどが合理的ではなく直感的であり、事後的に合理化を構築することを意味します。

## 認知バイアス
### 判断バイアス
|バイアス |説明 |例 |
|------|-------------|----------|
| **アンカリング** |最初に出会った情報に過度に依存する |給与交渉: 最初に挙げた数字が議論のアンカーとなる |
| **可用性ヒューリスティック** |例が思い浮かびやすいかどうかで確率を判断する |墜落事故が広く報道されているため、飛行機事故のリスクを過大評価している |
| **代表性** |ステレオタイプとの類似性による確率の判断 |物静かな人が農民ではなく図書館員であると仮定します (基本料金は無視します)。
| **フレーミング効果** |選択肢がどのように提示されるかによって意思決定が変わります。 「生存率90％」は「死亡率10％」よりも良いと感じる |
| **後知恵バイアス** | 「私はそれをずっと知っていました」 - 過去の出来事は予測可能であると考える |市場暴落の後、人々はそれが明らかだったと主張する |
| **ダニング・クルーガー効果** |能力の低い人は自分の能力を過大評価します。専門家は自分たちの意見を過小評価している |初心者投資家は市場に勝てると確信 |
### 意思決定バイアス
|バイアス |説明 |例 |
|------|-------------|----------|
| **損失回避** |損失は​​、同等の利益が気持ちいいと感じるのと比べて、およそ 2 倍苦痛に感じられます。負け株を長く保有しすぎる。必要なリスクを回避する |
| **現状維持バイアス** |現状を優先する |より良い医療プランや年金基金に切り替えない |
| **養老効果** |すでに所有しているものを過大評価する |マグカップを買うよりも売るために多くを求める |
| **サンクコストの誤謬** |将来の価値ではなく、過去の投資のために継続 |もう半分読んだので、ダメな本を読み終える |
| **確証バイアス** |既存の信念を裏付ける情報を求めています |自分の意見に同意するニュースソースのみを読む |
| **現在バイアス (双曲割引)** |当面の報酬と将来の報酬を重視する |先延ばしにする。退職後の貯蓄不足 |
| **バンドワゴン効果** |他の人がやっているから何かをする |バブル時の資産購入 |
| **おとり効果** |別のオプションをより良く見せるために劣ったオプションを追加する | 3 つの価格帯で、最上位を合理的に見せるために中間のオプションが存在します。

## ヒューリスティック
|ヒューリスティック |説明 |それが役立つとき |失敗したとき |
|----------|---------------|--------------|--------------|
| **認識** |認識しているものを選択してください |使い慣れた分野での迅速な意思決定 |馴染みのない、しかしより良いオプションが見落とされています。
| **ベストを尽くします** |最も重要な手がかりに基づいて選択してください | 1 つの要素が優勢な場合 |複数の要素が同等に重要な場合 |
| **満足** |最小基準を満たす最初のオプションを選択してください |検索コストが高い場合 |より良いものがあるのに「十分」で満足する |
| **側面による消去** |オプションを一度に 1 つの属性ごとに削除します。多くのオプションを比較する場合 |属性の順序によって結果が変わる |
| **ヒューリスティックに影響する** |感情に基づいて意思決定を行う |迅速な脅威評価 |感情的な反応はデータを上書きします。

## プロスペクト理論
カーネマンとトベルスキーの期待効用理論に対する代替案:
|原則 |説明 |
|----------|---------------|
| **参照依存性** |人は結果を絶対的な基準ではなく、基準点 (通常は現状) と比較して評価します。
| **損失回避** |損失は​​同等の利益の約 2 倍に達します。
| **感度の低下** | 100 ドルと 200 ドルの差は、1,100 ドルと 1,200 ドルの差よりも大きく感じられます。
| **確率の重み付け** |人々は小さな確率を重視し、大きな確率を軽視します。
### 値関数
|地域 |形状 |行動 |
|----------|----------|----------|
| **利益** |凹面（リスク回避） | 50% の確率で 1,000 ドルよりも確実に 500 ドルを優先する |
| **損失** |コンベックス（リスク追求型） | 500 ドルの確実な損失よりも 50% の確率で 1,000 ドルを損失することを優先 |
| **損失領域は急勾配です** |損失回避 | 500 ドルを失うのは、500 ドルを得るのが気持ちいいよりも痛い |

## ナッジ理論
### アーキテクチャ選択の原則
|原則 |説明 |例 |
|----------|---------------|----------|
| **デフォルトのオプション** |人々はデフォルトを受け入れる傾向があります。オプトアウト臓器提供により提供率が劇的に上昇 |
| **簡略化** |複雑さを軽減します。簡単にしてください |年金制度への自動加入 |
| **社会的証明** |人は他人の行動に従う | 「10 人中 9 人のゲストがタオルを再利用しています」 |
| **顕著性** |重要な情報を目立つようにする |メニューにはカロリーが含まれています。家電製品のエネルギーラベル |
| **コミットメントデバイス** |将来の行動を固定する |自動貯蓄送金;運動への事前の約束 |
| **タイミング** |質問するとき |年金は月末ではなく給料日に加入 |
### ナッジ vs スラッジ
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **ナッジ** |正しいことをやりやすくする |デフォルトの登録。簡略化されたフォーム |
| **スラッジ** |適切な意思決定を妨げる過度の摩擦 |官僚的な形式。非表示のキャンセル プロセス |
| **汚泥監査** |不必要な摩擦を特定して取り除く |タスクを完了するまでのクリック数/ステップ数をカウントする |

## アプリケーション
### ビジネス中
|アプリケーション |行動洞察 |結果 |
|-----------|-------|----------|
| **価格** |アンカリング;おとり効果 | 3 段階の価格設定。プレミアム オプションが中間層の売上を押し上げる |
| **マーケティング** |希少性。社会的証明 | 「在庫はあと 2 個だけです」; 「ベストセラー」ラベル |
| **製品デザイン** |デフォルトのオプション。摩擦 |事前に選択されたオプション;ワンクリック購入 |
| **交渉** |フレーミング;アンカリング |最初のオファーが交渉のアンカーとなる |
| **従業員の行動** |社会規範。こだわり |公的目標。仲間の認識 |
### 公共政策において
|アプリケーション |行動洞察 |例 |
|-----------|-------|-----------|
| **税務コンプライアンス** |社会的証明 | 「あなたの地域では 10 人中 9 人が期限内に税金を払っています。」 |
| **健康** |デフォルト。こだわり |臓器提供のオプトアウト。自動予約スケジュール |
| **節約** |現在の偏見。デフォルト |退職金制度への自動登録。明日はもっと節約 |
| **エネルギー** |社会的比較。顕著性 |近隣諸国とのエネルギー使用量の比較 |
| **教育** |簡素化;ナッジ |簡素化された FAFSA フォーム。テキストメッセージリマインダー |

## 制限と批判
|批評 |説明 |
|----------|---------------|
| **レプリケーションの危機** |いくつかの古典的な発見 (例: 自我の枯渇) は再現できませんでした。
| **効果の大きさ** |一部のナッジは効果が小さく、実装コストが正当化されない可能性があります。
| **倫理的懸念** |何が「正しい」選択なのかを誰が決めるのでしょうか？パターナリズム vs 自主性 |
| **コンテキスト依存性** |偏見は、ある状況では他の状況よりも強くなります。検査結果は一般化できない可能性があります |
| **過度の単純化** |人間の行動は複雑です。偏見がすべてを説明するわけではない |
| **バックファイア効果** |一部のナッジはリアクタンスを引き起こしたり、内発的動機を低下させたりする可能性があります。

＃＃ まとめ
行動経済学は、人間の意思決定が合理的なエージェント モデルとは体系的に異なることを明らかにしています。システム 1 (高速、直感的) がシステム 2 (低速、分析的) を支配します。アンカリング、可用性、損失回避、現状維持バイアスなどの認知バイアスは、予測可能であり、蔓延しています。プロスペクト理論は、人々が基準点と比較して結果を評価し、損失を嫌う傾向があり、変化に対する感受性が低下していることを示しています。ナッジ理論は、これらの洞察を利用して、人々が自由を制限することなくより良い意思決定を行えるようにする選択アーキテクチャを設計します。アプリケーションはビジネス (価格設定、マーケティング、製品設計) から公共政策 (税務コンプライアンス、節約、健康) まで多岐にわたります。しかし、この分野には、複製の失敗、効果の大きさの小ささ、パターナリズムに関する倫理的問題などの限界があります。実際的なポイントは、人々がどのように行動するかを私たちが望むのではなく、実際にどのように行動するかを考慮してシステムを設計することです。
