# ビジネスと経済
製品やサービスを販売するすべての組織はビジネスであり、商品を生産および流通させるすべての社会は経済です。このファイルの概念は、フリーランスで事業を運営している場合でも、企業で働いている場合でも、ニュースを理解しようとしている場合でも、単にお金が世界でどのように動いているかを理解しようとしている場合でも当てはまります。
---

## ビジネスの構造
ビジネスの法的構造によって、税金の支払い方法、債務の責任者、意思決定の方法が決まります。
|構造 |オーナー |責任 |税金の取り扱い |最適な用途 |
|----------|----------|---------------|--------------|----------|
| **個人事業主** | 1人 |無制限の個人責任 |個人申告で申告される所得 |フリーランス、副業 |
| **パートナーシップ** | 2人以上 |無制限の個人責任 (ジェネラルパートナー) |パートナー間での収入の分配 |プロフェッショナルサービス（法律事務所、コンサルタント） |
| **LLC** | 1 人以上のメンバー |有限責任 (個人資産は保護されます) |柔軟性 – 個人事業、パートナーシップ、法人として課税可能 |ほとんどの中小企業 |
| **C-コーポレーション** |株主 |有限責任 |二重課税（法人税＋配当税） |ベンチャーキャピタルの調達または上場を計画している企業 |
| **エスコーポレーション** |株主様（限定100名） |有限責任 |パススルー (二重課税なし) |税制上の優遇措置を求める中小企業 |
### 企業階層
ほとんどの中大企業は同様の構造に従っています。
- **取締役会**: 株主によって選出されます。戦略を策定し、CEO を雇用します。
- **経営幹部**: CEO (全体戦略)、CFO (財務)、COO (運営)、CTO (テクノロジー)。
- **副社長 / ディレクター**: 部門または事業部門を指揮します。
- **マネージャー**: チームと日々の業務執行を監督します。
- **個人貢献者**: 実際の作業を行っている人々。
役職や報告構造は異なりますが、この階層はほぼすべての大規模組織に存在します。

## 経済学 — 社会が資源をどのように配分するか
経済学では、希少な資源が無制限の欲求にどのように分配されるかを研究します。これは 2 つのブランチに分かれています。
**ミクロ経済学**は個人の意思決定を考察します:消費者はどのように製品を選択するのでしょうか?企業はどうやって価格を設定するのでしょうか？新しい競合他社が市場に参入すると何が起こるでしょうか?
**マクロ経済学**は全体像を考察します。なぜ一部の国は成長する一方で、他の国は停滞するのでしょうか?不況の原因は何ですか?インフレは購買力にどのような影響を与えるのでしょうか?
### 需要と供給 — 中心的なメカニズム
経済学のほぼすべてのものは需要と供給によって決まります。何かの需要が増えると（それを望む人が増えると）、価格は上昇します。供給が増えると（より多くのものが入手可能になると）、価格は下がります。供給が需要と一致する点が**均衡価格**です。
|コンセプト |何が起こるのか |実際の例 |
|----------|---------------|--------|
| **需要は増加し、供給は一定** |価格上昇 |人気都市の住宅 |
| **供給は増加し、需要は一定** |価格が下落する |テクノロジーの進歩に伴うエレクトロニクス |
| **どちらも等しく増加します** |数量は増加、価格はほぼ安定 |消費財の経年変化 |
| **供給ショック** |価格が突然急騰 |石油危機、チップ不足 |
| **需要ショック** |価格が突然暴落します。パンデミックによる旅行崩壊 |
### 主要な経済指標
これらの数字は、経済が健全か、過熱しているか、または問題に陥っているかを示します。
|インジケーター |何を測定するのか |なぜそれが重要なのか |
|----------|------|----------------|
| **GDP** |生産された商品とサービスの総額 |経済規模と成長率 |
| **GDP成長率** |経済はどのくらいの速さで拡大しているのか | >2-3% は健康です。マイナス = 景気後退 |
| **インフレ (CPI)** |物価上昇率 |中程度 (2%) は健康的です。高い浸食性の節約 |
| **失業率** |仕事のない労働力の割合 |高い失業率 = 資源の浪費と人的苦痛 |
| **金利** |お金を借りるコスト |中央銀行によって設定されます。低レートは刺激し、高レートは冷却します。
| **貿易収支** |輸出から輸入を差し引いた額 |持続的な赤字は構造的な問題を示す可能性があります。
| **消費者の信頼感** |人々は経済についてどのように楽観的に感じているか |先進国のGDPの約70%にあたる支出を促進 |
### ビジネスサイクル
経済は直線的には成長しません。これらはフェーズを循環します。
1. **拡大**: 成長、低失業率、賃金上昇、信頼感の高まり
2. **ピーク**: 最大の成長。インフレが上昇し始める可能性がある。資産が過大評価される可能性がある
3. **景気後退（リセッション）**: 生産量の減少、失業率の上昇、信頼感の低下
4. **トラフ**: 底。価格が調整され需要が戻ると回復が始まる
景気後退は通常、GDP 成長率が 2 四半期連続でマイナスになることと定義されます。これらは金融危機、石油ショック、パンデミックによる混乱、資産バブルの崩壊など、さまざまな引き金によって引き起こされますが、パターンは常に似ています。つまり、信頼感の低下、支出の減少、企業の人員削減によってさらに支出が削減されるということです。
中央銀行（米国連邦準備制度など）は金利を調整することでサイクルを平滑化しようとします。不況時には金利を下げて借入と支出を促進し、好況時には金利を上げて過熱を防ぎます。

## マーケティング — 企業が顧客にアプローチする方法
マーケティングは単なる広告ではありません。これは、顧客が何を必要としているかを理解し、それらのニーズを満たす製品を作成し、適切な価格を設定し、顧客が購入できる場所に配布し、その価値を伝えるというプロセス全体です。
### マーケティング ミックス (4 つの P)
| P |意味 |主な質問 |
|---|--------------|--------------|
| **製品** |販売するもの |それはどのような問題を解決しますか?何が違うのでしょうか？ |
| **価格** |請求内容 |顧客は何を支払うのでしょうか?競合他社の料金はいくらですか? |
| **場所** |どこで売っているか |オンライン？小売り？消費者直販ですか？ |
| **プロモーション** |人に伝える方法 |広告、ソーシャルメディア、PR、コンテンツマーケティング? |
### 主要なマーケティング指標
- **CAC (顧客獲得コスト)**: 1 人の新規顧客を獲得するのにかかる費用。広告に 10,000 ドルを費やして 100 人の顧客を獲得した場合、CAC は 100 ドルになります。
- **CLV (顧客生涯価値)**: 1 人の顧客が会社との関係全体でどれだけの収益を生み出すか。平均的な顧客が 3 年間毎月 50 ドルを費やした場合、CLV = 1,800 ドルとなります。
- **CAC:CLV 比率**は少なくとも 1:3 である必要があります。コストは顧客が支払う金額の最大 3 分の 1 である必要があります。 CAC が CLV を超えると、企業はすべての顧客に対して損失を被ることになります。
- **コンバージョン率**: オファーを見た人の何パーセントが実際に購入するか。一般的な電子商取引のコンバージョン率は 1 ～ 3% です。
- **解約率**: 各期間に離脱した顧客の割合。月次解約率が 5% ということは、約 14 か月で顧客の半分を失うことになります。

## 会計 — ビジネスの言語
会計は、企業が財務情報を記録、報告、分析する方法です。あらゆるビジネス上の意思決定には財務的な側面があり、会計はそれを理解するためのツールです。
### 基本方程式
**資産 = 負債 + 資本**
この方程式は常にバランスが取れています。資産とは、企業が所有するもの（現金、設備、在庫）です。負債とは、借りているもの（ローン、買掛金）です。資本は所有者に残されるものです。
### 3 つの財務諸表
|声明 |それが示すもの |時間枠 |重要な質問に答えます |
|----------|--------------|---------------|--------------------------|
| **損益計算書** (損益計算書) |収益、費用、利益 |期間 (四半期、年) | 「私たちはお金を儲けましたか？」 |
| **貸借対照表** |資産、負債、資本 |特定の時点 | 「会社の価値は何ですか？」 |
| **キャッシュ フロー計算書** |入金、出金 |期間 | 「運営するのに十分な現金はありますか？」 |
企業は損益計算書では利益を上げていても、（顧客がまだ支払いをしていない場合、または設備に多額の費用を費やした場合）依然として現金が不足している可能性があります。これが、キャッシュ フロー計算書が重要である理由です。現金は明かりを灯し続けるものです。
### 主要な財務比率
|比率 |式 |それがあなたに伝えること |
|------|-----------|--------|
| **粗利益率** | (収益 - COGS) / 収益 |諸経費を除く売上高 1 ドルあたりの利益はいくらですか |
| **純利益** |純利益/売上高 |結局のところ、各ドルでどれくらいの利益になりますか？
| **流動比率** |流動資産・流動負債 |会社は短期請求を支払うことができますか? |
| **負債から資本へ** |負債総額 / 資本総額 |会社はどの程度活用されていますか? |
| **ROI** |利益 / コスト |投資する価値はありましたか? |

## 起業家精神とスタートアップ
スタートアップは、拡張可能なビジネス モデルを模索する一時的な組織です。この定義 (Steve Blank 氏による) は、スタートアップと中小企業の重要な違いを捉えています。スタートアップは何か新しいものを探しているのに対し、中小企業は実績のあるものを実行します。
### スタートアップのライフサイクル
1. **アイデア**: 解決する価値のある問題を特定します。潜在的な顧客と話をしましょう。
2. **検証**: 実用最小限の製品 (MVP) を構築します。これは、中心となる前提条件をテストする最も単純なバージョンです。
3. **製品と市場の適合**: 顧客が製品を手放すまで繰り返します。これは最も重要なマイルストーンです。
4. **スケーリング**: 製品を市場に適合させたら、雇用、マーケティング、拡大などの成長に投資します。
5. **満期/撤退**: 会社は安定するか、上場 (IPO) するか、買収されます。
### 資金調達の段階
|ステージ |典型的な量 |出典 |資金源となるもの |
|------|------|----------|---------------|
| **ブートストラッピング** |個人貯蓄 |創設者 |初期開発、コンセプトの実証 |
| **プレシード** | 50,000～500,000ドル |友人、家族、エンジェル投資家 | MVP、初期チーム |
| **シード** | 50 万ドル～500 万ドル |エンジェル投資家、初期段階の VC |製品開発、初期顧客 |
| **シリーズ A** | 500 万ドル～2,000 万ドル |ベンチャーキャピタル |製品の拡張と市場投入 |
| **シリーズ B+** | 2000万ドル以上 |ベンチャーキャピタル、グロースエクイティ |急成長、新たな市場 |
| **IPO** | 1億ドル以上 |公設市場 |初期投資家向けの拡大、買収、流動性 |
ほとんどのスタートアップは失敗します。推定では、ベンチャー支援を受けたスタートアップ企業の 90% が初期投資を回収していないことが示唆されています。最も一般的な理由は、市場のニーズがない (42%)、現金がなくなった (29%)、間違ったチーム (23%)、競争に負けている (19%) です。

## サプライチェーンとオペレーション
サプライチェーン管理は、適切な製品を適切なタイミングで適切なコストで適切な場所に届ける調整されたプロセスです。目的は単純明快です。実行は複雑です。
### 主要な概念
- **ジャストインタイム (JIT)**: 必要なときだけ材料を受け取り、在庫コストを削減します。トヨタはこれに先駆けて取り組みました。トレードオフ: サプライチェーンが混乱すると、JIT システムは脆弱になります (2020 年から 2022 年のチップ不足が証明したように)。
- **無駄のない製造**: 無駄、つまり顧客に価値を付加しないものはすべて排除します。過剰生産、待機、輸送、過剰加工、在庫、動作、不良の「7つのムダ」を特定し、排除します。
- **シックス シグマ**: 欠陥を 100 万件の機会あたり 3.4 件に削減します。データと統計的手法を使用して変動の原因を特定し排除します。
- **ブルウィップ効果**: 消費者需要の小さな変化が、サプライチェーンの上流でますます大きな変動を引き起こします。小売売上高が 5% 増加すると、メーカーの注文が 40% 増加する可能性があります。

## 国際貿易
各国が貿易するのは、それぞれに異なる強みがあるからです。デビッド・リカードの **比較優位** (1817 年) の概念は依然として基礎となっています。A 国が B 国よりもあらゆるものを生産するのが優れているとしても、A が最も効率的なことに焦点を当て、B が最も苦手な分野に焦点を当てれば、どちらも利益を得ることができます。
|コンセプト |意味 |例 |
|----------|---------------|----------|
| **関税** |輸入品にかかる税金 |米国の中国製品に対する関税。国内産業を保護するが価格は引き上げる |
| **自由貿易協定** |国家間の障壁を減らす | USMCA (米国-メキシコ-カナダ)、EU 単一市場 |
| **貿易赤字** |インポート > エクスポート |米国は恒久的な貿易赤字を抱えている |
| **貿易黒字** |輸出 > 輸入 |中国とドイツは黒字が続く |
| **為替レート** |ある通貨の別の通貨に対する相対的な価値 |ドル安で輸出は安くなり、輸入は高くなる |
グローバリゼーションは何億人もの人々を（特に中国とインドで）貧困から救い出したが、同時に先進国の労働者を追い出し、仕事が海外に移った。貿易の利益とその分配上の影響との間の政治的緊張は、現代経済学の決定的な問題の 1 つです。

## ビジネス倫理と企業責任
ビジネスは社会の中に存在し、その決定は株主を超えて人々に影響を与えます。問題は、企業が倫理的であるべきかどうかではなく、利益と責任のバランスをどう取るかということです。
|フレームワーク |フォーカス |例 |
|----------|----------|----------|
| **CSR (企業の社会的責任)** |社会的および環境的目標への自主的な取り組み |パタゴニアの環境活動。 TOMS「ワン・フォー・ワン」モデル |
| **ESG (環境、社会、ガバナンス)** |企業行動を評価するための測定可能な基準 |炭素排出量、取締役会の多様性、労働慣行 |
| **B-Corp 認証** |株主だけでなく利害関係者を考慮するという法的要件 |ベン＆ジェリーズ、ダノン |
| **ステークホルダー資本主義** |顧客、従業員、地域社会、株主にサービスを提供する | 「株主至上主義」（利益が何よりも優先）との対比 |
株主優先主義（ミルトン・フリードマン：「企業の社会的責任は利益を増やすことである」）とステークホルダー資本主義（企業はすべてのステークホルダーに奉仕すべきである）の間の議論は、まだ決着していない。従業員を適切に扱い、持続可能な経営を行い、倫理基準を維持している企業は、長期的には優れた業績をあげる傾向にあることが、証拠によってますます示唆されています。しかし、短期的なインセンティブが別の方向に進むことがよくあります。
---

＃＃ まとめ
ビジネスと経済は日常生活から切り離されたものではなく、日常生活のインフラです。需要と供給を理解すると、価格を理解するのに役立ちます。会計を理解することは、ビジネスが健全であるかどうかを評価するのに役立ちます。マーケティングを理解すると、商品を購入する理由がわかります。企業構造を理解することは、組織をナビゲートするのに役立ちます。また、経済学を理解することは、なぜ一部の国が裕福で他の国が貧しいのか、なぜ不況が起こるのか、どのような政策がそれらを解決するのかなど、世界を理解するのに役立ちます。これらの概念を活用するために MBA は必要ありません。基本を理解するだけで十分です。
