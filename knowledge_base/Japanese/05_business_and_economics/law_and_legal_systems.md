# 法律と法制度
法律は、社会がその制度を通じて強制することに同意した一連の規則です。それは道徳とは同じではありません。非道徳的であることを合法にすることも、道徳的に正当化される違法なことを行うこともできます。法律は予測可能性を提供するために存在し、何が許可され、何が禁止され、ルールが破られた場合に何が起こるかを確立します。それがなければ、紛争は権力によって解決されます。これにより、紛争はプロセスによって解決されます。
このファイルは、主要な法制度、法の主な分野、法制度が実際にどのように機能するかを形作る概念をカバーしています。
---

## 世界の法制度
すべての法制度が同じように機能するわけではありません。 3 つの主要な伝統:
|システム |基礎 |使用場所 |裁判官はどのように判断するのか |
|----------|------|----------|----------|
| **慣習法** |判例（過去の裁判例） |英国、米国、カナダ、オーストラリア、インド |裁判官は法令を解釈し、過去の同様の訴訟の先例を適用します。
| **民法** |包括的な法典 |ヨーロッパの大部分、ラテンアメリカ、日本、韓国 |裁判官は書かれた法典を事件に適用します。前例は拘束力が低い |
| **宗教法** |宗教文書とその解釈 |イスラム諸国 (シャリーア)、イスラエル (一部の問題についてはラビ裁判所) |宗教当局は聖典を解釈する |
**コモンロー**は裁判官に多大な影響を及ぼします。状況をカバーする法律がない場合、裁判官は過去に同様の事件がどのように判決されたかを検討します（先例 / *判例*）。これは、コモンローが裁判所の判決を通じて進化することを意味します。裁判官は解釈を通じて事実上法律を制定します。
**民法**は多くの法典を含んでいます。包括的な法典がほとんどの状況をカバーしており、裁判官はその法典を適用します。過去の決定は参考になりますが、拘束力はありません。このシステムは予測可能ですが、柔軟性に欠けます。
ほとんどの国は混合を使用しています。たとえば、米国はコモンローを中核としていますが、ルイジアナ州では民法が適用されます（フランスとスペインの法的伝統の影響を受けています）。

## 法の分野
### 公法と私法
**公法**は、個人と国家との関係を規定します。
- **憲法**: 政府の構造と政府が持つ権限に関する規則。憲法裁判所は、憲法に違反する法律を取り消すことができます（司法審査）。
- **刑法**: 国家は社会に対する犯罪で個人を起訴します。立証責任は「合理的な疑いを超えたもの」であり、これは法律の最高基準である。
- **行政法**: 政府機関の決定に対する異議。規制当局があなたの許可を拒否したり、税務当局があなたを不当に評価したりした場合、行政法を利用して異議を申し立てることができます。
**私法** (紛らわしいですが、民法とも呼ばれます) は、個人間の関係を統治します。
- **契約法**: 当事者間の強制力のある合意
- **不法行為法**: 民事上の違法行為 - 誰かの過失または意図的な行為によってあなたに損害が与えられた場合
- **財産法**: 誰が何を所有し、所有権にはどのような権利が伴うか
- **家族法**: 結婚、離婚、子供の親権、養子縁組
### 刑事事件と民事事件
|特集 |刑事事件 |民事訴訟 |
|-----------|--------------|-----------|
| **誰がそれを持ってくる** |国（検察） |被害者（原告） |
| **立証責任** |合理的な疑いを超えて |証拠の優位性 (可能性の方が高い) |
| **結果** |刑罰（懲役、罰金、執行猶予） |補償（損害賠償）または裁判所命令 |
| **陪審員** |通常ははい |時々 |
| **例** |窃盗、暴行、殺人 |契約違反、人身傷害、財産紛争 |
同じ行為が刑事事件と民事事件の両方につながる可能性があります。 O.J.シンプソンは刑事法廷では無罪となったが（州は合理的な疑いを超えて有罪を証明しなかった）、民事法廷では有罪とされた（原告は自分に責任がある可能性が高いことを証明した）。

## 憲法
憲法は国の最高法規です。政府の構造を確立し、各部門に権限を分配し、基本的権利を保護します。それ以外のすべての法令、規制、大統領令は、それと一致していなければなりません。
### 重要な原則
- **三権分立**: 政府は立法府 (法律の制定)、行政府 (法律の施行)、司法府 (法律の解釈) に分かれています。各ブランチが他のブランチをチェックします。
- **司法審査**: 裁判所は法律または政府の行為を違憲と宣言することができます。米国では、*マーベリー対マディソン* (1803 年) で最高裁判所がこの権限を確立しました。
- **基本的権利**: ほとんどの憲法は、言論、宗教、集会、適正手続き、平等な保護といった核となる自由を保護しています。これらの権利は絶対的なものではありません。やむを得ない理由があり、最も制限の少ない手段を使用する場合、政府はそれらを制限することができます。
- **連邦主義** (連邦制度において): 権力は国と州/地方政府の間で分割されます。一部の権限は 1 つのレベルにのみ属します。他は共有されています。

## 契約法
契約は法的に強制力のある合意です。すべての約束が契約であるわけではありません。契約が有効であるためには、特定の要素が必要です。
### 有効な契約の要素
|要素 |意味 |例 |
|----------|---------------|----------|
| **オファー** |具体的な条件を含む明確な提案 | 「私の車を5,000ドルで売ります」 |
| **承認** |それらの条件に正確に同意する | 「その車を 5,000 ドルで購入するというあなたの申し出を受け入れます。」 |
| **考慮事項** |双方が交換する価値のあるもの |買い手からのお金。販売者からの車 |
| **容量** |契約を締結する法的能力 |未成年者および知的障害のある人は能力が欠けている可能性があります |
| **合法性** |契約の目的は合法的でなければなりません |犯罪を犯す契約は無効です |
### 契約がうまくいかないとき
**契約違反**は、一方の当事者が義務を履行しない場合に発生します。救済策には次のようなものがあります。
- **損害**: 損失を補うための金銭 (最も一般的)
- **具体的な履行**: 裁判所は違反当事者に契約を履行するよう命じます (まれです - 通常は不動産のような固有の品目の場合のみ)
- **取消し**: 契約は取り消されます。双方が契約前の立場に戻る
違反に対する防御策には、契約が詐欺に基づいていた、一方の当事者に能力が欠けていた、履行が不可能になった（不可抗力）、または条件が非良心的であることが含まれます。

## 不法行為法 — 誰かが傷ついたとき
不法行為法は、損害を引き起こす民事上の不正行為に対処します。刑法（国家が起訴する）とは異なり、不法行為法では被害者が賠償を求める訴訟を起こすことができます。
### 不法行為の種類
|タイプ |必要なもの |例 |
|------|------|-----------|
| **過失** |注意義務→違反→因果関係→損害賠償 |運転手が赤信号を無視してあなたの車に衝突する |
| **意図的な不法行為** |意図的な有害行為 |暴行、名誉毀損、不法侵入 |
| **厳格な責任** |過失の有無に関わらず責任 |製品の欠陥、危険な行為、犬の咬傷（一部の州） |
**過失**は、最も一般的な不法行為です。過失訴訟で勝訴するには、原告は次の 4 つのことを証明する必要があります。
1. 被告には**注意義務**があった（運転者には安全運転の義務がある）
2. 被告はその義務に**違反**した(赤信号を無視した)
3. 違反は損害を**引き起こしました** (そうでなければ衝突は起こらなかったでしょう)
4. 原告は実際に**損害**を被った（医療費、賃金の損失、痛み）

## 財産法
財産法は、誰が何を所有するのか、また所有権にはどのような権利が伴うのかを定義します。
### プロパティの種類
|タイプ |例 |重要なルール |
|------|------|-----------|
| **不動産** |土地・建物・備品 |所有権は証書によって譲渡されます。公的記録に記録される |
| **個人所有物** |車、家具、設備 |所有権または売渡証書によって譲渡された所有権 |
| **知的財産** |特許、著作権、商標 |無形;登録または使用によって保護されます |
**知的財産**は、デジタル経済においてますます重要になっているため、特別な注意を払う必要があります。
- **特許** (20 年): 発明を保護します。発明がどのように機能するかを公開する代わりに、発明の製造、使用、販売を独占することができます。
- **著作権** (存続期間 + 70 年): 書籍、音楽、ソフトウェア、アートなどのオリジナルの創造的な作品を保護します。登録する必要はありません。著作権は作成された瞬間から存在します。
- **商標** (無期限に更新可能): ブランド識別子 (名前、ロゴ、スローガン) を保護します。消費者の混乱を防ぎます。
- **企業秘密**: ビジネスの機密情報 (コカ・コーラのレシピ、Google の検索アルゴリズム) を保護します。登録は必要ありませんが、秘密が独自に発見された場合、保護は終了します。

## 雇用法
雇用法は、雇用主と従業員の間の関係を規定します。それは国によって、そして（米国の場合）州によって大きく異なります。
### 主要な概念
|コンセプト |意味 |によって異なります |
|----------|---------------|----------|
| **随意雇用** |いずれの当事者も、法的理由にかかわらず、いつでも終了できます。米国 (ほとんどの州);他のほとんどの国では大義が必要です。
| **最低賃金** |法定最低時給 |国、州、都市 |
| **反差別** |人種、性別、年齢、宗教、障害を理由に解雇したり雇用を拒否したりすることはできません |保護されるカテゴリは管轄区域によって異なります。
| **労働災害補償** |業務上の災害に対する給付金（無過失） |米国の州レベル |
| **非競争契約** |従業員が退職後に働ける場所を制限する |ますます制限されています。米国の一部の州では禁止されています。
| **残業** |週の標準労働時間を超えた時間に対する割増賃金 |米国: 週 40 時間後に 1.5 倍 |
多くの国では、有給休暇の義務化、賃金透明性法、競業禁止の制限、ギグワーカーの分類など、労働者保護を強化する傾向にあります。これらの変化はビジネスの運営方法に直接影響します。

## 法的手続き
### 民事訴訟の仕組み
1. **提出**: 原告は、法的請求と救済の要求を記載した訴状を提出します。
2. **回答**: 被告は回答 (主張を認める/否認) するか、却下を求める申し立てを提出します。
3. **証拠開示**: 双方が文書、証言録取書、尋問などの情報を交換します。ほとんどの場合、ここで勝敗が決まります。
4. **公判前申し立て**: どちらの側も、特定の問題について判決を下すか、訴訟を完全に却下するよう裁判官に求めることができます (略式判決)。
5. **裁判**: 双方が裁判官または陪審に証拠と弁論を提出します。
6. **評決と判決**: 判決が下されます。
7. **控訴**: 敗訴した当事者は、法的誤りを主張して上級裁判所で決定に異議を申し立てることができます。
ほとんどの民事訴訟は裁判まで至りません。およそ 95 ～ 97% が裁判前に和解しますが、多くの場合、双方が証拠をより明確に把握している場合、証拠開示中または証拠開示後に解決されます。
### 裁判外の紛争解決
|方法 |仕組み |バインディング？ |コスト |
|----------|---------------|----------|------|
| **交渉** |当事者は直接（または弁護士を通じて）話し合います。いいえ |低い |
| **調停** |中立的な第三者が議論を促進 |いいえ |中 |
| **仲裁** |中立的な第三者が双方の意見を聞いて決定 |通常ははい |中～高 |
| **訴訟** |裁判官および場合によっては陪審員による法廷手続き |はい |高 |
多くの契約には強制的な仲裁条項が含まれており、紛争は裁判所ではなく仲裁によって解決されることが求められます。これらは物議を醸しています。一般に、これらの方法はより速く、より安価ですが、裁判所システムへのアクセスが制限され、通常、結果は公開されません。

## 国際法
国際法は国家間の関係を統治します。それを施行する世界政府がないため、国内法とは根本的に異なります。コンプライアンスは、相互の利益、互恵性、および国際的な圧力に依存します。
|エリア |内容 |執行 |
|------|---------------|---------------|
| **条約** |国家間の拘束力のある協定 |相互同意。出金可能 |
| **国際人道法** |戦争の規則。民間人の保護 |国際刑事裁判所、特別法廷 |
| **人権法** |すべての人に固有の普遍的権利 |国連機構、地方裁判所、国内での実施 |
| **通商法 (WTO)** |国際商取引に関する規則 | WTO紛争解決。貿易制裁 |
| **海洋法** |海上境界、航行、資源 |国際海洋法裁判所 |
| **国際私法** |国境を越えた紛争に適用されるのはどの国の法律ですか |複雑な;管轄規則に依存します |
---

＃＃ まとめ
法律は弁護士だけのものではありません。契約がどのように機能するか、あなたの権利とは何か、法制度が紛争をどのように処理するかなど、基本を理解することは、ビジネスを経営する人、協定に署名する人、または市民生活に参加する人にとって不可欠です。法制度は不完全です。費用がかかり、時間がかかり、時には不当な結果を生み出すこともあります。しかし、それは暴力と恣意的な権力をプロセスと予測可能性に置き換えるために存在します。その仕組みを理解すればするほど、より適切に対処できるようになり、不十分な場合には変更をより適切に主張できるようになります。
