# 知的財産とイノベーション
知的財産 (IP) とは、法律によって不正使用から保護されている、発明、芸術作品、ブランド名、デザイン、企業秘密などの創作物を指します。イノベーションとは、アイデアを価値に変えるプロセスです。知的財産法は、クリエイターに報酬を与える（一時的な独占を与えることで）と社会に利益をもたらす（知識が最終的に自由に利用できるようにすることで）という 2 つの相反する利益のバランスを取るために存在します。 IP を理解することは、製品を構築したり、コンテンツを作成したり、ビジネスを運営したり、研究に携わったりする人にとって不可欠です。

## 知的財産の種類
＃＃＃ 概要
|タイプ |保護するもの |期間 |入手方法 |例 |
|------|------|----------|---------------|-----------|
| **特許** |発明 (プロセス、機械、組成物) |出願から20年 |応用;検査;助成金 |新しい薬剤の化合物。製造工程 |
| **著作権** |著者のオリジナル作品 |寿命 + 70 年 (ほとんどの国) |作成時に自動 |本;音楽;ソフトウェアコード。映画 |
| **商標** |ブランド識別子 (名前、ロゴ、スローガン) |無期限 (使用および更新された場合) |商業での使用。登録強化 | 「Nike」の名前とスウッシュのロゴ |
| **企業秘密** |ビジネスの機密情報 |無期限（秘密に限ります） |登録はありません。秘密を守るために合理的な措置を講じなければなりません |コカ・コーラ配合。 Google 検索アルゴリズム |
| **工業デザイン** |製品の外観 | 15 ～ 25 歳 (さまざま) |登録 |スマートフォンの形状。家具デザイン |
| **地理的表示** |特定の地理的起源を持つ製品 |無期限 |登録;地域にリンク |シャンパン;パルミジャーノ・レッジャーノ。ダージリン紅茶 | ダージリン紅茶

## 特許
### 特許要件
|要件 |説明 |
|---------------|---------------|
| **斬新さ** |発明は新しいものでなければなりません。これまで世界のどこにも開示されていなかった |
| **非自明性 (進歩性)** |本発明は、関連分野の当業者にとって自明であってはなりません。
| **実用性（産業上の利用可能性）** |発明には具体的で実用的な用途がなければなりません。
| **主題の資格** |プロセス、機械、製造、または物質の組成物である必要があります。抽象的なアイデア、自然法則、自然現象は特許対象ではありません。
### 特許の種類
|タイプ |説明 |用語 |
|------|---------------|------|
| **実用特許** |発明の機能を保護します |出願から20年 |
| **意匠特許** |機能的なアイテムの装飾デザインを保護 |助成金から 15 年 (米国) |
| **植物特許** |新品種の植物（無性生殖）を保護 |出願から20年 |
### 特許プロセス
|ステップ |説明 |タイムライン |
|------|---------------|----------|
| **1.先行技術調査** |既存の特許および刊行物を検索して新規性を確認する |数週間から数か月 |
| **2.申請草案** |クレーム (保護範囲の定義) と説明を書く |数週間から数か月 |
| **3.ファイルアプリケーション** |特許庁（USPTO、EPOなど）への提出 |出願日 = 優先日 |
| **4.試験** |特許審査官による新規性、非自明性、実用性の審査 | 1 ～ 5 年 |
| **5.オフィスアクション** |審査官は拒否する可能性があります。出願人がクレームを主張または修正する |行ったり来たりの交渉 |
| **6.助成金** |許可されれば特許が付与されます。維持費が必要 |生き続けるための定期料金 |

## 著作権
### 著作権が保護するもの
|保護中 |保護されていません |
|----------|------|
|文学作品 (書籍、記事、コード) |アイデア;事実。システム |
|音楽作品（メロディー・歌詞）｜タイトル;名前;短いフレーズ |
|芸術作品（絵画、写真、デザイン） |操作方法 |
|ソフトウェア コード (記述どおり) |アルゴリズムの機能 (特許可能性がある) |
|映画;テレビ番組。ビデオ |スタイル;テクニック |
|建築設計 |建物の機能面 |
### 著作権の重要な概念
|コンセプト |説明 |
|----------|---------------|
| **固定** |著作権は、作品が有形媒体に固定される（書き留められる、記録される）ときに存在します。
| **自動保護** |登録は必要ありません (ただし、米国では登録により法定損害賠償が認められます) |
| **フェアユース/フェアディーリング** |批評、解説、教育、パロディ目的で許可なく限定的に使用 |
| **クリエイティブ コモンズ** |さまざまな程度の再利用を可能にする標準化されたライセンス |
| **パブリックドメイン** |著作権で保護されていない作品 (期限切れ、権利放棄、または対象外) |
| **雇用の仕事** |従業員が職務の範囲内で作成した著作物は雇用主に帰属します。

## 商標
### 商標の基礎
|側面 |説明 |
|----------|---------------|
| **目的** |商品/サービスの供給元を特定する。消費者の混乱を防ぐ |
| **識別スペクトル** |空想的（最強）→恣意的→示唆的→説明的（弱い）→一般的（保護不可能） |
| **登録** |必須ではありません (慣習法上の使用権) が、重大な法的利点をもたらします。
| **クラス** | 45 クラスに分類された商品/サービス (ニース分類) |
| **メンテナンス** |商用で使用する必要があります。登録は定期的に更新されます |
| **権利侵害** |不正使用は混乱を引き起こす可能性があります |
### 商標の識別性
|カテゴリー |説明 |保護性 |例 |
|----------|---------------|----------|----------|
| **空想的** |ブランド外では意味のない造語 |最強 | 「コダック」; 「ゼロックス」 |
| **任意** |製品に関係なく使用されている実際の言葉 |非常に強い |コンピュータの「Apple」 |
| **挑発的** |製品の性質に関するヒント |強い | 「Netflix」（インターネット映画） |
| **説明** |製品について説明します |弱い;二次的な意味が必要です | 「ホリデイ・イン」 |
| **一般的な** |製品の通称名 |保護できません | 「アスピリン」（かつては商標でした） |

## 営業秘密
|側面 |説明 |
|----------|---------------|
| **定義** |機密であることで経済的価値のある情報。一般には知られていない。秘密を維持するための合理的な努力の対象となります。
| **例** |数式;アルゴリズム。顧客リスト。製造プロセス。事業戦略 |
| **保護** |登録はありません。 NDA が必要です。アクセス制御。知っておくべき基礎 |
| **期間** |無期限 — 秘密が維持される限り |
| **不正流用** |不正な手段による取得（窃盗、スパイ行為、秘密保持契約違反） |
| **対特許** |開示は必要ありません。時間制限なし。しかし、独立した発見やリバースエンジニアリングに対する保護はありません。

## オープンソースとオープンイノベーション
### オープンソースライセンス
|ライセンス |タイプ |主要な要件 |ユーザー例 |
|-------|------|----------------|---------------|
| **マサチューセッツ工科大学** |寛容 |著作権表示を含めます。保証なし | jQuery;反応する |
| **Apache 2.0** |寛容 |通知を含める;特許付与 |アンドロイド; Kubernetes |
| **BSD (2 節)** |寛容 |著作権表示を含める | FreeBSD |
| **GPL v3** |コピーレフト |派生作品も GPL でなければなりません | Linux カーネル。ワードプレス |
| **LGPL** |弱いコピーレフト |リンクによってコピーレフトが引き起こされることはありません。変更するのは | GTK |
| **MPL 2.0** |ファイルレベルのコピーレフト |変更されたファイルは開いている必要があります。新しいファイルは独自のものになる可能性があります。 Firefox |
| **AGPL** |強力なコピーレフト |ネットワーク使用がソース開示のきっかけとなる | MongoDB (旧) |
### オープンイノベーションモデル
|モデル |説明 |例 |
|----------|---------------|----------|
| **オープンソース** |コードは自由に利用できます。コミュニティへの貢献 | Linux; Kubernetes;反応する |
| **オープンデータ** |誰でも使用できるように公的に共有されるデータ |政府のデータセット。研究データ |
| **オープンハードウェア** |ハードウェア設計をオープンに共有 |アルドゥイーノ;ラズベリーパイ |
| **特許プール** |複数の企業がドメイン内の特許を共有 | MPEG-LA (ビデオ コーデック) |
| **競争前のコラボレーション** |競合他社は共通の課題に協力します |株式会社半導体研究所 |

## 知財戦略
### 各タイプの IP をいつ使用するか
|状況 |推奨IP |理由 |
|----------|------|----------|
| **斬新な発明** |特許 | 20年間の独占。強力な保護 |
| **ソフトウェアアルゴリズム** |特許+営業秘密 |特許可能であれば特許。実装を秘密にする |
| **ブランド名/ロゴ** |商標 |ブランドアイデンティティを無期限に保護 |
| **書かれた内容/コード** |著作権 |自動;式を保護します |
| **レシピ/配合** |営業秘密 |開示なし。無期限の保護 |
| **製品デザイン** |デザイン特許 + トレードドレス |外観を保護 |
| **動きの速い市場** |営業秘密 + 先行者利益 |特許には時間がかかりすぎる。競合他社がコピーできるよりも速く動く |
---

＃＃ まとめ
知的財産法は、クリエイターへの報酬と社会への利益のバランスをとります。特許は、一般公開と引き換えに発明を 20 年間保護します。著作権は、著作者の生涯プラス 70 年間、著作物のオリジナル作品を保護します。商標は、使用されている限り、ブランド識別子を無期限に保護します。営業秘密は機密情報を無期限に保護しますが、独立した開示に対する保護は提供しません。オープンソース ライセンスは従来の IP に代わるものを提供し、共同開発を可能にします。適切な知財戦略は、創作物の種類、市場、業界のスピード、企業の目標によって異なります。知的財産を理解することは弁護士だけのものではありません。知識経済を創造、構築、または革新するすべての人にとって不可欠です。
