# サプライチェーンと運用管理
サプライチェーン管理とは、原材料から顧客の手に渡る最終製品に至るまで、調達、調達、変換、物流に関わるすべての活動を調整することです。運用管理は、実稼働システムの日常的な実行です。これらを組み合わせて、企業が適切な製品を、適切なタイミング、適切なコスト、適切な品質で提供できるかどうかを判断します。パンデミック、チップ不足、運河の閉塞は、サプライチェーンがいかに脆弱で世界的に相互接続されているかを示しています。
---

## サプライチェーンの基礎
### サプライチェーンの流れ
|ステージ |アクティビティ |主な懸念事項 |
|----------|----------|---------------|
| **計画** |需要予測;供給計画。 S&OP |正確さ;応答性 |
| **出典** |サプライヤーの選択;調達;契約 |料金;品質;信頼性;倫理 |
| **作る** |生産;組み立て;品質管理 |効率;柔軟性。容量 |
| **配達** |倉庫保管;注文の履行。交通機関 |スピード;料金;精度 |
| **戻る** |逆物流。戻ります。リサイクル |顧客満足度。コスト回収 |
### サプライチェーンの種類
|タイプ |特徴 |最適な用途 |
|-----|-----|----------|
| **効率的** |高い使用率。低コスト;予測可能な |安定需要の機能性商品（食料品） |
| **レスポンシブ** |バッファ容量。フレキシブル;速い |需要が不透明な革新的な商品（ファッション） |
| **回復力** |冗長性。視認性;適応性 |高リスク環境。重要品 |
| **アジャイル** |延期;マスカスタマイゼーション |多様性とライフサイクルの短い製品 |
| **無駄のない** |無駄を排除する。プルベース。ジャストインタイム |大容量。多様性が低い。安定した需要 |

## 在庫管理
### 在庫タイプ
|タイプ |説明 |目的 |
|------|-------------|----------|
| **原材料** |未処理の入力 |供給変動に対する緩衝 |
| **進行中の作業 (WIP)** |半完成品 |生産段階間のバッファ |
| **完成品** |販売準備完了 |需要の変動に対する緩衝 |
| **MRO** (メンテナンス、修理、運用) |作業に必要な物品 |本番稼働を継続する |
| **安全在庫** |予想需要を上回る余剰在庫 |不確実性から守る |
| **パイプライン在庫** |拠点間の移動中 |輸送中は避けられない |
### 在庫管理モデル
|モデル |説明 |いつ使用するか |
|----------|---------------|---------------|
| **EOQ** (経済的注文数量) |保有総額 + 発注コストを最小限に抑える最適な注文サイズ |安定した需要。一定のリードタイム |
| **リオーダーポイント (ROP)** |在庫がしきい値まで下がったら注文する |継続的なレビュー。予測可能な需要 |
| **ABC分析** |項目を値で分類: A (高)、B (中)、C (低) |管理者の注意を優先する |
| **ジャストインタイム (JIT)** |生産で必要な場合にのみ商品を受け取る |安定したサプライチェーン。変動性が低い |
| **ベンダー管理在庫 (VMI)** |サプライヤーが在庫レベルを管理 |サプライヤーとの強力な関係 |
| **委託品** |サプライヤーは使用されるまで在庫を所有します。購入者の携帯コストを削減 |

## 生産システム
### 製造アプローチ
|アプローチ |説明 |ボリューム |バラエティ |例 |
|----------|---------------|----------|---------|---------|
| **ジョブショップ** |カスタム製品。汎用機器 |低い |高 |機械工場;カスタム家具 |
| **バッチ** |大量に生産します。バッチ間の切り替え |中 |中 |ベーカリー;医薬品 |
| **量産** |大容量。専用の機器。組立ライン |高 |低い |自動車;エレクトロニクス |
| **連続フロー** |ノンストップ生産。完全に自動化された |非常に高い |非常に低い |石油精製;化学薬品。スチール |
| **マスカスタマイゼーション** |大量 + 多様性;柔軟な自動化 |高 |高 |デルのコンピュータ。ナイキ バイ ユー |
### 無駄のない製造
|原則 |説明 |
|----------|---------------|
| **値** |顧客が価値があると考えるものを定義する |
| **バリューストリーム** |すべてのステップをマップします。付加価値をもたらすものを特定する |
| **流れ** |価値創造のステップを中断することなくスムーズに進める |
| **プル** |お客様のご要望があった場合のみ製作します |
| **完璧** |ムダ（ムダ）を継続的に排除 |
### 七つの無駄（ムダ）
|廃棄物 |説明 |例 |
|----------|---------------|----------|
| **過剰生産** |必要以上のものを作る |需要が不確実な場合でも予測に基づいて生産する |
| **待っています** |ステップ間のアイドル時間 |次の機械を待っている部品 |
| **交通機関** |材料の不必要な移動 |離れた倉庫間での商品の移動 |
| **過剰処理** |必要以上に仕事をする |追加の検査。不要な機能 |
| **在庫** |必要以上の過剰在庫 | 「万が一に備えて」安全在庫 |
| **モーション** |人の不必要な移動 |道具を取りに歩く。部品に手を伸ばす |
| **欠陥** |仕様を満たしていない製品 |やり直し。スクラップ;保証請求 |

## 物流と輸送
### 交通手段
|モード |コスト |スピード |容量 |最適な用途 |
|------|------|------|----------|----------|
| **道路** (トラック) |中 |中 |中 |ラストマイル。地域的な;柔軟なルーティング |
| **レール** |低い |中 |高 |バルク商品;陸上の長距離 |
| **海事** (船舶) |非常に低い |非常に遅い |非常に高い |国際的;バルク;コンテナ |
| **航空** |非常に高い |非常に速い |低い |高価値。緊急;腐りやすい |
| **パイプライン** |低い（建設後） |連続 |高 |油;ガス;水 |
| **インターモーダル** |さまざま |さまざま |高 |モードの結合。コンテナ貨物 |
### 倉庫設計
|決定 |オプション |トレードオフ |
|----------|-----------|----------|
| **倉庫の数** |少数 (集中型) 対多数 (地域的) |コスト効率と配送速度 |
| **自動化レベル** |手動 vs 半自動 vs 完全自動 |資本コストと人件費と精度 |
| **レイアウト** | U フローとスルーフロー |スペース利用率と移動距離 |
| **ストレージ システム** |棚。ラッキング; AS/RS;カルーセル |密度、アクセシビリティ、コスト |

## サプライチェーンのリスク管理
### 一般的なリスク
|リスクカテゴリ |例 |緩和 |
|--------------|----------|---------------|
| **需要リスク** |予測誤差。鞭効果 | 鞭効果より良い予測。デマンドセンシング。安全在庫 |
| **供給リスク** |サプライヤーの破産。品質上の欠陥 |二重調達。サプライヤーの監査。安全在庫 |
| **物流リスク** |ポートの混雑。キャリアの障害 |マルチモーダル。代替ルート |
| **地政学的リスク** |関税;貿易戦争。制裁 |ニアショアリング。調達国の多様化 |
| **自然災害** |地震;洪水;パンデミック |地理的多様化。事業継続計画 |
| **サイバーリスク** |ランサムウェア。データ侵害 | ITセキュリティ。バックアップシステム |
### ブルウィップ効果
|原因 |説明 |ソリューション |
|----------|---------------|----------|
| **需要予測の更新** |各段階で独自の安全在庫が追加されます。チェーン全体で POS データを共有する |
| **注文のバッチ処理** |定期的な注文により需要が急増します。注文サイクル時間を短縮します。 EDI |
| **価格変動** |プロモーション中の先物購入 |毎日の低価格設定。安定した価格設定 |
| **ゲームの配給と不足** |欠品中の過剰注文 |過去の売上に基づいて割り当てます。共有容量情報 |

## 現代のサプライチェーンのトレンド
|トレンド |説明 |影響 |
|----------|---------------|----------|
| **デジタルツイン** |シミュレーション用のサプライチェーンの仮想レプリカ |より良い計画。シナリオ分析 |
| **サプライチェーンのコントロールタワー** |チェーン全体にわたる一元的な可視性 |混乱へのより迅速な対応 |
| **ニアショアリング / フレンドショアリング** |生産拠点を自国または同盟国に近づける |リスクの軽減;コストが高い |
| **循環型サプライチェーン** |再利用、再製造、リサイクルのための設計 |持続可能性。資源効率 |
| **AI 主導の需要センシング** |短期予測のためのリアルタイム データの機械学習 |より正確;より速い応答 |
| **自動運転車とドローン** |自動運転トラック。ドローン配送 |低コスト。ラストマイルの高速化 |

＃＃ まとめ
サプライ チェーンと運用管理は、商品の物理的な流れを効率的、即応性、回復力のあるものにすることです。在庫管理では、在庫を保有するコストと在庫切れのリスクのバランスがとれます。生産システムは、ジョブショップ (カスタム、少量) から連続フロー (商品、大量) まで多岐にわたります。無駄のない製造により無駄が排除され、効率が向上します。輸送モード、倉庫の場所、自動化レベルなどの物流上の決定によって、コストとサービスの品質が決まります。リスク管理は、鞭効果、サプライヤーの失敗、地政学的混乱、自然災害に対処します。デジタル ツイン、AI 主導の需要センシング、ニアショアリングなどの現代のトレンドは、ますます不安定になる世界に対する業界の対応を反映しています。最高のサプライチェーンは効率的であるだけでなく、可視化され、柔軟性があり、混乱に備えています。
