# ゲーム理論と戦略的思考
ゲーム理論は戦略的相互作用、つまり自分の結果が自分の行動だけでなく他人の行動に依存する状況を数学的に研究したものです。これは、ビジネス競争、国際関係、オークション、交渉、進化生物学、交通機関のルート選択などの日常的な決定など、あらゆる場面に当てはまります。核となる洞察は、戦略的状況における合理的な主体は、自分の戦略を最適化するだけではなく、他の人が何をするかを予測し、他の人も同じことをしているということです。
---

## 基本的な概念
### 重要な用語
|用語 |定義 |
|------|-----------|
| **ゲーム** | 2 人以上の意思決定者 (プレイヤー) がおり、その選択が互いの結果に影響を与える状況 |
| **プレイヤー** |ゲームの意思決定者 |
| **戦略** |起こり得るあらゆる状況に対する完全な行動計画 |
| **報酬** |戦略の特定の組み合わせからプレイヤーが受け取る結果 |
| **ナッシュ均衡** |プレイヤーが一方的に戦略を変更することで利益を向上させることができない一連の戦略 |
| **ドミナント戦略** |他のプレイヤーが何をしようと最善の戦略 |
| **ゼロサム ゲーム** |あるプレイヤーの利益は、別のプレイヤーの損失とまったく同じです。
| **非ゼロサム ゲーム** |プレイヤーは全員が得をすることも、全員が負けることもある |
| **協力ゲーム** |プレイヤーは拘束力のある契約を結ぶことができます |
| **非協力ゲーム** |拘束力のある合意はありません。各プレイヤーは自己の利益のために行動します。

## クラシック ゲーム
### 囚人のジレンマ
容疑者２人が逮捕される。それぞれが協力する（黙秘する）ことも、反抗する（自白する）こともできます。
| | B 協力 | B 欠陥 |
|---|-------------|----------|
| **A は協力します** | A: 1 年、B: 1 年 | A: 10 年間、B: 無料 |
| **欠陥** | A: 無料、B: 10 年 | A: 5 年、B: 5 年 |
|洞察 |説明 |
|----------|---------------|
| **ドミナント戦略** |両方のプレーヤーにとってディフェクトが優勢 |
| **ナッシュ均衡** |両方とも欠陥あり (それぞれ 5 年) |
| **パレート最適** |両者協力（各1年） |
| **レッスン** |個人の合理的な決定は、全体としてはより悪い結果を招く可能性があります。
### その他の古典的なゲーム
|ゲーム |説明 |ナッシュ均衡 | ナッシュ均衡レッスン |
|------|---------------|------|----------|
| **ニワトリ (タカ-ハト)** | 2 人のドライバーが互いに向かい合います。方向転換するか直進する | 1 つは曲がり、1 つは直進 |瀬戸際政策。コミットメントの信頼性 |
| **スタッグハント** |一緒に鹿を狩る (高い報酬)、または一人でウサギを狩る (低い報酬) |両方の鹿または両方のウサギ | 写真調整;信頼 |
| **男女の戦い** | 2 人のプレーヤーは異なる結果を好みますが、調整したいと考えています |両方とも同じイベントに参加します |多重均衡。先に動いた人が有利 |
| **最後通牒ゲーム** |提案者はお金を分割します。応答側が受け入れるか拒否する (どちらも何も得られない) |提案者は最低限のものを提供します。応答者は受け入れます |人々は不公平な申し出を拒否します (不合理だがよくあること) |
| **公共財ゲーム** |共有プールまたはフリーライドに貢献する |誰もがフリーライド |コモンズの悲劇。強制執行の必要性 |

## ゲームの種類
### タイミング別
|タイプ |説明 |例 |
|------|-------------|----------|
| **同時** |プレイヤーは同時に (または他のプレイヤーの動きを知らずに) 動きます。じゃんけん。封印入札オークション |
| **順次** |プレイヤーは次々と動きます。後のプレイヤーは前の動きを観察します。チェス;市場参入の決定 |
| **繰り返し** |同じゲームを複数回プレイ |繰り返される囚人のジレンマ。進行中のビジネス競争 |
### 情報による
|タイプ |説明 |例 |
|------|-------------|----------|
| **完璧な情報** |すべてのプレイヤーは以前のすべての動きを知っています |チェス;チェッカー
| **不完全な情報** |いくつかの動きは隠されています |ポーカー;ビジネスコンテスト |
| **完全な情報** |すべてのプレイヤーはすべての利益と戦略を知っています |ほとんどの教科書的なゲーム |
| **不完全な情報** |一部の利得や種類は不明です。オークション;交渉 |

## ソリューションの概念
### ナッシュ均衡
|側面 |説明 |
|----------|---------------|
| **定義** |戦略を変更するだけでは、プレイヤーの利益を向上させることはできません。
| **見つけ方** |各プレイヤーにとって、他のプレイヤーの戦略に対する最善の対応を見つけてください。それらすべてが交差する場所がナッシュ均衡です。
| **存在** |すべての有限ゲームには少なくとも 1 つのナッシュ均衡があります (おそらく混合戦略で)。
| **独自性** |ゲームには複数のナッシュ均衡が存在する可能性があります。調整の問題が発生します。
| **制限事項** |ナッシュ均衡では、どの均衡が選択されるかはわかりません。公平性を考慮していない |
### ドミナント戦略の均衡
|ステップ |説明 |
|------|---------------|
| **1.戦略を特定する** |各プレイヤーの利用可能な戦略をすべてリストする |
| **2.有力な戦略を見つける** |他人が何をしようと最善の戦略 |
| **3.すべてのプレイヤーが 1 つを持っている場合** |この組み合わせは、支配的な戦略均衡です。
| **4.そうでない場合** |支配戦略またはナッシュ均衡の反復消去を使用する |
### 後方誘導 (連続ゲーム)
|ステップ |説明 |
|------|---------------|
| **1.ゲームツリーを描く** |ノード = 意思決定ポイント。ブランチ = アクション |
| **2.最後から開始** |各ターミナルノードで最後のプレイヤーの最適な選択を特定する |
| **3.逆算して作業** |前の各ノードで、最良の結果につながるアクションを選択します。
| **4.結果** |サブゲームの完璧な均衡 — あらゆる意思決定ポイントにおける最適な戦略 |

## 高度な概念
### 混合戦略
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **混合戦略** |確率に従ってアクションをランダム化する |ジャンケン: それぞれ 1/3 の確率でプレイします |
| **なぜランダム化するのですか?** |対戦相手があなたの動きを予測できないようにします |サッカーにおけるペナルティキック。税務調査 |
| **混合戦略ナッシュ均衡** |各プレイヤーは自分の純粋な戦略に無関心です。どちらのプレイヤーも他のプレイヤーを悪用することはできません。
### 繰り返されるゲームと民俗定理
|コンセプト |説明 |
|----------|---------------|
| **有限回繰り返し** |逆誘導は協力を解きほぐします。一発勝負と同じ |最終ラウンドの離脱は逆伝播 |
| **無限に繰り返されます** |協力は将来の処罰の脅威を通じて維持できる |しっぺ返し。厳しいトリガー戦略 |
| **フォーク定理** |個別に合理的な利得は、無限に繰り返されるゲームではナッシュ均衡になる可能性があります。将来が十分に重要であれば協力は可能です |
| **割引率** |プレイヤーが将来の利益をどれだけ重視しているか。高い = より多くの協力 |忍耐強いプレイヤーはもっと協力してください |
### メカニズム設計 (逆ゲーム理論)
|コンセプト |説明 |
|----------|---------------|
| **目標** |望ましい結果を達成するためにゲームのルールを設計する |
| **アプリケーション** |オークション;投票システム。契約設計。市場デザイン |
| **啓示の原則** |いかなるメカニズムによって達成可能な結果も、真実の直接メカニズムによって達成できます。
| **例** | Vickrey オークション (第 2 価格非公開入札) — 本当の価値を入札するのが支配的な戦略です |

## アプリケーション
＃＃＃ 仕事
|アプリケーション |ゲーム理論のコンセプト |洞察 |
|-----------|-------|-----------|
| **価格競争** |囚人のジレンマ |価格競争は両社に打撃を与えた。繰り返されるゲームにおける暗黙の共謀 |
| **市場参入** |シーケンシャルゲーム。こだわり |参入を阻止するという現職企業の脅しは、彼らが生産能力に投資した場合にのみ信頼できる。
| **オークション** |機構設計 |セカンドプライスオークションは真の価値を引き出します。周波数オークションで数十億ドルを調達 |
| **交渉** |交渉ゲーム。ナッシュ均衡 |余剰を分割します。最後通牒ゲームにおける先行者利益 |
| **シグナリング** |スペンスの教育モデル |低品質のタイプでは高価な信号を入手できないため、高価な信号は信頼できます。
### 国際関係
|アプリケーション |ゲーム理論のコンセプト |洞察 |
|-----------|-------|-----------|
| **軍拡競争** |囚人のジレンマ |双方とも武装解除したほうが良いのですが、お互いを信頼することができません。
| **貿易戦争** |繰り返しゲーム |報復: 他の欠陥が見つかるまでは協力し、その後は報復する |
| **気候変動に関する協定** |公共財ゲーム |ただ乗りは合理的です。強制メカニズムが必要 |
| **抑止** |チキン;信頼できるコミットメント |相互確証破壊はナッシュ均衡である |

＃＃ まとめ
ゲーム理論では、自分の結果が他人の行動に依存する戦略的相互作用を研究します。戦略を変更するだけではどのプレイヤーも利益を得られないナッシュ均衡が、中心的な解決策の概念です。囚人のジレンマのような古典的なゲームは、個人の合理的な決定が全体として悪い結果を生み出す可能性があることを示しています。連続したゲームは後方帰納法によって解決されます。ゲームを繰り返すことで、将来の罰の脅威にさらされても協力を維持できます。混合戦略には、予測不可能なままにするためのランダム化が含まれます。メカニズムの設計は問題を逆転させます。結果を予測するのではなく、望ましい結果を達成するためのルールを設計します (オークションの場合のように)。アプリケーションは、ビジネス (価格設定、エントリー、オークション)、政治 (投票、条約)、生物学 (進化的安定戦略)、および日常生活に及びます。基本的な教訓は、戦略とは単に自分が何をするかということではなく、他の人も同じことをしていることを知って、何をするかを予測することであるということです。
