# 組織設計と文化
組織デザインとは、戦略を効果的に実行するための構造、プロセス、役割、意思決定権を意図的に配置することです。文化とは、人々が実際にどのように協力するかを形作る共有の価値観、信念、規範、行動です。構造はフレームワークを提供します。文化は行動を形成します。構造は紙の上で再設計できますが、文化がその変更をサポートしていなければ、実装は失敗します。同様に、強力な文化と非効率な構造が組み合わされると、組織のパフォーマンスは徐々に低下します。最も効果的な組織は両方に取り組み、それらが深く相互に関連していることを認識しています。

## 組織構造
### 一般的な構造
|構造 |説明 |強み |弱点 |
|----------|---------------|---------------|---------------|
| **機能的** |専門分野ごとにグループ化 (エンジニアリング、マーケティング、販売) |深い専門知識。効率;明確なキャリアパス |サイロ。部門間の調整が遅い |
| **部門** |製品、市場、地域ごとにグループ化 |顧客/市場に焦点を当てます。損益の説明責任 |機能の重複。資源競争 |
| **マトリックス** |二重レポート: 機能 + 製品/プロジェクト |柔軟性。部門を超えたコラボレーション |混乱;権力闘争。決断が遅い |
| **平ら/水平** |管理レイヤーがほとんどありません。幅広い制御範囲 |迅速な意思決定。権限を与えられた従業員。低いオーバーヘッド |スケーリングが難しい。不明確な報告 |
| **チームベース** |部門を超えたチームを中心に組織される |自律性。スピード;顧客重視 |チーム間の調整。一貫性 |
| **ネットワーク / プラットフォーム** |コアチーム + 外部パートナー。プラットフォームは他の人を可能にする |スケーラビリティ。柔軟性。アセットライト |品質管理;パートナーへの依存 |
| **ホラクラシー** |自己管理チーム。責任によって定義される役割 |高い自律性。アダプティブ |紛らわしい;誰にとってもうまくいくわけではありません |
### 制御範囲
|係数 |ナロースパン (4-6) |ワイドスパン (10-15+) |
|----------|---------------------|----------|
| **管理レイヤー** |たくさん |少数 |
| **監修** |近い;実践 |委任された;ハンズオフ |
| **こんな用途に最適** |複雑なタスク。未経験のチーム |日常的なタスク。経験豊富な自律的なチーム |
| **リスク** |マイクロマネジメント。決断が遅い |サポートの欠如。調整ギャップ |
### 集中化と分散化
|寸法 |集中型 |分散型 |
|-----------|-----------|---------------|
| **意思決定** |トップダウン |端に追いやられた |
| **速度** |遅い (上部のボトルネック) |迅速 (ローカルでの決定) |
| **一貫性** |高 |変数 |
| **イノベーション** |トップの帯域幅によって制限される |複数の情報源から出てくる |
| **こんな用途に最適** |危機;初期段階。コンプライアンス重視の業界 |知識労働。動きの速い市場。スケールアップ |

## 設計原則
### 組織設計における重要な決定
|決定 |質問 |オプション |
|----------|----------|----------|
| **部門別化** |人々をどのようにグループ化するのでしょうか? |機能別;製品;お客様;地理;プロセス |
| **指揮系統** |誰が誰に報告しますか? |明確な階層構造。マトリックス;ネットワーク |
| **決定権** |誰が何を決めるのでしょうか？ |集中化。分散化。 RACI マトリックス |
| **調整メカニズム** |チームはどのように連携するのでしょうか? |連絡役。部門横断的なチーム。インテグレーター;共有目標 |
| **標準化** |標準化とローカルの違いはどれくらいですか? |プロセス;出力。スキル;規範 |
### ガルブレイスのスターモデル
|要素 |説明 |
|----------|---------------|
| **戦略** |方向;目標。競争上の優位性。組織が存在する理由 |
| **構造** |関係の報告。階層;ユニットのグループ化 |
| **プロセス** |情報の流れ。意思決定;計画;予算編成 |
| **報酬** |インセンティブ;パフォーマンスの測定。戦略との整合性 |
| **人** |雇用;発達;文化;人間の能力 |
重要な洞察: 戦略は構造を推進します。他のすべての要素は整列する必要があります。プロセス、報酬、人材育成を変えずに構造を変えると失敗します。

## 組織文化
### 文化とは実際何なのか
|レイヤー |説明 |可視性 |
|----------|---------------|----------|
| **アーティファクト** |目に見える構造、プロセス、行動、ドレスコード、オフィスのレイアウト |見やすく、解釈が難しい |
| **支持される価値観** |戦略、目標、哲学、ミッションステートメントを表明 |公的に宣言される。実際の動作と一致しない可能性があります。
| **基本的な前提条件** |無意識で当然と思われている信念、認識、思考、感情 |見えない;行動の本当の推進力 |
### 文化の種類 (競合する価値観のフレームワーク)
|文化 |フォーカス |特徴 |例 |
|----------|----------|-----|----------|
| **クラン** (コラボレーション) |内部 + 柔軟 |家族のようです。指導;チームワーク。コンセンサス |ザッポス。小規模なスタートアップ |
| **アドホクラシー** (作成) |外部 + フレキシブル |革新的;リスクを取ること。起業家精神のある;動的 | Google (初期);スペースX |
| **市場** (競争) |外部 + 制御 |結果志向。競争力;目標に焦点を当てた;市場シェア |アマゾン;ウォール街の企業 |
| **階層** (コントロール) |内部 + 制御 |構造化された;プロセス主導型。効率;一貫性 |政府機関;軍隊;伝統的な銀行 |
### 文化的側面
|寸法 |説明 |
|----------|---------------|
| **心理的安全性** |人々は罰を恐れずにリスクを負い、弱者になれるでしょうか? |
| **説明責任** |人々は自分の約束に対して責任を負っていますか? |
| **透明性** |情報はオープンに共有されていますか、それとも権力として蓄えられていますか? |
| **イノベーションへの寛容** |失敗は罰されるのでしょうか、それとも学習として扱われますか? |
| **顧客志向** |意思決定は顧客のニーズから始まりますか、それとも社内の都合から始まりますか? |
| **スピードと品質** |素早い反復と慎重な熟慮のどちらに偏っていますか? |
| **階層の尊重** |後輩は先輩のアイデアに異議を唱えることができますか？ |

## 変更管理
### 変革への取り組みが失敗する理由
|理由 |説明 |
|----------|---------------|
| **緊急性はありません** |なぜ変化が必要なのかを人々は理解していない |
| **連合はありません** |変化を推進する強力なグループは存在しない |
| **ビジョンがない** |将来の状態がどのようになるかは不明 |
| **コミュニケーションが不十分** |人々は変化やその中での自分の役割を理解していません。
| **すぐに勝つことはできません** |勢いを増すための目に見える進歩はない |
| **早めのお祝い** |変化が組み込まれる前に勝利を宣言 |
| **耐培養性** |変更は根深い仮定と矛盾する |
| **補強なし** |昔の行動は報われる。新しい行動は維持されない |
### コッターの 8 ステップ モデル
|ステップ |アクション |
|------|----------|
| **1.緊急性を高める** |変化しないことの脅威を人々が理解できるようにする |
| **2.指導的な連合を構築します** |十分な力と信頼性を備えたグループを編成する |
| **3.戦略的ビジョンを形成する** |明確な将来像を描く |
| **4.義勇軍に入隊する** |クリティカルマスから賛同を得る |
| **5.アクションを有効にする** |障壁を取り除きます。人々に力を与える |
| **6.短期的な勝利を生み出す** |目に見える成功を生み出す |
| **7.加速を維持** |押し続けてください。あまり早く勝利宣言しないでください |
| **8.研究所の変更** |新しい行動を文化に定着させる |

## リモートワークとハイブリッドワーク
|チャレンジ |戦略 |
|----------|----------|
| **コミュニケーション** |デフォルトは書き込みです。非同期ファースト;文書による決定 |
| **信頼** |時間ではなく成果を測定します。監視を避ける |
| **オンボーディング** |構造化されたプログラム。バディシステム。明示的なドキュメント |
| **文化** |意図的な儀式。通常のオールハンド。バーチャルソーシャルイベント |
| **資本** |近接バイアス: リモート ワーカーが平等な可視性と機会を確保できるようにする |
| **コラボレーション** |明確な所有権。定義されたインターフェース。定期的な同期 |
| **健康** |境界を尊重します。接続を切断する権利。会議の過多を避ける |

＃＃ まとめ
企業が戦略を実行できるかどうかは、組織設計と文化によって決まります。構造は、報告関係、決定権、調整メカニズムを定義します。文化は、人々が実際にどのように行動するか、つまり日々の仕事の指針となる前提、規範、価値観を定義します。ガルブレイスのスター モデルは、戦略、構造、プロセス、報酬、人材がすべて一致していなければならないことを思い出させます。文化の種類は、氏族 (協調) からアドホクラシー (革新的)、市場 (競争)、階層 (統制) まで多岐にわたります。コッター氏の 8 ステップ モデルのような変更管理フレームワークは、変革のための構造を提供しますが、本当の戦場は文化です。変更が深い前提と矛盾する場合、それがどれほど綿密に計画されていたとしても失敗します。リモートワークとハイブリッドワークでは、コミュニケーション、信頼、近接性バイアスに関する新たな課題が加わります。優れた組織は、意図的に設計し、戦略をサポートする文化を構築し、環境が変化しても喜んで進化し続けます。
