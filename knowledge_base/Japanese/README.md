## 貢献とメタデータ
このナレッジ ベース内のすべてのコンテンツ ファイル (この`README.md`を除くすべて) は、YAML フロントマター ブロックで開きます。[skills](../../skills/skill-creator.md)で使用されているものと同じ投稿者追跡パターンに従っているため、両方のコレクションにわたって著者、編集、レビューを追跡できる状態が維持されます。一般的なコントリビューション ワークフロー (フォーク、分岐、プル リクエスト、ファイルの配置、命名規則) については、ルート[CONTRIBUTING.md](../../CONTRIBUTING.md)を参照してください。
### フロントマター スキーマ
各ファイルはこのブロック (`---` 区切り記号の間) で始まり、5 つのコメント付きセクションに分割されます。
```yaml
---
# Metadata
title: "Python"            # the file's H1 heading
description: "..."          # one-line summary (see field table below)
category: "Coding and Technology"
version: "1.0.0"
status: "active"            # active | draft | deprecated | archived

# Contribution
authors:
  - name: "AI Model Training Team"
    email: ""
    role: "original_author"  # original_author | contributor | maintainer | reviewer
contributors: []
changelog:
  - version: "1.0.0"
    date: "2026-08-05"
    author: "AI Model Training Team"
    changes: "Added YAML frontmatter metadata for contributor tracking"

# Review
created: "2026-08-05"
last_modified: "2026-08-05"
review_date: "2027-02-05"
reviewed_by: "Coding & Technology Knowledge Base Team"
next_review: "2027-08-05"

# Classification
tags: [python, programming-language, syntax, ecosystem, coding-and-technology]
difficulty_level: "intermediate"   # beginner | intermediate | advanced
prerequisites: []
estimated_reading_time: "58 min"

# Contribution Guide
contribution:
  license: "MIT"
  feedback_channel: "GitHub Issues"
  how_to_contribute: "Submit a PR with changes and update the changelog"
  review_process: "Changes are reviewed by category maintainers before merge"
---
```

|フィールド |出典/目的 |
|---|---|
| `title`|ファイルの最初の`#`見出しから取得 |
| `description`|一行の要約。トピック ファイルはこの README のインデックスのエントリを再利用し、プログラミング言語ファイルは生成された説明を使用します。
| `category`/`reviewed_by`|親ディレクトリから派生 (`01_coding_and_technology` → "コーディングとテクノロジ" / "コーディングとテクノロジ ナレッジ ベース チーム") |
| `version`|セマンティックバージョン。各編集でバンプします (以下を参照) |
| `authors`/`contributors`|元の作成者とそれ以降にファイルを編集した人 |
| `changelog`|追加専用の変更リスト (最新のものから順) |
| `review_date`/`next_review`|スキル レビュー スケジュールを反映した、約 6 か月と約 1 年のペース |
| `tags`|ファイル名トークンとクリーン カテゴリ キーワード (例:`coding-and-technology`) |
| `difficulty_level`|カテゴリごとに設定し、言語ごとにオーバーライドします (例: Haskell/Assembly →`advanced`、Scratch →`beginner`)。
| `estimated_reading_time`|行数から計算 |
### ファイルの編集
ナレッジ ベース ファイルを変更するときは、そのフロントマターの同期を維持します。
1. **[SemVer](https://semver.org/)に続いて`version`** をバンプします:
   - パッチ (`1.0.x`): タイプミス、書式設定、軽微な修正
   - マイナー (`1.x.0`): 新しいセクション、拡張されたコンテンツ、新しい例
   - メジャー (`x.0.0`): 完全な書き換えまたは再構築
2. 変更内容を説明する **変更ログ エントリを追加** (新しいものから順):   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **`last_modified` **を変更の日付に更新します
4. ファイルを初めて編集する場合は、**自分自身を`contributors`** に追加します。   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
