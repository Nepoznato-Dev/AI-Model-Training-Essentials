# 哲学と批判的思考
哲学は、トーガを着たひげを生やしたギリシャ人専用の埃っぽい主題ではありません。これは、あなたが行うすべての意思決定の背後にあるオペレーティング システムです。何が知識として重要か、何を行う価値があるか、良い議論と悪い議論をどのように区別するかなどです。クリティカルシンキングは実践的な側面であり、主張を分析し、間違った推論を見つけ、より良い決定を下すスキルです。このファイルには、主要なアイデア、それを評価するためのツール、そして誰もが陥る認知の罠が含まれています。

## 倫理の枠組み
何が正しいかを判断する必要があるとき、意識しているかどうかにかかわらず、あなたは倫理を実践していることになります。主なアプローチは 3 つあります。
### 3 つのフレームワーク
|フレームワーク |それが尋ねる質問 |強さ |弱点 |
|----------|------|----------|----------|
| **結果主義** (功利主義) | 「何が最良の結果を生み出すのか？」 |実践的で測定可能、ポリシーに合わせたスケール |結果を予測するのは困難です。少数派への危害を正当化できる |
| **義務論** (カント倫理学) | 「みんなが守るべきルールは何ですか？」 |個人の権利を保護します。一貫性のある |硬い;相反する職務 |
| **美徳倫理** | 「善良な人は何をするでしょうか？」 |フレキシブル;キャラクターに焦点を当てます |漠然;明確な行動指針を与えていない |
### カントの定言命法
行動が道徳的かどうかを判断するカントのテスト:
1. **普遍性**: 誰もがこのように行動するようにしていただけますか? （もし嘘が普遍的であれば、信頼は崩壊するでしょう。）
2. **目的としての人類**: 人間を単に目的を達成するための手段として扱ってはなりません。
### 応用倫理
|ドメイン |主な質問 |
|------|--------------|
| **生命倫理** |中絶、安楽死、遺伝子工学、動物の権利 |
| **ビジネス倫理** |企業責任、内部告発、公正な賃金 |
| **テクノロジー/AI 倫理** |プライバシー、アルゴリズムによる偏見、自律型兵器、雇用の喪失 |
| **環境倫理** |気候変動への責任、動物福祉、世代間の正義 |

## 論理と議論
論理学は正当な推論の研究です。これは、誰かの議論が実際にその結論を裏付ける場合と、そうでない場合を判断するツールを提供します。
### 推論の種類
|タイプ |説明 |例 |
|------|-------------|----------|
| **演繹法** |前提が真であれば、結論は *必ず* 真です。 |すべての人間は死すべき存在です。ソクラテスは人間です。 →ソクラテスは死ぬ。 |
| **誘導性** |前提は結論を*おそらく*、確実ではありません。 |私が見た白鳥はどれも白いです。 →おそらくすべての白鳥は白いでしょう。 |
| **誘拐的** |最良の説明への推論。 |草が濡れています。最も適切な説明は、雨が降ったことです。 |
### よくある論理的誤り
|誤謬 |説明 |例 |
|----------|---------------|----------|
| **アドホミネム** |議論ではなく人を攻撃する | 「経済学に関して彼女を信頼することはできません。彼女は経済学者ではありません。」 |
| **ストローマン** |攻撃を容易にするために議論を誤って伝える | 「軍事予算を削減したいのですか？ それで国を無防備なままにしておきたいのですか？」 |
| **当局への訴え** | 「専門家がそう言っているので、X は正しい」（議論を確認せずに） | 「このノーベル賞受賞者が政治についてこう言っているのだから、それは正しいに違いない。」 |
| **誤った二分法** |他にも選択肢がある場合に 2 つの選択肢だけを提示する | 「あなたはこの政策を支持するか、それとも子供のことを気にしないかのどちらかです。」 |
| **滑りやすい坂道** | A は、ありそうもない出来事の連鎖を通じて Z につながります。 「マリファナを合法化すれば、すぐにすべてが合法化されるでしょう。」 |
| **質問です** |結論は前提条件内で想定されます。 「この法律は不公平だから不当だ。」 (不当 = 不公平 — 同じこと) |
| **ポストホックエルゴプロパティホック** | A は B の前に発生したため、A が B を引き起こしました。 「サプリメントを摂取したら、気分が良くなりました。サプリメントが効いたのです。」 |
| **トゥ クォケ** | 「あなたもやっているのよ」―批評家は偽善的であるという理由で批判を無視する | 「もっと健康的な食事をするように言うのに、あなたはファストフードを食べています。」 |
| **自然に訴える** | 「自然＝良い」 | 「人間は肉を食べるように進化したので、ヴィーガンは不自然で間違っています。」 |
| **サンクコストの誤謬** |将来の価値ではなく、過去の投資のために継続 | 「私たちはこのプロジェクトに 1,000 万ドルを費やしました。もう止めることはできません。」 |
### 引数の評価
良い議論には次のようなものがあります。
1. **真の (または十分にサポートされた) 施設 **
2. **有効なロジック** (結論は前提から導き出されます)
3. **隠れた仮定はありません**
4. **関連性** (前提は実際に結論に取り組んでいます)

## 認識論: 私たちは何を知ることができるのでしょうか?
認識論は、知識そのもの、つまりそれが何であるか、どのようにしてそれを得るのか、そしてその限界は何なのかについての研究です。
### 知識の源
|出典 |説明 |制限 |
|----------|---------------|---------------|
| **認識** |直接的な感覚体験 |錯覚、幻覚、限られた範囲 |
| **理由** |論理的推論と数学的証明 |あなたの敷地から何が起こるかだけを伝えます |
| **内省** |自分自身の考えや感情を調べる |自己欺瞞。自分のプロセスへのアクセスが制限されている |
| **証言** |他の人があなたに言うこと |人は嘘をついたり、誤解したり、単純化しすぎたりする |
| **メモリ** |過去の経験を思い出す |信頼性が低い;再建的;時間の経過とともに劣化します。
| **科学的方法** |体系的な観察、仮説検証、再現 |遅い;テスト可能な質問に限定されます。パラダイム依存 |
### 重要な認識論的問題
|問題 |説明 |
|----------|---------------|
| **帰納法の問題** |過去に毎日太陽が昇ったからといって、*論理的に*、明日も太陽が昇るという保証はありません (ヒューム)
| **Gettier の問題** |正当化された真の信念は知識ではないかもしれない — 運次第で正しいこともある |
| **境界設定の問題** |科学と疑似科学の違いは何ですか? (ポッパー:反証可能性) |
| **決定不足** |証拠だけでは、どの理論が正しいかを一意に決定できるわけではありません。

## 認知バイアス
あなたの脳はショートカットをします。ほとんどの場合、それらはうまくいきます。そうでない場合、その結果は認知バイアスと呼ばれます。それらを知ることがそれらを回避するための第一歩です。
### 意思決定のバイアス
|バイアス |説明 |例 |
|------|-------------|----------|
| **確証バイアス** |既存の信念を裏付ける情報を求めています |自分に同意するニュースソースのみを読む |
| **アンカリング** |最初に出会った情報に過度に依存する |高すぎる初値からの交渉 |
| **可用性ヒューリスティック** |例が思い浮かびやすいかどうかで確率を判断する |飛行機事故のリスクは広く報道されているため、過大評価されている |
| **ダニング・クルーガー効果** |能力の低い人は自分の能力を過大評価します。専門家は自分たちの意見を過小評価している |専門家が難しいと感じる問題を自分は解決できると自信を持っている初心者 |
| **フレーミング効果** |選択肢がどのように提示されるかによって意思決定が変わります。 「生存率 90%」は「死亡率 10%」よりも良く聞こえます。
| **損失回避** |損失は​​、同等の利益が良いと感じるのと比べて、およそ 2 倍悪く感じられます。売却すると損失が「固定」されるため、損失を被った株式を保有する |
| **現状維持バイアス** |物事は変わらないことを好む |変更するのは労力なので、より良いプランに切り替えない |
### 社会的偏見
|バイアス |説明 |
|------|---------------|
| **ハロー効果** | 1 つのポジティブな特徴がその人の全体的な印象を決定づけます |
| **根本的な帰属エラー** |他人の行動は性格のせい、自分の行動は状況のせいだと考える |
| **グループ内バイアス** |自分のグループの一員であると認識している人を優遇する |
| **バンドワゴン効果** |他の多くの人が信念を持っているため、それを採用する |
| **公正世界の誤謬** |信じる人は当然のものを得る |
### 偏見を軽減する方法
1. **反対派の鉄人**: あなたが同意しない議論の最も強力なバージョンを構築します。
2. **反証の証拠を探す**: 自分が間違っている可能性がある理由を積極的に探します。
3. **基本料金を考慮してください**: この種の結果は一般的にどれくらい一般的ですか?
4. **チェックリストとフレームワークを使用する**: 思考を外部化し、盲点を見つけます。
5. **重要な決定については睡眠をとる**: 第一本能は偏ったものであることがよくあります。
6. **意見の相違を招く**: あなたが間違っているときに教えてくれる人々に囲まれてください。

## なぜこれが重要なのか
哲学と批判的思考は抽象的な練習ではありません。これらは実用的なツールです。
- **倫理フレームワーク**は、ビジネス、テクノロジー、私生活における現実のジレンマを乗り越えるのに役立ちます。
- **ロジック**は、政治、広告、ソーシャルメディアにおける悪い議論を見つけるのに役立ちます。
- **認知バイアス**は、賢い人が愚かな決断をする理由と、その決断を減らす方法を説明します。
- **認識論**は、誤った情報の時代にますます関連性を増しています。何が真実であるかをどうやって知ることができますか?
特定の哲学者に同意する必要はありません。必要なのは、自分が何を信じているのか、なぜそう信じているのかを明確に考えることができることだけです。
