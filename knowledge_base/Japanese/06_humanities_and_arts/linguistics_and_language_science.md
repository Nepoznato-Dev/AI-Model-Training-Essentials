# 言語学と言語科学
言語学は、言語、つまりその構造、意味、使用、獲得、進化についての科学的研究です。言語は人間のコミュニケーションをユニークなものにします。言語は無限に生産的であり (これまで聞いたことのない文章を作成して理解することができます)、文化的に伝わり (私たちは学習します。純粋に生得的なものではありません)、常に変化しています。言語の仕組みを理解することは、言語テクノロジーを構築したり、教育したり、翻訳したり、あるいは単により効果的にコミュニケーションを図ろうとしている人にとって重要です。

## 音声学と音韻論
### 国際音声アルファベット (IPA)
|カテゴリー |記号 |例 |
|----------|-----------|----------|
| **破裂音** | p、b、t、d、k、g | 「パット」、「コウモリ」、「ネコ」、「ゲット」 |
| **摩擦音** | f、v、θ、ð、s、z、ʃ、ʼ、h | 「太い」、「バット」、「薄い」、「それから」、「一口」、「zip」 |
| **鼻** | m、n、Å‹ | 「マット」、「ナット」、「歌う」 |
| **近似値** | l、r、w、j | 「レット」、「レッド」、「ウェット」、「まだ」 |
| **破擦音** | tʃ、dʼ | 「教会」、「裁判官」 |
### 主要な音韻概念
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **最小ペア** | 1 つの音素で異なる 2 つの単語が意味を変える | 「パット」対「バット」（p/b コントラスト） |
| **フォノタクティクス** |許可されるサウンドの組み合わせに関するルール |英語では単語の頭文字 /Å‹/ は許可されません。
| **ストレス** |特定の音節を強調する | 「記録」（名詞） vs 「記録」（動詞） |
| **イントネーション** |発話全体のピッチ パターン |上昇イントネーション = 英語の質問 |
| **同化** |音が近くの音に近くなる | 「ハンドバッグ」は「ハムバッグ」と発音されることが多い |

## 形態学
### 形態素の種類
|タイプ |説明 |例 |
|------|-------------|----------|
| **自由形態素** |単語として独立できる | "猫"; "走る"; 「幸せ」 |
| **結合形態素** |別の形態素に付加する必要があります | 「-s」（複数）; 「-ed」（過去形）; 「un-」（否定） |
| **派生** |新しい単語を作成します。品詞を変更する可能性があります | 「幸せ」→「幸福」（形容詞→名詞） |
| **屈折** |単語の文法形式を変更します。品詞は変わりません | 「歩く」→「歩いた」（現在→過去） |
### 単語の形成プロセス
|プロセス |説明 |例 |
|----------|---------------|----------|
| **配合** | 2 つの自由な形態素を結合する | 「ひまわり」。 「歯ブラシ」 |
| **導出** |接辞の追加 | 「教える」→「先生」 |
| **クリッピング** |単語を短縮する | 「研究室」→「研究室」 |
| **ブレンディング** | 2 つの単語の一部を結合する | 「煙」+「霧」=「スモッグ」 |
| **頭字語** |頭文字の使用 | NASA;レーザ;スキューバ |
| **借入** |他の言語から言葉を取り入れる | 「寿司」（日本語）; 「カフェ」（フランス語） |
| **貨幣** |新しい言葉を発明する | 「グーグル」（動詞）; 「クォーク」 |

## 構文
### フレーズ構造
|フレーズ |頭 |例 |
|----------|------|----------|
| **名詞フレーズ (NP)** |名詞 | 「大きな赤いボール」 |
| **動詞フレーズ (VP)** |動詞 | 「ケーキを早く食べました」 |
| **前置詞句 (PP)** |前置詞 | 「庭で」 |
| **形容詞句 (AP)** |形容詞 | 「結果にとても満足しています」 |
| **決定フレーズ (DP)** |決定者 | 「その」; 「私のお気に入り3つ」 |
### 構文の概念
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **選挙区** |単語を階層単位 (構成要素) にグループ化する | 「老人」は構成要素です。 「老人」はそうではありません |
| **再帰** |フレーズには同じタイプのフレーズを含めることができます。 「ネズミに噛まれた犬が追いかけた猫が逃げた」｜
| **曖昧さ** |複数の構造解釈を持つ文 | 「私は望遠鏡を持った男を見た」（誰が望遠鏡を持っていますか？）
| **動き** |要素は基本位置から移動できます | 「＿＿何を食べましたか？」 (オブジェクトの位置から移動したもの) |
| **同意** |単語は特徴 (数字、人物、性別) で一致する必要があります。 「彼女は走る」 (「彼女は走る」ではない) |

## セマンティクス
### 意味関係
|関係 |説明 |例 |
|----------|---------------|----------|
| **同義語** |同じまたは似た意味 | 「大きい」 ≈ 「大きい」 |
| **対義語** |反対の意味 | 「暑い」↔「寒い」 |
| **匿名** |特定→一般 | 「バラ」は「花」の下位語です |
| **ハイパーニム** |一般→特定 | 「フルーツ」は「リンゴ」の上位概念です。
| **メロニミー** |部分→全体 | 「ホイール」は「車」のメロニムです。
| **多義性** |複数の関連する意味を持つ 1 つの単語 | 「頭」（体の部分、リーダー、何かの頂上） |
| **同音異義語** |同じ形式。無関係な意味 | 「銀行」（川）。 「銀行」（金融機関）｜
### 構成意味論
|コンセプト |説明 |
|----------|---------------|
| **構成性の原則** |複雑な式の意味は、その部分とその組み合わせによって決まります。
| **テーマ別の役割** |エージェント (行為者);患者（影響を受けている）;器具（ツール）;ゴール;ソース;場所 |
| **含意** | A が真である場合、B も真である必要があります。「彼女が彼を殺害した」には「彼は死んだ」が含まれます。
| **前提** |背景の仮定: 「フランス国王はハゲである」は、フランス国王が存在することを前提としています。

## 語用論
### 主要な概念
|コンセプト |説明 |例 |
|----------|---------------|----------|
| **言論行為** |発話はアクションを実行します。要求する。有望な;謝罪する | 「謝罪します」 = 謝罪する行為 |
| **暗示** |暗示されているが明示されていない意味 | 「一部の生徒が合格した」ということは、「全員が合格したわけではない」ことを意味する |
| **グリスの格言** |品質（正直であること）。量（多すぎず、十分な情報を提供すること）。関係 (関連性があること);マナー（明確に） |格言に違反すると暗黙の結果が生じます。
| **ディクシス** |参照が文脈に依存する単語 | "ここ"; "今"; "これ"; 「彼女」 |
| **礼儀正しさ** |顔を脅かす行為は間接的であることで緩和される | 「もしかしたら...」 vs 「これをしてください」 |
| **共通の根拠** |講演者間で知識を共有 | 「通常の」は共有コンテキストでのみ機能します。

## 言語の習得
### 第一言語の習得
|ステージ |年齢 |特徴 |
|------|-----|------|
| **せせらぎ** | 6 ～ 12 か月 |反復音節：「バババ」。 「ダダダ」 |
| **一言 (ホロフラスティック)** | 12 ～ 18 か月 |単一の単語が全体のメッセージを伝えます。「ミルク！」 = "牛乳が欲しいです" |
| **2 単語** | 18 ～ 24 か月 |簡単な組み合わせ：「ミルクをもっと」。 「パパ行って」 |
| **電信** | 24 ～ 30 か月 |複数の単語が含まれていますが、機能単語がありません: 「クッキーが欲しい」 |
| **後の段階** | 3 ～ 5 年 |文法は発達します。過剰正則化 (「行った」);語彙爆発 |
### 主要な議論
|討論 |ポジション |
|----------|----------|
| **自然と育成** |チョムスキー: 生来の普遍文法。使用法ベース: 言語は一般的な認知能力とインプットから生まれます。
| **臨界期** |レンネバーグ氏: 言語は思春期までに獲得する必要があります。証拠: 野生の子供たち。 L2 後期学習者 |
| **モジュール性** |言語は別個のモジュールですか、それとも一般的な認識を使用しますか? |

＃＃ まとめ
言語学では、音声学 (音)、音韻論 (音声システム)、形態学 (単語の構造)、構文 (文の構造)、意味論 (意味)、および語用論 (文脈における意味) という複数のレベルで言語を研究します。言語は無限に生産的です。私たちは聞いたことのない文章を作成して理解することができます。単語は形態素から構築されます。階層的な句構造からの文。意味は構成的なものですが、文脈、含意、共有された知識にも依存します。言語習得は喃語から始まり、1語、2語の段階を経て進みますが、自然育成に関する議論はまだ解決されていません。世界の約 7,000 の言語は、人類の移住と文化の歴史を反映した言語族 (インド・ヨーロッパ語、中国・チベット語、ニジェール・コンゴ語) に属しています。言語テクノロジーに取り組む人にとって、これらの基本、つまり音がどのように意味にマッピングされるか、構文がどのように機能するか、コンテキストがどのように解釈を形成するかなどを理解することは、純粋な統計モデルでは置き換えることのできない重要な背景です。
