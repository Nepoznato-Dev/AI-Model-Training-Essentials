# 音楽理論と音響学
音楽理論は、音楽がどのように機能するか、つまりある音の組み合わせを心地よく、意味のあるものにし、その他の音を不調和または混沌にするパターン、構造、原理を研究するものです。音響学は音の物理学、つまり振動が空気中をどのように伝わるか、振動がどのように生成され知覚されるかということです。ハ長調のコードがなぜ幸せに聞こえるのか、短調がなぜ悲しく聞こえるのか、コンサート ホールがどのように設計されているのか、そしてなぜお気に入りの曲がゾクゾクするのかを一緒に説明します。
---

## 音の物理学
### サウンドの基本
|プロパティ |説明 |認識 |
|----------|---------------|----------|
| **周波数** | 1 秒あたりの振動数 (Hz) |ピッチ (周波数が高い = ピッチが高い) |
| **振幅** |振動の大きさ |ラウドネス (振幅が大きい = 大きい) |
| **波形** |振動の形状 |音色 (同じ音を弾くとピアノとギターが異なるように聞こえる理由) |
| **期間** |振動はどのくらい持続しますか |音符の長さ。リズム |
### 高調波シリーズ
|部分的 |周波数 (基本波に対する) |間隔 |知覚される品質 |
|----------|-------------------------------------|----------|--------|
| **第 1 回 (基本)** | f |ユニゾン |聞こえるピッチ |
| **2 番目** | 2階 |オクターブ |とても子音 |
| **3 位** | 3f |オクターブ + 5 度 |子音 |
| **4 位** | 4f | 2オクターブ |とても子音 |
| **5位** | 5f | 2 オクターブ + 長 3 度 |適度に子音 |
| **6位** | 6f | 2 オクターブ + 5 度 |子音 |
| **7位** | 7f | 2 オクターブ + 短 7 度 |不協和音 |
倍音列は、特定の間隔が子音に聞こえる理由、つまり倍音が重なって整列する理由を説明します。

## ハーモニーとコード
### トライアド
|コード |間隔 |キャラクター |例 (C から) |
|----------|-----------|----------||----------|
| **メジャー** |ルート + M3 + P5 |ハッピー;安定した | C-E-G |
| **マイナー** |ルート + m3 + P5 |悲しい;安定した | C-Eb-G |
| **減少** |ルート + m3 + d5 |時制;不安定 | C-Eb-Gb |
| **拡張** |ルート + M3 + A5 |神秘的です。不安定 | C-E-G# |
### セブンスコード
|コード |間隔 |キャラクター |一般的な使用法 |
|----------|-----------|---------------|---------------|
| **メジャーセブンス** |メジャートライアド + M7 |夢見心地。緑豊かな |ジャズ;ローファイ |
| **ドミナントセブンス** |メジャートライアド+m7 |ブルージー;解決したい |メジャーキーのVコード |
| **短7度** |マイナートライアド+m7 |スムーズ;リラックスした |ジャズ; R&B;ファンク |
| **ハーフディミニッシュ7度** |ディミニッシュトライアド+m7 |時制;曖昧 | ii 短調の和音。ジャズ |
| **ディミニッシュ 7th** |ディミニッシュトライアド + d7 |とても緊張しています。ドラマチック |コードを渡す;変調 |
### コード進行
|進行状況 |名前 |キャラクター |例の曲 |
|-----------|------|-----------|------|
| **I-IV-V-I** |標準ケイデンス |解決済み。クラシック | 「ツイスト・アンド・シャウト」; 「ラ・バンバ」 |
| **I-V-vi-IV** |ポップス進行 |気分を高揚させます。おなじみ |何千ものポップソング |
| **ii-V-I** |ジャズのリズム |スムーズ;洗練された |ジャズスタンダード |
| **I-vi-IV-V** | 50代の進歩 |懐かしい。ドゥーワップ | "私のそばにいて"; 「アースエンジェル」 |
| **vi-IV-I-V** |マイナーポップ |感情的;アンセミック |モダンなポップソング多数 |
| **I-IV-vi-V** |バリアント |わずかに異なる感情の弧 | 「あなたがいてもいなくても」 |
| **12小節ブルース** | I-I-I-I-IV-IV-I-I-V-IV-I-V |ブルーススタンダード |数え切れないほどのブルースやロックの曲 |

## リズムとメーター
### 拍子記号
|署名 |小節あたりの拍数 |音価 |感じる |例 |
|----------|--------------|---------------|------|---------|
| **4/4** (共通時間) | 4 |四分音符 |標準;ロック;ポップ |最も人気のある音楽 |
| **3/4** (ワルツタイム) | 3 |四分音符 |スイング;ダンス | 「青きドナウ」 |
| **6/8** | 6 | 8分音符 |化合物;軽快な | 「日出ずる家」 |
| **2/4** | 2 |四分音符 | 3月っぽい | 「星条旗は永遠に」 |
| **5/4** | 5 |四分音符 |奇数;不安になる | 「Take Five」 (デイブ・ブルーベック) |
| **7/8** | 7 | 8分音符 |奇数;複雑な | 「マネー」 (ピンク・フロイド) |
### リズミカルな概念
|コンセプト |説明 |
|----------|---------------|
| **テンポ** |ビートの速度 (BPM で測定 - 1 分あたりのビート数) |
| **シンコペーション** |オフビートのアクセント。リズミカルな緊張感を生み出す |
| **スイング** |ビートの不等分割（長短パターン） |
| **ポリリズム** | 2 つ以上の矛盾するリズムを同時に実行 (例: 3 対 4) |
| **グルーヴ** |リズミカルな勢いのフェルトセンス。 「ポケット」 |
| **ルバート** |表現力豊かなテンポの加速と減速 |

## 音響
### 室内音響
|プロパティ |説明 | |にとって重要
|----------|---------------|----------|
| **残響時間 (RT60)** |音が 60 dB 減衰するまでの時間 |コンサート ホール (1.5 ～ 2.5 秒)。レコーディングスタジオ (0.3-0.5秒) |
| **初期の反省** |直接音から50ms以内に届く音 |明瞭さ。親密さ |
| **定在波** |部屋の共鳴周波数 |低音の増強。特定の位置で null |
| **拡散** |複数の方向への音の散乱 |均一なサウンド配信 |
| **吸収** |音エネルギーを低減する材料 |エコーを低減します。残響をコントロールする |
| **フラッターエコー** |平行な表面間で急速に繰り返される反射 |望ましくない。拡散または吸収で固定 |

＃＃ まとめ
音楽理論は、音楽が機能するパターンを説明します。音は振動であり、周波数 (ピッチ)、振幅 (音量)、および波形 (音色) によって特徴付けられます。倍音列は、特定の間隔が子音に聞こえる理由を説明します。スケールは、音楽システムを定義する順序付けされた音符のシーケンスです。長音階は明るく聞こえます。短音階は暗く聞こえます。モードでは他の色も提供されます。コードは積み重ねられた音程から構築されます。メジャー トライアドは安定しています。ディミニッシュトライアドは緊張しています。セブンスコードは色と複雑さを加えます。コード進行は期待と決意を生み出します。リズムは、拍子、テンポ、シンコペーション、グルーヴによって時間を構成します。音楽形式は、2 部および 3 部からソナタ形式、詩コーラスまで、構造を提供します。音響学は、音が空間内でどのように作用するかを説明します。つまり、部屋の音が良いかどうかは、残響、反射、吸収、拡散によって決まります。これらの基本を理解することで、音楽の創作と鑑賞の両方が豊かになります。
