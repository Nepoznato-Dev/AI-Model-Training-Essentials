# 舞台芸術
演劇、映画、ダンス、音楽パフォーマンスなどの舞台芸術は、芸術が観客の生きた存在と出会う場所です。壁に描かれた絵や棚に置かれた本とは異なり、パフォーマンスはリアルタイムで展開され、アーティストと観客の間に共有の経験を生み出します。これは、何千年にもわたって人類文化の中心となってきました。
---

＃＃ 劇場
演劇は 2,500 年以上にわたり、人類の物語の舞台となってきました。古代ギリシャの円形劇場からブロードウェイやウエスト エンドに至るまで、ライブ パフォーマンスは依然として最も強力な芸術表現形式の 1 つです。
### ドラマティックなフォルム
|タイプ |説明 |注目すべき例 |
|------|---------------|------|
| **悲劇** |深刻なテーマ、主人公の転落 |ギリシャ悲劇、シェイクスピアの *ハムレット* |
| **コメディ** |ユーモラスな状況、ハッピーエンド |シェイクスピアの喜劇、オスカー ワイルド |
| **悲劇** |悲劇と喜劇の要素を融合 | *ゴドーを待ちながら* (ベケット)
| **ミュージカル劇場** |歌、ダンス、セリフを統合 | *ハミルトン*、*レ・ミゼラブル* |
| **オペラ** |完全歌唱ドラマティック作品 | *ラ・ボエーム* (プッチーニ)、*カルメン* (ビゼー) |
| **アバンギャルド** |非伝統的な形式、聴衆の参加 |実験劇場 |
| **メロドラマ** |誇張された登場人物、センセーショナルなプロット | 19 世紀の舞台メロドラマ |
| **茶番劇** |物理的なコメディ、不条理な状況 |フェイドー、*ノイズオフ* (フレン) |
### 主要な劇作家
|時代 |劇作家 |
|-----|-----------|
| **クラシック** |ソフォクレス、エウリピデス、アリストファネス |
| **エリザベス/ジャコビアン** |シェイクスピア、マーロウ、ジョンソン |
| **モダン** |イプセン、チェーホフ、ストリンドベリ |
| **20世紀** |アーサー・ミラー、テネシー・ウィリアムズ、サミュエル・ベケット、オーガスト・ウィルソン |
| **現代** |リン＝マヌエル・ミランダ、スーザン＝ロリ・パークス、トム・ストッパード |
### 世界中の演劇の伝統
|伝統 |由来 |特徴 |
|----------|----------|-----|
| **能** |日本 |仮面をかぶったパフォーマー、ゆっくりとした様式化された動き、精神的なテーマ |
| **歌舞伎** |日本 |精巧な衣装、ドラマチックなメイク、歴史的な物語 |
| **文楽** |日本 |人形遣いが見える人形劇 | 写真
| **北京オペラ** |中国 |歌、朗読、アクロバット、武道 |
| **カタカリ** |インド |メイクも衣装も凝ったダンスドラマ |
| **コメディア デラルテ** |イタリア |即興、ストックキャラクター、覆面パフォーマー |
| **京劇** |中国 |様式化された動き、象徴的なジェスチャー |

## 映画
映画は主要な芸術形式の中で最も新しく、誕生してからわずか 1 世紀を超えていますが、最も広く消費され、文化的に影響力を持っています。
### フィルムの動き
|動き |期間 |特徴 |主な作品 / 監督 |
|----------|----------|-----|----------|
| **ドイツ表現主義** | 1920年代 |歪んだビジュアル、心理的なテーマ | *ノスフェラトゥ* (ムルナウ)、*メトロポリス* (ラング) |
| **ソビエト モンタージュ** | 1920 年代 – 1930 年代 |意味としての編集、ショットの衝突 |エイゼンシュタインの *戦艦ポチョムキン* |
| **イタリアのネオリアリズム** | 1940 年代 – 1950 年代 |労働者階級の物語、ロケ撮影 | *自転車泥棒* (デ・シーカ) |
| **フレンチ ニュー ウェーブ** | 1950 年代 – 1960 年代 |革新的な編集、作家論 |トリュフォー・ゴダール | ゴダール
| **ニューハリウッド** | 1960 年代 – 1980 年代 |ディレクター主導の成熟したテーマ |コッポラ、スコセッシ、キューブリック |
| **新しいドイツ映画** | 1960 年代 – 1970 年代 |政治的、作家主導 |ファスビンダー、ヴェンダース、ヘルツォーク |
| **ドッグミー 95** | 1990年代 |ミニマリストのルール、自然光 |フォン・トリアー、ヴィンターベルク |
| **ニューウェーブの動き** | 2000年代～現在 |世界的な映画の多様化 |ノリウッド、韓国のニューウェーブ |
### 映画の主要なコンセプト
|コンセプト |説明 |
|----------|---------------|
| **ミザンセン** |フレーム内に配置されたすべて - セット、衣装、照明、俳優 |
| **モンタージュ** |ショットの並べ方で意味を生み出す編集技術 |
| **映画撮影** |カメラワークの芸術 — フレーミング、動き、照明、レンズの選択 |
| **作者理論** |認識できる個人的なスタイルを持つ、映画の「作者」としての監督 |
| **ジャンル** |映画のカテゴリ: ドラマ、コメディ、ホラー、SF、西部劇、ドキュメンタリーなど |
| **サウンドデザイン** |すべてのオーディオ要素: ダイアログ、音楽、効果音、沈黙 |
### 主要な映画産業
|業界 |国 |注目すべき点 |
|----------|-----------|---------------|
| **ハリウッド** |アメリカ |大ヒット作、スタジオ システム、世界的な展開 |
| **ボリウッド** |インド |音楽的な物語、大量の出力 |
| **ノリウッド** |ナイジェリア |迅速な制作、ビデオへのダイレクト |
| **カンヌ / ヨーロッパ** |フランス / ヨーロッパ |作家映画、映画祭 |
| **韓国映画** |韓国 |ジャンル混合、社会評論 |
| **アニメ** |日本 |アニメーション映画およびシリーズ |

＃＃ ダンス
ダンスは人間の動きの芸術であり、多くの場合 (常にではありませんが) 音楽に合わせて行われます。それは儀式、エンターテイメント、高度な芸術に及びます。
|フォーム |由来 |特徴 |
|-----|--------|----------------|
| **バレエ** |ルネッサンス イタリア / フランス |体系化されたテクニック、ポワントワーク、物語 |
| **コンテンポラリーダンス** | 20世紀アメリカ / ヨーロッパ |バレエの固さ、フロアワーク、即興演奏を拒否 |
| **タップ** |アメリカ (アフリカ系アメリカ人 + アイルランド人のルーツ) |パーカッションとしてのリズミカルなフットワーク |
| **フラメンコ** |スペイン (アンダルシア) |ギター、歌、パーカッシブなフットワーク、感情の激しさ |
| **ヒップホップ / ブレイクダンス** |アメリカ (ブロンクス、1970 年代) | Bボーイ、ポッピング、ロック、バトル |
| **インド古典舞踊** |インド |バラタナティヤム、カタック、オディッシー — ジェスチャーによるストーリーテリング |
| **ボールルーム** |ヨーロッパ |パートナーダンス: ワルツ、タンゴ、フォックストロット |
| **フォーク / トラディショナル** |世界中 |文化的な祭典、儀式、コミュニティ |
---

## なぜこれが重要なのか
舞台芸術は文化がリアルタイムに息づく場所です。演劇は、私たちを 2 時間他人の立場に置くことで共感を教えます。映画は私たちを歴史の目撃者にさせたり、想像の世界に連れて行ってくれたりします。ダンスは言葉では表現できないものを表現します。これらの芸術形式は共に、つながり、反映、変革のための人類の最も強力なツールの一部を表しています。
