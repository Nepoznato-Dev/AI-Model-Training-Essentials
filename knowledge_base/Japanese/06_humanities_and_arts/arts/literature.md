＃ 文学
文学は、人類の思考、感情、経験の最も永続的な記録です。古代文明の口承叙事詩から今日のデジタル時代の小説に至るまで、すべての作品は以前のものと対話しています。文学のジャンル、動き、技法を理解することで、読書やそれらの作品を生み出した文化を理解するためのより豊かなレンズが得られます。
---

## 文学のジャンルと形式
### フィクションのジャンル
|ジャンル |主な特徴 |注目すべき例 |
|------|-----------|------|
| **文学小説** |キャラクター主導、テーマの奥深さ、文体の巧みさ | *アラバマ物語* (ハーパー・リー) |
| **サイエンス フィクション** |投機的テクノロジー、空間、時間、平行世界 | *デューン* (ハーバート)、*1984* (オーウェル) |
| **ファンタジー** |魔法の世界、神話上の生き物 | *ロード・オブ・ザ・リング* (トールキン)、*ハリー・ポッター* (ローリング) |
| **ミステリー/探偵** |犯罪解決パズル、捜査 |シャーロック・ホームズ (ドイル)、ポアロ (クリスティ) |
| **ホラー** |恐怖、サスペンス、超常現象 | *シャイニング* (キング)、*ドラキュラ* (ストーカー) |
| **ロマンス** |恋愛関係、感情の旅 | *高慢と偏見* (オースティン) |
| **歴史小説** |特定の歴史的期間、正確な詳細 | *The Book Thief* (Zusak)、*Wolf Hall* (マンテル) |
| **マジカル リアリズム** |現実的な設定では魔法の要素が普通のものとして扱われる | *百年の孤独* (ガルシア マルケス) |
| **ディストピア** |抑圧的な社会、将来の傾向について警告 | *すばらしい新世界* (ハクスリー)、*侍女の物語* (アトウッド) |
| **風刺** |社会を批判するために使用されるユーモアと皮肉 | *ガリバー旅行記* (スウィフト)、*キャッチ 22* (ヘラー) |
### ノンフィクション形式
|フォーム |説明 |注目すべき例 |
|------|---------------|------|
| **伝記/自伝** |実在の人々のライフストーリー | *少女の日記* (アンネ フランク)、*Becoming* (ミシェル オバマ) |
| **回想録** |特定の経験やテーマに焦点を当てた個人アカウント | *教育を受けています* (タラ・ウェストオーバー) |
| **エッセイ** |特定の主題に関する短い散文 |ジェームズ・ボールドウィン、ジョーン・ディディオン、ジョージ・オーウェル |
| **ジャーナリズム** |ニュース報道、調査記事、特集記事 | *大統領の部下全員* (ウッドワード & バーンスタイン) |
| **セルフヘルプ** |自己啓発と実践的な改善 | *速くも遅くも考える* (カーネマン) |
| **哲学論文** |哲学的問いの体系的な探求 | *瞑想* (マルクス アウレリウス) |
| **トラベルライティング** |場所、文化、旅についての説明 | *パタゴニアにて* (Chatwin) |
### 詩の形式
|フォーム |構造 |例 |
|------|-----------|-----------|
| **ソネット** | 14 行、特定の押韻スキーム |シェイクスピアリアン (ABAB CDCD EFEF GG)、ペトラルチャン (ABBAABBA CDECDE) |
| **俳句** | 5-7-5 の音節パターン |日本の伝統、自然重視 |
| **リムリック** | 5 行、AABBA 韻、ユーモラス |光の詩 |
| **無料詩** |通常の拍子や韻はありません |ウォルト・ホイットマン、T.S.エリオット |
| **ヴィラネル** |繰り返されるリフレインを含む 19 行 | 「ドント・ゴー・ジェントル」（ディラン・トーマス） |
| **壮大な** |英雄的な行為についての長い物語 | *オデュッセイア* (ホーマー)、*ベーオウルフ* |
| **オード** |主題を取り上げた抒情詩 |キーツの「ギリシャの壺の頌歌」 |
| **エレジー** |死者のための追悼詩 | 写真「ああ、キャプテン！ 私のキャプテン！」 (ホイットマン) |
| **空白の詩** |韻のない弱強五歩格 |シェイクスピアの戯曲、ミルトンの *失楽園* |

## 主な文学運動
文学はそれぞれの時代を経て進化し、それぞれがそれ以前の時代に対抗してきました。
|期間 |時代 |主要なアイデア |主要人物 |
|----------|-----|----------|-----|
| **クラシック** | 8世紀紀元前 – 5世紀CE |理性、秩序、ヒューマニズム |ホメロス、ソフォクレス、ウェルギリウス |
| **中世** | 5世紀～15世紀|宗教的テーマ、騎士道、寓意 |ダンテ、チョーサー |
| **ルネッサンス** | 14世紀から17世紀。 |ヒューマニズム、古典学習の復活 |シェイクスピア、セルバンテス |
| **啓発** | 17世紀から18世紀。 |理性、科学、個人の権利 |ヴォルテール、スウィフト |
| **ロマン主義** | 18世紀後半から19世紀半ばまで。 |感情、自然、個人主義 |ワーズワース、ゲーテ、メアリー・シェリー |
| **リアリズム** | 19世紀半ば|日常生活の正確な描写 |トルストイ、ジョー​​ジ・エリオット、マーク・トウェイン |
| **自然主義** | 19世紀後半。 |決定論、科学的観察 |エミール・ゾラ、スティーヴン・クレーン |
| **モダニズム** | 19 世紀後半から 20 世紀半ばまで|実験的な形態、意識の流れ |ジョイス、ヴァージニア・ウルフ、T.S.エリオット |
| **ハーレム ルネッサンス** | 1920 年代 – 1930 年代 |アフリカ系アメリカ人の文化の開花 |ラングストン・ヒューズ、ゾラ・ニール・ハーストン |
| **ポストモダニズム** | 20世紀半ば– 現在 |断片化、メタフィクション、アイロニー |ピンチョン、ドン・デリーロ |
| **ポストコロニアル** | 20世紀半ば– 現在 |アイデンティティ、移住、文化的ハイブリッド性 |チヌア・アチェベ、サルマン・ラシュディ |
それぞれの運動は、部分的には反乱でした。ロマン主義は啓蒙合理主義を拒否した。モダニズムはビクトリア朝の慣習から脱却しました。ポストモダニズムは、壮大な物語という概念そのものに疑問を投げかけました。

## 文学デバイス
優れた文章を書くには、次のようなテクニックのツールキットが使用されます。
|デバイス |何をするのか |例 |
|----------|---------------|----------|
| **比喩** |直接比較 | 「すべての世界は舞台だ」 (シェイクスピア) |
| **直喩** | 「like」または「as」を使用した比較 | 「私の愛は赤い、赤いバラのようです」 (バーンズ) |
| **擬人化** |人間以外のものに人間の特質が与えられる | 「風が木々の間をささやきました」 |
| **皮肉** |期待と現実のコントラスト |状況的、劇的な、言葉による皮肉 |
| **象徴主義** |抽象的なアイデアを表すオブジェクト | *『華麗なるギャツビー』* の青信号 |
| **伏線** |今後のイベントに関するヒント | *マクベス*における魔女の予言 |
| **信頼できないナレーター** |信頼性が損なわれたナレーター | *ロリータ* (ナボコフ)、*ファイトクラブ* (パラニューク) |
| **意識の流れ** |思考の継続的な流れ | *ユリシーズ* (ジョイス)、*ダロウェイ夫人* (ウルフ)
| **暗示** |別の作品やイベントへの言及 |聖書と神話の参照 |
| **寓意** |隠された道徳的または政治的意味を持つ物語 | *動物農場* (オーウェル) |
| **並列** |対照的な要素を並べて配置する |光と闇、若者と年齢 |
| **モチーフ** |テーマ上の重要性を持つ繰り返しの要素 | T.J.博士の目*ギャツビー*のエクルバーグ |

## なぜこれが重要なのか
文学は単なる娯楽ではありません。社会が経験を処理し、仮定に疑問を投げかけ、代替案を想像する方法です。小説は世論を変えることができます。詩は時代を定義することができます。文学表現を形成した伝統、ジャンル、技術を理解することで、読み、書き、世界を理解するためのより豊かなレンズが得られます。
