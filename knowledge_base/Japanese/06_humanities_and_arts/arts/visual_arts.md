# ビジュアルアーツ
ビジュアル アートは、ラスコーの洞窟壁画から今日のデジタル インスタレーションに至るまで、人類最古のコミュニケーション形式です。芸術運動、媒体、創造的な作品を保存する機関を理解すると、何千年にもわたって社会が美、力、精神性、反対意見をどのように表現してきたかについて、より深く理解できるようになります。
---

## アートメディア
アーティストが使用する素材と手法が作品自体を形作ります。
|中 |説明 |注目すべき例 |
|----------|---------------|------|
| **油絵** |油中の顔料（亜麻仁、クルミ）。遅乾、ブレンド可能 |レンブラント、フェルメール |
| **アクリル** |速乾性合成ポリマー。多用途 |デビッド・ホックニー |
| **水彩** |水に懸濁した顔料。透明、明るい | J.M.W.ターナー |
| **フレスコ画** |濡れた石膏に顔料を塗る。耐久性のある、記念碑的な |ミケランジェロ (システィーナ礼拝堂) |
| **木炭 / 鉛筆** |描画用の乾燥メディア。表現範囲 |レオナルドのスケッチ |
| **インク** |流体媒体。カリグラフィー、精密 |東アジアの筆絵 | 写真
| **彫刻** |彫刻（石、木）、造形（粘土）、鋳物（ブロンズ） |ロダン、ブランクーシ |
| **版画制作** |エッチング、リソグラフィー、スクリーン印刷、木版画 |デューラー、北斎 |
| **写真** |光に敏感な表面。デジタルまたはフィルム |アンセル・アダムス、シンディ・シャーマン |
| **デジタル アート** |コンピューターによって生成または操作されたもの。 3D、生成を含む |ビープル、レフィク・アナドル |
| **インストール** |サイト固有の没入型環境 |クリストとジャンヌ＝クロード |
| **パフォーマンス アート** |媒体としての身体、時間、空間 |マリーナ・アブラモヴィッチ |

## 設計の原則
アーティストは次の原則を使用して視覚要素を整理します。
|原則 |説明 |
|----------|---------------|
| **バランス** |視覚的な重みの分布 (対称、非対称、放射状) |
| **コントラスト** |さまざまな要素を並べて視覚的な面白さを生み出す |
| **強調** |見る人の目を引き付ける焦点を作成する |
| **動き** |構図を通して視聴者の目を誘導する |
| **パターン/繰り返し** |要素を繰り返してリズムと統一感を生み出す |
| **比率 / スケール** |要素間のサイズ関係 |
| **団結 / 調和** |すべての要素がまとまった全体として連携します |

## なぜこれが重要なのか
ビジュアル アートは単なる装飾ではなく、人間の思考、信念、願望の記録です。すべての絵画、彫刻、インスタレーションは、それを生み出した文化を反映しています。芸術の動きを理解すると、広告、建築、映画、デザインなど、自分を取り囲む視覚言語を読み取ることができます。博物館やギャラリーは単なる古い物品の保管庫ではなく、人間であることが何を意味するかについての生きた会話の場です。
