# 心理学と人間の行動
心理学は、人々がどのように、そしてなぜそのように考え、感じ、行動するのかについての科学です。それは心を読むものではなく、常識でもありません。ただし、常識が示唆していることを裏付ける場合もあれば、完全に矛盾する場合もあります。心理学では、観察、仮説、テスト、修正という他の科学と同じ科学的手法が使用されます。この作品を困難にしているのは、その主題である人間の心というものが、私たちが知っている中で最も複雑な対象であるということです。
このファイルは、私たちがどのように考えるか、どのように成長するか、他者からどのように影響を受けるか、何がうまくいかないのか、そしてそれに対して何ができるのかなど、心理学の主要な領域をカバーしています。
---

## 心理学の仕組み — 主なアプローチ
心理学は単一の統一された理論ではありません。これは視点の集合であり、それぞれが行動のさまざまな側面を説明します。
|アプローチ |フォーカス |主要なアイデア |
|----------|----------|----------|
| **生物学的** |脳の構造、神経伝達物質、遺伝学 |行動は脳内の物理的プロセスによって引き起こされます。
| **認知** |思考、記憶、知覚、意思決定 |行動は情報をどのように処理するかによって形成されます。
| **行動** |観察可能な行動と学習 |行動は報酬、罰、連想を通じて学習されます。
| **精神力学** |無意識の衝動、初期の経験 |行動は無意識の葛藤に影響される (フロイトに由来) |
| **人道主義** |個人の成長、自己実現 |人には成長と充実感を求める生来の意欲があります。
| **社会文化** |環境と文化がどのように行動を形作るのか |行動は社会的文脈の外では理解できません。
現代の心理学者のほとんどは**折衷的**であり、質問に応じて複数のアプローチを利用します。

## 認知心理学 — 自分の考え方
あなたの脳はカメラではありません。現実を正確に記録して再生するわけではありません。不完全な感覚データ、過去の経験、期待、感情から世界の経験を構築します。この構造は通常は十分に優れていますが、予測可能な点で体系的な欠陥もあります。
＃＃＃ メモリ
メモリはファイルキャビネットではありません。それはむしろ再構築に似ています。何かを思い出すたびに、完璧なコピーを取得するのではなく、それを再構築することになります。
|ステージ |何が起こるのか |制限 |
|----------|---------------|---------------|
| **エンコーディング** |情報がシステムに入る |注意したものだけをエンコードします。
| **ストレージ** |情報は保持されます |思い出は時間の経過とともに変化します。詳細が失われるか追加される |
| **検索** |情報へのアクセス |検索の手がかりは重要です。コンテキスト依存メモリ |
**短期記憶**は、約 7 項目 (±2) を約 20 秒間保持します。 **作業記憶** は、情報を操作する能動的なシステムです。これは、あなたが今この文を理解するために使用しているものです。 **長期記憶**は本質的に無制限の容量を持っていますが、エンコードするには反復、感情的な意味、または深い処理が必要です。
主な調査結果:
- **間隔効果**: 分散練習 (時間をかけて勉強する) は、詰め込み学習よりもはるかに効果的です。
- **テスト効果**: 記憶から情報を取り出すことは、再読するよりも情報を強化します。
- **誤った情報の影響**: 誘導的な質問は記憶を変える可能性があります。エリザベス・ロフタスは、目撃者は決して起こらなかった出来事を「覚えている」可能性があることを実証しました。
- **フラッシュバルブの記憶**: 鮮明な感情的な記憶は永続的に感じられますが、それでも歪められる可能性があります。
### 認知バイアス
あなたの脳はショートカットをします。ほとんどの場合、これらのショートカットは機能します。そうしないと、結果として認知バイアスが生じます。これらは愚かな間違いではなく、人間の認識構造に組み込まれているものです。
|バイアス |何が起こるのか |現実世界への影響 |
|------|-------------|--------|
| **確証バイアス** |既存の信念を裏付ける情報を求める |政治的な二極化。不十分な科学的推論 |
| **アンカリング** |最初の情報に過度に依存する |給与交渉。価格判断 |
| **可用性ヒューリスティック** |例がどれだけ思い浮かびやすいかによって確率を判断する |飛行機の恐怖（劇的な恐怖） vs 運転の恐怖（統計的に危険） |
| **ダニング・クルーガー効果** |能力の低い人は自分のスキルを過大評価します。専門家は自分たちの意見を過小評価している |なじみのない領域に対する過信 |
| **損失回避** |損失は​​、同等の利益が良いと感じるのと比べて、約 2 倍悪く感じます。損失を被った投資を保有する。変化に抵抗する |
| **サンクコストの誤謬** |将来の価値ではなく過去の投資のために投資を続ける |悪い人間関係を続ける。悪い後に良いお金を投げる |
| **フレーミング効果** |選択肢がどのように提示されるかによって意思決定が変わります。 「生存率 90%」 vs. 「死亡率 10%」 |
| **後知恵バイアス** | 「ずっと分かっていた」―事後 |予測能力への過信 |

## 発達心理学 — 人はどのように成長するのか
人間は他の哺乳類に比べて非常に未発達な状態で生まれます。子馬は生後数時間以内に歩きます。人間の乳児は1年以上かかります。この開発期間の延長により、かなりの柔軟性と学習が可能になりますが、初期の経験が重要な意味を持つことも意味します。
### 主要な発達段階
|ステージ |年齢 |何が発展するのか |主要理論家 |
|------|-----|---------------|---------------|
| **センサーモーター** | 0～2歳 |物体の永続性（見えなくても存在するもの） |ピアジェ |
| **運用前** | 2～7年 |言語、象徴的思考。自己中心的（他人の視点が見えない） |ピアジェ |
| **具体的な運用** | 7～11歳 |具体的な出来事についての論理的思考。保全 |ピアジェ |
| **正式に運用中** | 11年以上 |抽象的思考、仮説推論 |ピアジェ |
| **信頼と不信** | 0～1歳 |世界は提供してくれるのか？ |エリクソン |
| **アイデンティティと役割の混同** | 12～18歳 |私は誰ですか？ |エリクソン |
### 自然と育成
自然が育む問い - 「それは遺伝学ですか、それとも環境ですか?」 — 解決されました。すべての場合において、それは両方であり、相互作用します。遺伝子はさまざまな可能性を設定します。環境によって、その範囲内で人がどの位置に該当するかが決まります。別々に育てられた一卵性双生児はかなりの類似性を示しますが（性格、知性、さらには好みに強い遺伝的影響があることを示唆しています）、それらは同一ではありません（環境も影響していることを示しています）。

## 社会心理学 — 他人があなたをどのように変えるか
あなたはグループの中で一人であるのと同じ人間ではありません。社会心理学では、現実または想像上の他者の存在が、人の考え方、感じ方、行動にどのような影響を与えるかを研究します。
### 古典的な実験
これらの実験により、人間の行動に関する不快な真実が明らかになりました。
|実験 |それが示したこと |なぜそれが重要なのか |
|----------|-----------------|--------------|
| **Asch 準拠** (1951) | 75% の人が少なくとも 1 回は間違ったグループの回答に同意しました |社会的圧力が個人の認識を覆す可能性がある |
| **ミルグラムの服従** (1961) |権威者の指示により、65% の人が致命的な電気ショックを与えた |普通の人が命令に従うと、重大な危害を引き起こす可能性があります。
| **スタンフォード刑務所** (1971) |数日以内に「看守」は虐待的になり、「囚人」は消極的になった。役割と状況が人格を上書きする可能性があります (現在、方法論は厳しく批判されています)。
| **傍観者効果** (ダーリーとラタネ、1968) |人は他の人がいると手助けする可能性が低くなります。責任の分散。証人が多ければ多いほど、誰かが行動する可能性は低くなります。
### 社会的影響力
|現象 |それは何ですか |例 |
|----------|-----------|----------|
| **適合性** |グループに合わせて動作を調整する |仲間と同じような服装をする。多数派に同意 |
| **従順** |権威ある人物の遵守 |たとえ疑わしい場合でも、上司の命令には従う |
| **グループシンク** |グループは批判的な評価よりも調和を優先します |誰も反対したくなかったため、間違った決定を下した |
| **ソーシャル手抜き** |グループで作業するときの労力を減らす |ほとんどの作業を 1 人で行うグループ プロジェクト |
| **根本的な帰属エラー** |他人の行動を性格のせいにし、自分の行動を状況のせいにする | 「彼らは怠け者だ」 vs. 「私は疲れていた」 |

## 個性 — あなたをあなたたらしめているもの
パーソナリティとは、状況や時間が経っても同じ人間であると認識できるようにする、思考、感情、行動の一貫したパターンです。
### ビッグ 5
最も科学的に裏付けられた性格モデルは、5 つの側面を特定します。誰もがそれぞれのスペクトルのどこかに当てはまります。
|特性 |ハイエンド |ローエンド |何を予測するのか |
|------|----------|-----------|------|
| **開放性** |好奇心旺盛、創造的、新しい経験にオープン |実用的でルーチンを好む |芸術的関心。政治的見解 |
| **誠実さ** |組織的、信頼できる、規律正しい |柔軟で自発的 |学業成績;健康行動。仕事のパフォーマンス |
| **外向性** |社交的、エネルギッシュ、刺激を求める |予約済み、反射型 |社会的関係。キャリアの選択 |
| **協調性** |協力的、信頼できる、思いやりのある |競争心、懐疑的 |人間関係の質。競合の解決 |
| **神経質主義** |感情的に反応する、不安になる、気分が不安定になる |感情的に安定し、回復力がある |精神的健康;人間関係の満足度 |
性格はおよそ 40 ～ 60% 遺伝し、30 歳以降は比較的安定しますが、固定されるわけではありません。一般に人は年齢を重ねるにつれて、より良心的で協調性が増し、神経質になることが少なくなります。

## メンタルヘルス — システムが故障したとき
精神的健康障害は性格上の欠陥や弱点ではありません。これらは、人々の考え方、感じ方、機能に影響を与える病状であり、多くの場合生物学的根拠があります。これらは非常に一般的であり、毎年、成人のおよそ 5 人に 1 人が精神的健康状態を経験しています。
### 主なカテゴリ
|カテゴリー |例 |コア機能 |治療 |
|----------|-----------|---------------|-----------|
| **不安障害** |全般性不安症、パニック障害、恐怖症、社交不安 |機能を妨げる過度の恐怖や心配 | CBT、投薬（SSRI）、曝露療法 |
| **気分障害** |うつ病、双極性障害 |持続的な感情状態 (悲しみや気分の変動) |薬物療法、心理療法、ライフスタイルの変更 |
| **精神障害** |統合失調症 |歪んだ思考、認識、そして現実 |抗精神病薬、治療、社会的支援 |
| **トラウマ関連** | PTSD |トラウマ後の再体験、回避、過覚醒 |トラウマに焦点を当てたCBT、EMDR、投薬 |
| **摂食障害** |拒食症、過食症、過食症 |乱れた食行動と身体イメージ |治療、栄養カウンセリング、投薬 |
| **パーソナリティ障害** |境界線、反社会的、ナルシスト |柔軟性に欠けたパターンが重大な問題を引き起こす |特殊な治療法（境界性パーソナリティ障害に対するDBT）、長期治療 |
### 治療に役立つもの
|アプローチ |仕組み |最適な用途 |
|----------|---------------|----------|
| **CBT (認知行動療法)** |歪んだ思考パターンを特定して変更する |不安、うつ病、恐怖症 — ほとんどの証拠に基づく |
| **精神力動療法** |無意識のパターンと初期の経験を探る |人間関係のパターン、繰り返される問題 |
| **薬** |脳の化学反応を変える (SSRI、気分安定剤、抗精神病薬) |中等度から重度の障害。治療と併用されることが多い |
| **ライフスタイルの変化** |運動、睡眠、栄養、社会的つながり |すべての条件。メンタルヘルスの基礎 |
| **マインドフルネス/瞑想** |注意力を訓練し、反応性を軽減します |不安、ストレス、うつ病の再発予防 |
ほとんどの症状に対して最も効果的な治療法は、運動、睡眠、社会的つながりなどのライフスタイル要因に加えて、治療法と（適切な場合）薬物療法を組み合わせることです。

## モチベーションと感情
### 行動を促すもの
- **内発的動機付け**: 本質的に満足できるから何かをすること (好奇心、習熟度、目的)。一般に、外発的動機付けよりも長期的な成果が高くなります。
- **外発的動機付け**: 外部の報酬 (お金、成績、賞賛) のために何かをすること。単純なタスクには効果的ですが、複雑なタスクや創造的なタスクでは実際に内発的動機が損なわれる可能性があります（「過剰正当化効果」）。
- **マズローの階層**: 生理的欲求 → 安全 → 帰属 → 自尊心 → 自己実現。高次の欲求よりも先に低次の欲求を満たさなければならないという考えは直感的ですが、研究によって強く裏付けられているわけではありません。極度の剥奪の中でも人は意味を追求します。
### 感情
感情は不合理なノイズではなく、特定の機能を果たす進化した反応です。恐怖はあなたを危険から逃げさせます。嫌悪感があると汚染を避けるようになります。怒りはあなたを脅威から守るよう促します。悲しみはサポートの必要性を示しています。
**闘争・逃走反応** (交感神経系の活性化) は、知覚された脅威に対する体の反応です。短期間では適応性がありますが、慢性的に活性化すると有害です。慢性的なストレスは、心臓病、うつ病、免疫機能不全、認知機能低下のリスクを高めます。

## 学習 — 行動がどのように変化するか
学習は教室で行われることだけではありません。すべての行動は経験によって形作られるのです。
### 3 種類の学習
|タイプ |メカニズム |主要研究者 |例 |
|------|-----------|---------------|----------|
| **古典的なコンディショニング** |刺激間の関連 |パブロフ (ベルに唾液を垂らす犬) | パブロフ過去のトラウマに関連する特定の音を聞くと不安を感じる |
| **オペラント条件付け** |結果によって形成される行動 |スキナー (餌を求めてレバーを押すネズミ) | スキナーボーナスのためにもっと一生懸命働く。お小遣いのために部屋を掃除する子供たち | 写真 小遣いのために部屋を掃除する子供たち
| **観察学習** |他人を見て学ぶ | Bandura (ボボ人形実験) |子供たちは親の真似をします。 YouTube からスキルを学ぶ |
**強化** (行動を増加させるもの) は、**罰** (行動を減少させるもの) よりも効果的です。最も効果的な強化スケジュールは可変的 (予測不可能) です。これが、スロット マシンが中毒性を持つ理由であり、ソーシャル メディアの通知が非常に魅力的な理由です。

＃＃ まとめ
心理学は、人間の精神が並外れた能力を持っていると同時に、体系的に欠陥があることを明らかにしています。私たちは言語を学び、複雑な問題を解決し、芸術を創造し、文明を築くことができますが、時には不利に働く偏見、社会的圧力、感情パターンにも弱いものです。心理学を理解することは、セラピストになることではありません。それは、なぜ自分が決断を下すのか、なぜ自分が感じていることを感じるのか、そして社会的および物理的環境が自分の行動をどのように形作るのかを理解することです。その理解は、人間関係、仕事、子育て、そしてしばしば不合理に見える世界を理解することなど、人生のあらゆる分野で役に立ちます。
