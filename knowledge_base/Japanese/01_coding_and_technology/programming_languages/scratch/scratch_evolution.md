## 主要なマイルストーン
### 原点 (2003–2006)
- **2003**: MIT メディア ラボの Lifelong Kindergarten グループが Scratch 開発を開始
- ミッチェル・レズニック率いる
- **目標**: ビジュアルブロックを通じて子供たちにプログラミングを教える
- インスピレーション源: ロゴ (シーモア パパート)、レゴ ロゴ、Squeak Etoys
- 名前: 「Scratch」 — DJ スクラッチ (メディアを混ぜ合わせる) から
### スクラッチ 1.0 (2007)
- **2007**: 初公開
- ドラッグアンドドロップブロックプログラミング
- スプライトベースのプロジェクト (キャラクター、アニメーション)
- サウンド、グラフィック、アニメーション
- Squeak (Smalltalk) を内蔵
- **対象**: 8 ～ 16 歳ですが、より幅広い年齢層に適用されます
### スクラッチ 1.4 (2009)
- グラフィックレンダリングの改善
- より多くのスプライト ライブラリ
- より良いサウンドサポート
- Squeak 上に構築された最後のバージョン
### スクラッチ 2.0 (2013)
- **完全な Web ベースのエディター** — ブラウザーで実行
- クラウド変数 — プロジェクト間でデータを共有する
- バックパック — プロジェクト間でスプライト/スクリプトを共有
- カスタムブロック（関数など）
- ActionScript 3 (Flash) を内蔵
- コミュニティ機能: リミックス、共有、コメント
### スクラッチ 3.0 (2019)
- **完全な書き直し** — HTML5/JavaScript (Flash なし)
- タブレット、携帯電話、Chromebook で動作します
- **拡張機能**:
  - ペン（描画）
  - ビデオセンシング（カメラ）
  - テキスト読み上げ
  - 翻訳（Google翻訳）
  - micro:bit (ハードウェア)
  - レゴ マインドストーム EV3
  - WeDo 2.0
- サウンドエディターの改善
- 新しいペイント エディター (ベクター + ビットマップ)
- バックパック、クラウド変数は保持
### Scratch デスクトップ以降 (2020–現在)
- **2020**: Scratch デスクトップ — オフライン エディター (Electron ベース)
- 拡張機能の開発を継続
- AI/ML 拡張機能 (コミュニティ作成)
- 物理コンピューティングとの統合 (micro:bit、Arduino)
## ブロック カテゴリの進化
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## 教えられるプログラミングの概念
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## 主要な設計原則
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## 影響と導入
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
