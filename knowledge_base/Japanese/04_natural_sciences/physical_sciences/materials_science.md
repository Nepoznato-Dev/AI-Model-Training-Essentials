# 材料科学
材料科学は、材料の構造 (原子、微視的、巨視的スケール) がその特性をどのように決定するか、また、加工方法を使用してその構造を制御して望ましい性能を達成する方法を研究するものです。これは、「なぜ鋼は強いのに重いのか?」といった質問に答える分野です。ガラスはなぜ透明なのに脆いのでしょうか?より速く充電できるバッテリーを作るにはどうすればよいでしょうか?火星の環境に耐えられる物質は何でしょうか?あなたがこれまでに使ってきたテクノロジーはすべて材料から作られており、テクノロジーの進歩にはほとんどの場合材料の進歩が必要です。
---

## 材料科学の四面体
フィールドを定義する 4 つの相互接続された要素:
|要素 |説明 |
|----------|---------------|
| **構造** |原子や分子の並び方（結晶構造、粒界、欠陥） |
| **プロパティ** |材料の挙動 (機械的、電気的、熱的、光学的、磁気的) |
| **処理中** |材料の作り方と形状（鋳造、焼結、ドーピング、アニーリング） |
| **パフォーマンス** |実際の用途で材料がどのように機能するのか |
重要な洞察: 処理を変更すると構造が変わり、それによって特性が変わり、パフォーマンスが変わります。

＃＃＃ 概要

|------|-------|------|-----------|

| **セラミックス** |イオン性/共有結合性 |難しい;脆い;耐熱性。絶縁 |アルミナ;炭化ケイ素。ガラス;磁器 |

## 結晶構造
### 一般的な金属結晶構造
|構造 |単位セルあたりの原子数 |パッキングフラクション |例 |
|----------|------|------|----------|
| **FCC** (面心立方体) | 4 | 0.74 (最密充填) |アルミニウム;銅;金;ニッケル;オーステナイト (γ-鉄) |
| **BCC** (体心立方体) | 2 | 0.68 |鉄（α鉄）；クロム;タングステン;モリブデン |
| **HCP** (六方最密充填) | 6 | 0.74 (最密充填) |チタン;亜鉛;マグネシウム;コバルト |
### 結晶構造が重要な理由
|プロパティ |結晶構造の影響 |
|----------|----------------------------|
| **強さ** |滑り系 (原子が滑る面) は構造によって異なります。 FCC 金属は HCP より延性が高い |
| **密度** |パッキング率は原子がどの程度密にパッキングされているかを決定します。
| **相変換** |鉄は 912°C で BCC から FCC に変化します。これが鋼の熱処理の基礎です。
| **異方性** |非立方晶系結晶では方向によって特性が変化する可能性があります。

## 機械的性質
### 主要な指標
|プロパティ |定義 |単位 |代表的な値 |
|----------|-----------|----------|-----|
| **ヤング率 (E)** |剛性;弾性領域における応力/ひずみ | GPa |スチール: 200;アルミニウム: 70;ゴム: 0.01–0.1 |
| **降伏強度** |永久（塑性）変形が始まる応力 | MPa |スチール: 250 ～ 1000。アルミニウム: 40–500 |
| **引張強さ (UTS)** |破壊前の最大応力 | MPa |スチール: 400 ～ 2000。アルミニウム: 90–600 |
| **延性 (%伸び)** |材料が破断する前にどのくらい伸びるか | % |スチール: 10–50;ガラス: <1 |
| **靭性** |破壊前に吸収されるエネルギー (応力-ひずみ曲線下の面積) | MJ/立方メートル |スチール: 高い。セラミックス: 低い |
| **硬度** |表面のへこみに対する耐性 |各種スケール |ダイヤモンド: 最も硬い。タルク: 最も柔らかい |
### 仕組みの強化
|メカニズム |仕組み |例 |
|----------|---------------|----------|
| **結晶粒の微細化** |粒子が小さい = 粒界が多い = 転位が移動しにくい |ホールとペッチの関係 |
| **固溶強化** |外来原子は格子を歪めます。転位の動きを妨げる |銅→真鍮に亜鉛を添加 |
| **析出硬化** |小さな粒子が転位の動きをブロック |時効硬化アルミニウム合金 |
| **加工硬化（ひずみ硬化）** |塑性変形により転位密度が増加します。それらはもつれ合い、お互いを妨げます。冷間圧延鋼 |
| **複合強化** |より柔らかいマトリックス内の強力な繊維が荷重を支えます。炭素繊維強化ポリマー |

## 電気的および熱的特性
### 導電率
|材料の種類 |導電率 (S/m) |メカニズム |
|--------------|---------|----------|
| **導体** (銅、銀) | 10^7 – 10^8 |金属結合の自由電子 | 金属結合における自由電子
| **半導体** (シリコン、GaAs) | 10^-6 – 10^4 |ドーピングにより調整可能。バンドギャップエンジニアリング |
| **絶縁体** (ガラス、ゴム) | 10^-12 – 10^-20 |バンドギャップが大きい。結合電子 |
| **超電導体** |無限 (臨界温度以下) |電気抵抗ゼロ。マイスナー効果 |
### 熱特性
|プロパティ |説明 | |にとって重要
|----------|---------------|----------|
| **熱伝導率** |熱が材料をどの程度よく流れるか |ヒートシンク;断熱材 |
| **熱膨張** |材料が加熱されるとどのくらい膨張するか |複合材料内の材料のマッチング。橋。レール |
| **比熱容量** |気温を1℃上げるのに必要なエネルギー |熱エネルギー貯蔵 |
| **融点** |固体が液体になる温度 |高温用途 |

## ポリマー
### ポリマーの種類
|タイプ |構造 |プロパティ |例 |
|------|-----------|-----------|----------|
| **熱可塑性プラスチック** |直鎖または分枝鎖。弱い分子間力 |加熱すると溶けます。リサイクル可能 |ポリエチレン;ポリスチレン;ナイロン |
| **熱硬化性樹脂** |クロスリンクネットワーク。鎖間の共有結合 |溶けないでください。高温で分解する |エポキシ;加硫ゴム;ベークライト |
| **エラストマー** |軽く架橋されています。コイル状チェーン |伸ばして形を戻す |天然ゴム;シリコーン;ネオプレン |
### ポリマーの特性
|プロパティ |説明 |
|----------|---------------|
| **ガラス転移温度 (Tg)** | Tg未満：硬くて脆い。 Tg 以上: 柔らかく柔軟 |
| **結晶度** |半結晶性ポリマーはより強く、より不透明です。アモルファスは透明です。
| **分子量** | MW が高い = より強力。処理が難しい |
| **重合度** |モノマー単位の数。プロパティに影響します |

＃＃ まとめ
材料科学は、材料の原子構造とその巨視的特性および現実世界の性能を結びつけます。金属は強くて導電性がありますが、重いです。セラミックは硬くて耐熱性がありますが、脆い性質があります。ポリマーは軽量で柔軟性がありますが、温度によって制限されます。複合材料は、さまざまなクラスの長所を組み合わせたものです。結晶構造は機械的挙動を決定します。熱処理、合金化、加工硬化などの加工により、微細構造、ひいては特性が制御されます。グラフェン、ペロブスカイト、MOF などの最新の素材は、可能性の限界を押し広げます。この分野は基本的に学際的です。物理学は結合を説明し、化学は反応を説明し、工学は性能を説明します。これらすべてがスマートフォンから宇宙船に至るあらゆるテクノロジーにとって重要です。
