# 物理学
物理学は、科学における最も基本的な質問、つまり物質とエネルギーはどのように振る舞うのかを問います。化学、生物学、工学など、その他すべては答えに基づいて構築されます。物理学は、素粒子スケール (量子力学) から宇宙スケール (一般相対性理論) にまで及び、その原理は他のすべての自然科学を支えています。
---

## 4 つの基本的な力
宇宙におけるあらゆる相互作用は 4 つの力に帰着します。足の下の地面、太陽の暖かさ、冷蔵庫の磁石など、あなたがこれまでに感じたことのあるものはすべて、これらが働いているのです。
|力 |相対強度 |範囲 |何をするのか |媒介粒子 |
|----------|--------|----------|---------------|--------|
| **強力な核** | 1(最強) |亜原子 (~10⁻¹5 m) |原子核内で陽子と中性子を一緒に保持します。グルーオン |
| **電磁** | ～1/137 |無限 |電気、磁気、光、化学を司る |フォトン |
| **弱い核** | ~10⁻⁶ |亜原子 (~10⁻¹⁸ m) |放射性崩壊の原因 | W ボソンと Z ボソン |
| **重力** | ~10⁻³⁹ (最弱) |無限 |大衆を引き寄せます。宇宙を形作る |グラビトン (仮説) |
重力は他のものに比べてばかげて弱いです - 小さな冷蔵庫の磁石が地球全体の重力を圧倒します。しかし、重力の範囲は無限であり、決して打ち消されることがないため、宇宙規模では重力が支配します。

## 古典力学
古典力学 (ニュートン力学) は、光速をはるかに下回る速度での巨視的な物体の運動を記述します。橋、自動車、発射体、軌道上の惑星など、日常のエンジニアリングには十分です。
### ニュートンの 3 つの法則
|法律 |声明 |意味 |
|-----|----------|---------------|
| **最初 (慣性)** |静止している物体は静止したままです。動いている物体は、正味の外力が作用しない限り、動き続けます。慣性基準系の概念を定義します |
| **2 番目 (F = ma)** |正味の力は質量と加速度の積に等しい |力が動きをどのように変化させるかを定量化します。
| **3 番目 (アクション-リアクション)** |あらゆる行動に対して、同等かつ反対の反応が存在します。力は常にペアで存在します。
### 主要な数量
|数量 |記号 |単位 |式 |
|----------|----------|------|----------|
| **速度** | v |メートル/秒 |変位 / 時間 |
| **加速** | | m/s² |速度 / 時間の変化 |
| **力** |ふ |ニュートン (N) | m×a |
| **勢い** | p | kg・m/s | m×v |
| **運動エネルギー** |ケ |ジュール (J) | 1/2mv² |
| **位置エネルギー** | PE |ジュール (J) | mgh (重力) |
| **仕事** | W |ジュール (J) | F × d × cos(θ) |
| **パワー** | P |ワット (W) | W / t |
運動量の保存とエネルギーの保存は、物理学における最も強力なツールの 1 つであり、衝突、爆発、軌道、およびほぼすべての機械的相互作用に適用されます。

## 熱力学
エネルギーを支配する 3 つの法則。これらは絶対的なものであり、既知のプロセスがそれらに違反することはありません。
### 3 つの法則
|法律 |声明 |結果 |
|-----|----------|---------------|
| **第一法則** |エネルギーは生成も破壊もできず、変換されるだけです。閉鎖系内の総エネルギーは一定です |
| **第二法則** |閉鎖系内のエントロピー (無秩序) は常に増加します。熱は熱い方から冷たい方へ流れます。効率が 100% のエンジンはありません。時間には方向がある |
| **第三法則** |絶対零度 (−273.15°C / 0 K) には到達できません |温度がゼロに近づくと、エントロピーは最小値に近づきます。
### 実際的な意味
- 熱が周囲に拡散するため、コーヒーは冷えます (第 2 法則)。
- 車のエンジンはガソリン エネルギーの約 25% を運動に変換します。残りは廃熱になります。
- 冷蔵庫とエアコンは熱を冷たいものから熱いものに移動させますが、そのためには外部からの作業が必要です (第 2 法則には違反しません)。
- これらの法律の下では永久機関は不可能です。

## 電気と磁気
電気と磁気は、同じ力、つまり電磁気の 2 つの側面です。電荷の移動により磁場が発生します。磁場を変化させると電流が発生します。この関係が現代テクノロジーのほとんどを支えています。
### 中心となる概念
|コンセプト |記号 |単位 |意味 |
|-------|-------|------|---------------|
| **電圧** | V |ボルト (V) |電荷を回路内に押し込む「圧力」 |
| **現在** |私 |アンペア (A) | 1 秒間に 1 点を通過する電荷の数 |
| **抵抗** | R |オーム (Ω) |材料が電流の流れをどの程度妨げるか |
| **パワー** | P |ワット (W) |エネルギー伝達率 (P = V × I) |
**オームの法則** (V = I × R) は回路解析の基礎です。 2 つの値がわかっている場合は、3 番目の値を計算できます。
**電磁誘導** - ファラデーによって発見された - は、発電所が電気を生成する方法です。コイル状のワイヤーの中で磁石を回すと電流が流れます。これは、蒸気 (石炭、原子力)、水 (水力発電)、または風力のいずれによって駆動されるかに関係なく、すべてのタービンが本質的に行うことです。
### マクスウェル方程式 (概念的)
ジェームズ・クラーク・マクスウェルは、電気と磁気を 4 つの方程式に統合しました。
|方程式 |内容 |
|----------|---------------|
| **ガウスの法則 (電気)** |電荷は電場を生成します。フィールドラインは電荷で始まり、電荷で終わります。
| **ガウスの法則 (磁気)** |磁気単極子は存在しません。磁力線は常に閉ループを形成します。
| **ファラデーの法則** |変化する磁場は電場を生成します (発電機の基礎) |
| **アンペール・マクスウェルの法則** |電流と変化する電界は磁界を生成します。
これらの方程式は電磁波を予測し、それは光であることが判明しました。マクスウェルは、可視光、電波、X線、マイクロ波は、異なる周波数ではすべて同じ現象であることを示しました。

## 相対性理論
アインシュタインの 2 つの相対性理論は、空間、時間、エネルギーに対する私たちの理解を根本的に変えました。
### 特殊相対性理論 (1905)
|原則 |説明 |
|----------|---------------|
| **光の速度は一定です** |光は、観測者の動きに関係なく、すべての参照フレームで約 300,000 km/s で伝わります。
| **時間の遅れ** |動いている時計は、静止している観測者に比べてゆっくりと時を刻みます。
| **長さの収縮** |動いているオブジェクトは動きの方向に短縮されます |
| **質量エネルギー等価** | E = mc² — 少量の質量には膨大な量のエネルギーが含まれています。
E = mc² は太陽が輝く理由 (核融合は質量のごく一部をエネルギーに変換する) であり、核兵器がどのように機能するのかを示します。
### 一般相対性理論 (1915)
一般相対性理論は特殊相対性理論を拡張して重力を含めます。質量は時空を湾曲させ、その湾曲は私たちが重力として経験するものです。主要な予測 - すべて確認されました:
- **重力レンズ**: 巨大な物体が周囲の光を曲げます。
- **重力時間の遅れ**: 重力場が強いと時計の時間が遅くなります (GPS 衛星がこれを補正する必要があります)
- **重力波**: 加速する巨大物体から生じる時空の波紋 (2015 年に LIGO によって初めて検出)
- **ブラックホール**: 時空の曲率が極端で、光さえも逃げることができない領域

## 量子力学
原子未満のスケールでは、ルールは完全に変わります。量子力学は科学全体の中で最も正確に検証された理論ですが、非常に直観に反しています。
### 基本原則
|原則 |説明 |
|----------|---------------|
| **波動粒子の二重性** |粒子 (電子、光子) は、測定方法に応じて波と粒子の両方として動作します。
| **重ね合わせ** |量子システムは、測定されるまで同時に複数の状態で存在できます。
| **不確定性原理** |粒子の正確な位置と正確な運動量の両方を同時に知ることはできません (ハイゼンベルク) |
| **絡み合い** | 2 つの粒子を相関付けることができるため、距離に関係なく、一方を測定するともう一方の状態が瞬時に判断できます。
| **量子化** |エネルギーは連続値ではなく、離散パケット (量子) で提供されます。
### なぜそれが重要なのか
- **半導体**: エレクトロニクス業界全体がシリコン内の電子の量子的挙動に依存しています。
- **レーザー**: 光子の誘導放出に基づいています (量子プロセス)
- **MRI 装置**: 量子現象である核磁気共鳴を使用します。
- **量子コンピューティング**: 重ね合わせともつれを利用して、特定の問題を古典的なコンピューターよりも指数関数的に高速に解決します。
- **化学**: 化学結合自体は量子現象です - 電子が分子軌道を占めています

＃＃ エネルギー
エネルギーには、運動（運動）、電位（貯蔵）、熱（熱）、化学、電気、核など、さまざまな形がありますが、常に 1 つのルールに従います。それは、生成したり破壊したりすることはできず、変換することだけです。これは熱力学の第一法則であり、絶対的なものです。
第 2 法則はそれほど陽気なものではありません。エネルギー変換のたびに、廃熱としてある程度のエネルギーが失われます。 100% 効率的なプロセスはありません。
|エネルギー源 |タイプ |効率 |キーの制限 |
|---------------|------|-----------|--------------|
| **石炭** |再生不可能 | ~33-40% | CO₂ 排出、大気汚染 |
| **天然ガス** |再生不可能 | ~40-60% (複合サイクル) |メタンが漏れ、依然として CO₂ を排出 |
| **核分裂** |非再生可能 (燃料限定) | ~33-37% |廃棄物保管、世論の反対 |
| **太陽光発電** |再生可能 | ~15-22% |断続的でストレージが必要 |
| **風** |再生可能 | ~35-45% |断続的、場所に依存 |
| **水力発電** |再生可能 | ~85-90% |地理的に限定された、生態系への影響 |
| **地熱** |再生可能 | ~10-23% |場所が限定されている (地殻変動ホットスポット) |

＃＃ まとめ
物理学はすべての自然科学の基礎です。 4 つの基本的な力が宇宙のあらゆる相互作用を支配します。古典力学は、運動と力の日常の世界を説明します。熱力学はエネルギー変換に絶対的な限界を設定します。電磁気は電気、磁気、光を統合します。相対性理論は、空間と時間が質量によって湾曲した単一の織物であることを明らかにします。量子力学は素粒子の世界を支配し、半導体から MRI 装置に至る現代技術を支えています。すべての物理学を統一するのは、数学的精度と実験的検証への取り組みです。すべての主張は測定に対してテストされ、すべての理論は暫定的なものです。
