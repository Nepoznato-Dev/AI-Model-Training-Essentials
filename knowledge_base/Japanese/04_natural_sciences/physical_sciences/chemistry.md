＃ 化学
物理学がゲームのルールだとすれば、化学はピースが相互作用するときに起こることです。化学は、原子がどのように結合し、分解し、再配置するか、つまりすべての物質がどのように動作するかを研究します。これは、基礎物理学と生物学、地質学、工学の複雑さとの間のギャップを橋渡しします。
---

## 原子構造
### 30 秒でわかるアトム
原子は、殻内の電子に囲まれた核（陽子 + 中性子）を持っています。陽子の数によって元素が定義されます (1 = 水素、6 = 炭素、79 = 金)。中性子の数によって同位体が決まります (炭素 12 と炭素 14)。電子の配置によって、原子が他の原子とどのように結合するかが決まります。
|粒子 |充電 |ミサ（アム） |場所 |
|----------|----------|----------|----------|
| **プロトン** | +1 | ~1 |核 |
| **中性子** | 0 | ~1 |核 |
| **電子** | −1 | ～1/1836 |電子殻 |
### 電子配置
電子は原子核の周りの殻（エネルギー準位）を占めています。各殻には最大数の電子が保持されます。
|シェル |最大電子数 |サブシェル |核からの距離 |
|------|--------------|-----------|----------------------|
| **1 (K)** | 2 | 1秒 |最も近い |
| **2 (L)** | 8 | 2秒、2p | |
| **3 (男)** | 18 | 3s、3p、3d | |
| **4 (N)** | 32 | 4s、4p、4d、4f |最も遠い (価数) |
最外殻（価電子殻）は化学的挙動を決定します。完全な原子価の殻を持つ原子 (希ガス) は不活性です。不完全なシェルを持つ原子は反応して安定性を達成します。

## 周期表
周期表はランダムなリストではなく、化学的挙動の地図です。同じ列 (グループ) の元素は、同じ数の価電子を持っているため、同様に動作します。
### キーグループ
|グループ |要素 |行動 |
|----------|----------|----------|
| **アルカリ金属** (グループ 1) |リ、ナ、カ... |非常に反応性が高く、電子を 1 つ失い、水中で爆発します。
| **アルカリ土類金属** (グループ 2) | Be、Mg、Ca... |反応性があり、電子を 2 つ失い、塩基性酸化物を形成します。
| **ハロゲン** (グループ 17) | F、Cl、Br、I... |非常に反応性が高く、電子を 1 つ獲得し、塩を形成します。
| **希ガス** (グループ 18) |彼、ね、あー... |ほぼ完全に不活性 - 完全な電子殻 |
| **遷移金属** (グループ 3 ～ 12) |鉄、銅、金... |さまざまな酸化状態、色の化合物を形成 |
| **ランタニド** (57-71) | CE、ND、EU... |希土類元素。磁石、レーザー、蛍光体に使用 |
| **アクチニド** (89-103) |ウ、プ、アム... |すべて放射性物質。原子力エネルギーに使用されるウランとプルトニウム |
### 定期的な傾向
|トレンド |期間をまたいで (→) |グループの下へ (↓) |
|------|---------------------|--------|
| **原子半径** |減少します (陽子が増えると電子がより強く引き寄せられます) |増加 (電子殻の増加) |
| **イオン化エネルギー** |増加（電子を除去しにくくなる） |減少（外側の電子が原子核から遠ざかる） |
| **電気陰性度** |増加 (共有電子のより強力な引力) |減少 |
| **メタリックキャラクター** |減少 |増加 |

## 化学結合
原子は結合して安定した電子配置を実現します。主なタイプは次の 3 つです。
### 結合タイプ
|結合タイプ |メカニズム |強さ |例 |
|----------|-----------|----------|----------|
| **イオン** |ある原子は電子を手放し、別の原子はそれを受け取ります。反対の電荷が引き寄せられます。 |強い | NaCl (食塩) |
| **共有結合** |原子は電子を共有します。 |イオンより強い | H₂O (水)、CO₂、DNA |
| **メタリック** |電子は原子間を自由に流れ、電荷の「海」を形成します。 |変数 | Fe、Cu、Au（全金属） |
### 分子間力
分子内の結合を超えて、分子間の力が融点、沸点、溶解度を決定します。
|力 |強さ |例 |
|----------|----------|----------|
| **水素結合** |強い（分子間力に対して） |水 (H₂O)、DNA 塩基対 |
| **双極子-双極子** |中程度 |塩酸、アセトン |
| **ロンドン分散** |弱い (しかし普遍的) |すべての分子;油のような非極性物質で優勢 |
水素結合は、このような小さな分子でありながら水の沸点が異常に高い理由、そして氷が浮く理由（水素結合が開いた結晶構造を形成する）の理由です。

## 化学反応
化学反応は、原子自体を変えることなく、原子を再配置し、古い結合を切断し、新しい結合を形成します。
### 反応の種類
|タイプ |パターン |例 |
|------|-------|-----------|
| **合成** | A + B → AB | 2H₂ + O₂ → 2H₂O |
| **分解** | AB → A + B | 2H₂O → 2H₂ + O₂ |
| **単一交換** | A + BC → AC + B | Zn + CuSO₄ → ZnSO₄ + Cu |
| **二重交換** | AB + CD → AD + CB | AgNO₃ + NaCl → AgCl + NaNO₃ |
| **燃焼** |燃料 + O₂ → CO₂ + H₂O | CH₄ + 2O₂ → CO₂ + 2H₂O |
| **レドックス** |種間の電子の移動 |錆びる: 4Fe + 3O₂ → 2Fe₂O₃ |
### バランス方程式
すべての化学方程式は、両側の各種類の原子の数が同じでなければなりません (質量保存)。係数 (分子の前にある数字) はバランスを保つために調整されます。分子内の添え字は決して調整されません。
### 反応率
|係数 |レートへの影響 |なぜ |
|------|------|-----|
| **温度** |増加 |分子はより速く移動し、よりエネルギー的に衝突します。
| **集中力** |増加 |体積あたりの分子が増えると、衝突も増える |
| **表面積** |増加 |より多くの露出粒子が反応可能 |
| **触媒** |増加 |活性化エネルギーを消費せずに低下させる |
| **圧力** (気体) |増加 |分子が強制的に接近する |

## 酸、塩基、および pH
pH スケールは 0 ～ 14 です。7 未満は酸性、7 を超えると塩基性 (アルカリ性)、7 が中性になります。
|物質 | pH |メモ |
|----------|-----|----------|
| **胃酸** | ~1.5 |金属を溶かすのに十分な強度 |
| **レモン汁** | ~2.0 |クエン酸 |
| **酢** | ~2.5 |酢酸 |
| **純水** | 7.0 |ニュートラル |
| **血液** | ～7.4 |厳しく規制されています。 ±0.5 の偏差は致命的となる可能性があります。
| **重曹溶液** | ～8.5 |マイルドベース |
| **漂白剤** | ~13 |強塩基（水酸化ナトリウム） |
整数の各ステップは酸性度の 10 倍の変化を表すため、pH 3 は pH 4 の 10 倍、pH 5 の 100 倍酸性になります。

## 有機化学
有機化学は炭素ベースの化合物の研究です。炭素は独特です。炭素は 4 つの安定した共有結合を形成し、長い鎖や環で結合することができ、既知のすべての生命の基礎となっています。
### 主要な官能基
|グループ |構造 |で見つかりました |
|------|-----------|----------|
| **ヒドロキシル** (−OH) |酸素＋水素 |アルコール類（エタノール、メタノール） |
| **カルボニル** (C=O) |酸素と二重結合した炭素 |アルデヒド、ケトン、糖 |
| **カルボキシル** (−COOH) |カルボニル + ヒドロキシル |有機酸（酢酸、アミノ酸） |
| **アミノ** (−NH₂) |窒素 + 2 つの水素 |アミノ酸、タンパク質 |
| **リン酸塩** (−PO₄) |リン + 4 つの酸素 | DNA、ATP (細胞エネルギー) |
| **メチル** (−CH₃) |炭素 + 3 つの水素 |遺伝子発現（メチル化）、脂肪 |
### 生命の高分子
|高分子 |ビルディングブロック |機能 |
|---------------|---------------|----------|
| **タンパク質** |アミノ酸（20種類）｜酵素、構造、シグナル伝達、輸送 |
| **炭水化物** |単糖類（グルコース） |エネルギー貯蔵、構造（セルロース） |
| **脂質** |脂肪酸 + グリセロール |細胞膜、長期エネルギー貯蔵、ホルモン |
| **核酸** |ヌクレオチド |情報ストレージ (DNA、RNA) |

## 物質の状態
|状態 |形状 |ボリューム |粒子の挙動 |
|----------|----------|----------|----------|
| **固体** |修正済み |修正済み |粒子はその場で振動します。強い絆 |
| **液体** |コンテナの形状をとる |修正済み |粒子は互いに滑りながら通り過ぎます。適度な債券 |
| **ガス** |コンテナに充填します |コンテナに充填します |粒子は自由に動きます。結合が弱い/結合がない |
| **プラズマ** |コンテナに充填します |コンテナに充填します |イオン化ガス;原子から剥ぎ取られた電子（星、稲妻） | 写真
相変化は特定の温度と圧力で発生します。融解、凍結、蒸発、凝縮、昇華 (固体→気体直接)、堆積 (気体→固体) です。

＃＃ まとめ
化学は、原子がどのように結合し、相互作用するかについての科学です。周期表は、電子配置によって決定される化学的挙動によって元素を整理します。原子はイオン結合 (電子の移動)、共有結合 (電子の共有)、または金属結合 (自由に流れる電子) で結合します。化学反応は質量を保存しながら原子を再配置し、その速度は温度、濃度、表面積、触媒によって異なります。酸と塩基は対数 pH スケールで測定されます。有機化学 (炭素化合物の研究) は、タンパク質、炭水化物、脂質、核酸という 4 つの高分子クラスを通じて生物学のすべてを支えています。化学を理解することは、生物学、医学、材料科学、環境科学、工学にとって不可欠です。
