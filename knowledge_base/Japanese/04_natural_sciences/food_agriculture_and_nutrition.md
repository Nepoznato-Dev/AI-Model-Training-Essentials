# 食料、農業、栄養
食糧は人間の最も基本的なニーズであり、農業は文明の基礎です。約1万年前の新石器革命による狩猟採集から農耕への移行により、人類は都市を建設し、文字を発展させ、その他「文明」と呼ばれるものすべてを創造することができた。現在、農業は世界の労働力の約 27% を雇用し、1 日あたり約 10 兆カロリーを生産しています。しかし、約8億​​人が依然として飢えに苦しんでおり、20億人以上が過体重または肥満です。問題は生産ではなく、配布、アクセス、選択肢です。

## 農業の仕組み
### 農業の種類
|タイプ |スケール |入力 |出力 |どこ |
|------|-------|----------|----------|------|
| **生存** |小規模（家族向け敷地） |手作業、簡単な工具 |家族を養うのに十分 |サハラ以南アフリカ、南アジアの一部 |
| **小規模農家** | 2ヘクタール未満 |一部の機械化、限られたインプット |ファミリー + ローカル マーケット |発展途上国のほとんど |
| **商用** |大規模 (数百ヘクタール) |重機械化、合成投入 |高利回りの販売 |米国、ヨーロッパ、ブラジル、オーストラリア |
| **産業/CAFO** |非常に大きい |最大投入量、閉じ込められた動物 |最大の生産量、ユニットあたりのコストの削減 |米国、中国、ブラジル |
| **オーガニック** |さまざま |合成肥料/農薬不使用 |利回りは低く、価格は割高 |世界中で成長 |
| **精度** |さまざま | GPS、センサー、データ分析 |投入物の最適化、無駄の削減 |先進国の先進農業 |
小規模農場（2 ヘクタール未満）は、農地の約 12% しか占めていないにもかかわらず、世界の食料の約 3 分の 1 を生産しています。これらは発展途上国の現地の食料安全保障にとって非常に重要です。
### 主要な主食作物
6 つの作物が人類のカロリーの大部分を供給します。
|作物 |カロリー/ヘクタール |主要な地域 |メモ |
|-----|-------------|---------------|----------|
| **米** | ~4,000-6,000 |アジア |世界の半分の定番品。大量の水を必要とする |
| **小麦** | ~3,000-5,000 |ヨーロッパ、北米、中国 |多用途。グルテンはパンに最適です |
| **トウモロコシ (トウモロコシ)** | ~5,000-8,000 |アメリカ、アフリカ、中国 |最高のカロリー収量。飼料、エタノール、甘味料にも使用される |
| **ジャガイモ** | ~8,000-12,000 |アンデス原産。グローバル |主要作物のヘクタール当たりのカロリー収量が最も高い |
| **キャッサバ** | ~5,000-10,000 |熱帯アフリカ、南アメリカ |干ばつに強い。適切に処理されない限り有毒です。
| **大豆** | ~2,000-3,000 |アメリカ大陸 (特にブラジル、米国) |主要なタンパク源。油も。土壌中の窒素を固定します |
### 畜産業
畜産は、最も資源を大量に消費し、環境に影響を与える人間活動の 1 つです。
- 家畜は農地 (放牧 + 飼料生産) の約 77% を占めていますが、世界のカロリーの約 18% しか提供しません。
- 牛肉の生産には約 28 倍の土地が必要で、タンパク質 1 グラムあたり豚肉の 5 倍、鶏肉の 11 倍の温室効果ガスを生成します。
- 乳製品、卵、鶏肉は牛肉や子羊肉よりもはるかに効率的です。
- 水産養殖（魚の養殖）は現在、天然漁業よりも多くの魚を供給しています。これは過去 20 年間の大きな変化です。

## 栄養 — あなたの体が実際に必要なもの
栄養科学は複雑です。その理由の 1 つは、それが本当に複雑であること、また 1 つは業界のマーケティングによって歪められているためです。実際に証拠が裏付けているものは次のとおりです。
### 主要栄養素
|主要栄養素 |エネルギー |主な役割 |良い情報源 |
|--------------|--------|---------------|--------------|
| **炭水化物** | 4kcal/g |一次エネルギー源。脳はブドウ糖で動く |全粒穀物、果物、野菜、豆類 |
| **タンパク質** | 4kcal/g |組織を構築して修復します。酵素;免疫機能 |肉、魚、卵、豆類、乳製品、大豆 |
| **脂肪** | 9kcal/g |細胞膜;ホルモンの生成。エネルギー貯蔵 |オリーブオイル、ナッツ、魚、アボカド。トランス脂肪を制限する |
**タンパク質**: 20 種類のアミノ酸すべてが必要ですが、体内でそのうち 11 種類を生成できます。 9つの「必須」アミノ酸は食物から摂取する必要があります。動物性タンパク質は「完全」です（9 つすべてが含まれています）。ほとんどの植物タンパク質は「不完全」ですが、さまざまな植物源（米 + 豆、フムス + ピタ）を組み合わせると、9 つすべてが得られます。
**脂肪**: すべての脂肪が同じというわけではありません。
- **不飽和** (オリーブオイル、魚、ナッツ): 一般に有益です。心臓病のリスクを軽減します。
- **飽和** (バター、赤身肉、ココナッツオイル): 議論の余地があります。現在のガイダンス: 適度な摂取。
- **トランス脂肪** (部分硬化油): 普遍的に有害です。ほとんどの国がそれらを禁止または制限しています。
### 微量栄養素 — 重要な小さなこと
|栄養素 |機能 |欠乏症 |ベストソース |
|----------|----------|----------------------|--------------|
| **ビタミンA** |視覚、免疫機能 |夜盲症、感染リスクの増加 |レバー、ニンジン、サツマイモ |
| **ビタミンC** |コラーゲン合成、抗酸化作用 |壊血病 |柑橘系の果物、ピーマン、ブロッコリー |
| **ビタミンD** |カルシウムの吸収、免疫機能 |くる病（小児）、骨軟化症 |日光、脂ののった魚、強化牛乳 |
| **鉄** |血液中の酸素輸送 |貧血（疲労、衰弱） |赤身肉、ほうれん草、レンズ豆 |
| **カルシウム** |骨構造、筋肉機能 |骨粗鬆症 |乳製品、葉物野菜、強化食品 |
| **亜鉛** |免疫機能、創傷治癒 |免疫力の低下、成長の遅れ |肉、貝類、豆類、種子 |
| **ヨウ素** |甲状腺ホルモンの生産 |甲状腺腫、認知障害 |ヨウ素添加塩、魚介類、乳製品 |
| **B12** |神経機能、赤血球形成 |貧血、神経損傷 |動物性食品のみ - ビーガンにはサプリメントが必要 |
### 証拠が実際に語っていること
数十年にわたる栄養学研究を通じて最も一貫した発見は次のとおりです。
1. **ほとんどが自然食品を食べる** - 野菜、果物、全粒穀物、豆類、ナッツ、および適度な量の脂肪分の少ないタンパク質。
2. **超加工食品を最小限に抑える** — 長い成分リスト、砂糖、工業用添加物が添加された製品は、一貫して肥満、心臓病、糖尿病と関連しています。
3. **カロリーは体重に関係します** — 食事の構成 (低炭水化物、低脂肪、地中海食) に関係なく、体重減少はエネルギー バランスによって決まります。しかし、食品の品質は空腹感、満腹感、そして長期的な健康に影響を与えます。
4. **完璧な食事は単一ではありません** — 地中海食、DASH 食、伝統的な日本食、および植物ベースの食事はすべて、強力な健康効果を示しています。最良のダイエットとは、継続できるものです。

## 食品の安全 — 食品を安全に食べられるようにする
食中毒は年間約 6 億人に影響を与えています (WHO)。主な危険性:
|危険の種類 |例 |予防 |
|---------------|----------|---------------|
| **生物学的** |サルモネラ菌、大腸菌、リステリア菌、ノロウイルス |適切な調理温度。冷凍;手洗い;相互汚染の回避 |
| **化学** |残留農薬、洗浄剤、アレルゲン |適切な保管;ラベリング;規制値 |
| **物理的** |ガラス、金属片、プラスチック |品質管理;処理中の金属探知機 |
**HACCP** (危険分析重要管理点) は、商業生産における食品の安全性の標準的な枠組みです。プロセス内で汚染が発生する可能性のあるポイントを特定し、それを防ぐための制御を確立します。
主要な温度ガイドライン:
- **危険ゾーン**: 4°C ～ 60°C (40°F ～ 140°F) — バクテリアが急速に増殖します。
- **以下の温度で冷蔵してください**: 4°C (40°F)
- **家禽を内部温度 74°C (165°F) まで調理します**
- **ひき肉を**まで調理します: 71°C (160°F)

## グローバルフードシステム — 全体像
世界の食料システムは、生産→加工→流通→消費→廃棄という連鎖になっています。各リンクには問題があります。
### 食品廃棄物
生産される食料の約 3 分の 1、13 億トンが毎年廃棄されています。
|ステージ |それが起こる場所 |主な原因 |
|------|---------------|---------------|
| **生産** |農場 |害虫、天候、市場価格が低すぎて収穫できない |
| **収穫後** |保管、輸送 |貧弱なインフラ（発展途上国） |
| **処理中** |工場 |トリミング、品質基準、腐敗 |
| **小売** |スーパーマーケット |過剰在庫、化粧品規格、使用期限 |
| **消費者** |世帯 |買いすぎ、日付の混乱、皿の無駄 |
裕福な国では、ほとんどの無駄は消費者レベルで発生します。発展途上国では、インフラが不十分なため、ほとんどの廃棄物は生産時と保管時に発生します。
### 代替タンパク質
持続可能なタンパク質源の探索が加速しています。
- **植物ベースの肉** (肉を超えて、インポッシブル フーズ): エンドウ豆タンパク質、大豆、または小麦グルテンを使用して、肉の食感と風味を模倣します。急速に成長していますが、市場におけるシェアはまだ小さいです。
- **培養 (研究室で栽培された) 肉**: バイオリアクターで培養された動物細胞。技術的には実現可能ですが、それでも高価です。規制当局の承認が始まっています。
- **昆虫タンパク質**: すでに世界中で約 20 億人が摂取しています。生産効率が高い（同じタンパク質を得るために、コオロギが必要とする飼料は牛の 6 分の 1）。西洋諸国における文化の壁。
- **発酵由来タンパク質**: 特定のタンパク質 (ヘム、カゼイン、卵白) を生産するように遺伝子操作された微生物。

## 持続可能な農業 — 長期的な農業
課題は、農業を可能にする土壌、水、気候を破壊することなく、100億人分の食料を生産することです。
|練習 |何をするのか |メリット |
|----------|---------------|----------|
| **輪作** |同じ畑で交互の作物 |害虫のサイクルを断ち切ります。土壌栄養素を改善します |
| **カバークロップ** |主要な季節の間に作物を植える |侵食を防ぎます。有機物を加える |
| **耕作量の削減** |土壌撹乱を最小限に抑える |水分を保持します。炭素を隔離します。土壌の生命を守る |
| **総合的な害虫管理** |化学薬品の前の生物学的管理 |農薬の使用を削減します。抵抗を遅くする |
| **アグロフォレストリー** |木 + 作物または家畜 |日陰、防風林、生物多様性、炭素貯蔵 |
| **精密農業** | GPS + センサー + データ |必要な場合にのみ入力を適用します。無駄を減らす |
| **再生型農業** |土壌の健康に焦点を当てる |大量の炭素を隔離できる。保水性を向上させる |
---

＃＃ まとめ
食品と農業は、生物学、経済学、文化、環境科学の交差点に位置します。 100億人に持続的に食料を供給するという課題は、間違いなく今世紀を決定づける問題です。良いニュースです。私たちは十分な食料を生産する方法を知っています。より困難な部分は、流通（食料を必要とする人々に届ける）、廃棄（損失の3分の1を阻止する）、そして移行（私たちが依存している資源を劣化させない農業慣行への移行）です。栄養面では、証拠は明らかです。ほとんどが自然食品、主に植物を食べ、あまり食べすぎないでください。そのアドバイスの単純さは、従うのが難しい食品システムの複雑さとは対照的です。
