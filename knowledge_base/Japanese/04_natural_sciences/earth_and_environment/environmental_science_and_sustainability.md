# 環境科学と持続可能性
環境科学は、物理学、化学、生物学、地質学、経済学の手法を「私たちの地球に何が起こっているのか、そしてそれに対して何ができるのか?」という問いに適用します。これは学際的な分野、つまり複数の専門分野が集まったものであり、分析の深さと政策の関連性の両方に貢献しています。
環境科学の中核となる緊張はこれです。人類の文明は環境から資源を抽出することに依存していますが、それらの資源を抽出すると、私たちが依存しているシステムを弱体化させる可能性のある方法で環境が変化します。一言で言えば、フィードバック ループがフィールド全体であることを理解します。
---

## 生態系 — 自然の経済がどのように機能するか
生態系は、生物とその物理的環境との間の関係のネットワークです。エネルギーは（主に太陽から）流入し、食物網を通過し、最終的には熱として排出されます。栄養素はシステム内を何度も循環します。
### エネルギーの流れ
**10% ルール** は重要な洞察です。食物連鎖の各段階で、エネルギーの約 90% が熱として失われます。これが、植物の数が草食動物よりもはるかに多く、草食動物の数が捕食動物よりもはるかに多い理由です。食物連鎖の下位で食べる方がエネルギー効率が高いのもこれが理由です。
```
Sunlight → Plants (producers) → Herbivores → Carnivores → Top predators
  100%          ~1%               ~0.1%      ~0.01%       ~0.001%
```

### 栄養サイクル
エネルギーとは異なり、物質はリサイクルされます。主要な生物地球化学サイクル:
|サイクル |主要なプロセス |なぜそれが重要なのか |
|------|---------------|----------------|
| **カーボン** |光合成 ↔ 呼吸 ↔ 分解 |大気中のCO₂を調整します。気候を推進する |
| **窒素** |細菌固定→硝化→脱窒 |タンパク質と DNA に必須。植物の成長を制限する |
| **水** |蒸発→凝縮→沈殿→流出 |淡水を配給します。天気を左右する |
| **リン** |岩石の風化→植物による取り込み→分解 |大気相はありません。多くの場合、生態系における制限栄養素です。
### 生物多様性と回復力
生物多様性は生態系の回復力に大きく貢献します。種が多い生態系は、ある種が失敗しても他の種がその役割を担うことができるため、撹乱に対してより耐性があります。これが、現在の絶滅の危機が非常に懸念される理由です。種は自然のバックグラウンド速度の数百倍の速度で消滅しています。科学者たちはこれを6度目の大量絶滅、つまり単一の種によって引き起こされた最初の大量絶滅と呼んでいます。
生物多様性に対する主な脅威を影響別にランク付け:
1. **生息地の破壊** — 森林破壊、都市化、農業
2. **気候変動** — 種が適応できるよりも早く気温と降水パターンが変化する
3. **過剰搾取** — 個体数が回復するよりも早く乱獲、狩猟、収穫が行われる
4. **汚染** — 化学物質、プラスチック、過剰な栄養素（窒素/リンの流出）
5. **侵入種** — 在来種と競合したり、在来種を捕食したりする外来生物

## 気候科学 — 全体像
気候と天気は同じものではありません。天気は今日何が起こるかです。気候は通常、数十年にわたって起こります。 7月の暑い日が気候変動を証明しないのと同様に、1月の寒波は気候変動を反証しません。
### 温室効果
温室効果は自然であり、必要なものです。温室効果がなければ、地球の平均気温は現在の +15°C ではなく、約 -18°C になるでしょう。問題は、人間の活動によってそれが激化していることです。
|温室効果ガス |一次情報源 |大気寿命 |相対温暖化係数 |
|---------------|---------------|----------------------------|---------------------------|
| **CO₂** |化石燃料、森林破壊 | 300～1,000年 | 1 (ベースライン) |
| **メタン (CH₄)** |農業、天然ガス漏洩、湿地 | ～12年 | ~28-36× CO₂ |
| **N₂O** |肥料、工業プロセス | ～114年 | ~265-298× CO₂ |
| **フッ素系ガス** |冷媒、工業用 |数百年から数千年 | CO₂の数千倍 |
CO₂ が最も注目されるのは、CO₂ が体積で最大の寄与物質であり、何世紀にもわたって残留するためです。しかし、メタンは分子あたりの効力がはるかに強いため、天然ガスの漏出をふさぎ、農業からの排出を管理することが非常に重要です。
### 人為的気候変動の証拠
- 世界の平均気温は産業革命前から最大1.1℃上昇
- 北極の海氷は1979年以来、夏の期間で最大40%減少した
- 1900 年以降、海面は約 20 cm 上昇しました (加速しています)
- 海洋のpHは産業革命以前に比べて0.1単位低下しました（酸性度が30％高くなりました）
- 同位体分析により、余分な CO₂ は天然源ではなく、化石燃料の燃焼に由来することが確認されました
### 緩和と適応
これらはどちらか一方ではなく、両方が必要です。
- **緩和**とは、再生可能エネルギー、効率、炭素価格設定、森林再生といった排出量の削減を意味します。
- **適応**とは、防潮堤、干ばつ耐性作物、洪水地帯からの管理された避難所、耐熱インフラなど、すでに固定化されている変化に適応することを意味します。

## 再生可能エネルギー — 移行を推進
このエネルギー転換はおそらく人類史上最大の工学プロジェクトです。目標は、経済を崩壊させたり、数十億人が電力を失ったりすることなく、化石燃料（200年間文明の原動力となってきた）をクリーンなエネルギー源に置き換えることです。
|出典 |仕組み |設備利用率 |主な課題 |
|--------|-------------|----------------|--------------|
| **太陽光発電** |光子がシリコンセル内で電子を解き放つ | 15-25% |間欠;夜は世代なし |
| **風** |タービンは移動する空気の運動エネルギーを変換します。 25-45% |間欠;視覚的/騒音に関する懸念 |
| **水力発電** |落ちてくる水がタービンを回す | 写真40-60% |地理的に限定されています。生態系の破壊 |
| **地熱** |地球内部からの熱を利用 | 70-90% |場所限定（火山地帯） |
| **核** |核分裂は水→蒸気→タービンを加熱します。 85-93% |コスト、無駄、世間の認識 |
断続的な問題（太陽光と風力が常に利用できるわけではない）には、バッテリー貯蔵（リチウムイオン、揚水水力）、系統相互接続（晴れた地域が曇りの地域に電力を送る）、デマンドレスポンス（供給が利用可能なときに使用をシフトする）、およびベースロード電源（原子力、地熱、水力）といった解決策が必要です。

## 汚染 — 私たちが空気、水、土壌に入れるもの
### 大気汚染
大気汚染により年間推定 700 万人が死亡しています (WHO)。主な犯人:
- **粒子状物質 (PM2.5 および PM10)**: 肺の奥深くまで浸透し、血流に入る小さな粒子。燃焼、工業、粉塵から。
- **オゾン (O₃)**: 太陽光中の窒素酸化物と揮発性有機化合物の反応により地上で形成されます。肺や作物にダメージを与えます。
- **NO₃ および SO₂**: 化石燃料の燃焼から。酸性雨、呼吸器疾患、水の酸性化を引き起こします。
### 水と土
- **栄養汚染**: 肥料の流出は藻類の発生を引き起こし、酸素を枯渇させ、湖や沿岸の海に「デッドゾーン」を生み出します。メキシコ湾のデッドゾーンはコネチカット州とほぼ同じ大きさだ。
- **プラスチック汚染**: 毎年約 800 万トンから 1,000 万トンのプラスチックが海に流入します。それはマイクロプラスチックに分解され、飲料水、食品、人間の血液に含まれています。
- **新たな汚染物質**: 医薬品、PFAS (「永遠の化学物質」)、およびマイクロプラスチックが世界中の水道に出現しています。治療技術は追いつくのに苦労しています。

## 水 — 私たちが代替できない資源
地球上の淡水はわずか 2.5% で、そのほとんどは氷の中に閉じ込められています。私たちが実際に利用できる淡水は、地球上の全水の 1% 未満です。
|セクター |世界の水使用量のシェア |
|----------|--------------------------|
| **農業** | ~70% |
| **業界** | ~20% |
| **国内** | ~10% |
水不足はすでに20億人以上に影響を与えています。この問題は、人口増加、気候変動（降水パターンの変化）、帯水層の過剰採取により悪化しています。膨大な量の農地を灌漑している米国グレートプレーンズのオガララ帯水層は、涵養するよりも早く枯渇しており、涵養するには何世紀もかかるだろう。
解決策には、点滴灌漑 (水の使用量を 30 ～ 60% 削減)、雨水の回収、廃水のリサイクル、淡水化 (エネルギー集約的だが改善)、水の真の価値での価格設定などが含まれます。

## 食品システムと持続可能性
世界中で生産される食料の約 3 分の 1、年間約 13 億トンが廃棄されています。一方、約8億人が慢性的な飢餓に直面している。これは製造上の問題ではありません。それは流通と廃棄物の問題です。
環境への影響を軽減する持続可能な農業実践:
- **輪作と多作栽培**: 害虫のサイクルを断ち切り、土壌の健康を改善し、肥料の必要性を削減します。
- **耕作量の削減**: 土壌構造を保存し、水分を保持し、炭素を隔離します。
- **統合害虫管理**: 化学殺虫剤の前に生物学的防除を使用します。
- **アグロフォレストリー**: 木と作物を組み合わせて、日陰、土壌保護、生物多様性を実現します。
- **精密農業**: GPS とセンサーのデータを利用して、必要な場所にのみ水、肥料、農薬を散布します。
- **再生型農業**: 土壌の健康を再構築することに焦点を当てます。大量の炭素を隔離できる

## 環境政策 — 社会はどのように対応するか
|同意/ポリシー |年 |何をするのか |
|---------------------|------|---------------|
| **モントリオール議定書** | 1987年 | CFCを段階的に廃止。オゾン層の修復 — 最も成功した環境条約と呼ばれることもある |
| **パリ協定** | 2015年 |各国は自主的な排出削減目標を設定します。温暖化を1.5～2℃に抑えるという目標 |
| **カーボンプライシング** |いろいろ |炭素税またはキャップアンドトレード制度。汚染を高価にする |
| **環境影響評価** |いろいろ |主要プロジェクトが承認される前に環境への影響の分析を義務付ける |
| **拡大された生産者責任** |いろいろ |メーカーに製品のライフサイクル全体に責任を持たせる |
科学的確実性が不完全な場合でも危害を防止するための予防原則には議論の余地がある。業界はイノベーションを抑制する可能性があると主張している。環境科学者らは、気候変動などの問題について確実性を待つことは、行動するには手遅れになるまで待つことを意味すると反論する。

＃＃ まとめ
環境科学は基本的にトレードオフに関するものです。あらゆる選択は、経済、生態系、将来の世代に影響を及ぼします。課題は、「環境」か「経済」のどちらかを選択することではなく、有限な惑星の物理的制限の中で繁栄できる文明を構築する方法を見つけ出すことです。良いニュースは、私たちはより良い選択をするための知識とテクノロジーを持っているということです。さらに難しいのは、実際にそれらを使用するかどうかを決定する政治、経済、人間の行動です。
