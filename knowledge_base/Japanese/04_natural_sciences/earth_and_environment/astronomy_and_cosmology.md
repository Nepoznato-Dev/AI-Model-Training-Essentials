# 天文学と宇宙論
天文学は、星、惑星、銀河、そして地球の大気圏外のすべてのものなどの天体に関する研究です。宇宙論は、宇宙全体、つまりその起源、構造、進化、そして最終的な運命についての研究です。これらは共に、人類がこれまでに抱いてきた最も基本的な質問のいくつかに対処します。宇宙はどのように始まったのでしょうか?どれくらいの大きさですか?私たちは一人ですか？結局それはどうなるのでしょうか？

### 宇宙距離ラダー

| **赤方偏移 (ハッブルの法則)** |宇宙論的距離 |後退速度は距離に比例します。膨張する宇宙 |

|ステージ |説明 |期間 |

| **プロトスター** |崩壊するコアは加熱します。水素はまだ核融合していない | ～10万年 |

## 宇宙論
### ビッグバン セオリー
|証拠 |説明 |
|----------|---------------|
| **宇宙マイクロ波背景放射 (CMB)** |ビッグバンの残光。 2.725K;全方向に均一。小さなゆらぎが播種された銀河 | 写真
| **ハッブル膨張** |銀河は私たちから遠ざかっています。遠ざかるほど速くなります - 空間自体が膨張しています |
| **軽元素の豊富さ** |ビッグバン元素合成は、観測された水素、ヘリウム、リチウムの比率を予測します。
| **大規模構造物** |銀河の分布は初期密度変動からの予測と一致する |
### 宇宙のタイムライン
|ビッグバン後の時間 |イベント |
|---------------------|------|
| **10^-43 秒** |プランク時代。すべての勢力が統一される。私たちが知っている物理学は壊れます。
| **10^-36 秒** |インフレが始まります。宇宙は指数関数的に膨張する |
| **10^-12 秒** |電弱対称性が破れます。ヒッグス場は粒子の質量を与える |
| **10^-6 秒** |クォークは結合して陽子と中性子になる |
| **3 分** |ビッグバン元素合成。最初の原子核 (H、He、Li) |
| **380,000 年** |組み換え;原子が形成されます。 CMB がリリースされました。宇宙が透明になる |
| **1 億～2 億年** |最初の星が点火する (人口 III の星) |
| **10 億年** |最初の銀河が形成される |
| **92億年** |太陽系の形 |
| **138 億年** |今 |
### ダークマターとダークエネルギー
|コンポーネント |割合 |証拠 |自然 |
|----------|----------|----------|----------|
| **普通の事** | ~5% |見える;光を放出/吸収する |よくわかる（原子・粒子） |
| **暗黒物質** | ~27% |銀河の回転曲線。重力レンズ。 CMB パターン |光と相互作用しません。重力によってのみ検出される |
| **暗黒エネルギー** | ~68% |宇宙の加速膨張（Ia型超新星） |未知;おそらく宇宙定数 (真空エネルギー) |

## 系外惑星と生命の探索
### 検出方法
|方法 |仕組み |強み |
|----------|---------------|----------|
| **交通機関** |惑星が星の前を通過します。星がわずかに暗くなります |最も生産的な方法 (Kepler、TESS)。大きさと公転周期を与える |
| **半径方向速度** |惑星の重力により星はぐらつきます。星の光のドップラーシフト | 写真質量を与えます。恒星に近い大質量惑星に有効 |
| **直接イメージング** |星の光を遮り、惑星を直接写真に撮る |星から遠く離れた大きな惑星でも機能します。
| **重力マイクロレンズ** |惑星の重力が背景の星からの光を曲げる | 写真遠く離れた惑星を検出します。珍しい出来事 |
| **天文測定** |星の正確な位置を測定します。ぐらつきを検出する |半径方向速度の相補 |
### ハビタブルゾーン
|係数 |要件 |
|----------|---------------|
| **星からの距離** |暑すぎない。寒すぎない。表面に液体の水が存在する可能性があります。
| **スタータイプ** |安定した;長命 (G、K、M のドワーフが好ましい) |
| **惑星の質量** |大気を保持するのに十分な重力。ガス巨人になるほど大きくない |
| **雰囲気** |表面温度を維持する温室効果。放射線からの保護 |
| **磁場** |恒星風をそらします。大気を保護します |

＃＃ まとめ
天文学と宇宙論は、惑星から宇宙全体に至るまであらゆるものを研究します。星は分子雲の中で生まれ、数十億年かけて水素を融合させ、白色矮星、中性子星、またはブラックホールとして終わります。渦巻銀河、楕円銀河、不規則銀河などは、宇宙の大規模構造の構成要素です。 CMB、ハッブル膨張、軽元素の存在量によって裏付けられたビッグバン理論は、138 億年前に始まり、約 5% の通常​​物質、約 27% の暗黒物質、約 68% の暗黒エネルギーで構成される宇宙を説明しています。系外惑星の発見により、惑星がありふれたものであることが示されており、居住可能な世界の探索が続けられています。最も重要な教訓は、私たちがどれだけわかっていないのかということです。暗黒物質と暗黒エネルギーは合わせて宇宙の 95% を構成しており、そのどちらが何であるのかはまだわかっていません。
