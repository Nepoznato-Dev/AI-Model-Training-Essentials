# 地球科学
地球科学は、私たちが住む惑星、つまりその構造、プロセス、歴史、そしてそれを居住可能にするシステムを研究します。これは、地質学 (固体の地球)、海洋学 (海洋)、気象学 (大気と天気)、および気候学 (長期的な気候パターン) に及びます。これらの分野を統合するのは、地球が動的なシステムであるという理解です。地球の内部は常に動き、表面は再形成され、大気と海洋は複雑な方法で相互作用します。
---

## 地球の内部構造
惑星はタマネギのように層になっています。各層は、温度、圧力、組成によって決まる異なる特性を持っています。
|レイヤー |深さ |構成 |状態 |主な機能 |
|----------|----------|---------------|----------|---------------|
| **クラスト** | 0-70km |ケイ酸塩岩 | ケイ酸塩岩ソリッド (剛性プレート) |海洋地殻 (薄い、緻密、玄武岩) vs 大陸地殻 (厚い、軽い、花崗岩) |
| **上部マントル** | 70～410km |かんらん岩 |半固体（ゆっくり流れる） |アセノスフェアが含まれています - 層プレートが滑空します。
| **下部マントル** | 410～2,900km |より高密度のケイ酸塩 |圧力下で固体 |対流がプレートの動きを駆動します |
| **外核** | 2,900～5,150km |鉄+ニッケル |液体 |対流を通じて地球の磁場を生成 |
| **内部コア** | 5,150～6,371 km |鉄+ニッケル |固体（極圧） |月の大きさについて。温度 ~5,400°C (太陽の表面と同様) |
### 磁場
地球の磁場は、外核内の液体鉄の運動 (地球ダイナモ) によって生成されます。宇宙まで数万キロメートルにわたって広がり、太陽からの荷電粒子の流れである太陽風から地球を守っています。それがなければ、太陽風によって大気は徐々に剥ぎ取られてしまうだろう（おそらく火星に起こったのと同じだろう）。
磁極は固定されておらず、ほぼ 20 万年から 30 万年ごとに移動し、時には完全に反転します (地磁気逆転)。最後の逆転は約78万年前でした。

## プレートテクトニクス
プレートテクトニクスは地質学の統一理論です。地球の地殻は約 15 枚の主要な構造プレートに分かれており、それらはその下を流れるマントルの上を年間数センチメートル漂流しています。
### プレート境界の種類
|境界タイプ |プレート |何が起こるのか |例 |
|--------------|--------|---------------|----------|
| **収束** |一緒に移動する |衝突 → 山脈 (大陸と大陸) または沈み込み → 火山と海溝 (海洋と大陸) |ヒマラヤ (インド - ユーラシア);アンデス山脈 (ナスカ-南アメリカ) |
| **発散** |別居 |マグマが上昇 → 新しい地殻が形成される。地溝帯または中央海嶺 |大西洋中央海嶺。東アフリカ地溝帯。アイスランド |
| **変換** |すれ違い | 写真 すれ違い断層に沿った地震。新しい地殻は作成されません |サンアンドレアス断層 (カリフォルニア州) |
### プレートテクトニクスの証拠
|証拠 |説明 |
|----------|---------------|
| **コンチネンタル フィット** |南アメリカとアフリカはパズルのピースのように組み合わされています |
| **化石の分布** |同じ化石が現在は海で隔てられた大陸で発見される |
| **ロックマッチング** |山脈と岩層は海を越えて一致します |
| **古地磁気** |海底の磁気ストライプは極性の反転を記録し、海底の広がりを示す |
| **地震パターン** |プレート境界に沿って地震が群発する |
| **ホットスポット チェーン** |火山列島 (ハワイ) は静止マントルプルーム上のプレートの動きを記録 |
### ロックサイクル
岩石は次の 3 つのタイプの間で常に変化しています。
|岩の種類 |どのように形成されるのか |例 |
|----------|---------------|----------|
| **火成岩** |マグマや溶岩の冷却 |花崗岩（地下でゆっくりと冷却）。玄武岩 (表面の急速冷却) |
| **堆積物** |堆積物（砂、泥、貝殻）の圧縮 |砂岩;石灰岩。頁岩 |
| **変態** |熱と圧力によって変形した既存の岩石 |大理石（石灰岩製）。スレート（頁岩由来） |
十分な時間と適切な条件があれば、どんな種類の岩石でも他の種類に変化する可能性があります。火成岩は風化して堆積物→圧縮されて堆積岩→埋もれて加熱→変成岩→溶けて再び火成岩になります。

## 雰囲気
地球の大気は、重力によって保持されるガスの薄い層です。温度パターンに基づいて層に分割されます。
### 大気層
|レイヤー |高度 |気温の傾向 |主な機能 |
|----------|----------|----------|---------------|
| **対流圏** | 0～12km |高度とともに減少します |天気が起こる場所。大気質量の約 75% を含む |
| **成層圏** | 12～50km |高度とともに増加 |オゾン層を含む（紫外線を吸収） |
| **中間圏** | 50～85km |高度とともに減少します |流星はここで燃え上がる |
| **熱圏** | 85～600km |高度とともに増加 |オーロラ。国際宇宙ステーションはここを周回します |
| **外気圏** | 600～10,000km |徐々に宇宙に消えていきます |宇宙への移行 |
### 大気組成
|ガス |パーセンテージ |役割 |
|-----|----------|------|
| **窒素 (N₂)** | 78.08% |酸素を薄めます。タンパク質に必須（細菌によって固定される） |
| **酸素 (O₂)** | 20.95% |呼吸;燃焼;光合成によって生成される |
| **アルゴン (Ar)** | 0.93% |不活性;産業用（溶接、電球） |
| **CO₂** | ~0.04% (420 ppm) |温室効果ガス;光合成;化石燃料による上昇 |
| **水蒸気** | 0-4% (可変) |温室効果ガス;天気と雲を動かす |

## 天気と気候
天気は短期的な大気状態です。気候は長期平均です。両方の主な要因は、太陽による地表の不均一な加熱です。赤道は極よりも多くのエネルギーを受け取り、大気と海洋はその熱を再分配するように機能します。
### 気象システム
|現象 |どのように形成されるのか |
|-----------|---------------|
| **風** |空気は高圧から低圧へと移動します。コリオリ効果がその軌道を曲げる |
| **雨** |暖かい空気が上昇→冷却→水蒸気が凝結→水滴が落下 |
| **ハリケーン** |暖かい海水 (>26°C) + 低圧 + コリオリ → 回転嵐システム |
| **竜巻** |ウィンドシアーを伴う激しい雷雨→回転メソサイクロン→漏斗雲 |
| **フロント** |暖気団と寒気団の境界→雲、降水 |
### 海流
海洋は、表層流と深層流のシステムを通じて地球の周囲に熱を分配します。
|現在 |タイプ |効果 |
|----------|------|----------|
| **メキシコ湾流** |表面（暖かい） |メキシコ湾からヨーロッパまで温水を運びます。ヨーロッパの気候を和らげる |
| **熱塩循環** |ディープ (グローバル「コンベア ベルト」) |温度と塩分濃度の違いによって引き起こされます。完全なサイクルには約 1,000 年かかります。
| **エルニーニョ / ラニーニャ** |地表 (太平洋) |太平洋赤道域の周期的な温暖化/寒冷化。地球規模の気象パターンに影響を与える |
| **湧昇** |ディープ→サーフェス |栄養豊富な水を表面にもたらします。主要な漁業をサポート |

## 地質時代
地球の年齢は約45億4000万年です。地質学的時間の広大さを理解するのは困難です。地球の歴史を 1 日 24 時間に圧縮すると:
|時間 |イベント |
|------|------|
| **00:00** |地球の形 |
| **04:00** |生命の最古の証拠 (ストロマトライト) |
| **20:00** |最初の多細胞生物 |
| **21:00** |カンブリア爆発 — 複雑な生命の急速な多様化 |
| **22:30** |最初の陸上植物 |
| **23:00** |恐竜の時代が始まる |
| **23:40** |小惑星の衝突で恐竜が死亡 |
| **23:55** |最初のヒト科 |
| **23:59:56** |現生人類登場 |
| **23:59:59** |記録された歴史が始まる |
### 大規模な絶滅事件
|イベント |いつ |重大度 |原因 |
|------|------|----------|------|
| **オルドビス紀・シルル紀** | ～4億4500万年前 | ~85% の種が失われた |氷河作用、海面低下 |
| **デボン紀後期** | ～3億7500万年前 | ~75% |気候変動、海洋貧酸素 |
| **ペルム紀～三畳紀 (「偉大なる瀕死」)** | ～2億5,200万年前 | ~96% |大規模な火山活動、気候崩壊 |
| **三畳紀～ジュラ紀** | ～2億100万年前 | ~80% |火山活動、気候変動 |
| **白亜紀～古第三紀** | ～6,600万年前 | ~76% |小惑星衝突 (Chicxulub);火山活動 |

＃＃ まとめ
地球科学は、惑星が絶えず運動していることを明らかにしました。内部は層状になっており、固体の内核、磁場を生成する液体の外核、対流するマントル、そして構造プレートに壊れた薄い硬い地殻です。プレートテクトニクスは地表を形成します。プレートが衝突する場所では山が隆起し、プレートが分岐する場所では海が広がり、プレートが互いに滑り合う場所では地震が発生します。大気（主に窒素と酸素）は生命を放射線から守り、気象システムや海流を通じて熱を分配します。気候は長期的なパターンであり、太陽エネルギー、温室効果ガス、海洋循環によって引き起こされます。地球の 45 億 4000 万年の歴史には 5 回の大量絶滅が含まれており、そのうちの最新の絶滅は哺乳類、そして最終的には人類が支配する道を開いたものです。地球をシステムとして理解することは、21 世紀の環境問題に対処するために不可欠です。
