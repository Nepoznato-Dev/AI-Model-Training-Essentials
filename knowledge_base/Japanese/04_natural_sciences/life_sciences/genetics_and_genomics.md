# 遺伝学とゲノミクス
遺伝学は遺伝、つまり DNA を通じて形質が親から子にどのように受け継がれるのかを研究するものです。ゲノミクスは、ゲノム全体、つまりすべての遺伝子、非コード領域、それらがどのように相互作用するか、そしてそれらが個人や集団間でどのように変化するかを研究することです。遺伝学からゲノミクスへの移行は、配列決定技術によって推進されました。私たちは、一度に 1 つの遺伝子を研究することから、数時間でゲノム全体を読み取るようになり、医学、農業、法医学、そして進化の理解を変えるデータを生成しました。

## DNA の基礎
### DNA 構造
|コンポーネント |説明 |
|----------|---------------|
| **ヌクレオチド** | DNAの構成要素。糖（デオキシリボース）、リン酸基、窒素含有塩基から構成されます。
| **ベース** |アデニン (A)、チミン (T)、グアニン (G)、シトシン (C) |
| **塩基ペアリング** | A は T とペアになります (2 つの水素結合)。 G と C のペア (3 つの水素結合) |
| **二重らせん** | 2 本の鎖は逆平行に走っています (5' から 3' および 3' から 5')。らせん状にねじれた | 写真
| **染色体** |単一の長い DNA 分子がヒストンタンパク質の周りに巻き付いています。人間は 46 (23 ペア) を持っています。
| **ゲノム** |生物内の DNA の完全なセット。ヒトゲノムは約 32 億塩基対です。
### 分子生物学のセントラルドグマ
|ステップ |プロセス |場所 |製品 |
|------|--------|----------|----------|
| **レプリケーション** | DNA → DNA |核 | 2 つの同一の DNA 分子 |
| **文字起こし** | DNA → mRNA |核 |メッセンジャーRNA |
| **翻訳** | mRNA → タンパク質 |リボソーム (細胞質) |ポリペプチド鎖（タンパク質） |

## 遺伝子発現
### 遺伝子はどのように制御されるのか
|レベル |メカニズム |例 |
|------|-----------|----------|
| **エピジェネティック** | DNAメチル化;ヒストン修飾;クロマチンリモデリング女性における 1 本の X 染色体のサイレンシング |
| **転写** |転写因子はプロモーター/エンハンサーに結合します。 | をアクティブ化または抑制します。細菌のlacオペロン。ホルモン応答性遺伝子 |
| **転写後** |代替スプライシング。 mRNAの安定性。マイクロRNA | 1 つの遺伝子 → 複数のタンパク質変異体 |
| **翻訳** |リボソームの入手可能性。開始因子調節 |フェリチン mRNA を介した鉄制御 |
| **翻訳後** |タンパク質修飾 (リン酸化、ユビキチン化);劣化 |細胞周期制御 |

## 継承パターン
### メンデル遺伝学
|パターン |説明 |例 |
|----------|---------------|----------|
| **常染色体優性** |対立遺伝子の 1 コピーで十分です。ハンチントン病;軟骨無形成症
| **常染色体劣性** | 2 部のコピーが必要です |嚢胞性線維症;鎌状赤血球貧血 | 鎌状赤血球貧血
| **X 連鎖ドミナント** | X染色体上の遺伝子。 1 部で十分 |レット症候群 |
| **X連鎖劣性型** | X染色体上の遺伝子。男性の方が影響を受けやすい |血友病;色覚異常 |
| **コドミナンス** |両方の対立遺伝子は同等に発現しました。 ABO 血液型 (A および B) |
| **不完全な支配** |ヘテロ接合体は中間です |赤と白の両親からのピンクの花 | 写真 赤と白の両親からのピンクの花
| **多遺伝子** |複数の遺伝子が 1 つの形質に寄与する |身長;肌の色。インテリジェンス |
| **多面発現性** | 1 つの遺伝子が複数の形質に影響を与える |マルファン症候群 (結合組織、目、心臓) |

## ゲノミクス
### ゲノミクスの種類
|タイプ |フォーカス |アプリケーション |
|------|----------|---------------|
| **構造ゲノミクス** |ゲノム内のすべてのタンパク質の 3D 構造 |薬剤設計。タンパク質工学 |
| **機能ゲノミクス** |遺伝子が何をするのか。遺伝子相互作用;表現パターン |病気のメカニズムを理解する |
| **比較ゲノミクス** |種間のゲノムの比較 |進化上の関係。保存領域の特定 |
| **メタゲノミクス** |環境サンプルからの DNA (培養されていない) |マイクロバイオームの研究;新しい生物の発見 |
| **薬理ゲノミクス** |遺伝子が薬物反応に与える影響 |個別化医療;薬物投与 |
| **エピゲノミクス** |ゲノム全体のエピジェネティック修飾 |がんの診断;発生生物学 |
### DNA シーケンシング技術
|世代 |テクノロジー |読み取り長 |スループット |主な機能 |
|----------|-----------|---------------|---------------|---------------|
| **第一世代** |サンガー配列決定 | ～1,000 bp |低い |ゴールドスタンダードの精度。検証に使用される |
| **第 2 世代** |イルミナ（ソレクサ） | 50 ～ 300 bp |非常に高い |短い読み物。支配的なプラットフォーム。拠点あたりのコストが低い |
| **第 2 世代** |イオントレント | 200 ～ 400 bp |高 |半導体ベース。光学系なし |
| **第 3 世代** |パックバイオ (SMRT) | 10,000 ～ 100,000 bp |中程度 |長い読み取り。繰り返し領域を解決します |
| **第 3 世代** |オックスフォードナノポア |最大数百万 bp |中程度から高度 |超長時間読み取り。ポータブル (MinION);リアルタイム |

## 遺伝的変異
### バリエーションの種類
|タイプ |説明 |周波数 |
|------|---------------|----------|
| **SNP** (一塩基多型) |単一塩基の変更 |最も一般的です。 ～ 1,000 塩基に 1 個 |
| **挿入/削除 (インデル)** |塩基の追加または削除 |フレームシフト突然変異を引き起こす可能性がある |
| **CNV** (コピー数バリエーション) |重複または削除されたセグメント (1 kb ～ 数 MB) |病気と進化に貢献 |
| **構造変化** |反転;転座;大規模な再配置 |あまり一般的ではありません。病原性がある可能性があります |
| **マイクロサテライト (STR)** |短いタンデム反復 (2 ～ 6 bp の反復) |法医学;親子鑑定 |
### GWAS (ゲノムワイド関連研究)
|ステップ |説明 |
|------|---------------|
| **1.サンプルを収集** |症例（疾患あり）と対照（疾患なし） |
| **2.遺伝子型** | SNP アレイを使用して数十万のバリアントの遺伝子型を特定する |
| **3.統計的検定** |各 SNP をテストして、形質との関連性を調べます。
| **4.マンハッタンプロット** |すべての染色体にわたる結果を視覚化 |
| **5.レプリケーション** |独立したサンプルの結果を確認する |

## 遺伝子編集
### CRISPR-Cas9
|コンポーネント |機能 |
|----------|----------|
| **ガイド RNA (gRNA)** | ~20ヌクレオチド;ターゲット DNA 配列と一致します |
| **Cas9 タンパク質** |分子はさみ。標的部位で DNA を切断します |
| **PAM シーケンス** |ターゲットの隣に短いモチーフ (NGG)。 Cas9結合に必要 |
| **HDR** (相同性指向修復) |ドナーテンプレートを使用した正確な編集 |
| **NHEJ** (非相同末端結合) |エラーが発生しやすい修復。挿入/削除 (ノックアウト) を作成します |
### 遺伝子編集アプリケーション
|アプリケーション |説明 |
|---------------|---------------|
| **治療** |病気の原因となる突然変異を修正する (鎌状赤血球、ベータサラセミア) |
| **農業** |病気に強い作物。改良された家畜 |
| **研究** |ノックアウトモデルを作成します。遺伝子機能を研究する |
| **遺伝子ドライブ** |集団全体に遺伝子組み換えを広める（マラリア耐性のある蚊など） |

## 倫理的配慮
|問題 |懸念事項 |
|------|-----------|
| **遺伝的プライバシー** |あなたのゲノムデータは誰が所有していますか?雇用主や保険会社はそれを使用できますか? |
| **胚における遺伝子編集** |遺伝性の変化。デザイナーベイビー。意図しないオフターゲット効果 |
| **遺伝子差別** | GINA (米国) は一部の差別から保護しているが、ギャップがある |
| **インフォームドコンセント** |ゲノムデータにより、同意していない親族に関する情報が明らかに |
| **データ ストレージ** |ゲノムは大きい (生の状態で約 200 GB)。長期保管とセキュリティの課題 |
| **資本** |ゲノム医療は、裕福な人々だけが利用できる場合、健康格差を拡大するリスクがあります。

＃＃ まとめ
遺伝学では、個々の遺伝子がどのように機能し、継承されるかを研究します。ゲノミクスは、ゲノム全体、つまりすべての遺伝子、それらの相互作用、およびそれらの変異を研究します。 DNAはRNAに転写され、RNAはタンパク質に翻訳されます。遺伝子発現は、エピジェネティック、転写、転写後、翻訳、翻訳後といった複数のレベルで制御されています。遺伝は、形質が世代間でどのように受け継がれるかを決定するパターン（優性、劣性、多遺伝子）に従います。最新のシーケンシング技術 (Illumina、PacBio、Nanopore) は、ゲノム全体を迅速かつ安価に読み取ることができます。 CRISPR-Cas9 は、医学と農業に変革の可能性をもたらす正確な遺伝子編集を可能にします。最大の課題は倫理面です。ゲノムデータを誰が管理するのか、胚における遺伝子編集をどのように規制するのか、そしてゲノム医療が特権階級だけでなくすべての人に利益をもたらすようにするにはどうすればよいのか、ということです。
