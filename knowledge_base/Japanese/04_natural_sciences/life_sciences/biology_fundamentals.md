# 生物学の基礎
生物学は生命の科学です。すべての生き物は、細胞で構成され、エネルギーを使用し、成長し、環境に反応し、繁殖し、進化するという特定の特徴を共有しています。生物学は単一細胞内の分子機構から生態系全体の相互作用にまで及び、医学、農業、バイオテクノロジー、保全の基礎となっています。
---

## セル — 基本単位
すべての生き物は細胞からできています。基本的なタイプは 2 つあります。
### 原核生物と真核生物
|特集 |原核生物 |真核生物 |
|----------|---------------|---------------|
| **核** |いいえ — DNA は自由に浮遊します。はい — DNA が膜に閉じ込められています |
| **サイズ** |小さい(1-5μm) |より大きい (10-100 μm) |
| **例** |細菌、古細菌 |動物、植物、菌類、原生生物 |
| **複雑さ** |シンプル |複雑な内部構造（オルガネラ） |
| **複製** |二分裂 |有糸分裂または減数分裂 |
| **DNA 形式** |単一の環状染色体 |複数の直鎖状染色体 |
| **オルガネラ** |なし (リボソームのみ) |ミトコンドリア、ER、ゴルジ、リソソームなど |
### 主要なオルガネラ
|オルガネラ |機能 |で見つかりました |
|----------|----------|----------|
| **核** | DNAを保存します。細胞活動を制御する |真核生物のみ |
| **ミトコンドリア** |細胞呼吸; ATP（エネルギー通貨）を生み出す |真核生物のみ |
| **葉緑体** |光合成;光エネルギーを化学エネルギーに変換します |植物細胞のみ |
| **小胞体** |タンパク質と脂質の合成 |真核生物のみ |
| **ゴルジ体** |タンパク質の変更、パッケージ化、出荷 |真核生物のみ |
| **リボソーム** |タンパク質合成（mRNAの翻訳） |すべてのセル |
| **細胞膜** |セルに何が入るか、何がセルから出るかを制御します |すべてのセル |
| **細胞壁** |構造的なサポートと保護 |植物、菌類、細菌 |
| **液胞** |ストレージ;植物の膨圧を維持します |すべて（植物では大きい） |
| **リソソーム** |消化と老廃物の除去 |主に動物細胞 |

## DNA と遺伝学
DNA は、生物を構築し実行するための取扱説明書です。アデニン (A)、チミン (T)、シトシン (C)、グアニン (G) の 4 つの塩基で構成される二重らせんです。 A は常に T とペアになります。 C は常に G とペアになります。このペアリングにより、DNA は自身をコピーします。
### DNAからタンパク質へ
|ステップ |プロセス |どこ |何が起こるのか |
|-----|----------|----------|---------------|
| **レプリケーション** | DNA → DNA |核 | DNAはほどけます。各鎖は新しいコピーのテンプレートとして機能します。
| **文字起こし** | DNA → mRNA |核 |遺伝子はメッセンジャーRNAにコピーされる |
| **翻訳** | mRNA → タンパク質 |リボソーム | mRNA はトリプレット (コドン) で読み取られます。各コドンはアミノ酸を指定します。
DNA → RNA → タンパク質というこの流れは、分子生物学の **セントラル ドグマ** と呼ばれます。
### 遺伝子と染色体
遺伝子は、タンパク質をコードする DNA の一部です。ヒトゲノムには、23 対の染色体に詰め込まれた約 20,000 個の遺伝子が含まれています。突然変異、つまり DNA 配列の変化は進化の原料です。
|突然変異の種類 |説明 |効果例 |
|--------------|-------------|--------------|
| **点突然変異** |単一塩基変更 (A → G) |鎌状赤血球貧血 (ヘモグロビン遺伝子の 1 塩基変化) |
| **挿入** |余分な塩基が追加されました |フレームシフト;しばしば破壊的です |
| **削除** |ベースが削除されました |フレームシフト;病気を引き起こす可能性があります |
| **重複** |コピーされたセグメント |余分な遺伝子コピー。時間の経過とともに新しい機能につながる可能性があります |
| **染色体** |大規模組織再編 |転座;がんや不妊症の原因となる可能性があります |
ほとんどの突然変異は無害ですが、一部は有益であり、少数は病気を引き起こします。

## 自然選択による進化
進化論は口語的な意味での「単なる理論」ではなく、すべての生物学の統一的な枠組みです。仕組みは簡単です。
1. 生物は、環境がサポートできる以上に多くの子孫を生み出します。
2. 個人の特性は異なります (一部の特性は遺伝します)。
3. 環境により適した形質を持つ個体は、生存し、繁殖する可能性が高くなります。
4. 世代が経つにつれて、有利な特性が集団内でより一般的になります。
このプロセスは、指針となる知性を一切持たずに、細菌からシロナガスクジラに至るまで、地球上のすべての生命の多様性を説明します。
### 進化の証拠
|証拠の種類 |説明 |
|--------------|---------------|
| **化石記録** |数十億年にわたる緩やかな変化を示します。移行形態 (始祖鳥、ティクタアリク) |
| **比較解剖学** |相同な構造 (人間の腕、クジラのひれ、コウモリの翼は同じ骨の配置を共有) |
| **分子生物学** | DNA とタンパク質の配列は、近縁種ほど類似しています。
| **伝記** |種の分布は大陸移動と隔離パターンに一致します。
| **観察された進化** |細菌の抗生物質耐性。昆虫の殺虫剤耐性。実験室での実験 |
### 進化のメカニズム
|メカニズム |説明 |
|----------|---------------|
| **自然選択** |有利な特性は世代を経るごとに一般的になる |
| **遺伝的漂流** |対立遺伝子頻度のランダムな変化。少数の集団でより強い |
| **遺伝子の流れ** |集団間の個体 (およびその遺伝子) の移動 |
| **突然変異** | DNA の変化によってもたらされる新しい遺伝的変異 |
| **性的選択** |交配の成功率を向上させる形質がより一般的になる (孔雀の尾) |
| **種分化** |集団は、交配できなくなるまで分岐します。

## エコロジー
生態学は、生物が互いにどのように相互作用するか、またその環境とどのように相互作用するかを研究します。
### 組織のレベル
|レベル |説明 |例 |
|----------|---------------|----------|
| **生物** |個々の生き物 |鹿一頭 | 写真
| **人口** |地域内の同じ種のグループ |鹿の群れ | 写真 鹿の群れ
| **コミュニティ** |エリア内のすべての人口 |鹿＋ウサギ＋鳥＋昆虫＋植物 |
| **生態系** |コミュニティ + 物理的環境 |森林 + すべての生物 + 土壌 + 水 + 気候 |
| **生物圏** |地球上のすべての生態系 |深海から高層大気まで |
### エネルギーの流れ
|コンセプト |説明 |
|----------|---------------|
| **プロデューサー** |太陽光をエネルギーに変換（植物、藻類、シアノバクテリア） |
| **一次消費者** |生産者を食べる（草食動物：シカ、ウサギ） |
| **二次消費者** |一次消費者（肉食動物：オオカミ）を食べる |
| **第三次消費者** |トップ捕食者 (ワシ、シャチ) |
| **分解者** |死骸（菌類、細菌）を分解 |
エネルギーの約 10% のみが栄養段階間で移動し、残りは熱として失われます。これが、食物連鎖が 4 ～ 5 レベルを超えることはほとんどなく、捕食者の数が被食者よりも少ない理由です。
### 生物地球化学サイクル
|サイクル |主要なプロセス |
|------|-----------|
| **炭素循環** |光合成は CO₂ を除去します。呼吸と燃焼によってそれが放出されます。
| **窒素サイクル** |窒素固定バクテリアは N2 を利用可能な形態に変換します。脱窒菌が返す |
| **水循環** |蒸発→凝縮→沈殿→流出→繰り返し |
| **リンサイクル** |岩石が風化するとリンが放出されます。大気相なし |

## 分類学と生命の樹
すべての生物は、領域→界→門→綱→目→科→属→種という階層に分類されます。
### 3 つのドメイン
|ドメイン |セルの種類 |主な機能 |例 |
|----------|-----------|---------------|-----------|
| **バクテリア** |原核生物 |ペプチドグリカン細胞壁。最も身近な細菌 |大腸菌、連鎖球菌 |
| **古細菌** |原核生物 |ペプチドグリカンは含まれていません。多くの場合、極限環境微生物メタン生成菌、好塩菌、好熱菌 |
| **真核生物** |真核生物 |膜結合核と細胞小器官 |その他すべて |
### 真核生物内の王国
|キングダム |主な機能 |例 |
|----------|---------------|----------|
| **動物** |多細胞;従属栄養性。細胞壁がない |人間、昆虫、魚、鳥 |
| **植物** |多細胞;独立栄養性（光合成）。セルロース細胞壁 | セルロース細胞壁木、草、シダ、コケ |
| **菌類** |ほとんどが多細胞。従属栄養性（吸収）。キチン細胞壁 | キチン細胞壁キノコ、酵母、カビ |
| **原生生物** |ほとんどが単細胞。多様な |アメーバ、藻類、ゾウリムシ |

＃＃ まとめ
生物学は、分子から生態系に至るまでの生命の科学です。すべての生き物は細胞でできており、単純な原核生物 (細菌、古細菌) または複雑な真核生物 (動物、植物、菌類) のいずれかです。 DNA は、DNA → RNA → タンパク質というセントラル ドグマを通じて遺伝情報を伝達します。自然選択による進化は統一的な枠組みであり、化石、解剖学、分子生物学、生物地理学、および直接観察によって裏付けられています。生態学は、生産者から消費者および分解者を介して流れるエネルギーによって、生物が互いにどのように相互作用し、またその環境と相互作用するかを研究します。生命の木では、すべての生物が細菌、古細菌、真核生物の 3 つの領域に分類され、さらに界、門、種に細分されます。生物学は、医学、農業、バイオテクノロジー、保全の基礎です。
