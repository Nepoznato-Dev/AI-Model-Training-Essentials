# 神経科学
神経科学は、脳、脊髄、およびそれらを身体に接続するすべての神経などの神経系の研究です。それは、分子や遺伝子から、個々のニューロンやシナプス、回路や脳領域、行動、認知、意識に至るまで、複数のレベルに及びます。脳は既知の宇宙で最も複雑な構造であり、数兆のシナプスで接続された約 860 億個のニューロンを含み、その仕組みを理解することは科学の大きな課題の 1 つです。
---

## ニューロン
### ニューロンの部分
|コンポーネント |機能 |
|----------|----------|
| **樹状突起** |他のニューロンから信号を受信します。枝のような拡張子 |
| **細胞体 (ソーマ)** |受信信号を統合します。核が含まれています |
| **軸索** |電気信号 (活動電位) を体細胞から伝達する長い繊維 |
| **ミエリン鞘** |軸索周囲の絶縁層。信号伝送を高速化します |
| **ランヴィエのノード** |ミエリンの隙間。塩性伝導を許可します (ノード間で信号がジャンプします)。
| **軸索終末 (シナプス ボタン)** |神経伝達物質をシナプスに放出する |
### ニューロンの種類
|タイプ |方向 |機能 |
|------|-----------|----------|
| **感覚 (求心性)** |体→脳 |感覚（触覚、温度、痛み、視覚など）からの情報を伝える |
| **モーター (遠心性)** |脳→体 |筋肉と腺を制御する |
| **介在ニューロン** | CNS内 |ニューロンを他のニューロンに接続します。ほとんどのニューロンは介在ニューロンです。
---

## ニューロンの通信方法
### 活動の可能性
|フェーズ |説明 |
|------|-----------|
| **安静時潜在能力** |ニューロンは約 -70 mV です。ナトリウム-カリウムポンプがイオンバランスを維持 |
| **脱分極** |刺激によりナトリウムチャネルが開きます。 Na+ が突入します。膜電位が上昇します |
| **しきい値** |電位が ~-55 mV に達すると、活動電位が発火します (全か無か)。
| **上昇期** |電位依存性ナトリウムチャネルが開きます。 ~+40 mV までの潜在的なスパイク |
| **下降段階** |ナトリウムチャネルは閉じます。カリウムチャネルが開きます。 K+ が流出します。潜在的な低下 |
| **アンダーシュート (過分極)** |電位が一時的に安静時レベルを下回ります。
| **不応期** |ニューロンはすぐには再起動できません。一方向の伝播を保証します。
### シナプス
|コンポーネント |役割 |
|-----------|------|
| **シナプス前ニューロン** |信号を送信します。神経伝達物質を含むシナプス小胞が含まれています。
| **シナプス間隙** |ニューロン間の小さなギャップ (~20 nm) |
| **シナプス後ニューロン** |信号を受信します。受容体タンパク質を持っています。
| **神経伝達物質** |シナプスを通過する化学メッセンジャー | シナプスを通過する化学メッセンジャー
| **受容体** |神経伝達物質を結合します。イオンチャネルを開くか、セカンドメッセンジャーカスケードをトリガーします。
---

## 主要な神経伝達物質
|神経伝達物質 |機能 |関連する条件 |
|-----------------|----------|-----------|
| **グルタミン酸** |主要な興奮性神経伝達物質。学ぶ;記憶 |過剰 → 興奮毒性 (脳卒中、神経変性) |
| **GABA** |主な抑制性神経伝達物質。神経活動を減少させる |赤字 → 不安、てんかん |
| **ドーパミン** |褒美;モチベーション;モーター制御;注意 |赤字→パーキンソン病。過剰→統合失調症 |
| **セロトニン** |気分;寝る;食欲;消化 |赤字 → うつ病、不安 |
| **アセチルコリン** |筋肉の活性化。学ぶ;記憶 |赤字 → アルツハイマー病 |
| **ノルアドレナリン** |覚醒;警戒心;ストレス反応 |調節不全→ADHD;うつ病 |
| **エンドルフィン** |痛みの軽減;喜び |運動誘発性の解放（「ランナーズハイ」） |

## 脳の構造
### 主要な脳領域
|地域 |機能 |
|----------|----------|
| **大脳皮質** |より高い認知力。前頭葉、頭頂葉、側頭葉、後頭葉に分かれる |
| **前頭葉** |企画;意思決定;人格;随意運動（運動野） |
| **頭頂葉** |感覚処理;空間認識。ナビゲーション |
| **側頭葉** |聴覚;言語理解。記憶（海馬） |
| **後頭葉** |視覚処理 |
| **小脳** |モーターの調整。バランス;運動学習。いくつかの認知機能 |
| **脳幹** |重要な機能: 呼吸。心拍;睡眠覚醒サイクル |
| **視床** |感覚中継局。信号を適切な皮質領域にルーティングします。
| **視床下部** |恒常性;ホルモン調節;飢え;渇き;概日リズム |
### 大脳辺縁系
|構造 |機能 |
|----------|----------|
| **扁桃体** |感情の処理。恐れ;脅威の検出。感情的な記憶 |
| **海馬** |記憶の形成。空間ナビゲーション。短期記憶を長期記憶に変換します |
| **大脳基底核** |習慣の形成。学習に報酬を与える。モーター制御 |
| **帯状皮質** |エラー検出;共感;インパルス制御。感情の制御 |
| **側坐核** |報酬回路。喜び;依存症 |

## 認知神経科学
### 主要な認知機能とその脳領域
|機能 |一次脳領域 |
|----------|--------|
| **注意** |前頭前野。頭頂皮質。視床 |
| **作業記憶** |前頭前野。頭頂皮質 |
| **長期記憶** |海馬 (形成);皮質 (ストレージ) |
| **言語** |ブローカ野 (生産);ウェルニッケ領域 (理解) |
| **感情の制御** |前頭前野。扁桃体。腹内側PFC |

| **視覚処理** |後頭葉 → 腹側ストリーム (「何を」) と背側ストリーム (「どこ」) |

| **アルファ** | 8～13Hz |リラックスした覚醒状態。目を閉じた | 写真

## 神経可塑性
|タイプ |説明 |例 |
|------|-------------|----------|
| **シナプス可塑性** |シナプスの強さは活動に応じて変化する |長期増強（LTP）;長期うつ病 (LTD) |
| **構造可塑性** |ニューロンは新しい樹状突起または軸索を成長させます。新しいスキルを学ぶ;怪我からの回復 |
| **皮質の再マッピング** |脳領域は機能を再割り当てする |視覚障害者の視覚野は接触と音を処理します |
| **神経新生** |新しいニューロンが生まれる |海馬で発生します。運動と学習によって刺激される |

## 研究方法
|方法 |何を測定するのか |解像度 |
|----------|------|-----------|
| **fMRI** |血中酸素濃度（BOLD信号）→脳活動 |良好な空間 (~1 mm)。一時的な不良 (~1 秒) |
| **脳波** |頭皮からの電気活動 |優れた時間的 (~1 ミリ秒)。空間が悪い |
| **メグ** |神経活動からの磁場 |時間的および空間的に優れている |
| **ペット** |放射性トレーサー → 代謝活動 |中程度の空間的および時間的 |
| **TMS** |磁気パルス → 脳領域を一時的に混乱させる |因果関係の証拠。奥行きが限られている |
| **単体録音** |個々のニューロンの電気活動 |単一細胞。侵襲的;主に動物研究 |
| **光遺伝学** |光活性化ニューロン |正確な制御。動物研究 |
| **DTI** (拡散テンソル イメージング) |白質路 | 写真接続マッピング |

## 神経障害および精神障害
|障害 |影響を受けるシステム |主な機能 |
|----------|----------------|--------------|
| **アルツハイマー病** |皮質;海馬 |記憶喪失。アミロイド斑;タウのもつれ
| **パーキンソン病** |黒質。大脳基底核 |振戦;剛性;ドーパミンニューロン喪失 |
| **てんかん** |大脳皮質 |再発性発作;異常な電気活動 |
| **多発性硬化症** |ミエリン鞘 (CNS) |脱髄。信号伝達の中断 |
| **うつ病** |前頭前野。大脳辺縁系 |持続的な気分の落ち込み。神経伝達物質のアンバランス |
| **統合失調症** |複数の地域 |幻覚;妄想。ドーパミン調節不全 |
| **ALS** |運動ニューロン |進行性の筋力低下。運動ニューロンの死

＃＃ まとめ
神経科学は、イオンチャネルの分子機構から意識の主観的経験に至るまで、あらゆるレベルで神経系を研究します。ニューロンは、グルタミン酸、GABA、ドーパミン、セロトニンなどの神経伝達物質を使用し、電気的活動電位と化学シナプスを介して通信します。脳は、高度な認知を司る皮質、感情と記憶を司る大脳辺縁系、調整を司る小脳という特殊な領域に組織されています。神経可塑性とは、脳が生涯を通じて自身の配線を再構築できることを意味します。研究方法は、fMRI (優れた空間分解能) から EEG (優れた時間分解能)、光遺伝学 (正確な因果関係制御) まで多岐にわたります。脳を理解することはおそらく科学において最も難しい問題です。脳はそれ自体を研究する唯一の器官です。
