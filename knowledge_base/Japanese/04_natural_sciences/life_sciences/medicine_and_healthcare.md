# 医療とヘルスケア
医学は、病気の診断、治療、予防を行う科学および実践です。これは人類の最も古い取り組みの 1 つであり、ヒポクラテスの誓いは古代ギリシャに遡りますが、最も急速に変化しているものの 1 つです。前世紀だけでも、抗生物質のない時代から、患者の DNA を書き換えることができる遺伝子治療が使えるようになりました。
このファイルには、主な専門分野、病気の診断と治療の仕組み、医療システムの組織化、人命が危険にさらされているときに生じる倫理的な問題など、医療の仕組みが取り上げられています。

## 体の仕組み - クイックツアー
病気を理解する前に、健康とはどのようなものかを理解するのに役立ちます。人間の体には 11 の主要な器官系があり、それぞれに特定の働きがありますが、すべてが深く相互に関連しています。
|システム |主要な臓器 |一次関数 |よくある問題 |
|------|-----------|------|------|
| **心臓血管** |心臓、血管 | 写真 心臓、血管血液をポンプで送ります。酸素と栄養素を届ける |心臓病、脳卒中、高血圧 |
| **呼吸器** |肺、気道 |酸素と二酸化炭素を交換する |喘息、COPD、肺炎、肺がん |
| **消化器** |胃、腸、肝臓、膵臓 |食べ物を分解する。栄養素を吸収します。無駄をなくす |逆流性食道炎、潰瘍、炎症性腸疾患、肝疾患 |
| **緊張** |脳、脊髄、神経 | 脳、脊髄、神経プロセス情報。体の機能をコントロールする |アルツハイマー病、パーキンソン病、てんかん、脳卒中 |
| **内分泌** |下垂体、甲状腺、副腎、膵臓 |代謝、成長、生殖を調節するホルモンを生成します。糖尿病、甲状腺疾患、肥満 |
| **免疫/リンパ** |白血球、リンパ節、脾臓 |病原体から身を守る |自己免疫疾患、免疫不全、アレルギー |
| **筋骨格系** |骨、筋肉、関節 | 写真支持体。移動を可能にする |関節炎、骨粗鬆症、骨折、腰痛 |
| **泌尿器/腎臓** |腎臓、膀胱 | 写真 腎臓、膀胱血液をろ過します。老廃物を取り除く。体液を調節する |腎臓病、尿路感染症、腎臓結石 |
| **生殖機能** |卵巣・精巣、子宮など |複製を有効にする |不妊、がん、ホルモン障害 |
| **外皮** |肌、髪、爪 |体を守る温度を調節する |湿疹、乾癬、皮膚がん、感染症 |
| **血液学** |血液、骨髄 | 写真酸素を輸送します。感染症と戦う。血が固まる貧血、白血病、凝固障害 |
### ホメオスタシス — 身体のバランスをとる作用
体内のあらゆるシステムは、**ホメオスタシス**を維持するために機能し、外部の変化にもかかわらず内部状態を安定に保ちます。外が凍えるような寒さであっても、うだるような暑さであっても、体温は約 37°C に保たれます。血液のpHは7.35から7.45の間に維持されます。血糖値は狭い範囲内で上下し、インスリンとグルカゴンによって制御されます。
病気は多くの場合、ホメオスタシスが崩れたときに起こります。発熱は免疫システムが感染と戦うために意図的に体温を上昇させることです。糖尿病は血糖調節機能の不全です。心不全は、心臓血管系が適切な血流を維持できない状態です。

## 診断 — 何が問題なのかを特定する
診断は消去と確認のプロセスです。医師は手がかり（症状、病歴、検査所見）を収集し、可能性を絞り込みます。
### 診断プロセス
1. **病歴**: どのような症状がありますか?いつから始めたのですか？何が彼らを良くするのか、悪くするのか？家族歴？薬？これだけでも可能性は大幅に狭まってしまいます。
2. **身体検査**: バイタルサイン (体温、血圧、心拍数)、心臓と肺の音を聞く、腹部を触診する、反射神経をチェックする。
3. **鑑別診断**: 考えられる状態を最も可能性の高いものから最も可能性の低いもの (および最も危険性の高いものから最も危険性の低いもの) にランク付けしたリスト。
4. **テスト**: ディファレンシャルの状態を確認または除外するために命令されます。
### 一般的な診断テスト
|テスト |それが示すもの |最適な用途 |
|-----|--------------|----------|
| **血液検査 (CBC)** |赤血球/白血球、血小板 |感染症、貧血、血液疾患 |
| **代謝パネル** |腎臓機能、肝機能、電解質、ブドウ糖 |臓器機能、糖尿病スクリーニング |
| **X線** |緻密な構造 (骨、肺) |骨折、肺炎、心臓の大きさ |
| **CT スキャン** | X線を使用した詳細な断面図 |外傷、腫瘍、内出血 |
| **MRI** |優れた軟組織の詳細 (放射線なし) |脳腫瘍、靱帯断裂、脊椎の問題 |
| **超音波** |音波を使ったリアルタイム画像 |妊娠、胆石、心臓機能 |
| **生検** |顕微鏡で検査された組織サンプル |がんの診断、炎症状態 |
| **心電図/心電図** |心臓の電気活動 |不整脈、心臓発作 |
| **内視鏡検査** |消化管を通るカメラ | 写真 消化管を通るカメラ潰瘍、ポリープ、がん |
### スクリーニング — 症状が出る前に病気を発見する
スクリーニング検査では、元気な人の病気を調べます。目標は、問題を早期に発見し、より治療可能になるようにすることです。
|上映 |誰 |頻度 |
|----------|-----|----------|
| **血圧** |すべての大人 | 1 ～ 2 年ごと |
| **コレステロール** | 20 歳以上の大人 | 4 ～ 6 年ごと |
| **マンモグラフィー** |女性 40 ～ 74 歳 | 1 ～ 2 年ごと |
| **大腸内視鏡検査** | 45 ～ 75 歳の大人 | 10年ごと |
| **パップスミア** |女性 21 ～ 65 歳 | 3 ～ 5 年ごと |
| **糖尿病スクリーニング** |太りすぎの 35 ～ 70 歳の成人 | 3年ごと |

## 治療 - 問題の解決
治療の選択肢は、何もしないこと（多くの症状は自然に解決する）から積極的な介入まで多岐にわたります。適切なアプローチは、状態、その重症度、患者の全体的な健康状態、および何が効果があるかの証拠によって異なります。
|アプローチ |例 |使用時 |
|----------|-----------|----------|
| **注意深く待っています** |積極的な治療を行わずにモニター |軽度の状態は解決される可能性があります。低リスクの所見 |
| **ライフスタイルの変化** |食事、運動、睡眠、ストレス管理 |多くの慢性疾患 (高血圧、2 型糖尿病) の第一選択 |
| **薬** |抗生物質、血圧薬、インスリン、抗うつ薬 |生活習慣の改善だけでは不十分な場合 |
| **手術** |虫垂切除術、関節置換術、腫瘍除去術 |構造的な問題に物理的な修理が必要な場合 |
| **放射線療法** |がん細胞を殺すための標的放射線 |がん治療は手術と併用されることが多い |
| **免疫療法** |がんに対する免疫システムを利用する |特定のがん (黒色腫、肺がん) |
| **理学療法** |動きと機能を回復するためのエクササイズ |怪我、手術後、または慢性的な痛みがある場合 |
| **心理療法** |トークセラピー（CBT、精神力学など） |精神的健康状態;慢性的な痛みにも効果あり |
| **緩和ケア** |症状の軽減と生活の質 |重篤な病気。耐用年数の終了に限らず |
### 薬理学の基礎
|薬物クラス |何をするのか |例 |重要な注意事項 |
|-----------|---------------|----------|-----|
| **抗生物質** |細菌を殺す |ペニシリン、アモキシシリン、シプロフロキサシン |ウイルスに対しては機能しません。使いすぎは抵抗を生みます |
| **鎮痛剤** |痛みを和らげる |イブプロフェン、アセトアミノフェン、モルヒネ |オピオイドには非常に依存性があります。慎重に使用してください |
| **降圧剤** |血圧を下げる | ACE阻害剤、β遮断薬、利尿薬 |多くの場合、複数の薬が必要です。生涯治療 |
| **スタチン** |コレステロールを下げる |アトルバスタチン、ロスバスタチン |世界中で最も処方されている薬の一つ |
| **抗凝固剤** |血栓を防ぐ |ワルファリン、ヘパリン、アピキサバン |出血のリスク;監視が必要 |
| **抗うつ薬** |うつ病と不安症の治療 | SSRI、SNRI、三環系 |作業には数週間かかります。急に止まらないでください。
| **インスリン** |血糖値を下げる |速効性、持続性 | 1 型糖尿病に必須。場合によってはタイプ 2 |
| **化学療法** |急速に分裂する細胞を殺す |シスプラチン、パクリタキセル |健康な高速分裂細胞への損傷による副作用 |

## 医療システム — 社会がケアをどのように組織するか
医療制度は国によって大きく異なりますが、どの国も同じ根本的な課題に直面しています。それは、個人や制度を破綻させることなく、どのようにしてすべての人に質の高い医療を提供するかということです。
|モデル |仕組み |例 |強み |弱点 |
|----------|---------------|----------|-----------|---------------|
| **単一支払者** |政府は資金を提供し、しばしばケアを提供します。英国 (NHS)、カナダ、スカンジナビア |普遍的な適用範囲。コスト管理 |待ち時間。選択肢が限られている |
| **社会保険** |雇用主と従業員による非営利の「疾病基金」への拠出義務 |ドイツ、フランス、日本 |ユニバーサル;複数の保険会社が競合 |複雑な;高価です |
| **複数支払者 (雇用主ベース)** |雇用主を通じた民間保険。政府は高齢者/貧困層をカバー |米国 |革新;被保険者の待ち時間が短い | 2,700万人が無保険。最高コスト |
| **自己負担** |患者は直接支払います |ほとんどの低所得国 |シンプル |金持ちだけがケアを受けられる |
米国は他の裕福な国に比べて1人当たり医療費のおよそ2倍を医療費に費やしており、多くの指標（平均余命、乳児死亡率、予防可能な死亡）の結果は悪化している。理由は複雑です。行政の無駄、薬価の高さ、価値よりも量を重視する報酬型インセンティブ、不平等なアクセスなどです。

## 公衆衛生 — 住民の保護
臨床医学は個々の患者に焦点を当てますが、公衆衛生は集団に焦点を当てます。そのツールは疫学、ワクチン接種、衛生、教育、政策です。
### 公衆衛生における最大の成果
1. **ワクチン接種** — 天然痘を撲滅し、ポリオをほぼ撲滅し、年間数百万人の死亡を防止
2. **きれいな水と衛生設備** — 先進国でコレラを撲滅。発展途上国では依然として主要な死因となっている
3. **抗生物質** — 感染症を死刑宣告から治療可能な状態に変えた
4. **タバコ規制** — 多くの国で喫煙率が劇的に低下し、何百万もの癌や心臓発作が予防されました。
5. **交通安全** — シートベルト、エアバッグ、飲酒運転に関する法律により、多くの国で交通死亡率が半減しました
### 疫学 — パターンの科学
疫学者は病気がどのように集団内に広がるかを研究します。主要な概念:
|用語 |意味 |例 |
|------|--------|----------|
| **発生率** |期間内の新規感染者数 |人口 100,000 人あたり年間 500 人の新規糖尿病患者 |
| **有病率** |ある時点での既存の症例の合計 |成人の 10% が現在糖尿病を患っています。
| **死亡率** |病気による死亡 |心臓病による死亡者数は10万人あたり150人 |
| **R₀ (R なし)** | 1人の感染者が感染させる平均人数 |麻疹：12～18人。インフルエンザ: 1-2 |
| **集団免疫** |十分な数の人々が免疫を持っていれば、病気は簡単には広がりません。はしかのワクチン接種が約 95% 必要 |

## 医療倫理 — 難しい質問
医学は簡単に答えのない倫理的な問題を提起します。医療倫理の指針となるのは次の 4 つの原則です。
1. **自律性**: たとえ医師が同意しない場合でも、患者は自分の治療について情報に基づいた決定を下す権利を有します。
2. **善意**: 患者の最善の利益を考えて行動します。
3. **非悪意**: 「まず、危害を加えないこと。」害が利益を上回る治療は避けてください。
4. **正義**: 医療リソースを公平に分配します。
これらの原則は時々矛盾します。患者は救命治療を拒否する可能性があります（自主性か慈善か）。高価な薬は 1 人の患者に利益をもたらす可能性がありますが、他の多くの患者のリソースを消耗する可能性があります (善対正義)。
現代医学における重要な倫理問題:
- **終末期ケア**: 生命維持装置を中止するのはいつが適切ですか?緩和ケア（苦しみを和らげる）と安楽死（意図的に命を終わらせる）の違いは何ですか？
- **インフォームドコンセント**: 患者は治療に同意する前に、リスク、利点、および代替手段を理解する必要があります。これは思っているよりも複雑で、ほとんどの患者は統計的リスクを完全には理解していません。
- **資源配分**: 十分な臓器がない場合、誰が臓器移植を受けますか?パンデミック中に人工呼吸器を装着するのは誰ですか?
- **遺伝子検査と編集**: 胚の遺伝性疾患をスクリーニングし、CRISPR で遺伝子を編集できるようになりました。そうすべきでしょうか？病気の治療と赤ちゃんの「デザイン」の間の境界線はどこにあるのでしょうか?
- **医療における AI**: AI 診断ツールが間違いを犯した場合、誰が責任を負いますか? AI がバイアスをエンコードしないようにするにはどうすればよいでしょうか?

＃＃ まとめ
医学は科学であると同時に芸術でもあります。科学は並外れたものです。私たちは数時間でゲノムを解読し、幹細胞から臓器を成長させ、がんと戦うために免疫系を再プログラムすることができます。技術は、その科学を、それぞれ独自の価値観、状況、好みを持つ個々の患者に適用することにあります。世界中の医療システムは、破産することなくすべての人に質の高い医療を提供するという同じ課題に取り組んでいます。治療法がより進歩し、人口が高齢化するにつれて、医学的に可能なことと経済的に持続可能なことの間の緊張は高まるばかりです。医療の仕組み、つまり病気がどのように診断、治療、予防されるのかを理解することは、自分自身の健康と社会の健康について十分な情報に基づいた意思決定を行うために不可欠です。
