# কম্পিউটার ভিশন ফান্ডামেন্টাল
কম্পিউটার ভিশন মেশিনগুলিকে বিশ্বের ভিজ্যুয়াল তথ্য - ছবি, ভিডিও এবং 3D ডেটা ব্যাখ্যা করার এবং বোঝার ক্ষমতা দেয়। এটি আপনার ফোনে মুখ শনাক্তকরণ থেকে শুরু করে স্ব-ড্রাইভিং গাড়ি, মেডিকেল ইমেজ বিশ্লেষণ এবং শিল্পের গুণমান নিয়ন্ত্রণ সবকিছুকে ক্ষমতা দেয়। এই ফাইলটি মূল ধারণা, আর্কিটেকচার এবং কৌশলগুলিকে কভার করে।
---

## কম্পিউটার কিভাবে ছবি দেখে
### পিক্সেল এবং চ্যানেল
ডিজিটাল ইমেজ হল পিক্সেলের একটি গ্রিড। প্রতিটি পিক্সেলের সংখ্যাসূচক মান রয়েছে যা রঙের তীব্রতার প্রতিনিধিত্ব করে।
| ছবির ধরন | চ্যানেল | পিক্সেল প্রতি মান | উদাহরণ |
|------------|------------|------|---------|
| **গ্রেস্কেল** | 1 | 0 (কালো) থেকে 255 (সাদা) | মেডিকেল এক্স-রে |
| **RGB** | 3 | লাল, সবুজ, নীল (প্রতিটি 0-255) | স্ট্যান্ডার্ড রঙিন ফটো |
| **আরজিবিএ** | 4 | RGB + আলফা (স্বচ্ছতা) | স্বচ্ছ ব্যাকগ্রাউন্ড সহ ছবি |
| **HSV** | 3 | রঙ, স্যাচুরেশন, মান | রঙ-ভিত্তিক বিভাজন |
একটি 1920×1080 RGB চিত্র হল`(1080, 1920, 3)`আকৃতির একটি টেনসর — এটি 6.2 মিলিয়ন পিক্সেল, প্রতিটি 3টি মান সহ।
### মূল অপারেশন
| অপারেশন | বর্ণনা |
|------------|-------------|
| **আকারকরণ** | টার্গেট ডাইমেনশনে ইমেজ স্কেল করুন (দ্বৈরৈখিক, নিকটতম-প্রতিবেশী ইন্টারপোলেশন) |
| **ক্রপিং** | আগ্রহের একটি অঞ্চল বের করুন |
| **স্বাভাবিককরণ** | নিউরাল নেটওয়ার্কের জন্য পিক্সেল মানকে [0,1] বা [-1,1] এ স্কেল করুন |
| **বর্ধন** | কৃত্রিমভাবে প্রশিক্ষণের ডেটা প্রসারিত করুন (ঘূর্ণন, ফ্লিপ, কালার জিটার, ক্রপ) |

## আবর্তন: মূল অপারেশন
একটি কনভল্যুশন চিত্র জুড়ে একটি ছোট ফিল্টার (কার্নেল) স্লাইড করে, প্রতিটি অবস্থানে ডট পণ্যগুলি গণনা করে। এইভাবে সিএনএনগুলি প্রান্ত, টেক্সচার এবং প্যাটার্ন সনাক্ত করে।
### কনভোলিউশন প্যারামিটার
| পরামিতি | প্রভাব |
|------------|---------|
| **কারনেলের আকার** | 3×3, 5×5, 7×7 — বড় কার্নেল বড় প্যাটার্ন ক্যাপচার করে |
| **স্ট্রাইড** | ধাপের আকার; stride=2 আউটপুট মাত্রা অর্ধেক করে |
| **প্যাডিং** | স্থানিক মাত্রা সংরক্ষণ করতে সীমান্তের চারপাশে শূন্য যোগ করুন |
| **ফিল্টারের সংখ্যা** | প্রতিটি ফিল্টার একটি ভিন্ন বৈশিষ্ট্য (প্রান্ত, টেক্সচার, রঙের প্যাটার্ন) শেখে |
### কনভল্যুশন কি শিখুন
| স্তর গভীরতা | বৈশিষ্ট্য সনাক্ত করা হয়েছে |
|-------------------------------------------------- |
| **প্রাথমিক স্তর** | প্রান্ত, কোণ, সরল টেক্সচার |
| **মাঝের স্তর** | আকৃতি, বস্তুর অংশ (চাকা, চোখ, পাতা) |
| **গভীর স্তর** | উচ্চ-স্তরের ধারণা (মুখ, গাড়ি, প্রাণী) |

## সিএনএন আর্কিটেকচার
সিএনএন আর্কিটেকচারের বিবর্তন কম্পিউটার দৃষ্টিতে গভীর শিক্ষার অগ্রগতির গল্প বলে।
| স্থাপত্য | বছর | মূল উদ্ভাবন |
|---------------|------|---------------|
| **LeNet-5** | 1998 | প্রথম ব্যবহারিক সিএনএন; অঙ্ক স্বীকৃতি |
| **আলেক্সনেট** | 2012 | ডিপ সিএনএন ইমেজনেট জিতেছে; ReLU, ড্রপআউট, GPU প্রশিক্ষণ |
| **VGGNet** | 2014 | স্ট্যাক করা 3×3 কনভোলিউশন (গভীর = ভাল) |
| **GoogLeNet (প্রবর্তন)** | 2014 | ইনসেপশন মডিউল (সমান্তরাল ফিল্টার মাপ); 22 স্তর |
| **রেসনেট** | 2015 | সংযোগগুলি এড়িয়ে যান (অবশিষ্ট শিক্ষা); 152+ স্তর |
| **দক্ষ নেট** | 2019 | যৌগিক স্কেলিং (গভীরতা + প্রস্থ + রেজোলিউশন) |
| **পরবর্তী** | 2022 | আধুনিক ResNet; ট্রান্সফরমারের সাথে প্রতিযোগিতামূলক |
### কেন ResNet সবকিছু পরিবর্তন করেছে
ResNet এর আগে, অদৃশ্য গ্রেডিয়েন্ট সমস্যার কারণে খুব গভীর নেটওয়ার্ক প্রশিক্ষণ প্রায় অসম্ভব ছিল। ResNet চালু করেছে **কানেকশন বাদ দিন** (এটিকে রেসিডুয়াল কানেকশনও বলা হয়): একটি লেয়ারের ইনপুট তার আউটপুটে যোগ করা হয়।
```
output = F(x) + x    # Skip connection
```

এই সাধারণ ধারণাটি 152+ স্তর সহ নেটওয়ার্কগুলিকে কার্যকরভাবে প্রশিক্ষিত করার অনুমতি দেয় এবং এটি এখন কার্যত সমস্ত গভীর আর্কিটেকচারে আদর্শ।

## কোর ভিশন টাস্ক
### ছবির শ্রেণীবিভাগ
একটি সম্পূর্ণ ছবিতে একটি লেবেল বরাদ্দ করুন।
| মডেল | দৃষ্টিভঙ্গি |
|-------|----------|
| CNNs (ResNet, EfficientNet) | ঐতিহ্যগত পদ্ধতি; চমৎকার নির্ভুলতা |
| ভিশন ট্রান্সফরমার (ViT) | চিত্রটিকে প্যাচের ক্রম হিসাবে বিবেচনা করুন; ট্রান্সফরমার এনকোডার |
| ট্রান্সফার লার্নিং | আপনার ডেটাসেটে একটি প্রাক-প্রশিক্ষিত মডেল ঠিক করুন |
### অবজেক্ট ডিটেকশন
বাউন্ডিং বাক্স সহ একটি চিত্রের মধ্যে একাধিক অবজেক্ট খুঁজুন এবং শ্রেণীবদ্ধ করুন।
| মডেল | প্রকার | গতি |
|-------|------|-------|
| **আর-সিএনএন** | দ্বি-পর্যায় (প্রস্তাব + শ্রেণীবিভাগ) | ধীর |
| **দ্রুত R-CNN** | উন্নত দুই-পর্যায়ে | মাঝারি |
| **দ্রুত R-CNN** | অঞ্চল প্রস্তাব নেটওয়ার্ক + ডিটেক্টর | মাঝারি |
| **YOLO** (v1–v10) | একক-পর্যায়; ভবিষ্যদ্বাণী বাক্স + এক পাসে ক্লাস | খুব দ্রুত |
| **DETR** | ট্রান্সফরমার ভিত্তিক; কোন নোঙ্গর বক্স | মাঝারি |
**YOLO** (আপনি শুধুমাত্র একবার দেখুন) রিয়েল-টাইম সনাক্তকরণের জন্য যেতে হবে। **দ্রুত R-CNN** পছন্দ করা হয় যখন গতির চেয়ে নির্ভুলতা বেশি গুরুত্বপূর্ণ।
### ইমেজ সেগমেন্টেশন
একটি চিত্রের প্রতিটি পিক্সেলকে শ্রেণিবদ্ধ করুন।
| প্রকার | বর্ণনা | কেস ব্যবহার করুন |
|------|---------------|------------|
| **অর্থবোধক সেগমেন্টেশন** | প্রতিটি পিক্সেল একটি ক্লাস লেবেল পায় | স্বায়ত্তশাসিত ড্রাইভিং (রাস্তা, গাড়ি, পথচারী) |
| **ইনস্ট্যান্স সেগমেন্টেশন** | প্রতিটি পিক্সেল + অবজেক্ট ইনস্ট্যান্স আইডি | বস্তু গণনা, মেডিকেল ইমেজিং |
| **প্যানপটিক সেগমেন্টেশন** | শব্দার্থক + উদাহরণ একত্রিত | ব্যাপক দৃশ্য বোঝার |
মূল মডেল: ইউ-নেট (মেডিকেল ইমেজিং), মাস্ক আর-সিএনএন (উদাহরণ), ডিপল্যাব (অর্থবোধক), সেগমেন্ট এনিথিং মডেল (এসএএম — ইউনিভার্সাল সেগমেন্টেশন)।
### ইমেজ জেনারেশন
| দৃষ্টিভঙ্গি | বর্ণনা | উদাহরণ |
|------------|-------------|------------|
| **GANs** | জেনারেটর বনাম বৈষম্যকারী প্রতিপক্ষ প্রশিক্ষণ | স্টাইলগান, সাইকেলগান |
| **VAEs** | সুপ্ত বিতরণ শিখুন; তৈরি করতে নমুনা | ভেরিয়েশনাল অটোএনকোডার |
| **ডিফিউশন মডেল** | পুনরাবৃত্তিমূলকভাবে এলোমেলো শব্দকে অস্বীকার করুন | স্টেবল ডিফিউশন, ডাল-ই, মিডজার্নি |
ইমেজ তৈরির মানের জন্য ডিফিউশন মডেলগুলি মূলত GAN-কে ছাড়িয়ে গেছে।

## দৃষ্টির জন্য শিক্ষা স্থানান্তর
স্ক্র্যাচ থেকে একটি CNN প্রশিক্ষণের জন্য বিশাল ডেটা এবং গণনা প্রয়োজন। ট্রান্সফার লার্নিং আপনাকে লক্ষ লক্ষ ছবিতে (ImageNet) ইতিমধ্যে প্রশিক্ষিত একটি মডেল দিয়ে শুরু করতে দেয় এবং আপনার নির্দিষ্ট কাজের জন্য এটিকে সূক্ষ্ম-টিউন করতে দেয়।
### ধাপ
1. **একটি প্রাক-প্রশিক্ষিত মডেল চয়ন করুন** (ResNet50, EfficientNet-B0, ViT)।
2. **শ্রেণিকরণ শিরোনাম** আপনার নিজের দিয়ে প্রতিস্থাপন করুন (আপনার ক্লাসের সংখ্যার সাথে মিলে যায়)।
3. **প্রাথমিক স্তরগুলিকে হিমায়িত করুন** (তারা প্রান্তের মতো জেনেরিক বৈশিষ্ট্যগুলি ক্যাপচার করে)।
4. কম শেখার হার সহ আপনার ডেটাসেটে **ফাইন-টিউন**।
5. **যদি আপনার আরো অভিযোজন প্রয়োজন হয় তাহলে ধীরে ধীরে আনফ্রিজ করুন**।
এই পদ্ধতিটি নিয়মিতভাবে 1,000-10,000 লেবেলযুক্ত চিত্রগুলির সাথে উচ্চ নির্ভুলতা অর্জন করে।

## ডেটা অগমেন্টেশন
পরিবর্ধন কৃত্রিমভাবে রূপান্তর প্রয়োগ করে আপনার প্রশিক্ষণ ডেটাসেটকে প্রসারিত করে।
| পরিবর্ধন | প্রভাব | কখন ব্যবহার করবেন |
|---------------|---------|---------------|
| **এলোমেলো ফসল** | এলোমেলো অঞ্চলে ক্রপ করুন | প্রায় সবসময় |
| **অনুভূমিক ফ্লিপ** | মিরর ইমেজ | যখন অভিযোজন কোন ব্যাপার না |

## ব্যবহারিক টিপস
- **ট্রান্সফার লার্নিং দিয়ে শুরু করুন। ** একটি প্রাক-প্রশিক্ষিত মডেল ফাইন-টিউনিং প্রায় প্রতিটি ক্ষেত্রেই স্ক্র্যাচ থেকে প্রশিক্ষণকে হার মানায়।
- **আপনার ইনপুটগুলিকে স্বাভাবিক করুন।** প্রাক-প্রশিক্ষিত মডেলের প্রত্যাশার সাথে মিল করুন (সাধারণত ImageNet গড়/std)।
- **উপযুক্ত মেট্রিক্স ব্যবহার করুন।** সুষম ডেটাসেটের জন্য যথার্থতা; ভারসাম্যহীন বা সনাক্তকরণ কাজের জন্য F1, mAP, বা IoU।
- **আপনার ডেটা ভিজ্যুয়ালাইজ করুন।** নমুনা ইমেজ দেখুন, ক্লাস ডিস্ট্রিবিউশন চেক করুন, মডেল ভবিষ্যতবাণী পরিদর্শন করুন।
- **বুদ্ধিমত্তার সাথে বৃদ্ধি করুন।** শুধুমাত্র আপনার ডোমেনের জন্য অর্থপূর্ণ রূপান্তরগুলি প্রয়োগ করুন (মেডিকেল ছবিগুলিকে উল্লম্বভাবে ফ্লিপ করবেন না)।
- **অভারফিটিং মনিটর করুন।** যদি প্রশিক্ষণের সঠিকতা বেশি হয় কিন্তু বৈধতা কম হয়, তাহলে পরিবর্ধন বাড়ান বা ড্রপআউট যোগ করুন।
