# গ্রাফ নিউরাল নেটওয়ার্ক
গ্রাফ নিউরাল নেটওয়ার্ক (GNNs) হল নিউরাল নেটওয়ার্ক যা গ্রাফ-স্ট্রাকচারড ডেটার উপর কাজ করার জন্য ডিজাইন করা হয়েছে — প্রান্ত দ্বারা সংযুক্ত নোডের নেটওয়ার্ক। প্রথাগত নিউরাল নেটওয়ার্ক গ্রিড (ছবি) বা সিকোয়েন্সে (টেক্সট) কাজ করলেও, GNN গুলি স্বেচ্ছাচারী রিলেশনাল স্ট্রাকচার পরিচালনা করে: সোশ্যাল নেটওয়ার্ক, আণবিক গ্রাফ, নলেজ গ্রাফ, রোড নেটওয়ার্ক, সুপারিশ গ্রাফ এবং আরও অনেক কিছু। তারা ড্রাগ আবিষ্কার, জালিয়াতি সনাক্তকরণ, সুপারিশ সিস্টেম, এবং সত্তার মধ্যে সম্পর্ক গুরুত্বপূর্ণ যে কোনো ডোমেনের জন্য অপরিহার্য হয়ে উঠেছে।

|------------|---------------|---------|

| **প্রান্ত** | দুটি নোডের মধ্যে একটি সম্পর্ক | বন্ধুত্ব, রাসায়নিক বন্ধন, রাস্তা |
| **প্রান্ত ওজন** | শক্তি বা সম্পর্কের ধরন | দূরত্ব, সাদৃশ্য, ক্ষমতা |
| **নোড বৈশিষ্ট্য** | প্রতিটি নোডের বৈশিষ্ট্য | বয়স, পারমাণবিক সংখ্যা, জনসংখ্যা |
| **এজ বৈশিষ্ট্য** | প্রতিটি প্রান্তের বৈশিষ্ট্য | সম্পর্কের ধরন, দূরত্ব |

## কেন নিয়মিত নিউরাল নেটওয়ার্ক নয়?
| দৃষ্টিভঙ্গি | কেন এটি ব্যর্থ হয় |
|------------|-------------|
| **ফিড-ফরোয়ার্ড নেটওয়ার্ক** | নির্দিষ্ট আকারের ইনপুট প্রয়োজন; গ্রাফ আকার এবং গঠনে পরিবর্তিত হয় |
| **সিএনএন** | গ্রিড গঠন অনুমান; গ্রাফের কোন নিয়মিত গ্রিড নেই |
| **আরএনএন/ট্রান্সফরমার** | অনুক্রমিক ক্রম অনুমান করে; গ্রাফের কোন স্বাভাবিক ক্রম নেই |
GNN গ্রাফ কাঠামোর উপর সরাসরি কাজ করে, প্রতিটি নোডকে তার প্রতিবেশীদের পরিপ্রেক্ষিতে প্রক্রিয়াকরণ করে এর সমাধান করে।

## কোর জিএনএন আর্কিটেকচার
### বার্তা পাসিং ফ্রেমওয়ার্ক
বেশিরভাগ জিএনএন একই প্যাটার্ন অনুসরণ করে: প্রতিটি নোড তার প্রতিবেশীদের কাছ থেকে তথ্য সংগ্রহ করে, এটিকে একত্রিত করে এবং নিজস্ব প্রতিনিধিত্ব আপডেট করে।
| ধাপ | বর্ণনা |
|------|---------------|
| **1। বার্তা** | প্রতিটি নোড তার প্রতিবেশীদের কাছে একটি বার্তা পাঠায় (তার বর্তমান বৈশিষ্ট্যের উপর ভিত্তি করে) |
| **2। মোট** | প্রতিটি নোড সমস্ত প্রতিবেশীদের থেকে বার্তা সংগ্রহ করে এবং একত্রিত করে |
| **3. আপডেট** | প্রতিটি নোড সমষ্টিগত বার্তা ব্যবহার করে নিজস্ব প্রতিনিধিত্ব আপডেট করে |
| **4. পুনরাবৃত্তি** | K স্তরগুলির জন্য এটি করুন → প্রতিটি নোড K হপস দূরে থেকে তথ্য ক্যাপচার করে |
### মূল GNN মডেল
| মডেল | একত্রীকরণ পদ্ধতি | মূল উদ্ভাবন |
|---------|----------------------------|
| **GCN** (গ্রাফ কনভোলিউশনাল নেটওয়ার্ক) | প্রতিবেশী বৈশিষ্ট্যের গড় | সরল; কার্যকরী বর্ণালী প্রেরণা |
| **গ্রাফসেজ** | নমুনা এবং সমষ্টি; গড়, LSTM, বা পুলিং | প্রবর্তক (অদেখা নোড পরিচালনা করে); মাপযোগ্য |
| **GAT** (গ্রাফ অ্যাটেনশন নেটওয়ার্ক) | মনোযোগ-ভারিত প্রতিবেশী সমষ্টি | কোন প্রতিবেশী সবচেয়ে গুরুত্বপূর্ণ তা শিখে |
| **GIN** (গ্রাফ আইসোমরফিজম নেটওয়ার্ক) | প্রতিবেশী বৈশিষ্ট্যের সমষ্টি | সর্বাধিক অভিব্যক্তিপূর্ণ; WL পরীক্ষা দ্বারা আলাদা করা যায় এমন যেকোনো গ্রাফকে আলাদা করতে পারে |
| **MPNN** (মেসেজ পাসিং নিউরাল নেটওয়ার্ক) | সাধারণ বার্তা পাসিং কাঠামো | অনেক GNN রূপকে একীভূত করে |
### কিভাবে GCN কাজ করে (ধাপে ধাপে)
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

K স্তরের পরে, প্রতিটি নোডের উপস্থাপনা K থেকে তথ্য গ্রাফে এনকোড করে।

## সারাংশ
গ্রাফ নিউরাল নেটওয়ার্কগুলি রিলেশনাল ডেটা - নেটওয়ার্ক, অণু, নলেজ গ্রাফ এবং যে কোনও সিস্টেম যেখানে সত্তা সংযুক্ত থাকে সেগুলিতে গভীর শিক্ষাকে প্রসারিত করে। তারা প্রতিবেশীদের মধ্যে বার্তা প্রেরণ করে কাজ করে, প্রতিটি নোডকে তার স্থানীয় প্রসঙ্গ থেকে শিখতে দেয়। GNNs ড্রাগ আবিষ্কার, সুপারিশ সিস্টেম, জালিয়াতি সনাক্তকরণ, এবং জ্ঞান গ্রাফে তাদের শক্তিশালী অ্যাপ্লিকেশন খুঁজে পেয়েছে। ক্ষেত্রটি গ্রাফ ট্রান্সফরমার, ভিন্নধর্মী গ্রাফ এবং বিশাল বাস্তব-বিশ্ব নেটওয়ার্কের জন্য মাপযোগ্য প্রশিক্ষণের দিকে বিকশিত হচ্ছে। যদি আপনার ডেটার সম্পর্ক থাকে, তাহলে GNNগুলি সম্ভবত বিবেচনা করার মতো।
