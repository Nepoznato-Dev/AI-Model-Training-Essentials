# ডেটা ইঞ্জিনিয়ারিং এবং পাইপলাইন
ডেটা ইঞ্জিনিয়ারিং হল সিস্টেমগুলি তৈরি করার শৃঙ্খলা যা স্কেলে ডেটা স্থানান্তর, রূপান্তর এবং সঞ্চয় করে। নির্ভরযোগ্য ডেটা পাইপলাইন ব্যতীত, মেশিন লার্নিং মডেলগুলিকে প্রশিক্ষিত করা যায় না, ড্যাশবোর্ডগুলি পুরানো নম্বরগুলি দেখায় এবং ব্যবসায়িক সিদ্ধান্তগুলি অনুমানের উপর ভিত্তি করে। এই ফাইলটি কাজ করে এমন ডেটা অবকাঠামো তৈরির জন্য আর্কিটেকচার, টুলস এবং অনুশীলনগুলি কভার করে।
---

## ইটিএল বনাম ইএলটি
| দৃষ্টিভঙ্গি | এটা কিভাবে কাজ করে | জন্য সেরা | টুলস |
|------------|-------------|------------|-------|
| **ETL** (এক্সট্রাক্ট → ট্রান্সফর্ম → লোড) | গুদামে লোড করার *আগে* ডেটা রূপান্তর করুন | সীমিত গণনা সহ ঐতিহ্যবাহী গুদাম | ইনফরমেটিকা, ট্যালেন্ড, অ্যাপাচি নিফাই |
| **ELT** (এক্সট্র্যাক্ট → লোড → ট্রান্সফর্ম) | প্রথমে কাঁচা ডেটা লোড করুন; গুদাম *ভিতরে* রূপান্তর করুন | ইলাস্টিক কম্পিউট সহ আধুনিক ক্লাউড গুদাম | dbt, Fivetran, Airbyte + BigQuery/Snowflake |
ETL থেকে ELT-এ স্থানান্তরটি ক্লাউড ডেটা গুদাম (BigQuery, Snowflake, Redshift) দ্বারা চালিত হয়েছে যা স্টোরেজ থেকে স্বাধীনভাবে গণনা করতে পারে। লোড করার আগে সবকিছু প্রি-প্রসেস করার আর প্রয়োজন নেই।

## ডেটা লেক বনাম ডেটা গুদাম
| বৈশিষ্ট্য | ডাটা লেক | ডেটা গুদাম |
|---------|------------|---------------|
| **ডেটা ফরম্যাট** | কাঁচা, নেটিভ ফরম্যাট (স্কিমা-অন-রিড) | স্ট্রাকচার্ড, প্রসেসড (স্কিমা-অন-রাইট) |
| **স্কিমা** | প্রশ্নের সময় সংজ্ঞায়িত | লোড করার আগে সংজ্ঞায়িত |
| **ডেটা প্রকার** | কাঠামোগত, আধা-কাঠামোগত, অসংগঠিত | প্রাথমিকভাবে কাঠামোগত |
| **ব্যবহারকারী** | তথ্য বিজ্ঞানী, প্রকৌশলী | ব্যবসা বিশ্লেষক, BI টুলস |
| **খরচ** | সস্তা স্টোরেজ (অবজেক্ট স্টোরেজ) | আরো ব্যয়বহুল (কোয়েরির জন্য অপ্টিমাইজড) |
| **উদাহরণ** | AWS S3, Azure Data Lake, GCS | স্নোফ্লেক, BigQuery, Redshift |
আধুনিক পদ্ধতি হল **লেকহাউস**: একটি গুদামের ব্যবস্থাপনা এবং কর্মক্ষমতা বৈশিষ্ট্যগুলির সাথে একটি হ্রদের সস্তা, নমনীয় স্টোরেজকে একত্রিত করুন। ডেল্টা লেক, অ্যাপাচি আইসবার্গ এবং অ্যাপাচি হুডি হল এখানকার মূল প্রযুক্তি।

## অ্যাপাচি কাফকা
কাফকা অনেক রিয়েল-টাইম ডেটা সিস্টেমের মেরুদণ্ড। এটি একটি বিতরণকৃত ইভেন্ট লগ যা উচ্চ-থ্রুপুট, ত্রুটি-সহনশীল বার্তা প্রদান করে।
### মূল ধারণা
| ধারণা | বর্ণনা |
|---------|---------------|
| **বিষয়** | বার্তাগুলির একটি বিভাগ (যেমন,`orders`,`user-events`) |
| **বিভাজন** | বিষয়গুলি সমান্তরালতার জন্য পার্টিশনে বিভক্ত
| **প্রযোজক** | অ্যাপ্লিকেশন যা বিষয়গুলিতে বার্তা লেখে |
| **ভোক্তা** | অ্যাপ্লিকেশন যা বিষয়গুলি থেকে বার্তাগুলি পড়ে |
| **ভোক্তা গ্রুপ** | ভোক্তাদের গ্রুপ যারা একটি বিষয় পড়ার লোড শেয়ার করে |
| **অফসেট** | একটি পার্টিশনের মধ্যে একজন ভোক্তার অবস্থান |
| **দালাল** | একটি কাফকা সার্ভার নোড |
### কখন কাফকা ব্যবহার করবেন
- **ইভেন্ট স্ট্রিমিং**: স্কেলে রিয়েল-টাইম ইভেন্ট প্রক্রিয়াকরণ।
- **ডিকপলিং পরিষেবা**: প্রযোজক এবং ভোক্তাদের একে অপরের সম্পর্কে জানার প্রয়োজন নেই।
- **পুনরায় চালান**: বার্তাগুলি রাখা হয়; গ্রাহকরা যেকোনো অফসেট থেকে পুনরায় পড়তে পারেন।
- **ব্যাকপ্রেশার**: কাফকা স্বাভাবিকভাবেই প্রযোজক এবং ভোক্তাদের মধ্যে গতির পার্থক্য পরিচালনা করে।

| **ফিচার মনিটরিং** | ড্রিফট, অনুপস্থিত মান, বন্টন পরিবর্তন সনাক্ত করুন |
| টুল | বর্ণনা |
|------|---------------|

## ডেটা গভর্নেন্স
ডেটা গভর্নেন্স নিশ্চিত করে যে সমস্ত সংস্থা জুড়ে ডেটা দায়িত্বের সাথে পরিচালিত হয়।
| এলাকা | বর্ণনা |
|------|---------------|
| **ডেটা ক্যাটালগ** | মেটাডেটা (Amundsen, DataHub, Atlan) সহ ডেটাসেটের অনুসন্ধানযোগ্য তালিকা |
| **ডেটা বংশ** | ট্র্যাক কোথা থেকে ডেটা আসে এবং কীভাবে এটি রূপান্তরিত হয় |
| **অ্যাক্সেস কন্ট্রোল** | ভূমিকা-ভিত্তিক অনুমতি; কে কি পড়তে/লিখতে পারে |
| **সম্মতি** | GDPR, CCPA, HIPAA মেনে চলা |
| **ডেটা মালিকানা** | প্রতিটি ডেটাসেটের জন্য মালিকানা পরিষ্কার করুন (স্টুয়ার্ডশিপ) |
| **ধারণ নীতি** | কতক্ষণ ডেটা রাখা হয় এবং কখন মুছে ফেলা হয় তা নির্ধারণ করুন

## আধুনিক ডেটা স্ট্যাক
"আধুনিক ডেটা স্ট্যাক" বলতে বোঝায় আজকের ডেটা টিম দ্বারা ব্যবহৃত সরঞ্জামগুলির সাধারণ সংমিশ্রণ:
| স্তর | সাধারণ সরঞ্জাম |
|---------|---------------|
| **ইনজেশন** | ফাইভট্রান, এয়ারবাইট |
| **গুদাম** | স্নোফ্লেক, BigQuery, Redshift |
| **পরিবর্তন** | dbt |
| **অর্কেস্ট্রেশন** | বায়ুপ্রবাহ, প্রিফেক্ট, ড্যাগস্টার |
| **BI / ভিজ্যুয়ালাইজেশন** | লুকার, মেটাবেস, মূকনাট্য |
| **বিপরীত ETL** | আদমশুমারি, হাইটাচ (গুদাম ডেটা সিঙ্ক করুন টুলগুলিতে ফিরে আসে) |
| **ডেটা কোয়ালিটি** | মহান প্রত্যাশা, মন্টে কার্লো |
প্রবণতাটি একচেটিয়া প্ল্যাটফর্মের পরিবর্তে ওপেন স্ট্যান্ডার্ড (এসকিউএল, ডিবিটি মডেল, এয়ারফ্লো ডিএজি) দ্বারা সংযুক্ত মডুলার, সেরা-প্রজাতির সরঞ্জামগুলির দিকে।
