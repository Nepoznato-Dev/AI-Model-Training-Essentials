# মেশিন লার্নিং ইভালুয়েশন এবং ওয়ার্কফ্লো
ML লাইফসাইকেলের একটি ব্যবহারিক গাইড — সমস্যা ফ্রেমিং থেকে প্রোডাকশন মনিটরিং পর্যন্ত — মেট্রিক্স, ভ্যালিডেশন এবং ডিবাগিংয়ের উপর ফোকাস সহ।
---

## এমএল ওয়ার্কফ্লো (CRISP-ML)
1. **ব্যবসায়িক বোঝাপড়া**: উদ্দেশ্য এবং সাফল্যের মানদণ্ড সংজ্ঞায়িত করুন।
2. **ডেটা বোঝার**: উপলব্ধ ডেটা অন্বেষণ করুন, গুণমানের সমস্যা চিহ্নিত করুন।
3. **ডেটা প্রস্তুতি**: ডেটা পরিষ্কার, রূপান্তর এবং বিভক্ত করুন।
4. **মডেলিং**: ট্রেনের মডেল, টিউন হাইপারপ্যারামিটার।
5. **মূল্যায়ন**: মেট্রিক্সের বিপরীতে কর্মক্ষমতা মূল্যায়ন করুন।
6. **ডিপ্লয়মেন্ট**: উৎপাদনে মডেল পরিবেশন করুন।
7. **মনিটরিং**: ট্র্যাক ড্রিফট, কর্মক্ষমতা, এবং অসঙ্গতি।
এটি একটি পুনরাবৃত্ত লুপ — আপনি মূল্যায়ন ফলাফলের উপর ভিত্তি করে আগের ধাপগুলি পুনরায় দেখতে পাবেন।
---

## ডেটা স্প্লিটিং
### ট্রেন / বৈধতা / টেস্ট স্প্লিট
- **প্রশিক্ষণ সেট** (~70%): মডেল প্যারামিটারের সাথে মানানসই করতে ব্যবহৃত হয়।
- **ভ্যালিডেশন সেট** (~15%): হাইপারপ্যারামিটার টিউন করতে এবং মডেল ভেরিয়েন্ট নির্বাচন করতে ব্যবহৃত হয়।
- **পরীক্ষা সেট** (~15%): সাধারণীকরণ কার্যক্ষমতা অনুমান করতে একেবারে শেষে শুধুমাত্র একবার ব্যবহার করা হয়।
**গুরুত্বপূর্ণ:** ডেটা ফাঁস এড়াতে চূড়ান্ত মূল্যায়ন না হওয়া পর্যন্ত পরীক্ষার সেটটিকে অবশ্যই সম্পূর্ণরূপে অস্পর্শ রাখতে হবে।
### ক্রস-ভ্যালিডেশন (k-ভাঁজ)
ছোট ডেটাসেটের জন্য, k-ভাঁজ ক্রস-ভ্যালিডেশন ব্যবহার করুন: k ভাঁজগুলিতে ডেটা বিভক্ত করুন, k-1-এ ট্রেন করুন, বাকিগুলিতে যাচাই করুন এবং k বার পুনরাবৃত্তি করুন। পারফরম্যান্সের গড়। k=5 বা k=10 সাধারণ।
### স্তরিত বিভাজন
ভারসাম্যহীন শ্রেণীগুলির সাথে শ্রেণীবিভাগের জন্য, প্রতিটি উপসেটে শ্রেণী অনুপাত সংরক্ষণের জন্য স্তরিত বিভাজন ব্যবহার করুন।
### সময়-ভিত্তিক বিভাজন
টাইম-সিরিজ ডেটার জন্য, এলোমেলোভাবে না করে কালানুক্রমিকভাবে বিভক্ত করুন (অতীতের উপর ট্রেন, ভবিষ্যতের পরীক্ষা)।

## মূল্যায়ন মেট্রিক্স
### শ্রেণিবিন্যাস মেট্রিক্স
| মেট্রিক | এটা কি পরিমাপ করে | সর্বোত্তম ব্যবহৃত |
|---------|---------|---------------|
| **নির্ভুলতা** | (TP + TN) / (TP + TN + FP + FN) | সুষম ডেটাসেট |
| **নির্ভুলতা** | TP / (TP + FP) | যখন মিথ্যা ইতিবাচক ব্যয়বহুল (যেমন, স্প্যাম সনাক্তকরণ) |
| **রিকল** | TP / (TP + FN) | যখন মিথ্যা নেতিবাচক ব্যয়বহুল (যেমন, ক্যান্সার স্ক্রীনিং) |
| **F1-স্কোর** | নির্ভুলতা এবং প্রত্যাহার হারমোনিক গড় | ভারসাম্যহীন ডেটাসেট, একক-সংখ্যা মেট্রিক |
| **AUC-ROC** | ROC বক্ররেখা অধীনে এলাকা; TPR এবং FPR এর মধ্যে ট্রেডঅফ | থ্রেশহোল্ড থেকে স্বাধীন সাধারণ ক্লাসিফায়ার কর্মক্ষমতা |
| **AUC-PR** | যথার্থ-রিকল বক্ররেখার অধীনে এলাকা | অত্যন্ত ভারসাম্যহীন ডেটাসেট |
**সংজ্ঞা:**
- TP = সত্য ইতিবাচক
- TN = সত্য নেতিবাচক
- FP = মিথ্যা ইতিবাচক (টাইপ I ত্রুটি)
- FN = মিথ্যা নেতিবাচক (টাইপ II ত্রুটি)
### রিগ্রেশন মেট্রিক্স
| মেট্রিক | এটা কি পরিমাপ করে | বহিরাগতদের প্রতি সংবেদনশীলতা |
|---------|------------------|----------------------------|
| **MSE** (মান বর্গীয় ত্রুটি) | গড় বর্গ পার্থক্য | উচ্চ |
| **RMSE** (রুট গড় বর্গাকার ত্রুটি) | MSE এর বর্গমূল (লক্ষ্য হিসাবে একই ইউনিট) | উচ্চ |
| **MAE** (মান সম্পূর্ণ ত্রুটি) | গড় পরম পার্থক্য | কম |
| **R²** (নির্ধারণের সহগ) | প্রকরণের অনুপাত ব্যাখ্যা করা হয়েছে | সরাসরি কোনোটিই নয়, কিন্তু পরোক্ষভাবে বহিরাগতদের প্রতি সংবেদনশীল |
### র‍্যাঙ্কিং এবং পুনরুদ্ধার মেট্রিক্স
- **Precision@k**: টপ-কে সুপারিশের মধ্যে প্রাসঙ্গিক আইটেমের ভগ্নাংশ।
- **Recall@k**: সমস্ত প্রাসঙ্গিক আইটেমের ভগ্নাংশ যা টপ-কে-তে প্রদর্শিত হয়।
- **NDCG** (নর্মালাইজড ডিসকাউন্টেড কিউমুলেটিভ গেইন): অবস্থান প্রাসঙ্গিকতার জন্য অ্যাকাউন্ট।
- **হিট রেট**: টপ-কেতে একটি প্রাসঙ্গিক আইটেম প্রদর্শিত হবে কিনা।
### জেনারেটিভ / এলএলএম মেট্রিক্স
- **বিভ্রান্তি**: একটি আটকে রাখা পাঠ্য দ্বারা মডেলটি কতটা "বিস্মিত" হয় (নিম্ন হলে ভাল)৷
- **BLEU**: রেফারেন্স অনুবাদের সাথে n-গ্রাম ওভারল্যাপ (নির্ভুলতা-কেন্দ্রিক)।
- **ROUGE**: সারসংক্ষেপের জন্য স্মরণ-ভিত্তিক ওভারল্যাপ।
- **BERTScore**: প্রাসঙ্গিক এম্বেডিং ব্যবহার করে শব্দার্থিক সাদৃশ্য (BLEU এর চেয়ে বেশি শক্তিশালী)।
- **উল্কা**: WordNet প্রতিশব্দ এবং কান্ডের সাথে সারিবদ্ধ করে।

## মূল্যায়ন ত্রুটি
### ডেটা লিকেজ
ঘটে যখন পরীক্ষার সেট থেকে তথ্য অসাবধানতাবশত প্রশিক্ষণকে প্রভাবিত করে।
- **প্রতিরোধ করুন:** ফিচার ইঞ্জিনিয়ারিং, নরমালাইজেশন বা হাইপারপ্যারামিটার টিউনিংয়ের জন্য কখনই পরীক্ষার ডেটা ব্যবহার করবেন না।
- **শনাক্ত করুন:** আপনার মডেলের স্কোর সন্দেহজনকভাবে বেশি হলে, ফুটো হওয়ার সন্দেহ।
### ওভারফিটিং
মডেল ট্রেনিং ডেটাতে ভাল পারফর্ম করে কিন্তু বৈধতা/পরীক্ষায় খারাপ।
- **প্রশমিত করুন:** নিয়মিতকরণ ব্যবহার করুন, তাড়াতাড়ি বন্ধ করুন, আর্কিটেকচারকে সরল করুন, বা আরও ডেটা সংগ্রহ করুন৷
### আন্ডারফিটিং
প্রশিক্ষণ এবং বৈধতা উভয় ক্ষেত্রে মডেলটি খারাপভাবে কাজ করে।
- **প্রশমিত করুন:** একটি আরও জটিল মডেল ব্যবহার করুন, বৈশিষ্ট্য যোগ করুন বা নিয়মিতকরণ হ্রাস করুন৷
### ভারসাম্যহীন ডেটা
- **মিটিগেট:** ক্লাস ওয়েট, ওভারস্যাম্পল (SMOTE), আন্ডারস্যাম্পল ব্যবহার করুন বা সঠিকতার পরিবর্তে উপযুক্ত মেট্রিক্স (F1, AUC-PR) ব্যবহার করুন।
### টেম্পোরাল ড্রিফ্ট (কনসেপ্ট ড্রিফ্ট)
বৈশিষ্ট্য এবং লক্ষ্যের মধ্যে সম্পর্ক সময়ের সাথে পরিবর্তিত হয়।
- **প্রশমিত করুন:** পর্যায়ক্রমে পুনরায় প্রশিক্ষণ দিন, কর্মক্ষমতা নিরীক্ষণ করুন, ড্রিফট সনাক্তকরণ অ্যালগরিদম ব্যবহার করুন।

## হাইপারপ্যারামিটার টিউনিং
- **গ্রিড অনুসন্ধান**: হাইপারপ্যারামিটারের একটি পূর্বনির্ধারিত সেটের সমস্ত সমন্বয় সম্পূর্ণভাবে চেষ্টা করুন। সহজ কিন্তু গণনাগতভাবে ব্যয়বহুল।
- **এলোমেলো অনুসন্ধান**: বিতরণ থেকে নমুনা এলোমেলো সমন্বয়। উচ্চ-মাত্রিক স্থানগুলির জন্য গ্রিড অনুসন্ধানের চেয়ে বেশি দক্ষ৷
- **বায়েসিয়ান অপ্টিমাইজেশন**: অবজেক্টিভ ফাংশনের একটি সম্ভাব্য মডেল তৈরি করে এবং হাইপারপ্যারামিটার বুদ্ধিমত্তার সাথে নির্বাচন করে। লাইব্রেরি: Optuna, Hyperopt, scikit-optimise.
- **অটোমেটেড টিউনিং**: ডিস্ট্রিবিউটেড টিউনিংয়ের জন্য অপটুনা, রে টিউন, বা ওয়েটস অ্যান্ড বায়েস সুইপসের মতো টুল ব্যবহার করুন।
**সাধারণ হাইপারপ্যারামিটারের জন্য প্রস্তাবিত অনুসন্ধান ব্যাপ্তি:**
| পরামিতি | প্রস্তাবিত পরিসর (লগ-স্কেল) |
|------------ |-------------------------------------------- |
| শেখার হার | 1e-5 থেকে 1e-1 |
| ব্যাচ আকার | 16, 32, 64, 128, 256 |
| স্তরের সংখ্যা (NN) | 2 থেকে 6 |
| নিউরনের সংখ্যা (NN) | 32 থেকে 1024 |
| নিয়মিতকরণ (L2) | 1e-6 থেকে 1e-2 |
| গাছের গভীরতা (XGBoost) | 3 থেকে 12 |

## মডেল নির্বাচন এবং বৈধতা
1. **বেসলাইন মডেল**: একটি নিম্ন সীমানা স্থাপন করতে একটি সাধারণ হিউরিস্টিক বা সাধারণ মডেল (যেমন, লজিস্টিক রিগ্রেশন, গড় ভবিষ্যদ্বাণী) দিয়ে শুরু করুন।
2. **প্রার্থী মডেল**: একাধিক মডেল পরিবারকে প্রশিক্ষণ দিন (যেমন, র্যান্ডম ফরেস্ট, XGBoost, নিউরাল নেটওয়ার্ক)।
3. **ক্রস-ভ্যালিডেট** বৈধকরণ সেটে প্রতিটি প্রার্থী।
4. **মেট্রিক্স তুলনা করুন** (আস্থার ব্যবধান সহ) এবং সেরা প্রার্থী নির্বাচন করুন।
5. অনুষ্ঠিত পরীক্ষার সেটে **চূড়ান্ত মূল্যায়ন**।
6. **ত্রুটি বিশ্লেষণ**: মডেলটি ভুল হয়েছে উদাহরণগুলি দেখুন। প্যাটার্নগুলি সনাক্ত করুন (যেমন, বিরল ক্লাস, অস্পষ্ট ইনপুট) এবং ডেটা প্রস্তুতি বা বৈশিষ্ট্য প্রকৌশলে ফিরে অন্তর্দৃষ্টি ফিড করুন।

## স্থাপনা এবং মনিটরিং
### পরিবেশন নিদর্শন
- **ব্যাচের অনুমান**: অফলাইনে প্রচুর পরিমাণে ডেটা প্রক্রিয়া করুন (যেমন, রাতের জন্য সুপারিশ)।
- **অনলাইন অনুমান**: API এর মাধ্যমে রিয়েল-টাইম ভবিষ্যদ্বাণী (যেমন, ক্রেডিট স্কোরিং, জালিয়াতি সনাক্তকরণ)।
- **স্ট্রিমিং অনুমান**: ইভেন্ট-চালিত, কম লেটেন্সি সহ রিয়েল-টাইম (যেমন, IoT সেন্সর সতর্কতা)।
### মডেল মনিটরিং
- **পারফরমেন্স মনিটরিং**: লাইভ ডেটাতে সময়ের সাথে সাথে সঠিকতা/F1 ট্র্যাক করুন (যখন গ্রাউন্ড ট্রুথ উপলব্ধ থাকে)।
- **ডেটা ড্রিফ্ট**: ইনপুট বৈশিষ্ট্য বিতরণে পরিবর্তনগুলি পর্যবেক্ষণ করুন (যেমন, PSI - জনসংখ্যা স্থিতিশীলতা সূচক ব্যবহার করে)।
- **কনসেপ্ট ড্রিফ্ট**: ইনপুট এবং আউটপুটগুলির মধ্যে সম্পর্কের পরিবর্তনগুলি নিরীক্ষণ করুন৷
- **ভবিষ্যদ্বাণী ড্রিফ্ট**: পূর্বাভাসিত আউটপুটগুলির বিতরণ ট্র্যাক করুন৷
- **লেটেন্সি এবং থ্রুপুট**: নিশ্চিত করুন যে SLAs (সার্ভিস লেভেল এগ্রিমেন্ট) পূরণ হয়েছে।
### লগিং এবং সতর্কতা
- সমস্ত ভবিষ্যদ্বাণী অনুরোধ এবং প্রতিক্রিয়া (অজ্ঞাতনামা সহ) লগ করুন।
- এর জন্য সতর্কতা সেট করুন:
  - কর্মক্ষমতা উল্লেখযোগ্য ড্রপ.
  - অনুপস্থিত বা অবৈধ ইনপুটগুলির উচ্চ শতাংশ।
  - প্রত্যাশিত সীমার বাইরে মডেল আউটপুট।
### মডেল সংস্করণ এবং রেজিস্ট্রি
- একটি মডেল রেজিস্ট্রি ব্যবহার করুন (যেমন, MLflow, Weights & Biases, Sagemaker Model Registry) এবং সংস্করণের মডেল, মেটাডেটা এবং মূল্যায়ন ফলাফল সংরক্ষণ করতে।
- মডেলের পাশাপাশি ট্রেনিং কোড এবং ডেটা সংস্করণ (DVC বা Git LFS এর মাধ্যমে) সংরক্ষণ করুন।
