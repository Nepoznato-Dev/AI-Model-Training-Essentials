# সংযোজন পদ্ধতি
এনসেম্বল পদ্ধতিগুলি একাধিক মেশিন লার্নিং মডেলকে একত্রিত করে যে কোনও একক মডেল একা অর্জন করতে পারে তার চেয়ে ভাল ভবিষ্যদ্বাণী তৈরি করে। অন্তর্দৃষ্টি সহজবোধ্য: যদি আপনার কাছে বেশ কয়েকটি মডেল থাকে যা প্রতিটি কিছুটা নির্ভুল কিন্তু বিভিন্ন ত্রুটি করে, তাদের ভবিষ্যদ্বাণীগুলিকে একত্রিত করা স্বতন্ত্র ভুলগুলি বাতিল করবে এবং আরও শক্তিশালী ফলাফল দেবে৷ এনসেম্বলগুলি বেশিরভাগ প্রতিযোগিতামূলক মেশিন লার্নিং সমাধানগুলির পিছনে রয়েছে এবং উত্পাদন ব্যবস্থার সবচেয়ে নির্ভরযোগ্য কৌশলগুলির মধ্যে রয়েছে।

## কেন Ensembles কাজ
| নীতি | বর্ণনা |
|------------|-------------|
| **জনতার জ্ঞান** | একাধিক অপূর্ণ অনুমান, গড়, যে কোনো একক অনুমানের চেয়ে ভালো |
| **পক্ষপাত-ভেরিয়েন্স ট্রেড-অফ** | এনসেম্বল অন্যকে ত্যাগ না করে ভিন্নতা (ব্যাগিং) বা পক্ষপাত (বুস্টিং) কমাতে পারে |
| **ত্রুটির বৈচিত্র্য** | যদি মডেলগুলি বিভিন্ন ত্রুটি করে, সেগুলিকে একত্রিত করা পৃথক ভুলগুলি বাতিল করে |
| **সিদ্ধান্তের সীমানা মসৃণ করা** | একাধিক মডেল একটি মডেলের চেয়ে আরও শক্তিশালী সিদ্ধান্তের পৃষ্ঠ তৈরি করে |

## ব্যাগিং (বুটস্ট্র্যাপ এগ্রিগেটিং)
### এটা কিভাবে কাজ করে
| ধাপ | বর্ণনা |
|------|---------------|
| **1। বুটস্ট্র্যাপ স্যাম্পলিং** | প্রশিক্ষণের তথ্য থেকে একাধিক এলোমেলো নমুনা (প্রতিস্থাপন সহ) আঁকুন |
| **2। ট্রেনের বেস মডেল** | প্রতিটি বুটস্ট্র্যাপ নমুনায় একটি মডেল প্রশিক্ষিত করুন (সাধারণত সিদ্ধান্ত গাছ) |
| **3. মোট** | রিগ্রেশনের জন্য: গড় ভবিষ্যদ্বাণী। শ্রেণীবিভাগের জন্য: সংখ্যাগরিষ্ঠ ভোট |
### মূল বৈশিষ্ট্য
| চারিত্রিক | বর্ণনা |
|---------------|---------------|
| **ভেদ কমায়** | গড় পৃথক মডেলের ওঠানামাকে মসৃণ করে |
| **সমান্তরাল প্রশিক্ষণ** | প্রতিটি বেস মডেল স্বাধীন; একই সাথে প্রশিক্ষিত হতে পারে |
| **ব্যাগের বাইরে মূল্যায়ন** | প্রতিটি নমুনা কিছু বুটস্ট্র্যাপ নমুনা বাদ দেওয়া হয়; যাচাইকরণের জন্য সেগুলি ব্যবহার করুন |
| **সজ্জা** | প্রতিটি বিভাজনে এলোমেলো বৈশিষ্ট্য নির্বাচন গাছের মধ্যে পারস্পরিক সম্পর্ক হ্রাস করে |
### এলোমেলো বন
| দৃষ্টিভঙ্গি | বর্ণনা |
|---------|-------------|
| **বেস লার্নার** | সিদ্ধান্ত গাছ |
| **মূল সংযোজন** | প্রতিটি বিভাজনে, শুধুমাত্র বৈশিষ্ট্যগুলির একটি এলোমেলো উপসেট বিবেচনা করুন (সাধারণত sqrt(n_features)) |
| **কেন এটা কাজ করে** | এলোমেলো বৈশিষ্ট্য নির্বাচন গাছকে সজ্জিত করে, দলটিকে আরও মজবুত করে তোলে |
| **হাইপারপ্যারামিটার** | গাছের সংখ্যা; সর্বোচ্চ গভীরতা; পাতা প্রতি মিনিট নমুনা; সর্বাধিক বৈশিষ্ট্য |
| **শক্তি** | উচ্চ-মাত্রিক ডেটা পরিচালনা করে; বহিরাগতদের জন্য শক্তিশালী; বৈশিষ্ট্য গুরুত্ব প্রদান করে |
| **দুর্বলতা** | একক গাছের চেয়ে কম ব্যাখ্যাযোগ্য; কোলাহলপূর্ণ রিগ্রেশন টাস্কে ওভারফিট করতে পারে |

## বুস্টিং
### এটা কিভাবে কাজ করে
| ধাপ | বর্ণনা |
|------|---------------|
| **1। ট্রেনের প্রথম মডেল** | ডেটাতে একটি বেস মডেল (প্রায়শই একটি অগভীর গাছ / "স্টাম্প") প্রশিক্ষণ দিন |
| **2। ত্রুটি চিহ্নিত করুন** | মডেলটি ভুল হয়েছে কোন উদাহরণ খুঁজুন |
| **3. পরবর্তী মডেলের ট্রেন** | ভুলগুলির উপর দৃষ্টি নিবদ্ধ করে একটি নতুন মডেলকে প্রশিক্ষণ দিন (পুনরায় ওজনযুক্ত বা অবশিষ্ট-যুক্ত) |
| **4. ক্রমানুসারে একত্রিত করুন** | প্রতিটি নতুন মডেল পূর্ববর্তী সমস্ত মডেলের জমে থাকা ত্রুটিগুলি সংশোধন করে |
| **5। পুনরাবৃত্তি** | একটি নির্দিষ্ট সংখ্যক রাউন্ডের জন্য চালিয়ে যান |
### বুস্টিং অ্যালগরিদম
| অ্যালগরিদম | লস ফাংশন | মূল বৈশিষ্ট্য |
|------------|---------------|-------------|
| **AdaBoost** | সূচকীয় | ভুল শ্রেণিবদ্ধ দৃষ্টান্তগুলি পুনরায় ওজন করে; সহজ শব্দ সংবেদনশীল |
| **গ্রেডিয়েন্ট বুস্টিং** | কোন পার্থক্যযোগ্য ক্ষতি | অবশিষ্টাংশ ফিট করে (ক্ষতির গ্রেডিয়েন্ট); আরো নমনীয় |
| **XGBoost** | নিয়মিত গ্রেডিয়েন্ট বুস্টিং | L1/L2 নিয়মিতকরণ; দ্বিতীয় ক্রম গ্রেডিয়েন্ট; হার্ডওয়্যার অপ্টিমাইজেশান |
| **LightGBM** | গ্রেডিয়েন্ট-ভিত্তিক একপাশে নমুনা | পাতা অনুসারে বৃদ্ধি; হিস্টোগ্রাম ভিত্তিক; বড় ডেটাসেটে দ্রুত |
| **ক্যাটবুস্ট** | বুস্টিং আদেশ | শ্রেণীগত বৈশিষ্ট্য স্থানীয়ভাবে পরিচালনা করে; ওভারফিটিং কমায় |
### বুস্টিং বনাম ব্যাগিং
| মাত্রা | ব্যাগিং | বুস্টিং |
|------------|---------|------------|
| **প্রশিক্ষণ** | সমান্তরাল | অনুক্রমিক |
| **ফোকাস** | বৈচিত্র্য হ্রাস করে | পক্ষপাত কমায় |
| **বেস মডেল** | উচ্চ-প্রকরণ, নিম্ন-পক্ষপাত (গভীর গাছ) | কম বৈচিত্র্য, উচ্চ-পক্ষপাত (অগভীর গাছ / স্টাম্প) |
| **কম্বিনেশন** | সমান ওজন | কর্মক্ষমতা দ্বারা ওজন করা |
| **ওভারফিটিং** | কম প্রবণ | খুব বেশি রাউন্ড হলে ওভারফিট করতে পারেন |
| **শব্দ সংবেদনশীলতা** | মজবুত | কোলাহলপূর্ণ ডেটার প্রতি সংবেদনশীল |

## স্ট্যাকিং
### এটা কিভাবে কাজ করে
| ধাপ | বর্ণনা |
|------|---------------|
| **1। ট্রেনের বেস মডেল** | বিভিন্ন মডেলের প্রশিক্ষণ দিন (যেমন, এলোমেলো বন, SVM, নিউরাল নেটওয়ার্ক, গ্রেডিয়েন্ট বুস্টিং) |
| **2। ভবিষ্যদ্বাণী তৈরি করুন** | ইনপুট বৈশিষ্ট্য হিসাবে আউট-অফ-ফোল্ড পূর্বাভাস (ক্রস-ভ্যালিডেশন) ব্যবহার করুন |
| **3. ট্রেন মেটা-মডেল** | বেস মডেলের ভবিষ্যদ্বাণীতে একটি দ্বিতীয়-স্তরের মডেলকে প্রশিক্ষণ দিন |
| **4. চূড়ান্ত ভবিষ্যদ্বাণী** | বেস মডেল ভবিষ্যদ্বাণী; মেটা-মডেল তাদের ভবিষ্যদ্বাণীগুলিকে একত্রিত করে |
### স্ট্যাকিং সেরা অভ্যাস
| অনুশীলন | কারণ |
|------------|---------|
| **বিভিন্ন বেস মডেল ব্যবহার করুন** | বিভিন্ন অ্যালগরিদম বিভিন্ন ত্রুটি করে; বৈচিত্র্য সমগ্র বিন্দু |
| **বেস ভবিষ্যদ্বাণীর জন্য ক্রস-ভ্যালিডেশন ব্যবহার করুন** | ওভারফিট বেস মডেলগুলিকে কাজে লাগাতে শেখা থেকে মেটা-মডেলকে বাধা দেয় |
| **মেটা-মডেল সহজ রাখুন** | লজিস্টিক রিগ্রেশন বা অগভীর গাছ; বেস মডেলগুলি ভারী উত্তোলন করে |
| **মেটা-মডেলে কাঁচা বৈশিষ্ট্য অন্তর্ভুক্ত করুন** | কখনও কখনও মূল বৈশিষ্ট্যগুলিতেও মেটা-মডেল অ্যাক্সেস দিতে সহায়ক |

## ব্যবহারিক দিকনির্দেশনা
### কখন কোন এনসেম্বল ব্যবহার করবেন
| দৃশ্যকল্প | প্রস্তাবিত পদ্ধতি |
|------------|---------|
| ** দ্রুত বেসলাইন; সারণী ডেটা** | এলোমেলো বন |
| **সর্বোচ্চ নির্ভুলতা; সারণী ডেটা** | XGBoost / LightGBM / CatBoost |
| **কোলাহলপূর্ণ ডেটা** | ব্যাগিং (বুস্টিং গোলমাল ওভারফিট হবে) |
| **ব্যাখ্যাযোগ্যতা প্রয়োজন** | বৈশিষ্ট্য গুরুত্ব সহ একক মডেল বা ছোট ensemble |

| **অনলাইন শিক্ষা** | স্ট্রিমিং ensemble পদ্ধতি; অভিযোজিত বুস্টিং |
| **ভারসাম্যহীন তথ্য** | সুষম এলোমেলো বন; খরচ সংবেদনশীল বুস্টিং |
### সমন্বয় বৈচিত্র্য কৌশল

## সারাংশ
এনসেম্বল পদ্ধতিগুলি কাজ করে কারণ তারা একাধিক অপূর্ণ মডেলকে একক শক্তিশালী ভবিষ্যদ্বাণীতে একত্রিত করে। ব্যাগিং (এলোমেলো বন) বুটস্ট্র্যাপ নমুনা এবং গড় উপর সমান্তরালভাবে প্রশিক্ষণ মডেল দ্বারা বৈচিত্র্য হ্রাস করে। বুস্টিং (XGBoost, LightGBM, CatBoost) ক্রমানুসারে মডেলদের প্রশিক্ষণের মাধ্যমে পক্ষপাত কমায়, প্রতিটি পূর্ববর্তী ত্রুটি সংশোধন করে। স্ট্যাকিং বিভিন্ন বেস মডেল একত্রিত করতে একটি মেটা-মডেল ব্যবহার করে। ভোট এবং গড় হল সহজতম ensembles. সাধারণ থ্রেড হল বৈচিত্র্য: ensembles ভাল কাজ করে যখন তাদের উপাদান মডেল পৃথকভাবে যুক্তিসঙ্গত হয় কিন্তু বিভিন্ন ত্রুটি করে। অনুশীলনে, টেবুলার ডেটাতে গ্রেডিয়েন্ট বুস্টিং প্রায়শই সর্বোচ্চ-সম্পাদক একক পদ্ধতি, যখন বিভিন্ন মডেলের স্ট্যাকিং প্রতিযোগিতা এবং উচ্চ-স্টেকের অ্যাপ্লিকেশনগুলিতে নির্ভুলতাকে আরও এগিয়ে দেয়।
