# ফিচার ইঞ্জিনিয়ারিং
ফিচার ইঞ্জিনিয়ারিং হল কাঁচা ডেটাকে উপস্থাপনায় রূপান্তরিত করার প্রক্রিয়া যা মেশিন লার্নিং মডেলগুলিকে আরও কার্যকর করে তোলে। এটিকে প্রায়শই ML পাইপলাইনের সবচেয়ে গুরুত্বপূর্ণ পদক্ষেপ হিসাবে বর্ণনা করা হয় — যে বৈশিষ্ট্যগুলি আপনি একটি মডেলকে আপনার বেছে নেওয়া অ্যালগরিদমের চেয়ে বেশি দেন৷ ভাল-কারুকৃত বৈশিষ্ট্য সহ একটি সাধারণ মডেল সাধারণত কাঁচা, অপ্রক্রিয়াজাত ইনপুট সহ একটি জটিল মডেলকে ছাড়িয়ে যায়। শিল্পটি ডোমেন এবং ডেটা উভয়কেই ভালভাবে বোঝার মধ্যে রয়েছে যাতে মডেলটি শিখতে পারে এমন সংকেত তৈরি করতে পারে।

## কেন ফিচার ইঞ্জিনিয়ারিং ব্যাপার
| ফ্যাক্টর | প্রভাব |
|---------|---------|
| **সংকেত গুণমান** | ভাল বৈশিষ্ট্য = মডেল শেখার জন্য পরিষ্কার নিদর্শন |
| **মডেল সরলতা** | ভাল বৈশিষ্ট্যগুলি সহজ মডেলগুলিকে ভাল কার্য সম্পাদন করতে দেয়; জটিল স্থাপত্যের জন্য কম প্রয়োজন |
| **প্রশিক্ষণের গতি** | প্রাসঙ্গিক, ভাল-স্কেল বৈশিষ্ট্যগুলি দ্রুত একত্রিত হয় |
| **সাধারণকরণ** | ডোমেন-অবহিত বৈশিষ্ট্যগুলি মডেলগুলিকে অদেখা ডেটাতে কাজ করতে সহায়তা করে |
| **ব্যাখ্যাযোগ্যতা** | অর্থপূর্ণ বৈশিষ্ট্যগুলি স্টেকহোল্ডারদের ব্যাখ্যা করা সহজ |

## বৈশিষ্ট্য রূপান্তরের প্রকার
### সংখ্যাগত রূপান্তর
| রূপান্তর | সূত্র / বর্ণনা | কখন ব্যবহার করবেন |
|---------------|------------|---------------|
| **লগ রূপান্তর** | লগ(x) বা লগ(x + 1) | ডান তির্যক বিতরণ; আর্থিক মান |
| **বর্গমূল** | sqrt(x) | মাঝারি তির্যক; তথ্য গণনা |
| **বক্স-কক্স** | প্যারামেট্রিক ট্রান্সফর্ম যা সেরা পাওয়ার ট্রান্সফরমেশন খুঁজে পায় | ডেটা আরও সাধারণভাবে বিতরণ করা |
| **ইয়ো-জনসন** | বক্স-কক্সের মতো কিন্তু নেতিবাচক মান পরিচালনা করে | নেতিবাচক মান সহ স্কুইড ডেটা |
| **মানককরণ** | (x - গড়) / std | বিভিন্ন স্কেল সঙ্গে বৈশিষ্ট্য; অ্যালগরিদম স্বাভাবিকতা অনুমান করে |
| **নূন্যতম-সর্বোচ্চ স্কেলিং** | (x - মিনিট) / (সর্বোচ্চ - মিনিট) | [0, 1] এর বৈশিষ্ট্যগুলিকে আবদ্ধ করা; ইমেজ পিক্সেল মান |
| **শক্তিশালী স্কেলিং** | (x - মধ্যমা) / IQR | Outliers সঙ্গে ডেটা |
| **বিনিং** | অবিচ্ছিন্নকে শ্রেণীবদ্ধে রূপান্তর করুন | অ-রৈখিক সম্পর্ক; সিদ্ধান্ত গাছ |
| **বহুপদ বৈশিষ্ট্য** | x², x³, x₁×x₂ | রৈখিক মডেলে নন-লিনিয়ার সম্পর্ক ক্যাপচার করা |
### ক্যাটাগরিক্যাল এনকোডিং
| এনকোডিং | বর্ণনা | কখন ব্যবহার করবেন |
|------------|---------------|------------|
| **এক-হট এনকোডিং** | প্রতিটি বিভাগের জন্য একটি বাইনারি কলাম তৈরি করুন | নিম্ন কার্ডিনালিটি বিভাগ; গাছ-ভিত্তিক মডেল নেটিভভাবে পরিচালনা করে |
| **লেবেল এনকোডিং** | প্রতিটি বিভাগে পূর্ণসংখ্যা বরাদ্দ করুন | সাধারণ বিভাগ; গাছ ভিত্তিক মডেল |
| **লক্ষ্য এনকোডিং** | লক্ষ্য পরিবর্তনশীল এর গড় দিয়ে বিভাগ প্রতিস্থাপন করুন | উচ্চ কার্ডিনালিটি বিভাগ; মসৃণ সঙ্গে overfitting এড়িয়ে চলুন |
| **ফ্রিকোয়েন্সি এনকোডিং** | এর গণনা বা ফ্রিকোয়েন্সি দিয়ে বিভাগ প্রতিস্থাপন করুন | যখন ফ্রিকোয়েন্সি নিজেই তথ্যপূর্ণ |
| **বাইনারী এনকোডিং** | পূর্ণসংখ্যা-এনকোড করা বিভাগগুলিকে বাইনারি সংখ্যায় রূপান্তর করুন | উচ্চ-কর্ডিনালিটি; এক-গরম বনাম মাত্রিকতা হ্রাস করে |
| **এম্বেডিং** | ঘন ভেক্টর উপস্থাপনা শিখুন | খুব উচ্চ কার্ডিনালিটি; এনএলপি; সুপারিশকারী সিস্টেম |
| **হ্যাশ এনকোডিং** | বৈশিষ্ট্যের একটি নির্দিষ্ট সংখ্যক হ্যাশ বিভাগ | খুব উচ্চ কার্ডিনালিটি; অনলাইন শিক্ষা |
### তারিখ এবং সময় বৈশিষ্ট্য
| বৈশিষ্ট্য | বর্ণনা |
|---------|---------------|

## অনুপস্থিত মানগুলি পরিচালনা করা

| **KNN অভিযোগ** | অনুপস্থিত মান অনুমান করতে k- নিকটতম প্রতিবেশীদের ব্যবহার করুন | যখন অনুরূপ উদাহরণ অনুপস্থিত মান ভবিষ্যদ্বাণী করতে সাহায্য করে |
| **মডেল-ভিত্তিক অভিযুক্তি** | অনুপস্থিত মান ভবিষ্যদ্বাণী করার জন্য একটি মডেলকে প্রশিক্ষণ দিন | আরো সঠিক; গণনাগতভাবে ব্যয়বহুল |
| **অনুপস্থিত সূচক** | একটি বাইনারি কলাম যোগ করুন অনুপস্থিত পতাকাঙ্কিত | যখন অনুপস্থিত নিজেই তথ্যপূর্ণ |
| **ইন্টারপোলেশন** | ইন্টারপোলেটেড মান দিয়ে পূরণ করুন (রৈখিক, স্প্লাইন) | সময় সিরিজ; অর্ডার করা ডেটা |

## সারাংশ
ফিচার ইঞ্জিনিয়ারিং হল যেখানে ডোমেন জ্ঞান মেশিন লার্নিং পূরণ করে। এটি কাঁচা ডেটা রূপান্তর করার প্রক্রিয়া — অগোছালো, অসম্পূর্ণ, উচ্চ-মাত্রিক — পরিষ্কার, তথ্যপূর্ণ উপস্থাপনা যা থেকে মডেলগুলি শিখতে পারে৷ সংখ্যাসূচক রূপান্তরগুলি তির্যক এবং স্কেল পরিচালনা করে। শ্রেণীবদ্ধ এনকোডিং লেবেলকে সংখ্যায় রূপান্তর করে যা মডেল ব্যবহার করতে পারে। তারিখ বৈশিষ্ট্য অস্থায়ী নিদর্শন ক্যাপচার. অনুপস্থিত মান কৌশলগুলি অসম্পূর্ণ ডেটা পরিচালনা করে। বৈশিষ্ট্য নির্বাচন গোলমাল এবং অপ্রয়োজনীয়তা সরিয়ে দেয়। সেরা বৈশিষ্ট্য প্রকৌশলীরা গোয়েন্দাদের মতো ভাবেন: তারা জিজ্ঞাসা করে যে ডেটাতে কী সংকেত থাকা উচিত, সেই সংকেতগুলি কোথায় লুকানো থাকতে পারে এবং কীভাবে সেগুলিকে সৎ (কোনও ডেটা ফাঁস নয়), পুনরুত্পাদনযোগ্য এবং সময়ের সাথে সাথে পরিবর্তন করার জন্য শক্তিশালী উপায়ে বের করা যায়।
