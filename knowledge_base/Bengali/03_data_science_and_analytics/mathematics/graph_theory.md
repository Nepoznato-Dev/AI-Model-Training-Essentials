# গ্রাফ তত্ত্ব
একটি **গ্রাফ** হল একটি গাণিতিক কাঠামো যা প্রান্ত (লিঙ্ক) দ্বারা সংযুক্ত শীর্ষবিন্দু (নোড) নিয়ে গঠিত। গ্রাফ মডেল সম্পর্ক: সামাজিক নেটওয়ার্ক, রাস্তা মানচিত্র, নিউরাল নেটওয়ার্ক, নির্ভরতা, যোগাযোগ চ্যানেল। গ্রাফ তত্ত্ব - এই কাঠামোগুলির অধ্যয়ন - অ্যালগরিদম এবং উপপাদ্যগুলি সরবরাহ করে যা কম্পিউটার বিজ্ঞান, অপারেশন গবেষণা এবং ডেটা বিজ্ঞানের কেন্দ্রবিন্দু।

| **নির্দেশিত (ডিগ্রাফ)** | প্রান্তের দিক আছে (আর্কস) | ওয়েব পেজ লিঙ্ক |

| **ওজনহীন** | সমস্ত প্রান্ত সমান | সামাজিক সংযোগ |
| **সহজ** | কোন লুপ নেই, একাধিক প্রান্ত নেই | সর্বাধিক পাঠ্যপুস্তকের গ্রাফ |

| **সম্পূর্ণ** | প্রতিটি জোড়া শীর্ষবিন্দু সংযুক্ত | Kₙ এর n(n−1)/2 প্রান্ত আছে |
| **দ্বিপক্ষীয়** | শীর্ষবিন্দু দুটি দলে বিভক্ত; প্রান্ত শুধুমাত্র ক্রস গ্রুপ | ব্যবহারকারী-আইটেম সুপারিশ ম্যাট্রিক্স |
| **প্ল্যানার** | প্রান্ত ক্রসিং ছাড়া আঁকা যাবে | সার্কিট বোর্ড লেআউট |
| **গাছ** | সংযুক্ত, অ্যাসাইক্লিক গ্রাফ | ডিসিশন ট্রি, ফাইল সিস্টেম |
| **DAG** | নির্দেশিত, কোন নির্দেশিত চক্র | টাস্ক শিডিউলিং, নির্ভরতা গ্রাফ |
### হ্যান্ডশেকিং লেমা
সমস্ত শীর্ষবিন্দু ডিগ্রীর যোগফল প্রান্তের সংখ্যার দ্বিগুণ সমান:
Σᵥ deg(v) = 2|E|
**করোলারি:** প্রতিটি গ্রাফে জোড় সংখ্যার বিজোড়-ডিগ্রী শীর্ষবিন্দু রয়েছে।
**উদাহরণ:** 10 জনের একটি পার্টিতে যেখানে সবাই ঠিক 3 জনের সাথে করমর্দন করে: Σ deg = 30, তাই |E| = মোট 15টি হ্যান্ডশেক।

## গ্রাফ উপস্থাপনা
আপনি কীভাবে মেমরিতে একটি গ্রাফ সঞ্চয় করবেন তা আপনি এটিতে চালিত প্রতিটি অ্যালগরিদমের কার্যকারিতা নির্ধারণ করে।
| প্রতিনিধিত্ব | মহাকাশ | এজ লুকআপ | প্রতিবেশীদের পুনরাবৃত্তি | জন্য সেরা |
|----------------|---------|---------------|---------|
| **অ্যাডজাসেন্সি ম্যাট্রিক্স** | O(n²) | O(1) | O(n) | ঘন গ্রাফ, দ্রুত প্রান্ত পরীক্ষা |
| **সংলগ্ন তালিকা** | O(n + m) | O(deg(v)) | O(deg(v)) | স্পার্স গ্রাফ, সবচেয়ে বাস্তব-বিশ্ব নেটওয়ার্ক |
| **প্রান্ত তালিকা** | O(m) | O(m) | O(m) | সহজ অ্যালগরিদম, ক্রুস্কালের MST |
| **ইনসিডেন্স ম্যাট্রিক্স** | O(n · m) | O(m) | O(m) | বিশেষ অ্যালগরিদম |
### অ্যাডজাসেন্সি ম্যাট্রিক্স
একটি n × n ম্যাট্রিক্স A যেখানে A[i][j] = 1 যদি প্রান্ত (i,j) থাকে, অন্যথায় 0। ওজনযুক্ত গ্রাফের জন্য, A[i][j] = ওজন।
**বৈশিষ্ট্য:**
- অনির্দেশিত গ্রাফের জন্য প্রতিসম
- Aᵏ[i][j] = i থেকে j পর্যন্ত k দৈর্ঘ্যের হাঁটার সংখ্যা
- A এর Eigenvalues কাঠামোগত বৈশিষ্ট্য প্রকাশ করে (বর্ণালী গ্রাফ তত্ত্ব দেখুন)
### সংলগ্ন তালিকা
একটি অ্যারে (বা হ্যাশ ম্যাপ) যেখানে প্রতিটি শীর্ষবিন্দু তার প্রতিবেশীদের একটি তালিকা সংরক্ষণ করে।
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

এটি বাস্তব-বিশ্বের গ্রাফগুলির জন্য সবচেয়ে সাধারণ উপস্থাপনা, যা সাধারণত বিক্ষিপ্ত (m ≪ n²)।

## গাছ
একটি **বৃক্ষ** হল একটি সংযুক্ত, অ্যাসাইক্লিক অনির্দেশিত গ্রাফ। একটি **বন** হল গাছের একটি বিচ্ছিন্ন মিলন।
### গাছের বৈশিষ্ট্য
n শীর্ষবিন্দু সহ একটি গাছের জন্য:
- এটির ঠিক n − 1 প্রান্ত রয়েছে
- যেকোনো দুটি শীর্ষবিন্দুর মধ্যে ঠিক একটি পথ আছে
- কোন প্রান্ত অপসারণ এটি সংযোগ বিচ্ছিন্ন
- যেকোনো প্রান্ত যোগ করলে ঠিক একটি চক্র তৈরি হয়
### গাছের প্রকারভেদ
| প্রকার | বর্ণনা | আবেদন |
|------|---------------|---------------|
| **মূল গাছ** | মূল হিসাবে মনোনীত একটি শীর্ষবিন্দু | ফাইল সিস্টেম, সাংগঠনিক চার্ট |
| **বাইনারী গাছ** | প্রতিটি নোডে সর্বাধিক 2 শিশু থাকে | বিএসটি, এক্সপ্রেশন পার্সিং, ডিসিশন ট্রি |
| **সুষম গাছ** | উচ্চতা হল O(log n) | AVL গাছ, লাল-কালো গাছ (ডাটাবেস) |
| **বিস্তৃত গাছ** | সাবগ্রাফ যা সমস্ত শীর্ষবিন্দু অন্তর্ভুক্ত করে এবং একটি গাছ | নেটওয়ার্ক ডিজাইন, আনুমানিক অ্যালগরিদম |
| **ন্যূনতম বিস্তৃত গাছ** | ন্যূনতম মোট প্রান্তের ওজন সহ প্রসারিত গাছ | নেটওয়ার্ক ডিজাইন, ক্লাস্টারিং |
| **তারকা গ্রাফ** | একটি কেন্দ্রীয় নোড অন্য সকলের সাথে সংযুক্ত | হাব এবং স্পোক নেটওয়ার্ক |
### বাইনারি ট্রি বৈশিষ্ট্য
| সম্পত্তি | সূত্র |
|----------|---------|
| d গভীরতায় সর্বোচ্চ নোড | 2ᵈ |
| উচ্চতার গাছে সর্বোচ্চ নোড h | 2ʰ⁺¹ − 1 |
| n নোডের জন্য সর্বনিম্ন উচ্চতা | ⌊log₂(n)⌋ |
| সম্পূর্ণ বাইনারি গাছে পাতার নোড | অভ্যন্তরীণ নোড + 1 |
### ট্রি ট্রাভার্সাল
| ট্রাভার্সাল | অর্ডার | কেস ব্যবহার করুন |
|------------|-------|----------|
| **প্রি-অর্ডার** | রুট → বাম → ডান | একটি গাছ অনুলিপি করা, উপসর্গ অভিব্যক্তি |
| **অনুযায়ী** | বাম → রুট → ডান | BST থেকে সাজানো আউটপুট |
| **পোস্ট-অর্ডার** | বাম → ডান → রুট | একটি গাছ মুছে ফেলা, পোস্টফিক্স এক্সপ্রেশন |
| **লেভেল-অর্ডার (BFS)** | লেভেল বাই লেভেল, বাম থেকে ডানে | ওজনহীন গাছে সবচেয়ে ছোট পথ |

## গ্রাফ ট্রাভার্সাল
ট্রাভার্সাল অ্যালগরিদম পদ্ধতিগতভাবে প্রতিটি পৌঁছানো যায় এমন শীর্ষবিন্দু পরিদর্শন করে।
### ব্রেডথ-ফার্স্ট সার্চ (BFS)
একটি **সারি** ব্যবহার করে স্তরে স্তরে শীর্ষবিন্দুগুলি অন্বেষণ করে৷
| সম্পত্তি | মান |
|----------|---------|
| তথ্য কাঠামো | সারি (FIFO) |
| সময় জটিলতা | O(V + E) |
| স্থান জটিলতা | O(V) |
| সংক্ষিপ্ততম পথ খুঁজে পায়? | হ্যাঁ (ভারহীন গ্রাফ) |
| সম্পূর্ণ? | হ্যাঁ (সমস্ত নাগালযোগ্য শীর্ষবিন্দু অন্বেষণ করে) |
**অ্যালগরিদম:**
1. উৎস শীর্ষবিন্দু থেকে শুরু করুন। মার্ক পরিদর্শন করেছেন। সারি সারি
2. সারি খালি না থাকার সময়: dequeue vertex u. U-এর প্রতিটি অনাদর্শিত প্রতিবেশীর জন্য: মার্ক v পরিদর্শন করা হয়েছে, সারিবদ্ধ ভি।
**অ্যাপ্লিকেশন:** ওজনহীন গ্রাফ, সংযুক্ত উপাদান, দ্বিপক্ষীয় পরীক্ষা, ওয়েব ক্রলিংয়ের সংক্ষিপ্ততম পথ।
### গভীরতা-প্রথম অনুসন্ধান (DFS)
**স্ট্যাক** (বা পুনরাবৃত্তি) ব্যবহার করে ব্যাকট্র্যাক করার আগে যতটা সম্ভব গভীরভাবে অন্বেষণ করুন।
| সম্পত্তি | মান |
|----------|---------|
| তথ্য কাঠামো | স্ট্যাক (LIFO) / পুনরাবৃত্তি |
| সময় জটিলতা | O(V + E) |
| স্থান জটিলতা | O(V) |
| সংক্ষিপ্ততম পথ খুঁজে পায়? | না |
| সম্পূর্ণ? | হ্যাঁ (সীমিত গ্রাফের জন্য) |
**অ্যালগরিদম:**
1. শীর্ষবিন্দু থেকে শুরু করুন। মার্ক পরিদর্শন করেছেন।
2. s-এর প্রতিটি অদেখা প্রতিবেশীর জন্য: v থেকে পুনরাবৃত্তভাবে DFS।
**DFS প্রান্তগুলিকে এতে শ্রেণীবদ্ধ করে:**
- **বৃক্ষের প্রান্ত:** DFS গাছের অংশ
- **পিছন প্রান্ত:** একটি শীর্ষবিন্দুকে তার পূর্বপুরুষের সাথে সংযুক্ত করুন (চক্র নির্দেশ করুন)
- **ফরওয়ার্ড প্রান্ত:** একটি শীর্ষবিন্দুকে তার বংশধরের সাথে সংযুক্ত করুন
- **প্রান্তগুলি:** বিভিন্ন শাখায় শীর্ষবিন্দুগুলিকে সংযুক্ত করুন৷
**অ্যাপ্লিকেশন:** টপোলজিকাল বাছাই, চক্র সনাক্তকরণ, দৃঢ়ভাবে সংযুক্ত উপাদান, গোলকধাঁধা সমাধান।
### BFS বনাম DFS তুলনা
| মানদণ্ড | BFS | ডিএফএস |
|------------|------|------|
| কৌশল | প্রশস্ত তারপর গভীর | গভীর তারপর প্রশস্ত |
| স্মৃতি | উচ্চতর (স্টোর সীমান্ত) | নিম্ন (স্টোর পাথ) |
| সংক্ষিপ্ততম পথ (ভারহীন) | গ্যারান্টিযুক্ত | নিশ্চিত নয় |
| সমাধান শুরু হওয়ার কাছাকাছি হলে ব্যবহার করুন | ভালো | আরও খারাপ |
| গ্রাফ খুব গভীর হলে ব্যবহার করুন | আরও খারাপ | ভালো |
| টপোলজিক্যাল বাছাই | কানের অ্যালগরিদম বৈকল্পিক | স্ট্যান্ডার্ড পদ্ধতি |

## সংক্ষিপ্ততম পথ অ্যালগরিদম
শীর্ষবিন্দুগুলির মধ্যে সংক্ষিপ্ততম পথ খুঁজে পাওয়া গ্রাফের সবচেয়ে গুরুত্বপূর্ণ সমস্যাগুলির মধ্যে একটি।
### Dijkstra এর অ্যালগরিদম
**নন-নেতিবাচক** প্রান্ত ওজন সহ একটি গ্রাফে একটি একক উত্স থেকে অন্য সকল শীর্ষবিন্দুতে সংক্ষিপ্ততম পথ খুঁজে পায়।
| সম্পত্তি | মান |
|----------|---------|
| প্রান্ত ওজন | ≥ 0 হতে হবে |
| সময় (বাইনারী গাদা) | O((V + E) লগ V) |
| সময় (ফিবোনাচি গাদা) | O(E + V লগ V) |
| লোভী? | হ্যাঁ |
| নেতিবাচক ওজন হ্যান্ডেল? | না |
**অ্যালগরিদম:**
1. সমস্ত v ≠ s এর জন্য dist[s] = 0, dist[v] = ∞ শুরু করুন। সমস্ত শীর্ষবিন্দু সহ অগ্রাধিকার সারি Q।
2. Q খালি না থাকলেও: ন্যূনতম দূরত্ব সহ শীর্ষবিন্দু u বের করুন। প্রান্ত ওজন সহ u এর প্রতিটি প্রতিবেশীর জন্য w: যদি dist[u] + w < dist[v], update dist[v] = dist[u] + w.
**কাজ করা উদাহরণ:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### বেলম্যান-ফোর্ড অ্যালগরিদম
**নেতিবাচক** প্রান্তের ওজন পরিচালনা করে এবং নেতিবাচক চক্র সনাক্ত করে।
| সম্পত্তি | মান |
|----------|---------|
| প্রান্ত ওজন | যেকোনো (নেতিবাচক চক্র সনাক্ত করে) |
| সময় জটিলতা | O(V · E) |
| স্থান জটিলতা | O(V) |
| নেতিবাচক চক্র পরিচালনা করে? | হ্যাঁ (সনাক্ত করে এবং রিপোর্ট) |
**অ্যালগরিদম:**
1. সমস্ত v ≠ s এর জন্য dist[s] = 0, dist[v] = ∞ শুরু করুন।
2. V − 1 বার পুনরাবৃত্তি করুন: প্রতিটি প্রান্তের জন্য (u, v) ওজন সহ: যদি dist[u] + w < dist[v], dist[v] আপডেট করুন।
3. নেতিবাচক চক্রের জন্য পরীক্ষা করুন: যদি কোনো প্রান্ত এখনও শিথিল করা যায় তবে একটি নেতিবাচক চক্র বিদ্যমান।
### ফ্লয়েড-ওয়ারশাল অ্যালগরিদম
**সমস্ত জোড়া** শীর্ষবিন্দুর মধ্যে সংক্ষিপ্ততম পথ খুঁজে পায়।
| সম্পত্তি | মান |
|----------|---------|
| সময় জটিলতা | O(V³) |
| স্থান জটিলতা | O(V²) |
| নেতিবাচক ওজন হ্যান্ডেল? | হ্যাঁ (কিন্তু নেতিবাচক চক্র নয়) |
| দৃষ্টিভঙ্গি | ডাইনামিক প্রোগ্রামিং |
**পুনরাবৃত্তি:** dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) প্রতিটি মধ্যবর্তী শীর্ষ k এর জন্য।
### অ্যালগরিদম নির্বাচন নির্দেশিকা
| দৃশ্যকল্প | অ্যালগরিদম |
|------------|------------|
| একক উৎস, অ ঋণাত্মক ওজন | Dijkstra |
| একক উৎস, ঋণাত্মক ওজন সম্ভব | বেলম্যান-ফোর্ড |
| সমস্ত জোড়া, ঘন গ্রাফ | ফ্লয়েড-ওয়ারশাল |
| সমস্ত জোড়া, স্পার্স গ্রাফ | প্রতিটি শীর্ষবিন্দু থেকে Dijkstra চালান |
| ওজনহীন গ্রাফ | BFS |
| DAG (কোন চক্র নেই) | টপোলজিক্যাল বাছাই + শিথিলকরণ |
| A* (হিউরিস্টিক-নির্দেশিত) | A* অনুসন্ধান (ভাল হিউরিস্টিক সহ পাথফাইন্ডিংয়ের জন্য) |

## নূন্যতম স্প্যানিং গাছ
একটি **ন্যূনতম স্প্যানিং ট্রি (MST)** ন্যূনতম মোট প্রান্তের ওজনের সাথে সমস্ত শীর্ষবিন্দুকে সংযুক্ত করে।
### বৈশিষ্ট্য
- একটি MST এর ঠিক n − 1 প্রান্ত রয়েছে (n শীর্ষবিন্দুর জন্য)
- গ্রাফটি সংযুক্ত থাকলে একটি MST বিদ্যমান
- স্বতন্ত্র প্রান্ত ওজন সহ একটি গ্রাফের একটি অনন্য MST আছে
- MST **কাট প্রপার্টি**কে সন্তুষ্ট করে: যেকোন কাটের ন্যূনতম-ওজন প্রান্তটি MST-এর অন্তর্গত
- MST **সাইকেল প্রপার্টি**কে সন্তুষ্ট করে: যেকোন সাইকেলে সর্বোচ্চ-ওজন এজ MST-এর অন্তর্গত নয়
### ক্রুসকালের অ্যালগরিদম
| সম্পত্তি | মান |
|----------|---------|
| কৌশল | লোভী — ওজন ক্রমে প্রান্ত যোগ করুন |
| তথ্য কাঠামো | Disjoint-set (ইউনিয়ন-খোঁজ) |
| সময় জটিলতা | O(E লগ ই) |
| জন্য সেরা | স্পার্স গ্রাফ |
**অ্যালগরিদম:**
1. ওজন অনুসারে সমস্ত প্রান্ত সাজান।
2. প্রতিটি প্রান্তের জন্য (ক্রমানুসারে): যদি এটি যোগ করার ফলে একটি চক্র তৈরি না হয় (ইউনিয়ন-ফাইন্ড দিয়ে পরীক্ষা করুন), এটি MST-তে যোগ করুন।
3. n − 1 প্রান্ত নির্বাচন করা হলে থামুন।
### প্রিম এর অ্যালগরিদম
| সম্পত্তি | মান |
|----------|---------|
| কৌশল | লোভী — একটি শুরু শীর্ষবিন্দু থেকে গাছ বৃদ্ধি |
| তথ্য কাঠামো | অগ্রাধিকার সারি (মিনিট-হিপ) |
| সময় জটিলতা | বাইনারি হিপ সহ O(E লগ V) |
| জন্য সেরা | ঘন গ্রাফ |
**অ্যালগরিদম:**
1. যেকোনো শীর্ষ থেকে শুরু করুন। MST এর অংশ হিসেবে চিহ্নিত করুন।
2. বারবার MST-তে একটি শীর্ষবিন্দুকে এর বাইরের একটি শীর্ষে সংযোগকারী সর্বনিম্ন-ওজন প্রান্তটি যোগ করুন।
3. সমস্ত শীর্ষবিন্দু অন্তর্ভুক্ত করা হলে থামুন।
### MST অ্যাপ্লিকেশন
| আবেদন | কিভাবে MST সাহায্য করে |
|---------------|---------------|
| নেটওয়ার্ক ডিজাইন | সমস্ত অবস্থানে সংযোগ করার জন্য ন্যূনতম তার/পাইপ রাখুন |
| ক্লাস্টারিং | k ক্লাস্টার পেতে k − 1 দীর্ঘতম MST প্রান্তগুলি সরান |
| আনুমানিক অ্যালগরিদম | মেট্রিক টিএসপির জন্য 2-আনুমানিক |
| চিত্র বিভাজন | রঙের মিলের MST দ্বারা পিক্সেল গ্রুপ |
| বৈশিষ্ট্য নির্মূল | পারস্পরিক সম্পর্ক গ্রাফের MST ব্যবহার করে অপ্রয়োজনীয় বৈশিষ্ট্যগুলি সরান |

## নেটওয়ার্ক ফ্লো
নেটওয়ার্ক প্রবাহ সমস্যা একটি সিস্টেমের মাধ্যমে সম্পদের গতিবিধি মডেল।
### ফ্লো নেটওয়ার্ক সংজ্ঞা
একটি **ফ্লো নেটওয়ার্ক** হল একটি নির্দেশিত গ্রাফ যার সাথে:
- একটি **উৎস** শীর্ষবিন্দু s (প্রবাহ উৎপন্ন করে)
- একটি **সিঙ্ক** শীর্ষবিন্দু t (প্রবাহ খরচ করে)
- **ক্ষমতা** প্রতিটি প্রান্তে c(u,v) ≥ 0
- **প্রবাহ** f(u,v) সন্তোষজনক:
  - **ক্ষমতা সীমাবদ্ধতা:** 0 ≤ f(u,v) ≤ c(u,v)
  - **প্রবাহ সংরক্ষণ:** ফ্লো ইন = s এবং t ব্যতীত প্রতিটি শীর্ষে প্রবাহিত হয়
### সর্বাধিক প্রবাহ সমস্যা
s থেকে t পর্যন্ত সর্বাধিক মোট প্রবাহ নির্ণয় করুন।
**ফোর্ড-ফুলকারসন পদ্ধতি:**
1. যখন অবশিষ্ট গ্রাফে s থেকে t পর্যন্ত একটি বর্ধনশীল পথ রয়েছে:
2. পথ বরাবর বাধা ক্ষমতা খুঁজুন
3. বটলনেক পরিমাণ দ্বারা পথ বরাবর প্রবাহ বৃদ্ধি
4. অবশিষ্ট ক্ষমতা আপডেট করুন
| অ্যালগরিদম | সময় জটিলতা | নোট |
|------------|----------------|---------|
| ফোর্ড-ফুলকারসন (DFS) | O(m · f*) যেখানে f* সর্বাধিক প্রবাহ | অযৌক্তিক ক্ষমতা দিয়ে শেষ করা যাবে না |
| এডমন্ডস-কার্প (BFS) | O(V · E²) | সর্বদা সমাপ্ত করে, সংক্ষিপ্ততম বৃদ্ধিকারী পথ বেছে নেয় |
| Dinic এর অ্যালগরিদম | O(V² · E) | ব্লকিং প্রবাহ ব্যবহার করে; O(V^(1/2) · E) ইউনিট ক্ষমতার জন্য |
### সর্বোচ্চ-প্রবাহ মিন-কাট উপপাদ্য
**সর্বোচ্চ প্রবাহ** s থেকে t এর সমান **সর্বনিম্ন কাট** ক্ষমতা s কে t থেকে আলাদা করে।
A **কাট** (S, T) পার্টিশনগুলিকে S (s ধারণ করে) এবং T (t ধারণ করে) শীর্ষে বিভক্ত করে। কাট ক্ষমতা হল S থেকে T পর্যন্ত প্রান্তের ধারণক্ষমতার সমষ্টি।
**সর্বাধিক প্রবাহের আবেদন:**
- দ্বিপক্ষীয় মিল (কাজের জন্য কর্মীদের নিয়োগ)
- চিত্র বিভাজন (পটভূমি থেকে পৃথক ফোরগ্রাউন্ড)
- বেসবল নির্মূল (টিম X এখনও জিততে পারে?)

### সর্বোচ্চ প্রবাহের মাধ্যমে দ্বিপক্ষীয় ম্যাচিং
একটি দ্বিপক্ষীয় গ্রাফ দেওয়া হয়েছে G = (L ∪ R, E):
1. L-এ সমস্ত শীর্ষবিন্দুতে প্রান্ত সহ উৎস s যোগ করুন (ক্ষমতা 1)
2. R-এ সমস্ত শীর্ষবিন্দু থেকে প্রান্ত সহ সিঙ্ক টি যোগ করুন (ক্ষমতা 1)
3. সমস্ত মূল প্রান্ত ক্ষমতা 1 এ সেট করুন
4. সর্বোচ্চ প্রবাহ = সর্বোচ্চ মিল

## বর্ণালী গ্রাফ তত্ত্ব
বর্ণালী গ্রাফ তত্ত্ব গ্রাফের সাথে যুক্ত ম্যাট্রিক্সের eigenvalues ​​এবং eigenvectors এর মাধ্যমে গ্রাফ অধ্যয়ন করে।
### মূল ম্যাট্রিক্স
| ম্যাট্রিক্স | সংজ্ঞা | এটা কি ক্যাপচার |
|---------|------------|-------|
| **সংলগ্ন ম্যাট্রিক্স** A | A[i][j] = 1 যদি প্রান্ত (i,j) বিদ্যমান থাকে | সংযোগ প্যাটার্ন |
| **ডিগ্রী ম্যাট্রিক্স** D | তির্যক; D[i][i] = deg(i) | ডিগ্রী দ্বারা ভার্টেক্স গুরুত্ব |
| **ল্যাপ্লাসিয়ান** L = D − A | L[i][j] = −1 যদি প্রান্ত, deg(i) তির্যক উপর | গ্রাফে ফাংশনের মসৃণতা |
| **সাধারণকৃত ল্যাপ্লাসিয়ান** L_norm = D^(−1/2) L D^(−1/2) | স্কেল-অপরিবর্তনীয় সংস্করণ | সম্প্রদায় কাঠামো |
### ল্যাপ্লাসিয়ানের আইজেন ভ্যালু
Laplacian L ধনাত্মক আধা-নির্দিষ্ট, তাই সমস্ত eigenvalue ≥ 0।
| Eigenvalue | অর্থ |
|------------|---------|
| λ₁ = 0 | সর্বদা শূন্য; eigenvector হল ধ্রুবক ভেক্টর |
| λ₂ (বীজগণিত সংযোগ) | > 0 iff গ্রাফ সংযুক্ত; বড় = ভাল সংযুক্ত |
| শূন্য eigenvalues ​​সংখ্যা | সংযুক্ত উপাদানের সংখ্যা সমান |
| λₙ | সর্বোচ্চ ডিগ্রি এবং গ্রাফ সম্প্রসারণের সাথে সম্পর্কিত |
### বর্ণালী পদ্ধতির প্রয়োগ
| আবেদন | পদ্ধতি |
|---------------|---------|
| **গ্রাফ পার্টিশন** | গ্রাফটিকে সুষম অংশে বিভক্ত করতে L এর eigenvectors ব্যবহার করুন |
| **সম্প্রদায় সনাক্তকরণ** | বর্ণালী ক্লাস্টারিং: নীচের ইজেনভেক্টর ব্যবহার করে শীর্ষবিন্দু এম্বেড করুন, তারপর ক্লাস্টার |
| **পেজর্যাঙ্ক** | ওয়েব গ্রাফের সংলগ্ন ম্যাট্রিক্স (বা ট্রানজিশন ম্যাট্রিক্স) এর আইজেনভেক্টর |
| **গ্রাফ অঙ্কন** | ল্যাপ্লাসিয়ানের eigenvectors ব্যবহার করে শীর্ষবিন্দুর অবস্থান
| **আধা-তত্ত্বাবধানে শিক্ষা** | গ্রাফ ল্যাপ্লাসিয়ান (লেবেল প্রচার) ব্যবহার করে লেবেল প্রচার করুন |
| **গ্রাফ নিউরাল নেটওয়ার্ক** | স্পেকট্রাল কনভোলিউশন: এল | এর ইজেনভেক্টর ব্যবহার করে গ্রাফে ফিল্টার সংকেত
### চিগারের অসমতা
দ্বিতীয় eigenvalue λ₂ কে গ্রাফের **প্রসারণ** এর সাথে সম্পর্কযুক্ত করে (এটি কতটা ভালোভাবে সংযুক্ত):
λ₂ / 2 ≤ h(G) ≤ √(2λ₂)
যেখানে h(G) হল চিগার ধ্রুবক (আইসোপারিমেট্রিক সংখ্যা)। এর অর্থ λ₂ প্রায় পরিমাপ করে যে গ্রাফটিকে দুটি টুকরো করা কতটা কঠিন - ক্লাস্টারিংয়ের জন্য একটি মূল অন্তর্দৃষ্টি।

## মেশিন লার্নিং এবং ডেটা সায়েন্সের প্রাসঙ্গিকতা

| BFS / DFS | ওয়েব ক্রলিং, সামাজিক নেটওয়ার্ক বিশ্লেষণ, সংযুক্ত উপাদান লেবেলিং |
| Dijkstra / A* | রুট পরিকল্পনা, গেম এআই পাথফাইন্ডিং, রোবোটিক্স নেভিগেশন |
| ন্যূনতম বিস্তৃত গাছ | ক্লাস্টারিং (একক-লিঙ্কেজ), বৈশিষ্ট্য নির্বাচন, নেটওয়ার্ক ডিজাইন |
| সর্বোচ্চ প্রবাহ / মিনিট কাটা | চিত্র বিভাজন, দ্বিপক্ষীয় ম্যাচিং, সুপারিশ অ্যাসাইনমেন্ট |
| বর্ণালী পদ্ধতি | বর্ণালী ক্লাস্টারিং, গ্রাফ নিউরাল নেটওয়ার্ক, মাত্রা হ্রাস (ল্যাপ্লাসিয়ান ইজেনম্যাপ) |
| পেজর্যাঙ্ক | সার্চ ইঞ্জিন র‌্যাঙ্কিং, সামাজিক নেটওয়ার্কে প্রভাব বিশ্লেষণ |
| DAGs | বায়েসিয়ান নেটওয়ার্ক, কার্যকারণ অনুমান, টাস্ক শিডিউলিং, গভীর শিক্ষায় গণনা গ্রাফ |
| দ্বিপক্ষীয় গ্রাফ | সুপারিশকারী সিস্টেমে ব্যবহারকারী-আইটেম ম্যাট্রিক্স, দ্বিমুখী বাজার |
| গাছের কাঠামো | সিদ্ধান্ত গাছ, এলোমেলো বন, শ্রেণিবদ্ধ ক্লাস্টারিং, ফাইল সিস্টেম নেভিগেশন |
| গ্রাফ উপস্থাপনা | নলেজ গ্রাফ (উইকিডাটা, ডিবিপিডিয়া), আণবিক গ্রাফ (ড্রাগ আবিষ্কার), উদ্ধৃতি নেটওয়ার্ক |

## সারাংশ
| বিষয় | মূল ধারণা | কী অ্যালগরিদম / ফলাফল |
|---------|------------|------------|
| মৌলিক | শীর্ষবিন্দু, প্রান্ত, ডিগ্রি, পথ | হ্যান্ডশেকিং লেম্মা |
| প্রতিনিধিত্ব | কিভাবে গ্রাফ সংরক্ষণ করতে হয় | সংলগ্নতা ম্যাট্রিক্স বনাম সংলগ্নতা তালিকা |
| গাছ | সংযুক্ত অ্যাসাইক্লিক গ্রাফ | n শীর্ষবিন্দু → n−1 প্রান্ত |
| ট্রাভার্সাল | পদ্ধতিগত শীর্ষবিন্দু অন্বেষণ | BFS (ছোটতম পথ), DFS (গভীর অন্বেষণ) |
| সংক্ষিপ্ততম পথ | সর্বনিম্ন-ওজন রুট | Dijkstra, Bellman-Ford, Floyd-Warshall |
| ন্যূনতম স্প্যানিং ট্রি | সব শিরোনাম সংযোগ করার সবচেয়ে সস্তা উপায় | Kruskal এর, Prim এর |
| নেটওয়ার্ক ফ্লো | সর্বোচ্চ থ্রুপুট | ফোর্ড-ফুলকারসন, সর্বোচ্চ-প্রবাহ মিন-কাট উপপাদ্য |
| বর্ণালী তত্ত্ব | Eigenvalues ​​গঠন প্রকাশ করে | ল্যাপ্লাসিয়ান ইজেনভ্যালুস, বর্ণালী ক্লাস্টারিং |
গ্রাফ তত্ত্ব যুক্তিযুক্তভাবে আধুনিক তথ্য বিজ্ঞানের জন্য গণিতের সবচেয়ে সরাসরি প্রযোজ্য শাখা। সামাজিক নেটওয়ার্ক, জ্ঞান গ্রাফ, আণবিক কাঠামো, গভীর শিক্ষার কাঠামোর গণনা গ্রাফ, নির্ভরতা রেজোলিউশন, সুপারিশ সিস্টেম - সবই মৌলিকভাবে গ্রাফ সমস্যা। এখানে কভার করা অ্যালগরিদমগুলি কেবল তাত্ত্বিক নয়; তারা প্রতিদিন উৎপাদন ব্যবস্থায় স্কেল চালায়।
