# ক্লাসিক্যাল মেকানিক্স
ক্লাসিক্যাল মেকানিক্স শক্তির প্রভাবে বস্তুর গতি বর্ণনা করে। পতিত আপেল থেকে শুরু করে প্রদক্ষিণকারী গ্রহ পর্যন্ত, কম্পনশীল স্ট্রিং থেকে সংঘর্ষকারী কণা পর্যন্ত, এর নীতিগুলি ম্যাক্রোস্কোপিক বিশ্বকে পরিচালনা করে। এর ভৌত প্রয়োগের বাইরে, ক্লাসিক্যাল মেকানিক্স বৈচিত্রের ক্যালকুলাস, সিমপ্লেটিক জ্যামিতি এবং হ্যামিলটোনিয়ান ফ্রেমওয়ার্কের জন্ম দিয়েছে যা কোয়ান্টাম মেকানিক্স এবং আধুনিক অপ্টিমাইজেশানকে আন্ডারপিন করে।

## নিউটনিয়ান মেকানিক্স
### নিউটনের তিনটি সূত্র
| আইন | বিবৃতি | গাণিতিক ফর্ম |
|------|------------|------|
| **প্রথম (জড়তা)** | একটি বস্তু বিশ্রামে বা অভিন্ন গতিতে থাকে যদি না কোন শক্তি দ্বারা কাজ করা হয় | যদি F_net = 0, তাহলে v = constant |
| **দ্বিতীয় (F = ma)** | বল সমান ভর গুণ ত্বরণ | **F** = m**a** = m(d²**x**/dt²) |
| **তৃতীয় (ক্রিয়া-প্রতিক্রিয়া)** | প্রতিটি ক্রিয়ার একটি সমান এবং বিপরীত প্রতিক্রিয়া আছে | **F**₁₂ = −**F**₂₁ |
### ফ্রি-বডি ডায়াগ্রাম
একটি **মুক্ত-বডি ডায়াগ্রাম** একটি বস্তুকে বিচ্ছিন্ন করে এবং তার উপর কাজ করছে এমন সমস্ত শক্তি দেখায়।
**সাধারণ শক্তি:**
| বল | সূত্র | দিকনির্দেশ |
|-------|---------|------------|
| মাধ্যাকর্ষণ (পৃথিবীর কাছাকাছি) | F = mg | নিম্নগামী |
| স্বাভাবিক বল | এন | পৃষ্ঠের লম্ব |
| ঘর্ষণ (স্থির) | f_s ≤ μ_s N | আসন্ন গতির বিরোধিতা করে |
| ঘর্ষণ (কাইনেটিক) | f_k = μ_k N | গতির বিরোধিতা করে |
| বসন্ত (হুকের আইন) | F = −kx | পুনঃস্থাপন (ভারসাম্যের দিকে) |
| টেনশন | টি | দড়ি/দড়ি বরাবর |
| টেনে আনুন | F_d = ½C_d ρAv² | বেগের বিরোধিতা করে |
### কাজের উদাহরণ: ইনলাইনে ব্লক করুন
θ কোণে ঘর্ষণহীন বাঁকের উপর m ভরের একটি ব্লক।
- বল: মাধ্যাকর্ষণ (মিগ্রা নিচে), স্বাভাবিক বল (N পৃষ্ঠের লম্ব)
- পচন মাধ্যাকর্ষণ: mg sin θ (বাঁক বরাবর), mg cos θ (পৃষ্ঠে)
- N = mg cos θ (পৃষ্ঠের উপর লম্ব কোন গতি নেই)
- বাঁক বরাবর ত্বরণ: a = g sin θ

## শক্তি পদ্ধতি
### কাজ এবং গতিশক্তি
**কাজ** একটি শক্তি দ্বারা সম্পন্ন: W = ∫ **F** · d**r**
**কর্ম-শক্তি তত্ত্ব:** W_net = ΔKE = ½mv₂² − ½mv₁²
### সম্ভাব্য শক্তি
| বল | সম্ভাব্য শক্তি | নোট |
|---------|------|---------|
| মাধ্যাকর্ষণ (পৃষ্ঠের কাছাকাছি) | U = mgh | h = রেফারেন্সের উপরে উচ্চতা |
| মাধ্যাকর্ষণ (সাধারণ) | U = −GMm/r | অনন্তে শূন্য |
| বসন্ত | U = ½kx² | x = ভারসাম্য থেকে স্থানচ্যুতি |
| ইলেক্ট্রোস্ট্যাটিক | U = kq₁q₂/r | লাইক চার্জ: পজিটিভ ইউ |
### শক্তি সংরক্ষণ
যদি শুধুমাত্র রক্ষণশীল শক্তি কাজ করে: E = KE + PE = ধ্রুবক
½mv₁² + U₁ = ½mv₂² + U₂
**কাজ করা উদাহরণ:** একটি বল h উচ্চতা থেকে নেমে গেছে।
- প্রাথমিক: KE = 0, PE = mgh
- মাটিতে আঘাত করার ঠিক আগে: KE = ½mv², PE = 0
- সংরক্ষণ: mgh = ½mv² → v = √(2gh)
### শক্তি
P = dW/dt = **F** · **v** (কাজ করার হার)

## মোমেন্টাম এবং সংঘর্ষ
### লিনিয়ার মোমেন্টাম
**p** = m**v**
নিউটনের দ্বিতীয় সূত্র (বিকল্প রূপ): **F** = d**p**/dt
### মোমেন্টাম সংরক্ষণ
যদি বাহ্যিক শক্তি না থাকে: মোট গতি সংরক্ষিত হয়।
| সংঘর্ষের ধরন | KE সংরক্ষিত? | মোমেন্টাম সংরক্ষিত? |
|---------------|---------------|------------|
| **ইলাস্টিক** | হ্যাঁ | হ্যাঁ |
| **অস্থিতিশীল** | না | হ্যাঁ |
| **পুরোপুরি স্থিতিস্থাপক** | না (সর্বোচ্চ ক্ষতি) | হ্যাঁ (বস্তু একসাথে লেগে থাকে) |
**1D ইলাস্টিক সংঘর্ষ:** দুটি ভর m₁, m₂ প্রাথমিক বেগ u₁, u₂ সহ:
- v₁ = (m₁−m₂)u₁ + 2m₂u₂) / (m₁+m₂)
- v₂ = ((m₂−m₁)u₂ + 2m₁u₁) / (m₁+m₂)
### কৌণিক গতিবেগ
**L** = **r** × **p** = m(**r** × **v**)
টর্ক: **τ** = d**L**/dt = **r** × **F**
**সংরক্ষণ:** বাইরের টর্ক না থাকলে, কৌণিক ভরবেগ সংরক্ষিত হয়।

## ল্যাগ্রাঞ্জিয়ান মেকানিক্স
**ল্যাগ্রাঞ্জিয়ান** ফর্মুলেশন শক্তিকে শক্তি দিয়ে প্রতিস্থাপন করে, আরও মার্জিত এবং সাধারণ কাঠামো প্রদান করে।
### ল্যাগ্রাঞ্জিয়ান
L = T − V (গতিশক্তি বিয়োগ সম্ভাব্য শক্তি)
### সর্বনিম্ন কর্মের নীতি (হ্যামিল্টনের নীতি)
t₁ এবং t₂ সময়ের মধ্যে একটি সিস্টেম দ্বারা নেওয়া প্রকৃত পথটি **ক্রিয়া**কে ছোট করে (আরো সঠিকভাবে, স্থির করে তোলে):
S = ∫_{t₁}^{t₂} L(q, q̇, t) dt
### অয়লার-ল্যাগ্রঞ্জ সমীকরণ
শর্ত δS = 0 ফলন:
d/dt(∂L/∂q̇) − ∂L/∂q = 0
প্রতিটি সাধারণীকৃত স্থানাঙ্কের জন্য q.
**কাজ করা উদাহরণ:** সরল পেন্ডুলাম (দৈর্ঘ্য l, ভর m, উল্লম্ব থেকে কোণ θ)।
- T = ½ml²θ̇²
- V = −mgl cos θ
- L = ½ml²θ̇² + mgl cos θ
- ∂L/∂θ = −mgl sin θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̈
- অয়লার-ল্যাগ্রেঞ্জ: ml²θ̈ + mgl sin θ = 0 → θ̈ + (g/l) sin θ = 0
### ল্যাগ্রাঞ্জিয়ান মেকানিক্সের সুবিধা
| সুবিধা | ব্যাখ্যা |
|------------|-------------|
| সমন্বয়-স্বাধীন | যেকোন সমন্বয় ব্যবস্থায় কাজ করে |
| স্বাভাবিকভাবেই প্রতিবন্ধকতা সামাল দেয় | সীমাবদ্ধতা শক্তি গণনা করার প্রয়োজন নেই |
| প্রতিসাম্য → সংরক্ষণ | নোথারের উপপাদ্য প্রতিসাম্যকে সংরক্ষিত পরিমাণের সাথে সংযুক্ত করে |
| সহজে সাধারণীকরণ করে | ক্ষেত্র, আপেক্ষিকতা, কোয়ান্টাম মেকানিক্স |

## হ্যামিলটোনিয়ান মেকানিক্স
**হ্যামিলটোনিয়ান** ফর্মুলেশন হল ল্যাগ্রাঞ্জিয়ান মেকানিক্সের একটি সংস্কার যা অবস্থান এবং মোমেন্টা (পজিশন এবং বেগের পরিবর্তে) ব্যবহার করে।
### হ্যামিলটোনিয়ান
H = Σᵢ pᵢq̇ᵢ − L = T + V (বেশিরভাগ যান্ত্রিক সিস্টেমের জন্য)
যেখানে pᵢ = ∂L/∂q̇ᵢ হল **সাধারণকৃত মোমেন্টা**।
### হ্যামিল্টনের সমীকরণ
q̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
এগুলি হল 2n প্রথম-ক্রম ODE (বনাম n দ্বিতীয়-ক্রম অয়লার-ল্যাগ্রেঞ্জ সমীকরণ)।
**কাজ করা উদাহরণ:** হারমোনিক অসিলেটর (ভর m, স্প্রিং ধ্রুবক k)।
- H = p²/(2m) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ (প্রত্যাশিত হিসাবে)
- ṗ = −∂H/∂x = −kx → mẍ = −kx (হুকের আইন)
### বিষ বন্ধনী
ফাংশনের জন্য f(q, p) এবং g(q, p):
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
| সম্পত্তি | বিবৃতি |
|------------|------------|
| সময়ের বিবর্তন | df/dt = {f, H} + ∂f/∂t |
| সংরক্ষণ | f সংরক্ষিত হয় iff {f, H} = 0 (এবং ∂f/∂t = 0) |
| মৌলিক বন্ধনী | {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**কোয়ান্টাম মেকানিক্সের সাথে সংযোগ:** পয়সন বন্ধনীগুলি কমিউটার হয়ে যায়: {f, g} → (1/iℏ)[f̂, ĝ]

## সংরক্ষণ আইন এবং নোথার উপপাদ্য
### নোথার উপপাদ্য
ল্যাগ্রাঞ্জিয়ানের প্রতিটি অবিচ্ছিন্ন প্রতিসাম্য একটি সংরক্ষিত পরিমাণের সাথে মিলে যায়।
| প্রতিসাম্য | সংরক্ষিত পরিমাণ |
|------------|---------|
| টাইম ট্রান্সলেশন ইনভেরিয়েন্স | শক্তি |
| স্থানিক অনুবাদ পরিবর্তন | রৈখিক ভরবেগ |
| ঘূর্ণনগত পরিবর্তন | কৌণিক ভরবেগ |
| গেজ ইনভেরিয়েন্স | বৈদ্যুতিক চার্জ |
এটি সমস্ত পদার্থবিজ্ঞানের গভীরতম ফলাফলগুলির মধ্যে একটি - এটি স্থানকালের জ্যামিতিকে মৌলিক সংরক্ষণ আইনের সাথে সংযুক্ত করে।

E = ½mv² − GMm/r
| ই | কক্ষপথের ধরন |
|---|------------|
| ই< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 | হাইপারবোলিক (আনবাউন্ড) |

## সারাংশ
| ফ্রেমওয়ার্ক | মূল সমীকরণ | শক্তি |
|------------|---------------|----------|
| নিউটনিয়ান | **F** = m**a** | স্বজ্ঞাত, সরাসরি বল বিশ্লেষণ |
| ল্যাগ্রাঞ্জিয়ান | d/dt(∂L/∂q̇) − ∂L/∂q = 0 | সমন্বয়-মুক্ত, সীমাবদ্ধতা পরিচালনা করে |
| হ্যামিলটোনিয়ান | q̇ = ∂H/∂p, ṗ = −∂H/∂q | সিমপ্লেটিক গঠন, QM এর সাথে সংযোগ করে |
| সংরক্ষণ আইন | নোথার উপপাদ্য | গভীর প্রতিসাম্য-সংরক্ষণ সংযোগ |
ক্লাসিক্যাল মেকানিক্স শুধুমাত্র বল পড়ে যাওয়া এবং দুল দুলানো সম্পর্কে নয়। এর গাণিতিক কাঠামো — ল্যাগ্রাঞ্জিয়ান এবং হ্যামিলটোনিয়ান মেকানিক্স — সমস্ত বিজ্ঞানের সবচেয়ে প্রভাবশালী ধারণাগুলির মধ্যে একটি। তারা কোয়ান্টাম মেকানিক্স, ফিল্ড থিওরি এবং এমনকি আধুনিক মেশিন লার্নিং-এ সাধারণীকরণ করে, যেখানে শক্তি-ভিত্তিক মডেল এবং পদার্থবিদ্যা-জ্ঞাত নিউরাল নেটওয়ার্কগুলি এই শতাব্দী-পুরনো ফর্মুলেশনগুলির উপর সরাসরি আঁকে।
