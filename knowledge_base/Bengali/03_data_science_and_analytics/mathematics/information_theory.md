# তথ্য তত্ত্ব
তথ্য তত্ত্ব, 1948 সালে ক্লড শ্যানন দ্বারা প্রতিষ্ঠিত, তথ্য নিজেই পরিমাপ করে। একটি বার্তা আপনাকে কতটা বলে? আপনি কতটা ডেটা সংকুচিত করতে পারেন? একটি কোলাহলপূর্ণ চ্যানেলের মাধ্যমে আপনি কত দ্রুত যোগাযোগ করতে পারেন? এই প্রশ্নগুলোর সুনির্দিষ্ট গাণিতিক উত্তর আছে। যোগাযোগের বাইরে, তথ্য তত্ত্ব মেশিন লার্নিং-এর ভিত্তি হয়ে উঠেছে — ক্রস-এনট্রপি হল শ্রেণিবিন্যাসের জন্য ডিফল্ট লস ফাংশন, কেএল ডাইভারজেন্স ডিস্ট্রিবিউশন সাদৃশ্য পরিমাপ করে এবং পারস্পরিক তথ্য ড্রাইভ বৈশিষ্ট্য নির্বাচন।

## এনট্রপি
**এনট্রপি** একটি এলোমেলো পরিবর্তনশীলের গড় অনিশ্চয়তা বা "আশ্চর্য" পরিমাপ করে।
### শ্যানন এনট্রপি (বিচ্ছিন্ন)
সম্ভাব্য ভর ফাংশন p(x) সহ একটি বিচ্ছিন্ন র্যান্ডম ভেরিয়েবল X এর জন্য:
H(X) = −Σₓ p(x) log₂ p(x)
ইউনিট: **বিট** (লগ₂ ব্যবহার করার সময়) বা **ন্যাট** (যখন ln ব্যবহার করা হয়)।
| বিতরণ | এনট্রপি | অন্তর্দৃষ্টি |
|---------------|---------|------------|
| ন্যায্য মুদ্রা (p = 0.5, 0.5) | 1 বিট | বাইনারি ফলাফলের জন্য সর্বাধিক অনিশ্চয়তা |
| পক্ষপাতমূলক মুদ্রা (p = 0.9, 0.1) | 0.469 বিট | কম আশ্চর্যজনক — বেশিরভাগই মাথা |
| ডিটারমিনিস্টিক (p = 1, 0) | 0 বিট | কোন অনিশ্চয়তা মোটেও |
| ফেয়ার ডাই (6 দিক) | 2.585 বিট | আরো ফলাফল = আরো অনিশ্চয়তা |
| n ফলাফলের উপর অভিন্ন | log₂(n) বিট | n ফলাফলের জন্য সর্বোচ্চ এনট্রপি |
### এনট্রপির বৈশিষ্ট্য
| সম্পত্তি | বিবৃতি |
|------------|------------|
| অ-নেতিবাচকতা | H(X) ≥ 0 |
| সর্বোচ্চ | H(X) ≤ log₂(\|X\|) সমতা সহ অভিন্ন বণ্টনের জন্য |
| চেইন নিয়ম | H(X, Y) = H(X) + H(Y \| X) |
| কন্ডিশনিং কমায় | H(X \| Y) ≤ H(X) |
| অবতল | H হল সম্ভাব্যতা বণ্টনের একটি অবতল ফাংশন |
### ডিফারেনশিয়াল এনট্রপি (একটানা)
ঘনত্ব p(x) সহ একটি অবিচ্ছিন্ন এলোমেলো পরিবর্তনশীল X এর জন্য:
h(X) = −∫ p(x) লগ p(x) dx
বিযুক্ত এনট্রপির বিপরীতে, ডিফারেনশিয়াল এনট্রপি **নেতিবাচক** হতে পারে।
| বিতরণ | ডিফারেনশিয়াল এনট্রপি |
|---------------|------------|
| ইউনিফর্ম অন [a,b] | লগ(b − a) |
| সাধারণ N(μ, σ²) | (1/2) লগ(2πeσ²) |
| সূচকীয়(λ) | 1 − ln(λ) |

## যৌথ, শর্তসাপেক্ষ এবং পারস্পরিক তথ্য
### জয়েন্ট এনট্রপি
H(X, Y) = −Σₓ Σᵧ p(x, y) লগ p(x, y)
জোড়ার মোট অনিশ্চয়তা পরিমাপ করে (X, Y)।
### শর্তাধীন এনট্রপি
H(Y | X) = −Σₓ Σᵧ p(x, y) লগ p(y | x) = H(X, Y) − H(X)
X পর্যবেক্ষণ করার পরে Y সম্পর্কে অবশিষ্ট অনিশ্চয়তা পরিমাপ করুন।
### পারস্পরিক তথ্য
I(X; Y) = Σₓ Σᵧ p(x, y) লগ [p(x, y) / (p(x)p(y))]
পরিমাপ করে যে X আপনাকে Y সম্পর্কে কতটা জানাবে (এবং এর বিপরীতে)।
| সম্পত্তি | বিবৃতি |
|------------|------------|
| অ-নেতিবাচকতা | I(X; Y) ≥ 0 |
| প্রতিসাম্য | I(X; Y) = I(Y; X) |
| এনট্রপির সাথে সম্পর্ক | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| যৌথ সম্পর্ক | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| স্বাধীনতা | I(X; Y) = 0 iff X এবং Y স্বাধীন |
| স্ব-তথ্য | I(X; X) = H(X) |
### ভিজ্যুয়াল: এনট্রপি ডায়াগ্রাম
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## কেএল ডাইভারজেন্স
**Kulback-Leibler (KL) ডাইভারজেন্স** পরিমাপ করে যে একটি ডিস্ট্রিবিউশন আরেকটি থেকে কতটা আলাদা।
D_KL(P || Q) = Σₓ P(x) লগ [P(x) / Q(x)]
| সম্পত্তি | বিবৃতি |
|------------|------------|
| অ-নেতিবাচকতা | D_KL(P \|\| Q) ≥ 0 (গিবসের অসমতা) |
| পরিচয় | D_KL(P \|\| Q) = 0 iff P = Q |
| অসমতা | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) সাধারণভাবে |
| একটি মেট্রিক নয় | ব্যর্থ প্রতিসাম্য এবং ত্রিভুজ অসমতা |
**ব্যাখ্যা:** D_KL(P || Q) হল Q-এর জন্য অপ্টিমাইজ করা কোড ব্যবহার করে P থেকে ডেটা এনকোড করার জন্য প্রয়োজনীয় অতিরিক্ত সংখ্যক বিট।
### অন্যান্য পরিমাণের সাথে সম্পর্ক
| সম্পর্ক | সূত্র |
|---------------|---------|
| ক্রস-এনট্রপি | H(P, Q) = H(P) + D_KL(P \|\| Q) |
| পারস্পরিক তথ্য | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| শর্তাধীন KL | D_KL(P(Y\|X) \|\| Q(Y\|X)) X এর উপর গড় |

## ক্রস-এনট্রপি
P এবং Q ডিস্ট্রিবিউশনের মধ্যে **ক্রস-এনট্রপি**:
H(P, Q) = −Σₓ P(x) লগ Q(x) = H(P) + D_KL(P || Q)
### লস ফাংশন হিসাবে ক্রস-এনট্রপি
শ্রেণীবিভাগে, P হল প্রকৃত বিতরণ (এক-হট এনকোডেড লেবেল) এবং Q হল মডেলের পূর্বাভাসিত বিতরণ।
**বাইনারী ক্রস-এনট্রপি (BCE):**
L = −[y লগ(ŷ) + (1−y) লগ(1−ŷ)]
**শ্রেণীগত ক্রস-এনট্রপি:**
L = −Σᵢ yᵢ লগ(ŷᵢ)
| দৃশ্যকল্প | y (সত্য) | ŷ (ভবিষ্যদ্বাণী করা) | ক্ষতি |
|----------|----------|---------------|------|
| সঠিক, আত্মবিশ্বাসী | 1 | 0.95 | ০.০৫১ |
| সঠিক, অনিশ্চিত | 1 | 0.55 | 0.598 |
| ভুল, আত্মবিশ্বাসী | 1 | 0.05 | 2.996 |
| ভুল, অনিশ্চিত | 1 | 0.45 | 0.799 |
ক্রস-এনট্রপি মিনিমাইজ করা সত্যিকারের ডিস্ট্রিবিউশন থেকে KL ডাইভারজেন্স কমানোর সমতুল্য — যে কারণে এটি ক্ষতির ফাংশন হিসাবে খুব ভাল কাজ করে।

## চ্যানেলের ক্ষমতা
### কমিউনিকেশন চ্যানেল মডেল
```
X → [Channel] → Y
```

- X: ইনপুট র্যান্ডম ভেরিয়েবল
- Y: আউটপুট র্যান্ডম ভেরিয়েবল
- চ্যানেল: শর্তসাপেক্ষ সম্ভাব্যতা দ্বারা সংজ্ঞায়িত p(y|x)
### শ্যাননের গোলমাল চ্যানেল কোডিং উপপাদ্য
ক্ষমতা C সহ একটি চ্যানেলের জন্য, যদি সংক্রমণ হার R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C হয়, নির্ভরযোগ্য যোগাযোগ অসম্ভব।
**চ্যানেল ক্ষমতা:**
C = সর্বোচ্চ_{p(x)} I(X; Y)
### গুরুত্বপূর্ণ চ্যানেলের উদাহরণ
| চ্যানেল | বর্ণনা | ক্ষমতা |
|---------|---------------|---------|
| **বাইনারী সিমেট্রিক (বিএসসি)** | সম্ভাব্যতা p | সহ প্রতিটি বিট ফ্লিপ করে 1 − H(p) বিট |
| **বাইনারী ইরেজার (BEC)** | সম্ভাব্যতা ε | সহ প্রতিটি বিট মুছে দেয় 1 − ε বিট |
| **গাউসিয়ান (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)লগ(1 + SNR) বিট |
| **নিঃশব্দ বাইনারি** | পারফেক্ট ট্রান্সমিশন | 1 বিট |

## সোর্স কোডিং এবং কম্প্রেশন
### সোর্স কোডিং থিওরেম
একটি উৎস এনকোড করার জন্য প্রয়োজনীয় বিটের গড় সংখ্যা তার এনট্রপি দ্বারা নীচে আবদ্ধ:
L ≥ H(X)
একটি সর্বোত্তম কোড এল ≈ H(X) অর্জন করে।
### হাফম্যান কোডিং
একটি **প্রিফিক্স-মুক্ত** কোড যা আরও সম্ভাব্য চিহ্নগুলিতে ছোট কোডগুলি বরাদ্দ করে৷
| প্রতীক | সম্ভাবনা | হাফম্যান কোড | দৈর্ঘ্য |
|---------|-------------|---------------|---------|
| ক | 0.5 | 0 | 1 |
| খ | 0.25 | 10 | 2 |
| গ | 0.125 | 110 | 3 |
| ডি | 0.125 | 111 | 3 |
গড় দৈর্ঘ্য: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 বিট/সিম্বল
এনট্রপি: H = 1.75 বিট/সিম্বল (এই ক্ষেত্রে সর্বোত্তম!)
### লসলেস বনাম ক্ষতিকর কম্প্রেশন
| প্রকার | নীতি | উদাহরণ | সীমা |
|------|------------|----------|-------|
| **ক্ষতিহীন** | পরিসংখ্যানগত অপ্রয়োজনীয়তা সরান | ZIP, PNG, FLAC | এনট্রপি রেট H(X) |
| **ক্ষতিকর** | ধারণাগতভাবে অপ্রাসঙ্গিক তথ্য সরান | JPEG, MP3, H.264 | হার-বিকৃতি ফাংশন R(D) |
**রেট-বিকৃতি তত্ত্ব:** সর্বাধিক বিকৃতি D সহ ক্ষতিকর সংকোচনের জন্য, সর্বনিম্ন হার হল R(D) = min I(X; X̂) E[d(X, X̂)] ≤ D এর সাপেক্ষে।

## অন্যান্য ক্ষেত্রের সংযোগ
### তথ্য তত্ত্ব এবং তাপগতিবিদ্যা
| ধারণা | তথ্য তত্ত্ব | তাপগতিবিদ্যা |
|---------|----------------------------|
| এনট্রপি | শ্যানন এনট্রপি H(X) | বোল্টজম্যান এনট্রপি S = k_B ln W |
| সর্বোচ্চ এনট্রপি | অভিন্ন বন্টন | তাপীয় ভারসাম্য |
| কেএল ডাইভারজেন্স | বন্টন পার্থক্য | বিনামূল্যে শক্তি পার্থক্য |
| পারস্পরিক তথ্য | শেয়ার করা তথ্য | শারীরিক সিস্টেমের মধ্যে পারস্পরিক সম্পর্ক |
গাণিতিক ফর্মগুলি অভিন্ন — শ্যানন ইচ্ছাকৃতভাবে পরিসংখ্যানগত বলবিদ্যা থেকে "এনট্রপি" শব্দটি ধার করেছিলেন।
### তথ্য তত্ত্ব এবং পরিসংখ্যান

## সারাংশ
| পরিমাণ | সূত্র (বিযুক্ত) | অর্থ |
|------------|----------------------|---------|
| এনট্রপি H(X) | −Σ p(x) লগ p(x) | গড় অনিশ্চয়তা |
| জয়েন্ট এনট্রপি H(X,Y) | −Σ p(x,y) লগ p(x,y) | জোড়ার মোট অনিশ্চয়তা |
| শর্তসাপেক্ষ এনট্রপি H(Y\|X) | H(X,Y) − H(X) | Y প্রদত্ত X সম্পর্কে অবশিষ্ট অনিশ্চয়তা |
| পারস্পরিক তথ্য I(X;Y) | H(X) − H(X\|Y) | X এবং Y এর মধ্যে শেয়ার করা তথ্য |
| কেএল ডাইভারজেন্স D_KL(P\|\|Q) | Σ P(x) লগ(P(x)/Q(x)) | বিতরণের মধ্যে "দূরত্ব" |
| ক্রস-এনট্রপি H(P,Q) | −Σ P(x) লগ Q(x) | ভুল বিতরণ ব্যবহার করে এনকোডিং খরচ |
| চ্যানেল ক্ষমতা C | সর্বোচ্চ I(X;Y) | সর্বাধিক নির্ভরযোগ্য যোগাযোগের হার |
তথ্য তত্ত্ব যা শেখা, সংকুচিত করা এবং যোগাযোগ করা যায় তার মৌলিক সীমা প্রদান করে। মেশিন লার্নিং অনুশীলনকারীদের জন্য, এটি ব্যাখ্যা করে কেন ক্রস-এনট্রপি একটি ক্ষতির ফাংশন হিসাবে কাজ করে, কীভাবে শেখা উপস্থাপনাগুলির গুণমান পরিমাপ করা যায় এবং কীভাবে মডেল জটিলতা এবং ডেটা ফিটের মধ্যে ট্রেড-অফ সম্পর্কে চিন্তা করা যায়। 1948 থেকে শ্যাননের অন্তর্দৃষ্টি আধুনিক এআই-এর সাথে টেলিকমিউনিকেশনের মতোই প্রাসঙ্গিক।
