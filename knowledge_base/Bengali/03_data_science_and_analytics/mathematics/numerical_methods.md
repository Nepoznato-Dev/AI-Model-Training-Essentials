# সংখ্যাগত পদ্ধতি
সংখ্যাসূচক পদ্ধতি হল গাণিতিক তত্ত্ব এবং ব্যবহারিক গণনার মধ্যে সেতু। যদিও বিশুদ্ধ গণিত প্রমাণ করে যে সমাধানগুলি বিদ্যমান, সংখ্যাগত পদ্ধতিগুলি আসলে সসীম নির্ভুলতার আনুমানিক উত্তরগুলি গণনা করে। প্রতিটি মেশিন লার্নিং মডেল, পদার্থবিদ্যা সিমুলেশন, এবং ডেটা বিশ্লেষণ পাইপলাইন শেষ পর্যন্ত সংখ্যাসূচক গণনার উপর নির্ভর করে। নির্ভরযোগ্য সফ্টওয়্যার তৈরির জন্য এই পদ্ধতিগুলি বোঝা — তাদের নির্ভুলতা, স্থিতিশীলতা এবং সীমাবদ্ধতাগুলি — অপরিহার্য৷

## ভাসমান-বিন্দু পাটিগণিত
কম্পিউটার সসীম নির্ভুলতা সহ বাস্তব সংখ্যা উপস্থাপন করে। **IEEE 754 মান** সংজ্ঞায়িত করে কিভাবে ফ্লোটিং-পয়েন্ট সংখ্যা সংরক্ষিত এবং ম্যানিপুলেট করা হয়।
### IEEE 754 ফরম্যাট
| বিন্যাস | বিট | সূচক | মানতিসা | আনুমানিক দশমিক সংখ্যা | পরিসীমা |
|---------|------|---------|----------|----------------------------|-------|
| অর্ধেক (fp16) | 16 | 5 | 10 | 3.3 | ±6.5 × 10⁴ |
| একক (fp32) | 32 | 8 | 23 | 7.2 | ±3.4 × 10³⁸ |
| ডাবল (fp64) | 64 | 11 | 52 | 15.9 | ±1.8 × 10³⁰⁸ |
### মেশিন এপসিলন
**মেশিন এপসিলন** (ε_mach) হল ক্ষুদ্রতম সংখ্যা যেমন 1 + ε_mach > 1 ভাসমান-বিন্দুতে।
| বিন্যাস | ε_মাচ |
|---------|---------|
| fp16 | 2⁻¹⁰ ≈ 9.8 × 10⁻⁴ |
| fp32 | 2⁻²³ ≈ 1.2 × 10⁻⁷ |
| fp64 | 2⁻⁵² ≈ 2.2 × 10⁻¹⁶ |
### সাধারণ ক্ষতি
| পিটফল | উদাহরণ | পরিণতি |
|---------|---------|---------------|
| **বিপর্যয়কর বাতিলকরণ** | ছোট x এর জন্য কম্পিউটিং (1 + x) −1 | উল্লেখযোগ্য সংখ্যার ক্ষতি |
| **শোষণ** | fp32 এ 10⁸ + 1 = 10⁸ | বড় অঙ্কে ছোট মান হারিয়েছে |
| **অ-সহযোগিতা** | (a + b) + c ≠ a + (b + c) | সমষ্টি অর্ডার বিষয় |
| **শুন্যের কাছাকাছি ** | 1 / 10⁻³⁰⁰ → ওভারফ্লো | ইনফিনিটি বা NaN |
### প্রশমন কৌশল
| কৌশল | বর্ণনা |
|------------|-------------|
| **কাহান সমষ্টি** | শোষণ ত্রুটি কমাতে ক্ষতিপূরণ যোগফল |
| **কাহান-বাবুস্কা-নিউমায়ের** | কাহান সমষ্টির উন্নত সংস্করণ |
| **বাছাইকৃত সমষ্টি** | শোষণ এড়াতে প্রথমে ছোট সংখ্যার যোগফল |
| **ডাবল-ডাবল পাটিগণিত** | বর্ধিত নির্ভুলতার জন্য জোড়া জোড়া ব্যবহার করুন |
| **কন্ডিশনিং বিশ্লেষণ** | বুঝুন যদি সমস্যা নিজেই ত্রুটিগুলিকে প্রসারিত করে |

## রুট ফাইন্ডিং
x খুঁজে বের করা যেমন f(x) = 0।
### দ্বিখণ্ডিত পদ্ধতি
| সম্পত্তি | মান |
|----------|---------|
| প্রয়োজন | f অবিরাম, f(a) এবং f(b) এর বিপরীত চিহ্ন আছে |
| কনভারজেন্স | রৈখিক (ত্রুটি প্রতিটি ধাপে অর্ধেক করে) |
| নিশ্চয়তা? | হ্যাঁ — সর্বদা একত্রিত হয় |
| d সংখ্যার জন্য পুনরাবৃত্তি | ≈ d / log₁₀(2) ≈ 3.32d |
**অ্যালগরিদম:**
1. বিরতি দিয়ে শুরু করুন [a, b] যেখানে f(a) · f(b) < 0
2. মধ্যবিন্দু গণনা করুন c = (a + b) / 2
3. যদি f(c) = 0 বা |b − a| < সহনশীলতা, থামুন
4. যদি f(a) · f(c) < 0, সেট b = c; else a = c সেট করুন
5. পুনরাবৃত্তি করুন
### নিউটন-র্যাফসন পদ্ধতি
| সম্পত্তি | মান |
|----------|---------|
| প্রয়োজন | f পার্থক্যযোগ্য, f'(x) ≠ 0 মূলে |
| কনভারজেন্স | দ্বিঘাত (মূলের কাছাকাছি) |
| নিশ্চয়তা? | না — বিচ্যুত বা চক্র হতে পারে |
| হালনাগাদ নিয়ম | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**কাজ করা উদাহরণ:** f(x) = x² − 2 = 0 সমাধান করে √2 খুঁজুন।
- f'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x₂ = 1.4167 − (2.0069 − 2) / 2.8333 = 1.4142
- x₃ = 1.41421356... (8 দশমিক স্থানে সঠিক)
### সেক্যান্ট পদ্ধতি
নিউটনের পদ্ধতির মত কিন্তু আনুমানিক ডেরিভেটিভ:
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
| সম্পত্তি | মান |
|----------|---------|
| কনভারজেন্স | সুপারলাইনার (ক্রম ≈ 1.618, সোনালী অনুপাত) |
| প্রয়োজন | দুটি প্রাথমিক অনুমান (কোন ডেরিভেটিভ প্রয়োজন নেই) |
### রুট-ফাইন্ডিং পদ্ধতির তুলনা
| পদ্ধতি | কনভারজেন্স | ডেরিভেটিভ প্রয়োজন? | নিশ্চয়তা? | প্রতি ধাপে খরচ |
|---------|---------------|------|-------------|---------------|
| বিভাজন | রৈখিক (1) | না | হ্যাঁ | 1 ফাংশন eval |
| নিউটন-র্যাফসন | দ্বিঘাত (2) | হ্যাঁ | না | 2 ফাংশন ইভাল |
| সেকান্ট | সুপারলিনিয়ার (1.618) | না | না | 1 ফাংশন eval |
| ব্রেন্ট এর পদ্ধতি | অতিরৈখিক | না | হ্যাঁ | পরিবর্তিত হয় |
**ব্রেন্টের পদ্ধতি** দ্বিখণ্ডন (গ্যারান্টিড কনভারজেন্স) কে সেকেন্ট/ইনভার্স কোয়াড্রাটিক ইন্টারপোলেশন (দ্রুত কনভারজেন্স) এর সাথে একত্রিত করে। এটি বেশিরভাগ সংখ্যাসূচক লাইব্রেরিতে ডিফল্ট রুট-ফাইন্ডার।

## সংখ্যাগত একীকরণ (চতুর্ভুজ)
কম্পিউটিং ∫ₐᵇ f(x) dx প্রায়।
### পদ্ধতি
| পদ্ধতি | সূত্র | ত্রুটি | অর্ডার |
|---------|---------|---------|-------|
| **আয়তক্ষেত্র (মধ্যবিন্দু)** | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **ট্রাপিজয়েডাল** | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **সিম্পসনের ১/৩** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | O(h⁴) | 3 |
| **সিম্পসনের 3/8** | 4টি সমান ব্যবধানযুক্ত বিন্দু ব্যবহার করে | O(h⁴) | 4 |
| **গাউসিয়ান চতুর্ভুজ** | সর্বোত্তম নোড বসানো | O(h²ⁿ) | n পয়েন্ট |
### যৌগিক নিয়ম
h = (b−a)/n প্রস্থের n সাব-ইনটারভালের জন্য:
| নিয়ম | যৌগিক সূত্র | ত্রুটি |
|------|-------------------|---------|
| কম্পোজিট ট্র্যাপিজয়েডাল | h[f(a)/2 + Σf(xᵢ) + f(b)/2] | O(h²) |
| কম্পোজিট সিম্পসনের | h/3[f(a) + 4Σf(বিজোড়) + 2Σf(জোড়) + f(b)] | O(h⁴) |
**কাজ করা উদাহরণ:** আনুমানিক ∫₀¹ e^(−x²) dx n = 4 সহ যৌগিক ট্র্যাপিজয়েডাল ব্যবহার করে।
- h = 0.25, পয়েন্ট: 0, 0.25, 0.5, 0.75, 1
- f(0) = 1, f(0.25) = 0.9394, f(0.5) = 0.7788, f(0.75) = 0.5698, f(1) = 0.3679
- T = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- সত্য মান: ≈ 0.7468 (ত্রুটি ≈ 0.5%)
### অভিযোজিত চতুর্ভুজ
স্বয়ংক্রিয়ভাবে ব্যবধানগুলিকে উপবিভাজন করে যেখানে ফাংশন দ্রুত পরিবর্তিত হয়, যেখানে এটি মসৃণ হয় সেখানে কম পয়েন্ট ব্যবহার করে। এটি`scipy.integrate.quad`ব্যবহার করে (QUADPACK এর উপর ভিত্তি করে)।

## ইন্টারপোলেশন
পরিচিত ডেটা পয়েন্টের মধ্যে মান অনুমান করা।
### পদ্ধতি
| পদ্ধতি | বর্ণনা | মসৃণতা | দোলনা |
|---------|-------------|------------|-------------|
| ** নিকটতম প্রতিবেশী** | নিকটতম ডেটা পয়েন্ট ব্যবহার করুন | অবিচ্ছিন্ন | কোনটিই না |
| **রৈখিক** | সরল রেখা দিয়ে বিন্দু সংযুক্ত করুন | C⁰ (একটানা) | কোনটিই না |
| **বহুপদ (ল্যাগ্রেঞ্জ)** | সমস্ত বিন্দুর মাধ্যমে একক বহুপদ | C^∞ | অনেক পয়েন্টের জন্য গুরুতর (Runge এর ঘটনা) |
| **কিউবিক স্প্লাইন** | পিসওয়াইজ কিউবিক, জয়েন্টগুলোতে মসৃণ | C² | সর্বনিম্ন |
| **রেডিয়াল বেসিস ফাংশন** | রেডিয়াল কার্নেলের ওজনযুক্ত সমষ্টি | কার্নেলের উপর নির্ভর করে | কম |
### ল্যাগ্রেঞ্জ ইন্টারপোলেশন
দেওয়া n+1 পয়েন্ট (x₀, y₀), ..., (xₙ, yₙ), ডিগ্রী ≤ n এর অনন্য বহুপদী সমস্ত বিন্দুর মধ্য দিয়ে যাচ্ছে:
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**রাঞ্জের ঘটনা:** সমান দূরত্বের বিন্দুতে উচ্চ-ডিগ্রী বহুপদী ইন্টারপোলেশন প্রান্তের কাছাকাছি বন্যভাবে দোলাতে পারে। চেবিশেভ নোড বা স্প্লাইন ব্যবহার করে প্রশমিত।
### কিউবিক স্প্লাইন্স
টুকরো টুকরো ঘনক বহুপদী যা C² অবিচ্ছিন্ন (একটানা দ্বিতীয় ডেরিভেটিভ)।
| প্রকার | সীমানা শর্ত |
|------|-------------------|
| প্রাকৃতিক স্প্লাইন | S''(x₀) = S''(xₙ) = 0 |
| ক্ল্যাম্পড স্প্লাইন | S'(x₀) এবং S'(xₙ) নির্দিষ্ট |
| নট-এ-নট | x₁ এবং xₙ₋₁ | এ তৃতীয় ডেরিভেটিভ ক্রমাগত

## ODE সমাধানকারী
সাধারণ ডিফারেনশিয়াল সমীকরণ dy/dt = f(t, y) সংখ্যাগতভাবে সমাধান করা।
### অয়লারের পদ্ধতি
সহজতম ODE সমাধানকারী।
**আপডেট:** y_{n+1} = y_n + h · f(t_n, y_n)
| সম্পত্তি | মান |
|----------|---------|
| অর্ডার | 1 (প্রতি ধাপে ত্রুটি: O(h²), বিশ্বব্যাপী: O(h)) |
| স্থিতিশীলতা | শর্তসাপেক্ষে স্থিতিশীল (ছোট h প্রয়োজন) |
| খরচ | প্রতি ধাপে 1টি ফাংশন মূল্যায়ন |
### রুঞ্জ-কুট্টা পদ্ধতি
| পদ্ধতি | অর্ডার | পর্যায় | নোট |
|---------|-------|---------|-------|
| **অয়লার** | 1 | 1 | সহজতম |

| **ডোরমান্ড-প্রিন্স (RK45)** | 4(5) | 6 | অভিযোজিত ধাপের আকার (ode45 এ ব্যবহৃত) |
### ক্লাসিক RK4 (৪র্থ ক্রম রুঞ্জ-কুট্টা)
k₁ = f(t_n, y_n)
k₂ = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk₂/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k₂ + 2k₃ + k₄) / 6
| সম্পত্তি | মান |
|----------|---------|
| অর্ডার | 4 (বিশ্বব্যাপী ত্রুটি: O(h⁴)) |
| খরচ | প্রতি ধাপে 4টি ফাংশন মূল্যায়ন |
| স্থিতিশীলতা | অয়লারের চেয়ে অনেক ভালো |
| ব্যবহার | অ-কঠোর ODE-র জন্য ডিফল্ট |
### শক্ত ওডিই
একটি **কঠোর** ODE-এর উপাদান রয়েছে যা বিভিন্ন সময় স্কেলে পরিবর্তিত হয়। স্পষ্ট পদ্ধতি (ইউলার, আরকে 4) অব্যবহারিকভাবে ছোট ধাপের আকার প্রয়োজন।

## সংখ্যাগত স্থিতিশীলতা এবং কন্ডিশনিং
### শর্ত নম্বর
**কন্ডিশন নম্বর** পরিমাপ করে যে ইনপুটে ছোট পরিবর্তনের তুলনায় কোনো সমস্যার আউটপুট কতটা পরিবর্তিত হয়।
একটি লিনিয়ার সিস্টেমের জন্য Ax = b: κ(A) = ||A|| · ||A⁻¹||
| κ(A) | ব্যাখ্যা |
|-------|---------------|
| ≈ 1 | ভাল-কন্ডিশনড |
| 10³ | হালকা সংবেদনশীল |
| 10⁸ | অসুস্থ (নির্ভুলতার ~8 সংখ্যা হারান) |
| → ∞ | একবচন (কোন অনন্য সমাধান) |
### অ্যালগরিদমের স্থায়িত্ব
একটি অ্যালগরিদম **সংখ্যাগতভাবে স্থিতিশীল** হয় যদি ইনপুটে ছোট গোলযোগের ফলে আউটপুটে ছোট গোলযোগ হয় (সমস্যার শর্ত সংখ্যার সাথে সম্পর্কিত)।
| অ্যালগরিদম | স্থিতিশীল? | নোট |
|------------|---------|---------|
| আংশিক পিভটিং সহ গাউসিয়ান নির্মূল | হ্যাঁ | স্ট্যান্ডার্ড পদ্ধতি |
| QR এর মাধ্যমে eigenvalues ​​গণনা করা | হ্যাঁ | অনগ্রসর স্থিতিশীল |
| সাদামাটা সমষ্টি (বড় + ছোট প্রথমে) | না | কাহান সমষ্টি ব্যবহার করুন |
| E[X²] − (E[X])² | হিসাবে কম্পিউটিং প্রকরণ সম্ভাব্য না | ওয়েলফোর্ডের অনলাইন অ্যালগরিদম ব্যবহার করুন |
### ওয়েলফোর্ডের অনলাইন অ্যালগরিদম
চলমান গড় এবং প্রকরণের সংখ্যাগতভাবে স্থিতিশীল গণনা:
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

এটি নিষ্পাপ টু-পাস সূত্রে ঘটে যাওয়া বিপর্যয়কর বাতিলকরণ এড়ায়।
