# সংকেত প্রক্রিয়াকরণ
সিগন্যাল প্রসেসিং হল সংকেত বিশ্লেষণ, পরিবর্তন এবং সংশ্লেষণ করার বিজ্ঞান — সময়, স্থান বা ফ্রিকোয়েন্সির সাথে পরিবর্তিত ভৌত পরিমাণের উপস্থাপনা। অডিও, ছবি, ভিডিও, সেন্সর ডেটা, মস্তিষ্কের তরঙ্গ, স্টকের দাম - সবই সংকেত। সিগন্যাল প্রসেসিং এর গাণিতিক টুলস (ফুরিয়ার ট্রান্সফর্মস, ফিল্টার, স্যাম্পলিং থিওরি) মেশিন লার্নিং, যোগাযোগ, মেডিকেল ইমেজিং এবং ডাটা নিয়ে কাজ করে এমন প্রতিটি ক্ষেত্রের ভিত্তি।

## ফুরিয়ার ট্রান্সফর্ম
**ফুরিয়ার ট্রান্সফর্ম** একটি সংকেতকে তার উপাদান ফ্রিকোয়েন্সিতে পচিয়ে দেয়।
### ক্রমাগত ফুরিয়ার ট্রান্সফর্ম
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
বিপরীত: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### ফুরিয়ার ট্রান্সফর্ম পেয়ার
| টাইম ডোমেন x(t) | ফ্রিকোয়েন্সি ডোমেন X(f) |
|-------------------------------------------- |
| আয়তক্ষেত্রাকার নাড়ি | sinc ফাংশন |
| sinc ফাংশন | আয়তক্ষেত্রাকার নাড়ি |
| গাউসিয়ান e^{−at²} | গাউসিয়ান (√(π/a))e^{−π²f²/a} |
| ডিরাক ডেল্টা δ(t) | 1 (সমস্ত ফ্রিকোয়েন্সি) |
| জটিল সূচকীয় e^{j2πf₀t} | δ(f − f₀) |
| কোসাইন cos(2πf₀t) | ½[δ(f−f₀) + δ(f+f₀)] |
### মূল বৈশিষ্ট্য
| সম্পত্তি | টাইম ডোমেন | ফ্রিকোয়েন্সি ডোমেন |
|------------|---------------|-------------------|
| রৈখিকতা | ax₁(t) + bx₂(t) | aX₁(f) + bX₂(f) |
| সময় পরিবর্তন | x(t − t₀) | X(f)e^{−j2πft₀} |
| ফ্রিকোয়েন্সি শিফট | x(t)e^{j2πf₀t} | X(f − f₀) |
| আবর্তন | x₁(t) ∗ x₂(t) | X₁(f) · X₂(f) |
| গুণ | x₁(t) · x₂(t) | X₁(f) ∗ X₂(f) |
| পার্থক্য | dx/dt | j2πf X(f) |
| পার্সেভালের উপপাদ্য | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**কনভোলিউশন থিওরেম:** সময়ের কনভল্যুশন = ফ্রিকোয়েন্সিতে গুন। এটি সবচেয়ে গুরুত্বপূর্ণ সম্পত্তি - এটি ব্যয়বহুল কনভল্যুশন অপারেশনকে সস্তা গুণে পরিণত করে।
### ডিসক্রিট ফুরিয়ার ট্রান্সফর্ম (DFT)
একটি ক্রম x[0], x[1], ..., x[N−1]:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}, k = 0, 1, ..., N−1
| সম্পত্তি | মান |
|----------|---------|
| ইনপুট | N বাস্তব বা জটিল নমুনা |
| আউটপুট | এন জটিল ফ্রিকোয়েন্সি বিন |
| ফ্রিকোয়েন্সি রেজোলিউশন | f_s/N (যেখানে f_s স্যাম্পলিং রেট) |
| Nyquist ফ্রিকোয়েন্সি | f_s/2 (সর্বোচ্চ প্রতিনিধিত্বযোগ্য ফ্রিকোয়েন্সি) |
| জটিলতা | O(N²) সরাসরি গণনা |
### ফাস্ট ফোরিয়ার ট্রান্সফর্ম (FFT)
**FFT** O(N²) এর পরিবর্তে O(N log N) এ DFT গণনা করে।
| এন | O(N²) অপারেশন | O(N log N) অপারেশন | স্পিডআপ |
|---|------|----------------------|---------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10¹² | 20,971,520 | 52,428× |
এফএফটি এখন পর্যন্ত উদ্ভাবিত সবচেয়ে গুরুত্বপূর্ণ অ্যালগরিদমগুলির মধ্যে একটি। এটি রিয়েল-টাইম অডিও প্রসেসিং, ইমেজ কম্প্রেশন (JPEG), ওয়্যারলেস কমিউনিকেশন (OFDM), এবং বর্ণালী বিশ্লেষণ সক্ষম করে।

## ল্যাপ্লেস ট্রান্সফর্ম
**ল্যাপ্লেস ট্রান্সফর্ম** অস্থির সিস্টেম এবং ক্ষণস্থায়ী বিশ্লেষণ পরিচালনা করতে ফুরিয়ার ট্রান্সফর্মকে প্রসারিত করে।
F(s) = ∫₀^∞ f(t) e^{−st} dt, যেখানে s = σ + jω
### সাধারণ ল্যাপ্লেস রূপান্তর
| f(t) | F(গুলি) | অভিসারী অঞ্চল |
|------|------|----------------------|
| δ(t) (আবেগ) | 1 | সবগুলো |
| u(t) (পদক্ষেপ) | 1/s | পুনঃ(গুলি) > 0 |
| e^{−at}u(t) | 1/(s+a) | পুনঃ(গুলি) > −a |
| tⁿu(t) | n!/s^{n+1} | পুনঃ(গুলি) > 0 |
| sin(ωt)u(t) | ω/(s²+ω²) | পুনঃ(গুলি) > 0 |
| cos(ωt)u(t) | s/(s²+ω²) | পুনঃ(গুলি) > 0 |
### ফুরিয়ার ট্রান্সফর্মের সাথে সংযোগ
যখন σ = 0 (s = jω), ল্যাপ্লেস ট্রান্সফর্ম ফুরিয়ার ট্রান্সফর্মে হ্রাস পায়। ল্যাপ্লেস ট্রান্সফর্ম বৃদ্ধি/ক্ষয় (σ) সম্পর্কে তথ্য অন্তর্ভুক্ত করে আরও সম্পূর্ণ চিত্র প্রদান করে।

## জেড-ট্রান্সফর্ম
**Z-ট্রান্সফর্ম** হল ল্যাপ্লেস ট্রান্সফর্মের বিচ্ছিন্ন-সময়ের সমতুল্য।
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### সাধারণ জেড-ট্রান্সফর্ম
| x[n] | X(z) | ROC |
|------|------|------|
| δ[n] | 1 | সব z |
| u[n] (পদক্ষেপ) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|a\| |
| naⁿu[n] | az/(z−a)² | \|z\| > \|a\| |
| sin(ω₀n)u[n] | z sin(ω₀)/(z²−2z cos(ω₀)+1) | \|z\| > 1 |
### অন্যান্য রূপান্তরের সাথে সম্পর্ক
| রূপান্তর | ডোমেন | পরিবর্তনশীল |
|------------|---------|------------|
| ফুরিয়ার | ক্রমাগত ফ্রিকোয়েন্সি | f বা ω |
| ল্যাপ্লেস | জটিল ফ্রিকোয়েন্সি | s = σ + jω |
| Z-রূপান্তর | জটিল ফ্রিকোয়েন্সি (বিযুক্ত) | z = e^{sT} |
z-প্লেনের একক বৃত্ত (|z| = 1) ফুরিয়ার রূপান্তরের সাথে মিলে যায়।

## ফিল্টার
ফিল্টারগুলি বেছে বেছে নির্দিষ্ট ফ্রিকোয়েন্সি উপাদান পাস বা ব্লক করে।
### ফিল্টার প্রকার
| প্রকার | পাস | ব্লক | আবেদন |
|------|---------|---------|-------------|
| **নিম্ন-পাস** | কম ফ্রিকোয়েন্সি | উচ্চ ফ্রিকোয়েন্সি | মসৃণ, অ্যান্টি-আলিয়াসিং |
| **উচ্চ পাস** | উচ্চ ফ্রিকোয়েন্সি | কম ফ্রিকোয়েন্সি | প্রান্ত সনাক্তকরণ, শব্দ অপসারণ |
| **ব্যান্ড-পাস** | ফ্রিকোয়েন্সি একটি পরিসীমা | সীমার বাইরে | চ্যানেল নির্বাচন (রেডিও) |
| **ব্যান্ড-স্টপ (খাঁজ)** | একটি পরিসীমা ছাড়া সবকিছু | একটি নির্দিষ্ট পরিসর | পাওয়ার লাইন হাম অপসারণ |
### এফআইআর বনাম আইআইআর ফিল্টার
| সম্পত্তি | FIR (Finite Impulse Response) | IIR (Infinite Impulse Response) |
|------------|--------------------------------------------------------------------------------------------|
| আবেগ প্রতিক্রিয়া | সসীম সময়কাল | অসীম সময়কাল |
| স্থিতিশীলতা | সর্বদা স্থিতিশীল | অস্থির হতে পারে |
| পর্যায় | ঠিক রৈখিক হতে পারে | সাধারণত অরৈখিক পর্যায় |
| প্রতিক্রিয়া | না | হ্যাঁ |
| গণনা | আরো সহগ প্রয়োজন | একই রোল-অফের জন্য কম সহগ |
| ডিজাইন | জানালা, পার্কস-ম্যাকক্লেলান | বাটারওয়ার্থ, চেবিশেভ, উপবৃত্তাকার |
| স্থানান্তর ফাংশন | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### ফিল্টার ডিজাইন স্পেসিফিকেশন
| পরামিতি | বর্ণনা |
|------------|-------------|
| **পাসব্যান্ড** | ফ্রিকোয়েন্সি পরিসীমা যা সর্বনিম্ন ক্ষতির সাথে পাস করা উচিত |
| **স্টপব্যান্ড** | ফ্রিকোয়েন্সি পরিসীমা যা কমানো উচিত |
| **কাটঅফ ফ্রিকোয়েন্সি** | পাসব্যান্ড এবং স্টপব্যান্ডের মধ্যে সীমানা |
| **লহর** | পাসব্যান্ড (বা স্টপব্যান্ড) লাভের পরিবর্তন |
| **রোল-অফ** | ক্ষীণকরণের হার (অষ্টক বা দশকে ডিবি) |
| **ট্রানজিশন ব্যান্ড** | পাসব্যান্ড এবং স্টপব্যান্ডের মধ্যে অঞ্চল |
### সাধারণ ফিল্টার ডিজাইন

## নমুনা তত্ত্ব
### নিকুইস্ট-শ্যানন স্যাম্পলিং থিওরেম
একটি অবিচ্ছিন্ন সংকেত তার নমুনা থেকে পুরোপুরি পুনর্গঠন করা যেতে পারে যদি নমুনার হার সর্বোচ্চ ফ্রিকোয়েন্সির দ্বিগুণ অতিক্রম করে:
f_s > 2f_max
| মেয়াদ | সংজ্ঞা |
|------|------------|
| **স্যাম্পলিং রেট** (f_s) | প্রতি সেকেন্ডে নমুনার সংখ্যা |
| **নিকুইস্ট রেট** | 2f_max (ন্যূনতম স্যাম্পলিং রেট) |
| **নিকুইস্ট ফ্রিকোয়েন্সি** | f_s/2 (সর্বোচ্চ প্রতিনিধিত্বযোগ্য ফ্রিকোয়েন্সি) |
| **আলিয়াসিং** | f_s < 2f_max | হলে উচ্চ ফ্রিকোয়েন্সিগুলি কম ফ্রিকোয়েন্সি হিসাবে মাস্করাড করে
### সাধারণ স্যাম্পলিং রেট
| আবেদন | হার | Nyquist ফ্রিকোয়েন্সি |
|---------------|------|---------|
| টেলিফোন বক্তৃতা | 8 kHz | 4 kHz |
| অডিও সিডি | 44.1 kHz | 22.05 kHz |
| পেশাদার অডিও | 48 kHz | 24 kHz |
| উচ্চ-রেজোলিউশন অডিও | 96 kHz | 48 kHz |
| ভিডিও (30 fps) | 30 Hz (টেম্পোরাল) | 15 Hz |
### অ্যান্টি-আলিয়াসিং
নমুনা নেওয়ার আগে, একটি **অ্যান্টি-আলিয়াসিং ফিল্টার** (লো-পাস) অ্যালিয়াসিং প্রতিরোধ করতে f_s/2 এর উপরে ফ্রিকোয়েন্সিগুলি সরিয়ে দেয়।

## জানালা
একটি সিগন্যালের একটি সীমিত অংশ বিশ্লেষণ করার সময়, আমরা একটি আয়তক্ষেত্রাকার উইন্ডো দ্বারা গুনিত করি, যার ফলে বর্ণালী ফুটো হয়। **উইন্ডো ফাংশন** এই ফুটো কমায়।
### সাধারণ উইন্ডোজ
| জানালা | প্রধান লোব প্রস্থ | সাইড লোব লেভেল | কেস ব্যবহার করুন |
|---------|------------|------------|
| আয়তক্ষেত্রাকার | সংকীর্ণ | −13 dB | যখন রেজোলিউশন সবচেয়ে গুরুত্বপূর্ণ |
| হ্যান | 2× আয়তক্ষেত্রাকার | −31 dB | সাধারণ উদ্দেশ্য |
| হ্যামিং | 2× আয়তক্ষেত্রাকার | −41 dB | নিকটতম পার্শ্ব লব হ্রাস |
| ব্ল্যাকম্যান | 3× আয়তক্ষেত্রাকার | −58 dB | উচ্চ গতিশীল পরিসীমা |
| কায়সার | সামঞ্জস্যযোগ্য | সামঞ্জস্যযোগ্য (β এর মাধ্যমে) | যখন ট্রেড-অফ টিউনযোগ্য হয় |
### বর্ণালী ফুটো
একটি উইন্ডো দ্বারা একটি সংকেত গুন করলে এর বর্ণালীটি উইন্ডোর বর্ণালীর সাথে জড়িত হয়। প্রশস্ত প্রধান লোব ফ্রিকোয়েন্সি রেজোলিউশন হ্রাস; নিচের দিকের লোব ফুটো কমায়।

## ওয়েভলেট
**ওয়েভলেট** হল ছোট, স্থানীয় তরঙ্গের মতো ফাংশন যা বহু-রেজোলিউশন সংকেত বিশ্লেষণের জন্য ব্যবহৃত হয়।
### ওয়েভলেট ট্রান্সফর্ম
ফুরিয়ার ট্রান্সফর্মের বিপরীতে (যা বিশ্বব্যাপী ফ্রিকোয়েন্সি তথ্য দেয়), ওয়েভলেট ট্রান্সফর্ম **সময়-ফ্রিকোয়েন্সি** স্থানীয়করণ দেয়।
| রূপান্তর | সময় রেজোলিউশন | ফ্রিকোয়েন্সি রেজোলিউশন |
|------------|-----------------------------------------|
| ফুরিয়ার | কোনটিই নয় (বিশ্বব্যাপী) | চমৎকার |
| স্বল্প সময়ের FT | স্থির (জানালার আকার) | স্থির |
| ওয়েভলেট | পরিবর্তনশীল (উচ্চ ফ্রিকোয়েন্সিতে ভাল) | পরিবর্তনশীল (কম ফ্রিকোয়েন্সিতে ভাল) |

## সারাংশ
| টুল | ডোমেন | মূল অন্তর্দৃষ্টি |
|------|---------|---------------|
| ফুরিয়ার ট্রান্সফর্ম | সময় → ফ্রিকোয়েন্সি | সংকেত হল সাইনুসয়েডের যোগফল |
| ল্যাপ্লেস ট্রান্সফর্ম | সময় → জটিল ফ্রিকোয়েন্সি | ক্ষণস্থায়ী এবং স্থিতিশীলতা পরিচালনা করে |
| জেড-ট্রান্সফর্ম | বিচ্ছিন্ন সময় → জটিল | ডিজিটাল ফিল্টার বিশ্লেষণ এবং নকশা |
| FFT | দক্ষ DFT গণনা | O(N²) এর পরিবর্তে O(N log N) |
| ফিল্টার | ফ্রিকোয়েন্সি নির্বাচন | আপনার যা প্রয়োজন তা পাস করুন, যা করবেন না তা ব্লক করুন |
| স্যাম্পলিং থিওরেম | ক্রমাগত ↔ বিযুক্ত | নমুনা যথেষ্ট দ্রুত, কিছুই হারান |
| জানালা | সময়-ফ্রিকোয়েন্সি ট্রেড-অফ | ভারসাম্য রেজোলিউশন এবং ফুটো |
| ওয়েভলেট | বহু-রেজোলিউশন বিশ্লেষণ | সময় এবং ফ্রিকোয়েন্সি উভয় ক্ষেত্রেই স্থানীয় |
সিগন্যাল প্রসেসিং ডেটা বোঝার, বিশ্লেষণ এবং ম্যানিপুলেট করার জন্য গাণিতিক ভিত্তি প্রদান করে। প্রতিটি মেশিন লার্নিং পাইপলাইন যা টাইম সিরিজ, অডিও, ইমেজ বা সেন্সর ডেটার সাথে কাজ করে সেগুলি অস্পষ্টভাবে সিগন্যাল প্রসেসিং ধারণা ব্যবহার করে। ফুরিয়ার ট্রান্সফর্ম, বিশেষ করে, যে কোনো তথ্য বিজ্ঞানীর জন্য ক্যালকুলাসের পর সবচেয়ে গুরুত্বপূর্ণ গাণিতিক হাতিয়ার।
