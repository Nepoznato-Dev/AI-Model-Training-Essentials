# স্টোকাস্টিক প্রসেস
একটি **স্টোকাস্টিক প্রক্রিয়া** হল সময় (বা স্থান) দ্বারা সূচিত করা এলোমেলো ভেরিয়েবলের একটি সংগ্রহ। যদিও সম্ভাব্যতা তত্ত্ব পৃথক এলোমেলো ঘটনাগুলি অধ্যয়ন করে, স্টোকাস্টিক প্রক্রিয়াগুলি অধ্যয়ন করে যে কীভাবে এলোমেলোতা সময়ের সাথে বিকশিত হয়। তারা স্টকের দাম, সারির দৈর্ঘ্য, রোগের বিস্তার, ভাষা তৈরি এবং মেশিন লার্নিং মডেলের প্রশিক্ষণ গতিশীলতার মডেল করে।
---

## ভিত্তি
### সংজ্ঞা
একটি স্টকাস্টিক প্রক্রিয়া {X_t : t ∈ T} হল একটি সাধারণ সম্ভাব্যতার স্থানের উপর সংজ্ঞায়িত এলোমেলো ভেরিয়েবলের একটি পরিবার। T হল **সূচক সেট** (সময়):
- **বিচ্ছিন্ন-সময়:** T = {0, 1, 2, ...}
- **একটানা-সময়:** T = [0, ∞)
**স্টেট স্পেস** S হল সম্ভাব্য মানগুলির সেট যা X_t নিতে পারে।
### মূল বৈশিষ্ট্য
| সম্পত্তি | সংজ্ঞা |
|----------|------------|
| **স্থিরতা** | (X_{t₁}, ..., X_{tₖ}) এর যৌথ বণ্টন একই (X_{t₁+τ}, ..., X_{tₖ+τ}) |
| **স্বাধীনতা** | t ≠ s | এর জন্য X_s থেকে X_t স্বাধীন
| **আর্গোডিসিটি** | সময়ের গড় একত্রিত হয় গড়ে |
| **মার্কভ সম্পত্তি** | ভবিষ্যৎ নির্ভর করে শুধু বর্তমানের উপর, অতীত নয়
| **মার্টিঙ্গেল** | প্রত্যাশিত ভবিষ্যতের মান বর্তমান মানের সমান |

## মার্কভ চেইনস
একটি **মার্কভ চেইন** একটি স্টোকাস্টিক প্রক্রিয়া যেখানে ভবিষ্যত অবস্থা শুধুমাত্র বর্তমান অবস্থার উপর নির্ভর করে (স্মৃতিহীন সম্পত্তি)।
### ডিসক্রিট-টাইম মার্কভ চেইনস (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**ট্রানজিশন ম্যাট্রিক্স** P এ এন্ট্রি আছে p_{ij} = P(j এ যান | বর্তমানে i এ)।
| সম্পত্তি | বিবৃতি |
|------------|------------|
| সারি যোগফল | প্রতিটি সারির যোগফল 1: Σⱼ p_{ij} = 1 |
| n-পদক্ষেপ রূপান্তর | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| স্থির বিতরণ | πP = π (ইগেনভ্যালু 1 সহ বাম ইজেনভেক্টর) |
### রাজ্যের শ্রেণীবিভাগ
| মেয়াদ | সংজ্ঞা |
|------|------------|
| **পুনরাবৃত্ত** | শৃঙ্খল 1 | সম্ভাব্যতা সহ i রাজ্যে ফিরে আসে
| **ক্ষণস্থায়ী** | কখনো ফিরে না আসার অ-শূন্য সম্ভাবনা |
| **শোষক** | p_{ii} = 1 (একবার ঢোকে, কখনো বাম না) |
| **কাল** | রিটার্ন সময়ের GCD; সময়কাল 1 = পর্যায়ক্রমিক |
| **যোগাযোগ* | রাজ্য i এবং j একে অপরের কাছে পৌঁছাতে পারে |
### স্থির বিতরণ
একটি অপরিবর্তনীয়, ধনাত্মক পুনরাবৃত্ত মার্কভ চেইনের জন্য, স্থির বন্টন π বিদ্যমান, অনন্য এবং সন্তুষ্ট:
πP = π, Σᵢ πᵢ = 1
**ব্যাখ্যা:** πᵢ = রাজ্যে অতিবাহিত সময়ের দীর্ঘমেয়াদী অনুপাত i.
**কাজ করা উদাহরণ:** {রোদ, বৃষ্টি} রাজ্যের আবহাওয়ার মডেল।
P = [[0.9, 0.1], [0.5, 0.5]] (সারি: রোদ থেকে, বৃষ্টি থেকে)
স্থির বিতরণ: πP = π
- π₁ = 0.9π₁ + 0.5π₂
- π₂ = 0.1π₁ + 0.5π₂
- π₁ + π₂ = 1
- সমাধান: π₁ = 5/6 ≈ 0.833, π₂ = 1/6 ≈ 0.167
### স্থিরতার সাথে কনভারজেন্স
একটি অপরিবর্তনীয়, এপিরিওডিক, ধনাত্মক পুনরাবৃত্ত শৃঙ্খলের জন্য:
- Pⁿ → Π (π এর সমান সমস্ত সারি সহ ম্যাট্রিক্স) n → ∞ হিসাবে
- **মিশ্রণের সময়:** বন্টন π-এর কাছাকাছি না হওয়া পর্যন্ত ধাপের সংখ্যা
- **স্পেকট্রাল গ্যাপ:** 1 − |λ₂| (যেখানে λ₂ হল দ্বিতীয় বৃহত্তম eigenvalue) মিশ্রণের গতি নির্ধারণ করে
### কন্টিনিউয়াস-টাইম মার্কভ চেইনস (CTMC)
পরিবর্তনগুলি সূচকীয় বন্টন দ্বারা নিয়ন্ত্রিত এলোমেলো সময়ে ঘটে।
| ধারণা | বর্ণনা |
|---------|---------------|
| **রেট ম্যাট্রিক্স Q** | i ≠ j এর জন্য q_{ij} ≥ 0; q_{ii} = −Σ_{j≠i} q_{ij} |
| **পরিবর্তনের সম্ভাবনা** | P(t) = e^{Qt} (ম্যাট্রিক্স সূচকীয়) |
| **স্থির বিতরণ** | πQ = 0 |
| **হোল্ডিং টাইম** | i রাজ্যে সময় হল Exp(−q_{ii}) |

## এলোমেলো হাঁটা
একটি **এলোমেলো হাঁটা** হল একটি পাথ যা ধারাবাহিক এলোমেলো পদক্ষেপ দ্বারা গঠিত।
### সহজ এলোমেলো হাঁটা
X_n = X_{n-1} + Z_n, যেখানে Z_n ∈ {+1, −1} সম্ভাব্যতা p, q = 1−p সহ।
| সম্পত্তি | p = 1/2 (প্রতিসম) | p ≠ 1/2 (পক্ষপাতমূলক) |
|------------|--------------------------------------------|
| E[X_n] | 0 | n(2p−1) |
| Var[X_n] | n | 4npq |
| মূলে ফিরে আসে? | হ্যাঁ (সম্ভাব্যতা 1 সহ) | না (দূরে চলে যায়) |
| বারবার? | হ্যাঁ (1D এবং 2D তে) | না |
### উচ্চ মাত্রায় র্যান্ডম ওয়াক
| মাত্রা | বারবার? | অন্তর্দৃষ্টি |
|------------|------------|------------|
| 1D | হ্যাঁ | "একজন মাতাল মানুষ সবসময় তার বাড়ির পথ খুঁজে পায়" |
| 2D | হ্যাঁ | "একটি মাতাল পাখি সর্বদা বাড়ির পথ খুঁজে পায়" |
| 3D+ | না | "মাতাল চড়ুই কখনই বাড়ির পথ খুঁজে পায় না" |
### ব্রাউনিয়ান মোশনের সাথে সংযোগ
একটি এলোমেলো হাঁটার স্কেলিং: যাক S_n = ΣZ_i। তারপর ধাপ আকার → 0 এবং ধাপ → ∞ হিসাবে:
S_{⌊nt⌋} / √n → B(t) (ব্রাউনিয়ান গতি, ডনসকারের উপপাদ্য দ্বারা)

## ব্রাউনিয়ান মোশন
**ব্রাউনিয়ান গতি** (উইনার প্রক্রিয়া) B(t) হল একটি এলোমেলো হাঁটার একটানা-সময়সীমা।
### সংজ্ঞা
B(t) সন্তুষ্ট করে:
1. B(0) = 0
2. B(t) এর অবিচ্ছিন্ন পথ রয়েছে
3. স্বাধীন বৃদ্ধি: B(t) − B(s) r < s < t এর জন্য B(s) − B(r) থেকে স্বাধীন
4. B(t) − B(s) ~ N(0, t − s) (গাউসিয়ান ইনক্রিমেন্ট)
### মূল বৈশিষ্ট্য
| সম্পত্তি | বিবৃতি |
|------------|------------|
| ই[বি(টি)] | = 0 |
| Var[B(t)] | = t |
| Cov[B(s), B(t)] | = মিনিট(গুলি, টি) |
| কোথাও পার্থক্য নেই | পথগুলি অবিচ্ছিন্ন কিন্তু কোন ডেরিভেটিভ নেই |
| ফ্র্যাক্টাল ডাইমেনশন | গ্রাফের হাউসডর্ফ মাত্রা 3/2 |
| মার্কভ সম্পত্তি | ভবিষ্যত নির্ভর করে শুধুমাত্র বর্তমান অবস্থানের উপর
| মার্টিংগেল | ই[বি(টি) | F_s] = B(s) এর জন্য s < t |
### জ্যামিতিক ব্রাউনিয়ান মোশন
S(t) = S(0) exp((μ− σ²/2)t + σB(t))
এটি ব্ল্যাক-স্কোলস ফ্রেমওয়ার্কের স্টকের দামের জন্য আদর্শ মডেল।
- μ: প্রবাহ (প্রত্যাশিত রিটার্ন)
- σ: অস্থিরতা

## বিষ প্রক্রিয়া
একটি **পয়সন প্রক্রিয়া** N(t) [0, t] এ সংঘটিত ঘটনার সংখ্যা গণনা করে।
### সংজ্ঞা
N(t) ~ Poisson(λt), যেখানে λ হল হার (প্রতি ইউনিট সময় ঘটনা)।
| সম্পত্তি | বিবৃতি |
|------------|------------|
| N(0) = 0 | — |
| স্বাধীন ইনক্রিমেন্ট | বিচ্ছিন্ন ব্যবধানের ঘটনাগুলি স্বাধীন |
| নিশ্চল বৃদ্ধি | N(t+s) − N(s) ~ Poisson(λt) |
| E[N(t)] | = λt |
| Var[N(t)] | = λt |
| আন্তঃ আগমনের সময় | দ্রুতগতিতে বিতরণ করা হয়েছে: T_i ~ Exp(λ) |
### সাধারণীকরণ
| বৈকল্পিক | বর্ণনা |
|---------|---------------|
| **অ-সমজাতীয়** | হার λ(t) সময়ের সাথে পরিবর্তিত হয় |
| **যৌগিক বিষ** | প্রতিটি ইভেন্টের একটি এলোমেলো আকার রয়েছে: S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **পয়সন এলোমেলো পরিমাপ** | স্থান-কালের বিন্দু, শুধু সময় নয় |
| **মাল্টিভেরিয়েট** | সম্ভাব্য মিথস্ক্রিয়া সহ একাধিক ইভেন্ট প্রকার |

## মার্টিঙ্গালেস
একটি **মার্টিঙ্গেল** একটি ন্যায্য খেলা: প্রত্যাশিত ভবিষ্যত মান, সমস্ত বর্তমান তথ্য দেওয়া, বর্তমান মানের সমান।
### সংজ্ঞা
পরিস্রাবণ {F_n} এর ক্ষেত্রে {X_n} হল একটি মার্টিংগেল যদি:
1. X_n হল F_n- পরিমাপযোগ্য (অভিযোজিত)
2. E[|X_n|] < ∞ (একীকরণযোগ্য)
3. E[X_{n+1} | F_n] = X_n (ন্যায্য খেলা)
| বৈকল্পিক | শর্ত | ব্যাখ্যা |
|---------|------------|----------------|
| **মার্টিঙ্গেল** | ই[X_{n+1} | F_n] = X_n | মেলা খেলা |
| **সাবমার্টিঙ্গেল** | ই[X_{n+1} | F_n] ≥ X_n | অনুকূল খেলা (প্রবণতা) |
| **সুপারমার্টিংগেল** | ই[X_{n+1} | F_n] ≤ X_n | প্রতিকূল খেলা (নিচে প্রবণতা) |
### মূল উপপাদ্য
| উপপাদ্য | বিবৃতি |
|---------|------------|
| **ঐচ্ছিক থামা** | শর্তে, E[X_T] = E[X_0] থামার সময় T |
| **কনভারজেন্স** | একটি আবদ্ধ মার্টিঙ্গেল প্রায় নিশ্চিতভাবে একত্রিত হয় |
| **সর্বোচ্চ অসমতা** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (ডুব'স) |

## মন্টে কার্লো পদ্ধতি
**মন্টে কার্লো পদ্ধতি** নির্ধারক পরিমাণ অনুমান করতে এলোমেলো নমুনা ব্যবহার করে।
### মৌলিক ধারণা
E[f(X)] অনুমান করতে যেখানে X ~ P:
1. N নমুনা আঁকুন: P থেকে x₁, x₂, ..., x_N
2. গণনা: Î = (1/N) Σᵢ f(xᵢ)
3. বড় সংখ্যার নিয়ম অনুসারে: Î → E[f(X)] N → ∞ হিসাবে
**ত্রুটি:** স্ট্যান্ডার্ড ত্রুটি = σ_f / √N, যেখানে σ_f² = Var[f(X)]
### বৈষম্য কমানোর কৌশল
| টেকনিক | আইডিয়া | স্পিডআপ |
|------------|------|---------|
| **গুরুত্বপূর্ণ নমুনা** | P এর পরিবর্তে Q থেকে নমুনা, P/Q দ্বারা ওজন | নাটকীয় হতে পারে |
| **অ্যান্টিথেটিক বৈচিত্র** | প্রকরণ বাতিল করতে জোড়া (x, −x) ব্যবহার করুন | ~2x |
| **নিয়ন্ত্রণ বৈচিত্র** | f | এর সাথে সম্পর্কযুক্ত পরিচিত-প্রত্যাশা ফাংশন বিয়োগ করুন পরিবর্তিত হয় |
| **স্তরিত নমুনা** | ডোমেন ভাগ করুন, প্রতিটি স্তরের নমুনা | বৈচিত্র্য হ্রাস করে |
| **রাও-ব্ল্যাকওয়েল** | পর্যাপ্ত পরিসংখ্যানের শর্ত | সর্বদা সাহায্য করে |

## মার্কভ চেইন মন্টে কার্লো (MCMC)
MCMC একটি মার্কভ চেইন তৈরি করে যার স্থির বন্টন হল লক্ষ্য বন্টন। একটি "বার্ন-ইন" সময়কালের পর, লক্ষ্য থেকে আনুমানিক নমুনা ড্র হয়।
### মেট্রোপলিস-হেস্টিংস অ্যালগরিদম
| ধাপ | কর্ম |
|------|---------|
| 1 | বর্তমান অবস্থা: x_t |
| 2 | প্রস্তাব: x*~ q(x* \| x_t) (প্রস্তাব বিতরণ) |
| 3 | গ্রহণযোগ্যতা অনুপাত: α = মিনিট(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | সম্ভাব্যতার সাথে গ্রহণ করুন α: x_{t+1} = x* (স্বীকার করুন) বা x_t (প্রত্যাখ্যান করুন) |
**বিশেষ ক্ষেত্রে — মেট্রোপলিস অ্যালগরিদম:** প্রতিসম প্রস্তাব q(x*|x) = q(x|x*), তাই α = min(1, π(x*)/π(x_t))।
### গিবস স্যাম্পলিং
Metropolis-Hastings এর একটি বিশেষ কেস যেখানে প্রতিটি ভেরিয়েবল তার সম্পূর্ণ শর্তসাপেক্ষ বন্টন থেকে আপডেট করা হয়।
লক্ষ্য π(x₁, x₂, ..., xₖ):
1. নমুনা x₁^{(t+1)} ~ π(x₁ | x₂^{(t)}, ..., xₖ^{(t)})
2. নমুনা x₂^{(t+1)} ~ π(x₂ | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. সমস্ত ভেরিয়েবলের জন্য চালিয়ে যান
4. পুনরাবৃত্তি করুন
| সম্পত্তি | বিবৃতি |
|------------|------------|
| সর্বদা গ্রহণ করে | α = 1 (কোন প্রত্যাখ্যান পদক্ষেপ) |
| প্রয়োজন | প্রতিটি সম্পূর্ণ শর্তাধীন থেকে নমুনা করার ক্ষমতা |
| কনভারজেন্স | অপরিবর্তনীয়, এপিরিওডিক চেইনের জন্য গ্যারান্টিযুক্ত |
### MCMC ডায়াগনস্টিকস
| ডায়াগনস্টিক | উদ্দেশ্য |
|------------|---------|
| **ট্রেস প্লট** | মিক্সিং এবং স্থিরতার জন্য ভিজ্যুয়াল চেক |
| **স্বয়ংক্রিয় সম্পর্ক** | নমুনা নির্ভরতা পরিমাপ করে (নিম্ন স্বতঃসম্পর্ক চাই) |
| **গেলম্যান-রুবিন (R̂)** | একাধিক চেইন তুলনা; R̂ < 1.05 কনভারজেন্সের পরামর্শ দেয় |
| **কার্যকর নমুনা আকার** | N_eff = N / (1 + 2Σρₖ); স্বয়ংক্রিয় সম্পর্কের জন্য অ্যাকাউন্ট |
| **বার্ন-ইন** | চেইন স্থিতিশীলতায় পৌঁছানোর আগে প্রাথমিক নমুনাগুলি বাতিল করুন |

স্টোকাস্টিক প্রক্রিয়াগুলি সময়ের সাথে এলোমেলোতার গণিত। তারা আধুনিক বায়েসিয়ান ইনফারেন্স (MCMC), রিইনফোর্সমেন্ট লার্নিং (মার্কভ ডিসিশন প্রসেস), জেনারেটিভ মডেলিং (ডিফিউশন মডেল), আর্থিক গণিত এবং সারিবদ্ধ তত্ত্বকে আন্ডারপিন করে। এই প্রক্রিয়াগুলি বোঝা আপনাকে গতিশীলভাবে অনিশ্চয়তা মডেল করার সরঞ্জাম দেয় — শুধুমাত্র একটি স্ন্যাপশট হিসাবে নয়, এটি বিকশিত হওয়ার সাথে সাথে।
