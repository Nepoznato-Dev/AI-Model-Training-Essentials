# বাস্তব বিশ্লেষণ
বাস্তব বিশ্লেষণ হল ক্যালকুলাসের শক্ত ভিত্তি। যদিও পরিচায়ক ক্যালকুলাস আপনাকে শেখায় কিভাবে ডেরিভেটিভ এবং ইন্টিগ্রেলগুলি গণনা করতে হয়, বাস্তব বিশ্লেষণ জিজ্ঞাসা করে *কেন* এই কৌশলগুলি কাজ করে — এবং কখন তারা ব্যর্থ হয়। এটি সীমা, ধারাবাহিকতা, অভিন্নতা এবং একীকরণের সুনির্দিষ্ট সংজ্ঞা প্রদান করে যা সম্ভাব্যতা তত্ত্ব, কার্যকরী বিশ্লেষণ, অপ্টিমাইজেশান, এবং মেশিন লার্নিং অ্যালগরিদমের পিছনে তাত্ত্বিক গ্যারান্টিগুলিকে আন্ডারপিন করে৷

## সিকোয়েন্স এবং সিরিজ
### সিকোয়েন্স
একটি **ক্রম** হল বাস্তব সংখ্যার একটি ক্রম তালিকা (aₙ)ₙ₌₁^∞। কেন্দ্রীয় প্রশ্ন হল: ক্রমটি কি একটি সীমাতে ** একত্রিত হয়?
**কভারজেন্সের সংজ্ঞা:** একটি সিকোয়েন্স (aₙ) L-এ রূপান্তরিত হয় যদি প্রতি ε > 0 এর জন্য N থাকে যাতে সকলের জন্য n > N: |aₙ − L| < ε।
| ধারণা | সংজ্ঞা | উদাহরণ |
|---------|------------|---------|
| **কনভারজেন্ট** | lim aₙ = L বিদ্যমান এবং সসীম | aₙ = 1/n → 0 |
| **বিমুখ** | একত্রিত হয় না | aₙ = (−1)ⁿ দোলনা |
| ** ∞** থেকে ভিন্ন | aₙ বাঁধা ছাড়াই বৃদ্ধি পায় | aₙ = n² → ∞ |
| **আবদ্ধ** | \|aₙ\| ≤ কিছু M এর জন্য M | প্রতিটি অভিসারী ক্রম আবদ্ধ |
| **একঘেয়ে** | হয় সর্বদা অ-হ্রাস বা অ-বৃদ্ধি | aₙ = 1 − 1/n বাড়ছে |
| **কৌচি ক্রম** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | ℝ, কচি ⟺ অভিসারী |
**মূল উপপাদ্য:**
- **মনোটোন কনভারজেন্স থিওরেম:** প্রতিটি আবদ্ধ একঘেয়ে ক্রম একত্রিত হয়
- **বোলজানো-ওয়েইয়েরস্ট্রাস উপপাদ্য:** প্রতিটি আবদ্ধ অনুক্রমের একটি অভিসারী অনুক্রম থাকে
- **ℝ এর সম্পূর্ণতা:** ℝ এর প্রতিটি কচি ক্রম একত্রিত হয় (এটি ℝ থেকে ℝকে আলাদা করে)
### সিরিজ
একটি **সিরিজ** হল একটি অনুক্রমের সমষ্টি: Σₙ₌₁^∞ aₙ। আংশিক যোগফল Sₙ = Σₖ₌₁ⁿ aₖ এর ক্রম একত্রিত হলে সিরিজটি একত্রিত হয়।
### কনভারজেন্স টেস্ট
| পরীক্ষা | শর্ত | উপসংহার |
|------|------------|------------|
| **বিমুখতা পরীক্ষা** | lim aₙ ≠ 0 | সিরিজ বিচ্ছিন্ন |
| **তুলনা পরীক্ষা** | 0 ≤ aₙ ≤ bₙ এবং Σbₙ একত্রিত হয় | Σaₙ একত্রিত হয় |
| **অনুপাত পরীক্ষা** | লিম \|aₙ₊₁/aₙ\| = L | রূপান্তরিত হয় যদি L< 1, diverges if L >1 |
| **মূল পরীক্ষা** | lim sup \|aₙ\|^(1/n) = L | রূপান্তরিত হয় যদি L< 1, diverges if L >1 |
| **অখণ্ড পরীক্ষা** | aₙ = f(n), f হ্রাস, ধনাত্মক | Σaₙ কনভারজেস iff ∫f(x)dx কনভারজেস |
| **অল্টারনেটিং সিরিজ** | aₙ হ্রাস, lim aₙ = 0, বিকল্প চিহ্ন | সিরিজ একত্রিত হয় |
| **পরম অভিন্নতা** | Σ\|aₙ\| একত্রিত হয় | Σaₙ একত্রিত হয় (এবং পুনর্বিন্যাস একই যোগফল দেয়) |
| **শর্তগত অভিসার** | Σaₙ একত্রিত হয় কিন্তু Σ\|aₙ\| বিচ্যুত | পুনর্বিন্যাস যে কোন যোগফল দিতে পারে (Riemann) |
### গুরুত্বপূর্ণ সিরিজ
| সিরিজ | সমষ্টি | শর্ত |
|---------|------|------------|
| জ্যামিতিক: Σ rⁿ | 1/(1−r) | \|r\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| হারমোনিক: Σ 1/n | বিচ্ছিন্ন (= ∞) | — |
| সূচকীয়: Σ xⁿ/n! | eˣ | সব x |
| ln(1+x) এর জন্য টেলর: Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < x ≤ 1 |

## সীমা এবং ধারাবাহিকতা
### ফাংশনের সীমা
**সংজ্ঞা:** lim_{x→c} f(x) = L মানে: প্রতিটি ε > 0 এর জন্য, δ > 0 আছে যেমন 0 < |x − c| < δ বোঝায় |f(x) − L| < ε।
এটি হল **ε-δ সংজ্ঞা** — "f(x) L-এর কাছে আসে যখন x c-এর কাছে আসে।"
### ধারাবাহিকতা
একটি ফাংশন f **c** এ একটানা থাকে যদি lim_{x→c} f(x) = f(c)। সমানভাবে: প্রতিটি ε > 0 এর জন্য, δ > 0 আছে যেটা |x − c| < δ বোঝায় |f(x) − f(c)| < ε।
**বিচ্ছিন্নতার প্রকার:**
| প্রকার | বর্ণনা | উদাহরণ |
|------|---------------|---------|
| অপসারণযোগ্য | সীমা বিদ্যমান কিন্তু ≠ f(c) | f(x) = sin(x)/x এ x = 0 |
| ঝাঁপ দাও | বাম এবং ডান সীমা বিদ্যমান কিন্তু ভিন্ন | ধাপ ফাংশন |
| অসীম | সীমা হল ±∞ | f(x) = 1/x² এ x = 0 |
| দোদুল্যমান | সীমা বিদ্যমান নেই | f(x) = sin(1/x) এ x = 0 |
### অবিচ্ছিন্ন ফাংশনের জন্য মূল উপপাদ্য
| উপপাদ্য | বিবৃতি |
|---------|------------|
| **ইন্টারমিডিয়েট ভ্যালু থিওরেম** | যদি [a,b] এবং f(a) < k < f(b) এর উপর f ক্রমাগত থাকে, তাহলে ∃c ∈ (a,b): f(c) = k |
| **চরম মূল্য উপপাদ্য** | যদি f [a,b]-এ একটানা থাকে, f তার সর্বোচ্চ এবং সর্বনিম্ন [a,b]-এ পৌঁছায় |
| **সীমাবদ্ধতা উপপাদ্য** | যদি f [a,b]-এর উপর অবিচ্ছিন্ন থাকে, f-এর উপর [a,b] |
| **অভিন্ন ধারাবাহিকতা** | [a,b] তে f অবিচ্ছিন্নভাবে যদি [a,b] (Heine-Cantor) এ অবিচ্ছিন্ন থাকে |
**কাজ করা উদাহরণ (IVT):** x³ + x − 1 = 0 এর (0, 1) মধ্যে একটি সমাধান আছে দেখান।
- ধরুন f(x) = x³ + x − 1. f অবিচ্ছিন্ন (বহুপদ)।
- f(0) = −1< 0 and f(1) = 1 >0।
- IVT দ্বারা, ∃c ∈ (0,1): f(c) = 0।

## পার্থক্য
### সংজ্ঞা
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
যদি এই সীমাটি বিদ্যমান থাকে, তাহলে c এ f **পার্থক্যযোগ্য**।
### পার্থক্য বনাম ধারাবাহিকতা
| সম্পর্ক | বিবৃতি |
|---------------|------------|
| পার্থক্যযোগ্য → ক্রমাগত | যদি f c-এ পার্থক্যযোগ্য হয়, f c এ অবিচ্ছিন্ন |
| ক্রমাগত ↛ পার্থক্যযোগ্য | f(x) = \|x\| 0 এ অবিচ্ছিন্ন কিন্তু সেখানে পার্থক্যযোগ্য নয় |
| কোথাও পার্থক্য নেই | Weierstrass ফাংশন: সর্বত্র অবিচ্ছিন্ন, কোথাও পার্থক্যযোগ্য |
### মূল ফলাফল
| উপপাদ্য | বিবৃতি |
|---------|------------|
| **গড় মান উপপাদ্য** | যদি [a,b] এর উপর f ক্রমাগত হয় এবং (a,b) এর উপর পার্থক্য করা যায়, ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **রোলের উপপাদ্য** | MVT এর বিশেষ ক্ষেত্রে যখন f(a) = f(b): ∃c: f'(c) = 0 |
| **L'Hôpital এর নিয়ম** | যদি lim f/g = 0/0 বা ∞/∞ হয়, তাহলে lim f/g = lim f'/g' (যখন পরেরটি থাকে) |
| **টেলরের উপপাদ্য** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x) স্পষ্ট অবশিষ্টাংশ সহ |

## ইন্টিগ্রেশন
### রিম্যান ইন্টিগ্রেশন
**Riemann integral** ∫ₐᵇ f(x)dx কে Riemann যোগফলের সীমা হিসাবে সংজ্ঞায়িত করে।
**নির্মাণ:**
1. বিভাজন [a,b] সাবইন্টারভালে: P = {x₀, x₁, ..., xₙ}
2. নমুনা পয়েন্ট নির্বাচন করুন tᵢ ∈ [xᵢ₋₁, xᵢ]
3. রিম্যান যোগফল: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. S(P,f) এর সীমা জাল → 0 হিসাবে বিদ্যমান থাকলে, f হল রিম্যান ইন্টিগ্রেবল
**রিম্যান অখণ্ডতার মানদণ্ড:**
| শর্ত | ইন্টিগ্রেবল? |
|------------|-------------|
| ক্রমাগত [a,b] | হ্যাঁ |
| সীমিতভাবে অনেক বিচ্ছিন্নতার সাথে আবদ্ধ | হ্যাঁ |
| [a,b] | হ্যাঁ |
| ডিরিচলেট ফাংশন (ℚ এর উপর 1, অযৌক্তিক উপর 0) | না |
### ক্যালকুলাসের মৌলিক উপপাদ্য
| অংশ | বিবৃতি |
|------|------------|
| **পার্ট 1** | যদি [a,b] এর উপর f অবিচ্ছিন্ন থাকে, তাহলে F(x) = ∫ₐˣ f(t)dt হবে পার্থক্যযোগ্য এবং F'(x) = f(x) |
| **পার্ট 2** | যদি F' = f এবং f রিম্যান একীভূত হয়, তাহলে ∫ₐᵇ f(x)dx = F(b) − F(a) |
### লেবেসগু ইন্টিগ্রেশন
রিম্যান ইন্টিগ্রালের সীমাবদ্ধতা রয়েছে - এটি বিশ্লেষণ এবং সম্ভাব্যতার মধ্যে উদ্ভূত অনেক ফাংশনকে একীভূত করতে পারে না। **Lebesgue ইন্টিগ্রাল** ফাংশনের অনেক বিস্তৃত শ্রেণীতে ইন্টিগ্রেশনকে প্রসারিত করে।
**মূল ধারণা:** ডোমেন (x-অক্ষ) বিভাজন করার পরিবর্তে, পরিসর (y-অক্ষ) বিভাজন করুন।
| দৃষ্টিভঙ্গি | রিম্যান ইন্টিগ্রাল | লেবেসগু ইন্টিগ্রাল |
|---------|----------------------------|
| দৃষ্টিভঙ্গি | পার্টিশন ডোমেন (x-অক্ষ) | পার্টিশন পরিসর (y-অক্ষ) |
| একীভূত করে | একটানা, টুকরো টুকরো একটানা | পরিমাপযোগ্য ফাংশন |
| সীমা উপপাদ্য | দুর্বল | শক্তিশালী (ডমিনেড কনভারজেন্স, মনোটোন কনভারজেন্স) |
| হ্যান্ডেল | "নাইস" ফাংশন | ঘন discontinuities সঙ্গে ফাংশন |
| এর ভিত্তি | শাস্ত্রীয় ক্যালকুলাস | আধুনিক সম্ভাব্যতা তত্ত্ব |
**লেবেসগুয়ের মানদণ্ড:** f হল Riemann integrable on [a,b] iff f প্রায় সর্বত্র আবদ্ধ এবং অবিচ্ছিন্ন (বিচ্ছিন্নতার সেটে শূন্য পরিমাপ করা হয়েছে)।

## মেট্রিক স্পেস
একটি **মেট্রিক স্পেস** বিমূর্ত সেটে "দূরত্ব" ধারণাটিকে সাধারণীকরণ করে।
### সংজ্ঞা
একটি **মেট্রিক স্পেস** (X, d) হল একটি সেট X যার একটি দূরত্ব ফাংশন d: X × X → ℝ সন্তোষজনক:
| স্বতঃসিদ্ধ | বিবৃতি |
|---------|------------|
| অ-নেতিবাচকতা | d(x,y) ≥ 0 |
| পরিচয় | d(x,y) = 0 iff x = y |
| প্রতিসাম্য | d(x,y) = d(y,x) |
| ত্রিভুজ অসমতা | d(x,z) ≤ d(x,y) + d(y,z) |
### সাধারণ মেট্রিক স্পেস
| মহাকাশ | সেট | মেট্রিক | আবেদন |
|-------|------|---------|-------------|
| ℝⁿ সাথে ইউক্লিডিয়ান | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² | স্ট্যান্ডার্ড জ্যামিতি |
| ম্যানহাটনের সাথে ℝⁿ | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| | গ্রিড-ভিত্তিক পাথ, LASSO |
| চেবিশেভের সাথে ℝⁿ | ℝⁿ | d(x,y) = সর্বোচ্চ\|xᵢ−yᵢ\| | দাবা রাজা দূরত্ব |
| বিচ্ছিন্ন মেট্রিক | যে কোন সেট | d(x,y) = 1 যদি x≠y, 0 যদি x=y | টপোলজি উদাহরণ |
| ফাংশন স্পেস C[a,b] | ক্রমাগত ফাংশন | d(f,g) = সর্বোচ্চ\|f(x)−g(x)\| | আনুমানিক তত্ত্ব |
| Lᵖ স্থান | p- ইন্টিগ্রেবল ফাংশন | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) | কার্যকরী বিশ্লেষণ, ML নিয়ম |
### মেট্রিক স্পেসে টপোলজিকাল ধারণা
| ধারণা | সংজ্ঞা | উদাহরণ |
|---------|------------|---------|
| **ওপেন বল** | B(x,r) = {y : d(x,y) < r} | খোলা ব্যবধান (x−r, x+r) ℝ |
| **ওপেন সেট** | প্রতিটি পয়েন্টে সেটে একটি বল থাকে | (0,1) ℝ ​​| এ খোলা আছে
| **বন্ধ সেট** | একটি খোলা সেটের পরিপূরক | [0,1] ℝ | এ বন্ধ
| **বন্ধ** | S | ধারণকারী ক্ষুদ্রতম বন্ধ সেট (0,1) = [0,1] |
| **কমপ্যাক্ট** | প্রতিটি খোলা কভারের একটি সীমিত সাবকভার আছে | ℝⁿ-এ: বদ্ধ এবং আবদ্ধ (হেইন-বোরেল) |
| **সম্পূর্ণ** | প্রতিটি কচি ক্রম একত্রিত হয় | ℝ সম্পূর্ণ; ℚ নয় |

## ইউনিফর্ম কনভারজেন্স
ফাংশনের একটি ক্রম (fₙ) দুটি উপায়ে একত্রিত হতে পারে:
| প্রকার | সংজ্ঞা | ধারাবাহিকতা রক্ষা করে? |
|------|------------|----------------------|
| **বিন্দু অনুসারে** | ∀x: fₙ(x) → f(x) | না |
| **ইউনিফর্ম** | sup\|fₙ(x) − f(x)\| → 0 | হ্যাঁ |
**ইনিফর্ম কনভারজেন্স** শক্তিশালী: কনভারজেন্সের হার সব জায়গায় একই।
**মূল উপপাদ্য:**
- অবিচ্ছিন্ন ফাংশনের অভিন্ন সীমা ক্রমাগত
- রিম্যান-ইনটিগ্রেবল ফাংশনের ইউনিফর্ম সীমা হল রিম্যান-ইনটিগ্রেবল, এবং লিমিটের ইন্টিগ্রেল ইন্টিগ্রেলের সীমার সমান
- **ওয়েয়ারস্ট্রাস এম-টেস্ট:** যদি |fₙ(x)| ≤ Mₙ সমস্ত x এবং ΣMₙ একত্রিত হয়, তারপর Σfₙ অভিন্নভাবে একত্রিত হয়

## পরিমাপ তত্ত্ব
**পরিমাপ তত্ত্ব** দৈর্ঘ্য, ক্ষেত্রফল এবং আয়তনের ধারণাকে সাধারণীকরণ করে।
### সংজ্ঞা
X একটি সেটের একটি **পরিমাপ** হল একটি ফাংশন μ: Σ → [0, ∞] (যেখানে Σ হল উপসেটের একটি σ-বীজগণিত) সন্তোষজনক:
- μ(∅) = 0
- **গণনাযোগ্য সংযোজন:** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) সংযোগ বিচ্ছিন্ন করার জন্য Aᵢ
### লেবেসগুয়ে পরিমাপ
ℝ এর **লেবেসগুয়ে পরিমাপ** λ দৈর্ঘ্যের ধারণাকে প্রসারিত করে:
| সেট | Lebesgue পরিমাপ |
|----------------------------------------- |
| ব্যবধান [a,b] | b − a |
| একক বিন্দু {x} | 0 |
| সসীম সেট | 0 |
| গণনাযোগ্য সেট (যেমন, ℚ) | 0 |
| ক্যান্টর সেট | 0 (অগণিত কিন্তু শূন্য পরিমাপ) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### মূল ধারণা
| ধারণা | সংজ্ঞা |
|---------|------------|
| **প্রায় সর্বত্র (যেমন)** | পরিমাপের শূন্য সেট ছাড়া একটি সম্পত্তি ধারণ করে |
| **পরিমাপযোগ্য ফাংশন** | প্রতিটি খোলা সেটের প্রিমেজ পরিমাপযোগ্য |
| **লেবেসগুয়ে অবিচ্ছেদ্য** | পরিমাপ তত্ত্ব ব্যবহার করে অখণ্ড সংজ্ঞায়িত |
| **Lᵖ স্পেস** | সসীম p-th পাওয়ার ইন্টিগ্রাল সহ ফাংশনের স্পেস |
### গুরুত্বপূর্ণ কনভারজেন্স উপপাদ্য
এই তত্ত্বগুলি কেন উন্নত গণিতে লেবেসগু ইন্টিগ্রেশন পছন্দ করা হয়:
| উপপাদ্য | বিবৃতি |
|---------|------------|
| **মনোটোন কনভারজেন্স** | যদি fₙ ↑ f পয়েন্টওয়াইজ এবং fₙ ≥ 0 হয়, তাহলে ∫fₙ → ∫f |
| **ডমিনেড কনভারজেন্স** | যদি fₙ → f পয়েন্টওয়াইজ এবং \|fₙ\| ≤ g (একীকরণযোগ্য), তারপর ∫fₙ → ∫f |
| **ফতুর লেমা** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
এই উপপাদ্যগুলি সীমা এবং অখণ্ডাকার বিনিময়ের অনুমতি দেয় — এমন কিছু যা সাধারণভাবে রিম্যান একীকরণের জন্য ব্যর্থ হয়।
