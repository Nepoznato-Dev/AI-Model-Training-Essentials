# অপটিক্স এবং তরঙ্গ
তরঙ্গ সর্বত্র রয়েছে: শব্দ, আলো, জল, রেডিও সংকেত, কোয়ান্টাম সম্ভাব্যতা প্রশস্ততা, স্টক মার্কেটের ওঠানামা, এবং নিউরাল নেটওয়ার্ক সক্রিয়করণের কম্পন। আলোকবিদ্যা - আলোর অধ্যয়ন - হল সবচেয়ে উন্নত তরঙ্গ বিজ্ঞান, এবং এর গাণিতিক সরঞ্জামগুলি (ফুরিয়ার বিশ্লেষণ, হস্তক্ষেপ, বিচ্ছুরণ) প্রতিটি তরঙ্গের ঘটনাতে প্রযোজ্য। সংকেত প্রক্রিয়াকরণ, চিত্র বিশ্লেষণ, যোগাযোগ এবং সমস্ত আধুনিক প্রযুক্তির শারীরিক স্তরের জন্য তরঙ্গ বোঝা অপরিহার্য।

## তরঙ্গ সমীকরণ
### সাধারণ তরঙ্গ সমীকরণ
এক-মাত্রিক তরঙ্গ সমীকরণ:
∂²u/∂t² = c² ∂²u/∂x²
যেখানে u(x,t) হল তরঙ্গ স্থানচ্যুতি এবং c হল তরঙ্গের গতি।
### সাধারণ সমাধান (d'Alembert)
u(x,t) = f(x − ct) + g(x + ct)
যেখানে f হল ডান-ভ্রমণকারী তরঙ্গ এবং g হল বাম-ভ্রমণকারী তরঙ্গ।
### কী ওয়েভ প্যারামিটার
| পরামিতি | প্রতীক | একক | বর্ণনা |
|------------|---------|------|-------------|
| প্রশস্ততা | ক | পরিবর্তিত হয় | সর্বোচ্চ স্থানচ্যুতি |
| তরঙ্গদৈর্ঘ্য | λ | মিটার | পরপর ক্রেস্টের মধ্যে দূরত্ব |
| ফ্রিকোয়েন্সি | f বা ν | হার্টজ (Hz) | প্রতি সেকেন্ডে চক্র |
| সময়কাল | T = 1/f | সেকেন্ড | একটি সম্পূর্ণ চক্রের জন্য সময় |
| তরঙ্গ সংখ্যা | k = 2π/λ | rad/m | স্থানিক ফ্রিকোয়েন্সি |
| কৌণিক কম্পাঙ্ক | ω = 2πf | rad/s | টেম্পোরাল ফ্রিকোয়েন্সি |
| তরঙ্গের গতি | c = fλ = ω/k | m/s | প্রচারের গতি |
### সাইনোসাইডাল ওয়েভ
u(x,t) = A sin(kx − ωt + φ)
যেখানে φ পর্যায় ধ্রুবক।
### বিভিন্ন মিডিয়াতে তরঙ্গের গতি
| তরঙ্গের ধরন | মাঝারি | গতির সূত্র |
|------------|---------|---------------|
| স্ট্রিং | টান T, রৈখিক ঘনত্ব μ | c = √(T/μ) |
| শব্দ | বাল্ক মডুলাস B, ঘনত্ব ρ | c = √(B/ρ) |
| শব্দ (আদর্শ গ্যাস) | γ, R, T, M | c = √(γRT/M) |
| EM তরঙ্গ | পারমিটিভিটি ε, ব্যাপ্তিযোগ্যতা μ | c = 1/√(με) |
| EM তরঙ্গ (শূন্যতা) | ε₀, μ₀ | c = 3 × 10⁸ m/s |

## সুপারপজিশন এবং হস্তক্ষেপ
### সুপারপজিশনের নীতি
যখন দুই বা ততোধিক তরঙ্গ ওভারল্যাপ হয়, ফলস্বরূপ স্থানচ্যুতি হল পৃথক স্থানচ্যুতির সমষ্টি:
u_total = u₁ + u₂ + ... + uₙ
এটি রৈখিক তরঙ্গ সমীকরণের জন্য ধারণ করে।
### দুটি তরঙ্গের হস্তক্ষেপ
একই ফ্রিকোয়েন্সি এবং প্রশস্ততা সহ দুটি তরঙ্গ, ফেজ পার্থক্য Δφ:
u_total = 2A cos(Δφ/2) sin(kx − ωt + Δφ/2)
| পর্যায় পার্থক্য | ফলাফল | তীব্রতা |
|------|---------|------------|
| Δφ = 0, 2π, 4π, ... | **গঠনমূলক** (প্রশস্ততা = 2A) | 4I₀ (সর্বোচ্চ) |
| Δφ = π, 3π, 5π, ... | **ধ্বংসাত্মক** (প্রশস্ততা = 0) | 0 (সর্বনিম্ন) |
| Δφ = π/2 | আংশিক | 2I₀ |
### হস্তক্ষেপের শর্ত
| শর্ত | প্রকার | পথের পার্থক্য |
|------------|---------|-----------------|
| গঠনমূলক | উজ্জ্বল পাড় | ΔL = mλ (m = 0, 1, 2, ...) |
| ধ্বংসাত্মক | অন্ধকার পাড় | ΔL = (m + ½)λ |

## তরুণের ডাবল-স্লিট পরীক্ষা
আলো দূরত্ব d দ্বারা পৃথক দুটি সরু স্লিটের মধ্য দিয়ে যায়, L দূরত্বে একটি পর্দায় একটি হস্তক্ষেপ প্যাটার্ন তৈরি করে।
### ফ্রঞ্জ পজিশন
| ঝালর | স্ক্রিনে অবস্থান |
|---------|-------------------|
| উজ্জ্বল (ম্যাক্সিমা) | y_m = mλL/d |
| অন্ধকার (মিনিমা) | y_m = (m + ½)λL/d |
| ফ্রেঞ্জ স্পেসিং | Δy = λL/d |
এই পরীক্ষাটি আলোর তরঙ্গ প্রকৃতি প্রমাণ করে (Thomas Young, 1801) এবং পরে কোয়ান্টাম মেকানিক্সের (তরঙ্গ-কণা দ্বৈততা) কেন্দ্রবিন্দু হয়ে ওঠে।

## বিচ্ছুরণ
**বিবর্তন** হল বাধার চারপাশে এবং খোলার মাধ্যমে তরঙ্গের বাঁকানো এবং ছড়িয়ে পড়া।
### একক-চেরা বিচ্ছুরণ
একটি প্রস্থের একটি স্লিটের মধ্য দিয়ে আলো উজ্জ্বল এবং অন্ধকার প্রান্তের একটি প্যাটার্ন তৈরি করে।
| বৈশিষ্ট্য | শর্ত |
|---------|------------|
| কেন্দ্রীয় সর্বোচ্চ | প্রশস্ত এবং উজ্জ্বল; প্রস্থ = 2λL/a |
| মিনিমা (অন্ধকার পাড়) | a sin θ = mλ (m = ±1, ±2, ...) |
| সেকেন্ডারি ম্যাক্সিমা | প্রায় minima মধ্যে; অনেক ম্লান |
### ডিফ্রাকশন গ্রেটিং
N সমানভাবে ব্যবধানযুক্ত স্লিট (ব্যবধান d) খুব তীক্ষ্ণ ম্যাক্সিমা তৈরি করে:
d sin θ = mλ (m = 0, 1, 2, ...)
| সম্পত্তি | প্রভাব |
|------------|---------|
| আরও স্লিট (বৃহত্তর N) | তীক্ষ্ণ, উজ্জ্বল ম্যাক্সিমা |
| সমাধান ক্ষমতা | R = mN (ঘনিষ্ঠ তরঙ্গদৈর্ঘ্যের পার্থক্য করতে পারে) |
| অ্যাপ্লিকেশন | স্পেকট্রোস্কোপি, তরঙ্গদৈর্ঘ্য পরিমাপ |
### Rayleigh মানদণ্ড (রেজোলিউশন সীমা)
দুটি বিন্দু উৎস ঠিক তখনই সমাধানযোগ্য যখন একটির কেন্দ্রীয় সর্বোচ্চ অন্যটির প্রথম সর্বনিম্ন উপর পড়ে:
θ_মিন = 1.22 λ/D
যেখানে D হল অ্যাপারচার ব্যাস।
| সিস্টেম | λ | ডি | θ_মিন |
|---------|---|---|-------|
| মানুষের চোখ | 550 এনএম | 5 মিমি | 1.3 × 10⁻⁴ rad (~0.01°) |
| হাবল স্পেস টেলিস্কোপ | 550 এনএম | 2.4 মি | 2.8 × 10⁻⁷ rad |
| রেডিও টেলিস্কোপ (Arecibo) | 21 সেমি | 305 মি | 8.4 × 10⁻⁴ rad |

## মেরুকরণ
**পোলারাইজেশন** একটি অনুপ্রস্থ তরঙ্গে বৈদ্যুতিক ক্ষেত্রের দোলনের অভিযোজন বর্ণনা করে।
### পোলারাইজেশনের প্রকারভেদ
| প্রকার | বর্ণনা |
|------|---------------|
| **রৈখিক** | E একটি স্থির সমতলে দোদুল্যমান |
| **পরিপত্র** | E একটি বৃত্তে ঘোরে (ডান বা বাম হাতে) |
| **উপবৃত্তাকার** | E একটি উপবৃত্ত (সবচেয়ে সাধারণ) |
| **আনপোলারাইজড** | সমস্ত মেরুকরণের এলোমেলো মিশ্রণ (সবচেয়ে প্রাকৃতিক আলো) |
### মালুসের আইন
যখন পোলারাইজড আলো θ কোণে পোলারাইজারের মধ্য দিয়ে মেরুকরণের দিকে যায়:
I = I₀ cos²θ
| কোণ θ | প্রেরিত তীব্রতা |
|---------|-------------------------|
| 0° | 100% (I₀) |
| 30° | 75% |
| 45° | 50% |
| 60° | 25% |
| 90° | 0% (সম্পূর্ণ অবরুদ্ধ) |
### প্রতিফলন দ্বারা মেরুকরণ (ব্রুস্টারের কোণ)
ব্রুস্টার কোণে প্রতিফলিত আলো সম্পূর্ণরূপে মেরুকরণ করা হয়:
tan θ_B = n₂/n₁
| ইন্টারফেস | n₁ | n₂ | θ_B |
|------------|------|------|------|
| বায়ু → গ্লাস | 1.0 | 1.5 | 56.3° |
| বায়ু → জল | 1.0 | 1.33 | 53.1° |
| গ্লাস → হীরা | 1.5 | 2.42 | 58.1° |

## জ্যামিতিক অপটিক্স
জ্যামিতিক (রশ্মি) অপটিক্স আলোকে রশ্মি হিসাবে বিবেচনা করে যা সরলরেখায় ভ্রমণ করে, ইন্টারফেসে বাঁকানো হয়।
### স্নেলের সূত্র (প্রতিসরণ)
n₁ sin θ₁ = n₂ sin θ₂
| উপাদান | প্রতিসরণ সূচক n |
|------------|---------|
| ভ্যাকুয়াম | 1.000 |
| বায়ু | 1.0003 |
| জল | 1.33 |
| কাচ (মুকুট) | 1.52 |
| গ্লাস (চকমকি) | 1.62 |
| হীরা | 2.42 |
### মোট অভ্যন্তরীণ প্রতিফলন
আলো যখন **গুরুত্বপূর্ণ কোণ** অতিক্রম করে ঘনত্ব থেকে কম ঘন মাঝারি পর্যন্ত ভ্রমণ করে:
θ_c = আর্কসিন(n₂/n₁)
সমস্ত আলো প্রতিফলিত হয় - এইভাবে অপটিক্যাল ফাইবার কাজ করে।
### পাতলা লেন্স সমীকরণ
1/f = 1/d_o + 1/d_i
| পরিমাণ | অর্থ |
|----------|---------|
| চ | ফোকাল দৈর্ঘ্য |
| d_o | বস্তুর দূরত্ব |
| d_i | ছবির দূরত্ব |
| M = −d_i/d_o | বিবর্ধন |
| লেন্সের ধরন | চ | ছবি |
|------------|---|-------|
| অভিসারী (উত্তল) | ইতিবাচক | বাস্তব (যদি d_o > f) বা ভার্চুয়াল |
| অপসারণ (অবতল) | নেতিবাচক | সর্বদা ভার্চুয়াল, ন্যায়পরায়ণ, হ্রাস |
### মিরর সমীকরণ
লেন্স সমীকরণের মতো একই ফর্ম: 1/f = 1/d_o + 1/d_i, যেখানে গোলাকার আয়নার জন্য f = R/2।

## ফুরিয়ার অপটিক্স
ফুরিয়ার অপটিক্স ইমেজিং এবং ডিফ্রাকশনকে ফুরিয়ার ট্রান্সফর্ম অপারেশন হিসাবে বিবেচনা করে।
### মূল নীতি
একটি অ্যাপারচারের দূর-ক্ষেত্রের বিচ্ছুরণ প্যাটার্ন হল অ্যাপারচার ফাংশনের **ফুরিয়ার রূপান্তর**।
| ছিদ্র | ডিফ্র্যাকশন প্যাটার্ন (ফুরিয়ার ট্রান্সফর্ম) |
|------------|------------------------------------------------------|
| একক চেরা | sinc ফাংশন |
| বৃত্তাকার অ্যাপারচার | বায়বীয় ডিস্ক (J₁(r)/r) |
| আয়তক্ষেত্রাকার অ্যাপারচার | 2D sinc |
| ঝাঁঝরি | বিচ্ছিন্ন ডেল্টা ফাংশন |
### অপটিক্যাল ফুরিয়ার ট্রান্সফর্ম
একটি লেন্স একটি 2D ফুরিয়ার ট্রান্সফর্ম করে: সামনের ফোকাল প্লেনে একটি বস্তু রাখলে পিছনের ফোকাল প্লেনে তার ফুরিয়ার ট্রান্সফর্ম উৎপন্ন হয়।
### আবেদন

## সারাংশ
| বিষয় | মূল ধারণা | মূল সমীকরণ |
|---------|------------|---------------|
| তরঙ্গ সমীকরণ | তরঙ্গ গতিতে প্রচার করে গ | ∂²u/∂t² = c²∂²u/∂x² |
| সুপারপজিশন | তরঙ্গ রৈখিকভাবে যোগ করুন | u = u₁ + u₂ |
| হস্তক্ষেপ | পর্যায় শক্তিবৃদ্ধি নির্ধারণ করে | Δφ = 2πΔL/λ |
| বিবর্তন | ঢেউ বাধার চারপাশে বাঁক | a sin θ = mλ (একক চেরা) |
| মেরুকরণ | দোলনের অভিযোজন | মালুসের সূত্র: I = I₀cos²θ |
| জ্যামিতিক অপটিক্স | রশ্মির মতো আলো | স্নেলের সূত্র: n₁sinθ₁ = n₂sinθ₂ |
| ফুরিয়ার অপটিক্স | ফুরিয়ার রূপান্তর হিসাবে ইমেজিং | দূর ক্ষেত্র = অ্যাপারচারের FT |
| ডপলার প্রভাব | গতি থেকে ফ্রিকোয়েন্সি স্থানান্তর | f' = f(v ± v_o)/(v ∓ v_s) |
তরঙ্গ হল দোদুল্যমান সিস্টেমের সার্বজনীন ভাষা। আপনি অডিও সিগন্যাল প্রসেস করছেন, টাইম সিরিজ বিশ্লেষণ করছেন, ইমেজ রিকগনিশন সিস্টেম ডিজাইন করছেন বা ফিজিক্স সিমুলেশন তৈরি করছেন, তরঙ্গের গণিত — সুপারপজিশন, ফুরিয়ার বিশ্লেষণ, হস্তক্ষেপ, বিভাজন — প্রয়োজনীয় টুলকিট প্রদান করে। অপটিক্স, সবচেয়ে পরিপক্ক তরঙ্গ বিজ্ঞান হিসাবে, তাত্ত্বিক ভিত্তি এবং ব্যবহারিক কৌশল উভয়ই অফার করে যা আধুনিক ডেটা বিজ্ঞানকে পরিব্যাপ্ত করে।
