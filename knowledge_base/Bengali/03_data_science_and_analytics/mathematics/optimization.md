# অপ্টিমাইজেশান
অপ্টিমাইজেশান হল সম্ভাব্য সমাধানের একটি সেট থেকে সেরা সমাধান খোঁজার গণিত। এটি জিজ্ঞাসা করে: একটি ফাংশন এবং সীমাবদ্ধতা দেওয়া হলে, কোন ইনপুট আউটপুটকে ছোট করে (বা সর্বাধিক করে)? অপ্টিমাইজেশান হল মেশিন লার্নিংয়ের ইঞ্জিন — একটি মডেলকে প্রশিক্ষণ দেওয়া মানে ক্ষতির কার্যকারিতা কমিয়ে আনা। এটি অপারেশন গবেষণা, অর্থনীতি, প্রকৌশল নকশা এবং কার্যত প্রতিটি পরিমাণগত ক্ষেত্রে প্রদর্শিত হয়।

## সমস্যা প্রণয়ন
একটি সাধারণ **অপ্টিমাইজেশান সমস্যা** এর ফর্ম রয়েছে:
ছোট করুন f(x)
সাপেক্ষে: gᵢ(x) ≤ 0 (বৈষম্যের সীমাবদ্ধতা), hⱼ(x) = 0 (সমতা সীমাবদ্ধতা)
| মেয়াদ | অর্থ |
|------|---------|
| **অবজেক্টিভ ফাংশন** f(x) | ন্যূনতম (বা সর্বাধিক) পরিমাণ |
| **ডিসিশন ভেরিয়েবল** x | আমরা যে মান নিয়ন্ত্রণ করতে পারি |
| **সম্ভাব্য অঞ্চল** | সমস্ত x সন্তুষ্ট সমস্ত সীমাবদ্ধতার সেট |
| **গ্লোবাল নূন্যতম** | সকল সম্ভাব্য x | এর জন্য f(x*) ≤ f(x) সহ সম্ভাব্য x*
| **স্থানীয় সর্বনিম্ন** | কোনো কোনো আশেপাশে সম্ভাব্য সব x এর জন্য f(x*) ≤ f(x) সহ সম্ভাব্য x* |
| **উত্তল সমস্যা** | f হল উত্তল, সম্ভাব্য অঞ্চল হল উত্তল সেট (স্থানীয় মিনিট = বিশ্ব মিনিট) |

## লিনিয়ার প্রোগ্রামিং (LP)
যখন উদ্দেশ্য এবং সমস্ত সীমাবদ্ধতা উভয়ই **রৈখিক** হয়, তখন সমস্যাটি একটি রৈখিক প্রোগ্রাম।
### স্ট্যান্ডার্ড ফর্ম
cᵀx ছোট করুন
সাপেক্ষে: Ax ≤ b, x ≥ 0
যেখানে c, x ∈ ℝⁿ, A ∈ ℝᵐˣⁿ, b ∈ ℝᵐ।
### বৈশিষ্ট্য
| সম্পত্তি | বিবৃতি |
|------------|------------|
| উত্তল | LP সবসময় একটি উত্তল সমস্যা |
| সর্বোত্তম সমাধান | সর্বদা সম্ভাব্য পলিটোপের একটি শীর্ষবিন্দুতে (কোণার বিন্দু) |
| অস্তিত্ব | যদি সম্ভাব্য অঞ্চল আবদ্ধ হয় এবং খালি না থাকে তবে সর্বোত্তম সমাধান বিদ্যমান |
| একাধিক অপটিমা | যদি দুটি শীর্ষবিন্দু সর্বোত্তম হয়, তবে তাদের মধ্যবর্তী প্রান্তের প্রতিটি বিন্দুও সর্বোত্তম |
### সিমপ্লেক্স পদ্ধতি
**সিমপ্লেক্স পদ্ধতি** (ড্যান্টজিগ, 1947) সম্ভাব্য পলিটোপের প্রান্ত বরাবর শীর্ষ থেকে শীর্ষে চলে, সর্বদা সর্বোত্তম না হওয়া পর্যন্ত উদ্দেশ্যকে উন্নত করে।
| সম্পত্তি | মান |
|----------|---------|
| সবচেয়ে খারাপ সময় | O(2ⁿ) (সূচকীয় — অনুশীলনে বিরল) |
| গড়-কেস সময় | অধিকাংশ ব্যবহারিক সমস্যার জন্য বহুপদ |
| মূল ধারণা | ভাল উদ্দেশ্য মান সহ সংলগ্ন শীর্ষবিন্দুতে যান |
**অ্যালগরিদম (ওভারভিউ):**
1. একটি মৌলিক সম্ভাব্য সমাধান থেকে শুরু করুন (পলিটোপের শীর্ষবিন্দু)
2. একটি এন্টারিং ভেরিয়েবল বেছে নিন (যেটি উদ্দেশ্যকে উন্নত করে)
3. একটি ছেড়ে যাওয়া পরিবর্তনশীল চয়ন করুন (সম্ভাব্যতা বজায় রাখুন)
4. পিভট: নতুন শীর্ষে যান
5. কোন উন্নতির দিক বিদ্যমান না হওয়া পর্যন্ত পুনরাবৃত্তি করুন
### অভ্যন্তরীণ পয়েন্ট পদ্ধতি
সিমপ্লেক্সের বিকল্প: সম্ভাব্য অঞ্চলের ভিতর থেকে সর্বোত্তম দিকে যান।
| সম্পত্তি | মান |
|----------|---------|
| সবচেয়ে খারাপ সময় | বহুপদ (O(n³·⁵) কিছু রূপের জন্য) |
| ব্যবহারিক কর্মক্ষমতা | বড় সমস্যা নিয়ে সিমপ্লেক্সের সাথে প্রতিযোগিতামূলক |
| মূল ধারণা | অভ্যন্তরের মধ্য দিয়ে একটি "কেন্দ্রীয় পথ" অনুসরণ করুন |
### কাজ করা এলপি উদাহরণ
**সমস্যা:** একটি কারখানা চেয়ার (x₁) এবং টেবিল (x₂) তৈরি করে।
- লাভ: প্রতি চেয়ার $30, প্রতি টেবিল $50
- কাঠ: 2x₁ + 4x₂ ≤ 100 (বোর্ড ফুট উপলব্ধ)
- শ্রম: x₁ + 3x₂ ≤ 60 (ঘন্টা উপলব্ধ)
- সর্বোচ্চ: 30x₁ + 50x₂
**সমাধান (২টি ভেরিয়েবলের জন্য গ্রাফিক্যাল পদ্ধতি):**
- সম্ভাব্য অঞ্চলের শীর্ষবিন্দু: (0,0), (30,0), (40,10), (0,20)
- প্রতিটি শীর্ষে উদ্দেশ্য মূল্যায়ন করুন:
  - (0,0): লাভ = 0
  - (30,0): লাভ = 900
  - (40,10): লাভ = 1700 ← সর্বোত্তম
  - (0,20): লাভ = 1000
- **অনুকূল:** x₁ = 40টি চেয়ার, x₂ = 10 টেবিল, লাভ = $1700

## উত্তল অপ্টিমাইজেশান
একটি সমস্যা হল **উত্তল** যদি উদ্দেশ্য ফাংশন উত্তল হয় এবং সম্ভাব্য অঞ্চলটি একটি উত্তল সেট হয়।
### উত্তল সেট এবং ফাংশন
| ধারণা | সংজ্ঞা |
|---------|------------|
| **উত্তল সেট** | যেকোন x এর জন্য সেটে y এবং t ∈ [0,1]: tx + (1−t)y সেটেও আছে |
| **উত্তল ফাংশন** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) সব t এর জন্য ∈ [0,1] |
| **কঠোরভাবে উত্তল** | অসমতা t ∈ (0,1) এবং x ≠ y | এর জন্য কঠোর
**কী সম্পত্তি:** উত্তল অপ্টিমাইজেশনের জন্য, প্রতিটি স্থানীয় সর্বনিম্ন একটি বিশ্বব্যাপী সর্বনিম্ন।
### সাধারণ উত্তল ফাংশন
| ফাংশন | উত্তল? | কোথায় |
|----------|---------|-------|
| ax + b (রৈখিক) | হ্যাঁ (এবং অবতল) | সর্বত্র |
| x² | হ্যাঁ | ℝ |
| eˣ | হ্যাঁ | ℝ |
| −log(x) | হ্যাঁ | x > 0 |
| \|x\|ᵖ (p ≥ 1) | হ্যাঁ | ℝⁿ |
| max(f₁, f₂) যদি f₁, f₂ উত্তল | হ্যাঁ | ডোমেনের ছেদ |
### গ্রেডিয়েন্ট ডিসেন্ট
মেশিন লার্নিংয়ে সবচেয়ে মৌলিক অপ্টিমাইজেশান অ্যালগরিদম।
**আপডেট নিয়ম:** x_{k+1} = x_k − α∇f(x_k)
যেখানে α > 0 হল **শিক্ষার হার** (পদক্ষেপের আকার)।
| বৈকল্পিক | হালনাগাদ করার নিয়ম | সুবিধা |
|---------|---------------|------------|
| **ব্যাচ জিডি** | x ← x − α∇f(x) | স্থিতিশীল অভিসার |
| **স্টোকাস্টিক জিডি (এসজিডি)** | x ← x − α∇fᵢ(x) (একটি নমুনা) | প্রতি পুনরাবৃত্তি দ্রুত, স্থানীয় মিনিমা এস্কেপ |
| **মিনি-ব্যাচ SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | ব্যাচ এবং স্টোকাস্টিক মধ্যে ভারসাম্য |
| **মোমেন্টাম** | v ← βv − α∇f(x); x ← x + v | সমতল অঞ্চলের মাধ্যমে ত্বরান্বিত হয় |
| **আদম** | প্রতি প্যারামিটারে অভিযোজিত শিক্ষার হার | গভীর শিক্ষার জন্য বাক্সের বাইরে ভাল কাজ করে |
| **RMSprop** | গ্রেডিয়েন্ট ম্যাগনিচুডের গড় চলমান দ্বারা স্কেল শেখার হার | RNN-এর জন্য ভালো |
### কনভারজেন্স রেট
| পদ্ধতি | উত্তল চ | দৃঢ়ভাবে উত্তল চ |
|---------|------------|---------|
| গ্রেডিয়েন্ট ডিসেন্ট | O(1/k) | O((1−μ/L)ᵏ) (রৈখিক) |
| SGD | O(1/√k) | O(1/k) |
| ত্বরিত জিডি (নেস্টেরভ) | O(1/k²) | O((1−√(μ/L))ᵏ) |
যেখানে k = পুনরাবৃত্তি গণনা, μ = শক্তিশালী উত্তল পরামিতি, L = লিপচিৎজ ধ্রুবক।
### শেখার হার নির্বাচন করা
| কৌশল | বর্ণনা |
|------------|-------------|
| স্থির α | সহজ কিন্তু বিচ্যুত হতে পারে (খুব বড়) অথবা ধীরে ধীরে একত্রিত হতে পারে (খুব ছোট) |
| লাইন অনুসন্ধান | α খুঁজুন যা গ্রেডিয়েন্ট দিক বরাবর f(x − α∇f(x)) ছোট করে |
| ক্ষয় সূচি | α_t = α₀ / (1 + βt) বা α_t = α₀ · βᵗ |
| ওয়ার্মআপ | ছোট শুরু করুন, বৃদ্ধি করুন, তারপর ক্ষয় করুন (ট্রান্সফরমার প্রশিক্ষণে সাধারণ) |
| অভিযোজিত (আদম) | গ্রেডিয়েন্ট পরিসংখ্যানের উপর ভিত্তি করে প্রতি-প্যারামিটার শেখার হার |

## সীমাবদ্ধ অপ্টিমাইজেশান
### ল্যাগ্রেঞ্জ মাল্টিপ্লায়ার
সমস্যার জন্য: h(x) = 0 সাপেক্ষে f(x) ছোট করুন।
**ল্যাগ্রাঞ্জিয়ান:** L(x, λ) = f(x) + λh(x)
সর্বোত্তম: ∇ₓL = 0 এবং ∇_λL = 0 (যা দেয় h(x) = 0)।
**কাজ করা উদাহরণ:** f(x,y) = x² + y² সাপেক্ষে x + y = 1 ছোট করুন।
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- সীমাবদ্ধতা: x + y = 1 → −λ = 1 → λ = −1
- সমাধান: x = 1/2, y = 1/2, f = 1/2
### KKT শর্তাবলী
**Karush-Kuhn-Tucker (KKT) শর্ত** Lagrange গুণককে অসমতার সীমাবদ্ধতায় সাধারণ করে।
জন্য: gᵢ(x) ≤ 0, hⱼ(x) = 0 সাপেক্ষে f(x) ছোট করুন।
**ল্যাগ্রাঞ্জিয়ান:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT শর্ত** (অনুকূলতার জন্য প্রয়োজনীয়):
| শর্ত | সমীকরণ |
|------------|----------|
| স্থিরতা | ∇ₓL = 0 |
| প্রাথমিক সম্ভাব্যতা | gᵢ(x) ≤ 0, hⱼ(x) = 0 |
| দ্বৈত সম্ভাব্যতা | λᵢ ≥ 0 |
| পরিপূরক শিথিলতা | λᵢgᵢ(x) = 0 সবার জন্য i |
**পরিপূরক শিথিলতা** মানে: যদি সীমাবদ্ধতা gᵢ সক্রিয় না হয় (gᵢ(x) < 0), তাহলে λᵢ = 0 (সীমাবদ্ধতা সমাধানকে প্রভাবিত করে না)।
স্লেটারের অবস্থাকে সন্তুষ্ট করার উত্তল সমস্যার জন্য, KKT শর্ত উভয়ই প্রয়োজনীয় এবং যথেষ্ট।

## দ্বৈততা
প্রতিটি অপ্টিমাইজেশান সমস্যা (**প্রাথমিক**) এর সাথে যুক্ত **দ্বৈত** সমস্যা রয়েছে।
### দুর্বল এবং শক্তিশালী দ্বৈততা
| ধারণা | বিবৃতি |
|---------|------------|
| **দ্বৈত ফাংশন** | g(λ, ν) = infₓ L(x, λ, ν) |
| **দ্বৈত সমস্যা** | λ ≥ 0 | সাপেক্ষে g(λ, ν) সর্বাধিক করুন
| **দুর্বল দ্বৈততা** | দ্বৈত সর্বোত্তম ≤ প্রাথমিক সর্বোত্তম (সর্বদা ধারণ করে) |
| **শক্তিশালী দ্বৈত** | দ্বৈত সর্বোত্তম = প্রাথমিক সর্বোত্তম (স্লেটারের অবস্থার সাথে উত্তল সমস্যার জন্য ধারণ করে) |
| **দ্বৈততার ফাঁক** | আদিম সর্বোত্তম − দ্বৈত সর্বোত্তম (শক্তিশালী দ্বৈততার অধীনে শূন্য) |
### কেন দ্বৈততা গুরুত্বপূর্ণ
| আবেদন | কিভাবে দ্বৈততা সাহায্য করে |
|---------------|-------------------|
| নিম্ন সীমানা | দ্বৈত প্রাথমিক সমাধান কতটা ভালো তার একটি শংসাপত্র দেয় |
| SVMs | দ্বৈত SVM সমস্যা কার্নেল কৌশলের দিকে নিয়ে যায় |
| সংবেদনশীলতা বিশ্লেষণ | দ্বৈত ভেরিয়েবল পরিমাপ করে যে সীমাবদ্ধতা শিথিল হলে সর্বোত্তম কতটা পরিবর্তন হয় |
| পচন | বড় সমস্যাগুলোকে ডুয়াল |

## ইন্টিজার প্রোগ্রামিং
যখন কিছু বা সমস্ত ভেরিয়েবল অবশ্যই **পূর্ণসংখ্যা** হতে হবে, সমস্যাটি অনেক কঠিন হয়ে যায় (সাধারণভাবে NP-হার্ড)।
### প্রকার
| প্রকার | বর্ণনা |
|------|---------------|
| বিশুদ্ধ আইপি | সমস্ত ভেরিয়েবল অবশ্যই পূর্ণসংখ্যা হতে হবে |
| মিশ্র আইপি (MIP) | কিছু ভেরিয়েবল পূর্ণসংখ্যা, কিছু একটানা |
| বাইনারি আইপি | ভেরিয়েবল সীমাবদ্ধ {0, 1} |
### সমাধান পদ্ধতি
| পদ্ধতি | আইডিয়া |
|---------|------|
| **শাখা এবং আবদ্ধ** | উপ-সমস্যাগুলিতে বিভক্ত করুন, LP শিথিলতা সমাধান করুন, ছাঁটাই |
| **কাটিং প্লেন** | LP শিথিলকরণকে শক্ত করতে রৈখিক সীমাবদ্ধতা যুক্ত করুন |
| **শাখা এবং কাটা** | কাটিং প্লেন সঙ্গে শাখা-ও-বাউন্ড একত্রিত করুন |
| ** হিউরিস্টিক** | লোভী, স্থানীয় অনুসন্ধান, আনুমানিক সমাধানের জন্য সিমুলেটেড অ্যানিলিং |

## হিউরিস্টিক এবং মেটাহিউরিস্টিক পদ্ধতি
যখন সঠিক অপ্টিমাইজেশন জটিল হয়, তখন হিউরিস্টিকরা ভাল (অগত্যা সর্বোত্তম নয়) সমাধান খুঁজে পায়।
| পদ্ধতি | মূল ধারণা | জন্য সেরা |
|---------|----------|----------|
| **গ্রেডিয়েন্ট ডিসেন্ট** | খাড়া বংশধারা অনুসরণ করুন | মসৃণ, পার্থক্যযোগ্য ফাংশন |
| **নিউটনের পদ্ধতি** | দ্বিতীয় ক্রম (বক্রতা) তথ্য ব্যবহার করুন | মসৃণ, ভাল-নিয়ন্ত্রিত সমস্যা |
| **সিমুলেটেড অ্যানিলিং** | কমার সম্ভাবনা সহ আরও খারাপ সমাধান গ্রহণ করুন | গ্লোবাল অপ্টিমাইজেশান, কম্বিনেটরিয়াল |
| **জেনেটিক অ্যালগরিদম** | নির্বাচন, ক্রসওভার, মিউটেশন ব্যবহার করে একটি জনসংখ্যার বিকাশ করুন | বহু-উদ্দেশ্য, অ-পার্থক্য |
| **কণা ঝাঁক** | এজেন্ট স্থান অন্বেষণ, সবচেয়ে পরিচিত অবস্থান দ্বারা প্রভাবিত | ক্রমাগত, অ-উত্তল |
| **বায়েসিয়ান অপ্টিমাইজেশান** | সারোগেট মডেল তৈরি করুন, অধিগ্রহণ ফাংশন ব্যবহার করুন | ব্যয়বহুল ব্ল্যাক-বক্স ফাংশন (হাইপারপ্যারামিটার টিউনিং) |
### অপ্টিমাইজেশনের জন্য নিউটনের পদ্ধতি
**আপডেট নিয়ম:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
যেখানে H হল হেসিয়ান ম্যাট্রিক্স (দ্বিতীয় ডেরিভেটিভের ম্যাট্রিক্স)।
| সম্পত্তি | মান |
|----------|---------|
| কনভারজেন্স রেট | দ্বিঘাত (সর্বোচ্চের কাছাকাছি) |
| প্রতি পুনরাবৃত্তি খরচ | হেসিয়ান ইনভার্সশনের জন্য O(n³) |
| প্রয়োজন | দ্বিগুণ পার্থক্যযোগ্য, ইতিবাচক নির্দিষ্ট হেসিয়ান |
| কোয়াসি-নিউটন (BFGS) | গ্রেডিয়েন্ট থেকে আনুমানিক হেসিয়ান | O(n²) প্রতি পুনরাবৃত্তি |

| অ্যাডাম, আরএমএসপ্রপ | গভীর শিক্ষার জন্য ডিফল্ট অপ্টিমাইজার |
| উত্তল অপ্টিমাইজেশান | SVMs, লজিস্টিক রিগ্রেশন, LASSO, Ridge (গ্যারান্টিযুক্ত গ্লোবাল অপ্টিমাম) |

| লিনিয়ার প্রোগ্রামিং | সম্পদ বরাদ্দ, পোর্টফোলিও অপ্টিমাইজেশান, নেটওয়ার্ক প্রবাহ |
| পূর্ণসংখ্যা প্রোগ্রামিং | বৈশিষ্ট্য নির্বাচন (বাইনারী), সময়সূচী, সমন্বিত সমস্যা |
| Bayesian অপ্টিমাইজেশান | হাইপারপ্যারামিটার টিউনিং (Optuna, Hyperopt) |
| নিউটন/কোয়াসি-নিউটন | ছোট থেকে মাঝারি সমস্যার জন্য দ্বিতীয় ক্রম পদ্ধতি (L-BFGS) |

## সারাংশ
| পদ্ধতি | সমস্যার ধরন | গ্যারান্টি | স্কেল |
|---------|-------------|------------|-------|
| সিম্পলেক্স | লিনিয়ার প্রোগ্রামিং | সঠিক সর্বোত্তম | লক্ষ লক্ষ ভেরিয়েবল |
| অভ্যন্তরীণ পয়েন্ট | উত্তল (LP, QP, SOCP) | সঠিক সর্বোত্তম | বড় স্কেল |
| গ্রেডিয়েন্ট ডিসেন্ট | মসৃণ অনিয়ন্ত্রিত | স্থানীয় মিনিটে রূপান্তরিত হয় | খুব বড় (গভীর শিক্ষা) |
| SGD | বড় মাপের অভিজ্ঞতামূলক ঝুঁকি | একত্রিত হয় (ক্ষয়ের সাথে) | বিশাল ডেটাসেট |
| নিউটন / BFGS | মসৃণ, দ্বিগুণ পার্থক্যযোগ্য | চতুর্মুখী অভিসরণ | ছোট থেকে মাঝারি |
| KKT / Lagrange | সীমাবদ্ধ (উত্তল) | শর্ত অনুযায়ী সঠিক | মাঝারি |
| শাখা এবং আবদ্ধ | পূর্ণসংখ্যা প্রোগ্রামিং | সঠিক সর্বোত্তম | ছোট থেকে মাঝারি |
| হিউরিস্টিকস | যেকোন (অ-উত্তল, সমন্বিত) | কোন গ্যারান্টি নেই | পরিবর্তিত হয় |
অপ্টিমাইজেশন যুক্তিযুক্তভাবে মেশিন লার্নিংয়ের সবচেয়ে গুরুত্বপূর্ণ গাণিতিক সরঞ্জাম। আপনি প্রশিক্ষিত প্রতিটি মডেল — রৈখিক রিগ্রেশন থেকে বৃহৎ ভাষার মডেল পর্যন্ত — একটি অপ্টিমাইজেশান সমস্যা সমাধানের সাথে জড়িত। কোন সমস্যা কখন উত্তল (গ্লোবাল সর্বোত্তম গ্যারান্টিযুক্ত), কখন গ্রেডিয়েন্ট ডিসেন্ট একত্রিত হবে এবং কীভাবে সীমাবদ্ধতাগুলি পরিচালনা করবেন তা বোঝা আপনাকে শেখার অ্যালগরিদমগুলি ডিজাইন, ডিবাগ এবং উন্নত করার তাত্ত্বিক ভিত্তি দেয়।
