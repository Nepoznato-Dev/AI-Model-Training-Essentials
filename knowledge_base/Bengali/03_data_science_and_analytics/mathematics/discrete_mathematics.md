# বিচ্ছিন্ন গণিত
বিচ্ছিন্ন গণিত হল গাণিতিক কাঠামোর অধ্যয়ন যা মৌলিকভাবে গণনাযোগ্য বা পৃথক করা হয় — ক্রমাগত গণিতের বিপরীতে (ক্যালকুলাস, বাস্তব বিশ্লেষণ), যা মসৃণ, অবিচ্ছিন্ন পরিমাণ নিয়ে কাজ করে। বিচ্ছিন্ন গণিত কম্পিউটার বিজ্ঞান, ক্রিপ্টোগ্রাফি, অ্যালগরিদম ডিজাইন এবং ডেটা স্ট্রাকচারকে আন্ডারপিন করে। যদি ক্রমাগত গণিত ভৌত জগতকে বর্ণনা করে, তবে পৃথক গণিত গণনা জগতের বর্ণনা করে।

## গভীরতায় তত্ত্ব সেট করুন
সেট হল সেই ভিত্তি যার উপর প্রায় সমস্ত আধুনিক গণিত নির্মিত হয়েছে। একটি **সেট** হল স্বতন্ত্র বস্তুর একটি ক্রমবিহীন সংগ্রহ, যাকে **উপাদান** বা **সদস্য** বলা হয়।
### স্বতঃসিদ্ধ ভিত্তি (জেডএফসি)
আধুনিক সেট তত্ত্ব **জেরমেলো-ফ্রেঙ্কেল স্বতঃসিদ্ধ স্বতঃসিদ্ধ সহ Axiom of Choice (ZFC)** এর উপর নির্ভর করে। এই স্বতঃসিদ্ধগুলি রাসেলের প্যারাডক্স ("সমস্ত সেটের সেট যা নিজেদেরকে ধারণ করে না") মত প্যারাডক্সের সমাধান করে কিভাবে সেট তৈরি করা যায় তা সীমাবদ্ধ করে।
| স্বতঃসিদ্ধ | অনানুষ্ঠানিক বিবৃতি |
|---------|---------|
| বিস্তৃতি | দুটি সেট সমান যদি তাদের একই উপাদান থাকে |
| খালি সেট | কোন উপাদান ছাড়া একটি সেট বিদ্যমান: ∅ |
| পেয়ারিং | যে কোনো a, b এর জন্য {a, b} | বিদ্যমান
| ইউনিয়ন | সেটের যে কোনো পরিবারের জন্য, তাদের মিলন বিদ্যমান |
| পাওয়ার সেট | যেকোনো সেট S-এর জন্য, S-এর সমস্ত উপসেটের সেট বিদ্যমান: P(S) |
| অনন্ত | একটি অসীম সেট বিদ্যমান |
| স্পেসিফিকেশন | যেকোন সেট A এবং প্রপার্টি P এর জন্য, {x ∈ A : P(x)} বিদ্যমান |
| প্রতিস্থাপন | একটি সংজ্ঞায়িত ফাংশনের অধীনে একটি সেটের চিত্র একটি সেট |
| নিয়মিততা | প্রতিটি অ-খালি সেটে এটি থেকে একটি উপাদান বিচ্ছিন্ন থাকে (স্ব-সদস্যতা প্রতিরোধ করে) |
| পছন্দ | অ-খালি পেয়ারওয়াইজ ডিসজয়েন্ট সেটের যেকোনো পরিবারের জন্য, একটি পছন্দ ফাংশন বিদ্যমান |
### কার্ডিনালিটি এবং সেটের আকার
একটি সেটের **কার্ডিনালিটি**, |S| নির্দেশিত, এর "আকার" পরিমাপ করে।
| ধারণা | সংজ্ঞা | উদাহরণ |
|---------|------------|---------|
| সসীম সেট | কার্ডিনালিটি হিসাবে একটি স্বাভাবিক সংখ্যা আছে | |{a, b, c}| = 3 |
| গননাত অসীম | একই কার্ডিনালিটি ℕ | ℤ, ℚ গণনাযোগ্যভাবে অসীম |
| অগণিত | ℕ এর চেয়ে বড় ℝ, P(ℕ), সমস্ত ফাংশনের সেট ℕ → {0,1} |
| ক্যান্টরের উপপাদ্য | যেকোনো সেট S, |P(S)| এর জন্য > |এস| | |P(ℕ)| > |ℕ| |
**ক্যান্টরের তির্যক যুক্তি** প্রমাণ করে যে ℝ গণনাযোগ্য: অনুমান করুন আপনি সমস্ত বাস্তবকে [0,1]-এ তালিকাভুক্ত করতে পারেন, তারপর একটি নতুন বাস্তব তৈরি করুন যা nম দশমিক স্থানে nম তালিকাভুক্ত বাস্তব থেকে আলাদা — দ্বন্দ্ব।
### সেটে অপারেশন
| অপারেশন | স্বরলিপি | সংজ্ঞা | সম্পত্তি |
|------------|----------|------------|----------|
| ইউনিয়ন | A ∪ B | {x : x ∈ A বা x ∈ B} | পরিবর্তনমূলক, সহযোগী |
| ছেদ | A ∩ B | {x : x ∈ A এবং x ∈ B} | পরিবর্তনমূলক, সহযোগী |
| পার্থক্য | ক \ বি | {x : x ∈ A এবং x ∉ B} | পরিবর্তনশীল নয় |
| প্রতিসম পার্থক্য | ক △ বি | (A\B) ∪ (B \A) | পরিবর্তনমূলক, সহযোগী |
| পরিপূরক | Aᶜ | U \ A (যেখানে U সর্বজনীন সেট) | (Aᶜ)ᶜ = A |
| কার্টেসিয়ান পণ্য | ক × বি | {(a,b): a ∈ A, b ∈ B} | |A × B| = |এ| · |বি| |
**ডি মরগানের আইন:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**অন্তর্ভুক্তি-বর্জনের নীতি** (সীমিত সেটের জন্য):
|A₁ ∪ A₂ ∪ ... ∪ Aₙ | = Σ|আ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|

## সম্পর্ক
A **সম্পর্ক** R সেট A এবং B A × B এর একটি উপসেট। যখন (a, b) ∈ R, তখন আমরা aRb লিখি।
### সম্পর্কের প্রকারভেদ
A সেটে একটি সম্পর্ক R এই বৈশিষ্ট্যগুলি থাকতে পারে:
| সম্পত্তি | সংজ্ঞা | উদাহরণ |
|----------|------------|---------|
| রিফ্লেক্সিভ | ∀a ∈ A: aRa | ≤ অন ℤ |
| অপ্রতিরোধ্য | ∀a ∈ A: ¬(aRa) | < অন ℤ |
| প্রতিসম | ∀a,b: aRb → bRa | = যেকোনো সেটে |
| অপ্রতিসম | ∀a,b: aRb ∧ bRa → a = b | ≤ অন ℤ |
| ট্রানজিটিভ | ∀a,b,c: aRb ∧ bRc → aRc | <, ≤, = অন ℤ |
### সমতা সম্পর্ক
একটি **সমতা সম্পর্ক** হল প্রতিফলিত, প্রতিসম, এবং ট্রানজিটিভ। এটি একটি সেটকে ডিসজয়েন্ট **ইকুয়ালেন্স ক্লাস**-এ বিভাজন করে।
**উদাহরণ:** মডুলার পাটিগণিত। a ~ b iff a ≡ b (mod n) সংজ্ঞায়িত করুন। সমতুল্য শ্রেণী হল [0], [1], ..., [n−1], যা ℤকে n শ্রেণীতে ভাগ করে।
**কাজ করা উদাহরণ:** ℤ × ℤ-এ, (a,b) ~ (c,d) iff a + d = b + c সংজ্ঞায়িত করুন। এটি একটি সমতুল্য সম্পর্ক। ক্লাস [(0,0)] = {(n,n): n ∈ ℤ}। ক্লাস [(1,0)] = {(n+1,n): n ∈ ℤ}। এই নির্মাণ প্রকৃতপক্ষে প্রাকৃতিক সংখ্যা থেকে পূর্ণসংখ্যা সংজ্ঞায়িত করে।
### আংশিক আদেশ
একটি **আংশিক ক্রম** রিফ্লেক্সিভ, অ্যান্টিসিমেট্রিক এবং ট্রানজিটিভ। আংশিক ক্রম সহ একটি সেটকে **আংশিকভাবে আদেশকৃত সেট (পোসেট)** বলা হয়।
| ধারণা | সংজ্ঞা | উদাহরণ |
|---------|------------|---------|
| পোসেট | (S, ≤) ≤ একটি আংশিক আদেশ সহ | (P(A), ⊆) — অন্তর্ভুক্তির দ্বারা ক্রমকৃত উপসেট |
| চেইন | একটি সম্পূর্ণ অর্ডার করা উপসেট | P({a,b,c}) এ {∅, {a}, {a,b}} |
| অ্যান্টিচেইন | একটি উপসেট যেখানে কোন দুটি উপাদান তুলনাযোগ্য নয় | {{a}, {b}} P({a,b}) |
| হাসে ডায়াগ্রাম | একটি পোজেটের ভিজ্যুয়াল উপস্থাপনা | শুধুমাত্র সম্পর্ক আবরণের জন্য প্রান্ত আঁকুন |
| আপার বাউন্ড | একটি উপাদান ≥ একটি উপসেটের প্রতিটি উপাদান | sup({2,3}) = 6 ইঞ্চি (ℤ, \|) (বিভাজ্যতা) |
| Least Upper Bound (sup) | সবচেয়ে ছোট উপরের সীমানা | sup({2,3}) in (ℕ, ≤) হল 3 |
| গ্রেটেস্ট লোয়ার বাউন্ড (inf) | সবচেয়ে বড় নিম্ন সীমানা | inf({4,6}) in (ℕ, \|) হল 2 |

## ফাংশন
A **ফাংশন** f: A → B A এর প্রতিটি উপাদানকে B এর ঠিক একটি উপাদান বরাদ্দ করে।
### ফাংশনের শ্রেণীবিভাগ
| প্রকার | সংজ্ঞা | উদাহরণ |
|------|------------|---------|
| ইনজেকটিভ (এক থেকে এক) | f(a) = f(b) → a = b | f(x) = 2x থেকে ℤ → ℤ |
| সারজেক্টিভ (অনটো) | ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x mod 2 থেকে ℤ → {0,1} |
| উদ্দেশ্যমূলক | ইনজেক্টিভ এবং সার্জেক্টিভ উভয়ই | f(x) = x + 1 থেকে ℤ → ℤ |
### গুরুত্বপূর্ণ ফাংশন ধারণা
| ধারণা | সংজ্ঞা | কেস ব্যবহার করুন |
|---------|------------|------------|
| বিপরীত ফাংশন | f⁻¹ বিদ্যমান iff f দ্বিমুখী | এনক্রিপ্ট করা ডেটা ডিক্রিপ্ট করা হচ্ছে |
| রচনা | (g ∘ f)(x) = g(f(x)) | চেইনিং রূপান্তর |
| আইডেন্টিটি ফাংশন | id(x) = x | রচনার জন্য নিরপেক্ষ উপাদান |
| স্থির বিন্দু | f(x) = x | পুনরাবৃত্ত সংজ্ঞা, শব্দার্থবিদ্যা |
| স্থানান্তর | একটি সেট থেকে নিজেই একটি দ্বিখণ্ডন | তথ্য পুনর্বিন্যাস, এলোমেলো |
### গণনা ফাংশন
প্রদত্ত সসীম সেট |A| = m এবং |B| = n:
| প্রকার | গণনা |
|------|---------|
| সমস্ত ফাংশন A → B | nᵐ |
| ইনজেকশন ফাংশন | n! / (n−m)! (যদি n ≥ m, অন্যথায় 0) |
| অনুমানমূলক ফাংশন | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ (অন্তর্ভুক্তি-বর্জন দ্বারা) |
| দ্বিমুখী ফাংশন | n! (যখন m = n) |

## কম্বিনেটরিক্স
কম্বিনেটরিক্স হল গণনা, সাজানো এবং নির্বাচন করার গণিত।
### মৌলিক গণনা নীতি
| নীতি | বিবৃতি | উদাহরণ |
|------------|------------|---------|
| সমষ্টির নিয়ম | যদি A এবং B বিচ্ছিন্ন হয়, |A ∪ B| = |এ| + |বি| | একটি ফল নির্বাচন করা: 3টি আপেল + 4টি কমলা = 7টি বিকল্প |
| পণ্যের নিয়ম | |A × B| = |এ| · |বি| | পোশাক: ৩টি শার্ট × ৪টি প্যান্ট = ১২টি পোশাক |
| বিজেকশন নিয়ম | যদি f: A → B একটি বিজেকশন হয়, |A| = |বি| | বাইনারি স্ট্রিং গণনা করে উপসেট গণনা করুন |
| পরিপূরক | |এ| = |U| − |আন | | মোট বিয়োগ "কোনটিই নয়" হিসাবে "অন্তত একটি" গণনা করুন |
### পারমুটেশন এবং কম্বিনেশন
| স্বরলিপি | নাম | সূত্র | অর্থ |
|----------|------|---------|---------|
| C(n, k) বা (n k) | দ্বিপদ সহগ | n! / (k!(n−k)!) | n থেকে k আইটেম বেছে নেওয়ার উপায় (অর্ডার কোন ব্যাপার না) |
| P(n, k) | n | এর k-ক্রম পরিবর্তন n! / (n−k)! | n থেকে k আইটেম সাজানোর উপায় (অর্ডার বিষয়) |
| n! | ফ্যাক্টরিয়াল | n × (n−1) × ... × 1 | সমস্ত n আইটেম সাজানোর উপায় |
| (n k) পুনরাবৃত্তি সহ | মাল্টিচোজ | C(n+k−1, k) | পুনরাবৃত্তির অনুমতি দিয়ে n থেকে k চয়ন করুন |
**দ্বিপদ উপপাদ্য:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**পাসকালের পরিচয়:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### কবুতরের মূল নীতি
**মৌলিক ফর্ম:** যদি n+1 বস্তু n বক্সে স্থাপন করা হয়, অন্তত একটি বক্সে ≥ 2টি বস্তু থাকে।
**সাধারণ রূপ:** যদি N বস্তুগুলিকে k বক্সে স্থাপন করা হয়, তাহলে অন্তত একটি বাক্সে ≥ ⌈N/k⌉ অবজেক্ট থাকে।
**কাজ করা উদাহরণ:**
1. যেকোনো 13 জনের মধ্যে, অন্তত 2 জন একটি জন্ম মাসে ভাগ করে নেয়। (13 জন, 12 মাস → কবুতর।)
2. দেখান যে কোন 5টি পূর্ণসংখ্যার মধ্যে 3টি আছে যার যোগফল 3 দ্বারা বিভাজ্য।
   - অবশিষ্টাংশ মোড 3 বিবেচনা করুন: {0, 1, 2}। 5টি পূর্ণসংখ্যা এবং 3টি অবশিষ্টাংশের সাথে, সাধারণীকৃত কবুতরের দ্বারা, কমপক্ষে ⌈5/3⌉ = 2 একটি অবশিষ্টাংশ ভাগ করে।
   - যদি 3 একটি অবশিষ্টাংশ ভাগ করে r: তাদের যোগফল ≡ 3r ≡ 0 (mod 3)।
   - যদি 2 ভাগ অবশিষ্টাংশ 0 এবং 2 ভাগ অবশিষ্টাংশ 1: ​​প্রতিটি জোড়া থেকে একটি বাছাই এবং একটি অবশিষ্টাংশ-0 উপাদান → সমষ্টি ≡ 0 (মোড 3)।
3. **CS-এ অ্যাপ্লিকেশন:** যেকোন ক্ষতিহীন কম্প্রেশন অ্যালগরিদমকে অবশ্যই কিছু ইনপুট প্রসারিত করতে হবে। (যদি প্রতিটি n-বিট স্ট্রিং < n বিটে সংকুচিত হয়, তাহলে আপনি 2ⁿ স্ট্রিংকে 2ⁿ কমপ্রেসড স্ট্রিং-এ ম্যাপ করবেন — ইনজেক্টিভিটি লঙ্ঘন করে।)
### কাতালান সংখ্যা
তম **কাতালান সংখ্যা** Cₙ = C(2n, n) / (n+1) গণনা:
| গঠন | উদাহরণ |
|------------|---------|
| বৈধ বন্ধনী ক্রম | ()(), ()) n = 2 এর জন্য |
| n অভ্যন্তরীণ নোড সহ বাইনারি গাছ | n = 2 এর জন্য 2টি গাছ |
| তির্যক অতিক্রম করে না পথ | (0,0) থেকে (n,n) পর্যন্ত গ্রিড পাথ y = x | এর নিচে থাকে
| বহুভুজের ত্রিভুজ | একটি (n+2)-গনকে ত্রিভুজে ভাগ করার উপায় |
প্রথম কয়েকটি: C₀ = 1, C₁ = 1, C₂ = 2, C₃ = 5, C₄ = 14, C₅ = 42।
পুনরাবৃত্তি: Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## পুনরাবৃত্তি সম্পর্ক
একটি **পুনরাবৃত্তি সম্পর্ক** একটি অনুক্রমের প্রতিটি পদকে পূর্ববর্তী পদের একটি ফাংশন হিসাবে সংজ্ঞায়িত করে।
### প্রকার ও সমাধান
| প্রকার | ফর্ম | সমাধান পদ্ধতি |
|------|------|-----------------|
| রৈখিক সমজাতীয় (ধ্রুবক কোফ।) | aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ | চারিত্রিক সমীকরণ |
| রৈখিক অ-সমজাতীয় | aₙ = c₁aₙ₋₁ + ... + f(n) | বিশেষ দ্রবণ + সমজাতীয় দ্রবণ |
| বিভক্ত করুন এবং জয় করুন | T(n) = aT(n/b) + f(n) | মাস্টার উপপাদ্য |
### চরিত্রগত সমীকরণ পদ্ধতি
aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ এর জন্য, চরিত্রগত সমীকরণ তৈরি করুন:
r² − c₁r − c₂ = 0
| মামলা | শিকড় | সাধারণ সমাধান |
|------|---------|------------------|
| দুটি স্বতন্ত্র বাস্তব মূল r₁, r₂ | r₁ ≠ r₂ | aₙ = A·r₁ⁿ + B·r₂ⁿ |
| পুনরাবৃত্ত মূল r | r₁ = r₂ = r | aₙ = (A + Bn)·rⁿ |
| জটিল শিকড় α ± βi | পোলারে রূপান্তর করুন: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**কাজ করা উদাহরণ:** ফিবোনাচি সিকোয়েন্স Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1।
- চরিত্রগত সমীকরণ: r² − r − 1 = 0
- মূল: r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618, ψ = (1−√5)/2 ≈ −0.618
- সাধারণ সমাধান: Fₙ = A·φⁿ + B·ψⁿ
- প্রাথমিক অবস্থা থেকে: A = 1/√5, B = −1/√5
- **বন্ধ ফর্ম:** Fₙ = (φⁿ − ψⁿ) / √5 (বিনেটের সূত্র)
### মাস্টার থিওরেম
ফর্মের পুনরাবৃত্তির জন্য T(n) = aT(n/b) + f(n) যেখানে a ≥ 1, b > 1:
চলুন c = log_b(a)।
| মামলা | শর্ত | সমাধান |
|------|------------|----------|
| 1 | f(n) = O(nᵈ) যেখানে d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c, এবং af(n/b) ≤ kf(n) কিছু k < 1 | T(n) = Θ(nᵈ) |
**উদাহরণ:**
- মার্জ সাজান: T(n) = 2T(n/2) + O(n)। এখানে a=2, b=2, c=1, f(n)=n=Θ(n¹)। কেস 2: T(n) = Θ(n লগ n)।
- বাইনারি অনুসন্ধান: T(n) = T(n/2) + O(1)। এখানে a=1, b=2, c=0, f(n)=1=Θ(n⁰)। কেস 2: T(n) = Θ(log n)।

## ফাংশন তৈরি করা
একটি **জেনারেটিং ফাংশন** একটি সিকোয়েন্স (aₙ) কে একটি আনুষ্ঠানিক পাওয়ার সিরিজের সহগ হিসাবে এনকোড করে।
### প্রকার
| প্রকার | ফর্ম | কেস ব্যবহার করুন |
|------|------|----------|
| সাধারণ (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ | লেবেলবিহীন কাঠামো, রচনা |
| সূচকীয় (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n! | লেবেলযুক্ত কাঠামো, স্থানান্তর |
### কমন জেনারেটিং ফাংশন
| ক্রম aₙ | OGF G(x) |
|---------------|------------|
| 1, 1, 1, 1, ... | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² |
| 1, r, r², r³, ... | 1/(1−rx) |
| স্থির k এর জন্য C(n,k) | xᵏ/(1−x)ᵏ⁺¹ |
| ফিবোনাচি Fₙ | x/(1−x−x²) |
| কাতালান Cₙ | (1 − √(1−4x)) / (2x) |
### পুনরাবৃত্ত সমাধান করতে জেনারেটিং ফাংশন ব্যবহার করে
**কাজ করা উদাহরণ:** aₙ = 3aₙ₋₁ − 2aₙ₋₂, a₀ = 1, a₁ = 3 সমাধান করুন।
1. ধরুন G(x) = Σ aₙxⁿ.
2. পুনরাবৃত্তি থেকে: G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. বিকল্প: G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. আংশিক ভগ্নাংশ: G(x) = 2/(1−2x) − 1/(1−x)
7. নির্যাস সহগ: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺¹ −1
**যাচাই:** a₀ = 2−1 = 1, a₁ = 4−1 = 3, a₂ = 8−1 = 7. চেক করুন: 3(3) − 2(1) = 7৷

## বুলিয়ান বীজগণিত এবং প্রস্তাবনামূলক যুক্তিবিদ্যা
বুলিয়ান বীজগণিত হল দুটি সত্য মানের বীজগণিত: **True (1)** এবং **False (0)**। এটি ডিজিটাল সার্কিট, ডাটাবেস প্রশ্ন এবং প্রোগ্রামিং শর্তাবলীর গাণিতিক ভিত্তি।
### অপারেশন এবং আইন
| অপারেশন | প্রতীক | অর্থ | সত্য ছক |
|------------|---------|---------|-------------|
| এবং | p ∧ q | সত্য শুধুমাত্র যখন উভয় সত্য | T∧T=T, T∧F=F, F∧T=F, F∧F=F |
| বা | p ∨ q | সত্য যখন অন্তত একটি সত্য | T∨T=T, T∨F=T, F∨T=T, F∨F=F |
| না | ¬p | অস্বীকার | ¬T=F, ¬F=T |
| XOR | p ⊕ q | সত্য যখন ঠিক এক সত্য | T⊕T=F, T⊕F=T, F⊕T=T, F⊕F=F |
| বোঝায় | p → q | মিথ্যা শুধুমাত্র তখনই যখন p=T এবং q=F | T→T=T, T→F=F, F→T=T, F→F=T |
| দ্বিশর্তিক | p ↔ q | সত্য যখন উভয়ের একই মান থাকে | T↔T=T, T↔F=F, F↔T=F, F↔F=T |
### মূল বুলিয়ান আইডেন্টিটিস
| আইন | সূত্র |
|------|---------|
| কমিউটেটিভিটি | p ∧ q = q ∧ p; p ∨ q = q ∨ p |
| সহযোগীতা | (p ∧ q) ∧ r = p ∧ (q ∧ r) |
| ডিস্ট্রিবিউটিভিটি | p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
| ডি মরগানের আইন | ¬(p ∧ q) = ¬p ∨ ¬q; ¬(p ∨ q) = ¬p ∧ ¬q |
| ডাবল নেগেশান | ¬(¬p) = p |
| অদম্যতা | p ∧ p = p; p ∨ p = p |
| শোষণ | p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
| কন্ট্রাপজিটিভ | (p → q) ≡ (¬q → ¬p) |
### সাধারণ ফর্ম
| ফর্ম | গঠন | কেস ব্যবহার করুন |
|------|------------|----------|
| কনজেক্টিভ নরমাল ফর্ম (CNF) | ORs এর AND: (A∨B) ∧ (C∨D) | SAT সমাধানকারী, রেজোলিউশন উপপাদ্য প্রমাণ করছে |
| ডিসজংক্টিভ নরমাল ফর্ম (DNF) | AND এর OR: (A∧B) ∨ (C∧D) | সার্কিট ডিজাইন, নিয়ম ভিত্তিক সিস্টেম |
**CNF-এ রূপান্তর:** ডি মর্গানের আইন প্রয়োগ করুন, ডিস্ট্রিবিউট বা ওভার করুন, দ্বিগুণ নেতিবাচকতা দূর করুন।

## মডুলার পাটিগণিত এবং সামঞ্জস্য
মডুলার গাণিতিক অধ্যয়ন পূর্ণসংখ্যা অপারেশন অধীনে "বিভাগের পরে অবশিষ্ট।" এটি ক্রিপ্টোগ্রাফি, হ্যাশিং এবং সংখ্যা তত্ত্বের জন্য অপরিহার্য।
### মূল সংজ্ঞা
| ধারণা | স্বরলিপি | সংজ্ঞা |
|---------|----------|------------|
| সঙ্গতি | a ≡ b (mod n) | n ভাগ করে (a − b) |
| অবশিষ্ট শ্রেণী | [a]ₙ | সেট {a + kn : k ∈ ℤ} |
| মডুলার বিপরীত | a⁻¹ মোড n | মান x যেমন ax ≡ 1 (mod n) |
| অয়লারের টোটেন্ট | φ(n) | {1,...,n} কপ্রিম থেকে n | এ পূর্ণসংখ্যার সংখ্যা
### মূল বৈশিষ্ট্য
| সম্পত্তি | বিবৃতি |
|------------|----------|
| সংযোজন | যদি a ≡ b এবং c ≡ d (mod n), তাহলে a+c ≡ b+d (mod n) |
| গুণ | যদি a ≡ b এবং c ≡ d (mod n), তাহলে ac ≡ bd (mod n) |
| Fermat এর ছোট উপপাদ্য | যদি p প্রাইম হয় এবং gcd(a,p) = 1, তাহলে aᵖ⁻¹ ≡ 1 (mod p) |
| অয়লারের উপপাদ্য | যদি gcd(a,n) = 1, তাহলে a^φ(n) ≡ 1 (mod n) |
| চীনা অবশিষ্ট উপপাদ্য | gcd(m,n) = 1 হলে, সিস্টেম x ≡ a (mod m), x ≡ b (mod n) একটি অনন্য সমাধান mod mn |
### কম্পিউটিং অয়লার'স টোটিয়েন্ট
n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ (প্রাইম ফ্যাক্টরাইজেশন):
φ(n) = n · (1 − 1/p₁) · (1 − 1/p₂) · ... · (1 − 1/pₖ)
**উদাহরণ:** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4. প্রকৃতপক্ষে, {1, 5, 7, 11} হল 12-এর সমপরিমাণ।
### অ্যাপ্লিকেশন: RSA ক্রিপ্টোগ্রাফি (ওভারভিউ)
1. বড় প্রাইম নির্বাচন করুন p, q। গণনা n = pq, φ(n) = (p−1)(q−1)।
2. e বেছে নিন যেমন gcd(e, φ(n)) = 1 (পাবলিক এক্সপোনেন্ট)।
3. গণনা করুন d ≡ e⁻¹ (mod φ(n)) (ব্যক্তিগত সূচক)।
4. এনক্রিপ্ট: c = mᵉ mod n. ডিক্রিপ্ট: m = cᵈ mod n.
5. নিরাপত্তা p এবং q খুঁজে বের করতে n ফ্যাক্টরিংয়ের অসুবিধার উপর নির্ভর করে।

## গাণিতিক আবেশ
**গাণিতিক আবেশ** হল সমস্ত প্রাকৃতিক সংখ্যার বিবৃতির প্রাথমিক প্রমাণ কৌশল।
### আনয়ন দ্বারা একটি প্রমাণের কাঠামো
1. **বেস কেস:** n = 0 (বা n = 1) এর বিবৃতিটি প্রমাণ করুন।
2. **ইন্ডাকটিভ স্টেপ:** ধরে নিন স্টেটমেন্টটি n = k (ইনডাকটিভ হাইপোথিসিস) এর জন্য, তারপর n = k + 1 এর জন্য এটি প্রমাণ করুন।
### বৈকল্পিক
| বৈকল্পিক | কখন ব্যবহার করবেন |
|---------|---------------|
| সরল আবেশ | প্রমাণ করুন P(k) → P(k+1) |
| শক্তিশালী আনয়ন | P(k+1) | প্রমাণ করতে P(0), P(1), ..., P(k) ধরুন
| স্ট্রাকচারাল আনয়ন | পুনরাবৃত্তিমূলকভাবে সংজ্ঞায়িত কাঠামোর বৈশিষ্ট্যগুলি প্রমাণ করুন (গাছ, সূত্র) |
| ট্রান্সফিনিট আনয়ন | ℕ | এর বাইরে সুশৃঙ্খল সেটগুলিতে আনয়ন প্রসারিত করুন
**ওয়ার্কড উদাহরণ (স্ট্রং ইন্ডাকশন):** প্রমাণ করুন প্রতিটি পূর্ণসংখ্যা n ≥ 2 কে মৌলিক সংখ্যার গুণফল হিসাবে লেখা যেতে পারে।
- বেস: n = 2 প্রাইম, তাই এটি প্রাইমগুলির একটি গুণফল (নিজেই)।
- প্রবর্তক ধাপ: 2 থেকে k পর্যন্ত সমস্ত পূর্ণসংখ্যার জন্য সত্য ধরে নিন। k+1 বিবেচনা করুন।
  - যদি k+1 প্রাইম হয়, সম্পন্ন হয়।
  - k+1 যৌগিক হলে, k+1 = ab যেখানে 2 ≤ a, b ≤ k। ইন্ডাকটিভ হাইপোথিসিস দ্বারা, a এবং b উভয়ই প্রাইমগুলির গুণফল, তাই k+1 হল মৌলিকগুলির একটি গুণফল।
