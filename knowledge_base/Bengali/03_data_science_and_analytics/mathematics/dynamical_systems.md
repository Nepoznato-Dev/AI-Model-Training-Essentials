# ডাইনামিক্যাল সিস্টেম
একটি **গতিশীল সিস্টেম** বর্ণনা করে কিভাবে একটি রাষ্ট্র একটি নির্দিষ্ট নিয়ম অনুযায়ী সময়ের সাথে বিকশিত হয়। গ্রহের কক্ষপথ থেকে জনসংখ্যার গতিবিদ্যা, আবহাওয়ার ধরণ থেকে শুরু করে নিউরাল নেটওয়ার্ক প্রশিক্ষণ পর্যন্ত, গতিশীল সিস্টেম তত্ত্ব জিনিসগুলি কীভাবে পরিবর্তিত হয় তা বোঝার জন্য ভাষা এবং সরঞ্জাম সরবরাহ করে। এই ফাইলটি সাধারণ ডিফারেনশিয়াল সমীকরণ (ODEs), আংশিক ডিফারেনশিয়াল সমীকরণ (PDEs), স্থিতিশীলতা বিশ্লেষণ, বিশৃঙ্খলা এবং দ্বিখণ্ডনগুলিকে কভার করে।

## সাধারণ ডিফারেন্সিয়াল ইকুয়েশন (ODEs)
একটি ODE একটি ফাংশনকে তার ডেরিভেটিভের সাথে একটি একক স্বাধীন পরিবর্তনশীল (সাধারণত সময়) সম্পর্কিত করে।
### শ্রেণীবিভাগ
| সম্পত্তি | প্রকার |
|----------|---------|
| **অর্ডার** | সর্বোচ্চ ডেরিভেটিভ বর্তমান (1ম ক্রম, 2য় ক্রম, ইত্যাদি) |
| **লিনিয়ার বনাম অরৈখিক** | লিনিয়ার: y'' + p(t)y' + q(t)y = g(t); অরৈখিক: অন্য কিছু |
| **একজাত** | g(t) = 0 (কোনও বাধ্যতামূলক শব্দ) |
| **স্বায়ত্তশাসিত** | কোন সুস্পষ্ট সময় নির্ভরতা নেই: dy/dt = f(y) |
| **ধ্রুবক সহগ** | p, q ধ্রুবক |
### প্রথম ক্রম ODE
**সাধারণ ফর্ম:** dy/dt = f(t, y)
| প্রকার | ফর্ম | সমাধান পদ্ধতি |
|------|------|-----------------|
| বিভাজ্য | dy/dt = g(t)h(y) | পৃথক এবং একত্রিত করুন: ∫dy/h(y) = ∫g(t)dt |
| লিনিয়ার ফার্স্ট অর্ডার | dy/dt + p(t)y = q(t) | ইন্টিগ্রেটিং ফ্যাক্টর: μ(t) = e^(∫p dt) |
| সঠিক | M(t,y)dt + N(t,y)dy = 0 এর সাথে ∂M/∂y = ∂N/∂t | সম্ভাব্য ফাংশন খুঁজুন F(t,y) |
| বার্নৌলি | dy/dt + p(t)y = q(t)yⁿ | রৈখিক করার জন্য v = y^(1−n) প্রতিস্থাপন করুন |
**কাজ করা উদাহরণ (একীকরণ ফ্যাক্টর):** dy/dt + 2y = e^(−t), y(0) = 1 সমাধান করুন।
- ইন্টিগ্রেটিং ফ্যাক্টর: μ(t) = e^(∫2 dt) = e^(2t)
- গুন করুন: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- ইন্টিগ্রেট: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- প্রাথমিক অবস্থা: y(0) = 1 → 1 = 1 + C → C = 0
- সমাধান: y(t) = e^(−t)
### সেকেন্ড-অর্ডার লিনিয়ার ODE
**সাধারণ রূপ:** ay'' + by' + cy = g(t)
**সমজাতীয় কেস** (g ​​= 0): চরিত্রগত সমীকরণ ar² + br + c = 0 সমাধান করুন।
| বৈষম্যমূলক | শিকড় | সাধারণ সমাধান |
|---------------|---------|-------|
| b² > 4ac (ওভারড্যাম্পড) | দুটি স্বতন্ত্র বাস্তব r₁, r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (সমালোচনামূলকভাবে স্যাঁতসেঁতে) | বারবার বাস্তব মূল r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (আন্ডারড্যাম্পড) | জটিল শিকড় α ± βi | y = e^(αt)(C₁ cos βt + C₂ sin βt) |
**ভৌত ব্যাখ্যা:** একটি ভর-স্প্রিং-ড্যাম্পার সিস্টেম mx'' + bx' + kx = 0।
- ওভারড্যাম্পড: ভারী স্যাঁতসেঁতে, কোন দোলন নেই (দরজা কাছাকাছি)
- সমালোচনামূলকভাবে স্যাঁতসেঁতে: দোলন ছাড়াই দ্রুততম রিটার্ন (গাড়ি সাসপেনশন ডিজাইন লক্ষ্য)
- আন্ডারড্যাম্পড: ক্ষয়িষ্ণু প্রশস্ততার সাথে দোদুল্যমান (গিটার স্ট্রিং)
### ODE-এর সিস্টেম
অনেক বাস্তব সিস্টেম একাধিক ইন্টারেক্টিং ভেরিয়েবল জড়িত:
dx/dt = f(x, y)
dy/dt = g(x, y)
এটি ভেক্টর আকারে লেখা যেতে পারে: d**x**/dt = **F**(**x**)
**লিনিয়ার সিস্টেম:** d**x**/dt = A**x**, যেখানে A একটি ম্যাট্রিক্স।
সমাধান A এর eigenvalues ​​এর উপর নির্ভর করে:
| Eigenvalues ​​| আচরণ |
|---------------|------------|
| উভয় বাস্তব, নেতিবাচক | স্থিতিশীল নোড (সমস্ত ট্র্যাজেক্টরি মূলে একত্রিত হয়) |
| উভয় বাস্তব, ইতিবাচক | অস্থির নোড |
| বাস্তব, বিপরীত লক্ষণ | স্যাডল পয়েন্ট (অস্থির) |
| জটিল, নেতিবাচক বাস্তব অংশ | স্থিতিশীল সর্পিল (স্যাঁতসেঁতে দোলন) |
| জটিল, ইতিবাচক বাস্তব অংশ | অস্থির সর্পিল |
| বিশুদ্ধ কাল্পনিক | কেন্দ্র (বন্ধ কক্ষপথ) |

## ফেজ পোর্ট্রেট
একটি **ফেজ পোর্ট্রেট** স্টেট স্পেসে (স্পষ্টভাবে সমাধান না করে) একটি গতিশীল সিস্টেমের ট্র্যাজেক্টোরিগুলিকে কল্পনা করে।
### মূল বৈশিষ্ট্য
| বৈশিষ্ট্য | বর্ণনা |
|---------|---------------|
| **স্থির বিন্দু (ভারসাম্য)** | যেখানে dx/dt = 0 (কোন গতি নেই) |
| **পথ** | রাষ্ট্রীয় স্থানে সিস্টেম দ্বারা চিহ্নিত পথ |
| **নালক্লাইন** | বক্ররেখা যেখানে একটি উপাদানের ডেরিভেটিভ শূন্য |
| **সীমা চক্র** | বিচ্ছিন্ন বন্ধ কক্ষপথ (স্ব-টেকসই দোলন) |
| **আকর্ষণ বেসিন** | প্রদত্ত আকর্ষণকারীর দিকে অগ্রসর হওয়া প্রাথমিক অবস্থার সেট |
| **সেপারাট্রিক্স** | আকর্ষণের বিভিন্ন অববাহিকার মধ্যে সীমানা |
### শিকারী-শিকারের মডেল (লোটকা-ভোল্টেরা)
dx/dt = αx − βxy (শিকার)
dy/dt = δxy − γy (শিকারী)
**নির্দিষ্ট পয়েন্ট:**
1. (0, 0) - বিলুপ্তি (স্যাডল পয়েন্ট)
2. (γ/δ, α/β) — সহাবস্থান (কেন্দ্র — বন্ধ কক্ষপথ)
সিস্টেমটি পর্যায়ক্রমিক দোলন প্রদর্শন করে: শিকার বৃদ্ধি পায় → শিকারী বৃদ্ধি → শিকার হ্রাস → শিকারী হ্রাস → চক্র পুনরাবৃত্তি।

## স্থিতিশীলতা বিশ্লেষণ
### রৈখিক স্থিতিশীলতা
একটি নির্দিষ্ট বিন্দু x* এর জন্য, এটির চারপাশে রৈখিক করুন: u = x − x*, তারপর du/dt ≈ J(x*)u যেখানে J হল জ্যাকোবিয়ান ম্যাট্রিক্স।
**স্থায়িত্বের মানদণ্ড:** নির্দিষ্ট পয়েন্ট হল:
- **স্থিতিশীল** যদি J-এর সমস্ত eigenvalue-এর ঋণাত্মক বাস্তব অংশ থাকে
- **অস্থির** যদি কোনো eigenvalue-এর ইতিবাচক বাস্তব অংশ থাকে
- **প্রান্তিকভাবে স্থিতিশীল** যদি eigenvalues শূন্য বাস্তব অংশ থাকে (অরৈখিক বিশ্লেষণ প্রয়োজন)
### লিয়াপুনভ স্থিতিশীলতা
**লিয়াপুনভের সরাসরি পদ্ধতি** রৈখিককরণ ছাড়াই স্থিতিশীলতা নির্ধারণ করে।
A **Lyapunov ফাংশন** V(x) সন্তুষ্ট করে:
1. V(x*) = 0 এবং V(x) > 0 এর জন্য x ≠ x* (ধনাত্মক নির্দিষ্ট)
2. dV/dt ≤ 0 ট্রাজেক্টোরি বরাবর (অ-বর্ধিত)
| শর্ত | উপসংহার |
|------------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | অস্থির |
**কাজ করা উদাহরণ:** সিস্টেম dx/dt = −x + y², dy/dt = −y।
- V(x,y) = x² + y² (শক্তির মতো ফাংশন) চেষ্টা করুন
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² −2y²
- উৎসের কাছাকাছি: dV/dt ≈ −2x² − 2y² < 0 (ছোট y-এর জন্য, −2y² প্রাধান্য পায়)
- উপসংহার: উত্স স্থানীয়ভাবে অ্যাসিম্পটোটিকভাবে স্থিতিশীল

## বিশৃঙ্খলা তত্ত্ব
**বিশৃঙ্খলা** নির্ধারক কিন্তু অপ্রত্যাশিত: সিস্টেমটি সঠিক নিয়ম অনুসরণ করে, কিন্তু প্রাথমিক অবস্থার ক্ষুদ্র পার্থক্য ব্যাপকভাবে ভিন্ন ফলাফলের দিকে নিয়ে যায়।
### বিশৃঙ্খলার জন্য প্রয়োজনীয়তা
| সম্পত্তি | বর্ণনা |
|------------|-------------|
| ডিটারমিনিস্টিক | কোন এলোমেলোতা নেই — সঠিক সমীকরণ দ্বারা নিয়ন্ত্রিত |
| প্রাথমিক অবস্থার প্রতি সংবেদনশীল | কাছাকাছি ট্র্যাজেক্টোরিগুলি দ্রুতগতিতে বিচ্ছিন্ন হয় |
| আবদ্ধ | ট্র্যাজেক্টোরিজ অনন্তে পালাতে পারে না |
| অ-পর্যায়ক্রমিক | কখনই ঠিক পুনরাবৃত্তি করবেন না |
### লরেঞ্জ সিস্টেম
নির্ধারক বিশৃঙ্খলার ক্লাসিক উদাহরণ:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
স্ট্যান্ডার্ড প্যারামিটার সহ σ = 10, ρ = 28, β = 8/3:
- সিস্টেমের তিনটি নির্দিষ্ট পয়েন্ট আছে, সব অস্থির
- ট্রাজেক্টরিগুলি একটি নির্দিষ্ট বিন্দুকে প্রদক্ষিণ করে, তারপর হঠাৎ করে অন্যটিতে চলে যায়
- ফলাফল হল **লরেঞ্জ আকর্ষক** — ফ্র্যাক্টাল গঠন সহ একটি অদ্ভুত আকর্ষণকারী
**লিয়াপুনভ সূচক:** কাছাকাছি গতিপথের বিচ্যুতির হার পরিমাপ করে।
- পজিটিভ লায়াপুনভ সূচক → বিশৃঙ্খলা
- স্ট্যান্ডার্ড প্যারামিটার সহ লরেঞ্জ সিস্টেমের জন্য: বৃহত্তম সূচক ≈ 0.9 > 0
### লজিস্টিক ম্যাপ
একটি সাধারণ বিচ্ছিন্ন সিস্টেম যা বিশৃঙ্খলা প্রদর্শন করে:
x_{n+1} = rx_n(1 − x_n)
| প্যারামিটার r | আচরণ |
|---------------|------------|
| 0 < r < 1 | জনসংখ্যা শেষ হয়ে যায় (x → 0) |
| 1 < r < 3 | x = 1 − 1/r | এ স্থির স্থির বিন্দু
| 3 < r < 3.449 | পিরিয়ড-2 দোলন |
| 3.449 < r < 3.544 | সময়কাল-4 দোলন |
| 3.544 < r < 3.570 | পিরিয়ড-৮, ১৬, ৩২, ... (পিরিয়ড-ডবলিং ক্যাসকেড) |
| r ≈ 3.570 | বিশৃঙ্খলার সূত্রপাত |
| 3.570 < r < 4 | বেশিরভাগই বিশৃঙ্খল, পর্যায়ক্রমিক জানালা সহ |
| r = 4 | [0, 1]-এ সম্পূর্ণ বিশৃঙ্খল |
### বাটারফ্লাই এফেক্ট
প্রাথমিক অবস্থার উপর সংবেদনশীল নির্ভরতার জনপ্রিয় নাম। আবহাওয়া ব্যবস্থায় (লরেঞ্জ সমীকরণ দ্বারা মডেল করা হয়েছে), ব্রাজিলে একটি প্রজাপতি তার ডানা ঝাপটায় টেক্সাসে একটি টর্নেডো শুরু করতে পারে - প্রজাপতি এটির কারণ নয়, বরং ছোট ছোট গোলযোগগুলি দ্রুত বৃদ্ধির কারণে।

## বিভাজন তত্ত্ব
একটি **বিভাজন** হল সিস্টেমের আচরণে একটি গুণগত পরিবর্তন কারণ একটি প্যারামিটার বৈচিত্র্যময়।
### বিভাজনের প্রকারভেদ
| বিভাজন | সাধারণ ফর্ম | কি হয় |
|---------------|---------------|---------------|
| **স্যাডল-নোড** | dx/dt = r − x² | দুটি স্থির বিন্দু উপস্থিত/অদৃশ্য হয়ে যায় |
| **ট্রান্সক্রিটিকাল** | dx/dt = rx − x² | দুটি নির্দিষ্ট পয়েন্ট বিনিময় স্থিতিশীলতা |
| **পিচফর্ক (সুপারক্রিটিকাল)** | dx/dt = rx − x³ | একটি স্থিতিশীল বিন্দু বিভক্ত হয়ে দুটি স্থিতিশীল + একটি অস্থির |
| **পিচফর্ক (সাবক্রিটিক্যাল)** | dx/dt = rx + x³ | অস্থির শাখা পতন (প্রায়ই বিপর্যয়কর) |
| **হপফ** | 2D সিস্টেম | স্থির বিন্দু অস্থির হয়ে ওঠে, সীমা চক্র উপস্থিত হয় |
### বিভাজন চিত্র
নির্দিষ্ট পয়েন্ট বনাম প্যারামিটার মান, স্থিতিশীলতা দেখানোর একটি প্লট (কঠিন = স্থিতিশীল, ড্যাশড = অস্থির)। লজিস্টিক মানচিত্রের বিভাজন চিত্রটি বিশৃঙ্খলার সময়কাল-দ্বিগুণ হওয়ার পথ এবং বিখ্যাত **ফিজেনবাউম ধ্রুবক** δ ≈ 4.669 (পরবর্তী বিভাজন ব্যবধানের মধ্যে সর্বজনীন অনুপাত) প্রকাশ করে।

## আংশিক পার্থক্য সমীকরণ (PDEs)
PDEs একাধিক ভেরিয়েবল এবং তাদের আংশিক ডেরিভেটিভের ফাংশন জড়িত।
### সেকেন্ড-অর্ডার লিনিয়ার PDE-এর শ্রেণীবিভাগ
Au_xx + 2Bu_xy + Cu_yy + ... = 0 এর জন্য:
| প্রকার | শর্ত | আচরণ | উদাহরণ |
|------|------------|------------|---------|
| **অধিবৃত্ত** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | তরঙ্গ প্রচার, ধারালো বৈশিষ্ট্য সংরক্ষণ করে | তরঙ্গ সমীকরণ: u_tt = c²u_xx |
### তাপ সমীকরণ
∂u/∂t = α ∂²u/∂x²
মডেল তাপ বিস্তার, জনসংখ্যার বিস্তার, বিকল্প মূল্য (ব্ল্যাক-স্কোলস)।
| সম্পত্তি | বিবৃতি |
|------------|------------|
| মসৃণ | সমাধানগুলি অবিলম্বে মসৃণ হয়ে যায়, এমনকি অবিচ্ছিন্ন প্রাথমিক ডেটা থেকেও |
| সর্বোচ্চ নীতি | সর্বোচ্চ তাপমাত্রা সীমানা বা প্রাথমিক সময়ে ঘটে |
| টাইম-রিভার্সিবিলিটি | অপরিবর্তনীয় — পিছনে দৌড়াতে পারে না |
### তরঙ্গ সমীকরণ
∂²u/∂t² = c² ∂²u/∂x²
মডেল কম্পন স্ট্রিং, শব্দ, ইলেক্ট্রোম্যাগনেটিক তরঙ্গ.
| সম্পত্তি | বিবৃতি |
|------------|------------|
| প্রচার | বিঘ্নিত গতিতে ভ্রমণ গ |
| প্রত্যাবর্তনযোগ্যতা | সময়-উল্টানো যায় |
| d'Alembert সমাধান | u(x,t) = f(x−ct) + g(x+ct) (বাম/ডান তরঙ্গের সুপারপজিশন) |
### ল্যাপ্লেসের সমীকরণ
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
সমাধান (হারমোনিক ফাংশন) স্থির-স্থিতি তাপমাত্রা, ইলেক্ট্রোস্ট্যাটিক সম্ভাবনা, অসংকোচনীয় তরল প্রবাহ উপস্থাপন করে।
| সম্পত্তি | বিবৃতি |
|------------|------------|
| গড় মান সম্পত্তি | u(x₀) = x₀ | কেন্দ্রিক যেকোনো বৃত্তের উপর u-এর গড়
| সর্বোচ্চ নীতি | কোন অভ্যন্তর ম্যাক্সিমা বা মিনিমা |
| স্বতন্ত্রতা | সম্পূর্ণরূপে সীমানা শর্ত দ্বারা নির্ধারিত |

## মেশিন লার্নিং এবং ডেটা সায়েন্সের প্রাসঙ্গিকতা
| ডিএস ধারণা | আবেদন |
|------------|-------------|
| ODEs | নিউরাল ODEs (একটানা-গভীর নেটওয়ার্ক), পুনরাবৃত্ত নেটওয়ার্ক গতিবিদ্যা |
| স্থিতিশীলতা বিশ্লেষণ | গ্রেডিয়েন্ট ডিসেন্টের প্রশিক্ষণ গতিবিদ্যা (ক্ষতি কি স্থিরভাবে কমছে?) |
| লায়াপুনভ ফাংশন | শেখার অ্যালগরিদম, শক্তিবৃদ্ধি শেখার স্থায়িত্বের একত্রীকরণ প্রমাণ করা
| বিশৃঙ্খলা | RNN-এ সংবেদনশীলতা বোঝা (বিলুপ্ত/বিস্ফোরিত গ্রেডিয়েন্ট), আবহাওয়ার পূর্বাভাস |
| বিভাজন | শেখার পর্যায়ে রূপান্তর (গ্রোকিং), প্রশিক্ষণের গতিবিদ্যায় শাসন পরিবর্তন |
| PDEs | ডিফিউশন মডেল (স্কোর-ভিত্তিক জেনারেটিভ মডেল), পদার্থবিদ্যা-তথ্যযুক্ত নিউরাল নেটওয়ার্ক |
| তাপ সমীকরণ | জেনারেটিভ মডেলিং-এ ডিফিউশন প্রসেস, গ্রাফ ল্যাপ্লাসিয়ান স্মুথিং |
| তরঙ্গ সমীকরণ | সিসমিক ডেটা প্রসেসিং, অডিও সিগন্যাল মডেলিং |
| Lotka-Volterra | জনসংখ্যার গতিবিদ্যা, মহামারীবিদ্যা, প্রতিযোগী এমএল এজেন্ট |
| ফেজ পোর্ট্রেট | লস ল্যান্ডস্কেপ গতিবিদ্যা ভিজ্যুয়ালাইজ করা, GAN প্রশিক্ষণ বোঝা |

## সারাংশ
| বিষয় | মূল ধারণা | কী টুল |
|---------|------------|----------|
| ODEs | ফাংশন এবং তাদের সময় ডেরিভেটিভ | চারিত্রিক সমীকরণ, একীভূতকরণ কারণ |
| ODEs এর সিস্টেম | একাধিক ইন্টারঅ্যাকটিং ভেরিয়েবল | জ্যাকোবিয়ানের আইজেনভ্যালু বিশ্লেষণ |
| ফেজ পোর্ট্রেট | রাষ্ট্রীয় স্থানের গতিবিদ্যা ভিজ্যুয়ালাইজ করা | স্থির বিন্দু, নালক্লাইন, সীমা চক্র |
| স্থিতিশীলতা | সিস্টেম কি ভারসাম্য ফিরে আসবে? | লিনিয়ারাইজেশন, লাইপুনভ ফাংশন |
| বিশৃঙ্খলা | ডিটারমিনিস্টিক আনপ্রেডিক্টিবিলিটি | Lyapunov সূচক, অদ্ভুত আকর্ষণকারী |
| বিভাজন | পরামিতি সহ গুণগত পরিবর্তন | সাধারণ ফর্ম, বিভাজন চিত্র |
| PDEs | একাধিক ভেরিয়েবলের কাজ | তাপ, তরঙ্গ এবং ল্যাপ্লেস সমীকরণ |
গতিশীল সিস্টেম তত্ত্ব হল পরিবর্তনের গণিত। এটি ব্যাখ্যা করে কেন কিছু সিস্টেম স্থির হয়, কেন কিছু দোদুল্যমান হয় এবং কেন কিছু বিশৃঙ্খল আচরণ করে। ডেটা সায়েন্টিস্টদের জন্য, এটি প্রশিক্ষণের গতিবিদ্যা বোঝা, স্থিতিশীল অ্যালগরিদম ডিজাইন করা, মডেলিং টাইম সিরিজ এবং পরবর্তী প্রজন্মের পদার্থবিদ্যা-অবহিত মেশিন লার্নিং মডেল তৈরি করার জন্য সরঞ্জাম সরবরাহ করে।
