# ডেটা বিজ্ঞান এবং বিশ্লেষণ
ডেটা সায়েন্স হল কাঁচা ডেটাকে কার্যকরী অন্তর্দৃষ্টিতে পরিণত করার শৃঙ্খলা। এটি পরিসংখ্যান, কম্পিউটার বিজ্ঞান এবং ডোমেন দক্ষতার সংযোগস্থলে বসে - এবং এটি অর্থ থেকে স্বাস্থ্যসেবা পর্যন্ত প্রতিটি সেক্টরে অপরিহার্য হয়ে উঠেছে। এই ফাইলটি মূল ধারণা, সরঞ্জাম এবং কর্মপ্রবাহের মধ্য দিয়ে চলে যা প্রতিটি অনুশীলনকারীর জানা উচিত।
---

## তথ্য বিজ্ঞান প্রক্রিয়া
বেশিরভাগ প্রকল্প **CRISP-DM**, শিল্প-মান জীবনচক্রের কিছু পরিবর্তন অনুসরণ করে:
| পর্যায় | কি হয় | সাধারণ সময় |
|---------|---------------|---------------|
| **ব্যবসায়িক বোঝাপড়া** | উদ্দেশ্য, সাফল্যের পরিমাপ এবং সীমাবদ্ধতা সংজ্ঞায়িত করুন | 10-15% |
| **ডেটা বোঝার** | ডেটা সংগ্রহ করুন, অন্বেষণ করুন এবং প্রোফাইল করুন | 10-15% |
| **ডেটা প্রস্তুতি** | পরিষ্কার, রূপান্তর, প্রকৌশলী বৈশিষ্ট্য | ~50–60% |
| **মডেলিং** | মডেল নির্বাচন এবং প্রশিক্ষণ | 10-15% |
| **মূল্যায়ন** | ব্যবসায়িক লক্ষ্যের বিরুদ্ধে কর্মক্ষমতা মূল্যায়ন করুন | 5-10% |
| **নিয়োগ** | উৎপাদনে মডেল পাঠান | 5-10% |
ডেটা প্রস্তুতি, বিশেষ করে ডেটা পরিষ্কার করা, একজন ডেটা বিজ্ঞানীর সময়ের প্রায় 80% খরচ করে বলে অনুমান করা হয়।

## পরিসংখ্যানের মৌলিক বিষয়
### বর্ণনামূলক বনাম অনুমানমূলক পরিসংখ্যান
বর্ণনামূলক পরিসংখ্যান আপনার *কি আছে* তা সংক্ষিপ্ত করে; আনুমানিক পরিসংখ্যান আপনাকে আপনার *না* আছে (বৃহত্তর জনসংখ্যা) সম্পর্কে সিদ্ধান্ত নিতে দেয়।
| ধারণা | মূল ধারণা |
|---------|------------|
| **কেন্দ্রীয় প্রবণতা** | গড় (বহিরাগতদের প্রতি সংবেদনশীল), মধ্যমা (শক্তিশালী), মোড (সবচেয়ে ঘন ঘন) |
| **বিচ্ছুরণ** | ব্যাপ্তি, প্রকরণ, প্রমিত বিচ্যুতি, আন্তঃবৃত্তীয় পরিসর |
| **বন্টন আকৃতি** | তির্যকতা (অসমতা), কুরটোসিস (লেজ ভারী হওয়া) |
| **হাইপোথিসিস টেস্টিং** | শূন্য বনাম বিকল্প অনুমান, পি-মান, তাৎপর্য স্তর (α) |
| **আস্থার ব্যবধান** | প্রকৃত জনসংখ্যার পরামিতি ধারণ করা পরিসীমা |
| **টাইপ I / টাইপ II ত্রুটি** | মিথ্যা ইতিবাচক (একটি সত্য নাল প্রত্যাখ্যান) / মিথ্যা নেতিবাচক (একটি বাস্তব প্রভাব অনুপস্থিত) |
### সাধারণ পরিসংখ্যান পরীক্ষা
| পরীক্ষা | কখন ব্যবহার করবেন |

| **চি-স্কয়ার** | শ্রেণীগত ভেরিয়েবলের স্বাধীনতা পরীক্ষা করুন |
| **মান-হুইটনি ইউ** | টি-টেস্টের অ-প্যারামেট্রিক বিকল্প (কোন স্বাভাবিকতা অনুমান নেই) |

| **স্পিয়ারম্যান পারস্পরিক সম্পর্ক** | একঘেয়ে সম্পর্ক (র্যাঙ্ক-ভিত্তিক, আরও শক্তিশালী) |
### সম্ভাব্যতা ডিস্ট্রিবিউশন জানার মতো
| বিতরণ | কেস ব্যবহার করুন |

| **দ্বিপদ** | সাফল্য/ব্যর্থতার গণনা (মুদ্রা উল্টানো, রূপান্তর হার) |
| **বিষ** | একটি নির্দিষ্ট ব্যবধানে ইভেন্ট গণনা (প্রতি ঘণ্টায় কল, প্রতি ব্যাচের ত্রুটি) |
| **সূচক** | ইভেন্টের মধ্যে সময় (অপেক্ষার সময়, ব্যর্থতার ব্যবধান) |
| **টি-বন্টন** | ছোট নমুনা বা অজানা জনসংখ্যা বৈচিত্র |
| **চি-স্কয়ার** | ক্যাটাগরিকাল ডাটা অ্যানালাইসিস, ফিট-অফ-ফিট টেস্ট |

## ডেটা সংগ্রহ এবং স্টোরেজ
### ডেটা কোথা থেকে আসে
রিলেশনাল ডাটাবেস, API (REST, GraphQL), ফ্ল্যাট ফাইল (CSV, JSON, Parquet), স্ট্রিমিং প্ল্যাটফর্ম (Kafka, Kinesis), সার্ভে এবং পাবলিক রিপোজিটরি (Kaggle, সরকারি পোর্টাল) থেকে বাস্তব-বিশ্বের ডেটা আসে। আপনি যে বিন্যাসটি পান তা আপনার প্রি-প্রসেসিং কৌশল নির্ধারণ করে।
### ডেটা গুদামজাতকরণ ধারণা
| ধারণা | বর্ণনা |
|---------|---------------|
| **ETL** | নিষ্কাশন → রূপান্তর → লোড — ঐতিহ্যগত পাইপলাইন পদ্ধতি |
| **ইএলটি** | এক্সট্রাক্ট → লোড → ট্রান্সফর্ম — আধুনিক ক্লাউড অ্যাপ্রোচ (লোড র, ট্রান্সফর্ম ইন-ওয়্যারহাউস) |
| **ডাটা লেক** | নেটিভ ফরম্যাটে সংরক্ষিত কাঁচা ডেটা (স্কিমা-অন-রিড) |
| **ডেটা গুদাম** | স্ট্রাকচার্ড, প্রসেসড ডেটা বিশ্লেষণের জন্য অপ্টিমাইজ করা হয়েছে (স্কিমা-অন-রাইট) |
| **ডেটা মার্ট** | একটি গুদামের একটি উপসেট, একটি বিভাগ বা ডোমেনে ব্যাপ্ত |
| **স্টার স্কিমা** | সেন্ট্রাল ফ্যাক্ট টেবিল ডাইমেনশন টেবিল দ্বারা বেষ্টিত |
| **স্নোফ্লেক স্কিমা** | সাধারণ আকারের টেবিল (কম অপ্রয়োজনীয়তা, আরও যোগদান) |
### ডাটাবেস প্রকার
| প্রকার | উদাহরণ | জন্য সেরা |
|------|------------|----------|
| **রিলেশনাল (SQL)** | PostgreSQL, MySQL, Oracle | স্ট্রাকচার্ড ডেটা, ACID লেনদেন |
| **নথি** | MongoDB, CouchDB | নমনীয় স্কিমা, JSON-এর মতো ডেটা |
| **মূল-মূল্য** | Redis, DynamoDB | ক্যাশিং, সেশন, সহজ লুকআপ |
| **কলাম-পরিবার** | Cassandra, HBase | লিখুন-ভারী কাজের চাপ, সময় সিরিজ |
| **গ্রাফ** | Neo4j, আমাজন নেপচুন | সম্পর্ক, সামাজিক নেটওয়ার্ক |
| **সময়-সিরিজ** | InfluxDB, TimescaleDB | IoT মেট্রিক্স, পর্যবেক্ষণ |
| **ভেক্টর** | পাইনকোন, মিলভাস | এমএল/এআই অনুসন্ধানের জন্য সঞ্চয়স্থান এম্বেড করা |

## ডেটা প্রিপ্রসেসিং এবং ফিচার ইঞ্জিনিয়ারিং
### ক্লিনিং চেকলিস্ট
প্রতিটি বাস্তব ডেটাসেট সমস্যা আছে. এখানে স্ট্যান্ডার্ড ক্লিনআপ রয়েছে:
| ইস্যু | দৃষ্টিভঙ্গি |
|-------|----------|
| **অনুপস্থিত মান** | ইমপুটেশন (গড়, মধ্যমা, ভবিষ্যদ্বাণী), অথবা বিক্ষিপ্ত হলে মুছে ফেলা |
| **বহিরাগত** | আইকিউআর বা জেড-স্কোরের মাধ্যমে সনাক্ত করুন; ক্যাপিং বা রূপান্তর দিয়ে চিকিত্সা |
| **সদৃশ** | সনাক্ত করুন এবং অপসারণ করুন |
| **অসংগতি** | ফরম্যাট মানান, টাইপ ভুল ঠিক করুন, ইউনিট স্বাভাবিক করুন |
### রূপান্তর কৌশল
| টেকনিক | এটা কি করে |
|------------|-------------|
| **স্বাভাবিককরণ** | মান 0-1 পরিসরে স্কেল করুন |
| **প্রমিতকরণ** | Z-স্কোর: গড় = 0, std = 1 |
| **এক-হট এনকোডিং** | বিভাগগুলিকে বাইনারি কলামে রূপান্তর করে |
| **লেবেল এনকোডিং** | বিভাগগুলিতে পূর্ণসংখ্যা লেবেল বরাদ্দ করে |
| **লগ রূপান্তর** | ডেটাতে ডান-তির্যক হ্রাস করে |
| **বিনিং** | বিচ্ছিন্ন বালতিতে অবিচ্ছিন্ন মানগুলিকে দলবদ্ধ করে |
### ফিচার ইঞ্জিনিয়ারিং
বৈশিষ্ট্য প্রকৌশল প্রায়ই একটি মধ্যম মডেল এবং একটি মহান এক মধ্যে পার্থক্য. মূল কৌশল অন্তর্ভুক্ত:
- **বৈশিষ্ট্য তৈরি**: বিদ্যমান থেকে নতুন কলাম তৈরি করা (যেমন,`age`থেকে `age_group`)।
- **ফিচার নির্বাচন**: ফিল্টার পদ্ধতি (পারস্পরিক সম্পর্ক), মোড়ক পদ্ধতি (পুনরাবৃত্ত নির্মূল), এমবেডেড পদ্ধতি (LASSO, গাছের গুরুত্ব)।
- **মাত্রিকতা হ্রাস**: লিনিয়ারের জন্য PCA, ভিজ্যুয়ালাইজেশনের জন্য t-SNE বা UMAP।
- **মিথস্ক্রিয়া পদ**: যৌথ প্রভাবগুলি ক্যাপচার করতে গুণগতভাবে বৈশিষ্ট্যগুলিকে একত্রিত করা।

## অনুসন্ধানমূলক ডেটা বিশ্লেষণ (EDA)
EDA হল যেখানে আপনি মডেলিং করার আগে আপনার ডেটা সম্পর্কে অন্তর্দৃষ্টি বিকাশ করেন। লক্ষ্য নিদর্শন, অসঙ্গতি, এবং সম্পর্ক চিহ্নিত করা হয়.
### সঠিক চার্ট নির্বাচন করা
| চার্টের ধরন | জন্য সেরা |
|------------|----------|
| **হিস্টোগ্রাম** | একটি একক চলকের বন্টন |
| **বক্স প্লট** | পাঁচ-সংখ্যার সারাংশ, আউটলিয়ার সনাক্তকরণ |
| **স্ক্যাটার প্লট** | দুটি ক্রমাগত চলকের মধ্যে সম্পর্ক |
| **হিটম্যাপ** | পারস্পরিক সম্পর্ক ম্যাট্রিক্স, ঘনত্ব ভিজ্যুয়ালাইজেশন |
| **বার চার্ট** | বিভাগ তুলনা |
| **লাইন চার্ট** | সময়ের সাথে প্রবণতা |
| **বেহালা প্লট** | বন্টন ঘনত্ব + বক্স প্লট সারাংশ |
| **জোড়া প্লট** | সমস্ত পরিবর্তনশীল জোড়ার দ্রুত ওভারভিউ |
### পাইথন ইডিএ স্ট্যাক
| লাইব্রেরি | ভূমিকা |
|---------|------|
| **পান্ডা** | ডেটা ম্যানিপুলেশন এবং বিশ্লেষণ |
| **নম্বি** | সংখ্যাসূচক কম্পিউটিং |
| **matplotlib** | ফাউন্ডেশন প্লটিং |
| **সমুদ্রজাত** | পরিসংখ্যানগত ভিজ্যুয়ালাইজেশন (ম্যাটপ্লটলিবের উপর নির্মিত) |
| **চক্রান্ত** | ইন্টারেক্টিভ, ওয়েব-ভিত্তিক ভিজ্যুয়ালাইজেশন |
| **সিপি** | বৈজ্ঞানিক কম্পিউটিং এবং পরিসংখ্যান |

### ড্যাশবোর্ড ডিজাইনের নীতি
কার্যকর ড্যাশবোর্ডগুলি প্রতিষ্ঠিত নীতিগুলি অনুসরণ করে: শ্রোতাদের সনাক্ত করুন, প্রতিটি মেট্রিকের জন্য উপযুক্ত ভিজ্যুয়ালাইজেশন চয়ন করুন, কৌশলগতভাবে রঙ ব্যবহার করুন (সজ্জাগতভাবে নয়), ধারাবাহিক স্কেল বজায় রাখুন এবং ইন্টারঅ্যাক্টিভিটি (ফিল্টার, ড্রিল-ডাউন) সক্ষম করুন। পারফরম্যান্সও গুরুত্বপূর্ণ — ধীর লোডের সময় সহ ড্যাশবোর্ডগুলি ব্যবহারকারীর গ্রহণ হ্রাস করে৷

| **বিপণন** | রূপান্তর হার, ক্লিক-থ্রু রেট, ROAS, অ্যাট্রিবিউশন |

### পক্ষপাতিত্ব এবং ন্যায্যতা
পক্ষপাত যে কোনো পর্যায়ে প্রবেশ করতে পারে: নমুনা পক্ষপাত (অ-প্রতিনিধিত্বমূলক ডেটা), পরিমাপের পক্ষপাত (ত্রুটিপূর্ণ উপকরণ), বা অ্যালগরিদমিক পক্ষপাত (বৈষম্যমূলক ভবিষ্যদ্বাণী)। প্রশমন কৌশলগুলির মধ্যে রয়েছে প্রি-প্রসেসিং (ডেটা ঠিক করা), ইন-প্রসেসিং (মডেলকে সীমাবদ্ধ করা), এবং পোস্ট-প্রসেসিং (আউটপুট সামঞ্জস্য করা)। জনসংখ্যার সমতা এবং সমান সুযোগের মতো ন্যায্যতা মেট্রিক্স সমস্যাটি পরিমাপ করতে সহায়তা করে।

## উদীয়মান প্রবণতা
- **অটোএমএল**: স্বয়ংক্রিয় পাইপলাইন তৈরি এবং মডেল নির্বাচন।
- **MLOps**: DevOps অনুশীলনগুলি ML লাইফসাইকেল পরিচালনায় প্রয়োগ করা হয়।
- **ফিচার স্টোর**: টিম জুড়ে পুনঃব্যবহারের জন্য কেন্দ্রীভূত বৈশিষ্ট্য ব্যবস্থাপনা।
- **ডেটা মেশ**: বিকেন্দ্রীকৃত, ডোমেনের মালিকানাধীন ডেটা আর্কিটেকচার।
- **LLMs এবং জেনারেটিভ AI**: টেক্সট, কোড এবং ইমেজ ওয়ার্কফ্লোকে রূপান্তরিত করে বড় ভাষা মডেল।
