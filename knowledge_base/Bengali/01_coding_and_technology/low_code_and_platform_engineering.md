# লো-কোড এবং প্ল্যাটফর্ম ইঞ্জিনিয়ারিং
লো-কোড প্ল্যাটফর্মগুলি মানুষকে ন্যূনতম হাতে লেখা কোড দিয়ে অ্যাপ্লিকেশন তৈরি করতে দেয় — সাধারণত ড্র্যাগ-এন্ড-ড্রপ ইন্টারফেস, ভিজ্যুয়াল ওয়ার্কফ্লো এবং পূর্ব-নির্মিত সংযোগকারীর মাধ্যমে। প্ল্যাটফর্ম ইঞ্জিনিয়ারিং হল অভ্যন্তরীণ বিকাশকারী প্ল্যাটফর্ম (IDPs) তৈরি করার শৃঙ্খলা যা পণ্য দলগুলির জন্য স্ব-পরিষেবা পরিকাঠামো, CI/CD এবং অপারেশনাল টুলিংকে সহজ করে তোলে। উভয় প্রবণতা একই সমস্যার প্রতিক্রিয়া: সফ্টওয়্যারের চাহিদা এবং এটি তৈরি করতে পারে এমন বিকাশকারীদের সরবরাহের মধ্যে ব্যবধান।
---

## লো-কোড প্ল্যাটফর্ম
### লো-কোড আসলে কি মানে
| দৃষ্টিভঙ্গি | বর্ণনা |
|---------|-------------|
| **ভিজ্যুয়াল ডেভেলপমেন্ট** | ড্র্যাগ-এন্ড-ড্রপ UI নির্মাতা; ভিজ্যুয়াল ওয়ার্কফ্লো সম্পাদক; ফর্ম ডিজাইনার |
| **প্রি-বিল্ট উপাদান** | রেডিমেড উইজেট, সংযোগকারী, টেমপ্লেট এবং ইন্টিগ্রেশন |
| **ঘোষণামূলক যুক্তি** | কোড লেখার পরিবর্তে নিয়ম ও শর্তের মাধ্যমে আচরণ কনফিগার করুন |
| **সম্প্রসারণযোগ্যতা** | প্ল্যাটফর্মের অন্তর্নির্মিত ক্ষমতা যথেষ্ট না হলে কাস্টম কোড যোগ করার ক্ষমতা |
| **পরিচালিত অবকাঠামো** | প্ল্যাটফর্ম হোস্টিং, স্কেলিং, নিরাপত্তা প্যাচ পরিচালনা করে |

| **সেলসফোর্স প্ল্যাটফর্ম** | CRM-নেটিভ; এক্সটেনশন জন্য শীর্ষ; ফ্লো বিল্ডার | গ্রাহক-মুখী অ্যাপস; বিক্রয় কর্মপ্রবাহ |
| **পরিষেবা এখন** | আইটি সেবা ব্যবস্থাপনা; ওয়ার্কফ্লো অটোমেশন | আইটি অপারেশন; এইচআর; সুবিধা |
| **অ্যাপিয়ান** | প্রক্রিয়া খনির; কেস ম্যানেজমেন্ট | জটিল ব্যবসায়িক প্রক্রিয়া; সম্মতি |
| **আউটসিস্টেম** | ফুল-স্ট্যাক ওয়েব এবং মোবাইল; এন্টারপ্রাইজ-গ্রেড | গ্রাহক পোর্টাল; মোবাইল অ্যাপস |
| **রিটুল** | অভ্যন্তরীণ টুল নির্মাতা; ডাটাবেস এবং API এর সাথে সংযোগ করে | অ্যাডমিন প্যানেল; ড্যাশবোর্ড; অপস টুলস |
| **এয়ারটেবল** | স্প্রেডশীট-ডাটাবেস হাইব্রিড; অটোমেশন | প্রকল্প ট্র্যাকিং; লাইটওয়েট CRM |
### যখন লো-কোড ভাল কাজ করে
| দৃশ্যকল্প | কেন লো-কোড ফিট করে |
|------------|---------|
| **অভ্যন্তরীণ সরঞ্জাম** | নির্মাণ দ্রুত; ব্যবহারকারীরা অভ্যন্তরীণ তাই UI নমনীয়তা কম গুরুত্বপূর্ণ |
| **ফর্ম এবং অনুমোদন** | ভিজ্যুয়াল ওয়ার্কফ্লো নির্মাতারা এতে এক্সেল |
| **CRUD অ্যাপ্লিকেশন** | বেশিরভাগ কম-কোড প্ল্যাটফর্মগুলি তৈরি-পড়া-আপডেট-মুছে ফেলার নিদর্শনগুলির জন্য অপ্টিমাইজ করা হয়েছে |
| **প্রোটোটাইপিং** | সপ্তাহের পরিবর্তে ঘন্টার মধ্যে একটি ধারণা যাচাই করুন |
| **নাগরিক উন্নয়ন** | ব্যবসায়িক বিশ্লেষকরা আইটি গভর্নেন্সের সাথে তাদের নিজস্ব সমাধান তৈরি করতে পারে |
### যখন লো-কোড ছোট হয়
| সীমাবদ্ধতা | প্রভাব |
|------------|---------|

| **পারফরম্যান্স সিলিং** | উচ্চ-থ্রুপুট বা লেটেন্সি-সংবেদনশীল অ্যাপ্লিকেশনের জন্য উপযুক্ত নয় |
| **UI সীমাবদ্ধতা** | কাস্টম ডিজাইন কঠিন; প্ল্যাটফর্ম যা সমর্থন করে তার মধ্যে আপনি সীমাবদ্ধ |
| **একীকরণ জটিলতা** | অস্বাভাবিক API বা লিগ্যাসি সিস্টেমের সাথে সংযোগ করার জন্য যেভাবেই হোক কাস্টম কোডের প্রয়োজন হতে পারে |
| **স্কেল এ খরচ** | প্রতি-ব্যবহারকারী বা প্রতি-অ্যাপ মূল্য ব্যবহার বৃদ্ধির সাথে সাথে ব্যয়বহুল হয়ে উঠতে পারে |
| **ডিবাগিং অসুবিধা** | ভিজ্যুয়াল বিমূর্ততা জটিল সমস্যাগুলি নির্ণয় করা কঠিন করে তোলে |

## প্ল্যাটফর্ম ইঞ্জিনিয়ারিং
### প্ল্যাটফর্ম ইঞ্জিনিয়ারিং সমস্যার সমাধান করে
| প্ল্যাটফর্ম ইঞ্জিনিয়ারিং ছাড়া | প্ল্যাটফর্ম ইঞ্জিনিয়ারিং সহ |
|-------------------------------------------- |----------------------------------------- |
| প্রতিটি দল তাদের নিজস্ব অবকাঠামো পরিচালনা করে | স্ব-পরিষেবা প্ল্যাটফর্ম অবকাঠামো বিমূর্ত করে |
| দল জুড়ে অসামঞ্জস্যপূর্ণ টুলিং | মানসম্মত টুলচেইন; সোনালী পথ |
| বিকাশকারীরা সংস্থান সংস্থান করার জন্য অপ্সের জন্য অপেক্ষা করে | ডেভেলপাররা চাহিদা অনুযায়ী সম্পদ সরবরাহ করে |
| জ্ঞান সাইলোস; উপজাতীয় জ্ঞান | নথিভুক্ত; স্বয়ংক্রিয়; আবিষ্কারযোগ্য |
| নতুন প্রকৌশলীদের জন্য ধীর গতিতে অনবোর্ডিং | প্রথম দিনে নতুন প্রকৌশলী মোতায়েন করতে পারেন |
### একটি অভ্যন্তরীণ বিকাশকারী প্ল্যাটফর্মের মূল উপাদান
| উপাদান | উদ্দেশ্য | উদাহরণ টুল |
|------------|---------|---------------|
| **পরিষেবা ক্যাটালগ** | সমস্ত পরিষেবা এবং তাদের মালিকদের কেন্দ্রীয় রেজিস্ট্রি | মঞ্চের নেপথ্যে; বন্দর; কর্টেক্স |
| **টেমপ্লেটেড ভারা** | অনুমোদিত টেমপ্লেট থেকে নতুন পরিষেবা তৈরি করুন | ব্যাকস্টেজ সফ্টওয়্যার টেমপ্লেট; কুকি কাটার |
| **স্ব-সেবা পরিকাঠামো** | বিকাশকারীরা টিকিট ফাইল না করেই ক্লাউড সংস্থানগুলি সরবরাহ করে | টেরাফর্ম মডিউল; পুলুমি; ক্রসপ্লেন |
| **CI/CD পাইপলাইন** | মানসম্মত নির্মাণ, পরীক্ষা, পাইপলাইন স্থাপন | গিটহাব অ্যাকশন; গিটল্যাব সিআই; আর্গো সিডি |
| **পরিবেশ ব্যবস্থাপনা** | চাহিদা অনুযায়ী ক্ষণস্থায়ী ডেভ/স্টেজিং পরিবেশ | ভিক্লাস্টার; নামস্থান; গিটপড |
| **পর্যবেক্ষণযোগ্যতা** | লগিং, মেট্রিক্স, ট্রেসিং প্রতিটি পরিষেবার মধ্যে তৈরি | প্রমিথিউস; গ্রাফানা; ওপেনটেলিমেট্রি; ডেটাডগ |
| **গোপন ব্যবস্থাপনা** | শংসাপত্রের সুরক্ষিত সঞ্চয়স্থান এবং ঘূর্ণন | ভল্ট; AWS সিক্রেটস ম্যানেজার; SOPS |
| **পরিচয় এবং প্রবেশাধিকার** | এসএসও; ভূমিকা-ভিত্তিক অ্যাক্সেস; পরিষেবা থেকে পরিষেবা প্রমাণীকরণ | ওক্তা; চাবিকাঠি; SPIFFE |
### সোনালী পথ
একটি সুবর্ণ পথ হল কিছু করার সমর্থিত, মতামতযুক্ত উপায়। এটি ন্যূনতম প্রতিরোধের পথ - আপনি যদি এটি অনুসরণ করেন তবে সবকিছু কাজ করে। আপনি অফ-পাথ যেতে পারেন, কিন্তু আপনি আপনার নিজের উপর আছে.
| সোনালী পথ | এটা কি প্রদান করে |
|----------------------------------------------- |
| **নতুন পরিষেবা** | টেমপ্লেট রেপো; সিআই/সিডি; পর্যবেক্ষণ লগিং স্থাপনা কনফিগার |
| **নতুন ডাটাবেস** | প্রস্তাবিত উদাহরণ; গোপনে সংযোগ স্ট্রিং; ব্যাকআপ কনফিগার করা হয়েছে |
| **নতুন ফ্রন্টএন্ড** | পাইপলাইন নির্মাণ; সিডিএন; পূর্বরূপ পরিবেশ; বাতিঘর চেক |
| **ডেটা পাইপলাইন** | অর্কেস্ট্রেশন; স্কিমা বৈধতা; পর্যবেক্ষণ সতর্কতা |

| ফ্যাক্টর | কাস্টম তৈরি করুন | বিদ্যমান টুল ব্যবহার করুন |

## সারাংশ
লো-কোড প্ল্যাটফর্ম এবং অভ্যন্তরীণ বিকাশকারী প্ল্যাটফর্ম উভয়েরই লক্ষ্য সফ্টওয়্যার সরবরাহ করতে পারে এমন লোকের সংখ্যা বৃদ্ধি করা। লো-কোড সম্পূর্ণভাবে কোডকে বিমূর্ত করে এটি করে — ভিজ্যুয়াল বিল্ডার, প্রি-বিল্ট সংযোগকারী, ঘোষণামূলক যুক্তি। প্ল্যাটফর্ম ইঞ্জিনিয়ারিং পেশাদার বিকাশকারীদের জন্য স্ব-পরিষেবা পরিকাঠামো, সুবর্ণ পথ এবং মানসম্মত টুলিং প্রদান করে এটি করে যাতে তারা অপস কাজে কম সময় এবং পণ্যের বৈশিষ্ট্যগুলিতে বেশি সময় ব্যয় করে। সিলভার বুলেটও নয়: লো-কোডে বিক্রেতা লক-ইন এবং কর্মক্ষমতা সীমাবদ্ধতা রয়েছে এবং প্ল্যাটফর্ম ইঞ্জিনিয়ারিং বজায় রাখার জন্য চলমান বিনিয়োগের প্রয়োজন। কিন্তু যখন সঠিক সমস্যাগুলির জন্য প্রয়োগ করা হয় — অভ্যন্তরীণ সরঞ্জাম, CRUD অ্যাপ, প্রমিত পরিষেবা সরবরাহ — উভয়ই ধারণা থেকে উত্পাদনের সময়কে নাটকীয়ভাবে হ্রাস করতে পারে।
