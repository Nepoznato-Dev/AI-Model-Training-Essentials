# ওয়েব ডেভেলপমেন্ট
## ফ্রন্টএন্ড ডেভেলপমেন্ট
### মূল প্রযুক্তি
#### HTML (হাইপারটেক্সট মার্কআপ ল্যাঙ্গুয়েজ)
- **অর্থসূচক HTML**: অর্থপূর্ণ ট্যাগ ব্যবহার করা (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, XQZMARKER6)
- **ফর্ম**: ইনপুট প্রকার, বৈধতা, অ্যাক্সেসযোগ্যতা লেবেল
- **মিডিয়া**: ছবি, ভিডিও, অডিও এম্বেডিং
- **মেটা ট্যাগ**: এসইও, ভিউপোর্ট, অক্ষর এনকোডিং
- **HTML5 বৈশিষ্ট্য**: ক্যানভাস, SVG, স্থানীয় স্টোরেজ, জিওলোকেশন, ওয়েব সকেট
#### CSS (ক্যাসকেডিং স্টাইল শীট)
- **বক্স মডেল**: বিষয়বস্তু, প্যাডিং, সীমানা, মার্জিন
- **লেআউট সিস্টেম**:
  - **ফ্লেক্সবক্স**: এক-মাত্রিক লেআউট, ন্যায্যতা-সামগ্রী, সারিবদ্ধ-আইটেম
  - **গ্রিড**: দ্বি-মাত্রিক বিন্যাস, গ্রিড-টেমপ্লেট, গ্রিড-এরিয়া
  - **পজিশনিং**: স্থির, আপেক্ষিক, পরম, স্থির, আঠালো
- **প্রতিক্রিয়াশীল ডিজাইন**: মিডিয়া প্রশ্ন, মোবাইল-প্রথম পদ্ধতি
- **CSS ভেরিয়েবল**: থিমিংয়ের জন্য কাস্টম বৈশিষ্ট্য
- **অ্যানিমেশন**: রূপান্তর, কীফ্রেম, রূপান্তর
- **প্রিপ্রসেসর**: সাস, কম (ভেরিয়েবল, মিক্সিন, নেস্টিং)
#### জাভাস্ক্রিপ্ট
- **DOM ম্যানিপুলেশন**: উপাদান নির্বাচন করা, তৈরি করা, পরিবর্তন করা
- **ইভেন্টস**: ক্লিক করুন, জমা দিন, কীবোর্ড, কাস্টম ইভেন্ট, ইভেন্ট প্রতিনিধি
- **ES6+ বৈশিষ্ট্য**: তীর ফাংশন, ধ্বংস, স্প্রেড/বিশ্রাম, মডিউল, অ্যাসিঙ্ক/অপেক্ষা
- **APIs**: আনুন, XMLHttpRequest, লোকাল স্টোরেজ, সেশন স্টোরেজ
- **টাইপস্ক্রিপ্ট**: স্ট্যাটিক টাইপিং, ইন্টারফেস, জেনেরিক, ডেকোরেটর
### আধুনিক ফ্রন্টেন্ড ফ্রেমওয়ার্ক
#### প্রতিক্রিয়া
- **উপাদান**: কার্যকরী উপাদান, শ্রেণীর উপাদান
- **হুক**: useState, useEffect, useContext, useReducer, কাস্টম হুক
- **স্টেট ম্যানেজমেন্ট**: কনটেক্সট এপিআই, রেডাক্স, জুস্ট্যান্ড, রিকোয়েল
- **রাউটিং**: প্রতিক্রিয়া রাউটার (ব্রাউজার রাউটার, রুট, রুট, লিঙ্ক)
- **ইকোসিস্টেম**: Next.js (SSR, SSG), Remix, Gatsby
- **ভার্চুয়াল DOM**: ডিফিং অ্যালগরিদমের মাধ্যমে দক্ষ রেন্ডারিং
#### Vue.js
- **বিকল্প API**: ডেটা, পদ্ধতি, গণনা করা, ঘড়ি
- **কম্পোজিশন API**: সেটআপ(), রেফ, রিঅ্যাকটিভ, কম্পিউটেড
- **নির্দেশনা**: v-if, v-for, v-bind, v-on, v-মডেল
- **Vuex/Pinia**: রাজ্য ব্যবস্থাপনা
- **ভিউ রাউটার**: ক্লায়েন্ট-সাইড রাউটিং
- **Nuxt.js**: সার্ভার-সাইড রেন্ডারিং ফ্রেমওয়ার্ক
#### কৌণিক
- **উপাদান**: ডেকোরেটর, টেমপ্লেট, লাইফসাইকেল হুক
- **পরিষেবা**: নির্ভরতা ইনজেকশন, সিঙ্গলটন প্যাটার্ন
- **RxJS**: প্রতিক্রিয়াশীল প্রোগ্রামিং, পর্যবেক্ষণযোগ্য
- **রাউটিং**: রাউটারমডিউল, গার্ডস, রেজলভার
- **ফর্ম**: টেমপ্লেট-চালিত, প্রতিক্রিয়াশীল ফর্ম
- **NgRx**: Redux-শৈলী রাষ্ট্র পরিচালনা
### সরঞ্জাম এবং বান্ডলার তৈরি করুন
- **ওয়েবপ্যাক**: মডিউল বান্ডলিং, কোড স্প্লিটিং, লোডার, প্লাগইন
- **Vite**: নেটিভ ES মডিউল ব্যবহার করে দ্রুত বিল্ড টুল
- **পার্সেল**: জিরো-কনফিগারেশন বান্ডলার
- **রোলআপ**: লাইব্রেরির জন্য অপ্টিমাইজ করা হয়েছে
- **esbuild**: অত্যন্ত দ্রুত জাভাস্ক্রিপ্ট বান্ডলার
- **ব্যাবেল**: ব্যাকওয়ার্ড সামঞ্জস্যের জন্য জাভাস্ক্রিপ্ট ট্রান্সপিলার
- **পোস্টসিএসএস**: প্লাগইনগুলির সাথে সিএসএস প্রক্রিয়াকরণ
### CSS ফ্রেমওয়ার্ক এবং লাইব্রেরি
- **বুটস্ট্র্যাপ**: কম্পোনেন্ট লাইব্রেরি, গ্রিড সিস্টেম, ইউটিলিটি
- **Tailwind CSS**: ইউটিলিটি-প্রথম CSS ফ্রেমওয়ার্ক
- **মেটেরিয়াল UI**: গুগলের মেটেরিয়াল ডিজাইন বাস্তবায়ন
- **চক্র UI**: অ্যাক্সেসযোগ্য কম্পোনেন্ট লাইব্রেরি
- **পিঁপড়া ডিজাইন**: এন্টারপ্রাইজ-স্তরের UI উপাদান
- **শৈলীকৃত উপাদান**: সিএসএস-ইন-জেএস লাইব্রেরি
- **আবেগ**: উৎস মানচিত্র সহ CSS-in-JS
## ব্যাকএন্ড ডেভেলপমেন্ট
### সার্ভার-সাইড ল্যাঙ্গুয়েজ
#### Node.js
- **রানটাইম**: সার্ভারে জাভাস্ক্রিপ্ট (V8 ইঞ্জিন)
- **Express.js**: ন্যূনতম ওয়েব ফ্রেমওয়ার্ক, মিডলওয়্যার আর্কিটেকচার
- **NestJS**: কৌণিক-অনুপ্রাণিত আর্কিটেকচার, টাইপস্ক্রিপ্ট
- **Fastify**: উচ্চ-পারফরম্যান্স ফ্রেমওয়ার্ক
- **Koa**: একই নির্মাতাদের দ্বারা আধুনিক এক্সপ্রেস
- **প্যাকেজ ব্যবস্থাপনা**: এনপিএম, সুতা, পিএনপিএম
#### পাইথন
- **জ্যাঙ্গো**: সম্পূর্ণ বৈশিষ্ট্যযুক্ত ফ্রেমওয়ার্ক, ORM, অ্যাডমিন প্যানেল, ব্যাটারি-অন্তর্ভুক্ত
- **ফ্লাস্ক**: মাইক্রোফ্রেমওয়ার্ক, এক্সটেনশন ইকোসিস্টেম
- **FastAPI**: আধুনিক, অ্যাসিঙ্ক, স্বয়ংক্রিয় API ডকুমেন্টেশন
- **পিরামিড**: নমনীয়, মাপযোগ্য কাঠামো
#### অন্যান্য ব্যাকএন্ড ভাষা
- **Ruby on Rails**: কনভেনশন ওভার কনফিগারেশন, ActiveRecord ORM
- **জাভা স্প্রিং**: এন্টারপ্রাইজ ফ্রেমওয়ার্ক, নির্ভরতা ইনজেকশন
- **PHP লারাভেল**: মার্জিত সিনট্যাক্স, বাগ্মী ORM, ব্লেড টেমপ্লেটিং
- **গো জিন**: উচ্চ কার্যক্ষমতা, ন্যূনতম কাঠামো
- **রাস্ট অ্যাক্টিক্স**: মেমরি নিরাপত্তা, কর্মক্ষমতা
- **C# ASP.NET কোর**: ক্রস-প্ল্যাটফর্ম, এন্টারপ্রাইজ বৈশিষ্ট্য
### ডাটাবেস ইন্টিগ্রেশন
#### ORMs (অবজেক্ট-রিলেশনাল ম্যাপিং)
- **সিক্যুয়ালাইজ**: SQL ডাটাবেসের জন্য Node.js ORM
- **প্রিজমা**: টাইপ-সেফ ডাটাবেস অ্যাক্সেস, স্বয়ংক্রিয়ভাবে তৈরি ক্লায়েন্ট
- **SQLAlchemy**: Python SQL টুলকিট এবং ORM
- **ActiveRecord**: Ruby on Rails ORM
- **হাইবারনেট**: জাভা ওআরএম
- **এন্টিটি ফ্রেমওয়ার্ক**: .NET ORM
#### ডাটাবেস ড্রাইভার
- **pg**: Node.js-এর জন্য PostgreSQL ক্লায়েন্ট
- **mysql2**: প্রতিশ্রুতি সহ MySQL ক্লায়েন্ট
- **পাইমঙ্গো**: পাইথনের জন্য মঙ্গোডিবি ড্রাইভার
- **redis**: একাধিক ভাষার জন্য Redis ক্লায়েন্ট
### API ডেভেলপমেন্ট
#### REST API
- **HTTP পদ্ধতি**: GET, POST, PUT, PATCH, DELETE
- **স্থিতি কোড**: 200, 201, 400, 401, 403, 404, 500
- **সম্পদ নামকরণ**: বিশেষ্য, বহুবচন, শ্রেণিবিন্যাস
- **সংস্করণ**: URL পাথ, হেডার, ক্যোয়ারী প্যারামিটার
- **প্রমাণিকরণ**: JWT, OAuth, API কী
- **ডকুমেন্টেশন**: OpenAPI/Swagger, পোস্টম্যান
#### গ্রাফকিউএল
- **স্কিমা সংজ্ঞা**: প্রকার, প্রশ্ন, মিউটেশন, সদস্যতা
- **সমাধানকারী**: ক্ষেত্র-স্তরের ডেটা আনা
- **অ্যাপোলো সার্ভার**: গ্রাফকিউএল সার্ভার বাস্তবায়ন
- **রিলে**: Facebook এর GraphQL ক্লায়েন্ট
- **সুবিধা**: কোন ওভার-ফেচিং, একক এন্ডপয়েন্ট, শক্তিশালী টাইপিং
#### জিআরপিসি
- **প্রটোকল বাফার**: ইন্টারফেস সংজ্ঞা ভাষা
- **HTTP/2**: দ্বিমুখী স্ট্রিমিং
- **ব্যবহারের ক্ষেত্রে**: মাইক্রোসার্ভিসেস যোগাযোগ, রিয়েল-টাইম অ্যাপ্লিকেশন
### প্রমাণীকরণ এবং অনুমোদন
- **সেশন-ভিত্তিক**: কুকিজ, সার্ভার-সাইড সেশন
- **টোকেন-ভিত্তিক**: JWT (JSON ওয়েব টোকেন), রাষ্ট্রহীন
- **OAuth 2.0**: অনুমোদন ফ্রেমওয়ার্ক, তৃতীয় পক্ষের লগইন
- **ওপেনআইডি কানেক্ট**: OAuth 2.0-এ আইডেন্টিটি লেয়ার
- **SAML**: এন্টারপ্রাইজ একক সাইন-অন
- **পাসওয়ার্ড হ্যাশিং**: bcrypt, argon2, scrypt
- **মাল্টি-ফ্যাক্টর প্রমাণীকরণ**: TOTP, SMS, ইমেল কোড
## DevOps এবং স্থাপনা
### সংস্করণ নিয়ন্ত্রণ
- **Git**: বিতরণকৃত সংস্করণ নিয়ন্ত্রণ
- **GitHub/GitLab/Bitbucket**: রিপোজিটরি হোস্টিং
- **শাখার কৌশল**: গিট ফ্লো, গিটহাব ফ্লো, ট্রাঙ্ক-ভিত্তিক উন্নয়ন
- **CI/CD**: অটোমেটেড টেস্টিং এবং ডিপ্লয়মেন্ট পাইপলাইন
### কন্টেইনারাইজেশন
- **ডকার**: কন্টেইনার রানটাইম, ডকারফাইল, ছবি
- **ডকার কম্পোজ**: মাল্টি-কন্টেইনার অর্কেস্ট্রেশন
- **কন্টেইনার রেজিস্ট্রি**: ডকার হাব, AWS ECR, Google GCR
- **সর্বোত্তম অনুশীলন**: মাল্টি-স্টেজ বিল্ড, মিনিমাম বেস ইমেজ
### অর্কেস্ট্রেশন
- **কুবারনেটস**: কন্টেইনার অর্কেস্ট্রেশন, পড, পরিষেবা, স্থাপনা
- **হেল্ম**: কুবারনেটস প্যাকেজ ম্যানেজার
- **পরিষেবা মেশ**: মাইক্রোসার্ভিসেস নেটওয়ার্কিংয়ের জন্য ইস্টিও, লিংকার্ড
