# এমবেডেড সিস্টেম এবং আইওটি
এমবেডেড সিস্টেমগুলি হল অন্যান্য ডিভাইসের ভিতরে লুকানো কম্পিউটারগুলি — আপনার গাড়ির ইঞ্জিন নিয়ন্ত্রণ ইউনিট, আপনার ওয়াশিং মেশিনের নিয়ামক, একটি স্মার্ট থার্মোস্ট্যাটে মাইক্রোকন্ট্রোলার৷ সাধারণ-উদ্দেশ্যের কম্পিউটারগুলির বিপরীতে, এগুলি নির্দিষ্ট কাজের জন্য ডিজাইন করা হয়েছে, প্রায়শই শক্তি, মেমরি এবং প্রক্রিয়াকরণের গতিতে কঠোর সীমাবদ্ধতার সাথে। ইন্টারনেট অফ থিংস (IoT) এম্বেড করা সিস্টেমগুলিকে নেটওয়ার্কের সাথে সংযুক্ত করে, দূরবর্তী পর্যবেক্ষণ, নিয়ন্ত্রণ এবং ডেটা সংগ্রহ সক্ষম করে প্রসারিত করে। একসাথে, তারা বিলিয়ন কম্পিউটিং ডিভাইসের প্রতিনিধিত্ব করে যা ভৌত জগতের সাথে যোগাযোগ করে।

## এমবেডেড সিস্টেম ফান্ডামেন্টাল
### কি এম্বেড করা ভিন্ন করে তোলে
| দৃষ্টিভঙ্গি | সাধারণ-উদ্দেশ্য কম্পিউটার | এমবেডেড সিস্টেম |
|---------|------------------------------------------------------------|
| **উদ্দেশ্য** | যেকোনো সফটওয়্যার চালান | নির্দিষ্ট কাজ সম্পাদন করুন |
| **সম্পদ** | প্রচুর CPU, RAM, স্টোরেজ | সীমিত (KB থেকে MB RAM; MHz থেকে কম GHz) |
| **শক্তি** | প্লাগ ইন বা বড় ব্যাটারি | প্রায়শই ব্যাটারি-চালিত বা শক্তি-হার্ভেস্টিং |
| **OS** | সম্পূর্ণ OS (Windows, Linux, macOS) | RTOS, বেয়ার-মেটাল, বা এমবেডেড লিনাক্স |
| **ইউজার ইন্টারফেস** | সমৃদ্ধ (স্ক্রীন, কীবোর্ড, মাউস) | ন্যূনতম (এলইডি, বোতাম, সেন্সর) বা কিছুই নয় |
| **রিয়েল-টাইম** | সর্বোত্তম প্রচেষ্টা | প্রায়ই হার্ড রিয়েল-টাইম সময়সীমা |
| **জীবনকাল** | 3-7 বছর | 10-25+ বছর |
### মাইক্রোকন্ট্রোলার বনাম মাইক্রোপ্রসেসর
| বৈশিষ্ট্য | মাইক্রোকন্ট্রোলার (MCU) | মাইক্রোপ্রসেসর (MPU) |
|---------|-------------------------|----------------------|
| **একীকরণ** | একটি চিপে CPU + RAM + ফ্ল্যাশ + পেরিফেরাল | শুধুমাত্র CPU; এক্সটার্নাল RAM এবং স্টোরেজ |
| **পারফরম্যান্স** | নিম্ন থেকে মাঝারি (MHz পরিসর) | উচ্চ (GHz পরিসীমা) |
| **শক্তি** | খুব কম (µA থেকে mA) | উচ্চতর (এমএ থেকে শত শত এমএ) |
| **খরচ** | $0.10 - $10 | $5 - $100+ |
| **উদাহরণ** | STM32, ESP32, Arduino (ATmega), nRF52 | রাস্পবেরি পাই (BCM2835), i.MX, Allwinner |
| **কেস ব্যবহার করুন** | সেন্সর, অ্যাকচুয়েটর, সহজ নিয়ন্ত্রণ | ডিসপ্লে, জটিল প্রক্রিয়াকরণ, লিনাক্স |

## সাধারণ এমবেডেড প্ল্যাটফর্ম
| প্ল্যাটফর্ম | MCU/MPU | মূল বৈশিষ্ট্য | জন্য সেরা |
|------------|---------|---------------|----------|
| **আরডুইনো** | ATmega328P (এবং অন্যান্য) | সরল; বিশাল সম্প্রদায় | শেখা; প্রোটোটাইপিং |
| **ESP32** | Espressif ডুয়াল-কোর | Wi-Fi + ব্লুটুথ; কম খরচে | আইওটি প্রকল্প; সংযুক্ত ডিভাইস |
| **রাস্পবেরি পাই পিকো** | RP2040 (ডুয়াল-কোর ARM) | সাশ্রয়ী মূল্যের; মাইক্রোপাইথন সমর্থন | শিক্ষা; শখ প্রকল্প |
| **STM32** | এআরএম কর্টেক্স-এম সিরিজ | শিল্প গ্রেড; বিস্তৃত পরিসর | পেশাদার এমবেডেড; শিল্প |
| **nRF52/nRF53** | নর্ডিক সেমিকন্ডাক্টর | ব্লুটুথ লো এনার্জি বিশেষজ্ঞ | পরিধানযোগ্য; বীকন |
| **রাস্পবেরি পাই** | ব্রডকম BCM (ARM) | সম্পূর্ণ লিনাক্স; GPIO পিন | প্রোটোটাইপিং; মিডিয়া সেন্টার; হালকা প্রান্ত কম্পিউটিং |
| **বিগলবোন** | টিআই সিতারা (এআরএম) | রিয়েল-টাইম PRU কোর | শিল্প; রিয়েল-টাইম অ্যাপ্লিকেশন |
| **ESP32-S3** | এসপ্রেসিফ | এআই ত্বরণ; ইউএসবি | এজ এআই; দৃষ্টি অ্যাপ্লিকেশন |

## রিয়েল-টাইম অপারেটিং সিস্টেম (RTOS)
একটি RTOS গ্যারান্টি দেয় যে গুরুত্বপূর্ণ কাজগুলি একটি নির্দিষ্ট সময়ের মধ্যে সম্পূর্ণ হবে৷
| RTOS | লাইসেন্স | জন্য সেরা |
|------|---------|----------|
| **FreeRTOS** | এমআইটি | সবচেয়ে সাধারণ; ব্যাপক MCU সমর্থন |
| **জেফাইর** | অ্যাপাচি 2.0 | আধুনিক; লিনাক্স ফাউন্ডেশন; ক্রমবর্ধমান বাস্তুতন্ত্র |
| **ThreadX (Azure RTOS)** | এমআইটি | নিরাপত্তা-প্রত্যয়িত; আইওটি |
| **এম্বস** | বাণিজ্যিক | শিল্প; প্রত্যয়িত |
| **আরটি-থ্রেড** | অ্যাপাচি 2.0 | চীনা বাস্তুতন্ত্র; বিশ্বব্যাপী ক্রমবর্ধমান |
### RTOS বনাম বেয়ার মেটাল
| দৃষ্টিভঙ্গি | বেয়ার মেটাল | RTOS |
|---------|------------|------|
| **জটিলতা** | সাধারণ কাজের জন্য সহজ | জটিল, সমসাময়িক কাজের জন্য প্রয়োজন |
| **শিডিউলিং** | ম্যানুয়াল (প্রধান লুপ + বাধা) | অগ্রাধিকার সহ পূর্বনির্ধারিত সময়সূচী |
| **স্কেলযোগ্যতা** | বৈশিষ্ট্য যোগ করা কঠিন | কাজ যোগ করা সহজ |
| **স্মৃতি** | ন্যূনতম ওভারহেড | ছোট ওভারহেড (কয়েক কেবি) |

## যোগাযোগ প্রোটোকল
### তারযুক্ত প্রোটোকল
| প্রোটোকল | গতি | দূরত্ব | কেস ব্যবহার করুন |
|----------|-------|------------|----------|
| **UART** | 1 Mbps পর্যন্ত | সংক্ষিপ্ত (অন-বোর্ড) | ডিবাগ কনসোল; GPS মডিউল |
| **SPI** | 100 MHz পর্যন্ত | সংক্ষিপ্ত (অন-বোর্ড) | উচ্চ-গতির পেরিফেরাল (ডিসপ্লে, ফ্ল্যাশ) |
| **I²C** | 3.4 MHz পর্যন্ত | সংক্ষিপ্ত (অন-বোর্ড) | সেন্সর; কম পিন-গণনা যোগাযোগ |
| **ক্যান** | 1 Mbps পর্যন্ত | 1 কিমি পর্যন্ত | স্বয়ংচালিত; শিল্প |
| **ইথারনেট** | 10 Mbps - 100 Gbps | 100 মিটার পর্যন্ত | নেটওয়ার্কিং; শিল্প (এক্সটেনশন সহ) |
| **USB** | 40 Gbps পর্যন্ত (USB4) | 5 মিটার পর্যন্ত | আনুষঙ্গিক; চার্জিং |
### ওয়্যারলেস প্রোটোকল
| প্রোটোকল | পরিসীমা | শক্তি | গতি | কেস ব্যবহার করুন |
|----------|-------|-------|-------|----------|
| **ওয়াই-ফাই** | ~100 মি | উচ্চ | Wi-Fi 7 পর্যন্ত (46 Gbps তাত্ত্বিক) | উচ্চ-ব্যান্ডউইথ আইওটি; স্ট্রিমিং |
| **ব্লুটুথ ক্লাসিক** | ~100 মি | মাঝারি | 1-3 Mbps | অডিও; ফাইল স্থানান্তর |
| **BLE** (ব্লুটুথ কম শক্তি) | ~100 মি | খুব কম | 1-2 Mbps | পরিধানযোগ্য; বীকন; সেন্সর |
| **জিগবি** | ~100 মি (জাল) | কম | 250 kbps | হোম অটোমেশন; শিল্প সেন্সর |
| **জেড-ওয়েভ** | ~100 মি (জাল) | কম | 100 kbps | হোম অটোমেশন |
| **লোরা / লোরাওয়ান** | 15 কিমি পর্যন্ত | খুব কম | 0.3-50 kbps | কৃষি; ইউটিলিটি; শহরব্যাপী সেন্সর |
| **NB-IoT** | সেলুলার কভারেজ | কম | 250 kbps | পরিমাপ; সম্পদ ট্র্যাকিং |
| **থ্রেড / ম্যাটার** | ~100 মি (জাল) | কম | মধ্যপন্থী | স্মার্ট হোম (অ্যাপল, গুগল, অ্যামাজন) |
| **সেলুলার (4G/5G)** | বিশ্বব্যাপী | উচ্চ | উচ্চ | সংযুক্ত যানবাহন; দূরবর্তী পর্যবেক্ষণ |

## আইওটি আর্কিটেকচার
### আইওটি স্ট্যাক
| স্তর | ফাংশন | উদাহরণ |
|-------|------------|---------|
| **ডিভাইস** | সেন্সর, অ্যাকচুয়েটর, মাইক্রোকন্ট্রোলার | ESP32, STM32, রাস্পবেরি পাই |
| **সংযোগ** | নেটওয়ার্ক প্রোটোকল | MQTT, HTTP, CoAP, LoRaWAN |
| **এজ কম্পিউটিং** | ডিভাইসের কাছাকাছি প্রক্রিয়াকরণ | AWS Greengrass, Azure IoT Edge |
| **ক্লাউড প্ল্যাটফর্ম** | ডেটা ইনজেশন, স্টোরেজ, প্রসেসিং | AWS IoT, Azure IoT হাব, Google Cloud IoT |
| **আবেদন** | ড্যাশবোর্ড, বিশ্লেষণ, সতর্কতা | Grafana, কাস্টম ওয়েব অ্যাপস |
### IoT কমিউনিকেশন প্রোটোকল
| প্রোটোকল | প্যাটার্ন | জন্য সেরা |
|----------|---------|----------|
| **MQTT** | প্রকাশ/সাবস্ক্রাইব করুন; লাইটওয়েট | বেশিরভাগ IoT অ্যাপ্লিকেশন; কম ব্যান্ডউইথ |
| **HTTP/বিশ্রাম** | অনুরোধ/প্রতিক্রিয়া | যখন সরলতা গুরুত্বপূর্ণ; ওয়েব ইন্টিগ্রেশন |
| **CoAP** | অনুরোধ/প্রতিক্রিয়া; UDP-ভিত্তিক | সীমাবদ্ধ ডিভাইস; কম শক্তি |
| **AMQP** | বার্তা সারিবদ্ধ | এন্টারপ্রাইজ আইওটি; নির্ভরযোগ্য ডেলিভারি |
| **ওয়েবসকেট** | দ্বিমুখী; অবিরাম সংযোগ | রিয়েল-টাইম ড্যাশবোর্ড; লাইভ ডেটা |
### MQTT বিস্তারিত
| ধারণা | বর্ণনা |
|---------|---------------|
| **দালাল** | সেন্ট্রাল সার্ভার যা বার্তাগুলিকে রুট করে (Mosquitto, EMQX, HiveMQ) |
| **বিষয়** | অনুক্রমিক ঠিকানা (যেমন,`home/living-room/temperature`) |
| **QoS** | 0 (সর্বোচ্চ একবার), 1 (কমপক্ষে একবার), 2 (ঠিক একবার) |
| **সংরক্ষিত বার্তা** | একটি বিষয়ে শেষ বার্তা; নতুন গ্রাহকদের কাছে বিতরণ করা হয়েছে |
| **শেষ ইচ্ছা** | একটি ক্লায়েন্ট অপ্রত্যাশিতভাবে সংযোগ বিচ্ছিন্ন হলে বার্তা প্রকাশিত

## এজ কম্পিউটিং
ক্লাউডে সবকিছু পাঠানোর পরিবর্তে উৎসের কাছাকাছি ডেটা প্রক্রিয়াকরণ।

## সারাংশ
এমবেডেড সিস্টেম এবং আইওটি সফ্টওয়্যার এবং ভৌত জগতের ছেদকে প্রতিনিধিত্ব করে। মোটর নিয়ন্ত্রণকারী মাইক্রোকন্ট্রোলার থেকে শুরু করে ক্লাউড-সংযুক্ত সেন্সর নেটওয়ার্কগুলিতে, তাদের ওয়েব বা অ্যাপ বিকাশ থেকে একটি ভিন্ন মানসিকতার প্রয়োজন: সীমাবদ্ধ সংস্থান, রিয়েল-টাইম প্রয়োজনীয়তা, দীর্ঘ জীবনকাল এবং বাগগুলির শারীরিক-বিশ্বের পরিণতি। ইকোসিস্টেম ব্যাপকভাবে পরিপক্ক হয়েছে — ESP-IDF এবং Zephyr-এর মতো কাঠামো পেশাদার বিকাশকে অ্যাক্সেসযোগ্য করে তোলে, যখন AWS IoT এবং Azure IoT হাবের মতো প্ল্যাটফর্মগুলি ক্লাউড সাইড পরিচালনা করে। মূল দক্ষতা হল হার্ডওয়্যার ইন্টারফেস, যোগাযোগ প্রোটোকল, পাওয়ার ম্যানেজমেন্ট এবং সফ্টওয়্যার লেখার শৃঙ্খলা বোঝা যা হস্তক্ষেপ ছাড়াই বছরের পর বছর নির্ভরযোগ্যভাবে চলতে হবে।
