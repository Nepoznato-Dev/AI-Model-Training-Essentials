# ডাটাবেস সিস্টেম
## ডাটাবেসের মৌলিক বিষয়
### ডেটাবেস কি?
একটি ডাটাবেস হল ইলেকট্রনিকভাবে সংরক্ষিত কাঠামোগত তথ্যের একটি সংগঠিত সংগ্রহ, যা দক্ষ পুনরুদ্ধার, সন্নিবেশ, আপডেট এবং ডেটা মুছে ফেলার জন্য ডিজাইন করা হয়েছে।
### ডাটাবেস ম্যানেজমেন্ট সিস্টেম (DBMS)
সফ্টওয়্যার যা ডেটা ক্যাপচার এবং বিশ্লেষণ করতে শেষ ব্যবহারকারী, অ্যাপ্লিকেশন এবং ডাটাবেসের সাথে ইন্টারঅ্যাক্ট করে। উদাহরণ: MySQL, PostgreSQL, Oracle, MongoDB।
### মূল ধারণা
- **স্কিমা**: ডাটাবেসের গঠন/সংগঠন (সারণী, ক্ষেত্র, সম্পর্ক)
- **উদাহরণ**: একটি নির্দিষ্ট মুহূর্তে সংরক্ষিত প্রকৃত তথ্য
- **এসিড বৈশিষ্ট্য**: পারমাণবিকতা, ধারাবাহিকতা, বিচ্ছিন্নতা, স্থায়িত্ব
- **CAP উপপাদ্য**: সামঞ্জস্য, প্রাপ্যতা, বিভাজন সহনশীলতা (2 চয়ন করুন)
- **স্বাভাবিককরণ**: অপ্রয়োজনীয়তা কমাতে ডেটা সংগঠিত করা
- **অসাধারণকরণ**: পঠন কার্যক্ষমতা উন্নত করতে অপ্রয়োজনীয়তা যোগ করা
## রিলেশনাল ডাটাবেস (SQL)
### মূল ধারণা
- **সারণী**: সারি (রেকর্ড) এবং কলাম (ক্ষেত্র)
- **প্রাথমিক কী**: প্রতিটি সারির জন্য স্বতন্ত্র শনাক্তকারী
- **বিদেশী কী**: অন্য টেবিলে প্রাথমিক কীর উল্লেখ
- **সূচীপত্র**: ডেটা স্ট্রাকচার কোয়েরির গতি উন্নত করে
- **দর্শন**: ক্যোয়ারী ফলাফলের উপর ভিত্তি করে ভার্চুয়াল টেবিল
- **সংরক্ষিত পদ্ধতি**: পূর্বে সংকলিত SQL কোড ব্লক
- **ট্রিগার**: ডেটা পরিবর্তনের উপর স্বয়ংক্রিয় ক্রিয়া
### SQL অপারেশন (CRUD)```sql
-- Create
INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com');

-- Read
SELECT * FROM users WHERE id = 1;
SELECT name, email FROM users ORDER BY name LIMIT 10;

-- Update
UPDATE users SET email = 'new@example.com' WHERE id = 1;

-- Delete
DELETE FROM users WHERE id = 1;
```

### যোগদান করে
- **অভ্যন্তরীণ যোগদান**: উভয় টেবিল থেকে মিলে যাওয়া সারি দেখায়
- **বাম যোগদান**: বাম টেবিলের সমস্ত সারি, ডান থেকে মেলে
- **ডান যোগ দিন**: ডান টেবিলের সমস্ত সারি, বাম থেকে মেলে
- **সম্পূর্ণ বাইরের যোগদান**: উভয় টেবিলের সমস্ত সারি
- **ক্রস জয়েন**: উভয় টেবিলের কার্টেসিয়ান পণ্য
- **নিজে যোগদান**: টেবিলটি নিজের সাথে যোগ দিয়েছে
### সাধারণীকরণ ফর্ম
- **1NF**: পারমাণবিক মান, কোনো পুনরাবৃত্ত গ্রুপ নেই
- **2NF**: 1NF + কোন আংশিক নির্ভরতা নেই (সমস্ত নন-কী অ্যাট্রিবিউট সম্পূর্ণ প্রাথমিক কী-এর উপর নির্ভর করে)
- **3NF**: 2NF + কোনো ট্রানজিটিভ নির্ভরতা নেই (নন-কী অ্যাট্রিবিউট অন্যান্য নন-কী অ্যাট্রিবিউটের উপর নির্ভর করে না)
- **BCNF**: শক্তিশালী 3NF, প্রতিটি নির্ধারক হল প্রার্থীর কী
- **4NF**: কোনো বহুমূল্য নির্ভরতা নেই
- **5NF**: কোনো যোগদান নির্ভরতা নেই
### জনপ্রিয় RDBMS
- **PostgreSQL**: উন্নত বৈশিষ্ট্য, এক্সটেনসিবল, এসিআইডি-সম্মত
- **MySQL**: ব্যাপকভাবে ব্যবহৃত, দ্রুত পঠিত, ওয়েব অ্যাপ্লিকেশন
- **ওরাকল**: এন্টারপ্রাইজ বৈশিষ্ট্য, মাপযোগ্যতা, ব্যয়বহুল
- **SQL সার্ভার**: মাইক্রোসফট ইকোসিস্টেম, ইন্টিগ্রেটেড টুলস
- **SQLite**: এম্বেডেড, সার্ভারহীন, লাইটওয়েট
- **মারিয়াডিবি**: মাইএসকিউএল ফর্ক, ওপেন সোর্স
## NoSQL ডাটাবেস
### NoSQL ডাটাবেসের প্রকারভেদ
#### নথির দোকান
- **গঠন**: JSON-এর মতো নথি (BSON)
- **ব্যবহারের ক্ষেত্রে**: বিষয়বস্তু পরিচালনা, ক্যাটালগ, ব্যবহারকারীর প্রোফাইল
- **উদাহরণ**: MongoDB, CouchDB, DocumentDB
- **কোয়েরির উদাহরণ** (MongoDB):```javascript
db.users.find({ age: { $gt: 25 } }).sort({ name: 1 });
```

#### মূল-মূল্যের দোকান
- **গঠন**: সরল কী-মানের জোড়া
- **ব্যবহারের ক্ষেত্রে**: ক্যাশিং, সেশন, শপিং কার্ট
- **উদাহরণ**: Redis, DynamoDB, Riak
- **বৈশিষ্ট্য**: দ্রুত, সহজ, সীমিত অনুসন্ধান
#### কলাম-ফ্যামিলি স্টোর
- **গঠন**: কলামগুলি পরিবারে বিভক্ত
- **কেস ব্যবহার করুন**: বড় ডেটা, বিশ্লেষণ, সময়-সিরিজ
- **উদাহরণ**: Cassandra, HBase, ScyllaDB
- **বৈশিষ্ট্য**: লিখুন-অপ্টিমাইজ করা, বিতরণ করা, মাপযোগ্য
#### গ্রাফ ডেটাবেস
- **গঠন**: নোড, প্রান্ত, বৈশিষ্ট্য
- **ব্যবহারের ক্ষেত্রে**: সামাজিক নেটওয়ার্ক, জালিয়াতি সনাক্তকরণ, সুপারিশ
- **উদাহরণ**: Neo4j, Amazon Neptune, ArangoDB
- **কোয়েরি ভাষা**: সাইফার (Neo4j), গ্রেমলিন
### কখন NoSQL ব্যবহার করবেন
- নমনীয়/বিকশিত স্কিমা
- অনুভূমিক স্কেলিং প্রয়োজনীয়তা
- উচ্চ লিখন থ্রুপুট
- হায়ারার্কিক্যাল/নেস্টেড ডেটা
- বিতরণ ব্যবস্থা
- রিয়েল-টাইম অ্যাপ্লিকেশন
## ডাটাবেস ডিজাইন
### সত্তা-সম্পর্ক মডেলিং
- **সত্তা**: বস্তু/ধারণা (গ্রাহক, পণ্য, অর্ডার)
- **গুণাবলী**: সত্তার বৈশিষ্ট্য (নাম, মূল্য, তারিখ)
- **সম্পর্ক**: সত্তার মধ্যে সংযোগ (এক-থেকে-এক, এক-থেকে-অনেক, বহু-থেকে-অনেক)
- **কার্ডিনালিটি**: সম্পর্কের ক্ষেত্রে দৃষ্টান্তের সংখ্যা
### স্কিমা ডিজাইন প্যাটার্ন
- **একক টেবিল ইনহেরিটেন্স**: টাইপ ডিসক্রিমিনেটরের সাথে এক টেবিলে সব ধরনের
- **ক্লাস টেবিল ইনহেরিটেন্স**: বেস এবং সাবক্লাসের জন্য আলাদা টেবিল
- **কংক্রিট টেবিল ইনহেরিটেন্স**: প্রতিটি কংক্রিট ক্লাসের জন্য আলাদা টেবিল
- **জংশন টেবিল**: বহু-থেকে-অনেক সম্পর্কের সমাধান করুন
- **অডিট টেবিল**: ট্র্যাক পরিবর্তন (created_at, update_at, deleted_at)
### ইন্ডেক্সিং কৌশল
- **বি-ট্রি**: ডিফল্ট, পরিসরের প্রশ্ন, সাজানো
- **হ্যাশ**: সঠিক মিল লুকআপ
- **বিটম্যাপ**: কম কার্ডিনালিটি কলাম (লিঙ্গ, স্থিতি)
- **ফুল-টেক্সট**: টেক্সট সার্চ করার ক্ষমতা
- **স্থানীয়**: ভৌগলিক তথ্য (GIS)
- **যৌগিক**: একাধিক কলাম একত্রিত
- **কভারিং**: প্রশ্নের জন্য প্রয়োজনীয় সমস্ত কলাম অন্তর্ভুক্ত করে
## ক্যোয়ারী অপ্টিমাইজেশান
### এক্সিকিউশন প্ল্যান
- কিভাবে ডাটাবেস প্রশ্নগুলি চালায় তা বোঝা
- বাধা সনাক্তকরণ (সম্পূর্ণ টেবিল স্ক্যান, অনুপস্থিত সূচক)
- টুলস: ব্যাখ্যা করুন, ব্যাখ্যা করুন বিশ্লেষণ করুন
### অপ্টিমাইজেশন কৌশল
- **সূচী ব্যবহার**: নিশ্চিত করুন যে প্রশ্নগুলি উপযুক্ত সূচী ব্যবহার করেছে
- **কোয়েরি পুনর্লিখন**: জটিল প্রশ্ন সরলীকরণ করুন
- **অপ্টিমাইজেশানে যোগ দিন**: সঠিক যোগদানের ধরন এবং অর্ডার বেছে নিন
- **পার্টিশনিং**: বড় টেবিল বিভক্ত করুন (পরিসীমা, হ্যাশ, তালিকা)
- **বস্তুকৃত দৃশ্য**: প্রাক-গণনা করা ক্যোয়ারী ফলাফল
- **ক্যোয়ারী ক্যাশিং**: ঘন ঘন ক্যোয়ারী ফলাফল সংরক্ষণ করুন
### সাধারণ কর্মক্ষমতা সমস্যা
- **N+1 ক্যোয়ারী সমস্যা**: অদক্ষভাবে সম্পর্কিত ডেটা আনা
- **অনুপস্থিত সূচক**: বড় টেবিলে সম্পূর্ণ টেবিল স্ক্যান
- **ওভার-ইনডেক্সিং**: অনেক সূচকের কারণে ধীরগতির লেখা
- **লক কনটেশন**: লেনদেন লকের জন্য অপেক্ষা করছে
- **অদক্ষ প্রশ্ন**: নির্বাচন করুন *, অপ্রয়োজনীয় যোগদান
## লেনদেন এবং সঙ্গতি
### লেনদেন বিচ্ছিন্নতা স্তর
- **পড়ুন অনিচ্ছাকৃত**: সর্বনিম্ন বিচ্ছিন্নতা, নোংরা পড়া সম্ভব
- **পড়ুন প্রতিশ্রুতিবদ্ধ**: শুধুমাত্র প্রতিশ্রুতিবদ্ধ ডেটা দৃশ্যমান (বেশিরভাগ ডিবিতে ডিফল্ট)
- **পুনরাবৃত্তিযোগ্য পঠন**: একই প্রশ্ন লেনদেনের মধ্যে একই ফলাফল প্রদান করে
- **সিরিয়ালাইজেবল**: সর্বোচ্চ বিচ্ছিন্নতা, লেনদেন ক্রমানুসারে সঞ্চালিত হয়
### সামঞ্জস্য নিয়ন্ত্রণ
- **হতাশাবাদী লকিং**: অ্যাক্সেসের আগে সম্পদ লক করুন
- **অপটিমিস্টিক লকিং**: কমিট করার আগে ভার্সন চেক করুন
- **MVCC (মাল্টি-ভার্সন কনকারেন্সি কন্ট্রোল)**: সারিগুলির একাধিক সংস্করণ বজায় রাখুন
- **রো-লেভেল লকিং**: নির্দিষ্ট সারি লক করুন
- **টেবিল-লেভেল লকিং**: পুরো টেবিল লক করুন
### অচলাবস্থা
- সার্কুলার নির্ভরতা যেখানে লেনদেন একে অপরের জন্য অপেক্ষা করে
- প্রতিরোধ: ধারাবাহিক লক অর্ডারিং, টাইমআউট, ডেডলক সনাক্তকরণ
- রেজোলিউশন: একটি লেনদেন বাতিল করুন
## প্রতিলিপি এবং স্কেলিং
### প্রতিলিপি প্রকার
- **মাস্টার-স্লেভ**: একটি প্রাথমিক, একাধিক পঠিত প্রতিলিপি
- **মাস্টার-মাস্টার**: একাধিক প্রাথমিক, দ্বিমুখী প্রতিলিপি
- **মাল্টি-মাস্টার**: N প্রাথমিক, দ্বন্দ্ব সমাধান প্রয়োজন
- **চেইন প্রতিলিপি**: নোডের মাধ্যমে অনুক্রমিক প্রতিলিপি
### স্কেলিং পদ্ধতি
- **উল্লম্ব স্কেলিং**: সার্ভারের সম্পদ বাড়ান (CPU, RAM, স্টোরেজ)
- **অনুভূমিক স্কেলিং**: আরও সার্ভার যোগ করুন (শার্ডিং, পার্টিশনিং)
- **প্রতিলিপি পড়ুন**: পড়া ট্রাফিক অফলোড
- **শার্ডিং**: কী/রেঞ্জ/হ্যাশ দ্বারা সার্ভার জুড়ে ডেটা বিভক্ত করুন
- **ফেডারেশন**: ফাংশন/পরিষেবা দ্বারা বিভক্ত
### সামঞ্জস্যপূর্ণ মডেল
- **দৃঢ় সামঞ্জস্য**: সমস্ত নোড একই সময়ে একই ডেটা দেখতে পায়
- **প্রকৃত সামঞ্জস্য**: নোডগুলি সময়ের সাথে একত্রিত হয়
- **কারণগত সামঞ্জস্য**: কারণ-প্রভাব সম্পর্ক সংরক্ষিত
- **পড়ুন-আপনার-লেখা**: ব্যবহারকারী অবিলম্বে তাদের নিজস্ব আপডেট দেখতে পায়
## ব্যাকআপ এবং পুনরুদ্ধার
### ব্যাকআপ কৌশল
- **সম্পূর্ণ ব্যাকআপ**: সম্পূর্ণ ডাটাবেস কপি
- **বর্ধিত ব্যাকআপ**: শেষ ব্যাকআপের পর থেকে পরিবর্তন
- **ডিফারেনশিয়াল ব্যাকআপ**: শেষ সম্পূর্ণ ব্যাকআপের পর থেকে পরিবর্তন
- **পয়েন্ট-ইন-টাইম রিকভারি**: নির্দিষ্ট মুহুর্তে পুনরুদ্ধার করুন
- **কন্টিনিউয়াস ব্যাকআপ**: ব্যাকআপে রিয়েল-টাইম রেপ্লিকেশন
### পুনরুদ্ধারের পদ্ধতি
- **RTO (পুনরুদ্ধারের সময় উদ্দেশ্য): সর্বোচ্চ গ্রহণযোগ্য ডাউনটাইম
- **RPO (পুনরুদ্ধার পয়েন্ট উদ্দেশ্য): সর্বাধিক গ্রহণযোগ্য ডেটা ক্ষতি
- **দুর্যোগ পুনরুদ্ধার পরিকল্পনা**: ব্যর্থতার জন্য নথিভুক্ত পদ্ধতি
- **পরীক্ষা**: নিয়মিত পুনরুদ্ধারের মহড়া
## নিরাপত্তা
### অ্যাক্সেস কন্ট্রোল
- **প্রমাণিকরণ**: ব্যবহারকারীর পরিচয় যাচাই করুন
- **অনুমোদন**: অনুমতি দিন (অনুমোদন, প্রত্যাহার)
- **ভুমিকা**: সহজ পরিচালনার জন্য গ্রুপ অনুমতি
- **নূন্যতম বিশেষাধিকারের নীতি**: ন্যূনতম প্রয়োজনীয় অ্যাক্সেস
### ডেটা সুরক্ষা
- **বিশ্রামে এনক্রিপশন**: সঞ্চিত ডেটা এনক্রিপ্ট করুন
- **ট্রানজিটে এনক্রিপশন**: সংযোগের জন্য TLS/SSL
- **মাস্কিং**: অ-উৎপাদনে সংবেদনশীল ডেটা লুকান
- **টোকেনাইজেশন**: টোকেন দিয়ে সংবেদনশীল ডেটা প্রতিস্থাপন করুন
### সাধারণ দুর্বলতা
- **SQL ইনজেকশন**: ব্যবহারকারীর ইনপুটে ক্ষতিকারক SQL
- **প্রিভিলেজ বৃদ্ধি**: অননুমোদিত অ্যাক্সেস লাভ করা
- **অডিট লগিং**: সমস্ত ডাটাবেস কার্যক্রম ট্র্যাক করুন
- **সম্মতি**: GDPR, HIPAA, PCI-DSS প্রয়োজনীয়তা
## আধুনিক ডেটাবেস প্রযুক্তি
### ক্লাউড ডেটাবেস
- **AWS**: RDS, Aurora, DynamoDB, Redshift
- **গুগল ক্লাউড**: ক্লাউড এসকিউএল, স্প্যানার, বিগটেবল, ফায়ারস্টোর
- **আজির**: SQL ডেটাবেস, কসমস ডিবি, সিন্যাপস
- **সুবিধা**: পরিচালিত পরিষেবা, অটো-স্কেলিং, ব্যাকআপ অন্তর্ভুক্ত
### নিউএসকিউএল ডাটাবেস
- NoSQL স্কেলেবিলিটির সাথে SQL ধারাবাহিকতা একত্রিত করুন
- **উদাহরণ**: CockroachDB, TiDB, YugabyteDB, Google Spanner
- **বৈশিষ্ট্য**: বিতরণ করা, ACID লেনদেন, অনুভূমিক স্কেলিং
### সময়-সিরিজ ডাটাবেস
- টাইমস্ট্যাম্পড ডেটার জন্য অপ্টিমাইজ করা হয়েছে
- **উদাহরণ**: InfluxDB, TimescaleDB, Prometheus
- **ব্যবহারের ক্ষেত্রে**: IoT, পর্যবেক্ষণ, আর্থিক ডেটা
### ভেক্টর ডাটাবেস
- এম্বেডিং ভেক্টর সঞ্চয় করুন এবং অনুসন্ধান করুন
- **উদাহরণ**: Pinecone, Milvus, Weaviate, Qdrant
- **কেস ব্যবহার করুন**: শব্দার্থগত অনুসন্ধান, সুপারিশ সিস্টেম, এআই অ্যাপ্লিকেশন
### মাল্টি-মডেল ডেটাবেস
- একক সিস্টেমে একাধিক ডেটা মডেল সমর্থন করে
- **উদাহরণ**: ArangoDB, OrientDB, Azure Cosmos DB
- **সুবিধা**: একাধিক ডাটাবেস ছাড়া নমনীয়তা
