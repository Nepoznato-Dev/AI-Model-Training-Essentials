## সিস্টেম তৈরি করুন
| টুল | প্রকার | জন্য সেরা |
|------|------|----------|
| **বানান** | ক্লাসিক | সাধারণ প্রকল্প, ইউনিক্স স্ট্যান্ডার্ড |
| **সিমেক** | ক্রস-প্ল্যাটফর্ম | শিল্প মান, জটিল প্রকল্প |
| **মেসন** | আধুনিক | দ্রুত, পরিষ্কার বাক্য গঠন |
| **নিনজা** | দ্রুত | নিম্ন-স্তরের বিল্ড সিস্টেম (CMake দ্বারা ব্যবহৃত) |
| **বেজেল** | স্কেল | Monorepos, Google |
| **xmake** | আধুনিক | লুয়া-ভিত্তিক, ক্রস-প্ল্যাটফর্ম |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## সারাংশ
C এর ইকোসিস্টেম হল আধুনিক কম্পিউটিং এর ভিত্তি। স্ট্যান্ডার্ড টুলচেন হল: সংকলনের জন্য **GCC** বা **ক্ল্যাং**, বিল্ডের জন্য **CMake**, ডিবাগিংয়ের জন্য **GDB**, মেমরি বিশ্লেষণের জন্য **ভালগ্রিন্ড** এবং লিন্টিংয়ের জন্য **ক্ল্যাং-পরিপাটি**। মূল লাইব্রেরির মধ্যে রয়েছে ক্রিপ্টোর জন্য **OpenSSL**, HTTP এর জন্য **libcurl**, ডাটাবেসের জন্য **SQLite**। সি-এর ইকোসিস্টেম ডিজাইনের দ্বারা ন্যূনতম — আপনি যা প্রয়োজন তা তৈরি করেন। আধুনিক উন্নয়নের জন্য, পরীক্ষার সময় সর্বদা স্যানিটাইজার (ASan, UBSan) ব্যবহার করুন।
