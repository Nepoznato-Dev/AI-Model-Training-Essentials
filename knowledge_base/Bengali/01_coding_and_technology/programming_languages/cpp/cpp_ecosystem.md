# C++ — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকা C++ ইকোসিস্টেমের প্রয়োজনীয় টুলস, লাইব্রেরি এবং অবকাঠামো কভার করে।

## কম্পাইলার
| কম্পাইলার | প্ল্যাটফর্ম | নোট |
|----------|----------|-------|
| **GCC (g++)** | লিনাক্স/ইউনিক্স | GNU কম্পাইলার সংগ্রহ, ব্যাপকভাবে ব্যবহৃত |
| **ঝনঝন শব্দ++** | ক্রস-প্ল্যাটফর্ম | LLVM-ভিত্তিক, চমৎকার ডায়াগনস্টিক |
| **MSVC** | উইন্ডোজ | মাইক্রোসফট ভিজ্যুয়াল সি++ কম্পাইলার |
| **Intel oneAPI (icpx)** | ক্রস-প্ল্যাটফর্ম | উচ্চ-কর্মক্ষমতা, HPC ফোকাস |
| **জিগ সি++** | ক্রস-প্ল্যাটফর্ম | দুর্দান্ত ক্রস-সংকলন |
```bash
g++ -std=c++23 -O2 -Wall -Wextra -o app main.cpp
clang++ -std=c++23 -stdlib=libc++ -o app main.cpp
```

## সিস্টেম তৈরি করুন
| টুল | প্রকার | জন্য সেরা |
|------|------|----------|
| **সিমেক** | ক্রস-প্ল্যাটফর্ম | শিল্প মান, অধিকাংশ প্রকল্প |
| **মেসন** | আধুনিক | দ্রুত, পরিষ্কার সিনট্যাক্স, নিনজা ব্যাকএন্ড |
| **বেজেল** | স্কেল | Monorepos, Google-স্কেল |
| **কোনান + সিমেক** | প্যাকেজ সচেতন | C++ প্যাকেজ ব্যবস্থাপনা |
| **xmake** | আধুনিক | লুয়া-ভিত্তিক, অন্তর্নির্মিত প্যাকেজ ম্যানেজার |
| **বানান** | ক্লাসিক | সাধারণ ইউনিক্স প্রকল্প |
| **নিনজা** | দ্রুত | নিম্ন-স্তরের বিল্ড সিস্টেম |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.24)
project(myapp LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(myapp src/main.cpp)
target_compile_features(myapp PRIVATE cxx_std_23)

# Find packages
find_package(fmt REQUIRED)
target_link_libraries(myapp PRIVATE fmt::fmt)
```

## সারাংশ
C++ এর সবচেয়ে ধনী এবং সবচেয়ে জটিল ইকোসিস্টেম রয়েছে। স্ট্যান্ডার্ড টুলচেন হল: সংকলনের জন্য **GCC** বা **ক্ল্যাং**, বিল্ডের জন্য **CMake**, প্যাকেজের জন্য **কোনান** বা **vcpkg**, পরীক্ষার জন্য **গুগল টেস্ট** বা **ক্যাচ2**, লিন্টিংয়ের জন্য **ক্ল্যাং-পরিপাটি**, ডিবাগিংয়ের জন্য **GDB** এবং **UBSannit** এর জন্য। মূল লাইব্রেরিগুলির মধ্যে রয়েছে ইউটিলিটিগুলির জন্য **বুস্ট**, বিন্যাসের জন্য **fmt**, JSON-এর জন্য **nlohmann/json**, লগিংয়ের জন্য **spdlog**, গণিতের জন্য **Eigen** এবং GUI-এর জন্য **Qt**। আধুনিক C++ (20/23) ধারণা, রেঞ্জ, কোরোটিন এবং মডিউলগুলি ইকোসিস্টেমকে রূপান্তরিত করছে। সবসময়`-Wall -Wextra -Werror`দিয়ে কম্পাইল করুন এবং CI-তে স্যানিটাইজার ব্যবহার করুন।
