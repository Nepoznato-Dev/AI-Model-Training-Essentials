# জাভাস্ক্রিপ্ট — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকা জাভাস্ক্রিপ্ট ইকোসিস্টেমের প্রয়োজনীয় টুল, ফ্রেমওয়ার্ক এবং অবকাঠামো কভার করে।

| রানটাইম | পরিবেশ | জন্য সেরা |

| **বন** | সার্ভার/CLI | দ্রুত, অন্তর্নির্মিত বান্ডলার/টেস্ট রানার |
| **ব্রাউজার** | ক্লায়েন্ট-সাইড | ওয়েব অ্যাপ্লিকেশন |

## প্যাকেজ ব্যবস্থাপনা
| টুল | রেজিস্ট্রি | বৈশিষ্ট্য |
|------|------------|----------|
| **npm** | npmjs.com | Node.js এর সাথে ডিফল্ট |
| **সুতা** | npmjs.com | ওয়ার্কস্পেস, PnP মোড |
| **pnpm** | npmjs.com | দ্রুত, ডিস্ক-দক্ষ, কঠোর |
| **বন** | npmjs.com | অতি দ্রুত, অন্তর্নির্মিত |
```bash
npm init -y                   # initialize project
npm install express           # add dependency
npm install -D typescript     # add dev dependency
npm run build                 # run script from package.json
```

## সারাংশ
জাভাস্ক্রিপ্টের ইকোসিস্টেম প্রোগ্রামিং এর মধ্যে সবচেয়ে বড়। আধুনিক স্ট্যাক হল: বিল্ডিংয়ের জন্য **Vite**, প্যাকেজের জন্য **pnpm**, পরীক্ষার জন্য **Vitest**, কোড মানের জন্য **ESLint + Prettier**, ফ্রন্টএন্ডের জন্য **React/Next.js** বা **Vue/Nuxt** এবং স্থাপনার জন্য **Vercel** বা **Cloudflare**। টাইপস্ক্রিপ্ট এখন যেকোনো গুরুতর প্রকল্পের জন্য অপরিহার্য। ইকোসিস্টেম দ্রুত চলে — বর্তমান থাকুন কিন্তু ফ্রেমওয়ার্ক মন্থন এড়িয়ে চলুন।
