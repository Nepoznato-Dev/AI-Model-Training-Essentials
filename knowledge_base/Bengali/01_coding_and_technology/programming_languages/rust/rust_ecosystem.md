# মরিচা — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকাটি জং বাস্তুতন্ত্রের প্রয়োজনীয় সরঞ্জাম, কাঠামো এবং অবকাঠামো কভার করে।
---

## প্যাকেজ ম্যানেজমেন্ট এবং বিল্ড
| টুল | উদ্দেশ্য |
|------|---------|
| **মালপত্র** | প্যাকেজ ম্যানেজার, বিল্ড সিস্টেম, টেস্ট রানার |
| **crates.io** | অফিসিয়াল প্যাকেজ রেজিস্ট্রি |
| **রাস্টআপ** | টুলচেইন ইনস্টলার এবং ম্যানেজার |
| **কার্গো-সম্পাদনা** | নির্ভরতা যোগ/সরান/আপগ্রেড করুন |
| **কার্গো-ঘড়ি** | ফাইল পরিবর্তনের উপর পুনর্নির্মাণ |
| **কার্গো-অডিট** | নিরাপত্তা দুর্বলতা পরীক্ষক |
| **কার্গো-ক্লিপি** | লিন্টার (বিল্ট-ইন) |
| **কার্গো-এফএমটি** | কোড ফরম্যাটার (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## সারাংশ
মরিচা এর ইকোসিস্টেম সুসংহত এবং উচ্চ মানের, কার্গোকে কেন্দ্র করে। স্ট্যান্ডার্ড স্ট্যাক হল: **কার্গো** সবকিছুর জন্য (বিল্ড, পরীক্ষা, প্রকাশ), **টোকিও** অ্যাসিঙ্কের জন্য, **Axum** বা **অ্যাক্টিক্স-ওয়েব** ওয়েবের জন্য, **সারডে** সিরিয়ালাইজেশনের জন্য, **SQLx** ডেটাবেসের জন্য, এবং **ক্ল্যাপ** CLI-এর জন্য। রাস্টের কিলার বৈশিষ্ট্যটি কোনো রানটাইম নির্ভরতা ছাড়াই একক স্ট্যাটিক বাইনারি হিসাবে স্থাপন করছে। ইকোসিস্টেম সুবিধার চেয়ে সঠিকতা এবং কর্মক্ষমতাকে অগ্রাধিকার দেয়।
