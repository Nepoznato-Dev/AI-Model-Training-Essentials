# স্ক্র্যাচ — সংস্করণ ইতিহাস এবং বিবর্তন
## টাইমলাইন
| সংস্করণ | বছর | মূল থিম |
|---------|------|------------|
| প্রাক স্ক্র্যাচ | 2003 | এমআইটি মিডিয়া ল্যাবে স্ক্র্যাচ টিম ফর্ম |
| স্ক্র্যাচ 1.0 | 2007 | **প্রাথমিক প্রকাশ** — বাচ্চাদের জন্য ভিজ্যুয়াল প্রোগ্রামিং |
| স্ক্র্যাচ 1.4 | 2009 | উন্নত গ্রাফিক্স, আরো ব্লক |
| স্ক্র্যাচ 2.0 | 2013 | **মেজর**: ওয়েব-ভিত্তিক সম্পাদক, ক্লাউড ভেরিয়েবল, ব্যাকপ্যাক |
| স্ক্র্যাচ 3.0 | 2019 | **মেজর**: সম্পূর্ণ পুনর্লিখন (HTML5/JS), এক্সটেনশন, কলম |
| স্ক্র্যাচ 3.x | 2019-25 | ভিডিও সেন্সিং, টেক্সট-টু-স্পীচ, অনুবাদ, মাইক্রো:বিট |
| স্ক্র্যাচ জুনিয়র | 2014 | ছোট শিশুদের জন্য সরলীকৃত সংস্করণ (5-7) |
| স্ক্র্যাচ ডেস্কটপ | 2020 | অফলাইন সম্পাদক (ইলেক্ট্রন-ভিত্তিক) |
## প্রধান মাইলফলক
### উৎপত্তি (2003-2006)
- **2003**: MIT মিডিয়া ল্যাবের লাইফলং কিন্ডারগার্টেন গ্রুপ স্ক্র্যাচ ডেভেলপমেন্ট শুরু করেছে
- মিচেল রেসনিকের নেতৃত্বে
- **লক্ষ্য**: ভিজ্যুয়াল ব্লকের মাধ্যমে বাচ্চাদের প্রোগ্রামিং শেখান
- দ্বারা অনুপ্রাণিত: লোগো (সেইমোর পেপার), লেগো লোগো, স্কুইক ইটয়স
- নাম: "স্ক্র্যাচ" — ডিজে স্ক্র্যাচিং থেকে (মিডিয়া একসাথে মিশ্রিত করা)
### স্ক্র্যাচ 1.0 (2007)
- **2007**: প্রথম পাবলিক রিলিজ
- ড্র্যাগ-এন্ড-ড্রপ ব্লক প্রোগ্রামিং
- স্প্রাইট-ভিত্তিক প্রকল্প (অক্ষর, অ্যানিমেশন)
- শব্দ, গ্রাফিক্স, অ্যানিমেশন
- বিল্ট ইন স্কুইক (স্মলটক)
- **লক্ষ্য**: বয়স 8-16, কিন্তু অনেক ব্যাপকভাবে গ্রহণ করা হয়েছে
### স্ক্র্যাচ 1.4 (2009)
- উন্নত গ্রাফিক্স রেন্ডারিং
- আরো পরী লাইব্রেরি
- ভাল শব্দ সমর্থন
- Squeak-এ নির্মিত শেষ সংস্করণ
### স্ক্র্যাচ 2.0 (2013)
- **সম্পূর্ণ ওয়েব-ভিত্তিক সম্পাদক** — ব্রাউজারে চলে
- ক্লাউড ভেরিয়েবল - প্রকল্পগুলির মধ্যে ডেটা ভাগ করে
- ব্যাকপ্যাক - প্রকল্পগুলির মধ্যে স্প্রাইট/স্ক্রিপ্ট শেয়ার করুন
- কাস্টম ব্লক (যেমন ফাংশন)
- বিল্ট ইন অ্যাকশনস্ক্রিপ্ট 3 (ফ্ল্যাশ)
- সম্প্রদায় বৈশিষ্ট্য: রিমিক্স, শেয়ার, মন্তব্য
### স্ক্র্যাচ 3.0 (2019)
- **সম্পূর্ণ পুনর্লিখন** — HTML5/জাভাস্ক্রিপ্ট (কোনও ফ্ল্যাশ নেই)
- ট্যাবলেট, ফোন, Chromebook এ কাজ করে
- **এক্সটেনশন**:
  - কলম (অঙ্কন)
  - ভিডিও সেন্সিং (ক্যামেরা)
  - টেক্সট টু স্পিচ
  - অনুবাদ (গুগল অনুবাদ)
  - মাইক্রো: বিট (হার্ডওয়্যার)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- সাউন্ড এডিটর উন্নতি
- নতুন পেইন্ট এডিটর (ভেক্টর + বিটম্যাপ)
- ব্যাকপ্যাক, মেঘ ভেরিয়েবল বজায় রাখা
### স্ক্র্যাচ ডেস্কটপ এবং এর বাইরে (2020-বর্তমান)
- **2020**: স্ক্র্যাচ ডেস্কটপ — অফলাইন সম্পাদক (ইলেক্ট্রন-ভিত্তিক)
- অবিরত এক্সটেনশন উন্নয়ন
- এআই/এমএল এক্সটেনশন (সম্প্রদায় দ্বারা তৈরি)
- শারীরিক কম্পিউটিংয়ের সাথে একীকরণ (মাইক্রো: বিট, আরডুইনো)
## ব্লক বিভাগ বিবর্তন
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## প্রোগ্রামিং ধারণা শেখানো হয়
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## মূল ডিজাইনের নীতি
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
