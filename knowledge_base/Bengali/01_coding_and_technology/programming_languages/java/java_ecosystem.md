# জাভা — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকা জাভা ইকোসিস্টেমের প্রয়োজনীয় টুলস, ফ্রেমওয়ার্ক এবং অবকাঠামো কভার করে।

## বিল্ড টুলস
| টুল | প্রকার | জন্য সেরা |
|------|------|----------|
| **মাভেন** | XML-ভিত্তিক | এন্টারপ্রাইজ, কনভেনশন ওভার কনফিগারেশন |
| **গ্রেডল** | গ্রোভি/কোটলিন ডিএসএল | নমনীয়, অ্যান্ড্রয়েড, বড় প্রকল্প |
| **পিঁপড়া** | XML-ভিত্তিক | উত্তরাধিকার প্রকল্প |

```bash
# Maven
mvn clean install               # build
mvn test                        # run tests
mvn package                     # create JAR/WAR

# Gradle
./gradlew build                 # build
./gradlew test                  # run tests
./gradlew bootRun               # run Spring Boot app
```

| **মকিটো** | উপহাস |
| **AssertJ** | সাবলীল দাবী |
| **পরীক্ষার পাত্র** | ডকার-ভিত্তিক ইন্টিগ্রেশন পরীক্ষা |
| **ওয়্যারমক** | HTTP API উপহাস |
| **আর্চইউনিট** | স্থাপত্য পরীক্ষা |
| **আশ্বস্ত** | REST API টেস্টিং |
| **জেএমএইচ** | মাইক্রোবেঞ্চমার্কিং |
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;
    @InjectMocks UserService service;

    @Test
    void shouldFindUserById() {
        when(repo.findById(1L)).thenReturn(Optional.of(new User("Alice")));
        var user = service.findById(1L);
        assertThat(user.name()).isEqualTo("Alice");
    }
}
```

## সারাংশ
জাভা এর ইকোসিস্টেম এন্টারপ্রাইজ কম্পিউটিং সবচেয়ে পরিপক্ক. স্ট্যান্ডার্ড স্ট্যাক হল: বিল্ডের জন্য **Gradle** বা **Maven**, ওয়েব/মাইক্রোসার্ভিসের জন্য **স্প্রিং বুট**, পরীক্ষার জন্য **JUnit 5 + Mockito**, ORM-এর জন্য **Hibernate**, IDE হিসেবে **IntelliJ IDEA**, এবং **Docker** স্থাপনের জন্য। জাভার শক্তি হল এর বিশাল ইকোসিস্টেম, এন্টারপ্রাইজ সমর্থন এবং পিছনের সামঞ্জস্য। রেকর্ড, সিল করা ক্লাস, প্যাটার্ন ম্যাচিং এবং ভার্চুয়াল থ্রেড সহ আধুনিক জাভা (17+) ভাষাকে পুনরুজ্জীবিত করছে।
