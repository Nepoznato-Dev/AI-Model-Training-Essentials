# টাইপস্ক্রিপ্ট — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকাটি TypeScript ইকোসিস্টেমের প্রয়োজনীয় টুল, ফ্রেমওয়ার্ক এবং অবকাঠামো কভার করে। টাইপস্ক্রিপ্ট জাভাস্ক্রিপ্টের সাথে তার ইকোসিস্টেমের বেশিরভাগ অংশ শেয়ার করে কিন্তু তার নিজস্ব বিশেষ সরঞ্জাম রয়েছে।
---

## কম্পাইলার এবং টাইপ চেকিং
| টুল | উদ্দেশ্য |
|------|---------|
| **tsc** | অফিসিয়াল টাইপস্ক্রিপ্ট কম্পাইলার |
| **ts-নোড** | সরাসরি TS চালান (dev) |
| **tsx** | দ্রুত টিএস এক্সিকিউশন (এসবিল্ড) |
| **SWC** | মরিচা-ভিত্তিক কম্পাইলার |
| **নির্মাণ** | TS সমর্থন সহ আল্ট্রা-ফাস্ট বান্ডলার |
| **টাইপস্ক্রিপ্ট SDK** | IDE ইন্টিগ্রেশন |
```bash
tsc --init                      # create tsconfig.json
tsc --noEmit                    # type-check only
tsc --watch                     # watch mode
tsx src/index.ts                # run TypeScript directly
```

## প্যাকেজ ব্যবস্থাপনা
জাভাস্ক্রিপ্টের মতোই: **npm**, **pnpm**, **সুতা**, **বন**। TypeScript npm রেজিস্ট্রি ব্যবহার করে ( টাইপ সংজ্ঞার জন্য`@types/*`প্যাকেজ)।
```bash
npm install -D @types/node @types/express  # type definitions
npx typesync                               # auto-install missing types
```

## ফুল-স্ট্যাক টাইপ নিরাপত্তা
| টুল | উদ্দেশ্য |
|------|---------|
| **tRPC** | কোডজেন ছাড়া এন্ড-টু-এন্ড প্রকার |
| **জোড** | রানটাইম বৈধতা + প্রকার অনুমান |
| **প্রিজমা** | টাইপ-সেফ ORM |
| **গুঁড়ি গুঁড়ি* | টাইপ-নিরাপদ SQL |
| **ওপেনএপিআই + কোডজেন** | API টাইপ প্রজন্ম |
```typescript
// Zod: runtime validation with type inference
import { z } from "zod";

const UserSchema = z.object({
  name: z.string().min(2),
  email: z.string().email(),
  age: z.number().int().positive(),
});

type User = z.infer<typeof UserSchema>;
// { name: string; email: string; age: number; }

const user = UserSchema.parse(data); // throws if invalid
```

## সারাংশ
টাইপস্ক্রিপ্টের ইকোসিস্টেম জাভাস্ক্রিপ্টের বিশাল লাইব্রেরি ব্যবহার করে টাইপ নিরাপত্তা যোগ করার সময়। আধুনিক স্ট্যাক হল: **বিল্ডিংয়ের জন্য **ভিটে**, পরীক্ষার জন্য **ভিটেস্ট**, লিন্টিংয়ের জন্য **টাইপস্ক্রিপ্ট-এসলিন্ট**, রানটাইম যাচাইকরণের জন্য **জোড**, এন্ড-টু-এন্ড টাইপ সেফটির জন্য **tRPC**, টাইপ-সেফ ডাটাবেস অ্যাক্সেসের জন্য **প্রিজমা** বা **ড্রিজল**, এবং **Next** বা ফ্রেমওয়ার্কের জন্য **Next** টাইপস্ক্রিপ্টের সুপারপাওয়ার জাভাস্ক্রিপ্ট ইকোসিস্টেমের প্রশস্ততা বজায় রেখে কম্পাইলের সময় বাগ ধরছে।
