# সমাবেশ — ইকোসিস্টেম এবং টুলিং গাইড
এই নির্দেশিকাটি অ্যাসেম্বলি ইকোসিস্টেমের প্রয়োজনীয় টুলস, অ্যাসেম্বলার এবং অবকাঠামো কভার করে।

## স্থাপত্য দ্বারা অ্যাসেম্বলার
### x86/x86-64
| সংযোজনকারী | প্ল্যাটফর্ম | নোট |
|------------|----------|---------|
| **NASM** | ক্রস-প্ল্যাটফর্ম | সর্বাধিক জনপ্রিয়, পরিষ্কার বাক্য গঠন |
| **MASM** | উইন্ডোজ | মাইক্রোসফট ম্যাক্রো অ্যাসেম্বলার |
| **FASM** | ক্রস-প্ল্যাটফর্ম | স্ব-হোস্টিং, দ্রুত |
| **GAS (as)** | লিনাক্স/ইউনিক্স | GNU অ্যাসেম্বলার (AT&T সিনট্যাক্স) |
| **ইয়াসম** | ক্রস-প্ল্যাটফর্ম | NASM- সামঞ্জস্যপূর্ণ |
| **ইউএএসএম** | ক্রস-প্ল্যাটফর্ম | MASM- সামঞ্জস্যপূর্ণ |
### এআরএম
| সংযোজনকারী | প্ল্যাটফর্ম | নোট |
|------------|----------|---------|
| **GNU as (ARM)** | ক্রস-প্ল্যাটফর্ম | এআরএম সমাবেশ |
| **কেল এএসএম** | এমবেডেড | এআরএম উন্নয়ন |
| **আর্ম অ্যাসেম্বলার** | এআরএম | ARM কম্পাইলার স্যুট |
### অন্যান্য
| সংযোজনকারী | স্থাপত্য | নোট |
|------------|---------------|---------|
| **avr-as** | AVR | মাইক্রোকন্ট্রোলার |
| **রাসম** | Z80 | বিপরীতমুখী কম্পিউটিং |
| **ca65** | 6502 | এনইএস, কমোডর |
| **স্পিম / মার্স** | MIPS | শিক্ষাগত |
```bash
# NASM (Linux x86-64)
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# NASM (Windows)
nasm -f win64 hello.asm -o hello.obj
golink /console /entry _start hello.obj

# FASM
fasm hello.asm hello

# GAS (AT&T syntax)
as -o hello.o hello.s
ld hello.o -o hello
```

## ডিবাগার
| টুল | স্থাপত্য | উদ্দেশ্য |
|------|---------------|---------|
| **GDB** | x86/ARM | GNU ডিবাগার |
| **lldb** | ক্রস-প্ল্যাটফর্ম | LLVM ডিবাগার |
| **x64dbg** | x86/x86-64 | Windows GUI ডিবাগার |
| **অলিডিবিজি** | x86 | ক্লাসিক উইন্ডোজ ডিবাগার |
| **আইডিএ প্রো** | ক্রস-প্ল্যাটফর্ম | Disassembler/decompiler |
| **গিদ্র** | ক্রস-প্ল্যাটফর্ম | এনএসএ রিভার্স ইঞ্জিনিয়ারিং |
| **radare2** | ক্রস-প্ল্যাটফর্ম | CLI রিভার্স ইঞ্জিনিয়ারিং |
| **কাটার** | ক্রস-প্ল্যাটফর্ম | radare2 এর জন্য GUI |
```bash
# GDB
gdb ./hello
(gdb) break main
(gdb) run
(gdb) info registers
(gdb) stepi
(gdb) x/10i $rip        # disassemble 10 instructions

# x64dbg (Windows)
# GUI-based, load executable, set breakpoints, step through
```

## বিল্ড টুলস
| টুল | উদ্দেশ্য |
|------|---------|
| **বানান** | ক্লাসিক বিল্ড অটোমেশন |
| **সিমেক** | ক্রস-প্ল্যাটফর্ম তৈরি করে |
| **ld** | GNU লিঙ্কার |
| **lld** | LLVM লিঙ্কার |
| **অবজকপি** | বাইনারি ম্যানিপুলেশন |
| **objdump** | বিচ্ছিন্ন করা |
| **রিডেলফ / এনএম** | প্রতীক পরিদর্শন |
| **হেক্সডাম্প** | বাইনারি পরিদর্শন |
```makefile
# Makefile for NASM project
ASM = nasm
ASM_FLAGS = -f elf64
LD = ld
TARGET = hello

all: $(TARGET)

$(TARGET): hello.o
	$(LD) hello.o -o $(TARGET)

hello.o: hello.asm
	$(ASM) $(ASM_FLAGS) hello.asm -o hello.o

clean:
	rm -f *.o $(TARGET)
```

## পরীক্ষা
| টুল | উদ্দেশ্য |
|------|---------|
| **কাস্টম টেস্ট জোতা** | সমাবেশ পরীক্ষার কাঠামো |
| **ঐক্য** | সি-ভিত্তিক ইউনিট পরীক্ষা (মিশ্র প্রকল্পের জন্য) |
| **গুগল টেস্ট** | C++ পরীক্ষা (মিশ্র প্রকল্পের জন্য) |
| **কাস্টম ম্যাক্রো** | দাবী ম্যাক্রো |
```nasm
; NASM test example
section .data
    test_pass db "PASS", 10, 0
    test_fail db "FAIL", 10, 0

section .text
    global _start

test_add:
    mov rax, 2
    mov rbx, 3
    add rax, rbx
    cmp rax, 5
    jne .fail
    ; print pass
    mov rax, 1
    mov rdi, 1
    mov rsi, test_pass
    mov rdx, 5
    syscall
    ret
.fail:
    mov rax, 1
    mov rdi, 1
    mov rsi, test_fail
    mov rdx, 5
    syscall
    ret

_start:
    call test_add
    mov rax, 60
    xor rdi, rdi
    syscall
```

## সারাংশ
সমাবেশের ইকোসিস্টেমটি স্থাপত্য-নির্দিষ্ট এবং নকশা দ্বারা ন্যূনতম। স্ট্যান্ডার্ড টুলচেন হল: **NASM** (x86/x86-64) বা **GNU as** (ARM), অ্যাসেম্বলির জন্য **ld** লিঙ্ক করার জন্য, **GDB** ডিবাগিংয়ের জন্য, **Ghidra** বা **IDA Pro** রিভার্স ইঞ্জিনিয়ারিংয়ের জন্য এবং **QEMU** অনুকরণের জন্য। অপারেটিং সিস্টেম ডেভেলপমেন্ট, এমবেডেড সিস্টেম, রিভার্স ইঞ্জিনিয়ারিং, পারফরম্যান্স-ক্রিটিকাল কোড এবং বুটলোডার ডেভেলপমেন্টে অ্যাসেম্বলি এক্সেল। কম্পিউটার কীভাবে সর্বনিম্ন স্তরে কাজ করে তা বোঝার জন্য ইকোসিস্টেম অপরিহার্য। শেখার জন্য, **MARS** (MIPS) এবং **SASM** (x86) শিক্ষানবিস-বান্ধব পরিবেশ প্রদান করে।
