# স্নায়ুবিজ্ঞান
স্নায়ুবিজ্ঞান হল স্নায়ুতন্ত্রের অধ্যয়ন — মস্তিষ্ক, মেরুদন্ড, এবং সমস্ত স্নায়ু যা তাদের শরীরের সাথে সংযুক্ত করে। এটি একাধিক স্তর বিস্তৃত করে: অণু এবং জিন থেকে, পৃথক নিউরন এবং সিন্যাপ্স, সার্কিট এবং মস্তিষ্কের অঞ্চল, আচরণ, জ্ঞান এবং চেতনা পর্যন্ত। মস্তিষ্ক হল পরিচিত মহাবিশ্বের সবচেয়ে জটিল গঠন, যার মধ্যে প্রায় 86 বিলিয়ন নিউরন ট্রিলিয়ন ট্রিলিয়ন সিন্যাপ্স দ্বারা সংযুক্ত, এবং এটি কীভাবে কাজ করে তা বোঝা বিজ্ঞানের অন্যতম বড় চ্যালেঞ্জ।
---

## নিউরন
### একটি নিউরনের অংশ
| উপাদান | ফাংশন |
|------------|----------|
| **ডেনড্রাইট** | অন্যান্য নিউরন থেকে সংকেত গ্রহণ; শাখার মত এক্সটেনশন |
| **কোষ শরীর (সোমা)** | ইনকামিং সংকেত সংহত করে; নিউক্লিয়াস ধারণ করে |
| **অ্যাক্সন** | দীর্ঘ ফাইবার যা সোমা থেকে দূরে বৈদ্যুতিক সংকেত (অ্যাকশন পটেনশিয়াল) প্রেরণ করে
| **মাইলিন খাপ** | অ্যাক্সনগুলির চারপাশে অন্তরক স্তর; সংকেত সংক্রমণ গতি বাড়ায় |
| **র্যানভিয়ারের নোড** | মাইলিন মধ্যে ফাঁক; লবণাক্ত সঞ্চালনের অনুমতি দিন (নোডের মধ্যে সংকেত জাম্প) |
| **অ্যাক্সন টার্মিনাল (সিনাপটিক বাউটন)** | সিন্যাপসে নিউরোট্রান্সমিটার ছেড়ে দিন |
### নিউরনের প্রকারভেদ
| প্রকার | দিকনির্দেশ | ফাংশন |
|------|------------|----------|
| **সংবেদনশীল (অ্যাফারেন্ট)** | শরীর → মস্তিষ্ক | ইন্দ্রিয় থেকে তথ্য বহন (স্পর্শ, তাপমাত্রা, ব্যথা, দৃষ্টি, ইত্যাদি) |
| **মোটর (এফারেন্ট)** | মস্তিষ্ক → শরীর | পেশী এবং গ্রন্থি নিয়ন্ত্রণ |
| **ইন্টারনিউরন** | CNS এর মধ্যে | অন্যান্য নিউরনের সাথে নিউরন সংযুক্ত করুন; বেশিরভাগ নিউরন হল ইন্টারনিউরন |

## কিভাবে নিউরন যোগাযোগ করে
### অ্যাকশন পটেনশিয়াল
| পর্যায় | বর্ণনা |
|-------|---------------|
| **বিশ্রামের সম্ভাবনা** | নিউরন ~-70 mV এ থাকে; সোডিয়াম-পটাসিয়াম পাম্প আয়নের ভারসাম্য বজায় রাখে |
| **বিধ্বংসীকরণ** | উদ্দীপনা সোডিয়াম চ্যানেল খোলে; Na+ ছুটে আসে; ঝিল্লি সম্ভাব্য বৃদ্ধি |
| **থ্রেশহোল্ড** | পটেনশিয়াল ~-55 mV এ পৌঁছালে, একটি অ্যাকশন পটেনশিয়াল আগুন (সব-বা-কিছুই) |
| **রাইজিং ফেজ** | ভোল্টেজ-গেটেড সোডিয়াম চ্যানেল খোলা; সম্ভাব্য স্পাইক ~+40 mV |
| **পতনের পর্যায়** | সোডিয়াম চ্যানেল বন্ধ; পটাসিয়াম চ্যানেল খোলা; K+ প্রবাহিত হয়; সম্ভাব্য ফোঁটা |
| **আন্ডারশুট (হাইপারপোলারাইজেশন)** | সম্ভাব্য সংক্ষিপ্তভাবে বিশ্রামের স্তরের নিচে নেমে যায় |
| **অবাধ্য সময়** | নিউরন অবিলম্বে আবার আগুন দিতে পারে না; একমুখী প্রচার নিশ্চিত করে |
### সিন্যাপ্স
| উপাদান | ভূমিকা |
|------------|------|
| **প্রিসিন্যাপটিক নিউরন** | সংকেত পাঠায়; নিউরোট্রান্সমিটার সহ সিনাপটিক ভেসিকেল রয়েছে
| **সিনাপটিক ফাট** | নিউরনের মধ্যে ক্ষুদ্র ব্যবধান (~20 nm) |
| **পোস্টসিন্যাপটিক নিউরন** | সংকেত গ্রহণ করে; রিসেপ্টর প্রোটিন আছে |
| **নিউরোট্রান্সমিটার** | রাসায়নিক বার্তাবাহক যা সিন্যাপস অতিক্রম করে |
| **রিসেপ্টর** | নিউরোট্রান্সমিটার বাঁধাই; আয়ন চ্যানেল খুলুন বা দ্বিতীয় মেসেঞ্জার ক্যাসকেড ট্রিগার করুন |

## মূল নিউরোট্রান্সমিটার
| নিউরোট্রান্সমিটার | ফাংশন | সংশ্লিষ্ট শর্তাবলী |
|-------------------|------------|----------------------|
| **গ্লুটামেট** | প্রধান উত্তেজক নিউরোট্রান্সমিটার; শিখন স্মৃতি | অতিরিক্ত → এক্সিটোটক্সিসিটি (স্ট্রোক, নিউরোডিজেনারেশন) |
| **গাবা** | প্রধান নিরোধক নিউরোট্রান্সমিটার; স্নায়বিক কার্যকলাপ হ্রাস করে | ঘাটতি → উদ্বেগ, মৃগীরোগ |
| **ডোপামিন** | পুরস্কার; প্রেরণা মোটর নিয়ন্ত্রণ; মনোযোগ | ঘাটতি → পারকিনসনস; অতিরিক্ত → সিজোফ্রেনিয়া |
| **সেরোটোনিন** | মেজাজ; ঘুম ক্ষুধা হজম | ঘাটতি → বিষণ্নতা, উদ্বেগ |
| **এসিটাইলকোলিন** | পেশী সক্রিয়করণ; শিখন স্মৃতি | ঘাটতি → আলঝেইমার রোগ |
| **নোরেপাইনফ্রাইন** | উত্তেজনা; সতর্কতা চাপ প্রতিক্রিয়া | অনিয়ন্ত্রণ → ADHD; বিষণ্নতা |
| **এন্ডরফিন** | ব্যথা উপশম; আনন্দ | ব্যায়াম-প্ররোচিত মুক্তি ("রানার উচ্চ") |

## জ্ঞানীয় স্নায়ুবিজ্ঞান
### মূল জ্ঞানীয় ফাংশন এবং তাদের মস্তিষ্কের অঞ্চল
| ফাংশন | প্রাথমিক মস্তিষ্ক এলাকা |
|------------|---------|
| **মনোযোগ** | প্রিফ্রন্টাল কর্টেক্স; প্যারিটাল কর্টেক্স; থ্যালামাস |
| **ওয়ার্কিং মেমরি** | প্রিফ্রন্টাল কর্টেক্স; প্যারিটাল কর্টেক্স |
| **দীর্ঘমেয়াদী স্মৃতি** | হিপ্পোক্যাম্পাস (গঠন); কর্টেক্স (সঞ্চয়স্থান) |
| **ভাষা** | ব্রোকার এলাকা (উৎপাদন); Wernicke এর এলাকা (বোধগম্যতা) |
| **আবেগ নিয়ন্ত্রণ** | প্রিফ্রন্টাল কর্টেক্স; অ্যামিগডালা; ventromedial PFC |
| **সিদ্ধান্ত গ্রহণ** | প্রিফ্রন্টাল কর্টেক্স; অরবিফ্রন্টাল কর্টেক্স; স্ট্রিয়াটাম |
| **ভিজ্যুয়াল প্রসেসিং** | অক্সিপিটাল লোব → ভেন্ট্রাল স্ট্রিম ("কি") এবং ডোরসাল স্ট্রিম ("কোথায়") |
| **মোটর নিয়ন্ত্রণ** | মোটর কর্টেক্স; সেরিবেলাম; বেসাল গ্যাংলিয়া |
### মস্তিষ্কের তরঙ্গ
| ঢেউ | ফ্রিকোয়েন্সি | অ্যাসোসিয়েটেড স্টেট |
|------|------------|-----------------|
| **ডেল্টা** | 0.5–4 Hz | গভীর ঘুম |
| **থেটা** | 4–8 Hz | হালকা ঘুম; ধ্যান তন্দ্রা |
| **আলফা** | 8–13 Hz | শিথিল জাগরণ; চোখ বন্ধ |
| **বেটা** | 13–30 Hz | সক্রিয় চিন্তাভাবনা; ফোকাস সতর্কতা |
| **গামা** | 30–100 Hz | উচ্চতর জ্ঞান; বাঁধাই চেতনা |

## নিউরোপ্লাস্টিসিটি
| প্রকার | বর্ণনা | উদাহরণ |
|------|---------------|---------|
| **সিনাপটিক প্লাস্টিকতা** | ক্রিয়াকলাপের সাথে সিন্যাপ্সের শক্তি পরিবর্তিত হয় | দীর্ঘমেয়াদী সম্ভাবনা (LTP); দীর্ঘমেয়াদী বিষণ্নতা (LTD) |
| **কাঠামোগত প্লাস্টিকতা** | নিউরন নতুন ডেনড্রাইট বা অ্যাক্সন জন্মায় | নতুন দক্ষতা শেখা; আঘাত থেকে পুনরুদ্ধার |

## সারাংশ
স্নায়ুবিজ্ঞান প্রতিটি স্তরে স্নায়ুতন্ত্রের অধ্যয়ন করে — আয়ন চ্যানেলের আণবিক প্রক্রিয়া থেকে চেতনার বিষয়গত অভিজ্ঞতা পর্যন্ত। নিউরনগুলি গ্লুটামেট, GABA, ডোপামিন এবং সেরোটোনিনের মতো নিউরোট্রান্সমিটার ব্যবহার করে বৈদ্যুতিক অ্যাকশন পটেনশিয়াল এবং রাসায়নিক সিন্যাপসের মাধ্যমে যোগাযোগ করে। মস্তিষ্ক বিশেষ অঞ্চলে সংগঠিত: উচ্চতর জ্ঞানের জন্য কর্টেক্স, আবেগ এবং স্মৃতির জন্য লিম্বিক সিস্টেম, সমন্বয়ের জন্য সেরিবেলাম। নিউরোপ্লাস্টিসিটি মানে মস্তিষ্ক সারা জীবন নিজেকে পুনরায় চালিত করতে পারে। গবেষণা পদ্ধতিগুলি এফএমআরআই (ভাল স্থানিক রেজোলিউশন) থেকে ইইজি (ভাল অস্থায়ী রেজোলিউশন) থেকে অপটোজেনেটিক্স (সুনির্দিষ্ট কার্যকারণ নিয়ন্ত্রণ) পর্যন্ত। মস্তিষ্ক বোঝা যুক্তিযুক্তভাবে বিজ্ঞানের সবচেয়ে কঠিন সমস্যা - এটিই একমাত্র অঙ্গ যা নিজেই অধ্যয়ন করে।
