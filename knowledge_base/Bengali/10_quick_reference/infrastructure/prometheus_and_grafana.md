# প্রমিথিউস এবং গ্রাফানা
প্রমিথিউস হল একটি ওপেন সোর্স মনিটরিং এবং সতর্ককারী টুলকিট যা নির্ভরযোগ্যতা এবং মাপযোগ্যতার জন্য ডিজাইন করা হয়েছে। গ্রাফানা হল টাইম-সিরিজ ডেটা ভিজ্যুয়ালাইজ করার জন্য নেতৃস্থানীয় ওপেন সোর্স প্ল্যাটফর্ম। একসাথে, তারা আধুনিক অবকাঠামো এবং অ্যাপ্লিকেশনগুলির জন্য সবচেয়ে জনপ্রিয় পর্যবেক্ষণ স্ট্যাক গঠন করে। প্রমিথিউস মেট্রিক্স সংগ্রহ ও সঞ্চয় করে; Grafana তাদের ড্যাশবোর্ডে প্রদর্শন করে।
---

## প্রমিথিউস আর্কিটেকচার
| উপাদান | বর্ণনা |
|------------|-------------|
| **প্রমিথিউস সার্ভার** | লক্ষ্য থেকে মেট্রিক্স স্ক্র্যাপ; সময়-সিরিজ ডেটা সঞ্চয় করে; সতর্কতা নিয়ম মূল্যায়ন করে |
| **রপ্তানিকারক** | একটি সিস্টেম থেকে মেট্রিক্স প্রকাশ করে (নোড এক্সপোর্টার, সিএডভাইজার, ইত্যাদি) |
| **পুশগেটওয়ে** | স্বল্পকালীন চাকরি (ব্যাচ জব, CI) থেকে মেট্রিক্স গ্রহণ করে |
| **সতর্ক ব্যবস্থাপক** | সতর্কতা পরিচালনা করে: গ্রুপিং, সাইলেন্সিং, রাউটিং, ইনহিবিশন |
| **পরিষেবা আবিষ্কার** | স্বয়ংক্রিয়ভাবে লক্ষ্যগুলি আবিষ্কার করে (Kubernetes, Consul, EC2, ইত্যাদি) |

| **নমুনা** | সময়ের একটি বিন্দুতে একটি মান: (টাইমস্ট্যাম্প, মান) |

## PromQL (কোয়েরি ভাষা)
### মৌলিক প্রশ্ন
| প্রশ্ন | বর্ণনা |
|-------|---------------|
| `http_requests_total`| কাঁচা সময় সিরিজ |
| `http_requests_total{method="GET"}`| লেবেল দ্বারা ফিল্টার |
| `http_requests_total{method="GET", status="200"}`| একাধিক লেবেল ফিল্টার |
| `rate(http_requests_total[5m])`| 5 মিনিটের বেশি প্রতি সেকেন্ডের হার |
| `increase(http_requests_total[1h])`| 1 ঘন্টার মধ্যে মোট বৃদ্ধি |
| `sum(rate(http_requests_total[5m])) by (status)`| স্ট্যাটাস দ্বারা মোট হার |
| `histogram_quantile(0.95, rate(http_duration_bucket[5m]))`| 95তম পার্সেন্টাইল লেটেন্সি |
| `avg(node_cpu_seconds_total{mode="idle"})`| গড় CPU নিষ্ক্রিয় |
| `1 - avg(rate(node_cpu_seconds_total{mode="idle"}[5m]))`| CPU ব্যবহার |
### সাধারণ ফাংশন
| ফাংশন | বর্ণনা | উদাহরণ |
|------------|---------------|---------|
| `rate()`| প্রতি সেকেন্ডে গড় বৃদ্ধির হার | `rate(requests_total[5m])`|
| `irate()`| শেষ দুটি ডেটা পয়েন্টের উপর ভিত্তি করে প্রতি-সেকেন্ডের হার | `irate(requests_total[1m])`|
| `increase()`| সময়ের পরিসরে মোট বৃদ্ধি | `increase(errors_total[1h])`|
| `sum()`| সিরিজ জুড়ে যোগফল | `sum(rate(requests_total[5m])) by (service)`|
| `avg()`| সিরিজ জুড়ে গড় | `avg(node_memory_usage)`|
| `histogram_quantile()`| হিস্টোগ্রাম থেকে কোয়ান্টাইল গণনা করুন | `histogram_quantile(0.99, rate(duration_bucket[5m]))`|
| `topk()`| মান অনুসারে শীর্ষ K সিরিজ | `topk(5, rate(requests_total[5m]))`|
| `predict_linear()`| রৈখিক ভবিষ্যদ্বাণী | `predict_linear(disk_usage[1h], 4*3600)`|
| `absent()`| মেট্রিক অনুপস্থিত কিনা পরীক্ষা করুন | `absent(up{job="myapp"})`|

## সতর্কতা
### সতর্কতা নিয়ম কাঠামো
```yaml
groups:
  - name: example
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate on {{ $labels.instance }}"
          description: "Error rate is {{ $value | humanizePercentage }}"
```

### অ্যালার্ট ম্যানেজার রাউটিং
| ধারণা | বর্ণনা |
|---------|---------------|
| **গ্রুপ** | একটি বিজ্ঞপ্তিতে অনুরূপ সতর্কতা একত্রিত করুন |
| **রুট** | ম্যাচার্সের গাছ যা সতর্কতা কোথায় যায় তা নির্ধারণ করে
| **রিসিভার** | কোথায় সতর্কতা পাঠাতে হবে (ইমেল, স্ল্যাক, পেজারডিউটি, ওয়েবহুক) |
| **নিষেধ** | অন্য সতর্কতা গুলি চালানো হলে সতর্কতা দমন করুন |
| **নিরবতা** | লেবেল ম্যাচার দ্বারা অস্থায়ীভাবে নিঃশব্দ সতর্কতা |

| **পুনঃসূচনা করার পরে অনুপস্থিত মেট্রিক** | প্রমিথিউস স্থানীয়ভাবে তথ্য সংরক্ষণ করে; ধরে রাখার সেটিংস চেক করুন |

## সারাংশ
প্রমিথিউস নিয়মিত বিরতিতে রপ্তানিকারকদের কাছ থেকে মেট্রিক্স স্ক্র্যাপ করে সিস্টেমগুলি পর্যবেক্ষণ করে। মেট্রিক্স চার প্রকারে আসে: কাউন্টার (শুধু উপরে যায়), গেজ (উপর এবং নিচে), হিস্টোগ্রাম (বাকেটেড পর্যবেক্ষণ), এবং সারাংশ (পরিমাণ)। PromQL হল ক্যোয়ারী ভাষা —`rate()`,`increase()`,`histogram_quantile()`, এবং একত্রীকরণ ফাংশন (`sum`,`avg`) হল সবচেয়ে সাধারণ ক্রিয়াকলাপ৷ গ্রাফানা প্যানেল, ভেরিয়েবল এবং টীকা সহ ড্যাশবোর্ডে প্রমিথিউস ডেটা ভিজ্যুয়ালাইজ করে। অ্যালার্টিং গ্রুপিং, রাউটিং, সাইলেন্সিং এবং অ্যালার্ট ইনহিবিটিং এর জন্য অ্যালার্টম্যানেজার ব্যবহার করে। মূল পর্যবেক্ষণের ধরণগুলি হল Google-এর সুবর্ণ সংকেত (বিলম্ব, ট্র্যাফিক, ত্রুটি, স্যাচুরেশন) এবং পরিষেবাগুলির জন্য RED পদ্ধতি (হার, ত্রুটি, সময়কাল) এবং অবকাঠামোর জন্য ব্যবহার পদ্ধতি (ব্যবহার, স্যাচুরেশন, ত্রুটি)৷
