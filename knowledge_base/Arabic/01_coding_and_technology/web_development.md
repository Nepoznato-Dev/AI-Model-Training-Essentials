# تطوير الويب
## تطوير الواجهة الأمامية
### التقنيات الأساسية
#### HTML (لغة ترميز النص التشعبي)
- **HTML الدلالي**: استخدام علامات ذات معنى (`<header>`,`<nav>`,`<main>`,`<article>`,`<section>`,`<aside>`,`<footer>`)
- **النماذج**: أنواع الإدخال، والتحقق من الصحة، وتسميات إمكانية الوصول
- **الوسائط**: الصور، الفيديو، تضمين الصوت
- ** العلامات الوصفية **: تحسين محركات البحث، إطار العرض، ترميز الأحرف
- **ميزات HTML5**: اللوحة القماشية، وSVG، والتخزين المحلي، وتحديد الموقع الجغرافي، ومآخذ الويب
#### CSS (أوراق الأنماط المتتالية)
- **نموذج الصندوق**: المحتوى، الحشو، الحدود، الهامش
- **أنظمة التخطيط**:
  - **Flexbox**: تخطيطات أحادية البعد، وضبط المحتوى، ومحاذاة العناصر
  - **الشبكة**: تخطيطات ثنائية الأبعاد، قالب الشبكة، منطقة الشبكة
  - **الموضع**: ثابت، نسبي، مطلق، ثابت، مثبت
- **التصميم سريع الاستجابة**: استعلامات الوسائط، نهج الهاتف المحمول أولاً
- **متغيرات CSS**: خصائص مخصصة للسمات
- **الرسوم المتحركة**: التحولات، والإطارات الرئيسية، والتحويلات
- **المعالجات المسبقة**: Sass، Less (المتغيرات، الخلطات، التداخل)
####جافا سكريبت
- **معالجة DOM**: تحديد العناصر وإنشاؤها وتعديلها
- **الأحداث**: انقر، أرسل، لوحة المفاتيح، الأحداث المخصصة، تفويض الأحداث
- **ميزات ES6+**: وظائف السهم، والتدمير، والانتشار/الراحة، والوحدات النمطية، والمزامنة/الانتظار
- **واجهات برمجة التطبيقات**: جلب، XMLHttpRequest، localStorage، sessionStorage
- **TypeScript**: الكتابة الثابتة، والواجهات، والأسماء العامة، وأدوات الديكور
### أطر الواجهة الأمامية الحديثة
#### رد فعل
- **المكونات**: المكونات الوظيفية، مكونات الفئة
- **الخطافات**: useState، useEffect، useContext، useReducer، الخطافات المخصصة
- **إدارة الحالة**: واجهة برمجة تطبيقات السياق، Redux، Zustand، Recoil
- ** التوجيه **: React Router (BrowserRouter، Routes، Route، Link)
- **النظام البيئي**: Next.js (SSR، SSG)، Remix، Gatsby
- **DOM الافتراضي**: عرض فعال من خلال خوارزمية مختلفة
#### فيو.js
- **Options API**: البيانات، الأساليب، المحسوبة، المراقبة
- **واجهة برمجة تطبيقات التركيب**: الإعداد()، المرجع، التفاعلي، المحسوب
- **التوجيهات**: v-if، v-for، v-bind، v-on، v-model
- **Vuex/Pinia**: إدارة الدولة
- **Vue Router**: التوجيه من جانب العميل
- **Nuxt.js**: إطار عمل العرض من جانب الخادم
#### الزاوي
- **المكونات**: أدوات الديكور، والقوالب، وخطافات دورة الحياة
- **الخدمات**: حقن التبعية، النمط المفرد
- **RxJS**: البرمجة التفاعلية، والأشياء القابلة للملاحظة
- **التوجيه**: RouterModule، الحراس، المحللون
- **النماذج**: نماذج تفاعلية تعتمد على القوالب
- **NgRx**: إدارة الحالة بأسلوب Redux
### أدوات البناء والحزم
- **Webpack**: تجميع الوحدات، وتقسيم التعليمات البرمجية، وأدوات التحميل، والمكونات الإضافية
- **Vite**: أداة بناء سريعة باستخدام وحدات ES الأصلية
- **الطرود**: أداة تجميع بدون تكوين
- **التراكمي**: مُحسّن للمكتبات
- **esbuild**: أداة تجميع جافا سكريبت سريعة للغاية
- **Babel**: أداة ترجمة JavaScript للتوافق مع الإصدارات السابقة
- **PostCSS**: معالجة CSS باستخدام المكونات الإضافية
### أطر عمل CSS والمكتبات
- **Bootstrap**: مكتبة المكونات ونظام الشبكة والأدوات المساعدة
- **Tailwind CSS**: إطار عمل CSS للأداة المساعدة أولاً
- ** واجهة المستخدم المادية **: تنفيذ التصميم متعدد الأبعاد من Google
- **واجهة مستخدم شقرا**: مكتبة المكونات التي يمكن الوصول إليها
- **تصميم النملة**: مكونات واجهة المستخدم على مستوى المؤسسة
- **المكونات المصممة**: مكتبة CSS-in-JS
- **العاطفة**: CSS-in-JS مع خرائط المصدر
## تطوير الواجهة الخلفية
### اللغات من جانب الخادم
#### نود.جي إس
- **وقت التشغيل**: جافا سكريبت على الخادم (محرك V8)
- **Express.js**: الحد الأدنى من إطار عمل الويب، وبنية البرامج الوسيطة
- **NestJS**: بنية مستوحاة من Angular، TypeScript
- **Fastify**: إطار عمل عالي الأداء
- **Koa**: Modern Express من نفس المبدعين
- **إدارة الحزم**: npm، الغزل، pnpm
#### بايثون
- **Django**: إطار كامل المواصفات، ORM، لوحة الإدارة، البطاريات متضمنة
- **Flask**: إطار عمل مصغر، نظام بيئي للامتدادات
- **FastAPI**: وثائق واجهة برمجة التطبيقات (API) الحديثة وغير المتزامنة والتلقائية
- **الهرم**: إطار عمل مرن وقابل للتطوير
#### لغات الواجهة الخلفية الأخرى
- **Ruby on Rails**: اتفاقية حول التكوين، ActiveRecord ORM
- **Java Spring**: إطار عمل المؤسسة، حقن التبعية
- **PHP Laravel**: بناء جملة أنيق، Eloquent ORM، قالب Blade
- **Go Gin**: أداء عالي، إطار عمل بسيط
- **Rust Actix**: سلامة الذاكرة والأداء
- **C# ASP.NET Core**: ميزات مشتركة بين الأنظمة الأساسية والمؤسسات
### تكامل قاعدة البيانات
#### ORMs (رسم الخرائط العلائقية للكائنات)
- **Sequelize**: Node.js ORM لقواعد بيانات SQL
- **Prisma**: وصول آمن إلى قاعدة البيانات، عميل يتم إنشاؤه تلقائيًا
- **SQLAlchemy**: مجموعة أدوات Python SQL وORM
- **ActiveRecord**: Ruby on Rails ORM
- **الإسبات**: Java ORM
- **إطار عمل الكيان**: .NET ORM
#### برامج تشغيل قاعدة البيانات
- **pg**: عميل PostgreSQL لـ Node.js
- **mysql2**: عميل MySQL مع الوعود
- **pymongo**: برنامج تشغيل MongoDB لـ Python
- **redis**: عميل Redis للغات متعددة
### تطوير واجهة برمجة التطبيقات
#### واجهات برمجة تطبيقات REST
- **طرق HTTP**: الحصول على، نشر، وضع، تصحيح، حذف
- **رموز الحالة**: 200، 201، 400، 401، 403، 404، 500
- **تسمية الموارد**: الأسماء، الجمع، التسلسل الهرمي
- **إصدار**: مسار URL، والرؤوس، ومعلمات الاستعلام
- **المصادقة**: مفاتيح JWT وOAuth وAPI
- **الوثائق**: OpenAPI/Swagger، Postman
#### الرسم البيانيQL
- **تعريف المخطط**: الأنواع والاستعلامات والطفرات والاشتراكات
- **المحللات**: جلب البيانات على مستوى الحقل
- **خادم أبولو**: تنفيذ خادم GraphQL
- **Relay**: عميل GraphQL على Facebook
- **المزايا**: لا يوجد جلب زائد، نقطة نهاية واحدة، كتابة قوية
#### جي آر بي سي
- **مخازن البروتوكول المؤقتة**: لغة تعريف الواجهة
- **HTTP/2**: التدفق ثنائي الاتجاه
- **حالات الاستخدام**: اتصالات الخدمات الصغيرة، والتطبيقات في الوقت الفعلي
### المصادقة والترخيص
- **المعتمدة على الجلسة**: ملفات تعريف الارتباط، والجلسات من جانب الخادم
- **معتمد على الرمز المميز**: JWT (رموز الويب JSON)، عديمة الحالة
- **OAuth 2.0**: إطار عمل التفويض، تسجيل دخول الطرف الثالث
- **OpenID Connect**: طبقة الهوية على OAuth 2.0
- **SAML**: تسجيل الدخول الموحد للمؤسسة
- **تجزئة كلمة المرور**: bcrypt، argon2، scrypt
- **المصادقة متعددة العوامل**: TOTP، والرسائل النصية القصيرة، ورموز البريد الإلكتروني
## DevOps والنشر
### التحكم في الإصدار
- **Git**: التحكم في الإصدار الموزع
- **GitHub/GitLab/Bitbucket**: استضافة المستودع
- **استراتيجيات التفرع**: تدفق Git، وتدفق GitHub، والتطوير القائم على الجذع
- **CI/CD**: الاختبار الآلي وخطوط النشر
###الحاويات
- **Docker**: وقت تشغيل الحاوية، ملف Dockerfile، الصور
- **Docker Compose**: تنسيق متعدد الحاويات
- **سجلات الحاويات**: Docker Hub، وAWS ECR، وGoogle GCR
- **أفضل الممارسات**: عمليات إنشاء متعددة المراحل، مع الحد الأدنى من الصور الأساسية
### التنسيق
- **Kubernetes**: تنسيق الحاويات، والكبسولات، والخدمات، وعمليات النشر
- **Helm**: مدير حزم Kubernetes
- **شبكة الخدمة**: Istio، Linkerd لشبكات الخدمات الصغيرة
### المنصات السحابية
- **AWS**: EC2، S3، Lambda، RDS، CloudFront، ECS/EKS
- **Google Cloud**: محرك الحوسبة، والتخزين السحابي، والوظائف السحابية، وGKE
- **Azure**: الأجهزة الافتراضية، وتخزين Blob، والوظائف، وAKS
- **Vercel**: نشر الواجهة الأمامية، وظائف بدون خادم
- **Netlify**: استضافة موقع ثابت، وظائف بدون خادم
- **Heroku**: النظام الأساسي كخدمة (PaaS)
- **DigitalOcean**: بنية أساسية سحابية مبسطة
### خطوط أنابيب CI/CD
- **إجراءات GitHub**: أتمتة سير العمل
- **GitLab CI**: التكامل المستمر المدمج
- **جينكينز**: خادم أتمتة قابل للتوسيع
- **CircleCI**: CI/CD المستند إلى السحابة
- **Travis CI**: خدمة التكامل المستمر
- **ArgoCD**: التسليم المستمر لـ GitOps لـ Kubernetes
### المراقبة والتسجيل
- **أداء التطبيق**: بقايا جديدة، Datadog، AppDynamics
- **تتبع الأخطاء**: Sentry، Rollbar، Bugsnag
- **التسجيل**: ELK Stack (Elasticsearch، Logstash، Kibana)، Splunk
- **مراقبة وقت التشغيل**: Pingdom، UptimeRobot
- **التحليلات**: Google Analytics، وMixpanel، وAmplitude
## أداء الويب
### تقنيات التحسين
- **تقسيم الكود**: التحميل البطيء والواردات الديناميكية
- **اهتزاز الشجرة**: إزالة الكود غير المستخدم
- **التصغير**: تقليل أحجام الملفات
- **الضغط**: غزيب، بروتلي
- **التخزين المؤقت**: ذاكرة التخزين المؤقت للمتصفح، CDN، عمال الخدمة
- **تحسين الصورة**: WebP، AVIF، التحميل البطيء، الصور سريعة الاستجابة
- **CSS الحرجة**: تضمين الأنماط العلوية
- **تحسين قاعدة البيانات**: الفهرسة، وتحسين الاستعلام، وتجميع الاتصالات
### مؤشرات الويب الأساسية
- **LCP (أكبر طلاء محتوى)**: أداء التحميل (<2.5 ثانية)
- **FID (تأخير الإدخال الأول)**: التفاعل (<100 مللي ثانية)
- **CLS (إزاحة التخطيط التراكمي)**: الاستقرار البصري (<0.1)
- **INP (التفاعل مع الطلاء التالي)**: مقياس الاستجابة
### شبكات تسليم المحتوى (CDNs)
- **Cloudflare**: الأمان، الأداء، DNS
- **Akamai**: شبكة CDN للمؤسسات
- **Amazon CloudFront**: AWS CDN
- **Fastly**: منصة سحابية متطورة
- **StackPath**: خدمات الحافة
## أمن الويب
### نقاط الضعف الشائعة (أهم 10 نقاط ضعف في OWASP)
- **الحقن**: حقن SQL، وحقن الأوامر
- **المصادقة المعطلة**: اختطاف الجلسة وحشو بيانات الاعتماد
- **الكشف عن البيانات الحساسة**: بيانات غير مشفرة، تشفير ضعيف
- **كيانات XML الخارجية (XXE)**: ثغرات أمنية في محلل XML
- **التحكم في الوصول المعطل**: تصعيد الامتيازات، الوصول غير المصرح به
- **التكوين الخاطئ للأمان**: بيانات الاعتماد الافتراضية، والأخطاء المطولة
- ** البرمجة النصية عبر المواقع (XSS) **: منعكسة ومخزنة ومعتمدة على DOM
- **إلغاء التسلسل غير الآمن**: هجمات حقن الكائنات
- **استخدام المكونات ذات الثغرات الأمنية المعروفة**: التبعيات القديمة
- **عدم كفاية التسجيل والمراقبة**: الانتهاكات غير المكتشفة
### أفضل الممارسات الأمنية
- **HTTPS**: تشفير TLS/SSL، HSTS
- **سياسة أمان المحتوى (CSP)**: منع هجمات XSS
- **التحقق من صحة الإدخال**: تطهير إدخال المستخدم
- **ترميز الإخراج**: منع هجمات الحقن
- **حماية CSRF**: الرموز المميزة لمكافحة CSRF وملفات تعريف الارتباط SameSite
- **تحديد المعدل**: منع هجمات القوة الغاشمة
- **رؤوس الأمان**: خيارات الإطار X، خيارات نوع المحتوى X
- **فحص التبعية**: تدقيق npm، Snyk، Dependabot

## إمكانية الوصول (a11y)
### إرشادات WCAG
- **يمكن إدراكه**: بدائل النص، والتسميات التوضيحية، والمحتوى القابل للتكيف
- **قابل للتشغيل**: التنقل عبر لوحة المفاتيح، وقت كافٍ، عدم وجود نوبات
- **مفهومة**: مساعدة في الإدخال يمكن قراءتها، ويمكن التنبؤ بها
- **قوي**: متوافق مع التقنيات المساعدة
### التنفيذ
- **HTML الدلالي**: التسلسل الهرمي الصحيح للعناوين والمعالم
- **سمات ARIA**: الأدوار والحالات والخصائص
- **إدارة التركيز**: مؤشرات التركيز المرئية، وترتيب علامات التبويب المنطقية
- **تباين الألوان**: الحد الأدنى لنسبة 4.5:1 للنص
- **اختبار قارئ الشاشة**: NVDA، JAWS، VoiceOver
- ** التنقل عبر لوحة المفاتيح **: يمكن الوصول إلى جميع العناصر التفاعلية

- **بيان تطبيق الويب**: مطالبة التثبيت والأيقونات وألوان السمات
- **App Shell**: هيكل واجهة المستخدم المخزنة مؤقتًا
- ** دفع الإخطارات **: مشاركة المستخدم
- **التصميم سريع الاستجابة**: يعمل على جميع الأجهزة
- **HTTPS مطلوب**: سياق آمن
### الأدوات
- **Workbox**: مكتبات العاملين في الخدمة
- **المنارة**: تدقيق PWA
- **PWA Builder**: إنشاء البيانات والأيقونات
## التقنيات الناشئة
### WebAssembly (Wasm)
- **الغرض**: تشغيل التعليمات البرمجية المترجمة في المتصفح بسرعة قريبة من السرعة الأصلية
- **اللغات**: أهداف التجميع C++ وRust وGo
- **حالات الاستخدام**: الألعاب، وتحرير الفيديو، والتشفير، واستدلال تعلم الآلة
### بنية بدون خادم
- **الوظائف كخدمة**: AWS Lambda، وAzure Functions، وGoogle Cloud Functions
- **الفوائد**: لا توجد إدارة للخادم، أو التوسع التلقائي، أو الدفع لكل استخدام
- **الاعتبارات**: عمليات التشغيل الباردة، وتقييد البائع، وتعقيد تصحيح الأخطاء
### هندسة جامستاك
- **جافا سكريبت**: التفاعل من جانب العميل
- **واجهات برمجة التطبيقات**: وظائف بدون خادم، وخدمات الجهات الخارجية
- **التوصيف**: ملفات ثابتة معدة مسبقًا
- **الأدوات**: Next.js، Gatsby، Hugo، Eleventy
- **الفوائد**: الأداء والأمان وقابلية التوسع وتجربة المطور
### التواصل في الوقت الحقيقي
- **WebSockets**: اتصال ثنائي الاتجاه
- **الأحداث المرسلة من الخادم**: البث من خادم إلى عميل
- **WebRTC**: الفيديو والصوت والبيانات من نظير إلى نظير
- **حالات الاستخدام**: الدردشة والتعاون والبث المباشر والألعاب
### الواجهات الأمامية الصغيرة
