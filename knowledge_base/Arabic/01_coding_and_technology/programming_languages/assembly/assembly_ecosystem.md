## المجمعون حسب الهندسة المعمارية
### x86/x86-64
| المجمع | منصة | ملاحظات |
|-----------|---------|-------|
| ** نسم ** | عبر منصة | بناء الجملة الأكثر شيوعًا والنظيف |
| **ماسم** | ويندوز | مجمع ماكرو مايكروسوفت |
| **فاسم** | عبر منصة | استضافة ذاتية وسريعة |
| **الغاز (مثل)** | لينكس/يونكس | مجمع جنو (بناء جملة AT&T) |
| **ياسم** | عبر منصة | متوافق مع NASM |
| **UASM** | عبر منصة | متوافق مع MASM |
### ذراع
| المجمع | منصة | ملاحظات |
|-----------|---------|-------|
| **جنو كـ (ARM)** | عبر منصة | تجميع ARM |
| ** كايل ASM ** | مضمن | تطوير أرم |
| **مجمع ARM** | أرمينيا | مجموعة مترجم ARM |
### آخر
| المجمع | العمارة | ملاحظات |
|-----------|-------------|-------|
| **أفر-كما** | أفر | المتحكمات الدقيقة |
| **رسم** | Z80 | الحوسبة الرجعية |
| **ca65** | 6502 | متنوعه، العميد البحري |
| **SPIM / المريخ** | ميبس | تعليمية |
```bash
# NASM (Linux x86-64)
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# NASM (Windows)
nasm -f win64 hello.asm -o hello.obj
golink /console /entry _start hello.obj

# FASM
fasm hello.asm hello

# GAS (AT&T syntax)
as -o hello.o hello.s
ld hello.o -o hello
```

## أدوات البناء
| أداة | الغرض |
|------|---------|
| **اصنع** | أتمتة البناء الكلاسيكي |
| **CMake** | يبني عبر منصة |

| ** ليرة لبنانية ** | رابط LLVM |

| **objdump** | التفكيك |
| **قراءة / نانومتر** | فحص الرمز |
| **التفريغ السداسي** | التفتيش الثنائي |
```makefile
# Makefile for NASM project
ASM = nasm
ASM_FLAGS = -f elf64
LD = ld
TARGET = hello

all: $(TARGET)

$(TARGET): hello.o
	$(LD) hello.o -o $(TARGET)

hello.o: hello.asm
	$(ASM) $(ASM_FLAGS) hello.asm -o hello.o

clean:
	rm -f *.o $(TARGET)
```

## الاختبار
| أداة | الغرض |
|------|---------|
| **أداة اختبار مخصصة** | إطار اختبار التجميع |
| **الوحدة** | اختبار الوحدة على أساس C (للمشاريع المختلطة) |
| **اختبار جوجل** | اختبار لغة C++ (للمشاريع المختلطة) |
| **وحدات الماكرو المخصصة** | وحدات الماكرو التأكيد |
```nasm
; NASM test example
section .data
    test_pass db "PASS", 10, 0
    test_fail db "FAIL", 10, 0

section .text
    global _start

test_add:
    mov rax, 2
    mov rbx, 3
    add rax, rbx
    cmp rax, 5
    jne .fail
    ; print pass
    mov rax, 1
    mov rdi, 1
    mov rsi, test_pass
    mov rdx, 5
    syscall
    ret
.fail:
    mov rax, 1
    mov rdi, 1
    mov rsi, test_fail
    mov rdx, 5
    syscall
    ret

_start:
    call test_add
    mov rax, 60
    xor rdi, rdi
    syscall
```

## ملخص
النظام البيئي الخاص بالتجميع خاص بالهندسة المعمارية وبسيط حسب التصميم. سلسلة الأدوات القياسية هي: **NASM** (x86/x86-64) أو **GNU as** (ARM) للتجميع، **ld** للربط، **GDB** لتصحيح الأخطاء، **Ghidra** أو **IDA Pro** للهندسة العكسية، و **QEMU** للمحاكاة. تتفوق شركة Assembly في تطوير نظام التشغيل، والأنظمة المدمجة، والهندسة العكسية، والتعليمات البرمجية المهمة للأداء، وتطوير أداة تحميل التشغيل. يعد النظام البيئي ضروريًا لفهم كيفية عمل أجهزة الكمبيوتر عند أدنى مستوى. للتعلم، يوفر **MARS** (MIPS) و**SASM** (x86) بيئات مناسبة للمبتدئين.
