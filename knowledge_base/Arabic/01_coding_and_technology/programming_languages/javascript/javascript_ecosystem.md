## أوقات التشغيل
| وقت التشغيل | البيئة | الأفضل لـ |

## إدارة الحزم
| أداة | التسجيل | المميزات |
|------|----------|---------|
| **نبم** | npmjs.com | الافتراضي مع Node.js |
| **غزل** | npmjs.com | مساحات العمل، وضع PnP |
| **بنم** | npmjs.com | سريع، فعال على القرص، صارم |
| ** كعكة ** | npmjs.com | فائق السرعة، مدمج |
```bash
npm init -y                   # initialize project
npm install express           # add dependency
npm install -D typescript     # add dev dependency
npm run build                 # run script from package.json
```

## ملخص
يعد النظام البيئي لجافا سكريبت هو الأكبر في مجال البرمجة. المكدس الحديث هو: **Vite** للبناء، **pnpm** للحزم، **Vitest** للاختبار، **ESLint + Prettier** لجودة التعليمات البرمجية، **React/Next.js** أو **Vue/Nuxt** للواجهة الأمامية، و **Vercel** أو **Cloudflare** للنشر. يعد TypeScript الآن ضروريًا لأي مشروع جاد. يتحرك النظام البيئي بسرعة - ابق على اطلاع دائم ولكن تجنب تغيير إطار العمل.
