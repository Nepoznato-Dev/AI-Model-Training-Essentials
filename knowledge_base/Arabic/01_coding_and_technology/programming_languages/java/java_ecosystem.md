## أدوات البناء
| أداة | اكتب | الأفضل لـ |
|------|------|----------|
| **مافن** | مبني على XML | مؤسسة، اتفاقية حول التكوين |
| ** جرادل ** | رائع/كوتلين DSL | مرنة، أندرويد، مشاريع كبيرة |
| **النملة** | مبني على XML | المشاريع التراثية |
| **بازل** | متعدد اللغات | مونوريبوس، مقياس جوجل |
```bash
# Maven
mvn clean install               # build
mvn test                        # run tests
mvn package                     # create JAR/WAR

# Gradle
./gradlew build                 # build
./gradlew test                  # run tests
./gradlew bootRun               # run Spring Boot app
```

| ** الوحدة الخامسة ** | إطار الاختبار القياسي |

| **وايرموك** | HTTP API يسخر |
| **وحدة القوس** | اختبارات العمارة |
| ** كن مطمئنا ** | اختبار REST API |
| **جي إم إتش** | العلامات المعيارية الدقيقة |
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;
    @InjectMocks UserService service;

    @Test
    void shouldFindUserById() {
        when(repo.findById(1L)).thenReturn(Optional.of(new User("Alice")));
        var user = service.findById(1L);
        assertThat(user.name()).isEqualTo("Alice");
    }
}
```

## ملخص
يعد نظام Java البيئي هو الأكثر نضجًا في مجال الحوسبة المؤسسية. المكدس القياسي هو: **Gradle** أو **Maven** للإنشاءات، **Spring Boot** للويب/الخدمات الصغيرة، **JUnit 5 + Mockito** للاختبار، **Hibernate** لـ ORM، **IntelliJ IDEA** كـ IDE، و **Docker** للنشر. تكمن قوة Java في نظامها البيئي الضخم ودعم المؤسسات والتوافق مع الإصدارات السابقة. تعمل Java الحديثة (17+) مع السجلات والفصول المختومة ومطابقة الأنماط والخيوط الافتراضية على تنشيط اللغة.
