يغطي هذا الدليل الأدوات والأطر والبنية التحتية الأساسية في نظام Rust البيئي.

## إدارة الحزم وبناءها
| أداة | الغرض |
|------|---------|
| **البضائع** | مدير الحزم، نظام البناء، مشغل الاختبار |
| **crates.io** | تسجيل الحزمة الرسمية |
| **رستوب** | مثبت ومدير سلسلة الأدوات |
| ** تحرير البضائع ** | إضافة/إزالة/ترقية التبعيات |
| **ساعة الشحن** | إعادة البناء على تغييرات الملف |
| **تدقيق البضائع** | مدقق الثغرات الأمنية |
| **البضائع كليبي** | لينتر (مدمج) |
| **البضائع FMT** | منسق الكود (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

## الاختبار
| أداة | الغرض |
|------|---------|
| **اختبار الحمولة** | الوحدة المدمجة + اختبارات التكامل |
| **المعيار** | إطار المقارنة المعيارية |
| **الاحتجاج** | الاختبار على أساس الملكية |
| ** موكال ** | إطار السخرية |
| **طوكيو::اختبار** | دعم اختبار غير متزامن |
| **إنستا** | اختبار اللقطة |
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## ملخص
يتميز نظام Rust البيئي بأنه متماسك وعالي الجودة، ويتمحور حول Cargo. المكدس القياسي هو: **Cargo** لكل شيء (الإنشاء والاختبار والنشر)، **Tokio** لعدم المزامنة، **Axum** أو **Actix-web** للويب، **serde** للتسلسل، **SQLx** لقواعد البيانات، و **clap** لـ CLIs. يتم نشر ميزة Rust القاتلة كثنائي ثابت واحد بدون تبعيات وقت التشغيل. يعطي النظام البيئي الأولوية للصحة والأداء على حساب الراحة.
