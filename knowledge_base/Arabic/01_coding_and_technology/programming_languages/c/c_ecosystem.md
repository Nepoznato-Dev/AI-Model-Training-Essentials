## بناء الأنظمة
| أداة | اكتب | الأفضل لـ |
|------|------|----------|
| **اصنع** | كلاسيك | مشاريع بسيطة، معيار يونكس |

| **بازل** | مقياس | مونوريبوس، جوجل |

```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## ملخص
النظام البيئي لـ C هو أساس الحوسبة الحديثة. سلسلة الأدوات القياسية هي: **GCC** أو **Clang** للتجميع، و**CMake** للبنيات، و**GDB** لتصحيح الأخطاء، و**Valgrind** لتحليل الذاكرة، و**clang-tidy** للفحص. تشمل المكتبات الرئيسية **OpenSSL** للعملات المشفرة، و**libcurl** لـ HTTP، و**SQLite** لقواعد البيانات. إن النظام البيئي لـ C هو الحد الأدنى من حيث التصميم - فأنت تبني ما تحتاجه. من أجل التطوير الحديث، استخدم دائمًا المطهرات (ASan، UBSan) أثناء الاختبار.
