# كوبول - دليل النظام البيئي والأدوات
يغطي هذا الدليل الأدوات الأساسية والمجمعات والبنية التحتية في نظام COBOL البيئي.

## المترجمون والتطبيقات
| مترجم | اكتب | ملاحظات |
|----------|------|-------|
| **جنوكوبول (أوبنكوبول)** | مفتوح المصدر | المترجم المجاني الأكثر استخدامًا على نطاق واسع |
| ** آي بي إم إنتربرايز كوبول ** | تجاري | معيار z/OS المركزي |
| **مايكرو فوكس كوبول** | تجاري | مؤسسة كوبول |
| **فوجيتسو كوبول** | تجاري | يونكس كوبول |
| **أكوكوبول-GT** | تجاري | الآن التركيز الجزئي |
| **كوبول-إيت** | تجاري | القائم على GnuCOBOL |
```bash
cobc --version              # GnuCOBOL version
cobc -x -o app program.cob  # compile to executable
cobc -m -o lib.so module.cob  # compile to shared library
cobc -free program.cob      # free-format source
```

## بناء الأنظمة
| أداة | الغرض |
|------|---------|
| **اصنع** | بنيات كلاسيكية |
| ** مترجم GnuCOBOL ** | التجميع المباشر |
| ** مخضرم (البرنامج المساعد كوبول) ** | مؤسسة يبني |
| ** جي سي إل ** | التحكم في وظيفة الحاسوب المركزي |
| **CMake** | عبر الأنظمة الأساسية (مع دعم COBOL) |
```makefile
# Makefile for COBOL project
COBOL = cobc
FLAGS = -free -O2 -Wall

SRCS = $(wildcard src/*.cob)
OBJS = $(SRCS:.cob=.o)

all: myapp

myapp: $(OBJS)
	$(COBOL) -x -o $@ $^

%.o: %.cob
	$(COBOL) $(FLAGS) -c $<

clean:
	rm -f $(OBJS) myapp
```

```cobol
       *> SQL example in COBOL
       EXEC SQL
           SELECT NAME, SALARY
           INTO :WS-NAME, :WS-SALARY
           FROM EMPLOYEES
           WHERE EMP_ID = :WS-EMP-ID
       END-EXEC.
       
       IF SQLCODE = 0
           DISPLAY "Name: " WS-NAME
           DISPLAY "Salary: " WS-SALARY
       ELSE
           DISPLAY "Error: " SQLCODE
       END-IF.
```

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. TEST-ADD.
       
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 WS-A    PIC 9(3) VALUE 5.
       01 WS-B    PIC 9(3) VALUE 3.
       01 WS-RESULT PIC 9(3).
       
       PROCEDURE DIVISION.
           COMPUTE WS-RESULT = WS-A + WS-B

           ELSE

           STOP RUN.
```

## ملخص
ويهيمن الحوسبة المركزية والحوسبة المؤسسية على النظام البيئي لـ COBOL. سلسلة الأدوات القياسية هي: **IBM Enterprise COBOL** على z/OS (الحاسب المركزي) أو **GnuCOBOL** (مفتوح المصدر، متعدد المنصات)، **Db2** و **VSAM** للبيانات، **CICS** للمعاملات، وأدوات **Micro Focus** للتحديث. تقوم COBOL بمعالجة ما يقدر بنحو 70% من المعاملات التجارية في العالم - لا تزال الخدمات المصرفية والتأمين والحكومة والرعاية الصحية تعتمد بشكل كبير على COBOL. يعد النظام البيئي ضروريًا للحفاظ على الأنظمة القديمة وتحديث تطبيقات الحواسيب المركزية. يوفر GnuCOBOL مسارًا مجانيًا مفتوح المصدر لتطوير COBOL وترحيله.
