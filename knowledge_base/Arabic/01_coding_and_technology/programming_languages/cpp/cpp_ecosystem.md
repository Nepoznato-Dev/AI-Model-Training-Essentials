# C++ - دليل النظام البيئي والأدوات
يغطي هذا الدليل الأدوات والمكتبات والبنية التحتية الأساسية في نظام C++ البيئي.

## المترجمين
| مترجم | منصة | ملاحظات |
|----------|---------|-------|
| **دول مجلس التعاون الخليجي (ز++)** | لينكس/يونكس | مجموعة مترجمات جنو، المستخدمة على نطاق واسع |
| **كلانج++** | عبر منصة | تشخيصات ممتازة قائمة على LLVM |
| **MSVC** | ويندوز | مترجم مايكروسوفت فيجوال C++ |
| **Intel oneAPI (icpx)** | عبر منصة | أداء عالي، وتركيز HPC |
| **منعرج ج++** | عبر منصة | تجميع متقاطع رائع |
```bash
g++ -std=c++23 -O2 -Wall -Wextra -o app main.cpp
clang++ -std=c++23 -stdlib=libc++ -o app main.cpp
```

## بناء الأنظمة
| أداة | اكتب | الأفضل لـ |
|------|------|----------|
| **CMake** | عبر منصة | معيار الصناعة لمعظم المشاريع |
| **ميسون** | حديث | بناء جملة سريع ونظيف، واجهة Ninja الخلفية |
| **بازل** | مقياس | مونوريبوس، مقياس جوجل |
| ** كونان + CMake ** | علم الحزمة | إدارة الحزم C++ |
| **xmake** | حديث | مدير الحزم المدمج القائم على Lua |
| **اصنع** | كلاسيك | مشاريع يونكس البسيطة |
| **النينجا** | سريع | نظام بناء منخفض المستوى |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.24)
project(myapp LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(myapp src/main.cpp)
target_compile_features(myapp PRIVATE cxx_std_23)

# Find packages
find_package(fmt REQUIRED)
target_link_libraries(myapp PRIVATE fmt::fmt)
```

```bash
vcpkg install
```

## الاختبار
| الإطار | الغرض |
|-----------|--------|
| **اختبار جوجل (gtest)** | الأكثر شهرة، جوجل |
| **جوجل موك (جموك)** | إطار السخرية |
| ** كاتش 2 ** | رأس واحد، نمط BDD |
| **دوكتيست** | خفيفة الوزن ذات رأس واحد |
| ** اختبار التعزيز ** | الاختبار القائم على التعزيز |
| **معيار جوجل** | العلامات المعيارية الدقيقة |
| **نانوبنش** | قياس الأداء خفيف الوزن |
```cpp
// Catch2 example
#define CATCH_CONFIG_MAIN
#include <catch2/catch.hpp>

TEST_CASE("vector operations") {
    std::vector<int> v = {1, 2, 3};
    REQUIRE(v.size() == 3);
    REQUIRE(v[0] == 1);
    SECTION("push_back") {
        v.push_back(4);
        REQUIRE(v.size() == 4);
    }
}
```

## ملخص
تمتلك لغة C++ النظام البيئي الأغنى والأكثر تعقيدًا. سلسلة الأدوات القياسية هي: **GCC** أو **Clang** للتجميع، **CMake** للبنيات، **Conan** أو **vcpkg** للحزم، **Google Test** أو **Catch2** للاختبار، **clang-tidy** للفحص، **GDB** لتصحيح الأخطاء، و **ASan/UBSan** للمطهرات. تتضمن المكتبات الرئيسية **Boost** للأدوات المساعدة، و**fmt** للتنسيق، و**nlohmann/json** لـ JSON، و**spdlog** للتسجيل، و**Eigen** للرياضيات، و**Qt** لواجهة المستخدم الرسومية. تعمل لغة C++ الحديثة (20/23) مع المفاهيم والنطاقات والكوروتينات والوحدات النمطية على تغيير النظام البيئي. قم دائمًا بالتجميع باستخدام`-Wall -Wextra -Werror`واستخدم المطهرات في CI.
