# ورقة الغش في التعبيرات العادية
التعبيرات العادية (regex) هي أنماط لمطابقة النص. يتم استخدامها في كل مكان — البحث والاستبدال، والتحقق من صحة الإدخال، وتحليل السجل، واستخراج البيانات، والمزيد. وهذا مرجع عملي، وليس كتابا مدرسيا.
---

## بناء الجملة الأساسي
### الشخصيات الحرفية
معظم الأحرف تتطابق مع نفسها:`a`يطابق "a"،`cat`يطابق "cat".
### الأحرف الخاصة (الأحرف الأولية)
هذه لها معنى خاص ويجب تجاوزها بـ`\`لتتطابق حرفيًا:
| حرف | معنى |
|-----------|--------|
|  __محمي_0__ | أي حرف باستثناء السطر الجديد |
|  __محمي_1__ | بداية السلسلة (أو السطر في وضع متعدد الأسطر) |
|  __محمي_2__ | نهاية السلسلة (أو السطر في وضع متعدد الأسطر) |
|  __محمي_3__ | 0 أو أكثر مما سبق |
|  __محمي_4__ | 1 أو أكثر مما سبق |
|  __محمي_5__ | 0 أو 1 مما سبق (يجعل أجهزة قياس الكميات كسولة مع`*?`,`+?`) |
|  __محمي_8__ | التناوب (أو) |
|  __محمي_9__ | التجميع والتقاط |
|  __محمي_10__ | فئة الشخصية |
|  __محمي_11__ | نطاق الكمي |
|  __محمي_12__ | شخصية الهروب |

## الاستخدام الخاص باللغة
### بايثون
```python
import re

text = "Contact us at info@example.com or support@test.org"

# Find all emails
emails = re.findall(r'\b[\w.+-]+@[\w.-]+\.\w{2,}\b', text)
# ['info@example.com', 'support@test.org']

# Search for first match
match = re.search(r'\d{4}-\d{2}-\d{2}', "Date: 2024-03-15")
if match:
    print(match.group())  # "2024-03-15"

# Replace
cleaned = re.sub(r'\s+', '', "hello  world")  # "helloworld"

# Named groups
pattern = r'(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})'
m = re.match(pattern, "2024-03-15")
print(m.group('year'))  # "2024"

# Compile for reuse
email_re = re.compile(r'\b[\w.+-]+@[\w.-]+\.\w{2,}\b')
results = email_re.findall(text)
```

###جافا سكريبت
```javascript
const text = "Contact us at info@example.com or support@test.org";

// Find all matches
const emails = text.match(/[\w.+-]+@[\w.-]+\.\w{2,}/g);
// ['info@example.com', 'support@test.org']

// Test if pattern matches
const hasDate = /\d{4}-\d{2}-\d{2}/.test("Date: 2024-03-15");  // true

// Replace
const cleaned = "hello  world".replace(/\s+/g, '');  // "helloworld"

// Capture groups
const match = /(\d{4})-(\d{2})-(\d{2})/.exec("2024-03-15");
// match[1] = "2024", match[2] = "03", match[3] = "15"

// Named groups
const dateRe = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const m = dateRe.exec("2024-03-15");
console.log(m.groups.year);  // "2024"
```

### grep / sed / awk (سطر الأوامر)
```bash
# grep: find lines matching a pattern
grep -E '[0-9]{4}-[0-9]{2}-[0-9]{2}' logfile.txt       # Find dates
grep -iE '\b[\w.+-]+@[\w.-]+\.\w{2,}\b' file.txt       # Find emails (case-insensitive)
grep -c 'ERROR' logfile.txt                              # Count matching lines
grep -rn 'TODO' src/                                     # Recursive with line numbers

# sed: find and replace
sed 's/old/new/g' file.txt                               # Replace all occurrences
sed 's/[[:space:]]\+/ /g' file.txt                       # Collapse whitespace
sed -n '/ERROR/p' logfile.txt                            # Print only matching lines
sed 's/^/# /' file.txt                                   # Prepend "# " to each line

# awk: field-based processing
awk '{print $1, $3}' file.txt                            # Print columns 1 and 3
awk -F',' '{print $2}' data.csv                          # CSV: print 2nd column
awk '/ERROR/ {count++} END {print count}' logfile.txt    # Count ERROR lines
awk 'length($0) > 80' file.txt                           # Lines longer than 80 chars
```

##أخطاء شائعة
| خطأ | مشكلة | إصلاح |
|---------|--------|-----|
| `.*`جشع | مباريات أكثر من اللازم | استخدم`.*?`للمطابقة البطيئة |
| نسيان الهروب __محمي_2__ | `file.txt`يتطابق مع`fileXtxt`أيضًا | استخدم __محمي_5__ |
| لا يتم تثبيت أنماط التحقق من الصحة | `^\d{3}$`مضمن في سلسلة أطول | استخدم __محمي_7__ و__محمي_8__ |
| فئة الأحرف داخل`[]`| `[\d+]`يتطابق مع `\`، `d`،`+`— وليس أرقامًا | استخدم`\d`خارج`[]`أو`[0-9]`|
| تحليل HTML باستخدام regex | HTML ليست لغة عادية | استخدم محلل HTML للتحليل الحقيقي؛ regex OK لاستخراج بسيط |
| التراجع الكارثي | يمكن أن تتعطل محددات الكمية المتداخلة مثل`(a+)+`| تبسيط النمط؛ استخدام المجموعات الذرية |
| عدم اختبار حالات الحافة | يعمل النمط على المسار السعيد، ويفشل على الحافة | اختبر باستخدام سلاسل فارغة وإدخالات طويلة جدًا وأحرف خاصة |

## ملخص
Regex هي أداة لمطابقة الأنماط في النص. ابدأ بشكل بسيط - معظم أنماط العالم الحقيقي هي مجرد مزيج من فئات الشخصيات، ومحددات الكمية، والمثبتات، والمجموعات. استخدم أداة اختبار للتحقق من أنماطك قبل وضعها في التعليمات البرمجية. وتذكر: إذا أصبح التعبير العادي الخاص بك معقدًا للغاية بحيث لا يمكنك قراءته، فمن المحتمل أن يكون الوقت قد حان لاستخدام محلل مناسب بدلاً من ذلك.
