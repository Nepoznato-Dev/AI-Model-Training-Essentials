# تكوين خط أنابيب CI/CD
تعمل مسارات التكامل المستمر (CI) والنشر المستمر (CD) على أتمتة عملية إنشاء البرامج واختبارها ونشرها. يغطي هذا المرجع أنماط التكوين لمنصات CI/CD الأكثر شيوعًا: GitHub Actions وGitLab CI ومبادئ تصميم خطوط الأنابيب العامة.
---

## إجراءات جيثب
### هيكل سير العمل
```yaml
name: CI Pipeline
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up language
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Run tests
        run: pytest
      - name: Build
        run: python setup.py build
```

| ميزة | الوصف |
|---------|------------|

### استراتيجية المصفوفة
```yaml
jobs:
  test:
    strategy:
      matrix:
        python-version: ['3.10', '3.11', '3.12']
        os: [ubuntu-latest, macos-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
```

## جيتلاب سي آي
### هيكل خطوط الأنابيب
```yaml
stages:
  - build
  - test
  - deploy

build:
  stage: build
  script:
    - docker build -t myapp:$CI_COMMIT_SHA .
    - docker push myapp:$CI_COMMIT_SHA

test:
  stage: test
  script:
    - docker run myapp:$CI_COMMIT_SHA pytest

deploy:
  stage: deploy
  script:
    - deploy.sh $CI_COMMIT_SHA
  only:
    - main
  when: manual
```

## استكشاف الأخطاء وإصلاحها
| مشكلة | الحل |
|---------|---------|
| **خط الأنابيب بطيء** | تبعيات ذاكرة التخزين المؤقت؛ موازنة الوظائف؛ استخدم صورًا أساسية أصغر |

| **الاختبارات غير المستقرة** | اختبارات الحجر الصحي غير المستقرة؛ إصلاح السبب الجذري؛ أعد المحاولة باستخدام`retry:`|

## ملخص
تعمل خطوط أنابيب CI/CD على أتمتة إنشاء البرامج واختبارها ونشرها. تستخدم إجراءات GitHub مسارات عمل YAML التي يتم تشغيلها بواسطة أحداث المستودع؛ يستخدم GitLab CI المراحل والوظائف بقواعد مرنة. تشمل الأنماط الرئيسية ما يلي: البناء بمجرد نشر العديد؛ فحص البوابة قبل الإنتاج؛ الوبر أولاً للحصول على ردود فعل سريعة؛ تبعيات ذاكرة التخزين المؤقت لتسريع عمليات الإنشاء؛ واختبارات موازية. تتقدم مراحل خطوط الأنابيب عادةً من الوبر → البناء → الاختبار → الأمان → الحزمة → النشر → اختبار الدخان. تختلف استراتيجيات التخزين المؤقت حسب اللغة ولكنها تتبع نفس المبدأ: أدلة تبعية ذاكرة التخزين المؤقت التي يتم ربطها بمفتاح تجزئات ملف القفل. الهدف هو تقديم تعليقات سريعة وموثوقة حول كل تغيير وعمليات نشر آمنة وقابلة للتكرار للإنتاج.
