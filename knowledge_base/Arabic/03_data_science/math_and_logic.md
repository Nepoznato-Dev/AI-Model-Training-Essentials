# Mathematics و Logic

# # What is Mathematics?

Mathematics is ال study من numbers, shapes, patterns, و logical relationships. It is both a العلوم و a اللغة used to describe ال universe. Mathematics is divided into branches including arithmetic, algebra, geometry, calculus, إحصائيات, و logic. Mathematics is ال foundation من physics, engineering, computer العلوم, الاقتصاد, و many other fields.

# # Arithmetic

Arithmetic is ال branch من mathematics dealing مع basic operations on numbers. ال four fundamental operations are addition (+), subtraction (−), multiplication (×), و division (÷). ال order من operations specifies ال sequence في which calculations must be performed: Parentheses, Exponents, Multiplication و Division (left to right), Addition و Subtraction (left to right). This is often remembered as **PEMDAS** or **BODMAS**. A prime number is a whole number greater than 1 that has no divisors other than 1 و itself. ال first prime numbers are 2, 3, 5, 7, 11, 13, 17, 19, 23, و 29.

**أمثلة:**
- Prime factorization: 84 = 2² × 3 × 7
- Greatest Common Divisor (GCD) من 24 و 36: 12
- Least Common Multiple (LCM) من 4 و 6: 12

# # Algebra

Algebra uses letters و symbols to represent numbers و quantities في equations و formulas. A **variable** is a symbol (usually a letter) that represents an unknown or changing quantity. An **equation** states that two expressions are equal. Solving an equation means finding ال value(s) من ال variable(s) that make ال equation true.

ال **quadratic formula** solves equations من ال form ax² + bx + c = 0: x = (−b ± √(b²−4ac)) / (2a)


A **function** maps each input to exactly one output. Common functions include:
- Linear: y = mx + b (straight line, constant rate من change)
- Quadratic: y = ax² + bx + c (parabola, curved)
- Exponential: y = a × bˣ (growth or decay, rapid change)
- Logarithmic: y = log_b(x) (inverse من exponential)

**Key concepts:**
- Domain: ال set من all possible input values
- Range: ال set من all possible output values
- Slope: rate من change (m في y = mx + b)
- Intercept: where ال function crosses ال y-axis (b في y = mx + b)

# # Geometry

Geometry is ال branch من mathematics that studies shapes, sizes, positions, و properties من figures. A point has no size; it represents a location. A line extends infinitely في both directions. A line segment has two endpoints. An angle is formed by two rays sharing an endpoint.

**Key rules:**
- ال sum من angles في a triangle is always 180 degrees.
- ال sum من angles في a quadrilateral is always 360 degrees.
- ال Pythagorean theorem: في a right triangle, a² + b² = c² (where c is ال hypotenuse).
- Circle circumference: 2πr
- Circle area: πr²
- Sphere volume: (4/3)πr³

**π (pi)** is approximately 3.14159 و is ال ratio من a circle's circumference to its diameter.

**Common geometric shapes:**
- Triangle: 3 sides, angles sum to 180°
- Square: 4 equal sides, 4 right angles
- Rectangle: 4 sides, opposite sides equal, 4 right angles
- Circle: no sides, continuous curved boundary
- Pentagon: 5 sides, angles sum to 540°
- Hexagon: 6 sides, angles sum to 720°

# # إحصائيات و Probability

إحصائيات is ال العلوم من collecting, analysing, interpreting, و presenting البيانات.

**Measures من central tendency:**
- **Mean** (average): sum من all values divided by ال number من values
- **Median**: middle value when البيانات is sorted (less sensitive to outliers)
- **Mode**: most frequently occurring value (can have multiple modes)

**Measures من spread:**
- **Range**: maximum - minimum
- **Variance**: average من squared deviations from ال mean
- **Standard deviation**: square root من variance (في same units as البيانات)

Probability measures ال likelihood من an event occurring, ranging from 0 (impossible) to 1 (certain). ال probability من two independent الأحداث both occurring is ال product من their individual probabilities.

**Example:** Probability من rolling a 6 on a fair die: 1/6. Probability من rolling two 6s في a row: (1/6) × (1/6) = 1/36.

# # Probability لأجل الحوسبة و ML

A **random variable** is a variable whose value depends on ال outcome من a random process. A **probability distribution** describes how likely each outcome is.

**Common distributions:**
- **Bernoulli**: single trial مع two outcomes (e.g., coin flip)
- **Binomial**: number من successes في n independent Bernoulli trials
- **Normal (Gaussian)**: bell curve, symmetric around ال mean (common في natural phenomena)
- **Poisson**: number من الأحداث في a fixed interval (e.g., emails per hour)

**Expected value** is ال long-run average outcome من a random variable. **Variance** measures spread around that expectation.

**Conditional probability** describes ال probability من an event given another event has occurred: P(A|B) = P(A ∩ B) / P(B) [if P(B) > 0].

**Bayes' theorem** updates beliefs using evidence: P(A|B) = P(B|A) × P(A) / P(B).


في التعلم الآلي, probability underpins classification confidence, uncertainty estimation, Bayesian methods, و many loss functions (such as cross-entropy).

# # Calculus

Calculus is ال branch من mathematics that studies continuous change.

**Differential calculus** deals مع rates من change و slopes من curves, using **derivatives**. ال derivative من a function f(x) represents ال rate من change من f مع respect to x at a point. Notation: f'(x) or df/dx.

**Common derivatives:**
- d/dx [x^n] = n·x^(n−1)
- d/dx [e^x] = e^x
- d/dx [ln(x)] = 1/x
- d/dx [sin(x)] = cos(x)

**Integral calculus** deals مع accumulation من quantities و areas under curves, using **integrals**. ال integral represents ال area under ال curve between two points.

ال **fundamental theorem من calculus** connects differentiation و integration: differentiation و integration are inverse operations.

Calculus was developed independently by Isaac Newton و Gottfried Wilhelm Leibniz في ال 17th century.

# # Number الأنظمة

- **Natural numbers**: 1, 2, 3, 4, ... (counting numbers)
- **Whole numbers**: 0, 1, 2, 3, ... (natural numbers plus zero)

# # Logic و Reasoning

Logic is ال study من valid reasoning.

**Deductive reasoning** draws specific conclusions from general premises. If ال premises are true و ال argument is valid, ال conclusion must be true.
- **Example:** All humans are mortal. Socrates is human. Therefore, Socrates is mortal.

**Inductive reasoning** draws general conclusions from specific observations. It does not guarantee ال conclusion is true, but makes it probable.
- **Example:** Every swan I've seen is white. Therefore, all swans are white. (Note: this is false; black swans exist!)

**Common logical fallacies (errors في reasoning):**
- **Ad hominem**: attacking ال person rather than ال argument
- **Straw man**: misrepresenting an argument to make it easier to attack
- **False dichotomy**: presenting only two options when more exist
- **Circular reasoning**: using ال conclusion as a premise
- **Appeal to authority**: claiming something is true because an authority says so
- **Post hoc fallacy**: assuming that because A happened before B, A caused B

# # Sets

A **set** is a collection من distinct objects.
- **Union** (A ∪ B): all elements from both sets
- **Intersection** (A ∩ B): only elements common to both
- **Empty set** (∅ or {}): contains no elements
- **Subset** (A ⊆ B): all elements من A are also في B
- **Venn diagrams**: visually represent relationships between sets

Set theory is ال foundation من modern mathematics و logic.

# # Binary و Number Bases

Computers represent البيانات في **binary** (base 2), using only digits 0 و 1. Each binary digit is called a **bit**. Eight bits make one **byte**.

**Decimal** is ال base-10 number system humans typically use.

**Hexadecimal** is base 16, using digits 0–9 و letters A–F, often used في الحوسبة to represent binary البيانات compactly.

**Conversions:**
- Binary 1011 = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11 (decimal)
- Hex A3 = 10×16¹ + 3×16⁰ = 160 + 3 = 163 (decimal)

Converting between number bases is a fundamental concept في computer العلوم.

# # Linear Algebra لأجل Developers و ML

Linear algebra studies vectors, matrices, و linear transformations.

A **vector** is an ordered list من numbers (e.g., features في an ML sample).
- Example: [23, 1.8, 175] represents a person's age, height, و weight

A **matrix** is a 2D array من numbers (e.g., model weights or dataset batches).
- Example: [[1, 2], [3, 4]] is a 2×2 matrix

**Matrix multiplication** combines linear transformations و is a core operation في graphics, simulation, و الشبكات العصبية.

**Dot product** measures similarity و projection between vectors:
- a·b = Σ(a_i × b_i)
- **Cosine similarity** = (a·b) / (||a|| × ||b||)
- Cosine similarity ranges from -1 (opposite) to 1 (same direction)

**Eigenvalues و eigenvectors** describe directions that are scaled (not rotated) by a matrix و are used في methods such as PCA (Principal Component Analysis).

**Rank** indicates how much independent information a matrix contains. Low-rank approximations are useful لأجل compression و dimensionality reduction.

Most modern ML workloads rely heavily on optimized linear algebra libraries و hardware acceleration.
