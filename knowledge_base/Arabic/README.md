## 🔧 إرشادات الاستخدام

### لأنظمة الذكاء الاصطناعي
- جميع الملفات منظمة بعناوين هرمية واضحة
- المصطلحات التقنية معرّفة ضمن النص أو في `dictionary.md`
- الإحالات المرجعية تستخدم روابط الماركداون
- أمثلة الشفرة البرمجية تتضمن تمييز الصيغة

### للقراء البشريين
- يتضمن كل ملف أهداف التعلم في البداية
- مستويات الصعوبة موضحة عند الاقتضاء
- تمارين ومسائل تدريبية مضمّنة في الملفات التقنية
- وسائل إيضاح بصرية (رسوم بيانية، جداول) تُستخدم عند الحاجة

## 📝 المساهمة

عند إضافة أو تعديل المحتوى:

1. **اتبع دليل الأسلوب:**
   - استخدم `#` لعنوان الملف فقط
   - استخدم `##` للأقسام الرئيسية
   - استخدم `###` للأقسام الفرعية
   - استخدم `-` للقوائم غير المرتبة
   - أدرج تمييز الصيغة في كتل الشفرة البرمجية

2. **أضف البيانات الوصفية** (ترويسة YAML):
```yaml
---
title: "File Title"
description: "Brief description"
topics: [topic1, topic2, topic3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **أدرج الاستشهادات** للادعاءات الواقعية
4. **أضف الإحالات المرجعية** إلى الملفات ذات الصلة
5. **حدّث هذا الملف التمهيدي (README)** عند إضافة ملفات جديدة
