# الهندسة المعمارية السحابية

## أساسيات الحوسبة السحابية

### ما هي الحوسبة السحابية؟
تقديم موارد الحوسبة عند الطلب (الخوادم، التخزين، قواعد البيانات، الشبكات، البرمجيات) عبر الإنترنت مع نموذج تسعير الدفع حسب الاستخدام.

### الخصائص الأساسية (تعريف NIST)
- **الخدمة الذاتية عند الطلب**: توفير الموارد دون تدخل بشري
- **وصول واسع للشبكة**: متاحة عبر الشبكة باستخدام آليات قياسية
- **تجميع الموارد**: نموذج متعدد المستأجرين مع تخصيص ديناميكي
- **المرونة السريعة**: التوسع للخارج وللداخل بسرعة
- **الخدمة المقاسة**: مراقبة استخدام الموارد وفوترتها

### نماذج نشر الحوسبة السحابية
- **السحابة العامة**: مملوكة من قبل مزودي الخدمة، بنية تحتية مشتركة (AWS، Azure، GCP)
- **السحابة الخاصة**: مخصصة لمؤسسة واحدة (محلية أو مستضافة)
- **السحابة الهجينة**: مزيج من السحابة العامة والخاصة
- **السحابة متعددة المزودين**: استخدام عدة مزودي حوسبة سحابية عامة
- **السحابة المجتمعية**: مشتركة بين مؤسسات لها اهتمامات مشتركة

### نماذج الخدمة

#### البنية التحتية كخدمة (IaaS)
- **توفر**: أجهزة افتراضية، تخزين، شبكات، أنظمة تشغيل
- **أمثلة**: AWS EC2، Google Compute Engine، Azure VMs
- **حالات الاستخدام**: عمليات الترحيل المباشر (Lift-and-shift)، بيئات التطوير، احتياجات التحكم العالي

#### المنصة كخدمة (PaaS)
- **توفر**: منصات تطوير، قواعد بيانات، برمجيات وسيطة
- **أمثلة**: Heroku، Google App Engine، AWS Elastic Beanstalk
- **حالات الاستخدام**: تطوير التطبيقات، نشر واجهات برمجة التطبيقات، الخدمات المصغرة

#### البرمجيات كخدمة (SaaS)
- **توفر**: تطبيقات كاملة عبر الإنترنت
- **أمثلة**: Salesforce، Google Workspace، Microsoft 365، Slack
- **حالات الاستخدام**: البريد الإلكتروني، إدارة علاقات العملاء، التعاون، تطبيقات الأعمال

#### الدالة كخدمة (FaaS) / الحوسبة بدون خادم
- **توفر**: تنفيذ دوال قائم على الأحداث
- **أمثلة**: AWS Lambda، Azure Functions، Google Cloud Functions
- **حالات الاستخدام**: معالجة الأحداث، واجهات برمجة التطبيقات، المهام المجدولة، المعالجة الفورية

## مزودو الحوسبة السحابية الرئيسيون

### أمازون ويب سيرفيسز (AWS)
- **الحصة السوقية**: ~32% (أكبر مزود)
- **الخدمات الرئيسية**:
  - الحوسبة: EC2، Lambda، ECS، EKS
  - التخزين: S3، EBS، Glacier
  - قواعد البيانات: RDS، DynamoDB، Aurora
  - الشبكات: VPC، Route 53، CloudFront
  - الذكاء الاصطناعي/تعلم الآلة: SageMaker، Rekognition، Comprehend

### مايكروسوفت أزور (Azure)
- **الحصة السوقية**: ~23%
- **نقاط القوة**: تكامل المؤسسات، السحابة الهجينة، منظومة مايكروسوفت
- **الخدمات الرئيسية**:
  - الحوسبة: Virtual Machines، Azure Functions، AKS
  - التخزين: Blob Storage، Disk Storage
  - قواعد البيانات: SQL Database، Cosmos DB
  - الشبكات: Virtual Network، Traffic Manager
  - الذكاء الاصطناعي/تعلم الآلة: Azure ML، Cognitive Services

### منصة جوجل السحابية (GCP)
- **الحصة السوقية**: ~10%
- **نقاط القوة**: تحليلات البيانات، الذكاء الاصطناعي/تعلم الآلة، Kubernetes
- **الخدمات الرئيسية**:
  - الحوسبة: Compute Engine، Cloud Functions، GKE
  - التخزين: Cloud Storage، Persistent Disk
  - قواعد البيانات: Cloud SQL، Firestore، Bigtable
  - التحليلات: BigQuery، Dataflow، Pub/Sub
  - الذكاء الاصطناعي/تعلم الآلة: Vertex AI، AutoML

### مزودون آخرون
- **IBM Cloud**: التركيز على المؤسسات، Watson AI
- **Oracle Cloud**: أعباء عمل قواعد البيانات، تطبيقات المؤسسات
- **Alibaba Cloud**: مهيمنة في منطقة آسيا والمحيط الهادئ
- **DigitalOcean**: سهلة الاستخدام للمطورين، عروض مبسطة

## أنماط الهندسة المعمارية السحابية

### مبادئ إطار العمل جيد التصميم (Well-Architected Framework)

#### التميز التشغيلي
- أتمتة العمليات
- إجراء تغييرات متكررة وقابلة للعكس
- تحسين الإجراءات باستمرار
- توقع الفشل

#### الأمان
- تطبيق أساس هوية قوي
- تمكين إمكانية التتبع
- تطبيق الأمان على جميع الطبقات
- أتمتة أفضل ممارسات الأمان
- حماية البيانات أثناء النقل وفي حالة السكون

#### الموثوقية
- اختبار إجراءات الاسترداد
- الاسترداد التلقائي من الفشل
- التوسع الأفقي لتحقيق التوافر
- التوقف عن تخمين السعة
- إدارة التغيير في الأتمتة

#### كفاءة الأداء
- إتاحة التقنيات المتقدمة للجميع
- الانتشار العالمي في دقائق
- استخدام الهياكل المعمارية بدون خادم
- التجربة بشكل أكثر تكرارًا
- مراعاة التوافق الميكانيكي (mechanical sympathy)

#### تحسين التكلفة
- اعتماد نموذج الاستهلاك
- قياس الكفاءة الإجمالية
- التوقف عن إنفاق المال على أعمال غير متمايزة
- تحليل وتخصيص الإنفاق
- استخدام الخدمات المُدارة

### أنماط الهندسة المعمارية الشائعة

#### هندسة الخدمات المصغرة (Microservices)
- تفكيك التطبيقات إلى خدمات صغيرة ومستقلة
- كل خدمة تمتلك بياناتها ومنطقها الخاص
- التواصل عبر واجهات برمجة التطبيقات (REST، gRPC، المراسلة)
- النشر بشكل مستقل
- **الفوائد**: قابلية التوسع، عزل الأعطال، تنوع التقنيات
- **التحديات**: التعقيد الموزع، اتساق البيانات، المراقبة

#### الهندسة المعمارية القائمة على الأحداث
- تتواصل المكونات من خلال الأحداث
- المنتجون يصدرون الأحداث، والمستهلكون يتفاعلون معها
- **الأنماط**: مصدر الأحداث (Event Sourcing)، CQRS، النشر/الاشتراك
- **التقنيات**: Kafka، SNS/SQS، EventBridge، Pub/Sub
- **الفوائد**: الاقتران الفضفاض، قابلية التوسع، المعالجة الفورية

#### الهندسة المعمارية بدون خادم
- لا حاجة لإدارة الخوادم
- الدفع لكل عملية تنفيذ
- التوسع التلقائي
- **المكونات**: الدوال، بوابة واجهة برمجة التطبيقات، الخدمات المُدارة
- **الفوائد**: كفاءة التكلفة، تقليل العمليات، النشر السريع
- **اعتبارات**: البدء البارد (cold starts)، الارتباط بمزود واحد، حدود التنفيذ

#### الهندسة المعمارية الطبقية (متعددة المستويات)
- طبقة العرض (واجهة المستخدم)
- طبقة منطق التطبيق/الأعمال
- طبقة الوصول إلى البيانات
- طبقة قاعدة البيانات
- **الفوائد**: فصل الاهتمامات، سهولة الصيانة
- **الشائع**: تطبيقات الويب ثلاثية الطبقات

#### الهندسة المعمارية القائمة على الفضاء (Space-Based)
- التعامل مع التزامن العالي مع بيانات موزعة
- ذاكرة افتراضية عبر الخوادم
- عقد المعالجة تتوسع بشكل مستقل
- **حالات الاستخدام**: تطبيقات عالية الحجم ومنخفضة زمن الاستجابة

## خدمات الحوسبة

### الأجهزة الافتراضية
- **الأنواع**: عام الغرض، محسّن للحوسبة، محسّن للذاكرة، معالج رسومي (GPU)
- **التسعير**: عند الطلب، الحالات المحجوزة، الحالات الفورية (spot)
- **الإدارة**: مجموعات التوسع التلقائي، موازنات التحميل
- **أفضل الممارسات**: التحجيم الصحيح، الوسم (tagging)، المراقبة، تطبيق التحديثات

### الحاويات
- **Docker**: معيار وقت تشغيل الحاويات
- **التنسيق (Orchestration)**: Kubernetes (EKS، AKS، GKE)، ECS، Fargate
- **الفوائد**: قابلية النقل، الكفاءة، الاتساق
- **السجل (Registry)**: ECR، GCR، ACR، Docker Hub

### الدوال بدون خادم
- **نموذج التنفيذ**: مُشغّل بالأحداث، عديم الحالة
- **الحدود**: زمن التنفيذ، الذاكرة، عمليات التنفيذ المتزامنة
- **حالات الاستخدام**: واجهات برمجة التطبيقات، معالجة الملفات، المهام المجدولة، خلفيات إنترنت الأشياء
- **المراقبة**: عدد الاستدعاءات، الأخطاء، المدة، البدء البارد

## حلول التخزين

### تخزين الكائنات (Object Storage)
- **الخصائص**: هيكل مسطح، بيانات وصفية، وصول عبر HTTP
- **أمثلة**: AWS S3، Google Cloud Storage، Azure Blob
- **حالات الاستخدام**: الأصول الثابتة، النسخ الاحتياطية، بحيرات البيانات، الأرشيفات
- **فئات التخزين**: ساخن، بارد نسبيًا، بارد، أرشيفي (تكلفة/وصول متفاوتان)

### تخزين الكتل (Block Storage)
- **الخصائص**: أحجام خام، مرتبطة بالأجهزة الافتراضية
- **أمثلة**: AWS EBS، Google Persistent Disk، Azure Disks
- **حالات الاستخدام**: قواعد البيانات، أحجام الإقلاع، الاحتياجات عالية الأداء
- **الأنواع**: SSD، HDD، IOPS مخصصة

### تخزين الملفات
- **الخصائص**: أنظمة ملفات مشتركة، بروتوكولات NFS/SMB
- **أمثلة**: AWS EFS، Google Filestore، Azure Files
- **حالات الاستخدام**: إدارة المحتوى، الإعدادات المشتركة، الترحيل المباشر

### تخزين الأرشيف
- **الخصائص**: أقل تكلفة، تأخيرات في الاسترجاع
- **أمثلة**: S3 Glacier، Azure Archive Storage
- **حالات الاستخدام**: الامتثال، النسخ الاحتياطية طويلة الأمد، البيانات التاريخية

## خدمات قواعد البيانات

### قواعد البيانات العلائقية المُدارة
- **الخدمات**: AWS RDS/Aurora، Google Cloud SQL، Azure SQL Database
- **الميزات**: نسخ احتياطية تلقائية، تحديثات، توسع، تكرار
- **المحركات**: MySQL، PostgreSQL، MariaDB، Oracle، SQL Server

### قواعد بيانات NoSQL
- **المستندات**: DocumentDB، Firestore، Cosmos DB
- **المفتاح-القيمة**: DynamoDB، Redis Cache
- **العمود الواسع**: Bigtable، Cassandra (مُدارة)
- **الرسوم البيانية**: Neptune، Cosmos DB (واجهة الرسم البياني)

### مستودعات البيانات
- **الخدمات**: Snowflake، Redshift، BigQuery، Synapse
- **الخصائص**: تخزين عمودي، هندسة MPP
- **حالات الاستخدام**: التحليلات، ذكاء الأعمال، تحليل البيانات واسعة النطاق

### خدمات التخزين المؤقت (Caching)
- **في الذاكرة**: ElastiCache (Redis/Memcached)، Cloud Memorystore
- **تخزين CDN المؤقت**: CloudFront، Cloud CDN، Azure CDN
- **حالات الاستخدام**: تخزين الجلسات، تخزين الاستعلامات مؤقتًا، توصيل المحتوى

## الشبكات

### الشبكات الافتراضية
- **VPC/VNet**: بيئات شبكة معزولة
- **الشبكات الفرعية**: عامة (مواجهة للإنترنت)، خاصة (داخلية فقط)
- **عنونة IP**: كتل CIDR، IPv4/IPv6
- **جداول التوجيه**: التحكم في تدفق حركة المرور

### موازنة التحميل
- **الأنواع**: التطبيق (L7)، الشبكة (L4)، البوابة
- **الميزات**: فحوصات السلامة، إنهاء SSL، الجلسات اللاصقة
- **الخدمات**: ELB/ALB/NLB، Cloud Load Balancing، Azure Load Balancer

### شبكات توصيل المحتوى (CDN)
- **الغرض**: تخزين المحتوى مؤقتًا في مواقع الحافة (edge)
- **الفوائد**: تقليل زمن الاستجابة، تقليل الحمل على المصدر، التوزيع العالمي
- **الخدمات**: CloudFront، Cloud CDN، Azure CDN، Akamai

### خدمات DNS
- **الوظائف**: تسجيل النطاقات، التوجيه، فحوصات السلامة
- **الخدمات**: Route 53، Cloud DNS، Azure DNS
- **سياسات التوجيه**: بسيطة، موزونة، قائمة على زمن الاستجابة، جغرافية، احتياطية عند الفشل

### خيارات الاتصال
- **بوابة الإنترنت**: وصول عام إلى الإنترنت
- **بوابة NAT**: وصول صادر للشبكات الفرعية الخاصة
- **VPN**: أنفاق مشفرة إلى البنية التحتية المحلية
- **Direct Connect/ExpressRoute**: اتصالات خاصة مخصصة
- **VPC Peering**: ربط الشبكات الافتراضية داخل/بين الحسابات

## الأمان في السحابة

### نموذج المسؤولية المشتركة
- **مسؤولية المزود**: أمان "السحابة" نفسها (البنية التحتية)
- **مسؤولية العميل**: الأمان "في" السحابة (البيانات، التطبيقات، الوصول)
- **يختلف حسب الخدمة**: كلما زادت الإدارة، زادت مسؤولية المزود

### إدارة الهوية والوصول (IAM)
- **المستخدمون**: هويات فردية
- **المجموعات**: تجمعات من المستخدمين
- **الأدوار**: بيانات اعتماد مؤقتة للخدمات/المستخدمين
- **السياسات**: مستندات JSON تحدد الصلاحيات
- **المبادئ**: أقل امتياز، فصل المهام

### أمان الشبكة
- **مجموعات الأمان**: جدران حماية ذات حالة للحالات (instances)
- **قوائم التحكم بالوصول للشبكة (Network ACLs)**: جدران حماية عديمة الحالة للشبكات الفرعية
- **جدار حماية تطبيقات الويب (WAF)**: الحماية من استغلالات الويب
- **الحماية من هجمات الحرمان من الخدمة (DDoS)**: Shield، Cloud Armor، DDoS Protection

### حماية البيانات
- **التشفير أثناء السكون**: KMS، مفاتيح مُدارة من قبل العميل
- **التشفير أثناء النقل**: TLS/SSL، HTTPS
- **إدارة المفاتيح**: HSM، تدوير المفاتيح، سجلات التدقيق
- **إدارة الأسرار**: Secrets Manager، Key Vault

### الامتثال والحوكمة
- **الشهادات**: SOC 2، ISO 27001، HIPAA، PCI-DSS، GDPR
- **الأدوات**: تطبيق السياسات، تقارير الامتثال، سجلات التدقيق
- **الأطر**: Cloud Security Alliance، NIST CSF

## DevOps في السحابة

### خدمات التكامل والتسليم المستمر (CI/CD)
- **AWS**: CodePipeline، CodeBuild، CodeDeploy
- **Azure**: Azure DevOps، GitHub Actions
- **GCP**: Cloud Build، Cloud Deploy
- **جهات خارجية**: Jenkins، CircleCI، GitLab CI

### البنية التحتية كشفرة (IaC)
- **Terraform**: متعدد السحابات، تعريفي، إدارة الحالة
- **CloudFormation**: خاص بـ AWS، قوالب YAML/JSON
- **ARM Templates**: خاص بـ Azure
- **Deployment Manager**: خاص بـ GCP
- **Pulumi**: بنية تحتية باستخدام لغات البرمجة
- **الفوائد**: التحكم بالإصدارات، القابلية للتكرار، التوثيق

### إدارة الإعدادات
- **Ansible**: بدون وكيل، كتيبات تشغيل YAML
- **Chef**: قائم على روبي، منظومة ناضجة
- **Puppet**: تعريفي، تقارير قوية
- **SaltStack**: سريع، قائم على بايثون

### المراقبة والملاحظة (Observability)
- **المقاييس**: CloudWatch، Cloud Monitoring، Azure Monitor
- **التسجيل**: CloudWatch Logs، Cloud Logging، Log Analytics
- **التتبع**: X-Ray، Cloud Trace، Application Insights
- **لوحات المعلومات**: CloudWatch Dashboards، Cloud Console
- **التنبيهات**: SNS، تنبيهات Cloud Monitoring، Action Groups

### تنسيق الحاويات (Orchestration)
- **Kubernetes**: معيار التنسيق في الصناعة
- **الخدمات المُدارة**: EKS، AKS، GKE
- **شبكة الخدمة (Service Mesh)**: Istio، Linkerd (إدارة حركة المرور، الأمان)
- **GitOps**: ArgoCD، Flux (عمليات نشر تعريفية)

## إدارة التكاليف

### نماذج التسعير
- **الدفع حسب الاستخدام**: ادفع مقابل ما تستخدمه
- **الحالات المحجوزة**: التزامات لمدة 1-3 سنوات، خصومات كبيرة
- **الحالات الفورية (Spot)**: المزايدة على السعة غير المستخدمة، قد تتعرض للمقاطعة
- **خطط التوفير (Savings Plans)**: تسعير مرن بالتزام
- **الطبقة المجانية**: استخدام مجاني محدود للحسابات الجديدة

### استراتيجيات تحسين التكلفة
- **التحجيم الصحيح**: مطابقة أنواع الحالات مع احتياجات عبء العمل
- **التوسع التلقائي**: التوسع بناءً على الطلب
- **السعة المحجوزة**: الالتزام بأعباء العمل الثابتة
- **استخدام الحالات الفورية**: للاستخدام في أعباء العمل المرنة والمتحملة للأعطال
- **طبقات التخزين**: نقل البيانات غير المتكررة الاستخدام إلى طبقات أرخص
- **التنظيف**: حذف الموارد وغير المستخدمة، اللقطات (snapshots)، صور AMI

### أدوات إدارة التكاليف
- **AWS**: Cost Explorer، Budgets، Trusted Advisor
- **Azure**: Cost Management، Advisor
- **GCP**: تقارير الفوترة، Recommender
- **جهات خارجية**: CloudHealth، CloudCheckr، Datadog

## التوافر العالي والتعافي من الكوارث

### مفاهيم التوافر
- **مناطق التوافر**: مراكز بيانات منفصلة فعليًا ضمن المنطقة
- **المناطق (Regions)**: مناطق جغرافية تضم عدة مناطق توافر
- **مواقع الحافة (Edge Locations)**: مواقع تخزين مؤقت لشبكات CDN عالميًا

### استراتيجيات التوافر العالي
- **متعدد مناطق التوافر**: النشر عبر مناطق التوافر
- **الشفاء الذاتي**: استبدال الحالات الفاشلة تلقائيًا
- **موازنة التحميل**: توزيع حركة المرور عبر الحالات السليمة
- **تكرار قاعدة البيانات**: عمليات نشر متعددة مناطق التوافر، النسخ المتماثلة للقراءة

### استراتيجيات التعافي من الكوارث
- **النسخ الاحتياطي والاستعادة**: نسخ احتياطية دورية، الاستعادة عند الحاجة (أقل تكلفة)
- **الضوء التجريبي (Pilot Light)**: العناصر الأساسية تعمل، التوسع أثناء الكارثة
- **الاستعداد الدافئ (Warm Standby)**: نسخة مصغرة تعمل دائمًا
- **متعدد المواقع نشط/نشط**: إنتاج كامل في مناطق متعددة (أعلى تكلفة)

### هدف زمن الاسترداد وهدف نقطة الاسترداد
- **هدف زمن الاسترداد (RTO)**: الحد الأقصى المقبول لوقت التوقف
- **هدف نقطة الاسترداد (RPO)**: الحد الأقصى المقبول لفقدان البيانات
- **اختيار الاستراتيجية**: بناءً على متطلبات العمل والميزانية

## الاتجاهات الناشئة

### الحوسبة الطرفية (Edge Computing)
- معالجة البيانات بالقرب من المصدر
- **الخدمات**: AWS Outposts، Wavelength، Azure Edge، Cloud CDN
- **حالات الاستخدام**: إنترنت الأشياء، التحليلات الفورية، التطبيقات منخفضة زمن الاستجابة

### السحابة المتعددة والسحابة الهجينة
- تجنب الارتباط بمزود واحد
- الاستفادة من أفضل الخدمات المتاحة
- **الأدوات**: Terraform، Anthos، Arc، CloudHealth

### خدمات الذكاء الاصطناعي/تعلم الآلة
- نماذج مُدربة مسبقًا: الرؤية، الكلام، اللغة
- تدريب نماذج مخصصة: SageMaker، Vertex AI، Azure ML
- MLOps: نشر النماذج، المراقبة، الحوكمة

### الحوسبة الكمومية
- **الخدمات**: AWS Braket، Azure Quantum
- **الحالة**: مرحلة مبكرة، تجريبية
- **الإمكانات**: التشفير، التحسين، اكتشاف الأدوية

### السحابة المستدامة
- تتبع البصمة الكربونية
- الالتزامات بالطاقة المتجددة
- الاستخدام الفعال للموارد
- أنماط الهندسة المعمارية الخضراء
