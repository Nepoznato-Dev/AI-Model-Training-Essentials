# لغات البرمجة

## Python

Python هي لغة برمجة عالية المستوى، مفسرة، ديناميكية النوع، متعددة الأغراض. تؤكد على قابلية القراءة وتستخدم المسافة البادئة ذات المعنى كفواصل للكتل.

### الصيغة الأساسية

```python
# المتغيرات والأنواع
name: str = "Alice"
age: int = 30
score: float = 9.5
active: bool = True

# الشروط
if age >= 18:
    print("بالغ")
elif age >= 13:
    print("مراهق")
else:
    print("طفل")

# الحلقات
for i in range(5):
    print(i)

while active:
    active = False
```

### الدوال وتعليقات النوع

```python
def greet(name: str, times: int = 1) -> str:
    return (f"مرحبًا، {name}! " * times).strip()
```

### فهم القوائم

```python
squares = [x**2 for x in range(10)]
evens   = [x for x in range(20) if x % 2 == 0]
```

### الفئات والبرمجة كائنية التوجه

```python
class Person:
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age
    
    def introduce(self) -> str:
        return f"اسمي {self.name} وعمري {self.age} سنة."
```

## JavaScript

JavaScript هي لغة برمجة مفسرة، كائنية التوجه، قائمة على الأحداث، تُستخدم أساسًا لتطوير الويب من جانب العميل والخادم.

### الصيغة الأساسية

```javascript
// المتغيرات والأنواع
let name = "Alice";
const age = 30;
let score = 9.5;
let active = true;

// الشروط
if (age >= 18) {
    console.log("بالغ");
} else if (age >= 13) {
    console.log("مراهق");
} else {
    console.log("طفل");
}

// الحلقات
for (let i = 0; i < 5; i++) {
    console.log(i);
}

while (active) {
    active = false;
}
```

### الدوال

```javascript
function greet(name, times = 1) {
    return `مرحبًا، ${name}! `.repeat(times).trim();
}

// دالة السهم
const greetArrow = (name, times = 1) => {
    return `مرحبًا، ${name}! `.repeat(times).trim();
};
```

### معالجة المصفوفات

```javascript
const numbers = [1, 2, 3, 4, 5];
const squares = numbers.map(x => x ** 2);
const evens = numbers.filter(x => x % 2 === 0);
const sum = numbers.reduce((acc, x) => acc + x, 0);
```

## Java

Java هي لغة برمجة مجمعة، كائنية التوجه، مستقلة عن المنصة، تُستخدم على نطاق واسع في تطبيقات المؤسسات وتطوير Android.

### الصيغة الأساسية

```java
// المتغيرات والأنواع
String name = "Alice";
int age = 30;
double score = 9.5;
boolean active = true;

// الشروط
if (age >= 18) {
    System.out.println("بالغ");
} else if (age >= 13) {
    System.out.println("مراهق");
} else {
    System.out.println("طفل");
}

// الحلقات
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

while (active) {
    active = false;
}
```

### الفئات والبرمجة كائنية التوجه

```java
public class Person {
    private String name;
    private int age;
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    public String introduce() {
        return "اسمي " + name + " وعمري " + age + " سنة.";
    }
}
```

## C++

C++ هي لغة برمجة مجمعة، عالية الأداء، متعددة الأغراض، تُستخدم للأنظمة وألعاب الفيديو والتطبيقات الحرجة.

### الصيغة الأساسية

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // المتغيرات والأنواع
    string name = "Alice";
    int age = 30;
    double score = 9.5;
    bool active = true;
    
    // الشروط
    if (age >= 18) {
        cout << "بالغ" << endl;
    } else if (age >= 13) {
        cout << "مراهق" << endl;
    } else {
        cout << "طفل" << endl;
    }
    
    // الحلقات
    for (int i = 0; i < 5; i++) {
        cout << i << endl;
    }
    
    while (active) {
        active = false;
    }
    
    return 0;
}
```

## أساسيات الترميز (مستقل عن اللغة)

المفاهيم الأساسية للبرمجة مشتركة بين جميع اللغات:

- **المتغيرات**: تخزين البيانات المسماة
- **أنواع البيانات**: تعريف طبيعة البيانات (أرقام، نص، قيم منطقية، إلخ)
- **هياكل التحكم**: الشروط (if/else) والحلقات (for، while)
- **الدوال**: كتل قابلة لإعادة الاستخدام من الكود
- **هياكل البيانات**: المصفوفات، القوائم، القواميس، المجموعات
- **البرمجة كائنية التوجه**: الفئات، الكائنات، الوراثة، تعدد الأشكال
- **معالجة الأخطاء**: Try/catch، الاستثناءات
- **الإدخال/الإخراج**: قراءة وكتابة البيانات

تنطبق هذه المفاهيم الأساسية بغض النظر عن لغة البرمجة المختارة. إتقان هذه الأساسيات يسهل تعلم لغات جديدة.
