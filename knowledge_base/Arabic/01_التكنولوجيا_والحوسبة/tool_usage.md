# استخدام الأدوات

## Git — التحكم في الإصدارات
### سير العمل الأساسي
1. إنشاء مستودع أو استنساخه.
2. فحص الحالة والتاريخ.
3. إضافة التعديلات.
4. الالتزام بالتغييرات.
5. الدفع إلى المستودع البعيد.

### التفرعات
- إنشاء فرع جديد للعمل: `git checkout -b feature/new-thing`

### الدمج وإعادة التأسيس
- الدمج يجمع الفروع.
- إعادة التأسيس تحافظ على تاريخ خطي.

### سير عمل طلبات السحب
- افتح فرعًا
- ادفعه
- اطلب مراجعة
- ادمج بعد الموافقة

### التراجع عن التغييرات
- `git restore`
- `git reset`
- `git revert`
