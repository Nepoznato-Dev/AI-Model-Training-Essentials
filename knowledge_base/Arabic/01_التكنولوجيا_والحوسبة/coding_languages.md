# لغات البرمجة

## Python
### أساسيات الصياغة
- المسافات البادئة مهمة جدًا.
- استخدم أسماء واضحة للمتغيرات.

### المتغيرات والأنواع
- `int`, `float`, `str`, `bool`
- القوائم، القواميس، المجموعات

### الشروط والحلقات
- `if / elif / else`
- `for` و `while`

### الدوال والتلميحات النوعية
- الدوال تعيد قيمة أو أكثر.
- التلميحات النوعية تحسن الوضوح.

### الأدوات
- `pip`
- `venv`
- `pytest`

## JavaScript
### الصياغة الحديثة (ES6+)

### البرمجة غير المتزامنة
- `async / await`
- `Promise`

### أدوات شائعة
