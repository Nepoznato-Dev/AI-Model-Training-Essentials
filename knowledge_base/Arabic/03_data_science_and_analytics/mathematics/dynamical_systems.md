# الأنظمة الديناميكية
يصف **النظام الديناميكي** كيفية تطور الحالة بمرور الوقت وفقًا لقاعدة ثابتة. من مدارات الكواكب إلى الديناميكيات السكانية، ومن أنماط الطقس إلى تدريب الشبكات العصبية، توفر نظرية الأنظمة الديناميكية اللغة والأدوات اللازمة لفهم كيفية تغير الأشياء. يغطي هذا الملف المعادلات التفاضلية العادية (ODEs)، والمعادلات التفاضلية الجزئية (PDEs)، وتحليل الاستقرار، والفوضى، والتشعبات.

## المعادلات التفاضلية العادية (ODEs)
يربط ODE دالة بمشتقاتها فيما يتعلق بمتغير مستقل واحد (عادة الوقت).
### التصنيف
| عقار | أنواع |
|----------|-------|
| **الطلب** | أعلى مشتق موجود (الترتيب الأول، الترتيب الثاني، وما إلى ذلك) |
| ** الخطية مقابل غير الخطية ** | خطي: y'' + p(t)y' + q(t)y = g(t); غير خطية: أي شيء آخر |
| **متجانسة** | g(t) = 0 (لا يوجد مصطلح قسري) |
| **الحكم الذاتي** | لا يوجد اعتماد واضح على الوقت: dy/dt = f(y) |
| **المعاملات الثابتة** | p, q ثوابت |
### قصائد غنائية غنائية من الدرجة الأولى
**الصيغة العامة:** dy/dt = f(t, y)
| اكتب | النموذج | طريقة الحل |
|------|------|-----------------|
| قابلة للفصل | دي/دت = ز(ر)ح(ذ) | افصل وادمج: ∫dy/h(y) = ∫g(t)dt |
| خطي من الدرجة الأولى | dy/dt + p(t)y = q(t) | عامل التكامل: μ(t) = e^(∫p dt) |
| بالضبط | M(t,y)dt + N(t,y)dy = 0 مع ∂M/∂y = ∂N/∂t | ابحث عن الدالة المحتملة F(t,y) |
| برنولي | dy/dt + p(t)y = q(t)yⁿ | عوّض v = y^(1−n) بالخطية |
**مثال عملي (عامل التكامل):** حل dy/dt + 2y = e^(−t), y(0) = 1.
- عامل التكامل: μ(t) = e^(∫2 dt) = e^(2t)
- اضرب: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- التكامل: e^(2t)y = e^t + C
- ص(ر) = ه^(−t) + Ce^(−2t)
- الشرط الأولي: y(0) = 1 → 1 = 1 + C → C = 0
- الحل: y(t) = e^(−t)
### المعادلات التفاضلية التفاضلية الخطية من الدرجة الثانية
**الصيغة العامة:** ay'' + by' + cy = g(t)
**الحالة المتجانسة** (g ​​= 0): حل المعادلة المميزة ar² + br + c = 0.
| المميز | جذور | الحل العام |
|-------------|------|-----------------|
| ب² > 4AC (مفرط التخميد) | اثنان حقيقيان مختلفان r₁، r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| ب² = 4ac (مخمد بشكل خطير) | تكرار الجذر الحقيقي ص | ذ = (C₁ + C₂t)e^(rt) |
| ب² <4ac (تحت التخميد) | الجذور المعقدة α ± βi | y = e^(αt)(C₁ cos βt + C₂ sin βt) |
**التفسير المادي:** نظام المثبط الزنبركي الشامل mx'' + bx' + kx = 0.
- التخميد الزائد: تخميد شديد، عدم التذبذب (إغلاق الباب)
- مخمد بشكل خطير: أسرع عودة دون تذبذب (هدف تصميم تعليق السيارة)
- ناقص التخميد: يتأرجح بسعة متدهورة (وتر الجيتار)
### أنظمة ODEs
تتضمن العديد من الأنظمة الحقيقية متغيرات متفاعلة متعددة:
دس/دت = و(س، ص)
دي / دينارا = ز (س، ص)
يمكن كتابة هذا في شكل متجه: d**x**/dt = **F**(**x**)
**الأنظمة الخطية:** d**x**/dt = A**x**، حيث A عبارة عن مصفوفة.
يعتمد الحل على القيم الذاتية لـ A:
| القيم الذاتية | السلوك |
|-------------|-----------|
| كلاهما حقيقي، سلبي | العقدة المستقرة (جميع المسارات تتلاقى مع الأصل) |
| كلاهما حقيقي وإيجابي | عقدة غير مستقرة |
| علامات حقيقية متضادة | نقطة السرج (غير مستقرة) |
| الجزء الحقيقي المعقد والسلبي | دوامة مستقرة (تذبذب مخمد) |
| جزء حقيقي معقد وإيجابي | دوامة غير مستقرة |
| خيالي خالص | المركز (المدارات المغلقة) |

## صور المرحلة
**صورة الطور** تصور مسارات النظام الديناميكي في مساحة الحالة (دون حل صريح).
### الميزات الرئيسية
| ميزة | الوصف |
|---------|------------|
| **النقطة الثابتة (التوازن)** | حيث dx/dt = 0 (بدون حركة) |
| **المسار** | المسار الذي يتتبعه النظام في مساحة الحالة |
| ** نولكلين ** | منحنى حيث مشتقة أحد المكونات هي صفر |
| ** دورة الحد ** | مدار مغلق معزول (تذبذب ذاتي الاكتفاء) |
| **حوض الجذب** | مجموعة من الشروط الأولية المؤدية إلى جاذب معين |
| **فاصلة** | الحدود بين أحواض الجذب المختلفة |
### نموذج المفترس والفريسة (لوتكا-فولتيرا)
dx/dt = αx - βxy (الفريسة)
dy/dt = δxy − γy (المفترس)
**النقاط الثابتة:**
1. (0، 0) — الانقراض (نقطة السرج)
2. (γ/δ, α/β) — التعايش (المركز — مدارات مغلقة)
يُظهر النظام تذبذبات دورية: زيادة الفريسة ← زيادة الحيوانات المفترسة ← انخفاض الفريسة ← انخفاض الحيوانات المفترسة ← تكرار الدورة.

## تحليل الاستقرار
### الاستقرار الخطي
بالنسبة لنقطة ثابتة x*، قم بالتخطيط حولها: Let u = x − x*، ثم du/dt ≈ J(x*)u حيث J هي المصفوفة اليعقوبية.
**معيار الاستقرار:** النقطة الثابتة هي:
- **مستقر** إذا كانت جميع القيم الذاتية لـ J تحتوي على أجزاء حقيقية سالبة
- **غير مستقرة** إذا كانت أي قيمة ذاتية تحتوي على جزء حقيقي موجب
- **مستقرة هامشيًا** إذا كانت القيم الذاتية تحتوي على أجزاء حقيقية صفر (تحتاج إلى تحليل غير خطي)
### استقرار ليابونوف
** طريقة ليابونوف المباشرة ** تحدد الاستقرار بدون خطية.
A ** دالة Lyapunov ** V(x) ترضي:
1. V(x*) = 0 و V(x) > 0 لـ x ≠ x* (موجب محدد)
2. dV/dt ≥ 0 على طول المسارات (غير متزايدة)
| الحالة | الخلاصة |
|-----------|-----------|
| دي في/دت< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | غير مستقر |
**مثال عملي:** النظام dx/dt = −x + y², dy/dt = −y.
- جرب V(x,y) = x² + y² (دالة تشبه الطاقة)
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- الأصل القريب: dV/dt ≈ −2x² − 2y² < 0 (بالنسبة لـ y الصغيرة، يهيمن −2y²)
- الخلاصة: الأصل مستقر محليا مقاربا

## نظرية الفوضى
**الفوضى** حتمية ولكن لا يمكن التنبؤ بها: يتبع النظام قواعد محددة، ولكن الاختلافات الصغيرة في الظروف الأولية تؤدي إلى نتائج مختلفة إلى حد كبير.
### متطلبات الفوضى
| عقار | الوصف |
|----------|------------|
| حتمية | لا عشوائية – تحكمها معادلات دقيقة |
| حساس للشروط الأولية | المسارات القريبة تتباعد بشكل كبير |
| يحدها | المسارات لا تهرب إلى ما لا نهاية |
| غير دورية | لا يتكرر بالضبط |
### نظام لورنز
المثال الكلاسيكي للفوضى الحتمية:
دس/دت = σ(ص - س)
dy/dt = x(ρ − z) − y
dz/dt = xy - βz
مع المعلمات القياسية σ = 10، ρ = 28، β = 8/3:
- النظام به ثلاث نقاط ثابتة، كلها غير مستقرة
- تدور المسارات حول نقطة ثابتة واحدة، ثم تتحول فجأة إلى النقطة الأخرى
- والنتيجة هي **جاذب لورينز** — جاذب غريب ذو بنية كسورية
**أس ليابونوف:** يقيس معدل انحراف المسارات القريبة.
- الأس ليابونوف الإيجابي → الفوضى
- لنظام لورينز مع المعلمات القياسية: الأس الأكبر ≈ 0.9 > 0
### الخريطة اللوجستية
نظام منفصل بسيط يظهر الفوضى:
x_{n+1} = rx_n(1 − x_n)
| المعلمة ص | السلوك |
|-------------|-----------|
| 0 < ص < 1 | يموت السكان (س → 0) |
| 1 < ص < 3 | نقطة ثابتة مستقرة عند x = 1 − 1/r |
| 3 < ص < 3.449 | تذبذب الفترة 2 |
| 3.449 < ص < 3.544 | تذبذب الفترة 4 |
| 3.544 < ص < 3.570 | الفترة 8، 16، 32، ... (سلسلة مضاعفة الفترة) |
| ص ≈ 3.570 | بداية الفوضى |
| 3.570 < ص < 4 | في الغالب فوضوية، مع نوافذ دورية |
| ص = 4 | فوضوية بالكامل على [0، 1] |
### تأثير الفراشة
الاسم الشائع للاعتماد الحساس على الشروط الأولية. في أنظمة الطقس (التي نموذجها معادلات لورينز)، فإن الفراشة التي ترفرف بجناحيها في البرازيل يمكن أن تؤدي إلى إحداث إعصار في تكساس - ليس لأن الفراشة تسبب ذلك، ولكن لأن الاضطرابات الصغيرة تنمو بشكل كبير.

## نظرية التشعب
**التشعب** هو تغيير نوعي في سلوك النظام عندما تتغير المعلمة.
### أنواع التشعبات
| التشعب | النموذج العادي | ماذا يحدث |
|-------------|---------------------------|--------|
| ** عقدة السرج ** | dx/dt = r − x² | تظهر/تختفي نقطتان ثابتتان |
| **تحويلي** | dx/dt = rx − x² | نقطتان ثابتتان تبادل الاستقرار |
| **المذراة (فوق الحرجة)** | dx/dt = rx − x³ | تنقسم النقطة المستقرة إلى نقطتين مستقرتين + نقطة غير مستقرة |
| **المذراة (دون الحرجة)** | dx/dt = rx + x³ | انهيار الفروع غير المستقرة (كارثية في كثير من الأحيان) |
| **هوبف** | نظام ثنائي الأبعاد | تصبح النقطة الثابتة غير مستقرة، وتظهر دورة الحد |
### مخطط التشعب
مخطط من النقاط الثابتة مقابل قيمة المعلمة، يوضح الاستقرار (صلب = مستقر، متقطع = غير مستقر). يكشف مخطط التشعب للخريطة اللوجستية عن طريق مضاعفة الفترة إلى الفوضى وثابت فيجنباوم الشهير δ ≈ 4.669 (النسبة العالمية بين فترات التشعب المتعاقبة).

## المعادلات التفاضلية الجزئية (PDEs)
تتضمن PDEs وظائف لمتغيرات متعددة ومشتقاتها الجزئية.
### تصنيف أجهزة PDE الخطية من الدرجة الثانية
بالنسبة لـ Au_xx + 2Bu_xy + Cu_yy + ... = 0:
| اكتب | الحالة | السلوك | مثال |
|------|-----------|----------|---------|
| ** الاهليلجيه ** | ب² - أس< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | انتشار الموجة، يحافظ على الملامح الحادة | المعادلة الموجية: u_tt = c²u_xx |
### المعادلة الحرارية
∂u/∂t = α ∂²u/∂x²
نماذج انتشار الحرارة، انتشار السكان، تسعير الخيارات (بلاك سكولز).
| عقار | بيان |
|----------|----------|
| تنعيم | تصبح الحلول سلسة على الفور، حتى من البيانات الأولية المتقطعة |
| المبدأ الأقصى | تحدث درجة الحرارة القصوى عند الحدود أو الوقت الأولي |
| انعكاس الزمن | لا رجعة فيه — لا يمكن الرجوع إلى الوراء |
### المعادلة الموجية
∂²u/∂t² = c² ∂²u/∂x²
نماذج اهتزاز الأوتار، الصوت، الموجات الكهرومغناطيسية.
| عقار | بيان |
|----------|----------|
| انتشار | تنتقل الاضطرابات بسرعة c |
| الرجوعية | عكس الزمن |
| حل دالمبرت | u(x,t) = f(x−ct) + g(x+ct) (تراكب الموجات اليسرى/اليمين) |
### معادلة لابلاس
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
تمثل المحاليل (الوظائف التوافقية) درجة حرارة الحالة المستقرة، والجهد الكهروستاتيكي، وتدفق السوائل غير القابلة للضغط.
| عقار | بيان |
|----------|----------|
| خاصية القيمة المتوسطة | u(x₀) = متوسط ​​u على أي دائرة مركزها x₀ |
| المبدأ الأقصى | لا يوجد حد أقصى داخلي أو حد أدنى |
| التفرد | يتم تحديده بالكامل من خلال الشروط الحدودية |

## ملخص
| الموضوع | الفكرة الأساسية | أداة رئيسية |
|-------|----------|----------|
| قصائد غنائية | الدوال ومشتقاتها الزمنية | المعادلات المميزة، تكامل العوامل |
| أنظمة ODEs | متغيرات متفاعلة متعددة | تحليل القيمة الذاتية لجاكوبيان |
| صور المرحلة | تصور الديناميكيات في مساحة الدولة | النقاط الثابتة، الخطوط الفارغة، الدورات الحدية |
| الاستقرار | فهل يعود النظام إلى توازنه؟ | الخطية، وظائف لابونوف |
| الفوضى | عدم القدرة على التنبؤ الحتمية | دعاة لابونوف، عوامل جذب غريبة |
| التشعبات | التغيرات النوعية مع المعلمات | الأشكال العادية، الرسوم البيانية التشعبية |
| PDEs | دوال المتغيرات المتعددة | معادلات الحرارة والموجة ولابلاس |
نظرية النظم الديناميكية هي رياضيات التغيير. فهو يفسر لماذا تستقر بعض الأنظمة، ولماذا يتأرجح بعضها، ولماذا يتصرف بعضها بشكل فوضوي. بالنسبة لعلماء البيانات، فهو يوفر أدوات لفهم ديناميكيات التدريب، وتصميم خوارزميات مستقرة، ونمذجة السلاسل الزمنية، وبناء الجيل التالي من نماذج التعلم الآلي المبنية على الفيزياء.
