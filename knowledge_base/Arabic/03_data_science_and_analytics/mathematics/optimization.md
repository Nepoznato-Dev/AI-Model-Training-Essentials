# تحسين
التحسين هو رياضيات إيجاد أفضل حل من مجموعة من الحلول الممكنة. فهو يسأل: بالنظر إلى الوظيفة والقيود، ما المدخلات التي تقلل (أو تزيد) المخرجات؟ التحسين هو محرك التعلم الآلي - تدريب النموذج يعني تقليل وظيفة الخسارة. ويظهر في بحوث العمليات، والاقتصاد، والتصميم الهندسي، وفي كل المجالات الكمية تقريبًا.
---

## صياغة المشكلة
**مشكلة التحسين** العامة لها الشكل:
تصغير f(x)
تخضع لـ: gᵢ(x) ≥ 0 (قيود عدم المساواة)، hⱼ(x) = 0 (قيود المساواة)
| مصطلح | معنى |
|------|---------|
| ** الدالة الموضوعية ** f(x) | الكمية المراد تقليلها (أو تعظيمها) |
| **متغيرات القرار** x | القيم التي يمكننا التحكم بها |
| **المنطقة الممكنة** | مجموعة الكل x تلبي جميع القيود |
| **الحد الأدنى العالمي** | ممكن x* مع f(x*) ≥ f(x) لجميع x ممكن |
| **الحد الأدنى المحلي** | ممكن x* مع f(x*) ≥ f(x) لجميع x ممكن في بعض الأحياء |
| **مشكلة محدبة** | f محدبة، والمنطقة الممكنة هي مجموعة محدبة (الحد الأدنى المحلي = الحد الأدنى العالمي) |
---

## البرمجة الخطية (LP)
عندما يكون الهدف وجميع القيود **خطية**، تكون المشكلة في البرنامج الخطي.
### النموذج القياسي
تصغير cᵀx
تخضع لـ: الفأس ≥ ب، س ≥ 0
حيث ج، س ∈ ℝⁿ، أ ∈ ℝᵐˣⁿ، ب ∈ ℝᵐ.
### ملكيات
| عقار | بيان |
|----------|----------|
| التحدب | LP دائمًا مشكلة محدبة |
| الحل الأمثل | دائمًا عند قمة (نقطة الزاوية) للبوليتوب الممكن |
| الوجود | إذا كانت المنطقة الممكنة محدودة وغير فارغة، فإن الحل الأمثل موجود |
| أوبتيما متعددة | إذا كان هناك رأسان مثاليان، فإن كل نقطة على الحافة بينهما هي أيضًا الأمثل |
### الطريقة البسيطة
تتحرك **الطريقة البسيطة** (Dantzig, 1947) على طول حواف متعدد الجوانب الممكن من قمة إلى قمة، مما يؤدي دائمًا إلى تحسين الهدف، حتى الوصول إلى المستوى الأمثل.
| عقار | القيمة |
|----------|-------|
| أسوأ الأوقات | O(2ⁿ) (أسي — نادر في الممارسة) |
| متوسط ​​​​الوقت | كثيرات الحدود لمعظم المشاكل العملية |
| الفكرة الرئيسية | انتقل إلى الرأس المجاور بقيمة موضوعية أفضل |
**الخوارزمية (نظرة عامة):**
1. ابدأ بالحل الأساسي الممكن (قمة polytope)
2. اختر متغير الإدخال (الذي يعمل على تحسين الهدف)
3. اختر متغير المغادرة (الحفاظ على الجدوى)
4. المحور: الانتقال إلى القمة الجديدة
5. كرر ذلك حتى لا يوجد أي اتجاه للتحسن
### طرق النقاط الداخلية
البديل عن البسيط: الاقتراب من المستوى الأمثل من داخل المنطقة الممكنة.
| عقار | القيمة |
|----------|-------|
| أسوأ الأوقات | كثير الحدود (O(n³·⁵) لبعض المتغيرات) |
| الأداء العملي | تتنافس مع البسيط في المشاكل الكبيرة |
| الفكرة الرئيسية | اتبع "المسار المركزي" عبر الداخل |
### مثال LP العملي
**المشكلة:** مصنع ينتج كراسي (x₁) وطاولات (x₂).
- الربح: 30 دولارًا لكل كرسي، و50 دولارًا لكل طاولة
- الخشب: 2x₁ + 4x₂ ≥ 100 (أقدام اللوحة متوفرة)
- العمالة: x₁ + 3x₂ ≥ 60 (الساعات المتاحة)
- الحد الأقصى: 30x₁ + 50x₂
**الحل (طريقة رسومية لمتغيرين):**
- رؤوس المنطقة الممكنة: (0,0)، (30,0)، (40,10)، (0,20)
- تقييم الهدف في كل قمة:
  - (0,0): الربح = 0
  - (30,0): الربح = 900
  - (40,10): الربح = 1700 ← الأمثل
  - (0,20): الربح = 1000
- **الأمثل:** x₁ = 40 كرسيًا، x₂ = 10 طاولات، الربح = 1700 دولار

## تحسين محدب
تكون المشكلة **محدبة** إذا كانت الدالة الهدف محدبة وكانت المنطقة الممكنة عبارة عن مجموعة محدبة.
### مجموعات ووظائف محدبة
| المفهوم | التعريف |
|---------|-----------|
| **مجموعة محدبة** | لأي x، y في المجموعة و t ∈ [0,1]: tx + (1−t)y موجود أيضًا في المجموعة |
| **وظيفة محدبة** | f(tx + (1−t)y) ≥ tf(x) + (1−t)f(y) للجميع t ∈ [0,1] |
| ** محدب بدقة ** | عدم المساواة صارمة بالنسبة لـ t ∈ (0,1) وx ≠ y |
**الخاصية الرئيسية:** بالنسبة للتحسين المحدب، كل حد أدنى محلي هو حد أدنى عالمي.
### وظائف محدبة مشتركة
| وظيفة | محدب؟ | أين |
|----------|--------|-------|
| الفأس + ب (خطي) | نعم (ومقعرة) | في كل مكان |
| ×² | نعم | ℝ |
| ه| نعم | ℝ |
| −سجل(س) | نعم | س > 0 |
| \|x\|ᵖ (ص ≥ 1) | نعم | ℝⁿ |
| الحد الأقصى (f₁، f₂) إذا كان f₁، f₂ محدب | نعم | تقاطع المجالات |
### نزول متدرج
خوارزمية التحسين الأساسية في التعلم الآلي.
**قاعدة التحديث:** x_{k+1} = x_k − α∇f(x_k)
حيث α > 0 هو **معدل التعلم** (حجم الخطوة).
| البديل | تحديث القاعدة | ميزة |
|---------|------------|-----------|
| ** الدفعة جي دي ** | س ← س − α∇f(x) | التقارب المستقر |
| **مؤشر ستوكاستيك GD (SGD)** | x ← x − α∇fᵢ(x) (عينة واحدة) | سريع لكل تكرار، ويهرب من الحد الأدنى المحلي |
| ** دفعة صغيرة دولار سنغافوري ** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | التوازن بين الدفعة والعشوائية |
| **الزخم** | ت ← βv − α∇f(x); س ← س + ت | يتسارع عبر المناطق المسطحة |
| **آدم** | معدلات التعلم التكيفي لكل معلمة | يعمل بشكل جيد خارج الصندوق للتعلم العميق |
| **RMSprop** | مقياس معدل التعلم عن طريق تشغيل متوسط ​​حجم التدرج | جيد لشبكات RNN |
### معدلات التقارب
| الطريقة | محدب و | محدب بقوة و |
|--------|---------|------------------|
| نزول متدرج | يا(1/ك) | O((1−μ/L)ᵏ) (خطي) |
| دولار سنغافوري | يا(1/√ك) | يا(1/ك) |
| GD المتسارع (نيستيروف) | O(1/ك²) | O((1−√(μ/L))ᵏ) |
حيث k = عدد التكرار، μ = معلمة التحدب القوية، L = ثابت Lipschitz.
### اختيار معدل التعلم
| استراتيجية | الوصف |
|----------|------------|
| ثابت α | بسيطة ولكنها قد تتباعد (كبيرة جدًا) أو تتقارب ببطء (صغيرة جدًا) |
| بحث الخط | ابحث عن α الذي يقلل f(x − α∇f(x)) على طول اتجاه التدرج |
| جداول الاضمحلال | α_t = α₀ / (1 + βt) أو α_t = α₀ · βᵗ |
| الاحماء | ابدأ صغيرًا ثم زد ثم اضمحلال (شائع في تدريب المحولات) |
| التكيف (آدم) | معدلات التعلم لكل معلمة بناءً على إحصائيات التدرج |

## التحسين المقيد
### مضاعفات لاغرانج
بالنسبة للمشكلة: قم بتصغير f(x) إلى h(x) = 0.
**لاغرانج:** L(x, lect) = f(x) + lecth(x)
عند الوضع الأمثل: ∇ₓL = 0 و ∇_lectL = 0 (مما يعطي h(x) = 0).
**مثال عملي:** تصغير f(x,y) = x² + y² مع مراعاة x + y = 1.
- ل = x² + y² + lect(x + y − 1)
- ∂L/∂x = 2x + lect = 0 → x = −lect/2
- ∂L/∂y = 2y +  = 0 → y = −/2
- القيد: x + y = 1 → −lect = 1 → lect = −1
- الحل: س = 1/2، ص = 1/2، و = 1/2
### شروط كي كي تي
تعمل **شروط كاروش-كوهن-تاكر (KKT)** على تعميم مضاعفات لاغرانج على قيود عدم المساواة.
من أجل: تصغير f(x) مع مراعاة gᵢ(x) ≥ 0، hⱼ(x) = 0.
**لاغرانج:** L(x, ο, ν) = f(x) + Σᵢ ᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**شروط كي كي تي** (ضرورية لتحقيق الأداء الأمثل):
| الحالة | معادلة |
|-----------|----------|
| قرطاسية | ∇ₓL = 0 |
| الجدوى الأولية | gᵢ(x) ≥ 0, hⱼ(x) = 0 |
| جدوى مزدوجة | ᵢ ≥ 0 |
| التراخي التكميلي | ᵢgᵢ(x) = 0 للكل i |
**التراخي التكميلي** يعني: إذا كان القيد gᵢ غير نشط (gᵢ(x) < 0)، فإن ᵢ = 0 (لا يؤثر القيد على الحل).
بالنسبة للمشكلات المحدبة التي تستوفي حالة سلاتر، فإن شروط كي كي تي ضرورية وكافية.

## الازدواجية
كل مشكلة تحسين (**الأساسية**) لها مشكلة **ثنائية** مرتبطة بها.
###ازدواجية ضعيفة وقوية
| المفهوم | بيان |
|---------|---------|
| **وظيفة مزدوجة** | g(π, ν) = infₓ L(x, π, ν) |
| **مشكلة مزدوجة** | قم بتعظيم g(lect, ν) الخاضع لـ lect ≥ 0 |
| **ازدواجية ضعيفة** | الأمثل المزدوج ≥ الأمثل البدائي (يثبت دائمًا) |
| **ازدواجية قوية** | ثنائي أمثل = أولي أمثل (ينطبق على المشاكل المحدبة مع حالة سلاتر) |
| **فجوة الازدواجية** | الأمثل البدائي – الأمثل المزدوج (صفر تحت الازدواجية القوية) |
### لماذا تعتبر الازدواجية مهمة؟
| التطبيق | كيف تساعد الازدواجية |
|-------------|------------------|
| الحدود الدنيا | Dual يعطي شهادة عن مدى جودة الحل الأولي |
| أجهزة SVM | تؤدي مشكلة SVM المزدوجة إلى خدعة kernel |
| تحليل الحساسية | تقيس المتغيرات المزدوجة مقدار التغييرات المثلى إذا تم تخفيف القيود |
| التحلل | يمكن تقسيم المشكلات الكبيرة إلى مشكلات فرعية أصغر عبر الثنائي |

## برمجة الأعداد الصحيحة
عندما تكون بعض أو كل المتغيرات **أعدادًا صحيحة**، تصبح المشكلة أكثر صعوبة (NP-hard بشكل عام).
### الأنواع
| اكتب | الوصف |
|------|------------|
| نقية IP | يجب أن تكون جميع المتغيرات أعدادًا صحيحة |
| IP المختلط (MIP) | بعض المتغيرات عدد صحيح، وبعضها مستمر |
| IP الثنائي | المتغيرات مقيدة بـ {0، 1} |
### طرق الحل
| الطريقة | فكرة |
|--------|-----|
| **فرع وملزم** | انقسم إلى مسائل فرعية، وحل استرخاءات LP، وPrune |
| **طائرات القطع** | أضف قيودًا خطية لتشديد استرخاء LP |
| **فرع وقطع** | الجمع بين الفروع والمرتبطة بمستويات القطع |
| **الاستدلال** | الجشع، البحث المحلي، محاكاة التلدين للحلول التقريبية |

## الطرق الإرشادية والميتاهيورستية
عندما يكون التحسين الدقيق مستعصيًا على الحل، فإن الاستدلال يجد حلولًا جيدة (ليست بالضرورة الأمثل).
| الطريقة | الفكرة الرئيسية | الأفضل لـ |
|--------|---------|----------|
| ** نزول متدرج ** | اتبع المنحدر الأكثر حدة | وظائف سلسة وقابلة للتمييز |
| **طريقة نيوتن** | استخدم معلومات من الدرجة الثانية (الانحناء) | مشاكل سلسة ومكيفة |
| ** محاكاة التلدين ** | اقبل الحلول الأسوأ مع احتمالية متناقصة | التحسين العالمي، اندماجي |
| **الخوارزميات الجينية** | تطوير السكان باستخدام الاختيار، والتقاطع، والطفرة | متعددة الأهداف، غير قابلة للتفاضل |
| **سرب الجسيمات** | يستكشف الوكلاء الفضاء، متأثرين بأفضل المواقف المعروفة | مستمرة غير محدبة |
| ** التحسين بايزي ** | بناء نموذج بديل، استخدام وظيفة الاستحواذ | وظائف الصندوق الأسود باهظة الثمن (ضبط المعلمة الفائقة) |
### طريقة نيوتن للتحسين
**قاعدة التحديث:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
حيث H هي مصفوفة هسه (مصفوفة المشتقات الثانية).
| عقار | القيمة |
|----------|-------|
| معدل التقارب | تربيعية (بالقرب من الأمثل) |
| تكلفة التكرار | O(n³) لانعكاس هسه |
| يتطلب | قابلة للتمييز مرتين، إيجابية محددة هسه |
| شبه نيوتن (BFGS) | هسي تقريبي من التدرجات | O(n²) لكل تكرار |

| التحسين بايزي | ضبط المعلمة الفائقة (Optuna، Hyperopt) |
| نيوتن/شبه نيوتن | طرق الدرجة الثانية للمشكلات الصغيرة والمتوسطة (L-BFGS) |

## ملخص
| الطريقة | نوع المشكلة | الضمانات | مقياس |
|--------|-------------|------------|-------|
| البسيط | البرمجة الخطية | الأمثل بالضبط | ملايين المتغيرات |
| نقطة داخلية | محدب (LP، QP، SOCP) | الأمثل بالضبط | نطاق واسع |
| نزول متدرج | السلس غير المقيد | يتقارب مع الدقيقة المحلية | كبير جدًا (التعلم العميق) |
| دولار سنغافوري | مخاطر تجريبية واسعة النطاق | يتقارب (مع الاضمحلال) | مجموعات بيانات ضخمة |
| نيوتن / بفغس | ناعم وقابل للتمييز مرتين | التقارب التربيعي | الصغيرة والمتوسطة |
| كي كي تي / لاغرانج | مقيدة (محدبة) | بالضبط تحت الشروط | متوسطة |
| فرع وملزم | برمجة الأعداد الصحيحة | الأمثل بالضبط | الصغيرة والمتوسطة |
| الاستدلال | أي (غير محدب، اندماجي) | لا يوجد ضمان | يختلف |
يمكن القول إن التحسين هو الأداة الرياضية الأكثر أهمية في التعلم الآلي. يتضمن كل نموذج تقوم بتدريبه - بدءًا من الانحدار الخطي وحتى نماذج اللغة الكبيرة - حل مشكلة التحسين. إن فهم الوقت الذي تكون فيه المشكلة محدبة (الأمثل العالمي المضمون)، ومتى يتقارب النسب المتدرج، وكيفية التعامل مع القيود، يمنحك الأساس النظري لتصميم خوارزميات التعلم وتصحيح أخطائها وتحسينها.
