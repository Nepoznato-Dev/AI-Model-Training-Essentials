# التحليل الحقيقي
التحليل الحقيقي هو الأساس الصارم لحساب التفاضل والتكامل. بينما يعلمك حساب التفاضل والتكامل التمهيدي كيفية حساب المشتقات والتكاملات، فإن التحليل الحقيقي يسأل *لماذا* تعمل هذه التقنيات - ومتى تفشل. فهو يوفر تعريفات دقيقة للحدود والاستمرارية والتقارب والتكامل التي تدعم نظرية الاحتمالات والتحليل الوظيفي والتحسين والضمانات النظرية وراء خوارزميات التعلم الآلي.

## المتتابعات والمتسلسلات
### تسلسلات
**التسلسل** عبارة عن قائمة مرتبة من الأعداد الحقيقية (aₙ)ₙ₌₁^∞. والسؤال المركزي هو: هل المتتالية **تتقارب** إلى حد ما؟
**تعريف التقارب:** يتقارب التسلسل (aₙ) مع L إذا كان لكل ε > 0، هناك N بحيث يكون لكل n > N: |aₙ − L| < ε.
| المفهوم | التعريف | مثال |
|---------|----------|---------|
| **متقاربة** | lim aₙ = L موجود ومحدود | أₙ = 1/ن → 0 |
| **متباعد** | لا تتقارب | أₙ = (−1)ⁿ يتأرجح |
| **متباعد عن ∞** | aₙ ينمو بلا حدود | أₙ = ن² → ∞ |
| ** يحدها ** | \|aₙ\| ≥ M لبعض M | كل تسلسل متقارب يحده |
| **رتيبة** | إما دائمًا غير متناقص أو غير متزايد | أₙ = 1 − 1/n يتزايد |
| **تسلسل كوشي** | ∀ε > 0, ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | في ℝ، كوشي ⟺ متقارب |
** النظريات الرئيسية: **
- **نظرية التقارب الرتيب:** كل متوالية رتيبة محددة تتقارب
- **نظرية بولزانو-فايرستراس:** كل تسلسل محدود له تابع متقارب
- **اكتمال ℝ:** كل متوالية كوشي في ℝ تتقارب (وهذا ما يميز ℝ عن ℚ)
### مسلسل
**السلسلة** هي مجموع التسلسل: Σₙ₌₁^∞ aₙ. تتقارب المتسلسلة إذا تقاربت تسلسل المجاميع الجزئية Sₙ = Σₖ₌₁ⁿ aₖ.
### اختبارات التقارب
| اختبار | الحالة | الخلاصة |
|------|-----------|------------|
| **اختبار التباعد** | ليم أₙ ≠ 0 | سلسلة تتباعد |
| **اختبار المقارنة** | 0 ≥ aₙ ≥ bₙ و Σbₙ يتقاربان | Σaₙ يتقارب |
| **اختبار النسبة** | ليم \|aₙ₊₁/aₙ\| = ل | يتقارب إذا L< 1, diverges if L >1 |
| **اختبار الجذر** | ليم سوب \|aₙ\|^(1/n) = L | يتقارب إذا L< 1, diverges if L >1 |
| **اختبار التكامل** | aₙ = f(n)، f متناقص، موجب | Σaₙ يتقارب إذا تقارب ∫f(x)dx |
| **سلسلة متناوبة** | aₙ متناقص، lim aₙ = 0، علامات متناوبة | المتسلسلة تتقارب |
| **التقارب المطلق** | Σ\|aₙ\| يتقارب | Σaₙ يتقارب (وإعادة الترتيب تعطي نفس المبلغ) |
| **التقارب المشروط** | Σaₙ يتقارب لكن Σ\|aₙ\| يتباعد | إعادة الترتيب يمكن أن تعطي أي مبلغ (ريمان) |
### سلسلة مهمة
| سلسلة | مجموع | الحالة |
|--------|-----|-----------|
| هندسي: Σ rⁿ | 1/(1−ص) | \|ص\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| التوافقي: Σ 1/n | يتباعد (= ∞) | — |
| الأسي: Σ xⁿ/n! | ه| الكل س |
| تايلور لـ ln(1+x): Σ (−1)ⁿ⁺¹xⁿ/n | قانون الجنسية(1+س) | −1 < س ≥ 1 |

## الحدود والاستمرارية
### حدود الوظائف
**تعريف:** lim_{x→c} f(x) = L يعني: لكل ε > 0، يوجد δ > 0 بحيث 0 < |x − c| < δ يعني |f(x) − L| < ε.
هذا هو تعريف **ε-δ** — النسخة الصارمة من "f(x) تقترب من L بينما يقترب x من c."
###الاستمرارية
الدالة f تكون **مستمرة عند c** إذا lim_{x→c} f(x) = f(c). بشكل مكافئ: لكل ε > 0، يوجد δ > 0 بحيث |x − c| < δ يعني |f(x) − f(c)| < ε.
**أنواع الانقطاع:**
| اكتب | الوصف | مثال |
|------|------------|---------|
| قابل للإزالة | الحد موجود ولكن ≠ f(c) | f(x) = sin(x)/x عند x = 0 |
| القفز | الحدود اليسرى واليمنى موجودة ولكنها تختلف | وظيفة الخطوة |
| لانهائي | الحد هو ±∞ | f(x) = 1/x² عند x = 0 |
| تتأرجح | الحد غير موجود | f(x) = sin(1/x) عند x = 0 |
### النظريات الأساسية للدوال المستمرة
| نظرية | بيان |
|---------|---------|
| **نظرية القيمة المتوسطة** | إذا كانت f مستمرة على [a,b] و f(a) < k < f(b)، إذن ∃c ∈ (a,b): f(c) = k |
| **نظرية القيمة القصوى** | إذا كانت f مستمرة على [a,b]، فإن f تصل إلى الحد الأقصى والأدنى على [a,b] |
| **نظرية الحدود** | إذا كانت f متصلة على [a,b]، فإن f محصورة على [a,b] |
| **الاستمرارية الموحدة** | f مستمر بشكل منتظم على [a,b] إذا كان f مستمر على [a,b] (Heine-Cantor) |
**مثال عملي (IVT):** أظهر أن x³ + x − 1 = 0 له حل في (0, 1).
- دع f(x) = x³ + x − 1. f مستمر (متعدد الحدود).
- و(0) = −1< 0 and f(1) = 1 >0.
- بواسطة IVT، ∃c ∈ (0,1): f(c) = 0.

## التمايز
### تعريف
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
إذا كان هذا الحد موجودًا، يكون f **قابلاً للتفاضل** عند c.
### التمايز مقابل الاستمرارية
| العلاقة | بيان |
|--------------|-----------|
| قابل للتفاضل → مستمر | إذا كانت f قابلة للاشتقاق عند c، فإن f متصلة عند c |
| مستمر ↛ قابل للتفاضل | و(خ) = \|س\| مستمر عند 0 ولكن غير قابل للتمييز هناك |
| لا يوجد مكان للتمييز | دالة فايرستراس: مستمرة في كل مكان، وغير قابلة للتفاضل في أي مكان |
### النتائج الرئيسية
| نظرية | بيان |
|---------|---------|
| **نظرية القيمة المتوسطة** | إذا كانت f مستمرة على [a,b] وقابلة للتفاضل على (a,b)، ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **نظرية رول** | حالة خاصة لـ MVT عندما f(a) = f(b): ∃c: f'(c) = 0 |
| **قاعدة لوبيتال** | إذا كانت lim f/g = 0/0 أو ∞/∞، فإن lim f/g = lim f'/g' (عند وجود الأخير) |
| **نظرية تايلور** | و(خ) = Σₖ₌₀ⁿ و⁽ᵏ⁾(أ)/ك! · (x−a)ᵏ + Rₙ(x) مع باقي صريح |

## اندماج
### تكامل ريمان
يُعرّف **تكامل ريمان** ∫ₐᵇ f(x)dx بأنه نهاية مجاميع ريمان.
** البناء: **
1. التقسيم [a,b] إلى فترات فرعية: P = {x₀, x₁, ..., xₙ}
2. اختر نقاط العينة tᵢ ∈ [xᵢ₋₁, xᵢ]
3. مجموع ريمان: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. إذا كان حد S(P,f) موجودًا كشبكة → 0، فإن f يكون Riemann قابلاً للتكامل
**معايير تكامل ريمان:**
| الحالة | قابل للتكامل؟ |
|-----------|------------|
| مستمر على [أ، ب] | نعم |
| يحدها عدد لا نهائي من الانقطاعات | نعم |
| رتابة على [أ، ب] | نعم |
| دالة ديريشليت (1 على ℚ، 0 على الأعداد غير النسبية) | لا |
### النظرية الأساسية في حساب التفاضل والتكامل
| الجزء | بيان |
|------|-----------|
| **الجزء الأول** | إذا كانت f مستمرة على [a,b]، فإن F(x) = ∫ₐˣ f(t)dt قابلة للاشتقاق وF'(x) = f(x) |
| **الجزء الثاني** | إذا كانت F' = f و f قابلة لتكامل ريمان، فإن ∫ₐᵇ f(x)dx = F(b) − F(a) |
### التكامل ليبيسج
تكامل ريمان له حدود - فهو لا يستطيع دمج العديد من الوظائف التي تنشأ في التحليل والاحتمالات. يعمل **تكامل Lebesgue** على توسيع نطاق التكامل ليشمل فئة أوسع بكثير من الوظائف.
**الفكرة الأساسية:** بدلاً من تقسيم المجال (المحور السيني)، قم بتقسيم النطاق (المحور الصادي).
| الجانب | تكامل ريمان | تكامل ليبيسج |
|--------|-----------------|-------------------|
| النهج | مجال التقسيم (المحور السيني) | نطاق التقسيم (المحور الصادي) |
| يدمج | مستمر، قطعي مستمر | وظائف قابلة للقياس |
| نظريات الحد | ضعيف | قوية (التقارب المسيطر، التقارب الرتيب) |
| مقابض | وظائف "لطيفة" | وظائف ذات انقطاعات كثيفة |
| مؤسسة | حساب التفاضل والتكامل الكلاسيكي | نظرية الاحتمالات الحديثة |
**معيار ليبيغ:** f هو تكامل ريمان على [a,b] إذا كان f محدودًا ومستمرًا في كل مكان تقريبًا (مجموعة الانقطاعات لها قياس صفر).

## المسافات المترية
تعمل **المساحة المترية** على تعميم مفهوم "المسافة" على المجموعات المجردة.
### تعريف
**المساحة المترية** (X, d) هي مجموعة X مع دالة مسافة d: X × X → ℝ مُرضية:
| اكسيوم | بيان |
|-------|-----------|
| عدم السلبية | د(س،ص) ≥ 0 |
| الهوية | د(س،ص) = 0 إذا س = ص |
| التماثل | د(س،ص) = د(ص،س) |
| عدم المساواة المثلثية | د(x,z) ≥ د(x,y) + d(y,z) |
### المسافات المترية المشتركة
| الفضاء | تعيين | متري | التطبيق |
|-------|-----|-------|-------------|
| ℝⁿ بالإقليدية | ℝⁿ | د(x,y) = √Σ(xᵢ−yᵢ)² | الهندسة القياسية |
| ℝⁿ مع مانهاتن | ℝⁿ | د(x,y) = Σ\|xᵢ−yᵢ\| | المسارات المبنية على الشبكة، LASSO |
| ℝⁿ مع تشيبيشيف | ℝⁿ | d(x,y) = الحد الأقصى\|xᵢ−yᵢ\| | مسافة ملك الشطرنج |
| متري منفصل | أي مجموعة | d(x,y) = 1 إذا x≠y, 0 إذا x=y | أمثلة الطوبولوجيا |
| مساحة الوظيفة C[a,b] | الدوال المستمرة | d(f,g) = max\|f(x)−g(x)\| | نظرية التقريب |
| مساحة Lᵖ | وظائف ع متكاملة | د(f,g) = (∫\|f−g\|ᵖ)^(1/p) | التحليل الوظيفي، معايير تعلم الآلة |
### المفاهيم الطوبولوجية في الفضاءات المترية
| المفهوم | التعريف | مثال |
|---------|----------|---------|
| **الكرة المفتوحة** | ب(x,r) = {y : d(x,y) < r} | الفترة المفتوحة (x−r, x+r) في ℝ |
| **مجموعة مفتوحة** | تحتوي كل نقطة على كرة موجودة في المجموعة | (0،1) مفتوح في ℝ |
| **مجموعة مغلقة** | تكملة لمجموعة مفتوحة | [0,1] مغلق في ℝ |
| **الإغلاق** | أصغر مجموعة مغلقة تحتوي على S | إغلاق (0,1) = [0,1] |
| **مضغوط** | كل غطاء مفتوح له غطاء فرعي محدود | في ℝⁿ: مغلق ومحدود (هاينه-بوريل) |
| **كاملة** | كل متوالية كوشي تتقارب | ℝ كامل؛ ℚ ليس |

## التقارب الموحد
يمكن لتسلسل الوظائف (fₙ) أن يتقارب بطريقتين:
| اكتب | التعريف | يحافظ على الاستمرارية؟ |
|------|----------------------------|-----|
| **نقطة** | ∀x: fₙ(x) → f(x) | لا |
| **الزي الرسمي** | سوب\|fₙ(x) − f(x)\| → 0 | نعم |
**التقارب الموحد** أقوى: معدل التقارب هو نفسه في كل مكان.
** النظريات الرئيسية: **
- الحد الموحد للوظائف المستمرة مستمر
- الحد الموحد لدوال ريمان القابلة للتكامل هو حد موحد لدوال ريمان القابلة للتكامل، وتكامل النهاية يساوي نهاية التكاملات
- **اختبار Weierstrass M:** إذا |fₙ(x)| ≥ Mₙ لجميع x و ΣMₙ يتقاربان، ثم Σfₙ يتقاربان بشكل موحد

## نظرية القياس
**نظرية القياس** تعمم مفاهيم الطول والمساحة والحجم.
### تعريف
**القياس** في المجموعة X هو دالة μ: Σ → [0, ∞] (حيث Σ عبارة عن جبر σ لمجموعات فرعية) مرضية:
- μ(∅) = 0
- **الجمع المعدود:** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) للمنفصلة Aᵢ
### قياس ليبيسج
يوسع **قياس Lebesgue** π على ℝ فكرة الطول:
| تعيين | قياس ليبيسج |
|-----|-----------------|
| الفاصل الزمني [أ، ب] | ب - أ |
| نقطة واحدة {س} | 0 |
| مجموعة محدودة | 0 |
| مجموعة قابلة للعد (على سبيل المثال، ℚ) | 0 |
| مجموعة كانتور | 0 (غير معدودة لكن قياسها صفر) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### المفاهيم الأساسية
| المفهوم | التعريف |
|---------|-----------|
| **في كل مكان تقريبًا (الإمارات العربية المتحدة)** | لا تصمد الخاصية إلا على مجموعة قياسها صفر |
| **وظيفة قابلة للقياس** | الصورة الأولية لكل مجموعة مفتوحة قابلة للقياس |
| ** ليبسيغ متكامل ** | التكامل المحدد باستخدام نظرية القياس |
| **مساحات Lᵖ** | فضاءات الدوال ذات تكامل القدرة p-th المحدود |
### نظريات التقارب الهامة
هذه النظريات هي سبب تفضيل تكامل Lebesgue في الرياضيات المتقدمة:
| نظرية | بيان |
|---------|---------|
| **التقارب الرتيب** | إذا كان fₙ ↑ f اتجاهيًا وfₙ ≥ 0، ثم ∫fₙ → ∫f |
| **التقارب المسيطر** | إذا كان fₙ → f بشكل نقطي و\|fₙ\| ≥ g (قابل للتكامل)، ثم ∫fₙ → ∫f |
| ** فاتو ليما ** | ∫lim inf fₙ ≥ lim inf ∫fₙ |
تسمح هذه النظريات بتبادل النهايات والتكاملات، وهو أمر يفشل في تكامل ريمان بشكل عام.

التحليل الحقيقي هو المكان الذي تنمو فيه الرياضيات. فهو يستبدل المفاهيم البديهية مثل "الاقتراب" و"المستمر" و"المنطقة" بتعريفات دقيقة يمكن إثباتها وتعميمها. بالنسبة لعلماء البيانات ومهندسي تعلم الآلة، يوفر التحليل الضمانات النظرية: متى يتقارب أصل التدرج؟ متى تكون وظيفة الخسارة حسنة التصرف؟ متى يمكننا تبادل الحدود والتوقعات؟ هذه ليست أسئلة فلسفية، فهي تحدد ما إذا كانت الخوارزمية الخاصة بك تعمل أم تفشل بصمت.
