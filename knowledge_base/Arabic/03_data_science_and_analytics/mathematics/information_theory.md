#نظرية المعلومات
نظرية المعلومات، التي أسسها كلود شانون في عام 1948، تقوم بقياس المعلومات نفسها. كم تخبرك الرسالة؟ إلى أي مدى يمكنك ضغط البيانات؟ ما مدى سرعة التواصل عبر قناة صاخبة؟ هذه الأسئلة لها إجابات رياضية دقيقة. وبعيدًا عن التواصل، أصبحت نظرية المعلومات أساسية للتعلم الآلي - فالإنتروبيا المتقاطعة هي دالة الخسارة الافتراضية للتصنيف، ويقيس تباعد KL تشابه التوزيع، وتدفع المعلومات المتبادلة اختيار الميزات.

## إنتروبيا
**الإنتروبيا** يقيس متوسط ​​عدم اليقين أو "المفاجأة" للمتغير العشوائي.
### إنتروبيا شانون (منفصلة)
بالنسبة للمتغير العشوائي المنفصل X مع دالة الكتلة الاحتمالية p(x):
H(X) = −Σₓ ص(خ) سجل₂ ص(س)
الوحدات: **البتات** (عند استخدام log₂) أو **nats** (عند استخدام ln).
| التوزيع | الانتروبيا | الحدس |
|-------------|---------|-----------|
| عملة عادلة (ع = 0.5، 0.5) | 1 بت | الحد الأقصى من عدم اليقين للنتيجة الثنائية |
| عملة متحيزة (ع = 0.9، 0.1) | 0.469 بت | أقل إثارة للدهشة – في الغالب رؤوس |
| حتمية (ع = 1, 0) | 0 بت | لا يوجد شك على الإطلاق |
| قالب عادل (6 جوانب) | 2.585 بت | المزيد من النتائج = المزيد من عدم اليقين |
| موحدة على نتائج ن | log₂(n) بت | الحد الأقصى للإنتروبيا لنتائج n |
### خصائص الانتروبيا
| عقار | بيان |
|----------|----------|
| عدم السلبية | ح(س) ≥ 0 |
| الحد الأقصى | H(X) ≥ log₂(\|X\|) مع المساواة في التوزيع الموحد |
| قاعدة السلسلة | ح(س، ص) = ح(س) + ح(ص \| س) |
| التكييف يقلل | ح(س \| ص) ≥ ح(س) |
| تقعر | H هي دالة مقعرة للتوزيع الاحتمالي |
### الانتروبيا التفاضلية (مستمر)
لمتغير عشوائي مستمر X مع الكثافة p(x):
h(X) = −∫ p(x) سجل p(x) dx
على عكس الإنتروبيا المنفصلة، ​​يمكن أن تكون الإنتروبيا التفاضلية **سلبية**.
| التوزيع | الانتروبيا التفاضلية |
|-------------|--------------------|
| زي موحد على [أ، ب] | سجل (ب - أ) |
| عادي N(μ, σ²) | (1/2) سجل(2πeσ²) |
| الأسي(π) | 1 − ln() |

## المعلومات المشتركة والمشروطة والمتبادلة
### الإنتروبيا المشتركة
H(X, Y) = −Σₓ Σᵧ ص(x, y) سجل ص(x, y)
يقيس عدم اليقين الكلي للزوج (X، Y).
### الإنتروبيا المشروطة
H(Y | X) = −Σₓ Σᵧ p(x, y) سجل p(y | x) = H(X, Y) − H(X)
يقيس عدم اليقين المتبقي بشأن Y بعد ملاحظة X.
### معلومات متبادلة
I(X; Y) = Σₓ Σᵧ p(x, y) سجل [p(x, y) / (p(x)p(y))]
يقيس مقدار ما تخبرك به معرفة X عن Y (والعكس صحيح).
| عقار | بيان |
|----------|----------|
| عدم السلبية | أنا(X; Y) ≥ 0 |
| التماثل | أنا(X; Y) = أنا(Y; X) |
| العلاقة بالانتروبيا | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| العلاقة بالمفاصل | أنا(X; Y) = H(X) + H(Y) − H(X, Y) |
| الاستقلال | I(X; Y) = 0 إذا كان X وY مستقلين |
| معلومات ذاتية | أنا(X; X) = ح(X) |
### مرئي: مخطط الإنتروبيا
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## تباعد كوالالمبور
يقيس ** تباعد Kullback-Leibler (KL) ** مدى اختلاف توزيع واحد عن الآخر.
D_KL(P || Q) = Σₓ P(x) سجل [P(x) / Q(x)]
| عقار | بيان |
|----------|----------|
| عدم السلبية | D_KL(P \|\| Q) ≥ 0 (متباينة جيبس) |
| الهوية | D_KL(P \|\| Q) = 0 إذا P = Q |
| عدم التماثل | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) بشكل عام |
| ليس مقياسا | فشل التناظر وعدم المساواة المثلث |
**التفسير:** D_KL(P || Q) هو العدد الإضافي من البتات اللازمة لتشفير البيانات من P باستخدام رمز محسّن لـ Q.
### العلاقة مع الكميات الأخرى
| العلاقة | صيغة |
|------------|---------|
| عبر الانتروبيا | ح(P, Q) = H(P) + D_KL(P \|\| Q) |
| معلومات متبادلة | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| كل الشرطية | D_KL(P(Y\|X) \|\| Q(Y\|X)) المتوسط ​​على X |

## الانتروبيا المتقاطعة
**الإنتروبيا المتقاطعة** بين التوزيعتين P وQ:
H(P, Q) = −Σₓ P(x) سجل Q(x) = H(P) + D_KL(P || Q)
### الانتروبيا المتقاطعة كدالة خسارة
في التصنيف، P هو التوزيع الحقيقي (تسمية مشفرة واحدة ساخنة) وQ هو التوزيع المتوقع للنموذج.
** الإنتروبيا الثنائية (BCE):**
L = −[سجل ص(ŷ) + (1−ص) سجل(1−ŷ)]
** الانتروبيا القاطعة: **
L = −Σᵢ yᵢ سجل(ŷᵢ)
| السيناريو | ذ (صحيح) | ŷ (متنبأ) | خسارة |
|----------|---------|---------------|------|
| صحيح واثق | 1 | 0.95 | 0.051 |
| صحيح غير مؤكد | 1 | 0.55 | 0.598 |
| خطأ واثق | 1 | 0.05 | 2.996 |
| خطأ وغير مؤكد | 1 | 0.45 | 0.799 |
إن تقليل الإنتروبيا المتقاطعة يعادل تقليل انحراف KL عن التوزيع الحقيقي - وهذا هو السبب في أنه يعمل بشكل جيد كدالة خسارة.

## سعة القناة
### نموذج قناة الاتصال
```
X → [Channel] → Y
```

- X: إدخال متغير عشوائي
- Y: إخراج متغير عشوائي
- القناة: محددة بالاحتمالات الشرطية p(y|x)
### نظرية شانون لتشفير القنوات الصاخبة
بالنسبة للقناة ذات السعة C، إذا كان معدل الإرسال R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C، فإن الاتصال الموثوق به مستحيل.
**سعة القناة:**
C = max_{p(x)} I(X; Y)
### أمثلة مهمة على القنوات
| قناة | الوصف | القدرة |
|---------|------------|----------|
| **ثنائي متماثل (BSC)** | يقلب كل بت مع احتمال ص | 1 - بتات H(p) |
| **محو ثنائي (BEC)** | يمحو كل بت مع احتمال ε | 1 − ε بت |
| ** غاوسي (AWGN) ** | Y = X + Z، Z ~ N(0, σ²) | (1/2) سجل (1 + SNR) بت |
| **ثنائي بلا ضوضاء** | انتقال مثالي | 1 بت |

## ترميز المصدر والضغط
### نظرية ترميز المصدر
متوسط عدد البتات اللازمة لتشفير المصدر يحده أدناه الإنتروبيا الخاصة به:
ل ≥ ح(X)
يحقق الكود الأمثل L ≈ H(X).
### ترميز هوفمان
رمز **خالي من البادئات** يعين رموزًا أقصر لرموز أكثر احتمالاً.
| الرمز | الاحتمال | كود هوفمان | الطول |
|--------|-------------|-------------|--------|
| أ | 0.5 | 0 | 1 |
| ب | 0.25 | 10 | 2 |
| ج | 0.125 | 110 | 3 |
| د | 0.125 | 111 | 3 |
متوسط الطول: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 بت/رمز
الإنتروبيا: H = 1.75 بت/رمز (الأمثل في هذه الحالة!)
### الضغط غير المنقوص مقابل الضغط المنقوص
| اكتب | المبدأ | أمثلة | الحد |
|------|-----------|---------|-------|
| ** بلا خسائر ** | إزالة التكرار الإحصائي | الرمز البريدي، PNG، FLAC | معدل الإنتروبيا H(X) |
| **الخسارة** | قم بإزالة المعلومات غير ذات الصلة بالإدراك الحسي | جبيغ، MP3، H.264 | دالة معدل التشويه R(D) |
**نظرية معدل التشويه:** بالنسبة للضغط مع الفقد مع أقصى قدر من التشوه D، فإن المعدل الأدنى هو R(D) = min I(X; X̂) الخاضع لـ E[d(X, X̂)] ≥ D.

## ملخص
| الكمية | صيغة (منفصلة) | معنى |
|----------|-------------------|---------|
| الانتروبيا H(X) | −Σ ص(x) سجل ص(x) | متوسط ​​عدم اليقين |
| الإنتروبيا المشتركة H(X,Y) | −Σ p(x,y) سجل p(x,y) | مجموع عدم اليقين من الزوج |
| الإنتروبيا المشروطة H(Y\|X) | ح(س،ص) – ح(س) | عدم اليقين المتبقي بشأن Y بالنظر إلى X |
| المعلومات المتبادلة I(X;Y) | ح(X) − ح(X\|Y) | المعلومات المشتركة بين X وY |
| تباعد KL D_KL(P\|\|Q) | Σ P(x) سجل(P(x)/Q(x)) | "المسافة" بين التوزيعات |
| عبر الانتروبيا H(P,Q) | −Σ P(x) سجل Q(x) | تكلفة الترميز باستخدام توزيع خاطئ |
| سعة القناة C | ماكس أنا(X;Y) | الحد الأقصى لمعدل الاتصال الموثوق به |
توفر نظرية المعلومات الحدود الأساسية لما يمكن تعلمه وضغطه وتوصيله. بالنسبة لممارسي التعلم الآلي، فهو يفسر سبب عمل الإنتروبيا المتقاطعة كدالة خسارة، وكيفية قياس جودة التمثيلات المستفادة، وكيفية التفكير في المفاضلة بين تعقيد النموذج وملاءمة البيانات. تظل رؤى شانون منذ عام 1948 ذات صلة بالذكاء الاصطناعي الحديث بقدر ارتباطها بالاتصالات.
