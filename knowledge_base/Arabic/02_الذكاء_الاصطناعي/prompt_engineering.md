# هندسة المطالبات

## المبادئ الأساسية
### الوضوح والدقة
- قل ما تريد بوضوح.
- تجنب الغموض.

### تقديم السياق
- أعطِ الخلفية اللازمة.
- حدّد الجمهور والهدف.

### استخدام التعليمات الإيجابية
- أخبر النموذج بما تريده.
- استخدم قيودًا واضحة.

## هياكل المطالبات
### أدوار النظام / المستخدم / المساعد
- النظام يحدد السلوك العام.
- المستخدم يحدد المهمة.

### Few-Shot Prompting
- قدّم أمثلة قليلة جيدة.

### Chain-of-Thought
- اطلب التفكير المنظم عند الحاجة.

### المخرجات المنظمة
- جداول
- JSON
- قوائم

## تقنيات متقدمة
### الاتساق الذاتي
- جرّب أكثر من مسار ثم اختر الأفضل.

### شجرة الأفكار
- استكشاف عدة مسارات حل.

### ReAct
- التفكير ثم الفعل.

### تعيين الشخصية
- اختر نبرة أو شخصية مناسبة للمهمة.

## ضبط المعلمات
- درجة الإبداع
- الطول
- التكرار

## المشكلات الشائعة وإصلاحها
- إجابات عامة جدًا
- تعليمات متعارضة
- نقص السياق
- طلبات طويلة جدًا

## قوالب لمهام شائعة
- التلخيص
- توليد الكود
- الشرح
- العصف الذهني
