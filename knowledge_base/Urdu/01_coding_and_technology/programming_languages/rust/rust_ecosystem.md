# زنگ - ایکو سسٹم اور ٹولنگ گائیڈ
یہ گائیڈ Rust ایکو سسٹم میں ضروری ٹولز، فریم ورک اور انفراسٹرکچر کا احاطہ کرتا ہے۔
---

## پیکیج مینجمنٹ اور تعمیر
| ٹول | مقصد |
|------|---------|
| **کارگو** | پیکیج مینیجر، بلڈ سسٹم، ٹیسٹ رنر |
| **crates.io** | سرکاری پیکج رجسٹری |
| **رسٹ اپ** | ٹول چین انسٹالر اور مینیجر |
| **کارگو ترمیم** | انحصار شامل کریں/ہٹائیں/اپ گریڈ کریں |
| **کارگو گھڑی** | فائل کی تبدیلیوں پر دوبارہ تعمیر کریں |
| **کارگو آڈٹ** | سیکورٹی کے خطرے کی جانچ کرنے والا |
| **کارگو کلپی** | لنٹر (بلٹ ان) |
| **کارگو-fmt** | کوڈ فارمیٹر (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

## ٹیسٹنگ
| ٹول | مقصد |
|------|---------|
| **کارگو ٹیسٹ** | بلٹ ان یونٹ + انٹیگریشن ٹیسٹ |
| **کسوٹی** | بینچ مارکنگ فریم ورک |
| **احتجاج** | جائیداد کی بنیاد پر جانچ |
| **مذاق** | طنزیہ فریم ورک |
| **ٹوکیو::ٹیسٹ** | Async ٹیسٹ سپورٹ |
| **انسٹا** | سنیپ شاٹ ٹیسٹنگ |
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## خلاصہ
زنگ کا ماحولیاتی نظام ہم آہنگ اور اعلیٰ معیار کا ہے، جس کا مرکز کارگو کے ارد گرد ہے۔ معیاری اسٹیک یہ ہے: **کارگو** ہر چیز کے لیے (تعمیر، جانچ، شائع)، **Tokio** async کے لیے، **Axum** یا **Actix-web** ویب کے لیے، **serde** سیریلائزیشن کے لیے، **SQLx** ڈیٹا بیس کے لیے، اور **clap** CLIs کے لیے۔ زنگ کی قاتل خصوصیت رن ٹائم انحصار کے بغیر ایک واحد جامد بائنری کے طور پر تعینات کر رہی ہے۔ ماحولیاتی نظام سہولت پر درستگی اور کارکردگی کو ترجیح دیتا ہے۔
