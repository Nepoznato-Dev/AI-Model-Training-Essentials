# C — ایکو سسٹم اور ٹولنگ گائیڈ
یہ گائیڈ C ماحولیاتی نظام میں ضروری ٹولز، لائبریریوں اور انفراسٹرکچر کا احاطہ کرتا ہے۔
---

## مرتب کرنے والے
| مرتب کرنے والا | پلیٹ فارم | نوٹس |
|------------|---------|-------|
| **GCC** | لینکس/یونکس | GNU کمپائلر کلیکشن، سب سے زیادہ استعمال ہونے والا |
| **کلنگ** | کراس پلیٹ فارم | LLVM پر مبنی، بہتر خرابی کے پیغامات |
| **MSVC** | ونڈوز | مائیکروسافٹ بصری C++ مرتب کرنے والا |
| **TCC** | کراس پلیٹ فارم | ٹنی سی کمپائلر، تیز تالیف |
| **زگ سی سی** | کراس پلیٹ فارم | Zig's C مرتب کرنے والا، زبردست کراس تالیف |
---

## سسٹمز بنائیں
| ٹول | قسم | کے لیے بہترین |
|------|------|---------|
| **بناؤ** | کلاسیکی | سادہ پروجیکٹس، یونکس معیاری |
| **CMake** | کراس پلیٹ فارم | صنعت معیاری، پیچیدہ منصوبے |
| **میسن** | جدید | تیز، صاف نحو |
| **ننجا** | تیز | کم سطحی تعمیراتی نظام (CMake کے ذریعے استعمال کیا جاتا ہے) |
| **بیزل** | پیمانہ | Monorepos، Google |
| **xmake** | جدید | Lua پر مبنی، کراس پلیٹ فارم |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## خلاصہ
سی کا ماحولیاتی نظام جدید کمپیوٹنگ کی بنیاد ہے۔ معیاری ٹول چین یہ ہے: تالیف کے لیے **GCC** یا **Clang**، تعمیرات کے لیے **CMake**، ڈیبگنگ کے لیے **GDB**، میموری تجزیہ کے لیے **والگرینڈ**، اور لنٹنگ کے لیے **کلنگ صاف**۔ کلیدی لائبریریوں میں کرپٹو کے لیے **OpenSSL**، HTTP کے لیے **libcurl**، ڈیٹا بیس کے لیے **SQLite** شامل ہیں۔ C کا ماحولیاتی نظام ڈیزائن کے لحاظ سے کم سے کم ہے — آپ اپنی ضرورت کی تعمیر کرتے ہیں۔ جدید ترقی کے لیے، جانچ کے دوران ہمیشہ سینیٹائزر (ASan، UBSan) استعمال کریں۔
