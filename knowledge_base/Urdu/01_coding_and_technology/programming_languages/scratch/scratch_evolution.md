# سکریچ - ورژن کی تاریخ اور ارتقاء
## ٹائم لائن
| ورژن | سال | کلیدی تھیم |
|---------|------|------------|
| پری سکریچ | 2003 | MIT میڈیا لیب میں سکریچ ٹیم کی تشکیل |
| سکریچ 1.0 | 2007 | **ابتدائی ریلیز** — بچوں کے لیے بصری پروگرامنگ |

## اہم سنگ میل
### اصل (2003–2006)
- **2003**: MIT میڈیا لیب کے لائف لانگ کنڈرگارٹن گروپ نے سکریچ کی ترقی شروع کی
- مچل ریسنک کی قیادت میں
- **مقصد**: بصری بلاکس کے ذریعے بچوں کو پروگرامنگ سکھائیں۔
- سے متاثر: لوگو (سیمور پیپرٹ)، لیگو لوگو، سکوک ایٹوز
- نام: "سکریچ" — DJ سکریچنگ سے (میڈیا کو آپس میں ملانا)
### سکریچ 1.0 (2007)
- **2007**: پہلی عوامی ریلیز
- ڈریگ اینڈ ڈراپ بلاک پروگرامنگ
- سپرائٹ پر مبنی منصوبے (کردار، متحرک تصاویر)
- آواز، گرافکس، حرکت پذیری۔
- بلٹ ان سکوک (Smalltalk)
- **ٹارگٹ**: عمریں 8-16، لیکن اس سے کہیں زیادہ وسیع کو اپنایا گیا۔
### سکریچ 1.4 (2009)
- بہتر گرافکس رینڈرنگ
- مزید سپرائٹ لائبریریاں
- بہتر آواز کی حمایت
- آخری ورژن Squeak پر بنایا گیا۔
### سکریچ 2.0 (2013)
- **مکمل ویب پر مبنی ایڈیٹر** — براؤزر میں چلتا ہے۔
- کلاؤڈ متغیرات - پروجیکٹس کے درمیان ڈیٹا کا اشتراک کریں۔
- بیگ - پروجیکٹس کے درمیان اسپرائٹس/اسکرپٹس کا اشتراک کریں۔
- اپنی مرضی کے بلاکس (جیسے افعال)
- بلٹ ان ایکشن اسکرپٹ 3 (فلیش)
- کمیونٹی کی خصوصیات: ریمکس، شیئر، تبصرہ
### سکریچ 3.0 (2019)
- **مکمل دوبارہ لکھنا** — HTML5/JavaScript (کوئی فلیش نہیں)
- ٹیبلٹس، فونز، کروم بکس پر کام کرتا ہے۔
- **توسیعات**:
  - قلم (ڈرائنگ)
  - ویڈیو سینسنگ (کیمرہ)
  - ٹیکسٹ ٹو اسپیچ
  - ترجمہ (گوگل ترجمہ)
  - مائیکرو: بٹ (ہارڈ ویئر)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- ساؤنڈ ایڈیٹر میں بہتری
- نیا پینٹ ایڈیٹر (ویکٹر + بٹ میپ)
- بیگ، کلاؤڈ متغیرات برقرار ہیں۔
### سکریچ ڈیسک ٹاپ اور اس سے آگے (2020–موجودہ)
- **2020**: سکریچ ڈیسک ٹاپ — آف لائن ایڈیٹر (الیکٹران پر مبنی)
- مسلسل توسیع کی ترقی
- AI/ML ایکسٹینشنز (کمیونٹی کی تخلیق کردہ)
- جسمانی کمپیوٹنگ کے ساتھ انضمام (مائیکرو: بٹ، آرڈوینو)
## بلاک زمرہ جات ارتقاء
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## پروگرامنگ کے تصورات سکھائے جاتے ہیں۔
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## ڈیزائن کے کلیدی اصول
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
