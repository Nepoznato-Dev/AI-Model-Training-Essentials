## اہم سنگ میل
### PHP/FI اور PHP 3 (1995–1999)
- **1995**: راسمس لیرڈورف نے "پرسنل ہوم پیج ٹولز" جاری کیا۔
- **1998**: پی ایچ پی 3 - سوراسکی اور گٹمینز کی طرف سے مکمل دوبارہ لکھنا؛ سکرپٹ کی زبان بن جاتی ہے۔
- کلیدی خصوصیات: HTML میں سرایت، فارم ہینڈلنگ، ڈیٹا بیس سپورٹ
### پی ایچ پی 4 — زینڈ انجن (2000–2004)
- **زینڈ انجن 1**: مرتب شدہ بائی کوڈ، بہت تیز
- سیشن ہینڈلنگ، آؤٹ پٹ بفرنگ، PEAR
- پہلا حقیقی ویب ڈویلپمنٹ فریم ورک دور
### پی ایچ پی 5 — آبجیکٹ اورینٹڈ پی ایچ پی (2004–2014)
- **5.0**: مکمل OOP دوبارہ لکھنا — کلاسز، انٹرفیس، استثناء، PDO
- **5.3**: نام کی جگہیں (جدید پی ایچ پی کے لیے اہم)، بندش، دیر سے جامد پابندیاں
- **5.4**: خصائص، مختصر صف نحو `[]`، بلٹ ان ویب سرور
- **5.5**: جنریٹرز (`yield`), `finally`
### پی ایچ پی 7 - کارکردگی کا انقلاب (2015-2019)
- **7.0**: Zend Engine 3 — **2x تیز**، اسکیلر قسم کے اعلانات، واپسی کی قسم کے اعلانات
- **7.1**: کالعدم قسمیں (`?int`)، باطل واپسی کی قسم
- **7.4**: ٹائپ شدہ خصوصیات، تیر کے فنکشنز`fn() =>`, null coalescing اسائنمنٹ `??=`
### پی ایچ پی 8 — جدید پی ایچ پی (2020–موجودہ)
- **8.0**: جے آئی ٹی کمپائلر، نامزد دلائل، مماثلت کا اظہار، یونین کی قسمیں، صفات (`#[...]`)، nullsafe آپریٹر`?->`
- **8.1**: Enums، fibers (ہلکے وزن کی ہم آہنگی)، صرف پڑھنے کی خصوصیات، چوراہے کی اقسام
- **8.2**: صرف پڑھنے کی کلاسیں، DNF کی اقسام،`null`/`false`/`true`اسٹینڈ اکیلی اقسام کے طور پر
- **8.3**: ٹائپ شدہ کلاس مستقل، `#[\Override]`،`json_validate()`
- **8.4**: پراپرٹی ہکس، `#[\Deprecated]`، غیر متناسب مرئیت
## ٹائپ سسٹم ارتقاء
```
PHP 4:    No type hints
PHP 5.0:  Class type hints
PHP 5.1:  Array type hint
PHP 7.0:  Scalar types (int, string, float, bool), return types
PHP 7.1:  Nullable types (?int), void, iterable
PHP 7.2:  object type
PHP 7.4:  Typed properties
PHP 8.0:  Union types (int|string), mixed
PHP 8.1:  Intersection types (A&B), never, first-class callable syntax
PHP 8.2:  DNF types ((A&B)|C), null/false/true standalone
PHP 8.3:  Typed class constants
PHP 8.4:  Property hooks (get/set)
```

## نحوی ارتقاء
```php
// PHP 3/4: Basic scripting
$users = array(1, 2, 3);

// PHP 5.4: Short array syntax
$users = [1, 2, 3];

// PHP 5.3: Namespaces
namespace App\Models;

// PHP 7.0: Scalar types
function add(int $a, int $b): int { return $a + $b; }

// PHP 7.4: Arrow functions
$doubled = array_map(fn($x) => $x * 2, $numbers);

// PHP 8.0: Named arguments, match
$result = process(value: $input, strict: true);
$label = match($status) { 0 => 'inactive', 1 => 'active', default => 'unknown' };

// PHP 8.1: Enums
enum Status: string { case Active = 'active'; case Inactive = 'inactive'; }

// PHP 8.4: Property hooks
class User {
    public string $name { get => strtoupper($this->name); set; }
}
```

## ڈیزائن کے کلیدی اصول
```
1. "Pragmatic" — solve real web problems
2. "Progressive enhancement" — easy to start, deep to master
3. "Backward compatibility" — old code keeps working
4. "Batteries included" — extensive standard library
5. "Community-driven" — RFC process for language changes
6. "Performance matters" — PHP 7/8 focus on speed
```
