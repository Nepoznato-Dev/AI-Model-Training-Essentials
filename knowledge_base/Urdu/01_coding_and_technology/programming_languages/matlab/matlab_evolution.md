## اہم سنگ میل
### اصل (1970-1984)
- **1970s**: کلیو مولر یونیورسٹی آف نیو میکسیکو میں فورٹران میٹرکس کے معمولات لکھتے ہیں۔
- **مقصد**: طلباء کو فورٹران لکھے بغیر LINPACK/EISPACK تک رسائی دیں۔
- **1984**: MathWorks کی بنیاد Moler & Jack Little; MATLAB 1.0 تجارتی طور پر جاری کیا گیا۔
### میٹلیب 4–5: میٹرکس ایرا (1992–1999)
- **4.0 (1992)**: Simulink — بلاک ڈایاگرام سمولیشن
- **5.0 (1996)**: سیل کی صفیں، ساخت کی صفیں، آبجیکٹ پر مبنی خصوصیات
- **5.3 (1999)**: علامتی ریاضی کا ٹول باکس (میپل پر مبنی)
### میٹلیب 6–7: جدید ماحول (2000–2011)
- **6.0 (2000)**: ڈیسک ٹاپ ماحول (کمانڈ ونڈو، ورک اسپیس، ایڈیٹر)
- **7.0 (2004): نیا ڈیسک ٹاپ، کوڈ تجزیہ کار (`mlint`)، بہتر گرافکس
- **7.6 (2008)**: مکمل OOP — کلاسز، وراثت، پیکجز، واقعات
### MATLAB 8+: ڈیٹا سائنس کا دور (2012–موجودہ)
- **8.0 (2012): لائیو ایڈیٹر - انٹرایکٹو نوٹ بک
- **8.5 (2015): ایپ ڈیزائنر — جدید GUI بلڈر
- **9.0 (2015)**:`string`قسم (مختص ٹیکسٹ ہینڈلنگ)
- **9.4 (2018)**:`dictionary`قسم
- **9.14 (2023): **AI اسسٹنٹ** — قدرتی زبان کے سوالات
- **2024**: MATLAB موبائل، کلاؤڈ انٹیگریشن، مسلسل AI خصوصیات
## نحوی ارتقاء
```matlab
% Early MATLAB: Basic matrix operations
A = [1 2 3; 4 5 6; 7 8 9];
b = [1; 2; 3];
x = A \ b;  % solve Ax = b

% MATLAB 5.0: Cell arrays, structs
C = {1, 'hello', [1 2 3]};
S.name = 'Alice';
S.age = 30;

% MATLAB 7.6: OOP
classdef MyClass < handle
    properties
        Value = 0;
    end
    methods
        function obj = MyClass(v)
            obj.Value = v;
        end
        function display(obj)
            fprintf('Value: %d\n', obj.Value);
        end
    end
end

% MATLAB 8.0: Live Editor (interactive)
% In Live Editor: mix code, output, text, images

% MATLAB 9.0: string type
s = "Hello, World";
names = ["Alice"; "Bob"; "Charlie"];

% MATLAB 9.4: dictionary
d = dictionary(["a","b","c"], [1, 2, 3]);
val = d("b");  % 2

% MATLAB 9.10: arguments validation
function result = myFunc(x, options)
    arguments
        x (1,:) double {mustBePositive}
        options.Method (1,1) string = "fast"
    end
    % ...
end

% MATLAB 2023+: AI Assistant
% Ask: "How do I fit a polynomial to my data?"
% MATLAB generates: polyfit(x, y, degree)
```

## ڈیزائن کے کلیدی اصول
```
1. "Matrix first" — everything is an array (historically)
2. "Interactive" — try things in Command Window
3. "Visualize everything" — powerful plotting
4. "Toolbox model" — domain-specific extensions
5. "Backward compatible" — old .m files keep working
6. "Engineer-friendly" — math notation, not CS notation
```
