# JavaScript — ایکو سسٹم اور ٹولنگ گائیڈ
یہ گائیڈ JavaScript ایکو سسٹم میں ضروری ٹولز، فریم ورک اور انفراسٹرکچر کا احاطہ کرتا ہے۔
---

## رن ٹائمز
| رن ٹائم | ماحولیات | کے لیے بہترین |
|---------|---------------|---------|
| **Node.js** | سرور/CLI | بیک اینڈ، APIs، ٹولنگ |
| **ڈینو** | سرور/CLI | بطور ڈیفالٹ محفوظ، ٹائپ اسکرپٹ مقامی |
| **بن** | سرور/CLI | تیز، بلٹ ان بنڈلر/ٹیسٹ رنر |
| **براؤزر** | کلائنٹ کی طرف | ویب ایپلیکیشنز |
---

## پیکیج مینجمنٹ
| ٹول | رجسٹری | خصوصیات |
|------|------------|---------|
| **npm** | npmjs.com | Node.js کے ساتھ طے شدہ |
| **سوت** | npmjs.com | ورک اسپیسز، PnP موڈ |
| **pnpm** | npmjs.com | تیز، ڈسک موثر، سخت |
| **روٹی** | npmjs.com | انتہائی تیز، بلٹ ان |
```bash
npm init -y                   # initialize project
npm install express           # add dependency
npm install -D typescript     # add dev dependency
npm run build                 # run script from package.json
```

## ٹیسٹنگ
| فریم ورک | قسم |
|------------|------|
| **ویسٹ** | تیز، وائٹ-آبائی |
| **مذاق** | بالغ، سنیپ شاٹ ٹیسٹنگ |
| ** ڈرامہ نگار** | E2E، ملٹی براؤزر |
| **صنوبر** | E2E، ڈویلپر کا تجربہ |
| **ٹیسٹنگ لائبریری** | اجزاء کی جانچ |
| **موچا** | لچکدار، پلگ ان پر مبنی |
```bash
vitest                        # run tests
vitest --coverage             # with coverage
playwright test               # E2E tests
```

## کوڈ کا معیار
| ٹول | مقصد |
|------|---------|
| **ESLint** | لنٹر (قابل ترتیب قواعد) |
| **خوبصورت** | کوڈ فارمیٹر |
| **بائیوم** | فاسٹ لنٹر + فارمیٹر (زنگ) |
| **TypeScript** | جامد قسم کی جانچ پڑتال |
| **ts-پیٹرن** | TS کے لیے پیٹرن میچنگ |
```json
// eslint.config.js (flat config)
export default [
  { rules: { "no-unused-vars": "warn" } }
];
```

## خلاصہ
جاوا اسکرپٹ کا ماحولیاتی نظام پروگرامنگ میں سب سے بڑا ہے۔ جدید اسٹیک یہ ہے: عمارت کے لیے **Vite**، **pnpm** پیکجز کے لیے، **Vitest** ٹیسٹنگ کے لیے، **ESLint + Prettier** کوڈ کے معیار کے لیے، **React/Next.js** یا **Vue/Nuxt** فرنٹ اینڈ کے لیے، اور **Vercel** یا **Cloudflare** تعیناتی کے لیے۔ TypeScript اب کسی بھی سنجیدہ پروجیکٹ کے لیے ضروری ہے۔ ماحولیاتی نظام تیزی سے آگے بڑھتا ہے - موجودہ رہیں لیکن فریم ورک کے منتھن سے گریز کریں۔
