## اہم سنگ میل
### کلاسیکی دور (1996–2004)
- **1.0 (1996)**: "ایک بار لکھیں، کہیں بھی چلائیں" - ایپلٹس، AWT
- **1.2 (1998)**: کلیکشن فریم ورک (جاوا کلیکشن کی بنیاد)
- **1.4 (2002)**: NIO، لاگنگ، ریجیکس، دعوے
- **5.0 (2004)**: سب سے بڑی تازہ کاری — جنرک، اینومس، تشریحات، آٹو باکسنگ، بہتر شدہ فار لوپ، ورارگس، `static import`
### انٹرپرائز کا دور (2006–2014)
- **6 (2006)**: سکرپٹ سپورٹ، کمپائلر API
- **7 (2011)**: `try-with-resources`، ڈائمنڈ آپریٹر،`switch`on String, NIO.2
- **8 (2014)**: دوسرا "بگ بینگ" — لیمبڈاس، اسٹریمز، `Optional`، `java.time`، پہلے سے طے شدہ طریقے، `CompletableFuture`
### جدید دور (2017–موجودہ)
- **9 (2017): ماڈیول سسٹم (JPMS)، `var`،`jshell`REPL
- **11 (2018): 6 ماہ کی ریلیز کیڈینس کے تحت پہلا LTS؛ `HttpClient`; اوریکل JDK لائسنسنگ میں تبدیلی
- **17 (2021): LTS — سیل شدہ کلاسز، پیٹرن میچنگ
- **21 (2023)**: LTS — **ورچوئل تھریڈز** (پروجیکٹ لوم)، پیٹرن میچنگ، ریکارڈ پیٹرن
## 6 ماہ کی ریلیز کیڈنس
```
Before Java 9:  Major releases every 2-4 years
Java 9+:        New release every 6 months (March & September)
LTS releases:   Every ~2 years (8, 11, 17, 21, 25...)
Non-LTS:        Feature previews, 6-month support
```

## عام سفر
```
2004: Java 5.0 — type erasure generics (backward compatible)
2014: Java 8 — improved inference with lambdas
2016: Java 9 — diamond operator with anonymous classes
2018: Java 11 — `var` with generics
2023: Java 21 — record patterns with generics
```

## فنکشنل پروگرامنگ ارتقاء
```
2004: Anonymous inner classes (verbose)
2004: Java 5 — enums as pseudo-functional
2014: Java 8 — lambdas, streams, Optional
2017: Java 9 — Stream API additions
2019: Java 12 — switch expressions
2023: Java 21 — pattern matching in switch, record patterns
```

Java 9:   var (local), modules, jshell
Java 14:  record (preview), switch expressions
