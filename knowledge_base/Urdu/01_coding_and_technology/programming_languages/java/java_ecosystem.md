# جاوا - ایکو سسٹم اور ٹولنگ گائیڈ
یہ گائیڈ جاوا ایکو سسٹم میں ضروری ٹولز، فریم ورک، اور انفراسٹرکچر کا احاطہ کرتا ہے۔
---

## ٹولز بنائیں
| ٹول | قسم | کے لیے بہترین |
|------|------|---------|
| **ماون** | XML پر مبنی | انٹرپرائز، کنونشن اوور کنفگ |
| **گریڈل** | گرووی/کوٹلن ڈی ایس ایل | لچکدار، اینڈرائیڈ، بڑے پروجیکٹس |
| **چیونٹی** | XML پر مبنی | میراثی منصوبے |
| **بیزل** | کثیر زبان | Monorepos, Google-scale |
```bash
# Maven
mvn clean install               # build
mvn test                        # run tests
mvn package                     # create JAR/WAR

# Gradle
./gradlew build                 # build
./gradlew test                  # run tests
./gradlew bootRun               # run Spring Boot app
```

## ٹیسٹنگ
| فریم ورک | مقصد |
|------------|---------|
| **جونائٹ 5** | معیاری ٹیسٹ فریم ورک |
| **موکیٹو** | طنز |
| **AssertJ** | روانی کے دعوے |
| **ٹیسٹ کنٹینرز** | ڈوکر پر مبنی انضمام ٹیسٹ |
| **وائر موک** | HTTP API کا مذاق اڑانا |
| **آرچ یونٹ** | فن تعمیر کے ٹیسٹ |
| **باقی یقینی** | REST API ٹیسٹنگ |
| **JMH** | مائیکرو بینچ مارکنگ |
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;
    @InjectMocks UserService service;

    @Test
    void shouldFindUserById() {
        when(repo.findById(1L)).thenReturn(Optional.of(new User("Alice")));
        var user = service.findById(1L);
        assertThat(user.name()).isEqualTo("Alice");
    }
}
```

## خلاصہ
جاوا کا ماحولیاتی نظام انٹرپرائز کمپیوٹنگ میں سب سے زیادہ پختہ ہے۔ معیاری اسٹیک یہ ہے: تعمیرات کے لیے **Gradle** یا **Maven**، ویب/مائیکرو سروسز کے لیے **Spring Boot**، **JUnit 5 + Mockito** ٹیسٹنگ کے لیے، **Hibernate** ORM کے لیے، **IntelliJ IDEA** بطور IDE، اور **Docker** تعیناتی کے لیے۔ جاوا کی طاقت اس کا وسیع پیمانے پر ماحولیاتی نظام، انٹرپرائز سپورٹ، اور پیچھے کی طرف مطابقت ہے۔ ریکارڈز، سیل شدہ کلاسز، پیٹرن میچنگ، اور ورچوئل تھریڈز کے ساتھ جدید جاوا (17+) زبان کو زندہ کر رہا ہے۔
