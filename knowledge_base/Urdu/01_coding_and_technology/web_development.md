# ویب ڈویلپمنٹ
## فرنٹ اینڈ ڈویلپمنٹ
### بنیادی ٹیکنالوجیز
#### HTML (ہائپر ٹیکسٹ مارک اپ لینگویج)
- **Semantic HTML**: معنی خیز ٹیگز استعمال کرنا (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<aside>`, XQZMARKER6)
- **فارم**: ان پٹ کی قسمیں، توثیق، قابل رسائی لیبل
- **میڈیا**: امیجز، ویڈیو، آڈیو ایمبیڈنگ
- **میٹا ٹیگز**: SEO، ویو پورٹ، کریکٹر انکوڈنگ
- **HTML5 خصوصیات**: کینوس، SVG، مقامی اسٹوریج، جغرافیائی محل وقوع، ویب ساکٹ
#### CSS (کیسکیڈنگ اسٹائل شیٹس)
- **باکس ماڈل**: مواد، پیڈنگ، بارڈر، مارجن
- **لے آؤٹ سسٹم**:
  - **فلیکس باکس**: ایک جہتی ترتیب، جواز پیش کرنے والے مواد، سیدھ میں آنے والی اشیاء
  - **گرڈ**: دو جہتی لے آؤٹ، گرڈ ٹیمپلیٹ، گرڈ ایریا
  - **پوزیشننگ**: جامد، رشتہ دار، مطلق، مقررہ، چپچپا
- **رسپانسیو ڈیزائن**: میڈیا کے سوالات، موبائل کا پہلا نقطہ نظر
- **CSS متغیرات**: تھیمنگ کے لیے حسب ضرورت خصوصیات
- **اینیمیشن**: ٹرانزیشنز، کی فریمز، ٹرانسفارمز
- **پری پروسیسرز**: ساس، کم (متغیر، مکسنس، نیسٹنگ)
#### جاوا اسکرپٹ
- **DOM ہیرا پھیری**: عناصر کا انتخاب، تخلیق، ترمیم کرنا
- **ایونٹس**: کلک کریں، جمع کرائیں، کی بورڈ، حسب ضرورت ایونٹس، ایونٹ ڈیلیگیشن
- **ES6+ خصوصیات**: تیر کے فنکشنز، ڈیسٹرکچرنگ، اسپریڈ/ریسٹ، ماڈیولز، async/await
- **APIs**: بازیافت کریں، XMLHttpRequest، لوکل اسٹوریج، سیشن اسٹوریج
- **TypeScript**: جامد ٹائپنگ، انٹرفیس، جنرک، ڈیکوریٹر
### جدید فرنٹ اینڈ فریم ورک
#### ردعمل دیں۔
- **اجزاء**: فنکشنل اجزاء، کلاس کے اجزاء
- **ہکس**: یوز اسٹیٹ، یوز ایفیکٹ، استعمال سیاق و سباق، استعمال ریڈوسر، کسٹم ہکس
- **State Management**: Context API، Redux، Zustand، Recoil
- **روٹنگ**: ری ایکٹ راؤٹر (براؤزر روٹر، روٹس، روٹ، لنک)
- **ایکو سسٹم**: Next.js (SSR, SSG), Remix, Gatsby
- **ورچوئل ڈوم**: مختلف الگورتھم کے ذریعے موثر رینڈرنگ
#### Vue.js
- **اختیارات API**: ڈیٹا، طریقے، کمپیوٹڈ، واچ
- **کمپوزیشن API**: سیٹ اپ()، ریف، ری ایکٹیو، کمپیوٹیڈ
- **ہدایات**: v-if, v-for, v-bind, v-on, v-model
- **Vuex/Pinia**: ریاستی انتظام
- **ویو راؤٹر**: کلائنٹ سائیڈ روٹنگ
- **Nuxt.js**: سرور سائیڈ رینڈرنگ فریم ورک
#### کونیی
- **اجزاء**: ڈیکوریٹر، ٹیمپلیٹس، لائف سائیکل ہکس
- **سروسز**: انحصار انجیکشن، سنگلٹن پیٹرن
- **RxJS**: ری ایکٹیو پروگرامنگ، مشاہدات
- **روٹنگ**: راؤٹر ماڈیول، گارڈز، حل کرنے والے
- **فارم**: ٹیمپلیٹ پر مبنی، رد عمل والی شکلیں۔
- **NgRx**: Redux طرز کا ریاستی انتظام
### ٹولز اور بنڈلرز بنائیں
- **ویب پیک**: ماڈیول بنڈلنگ، کوڈ اسپلٹنگ، لوڈرز، پلگ ان
- **وائٹ**: مقامی ES ماڈیولز کا استعمال کرتے ہوئے فاسٹ بلٹ ٹول
- **پارسل**: زیرو کنفیگریشن بنڈلر
- **رول اپ**: لائبریریوں کے لیے آپٹمائزڈ
- **esbuild**: انتہائی تیز جاوا اسکرپٹ بنڈلر
- **بیبل**: پسماندہ مطابقت کے لیے جاوا اسکرپٹ ٹرانسپلر
- **پوسٹ سی ایس ایس**: پلگ ان کے ساتھ سی ایس ایس پروسیسنگ
### CSS فریم ورک اور لائبریریاں
- **بوٹسٹریپ**: اجزاء کی لائبریری، گرڈ سسٹم، یوٹیلیٹیز
- **ٹیل ونڈ سی ایس ایس**: یوٹیلیٹی فرسٹ سی ایس ایس فریم ورک
- **مٹیریل UI**: گوگل کا میٹریل ڈیزائن کا نفاذ
- **چاکرا UI**: قابل رسائی جزو لائبریری
- **چیونٹی ڈیزائن**: انٹرپرائز کی سطح کے UI اجزاء
- **اسٹائل شدہ اجزاء**: CSS-in-JS لائبریری
- **جذبات**: CSS-in-JS ماخذ کے نقشوں کے ساتھ
## بیک اینڈ ڈویلپمنٹ
### سرور سائیڈ لینگویجز
#### Node.js
- **رن ٹائم**: سرور پر جاوا اسکرپٹ (V8 انجن)
- **Express.js**: کم سے کم ویب فریم ورک، مڈل ویئر فن تعمیر
- **NestJS**: کونیی سے متاثر فن تعمیر، ٹائپ اسکرپٹ
- **Fastify**: اعلی کارکردگی کا فریم ورک
- **Koa**: اسی تخلیق کاروں کے ذریعہ جدید ایکسپریس
- **پیکیج مینجمنٹ**: این پی ایم، یارن، پی این پی ایم
#### ازگر
- **جنگو**: مکمل خصوصیات والا فریم ورک، ORM، ایڈمن پینل، بیٹریاں شامل
- **فلاسک**: مائیکرو فریم ورک، ایکسٹینشن ایکو سسٹم
- **FastAPI**: جدید، async، خودکار API دستاویزات
- **اہرام**: لچکدار، توسیع پذیر فریم ورک
#### دیگر بیک اینڈ لینگویجز
- **روبی آن ریلز**: کنونشن اوور کنفیگریشن، ActiveRecord ORM
- **جاوا اسپرنگ**: انٹرپرائز فریم ورک، انحصار انجیکشن
- **PHP Laravel**: خوبصورت نحو، فصیح ORM، بلیڈ ٹیمپلیٹنگ
- **گو جن**: اعلی کارکردگی، کم سے کم فریم ورک
- **رسٹ ایکٹکس**: میموری کی حفاظت، کارکردگی
- **C# ASP.NET کور**: کراس پلیٹ فارم، انٹرپرائز کی خصوصیات
### ڈیٹا بیس انٹیگریشن
#### ORMs (آبجیکٹ-ریلیشنل میپنگ)
- **Sequelize**: SQL ڈیٹا بیس کے لیے Node.js ORM
- **پریزما**: ٹائپ سیف ڈیٹا بیس تک رسائی، خود کار طریقے سے تیار کردہ کلائنٹ
- **SQLAlchemy**: Python SQL ٹول کٹ اور ORM
- **ActiveRecord**: Ruby on Rails ORM
- **ہائبرنیٹ**: Java ORM
- **اینٹیٹی فریم ورک**: .NET ORM
#### ڈیٹا بیس ڈرائیورز
- **pg**: Node.js کے لیے PostgreSQL کلائنٹ
- **mysql2**: وعدوں کے ساتھ MySQL کلائنٹ
- **pymongo**: Python کے لیے MongoDB ڈرائیور
- **redis**: متعدد زبانوں کے لیے Redis کلائنٹ
### API ڈویلپمنٹ
#### REST APIs
- **HTTP طریقے**: حاصل کریں، پوسٹ کریں، ڈالیں، پیچ کریں، حذف کریں
- **سٹیٹس کوڈ**: 200، 201، 400، 401، 403، 404، 500
- **وسائل کا نام**: اسم، جمع، درجہ بندی
- **ورژننگ**: URL پاتھ، ہیڈرز، استفسار کے پیرامیٹرز
- **توثیق**: JWT، OAuth، API کیز
- **دستاویزات**: OpenAPI/Swagger، پوسٹ مین
#### گراف کیو ایل
- **اسکیما کی تعریف**: اقسام، سوالات، تغیرات، سبسکرپشنز
- **حل کرنے والے**: فیلڈ لیول ڈیٹا لانا
- **اپولو سرور**: گراف کیو ایل سرور کا نفاذ
- **ریلے**: فیس بک کا گراف کیو ایل کلائنٹ
- **فائدے**: کوئی اوور فیچنگ نہیں، سنگل اینڈ پوائنٹ، مضبوط ٹائپنگ
#### جی آر پی سی
- **پروٹوکول بفرز**: انٹرفیس کی تعریف کی زبان
- **HTTP/2**: دو طرفہ سلسلہ بندی
- **کیسز استعمال کریں**: مائیکرو سروسز کمیونیکیشن، ریئل ٹائم ایپلی کیشنز
### توثیق اور اجازت
- **سیشن پر مبنی**: کوکیز، سرور سائیڈ سیشنز
- **ٹوکن پر مبنی**: JWT (JSON ویب ٹوکنز)، بے وطن
- **OAuth 2.0**: اجازت دینے کا فریم ورک، فریق ثالث لاگ ان
- **OpenID Connect**: OAuth 2.0 پر شناختی پرت
- **SAML**: انٹرپرائز سنگل سائن آن
- **پاس ورڈ ہیشنگ**: bcrypt، argon2، scrypt
- **ملٹی فیکٹر توثیق**: TOTP، SMS، ای میل کوڈز

### ورژن کنٹرول
- **گٹ**: تقسیم شدہ ورژن کنٹرول
- **GitHub/GitLab/Bitbucket**: ریپوزٹری ہوسٹنگ
- **برانچنگ کی حکمت عملی**: گٹ فلو، گٹ ہب فلو، ٹرنک پر مبنی ترقی

### کنٹینرائزیشن

- **کنٹینر رجسٹریاں**: ڈوکر ہب، اے ڈبلیو ایس ای سی آر، گوگل جی سی آر
- **بہترین پریکٹسز**: ملٹی اسٹیج بلڈز، کم سے کم بیس امیجز

- **سروس میش**: مائیکرو سروسز نیٹ ورکنگ کے لیے اسٹیو، لنکرڈ
### کلاؤڈ پلیٹ فارمز
- **AWS**: EC2, S3, Lambda, RDS, CloudFront, ECS/EKS
- **گوگل کلاؤڈ**: کمپیوٹ انجن، کلاؤڈ اسٹوریج، کلاؤڈ فنکشنز، جی کے ای

- **ورسل**: فرنٹ اینڈ تعیناتی، سرور کے بغیر افعال
- **Netlify**: جامد سائٹ ہوسٹنگ، سرور کے بغیر افعال
- **ہیروکو**: پلیٹ فارم بطور سروس (PaaS)
- **DigitalOcean**: آسان کلاؤڈ انفراسٹرکچر
### CI/CD پائپ لائنز
- **گٹ ہب ایکشنز**: ورک فلو آٹومیشن
- **GitLab CI**: بلٹ ان لگاتار انضمام
- **جینکنز**: قابل توسیع آٹومیشن سرور
- **CircleCI**: کلاؤڈ بیسڈ CI/CD

- **لاگنگ**: ELK اسٹیک (Elasticsearch، Logstash، Kibana)، Splunk
- **اپ ٹائم مانیٹرنگ**: پنگڈم، اپ ٹائم روبوٹ
- **تجزیات**: گوگل تجزیات، مکسپینل، طول و عرض
## ویب کی کارکردگی
### اصلاح کی تکنیک
- **کوڈ اسپلٹنگ**: سست لوڈنگ، متحرک درآمدات
- **درخت ہلانا**: غیر استعمال شدہ کوڈ کو ہٹانا
- **منیفیکیشن**: فائل کے سائز کو کم کرنا
- **کمپریشن**: Gzip، Brotli
- **کیچنگ**: براؤزر کیش، CDN، سروس ورکرز
- **امیج آپٹیمائزیشن**: ویب پی، اے وی آئی ایف، سست لوڈنگ، ریسپانسیو امیجز
- **تنقیدی CSS**: اوپر کی تہہ والی شیلیوں کو ان لائن کرنا
- **ڈیٹا بیس آپٹیمائزیشن**: انڈیکسنگ، استفسار کی اصلاح، کنکشن پولنگ
### کور ویب وائٹلز
- **LCP (سب سے بڑا مواد والا پینٹ)**: لوڈنگ کارکردگی (<2.5s)
- **FID (پہلے ان پٹ میں تاخیر)**: انٹرایکٹیویٹی (<100ms)
- **CLS (مجموعی لے آؤٹ شفٹ)**: بصری استحکام (<0.1)
- **INP (اگلے پینٹ سے تعامل)**: ردعمل کا میٹرک
### مواد کی ترسیل کے نیٹ ورکس (CDNs)
- **Cloudflare**: سیکورٹی، کارکردگی، DNS
- **اکامائی**: انٹرپرائز CDN
- **Amazon CloudFront**: AWS CDN
- **تیزی سے**: ایج کلاؤڈ پلیٹ فارم
- **اسٹیک پاتھ**: ایج سروسز
## ویب سیکیورٹی
### عام کمزوریاں (OWASP ٹاپ 10)
- **انجیکشن**: ایس کیو ایل انجیکشن، کمانڈ انجیکشن
- **ٹوٹی ہوئی توثیق**: سیشن ہائی جیکنگ، اسناد بھرنا
- **حساس ڈیٹا کی نمائش**: غیر خفیہ کردہ ڈیٹا، کمزور خفیہ نگاری
- **XML External Entities (XXE): XML پارسر کی کمزوریاں
- **بروکن ایکسیس کنٹرول**: استحقاق میں اضافہ، غیر مجاز رسائی
- **سیکیورٹی غلط کنفیگریشن**: ڈیفالٹ اسناد، لفظی غلطیاں
- **کراس سائٹ اسکرپٹنگ (XSS): منعکس، ذخیرہ شدہ، DOM پر مبنی
- **غیر محفوظ ڈیسیریلائزیشن**: آبجیکٹ انجیکشن حملے
- **معروف کمزوریوں کے ساتھ اجزاء کا استعمال**: فرسودہ انحصار
- **ناکافی لاگنگ اور مانیٹرنگ**: ناقابل شناخت خلاف ورزیاں
### سیکیورٹی کے بہترین طریقے
- **HTTPS**: TLS/SSL انکرپشن، HSTS
- **مواد کی حفاظت کی پالیسی (CSP): XSS حملوں کو روکیں۔
- **ان پٹ کی توثیق**: صارف کے ان پٹ کو صاف کریں۔
- **آؤٹ پٹ انکوڈنگ**: انجیکشن حملوں کو روکیں۔
- **CSRF تحفظ**: اینٹی CSRF ٹوکنز، SameSite کوکیز
- **ریٹ کی حد بندی**: وحشیانہ طاقت کے حملوں کو روکیں۔
- **سیکیورٹی ہیڈرز**: ایکس فریم کے اختیارات، ایکس مواد کی قسم کے اختیارات
- **انحصار اسکیننگ**: npm آڈٹ، Snyk، Dependabot

### WCAG رہنما خطوط
- **قابل ادراک**: متن کے متبادل، کیپشن، قابل موافق مواد
- **آپریبل**: کی بورڈ نیویگیشن، کافی وقت، کوئی دورے نہیں۔
- **قابل فہم**: پڑھنے کے قابل، قابل قیاس، ان پٹ مدد
- **مضبوط**: معاون ٹیکنالوجیز کے ساتھ ہم آہنگ
### نفاذ
- **Semantic HTML**: مناسب سرخی کا درجہ بندی، نشانیاں
- **ARIA خصوصیات**: کردار، ریاستیں، خواص
- **فوکس مینجمنٹ**: مرئی فوکس اشارے، منطقی ٹیب آرڈر
- **رنگ کنٹراسٹ**: متن کے لیے کم از کم 4.5:1 کا تناسب
- **اسکرین ریڈر ٹیسٹنگ**: NVDA، JAWS، وائس اوور
- **کی بورڈ نیویگیشن**: تمام انٹرایکٹو عناصر قابل رسائی
## پروگریسو ویب ایپس (PWAs)
### PWA کی خصوصیات
- **سروس ورکرز**: آف لائن فعالیت، پس منظر کی مطابقت پذیری۔
- **ویب ایپ مینی فیسٹ**: پرامپٹ، شبیہیں، تھیم کے رنگ انسٹال کریں۔
- **ایپ شیل**: کیشڈ UI کنکال
- **پش اطلاعات**: صارف کی مصروفیت
- ** ذمہ دار ڈیزائن**: تمام آلات پر کام کرتا ہے۔
- **HTTPS درکار ہے**: محفوظ سیاق و سباق
### ٹولز
- **ورک باکس**: سروس ورکر لائبریریاں
- **لائٹ ہاؤس**: PWA آڈیٹنگ
- **PWA بلڈر**: مینی فیسٹ اور شبیہیں بنائیں
## ابھرتی ہوئی ٹیکنالوجیز
### WebAssembly (Wasm)
- **مقصد**: براؤزر میں مرتب شدہ کوڈ کو مقامی رفتار سے چلائیں۔
- **زبانیں**: C++, Rust, Go تالیف کے اہداف
- **کیسز استعمال کریں**: گیمز، ویڈیو ایڈیٹنگ، کرپٹوگرافی، ایم ایل انفرنس
### سرور لیس فن تعمیر
- **سروس کے طور پر کام کرتا ہے**: AWS Lambda، Azure Functions، Google Cloud Functions
- **فوائد**: کوئی سرور مینجمنٹ، آٹو اسکیلنگ، ادائیگی فی استعمال نہیں۔
- **غور و فکر**: کولڈ اسٹارٹس، وینڈر لاک ان، ڈیبگنگ پیچیدگی
### جیم اسٹیک آرکیٹیکچر
- **جاوا اسکرپٹ**: کلائنٹ سائیڈ انٹرایکٹیویٹی
- **APIs**: سرور کے بغیر فنکشنز، تھرڈ پارٹی سروسز
- **مارک اپ**: پہلے سے بنی ہوئی جامد فائلیں۔
- **ٹولز**: Next.js, Gatsby, Hugo, Eleventy
- **فوائد**: کارکردگی، سیکورٹی، اسکیل ایبلٹی، ڈویلپر کا تجربہ
### ریئل ٹائم مواصلات
- **ویب ساکٹس**: دو طرفہ مواصلات
- **سرور سے بھیجے گئے ایونٹس**: سرور سے کلائنٹ اسٹریمنگ
- **WebRTC**: پیئر ٹو پیئر ویڈیو، آڈیو، ڈیٹا
- **کیسز استعمال کریں**: چیٹ، تعاون، لائیو سلسلہ بندی، گیمنگ
### مائیکرو فرنٹنڈز
- **تصور**: مائیکرو سروسز کو فرنٹ اینڈ تک بڑھائیں۔
- **نقطہ نظر**: تعمیر کا وقت، رن ٹائم، کنارے کی طرف انضمام
- **فوائد**: آزاد تعیناتی، ٹیم کی خودمختاری
- **چیلنجز**: مستقل مزاجی، کارکردگی، پیچیدگی
