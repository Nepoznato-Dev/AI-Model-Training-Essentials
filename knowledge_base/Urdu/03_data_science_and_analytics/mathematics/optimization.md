# اصلاح
اصلاح ایک قابل عمل حل کے سیٹ سے بہترین حل تلاش کرنے کی ریاضی ہے۔ یہ پوچھتا ہے: ایک فنکشن اور رکاوٹوں کو دیکھتے ہوئے، کون سا ان پٹ آؤٹ پٹ کو کم کرتا ہے (یا زیادہ سے زیادہ)؟ آپٹیمائزیشن مشین لرننگ کا انجن ہے — ایک ماڈل کو تربیت دینے کا مطلب ہے نقصان کو کم سے کم کرنا۔ یہ آپریشن ریسرچ، اکنامکس، انجینئرنگ ڈیزائن، اور عملی طور پر ہر مقداری فیلڈ میں ظاہر ہوتا ہے۔
---

## مسئلہ کی تشکیل
ایک عمومی **اصلاحی مسئلہ** کی شکل یہ ہے:
کم سے کم f(x)
سے مشروط: gᵢ(x) ≤ 0 (مساوات کی پابندیاں)، hⱼ(x) = 0 (مساوات کی پابندیاں)
| مدت | معنی |
|------|---------|
| **مقصد فنکشن** f(x) | کم سے کم (یا زیادہ سے زیادہ) کی مقدار |
| **فیصلے کے متغیرات** x | وہ اقدار جنہیں ہم کنٹرول کر سکتے ہیں |
| **ممکن علاقہ** | تمام رکاوٹوں کو پورا کرنے والے تمام x کا مجموعہ |
| **عالمی کم از کم** | F(x*) ≤ f(x) کے ساتھ تمام قابل عمل x |
| **مقامی کم از کم** | کسی محلے میں تمام ممکنہ ایکس کے لیے f(x*) ≤ f(x) کے ساتھ قابل عمل x* |
| ** محدب مسئلہ** | f محدب ہے، قابل عمل خطہ محدب سیٹ ہے (مقامی منٹ = عالمی منٹ) |

## لکیری پروگرامنگ (LP)
جب مقصد اور تمام رکاوٹیں ** لکیری** ہوں تو مسئلہ ایک لکیری پروگرام ہے۔
### معیاری فارم
cᵀx کو کم سے کم کریں۔
موضوع: Ax ≤ b, x ≥ 0
جہاں c، x ∈ ℝⁿ، A ∈ ℝᵐˣⁿ، b ∈ ℝᵐ۔
### پراپرٹیز
| پراپرٹی | بیان |
|------------|------------|
| محدب | LP ہمیشہ ایک محدب مسئلہ ہے |
| بہترین حل | ہمیشہ قابل عمل پولی ٹاپ کے ایک چوٹی (کونے کے نقطہ) پر |
| وجود | اگر قابل عمل خطہ پابند اور غیر خالی ہے تو بہترین حل موجود ہے |
| ایک سے زیادہ آپٹیما | اگر دو عمودی زیادہ سے زیادہ ہیں، تو ان کے درمیان کنارے پر ہر نقطہ بھی بہترین ہے |
### سادہ طریقہ
**سادہ طریقہ** (Dantzig, 1947) قابل عمل پولی ٹاپ کے کناروں کے ساتھ عمودی سے عمودی تک منتقل ہوتا ہے، ہمیشہ مقصد کو بہتر کرتا ہے، جب تک کہ زیادہ سے زیادہ حد تک نہ پہنچ جائے۔
| پراپرٹی | قدر |
|------------|-------|
| بدترین وقت | O(2ⁿ) (قطعی - عملی طور پر نایاب) |
| اوسط کیس کا وقت | زیادہ تر عملی مسائل کے لیے کثیر الجہتی |
| کلیدی خیال | بہتر معروضی قدر کے ساتھ ملحقہ چوٹی پر جائیں |
**الگورتھم (جائزہ):**
1. ایک بنیادی ممکنہ حل سے شروع کریں (پولی ٹاپ کی چوٹی)
2. داخل ہونے والے متغیر کا انتخاب کریں (جو مقصد کو بہتر بناتا ہے)
3. چھوڑنے والے متغیر کا انتخاب کریں (فزیبلٹی کو برقرار رکھیں)
4. محور: نئے سرے پر جائیں۔
5. اس وقت تک دہرائیں جب تک کہ کوئی بہتر سمت موجود نہ ہو۔
### داخلہ پوائنٹ کے طریقے
سمپلیکس کا متبادل: قابل عمل خطے کے اندر سے زیادہ سے زیادہ تک رسائی حاصل کریں۔
| پراپرٹی | قدر |
|------------|-------|
| بدترین وقت | کثیر الثانی (O(n³·⁵) کچھ متغیرات کے لیے) |
| عملی کارکردگی | بڑے مسائل پر سمپلیکس کے ساتھ مسابقتی |
| کلیدی خیال | داخلہ کے ذریعے ایک "مرکزی راستہ" پر عمل کریں |
### کام کرنے والی ایل پی کی مثال
**مسئلہ:** ایک فیکٹری کرسیاں (x₁) اور میزیں (x₂) تیار کرتی ہے۔
- منافع: $30 فی کرسی، $50 فی میز
- لکڑی: 2x₁ + 4x₂ ≤ 100 (بورڈ فٹ دستیاب)
- مزدوری: x₁ + 3x₂ ≤ 60 (گھنٹے دستیاب)
- زیادہ سے زیادہ: 30x₁ + 50x₂
**حل (2 متغیرات کے لیے گرافیکل طریقہ):**
- قابل عمل خطے کے عمودی: (0,0), (30,0), (40,10), (0,20)
- ہر چوٹی پر مقصد کا اندازہ کریں:
  - (0,0): منافع = 0
  - (30,0): منافع = 900
  - (40,10): منافع = 1700 ← بہترین
  - (0,20): منافع = 1000
- **بہترین:** x₁ = 40 کرسیاں، x₂ = 10 میزیں، منافع = $1700

## محدب اصلاح
ایک مسئلہ **محدب** ہے اگر مقصدی فعل محدب ہے اور قابل عمل خطہ محدب مجموعہ ہے۔
### محدب سیٹ اور افعال
| تصور | تعریف |
|---------|------------|
| ** محدب سیٹ** | کسی بھی x کے لیے سیٹ میں y اور t ∈ [0,1]: tx + (1−t)y بھی سیٹ میں ہے |
| ** محدب فنکشن** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) تمام t کے لیے ∈ [0,1] |
| **سختی سے محدب** | عدم مساوات t ∈ (0,1) اور x ≠ y | کے لیے سخت ہے۔
**کلیدی خاصیت:** محدب اصلاح کے لیے، ہر مقامی کم از کم عالمی کم از کم ہے۔
### عام محدب افعال
| فنکشن | محدب۔ | کہاں |
|------------|---------|-------|
| ax + b (لکیری) | ہاں (اور مقعر) | ہر جگہ |
| x² | جی ہاں | ℝ |
| eˣ | جی ہاں | ℝ |
| −log(x) | جی ہاں | x > 0 |
| \|x\|ᵖ (p ≥ 1) | جی ہاں | ℝⁿ |
| max(f₁, f₂) اگر f₁, f₂ محدب | جی ہاں | ڈومینز کا چوراہا |
### تدریجی نزول
مشین لرننگ میں سب سے بنیادی اصلاحی الگورتھم۔
**اپ ڈیٹ کا اصول:** x_{k+1} = x_k − α∇f(x_k)
جہاں α > 0 ہے **سیکھنے کی شرح** (قدم کا سائز)۔
| متغیر | اپ ڈیٹ رول | فائدہ |
|---------|------------|------------|
| **بیچ GD** | x ← x − α∇f(x) | مستحکم کنورجنسی |
| **سٹوکاسٹک GD (SGD)** | x ← x − α∇fᵢ(x) (ایک نمونہ) | تیزی سے فی تکرار، مقامی منیما سے فرار |
| **منی بیچ SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | بیچ اور اسٹاکسٹک کے درمیان توازن |
| **مومینٹم** | v ← βv − α∇f(x); x ← x + v | فلیٹ علاقوں کے ذریعے تیز ہوتا ہے |
| **آدم** | انکولی سیکھنے کی شرح فی پیرامیٹر | گہرائی سے سیکھنے کے لیے اچھی طرح سے کام کرتا ہے |
| **RMSprop** | تدریجی وسعت کی اوسط چلا کر سیکھنے کی شرح کو پیمانہ کریں | RNNs کے لیے اچھا ہے |
### کنورجنسی ریٹس
| طریقہ | محدب f | مضبوطی سے محدب f |
|---------|------------|-------------------|
| تدریجی نزول | O(1/k) | O((1−μ/L)ᵏ) (لکیری) |
| SGD | O(1/√k) | O(1/k) |
| تیز رفتار جی ڈی (نیسٹروف) | O(1/k²) | O((1−√(μ/L))ᵏ) |
جہاں k = تکرار کی گنتی، μ = مضبوط محدب پیرامیٹر، L = Lipschitz مستقل۔
### سیکھنے کی شرح کا انتخاب
| حکمت عملی | تفصیل |
|------------|---------------|
| فکسڈ α | سادہ لیکن مختلف ہو سکتا ہے (بہت بڑا) یا آہستہ آہستہ (بہت چھوٹا) |
| لائن تلاش | α تلاش کریں جو میلان سمت کے ساتھ f(x − α∇f(x)) کو کم کرتا ہے |
| کشی کے نظام الاوقات | α_t = α₀ / (1 + βt) یا α_t = α₀ · βᵗ |
| وارم اپ | چھوٹی شروعات کریں، بڑھائیں، پھر زوال پذیر ہوں (ٹرانسفارمر کی تربیت میں عام) |
| موافقت (آدم) | تدریجی اعدادوشمار پر مبنی فی پیرامیٹر سیکھنے کی شرح |

## محدود اصلاح
### لگرینج ملٹیپلائرز
مسئلہ کے لیے: f(x) کو h(x) = 0 سے مشروط کم سے کم کریں۔
**لاگریجیئن:** L(x, λ) = f(x) + λh(x)
زیادہ سے زیادہ: ∇ₓL = 0 اور ∇_λL = 0 (جو دیتا ہے h(x) = 0)۔
**کام کی مثال:** f(x,y) = x² + y² کو x + y = 1 سے مشروط چھوٹا کریں۔
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- رکاوٹ: x + y = 1 → −λ = 1 → λ = −1
- حل: x = 1/2، y = 1/2، f = 1/2
### KKT شرائط
**Karush-kuhn-Tucker (KKT) کی شرائط** Lagrange multipliers کو عدم مساوات کی رکاوٹوں پر عام کرتی ہیں۔
برائے: f(x) کو چھوٹا کریں gᵢ(x) ≤ 0، hⱼ(x) = 0 کے تابع۔
**لاگریجیئن:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT شرائط** (بہتری کے لیے ضروری):
| حالت | مساوات |
|------------|----------|
| اسٹیشنریٹی | ∇ₓL = 0 |
| ابتدائی فزیبلٹی | gᵢ(x) ≤ 0، hⱼ(x) = 0 |
| دوہری فزیبلٹی | λᵢ ≥ 0 |
| تکمیلی سستی | λᵢgᵢ(x) = 0 for all i |
**تکمیلی سست روی** کا مطلب ہے: اگر رکاوٹ gᵢ فعال نہیں ہے (gᵢ(x) <0)، تو λᵢ = 0 (حل کو متاثر نہیں کرتا ہے)۔
سلیٹر کی حالت کو مطمئن کرنے والے محدب مسائل کے لیے، KKT شرائط دونوں ضروری اور کافی ہیں۔

## دوہرا پن
ہر اصلاحی مسئلہ (**پرائمل**) میں ایک منسلک **دوہری** مسئلہ ہوتا ہے۔
### کمزور اور مضبوط دوہرای۔
| تصور | بیان |
|---------|------------|
| **دوہری تقریب** | g(λ, ν) = infₓ L(x, λ, ν) |
| **دوہری مسئلہ** | g(λ, ν) کو زیادہ سے زیادہ کریں λ ≥ 0 |
| **کمزور دوہرا** | دوہری بہترین ≤ پرائمل بہترین (ہمیشہ رکھتا ہے) |
| **مضبوط دوہرا** | Dual optimal = Primal optimal (Slater کی حالت کے ساتھ محدب مسائل کے لیے رکھتا ہے) |
| **دوہری فرق** | پرائمل بہترین − ڈوئل بہترین (زیرو زیرو مضبوط ڈوئلٹی) |
### کیوں دوہری اہمیت رکھتا ہے۔
| درخواست | ڈوئلٹی کس طرح مدد کرتی ہے |
|----------------------------|-------------------|
| نچلی حدیں | Dual اس بات کا سرٹیفکیٹ دیتا ہے کہ بنیادی حل کتنا اچھا ہے |
| SVMs | SVM مسئلہ کی دوہری دانا کی چال کی طرف جاتا ہے |
| حساسیت کا تجزیہ | دوہری متغیر اس بات کی پیمائش کرتے ہیں کہ اگر رکاوٹوں میں نرمی کی جائے تو کتنی زیادہ سے زیادہ تبدیلیاں آتی ہیں |
| گلنا | دوہری کے ذریعے بڑے مسائل کو چھوٹے ذیلی مسائل میں تقسیم کیا جا سکتا ہے۔

## انٹیجر پروگرامنگ
جب کچھ یا تمام متغیرات کا **انٹیجرز** ہونا ضروری ہے، تو مسئلہ بہت مشکل ہو جاتا ہے (عام طور پر NP- مشکل)۔
### اقسام
| قسم | تفصیل |
|------|---------------|
| خالص IP | تمام متغیرات کا عددی ہونا ضروری ہے |
| مخلوط IP (MIP) | کچھ متغیرات عددی، کچھ مسلسل |
| بائنری آئی پی | متغیرات {0, 1} تک محدود |
### حل کے طریقے
| طریقہ | آئیڈیا |
|---------|------|
| **برانچ اور پابند** | ذیلی مسائل میں تقسیم کریں، ایل پی کی نرمی کو حل کریں، کٹائی |
| ** ہوائی جہاز کاٹنا** | LP نرمی کو سخت کرنے کے لیے لکیری رکاوٹیں شامل کریں۔
| **شاخ اور کٹ** | کٹنگ طیاروں کے ساتھ شاخ اور پابند کو جوڑیں |
| **حیورسٹکس** | لالچی، مقامی تلاش، تخمینی حل کے لیے مصنوعی اینیلنگ |
---

## Heuristic اور Metaheuristic طریقے
جب عین مطابق اصلاح قابل عمل ہوتی ہے، تو تحقیق کرنے والے اچھے (ضروری نہیں کہ زیادہ سے زیادہ) حل تلاش کرتے ہیں۔
| طریقہ | کلیدی خیال | کے لیے بہترین |
|---------|----------|---------|
| **گریڈینٹ ڈیسنٹ** | سب سے تیز نزول کی پیروی کریں | ہموار، مختلف افعال |
| **نیوٹن کا طریقہ** | سیکنڈ آرڈر (کرویچر) معلومات کا استعمال کریں | ہموار، اچھی طرح سے کنڈیشنڈ مسائل |
| **نقلی اینیلنگ** | کم ہوتے امکان کے ساتھ بدتر حل قبول کریں | عالمی اصلاح، مشترکہ |
| **جینیاتی الگورتھم** | سلیکشن، کراس اوور، میوٹیشن کا استعمال کرتے ہوئے آبادی کو تیار کریں۔ کثیر مقصدی، غیر امتیازی |
| **ذرہ کا بھیڑ** | ایجنٹس جگہ کی تلاش کرتے ہیں، مشہور ترین عہدوں سے متاثر ہو کر | مسلسل، غیر محدب |
| **بیسیئن اصلاح** | سروگیٹ ماڈل بنائیں، حصول فنکشن کا استعمال کریں | مہنگے بلیک باکس فنکشنز (ہائپر پیرامیٹر ٹیوننگ) |
### اصلاح کے لیے نیوٹن کا طریقہ
**اپ ڈیٹ کا اصول:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
جہاں H ہیسیئن میٹرکس ہے (دوسرے مشتقات کا میٹرکس)۔
| پراپرٹی | قدر |
|------------|-------|
| کنورجنسی کی شرح | چوکور (قریب زیادہ سے زیادہ) |
| فی تکرار لاگت | O(n³) برائے Hessian inversion |
| کی ضرورت ہے | دو بار قابل تفریق، مثبت یقینی ہیسیئن |
| Quasi-Newton (BFGS) | میلان سے تخمینی ہیسیئن | O(n²) فی تکرار |
---

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| اصلاح کا تصور | درخواست |
|------------|------------|
| تدریجی نزول | عصبی نیٹ ورکس کی تربیت، لاجسٹک ریگریشن، کوئی بھی قابل تفریق ماڈل |
| SGD اور متغیرات | بڑے پیمانے پر ایم ایل (منی بیچ ٹریننگ)، آن لائن سیکھنے |
| آدم، RMSprop | گہری سیکھنے کے لیے پہلے سے طے شدہ اصلاح کار |
| محدب اصلاح | SVMs، لاجسٹک ریگریشن، LASSO، Ridge (Garanted Global optimum) |
| Lagrange multipliers | محدود تعلیم، منصفانہ ایم ایل، وسائل کی تقسیم |
| KKT شرائط | SVM دوہری اخذ کرنا، رکاوٹ کی سرگرمی کو سمجھنا |
| دوہری | SVM دانا کی چال، حساسیت کا تجزیہ، سڑنے کے طریقے |
| لکیری پروگرامنگ | وسائل کی تقسیم، پورٹ فولیو آپٹیمائزیشن، نیٹ ورک فلو |
| انٹیجر پروگرامنگ | خصوصیت کا انتخاب (بائنری)، شیڈولنگ، مشترکہ مسائل |
| Bayesian اصلاح | Hyperparameter ٹیوننگ (Optuna, Hyperopt) |
| نیوٹن/کواسی-نیوٹن | چھوٹے سے درمیانے درجے کے مسائل کے لیے سیکنڈ آرڈر کے طریقے (L-BFGS) |

## خلاصہ
| طریقہ | مسئلہ کی قسم | ضمانتیں | پیمانہ |
|---------|------------|------------|---------|
| سمپلیکس | لکیری پروگرامنگ | عین مطابق زیادہ سے زیادہ | لاکھوں متغیرات |
| اندرونی نقطہ | محدب (LP, QP, SOCP) | عین مطابق زیادہ سے زیادہ | بڑے پیمانے پر |
| تدریجی نزول | ہموار غیر محدود | مقامی منٹ میں بدل جاتا ہے | بہت بڑا (گہری سیکھنے) |
| SGD | بڑے پیمانے پر تجرباتی خطرہ | کنورجس (سڑنے کے ساتھ) | بڑے پیمانے پر ڈیٹا سیٹس |
| نیوٹن / BFGS | ہموار، دو بار قابل تفریق | چوکور کنورجنسنس | چھوٹے سے درمیانے |
| KKT / Lagrange | محدود (محدب) | بالکل شرائط کے تحت | میڈیم |
| شاخ اور پابند | انٹیجر پروگرامنگ | عین مطابق زیادہ سے زیادہ | چھوٹے سے درمیانے |
| Heuristics | کوئی بھی (غیر محدب، امتزاج) | کوئی گارنٹی نہیں | مختلف ہوتی ہے |
مشین لرننگ میں آپٹمائزیشن دلیلاً سب سے اہم ریاضیاتی ٹول ہے۔ ہر وہ ماڈل جسے آپ تربیت دیتے ہیں — لکیری ریگریشن سے لے کر بڑے لینگویج ماڈلز تک — میں اصلاح کا مسئلہ حل کرنا شامل ہے۔ یہ سمجھنا کہ مسئلہ کب محدب ہوتا ہے (عالمی سطح پر زیادہ سے زیادہ کی ضمانت دی جاتی ہے)، جب تدریجی نزول آپس میں مل جاتا ہے، اور رکاوٹوں کو کیسے ہینڈل کرنا ہے آپ کو سیکھنے کے الگورتھم کو ڈیزائن، ڈیبگ کرنے اور بہتر بنانے کی نظریاتی بنیاد فراہم کرتا ہے۔
