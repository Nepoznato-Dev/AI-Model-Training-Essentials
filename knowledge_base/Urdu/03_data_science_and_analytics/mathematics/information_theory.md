#انفارمیشن تھیوری
انفارمیشن تھیوری، جس کی بنیاد 1948 میں کلاڈ شینن نے رکھی تھی، خود معلومات کی مقدار بتاتی ہے۔ ایک پیغام آپ کو کتنا بتاتا ہے؟ آپ ڈیٹا کو کتنا کمپریس کر سکتے ہیں؟ آپ شور مچانے والے چینل پر کتنی تیزی سے بات چیت کر سکتے ہیں؟ ان سوالات کے عین حسابی جوابات ہیں۔ کمیونیکیشن کے علاوہ، انفارمیشن تھیوری مشین لرننگ کی بنیاد بن گئی ہے — کراس اینٹروپی درجہ بندی کے لیے ڈیفالٹ نقصان کا فنکشن ہے، KL ڈائیورجینس تقسیم کی مماثلت کی پیمائش کرتا ہے، اور باہمی معلومات کی ڈرائیو فیچر سلیکشن ہے۔

## اینٹروپی
**Entropy** ایک بے ترتیب متغیر کی اوسط غیر یقینی صورتحال یا "حیرت" کی پیمائش کرتی ہے۔
### شینن اینٹروپی (مجرد)
امکانی ماس فنکشن p(x) کے ساتھ ایک مجرد بے ترتیب متغیر X کے لیے:
H(X) = −Σₓ p(x) log₂ p(x)
اکائیاں: **بٹس** (جب لاگ₂ استعمال کرتے ہیں) یا **نیٹس** (جب ایل این استعمال کرتے ہیں)۔
| تقسیم | اینٹروپی | وجدان |
|---------------|---------|------------|
| فیئر کوائن (p = 0.5، 0.5) | 1 بٹ | بائنری نتائج کے لیے زیادہ سے زیادہ غیر یقینی صورتحال |
| متعصب سکہ (p = 0.9، 0.1) | 0.469 بٹس | کم حیران کن - زیادہ تر سر |
| ڈیٹرمنسٹک (p = 1, 0) | 0 بٹس | کوئی غیر یقینی صورتحال نہیں |
| فیئر ڈائی (6 اطراف) | 2.585 بٹس | مزید نتائج = مزید غیر یقینی صورتحال |
| n نتائج پر یکساں | log₂(n) بٹس | n نتائج کے لیے زیادہ سے زیادہ اینٹروپی |
### اینٹروپی کی خصوصیات
| پراپرٹی | بیان |
|------------|------------|
| غیر منفی | H(X) ≥ 0 |
| زیادہ سے زیادہ | H(X) ≤ log₂(\|X\|) یکساں تقسیم کے لیے مساوات کے ساتھ |
| سلسلہ اصول | H(X, Y) = H(X) + H(Y \| X) |
| کنڈیشنگ کم کر دیتا ہے | H(X \| Y) ≤ H(X) |
| مقعر | H امکانی تقسیم کا ایک مقعر فعل ہے |
### تفریق انٹروپی (مسلسل)
کثافت p(x) کے ساتھ مسلسل بے ترتیب متغیر X کے لیے:
h(X) = −∫ p(x) لاگ p(x) dx
مجرد انٹروپی کے برعکس، تفریق انٹروپی **منفی** ہوسکتی ہے۔
| تقسیم | تفریق اینٹروپی |
|----------------------------|----------------------|
| یونیفارم پر [a,b] | log(b − a) |
| نارمل N(μ, σ²) | (1/2) لاگ(2πeσ²) |
| کفایتی(λ) | 1 − ln(λ) |

## مشترکہ، مشروط اور باہمی معلومات
### جوائنٹ اینٹروپی
H(X, Y) = −Σₓ Σᵧ p(x, y) لاگ p(x, y)
جوڑے کی کل غیر یقینی صورتحال (X، Y) کی پیمائش کرتا ہے۔
### مشروط اینٹروپی
H(Y | X) = −Σₓ Σᵧ p(x, y) لاگ p(y | x) = H(X, Y) − H(X)
X کا مشاہدہ کرنے کے بعد Y کے بارے میں باقی رہنے والی غیر یقینی صورتحال کے اقدامات۔
### باہمی معلومات
I(X; Y) = Σₓ Σᵧ p(x, y) لاگ [p(x, y) / (p(x)p(y))]
پیمائش کرتا ہے کہ X جاننا آپ کو Y کے بارے میں کتنا بتاتا ہے (اور اس کے برعکس)۔
| پراپرٹی | بیان |
|------------|------------|
| غیر منفی | I(X; Y) ≥ 0 |
| ہم آہنگی | I(X; Y) = I(Y; X) |
| اینٹروپی سے تعلق | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
| مشترکہ سے تعلق | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| آزادی | I(X; Y) = 0 iff X اور Y آزاد ہیں |
| خود معلومات | I(X; X) = H(X) |
### بصری: اینٹروپی ڈایاگرام
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## کے ایل ڈائیورجنس
**Kullback-Leibler (KL) کا انحراف** پیمائش کرتا ہے کہ ایک تقسیم دوسری تقسیم سے کتنی مختلف ہے۔
D_KL(P || Q) = Σₓ P(x) لاگ [P(x) / Q(x)]
| پراپرٹی | بیان |
|------------|------------|
| غیر منفی | D_KL(P \|\| Q) ≥ 0 (گبز کی عدم مساوات) |
| شناخت | D_KL(P \|\| Q) = 0 iff P = Q |
| غیر متناسب | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) عام طور پر |
| میٹرک نہیں | ہم آہنگی اور مثلث کی عدم مساوات میں ناکامی |
**تشریح:** D_KL(P || Q) P سے ڈیٹا کو انکوڈ کرنے کے لیے درکار بٹس کی اضافی تعداد ہے جو Q کے لیے آپٹمائزڈ کوڈ کا استعمال کرتے ہوئے ہے۔
### دیگر مقداروں سے تعلق
| رشتہ | فارمولہ |
|---------------|---------|
| کراس اینٹروپی | H(P, Q) = H(P) + D_KL(P \|\| Q) |
| باہمی معلومات | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| مشروط KL | D_KL(P(Y\|X) \|\| Q(Y\|X)) X سے زیادہ اوسط |

## کراس اینٹروپی
**کراس اینٹروپی** تقسیم P اور Q کے درمیان:
H(P, Q) = −Σₓ P(x) لاگ Q(x) = H(P) + D_KL(P || Q)
### کراس اینٹروپی بطور نقصان فنکشن
درجہ بندی میں، P حقیقی تقسیم ہے (ایک گرم انکوڈ شدہ لیبل) اور Q ماڈل کی پیش گوئی شدہ تقسیم ہے۔
**بائنری کراس اینٹروپی (BCE):**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**کیٹیگوریکل کراس اینٹروپی:**
L = −Σᵢ yᵢ log(ŷᵢ)
| منظر نامہ | y (سچ) | ŷ (پیش گوئی) | نقصان |
|------------|---------|---------------|------|
| درست، پر اعتماد | 1 | 0.95 | 0.051 |
| درست، غیر یقینی | 1 | 0.55 | 0.598 |
| غلط، پر اعتماد | 1 | 0.05 | 2.996 |
| غلط، غیر یقینی | 1 | 0.45 | 0.799 |
کراس اینٹروپی کو کم سے کم کرنا حقیقی تقسیم سے KL کے انحراف کو کم کرنے کے مترادف ہے - یہی وجہ ہے کہ یہ نقصان کے فنکشن کے ساتھ اتنا اچھا کام کرتا ہے۔

## چینل کی صلاحیت
### کمیونیکیشن چینل ماڈل
```
X → [Channel] → Y
```

- X: ان پٹ بے ترتیب متغیر
- Y: آؤٹ پٹ بے ترتیب متغیر
- چینل: مشروط امکانات کے ذریعہ بیان کردہ p(y|x)
### شینن کے شور والے چینل کوڈنگ تھیوریم
صلاحیت C کے ساتھ ایک چینل کے لئے، اگر ٹرانسمیشن کی شرح R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C، قابل اعتماد مواصلات ناممکن ہے.
**چینل کی گنجائش:**
C = max_{p(x)} I(X; Y)
### چینل کی اہم مثالیں۔
| چینل | تفصیل | صلاحیت |
|---------|---------------|---------|
| **بائنری سمیٹرک (BSC)** | امکان p | کے ساتھ ہر ایک بٹ کو پلٹتا ہے۔ 1 − H(p) بٹس |
| **بائنری ایریزر (BEC)** | ہر ایک بٹ کو امکان کے ساتھ مٹاتا ہے ε | 1 - ε بٹس |
| **Gaussian (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)لاگ(1 + SNR) بٹس |
| ** بے آواز بائنری** | کامل ٹرانسمیشن | 1 بٹ |

## سورس کوڈنگ اور کمپریشن
### سورس کوڈنگ تھیوریم
کسی ماخذ کو انکوڈ کرنے کے لیے درکار بٹس کی اوسط تعداد اس کی اینٹروپی کے نیچے پابند ہے:
L ≥ H(X)
ایک بہترین کوڈ L ≈ H(X) حاصل کرتا ہے۔
### ہف مین کوڈنگ
ایک **پریفکس فری** کوڈ جو زیادہ ممکنہ علامتوں کو چھوٹے کوڈز تفویض کرتا ہے۔
| علامت | امکان | ہف مین کوڈ | لمبائی |
|---------|------------|---------------|---------|
| ایک | 0.5 | 0 | 1 |
| ب | 0.25 | 10 | 2 |
| سی | 0.125 | 110 | 3 |
| ڈی | 0.125 | 111 | 3 |
اوسط لمبائی: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 بٹس/علامت
اینٹروپی: H = 1.75 بٹس/علامت (اس معاملے میں بہترین!)
### نقصان دہ بمقابلہ نقصان دہ کمپریشن
| قسم | اصول | مثالیں | حد |
|------|------------|---------|-------|
| **بے ​​نقصان** | شماریاتی فالتو پن کو ہٹا دیں | ZIP، PNG، FLAC | اینٹروپی ریٹ H(X) |
| **نقصان مند** | ادراک سے غیر متعلقہ معلومات کو ہٹا دیں | JPEG, MP3, H.264 | شرح مسخ فنکشن R(D) |
**ریٹ ڈسٹورشن تھیوری:** زیادہ سے زیادہ ڈسٹورشن D کے ساتھ نقصان دہ کمپریشن کے لیے، کم از کم شرح ہے R(D) = min I(X; X̂) E[d(X, X̂)] ≤ D کے تابع۔

## دوسرے شعبوں سے رابطے
### انفارمیشن تھیوری اور تھرموڈینامکس
| تصور | انفارمیشن تھیوری | تھرموڈینامکس |
|---------|-------------------------|
| اینٹروپی | شینن اینٹروپی H(X) | بولٹزمین اینٹروپی S = k_B ln W |
| زیادہ سے زیادہ اینٹروپی | یکساں تقسیم | تھرمل توازن |
| کے ایل ڈائیورجنس | تقسیم کا فرق | مفت توانائی فرق |
| باہمی معلومات | مشترکہ معلومات | جسمانی نظاموں میں ارتباط |
ریاضی کی شکلیں ایک جیسی ہیں — شینن نے جان بوجھ کر شماریاتی میکانکس سے اصطلاح "اینٹروپی" مستعار لی۔
### انفارمیشن تھیوری اور شماریات
| تصور | درخواست |
|---------|---------------|
| زیادہ سے زیادہ امکان | تجرباتی سے ماڈل ڈسٹری بیوشن تک KL کے انحراف کو کم کرنے کے مترادف |
| فشر کی معلومات | KL انحراف کی گھماؤ؛ تخمینہ لگانے والے تغیر پر کم حد (Cramér-Rao) |
| کم از کم تفصیل کی لمبائی (MDL) | انکوڈنگ کی کل لمبائی کو کم سے کم کرکے ماڈل کا انتخاب |
| AIC / BIC | تخمینی KL پر مبنی ماڈل کے انتخاب کا معیار |

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| آئی ٹی کا تصور | ایم ایل ایپلیکیشن |
|------------|----------------|
| کراس اینٹروپی نقصان | پہلے سے طے شدہ درجہ بندی کا نقصان (بائنری اور ملٹی کلاس) |
| کے ایل ڈائیورجنس | VAE نقصان (ریگولرائزیشن ٹرم)، ڈسٹری بیوشن میچنگ، ڈسٹلیشن |
| باہمی معلومات | فیچر سلیکشن (MIFS)، نمائندگی سیکھنے (InfoMax)، disentanglement |
| اینٹروپی | فیصلے کے درخت کی تقسیم کا معیار (معلومات حاصل کرنا)، آر ایل میں ایکسپلوریشن (زیادہ سے زیادہ اینٹروپی آر ایل) |
| چینل کی صلاحیت | کمیونیکیشن کی پیچیدگی، جنرلائزیشن کی حدود کو سمجھنا |
| ماخذ کوڈنگ | اسٹوریج اور ٹرانسمیشن کے لیے ڈیٹا کمپریشن، موثر انکوڈنگ |
| زیادہ سے زیادہ اینٹروپی | MaxEnt درجہ بندی، Bayesian inference میں پیشگی انتخاب |
| شرح مسخ | نقصان دہ کمپریشن میں تجارتی معاہدوں کو سمجھنا، نیورل نیٹ ورکس میں کوانٹائزیشن |
| فشر کی معلومات | قدرتی میلان نزول، پیرامیٹر کی حساسیت کو سمجھنا |
| MDL/AIC/BIC | ماڈل کا انتخاب، اوور فٹنگ کو روکنا |

## خلاصہ
| مقدار | فارمولہ (مجرد) | معنی |
|------------|----------------------|---------|
| اینٹروپی H(X) | −Σ p(x) لاگ p(x) | اوسط غیر یقینی صورتحال |
| مشترکہ اینٹروپی H(X,Y) | −Σ p(x,y) لاگ p(x,y) | جوڑی کی مکمل غیر یقینی صورتحال |
| مشروط اینٹروپی H(Y\|X) | H(X,Y) − H(X) | Y دی گئی X کے بارے میں باقی غیر یقینی صورتحال |
| باہمی معلومات I(X;Y) | H(X) − H(X\|Y) | X اور Y کے درمیان مشترکہ معلومات |
| KL ڈائیورژن D_KL(P\|\|Q) | Σ P(x) لاگ(P(x)/Q(x)) | تقسیم کے درمیان "فاصلہ" |
| کراس اینٹروپی H(P,Q) | −Σ P(x) لاگ Q(x) | غلط تقسیم کا استعمال کرتے ہوئے انکوڈنگ لاگت |
| چینل کی صلاحیت C | زیادہ سے زیادہ I(X;Y) | زیادہ سے زیادہ قابل اعتماد مواصلات کی شرح |
انفارمیشن تھیوری اس کی بنیادی حدود فراہم کرتی ہے کہ کیا سیکھا جا سکتا ہے، کمپریس کیا جا سکتا ہے، اور بات چیت کی جا سکتی ہے۔ مشین لرننگ پریکٹیشنرز کے لیے، یہ بتاتا ہے کہ کراس اینٹروپی نقصان کے فنکشن کے طور پر کیوں کام کرتی ہے، سیکھی ہوئی نمائندگی کے معیار کی پیمائش کیسے کی جائے، اور ماڈل کی پیچیدگی اور ڈیٹا فٹ کے درمیان تجارت کے بارے میں کیسے سوچا جائے۔ 1948 سے شینن کی بصیرتیں جدید AI سے اتنی ہی متعلقہ رہیں جتنی کہ وہ ٹیلی کمیونیکیشن سے ہیں۔
