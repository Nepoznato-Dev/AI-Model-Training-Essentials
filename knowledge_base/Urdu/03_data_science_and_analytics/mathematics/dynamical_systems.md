# متحرک نظام
ایک **متحرک نظام** بیان کرتا ہے کہ ایک ریاست ایک مقررہ اصول کے مطابق وقت کے ساتھ کیسے تیار ہوتی ہے۔ سیاروں کے مدار سے لے کر آبادی کی حرکیات تک، موسم کے نمونوں سے لے کر نیورل نیٹ ورکس کی تربیت تک، متحرک نظام کا نظریہ یہ سمجھنے کے لیے زبان اور اوزار فراہم کرتا ہے کہ چیزیں کیسے بدلتی ہیں۔ یہ فائل عام تفریق مساوات (ODEs)، جزوی تفریق مساوات (PDEs)، استحکام تجزیہ، افراتفری، اور تقسیم کا احاطہ کرتی ہے۔

## عام تفریق مساوات (ODEs)
ایک ODE کسی فنکشن کو اس کے مشتقات سے ایک واحد آزاد متغیر (عام طور پر وقت) کے حوالے سے جوڑتا ہے۔
### درجہ بندی
| پراپرٹی | اقسام |
|------------|-------|
| **آرڈر** | سب سے زیادہ مشتق موجود (پہلا آرڈر، دوسرا آرڈر، وغیرہ) |
| ** لکیری بمقابلہ نان لائنر** | لکیری: y'' + p(t)y' + q(t)y = g(t); غیر لکیری: کچھ اور |
| **یکساں** | g(t) = 0 (کوئی زبردستی اصطلاح نہیں) |
| **خود مختار** | کوئی واضح وقت پر انحصار نہیں: dy/dt = f(y) |
| **مستقل قابلیت** | p، q مستقل ہیں |
### فرسٹ آرڈر ODEs
**عام شکل:** dy/dt = f(t, y)
| قسم | فارم | حل کا طریقہ |
|------|------|-----------------|
| الگ ہونے والا | dy/dt = g(t)h(y) | الگ اور مربوط کریں: ∫dy/h(y) = ∫g(t)dt |
| لکیری فرسٹ آرڈر | dy/dt + p(t)y = q(t) | ضم کرنے والا عنصر: μ(t) = e^(∫p dt) |
| عین مطابق | M(t,y)dt + N(t,y)dy = 0 کے ساتھ ∂M/∂y = ∂N/∂t | ممکنہ فنکشن تلاش کریں F(t,y) |
| برنولی | dy/dt + p(t)y = q(t)yⁿ | v = y^(1−n) کو لکیری بنائیں |
** کام کی مثال (انٹیگریٹنگ فیکٹر):** حل کریں dy/dt + 2y = e^(−t), y(0) = 1۔
- انٹیگریٹنگ فیکٹر: μ(t) = e^(∫2 dt) = e^(2t)
- ضرب: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- انٹیگریٹ: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- ابتدائی حالت: y(0) = 1 → 1 = 1 + C → C = 0
- حل: y(t) = e^(−t)
### سیکنڈ آرڈر لکیری ODEs
**عام شکل:** ay'' + by' + cy = g(t)
**یکساں صورت** (g ​​= 0): خصوصیت کی مساوات ar² + br + c = 0 کو حل کریں۔
| امتیازی | جڑیں | عمومی حل |
|---------------|---------|------|
| b² > 4ac (زیادہ ڈیمپڈ) | دو الگ الگ اصلی r₁, r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (تنقیدی طور پر گیلا) | بار بار اصلی جڑ r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (کم ڈیمپڈ) | پیچیدہ جڑیں α ± βi | y = e^(αt)(C₁ cos βt + C₂ sin βt) |
**جسمانی تشریح:** ایک ماس-اسپرنگ ڈیمپر سسٹم mx'' + bx' + kx = 0۔
- اوورڈیمپڈ: بھاری نمی، کوئی دوغلا پن نہیں (دروازہ قریب)
- تنقیدی طور پر نم ہوا: بغیر دولن کے تیز ترین واپسی (کار کی معطلی کے ڈیزائن کا ہدف)
- انڈرڈیمپڈ: زوال پذیر طول و عرض کے ساتھ دوہرتا ہے (گٹار کی تار)
### ODEs کے نظام
بہت سے حقیقی نظاموں میں متعدد تعامل متغیرات شامل ہیں:
dx/dt = f(x, y)
dy/dt = g(x, y)
اسے ویکٹر کی شکل میں لکھا جا سکتا ہے: d**x**/dt = **F**(**x**)
**لکیری نظام:** d**x**/dt = A**x**، جہاں A ایک میٹرکس ہے۔
حل کا انحصار A کی egenvalues ​​پر ہے:
| Eigenvalues ​​| سلوک |
|---------------|------------|
| دونوں حقیقی، منفی | مستحکم نوڈ (تمام رفتاریں اصل میں ملتی ہیں) |
| دونوں حقیقی، مثبت | غیر مستحکم نوڈ |
| حقیقی، مخالف علامات | سیڈل پوائنٹ (غیر مستحکم) |
| پیچیدہ، منفی حقیقی حصہ | مستحکم سرپل (نم شدہ دولن) |
| پیچیدہ، مثبت حقیقی حصہ | غیر مستحکم سرپل |
| خالص خیالی | مرکز (بند مدار) |

## فیز پورٹریٹ
ایک **فیز پورٹریٹ** ریاستی جگہ میں متحرک نظام کی رفتار کو دیکھتا ہے (واضح طور پر حل کیے بغیر)۔
### اہم خصوصیات
| خصوصیت | تفصیل |
|---------|---------------|
| **مقررہ نقطہ (توازن)** | جہاں dx/dt = 0 (کوئی حرکت نہیں) |
| **ٹریجیکٹری** | ریاستی جگہ میں نظام کے ذریعہ تلاش کردہ راستہ |
| **Nulcline** | وکر جہاں ایک جزو کا مشتق صفر ہے |
| **حد سائیکل** | الگ تھلگ بند مدار (خود مسلسل دولن) |
| ** کشش کا بیسن** | ابتدائی حالات کا سیٹ جو کسی دیے گئے متوجہ کی طرف لے جاتا ہے |
| **Separatrix** | کشش کے مختلف بیسن کے درمیان حد |
### پریڈیٹر-پری ماڈل (لوٹکا-وولٹررا)
dx/dt = αx − βxy (شکار)
dy/dt = δxy − γy (شکاری)
**فکسڈ پوائنٹس:**
1. (0، 0) - ناپید ہونا (سیڈل پوائنٹ)
2. (γ/δ, α/β) — بقائے باہمی (مرکز — بند مدار)
نظام وقتاً فوقتاً دوہرائیوں کی نمائش کرتا ہے: شکار بڑھتا ہے → شکاری بڑھتا ہے → شکار کم ہوتا ہے → شکاری کم ہوتا ہے → سائیکل دہراتا ہے۔

## استحکام تجزیہ
### لکیری استحکام
ایک مقررہ نقطہ x* کے لیے، اس کے ارد گرد لکیری بنائیں: let u = x − x*، پھر du/dt ≈ J(x*)u جہاں J Jacobian میٹرکس ہے۔
**استحکام کا معیار:** مقررہ نقطہ یہ ہے:
- **مستحکم** اگر J کی تمام eigenvalues کے حقیقی حصے منفی ہوں۔
- **غیر مستحکم** اگر کسی ایگن ویلیو میں مثبت حقیقی حصہ ہو۔
- **معمولی طور پر مستحکم** اگر eigenvalues کے اصلی حصے صفر ہیں (نان لائنر تجزیہ کی ضرورت ہے)
### لیپونوف استحکام
**لیاپونوف کا براہ راست طریقہ** بغیر خطوط کے استحکام کا تعین کرتا ہے۔
A **Lyapunov فنکشن** V(x) مطمئن کرتا ہے:
1. V(x*) = 0 اور V(x) > 0 برائے x ≠ x* (مثبت قطعی)
2. dV/dt ≤ 0 رفتار کے ساتھ ساتھ (غیر بڑھنے والا)
| حالت | نتیجہ |
|------------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | غیر مستحکم |
**کام کی مثال:** سسٹم dx/dt = −x + y²، dy/dt = −y۔
- V(x,y) = x² + y² (توانائی جیسا فنکشن) آزمائیں
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² −2y²
- اصل کے قریب: dV/dt ≈ −2x² − 2y² < 0 (چھوٹے y کے لیے، −2y² کا غلبہ)
- نتیجہ: اصلیت مقامی طور پر غیر علامتی طور پر مستحکم ہے۔

## افراتفری کا نظریہ
**افراتفری** تعییناتی لیکن غیر متوقع ہے: نظام قطعی اصولوں کی پیروی کرتا ہے، لیکن ابتدائی حالات میں چھوٹے فرق بہت مختلف نتائج کا باعث بنتے ہیں۔
### افراتفری کے تقاضے
| پراپرٹی | تفصیل |
|------------|---------------|
| تعین پرست | کوئی تصادفی نہیں — عین مساوات کے ذریعے کنٹرول کیا جاتا ہے۔
| ابتدائی حالات کے لیے حساس | قریبی رفتار تیزی سے بدل جاتی ہے |
| پابند | رفتار لامحدودیت کی طرف نہیں بھاگتی |
| غیر متواتر | کبھی بھی بالکل نہیں دہرایا جاتا |
### لورینز سسٹم
تعییناتی افراتفری کی بہترین مثال:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
معیاری پیرامیٹرز کے ساتھ σ = 10، ρ = 28، β = 8/3:
- نظام کے تین فکسڈ پوائنٹس ہیں، تمام غیر مستحکم
- رفتار ایک مقررہ نقطے کا چکر لگاتی ہے، پھر اچانک دوسرے پر سوئچ کرتی ہے۔
- نتیجہ **لورینز کو متوجہ کرنے والا** ہے — فریکٹل ساخت کے ساتھ ایک عجیب کشش کرنے والا
**لیاپونوف ایکسپوننٹ:** قریبی رفتار کے انحراف کی شرح کی پیمائش کرتا ہے۔
- مثبت لائاپونوف ایکسپوننٹ → افراتفری
- معیاری پیرامیٹرز کے ساتھ لورینز سسٹم کے لیے: سب سے بڑا ایکسپوننٹ ≈ 0.9 > 0
### لاجسٹک نقشہ
ایک سادہ مجرد نظام جو افراتفری کو ظاہر کرتا ہے:
x_{n+1} = rx_n(1 − x_n)
| پیرامیٹر r | سلوک |
|---------------|------------|
| 0 < r < 1 | آبادی ختم ہو جاتی ہے (x → 0) |
| 1 < r < 3 | x = 1 − 1/r | پر مستحکم فکسڈ پوائنٹ
| 3 < r < 3.449 | دورانیہ-2 دولن |
| 3.449 < r < 3.544 | پیریڈ-4 دولن |
| 3.544 < r < 3.570 | Period-8, 16, 32, ... (مدت دوگنا جھرن) |
| r ≈ 3.570 | افراتفری کا آغاز |
| 3.570 < r < 4 | متواتر کھڑکیوں کے ساتھ زیادہ تر افراتفری |
| r = 4 | [0, 1] پر مکمل طور پر افراتفری |
### تتلی کا اثر
ابتدائی حالات پر حساس انحصار کا مشہور نام۔ موسمی نظاموں میں (لورینز مساوات کے ذریعہ تیار کردہ)، برازیل میں ایک تتلی اپنے پروں کو پھڑپھڑاتی ہوئی ٹیکساس میں طوفان کا آغاز کر سکتی ہے - اس لیے نہیں کہ تتلی اس کا سبب بنتی ہے، بلکہ اس لیے کہ چھوٹی چھوٹی پریشانیاں تیزی سے بڑھتی ہیں۔

## تقسیم نظریہ
ایک **تقسیم** نظام کے رویے میں ایک معیاری تبدیلی ہے کیونکہ پیرامیٹر مختلف ہوتا ہے۔
### تقسیم کی اقسام
| تقسیم | عام شکل | کیا ہوتا ہے |
|---------------|------------|---------------|
| **سیڈل نوڈ** | dx/dt = r − x² | دو فکسڈ پوائنٹس ظاہر / غائب |
| **ٹرانسکریٹیکل** | dx/dt = rx − x² | دو فکسڈ پوائنٹس کا تبادلہ استحکام |
| **پچ فورک (سپر کریٹیکل)** | dx/dt = rx − x³ | ایک مستحکم نقطہ دو مستحکم + ایک غیر مستحکم |
| **پچ فورک (ذیلی تنقیدی)** | dx/dt = rx + x³ | غیر مستحکم شاخیں گر جاتی ہیں (اکثر تباہ کن) |
| **Hopf** | 2D نظام | فکسڈ پوائنٹ غیر مستحکم ہو جاتا ہے، حد سائیکل ظاہر ہوتا ہے |
### تقسیم کا خاکہ
فکسڈ پوائنٹس بمقابلہ پیرامیٹر ویلیو کا ایک پلاٹ، استحکام دکھا رہا ہے (ٹھوس = مستحکم، ڈیشڈ = غیر مستحکم)۔ لاجسٹک نقشے کی تقسیم کا خاکہ افراتفری کے دورانیے کو دوگنا کرنے کے راستے اور مشہور **فیگنبام مستقل** δ ≈ 4.669 (متواتر تقسیم کے وقفوں کے درمیان عالمگیر تناسب) کو ظاہر کرتا ہے۔

## جزوی تفریق مساوات (PDEs)
PDEs میں متعدد متغیرات اور ان کے جزوی مشتق کے افعال شامل ہوتے ہیں۔
### سیکنڈ آرڈر لائنر PDEs کی درجہ بندی
Au_xx + 2Bu_xy + Cu_yy + ... = 0 کے لئے:
| قسم | حالت | سلوک | مثال |
|------|------------|------------|---------|
| **بیضوی** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | لہر کا پھیلاؤ، تیز خصوصیات کو محفوظ رکھتا ہے | لہر مساوات: u_tt = c²u_xx |
### حرارت کی مساوات
∂u/∂t = α ∂²u/∂x²
ماڈلز گرمی کا پھیلاؤ، آبادی کا پھیلاؤ، اختیارات کی قیمتوں کا تعین (بلیک-سکولز)۔
| پراپرٹی | بیان |
|------------|------------|
| ہموار | حل فوری طور پر ہموار ہو جاتے ہیں، یہاں تک کہ متواتر ابتدائی ڈیٹا سے بھی |
| زیادہ سے زیادہ اصول | زیادہ سے زیادہ درجہ حرارت حد یا ابتدائی وقت پر ہوتا ہے |
| وقت کی تبدیلی | ناقابل واپسی - پیچھے کی طرف نہیں چل سکتا |
### لہر کی مساوات
∂²u/∂t² = c² ∂²u/∂x²
ماڈلز ہلتے ہوئے تار، آواز، برقی مقناطیسی لہریں۔
| پراپرٹی | بیان |
|------------|------------|
| تبلیغ | خلل رفتار سے سفر کرنا c |
| Reversibility | وقت الٹنے والا |
| d'Alembert حل | u(x,t) = f(x−ct) + g(x+ct) (بائیں/دائیں لہروں کی سپرپوزیشن) |
### لاپلیس کی مساوات
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
حل (ہارمونک افعال) مستحکم درجہ حرارت، الیکٹرو اسٹاٹک پوٹینشل، ناقابل تسخیر سیال بہاؤ کی نمائندگی کرتے ہیں۔
| پراپرٹی | بیان |
|------------|------------|
| اوسط قدر کی جائیداد | u(x₀) = کسی بھی دائرے پر u کا اوسط جس کا مرکز x₀ |
| زیادہ سے زیادہ اصول | کوئی اندرونی میکسما یا منیما نہیں |
| انفرادیت | مکمل طور پر باؤنڈری حالات سے طے شدہ |

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| ڈی ایس تصور | درخواست |
|------------|-------------|
| ODEs | اعصابی ODEs (مسلسل گہرائی والے نیٹ ورک)، بار بار چلنے والی نیٹ ورک کی حرکیات |
| استحکام تجزیہ | تدریجی نزول کی تربیتی حرکیات (کیا نقصان مستحکم طور پر کم ہو رہا ہے؟) |
| لیپونوف افعال | سیکھنے کے الگورتھم کے کنورجنسی کو ثابت کرنا، کمک سیکھنے کا استحکام |
| افراتفری | RNNs میں حساسیت کو سمجھنا (غائب ہونے / پھٹنے والے میلان)، موسم کی پیشن گوئی |
| تقسیم | سیکھنے میں مرحلے کی منتقلی (گروکنگ)، تربیتی حرکیات میں نظام کی تبدیلی |
| PDEs | ڈفیوژن ماڈل (اسکور پر مبنی جنریٹو ماڈل)، فزکس سے باخبر نیورل نیٹ ورکس |
| حرارت کی مساوات | جنریٹیو ماڈلنگ میں پھیلاؤ کے عمل، گراف لیپلاسیئن اسموتھنگ |
| لہر مساوات | سیسمک ڈیٹا پروسیسنگ، آڈیو سگنل ماڈلنگ |
| Lotka-Volterra | آبادی کی حرکیات، وبائی امراض، مقابلہ کرنے والے ایم ایل ایجنٹس |
| فیز پورٹریٹ | نقصان کی زمین کی تزئین کی حرکیات کو تصور کرنا، GAN ٹریننگ کو سمجھنا |

## خلاصہ
| موضوع | بنیادی خیال | کلیدی ٹول |
|---------|------------|---------|
| ODEs | افعال اور ان کے وقت مشتقات | خصوصیت کی مساوات، ضم کرنے والے عوامل |
| ODEs کے نظام | متعدد تعامل متغیرات | جیکوبیان کا Eigenvalue تجزیہ |
| فیز پورٹریٹ | ریاستی جگہ میں حرکیات کا تصور کرنا | فکسڈ پوائنٹس، nullclines، حد کے چکر |
| استحکام | کیا نظام توازن کی طرف لوٹ آئے گا؟ | لکیریائزیشن، لیپونوف فنکشنز |
| افراتفری | تعییناتی غیر متوقع صلاحیت | لیپونوف کی وضاحت کرنے والے، عجیب متوجہ کرنے والے |
| تقسیم | پیرامیٹرز کے ساتھ معیار کی تبدیلیاں | عام شکلیں، تقسیم خاکہ |
| PDEs | متعدد متغیرات کے افعال | حرارت، لہر، اور لاپلیس مساوات |
ڈائنامیکل سسٹم تھیوری تبدیلی کی ریاضی ہے۔ یہ بتاتا ہے کہ کیوں کچھ نظام آباد ہو جاتے ہیں، کچھ کیوں چلتے ہیں، اور کیوں کچھ افراتفری سے برتاؤ کرتے ہیں۔ ڈیٹا سائنسدانوں کے لیے، یہ تربیتی حرکیات کو سمجھنے، مستحکم الگورتھم ڈیزائن کرنے، ماڈلنگ ٹائم سیریز، اور فزکس سے باخبر مشین لرننگ ماڈلز کی اگلی نسل کی تعمیر کے لیے ٹولز فراہم کرتا ہے۔
