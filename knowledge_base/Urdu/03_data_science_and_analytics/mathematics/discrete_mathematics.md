## تھیوری کو گہرائی میں مرتب کریں۔
سیٹ وہ بنیاد ہیں جس پر تقریباً تمام جدید ریاضی قائم ہے۔ ایک **سیٹ** مختلف اشیاء کا ایک غیر ترتیب شدہ مجموعہ ہے، جسے **عناصر** یا **ممبر** کہتے ہیں۔
### محوری بنیادیں (ZFC)
جدید سیٹ تھیوری **زرمیلو فرینکل کے محوروں پر محوری انتخاب (ZFC)** کے ساتھ قائم ہے۔ یہ محور رسل کے پیراڈوکس ("تمام سیٹوں کا سیٹ جو خود پر مشتمل نہیں ہیں") جیسے تضادات کو اس بات پر پابندی لگا کر حل کرتے ہیں کہ سیٹ کیسے بن سکتے ہیں۔
| محور | غیر رسمی بیان |
|---------|---------|
| توسیع | دو سیٹ برابر ہیں اگر ان میں ایک جیسے عناصر ہوں |
| خالی سیٹ | ایک سیٹ موجود ہے جس میں عناصر نہیں ہیں: ∅ |
| جوڑا بنانا | کسی بھی a, b کے لیے موجود ہے {a, b} |
| یونین | سیٹوں کے کسی بھی خاندان کے لیے، ان کا اتحاد موجود ہے |
| پاور سیٹ | کسی بھی سیٹ S کے لیے، S کے تمام ذیلی سیٹوں کا سیٹ موجود ہے: P(S) |
| انفینٹی | ایک لامحدود سیٹ موجود ہے |
| تفصیلات | کسی بھی سیٹ A اور پراپرٹی P کے لیے، {x ∈ A : P(x)} موجود ہے |
| متبادل | قابل تعریف فنکشن کے تحت سیٹ کی تصویر ایک سیٹ ہے |
| باقاعدگی | ہر غیر خالی سیٹ میں ایک عنصر ہوتا ہے جو اس سے الگ ہوتا ہے (خود رکنیت کو روکتا ہے) |
| انتخاب | کسی بھی خاندان کے لیے جوڑے کی صورت میں نان جوائنٹ سیٹ، ایک چوائس فنکشن موجود ہے |
### کارڈنلٹی اور سیٹ کا سائز
سیٹ کی **کارڈینیلٹی**، جس کی نشاندہی |S|، اس کے "سائز" کی پیمائش کرتی ہے۔
| تصور | تعریف | مثال |
|---------|------------|---------|
| محدود سیٹ | کارڈنلٹی کے طور پر ایک قدرتی نمبر ہے | |{a, b, c}| = 3 |
| بے شمار لامحدود | ℕ جیسا ہی کارڈنلٹی | ℤ، ℚ گنتی کے لحاظ سے لامحدود ہیں |
| بے شمار | ℕ سے بڑا | ℝ, P(ℕ), تمام افعال کا مجموعہ ℕ → {0,1} |
| کینٹر کا نظریہ | کسی بھی سیٹ کے لیے S, |P(S)| > |S| | |P(ℕ)| > |ℕ| |
**کینٹر کی ترچھی دلیل** ثابت کرتی ہے کہ ℝ بے شمار ہے: فرض کریں کہ آپ تمام اصلیت کو [0,1] میں درج کر سکتے ہیں، پھر ایک نیا اصلی بنائیں جو nویں درج شدہ حقیقی سے nویں اعشاریہ جگہ پر مختلف ہو — تضاد۔
### سیٹوں پر آپریشنز
| آپریشن | نوٹیشن | تعریف | پراپرٹی |
|------------|---------|------------|----------|
| یونین | A ∪ B | {x : x ∈ A یا x ∈ B} | تبادلاتی، ہم آہنگی |
| چوراہا | A ∩ B | {x : x ∈ A اور x ∈ B} | تبادلاتی، ہم آہنگی |
| فرق | A \ B | {x : x ∈ A اور x ∉ B} | تبدیل کرنے والا نہیں |
| ہم آہنگی فرق | A △ B | (A\B) ∪ (B\A) | تبادلاتی، ہم آہنگی |
| تکمیل | Aᶜ | U \ A (جہاں U یونیورسل سیٹ ہے) | (Aᶜ)ᶜ = A |
| کارٹیشین پروڈکٹ | A × B | {(a,b): a ∈ A, b ∈ B} | |A × B| = |A| · |B| |
**ڈی مورگن کے قوانین:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**شامل کرنے سے اخراج کا اصول** (محدود سیٹوں کے لیے):
|A₁ ∪ A₂ ∪ ... ∪ Aₙ | = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺¹|A₁ ∩ ... ∩ Aₙ|

## تعلقات
A **رشتہ** R سیٹ A اور B پر A × B کا سب سیٹ ہے۔ جب (a, b) ∈ R، ہم aRb لکھتے ہیں۔
### رشتوں کی اقسام
سیٹ A پر تعلق R میں یہ خصوصیات ہو سکتی ہیں:
| پراپرٹی | تعریف | مثال |
|------------|------------|---------|
| اضطراری | ∀a ∈ A: aRa | ≤ پر ℤ |
| غیر متزلزل | ∀a ∈ A: ¬(aRa) | < پر ℤ |
| ہم آہنگی | ∀a,b: aRb → bRa | = کسی بھی سیٹ پر |
| متضاد | ∀a,b: aRb ∧ bRa → a = b | ≤ پر ℤ |
| عبوری | ∀a,b,c: aRb ∧ bRc → aRc | <، ≤، = پر ℤ |
### مساوی تعلقات
ایک **مساوی تعلق** اضطراری، ہم آہنگی، اور عبوری ہے۔ یہ ایک سیٹ کو الگ الگ **مساوات کلاسوں** میں تقسیم کرتا ہے۔
**مثال:** ماڈیولر ریاضی۔ a ~ b iff a ≡ b (mod n) کی وضاحت کریں۔ مساوات کی کلاسیں [0]، [1]، ...، [n−1] ہیں، جو ℤ کو n کلاسز میں تقسیم کرتی ہیں۔
**کام شدہ مثال:** ℤ × ℤ پر، (a,b) ~ (c,d) iff a + d = b + c کی وضاحت کریں۔ یہ ایک مساوات کا رشتہ ہے۔ کلاس [(0,0)] = {(n,n): n ∈ ℤ}۔ کلاس [(1,0)] = {(n+1,n): n ∈ ℤ}۔ یہ تعمیر دراصل فطری اعداد سے عدد کو متعین کرتی ہے۔
### جزوی احکامات
ایک **جزوی ترتیب** اضطراری، متضاد، اور عبوری ہے۔ جزوی ترتیب کے ساتھ ایک سیٹ کو **جزوی ترتیب شدہ سیٹ (پوزیٹ)** کہا جاتا ہے۔
| تصور | تعریف | مثال |
|---------|------------|---------|
| پوسیٹ | (S, ≤) ≤ جزوی حکم کے ساتھ | (P(A)، ⊆) — شامل کرنے کے لحاظ سے ترتیب دیئے گئے ذیلی سیٹ |
| سلسلہ | مکمل طور پر ترتیب دیا ہوا سب سیٹ | P({a,b,c}) میں {∅, {a}, {a,b}} |
| اینٹی چین | ایک ذیلی سیٹ جہاں کوئی دو عناصر موازنہ نہیں ہوتے | {{a}، {b}} P({a,b}) میں |
| ہاسے ڈایاگرام | ایک پوزیٹ کی بصری نمائندگی | صرف رشتوں کو ڈھانپنے کے لیے کنارے کھینچیں |
| اپر باؤنڈ | ایک عنصر ≥ ایک ذیلی سیٹ میں ہر عنصر | sup({2,3}) = 6 انچ (ℤ, \|) (تقسیم) |
| لیسٹ اپر باؤنڈ (sup) | سب سے چھوٹی اوپری حد | sup({2,3}) in (ℕ, ≤) ہے 3 |
| عظیم ترین لوئر باؤنڈ (inf) | سب سے بڑا لوئر باؤنڈ | inf({4,6}) in (ℕ, \|) ہے 2 |

## افعال
A **فنکشن** f: A → B A کے ہر عنصر کو B کے بالکل ایک عنصر کو تفویض کرتا ہے۔
### افعال کی درجہ بندی
| قسم | تعریف | مثال |
|------|------------|---------|
| انجیکشن (ایک سے ایک) | f(a) = f(b) → a = b | f(x) = 2x از ℤ → ℤ |
| سرجیکٹیو (پر) | ∀b ∈ B، ∃a ∈ A: f(a) = b | f(x) = x mod 2 از ℤ → {0,1} |
| طنزیہ | انجیکشن اور تخمینہ دونوں | f(x) = x + 1 از ℤ → ℤ |
### اہم فنکشن کے تصورات
| تصور | تعریف | کیس استعمال کریں |
|---------|------------|---------|
| الٹا فنکشن | f⁻¹ موجود ہے iff f bijective ہے | خفیہ کردہ ڈیٹا کو ڈکرپٹ کرنا |
| ساخت | (g ∘ f)(x) = g(f(x)) | تبدیلیوں کی زنجیریں |
| شناختی فنکشن | id(x) = x | ساخت کے لیے غیر جانبدار عنصر |
| فکسڈ پوائنٹ | f(x) = x | تکراری تعریفیں، سیمنٹکس |
| ترتیب | ایک سیٹ سے بذات خود | ڈیٹا کو دوبارہ ترتیب دینا، شفلنگ |
### گنتی کے افعال
دیئے گئے محدود سیٹ |A| = m اور |B| = n:
| قسم | شمار |
|------|---------|
| تمام افعال A → B | nᵐ |
| انجیکشن کے افعال | n! / (n−m)! (اگر n ≥ m، ورنہ 0) |
| تخصیصی افعال | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ (شامل کرنے سے خارج) |
| مقصدی افعال | n! (جب m = n) |

## امتزاج
Combinatorics شمار کرنے، ترتیب دینے اور منتخب کرنے کی ریاضی ہے۔
### گنتی کے بنیادی اصول
| اصول | بیان | مثال |
|------------|------------|---------|
| رقم کا اصول | اگر A اور B متضاد ہیں، |A ∪ B| = |A| + |B| | پھل کا انتخاب: 3 سیب + 4 سنتری = 7 اختیارات |
| مصنوعات کے اصول | |A × B| = |A| · |B| | لباس: 3 شرٹس × 4 پینٹ = 12 کپڑے |
| Bijection اصول | اگر f: A → B ایک bijection ہے، |A| = |B| | بائنری تاروں کو گن کر ذیلی سیٹوں کو شمار کریں |
| تکمیل | |A| = |U| − |Aᶜ| | "کم از کم ایک" کو کل مائنس "کوئی نہیں" کے طور پر شمار کریں۔
### ترتیب اور امتزاج
| نوٹیشن | نام | فارمولہ | معنی |
|----------|------|---------|---------|
| C(n, k) یا (n k) | بائنومیئل گتانک | n! / (k!(n−k)!) | n سے k اشیاء کو منتخب کرنے کے طریقے (آرڈر سے کوئی فرق نہیں پڑتا) |
| P(n, k) | n | کے k-ترمیمات n! / (n−k)! | n سے k اشیاء کو ترتیب دینے کے طریقے ( آرڈر کے معاملات) |
| n! | فیکٹریل | n × (n−1) × ... × 1 | تمام n اشیاء کو ترتیب دینے کے طریقے |
| (n k) تکرار کے ساتھ | کثیر انتخاب | C(n+k−1, k) | دہرانے کی اجازت کے ساتھ n سے k کا انتخاب کریں |
**بائنومیل تھیوریم:**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**پاسکل کی شناخت:** C(n,k) = C(n−1,k−1) + C(n−1,k)
### کبوتر کے سوراخ کا اصول
**بنیادی شکل:** اگر n+1 اشیاء کو n خانوں میں رکھا جاتا ہے، تو کم از کم ایک باکس میں ≥ 2 آبجیکٹ ہوتے ہیں۔
**عام شکل:** اگر N اشیاء کو k خانوں میں رکھا جاتا ہے تو کم از کم ایک باکس میں ≥ ⌈N/k⌉ آبجیکٹ ہوتے ہیں۔
** کام کی مثالیں:**
1. کسی بھی 13 افراد میں سے، کم از کم 2 پیدائش کے مہینے میں شریک ہوتے ہیں۔ (13 افراد، 12 ماہ → کبوتر۔)
2. دکھائیں کہ کسی بھی 5 عدد میں، 3 موجود ہیں جن کا مجموعہ 3 سے تقسیم کیا جا سکتا ہے۔
   - باقیات موڈ 3 پر غور کریں: {0، 1، 2}۔ 5 انٹیجرز اور 3 ریزیڈیو کلاسز کے ساتھ، عام کبوتر ہول کے ذریعے، کم از کم ⌈5/3⌉ = 2 ایک باقیات کا اشتراک کریں۔
   - اگر 3 باقیات کا اشتراک کریں r: ان کا مجموعہ ≡ 3r ≡ 0 (mod 3)۔
   - اگر 2 باقیات 0 کا اشتراک کریں اور 2 باقیات 1 کا اشتراک کریں: ہر جوڑے میں سے ایک کو منتخب کریں اور ایک باقیات -0 عنصر → sum ≡ 0 (mod 3)۔
. (اگر ہر n-bit سٹرنگ کو < n بٹس پر کمپریس کیا جاتا ہے، تو آپ 2ⁿ سٹرنگز کو 2ⁿ سے کم کمپریسڈ سٹرنگز میں نقشہ بنائیں گے — انجیکشن کی خلاف ورزی کر رہے ہیں۔)
### کاتالان نمبرز
نواں **کیٹلان نمبر** Cₙ = C(2n, n) / (n+1) شمار:
| ساخت | مثال |
|------------|---------|
| درست قوسین کی ترتیب | ()()، ()) برائے n = 2 |
| n اندرونی نوڈس کے ساتھ بائنری درخت | n = 2 کے لیے 2 درخت |
| راستے ترچھے کو پار نہیں کرتے | (0,0) سے (n,n) تک گرڈ کے راستے y = x | کے نیچے رہتے ہیں۔
| کثیرالاضلاع کی تکون | ایک (n+2)-گون کو مثلث میں تقسیم کرنے کے طریقے |
پہلے چند: C₀ = 1، C₁ = 1، C₂ = 2، C₃ = 5، C₄ = 14، C₅ = 42۔
تکرار: Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## تکرار تعلقات
ایک **تکرار کا رشتہ** ایک ترتیب کی ہر اصطلاح کو سابقہ ​​اصطلاحات کے فعل کے طور پر متعین کرتا ہے۔
### اقسام اور حل
| قسم | فارم | حل کا طریقہ |
|------|------|-----------------|
| لکیری یکساں (مسلسل coeff.) | aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ | خصوصیت کی مساوات |
| لکیری غیر یکساں | aₙ = c₁aₙ₋₁ + ... + f(n) | خاص حل + یکساں حل |
| تقسیم کرو اور فتح کرو | T(n) = aT(n/b) + f(n) | ماسٹر تھیوریم |
### خصوصیت کی مساوات کا طریقہ
aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ کے لیے، خصوصیت کی مساوات بنائیں:
r² − c₁r − c₂ = 0
| کیس | جڑیں | عمومی حل |
|------|---------|------|
| دو الگ الگ اصلی جڑیں r₁, r₂ | r₁ ≠ r₂ | aₙ = A·r₁ⁿ + B·r₂ⁿ |
| بار بار جڑ r | r₁ = r₂ = r | aₙ = (A + Bn)·rⁿ |
| پیچیدہ جڑیں α ± βi | قطبی میں تبدیل کریں: r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**کام کی مثال:** فبونیکی ترتیب Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0، F₁ = 1۔
- خصوصیت کی مساوات: r² − r − 1 = 0
- جڑیں: r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618, ψ = (1−√5)/2 ≈ −0.618
- عمومی حل: Fₙ = A·φⁿ + B·ψⁿ
- ابتدائی حالات سے: A = 1/√5، B = −1/√5
- **بند شکل:** Fₙ = (φⁿ − ψⁿ) / √5 (بائنٹ کا فارمولا)
### ماسٹر تھیوریم
فارم کی تکرار کے لیے T(n) = aT(n/b) + f(n) جہاں a ≥ 1, b > 1:
چلو c = log_b(a)۔
| کیس | حالت | حل |
|------|------------|---------|
| 1 | f(n) = O(nᵈ) جہاں d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c، اور af(n/b) ≤ kf(n) کچھ k کے لیے < 1 | T(n) = Θ(nᵈ) |
**مثالیں:**
- ترتیب کو ضم کریں: T(n) = 2T(n/2) + O(n)۔ یہاں a=2، b=2، c=1، f(n)=n=Θ(n¹)۔ کیس 2: T(n) = Θ(n log n)۔
- بائنری تلاش: T(n) = T(n/2) + O(1)۔ یہاں a=1، b=2، c=0، f(n)=1=Θ(n⁰)۔ کیس 2: T(n) = Θ(log n)۔

## افعال پیدا کرنا
ایک **جنریٹنگ فنکشن** ایک ترتیب (aₙ) کو ایک رسمی پاور سیریز کے گتانک کے طور پر انکوڈ کرتا ہے۔
### اقسام
| قسم | فارم | کیس استعمال کریں |
|------|------|---------|
| عام (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ | بغیر لیبل والے ڈھانچے، کمپوزیشن |
| ایکسپونینشل (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n! | لیبل شدہ ڈھانچے، ترتیب |
### کامن جنریٹنگ فنکشنز
| ترتیب aₙ | OGF G(x) |
|---------------|------------|
| 1، 1، 1، 1، ... | 1/(1−x) |
| 1، 2، 3، 4، ... | 1/(1−x)² |
| 1، r، r²، r³، ... | 1/(1−rx) |
| C(n,k) فکسڈ k کے لیے | xᵏ/(1−x)ᵏ⁺¹ |
| فبونیکی Fₙ | x/(1−x−x²) |
| کاتالان Cₙ | (1 − √(1−4x)) / (2x) |
### تکرار کو حل کرنے کے لیے جنریٹنگ فنکشنز کا استعمال
**کام کی مثال:** aₙ = 3aₙ₋₁ − 2aₙ₋₂، a₀ = 1، a₁ = 3 حل کریں۔
1. چلیں G(x) = Σ aₙxⁿ۔
2. تکرار سے: G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. متبادل: G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. جزوی کسر: G(x) = 2/(1−2x) − 1/(1−x)
7. ایکسٹریکٹ گتانک: aₙ = 2·2ⁿ − 1 = 2ⁿ⁺¹ −1
**تصدیق:** a₀ = 2−1 = 1، a₁ = 4−1 = 3، a₂ = 8−1 = 7. چیک کریں: 3(3) −2(1) = 7۔

## بولین الجبرا اور تجویزی منطق
بولین الجبرا دو سچائی اقدار کا الجبرا ہے: **True (1)** اور **False (0)**۔ یہ ڈیجیٹل سرکٹس، ڈیٹا بیس کے سوالات، اور پروگرامنگ کنڈیشنلز کی ریاضیاتی بنیاد ہے۔
### آپریشنز اور قوانین
| آپریشن | علامت | معنی | سچائی کی میز |
|------------|---------|---------|-------------|
| اور | p ∧ q | سچ تب ہی جب دونوں سچے ہوں | T∧T=T، T∧F=F، F∧T=F، F∧F=F |
| یا | p ∨ q | سچ ہے جب کم از کم ایک سچ ہے | T∨T=T، T∨F=T، F∨T=T، F∨F=F |
| نہیں | ¬p | نفی | ¬T=F، ¬F=T |
| XOR | p ⊕ q | سچ ہے جب بالکل ایک سچ ہے | T⊕T=F، T⊕F=T، F⊕T=T، F⊕F=F |
| IMPLIES | p → q | غلط صرف اس صورت میں جب p=T اور q=F | T→T=T، T→F=F، F→T=T، F→F=T |
| دو مشروط | p ↔ q | درست ہے جب دونوں کی ایک ہی قدر ہو | T↔T=T، T↔F=F، F↔T=F، F↔F=T |
### کلیدی بولین شناخت
| قانون | فارمولہ |
|------|---------|
| Commutativity | p ∧ q = q ∧ p; p ∨ q = q ∨ p |
| ایسوسی ایٹیوٹی | (p ∧ q) ∧ r = p ∧ (q ∧ r) |
| تقسیم کاری | p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
| ڈی مورگن کے قوانین | ¬(p ∧ q) = ¬p ∨ ¬q; ¬(p ∨ q) = ¬p ∧ ¬q |
| دوہری نفی | ¬(¬p) = p |
| بے حسی | p ∧ p = p؛ p ∨ p = p |
| جذب | p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
| متضاد | (p → q) ≡ (¬q → ¬p) |
### عام شکلیں۔
| فارم | ساخت | کیس استعمال کریں |
|------|------------|---------|
| کنجیکٹیو نارمل فارم (CNF) | ORs کا AND: (A∨B) ∧ (C∨D) | SAT حل کرنے والے، ریزولیوشن تھیوریم ثابت کرنے والے |
| غیر منقولہ نارمل فارم (DNF) | OR کا ANDs: (A∧B) ∨ (C∧D) | سرکٹ ڈیزائن، اصول پر مبنی نظام |
**CNF میں تبدیل:** ڈی مورگن کے قوانین کو لاگو کریں، تقسیم یا اس سے زیادہ اور، دوہری نفی کو ختم کریں۔

## ماڈیولر ریاضی اور موافقت
"تقسیم کے بعد باقی ماندہ" کے آپریشن کے تحت ماڈیولر ریاضی کا مطالعہ انٹیجرز۔ یہ خفیہ نگاری، ہیشنگ، اور نمبر تھیوری کے لیے ضروری ہے۔
### بنیادی تعریفیں۔
| تصور | نوٹیشن | تعریف |
|---------|---------|------------|
| ہم آہنگی | a ≡ b (mod n) | n تقسیم کرتا ہے (a − b) |
| باقیات کی کلاس | [a]ₙ | سیٹ {a + kn : k ∈ ℤ} |
| ماڈیولر الٹا | a⁻¹ mod n | قدر x ایسی کہ ax ≡ 1 (mod n) |
| Euler's totient | φ(n) | {1,...,n} coprime to n | میں عدد کی تعداد
### کلیدی خصوصیات
| پراپرٹی | بیان |
|------------|------------|
| اضافہ | اگر a ≡ b اور c ≡ d (mod n) تو a+c ≡ b+d (mod n) |
| ضرب | اگر a ≡ b اور c ≡ d (mod n)، تو ac ≡ bd (mod n) |
| فرمیٹ کا چھوٹا نظریہ | اگر p اعظم ہے اور gcd(a,p) = 1، تو aᵖ⁻¹ ≡ 1 (mod p) |
| یولر کا نظریہ | اگر gcd(a,n) = 1، تو a^φ(n) ≡ 1 (mod n) |
| چینی باقی ماندہ تھیوریم | اگر gcd(m,n) = 1، سسٹم x ≡ a (mod m)، x ≡ b (mod n) کا ایک منفرد حل ہے mod mn |
### کمپیوٹنگ یولر کا ٹوٹینٹ
برائے n = p₁^a₁ · p₂^a₂ · ... · pₖ^aₖ (پرائم فیکٹرائزیشن):
φ(n) = n · (1 − 1/p₁) · (1 − 1/p₂) · ... · (1 − 1/pₖ)
**مثال:** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4۔ درحقیقت، {1, 5, 7, 11} 12 کے برابر ہیں۔
### درخواست: RSA کرپٹوگرافی (جائزہ)
1. بڑے پرائمز p، q کا انتخاب کریں۔ کمپیوٹ n = pq، φ(n) = (p−1)(q−1)۔
2. e کو اس طرح کا انتخاب کریں کہ gcd(e, φ(n)) = 1 (عوامی ایکسپوننٹ)۔
3. کمپیوٹ d ≡ e⁻¹ (mod φ(n)) (پرائیویٹ ایکسپوننٹ)۔
4. خفیہ کاری: c = mᵉ mod n. ڈیکرپٹ: m = cᵈ mod n.
5. سیکورٹی p اور q کو تلاش کرنے کے لیے n کی فیکٹرنگ کی مشکل پر انحصار کرتی ہے۔

## ریاضی کی شمولیت
**ریاضی شامل کرنا** تمام قدرتی اعداد کے بارے میں بیانات کے لیے بنیادی ثبوت کی تکنیک ہے۔
### شامل کرنے کے ذریعہ ثبوت کا ڈھانچہ
1. **بیس کیس:** بیان کو n = 0 (یا n = 1) کے لیے ثابت کریں۔
2. **آمدنی مرحلہ:** فرض کریں کہ بیان n = k (آنے والا مفروضہ) کے لیے رکھتا ہے، پھر اسے n = k + 1 کے لیے ثابت کریں۔
### متغیرات
| متغیر | کب استعمال کریں |
|---------|---------------|
| سادہ انڈکشن | ثابت کریں P(k) → P(k+1) |
| مضبوط انڈکشن | P(k+1) | ثابت کرنے کے لیے P(0)، P(1)، ...، P(k) فرض کریں۔
| ساختی انڈکشن | بار بار متعین ڈھانچے (درخت، فارمولے) کی خصوصیات ثابت کریں۔
| ٹرانسفینائٹ انڈکشن | انڈکشن کو ℕ سے آگے اچھی طرح سے ترتیب والے سیٹوں تک بڑھائیں۔
** کام کی مثال (مضبوط انڈکشن):** ثابت کریں کہ ہر عدد n ≥ 2 کو پرائمز کی پیداوار کے طور پر لکھا جا سکتا ہے۔
- بنیاد: n = 2 اعظم ہے، لہذا یہ پرائمز (خود) کی پیداوار ہے۔
- اشتعال انگیز مرحلہ: 2 سے k تک کے تمام عدد کے لیے درست فرض کریں۔ k+1 پر غور کریں۔
  - اگر k+1 پرائم ہے تو ہو گیا۔
  - اگر k+1 جامع ہے، k+1 = ab جہاں 2 ≤ a، b ≤ k۔ دلکش مفروضے کے مطابق، a اور b دونوں پرائمز کی پیداوار ہیں، لہذا k+1 پرائمز کی پیداوار ہے۔
