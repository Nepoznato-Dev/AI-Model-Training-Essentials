# گراف تھیوری
A **گراف** ایک ریاضیاتی ڈھانچہ ہے جو کناروں (لنک) سے جڑے ہوئے عمودی (نوڈس) پر مشتمل ہے۔ گراف ماڈل تعلقات: سوشل نیٹ ورکس، روڈ میپس، نیورل نیٹ ورکس، انحصار، کمیونیکیشن چینلز۔ گراف تھیوری — ان ڈھانچے کا مطالعہ — الگورتھم اور تھیورمز فراہم کرتا ہے جو کمپیوٹر سائنس، آپریشنز ریسرچ، اور ڈیٹا سائنس میں مرکزی حیثیت رکھتے ہیں۔
---

## بنیادی تصورات
### تعریفیں
| مدت | تعریف | نوٹیشن |
|------|------------|---------|
| **گراف** | ایک جوڑا G = (V, E) عمودی اور کناروں کا | جی |
| **ورٹیکس (نوڈ)** | V کا ایک عنصر | v، u، w |
| **کنارا** | دو چوٹیوں کے درمیان ایک کنکشن | e = (u, v) یا {u, v} |
| **آرڈر** | چوٹیوں کی تعداد | \|V\| = ن |
| **سائز** | کناروں کی تعداد | \|E\| = m |
| **ڈگری** | کناروں کی تعداد ایک چوٹی تک واقعہ | deg(v) |
| **راستہ** | کناروں سے جڑے ہوئے الگ الگ چوٹیوں کی ترتیب | v₁, v₂, ..., vₖ |
| **سائیکل** | ایک راستہ جو ایک ہی چوٹی پر شروع اور ختم ہوتا ہے | v₁ → v₂ → ... → vₖ → v₁ |
| **منسلک** | عمودی کے ہر جوڑے کے درمیان ایک راستہ موجود ہے | - |
| **جزو** | زیادہ سے زیادہ منسلک ذیلی گراف | - |
| **سب گراف** | V اور E | کے ذیلی سیٹ سے بنا ایک گراف H ⊆ G |
### گراف کی اقسام
| قسم | تفصیل | مثال |
|------|---------------|---------|
| **غیر ہدایت شدہ** | کناروں کی کوئی سمت نہیں ہوتی | دوستی نیٹ ورک |
| **ہدایت کردہ (ڈیگراف)** | کناروں کی سمت ہوتی ہے (آرکس) | ویب صفحہ کے لنکس |
| **وزن شدہ** | کناروں میں عددی اقدار ہوتی ہیں | سڑک کے فاصلے |
| **بے ​​وزن** | تمام کنارے برابر ہیں | سماجی رابطے |
| **سادہ** | کوئی لوپس نہیں، متعدد کنارے نہیں | زیادہ تر درسی کتاب کے گرافس |
| **ملٹی گراف** | ایک ہی چوٹیوں کے درمیان متعدد کناروں کی اجازت ہے | پرواز کے راستے (شہروں کے درمیان متعدد پروازیں) |
| **مکمل** | عمودی کا ہر جوڑا جڑا ہوا ہے | Kₙ کے n(n−1)/2 کنارے ہیں |
| **دو طرفہ** | عمودی دو گروہوں میں تقسیم؛ کنارے صرف کراس گروپس | یوزر آئٹم کی سفارشی میٹرکس |
| **پلانر** | کنارے کراسنگ کے بغیر تیار کیا جا سکتا ہے | سرکٹ بورڈ لے آؤٹ |
| **درخت** | منسلک، تیزابی گراف | فیصلے کے درخت، فائل سسٹم |
| **DAG** | ہدایت کردہ، کوئی ہدایت شدہ سائیکل نہیں | ٹاسک شیڈولنگ، انحصار گرافس |
### مصافحہ کرنے والی لیما۔
تمام عمودی ڈگریوں کا مجموعہ کناروں کی تعداد کے دو گنا کے برابر ہے:
Σᵥ deg(v) = 2|E|
**تعاون:** ہر گراف میں طاق ڈگری کے عمودی عمودی نمبر ہوتے ہیں۔
**مثال:** 10 لوگوں کی پارٹی میں جہاں ہر کوئی بالکل 3 دوسروں کے ساتھ مصافحہ کرتا ہے: Σ deg = 30، تو |E| = کل 15 مصافحہ۔

## گراف کی نمائندگی
آپ کسی گراف کو میموری میں کیسے محفوظ کرتے ہیں اس سے آپ اس پر چلنے والے ہر الگورتھم کی کارکردگی کا تعین کرتے ہیں۔
| نمائندگی | خلائی | کنارے تلاش | پڑوسیوں کی تکرار | کے لیے بہترین |
|----------------|---------|------------|
| **ملحقہ میٹرکس** | O(n²) | O(1) | O(n) | گھنے گراف، فوری کنارے ٹیسٹ |
| **ملحقہ فہرست** | O(n + m) | O(deg(v)) | O(deg(v)) | ویرل گرافس، سب سے زیادہ حقیقی دنیا کے نیٹ ورکس |
| **کنارے کی فہرست** | O(m) | O(m) | O(m) | سادہ الگورتھم، کرسکل کا MST |
| **واقعات میٹرکس** | O(n · m) | O(m) | O(m) | خصوصی الگورتھم |
### ملحقہ میٹرکس
ایک n × n میٹرکس A جہاں A[i][j] = 1 اگر کنارہ (i,j) موجود ہے، ورنہ 0۔ وزن والے گرافس کے لیے، A[i][j] = وزن۔
**پراپرٹیز:**
- غیر ہدایت شدہ گرافس کے لیے ہم آہنگ
- Aᵏ[i][j] = i سے j تک کی لمبائی کے پیدل چلنے کی تعداد
- A کی Eigenvalues ساختی خصوصیات کو ظاہر کرتی ہیں (دیکھیں سپیکٹرل گراف تھیوری)
### ملحقہ فہرست
ایک صف (یا ہیش میپ) جہاں ہر ورٹیکس وی اپنے پڑوسیوں کی فہرست اسٹور کرتا ہے۔
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

یہ حقیقی دنیا کے گراف کے لیے سب سے عام نمائندگی ہے، جو عام طور پر ویرل ہوتے ہیں (m ≪ n²)۔

## درخت
ایک **درخت** ایک منسلک، تیزابی غیر ہدایت شدہ گراف ہے۔ ایک **جنگل** درختوں کا ایک منقطع اتحاد ہے۔
### درختوں کی خصوصیات
این عمودی والے درخت کے لیے:
- اس کے بالکل n − 1 کنارے ہیں۔
- کسی بھی دو چوٹیوں کے درمیان بالکل ایک راستہ ہے۔
- کسی بھی کنارے کو ہٹانے سے اس کا رابطہ منقطع ہو جاتا ہے۔
- کسی بھی کنارے کو شامل کرنے سے بالکل ایک سائیکل بنتا ہے۔
### درختوں کی اقسام
| قسم | تفصیل | درخواست |
|------|---------------|------------|
| **جڑ دار درخت** | جڑ کے طور پر نامزد ایک چوٹی | فائل سسٹم، تنظیمی چارٹ |
| **بائنری درخت** | ہر نوڈ میں زیادہ سے زیادہ 2 بچے ہوتے ہیں۔ BSTs، اظہار تجزیہ، فیصلے کے درخت |
| **متوازن درخت** | اونچائی O(log n) ہے | AVL درخت، سرخ سیاہ درخت (ڈیٹا بیس) |
| ** پھیلا ہوا درخت** | ذیلی گراف جس میں تمام خطوط شامل ہیں اور یہ ایک درخت ہے | نیٹ ورک ڈیزائن، لگ بھگ الگورتھم |
| **کم سے کم پھیلا ہوا درخت** | کم از کم کل کنارے کے وزن کے ساتھ پھیلا ہوا درخت | نیٹ ورک ڈیزائن، کلسٹرنگ |
| **ستارہ گراف** | ایک مرکزی نوڈ تمام دوسرے سے منسلک | حب اور اسپاک نیٹ ورکس |
### بائنری ٹری پراپرٹیز
| پراپرٹی | فارمولہ |
|------------|---------|
| زیادہ سے زیادہ نوڈس کی گہرائی d | 2ᵈ |
| اونچائی کے درخت میں زیادہ سے زیادہ نوڈس h | 2ʰ⁺¹ −1 |
| n نوڈس کے لیے کم از کم اونچائی | ⌊log₂(n)⌋ |
| مکمل بائنری درخت میں لیف نوڈس | اندرونی نوڈس + 1 |
### درختوں کی آمدورفت
| ٹراورسل | آرڈر | کیس استعمال کریں |
|------------|-------|------------|
| **پیشگی آرڈر** | جڑ → بائیں → دائیں | ایک درخت کو کاپی کرنا، سابقہ ​​اظہار |
| **ان آرڈر** | بائیں → جڑ → دائیں | BST سے ترتیب شدہ آؤٹ پٹ |
| **پوسٹ آرڈر** | بائیں → دائیں → جڑ | ایک درخت کو حذف کرنا، پوسٹ فکس اظہار |
| **لیول آرڈر (BFS)** | سطح بہ سطح، بائیں سے دائیں | بغیر وزن کے درخت میں سب سے چھوٹا راستہ |

## گراف ٹراورسلز
ٹراورسل الگورتھم ہر قابل رسائی ورٹیکس کو منظم طریقے سے دیکھتے ہیں۔
### چوڑائی-پہلی تلاش (BFS)
**قطار** کا استعمال کرتے ہوئے، پرت کے لحاظ سے عمودی پرت کو دریافت کرتا ہے۔
| پراپرٹی | قدر |
|------------|-------|
| ڈیٹا ڈھانچہ | قطار (FIFO) |
| وقت کی پیچیدگی | O(V + E) |
| خلائی پیچیدگی | O(V) |
| مختصر ترین راستہ ڈھونڈتا ہے؟ | ہاں (غیر وزنی گراف) |
| مکمل؟ | ہاں (تمام قابل رسائی چوٹیوں کو دریافت کرتا ہے) |
**الگورتھم:**
1. سورس ورٹیکس s سے شروع کریں۔ مارک نے دورہ کیا۔ قطار s.
2. جبکہ قطار خالی نہیں ہے: dequeue vertex u. u کے ہر غیر دیکھے پڑوسی v کے لیے: نشان v ملاحظہ کیا گیا، enqueue v.
**درخواستیں:** بغیر وزن والے گرافس، منسلک اجزاء، دو طرفہ جانچ، ویب کرالنگ میں مختصر ترین راستہ۔
### گہرائی سے پہلی تلاش (DFS)
**اسٹیک** (یا تکرار) کا استعمال کرتے ہوئے، بیک ٹریکنگ سے پہلے ممکنہ حد تک گہرائی میں دریافت کرتا ہے۔
| پراپرٹی | قدر |
|------------|-------|
| ڈیٹا ڈھانچہ | اسٹیک (LIFO) / تکرار |
| وقت کی پیچیدگی | O(V + E) |
| خلائی پیچیدگی | O(V) |
| مختصر ترین راستہ ڈھونڈتا ہے؟ | نہیں |
| مکمل؟ | ہاں (محدود گراف کے لیے) |
**الگورتھم:**
1. vertex s سے شروع کریں۔ مارک نے دورہ کیا۔
2. s کے ہر غیر دیکھے پڑوسی کے لیے: v سے بار بار DFS۔
**DFS کناروں کو اس میں درجہ بندی کرتا ہے:**
- **درخت کے کنارے:** DFS درخت کا حصہ
- **پچھلے کنارے:** ایک چوٹی کو اس کے آباؤ اجداد سے جوڑیں (سائیکل کی نشاندہی کریں)
- **فارورڈ کناروں:** ایک چوٹی کو اس کی نسل سے جوڑیں۔
- **کراس ایجز:** مختلف شاخوں میں چوٹیوں کو جوڑیں۔
** ایپلی کیشنز:** ٹاپولوجیکل چھانٹنا، سائیکل کا پتہ لگانا، مضبوطی سے جڑے ہوئے اجزاء، حل کرنے والی میزز۔
### BFS بمقابلہ DFS موازنہ
| معیار | BFS | ڈی ایف ایس |
|------------|------|------|
| حکمت عملی | چوڑا پھر گہرا | گہرا پھر چوڑا |
| یادداشت | ہائر (اسٹور فرنٹیئر) | لوئر (اسٹور کا راستہ) |
| سب سے چھوٹا راستہ (بغیر وزن والا) | ضمانت | ضمانت نہیں |
| اس وقت استعمال کریں جب حل شروع ہونے کے قریب ہو۔ بہتر | بدتر |
| اس وقت استعمال کریں جب گراف بہت گہرا ہو۔ بدتر | بہتر |
| ٹاپولوجیکل چھانٹنا | کاہن کا الگورتھم مختلف قسم | معیاری نقطہ نظر |

## مختصر ترین راستہ الگورتھم
عمودی خطوط کے درمیان مختصر ترین راستہ تلاش کرنا عملی طور پر گراف کے سب سے اہم مسائل میں سے ایک ہے۔
### ڈجکسٹرا کا الگورتھم
**غیر منفی** کناروں کے وزن کے ساتھ گراف میں واحد ذریعہ سے دیگر تمام چوٹیوں تک مختصر ترین راستے تلاش کرتا ہے۔
| پراپرٹی | قدر |
|------------|-------|
| کنارے کا وزن | ≥ 0 | ہونا ضروری ہے۔
| وقت (بائنری ہیپ) | O((V + E) لاگ V) |
| وقت (فبونیکی ہیپ) | O(E + V لاگ V) |
| لالچی۔ | جی ہاں |
| منفی وزن کو سنبھالتا ہے؟ | نہیں |
**الگورتھم:**
1. شروع کریں dist[s] = 0، dist[v] = ∞ تمام v ≠ s کے لیے۔ ترجیحی قطار Q تمام عمودی خطوط کے ساتھ۔
2. جبکہ Q خالی نہیں ہے: کم از کم ڈسٹ کے ساتھ ورٹیکس u کو نکالیں۔ U کے ہر پڑوسی کے لیے کنارے کے وزن کے ساتھ w: اگر dist[u] + w < dist[v]، update dist[v] = dist[u] + w۔
**کام کی مثال:**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### بیل مین فورڈ الگورتھم
**منفی** کنارے کے وزن کو سنبھالتا ہے اور منفی سائیکلوں کا پتہ لگاتا ہے۔
| پراپرٹی | قدر |
|------------|-------|
| کنارے کا وزن | کوئی بھی (منفی چکروں کا پتہ لگاتا ہے) |
| وقت کی پیچیدگی | O(V · E) |
| خلائی پیچیدگی | O(V) |
| منفی سائیکلوں کو ہینڈل کرتا ہے؟ | ہاں (پتہ لگاتا ہے اور رپورٹ کرتا ہے) |
**الگورتھم:**
1. شروع کریں dist[s] = 0، dist[v] = ∞ تمام v ≠ s کے لیے۔
2. V − 1 بار دہرائیں: وزن کے ساتھ ہر کنارے (u, v) کے لیے: اگر dist[u] + w < dist[v]، dist[v] کو اپ ڈیٹ کریں۔
3. منفی سائیکلوں کی جانچ کریں: اگر کوئی کنارے اب بھی آرام دہ ہو سکتا ہے، تو ایک منفی سائیکل موجود ہے۔
### Floyd-Warshall الگورتھم
عمودی **تمام جوڑوں** کے درمیان مختصر ترین راستے تلاش کرتا ہے۔
| پراپرٹی | قدر |
|------------|-------|
| وقت کی پیچیدگی | O(V³) |
| خلائی پیچیدگی | O(V²) |
| منفی وزن کو سنبھالتا ہے؟ | ہاں (لیکن منفی چکر نہیں) |
| نقطہ نظر | متحرک پروگرامنگ |
**تکرار:** dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) ہر انٹرمیڈیٹ ورٹیکس k کے لیے۔
### الگورتھم سلیکشن گائیڈ
| منظر نامہ | الگورتھم |
|------------|------------|
| واحد ذریعہ، غیر منفی وزن | Dijkstra |
| واحد ذریعہ، منفی وزن ممکن | بیل مین فورڈ |
| تمام جوڑے، گھنے گراف | Floyd-Warshall |
| تمام جوڑے، ویرل گراف | ہر ایک چوٹی سے Dijkstra چلائیں |
| غیر وزنی گراف | BFS |
| DAG (کوئی سائیکل نہیں) | ٹاپولوجیکل ترتیب + نرمی |
| A* (ہورسٹک گائیڈڈ) | A* تلاش (اچھی ہورسٹک کے ساتھ پاتھ فائنڈنگ کے لیے) |

## کم سے کم پھیلے ہوئے درخت
ایک **کم سے کم پھیلا ہوا درخت (MST)** تمام چوٹیوں کو کم از کم کل کنارے کے وزن کے ساتھ جوڑتا ہے۔
### پراپرٹیز
- ایک MST کے بالکل n − 1 کنارے ہوتے ہیں (n چوٹیوں کے لیے)
- اگر گراف منسلک ہے تو ایک MST موجود ہے۔
- مختلف کنارے کے وزن والے گراف میں ایک منفرد MST ہوتا ہے۔
- MST **کٹ پراپرٹی** کو مطمئن کرتا ہے: کسی بھی کٹ کو عبور کرنے والے کم از کم وزن والے کنارے کا تعلق MST سے ہے
- MST **سائیکل کی خاصیت** کو مطمئن کرتا ہے: کسی بھی سائیکل میں زیادہ سے زیادہ وزن والے کنارے کا تعلق MST سے نہیں ہوتا ہے۔
### کرسکل کا الگورتھم
| پراپرٹی | قدر |
|------------|-------|
| حکمت عملی | لالچی - وزن کی ترتیب میں کناروں کو شامل کریں |
| ڈیٹا ڈھانچہ | Disjoint-set (یونین کی تلاش) |
| وقت کی پیچیدگی | O(E log E) |
| کے لیے بہترین | ویرل گرافس |
**الگورتھم:**
1. تمام کناروں کو وزن کے لحاظ سے ترتیب دیں۔
2. ہر کنارے کے لیے (ترتیب میں): اگر اسے شامل کرنے سے کوئی سائیکل نہیں بنتا ہے (یونین فائنڈ کے ساتھ چیک کریں)، اسے MST میں شامل کریں۔
3. رکیں جب n − 1 کناروں کا انتخاب کیا جائے۔
### پرائمز الگورتھم
| پراپرٹی | قدر |
|------------|-------|
| حکمت عملی | لالچی - ایک ابتدائی چوٹی سے درخت اگائیں |
| ڈیٹا ڈھانچہ | ترجیحی قطار (منٹ ہیپ) |
| وقت کی پیچیدگی | O(E log V) بائنری ہیپ کے ساتھ |
| کے لیے بہترین | گھنے گرافس |
**الگورتھم:**
1. کسی بھی چوٹی سے شروع کریں۔ اسے MST کے حصے کے طور پر نشان زد کریں۔
2. MST میں ایک چوٹی کو جوڑنے والے کم از کم وزن والے کنارے کو اس کے باہر کی چوٹی سے بار بار شامل کریں۔
3. تمام چوٹیوں کو شامل ہونے پر رکیں۔
### MST ایپلی کیشنز
| درخواست | MST کس طرح مدد کرتا ہے |
|---------------|---------------|
| نیٹ ورک ڈیزائن | تمام مقامات کو جوڑنے کے لیے کم از کم کیبل/پائپ لگائیں۔
| جھرمٹ | k کلسٹرز حاصل کرنے کے لیے k − 1 طویل ترین MST کناروں کو ہٹا دیں۔
| لگ بھگ الگورتھم | میٹرک TSP کے لیے 2-تقریبا |
| تصویر کی تقسیم | رنگ کی مماثلت کے MST کے حساب سے پکسلز کو گروپ کریں۔
| خصوصیت کا خاتمہ | ارتباط گراف کے MST کا استعمال کرتے ہوئے بے کار خصوصیات کو ہٹا دیں۔

## نیٹ ورک فلو
نیٹ ورک کے بہاؤ کے مسائل نظام کے ذریعے وسائل کی نقل و حرکت کا نمونہ بناتے ہیں۔
### فلو نیٹ ورک کی تعریف
ایک **فلو نیٹ ورک** ایک ڈائریکٹڈ گراف ہے جس کے ساتھ:
- A **ذریعہ** ورٹیکس s (بہاؤ پیدا کرتا ہے)
- A **سنک** ورٹیکس ٹی (بہاؤ استعمال کرتا ہے)
- **صلاحیت** c(u,v) ≥ 0 ہر کنارے پر
- **بہاؤ** f(u,v) اطمینان بخش:
  - **صلاحیت کی پابندی:** 0 ≤ f(u,v) ≤ c(u,v)
  - **بہاؤ کا تحفظ:** بہاؤ میں = ہر چوٹی پر s اور t کے علاوہ بہاؤ
### زیادہ سے زیادہ بہاؤ کا مسئلہ
s سے t تک زیادہ سے زیادہ کل بہاؤ تلاش کریں۔
**فورڈ فلکرسن طریقہ:**
1. جب کہ بقایا گراف میں s سے t تک ایک بڑھانے والا راستہ موجود ہے:
2. راستے میں رکاوٹ کی گنجائش تلاش کریں۔
3. رکاوٹ کی رقم سے راستے میں بہاؤ میں اضافہ کریں۔
4. بقایا صلاحیتوں کو اپ ڈیٹ کریں۔
| الگورتھم | وقت کی پیچیدگی | نوٹس |
|------------|----------------|---------|
| Ford-Fulkerson (DFS) | O(m · f*) جہاں f* زیادہ سے زیادہ بہاؤ ہے | غیر معقول صلاحیتوں کے ساتھ ختم نہیں ہو سکتا |
| ایڈمنڈز کارپ (BFS) | O(V · E²) | ہمیشہ ختم کرتا ہے، سب سے چھوٹا بڑھانے والا راستہ چنتا ہے |
| ڈینک کا الگورتھم | O(V² · E) | مسدود بہاؤ کا استعمال کرتا ہے؛ O(V^(1/2) · E) یونٹ کی صلاحیتوں کے لیے |
### میکس فلو من کٹ تھیوریم
**زیادہ سے زیادہ بہاؤ** s سے t تک ** کم از کم کٹ** کی گنجائش s کو t سے الگ کرنے کے برابر ہے۔
A **کٹ** (S, T) پارٹیشنز کو S (s پر مشتمل) اور T (t پر مشتمل) میں تقسیم کرتا ہے۔ کٹ کی گنجائش S سے T تک کناروں کی صلاحیتوں کا مجموعہ ہے۔
**زیادہ سے زیادہ بہاؤ کی درخواستیں:**
- دو طرفہ مماثلت (کارکنوں کو ملازمتیں تفویض کریں)
- تصویری تقسیم (پس منظر سے الگ پیش منظر)
- بیس بال کا خاتمہ (کیا ٹیم X اب بھی جیت سکتی ہے؟)
- نیٹ ورک کی وشوسنییتا (زیادہ سے زیادہ ڈیٹا تھرو پٹ)
### میکس فلو کے ذریعے دو طرفہ ملاپ
ایک دو طرفہ گراف دیا گیا G = (L ∪ R, E):
1. L میں تمام چوٹیوں پر کناروں کے ساتھ ماخذ s شامل کریں (صلاحیت 1)
2. R میں تمام چوٹیوں سے کناروں کے ساتھ سنک ٹی شامل کریں (کیپیسٹی 1)
3. تمام اصل کنارے کی صلاحیتوں کو 1 پر سیٹ کریں۔
4. زیادہ سے زیادہ بہاؤ = زیادہ سے زیادہ ملاپ

## سپیکٹرل گراف تھیوری
اسپیکٹرل گراف تھیوری گراف سے وابستہ میٹرکس کے eigenvalues ​​اور eigenvectors کے ذریعے گراف کا مطالعہ کرتی ہے۔
### کلیدی میٹرکس
| میٹرکس | تعریف | یہ کیا قبضہ کرتا ہے |
|---------|------------|------|
| **ملحقہ میٹرکس** A | A[i][j] = 1 اگر کنارہ (i,j) موجود ہے | کنیکٹیویٹی پیٹرن |
| **ڈگری میٹرکس** D | ترچھی؛ D[i][i] = deg(i) | ڈگری کے لحاظ سے عمودی اہمیت |
| **لیپلیسیئن** L = D − A | L[i][j] = −1 اگر کنارے، deg(i) اخترن پر | گراف پر افعال کی ہمواری |
| **نارملائزڈ لیپلیسیئن** L_norm = D^(−1/2) L D^(−1/2) | اسکیل غیر متغیر ورژن | کمیونٹی ڈھانچہ |
### لیپلیسیئن کی ایگن ویلیوز
Laplacian L مثبت نیم متعین ہے، لہذا تمام eigenvalues ​​≥ 0 ہیں۔
| Eigenvalue | معنی |
|------------|---------|
| λ₁ = 0 | ہمیشہ صفر؛ eigenvector مستقل ویکٹر ہے |
| λ₂ (الجبری کنیکٹیویٹی) | > 0 iff گراف منسلک ہے؛ larger = بہتر جڑا ہوا |
| صفر eigenvalues ​​کی تعداد | منسلک اجزاء کی تعداد کے برابر |
| λₙ | زیادہ سے زیادہ ڈگری اور گراف کی توسیع سے متعلق |
### سپیکٹرل طریقوں کا اطلاق
| درخواست | طریقہ |
|---------------|---------|
| **گراف کی تقسیم** | گراف کو متوازن حصوں میں تقسیم کرنے کے لیے L کے eigenvectors استعمال کریں۔
| **کمیونٹی کا پتہ لگانا** | سپیکٹرل کلسٹرنگ: نیچے ایگین ویکٹر کا استعمال کرتے ہوئے چوٹیوں کو سرایت کریں، پھر کلسٹر |
| **پیج رینک** | ویب گراف کے ملحقہ میٹرکس (یا ٹرانزیشن میٹرکس) کا ایجین ویکٹر |
| **گراف ڈرائنگ** | Laplacian کے eigenvectors کا استعمال کرتے ہوئے چوٹیوں کی پوزیشن |
| **نیم زیر نگرانی سیکھنے** | گراف لیپلیسیئن (لیبل پروپیگیشن) کا استعمال کرتے ہوئے لیبلوں کی تشہیر کریں |
| **گراف نیورل نیٹ ورکس** | سپیکٹرل کنولوشنز: L | کے eigenvectors کا استعمال کرتے ہوئے گراف پر فلٹر سگنلز
### چیگر کی عدم مساوات
دوسری eigenvalue λ₂ کو گراف کے **توسیع** سے جوڑتا ہے (یہ کتنی اچھی طرح سے جڑا ہوا ہے):
λ₂ / 2 ≤ h(G) ≤ √(2λ₂)
جہاں h(G) Cheeger مستقل (isoperimetric نمبر) ہے۔ اس کا مطلب ہے کہ λ₂ تقریبا پیمائش کرتا ہے کہ گراف کو دو ٹکڑوں میں کاٹنا کتنا مشکل ہے - کلسٹرنگ کے لیے ایک اہم بصیرت۔

## خصوصی گراف سٹرکچرز
| گراف | عمودی | کناروں | پراپرٹیز |
|---------|---------|-------|------------|
| مکمل Kₙ | n | n(n−1)/2 | ہر جوڑا جڑا ہوا؛ قطر 1 |
| سائیکل Cₙ | n | n | 2-باقاعدہ؛ منسلک |
| پاتھ Pₙ | n | n−1 | درخت قطر n−1 |
| ہائپر کیوب Qₖ | 2ᵏ | k·2ᵏ⁻¹ | k-باقاعدہ؛ قطر k؛ دو طرفہ |

| پیٹرسن گراف | 10 | 15 | 3-باقاعدہ؛ قطر 2؛ پلانر نہیں؛ ہیملٹونین سائیکل نہیں |

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| گراف کا تصور | درخواست |
|---------------|---------------|
| BFS / DFS | ویب کرالنگ، سوشل نیٹ ورک کا تجزیہ، منسلک جزو لیبلنگ |
| Dijkstra / A* | روٹ پلاننگ، گیم AI پاتھ فائنڈنگ، روبوٹکس نیویگیشن |
| کم از کم پھیلے ہوئے درخت | کلسٹرنگ (سنگل لنکیج)، فیچر کا انتخاب، نیٹ ورک ڈیزائن |
| زیادہ سے زیادہ بہاؤ / منٹ کٹ | تصویر کی تقسیم، دو طرفہ مماثلت، سفارش کی تفویض |
| سپیکٹرل طریقے | سپیکٹرل کلسٹرنگ، گراف نیورل نیٹ ورکس، جہت میں کمی (Laplacian eigenmaps) |
| پیج رینک | سرچ انجن کی درجہ بندی، سوشل نیٹ ورکس میں اثر و رسوخ کا تجزیہ |
| DAGs | Bayesian نیٹ ورکس، causal inference، ٹاسک شیڈولنگ، گہرے سیکھنے میں کمپیوٹیشن گرافس |
| دو طرفہ گرافس | تجویز کنندہ سسٹمز میں یوزر آئٹم میٹرکس، دو طرفہ مارکیٹس |
| درختوں کے ڈھانچے | فیصلہ کن درخت، بے ترتیب جنگلات، درجہ بندی کے جھرمٹ، فائل سسٹم نیویگیشن |
| گراف کی نمائندگی | نالج گرافس (وکیڈیٹا، ڈی بی پیڈیا)، مالیکیولر گرافس (منشیات کی دریافت)، حوالہ جات |

## خلاصہ
| موضوع | بنیادی خیال | کلیدی الگورتھم / نتیجہ |
|---------|------------|----------------------|
| بنیادی باتیں | عمودی، کنارے، ڈگری، راستے | مصافحہ لیما |
| نمائندگی | گراف کو کیسے ذخیرہ کیا جائے | ملحقہ میٹرکس بمقابلہ ملحقہ فہرست |
| درخت | متصل ایسکلک گرافس | n عمودی → n−1 کنارے |
| ٹریورسلز | منظم ورٹیکس ایکسپلوریشن | BFS (سب سے چھوٹا راستہ)، DFS (گہری تلاش) |
| مختصر ترین راستے | کم از کم وزن والے راستے | Dijkstra, Bellman-Ford, Floyd-Warshall |
| کم سے کم پھیلے ہوئے درخت | تمام چوٹیوں کو جوڑنے کا سب سے سستا طریقہ | Kruskal's, Prim's |
| نیٹ ورک فلو | زیادہ سے زیادہ تھرو پٹ | Ford-Fulkerson, max-flow min-cut theorem |
| سپیکٹرل تھیوری | Eigenvalues ​​ساخت کو ظاہر کرتی ہے | Laplacian eigenvalues، سپیکٹرل کلسٹرنگ |
گراف تھیوری جدید ڈیٹا سائنس میں ریاضی کی سب سے براہ راست قابل اطلاق شاخ ہے۔ سوشل نیٹ ورکس، نالج گرافس، مالیکیولر اسٹرکچرز، گہرے سیکھنے کے فریم ورک میں کمپیوٹیشن گرافس، انحصار حل، سفارشی نظام - یہ سب بنیادی طور پر گراف کے مسائل ہیں۔ یہاں احاطہ کیے گئے الگورتھم صرف نظریاتی نہیں ہیں۔ وہ ہر روز پیداواری نظام میں بڑے پیمانے پر چلتے ہیں۔
