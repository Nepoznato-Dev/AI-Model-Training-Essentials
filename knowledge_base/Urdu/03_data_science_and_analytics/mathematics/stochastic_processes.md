# اسٹاکسٹک عمل
ایک **اسٹاکسٹک عمل** وقت (یا جگہ) کے حساب سے ترتیب کردہ بے ترتیب متغیرات کا مجموعہ ہے۔ جبکہ امکانی نظریہ انفرادی بے ترتیب واقعات کا مطالعہ کرتا ہے، اسٹاکسٹک عمل اس بات کا مطالعہ کرتے ہیں کہ وقت کے ساتھ بے ترتیب پن کیسے تیار ہوتا ہے۔ وہ اسٹاک کی قیمتوں، قطار کی لمبائی، بیماری کے پھیلاؤ، زبان کی تخلیق، اور مشین لرننگ ماڈلز کی تربیتی حرکیات کا نمونہ بناتے ہیں۔
---

## بنیادیں
### تعریف
ایک اسٹاکسٹک عمل {X_t : t ∈ T} بے ترتیب متغیرات کا ایک خاندان ہے جو ایک عام امکانی جگہ پر بیان کیا جاتا ہے۔ T ہے **انڈیکس سیٹ** (وقت):
- **مجرد وقت:** T = {0, 1, 2, ...}
- **مسلسل وقت:** T = [0، ∞)
**ریاست کی جگہ** S ممکنہ اقدار کا مجموعہ ہے جو X_t لے سکتا ہے۔
### کلیدی خصوصیات
| پراپرٹی | تعریف |
|------------|------------|
| **اسٹیشناریٹی** | (X_{t₁}, ..., X_{tₖ}) کی مشترکہ تقسیم اسی طرح (X_{t₁+τ}, ..., X_{tₖ+τ}) |
| **آزادی** | T ≠ s کے لیے X_s سے آزاد X_t |
| **ارگوڈیکیٹی** | وقت کی اوسطیں جوڑتی ہوئی اوسط |
| **مارکوف پراپرٹی** | مستقبل صرف حال پر منحصر ہے ماضی پر نہیں۔
| **مارٹنگیل** | متوقع مستقبل کی قیمت موجودہ قدر کے برابر ہے |
---

## مارکوف چینز
A **مارکوو چین** ایک اسٹاکسٹک عمل ہے جہاں مستقبل کی حالت صرف موجودہ حالت (یاد گار پراپرٹی) پر منحصر ہوتی ہے۔
### ڈسکریٹ ٹائم مارکوف چینز (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**ٹرانزیشن میٹرکس** P میں اندراجات ہیں p_{ij} = P(j پر جائیں | فی الحال i پر)۔
| پراپرٹی | بیان |
|------------|------------|
| قطار کی رقم | ہر قطار کا مجموعہ 1: Σⱼ p_{ij} = 1 |
| n-مرحلہ منتقلی | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
| اسٹیشنری تقسیم | πP = π (بائیں eigenvector eigenvalue 1 کے ساتھ) |
### ریاستوں کی درجہ بندی
| مدت | تعریف |
|------|------------|
| **بار بار ہونے والا** | سلسلہ امکان 1 کے ساتھ ریاست i میں واپس آجاتا ہے۔
| **عارضی** | کبھی واپس نہ آنے کا غیر صفر امکان |
| **جذب کرنے والا** | p_{ii} = 1 (ایک بار داخل ہوا، کبھی نہیں چھوڑا) |
| **مدت** | واپسی کے اوقات کی GCD؛ دورانیہ 1 = aperiodic |
| **مواصلات** | ریاستیں i اور j ایک دوسرے تک پہنچ سکتی ہیں |
### اسٹیشنری تقسیم
ایک ناقابل تلافی، مثبت بار بار مارکوف چین کے لیے، اسٹیشنری تقسیم π موجود ہے، منفرد ہے، اور مطمئن ہے:
πP = π، Σᵢ πᵢ = 1
** تشریح:** πᵢ = ریاست میں گزارے گئے وقت کا طویل مدتی تناسب i۔
**کام کی مثال:** موسم کا ماڈل {دھوپ، بارش} کے ساتھ۔
P = [[0.9، 0.1]، [0.5، 0.5]] (قطاریں: دھوپ سے، بارش سے)
اسٹیشنری تقسیم: πP = π
- π₁ = 0.9π₁ + 0.5π₂
- π₂ = 0.1π₁ + 0.5π₂
- π₁ + π₂ = 1
- حل کرنا: π₁ = 5/6 ≈ 0.833، π₂ = 1/6 ≈ 0.167
### سٹیشناریٹی میں کنورجنشن
ایک ناقابل تلافی، اپیریوڈک، مثبت بار بار آنے والی زنجیر کے لیے:
- Pⁿ → Π ( تمام قطاروں کے ساتھ میٹرکس π کے برابر) بطور n → ∞
- **مکسنگ کا وقت:** مراحل کی تعداد جب تک کہ تقسیم π کے قریب نہ ہو۔
- **اسپیکٹرل گیپ:** 1 − |λ₂| (جہاں λ₂ دوسرا سب سے بڑا eigenvalue ہے) اختلاط کی رفتار کا تعین کرتا ہے۔
### مسلسل-وقت مارکوف چینز (CTMC)
ٹرانزیشنز بے ترتیب اوقات میں ہوتی ہیں جو کفایتی تقسیم کے زیر انتظام ہیں۔
| تصور | تفصیل |
|---------|---------------|
| **ریٹ میٹرکس Q** | q_{ij} ≥ 0 i ≠ j کے لیے؛ q_{ii} = −Σ_{j≠i} q_{ij} |
| **منتقلی کے امکانات** | P(t) = e^{Qt} (میٹرکس ایکسپونینشل) |
| **اسٹیشنری ڈسٹری بیوشن** | πQ = 0 |
| **ہولڈنگ ٹائم** | حالت i میں وقت ہے Exp(−q_{ii}) |

## بے ترتیب سیر
**بے ​​ترتیب چہل قدمی** ایک ایسا راستہ ہے جو یکے بعد دیگرے بے ترتیب قدموں سے بنتا ہے۔
### سادہ رینڈم واک
X_n = X_{n-1} + Z_n، جہاں Z_n ∈ {+1, −1} احتمالات p، q = 1−p کے ساتھ۔
| پراپرٹی | p = 1/2 (سمیٹرک) | p ≠ 1/2 (متعصب) |
|------------|--------------------------------------------|
| E[X_n] | 0 | n(2p−1) |
| Var[X_n] | n | 4npq |
| اصل کی طرف لوٹتا ہے؟ | ہاں (امکان 1 کے ساتھ) | نہیں (بہک جاتا ہے) |
| بار بار۔ | ہاں (1D اور 2D میں) | نہیں |
### اعلیٰ جہتوں میں بے ترتیب واک
| طول و عرض | بار بار۔ | وجدان |
|------------|------------|------------|
| 1D | جی ہاں | "ایک شرابی آدمی ہمیشہ اپنے گھر کا راستہ تلاش کرتا ہے" |
| 2D | جی ہاں | "ایک شرابی پرندہ ہمیشہ اپنے گھر کا راستہ تلاش کرتا ہے" |
| 3D+ | نہیں | "ایک شرابی چڑیا کبھی گھر کا راستہ نہیں پاتی" |
### براؤنین موشن سے کنکشن
بے ترتیب چہل قدمی کو پیمانہ کرنا: چلو S_n = ΣZ_i۔ پھر قدم سائز → 0 اور اقدامات → ∞ کے طور پر:
S_{⌊nt⌋} / √n → B(t) (Brownian motion، by Donsker theorem)
---

## براؤنین موشن
**براؤنین موشن** (وینر عمل) B(t) بے ترتیب واک کی مسلسل وقت کی حد ہے۔
### تعریف
B(t) مطمئن کرتا ہے:
1. B(0) = 0
2. B(t) کے مسلسل راستے ہیں۔
3. آزاد اضافہ: B(t) − B(s) r < s < t کے لیے B(s) − B(r) سے آزاد ہے۔
4. B(t) − B(s) ~ N(0, t − s) (Gaussian increments)
### کلیدی خصوصیات
| پراپرٹی | بیان |
|------------|------------|
| E[B(t)] | = 0 |
| Var[B(t)] | = t |
| Cov[B(s), B(t)] | = منٹ(s, t) |
| کہیں بھی تفریق نہیں | راستے مسلسل ہیں لیکن کوئی مشتق نہیں |
| فریکٹل طول و عرض | گراف میں Hausdorff طول و عرض 3/2 ہے |
| مارکوف پراپرٹی | مستقبل صرف موجودہ پوزیشن پر منحصر ہے |
| مارنگیل | E[B(t) | F_s] = B(s) برائے s < t |
### جیومیٹرک براؤنین موشن
S(t) = S(0) exp((μ− σ²/2)t + σB(t))
یہ Black-Scholes فریم ورک میں اسٹاک کی قیمتوں کے لیے معیاری ماڈل ہے۔
- μ: بہاؤ (متوقع واپسی)
- σ: اتار چڑھاؤ
---

## زہر کے عمل
A **Poisson process** N(t) [0, t] میں ہونے والے واقعات کی تعداد کو شمار کرتا ہے۔
### تعریف
N(t) ~ Poisson(λt)، جہاں λ شرح ہے (واقعات فی یونٹ وقت)۔
| پراپرٹی | بیان |
|------------|------------|
| N(0) = 0 | - |
| آزادانہ اضافہ | متضاد وقفوں میں ہونے والے واقعات آزاد ہیں |
| اسٹیشنری اضافہ | N(t+s) − N(s) ~ Poisson(λt) |
| E[N(t)] | = λt |
| Var[N(t)] | = λt |
| بین آمد کے اوقات | تیزی سے تقسیم کیا گیا: T_i ~ Exp(λ) |
### عام کرنا
| متغیر | تفصیل |
|---------|---------------|
| **غیر یکساں** | شرح λ(t) وقت کے ساتھ مختلف ہوتی ہے۔
| **کمپاؤنڈ زہر** | ہر ایونٹ کا ایک بے ترتیب سائز ہوتا ہے: S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **پوسن بے ترتیب پیمائش** | اسپیس ٹائم میں پوائنٹس، نہ صرف وقت |
| **ملٹی ویریٹ** | ممکنہ تعاملات کے ساتھ متعدد ایونٹ کی اقسام |
---

## مارنگیلز
ایک **مارٹنگیل** ایک منصفانہ کھیل ہے: تمام موجودہ معلومات کے پیش نظر مستقبل کی متوقع قیمت موجودہ قدر کے برابر ہے۔
### تعریف
فلٹریشن {F_n} کے حوالے سے {X_n} ایک مارٹنگیل ہے اگر:
1. X_n F_n-قابل پیمائش ہے (موافق)
2. E[|X_n|] < ∞ (انٹیگریبل)
3. E[X_{n+1} | F_n] = X_n (منصفانہ کھیل)
| متغیر | حالت | تشریح |
|---------|------------|----------------|
| **مارٹنگیل** | ای[X_{n+1} | F_n] = X_n | منصفانہ کھیل |
| **سبمارٹنگیل** | ای[X_{n+1} | F_n] ≥ X_n | سازگار کھیل (رجحان بڑھ رہا ہے) |
| **سپرمارٹنگیل** | ای[X_{n+1} | F_n] ≤ X_n | ناموافق کھیل (نیچے کا رجحان) |
### کلیدی نظریات
| تھیوریم | بیان |
|---------|------------|
| **اختیاری رکنا** | شرائط کے تحت، E[X_T] = E[X_0] رکنے کے وقت T |
| **کنورجنسی** | ایک باؤنڈڈ مارٹنگیل تقریباً یقینی طور پر مل جاتا ہے |
| **زیادہ سے زیادہ عدم مساوات** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Doob's) |
---

## مونٹی کارلو کے طریقے
**مونٹی کارلو کے طریقے** تعییناتی مقداروں کا اندازہ لگانے کے لیے بے ترتیب نمونے لینے کا استعمال کرتے ہیں۔
### بنیادی خیال
E[f(X)] کا اندازہ لگانے کے لیے جہاں X ~ P:
1. N نمونے کھینچیں: x₁, x₂, ..., x_N P سے
2. شمار کریں: Î = (1/N) Σᵢ f(xᵢ)
3. بڑی تعداد کے قانون کے مطابق: Î → E[f(X)] بطور N → ∞
**خرابی:** معیاری خرابی = σ_f / √N، جہاں σ_f² = Var[f(X)]
### تغیرات کو کم کرنے کی تکنیک
| تکنیک | آئیڈیا | سپیڈ اپ |
|------------|------|---------|
| **اہمیت کے نمونے** | P کی بجائے Q سے نمونہ، P/Q کے حساب سے وزن | ڈرامائی ہو سکتا ہے |
| **مخالف تغیرات** | تغیر کو منسوخ کرنے کے لیے جوڑے (x, −x) استعمال کریں۔ ~2x |
| **کنٹرول متغیرات** | f | کے ساتھ منسلک معروف توقع فنکشن کو گھٹائیں۔ مختلف ہوتی ہے |
| **سطح شدہ نمونے** | ڈومین تقسیم کریں، ہر سطح کا نمونہ لیں | فرق کو کم کرتا ہے |
| **راؤ-بلیک ویل** | کافی اعدادوشمار پر شرط | ہمیشہ مدد کرتا ہے |
---

## مارکوف چین مونٹی کارلو (MCMC)
MCMC ایک مارکوف چین بناتا ہے جس کی اسٹیشنری تقسیم ہدف کی تقسیم ہے۔ "برن ان" مدت کے بعد، ہدف سے تخمینی نمونے نکالے جاتے ہیں۔
### میٹروپولیس-ہسٹنگز الگورتھم
| مرحلہ | ایکشن |
|------|---------|
| 1 | موجودہ حالت: x_t |
| 2 | تجویز: x*~ q(x* \| x_t) (تجویز کی تقسیم) |
| 3 | قبولیت کا تناسب: α = منٹ(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 | امکان کے ساتھ قبول کریں α: x_{t+1} = x* (قبول کریں) یا x_t (مسترد) |
**خصوصی صورت — میٹروپولیس الگورتھم:** ہم آہنگی تجویز q(x*|x) = q(x|x*)، تو α = min(1, π(x*)/π(x_t))۔
### گبز سیمپلنگ
Metropolis-Hastings کا ایک خاص معاملہ جہاں ہر متغیر کو اس کی مکمل مشروط تقسیم سے اپ ڈیٹ کیا جاتا ہے۔
ہدف π(x₁, x₂, ..., xₖ):
1. نمونہ x₁^{(t+1)} ~ π(x₁ | x₂^{(t)}, ..., xₖ^{(t)})
2. نمونہ x₂^{(t+1)} ~ π(x₂ | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. تمام متغیرات کے لیے جاری رکھیں
4. دہرائیں۔
| پراپرٹی | بیان |
|------------|------------|
| ہمیشہ قبول کرتا ہے | α = 1 (کوئی رد عمل نہیں) |
| کی ضرورت ہے | ہر مکمل مشروط سے نمونہ لینے کی صلاحیت |
| کنورجنسی | ناقابل واپسی، aperiodic زنجیروں کی ضمانت |
### MCMC تشخیص
| تشخیصی | مقصد |
|------------|---------|
| **ٹریس پلاٹ** | اختلاط اور سٹیشناریٹی کے لیے بصری جانچ |
| **خودکار تعلق** | نمونے کے انحصار کی پیمائش کریں (کم خودکار تعلق چاہتے ہیں) |
| **گیلمین-روبن (R̂)** | متعدد زنجیروں کا موازنہ کریں؛ R̂ < 1.05 کنورجنسنس کی تجویز کرتا ہے |
| **موثر نمونہ سائز** | N_eff = N / (1 + 2Σρₖ); خود کار تعلق کے لیے اکاؤنٹس |
| **برن ان** | زنجیر کے مستحکم ہونے سے پہلے ابتدائی نمونے ضائع کر دیں۔

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| اسٹاکسٹک عمل | درخواست |
|-------------------|---------------|
| مارکوف کی زنجیریں | پیج رینک (ویب گراف پر بے ترتیب واک)، ٹیکسٹ جنریشن (این-گرام ماڈلز)، MCMC |
| بے ترتیب چہل قدمی | Node2Vec اور DeepWalk (گراف ایمبیڈنگز)، RL میں ایکسپلوریشن |
| براؤنین موشن | سٹاک کی قیمت کی ماڈلنگ، جنریٹو AI میں پھیلاؤ کے ماڈل |
| زہر کے عمل | ماڈلنگ ایونٹ کی آمد (کلکس، ناکامیاں)، قطار کا نظریہ |
| Martingales | مالیاتی ریاضی، SGD کا کنورجنس ثابت کرنا (اسٹاکسٹک تخمینہ) |
| مونٹی کارلو | متوقع اقدار کا تخمینہ لگانا، Bayesian inference، reinforcement Learning (پالیسی کی تشخیص) |
| MCMC (Metropolis-Hastings) | Bayesian posterior سیمپلنگ، probabilistic programming (Stan, PyMC) |

|---------|------------|------|---------------|
| مارکوف چین | مجرد/مسلسل | مجرد/مسلسل | یادداشت کے بغیر (مارکوف پراپرٹی) |

اسٹاکسٹک عمل وقت کے ساتھ بے ترتیب ہونے کی ریاضی ہیں۔ وہ جدید Bayesian inference (MCMC)، کمک سیکھنے (مارکوف کے فیصلے کے عمل)، جنریٹو ماڈلنگ (ڈفیوژن ماڈلز)، مالیاتی ریاضی، اور قطار بندی تھیوری کو زیر کرتے ہیں۔ ان عملوں کو سمجھنا آپ کو غیر یقینی صورتحال کو متحرک طور پر ماڈل کرنے کے لیے ٹولز فراہم کرتا ہے — نہ صرف اسنیپ شاٹ کے طور پر، بلکہ جیسا کہ یہ تیار ہوتا ہے۔
