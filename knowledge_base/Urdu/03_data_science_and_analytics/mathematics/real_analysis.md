#حقیقی تجزیہ
حقیقی تجزیہ کیلکولس کی سخت بنیاد ہے۔ جب کہ تعارفی کیلکولس آپ کو مشتقات اور انٹیگرلز کی گنتی کرنے کا طریقہ سکھاتا ہے، حقیقی تجزیہ پوچھتا ہے کہ *کیوں* یہ تکنیکیں کام کرتی ہیں — اور کب ناکام ہوجاتی ہیں۔ یہ حدود، تسلسل، کنورجنسنس، اور انضمام کی درست تعریفیں فراہم کرتا ہے جو امکانی نظریہ، فنکشنل تجزیہ، اصلاح، اور مشین لرننگ الگورتھم کے پیچھے نظریاتی ضمانتوں کو اہمیت دیتا ہے۔

## سلسلے اور سلسلہ
### سلسلے
ایک **سلسلہ** حقیقی نمبروں کی ترتیب شدہ فہرست ہے (aₙ)ₙ₌₁^∞۔ مرکزی سوال یہ ہے کہ: کیا ترتیب ** ایک حد تک ** ملتی ہے؟
**تجزیہ کی تعریف:** ایک ترتیب (aₙ) L میں بدل جاتی ہے اگر ہر ε > 0 کے لیے، وہاں N موجود ہے جو کہ سب کے لیے n > N: |aₙ − L| < ε.
| تصور | تعریف | مثال |
|---------|------------|---------|
| **کنورجنٹ** | lim aₙ = L موجود ہے اور محدود ہے | aₙ = 1/n → 0 |
| **مختلف** | اکٹھا نہیں ہوتا | aₙ = (−1)ⁿ oscillates |
| ** ∞** سے مختلف | aₙ بغیر کسی پابندی کے بڑھتا ہے | aₙ = n² → ∞ |
| **حدود** | \|aₙ\| ≤ کچھ M کے لیے M | ہر متضاد ترتیب پابند ہے |
| **مونوٹون** | یا تو ہمیشہ غیر کم ہونے والا یا غیر بڑھنے والا | aₙ = 1 − 1/n بڑھ رہا ہے |
| **کوچی ترتیب** | ∀ε > 0، ∃N: ∀m,n > N, \|aₘ − aₙ\| < ε | ℝ میں، کاچی ⟺ کنورجنٹ |
**اہم نظریات:**
- **مونوٹون کنورجینس تھیوریم:** ہر پابند مونوٹون سیکوینس کنورج ہوتا ہے
- **Bolzano-Weierstrass Theorem:** ہر پابند ترتیب کا ایک متضاد نتیجہ ہوتا ہے
- **ℝ کی مکملیت:** ℝ میں ہر کاچی ترتیب آپس میں مل جاتی ہے (یہ ℝ کو ℚ سے ممتاز کرتا ہے)
### سیریز
A **سیریز** ایک ترتیب کا مجموعہ ہے: Σₙ₌₁^∞ aₙ۔ اگر جزوی رقم Sₙ = Σₖ₌₁ⁿ aₖ کی ترتیب آپس میں مل جاتی ہے تو سیریز آپس میں بدل جاتی ہے۔
### کنورجنسی ٹیسٹ
| ٹیسٹ | حالت | نتیجہ |
|------|------------|------------|
| **اختلاف ٹیسٹ** | lim aₙ ≠ 0 | سیریز مختلف ہوتی ہے |
| **موازنہ ٹیسٹ** | 0 ≤ aₙ ≤ bₙ اور Σbₙ کنورجز | Σaₙ کنورجز |
| **تناسب ٹیسٹ** | lim \|aₙ₊₁/aₙ\| = L | اگر L< 1, diverges if L >1 |
| **روٹ ٹیسٹ** | lim sup \|aₙ\|^(1/n) = L | اگر L< 1, diverges if L >1 |
| **انٹیگرل ٹیسٹ** | aₙ = f(n)، f گھٹتا ہوا، مثبت | Σaₙ converges iff ∫f(x)dx کنورجز |
| **متبادل سیریز** | aₙ گھٹتا ہوا، لم aₙ = 0، متبادل علامات | سیریز کنورجز |
| **مکمل ہم آہنگی** | Σ\|aₙ\| جمع | Σaₙ converges (اور دوبارہ ترتیب دینے سے ایک ہی رقم ملتی ہے) |
| **مشروط کنورجنسی** | Σaₙ بدل جاتا ہے لیکن Σ\|aₙ\| ہٹ جاتا ہے | دوبارہ ترتیب سے کوئی بھی رقم مل سکتی ہے (Riemann) |
### اہم سیریز
| سیریز | رقم | حالت |
|---------|------|------------|
| جیومیٹرک: Σ rⁿ | 1/(1−r) | \|r\| < 1 |
| p-series: Σ 1/nᵖ | Converges | p >1 |
| ہارمونک: Σ 1/n | اختلاف (= ∞) | - |
| ایکسپونینشل: Σ xⁿ/n! | eˣ | تمام x |
| ٹیلر برائے ln(1+x): Σ (−1)ⁿ⁺¹xⁿ/n | ln(1+x) | −1 < x ≤ 1 |

## حدود اور تسلسل
### افعال کی حدود
**تعریف:** lim_{x→c} f(x) = L کا مطلب ہے: ہر ε > 0 کے لیے، موجود ہے δ > 0 اس طرح کہ 0 < |x − c| < δ کا مطلب ہے |f(x) − L| < ε.
یہ **ε-δ تعریف** ہے — کا سخت ورژن "f(x) L کے قریب پہنچتا ہے جیسا کہ x c کے قریب آتا ہے۔"
### تسلسل
ایک فنکشن f **c** پر مسلسل ہے اگر lim_{x→c} f(x) = f(c)۔ مساوی طور پر: ہر ε > 0 کے لیے، موجود ہے δ > 0 اس طرح کہ |x − c| < δ کا مطلب ہے |f(x) − f(c)| < ε.
**منقطع ہونے کی اقسام:**
| قسم | تفصیل | مثال |
|------|---------------|---------|
| ہٹنے والا | حد موجود ہے لیکن ≠ f(c) | f(x) = sin(x)/x پر x = 0 |
| چھلانگ | بائیں اور دائیں حدود موجود ہیں لیکن مختلف | سٹیپ فنکشن |
| لامحدود | حد ہے ±∞ | f(x) = 1/x² at x = 0 |
| دوہری | حد موجود نہیں ہے | f(x) = sin(1/x) at x = 0 |
### مسلسل افعال کے لیے کلیدی تھیورمز
| تھیوریم | بیان |
|---------|------------|
| **انٹرمیڈیٹ ویلیو تھیورم** | اگر f مسلسل ہے [a,b] اور f(a) < k < f(b)، تو ∃c ∈ (a,b): f(c) = k |
| **ایکسٹریم ویلیو تھیورم** | اگر f مسلسل [a,b] پر ہے، f اپنی زیادہ سے زیادہ اور کم از کم [a,b] پر حاصل کرتا ہے |
| **حد بندی کا نظریہ** | اگر f [a,b] پر مسلسل ہے تو f [a,b] | پر پابند ہے۔
| **یکساں تسلسل** | f یکساں طور پر مسلسل ہے [a,b] پر اگر f مسلسل ہے [a,b] (Heine-Cantor) |
**کام شدہ مثال (IVT):** دکھائیں x³ + x − 1 = 0 کا حل (0, 1) میں ہے۔
- چلیں f(x) = x³ + x − 1. f مسلسل ہے (کثیریتی)۔
- f(0) = −1< 0 and f(1) = 1 >0۔
- بذریعہ IVT، ∃c ∈ (0,1): f(c) = 0۔

## تفریق
### تعریف
f'(c) = lim_{h→0} (f(c+h) − f(c)) / h
اگر یہ حد موجود ہے تو، c پر f **تفرق قابل** ہے۔
### تفریق بمقابلہ تسلسل
| رشتہ | بیان |
|---------------|------------|
| قابل تفریق → مسلسل | اگر f c پر تفریق پذیر ہے، f c پر مسلسل ہے۔
| مسلسل ↛ قابل تفریق | f(x) = \|x\| 0 پر مسلسل ہے لیکن وہاں فرق نہیں ہے |
| کہیں بھی تفریق نہیں | Weierstrass فنکشن: ہر جگہ مسلسل، کہیں بھی فرق نہیں کیا جا سکتا |
### کلیدی نتائج
| تھیوریم | بیان |
|---------|------------|
| **مین ویلیو تھیورم** | اگر f مسلسل [a,b] پر ہے اور (a,b) پر فرق ہے، ∃c: f'(c) = (f(b)−f(a))/(b−a) |
| **رول کا نظریہ** | MVT کی خصوصی صورت جب f(a) = f(b): ∃c: f'(c) = 0 |
| **L'Hôpital's Rule** | اگر lim f/g = 0/0 یا ∞/∞، تو lim f/g = lim f'/g' (جب مؤخر الذکر موجود ہو) |
| **ٹیلر کا نظریہ** | f(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x) واضح باقی کے ساتھ |

## انضمام
### ریمن انٹیگریشن
**ریمن انٹیگرل** ∫ₐᵇ f(x)dx کو ریمن رقوم کی حد کے طور پر بیان کرتا ہے۔
**تعمیر:**
1. [a،b] کو ذیلی وقفوں میں تقسیم کریں: P = {x₀، x₁، ...، xₙ}
2. نمونہ پوائنٹس کا انتخاب کریں tᵢ ∈ [xᵢ₋₁, xᵢ]
3. ریمن کا مجموعہ: S(P,f) = Σᵢ f(tᵢ)(xᵢ − xᵢ₋₁)
4. اگر S(P,f) کی حد میش → 0 کے طور پر موجود ہے، f ریمن انٹیگریبل ہے
**ریمن انضمام کا معیار:**
| حالت | انٹیگریبل۔ |
|------------|-------------|
| مسلسل [a,b] | جی ہاں |
| بہت سے وقفوں کے ساتھ پابند | جی ہاں |
| [a,b] | جی ہاں |
| ڈیریچلیٹ فنکشن (ℚ پر 1، غیر معقول پر 0) | نہیں |
### کیلکولس کا بنیادی نظریہ
| حصہ | بیان |
|------|------------|
| **حصہ 1** | اگر f [a,b] پر مسلسل ہے، تو F(x) = ∫ₐˣ f(t)dt قابل تفریق ہے اور F'(x) = f(x) |
| **حصہ 2** | اگر F' = f اور f ریمن انٹیگریبل ہے، تو ∫ₐᵇ f(x)dx = F(b) − F(a) |
### لیبیسگو انٹیگریشن
ریمن انٹیگرل کی حدود ہیں - یہ تجزیہ اور احتمال میں پیدا ہونے والے بہت سے افعال کو مربوط نہیں کر سکتا۔ **Lebesgue انٹیگرل** انضمام کو فنکشنز کی ایک بہت وسیع کلاس تک پھیلاتا ہے۔
**اہم خیال:** ڈومین (x-axis) کو تقسیم کرنے کے بجائے رینج (y-axis) کو تقسیم کریں۔
| پہلو | ریمن انٹیگرل | Lebesgue Integral |
|---------|-------------------------|
| نقطہ نظر | پارٹیشن ڈومین (x-axis) | تقسیم کی حد (y-axis) |
| انضمام | مسلسل، ٹکڑے وار مسلسل | قابل پیمائش افعال |
| محدود نظریات | کمزور | طاقتور (غلبہ کنورجنسی، مونوٹون کنورجنسی) |
| ہینڈل | "اچھا" افعال | گھنے وقفے کے ساتھ افعال |
| کی بنیاد | کلاسیکی کیلکولس | جدید امکان نظریہ |
**لیبیسگیو کا معیار:** f ہے Riemann integrable on [a,b] iff f تقریبا ہر جگہ پابند اور مسلسل ہے (منقطعات کے سیٹ میں صفر کی پیمائش ہوتی ہے)۔

## میٹرک اسپیسز
ایک **میٹرک اسپیس** تجریدی سیٹوں کے لیے "فاصلے" کے تصور کو عام کرتا ہے۔
### تعریف
A **میٹرک اسپیس** (X, d) فاصلاتی فنکشن کے ساتھ ایک سیٹ X ہے d: X × X → ℝ اطمینان بخش:
| محور | بیان |
|---------|------------|
| غیر منفی | d(x,y) ≥ 0 |
| شناخت | d(x,y) = 0 iff x = y |
| ہم آہنگی | d(x,y) = d(y,x) |
| مثلث عدم مساوات | d(x,z) ≤ d(x,y) + d(y,z) |
### کامن میٹرک اسپیسز
| خلائی | سیٹ | میٹرک | درخواست |
|-------|------|---------|------------|
| ℝⁿ Euclidean کے ساتھ | ℝⁿ | d(x,y) = √Σ(xᵢ−yᵢ)² | معیاری جیومیٹری |
| ℝⁿ مین ہٹن کے ساتھ | ℝⁿ | d(x,y) = Σ\|xᵢ−yᵢ\| | گرڈ پر مبنی راستے، LASSO |
| Chebyshev کے ساتھ ℝⁿ | ℝⁿ | d(x,y) = زیادہ سے زیادہ\|xᵢ−yᵢ\| | شطرنج بادشاہ فاصلہ |
| مجرد میٹرک | کوئی بھی سیٹ | d(x,y) = 1 اگر x≠y، 0 اگر x=y | ٹوپولوجی کی مثالیں |
| فنکشن اسپیس C[a,b] | مسلسل افعال | d(f,g) = زیادہ سے زیادہ\|f(x)−g(x)\| | نظریہ قریب |
| Lᵖ space | p-انٹیگریبل فنکشنز | d(f,g) = (∫\|f−g\|ᵖ)^(1/p) | فنکشنل تجزیہ، ایم ایل کے اصول |
### میٹرک اسپیس میں ٹاپولوجیکل تصورات
| تصور | تعریف | مثال |
|---------|------------|---------|
| **اوپن بال** | B(x,r) = {y : d(x,y) < r} | کھلا وقفہ (x−r, x+r) ℝ میں |
| **اوپن سیٹ** | ہر پوائنٹ میں سیٹ میں ایک گیند ہوتی ہے | (0,1) ℝ ​​| میں کھلا ہے۔
| **بند سیٹ** | ایک کھلے سیٹ کی تکمیل | [0,1] ℝ | میں بند ہے۔
| **بندش** | سب سے چھوٹا بند سیٹ جس میں S | کی بندش (0,1) = [0,1] |
| **کومپیکٹ** | ہر کھلے کور کا ایک محدود ذیلی کور ہوتا ہے | ℝⁿ میں: بند اور جکڑے ہوئے (Heine-Borel) |
| **مکمل** | ہر کاچی ترتیب ایک دوسرے سے بدل جاتا ہے | ℝ مکمل ہے؛ ℚ نہیں ہے |

## یکساں کنورجنسی۔
افعال کا ایک سلسلہ (fₙ) دو طریقوں سے اکٹھا ہو سکتا ہے:
| قسم | تعریف | تسلسل کو محفوظ رکھتا ہے؟ |
|------|------------|----------------------|
| **نقطہ وار** | ∀x: fₙ(x) → f(x) | نہیں |
| **یونیفارم** | sup\|fₙ(x) − f(x)\| → 0 | جی ہاں |
**یکساں کنورجنسی** زیادہ مضبوط ہے: کنورجن کی شرح ہر جگہ یکساں ہے۔
**اہم نظریات:**
- مسلسل افعال کی یکساں حد مسلسل ہے۔
- ریمن انٹیگریبل فنکشنز کی یکساں حد ریمن انٹیگریبل ہے، اور حد کا انٹیگرل انٹیگرلز کی حد کے برابر ہے۔
- **Weierstrass M-test:** اگر |fₙ(x)| ≤ Mₙ تمام x اور ΣMₙ کنورجز کے لیے، پھر Σfₙ یکساں طور پر اکٹھا ہوتا ہے

## پیمائش کا نظریہ
** پیمائش کا نظریہ** لمبائی، رقبہ اور حجم کے تصورات کو عام کرتا ہے۔
### تعریف
سیٹ X پر ایک ** پیمائش** ایک فنکشن ہے μ: Σ → [0, ∞] (جہاں Σ ذیلی سیٹوں کا σ-الجبرا ہے) اطمینان بخش:
- μ(∅) = 0
- **قابل شمار اضافیت:** μ(∪ᵢ Aᵢ) = Σᵢ μ(Aᵢ) منقطع Aᵢ کے لیے
### Lebesgue پیمائش
ℝ پر **Lebesgue پیمائش** λ لمبائی کے تصور کو بڑھاتا ہے:
| سیٹ | Lebesgue پیمائش |
|-----------------------------------------|
| وقفہ [a,b] | b − a |
| سنگل پوائنٹ {x} | 0 |
| محدود سیٹ | 0 |
| قابل شمار سیٹ (مثلاً، ℚ) | 0 |
| کینٹر سیٹ | 0 (بے شمار لیکن پیمائش صفر) |
| [0,1] ∩ ℚ | 0 |
| [0,1] \ ℚ | 1 |
### کلیدی تصورات
| تصور | تعریف |
|---------|------------|
| **تقریبا ہر جگہ (یعنی)** | ایک پراپرٹی رکھتا ہے سوائے پیمائش کے صفر کے سیٹ کے |
| **قابل پیمائش فنکشن** | ہر کھلے سیٹ کی پری امیج قابل پیمائش ہے |
| **لیبیسگو انٹیگرل** | پیمائش تھیوری کا استعمال کرتے ہوئے انٹیگرل کی تعریف |
| **Lᵖ spaces** | محدود p-th پاور انٹیگرل کے ساتھ افعال کی خالی جگہیں |
### اہم کنورجنسی تھیورمز
یہ تھیومز اس لیے ہیں کہ لیبیسگ انضمام کو جدید ریاضی میں ترجیح دی جاتی ہے:
| تھیوریم | بیان |
|---------|------------|
| **مونوٹون کنورجنسی** | اگر fₙ ↑ f پوائنٹ وائز اور fₙ ≥ 0، تو ∫fₙ → ∫f |
| **غلبہ کنورجنسی** | اگر fₙ → f پوائنٹ وار اور \|fₙ\| ≤ جی (انٹیگریبل)، پھر ∫fₙ → ∫f |
| **فتو کی لما** | ∫lim inf fₙ ≤ lim inf ∫fₙ |
یہ نظریات حدود اور انضمام کے تبادلے کی اجازت دیتے ہیں — ایسی چیز جو عام طور پر ریمن کے انضمام میں ناکام ہوجاتی ہے۔

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| تجزیہ تصور | درخواست |
|------|---------------|
| حدود اور ہم آہنگی | یہ سمجھنا کہ جب تکراری الگورتھم (گریڈینٹ ڈیسنٹ، EM) آپس میں مل جاتے ہیں |
| تسلسل | بیک پروپیگیشن کے لیے ایکٹیویشن فنکشنز کو مسلسل ہونا چاہیے |
| تفریق | گریڈینٹ پر مبنی اصلاح کے لیے نقصان کے فرق کے افعال کی ضرورت ہوتی ہے۔
| مین ویلیو تھیورم | عددی قربت میں غلطی کی حد، کنورجنسی ثبوت |
| میٹرک اسپیس | کلسٹرنگ میں فاصلاتی افعال (k-means، DBSCAN)، قریبی پڑوسی |
| Compactness | بہترین حل کے لیے وجود کے ثبوت، محدود جہتی اصلاح میں ہین بوریل |
| یکساں کنورجنسی | اس بات کی گارنٹی دینا کہ قریب قریب (نیورل نیٹ ورک یونیورسل پروکسیمیشن) ہر جگہ کام کرتا ہے۔
| نظریہ پیمائش | جدید امکان کی بنیاد (امکان ایک پیمانہ ہے)، متوقع قدریں بطور Lebesgue integrals |
| Lebesgue انضمام | متوقع قدر E[X] = ∫X dP ایک Lebesgue integral |
| Lᵖ spaces | L¹ (LASSO)، L² (Ridge)، Lᵖ معمولات ریگولرائزیشن میں |
| غلبہ کنورجنسی | تخمینوں کی مستقل مزاجی کو ثابت کرنا، بایسیئن تخمینے میں حدود کا تبادلہ |

## خلاصہ
| موضوع | بنیادی خیال | کلیدی نتیجہ |
|---------|------------|------------|
| تسلسل | نمبروں کی ترتیب دی گئی فہرستیں | کنورجنسی، کاچی معیار، بولزانو-ویئرسٹراس |
| سیریز | لامحدود رقم | کنورجنسی ٹیسٹ، مطلق بمقابلہ مشروط |
| حدود | "قریب آنے" کے لیے سخت نقطہ نظر | ε-δ تعریف |
| تسلسل | کوئی وقفہ یا چھلانگ نہیں | IVT، ایکسٹریم ویلیو تھیورم |
| تفریق | تبدیلی کی فوری شرح | مین ویلیو تھیورم، ٹیلر کا تھیوریم |
| ریمن انٹیگریشن | منحنی خطوط کے نیچے کا علاقہ | کیلکولس کا بنیادی نظریہ |
| Lebesgue انٹیگریشن | پیمائش کے ذریعے انضمام | ڈومینیٹڈ/مونوٹون کنورجنسی |
| میٹرک اسپیسز | خلاصہ فاصلہ | کھلے/بند سیٹ، کمپیکٹ پن، مکمل |
| یکساں کنورجنسی | ہر جگہ ایک ہی شرح پر کنورجنسی | تسلسل اور انضمام کو محفوظ رکھتا ہے |
| پیمائش تھیوری | عمومی لمبائی/رقبہ/حجم | امکان کی بنیاد، Lebesgue پیمائش |
حقیقی تجزیہ وہ ہے جہاں ریاضی پروان چڑھتی ہے۔ یہ "قریب"، "مسلسل،" اور "علاقہ" کے بدیہی تصورات کو درست تعریفوں کے ساتھ بدل دیتا ہے جنہیں ثابت اور عام کیا جا سکتا ہے۔ ڈیٹا سائنسدانوں اور ایم ایل انجینئرز کے لیے، تجزیہ نظریاتی ضمانتیں فراہم کرتا ہے: تدریجی نزول کب اکٹھا ہوتا ہے؟ نقصان کا فعل کب اچھا برتا جاتا ہے؟ ہم حدود اور توقعات کا تبادلہ کب کر سکتے ہیں؟ یہ فلسفیانہ سوالات نہیں ہیں - یہ طے کرتے ہیں کہ آیا آپ کا الگورتھم کام کرتا ہے یا خاموشی سے ناکام ہوجاتا ہے۔
