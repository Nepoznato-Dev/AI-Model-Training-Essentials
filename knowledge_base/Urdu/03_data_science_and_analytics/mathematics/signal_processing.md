# سگنل پروسیسنگ
سگنل پروسیسنگ سگنلز کا تجزیہ، ترمیم، اور ترکیب کرنے کی سائنس ہے - وقت، جگہ، یا فریکوئنسی کے ساتھ مختلف جسمانی مقداروں کی نمائندگی۔ آڈیو، تصاویر، ویڈیو، سینسر ڈیٹا، دماغی لہریں، اسٹاک کی قیمتیں — یہ سب سگنلز ہیں۔ سگنل پروسیسنگ کے ریاضیاتی ٹولز (فورئیر ٹرانسفارمز، فلٹرز، سیمپلنگ تھیوری) مشین لرننگ، کمیونیکیشنز، میڈیکل امیجنگ اور ڈیٹا کے ساتھ کام کرنے والے عملی طور پر ہر شعبے کی بنیاد ہیں۔

### سگنل کی درجہ بندی
| قسم | تفصیل | مثال |
|------|---------------|---------|

## فوئیر ٹرانسفارم
**فورئیر ٹرانسفارم** ایک سگنل کو اس کے اجزاء کی فریکوئنسیوں میں تحلیل کرتا ہے۔
### مسلسل فوئیر ٹرانسفارم
X(f) = ∫_{−∞}^{∞} x(t) e^{−j2πft} dt
الٹا: x(t) = ∫_{−∞}^{∞} X(f) e^{j2πft} df
### فوئیر ٹرانسفارم پیئرز
| ٹائم ڈومین x(t) | فریکوئینسی ڈومین X(f) |
|--------------------------------------------
| مستطیل نبض | sinc فنکشن |
| sinc فنکشن | مستطیل نبض |
| Gaussian e^{−at²} | Gaussian (√(π/a))e^{−π²f²/a} |
| ڈیرک ڈیلٹا δ(t) | 1 (تمام تعدد) |
| پیچیدہ ایکسپونینشل e^{j2πf₀t} | δ(f − f₀) |
| Cosine cos(2πf₀t) | ½[δ(f−f₀) + δ(f+f₀)] |
### کلیدی خصوصیات
| پراپرٹی | ٹائم ڈومین | فریکوئنسی ڈومین |
|------------|---------------|-------------------|
| لکیریٹی | ax₁(t) + bx₂(t) | aX₁(f) + bX₂(f) |
| وقت کی تبدیلی | x(t − t₀) | X(f)e^{−j2πft₀} |
| فریکوئینسی شفٹ | x(t)e^{j2πf₀t} | X(f − f₀) |
| Convolution | x₁(t) ∗ x₂(t) | X₁(f) · X₂(f) |
| ضرب | x₁(t) · x₂(t) | X₁(f) ∗ X₂(f) |
| تفریق | dx/dt | j2πf X(f) |
| پارسیوال کا نظریہ | ∫\|x(t)\|² dt | ∫\|X(f)\|² df |
**Convolution theorem:** وقت میں Convolution = تعدد میں ضرب۔ یہ سب سے اہم خاصیت ہے - یہ مہنگے کنولوشن آپریشنز کو سستے ضرب میں بدل دیتی ہے۔
### ڈسکریٹ فوئیر ٹرانسفارم (DFT)
ایک ترتیب کے لیے x[0]، x[1]، ...، x[N−1]:
X[k] = Σ_{n=0}^{N−1} x[n] e^{−j2πkn/N}, k = 0, 1, ..., N−1
| پراپرٹی | قدر |
|------------|-------|
| ان پٹ | N اصلی یا پیچیدہ نمونے |
| آؤٹ پٹ | N پیچیدہ فریکوئنسی ڈبے |
| فریکوئنسی ریزولوشن | f_s/N (جہاں f_s نمونے لینے کی شرح ہے) |
| Nyquist تعدد | f_s/2 (زیادہ سے زیادہ قابل نمائندگی تعدد) |
| پیچیدگی | O(N²) براہ راست حساب |
### فاسٹ فوئیر ٹرانسفارم (FFT)
**FFT** O(N²) کی بجائے O(N log N) میں DFT کی گنتی کرتا ہے۔
| ن | O(N²) آپریشنز | O(N log N) آپریشنز | سپیڈ اپ |
|---|------|----------------------|---------|
| 1,024 | 1,048,576 | 10,240 | 102× |
| 1,048,576 | 1.1 × 10¹² | 20,971,520 | 52,428× |
FFT اب تک کی ایجاد کردہ سب سے اہم الگورتھم میں سے ایک ہے۔ یہ ریئل ٹائم آڈیو پروسیسنگ، امیج کمپریشن (JPEG)، وائرلیس کمیونیکیشن (OFDM)، اور سپیکٹرل تجزیہ کو قابل بناتا ہے۔

## لیپلیس ٹرانسفارم
**لیپلس ٹرانسفارم** غیر مستحکم سسٹمز اور عارضی تجزیہ کو سنبھالنے کے لیے فوئیر ٹرانسفارم کو بڑھاتا ہے۔
F(s) = ∫₀^∞ f(t) e^{−st} dt، جہاں s = σ + jω
### کامن لیپلیس ٹرانسفارمز
| f(t) | F(s) | کنورجنسی کا علاقہ |
|------|------|----------------------|
| δ(t) (تسلسل) | 1 | تمام s |
| u(t) (قدم) | 1/s | Re(s) > 0 |
| e^{−at}u(t) | 1/(s+a) | Re(s) > −a |
| tⁿu(t) | n!/s^{n+1} | Re(s) > 0 |
| sin(ωt)u(t) | ω/(s²+ω²) | Re(s) > 0 |
| cos(ωt)u(t) | s/(s²+ω²) | Re(s) > 0 |
### فوئیر ٹرانسفارم سے کنکشن
جب σ = 0 (s = jω)، لاپلیس ٹرانسفارم کم ہو کر فوئیر ٹرانسفارم ہو جاتا ہے۔ لاپلیس ٹرانسفارم ترقی/زوال (σ) کے بارے میں معلومات کو شامل کرکے مزید مکمل تصویر فراہم کرتا ہے۔
---

## زیڈ ٹرانسفارم
**Z-transform** لاپلیس ٹرانسفارم کے مجرد وقتی مساوی ہے۔
X(z) = Σ_{n=−∞}^{∞} x[n] z^{−n}
### عام Z-ٹرانسفارمز
| x[n] | X(z) | ROC |
|------|------|------|
| δ[n] | 1 | تمام z |
| u[n] (قدم) | z/(z−1) | \|z\| > 1 |
| aⁿu[n] | z/(z−a) | \|z\| > \|a\| |
| naⁿu[n] | az/(z−a)² | \|z\| > \|a\| |
| گناہ (ω₀n)u[n] | z sin(ω₀)/(z²−2z cos(ω₀)+1) | \|z\| > 1 |
### دیگر تبدیلیوں سے تعلق
| ٹرانسفارم | ڈومین | متغیر |
|------------|---------|------------|
| فوئیر | مسلسل تعدد | f یا ω |
| لاپلاس | پیچیدہ تعدد | s = σ + jω |
| زیڈ ٹرانسفارم | پیچیدہ تعدد (مجرد) | z = e^{sT} |
z-plane (|z| = 1) میں یونٹ کا دائرہ فوئیر ٹرانسفارم سے مساوی ہے۔

## فلٹرز
فلٹرز منتخب طور پر کچھ تعدد اجزاء کو پاس یا بلاک کرتے ہیں۔
### فلٹر کی اقسام
| قسم | پاس | بلاکس | درخواست |
|------|---------|---------|-------------|
| **کم پاس** | کم تعدد | اعلی تعدد | ہموار، اینٹی ایلیزنگ |
| **ہائی پاس** | اعلی تعدد | کم تعدد | کنارے کا پتہ لگانا، شور ہٹانا |
| **بینڈ پاس** | تعدد کی ایک رینج | حد سے باہر | چینل کا انتخاب (ریڈیو) |
| **بینڈ اسٹاپ (نشان)** | ایک رینج کے علاوہ سب کچھ | ایک مخصوص رینج | پاور لائن ہم ہٹانا |
### ایف آئی آر بمقابلہ آئی آئی آر فلٹرز
| پراپرٹی | FIR (Finite Impulse Response) | IIR (Infinite Impulse Response) |
|------------|--------------------------------------------------------------------------------------------
| تسلسل کا جواب | محدود مدت | لامحدود دورانیہ |
| استحکام | ہمیشہ مستحکم | غیر مستحکم ہو سکتا ہے |
| مرحلہ | بالکل لکیری ہو سکتا ہے | عام طور پر غیر خطی مرحلہ |
| تاثرات | نہیں | جی ہاں |
| حساب | مزید گتانک کی ضرورت ہے | ایک ہی رول آف کے لیے کم گتانک |
| ڈیزائن | ونڈونگ، پارکس میک کلیلن | بٹر ورتھ، چیبیشیو، بیضوی |
| ٹرانسفر فنکشن | H(z) = Σ bₖz⁻ᵏ | H(z) = Σ bₖz⁻ᵏ / (1 + Σ aₖz⁻ᵏ) |
### فلٹر ڈیزائن کی تفصیلات
| پیرامیٹر | تفصیل |
|------------|-------------|
| **پاس بینڈ** | تعدد کی حد جو کم سے کم نقصان کے ساتھ گزرنی چاہیے |
| **سٹاپ بینڈ** | تعدد کی حد جس کو کم کیا جانا چاہئے |
| **کٹ آف فریکوئنسی** | پاس بینڈ اور اسٹاپ بینڈ کے درمیان حد |
| **لہر** | پاس بینڈ (یا اسٹاپ بینڈ) میں تبدیلی |
| **رول آف** | کشندگی کی شرح (ڈی بی فی آکٹیو یا دہائی) |
| **ٹرانسیشن بینڈ** | پاس بینڈ اور اسٹاپ بینڈ کے درمیان علاقہ |
### عام فلٹر ڈیزائن
| ڈیزائن | خصوصیات | کیس استعمال کریں |
|---------|----------------|---------|
| **بٹر ورتھ** | زیادہ سے زیادہ فلیٹ پاس بینڈ، اعتدال پسند رول آف | عام مقصد |
| **چیبیشیو ٹائپ I** | پاس بینڈ میں لہر، اسٹیپر رول آف | جب رول آف معاملات |
| **چیبیشیو ٹائپ II** | سٹاپ بینڈ میں لہر، فلیٹ پاس بینڈ | جب پاس بینڈ فلیٹنس اہمیت رکھتا ہے |
| **بیضوی (Cauer)** | دونوں میں لہر، سب سے تیز رول آف | کم از کم آرڈر کی ضرورت ہے |
| **بیسل** | لکیری مرحلہ (زیادہ سے زیادہ فلیٹ گروپ میں تاخیر) | لہر کی شکل کو محفوظ کرنا |

## سیمپلنگ تھیوری
### Nyquist-Shannon سیمپلنگ تھیوریم
اگر نمونے لینے کی شرح زیادہ سے زیادہ فریکوئنسی سے دوگنا بڑھ جائے تو ایک مسلسل سگنل کو اس کے نمونوں سے بالکل دوبارہ بنایا جا سکتا ہے:
f_s > 2f_max
| مدت | تعریف |
|------|------------|
| **نمونے کی شرح** (f_s) | فی سیکنڈ نمونوں کی تعداد |
| **Nyquist ریٹ** | 2f_max (کم از کم نمونے لینے کی شرح) |
| **Nyquist تعدد** | f_s/2 (زیادہ سے زیادہ قابل نمائندگی تعدد) |
| **علامت** | جب f_s < 2f_max |
### نمونے لینے کے عام نرخ
| درخواست | شرح | Nyquist تعدد |
|---------------|------|-------------------|
| ٹیلی فون تقریر | 8 kHz | 4 kHz |
| آڈیو سی ڈی | 44.1 kHz | 22.05 kHz |
| پیشہ ورانہ آڈیو | 48 کلو ہرٹز | 24 کلو ہرٹز |
| ہائی ریزولوشن آڈیو | 96 kHz | 48 کلو ہرٹز |
| ویڈیو (30 ایف پی ایس) | 30 ہرٹز (دنیاوی) | 15 ہرٹج |
### اینٹی ایلائزنگ
نمونے لینے سے پہلے، ایک **اینٹی ایلیزنگ فلٹر** (کم پاس) الیاسنگ کو روکنے کے لیے f_s/2 سے اوپر کی فریکوئنسیوں کو ہٹاتا ہے۔

## کھڑکی
سگنل کے محدود حصے کا تجزیہ کرتے وقت، ہم واضح طور پر ایک مستطیل کھڑکی سے ضرب لگاتے ہیں، جس سے سپیکٹرل رساو ہوتا ہے۔ **ونڈو کے افعال** اس رساو کو کم کرتے ہیں۔
### عام ونڈوز
| کھڑکی | مین لوب کی چوڑائی | سائیڈ لاب لیول | کیس استعمال کریں |
|---------|----------------|------|---------|
| مستطیل | تنگ ترین | −13 dB | جب ریزولوشن سب سے زیادہ اہمیت رکھتا ہے |
| ہان | 2× مستطیل | −31 dB | عام مقصد |
| ہیمنگ | 2× مستطیل | −41 dB | قریب ترین سائیڈ لاب میں کمی |
| بلیک مین | 3× مستطیل | −58 dB | ہائی ڈائنامک رینج |
| قیصر | سایڈست | سایڈست (β کے ذریعے) | جب ٹریڈ آف ٹیون ایبل ہو |
### سپیکٹرل لیکیج
ونڈو کے ذریعہ سگنل کو ضرب دینا اس کے سپیکٹرم کو ونڈو کے سپیکٹرم کے ساتھ جوڑتا ہے۔ وسیع مین لابز فریکوئنسی ریزولوشن کو کم کرتے ہیں۔ نچلے حصے کے لاب رساو کو کم کرتے ہیں۔

## لہریں
**ویولٹس** چھوٹے، مقامی لہر نما فنکشنز ہیں جو ملٹی ریزولوشن سگنل تجزیہ کے لیے استعمال ہوتے ہیں۔
### ویولیٹ ٹرانسفارم
فوئیر ٹرانسفارم کے برعکس (جو عالمی فریکوئنسی کی معلومات فراہم کرتا ہے)، ویولیٹ ٹرانسفارم **وقت کی تعدد** لوکلائزیشن دیتا ہے۔
| ٹرانسفارم | وقت کی قرارداد | فریکوئینسی ریزولوشن |
|------------|----------------|---------|
| فوئیر | کوئی نہیں (عالمی) | بہترین |
| شارٹ ٹائم FT | فکسڈ (ونڈو کا سائز) | فکسڈ |
| ویولیٹ | متغیر (اعلی تعدد پر اچھا) | متغیر (کم تعدد پر اچھا) |
### عام ویولیٹ فیملیز
| خاندان | پراپرٹیز | درخواست |
|---------|------------|------------|
| **ہار** | سب سے آسان، منقطع | کنارے کا پتہ لگانے، فوری تجزیہ |
| **ڈوبیچیز** (dbN) | کومپیکٹ سپورٹ، N غائب ہونے والے لمحات | کمپریشن، denoising |
| **سیملیٹس** | تقریبا متوازی Daubechies | مرحلے کی تحریف میں کمی |
| **کوفلیٹ** | لمحے کے حالات کے لیے ڈیزائن کیا گیا | سگنل پروسیسنگ |
| **مورلیٹ** | Gaussian-windowed sinusoid | وقت کی تعدد کا تجزیہ |
| **میکسیکن ہیٹ** | Gaussian کا دوسرا مشتق | خصوصیت کا پتہ لگانا |
### ویولیٹس کی ایپلی کیشنز
| درخواست | ویولیٹ کس طرح مدد کرتے ہیں |
|----------------------------|-------------------|
| امیج کمپریشن (JPEG 2000) | کثیر ریزولوشن کی نمائندگی، کناروں کے لیے DCT سے بہتر |
| Denoising | تھریشولڈ چھوٹے ویولیٹ گتانک (سگنل بڑے گتانک میں ہے) |

| ای سی جی تجزیہ | QRS کمپلیکس کا پتہ لگانا، اریتھمیا کی درجہ بندی |

## مشین لرننگ اور ڈیٹا سائنس سے مطابقت
| سگنل پروسیسنگ کا تصور | درخواست |
|---------------|---------------|
| فوئیر ٹرانسفارم | آڈیو ایم ایل کے لیے سپیکٹرل خصوصیات، ٹائم سیریز کا فریکوئنسی ڈومین تجزیہ |
| FFT | CNNs میں تیز کنولیشن (سپیکٹرل کنوولوشن)، موثر ارتباط |
| Convolution تھیوریم | یہ سمجھنا کہ CNNs کیسے کام کرتے ہیں (وہ سیکھے ہوئے فلٹر ہیں) |
| فلٹرز | پری پروسیسنگ (ہموار کرنا، ڈینوائزنگ)، خصوصیت نکالنا |
| سیمپلنگ تھیوریم | امتیازی سلوک کو سمجھنا، سینسر کی شرحوں کا انتخاب، عرفیت سے گریز کرنا |
| کھڑکی | آڈیو ایم ایل (سپیکٹروگرام) کے لیے STFT، ٹائم فریکوئنسی تجزیہ |
| ویولیٹ | ٹائم سیریز، کمپریشن، ڈینوائزنگ کے لیے فیچر نکالنا |
| Laplace/Z-transform | روبوٹکس کے لیے کنٹرول تھیوری، نظام کے استحکام کو سمجھنا |
| سپیکٹرل تجزیہ | EEG/fMRI تجزیہ، وائبریشن مانیٹرنگ، پیشن گوئی کی دیکھ بھال |
| Nyquist کی شرح | ایم ایل پائپ لائنز کے لیے ڈیٹا اکٹھا کرنے کے مناسب نرخوں کا انتخاب کرنا |

## خلاصہ
| ٹول | ڈومین | کلیدی بصیرت |
|------|---------|------------|
| فوئیر ٹرانسفارم | وقت → تعدد | سگنلز سائنوسائڈز کے مجموعے ہیں |
| لاپلاس ٹرانسفارم | وقت → پیچیدہ تعدد | عارضی اور استحکام کو ہینڈل کرتا ہے |
| Z-Transform | مجرد وقت → پیچیدہ | ڈیجیٹل فلٹر تجزیہ اور ڈیزائن |
| FFT | موثر DFT حساب | O(N²) کی بجائے O(N log N) |
| فلٹرز | تعدد کا انتخاب | جس چیز کی آپ کو ضرورت ہے اسے پاس کریں، جو نہیں ہے اسے بلاک کریں |
| سیمپلنگ تھیوریم | مسلسل ↔ مجرد | کافی تیزی سے نمونہ، کچھ بھی نہیں کھو |
| کھڑکی | ٹائم فریکوئنسی ٹریڈ آف | بیلنس ریزولوشن اور رساو |
| ویولیٹ | ملٹی ریزولوشن تجزیہ | وقت اور تعدد دونوں میں مقامی |
سگنل پروسیسنگ اعداد و شمار کو سمجھنے، تجزیہ کرنے اور جوڑ توڑ کے لیے ریاضیاتی بنیاد فراہم کرتی ہے۔ ہر مشین لرننگ پائپ لائن جو ٹائم سیریز، آڈیو، امیجز، یا سینسر ڈیٹا کے ساتھ کام کرتی ہے واضح طور پر سگنل پروسیسنگ کے تصورات کا استعمال کرتی ہے۔ فوئیر ٹرانسفارم، خاص طور پر، کسی بھی ڈیٹا سائنسدان کے لیے حساب کتاب کے بعد سب سے اہم ریاضیاتی ٹول ہے۔
