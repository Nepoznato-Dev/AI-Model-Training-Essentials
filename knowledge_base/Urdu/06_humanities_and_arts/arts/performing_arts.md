# پرفارمنگ آرٹس
پرفارمنگ آرٹس — تھیٹر، فلم، رقص، اور موسیقی کی کارکردگی — وہ ہیں جہاں آرٹ سامعین کی زندہ موجودگی کو پورا کرتا ہے۔ دیوار پر پینٹنگ یا شیلف پر کتاب کے برعکس، کارکردگی حقیقی وقت میں سامنے آتی ہے، جس سے فنکار اور تماشائی کے درمیان ایک مشترکہ تجربہ پیدا ہوتا ہے جو ہزاروں سالوں سے انسانی ثقافت میں مرکزی حیثیت رکھتا ہے۔
---

## تھیٹر
تھیٹر 2,500 سالوں سے انسانیت کی کہانی سنانے کا مرحلہ رہا ہے۔ قدیم یونان کے ایمفی تھیٹرز سے لے کر براڈوے اور ویسٹ اینڈ تک، لائیو پرفارمنس فنکارانہ اظہار کی سب سے طاقتور شکلوں میں سے ایک ہے۔
### ڈرامائی شکلیں۔
| قسم | تفصیل | قابل ذکر مثالیں |
|------|----------------------------|----------------|
| **سانحہ** | سنجیدہ موضوعات، مرکزی کردار کا زوال | یونانی سانحات، شیکسپیئر کا *ہیملٹ* |
| **مزاحیہ** | مزاحیہ حالات، خوش کن انجام | شیکسپیئر کی مزاحیہ، آسکر وائلڈ |
| **ٹریجی کامیڈی** | المناک اور مزاحیہ عناصر کو ملا دیتا ہے | *گوڈوٹ کا انتظار* (بیکیٹ) |
| **میوزیکل تھیٹر** | گانے، رقص، ڈائیلاگ مربوط | *ہیملٹن*، *لیس Misérables* |
| **اوپیرا** | مکمل طور پر گایا ڈرامائی کام | *La Bohème* (Puccini)، *Carmen* (Bizet) |
| **Avant-Garde** | غیر روایتی شکلیں، سامعین کی شرکت | تجرباتی تھیٹر |
| **میلو ڈرامہ** | مبالغہ آمیز کردار، سنسنی خیز پلاٹ | 19ویں صدی کے اسٹیج میلو ڈرامے |
| **فرس** | جسمانی مزاح، مضحکہ خیز حالات | Feydeau، *شور بند* (Frayn) |
### کلیدی ڈرامہ نگار
| دور | ڈرامہ نگار |
|------|------------|
| **کلاسیکی** | Sophocles, Euripides, Aristophanes |
| **الزبیتھن / جیکوبین** | شیکسپیئر، مارلو، جانسن |
| **جدید** | Ibsen، Chekhov، Strindberg |
| **20ویں صدی** | آرتھر ملر، ٹینیسی ولیمز، سیموئیل بیکٹ، اگست ولسن |
| **ہم عصر** | لن مینوئل مرانڈا، سوزان لوری پارکس، ٹام اسٹاپپارڈ |
### دنیا بھر میں تھیٹر کی روایات
| روایت | اصل | خصوصیات |
|------------|---------|----------------|
| **نہیں** | جاپان | نقاب پوش اداکار، سست طرز کی حرکت، روحانی موضوعات |
| **کابوکی** | جاپان | وسیع ملبوسات، ڈرامائی میک اپ، تاریخی کہانیاں |
| **بنراکو** | جاپان | نظر آنے والے کٹھ پتلیوں کے ساتھ کٹھ پتلی تھیٹر |
| **بیجنگ اوپیرا** | چین | گانا، تلاوت، ایکروبیٹکس، مارشل آرٹس |
| **کتھاکلی** | انڈیا | وسیع میک اپ اور ملبوسات کے ساتھ ڈانس ڈرامہ |
| **Commedia dell'Arte** | اٹلی | اصلاحی، اسٹاک کردار، نقاب پوش اداکار |
| **پیکنگ اوپیرا** | چین | اسٹائلائزڈ حرکت، علامتی اشارے |

## فلم
سینما آرٹ کی سب سے چھوٹی شکل ہے - بمشکل ایک صدی سے زیادہ پرانی - پھر بھی یہ سب سے زیادہ استعمال ہونے والا اور ثقافتی طور پر بااثر بن گیا ہے۔
### فلمی تحریکیں۔
| تحریک | مدت | خصوصیات | کلیدی فلمیں / ہدایت کار |
|------------|---------|----------------|----------------------|
| **جرمن اظہار پسندی** | 1920 | مسخ شدہ بصری، نفسیاتی موضوعات | *Nosferatu* (Murnau)، *Metropolis* (Lang) |
| **سوویت مونٹیج** | 1920 - 1930 | معنی کے طور پر ترمیم کرنا، شاٹس کا تصادم | آئزن اسٹائن کی *بیٹل شپ پوٹیمکن* |
| **اطالوی نیورئیلزم** | 1940 - 1950 | ورکنگ کلاس کی کہانیاں، لوکیشن شوٹنگ | *سائیکل چور* (ڈی سیکا) |
| **فرانسیسی نئی لہر** | 1950 - 1960 | اختراعی ترمیم، مصنف نظریہ | Godard, Truffaut |
| **نیو ہالی ووڈ** | 1960 - 1980 | ڈائریکٹر پر مبنی، بالغ تھیمز | کوپولا، سکورسی، کبرک |
| **نیا جرمن سنیما** | 1960 - 1970 | سیاسی، خودکار | فاس بائنڈر، وینڈرز، ہرزوگ |
| **Dogme 95** | 1990 کی دہائی | مرصع اصول، قدرتی روشنی | وان ٹریر، ونٹربرگ |
| **نئی لہر کی نقل و حرکت** | 2000 - موجودہ | عالمی سنیما تنوع | نولی ووڈ، کورین نیو ویو |
### فلم کے اہم تصورات
| تصور | تفصیل |
|---------|---------------|
| **Mise-en-scène** | ہر چیز جو فریم کے اندر رکھی جاتی ہے — سیٹ، ملبوسات، لائٹنگ، اداکار |
| **مونٹیج** | تدوین کی تکنیک جو شاٹس کے جوکسٹاپوزیشن کے ذریعے معنی پیدا کرتی ہے |
| **سینماٹوگرافی** | کیمرے کے کام کا فن - فریمنگ، حرکت، روشنی، لینس کا انتخاب |
| **آٹور تھیوری** | ہدایت کار ایک فلم کے "مصنف" کے طور پر، ایک قابل شناخت ذاتی انداز کے ساتھ |
| **نوع** | فلم کے زمرے: ڈرامہ، کامیڈی، ہارر، سائنس فائی، ویسٹرن، ڈاکومنٹری وغیرہ۔
| **صوتی ڈیزائن** | تمام آڈیو عناصر: مکالمہ، موسیقی، صوتی اثرات، خاموشی |
### بڑی فلم انڈسٹریز
| صنعت | ملک | کے لیے قابل ذکر |
|------------|---------|------------|
| **ہالی ووڈ** | USA | بلاک بسٹرز، اسٹوڈیو سسٹم، عالمی رسائی |
| **بالی ووڈ** | انڈیا | موسیقی کی داستانیں، بڑے پیمانے پر پیداوار |
| **نولی ووڈ** | نائیجیریا | تیزی سے پیداوار، براہ راست سے ویڈیو |
| **کینز / یورپی** | فرانس / یورپ | Auteur سنیما، فلمی میلے |
| **کورین سنیما** | جنوبی کوریا | انواع ملاوٹ، سماجی تبصرہ |
| **اینیمی** | جاپان | متحرک فلمیں اور سیریز |

## ڈانس
رقص انسانی حرکت کا فن ہے، اکثر (لیکن ہمیشہ نہیں) موسیقی پر سیٹ کیا جاتا ہے۔ یہ رسم، تفریح، اور اعلیٰ فن پر محیط ہے:
| فارم | اصل | خصوصیات |
|------|---------|----------------|
| **بیلے** | نشاۃ ثانیہ اٹلی / فرانس | کوڈفائیڈ تکنیک، پوائنٹ کام، بیانیہ |
| **ہم عصر رقص** | 20 ویں سی. امریکہ/یورپ | بیلے کی سختی کو مسترد کرتا ہے، فرش کا کام، اصلاح |
| **تھپتھپائیں** | USA (افریقی امریکن + آئرش جڑیں) | ٹککر کے طور پر ردھمک فٹ ورک |
| **فلیمینکو** | سپین (اندلس) | گٹار، گانا، ٹکرانے والا فٹ ورک، جذباتی شدت |
| **ہپ ہاپ / بریک ڈانس** | USA (Bronx, 1970s) | بی بوائےنگ، پاپنگ، لاکنگ، لڑائیاں |
| **کلاسیکل انڈین ڈانس** | انڈیا | بھرتناٹیم، کتھک، اوڈیسی — اشارے کے ذریعے کہانی سنانا |
| **بال روم** | یورپ | شراکت دار رقص: والٹز، ٹینگو، فاکسٹروٹ |
| **لوک/روایتی** | دنیا بھر میں | ثقافتی تقریبات، رسومات، برادری |

## یہ کیوں اہم ہے۔
پرفارمنگ آرٹس وہ ہیں جہاں ثقافت حقیقی وقت میں زندہ ہوتی ہے۔ تھیٹر ہمیں دو گھنٹے کے لیے دوسرے شخص کے جوتے میں رکھ کر ہمدردی سکھاتا ہے۔ فلم ہمیں تاریخ کا گواہ بنا سکتی ہے، یا ہمیں تصوراتی دنیا تک پہنچا سکتی ہے۔ رقص وہ بیان کرتا ہے جو الفاظ نہیں کر سکتے۔ ایک ساتھ، یہ آرٹ کی شکلیں کنکشن، عکاسی، اور تبدیلی کے لیے انسانیت کے سب سے طاقتور ٹولز کی نمائندگی کرتی ہیں۔
