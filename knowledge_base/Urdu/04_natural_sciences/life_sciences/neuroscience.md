# عصبی سائنس
نیورو سائنس اعصابی نظام کا مطالعہ ہے - دماغ، ریڑھ کی ہڈی، اور تمام اعصاب جو انہیں جسم سے جوڑتے ہیں۔ یہ متعدد سطحوں پر محیط ہے: مالیکیولز اور جینز سے لے کر انفرادی نیورانز اور سینیپس تک، سرکٹس اور دماغی علاقوں تک، رویے، ادراک اور شعور تک۔ دماغ معلوم کائنات کا سب سے پیچیدہ ڈھانچہ ہے، جس میں تقریباً 86 بلین نیورونز ہیں جو کھربوں Synapses سے جڑے ہوئے ہیں، اور یہ سمجھنا کہ یہ کیسے کام کرتا ہے سائنس کے بڑے چیلنجز میں سے ایک ہے۔
---

## نیوران
### نیوران کے حصے
| جزو | فنکشن |
|------------|----------|
| **ڈینڈرائٹس** | دوسرے نیوران سے سگنل وصول کریں؛ برانچ نما ایکسٹینشنز |
| **خلیہ کا جسم (سوما)** | آنے والے سگنلز کو مربوط کرتا ہے۔ نیوکلئس پر مشتمل ہے |
| **ایکسن** | لمبا ریشہ جو سوما سے دور برقی سگنلز (ایکشن پوٹینشل) منتقل کرتا ہے۔
| **مائلین میان** | محور کے ارد گرد موصل پرت؛ سگنل ٹرانسمیشن کو تیز کرتا ہے |
| **رنویر کے نوڈس** | مائیلین میں خلاء؛ نمکین ترسیل کی اجازت دیں (نوڈس کے درمیان سگنل چھلانگ) |
| **ایکسن ٹرمینلز (Synaptic boutons)** | Synapse میں نیورو ٹرانسمیٹر جاری کریں |
### نیوران کی اقسام
| قسم | سمت | فنکشن |
|------|------------|---------|
| ** حسی (افسرنٹ)** | جسم → دماغ | حواس سے معلومات لے جائیں (ٹچ، درجہ حرارت، درد، وژن، وغیرہ) |
| **موٹر (Efferent)** | دماغ → جسم | پٹھوں اور غدود کو کنٹرول کریں |
| **انٹرنیورون** | CNS کے اندر | نیوران کو دوسرے نیوران سے جوڑیں؛ زیادہ تر نیوران انٹرنیوران ہیں |

## نیوران کیسے بات چیت کرتے ہیں۔
### ایکشن پوٹینشل
| مرحلہ | تفصیل |
|---------|---------------|
| **آرام کی صلاحیت** | نیوران ~-70 mV پر ہے۔ سوڈیم پوٹاشیم پمپ آئن توازن کو برقرار رکھتا ہے |
| **ڈیپولائزیشن** | محرک سوڈیم چینلز کو کھولتا ہے؛ Na+ میں جلدی جھلی کی صلاحیت میں اضافہ |
| **تھریشولڈ** | اگر پوٹینشل ~-55 mV تک پہنچ جائے تو ایک ایکشن پوٹینشل فائر (سب یا کچھ بھی نہیں) |
| **بڑھتا ہوا مرحلہ** | وولٹیج گیٹڈ سوڈیم چینلز کھلے؛ ممکنہ اضافہ ~+40 mV |
| **گرنے کا مرحلہ** | سوڈیم چینلز بند؛ پوٹاشیم چینلز کھلے؛ K+ باہر نکلتا ہے۔ ممکنہ قطرے |
| **انڈر شوٹ (ہائپر پولرائزیشن)** | ممکنہ طور پر آرام کی سطح سے نیچے گرتا ہے |
| **ریفریکٹری پیریڈ** | نیوران فوری طور پر دوبارہ فائر نہیں کر سکتا۔ یک طرفہ پھیلاؤ کو یقینی بناتا ہے |
### Synapse
| جزو | کردار |
|------------|------|
| **پری سینیپٹک نیوران** | سگنل بھیجتا ہے؛ نیورو ٹرانسمیٹر کے ساتھ synaptic vesicles پر مشتمل ہے |
| **Synaptic درار** | نیوران کے درمیان چھوٹا فاصلہ (~20 nm) |
| **پوسٹسی نیپٹک نیوران** | سگنل وصول کرتا ہے؛ ریسیپٹر پروٹین ہے |
| **نیورو ٹرانسمیٹر** | کیمیکل میسنجر جو Synapse کو پار کرتے ہیں |
| **رسیپٹرز** | نیورو ٹرانسمیٹر باندھنا؛ آئن چینلز کھولیں یا دوسرے میسنجر کیسکیڈز کو متحرک کریں |

## کلیدی نیورو ٹرانسمیٹر
| نیورو ٹرانسمیٹر | فنکشن | متعلقہ شرائط |
|-------------------|------------|
| **گلوٹامیٹ** | اہم حوصلہ افزائی نیورو ٹرانسمیٹر؛ سیکھنا میموری | اضافی → excitotoxicity (فالج، نیوروڈیجنریشن) |
| **GABA** | اہم روکنا نیورو ٹرانسمیٹر؛ اعصابی سرگرمی کو کم کرتا ہے | خسارہ → بے چینی، مرگی |
| **ڈوپامائن** | انعام؛ حوصلہ افزائی موٹر کنٹرول؛ توجہ | خسارہ → پارکنسنز؛ اضافی → شیزوفرینیا |
| **سیروٹونن** | مزاج؛ نیند بھوک ہاضمہ | خسارہ → ڈپریشن، اضطراب |
| **Acetylcholine** | پٹھوں کی ایکٹیویشن؛ سیکھنا میموری | خسارہ → الزائمر کی بیماری |
| **نورپائنفرین** | حوصلہ افزائی؛ چوکسی کشیدگی کا جواب | بے ضابطگی → ADHD؛ ڈپریشن |
| **اینڈورفنز** | درد سے نجات؛ خوشی | ورزش سے متاثر ریلیز ("رنرز ہائی") |
---

## دماغ کی ساخت
### دماغ کے بڑے علاقے
| علاقہ | فنکشن |
|---------|---------|
| **دماغی پرانتستا** | اعلی ادراک؛ فرنٹل، parietal، دنیاوی، occipital lobes میں تقسیم |
| **فرنٹل لاب** | منصوبہ بندی فیصلہ سازی؛ شخصیت؛ رضاکارانہ تحریک (موٹر کارٹیکس) |
| **پیریٹل لوب** | حسی پروسیسنگ؛ مقامی بیداری؛ نیویگیشن |
| **ٹیمپورل لاب** | سماعت؛ زبان کی سمجھ؛ میموری (ہپپوکیمپس) |
| **Occipital lobe** | بصری پروسیسنگ |
| **سیریبیلم** | موٹر کوآرڈینیشن؛ توازن؛ موٹر سیکھنے؛ کچھ علمی افعال |
| **دماغی نظام** | اہم افعال: سانس لینے؛ دل کی شرح؛ نیند جاگنے کا چکر |
| **تھیلامس** | حسی ریلے اسٹیشن؛ روٹس سگنلز کو مناسب cortical علاقوں تک |
| **ہائپوتھیلمس** | ہومیوسٹاسس؛ ہارمون ریگولیشن؛ بھوک پیاس سرکیڈین تال |
### لمبک سسٹم
| ساخت | فنکشن |
|------------|----------|
| **امیگڈالا** | جذباتی پروسیسنگ؛ خوف خطرے کا پتہ لگانا؛ جذباتی یادداشت |
| **ہپپوکیمپس** | یادداشت کی تشکیل؛ مقامی نیویگیشن؛ مختصر مدت کو طویل مدتی میموری میں تبدیل کرتا ہے |
| **بیسل گینگلیا** | عادت کی تشکیل؛ اجر سیکھنے؛ موٹر کنٹرول |
| **Cingulate cortex** | غلطی کا پتہ لگانا؛ ہمدردی تسلسل کنٹرول؛ جذبات کا ضابطہ |
| **نیوکلئس ایکمبنس** | انعامی سرکٹ؛ خوشی لت |

## علمی نیورو سائنس
### کلیدی علمی افعال اور ان کے دماغی علاقے
| فنکشن | بنیادی دماغی علاقے |
|------------|-------------------|
| **توجہ** | Prefrontal cortex; parietal پرانتستا؛ تھیلامس |
| ** ورکنگ میموری** | Prefrontal cortex; parietal cortex |
| **طویل مدتی یادداشت** | ہپپوکیمپس (تشکیل)؛ پرانتستا (اسٹوریج) |
| **زبان** | بروکا کا علاقہ (پیداوار)؛ ورنک کا علاقہ (فہم) |
| **جذبات کا ضابطہ** | Prefrontal cortex; amygdala وینٹرومیڈیل پی ایف سی |
| **فیصلہ سازی** | Prefrontal cortex; orbitofrontal پرانتستا؛ سٹرائٹم |
| **بصری پروسیسنگ** | Occipital lobe → ventral stream ("what") اور ڈورسل اسٹریم ("جہاں") |
| **موٹر کنٹرول** | موٹر کارٹیکس؛ سیریبیلم بیسل گینگلیا |
### دماغ کی لہریں۔
| لہر | تعدد | ایسوسی ایٹڈ اسٹیٹ |
|------|------------|-----------------|
| **ڈیلٹا** | 0.5–4 ہرٹز | گہری نیند |
| **تھیٹا** | 4–8 ہرٹز | ہلکی نیند؛ مراقبہ غنودگی |
| **الفا** | 8–13 ہرٹز | آرام سے بیداری؛ آنکھیں بند |
| **بیٹا** | 13–30 ہرٹز | فعال سوچ؛ توجہ مرکوز چوکسی |
| **گاما** | 30–100 ہرٹز | اعلی ادراک؛ پابند شعور |

## نیوروپلاسٹیٹی
| قسم | تفصیل | مثال |
|------|---------------|---------|
| **Synaptic پلاسٹکٹی** | Synapses کی طاقت سرگرمی کے ساتھ بدل جاتی ہے | طویل مدتی صلاحیت (LTP)؛ طویل مدتی ڈپریشن (LTD) |
| **ساختی پلاسٹکٹی** | نیوران نئے ڈینڈرائٹس یا محور اگاتے ہیں | نئی مہارتیں سیکھنا؛ چوٹ سے صحت یابی |
| **کارٹیکل ری میپنگ** | دماغی علاقے دوبارہ تفویض افعال | نابینا افراد کی بصری پرانتستا ٹچ اور آواز |
| **نیوروجنسیس** | نئے نیوران پیدا ہوتے ہیں | ہپپوکیمپس میں ہوتا ہے؛ ورزش اور سیکھنے سے حوصلہ افزائی |

## تحقیق کے طریقے
| طریقہ | یہ کیا پیمائش کرتا ہے | قرارداد |
|---------|------|------------|
| **fMRI** | خون میں آکسیجن کی سطح (بولڈ سگنل) → دماغی سرگرمی | اچھا مقامی (~1 ملی میٹر)؛ ناقص وقتی (~1 s) |
| **EEG** | کھوپڑی سے برقی سرگرمی | بہترین وقتی (~1 ms)؛ غریب مقامی |
| **MEG** | عصبی سرگرمی سے مقناطیسی میدان | اچھا وقتی اور مقامی |
| **PET** | تابکار ٹریسر → میٹابولک سرگرمی | اعتدال پسند مقامی اور وقتی |
| **TMS** | مقناطیسی دالیں → عارضی طور پر دماغ کے علاقے میں خلل ڈالتی ہیں | وجہ ثبوت؛ محدود گہرائی |
| **سنگل یونٹ کی ریکارڈنگ** | انفرادی نیوران کی برقی سرگرمی | سنگل سیل؛ ناگوار زیادہ تر جانوروں کی تحقیق |
| **آپٹوجنیٹکس** | روشنی سے متحرک نیوران | عین مطابق کنٹرول؛ جانوروں کی تحقیق |
| **DTI** (ڈفیوژن ٹینسر امیجنگ) | سفید مادے کے راستے | کنیکٹیویٹی میپنگ |

## اعصابی اور نفسیاتی امراض
| خرابی | متاثرہ نظام | اہم خصوصیات |
|------------|----------------|---------------|
| **الزائمر** | پرانتستا; ہپپوکیمپس | یادداشت کا نقصان؛ amyloid تختیوں؛ tau tangles |
| **پارکنسنز** | Substantia nigra; بیسل گینگلیا | تھرتھراہٹ؛ سختی ڈوپامائن نیوران نقصان |
| **مرگی** | دماغی پرانتستا | بار بار دورے؛ غیر معمولی برقی سرگرمی |
| **ایک سے زیادہ سکلیروسیس** | مائیلین میان (CNS) | ڈیمیلینیشن؛ رکاوٹ سگنل ٹرانسمیشن |
| **ڈپریشن** | Prefrontal cortex; limbic نظام | مسلسل کم موڈ؛ نیورو ٹرانسمیٹر عدم توازن |
| **شیزوفرینیا** | ایک سے زیادہ علاقے | ہیلوسینیشنز وہم dopamine dysregulation |
| **ALS** | موٹر نیوران | ترقی پسند پٹھوں کی کمزوری؛ موٹر نیوران کی موت |

## خلاصہ
نیورو سائنس ہر سطح پر اعصابی نظام کا مطالعہ کرتی ہے - آئن چینلز کے مالیکیولر میکانزم سے لے کر شعور کے موضوعی تجربے تک۔ نیوران برقی ایکشن پوٹینشل اور کیمیکل synapses کے ذریعے بات چیت کرتے ہیں، نیورو ٹرانسمیٹر جیسے گلوٹامیٹ، GABA، dopamine، اور serotonin کا ​​استعمال کرتے ہوئے۔ دماغ کو مخصوص علاقوں میں منظم کیا جاتا ہے: اعلی ادراک کے لیے پرانتستا، جذبات اور یادداشت کے لیے لمبک نظام، ہم آہنگی کے لیے سیریبیلم۔ نیوروپلاسٹی کا مطلب ہے کہ دماغ زندگی بھر اپنے آپ کو دوبارہ جوڑ سکتا ہے۔ تحقیق کے طریقے ایف ایم آر آئی (اچھی مقامی ریزولیوشن) سے لے کر ای ای جی (اچھی وقتی ریزولیوشن) سے لے کر اوپٹوجنیٹکس (پرائس کازل کنٹرول) تک ہیں۔ دماغ کو سمجھنا سائنس کا سب سے مشکل مسئلہ ہے - یہ واحد عضو ہے جو خود مطالعہ کرتا ہے۔
