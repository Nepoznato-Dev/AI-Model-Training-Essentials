# Nauki humanistyczne i artystyczne
Ustrukturyzowany zbiór dokumentów referencyjnych obejmujących historię, sztukę, język, filozofię, psychologię i religię — podstawowe dyscypliny humanistyczne, które zapewniają kontekst dla zrozumienia ludzkiej cywilizacji, twórczej ekspresji i krytycznego myślenia.
