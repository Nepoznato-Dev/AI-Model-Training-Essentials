## 📝 Współtworzenie

Podczas dodawania lub modyfikowania treści:

1. **Postępuj zgodnie z przewodnikiem stylu:**
   - Używaj `#` tylko dla tytułu pliku
   - Używaj `##` dla głównych sekcji
   - Używaj `###` dla podsekcji
   - Używaj `-` dla list nieuporządkowanych
   - Dołącz podświetlanie składni w blokach kodu

2. **Dodaj metadane** (frontmatter YAML):
```yaml
---
title: "Tytuł Pliku"
description: "Krótki opis"
topics: [temat1, temat2, temat3]
difficulty: beginner|intermediate|advanced
last_updated: YYYY-MM-DD
---
```

3. **Dołącz cytaty** dla twierdzeń faktograficznych
4. **Dodaj odnośniki krzyżowe** do powiązanych plików
5. **Zaktualizuj ten README** jeśli dodajesz nowe pliki
