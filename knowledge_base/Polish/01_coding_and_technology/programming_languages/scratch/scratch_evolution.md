# Scratch — historia wersji i ewolucja
## Oś czasu
| Wersja | Rok | Kluczowy motyw |
|--------|------|-----------|
| Przed zgrzytem | 2003 | Formularze zespołu Scratch w MIT Media Lab |
| Scratch 1.0 | 2007 | **Pierwsze wydanie** — programy wizualne dla dzieci |
| Scratch 1.4 | 2009 | Poprawiona grafika, więcej bloków |
| Scratch 2.0 | 2013 | **Główny**: edytor internetowy, zmienne w chmurze, plecak |
| Scratch 3.0 | 2019 | **Główne**: Całkowite przepisanie (HTML5/JS), rozszerzenia, pióro |
| Scratch 3.x | 2019–25 | Wykrywanie wideo, zamiana tekstu na mowę, tłumaczenie, micro:bit |
| Scratch Jr. | 2014 | Wersja uproszczona dla młodszych dzieci (5-7 lat) |
| Scratch Pulpit | 2020 | Edytor offline (oparty na elektronice) |
## Główne kamienie milowe
### Początki (2003–2006)
- **2003**: Grupa Lifelong Kindergarten z MIT Media Lab rozpoczyna prace nad programem Scratch
- Prowadzony przez Mitchela Resnicka
- **Cel**: Nauczanie dzieci programowania poprzez bloki wizualne
Zainspirowany: Logo (Seymour Papert), Logo Lego, Squeak Etoys
- Nazwa: „Scratch” — od DJ-a skreczującego (łączenie multimediów)
### Scratch 1.0 (2007)
- **2007**: Pierwsze publiczne wydanie
- Programowanie blokowe metodą „przeciągnij i upuść”.
- Projekty oparte na sprite'ach (postacie, animacje)
- Dźwięk, grafika, animacja
- Wbudowany pisk (Smalltalk)
- **Docelowa**: Wiek 8-16 lat, ale dostosowany znacznie szerzej
### Scratch 1.4 (2009)
- Poprawione renderowanie grafiki
- Więcej bibliotek sprite'ów
- Lepsze wsparcie dźwięku
- Ostatnia wersja zbudowana na Squeaku
### Scratch 2.0 (2013)
- **Kompletny edytor internetowy** — działa w przeglądarce
- Zmienne chmurowe — udostępniaj dane pomiędzy projektami
- Plecak — udostępniaj duszki/skrypty pomiędzy projektami
- Niestandardowe bloki (takie jak funkcje)
- Wbudowany ActionScript 3 (Flash)
- Funkcje społecznościowe: remiksowanie, udostępnianie, komentowanie
### Scratch 3.0 (2019)
- **Całkowite przepisanie** — HTML5/JavaScript (bez Flash)
- Działa na tabletach, telefonach i Chromebookach
- **Rozszerzenia**:
  - Długopis (rysunek)
  - Wykrywanie wideo (kamera)
  - Tekst na mowę
  - Tłumacz (Tłumacz Google)
  - micro:bit (sprzęt)
  - LEGO Mindstorms EV3
  - WeDo 2.0
- Ulepszenia edytora dźwięku
- Nowy edytor farb (wektor + bitmapa)
- Plecak, zachowane zmienne w chmurze
### Scratch Desktop i nie tylko (2020 – obecnie)
- **2020**: Scratch Desktop — edytor offline (oparty na elektronice)
- Dalszy rozwój rozszerzeń
- Rozszerzenia AI/ML (stworzone przez społeczność)
- Integracja z obliczeniami fizycznymi (micro:bit, Arduino)
## Ewolucja kategorii bloków
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## Nauczane koncepcje programowania
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## Kluczowe zasady projektowania
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```

## Wpływ i przyjęcie
```
2007: Scratch 1.0 released
2009: 1 million projects shared
2013: Scratch 2.0 — web-based
2015: 10 million registered users
2019: Scratch 3.0 — HTML5, 50+ million users
2020: Scratch Desktop — offline access
2023: 100+ million registered users
2025: Scratch is the #1 introductory programming language worldwide
       Used in: 200+ countries, schools, libraries, after-school programs
       Translated into 70+ languages
       100M+ projects created on scratch.mit.edu
       Scratch Jr. for ages 5-7 (iPad only)
       Community: remix culture, creative coding, computational thinking
```
