# COBOL — typowe błędy i anty-wzorce
Ten dokument kataloguje najczęstsze błędy, pułapki i antywzorce w języku COBOL wraz z poprawkami.
---

## 1. Nieużywanie nazw warunków składających się z 88 poziomów
```cobol
* ❌ WRONG — magic numbers
01  STATUS-CODE     PIC 9.
    88  STATUS-ACTIVE   VALUE 1.
    88  STATUS-INACTIVE VALUE 2.

IF STATUS-CODE = 1  * what does 1 mean?
```

```cobol
* ✅ CORRECT — use 88-level for readability
01  STATUS-CODE     PIC 9.
    88  STATUS-ACTIVE   VALUE 1.
    88  STATUS-INACTIVE VALUE 2.

IF STATUS-ACTIVE
    PERFORM PROCESS-RECORD
END-IF
```

---

## 2. Przepełnienie numeryczne
```cobol
* ❌ WRONG — field too small
01  TOTAL    PIC 9(4).  * max 9999
COMPUTE TOTAL = A + B.   * silent truncation if > 9999

* ✅ CORRECT — adequate size or check ON SIZE ERROR
01  TOTAL    PIC 9(10).
COMPUTE TOTAL = A + B
    ON SIZE ERROR
        DISPLAY "Overflow!"
END-COMPUTE
```

---

## 3. Brak inicjowania zmiennych
```cobol
* ❌ WRONG — uninitialized data
01  COUNTER  PIC 9(5).
* contains garbage from previous run

* ✅ CORRECT — VALUE clause
01  COUNTER  PIC 9(5) VALUE ZERO.
```

---

## 4. DZIAŁAJ bez wyraźnych ograniczeń
```cobol
* ❌ WRONG — unbounded PERFORM
PERFORM PROCESS-RECORD UNTIL EOF-FLAG = 'Y'.
* if EOF-FLAG never set, infinite loop

* ✅ CORRECT — bounded PERFORM
PERFORM PROCESS-RECORD
    VARYING I FROM 1 BY 1
    UNTIL I > MAX-RECORDS
END-PERFORM
```

---

## 5. Nieużywanie nowoczesnych funkcji języka COBOL
```cobol
* ❌ WRONG — old-style COBOL
MOVE SPACES TO WS-NAME.
IF WS-NAME = SPACES
    DISPLAY "EMPTY"
END-IF.

* ✅ CORRECT — modern COBOL (2002+)
IF FUNCTION TRIM(WS-NAME) = ""
    DISPLAY "EMPTY"
END-IF
```

---

## Streszczenie
Pełna składnia języka COBOL ukrywa pułapki: magiczne liczby bez 88-poziomowych nazw warunków, przepełnienie numeryczne z powodu zbyt małych klauzul PIC, niezainicjowane zmienne i nieograniczone pętle PERFORM. Nowoczesny COBOL (2002+) dodaje FUNCTION TRIM, inline PERFORM i inne ulepszenia. Metoda COBOL jest następująca: użyj 88-poziomowych nazw warunków, sprawdź BŁĄD ROZMIARU, zainicjuj wartością WARTOŚĆ i zwiąż wszystkie pętle.
