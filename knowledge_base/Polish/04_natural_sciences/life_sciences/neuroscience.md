# Neuronauka
Neuronauka to nauka o układzie nerwowym – mózgu, rdzeniu kręgowym i wszystkich nerwach łączących je z ciałem. Obejmuje wiele poziomów: od cząsteczek i genów, przez pojedyncze neurony i synapsy, obwody i obszary mózgu, aż po zachowanie, funkcje poznawcze i świadomość. Mózg to najbardziej złożona struktura w znanym wszechświecie, zawierająca około 86 miliardów neuronów połączonych bilionami synaps, a zrozumienie, jak to działa, jest jednym z największych wyzwań nauki.
---

## Neuron
### Części neuronu
| Składnik | Funkcja |
|----------|----------|
| **Dendryty** | Odbieraj sygnały z innych neuronów; rozszerzenia przypominające gałęzie |
| **Ciało komórkowe (soma)** | Integruje przychodzące sygnały; zawiera jądro |
| **Akson** | Długie włókno, które przekazuje sygnały elektryczne (potencjały czynnościowe) z dala od somy |
| **Osłona mielinowa** | Warstwa izolacyjna wokół aksonów; przyspiesza transmisję sygnału |
| **Węzły Ranviera** | Luki w mielinie; umożliwiają przewodzenie solne (przeskoki sygnału między węzłami) |
| **Zakończenia aksonów (butony synaptyczne)** | Uwolnij neuroprzekaźniki do synapsy |
### Rodzaje neuronów
| Wpisz | Kierunek | Funkcja |
|------|-----------|---------|
| **Czuciowy (aferentny)** | Ciało → mózg | Przenoszą informacje ze zmysłów (dotyk, temperatura, ból, wzrok itp.) |
| **Silnik (eferentny)** | Mózg → ciało | Kontroluj mięśnie i gruczoły |
| **Interneurony** | W obrębie OUN | Połącz neurony z innymi neuronami; większość neuronów to interneurony |

## Jak neurony się komunikują
### Potencjał działania
| Faza | Opis |
|-------|------------|
| **Potencjał spoczynkowy** | Neuron ma napięcie ~ -70 mV; pompa sodowo-potasowa utrzymuje równowagę jonową |
| **Depolaryzacja** | Bodziec otwiera kanały sodowe; Na+ wkracza; potencjał błonowy wzrasta |
| **Próg** | Jeśli potencjał osiągnie ~-55 mV, następuje wyzwolenie potencjału czynnościowego (wszystko albo nic) |
| **Faza wzrostu** | Otwarte kanały sodowe bramkowane napięciem; potencjalne skoki do ~+40 mV |
| **Faza opadania** | Kanały sodowe zamykają się; otwarte kanały potasowe; K+ wypływa; potencjalne spadki |
| **Niedoszacowanie (hiperpolaryzacja)** | Potencjał na krótko spada poniżej poziomu spoczynkowego |
| **Okres refrakcji** | Neuron nie może natychmiast odpalić ponownie; zapewnia propagację jednokierunkową |
### Synapsa
| Składnik | Rola |
|----------|------|
| **Neuron presynaptyczny** | Wysyła sygnał; zawiera pęcherzyki synaptyczne z neuroprzekaźnikami |
| **Szczelina synaptyczna** | Mała szczelina (~20 nm) pomiędzy neuronami |
| **Neuron postsynaptyczny** | Odbiera sygnał; ma białka receptorowe |
| **Neuroprzekaźniki** | Chemiczne posłańcy przechodzący przez synapsę |
| **Receptory** | Wiążą neuroprzekaźniki; otwierają kanały jonowe lub wyzwalają kaskady drugiego przekaźnika |

## Kluczowe neuroprzekaźniki
| Neuroprzekaźnik | Funkcja | Powiązane warunki |
|----------------|----------|----------------------|
| **Glutaminian** | Główny neuroprzekaźnik pobudzający; nauka; pamięć | Nadmiar → ekscytotoksyczność (udar, neurodegeneracja) |
| **GABA** | Główny neuroprzekaźnik hamujący; zmniejsza aktywność nerwową | Deficyt → stany lękowe, epilepsja |
| **Dopamina** | Nagroda; motywacja; sterowanie silnikiem; uwaga | Deficyt → Choroba Parkinsona; nadmiar → schizofrenia |
| **Serotonina** | Nastrój; spać; apetyt; trawienie | Deficyt → depresja, stany lękowe |
| **Acetylocholina** | Aktywacja mięśni; nauka; pamięć | Deficyt → Choroba Alzheimera |
| **Norepinefryna** | Pobudzenie; czujność; reakcja na stres | Rozregulowanie → ADHD; depresja |
| **Endorfiny** | Ulga w bólu; przyjemność | Uwolnienie wywołane wysiłkiem fizycznym („haj biegacza”) |

## Struktura mózgu
### Główne obszary mózgu
| Region | Funkcja |
|------------|---------|
| **Kora mózgowa** | Wyższe poznanie; podzielony na płaty czołowe, ciemieniowe, skroniowe, potyliczne |
| **Płat czołowy** | Planowanie; podejmowanie decyzji; osobowość; ruch dobrowolny (kora ruchowa) |
| **Płat ciemieniowy** | Przetwarzanie sensoryczne; świadomość przestrzenna; nawigacja |
| **Płat skroniowy** | Przesłuchanie; rozumienie języka; pamięć (hipokamp) |
| **Płat potyliczny** | Przetwarzanie wizualne |
| **Móżdżek** | Koordynacja ruchowa; balansować; nauka motoryczna; niektóre funkcje poznawcze |
| **Pień mózgu** | Funkcje życiowe: oddychanie; tętno; cykl snu i czuwania |
| **Wzgórze** | Stacja przekaźników sensorycznych; kieruje sygnały do ​​odpowiednich obszarów korowych |
| **Podwzgórze** | Homeostaza; regulacja hormonalna; głód; pragnienie; rytmy dobowe |
### Układ limbiczny
| Struktura | Funkcja |
|----------|----------|
| **Amygdala** | Przetwarzanie emocjonalne; strach; wykrywanie zagrożeń; pamięć emocjonalna |
| **Hipokamp** | Tworzenie pamięci; nawigacja przestrzenna; konwertuje pamięć krótkotrwałą na długoterminową |
| **Zwoje podstawy** | Tworzenie nawyków; nagradzaj naukę; sterowanie silnikiem |
| **Kora obręczy** | Wykrywanie błędów; empatia; kontrola impulsów; regulacja emocji |
| **Jądro półleżące** | Obwód nagrody; przyjemność; uzależnienie |

## Neuronauka poznawcza
### Kluczowe funkcje poznawcze i ich obszary mózgu
| Funkcja | Podstawowe obszary mózgu |
|---------|----------------------|
| **Uwaga** | Kora przedczołowa; kora ciemieniowa; wzgórze |
| **Pamięć robocza** | Kora przedczołowa; kora ciemieniowa |
| **Pamięć długoterminowa** | Hipokamp (formacja); kora (przechowywanie) |
| **Język** | Obszar Broki (produkcja); Pole Wernickego (rozumienie) |
| **Regulacja emocji** | Kora przedczołowa; migdał; brzuszno-przyśrodkowy PFC |
| **Podejmowanie decyzji** | Kora przedczołowa; kora oczodołowo-czołowa; prążkowie |
| **Obróbka wizualna** | Płat potyliczny → strumień brzuszny („co”) i strumień grzbietowy („gdzie”) |
| **Sterowanie silnikiem** | Kora ruchowa; móżdżek; zwoje podstawne |

| Fala | Częstotliwość | Państwo stowarzyszone |
|------|------|--------------------------------|
| **Delta** | 0,5–4 Hz | Głęboki sen |
| **Teta** | 4–8 Hz | Lekki sen; medytacja; senność |
| **Alfa** | 8–13 Hz | Zrelaksowana czuwanie; oczy zamknięte |
| **Beta** | 13–30 Hz | Aktywne myślenie; centrum; czujność |
| **Gamma** | 30–100 Hz | Wyższe poznanie; wiążący; świadomość |

## Neuroplastyczność
| Wpisz | Opis | Przykład |
|------|------------|--------|
| **Plastyczność synaptyczna** | Siła synaps zmienia się wraz z aktywnością | Długotrwałe wzmocnienie (LTP); depresja długoterminowa (LTD) |
| **Plastyczność strukturalna** | Neurony wytwarzają nowe dendryty lub aksony | Nauka nowych umiejętności; powrót do zdrowia po kontuzji |
| **Ponowne mapowanie kory** | Regiony mózgu ponownie przypisują funkcje | Kora wzrokowa osób niewidomych przetwarza dotyk i dźwięk |
| **Neurogeneza** | Rodzą się nowe neurony | Występuje w hipokampie; stymulowane ćwiczeniami i nauką |

## Metody badawcze
| Metoda | Co to mierzy | Rozdzielczość |
|------------|-------|------------|
| **fMRI** | Poziom tlenu we krwi (sygnał BOLD) → aktywność mózgu | Dobra przestrzenność (~1 mm); słaby czasowy (~1 s) |
| **EEG** | Aktywność elektryczna skóry głowy | Doskonały czasowy (~1 ms); słaba przestrzennie |
| **MEG** | Pola magnetyczne pochodzące z aktywności neuronowej | Dobra czasowo i przestrzennie |
| **ZWIERZĘ** | Znacznik radioaktywny → aktywność metaboliczna | Umiarkowane przestrzenno-czasowe |
| **TMS** | Impulsy magnetyczne → tymczasowo zakłócają obszar mózgu | Dowód przyczynowy; ograniczona głębokość |
| **Nagranie pojedynczego urządzenia** | Aktywność elektryczna poszczególnych neuronów | Pojedyncza komórka; zaborczy; głównie badania na zwierzętach |
| **Optogenetyka** | Neurony aktywowane światłem | Precyzyjna kontrola; badania na zwierzętach |
| **DTI** (obrazowanie tensora dyfuzji) | Drogi istoty białej | Mapowanie łączności |

## Zaburzenia neurologiczne i psychiczne
| Zaburzenie | Dotknięty system | Kluczowe funkcje |
|---------|----------------|-------------|
| **Alzheimer** | Kora; hipokamp | Utrata pamięci; płytki amyloidowe; tau splątane |
| **choroba Parkinsona** | istota czarna; zwoje podstawne | Drżenie; sztywność; utrata neuronów dopaminy |
| **Padaczka** | Kora mózgowa | Nawracające drgawki; nieprawidłowa aktywność elektryczna |
| **Stwardnienie rozsiane** | Osłonka mielinowa (OUN) | demielinizacja; zakłócona transmisja sygnału |
| **Depresja** | Kora przedczołowa; układ limbiczny | Utrzymujący się niski nastrój; brak równowagi neuroprzekaźników |
| **Schizofrenia** | Wiele regionów | Halucynacje; urojenia; rozregulowanie dopaminy |
| **ALS** | Neurony ruchowe | Postępujące osłabienie mięśni; śmierć neuronu ruchowego |

## Streszczenie
Neuronauka bada układ nerwowy na każdym poziomie – od molekularnych mechanizmów kanałów jonowych po subiektywne doświadczenie świadomości. Neurony komunikują się poprzez elektryczne potencjały czynnościowe i synapsy chemiczne, wykorzystując neuroprzekaźniki, takie jak glutaminian, GABA, dopamina i serotonina. Mózg jest podzielony na wyspecjalizowane obszary: korę odpowiedzialną za wyższe funkcje poznawcze, układ limbiczny odpowiedzialny za emocje i pamięć oraz móżdżek odpowiedzialny za koordynację. Neuroplastyczność oznacza, że ​​mózg może się przebudowywać przez całe życie. Metody badawcze obejmują fMRI (dobra rozdzielczość przestrzenna), EEG (dobra rozdzielczość czasowa) i optogenetykę (precyzyjna kontrola przyczynowa). Zrozumienie mózgu jest prawdopodobnie najtrudniejszym problemem w nauce – to jedyny organ, który sam się bada.
