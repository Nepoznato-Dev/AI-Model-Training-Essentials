# 世界宗教和比较神话
世界宗教是数千年来塑造人类文明的主要信仰、实践和社区体系。比较神话学研究不同文化讲述的有关创造、英雄、诸神和存在意义的故事，以及相隔数千英里和数千年的传统中反复出现的引人注目的模式。理解两者对于理解人们为何相信自己的信念、文化有何不同以及人类经验的共同点至关重要。

## 比较神话
### 英雄之旅（Monomyth）
约瑟夫·坎贝尔发现了一种在不同文化的神话中反复出现的模式：
|舞台|描述 |示例|
|--------|-------------|---------|
| **平凡的世界** |英雄的平凡生活|佛罗多在夏尔 |
| **冒险的召唤** |出现挑战或任务 |甘道夫带着魔戒到来 |
| **拒绝来电** |英雄犹豫|佛罗多：“为什么是我？” |
| **超自然的援助** | Mentor提供工具或指导|甘道夫给出建议；埃尔隆德提供奖学金 |
| **跨越门槛** |英雄进入未知|离开夏尔 |
| **鲸鱼的腹部** |与已知世界完全分离 |莫瑞亚矿井 |
| **测试、盟友、敌人** |挑战；友谊；反对派 |各种尝试；形成债券 |
| **接近最里面的洞穴** |为重大挑战做好准备 |接近末日山|
| **磨难** |中央危机；死亡与重生|与敌人对抗|
| **奖励** |获得宝藏或知识|指环被毁|
| **回归之路** |回程旅程；最后的挑战|返回首页 |
| **复活** |最终改造；英雄换了 |佛罗多归来，但一切都永远改变了 |
| **带着长生不老药归来** |英雄将智慧或礼物带回平凡世界 |夏尔得救了 |

＃＃ 概括
世界宗教是人类最古老、最广泛的尝试来回答基本问题：我们为什么在这里？我们应该怎样生活？死后会发生什么？亚伯拉罕信仰（犹太教、基督教、伊斯兰教）有一个共同的祖先——亚伯拉罕，并强调一神论、圣经和伦理法。东方传统（印度教、佛教、耆那教、道教）注重佛法、业力、从轮回中解脱以及与自然的和谐。比较神话揭示了跨文化的显着模式——英雄的旅程、创世神话、洪水故事——暗示了人类讲故事的深层结构。宗教活动（祈祷、冥想、禁食、朝圣、慈善）出现在每一个传统中。世俗世界观（人道主义、存在主义、斯多葛主义）提供了非宗教的意义框架。了解这些传统并不是要相信它们中的任何一个，而是要了解数十亿人的生活、价值观和决定是由这些传统决定的。
