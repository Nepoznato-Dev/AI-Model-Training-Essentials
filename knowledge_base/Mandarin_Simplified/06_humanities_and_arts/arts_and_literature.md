# 艺术与文学
人类的创造性表达——无论是书籍、绘画、音乐还是电影——是最持久的文明记录之一。了解主要流派、运动和人物为我们当今生活的世界提供了背景。每部小说、每一部交响乐、每一部电影都与之前的事物进行对话。
---

## 文学流派和形式
### 小说类型
|类型 |主要特征|著名的例子|
|--------|---------|-----------------|
| **文学小说** |人物驱动、主题深度、风格工艺 | *杀死一只知更鸟*（哈珀·李）|
| **科幻小说** |投机技术、空间、时间、平行世界| *沙丘*（赫伯特），*1984*（奥威尔）|
| **幻想** |神奇的世界，神秘的生物| *指环王*（托尔金），*哈利·波特*（罗琳）|
| **悬疑/侦探** |解决犯罪难题、调查 |夏洛克·福尔摩斯（道尔）、波洛（克里斯蒂） |
| **恐怖** |恐惧、悬疑、超自然 | *闪灵*（国王）、*德古拉*（斯托克）|
| **浪漫** |浪漫关系，情感旅程| *傲慢与偏见*（奥斯汀）|
| **历史小说** |具体的历史时期，准确的细节| *偷书贼*（祖萨克）、*狼厅*（曼特尔）|
| **魔幻现实主义** |现实环境中的魔法元素被视为普通元素 | *一百年的孤独*（加西亚·马尔克斯）|
### 非小说形式
|表格 |描述 |
|------|-------------|
| **传记/自传** |真实人物的生活故事——*年轻女孩的日记*（安妮·弗兰克）、*成为*（米歇尔·奥巴马）|
| **回忆录** |专注于特定体验或主题的个人帐户 |
| **论文** |关于特定主题的短文——詹姆斯·鲍德温、琼·迪迪安 |
| **新闻** |新闻报道、调查文章、专题文章 |
| **自助** |个人发展与实践提升|
### 诗歌形式
|表格 |结构|示例|
|------|------------|---------|
| **十四行诗** | 14行，具体韵律|莎士比亚 (ABAB CDCD EFEF GG)、彼特拉克 (ABBAABBA CDECDE) |
| **俳句** | 5-7-5 音节模式 |日本传统，注重自然|
| **利默里克** |五句台词，AABBA韵，幽默|轻诗|
| **自由诗** |没有规律的韵律或韵律|沃尔特·惠特曼，T.S.艾略特 |
| **维拉内尔** | 19 行重复的副歌 | “不要温柔”（迪伦·托马斯）|
| **史诗** |关于英雄事迹的长篇叙述| *奥德赛*（荷马），*贝奥武甫* |

## 主要文学运动
文学经历了不同的时期，每个时期都与前一个时期发生反应：
|期间 |时代|关键想法|主要人物 |
|--------|-----|------------|----------------|
| **古典** | 8世纪公元前 – 5世纪欧盟CE |理性、秩序、人文主义 |荷马、索福克勒斯、维吉尔 |
| **中世纪** | 5世纪至15世纪|宗教题材、骑士精神、寓言|乔叟但丁|
| **文艺复兴** | 14世纪至17世纪|人文主义，古典学的复兴|莎士比亚、塞万提斯 |
| **启蒙** |十七至十八世纪。 |理性、科学、个人权利 |伏尔泰、斯威夫特 |
| **浪漫主义** | 18世纪末至19世纪中期|情感、自然、个人主义 |华兹华斯、歌德、玛丽·雪莱 |
| **现实主义** |十九世纪中期。 |精准描绘日常生活|托尔斯泰、乔治·艾略特、马克·吐温 |
| **现代主义** |十九世纪末至二十世纪中期|实验形式，意识流|乔伊斯、弗吉尼亚·伍尔夫、T.S.艾略特 |
| **后现代主义** | 20世纪中期– 现在 |碎片化、元小说、讽刺 |唐·德里罗·品钦 |
每一次运动都在一定程度上是一次叛乱。浪漫主义拒绝启蒙理性主义；现代主义打破了维多利亚时代的惯例；后现代主义质疑宏大叙事的理念。

## 视觉艺术
### 几个世纪以来的艺术运动
|运动|期间 |特点 |主要艺术家 |
|----------|--------|----------------|------------------------|
| **文艺复兴** | 14世纪至17世纪|现实主义、透视、解剖 |列奥纳多、米开朗基罗、拉斐尔 |
| **巴洛克** |十七世纪|戏剧性的灯光，情感的强度|卡拉瓦乔、伦勃朗、贝尔尼尼 |
| **印象派** |十九世纪末。 |光、色彩、可见的笔触|莫奈、雷诺阿、德加 |
| **后印象派** |十九世纪末。 |大胆的色彩、几何形状|梵高、塞尚、高更 |
| **立体主义** | 20世纪初c. |几何形状，多视角|布拉克·毕加索 |
| **超现实主义** | 1920 年代 – 1940 年代 |梦境意象，无意识|达利、马格里特、弗里达·卡罗 |
| **抽象表现主义** | 20 世纪 40 年代 – 1950 年代 |自发的手势绘画 |波洛克、罗斯科、德库宁 |
| **波普艺术** | 20 世纪 50 年代 – 1960 年代 |流行文化意象|沃霍尔，列支敦士登 |
| **当代** | 20 世纪 70 年代至今 |多元化媒体、概念、社会评论 |班克斯、草间弥生、艾未未 |
### 艺术媒介
绘画（油画、丙烯、水彩、壁画）、素描（铅笔、木炭、墨水）、雕塑（雕刻、建模、铸造）、版画（蚀刻、平版印刷、丝网印刷）、摄影（数字、电影）、数字艺术（3D 建模、生成艺术）、装置艺术和表演艺术。

＃＃ 音乐
### 古典音乐时期
|期间 |年 |特点 |主要作曲家 |
|--------|------|----------------|------------------------|
| **中世纪** | 500–1400 |格里高利圣歌，早期复调音乐|希尔德加德·冯·宾根 |
| **文艺复兴** | 1400–1600 |声乐复调音乐、牧歌|若斯坎·德·佩雷斯·帕莱斯特里纳 |
| **巴洛克** | 1600–1750 |华丽的旋律，连续低音|巴赫、亨德尔、维瓦尔第 |
| **古典** | 1750–1820 |形式平衡、清晰 |莫扎特、海顿、贝多芬 |
| **浪漫** | 1820–1900 |情感表达，扩大管弦乐队|肖邦、瓦格纳、柴可夫斯基 |
| **20 世纪/当代** | 1900 年至今 |无调性、极简主义、实验 |斯特拉文斯基、勋伯格、菲利普·格拉斯 |
### 现代音乐流派
|类型 |主要特征|著名艺术家 |
|------|----------|----------------|
| **爵士乐** |即兴创作，摇摆节奏|路易斯·阿姆斯特朗、迈尔斯·戴维斯、约翰·科尔特兰 |
| **蓝调** | 12小节结构，富有表现力的人声| B.B. King，浑水
| **摇滚** |电吉他，节奏强劲|披头士乐队、齐柏林飞艇、涅槃 |
| **嘻哈/说唱** |有节奏的演讲、节拍、DJ 文化 |图帕克、肯德里克·拉马尔、Jay-Z |
| **电子** |合成器，数字制作| Kraftwerk、Daft Punk、Aphex Twin |
| **国家** |民间传统，讲故事|约翰尼·卡什、多莉·帕顿 |
| **R&B / 灵魂乐** |动人的歌声，律动 |艾瑞莎·富兰克林、史蒂夫·旺德、碧昂斯 |
### 音乐理论基础
音乐的组成部分：**音符和音阶**（大调、小调、五声音阶、调式）、**和弦与和声**（三和弦、七和弦、进行）、**节奏和韵律**（拍号、速度、切分音）、**旋律和对位法**以及**形式和结构**（奏鸣曲形式、主歌合唱、交响乐乐章）。

## 戏剧和电影
### 剧院
2500 多年来，剧院一直是人类讲故事的舞台。主要的戏剧形式有：
|类型 |描述 |著名的例子|
|------|-------------|-----------------|
| **悲剧** |严肃题材，主角垮台 |希腊悲剧，莎士比亚的*哈姆雷特* |
| **喜剧** |幽默的情景，美好的结局|莎士比亚的喜剧，奥斯卡·王尔德 |
| **音乐剧** |歌、舞、对白融为一体| *汉密尔顿*，*悲惨世界* |
| **前卫** |非传统形式，观众参与 |实验剧场|
主要剧作家：莎士比亚、契诃夫、田纳西·威廉斯、阿瑟·米勒、塞缪尔·贝克特、奥古斯特·威尔逊。

## 文学装置

|--------|-------------|

| **拟人化** |赋予非人类事物人类的品质|
| **讽刺** |期望与现实的对比 |

## 为什么这很重要
艺术和文学不仅仅是娱乐——它们是社会处理经验、挑战假设和想象替代方案的方式。一部小说可以改变舆论；一幅画可以定义一个时代；一首歌可以成为变革的赞歌。了解塑造创意表达的传统和运动可以让您以更丰富的视角来理解世界。
