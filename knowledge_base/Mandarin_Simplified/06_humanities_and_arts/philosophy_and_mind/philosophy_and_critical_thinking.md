# 哲学和批判性思维
哲学是对有关知识、现实和存在的基本问题的系统研究。它提供了一个框架来评估什么算作知识、什么值得做，以及如何区分合理的论点和薄弱的论点。批判性思维是该框架的实际应用：分析主张、识别有缺陷的推理以及做出更明智决策的技能。该文件涵盖了主要想法、评估它们的工具以及影响每个人的认知偏见。
---

## 主要思想流派
哲学有几千年的传统。大多数重要职位都可以分为几所学校。
### 古代和古典
|学校 |核心理念|关键人物|
|--------|------------|------------|
| **斯多葛主义** |专注于你能控制的事情；接受你不能接受的。美德是唯一的善。 |马库斯·奥勒留、爱比克泰德、塞内卡 |
| **享乐主义** |美好的生活就是简单的快乐、友谊和免于焦虑的自由。 |伊壁鸠鲁|
| **愤世嫉俗** |拒绝传统欲望和社会规范；顺应自然生活。 |第欧根尼 |
| **怀疑** |暂停判断——确定性是不可能的，或者至少很难确定。 |皮浪，塞克斯图斯·恩皮里库斯 |
| **儒家思想** |社会和谐通过道德修养、仪式和适当的关系来实现。 |孔子 |
| **道教** |与道和谐相处；不费力的行动（无为）。 |老子|
| **佛教** |痛苦来自于执着；通过八正道解脱。 |悉达多·乔达摩 |
### 现代哲学
|学校 |核心理念|关键人物|
|--------|------------|------------|

## 道德框架
当你需要决定什么是正确的时候，你就在遵守道德——无论你是否意识到。主要有以下三种方法。
### 三个框架
|框架|它提出的问题|实力|弱点|
|------------|------------------|----------|----------|
| **结果主义**（功利主义）| “什么会产生最好的结果？” |实用、可衡量、符合政策|难以预测后果；可以证明伤害少数群体是正当的|
| **道义论**（康德伦理学）| “每个人都应该遵守什么规则？” |保护个人权利；一致|死板的;相互冲突的职责|
| **美德伦理** | “一个好人会做什么？” |灵活的;注重性格|模糊的;没有给出明确的行动指导|
### 康德的绝对命令
康德对一个行为是否道德的检验：
1. **普遍性**：你希望每个人都这样做吗？ （如果撒谎普遍存在，信任就会崩溃。）
2. **以人性为目的**：永远不要仅仅将人视为达到目的的手段。
### 应用伦理学
|域名 |关键问题|
|--------|--------------|
| **生物伦理学** |堕胎、安乐死、基因工程、动物权利 |
| **商业道德** |企业责任、举报、公平工资 |
| **技术/人工智能道德** |隐私、算法偏见、自主武器、工作取代 |
| **环境道德** |气候责任、动物福利、代际正义 |

## 逻辑和论证
逻辑是对有效推理的研究。它为您提供了工具来判断某人的论点何时真正支持他们的结论，何时不支持。
### 推理类型
|类型 |描述 |示例|
|------|-------------|---------|
| **演绎** |如果前提为真，则结论*必须*为真。 |所有人类都会有一死。苏格拉底是人。 → 苏格拉底终有一死。 |
| **感应式** |前提使结论“可能”，而不是确定。 |我见过的每只天鹅都是白色的。 → 可能所有天鹅都是白色的。 |
| **溯因** |推断出最好的解释。 |草是湿的。最好的解释：下雨了。 |
### 常见的逻辑谬误
|谬论|描述 |示例|
|---------|-------------|---------|
| **人身攻击** |攻击人，而不是争论| “你不能相信她的经济学——她不是经济学家。” |
| **稻草人** |歪曲论点以使其更容易受到攻击 | “你想削减军事预算？所以你想让这个国家失去防御能力？” |
| **诉诸权威** | “X 是正确的，因为专家是这么说的”（不检查论证）| “这位诺贝尔奖获得者这样说是关于政治的，所以这一定是对的。” |
| **错误的二分法** |当存在更多选项时仅提供两个选项 | “要么你支持这项政策，要么你不关心孩子。” |
| **滑坡** |通过一系列看似不可能的事件，A 通向 Z | “如果我们使大麻合法化，很快我们就会使一切合法化。” |
| **提出问题** |结论是在前提下假设的 | “这项法律不公正，因为它不公平。” （不公正=不公平——同样的事情）|
| **事后因故** | A 发生在 B 之前，因此 A 导致了 B | “我服用了补充剂，然后我感觉好多了——补充剂起作用了。” |
| **你现在** | “你也这么做”——驳斥批评，因为批评者虚伪| “你告诉我要吃得更健康，但你却吃快餐。” |
| **诉诸自然** | “自然=好” | “人类进化来吃肉，所以素食主义是不自然和错误的。” |
| **沉没成本谬论** |继续是因为过去的投资，而不是未来的价值| “我们已经在这个项目上花费了 1000 万美元；我们现在不能停止。” |
### 评估参数
一个好的论证有：
1. **真实（或有充分支持的）前提**
2. **有效的逻辑**（从前提得出结论）
3. **没有隐藏的假设**
4. **相关性**（前提实际上解决了结论）

## 认识论：我们能知道什么？
认识论是对知识本身的研究——它是什么、我们如何获得它以及它的局限性是什么。
### 知识来源
|来源 |描述 |限制|
|--------|-------------|------------|
| **感知** |直接的感官体验 |幻觉、幻觉，范围有限 |
| **原因** |逻辑演绎与数学证明|只告诉您从您的场所发生的情况 |
| **内省** |检查你自己的想法和感受|自欺欺人；对您自己的进程的有限访问
| **见证** |其他人告诉你什么 |人们撒谎、犯错或过于简单化 |
| **内存** |回顾过去的经历 |不可靠；重建；随着时间的推移而退化|
| **科学方法** |系统观察、假设检验、复制 |慢的;仅限于可测试的问题；范式依赖|
### 关键认识论问题
|问题 |描述 |
|---------|-------------|
| **归纳问题** |仅仅因为过去太阳每天都会升起，并不能“逻辑上”保证明天也会升起（休谟）|
| **盖蒂尔问题** |合理的真实信念可能不是知识——运气好的话你可能是对的 |
| **分界问题** |科学与伪科学的区别是什么？ （波普尔：可证伪性）|
| **不确定性** |仅凭证据可能无法唯一确定哪种理论是正确的 |

##心灵哲学
|职位|索赔 |挑战|
|----------|---------|------------|
| **二元论** |心灵和身体是不同的实体|他们如何互动？ （交互问题） |
| **物理主义/唯物主义** |一切都是物质的；意识是一个大脑过程|难题：为什么体验“感觉”像什么？ |
| **功能主义** |精神状态是由其功能作用而不是其基础来定义的 |足够复杂的计算机能够有意识吗？ |
| **泛心论** |意识是一切物质的基本特征 |微观意识如何与宏观意识结合？ |
| **幻觉** |我们所体验到的意识是一种幻觉 |似乎否认了我们最确定的一件事 |
### 关键思想实验
|实验|点|
|----------|------|
| **图灵测试** |如果机器的反应与人类的反应没有区别，它还能思考吗？ |
| **中式房间**（塞尔）|操纵符号≠理解。语法不是语义。 |
| **玛丽的房间**（杰克逊）|一位了解有关颜色的所有物理事实的科学家在第一次看到红色时仍然会学到新的东西。 |
| **哲学僵尸** |一个与你身体相同但没有内在体验的存在——这可以想象吗？ |
| **电车难题** |牺牲一个人拯救五个人在道德上可以接受吗？测试关于结果论与道义论的直觉。 |

## 认知偏差
你的大脑会走捷径。大多数时候，它们工作得很好。如果不这样做，结果称为认知偏差。了解它们是避免它们的第一步。
### 决策偏差
|偏见|描述 |示例|
|------|-------------|---------|
| **确认偏差** |寻求证实现有信念的信息|只阅读与您观点一致的新闻来源 |
| **锚定** |过度依赖遇到的第一条信息 |从过高的初始价格进行谈判 |
| **可用性启发式** |通过想到例子的难易程度来判断概率|高估了飞机失事的风险，因为此类事件被广泛报道
| **邓宁-克鲁格效应** |能力低下的人高估了自己的能力；专家低估了他们的水平初学者自信自己能够解决专家认为很难的问题 |
| **取景效果** |决策会根据选项的呈现方式而变化 | “90%的存活率”听起来比“10%的死亡率”好 |
| **损失厌恶** |损失的感觉大约是同等收益感觉良好的两倍持有亏损股票，因为卖出会“锁定”损失|
| **现状偏见** |喜欢事物保持不变 |不改用更好的计划，因为改变需要付出努力 |
### 社会偏见
|偏见|描述 |
|------|-------------|
| **光环效应** |一项积极的特质会影响您对一个人的整体印象 |
| **基本归因错误** |将别人的行为归因于性格，将自己的行为归因于环境|
| **群体内偏见** |偏爱那些你认为属于你的团队的人 |
| **跟风效应** |因许多人持有信念而接受这些信念 |
| **正义世界谬误** |相信人们会得到他们应得的 |
### 如何减少偏见
1. **钢铁侠反对派**：构建你不同意的论点的最有力版本。
2. **寻求反驳证据**：积极寻找你可能错误的原因。
3. **考虑基本利率**：这种类型的结果一般有多常见？
4. **使用清单和框架**：将你的思维具体化以发现盲点。
5. **在重要决定上睡觉**：第一直觉往往是有偏见的。
6. **邀请不同意见**：让自己周围都是那些会在你错误时告诉你的人。

## 为什么这很重要
哲学和批判性思维不是抽象的练习。它们是实用的工具：
- **道德框架**帮助您应对商业、技术和个人生活中的真正困境。
- **逻辑**可以帮助您发现政治、广告和社交媒体中的不良论点。
- **认知偏差**解释了为什么有能力的人在判断时会犯系统性错误，以及如何减少这种错误的频率。
- **认识论**在错误信息时代变得越来越重要：如何评估主张的真实性？
哲学研究不需要与任何特定哲学家达成一致。它需要有能力检查信念及其背后的推理。
