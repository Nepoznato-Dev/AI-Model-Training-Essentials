# 表演艺术
表演艺术——戏剧、电影、舞蹈和音乐表演——是艺术与观众现场互动的地方。与墙上的画或书架上的书不同，表演是实时展开的，在艺术家和观众之间创造了一种共享体验，这在数千年来一直是人类文化的核心。
---

## 剧院
2500 多年来，剧院一直是人类讲故事的舞台。从古希腊的圆形剧场到百老汇和伦敦西区，现场表演仍然是最有力的艺术表达形式之一。
### 戏剧形式
|类型 |描述 |著名的例子|
|------|-------------|-----------------|
| **悲剧** |严肃题材，主角垮台 |希腊悲剧，莎士比亚的*哈姆雷特* |
| **喜剧** |幽默的情景，美好的结局|莎士比亚的喜剧，奥斯卡·王尔德 |
| **悲喜剧** |融合悲剧与喜剧元素| *等待戈多*（贝克特）|
| **音乐剧** |歌、舞、对白融为一体| *汉密尔顿*，*悲惨世界* |
| **歌剧** |全唱戏剧作品| *波希米亚人*（普契尼）、*卡门*（比才）|
| **前卫** |非传统形式，观众参与 |实验剧场|
| **情节剧** |夸张的人物，煽情的情节| 19 世纪舞台情节剧 |
| **闹剧** |肢体喜剧、荒诞情境| Feydeau，*噪音关闭*（弗雷恩）|
### 主要剧作家
|时代|剧作家 |
|-----|------------|
| **古典** |索福克勒斯、欧里庇得斯、阿里斯托芬 |
| **伊丽莎白/詹姆士一世** |莎士比亚、马洛、琼森 |
| **现代** |易卜生、契诃夫、斯特林堡 |
| **二十世纪** |阿瑟·米勒、田纳西·威廉姆斯、塞缪尔·贝克特、奥古斯特·威尔逊 |
| **当代** |林-曼努尔·米兰达、苏珊-洛瑞·帕克斯、汤姆·斯托帕德
### 全球戏剧传统
|传统|产地 |特点 |
|------------|--------------------|----------------|
| **能乐** |日本 |蒙面表演者，缓慢的程式化动作，精神主题|
| **歌舞伎** |日本 |精致的服装、戏剧性的妆容、历史故事|
| **文乐** |日本 |木偶剧院与可见的木偶师 |
| **京剧** |中国 |歌唱、朗诵、杂技、武术|
| **卡塔卡利语** |印度 |精心化妆和服装的舞剧 |
| **即兴喜剧** |意大利 |即兴表演、库存人物、蒙面表演者 |
| **京剧** |中国 |程式化的动作，象征性的手势|

＃＃ 电影
电影是主要艺术形式中最年轻的——只有一个多世纪的历史——但它已成为消费最广泛、文化影响力最广的艺术形式。
### 电影运动
|运动|期间 |特点 |重要电影/导演 |
|----------|--------|----------------|------------------------|
| **德国表现主义** | 20 年代 |扭曲的视觉效果、心理主题| *诺斯费拉图*（穆尔瑙）、*大都会*（朗）|
| **苏联蒙太奇** | 1920 年代 – 1930 年代 |剪辑即意义，镜头碰撞|爱森斯坦的*战舰波将金号* |
| **意大利新现实主义** | 20 世纪 40 年代 – 1950 年代 |工人阶级故事，外景拍摄| *自行车窃贼*（德西卡）|
| **法国新浪潮** | 20 世纪 50 年代 – 1960 年代 |创新剪辑，作者论|特吕弗·戈达尔 |
| **新好莱坞** | 20 世纪 60 年代 – 1980 年代 |导演驱动、成熟主题|科波拉、斯科塞斯、库布里克 |
| **新德国电影** | 20 世纪 60 年代 – 1970 年代 |政治，导演驱动 |法斯宾德、文德斯、赫尔佐格 |
| **多美95** | 20 世纪 90 年代 |极简规则，自然采光|冯·提尔 (Von Trier)，温特贝格 |
| **新浪潮运动** | 2000 年代至今 |全球电影多元化 |诺莱坞，韩国新浪潮 |
### 关键电影概念
|概念 |描述 |
|---------|-------------|
| **场景调度** |一切都放置在框架内——布景、服装、灯光、演员|
| **蒙太奇** |通过并置镜头创造意义的剪辑技术 |
| **摄影** |摄影艺术——取景、动作、灯光、镜头选择|
| **作者理论** |导演作为电影“作者”，具有辨识度的个人风格 |
| **类型** |影片类别：剧情片、喜剧片、恐怖片、科幻片、西部片、纪录片等|
| **声音设计** |所有音频元素：对话、音乐、音效、静音 |
### 主要电影产业
|工业|国家 |著名的 |
|----------|---------|-------------|
| **好莱坞** |美国 |大片、制片厂体系、全球影响力|
| **宝莱坞** |印度 |音乐叙事，海量产出|
| **诺莱坞** |尼日利亚 |快速制作，直接制作视频 |
| **戛纳/欧洲** |法国/欧洲|作者电影、电影节 |
| **韩国电影** |韩国 |类型融合、社会评论 |
| **动漫** |日本 |动画电影和系列 |

＃＃ 舞蹈
舞蹈是人类运动的艺术，通常（但并非总是）伴随着音乐。它涵盖仪式、娱乐和高雅艺术：
|表格 |产地 |特点 |
|------|--------------------|----------------|
| **芭蕾** |文艺复兴时期的意大利/法国|编码技术、足尖训练、叙述 |
| **当代舞蹈** | 20世纪美国/欧洲 |拒绝僵化的芭蕾舞、地板动作、即兴创作|
| **点击** |美国（非裔美国人+爱尔兰血统）|节奏步法作为打击乐 |
| **弗拉门戈** |西班牙（安达卢西亚）|吉他、歌唱、打击乐步法、情感强度|
| **嘻哈/霹雳舞** |美国（布朗克斯，20 世纪 70 年代）| B-boying、pop、locking、战斗 |
| **古典印度舞** |印度 | Bharatanatyam、Kathak、Odissi — 通过手势讲故事 |
| **宴会厅** |欧洲 |伴舞：华尔兹、探戈、狐步|
| **民间/传统** |全球 |文化庆典、仪式、社区 |

## 为什么这很重要
表演艺术是文化实时活跃的地方。戏剧通过让我们站在另一个人的立场上两个小时来培养同理心。电影可以让我们见证历史，或者带我们进入想象的世界。舞蹈表达了言语无法表达的东西。这些艺术形式共同代表了人类最强大的联系、反思和变革工具。
