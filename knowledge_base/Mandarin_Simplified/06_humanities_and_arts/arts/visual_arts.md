#视觉艺术
视觉艺术是人类最古老的交流形式——从拉斯科的洞穴壁画到今天的数字装置。了解艺术运动、媒介和保存创意作品的机构，可以让您更深入地了解社会数千年来如何表达美、力量、灵性和异议。
---

## 几个世纪以来的艺术运动
|运动|期间 |特点 |主要艺术家 |
|----------|--------|----------------|------------------------|
| **文艺复兴** | 14世纪至17世纪|现实主义、透视、解剖、古典主题 |列奥纳多、米开朗基罗、拉斐尔 |
| **矫揉造作** | 16世纪晚期。 |修长的身材，人造的优雅|埃尔·格列柯，蓬托尔莫 |
| **巴洛克** |十七世纪|戏剧性的灯光、情感的强度、宏伟|卡拉瓦乔、伦勃朗、贝尔尼尼 |
| **洛可可** | 18世纪初。 |装饰性、俏皮、柔和的调色板 |华托·弗拉戈纳尔 |
| **新古典主义** | 18世纪末至19世纪初|回归古典秩序，道德严肃 |大卫·安格尔 |
| **浪漫主义** | 18世纪末至19世纪中期|情感、自然、崇高|特纳、德拉克洛瓦、杰里科|
| **现实主义** |十九世纪中期。 |对日常生活的不理想描述|米勒·库尔贝 |
| **印象派** |十九世纪末。 |光、色彩、可见的笔触、现代生活|莫奈、雷诺阿、德加 |
| **后印象派** |十九世纪末。 |大胆的色彩、几何形状、情感深度|梵高、塞尚、高更 |
| **新艺术风格** | 1890 年代 – 1910 年代 |有机线条、装饰图案|克里姆特、穆夏、高迪 |
| **表现主义** | 20世纪初c. |扭曲的形式，强烈的情感|蒙克、基什内尔、康定斯基 |
| **立体主义** | 20世纪初c. |几何形状，多视角|布拉克·毕加索 |
| **未来主义** | 1910 年代 – 1920 年代 |速度、技术、活力|博乔尼·巴拉 |
| **达达** | 1910 年代 – 1920 年代 |反艺术、荒诞、挑衅|豪斯曼·杜尚 |
| **超现实主义** | 1920 年代 – 1940 年代 |梦境意象、无意识、自动主义 |达利、马格里特、弗里达·卡罗 |
| **抽象表现主义** | 20 世纪 40 年代 – 1950 年代 |自发的手势绘画、大型画布|波洛克、罗斯科、德库宁 |
| **波普艺术** | 20 世纪 50 年代 – 1960 年代 |大众文化意象、量产美学|沃霍尔，列支敦士登 |
| **极简主义** | 20 世纪 60 年代 – 1970 年代 |简约、几何形状、工业材料 |唐纳德·贾德、艾格尼丝·马丁 |
| **概念艺术** | 20 世纪 60 年代至今 |关于美学、文本、表现的想法 |索尔·勒维特、小野洋子 |
| **当代** | 20 世纪 70 年代至今 |多元化媒体、概念、社会评论 |班克斯、草间弥生、艾未未 |

## 艺术媒介
艺术家使用的材料和方法塑造了作品本身：
|中等|描述 |著名的例子|
|--------|-------------|-----------------|
| **油画** |油中色素（亚麻籽、核桃）；慢干，可混合|伦勃朗、维米尔 |
| **亚克力** |快干合成聚合物；多才多艺 |大卫·霍克尼 |
| **水彩** |颜料悬浮在水中；透明、发光| J.M.W.特纳|
| **壁画** |湿石膏上的颜料；耐用、不朽|米开朗基罗（西斯廷教堂）|
| **木炭/铅笔** |用于绘图的干燥介质；表达范围 |莱昂纳多的草图|
| **墨水** |流体介质；书法，精确|东亚毛笔画|
| **雕塑** |雕刻（石、木）、造型（粘土）、铸造（青铜）|布朗库西·罗丹 |
| **版画** |蚀刻、平版印刷、丝网印刷、木刻|葛饰北斋·丢勒 |
| **摄影** |光敏表面；数字或电影|安塞尔·亚当斯、辛迪·雪曼 |
| **数字艺术** |计算机生成或操纵的；包括 3D、生成 |雷菲克·阿纳多尔·比普尔 |
| **安装** |特定地点的沉浸式环境 |克里斯托和珍妮-克洛德|
| **行为艺术** |身体、时间、空间为媒介|玛丽娜·阿布拉莫维奇 |

## 设计原则
艺术家使用这些原则来组织视觉元素：
|原理|描述 |
|------------|-------------|
| **余额** |视觉权重分布（对称、不对称、放射状）|
| **对比** |并置不同元素以创造视觉趣味 |
| **强调** |创建吸引观众眼球的焦点 |
| **运动** |引导观众的视线贯穿构图 |
| **模式/重复** |重复元素创造节奏和统一 |
| **比例/比例** |元素之间的大小关系 |
| **团结/和谐** |所有元素作为一个有凝聚力的整体一起工作|

## 为什么这很重要
视觉艺术不仅仅是装饰——它是人类思想、信仰和愿望的记录。每幅画、雕塑和装置都反映了其产生的文化。了解艺术运动可以帮助您解读广告、建筑、电影和设计中围绕您的视觉语言。博物馆和画廊不仅仅是旧物品的储藏室，它们还是关于人类意义的生动对话。
