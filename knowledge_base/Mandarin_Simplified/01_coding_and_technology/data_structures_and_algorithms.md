# 数据结构和算法
数据结构是我们在内存中组织数据的方式，以便对其进行高效的操作。算法是解决问题的逐步过程。它们共同构成了计算机科学的基础——您使用过的每个程序都依赖于它们。选择正确的数据结构可以将一个极其缓慢的程序变成一个快速的程序，而了解正确的算法可以将一个无法解决的问题变成一个微不足道的问题。
---

## 基本数据结构
### 线性结构
|结构|访问 |搜索 |插入|删除|使用案例|
|------------|--------|--------|--------|--------|---------|
| **数组** | O(1) 按索引 | O(n) | O(n) | O(n) |固定大小的集合；随机访问|
| **链接列表** | O(n) | O(n) | O(1) 头部 | O(1) 头部 |动态尺寸；插入/删除|
| **堆栈** | O(n) | O(n) | O(1) 推入/弹出 | O(1) 弹出 |函数调用；撤消；解析 |
| **队列** | O(n) | O(n) | O(1) 入队 | O(1) 出队 |任务调度；广度优先搜索；消息队列|
| **双端队列** |两端 O(1) | O(n) |两端 O(1) |两端 O(1) |推拉窗；偷工减料 |
### 基于哈希的结构
|结构|搜索 |插入|删除|使用案例|
|------------|--------|--------|--------|---------|
| **哈希表** | O(1) 平均 | O(1) 平均 | O(1) 平均 |键值查找；缓存；套|
| **哈希集** | O(1) | O(1) | O(1) | O(1) | O(1) | O(1) |会员资格测试；重复数据删除 |
**哈希冲突**：当两个键哈希到同一个槽时，它们存储在链表（链接）或下一个可用槽（开放寻址）中。好的哈希函数可以最大限度地减少冲突。

## 算法复杂度（Big-O）
Big-O 表示法描述了算法的时间或空间需求如何随着输入大小的增加而增长。
|复杂性 |名称 |示例|
|------------|------|---------|
| **O(1)** |恒定|哈希表查找；按索引访问数组 |
| **O(log n)** |对数 |二分查找；平衡树操作|
| **O(n)** |线性|线性搜索；迭代数组 |
| **O(n log n)** |线性|归并排序；堆排序；最高效的通用排序 |
| **O(n²)** |二次 |冒泡排序；相同数据上的嵌套循环 |
| **O(2^n)** |指数|暴力子集生成；朴素递归斐波那契 |
| **O(n!)** |阶乘|旅行推销员（暴力）；排列|
### 常见误解
|误解|现实|
|--------------|---------|
| “O(n) 总是比 O(n²) 快”|对于较小的 n，常数因子更重要 |
| “降低大 O 总是更好” |存在时空权衡； O(1) 查找使用 O(n) 内存 |
| “Big-O 告诉你准确的速度”|它描述的是增长率，而不是绝对时间 |

## 排序算法
|算法|最佳|平均 |最差|空间|稳定|就地|
|------------|------|---------|--------|--------|--------|----------|
| **冒泡排序** | O(n) | O(n²) | O(n²) | O(1) | O(1) |是的 |是的 |
| **插入排序** | O(n) | O(n²) | O(n²) | O(1) | O(1) |是的 |是的 |
| **选择排序** | O(n²) | O(n²) | O(n²) | O(1) | O(1) |没有 |是的 |
| **合并排序** | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n) |是的 |没有 |
| **快速排序** | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n²) | O(log n) |没有 |是的 |
| **堆排序** | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(1) | O(1) |没有 |是的 |
| **蒂姆·索特** | O(n) | O(n log n) | O(n log n) | O(n log n) | O(n log n) | O(n) |是的 |没有 |
**实用建议**：使用您语言的内置排序（Python 的`sorted()`、JavaScript 的`Array.sort()`）。他们使用高度优化的算法（Tim Sort、Introsort）来处理所有边缘情况。

## 搜索算法
|算法|数据结构|复杂性 |要求 |
|----------|--------------|---------|-------------|
| **线性搜索** |任何 | O(n) |无 |
| **二分查找** |排序数组 | O(log n) |数据必须排序|
| **哈希表查找** |哈希表| O(1) 平均 |良好的哈希函数 |
| **BFS*​​（广度优先搜索）|图/树| O(V + E) |未加权最短路径 |
| **DFS**（深度优先搜索）|图/树| O(V + E) |寻路；循环检测|
| **迪杰斯特拉** |加权图 | O((V + E) log V) |非负权重；最短路径|
| **A* 搜索** |加权图 | O((V + E) log V) |启发式引导；具有可接受的启发式的最优 |

## 关键算法模式
|图案|描述 |示例问题 |
|--------|-------------|-----------------|
| **分而治之** |将问题分解为子问题；递归求解；结合|归并排序；快速排序；二分查找|
| **动态规划** |分解为重叠的子问题；缓存结果 |斐波那契；背包;最长公共子序列|
| **贪婪** |每一步做出局部最优选择 |迪杰斯特拉的；霍夫曼编码；活动选择|
| **回溯** |尝试各种可能性；撤销错误的选择；尝试替代方案 |数独解算器； N-皇后；排列|
| **滑动窗** |维护一个元素窗口；将其滑过数据 |大小为 K 的最大和子数组；最长的无重复子串 |
| **两个指针** |使用两个指针朝彼此或向同一方向移动 |排序数组中的对和；删除重复项 |
| **对答案进行二分搜索** |二分查找答案空间 |分配最小页数；好斗的奶牛|

## 何时使用什么
|问题 |数据结构|算法|
|--------|----------------|------------|
|快速键值查找 |哈希表/字典|哈希 |
|维护排序顺序 |平衡 BST（TreeMap、std::set）|树操作 |
|基于优先级的处理 |堆/优先队列|堆操作 |
|最短路径（未加权）|图（邻接表）| BFS |
|最短路径（加权）|图（邻接表）| Dijkstra 的 / A* |
|会员测试|哈希集/布隆过滤器|哈希 |
|前缀匹配 |特里树 | Trie 遍历 |
|范围查询 |线段树/芬威克树|树操作|
| LRU 缓存 |哈希图+双向链表|联合经营 |
|连接组件|不相交集并集（并查找）|联合与查找 |

＃＃ 概括
数据结构和算法不仅仅是面试主题——它们是高效软件的构建块。数组和哈希表可以满足大多数日常需求。树和图处理层次结构和关系数据。排序和搜索已解决标准库中的问题。算法模式——分而治之、动态规划、贪婪、回溯——是解决新问题的可重用策略。关键技能不是记住算法，而是记住算法。它识别哪种模式适合给定的问题并为工作选择正确的数据结构。
