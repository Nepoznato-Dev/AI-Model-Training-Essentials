# 生成式人工智能深入研究
生成式人工智能是指创建新内容（图像、文本、音频、视频、代码）的模型，而不仅仅是对现有数据进行分类或预测。虽然大型语言模型受到了大部分关注，但生成式人工智能的前景要广阔得多。该文件涵盖了现代生成系统背后的架构、技术和权衡，从扩散模型到变分自动编码器再到流模型。
---

## 是什么让模型具有“生成性”？
|类型 |它有什么作用 |示例|
|------|-------------|---------|
| **歧视性** |了解班级之间的界限 | “这个图像是猫还是狗？” |
| **生成** |了解数据本身的分布 | “生成一个新的猫形象”|
生成模型捕获*数据是如何生成的*，而不仅仅是如何对其进行分类。这使得它们从根本上变得更强大——也更难训练。
---

## 主要生成架构
### 变分自动编码器 (VAE)
VAE 学习数据的压缩、结构化表示（潜在空间），然后通过从该空间采样来生成新样本。
|组件|角色 |
|------------|------|
| **编码器** |将输入数据映射到潜在空间中的分布（均值和方差） |
| **潜在空间** |连续的低维空间，其中相似的数据点靠得很近 |
| **解码器** |将潜在空间中的点映射回数据空间 |
| **KL 散度** |正则化项使潜在分布接近标准正态 |
**生成如何工作**：从潜在空间采样随机向量→将其通过解码器→获得新的数据点。
|实力|弱点|
|----------|----------|
|平滑、连续的潜在空间 |输出往往是模糊的 |
|有原则的数学框架 |受架构容量限制|
|可以在示例之间插入 |不如扩散或 GAN 输出锐利 |
VAE 通常用作其他模型中的组件（例如，稳定扩散使用 VAE 作为其管道的一部分）。
### 生成对抗网络（GAN）
GAN 使两个网络相互竞争：一个创建虚假数据的**生成器**，以及一个试图辨别真实与虚假数据的**鉴别器**。
|组件|目标|
|------------|------|
| **发电机** |产生愚弄鉴别器的数据 |
| **鉴别器** |正确分类真实数据与生成数据 |
他们同时训练，互相推动对方进步。理论上，生成器最终会生成与真实数据无法区分的数据。
| GAN 变体 |关键创新|
|------------|----------------|
| **DCGAN** |卷积架构；稳定训练|
| **StyleGAN / StyleGAN2 / StyleGAN3** |基于风格的生成；逼真的面孔；可控属性|
| **CycleGAN** |不成对的图像到图像转换（马 → 斑马）|
| **像素2像素** |配对图像到图像转换（草图 → 照片）|
| **ProGAN** |高分辨率图像的渐进式增长 |
| **BigGAN** |大规模类条件生成 |
**GAN 为何衰落**：众所周知，训练非常不稳定（模式崩溃、梯度消失）。扩散模型现在可以为大多数图像生成任务提供更好的质量。 GAN 仍然用于实时应用程序（它们的推理速度很快）和超分辨率等特定任务。
### 扩散模型
扩散模型是图像和视频生成的最新技术。他们的工作原理是逐渐向数据中添加噪声，直到变成纯随机噪声，然后学习逆转该过程。
|相|发生了什么 |
|--------|-------------|
| **正向过程（训练）** |缓慢地添加数百/数千步的高斯噪声，直到数据被破坏 |
| **逆向过程（生成）** |逐步学习去噪，从纯噪声开始，直到出现干净的图像 |
|型号|开发商|显着特点|
|--------|---------|-----------------|
| **DDPM**（去噪扩散概率模型）|何等人，2020 |显示扩散模型可以产生高质量图像 |
| **稳定扩散** |稳定性人工智能 |潜在扩散（在压缩空间中运行）；开源 |
| **DALL-E 3** |开放人工智能 |与 ChatGPT 集成以进行文本理解 |
| **中途** |中途 |艺术性;闭源 |
| **图像** |谷歌 DeepMind |高保真文本到图像 |
| **索拉** |开放人工智能 |通过扩散变压器生成视频 |
| **通量** |黑森林实验室|稳定扩散的开放重量后继者 |
### 为什么扩散模型获胜
|优势 |说明|
|------------|-------------|
| **训练稳定性** |比 GAN 稳定得多；没有对抗性训练|
| **输出质量** |最先进的图像质量和多样性 |
| **可控性** |可以通过文本（通过 CLIP）、修复蒙版或其他条件进行引导 |
| **多元化** |比 GAN 更少的模式崩溃；产生不同的输出 |
|缺点|说明|
|-------------|-------------|
| **推理缓慢** |需要许多去噪步骤（典型值为 20-50）|
| **计算密集型** |每一步都是对大型模型的完整前向传递 |
### 潜在扩散
在像素空间中运行扩散是昂贵的。 **潜在扩散**（由稳定扩散使用）改为在压缩的潜在空间中运行扩散过程。
|步骤|发生了什么 |
|------|-------------|
| 1. 压缩 |预训练的 VAE 将图像编码为更小的潜在表示 |
| 2. 扩散|扩散模型添加/消除潜在空间中的噪声 |
| 3. 解码 | VAE 解码器将潜在图像转换回完整图像 |
这使得发电速度显着加快、成本降低，同时保持质量。

## 文本条件生成
大多数现代生成系统都以文本提示为条件——您描述您想要的内容，然后模型生成它。
### CLIP（对比语言-图像预训练）
CLIP 学习文本和图像的共享嵌入空间。它接受了来自互联网的数十亿图像文本对的训练。
|能力|描述 |
|------------|-------------|
| **零样本分类** |无需任何训练即可使用文本描述对图像进行分类 |
| **图文检索** |查找与文本查询最相关的图像 |
| **引导扩散** |引导图像生成朝向文本提示 |
### 无分类器指导 (CFG)
CFG 控制生成的图像遵循文本提示的程度。
| CFG 规模 |效果|
|------------|--------|
| **1.0** |没有指导；多样但可能与提示不符 |
| **5.0–7.5** |均衡;良好的品质和及时的遵守|
| **10.0+** |坚持力强；可以生成过饱和或伪影较多的图像

## 其他生成方法
### 流量标准化
|特色 |描述 |
|---------|-------------|
| **它是如何工作的** |学习数据和简单分布之间的可逆映射 |
| **实力** |精确的似然计算；快速采样|
| **弱点** |需要精心设计的架构；不太灵活|
| **用例** |异常检测、密度估计 |
### 自回归模型
|特色 |描述 |
|---------|-------------|
| **它是如何工作的** |一次生成一个元素的数据，以所有先前的元素为条件 |
| **实力** |自然的顺序数据（文本、代码、音乐）|
| **弱点** |生成速度慢（必须是顺序的）；受训练数据分布限制 |
| **示例** | GPT（文本）、WaveNet（音频）、ImageGPT（图像）|
### 基于能量的模型
|特色 |描述 |
|---------|-------------|
| **它是如何工作的** |学习能量函数；低能量=真实数据|
| **实力** |灵活的;无需标准化 |
| **弱点** |训练困难；采样需要MCMC |
| **用例** |理论研究；一些机器人应用|

## 评估指标
如何衡量生成数据的质量？这比你想象的要难。
|公制|对于|它测量什么 |限制|
|--------|-----|-----------------|------------|
| **FID**（Fréchet 起始距离）|图片 |真实图像分布与生成图像分布之间的距离 |越低越好；没有很好地捕捉多样性|
| **IS**（初始分数）|图片 |生成图像的质量和多样性 |有争议的;可以玩游戏|
| **剪辑分数** |文字转图像 |图像与文字提示的匹配程度如何？取决于 CLIP 的偏见 |
| **困惑** |文字|模型预测下一个标记的效果如何？越低越好；不衡量连贯性|
| **蓝色/胭脂** |文本生成 |与参考文本重叠|人类判断的糟糕代表
| **FAD**（Fréchet 音频距离）|音频|真实和生成的音频分布之间的距离 |类似于音频的 FID |

## 可控发电
现代系统让您可以控制生成的内容，而不仅仅是文本提示。
|方法|控制类型 |示例|
|--------|-------------|---------|
| **修复** |填充遮罩区域 |从照片中删除对象 |
| **外画** |超越图像边界|让风景更宽广 |
| **控制网** |结构指导（边缘、深度、姿势）|生成与特定姿势匹配的图像 |
| **IP 适配器** |参考图像的样式或内容 | “让它看起来像这幅画”|
| **洛拉** |微调风格或概念|添加特定的角色或艺术风格|
| **Img2Img** |转换现有图像 |将草图变成逼真的图像 |

## 视频生成
视频生成是继图像之后的下一个前沿领域。它增加了时间和运动的维度。
|型号|方法|显着特点|
|--------|----------|-----------------|
| **索拉** (OpenAI) |扩散变压器|高达 1080p；相当了解物理学|
| **跑道第三代** |基于扩散|商业视频生成工具|
| **皮卡** |基于扩散|文字短视频剪辑|
| **克林** |自回归+扩散|长视频生成|
| **Veo 2**（谷歌）|扩散变压器|高品质、物理一致的视频 |
### 视频生成的挑战
|挑战|为什么这很难 |
|------------|--------------|
| **时间一致性** |对象在不同帧中看起来应该是相同的 |
| **物理** |重力、碰撞、流体动力学必须大致正确 |
| **长度** |生成几分钟的连贯视频比生成单个图像要困难得多 |
| **计算** |视频本质上是许多图像；成本与帧数的关系|
| **评估** |没有标准指标可以很好地捕捉视频质量|

## 发电经济学
|因素|影响 |
|--------|--------|
| **培训费用** |扩散模型：10 万美元至 1000 万美元以上，具体取决于规模 |
| **推理成本** |图像生成：每幅图像约 0.01–0.05 美元 |
| **硬件** |训练：多个A100/H100 GPU；推理：单 GPU 成为可能 |
| **开放式与封闭式** |开放模型（Stable Diffusion、FLUX）可以本地运行；封闭模型（DALL-E、Midjourney）仅支持 API |

＃＃ 概括
生成式人工智能已经从 GAN 发展到 VAE，再到扩散模型等等。所有这些架构的关键见解都是相同的：了解数据的分布，然后从中采样以创建新内容。由于其训练稳定性和输出质量，扩散模型目前在图像和视频生成中占据主导地位。 VAE 是关键的构建模块。自回归模型主导文本和代码。该领域正在朝着多模式生成的方向发展——可以通过任意输入组合生成文本、图像、音频和视频的系统——并朝着使生成更快、更便宜、更可控的方向发展。
