# 计算机视觉基础知识
计算机视觉使机器能够解释和理解来自世界的视觉信息——图像、视频和 3D 数据。它为从手机上的人脸识别到自动驾驶汽车、医学图像分析和工业质量控制的一切提供支持。该文件涵盖了核心概念、架构和技术。
---

## 计算机如何查看图像
### 像素和通道
数字图像是像素网格。每个像素都有代表颜色强度的数值。
|图像类型|频道 |每像素值 |示例|
|------------|----------|-----------------|---------|
| **灰度** | 1 | 0（黑色）至 255（白色）|医用X射线|
| **RGB** | 3 |红色、绿色、蓝色（每个 0–255）|标准彩色照片|
| **RGBA** | 4 | RGB + Alpha（透明度）|具有透明背景的图像|
| **单纯疱疹病毒** | 3 |色相、饱和度、明度 |基于颜色的分割 |
1920×1080 RGB 图像是形状为`(1080, 1920, 3)`的张量，即 620 万像素，每个像素有 3 个值。
### 关键操作
|运营|描述 |
|------------|-------------|
| **调整大小** |将图像缩放到目标尺寸（双线性、最近邻插值）|
| **裁剪** |提取感兴趣区域 |
| **标准化** |将神经网络的像素值缩放为 [0,1] 或 [-1,1] |
| **增强** |人为扩展训练数据（旋转、翻转、颜色抖动、裁剪）|

## 卷积：核心运算
卷积在图像上滑动一个小过滤器（内核），计算每个位置的点积。这就是 CNN 检测边缘、纹理和图案的方式。
### 卷积参数
|参数|效果|
|------------|--------|
| **内核大小** | 3×3、5×5、7×7 — 较大的内核捕获更大的模式 |
| **大步** |步长大小； stride=2 将输出尺寸减半 |
| **填充** |在边界周围添加零以保留空间维度 |
| **过滤器数量** |每个过滤器学习不同的特征（边缘、纹理、颜色图案）|
### 卷积学到什么
|层深|检测到的特征 |
|----------|--------------------|
| **早期层** |边缘、角落、简单纹理 |
| **中间层** |形状、物体部分（轮子、眼睛、叶子）|
| **深层** |高级概念（面孔、汽车、动物）|

## CNN 架构
CNN 架构的演变讲述了深度学习在计算机视觉领域的进步。
|建筑|年份|关键创新|
|------------|-----|------------|
| **LeNet-5** | 1998 |第一个实用的 CNN；数字识别 |
| **亚历克斯网络** | 2012 | Deep CNN 战胜 ImageNet； ReLU、dropout、GPU 训练 |
| **VGGNet** | 2014年|堆叠 3×3 卷积（更深=更好）|
| **GoogLeNet（盗梦空间）** | 2014年| Inception 模块（并行过滤器大小）； 22层|
| **ResNet** | 2015 | 2015跳过连接（残差学习）； 152+ 层 |
| **高效网** | 2019 | 2019复合缩放（深度+宽度+分辨率）|
| **ConvNeXt** | 2022 | 2022现代化的 ResNet；与变形金刚竞争|
### 为什么 ResNet 改变了一切
在 ResNet 之前，由于梯度消失问题，训练非常深的网络几乎是不可能的。 ResNet 引入了**跳过连接**（也称为残差连接）：层的输入被添加到其输出中。
```
output = F(x) + x    # Skip connection
```

这个简单的想法使得 152+ 层的网络能够得到有效的训练，现在它几乎成为所有深度架构的标准。

## 核心愿景任务
### 图像分类
为整个图像分配标签。
|型号|方法|
|--------|----------|
| CNN（ResNet、EfficientNet）|传统方法；卓越的准确性 |
|视觉变形金刚 (ViT) |将图像视为补丁序列；变压器编码器|
|迁移学习|在数据集上微调预训练模型 |
### 物体检测
使用边界框查找图像中的多个对象并对其进行分类。
|型号|类型 |速度|
|--------|------|--------|
| **R-CNN** |两阶段（提案+分类）|慢|
| **快速 R-CNN** |改进的两级 |中等|
| **更快的 R-CNN** |区域提案网络+检测器 |中等|
| **YOLO** (v1–v10) |单级；一次性预测框+类 |非常快|
| **DETR** |基于变压器；没有锚框|中等|
**YOLO**（You Only Look Once）是实时检测的首选。当准确性比速度更重要时，**更快的 R-CNN** 是首选。
### 图像分割
对图像中的每个像素进行分类。
|类型 |描述 |使用案例|
|------|-------------|----------|
| **语义分割** |每个像素都有一个类标签 |自动驾驶（道路、汽车、行人）|
| **实例分割** |每个像素+对象实例ID |计数物体、医学成像 |
| **全景分割** |语义+实例结合|全面场景了解 |
关键模型：U-Net（医学成像）、Mask R-CNN（实例）、DeepLab（语义）、Segment Anything Model（SAM — 通用分割）。
### 图像生成
|方法|描述 |示例 |
|----------|-------------|----------|
| **GAN** |生成器与判别器对抗训练 | StyleGAN、CycleGAN |
| **VAE** |学习潜在分布；生成样本 |变分自编码器 |
| **扩散模型** |迭代地消除随机噪声 |稳定扩散、DALL-E、中途 |
就图像生成质量而言，扩散模型已大大超越 GAN。

## 视觉迁移学习
从头开始训练 CNN 需要大量数据和计算。迁移学习可让您从已在数百万张图像 (ImageNet) 上训练的模型开始，并针对您的特定任务对其进行微调。
### 步骤
1. **选择预训练模型**（ResNet50、EfficientNet-B0、ViT）。
2. **将分类头**替换为您自己的分类头（与您的类别数相匹配）。
3. **冻结早期层**（它们捕获边缘等通用特征）。
4. 以低学习率对数据集进行**微调**。
5. **如果您需要更多适应，请逐渐解冻**。
这种方法通常只需 1,000-10,000 个标记图像即可实现高精度。

## 数据增强
增强通过应用转换来人为地扩展您的训练数据集。
|增强 |效果|何时使用 |
|-------------|--------|-------------|
| **随机裁剪** |裁剪到随机区域 |几乎总是 |
| **水平翻转** |镜像|当方向不重要时 |
| **旋转** |随机角度旋转 |当物体以任意角度出现时|
| **颜色抖动** |随机调节亮度、对比度、饱和度 |当光线变化时|
| **随机擦除** |屏蔽随机区域 |提高稳健性 |
| **混音/剪切混音** |混合两个图像和标签 |正则化|
库：`torchvision.transforms`、`albumentations`、`imgaug`、`tf.keras.preprocessing`。

## 实用技巧
- **从迁移学习开始。** 几乎在所有情况下，微调预训练模型都胜过从头开始训练。
- **对您的输入进行标准化。** 匹配预训练模型期望的标准化（通常是 ImageNet 均值/标准差）。
- **使用适当的指标。**平衡数据集的准确性；用于不平衡或检测任务的 F1、mAP 或 IoU。
- **可视化您的数据。** 查看示例图像，检查类别分布，检查模型预测。
- **明智地增强。** 仅应用对您的领域有意义的转换（不要垂直翻转医学图像）。
- **监控过度拟合。** 如果训练准确度较高但验证较低，请增加增强或添加 dropout。
