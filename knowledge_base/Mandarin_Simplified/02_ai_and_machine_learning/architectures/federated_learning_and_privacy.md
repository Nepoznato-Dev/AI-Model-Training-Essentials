# 联邦学习和隐私
联合学习是一种跨多个设备或组织训练机器学习模型而无需共享原始数据的技术。每个设备不将数据发送到中央服务器，而是训练本地模型并仅共享模型更新（梯度或权重）。中央服务器聚合这些更新以生成全局模型。它是由谷歌设计的，用于训练 Android 手机上的键盘语言模型 - 此后它已成为保护隐私的人工智能的关键技术。
---

## 为什么要联邦学习？
|动机|描述 |示例|
|------------|-------------|---------|
| **数据隐私** |原始数据永远不会离开设备|病历保存在医院；照片保留在手机上|
| **监管合规性** | GDPR、HIPAA 和其他法规限制数据共享 |银行无需共享客户数据即可进行协作 |
| **数据量** |移动数据既昂贵又缓慢|如果必须上传数据，那么在数十亿部手机上进行训练是不切实际的 |
| **数据敏感性** |有些数据过于敏感，即使经过同意也无法共享 |政府情报；个人健康数据|
---

## 联邦学习的工作原理
### 基本协议 (FedAvg)
|步骤|发生了什么 |
|------|-------------|
| **1.初始化** |中央服务器创建具有随机权重的全局模型 |
| **2.分发** |服务器将当前全局模型发送到选定的设备 |
| **3.本地培训** |每个设备都会根据其本地数据训练模型几个时期 |
| **4.上传** |设备将更新后的模型权重（而非数据）发送回服务器 |
| **5.合计** |服务器对权重进行平均（联合平均）以创建新的全局模型 |
| **6。重复** |返回步骤 2，直到模型收敛 |
```
Server: global_model = average(local_model_1, local_model_2, ..., local_model_n)
```

### 关键属性
|物业 |描述 |
|----------|-------------|
| **非独立同分布数据** |每个设备的数据分布不同（非独立同分布）|
| **不平衡数据** |有些设备有大量数据，有些设备则很少 |
| **部分参与** |并非所有设备在每一轮都可用 |
| **沟通效率** |瓶颈是通信，而不是计算 |

## 联邦学习变体
|变体 |描述 |优势 |
|--------|-------------|------------|
| **美联储平均** |跨设备的平均模型权重 |简单的;适用于 IID 数据 |
| **FedProx** |为本地培训添加最近术语 |更适合非 IID 数据 |
| **脚手架** |使用控制变量来纠正数据异质性 |非独立同分布数据的更快收敛 |
| **美联储新元** |与 FedAvg 类似，但每轮有一个梯度步长 |每轮通信成本更低 |
| **个性化FL** |每台设备都与全球设备保持个性化模型 |更好的每台设备性能 |
| **垂直FL** |各方的不同特征（不是不同的样本）|当各方持有相同数据的不同方面时 |

## 差异隐私
差分隐私 (DP) 提供了数学保证，即算法的输出不会泄露是否包含任何个人的数据。
### 核心定义
如果对于任意两个数据集 D 和 D' 在一条记录中不同，则机制 M 满足 (ε, δ)-差分隐私：
```
P(M(D) ∈ S) ≤ e^ε × P(M(D') ∈ S) + Î´
```

|参数|意义|
|------------|---------|
| **ε（ε）** |隐私预算。更小=更私密。典型值：0.1–10。 |
| **δ（δ）** |隐私保障失败的概率。通常设置为 1/N（数据集大小的倒数）。 |
### 添加隐私的机制
|机制|它是如何运作的 |使用案例|
|------------|-------------|----------|
| **高斯机制** |添加校准到查询灵敏度的高斯噪声 |连续值（模型权重）|
| **拉普拉斯机制** |添加拉普拉斯噪声 |计数查询 |
| **指数机制** |选择与其效用成正比的概率的输出 |离散选择|
### DP-SGD（差分私有随机梯度下降）
|步骤|描述 |
|------|-------------|
| 1. 计算每个样本的梯度 |而不是批量梯度 |
| 2.剪辑渐变|限制每个梯度的最大范数（限制任何单个样本的影响）|
| 3.添加噪音|将校准的高斯噪声添加到聚合梯度 |
| 4.更新参数|标准梯度下降步骤|
|权衡|描述 |
|------------|-------------|
| **隐私与准确性** |更强的隐私（更低的ε）需要更多的噪声，这会降低模型的准确性 |
| **隐私与培训时间** |噪声越大意味着收敛速度越慢 |
| **隐私预算跟踪** |每个训练步骤都会消耗一些隐私预算；一旦花费，就无法收回|
---

## 将联邦学习与差异隐私相结合
|层|保护|
|------|----------|
| **联邦学习** |原始数据保留在设备上 |
| **差异隐私** |甚至模型更新也很嘈杂，保护个人贡献 |
| **安全聚合** |服务器只能看到所有更新的聚合，而不是单个更新 |
这种组合提供了强大的隐私保证：即使服务器受到损害，它也无法确定训练中是否使用了任何特定个人的数据。

## 其他隐私保护技术
### 安全多方计算 (SMPC)
多方根据其组合数据计算函数，而无需透露各自的输入。
|特色|描述 |
|---------|-------------|
| **它是如何工作的** |数据被分成分布在各方之间的共享；计算发生在股票上 |
| **保证** |任何一方都不会了解其他方的输入信息 |
| **开销** |大量的通信和计算成本|
| **用例** |银行在不共享客户数据的情况下计算联合风险模型|
### 同态加密 (HE)
直接对加密数据执行计算。
|类型 |它支持什么 |开销|
|------|-----------------|----------|
| **部分是他** |一次运算（加法或乘法）|低|
| **有点他** |两项操作数量有限|中等|
| **完全他** |任意计算 |非常高（减速 100-1000 倍）|
|应用 |描述 |
|-------------|-------------|
| **私人推论** |在加密数据上运行机器学习模型；返回加密预测 |
| **加密训练** |训练加密数据（对于深度学习来说仍然主要是理论上的）|
| **私人查询** |查询数据库而不泄露查询或数据 |
### 可信执行环境 (TEE)
基于硬件的隔离（Intel SGX、ARM Trustzone）甚至可以保护操作系统中的数据。
|优势 |限制|
|------------|------------|
|接近原生的性能 |需要特定硬件 |
|强有力的安全保障|内存有限（飞地大小）|
|无加密开销 |可能发生旁道攻击 |

## 隐私法规和机器学习
|监管|地区 |对机器学习的影响 |
|------------|--------|-------------|
| **GDPR** |欧盟|解释权；数据最小化；同意处理；删除权|
| **CCPA** |加利福尼亚州 |知情权、删除权和选择退出数据销售的权利 |
| **健康保险流通与责任法案** |美国（医疗保健）|严格控制健康数据；去识别化要求 |
| **PIPL** |中国 |数据本地化；同意要求；跨境转账规则|
| **人工智能法案** |欧盟|透明度要求；风险分类；禁止的做法|
### 对机器学习工作流程的影响
| GDPR 原则 |机器学习的意义 |
|----------------|------------------------|
| **数据最小化** |只收集需要的东西；联邦学习有帮助|
| **目的限制** |未经新同意，无法重新利用数据 |
| **删除权** |必须能够从经过训练的模型中删除一个人的数据（机器取消学习）|
| **解释权** |模型必须具有足够的可解释性，才能解释个人的预测 |
| **隐私设计** |隐私必须从一开始就内置到系统中 |
---

## 挑战
|挑战|描述 |
|------------|-------------|
| **通讯费用** |在数百万台设备上发送模型更新的成本高昂 |
| **非独立同分布数据** |设备的数据分布差异很大，损害了融合 |
| **掉队者** |慢速设备会延迟整轮比赛 |
| **隐私与实用性的权衡** |更强的隐私意味着更差的模型性能
| **中毒攻击** |恶意参与者可能会破坏全球模型 |
| **模型提取** |即使共享模型更新也可能泄露有关训练数据的信息 |
| **硬件异构性** |不同的设备有不同的计算能力 |

＃＃ 概括
联邦学习和隐私保护技术解决了一个根本性的矛盾：当数据是分布式的、敏感的或受监管的时候，如何构建强大的人工智能模型？联邦学习将数据保留在设备上并仅共享模型更新。差异隐私增加了个人贡献无法被检测到的数学保证。安全计算和同态加密更进一步，允许对加密数据进行计算。每种技术都有成本——通信开销、准确性降低、计算费用——但它们共同构成了一个工具包，用于构建尊重隐私的人工智能，同时仍然可以从世界数据中学习。
