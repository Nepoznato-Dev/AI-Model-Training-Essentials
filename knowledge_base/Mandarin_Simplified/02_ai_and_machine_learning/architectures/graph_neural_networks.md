# 图神经网络
图神经网络 (GNN) 是设计用于操作图结构数据的神经网络，即通过边连接的节点网络。传统神经网络在网格（图像）或序列（文本）上工作，而 GNN 可以处理任意关系结构：社交网络、分子图、知识图、道路网络、推荐图等。它们对于药物发现、欺诈检测、推荐系统以及实体之间的关系很重要的任何领域都至关重要。
---

## 什么是图？
|组件|描述 |示例|
|------------|-------------|---------|
| **节点（顶点）** |实体 |一个人，一个分子的原子，一座城市|
| **边缘** |两个节点之间的关系 |友谊、化学键、道路|
| **边缘重量** |关系的强度或类型 |距离、相似度、容量 |
| **节点功能** |每个节点的属性|年龄、原子序数、人口|
| **边缘特征** |每条边的属性 |关系类型、距离 |
| **邻接矩阵** |矩阵 A，其中 A[i][j] = 1，如果节点 i 和 j 连接 |对图结构进行编码 |
### 图的类型
|类型 |描述 |示例|
|------|-------------|---------|
| **无指导** |边缘没有方向 |友情网|
| **导演** |边有方向 (A→B ≠ B→A) |推特关注者 |
| **加权** |边有数值|道路网络与距离|
| **异质** |多种节点和边缘类型 |学术图表（论文、作者、地点）|
| **动态** |图结构随时间变化 |社交网络随着时间的推移而发展|
| **双方** |两种类型的节点；边缘仅在类型之间 |用户-项目推荐图|
---

## 为什么不使用常规神经网络？
|方法|为什么失败 |
|----------|-------------|
| **前馈网络** |需要固定大小的输入；图表的大小和结构各不相同 |
| **美国有线电视新闻网** |假设网格结构；图表没有规则的网格 |
| **RNN/变压器** |假设顺序；图没有自然顺序 |
GNN 通过直接在图结构上操作、在其邻居的上下文中处理每个节点来解决这个问题。
---

## 核心 GNN 架构
### 消息传递框架
大多数 GNN 遵循相同的模式：每个节点从其邻居收集信息，组合信息，并更新自己的表示。
|步骤|描述 |
|------|-------------|
| **1.留言** |每个节点向其邻居发送消息（基于其当前功能）|
| **2.合计** |每个节点收集并组合来自所有邻居的消息 |
| **3.更新** |每个节点使用聚合消息更新自己的表示 |
| **4.重复** |对 K 层执行此操作 → 每个节点捕获 K 跳之外的信息 |
### 关键 GNN 模型
|型号|聚合方法|关键创新|
|--------|--------------------------------|----------------|
| **GCN**（图卷积网络）|邻居特征的平均值 |简单的;有效的;光谱动机|
| **GraphSAGE** |样本和聚合；可以使用均值、LSTM 或池化 |归纳（处理看不见的节点）；可扩展|
| **GAT**（图注意力网络）|注意力加权邻居聚合 |了解哪些邻居最重要 |
| **GIN**（图同构网络）|邻居特征总和|最大限度地表达；可以区分任何可通过 WL 测试区分的图 |
| **MPNN**（消息传递神经网络）|通用消息传递框架|统一许多 GNN 变体 |
### GCN 的工作原理（一步一步）
```
For each layer:
  1. For each node, collect features from all neighbours
  2. Multiply by a learnable weight matrix W
  3. Normalise by node degree (so high-degree nodes don't dominate)
  4. Apply non-linearity (ReLU)
  5. This becomes the node's new representation
```

经过 K 层后，每个节点的表示对图中距离 K 跳的信息进行编码。

## 图级任务
|任务|描述 |示例|
|------|-------------|---------|
| **节点分类** |预测每个节点的标签 |将用户分类为机器人或人类 |
| **链接预测** |预测边缘是否存在（或将存在） |预测缺失的关系；推荐连接 |
| **图分类** |预测整个图的标签 |将分子分类为有毒或无毒 |
| **社区检测** |查找密集连接节点的集群 |识别社会群体 |
| **图形生成** |生成具有所需属性的新图表 |设计新分子|
---

## 应用
### 药物发现和分子特性预测
|任务| GNN 如何提供帮助 |
|------|--------------|
| **分子性质预测** |将分子表示为图（原子=节点，键=边）；预测毒性、溶解度、结合亲和力 |
| **药物间相互作用** |将药物和靶点建模为图表；预测不良相互作用|
| **从头药物设计** |生成具有所需特性的新颖分子图 |
### 推荐系统
|方法|描述 |
|----------|-------------|
| **用户-项目图** |用户和物品都是节点；购买/观看是优势 |
| **基于图的协同过滤** | GNN 通过图传播偏好 |
| **知识图谱推荐** |将用户偏好与项目知识（类型、演员、导演）相结合 |
### 欺诈检测
|应用 |图结构|
|-------------|----------------|
| **财务欺诈** |交易形成图表；欺诈模式以子图结构的形式出现
| **保险欺诈** |索赔人、提供者和保单形成一个图表；诈骗团伙被发现|
| **帐户接管** |登录模式形成图表；异常连接信号泄露|
### 知识图谱
|任务|描述 |
|------|-------------|
| **链接预测** |预测缺失的事实（例如，“巴黎是……的首都？”）|
| **实体解析** |确定两个提及是否指的是同一实体 |
| **问答** |浏览图表寻找答案 |

## 高级 GNN 概念
### 过度平滑
|问题 |描述 |解决方案 |
|---------|-------------|----------|
| **过度平滑** |经过许多层后，所有节点表示都变得相似 |限制深度（2-4层）；使用剩余连接；使用跳跃知识|
### 过度挤压
|问题 |描述 |解决方案 |
|---------|-------------|----------|
| **过度挤压** |来自远程节点的信息被压缩为固定大小的向量 |使用图形转换器；分层池|
### 图形转换器
|型号|主要特点|
|--------|-------------|
| **图形转换器** |将标准 Transformer 注意力应用于所有节点对 |
| **GPS**（图形提示系统）|将局部 GNN 层与全局 Transformer 层相结合 |
| **绘图师** |添加基于图结构的位置编码 |
### 异构图网络
|型号|描述 |
|--------|-------------|
| **R-GCN** |关系型GCN；不同边类型的不同权重矩阵|
| **韩** |异构注意力网络；注意不同的节点和边类型 |
| **HetGNN** |异构图神经网络；处理多种节点类型 |

## 可扩展性
|挑战|解决方案 |
|------------|----------|
| **大型图**（数百万个节点）|小批量训练；邻点抽样|
| **内存** |跨 GPU 的图形分区 |
| **速度** |稀疏矩阵运算；专业图书馆|
### 抽样策略
|策略|描述 |
|----------|-------------|
| **节点采样** |对节点子集及其 K 跳邻域进行采样 |
| **边缘采样** |示例边及其连接的节点 |
| **聚类抽样** |将图划分为簇；集群训练 |
| **随机游走采样** |通过从目标节点随机游走的样本节点 |

＃＃ 概括
图神经网络将深度学习扩展到关系数据——网络、分子、知识图以及任何实体连接的系统。它们通过在邻居之间传递消息来工作，允许每个节点从其本地上下文中学习。 GNN 在药物发现、推荐系统、欺诈检测和知识图谱中找到了最强大的应用。该领域正在朝着图转换器、异构图和大规模现实网络的可扩展训练方向发展。如果您的数据存在关系，GNN 可能值得考虑。
