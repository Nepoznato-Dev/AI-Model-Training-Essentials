# 强化学习
强化学习 (RL) 是机器学习通过反复试验做出一系列决策的方式。与为每个示例提供正确答案的监督学习不同，强化学习仅向代理提供奖励信号，并且代理必须弄清楚哪些行动会随着时间的推移带来最佳结果。它是 AlphaGo、机器人控制、游戏人工智能以及最重要的 RLHF（用于将现代大型语言模型与人类偏好保持一致的技术）背后的方法。
---

## 核心概念
强化学习将决策框架构建为**代理**和**环境**之间的循环。
|组件|角色 |示例|
|------------|------|---------|
| **代理** |决策者|国际象棋程序、机器人、语言模型 |
| **环境** |代理与之交互的世界 |棋盘、仓库、对话|
| **状态** |现状|棋盘位置、机器人传感器读数、聊天记录 |
| **行动** |代理可以做什么 |移动一个棋子，左转，生成一个令牌 |
| **奖励** |反馈信号（标量）| +1 表示获胜，-1 表示崩溃，人类偏好分数 |
| **政策** |战略将状态映射到行动| “如果国王受到威胁，就移动它”|
| **价值函数** |国家的预期累积奖励| “这个棋盘位置大约值+3分”|
### 强化学习循环
```
Agent observes State → chooses Action → Environment returns new State + Reward
        ↑                                                                         |
        └─────────────────────────────────────────────────────────────────────────┘
```

代理的目标是随着时间的推移最大化**累积奖励**，而不仅仅是即时奖励。这就是强化学习与监督学习的根本区别。
---

## 与其他学习范式的主要区别
|方面|监督学习|无监督学习 |强化学习 |
|--------------------|--------------------|---------------------|------------------------|
| **信号** |每个示例的正确标签 |没有标签；查找结构|标量奖励，经常延迟 |
| **反馈** |立即 |无 |延迟且稀疏|
| **顺序** |每个例子都是独立的 |每个例子都是独立的 |行动影响未来状态|
| **目标** |最小化预测误差 |发现模式|最大化累积奖励 |
---

## 马尔可夫决策过程 (MDP)
MDP 是强化学习的数学框架。他们认为未来仅取决于当前状态，而不取决于您如何到达那里的历史（**马尔可夫属性**）。
|组件|符号|意义|
|------------|----------|---------|
| **州** | S |代理可能处于的所有可能情况 |
| **行动** |一个 |代理可以做的所有事情 |
| **转换函数** | P(s' \| s, a) | P(s' \| s, a) |在状态 s 中采取动作 a 后到达状态 s' 的概率 |
| **奖励功能** | R(s, a, s') | R(s, a, s') |获得的过渡奖励 |
| **折扣系数** | γ（伽玛）|未来奖励与眼前奖励的价值有多大（0 到 1）|
**回报**（总折扣奖励）是：
```
G = R₁ + γR₂ + γ²R₃ + ...
```

高折扣因子（γ接近1）意味着代理人有远见。低意味着它是短视的。

## 经典强化学习算法
### 基于值的方法
这些学习每个状态（或状态-动作对）的好坏。
|算法|关键理念|限制|
|------------|----------|------------|
| **Q-学习** |了解 Q 值表：Q(状态，动作) = 预期奖励 |无法扩展到大型状态空间 |
| **深度 Q 网络 (DQN)** |使用神经网络来近似 Q 值 |只处理离散动作；可能不稳定 |
| **双 DQN** |修复 Q-learning 的高估偏差 |仍仅限于离散行动|
Q-learning更新规则：
```
Q(s, a) ← Q(s, a) + α [r + γ max Q(s', a') - Q(s, a)]
```

### 基于策略的方法
这些直接学习策略（策略）而不估计值。
|算法|关键理念|优势 |
|------------|----------|------------|
| **加强** |蒙特卡罗政策梯度；更新政策以取得良好成果|简单的;持续行动|
| **PPO**（近端策略优化）|剪辑政策更新以防止发生重大的、不稳定的变化|稳定的;广泛使用；良好的默认|
| **TRPO** |策略更新的信任域方法|比PPO更有原则性；实施起来更困难|
### Actor-Critic 方法
结合两者的优点：**参与者**（政策）和**批评家**（价值函数）。
|算法|关键理念|
|------------|----------|
| **A2C / A3C** |优势演员评论家；使用优势估计来减少方差 |
| **SAC**（软演员评论家）|在保持探索的同时最大化奖励（熵正则化）|
| **TD3**（双延迟 DDPG）|解决连续动作空间中的高估问题 |

## RLHF：根据人类反馈进行强化学习
RLHF 是使 ChatGPT 成为可能的技术。它弥合了可以预测文本的模型和产生人类实际上认为有用的输出的模型之间的差距。
### 三个步骤
|步骤|发生了什么 |输出|
|------|-------------|--------|
| **1.监督微调 (SFT)** |根据高质量的人工编写示例微调预训练模型 |能够很好地遵循说明的模型 |
| **2.奖励模型培训** |人类比较成对的模型输出；训练模型来预测人类偏好 |对输出质量进行评分的奖励模型 |
| **3.强化学习优化** |使用PPO微调SFT模型，最大化奖励模型的分数 |符合人类偏好的模型 |
### 为什么 RLHF 很重要
如果没有 RLHF，语言模型就像一个读过每一本书但不知道如何在对话中表现的学生。它可以生成文本，但文本可能没有帮助、有毒或完全没有抓住重点。 RLHF 教导模型“人类想要什么”——而不仅仅是文本的外观。
### 变体和替代方案
|方法|描述 |优势 |
|--------|-------------|------------|
| **DPO**（直接偏好优化）|跳过奖励模式；直接根据人类偏好优化政策 |更简单；没有单独的奖励模型可以训练|
| **RLAIF** |使用人工智能（而不是人类）生成偏好标签 |比人工标记更便宜 |
| **宪法人工智能** |使用一组原则来指导模型行为，无需人工标签 |更具可扩展性；人择的方法|
| **GRPO**（集团相关政策优化）|比较一组内的输出，而不是与单独的模型进行比较 |用于DeepSeek-R1；减少对价值网络的需求|

## 探索与利用
这是强化学习的核心张力。 **利用**意味着选择你知道行之有效的行动。 **探索**意味着尝试新事物以发现可能更好的策略。
|战略|它是如何运作的 |权衡|
|----------|-------------|------------|
| **ε-贪婪** |大多数时候选择最好的动作；概率为 ε 的随机行动 |简单但低效 |
| **玻尔兹曼探索** |根据估计值概率性地选择行动 |比 ε-贪婪更平滑 |
| **UCB**（置信上限）|偏好具有高度不确定性的行动（面对不确定性保持乐观）|良好的理论保证 |
| **熵正则化** |为访问不同的州添加奖励（用于 SAC、PPO） |鼓励自然探索 |

## 多智能体强化学习
当多个智能体同时学习时，动态就会变得更加复杂。
|场景 |挑战|示例|
|----------|------------|---------|
| **合作** |代理商必须协调；学分分配很难|机器人足球队；分布式传感器网络|
| **有竞争力** |对手适应；环境是非平稳的 |游戏人工智能（扑克、星际争霸）；网络安全 |
| **混合** |一些代理商合作，另一些代理商竞争 |拍卖市场；交通系统|
|算法|描述 |
|------------|-------------|
| **MADDPG** | DDPG多代理版本；集中的评论家，分散的行动者|
| **MAPPO** |多智能体PPO；广泛应用于实践 |
| **自玩** |特工针对自身副本进行训练（AlphaGo、AlphaStar）|

## 模拟到真实的传输
在现实世界中训练机器人既缓慢又危险。相反，代理在模拟中进行训练并转移到现实中。
|挑战|解决方案 |
|------------|----------|
| **现实差距**（模拟≠现实世界）|领域随机化：在训练期间改变物理参数 |
| **样品效率低下** |使用基于模型的 RL 或在大型并行仿真中进行训练 |
| **安全** |约束强化学习：惩罚训练期间的不安全行为 |
| **部分可观察性** |使用噪声传感器和延迟观测进行训练 |
波士顿动力和特斯拉等公司广泛使用模拟，但模拟性能和物理性能之间的差距仍然是该领域最大的挑战之一。

## 实用技巧
- **从 PPO 开始。** 它是最可靠的通用算法。如果您不确定使用什么，PPO 是默认值。
- **使你的奖励正常化。** 奖励比例会极大地影响训练的稳定性。
- **使用矢量化环境。** 并行运行多个环境（例如 8-64）可以稳定梯度估计并极大地加快训练速度。
- **同时监控奖励和熵。** 如果熵降至零，则您的代理已停止探索并且可能陷入局部最优。
- **奖励塑造是一门艺术。** 设计正确的奖励函数通常是最困难的部分。稀疏的奖励（仅在最后）使学习变得极其缓慢。密集、形状良好的奖励可以指导智能体，但可能会带来意想不到的行为。
- **RLHF 很脆弱。** 奖励模型或 PPO 超参数的微小变化可能会导致质量大幅下降。如果您不需要完整的 RLHF 管道，DPO 是更稳定的替代方案。

＃＃ 概括
强化学习是对智能体如何通过交互学习做出决策的研究。它的范围从 Q-learning 等经典算法到 PPO 和 SAC 等现代深度强化学习方法，并且它支撑着人工智能领域的一些最重要的最新进展——从游戏到语言模型对齐。核心挑战仍然是一样的：当反馈延迟、稀疏和嘈杂时，如何学习最佳行为？答案是在巧妙的数学指导下进行反复试验，结果证明这是所有人工智能中最强大的想法之一。
