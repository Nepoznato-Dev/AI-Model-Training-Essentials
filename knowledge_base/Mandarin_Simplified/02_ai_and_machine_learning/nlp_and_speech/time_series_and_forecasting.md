# 时间序列和预测
时间序列数据是随时间推移收集的任何数据：股票价格、温度读数、网站流量、销售数据、心率监测器、能源消耗。预测是指根据过去的模式预测未来的价值。它是数据科学最有实际价值的应用之一，也是最困难的应用之一，因为未来确实是不确定的，而现实世界的时间序列充满了噪音、季节性和结构性中断。
---

## 时间序列的特征
|组件|描述 |示例|
|------------|-------------|---------|
| **趋势** |长期增减|数十年来全球气温不断上升
| **季节性** |固定时间间隔内有规律、可预测的模式 |每年 12 月零售额激增 |
| **周期性** |以非固定间隔波动（通常是经济波动） |每5-10年就会出现一次衰退|
| **噪音（残余）** |无法解释的随机变化 |每日股价走势|
| **自相关** |当前值取决于过去值 |今天的气温与昨天相似 |
### 平稳性
如果时间序列的统计属性（均值、方差）不随时间变化，则该时间序列是**平稳的**。大多数预测方法都假设平稳性。
|测试|目的|
|------|---------|
| **增强迪基-富勒 (ADF)** |测试单位根是否存在（非平稳） |
| **KPSS 测试** |测试该系列是否趋势平稳 |
|转型|何时使用 |
|----------------|-------------|
| **差异** |删除趋势： y'(t) = y(t) - y(t-1) |
| **对数变换** |稳定方差（指数增长）|
| **季节性差异** |消除季节性： y'(t) = y(t) - y(t-s) 其中 s 是季节长度 |

## 经典预测方法
### 移动平均线
|方法|描述 |最适合 |
|--------|-------------|----------|
| **简单移动平均线 (SMA)** |最后 N 个观测值的平均值 |平滑噪声数据 |
| **加权移动平均线** |最近的观察结果获得更高的权重 |当最新数据更重要时 |
| **指数移动平均线 (EMA)** |重量呈指数下降|以更少的滞后跟踪趋势 |
### 指数平滑
|方法|组件|使用案例|
|--------|------------|----------|
| **简单（SES）** |仅限级别 |无趋势，无季节性 |
| **霍尔特（双人间）** |水平+趋势|数据有趋势但无季节性 |
| **霍尔特-温特斯（三重）** |水平+趋势+季节性 |具有趋势和季节性的数据 |
### ARIMA 及其变体
ARIMA（自回归综合移动平均线）是经典时间序列预测的主力。
|组件|意义|参数|
|------------|---------|------------|
| **AR (p)** |对之前的 p 值进行回归 |使用多少个过去的值|
| **我（d）** |使平稳的差分步骤数 |相差多少倍|
| **MA (q)** |将错误建模为过去错误的组合 |使用多少过去的错误|
|变体 |扩展|使用案例|
|--------|------------|----------|
| **萨里玛** |添加季节性成分（P、D、Q、s）|数据季节性较强|
| **阿里麦克斯** |添加外部变量 |当您了解即将举行的活动时 |
| **VAR** |多元 ARIMA；多个相互依存的系列|当变量相互影响时|

## 现代机器学习方法
### 基于 LSTM 和 RNN 的模型
|型号|建筑|优势 |
|--------|-------------|------------|
| **LSTM** |长短期记忆网络|捕获远程时间依赖性 |
| **格鲁** |门控循环单元（更简单的 LSTM）|更快的训练；类似的表现 |
| **Seq2Seq** |时间序列的编码器-解码器 |灵活的输入/输出长度|
| **时间卷积网络（TCN）** |扩张因果卷积 |并行训练；长感受野|
### 先知（元）
专为业务时间序列设计的实用预测工具。
|特色 |描述 |
|---------|-------------|
| **分解** |趋势+季节性+假期|
| **灵活** |处理缺失数据、异常值和结构断裂 |
| **可解释** |组件是人类可读的 |
| **自动** |合理的默认值；需要最少的调整|
|实力|限制|
|----------|------------|
|非常适合业务指标（销售额、用户）|对于高频数据来说并不理想 |
|处理假期和特殊活动|假设加法或乘法季节性 |
|对异常值具有鲁棒性 |对于复杂模式的准确度不如深度学习 |
### 基于 Transformer 的模型
|型号|主要特点|
|--------|-------------|
| **线人** | ProbSparse 对长序列的关注 |
| **自动成型机** |级数分解的自相关机制|
| **补丁TST** |修补时间序列；渠道无关|
| **TimesFM**（谷歌）|时间序列的基础模型；对不同数据进行预训练 |
| **Chronos**（亚马逊）|对时间序列进行标记；使用LLM风格的架构|

## 时间序列中的异常检测
检测偏离预期行为的异常模式。
|方法|方法|使用案例|
|--------|----------|----------|
| **统计** | Z 分数、IQR、控制图 |简单易懂|
| **隔离森林** |基于树；通过随机分区隔离异常 |多变量异常检测 |
| **LOF**（局部异常值因子）|基于密度；与邻居比较本地密度 |当异常出现在低密度区域时 |
| **自动编码器** |重建错误；高错误 = 异常 |复杂的非线性模式 |
| **基于 LSTM** |预测下一步；大的预测误差=异常|连续异常 |
### 应用程序
|域名 |异常意味着什么？
|--------|--------------------|
| **金融** |欺诈、市场崩盘、闪电崩盘 |
| **医疗保健** |心率异常、癫痫发作 |
| **制造** |设备故障、质量缺陷|
| **网络安全** |入侵尝试、DDoS 攻击 |
| **基础设施** |服务器过载、网络故障|

## 评估指标
|公制|公式（概念）|何时使用 |
|--------|---------------------|-------------|
| **MAE**（平均绝对误差）|绝对误差的平均值|可解释；与数据相同的单位 |
| **RMSE**（均方根误差）|平均平方误差的平方根 |大错误处罚更多 |
| **MAPE**（平均绝对百分比误差）|绝对百分比误差的平均值 |当相对误差很重要时 |
| **SMAPE**（对称 MAPE）| MAPE 的对称版本 |更好地处理接近于零的值 |
| **MASE**（平均绝对标度误差）| MAE 相对于天真的预测 |不同系列的比较|

## 实际工作流程
|步骤|描述 |
|------|-------------|
| **1.探索** |绘制系列图；识别趋势、季节性、异常值 |
| **2.分解** |分为趋势、季节性和残余成分 |
| **3.静止** |如果需要，应用差分或变换 |
| **4.分裂** |基于时间的分割（时间序列绝不随机分割）|
| **5.基线** |从天真的预测开始（最后一个值，季节性天真）|
| **6。型号** |尝试经典方法（ARIMA、Prophet），然后尝试 ML 方法 |
| **7.评估** |使用适当的指标；与基线比较|
| **8.迭代** |添加功能、尝试不同的模型、调整超参数 |

＃＃ 概括
时间序列预测将经典统计学与现代机器学习相结合。经典方法（ARIMA、指数平滑、Prophet）可解释、快速且通常准确。深度学习方法（LSTM、Transformers）捕获复杂模式，但需要更多数据和调整。无论采用何种方法，关键原则都是相同的：了解数据的结构（趋势、季节性、噪声）、与简单的基线进行比较、使用适当的指标进行评估，并考虑到未来不会完全复制过去的事实。
