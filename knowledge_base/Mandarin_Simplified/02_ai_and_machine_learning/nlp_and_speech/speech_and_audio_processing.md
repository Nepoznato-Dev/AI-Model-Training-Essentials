# 语音和音频处理
语音和音频处理涵盖了让机器听到、理解、生成和操纵声音的技术。这包括语音识别（将口语单词转换为文本）、语音合成（将文本转换为口语单词）、说话人识别、音乐生成和环境声音理解。深度学习已经改变了这个领域——现代系统的语音识别精度达到了人类水平，并产生出奇自然的合成声音。
---

## 数字音频基础知识
声音是一种压力波。为了以数字方式处理它，我们定期对波进行采样。
|概念 |描述 |典型值|
|--------|-------------|---------------|
| **采样率** |每秒测量声音多少次 | 8 kHz（电话）、16 kHz（语音）、44.1 kHz（CD）、48 kHz（专业）|
| **位深度** |每个样品的精度 | 16 位（CD）、24 位（专业）、32 位浮点（处理）|
| **频道** |单声道 (1)、立体声 (2)、环绕声 (5.1、7.1) |音乐立体声；单声道语音 |
| **持续时间** |音频长度 |变化 |
1 分钟单声道录音，频率为 16 kHz，16 位 = 1.92 MB。一首 3 分钟的立体声歌曲，44.1 kHz，16 位 = 30.3 MB。

## 音频特征提取
原始音频波形很难让模型直接使用。我们提取捕捉声音重要特征的特征。
|特色 |它捕获了什么 |使用案例|
|------|------------------|----------|
| **梅尔谱图** |随时间变化的频率内容，映射到人类听觉感知 |语音识别、音乐分类|
| **MFCC**（梅尔频率倒谱系数）|频谱包络的​​紧凑表示 |传统语音识别 |
| **色谱图** |音高分布（正在播放哪些音符）|音乐分析、和弦检测 |
| **过零率** |信号过零的频率 |浊音与清音检测 |
| **均方根能量** |随时间变化的信号响度|语音活动检测 |
| **俯仰 (F0)** |基频|说话人识别、音乐转录 |
### 梅尔频谱图
深度学习最常见的音频表示。它将音频转换为类似 2D 图像的格式：
|轴|代表|
|------|------------|
| **X 轴** |时间 |
| **Y 轴** |频率（梅尔等级 - 感知间隔）|
| **颜色/强度** |在该频率和时间的能量|
梅尔音阶近似于人类的听力：我们比高频更擅长区分低频。

## 自动语音识别 (ASR)
ASR 将口语转换为文本。它是音频人工智能最重要的商业应用之一。
### ASR 的演变
|时代|方法|限制|
|-----|----------|------------|
| **2010 年之前** |隐马尔可夫模型+高斯混合模型|需要大量的手工工程；噪音条件下较差|
| **2010-2015** | DNN-HMM 混合 |神经网络取代了 GMM；显着改善|
| **2015-2020** |端到端模型（深度语音、LAS）|从音频到文本的单一神经网络 |
| **2020+** |基于 Transformer（Whisper、Conformer）|最先进的精度；多种语言;坚固耐用 |
### 关键 ASR 模型
|型号|建筑|培训数据|显着特点|
|--------|-------------|------------------------|-----------------|
| **耳语** (OpenAI) |编码器-解码器变压器| 680,000 小时，99 种语言 |多种语言;对口音和噪音具有鲁棒性；开源 |
| **符合者** |卷积+自注意力|各种|结合局部（转换）和全局（注意力）特征 |
| **wav2vec 2.0** |自监督变压器 |未标记的言论 |从原始音频中学习，无需转录 |
| **USM**（谷歌）|通用语音模型 | 200 万小时，300 多种语言 |涵盖的大多数语言 |
| **彩信**（元）|大规模多语言语音 | 1,400 多种语言 |将覆盖范围扩展到资源匮乏的语言 |
### ASR 指标
|公制|描述 |
|--------|-------------|
| **WER**（字错误率）|错误转录的单词百分比。越低越好。对于干净的英语，人类的表现约为 4-5%。 |
| **CER**（字符错误率）|与 WER 相同，但在角色级别。用于没有单词边界的语言（中文、日语）。 |
### 常见的 ASR 挑战
|挑战|描述 |
|------------|-------------|
| **口音和方言** |对于非标准口音，性能显着下降 |
| **背景噪音** |音乐、交通、其他说话者会降低准确性 |
| **代码转换** |说话者在句子中间切换语言 |
| **同音字** | “那里”与“他们的”与“他们是”——需要上下文 |
| **标点符号和格式** | ASR 输出通常不加标点；需要后期处理 |
| **低资源语言** |大多数模型对于训练数据很少的语言表现不佳

## 文本转语音 (TTS)
TTS 将书面文本转换为语音音频。现代系统产生的语音通常与人类录音无法区分。
### TTS 的演变
|时代|方法|品质 |
|-----|----------|---------|
| **2010 年之前** |连接（拼接记录的片段）|机器人；表达能力有限|
| **2010-2017** |统计参数（HMM、早期神经网络）|更好，但仍可被识别为合成的 |
| **2017-2020** |神经网络（Tacotron、WaveNet）|接近人类的品质；富有表现力|
| **2020+** |神经编解码器（VALL-E、Bark）|语音克隆；少射；高度自然 |
### 关键 TTS 模型
|型号|建筑|显着特点|
|--------|-------------|-----------------|
| **WaveNet** (DeepMind) |自回归生成模型 |第一个真正听起来自然的 TTS |
| **Tacotron 2**（谷歌）| Seq2seq + 声码器 |端到端；高品质|
| **维特** |变分推理+对抗训练 |快速地;质量好；广泛应用|
| **VALL-E**（微软）|神经编解码器语言模型 |从 3 秒样本克隆声音 |
| **树皮** (Suno) |基于变压器|多种语言;非言语声音（笑声、音乐） |
| **十一实验室** |商业|业界领先的语音克隆|
| **聊天TTS** |开源|针对对话式语音进行了优化 |
| **鱼语** |开源|快速地;多语言 |
### 语音克隆
语音克隆可以从短音频样本中创建听起来像特定人的合成语音。
|方法|所需数据|品质 |
|--------|------------|---------|
| **微调** | 10-60 分钟演讲 |高质量;特定于演讲者 |
| **少射** | 3-30 秒演讲 |品质好；快速设置 |
| **零射击** |没有目标说话人数据 |在推理时使用参考音频 |
**道德问题**：语音克隆可用于冒充、欺诈和深度伪造。大多数商业提供商都需要语音同意。

## 说话人识别
|任务|描述 |应用 |
|------|-------------|-------------|
| **发言者验证** | “这个人就是他们声称的那个人吗？” |电话银行、设备解锁 |
| **说话人识别** | “谁在说话？” |会议转录、取证 |
| **演讲者分类** | “谁在什么时候说话？” （在多扬声器音频中）|会议摘要、字幕生成 |
|型号|方法|
|--------|----------|
| **ECAPA-TDNN** |基于嵌入；最先进的验证 |
| **d-向量** |来自 DNN 的简单说话者嵌入 |
| **x-向量** |改进的扬声器嵌入；广泛应用|

## 实用技巧
- **始终聆听您的数据。** 在进行任何训练之前，请聆听示例音频。注意采样率、噪声水平和扬声器特性。
- **匹配采样率。** Whisper 预计为 16 kHz。如果您的音频为 44.1 kHz，请对其重新采样 - 但请注意，下采样会丢失信息。
- **增强音频数据。** 添加背景噪音，改变速度和音调，模拟不同的麦克风。这极大地提高了鲁棒性。
- **使用预先训练的模型。** 用于 ASR 的 Whisper 和用于 TTS 的 VITS/Bark 是很好的起点。微调几乎总是比从头开始训练要好。
- **处理静音。** 语音活动检测 (VAD) 在处理之前消除静音，从而节省计算量并提高准确性。 Silero VAD 和 WebRTC VAD 是流行的选择。
- **标准化音量。**不同的录音具有非常不同的响度级别。处理前标准化至一致的水平。

＃＃ 概括
深度学习彻底改变了语音和音频处理。 Whisper 等现代 ASR 系统在数十种语言中都达到了人类水平的准确性。 TTS 系统产生的语音与人类录音越来越难以区分。语音克隆可以从几秒钟的音频开始。音乐生成、源分离和环境声音检测都在快速发展。该领域面临着持续的挑战——资源匮乏的语言、嘈杂的环境、语音克隆的伦理问题——但发展轨迹是明确的：机器在听觉、理解和产生声音方面正变得和人类一样好。
