# 多模态人工智能
多模式人工智能系统同时处理和组合来自多种类型数据（文本、图像、音频、视频等）的信息。虽然早期的人工智能系统通常是单模态（仅文本、仅图像），但最强大的现代系统是多模态的。 GPT-4V同时读取图像和文本； Gemini 原生处理文本、图像、音频和视频；像 Sora 这样的系统可以根据文本描述生成视频。该文件介绍了多模式人工智能的工作原理、其背后的架构，以及为什么组合模式如此强大。
---

## 为什么是多式联运？
|效益 |描述 |示例|
|---------|-------------|---------|
| **更丰富的理解** |不同的方式提供补充信息|视频能够传达仅靠文本无法传达的动作、声音和背景 |
| **更好的概括** |跨模式学习创造更强大的表征 |看过“猫”的图像和文字描述的模型可以更好地理解这个概念 |
| **更自然的互动** |人类通过多种渠道进行交流|语音助手可以看到你所指的内容 |
| **跨模式转乘** |来自一种方式的知识有助于另一种方式 |图像理解可以改善文本生成，反之亦然 |
---

## 核心架构
### 视觉语言模型 (VLM)
同时处理图像和文本的模型。
|建筑|它是如何运作的 |示例 |
|-------------|-------------|---------|
| **双编码器** |图像和文本分开的编码器；稍后合并|剪辑、对齐 |
| **融合编码器** |图像和文本标记交织并一起处理 |火烈鸟，双子座|
| **交叉关注** |文本标记关注图像特征（反之亦然）|火烈鸟、可口可乐|
| **统一标记器** |图像被转换为​​标记并与文本标记一起处理 |双子座、变色龙|
### 视觉语言模型如何工作
|步骤|描述 |
|------|-------------|
| **1.编码图像** |视觉编码器（ViT、SigLIP）将图像转换为一组特征向量 |
| **2.编码文本** |语言编码器处理文本标记 |
| **3.熔断方式** |图像特征被投影到语言模型的嵌入空间中 |
| **4.生成** |语言模型根据图像和文本输入生成文本
### 关键视觉语言模型
|型号|开发商|建筑|显着特点|
|--------|---------|-------------|------------------|
| **剪辑** |开放人工智能 |双编码器（ViT + 文本编码器）|通过文本进行零样本图像分类 |
| **拉瓦** |开源| LLaMA + CLIP 视觉编码器 |开源VLM；强大的社区|
| **GPT-4V/4o** |开放人工智能 |统一多式联运|一起处理文本、图像、音频 |
| **双子座** |谷歌 DeepMind |来自培训的原生多模式 |从头开始为多式联运而打造 |
| **克劳德** |人择 |视觉+文字|擅长文档和图表理解 |
| **Qwen-VL** |阿里巴巴 |开放重量 VLM |与封闭机型竞争|
| **实习生VL** |开源|多尺度视觉编码器 |强大的开源选项|

| **聊天TTS** |开源|具有自然韵律的对话式演讲 |
| **鱼语** |开源|多种语言;快速推理 |

|型号|能力|

## 视频模型
视频结合了图像、音频、文本和时间——使其成为最复杂的模式。
|型号|类型 |能力|
|--------|------|-------------|
| **索拉** (OpenAI) |文字转视频|高达 1080p；懂物理 |
| **双子座** |视频理解 |可以分析带音频的长视频 |
| **视频-LLaVA** |视频+文字|开源视频理解|
| **跑道第三代** |文本/图像转视频 |商业视频生成 |
| **克林** |文字转视频|长视频生成 |
### 视频理解挑战
|挑战|描述 |
|------------|-------------|
| **时间推理** |了解随时间推移发生的事件 |
| **长上下文** |视频可能长达数小时；处理所有帧的成本很高|
| **视听同步** |将所说的与所显示的联系起来 |
| **因果关系** |了解视频序列中的因果关系 |

## 跨模态检索
跨不同方式查找相关内容。
|任务|描述 |示例|
|------|-------------|---------|
| **文本→图像** |查找与文本查询匹配的图像 |在照片库中搜索“山上的日落”|
| **图像 → 文本** |查找与图像相关的文本 |为图像生成标题 |
| **文本 → 音频** |查找与描述匹配的声音 |声音设计：“碎石上的脚步声”|
| **图像→图像** |查找视觉上相似的图像 |按图片搜索产品|
### 用于跨模式检索的 CLIP
CLIP 的共享嵌入空间可实现零样本跨模态检索：
|步骤|描述 |
|------|-------------|
| 1 |使用视觉编码器对所有图像进行编码 |
| 2 |使用文本编码器对文本查询进行编码 |
| 3 |计算文本嵌入和所有图像嵌入之间的余弦相似度 |
| 4 |返回相似度最高的图像 |
这无需任何特定于任务的训练即可工作——这种特性称为“零射击”能力。

## 体现人工智能
具身人工智能将多模态感知与身体动作相结合。
|系统|模态 |应用 |
|--------|----------|-------------|
| **RT-2**（谷歌）|视觉+语言→机器人动作|通过文本指令进行通用机器人控制 |
| **奥克托** |开源机器人政策|使用不同的机器人数据进行训练 |
| **特斯拉擎天柱** |视觉+语言→体力任务|用于一般任务的人形机器人|
| **图01** |视觉+语言+言语|具有对话能力的人形机器人|
### 嵌入式人工智能的挑战
|挑战|为什么这很难 |
|------------|--------------|
| **模拟与真实的差距** |模拟并不能完美地捕捉现实世界的物理现象
| **灵巧** |精细运动控制（手、手指）极其困难 |
| **安全** |物理机器人会造成真正的伤害|
| **实时处理** |必须在毫秒内感知、决定并采取行动 |
| **概括** |接受过拿起红色杯子训练的机器人可能会无法拿起蓝色杯子

|----------|-------------|-------------|

＃＃ 概括
多模态人工智能代表了从单一用途模型到能够感知和推理所有形式数据的系统的转变。 GPT-4V和Gemini等视觉语言模型可以同时理解图像和文本； Whisper 和 VALL-E 等语音模型处理音频；视频模型开始处理带有声音的运动图像的全部复杂性。趋势很明显：未来最强大的人工智能系统将是原生多模式的，同时处理所有类型的信息。数据对齐、计算成本、评估和具体部署等挑战是巨大的，但 2024 年至 2026 年的进展很快。
