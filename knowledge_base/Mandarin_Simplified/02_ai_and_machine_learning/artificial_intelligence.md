＃ 人工智能
人工智能是试图构建机器，使其能够完成人类需要智能才能完成的事情：识别面孔、理解语音、做出决定、编写文本、玩游戏、驾驶汽车、诊断疾病。这个领域与计算本身一样古老——阿兰·图灵问“机器能思考吗？” 1950 年，但最近（2020 年代）能力的爆炸性增长使人工智能成为人类历史上最重要和最具争议的技术之一。
---

## 简史
几十年来，人工智能经历了炒作和失望的循环。了解这段历史可以帮助您理解为什么人们既兴奋又怀疑。
|时代|发生了什么 |结果|
|-----|----------------|---------|
| **1950 年代-1960 年代** |早期的乐观。提出图灵测试（1950）。达特茅斯会议硬币“人工智能”（1956）。早期的程序如 ELIZA（聊天机器人）和 SHRDLU（语言理解）。 |兴奋：“我们将在一代人的时间内拥有通用人工智能！” |
| **20世纪70年代** |第一个人工智能冬天。早期方法的局限性变得显而易见。资金枯竭。 |失望：承诺未兑现 |
| **20世纪80年代** |专家系统蓬勃发展——编码人类专业知识的基于规则的程序。日本第五代项目。 |再次兴奋：企业人工智能投资|
| **1987-1993** |第二个人工智能冬天。事实证明，专家系统很脆弱且维护成本高昂。 |再次失望|
| **2000s** |机器学习受到关注。更多可用数据（互联网）。统计方法取代了手工编码的规则。 |稳步前进 |
| **2012+** |深度学习革命。 AlexNet 使用 GPU 赢得了 ImageNet 竞赛。神经网络在视觉、语音和语言方面开始优于传统方法。 |快速转型 |
| **2017** | 《Attention Is All You Need》论文介绍了 Transformer 架构。 |为接下来的一切打下基础 |
| **2020-2026** |大型语言模型（GPT-3、GPT-4、Claude、Gemini、LLaMA）。人工智能生成文本、代码、图像、视频。企业采用加速。 |人工智能成为日常生活的一部分 |

## 现代人工智能如何运作
### 机器学习——从数据中学习
机器学习不是编写明确的规则，而是将数据提供给自行发现模式的算法。
|类型 |它是如何运作的 |示例|
|------|-------------|---------|
| **监督学习** |在标记示例上进行训练（输入→正确输出）|垃圾邮件检测：向其提供数千封标有“垃圾邮件”或“非垃圾邮件”的电子邮件 |
| **无监督学习** |在未标记的数据中查找模式 |客户细分：无需预先定义组即可对相似客户进行分组 |
| **强化学习** |代理通过反复试验来学习，获得奖励或惩罚 |玩游戏的人工智能：尝试动作、获胜获得积分、了解哪些策略有效 |
### 深度学习——神经网络
深度学习使用人工神经网络——简单的数学运算层，堆叠在一起，可以学习极其复杂的模式。 “深”是指层数。
关键架构：
|建筑|最擅长 |实际使用 |
|----------|---------|----------------|
| **CNN**（卷积神经网络）|图像和空间数据|人脸识别、医学成像、自动驾驶汽车 |
| **RNN/LSTM** |序列数据（时间序列）|语音识别、音乐生成（很大程度上被变形金刚取代）|
| **变压器** |一切——文本、图像、音频、代码| GPT、Claude、Gemini、BERT、DALL-E——主导架构 |
| **GAN**（生成对抗网络）|生成真实数据 |图像合成、风格迁移（部分被扩散模型替代）|
| **扩散模型** |高质量图像/视频生成 |稳定扩散，DALL-E 3，中途，索拉 |
### 大型语言模型 (LLM)
LLM 是基于 Transformer 的模型，经过大量文本训练。他们学习预测序列中的下一个标记（单词片段），这需要理解语法、事实、推理，甚至类似于“知识”的东西。
|型号|开发商|显着特点|
|--------|---------|-----------------|
| **GPT-4 / GPT-4o** |开放人工智能 |多模式（文本+图像）；强有力的推理|
| **克劳德** |人择 |注重安全和帮助；长上下文窗口|
| **双子座** |谷歌 DeepMind |原生多式联运；与谷歌服务集成|
| **骆驼 / 骆驼 3** |元 |自由重量；可以在本地运行；大型社区|
| **米斯特拉尔** |米斯特拉尔人工智能 |高效的开放模型可与更大的模型竞争|
**训练过程**：
1. **预训练**：从海量文本数据中学习（预测下一个标记）。这是模型获取“知识”的地方。
2. **微调**：针对特定任务或根据人类偏好进行训练。
3. **RLHF**（来自人类反馈的强化学习）：人类对模型输出进行评分；该模型学习产生人类喜欢的输出。
**上下文窗口**（模型一次可以处理多少文本）已从 4K 令牌（早期的 GPT-3）增长到 2026 年模型中的超过 100 万个令牌。

## 人工智能能做什么和不能做什么
### 当前能力
|任务|性能|限制 |
|------|-------------|-------------|
| **文本生成** |优秀——连贯、上下文相关、风格多样 |可以产生幻觉（自信地生成虚假信息）|
| **代码生成** |非常适合常见模式；可以编写整个程序|与新颖的架构作斗争；可能会引入微妙的错误|
| **图像生成** |逼真；艺术风格；编辑|手和文字仍然不完善；与精确的空间推理作斗争|
| **翻译** |主要语言对接近人类 |资源匮乏的语言不太准确；文化的细微差别可能会丢失|
| **语音识别** |纯净的音频接近人类 |与浓重的口音和背景噪音作斗争|
| **推理** |进步很快；可以解决很多逻辑问题|未能解决需要真正理解的新问题 |
| **数学** |擅长标准问题|在新颖的校样上犯错误；不能替代形式验证|
| **规划和工具使用** |新兴（代理）|在没有人工监督的情况下，对于复杂的多步骤任务仍然不可靠 |
### 人工智能不能做什么（截至 2026 年）
- **真正理解**人类所做的任何事情 - 它处理模式，而不是意义
- **保证事实准确性** - 幻觉仍然是一个未解决的问题
- **在没有监督的情况下在高风险决策中取代人类判断**
- **完美概括**到与训练数据截然不同的领域
- **在不可预测的物理环境中自主操作**（机器人仍然很难）

## 人工智能道德与安全
人工智能不是中立的。它反映了它所训练的数据、开发人员的选择以及部署它的组织的激励。
### 主要问题
|问题 |发生了什么 |示例|
|--------|-------------|---------|
| **偏见** |人工智能系统会重现并放大训练数据中的偏差招聘算法有利于男性候选人；面部识别对于深色皮肤的错误率更高
| **隐私** |人工智能接受个人数据训练；监控能力|有关版权作品的培训；公共场所面部识别|
| **滥用** |深度造假、虚假信息、自动网络钓鱼 |人工智能生成政客的虚假视频；自动诈骗电话|
| **工作转移** |以前由人类完成的任务的自动化|内容创建、客户服务、数据输入、一些编程 |
| **对齐** |确保人工智能目标符合人类价值观 |人工智能被告知“最大化回形针产量”可能会将所有物质转化为回形针 |
| **存在风险** |对未来AGI的理论关注|研究人员之间的争论——一些人认为这是紧迫的，另一些人则认为为时过早
### 谁在从事安全工作
- **Anthropic** — 由前 OpenAI 研究人员创立，专门专注于人工智能安全
- **DeepMind Safety** — Google DeepMind 内的研究团队
- **MIRI**（机器智能研究所）——理论安全研究
- **ARC**（人工智能研究中心）——实证安全研究
- **政府机构** — 欧盟人工智能法案 (2026)、美国行政命令、国际框架

## 机器人技术和嵌入式人工智能
机器人技术将人工智能与物理机器相结合。尽管取得了数十年的进步，但与世界的物理交互仍然比数字智能困难得多。
- **波士顿动力公司的 Atlas** — 先进的双足运动；跑酷；仓库任务
- **工业机器人**（ABB、FANUC、KUKA）——自动化制造；焊接;组装
- **手术机器人**（达芬奇系统）——微创手术，精度超越人手
- **家用机器人** (Roomba) — 简单但商业上成功
- **人形机器人**（Tesla Optimus、Figure AI）——新兴；通用体力任务仍然非常困难
数字人工智能（已经取得了巨大进步）和物理人工智能（在灵活性、平衡性和不可预测的环境中挣扎）之间的差距是该领域面临的巨大挑战之一。

＃＃ 概括
人工智能是21世纪迄今为止最重大的技术发展。这不是魔法，而是通过海量数据、强大的硬件和巧妙的架构实现的大规模模式匹配。其变革性在于，模式匹配如果做得足够好，可以复制许多以前需要人类智能的任务。挑战同样重大：幻觉、偏见、工作取代、滥用，以及从狭义人工智能到通用智能的道路是短还是长的悬而未决的问题。显而易见的是，人工智能将重塑各行各业、各职业、日常生活的方方面面。了解它的工作原理以及它不能做什么对于驾驭我们正在建设的世界至关重要。
