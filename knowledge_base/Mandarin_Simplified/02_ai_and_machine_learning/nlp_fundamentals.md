# NLP 基础知识
自然语言处理 (NLP) 是教导机器理解、生成和使用人类语言的领域。它为搜索引擎、聊天机器人、翻译系统、情感分析和大型语言模型 (LLM) 提供支持，这些模型自 2020 年以来已经改变了人工智能。该文件涵盖了从经典技术到基于 Transformer 的现代架构的演变。
---

## 文本预处理
原始文本很混乱。在模型可以使用它之前，需要对其进行清理和结构化。
|步骤|它有什么作用 |示例|
|------|-------------|---------|
| **代币化** |将文本拆分为标记（单词、子单词或字符）| “我爱 NLP” →`["I", "love", "NLP"]`|
| **小写** |转换为小写 | “你好”→“你好”|
| **停用词删除** |删除常用词（the、is、at）| “猫坐着”→“猫坐着”|
| **词干** |砍掉词尾（粗略）| “运行”→“运行” |
| **词形还原** |简化为字典形式（上下文感知）| “更好”→“好”|
| **标准化** |修复编码、删除特殊字符、展开缩写 | “不要”→“不要” |
现代 Transformer 模型经常跳过停用词删除和词干提取——它们从数据中学习这些模式。

## 文本表示
机器需要数字，而不是文字。我们如何将文本表示为向量是基础。
### 经典方法
|方法|描述 |限制|
|--------|-------------|------------|
| **One-Hot 编码** |每个单词都是一个巨大向量中的唯一位置 |疏;无语义 |
| **词袋 (BoW)** |统计词频；忽略顺序 |完全失去词序 |
| **TF-IDF** |按文档中的频率 × 语料库中的稀有度对单词进行加权 |仍然忽略顺序和上下文 |
### 词嵌入
嵌入将单词映射到密集向量，其中相似的单词靠近在一起。
|型号|关键理念|
|--------|----------|
| **Word2Vec** (2013) |根据上下文预测单词 (CBOW) 或根据单词上下文预测单词 (Skip-gram) |
| **手套** (2014) |全局共现统计→稠密向量|
| **快速文本** (2016) | Word2Vec + 子词信息（更好地处理稀有词）|
著名的例子：`king - man + woman ≈ queen`。嵌入捕获语义关系。
**限制**：经典嵌入为每个单词分配一个向量，因此它们无法处理一词多义（具有多种含义的单词）。 “河岸”和“银行帐户”中的“银行”获得相同的向量。

## 序列模型
在 Transformer 出现之前，NLP 的标准方法是按顺序处理文本。
|建筑|它是如何运作的 |实力|弱点|
|----------|-------------|----------|----------|
| **RNN** |一次处理一个令牌；保持隐藏状态 |处理可变长度输入 |梯度消失；无法捕获长依赖关系|
| **LSTM** | RNN 带有门（遗忘、输入、输出）来控制信息流 |更擅长远程依赖 |仍然是连续的；训练慢|
| **格鲁** |简化的 LSTM（更少的门）|比 LSTM 更快；类似的表现 |相同的基本限制|
这些模型从左到右处理文本，这意味着它们训练速度很慢（无法并行）并且难以应对远程依赖性。

## 注意力机制
注意力机制让模型同时查看序列中的所有位置，并决定哪些位置与当前预测最相关。
### 关键见解
注意力机制不是将整个句子压缩为单个隐藏状态（如 RNN 那样），而是计算所有隐藏状态的加权和，并在其中学习权重。
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

|组件|角色 |
|------------|------|
| **查询（Q）** |我在寻找什么？ |
| **键 (K)** |我包含什么？ |
| **值（V）** |我提供什么信息？ |
| **√d_k** |防止大点积的缩放因子 |

## Transformer 架构
Transformer（Vaswani 等人，2017 年——“Attention Is All You Need”）完全用注意力取代了复发。它几乎是所有现代 NLP 的基础。
＃＃＃ 建筑学
|组件|描述 |
|------------|-------------|
| **编码器** |读取输入文本；产生上下文表征 |
| **解码器** |生成输出文本；关注编码器输出 |
| **自我关注** |每个令牌以相同的顺序关注所有其他令牌 |
| **多头注意力** |并行运行多个注意力头；捕捉不同的关系|
| **位置编码** |注入位置信息（因为没有重复）|
| **前馈网络** |独立应用于每个职位|
| **层标准化** |稳定训练|
| **剩余连接** |梯度流的跳过连接 |
### 仅编码器、仅解码器、编码器-解码器
|变体 |建筑|最适合 |示例 |
|---------|-------------|----------|---------|
| **仅编码器** |理解文字 |分类、NER、情感分析 |伯特、罗伯塔、德伯特 |
| **仅解码器** |生成文本 |语言模型、聊天机器人、代码生成 | GPT-3/4，LLaMA，克劳德 |
| **编码器-解码器** |转换文本 |翻译、摘要 | T5、BART、mBART |

## 主要模型系列
### BERT 系列（仅限编码器）
|型号|主要特点|
|--------|-------------|
| **伯特** (2018) |掩码语言模型+下一句预测|
| **罗伯塔** |删除了 NSP；使用更多数据训练更长时间 |
| **阿尔伯特** |参数共享；占地面积更小|
| **德伯特** |注意力分散；改进的 NLU |
| **DistillBERT** |体积缩小 40%，速度提高 60%，保留 BERT 97% 的性能 |
### GPT 系列（仅限解码器）
|型号|参数|笔记|
|--------|---------|--------|
| **GPT-2** | 1.5B | 1.5B显示仅解码器模型可以生成连贯的文本 |
| **GPT-3** | 175B | 175B少样本学习；提示而不是微调|
| **GPT-3.5 / GPT-4** |未公开 |指令调整+RLHF；会话 |
| **LLaMA**（元）| 7B–70B |自由重量；催生了开源LLM生态系统|
| **米斯特拉尔/混合** | 7B / 8×7B（教育部）|高效开放机型，性能强劲|

## 核心 NLP 任务
|任务|描述 |典型型号|
|------|-------------|--------------|
| **文本分类** |为文本分配标签（垃圾邮件/非垃圾邮件，正面/负面）| BERT，微调分类器 |
| **命名实体识别 (NER)** |识别文本中的人物、组织、地点 | BERT + CRF 层 |
| **情绪分析** |确定情绪基调 |微调 BERT 或零样本 LLM |
| **机器翻译** |语言间翻译 | T5、mBART、玛丽安MT |
| **问答** |根据上下文回答问题 | BERT（提取）、GPT（生成）|
| **总结** |压缩长文本 | T5、BART、GPT |
| **文本生成** |生成连贯的文本 | GPT-4，骆驼，克劳德 |

## 微调与提示
|方法|它是如何运作的 |何时使用 |
|----------|-------------|-------------|
| **微调** |更新特定于任务的数据的模型权重 |您已标记数据；需要最大性能|
| **提示** |用自然语言给出模型指令 |快速原型制作；数据有限；使用法学硕士 |
| **少射** |在提示中包含示例 |当你有几个例子但不足以进行微调时 |
| **LoRA / QLoRA** |高效微调；更新小型低秩矩阵 |使用有限的 GPU 内存微调大型模型 |

## 法学硕士景观
现代 NLP 领域由大型语言模型主导：
|类别 |示例 |笔记|
|----------|---------|--------|
| **专有** | GPT-4，克劳德，双子座 |最佳表现；仅限 API 访问 |
| **自由重量** | LLaMA 3，米斯特拉尔，Qwen |可用重量；本地运行 |
| **开源** |皮提亚，OPT |完全开放（数据、权重、代码）|
| **多式联运** | GPT-4V、双子座、LLaVA |处理文字+图像 |
| **代码专业** | CodeLlama、StarCoder、DeepSeek 编码器 |接受过代码培训 |
| **小型/高效** | Phi-3、Gemma、TinyLlama |小规模下表现强劲|
该领域正在快速发展。今天的前沿技术可能会在几个月内被取代。基本面——注意力、代币化、微调、评估——保持稳定。
