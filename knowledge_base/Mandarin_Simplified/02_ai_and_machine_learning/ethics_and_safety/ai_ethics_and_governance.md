# 人工智能道德与治理
人工智能系统不是中立的。它们反映了接受训练的数据、创建者的价值观以及部署它们的组织的激励措施。道德不仅仅是问“我们能建造这个吗？”但“我们应该吗？”治理就是建立法律、标准、监督机构等结构，以确保人工智能的开发和使用是负责任的。该文件涵盖了人工智能的关键道德维度以及为解决这些问题而出现的治理框架。
---

## 人工智能的核心道德原则
大多数人工智能道德框架都遵循一组共同原则。
|原理|这意味着什么？挑战|
|------------|--------------|------------|
| **公平** |人工智能不应歧视受保护群体 |从数学上定义公平是很困难的；不同的公平定义可能会发生冲突|
| **透明度** |用户应该知道他们何时与人工智能交互以及它是如何工作的 |完全透明可以进行游戏；专有系统拒绝披露|
| **责任** |当人工智能造成伤害时，必须有人负责 |将责任分散到开发人员、部署人员和用户之间 |
| **隐私** |人工智能应尊重个人数据和自主权 |训练数据通常包括个人信息；隐私与实用的冲突|
| **安全** |人工智能不应造成身体或心理伤害|伤害的定义取决于具体情况；边缘情况是不可预测的 |
| **人类监督** |人类应该保留有意义的控制|自动化偏见意味着人类服从人工智能；监督变成橡皮图章|

## 人工智能系统中的偏见
### 偏见从何而来
|来源 |描述 |示例|
|--------|-------------|---------|
| **训练数据** |数据中编码的历史偏差|招聘数据反映了过去的歧视→模型歧视|
| **标签偏差** |人类注释者强加他们的偏见带有“女性”名字的简历被注释者评分较低
| **选择偏差** |数据不代表目标人群 |面部识别主要针对浅肤色面孔进行训练
| **测量偏差** |受保护属性的功能代理 |邮政编码与种族相关
| **算法偏差** |优化放大了小偏差 |训练数据中的小差距会成为预测中的大差距|
### 公平指标
|公制|定义 |何时使用 |
|--------|------------|-------------|
| **人口平等** |各组阳性率相等 |当您想要平等的结果时 |
| **均等赔率** |各组的真阳性率和假阳性率相等 |当您想要相同的错误率时 |
| **预测平价** |各组的精度相同 |当您希望预测对所有群体都具有相同的意义时 |
| **个人公平** |相似的人受到相似的对待|当您想要一致性时 |
**不可能性定理**：通常无法同时满足多个公平性定义。选择使用哪种公平指标本身就是一种价值判断。
### 减少偏见
|舞台|技术|
|------|----------|
| **预处理** |重新平衡训练数据；删除有偏见的特征；合成过采样|
| **处理中** |给损失函数添加公平约束；对抗性去偏见|
| **后处理** |调整每组的阈值；校准预测|
| **评估** |定期公平性审核；分类绩效指标|

## 可解释性
### 为什么可解释性很重要
|原因 |描述 |
|--------|-------------|
| **信任** |用户需要了解为什么做出决定 |
| **调试** |开发人员需要查找并修复模型错误 |
| **监管** | GDPR 的“解释权”；欧盟人工智能法案要求 |
| **公平** |如果不了解模型行为，就无法检测偏差 |
| **责任** |组织需要证明自动化决策的合理性|
### 解释方法
|方法|类型 |它是如何运作的 |限制|
|--------|------|-------------|------------|
| **形状** |特征重要性|使用博弈论估计每个特征的贡献 |计算成本昂贵；近似值|
| **石灰** |本地代孕 |围绕预测拟合一个简单模型 |不稳定；不反映实际的模型逻辑 |
| **注意力可视化** |内部机制|显示模型关注哪些输入 |关注≠重要性；可能会产生误导 |
| **反事实** |假设分析| “如果这个特征不同，预测会改变吗？” |取决于现实的反事实|
| **特征归因** |重要性分数 |显着图、积分梯度 |没有解释*为什么*；就在*哪里* |

## 人工智能监管
### 欧盟人工智能法案 (2026)
全球首部综合性人工智能法。
|风险等级|示例 |要求|
|------------|----------|----------|
| **不可接受的风险** |社会评分；潜意识操纵；实时生物识别监控（有例外）|禁止 |
| **高风险** |医疗人工智能；自动驾驶汽车；执法;关键基础设施|合格评定；人为监督；透明度|
| **风险有限** |聊天机器人；深度造假；推荐系统|必须披露人工智能的参与 |
| **风险最小** |垃圾邮件过滤器；视频游戏；大多数人工智能应用|无具体要求 |
### 其他监管方法
|地区 |方法|状态 |
|--------|----------|--------|
| **美国** |特定行业；行政命令；自愿承诺|支离破碎；没有全面的联邦法律|
| **英国** |以原则为基础；行业监管机构|人工智能安全研究所；支持创新的方法|
| **中国** |生成式人工智能、深度造假、建议的具体规定 |积极执法；内容要求|
| **加拿大** | AIDA（人工智能和数据法案）|建议的;类似于欧盟的做法|
| **巴西** |人工智能监管框架|进行中 |

## 环境影响
训练和运行人工智能模型会消耗能源并产生碳排放。
|活动 |预计排放量|比较|
|----------|--------------------|------------|
| **培训 GPT-4** |估计排放超过 50 吨二氧化碳 |相当于几辆汽车的年排放量|
| **训练大型 Transformer** | 280-620 吨二氧化碳 |汽车终生排放量的 5 倍 |
| **每日推理（100 万用户）** |正在进行；取决于型号尺寸和硬件|随着时间的推移可能会超过训练排放量 |
| **微调 7B 模型** | 1-5 吨二氧化碳 |显着但比预训练少得多 |
### 缓解措施
|战略|影响 |
|----------|--------|
| **高效的硬件** |新型 GPU 每次计算的能源效率更高 |
| **模型优化** |更小的量化模型使用更少的能量 |
| **绿色能源** |使用可再生能源为数据中心供电|
| **高效架构** |专家组合；稀疏模型；蒸馏|
| **碳意识调度** |当网格最干净时进行训练 |

## 知识产权和版权
|问题 |描述 |状态 |
|--------|-------------|--------|
| **版权作品培训** |未经许可使用书籍、文章、图像训练模型 |积极的诉讼；合理使用辩论|
| **人工智能生成的输出** |谁拥有人工智能生成的内容？ |美国版权局：如果没有足够的人类作者，人工智能生成的内容不受版权保护
| **风格模仿** |人工智能可以模仿艺术家的风格 |法律上是灰色的；道德问题|
| **选择退出机制** |一些提供商允许创作者选择退出培训 |机器人.txt；内容过滤 |

## 负责任的披露
|原理|描述 |
|------------|-------------|
| **部署前测试** |发布前的红队、偏见审核、安全评估 |
| **逐步部署** |从有限的访问开始；随着安全性得到证实而扩大|
| **事件报告** |记录并分享有关失败和危害的信息 |
| **错误赏金** |奖励发现漏洞的外部研究人员 |
| **模型卡** |记录模型的功能、限制和预期用途 |

## 实用道德框架
### 对于人工智能开发者
|问题 |为什么这很重要？
|----------|--------------|
| **谁可能会受到该系统的伤害？** |确定受影响的利益相关者 |
| **如果模型错误会发生什么？** |评估错误的成本 |
| **模型的决策可以解释一下吗？** |确定可解释性要求 |
| **训练数据是否具有代表性？** |检查选择和测量偏差 |
| **故障模式有哪些？** |预测边缘情况和滥用 |
| **如何监控系统？** |持续监督计划|
### 对于部署人工智能的组织
|实践|描述 |
|----------|-------------|
| **人工智能治理委员会** |跨职能团队审查人工智能部署 |
| **影响评估** |部署前评估潜在危害 |
| **人工监督流程** |当人工智能出错时清除升级路径 |
| **定期审核** |检查是否存在偏见、漂移和意外后果 |
| **用户反馈渠道** |允许受影响的人报告问题|
| **文档** |维护模型决策和理由的记录 |

＃＃ 概括
人工智能道德和治理是工程要求。偏见、不透明、环境成本和侵犯隐私不仅是道德问题，也是问题所在。它们是造成真正伤害的缺陷。治理格局正在迅速发展，欧盟人工智能法案设定了全球标准。仅靠监管是不够的——公平性、可解释性和问责制必须融入每个人工智能开发人员的日常工作中。核心问题是如何构建值得信任的系统。
