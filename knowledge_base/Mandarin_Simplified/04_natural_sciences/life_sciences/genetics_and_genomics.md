# 遗传学和基因组学
遗传学是一门研究遗传的学科，即性状如何通过 DNA 从父母传给后代。基因组学是对整个基因组的研究：所有基因、非编码区域、它们如何相互作用以及它们如何在个体和人群中变化。从遗传学到基因组学的转变是由测序技术推动的——我们从一次研究一个基因发展到在数小时内读取整个基因组，生成的数据正在改变医学、农业、法医学以及我们对进化的理解。
---

## DNA 基础知识
### DNA 结构
|组件|描述 |
|------------|-------------|
| **核苷酸** | DNA 的组成部分；由糖（脱氧核糖）、磷酸基团和含氮碱基组成 |
| **基地** |腺嘌呤 (A)、胸腺嘧啶 (T)、鸟嘌呤 (G)、胞嘧啶 (C) |
| **碱基配对** | A与T配对（2个氢键）； G 与 C 配对（3 个氢键）|
| **双螺旋** |两条反平行运行的链（5' 至 3' 和 3' 至 5'）；扭曲成螺旋|
| **染色体** |包裹着组蛋白的单个长 DNA 分子；人类有 46 个（23 对）|
| **基因组** |有机体中完整的DNA组；人类基因组约有 32 亿个碱基对 |
### 分子生物学的中心法则
|步骤|流程|地点 |产品 |
|------|---------|----------|---------|
| **复制** |脱氧核糖核酸→脱氧核糖核酸|核心 |两个相同的DNA分子|
| **转录** | DNA → mRNA |核心 |信使RNA |
| **翻译** | mRNA → 蛋白质 |核糖体（细胞质）|多肽链（蛋白质）|

## 基因表达
### 基因是如何调控的
|水平|机制|示例|
|--------|------------|---------|
| **表观遗传** | DNA甲基化；组蛋白修饰；染色质重塑 |女性中一条X染色体的沉默|
| **转录** |转录因子结合启动子/增强子；激活或抑制|细菌中的紫胶操纵子；激素反应基因|
| **转录后** |选择性拼接； mRNA稳定性；微小RNA |一种基因→多种蛋白质变体|
| **翻译** |核糖体可用性；起始因子调控|通过铁蛋白 mRNA 调节铁
| **翻译后** |蛋白质修饰（磷酸化、泛素化）；降解|细胞周期控制|

## 继承模式
### 孟德尔遗传学
|图案|描述 |示例|
|---------|-------------|---------|
| **常染色体显性遗传** |等位基因的一份副本就足够了 |亨廷顿舞蹈症；软骨发育不全 |
| **常染色体隐性遗传** |需要两份 |囊性纤维化;镰状细胞性贫血 |
| **X连锁显性** | X染色体上的基因；一份就足够了 |雷特综合症|
| **X连锁隐性** | X染色体上的基因；男性受影响更大血友病;色盲 |
| **共显性** |两个等位基因的表达相同| ABO 血型（A 和 B）|
| **不完全的统治** |杂合子是中间的|红色和白色父母的粉红色花朵|
| **多基因** |多个基因促成一种性状 |高度;肤色；情报|
| **多效性** |一个基因影响多个性状|马凡氏综合症（结缔组织、眼睛、心脏）|

## 基因组学
### 基因组学的类型
|类型 |焦点 |应用 |
|------|--------|-------------|
| **结构基因组学** |基因组中所有蛋白质的 3D 结构 |药物设计；蛋白质工程|
| **功能基因组学** |基因有什么作用；基因相互作用；表达模式|了解疾病机制 |
| **比较基因组学** |比较不同物种的基因组 |进化关系；识别保护区|
| **宏基因组学** |来自环境样本的 DNA（未培养）|微生物组研究；发现新生物|
| **药物基因组学** |基因如何影响药物反应？个性化医疗；药物剂量|
| **表观基因组学** |全基因组表观遗传修饰|癌症诊断；发育生物学|
### DNA 测序技术
|一代|技术 |阅读长度 |吞吐量|主要特点|
|----------|----------|-------------|------------|-------------|
| **第一代** |桑格测序| 〜1,000 bp |低|金标准精度；用于验证|
| **第二代** | Illumina（Solexa）| 50–300 bp |非常高|短读；主导平台；每个碱基成本低|
| **第二代** |离子激流| 200–400 bp |高|基于半导体；无光学|
| **第三代** |太平洋生物 (SMRT) | 10,000–100,000 bp |中等|长读；解决重复区域 |
| **第三代** |牛津纳米孔 |高达数百万bp |中到高|超长阅读；便携式（MinION）；实时|

## 遗传变异
### 变异类型
|类型 |描述 |频率|
|------|-------------|------------|
| **SNP**（单核苷酸多态性）|单碱基变化 |最常见； ~1,000 个碱基中就有 1 个 |
| **插入/删除（indel）** |碱基的添加或去除|可能导致移码突变|
| **CNV**（拷贝数变异）|重复或删除的段（1 kb – 几 Mb）|有助于疾病和进化|
| **结构变化** |倒转；易位；大重组|不太常见；可能致病|
| **微卫星（STR）** |短串联重复序列（2-6 bp 重复）|法医；亲子鉴定 |
### GWAS（全基因组关联研究）
|步骤|描述 |
|------|-------------|
| **1.收集样本** |病例（有疾病）和对照（无疾病）|
| **2.基因型** |使用 SNP 阵列对数十万种变异进行基因分型 |
| **3.统计测试** |测试每个 SNP 与性状的关联 |
| **4.曼哈顿情节** |可视化所有染色体的结果 |
| **5.复制** |确认独立样本中的发现 |

## 基因编辑
### CRISPR-Cas9
|组件|功能|
|------------|----------|
| **引导 RNA (gRNA)** | 〜20个核苷酸；匹配目标 DNA 序列 |
| **Cas9 蛋白** |分子剪刀；在目标位点切割 DNA |
| **PAM 序列** |目标旁边的短基序 (NGG)； Cas9 结合所需 |
| **HDR**（同源定向修复）|使用捐赠者模板进行精确编辑 |
| **NHEJ**（非同源末端连接）|容易出错的修复；创建插入/删除（剔除）|
### 基因编辑应用
|应用 |描述 |
|-------------|-------------|
| **治疗** |纠正致病突变（镰状细胞；β-地中海贫血）|
| **农业** |抗病作物；改良牲畜|
| **研究** |创建淘汰模型；研究基因功能|
| **基因驱动** |在人群中传播基因改造（例如抗疟疾蚊子）|

## 道德考虑
|问题 |关注|
|--------|---------|
| **遗传隐私** |谁拥有您的基因组数据？雇主或保险公司可以使用它吗？ |
| **胚胎基因编辑** |可遗传的变化；设计师婴儿；意外的脱靶效应|
| **基因歧视** | GINA（美国）防止某些歧视，但仍存在差距 |
| **知情同意** |基因组数据揭示了未经同意的亲属信息
| **数据存储** |基因组很大（原始基因组约为 200 GB）；长期存储和安全挑战|
| **股权** |如果基因组医学仅适用于富裕人群，则可能会扩大健康差距
---

＃＃ 概括
遗传学研究个体基因如何发挥作用并遗传。基因组学研究整个基因组——所有基因、它们的相互作用以及它们的变异。 DNA被转录成RNA，RNA被翻译成蛋白质。基因表达在多个层面上受到调节：表观遗传、转录、转录后、翻译和翻译后。遗传遵循决定性状如何在世代之间传递的模式（显性、隐性、多基因）。现代测序技术（Illumina、PacBio、Nanopore）可以快速且廉价地读取整个基因组。 CRISPR-Cas9 能够实现精确的基因编辑，在医学和农业领域具有变革潜力。最大的挑战是道德方面的：谁控制基因组数据，如何监管胚胎中的基因编辑，以及如何确保基因组医学惠及所有人，而不仅仅是特权阶层。
