# 医药与保健
医学是诊断、治疗和预防疾病的科学和实践。这是人类最古老的事业之一——希波克拉底誓言可以追溯到古希腊——也是变化最快的事业之一。仅在上个世纪，我们就从没有抗生素发展到拥有可以重写患者 DNA 的基因疗法。
该文件涵盖了医学的运作方式：主要专业、疾病如何诊断和治疗、医疗保健系统如何组织，以及当人类生命受到威胁时出现的道德问题。
---

## 身体如何运作——快速浏览
在了解疾病之前，了解健康是什么样子会有所帮助。人体有 11 个主要器官系统，每个器官系统都有特定的功能，但又紧密相连。
|系统|重要器官|主要功能|常见问题 |
|--------|---------|-----------------|-----------------|
| **心血管** |心脏、血管|泵血；输送氧气和营养|心脏病、中风、高血压|
| **呼吸系统** |肺、呼吸道 |交换氧气和二氧化碳 |哮喘、慢性阻塞性肺病、肺炎、肺癌|
| **消化** |胃、肠、肝、胰 |分解食物；吸收营养；消除浪费| GERD、溃疡、IBD、肝病 |
| **紧张** |大脑、脊髓、神经 |处理信息；控制身体功能|阿尔茨海默病、帕金森病、癫痫、中风|
| **内分泌** |垂体、甲状腺、肾上腺、胰腺 |产生调节新陈代谢、生长、繁殖的激素|糖尿病、甲状腺疾病、肥胖|
| **免疫/淋巴** |白细胞、淋巴结、脾 |防御病原体 |自身免疫性疾病、免疫缺陷、过敏 |
| **肌肉骨骼** |骨骼、肌肉、关节 |支撑体；启用运动|关节炎、骨质疏松、骨折、背痛|
| **泌尿/肾脏** |肾脏、膀胱 |过滤血液；清除废物；调节液体|肾脏疾病、尿路感染、肾结石 |
| **生殖** |卵巢/睾丸、子宫等 |启用复制 |不孕不育、癌症、荷尔蒙失调 |
| **外皮** |皮肤、头发、指甲 |保护身体；调节温度|湿疹、牛皮癣、皮肤癌、感染 |
| **血液学** |血液、骨髓|输送氧气；对抗感染；血凝块|贫血、白血病、凝血障碍|
### 体内平衡——身体的平衡行为
身体的每个系统都致力于维持**体内平衡**——尽管外部发生变化，仍保持内部条件稳定。无论室外严寒还是酷热，您的体温都会保持在 37°C 左右。血液 pH 值保持在 7.35 至 7.45 之间。血糖在一个狭窄的范围内上升和下降，受胰岛素和胰高血糖素的调节。
当体内平衡被破坏时，通常会发生疾病。发烧是您的免疫系统故意提高体温以抵抗感染。糖尿病是血糖调节失败。心力衰竭是心血管系统无法维持足够的血流量。

## 诊断 — 找出问题所在
诊断是一个排除和确认的过程。医生收集线索（症状、病史、检查结果）并缩小可能性。
### 诊断过程
1. **病史**：有什么症状？他们什么时候开始的？是什么让它们变得更好或更糟？家史？药物治疗？仅此一点就大大缩小了可能性。
2. **体检**：生命体征（体温、血压、心率）、听心肺、触诊腹部、检查反射。
3. **鉴别诊断**：可能情况的排名列表，从最有可能到最不可能（以及从最危险到最不危险）。
4. **测试**：命令确认或排除差速器上的情况。
### 常见诊断测试
|测试|它显示了什么 |最适合 |
|------|--------------|----------|
| **血液测试（CBC）** |红/白细胞、血小板 |感染、贫血、血液疾病|
| **代谢面板** |肾功能、肝功能、电解质、血糖|器官功能、糖尿病筛查|
| **X 射线** |致密结构（骨骼、肺）|骨折、肺炎、心脏大小|
| **CT 扫描** |使用 X 射线观察详细的横截面 |外伤、肿瘤、内出血|
| **核磁共振** |出色的软组织细节（无辐射）|脑肿瘤、韧带撕裂、脊柱问题 |
| **超声波** |使用声波的实时图像 |怀孕、胆结石、心脏功能|
| **活检** |显微镜下检查的组织样本|癌症诊断、炎症状况|
| **心电图/心电图** |心脏的电活动|心律失常、心脏病发作 |
| **内窥镜检查** |相机穿过消化道|溃疡、息肉、癌症|
### 筛查 — 在出现症状之前发现疾病
筛查测试会在感觉良好的人身上寻找疾病。我们的目标是在问题更容易治疗时及早发现问题。
|放映|谁 |多久一次 |
|------------|-----|------------|
| **血压** |所有成人 |每 1-2 年 |
| **胆固醇** | 20 岁以上成人 |每 4-6 年 |
| **乳房X光检查** | 40-74 岁女性 |每 1-2 年 |
| **结肠镜检查** | 45-75 岁成人 |每10年|
| **子宫颈抹片检查** | 21-65 岁女性 |每 3-5 年 |
| **糖尿病筛查** | 35-70 岁超重的成年人 |每 3 年 |

## 治疗——解决问题
治疗选择范围从无所作为（许多情况会自行解决）到积极干预。正确的方法取决于病情、严重程度、患者的整体健康状况以及有效的证据。
|方法|示例 |使用时 |
|----------|---------|------------|
| **警惕等待** |无需积极治疗即可监测|可能解决的小问题；低风险发现|
| **生活方式的改变** |饮食、运动、睡眠、压力管理|许多慢性疾病（高血压、2 型糖尿病）的一线治疗 |
| **药物** |抗生素、降压药、胰岛素、抗抑郁药|当生活方式的改变还不够时 |
| **手术** |阑尾切除术、关节置换术、肿瘤切除|当结构问题需要物理修复时 |
| **放射治疗** |靶向放射杀死癌细胞|癌症治疗，通常与手术相结合|
| **免疫治疗** |利用免疫系统对抗癌症|某些癌症（黑色素瘤、肺癌）|
| **物理治疗** |恢复运动和功能的练习|受伤、手术或慢性疼痛后 |
| **心理治疗** |谈话疗法（CBT、心理动力学等）|心理健康状况；对慢性疼痛也有效|
| **姑息治疗** |症状缓解和生活质量|严重疾病；不限于报废 |
### 药理学基础知识
|药品类|它有什么作用 |示例 |重要提示|
|------------|-------------|----------|----------------|
| **抗生素** |杀死细菌|青霉素、阿莫西林、环丙沙星|不针对病毒；过度使用会产生抵抗力|
| **镇痛药** |缓解疼痛|布洛芬、对乙酰氨基酚、吗啡 |阿片类药物具有高度成瘾性；谨慎使用|
| **抗高血压药** |降低血压 | ACE 抑制剂、β 受体阻滞剂、利尿剂 |经常需要多种药物；终身治疗|
| **他汀类药物** |降低胆固醇 |阿托伐他汀、瑞舒伐他汀|全球处方最多的药物之一 |
| **抗凝剂** |预防血栓 |华法林、肝素、阿哌沙班 |出血风险；需要监控|
| **抗抑郁药** |治疗抑郁症和焦虑症 | SSRIs、SNRIs、三环类 |需要几周的时间才能工作；不要突然停下|
| **胰岛素** |降低血糖 |速效、长效|对于 1 型糖尿病至关重要；有时适用于类型 2 |
| **化疗** |杀死快速分裂的细胞|顺铂、紫杉醇|健康快速分裂细胞受损带来的副作用

## 医疗保健系统——社会如何组织护理
各国的医疗保健系统差异巨大，但它们都面临着相同的根本挑战：如何在不导致个人或系统破产的情况下为每个人提供高质量的护理。
|型号|它是如何运作的 |示例 |优势 |弱点|
|--------|-------------|----------|------------|------------|
| **单一付款人** |政府资助并经常提供护理|英国 (NHS)、加拿大、斯堪的纳维亚 |全民覆盖；成本控制|等待时间；选择有限|
| **社会保险** |雇主和雇员对非营利性“疾病基金”的强制性缴款|德国、法国、日本 |普遍的;多家保险公司竞争|复杂的;昂贵|
| **多付款人（基于雇主）** |通过雇主提供私人保险；政府覆盖老年人/穷人|美国 |创新;被保险人等待时间短| 2700 万人没有保险；最高成本|
| **自付费用** |患者直接付费 |大多数低收入国家 |简单|只有富人才能得到照顾|
美国人均医疗保健支出大约是其他富裕国家的两倍，许多指标（预期寿命、婴儿死亡率、可预防的死亡）的结果更差。原因很复杂：行政浪费、药品价格高、奖励数量多于价值的按服务收费激励措施以及不平等的获取机会。

## 公共卫生——保护人群
临床医学关注的是个体患者，而公共卫生关注的是人群。其工具包括流行病学、疫苗接种、卫生、教育和政策。
### 最伟大的公共卫生成就
1. **疫苗接种** — 消灭天花，几乎消灭脊髓灰质炎，每年防止数百万人死亡
2. **清洁水和卫生设施**——发达国家消除了霍乱；仍然是发展中国家的主要杀手
3. **抗生素**——将传染病从死刑转变为可治疗的疾病
4. **烟草控制** — 许多国家的吸烟率大幅下降，预防了数百万癌症和心脏病发作
5. **道路安全**——安全带、安全气囊和醉酒驾驶法使许多国家的交通死亡率降低了一半
### 流行病学——模式科学
流行病学家研究疾病如何在人群中传播。关键概念：
|术语 |意义|示例|
|------|---------|---------|
| **发生率** |一段时间内的新病例 |每年每 10 万人新增 500 例糖尿病病例 |
| **流行率** |某个时间点的现有病例总数 |目前有 10% 的成年人患有糖尿病 |
| **死亡率** |疾病死亡人数 |每 10 万人中有 150 人死于心脏病 |
| **R₀（R-无）** |一名感染者平均会感染多少人|麻疹：12-18；流感：1-2 |
| **群体免疫** |当足够多的人具有免疫力时，疾病就不会轻易传播|需要约 95% 的人接种麻疹疫苗 |

## 医学伦理——难题
医学提出的伦理问题没有简单的答案。指导大多数医学道德的四个原则：
1. **自主**：即使医生不同意，患者也有权就自己的护理做出明智的决定。
2. **仁慈**：以患者的最大利益为出发点。
3. **非恶意**：“首先，不要伤害。”避免弊大于利的治疗。
4. **正义**：公平分配医疗资源。
这些原则有时会发生冲突。患者可能会拒绝挽救生命的治疗（自主与仁慈）。一种昂贵的药物可能会使一名患者受益，但会消耗许多其他患者的资源（慈善与正义）。
现代医学的关键伦理问题：
- **临终关怀**：什么时候撤回生命维持系统合适？姑息治疗（减轻痛苦）和安乐死（故意结束生命）有什么区别？
- **知情同意**：患者在同意治疗之前必须了解风险、益处和替代方案。这比听起来更复杂——大多数患者并不完全了解统计风险。
- **资源分配**：当器官不足时谁接受器官移植？大流行期间谁获得呼吸机？
- **基因测试和编辑**：我们现在可以筛选胚胎的遗传疾病并使用 CRISPR 编辑基因。我们应该吗？治疗疾病和“设计”婴儿之间的界限在哪里？
- **人工智能在医学中**：当人工智能诊断工具出错时，谁该负责？我们如何确保人工智能不会编码偏见？
---

＃＃ 概括
医学既是一门科学，也是一门艺术。科学是非凡的——我们可以在数小时内对基因组进行测序，用干细胞培育器官，并重新编程免疫系统来对抗癌症。艺术在于将科学应用于个体患者，每个患者都有自己的价值观、环境和偏好。世界各地的医疗保健系统都在努力应对同样的挑战：在不破产的情况下为每个人提供高质量的护理。随着治疗方法变得更加先进和人口老龄化，医学上可行与经济上可持续之间的紧张关系只会加剧。了解医学的工作原理——如何诊断、治疗和预防疾病——对于就自己的健康和社会的健康做出明智的决定至关重要。
