# 化学
如果物理是游戏规则，那么化学就是各个部分相互作用时发生的事情。化学研究原子如何结合、分裂和重新排列——也就是说，所有材料的行为方式。它弥合了基础物理学与复杂的生物学、地质学和工程学之间的差距。
---

## 原子结构
### 30 秒了解原子
原子有一个原子核（质子+中子），周围有壳层中的电子。质子数定义了元素（1 = 氢，6 = 碳，79 = 金）。中子数决定同位素（碳 12 与碳 14）。电子的排列决定了原子如何与其他原子结合。
|粒子|充电|质量 (amu) |地点 |
|----------|--------|------------|----------|
| **质子** | +1 | 〜1 |核心 |
| **中子** | 0 | 〜1 |核心 |
| **电子** | −1 | ~1/1836 |电子壳|
### 电子构型
电子占据原子核周围的壳层（能级）。每个壳层拥有最大数量的电子：
|壳牌|麦克斯电子|子壳 |距核的距离 |
|--------|--------------|------------|------------------------|
| **1 (K)** | 2 | 1秒|最近的|
| **2（大）** | 8 | 2 秒，2 秒 | |
| **3（男）** | 18 | 18 3s、3p、3d | |
| **4（N）** | 32 | 32 4s、4p、4d、4f |最远（化合价）|
最外层的壳（价壳）决定化学行为。具有全价壳层的原子（稀有气体）是惰性的；具有不完整壳层的原子发生反应以实现稳定性。

## 元素周期表
元素周期表不是随机列表，而是化学行为图。同一列（组）中的元素表现相似，因为它们具有相同数量的价电子。
### 关键群体
|集团|元素|行为 |
|--------|----------|----------|
| **碱金属**（第 1 组）|李、娜、K…… |反应性极强，失去 1 个电子，在水中爆炸 |
| **碱土金属**（第 2 族）|铍、镁、钙... |反应性，失去 2 个电子，形成碱性氧化物 |
| **卤素**（第 17 组）| F、Cl、Br、I... |非常活泼，获得 1 个电子，形成盐 |
| **稀有气体**（第 18 组）|他、Ne、Ar... |几乎完全惰性——完整的电子壳层|
| **过渡金属**（第 3-12 族）|铁、铜、金... |可变氧化态，形成有色化合物 |
| **镧系元素** (57-71) | Ce、Nd、Eu... |稀土元素；用于磁铁、激光、磷光体|
| **锕系元素** (89-103) | U、Pu、Am... |全部具有放射性；核能中使用的铀和钚|
### 周期性趋势
|趋势 |跨越一个时期 (→) |下一组 (↓) |
|--------|---------------------|--------------------|
| **原子半径** |减少（更多质子将电子拉得更紧）|增加（更多电子壳层） |
| **电离能** |增加（更难去除电子）|减少（外层电子远离原子核）|
| **电负性** |增加（共享电子的吸引力更强）|减少 |
| **金属特性** |减少 |增加|

## 化学键合
原子键合以实现稳定的电子构型。三种主要类型：
### 债券类型
|债券类型|机制|实力|示例|
|------------|------------|----------|---------|
| **离子** |一个原子放弃一个电子，另一个原子接受它。相反的电荷相互吸引。 |强|氯化钠（食盐）|
| **共价** |原子共享电子。 |比离子强 | H2O（水）、CO2、DNA |
| **金属** |电子在原子之间自由流动，形成电荷“海洋”。 |变量|铁、铜、金（所有金属）|
### 分子间力
除了分子内的键之外，分子之间的力决定熔点、沸点和溶解度：
|力|实力|示例|
|--------|----------|---------|
| **氢键** |强（分子间力）|水 (H2O)、DNA 碱基对 |
| **偶极子-偶极子** |中等|盐酸、丙酮|
| **伦敦分散** |弱（但普遍）|所有分子；在石油等非极性物质中占主导地位
氢键是水如此小分子的沸点异常高的原因，也是冰漂浮的原因（氢键形成开放的晶体结构）。

## 化学反应
化学反应会重新排列原子——打破旧的键并形成新的键——而不改变原子本身。
### 反应类型
|类型 |图案|示例|
|------|---------|---------|
| **合成** | A + B → AB | 2H2 + O2 → 2H2O |
| **分解** | AB → A + B | 2H2O → 2H2 + O2 |
| **单个更换** | A + BC → AC + B | Zn + CuSO₄ → ZnSO₄ + Cu |
| **双重更换** | AB + CD → AD + CB | AgNO₃ + NaCl → AgCl + NaNO₃ |
| **燃烧** |燃料 + O2 → CO2 + H2O | CH₄ + 2O2 → CO2 + 2H2O |
| **氧化还原** |物种之间的电子转移 |生锈：4Fe + 3O2 → 2Fe2O₃ |
### 平衡方程
每个化学方程式两侧的每种类型原子的数量必须相同（质量守恒）。调整系数（分子前面的数字）以实现平衡，而不是分子内的下标。
### 反应率
|因素 |对利率的影响|为什么 |
|--------|----------------|-----|
| **温度** |增加|分子运动得更快，碰撞更剧烈 |
| **专注** |增加|每体积更多的分子，更多的碰撞 |
| **表面积** |增加|更多暴露的颗粒可发生反应|
| **催化剂** |增加|降低活化能而不被消耗 |
| **压力**（气体）|增加|分子被迫靠得更近|

## 酸、碱和 pH 值
pH 范围为 0 至 14。低于 7 为酸性，高于 7 为碱性（碱性），7 为中性。
|物质 |酸碱度|笔记|
|------------|-----|--------|
| **胃酸** | 〜1.5 |强度足以溶解金属 |
| **柠檬汁** | 〜2.0 |柠檬酸|
| **醋** | 〜2.5 |醋酸|
| **纯净水** | 7.0 |中性|
| **血** | 〜7.4 |严格监管； ±0.5的偏差可能是致命的 |
| **小苏打溶液** | 〜8.5 |温和的碱 |
| **漂白剂** | 〜13 |强碱（氢氧化钠）|
每个整数阶跃代表酸度的 10 倍变化，因此 pH 3 的酸性是 pH 4 的十倍，是 pH 5 的一百倍。

## 有机化学
有机化学是对碳基化合物的研究。碳是独特的——它形成四个稳定的共价键，可以以长链和环的形式与自身结合，是所有已知生命的基础。
### 关键功能组
|集团|结构|发现于 |
|--------|------------|----------|
| **羟基** (−OH) |氧气+氢气|醇类（乙醇、甲醇）|
| **羰基** (C=O) |碳与氧双键 |醛、酮、糖|
| **羧基** (−COOH) |羰基+羟基|有机酸（乙酸、氨基酸）|
| **氨基** (−NH2) |氮+两个氢|氨基酸、蛋白质 |
| **磷酸盐** (−PO₄) |磷+四个氧| DNA、ATP（细胞能量）|
| **甲基** (−CH₃) |碳+三个氢 |基因表达（甲基化），脂肪 |
### 生命大分子
|高分子|积木 |功能|
|----------------|----------------|----------|
| **蛋白质** |氨基酸（20种）|酶、结构、信号传导、运输 |
| **碳水化合物** |单糖（葡萄糖）|结构储能（纤维素）|
| **脂质** |脂肪酸+甘油 |细胞膜、长期能量储存、激素|
| **核酸** |核苷酸|信息存储（DNA、RNA）|

## 物质状态
|状态 |形状|卷 |粒子行为|
|--------|--------|--------|--------------------|
| **固体** |固定|固定|粒子原地振动；牢固的联系|
| **液体** |呈容器形状|固定|粒子相互滑过；中等债券|
| **天然气** |填充容器|填充容器|颗粒自由移动；弱/无键 |
| **等离子** |填充容器|填充容器|电离气体；从原子中剥离的电子（恒星、闪电）|
在特定温度和压力下发生相变：熔化、冻结、蒸发、冷凝、升华（直接固体→气体）和沉积（气体→固体）。

＃＃ 概括
化学是研究原子如何结合和相互作用的科学。元素周期表根据元素的化学行为来组织元素，而化学行为是由电子构型决定的。原子以离子键（转移电子）、共价键（共享电子）或金属键（自由流动电子）键合。化学反应在质量守恒的同时重新排列原子，其速率取决于温度、浓度、表面积和催化剂。酸和碱以对数 pH 值表示。有机化学——对碳化合物的研究——通过四种大分子类别支撑所有生物学：蛋白质、碳水化合物、脂质和核酸。了解化学对于生物学、医学、材料科学、环境科学和工程学至关重要。
