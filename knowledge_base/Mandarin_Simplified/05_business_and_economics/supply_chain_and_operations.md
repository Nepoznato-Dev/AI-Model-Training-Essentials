# 供应​​链和运营管理
供应链管理是对涉及寻源、采购、转换和物流的所有活动的协调——从原材料到客户手中的成品。运营管理是生产系统的日常运行。它们共同决定了公司是否能够在正确的时间、以正确的成本、以正确的质量交付正确的产品。疫情、芯片短缺和运河堵塞表明，全球供应链是多么脆弱且相互关联。
---

## 供应链基础知识
### 供应链流程
|舞台|活动 |主要关注点|
|--------|----------|-------------|
| **计划** |需求预测；供应计划；标准与操作 |准确性;反应能力|
| **来源** |供应商选择；采购;承包|成本;质量;可靠性;道德 |
| **制作** |生产;集会;质量控制|效率;灵活性;容量|
| **交付** |仓储；订单履行；交通 |速度;成本;准确度 |
| **返回** |逆向物流；返回；回收|客户满意度；成本回收|
### 供应链类型
|类型 |特点 |最适合 |
|------|----------------|----------|
| **高效** |利用率高；低成本;可预测|需求稳定的功能性产品（杂货）|
| **反应灵敏** |缓冲能力；灵活的;快|需求不确定的创新产品（时尚）|
| **有弹性** |冗余;能见度;适应性 |高风险环境；关键货物|
| **敏捷** |延期；大规模定制|产品品种多、生命周期短 |
| **精益** |消除浪费；基于拉动；及时 |大容量；品种少；需求稳定|

## 库存管理
### 库存类型
|类型 |描述 |目的|
|------|-------------|---------|
| **原材料** |未处理的输入 |缓冲供应波动|
| **进行中工作 (WIP)** |半成品|生产阶段之间的缓冲|
| **成品** |准备出售 |缓冲需求变化|
| **MRO**（维护、修理、运营）|运营所需的物资 |保持生产运行 |
| **安全库存** |超出预期需求的额外库存 |防范不确定性|
| **管道库存** |在地点之间过境 |运输过程中不可避免的 |
### 库存管理模型
|型号|描述 |何时使用 |
|--------|-------------|-------------|
| **EOQ**（经济订单数量）|最小化总持有+订购成本的最佳订单规模|需求稳定；恒定的交货时间|
| **再订购点 (ROP)** |库存下降到阈值时订购 |持续审查；可预测的需求|
| **ABC分析** |按价值对项目进行分类：A（高）、B（中）、C（低）|优先考虑管理层的关注|
| **准时制 (JIT)** |仅根据生产需要接收货物 |稳定的供应链；低变异性 |
| **供应商管理库存 (VMI)** |供应商管理库存水平 |强大的供应商关系 |
| **寄售** |供应商拥有库存直到使用为止 |降低买家的搬运成本|

## 生产系统
### 制造方法
|方法|描述 |卷 |品种 |示例|
|----------|-------------|--------|---------|---------|
| **工作店** |定制产品；通用设备|低|高|机械车间；定制家具 |
| **批次** |批量生产；批次之间的转换|中等|中等|面包店；药品 |
| **量产** |大容量；专用设备；装配线|高|低|汽车；电子产品 |
| **连续流动** |不间断生产；全自动|非常高|非常低|炼油；化学品；钢 |
| **大规模定制** |高产量+高品种；灵活的自动化|高|高|戴尔电脑；耐克为你|
### 精益制造
|原理|描述 |
|------------|-------------|
| **价值** |定义客户认为有价值的东西 |
| **价值流** |绘制所有步骤；识别那些能增加价值的|
| **流量** |让创造价值的步骤顺利进行而不会中断 |
| **拉** |仅在客户要求时生产 |
| **完美** |持续消除浪费（muda）|
### 七种浪费（Muda）
|废物|描述 |示例|
|--------|-------------|---------|
| **生产过剩** |赚得比需要的多|当需求不确定时按预测生产 |
| **等待** |步骤之间的空闲时间|等待下一台机器的零件|
| **交通** |不必要的物料移动 |在遥远的仓库之间移动产品 |
| **过度加工** |做超出必要的工作 |额外检查；不必要的功能|
| **库存** |库存过剩，超出需求 | “以防万一”的安全库存 |
| **运动** |人员不必要的流动|步行取工具；伸手去拿零件|
| **缺陷** |不符合规格的产品 |返工；废料;保修索赔|

## 物流运输
### 交通方式
|模式|成本|速度|产能 |最适合 |
|------|------|--------|----------|----------|
| **公路**（卡车）|中等|中等|中等|最后一英里；区域性；灵活的路由|
| **铁路** |低|中等|高|大宗商品；陆地长途|
| **海事**（船舶）|非常低|很慢|非常高|国际的;大部分;集装箱 |
| **空气** |非常高|非常快|低|高价值；紧迫的;易腐烂|
| **管道** |低（施工后）|连续 |高|油;气体;水 |
| **联运** |变化 |变化 |高|组合模式；集装箱货运|
### 仓库设计
|决定|选项|权衡|
|----------|---------|------------|
| **仓库数量** |很少（集中）与很多（区域）|成本效率与交付速度 |
| **自动化水平** |手动 vs 半自动 vs 全自动 |资本成本与劳动力成本和准确性 |
| **布局** | U 型流与贯通流 |空间利用率与行驶距离|
| **存储系统** |货架；货架；自动化/RS；旋转木马|密度与可达性与成本|

## 供应链风险管理
### 常见风险
|风险类别 |示例 |缓解措施 |
|--------------|----------|------------|
| **需求风险** |预测错误；牛鞭效应|更好的预测；需求感知；安全库存|
| **供应风险** |供应商破产；质量故障|双重来源；供应商审核；安全库存|
| **物流风险** |港口拥堵；运营商故障 |多式联运；替代路线|
| **地缘政治风险** |关税；贸易战；制裁|近岸外包；多元化采购国家|
| **自然灾害** |地震;洪水;流行病|地理多样化；业务连续性计划|
| **网络风险** |勒索软件；数据泄露|信息技术安全；备份系统|
### 牛鞭效应
|原因 |描述 |解决方案 |
|--------|-------------|----------|
| **需求预测更新** |每个阶段都会增加自己的安全库存|跨链共享销售点数据 |
| **订单批量** |定期订购造成需求激增|减少订单周期时间；电子数据交换 |
| **价格波动** |促销期间提前购买 |每日低价；价格稳定|
| **配给和短缺游戏** |缺货期间超额订购 |根据过去的销售情况进行分配；分享容量信息 |

## 现代供应链趋势
|趋势 |描述 |影响 |
|--------|-------------|--------|
| **数字孪生** |用于模拟的供应链虚拟复制品|更好的规划；情景分析|
| **供应链控制塔** |整个链条的集中可见性|更快地响应中断 |
| **近岸外包/友岸外包** |将生产转移到离本国或盟国更近的地方|降低风险；成本较高|
| **循环供应链** |再利用、再制造、回收设计 |可持续性；资源效率|
| **人工智能驱动的需求感知** |用于短期预测的实时数据机器学习 |更准确；更快的响应 |
| **自动驾驶汽车和无人机** |自动驾驶卡车；无人机送货|成本更低；更快的最后一英里|
---

＃＃ 概括
供应链和运营管理旨在提高货物的实际流动效率、响应速度和弹性。库存管理平衡持有库存的成本和缺货风险。生产系统范围从加工车间（定制、小批量）到连续流程（商品、大批量）。精益制造消除浪费，提高效率。物流决策——运输模式、仓库位置、自动化水平——决定成本和服务质量。风险管理解决牛鞭效应、供应商失败、地缘政治混乱和自然灾害。数字孪生、人工智能驱动的需求感知和近岸外包等现代趋势反映了该行业对日益动荡的世界的反应。最好的供应链不仅是高效的，而且是可见的、灵活的，并且为中断做好了准备。
