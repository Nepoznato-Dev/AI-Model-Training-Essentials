# 组织设计和文化
组织设计是为了有效执行战略而对结构、流程、角色和决策权进行的有意安排。文化是塑造人们实际合作方式的共同价值观、信仰、规范和行为。结构提供框架；文化塑造行为。可以在纸上重新设计结构，但如果文化不支持变革，实施就会失败。同样，强大的文化与无效的结构相结合也会逐渐损害组织绩效。最有效的组织会同时解决这两个问题，并认识到它们之间是紧密相连的。
---

## 组织结构
### 常见结构
|结构|描述 |优势 |弱点|
|------------|-------------|------------|------------|
| **功能性** |按专业分组（工程、营销、销售）|深厚的专业知识；效率;清晰的职业道路 |筒仓；跨职能协调缓慢|
| **部门** |按产品、市场或地理位置分组 |关注客户/市场；损益责任 |职能重复；资源竞争|
| **矩阵** |双重报告：职能+产品/项目|灵活性;跨职能协作|困惑;权力斗争；缓慢的决定|
| **平面/水平** |管理层较少；广泛的控制范围|快速决策；赋予员工权力；低开销|难以扩展；报告不明确|
| **基于团队** |围绕跨职能团队组织 |自治;速度;以客户为中心 |团队间的协调；一致性|
| **网络/平台** |核心团队+外部合作伙伴；平台赋能他人|可扩展性；灵活性;轻资产|质量控制；对合作伙伴的依赖|
| **合弄制** |自我管理的团队；由职责定义的角色|高度自主性；自适应 |令人困惑；并不适合所有人|
### 控制范围
|因素|窄跨度 (4-6) |跨度大（10-15+）|
|--------------------|--------------------|---------------------|
| **管理层** |许多 |很少|
| **监督** |关闭;动手|委托；放手 |
| **最适合** |复杂的任务；缺乏经验的团队|日常任务；经验丰富、自主的团队 |
| **风险** |微观管理；缓慢的决定|缺乏支持；协调差距|
### 集中化与分散化
|尺寸|集中式|去中心化|
|----------|----------|--------------|
| **决策** |自上而下|被推到边缘|
| **速度** |慢（顶部瓶颈）|快速（本地决策）|
| **一致性** |高|变量|
| **创新** |受top带宽限制|来自多个来源|
| **最适合** |危机;早期阶段；合规重工业|知识工作；快速变化的市场；放大 |

## 设计原则
### 组织设计中的关键决策
|决定|问题 |选项|
|----------|----------|---------|
| **部门化** |我们如何对人进行分组？ |按功能；产品;顾客;地理;流程|
| **命令链** |谁向谁汇报？ |层次清晰；矩阵;网络|
| **决定权** |谁决定什么？ |集中;去中心化； RACI矩阵|
| **协调机制** |团队如何协同工作？ |联络角色；跨职能团队；集成商；共同目标|
| **标准化** |标准化与本地化的区别是多少？ |流程；输出；技能；规范 |
### 加尔布雷思的明星模特
|元素|描述 |
|---------|-------------|
| **策略** |方向;目标；竞争优势；该组织存在的原因|
| **结构** |报告关系；等级制度;单位分组 |
| **流程** |信息流；决策;规划;预算|
| **奖励** |激励措施；绩效衡量；与战略保持一致|
| **人** |招聘；发展;文化;人类的能力|
关键见解：战略驱动结构。所有其他元素必须对齐。改变结构而不改变流程、奖励和人员发展将会失败。

## 组织文化
### 文化到底是什么
|层 |描述 |能见度|
|--------|-------------|------------|
| **文物** |可见的结构、流程、行为、着装规范、办公室布局 |容易看到；难以解释|
| **拥护的价值观** |明确的战略、目标、理念、使命宣言|公开宣布；可能与实际行为不符 |
| **基本假设** |无意识的、被视为理所当然的信念、看法、想法、感受|无形的;行为的真正驱动力|
### 文化类型（竞争价值观框架）
|文化|焦点 |特点 |示例|
|--------|---------|----------------|---------|
| **氏族**（合作）|内部+灵活|像家人一样；指导；团队合作；共识 |捷步；小型初创公司|
| **临时性**（创建）|外部+灵活|创新的;承担风险；创业精神；动态 |谷歌（早期）；太空探索技术公司 |
| **市场**（竞争）|外部+控制|以结果为导向；竞争的;以目标为中心；市场份额|亚马逊;华尔街公司|
| **层次结构**（控制）|内部+控制|结构化；流程驱动；效率;一致性|政府机构；军队;传统银行|
### 文化维度
|尺寸|描述 |
|------------|-------------|
| **心理安全** |人们能否承担风险并表现出脆弱性而不必担心受到惩罚？ |
| **责任** |人们对自己的承诺负责吗？ |
| **透明度** |信息是公开分享还是作为权力被储藏起来？ |
| **创新宽容** |失败是受到惩罚还是被视为学习？ |
| **以客户为导向** |决策是从客户需求出发还是从内部便利出发？ |
| **速度与质量** |是偏向快速迭代还是仔细考虑？ |
| **等级尊重** |初级人员可以挑战高级人员的想法吗？ |

## 变革管理
### 为什么变革计划失败
|原因 |描述 |
|--------|-------------|
| **不紧急** |人们不明白为什么需要改变|
| **没有联盟** |没有强大的团体推动变革|
| **没有视力** |不清楚未来的状态是什么样子 |
| **沟通不畅** |人们不理解这种变化或他们在其中的角色|
| **没有速效** |没有明显的进展来建立势头|
| **过早的庆祝** |在嵌入变革之前宣布胜利 |
| **文化抵抗** |变革与根深蒂固的假设相冲突|
| **无加固** |旧行为得到奖励；新行为未能持续|
### Kotter 的 8 步模型
|步骤|行动|
|------|--------|
| **1.制造紧迫感** |帮助人们看到不改变的威胁|
| **2.建立指导联盟** |组建一个有足够权力和信誉的团体 |
| **3.形成战略愿景** |创造清晰的未来图景 |
| **4.招募志愿军** |获得关键群体的支持 |
| **5.启用操作** |消除障碍；赋予人们权力|
| **6。产生短期胜利** |创造看得见的成功|
| **7.持续加速** |继续推动；不要太早宣布胜利|
| **8.机构变革** |在文化中锚定新行为|

## 远程和混合工作
|挑战|战略|
|------------|----------|
| **通讯** |默认为书面；异步优先；记录决定|
| **信任** |衡量结果，而不是时间；避免监视|
| **入职** |结构化课程；好友系统；明确的文档|
| **文化** |有意识的仪式；定期全体人员；虚拟社交活动|
| **股权** |邻近偏见：确保远程工作人员获得平等的可见性和机会 |
| **合作** |所有权清晰；定义的接口；定期同步 |
| **幸福** |尊重界限；断开连接的权利；避免会议超载 |
---

＃＃ 概括
组织设计和文化决定了一个公司能否执行其战略。结构定义了报告关系、决策权和协调机制。文化定义了人们的实际行为方式——指导日常工作的假设、规范和价值观。加尔布雷思的明星模型提醒我们，战略、结构、流程、奖励和人员必须保持一致。文化类型范围从氏族（协作）到临时（创新）到市场（竞争）到等级（控制）。像科特的八步模型这样的变革管理框架为变革提供了结构，但文化才是真正的战场——如果变革与深刻的假设相冲突，那么无论计划得多么好，它都将失败。远程和混合工作给沟通、信任和邻近偏见带来了新的挑战。最好的组织会精心设计，建立支持其战略的文化，并在环境发生变化时仍然愿意不断发展。
