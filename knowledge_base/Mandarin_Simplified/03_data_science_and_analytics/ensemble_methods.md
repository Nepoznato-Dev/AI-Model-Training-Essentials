# 集成方法
集成方法结合了多个机器学习模型，可以产生比任何单个模型单独实现的更好的预测。直觉很简单：如果您有多个模型，每个模型都有些准确，但会产生不同的错误，那么将它们的预测结合起来将消除单个错误并产生更稳健的结果。集成是最具竞争力的机器学习解决方案的背后，并且仍然是生产系统中最可靠的技术之一。
---

## 为什么集成有效
|原理|描述 |
|------------|-------------|
| **群众的智慧** |多个不完美的估计的平均值比任何单个估计都要好 |
| **偏差-方差权衡** |集成可以在不牺牲其他 | 的情况下减少方差（bagging）或偏差（boosting）
| **错误多样性** |如果模型犯了不同的错误，将它们组合起来可以消除个别错误 |
| **决策边界平滑** |多个模型可创建比单个模型更稳健的决策面 |
---

## 装袋（引导聚合）
### 它是如何运作的
|步骤|描述 |
|------|-------------|
| **1.引导抽样** |从训练数据中抽取多个随机样本（带替换）|
| **2.火车基础模型** |在每个引导样本（通常是决策树）上训练一个模型 |
| **3.合计** |对于回归：平均预测。分类：多数票|
### 主要特征
|特点|描述 |
|----------------|-------------|
| **减少方差** |平均可以消除各个模型的波动 |
| **并行训练** |每个基础模型都是独立的；可以同时训练|
| **袋外评估** |每个样本都被排除在一些引导样本之外；使用它们进行验证 |
| **去相关** |每次分割时的随机特征选择会降低树之间的相关性 |
### 随机森林
|方面|描述 |
|--------|-------------|
| **基础学习者** |决策树|
| **关键补充** |在每次分割时，仅考虑特征的随机子集（通常为 sqrt(n_features)） |
| **为什么它有效** |随机特征选择使树去相关，使整体更加稳健 |
| **超参数** |树木数量；最大深度；每片叶子的最小样本数；最大功能 |
| **优势** |处理高维数据；对异常值具有鲁棒性；提供特征重要性|
| **弱点** |比单棵树更难解释；可能会过度拟合嘈杂的回归任务
---

## 提升
### 它是如何运作的
|步骤|描述 |
|------|-------------|
| **1.训练第一个模型** |在数据上训练基本模型（通常是浅树/“树桩”）|
| **2.识别错误** |找出模型出错的实例 |
| **3.训练下一个模型** |训练一个专注于错误的新模型（重新加权或残差拟合）|
| **4.按顺序组合** |每个新模型都会纠正所有先前模型的累积误差 |
| **5.重复** |继续指定的回合数 |
### 增强算法
|算法|损失函数|主要特点|
|------------|--------------|-------------|
| **AdaBoost** |指数|重新加权错误分类的实例；简单的;对噪音敏感|
| **梯度提升** |任何可微分损失 |拟合残差（损失梯度）；更灵活 |
| **XGBoost** |正则化梯度提升 | L1/L2 正则化；二阶梯度；硬件优化|
| **LightGBM** |基于梯度的一侧采样 |叶向生长；基于直方图；快速处理大型数据集 |
| **猫助推** |订购升压|本地处理分类特征；减少过度拟合 |
### Boosting 与 Bagging
|尺寸|装袋|提升|
|------------|---------|----------|
| **培训** |平行|顺序 |
| **焦点** |减少方差 |减少偏见 |
| **基本型号** |高方差、低偏差（深树）|低方差、高偏差（浅树/树桩）|
| **组合** |同等重量|按绩效加权 |
| **过度拟合** |不易发生 |如果轮数太多，可能会过拟合 |
| **噪音敏感度** |坚固耐用|对噪声数据敏感 |

## 堆叠
### 它是如何运作的
|步骤|描述 |
|------|-------------|
| **1.火车基础模型** |训练不同的模型（例如随机森林、SVM、神经网络、梯度提升）|
| **2.生成预测** |使用折叠预测（交叉验证）作为输入特征 |
| **3.训练元模型** |根据基本模型的预测训练二级模型 |
| **4.最终预测** |基础模型预测；元模型结合了他们的预测|
### 堆叠最佳实践
|实践|原因 |
|----------|--------|
| **使用不同的基础模型** |不同的算法会产生不同的错误；多样性是重点|
| **使用交叉验证进行基本预测** |防止元模型学习利用过度拟合的基本模型 |
| **保持元模型简单** |逻辑回归或浅树；基本模型承担繁重的工作|
| **在元模型中包含原始特征** |有时也有助于让元模型访问原始功能 |

## 实用指导
### 何时使用哪个 Ensemble
|场景 |推荐方法 |
|----------|--------------------|
| **快速基线；表格数据** |随机森林|
| **最大准确度；表格数据** | XGBoost / LightGBM / CatBoost | XGBoost / LightGBM / CatBoost |
| **噪音数据** |装袋（提升会过度拟合噪声）|
| **需要可解释性** |具有特征重要性的单一模型或小型整体 |
| **多样的型号类型** |堆叠或投票 |
| **在线学习** |流集成方法；自适应增强|
| **数据不平衡** |平衡随机森林；成本敏感的提升|
### 整体多样性策略
|战略|描述 |
|----------|-------------|
| **不同的算法** |结合基于树、线性和神经模型 |
| **不同的功能** |在不同的特征子集上训练模型 |
| **不同的数据子集** |装袋；二次抽样|
| **不同的超参数** |相同的算法不同的配置 |
| **不同时间段** |在不同的时间窗口进行训练 |

＃＃ 概括
集成方法之所以有效，是因为它们将多个不完美的模型组合成一个强大的预测器。套袋（随机森林）通过在引导样本上并行训练模型并求平均值来减少方差。 Boosting（XGBoost、LightGBM、CatBoost）通过顺序训练模型来减少偏差，每个模型都会纠正之前的错误。 Stacking 使用元模型来组合不同的基本模型。投票和平均是最简单的组合。共同点是多样性：当组件模型各自合理但会犯不同的错误时，集成效果最好。在实践中，表格数据的梯度提升通常是性能最高的单一方法，而堆叠不同的模型可以进一步提高竞赛和高风险应用中的准确性。
