# 因果推理
因果推理是一门确定一件事是否确实导致另一件事的科学，而不仅仅是它们是否相关。相关性告诉您两个变量一起移动。因果关系告诉你，改变一个就会改变另一个。这种区别在医学（这种药物有效吗？）、政策（这种干预措施是否减少贫困？）、商业（这种广告活动是否增加销量？）和科学（这种机制是否解释了这种现象？）中非常重要。
---

## 相关性与因果性
|概念 |描述 |示例|
|---------|-------------|---------|
| **相关性** |两个变量一起移动 |夏季冰淇淋销量和溺水死亡人数双双增加
| **因果关系** |一个变量直接影响另一个变量 |吸烟导致肺癌|
| **混淆** |第三个变量导致两者 |炎热的天气导致冰淇淋销售和游泳（和溺水）|
| **反向因果关系** |结果实际上导致了假定的原因 |人们购买保健品是因为生病了，而不是相反 |
| **虚假相关性** |巧合的关系|人均奶酪消费量与床单缠绕死亡相关

## 潜在成果框架
### 鲁宾因果模型
|概念 |描述 |
|---------|-------------|
| **潜在结果** |对于每个单元，如果处理 Y(1) 则有一个结果，如果未处理 Y(0) | 则有一个结果
| **治疗效果** |区别：给定单位的 Y(1) - Y(0) |
| **根本问题** |对于同一个单元，我们永远无法同时观察到 Y(1) 和 Y(0) — 我们只能看到一个 |
| **平均治疗效果 (ATE)** |人群中个体治疗效果的平均值|
| **反事实** |未观察到的结果——在其他条件下会发生什么|
### 关键假设
|假设|意义|如何满足|
|------------|--------------------|----------------|
| **可忽略性（无混淆性）** |鉴于观察到的协变量，治疗分配与潜在结果无关|随机化；衡量所有混杂因素|
| **积极性（重叠）** |每个单位接受任一治疗的概率均非零 |检查组之间的协变量重叠 |
| **SUTVA**（稳定单位处理值假设）|一个单位的治疗不会影响另一个单位的结果；治疗一致|无干扰；没有隐藏版本的治疗|
| **一致性** |观察到的结果等于接受治疗的潜在结果|明确的治疗 |

## 因果推理方法
### 实验方法
|方法|描述 |实力|限制|
|--------|-------------|----------|------------|
| **随机对照试验（RCT）** |随机分配单位进行治疗或对照 |黄金标准；消除混淆 |昂贵的;有时不道德；不可一概而论|
| **A/B 测试** |商业/技术背景下的 RCT |简单的;严谨|短期指标；新奇效果；干扰|
| **折返实验** |不同时间段的交替治疗 |处理市场干扰|需要稳定的环境 |
### 准实验方法
|方法|描述 |关键假设|
|--------|-------------|----------------|
| **双重差分 (DiD)** |比较治疗组和对照组随时间的结果变化 |平行趋势：在没有治疗的情况下，群体会遵循相同的轨迹|
| **回归不连续性 (RD)** |比较治疗截止值上方和下方的单位 |接近截止值的单位具有可比性（如同随机）|
| **工具变量 (IV)** |使用影响治疗但不影响结果（除非通过治疗）的变量 |仪器与治疗相关；仅通过治疗影响结果|
| **综合控制** |构建控制单元的加权组合以匹配处理单元 |综合控制准确地代表了被处理单位的反事实 |
| **倾向得分匹配** |将具有相似治疗概率的治疗组和对照组进行匹配 |所有混杂因素均经过测量并包含在倾向模型中 |
### 双重差异（可视化）
|期间 |治疗组|对照组|差异|
|--------|--------------|----------------|------------|
| **预处理** | Y_t_pre | Y_c_pre | Y_t_pre - Y_c_pre |
| **后处理** | Y_t_post | Y_c_post | Y_t_post - Y_c_post |
| **DiD 估计** | | | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) | (Y_t_post - Y_t_pre) - (Y_c_post - Y_c_pre) |

## 有向无环图 (DAG)
DAG 是用于编码因果假设和识别混杂因素的可视化工具。
### 基本结构
|结构|图案|寓意 |
|------------|---------|-------------|
| **链** | A → B → C | A和C通过B关联；控制 B 会阻塞路径 |
| **叉子** | A ← B → C | A 和 C 被 B 混淆；控制 B 会阻塞路径 |
| **对撞机** | A → B ← C | A和C是独立的；控制 B 打开路径（创建虚假关联） |
### DAG 规则
|规则|描述 |
|------|-------------|
| **后门标准** |要估计 X 对 Y 的因果影响，请通过调节适当的变量来阻止所有后门路径（带有指向 X 的箭头的路径）|
| **前门标准** |如果无法阻止后门路径，请使用中介：分两个阶段估计 X → M → Y |
| **不要以碰撞器为条件** |控制共同效果会打开一条虚假路径|
| **不要以碰撞器的后代为条件** |与对撞机本身的调节有同样的问题|

## 常见陷阱
|陷阱|描述 |示例|
|---------|-------------|---------|
| **省略变量偏差** |未能控制混杂因素|估算教育程度 → 不控制能力的收入 |
| **过度控制** |调节中介者或对撞机 |在估算教育程度 → 收入时控制职称 |
| **选择偏差** |调节受治疗影响的变量|研究培训→工资时只分析就业人员|
| **不朽的时间偏差** |队列研究中的人员时间错误分类患者必须存活足够长的时间才能接受治疗|
| **回归均值** |极值往往会趋向平均值 |患者治疗后病情好转无论如何|
| **治疗后偏差** |以治疗后发生的变量为条件|评估药物疗效时控制不良事件|

＃＃ 概括
因果推理是超越“发生了什么”到“如果事情不同的话会发生什么”。根本的挑战是我们永远无法观察同一单位经过治疗和未经治疗的结果——反事实总是缺失。随机实验通过使治疗组和对照组具有可比性来解决这个问题。当随机化不可能时，准实验方法——DiD、不连续性回归、工具变量、合成控制——尝试从观察数据中重建反事实。 DAG 有助于明确假设并确定要控制的正确变量。关键技能是仔细思考数据生成过程：什么导致什么，什么是混杂因素，什么是碰撞，以及在替代方案下会发生什么。
