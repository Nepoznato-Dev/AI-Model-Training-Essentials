# 特征工程
特征工程是将原始数据转换为使机器学习模型更有效的表示的过程。它通常被描述为 ML 管道中最重要的步骤 - 您为模型提供的功能比您选择的算法更重要。具有精心设计的特征的简单模型通常会优于具有原始、未经处理的输入的复杂模型。艺术在于充分理解领域和数据，以创建模型可以学习的信号。
---

## 为什么特征工程很重要
|因素|影响 |
|--------|--------|
| **信号质量** |更好的特征 = 更清晰的模型学习模式 |
| **模型简单** |好的特征可以让更简单的模型表现良好；减少对复杂架构的需求
| **训练速度** |相关的、规模化的特征收敛得更快 |
| **概括** |领域知情功能可帮助模型处理看不见的数据 |
| **可解释性** |有意义的功能更容易向利益相关者解释|
---

## 特征转换的类型
### 数值变换
|转型|公式/说明|何时使用 |
|----------------|----------------------|-------------|
| **对数变换** | log(x) 或 log(x + 1) |右偏分布；货币价值|
| **平方根** |开方(x) |适度倾斜；计数数据|
| **博克斯-考克斯** |寻找最佳功率变换的参数变换 |使数据更加正态分布 |
| **杨约翰逊** |与 Box-Cox 类似，但处理负值 |带有负值的倾斜数据 |
| **标准化** | (x - 平均值) / 标准差 |具有不同尺度的特征；假设正态性的算法 |
| **最小-最大缩放** | (x - 最小值) / (最大值 - 最小值) |将特征限制为 [0, 1]；图像像素值|
| **稳健的缩放** | (x - 中位数) / IQR |含有异常值的数据 |
| **分档** |将连续转换为分类 |非线性关系；决策树 |
| **多项式特征** | x2, x3, x₁×x2 |捕获线性模型中的非线性关系 |
### 分类编码
|编码 |描述 |何时使用 |
|----------|-------------|-------------|
| **One-hot 编码** |为每个类别创建一个二进制列 |低基数类别；基于树的模型本地处理
| **标签编码** |为每个类别分配整数 |序数类别；基于树的模型|
| **目标编码** |将类别替换为目标变量的平均值 |高基数类别；通过平滑避免过度拟合 |
| **频率编码** |将类别替换为其计数或频率 |当频率本身就具有信息性时 |
| **二进制编码** |将整数编码类别转换为二进制数字 |高基数；降低维度与 one-hot |
| **嵌入** |学习密集向量表示 |基数非常高；自然语言处理；推荐系统|
| **哈希编码** |将类别哈希为固定数量的特征 |基数非常高；在线学习 |
### 日期和时间功能
|特色 |描述 |
|---------|-------------|
| **一天中的某个时间** |捕捉日常模式（高峰时段、夜间）|
| **星期几** |工作日 vs 周末效果 |
| **月/季度** |季节性图案 |
| **是周末** |周末的二进制标志 |
| **是假期** |公共假期的二进制标志 |
| **事件发生后的时间** |自上次购买以来的天数；自上次登录以来的小时数 |
| **循环编码** | sin(2π × 小时 / 24), cos(2π × 小时 / 24) — 保留时间的循环性质 |

## 处理缺失值
|战略|描述 |何时使用 |
|----------|-------------|-------------|
| **删除行** |删除缺失值的行 |缺失数据只是一小部分； MCAR（完全随机缺失）|
| **删除列** |删除缺失值过多的特征 |大部分功能缺失；不重要|
| **均值/中位数插补** |填充特征的均值或中位数 |简单的;保留均值但减少方差 |
| **模式插补** |用最常见的值填充类别 |分类特征|
| **KNN 插补** |使用 k-近邻估计缺失值 |当相似的实例有助于预测缺失值时 |
| **基于模型的插补** |训练模型来预测缺失值 |更准确；计算成本高昂|
| **缺少指示器** |添加标记缺失的二进制列 |当缺失本身就具有丰富的信息时 |
| **插值** |用插值填充（线性、样条）|时间序列；订购数据|

## 特征选择
### 过滤方法
|方法|描述 |
|--------|-------------|
| **相关性** |删除彼此高度相关的特征 |
| **方差阈值** |删除方差接近于零的特征 |
| **相互信息** |测量每个特征提供的有关目标的信息 |
| **卡方** |测试分类特征和目标之间的独立性 |
| **方差分析 F 检验** |测试不同目标类别的数字特征平均值是否不同 |
### 包装方法
|方法|描述 |
|--------|-------------|
| **向前选择** |从空开始；一次添加一个最好的功能 |
| **向后消除** |从一切开始；一次删除一个最差的功能 |
| **递归特征消除（RFE）** |反复训练模型；删除最不重要的功能 |
### 嵌入方法
|方法|描述 |
|--------|-------------|
| **L1 正则化（套索）** |将不相关的特征权重缩小到零 |
| **基于树的重要性** |使用树模型中的特征重要性 |
| **形状值** |衡量每个特征对预测的贡献 |

## 特定领域的特征工程
### 文本特征
|特色 |描述 |
|---------|-------------|
| **TF-IDF** |按逆文档频率加权的词频 |
| **词嵌入** |捕获语义的密集向量（Word2Vec、GloVe）|
| **字符 n 元语法** |捕获子词模式；对于拼写错误和词法有用 |
| **文本统计** |长度;字数统计；句子计数；平均字长 |
| **可读性分数** |弗莱施-金凯德；喷枪雾指数|
### 时间序列特征
|特色 |描述 |
|---------|-------------|
| **滞后功能** |先前值：y(t-1)、y(t-7)、y(t-30) |
| **滚动统计** |窗口上的平均值、标准差、最小值、最大值 |
| **差异** | y(t) - y(t-1)；捕捉趋势|
| **季节差异** | y(t) - y(t-12) 用于具有年度季节性的月度数据 |
| **傅里叶项** |季节性模式的正弦和余弦术语 |
### 图像特征（深度学习前）
|特色 |描述 |
|---------|-------------|
| **HOG**（定向梯度直方图）|边缘方向分布|
| **LBP**（本地二进制模式）|纹理描述|
| **SIFT**（尺度不变特征变换）|关键点描述符 |
| **颜色直方图** |图像中颜色的分布|

## 特征工程最佳实践
|实践|描述 |
|----------|-------------|
| **避免数据泄露** |永远不要使用来自未来或测试集的信息来创建特征 |
| **记录一切** |记录应用了哪些转换以及原因 |
| **版本化您的功能** |跟踪功能更改以及模型更改 |
| **使用和不使用**进行验证 |测试新功能是否真正提高了模型性能 |
| **保持可重复性** |特征工程管道应该是确定性的和可重复的 |
| **监控功能漂移** |特征分布可能会随着时间的推移而改变；监控和再培训|
---

＃＃ 概括
特征工程是领域知识与机器学习的结合。这是将原始数据（杂乱、不完整、高维）转换为模型可以学习的干净、信息丰富的表示的过程。数值转换处理倾斜和缩放。分类编码将标签转换为模型可以使用的数字。日期特征捕获时间模式。缺失值策略处理不完整的数据。特征选择消除了噪声和冗余。最好的功能工程师像侦探一样思考：他们询问数据中应该存在哪些信号，这些信号可能隐藏在哪里，以及如何以诚实（无数据泄漏）、可重复且能够随时间变化的方式提取它们。
