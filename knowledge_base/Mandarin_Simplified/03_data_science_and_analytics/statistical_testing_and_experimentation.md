# 统计测试和实验
统计学是科学的语法。它为您提供了区分真实模式和随机噪声的工具，衡量更改是否真正改善了情况，并在不确定的情况下做出决策。该文件涵盖了假设检验、实验设计的核心概念，以及令人困惑的常见陷阱。
---

## 假设检验框架
每个统计测试都遵循相同的逻辑：
1. **陈述原假设 (H₀)**：没有影响/没有差异。
2. **陈述备择假设 (H₁)**：存在效果/差异。
3. **选择显着性水平 (α)**：通常为 0.05（5% 的假阳性几率）。
4. **收集数据并计算检验统计量**。
5. **计算 p 值**：如果 H₀ 为真，则观察到此结果（或更极端）的概率。
6. **做出决定**：如果 p < α，则拒绝 H₀（具有统计显着性）。否则，无法拒绝 H₀。
### 关键概念
|概念 |意义|常见的误解 |
|--------|---------|---------------------|
| **p 值** | P(数据\| H₀为真) |不是“H₀ 为真的概率”|
| **α（显着性水平）** |拒绝 H₀ | 的阈值不是效果重要性的衡量标准|
| **统计意义** |仅凭偶然性，结果不太可能|并不意味着具有实际意义 |
| **效果大小** |观察到的影响的大小|与 p 值分开；当 N 较大时，微小的影响可能会很显着 |
| **电源** |正确拒绝错误 H₀ 的概率 |通常目标是 80% 以上 |
| **置信区间** |参数的合理值范围 | 95% CI 并不意味着“真实值有 95% 的概率在此范围内”|
---

## 错误类型
| | H₀ 为真 | H₀ 为假 |
|---|-----------|------------|
| **拒绝 H₀** | I 类错误（误报）| ✅ 正确（真阳性）|
| **无法拒绝H₀** | ✅ 正确（真阴性）| II 类错误（假阴性）|
|错误 |符号|意义|
|--------|--------|---------|
| **I 型** | α |当没有效果时就得出有效果的结论|
| **II 型** | β |缺少真实效果|
---

## 选择正确的测试
|场景 |测试|假设|
|----------|------|-------------|
|比较 2 组的平均值 | **t 检验**（独立）|正态分布，等方差 |
|比较配对观察的平均值 | **配对 t 检验** |差异呈正态分布|
|比较 3 个以上组的平均值 | **方差分析** |正态分布，等方差 |
|比较分类分布 | **卡方检验** |每个细胞有足够的样本量 |
|比较分布（非参数）| **曼-惠特尼大学** |无正态性假设 |
|比较 3 个以上组（非参数）| **克鲁斯卡尔-沃利斯** |无正态性假设 |
|测试相关性 | **Pearson**（线性）或 **Spearman**（单调）|皮尔逊：正常；斯皮尔曼：基于等级 |
|测试数据是否服从分布 | **柯尔莫哥洛夫-斯米尔诺夫** |连续数据|
### 参数化与非参数化
| |参数|非参数|
|---|-----------|---------------|
| **假设** |数据遵循特定分布（通常是正态分布） |无分布假设 |
| **电源** |满足假设时更高 |更低，但更坚固 |
| **何时使用** |大样本，近似正态数据|小样本、倾斜数据、有序数据 |

## 详细具体测试
### t 检验
比较两组的平均值。
|变体 |使用案例|
|---------|----------|
| **独立 t 检验** |两个独立的组（治疗组与对照组）|
| **配对 t 检验** |同一组测量两次（之前与之后）|
| **单样本 t 检验** |将样本均值与已知值进行比较 |
```python
from scipy import stats

# Independent t-test
t_stat, p_value = stats.ttest_ind(group_a, group_b)
```

### ANOVA（方差分析）
比较 3 个或更多组的平均值。测试至少一组平均值是否与其他组不同。
|类型 |设计|
|------|--------|
| **单向方差分析** |具有 3 个以上级别的一个自变量 |
| **双向方差分析** |两个自变量；测试交互效果|
| **重复测量方差分析** |相同的受试者在不同条件下测量|
如果方差分析显着，请进行**事后检验**（Tukey 的 HSD）以找出哪些特定组存在差异。
### 卡方检验
测试两个分类变量是否独立。
|使用案例|示例|
|----------|---------|
| **独立性测试** |性别与产品偏好有关吗？ |
| **贴合度** |骰子是否遵循均匀分布？ |
**经验法则**：每个单元格的预期计数应至少为 5。
---

## A/B 测试
A/B 测试是假设检验在业务决策中的应用——通常将对照 (A) 与变体 (B) 进行比较。
### 设计流程
|步骤|描述 |
|------|-------------|
| **1.定义假设** | “将按钮颜色从蓝色更改为绿色将提高点击率”|
| **2.选择指标** |主要：点击率。第二：转化率、收入。 |
| **3.计算样本量** |基于最小可检测效果、功效 (80%) 和显着性 (5%) |
| **4.随机化** |随机分配用户进行控制和治疗 |
| **5.运行实验** |收集数据直至达到目标样本量 |
| **6。分析** |使用适当的统计测试来比较指标 |
| **7.决定** |如果具有统计意义和实际意义，则实施 |
### 样本量计算
您需要的样本量取决于：
|因素|对样本量的影响|
|--------|----------------------|
| **检测到的影响较小** |需要更多样品 |
| **更高功率** |需要更多样品 |
| **较低的显着性水平** |需要更多样品 |
| **更高的方差** |需要更多样品 |
### 常见的 A/B 测试错误
|错误|为什么这是错误的 |
|--------|----------------|
| **早点看** |每日检查结果会增加误报率 |
| **多个指标无需修正** |在 α=0.05 处测试 20 个指标 → 预计会偶然出现 1 个误报 |
| **在目标 N 之前停止** |动力不足的测试无法检测出真实效果 |
| **忽略季节性** |在假期期间与正常周进行测试 |
| **非随机分配** |选择偏差（例如，为新用户分配治疗）|
| **混淆意义与重要性** | 0.1% 的提升可能具有统计意义，但不值得运送 |
---

## 多重比较
当您同时运行多项测试时，至少出现一项误报的可能性会急剧增加。
|测试次数|假阳性率≥1（α=0.05）|
|----------------|----------------------------------------------------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 10 40% |
| 20 | 20 64% |
### 更正
|方法|它是如何运作的 |何时使用 |
|--------|-------------|-------------|
| **邦费罗尼** |将 α 除以测试次数 (α/n) |保守的;一些比较|
| **霍尔姆-邦费罗尼** |降压程序；不那么保守|一般用途 |
| **杰明尼-霍赫伯格 (FDR)** |控制错误发现率|许多测试；探索性分析 |
---

## 效果大小
P 值告诉您*是否*存在效果。效应大小告诉您它有“多大”。
|测量|对于|解读|
|--------|-----|----------------|
| **科恩的d** |两种方法之间的差异| 0.2 = 小，0.5 = 中，0.8 = 大 |
| **皮尔逊的r** |相关性| 0.1 = 小，0.3 = 中，0.5 = 大 |
| **η²（eta 平方）** |方差分析 | 0.01 = 小，0.06 = 中，0.14 = 大 |
| **优势比** |分类结果 | 1.0 = 无影响； >1 或 <1 = 效果 |
**始终与 p 值一起报告效应大小。** 结果可能具有统计显着性，但实际上毫无意义。
---

## 贝叶斯主义与频率主义
|方面|常客 |贝叶斯 |
|--------|------------|----------|
| **概率** |事件的长期频率|信念程度|
| **参数** |已修复但未知 |具有分布的随机变量 |
| **用途** | p 值、置信区间、假设检验 |后验分布，可信区间 |
| **之前** |没有纳入先前的信念|显式先验分布 |
| **解读** | “如果我们多次重复这个实验......”| “根据数据，概率......”|
| **优势** |客观、完善、简单 |直观的解释，融合了先验知识 |
| **弱点** | p 值被广泛误解 |先验的选择可能是主观的 |
---

## 因果推理基础知识
相关性不是因果关系。但有时您需要知道 *X 是否导致 Y*，而不仅仅是它们是否相关。
|方法|描述 |何时使用 |
|--------|-------------|-------------|
| **随机实验** |黄金标准；随机分配消除了混杂因素当你可以随机化|
| **双重差分 (DiD)** |比较治疗组和对照组之间随时间的变化|政策变化，自然实验|
| **断点回归 (RDD)** |利用截止阈值 |奖学金、资格门槛|
| **工具变量 (IV)** |使用影响治疗但不直接影响结果的仪器 |当随机化不可能时 |
| **倾向得分匹配** |根据观察到的特征匹配处理单元和对照单元 |观察性研究|
---

## 常见统计错误
|错误|描述 |
|---------|-------------|
| **p-黑客** |尝试多次分析，直到发现 p < 0.05 |
| **聆听** |已知结果后进行假设 |
| **幸存者偏差** |只关注成功（例如，成功的公司）|
| **辛普森悖论** |当数据聚合与按组拆分时，趋势会发生逆转 |
| **基本利率忽略** |解释结果时忽略先验概率 |
| **生态谬误** |从群体层面的数据推断个体行为 |
| **混淆** |第三个变量解释了观察到的关系|
| **过度拟合** |模型捕获噪声，而不是信号 |
---

＃＃ 概括
统计测试是在不确定的情况下以理智的诚实做出决策。在收集数据之前始终陈述您的假设。为您的数据类型选择正确的测试。报告效应大小，而不仅仅是 p 值。多重比较正确。请记住：统计显着性与实际显着性不同。
