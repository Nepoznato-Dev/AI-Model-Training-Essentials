# 地理空间分析
地理空间分析是检查具有地理成分（坐标、地址、边界或与地球上某个位置相关的任何数据）的数据的过程。它回答了诸如“我们的客户在哪里？”、“最佳路线是什么？”以及“土地利用如何随时间变化？”等问题。每个数据集都有一个空间维度，理解它可以解锁纯统计分析所错过的见解。
---

## 核心概念
### 坐标系
|系统|描述 |使用案例|
|--------|-------------|----------|
| **WGS 84 (EPSG:4326)** |全球标准；纬度/经度（以度为单位）|全球定位系统;大多数网络地图； GeoJSON |
| **网络墨卡托 (EPSG:3857)** |将地球仪投影到圆柱体上；扭曲极点面积 |谷歌地图；地图盒；大多数网络磁贴服务|
| **UTM**（通用横轴墨卡托）|将地球分为60个区域；以米为基础 |军队;测量；高精度本地作业|
| **英国国家电网（EPSG：27700）** | OSGB36数据；以米为基础 |英国地图|
| **本地预测** |针对特定区域的自定义预测 |最大限度地减少特定区域的变形 |
### 几何类型
|类型 |描述 |示例|
|------|-------------|---------|
| **点** |单坐标 |一家餐厅；传感器；一位客户 |
| **线串** |点的有序序列 |一条路；一条河；一条路线 |
| **多边形** |带内部的封闭形状|一个国家；一个湖；交货区 |
| **多点** |积分收集|一个城市的所有公交车站 |
| **多行字符串** |线条集合|网络中的所有道路|
| **多重多边形** |多边形的集合|一个群岛；一个有岛屿的国家|
| **几何集合** |混合型|一个拥有城市、道路和河流的国家|
---

## 数据格式
|格式|类型 |主要特点|
|--------|------|-------------|
| **GeoJSON** |文本 (JSON) |人类可读；网络友好；支持所有几何类型 |
| **形状文件** |二进制（多个文件）| ESRI 的旧版格式； .shp + .shx + .dbf + .prj |
| **KML** | XML |谷歌地球；支持3D和时间|
| **地理包** |基于 SQLite |单个文件；支持光栅和矢量；现代标准|
| **GeoParquet** |柱状（实木复合地板）|对于大型数据集有效；与数据工程工具集成|
| **WKT / WKB** |文本/二进制|众所周知的文本；众所周知的二进制文件；用于数据库存储|
| **MVT** |二进制 | Mapbox 矢量图块；用于向网络客户端提供地图数据|
---

## 空间操作
### 基本操作
|运营|描述 |示例|
|------------|-------------|---------|
| **距离** |计算几何图形之间的距离 | “查找10公里内所有医院” |
| **缓冲区** |以给定距离围绕几何体创建多边形 | “显示学校周围 500m 的区域”|
| **十字路口** |查找几何图形之间的重叠区域 | “哪些地块位于洪水区？” |
| **联盟** |将几何图形合并为一个 | “将所有地块合并为一个区域”|
| **差异** |从一种几何图形中减去另一种几何图形 | “可建设面积不包括保护区”|
| **包含/内** |测试一个几何体是否在另一个几何体内部 | “哪些客户在这个送货范围内？” |
| **最近的邻居** |找到最接近的几何形状 | “最近的消防局是哪一个？” |
| **空间连接** |基于空间关系连接属性| “将每个点分配给其包含的人口普查区域” |
### 空间索引
|指数类型 |描述 |使用案例|
|------------|-------------|----------|
| **R 树** |边界框层次结构；最常见 |后地理信息系统； SQLite；通用 |
| **四叉树** |递归细分为象限 |点数据；游戏引擎|
| **Geohash** |分层网格；编码为字符串 |邻近搜索；数据库分片 |
| **H3**（优步）|六边形分层网格 |分析；拼车；统一垃圾箱|
| **S2**（谷歌）|球体上基于单元的层次结构 |大规模空间索引 |

## 地理空间分析模式
### 常见分析类型
|图案|描述 |使用案例|
|---------|-------------|----------|
| **点模式分析** |检查点分布 |犯罪地图；疾病爆发检测|
| **热点分析** |查找具有统计显着性的聚类 |零售地点；犯罪;流行病学 |
| **网络分析** |路线优化；服务领域 |后勤;应急响应；公用事业|
| **空间插值** |未采样位置的估计值 |空气质量；土壤特性；天气 |
| **土地利用变化检测** |比较一段时间内的卫星图像 |城市扩张；毁林；农业 |
| **适宜性分析** |查找满足多个条件的地点 |选址；保护规划|
| **空间自相关** |测量附近值的相关性 |房地产价格；疾病传播|
### 可修改面积单位问题 (MAUP)
|方面|问题 |
|--------|---------|
| **规模效应** |结果会根据分析单位的大小而变化（人口普查区、县、州）|
| **分区效应** |结果会根据边界的绘制方式而变化，即使比例相同 |
| **含义** |切勿假设一个聚合级别的结果适用于另一聚合级别；总是测试对边界的敏感度|

## 实际考虑
|关注|指导|
|---------|----------|
| **坐标参考系统** |经常检查 CRS；切勿在计算中混合预测；在计算距离之前进行变换 |
| **精确** |浮点精度在小规模下很重要；使用适当的数据类型 |
| **性能** |空间操作成本高昂；使用空间索引；简化显示几何形状|
| **拓扑** |分析之前确保几何形状有效（无自相交、闭合多边形）|
| **规模** | Web 墨卡托扭曲面积；不要用它来计算面积 |
| **数据质量** |检查空几何图形、重复顶点、长条多边形 |
---

＃＃ 概括
地理空间分析将位置数据转化为可操作的见解。点、线和多边形代表现实世界的实体。空间操作——距离、缓冲区、交叉、连接——回答有关邻近、重叠和包含的问题。工具范围广泛，从用于数据库规模分析的 PostGIS、用于 Python 工作流程的 GeoPandas 到用于 Web 可视化的 Deck.gl。关键挑战是选择正确的坐标系、管理大型数据集的性能以及了解 MAUP——您选择的聚合边界会影响您的结果。无论您是优化配送路线、分析疾病传播还是绘制城市增长图，地理空间分析都可以提供纯数字无法捕获的空间背景。
