# 数值方法
数值方法是数学理论和实际计算之间的桥梁。虽然纯数学证明了解的存在，但数值方法实际上计算的是有限精度的近似答案。每个机器学习模型、物理模拟和数据分析管道最终都依赖于数值计算。了解这些方法——它们的准确性、稳定性和局限性——对于构建可靠的软件至关重要。
---

## 浮点运算
计算机以有限精度表示实数。 **IEEE 754 标准**定义了如何存储和操作浮点数。
### IEEE 754 格式
|格式|比特|指数|尾数|近似十进制数字|范围 |
|--------|------|----------|---------|----------------------------|--------|
|一半 (fp16) | 16 | 16 5 | 10 | 10 3.3 | ±6.5×10⁴|
|单人 (fp32) | 32 | 32 8 | 23 | 23 7.2 | ±3.4 × 10³⁸ |
|双 (fp64) | 64 | 64 11 | 11 52 | 52 15.9 | 15.9 ±1.8 × 10³⁰⁸ |
### 机器埃普西隆
**机器 epsilon** (ε_mach) 是浮点型中 1 + ε_mach > 1 的最小数。
|格式| ε_马赫 |
|--------|--------|
| FP16 | 2⁻1⁰ ≈ 9.8 × 10⁻⁴ |
| FP32 | 2⁻²³ ≈ 1.2 × 10⁻⁷ |
| FP64 | 2⁻⁵² ≈ 2.2 × 10⁻1⁶ |
### 常见陷阱
|陷阱|示例|后果|
|---------|---------|-------------|
| **灾难性取消** |计算 (1 + x) − 1 对于小 x |有效数字丢失 |
| **吸收** | 10⁸ + 1 = 10⁸ (fp32) |小价值损失大金额 |
| **非关联性** | (a + b) + c ≠ a + (b + c) |总和顺序很重要 |
| **除以接近零** | 1 / 10⁻3⁰⁰ → 溢出 |无穷大或 NaN |
### 缓解策略
|战略|描述 |
|----------|-------------|
| **卡汉求和** |补偿求和以减少吸收误差 |
| **卡汉-巴布斯卡-诺迈尔** | Kahan求和的改进版 |
| **排序求和** |先对小数求和以避免吸收 |
| **双精度算术** |使用成对的双精度数来扩展精度 |
| **体能分析** |了解问题本身是否会放大错误 |

## 求根
找到 x 使得 f(x) = 0。
### 二分法
|物业 |价值|
|----------|--------|
|需要| f 连续，f(a) 和 f(b) 符号相反 |
|收敛|线性（每一步误差减半）|
|有保证吗？ |是的——总是收敛|
| d 位数字的迭代 | ≈ d / log₁₀(2) ≈ 3.32d |
**算法：**
1. 从区间 [a, b] 开始，其中 f(a) · f(b) < 0
2. 计算中点 c = (a + b) / 2
3. 如果 f(c) = 0 或 |b − a| < 宽容，停止
4、若f(a)·f(c)<0，则设b=c；否则设置 a = c
5. 重复
### 牛顿拉夫逊法
|物业 |价值|
|----------|--------|
|需要| f 可微分，f'(x) ≠ 0 根 |
|收敛|二次（近根）|
|有保证吗？ |否——可能会出现分歧或循环|
|更新规则 | x_{n+1} = x_n − f(x_n) / f'(x_n) |
**工作示例：** 通过求解 f(x) = x² − 2 = 0 找到 √2。
- f'(x) = 2x
- x₀ = 1.5
- x₁ = 1.5 − (2.25 − 2) / 3 = 1.5 − 0.0833 = 1.4167
- x2 = 1.4167 - (2.0069 - 2) / 2.8333 = 1.4142
- x₃ = 1.41421356...（精确到小数点后 8 位）
### 割线法
类似于牛顿法，但近似导数：
x_{n+1} = x_n − f(x_n) · (x_n − x_{n-1}) / (f(x_n) − f(x_{n-1}))
|物业 |价值|
|----------|--------|
|收敛|超线性（阶数 ≈ 1.618，黄金比例）|
|需要|两个初步猜测（无需导数）|
### 求根方法比较
|方法|收敛|需要衍生品吗？ |有保证吗？ |每步成本|
|--------|-------------|--------------------|-------------|----------------|
|二分|线性 (1) |没有 |是的 | 1 函数评估 |
|牛顿-拉夫森|二次 (2) |是的 |没有 | 2 函数评估 |
|割线|超线性 (1.618) |没有 |没有 | 1 函数评估 |
|布伦特法|超线性|没有 |是的 |变化 |
**布伦特方法** 将二分法（保证收敛）与割线/逆二次插值（快速收敛）相结合。它是大多数数值库中默认的根查找器。

## 数值积分（求积）
近似计算 ∫ₐᵇ f(x) dx。
＃＃＃ 方法
|方法|公式|错误|订单|
|--------|---------|--------|--------|
| **矩形（中点）** | (b−a) · f((a+b)/2) | (b−a) · f((a+b)/2) | O(h²) | 1 |
| **梯形** | (b−a)/2 · [f(a) + f(b)] | (b−a)/2 · [f(a) + f(b)] | O(h²) | 2 |
| **辛普森的 1/3** | (b−a)/6 · [f(a) + 4f(m) + f(b)] | (b−a)/6 · [f(a) + 4f(m) + f(b)] | O(h⁴) | 3 |
| **辛普森 3/8** |使用 4 个等距点 | O(h⁴) | 4 |
| **高斯求积** |最佳节点放置 | O(h²ⁿ) | n 点 |
### 复合规则
对于宽度为 h = (b−a)/n 的 n 个子区间：
|规则|复合配方|错误|
|------|--------------------|--------|
|复合梯形| h[f(a)/2 + Σf(xᵢ) + f(b)/2] | h[f(a)/2 + Σf(xᵢ) + f(b)/2] O(h²) |
|复合辛普森 | h/3[f(a) + 4Σf(奇数) + 2Σf(偶数) + f(b)] | O(h⁴) |
**工作示例：** 使用 n = 4 的复合梯形近似 ∫₀1 e^(−x²) dx。
- h = 0.25，点数：0、0.25、0.5、0.75、1
- f(0) = 1、f(0.25) = 0.9394、f(0.5) = 0.7788、f(0.75) = 0.5698、f(1) = 0.3679
- T = 0.25[1/2 + 0.9394 + 0.7788 + 0.5698 + 0.3679/2] = 0.25[1/2 + 2.2880 + 0.1840] = 0.7430
- 真实值： ≈ 0.7468（误差 ≈ 0.5%）
### 自适应正交
自动细分函数快速变化的区间，在平滑的情况下使用较少的点。这就是`scipy.integrate.quad`使用的（基于 QUADPACK）。

## 插值
估计已知数据点之间的值。
＃＃＃ 方法
|方法|描述 |光滑度|振荡|
|--------|-------------|------------|------------|
| **最近的邻居** |使用最近的数据点 |不连续 |无 |
| **线性** |用直线连接点 | C⁰（连续）|无 |
| **多项式（拉格朗日）** |通过所有点的单多项式 | C^∞|许多点都严重（龙格现象）|
| **三次样条** |分段立方，接缝处光滑 | C² |最小 |
| **径向基函数** |径向核的加权和 |取决于内核 |低|
### 拉格朗日插值
给定 n+1 个点 (x₀, y₀), ..., (xₙ, yₙ)，通过所有点的唯一次数 ≤ n 多项式：
P(x) = Σᵢ₌₀ⁿ yᵢ · Πⱼ≠ᵢ (x − xⱼ) / (xᵢ − xⱼ)
**龙格现象：** 等距点处的高次多项式插值可能会在边缘附近剧烈振荡。通过使用切比雪夫节点或样条线可以缓解。
### 三次样条
C² 连续的分段三次多项式（连续二阶导数）。
|类型 |边界条件|
|------|--------------------|
|自然样条| S''(x₀) = S''(xₙ) = 0 |
|夹紧花键| S'(x₀) 和 S'(xₙ) 指定 |
|不结|在 x₁ 和 xₙ₋₁ 处连续的三阶导数 |

## ODE 求解器
以数值方式求解常微分方程 dy/dt = f(t, y)。
### 欧拉方法
最简单的 ODE 求解器。
**更新：** y_{n+1} = y_n + h · f(t_n, y_n)
|物业 |价值|
|----------|--------|
|订单| 1（每步错误：O(h²)，全局：O(h)）|
|稳定性|有条件稳定（需要小 h）|
|成本|每步 1 次函数评估 |
### 龙格-库塔方法
|方法|订单|阶段 |笔记|
|--------|--------|--------|--------|
| **欧拉** | 1 | 1 |最简单|
| **中点** | 2 | 2 |更高的准确性 |
| **赫恩 (RK2)** | 2 | 2 |预测校正器 |
| **经典RK4** | 4 | 4 |标准主力 |
| **多蒙王子 (RK45)** | 4(5) | 4(5) | 6 |自适应步长（ode45中使用）|
### 经典 RK4（4 阶龙格-库塔）
k₁ = f(t_n, y_n)
k2 = f(t_n + h/2, y_n + hk₁/2)
k₃ = f(t_n + h/2, y_n + hk2/2)
k₄ = f(t_n + h, y_n + hk₃)
y_{n+1} = y_n + h(k₁ + 2k2 + 2k₃ + k₄) / 6
|物业 |价值|
|----------|--------|
|订单| 4（全局误差：O(h⁴)）|
|成本|每步 4 次功能评估 |
|稳定性|比欧拉好得多|
|用途 |非刚性 ODE 的默认值 |
### 刚性 ODE
**刚性** ODE 的组成部分在不同的时间尺度上变化很大。显式方法（Euler、RK4）需要不切实际的小步长。
|方法|类型 |稳定性|
|--------|------|------------|
|隐式欧拉|隐式| A-稳定（无条件稳定）|
|后向微分公式（BDF）|隐式| A-稳定（最多 5 阶）|
|隐式龙格-库塔|隐式|存在 L-稳定变体 |
| LSODA |自动|在刚性/非刚性之间切换 |

## 数值稳定性和调节
### 条件号
**条件数**衡量问题的输出相对于输入的微小变化有多少变化。
对于线性系统 Ax = b： κ(A) = ||A|| · ||A⁻1||
| κ(A)|解读|
|--------|----------------|
| ≈ 1 |条件优越 |
| 10立方|轻度敏感|
| 10⁸ |病态（损失约 8 位精度）|
| → 无穷大 |奇异（无唯一解） |
### 算法的稳定性
如果输入中的小扰动导致输出中的小扰动（相对于问题的条件数），则算法是**数值稳定的**。
|算法|稳定的？ |笔记|
|------------|---------|--------|
|部分旋转的高斯消去法 |是的 |标准方法 |
|通过 QR 计算特征值 |是的 |向后稳定|
|朴素求和（先大+小）|没有 |使用卡汉求和 |
|计算方差为 E[X²] − (E[X])² |可能没有 |使用 Welford 的在线算法 |
### 韦尔福德在线算法
运行均值和方差的数值稳定计算：
```
mean_new = mean_old + (x − mean_old) / n
M2_new = M2_old + (x − mean_old)(x − mean_new)
variance = M2 / (n − 1)
```

这避免了在简单的两次传递公式中发生的灾难性抵消。

|稳定求和|计算损失函数、批量归一化统计 |
| RK4 / 自适应求解器 |模拟动力系统，训练连续深度网络 |

|稳定性|对舍入误差的敏感性 |条件数，算法稳定|
数值方法是数学与现实的结合。没有计算机可以准确地表示大多数实数，在实践中没有符号计算导数，也没有针对现实世界问题以封闭形式计算积分。了解数值方法可以让您选择正确的算法，预测其准确性，并避免有限精度算术产生的细微错误。
