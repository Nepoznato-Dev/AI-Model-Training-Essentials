# 图论
**图**是由通过边（链接）连接的顶点（节点）组成的数学结构。图模型关系：社交网络、路线图、神经网络、依赖关系、沟通渠道。图论——对这些结构的研究——提供了计算机科学、运筹学和数据科学的核心算法和定理。
---

## 基本概念
### 定义
|术语 |定义 |符号|
|------|------------|----------|
| **图表** |一对 G = (V, E) 顶点和边 | G |
| **顶点（节点）** | V 的一个元素 | v、u、w |
| **边缘** |两个顶点之间的连接 | e = (u, v) 或 {u, v} |
| **订单** |顶点数 | \|V\| = n |
| **尺寸** |边数 | \|E\| =米|
| **学位** |与顶点相关的边数 |度(v) |
| **路径** |由边连接的不同顶点的序列 | v₁、v2、...、vₖ |
| **循环** |起始和结束于同一顶点的路径 | v₁ → v2 → ... → vₖ → v₁ |
| **已连接** |每对顶点之间都存在一条路径 | — |
| **组件** |最大连通子图 | — |
| **子图** |由 V 和 E 的子集形成的图 | H ⊆ G |
### 图的类型
|类型 |描述 |示例|
|------|-------------|---------|
| **无指导** |边缘没有方向 |友情网|
| **定向（有向图）** |边缘有方向（弧线） |网页链接|
| **加权** |边带有数值 |道路距离|
| **未加权** |所有边都是等价的 |社会关系 |
| **简单** |没有循环，没有多重边缘 |大多数教科书图表|
| **多重图** |允许相同顶点之间存在多条边 |飞行路线（城市之间的多个航班）|
| **完成** |每对顶点都是相连的 | Kₙ 有 n(n−1)/2 条边 |
| **双方** |顶点分为两组；边缘仅交叉组 |用户-项目推荐矩阵 |
| **平面** |可以无边交叉地绘制 |电路板布局|
| **树** |连通的非循环图 |决策树、文件系统 |
| **DAG** |有向循环、无向循环 |任务调度、依赖图|
### 握手引理
所有顶点度数的总和等于边数的两倍：
Σᵥ deg(v) = 2|E|
**推论：** 每个图都有偶数个奇数度顶点。
**示例：** 在 10 人聚会中，每个人都与另外 3 个人握手：Σ deg = 30，因此 |E| = 总共 15 次握手。

## 图形表示
在内存中存储图表的方式决定了在其上运行的每个算法的效率。
|代表|空间|边缘查找 |迭代邻居|最适合 |
|----------------|---------|-------------|--------------------|----------|
| **邻接矩阵** | O(n²) | O(1) | O(1) | O(n) |密集图形，快速边缘测试 |
| **邻接列表** | O(n + m) | O(度(v)) | O(度(v)) |稀疏图，最真实的网络 |
| **边缘列表** | O(米) | O(米) | O(米) |简单的算法，Kruskal 的 MST |
| **关联矩阵** | O(n·m) | O(米) | O(米) |专业算法|
### 邻接矩阵
n × n 矩阵 A，其中如果边 (i,j) 存在，则 A[i][j] = 1，否则为 0。对于加权图，A[i][j] = 权重。
**特性：**
- 无向图对称
- Aᵏ[i][j] = 从 i 到 j 长度为 k 的行走次数
- A 的特征值揭示了结构特性（参见谱图理论）
### 邻接表
一个数组（或哈希图），其中每个顶点 v 存储其邻居的列表。
```
Vertex 0: [1, 3]
Vertex 1: [0, 2, 3]
Vertex 2: [1, 3]
Vertex 3: [0, 1, 2]
```

这是现实世界图最常见的表示形式，通常是稀疏的 (m ≪ n²)。

## 树
**树**是一个连通的、非循环的无向图。 **森林**是树木的不相交联合体。
### 树的属性
对于有 n 个顶点的树：
- 它恰好有 n − 1 条边
- 任意两个顶点之间只有一条路径
- 移除任何边缘会断开连接
- 添加任何边都会创建一个循环
### 树木的类型
|类型 |描述 |应用 |
|------|-------------|-------------|
| **树根** |指定一个顶点为根|文件系统、组织结构图|
| **二叉树** |每个节点最多有 2 个子节点 | BST、表达式解析、决策树 |
| **平衡树** |高度为 O(log n) | AVL 树、红黑树（数据库）|
| **生成树** |包含所有顶点且是树的子图 |网络设计、近似算法|
| **最小生成树** |具有最小总边权的生成树 |网络设计、集群|
| **星图** |一个中心节点连接到所有其他节点 |中心辐射型网络 |
### 二叉树属性
|物业 |公式|
|----------|---------|
|深度 d 处的最大节点 | 2ᵈ |
|高度为 h 的树中的最大节点 | 2ʰ⁺1 − 1 |
| n 个节点的最小高度 | ⌊log2(n)⌋ |
|完全二叉树中的叶节点 |内部节点 + 1 |
### 树遍历
|遍历|订单|使用案例|
|------------|--------|----------|
| **预购** |根→左→右|复制树，前缀表达式 |
| **按顺序** |左→根→右| BST 的排序输出 |
| **订购后** |左→右→根|删除树，后缀表达式 |
| **水平顺序（BFS）** |从左到右逐级|未加权树中的最短路径|

## 图遍历
遍历算法系统地访问每个可到达的顶点。
### 广度优先搜索（BFS）
使用**队列**逐层探索顶点。
|物业 |价值|
|----------|--------|
|数据结构|队列（先进先出）|
|时间复杂度| O(V + E) |
|空间复杂度| O(V) |
|找到最短路径？ |是（未加权图表）|
|完全的？ |是（探索所有可到达的顶点）|
**算法：**
1. 从源顶点 s 开始。马克来访过。入队 s.
2. 当队列不为空时：将顶点u出队。对于 u 的每个未访问的邻居 v：标记 v 已访问，将 v 入队。
**应用：**未加权图中的最短路径、连接组件、二分测试、网络爬行。
### 深度优先搜索（DFS）
在回溯之前使用**堆栈**（或递归）尽可能深入地探索。
|物业 |价值|
|----------|--------|
|数据结构|堆栈（后进先出）/递归 |
|时间复杂度| O(V + E) |
|空间复杂度| O(V) |
|找到最短路径？ |没有 |
|完全的？ |是（对于有限图）|
**算法：**
1. 从顶点 s 开始。马克来访过。
2. 对于 s 的每个未访问的邻居 v：从 v 递归地进行 DFS。
**DFS将边分类为：**
- **树边：** DFS 树的一部分
- **后边：** 将顶点连接到其祖先（表示循环）
- **前向边：** 将顶点连接到其后代
- **交叉边：**连接不同分支中的顶点
**应用：**拓扑排序、循环检测、强连通分量、求解迷宫。
### BFS 与 DFS 比较
|标准| BFS |免税店 |
|------------|-----|-----|
|战略|宽而深|深而宽|
|内存|更高（商店前沿）|下层（存储路径）|
|最短路径（未加权）|保证|不保证 |
|当溶液即将开始时使用 |更好 |更糟|
|当图形很深时使用 |更糟|更好 |
|拓扑排序|卡恩算法变体 |标准方法 |

## 最短路径算法
寻找顶点之间的最短路径是最实际重要的图问题之一。
### Dijkstra 算法
查找图中从单个源到具有**非负**边权重的所有其他顶点的最短路径。
|物业 |价值|
|----------|--------|
|边缘权重|必须 ≥ 0 |
|时间（二进制堆）| O((V + E) log V) |
|时间（斐波那契堆）| O(E + V log V) | O(E + V log V) |
|贪婪的？ |是的 |
|处理负权重？ |没有 |
**算法：**
1. 对于所有 v ≠ s，初始化 dist[s] = 0，dist[v] = ∞。具有所有顶点的优先级队列 Q。
2. 当Q不为空时：提取距离最小的顶点u。对于 u 的每个具有边权重 w 的邻居 v：如果 dist[u] + w < dist[v]，则更新 dist[v] = dist[u] + w。
**工作示例：**```
Graph: A --1-- B --2-- C --1-- D
       A --4-- C
       B --1-- D

Shortest paths from A:
A → B: 1 (direct)
A → D: 2 (A→B→D)
A → C: 3 (A→B→C, NOT A→C=4)
```

### 贝尔曼-福特算法
处理**负**边缘权重并检测负循环。
|物业 |价值|
|----------|--------|
|边缘权重|任意（检测负循环）|
|时间复杂度| O(V·E) |
|空间复杂度| O(V) |
|处理负循环？ |是（检测并报告）|
**算法：**
1. 对于所有 v ≠ s，初始化 dist[s] = 0，dist[v] = ∞。
2. 重复 V − 1 次：对于权重为 w 的每条边 (u, v)：如果 dist[u] + w < dist[v]，则更新 dist[v]。
3. 检查负循环：如果任何边沿仍然可以松弛，则存在负循环。
### 弗洛伊德-沃歇尔算法
查找**所有对**顶点之间的最短路径。
|物业 |价值|
|----------|--------|
|时间复杂度| O(V3) |
|空间复杂度| O(V²) |
|处理负权重？ |是（但不是负循环）|
|方法|动态规划|
**递归：** 对于每个中间顶点 k，dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。
### 算法选择指南
|场景|算法|
|----------|------------|
|单一来源、非负权重 |迪杰斯特拉 |
|单一来源，可能负权重 |贝尔曼-福特 |
|所有对，密集图 |弗洛伊德·沃歇尔 |
|所有对，稀疏图 |从每个顶点运行 Dijkstra |
|未加权图 | BFS |
| DAG（无循环）|拓扑排序+松弛|
| A*（启发式引导）| A* 搜索（用于具有良好启发式的寻路）|

## 最小生成树
**最小生成树 (MST)** 以最小总边权重连接所有顶点。
＃＃＃ 特性
- MST 恰好有 n − 1 条边（对于 n 个顶点）
- 如果图已连接，则存在 MST
- 具有不同边权重的图具有唯一的 MST
- MST满足**割属性**：穿过任何割的最小权重边属于MST
- MST满足**循环属性**：任何循环中的最大权重边不属于MST
### 克鲁斯卡尔算法
|物业 |价值|
|----------|--------|
|战略|贪婪 - 按权重顺序添加边 |
|数据结构|不相交集（并集查找）|
|时间复杂度| O(E 日志 E) |
|最适合 |稀疏图|
**算法：**
1. 按权重对所有边进行排序。
2. 对于每条边（按顺序）：如果添加它不会创建循环（使用 union-find 检查），则将其添加到 MST。
3. 当选择了 n − 1 条边时停止。
### Prim 算法
|物业 |价值|
|----------|--------|
|战略|贪婪 — 从起始顶点开始生长树 |
|数据结构|优先级队列（最小堆）|
|时间复杂度| O(E log V) 与二叉堆 |
|最适合 |密集图|
**算法：**
1. 从任意顶点开始。将其标记为 MST 的一部分。
2. 重复添加连接 MST 中的顶点与其外部顶点的最小权重边。
3. 当所有顶点都包含在内时停止。
### MST 应用
|应用 | MST 如何提供帮助 |
|------------|----------------|
|网络设计|铺设最少的电缆/管道来连接所有位置 |
|聚类|删除 k − 1 条最长的 MST 边以获得 k 个簇 |
|近似算法|公制 TSP 的 2 近似 |
|图像分割|按颜色相似度的 MST 对像素进行分组 |
|特征消除 |使用相关图的MST去除冗余特征|

## 网络流量
网络流问题对系统中资源的移动进行建模。
### 流网络定义
**流网络**是一个有向图，其中：
- **源**顶点 s （产生流）
- A **sink** 顶点 t （消耗流量）
- **容量** 每条边上的 c(u,v) ≥ 0
- **流程** f(u,v) 满足：
  - **容量约束：** 0 ≤ f(u,v) ≤ c(u,v)
  - **流守恒：** 流入 = 除 s 和 t 之外的每个顶点流出
### 最大流量问题
求从 s 到 t 的最大总流量。
**福特-富尔克森方法：**
1. 虽然残差图中存在从 s 到 t 的增广路径：
2. 找出路径上的瓶颈容量
3. 按瓶颈量增加沿路径的流量
4. 更新剩余容量
|算法|时间复杂度|笔记|
|------------|----------------|--------|
|福特-富尔克森 (DFS) | O(m·f*) 其中 f* 是最大流量 |不得以非理性能力终止 |
|埃德蒙兹-卡普 (BFS) | O(V·E²) |总是终止，选择最短增广路径 |
| Dinic 算法 | O(V²·E) |使用阻塞流；单位容量为 O(V^(1/2) · E) |
### 最大流最小割定理
从 s 到 t 的**最大流量**等于将 s 与 t 分开的**最小切割**容量。
**割** (S, T) 将顶点划分为 S（包含 s）和 T（包含 t）。切割能力是从S到T的边的能力之和。
**最大流量的应用：**
- 双向匹配（将工人分配给工作）
- 图像分割（将前景与背景分开）
- 棒球淘汰赛（X 队还能获胜吗？）
- 网络可靠性（最大数据吞吐量）
### 通过最大流进行二分匹配
给定二部图 G = (L ∪ R, E)：
1.将有边的source添加到L中的所有顶点（容量1）
2. 添加带有来自R中所有顶点的边的sink t（容量1）
3. 将所有原始边容量设置为1
4、最大流量=最大匹配

## 谱图论
谱图理论通过与图相关的矩阵的特征值和特征向量来研究图。
### 关键矩阵
|矩阵|定义 |它捕获了什么 |
|--------|------------|--------------------|
| **邻接矩阵** A |如果边 (i,j) 存在，则 A[i][j] = 1 |连接模式|
| **度矩阵** D |对角线; D[i][i] = 度(i) |按程度划分的顶点重要性 |
| **拉普拉斯** L = D − A | L[i][j] = −1 如果边缘，deg(i) 在对角线上 |图形上函数的平滑度 |
| **归一化拉普拉斯** L_norm = D^(−1/2) L D^(−1/2) |尺度不变版本 |社区结构|
### 拉普拉斯算子的特征值
拉普拉斯 L 是半正定的，因此所有特征值都 ≥ 0。
| Eigenvalue |意义|
|------------|---------|
| λ₁ = 0 | Always zero; eigenvector is the constant vector |
| λ₂ (algebraic connectivity) | > 0 iff graph is connected; larger = better connected |
| Number of zero eigenvalues | Equals number of connected components |
| λₙ | Related to maximum degree and graph expansion |
### 光谱方法的应用
|应用 |方法|
|-------------|--------|
| **图划分** |使用 L 的特征向量将图分成平衡部分 |
| **社区检测** |谱聚类：使用底部特征向量嵌入顶点，然后聚类 |
| **页面排名** |网络图的邻接矩阵（或转移矩阵）的特征向量 |
| **图表绘制** |使用拉普拉斯特征向量定位顶点 |
| **半监督学习** |使用图拉普拉斯传播标签（标签传播）|
| **图神经网络** |谱卷积：使用 L 的特征向量过滤图上的信号 |
### 奇格不等式
将第二个特征值 λ2 与图的 **展开** 相关联（它的连接程度）：
λ2 / 2 ≤ h(G) ≤ √(2λ2)
其中 h(G) 是 Cheeger 常数（等周数）。这意味着 λ2 大约衡量将图切成两部分的难度 - 这是聚类的一个关键见解。
