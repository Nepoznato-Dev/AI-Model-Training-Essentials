# 随机过程
**随机过程**是按时间（或空间）索引的随机变量的集合。概率论研究单个随机事件，而随机过程研究随机性如何随时间演变。他们对股票价格、队列长度、疾病传播、语言生成以及机器学习模型的训练动态进行建模。
---

## 基础
＃＃＃ 定义
随机过程 {X_t : t ∈ T} 是在公共概率空间上定义的一系列随机变量。 T 是**索引集**（时间）：
- **离散时间：** T = {0, 1, 2, ...}
- **连续时间：** T = [0, ∞)
**状态空间** S 是 X_t 可以取的可能值的集合。
### 关键属性
|物业 |定义 |
|----------|------------|
| **平稳性** | (X_{t₁}, ..., X_{tₖ}) 的联合分布与 (X_{t₁+τ}, ..., X_{tₖ+τ}) 相同 |
| **独立** |对于 t ≠ s，X_t 独立于 X_s |
| **遍历性** |时间平均值收敛于整体平均值 |
| **马尔可夫性质** |未来只取决于现在，而不取决于过去 |
| **鞅** |预期未来值等于当前值 |
---

## 马尔可夫链
**马尔可夫链**是一个随机过程，其中未来状态仅取决于当前状态（无记忆属性）。
### 离散时间马尔可夫链 (DTMC)
P(X_{n+1} = j | X_n = i, X_{n-1} = i_{n-1}, ...) = P(X_{n+1} = j | X_n = i) = p_{ij}
**转移矩阵** P 具有条目 p_{ij} = P(转到 j | 当前位于 i)。
|物业 |声明|
|----------|------------|
|行总和|每行总和为 1： Σⱼ p_{ij} = 1 |
| n 步过渡​​ | P(X_{n+m} = j | X_m = i) = (Pⁿ)_{ij} |
|固定式配送| πP = π（特征值为 1 的左特征向量）|
### 国家分类
|术语 |定义 |
|------|------------|
| **经常性** |链以概率 1 返回到状态 i |
| **瞬态** |永不返回的非零概率 |
| **吸收** | p_{ii} = 1（一旦进入，永不离开）|
| **期间** |返回时间的 GCD；周期 1 = 非周期 |
| **沟通**​​ |状态 i 和 j 可以互相到达 |
### 固定分布
对于不可约的正循环马尔可夫链，平稳分布 π 存在且唯一，并且满足：
πP = π, Σᵢ πᵢ = 1
**解释：** πᵢ = 处于状态 i 的长期时间比例。
**工作示例：**状态为{晴天、雨天}的天气模型。
P = [[0.9, 0.1], [0.5, 0.5]]（行：来自晴天，来自雨天）
平稳分布： πP = π
- π₁=0.9π₁+0.5π2
- π2 = 0.1π₁ + 0.5π2
- π₁ + π2 = 1
- 求解： π₁ = 5/6 ≈ 0.833, πϒ = 1/6 ≈ 0.167
### 收敛到平稳性
对于不可约、非周期、正循环链：
- Pⁿ → Π（所有行都等于 π 的矩阵）作为 n → Infini
- **混合时间：** 分布接近 π 之前的步骤数
- **光谱间隙：** 1 − |λ2| （其中 λ2 是第二大特征值）决定混合速度
### 连续时间马尔可夫链 (CTMC)
转变发生在受指数分布支配的随机时间。
|概念 |描述 |
|---------|-------------|
| **速率矩阵Q** | q_{ij} ≥ 0（i ≠ j）； q_{ii} = −Σ_{j≠i} q_{ij} |
| **转移概率** | P(t) = e^{Qt}（矩阵指数）|
| **固定分布** | πQ = 0 |
| **保持时间** |状态 i 的时间为 Exp(−q_{ii}) |

## 随机游走
**随机游走**是由连续的随机步骤形成的路径。
### 简单随机游走
X_n = X_{n-1} + Z_n，其中 Z_n ∈ {+1, −1}，概率为 p，q = 1−p。
|物业 | p = 1/2（对称）| p ≠ 1/2（有偏差）|
|----------|---------------------|--------------------|
| E[X_n] | 0 | n(2p−1) | n(2p−1) | n(2p−1) | n(2p−1)
|变量[X_n] | n | 4npq |
|返回原点？ |是（概率为 1）|不（渐行渐远）|
|反复发作？ |是（一维和二维）|没有 |
### 高维随机游走
|尺寸|反复发作？ |直觉|
|------------|------------|------------|
|一维 |是的 | “醉酒的人总能找到回家的路”|
| 2D |是的 | “醉鸟总能找到回家的路”|
| 3D+ |没有 | “喝醉的麻雀永远找不到回家的路” |
### 与布朗运动的联系
缩放随机游走：令 S_n = ΣZ_i。然后步长 → 0 且步长 → ∞：
S_{⌊nt⌋} / √n → B(t) （布朗运动，根据 Donsker 定理）
---

## 布朗运动
**布朗运动**（维纳过程）B(t) 是随机游走的连续时间限制。
＃＃＃ 定义
B(t) 满足：
1. B(0) = 0
2. B(t) 具有连续路径
3. 独立增量：B(t) − B(s) 独立于 B(s) − B(r)，且 r < s < t
4. B(t) − B(s) ~ N(0, t − s) （高斯增量）
### 关键属性
|物业 |声明|
|----------|------------|
| E[B(t)] | = 0 |
|变量[B(t)] | = t |
| Cov[B(s), B(t)] | Cov[B(s), B(t)] | = 分钟（s，t）|
|无处可微 |路径是连续的但没有导数 |
|分形维数 |图的 Hausdorff 维数为 3/2 |
|马尔可夫性质 |未来仅取决于当前位置 |
|鞅| E[B(t) | F_s] = B(s) 对于 s < t |
### 几何布朗运动
S(t) = S(0) exp((μ − σ²/2)t + σB(t))
这是布莱克-斯科尔斯框架中股票价格的标准模型。
- μ：漂移（预期回报）
- σ：波动性
---

## 泊松过程
**泊松过程** N(t) 计算 [0, t] 中发生的事件数。
＃＃＃ 定义
N(t) ~ Poisson(λt)，其中 λ 是速率（每单位时间的事件）。
|物业 |声明|
|----------|------------|
| N(0) = 0 | N(0) = 0 — |
|独立增量|不相交区间内的事件是独立的 |
|固定增量| N(t+s) − N(s) ~ 泊松(λt) |
| E[N(t)] | = λt |
|变量[N(t)] | = λt |
|到达间隔时间 |指数分布：T_i ~ Exp(λ) |
### 概括
|变体 |描述 |
|---------|-------------|
| **非同质** |速率 λ(t) 随时间变化 |
| **复合泊松** |每个事件都有一个随机大小：S(t) = Σᵢ₌₁^{N(t)} Yᵢ |
| **泊松随机测量** |时空点，而不仅仅是时间|
| **多元** |具有可能交互的多种事件类型 |
---

## 鞅
**鞅**是一个公平的游戏：在给定所有当前信息的情况下，预期未来价值等于当前价值。
＃＃＃ 定义
{X_n} 是关于过滤 {F_n} 的鞅，如果：
1. X_n 是 F_n 可测量的（已调整）
2. E[|X_n|] < ∞（可积）
3.E[X_{n+1}|E[X_{n+1}] F_n] = X_n（公平游戏）
|变体 |状况 |解读|
|--------|---------|----------------|
| **鞅** | E[X_{n+1} | F_n] = X_n |公平游戏|
| **下鞅** | E[X_{n+1} | F_n] ≥ X_n |好游戏（热度上升）|
| **超级鞅** | E[X_{n+1} | F_n] ≤ X_n |不利的游戏（趋势下降） |
### 关键定理
|定理|声明|
|--------|------------|
| **可选停止** |在一定条件下，E[X_T] = E[X_0]，停止时间为 T |
| **收敛** |有界鞅几乎肯定收敛 |
| **最大不平等** | P(max_{k≤n} X_k ≥ λ) ≤ E[X_n] / λ (Doob 的) |
---

## 蒙特卡罗方法
**蒙特卡罗方法**使用随机抽样来估计确定性数量。
### 基本思想
估计 E[f(X)]，其中 X ~ P：
1. 从P中抽取N个样本：x₁, x2, ..., x_N
2. 计算： Î = (1/N) Σᵢ f(xᵢ)
3. 根据大数定律： Î → E[f(X)] as N → ∞
**误差：** 标准误差 = σ_f / √N，其中 σ_f² = Var[f(X)]
### 方差减少技术
|技术|想法 |加速|
|------------|------|---------|
| **重要性抽样** |从 Q 而不是 P 采样，按 P/Q 加权 |可以是戏剧性的|
| **对立变量** |使用 (x, −x) 对消除方差 | 〜2x |
| **控制变量** |减去与 f | 相关的已知期望函数变化 |
| **分层抽样** |划分域，对各层进行采样 |减少方差 |
| **拉奥-布莱克威尔** |条件是有足够的统计数据|总是有帮助 |
---

## 马尔可夫链蒙特卡罗 (MCMC)
MCMC构造一个马尔可夫链，其平稳分布是目标分布。经过“老化”期后，样本近似于目标值。
### Metropolis-Hastings 算法
|步骤|行动|
|------|--------|
| 1 |当前状态：x_t |
| 2 |提议：x* ~ q(x* \| x_t) （提议分布） |
| 3 |接受率： α = min(1, [π(x*)q(x_t\|x*)] / [π(x_t)q(x*\|x_t)]) |
| 4 |以概率 α 接受：x_{t+1} = x*（接受）或 x_t（拒绝）|
**特殊情况 - Metropolis 算法：** 对称提议 q(x*|x) = q(x|x*)，因此 α = min(1, π(x*)/π(x_t))。
### 吉布斯采样
Metropolis-Hastings 的一个特例，其中每个变量都根据其完整条件分布进行更新。
对于目标 π(x₁, x2, ..., xₖ)：
1. 样本 x₁^{(t+1)} ~ π(x₁ | x2^{(t)}, ..., xₖ^{(t)})
2. 样本 x2^{(t+1)} ~ π(x2 | x₁^{(t+1)}, x₃^{(t)}, ..., xₖ^{(t)})
3. 继续处理所有变量
4. 重复
|物业 |声明|
|----------|------------|
|始终接受 | α = 1（无拒绝步骤）|
|需要|能够从每个完整的条件中进行采样 |
|收敛|保证不可约的非周期链 |
### MCMC 诊断
|诊断|目的|
|------------|---------|
| **跟踪图** |目视检查混合和平稳性 |
| **自相关** |测量样本依赖性（需要低自相关）|
| **格尔曼-鲁宾 (R̂)** |比较多个链； R̂ < 1.05 表明收敛 |
| **有效样本量** | N_eff = N / (1 + 2Σρₖ);考虑自相关|
| **老化** |在链达到静止之前丢弃初始样本 |

## 与机器学习和数据科学的相关性
|随机过程|应用 |
|--------------------|-------------|
|马尔可夫链| PageRank（网络图上的随机游走）、文本生成（n-gram 模型）、MCMC |
|随机游走 | Node2Vec 和 DeepWalk（图嵌入），强化学习中的探索 |
|布朗运动|生成人工智能中的股票价格建模、扩散模型 |
|泊松过程|事件到达建模（点击、失败）、排队理论 |
|鞅|金融数学，证明SGD的收敛性（随机近似）|
|蒙特卡洛 |估计期望值、贝叶斯推理、强化学习（策略评估）|
| MCMC（大都会-黑斯廷斯）|贝叶斯后验采样，概率编程（Stan，PyMC）|
|吉布斯采样|主题模型（LDA）、贝叶斯网络、图像去噪 |
| MCMC 诊断 |确保概率模型的可靠推理 |

|---------|-------------|------|-------------|

随机过程是随时间变化的随机性的数学。它们支撑现代贝叶斯推理 (MCMC)、强化学习（马尔可夫决策过程）、生成模型（扩散模型）、金融数学和排队论。了解这些过程为您提供了动态建模不确定性的工具 - 不仅仅是作为快照，而是随着它的发展。
