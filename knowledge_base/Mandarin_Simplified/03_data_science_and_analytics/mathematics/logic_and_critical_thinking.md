# 逻辑和批判性思维
逻辑是对有效推理的研究——如何构建合理的论证并识别有缺陷的论证。批判性思维是质疑假设、评估证据和仔细推理的纪律习惯。这些技能不仅在数学和计算机科学中至关重要，而且在日常决策、科学研究和驾驭信息丰富的世界中也至关重要。
---

## 什么是论证？
在逻辑中，**论证**是一组旨在支持结论的陈述（前提）。
|组件|角色 |示例|
|------------|------|---------|
| **前提** |作为证据的声明 | “所有人都会死” |
| **结论** |场地支持的主张| “苏格拉底终有一死”|
| **推论** |从前提到结论的逻辑步骤| “苏格拉底是人，因此……” |
### 有效与合理
|术语 |意义|示例|
|------|---------|---------|
| **有效** |如果前提为真，则结论必定为真 |即使前提是错误的，结构也是正确的 |
| **无效** |结论不是从前提得出的 |逻辑结构被打破|
| **声音** |有效并且所有前提实际上都是正确的 |论证的黄金标准|
| **不健全** |无效或有虚假前提 |最有缺陷的论点|

## 推理类型
|类型 |方向 |实力|示例|
|------|---------|----------|------|
| **演绎** |一般→具体|某些（如果有效）| “所有哺乳动物都有肺。鲸鱼是哺乳动物。因此，鲸鱼有肺。” |
| **感应式** |具体→一般|可能 | “我见过的每一只天鹅都是白色的。因此，所有的天鹅可能都是白色的。” |
| **溯因** |观察→最佳解释|似是而非的| “草湿了，最好的解释就是下雨了。” |

## 命题逻辑
命题逻辑处理简单的命题以及它们如何组合：
### 逻辑连接词
|连接词|符号|意义|真实条件 |
|------------|--------|---------|----------------|
| **和** | ∧ (p ∧ q) |连词|仅当两者都为真时才为真 |
| **或** | ∨ (p ∨ q) |析取 |当至少有一个为真时为真 |
| **不** | ← (←p) |否定|相反的真值 |
| **如果...那么** | → (p → q) |寓意 |仅当 p 为真且 q 为假时才为假 |
| **国际金融论坛** | ↔ (p ↔ q) |双条件|当两者具有相同的真值时为真 |
### 蕴涵真值表 (p → q)
| p|问 | p → q |
|---|---|-------|
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |
注意：错误的前提使得暗示空洞地真实。 “如果月亮是奶酪，那么我就是教皇”在逻辑上是正确的。

## 布尔代数
布尔代数是真/假值的数学，是数字电路设计和编程的基础：
|法律 |表达 |意义|
|-----|------------|---------|
| **可交换** | A ∧ B = B ∧ A |顺序并不重要 |
| **联想** | (A∧B)∧C=A∧(B∧C)|分组并不重要 |
| **分配** | A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) | AND 分布于 OR |
| **德摩根** | Ø(A ∧ B) = ØA ∨ ØB |否定将 AND 翻转为 OR |
| **德摩根** | Ø(A ∨ B) = ØA ∧ ØB |否定将 OR 翻转为 AND |
| **双重否定** | Ø(ØA) = A |两个否定取消 |
| **身份** | A∧T=A； A ∨ F = A |身份元素|
| **补充** | A ∧ ØA = F； A ∨ ØA = T |矛盾与同义反复 |

## 常见的逻辑谬误
认识谬误对于批判性思维至关重要：
### 形式谬误（结构性错误）
|谬论|结构|示例|
|--------|------------|---------|
| **确认后果** |如果 P 则 Q. Q. 因此 P. | “如果下雨，地就湿了。地湿了，所以就下雨了。” （可能是洒水器。）
| **否认前因** |如果 P 则 Q。不是 P。因此不是 Q。 “如果下雨，地就湿。没有下雨，所以地不湿。” |
### 非正式谬误（内容错误）
|谬论|描述 |示例|
|---------|-------------|---------|
| **人身攻击** |攻击人，而不是争论| “你不能相信她的经济计划——她甚至不是经济学家。” |
| **稻草人** |歪曲论点以使其更容易受到攻击 | “你想减少军费开支？所以你想让这个国家毫无防备！” |
| **向当局上诉** |引用非相关领域专家的权威人士 | “这位名人说这种饮食有效，所以它一定有效。” |
| **虚假困境** |当存在更多选项时仅提供两个选项 | “你要么支持我们，要么反对我们。” |
| **滑坡** |认为一个事件将不可避免地导致极端结果| “如果我们允许这种情况发生，接下来你就会知道，一切都会一片混乱。” |
| **循环推理** |结论是在前提下假设的 | “这本书是真的，因为它说的是真的。” |
| **仓促概括** |从证据不足得出广泛的结论| “我在那个城市遇到了两个粗鲁的人。那里的每个人都一定很粗鲁。” |
| **事后 Ergo Propter Hoc** |从时间序列假设因果关系 | “我服用了这种补充剂，感觉好多了，所以它一定有效。” |
| **红鲱鱼** |引入一个不相关的话题来分散注意力 | “你问我的教育政策，但真正重要的是经济。” |
| **跟风** |有些事是真的，因为很多人相信它 | “每个人都买这个产品，所以它一定是最好的。” |

## 评估参数：清单
|步骤|问题 |
|------|----------|
| 1. **确定结论** |论证试图证明什么？ |
| 2. **确定场所** |提供什么证据？ |
| 3. **检查有效性** |结论是从前提推导出来的吗？ |
| 4. **检查健全性** |这些前提真的是真的吗？ |
| 5. **寻找谬误** |是否存在结构或内容错误？ |
| 6. **考虑反驳** |可能会有什么反对意见？ |
| 7. **评估证据质量** |证据是否可靠、充分且相关？ |
---

## 为什么这很重要
逻辑和批判性思维是数学、计算机科学、法律和科学探究的基础。在一个充满错误信息、广告和说服性言论的世界里，严格评估论点的能力不仅仅是一种学术技能——更是一种生存技能。无论您是在调试代码、设计算法还是做出人生决策，清晰的推理都可以区分正确的判断和错误的判断。
