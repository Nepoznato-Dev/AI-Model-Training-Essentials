# 控制理论
控制理论是使系统按照您希望的方式运行的数学。从恒温器到自动驾驶仪，从机械臂到化学反应器，控制系统感知、决定并采取行动以维持所需的行为。该领域提供了用于分析稳定性、性能和鲁棒性的严格工具，这些概念已迁移到强化学习、超参数调整和自适应系统中。
---

## 基本概念
### 开环与闭环
|类型 |描述 |示例|优势 |
|------|-------------|---------|------------|
| **开环** |控制动作独立于输出|洗衣机定时器|简单，无需传感器 |
| **闭环（反馈）** |控制动作取决于输出|恒温器、巡航控制|拒绝干扰，稳健|
### 框图元素
|元素|符号|功能|
|---------|--------|----------|
| **工厂** | G(s) |被控制的系统|
| **控制器** | C(s) |计算控制动作 |
| **传感器** | H(s) |测量输出 |
| **求和点** | ⊕ |计算误差：r − y |
| **参考** | r(t) | r(t) |期望的输出|
| **错误** | e(t) = r(t) − y(t) |期望与实际之间的差异|
| **打扰** | d(t) |影响工厂的不需要的输入 |
### 闭环传递函数
对于标准负反馈系统：
T(s) = C(s)G(s) / (1 + C(s)G(s)H(s))
|数量 |公式|
|----------|---------|
|开环传递函数| L(s) = C(s)G(s)H(s) | L(s) = C(s)G(s)H(s) |
|闭环传递函数| T(s) = L(s)/H(s) / (1 + L(s)) |
|误差传递函数| E(s)/R(s) = 1 / (1 + L(s)) |
|灵敏度| S(s) = 1 / (1 + L(s)) | S(s) = 1 / (1 + L(s)) |

## 传递函数
**传递函数** H(s) = Y(s)/X(s) 描述拉普拉斯域中线性时不变 (LTI) 系统的输入输出关系。
### 标准表格
|系统|传递函数|参数|
|--------|--------------------|------------|
| **一阶** | K/(τs + 1) | K = 增益，τ = 时间常数 |
| **二阶** | Kωₙ²/(s² + 2ζωₙs + ωₙ²) | ωₙ = 固有频率，ze = 阻尼比 |
| **积分器** | K/s | — |
| **差异化因素** |凯斯 | — |
| **延迟** | e^{−sT_d} | T_d = 时间延迟 |
### 二阶系统行为
|阻尼比 ζ |行为 |杆位置 |
|-----------------|---------|----------------|
| δ = 0 |无阻尼振荡|纯属虚构|
| 0< ζ < 1 | Underdamped (oscillates, decays) | Complex with negative real part |
| ζ = 1 | Critically damped (fastest no-oscillation) | Real, repeated |
| ζ >1 |过阻尼（缓慢，无振荡）|真实、鲜明 |
### 性能指标（阶跃响应）
|公制|公式（二阶，欠阻尼）|描述 |
|--------|----------------------------------|-------------|
|上升时间 (t_r) | ≈ 1.8/ωₙ |从 10% 到 90% 的时间到了 |
|高峰时间 (t_p) | π/(ωₙ√(1−z²)) |达到第一个最大值的时间 |
|过冲 (M_p) | e^{−πz/√(1−z²)} × 100% |高于最终值的最大峰值 |
|稳定时间 (t_s) | ≈ 4/(ζωₙ) |时间与最终成绩保持在 2% 以内 |
|稳态误差|取决于系统类型 |当 t → ∞ | 时，期望值与实际值之间的差异

## PID 控制器
**PID控制器**是工业中使用最广泛的控制器（超过90%的工业控制器）。
### PID 公式
u(t) = K_p e(t) + K_i ∫₀ᵗ e(τ)dτ + K_d de(t)/dt
在拉普拉斯域中： C(s) = K_p + K_i/s + K_d s
|术语 |效果|太多了|太少了|
|------|--------|----------|------------|
| **比例 (K_p)** |对当前错误作出反应 |振荡、不稳定 |响应慢、误差大|
| **积分 (K_i)** |消除稳态误差 |过冲、振荡|持续偏移|
| **导数 (K_d)** |预测未来误差（阻尼）|噪音放大|抗干扰能力差|
### PID整定方法
|方法|方法|
|--------|----------|
| **齐格勒-尼科尔斯** |增大K_u直至振荡；使用 K_u 和周期 P_u 设置增益 |
| **科恩-库恩** |基于阶跃响应参数（增益、时​​间常数、死区时间）|
| **IMC（内模型控制）** |基于流程模型；提供良好的鲁棒性|
| **自动调整** |在线识别+调整（许多现代控制器）|
| **手册** |仅从 K_p 开始，添加 K_i 以消除偏移，添加 K_d 以实现阻尼 |
### 齐格勒-尼科尔斯规则
1.设置K_i = K_d = 0
2. 增加K_p直至持续振荡：最终增益K_u，周期P_u
3. 设置增益：
|控制器| K_p | K_i | K_d |
|------------|-----|-----|-----|
|普 | 0.5K_u | — | — |
| PI | 0.45K_u | 1.2K_u/P_u | — |
| PID| 0.6K_u | 2K_u/P_u | K_u P_u/8 |

## 稳定性分析
如果系统的输出对于有界输入保持有界（BIBO 稳定性），则系统是**稳定的**。
### 基于杆的稳定性
|状况 |稳定性|
|------------|------------|
|所有极点均位于左半平面 (Re(s)< 0) | Stable |
| Any pole in right half-plane (Re(s) >0) |不稳定|
|虚轴上的极点 (Re(s) = 0) |边缘稳定（或重复不稳定）|
### 劳斯-赫尔维茨准则
无需显式计算极点即可确定稳定性。根据特征多项式系数构造劳斯数组。
**规则：** 第一列中符号变化的数量等于右半平面极点的数量。
### 奈奎斯特稳定性准则
在复平面中绘制开环频率响应 L(jω)。
**规则：** 如果奈奎斯特图逆时针围绕点 (−1, 0) 的次数等于开环不稳定极点的数量，则闭环系统稳定。
**增益裕度：** 在不稳定之前增益可以增加多少（从绘图到实轴上 -1 的距离）。
**相位裕度：** 在不稳定之前可以增加多少相位滞后（增益交叉处从图到单位圆的角度）。
### 波特图分析
绘制增益 (dB) 和相位（度）与频率（对数刻度）的关系图。
|公制|定义 |期望值|
|--------|------------|---------------|
| **利润率（GM）** |在相位 = −180° 时增益增加至 0 dB | > 6 分贝 |
| **相位裕度 (PM)** |增益交叉时的相位 (0 dB) + 180° | > 45° |
| **获得交叉** |增益 = 0 dB 时的频率 | — |
| **相位交叉** |相位 = −180° 时的频率 | — |

## 状态空间表示
对于多输入多输出（MIMO）系统，状态空间形式比传递函数更自然。
### 标准表格
ẋ(t) = Ax(t) + Bu(t)（状态方程）
y(t) = Cx(t) + Du(t)（输出方程）
|矩阵|名称 |尺寸|
|--------|------|------------|
|一个 |系统/状态矩阵| n × n |
|乙|输入矩阵| n × 米 |
| C |输出矩阵| p × n |
| d |馈通矩阵 | p × m |
### 状态空间的传递函数
G(s) = C(sI − A)⁻1B + D
### 可控性和可观察性
|物业 |测试|意义|
|----------|------|---------|
| **可控** | Rank[C_B] = n（其中 C_B = [B, AB, A²B, ...]）|可以转向任何状态 |
| **可观察** | Rank[O_B] = n（其中 O_B = [C; CA; CA²; ...]）|可以根据输出确定状态 |
系统必须是可控制的，可通过反馈来稳定，并且可观察以进行状态估计。
### 状态反馈
u = −Kx + r（全状态反馈）
闭环：ẋ = (A − BK)x + Br
**极点位置：** 选择 K，使 A − BK 具有所需的特征值（极点）。

## 最优控制
### 线性二次调节器 (LQR)
最小化： J = ∫₀^∞ (xᵀQx + uᵀRu) dt
其中 Q ≥ 0（状态成本）且 R > 0（控制成本）。
**解：** u = −Kx 其中 K = R⁻1BᵀP，并且 P 求解 **代数 Riccati 方程：**
AᵀP + PA − PBR⁻1BᵀP + Q = 0
|调整|效果|
|--------|--------|
|增加 Q |响应更快，控制力更强 |
|增加 R |响应速度较慢，控制力度较小 |
| Q ≫ R |积极的控制（如高 K_p） |
### 卡尔曼滤波器
具有高斯噪声的线性系统的最佳状态估计器。
**系统型号：**
ẋ = Ax + Bu + w（过程噪声 w ~ N(0, Q)）
y = Cx + v（测量噪声 v ~ N(0, R)）
**卡尔曼滤波器方程：**
- 预测：x̂⁻ = Ax̂ + Bu, P⁻ = APAᵀ + Q
- 更新：K = P⁻Cᵀ(CP⁻Cᵀ + R)⁻1，x̂ = x̂⁻ + K(y − Cx̂⁻)，P = (I − KC)P⁻
卡尔曼滤波器是 LQR 对偶滤波器 — 它最大限度地减少了估计误差方差。

控制理论是让系统可靠、稳健、高效地做你想做的事的数学。事实证明，它的反馈、稳定性和最优性原则具有普遍性，出现在从机器人到强化学习、从经济学到生物学的各个领域。对于数据科学家来说，控制理论提供了理解自适应系统、设计稳定的训练程序以及构建与动态环境交互的智能代理的语言。
