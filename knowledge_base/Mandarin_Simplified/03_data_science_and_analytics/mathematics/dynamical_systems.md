# 动力系统
**动态系统**描述了状态如何根据固定规则随时间演变。从行星轨道到人口动态，从天气模式到训练神经网络，动力系统理论提供了理解事物如何变化的语言和工具。该文件涵盖常微分方程 (ODE)、偏微分方程 (PDE)、稳定性分析、混沌和分岔。
---

## 常微分方程 (ODE)
ODE 将函数与其相对于单个自变量（通常是时间）的导数联系起来。
＃＃＃ 分类
|物业 |类型 |
|----------|--------|
| **订单** |存在的最高导数（一阶、二阶等）|
| **线性与非线性** |线性：y'' + p(t)y' + q(t)y = g(t)；非线性：其他任何东西|
| **同质** | g(t) = 0（无强迫项）|
| **自主** |无明确的时间依赖性：dy/dt = f(y) |
| **常数系数** | p、q 是常数 |
### 一阶常微分方程
**一般形式：** dy/dt = f(t, y)
|类型 |表格 |解决方法|
|------|------|-----------------|
|可分离 | dy/dt = g(t)h(y) |分离和积分： ∫dy/h(y) = ∫g(t)dt |
|线性一阶 | dy/dt + p(t)y = q(t) |积分因子：μ(t) = e^(∫p dt) |
|准确| M(t,y)dt + N(t,y)dy = 0 且 ∂M/∂y = ∂N/∂t |求势函数 F(t,y) |
|伯努利| dy/dt + p(t)y = q(t)yⁿ |代入 v = y^(1−n) 来线性化 |
**工作示例（积分因子）：** 求解 dy/dt + 2y = e^(−t), y(0) = 1。
- 积分因子：μ(t) = e^(∫2 dt) = e^(2t)
- 乘法：d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- 积分：e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- 初始条件：y(0) = 1 → 1 = 1 + C → C = 0
- 解：y(t) = e^(−t)
### 二阶线性常微分方程
**一般形式：** ay'' + by' + cy = g(t)
**齐次情况** (g​​ = 0)：求解特征方程 ar² + br + c = 0。
|判别式|根|通用解决方案|
|-------------|------|------------------|
| b² > 4ac（过阻尼）|两个不同的实数 r₁、r2 | y = C₁e^(r₁t) + C2e^(r2t) |
| b² = 4ac（临界阻尼）|重实根 r | y = (C₁ + C2t)e^(rt) |
| b² < 4ac（欠阻尼）|复数根 α ± βi | y = e^(αt)(C₁ cos βt + C2 sin βt) |
**物理解释：** 质量-弹簧-阻尼器系统 mx'' + bx' + kx = 0。
- 过阻尼：重阻尼，无振荡（闭门器）
- 临界阻尼：最快返回且无振荡（汽车悬架设计目标）
- 欠阻尼：以衰减幅度振荡（吉他弦）
### 常微分方程组
许多实际系统涉及多个相互作用的变量：
dx/dt = f(x, y)
dy/dt = g(x, y)
这可以写成向量形式：d**x**/dt = **F**(**x**)
**线性系统：** d**x**/dt = A**x**，其中 A 是矩阵。
解取决于 A 的特征值：
|特征值 |行为 |
|------------|------------|
|既有实数，也有负数|稳定节点（所有轨迹收敛到原点）|
|既真实又积极|不稳定的节点 |
|实数相反的符号 |鞍点（不稳定）|
|复数负实部 |稳定螺旋（阻尼振荡）|
|复数正实部 |不稳定的螺旋 |
|纯属虚构|中心（闭合轨道）|

## 相图
**相图**可视化状态空间中动力系统的轨迹（无需明确求解）。
### 主要特点
|特色 |描述 |
|---------|-------------|
| **定点（平衡）** |其中 dx/dt = 0（无运动）|
| **轨迹** |系统在状态空间中追踪的路径|
| **零斜线** |一个分量的导数为零的曲线 |
| **极限循环** |孤立闭合轨道（自持振荡）|
| **吸引力盆地** |导致给定吸引子的一组初始条件 |
| **分离体** |不同吸引力盆地之间的边界|
### 捕食者-猎物模型 (Lotka-Volterra)
dx/dt = αx − βxy（猎物）
dy/dt = δxy − γy（捕食者）
**固定点：**
1. (0, 0) — 灭绝（鞍点）
2. (γ/δ, α/β) — 共存（中心 — 闭合轨道）
该系统表现出周期性振荡：猎物增加→捕食者增加→猎物减少→捕食者减少→循环重复。

## 稳定性分析
### 线性稳定性
对于固定点 x*，对其进行线性化：令 u = x − x*，则 du/dt ≈ J(x*)u，其中 J 是雅可比矩阵。
**稳定性准则：** 不动点为：
- **稳定** 如果 J 的所有特征值都有负实部
- **不稳定**如果任何特征值具有正实部
- **边际稳定** 如果特征值的实部为零（需要非线性分析）
### 李亚普诺夫稳定性
**李亚普诺夫直接法**无需线性化即可确定稳定性。
**Lyapunov 函数** V(x) 满足：
1. V(x*) = 0 且 V(x) > 0，因为 x ≠ x*（正定）
2. 沿轨迹 dV/dt ≤ 0（非增加）
|状况 |结论 |
|------------|------------|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 |不稳定|
**工作示例：**系统 dx/dt = −x + y²，dy/dt = −y。
- 尝试 V(x,y) = x² + y²（类能量函数）
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- 近原点：dV/dt ≈ −2x² − 2y² < 0（对于小 y，−2y² 占主导地位）
- 结论：原点局部渐近稳定

## 混沌理论
**混沌**是确定性但不可预测的：系统遵循精确的规则，但初始条件的微小差异会导致截然不同的结果。
### 混沌的要求
|物业 |描述 |
|----------|-------------|
|确定性|没有随机性——由精确方程控制|
|对初始条件敏感 |附近的轨迹呈指数级分歧|
|有界|轨迹不会逃逸到无穷大|
|非周期|从不完全重复 |
### 洛伦兹系统
确定性混沌的经典例子：
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy – βz
标准参数 σ = 10、ρ = 28、β = 8/3：
- 系统有三个固定点，均不稳定
- 轨迹绕一个固定点运行，然后突然切换到另一个固定点
- 结果是 **洛伦兹吸引子** — 具有分形结构的奇怪吸引子
**李雅普诺夫指数：** 测量附近轨迹的发散率。
- 正李雅普诺夫指数 → 混沌
- 对于具有标准参数的洛伦兹系统：最大指数 ≈ 0.9 > 0
### 物流地图
一个表现出混沌的简单离散系统：
x_{n+1} = rx_n(1 − x_n)
|参数 r |行为 |
|------------|------------|
| 0 < r < 1 |人口灭绝 (x → 0) |
| 1 < r < 3 | 1 < r < 3 | x = 1 − 1/r | 处的稳定不动点
| 3 < r < 3.449 | 3 < r < 3.449周期 2 振荡 |
| 3.449 < r < 3.544 | 3.449 < r < 3.544周期 4 振荡 |
| 3.544 < r < 3.570 |周期 8、16、32、...（倍周期级联）|
| r ≈ 3.570 |混乱的开始|
| 3.570 < r < 4 |大多是混乱的，具有周期性窗口 |
| r = 4 | [0, 1] | 上完全混沌
### 蝴蝶效应
对初始条件的敏感依赖性的流行名称。在天气系统（由洛伦兹方程建模）中，巴西的一只蝴蝶扇动翅膀可能会在德克萨斯州引发龙卷风——不是因为蝴蝶引起的，而是因为微小的扰动呈指数级增长。

## 分岔理论
**分叉**是系统行为随着参数变化而发生的质变。
### 分叉的类型
|分叉|范式|发生了什么 |
|----------|-------------|--------------|
| **鞍节点** | dx/dt = r − x² |两个固定点出现/消失 |
| **跨临界** | dx/dt = rx − x² |两定点互换稳定性|
| **干草叉（超临界）** | dx/dt = rx − x³ |一个稳定点分裂为两个稳定点+一个不稳定点 |
| **干草叉（亚临界）** | dx/dt = rx + x³|不稳定的树枝倒塌（通常是灾难性的）|
| **霍普夫** | 2D系统|不动点变得不稳定，出现极限环 |
### 分叉图
固定点与参数值的关系图，显示稳定性（实线 = 稳定，虚线 = 不稳定）。逻辑图的分叉图揭示了通向混沌的倍周期路线和著名的 **费根鲍姆常数** δ ≈ 4.669（连续分叉区间之间的通用比率）。

## 偏微分方程 (PDE)
偏微分方程涉及多个变量及其偏导数的函数。
### 二阶线性偏微分方程的分类
对于 Au_xx + 2Bu_xy + Cu_yy + ... = 0：
|类型 |状况 |行为 |示例|
|------|---------|------------|---------|
| **椭圆形** | B² - AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 |波传播，保留锐利特征 |波动方程： u_tt = c²u_xx |
### 热方程
∂u/∂t = α ∂²u/∂x²
模拟热扩散、人口分布、期权定价（Black-Scholes）。
|物业 |声明|
|----------|------------|
|平滑|即使初始数据不连续，解决方案也会立即变得平滑 |
|最大化原则|最高温度出现在边界或初始时间 |
|时间可逆 |不可逆转——无法倒退|
### 波动方程
∂²u/∂t² = c² ∂²u/∂x²
模拟振动弦、声音、电磁波。
|物业 |声明|
|----------|------------|
|传播|干扰以 c 的速度传播 |
|可逆性|时间可逆|
|达朗贝尔溶液| u(x,t) = f(x−ct) + g(x+ct) （左/右波的叠加）|
### 拉普拉斯方程
∇²u = ∂²u/∂x² + ∂²u/∂y² = 0
解（调和函数）代表稳态温度、静电势、不可压缩流体流动。
|物业 |声明|
|----------|------------|
|平均值属性 | u(x₀) = u 在以 x₀ 为中心的任何圆上的平均值 |
|最大化原则|没有内部最大值或最小值|
|独特性|完全由边界条件决定 |

## 与机器学习和数据科学的相关性
| DS概念|应用 |
|------------|-------------|
|常微分 |神经 ODE（连续深度网络）、循环网络动力学 |

|混沌|了解 RNN（梯度消失/爆炸）、天气预报的敏感性 |
|分叉|学习中的相变（grokking）、训练动态中的政权变化 |
|偏微分方程 |扩散模型（基于分数的生成模型）、物理信息神经网络 |

|波动方程|地震数据处理、音频信号建模|
|洛特卡-沃尔泰拉 |人口动态、流行病学、竞争性机器学习代理 |
|相像|可视化损失动态，理解 GAN 训练 |

动力系统理论是变化的数学。它解释了为什么有些系统会稳定下来，为什么有些系统会振荡，以及为什么有些系统会表现得很混乱。对于数据科学家来说，它提供了用于理解训练动态、设计稳定算法、建模时间序列以及构建下一代基于物理的机器学习模型的工具。
