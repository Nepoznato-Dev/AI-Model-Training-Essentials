# 抽象代数
抽象代数研究代数结构——具有遵循特定规则的运算的集合。抽象代数不是处理数字，而是处理任何满足公理的对象。这种普遍性是强大的：为“群”证明的定理同时适用于整数、对称性、矩阵、排列和量子态。抽象代数是密码学、纠错码、量子计算和整个物理学中使用的对称分析的基础。
---

## 团体
**群**是最基本的代数结构。它抓住了对称的本质。
＃＃＃ 定义
**群** (G, *) 是一个具有二元运算 * 的集合 G，满足：
|公理|声明|示例 (ℤ, +) |
|--------|---------|-----------------|
| **关闭** | ∀a,b ∈ G: a ∗ b ∈ G | a + b 是整数 |
| **关联性** | (a*b)*c=a*(b*c)| (a + b) + c = a + (b + c) | (a + b) + c = a + (b + c) |
| **身份** | ∃e ∈ G: e ＊ a = a ＊ e = a | 0 + a = a + 0 = a |
| **逆** | ∀a ∈ G, ∃a⁻1: a * a⁻1 = a⁻1 * a = e | a + (−a) = 0 |
如果该运算也是**交换性** (a * b = b * a)，则该群称为**阿贝尔**。
### 组的示例
|集团|设置|运营|身份 |逆|阿贝尔？ |

| (ℤ, +) |整数 |加法 | 0 | -a |是的 |
| (ℚ*, ×) |非零有理数|乘法| 1 | 1/一个 |是的 |
| (ℤ/nℤ, +) |余数 mod n |加法 n | [0]| [n−a] | [n−a] |是的 |
| Sₙ | {1,...,n} | 的排列成分|编号 |逆排列|否 (n ≥ 3) |
| GL(n, ℝ) | GL(n, ℝ) |可逆 n×n 矩阵 |矩阵乘法 |我ₙ | A⁻1 |否 (n ≥ 2) |
| (ℝⁿ, +) | n 维向量 |向量加法 | 0 | -v|是的 |
### 组和元素的顺序
|术语 |定义 |示例|
|------|------------|---------|
| **G 阶** (\|G\|) | G | 中的元素数量\|ℤ/5ℤ\| = 5 |
| **元素 a 的顺序** (ord(a)) |最小正 k 且 aᵏ = e | (ℤ/7ℤ)* = 3 中的 ord(2)（因为 2³ = 8 ≡ 1） |

### 子组
G 的**子群** H 是子集 H ⊆ G ，它本身就是同一操作下的群。
**子群测试：** H 是 G 的子群当且仅当：
1. H非空
2. 对于所有 a, b ∈ H: a ∗ b⁻1 ∈ H
**示例：**
- (ℤ, +) 具有子群 nℤ = {..., −2n, −n, 0, n, 2n, ...} 对于每个 n ≥ 0
- **平凡子群** {e} 和群 G 本身始终是子群
- 在 S₃ 中，集合 {id, (12)} 是 2 阶子群
### 陪集和拉格朗日定理
对于 G 的子群 H 且元素 a ∈ G：
- **左陪集：** aH = {ah : h ∈ H}
- **右陪集：** Ha = {ha : h ∈ H}
**拉格朗日定理：** 对于有限群 G 和子群 H：
|H|除|G|
**推论：**
- 每个元素的顺序除|G|
- 如果|G| = p（素数），则 G 是循环的（没有非平凡子群）
-a^|G| = e 对于所有 a ∈ G （推广费马小定理）
### 循环群
如果存在 g ∈ G 且 G 的每个元素都是 g 的幂，则群 G 是**循环**。我们写 G = ⟨g⟩。
|物业 |声明|
|----------|------------|
|每个循环群都是交换群 | — |
|加法下的 ℤ/nℤ 是循环 |由 [1] | 生成
| (ℤ/pℤ)* 对于素数 p 是循环的 |生成元称为原根 |
|分类|对于某些 n | 每个有限循环群都同构于 ℤ/nℤ

## 同态和同构
**同态**是组之间的结构保留映射。
### 定义
|术语 |定义 |示例|
|------|------------|---------|
| **同态** | φ: G → H 其中 φ(ab) = φ(a)φ(b) |检测： GL(n,ℝ) → ℝ* |
| **同构** |双射同态（群是“相同的”） | (ℤ/6ℤ) ≅ (ℤ/2ℤ) × (ℤ/3ℤ) |
| **内核** | ker(φ) = {g ∈ G : φ(g) = e_H} | ker(det) = SL(n, ℝ) |
| **图片** | im(φ) = {φ(g) : g ∈ G} | im(det) = ℝ* |
### 第一同构定理
如果 φ: G → H 是同态，则：
G / ker(φ) ≅ im(φ)
这是代数中最重要的定理之一——它说每个同态都分解为一个商，后面跟着一个同构。

## 戒指
**环**向组添加第二个运算，对加法和乘法的算术进行建模。
＃＃＃ 定义
**环** (R, +, ×) 是一个集合 R，其两个运算满足：
|公理|声明|
|------|----------|
| (R, +) 是阿贝尔群 |加法是可交换的、结合的、恒等式 0、每个元素都有加法逆元 |
|乘法是结合律 | (a × b) × c = a × (b × c) | (a × b) × c = a × (b × c) |
|分配律| a(b + c) = ab + ac 且 (a + b)c = ac + bc |
如果乘法也是可交换的并且具有恒等式 (1)，则 R 是**具有单位的交换环**。
### 戒指的例子
|戒指|描述 |可交换的？ |有1个吗？ |
|------|-------------|-------------|--------|
| (ℤ, +, ×) |整数 |是的 |是的 |
| (ℚ, +, ×) |理由|是的 |是的 |
| (ℝ, +, ×) |实数 |是的 |是的 |
| (ℤ/nℤ, +, ×) |整数 mod n |是的 |是的 |
| Mₙ(ℝ) | n×n 实数矩阵 |否 (n ≥ 2) |是的 |
| ℝ[x] |具有实数系数的多项式 |是的 |是的 |
### 理想和商环
环 R 的**理想** I 是满足以下条件的子集：
1. 是加法下的子群
2. 吸收乘法：对于所有 r ε R 和 a ε I，ra ε I 和 ar ε I
**商环** R/I：元素是 I 的陪集，操作继承自 R。
**示例：** ℤ/nℤ = ℤ/nℤ 是 ℤ 除以理想 nℤ 的商。
### 积分域和字段
|结构|定义 |示例 |
|------------|------------|----------|
| **积分域** | 1 的交换环，无零因数 (ab = 0 → a = 0 或 b = 0) | ℤ, ℚ[x], ℝ[x] |
| **领域** |每个非零元素都有一个乘法逆元的交换环 | ℚ、ℝ、ℂ、ℤ/pℤ（p 素数）|

## 字段
域是常用的最结构化的代数对象。每个非零元素都可以进行加、减、乘、除运算。
### 关键属性
|物业 |声明|
|----------|------------|
|每个领域都是一个完整的领域 | — |
|每个有限积分域都是一个域 | — |
|特点| n·1 = 0 时的最小 n，如果不存在这样的 n，则为 0 |
| char(ℚ) = char(ℝ) = char(ℂ) | = 0 |
|字符（ℤ/pℤ）| = p（对于质数 p）|
### 有限域（伽罗瓦域）
对于每个素数幂 pᵏ，都存在一个唯一的（直至同构）pᵏ 阶有限域，表示为 GF(pᵏ) 或 𝔽_{pᵏ}。
|领域|尺寸|建筑 |应用 |
|--------|------|-------------|----------|
| GF(2) | 2 | {0, 1} 模 2 |二进制算术，异或 |
| GF(2ᵏ) | 2ᵏ |多项式对 GF(2) 上的不可约多项式取模 | AES 加密、CRC 代码 |
| GF（p）| p| ℤ/pℤ 对于质数 p |模算术、编码理论|
| GF(pᵏ) | GF(pᵏ) | pᵏ |扩展字段 | Reed-Solomon 码、椭圆曲线 |
**GF(2⁸)的构造**（用于 AES）：
- 从 GF(2) = {0, 1} 开始
- 在 GF(2) 上选择不可约多项式 p(x) = x⁸ + x⁴ + x3 + x + 1
- 元素是次数 < 8 的多项式，系数为 GF(2)
- 算术：多项式加法 (XOR) 和乘法 mod p(x)

## 向量空间
**向量空间**是一组可以相加和缩放的向量，构成线性代数的基础。
＃＃＃ 定义
域 F 上的 **向量空间** V 是一个集合：
- 向量加法：V × V → V（使 V 成为阿贝尔群）
- 标量乘法：F × V → V
满足：结合律、加法交换律、标量乘法分配律、1·v = v。
### 关键概念
|概念 |定义 |示例|
|--------|------------|---------|
| **基础** |线性无关的生成集 | Fⁿ | {e₁, e2, ..., eₙ} |
| **尺寸** |任意基中的向量数量 |暗淡（ℝ³）= 3 |
| **子空间** |加法和标量乘法下的封闭子集 |通过 ℝ³ | 中原点的平面
| **线性组合** | Σ cᵢvᵢ 其中 cᵢ ∈ F | 3v₁ + 2v2 - v₃ |
| **跨度** |所有线性组合的集合 | Span({v₁, v2}) = 平面，如果 v₁, v2 独立 |
| **线性独立** |没有一个向量是其他向量的线性组合 | ℝ3 中的 e₁、e2、e₃ |
### 重要的向量空间
|空间|描述 |尺寸|
|--------|-------------|------------|
| Fⁿ |字段 F 上的 n 元组 | n |
| Pₙ(F) |次数 ≤ n | 的多项式n + 1 |
| Mₘₓₙ(F) | F 上的 m × n 矩阵 |百万 |
| C[a,b] | [a,b] | 上的连续函数无限|
| L²(ℝ) |平方可积函数 |无限（希尔伯特空间）|

## 线性映射和特征理论
### 线性映射
一个**线性映射**（线性变换）T：V→W满足：
- T(u + v) = T(u) + T(v)
- 对于所有标量 c，T(cv) = cT(v)
|概念 |定义 |示例|
|--------|------------|---------|
| **内核** | {v ∈ V : T(v) = 0} |矩阵的零空间 |
| **图片** | {T(v) : v ∈ V} |矩阵的列空间 |
| **秩无效定理** |暗淡（ker T）+暗淡（im T）=暗淡（V）|基本约束|
| **矩阵表示** | T(v) = Av 对于某个矩阵 A |有限维空间之间的每个线性映射|
### 特征值和特征向量
对于线性映射 T：V → V（或矩阵 ​​A）：
**特征值方程：** Av = λv，其中v ≠ 0
|术语 |定义 |
|------|------------|
| **特征值** λ |对于某些 v ≠ 0，Av = λv 的标量 |
| **特征向量** v |满足 Av = λv | 的非零向量
| **特征多项式** | det(A − λI) = 0 |
| **特征空间** | {v : Av = λv} — λ 的所有特征向量的集合（加上 0） |
| **光谱** |所有特征值的集合 |
### 计算特征值
对于 2×2 矩阵 A = [[a, b], [c, d]]：
- 特征多项式： λ² − (a+d)λ + (ad−bc) = 0
- λ = ((a+d) ± √((a+d)² − 4(ad−bc))) / 2
**关键属性：**
- 特征值之和 = 迹 (A) = 对角线元素之和
- 特征值的乘积 = det(A)
### 对角化
矩阵 A **可对角化**当且仅当它具有 n 个线性独立特征向量（其中 A 为 n×n）。
如果 A = PDP⁻1，其中 D 是对角线：
- Aᵏ = PDᵏP⁻¹（快速矩阵求幂）
- D 包含对角线上的特征值
- P 包含特征向量作为列
**谱定理：** 每个实对称矩阵都可以通过正交矩阵对角化。它的特征值是实数。

## 应用
### 编码理论（纠错码）
有限域是现代纠错码的基础。
|代码|领域|更正|应用 |
|------|--------|----------|----------|
|汉明码 | GF(2) |每块 1 个错误 | RAM ECC、早期网络|
|里德-所罗门 | GF(2ᵏ) |多个错误 | CD、DVD、QR 码、卫星通信 |
| BCH 代码 | GF(2ᵏ) |多个错误 |卫星闪存|
| LDPC码| GF(2) |多个错误 | Wi-Fi (802.11n)、DVB-S2、5G |
**Reed-Solomon 编码：** 将数据视为 GF(2ᵏ) 上的多项式，在多个点进行评估。即使某些评估被破坏，也可以恢复原始多项式。
### 量子计算
量子态存在于复向量空间（希尔伯特空间）中。量子门是酉矩阵。
|量子概念|代数结构|
|----------------|--------------------|
|量子比特 | ℂ² 中的单位向量（复数二维向量空间）|
|量子门|酉矩阵 U ∈ U(2ⁿ) |
|测量|投影算子 |
|纠缠|不可分离张量积状态 |
|不可克隆定理|没有线性映射可以复制未知的量子态 |
**单量子位门：**
|门 |矩阵|效果|
|------|--------|--------|
| Pauli-X（非）| [[0,1],[1,0]] |位翻转 |
|泡利-Z | [[1,0],[0,−1]] |相位翻转|
|哈达玛| (1/√2)[[1,1],[1,−1]] | (1/√2)[[1,1],[1,−1]] |创建叠加 |
|中国诺特| 4×4 控制门 |纠缠两个量子比特 |
### 密码学
|应用 |代数使用 |
|-------------|-------------|
| RSA |乘法群 (ℤ/nℤ)* |
|椭圆曲线密码学 |有限域上椭圆曲线上的点群 |
|高级加密标准 | GF(2⁸) 中的算术 |
|迪菲·赫尔曼 | (ℤ/pℤ)* 的循环子群或椭圆曲线群 |
