＃ 优化
优化是从一组可行解决方案中找到最佳解决方案的数学。它问：给定一个函数和约束，什么输入可以最小化（或最大化）输出？优化是机器学习的引擎——训练模型意味着最小化损失函数。它出现在运筹学、经济学、工程设计以及几乎所有定量领域。
---

## 问题表述
一般的**优化问题**具有以下形式：
最小化 f(x)
服从：gᵢ(x) ≤ 0（不等式约束），hⱼ(x) = 0（等式约束）
|术语 |意义|
|------|---------|
| **目标函数** f(x) |最小化（或最大化）的数量 |
| **决策变量** x |我们可以控制的价值观|
| **可行区域** |满足所有约束的所有 x 的集合 |
| **全局最小值** |对于所有可行 x，可行 x* 且 f(x*) ≤ f(x) |
| **局部最小值** |对于某个邻域中的所有可行 x，可行 x* 且 f(x*) ≤ f(x) |
| **凸问题** | f 是凸的，可行区域是凸集（局部最小值 = 全局最小值） |
---

## 线性规划 (LP)
当目标和所有约束都是**线性**时，问题就是线性规划。
### 标准表格
最小化 cᵀx
满足：Ax ≤ b，x ≥ 0
其中c，x ε ℝⁿ，A ε ℝᵐˣⁿ，b ε ℝᵐ。
＃＃＃ 特性
|物业 |声明|
|----------|------------|
|凸性| LP 始终是凸问题 |
|最优解 |始终位于可行多胞形的顶点（角点）|
|存在|如果可行区域有界且非空，则存在最优解 |
|多重最优|如果两个顶点是最优的，则它们之间的边上的每个点也是最优的 |
### 单纯形法
**单纯形法**（Datzig，1947）沿着可行多面体的边缘从一个顶点移动到另一个顶点，始终改进目标，直到达到最佳值。
|物业 |价值|
|----------|--------|
|最坏情况时间| O(2ⁿ)（指数 - 实践中很少见）|
|平均案例时间 |大多数实际问题的多项式 |
|关键理念|移动到具有更好目标值的相邻顶点 |
**算法（概述）：**
1. 从基本可行解（多面体的顶点）开始
2. 选择一个输入变量（可以改善目标的变量）
3.选择离开变量（保持可行性）
4. Pivot：移动到新的顶点
5. 重复直到不存在改进方向
### 内点法
单纯形的替代方案：从可行区域内接近最优值。
|物业 |价值|
|----------|--------|
|最坏情况时间|多项式（对于某些变体为 O(n3·⁵)）|
|实用性能|在大型问题上与单纯形竞争
|关键理念|沿着内部的“中心路径”|
### 已工作 LP 示例
**问题：** 一家工厂生产椅子 (x₁) 和桌子 (x2)。
- 利润：每把椅子 30 美元，每张桌子 50 美元
- 木材：2x₁ + 4x2 ≤ 100（可用板脚）
- 劳动力：x₁ + 3x2 ≤ 60（可用小时数）
- 最大化：30x₁ + 50x2
**解决方案（2个变量的图形方法）：**
- 可行区域的顶点：(0,0)、(30,0)、(40,10)、(0,20)
- 评估每个顶点的目标：
  - (0,0)：利润 = 0
  - (30,0)：利润 = 900
  - (40,10): 利润 = 1700 ← 最优
  - (0,20)：利润 = 1000
- **最佳：** x₁ = 40 把椅子，x2 = 10 张桌子，利润 = 1700 美元

## 凸优化
如果目标函数是凸的并且可行区域是凸集，则问题是**凸**。
### 凸集和函数
|概念 |定义 |
|---------|------------|
| **凸集** |对于集合中的任何 x, y 且 t ∈ [0,1]： tx + (1−t)y 也在集合 |
| **凸函数** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) 对于所有 t ∈ [0,1] |
| **严格凸** |对于 t ∈ (0,1) 且 x ≠ y | 来说，不等式是严格的。
**关键属性：** 对于凸优化，每个局部最小值都是全局最小值。
### 常见的凸函数
|功能|凸？ |哪里 |
|----------|---------|--------|
| ax + b（线性）|是（并且凹）|无处不在 |
| x² |是的 | ℝ |
| eˣ |是的 | ℝ |
| −log(x) |是的 | x > 0 |
| \|x\|ᵖ (p ≥ 1) |是的 | ℝⁿ |
| max(f1, f2) 如果 f1, f2 凸 |是的 |域的交集 |
### 梯度下降
机器学习中最基本的优化算法。
**更新规则：** x_{k+1} = x_k − α∇f(x_k)
其中 α > 0 是**学习率**（步长）。
|变体 |更新规则 |优势 |
|--------|-------------|------------|
| **批量GD** | x ← x − α∇f(x) |稳定收敛 |
| **随机 GD (SGD)** | x ← x − α∇fᵢ(x)（一个样本）|每次迭代速度快，逃脱局部最小值 |
| **小批量 SGD** | x ← x − α(1/|B|)ΣᵢεB ∇fᵢ(x) |批量与随机之间的平衡 |
| **势头** | v ← βv − α∇f(x); x ← x + v |通过平坦区域加速 |
| **亚当** |每个参数的自适应学习率 |开箱即用，适合深度学习 |
| **RMS 螺旋** |通过梯度大小的运行平均值来缩放学习率 |适合 RNN |
### 收敛率
|方法|凸 f |强凸 f |
|--------|----------|--------------------|
|梯度下降| O(1/k) | O(1/k) | O((1−μ/L)ᵏ)（线性）|
|新元 | O(1/√k) | O(1/√k) | O(1/k) | O(1/k) |
|加速 GD (Nesterov) | O(1/k²) | O(1/k²) | O((1−√(μ/L))ᵏ) | O((1−√(μ/L))ᵏ)
其中 k = 迭代次数，μ = 强凸性参数，L = Lipschitz 常数。
### 选择学习率
|战略|描述 |
|----------|-------------|
|固定α |简单但可能发散（太大）或收敛缓慢（太小）|
|线搜索|找到沿梯度方向最小化 f(x − α∇f(x)) 的 α |
|腐烂时间表| α_t = α₀ / (1 + βt) 或 α_t = α₀ · βᵗ |
|热身|从小处开始，增加，然后衰减（在变压器训练中常见）|
|自适应（亚当）|基于梯度统计的每参数学习率 |

## 约束优化
### 拉格朗日乘数
对于该问题：在 h(x) = 0 的情况下最小化 f(x)。
**拉格朗日：** L(x, λ) = f(x) + λh(x)
最优情况下：∇ₓL = 0 且∇_λL = 0（得出 h(x) = 0）。
**工作示例：** 在 x + y = 1 的条件下最小化 f(x,y) = x² + y²。
- L = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- 约束：x + y = 1 → −λ = 1 → λ = −1
- 解：x = 1/2，y = 1/2，f = 1/2
### KKT 条件
**Karush-Kuhn-Tucker (KKT) 条件**将拉格朗日乘数推广到不等式约束。
对于：在 gᵢ(x) ≤ 0、hⱼ(x) = 0 的条件下最小化 f(x)。
**拉格朗日：** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**KKT 条件**（最优性所必需）：
|状况 |方程 |
|------------|----------|
|平稳性| ∇ₓL = 0 |
|初步可行性| gᵢ(x) ≤ 0, hⱼ(x) = 0 |
|双重可行性 | λᵢ ≥ 0 |
|互补松弛 |对于所有 i，λᵢgᵢ(x) = 0 |
**互补松弛**意味着：如果约束 gᵢ 未激活 (gᵢ(x) < 0)，则 λᵢ = 0 （约束不影响解）。
对于满足斯莱特条件的凸问题，KKT 条件既是必要的又是充分的。

## 二元性
每个优化问题（**原始**）都有一个相关的**对偶**问题。
### 弱对偶和强对偶
|概念 |声明|
|--------|------------|
| **双重功能** | g(λ, ν) = infₓ L(x, λ, ν) |
| **双重问题** |在 λ ≥ 0 的情况下最大化 g(λ, ν) |
| **弱对偶性** |对偶最优 ≤ 原始最优（始终成立）|
| **强二元性** |对偶最优 = 原始最优（适用于斯莱特条件的凸问题）|
| **对偶差距** |原始最优 - 对偶最优（强对偶性下为零）|
### 为什么二元性很重要
|应用 |二元性如何提供帮助？
|------------------------|--------------------|
|下限 | Dual 证明了原始解决方案有多好 |
|支持向量机 | SVM 问题的对偶导致核技巧 |
|敏感性分析 |双变量衡量如果放松约束，最优变化有多大？
|分解 |大问题可以通过对偶 | 分解为更小的子问题。

## 整数规划
当某些或所有变量必须是**整数**时，问题就会变得更加困难（通常是 NP 困难）。
### 类型
|类型 |描述 |
|------|-------------|
|纯IP |所有变量必须是整数 |
|混合 IP (MIP) |有些变量是整数，有些是连续 |
|二进制IP |变量限制为 {0, 1} |
###解决方法
|方法|想法 |
|--------|------|
| **分支定界** |拆分为子问题，解决 LP 松弛，剪枝 |
| **切割平面** |添加线性约束以收紧 LP 松弛 |
| **分支和切割** |将分支定界与剖切面相结合 |
| **启发式** |贪婪、局部搜索、模拟退火求近似解 |
---

## 启发式和元启发式方法
当精确优化难以解决时，启发式方法会找到好的（不一定是最佳的）解决方案。
|方法|关键理念|最适合 |
|--------|----------|----------|
| **梯度下降** |沿着最陡的下坡路线 |平滑、可微的函数 |
| **牛顿法** |使用二阶（曲率）信息 |顺利、条件良好的问题 |
| **模拟退火** |以降低的概率接受更差的解决方案 |全局优化，组合 |
| **遗传算法** |使用选择、交叉、突变来进化种群 |多目标，不可微 |
| **粒子群** |受最著名职位影响，特工探索太空 |连续、非凸 |
| **贝叶斯优化** |建立代理模型，使用获取函数|昂贵的黑盒函数（超参数调整）|
### 牛顿优化法
**更新规则：** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
其中 H 是 Hessian 矩阵（二阶导数矩阵）。
|物业 |价值|
|----------|--------|
|收敛速度|二次（接近最佳）|
|每次迭代成本 | Hessian 反演的 O(n3) |
|需要|两次可微、正定 Hessian |
|拟牛顿 (BFGS) |从梯度近似 Hessian |每次迭代 O(n²) |

## 与机器学习和数据科学的相关性
|优化理念|应用 |
|--------------------|-------------|
|梯度下降|训练神经网络、逻辑回归、任何可微分模型 |
| SGD 及其变体 |大规模ML（小批量训练）、在线学习 |
|亚当，RMSprop |深度学习的默认优化器 |
|凸优化 | SVM、逻辑回归、LASSO、Ridge（保证全局最优）|
|拉格朗日乘子 |约束学习、公平机器学习、资源分配 |
| KKT 条件 |推导 SVM 对偶，理解约束活动 |
|二元性| SVM核技巧、敏感性分析、分解方法|
|线性规划|资源配置、组合优化、网络流量|
|整数规划 |特征选择（二值）、调度、组合问题 |
|贝叶斯优化 |超参数调整（Optuna、Hyperopt）|
|牛顿/拟牛顿|中小型问题的二阶方法 (L-BFGS) |

＃＃ 概括
|方法|问题类型 |保证|规模|
|--------|-------------|------------|--------|
|单工|线性规划|精确最优|数以百万计的变量|
|内点|凸（LP、QP、SOCP）|精确最优 |规模宏大|
|梯度下降|流畅无拘无束|收敛到本地最小值 |非常大（深度学习）|
|新元 |大规模经验风险|收敛（有衰减）|海量数据集 |
|牛顿/BFGS |平滑、二次可微 |二次收敛|中小型 |
| KKT / 拉格朗日 |约束（凸）|条件下精确 |中等|
|分支定界|整数规划 |精确最优|中小型 |
|启发式 |任意（非凸、组合）|没有保证|变化 |
优化可以说是机器学习中最重要的数学工具。您训练的每个模型（从线性回归到大型语言模型）都涉及解决优化问题。了解问题何时是凸的（保证全局最优）、梯度下降何时收敛以及如何处理约束，为您提供设计、调试和改进学习算法的理论基础。
