# 热力学和统计力学
热力学用温度、压力和熵来描述系统的宏观行为——而不知道原子是什么样子。统计力学自下而上地解释热力学：它从大量粒子的微观行为中得出宏观特性。它们共同提供了对能量、熵和平衡的最深入的理解——这些概念已经迁移到信息论、机器学习等领域。
---

## 热力学变量和状态
### 状态变量
|变量|类型 |单位|描述 |
|----------|------|------|----------|
|温度（T）|强化 |开尔文 (K) |每个粒子的平均动能 |
|压力（P）|强化 |帕斯卡 (Pa) |单位面积力|
|体积 (V) |广泛 |立方米|占用空间|
|内能 (U) |广泛 |焦耳 (J) |总微观能量|
|熵 (S) |广泛 | J/K |无序/微观状态的测量 |
|颗粒数 (N) |广泛 |摩尔或计数|物质的量 |
**密集**变量不依赖于系统大小； **广泛的**变量确实如此。
### 状态方程
对于理想气体：PV = nRT = Nk_BT
|恒定|价值|
|----------|--------|
| R（气体常数）| 8.314 焦耳/(摩尔·K) |
| k_B（玻尔兹曼常数）| 1.381 × 10⁻²³ J/K |
| N_A（阿伏伽德罗常数）| 6.022 × 10²³ /摩尔 |

## 热力学定律
### 第零法则
如果 A 与 B 处于热平衡，B 与 C 处于热平衡，则 A 与 C 处于热平衡。
**含义：** 温度是明确定义且可测量的。
### 第一定律（能量守恒定律）
ΔU = Q − W
|符号|意义|
|--------|---------|
| ΔU|内能变化|
|问 |向系统添加热量|
|西 |系统完成的工作 |
**微分形式：** dU = δQ − δW = δQ − PdV
|流程|约束|后果|
|--------|------------|-------------|
|等容 | dV = 0 | W = 0，ΔU = Q |
|等压| dP = 0 | W = PΔV |
|等温| dT = 0 | ΔU = 0（理想气体），Q = W |
|绝热 | δQ = 0 | ΔU = -W |
### 第二定律（熵）
**克劳修斯陈述：** 热量不能自发地从冷流向热。
**开尔文-普朗克声明：** 没有任何发动机可以将所有热量转化为功。
**熵表述：** 对于任何过程：ΔS_universe ≥ 0
|工艺类型| ΔS_宇宙 |
|-------------|-------------|
|双面 | = 0 |
|不可逆转（真实）| > 0 |
**熵变：** dS = δQ_rev / T
### 第三定律
当 T → 0 K 时，完美晶体的熵接近零： lim_{T→0} S = 0
**含义：** 绝对零在有限的步骤中是无法实现的。

## 深度熵
### 热力学熵
S 是状态函数。对于状态 A 和 B 之间的可逆过程：
ΔS = ∫_A^B δQ_rev / T
**工作示例：** 在恒压下将水从 T₁ 加热到 T2 时的熵变。
ΔS = ∫_{T₁}^{T2} (mc_p/T) dT = mc_p ln(T2/T₁)
### 统计熵（玻尔兹曼）
S = k_B ln Ω
其中Ω是与宏观状态一致的微观状态的数量。
|宏观状态|微观状态 (Ω) |熵 |
|------------|------------------|---------|
|所有气体都集中在半个盒子中 |小|低|
|气体分布均匀 |非常大|高|
| 0 K 下的完美晶体 | 1 | 0 |
**联系：** 第二定律变成了统计定律——系统向具有更多微观状态的宏观状态发展，仅仅是因为它们的可能性更大。

## 焓和自由能
### 焓
H = U + PV
适用于恒压过程（大多数化学和生物学）。
ΔH = Q_p（恒压热量）
### 亥姆霍兹自由能
F = U − TS
|物业 |声明|
|----------|------------|
|意义| T、V 恒定时可提取的最大功 |
|平衡|系统在 T、V 恒定时最小化 F |
|与配分函数的关系 | F = −k_BT ln Z |
### 吉布斯自由能
G = H − TS = U + PV − TS
|物业 |声明|
|----------|------------|
|意义| T、P 恒定时的最大非膨胀功 |
|平衡|系统在 T、P 恒定时最小化 G |
|自发性| ΔG < 0 → 自发； ΔG = 0 → 平衡 |
|化学反应| ΔG = ΔH − TΔS 确定方向 |
### 热力学势总结
|潜力|自然变量|差速器|最小化时 |
|------------|--------------------|-------------|----------------|
| U（内能）| S、V | dU = TdS – PdV |隔离系统|
| H（焓）| S、P | dH = TdS + VdP |常数 P，绝热 |
| F（亥姆霍兹）| T、V | dF = −SdT − PdV |常数 T、V |
| G（吉布斯）| T、P | dG = −SdT + VdP |常数 T、P |

## 卡诺循环
**卡诺循环**是最高效的热机，在温度 T_H（热）和 T_C（冷）之间运行。
### 四个阶段
|舞台|流程|发生了什么 |
|--------|---------|-------------|
| 1 → 2 |等温膨胀|从 T_H 的热储层吸收热量 Q_H |
| 2 → 3 |绝热膨胀|气体从 T_H 冷却至 T_C |
| 3 → 4 |等温压缩|将热量 Q_C 拒绝到 T_C 处的冷库 |
| 4 → 1 |绝热压缩 |燃气从 T_C 加热至 T_H |
### 卡诺效率
η_卡诺 = 1 − T_C/T_H
| T_H | T_C | η_卡诺 |
|-----|-----|----------|
| 500K| 300K| 40% |
| 1000 K | 300K| 70% |
| 300K| 299 K | 299 K 0.33% |
**没有真正的发动机可以超过卡诺效率。**真正的发动机总是不可逆的（摩擦、湍流、有限温差）。

## 统计力学
### 玻尔兹曼分布
对于温度 T 下处于热平衡的系统，处于能量 E_i 的微观状态的概率：
P(E_i) = (1/Z) e^{−E_i / k_BT}
其中 Z 是 **配分函数**：
Z = Σᵢ e^{−E_i / k_BT}
### 配分函数
Z 对系统的所有热力学信息进行编码。
|数量 |公式|
|----------|---------|
|亥姆霍兹自由能| F = −k_BT ln Z |
|平均能量| ⟨E⟩ = −∂(ln Z)/∂β 其中 β = 1/(k_BT) |
|熵 | S = k_B(ln Z + β⟨E⟩) |
|热容量| C_V = ∂⟨E⟩/∂T = k_Bβ²(⟨E²⟩ − ⟨E⟩²) |
|压力| P = (1/β) ∂(ln Z)/∂V |
### 工作示例：两国系统
粒子可以处于状态 0（能量 0）或状态 1（能量 ε）。
Z = 1 + e^{−βε}
|数量 |结果 |
|----------|--------|
| P(状态 0) | 1/(1 + e^{−βε}) | 1/(1 + e^{−βε}) |
| P(状态 1) | e^{−βε}/(1 + e^{−βε}) |
| ⟨E⟩ | ε/(1 + e^{βε}) |
| T 上限 (β→0) | ⟨E⟩ → ε/2（等概率）|
| T 下限 (β→∞) | ⟨E⟩ → 0（基态）|
### 均分定理
每个二次自由度对平均能量贡献 ½k_BT。
|系统|自由度| ⟨E⟩ |
|--------|--------------------|------|
|单原子气体 (He) | 3 翻译 | (3/2)k_BT |
| T 室的双原子气体 (N2) | 3 反式 + 2 旋转 | (5/2)k_BT |
|高 T 下的双原子气体 | 3 个反式 + 2 个旋转 + 1 个振动 | (7/2)k_BT |
|固体（爱因斯坦模型）| 3 个振动（每个原子）| 3k_BT |

## 与信息论的联系
### 香农熵与热力学熵
|方面|香农熵 H(X) |热力学熵 S |
|--------|--------------------------------|------------------------|
|定义 | −Σ pᵢ log pᵢ | k_B ln Ω（或−k_B Σ pᵢ ln pᵢ）|
|最大时 |均匀分布|热平衡|
|措施|不确定性/信息内容|可访问的微观状态数量 |
|单位 |比特或纳特| J/K |
**吉布斯熵公式：** S = −k_B Σᵢ pᵢ ln pᵢ （与香农熵的形式相同）
### 最大熵原理
这两个领域都使用相同的原理：最能代表我们的知识状态的分布是在已知约束下最大化熵的分布。
|约束|结果分布|
|------------|------------------------|
|已知均值|指数分布|
|已知均值和方差 |高斯分布|
|已知能量 ⟨E⟩ |玻尔兹曼分布|
|没有限制|均匀分布|
### 兰道尔原理
擦除一位信息至少会以热量的形式消耗 k_BT ln 2 的能量。这将信息处理直接与热力学联系起来——计算具有基本的能源成本。

## 与机器学习和数据科学的相关性
| Thermo/StatMech 概念 |应用 |
|------------------------|-------------|
|玻尔兹曼分布| Softmax 函数、基于能量的模型、模拟退火 |
|配分函数|概率模型中的标准化常数，一般来说很棘手 |
|免费能源|变分推理（最小化变分自由能 = 最小化 KL 散度）|
|熵 |正则化、RL 探索（最大熵 RL）、决策树 |
|最大熵原理| MaxEnt 分类器、先验选择、分布估计 |
|模拟退火|逐步降低“温度”进行全局优化 |
|统计力学|了解学习中的阶段转变（grokking、双重下降） |
|均分|了解物理模拟中的能量分布 |
|兰道尔原理|计算的基本限制，可逆计算|
|吉布斯采样| MCMC方法直接受统计力学启发|
|温度（以 softmax 为单位）|控制预测的随机性：P(i) ∝ exp(z_i/T) |

热力学和统计力学是物理学与信息论的结合。控制热机的熵也控制着数据压缩。描述气体分子的相同玻尔兹曼分布为每个分类器中的 softmax 层提供动力。了解这些联系可以让您对物理学、概率和机器学习有一个统一的看法。
