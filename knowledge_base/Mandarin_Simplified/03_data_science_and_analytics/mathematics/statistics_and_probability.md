# 统计与概率
概率和统计学是数据科学、机器学习和科学研究的数学基础。概率告诉你事件发生的可能性有多大；统计学告诉你如何从数据中得出结论。他们共同将不确定性转化为可量化、可管理的知识。
---

## 概率论
### 核心概念
|概念 |描述 |示例|
|---------|-------------|---------|
| **样本空间** |所有可能结果的集合|掷骰子：{1, 2, 3, 4, 5, 6} |
| **活动** |样本空间的子集 |滚动偶数：{2, 4, 6} |
| **概率** |测量可能性的 0 到 1 之间的数字 | P(滚动 6) = 1/6 |
| **条件概率** | P(A|B)：给定 B 的情况下 A 发生的概率 | P(雨 | 阴天) |
| **独立** |一方不影响另一方的事件 |抛硬币是独立的 |
### 概率规则
|规则|公式|使用案例|
|------|---------|----------|
| **加法规则** | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) | A 或 B 的概率 |
| **乘法规则** | P(A ∩ B) = P(A) × P(B|A) | P(A ∩ B) = P(A) × P(B|A) | A 和 B 的概率 |
| **补足规则** | P(非 A) = 1 − P(A) |事件不发生的概率 |
| **总概率定律** | P(A) = Σ P(A|Bᵢ) × P(Bᵢ) |按互斥事件划分 |
| **贝叶斯定理** | P(A|B) = P(B|A) × P(A) / P(B) |用证据更新信念|
### 概率分布
|分销|类型 |关键参数|使用案例|
|----------|------|----------------|----------|
| **正态（高斯）** |连续 |平均值 (μ)、标准差 (σ) |自然现象、测量误差|
| **二项式** |离散| n（试验），p（概率）|成功/失败很重要|
| **泊松** |离散| λ（速率）|跨越时间/空间的罕见事件 |
| **指数** |连续 | λ（速率）|事件之间的时间 |
| **制服** |两者 | a、b（边界）|同等可能的结果 |
| **卡方** |连续 | k（自由度）|拟合优度检验 |
| **t-分布** |连续 | ν（自由度）|小样本推断 |
### 分布的关键属性
|物业 |描述 |
|----------|-------------|
| **平均值（预期值）** |分布的质心：E[X] = Σ xᵢ × P(xᵢ) |
| **方差** |围绕均值展开： Var(X) = E[(X − μ)²] |
| **标准差** |方差的平方根；与数据相同的单位 |
| **偏度** |分布不对称|
| **峰度** | “尾巴”——尾巴有多重 |

## 统计推断
### 描述性统计与推论性统计
| |描述性|推理 |
|---|-------------|-------------|
| **目的** |总结和描述数据 |从样本中得出关于总体的结论 |
| **工具** |平均值、中位数、众数、标准差、图表 |假设检验、置信区间、回归 |
| **范围** |仅您拥有的数据 |超越你的样本进行概括 |
### 假设检验框架
|步骤|描述 |
|------|-------------|
| 1. **陈述假设** |零假设（H₀）：没有影响；替代方案（H₁）：效果存在 |
| 2. **选择显着性水平** | α = 0.05（常规）|
| 3. **选择测试** |基于数据类型、样本大小和假设 |
| 4. **计算检验统计量** |取决于所选的测试 |
| 5. **查找 p 值** |如果 H₀ 为真，则观察到数据的概率 |
| 6. **做出决定** |如果 p < α，则拒绝 H₀；否则，无法拒绝 H₀ |
### 常见统计测试
|测试|何时使用 |比较什么 |
|------|-------------|-----------------|
| **t 检验** |比较 1-2 组的平均值 |将平均值分组为一个值或彼此分组 |
| **卡方检验** |分类数据|观察到的频率与预期的频率 |
| **方差分析** |比较 3 个以上组的平均值 |组间方差与组内方差 |
| **曼-惠特尼大学** | t 检验的非参数替代方案 |两组的排名分布|
| **皮尔逊相关性** |两个连续变量之间的线性关系 | r 值从 −1 到 +1 |
| **斯皮尔曼相关性** |单调关系（基于等级）|序数或非正态数据的 ρ 值 |
### 置信区间
置信区间给出了总体参数的一系列合理值：
- **平均值的 95% CI**（已知 σ）：x̄ ± 1.96 × (σ / √n)
- **解释**：“我们有 95% 的信心认为真实总体平均值位于该区间内”
- **更宽的 CI** = 更大的不确定性（更小的样本、更高的变异性或更高的置信水平）

## 回归分析
### 回归类型
|类型 |因变量|使用案例|
|------|--------------------|----------|
| **线性回归** |连续 |预测房价、销售|
| **逻辑回归** |二进制 (0/1) |分类：垃圾邮件检测、疾病诊断|
| **多项式回归** |连续（弯曲）|增长曲线，非线性趋势|
| **多元回归** |连续（2+ 个预测变量）|控制混杂因素|
| **山脊/套索** |连续（正规化）|防止过拟合，特征选择|
### 线性回归基础知识
模型：**y = β₀ + β₁x + ε**
|组件|意义|
|------------|---------|
| β₀（截距）| x = 0 时 y 的值 |
| β₁（斜率）| x 变化一单位时 y 的变化 |
| ε（误差项）|无法解释的变异 |
**关键指标：**
- **R²（决定系数）**：模型解释的方差比例（0 到 1）
- **调整 R²**：R² 因预测变量数量而受到惩罚
- **RMSE**：均方根误差 — 与 y 单位相同的平均预测误差
### 线性回归的假设
|假设|这意味着什么？如何检查 |
|------------|--------------|--------------|
| **线性** | X 和 Y 之间的关系是线性的 |散点图|
| **独立** |观察是独立的 |研究设计|
| **同方差** |残差常数方差 |剩余地块|
| **正常** |残差呈正态分布 | Q-Q 图，Shapiro-Wilk 检验 |
| **无多重共线性** |预测因子并不高度相关 | VIF（方差膨胀因子）|

## 贝叶斯统计
### 频率论与贝叶斯论
| |常客 |贝叶斯 |
|---|-------------|----------|
| **概率意味着** |长期运行频率|信念程度|
| **参数为** |已修复但未知 |具有分布的随机变量 |
| **用途** | p 值、置信区间 |后验分布，可信区间 |
| **优势** |客观、有理|结合先验知识、直观解释 |
### 贝叶斯定理的实践
**后验=（可能性×先验）/证据**
示例 — 医学检测：
- 疾病患病率：1%（之前）
- 测试灵敏度：95%（真阳性率）
- 测试特异性：90%（真阴性率）
- 如果检测呈阳性：P(疾病 | 阳性) = (0.95 × 0.01) / (0.95 × 0.01 + 0.10 × 0.99) ≈ 8.8%
这种违反直觉的结果——当疾病罕见时，大多数阳性结果都是假阳性——是**基本率谬误**，它说明了为什么贝叶斯思维很重要。

## 实用技巧
- **在运行任何统计测试之前始终可视化您的数据**
- **检查假设** - 违规可能会使结果无效
- **效果大小很重要** - 统计上显着的结果可能实际上毫无意义
- **相关性不是因果关系**——即使是很强的相关性也可能会产生混杂因素
- **多重比较** 夸大误报率 - 应用修正（Bonferroni、FDR）
- **报告置信区间**，而不仅仅是 p 值
---

## 为什么这很重要
统计学是科学研究、商业分析和机器学习的支柱。没有它，您就无法区分信号和噪声，无法识别随机波动的真实影响，也无法做出具有量化不确定性的预测。无论您是分析 A/B 测试、训练 ML 模型还是阅读研究论文，统计素养都是必不可少的。
