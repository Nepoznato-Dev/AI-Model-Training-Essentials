# 离散数学
离散数学是对从根本上可数或分离的数学结构的研究，而不是连续数学（微积分、实分析），后者处理平滑、不间断的数量。离散数学是计算机科学、密码学、算法设计和数据结构的基础。如果连续数学描述了物理世界，那么离散数学则描述了计算世界。

## 深入阐述理论
集合是几乎所有现代数学的基础。 **集合**是不同对象的无序集合，称为**元素**或**成员**。
### 公理基础 (ZFC)
现代集合论依赖于 **Zermelo-Fraenkel 公理和选择公理 (ZFC)**。这些公理通过限制集合的形成方式来解决诸如罗素悖论（“所有不包含自身的集合的集合”）之类的悖论。
|公理|非正式声明|
|--------|--------------------|
|外延性|两个集合相等当且仅当它们具有相同的元素 |
|空集|存在一个没有元素的集合： ∅ |
|配对 |对于任意a，b，存在{a，b} |
|联盟|对于任何集合族，它们的并集都存在 |
|电源组|对于任何集合S，S的所有子集的集合都存在：P(S) |
|无限|存在无限集 |
|规格|对于任何集合 A 和属性 P，存在 {x ∈ A : P(x)} |
|更换|可定义函数下的集合的形象是集合 |
|规律性|每个非空集合都包含一个与其不相交的元素（防止自成员资格）|
|选择|对于任何非空成对不相交集族，都存在选择函数 |
### 集合的基数和大小
集合的**基数**，表示为 |S|，衡量其“大小”。
|概念 |定义 |示例|
|--------|------------|---------|
|有限集 |具有自然数作为基数 | |{a,b,c}| = 3 |
|可数无穷 |与 ℕ | 相同的基数ℤ, ℚ 可数无穷 |
|不可数|大于 ℕ | ℝ, P(ℕ)，所有函数的集合 ℕ → {0,1} |
|康托尔定理 |对于任何集合 S，|P(S)| > |S| | |P(ℕ)| > |ℕ| |
**康托尔的对角论证**证明 ℝ 是不可数的：假设您可以列出 [0,1] 中的所有实数，然后构造一个与小数点后第 n 个列出的实数不同的新实数 — 矛盾。
### 集合的运算
|运营|符号|定义 |物业 |
|------------|----------|------------|----------|
|联盟| A ∪ B | {x : x Î A 或 x Î B} |交换律、结合律 |
|交叉口| A ∩ B | {x : x ∈ A 且 x ∈ B} |交换律、结合律 |
|差异|甲\乙| {x : x ∈ A 且 x ∉ B} |不可交换 |
|对称差| △B| (A \ B) ∪ (B \ A) | (A \ B) ∪ (B \ A) |交换律、结合律 |
|补充 | Aᶜ | U\A（其中U是通用集）| (Aᶜ)ᶜ = A |
|笛卡尔积|甲 × 乙 | {(a,b) : a Î A, b Î B} | |A×B| =|A| ·|B| |
**德摩根定律：**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
**包含-排除原则**（对于有限集）：
|A₁ ∪ A2 ∪ ... ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| − ... + (−1)ⁿ⁺1|A₁ ∩ ... ∩ Aₙ|

## 关系
集合 A 和 B 上的 **关系** R 是 A × B 的子集。当 (a, b) ∈ R 时，我们写为 aRb。
### 关系类型
集合 A 上的关系 R 可以具有以下属性：
|物业 |定义 |示例|
|----------|------------|---------|
|反身性| ∀a ∈ A: aRa | ≤ ℤ |
|不自反 | ∀a ∈ A: Ø(aRa) | < 上 ℤ |
|对称| ∀a,b: aRb → bRa | = 在任意集合上 |
|反对称| ∀a,b: aRb ∧ bRa → a = b | ≤ ℤ |
|及物| ∀a,b,c: aRb ∧ bRc → aRc | <、≤、= ℤ |
### 等价关系
**等价关系**是自反的、对称的和传递的。它将集合划分为不相交的**等价类**。
**示例：** 模算术。定义 a ~ b 当且仅当 a == b (mod n)。等价类为 [0], [1], ..., [n−1]，将 ℤ 分为 n 个类。
**工作示例：** 在 ℤ × ℤ 上，定义 (a,b) ~ (c,d) 当且仅当 a + d = b + c。这是一个等价关系。类 [(0,0)] = {(n,n) : n ∈ ℤ}。类 [(1,0)] = {(n+1,n) : n ∈ ℤ}。这种结构实际上定义了自然数中的整数。
### 部分订单
**偏序**是自反的、反对称的和传递的。具有偏序的集合称为**偏序集合（poset）**。
|概念 |定义 |示例|
|--------|------------|---------|
|姿势| (S, ≤) 且 ≤ 偏序 | (P(A), ⊆) — 按包含排序的子集 |
|链条|全序子集 | P({a,b,c}) 中的 {∅, {a}, {a,b}} |
|反链|没有两个元素可比较的子集 | P({a,b}) 中的 {{a}, {b}} |
|哈斯图|偏序集的视觉表示 |仅绘制边缘以覆盖关系 |
|上限 |一个元素 ≥ 子集中的每个元素 | super({2,3}) = 6 in (ℤ, \|) （整除性） |
|最小上界（sup）|最小上限 | (ℕ, ≤) 中的sup({2,3}) 是3 |
|最大下界 (inf) |最大下界 | (ℕ, \|) 中的 inf({4,6}) 为 2 |

## 函数
A **函数** f: A → B 为 A 的每个元素恰好分配 B 的一个元素。
### 函数的分类
|类型 |定义 |示例|
|------|------------|---------|
|单射（一对一）| f(a) = f(b) → a = b | f(x) = 2x 从 ℤ → ℤ |
|满射（到）| ∀b ∈ B, ∃a ∈ A: f(a) = b | f(x) = x mod 2 从 ℤ → {0,1} |
|双射|单射和满射| f(x) = x + 1 从 ℤ → ℤ |
### 重要的函数概念
|概念 |定义 |使用案例|
|---------|------------|----------|
|反函数 | f⁻¹ 存在当且仅当 f 是双射 |解密加密数据 |
|成分| (g ∘ f)(x) = g(f(x)) | (g ∘ f)(x) = g(f(x)) |链接转换 |
|恒等函数| id(x) = x |成分为中性元素|
|定点| f(x) = x | f(x) = x |递归定义、语义 |
|排列|从集合到自身的双射 |重新排列数据、改组 |
### 计数函数
给定有限集 |A| = m 和 |B| = n：
|类型 |计数|
|------|--------|
|所有功能 A → B |不 | |
|内射函数 |嗯！ / (n−m)! （如果 n ≥ m，则 0）|
|满射函数 | Σₖ₌₀ⁿ (−1)ᵏ · C(n,k) · (n−k)ᵐ（通过包含-排除）|
|双射函数|嗯！ (当 m = n 时) |

## 组合学
组合学是计算、排列和选择的数学。
### 基本计数原则
|原理|声明|示例|
|------------|------------|---------|
|总和规则 |如果 A 和 B 不相交，|A ∪ B| =|A| + |B| |选择水果：3个苹果+4个橙子=7种选择|
|产品规则| |A×B| =|A| ·|B| |服装： 3 件衬衫 × 4 条裤子 = 12 套服装 |
|双射规则 |如果 f: A → B 是双射，|A| =|B| |通过计算二进制字符串来计算子集 |
|补充 | |一个| =|U| - |Aᶜ| |将“至少一个”计为总数减去“无” |
### 排列和组合
|符号|名称 |公式|意义|
|----------|------|---------|---------|
| C(n, k) 或 (n k) |二项式系数 |嗯！ / (k!(n−k)!) |从 n 项中选择 k 项的方法（顺序无关紧要） |
| P(n, k) | P(n, k) | n | k 的排列嗯！ / (n−k)! |从 n 个项目中排列 k 个项目的方法（顺序很重要）|
|嗯！ |阶乘 | n × (n−1) × ... × 1 |排列所有 n 项的方法 |
| (n k) 重复 |多选 | C(n+k−1, k) | C(n+k−1, k) | C(n+k−1, k) |从n中选择k并允许重复|
**二项式定理：**
(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · xᵏ · yⁿ⁻ᵏ
**帕斯卡恒等式：** C(n,k) = C(n−1,k−1) + C(n−1,k)
### 鸽笼原理
**基本形式：** 如果将n+1个物体放入n个盒子中，则至少有一个盒子包含≥2个物体。
**一般形式：** 如果将N个物体放入k个盒子中，则至少有一个盒子包含≥ ⌈N/k⌉ 个物体。
**工作示例：**
1. 任意 13 人中，至少有 2 人同一出生月份。 （13 人，12 个月 → 归入档案。）
2. 证明任意 5 个整数中，存在 3 个其和能被 3 整除。
   - 考虑余数 mod 3: {0, 1, 2}。对于 5 个整数和 3 个残基类别，通过广义鸽巢，至少 ⌈5/3⌉ = 2 共享一个残基。
   - 如果 3 共享一个残基 r：它们的和 == 3r == 0 (mod 3)。
   - 如果 2 个共享残基 0 且 2 个共享残基 1：从每对中选择一个加上一个残基 0 元素 → sum == 0 (mod 3)。
3. **在CS中的应用：**任何无损压缩算法都必须扩展一些输入。 （如果每个 n 位字符串都压缩为 < n 位，则将 2ⁿ 字符串映射到少于 2ⁿ 压缩字符串 - 违反了单射性。）
### 加泰罗尼亚数字
第 n 个 **加泰罗尼亚数** Cₙ = C(2n, n) / (n+1) 计数：
|结构|示例|
|------------|---------|
|有效的括号序列 | ()(), (()) 对于 n = 2 |
|具有 n 个内部节点的二叉树 | n = 2 时有 2 棵树 |
|不穿过对角线的路径 |从 (0,0) 到 (n,n) 的网格路径保持低于 y = x |
|多边形的三角剖分|将 (n+2) 边形划分为三角形的方法 |
前几个：C₀ = 1、C₁ = 1、C2 = 2、C₃ = 5、C₄ = 14、C₅ = 42。
递归式： Cₙ₊₁ = Σᵢ₌₀ⁿ Cᵢ · Cₙ₋ᵢ

## 递归关系
**递归关系**将序列的每一项定义为前一项的函数。
### 类型和解决方案
|类型 |表格 |解决方法|
|------|------|-----------------|
|线性齐次（常数系数）| aₙ = c₁aₙ₋₁ + c2aₙ₋2 + ... + cₖaₙ₋ₖ |特征方程|
|线性非齐次 | aₙ = c₁aₙ₋₁ + ... + f(n) |特定溶液+均质溶液 |
|分而治之 | T(n) = aT(n/b) + f(n) | T(n) = aT(n/b) + f(n) |主定理|
### 特征方程法
对于aₙ=c₁aₙ₋₁+c2aₙ₋，形成特征方程：
r2−c₁r−c2=0
|案例 |根|通用解决方案|
|------|------|------------------|
|两个不同的实根 r₁, r2 | r₁ ≠ r2 | aₙ = A·r₁ⁿ + B·r2ⁿ |
|重复根 r | r₁ = r2 = r | aₙ = (A + Bn)·rⁿ |
|复数根 α ± βi |转换为极坐标： r·e^(±iθ) | aₙ = rⁿ(A cos(nθ) + B sin(nθ)) |
**工作示例：** 斐波那契数列 Fₙ = Fₙ₋₁ + Fₙ₋2，F₀ = 0，F₁ = 1。
- 特征方程：r² − r − 1 = 0
- 根：r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618, ψ = (1−√5)/2 ≈ −0.618
- 通解：Fₙ = A·φⁿ + B·ψⁿ
- 根据初始条件：A = 1/√5，B = −1/√5
- **闭合形式：** Fₙ = (φⁿ − ψⁿ) / √5 （比奈公式）
### 主定理
对于 T(n) = aT(n/b) + f(n) 形式的递归，其中 a ≥ 1，b > 1：
令 c = log_b(a)。
|案例 |状况 |解决方案 |
|------|------------|----------|
| 1 | f(n) = O(nᵈ) 其中 d< c | T(n) = Θ(nᶜ) |
| 2 | f(n) = Θ(nᶜ) | T(n) = Θ(nᶜ log n) |
| 3 | f(n) = Θ(nᵈ) where d >c，并且 af(n/b) ≤ kf(n) 对于某些 k < 1 | T(n) = θ(nᵈ) | T(n) = θ(nᵈ) |
**示例：**
- 归并排序：T(n) = 2T(n/2) + O(n)。这里a=2，b=2，c=1，f(n)=n=θ(n1)。情况 2：T(n) = θ(n log n)。
- 二分查找：T(n) = T(n/2) + O(1)。这里a=1，b=2，c=0，f(n)=1=θ(n⁰)。情况 2：T(n) = θ(log n)。

## 生成函数
**生成函数**将序列 (aₙ) 编码为形式幂级数的系数。
### 类型
|类型 |表格 |使用案例|
|------|------|----------|
|普通 (OGF) | G(x) = Σₙ₌₀^∞ aₙxⁿ |未标记的结构、组合物 |
|指数 (EGF) | E(x) = Σₙ₌₀^∞ aₙxⁿ/n！ |标记结构、排列 |
### 常用生成函数
|序列 aₙ | OGF G（x）|
|------------|------------|
| 1, 1, 1, 1, ... | 1/(1−x) | 1/(1−x) |
| 1, 2, 3, 4, ... | 1/(1−x)² | 1/(1−x)² |
| 1、r、r2、r3、... | 1/(1−rx) | 1/(1−rx) |
| C(n,k) 对于固定 k | xᵏ/(1−x)ᵏ⁺¹ |
|斐波那契 Fₙ | x/(1−x−x²) | x/(1−x−x²) |
|加泰罗尼亚语 Cₙ | (1 − √(1−4x)) / (2x) | (1 − √(1−4x)) / (2x) |
### 使用生成函数解决递归问题
**工作示例：** 求解 aₙ = 3aₙ₋₁ − 2aₙ₋2，a₀ = 1，a₁ = 3。
1. 设 G(x) = Σ aₙxⁿ。
2. 根据递推式： G(x) − a₀ − a₁x = 3x(G(x) − a₀) − 2x²G(x)
3. 代入： G(x) − 1 − 3x = 3x(G(x) − 1) − 2x²G(x)
4. G(x)(1 − 3x + 2x²) = 1
5. G(x) = 1 / (1 − 3x + 2x²) = 1 / ((1−x)(1−2x))
6. 部分分数：G(x) = 2/(1−2x) − 1/(1−x)
7. 提取系数：aₙ = 2·2ⁿ − 1 = 2ⁿ⁺1 − 1
**验证：** a₀ = 2−1 = 1，a₁ = 4−1 = 3，a2 = 8−1 = 7。检查：3(3) − 2(1) = 7。

## 布尔代数和命题逻辑
布尔代数是两个真值的代数：**True (1)** 和 **False (0)**。它是数字电路、数据库查询和编程条件的数学基础。
### 运营和法律
|运营|符号|意义|真值表|
|------------|--------|---------|-------------|
|和| p ∧ q |仅当两者都为真时才为真 | T∧T=T，T∧F=F，F∧T=F，F∧F=F |
|或 | p ∨ q |当至少有一个为真时为真 | T∨T=T，T∨F=T，F∨T=T，F∨F=F |
|不 | Øp |否定| ØT=F，ØF=T |
|异或| p ⊕ q |当恰好有一个为真时为真 | T⊕T=F，T⊕F=T，F⊕T=T，F⊕F=F |
|意味着 | p → q |仅当 p=T 且 q=F 时为 False | T→T=T，T→F=F，F→T=T，F→F=T |
|双条件| p ↔ q |当两者具有相同值时为真 | T↔T=T，T↔F=F，F↔T=F，F↔F=T |
### 关键布尔恒等式
|法律|公式|
|-----|--------|
|交换律 | p ∧ q = q ∧ p； p ∨ q = q ∨ p |
|关联性| (p ∧ q) ∧ r = p ∧ (q ∧ r) |
|分配率| p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) |
|德摩根定律 | Ø(p ∧ q) = Øp ∨ Øq; Ø(p ∨ q) = Øp ∧ Øq |
|双重否定| Ø(Øp) = p |
|幂等性 | p ∧ p = p； p ∨ p = p |
|吸收| p ∨ (p ∧ q) = p; p ∧ (p ∨ q) = p |
|反证| (p → q) ≡ (Øq → Øp) |
### 范式
|表格 |结构|使用案例|
|------|------------|----------|
|连接范式 (CNF) | OR 的与： (A∨B) ∧ (C∨D) | SAT 求解器，解析定理证明 |
|析取范式 (DNF) | AND 的或： (A∧B) ∨ (C∧D) |电路设计，基于规则的系统|
**转换为 CNF：** 应用德摩根定律，将 OR 分配给 AND，消除双重否定。

## 模算术和同余
模算术研究“除法余数”运算下的整数。它对于密码学、散列和数论至关重要。
### 核心定义
|概念 |符号|定义 |
|---------|----------|------------|
|一致性| a == b (mod n) | a == b (mod n) | n 除 (a − b) |
|残留类| [一]ₙ |集合 {a + kn : k ∈ ℤ} |
|模逆| a⁻¹ mod n |值 x 使得 ax == 1 (mod n) |
|欧拉方程 | φ(n) |与 n 互质的 {1,...,n} 中的整数计数 |
### 关键属性
|物业 |声明|
|----------|----------|
|加法 |如果 a == b 且 c == d (mod n)，则 a+c == b+d (mod n) |
|乘法|如果 a == b 且 c == d (mod n)，则 ac == bd (mod n) |
|费马小定理 |如果 p 是素数且 gcd(a,p) = 1，则 aᵖ⁻¹ ≡ 1 (mod p) |
|欧拉定理|如果 gcd(a,n) = 1，则 a^φ(n) == 1 (mod n) |
|中国剩余定理|如果 gcd(m,n) = 1，则系统 x == a (mod m), x == b (mod n) 有唯一解 mod mn |
### 计算欧拉 Totient
对于 n = p₁^a₁·p2^a2·...·pₖ^aₖ（质因数分解）：
φ(n) = n·(1−1/p₁)·(1−1/p2)·...·(1−1/pₖ)
**示例：** φ(12) = 12 · (1 − 1/2) · (1 − 1/3) = 12 · 1/2 · 2/3 = 4。事实上，{1, 5, 7, 11} 与 12 互质。
### 应用：RSA 加密（概述）
1. 选择大素数p、q。计算 n = pq，φ(n) = (p−1)(q−1)。
2. 选择 e 使得 gcd(e, φ(n)) = 1（公共指数）。
3. 计算 d eq e⁻1 (mod φ(n))（私有指数）。
4. 加密：c = mᵉ mod n。解密：m = cᵈ mod n。
5. 安全性依赖于因式分解 n 来求 p 和 q 的难度。

## 数学归纳法
**数学归纳法**是所有自然数陈述的主要证明技术。
### 归纳证明的结构
1. **基本情况：** 证明 n = 0（或 n = 1）的陈述。
2. **归纳步骤：** 假设该命题对于 n = k（归纳假设）成立，然后证明 n = k + 1。
### 变体
|变体 |何时使用 |
|---------|-------------|
|简单归纳|证明 P(k) → P(k+1) |
|强感应|假设 P(0), P(1), ..., P(k) 证明 P(k+1) |
|结构归纳|证明递归定义的结构（树、公式）的属性 |
|超限归纳 |将归纳法扩展到 ℕ | 之外的良序集合
**工作示例（强归纳法）：** 证明每个整数 n ≥ 2 都可以写成素数的乘积。
- 基数：n = 2 是素数，因此它是素数（本身）的乘积。
- 归纳步骤：假设从 2 到 k 的所有整数都为 true。考虑k+1。
  - 如果 k+1 是质数，完成。
  - 如果 k+1 是合数，则 k+1 = ab，其中 2 ≤ a，b ≤ k。根据归纳假设，a 和 b 都是素数的乘积，因此 k+1 是素数的乘积。

离散数学提供了用于推理有限或可数结构的语言和工具——这正是计算机所操纵的。每个算法、数据结构、数据库查询和加密协议都建立在离散的基础上。掌握这些主题可以提高解决问题的能力，并为算法、复杂性理论和机器学习的高级研究提供词汇。
