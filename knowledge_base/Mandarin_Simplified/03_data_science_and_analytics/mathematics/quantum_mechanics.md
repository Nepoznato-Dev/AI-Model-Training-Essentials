# 量子力学
量子力学是最小尺度的物理理论——原子、电子、光子和自然界的基本粒子。它用概率、叠加和纠缠取代了经典力学的确定性世界。尽管量子力学具有违反直觉的性质，但它是所有科学中经过最精确检验的理论。如今，它的原理正与量子计算机的计算直接相关，量子计算机有望比传统计算机以指数速度更快地解决某些问题。

## 波粒二象性
### 德布罗意波长
每个动量为 p 的粒子都有一个相关的波长：
λ = h/p = h/(mv)
|粒子|典型 λ |可观察到的波浪行为？ |
|----------|----------|----------------------------|
|电子（100 eV）| 0.12纳米|是（晶体衍射）|
|质子 | 0.003纳米|是（中子散射）|
|棒球 (40 m/s) | 10⁻3⁴米|否（太小而无法检测到）|
### 双缝实验
典型的量子实验：
1. 在两个狭缝中一次发射一个粒子（电子、光子）
2. 每个粒子落在探测器上的一个点上
3. 随着时间的推移，会出现干涉图案——就好像每个粒子同时通过两个狭缝
4. 如果测量粒子穿过哪个狭缝，干涉图案就会消失
**结论：** 量子物体既不是纯粹的粒子，也不是纯粹的波。它们在未观察到时表现出波状行为，在测量时表现出粒子状行为。

## 波函数
＃＃＃ 定义
**波函数** ψ(x, t) 完整地描述了一个量子系统。它是一个复值函数，其平方模给出了概率密度：
P(x) = |ψ(x)|² = ψ*(x)ψ(x)
### 标准化
总概率必须等于 1：
∫ |ψ(x)|² dx = 1（在所有空间上）
### 天生法则
找到 x 和 x + dx 之间粒子的概率：
P(x 至 x+dx) = |ψ(x)|² dx
对于具有本征态 φₙ 的一般可观测量：
P(测量特征值aₙ) = |⟨φₙ|ψ⟩|²

## 薛定谔方程
### 瞬态薛定谔方程
iℏ ∂ψ/∂t = Ĥψ
其中 Ĥ 是 **哈密尔顿算子**（总能量算子）。
### 与时间无关的薛定谔方程
对于稳态（能量本征态）：
ψ = Eψ
这是一个特征值方程：允许的能量 E 是 Ĥ 的特征值。
### 盒中粒子（无限方井）
最简单的量子系统：粒子限制在 0 < x < L。
|数量 |结果 |
|----------|--------|
|波函数| ψₙ(x) = √(2/L) sin(nπx/L) |
|能量水平| Eₙ = n²π²ℏ²/(2mL²) = n²h²/(8mL²) |
|基态| n = 1，E₁ = h²/(8mL²) |
|零点能量| E₁ > 0（粒子不能完全静止）|
|量子数| n = 1, 2, 3, ...（仅限正整数）|
### 量子谐波振荡器
V(x) = ½mω²x²
|数量 |结果 |
|----------|--------|
|能量水平| Eₙ = (n + ½)ℏω |
|零点能量| E₀ = ½ℏω |
|间距| ΔE = ℏω（均匀）|
|波函数|厄米多项式 × 高斯 |

## 运算符和可观察量
在量子力学中，每个物理可观察量都对应于一个**厄米算子**。
### 关键操作员
|可观察|运算符（位置空间）|特征值 |
|------------|------------------------|-------------|
|职位| x̂ = x |全部真实x|
|势头| p̂ = −iℏ ∂/∂x |全部真实p |
|能量（哈密尔顿）| Ĥ = −(ℏ²/2m)∂²/∂x² + V(x) | Eₙ（束缚态的离散）|
|角动量| L̂ = r × p̂ | ℏ√(l(l+1)) |
|旋转| Ŝ = (ℏ/2)σ（泡利矩阵）| ±ℏ/2（对于旋转 1/2）|
### 期望值
状态 ψ 上测量可观测 A 的平均结果：
⟨A⟩ = ⟨ψ|Â|ψ⟩ = ∫ ψ*(x) ψ(x) dx
### 交换关系
[，B̂] = B̂ − B̂
|换向器|结果 |意义 |
|------------|--------|-------------|
| [x̂, p̂] |我ℏ |位置和动量是不相容的|
| [L̂ₓ，L̂ᵧ] | iℏL̂_z |角动量分量不相容 |
| [σ̂ₓ, σ̂ᵧ] | 2iσ̂_z |泡利矩阵（自旋分量）|
如果 [Â, B̂] = 0，则可以同时测量可观测量（共享本征态）。

## 不确定性原理
### 海森堡测不准原理
Δx·Δp≥ℏ/2
更一般地，对于任意两个可观察量 A 和 B：
ΔA · ΔB ≥ (1/2)|⟨[,B̂]⟩|
### 不确定性关系
|配对|关系 |解读|
|------|----------|----------------|
|位置动量| ΔxΔp ≥ ℏ/2 |无法准确了解两者 |
|能源时代| ΔEΔt ≥ ℏ/2 |短暂的状态具有不确定的能量|
|角动量| ΔLₓΔLᵧ ≥ (ℏ/2)\|⟨L_z⟩\| |无法同时知道所有组件 |
**重要提示：** 不确定性与测量干扰无关——它是量子态的基本属性。粒子不会同时具有确定的位置和动量。

## 量子态和叠加
### 狄拉克表示法 (Bra-Ket)
|符号|名称 |意义|
|--------|------|---------|
| \|ψ⟩ |凯特 |状态向量（列向量）|
| ⟨ψ\| |文胸 |共轭转置（行向量）|
| ⟨φ\|ψ⟩ |内积 | ψ 状态下的振幅 |
| \|ψ\|² |范数平方 |概率|
### 叠加原理
如果 \|ψ₁⟩ 和 \|ψ2⟩ 是有效的量子态，则任何线性组合也是有效的：
\|ψ⟩ = α\|ψ₁⟩ + β\|ψ₂⟩

其中 |α|² + |β|² = 1（归一化）。
**测量：** 测量时，系统以 |α|2 的概率“崩溃”到 \|ψ₁⟩ 或以 |β|2 的概率“崩溃”到 \|ψ2⟩。
### 量子位
**量子位**是一个量子位：一个两级量子系统。
\|ψ⟩ = α\|0⟩ + β\|1⟩，其中 |α|² + |β|² = 1
|代表| \|0⟩ | \|1⟩ |
|----------------|------|------|
|旋转|旋转起来 ↑ |向下旋转 ↓ |
|光子偏振|卧式|垂直|
|能量水平|基态|兴奋状态|
|电路| \|0⟩ = [1, 0]ᵀ | \|1⟩ = [0, 1]ᵀ |
**布洛赫球体：**任何量子位状态都可以写成：
\|ψ⟩ = cos(θ/2)\|0⟩ + e^{iφ} sin(θ/2)\|1⟩
其中 θ ε [0, π] 且 φ ε [0, 2π)。状态空间是一个球体。

## 纠缠
当两个量子位的联合状态无法写为各个状态的乘积时，它们就被**纠缠**。
### 贝尔状态（最大纠缠）
|状态 |表达 |名称 |
|--------|------------|------|
| \|Φ⁺⟩ | (1/√2)(\|00⟩ + \|11⟩) |贝尔州|
| \|Φ⁻⟩ | (1/√2)(\|00⟩ − \|11⟩) |贝尔州|
| \|Ψ⁺⟩ | (1/√2)(\|01⟩ + \|10⟩) |贝尔州|
| \|Ψ⁻⟩ | (1/√2)(\|01⟩ − \|10⟩) |单线态|
### 纠缠的性质
|物业 |描述 |
|----------|-------------|
|相关性|无论距离如何，测量一个量子位即可立即确定另一个量子位 |
|没有沟通|无法单独使用纠缠来以比光更快的速度发送信息 |
|一夫一妻制 |如果A与B最大程度地纠缠，则它不能与C纠缠 |
|脆弱性|与环境的相互作用破坏了纠缠（退相干） |
### EPR 悖论和贝尔定理
爱因斯坦、波多尔斯基和罗森认为量子力学一定是不完备的（隐变量）。贝尔表明，任何局部隐变量理论都满足某些不等式。实验违反了贝尔不等式——证实了量子力学并排除了局部隐变量。

## 量子门
量子门是量子位上的酉运算。
### 单量子位门
|门 |矩阵|效果|
|------|--------|--------|
| **泡利-X**（不）| [[0,1],[1,0]] |位翻转：\|0⟩↔\|1⟩|
| **泡利-Y** | [[0,−i],[i,0]] |位+相位翻转|
| **泡利-Z** | [[1,0],[0,−1]] |相位翻转： \|1⟩ → −\|1⟩ |
| **阿达玛** (H) | (1/√2)[[1,1],[1,−1]] | (1/√2)[[1,1],[1,−1]] |创建叠加： \|0⟩ → (\|0⟩+\|1⟩)/√2 |
| **阶段** (S) | [[1,0],[0,i]] |绕 Z 旋转 π/2 |
| **T型门** | [[1,0],[0,e^{iπ/4}]] |绕 Z 旋转 π/4 |
| **旋转** Rₓ(θ) | cos(θ/2)I − i sin(θ/2)σₓ |绕 X 轴旋转 θ |
### 二量子位门
|门 |描述 |效果|
|------|-------------|--------|
| **中国不** |受控-NOT |如果控制为 \|1⟩ | 则翻转目标
| **捷克** |受控-Z |如果控制为 \|1⟩ |，则将 Z 应用于目标
| **交换** |交换量子比特 | \|ab⟩ → \|ba⟩ |
### 创造纠缠
将 H 应用于量子位 1，然后以量子位 1 作为控制进行 CNOT：
\|00⟩ → (H⊗I)\|00⟩ → CNOT → (1/√2)(\|00⟩ + \|11⟩) = \|Φ⁺⟩
