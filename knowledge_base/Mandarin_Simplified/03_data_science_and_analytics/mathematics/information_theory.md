# 信息论
信息论由克劳德·香农 (Claude Shannon) 于 1948 年创立，对信息本身进行量化。一条消息能告诉你多少信息？您可以将数据压缩到什么程度？在嘈杂的信道上您的通信速度有多快？这些问题都有精确的数学答案。除了通信之外，信息论已经成为机器学习的基础——交叉熵是分类的默认损失函数，KL 散度衡量分布相似性，互信息驱动特征选择。
---

## 熵
**熵**衡量随机变量的平均不确定性或“意外”。
### 香农熵（离散）
对于具有概率质量函数 p(x) 的离散随机变量 X：
H(X) = −Σₓ p(x) log2 p(x)
单位：**位**（使用 log2 时）或 **nats**（使用 ln 时）。
|分销|熵 |直觉|
|------------|---------|------------|
|公平币 (p = 0.5, 0.5) | 1 位 |二元结果的最大不确定性|
|有偏差的硬币 (p = 0.9, 0.1) | 0.469 位 |不那么令人惊讶——大部分都是正面|
|确定性 (p = 1, 0) | 0 位 |完全没有不确定性|
|公平模具（6 面）| 2.585 位 |更多结果 = 更多不确定性 |
|统一 n 个结果 | log2(n) 位 | n 个结果的最大熵 |
### 熵的性质
|物业 |声明|
|----------|------------|
|非负性| H(X) ≥ 0 |
|最大| H(X) ≤ log2(\|X\|) 且均匀分布相等 |
|链式法则| H(X, Y) = H(X) + H(Y \| X) | H(X, Y) = H(X) + H(Y \| X) |
|调节减少| H(X \| Y) ≤ H(X) | H(X \| Y) ≤ H(X) |
|凹度| H 是概率分布的凹函数 |
### 微分熵（连续）
对于密度为 p(x) 的连续随机变量 X：
h(X) = −∫ p(x) log p(x) dx
与离散熵不同，微分熵可以是**负**。
|分销|微分熵|
|----------|------------------------|
| [a,b] 上的制服 |日志（b - a）|
|正态 N(μ, σ²) | (1/2) log(2πeσ²) | (1/2) log(2πeσ²) |
|指数(λ) | 1 − ln(λ) | 1 − ln(λ) |

## 联合信息、条件信息和互信息
### 联合熵
H(X, Y) = −Σₓ Σᵧ p(x, y) log p(x, y)
测量对 (X, Y) 的总不确定性。
### 条件熵
H(Y | X) = −Σₓ Σᵧ p(x, y) log p(y | x) = H(X, Y) − H(X)
测量观察 X 后 Y 的剩余不确定性。
### 互信息
I(X; Y) = Σₓ Σᵧ p(x, y) log [p(x, y) / (p(x)p(y))]
衡量 X 对 Y 的了解有多少（反之亦然）。
|物业 |声明|
|----------|------------|
|非负性| I(X;Y) ≥ 0 |
|对称性| I(X; Y) = I(Y; X) | I(X; Y) = I(Y; X) |
|与熵的关系 | I(X; Y) = H(X) − H(X \| Y) = H(Y) − H(Y \| X) |
|与关节的关系 | I(X;Y) = H(X) + H(Y) − H(X, Y) |
|独立| I(X; Y) = 0 当且仅当 X 和 Y 独立 |
|自我信息 | I(X;X) = H(X) | I(X;X) = H(X) |
### 视觉：熵图
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## KL 散度
**Kullback-Leibler (KL) 散度**衡量一种分布与另一种分布的差异程度。
D_KL(P || Q) = Σₓ P(x) log [P(x) / Q(x)]
|物业 |声明|
|----------|------------|
|非负性| D_KL(P \|\| Q) ≥ 0（吉布斯不等式）|
|身份 | D_KL(P \|\| Q) = 0 当且仅当 P = Q |
|不对称|一般而言，D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) |
|不是一个指标 |对称性和三角不等式失败 |
**解释：** D_KL(P || Q) 是使用针对 Q 优化的代码对 P 中的数据进行编码所需的额外位数。
### 与其他数量的关系
|关系 |公式|
|-------------|---------|
|交叉熵 | H(P, Q) = H(P) + D_KL(P \|\| Q) |
|互信息| I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
|有条件 KL | D_KL(P(Y\|X) \|\| Q(Y\|X)) X | 上的平均值

## 交叉熵
分布 P 和 Q 之间的 **交叉熵**：
H(P, Q) = −Σₓ P(x) log Q(x) = H(P) + D_KL(P || Q)
### 交叉熵作为损失函数
在分类中，P 是真实分布（one-hot 编码标签），Q 是模型的预测分布。
**二元交叉熵（BCE）：**
L = −[y log(ŷ) + (1−y) log(1−ŷ)]
**分类交叉熵：**
L = −Σᵢ yᵢ log(ŷᵢ)
|场景| y（真）| ŷ（预测）|损失|
|----------|----------|----------------|------|
|正确、自信| 1 | 0.95 | 0.95 0.051 | 0.051
|正确，不确定 | 1 | 0.55 | 0.55 0.598 | 0.598
|错了，自信| 1 | 0.05 | 0.05 2.996 | 2.996
|错误，不确定| 1 | 0.45 | 0.45 0.799 | 0.799
最小化交叉熵相当于最小化与真实分布的 KL 散度——这就是它作为损失函数效果如此良好的原因。

## 通道容量
### 沟通渠道模型
```
X → [Channel] → Y
```

- X：输入随机变量
- Y：输出随机变量
- 通道：由条件概率 p(y|x) 定义
### 香农的噪声信道编码定理
对于容量为C的信道，如果传输速率为R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C，则可靠通信是不可能的。
**通道容量：**
C = max_{p(x)} I(X; Y)
### 重要频道示例
|频道|描述 |产能 |
|---------|-------------|----------|
| **二元对称 (BSC)** |以概率 p | 翻转每一位1 − H(p) 位 |
| **二进制擦除（BEC）** |以概率 ε 擦除每一位 | 1 − ε 位 |
| **高斯 (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)log(1 + SNR) 位 |
| **无噪音二进制** |完美传输 | 1 位 |

## 源代码编码和压缩
### 源代码定理
对源进行编码所需的平均位数受其熵限制：
L≥H(X)
最优代码实现 L ≈ H(X)。
### 霍夫曼编码
**无前缀**代码，将较短的代码分配给更可能的符号。
|符号|概率|霍夫曼代码|长度 |
|--------|-------------|-------------|--------|
|一个 | 0.5 | 0.5 0 | 1 |
|乙| 0.25 | 0.25 10 | 10 2 |
| C | 0.125 | 0.125 110 | 110 3 |
| d | 0.125 | 0.125 111 | 111 3 |
平均长度：0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 位/符号
熵：H = 1.75 位/符号（本例中最佳！）
### 无损压缩与有损压缩
|类型 |原理|示例 |限制|
|------|------------|----------|--------|
| **无损** |消除统计冗余 |邮政编码、PNG、FLAC |熵率 H(X) |
| **有损** |删除感知上不相关的信息 | JPEG、MP3、H.264 |率失真函数 R(D) |
**速率失真理论：** 对于具有最大失真 D 的有损压缩，最小速率为 R(D) = min I(X; X̂)，且满足 E[d(X, X̂)] ≤ D。

## 与其他字段的连接
### 信息论和热力学
|概念 |信息论|热力学|
|--------------------|--------------------------------|----------------|
|熵 |香农熵 H(X) |玻尔兹曼熵 S = k_B ln W |
|最大熵 |均匀分布|热平衡|
| KL 散度 |分布差异|自由能差|
|互信息|共享信息|物理系统中的相关性|
数学形式是相同的——香农故意借用了统计力学中的“熵”一词。
### 信息论与统计学
|概念 |应用 |
|---------|-------------|
|最大似然|相当于最小化从经验分布到模型分布的 KL 散度 |
|费舍尔资讯| KL散度的曲率；估计方差的下界 (Cramér-Rao) |
|最小描述长度 (MDL) |通过最小化总编码长度来选择模型 |
| AIC/BIC |基于 KL 的近似模型选择标准 |

|数量 |公式（离散）|意义|
|----------|--------------------|---------|
|熵 H(X) | −Σ p(x) log p(x) |平均不确定性|
|联合熵 H(X,Y) | −Σ p(x,y) log p(x,y) | −Σ p(x,y) log p(x,y) |配对的总不确定性 |
|条件熵 H(Y\|X) | H(X,Y) − H(X) | H(X,Y) − H(X) |给定 X | Y 的剩余不确定性

| KL 散度 D_KL(P\|\|Q) | Σ P(x) log(P(x)/Q(x)) |分布之间的“距离”|
|交叉熵 H(P,Q) | −Σ P(x) log Q(x) |使用错误分布的编码成本 |
|通道容量C|最大 I(X;Y) |最大可靠通信速率 |
信息论提供了可学习、压缩和交流的基本限制。对于机器学习从业者来说，它解释了为什么交叉熵作为损失函数，如何衡量学习表示的质量，以及如何考虑模型复杂性和数据拟合之间的权衡。香农 1948 年的见解至今仍然与现代人工智能和电信息息相关。
