# 经典力学
经典力学描述了物体在力的影响下的运动。从下落的苹果到绕轨道运行的行星，从振动的弦到碰撞的粒子，它的原理支配着宏观世界。除了物理应用之外，经典力学还催生了变分法、辛几何以及支撑量子力学和现代优化的哈密顿框架。
---

## 牛顿力学
### 牛顿三定律
|法律|声明|数学形式|
|-----|---------|--------------------|
| **第一（惯性）** |除非受到力的作用，否则物体保持静止或匀速运动 |如果 F_net = 0，则 v = 常数 |
| **第二（F = ma）** |力等于质量乘以加速度 | **F** = m**a** = m(d²**x**/dt²) |
| **第三（动作-反应）** |每个动作都会产生大小相等、方向相反的反应 | **F**₁2 = -**F**2₁ |
### 自由体图
**自由体图**隔离一个物体并显示作用在其上的所有力。
**共同力量：**
|力|公式|方向 |
|--------|---------|------------|
|重力（近地球）| F = 毫克 |向下|
|法向力|尼 |垂直于表面 |
|摩擦力（静态）| f_s ≤ μ_s N |反对即将发生的议案 |
|摩擦力（动能）| f_k = μ_k N |反对议案 |
|弹簧（胡克定律）| F = −kx |恢复（趋向平衡）|
|紧张| T |沿着绳子/绳子|
|拖动 | F_d = ½C_d ρAv² |反对速度 |
### 示例：斜坡上的方块
质量为 m 的木块位于角度为 θ 的无摩擦斜面上。
- 力：重力（毫克向下）、法向力（N 垂直于表面）
- 分解重力：mg sin θ（沿斜坡），mg cos θ（进入表面）
- N = mg cos θ（垂直于表面无运动）
- 沿斜坡的加速度：a = g sin θ

## 能量方法
### 功和动能
**功** 由力完成：W = ∫ **F** · d**r**
**功能量定理：** W_net = ΔKE = ½mv²² − ½mv₁²
### 势能
|力|势能|笔记|
|--------|-----------------|--------|
|重力（近表面）| U = 毫克 | h = 参考高度以上 |
|重力（一般）| U = −GMm/r |无穷远为零|
|春天| U = ½kx² | x = 平衡位移 |
|静电| U = kq₁q2/r |类似电荷：正U|
### 节约能源
如果只有保守力起作用：E = KE + PE = 常数
½mv₁² + U₁ = ½mv²² + U²
**工作示例：** 球从高度 h 落下。
- 初始：KE = 0，PE = mgh
- 即将落地之前：KE = ½mv²，PE = 0
- 守恒：mgh = ½mv² → v = √(2gh)
＃＃＃ 力量
P = dW/dt = **F** · **v**（做功率）

## 动量和碰撞
### 线性动量
**p** = m**v**
牛顿第二定律（替代形式）： **F** = d**p**/dt
### 动量守恒
如果没有外力：总动量守恒。
|碰撞类型| KE 保守吗？ |动量守恒？ |
|--------------|--------------|----------|
| **有弹性** |是的 |是的 |
| **无弹性** |没有 |是的 |
| **完全无弹性** |否（最大损失）|是（物体粘在一起）|
**一维弹性碰撞：** 两个质量 m₁、m2，初始速度为 u₁、u2：
- v₁ = ((m₁−m2)u₁ + 2m2u2) / (m₁+m2)
- v2 = ((m2−m₁)u2 + 2m₁u₁) / (m₁+m2)
### 角动量
**L** = **r** × **p** = m(**r** × **v**)
扭矩：**τ** = d**L**/dt = **r** × **F**
**守恒：** 如果没有外部扭矩，角动量守恒。

## 拉格朗日力学
**拉格朗日**公式用能量代替力，提供了一个更优雅和通用的框架。
### 拉格朗日
L = T − V（动能减去势能）
### 最小作用原理（汉密尔顿原理）
系统在时间 t₁ 和 t2 之间所采取的实际路径最小化（更准确地说，使静止）**动作**：
S = ∫_{t₁}^{t2} L(q, q̇, t) dt
### 欧拉-拉格朗日方程
条件 δS = 0 得出：
d/dt(∂L/∂q̇) − ∂L/∂q = 0
对于每个广义坐标 q。
**工作示例：** 简单摆（长度 l，质量 m，与垂直方向的角度 θ）。
- T = ½ml²θ̇²
- V = −mgl cos θ
- L = ½ml²θ̇² + mgl cos θ
- ∂L/∂θ = −mgl sin θ
- ∂L/∂θ̇ = ml²θ̇ → d/dt(∂L/∂θ̇) = ml²θ̈
- 欧拉-拉格朗日：ml²θ̈ + mgl sin θ = 0 → θ̈ + (g/l) sin θ = 0
### 拉格朗日力学的优点
|优势 |说明|
|------------|-------------|
|坐标独立 |适用于任何坐标系 |
|自然地处理约束 |无需计算约束力 |
|对称→守恒|诺特定理将对称性与守恒量联系起来 |
|轻松概括 |到场、相对论、量子力学 |
---

## 哈密顿力学
**哈密尔顿**公式是拉格朗日力学的重新公式，它使用位置和动量（而不是位置和速度）。
### 哈密顿量
H = Σᵢ pᵢq̇ᵢ − L = T + V（对于大多数机械系统）
其中 pᵢ = ∂L/∂q̇ᵢ 是**广义动量**。
### 汉密尔顿方程
q̇ᵢ = ∂H/∂pᵢ
ṗᵢ = −∂H/∂qᵢ
这些是 2n 个一阶 ODE（相对于 n 个二阶欧拉-拉格朗日方程）。
**工作示例：** 谐波振荡器（质量 m，弹簧常数 k）。
- H = p²/(2m) + ½kx²
- ẋ = ∂H/∂p = p/m → p = mẋ （如预期）
- ṗ = −∂H/∂x = −kx → mẍ = −kx （胡克定律）
### 泊松括号
对于函数 f(q, p) 和 g(q, p)：
{f, g} = Σᵢ (∂f/∂qᵢ · ∂g/∂pᵢ − ∂f/∂pᵢ · ∂g/∂qᵢ)
|物业 |声明|
|----------|------------|
|时间演变| df/dt = {f, H} + ∂f/∂t |
|保护| f 是守恒的当且仅当 {f, H} = 0（并且 ∂f/∂t = 0）|
|基本括号| {qᵢ, pⱼ} = δᵢⱼ, {qᵢ, qⱼ} = 0, {pᵢ, pⱼ} = 0 |
**与量子力学的联系：** 泊松括号成为交换子：{f, g} → (1/iℏ)[f̂, ĝ]

## 守恒定律和诺特定理
### 诺特定理
拉格朗日量的每个连续对称性都对应于一个守恒量。
|对称性|保守数量 |
|----------|--------------------|
|时间平移不变性 |能源|
|空间平移不变性 |线性动量|
|旋转不变性|角动量|
|规格不变性 |电荷 |
这是所有物理学中最深刻的结果之一——它将时空几何与基本守恒定律联系起来。

## 刚体动力学
**刚体**是所有内部距离保持固定的物体。
### 关键概念
|概念 |公式|描述 |
|---------|---------|-------------|
| **转动惯量** | I = Σmᵢrᵢ² 或 I = ∫r² dm |抗旋转加速度|
| **旋转KE** | KE = ½Iω² |旋转能量|
| **角动量** | L = Iω | p = mv | 的旋转模拟
| **扭矩** | τ = Iα | F = ma | 的旋转模拟
### 转动惯量（常见形状）
|形状|轴|我|
|--------|------|---|
|实心球|通过中心| (2/5)MR² |
|空心球|通过中心| (2/3)MR² |
|实心圆柱|沿轴| (1/2)MR² |
|细棒|通过中心，垂直 | (1/12)ML² |
|细棒|通过端部，垂直| (1/3)ML² |
|光盘|通过中心，垂直| (1/2)MR² |

## 轨道力学
### 开普勒定律
|法律|声明|
|-----|------------|
| **第一个（省略号）** |行星绕椭圆运动，太阳位于一个焦点 |
| **第二（等面积）** |从太阳到行星的直线在相同的时间内扫过相同的面积|
| **三次（谐波）** | T² ∝ a³（周期的平方与长半轴的立方成正比）|
### 轨道能量
E = ½mv² – GMm/r
|电子|轨道类型|
|---|-----------|
| E< 0 | Elliptical (bound) |
| E = 0 | Parabolic (escape trajectory) |
| E >0 |双曲线（未绑定）|
### 逃逸速度
v_escape = √(2GM/R)
对于地球：v_escape ≈ 11.2 km/s

经典力学不仅仅是下落的球和摆动的钟摆。它的数学框架——拉格朗日力学和哈密顿力学——是所有科学中最有影响力的思想之一。它们推广到量子力学、场论，甚至现代机器学习，其中基于能量的模型和基于物理的神经网络直接借鉴了这些具有数百年历史的公式。
