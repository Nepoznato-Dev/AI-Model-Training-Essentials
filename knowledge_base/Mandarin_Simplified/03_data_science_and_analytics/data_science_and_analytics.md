# 数据科学与分析
数据科学是将原始数据转化为可操作的见解的学科。它位于统计学、计算机科学和领域专业知识的交叉点，并且已经成为从金融到医疗保健的各个领域的重要组成部分。该文件介绍了每个从业者都应该了解的核心概念、工具和工作流程。
---

## 数据科学过程
大多数项目都遵循行业标准生命周期 **CRISP-DM** 的一些变体：
|相|发生了什么 |典型时间 |
|--------|-------------|--------------|
| **业务理解** |定义目标、成功指标和约束条件 | 10–15% |
| **数据理解** |收集、探索和分析数据 | 10–15% |
| **数据准备** |清理、改造、设计功能 | 〜50–60% |
| **建模** |选择和训练模型 | 10–15% |
| **评估** |根据业务目标评估绩效 | 5–10% |
| **部署** |将模型交付生产 | 5–10% |
据广泛估计，数据准备（尤其是数据清理）消耗了数据科学家约 80% 的时间。

## 数据类型概览
|类型 |描述 |示例|
|------|-------------|---------|
| **结构化** |按行和列组织 | SQL 表、电子表格 |
| **非结构化** |没有预定义格式 |文字、图像、音频、视频 |
| **半结构化** |有组织但灵活 | JSON、XML、HTML |
| **时间序列** |按时间索引的顺序数据 |股票价格、传感器读数|
| **空间** |基于地理或位置的| GPS坐标、地图数据|
| **图表** |表示关系的节点和边 |社交网络、知识图 |

## 统计基础知识
### 描述性统计与推论性统计
描述性统计总结了您*拥有*的东西；推论统计可以让你对你“没有”的东西（更广泛的人群）得出结论。
|概念 |关键想法|
|--------|------------|
| **集中趋势** |均值（对异常值敏感）、中位数（稳健）、众数（最常见）|
| **分散** |极差、方差、标准差、四分位距 |
| **分布形状** |偏度（不对称）、峰度（尾重）|
| **假设检验** |零假设与备择假设、p 值、显着性水平 (α) |
| **置信区间** |可能包含真实总体参数的范围 |
| **I 类/II 类错误** |假阳性（拒绝真正的无效值）/假阴性（缺少真实效果）|
### 常见统计测试
|测试|何时使用 |
|------|-------------|
| **t 检验** |比较两组之间的平均值 |
| **方差分析** |比较三个或更多组的平均值 |
| **卡方** |测试分类变量的独立性 |
| **曼-惠特尼大学** | t 检验的非参数替代方案（无正态性假设）|
| **皮尔逊相关性** |两个连续变量之间的线性关系 |
| **斯皮尔曼相关性** |单调关系（基于排名，更稳健）|
### 值得了解的概率分布
|分销|使用案例|
|-------------|----------|
| **正常** |自然现象、测量误差——经典钟形曲线|
| **二项式** |成功/失败计数（抛硬币、转化率）|
| **泊松** |固定间隔内的事件计数（每小时调用次数、每批缺陷）|
| **指数** |事件之间的时间（等待时间、故障间隔）|
| **t-分布** |小样本或未知总体方差 |
| **卡方** |分类数据分析、拟合优度检验 |

## 数据收集和存储
### 数据从何而来
现实世界的数据有很多来源：关系数据库、API（REST、GraphQL）、平面文件（CSV、JSON、Parquet）、流平台（Kafka、Kinesis）、调查和公共存储库（Kaggle、政府门户网站）。您收到的格式很大程度上决定了您的预处理策略。
### 数据仓库概念
|概念 |描述 |
|---------|-------------|
| **ETL** |提取 → 转换 → 加载 — 传统的管道方法 |
| **英语语言测试** |提取 → 加载 → 转换 — 现代云方法（加载原始数据，在仓库内转换）|
| **数据湖** |以本机格式存储的原始数据（读取时模式）|
| **数据仓库** |为分析而优化的结构化、经过处理的数据（写入时模式）|
| **数据集市** |仓库的子集，范围为一个部门或域 |
| **星型架构** |中央事实表被维度表包围 |
| **雪花模式** |标准化维度表（更少的冗余，更多的连接）|
### 数据库类型
|类型 |示例 |最适合 |
|------|----------|----------|
| **关系 (SQL)** | PostgreSQL、MySQL、Oracle |结构化数据、ACID 事务 |
| **文件** | MongoDB、CouchDB |灵活的架构、类似 JSON 的数据 |
| **键值** | Redis、DynamoDB |缓存、会话、简单查找 |
| **列族** |卡桑德拉、HBase |写入繁重的工作负载、时间序列 |
| **图表** | Neo4j、亚马逊海王星 |人际关系、社交网络 |
| **时间序列** | InfluxDB、TimescaleDB |物联网指标、监控 |
| **矢量** |松果，Milvus |用于 ML/AI 搜索的嵌入存储 |

## 数据预处理和特征工程
### 清洁清单
每个真实的数据集都有问题。这是标准清理：
|问题 |方法|
|--------|----------|
| **缺失值** |插补（均值、中位数、预测），或稀疏情况下的删除 |
| **异常值** |通过 IQR 或 Z 分数检测；封盖或转化处理|
| **重复** |识别并删除 |
| **不一致** |标准化格式、修复拼写错误、标准化单位 |
### 转换技术
|技术|它有什么作用 |
|------------|-------------|
| **标准化** |将值缩放到 0–1 范围 |
| **标准化** | Z 分数：平均值 = 0，标准差 = 1 |
| **One-hot 编码** |将类别转换为二进制列 |
| **标签编码** |将整数标签分配给类别 |
| **日志转换** |减少数据右偏 |
| **分档** |将连续值分组到离散桶中 |
### 特征工程
特征工程通常是平庸模型和优秀模型之间的区别。关键技术包括：
- **功能创建**：从现有列派生新列（例如，从`age`派生`age_group`）。
- **特征选择**：过滤方法（相关）、包装方法（递归消除）、嵌入方法（LASSO、树重要性）。
- **降维**：用于线性的 PCA、用于可视化的 t-SNE 或 UMAP。
- **交互项**：乘法组合特征以捕获联合效果。

## 探索性数据分析 (EDA)
EDA 是您在建模之前培养对数据的直觉的地方。目标是发现模式、异常和关系。
### 选择正确的图表
|图表类型 |最适合 |
|------------|----------|
| **直方图** |单个变量的分布 |
| **箱线图** |五数汇总、异常值检测 |
| **散点图** |两个连续变量之间的关系 |
| **热图** |相关矩阵、密度可视化 |
| **条形图** |比较类别 |
| **折线图** |随时间变化的趋势|
| **小提琴情节** |分布密度+箱线图总结|
| **配对图** |所有变量对的快速概览 |
### Python EDA 堆栈
|图书馆 |角色 |
|---------|------|
| **熊猫** |数据处理和分析|
| **numpy** |数值计算|
| **matplotlib** |基础绘图|
| **海生** |统计可视化（基于 matplotlib 构建）|
| **情节** |基于网络的交互式可视化 |
| **scipy** |科学计算与统计|

## 数据科学中的机器学习
### 监督学习概览
|任务|算法 |
|------|------------|
| **回归**（预测一个数字）|线性、岭/LASSO、决策树、随机森林、梯度提升（XGBoost、LightGBM）|
| **分类**（预测一个类别） |逻辑回归、k-NN、朴素贝叶斯、SVM、决策树、随机森林、神经网络 |
### 无监督学习概览
|任务|算法 |
|------|------------|
| **聚类** | k 均值、分层、DBSCAN、高斯混合模型 |
| **降维** | PCA、t-SNE、UMAP、自动编码器 |
| **协会规则** | Apriori，FP-增长 |
### 模型评估
|公制类型 |关键指标|
|-------------|-------------|
| **分类** |准确率、精确率、召回率、F1 分数、ROC-AUC、混淆矩阵 |
| **回归** | MAE、MSE、RMSE、R²、调整后的 R² |
| **验证** | k 折交叉验证、分层、时间序列分割 |
| **调整** |网格搜索、随机搜索、贝叶斯优化 |

## 商业智能和分析
### BI 工具比较
|工具|类型 |实力|
|------|------|----------|
| **画面** |商业|丰富的可视化分析、拖放 |

### 仪表板设计原则
有效的仪表板遵循既定原则：识别受众、为每个指标选择适当的可视化、战略性地使用颜色（而不是装饰性的）、保持一致的比例以及启用交互性（过滤器、向下钻取）。性能也很重要——加载时间慢的仪表板会降低用户采用率。
### 常见 KPI 类别
|类别 |示例 |
|----------|---------|
| **财务** |收入、利润率、投资回报率、客户终身价值 |
| **客户** |获取成本 (CAC)、流失率、NPS、满意度评分 |
| **运营** |效率、周期时间、缺陷率 |
| **营销** |转化率、点击率、ROAS、归因 |
| **产品** |每日活跃用户、参与度、保留率、功能采用 |

## 数据伦理与治理
### 隐私规定
|监管|范围 |
|----------|------|
| **GDPR** |欧盟数据主体；删除权、同意权、数据可移植性|
| **CCPA** |加州消费者；选择退出数据销售 |
| **健康保险流通与责任法案** |美国医疗保健数据；严格的保密规定|
### 数据质量维度
|尺寸|问题 |
|------------|----------|
| **准确度** |数据正确吗？ |
| **完整性** |有什么遗漏吗？ |
| **一致性** |消息来源同意吗？ |
| **时效性** |是当前的吗？ |
| **有效期** |它符合预期的格式吗？ |
| **独特性** |有重复的吗？ |
### 偏见和公平
偏差可以在任何阶段出现：抽样偏差（非代表性数据）、测量偏差（有缺陷的仪器）或算法偏差（歧视性预测）。缓解策略包括预处理（修复数据）、处理中（约束模型）和后处理（调整输出）。人口平等和机会均等等公平指标有助于量化问题。

## 新兴趋势
- **AutoML**：自动化管道创建和模型选择。
- **MLOps**：应用于 ML 生命周期管理的 DevOps 实践。
- **功能存储**：集中功能管理，以便跨团队重用。
- **数据网格**：分散的、域拥有的数据架构。
- **法学硕士和生成式人工智能**：转换文本、代码和图像工作流程的大型语言模型。
- **边缘分析**：在设备上而不是在云端处理数据。
- **因果推理**：超越相关性来理解实际的因果关系。
- **联邦学习**：在不移动分散数据的情况下训练模型。
- **负责任的人工智能**：道德、可解释性和透明度成为标准要求。
