# 研究方法论
研究方法是调查问题、检验假设和生成可靠知识的系统方法。无论您是在进行科学实验、社会科学调查、商业分析还是学术研究，您选择的方法都决定了您的发现是否可信、可重复和有用。精心设计的研究会产生值得信赖的结果；设计不佳的答案会产生噪音，或者更糟糕的是，会产生自信的错误答案。
---

## 研究类型
|尺寸|选项|描述 |
|------------|---------|-------------|
| **目的** |基础与应用 |基本：为了知识本身而扩展知识。应用：解决实际问题 |
| **方法** |演绎与归纳|演绎：理论→假设→观察。归纳：观察→模式→理论|
| **数据类型** |定量、定性、混合 |数量：数字。定性：词语、含义。混合：两者|
| **时间范围** |横截面与纵向 |横截面：某一时间点。纵向：随着时间的推移|
| **设置** |实验与观察 |实验：研究人员操纵变量。观察性：研究人员在没有干预的情况下观察|
---

## 科学方法
|步骤|描述 |
|------|-------------|
| **1.观察** |注意一种现象或模式 |
| **2.问题** |制定一个具体的、可测试的问题|
| **3.假设** |提出初步解释或预测 |
| **4.预测** |从假设中得出可检验的预测 |
| **5.实验/观察** |收集数据来测试预测 |
| **6。分析** |分析数据；确定结果是否支持或反驳假设|
| **7.结论** |得出结论；考虑限制；建议进一步研究|
| **8.同行评审和复制** |其他人评估并尝试重现研究结果 |

## 定量研究
### 实验设计
|设计|描述 |实力|弱点|
|--------|-------------|----------|---------|
| **真实实验（RCT）** |随机分配治疗和对照|最有力的因果证据|昂贵的;不可一概而论|
| **准实验** |没有随机分配；比较组|更实用；现实世界的设置|混杂变量 |
| **预测试/后测试** |干预前后的测量|显示随时间的变化|无法控制外部因素|
| **因子设计** |同时操纵多个自变量|测试变量之间的相互作用 |复杂的;需要大量样品|
| **科目内** |所有条件下的相同参与者 |控制个体差异；参与者减少 |订单效应；结转 |
| **科目之间** |每种情况下的不同参与者 |无残留效应 |个体差异；需要更多参与者|
### 采样方法
|方法|类型 |描述 |何时使用 |
|--------|------|-------------|------------|
| **简单随机** |概率 |每个会员都有平等的选择机会 |黄金标准；需要完整的采样框|
| **分层随机** |概率 |分层；从每个 | 中随机抽取样本确保子群体的代表性 |
| **集群** |概率 |随机选择组；调查所有内|人口众多；性价比|
| **便利** |非概率|采样任何有空的人 |快的;便宜的;但有偏见|
| **有目的** |非概率|刻意选择具体案例|专家意见；具体特点|
| **雪球** |非概率|现有参与者招募其他参与者 |难以接触的人群|
### 统计分析
|分析类型 |目的|示例|
|--------------|---------|---------|
| **描述性统计** |汇总数据|意思是;中位数；标准差；频率分布 |
| **推断统计** |从样本中得出关于总体的结论 | t 检验；方差分析；卡方；回归 |
| **相关性** |测量变量之间的关联 |皮尔逊的 r;斯皮尔曼氏rho |
| **回归** |因变量和自变量之间的模型关系 |线性回归；逻辑回归 |
| **因素分析** |识别数据中的基础维度 |主成分分析；探索性因素分析|
| **荟萃分析** |结合多项研究的结果 |治疗效果系统评价|

## 定性研究
＃＃＃ 方法
|方法|描述 |最适合 |
|--------|-------------|----------|
| **访谈**（半结构化）|开放式问题；探测|对经验的深刻理解；含义 |
| **焦点小组** |由主持人引导的小组讨论 |探索群体规范；产生想法|
| **民族志** |自然环境中的沉浸式观察 |了解文化；社会实践|
| **案例研究** |深入查处单案或小案数|背景下的复杂现象|
| **扎根理论** |通过迭代编码从数据构建理论 |当现有理论不充分时 |
| **内容分析** |文本/媒体的系统编码 |大量文字；媒体分析 |
| **话语分析** |研究所使用的语言；权力关系|语言如何构建现实|
| **现象学** |了解生活经验 |人们如何体验一种现象|
### 确保定性研究的质量
|标准|描述 |如何实现 |
|------------|-------------|----------------|
| **可信度**（内部有效性）|调查结果准确地代表了参与者的观点|三角测量；会员检查；长期参与 |
| **可转让性**（外部有效性）|适用于其他情况的调查结果 |详细描述；有目的的抽样|
| **可靠性**（可靠性）|如果重复研究，结果是一致的|审计追踪；同行汇报|
| **可证实性**（客观性）|研究结果植根于数据，而非研究人员的偏见 |反身性；三角测量；审计追踪|

## 混合方法
|设计|描述 |何时使用 |
|--------|-------------|-------------|
| **收敛并行** |同时收集定量和定性数据；比较|当您想要广度和深度时 |
| **解释性顺序** |定量第一；定性解释结果|当调查结果需要更深入的了解时 |
| **探索性顺序** |质为先；定量测试结果|当您需要首先开发仪器或理论时 |

## 有效性和可靠性
### 有效性的威胁
|威胁|描述 |缓解措施 |
|--------|-------------|------------|
| **选择偏差** |干预前各组存在系统性差异|随机分配；匹配|
| **流失偏差** |参与者非随机退出 |跟踪原因；意向治疗分析|
| **霍桑效应** |人们改变行为是因为他们被观察了|对照组；致盲|
| **需求特征** |参与者猜测假设并采取相应行动 |欺骗；封面故事|
| **实验者偏差** |研究人员的期望影响结果|致盲；标准化程序|
| **混淆** |第三个变量解释了关系 |控制变量；随机化；统计调整|
| **P-黑客** |测试许多假设，直到其中一个具有显着性 |预先登记；多重比较校正|
### 可靠性措施
|测量|描述 |
|---------|-------------|
| **测试再测试** |相同的测试进行两次；分数之间的相关性|
| **评估者间** |不同评估者/编码者之间的协议 |
| **内部一致性** |克朗巴赫阿尔法；测量相同结构的项目|
| **并行形式** |同一测试不同版本之间的相关性 |

## 研究伦理
|原理|描述 |
|------------|-------------|
| **知情同意** |参与者了解他们同意的内容；自愿参与 |
| **慈善** |利益最大化；尽量减少伤害|
| **非恶意** |不伤害身体、心理、社会 |
| **正义** |公平分配利益和负担；不要剥削弱势群体|
| **隐私和保密** |保护参与者的数据；尽可能匿名 |
| **退出权** |参与者可以随时退出研究而不会受到处罚 |
| **汇报** |参与后解释研究的目的；特别是如果使用了欺骗手段 |

＃＃ 概括
研究方法是决定你的研究结果是否值得信赖的框架。定量方法（实验、调查、统计分析）最适合检验假设和测量效果。定性方法（访谈、民族志、案例研究）最适合理解意义、背景和经验。混合方法结合了广度和深度。科学方法提供了从观察到假设、数据收集、分析和同行评审的结构化过程。有效性（您测量的是您认为正在测量的内容吗？）和可靠性（您会再次得到相同的结果吗？）是关键的质量标准。研究伦理确保对知识的追求不会以牺牲参与者的权利和福祉为代价。最重要的原则是方法论服务于研究问题——选择最能回答你的问题的方法，而不是最熟悉或最简单的方法。
