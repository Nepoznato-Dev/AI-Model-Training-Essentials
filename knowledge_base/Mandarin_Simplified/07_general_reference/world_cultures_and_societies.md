# 世界文化和社会
文化是社会的框架——成员用来应对世界和彼此之间的共同信仰、价值观、习俗、行为和人工制品。理解文化多样性并不是死记硬背，而是要理解文化多样性。它是关于认识到看待世界的方式有数以千计，而其他系统是内部连贯的、有历史依据的，并且值得根据自己的方式来理解。
---

## 文化维度
人类学家和跨文化心理学家使用框架来系统地比较社会。最有影响力的是吉尔特·霍夫斯泰德的文化维度模型。
|尺寸|它测量什么 |对比示例 |
|------------------------|-----------------|-----------------|
| **权力距离** |多少不平等被视为正常？高（马来西亚、菲律宾）与低（丹麦、新西兰）|
| **个人主义与集体主义** | “我”身份与“我们”身份|高度个人主义（美国、澳大利亚）与高度集体主义（危地马拉、印度尼西亚）|
| **男性气质与女性气质** |竞争和成就 vs 合作和生活质量 |男性（日本、匈牙利）与女性（瑞典、荷兰）|
| **避免不确定性** |容忍歧义和无组织的情况|高（希腊、葡萄牙）与低（新加坡、牙买加）|
| **长期与短期定位** |未来的奖励与当前的传统|长期（中国、韩国）与短期（美国、尼日利亚）|
| **放纵与克制** |满足冲动的自由与严格的社会规范|放纵（墨西哥、尼日利亚）与克制（俄罗斯、埃及）|
> **实用洞察**：这些是频谱位置，而不是价值判断。高权力距离文化并不“压抑”——它可能重视对长辈的尊重和社会和谐。低权力距离文化并不“混乱”——它可能重视精英管理和公开辩论。

## 主要文化区
### 东亚
|方面|详情 |
|--------|---------|
| **国家** |中国、日本、韩国、台湾、越南 |
| **哲学根源** |儒、道、佛、神道|
| **关键值** |孝道、教化、和谐、面子（社会声誉）、集体责任|
| **沟通方式** |高语境：含义是隐含的、间接的、字里行间的 |
| **时间导向** |长期;强调坚持和未来的回报|
| **商业文化** |关系至上；通过进餐和反复会面建立的信任；尊重等级制度|
东亚文化与中国的书写系统、筷子使用和农历新年庆祝活动有着共同的影响，但又存在显着差异——日本人的交流比中国人更加间接，韩国商业文化比台湾人更加等级化。
### 南亚
|方面|详情 |
|--------|---------|
| **国家** |印度、巴基斯坦、孟加拉国、斯里兰卡、尼泊尔 |
| **哲学根源** |印度教、佛教、伊斯兰教、锡克教、耆那教 |
| **关键值** |家庭责任、尊重长辈、精神多样性、热情好客（atithi devo bhava —“客人就是上帝”）|
| **沟通方式** |高语境；著名的摇头；间接分歧|
| **社会结构** |大家庭系统；印度历史种姓的影响；牢固的社区纽带|
| **语言多样性** |数百种语言；最常用的语言包括印地语、孟加拉语、乌尔都语、泰米尔语、泰卢固语 |
### 中东和北非 (MENA)
|方面|详情 |
|--------|---------|
| **国家** |沙特阿拉伯、阿联酋、埃及、摩洛哥、伊朗、土耳其、以色列 |
| **哲学根源** |伊斯兰教、犹太教、基督教（起源于这里）、奥斯曼和波斯传统 |
| **关键值** |热情好客、荣誉、家庭忠诚、宗教仪式、慷慨|
| **沟通方式** |高语境；关系驱动；间接拒绝保全面子|
| **商业文化** |人际关系至关重要；谈判可能会很漫长；星期五是穆斯林占多数的国家的圣日|
| **多样性说明** |范围巨大——世俗的土耳其与保守的沙特阿拉伯有很大不同；黎巴嫩比也门更加国际化
### 撒哈拉以南非洲
|方面|详情 |
|--------|---------|
| **国家** | 46+ 个国家；尼日利亚、埃塞俄比亚、肯尼亚、南非、加纳、塞内加尔位列人口最多国家之列
| **哲学根源** | Ubuntu（“我是因为我们是”）、祖先传统、伊斯兰教、基督教、土著信仰体系 |
| **关键值** |社区、大家庭、口头传统、尊重长辈、热情好客|
| **语言多样性** | 2,000 多种语言；斯瓦希里语、约鲁巴语、阿姆哈拉语、祖鲁语、豪萨语、伊博语是最常用的语言 |
| **社会结构** |年龄等级系统、部落归属、强烈的社区认同 |
| **多样性说明** |地球上基因和文化最多样化的大陆。对“非洲文化”的概括就像对“欧洲文化”的概括——在高层次上是可能的，但在细节上会产生误导 |
＃＃＃ 拉美
|方面|详情 |
|--------|---------|
| **国家** |墨西哥、巴西、阿根廷、哥伦比亚、秘鲁、智利等 |
| **哲学根源** |土著文明（阿兹特克、玛雅、印加）、天主教、非洲侨民影响 |
| **关键值** |家庭（familismo）、个人关系（personalismo）、温暖、时间的灵活性 |
| **沟通方式** |高语境；身体接近和触摸是正常的；间接分歧|
| **时间导向** |多时性——同时执行多项任务；关系优先于日程安排|
| **商业文化** |信任和个人联系先于业务；会议从扩展的社交对话开始 |
### 西方（欧洲、北美、澳大利亚）
|方面|详情 |
|--------|---------|
| **国家** |美国、加拿大、英国、德国、法国、澳大利亚、新西兰、北欧国家 |
| **哲学根源** |希腊罗马哲学、基督教、启蒙运动、自由主义 |
| **关键值** |个人主义、任人唯贤、直接、准时、创新|
| **沟通方式** |低语境：含义明确； “说出你的意思”|
| **时间导向** |单一性——时间是一种需要管理的资源；守时是一种美德|
| **商业文化** |任务第一；重视效率；合同高于关系；扁平的等级制度（特别是在北欧国家）|
> **西方内部的多样性**：北欧社会民主主义与美国资本主义有很大不同。德国人的直接与英国人的礼貌不同。意大利人的表现力与瑞士人的矜持不同。 “西方文化”是一个有用的缩写，但并不是一个整体。

## 沟通风格：高语境与低语境
爱德华·T·霍尔的框架是跨文化理解最实用的工具之一。
|特色 |高语境 |低语境 |
|---------|-------------|----------|
| **含义** |在情境、关系和非语言暗示中 |用明确的话来说|
| **协议** |以信任为基础；可能是口头的 |书面合同优先 |
| **不同意** |间接; “也许”通常意味着“不” |直接的; “不”的意思是“不” |
| **反馈** |微妙的;私下交付保住面子|明确；直接发货|
| **沉默** |舒服的;有意义|不舒服；出问题了|
| **示例** |日本、中国、阿拉伯国家、拉丁​​美洲|美国、德国、斯堪的纳维亚、瑞士 |

## 社会结构和组织
|结构|描述 |常见之处 |
|------------|-------------|-------------|
| **核心家庭** |仅限家长 + 孩子 |全球西方国家、城市地区|
| **大家庭** |多代人共同生活或密切接触|南亚、中东、非洲、拉丁美洲 |
| **氏族/部落** |拥有共同祖先的更大的亲属群体|非洲、中东、中亚部分地区 |
| **种姓/阶级** |世袭的社会分层|历史印度（现已合法废除）；阶级制度无处不在|
| **平等主义** |最小的层次结构；以绩效为基础 |北欧国家在线社区|

## 宗教与文化实践
宗教不仅仅是信仰，它还影响着饮食、着装、日历、性别角色、工作时间和法律体系。
|宗教 |追随者|主要文化影响|
|----------|----------|----------------------|
| **基督教** |约 24 亿 |周日休息；圣诞节/复活节日历；影响了西方的法律和道德|
| **伊斯兰教** |约 19 亿 |每日五次祈祷；斋月斋戒；清真饮食法；周五为集会日|
| **印度教** |约 12 亿 |种姓影响；许多人实行素食主义；排灯节/洒红节；牛尊|
| **佛教** |约 5 亿 |冥想;非暴力；修道院传统；世俗环境中的正念|
| **锡克教** |约 3000 万 |头巾；兰加尔（社区厨房）；平等;服务（服务）|
| **犹太教** |约 1500 万 |安息日（周六休息）；犹太饮食法；崇高的圣日；重视学习|
| **世俗/非宗教** |约 12 亿 |没有宗教日历；多元价值观；不同国家差异很大|

## 全球化与文化变革
文化不是静态的。全球化、移民和互联网正在重塑世界各地的文化习俗。
**均质化与杂交：**
- 一些人认为全球化正在创造一种单一的消费文化（麦当劳、Netflix、英语作为通用语言）
- 其他人则看到杂交：当地文化吸收并改变全球影响（宝莱坞、韩国流行音乐、非洲节奏）
- 现实是两者兼而有之：表面层的融合（服装、技术）和深层的多样性（价值观、沟通、身份）
**主要趋势：**
- 城市化：超过 56% 的世界人口居住在城市（1950 年为 30%）
- 移民：全球约有 2.8 亿国际移民，创造了侨民社区
- 数字文化：社交媒体创造跨国文化社区
- 语言转变：世界上约 7,000 种语言中约 40% 处于濒危状态；英语、普通话和西班牙语占主导地位

＃＃ 概括
了解其他文化并不是关于刻板印象，而是关于培养文化智慧：认识到你的规范不具有普遍性、适当地调整你的行为以及跨越差异相互尊重的能力。上述框架（文化维度、高/低背景、社会结构）是思考的工具，而不是给人们贴上标签的盒子。每个人都同时受到多种文化的影响——国家的、地区的、专业的、代际的、家庭的。我们的目标不是根据护照来预测某人的行为方式，而是以好奇心而不是判断力来对待差异。
