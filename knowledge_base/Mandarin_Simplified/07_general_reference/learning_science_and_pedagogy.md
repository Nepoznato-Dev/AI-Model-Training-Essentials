# 学习科学和教育学
学习科学是对人们如何学习的跨学科研究——借鉴心理学、神经科学、教育和认知科学。教育学是教学的实践和方法。他们共同解决了与任何教学、培训、指导或设计教育内容的人相关的问题：什么方法可以帮助人们有效学习？哪些常见的学习方法效率低下？应如何构建教学以实现最佳保留和转移？
---

## 学习如何进行
### 学习过程
|舞台|描述 |关键因素|
|--------|-------------|------------|
| **注意** |信息处理须注意 |新奇;关联;情感意义|
| **编码** |信息转化为心理表征 |连接到先验知识；阐述 |
| **整合** |记忆痕迹随着时间的推移而稳定|睡觉;间隔重复；反思|
| **存储** |信息保存在长期记忆中|有意义的组织；与现有知识的联系|
| **检索** |需要时即可访问信息 |练习检索；不同的背景 |
| **转让** |知识应用于新情况|多样化的练习；理解原理，而不仅仅是程序|
### 认知负荷理论
|类型 |描述 |教学意义|
|------|-------------|--------------------------|
| **内在负载** |材料固有的难度|管理复杂性；从简单到复杂的顺序 |
| **外部负载** |教学设计不当造成的困难 |消除不必要的复杂性；清晰的例子；良好的格式 |
| **德国负载** |投入到实际学习中的脑力劳动（图式构建） |鼓励详细阐述；自我解释；有意义的实践|
**关键见解**：工作记忆是有限的（一次大约 4±1 项）。教学应尽量减少无关负荷，以便认知资源可用于学习。

## 循证学习策略
### 高效策略
|战略|描述 |为什么它有效？证据级别|
|----------|-------------|-------------|----------------|
| **检索练习** |主动从记忆中回忆信息 |强化记忆痕迹；找出差距|很强|
| **间隔练习** |随着时间的推移分配学习课程|部队重组；对抗遗忘曲线|很强|
| **交错** |混合不同类型的问题或主题 |改善歧视；更好的转移|强|
| **详细说明** |解释新信息如何与您所知道的相关联 |创造更丰富的记忆痕迹；更深层次的编码 |强|
| **具体例子** |用具体的例子来说明抽象的概念 |使抽象的想法变得具体；帮助理解|强|
| **双编码** |文字与视觉的结合|使用语言和视觉处理渠道 |强|
### 无效的策略（尽管很受欢迎）
|战略|为什么感觉有效 |为什么它实际上不是|
|----------|------------------------|----------------------|
| **重读** |流畅错觉——文字感觉很熟悉 |被动的;不加强检索 |
| **突出显示** |感觉富有成效；标记重要信息 |不需要深加工 |
| **总结** |看起来像是积极参与 |经常逐字复制；不需要检索 |
| **集中练习（临时抱佛脚）** |适用于短期回忆 |快速遗忘；转移不良|
| **学习风格**（视觉/听觉/动觉）|直观吸引人 |没有证据表明将教学与首选风格相匹配可以改善学习 |

## 遗忘曲线和间隔重复
### 艾宾浩斯遗忘曲线
|学习后的时间 |保留（无审查）|
|--------------------------------|------------------------|
| **20 分钟** | 〜58% |
| **1 小时** | ~44% |
| **1 天** | ~33% |
| **2 天** | 〜28% |
| **6 天** | 〜25% |
| **31 天** | 〜21% |
### 间隔重复计划
|评论 |时间 |效果|
|--------|--------|--------|
| **第一次评论** |学习后1天 |显着提高保留率 |
| **第二次审查** | 3 天后 |进一步强化记忆 |
| **第三次评论** | 7 天后 |内存变得更耐用 |
| **第四次评论** | 14 天后 |长期巩固|
| **第五次评论** | 30 天后 |稳定的长期记忆 |
每一次回顾都会将遗忘曲线推得更远。最佳间隔随着每次成功检索而增加。

## 布鲁姆分类法
|水平|认知过程|动作动词|示例任务 |
|------|--------------------|-------------|--------------|
| **记住** |回忆事实和基本概念|定义;列表;姓名;识别| “列出有丝分裂的阶段” |
| **了解** |解释想法或概念 |描述;解释;总结;分类 | “解释为什么有丝分裂很重要”|
| **申请** |在新情况下使用信息 |解决;使用;证明;实施 | “预测如果有丝分裂被破坏会发生什么” |
| **分析** |建立想法之间的联系|比较;对比;分类；检查| “比较有丝分裂和减数分裂”|
| **评估** |证明立场或决定的合理性 |法官;批判;保卫;争论| “评估不受控制的细胞分裂的后果”|
| **创建** |创作新的或原创的作品 |设计;构造;发展;制定 | “设计一个实验来测试毒素对细胞分裂的影响”|

## 教学设计模型
### ADDIE模型
|相|描述 |
|--------|-------------|
| **分析** |确定学习者的需求；目标；现有知识；限制|
| **设计** |定义学习目标；评估策略；内容结构 |
| **开发** |创建材料；活动;评估|
| **实施** |传达指令；方便学习 |
| **评估** |评估有效性；收集反馈；迭代|
### 逆向设计（通过设计理解）
|步骤|描述 |
|------|-------------|
| **1.确定所需的结果** |学习者应该知道、理解并能够做到什么？ |
| **2.确定可接受的证据** |您如何知道他们已经取得了成果？ （先评估）|
| **3.计划学习经历** |哪些活动、指导和实践将使学习者取得成功？ |
### 脚手架
|技术|描述 |
|------------|-------------|
| **建模** |展示技能或思维过程 |
| **出声思考** |在解决问题时用语言表达你的推理 |
| **工作示例** |在要求学习者解决问题之前展示完整的解决方案 |
| **逐步发布** | “我愿意→我们愿意→你愿意”——逐步消除支持 |
| **提示** |提出问题，引导学习者找到答案 |
| **分块** |将复杂的任务分解为可管理的部分 |

## 动机和参与
### 自决理论
|需要|描述 |如何支持 |
|------|-------------|----------------|
| **自治** |感觉可以控制自己的行为|提供选择；解释理由；避免控制语言|
| **能力** |感觉有效和有能力|适当的挑战；及时反馈；庆祝进步|
| **相关性** |感觉与他人有联系 |协作学习；支持性环境；与社区的相关性|
### 成长与固定心态（Carol Dweck）
|心态|信念|行为 |对失败的回应|
|--------|--------|------------|--------------------|
| **已修复** |智力是静态的|回避挑战；轻易放弃| “我不擅长这个” |
| **增长** |智力是可以开发的|拥抱挑战；持续| “我还没学会这个” |

＃＃ 评估
### 评估类型
|类型 |目的|时间 |示例|
|------|---------|--------|---------|
| **诊断** |识别先验知识和误解 |教学前|预测试；概念盘点 |
| **形成性** |监控学习情况；提供反馈 |教学期间 |测验；出境门票；同行评审 |
| **总结性** |最后评估学习情况 |指导后 |期末考试；项目;投资组合 |
| **正品** |评估实际应用 |期间或之后 |案例研究；模拟;实习|
### 有效的反馈
|原理|描述 |
|------------|-------------|
| **及时** |很快就可以采取行动|
| **具体** |指出特定的优点和缺点|
| **可操作** |告诉学习者下一步该做什么 |
| **专注于任务** |与人无关（“这个论点需要更多证据”而不是“你不是一个好作家”）|
| **平衡** |确定什么是有效的以及什么需要改进 |
---

＃＃ 概括
学习科学表明，最有效的策略往往是违反直觉的。检索练习（测试自己）比重读更有效。间隔重复胜过死记硬背。不同类型的问题交织在一起可以改善区分和转移。认知负荷理论提醒我们，工作记忆是有限的——教学的设计应尽量减少无关负荷。布鲁姆的分类法提供了一个从回忆到创造的框架。教学设计模型（ADDIE，逆向设计）提供了开发有效学习体验的结构化方法。动机取决于自主性、能力和相关性。评估应与学习目标保持一致，并包括形成性反馈，而不仅仅是总结成绩。学习中最大的神话是人们有固定的“学习风格”——证据一致表明，将教学与首选风格相匹配并不能改善结果。对每个人都有效的是努力检索、间隔练习、多样化的例子和有意义的反馈。
