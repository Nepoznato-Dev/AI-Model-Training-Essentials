计算无处不在——在你的手机、你的汽车、你的冰箱、你的医疗设备以及运行现代社会的基础设施中。您无需成为一名程序员即可从了解其工作原理中受益。该文件涵盖了基础知识：什么是计算机、互联网如何工作、软件如何构建以及塑造数字世界的概念。

## 什么是计算机？
从本质上讲，每台计算机（从智能手机到超级计算机）都做同样的事情：接受输入，根据指令（程序）处理它，并产生输出。神奇之处在于速度和规模。
### 冯诺依曼架构
几乎所有现代计算机都遵循以下基本设计：
|组件|它有什么作用 |类比|
|------------|-------------|---------|
| **CPU**（中央处理单元）|执行指令； “大脑” |厨师按照食谱做|
| **RAM**（内存）|存储CPU正在使用的数据；断电时丢失|台面——快速访问，空间有限|
| **存储**（SSD/HDD）|永久存储数据 |食品储藏室——访问速度较慢，空间更大 |
| **输入/输出** |键盘、鼠标、屏幕、网络|厨师如何接单并送餐 |
| **GPU**（图形处理单元）|用于并行任务（图形、AI）的专用处理器 |一组助手同时执行相同的任务 |
**关键见解**：RAM 速度很快，但只是暂时的。存储速度缓慢但持久。当您的计算机“感觉很慢”时，通常是因为它的 RAM 不足，必须使用存储作为临时内存（交换），这要慢得多。

## 互联网如何运作
互联网与网络不同。互联网是物理网络——连接数十亿设备的电缆、路由器、服务器和协议。万维网是一项在互联网上运行的服务（还有电子邮件、文件传输、流媒体、游戏等）。
### Web 请求的旅程
当您在浏览器中输入`https://www.example.com`时：
1. **DNS 查找**：您的浏览器要求 DNS 服务器将“www.example.com”转换为 IP 地址（如 93.184.216.34）。
2. **TCP 连接**：您的设备使用 TCP（保证可靠传输的协议）建立与该 IP 地址的连接。
3. **TLS 握手**：如果使用 HTTPS，您的浏览器和服务器将协商加密连接。
4. **HTTP 请求**：您的浏览器发送请求：“给我 /index.html 的页面。”
5. **服务器处理**：Web 服务器查找页面，可能查询数据库，并准备响应。
6. **HTTP 响应**：服务器发回 HTML、CSS 和 JavaScript。
7. **渲染**：您的浏览器解析 HTML、应用 CSS 样式并执行 JavaScript 以显示页面。
整个过程通常需要不到一秒钟的时间。
### 关键协议
|协议|它有什么作用 |层|
|----------|-------------|--------|
| **IP**（互联网协议）|在网络之间路由数据包 |网络|
| **TCP** |可靠、有序的传送（重新传输丢失的数据包）|交通 |
| **UDP** |快速、不可靠的传送（无重传）|交通 |
| **HTTP/HTTPS** |网页传输（HTTPS添加加密）|应用 |
| **DNS** |将域名转换为 IP 地址 |应用 |
| **SSH** |安全地远程访问计算机|应用 |
| **SMTP/IMAP** |电子邮件发送和接收 |应用 |

## 软件开发——程序如何构建
### 开发过程
1. **编写代码**：开发人员用编程语言编写指令。
2. **测试代码**：运行代码以验证其是否正常工作。
3. **版本控制**：使用通用标准 Git 跟踪更改。
4. **审查**：其他开发人员检查代码的错误和质量。
5. **Build**：将源代码转换为可运行的程序（编译）。
6. **部署**：将程序发布给用户（服务器、应用商店等）。
7. **监控**：监视生产中的错误和性能问题。
### 关键概念
|概念 |这意味着什么？为什么这很重要？
|--------|-------------|----------------|
| **版本控制 (Git)** |跟踪一段时间内代码的每次更改 |合作;纠正错误的能力|
| **API**（应用程序编程接口）|软件组件通信的定义方式 |允许不同系统协同工作 |
| **数据库** |数据有组织的存储|每个应用程序都需要存储和检索数据|
| **测试** |自动检查代码是否正常工作 |防止错误影响用户 |
| **CI/CD**（持续集成/交付）|从代码提交到生产的自动化管道 |更快、更安全的发布 |
| **容器化（Docker）** |打包应用程序及其所有依赖项 | “在我的机器上运行”变成“在任何地方都可以运行”|

## 数据库——数据所在
每个应用程序都需要存储数据。数据库是高效、可靠地完成此任务的系统。
|类型 |数据如何存储 |最适合 |示例 |
|------|--------------------|----------|---------|
| **关系 (SQL)** |有行和列的表格；严格的模式|结构化数据；复杂的查询；交易 | PostgreSQL、MySQL、SQLite |
| **文档 (NoSQL)** |类似 JSON 的文档；灵活的模式|半结构化数据；快速迭代 | MongoDB、CouchDB |
| **键值** |简单键→值对|缓存；会话存储；快速查找| Redis、DynamoDB |
| **图表** |节点和边（关系）|社交网络；推荐引擎| Neo4j、JanusGraph |
| **时间序列** |针对带时间戳的数据进行了优化 |监控；分析；物联网 | InfluxDB、TimescaleDB |
**SQL**（结构化查询语言）是关系数据库的标准语言。这是您可以学习的最有价值的技术技能之一 - 几乎每个组织都使用数据库，而 SQL 是您与他们交谈的方式。

## 操作系统
操作系统 (OS) 是您（和您的程序）与硬件之间的软件层。它管理内存、进程、文件和设备。
|操作系统 |它在哪里占主导地位|主要特点|
|----|--------------------|-------------|
| **Windows** |台式机/笔记本电脑（约 72% 的市场份额）|最广泛的软件/硬件兼容性 |
| **macOS** |创意专业人士、开发人员 |基于Unix；精美的用户界面；苹果生态系统 |
| **Linux** |服务器 (~96%)、超级计算机 (100%)、嵌入式、开发人员 |开源；自由的;高度可定制|
| **安卓** |移动（全球市场份额约 72%）|基于Linux内核；开源|
| **iOS** |移动（全球约 27%，但收入更高）|封闭的生态系统；抛光；注重隐私 |
Linux 值得特别一提：它为大部分互联网、每台 500 强超级计算机、大多数云基础设施以及所有 Android 手机提供动力。它是免费的、开源的，并由全球社区维护。

## 云计算
云计算意味着通过互联网租用计算资源（服务器、存储、数据库等），而不是购买和维护自己的硬件。有关云架构、服务模型和提供商比较的综合指南，请参阅[cloud architecture](../01_coding_and_technology/cloud_architecture.md)。
|服务模式|你得到什么 |类比|示例 |
|----------------|-------------|---------|---------|
| **IaaS**（基础设施）|虚拟服务器、存储、网络|租一块地，建造你想要的东西 | AWS EC2、谷歌计算引擎 |
| **PaaS**（平台）|运行时环境；你带上代码|出租带家具的公寓 | Heroku，谷歌应用程序引擎 |
| **SaaS**（软件）|完成申请；你只要使用它|入住酒店 | Gmail、Slack、Salesforce |
三大云提供商是**AWS**（亚马逊，约 32% 的市场份额）、**Azure**（微软，约 23%）和 **GCP**（谷歌，约 10%）。他们提供数百种服务，涵盖计算、存储、数据库、人工智能、网络等。

## 网络安全——保护数字系统
网络安全是保护计算机、网络和数据免受攻击的实践。这很重要，因为一切都是相互关联的，而违规的成本是巨大的。有关涵盖 OWASP Top 10、安全开发生命周期和机密管理的完整指南，请参阅。
### 常见威胁
|威胁|它是什么 |预防|
|--------|------------|------------|
| **恶意软件** |恶意软件（病毒、蠕虫、木马）|防病毒；保持软件更新 |
| **网络钓鱼** |虚假电子邮件/消息诱骗您泄露信息 |训练;电子邮件过滤；怀疑主义|
| **勒索软件** |加密您的数据；要求支付钥匙费用|备份；补丁系统；不付钱|
| **DDoS** |流量压垮服务 |流量过滤； CDN保护|
| **SQL注入** |将恶意 SQL 插入输入字段 |参数化查询；输入验证|
| **中间人** |拦截两方之间的通信 | HTTPS/TLS 加密 |
### 安全基础知识
- **加密**：对数据进行加密，以便只有授权方才能读取它。 HTTPS 使用 TLS 加密 Web 流量。
- **身份验证**：验证身份。使用多重身份验证 (MFA) — 密码 + 其他内容（代码、生物识别）。
- **授权**：验证权限。仅仅因为您已登录并不意味着您应该访问所有内容。
- **最小权限原则**：仅向用户和系统提供他们需要的访问权限，仅此而已。
- **补丁管理**：保持软件更新。大多数违规行为都利用了已经有补丁的已知漏洞。

## 数据格式
程序以特定格式交换数据。最常见的：
|格式|结构|用于 |
|--------|------------|----------|
| **JSON** |键值对；人类可读 |蜜蜂;配置;数据交换|
