# 计算的未来
挑战过去 60 年基本假设的力量正在塑造计算的未来。摩尔定律——计算能力大约每两年翻一番——正在放缓。冯·诺依曼架构——独立的 CPU 和内存——正在撞上“内存墙”。量子计算有望解决经典计算机无法解决的问题。神经形态芯片模仿大脑的结构。边缘计算使处理远离集中式数据中心。人工智能正在改变计算机的用途——从执行指令的工具到学习、生成和推理的系统。了解这些转变对于任何构建、购买或依赖技术的人都很重要。
---

## 摩尔定律的终结
＃＃＃ 发生了什么
|时代|晶体管尺寸|趋势 |
|-----|----------------|--------|
| **1970 年代–2000 年代** | 10,000 纳米 → 130 纳米 |指数增长；性能每约 2 年翻一番 |
| **2000 年代–2010 年代** | 130 纳米 → 22 纳米 |增长持续，但功率密度成为问题|
| **2010 年代–2020 年代** | 22 纳米 → 3 纳米 |减速；每个节点的成本更高；福利减少|
| **2020 年代+** | 3 纳米 → 亚 1 纳米 |接近原子极限；量子效应干涉|
### 为什么它很重要
|后果|描述 |
|-------------|-------------|
| **性能提升缓慢** |不能依靠更小的晶体管来免费提高性能 |
| **专业化** |通用 CPU 让位于特定领域加速器（GPU、TPU、NPU）|
| **软件效率很重要** |无法对硬件进行暴力破解；算法和代码质量变得更加重要 |
| **需要新架构** |冯诺依曼瓶颈；记忆墙；电源墙|

## 量子计算
### 基础知识
|概念 |描述 |
|---------|-------------|
| **量子比特** |量子比特；可以是 0、1 或两者的叠加 |
| **叠加** |一个量子位在测量之前同时存在于多种状态 |
| **纠缠** |两个量子位变得相关；测量其中一个即可立即确定另一个|
| **干扰** |量子算法放大正确答案并消除错误答案 |
| **退相干** |量子位通过与环境的相互作用而失去量子特性；主要的工程挑战|
### 量子与经典
|方面|古典|量子|
|--------|------------|---------|
| **基本单位** |位（0 或 1）|量子位（0 和 1 的叠加）|
| **运营** |逻辑门（AND、OR、NOT）|量子门（Hadamard、CNOT 等）|
| **并行性** |一次进行一项计算（或许多独立的计算） |叠加可以同时探索多种可能性 |
| **缩放** | n 位 = n 个值 | n 个量子位 = 2^n 个叠加值 |
| **错误率** |非常低|目前处于高位；需要纠错|
### 量子擅长的应用
|应用 |为什么量子有帮助？时间轴 |
|------------|--------------------|----------|
| **密码学** | Shor算法可破解RSA加密 |威胁当前的加密；后量子密码学正在开发|
| **药物发现** |模拟量子水平的分子相互作用| 5-15 年产生实际影响 |
| **优化** |在广阔的搜索空间中寻找最佳解决方案 |后勤;金融;材料科学|
| **机器学习** |某些机器学习算法的量子加速 |早期研究；实际优势尚不清楚|
| **材料科学** |在原子水平上模拟新材料|电池材料；催化剂；超导体|
### 当前状态
|公司/项目 |方法|量子比特 |状态 |
|--------------------|----------|--------|--------|
| **IBM** |超导| 1,000+ |秃鹰处理器；量子优势尚未在实际问题中得到证明
| **谷歌** |超导| 70+ |梧桐；声称针对特定任务的量子霸权（2019）|
| **离子Q** |被捕获的离子| 30+（高保真）|精度高；较慢的门速度|
| **量子** |被捕获的离子| 50+ |合并霍尼韦尔 + 剑桥量子 |
| **PsiQuantum** |光子|未公开 |目标是 100 万个量子比特 |
| **微软** |拓扑|研究阶段|理论上最不易出错；最难建造|

## 神经形态计算
|方面|描述 |
|--------|-------------|
| **灵感** |大脑的神经结构——神经元和突触|
| **主要区别** |处理和内存位于同一位置（如突触）；没有冯诺依曼瓶颈|
| **尖峰神经网络** |神经元通过离散尖峰进行交流；节能 |
| **事件驱动** |只有活跃的神经元才会消耗能量；空闲的神经元是自由的|
| **硬件示例** |英特尔Loihi； IBM 北极； SpiNNaker |
| **应用** |边缘人工智能；机器人技术；感官处理；永远在线的设备 |

## 边缘计算
### 为什么是边缘？
|司机 |描述 |
|--------|-------------|
| **延迟** |本地处理数据避免往返云端 |
| **带宽** |并非所有数据都需要发送到云端（例如来自安全摄像头的视频）|
| **隐私** |敏感数据保留在设备上 |
| **可靠性** |在连接间歇性时工作 |
| **成本** |降低云计算和数据传输成本 |
### 边缘计算频谱
|地点 |延迟 |使用案例|
|----------|---------|----------|
| **On-device** (phone, IoT) | <1 毫秒 |语音识别；相机处理|
| **Near edge** (gateway, base station) | 1–10 毫秒 |工业控制；自动驾驶汽车|
| **Far edge** (regional data centre) | 10–50 毫秒 |内容交付；游戏 |
| **Cloud** (central data centre) | 50–200 毫秒 |训练;批处理；分析|

## 人工智能硬件
### AI 加速器的类型
|硬件|实力|弱点|示例|
|----------|----------|----------|------|
| **GPU** |大规模并行；有利于训练和推理 |耗电；通用 |英伟达 H100； AMD MI300 | AMD MI300
| **TPU**（张量处理单元）|专为张量运算而设计；高效|不如 GPU 灵活 |谷歌 TPU v5 |
| **NPU**（神经处理单元）|设备端人工智能推理；节能 |仅限于推理；较小的型号|苹果神经引擎；高通六边形 |
| **FPGA** |可重新配置；低延迟 |更难编程；较小的生态系统|英特尔Agilex；赛灵思 Versal |
| **专用集成电路** |专为特定人工智能工作负载定制设计 |设计成本昂贵；不灵活|谷歌 TPU（也是 ASIC）；大脑 |
| **晶圆级** |整个晶圆就是一颗芯片；大规模并行|小说;昂贵|大脑 WSE-3 |
### 记忆墙
|问题 |描述 |解决方案 |
|--------|-------------|------------|
| **冯诺依曼瓶颈** |数据必须在CPU和内存之间移动；这种传输比计算慢 |近内存计算；内存处理|
| **内存带宽** | AI模型需要读取数十亿个参数；内存无法足够快地提供数据|高带宽内存（HBM）；压缩|
| **内存容量** |大型模型不适合快速内存 |模型并行性；卸载到较慢的存储|

## 后硅技术
|技术 |描述 |潜力|
|------------|-------------|------------|
| **光子计算** |使用光代替电进行计算 |快点;功率较低；小型化的挑战|
| **自旋电子学** |使用电子自旋（而不是电荷）获取信息 |非挥发性；低功率；早期研究|
| **碳纳米管晶体管** |碳基晶体管代替硅|快点;更有效率；制造挑战|
| **DNA 计算** |使用 DNA 分子进行计算 |大规模并行性；非常慢；研究阶段|
| **生物计算** |使用活细胞进行计算 |可编程生物学；医疗应用|

＃＃ 概括
计算的未来并不是过去的简单延续。摩尔定律正在放缓，迫使人们从通用处理器转向专用加速器。量子计算有望为特定问题（密码学、药物发现、材料科学）带来指数级的加速，但实用的、纠错的量子计算机还需要数年时间。神经形态芯片模仿大脑的架构，实现节能边缘人工智能。边缘计算使处理过程更接近数据源，以降低延迟并提高隐私性。 AI 硬件正在多样化——GPU、TPU、NPU、FPGA 和定制 ASIC 各自满足不同的需求。内存墙（处理器速度和内存带宽之间的差距）是推动近内存计算创新的基本瓶颈。后硅技术（光子学、自旋电子学、碳纳米管）正在研究中，但可能会在几十年后重塑计算。总体主题是专业化：一刀切的计算时代正在结束，取而代之的是针对特定工作负载优化的异构系统。
