# 日常生活中的人工智能
人工智能不再是一个未来概念——它已融入日常生活。从您醒来并检查手机的那一刻（推荐算法决定您看到的通知）到您入睡的那一刻（您的智能扬声器处理您的最后一个命令），人工智能系统正在代表您、为您做出决定，有时甚至是关于您的决定。了解人工智能出现在哪里、它在基本层面上如何工作以及它的影响不再是可选的，而是 21 世纪知情公民的要求。

## 常见人工智能系统如何工作
### 推荐系统
|组件|描述 |
|------------|-------------|
| **协同过滤** | “喜欢 X 的用户也喜欢 Y”——基于用户或项目之间的相似性 |
| **基于内容的过滤** | “您喜欢动作片，这里有更多动作片”——基于项目功能 |
| **混合** |结合两种方法；大多数真实的系统都是混合的|
| **探索与利用** |展示您可能喜欢的内容（利用）与介绍新内容（探索）|
### 搜索引擎
|步骤|描述 |
|------|-------------|
| **爬行** |自动机器人（蜘蛛）访问网页并跟踪链接 |
| **索引** |页面被分析并存储在庞大的数据库中 |
| **查询处理** |您的搜索词已被解析；意图被推断 |
| **排名** |数百个信号决定顺序：相关性；权威;新鲜;地点;个性化|
| **结果** |显示热门结果；可能包含广告；知识面板；精选片段|
### 垃圾邮件过滤器
|技术|描述 |
|------------|-------------|
| **基于规则** |关键词；发件人信誉；已知的垃圾邮件模式|
| **统计** |朴素贝叶斯分类器；鉴于其特征，电子邮件是垃圾邮件的概率|
| **机器学习** |从数十亿封电子邮件中学习的深度学习模型 |
| **合奏** |多种方法的结合；持续更新|
### 欺诈检测
|方面|描述 |
|--------|-------------|
| **实时计分** |每笔交易均以毫秒计分 |
| **特点** |数量;地点;时间;设备;商人;消费模式|
| **异常检测** |标记偏离用户正常模式的交易 |
| **误报** |关键挑战：阻止合法交易成本高昂且令人沮丧 |

## 人工智能素养
### 每个人都应该知道什么
|概念 |描述 |
|---------|-------------|
| **人工智能是统计性的** |它从数据中学习模式；它不“理解”人类的意义|
| **人工智能可能是错误的** |模型会犯错误；信心不等于准确性|
| **人工智能有偏见** |训练数据反映了历史偏差；模型可以放大它们|
| **人工智能不是中立的** |设计选择（优化什么、使用什么数据）嵌入值 |
| **人工智能可以被操纵** |对抗性例子；及时注射；数据中毒|
| **人工智能正在迅速发展** |去年不可能实现的功能今天可能已成为家常便饭 |
### 关于人工智能系统的问题
|问题 |为什么这很重要？
|----------|--------------|
| **这是根据什么数据进行训练的？** |确定模型知道什么以及它可能有什么偏差 |
| **它优化的目的是什么？** |目标函数决定行为；目标不一致会导致问题|
| **故障模式有哪些？** |知道何时不信任人工智能与知道何时信任它同样重要 |
| **失败时谁负责？** |责任必须明确，尤其是在高风险领域|
| **我可以选择退出吗？** |并非所有人工智能系统都给你选择 |
| **这对我的隐私有何影响？** |许多人工智能系统需要个人数据才能运行 |

＃＃ 概括
人工智能不再是科幻小说——它是基础设施。推荐算法塑造您观看、阅读和购买的内容。搜索引擎决定您找到什么信息。垃圾邮件过滤器和欺诈检测可保护您免受威胁。医疗AI辅助诊断。导航应用程序优化您的通勤。但这些系统也引发了有关隐私、监视、偏见和自治的基本问题。注意力经济利用人工智能来最大限度地提高参与度，但往往以心理健康和民主话语为代价。人工智能素养——了解这些系统如何工作、它们的局限性及其影响——正变得像十年前的数字素养一样重要。关键不是要害怕人工智能或崇拜它，而是要充分了解它，以便明智地使用它，适当地质疑它，并要求部署它的人承担责任。
