category: "Coding and Technology"
version: "1.0.0"
status: "active"            # active | draft | deprecated | archived

# Contribution
authors:
  - name: "AI Model Training Team"
    email: ""
    role: "original_author"  # original_author | contributor | maintainer | reviewer
contributors: []
changelog:
  - version: "1.0.0"
    date: "2026-08-05"
    author: "AI Model Training Team"
    changes: "Added YAML frontmatter metadata for contributor tracking"

# Review
created: "2026-08-05"
last_modified: "2026-08-05"
review_date: "2027-02-05"
reviewed_by: "Coding & Technology Knowledge Base Team"
next_review: "2027-08-05"

# Classification
tags: [python, programming-language, syntax, ecosystem, coding-and-technology]
difficulty_level: "intermediate"   # beginner | intermediate | advanced
prerequisites: []
estimated_reading_time: "58 min"

# Contribution Guide
contribution:
  license: "MIT"
  feedback_channel: "GitHub Issues"
  how_to_contribute: "Submit a PR with changes and update the changelog"

---
```

|领域 |来源/目的|
|---|---|
| `title`|从文件的第一个`#`标题中提取 |
| `description`|一行摘要；主题文件重用本自述文件索引中的条目，编程语言文件使用生成的描述 |
| `category`/`reviewed_by`|源自父目录（`01_coding_and_technology`→“编码与技术”/“编码与技术知识库团队”）|

| `changelog`|仅附加更改列表，最新的在前 |
| `review_date`/`next_review`| 〜6 个月和〜1 年的节奏，反映了技能审查时间表 |
| `tags`|文件名标记加上干净的类别关键字（例如`coding-and-technology`）|

### 编辑文件
当您更改知识库文件时，请保持其 frontmatter 同步：
1. **凹凸`version`** 以下[SemVer](https://semver.org/)：
   - 补丁（`1.0.x`）：拼写错误、格式、细微修正
   - 次要 (`1.x.0`)：新部分、扩展内容、新示例
   - 主要 (`x.0.0`): 完全重写或重组
2. **添加变更日志条目**（最新的在前）描述您所做的更改：   ```yaml
   changelog:
     - version: "1.1.0"
       date: "2026-08-05"
       author: "Your Name"
       changes: "Expanded the ecosystem section with packaging tools"
     - version: "1.0.0"
       date: "2026-08-05"
       author: "AI Model Training Team"
       changes: "Added YAML frontmatter metadata for contributor tracking"
   ```
3. **将`last_modified`** 更新为更改日期
4. **如果这是您第一次编辑该文件，请将您自己添加到`contributors`**：   ```yaml
   contributors:
     - name: "Your Name"
       email: "you@example.com"
       role: "contributor"
   ```
