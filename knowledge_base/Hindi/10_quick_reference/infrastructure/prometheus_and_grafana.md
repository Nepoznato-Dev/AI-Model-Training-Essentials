# प्रोमेथियस और ग्राफाना
प्रोमेथियस एक ओपन-सोर्स मॉनिटरिंग और अलर्टिंग टूलकिट है जिसे विश्वसनीयता और स्केलेबिलिटी के लिए डिज़ाइन किया गया है। ग्राफाना समय-श्रृंखला डेटा को विज़ुअलाइज़ करने के लिए अग्रणी ओपन-सोर्स प्लेटफ़ॉर्म है। साथ में, वे आधुनिक बुनियादी ढांचे और अनुप्रयोगों के लिए सबसे लोकप्रिय निगरानी स्टैक बनाते हैं। प्रोमेथियस मेट्रिक्स एकत्र और संग्रहीत करता है; ग्राफाना उन्हें डैशबोर्ड में प्रदर्शित करता है।
---

## प्रोमेथियस वास्तुकला
| घटक | विवरण |
|----|----|
| **प्रोमेथियस सर्वर** | लक्ष्यों से मेट्रिक्स स्क्रैप करता है; समय-श्रृंखला डेटा संग्रहीत करता है; चेतावनी नियमों का मूल्यांकन करता है |
| **निर्यातक** | एक सिस्टम (नोड एक्सपोर्टर, सीएडवाइजर, आदि) से मेट्रिक्स को उजागर करता है |
| **पुशगेटवे** | अल्पकालिक नौकरियों (बैच नौकरियों, सीआई) से मेट्रिक्स प्राप्त करता है |
| **अलर्टमैनेजर** | अलर्ट संभालता है: समूहीकरण, मौन, रूटिंग, निषेध |
| **सेवा खोज** | स्वचालित रूप से लक्ष्यों की खोज करता है (कुबेरनेट्स, कॉन्सल, ईसी2, आदि) |

## महत्वपूर्ण अवधारणाएं
| संकल्पना | विवरण |
|---------|-----------------|
| **मीट्रिक** | वैकल्पिक लेबल और मान के साथ एक नामित माप |
| **समय श्रृंखला** | एक विशिष्ट मीट्रिक + लेबल संयोजन के लिए डेटा बिंदुओं की एक धारा |
| **नौकरी** | एक ही उद्देश्य से लक्ष्यों का संग्रह |
| **उदाहरण** | परिमार्जन करने के लिए एक एकल लक्ष्य (आमतौर पर एक प्रक्रिया) |
| **स्क्रैप** | प्रोमेथियस नियमित अंतराल पर लक्ष्य से मेट्रिक्स खींच रहा है |
| **लेबल** | एक कुंजी-मूल्य जोड़ी जो एक मीट्रिक को आयाम देती है (उदाहरण के लिए,`method="GET"`) |
| **नमूना** | समय में एक बिंदु पर एक मान: (टाइमस्टैम्प, मान) |

## मीट्रिक प्रकार
| प्रकार | विवरण | केस का प्रयोग करें |
|------|----|---|
| **काउंटर** | नीरस रूप से बढ़ता मूल्य (केवल बढ़ता है) | अनुरोध संख्या; त्रुटियाँ; कार्य पूर्ण |
| **गेज** | मान जो ऊपर या नीचे जा सकता है | तापमान; स्मृति प्रयोग; कतार की लंबाई |
| **हिस्टोग्राम** | मूल्य के अनुसार बकेट की गई टिप्पणियाँ | विलंबता का अनुरोध करें; प्रतिक्रिया का आकार |
| **सारांश** | हिस्टोग्राम के समान; क्वांटाइल क्लाइंट-साइड की गणना करता है | विलंबता प्रतिशत |

## प्रोमक्यूएल (क्वेरी भाषा)
### बुनियादी प्रश्न
| प्रश्न | विवरण |
|-------|----||
| `http_requests_total`| रॉ टाइम सीरीज़ |
| `http_requests_total{method="GET"}`| लेबल द्वारा फ़िल्टर करें |
| `http_requests_total{method="GET", status="200"}`| एकाधिक लेबल फ़िल्टर |
| `rate(http_requests_total[5m])`| 5 मिनट से अधिक प्रति सेकंड की दर |
| `increase(http_requests_total[1h])`| 1 घंटे से अधिक की कुल वृद्धि |
| `sum(rate(http_requests_total[5m])) by (status)`| स्थिति के अनुसार कुल दर |
| `histogram_quantile(0.95, rate(http_duration_bucket[5m]))`| 95वीं प्रतिशतक विलंबता |
| `avg(node_cpu_seconds_total{mode="idle"})`| औसत सीपीयू निष्क्रिय |
| `1 - avg(rate(node_cpu_seconds_total{mode="idle"}[5m]))`| सीपीयू उपयोग |
### सामान्य कार्य
| कार्य | विवरण | उदाहरण |
|---|---|---|
| `rate()`| प्रति सेकंड औसत वृद्धि दर | `rate(requests_total[5m])`|
| `irate()`| पिछले दो डेटा बिंदुओं के आधार पर प्रति सेकंड की दर | `irate(requests_total[1m])`|
| `increase()`| समय सीमा के साथ कुल वृद्धि | `increase(errors_total[1h])`|
| `sum()`| श्रृंखला भर में योग | `sum(rate(requests_total[5m])) by (service)`|
| `avg()`| श्रृंखला भर में औसत | `avg(node_memory_usage)`|
| `histogram_quantile()`| हिस्टोग्राम से मात्रा की गणना करें | `histogram_quantile(0.99, rate(duration_bucket[5m]))`|
| `topk()`| मूल्य के अनुसार शीर्ष K श्रृंखला | `topk(5, rate(requests_total[5m]))`|
| `predict_linear()`| रैखिक भविष्यवाणी | `predict_linear(disk_usage[1h], 4*3600)`|
| `absent()`| जांचें कि क्या मीट्रिक गायब है | `absent(up{job="myapp"})`|

| संकल्पना | विवरण |
|---------|-----------------|
| **डेटा स्रोत** | प्रोमेथियस (या अन्य बैकएंड) से कनेक्शन |

| **पैनल** | एकल विज़ुअलाइज़ेशन (ग्राफ, गेज, टेबल, हीटमैप) |
| **परिवर्तनीय** | डैशबोर्ड के लिए डायनामिक फ़िल्टर (उदाहरण के लिए, उदाहरण चुनें) |
| **टिप्पणी** | ग्राफ़ पर घटनाओं को चिह्नित करें (तैनाती, घटनाएं) |
| **चेतावनी नियम** | ग्राफाना के भीतर थ्रेसहोल्ड-आधारित चेतावनी |
| **टेम्पलेटिंग** | वेरिएबल के साथ पुन: प्रयोज्य डैशबोर्ड पैटर्न |

| पैटर्न | विवरण |
|---------|-----------------|
| **अवलोकन पंक्ति** | मुख्य मेट्रिक्स एक नज़र में: त्रुटि दर, विलंबता, थ्रूपुट |
| **ड्रिल-डाउन** | वेरिएबल्स का उपयोग करके सारांश से विस्तृत दृश्य तक क्लिक करें |
| **लाल विधि** | दर, त्रुटियाँ, अवधि - तीन प्रमुख सेवा मेट्रिक्स |
| **उपयोग विधि** | उपयोग, संतृप्ति, त्रुटियाँ - बुनियादी ढांचे के लिए |
| **स्वर्णिम संकेत** | विलंबता, ट्रैफ़िक, त्रुटियाँ, संतृप्ति (Google की SRE पुस्तक) |

## सचेत करना
### चेतावनी नियम संरचना
```yaml
groups:
  - name: example
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate on {{ $labels.instance }}"
          description: "Error rate is {{ $value | humanizePercentage }}"
```

| संकल्पना | विवरण |
|---------|-----------------|

## समस्या निवारण
| समस्या | समाधान |
|---------|----------|
| **लक्ष्य नीचे** | जांचें कि क्या निर्यातक चल रहा है; नेटवर्क/फ़ायरवॉल की जाँच करें; स्क्रैप कॉन्फ़िगरेशन सत्यापित करें |
| **कोई डेटा नहीं** | मीट्रिक नाम वर्तनी की जाँच करें; लेबल फ़िल्टर की जाँच करें; समय सीमा सत्यापित करें |
| **उच्च कार्डिनैलिटी** | बहुत सारे लेबल संयोजन; लेबल मान कम करें; रिकॉर्डिंग नियमों का उपयोग करें |
| **धीमी क्वेरी** | जटिल प्रश्नों के लिए रिकॉर्डिंग नियमों का उपयोग करें; स्क्रैप अंतराल बढ़ाएँ |
| **चेतावनी थकान** | धुन दहलीज;`for`अवधि जोड़ें; समूह संबंधी अलर्ट |
| **पुनः आरंभ करने के बाद गुम मेट्रिक्स** | प्रोमेथियस डेटा को स्थानीय रूप से संग्रहीत करता है; अवधारण सेटिंग्स की जाँच करें |

## सारांश
प्रोमेथियस नियमित अंतराल पर निर्यातकों से मेट्रिक्स निकालकर सिस्टम की निगरानी करता है। मेट्रिक्स चार प्रकार में आते हैं: काउंटर (केवल ऊपर जाते हैं), गेज (ऊपर और नीचे), हिस्टोग्राम (बकेट किए गए अवलोकन), और सारांश (मात्राएं)। PromQL क्वेरी भाषा है - `rate()`, `increase()`, `histogram_quantile()`, और एकत्रीकरण फ़ंक्शन (`sum`, `avg`) सबसे आम ऑपरेशन हैं। ग्राफाना डैशबोर्ड में प्रोमेथियस डेटा को पैनल, वेरिएबल और एनोटेशन के साथ विज़ुअलाइज़ करता है। अलर्टिंग, ग्रुपिंग, रूटिंग, साइलेंसिंग और अलर्ट को रोकने के लिए अलर्टमैनेजर का उपयोग करता है। मुख्य निगरानी पैटर्न Google के सुनहरे सिग्नल (विलंबता, ट्रैफ़िक, त्रुटियां, संतृप्ति) और सेवाओं के लिए RED विधि (दर, त्रुटियां, अवधि) और बुनियादी ढांचे के लिए USE विधि (उपयोग, संतृप्ति, त्रुटियां) हैं।
