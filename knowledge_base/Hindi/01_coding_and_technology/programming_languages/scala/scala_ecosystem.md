## उपकरण बनाएं
| उपकरण | प्रकार | के लिए सर्वश्रेष्ठ |
|------|------|----------|
| **एसबीटी** | मानक | अधिकांश स्काला परियोजनाएं |
| **मिल** | आधुनिक | तेज़, सरल कॉन्फ़िगरेशन |
| **ग्रैडल** | जावा इंटरऑप | मिश्रित जावा/स्कैला |
| **स्काला-क्ली** | हल्का वजन | स्क्रिप्ट, छोटे प्रोजेक्ट |
```scala
// build.sbt
lazy val root = (project in file("."))
  .settings(
    name := "myapp",
    version := "0.1.0",
    scalaVersion := "3.4.0",
    libraryDependencies ++= Seq(
      "org.http4s" %% "http4s-dsl" % "0.23.25",
      "org.http4s" %% "http4s-ember-server" % "0.23.25",
      "org.typelevel" %% "cats-effect" % "3.5.4",
      "org.scalameta" %% "munit" % "1.0.0" % Test
    )
  )
```

```bash
sbt compile               # compile
sbt test                  # run tests
sbt run                   # run application
sbt package               # create JAR
sbt assembly              # fat JAR (sbt-assembly)
```

## वेब फ्रेमवर्क
| ढाँचा | प्रकार | के लिए सर्वश्रेष्ठ |
|--------|------|-------|
| **http4s** | कार्यात्मक | प्रकार-सुरक्षित HTTP (बिल्लियाँ-प्रभाव) |
| **पेक्को HTTP** | अभिनेता आधारित | अपाचे पेक्को (अक्का कांटा) |
| **प्ले फ्रेमवर्क** | फुल-स्टैक | प्रतिक्रियाशील वेब ऐप्स |
| **ZIO HTTP** | ZIO-आधारित | कार्यात्मक, उच्च प्रदर्शन |
| **फिनात्रा** | ट्विटर | माइक्रोसर्विसेज |
| **तापीर** | समापन बिंदु डीएसएल | टाइप-सुरक्षित एपीआई विवरण |
```scala
// http4s + cats-effect example
import cats.effect.*
import org.http4s.*
import org.http4s.dsl.io.*
import org.http4s.ember.server.*

object HelloWorld extends IOApp.Simple {
  val routes = HttpRoutes.of[IO] {
    case GET -> Root / "hello" => Ok("Hello, World!")
    case GET -> Root / "users" / IntVar(id) =>
      UserService.find(id).flatMap {
        case Some(user) => Ok(user.asJson)
        case None       => NotFound()
      }
  }.orNotFound

  def run = EmberServerBuilder
    .default[IO]
    .withHost(ipv4"0.0.0.0")
    .withPort(port"8080")
    .withHttpApp(routes)
    .build
    .useForever
}
```

```scala
// MUnit example
class UserServiceSuite extends munit.FunSuite {
  test("find user by id") {
    val repo = new InMemoryUserRepo
    repo.insert(User(1, "Alice"))
    val service = new UserService(repo)

    val result = service.find(1).unsafeRunSync()

    assertEquals(result.map(_.name), Some("Alice"))
  }
}
```

## सारांश
स्काला का पारिस्थितिकी तंत्र उद्यम, कार्यात्मक प्रोग्रामिंग और बड़े डेटा तक फैला हुआ है। मानक स्टैक है: बिल्ड के लिए **sbt**, भाषा के लिए **Scala 3**, कार्यात्मक वेब सेवाओं के लिए **http4s + cats-effect** या **ZIO**, डेटाबेस एक्सेस के लिए **Doobie** या **Slick**, परीक्षण के लिए **MUnit**, फ़ॉर्मेटिंग के लिए **scalafmt**, और IDE समर्थन के लिए **InteliJ + Metals**। बड़े डेटा में स्काला हावी है (अपाचे स्पार्क स्काला में लिखा गया है), स्ट्रीमिंग (पेको स्ट्रीम), और कहीं भी जेवीएम प्रदर्शन कार्यात्मक प्रोग्रामिंग से मिलता है। स्काला 3 के स्वच्छ सिंटैक्स, एनम्स और इंटरसेक्शन प्रकार भाषा को अधिक सुलभ बनाते हैं।
