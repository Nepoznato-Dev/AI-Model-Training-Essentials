# जंग - पारिस्थितिकी तंत्र और टूलींग गाइड
यह गाइड रस्ट पारिस्थितिकी तंत्र में आवश्यक उपकरण, ढांचे और बुनियादी ढांचे को शामिल करता है।
---

## पैकेज प्रबंधन एवं निर्माण
| उपकरण | उद्देश्य |
|------|---------|
| **कार्गो** | पैकेज मैनेजर, बिल्ड सिस्टम, टेस्ट रनर |
| **क्रेट्स.आईओ** | आधिकारिक पैकेज रजिस्ट्री |
| **रस्टअप** | टूलचेन इंस्टॉलर और प्रबंधक |
| **कार्गो-संपादन** | निर्भरताएँ जोड़ें/निकालें/अपग्रेड करें |
| **कार्गो-घड़ी** | फ़ाइल परिवर्तनों पर पुनर्निर्माण करें |
| **कार्गो-ऑडिट** | सुरक्षा भेद्यता जांचकर्ता |
| **कार्गो-क्लिपी** | लिंटर (अंतर्निहित) |
| **कार्गो-एफएमटी** | कोड फ़ॉर्मेटर (rustfmt) |
```bash
cargo new project               # new binary project
cargo new --lib project         # new library
cargo build                     # debug build
cargo build --release           # optimized build
cargo run                       # build and run
cargo test                      # run tests
cargo clippy                    # lint
cargo fmt                       # format
cargo doc --open                # generate and view docs
```

## परीक्षण
| उपकरण | उद्देश्य |
|------|---------|
| **कार्गो परीक्षण** | अंतर्निर्मित इकाई + एकीकरण परीक्षण |
| **मानदंड** | बेंचमार्किंग ढांचा |
| **प्रस्ताव** | संपत्ति आधारित परीक्षण |
| **मॉकॉल** | मॉकिंग फ्रेमवर्क |
| **टोकियो::परीक्षण** | Async परीक्षण समर्थन |
| **इंस्टा** | स्नैपशॉट परीक्षण |
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_addition() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[should_panic(expected = "overflow")]
    fn test_overflow() {
        panic!("overflow!");
    }
}
```

## सारांश
रस्ट का पारिस्थितिकी तंत्र सामंजस्यपूर्ण और उच्च गुणवत्ता वाला है, जो कार्गो पर केंद्रित है। मानक स्टैक है: हर चीज़ के लिए **कार्गो** (निर्माण, परीक्षण, प्रकाशन), **टोकियो** एसिंक के लिए, **एक्सम** या **एक्टिक्स-वेब** वेब के लिए, **सर्डे** क्रमबद्धता के लिए, **एसक्यूएलएक्स** डेटाबेस के लिए, और **क्लैप** सीएलआई के लिए। रस्ट की किलर सुविधा बिना किसी रनटाइम निर्भरता के एकल स्थिर बाइनरी के रूप में तैनात हो रही है। पारिस्थितिकी तंत्र सुविधा से अधिक शुद्धता और प्रदर्शन को प्राथमिकता देता है।
