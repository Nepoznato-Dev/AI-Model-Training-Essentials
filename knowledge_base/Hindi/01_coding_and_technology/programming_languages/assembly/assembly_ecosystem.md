# असेंबली - इकोसिस्टम और टूलींग गाइड
यह मार्गदर्शिका असेंबली पारिस्थितिकी तंत्र में आवश्यक उपकरण, असेंबलर और बुनियादी ढांचे को कवर करती है।

## वास्तुकला द्वारा असेंबलर
### x86/x86-64
| असेंबलर | प्लेटफार्म | नोट्स |
|----|-------|-------|
| **NASM** | क्रॉस-प्लेटफ़ॉर्म | सर्वाधिक लोकप्रिय, स्वच्छ वाक्यविन्यास |
| **MASM** | खिड़कियाँ | माइक्रोसॉफ्ट मैक्रो असेंबलर |
| **FASM** | क्रॉस-प्लेटफ़ॉर्म | स्व-मेज़बान, तेज़ |
| **गैस (जैसा)** | लिनक्स/यूनिक्स | जीएनयू असेंबलर (एटी एंड टी सिंटैक्स) |
| **यासम** | क्रॉस-प्लेटफ़ॉर्म | NASM-संगत |
| **यूएएसएम** | क्रॉस-प्लेटफ़ॉर्म | MASM-संगत |
### हाथ
| असेंबलर | प्लेटफार्म | नोट्स |
|----|-------|-------|
| **जीएनयू (एआरएम) के रूप में** | क्रॉस-प्लेटफ़ॉर्म | एआरएम असेंबली |
| **कील एएसएम** | एंबेडेड | एआरएम विकास |
| **एआरएम असेंबलर** | एआरएम | एआरएम कंपाइलर सुइट |
### अन्य
| असेंबलर | वास्तुकला | नोट्स |
|----|---|-------|
| **avr-as** | एवीआर | माइक्रोकंट्रोलर |
| **रसम** | Z80 | रेट्रो कंप्यूटिंग |
| **ca65** | 6502 | एनईएस, कमोडोर |
| **स्पिम/मंगल** | एमआईपीएस | शैक्षिक |
```bash
# NASM (Linux x86-64)
nasm -f elf64 hello.asm -o hello.o
ld hello.o -o hello

# NASM (Windows)
nasm -f win64 hello.asm -o hello.obj
golink /console /entry _start hello.obj

# FASM
fasm hello.asm hello

# GAS (AT&T syntax)
as -o hello.o hello.s
ld hello.o -o hello
```

## उपकरण बनाएं
| उपकरण | उद्देश्य |
|------|---------|
| **बनाओ** | क्लासिक बिल्ड ऑटोमेशन |
| **सीमेक** | क्रॉस-प्लेटफ़ॉर्म बनाता है |
| **ld** | जीएनयू लिंकर |
| **एलएलडी** | एलएलवीएम लिंकर |
| **ऑब्जेक्टकॉपी** | बाइनरी हेरफेर |
| **objdump** | जुदा करना |
| **रीडेल्फ़ / एनएम** | प्रतीक निरीक्षण |
| **हेक्सडम्प** | बाइनरी निरीक्षण |
```makefile
# Makefile for NASM project
ASM = nasm
ASM_FLAGS = -f elf64
LD = ld
TARGET = hello

all: $(TARGET)

$(TARGET): hello.o
	$(LD) hello.o -o $(TARGET)

hello.o: hello.asm
	$(ASM) $(ASM_FLAGS) hello.asm -o hello.o

clean:
	rm -f *.o $(TARGET)
```

## परीक्षण
| उपकरण | उद्देश्य |
|------|---------|
| **कस्टम परीक्षण हार्नेस** | असेंबली टेस्ट फ्रेमवर्क |
| **एकता** | सी-आधारित इकाई परीक्षण (मिश्रित परियोजनाओं के लिए) |
| **गूगल टेस्ट** | C++ परीक्षण (मिश्रित परियोजनाओं के लिए) |
| **कस्टम मैक्रोज़** | अभिकथन मैक्रोज़ |
```nasm
; NASM test example
section .data
    test_pass db "PASS", 10, 0
    test_fail db "FAIL", 10, 0

section .text
    global _start

test_add:
    mov rax, 2
    mov rbx, 3
    add rax, rbx
    cmp rax, 5
    jne .fail
    ; print pass
    mov rax, 1
    mov rdi, 1
    mov rsi, test_pass
    mov rdx, 5
    syscall
    ret
.fail:
    mov rax, 1
    mov rdi, 1
    mov rsi, test_fail
    mov rdx, 5
    syscall
    ret

_start:
    call test_add
    mov rax, 60
    xor rdi, rdi
    syscall
```

## सारांश
असेंबली का पारिस्थितिकी तंत्र वास्तुकला-विशिष्ट और डिज़ाइन द्वारा न्यूनतम है। मानक टूलचेन है: असेंबली के लिए **NASM** (x86/x86-64) या **GNU as** (ARM), लिंकिंग के लिए **ld**, डिबगिंग के लिए **GDB**, रिवर्स इंजीनियरिंग के लिए **Ghidra** या **IDA Pro** और अनुकरण के लिए **QEMU**। असेंबली ऑपरेटिंग सिस्टम विकास, एम्बेडेड सिस्टम, रिवर्स इंजीनियरिंग, प्रदर्शन-महत्वपूर्ण कोड और बूटलोडर विकास में उत्कृष्टता प्राप्त करती है। यह समझने के लिए पारिस्थितिकी तंत्र आवश्यक है कि कंप्यूटर निम्नतम स्तर पर कैसे काम करते हैं। सीखने के लिए, **MARS** (MIPS) और **SASM** (x86) शुरुआती-अनुकूल वातावरण प्रदान करते हैं।
