# सी++ - पारिस्थितिकी तंत्र और टूलींग गाइड
यह मार्गदर्शिका C++ पारिस्थितिकी तंत्र में आवश्यक उपकरण, लाइब्रेरी और बुनियादी ढांचे को शामिल करती है।
---

## कंपाइलर
| संकलक | प्लेटफार्म | नोट्स |
|---|-------|-------|
| **जीसीसी (जी++)** | लिनक्स/यूनिक्स | जीएनयू कंपाइलर संग्रह, व्यापक रूप से उपयोग किया जाता है |
| **क्लैंग++** | क्रॉस-प्लेटफ़ॉर्म | एलएलवीएम-आधारित, उत्कृष्ट निदान |
| **एमएसवीसी** | खिड़कियाँ | माइक्रोसॉफ्ट विजुअल सी++ कंपाइलर |
| **इंटेल वनएपीआई (आईसीपीएक्स)** | क्रॉस-प्लेटफ़ॉर्म | उच्च प्रदर्शन, एचपीसी फोकस |
| **ज़िग सी++** | क्रॉस-प्लेटफ़ॉर्म | बढ़िया क्रॉस-संकलन |
```bash
g++ -std=c++23 -O2 -Wall -Wextra -o app main.cpp
clang++ -std=c++23 -stdlib=libc++ -o app main.cpp
```

## सिस्टम बनाएं
| उपकरण | प्रकार | के लिए सर्वश्रेष्ठ |
|------|------|----------|
| **सीमेक** | क्रॉस-प्लेटफ़ॉर्म | उद्योग मानक, अधिकांश परियोजनाएँ |
| **मेसन** | आधुनिक | तेज़, साफ़ सिंटैक्स, निंजा बैकएंड |
| **बज़ेल** | स्केल | मोनोरेपोस, गूगल-स्केल |
| **कॉनन + सीएमके** | पैकेज-जागरूक | सी++ पैकेज प्रबंधन |
| **xमेक** | आधुनिक | लुआ-आधारित, अंतर्निर्मित पैकेज प्रबंधक |
| **बनाओ** | क्लासिक | सरल यूनिक्स परियोजनाएँ |
| **निंजा** | तेज | निम्न-स्तरीय निर्माण प्रणाली |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.24)
project(myapp LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(myapp src/main.cpp)
target_compile_features(myapp PRIVATE cxx_std_23)

# Find packages
find_package(fmt REQUIRED)
target_link_libraries(myapp PRIVATE fmt::fmt)
```

TEST_CASE("vector operations") {

## सारांश
C++ में सबसे समृद्ध और सबसे जटिल पारिस्थितिकी तंत्र है। मानक टूलचेन है: संकलन के लिए **जीसीसी** या **क्लैंग**, बिल्ड के लिए **सीमेक**, पैकेज के लिए **कॉनन** या **वीसीपीकेजी**, परीक्षण के लिए **गूगल टेस्ट** या **कैच2**, लिंटिंग के लिए **क्लैंग-टिडी**, डिबगिंग के लिए **जीडीबी** और सैनिटाइज़र के लिए **एएसएन/यूबीएसएन**। प्रमुख पुस्तकालयों में उपयोगिताओं के लिए **बूस्ट**, फ़ॉर्मेटिंग के लिए **fmt**, JSON के लिए **nlohmann/json**, लॉगिंग के लिए **spdlog**, गणित के लिए **Eigen** और GUI के लिए **Qt** शामिल हैं। अवधारणाओं, श्रेणियों, कोरटाइन और मॉड्यूल के साथ आधुनिक C++ (20/23) पारिस्थितिकी तंत्र को बदल रहा है। हमेशा`-Wall -Wextra -Werror`के साथ संकलन करें और CI में सैनिटाइज़र का उपयोग करें।
