# टाइपस्क्रिप्ट - इकोसिस्टम और टूलींग गाइड
यह मार्गदर्शिका टाइपस्क्रिप्ट पारिस्थितिकी तंत्र में आवश्यक उपकरण, ढांचे और बुनियादी ढांचे को शामिल करती है। टाइपस्क्रिप्ट अपने अधिकांश पारिस्थितिकी तंत्र को जावास्क्रिप्ट के साथ साझा करता है लेकिन इसके अपने विशेष उपकरण हैं।
---

## कंपाइलर और टाइप चेकिंग
| उपकरण | उद्देश्य |
|------|---------|
| **tsc** | आधिकारिक टाइपस्क्रिप्ट कंपाइलर |
| **टीएस-नोड** | सीधे टीएस चलाएं (देव) |
| **tsx** | तेज़ टीएस निष्पादन (एसबिल्ड) |
| **एसडब्ल्यूसी** | जंग-आधारित कंपाइलर |
| **एस्बिल्ड** | टीएस समर्थन के साथ अल्ट्रा-फास्ट बंडलर |
| **टाइपस्क्रिप्ट एसडीके** | आईडीई एकीकरण |
```bash
tsc --init                      # create tsconfig.json
tsc --noEmit                    # type-check only
tsc --watch                     # watch mode
tsx src/index.ts                # run TypeScript directly
```

---

## पैकेज प्रबंधन
जावास्क्रिप्ट के समान: **npm**, **pnpm**, **यार्न**, **बन**। टाइपस्क्रिप्ट npm रजिस्ट्री (टाइप परिभाषाओं के लिए`@types/*`पैकेज) का उपयोग करता है।
```bash
npm install -D @types/node @types/express  # type definitions
npx typesync                               # auto-install missing types
```

## फुल-स्टैक प्रकार की सुरक्षा
| उपकरण | उद्देश्य |
|------|---------|
| **टीआरपीसी** | कोडजेन के बिना एंड-टू-एंड प्रकार |
| **ज़ोड** | रनटाइम सत्यापन + प्रकार अनुमान |
| **प्रिज्मा** | टाइप-सुरक्षित ओआरएम |
| **बूंदा बांदी** | टाइप-सुरक्षित एसक्यूएल |
| **ओपनएपीआई + कोडजेन** | एपीआई प्रकार पीढ़ी |
```typescript
// Zod: runtime validation with type inference
import { z } from "zod";

const UserSchema = z.object({
  name: z.string().min(2),
  email: z.string().email(),
  age: z.number().int().positive(),
});

type User = z.infer<typeof UserSchema>;
// { name: string; email: string; age: number; }

const user = UserSchema.parse(data); // throws if invalid
```

## तैनाती
जावास्क्रिप्ट के समान: **वर्सेल**, **नेटलिफाई**, **क्लाउडफ्लेयर वर्कर्स**, **डॉकर**, **एडब्ल्यूएस लैम्ब्डा**, आदि। टाइपस्क्रिप्ट जावास्क्रिप्ट में संकलित होता है, इसलिए सभी जेएस परिनियोजन विकल्प काम करते हैं।
---

## सारांश
टाइपस्क्रिप्ट का पारिस्थितिकी तंत्र टाइप सुरक्षा जोड़ते हुए जावास्क्रिप्ट की विशाल लाइब्रेरी का लाभ उठाता है। आधुनिक स्टैक है: निर्माण के लिए **वाइट**, परीक्षण के लिए **विटेस्ट**, लिंटिंग के लिए **टाइपस्क्रिप्ट-एसलिंट**, रनटाइम सत्यापन के लिए **ज़ोड**, एंड-टू-एंड प्रकार की सुरक्षा के लिए **टीआरपीसी**, टाइप-सुरक्षित डेटाबेस एक्सेस के लिए **प्रिज्मा** या **ड्रिज़ल**, और फुल-स्टैक फ्रेमवर्क के लिए **नेक्स्ट.जेएस** या **नक्स्ट**। टाइपस्क्रिप्ट की महाशक्ति जावास्क्रिप्ट पारिस्थितिकी तंत्र की चौड़ाई को बनाए रखते हुए संकलन समय पर बग पकड़ रही है।
