# जावा - पारिस्थितिकी तंत्र और टूलींग गाइड
यह मार्गदर्शिका जावा पारिस्थितिकी तंत्र में आवश्यक उपकरण, ढांचे और बुनियादी ढांचे को शामिल करती है।

## उपकरण बनाएं
| उपकरण | प्रकार | के लिए सर्वश्रेष्ठ |
|------|------|----------|
| **मेवेन** | XML-आधारित | एंटरप्राइज़, कॉन्फ़िगरेशन पर कन्वेंशन |
| **ग्रैडल** | ग्रूवी/कोटलिन डीएसएल | लचीला, Android, बड़े प्रोजेक्ट |
| **चींटी** | XML-आधारित | विरासत परियोजनाएं |
| **बज़ेल** | बहुभाषा | मोनोरेपोस, गूगल-स्केल |
```bash
# Maven
mvn clean install               # build
mvn test                        # run tests
mvn package                     # create JAR/WAR

# Gradle
./gradlew build                 # build
./gradlew test                  # run tests
./gradlew bootRun               # run Spring Boot app
```

## परीक्षण
| ढाँचा | उद्देश्य |
|----|----|
| **जूनिट 5** | मानक परीक्षण रूपरेखा |
| **मॉकिटो** | उपहास |
| **AssertJ** | धाराप्रवाह दावे |
| **टेस्टकंटेनर** | डॉकर-आधारित एकीकरण परीक्षण |
| **वायरमॉक** | HTTP एपीआई मॉकिंग |
| **आर्कयूनिट** | वास्तु परीक्षण |
| **निश्चिंत रहें** | रेस्ट एपीआई परीक्षण |
| **जेएमएच** | माइक्रोबेंचमार्किंग |
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock UserRepository repo;
    @InjectMocks UserService service;

    @Test
    void shouldFindUserById() {
        when(repo.findById(1L)).thenReturn(Optional.of(new User("Alice")));
        var user = service.findById(1L);
        assertThat(user.name()).isEqualTo("Alice");
    }
}
```

## सारांश
एंटरप्राइज़ कंप्यूटिंग में जावा का पारिस्थितिकी तंत्र सबसे परिपक्व है। मानक स्टैक है: बिल्ड के लिए **ग्रैडल** या **मेवेन**, वेब/माइक्रोसर्विसेज के लिए **स्प्रिंग बूट**, परीक्षण के लिए **जूनिट 5 + मॉकिटो**, ओआरएम के लिए **हाइबरनेट**, आईडीई के रूप में **इंटेलिजे आइडिया**, और तैनाती के लिए **डॉकर**। जावा की ताकत इसका विशाल पारिस्थितिकी तंत्र, उद्यम समर्थन और बैकवर्ड संगतता है। आधुनिक जावा (17+) रिकॉर्ड, सीलबंद कक्षाओं, पैटर्न मिलान और वर्चुअल थ्रेड्स के साथ भाषा को पुनर्जीवित कर रहा है।
