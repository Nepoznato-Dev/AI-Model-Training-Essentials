# सी - पारिस्थितिकी तंत्र और टूलींग गाइड
यह मार्गदर्शिका सी पारिस्थितिकी तंत्र में आवश्यक उपकरण, पुस्तकालय और बुनियादी ढांचे को शामिल करती है।
---

## कंपाइलर
| संकलक | प्लेटफार्म | नोट्स |
|---|-------|-------|
| **जीसीसी** | लिनक्स/यूनिक्स | जीएनयू कंपाइलर संग्रह, सबसे व्यापक रूप से उपयोग किया जाने वाला |
| **क्लैंग** | क्रॉस-प्लेटफ़ॉर्म | एलएलवीएम-आधारित, बेहतर त्रुटि संदेश |
| **एमएसवीसी** | खिड़कियाँ | माइक्रोसॉफ्ट विजुअल सी++ कंपाइलर |
| **टीसीसी** | क्रॉस-प्लेटफ़ॉर्म | टिनी सी कंपाइलर, तेज़ कंपाइलर |
| **ज़िग सीसी** | क्रॉस-प्लेटफ़ॉर्म | ज़िग का सी कंपाइलर, बेहतरीन क्रॉस-संकलन |

## सिस्टम बनाएं
| उपकरण | प्रकार | के लिए सर्वश्रेष्ठ |
|------|------|----------|
| **बनाओ** | क्लासिक | सरल परियोजनाएँ, यूनिक्स मानक |
| **सीमेक** | क्रॉस-प्लेटफ़ॉर्म | उद्योग मानक, जटिल परियोजनाएँ |
| **मेसन** | आधुनिक | तेज़, साफ़ वाक्यविन्यास |
| **निंजा** | तेज | निम्न-स्तरीय निर्माण प्रणाली (सीमेक द्वारा प्रयुक्त) |
| **बज़ेल** | स्केल | मोनोरेपोस, गूगल |
| **xमेक** | आधुनिक | लुआ-आधारित, क्रॉस-प्लेटफ़ॉर्म |
```cmake
# CMakeLists.txt example
cmake_minimum_required(VERSION 3.20)
project(myapp C)
set(CMAKE_C_STANDARD 17)
add_executable(myapp src/main.c)
target_link_libraries(myapp m)  # link math library
```

## सारांश
सी का पारिस्थितिकी तंत्र आधुनिक कंप्यूटिंग की नींव है। मानक टूलचेन है: संकलन के लिए **जीसीसी** या **क्लैंग**, बिल्ड के लिए **सीमेक**, डिबगिंग के लिए **जीडीबी**, मेमोरी विश्लेषण के लिए **वालग्रिंड** और लिंटिंग के लिए **क्लैंग-टिडी**। प्रमुख पुस्तकालयों में क्रिप्टो के लिए **OpenSSL**, HTTP के लिए **libcurl**, डेटाबेस के लिए **SQLite** शामिल हैं। सी का पारिस्थितिकी तंत्र डिज़ाइन के हिसाब से न्यूनतम है - आप वही बनाते हैं जिसकी आपको आवश्यकता है। आधुनिक विकास के लिए, परीक्षण के दौरान हमेशा सैनिटाइज़र (ASan, UBSan) का उपयोग करें।
