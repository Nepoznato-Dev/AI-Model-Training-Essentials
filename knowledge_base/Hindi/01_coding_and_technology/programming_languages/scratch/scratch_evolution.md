# स्क्रैच - संस्करण इतिहास और विकास
## समयरेखा
| संस्करण | वर्ष | मुख्य विषय |
|------|------|-------|
| प्री-स्क्रैच | 2003 | एमआईटी मीडिया लैब में स्क्रैच टीम का गठन |
| स्क्रैच 1.0 | 2007 | **प्रारंभिक रिलीज़** — बच्चों के लिए विज़ुअल प्रोग्रामिंग |
| स्क्रैच 1.4 | 2009 | बेहतर ग्राफ़िक्स, अधिक ब्लॉक |
| स्क्रैच 2.0 | 2013 | **प्रमुख**: वेब-आधारित संपादक, क्लाउड वेरिएबल, बैकपैक |
| स्क्रैच 3.0 | 2019 | **प्रमुख**: पूर्ण पुनर्लेखन (HTML5/JS), एक्सटेंशन, पेन |
| स्क्रैच 3.x | 2019–25 | वीडियो सेंसिंग, टेक्स्ट-टू-स्पीच, अनुवाद, माइक्रो:बिट |
| स्क्रैच जूनियर | 2014 | छोटे बच्चों के लिए सरलीकृत संस्करण (5-7) |
| स्क्रैच डेस्कटॉप | 2020 | ऑफ़लाइन संपादक (इलेक्ट्रॉन-आधारित) |
## प्रमुख मील के पत्थर
### मूल (2003-2006)
- **2003**: एमआईटी मीडिया लैब के लाइफलॉन्ग किंडरगार्टन समूह ने स्क्रैच विकास शुरू किया
- मिशेल रेसनिक के नेतृत्व में
- **लक्ष्य**: विज़ुअल ब्लॉक के माध्यम से बच्चों को प्रोग्रामिंग सिखाएं
- इनसे प्रेरित: लोगो (सेमुर पैपर्ट), लेगो लोगो, स्क्वीक एटॉयज़
- नाम: "स्क्रैच" - डीजे स्क्रैचिंग से (मीडिया को एक साथ मिलाना)
### स्क्रैच 1.0 (2007)
- **2007**: पहली सार्वजनिक रिलीज़
- ड्रैग-एंड-ड्रॉप ब्लॉक प्रोग्रामिंग
- स्प्राइट-आधारित परियोजनाएं (अक्षर, एनिमेशन)
- ध्वनि, ग्राफिक्स, एनीमेशन
- स्क्वीक में निर्मित (स्मॉलटॉक)
- **लक्ष्य**: आयु 8-16, लेकिन अधिक व्यापक रूप से अपनाया गया
### स्क्रैच 1.4 (2009)
- बेहतर ग्राफिक्स रेंडरिंग
- अधिक स्प्राइट लाइब्रेरीज़
- बेहतर ध्वनि समर्थन
- स्क्वीक पर निर्मित अंतिम संस्करण
### स्क्रैच 2.0 (2013)
- **संपूर्ण वेब-आधारित संपादक** — ब्राउज़र में चलता है
- क्लाउड वैरिएबल - परियोजनाओं के बीच डेटा साझा करें
- बैकपैक - परियोजनाओं के बीच स्प्राइट/स्क्रिप्ट साझा करें
- कस्टम ब्लॉक (कार्यों की तरह)
- एक्शनस्क्रिप्ट 3 (फ़्लैश) में निर्मित
- सामुदायिक विशेषताएं: रीमिक्स, शेयर, टिप्पणी
### स्क्रैच 3.0 (2019)
- **पूर्ण पुनर्लेखन** — HTML5/जावास्क्रिप्ट (कोई फ़्लैश नहीं)
- टैबलेट, फोन, क्रोमबुक पर काम करता है
- **एक्सटेंशन**:
  - पेन (ड्राइंग)
  - वीडियो सेंसिंग (कैमरा)
  - टेक्स्ट टू स्पीच
  - अनुवाद (गूगल अनुवाद)
  - माइक्रो: बिट (हार्डवेयर)
  - लेगो माइंडस्टॉर्म EV3
  - वीडीओ 2.0
- ध्वनि संपादक में सुधार
- नया पेंट संपादक (वेक्टर + बिटमैप)
- बैकपैक, क्लाउड वैरिएबल बरकरार रखा गया
### स्क्रैच डेस्कटॉप और बियॉन्ड (2020–मौजूदा)
- **2020**: स्क्रैच डेस्कटॉप — ऑफ़लाइन संपादक (इलेक्ट्रॉन-आधारित)
- निरंतर विस्तार विकास
- एआई/एमएल एक्सटेंशन (समुदाय-निर्मित)
- भौतिक कंप्यूटिंग के साथ एकीकरण (माइक्रो: बिट, Arduino)
## ब्लॉक श्रेणियाँ विकास
```
Scratch 1.0 (2007):
  Motion, Looks, Sound, Pen, Control, Sensing, Operators, Variables

Scratch 2.0 (2013):
  + Custom blocks (My Blocks), Lists, Cloud variables

Scratch 3.0 (2019):
  Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
  Extensions: Pen, Video Sensing, Text to Speech, Translate,
              micro:bit, LEGO EV3, WeDo 2.0
```

## प्रोग्रामिंग अवधारणाएँ सिखाई गईं
```
Scratch teaches fundamental CS concepts without syntax:

Sequences:     Stack blocks in order
Loops:         Repeat, Forever, Repeat Until
Conditionals:  If, If-Then-Else
Events:        When Green Flag Clicked, When Key Pressed
Variables:     Score, Timer, custom variables
Lists:         Arrays (called "Lists")
Functions:     Custom blocks (My Blocks) with parameters
Concurrency:   Multiple sprites running simultaneously
Messages:      Broadcast and receive (event-based communication)
Random:        Pick random number
Sensing:       Touching, distance, color detection
```

## मुख्य डिज़ाइन सिद्धांत
```
1. "Low floor" — easy to start (drag and drop)
2. "High ceiling" — complex projects possible
3. "Wide walls" — many types of projects (games, stories, art, music)
4. "Creative" — express yourself through code
5. "Social" — share, remix, collaborate
6. "Fun" — learning through play
7. "Tinkerable" — experiment, iterate, discover
```
