# COBOL - पारिस्थितिकी तंत्र और टूलींग गाइड
यह मार्गदर्शिका COBOL पारिस्थितिकी तंत्र में आवश्यक उपकरण, कंपाइलर और बुनियादी ढांचे को शामिल करती है।
---

## कंपाइलर और कार्यान्वयन
| संकलक | प्रकार | नोट्स |
|-------|------|-------|
| **ग्नुकोबोल (ओपनकोबोल)** | ओपन-सोर्स | सर्वाधिक व्यापक रूप से उपयोग किया जाने वाला निःशुल्क कंपाइलर |
| **आईबीएम एंटरप्राइज कोबोल** | वाणिज्यिक | z/OS मेनफ्रेम मानक |
| **माइक्रो फोकस कोबोल** | वाणिज्यिक | एंटरप्राइज़ COBOL |
| **फुजित्सु कोबोल** | वाणिज्यिक | यूनिक्स कोबोल |
| **अकुकोबोल-जीटी** | वाणिज्यिक | अब माइक्रो फोकस |
| **कोबोल-आईटी** | वाणिज्यिक | GnuCOBOL-आधारित |
```bash
cobc --version              # GnuCOBOL version
cobc -x -o app program.cob  # compile to executable
cobc -m -o lib.so module.cob  # compile to shared library
cobc -free program.cob      # free-format source
```

## सिस्टम बनाएं
| उपकरण | उद्देश्य |
|------|---------|
| **बनाओ** | क्लासिक बिल्ड |
| **GnuCOBOL कंपाइलर** | प्रत्यक्ष संकलन |
| **मेवेन (कोबोल प्लगइन)** | उद्यम बनाता है |
| **जेसीएल** | मेनफ्रेम कार्य नियंत्रण |
| **सीमेक** | क्रॉस-प्लेटफ़ॉर्म (COBOL समर्थन के साथ) |
```makefile
# Makefile for COBOL project
COBOL = cobc
FLAGS = -free -O2 -Wall

SRCS = $(wildcard src/*.cob)
OBJS = $(SRCS:.cob=.o)

all: myapp

myapp: $(OBJS)
	$(COBOL) -x -o $@ $^

%.o: %.cob
	$(COBOL) $(FLAGS) -c $<

clean:
	rm -f $(OBJS) myapp
```

| **GnuCOBOL + SQLite** | एंबेडेड डेटाबेस |
```cobol
       *> SQL example in COBOL
       EXEC SQL
           SELECT NAME, SALARY
           INTO :WS-NAME, :WS-SALARY
           FROM EMPLOYEES
           WHERE EMP_ID = :WS-EMP-ID
       END-EXEC.
       
       IF SQLCODE = 0
           DISPLAY "Name: " WS-NAME
           DISPLAY "Salary: " WS-SALARY
       ELSE
           DISPLAY "Error: " SQLCODE
       END-IF.
```

| **कोबोलयूनिट** | यूनिट परीक्षण (माइक्रो फोकस) |

| **कस्टम स्क्रिप्ट** | शैल-आधारित परीक्षण |
```cobol
       *> Simple test in COBOL
       IDENTIFICATION DIVISION.
       PROGRAM-ID. TEST-ADD.
       
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 WS-A    PIC 9(3) VALUE 5.
       01 WS-B    PIC 9(3) VALUE 3.
       01 WS-RESULT PIC 9(3).
       
       PROCEDURE DIVISION.
           COMPUTE WS-RESULT = WS-A + WS-B
           
           IF WS-RESULT = 8
               DISPLAY "PASS: 5 + 3 = 8"
           ELSE
               DISPLAY "FAIL: Expected 8, got " WS-RESULT
           END-IF
           
           STOP RUN.
```

## सारांश
COBOL के पारिस्थितिकी तंत्र में मेनफ्रेम और एंटरप्राइज़ कंप्यूटिंग का प्रभुत्व है। मानक टूलचेन है: **IBM Enterprise COBOL** z/OS (मेनफ्रेम) पर या **GnuCOBOL** (ओपन-सोर्स, क्रॉस-प्लेटफॉर्म), **Db2** और **VSAM** डेटा के लिए, **CICS** लेनदेन के लिए, और **माइक्रो फोकस** आधुनिकीकरण के लिए उपकरण। COBOL दुनिया के अनुमानित 70% व्यापारिक लेनदेन को संसाधित करता है - बैंकिंग, बीमा, सरकार और स्वास्थ्य सेवा अभी भी COBOL पर बहुत अधिक निर्भर हैं। विरासत प्रणालियों को बनाए रखने और मेनफ्रेम अनुप्रयोगों के आधुनिकीकरण के लिए पारिस्थितिकी तंत्र आवश्यक है। GnuCOBOL COBOL विकास और माइग्रेशन के लिए एक मुफ़्त, ओपन-सोर्स पथ प्रदान करता है।
