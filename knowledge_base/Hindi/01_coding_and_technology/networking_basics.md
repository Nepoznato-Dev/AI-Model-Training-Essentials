# नेटवर्किंग मूल बातें
डेवलपर्स और सिस्टम एडमिन के लिए एक व्यावहारिक संदर्भ - मुख्य अवधारणाएं, प्रोटोकॉल, कमांड और समस्या निवारण।

## ओएसआई मॉडल (7 परतें)
नेटवर्क संचार को समझने के लिए एक वैचारिक ढांचा।
| परत | नाम | कार्य | उदाहरण प्रोटोकॉल |
|-------|------|-------|-------------------|
| 7 | आवेदन | अंतिम-उपयोगकर्ता सेवाएँ | HTTP, HTTPS, FTP, SMTP, DNS, SSH |
| 6 | प्रस्तुति | डेटा फ़ॉर्मेटिंग, एन्क्रिप्शन, संपीड़न | टीएलएस, जेपीईजी, एएससीआईआई |
| 5 | सत्र | कनेक्शन प्रबंधन | नेटबीआईओएस, आरपीसी |
| 4 | परिवहन | शुरू से अंत तक डिलीवरी, त्रुटि सुधार, प्रवाह नियंत्रण | टीसीपी, यूडीपी |
| 3 | नेटवर्क | रूटिंग, संबोधन | आईपी, आईसीएमपी, ओएसपीएफ, बीजीपी |
| 2 | डेटा लिंक | फ़्रेमिंग, त्रुटि का पता लगाना, मैक पते | ईथरनेट, वाई-फाई, पीपीपी |
| 1 | शारीरिक | कच्चा बिट ट्रांसमिशन | ईथरनेट केबल, फाइबर ऑप्टिक्स, रेडियो तरंगें |
व्यवहार में, **टीसीपी/आईपी मॉडल** (4 परतें: लिंक, इंटरनेट, परिवहन, एप्लिकेशन) का उपयोग आमतौर पर इंटरनेट के लिए किया जाता है।

## आईपी एड्रेसिंग
### आईपीवी4
- 32-बिट पता, चार ऑक्टेट के रूप में लिखा गया:`192.168.1.1`
- कुल: ~4.3 बिलियन पते (लेकिन व्यवहार में समाप्त हो गए)।
### आईपीवी6
- 128-बिट पता, हेक्स में लिखा गया:`2001:0db8:85a3:0000:0000:8a2e:0370:7334`
- कुल: 2¹²⁸ पते (व्यावहारिक रूप से अनंत)।
### निजी आईपी रेंज (आरएफसी 1918)
ये इंटरनेट पर निष्क्रिय नहीं हैं; स्थानीय नेटवर्क के अंदर उपयोग किया जाता है:
- __संरक्षित_0__ (10.0.0.0 – 10.255.255.255)
- __संरक्षित_1__ (172.16.0.0 – 172.31.255.255)
- __संरक्षित_2__ (192.168.0.0 – 192.168.255.255)
### सीआईडीआर नोटेशन
`192.168.1.0/24`का अर्थ है कि पहले 24 बिट नेटवर्क उपसर्ग हैं; अंतिम 8 बिट होस्ट हैं। इसमें`192.168.1.0`से`192.168.1.255`तक के पते शामिल हैं।

## डीएनएस (डोमेन नाम सिस्टम)
डोमेन नाम (उदा.,`example.com`) को आईपी पते पर मैप करता है।
### रिकॉर्ड प्रकार
| प्रकार | उद्देश्य |
|------|---------|
| **ए** | डोमेन को IPv4 पते पर मैप करता है |
| **एएएए** | डोमेन को IPv6 पते पर मैप करता है |
| **CNAME** | किसी अन्य डोमेन नाम का उपनाम |
| **एमएक्स** | मेल एक्सचेंज सर्वर |
| **TXT** | मनमाना पाठ (एसपीएफ़, डीकेआईएम, सत्यापन) |
| **एनएस** | डोमेन के लिए नेमसर्वर |
| **एसआरवी** | सेवा रिकॉर्ड (जैसे, एसआईपी के लिए) |
### सामान्य उपकरण```bash
dig example.com            # DNS lookup (detailed)
nslookup example.com       # DNS lookup (simpler)
host example.com           # Quick lookup
dig -x 8.8.8.8             # Reverse lookup (IP to name)
```

## HTTP और HTTPS
### HTTP तरीके
| विधि | विवरण |
|-------|----|
| **प्राप्त करें** | एक संसाधन पुनः प्राप्त करें (निष्क्रिय, सुरक्षित) |
| **पोस्ट** | डेटा सबमिट करें (बेवकूफ़ नहीं) |
| **पुट** | किसी संसाधन को अद्यतन/प्रतिस्थापित करें (इडेम्पोटेंट) |
| **पैच** | आंशिक अद्यतन |
| **हटाएं** | एक संसाधन निकालें (निष्क्रिय) |
### स्थिति कोड
| कोड | मतलब |
|------|---------|
| **1xx** | सूचनात्मक (100 जारी) |
| **2xx** | सफलता (200 ठीक, 201 निर्मित, 204 कोई सामग्री नहीं) |
| **3xx** | पुनर्निर्देशन (301 स्थायी रूप से स्थानांतरित, 302 मिले, 304 संशोधित नहीं) |
| **4xx** | ग्राहक त्रुटि (400 ग़लत अनुरोध, 401 अनधिकृत, 403 निषिद्ध, 404 नहीं मिले, 429 बहुत अधिक अनुरोध) |
| **5xx** | सर्वर त्रुटि (500 आंतरिक सर्वर त्रुटि, 502 खराब गेटवे, 503 सेवा अनुपलब्ध) |
### हेडर
| हेडर | उद्देश्य |
|-------|------|
|  __संरक्षित_0__ | मीडिया प्रकार (`application/json` ,`text/html`) |
|  __संरक्षित_3__ | क्रेडेंशियल्स (जैसे,`Bearer <token>`) |
|  __संरक्षित_5__ | कैशिंग नीति |
| CORS हेडर |  __संरक्षित_6__ , आदि |

## टीएलएस/एसएसएल
HTTP ट्रैफ़िक को एन्क्रिप्ट करता है (HTTPS = TLS पर HTTP)।
- सर्टिफिकेट अथॉरिटीज (सीए) के प्रमाणपत्र सर्वर को प्रमाणित करते हैं।
- क्लाइंट साइड पर प्रमाणपत्र श्रृंखला और होस्टनाम सत्यापित करें।

## फ़ायरवॉल और NAT
### फ़ायरवॉल
- नियमों (स्रोत आईपी, डेस्ट आईपी, पोर्ट, प्रोटोकॉल) के आधार पर ट्रैफ़िक को फ़िल्टर करता है।
- स्टेटफुल फ़ायरवॉल कनेक्शन स्थिति को ट्रैक करते हैं।
### NAT (नेटवर्क एड्रेस ट्रांसलेशन)
- इंटरनेट एक्सेस के लिए निजी आईपी को सार्वजनिक आईपी में अनुवादित करता है।
- पोर्ट अग्रेषण: एक सार्वजनिक पोर्ट को आंतरिक होस्ट/पोर्ट पर मैप करता है।

## सामान्य नेटवर्किंग कमांड
### कनेक्टिविटी परीक्षण
```bash
ping google.com            # ICMP echo request
ping -c 4 8.8.8.8          # ping 4 times
traceroute google.com      # Trace the route (Linux)
tracert google.com         # Windows version
```

### रूटिंग
```bash
ip route show              # Linux: routing table
route -n                   # Older Linux
netstat -r                 # Windows/Mac
```

### नेटवर्क इंटरफेस
```bash
ip addr show               # List interfaces and IPs
ifconfig                   # Older command
```

### डीएनएस
```bash
dig example.com
nslookup example.com
host example.com
```

### किसी बंदरगाह से कनेक्टिविटी
```bash
nc -zv google.com 443      # Netcat: check if port 443 is open
telnet google.com 443      # Telnet to port
curl -v https://google.com # Verbose output
```

### फ़ायरवॉल (लिनक्स iptables/nftables)
```bash
sudo ufw status            # Ubuntu: simple firewall
sudo iptables -L -n        # List rules
```

### नेटवर्क सांख्यिकी
```bash
ss -tulpn                  # Show listening sockets (Linux)
netstat -an                # All sockets (all OS)
```

## लोड संतुलन और रिवर्स प्रॉक्सी
### Nginx रिवर्स प्रॉक्सी के रूप में
```nginx

    listen 80;
    server_name example.com;
    location / {
        proxy_pass http://localhost:3000;

        proxy_set_header X-Real-IP $remote_addr;
