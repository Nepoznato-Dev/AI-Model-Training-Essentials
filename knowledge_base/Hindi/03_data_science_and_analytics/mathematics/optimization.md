# अनुकूलन
अनुकूलन व्यवहार्य समाधानों के एक सेट से सर्वोत्तम समाधान खोजने का गणित है। यह पूछता है: एक फ़ंक्शन और बाधाओं को देखते हुए, कौन सा इनपुट आउटपुट को न्यूनतम (या अधिकतम) करता है? अनुकूलन मशीन लर्निंग का इंजन है - एक मॉडल को प्रशिक्षित करने का अर्थ है हानि फ़ंक्शन को कम करना। यह संचालन अनुसंधान, अर्थशास्त्र, इंजीनियरिंग डिजाइन और वस्तुतः हर मात्रात्मक क्षेत्र में दिखाई देता है।
---

## समस्या सूत्रीकरण
एक सामान्य **अनुकूलन समस्या** का स्वरूप इस प्रकार है:
f(x) को छोटा करें
इसके अधीन: gᵢ(x) ≤ 0 (असमानता बाधाएं), hⱼ(x) = 0 (समानता बाधाएं)
| अवधि | मतलब |
|------|---------|
| **उद्देश्य फलन** f(x) | न्यूनतम करने (या अधिकतम करने) की मात्रा |
| **निर्णय चर** x | वे मूल्य जिन्हें हम नियंत्रित कर सकते हैं |
| **संभावित क्षेत्र** | सभी बाधाओं को संतुष्ट करने वाले सभी x का सेट |
| **वैश्विक न्यूनतम** | सभी व्यवहार्य x के लिए f(x*) ≤ f(x) के साथ व्यवहार्य x* |
| **स्थानीय न्यूनतम** | कुछ पड़ोस में सभी व्यवहार्य x के लिए f(x*) ≤ f(x) के साथ व्यवहार्य x* |
| **उत्तल समस्या** | f उत्तल है, सुसंगत क्षेत्र उत्तल समुच्चय है (स्थानीय न्यूनतम = वैश्विक न्यूनतम) |

## रैखिक प्रोग्रामिंग (एलपी)
जब उद्देश्य और सभी बाधाएं दोनों **रैखिक** हों, तो समस्या एक रैखिक कार्यक्रम है।
### आदर्श फॉर्म
Cᵀx कम करें
विषय: Ax ≤ b, x ≥ 0
जहाँ c, x ∈ ℝⁿ, A ∈ ℝᵐˣⁿ, b ∈ ℝᵐ।
### गुण
| संपत्ति | कथन |
|---|--------|
| उत्तलता | एलपी हमेशा एक उत्तल समस्या है |
| इष्टतम समाधान | हमेशा व्यवहार्य पॉलीटोप के एक शीर्ष (कोने बिंदु) पर |
| अस्तित्व | यदि व्यवहार्य क्षेत्र परिबद्ध और गैर-रिक्त है, तो इष्टतम समाधान मौजूद है |
| मल्टीपल ऑप्टिमा | यदि दो शीर्ष इष्टतम हैं, तो उनके बीच के किनारे पर प्रत्येक बिंदु भी इष्टतम है |
### सिम्पलेक्स विधि
**सिंप्लेक्स विधि** (डैंटज़िग, 1947) व्यवहार्य पॉलीटोप के किनारों के साथ शीर्ष से शीर्ष तक चलती है, हमेशा उद्देश्य में सुधार करती है, जब तक कि इष्टतम तक नहीं पहुंच जाती।
| संपत्ति | मूल्य |
|-------|-------|
| सबसे खराब स्थिति का समय | O(2ⁿ) (घातीय - व्यवहार में दुर्लभ) |
| औसत-मामला समय | अधिकांश व्यावहारिक समस्याओं के लिए बहुपद |
| मुख्य विचार | बेहतर वस्तुनिष्ठ मान के साथ निकटवर्ती शीर्ष पर जाएँ |
**एल्गोरिदम (अवलोकन):**
1. एक बुनियादी व्यवहार्य समाधान (पॉलीटोप का शीर्ष) से प्रारंभ करें
2. एक प्रवेश चर चुनें (वह जो उद्देश्य में सुधार करता है)
3. एक छोड़ने वाला चर चुनें (व्यवहार्यता बनाए रखें)
4. धुरी: नए शीर्ष पर जाएँ
5. तब तक दोहराएँ जब तक सुधार की कोई दिशा मौजूद न हो
### आंतरिक बिंदु विधियाँ
सिम्प्लेक्स का विकल्प: व्यवहार्य क्षेत्र के अंदर से इष्टतम तक पहुंचें।
| संपत्ति | मूल्य |
|-------|-------|
| सबसे खराब स्थिति का समय | बहुपद (O(n³·⁵) कुछ प्रकारों के लिए) |
| व्यावहारिक प्रदर्शन | बड़ी समस्याओं पर सिम्प्लेक्स के साथ प्रतिस्पर्धी |
| मुख्य विचार | आंतरिक भाग के माध्यम से एक "केंद्रीय पथ" का अनुसरण करें |
### कार्यशील एलपी उदाहरण
**समस्या:** एक फैक्ट्री कुर्सियाँ (x₁) और टेबल (x₂) बनाती है।
- लाभ: $30 प्रति कुर्सी, $50 प्रति टेबल
- लकड़ी: 2x₁ + 4x₂ ≤ 100 (बोर्ड फीट उपलब्ध)
- श्रम: x₁ + 3x₂ ≤ 60 (घंटे उपलब्ध)
- अधिकतम: 30x₁ + 50x₂
**समाधान (2 चरों के लिए ग्राफिकल विधि):**
- व्यवहार्य क्षेत्र के शीर्ष: (0,0), (30,0), (40,10), (0,20)
- प्रत्येक शीर्ष पर उद्देश्य का मूल्यांकन करें:
  - (0,0): लाभ = 0
  - (30,0): लाभ = 900
  - (40,10): लाभ = 1700 ← इष्टतम
  - (0,20): लाभ = 1000
- **इष्टतम:** x₁ = 40 कुर्सियाँ, x₂ = 10 टेबल, लाभ = $1700

## उत्तल अनुकूलन
एक समस्या **उत्तल** है यदि उद्देश्य फ़ंक्शन उत्तल है और व्यवहार्य क्षेत्र एक उत्तल सेट है।
### उत्तल सेट और कार्य
| संकल्पना | परिभाषा |
|--|----|
| **उत्तल सेट** | किसी भी x के लिए, y सेट में है और t ∈ [0,1]: tx + (1−t)y भी सेट में है |
| **उत्तल कार्य** | f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y) सभी t ∈ [0,1] के लिए |
| **सख्ती से उत्तल** | t ∈ (0,1) और x ≠ y | के लिए असमानता सख्त है
**मुख्य संपत्ति:** उत्तल अनुकूलन के लिए, प्रत्येक स्थानीय न्यूनतम एक वैश्विक न्यूनतम है।
### सामान्य उत्तल फलन
| कार्य | उत्तल? | कहाँ |
|---|-------|-------|
| कुल्हाड़ी + बी (रैखिक) | हाँ (और अवतल) | हर जगह |
| x² | हाँ | ℝ |
| ईˣ | हाँ | ℝ |
| −लॉग(x) | हाँ | एक्स > 0 |
| \|x\|ᵖ (पी ≥ 1) | हाँ | ℝⁿ |
| अधिकतम(f₁, f₂) यदि f₁, f₂ उत्तल | हाँ | डोमेन का प्रतिच्छेदन |
### धीरे-धीरे उतरना
मशीन लर्निंग में सबसे मौलिक अनुकूलन एल्गोरिदम।
**अद्यतन नियम:** x_{k+1} = x_k − α∇f(x_k)
जहां α > 0 **सीखने की दर** (चरण आकार) है।
| वेरिएंट | अद्यतन नियम | फायदा |
|--|----|----|
| **बैच जीडी** | x ← x − α∇f(x) | स्थिर अभिसरण |
| **स्टोकेस्टिक जीडी (एसजीडी)** | x ← x − α∇fᵢ(x) (एक नमूना) | प्रति पुनरावृत्ति तेज़, स्थानीय न्यूनतम से बच जाता है |
| **मिनी-बैच SGD** | x ← x − α(1/|B|)Σᵢ∈B ∇fᵢ(x) | बैच और स्टोकेस्टिक के बीच संतुलन |
| **गति** | v ← βv − α∇f(x); x ← x + v | समतल क्षेत्रों के माध्यम से तेजी लाता है |
| **एडम** | प्रति पैरामीटर अनुकूली सीखने की दरें | गहन शिक्षण के लिए लीक से हटकर अच्छा काम करता है |
| **आरएमएसप्रॉप** | क्रमिक परिमाण के रनिंग औसत द्वारा सीखने की दर को मापें | आरएनएन के लिए अच्छा है |
### अभिसरण दरें
| विधि | उत्तल च | दृढ़ता से उत्तल एफ |
|--------|---|-----|
| क्रमिक अवतरण | ओ(1/के) | O((1−μ/L)ᵏ) (रैखिक) |
| एसजीडी | O(1/√k) | ओ(1/के) |
| त्वरित जीडी (नेस्टरोव) | O(1/k²) | O((1−√(μ/L))ᵏ) |
जहां k = पुनरावृत्ति गणना, μ = मजबूत उत्तलता पैरामीटर, L = लिप्सचिट्ज़ स्थिरांक।
### सीखने की दर चुनना
| रणनीति | विवरण |
|---|----|
| निश्चित α | सरल लेकिन अलग हो सकता है (बहुत बड़ा) या धीरे-धीरे परिवर्तित हो सकता है (बहुत छोटा) |
| लाइन खोज | α ढूंढें जो ढाल दिशा के साथ f(x − α∇f(x)) को न्यूनतम करता है |
| क्षय कार्यक्रम | α_t = α₀ / (1 + βt) या α_t = α₀ · βᵗ |
| वार्मअप | छोटी शुरुआत करें, वृद्धि करें, फिर क्षय (ट्रांसफार्मर प्रशिक्षण में सामान्य) |
| अनुकूली (एडम) | क्रमिक आँकड़ों के आधार पर प्रति-पैरामीटर सीखने की दरें |

## विवश अनुकूलन
### लैग्रेंज मल्टीप्लायर
समस्या के लिए: h(x) = 0 के अधीन f(x) को न्यूनतम करें।
**लैग्रेंजियन:** L(x, λ) = f(x) + λh(x)
इष्टतम पर: ∇ₓL = 0 और ∇_λL = 0 (जो h(x) = 0 देता है)।
**कार्य उदाहरण:** x + y = 1 के अधीन f(x,y) = x² + y² को न्यूनतम करें।
- एल = x² + y² + λ(x + y − 1)
- ∂L/∂x = 2x + λ = 0 → x = −λ/2
- ∂L/∂y = 2y + λ = 0 → y = −λ/2
- बाधा: x + y = 1 → −λ = 1 → λ = −1
- समाधान: x = 1/2, y = 1/2, f = 1/2
### केकेटी शर्तें
**करुश-कुह्न-टकर (केकेटी) स्थितियाँ** लैग्रेंज मल्टीप्लायरों को असमानता बाधाओं के लिए सामान्यीकृत करती हैं।
के लिए: gᵢ(x) ≤ 0, hⱼ(x) = 0 के अधीन f(x) को न्यूनतम करें।
**लैग्रेंजियन:** L(x, λ, ν) = f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
**केकेटी स्थितियाँ** (इष्टतमता के लिए आवश्यक):
| शर्त | समीकरण |
|----|----|
| स्थिरता | ∇ₓL = 0 |
| प्रारंभिक व्यवहार्यता | gᵢ(x) ≤ 0, hⱼ(x) = 0 |
| दोहरी व्यवहार्यता | λᵢ ≥ 0 |
| पूरक शिथिलता | λᵢgᵢ(x) = 0 सभी i | के लिए
**पूरक शिथिलता** का अर्थ है: यदि बाधा gᵢ सक्रिय नहीं है (gᵢ(x) < 0), तो λᵢ = 0 (बाधा समाधान को प्रभावित नहीं करती है)।
स्लेटर की स्थिति को संतुष्ट करने वाली उत्तल समस्याओं के लिए, केकेटी स्थितियाँ आवश्यक और पर्याप्त दोनों हैं।

## द्वंद्व
प्रत्येक अनुकूलन समस्या (**प्राइमल**) में एक संबद्ध **दोहरी** समस्या होती है।
### कमजोर और मजबूत द्वंद्व
| संकल्पना | कथन |
|---------|--------|
| **दोहरा कार्य** | g(λ, ν) = infₓ L(x, λ, ν) |
| **दोहरी समस्या** | λ ≥ 0 | के अधीन g(λ, ν) को अधिकतम करें
| **कमज़ोर द्वंद्व** | दोहरा इष्टतम ≤ प्रारंभिक इष्टतम (हमेशा कायम रहता है) |
| **मजबूत द्वंद्व** | दोहरा इष्टतम = प्रारंभिक इष्टतम (स्लेटर की स्थिति के साथ उत्तल समस्याओं के लिए मान्य) |
| **द्वैत अंतराल** | प्राइमल ऑप्टिमल − डुअल ऑप्टिमल (मजबूत द्वंद्व के तहत शून्य) |
### द्वंद्व क्यों मायने रखता है
| आवेदन | द्वंद्व कैसे मदद करता है |
|---|-------------------|
| निचली सीमा | डुअल इस बात का प्रमाण पत्र देता है कि प्रारंभिक समाधान कितना अच्छा है |
| एसवीएम | एसवीएम समस्या का दोहराव कर्नेल ट्रिक की ओर ले जाता है |
| संवेदनशीलता विश्लेषण | दोहरे चर मापते हैं कि यदि बाधाओं में ढील दी जाती है तो इष्टतम परिवर्तन कितना होता है |
| अपघटन | बड़ी समस्याओं को दोहरी | के माध्यम से छोटी उपसमस्याओं में विभाजित किया जा सकता है

## पूर्णांक प्रोग्रामिंग
जब कुछ या सभी चर **पूर्णांक** होने चाहिए, तो समस्या बहुत कठिन हो जाती है (सामान्य तौर पर एनपी-हार्ड)।
### प्रकार
| प्रकार | विवरण |
|------|----||
| शुद्ध आईपी | सभी चर पूर्णांक होने चाहिए |
| मिश्रित आईपी (एमआईपी) | कुछ चर पूर्णांक, कुछ सतत |
| बाइनरी आईपी | वेरिएबल्स {0, 1} तक सीमित हैं |
### समाधान के तरीके
| विधि | आइडिया |
|--------|------|
| **शाखा और बाध्य** | उपसमस्याओं में विभाजित करें, एलपी विश्राम को हल करें, काट-छाँट करें |
| **विमान काटना** | एलपी छूट को मजबूत करने के लिए रैखिक बाधाएं जोड़ें |
| **शाखा और काट** | कटिंग विमानों के साथ शाखा-और-बाउंड को संयोजित करें |
| **ह्यूरिस्टिक्स** | लालची, स्थानीय खोज, अनुमानित समाधान के लिए नकली एनीलिंग |

## अनुमानी और मेटाह्यूरिस्टिक विधियाँ
जब सटीक अनुकूलन कठिन होता है, तो अनुमान अच्छे (जरूरी नहीं कि इष्टतम) समाधान ढूंढते हैं।
| विधि | मुख्य विचार | के लिए सर्वश्रेष्ठ |
|--------|----------|----------|
| **क्रमिक अवतरण** | सबसे तीव्र अवतरण का अनुसरण करें | सहज, भिन्न कार्य |
| **न्यूटन की विधि** | दूसरे क्रम (वक्रता) की जानकारी का उपयोग करें | चिकनी, अच्छी तरह से वातानुकूलित समस्याएँ |
| **सिम्युलेटेड एनीलिंग** | घटती संभावना के साथ बदतर समाधान स्वीकार करें | वैश्विक अनुकूलन, संयोजक |
| **जेनेटिक एल्गोरिदम** | चयन, क्रॉसओवर, उत्परिवर्तन का उपयोग करके जनसंख्या का विकास करें | बहुउद्देश्यीय, अभेद्य |
| **कण झुंड** | एजेंट सबसे प्रसिद्ध पदों से प्रभावित होकर अंतरिक्ष का पता लगाते हैं | सतत, गैर-उत्तल |
| **बायेसियन अनुकूलन** | सरोगेट मॉडल बनाएं, अधिग्रहण फ़ंक्शन का उपयोग करें | महंगे ब्लैक-बॉक्स फ़ंक्शन (हाइपरपैरामीटर ट्यूनिंग) |
### अनुकूलन के लिए न्यूटन की विधि
**अद्यतन नियम:** x_{k+1} = x_k − [H(x_k)]⁻¹ ∇f(x_k)
जहां H हेसियन मैट्रिक्स (दूसरे डेरिवेटिव का मैट्रिक्स) है।
| संपत्ति | मूल्य |
|-------|-------|
| अभिसरण दर | द्विघात (इष्टतम के निकट) |
| प्रति-पुनरावृत्ति लागत | हेसियन व्युत्क्रम के लिए O(n³) |
| आवश्यकता है | दो बार अवकलनीय, सकारात्मक निश्चित हेस्सियन |
| अर्ध-न्यूटन (बीएफजीएस) | ग्रेडिएंट्स से अनुमानित हेस्सियन | O(n²) प्रति पुनरावृत्ति |

## मशीन लर्निंग और डेटा साइंस की प्रासंगिकता

| एडम, आरएमएसप्रॉप | गहन शिक्षण के लिए डिफ़ॉल्ट अनुकूलक |

| द्वंद्व | एसवीएम कर्नेल ट्रिक, संवेदनशीलता विश्लेषण, अपघटन विधियां |
| रैखिक प्रोग्रामिंग | संसाधन आवंटन, पोर्टफोलियो अनुकूलन, नेटवर्क प्रवाह |
| पूर्णांक प्रोग्रामिंग | फ़ीचर चयन (बाइनरी), शेड्यूलिंग, कॉम्बिनेटरियल समस्याएं |
| बायेसियन अनुकूलन | हाइपरपैरामीटर ट्यूनिंग (ऑप्टुना, हाइपरऑप्ट) |
| न्यूटन/अर्ध-न्यूटन | छोटी से मध्यम समस्याओं के लिए दूसरे क्रम के तरीके (एल-बीएफजीएस) |

## सारांश
| विधि | समस्या का प्रकार | गारंटी | स्केल |
|--------|---|---|-------|
| सिम्प्लेक्स | रैखिक प्रोग्रामिंग | सटीक इष्टतम | लाखों चर |
| आंतरिक बिंदु | उत्तल (एलपी, क्यूपी, एसओसीपी) | सटीक इष्टतम | बड़े पैमाने पर |
| क्रमिक अवतरण | चिकना मुक्त | स्थानीय मिनट में परिवर्तित हो जाता है | बहुत बड़ा (गहन शिक्षण) |
| एसजीडी | बड़े पैमाने पर अनुभवजन्य जोखिम | अभिसरण (क्षय के साथ) | विशाल डेटासेट |
| न्यूटन/बीएफजीएस | चिकना, दो बार भिन्न | द्विघात अभिसरण | छोटे से मध्यम |
| केकेटी/लैग्रेंज | विवश (उत्तल) | सटीक शर्तों के तहत | मध्यम |
| शाखा और बाध्य | पूर्णांक प्रोग्रामिंग | सटीक इष्टतम | छोटे से मध्यम |
| अनुमान | कोई भी (गैर-उत्तल, संयोजक) | कोई गारंटी नहीं | बदलता रहता है |
मशीन लर्निंग में अनुकूलन यकीनन सबसे महत्वपूर्ण गणितीय उपकरण है। आपके द्वारा प्रशिक्षित प्रत्येक मॉडल - रैखिक प्रतिगमन से लेकर बड़े भाषा मॉडल तक - में एक अनुकूलन समस्या को हल करना शामिल है। यह समझना कि कोई समस्या कब उत्तल है (वैश्विक इष्टतम की गारंटी), कब ग्रेडिएंट डिसेंट अभिसरण होगा, और बाधाओं को कैसे संभालना है, आपको डिजाइन, डिबग और सीखने के एल्गोरिदम में सुधार करने के लिए सैद्धांतिक आधार मिलता है।
