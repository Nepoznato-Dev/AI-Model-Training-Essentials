# डायनामिकल सिस्टम
एक **गतिशील प्रणाली** बताती है कि एक राज्य एक निश्चित नियम के अनुसार समय के साथ कैसे विकसित होता है। ग्रहों की कक्षाओं से लेकर जनसंख्या की गतिशीलता तक, मौसम के पैटर्न से लेकर तंत्रिका नेटवर्क के प्रशिक्षण तक, गतिशील प्रणाली सिद्धांत यह समझने के लिए भाषा और उपकरण प्रदान करता है कि चीजें कैसे बदलती हैं। यह फ़ाइल सामान्य अंतर समीकरण (ओडीई), आंशिक अंतर समीकरण (पीडीई), स्थिरता विश्लेषण, अराजकता और द्विभाजन को कवर करती है।

## साधारण विभेदक समीकरण (ओडीई)
एक ODE एक एकल स्वतंत्र चर (आमतौर पर समय) के संबंध में एक फ़ंक्शन को उसके डेरिवेटिव से जोड़ता है।
### वर्गीकरण
| संपत्ति | प्रकार |
|-------|-------|
| **आदेश** | उच्चतम व्युत्पन्न वर्तमान (प्रथम क्रम, द्वितीय क्रम, आदि) |
| **रैखिक बनाम अरेखीय** | रैखिक: y'' + p(t)y' + q(t)y = g(t); अरैखिक: कुछ और |
| **सजातीय** | जी(टी) = 0 (कोई जबरदस्ती शब्द नहीं) |
| **स्वायत्त** | कोई स्पष्ट समय निर्भरता नहीं: dy/dt = f(y) |
| **निरंतर गुणांक** | p, q स्थिरांक हैं |
### प्रथम-क्रम ODEs
**सामान्य रूप:** dy/dt = f(t, y)
| प्रकार | फॉर्म | समाधान विधि |
|------|------|-----------------|
| वियोज्य | डाई/डीटी = जी(टी)एच(वाई) | अलग करें और एकीकृत करें: ∫dy/h(y) = ∫g(t)dt |
| रैखिक प्रथम क्रम | डाई/डीटी + पी(टी)वाई = क्यू(टी) | एकीकृत कारक: μ(t) = e^(∫p dt) |
| सटीक | M(t,y)dt + N(t,y)dy = 0 ∂M/∂y = ∂N/∂t | संभावित फ़ंक्शन F(t,y) | खोजें
| बर्नौली | डाई/डीटी + पी(टी)वाई = क्यू(टी)वाईⁿ | | को रैखिक करने के लिए v = y^(1−n) रखें
**कार्य उदाहरण (एकीकरण कारक):** dy/dt + 2y = e^(−t), y(0) = 1 को हल करें।
- एकीकृत कारक: μ(t) = e^(∫2 dt) = e^(2t)
- गुणा करें: d/dt[e^(2t)y] = e^(2t) · e^(−t) = e^t
- एकीकृत करें: e^(2t)y = e^t + C
- y(t) = e^(−t) + Ce^(−2t)
- प्रारंभिक स्थिति: y(0) = 1 → 1 = 1 + C → C = 0
- समाधान: y(t) = e^(−t)
### दूसरे क्रम के रैखिक ओडीई
**सामान्य रूप:** ay'' + by' + cy = g(t)
**सजातीय मामला** (g ​​= 0): विशेषता समीकरण ar² + br + c = 0 को हल करें।
| विभेदक | जड़ें | सामान्य समाधान |
|---|-------|------------------|
| b² > 4ac (ओवरडैम्प्ड) | दो भिन्न वास्तविक r₁, r₂ | y = C₁e^(r₁t) + C₂e^(r₂t) |
| b² = 4ac (गंभीर रूप से गीला) | बार-बार वास्तविक मूल r | y = (C₁ + C₂t)e^(rt) |
| b² < 4ac (अंडरडैम्प्ड) | जटिल जड़ें α ± βi | y = e^(αt)(C₁ cos βt + C₂ syn βt) |
**भौतिक व्याख्या:** एक मास-स्प्रिंग-डैम्पर सिस्टम mx'' + bx' + kx = 0.
- अत्यधिक नमी: भारी नमी, कोई दोलन नहीं (दरवाजा करीब)
- गंभीर रूप से नम: दोलन के बिना सबसे तेज़ वापसी (कार निलंबन डिजाइन लक्ष्य)
- अंडरडैम्प्ड: क्षयकारी आयाम (गिटार स्ट्रिंग) के साथ दोलन करता है
### ओडीई की प्रणालियाँ
कई वास्तविक प्रणालियों में कई इंटरैक्टिंग चर शामिल होते हैं:
dx/dt = f(x, y)
डाई/डीटी = जी(एक्स, वाई)
इसे वेक्टर रूप में लिखा जा सकता है: d**x**/dt = **F**(**x**)
**रैखिक प्रणाली:** d**x**/dt = A**x**, जहां A एक मैट्रिक्स है।
समाधान A के eigenvalues ​​​​पर निर्भर करता है:
| स्वदेशी मूल्य | व्यवहार |
|---|----|
| वास्तविक, नकारात्मक दोनों | स्थिर नोड (सभी प्रक्षेप पथ मूल में परिवर्तित होते हैं) |
| दोनों वास्तविक, सकारात्मक | अस्थिर नोड |
| वास्तविक, विपरीत लक्षण | सैडल पॉइंट (अस्थिर) |
| जटिल, नकारात्मक वास्तविक भाग | स्थिर सर्पिल (नम दोलन) |
| जटिल, सकारात्मक वास्तविक भाग | अस्थिर सर्पिल |
| शुद्ध काल्पनिक | केंद्र (बंद कक्षाएँ) |

## चरण चित्र
एक **चरण चित्र** राज्य अंतरिक्ष में एक गतिशील प्रणाली के प्रक्षेपवक्र की कल्पना करता है (स्पष्ट रूप से हल किए बिना)।
### प्रमुख विशेषताऐं
| फ़ीचर | विवरण |
|---------|-----------------|
| **निश्चित बिंदु (संतुलन)** | जहाँ dx/dt = 0 (कोई गति नहीं) |
| **प्रक्षेप पथ** | राज्य स्थान में सिस्टम द्वारा पथ का पता लगाया गया |
| **नलक्लाइन** | वक्र जहां एक घटक का व्युत्पन्न शून्य है |
| **सीमा चक्र** | पृथक बंद कक्षा (स्व-निरंतर दोलन) |
| **आकर्षण का केंद्र** | किसी दिए गए आकर्षणकर्ता की ओर ले जाने वाली प्रारंभिक स्थितियों का सेट |
| **सेपराट्रिक्स** | आकर्षण के विभिन्न घाटियों के बीच की सीमा |
### शिकारी-शिकार मॉडल (लोटका-वोल्टेरा)
dx/dt = αx - βxy (शिकार)
डाई/डीटी = δxy - γy (शिकारी)
**निश्चित बिंदु:**
1. (0, 0) - विलुप्ति (काठी बिंदु)
2. (γ/δ, α/β) - सह-अस्तित्व (केंद्र - बंद कक्षाएँ)
सिस्टम आवधिक दोलन प्रदर्शित करता है: शिकार बढ़ता है → शिकारी बढ़ते हैं → शिकार घटते हैं → शिकारी घटते हैं → चक्र दोहराता है।

## स्थिरता विश्लेषण
### रैखिक स्थिरता
एक निश्चित बिंदु x* के लिए, इसके चारों ओर रैखिक करें: मान लीजिए u = x - x*, फिर du/dt ≈ J(x*)u जहां J जैकोबियन मैट्रिक्स है।
**स्थिरता मानदंड:** निश्चित बिंदु है:
- **स्थिर** यदि J के सभी eigenvalues में नकारात्मक वास्तविक भाग हैं
- **अस्थिर** यदि किसी eigenvalue का वास्तविक भाग सकारात्मक है
- **मामूली रूप से स्थिर** यदि eigenvalues ​​में शून्य वास्तविक भाग हैं (गैर-रेखीय विश्लेषण की आवश्यकता है)
### लायपुनोव स्थिरता
**लायपुनोव की सीधी विधि** रैखिकरण के बिना स्थिरता निर्धारित करती है।
ए **ल्यपुनोव फ़ंक्शन** वी(एक्स) संतुष्ट करता है:
1. V(x*) = 0 और V(x) > 0 x ≠ x* के लिए (सकारात्मक निश्चित)
2. प्रक्षेपपथ के साथ dV/dt ≤ 0 (बढ़ती नहीं)
| शर्त | निष्कर्ष |
|----|----|
| dV/dt< 0 (negative definite) | Asymptotically stable |
| dV/dt ≤ 0 (negative semi-definite) | Stable (but may not converge) |
| dV/dt >0 | अस्थिर |
**कार्य उदाहरण:** सिस्टम dx/dt = −x + y², dy/dt = −y.
- V(x,y) = x² + y² (ऊर्जा जैसा फ़ंक्शन) आज़माएं
- dV/dt = 2x(−x + y²) + 2y(−y) = −2x² + 2xy² − 2y²
- निकट मूल: dV/dt ≈ −2x² − 2y² < 0 (छोटे y के लिए, −2y² हावी है)
- निष्कर्ष: उत्पत्ति स्थानीय रूप से स्पर्शोन्मुख रूप से स्थिर है

## अराजकता सिद्धांत
**अराजकता** नियतिवादी है फिर भी अप्रत्याशित है: प्रणाली सटीक नियमों का पालन करती है, लेकिन प्रारंभिक स्थितियों में छोटे अंतर से काफी भिन्न परिणाम सामने आते हैं।
### अराजकता के लिए आवश्यकताएँ
| संपत्ति | विवरण |
|---|----|
| नियतिवादी | कोई यादृच्छिकता नहीं - सटीक समीकरणों द्वारा शासित |
| प्रारंभिक स्थितियों के प्रति संवेदनशील | निकटवर्ती प्रक्षेप पथ तेजी से भिन्न होते हैं |
| घिरा हुआ | प्रक्षेपपथ अनंत तक नहीं भागते |
| गैर-आवधिक | बिल्कुल कभी नहीं दोहराता |
### लॉरेन्ज़ प्रणाली
नियतिवादी अराजकता का उत्कृष्ट उदाहरण:
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
मानक मापदंडों के साथ σ = 10, ρ = 28, β = 8/3:
- सिस्टम में तीन निश्चित बिंदु हैं, सभी अस्थिर हैं
- प्रक्षेप पथ एक निश्चित बिंदु की परिक्रमा करते हैं, फिर अचानक दूसरे पर स्विच हो जाते हैं
- परिणाम **लॉरेंज अट्रैक्टर** है - भग्न संरचना वाला एक अजीब अट्रैक्टर
**ल्यपुनोव प्रतिपादक:** निकटवर्ती प्रक्षेप पथों के विचलन की दर को मापता है।
- सकारात्मक ल्यपुनोव प्रतिपादक → अराजकता
- मानक मापदंडों के साथ लोरेंज प्रणाली के लिए: सबसे बड़ा घातांक ≈ 0.9 > 0
### लॉजिस्टिक मानचित्र
एक सरल पृथक प्रणाली जो अराजकता प्रदर्शित करती है:
x_{n+1} = rx_n(1 − x_n)
| पैरामीटर आर | व्यवहार |
|---|----|
| 0 < आर < 1 | जनसंख्या समाप्त हो जाती है (x → 0) |
| 1 < आर < 3 | x = 1 − 1/r | पर स्थिर स्थिर बिंदु
| 3 < आर < 3.449 | अवधि-2 दोलन |
| 3.449 < आर < 3.544 | अवधि-4 दोलन |
| 3.544 < आर < 3.570 | अवधि-8, 16, 32, ... (अवधि-दोहरीकरण झरना) |
| आर ≈ 3.570 | अराजकता की शुरुआत |
| 3.570 < आर < 4 | अधिकतर अराजक, आवधिक खिड़कियों के साथ |
| आर = 4 | [0,1] पर पूरी तरह से अराजक |
### तितली प्रभाव
प्रारंभिक स्थितियों पर संवेदनशील निर्भरता का लोकप्रिय नाम। मौसम प्रणालियों में (लोरेंज़ समीकरणों द्वारा प्रतिरूपित), ब्राज़ील में अपने पंख फड़फड़ाने वाली तितली टेक्सास में बवंडर ला सकती है - इसलिए नहीं कि तितली इसका कारण बनती है, बल्कि इसलिए कि छोटी-छोटी गड़बड़ी तेजी से बढ़ती है।

## द्विभाजन सिद्धांत
एक **द्विभाजन** सिस्टम व्यवहार में एक गुणात्मक परिवर्तन है क्योंकि पैरामीटर भिन्न होता है।
### द्विभाजन के प्रकार
| द्विभाजन | सामान्य रूप | क्या होता है |
|---|---|----|
| **सैडल-नोड** | dx/dt = r − x² | दो निश्चित बिंदु प्रकट/ग़ायब हो जाते हैं |
| **ट्रांसक्रिटिकल** | dx/dt = rx − x² | दो निश्चित बिंदु विनिमय स्थिरता |
| **पिचफोर्क (सुपरक्रिटिकल)** | dx/dt = rx − x³ | एक स्थिर बिंदु दो स्थिर + एक अस्थिर में विभाजित हो जाता है |
| **पिचफोर्क (सबक्रिटिकल)** | dx/dt = rx + x³ | अस्थिर शाखाएँ ढह जाती हैं (अक्सर विनाशकारी) |
| **होपफ** | 2डी सिस्टम | स्थिर बिंदु अस्थिर हो जाता है, सीमा चक्र प्रकट हो जाता है |
### द्विभाजन आरेख
निश्चित बिंदुओं बनाम पैरामीटर मान का एक प्लॉट, स्थिरता दर्शाता है (ठोस = स्थिर, धराशायी = अस्थिर)। लॉजिस्टिक मानचित्र के द्विभाजन आरेख से अराजकता की अवधि-दोहरीकरण मार्ग और प्रसिद्ध **फीजेनबाम स्थिरांक** δ ≈ 4.669 (क्रमिक द्विभाजन अंतराल के बीच सार्वभौमिक अनुपात) का पता चलता है।

## आंशिक विभेदक समीकरण (पीडीई)
पीडीई में कई चर और उनके आंशिक व्युत्पन्न के कार्य शामिल होते हैं।
### दूसरे क्रम के रैखिक पीडीई का वर्गीकरण
Au_xx + 2Bu_xy + Cu_yy + ... = 0 के लिए:
| प्रकार | शर्त | व्यवहार | उदाहरण |
|------|-----|----|---|
| **अण्डाकार** | B² − AC< 0 | Steady-state, no time dependence | Laplace's equation: ∇²u = 0 |
| **Parabolic** | B² − AC = 0 | Diffusion, smoothing over time | Heat equation: u_t = αu_xx |
| **Hyperbolic** | B² − AC >0 | तरंग प्रसार, तीक्ष्ण विशेषताओं को सुरक्षित रखता है | तरंग समीकरण: u_tt = c²u_xx |
### ऊष्मा समीकरण
∂u/∂t = α ∂²u/∂x²

## सारांश
| विषय | मूल विचार | कुंजी उपकरण |
|-------|----|---|
| ODEs | कार्य और उनके समय व्युत्पन्न | विशेषता समीकरण, कारकों को एकीकृत करना |
| ODE की प्रणालियाँ | एकाधिक अंतःक्रियात्मक चर | जैकोबियन का आइगेनवैल्यू विश्लेषण |
| चरण चित्र | राज्य स्थान में गतिशीलता की कल्पना | निश्चित बिंदु, अशक्त रेखाएं, सीमा चक्र |
| स्थिरता | क्या व्यवस्था पुनः संतुलन में आ जायेगी? | रैखिककरण, ल्यपुनोव कार्य |
| अराजकता | नियतिवादी अप्रत्याशितता | लायपुनोव प्रतिपादक, अजीब आकर्षणकर्ता |
| द्विभाजन | मापदंडों के साथ गुणात्मक परिवर्तन | सामान्य रूप, द्विभाजन आरेख |
| पीडीई | एकाधिक चर के कार्य | ताप, तरंग और लाप्लास समीकरण |
डायनामिकल सिस्टम सिद्धांत परिवर्तन का गणित है। यह बताता है कि क्यों कुछ प्रणालियाँ स्थिर हो जाती हैं, क्यों कुछ दोलन करती हैं, और क्यों कुछ अराजक व्यवहार करती हैं। डेटा वैज्ञानिकों के लिए, यह प्रशिक्षण गतिशीलता को समझने, स्थिर एल्गोरिदम डिजाइन करने, समय श्रृंखला मॉडलिंग करने और भौतिकी-सूचित मशीन लर्निंग मॉडल की अगली पीढ़ी के निर्माण के लिए उपकरण प्रदान करता है।
