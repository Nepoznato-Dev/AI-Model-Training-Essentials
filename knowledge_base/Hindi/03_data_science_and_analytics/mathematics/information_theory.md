# सूचना सिद्धांत
1948 में क्लाउड शैनन द्वारा स्थापित सूचना सिद्धांत, सूचना को स्वयं निर्धारित करता है। एक संदेश आपको कितना कुछ बताता है? आप डेटा को कितना संपीड़ित कर सकते हैं? आप शोरगुल वाले चैनल पर कितनी तेजी से संवाद कर सकते हैं? इन प्रश्नों के सटीक गणितीय उत्तर हैं। संचार से परे, सूचना सिद्धांत मशीन लर्निंग के लिए मूलभूत बन गया है - क्रॉस-एन्ट्रॉपी वर्गीकरण के लिए डिफ़ॉल्ट हानि फ़ंक्शन है, केएल विचलन वितरण समानता को मापता है, और पारस्परिक जानकारी फीचर चयन को संचालित करती है।
---

## एन्ट्रॉपी
**एंट्रॉपी** एक यादृच्छिक चर की औसत अनिश्चितता या "आश्चर्य" को मापता है।
### शैनन एन्ट्रॉपी (अलग)
संभाव्यता द्रव्यमान फलन p(x) के साथ एक असतत यादृच्छिक चर X के लिए:
H(X) = −Σₓ p(x) log₂ p(x)
इकाइयाँ: **बिट्स** (लॉग₂ का उपयोग करते समय) या **नैट** (एलएन का उपयोग करते समय)।
| वितरण | एन्ट्रॉपी | अंतर्ज्ञान |
|---|---|----|
| उचित सिक्का (पी = 0.5, 0.5) | 1 बिट | द्विआधारी परिणाम के लिए अधिकतम अनिश्चितता |
| पक्षपाती सिक्का (पी = 0.9, 0.1) | 0.469 बिट्स | कम आश्चर्य की बात - अधिकतर सिर |
| नियतात्मक (पी = 1, 0) | 0 बिट्स | बिल्कुल कोई अनिश्चितता नहीं |
| निष्पक्ष पासा (6 भुजाएँ) | 2.585 बिट्स | अधिक परिणाम = अधिक अनिश्चितता |
| n परिणामों पर एकसमान | लॉग₂(एन) बिट्स | n परिणामों के लिए अधिकतम एन्ट्रापी |
### एन्ट्रापी के गुण
| संपत्ति | कथन |
|---|--------|
| गैर-नकारात्मकता | एच(एक्स) ≥ 0 |
| अधिकतम | समान वितरण के लिए समानता के साथ H(X) ≤ log₂(\|X\|) |
| शृंखला नियम | एच(एक्स, वाई) = एच(एक्स) + एच(वाई \| एक्स) |
| कंडीशनिंग कम हो जाती है | एच(एक्स \| वाई) ≤ एच(एक्स) |
| अवतलता | H संभाव्यता वितरण का एक अवतल फलन है |
### विभेदक एन्ट्रॉपी (निरंतर)
घनत्व p(x) के साथ एक सतत यादृच्छिक चर X के लिए:
h(X) = −∫ p(x) log p(x) dx
असतत एन्ट्रापी के विपरीत, विभेदक एन्ट्रापी **नकारात्मक** हो सकती है।
| वितरण | विभेदक एन्ट्रॉपी |
|---|----||
| [ए,बी] पर वर्दी | लॉग(बी − ए) |
| सामान्य एन(μ, σ²) | (1/2) लॉग(2πeσ²) |
| घातीय(λ) | 1 - एलएन(λ) |

## संयुक्त, सशर्त और पारस्परिक जानकारी
### संयुक्त एन्ट्रॉपी
एच(एक्स, वाई) = −Σₓ Σᵧ पी(एक्स, वाई) लॉग पी(एक्स, वाई)
जोड़ी (एक्स, वाई) की कुल अनिश्चितता को मापता है।
### सशर्त एन्ट्रॉपी
एच(वाई | एक्स) = −Σₓ Σᵧ पी(एक्स, वाई) लॉग पी(वाई | एक्स) = एच(एक्स, वाई) − एच(एक्स)
X के अवलोकन के बाद Y के बारे में अनिश्चितता बनी हुई है।
### आपसी जानकारी
I(X; Y) = Σₓ Σᵧ p(x, y) लॉग [p(x, y) / (p(x)p(y))]
यह मापता है कि X को जानना आपको Y के बारे में कितना बताता है (और इसके विपरीत)।
| संपत्ति | कथन |
|---|--------|
| गैर-नकारात्मकता | मैं(एक्स; वाई) ≥ 0 |
| समरूपता | मैं(एक्स; वाई) = मैं(वाई; एक्स) |
| एन्ट्रापी से संबंध | I(X; Y) = H(X) - H(X \| Y) = H(Y) - H(Y \| X) |
| जोड़ से संबंध | I(X; Y) = H(X) + H(Y) − H(X, Y) |
| आज़ादी | I(X; Y) = 0 यदि X और Y स्वतंत्र हैं |
| स्वयं की जानकारी | मैं(एक्स; एक्स) = एच(एक्स) |
### दृश्य: एन्ट्रॉपी आरेख
```
┌─────────────────────────────────────────┐
│            H(X, Y)                      │
│  ┌──────────────┐  ┌──────────────┐    │
│  │   H(X|Y)     │  │   H(Y|X)     │    │
│  │              │I │              │    │
│  │              │( │              │    │
│  │   H(X)−I    │X │   H(Y)−I    │    │
│  │              │; │              │    │
│  │              │Y │              │    │
│  └──────────────┘  └──────────────┘    │
│         H(X)              H(Y)          │
└─────────────────────────────────────────┘
```

## केएल विचलन
**कुल्बैक-लीब्लर (केएल) विचलन** मापता है कि एक वितरण दूसरे से कितना भिन्न है।
D_KL(P || Q) = Σₓ P(x) लॉग [P(x) / Q(x)]
| संपत्ति | कथन |
|---|--------|
| गैर-नकारात्मकता | D_KL(P \|\| Q) ≥ 0 (गिब्स की असमानता) |
| पहचान | D_KL(P \|\| Q) = 0 यदि P = Q |
| विषमता | D_KL(P \|\| Q) ≠ D_KL(Q \|\| P) सामान्य तौर पर |
| मीट्रिक नहीं | समरूपता और त्रिभुज असमानता विफल |
**व्याख्या:** D_KL(P || Q) Q के लिए अनुकूलित कोड का उपयोग करके P से डेटा को एन्कोड करने के लिए आवश्यक बिट्स की अतिरिक्त संख्या है।
### अन्य मात्राओं से संबंध
| रिश्ता | सूत्र |
|---|---|
| क्रॉस-एन्ट्रॉपी | एच(पी, क्यू) = एच(पी) + डी_केएल(पी \|\| क्यू) |
| आपसी जानकारी | I(X; Y) = D_KL(P(X,Y) \|\| P(X)P(Y)) |
| सशर्त केएल | D_KL(P(Y\|X) \|\| Q(Y\|X)) का औसत X |
---

## क्रॉस-एंट्रॉपी
वितरण पी और क्यू के बीच **क्रॉस-एंट्रॉपी**:
H(P, Q) = −Σₓ P(x) लॉग Q(x) = H(P) + D_KL(P || Q)
### एक हानि फ़ंक्शन के रूप में क्रॉस-एन्ट्रॉपी
वर्गीकरण में, P वास्तविक वितरण (वन-हॉट एन्कोडेड लेबल) है और Q मॉडल का अनुमानित वितरण है।
**बाइनरी क्रॉस-एन्ट्रॉपी (बीसीई):**
एल = −[y लॉग(ŷ) + (1−y) लॉग(1−ŷ)]
**श्रेणीबद्ध क्रॉस-एन्ट्रॉपी:**
एल = −Σᵢ yᵢ लॉग(ŷᵢ)
| परिदृश्य | y (सच) | ŷ (अनुमानित) | हानि |
|-------|----------|------------|------|
| सही, आश्वस्त | 1 | 0.95 | 0.051 |
| सही, अनिश्चित | 1 | 0.55 | 0.598 |
| ग़लत, आश्वस्त | 1 | 0.05 | 2.996 |
| ग़लत, अनिश्चित | 1 | 0.45 | 0.799 |
क्रॉस-एन्ट्रॉपी को न्यूनतम करना वास्तविक वितरण से केएल विचलन को कम करने के बराबर है - यही कारण है कि यह हानि फ़ंक्शन के रूप में इतनी अच्छी तरह से काम करता है।

## चैनल क्षमता
### संचार चैनल मॉडल
```
X → [Channel] → Y
```

- एक्स: इनपुट यादृच्छिक चर
- वाई: आउटपुट रैंडम वैरिएबल
- चैनल: सशर्त संभावनाओं द्वारा परिभाषित p(y|x)
### शैनन का शोर चैनल कोडिंग प्रमेय
क्षमता C वाले चैनल के लिए, यदि संचरण दर R< C, there exists a coding scheme that achieves arbitrarily small error probability. If R >C है, तो विश्वसनीय संचार असंभव है।
**चैनल क्षमता:**
सी = अधिकतम_{पी(एक्स)} आई(एक्स; वाई)
### महत्वपूर्ण चैनल उदाहरण
| चैनल | विवरण | क्षमता |
|--|----|---|
| **बाइनरी सममिति (बीएससी)** | प्रत्येक बिट को प्रायिकता p | के साथ फ़्लिप करता है 1 - एच(पी) बिट्स |
| **बाइनरी इरेज़र (बीईसी)** | प्रायिकता ε | के साथ प्रत्येक बिट को मिटा देता है 1 - ε बिट्स |
| **गाऊशियन (AWGN)** | Y = X + Z, Z ~ N(0, σ²) | (1/2)लॉग(1 + एसएनआर) बिट्स |
| **नीरव रहित बाइनरी** | उत्तम संचरण | 1 बिट |

## स्रोत कोडिंग और संपीड़न
### सोर्स कोडिंग प्रमेय
किसी स्रोत को एन्कोड करने के लिए आवश्यक बिट्स की औसत संख्या इसकी एन्ट्रापी द्वारा नीचे दी गई है:
एल ≥ एच(एक्स)
एक इष्टतम कोड L ≈ H(X) प्राप्त करता है।
### हफ़मैन कोडिंग
एक **उपसर्ग-मुक्त** कोड जो अधिक संभावित प्रतीकों को छोटे कोड निर्दिष्ट करता है।
| प्रतीक | संभाव्यता | हफ़मैन कोड | लंबाई |
|--------|---|---|--------|
| ए | 0.5 | 0 | 1 |
| बी | 0.25 | 10 | 2 |
| सी | 0.125 | 110 | 3 |
| डी | 0.125 | 111 | 3 |
औसत लंबाई: 0.5(1) + 0.25(2) + 0.125(3) + 0.125(3) = 1.75 बिट/प्रतीक
एन्ट्रॉपी: एच = 1.75 बिट्स/प्रतीक (इस मामले में इष्टतम!)
### दोषरहित बनाम हानिपूर्ण संपीड़न
| प्रकार | सिद्धांत | उदाहरण | सीमा |
|------|----||-------|-------|
| **दोषरहित** | सांख्यिकीय अतिरेक हटाएँ | ज़िप, पीएनजी, एफएलएसी | एन्ट्रापी दर एच(एक्स) |
| **हानिकारक** | अवधारणात्मक रूप से अप्रासंगिक जानकारी हटाएँ | जेपीईजी, एमपी3, एच.264 | दर-विरूपण फलन R(D) |
**दर-विरूपण सिद्धांत:** अधिकतम विरूपण डी के साथ हानिपूर्ण संपीड़न के लिए, न्यूनतम दर आर(डी) = न्यूनतम आई(एक्स; एक्स̂) है जो ई[डी(एक्स, एक्स̂)] ≤ डी के अधीन है।

## अन्य क्षेत्रों से जुड़ाव
### सूचना सिद्धांत और ऊष्मप्रवैगिकी
| संकल्पना | सूचना सिद्धांत | ऊष्मप्रवैगिकी |
|---------|-------------------|----------------|
| एन्ट्रॉपी | शैनन एन्ट्रॉपी एच(एक्स) | बोल्ट्ज़मैन एन्ट्रॉपी S = k_B ln W |

| आपसी जानकारी | साझा की गई जानकारी | भौतिक प्रणालियों में सहसंबंध |
गणितीय रूप समान हैं - शैनन ने जानबूझकर सांख्यिकीय यांत्रिकी से "एन्ट्रॉपी" शब्द उधार लिया है।

| संकल्पना | आवेदन |
|---------|-----------------|
| अधिकतम संभावना | अनुभवजन्य से मॉडल वितरण तक केएल विचलन को कम करने के बराबर |
| फिशर जानकारी | केएल विचलन की वक्रता; अनुमानक विचरण पर निचली सीमा (क्रैमर-राव) |
| न्यूनतम विवरण लंबाई (एमडीएल) | कुल एन्कोडिंग लंबाई को न्यूनतम करके मॉडल चयन |
| एआईसी/बीआईसी | अनुमानित केएल-आधारित मॉडल चयन मानदंड |

| एन्ट्रॉपी | निर्णय वृक्ष विभाजन मानदंड (सूचना लाभ), आरएल में अन्वेषण (अधिकतम एन्ट्रापी आरएल) |

| अधिकतम एन्ट्रॉपी | मैक्सएंट क्लासिफायर, बायेसियन अनुमान में पूर्व चयन |
| दर-विरूपण | तंत्रिका नेटवर्क में हानिपूर्ण संपीड़न, परिमाणीकरण में व्यापार-बंद को समझना |
| फिशर जानकारी | प्राकृतिक ग्रेडिएंट डिसेंट, पैरामीटर संवेदनशीलता को समझना |
| एमडीएल/एआईसी/बीआईसी | मॉडल चयन, ओवरफिटिंग को रोकना |

## सारांश
| मात्रा | सूत्र (अलग) | मतलब |
